OBJECTIVES OF THE OLYMPICS

1. We will call a finite set S of points on the plane balanced if for any distinct points A and B from the set S there is a point C from the set S such that AC = BC. We will call a set S eccentric if for any three distinct points A, B and C from the set S there is no point P from the set S such that PA = PB = PC. a) Prove that for any integer $n \ge 3$ there is a balanced set consisting of n points. b) Find all integers $n \ge 3$ for which there exists a balanced eccentric set consisting of n points. Netherlands

4. Let Ω be the circle circumscribed about triangle ABC, and point O be its center. Circle $\Gamma$ with center A intersects line segment BC at points D and E so that points B, D, E and C are all distinct and lie on line BC in that order. Let F and G be the intersection points of the circles $\Gamma$ and Ω, and let the points A, F, B, C and G lie on Ω in the indicated order. Let K be the second intersection point of the circumcircle of the triangle BDF and the segment AB. Let L be the second intersection point of the circumcircle of triangle CGE and the segment CA. Let the lines FK and GL be distinct and intersect at point X. Prove that point X lies on line AO. Greece

5. Let R be the set of all real numbers. Find all functions $f : R \to R$ satisfying the equality f ( x + f ( x + y ) ) + f ( xy ) = x + f ( x + y ) + yf ( x ) for all real numbers x and y.

Albania

XLVI International Physics Olympiad

In the city of Mumbai (India), from July 5 to July 12, 2015, the next International Olympiad for Schoolchildren in Physics was held. 84 countries took part in the Olympiad. Participants in the Olympiad were offered three theoretical problems (theoretical round) and two experimental problems (experimental round). All tasks were assessed with a maximum of 10 points. Thus, each participant could score a maximum of 50 points.
