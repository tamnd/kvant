Supreme strategy to the cerrams

1. The beginner loses if each pile contains an odd number of stones. If at least one of the piles contains an even number of stones, then he takes the second pile, and divides the first into two parts so that they each contain an odd number of stones. Then the second player is forced to take one of the piles, and when dividing the second one, one pile with an even number of stones will again appear. Then, having taken the second pile, the first one can again divide into two parts the pile containing four stones.
2. If one of the pegs is already connected to two others, then the one making the next move wins by connecting these two pegs. Therefore, the game will continue as long as “free” pegs can be connected to each other. There are n/2 such pairs of free rings if n is even, and (n-1)/2 if n is odd. If there is an even number of such pairs, then the second one wins, and if there is an odd number, then the first one wins. Therefore, the second one wins if the number of rings has a remainder of 0 or 1 when divided by 4, and loses if this remainder is 2 or 3.
