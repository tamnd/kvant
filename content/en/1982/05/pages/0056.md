The program will be helped to understand by the comments, the numbers of which are included in the program, and the texts are given after it. So, sorting distributed over a 33-character alphabet is performed by the following procedure:

procedure sorter (var f:file; l:integer);
{1}
var i, j: integer;
pocket: array [1..33] of ↑file; {2}
begin
for j to 33 do new(pocket/j]);
for i:=l downto 1 do {4}
begin
for j to 33 do rewrite(pocket/j)↑;
reset(f);
while NOT eof(f) do {7}
begin
write(pocket/number(f↑.keys/i))↑,f↑);
get(f);
end;
rewrite(f);
for j to 33 do {11}
begin
reset(pocket/j)↑;
while NOT eof(pocket/j)↑) do
begin
write(f, pocket/j)↑);
get(pocket/j)↑)
end {end of cycle, read pocket}
end {end of the cycle, circle the pockets}
end {end of the main loop}
end; {end of procedure}

1: $f$ — file to be sorted; $l$ — key length.
2: pocket is an array composed of 33 pointers (according to the number of intermediate files created each time the loop is executed $i$); the order of the elements of the pocket array corresponds to the order of letters in the alphabet abv...eyuya.
3: The *new* procedure creates files pocket $j/j$↑ is a pointer to variables relative to the pocket pointer $j/j$ - elements of the pocket array (see Lesson 19).
4: Main loop through the letters of the key from end to beginning.
5: Cleaning all intermediate files - “pockets” in the cycle; the arrow to the right of the pockets $j/j$ means that what is in parentheses is not an element of the pointer array, but the value that is marked by this pointer, that is, the file.
6: Initial setting of file $f$ for reading.
7: Loop reading records from file $f$.
8: It’s important to understand this. In this line, the first and third arrows are buffer symbols, and the middle one symbolizes the value offset by the pointer. Pocket $j/j$ is the letter of the key, standing in the $i$th (right) place; $f↑.ключи$ — variable pockets field, that is, in the current file record $f$; number($f↑.ключи/i$) - the number of the letter of pockets$j/j$ in the alphabet abv...eyuya, the number($x$) procedure, which converts a letter into the corresponding number, is described in the Addendum on sortings («Kvant» No. 2); pocket/number($f↑.ключи/i$)/↑ — intermediate “pocket” file, defined by the pointer corresponding to the sample; The *write* procedure here rewrites the buffer $f↑$ into the corresponding file - “pocket”.
9: Fetching the next record of file $f$.
10. Cleaning up the $f$ file before creating its next generation.
11. Pocket tracing cycle.
12: Installing a pocket for reading from it.
13: The second parameter of the *write* procedure is the buffer (right arrow) of the pocket file $j/j$↑.
14. Selecting the next element from the pocket. The reader, interested in the task of organizing information, can be recommended for server reading the third volume of D. Knuth’s fundamental work “The Art of Computer Programming.”
This volume is called “Sorting and Search” (M., “Mir”, 1978).
