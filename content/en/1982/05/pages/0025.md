$$\Delta = m^2 + n^2 - 2mn \cos \left( \widehat{L} + 60^\circ \right) - \left( l^2 + n^2 \right) + 2ln \cos \left( \widehat{M} + 60^\circ \right) = m^2 - l^2 + 2n \left( l \cos \left( \widehat{M} + 60^\circ \right) - m \cos \left( \widehat{L} + 60^\circ \right) \right) = m^2 - l^2 + n \left( l \cos \widehat{M} - m \cos \widehat{L} + \sqrt{3} \left( m \sin \widehat{L} - l \sin \widehat{M} \right) \right) = m^2 - l^2 + n \left( l \cos \widehat{M} - m \cos \widehat{L} \right),$$

First decision. Let us prove a more general statement by considering together sequences of prime numbers the sequence $(p_n)$ such that $p_1 = 2, p_2 \geq 3, p_{n+1} - p_n \geq 2$. Let us prove that for any $n$ between the numbers $s_n$ and $s_{n+1}$, where $s_n = p_1 + p_2 + \dots + p_n$, an exact square occurs.

Suppose that for some $n$ there are no squares between the numbers $s_n$ and $s_{n+1}$; that is, for some $k$
$$k^2 \leq s_n < s_{n+1} \leq (k+1)^2.$$

Then $p_{n+1} = s_{n+1} - s_n \leq (k+1)^2 - k^2 = 2k+1$, therefore $p_n \leq p_{n+1} - 2 \leq 2k-1$, etc. - all the correspondences written out in the table in the fields are fulfilled. What number can $x$ be? If $x=3$, then all inequalities must turn into equalities (in this case $k=n$) and
$$s_{n+1} = 2 + p_2 + \dots + p_{n+1} > 1 + 3 + \dots + (2k+1) = (k+1)^2,$$
in contradiction with the right inequality (*). If $x \geq 5$, then $x-2 \geq 3$ and
$$s_n = 2 + p_2 + \dots + p_n < 1 + 3 + \dots + (2k-1) = k^2,$$
in contradiction with the left inequality (*).
