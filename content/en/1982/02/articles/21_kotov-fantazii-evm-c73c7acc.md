Computer fantasies

Figure on the first page of the cover was obtained using a computer as follows. Each closed curve is constructed using a special program using five reference points (one for each curve). The first reference point is selected randomly in a given square. The post-ear points are located - each - at a random distance from the previous one (distances are taken in the range from 0 to 30 mm); the first chord (a segment connecting the first and second support points) has an arbitrary direction; post-ear chords form angles with previous chords, chosen at random in the range from 0 to π/2. In a certain sense, the color of each spot is assigned at random (think about how the color is chosen when figures intersect).

As a result, the resulting spots have random sizes, locations, shapes and colors. But how can a computer act accidentally?

Doesn't the machine execute the definition of a program instruction?

It turns out that a modern computer can be equipped with a program called a random number generator. This program produces a list of numbers that do not follow any simple rules (say, successive decimal places for sin 67°). Operating according to certain instructions with these numbers, the computer becomes an “artist” whose colored figure cannot be predicted in advance even by the mathematician who wrote the program for it.
