◆ Note that any positive number can be represented as the sum of nine numbers containing only the digits 0 and 1 in their decimal notation (the number $\pi = 3,14159265\dots$ is represented in this form in the margins). Let now $a > 0$ be the given number. Representing $\frac{a}{7}$ as the sum of nine numbers containing only the digits 0 and 1 in their decimal notation, and taking into account that $a = 7 \cdot \left(\frac{a}{7}\right)$, we obtain the desired representation of the number $a$.

Problem M712 is obviously generalized: any positive number can be represented as a sum of q-1 numbers, the q-ary notation of which contains only the digits 0 and k (k<q).

E. Turkevich

◆ A finite set of points on a plane can have 0, 1, 2, 3 “almost centers of symmetry” (see figure 1, a)—respectively. Let us show that a finite set M on a plane cannot have more than three “almost centers of symmetry”.

First of all, we note that the set M has a finite number of “almost centers of symmetry”, since they can only be the midpoints of the segments connecting the points of the set M. Let us now choose a straight line on which, when projected, the points of the set M and its “almost centers of symmetry” do not merge. Since upon projection onto a straight line the center of symmetry goes back to the center of symmetry, it is enough to prove our statement for a finite set of points lying on the same straight line.

Consider a set of points on a line with coordinates $x_1 < x_2 < \dots < x_n$. If we throw out the first point, then the center of symmetry of the remaining set can only be the point with coordinate $(x_2 + x_n)/2$; if we throw out the last one, then only the point with coordinate $(x_1 + x_{n-1})/2$; finally, if we throw out some non-extreme point, then the center of symmetry of the remaining set can only be the point with coordinate $(x_1 + x_n)/2$ (see Fig. 2; at figure 2, and we threw out the middle point - the center of symmetry of the remaining set falls into it). This means that a finite set of points on a line, and thereby any finite set of points on a plane, cannot have more than three “almost centers of symmetry.”

V. Prasolov
