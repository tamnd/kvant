6) Amounts
$$\sum_{1 \le k_1 < k_2 < \dots < k_q \le p-1} \prod_i k_i$$
And
$$\sum_{1 \le k_1 < k_2 < \dots < k_q \le p-1} \prod_i (p^-k_i)$$ will differ

only by the order of the terms (if $k<p$, then also $p-k-p$). Therefore, for odd $q$ (3≤q≤2)

$$S_q = \sum_{1 \le k_1 < k_2 < \dots < k_q \le p-1} \prod_i k_i =$$
$$= \sum_{1 \le k_1 k_2 < \dots < k_q \le p-1} \prod_i (p^-k_i) =$$
$$= C_q^{p-1} p^q + \sum_{i=1}^{q-1} (-1)^i C_q^{q-i-j} p^{q-j} S_j - S_q,$$

that is
$$2S_q = C_q^{q-1} p^q + \sum_{j=1}^{q-1} (-1)^j C_q^{q-i-j} p^{q-j} S_j,$$
whence, taking into account that all $S_j$ are divisible by $p$, we obtain that $S_q$ is divisible by $p^2$.
