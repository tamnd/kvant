Let's assume that $q^n+1 = M^2N$, $M > 1$. If the number $N$ is already $n$-valued, that is, if $q^{n-1} \leq N < q^n$, then everything is in order: $N$ itself is suitable as $A$: then $\overline{AA} = N(q^n+1) = M^2N^2$ is an exact square. But for now we can only say that $q^{n-i-1} \leq N < q^{n-i}$, $i \geq 0$ (i.e. $N$ may turn out to be less than $n$-digit). Let's take $r > 1$ such that $r^2 \leq q$ (this can always be done if $q \geq 4$; for example, put $r = 2$), and consider the geometric progression $\{N \cdot r^{2k}\}$, $k = 0, 1, \dots$. Since the first term of this progression is less than $q^n$ and the denominator $r^2 \leq q$, it is clear that it contains the term $B$, which belongs to the interval $[q^{n-1}, q^n]$. Since $B$ has the form $N \cdot r^{2i}$, then, putting $A = B$, we obtain that $\overline{AA}_q = N \cdot r^{2i}(q^n+1) = M^2N^2 \cdot r^{2i}$ is an exact square.

Our reasoning holds for all $q \geq 4$. This leaves the case $q = 2$ and $q = 3$. In the case of $q = 3$ we take $A = 1$ since $\overline{AA}_3 = 11_3 = 1 \cdot 3 + 1 = 4$ is a perfect square. In the case of $q = 2$, putting $n = 3$, we get $2^3 + 1 = 3^2 \cdot 1$, i.e. $N = 1 < 2$, and we need $2^2 \leq N < 2^3$. Multiplying $N = 1$ by $2^2 = 100_2$, we get a three-digit number $A = 100_2$. The number $\overline{AA}_2 = 100 \cdot 100_2 = 36$ is a perfect square.
