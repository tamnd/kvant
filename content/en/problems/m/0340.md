## Condition

Each cell of the rectangular table contains a real number. Some table cells are called its *saddle* cell if the number in it is not less than the other numbers in its line.

a) Let it be known about table $T$ that any table $2 \times 2$ that receives table $T$ at the intersection of two rows and two columns has a saddle cell. Prove that then table $T$ also has a saddle cell.

b) Let $a_1, a_2, \dots, a_m, b_1, b_2, \dots, b_n$ be arbitrary numbers, $p_1, p_2, \dots, p_m, q_1, q_2, \dots, q_n$ be positive numbers. Prove that the table $m \times n$, at the intersection of the $i$th row and the $j$th column of which contains the number $\frac{a_i + b_j}{p_i + q_j}$, has a saddle cell.

One of the solutions to problem 6) can be obtained using a). However, think about how you can solve this problem in another way. (10 grades)

V. P. Gribere

## Solution

A real number is written in each cell of a rectilinear mabiliza. A certain cell of a mabiliza is called its saddle cell if the number in it is not less than the other numbers in its number and not more than the main one.

Let us give one more proof of point 6), independent of a).

Let's consider two functions:

$$f(t) = \max_i (a_i - p_i t),$$

And

$$g(t) = \max_j (q_j t - b_j),$$

defined for all $t$. (Such functions are called piecewise linear; their graphs are broken lines.) The function $f$ is strictly killing, and the function $g$ is strictly increasing (since the numbers $p_i$ and $q_j$ are positive). Therefore, there is a number $t_0$ such that $f(t_0) = g(t_0)$ — Fig. 4.

Let us show that this number $t_0$ is an element of our table. Indeed, for some indices $i_0, j_0$ we have:

$$a_{i_0} - p_{i_0} t_0 = q_{j_0} t_0 - b_{j_0},$$

where

$$t_0 = \frac{a_{i_0} + b_{j_0}}{p_{i_0} + q_{j_0}}.$$

Let us prove that this element $t_0$ is a saddle element for our table. From the definition of function $f$ it follows that

$$a_i - p_i t_0 \leq a_{i_0} - p_{i_0} t_0 = q_{j_0} t_0 - b_{j_0},$$

and, therefore,

$$t_0 \geq \frac{a_i + b_{j_0}}{p_i + q_{j_0}},$$

i.e. the element $t_0$ is not less than the numbers in the same column with it (with the number $j_0$). And from the definition of the function $g$ it follows that

$$q_j t_0 - b_j \leq q_{j_0} t_0 - b_{j_0} = a_{i_0} - p_{i_0} t_0,$$

where

$$t_0 \leq \frac{a_{i_0} + b_{j_0}}{p_{i_0} + q_{j_0}},$$

i.e. the element $t_0$ is not greater than the numbers on the same line with it (with the number $i_0$). The proof is legal.
