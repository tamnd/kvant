## Condition

It is known that among several banknotes whose denominations are pairwise different natural numbers, there are exactly N counterfeit ones. In one check, the detector determines the sum of the denominations of all real banknotes included in the set we have selected. Prove that after N checks it is possible to find all counterfeit bills if: a) N 2; b) N 3. S. Tokarev

## Solution

It is known that among several banknotes whose denominations are pairwise different natural numbers, there are exactly N counterfeit ones. In one check, the detector determines the sum of the denominations of all real banknotes included in the set we have selected. Prove that after N checks it is possible to find all counterfeit bills if: a) N 2; b) N 3.

a) Having checked the set of all banknotes, we find the sum S of the denominations of two counterfeits. Then you can proceed in different ways. Method 1. Pairs of banknotes with a sum of denominations S do not intersect. Taking a banknote from each pair, we will find one counterfeit in this set in one test. Thus, a couple of fakes will be identified. Method 2. Let's check the set of all banknotes whose denominations are less than S 2. There is exactly one counterfeit in this set, which means we recognize it. The second counterfeit is the one whose denomination complements the denomination of the first one up to S. b) Having checked the set of all banknotes, we find the sum S of the denominations of all three counterfeits.
