## Condition

a) At what maximum n is the system of inequalities
$$\begin{cases} 1 < x < 2, \\ 2 < x^2 < 3, \\ 3 < x^3 < 4, \\ \dots \\ n < x^n < n+1 \end{cases}$$
has a solution?

6) For which n there are two progressions - arithmetic a₁, a₂, a₃, ..., aₙ+1 and geometric b₁, b₂, b₃, ..., bₙ, such that a₁ < b₁ < a₂ < b₂ < a₃ < ... < aₙ < bₙ < aₙ+1?
