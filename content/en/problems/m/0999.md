## Condition

a) Prove that for any positive numbers $a_1, a_2, \dots, a_n$ the following inequality holds:

$$\frac{1}{a_1} + \frac{2}{a_1 + a_2} + \dots + \frac{n}{a_1 + a_2 + \dots + a_n} < 4\left(\frac{1}{a_1} + \frac{1}{a_2} + \dots + \frac{1}{a_n}\right).$$

Prove that the constant 4 on the right side of inequality 6) can be replaced by 2;
c cannot be replaced by the number 2.

## Solution

a) Prove that for any positive numbers $a_1, a_2, \dots, a_n$ the inequality holds

$$\frac{1}{a_1} + \frac{2}{a_1 + a_2} + \dots + \frac{n}{a_1 + a_2 + \dots + a_n} < 4\left(\frac{1}{a_1} + \frac{1}{a_2} + \dots + \frac{1}{a_n}\right).$$

Prove that the constant 4 on the right side of inequality 6) can be replaced by 2; c) cannot be replaced by a number less than 2.

**Let us denote by $A_1, B_1, X_1, Y_1$ the points of contact of the sphere with the edges BXY, XYA, YAB, ABX, respectively (see figure). Triangles $AXB_1$ and $AXY_1$ are equal (they have a common side $AX$, and $AB_1=AY_1$ and $XB_1=XY_1$ are tangents drawn to the sphere from a common point), therefore $\angle B_1AX = \angle Y_1AX$. Therefore, the sum of $\angle B_1AX + \angle AXY_1$ is equal to $\angle Y_1AX + \angle AXY_1$, that is, the external angle of the triangle $AY_1X$ at vertex $Y_1$ (at figure marked with a red bow). Likewise, the sum of $\angle A_1BX + \angle BXY_1$ is equal to the outer angle of the triangle $BY_1X$ at $Y_1$ (marked with a blue bow), so $\angle B_1AX + \angle AXB + \angle A_1BX = \angle AY_1B$. Exactly the same

$$\angle B_1AX + \angle AYB + \angle A_1BY = \angle AX_1B.$$

Adding these equalities, we obtain on the left side the sum of angles considered in the problem, and on the right side - quantities that do not depend on X and Y (points $X_1$ and $Y_1$ are determined by the straight line $AB$ and the spheres are unique).

I. F. Sharyzin

**a) Let $b_1, b_2, \dots, b_n$ be a sequence of numbers $a_1, a_2, \dots, a_n$, arranged in ascending order. Since for any $i$ from 1 to $n$

$$\frac{i}{a_1 + a_2 + \dots + a_i} \leq \frac{i}{b_1 + b_2 + \dots + b_i}$$

$$\frac{1}{a_1} + \frac{1}{a_2} + \dots + \frac{1}{a_n} = \frac{1}{b_1} + \frac{1}{b_2} + \dots + \frac{1}{b_n},$$

it is enough to prove the inequality for the numbers $b_i$:

$$\frac{1}{b_1} + \frac{2}{b_1 + b_2} + \dots + \frac{n}{b_1 + b_2 + \dots + b_n} \leq 4\left(\frac{1}{b_1} + \frac{1}{b_2} + \dots + \frac{1}{b_n}\right).$$

Let us evaluate the terms on the left side as follows:

$$\frac{2}{b_1 + b_2} \leq \frac{2}{b_1 + b_1} = \frac{1}{b_1},$$

and for any $k$, $2 \leq k \leq (n+1)/2$,

$$\frac{2k-1}{b_1 + b_2 + \dots + b_{2k-1}} \leq \frac{2k-1}{b_k + \dots + b_{2k-1}} < \frac{2}{b_k-1},$$

$$\frac{2k}{b_1 + b_2 + \dots + b_{2k}} \leq \frac{2k}{b_{k+1} + \dots + b_{2k}} < \frac{2k}{b_k}.$$

This implies the necessary inequality:

6) The example given in part c) suggests that an inequality with a constant 2 on the right-hand side is close to equality when the numbers $a_i/i$ are approximately equal. Let's put $t_i = a_i/i$, $1 \leq i \leq n$. Then for any $m \leq n$ the following estimate is true:

$$\left( p_1 + \dots + p_N \right) \left( \frac{1}{p_1} + \dots + \frac{1}{p_N} \right) \geq
\geq N + \sum_{1 \leq i < j \leq N} \left( \frac{p_i}{p_j} + \frac{p_j}{p_i} \right) \geq
\geq N + \frac{N(N-1)}{2} \cdot 2 = N^2.$$

Cauchy-Bunyakovsky inequality:
$$\left( x_1^2 + \dots + x_n^2 \right) \left( y_1^2 + \dots + y_n^2 \right) \geq
\geq \left( x_1 y_1 + \dots + x_n y_n \right)^2$$

We have applied the inequality given in the margin for $N = \frac{m(m+1)}{2} = 1 + 2 + \dots + m$ numbers, among which $t_j$ is taken $j$ times; the same estimate can be obtained using the Cauchy-Bunyakovsky inequality for the sets $x_i = \sqrt{a_i}$ and $y_i = i/\sqrt{a_i}$, $1 \leq i \leq m$).

Let us add up all such estimates for $m$ from 1 to $n$; the coefficient for $1/a_i$ will be equal to
$$\beta_i = 4i^2 \left( \frac{1}{i(i+1)^2} + \frac{1}{(i+1)(i+1)^2} + \dots + \frac{1}{n(n+1)^2} \right).$$

And since
$$\frac{1}{j(j+1)^2} < \frac{1}{2} \frac{2j+1}{j^2(j+1)^2} = \frac{1}{2} \left( \frac{1}{j^2} - \frac{1}{(j+1)^2} \right),$$
fair assessment
$$\beta_i < 4i^2 \cdot \frac{1}{2} \left( \frac{1}{i^2} - \frac{1}{(n+1)^2} \right) < 2.$$

c) Put $a_i = i$. Then the left side of the inequality is equal to $2\left( \frac{1}{2} + \frac{1}{3} + \dots + \frac{1}{1+n} \right)$, and the right side is $c\left( 1 + \frac{1}{2} + \dots + \frac{1}{n} \right)$, where $c$ is the constant with which we want to replace 4. If $c \leq 2$, then their difference
$$2\left( \frac{1}{2} + \frac{1}{3} + \dots + \frac{1}{n+1} \right) - c\left( 1 + \frac{1}{2} + \dots + \frac{1}{n} \right) =
(2 - c)\left( \frac{1}{2} + \frac{1}{3} + \dots + \frac{1}{n} \right) + \frac{2}{n+1} - c$$

for a sufficiently large $n$ will be positive, since as $n$ increases the sum $\frac{1}{2} + \dots + \frac{1}{n}$ grows without limit.

This follows, for example, from the following estimate: for $n = 2^k$
$$\frac{1}{2} + \frac{1}{3} + \frac{1}{4} + \dots + \frac{1}{2^k} > \frac{1}{2} + \frac{1}{2^2} + \frac{1}{2^3} + \dots + \frac{1}{2^{k-1}} = \frac{k}{2}.$$

On the continuation of the segment AM we plot a point B' such that MB'=MB (see figure). Angle B'MB as an external angle of triangle AMB is equal to the sum of angles MAB and MBA. At the same time, the inscribed angle KMA is measured by half the arc AK and, therefore, is equal to half the sum of the angles MAB and MBA. Therefore MK is the bissertis of the angle B'MB. This means that MK⊥B'B and KB'=KB. It follows that KA=KB=KB'. Dropping the redistributor KH from point K to AM, we obtain AH=HB'=HM+MB, as required.
