## Condition

On the segment [0; 1] points x0, x1, x2, ..., xn are displaced in turn. For each point k (k=1, ..., n), the distance dk from it to the closest point to it from the previously set points changes. Prove that d1+d2+...+dn≤1+\frac{\log_2 n}{2}.

B. S. Grieberg

## Solution

On the segment [0; 1] points $x_0, x_1, x_2, ..., x_n$ are displaced one by one. For each point $x_k$ ($k=1, ..., n$), the distance $d_k$ from it to the closest previously placed point changes. Prove that $d_1+d_2+...+d_n \leq 1 + \frac{\log_2 n}{2}$.

Fig. 2. Transformation of the set $x_0, x_1,...,x_n$ when shifting the point $x_2$: each value $x_2, 0 \leq x_2 \leq 1$ corresponds to a horizontal segment, at the intersection of which with the blue lines the points $x_i$ are located.

Fig. 3.

Let us first show that any set of points $x_0, x_1, ..., x_n$ on the interval [0; 1] is possible without reducing the amount

$$s = d_1 + d_2 + ... + d_n,$$

transform into a set, the first two points of which are 0 and 1, and each next one is the middle of one of the segments into which the previous points are divided [0; 1]. It is clear that you can limit yourself to sets of different points (if the point $x_i$ coincides with one of the previous ones, you can simply cross it out - $d_i=0$ - and add a new point to the end). But it will be convenient for us to allow coincidences.

Let $x_i$ be the leftmost and $x_k$ the rightmost point of the set. Obviously, $s$ will not decrease if we replace $x_i$ with 0, and $x_k$ with 1. In addition, with $i \geq 1$ we can swap $x_i=0$ and $x_{i-1}$ with each other - in this case the sum $d_{i-1}+d_i$ can only increase (Fig. 1), and the remaining sums $s$ will not change. Therefore, henceforth we can assume that $x_0=0$, and $x_1=1$. We will “improve” set $x_0, ..., x_n$ further. Let's consider point $x_2$. If $x_2=x_0$ or $x_2=x_1$, skip it and go to $x_3$. Let now $x_2=x$, $0<x<1$. We will move the point $x_2=x$ along the segment [0; 1] and at the same time one of the segments [0; x] or [x; 1] together with all points falling on it $x_i$ stretch, and the other - skim (Fig. 2). It is clear that then the sum of numbers $d_i$ for points $x_i$ of the segment [0; x] will change proportionally to $x$, and for the segment [x; 1] is proportional to 1—x, so the total sum, as a function of $x$, will be equal

$$s = 1 + \min(x, 1-x) + lx + r(1-x)$$

($d_1=1, d_2=\min(x, 1-x), l$ and $r$ are constants). This function is linear on the intervals [0; 1/2] and [1/2; 1] and has a kink at point $x=1/2$ (Fig. 3), so its maximum is achieved at one of the points $0, 1/2, 1$. Let's move $x_2$ to the maximum point and at the same time, using an appropriate plant (or creating) a set of point $x_i$ on the segments [0; $x_2$] and [$x_2; 1$]. We will obtain a set of points for which the sum $s$ is not less than the first initial one, and the point $x_2$ is either in the middle of the segment [$x_0; x_1$] ($x_2=1/2$) or on the edge of this segment. If, further, $x_3$ does not coincide with any of the points $x_0, x_1$, $x_2$, consider the one of the segments [$x_0; x_2$] and [$x_2; x_1$] on which $x_3$ lies. As above, we can change the set of point $x_i$ on this segment so that point $x_3$ becomes its middle or end, and the sum $s$ does not decrease. Doing the same with the following points, we will arrive at a set in which $x_0=0$, $x_1=1$, and each next point coincides either with the middle of the segment connecting two adjacent points, or with one of these points. All points coinciding with the previous ones can be crossed out, after which a set of $k$ points ($k \leq n$) remains, satisfying the condition formulated at the beginning of the solution.

For such a set of points $d_1=1, d_2=1/2, d_3=1/4, d_4=1/4$ or $1/8$ for $i \geq 2$, each number $d_i$ is equal to $2^{-m}$ with some natural number $m$, and there are at most $2^{m-1}$ numbers $2^{-m}$. It is clear that the sum of the first $n$ such numbers takes on the greatest value when

$$d_1 = 1, \quad d_2 = 1/2, \quad d_3 = d_4 = 1/4, \quad d_5 = \dots = d_8 = 1/8, \dots$$
(1) $(d_i = 2^{-m}$ for $2^{m-1} < i \leq 2^m$), i.e. for a sequence of points

$$0, 1, \frac{1}{2}, \frac{1}{4}, \frac{3}{4}, \frac{1}{8}, \frac{3}{8}, \frac{5}{8}, \frac{7}{8}, \frac{1}{16}, \dots$$

(2)

(fractions with the same values ​​can be rearranged in this sequence). It remains to estimate the sum $s(n) = d_1 + \dots + d_n$ for sequence (1). At $n = 2^m + k, 0 \leq k < 2^m, m \geq 0$,

$$s(n) = 1 + \frac{1}{2} + 2 \cdot \frac{1}{4} + 4 \cdot \frac{1}{8} + \dots + 2^{m-1} \cdot \frac{1}{2^m} + \frac{k}{2^{m+1}} =$$

$$= 1 + \frac{m}{2} + \frac{k}{2^{m+1}},$$

i.e. $s(n) = 1 + (\log_2 n)/2$ at $n = 2^m$, and in sections from $2^m$ to $2^{m+1}$ the function $s(n)$ changes linearly. Since $\log_2 x$ is a convex function, $s(n) \leq 1 + (\log_2 n)/2$ for all natural $n$ (Fig. 4).

It is interesting that the optimal location of points (2) is given by a “greedy” algorithm (this is a completely official term): at each step it is enough to ensure the maximum of the next term, without worrying about what follows.
