## Condition

The function $f$ is defined on the interval $[a; b]$ for 4 and has a continuous derivative $f'$ on it. Prove that inside the segment $[a; b]$ there is a point $x$ for which

$$f'(x) - (f(x))^2 < 1.$$

S. Fomin

## Solution

The function f is defined on the interval [a; b] of length 4 and has a continuous derivative f' on it. Prove that inside the segment [a; b] there is a point x for which

$$f'(x) - (f(x))^2 < 1.$$

Let us assume that the statement of the problem is false, that is, that at all points x∈[a; b] the inequality holds

$$f'(x) - (f(x))^2 \geq 1,$$

or

$$\frac{f'(x)}{1 + (f(x))^2} \geq 1.$$

Since (arctg y)' = $\frac{1}{1 + y^2}$, the derivative of the complex function follows Φ(x) = arctan f(x). So, we know that at all points of the segment [a; b]

$$\Phi'(x) \geq 1.$$

Let's use the Newton-Leibniz formula:

$$\Phi(b) - \Phi(a) = \int_a^b \Phi'(x) dx \geq \int_a^b dx = b - a = 4.$$

But arctg only takes values ​​from the interval $] - \frac{\pi}{2}; \frac{\pi}{2}$ [, which means $\Phi(b) - \Phi(a) < \pi$. We received a contradiction.

From our solution it is clear that the statement of the problem is true for the segment [a; b] of length π (or more). In addition, in our solution we ignored the continuity of the derivative function f.
