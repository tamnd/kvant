## Condition

There were 100 doors, each with its own key (unlocking only that door). The doors are numbered 1, 2, ......, 100, the keys are also numbered, but perhaps with errors: the key number matches the door number or differs by 1. In one attempt, you can select any key, any door and check whether this key fits this door. Is it possible to reliably find out which key opens which door by making no more than: a) 99 attempts; b) 75 attempts; c) 74 attempts? A. Lebedev, A. Shapovalov

The doors are numbered 1, 2, ......, 100, the keys are also numbered, but perhaps with errors: the key number matches the door number or differs by 1. In one attempt, you can select any key, any door and check whether this key fits this door. Is it possible to reliably find out which key opens which door by making no more than: a) 99 attempts; b) 75 attempts; c) 74 attempts?

Answer. a), b) It is possible; c) it is impossible. a) Let's try to see if the first key fits the first door. If yes, then the first key is recognized. If not, then it goes to the second door, and the second key goes to the first door. In this case, two keys are identified. We take the next unidentified key on the left, check it on the corresponding door, and recognize at least one key. If after 99 such attempts there remains something unrecognized, then this is the last key and there is only one door left for it. b) Let's try to see if the third key fits the third door. If it fits, then we can figure out the first two keys in one try. In total, the first three keys were identified in two attempts. If he doesn’t come, then let’s try to see if he comes to the second door. If so, then the first key can only fit the first door, and the second key can only fit the third. Again, in two attempts, the first three keys were identified. If he doesn’t come up again, then he goes to the fourth door. The first two keys can only open two doors, therefore the third door is opened by the fourth key. We'll figure out the first two keys and doors in one try. In this case, four keys were identified in three attempts. We repeat the process: try the third from the left unidentified key to the corresponding door. We recognize three keys in two attempts or four keys in three attempts. If we can no longer complete this step, then there are less than three unrecognized keys left. We will deal with two keys in one attempt, and with one – in zero attempts.
