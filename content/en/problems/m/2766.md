## Condition

Given a natural number n. The “Master Sudoku” field represents $собой^{n} n 1 2$ cells $квадрата^{n} u^{n}$ lying on or below the main diagonal. The master guesses n cells of this field, one in each column, and tells the student about each row how many hidden cells are in it (the student is also aware that there is exactly one hidden cell in each column). The student should be able to use this information to reliably restore the cells hidden by the Master. How many different Sudoku puzzles can a Master create? T.Amdeberhan, M.Rubi, F.Petrov
