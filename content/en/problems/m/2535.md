## Condition

You need to write down a number of the form 77...7, using only sevens (they can be written one at a time or several in a row), and only addition, subtraction, multiplication, division and exponentiation, as well as parentheses, are allowed. For the number 77, the shortest notation is simply 77. Is there a number of the form 77...7 that can be written using these rules using fewer sevens than in its decimal notation? S.Markelov

$М2537^{*}$. There are infinitely many points with natural coordinates marked on the number axis. When a wheel rolls along an axle, each marked point along which the wheel has passed leaves a dotted mark on it. Prove that you can choose a real R such that if you roll a wheel of radius R along the axis, starting from zero, then on each arc of the wheel of size $1 ^\circ$ there will be a trace of at least one marked point. I. Mitrofanov
