## Condition

A non-empty set of nodes is marked on an integer lattice. In addition, a finite set of vectors with integer coordinates is given. It is known that if all given vectors are plotted from any marked node, then among their ends there will be more marked nodes than unmarked ones. Prove that there are infinitely many marked nodes.

D. G. Flaas

## Solution

A non-empty set of nodes is marked on an integer lattice. In addition, a finite set of vectors with integer coordinates is given. It is known that if all given vectors are disconnected from any canceled node, then among their ends there will be more canceled nodes than non-cancelled ones. Prove that there are infinitely many excellent nodes.
