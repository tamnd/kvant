## Condition

A finite set $K_0$ is given. To it are added all the points that can be obtained by symmetrically reflecting one point of this set relative to another. The resulting set is denoted $K_1$. Similarly, from the set $K_1$ one obtains $K_2$, from $K_2 \leftarrow K_3$, etc.

a) Let the set $K_0$ consist of $d$ in $x$ points $A$ and $B$ at a distance $1$. For what minimum $n$ in the set $K_n$ there is a point located at a distance of 10000 from the point $A$?

b) Let $K_0$ be a three-point $K_0 \leftarrow$ set of quadrilateral with area 1. Find the area of ​​the smallest convex polygon containing the set $K_n$ ($n = 1, 2 \ldots$). (8 grades)

In the next three paragraphs $K_0 \leftarrow$ is the set of a quadrilateral with area 1.

b) Consider the smallest convex polygon containing all the points of the polygon $K_1$. How many and what kind of faces does this polygon have?
