## Condition

Several points are given, connected by segments of two chains: some pairs of points - by head segments, some others - by paint. It is known that in any closed path consisting of several segments, the number of beautiful segments is even. Prove that all points can be divided into two sets so that each colored segment connects points from different sets, and each blue segment connects points from the same set.

## Solution

Given several points connected by segments of two cents: some pairs of points - we get segments, several segments, several even segments. Prove that all points can be divided into two sets so that each red segment connects points from different sets, and each blue segment connects points from the same set.

Let's take one of the given points $a$ and consider all the points connected to $a$ by a path from the given segments. If such a path contains an even number (possibly zero) of red segments, then we assign the corresponding point to the set $A$, in particular, $a \in A$; if the number of red segments on such a path is odd, then we assign its end to the set $B$ (see figure). This rule breaks down correctly: if one could come to some point $x$ from $a$ along two different paths, and one of them would have an even and the other an odd number of red segments, then they would form a closed path with an odd number of red segments, which is impossible by condition.

It is clear that any segment connecting points of different sets is red, and any segment connecting two points $y$ and $z$ of set $B$ is also blue - if it were red, then, when connecting it to a path from $a$ and $b$ with an odd number of red segments, we would get a path from $a$ to $z$ with an even number of red segments.
