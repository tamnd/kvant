## Condition

Is it possible to divide the set of all integers into three subsets so that for any integer n the numbers n-50, n+1987 belong to three different subsets?

S. V. Konyazin

## Solution

Can the set of all integers be divided into three subsets so that for any integer n the numbers n, n−50, n+1987 belong to three different subsets?

Answer: no. We will carry out the proof by contradiction. Let us assume that the partition specified in the conditions exists. We will write m≈k if the integers m and k belong to the same subset of the partition, and m≠k if not. Let's prove that n≈n+1937 and n≈n−150

This follows our statement: n≈n+1937. The number n+1937 in the second triple can be replaced by n, i.e. the triple n−100, n−50, n is represented. Substituting n−50 together with n into it, we get another representative triple n−150, n−100, n−50. From the comparison of these two triplets, the second statement follows: n≈n−150.
