## Condition

a) A regular triangle T with side 111 is divided by straight lines parallel to its sides into regular triangles with side 1. All vertices of these triangles, except the center of triangle T, are marked. Let's call a set of several marked points linear if all these points lie on the same straight line parallel to side T. How many ways are there to divide all marked points into 111 linear sets? b) The same question if it is additionally required that each linear set be a segment of marked points (i.e., if two different marked points are included in one linear set, then all marked points on the segment between them are too). I. Bogdanov
