## Condition

Given a table n ѣ n, the columns of which are numbered from 1 to n. The numbers 1, 2, ..., n are placed in the cells of the table so that in each row and in each column all numbers are different. Let's call a cell good if the number in it is greater than the number of the column in which it is located. For what n is there an arrangement in which all rows have the same number of good cells? K.
