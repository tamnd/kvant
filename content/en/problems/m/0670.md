## Condition

a) Given several points, non-tortic pairs of which are connected by lines (the points of such pairs are called neighbors). The number of neighbors of each point is odd. At the initial moment, all points are colored in two colors - red and blue. Then, every minute, a simultaneous recoloring of the point will occur according to the following rule: each point whose most neighbors have a different color from it changes its color; otherwise, its color is retained.

Prove that a moment will come from which some points will not change, and some will have the same point.

b) Will this statement remain true if it is not assumed that each point has an odd number of neighbors?

O. Kozlov

## Solution

a) Several points are given, some pairs of which are connected by lines (the points of such pairs are called connected by them). The number of connections at each point is odd. At the initial moment, all points are colored in two colors - red and blue. Then, every minute, the points are recolored according to the following rule: each point in which the majority of connections has a different color from it changes its color; otherwise its color is preserved. Prove that there will come a moment from which some points will not change color, but some will change every minute. b) Will this statement remain true if it is not assumed that each point has an odd number of connections?
