## Condition

a) Is there a three-digit number whose cube ends in three sevens?
b) For any set of digits, the last of which is not 0, is there a cube ending with this set of digits?

A. Brotsky

## Solution

a) Is there a three-digit number whose cube turns into three sevens?
6) For any set of numbers, the last of which is not 0, is there a cube containing this set of numbers?

a) For the number $n^3$ to end up at 7, the number $n$ itself must end up at 3, so if the desired three-digit number $n$ exists, then $n = ab^3 = 100a + 10b + 3 = 10(10a + b) + 3$. Then $n^3 = 10^3 \cdot A + 10^2(7a + 2b + 9b^2) + 10(7b + 2) + 7$.

The number $7b + 2$ turned to 7 if and only if $7b$ turned to 5, that is, when $b = 5$. Then $n^3 = 10^3 \cdot A + 10^2(7a + 8) + 77$.

The number $7a + 8$ turned to 7 if and only if $a = 7$.

Thus, $753^3$ turned out to be (at least) three sevens.

6) No, not for everyone. If the number $n^3$ turned to 5, then the number $n$ itself turned to 5. But the number $(10a + 5)^3$ turned to 25 if $a$ was even, and to 75 if $a$ was odd. Therefore, for each $n$ the number $n^3$ ended up being 05, 15, 35, 45, 55, 65, 85, 95.

In addition, if the number $n^3$ turned out to be an even digit, then $n^3$ is divisible by 2; then $n$ is divisible by 2 and, therefore, $n^3$ is divisible by 8. But the number $a$ is divisible by 8 if and only if the number formed by its last digits is divisible by 8. This means that for no $n$ the number $n^3$ ended up being an even three-digit number is divisible by 8.

What will be the answer in problem 6), if you require that the last digit of this set be odd and different from 5?
