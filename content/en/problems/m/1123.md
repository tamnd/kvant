## Condition

The primo angle is divided into an infinite number of square cells on the unit side. We will consider a row of cells parallel to the sides of the angle (“vertical” and “horizontal” rows). Is it possible to write a natural number in each cell so that each vertical and each horizontal row of cells contains all the natural numbers once?

V. S. Shevelev

## Solution

The right angle is divided into an infinite number of square cells on the unit side. We will consider rows of cells, parallel sides of the lot (“vertical” and “horizontal” rows). Is it possible to write a natural number in each cell so that each vertical and each horizontal row of cells contains all the natural numbers once?

This question has been answered. However, from the possible arrangements it is constructed by an indication in powers of 2 (Fig. 1). Let a square $A_n$ of size $2^n \times 2^n$ (at the intersection of the first $2^n$ rows and $2^n$ columns) contain numbers from 1 to $2^n$ so that each of them appears once in each row and each column. figure 2 shows how from $A_n$ a square $A_{n+1}$ of size $2^{n+1} \times 2^{n+1}$ is made, in which the numbers from 1 to $2^{n+1}$ are located and the same condition is satisfied; the notation $A_n+2^n$ here means that $2^n$ is added to all numbers of the square $A_n$.

This problem is related to such an interesting question. Let the cells of an infinite chessboard occupying a right angle be lined with the numbers 0, 1, 2, ... as follows: 0 is placed on the first corner cell, and then each cell is assigned the smallest number that is not yet used to number any previous cells located to the left of it on the same horizontal or lower - on the same vertical. What number will the cell at the intersection of the $i$ horizontal line and the $j$ vertical line get? (Numbers are assigned to cells in increasing order of the sum $i+j$; see problem 127 in the book by A. M. and I. M. Yaglomov “Non-elementary problems in an elementary presentation”, M.: 1954, Gostekhteorizdat.)
