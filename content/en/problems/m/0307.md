## Condition

The plane is divided into identical hexagonal rooms (Fig. 2). Some walls have doors in such a way that for any vertex at which three walls (sides of hexagons) meet, there are doors in exactly two walls. Prove that any closed path through such a labyrinth passes through an even number of doors.

V. P. Golubyatnikov

## Solution

The plane is divided into identical six-walled rooms. Some walls have poppy doors, so that for any vertex at which three walls (the sides of the poles) meet, there are doors in exactly two walls. Let us prove that any closed path through a maze passes through an even number of doors.

Let us now have a closed path along the red lines. Generally speaking, it can cross itself. But if he passes through the same room twice, we will split him into d in a closed path. We will do this until we split this path into several closed non-self-intersecting paths. Thus, it is enough to note that every non-self-intersecting path contains an even number of segments.

Let us be given a non-self-intersecting closed path $L$ (one such path is shown at figure by 9 arrows). It limits the part of the plane consisting of rhombuses. Let there be $A$ rhombuses in it. They only have 4A sides. To find out the number of segments of the path $L$, it is necessary to subtract from the number 4A the double number of those sides along which the rhombuses meet. The difference will be an even number, as required.

Another solution can be obtained by making sure that for a given layout it is possible to paint the rooms in two colors so that adjacent rooms have different colors (Fig. 10).

A. L. Toom
