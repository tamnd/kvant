## Condition

On the given plane there is a finite set of points, no three of which lie on the same line. Several segments were drawn with ends at these points. These segments are allowed to be changed: if any two of them, AC and BD, intersect, they can be erased and drawn:
a) segments AB and CD,
b) segments AB and BC.
(If the “new” segment has already been drawn, there is no need to draw it a second time.)
Is it possible after several such replacements (only according to rule a) or only according to rule b), but not according to both) to return to the original set of segments?

V. E. Kolosov
