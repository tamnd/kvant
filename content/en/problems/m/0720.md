## Condition

The following is known about the function $f$, defined on the set of all pairs of non-negative integers $(x; y)$:

$$1^\circ. f(0, y) = y+1,$$
$$2^\circ. f(x+1, 0) = f(x, 1),$$
$$3^\circ. f(x+1, y+1) = f(x, f(x+1, y))$$

for each pair $x \geqslant 0, y \geqslant 0$. Find the value of $f(4, 1981)$.
