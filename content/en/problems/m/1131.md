## Condition

Let $n$ be a natural number and $A_1, A_2, ..., A_{2n+1}$ be a subset of some set $B$. Let's assume that
a) each set $A_i$ ($i=1, 2, ..., 2n+1$) contains exactly $2n$ elements;
b) each set $A_i \cap A_j$ ($1 \leq i < j \leq 2n+1$) contains exactly one element;
b) any element of the set $B$ belongs to at least two of the set $A_i$ ($i=1, 2, ..., 2n+1$).
For what values ​​of $n$ can each element of the set $B$ be assigned one of the numbers - 0 or 1 - so that each of the set $A_1, A_2, ..., A_{2n+1}$ contains exactly $n$ elements corresponding to the number 0?
