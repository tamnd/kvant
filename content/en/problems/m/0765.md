## Condition

Let $B$ be a finite set of points on the plane that do not belong to the same line. a) Prove that there are three points in the set $B$ and that the circle passing through them does not contain other sets $B$.

b) * By triangulation of the set $B$ we define a family of triangles with a set of vertices $B$ that do not overlap each other and form a convex polygon (the triangulation of the set $B$ can be obtained by connecting its points with disjoint segments, as long as this is possible). Prove that for any $B$ there is a triangulation such that the circle circumscribed about any triangle of this triangulation does not contain the sets $B$ within itself. Specify construction method

of such triangulation.
c) * Prove that if no points of the set $B$ lie on the same circle, then the triangulation described in paragraph 6) is unique.
