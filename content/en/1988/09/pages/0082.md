4. 1988. Proof. Let the number 2$^{1987}$ contain $n$ digits, and the number 5$^{1987}$ contain $k$ digits. Then

$$10^{n-1} < 2^{1987} < 10^n \text{ и } 10^{k-1} < 5^{1987} < 10^k.$$

Hence $10^{n+k-2} < 10^{1987} < 10^{n+k}$, which means $k+n-2 < 1987 < k+n$, i.e. 1987=k+n-1, hence $k+n=1988$.
