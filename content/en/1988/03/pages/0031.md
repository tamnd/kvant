$$\alpha_{0A} \leqslant \alpha_0 \leqslant \frac{\pi}{2},$$
then the acceleration $a$ takes on a minimum value at $\alpha_1 = \arccos \left( \frac{4}{3} \cos \alpha_0 \right)$ (see Fig. 2).

$$\Delta = f(1) - f(\cos \alpha_0) = 5 \cos^2 \alpha_0 - 8 \cos \alpha_0 + 3.$$

The maximum value of $f(\cos \alpha)$ (and hence the acceleration of $a$) is either $\cos \alpha = \cos \alpha_0$ or $\cos \alpha = 1$. Distance difference

$$\Delta = f(1) - f(\cos \alpha_0) = 5 \cos^2 \alpha_0 - 8 \cos \alpha_0 + 3.$$

We see that

$$\Delta \leqslant 0 \text{ при } \cos \alpha_0 \geqslant 3/5,$$
$$\Delta > 0 \text{ при } \cos \alpha_0 < 3/5.$$

This means that the acceleration $a$ takes on the maximum value (see Fig. 2)

at $\alpha_2 = \alpha_0$, if $\alpha_0 \leqslant \alpha_{0B} = \arccos \frac{3}{5}$,

at $\alpha_2 = 0$, if $\alpha_{0B} < \alpha_0 \leqslant \frac{\pi}{2}$.
