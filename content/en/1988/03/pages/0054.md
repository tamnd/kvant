Is it possible to connect the structure approach implemented in the school algorithmic language with writing a program in the non-structural language BASIC? It turns out that it is possible. The purpose of this article is to show exactly how it does this. More precisely, we are simply developing a technique that allows us to “automatically” translate programs written in a school algorithmic language into the BASIC language.

At the same time, we will not strive to write the best (say, the shortest) program in BASIC corresponding to an algorithm written in a school algorithmic language. For example, we will enter a number of additional lines (starting with the word REM) that are not needed for the executor (computer), but ensure the structure of the resulting program and its readability.

We assume that the reader is familiar - at least in general terms - with the school algorithmic language and the BASIC language. We believe that we have been given a ready-made program in an algorithmic language; our goal is to translate it into BASIC. This program may contain the following basic constructions of the school algorithmic language: 1) types of variables and CONSTANT; 2) tables; 3) assignment operator; 4) branch operator; 5) loop operator; 6) input and output operators; 7) algorithm title; 8) methods of outputting subroutines, passing parameters.

Let us indicate in order how each of these constructions is translated.

1) The types of variables and CONSTANT in the school algorithmic language are the following: natural, integer, real and literal. In BASIC, the type of a variable is not described, but is indicated by a symbol after the variable name: % - integer, - literal, no symbol - real. natural variables in Bay-

There is no sike, we will use whole ones instead. When translating, we will leave type descriptions in comments (starting with the word REM), and in the program after the names of integer and literal variables we will put % and respectively. For example, if the program contains

nat i, whole k, thing a, lit t
then we write (we denote the line number with the letter n)

n REM NAT I, TARGET K, WEIGHT A, LIT T
and in the program we use the variables I %, N %, A, T ↵.

2) Tables also come in three types. The minimum value of indexes in BASIC is 0. If the program contains tables

int tab x [0:10], int tab k [0:3, 0:5]
we write (line numbers omitted)

REM WEIGHT TAB X [0:10]
OBJECT TAB K [0:3, 0:5]
DIM X (10), K % (3,5)

Note that the line beginning with the word REM will not affect the use of the algorithm (although it is entered into the computer and appears in the program printout). We are writing it in order to provide a more detailed and clear description of the variables than that given by the next translation line.

3) The assignment operator (symbol :=) of the algorithmic language is translated into BASIC by the equal sign (=). For example, the string x:=x+1 is translated as X=X+1.

4) It is proposed to translate the branch operator as follows:

if condition IF (NOT condition) THEN n1
then episode 1 GOTO n2
otherwise n1 REM ELSE
episode 2
all n2 REM ALL
or in abbreviated form (without inchae)
if condition IF (NOT condition) THEN n
then series n REM ALL
here cond are conditions, n1, n2, n are line numbers.

5) The loop operator (while loop) is proposed to be translated according to the following scheme:

while conv n1 IF (NOT conv) THEN n2
no qi GOTO n1
GOTO n1 series
ki n2 REM END OF CYCLE
