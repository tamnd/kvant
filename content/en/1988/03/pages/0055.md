6) Input and output operators are, strictly speaking, absent in algorithmic language. If, however, they are added to the language (for example, as in «Kvant», 1986, No. 11, p. 40 or as in “E - workshop” *), then they are translated by the words INPUT and PRINT, respectively. Otherwise, at the end of the BASIC program you should write PRINT X, where X is the name of the variable (or list of variable names) that appears after the word REM. The word con is replaced by RETURN (or by END in the main program), the word begin is ignored.

7) The title of the algorithm (procedure, function or main program) is written in comments, i.e., rewritten after the word REM. The word con is replaced by RETURN (or by END in the main program), the word begin is ignored.

To organize a subroutine in BASIC there are GOSUB and RETURN operators. For example, to output the KBUR (a, b, c, x₁, x₂) subroutine (starting at line 170 and calculating the x₁ and x₂ roots of the quadratic equation ax²+bx+c=0), to solve the equation x²+(P+2)x+4Q, you would write:
REM KBUR (1, P+2, Q*4, X, y)
A=1
B=P+2
C=Q*4
GOSUB 170
X=X1
Y=X2
REM END OF CALL KBUR
