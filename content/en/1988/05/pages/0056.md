Note that the basic blue sea algorithm is an image plan. The corresponding auxiliary algorithm is “responsible” for drawing individual objects. In the BASIC language, access to an auxiliary algorithm (subroutine) is carried out by the operator
N GOSUB start-number,
where start-number is the number of the statement with which the subroutine begins.
The BASIC operator N RETURN is used as the end operator of the auxiliary algorithm (con)

(in the main program for this use the N END statement).
