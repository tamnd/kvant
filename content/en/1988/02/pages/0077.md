10. The sum $\frac{a}{c} + \frac{b}{d}$ is maximum when one of the terms is equal to 999. Solution. Let $\frac{a}{c} \geq \frac{b}{d}$. Then $\frac{b}{d} \leq \frac{a+b}{c+d} \leq \frac{a}{c}$, i.e. $\frac{b}{d} \leq 1$. Let $a \leq 998$, then $\frac{a}{c} \leq 998$, so $\frac{a}{c} + \frac{b}{d} \leq 999$. But if $\frac{a}{c} = 999$ (at $a = 999$, $c = 1$), then $\frac{a}{c} + \frac{b}{d} > 999$.

11. $0,9 < x_1 < 1; -1,1 < x_2 < -1; -1000 < x_3 < -999,9$. Solution. $f(x) = 0,001x^3 + x^2 - 1 = f_1(x) + f_2(x)$, where $f_1(x) = 0,001x^3, f_2(x) = x^2 - 1$. The roots of $f_2(x) = 0$ are $(+1)$ and $(-1)$, and for $|x| < 2, |f_1(x)| < 0,01$. Therefore two roots $f(x)$ are equal to $x_1 \approx +1, x_2 \approx -1: f(+1) = 0,001 > 0, f(0,9) < 0 \Rightarrow 0,9 < x_1 < 1$, and similarly, $-1,1 < x_2 < -1$. Let us now note that the equation $0,001x^3 + x^2 = 0$ has a root $(-1000)$, and $f(-1000) = -1 < 0$, and $f(-999,9) > 0$, therefore, $-1000 < x_3 < -999,9$.

15. Let us denote $k = tg \alpha$, where $\alpha$ is the angle of inclination of the tangents. Then

$$f'(0) = g'(0) = \frac{f'(0)g(0) - f(0)g'(0)}{g^2(0)} = k,$$

whence $\frac{k \cdot g(0) - k \cdot f(0)}{g^2(0)} = k$ and $g(0) - f(0) = g^2(0)$. We denote $g(0) = t$, then the last equality is rewritten as $t^2 - t + f(0) = 0$. This equation has a solution $t = g(0)$. So its discriminant is $D = 1 - 4f(0) \geq 0$. Hence $f(0) \leq 1/4$; max $f(0) = 1/4$.
