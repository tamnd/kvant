⟦folio 33⟧

We have been running this section from issue to issue since the founding of the magazine. The problems published in it are non-standard, but their solution does not require knowledge beyond the scope of the school curriculum. The most difficult tasks are marked with an asterisk. After creating the task, we promise to indicate who suggested it to us. Of course, not all of these problems are published for the first time.

Solutions to the problem from this issue should be sent no later than February 1, 1989 to the address: 103006 Moscow K-6, st. Gorky, 32/1, «Kvant». Solutions to problems from different numbers or in different subjects (mathematics and physics) are assigned in different envelopes. On the envelope, in the “To” column, write: “Problem «Kvant» No. 11-12-88” and the numbers of the problems whose solutions you are sending, for example “M1131” or “F1143”. In the column “... sender’s address”, please write your first and last name separately. Include an envelope with your address written on it (you will receive the results of the decision verification in this envelope).

The condition of each original problem proposed for publication is assigned in a separate envelope in duplicate along with your solution to this problem (on the envelope place: “Problem «Kvant», a new problem in physics” or “... a new problem in mathematics”).

At the beginning of each letter, please indicate the school number and the class in which you will study.

Tasks M1131 - M1135 are intended.

Tasks
M1131—M1140, F1143—F1147

M1131. Let $n$ be a natural number and $A_1, A_2, ..., A_{2n+1}$ be a subset of some set $B$. Let's assume that
a) each set $A_i$ ($i=1, 2, ..., 2n+1$) contains exactly $2n$ elements;
b) each set $A_i \cap A_j$ ($1 \leq i < j \leq 2n+1$) contains exactly one element;
b) any element of the set $B$ belongs to at least two of the set $A_i$ ($i=1, 2, ..., 2n+1$).
For what values ​​of $n$ can each element of the set $B$ be assigned one of the numbers - 0 or 1 - so that each of the set $A_1, A_2, ..., A_{2n+1}$ contains exactly $n$ elements corresponding to the number 0?

M1132. The function $f$ is defined on the set of positive integers and satisfies the following conditions:
$$f(1) = 1, f(3) = 3, f(2n) = f(n),$$
$$f(4n+1) = 2f(2n+1) - f(n),$$
$$f(4n+3) = 3f(2n+1) - 2f(n).$$
Find the number of all values ​​of $n$ for which $f(n) = n$ and $1 \leq n \leq 1988$.

M1133. Prove that the set of solutions to the inequality
$$\sum_{k=1}^{70} \frac{k}{x-k} \geq \frac{5}{4}$$

is the union of disjoint intervals whose sum of lengths is 1988.

M1134. Let $AD$ be the height in the right triangle $ABC$, $\angle A = 90^\circ$. A line passing through the centers of the circles inscribed in triangles $ABD$ and $ACD$ intersects sides $AB$ and $AC$, respectively, at points $K$ and $L$. Prove inequality $S_{ABC} \geq 2S_{AKL}$.

M1135. Let $a$ and $b$ be positive integers such that $a^2 + b^2$ is divisible by $ab + 1$ without remainder. Prove that $\frac{a^2 + b^2}{ab + 1}$ is the square of an integer.

M1136*. Prove the inequality for non-negative numbers $A, M, S$
$$3 + (A + M + S) + \left(\frac{1}{A} + \frac{1}{M} + \frac{1}{S}\right) + \left(\frac{A}{M} + \frac{M}{S} + \frac{S}{A}\right) \geq \frac{3(A + 1)(M + 1)(S + 1)}{AMS + 1}.$$

D. P. Mavlo

The author dedicated this problem to the 100th anniversary of the American Mathematical Society (AMS), which is celebrated this year.

M1137. In a convex $n$-gon, all angles are equal and from a certain point located inside the $n$-gon, all its sides are visible at equal angles. Prove that this $n$-gon is regular.

K. P. Kohas

6) Is it always possible to make rearrangements so that the result is one curve?
c) Let’s choose the direction of traversal on each curve and make adjustments in accordance with this direction so that the arrows “repel” each other (Fig. 4). Could the result be a single curve?

F1143. There are a very large number of cylindrical vessels with water, immersed one in the other so that each next one floats in the limit. The area of ​​the bottom of the smallest vessel is $s_0$ and much less than the area of ​​the bottom of the largest. The smallest vessel should have a volume of water $v_0$. How far will this vessel descend relative to the ground? (After adding water, all the vessels continue to float.)
G. V. Grigoriev

F1144. There are $N$ identical billiard balls on the plane. One ball was pushed, and after experiencing several impacts, it stopped at the same point from which it began to move. At what minimum $N$ is this possible? The collisions are considered to be absolutely elastic.

A. A. Belopolsky
