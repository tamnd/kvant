⟦folio 64⟧

To participate in the competition, you must send an application and a detailed program script before February 1, 1989. The script should contain the main ideas and a descriptive description of the program. The application is written in the following format:

Bid
Full name
Home address
School number and address (SPTU)
Class
Machine type
Programming language
Name of the program (to whom and what is it intended for)
Scope of the program
Average program running time

The authors of the screenplays shown will be invited to Krasnoyarsk at the end of March 1989 to participate in the final type of competition.

Send materials for the competition to the address: 660051 Krasnoyarsk, PO Box No. 11533, organizing committee of the “Young Programmer” competition.
