12. $x \geq -\frac{1}{4}$. Proof. For $f_{n+1}(x)$ to be defined, $f_n(x)$ must be defined and for $x+f_n(x) \geq 0$ to be defined. Let us first assume that $x \geq -\frac{1}{4}$. If $f_n(x) > \frac{1}{2}$, then $f_{n+1}(x) = \sqrt{x+f_n(x)} > \sqrt{-\frac{1}{4}+\frac{1}{2}} = \sqrt{\frac{1}{4}} = \frac{1}{2}$, i.e. also $f_{n+1}(x) > \frac{1}{2}$. Since $f_0(x)=1 > \frac{1}{2}$, then by virtue of what was proved, $f_1(x) > \frac{1}{2}, f_2(x) > \frac{1}{2}, f_3(x) > \frac{1}{2}, \dots$, i.e. $f_n(x) > \frac{1}{2}$ and $x+f_n(x) > -\frac{1}{4} + \frac{1}{2} > 0$ for any $n$; thus, for $x \geq -\frac{1}{4}$ all $f_n(x)$ are defined. Let now $x < -\frac{1}{4}$. Therefore $x + \frac{1}{4} = -a$; then $a > 0$. Obviously, for any $y \geq 0$ the inequality $\sqrt{y} \leq y + \frac{1}{4}$ is valid (indeed, $y - \sqrt{y} + \frac{1}{4} = \left(\sqrt{y} - \frac{1}{2}\right)^2 \geq 0$). This means that if $f_{n+1}(x)$ is defined, then $f_{n+1}(x) = \sqrt{x+f_n(x)} \leq x+f_n(x) + \frac{1}{4} = f_n(x) - a$, and therefore $f_{n+1}(x) \leq f_0(x) - (n+1)a = 1 - (n+1)a$, from which it is clear that for a sufficiently large $n$ the number $f_{n+1}(x)$, if it is defined, must be negative, which is impossible.

15. $a = \frac{1}{5}, b = \frac{49}{40}$; the formula $\sqrt{x} \approx \frac{1}{5} x + \frac{49}{40}$ with $4 \leq x \leq 9$ allows an error of no more than $\frac{1}{40}$. Solution. Let's draw the graphs of the functions $y = \sqrt{x}, y = ax + b$ and $y = \sqrt{x} - ax - b$ (Fig. 7). The generated function $y = \sqrt{x} - ax - b$ is equal to $\frac{1}{2\sqrt{x}} - a$ and vanishes at the single point $x = \frac{1}{4a^2}$. The function can reach an extremum at the point $\frac{1}{4a^2}$ and at the ends of the segment. The values ​​at these points are $4a - b + 2, \frac{1}{4a} - b, -9a - b + 3$. The largest error is equal to the maximum absolute value of the three numbers. This error will be minimal if all three absolute values ​​are the same (proof!); in this case, the middle number will be positive, and the extreme numbers will be negative (see Fig. 7). So,

$$4a + b - 2 = \frac{1}{4a} - b = 9a + b - 3,$$

whence $a = \frac{1}{5}, b = \frac{49}{40}$; in this case, the maximum error is $4a + b - 2 = \frac{4}{5} + \frac{49}{40} - 2 = \frac{1}{40}$. Example: $\sqrt{5} \approx \frac{1}{5} \cdot 5 + \frac{49}{40} = 2,225$; actually $\sqrt{5} = 2,236$...
