However, Ramsay games and puzzles with smaller full graphs and with only two colors of pencils can be quite entertaining.

Nibaulier's famous game of Ramsey is called Sim*). It is played on a complete graph of six vertices ($K_6$), which models the problem of a group of six people. It is not difficult to prove that 6 is the Ramsey number for the following two subgraphs:

1. red: triangle ($K_3$),
2. blue: triangle ($K_3$).

In classical Ramsey theory, complete graphs are usually denoted simply by numbers. So we can express the above result in a compact formula: $R(3, 3)=6$. This means that the number of vertices of the smallest complete graph, which for any 2-coloring necessarily contains a single-valued (red or blue) triangle, is 6.

Thus, if two players alternately color the graph $K_6$ red or blue, then one of them will inevitably lose, having completed the construction of a single-valued triangle. The corresponding puzzle is quite simple; it consists of 2-coloring the critical graph $K_5$ so that there are no single-valued triangles.

It turns out that if the graph $K_6$ is 2-colored, then it is obligatory to find at least two single-valued triangles. (If there are exactly two of them and they are different colors, they form bow ties.) This raises an interesting question. What is the smallest number of single-valued triangles that can be obtained by 2-coloring a complete graph with $n$ vertices? A.V. Goodman was the first to answer this question.

*) M. Gardner. Mathematical novels. - M.: Mir, 1974, ch. 33. Hereinafter notes by S. V. Bely.

Goodman's formula is conveniently broken down into three parts:

if $n=2k$, then the smallest number of single-valued triangles is $1/3 \cdot k(k-1)(k-2)$;

if $n=4k+1$, then the smallest number of single-valued triangles is $1/3 \cdot 2k(k-1)(k+1)$;

if $n=4k+3$, then the smallest number of single-valued triangles is $1/3 \cdot 2k(k+1)(4k-1)$.

Thus, for complete graphs with 6 to 12 vertices, the smallest number of single-valued triangles is correspondingly 2, 4, 8, 12, 20, 28, and 40.

The following 2-coloring will, as a rule, produce large single-valued triangles. If a coloring of a Ramsey graph contains exactly the smallest number of single-valued triangles, then it is called extremal. Is there always an extremal coloring in which all single-valued triangles have the same color? In 1961, Leopold Sauvé showed that the answer to this question was established.*) This gives rise to a new class of puzzles. For example, on figure there is a complete graph with 7 vertices. Can you 2-color this graph so that you get no blue triangles and get no more than four red triangles? (For the answer, see page 73.)

Very little is known about the "classical" Ramsey numbers. The classical Ramsey number is the Ramsey number corresponding to the situation when all graphs from a given set are complete.
