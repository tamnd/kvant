1. $x_1 = x_2 = \dots = x_{100} = \frac{-1 \pm \sqrt{5}}{2}$. Solution e.
If $x_1 = \dots = x_{100}$, then all equations of the system turn into the same equation $x_1^2 + x_1 - 1 = 0$, solving which we obtain $x_1 = \frac{-1 \pm \sqrt{5}}{2}$. Let us show that there are no other solutions. Let's transform the equation to the form $x_1 = \frac{1}{1+x_2}$, $x_2 = \frac{1}{1+x_3}, \dots, x_{99} = \frac{1}{1+x_{100}}, x_{100} = \frac{1}{1+x_1}$. Let's substitute the expression for $x_{100}$ into the expression for $x_{99}$, the expression for $x_{99}$ into the expression for $x_{98}$, etc. We get

$$x_1 = \frac{1}{1 + \frac{1}{1 + \dots + \frac{1}{1+x_1}}}.$$

Transforming the multi-level fraction on the right side of the equality *) to the general form, we reduce the equality to the form

$$x_1 = \frac{ax_1 + b}{cx_1 + d},$$

which is equivalent to a quadratic equation. This means that $x_1$ has no more than 2 possible values, but we already know 2 values: $\frac{-1 \pm \sqrt{5}}{2}$. 3. $\{1, 1, 1\}, \{1, 1, 2\}, \{1, 2, 3\}$ (up to order). Solution e. Let $x_1, x_2, x_3$ be the given numbers, and let $x_1 \leq x_2 \leq x_3$. Then $x_1 + x_2 \leq 2x_3$, whence either $x_1 + x_2 = x_3$ or $x_1 + x_2 = 2x_3$. The latter is possible only for $x_1 = x_2 = x_3$, and then (due to the condition of mutual simplicity) $x_1 = x_2 = x_3 = 1$. Let $x_1 + x_2 = x_3$. Then $x_1 + x_3 = 2x_1 + x_2$ is divisible by $x_2$; that means $2x_1$ is divisible by $x_2$. But $2x_1 \leq 2x_2$, so it's either $x_1 = x_2$ or $2x_1 = x_2$. In the first case, $x_3 = 2x_1$ and (due to the simplicity condition) $\{x_1, x_2, x_3\} = \{1, 1, 2\}$; in the second case $x_3 = 3x_1$ and $\{x_1, x_2, x_3\} = \{1, 2, 3\}$.
