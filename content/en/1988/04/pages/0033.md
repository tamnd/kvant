Note. A permutation of a finite set $S$ is a one-to-one mapping $f$ of the set $S$ onto itself; the number of all permutations of a set of $n$ elements is $n! = 1 \cdot 2 \cdot \dots \cdot n$. The element $a$ of the set $S$ is called a fixed point of the permutation $f$ if $f(a) = a$.

$$\sum_{k=0}^{n} kp_n(k) = n \sum_{k=1}^{n} p_{n-1}(k-1) = n \cdot (n-1)! = n!.$$

6) Let us immediately prove a more general point

$$s(n, m) = \sum_{k=m}^{n} \frac{k!}{(k-m)!} p_n(k) = n!$$

for all $n \geq m$, $m=0, 1, 2, \dots$ (by definition, $0!=1$). For $m=0$ it coincides with (1), for $m=1$ it coincides with statement a), and for $m=2$ it is equivalent to 6), since

$$\sum_{k=0}^{n} (k-1)^2 p_n(k) = \sum_{k=0}^{n} k(k-1)p_n(k) - \sum_{k=0}^{n} kp_n(k) + \sum_{k=0}^{n} p_n(k) = s(n, 2) - s(n, 1) + s(n, 0).$$

From point (2) it follows that for $1 \leq m \leq k \leq n$

$$\frac{k!}{(k-m)!} p_n(k) = k(k-1) \dots (k-m+1)p_n(k) = n(k-1) \dots (k-m+1)p_{n-1}(k-1) = n(n-1)(k-2) \dots (k-m+1)p_{n-2}(k-2) = \dots = n(n-1) \dots (n-m+1)p_{n-m}(k-m) = \frac{n!}{(n-m)!} p_{n-m}(k-m).$$

We sum these equalities over $k=1, 2, \dots n$:

$$s(n, m) = \frac{n!}{(n-m)!} s(n-m, 0) = n!.$$

Another proof of (3) can be obtained from the apparent correspondence post $p_n(k) = C_n^k p_{n-k}(0)$, where $C_n^k = n!/(k!(n-k)!)$ is the number of $k$-elements of a subset of the set of $n$ elements (the number of combinations).

Our reader L.M. Koganov (Moscow) reported another generalization of this problem, due to the American mathematician J. Goldman: if $S(q, i)$ is the number of partitions of the set $\{1, 2, \dots, q\}$ into $i$ non-empty disjoint sets, then

$$\sum_{k=0}^{n} k^q p_n(k) = n! \sum_{i=1}^{m} S(q, i),$$

where $m=\min(n, q)$. The proof of this correspondence, proposed by L. M. Koganov, is written by the derivation of formula (2) and coincides with counting in two ways the number of pairs $(f, \varphi)$, where $f$ is an arbitrary permutation of the set of $n$ elements, and $\varphi$ is an arbitrary mapping of the set $\{1, 2, \dots, q\}$ in the set of fixed points of the permutation $f$.
