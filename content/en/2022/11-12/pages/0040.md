Comment

Let's consider some set, for example, a set of goods displayed on the sales floor of a store. The goods are laid out on the shelves. The buyer walks around the shelves one by one and puts the goods he needs into the basket. For definiteness, we will assume that only one product is taken from each shelf. This is how a purchase is formed - a set consisting of selected goods. This process is familiar, visual, and allows for the following mathematical formulation. Let set A be represented as a union of disjoint sets:

A

B  C  D ...

Then we can construct a set X containing one element from each set B, C, D,... In our example, A is the set of goods in the store, B, C, D,... are the sets of goods lying on the shelves, X is the purchase. And in fact, in this formulation there is invisibly present one more set, disguised in the formula with an ellipsis symbol - the set by which the union is taken (the set of shelves in a store). Of course, instead of A, you can take an arbitrary set and split it into arbitrary parts. So, in a fairy tale, set A is a set of all possible sequences of real numbers, divided into parts, each of which contains some “main” sequence (in fact, this is absolutely any sequence chosen at this time).

How to construct such a partition of a set of sequences into lists? In the fairy tale, the woodpecker explains how. To build the first list, let's call it B, take any sequence, for example (0, 0, 0, 0,...), call it the main one and, in addition to it, place in the list B all sequences that differ from the main one in a finite number of places. List B is built. By the way, if we were talking only about sequences of integers, we could consider that B is really an infinite list: the sequences are written out in an imaginary table, one sequence is written in each line, and the lines themselves are numbered with natural numbers. But for sequences of real numbers, the set B will turn out to be uncountable - its elements cannot be numbered by natural numbers, it is an infinite set, “larger” than the set of natural numbers. Calling it a list can only be done in an artistic sense. Now we build a second list, let's call it C. Take any sequence that is not included in B, for example (0, 1, 0, 1, 0, 1,...), now we call this sequence the main one and write down in the list C all sequences that differ from the main one in a finite number of places. List C is also built. Now take the next sequence, which is not contained in either B or C, etc. Note, however, that this last “etc.” despite its apparent clarity and persuasiveness, it is not at all obvious. What does “and so on” mean? This means that we will similarly construct the third list, the fourth, the hundredth, the millionth... But even if we imagine that the infinite process has ended and for each natural number n we have built the nth list, the contents of these lists do not exhaust the entire set of sequences for the same reason as above: the set of sequences consisting of integers is uncountable, and each list contains only a countable set of such sequences.
