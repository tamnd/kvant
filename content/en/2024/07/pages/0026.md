M2791. In each cell of the table $N \times N$
number is written down. Let's call cell C good
necks, if in each of the cells adjacent
with C on the side, look at the number 1 more,
than in C, and in each of the other cells,
middle ones with C on the side, look at the number on
3 is more than in C. What is the most
possible number of good cells?

Answer: $N^2 - N$.
An example arrangement is shown at figure
for $N = 8$: in the green part of the number table
the lines are in ascending order
from left to right, and in columns increasing by 3 bluish upwards. The desired part of the table is filled in so that the table is symmetrical relative to the main diagonal coming from the upper left corner. We see that in this example all cells, with the exception of the cells of this main diagonal, are good. An example is constructed similarly for any $N$.

Grade. Let us prove that $X \leq N^2 - N$, where $X$ is the number of good cells. Let's draw two arrows from each good cell: a blue arrow - to the adjacent cell, in which the number is 1 more, and a red arrow - to the adjacent cell, in which the number is 3 more. In total, 2X shooters were carried out. On the other hand, there are no more arrows than there are pairs of adjacent cells in the table, since at most one arrow can be drawn between cells in one pair. But the number of pairs of neighboring cells is $2N(N - 1)$. Hence $2X \leq 2N(N - 1)$ and $X \leq N^2 - N$, which is what was required.
