$$Ae^{x+y} + B - \left(Ae^x + B\right)^2 = e^x \left(Ae^x + B + Ae^y + B\right).$$

Let us rewrite the last equality in the form of a polynomial in $e^x$:

$$A(A + 1)e^{2x} + 2B(A + 1)e^x + B(B - 1) = 0.$$

The equality must hold for all $x$. This will happen if and only if the coefficients of $e^{2x}, e^x$ and the free term are equal to zero. The last property can be achieved in three ways:

1) $A = 0, B = 0$; 2) $A = -1, B = 0$; 3) $A = -1, B = 1$.

Correspondingly, we obtain three solutions to the problem: $f(x) = 0, f(x) = -e^x, f(x) = -e^x + 1$.

10. $(-\infty; 0) \cup \left\{\frac{1}{4}\right\}$.

Let's square the equation:

$$\begin{cases} y^2 = x - a, \\ x^2 = y - a. \end{cases}$$

Let us now subtract one equation from the other:

$$y^2 - x^2 = x - y,$$ from where $(y - x)(x + y + 1) = 0$.

Since it immediately follows from the equation of the original system that $x \ge 0, y \ge 0$, then the second set is non-zero, it turns out that $x = y$ and the system is freed to one equation

$$x^2 = x - a, x^2 - x + a = 0.$$

We need to find the values ​​of $a$ at which this equation has a unique non-negative solution. The discriminant of the quadratic equation $x^2 - x + a = 0$ is $D = 1 - 4a$. If $D = 0$, then $a = \frac{1}{4}$, and $x = \frac{1}{2}$ is the only solution to the equation and this solution is non-negative. If $a > \frac{1}{4}$, then $D < 0$ and there are no solutions. If $0 \leq a < \frac{1}{4}$, the equation has two non-negative solutions. If $a < 0$, the equation has two roots of different signs. It is assumed that the equation has one non-negative root if $a \in (-\infty; 0) \cup \left\{\frac{1}{4}\right\}$.
