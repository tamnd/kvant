Henri Poincaré

The integral on the right-hand side is taken by replacing $u^2 = \frac{R}{cR + c_1}$. Let's express the old variable $R$ through the new one $u$:

$$R = \frac{c_1 u^2}{1 - cu^2},$$

let's find $dR$:

$$dR = \frac{c_1}{c} d \frac{1}{1 - cu^2}$$

and from the equation connecting $dt$ with $dR$ we get

$$t = \frac{c_1}{c} \int u d\left(\frac{1}{1 - cu^2}\right),$$

or, integrate by parts,

$$t = \frac{c_1}{c} \left(\frac{u}{1 - cu^2} - \int \frac{du}{1 - cu^2}\right).$$

The last integral is tabular and depends on the sign of $c$:

$$t = \begin{cases} \frac{c_1}{c} \left(\frac{u}{1 - cu^2} - \frac{1}{2\sqrt{c}} \ln \left| \frac{1 + \sqrt{cu}}{1 - \sqrt{cu}} \right|\right), & \text{ если } c > 0, \\ \frac{2}{3} \frac{1}{\sqrt{c_1}} \left(R^{3/2}\right), & \text{ если } c = 0, \\ \frac{c_1}{c} \left(\frac{u}{1 - cu^2} - \frac{1}{\sqrt{|c|}} \mathrm{arctg}\left(\sqrt{|c|} u\right)\right), & \text{ если } c < 0. \end{cases}$$

Remembering the replacement $u = \sqrt{\frac{R}{cR + c_1}}$, we get

$$\begin{cases} \frac{c_1}{c} \left(\frac{\sqrt{R(cR + c_1)}}{c_1} - \frac{1}{2\sqrt{c}} \ln \left| \frac{\sqrt{cR + c_1} + \sqrt{cR}}{\sqrt{cR + c_1} - \sqrt{cR}} \right|\right), \\ \text{ если } c > 0, \\ \frac{2}{3} \frac{1}{\sqrt{c_1}} \left(R^{3/2}\right), \text{ если } c = 0, \\ \frac{c_1}{c} \left(\frac{\sqrt{R(cR + c_1)}}{c_1} - \frac{1}{2\sqrt{c}} \ln \left| \frac{\sqrt{cR + c_1} + \sqrt{cR}}{\sqrt{cR + c_1} - \sqrt{cR}} \right|\right), \\ \text{ если } c < 0. \end{cases}$$

Of course, Newton could easily handle all the calculations.

Now we have two tasks:

1) show that we have obtained exactly Friedman's solutions;
2) show that our decisions are consistent.

Part 2

• The simplest case is when $c = 0$. We get

$$t = \frac{2}{3} \frac{1}{\sqrt{c_1}} \left(R^{3/2}\right),$$

$$R = \left(\frac{3}{2} \sqrt{c_1}\right)^{2/3} t^{2/3},$$

$$R' = \left(\frac{3}{2} \sqrt{c_1}\right)^{2/3} \cdot \frac{2}{3} t^{-1/3},$$

$$H = \frac{2}{3} t^{-1}.$$

As can be seen from the last equality, $H$ does not depend on any constants, but depends only on time. This means that it is the same for all points in space. In this case, the dependence of the average density on time is easily calculated:

$$\rho = \frac{1}{6\pi G} t^{-2}.$$

Task 3. Derive this dependence.

This model is called the flat model.

• Case $c > 0$. We get

$$t = \frac{c_1}{c} \left(\frac{\sqrt{R(cR + c_1)}}{c_1} - \frac{1}{2\sqrt{c}} \ln \left| \frac{\sqrt{cR + c_1} + \sqrt{cR}}{\sqrt{cR + c_1} - \sqrt{cR}} \right|\right).$$
