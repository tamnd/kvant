Let's color the cells of the table in a checkerboard pattern so that the bottom left cell is black. Then the sum of the coordinates of each cell is odd, and the sum of the coordinates of each black cell is black. From the above it follows that the white cells contain the number of exact squares. In this case, numbers of the same parity are written in cells of the same color. If $n$ is odd, then there are one more black cells than white cells, so black cells are filled with odd numbers, and white cells are filled with black ones. And if $n$ is even, then numbering can start from a cell of any color. But if it starts with a white cell, then we can consider a symmetrical arrangement of numbers in which the numbering begins with a black one. Thus, in any case, the number of perfect squares among the numbers from 1 to $n^2$ is even. This is only true for $n$, multiples of 4, and remainder 1 when divided by 4.

Now we will prove that for all the indicated values ​​of $n$ the required arrangement exists, and such that the number $n^2$ is in the corner cell. For $n = 1$ this is obvious, for $n = 4$ an example is given at figure 5. At figure 6 a diagram is shown of how to obtain an arrangement for table $(n + 4) \times (n + 4)$ from the completed table $n \times n$. It is easy to check that the first transition between displaced cells has length $2n + 1$, the second $2n + 3$, the third $2n + 5$, and the fourth $2n + 7$. Therefore, after the number $n^2$, they contain $(n + 1)^2$, $(n + 2)^2$, $(n + 3)^2$ and $(n + 4)^2$, all of which are in different rows and in different columns, and the last number is again in the corner cell.
