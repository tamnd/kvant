In the factorization method, we generalize Fermat's method, a number $x$ is selected such that $x^2 (\bmod r)$ is a square. However, such a number is difficult to come by. The key to moving forward is the observation that if we take several values ​​of $x^2 (\bmod r)$ for different $x$, none of which are squares, then their product may already be a square.

For example, let's expand the number 1411. Consider squares modulo 1411:

$$38^2 (\bmod 1411) = 33,$$
$$39^2 (\bmod 1411) = 110,$$
$$40^2 (\bmod 1411) = 189,$$
$$41^2 (\bmod 1411) = 270,$$
$$44^2 (\bmod 1411) = 525,$$
$$49^2 (\bmod 1411) = 990.$$

None of the results obtained is a square, but the result of the product $33 \times 189 \times 270$ is $980110 = 990^2$. So, $(33 \times 189 \times 270)^2 = 990^2$, it follows that

$$(33 \times 189 \times 270 - 990) (33 \times 189 \times 270 + 990)$$

- factorization of a certain multiple of 1411. Then

$$1411 = \text{НОД}(1411, 33 \times 189 \times 270 - 990) \times \text{НОД}(1411, 33 \times 189 \times 270 + 990).$$

Exercise. Prove that if $r$ divides $x^2 - y^2 = (x - y)(x + y)$, then

$$r = \text{НОД}(r, x - y) \cdot \text{НОД}(r, x + y).$$

How to check if among the given numbers there are several whose product gives a square? Going through all kinds of works, even in our example, is too laborious. We use a method based on factorization into factors:

$$33 = 3^1 \cdot 11^1,$$
$$110 = 2^1 \cdot 5^1 \cdot 11^1,$$
$$189 = 3^3 \cdot 7^1,$$

$$270 = 2^1 \cdot 3^3 \cdot 5^1,$$
$$525 = 3^1 \cdot 5^2 \cdot 7^1,$$
$$990 = 2^1 \cdot 3^2 \cdot 5^1 \cdot 11^1.$$

Note that when multiplying numbers, the exponents of the prime numbers included in their expansion are added. Therefore, it is convenient to consider a vector of exponents - this is a vector whose coordinates are the powers of the input prime numbers. Multiplying numbers corresponds to adding vectors of indicators. In our case, the vectors have the form

$$\vec{a}_1 = \{0, 1, 0, 0, 1\};$$
$$\vec{a}_2 = \{1, 0, 1, 0, 1\};$$
$$\vec{a}_3 = \{0, 3, 0, 1, 0\};$$
$$\vec{a}_4 = \{1, 3, 1, 0, 0\};$$
$$\vec{a}_5 = \{0, 1, 2, 1, 0\};$$
$$\vec{a}_6 = \{1, 2, 1, 0, 1\}.$$

The product of numbers will be a square if and only if all powers are even. Since we are only interested in parity, we will consider coordinates modulo 2:

$$\vec{a}_1 = \{0, 1, 0, 0, 1\};$$
$$\vec{a}_2 = \{1, 0, 1, 0, 1\};$$
$$\vec{a}_3 = \{0, 1, 0, 1, 0\};$$
$$\vec{a}_4 = \{1, 1, 1, 0, 0\};$$
$$\vec{a}_5 = \{0, 1, 0, 1, 0\};$$
$$\vec{a}_6 = \{1, 0, 1, 0, 1\}.$$

Our task is to find a linear combination of these vectors, giving the vector $\{0, 0, 0, 0, 0\}$, i.e. such non-zero $\alpha_1$, ..., $\alpha_6$ that

$$\alpha_1 \vec{a}_1 + \dots + \alpha_6 \vec{a}_6 = \{0, 0, 0, 0, 0\}.$$
