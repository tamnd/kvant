On the other hand, the lemma we will prove below turns out to be false if we allow sequences of different lengths to be compared.

**Lemma 1.** For lexicographic order on a sequence of length n, there are no infinitely killing chains, m.e. there are no sequences for which this is done

$$\left(a_1^1, \ldots, a_n^1\right) > \left(a_1^2, \ldots, a_n^2\right) > \ldots > \left(a_1^m, \ldots, a_n^m\right) > \ldots$$

**Proof.** Let's assume that such an infinitely killing chain exists. Let's look at the first terms of these sequences $a_1^1, a_2^1, \ldots$. These numbers do not increase, therefore, starting from a certain moment, this sequence will stabilize (there will be no strict killing). Let's consider this moment and reverse the finite number of terms of the sequence that precede it, redesignating the indices if necessary. Thus, now in all sequences the first term is the same. Let us consider the second terms of these sequences $a_1^2, a_2^2, \ldots$. For the same reasons, starting from a certain point, they stabilize. Let's consider this point. Having repeated the same reasoning n times, we come to the conclusion that all n terms stabilize at some point, which contradicts the strict killing in lexicographical order. The lemma is proven.

Using this lemma, we prove that if we start with some initial arrangement of coins in the boxes, then the number of coins we will add up is bounded from above. We will not give any (further rough) estimates for this upper bound. The proof will be based solely on general messages related to finite and infinite.

We will imagine the possibility of arranging coins in boxes in the form of tree tops. The root of this tree is the original arrangement of the coins. An arrow leads from an ancestor to a child if the sequence of coins stored in the child can be obtained from the sequence of coins recorded in the ancestor using one of two permitted operations.

Let's make two important remarks about obtaining a tree.

• Lemma 1 means that there are no infinite paths in this tree.

• In this tree, from each vertex there is a finite (further limited from above by a single number) number of arrows leading to descendants. This quantity is trivially estimated from above by the number $2n - 3$ (no operations can be performed on the last box, only the first operation can be performed on the penultimate box, and no more than 2 different operations can be performed on all the others). Thus, we are dealing with a finite time tree.

To complete the proof, it remains to apply Köngig's lemma. This statement, which is not difficult to prove, plays an important role in mathematical logic.

**Lemma 2 (Köngig).** In an infinite tree with finite time, there is an infinite path.

From Köngig's lemma it follows that our tree must be finite: if it were infinite, then, since it has finite branching, it would have an infinite path. Thus, since our tree with possible arrangements of coins is finite, then the number of coins in the boxes (both overall and in each specific box) will necessarily be limited from above.
