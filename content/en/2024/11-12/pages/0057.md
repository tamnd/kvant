6. $(26;34;35), (26;34;25), (-27;-19;-18), (-27;-19;-28)$.

Since $(a-c)(b-c) = p^2$, where $p - \text{простое}, a - c < b - c$ (due to the fact that $a < b$), the following two options are possible:

$$\begin{cases} a - c = 1, \\ b - c = p^2 \end{cases}$$ or $$\begin{cases} a - c = -p^2, \\ b - c = -1. \end{cases}$$ (*)

Subtracting the first from the second equality, in general cases we obtain $b - a = p^2 - 1$. Consider the possibility of separating $p$ by 3:

- $p = 3k + 1$ - then $p^2 - 1 = 9k^2 + 6k = 3(3k^2 - 2k)$ is divisible by 3;
- $p = 3k + 2$ - then $p^2 - 1 = 9k^2 + 12k + 3 = 3(3k^2 + 4k + 1)$ is also divisible by 3;
- $p = 3k$ - then $p^2 - 1 = 9k^2 - 1$ and there is no divisibility by 3.

Since the number $b - a$ is not a multiple of 3, only the third case is possible. But since $p$ is prime, $p = 3$. So, $b - a = 8$. Adding here the equation $a^2 + b = 710$ given in the condition, we obtain a system with two unknowns $a$ and $b$. Solving it, we find $a = 26$, $b = 34$ or $a = -27$, $b = -19$. Based on system (*), for each pair $(a;b)$ there are two suitable values ​​$c$. This is $c = a + p^2 = a + 9$ or $c = a - 1$.
