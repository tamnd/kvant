Grade. We will match people to the vertices of the graph, the number of the vertex will indicate the answer of the corresponding person, and if a pair of people are friends, then we will draw an edge between the corresponding vertices.

Let $A$ be the set of all people who named the numbers from 0 to $n - 1$, and $B$ be the set of all people who named the numbers from $n$ to $2n - 1$. Let $d_i$ be the degree of vertex $i$ (i.e. the number of edges leaving vertex $i$). Then by condition $d_i = i$ if $i$ is a knight, and $|d_i - i| = 1$ otherwise. Let the set $A$ contain exactly $x$ liars, and the set $B$ have exactly $y$.
Let us estimate the number of $E$ edges between people from different sets $A$ and $B$.
On the one hand, $E$ is not greater than the sum of the degrees of the vertices of the set $A$, revealing

$$E \leq d_0 + d_1 + \dots + d_{n-1} \leq$$
$$\leq 0 + 1 + 2 + \dots + (n - 1) + x = \frac{(n - 1)n}{2} + x.$$

On the other hand, from each vertex $i$ the set $B$ of no more than $n - 1$ edges goes to the vertices of the set $B$, and therefore at least $d_i - (n - 1)$ edges go to the vertices of the set $A$. From here

$$E \geq d_n + d_{n+1} + \dots + d_{2n-1} - n(n - 1) \geq$$
$$\geq n + (n + 1) + \dots + (2n - 1) - y - n(n - 1) = \frac{n(n + 1)}{2} - y.$$

We get inequality

$$\frac{(n - 1)n}{2} + x \geq \frac{n(n + 1)}{2} - y,$$

whence $x + y \geq n$. This means that all liars are at least $n$.
