12) Let us denote by $\alpha, \beta, \gamma, \delta$, respectively, the number of characters $b$ in the sequence
$$\left(d_{-q_1}, \dots, d_{-2}, d_{-1}\right),$$

Note that
$$h(r_2) + h(-r_2) = \left(h\left(\frac{q_2}{s}\right) - h(0)\right) - \left(h(0) - h\left(\frac{-q_2}{s}\right)\right) = \left(d_0 + d_1 + \dots + d_{q_2-1}\right) - \left(d_{-q_2} + \dots + d_{-2} + d_{-1}\right) = (\delta - \gamma)(b - m).$$

This expression is not equal to 0, but in addition, as we know from 11), $|\delta - \gamma| \leq 1$. Likewise,
$$h(r_1) + h(-r_1) = (\beta - \alpha)(b - m),$$

where $0 < |\beta - \alpha| \leq 1$. Since $h(r_2) + h(-r_2) \neq h(r_1) + h(-r_1)$, exactly one of the expressions $\delta - \gamma$, $\beta - \alpha$ is equal to 1 and the other is equal to -1; for definition, let $\delta - \gamma = 1$, $\beta - \alpha = -1$.

The number of characters $b$ in the sequence (of length $q_1 + q_2$) ($d_{-q_1}, \dots, d_{-1}, d_0, \dots, d_{q_2-1}$) is equal to the corresponding $\alpha + \delta$ and $\beta + \gamma$. But the difference between these quantities is $(\alpha + \delta) - (\beta + \gamma) = (\delta - \gamma) - (\beta - \alpha) = 2$, which contradicts point 11) for $t = q_1 + q_2$.

14) It remains to give an example of a function satisfying the conditions for which $c = 2$. Also, for this function there are $f(0) + f(0) = 0$ and $f\left(\frac{1}{2}\right) + f\left(-\frac{1}{2}\right) = -2$, so for it there are $c \geq 2$.
