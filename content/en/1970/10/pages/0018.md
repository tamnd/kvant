NEIGHBORHOOD

Let us now return to two-dimensional space—to the $R^2$ plane—and discuss one visual way to compare different distances (4)–(6).

Let point $O=(0, 0)$ be the origin. Let us find the set of points located from the point $O$ at a distance less than a given number $r$. Everyone knows that this set is the interior of a circle with center $O$ of radius $r$ (Fig. 4, a); Of course, we are talking about distance (4), that is, about the set of points $(x, y)$ for which $\sqrt{x^2+y^2}<r$. And what will be the “circles of radius $r$” if the distance is determined by formula (5) or (6)? The set of points $(x, y)$ for which $|x|+|y|<r$ is the interior of a square with vertices $(0, r)$, $(-r, 0)$, $(0, -r)$ and $(r, 0)$ (Fig. 4, b); and the set of the point $\max\{|x|, |y|\}<r$, in other words, the set of points for which $|x|<r$ and $|y|<r$ are obviously a square with vertices $(-r, -r)$, $(-r, r)$, $(r, -r)$ and $(r, r)$ (Fig. 4, c).

Obviously, when talking about metric spaces, instead of the words “circles of radius $r$ with center $a$” they say “$r$ neighborhoods of the point $a$”.

Definition 1. Let $X$ be a metric space, $\rho$ the distance in $X$, $r$ a positive number. Then the $r$-neighborhood of the point $a$ is called the set of all points $m$ from $X$ for which $\rho(m, a)\leqslant r$. Briefly, this set can be written as follows: $\{m: \rho(m, a)\leqslant r\}$.

Thus, in Figures 4, a, b, c, the $r$-neighborhoods of the point $(0, 0)$ are depicted, if the distance on the plane is given by the corresponding formulas (4), (5) and (6); it is not difficult to report that the $r$-neighborhood of any other point $(x_0, y_0)$ in these metric spaces looks exactly the same as the neighborhood of the point $(0, 0)$ - simply the center of the circle or square is shifted to the point $(x_0, y_0)$.

Let's see what the $r$-neighborhoods are in the metric spaces we talked about earlier. In Example 1, $r$ is the neighborhood of the point $a$ on the number axis

$$\{x; |x-a|\leqslant r\}$$

is a segment of length $2r$, the middle of which lies at the point $a$ (Fig. 5). In example 3′, the 20-neighborhood of Moscow is a set of cities where you can actually fly for no more than 20 rubles; in Example 2, the $r$-neighborhood consists of only one point if $r<1$, and contains the entire set $X$ if $r\geqslant 1$.
