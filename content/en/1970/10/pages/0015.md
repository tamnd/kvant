3°. The distance from $a$ to $c$ is not greater than the sum of the distances from $a$ to $b$ and from $b$ to $c$ (“triangle axiom”).

Let's start with the simplest examples of metric spaces.

Example 1. $X$ is the number line, that is, the set of all real numbers*). The distance $\rho$ is determined by the formula

$$\rho(x, y) = |x - y|.$$

(1)

Recall that $|a - b| = a - b$ if $a \geqslant b$ and $b - a$ if $b \geqslant a$, so in all cases $\rho(a, b)$ is equal to the length of the segment of the real line with ends $a$ and $b$ (Fig. 2, a).

Let's check that $\rho$ satisfies all three requirements $1^\circ - 3^\circ$. It is obvious that $|a - b| = 0$ if and only if $a = b$, and that always $|a - b| = |b - a|$.

The inequality $3^\circ$ is also almost obvious (Fig. 2, b). In each of the possible cases in the relative position of points $a, b$ and $c$ on a line, including also when two of the points $a, b$ and $c$ coincide, the inequality

$$|a - c| \leqslant |a - b| + |b - c|$$

(2)

easy to prove formally without referring to figure. For example, if $b \leqslant a \leqslant c$ (lower Fig. 2, b), then

$$|a - c| = c - a,$$

$$|a - b| + |b - c| = a - b + c - b = a + c - 2b \geqslant a + c - 2a = c - a,$$

and therefore (2) is true.

Example 2. $X$ is any set,

$$\rho(a, b) = \begin{cases} 0, & \text{ если } a = b, \\ 1, & \text{ если } a \neq b. \end{cases}$$

(3)

All axions $1^\circ - 3^\circ$ are obviously fulfilled. This is, as they say, a “discrete” space, in which all the points seem to be separate, not too close to each other.
