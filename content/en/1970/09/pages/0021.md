equation - parameter!

A. Ya. Margulis,
A. G. Mordkovich,
B. A. Radunsky

Instead of a preface
I remember such a case. The student was asked to solve a seemingly harmless equation:
$(a^2 - 5a + 6)x = a^2 - 4$. (1)
Without thinking twice, the student continued the following calculations:
$$x = \frac{a^2 - 4}{a^2 - 5a + 6} = \frac{(a - 2)(a + 2)}{(a - 2)(a - 3)};
x = \frac{a + 2}{a - 3}.$$ (2)
He clearly did not take into account that the given equation contains the parameter $a$ and that an equation with a parameter is, in essence, a set of equations. So our equation for $a = 0$ takes the form $6x = -4$, for $a = 1$ it takes the form $2x = -3$, etc. In other words, having given the parameter a specific numerical value, we select one from the set of equations - corresponding to the selected value of the parameter. But then the solution depends on the parameter.
We have already said that for $a = 0$ equation (1) takes the form $6x = -4$. The root of this equation is the value $x = -\frac{2}{3}$. But according to formula (2) with $a = 0$ we get $x = -\frac{2}{3}$.
For $a = 1$, equation (1) takes the form $2x = -3$, hence $x = -\frac{3}{2}$. But according to formula (2) with $a = 1$ we get $x = -\frac{3}{2}$.
If such a situation occurred for any active knowledge $a$, then it could be argued that formula (2) determines the solution to equation (1). But that's not true.
Let's put $a = 2$. Equation (1) becomes $0 \cdot x = 0$. The root of this equation is any real number, while formula (2) gives in this case $x = -4$.
For $a = 3$, equation (1) takes the form $0 \cdot x = 5$. This equation has no solutions. However, the expression $\frac{a + 2}{a - 3}$ does not make sense with $a = 3$.
Thus, it is impossible to assert that $x = \frac{a + 2}{a - 3}$ for any value of the parameter.
In fact, it was necessary to reason as follows. Before dividing both sides of equation (1) by the coefficient for the unknown, let's see if it could happen that for some values ​​of the parameter this coefficient will become zero. We note that the trinomial $a^2 - 5a + 6$ vanishes at $a = 2$, $a = 3$. This means that we need to consider these cases separately, which we have already done. If $a \neq 2$, $a \neq 3$, then we can divide both sides of the equation by the coefficient of $x$, we get $x = \frac{a + 2}{a - 3}$. Combining the results obtained, we write down
ANSWER: if $a = 2$, then $x$ is any real number;
if $a = 3$, then there are no solutions;
if $a \neq 2$, $a \neq 3$, then $x = \frac{a + 2}{a - 3}$.
