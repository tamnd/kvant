Task 3

Solution of the first equation of this system:

$$\cos x - \cos 13x = 0$$

or

$$2\sin 7x\sin 6x = 0$$

gives two series of values

a) $x = \frac{1}{7}n\pi$ ($n = 0, \pm 1, \pm 2, \ldots$),

6) $x = \frac{1}{6}m\pi$ ($m = 0, \pm 1, \pm 2, \ldots$).

Selecting from these values ​​those that satisfy the inequality $|x| < 3$, we find:

a) $x = \frac{1}{7}n\pi$, $|n| \leq 6$,

6) $x = \frac{1}{6}m\pi$, $|m| \leq 5$.

Now we must choose those values ​​of $x$ that satisfy the second equation of the system. This equation can be represented as:

$$1 = \sin 5x + \cos 2x = \sin 5x + \sin \left(\frac{\pi}{2} + 2x\right) = 2\sin \left(\frac{7x}{2} + \frac{\pi}{4}\right)\cos \left(\frac{3x}{2} - \frac{\pi}{4}\right).$$

Let us first substitute series (a) into it. Since $7x = n\pi$ ($|n| \leq 6$), the equality must be satisfied:

$$\sin \left(\frac{n\pi}{2} + \frac{\pi}{4}\right)\cos \left(\frac{3n\pi}{14} - \frac{\pi}{4}\right) = \frac{1}{2}$$

Since $\sin \left(\frac{n\pi}{2} + \frac{\pi}{4}\right) = \pm \frac{V^2}{2}$, then $\cos \left(\frac{3n\pi}{14} - \frac{\pi}{4}\right) = \pm \frac{V^2}{2}$ and, therefore, $\frac{3n\pi}{14} - \frac{\pi}{4}$ must differ from $\frac{\pi}{4}$ by an initial multiple of $\frac{\pi}{2}$. However, $\frac{3n\pi}{14} = \frac{3n}{7}\cdot \frac{\pi}{2}$, so $\frac{3n}{7}$ must be an integer. Under the constraint $|n| \leq 6$ this occurs only at $n = 0$. Substituting the value $n = 0$ into equation (1), we make sure that it satisfies it. So from series (a) only $x = 0$ is a solution.

Let's now check series (6). Presenting the second equation of this system in the form:

$$\sin 5x = 1 - \cos 2x = 2\sin^2x,$$

we note that $\sin 5x$ must be non-negative, that is, the angle $5x = \frac{5}{6}m\pi$ ($|m| \leq 5$) is contained in the first two quadruples. Substituting possible integer values ​​$m$ from $-5$ to $+5$ into the expression $\frac{5}{6}m\pi$, we establish that only six are subject to verification
