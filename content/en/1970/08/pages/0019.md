It is important to understand that any of these formulations define a singular number.

It is easy to show (do this) that if the irrational number $\alpha$ is decomposed into an integer fraction, then successive suitable fractions are alternately smaller and larger than $\alpha$. It follows that this number $\alpha$ is the value that is now assigned to the infinite whole fraction (the unity of the point belonging to all segments!). Others are allowed to write

$$\alpha = [a_0; a_1, a_2, \dots].$$

It is now clear that each suitable fraction can be considered an approximation of the whole fraction. The larger the number, the more accurate the approximation.

Almost the same thing was said about the approximation of a finite integer fraction by suitable fractions. The only difference is that in the case of an infinite whole fraction, there is no last good fraction, and significant, no good fraction gives the powerful value of the whole fraction.

For infinite integer fractions, the sign of equality is preserved («Kvant», No. 1, p. 22). Let's formulate it like this:

1) Two infinite integer fractions $[a_0; a_1, a_2, \dots, a_n, \dots]$ and $[b_0; b_1, b_2, \dots, b_n, \dots]$ are equal to each other if and only if their corresponding elements coincide, i.e. $a_n = b_n$ with $n=0, 1, 2, \dots$.

2) An infinite whole fraction cannot be equal to a finite fraction.

Can. For example,

In this example, we replace a cumbersome rational number with a simpler one.

Once we've become familiar with whole fractions, a natural project that comes up is to factor the number $\alpha$ into a whole fraction and count successive suitable fractions as approximations of that number. In other words, truncate the whole fraction, discarding all elements starting from some, and take the remaining truncated fraction as an approximate value of the full whole fraction. This is exactly what we do by truncating the decimal fraction and leaving only the desired number of francs after the decimal point.

In order to accept or reject this project, we need to find out what kind of error we allow by replacing the number $\alpha$ with a suitable fraction, i.e., assuming

$$\alpha \approx \frac{p_n}{q_n}.$$

In all further reasoning it is assumed that the fraction $\frac{p_n}{q_n}$ is not zero and not the last. For $n=0$ the use of whole fractions does not provide anything new compared to the use of decimals, and the case $n=s$ is uninteresting since we get $\alpha=\alpha$ and the error is zero.
