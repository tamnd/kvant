4. Difference of adjacent suitable fractions. The step from the $n$th suitable fraction to the next one is represented by the $n$th fraction and is designated $\Delta_n$:

$$\Delta_n = \frac{p_{n+1}}{q_{n+1}} - \frac{p_n}{q_n} = \frac{p_{n+1} q_n - p_n q_{n+1}}{q_n q_{n+1}} = \frac{D_n}{q_n q_{n+1}},$$

where $D_n$ denotes numeric

$$D_n = p_{n+1} q_n - p_n q_{n+1}.$$

Let us lower the indices $y$ $p_{n+1}$ and $q_{n+1}$ according to formulas (3.2):

$$D_n = \left( p_n a_{n+1} + p_{n-1} \right) q_n - p_n \left( q_n a_{n+1} + q_{n-1} \right) = -\left( p_n q_{n-1} - p_{n-1} q_n \right).$$

The expression in parentheses is the same type as (**), but all indices are by one

less. So it represents $D_{n-1}$:

$$D_n = -D_{n-1}.$$

This recurrence relationship allows you to lower the index to zero:

$$D_n = -D_{n-1} = D_{n-2} = -D_{n-3} = \dots = (-1)^n D_0.$$

For complete success, all that remains is to directly calculate $D_0$:

$$D_0 = p_1 q_0 - p_0 q_1 = (a_1 a_0 + 1) \cdot 1 - a_0 a_1 = 1.$$

Hence,

$$D_n = p_{n+1} q_n - p_n q_{n+1} = (-1)^n,$$

(4.1) and by formula (*)

$$\Delta_n = \frac{p_{n+1}}{q_{n+1}} - \frac{p_n}{q_n} = \frac{(-1)^n}{q_n q_{n+1}}.$$

5. Comparing the one with the odd number greater than the neighboring fractions (previous and subsequent). What suitable odd-numbered fraction is smaller than its neighboring fractions.

When applying this formulation to the zero and last suitable fractions, we must take into account that each of them has only one neighboring fraction.

The validity of this property is immediately clear from formula (4.2).

Property 1 means that successive suitable fractions are alternately greater and lesser.

Property 2. Differences between adjacent fractions in abscimal values ​​cancel out (meaning: as the number increases).

Let's compare:

$$|\Delta_n| = \frac{1}{q_n q_{n+1}},$$

$$|\Delta_{n+1}| = \frac{1}{q_n+1 q_{n+2}}.$$

We have $q_{n+2} > q_n$. This means that the second fraction has a larger denominator, but it itself is smaller:

$$|\Delta_{n+1}| < |\Delta_n|.$$
