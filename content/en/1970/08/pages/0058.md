As is known, for ordinary arithmetic operations the distributivity of addition with respect to multiplication does not apply: the equality $(ab) + c = (a + c) \times (b + c)$ is not true for all real numbers. But for the operations “addition” and “multiplication” we introduced, this distributivity is also true:

$$(a \otimes b) \oplus c = (a \oplus c) \otimes (b \oplus c).$$

The reader will be convinced of this by checking that max $(\min(a, b), c) = \min(\max(a, c), \max(b, c))$ for any real numbers $a, b, c$.

Interestingly, “addition” and “multiplication” also have other properties that are not observed in ordinary real number arithmetic:

$$a \oplus a = a, a \otimes a = a;$$

$$a \otimes (a \oplus b) = a, a \oplus (a \otimes b) = a.$$

These relations directly follow from the definitions of the operations $\oplus$ and $\otimes$.
