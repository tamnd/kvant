Erdős–Szekeres problem: continuation of the story

V. KOSHELEV, A. RAIGORODSKY

On the road again

In «Kvant» No. 2 for this year, our article “The Erdős–Szekeres Problem on Convex Polygons” [1] was published. There we told the amazing (and sometimes even romantic) story of one of the most beautiful and popular problems in combinatorial geometry - a story that began 75 years ago and which is very far from its end. The reader who wants to properly understand the origins of what we will talk about in this article must, of course, arm himself with the above-mentioned article, because here we will only recall a brief summary of the “previous series”, and then we will move into fundamentally new for us, hitherto unexplored areas. So, the main objects of our research were sets of points in general position on the plane. Recall that these are all sets in which no three elements lie on the same line. Our goal was to find for each natural number n the value of the function g(n), which we assumed to be equal to the smallest g such that in any general position set on the plane with cardinality g, there are necessarily n points that are the vertices of a convex n-gon. First, we discussed the behavior of the function g(n) for $n \in { 3,4,5,6 }$ and found out that every time $g ( n ) = 2^{n} -^{2} + 1$. Then we were convinced that in general for all $n \ge 3$ the value of g(n) is finite and that, moreover, $g ( n ) \le 4^{n}$, more precisely $g ( n ) \le C_{2} nn --_{5}^{2} + 1$ for $n \ge 5$. Finally, we showed that, again, for any $n g ( n ) \ge 2^{n} -^{2} + 1$. That's basically all. It turns out, however, that this is just the beginning of the journey. And the point is not only that the exact form of the function g(n) is still unknown (we can only believe, following the authors of the problem, that $g ( n ) = 2^{n} -^{2} + 1 );$ the point is also that the original problem allows for a number of very natural, no less beautiful generalizations and, as they usually say in science, modifications. It is about them that we will now talk.

Convex and empty polygons

Modification of the Erdos–Szekeres problem

Almost half a century after the publication of the remarkable article [2], or more precisely in 1978, P. Erdős proposed slightly modifying the condition of the original problem, which by that time had become classic.

He asked the question: what if we look for in one or another $множестве^{X}$ of general position on the plane not just the vertices of convex polygons, but the vertices of such convex polygons, inside which there are no other points $множества^{X}$? It is natural to call such polygons empty or holes. figure1 shows an example of a hole and an example of a non-hole. Let us introduce the value h(n), which will serve as an analogue of the value g(n) within the framework of the new problem. What does it mean? In theory, everything is very simple. Let us assume that for a given natural number $n \ge 3$ we have found a number h such that in any general position set on the plane with cardinality h there is an empty n-gon and there is a general position set on the plane having size h – 1 and not containing holes on n vertices. So let’s then put h ( n ) = h. Just? Not really. The point is that it is not immediately clear why the presence of empty polygons in an arbitrary h-point set guarantees us their presence in every set of size h + 1. A problem arises with satisfying the condition of emptiness, which was not there before (i.e. when determining the value of g(n)). In other words, if previously we calmly spoke about the boundary value g(n), starting from which every set of the appropriate size contained a convex polygon, then from now on such calmness still needs to be earned. Fortunately, the problem is easily fixable. Statement 1. Let, for some h, any general position set on the plane with cardinality h contain a convex and empty n-gon. Then the same is true for every generic set of size h + 1. Proof. Consider an arbitrary set X of cardinality $h + 1. Пусть^{H}$ – a polygon that is its convex hull (see [1]). Let's delete $из^{X}$ any vertex of this polygon. What remains is a set of size h, which, according to our assumption, contains a convex and empty n-gon.
