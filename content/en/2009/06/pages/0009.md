The above counterexample was constructed by Motzkin in 1951 [9]. He also proved the following (more correct) generalization of the Sylvester–Gallay theorem. Theorem 4. If not all points of a finite set M lie in the same plane, then there is such a plane (we will call it the Motzkin plane), the intersection of which with M consists of several (at least two) collinear points and one more point that is not collinear with them.

Circles

Motzkin's theorem can be used to extend the Sylvester–Gallay theorem to the case of circles. Consider a finite set of points on a sphere. Every plane passing through 3 different points on a sphere cuts out a certain circle on the sphere. Let us assume that not all points of the set M lie on the same circle (or, equivalently, not all points lie in the same plane). Then there is a Motzkin plane whose intersection with M consists of a series of collinear points and one more single point that is not collinear to this series. Note, however, that a series of collinear points on a sphere cannot contain more than two points. Consequently, the Motzkin plane contains exactly three points of the set M, and these points are necessarily not collinear. In particular, these three points lie on a circle that does not contain other points of the set M. Thus, we obtain the following statement. Theorem 5. For a finite set of points M on a sphere, not all of which lie on the same circle, there is a circle (analogous to the Sylvester line) that contains exactly three points of the set M. Consider the stereographic projection of the sphere onto the plane. Recall that stereographic projection is defined in this way. The center of the projection is point A on the sphere. The projection of point B on a sphere (different from point A) is a point C on the plane we have chosen such that A, B and C are collinear (Fig.7). A well-known fact is that the stereographic projection of a circle on a sphere is a circle or

On the contrary, a curve projected into a circle or straight line on a plane is necessarily a circle on a sphere. If this fact is unknown to the reader, then it would be very useful to prove it yourself. Using stereographic projection we obtain the following theorem. Theorem 6. Let a finite set of points on the plane be given. Let us assume that not all points of this set lie on the same line and not all points lie on the same circle. Then there is a straight line or circle containing exactly three points of our set. In fact, it is possible to prove a stronger statement without even having to use Motzkin's theorem. Theorem 7. Let a finite set M of points on the plane be given. Let us assume that not all points of the set M lie on the same line, and not all lie on the same circle. Then for every point A in M ​​there is a line or circle containing A and exactly two more points of the set M. Proof. It is clear that it is enough to prove the following statement for the sphere (it is obtained from the theorem just formulated by stereographic projection). Let us be given a finite set of points $M '$ on a sphere that does not lie on the same circle. Then, for every point $A '$ from the set $M '$ there is a circle on the sphere containing the point $A '$ and exactly two more points of the set $M '$. To prove this statement, let's make another stereographic projection, this time centered at point $A '$. With this projection, the point $A '$ itself does not correspond to any point on the plane (informally speaking, it corresponds to a point at infinity). All circles containing the point $A '$ become straight lines. As a result of our new stereographic projection, we get a new set of $M ''$ points on the plane that does not lie on the same line (since the set $M '$ did not lie on the same circle). But then for him there is Sylvester's direct line! We project this line back onto the sphere and obtain a circle containing, in addition to the point $A '$, exactly two more points of the set $M '$. The theorem has been proven.
