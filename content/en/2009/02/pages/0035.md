no one has yet succeeded in creating a square that would allow only non-periodic tilings!

Did you know that:

1. The plane can be divided into identical non-convex heptagons.

2. If the plane is divided into convex heptagons, then among them there is either an arbitrarily small one or an arbitrarily large one. 3. There is an example of partitioning space into equal convex 38-hedrons, but no one knows whether the number 38 can be replaced by a larger one. 4. There is a set of three convex polygons that can be used to tile a plane in an infinite number of ways, but each of these ways is non-periodic. However, no one knows whether the number 3 can be reduced - this is an open problem. In space, the problem is solved - there is a polyhedron that can be used to tile the entire space, but only non-periodically. 5. It is unknown what tetrahedrons can be used to cover the entire space. 6. There are 3 types of convex hexagons and 14 types of convex pentagons that can be used to cover the entire plane. The problem about non-convex ones is open. 7. Nobody knows whether there is an algorithm that takes a polygon as input, and at the output says whether it is possible to tile the entire plane with this polygon. S.
