Task 2. Prove that
ctg30° + ctg75° = 2.

Solution. Consider an equilibrium triangle ABC such that
∠A = 30°, AB = AC. Let's find its height BD. Let BD = 1. Then AB = AC = 2, AD = ctg30°, CD = ctg75° and AD + CD = AC.

Task 3. Calculate tg15°.

Solution. Consider the equilibrium triangle ABC from the previous problem. Then ∠CBD = 15°, AD = √3 and tan15° = CD = 2 - √3.

x/1-x = 1/x, whence x = -1 + √5/2. So sin18° = √5 - 1/4.
