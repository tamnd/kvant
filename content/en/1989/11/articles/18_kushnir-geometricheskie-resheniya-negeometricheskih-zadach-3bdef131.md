Geometric solutions to non-geometric problems

I. A. KUSHNIR

Many problems in algebra and trionometry can be solved using geometry. In this post we will show several examples of such tasks.

Numerical Equalities

Task 1. Prove the equalities

a) $\cos \frac{\pi}{5} - \cos \frac{2\pi}{5} = \frac{1}{2}$;

b) $\frac{1}{\sin \frac{\pi}{7}} = \frac{1}{\sin \frac{2\pi}{7}} + \frac{1}{\sin \frac{3\pi}{7}}$

Solution. a) To prove this, consider an equilateral triangle $ABC$ with angles $\pi/5, 2\pi/5, 2\pi/5$ (see Fig. 1) and draw the bisector $BD$ of angle $B$. Then $BC=BD=AD$. Let, for definiteness, $BC=1$. From the triangles $ABD$ and $BCD$ we obtain $AB=2\cos \frac{\pi}{5}, CD=2\cos \frac{2\pi}{5}$, and from the equality $AD=AB-AC$ the correspondence immediately follows.

6) Proves similarly. We only need to consider the equilateral triangle $ABC$ with vertex angle $\pi/7$ (see Fig. 2) and height $BB_1=1$. From triangles $ABB_1, BDB_1, BCB_1$ there is

$$AB=AC = \frac{1}{\sin \frac{\pi}{7}}; \quad BD=AD = \frac{1}{\sin \frac{2\pi}{7}};$$

$$BC = \frac{1}{\sin \frac{3\pi}{7}}.$$

It remains to note that $AC=AD+CD$.

Task 2. Prove that
ctg30° + ctg75° = 2.

Solution. Consider an equilibrium triangle ABC such that
∠A = 30°, AB = AC. Let's find its height BD. Let BD = 1. Then AB = AC = 2, AD = ctg30°, CD = ctg75° and AD + CD = AC.

Task 3. Calculate tg15°.

Solution. Consider the equilibrium triangle ABC from the previous problem. Then ∠CBD = 15°, AD = √3 and tan15° = CD = 2 - √3.

Task 4. Calculate sin 18°.

Solution. Let's go back to figure 1. Let AB = 1, BC = x = 2sin18°. Search △BDC ∞ △ABC, we have
x/1-x = 1/x, whence x = -1 + √5/2. So sin18° = √5 - 1/4.

Task 5. Prove that
sin9° + sin49° + sin89° + ... + sin289° + sin329° = 0.

Solution. Consider an equal decagon A₁A₂...Aₙ, formed into a unit circle with center at point O (see Fig. 3). Let
e₁ = OA₁. Then e₁ + e₂ + ... + eₙ = 0. We require that the familiarity of the n-gon A₁A₂...Aₙ (cos (9° + i40°); sin (9° + i40°)) is equal to zero.
