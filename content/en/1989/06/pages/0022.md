Application to linear programming

In the article by V. M. Tikhomirov in this issue of the Kurnal he talks about linear programming. We will show how a linear programming problem can be reduced to solving a certain system of linear inequalities. This solution is not the most economical, but logically it is simple in terms of weight.

So, let’s say we need to find the minimum (or maximum) of some linear function $F=a_1x_1+\dots+a_nx_n$ under the conditions

$$\begin{cases} L_1 \geq 0, \\ L_2 \geq 0, \\ \dots, \\ L_n \geq 0, \end{cases}$$

where $L_i$ ($i=1, 2, \dots, m$) are linear functions of $x_1, x_2, \dots, x_n$.

Let $M$ be the set of all solutions of the system $L$, and $d$ be the minimum of the function $F$ on this set. For each of the solutions $x=(x_1, x_2, \dots, x_n)$, consider the number $F(x)$. The smallest of all numbers is $F(x)$, where $x \in M$ is $d$.

However, the number $F(x)$ itself, for a given $x \in M$, is also the largest of all numbers in a certain set, namely, of all the numbers $z$ such that $z \geq F(x)$. Therefore, we can define the number $d$ in another way: we should consider the system

$$\begin{cases} L_1 \geq 0, \\ L_m \geq 0, \\ z-F \geq 0 \end{cases}$$

linear inequalities with $n+1$ unknowns $z, x_1, \dots, x_n$ and from all its solutions choose the one for which $z$ takes the smallest value.

The method of reducing a linear programming problem to solving a certain system of linear inequalities, indicated in this section, makes it possible to easily prove the following theorem (which is one of the main theorems of linear programming).

Theorem. If the collection of a linear function $L$ on the set $M$, defined by the system $S$ of linear inequalities, is bounded by space, then in this collection there exists a smallest number ($t$, i.e. there is a minimum $L$ on the set $M$).

Indeed, after eliminating the unknowns $x_n, x_{n-1}, \dots, x_1$ from the system $T$, we obtain a system $T^{(n)}$ of inequalities with one unknown $z$. The set of its solutions coincides with the set of values ​​of the function $L$ (on $M$). This is where the statement of the theorem follows.
