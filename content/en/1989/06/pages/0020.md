Related system of linear inequalities

Let a system of linear inequalities with $n$ unknowns $x_1, \dots, x_n$ be given—we will call it the “system $S$”. In the following, we consider only inequalities of type $\geq$. Thus, the system $S$ has the form

$$\begin{cases} L_1 \geq 0, \\ L_2 \geq 0, \\ \dots \dots \\ L_m \geq 0, \end{cases}$$

where each $L_i$ ($i=1, 2, \dots, m$) is an expression of the form

$$a_1x_1 + a_2x_2 + \dots + a_nx_n + a.$$

When considering the $S$ system, two main questions arise:

a) is the system consistent, i.e. does it have at least one solution $x_1 = x_1^0, x_2 = x_2^0, \dots, x_n = x_n^0$;

b) if so, how to find all its solutions?

Consider any of the inequalities of the system $S$. It looks like

$$a_1x_1 + a_2x_2 + \dots + a_nx_n + a \geq 0.$$ (*)

If $a_n = 0$, leave inequality (*) unchanged. If $a_n \neq 0$, then, depending on the sign of $a_n$, we reduce it to the form $P_n \geq x_n$ (for $a_n \geq 0$) or $Q \leq x_n$ (for $a_n < 0$). So, any of the inequalities of the system $S$ is reduced to one of three types $R \geq 0, P \geq x_n, Q \leq x_n$, where $R, P$ and $Q$ are expressions of the form

$$b_1x_1 + b_2x_2 + \dots + b_{n-1}x_{n-1} + b,$$

i.e. linear polynomials, already dependent on the $(n-1)$-th variable.

Thus, the system $S$ is equal to the system $S_1$:

$$P_1 \geq x_n,$$
$$P_2 \geq x_n,$$
$$P_p \geq x_n,$$

$$x_n \geq Q_1,$$
$$x_n \geq Q_2,$$
$$x_n \geq Q_q,$$

$S_1$

This system consists, generally speaking, of three blocks, outlined by frames. Of course, it is not excluded that the system $S_1$ will not have one or even two blocks. It depends on the signs of the numbers $a_n$.

Let us now construct a system with a smaller number of unknowns in the same way as we did when considering the example:

$$\begin{cases} P_\alpha \geq Q_\beta, \\ R_\gamma \geq 0, \end{cases}$$

where $\alpha = 1, 2, \dots, p, \beta = 1, 2, \dots, q, \gamma = 1, 2, \dots, r$.

There are $pq + r$ inequalities in this system.

The system $S^{(1)}$ is called `conuctвуошей` in relation to the original system $S$.

If it turns out that in the system $S_1$ the first or second block is missing, then the accompanying system will consist only of inequalities $R_\gamma \geq 0$, if the third block is missing, then it will only contain inequalities $P_\alpha \geq Q_\beta$. Finally, if the first and third blocks or the second and third are missing, then there is no accompanying system at all. We will consider it to be effective in this case too, i.e., the state from inequality $0 \geq 0$ (or, more precisely, from inequality $0 \cdot x_1 + \dots + 0 \cdot x_n + 0 \geq 0$).
