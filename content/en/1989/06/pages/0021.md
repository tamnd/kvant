What does it mean to solve a system of linear inequalities?

We have already discovered the connection between the solutions of the original system $S$ and the accompanying system $S^{(1)}$ using an example. In the general case, this connection is expressed by the following theorem.

Theorem. If from any solution of the system $S$ we discard the value of the last unknown $x_n$, then we obtain a certain solution of the accompanying system $S^{(1)}$.

Conversely, for any solution of the accompanying system $S^{(1)}$ one can find a value of the unknown $x_n$, which we add to obtain a solution to the original system $S$.

The first statement of the theorem is very indo (if any set of values ​​of unknowns satisfies the system $S$, then it also satisfies system (2); but then for the same set all the inequalities of the system $S$ are satisfied). Let's prove the converse theorem.

First, consider the main case—when the accompanying system $S^{(1)}$ has at least one inequality $P_\alpha \geq Q_\beta$. Let
$$x_1 = x_1^0, \dots, x_{n-1} = x_{n-1}^0$$
— some solution of the system $S^{(1)}$. Substituting the indicated values ​​of the unknowns into the expressions $P_1, \dots, P_p, Q_1, \dots, Q_q, R_1, \dots, R_r$, we obtain some numbers $P_1^0, \dots, P_p^0, Q_1^0, \dots, Q_q^0, R_1^0, \dots, R_{1r}$. For them the inequalities hold
$$P_\alpha^0 \geq Q_\beta^0, R_\gamma^0 \geq 0$$
($\alpha=1, 2, \dots, p; \beta=1, 2, \dots, q; \gamma=1, 2, \dots, r$).

We see that each of the numbers $Q_1^0, \dots, Q_q^0$ is no greater than any of the numbers $P_1^0, \dots, P_p^0$. But in this case it is necessary to find the number $x_n^0$, which

enclosed between all numbers $Q_1^0, \dots, Q_q^0$ and all numbers $P_1^0, \dots, P_p^0$:
$$P_\alpha^0 \geq x_n^0 \geq Q_\beta^0$$
($\alpha=1, 2, \dots, p; \beta=1, 2, \dots, q$).

It follows that the set of unknown values
$$x_1 = x_1^0, \dots, x_{n-1} = x_{n-1}^0, x_n = x_n^0$$ is a solution to system $S^{(1)}$, and therefore $S$.

In the exceptional case - when the accompanying system $S^{(1)}$ consists only of inequalities $R_\gamma \geq 0$ - the first or second block is missing in the system $S_1$. If there is no first block, any number that satisfies the condition can be taken as $x_n$
$$x_n^0 \geq Q_\beta^0 (\beta=1, \dots, q).$$

Similarly, in the absence of the second block $x_n^0$ we choose based on the condition
$$P_\alpha^0 \geq x_n^0 (\alpha=1, \dots, p).$$

Finally, if the first and second blocks are missing at once, then any number can be taken as $x_n^0$. The theorem has been proven.

So, the system $S$ of linear inequalities is consistent if and only if the system $S^{(1)}$ accompanying it is consistent. In this case, all solutions of the original system $S$ can be obtained in the following way: it is necessary to add to each solution $x_1^0, \dots, x_{n-1}^0$ of the accompanying system $S^{(1)}$ any of the numbers $x_n^0$ contained between all numbers $P_1^0, \dots, P_p^0$ and all numbers $Q_1^0, \dots, Q_q^0$.

Let's say a few words about the geometric meaning of the theorem proved above. Let us assume that $S$ is a system of inequalities with unknowns $x, y, z$. the accompanying system $S^{(1)}$ is a system with two unknowns $x, y$. Let $M(S)$ be the set of solutions of the system $S$ (this is a certain set of points in space), and $M(S^{(1)}$ be the set of solutions of the system $S^{(1)}$ (the set of points on the plane). The region $M(S^{(1)})$ is the projection of the region $M(S)$ onto the xy coordinate plane.
