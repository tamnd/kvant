⟦folio 17⟧

SYSTEMS
LINEAR INEQUALITIES
AND THEIR APPLICATION

Doctor of Physical and Mathematical Sciences
A. S. SOLODOVNIKOV

The theory of systems of linear inequalities is close to school mathematics. This theory has many applications, mainly to linear programming, which is discussed in the article by V. M. Tikhomirov in this issue of the journal. We will talk about the very basics of the theory of systems of linear inequalities.

System solution
linear inequalities by successively decreasing the number of unknowns
Let's start with an example. Suppose we need to solve a system of inequalities (more precisely, learn to find all its solutions):
$$\begin{cases}
7x+2y-2z-4 \geq 0, \\
-x-y-z+4 \geq 0, \\
-2x+3y+z-1 \geq 0, \\
5x-y+z+2 \geq 0.
\end{cases}$$

We will use an example that resembles the solution of a general system of linear equations. Let us rewrite system (1) as follows:
$$\begin{cases}
\frac{7}{2}x+y-2 \geq z, \\
-x-y+4 \geq z, \\
z \geq 2x-3y+1, \\
z \geq -5x+y-2.
\end{cases}$$

From (2), it follows that
$$\begin{cases}
\frac{7}{2}x+y-2 \geq 2x-3y+1, \\
\frac{7}{2}x+y-2 \geq -5x+y-2, \\
-x-y+4 \geq 2x-3y+1, \\
-x-y+4 \geq -5x+y-2.
\end{cases}$$

Let us assume that we know at least one solution ($x_0, y_0$) of system (3). But then the solution to system (2) will be any triple ($x_0, y_0, z_0$), where $z_0$ is any number contained between the smallest of the left-hand sides of the inequalities of system (2) and the largest of the right-hand sides of the inequalities of this system. Conversely, if ($x_0, y_0, z_0$) is a solution to system (1), then the pair ($x_0, y_0$) is a solution to system (3).

System (3) can be rewritten (by analogy with what we did with system (1)) as follows:
$$\begin{cases}
y \geq -\frac{3}{8}x + \frac{3}{4}, \\
y \geq \frac{3}{2}x - \frac{3}{2}, \\
2x+3 \geq y, \\
x \geq 0.
\end{cases}$$

Again, if ($x_0, y_0$) is a solution to system (4), then $x_0$ satisfies the system
$$\begin{cases}
2x+3 \geq \frac{3}{8}x + \frac{3}{4}, \\
2x+3 \geq \frac{3}{2}x - \frac{3}{2}, \\
x \geq 0,
\end{cases}$$

which is equivalent to a single inequality $x \geq 0$.

Let us now take some solution to this inequality, say $x=1$, and substitute this value $x$ in system (4):
$$y \geq \frac{3}{8}, y \geq 0, y \leq 5$$

whence $\frac{3}{8} \leq y \leq 5$. Let us now take $y=4$ and substitute $x=1$ and $y=4$ in system (2). We get $-1 \geq z \geq -3$. For such $z$ any triple (1, 4, $z$) satisfies the original system.
