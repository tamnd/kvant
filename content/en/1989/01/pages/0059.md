⟦folio 57⟧

Through the point $P$, the small circle intersects for the second time at the point $A$ (in the case when $l$ is a tangent to the circle, we assume that $A=P$).

1) Find the set of values ​​of the expression $BC^2+CA^2+AB^2$.

2) Find the set of points that are the midpoints of the segments $AB$.

2 (Czechoslovakia). Let $n$ be a natural number and $A_1, A_2, \dots, A_{2n+1}$ be subsets of some set $B$. Suppose that $a)$ each set $A_i(i=1, 2, \dots, 2n+1)$ contains exactly $2n$ elements;

$b)$ each set $A_i \cap A_j(1 \leq i < j \leq 2n+1)$ contains exactly one element;

$c)$ any element of the set $B$ takes at least two from the set $A_i(i=1, 2, \dots, 2n+1)$.

For what values ​​of $n$ can each element of the set $B$ be assigned one of the numbers 0 or 1 so that each of the set $A_1, A_2, \dots, A_{2n+1}$ contains equal to $n$ elements corresponding to the number zero?

3 (England). The function $f$ is defined on the set of positive integers and satisfies the following conditions:

$$f(1)=1, f(3)=3, f(2n)=f(n),$$
$$f(4n+1)=2f(2n+1)-f(n),$$
$$f(4n+3)=3f(2n+1)-2f(n).$$

Find the number of all such values ​​$n$, $1 \leq n \leq 1988$ for which $f(n)=n$.

4 (Ireland). Prove that the set of solutions to the inequality

$$\sum_{k=1}^{70} \frac{k}{x-k} \geq \frac{5}{4}$$

is the union of disjoint intervals whose sum of lengths is 1988.

5 (Greece). Let $AD$ be the height in right triangle $ABC, <A=90^\circ$. The prima line passing through the centers of the circles inscribed in triangles $ABD$ and $ACD$ intersects the sides $AB$ and $AC$, respectively, at points $K$ and $L$. Prove that

$$S_{ABC} \geq 2S_{AKL}.$$

6 (Germany). Let $a$ and $b$ be positive integers such that $a^2+b^2$ is divisible by $ab+1$ without remainder. Prove that $\frac{a^2+b^2}{ab+1}$ is the square of an integer.

Let's briefly talk about how tasks for optimization are selected, how the MMO jury is formed and how it works. Each participating country is given the opportunity to propose no more than 6 problems with complete solutions, which, if possible, should cover different sections of the school mathematics course and have varying degrees of difficulty. From all the problems submitted to the competition, a special commission of the country carrying out the optimization selects, as a rule, 20-30 problems for further development.
