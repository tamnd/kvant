⟦folio 49⟧

Time intervals from 1 to 17 minutes.
Why are we confident that this can be done? The fact is that the following theorem holds:
If k and m are coprime numbers, then for any integer n we can also choose integers x and y, such that xk+ym=n. What does this theorem have to do with the hourglass? The most direct. It follows from it that if you have k-minute and m-minute clocks, you can measure any integer number of minutes if the numbers k and m are coprime. Indeed, if we want to measure n minutes, we will find the numbers x and y that satisfy this equation. Now, in the case when both of these numbers are positive, first we measure xk minutes using k-minute clocks, and then another ym minutes using m-minute clocks. If one of them, for example y, is negative, then we start both clocks at the same time, reverse the time of the clock from which the sand poured out, and at the moment when the m-minute clock counts its (-ym) minutes (y<0!), we stop the k-minute clock. Now, to count n minutes, you should start a k-minute clock and keep it running until it finishes counting xk minutes.

Thus, the k-minute clock started after stopping will count xk-(−y)m=xk+ym=n minutes.

No how to find the solution to the equation xk+ym=n? It turns out that it is enough to learn how to solve the equation xk+ym=1: if x=a, y=b is a solution to this equation, then x=na, y=nb is a solution to the equation xk+ym=n.

Yes, but how to find any solution to the equation xk+ym=1? There are quite a few ways, we will describe the simplest, but probably not the shortest.

Let's write this equation in the form y=(1−xk):m and give the number x the values ​​0, 1, 2, ..., m−1. Let us show that if k and m are coprime, then for one of these values ​​the number (1−xk):m will be an integer. Let's find divisions into m numbers 1−0·k, 1−1·k, ..., 1−(m−1)·k. They are pairwise distinct, or otherwise the number (1−x1k)−(1−x2k)=(x2−x1)k would be divisible by m, which means x2−x1 would be divisible by m (k and m are coprime!), which is impossible, since x2−x1<m. So, for some values ​​of x the remainder is zero; therefore, the number y=(1−kx):m is an integer. These x and y constitute the desired solution to the equation xk+ym=1.
