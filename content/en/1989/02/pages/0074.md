⟦folio 72⟧

Naimput

P. Wolfbein from Kyiv reports the following theorem:

If the natural numbers $a_1, a_2, \dots, a_n (n \geq 3)$ satisfy the corresponding $f(x) = x^2 - px + q$, where $p = na_2a_3\dots a_n$, $q = a_2^2 + a_3^2 + \dots + a_n^2$. According to the conditions, $f(a_1) = 0$. Also, $a_2^2 + q = 2a_2^2 + a_3^2 + \dots + a_n^2 \leq na_2^2$ and $pa_2 = na_2^2a_3\dots a_n$. This means $f(a_2) = a_2^2 - pa_2 + q \leq 0$, and equality is achieved only at $a_2 = a_3 = \dots = a_n = 1$.

If not all $a_i = 1$, then $f(a_2) < 0$. This means $a_1$ is the larger root $f(x)$; Let's denote by $a'_1$ the smaller root. From Vieta's theorem it follows that $a'_1$ is a natural number and the numbers $a'_1, a_2, \dots, a_n$ also satisfy the original relation. So, from this set $a_1, a_2, \dots, a_n$ we can make a new set $a'_1, a_2, \dots, a_n$ with a smaller amount.

Continuing this procedure, we will arrive at a set of only units. If the original set contained pairs of non-coprime numbers, then such pairs will be present from Vieta’s formula: $a'_1 = na_2\dots a_n - a_1$. But in a set of only ones there are no such pairs, which proves that the numbers in the original set are coprime.
