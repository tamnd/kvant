2. $v_x > 0$ (passing rain).

There are two intervals to consider here:

1) $0 < u \leq v_x$. Then $|v_x - u| = v_x - u$, and

$$\psi = \frac{v_x S_{\pi} + v_y S_B + v_z S_B}{u} - S_{\pi}.$$

This function kills on the interval $(0; v_x]$ and reaches a minimum at $u = v_x$:

$$\psi |_{u = v_x} = \frac{v_y S_B + v_z S_B}{v_x}.$$

2) $u > v_x$. Then $|v_x - u| = u - v_x$, and

$$\psi = \frac{-v_x S_{\pi} + v_y S_B + v_z S_B}{u} + S_{\pi}.$$

Here it is no longer possible to immediately say how $\psi$ behaves as $u$ increases. It depends on the numerator of the fraction $A = -v_x S_{\pi} + v_y S_B + v_z S_B$. If $A > 0$, then $\psi(u)$ is a killing function on the segment $(v_x; +\infty)$, if $A < 0$ is increasing on this interval, and if $A = 0$, then $\psi = S_{\pi}$ is const on this interval.

The dependence graphs $\psi(u)$ for all $u \in (0; +\infty)$ are shown on figure 5. It can be seen that in the section from 0 to $v_x$ the curves have the same appearance for all three cases $(A > 0, A = 0$ and $A < 0)$, and after the break at $u = v_x$ they are different.

Conclusions

Having analyzed the calculation results and graphs in Figures 4 and 5, we can thoroughly answer the question of how to run away from the board.

So, if the board is counter, then you need to run to the steal as quickly as possible. If the board is downwind, then first you need to mentally estimate the values ​​of $A = -v_x S_{\pi} + v_y S_B + v_z S_B$. If it turns out that $A > 0$, then in this case it is advisable to hurry up. If $A = 0$, you can move at any speed exceeding $v_x$, you will get wet equally. Well, if $A < 0$ - you need to run strictly at a speed equal to $v_x$ - then you will get the least wet.

If, say, $v_y = 0$ (the case of a tailwind), then the inequality $A < 0$ is equivalent to the inequality $v_x S_{\pi} > v_z S_B$. Since for a tall, thin person $S_{\pi}$ is significantly larger than $S_B$, this inequality can hold for relatively small, “pedestrian” $v_x$. Such a person, if he moves towards stealing so that the trajectories of the drops seem vertical to him, has a chance to generally stay dry. This is called “slipping between the droplets.”
