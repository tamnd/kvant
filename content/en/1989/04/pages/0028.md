⟦folio 26⟧

For what values ​​of $n$ can we assign to which element of the set $B$ one of the numbers - 0 or 1 - so that each of the set $A_1, A_2, \dots, A_{2n+1}$ contains exactly $n$ elements corresponding to the number 0?

Fig. 2.

M1132. The function $f$ defines the set of positive integers and satisfies the following conditions:
$$f(1) = 1, f(3) = 3, f(2n) = f(n),$$
$$f(4n+1) = 2f(2n+1) - f(n),$$
$$f(4n+3) = 3f(2n+1) - 2f(n).$$
Find the number of all values ​​of $n$ for which $f(n) = n$ and $1 \leq n \leq 1988$.

If the distribution of zeros and ones over the elements of the set $B$ is given such that in each set $A_i$ there are exactly $n$ “0-elements”, then the total number of “0-elements” is equal to $n(2n+1)/2$ (each of them belongs to two sets $A_i$). And this number is an integer only if $n$ is even.

Conversely, for each element $x$ of the set $B$ the distance is the only pair of the set $\{A_i, A_j\}$ containing it and assign to the element $x$ the number 0 if $|i - j| \leq n/2$ or $|i - j| > 3n/2$, and 1 if $n/2 < |i - j| \leq 3n/2$.

For even $n$ we get exactly $n$ “0-elements” in each set $A_i$, which is what is required.

In solving this problem, the main considerations go into understanding the conditions properly. A graphical interpretation is very helpful here (see Fig. 1 and 2 for $n=4$): each set $A_i$ is represented by a vertex of a regular $(2n+1)$-gon, and the only common element of the set $A_i$ and $A_j$ is represented by a segment connecting the corresponding vertices, with red segments representing “0-elements” and blue “1-elements”; the set $B$ is in one-to-one correspondence with the set of all these segments. It would be useful to follow our reasoning on this graph.

V. V. Vavilov

ANSWER: 92.

Let us prove by indication of the number $k$ characters in double notation $a_1 a_2 \dots a_{k-1} a_k$ ($a_1=1$) of the number $m$ that
$$f(m) = a_k a_{k-1} \dots a_2 a_1.$$

For $k=1$ we have $f(1)=1$; for $k=2$ we have
$$f(\bar{10}) = f(2) = f(1) = 1 = \bar{01},$$
$$f(\bar{11}) = f(3) = 3 = \bar{11}.$$

Let us now prove our statement for the $k$-digit ($k>2$) number $m$ in the double system, assuming that it is true for all numbers with fewer digits. Distance three possible cases.

1) $m$ is even: $m=2n = a_1 \dots a_{k-1} 0$. Then $n = a_1 \dots a_{k-1}$ and
$$f(m) = f(n) = a_{k-1} \dots a_1 = 0 a_{k-1} \dots a_1.$$

2) $m=4n+1 = a_1 \dots a_{k-2} 01$. Then $n = a_1 \dots a_{k-2} 2n+1 = a_1 \dots a_{k-2} 1$ and
$$f(m) = 2f(2n+1) - f(n) = f(2n+1) + (f(2n+1) - f(n)) = 1 a_{k-2} \dots a_1 + (1 a_{k-2} \dots a_1 - a_{k-2} \dots a_1) = 10 a_{k-2} \dots a_1.$$
3) $m=4n+3 = a_1 \dots a_{k-2} 11$. Then $n = a_1 \dots a_{k-2}$ and
$$f(m) = 3f(2n+1) - 2f(n) = f(2n+1) + 2(f(2n+1) - f(n)) = 1 a_{k-2} \dots a_1 + 2(1 a_{k-2} \dots a_1 - a_{k-2} \dots a_1) = 11 a_{k-2} \dots a_1.$$

In all cases, formula (*) is correct; thus it is proven for all $m$.
