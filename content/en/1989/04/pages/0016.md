Reidemeistr's theorem adapts the difficult spatial problem of equivalence of two nodes to the simpler “flat” problem of transforming one node diagram into another using three well-known operations $\Omega_1^{\pm}, \Omega_2^{\pm}, \Omega_3$ (see Fig. 4). We will not carry out a rather interesting proof of this theorem* here.

Exercises
2. Unravel the knot $Y_1$, use only the operations $\Omega_1^{+}$ and $\Omega_2^{+}$.
3. Show that operations $\Omega_1^{+}$ and $\Omega_2^{+}$ cannot be applied to node $Y_2$.

A successful solution to exercises 2 and 3 will always solve the unraveling problem. Using only the Reidemeister operation $\Omega_1^{+}, \Omega_2^{+}$, which reduces the number of double points, we will systematically stitch the diagram until the knot is unraveled. If the operations are not applicable, the knot cannot be untangled.

Alas! This idea is flawed:

Exercise 4: Show that the operations $\Omega_1^{+}, \Omega_2^{+}$ are not applied to the (trivial!) node $Y_4$.

We've reached a dead end. To untangle a knot, sometimes it is necessary to first increase the number of double points, and only then untangle the knot diagram. And the trouble is that it is not known in advance how much this number needs to be increased - there is no algorithm here. After all, a systematic attempt to untangle the knot using the Reidemeister operation that did not lead to success does not prove anything: perhaps the knot could not be untangled not because it is non-trivial, but because we did not increase the number of double points enough.

Our naive geometric approach ended in complete failure. After all, at the moment we do not have proof of a single node that is non-trivial! Maybe all the knots are unraveling? We need other ideas.

Anti-unraveling invariant

What does it mean? It is necessary to associate with each knot diagram some algebraic object - an invariant - so that the diagrams of equivalent knots are given the same invariants. Then, if the invariants of the nodes are different, these nodes cannot be equivalent. If a node has an invariant that is not equal to the invariant of a trivial node, the node cannot be trivial.
