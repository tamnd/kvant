Any natural number $n$ sum
$$|\cos x| + |\cos 2x| + \dots + |\cos 2^n x|$$
b) not less than $\frac{n}{4}$;
c) not less than $\frac{n}{2}$.

$$y(t) = t + (1 - \sqrt{2} t) (1 + \sqrt{2} t) \geq t + (1 - \sqrt{2} t) = 1 - t(\sqrt{2} - 1) \geq 1 - \frac{1}{\sqrt{2}} (\sqrt{2} - 1) = \frac{1}{2}.$$

If $\frac{1}{\sqrt{2}} < t \leq 1$, then $y(t) \geq t \geq \frac{1}{\sqrt{2}}$. Thus, $y(t) \geq \frac{1}{\sqrt{2}}$ for all $t \in [0; 1]$. But at $t = \frac{1}{\sqrt{2}}$ (that is, $x = \frac{\pi}{4}$) $y(t) = \frac{1}{\sqrt{2}}$. This means that the smallest value of the expression $|\cos x| + |\cos 2x|$ is $\frac{1}{\sqrt{2}}$.

The same result could be arrived at by noticing that the graph of the function $y(t)$ on the interval [0; 1] consists of two pieces of parabolas:

$$y(t) = \begin{cases} -2t^2 + t + 1 & \text{при } t \in \left[0; \frac{1}{\sqrt{2}}\right], \\ 2t^2 + t - 1 & \text{при } t \in \left[\frac{1}{\sqrt{2}}; 1\right], \end{cases}$$

and then carefully examining at least each of the pieces (see figure).

Similarly, we can prove the simpler inequality
$$2|\cos x| + |\cos 2x| \geq 1$$
and even combine it with inequality
$$|\cos x| + |\cos 2x| \geq \frac{1}{\sqrt{2}}$$

in one:

$$a|\cos x| + |\cos 2x| \geq \min\{1, \frac{a}{\sqrt{2}}\},$$

valid for all real numbers $a \geq 0$ and $x$ (check this for yourself).

b) Let us denote the amount
$$|\cos x| + |\cos 2x| + |\cos 4x| + \dots + |\cos 2^n x|$$

via $\sigma_n(x)$. Let's put $f(x) = |\cos x| + |\cos 2x|$. By what was proven in point a) $f(x) \geq \frac{1}{\sqrt{2}}$, so

$$\sigma_n(x) = f(x) + f(4x) + f(16x) + \dots + f(2^n \left[\frac{n-1}{2}\right] x) \geq \frac{1}{\sqrt{2}} + \dots + \frac{1}{\sqrt{2}} = \left(\left[\frac{n-1}{2}\right] + 1\right) \frac{1}{\sqrt{2}} \geq \frac{n}{2\sqrt{2}} > \frac{n}{4}.$$

c) Let us first prove that if $|\cos x| \leq \frac{1}{2}$, then $|\cos x| + |\cos 2x| \geq 1$. Indeed, if $t = |\cos x| \leq \frac{1}{2}$, then $\cos 2x = 2t^2 - 1 \leq 2 \cdot \left(\frac{1}{2}\right)^2 - 1 < 0$. Hence,

$$|\cos x| + |\cos 2x| = t + 1 - 2t^2 = 1 + 2t \left(\frac{1}{2} - t\right) \geq 1.$$

Let's move on to task c). Let us fix $x$ and $n$ and call the integer $k \in [0; n]$ “bad” if $|\cos 2^k x| < \frac{1}{2}$ and “good” if $|\cos 2^k x| \geq \frac{1}{2}$.
