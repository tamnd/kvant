M590. a) Find the smallest value of the expression $|\cos x| + |\cos 2x|$. Prove that for any number $x$ and $60^\circ$. But then, obviously, the length of the difference between these two vectors will not exceed 1 (Fig. 1).

The statement of the problem is now proved as follows. Let $n > 1$ and $a_n$ be the smallest number that has the following property: for any vectors $\vec{a}_1, \dots, \vec{a}_n$ on the plane such that $|\vec{a}_1| \leq 1$, ..., $|\vec{a}_n| \leq 1$, in the sum $x = \pm a_1 \pm \dots \pm a_n$ we can choose signs such that $|\vec{x}| \leq a_n$. We need to check that $a_n \leq \sqrt{2}$. The lemma shows that if $n > 3$ then $a_n = a_{n-1}$. Therefore $a_n = a_2$. But obviously $a_2 = \sqrt{2}$ (Fig. 2), which completes the proof.

It is curious that the proven result (with a slightly worse constant) is also valid for the “non-Euclidean” method of measuring the length of vectors, in which the role of the unit circle is played by an arbitrary convex bounded centrally symmetrical figure $\Phi$ on the plane. This method is very popular in modern mathematics and consists of the following.

To change the length $\vec{a}$, we disconnect this vector from the center of symmetry $O$ of the figure $\Phi$ - let $\vec{a} = OA$ - and find the smallest number $\lambda > 0$ such that $A \in \lambda \Phi$ (λФ is the image of the figure $\Phi$ when tometing with the center $O$ and the coefficient $\lambda$ - see figure 3; we assume that Φ contains its own boundary and that the point $O$ lies inside $\Phi$). This number is $\lambda$ and is taken to be the “generalized length” $|\vec{a}|_\Phi$ of the vector $\vec{a}$. It is clear that if $\Phi$ is a circle of radius 1, then $|\vec{a}|_\Phi = |\vec{a}|$ and so is $|OA|_\Phi < 1 \iff A \in \Phi$. In wave-speak, we change the lengths of the vectors by choosing different scales in different directions. It is easy to verify that the entered number $|\vec{a}|_\Phi$ has the general properties of length; in particular, the inequality $|\vec{a} + \vec{b}|_\Phi < |\vec{a}|_\Phi + |\vec{b}|_\Phi$ is valid (Check! Here you need the convexity of the figure $\Phi$).

An analogue of the statement proved above looks like this. If $|\vec{a}_1|_\Phi \leq 1$, ..., $|\vec{a}_n|_\Phi \leq 1$, then in the sum $\vec{x} = \pm a_1 \pm a_2 \pm \dots \pm a_n$ we can choose signs such that $|\vec{x}|_\Phi \leq 2$.

The proof follows the same scheme; Only the proof of the lemma requires new reasoning, since we cannot now assert that if $|\vec{a}|_\Phi, |\vec{b}|_\Phi \leq 1$ and $(a, b) \leq 60^\circ$, then $|a - b|_\Phi \leq 1$.

So let $|\vec{a}|_\Phi, |\vec{b}|_\Phi, |c|_\Phi \leq 1$. This means that points $A, B, C$ such that $OA = \vec{a}, OB = \vec{b}, OC = \vec{c}$ belong to $\Phi$.

Let $OD = a + b$. It is clear that, considering the possibility of the point $C$, we can restrict ourselves to the case where $C$ belongs to the angle $BOD$. If $C$ is in the triangle $OBD$, then $P_-b$ (C) lies in the triangle $AOB'$ (here $P_-b$ is a parallel translation to the vector $-b$). Therefore, $P_-b$ (C) ∈ Ф, so in this case $|c - b|_\Phi \leq 1$. We divide the remaining part of the angle $BOD$ into zones I and II, as shown in figure 4. If the point $C$ lies in zone I, then the point $D$ belongs to the triangle $ABC$, lying in Ф, and therefore $|\vec{a} + \vec{b}|_\Phi \leq 1$, and if $C$ is in zone II, then, obviously, the point $P_-b$ (C) belongs to the convex quadrilateral $OACB$ lying in the figure $\Phi$, and we again get that $|c - b|_\Phi \leq 1$.

Now introducing the numbers $a_n = a_n(\Phi)$ as above, we again see that $a_n(\Phi) = a_2(\Phi)$ at $n > 2$. But $a_2(\Phi) \leq 2$, or $|a_1 + a_2|_\Phi \leq |a_1|_\Phi + |a_2|_\Phi \leq 2$, and therefore $a_n(\Phi) \leq 2$, which is what was required.
