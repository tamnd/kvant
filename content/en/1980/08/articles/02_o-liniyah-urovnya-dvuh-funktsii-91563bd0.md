This figure, sketched by Vasiliev, Kormilchenko and Romanov, a boarding school student at Moscow State University, depicts a level line of two functions. For functions $f$ taking real values ​​at points $(x; y)$ of the plane, the level line $k$ is the set $\{(x, y)|f(x, y) = k\}$. If the number $f(x; y)$ is taken to be the height above sea level (plane $Oxy$) at point $(x, y)$, these lines can be understood as ordinary geographic level lines. However, we did not dare to write down “real” expressions for using the “complex” functions arg $e^{z-3}$ (green level lines) and $|e^{z-3}|$ (red) - writing them in “real” column notation, which will only spoil the typing of the red geometric pattern.
