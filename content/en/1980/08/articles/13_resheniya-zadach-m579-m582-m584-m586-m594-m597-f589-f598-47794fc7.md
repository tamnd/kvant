M579. Prove that for any numbers $x_1, x_2, \dots, x_n$ belonging to the interval [0; 1], the inequality holds
$$x_1 + x_2 + \dots + x_n + 1)^2 \geqslant 4(x_1^2 + x_2^2 + \dots + x_n^2).$$

First decision. With respect to $x_n$ this inequality is quadratic, $P_2(x) = 3x_n^2 + Ax_n + B \leqslant 0$, and it holds on the interval [0; 1], if $P_2(0) \leqslant 0$ and $P_2(1) \leqslant 0$. These two inequalities with respect to $x_{n-1}$ are also square, of the same form, and are valid on the entire interval [0; 1], if valid for $x_{n-1} = 0$ and $x_{n-1} = 1$. Arguing this way further, we find that it is enough to check the original inequality for the sets $x_1, \dots, x_n$ of 0 and 1. If the number of $x_i$ equal to one is equal to $k$, then we obtain the obvious inequality $(k+1)^2 \geqslant 4k$ (that is, $(k-1)^2 \geqslant 0)$.

Second solution. Since the numbers $x_1, x_2, \dots, x_n$ belong to the interval [0; 1],
$$4(x_1^2 + x_2^2 + \dots + x_n^2) \leqslant 4(x_1 + \dots + x_n),$$
and our inequality coincides again to the next
$$4S \leqslant (S+1)^2.$$

M580. In parliament, each member has no more than three enemies. Prove that parliament can be divided into two chambers so that each parliamentarian in the same chamber with him will have no more than one enemy. (It is considered that if $A$ is the enemy of $B$, then $B$ is the enemy of $A$)

Let's carry out the partition in an arbitrary way. If in any of the chambers some parlamentaria $A$ has $\geqslant 2$ enemies, then the number of his enemies in the other chamber is $\leqslant 1$. Therefore, after moving $A$ to another chamber, the total number of pairs of enemies inside the chambers will decrease. We will continue such movements until the required condition is met.

a) For the number $n^3$ to end up at 7, the number $n$ itself must end up at 3, so if the desired three-digit number $n$ exists, then $n = ab^3 = 100a + 10b + 3 = 10(10a + b) + 3$. Then $n^3 = 10^3 \cdot A + 10^2(7a + 2b + 9b^2) + 10(7b + 2) + 7$.

The number $7b + 2$ turned to 7 if and only if $7b$ turned to 5, that is, when $b = 5$. Then $n^3 = 10^3 \cdot A + 10^2(7a + 8) + 77$.

The number $7a + 8$ turned to 7 if and only if $a = 7$.

Thus, $753^3$ turned out to be (at least) three sevens.

6) No, not for everyone. If the number $n^3$ turned to 5, then the number $n$ itself turned to 5. But the number $(10a + 5)^3$ turned to 25 if $a$ was even, and to 75 if $a$ was odd. Therefore, for each $n$ the number $n^3$ ended up being 05, 15, 35, 45, 55, 65, 85, 95.

But the number $a$ is divisible by 8 if and only if the number formed by its last digits is divisible by 8. The statement of the problem is now proved as follows. It is curious that the proven result (with a slightly worse constant) is also valid for the “non-Euclidean” method of measuring the length of vectors, in which the role of the unit circle is played by an arbitrary convex bounded centrally symmetrical figure $\Phi$ on the plane. This method is very popular in modern mathematics and consists of the following.

To change the length $\vec{a}$, we disconnect this vector from the center of symmetry $O$ of the figure $\Phi$ - let $\vec{a} = OA$ - and find the smallest number $\lambda > 0$ such that $A \in \lambda \Phi$ (λФ is the image of the figure $\Phi$ when tometing with the center $O$ and the coefficient $\lambda$ - see figure 3; we assume that Φ contains its own boundary and that the point $O$ lies inside $\Phi$). It is clear that if $\Phi$ is a circle of radius 1, then $|\vec{a}|_\Phi = |\vec{a}|$ and so is $|OA|_\Phi < 1 \iff A \in \Phi$. Then, as the last circle, you need to take a circle of radius less than $R/2$, passing through the points $O$, $B$ and the last resulting point of the partition.

The required partition has been constructed.

It remains to consider the case when the arc $AB$ inside the circle touches the circle $\Gamma$. Our goal is to prove the inequality $\overrightarrow{AB} < R\alpha$.
