Modern computers are designed for multi-program operation. By analogy with a factory, we can say that several different products are manufactured simultaneously (according to different technological plans). To prevent parts for the aircraft from ending up in the workshop where children's bicycles are produced, it is necessary to organize control over the issue from the warehouse: to whom, what and when to issue. The functions of storing contents in the computer memory are performed by keys. Imagine a long warehouse corridor (memo). Each room facing the corridor has its own lock, and therefore its own key. Each computer has its own concept of a “room” - its own standard size of a protected memory block. In the EU computer, such a “room” is a memory capacity of 2.KB. Each memory access, in addition to the address, also contains a key. This allows different programs to coexist peacefully in memory without interfering with each other.

Memory is the most expensive part of a computer. Its characteristics determine the performance of the entire machine. It is not difficult to understand that the problem will be solved quickly if the program for solving it and all the necessary data are in RAM, and the most used information is in the super-RAM, rather than in the case when the program or data is located on external memory (disk, drum, tape recorder). If the computer solves several problems at once (multi-program mode), then there is not enough RAM and extra-RAM. Attempts to increase the efficiency of computers through more complete use of all the capabilities of non-Rahvoch memory systems led to an interesting organization called virtual (apparent) memory.

The essence of this organization is that the programmer works as if with direct access memory (for example, RAM), and at the time the program is executed, all computer memory devices are working (if, of course, the program is large enough). High efficiency is achieved due to the fact that the main memory stores a “general plan” of memory - something like a geographical map. The program that manages the solution of problems in a computer (it is called an operating system) uses this plan, delivering information at the moment when it is required to solve a specific problem (or a little later). Virtual memory is a complex mixture of software and electronic hardware.
