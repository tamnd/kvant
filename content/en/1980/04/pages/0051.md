3. Answer. The function $f(x) = x^3 - 2x \cdot |x| - 2$ ($x \in [0; 3]$) has one minimum point $x = \frac{2}{3}$, its maximum value is at [0; 3] is equal to 21 ($\max f(x) = f(3) = 21$). Solution. According to the conditions, the domain of definition of the function $f$ under study is the segment [0; 3]. By definition of the model

$$f(x) = \begin{cases} x^3 + 2x^2 - 4x, & \text{ если } 0 \leq x \leq 2, \\ x^3 - 2x^2 + 4x, & \text{ если } 2 < x \leq 3. \end{cases}$$

Means,

$$f'(x) = \begin{cases} 3x^2 + 4x - 4, & \text{ если } 0 < x < 2, \\ 3x^2 - 4x + 4, & \text{ если } 2 < x < 3. \end{cases}$$

On ]0; 2[ function $f$ has one critical point $x = \frac{2}{3}$, and $f'(x) < 0$ on ]0; $\frac{2}{3}$ [, $f'(\frac{2}{3}) = 0$ and $f'(x) > 0$ on ]2; $\frac{2}{3}$[. This means that $x = \frac{2}{3}$ is the minimum point.

On ]2; 3[ $f'(x) > 0$. So, on ]2; 3[function $f$ has no critical points.

Let us now consider the point $x = 2$. This point cannot be a minimum point, since in any neighborhood of point 2 the function $f$ belongs to a value less than $f(2)$; indeed, for $0 \leq x \leq 2$ the function $f$ coincides with the polynomial $f_1(x) = x^3 + 2x^2 - 4x$, which is on ]2; $+\infty$ [ returns.
