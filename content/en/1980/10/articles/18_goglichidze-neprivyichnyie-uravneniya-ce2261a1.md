Unusual equations

Let us define the sum of the number set $A$ with the number $b$ as a set of numbers of the form $a + b$, where $a \in A$. The sets $A - b$, $A \cdot b$, $A:b$ are defined similarly. For example:

$$\{1, 5, 10\} + 3 = \{4, 8, 13\},$$

$$\{2, 4, 6, 8, 10, \dots\}: 2 = \{1, 2, 3, 4, 5, \dots\}.$$

Now we can write “equations with a set,” equations in which the “sought” values ​​of a variable are numerical sets. For example, it is easy to see that a set of numbers is the root of the equation

$$X + 2 = X,$$

(1)

and the set of numbers $2^p(p \in \mathbb{Z})$ is the root of the equation

$$X \cdot 2 = X.$$

By the way, each of these “equations of the first degree with one variable” has an infinite number of roots. Equation (1) is equal to the salt of equation $X - 2 = X$, and equation (2) is equal to equation $X:2 = X$.

Let us now define the square of a number set as follows:

$$A^2 = \{a^2 | a \in A\}.$$

Now you can compose and solve “quadratic” equations. Equation

$$X^2 = X$$

again has an infinite number of roots (the set $\{..., \sqrt{2}, \sqrt{2}, 2, 4, 16, \dots\}$ is one of its roots), and the equation

$$X^2 + 1 = X$$

has no roots*). (This can be easily deduced from the fact that if $A$ is its root and $a \in A$, then $\sqrt{a-1} \in A$.) (The speaker said that she did not know at what $a, b, c$ the equation $aX^2 + c = X \cdot b$ has roots.)

H. Golitsidze

*) Except for the empty set. (Editor's note)
