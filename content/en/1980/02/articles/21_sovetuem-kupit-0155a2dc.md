4°. One of the interesting applications of computer graphics is the automation of cartoon production. It is, of course, convenient to draw books separately in a cycle. As a rule, there are several stationary objects and one or more moving objects in the frame. Each moving object can be specified by a separate procedure, the parameters of which determine its size and position in the frame.

Let's give a very simple example: you need to depict a moving truck against the background of a stationary tree.

The program for such a mini-cartoon was compiled by second classicist V. Fishchev:

PERC MACHINE X Y; P(X,U);
L(X,Y+15); L(X+15,Y+15);
L(X+15,Y+25); L(X+30,Y+25);
L(X+30,U+15); L(X+35,U+15);
L(X+35,Y+20); L(X+70,Y+20);

Task 6.1. Create a program to fill a 100 by 100 mm frame with a rectangular grid with a step of 2 mm along the abscissa axis and 5 mm along the ordinate axis.

Task 6.2. Write a program to print a table of expression values

$$\frac{X(X^2+1)+(X+2)(X^2-1)^2}{(X^3+4)^2}$$

for natural X from 1 to 25.

Task 6.3. Create a program for drawing a cartoon depicting two planes burning out each other.

G. Zvenitsgorodsky
