Are there any contradictions?
We introduced into the machine everything that we ourselves, created it, know about elementary arithmetic. The internal workings of a machine are elementary arithmetic. The theory of such a machine, its design, its structure properties is part of another discipline, often called *metamathematics* (or, in our case, metaarimetic). The following question is a typical question asked in metamathematics: "Will a machine ever print both the proposition $P$ and its negation $\neg P$?" If she had ever done this, we would, we believe, express our dissatisfaction with this state of affairs, saying that elementary arithmetic is contradictory. Fortunately, this is not the case: arithmetic is not inconsistent. The proof of this depends on a very refined, not elementary, study of the machine we have described. Learning is “non-elemental” in several senses of the word. In the most technical sense, the point is that proving that a machine is consistent is not one of the theorems that the machine itself can prove. Let's repeat this differently: the machine will not contradict itself, but it cannot prove it.

Can everything be proven?

Another interesting question in metamathematics is this: “Is a machine complete in the sense that it either proves or verifies every proposition of elementary arithmetic?” In fact, I have already given an answer to this question, but it is still worth repeating. Given the current situation, in each, everything that the machine writes, it proves. If I am interested in a particular arithmetic sentence, I can write this sentence on a piece of paper and then, after turning on the machine, compare all subsequent text printed by the machine using the prepared form. If the paper states $P$ and if at some stage the machine also prints $P$, then I retire victorious; my statement $P$ is proven. If the paper says $P$, but at some stage the machine prints $\neg P$, then I walk away victorious: my $P$ has been refuted. However, isn't there a third possibility here? Could it be that the machine cannot write $P$, and also cannot write $\neg P$? Could it be that the machine will never resolve the dispute between $P$ and $\neg P$?
