Mechanical mathematician

Let us now proceed to create the mechanical mathematician who will end all mathematicians. The merits of this imaginary machine are purely speculative; we do not claim that the creation of a mechanical mathematician will bring any practical benefit. He will never be able to replace a living mathematician.

Let's start building the car. To do this, we will need a ribbon for typing machines, a keypad (each one contains one of the main symbols) and a potentially infinitely long roll of printing paper. The idea behind the machine is that once the start button is pressed, the machine should print everything it can ever print. One way to program this is to arrange the genie of characters in a random order (call it alphabetical) and then instruct the machine to print the first twelve characters (“letters”) of the alphabet, then print 144 “words” of two letters, then 1728 “words” of three letters, etc. ad infinitum. A machine designed this way will print a lot of nonsense, such as:
