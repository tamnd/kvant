Let's program the procedure

Above I said that no one can prove something from nothing, for this reason I gave the mechanical mathematician some initial proposals. But it is also true that no one can prove anything by printing sentences in black and red, and if the axums were chosen according to the wishes of an intelligent being, then the sentences printed in red (the axums) will be true. However, the machine can print a lot of false things, and it still has no means of creating new correct sentences from old ones.

Now the machine learning process is available. At this stage, the machine must learn to recognize certain combinations of sentences and is rewarded for this by being allowed to use more red printing ink. The general list of such rules of procedure is not long; the list of two examples of such rules that I am about to give is even shorter. Possible rule number 1: if $P$ is a red sentence and if $P \Rightarrow Q$ is a red sentence, then stamp $Q$ in red. (Explanation: If "The sun is shining" is an axiom or has already been proven, just like the statement "If the sun is shining, then the weather is calf", then we can take it as proven that "The weather is calf".) (Explanation: If we put 0 together $X$ into $(1+X)=1$, we get $(1+0=1)$. If this sentence is an axiom or has already been proven, then we can consider $(1+X=1$ proven for some $X$).)
