If the action of one cycle ends before the start of another, such two cycles are called independent.

You can use the same names for variables in two independent loops. This even leads to some savings in memory space. Otherwise, it is not recommended to strive for such savings, since it becomes more difficult to read a program with synonymous names: having encountered such a name, you have to think about which of the variables it denotes. In (4), two different counters are called by the same name. Using the same name for the X and Y variables seems less obvious.
