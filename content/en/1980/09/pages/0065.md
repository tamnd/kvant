1. a) If $abc = (a + b + c)^3$, then $5 \leq a + b + c \leq 9$, hence $a + b + c = \{5, 6, 7, 8, 9\}$.
It is easy to report that $a + b + c$ cannot equal 5, 6 and 9 (the cubes of these numbers end in 5, 6 and 9 respectively). It remains to check the cases $a + b + c = 7$ and $a + b + c = 8$.
We have: $7^3 = 343$ - not suitable; $8^3 = 512$ - suitable. Thus, we exclude the number 512.
6) If $abcd = (a + b + c + d)^4$, then $6 \leq a + b + c + d \leq 9$, that is, $a + b + c + d = \{6, 7, 8, 9\}$.
$a + b + c + d \neq 6$ again, since $6^4$ ends in 6.
