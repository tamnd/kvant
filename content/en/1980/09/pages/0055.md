Before writing the program, we note the following:

— it is unreasonable to draw each line separately: you need to write operators for drawing one line, and then repeat them several times in a loop;

— since one ruler differs from another only in height, it makes sense to choose the y coordinate as a loop variable;

— with each repetition of the cycle, its variable changes by a constant value Δy=2.5, which is called shad;

— the first execution repeating in a cycle of operators (drawing the first blue line) is carried out at y₀=10; this means that before starting the loop, it is necessary to ensure that the value y receives an initial value of 10; assigning an initial value to a loop variable is called its initialization; repeating loop statements are called loop body;

- according to the definition of the conditions written after the word BYE («Kvant», 1980, No. 1), the cycle ends when the variable y changes during the execution of the cycle and reaches its value yₖ, which is calculated by the formula
