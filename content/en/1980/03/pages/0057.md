Problem 1. Let $A$ be a set whose elements are positive numbers.
+ a) Prove that the Rapier program
0 -> MAX;
FOR NUMBERS FROM A::
IF NUM > MAX
TO NUMBER -> MAX ALL
ALL;
PRINT(MAX);

+ 6) Write a program that prints all the numbers from the set $A$ in descending order (Fig. 1).

Problem 2. Let us assume that the program describes a function with one parameter $\Phi_1(M)$. Function values ​​can be integers from 0 to 100. Create programs to solve the following problems:
+ a) Print a table of function values ​​for integer values ​​of the parameter $M$ lying on the interval [0; 100].
6) Find and print the integer roots of the equation $\Phi_1(M) = 0$ lying on the same segment.
+ b) Construct a graph of the function using the procedures of the Spar system.
* d) Find and print the area under the graph of the function (Fig. 2).
* Problem 3. Create a program to depict a regular 16-gon, in which all diagonals are drawn that do not pass through the center (Fig. 3).
Task 4. In the memory of computers you can store newspapers and magazine articles, documents, books and other printed materials in the form of texts. Create programs to solve the following problems:
+ a) Count how many times the letters 'A' and 'O' appear in the text named BREAK.
+ b) Count how many times the word 'BLUE-EYED' appears in the text with the name UNZNAYKA.
* b) Everywhere in the text with the name ORDER, replace the words 'CAPTAIN IVANOV' with 'MAJOR IVANOV'.

* d) Split the text with the name CHA-PAEV into lines of 60 characters and make a tuple from them. If any word falls on the line boundary, then it must be “moved” to the beginning of the next line, adding the required number of spaces to the text.
**e) Under the conditions of the previous automatic “stretching” of lines: if there are spaces at the end of the line, then they must be eliminated by increasing the intervals between words within the line (as evenly as possible).
Problem 6. An interplanetary station moves parallel to the OX axis in a certain coordinate plane OXY with a constant speed V. A transport ship with a constant speed V1, which at each moment of time is directed towards the station (Fig. 4), is sent to it in automatic mode.
