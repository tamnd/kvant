OLYMPICS

5. See problem 5 for 9th grade. 6. Are there non-zero numbers a, b, c such that for any n > 3 one can find a polynomial of the form $P_{n} ( x ) = x^{n} + K K + ax^{2} + bx + c$ having exactly n (not necessarily different) integer roots? N. Agakhanov, I. Bogdanov

7. Given a triangular pyramid. Lesha wants to select two of its intersecting edges and build balls on them, as on diameters. Can he always choose a pair such that any point of the pyramid lies in at least one of these balls? A. Zaslavsky

8. There are N cities in the country. Some pairs of them are connected by non-stop two-way airlines. It turned out that for any $k ( 2^{£} k^{£} N )$ and any choice of k cities, the number of airlines between these cities will not exceed 2k – 2. Prove that all airlines can be distributed between two airlines so that there is no closed air route in which all airlines belong to one company. I. Bogdanov, G. Chelnokov
