M2581. In a social network with a fixed finite number of users, each user has a fixed set of subscribers among other users. In addition, each user has some initial rating - a positive integer (not necessarily the same for all users). Every midnight, each user's rating increases by the sum of the ratings that their followers had immediately before midnight. Let m be some natural number. A hacker who is not a network user wants the ratings of all users to be divisible by m. Once a day, he can either select a certain user and increase his rating by 1, or do nothing. Prove that in a few days the hacker will be able to achieve his goal.

Let n be the number of people in the social network. We will only monitor the remainder of the ratings after dividing by m. The hacker's goal is to make all n remainders equal to 0. If the hacker were allowed to change the rating more than once a day, then he could achieve his goal on the first day. Indeed, he could first add the rating of the first user several times so that it becomes equal to 0 modulo m, then do the same for the second, etc. On other days, the hacker can do nothing, and the ratings of all users

Let us now prove that a hacker can make the same changes in ratings, but on different days, so that after some time the ratings of all users become equal to 0. We will represent the states of the social network using lines consisting of n remainders modulo m (corresponding to user ratings). Such strings can be added modulo m. For example, if m = 4 and n = 6, then

( 1,2,3,0,2,1 ) + ( 2,3,2,0,2,3 ) = ( 3,1,2,0,0,0 ).

If there was a string X just before midnight, let f(X) denote the string of states after midnight. Lemma. The function f is additive, i.e.

f ( X + Y ) = f ( X ) + f ( Y ).

Proof of the lemma. We need to show that the strings f ( X + Y ) and f ( X ) + f ( Y ) coincide at every position, i.e. for each user. Consider an arbitrary user, let's say his name is Bob. Let in arrangement X Bob have a remaining rating of $b_{x}$, and his subscribers have a total of $s_{x}$ (the sum is taken modulo m). Let Bob have a rating of $b_{y}$ in arrangement Y, and a total of $s_{y}$ for his subscribers. Then Bob will have $b_{x} + s_{x}$ in f(X), $b_{y} + s_{y}$ in f(Y), and $b_{x} + b_{y} + s_{x} + s_{y}$ in f(X + Y). The lemma is proven.
