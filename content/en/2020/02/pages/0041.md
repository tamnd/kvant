Prove that it is possible to draw a diameter through one of these points so that there are equal points on both sides of the diameter. Solution. Let's draw the diameter of the circle through an arbitrary marked point and color one of the halves of the circle blue and the other red. If there are equal numbers of points in the halves, then the required diameter has been found. Otherwise, we define the sequence as follows: $a_{1}$ is equal to the difference between the number of marked points in the blue part and the red part for a given diameter position. We will gradually rotate the diameter around the center of the circle (the colored halves of the circle rotate with it) and each time a marked point leaves the diameter or falls on it, we write a new element of the sequence (which is also equal to the difference between the number of marked points in the blue part and the red part). The last element of the sequence corresponds to the position of the diameter when it again passes through the first marked point. In this position, the diameter rotates 180°, and the blue and red halves change places. Consequently, the last element of the sequence is opposite to the first, i.e. one of them is positive, and the second is negative. Since any two adjacent elements of a sequence differ by 1, by the discrete intermediate value theorem there is an element of the sequence equal to zero. It remains to note that this element of the sequence corresponds to the position of the diameter passing through one of the marked points, since the total number of points is odd.
