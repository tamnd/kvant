So, for polygons with an even number of sides, there is a series of examples. It remains to understand for what odd n there exist suitable n-gons. Let us consider the smallest n among all such n, let us denote it M. Then for all odd n greater than M, a suitable example can be obtained by repeating the “restructuring” the required number of times (you will also need to make sure that there is at least one small angle in the original example so that the “restructuring” can be carried out). It remains to find M. There is an inaccuracy hidden in the above reasoning: such a smallest n may not exist - if there are no suitable examples for odd n at all. But now we will give such an example.

First estimate Some example has been obtained, now let's get some estimate for the number of sides of a suitable polygon. We will consider directions again, but differently. Let's start walking around the border of the polygon counterclockwise and watch how the direction in which we move changes. Since in a suitable polygon each angle is either small or large, then when we move to the next side, the direction in which we are moving changes to almost the opposite. There are no difficulties with the example for even n - when going around, the direction changes almost the opposite even number of times and becomes the original one. In the case of odd n, we will need to estimate the possible contribution of these “almosts”. We can assume that the directions correspond to rays emanating from one point.
