Quests for the second day of perfection

4. Consider partitions of the chessboard $8 \times 8$ into $p$ mutually disjoint rectangles satisfying the following conditions:

1) each rectangle consists of a certain number of cells and contains as many white cells as black ones;
2) if $a_i$ is the number of white cells in the $i$-th rectangle, then $a_1 < a_2 < \dots < a_p$.

Find the maximum value $p$ for which such a partition is possible, and determine for this value $p$ all sequences $a_1, a_2, \dots, a_p$ for which such a partition can be realized (Bulgaria; 6 points).

5. Find set of sum values

$$S = \frac{a}{a+b+d} + \frac{b}{a+b+c} + \frac{c}{b+c+d} + \frac{d}{a+c+d},$$

where $a, b, c, d$ are arbitrary positive real numbers (Netherlands; 7 points).

6. Let $P$ be a polynomial with non-constant integer coefficients, and let $n(P)$ be the number of all distinct integers $k$ for which $[P(k)]^2 = 1$. Prove that

$$n(P) - \deg(P) \leq 2,$$

where $\deg(P)$ denotes the degree of the polynomial $P$ (Sweden; 8 points).
