M1050. On the segment $[-1; 1]$ $k$ different points were selected, for each one the product of the distances to the remaining $k-1$ points and through $S$ denoting the sum of the reciprocals of these $k$ products. Prove that a) $S \geqslant 2$ for $k=3; 6)$* $S \geqslant 4$ for $k=4$.

Puc. 2.

a) It is clear that each of the three products will only increase (and the sum $S$ of their inverses will decrease) if the extreme numbers are expanded: the left one is replaced by -1, the right one by 1. Therefore, we can assume that the points -1, $x, 1$, where $-1 < x < 1$, have been chosen. In this case

$$S = \frac{1}{2(1+x)} + \frac{1}{(1+x)(1-x)} + \frac{1}{2(1-x)} = \frac{2}{1-x^2} \geqslant 2,$$

Moreover, equality is achieved only at $x=0$.

6) Similar to point a), the problem for four points can be solved using the “gradual improvement” method. As above, by replacing the extreme numbers with -1 and 1, we can only decrease $S$. We represent the midpoints as $-1+u$ and $1-v$ ($u>0, v>0, -1+u<1-v$; Fig. 1).

Now we transform the sum $S$, assuming $d=2-u-v$:

$$S = \frac{1}{2u(u+d)} + \frac{1}{2v(v+d)} + \frac{1}{2u(v+d)} + \frac{1}{2v(v+d)} =$$

$$= \frac{d(v(2-u)+u(2-v))+2(2uv+d(u+v))}{2duv(2-u)(2-v)} =$$

$$= \frac{d(2(2-d)-2uv)+2(2uv+d(2-d))}{2duv(4-2(u+v)+uv)} =$$

$$= \frac{2d(2-d)+uv(2-d)}{2duv(2d+uv)} = \frac{2-d}{duv}.$$

The product $uv$ for a given sum $u+v=2-d$ is maximum when $u=v=(2-d)/2$, so

$$S \geqslant \frac{4}{d(2-d)} \geqslant 4,$$

Moreover, equality is achieved at $d=1, u=v=1/2$, i.e. for point -1, $-1/2, 1/2, 1$.

It turns out that for every $k \geqslant 3$ the smallest value of $S$ is $2^{k-2}$ and is achieved for the set $x_n = -\cos \frac{n\pi}{k-1}, n=0, 1, \dots, k-1$. Let us indicate a beautiful reasoning, which (unlike the direct calculations given above) is suitable for the general case.

Using the same principle $\cos(m+1)\varphi = 2(\cos m\varphi)\cos \varphi - \cos(m-1)\varphi$, it is easy to prove that for any $m \geqslant 1$ there is a polynomial $T_m(x)$ such that $T_m(\cos \varphi) = \cos m\varphi$, and its leading coefficient is $2^{m-1}$.
