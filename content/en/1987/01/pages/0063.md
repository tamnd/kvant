Theoretical tour
Problem 1
1) The path difference between the two waves emerging from the slits $L$ and $M$ is equal to $d \sin \theta$, therefore the phase difference is $\Delta \varphi = (2\pi d \sin \theta)/\lambda$. Adding up the oscillations, we get
$y = a \cos (2\pi vt - 2\pi x/\lambda) + a \cos (2\pi vt - 2\pi x/\lambda + \Delta \varphi) = 2a \cos (\Delta \varphi/2) \cos (2\pi vt - 2\pi x/\lambda + \Delta \varphi/2)$.
If we denote $\Delta \varphi/2 = \beta$, then the resulting amplitude is $A = 2a \cos \beta$. The vector diagram is shown in figure 4.
2) Let's add up the vibrations from $N$ slits using a vector diagram (Fig. 5). All sides of the resulting polygon are equal to $a$, the angles between the sides are equal to $(\pi - 2\beta)$, therefore, a circle with a radius of $R$ can be described around the polygon. It is not difficult to show geometrically that
$R = a/(2 \sin \beta)$ and $A = a (\sin N \beta/\sin \beta)$.
The phase difference between the original and resulting waves is determined by the angle $\alpha$:
$\alpha = (\pi/2 - \beta) - (\pi/2 - N \beta) = (N - 1) \beta$.
3) Let us plot sin $N \beta$ and 1/sin $\beta$ as a function of $\beta$ on the same scale at $N = 8$ (Fig. 6). Considering that the intensity of the wave is proportional to the square of the amplitude, we will construct a graph $I = I_0 \sin^2 N \beta/\sin^2 \beta$ ($I_0$ is the intensity of change from one cell) for $N = 8$ (Fig. 7).
4) At the main maxima, the vector diagram is a rectangle. Moreover, $2\beta = 2\pi n$, where $n = 0, \pm 1, \pm 2, \dots$. The application of the resulting wave is $Na$, and the intensity is $I = N^2 I_0$.
5) Condition for main maxima:
$\beta = \pi n$, or $(\pi d \sin \theta)/\lambda = \pi n$,
where $n = 0, \pm 1, \pm 2, \dots$. Since $|\sin \theta| \leq 1$, the number of main maxima does not exceed $2d/\lambda + 1$.
6) Differentiating the conditions of the main maxima with respect to $\theta$, we obtain
$\lambda'(\theta) = (d \cos \theta)/n$.
Therefore, at $\Delta \lambda \ll \lambda$
$\Delta \lambda = (d \cos \theta) / n$,
$\theta = n \sqrt{1 + (\sqrt{1 - \lambda^2})^2}$.
