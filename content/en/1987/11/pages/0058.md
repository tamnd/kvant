I All-Union Olympiad for schoolchildren in computer science

(For the beginning, see p. 30)

I International Programming Olympiad

Braticheska, August 23-30, 1987

1st round

Problem 1 (USSR). For natural numbers X and Y, we will say that X is included in Y if the double entry X can be obtained from the double entry Y by crossing out zero, one, or a large number of digits. (For example: X=1010 is included in Y=1001100). Construct an algorithm that, given two natural numbers A and B, will find the maximum number C that appears in both A and B.

Problem 2 (Czechoslovakia). Given n cards, numbered 1, 2, 3, ..., n (each number appears only once). Construct an algorithm that, for an arbitrary sequence A₁, A₂, A₃, ..., Aₙ of these cards, will find the greatest number of permutations necessary to arrange the cards in ascending order of their numbers. By permutation we mean a unit volume of interchanging any two cards. Example: For the sequence 1, 5, 3, 2, 4, two permutations are needed: No. 5 and No. 2, and then No. 4 and No. 5, after which the ordered sequence 1, 2, 3, 4, 5 is obtained.

2 round

Problem 3 (NRV). Construct an algorithm that distributes the first N² natural numbers (N>2) in an N group so that the following three conditions are simultaneously satisfied:

1) each group contains exactly N numbers;
2) each number belongs to only one group;
3) the sum of the numbers in each group is the same for all groups.

Problem 4 (Czechoslovakia). Distance next game. For a given fixed natural number N>1, player A chooses a natural number X that cannot be exceeded by N. The goal of player B is to guess the number X using questions of the form “Is the number X greater than or equal to K?”, where K is some natural number. For each question, player B, player A obtues the number and does not change the number X. Player B pays player A for each answer: 2 rubles. for the answer “YES” and 1 rub. for "NO". Determine for a given N the smallest sum P(N), sufficient to guarantee the gradation of any number X from 1 to N. Construct an algorithm by which player B asks questions in such a way that he guesses the number X and at the same time burns no more than P(N) rubles (i.e., an algorithm that determines the values ​​of K in the questions asked).

R. M. Shakirov, Scientific Secretary of the section on the fundamentals of information science and computer technology of the Scientific Methodological Council under the Ministry of Education of the USSR.
