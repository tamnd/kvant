Solutions and comments to individual problems.

IX—1. In order for the correspondence between finite sets X and Y, given by means of arrows, to be a function of the domain of definition of X, it is necessary and sufficient that one and only one arrow emerges from each domain of X. This means that the number of arrows must be equal to the number of elements of the set X; in this case, when x = {x₁, x₂, x₃}, the number of arrows can be from 0 to 3 (the correspondence with 0 arrows is a function with an empty domain).

IX—3. x²−y²=0 ⇒ x−y=0 or x+y=0, so the original equation gives the circled lines y = x and y = −x.

IX—5. The value 2A can be specified with an accuracy of 0.02, and if two numbers are known with an accuracy of 0.02, then their difference can be specified with an accuracy of 0.02+0.02=0.04. (The error limits for both addition and subtraction add up.)

IX—6. A triangle with side lengths a, b and c exists if and only if the inequalities |a−b| < c < a+b.
