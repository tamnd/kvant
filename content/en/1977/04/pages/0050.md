It is clear that the inequality $f(x) > g(x)$ holds on the entire interval $[a; x_1]$.

Note that the separating constant $c_1 = f(a)$ is in some case the best: if we take $c_1$ as a constant less than $f(a)$, then the segment on which this constant “acts” can be changed.

Telegram draw the straight line $y = f(x_1)$ and get the segment $[x_1; x_2]$, on which $c_2 = f(x_1)$ is a separating constant; then we draw a straight line $y = f(x_2)$ and so on (Fig. 4). As a result, we will divide the segment $[a; b]$ into parts and for each of these parts we will obtain a separating constant, thereby validly proving the inequalities $f(x) > g(x)$ on the entire segment $[a; b]$.

The above reasoning can be formalized as follows.

We'll start at point $x_0 = a$.

If for some $k = 0, 1, \dots$ the point $x_h$ is already known, then we also find the point $x_{k+1}$, which is $g(x_{k+1}) = f(x_h)$.

By repeating this process (or, as we say in mathematics, interseid), we use $x_0$ to find $x_1$, then use $x_1$ to find $x_2$, and so on. If after several iterations we manage to get to the right end of the segment on which the functions $f(x)$, $g(x)$ are given, then the inequality $f(x) > g(x)$ will be proven.
