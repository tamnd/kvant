Example 7. The base of the parameters is a rhombus, the side length of which is $a$. It is known that the lengths of the heights dropped from the top parameters to two opposite sides of the base are equal to $h$. What is the maximum volume that a parameter maxim can have?

Let $NABCD$ be the given parameter, $[NL]$ and $[NM]$ the heights of the faces $ABN$ and $CDN$, $[NO]$ the height of the equilateral triangle $LNM$ (Fig. 2). Then $(AB)_\perp(NL)$ and $(AB)_\perp(NM)$, therefore $(AB)_\perp(LM)$ and $(AB)_\perp(NO)$. Therefore, $[LM]$ is the height of the diamond $ABCD$, and $[NO]$ is the height of the parameters.

According to the conditions $|AB| = a, |NL| = |MN| = h$. Let us put $|LM| = 2|LO| = x$, then $S_{ABCD} = ax, |NO| = \sqrt{h^2 - \frac{x^2}{4}}$, and the volume of $V$ parameters is equal to

$$V(x) = \frac{1}{6} a \sqrt{(4h^2 - x^2)x^2}.$$

Thus, the problem has been reduced to finding the most value on the segment $[0; a]$ of the function $V$, which it reaches simultaneously with the function

$$f(x) = -x^4 + 4h^2x^2.$$

Since $f'(x) = -4x^3 + 8h^2x$, then, equating the derivative to zero, we obtain the equation

$$x(x^2 - 2h^2) = 0$$

for critical points, of which we can only be interested in $x = h\sqrt{2}$.

The point $h\sqrt{2}$ belongs to the interval $[0; a]$ if and only if $a \geq h\sqrt{2}$. We will first assume that this condition is satisfied. Comparing the value of the function $f(x)$ at the found point and at the ends of the interval $[0; a]$, we conclude that the function $f(x)$ takes on its greatest value at $x = h\sqrt{2}$. Therefore, if $a \geq h\sqrt{2}$, then

$$V_{\max} = \frac{1}{6} a^2 \sqrt{4h^2 - a^2}.$$

The final answer will look like this:

$$V_{\max} = \begin{cases} \frac{1}{3} ah^2, \text{ если } a \geq h\sqrt{2}; \\ \frac{1}{6} a^2 \sqrt{4h^2 - a^2}, \text{ если } a < h\sqrt{2}. \end{cases}$$
