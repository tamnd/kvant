Memory protection
If an error is detected by the machine, the solution to the problem will stop. Thus, thanks to the presence of tags, it becomes possible to strictly control

the birth of address information and its processing. As a result, Elbrus managed to implement a new, very convenient and effective information security system.

Information security is a very important issue when operating a modern machine. Large machines simultaneously perform many tasks, but these tasks are not solved entirely simultaneously. If, for example, when solving a problem it was necessary to turn to a slow external storage device to transfer information from them to the main memory, then this relatively lengthy work is entrusted to the input process, the central processor itself switches to solving some other task. “Let’s distribute responsibilities” in this case is carried out by the operating system - a set of special programs that manage the completion of the task and organize the process of “parallel” execution of their solution.

In a multiprocessor machine, there are many processors, but there are even more tasks located in memory, so the processors take turns solving all the problems. If a bug can exist in one task that will change information in the memory cells of another task, then it is said that memory protection is violated. If this could have worked, then another problem would have been solved incorrectly. All modern machines have some form of memory protection. IN
