The resulting contradiction ($p_n$ is the simplest number and, at the same time, either $p$ or $q$ is a prime number greater than $p_n$) proves the falsity of the assumption made and, thus, the truth of the statement The greatest prime number does not exist.

Recall that the set $M$ is called a subset of the set $N$ if every element of the set $M$ belongs to the set $N$. Let us assume that the empty set $M$ is not a subset of the set $N$, that is, there is an element of the set $M$ that does not belong to $N$. But this is a very bad thing, since in the empty set, according to its definition, there are no elements at all. Therefore, the empty set is a subset of the set $N$.
