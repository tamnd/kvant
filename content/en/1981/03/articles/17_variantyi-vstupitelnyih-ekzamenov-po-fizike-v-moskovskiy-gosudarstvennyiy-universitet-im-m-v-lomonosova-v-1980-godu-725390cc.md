Analysis of problems of option 1
1. Answer. $\{-1, 2\}$.
Almost all applicants successfully completed this task. However, some wrote
$$(x^2 - 4)\sqrt{x + 1} = 0 \iff \left[\frac{x^2 - 4}{x + 1} = 0\right];$$
Moreover, even if the value $x = -2$ was not included in the final answer, the examiners could not consider the problem solved flawlessly.

2. Answer. $x_1 = \pi m, x_2 = \pm \frac{\pi}{6} + 2\pi n(m, n \in \mathbb{Z})$.

$$\sin x = 0$$

3. Answer. 3 and 5.

Solution. Let $KM$ be the midline of the trapezoid, $ABCD, LN$ be the segment connecting bases BC and AD, $BAD = 50^\circ$, $CDA = 40^\circ$. Note that $|AD| > |BC|$ since $BAD + CDA = 90^\circ < 180^\circ$ (Fig. 1). Let $Q$ be the intersection point of lines $AB$ and $DC$. Since $CB \parallel AD$, triangle $AQD$ is similar to triangle $BQC$. That's why
$$\frac{|BQ|}{|AQ|} = \frac{|BC|}{|AD|} = \frac{|BC|/2}{|AD|/2} = \frac{|BL|}{|AN|}.$$
Since $QBC = QAD$ and $\frac{|BD|}{|AQ|} = \frac{|BL|}{|AN|}$, the triangles $QBL$ and $QAN$ are similar. Therefore $BQL = AQN$ and, consequently, the points $Q, L, N$ lie on the same line. The triangle $AQD$ is a right triangle because $AQD = 180^\circ - QAD - QDA = 90^\circ$. Therefore $N$ is the center of the circle described around it; means $|QN| = \frac{|AD|}{2}$. Likewise, $|QL| = \frac{|BC|}{2}$. So,
$$\frac{|AD|}{2} - \frac{|BC|}{2} = |QN| - |QL| = |LN| = 1.$$
By the property of the midline of a trapezoid $\frac{|AD| + |BC|}{2} = |KM| = 4$.
From the system $\left\{ \begin{array}{l} |AD| - |BC| = 2, \\ |AD| + |BC| = 8 \end{array} \right.$ we find $|AD| = 5, |BC| = 3$.
Only about half of the applicants fully coped with this task. Some applicants who received the correct answer were unable to justify it. For example, without proving that the points $Q, L, N$ lie on the same line.

5. Answer. $a = 2$.

Solution. The left side of this inequality is defined at $a \in ]0; 1[ \cup ]1; +\infty[$.

Let $a > 1$ first. Taking the first logarithm to base 3 and multiplying both sides of the inequality by $\log_3 \frac{1}{a} < 0$, we obtain the equivalent inequality

$$\log_3 \left( \sqrt{x^2 + ax + 5} + 1 \right) \cdot \log_5 \left( x^2 + ax + 6 \right) \leq 1.$$

Here we used the fact that $\log_3 3 \cdot \log_3 \frac{1}{a} = -1$. Let $u = x^2 + ax + 5$.

Then the last inequality can be rewritten as

$$\log_3 \left( \sqrt{u} + 1 \right) \cdot \log_5 \left( u + 1 \right) \leq 1.$$

The function $f(u) = \log_3 \left( \sqrt{u} + 1 \right) \cdot \log_5 \left( u + 1 \right)$ is defined and returns to $[0; +\infty[$. Note that $f(4) = 1$. Therefore $f(u) \leq 1$ if and only if $0 \leq u \leq 4$. Consequently, the original inequality is equivalent to the system of inequalities

$$0 \leq x^2 + ax + 5 \leq 4.$$

Solving this system, we get

1) $$\frac{-a - \sqrt{a^2 - 4}}{2}; \frac{-a - \sqrt{a^2 - 20}}{2}$$

$$\cup \left[ \frac{-a + \sqrt{a^2 - 20}}{2}; \frac{-a + \sqrt{a^2 - 4}}{2} \right],$$

if $a^2 - 20 \geq 0$

2) $$\frac{-a - \sqrt{a^2 - 4}}{2}; \frac{-a + \sqrt{a^2 - 4}}{2}$$

$$\cup \left\{ a^2 - 4 \geq 0; a^2 - 20 < 0 \right\}$$

3) Solved no if $a^2 - 4 < 0$.

Thus, the system has exactly one solution if $a^2 - 4 = 0$. Considering that $a > 1$, we get $a = 2$.

If $0 < a < 1$, then the original inequality is equivalent to the inequality

$$\log_3 \left( \sqrt{x^2 + ax + 5} + 1 \right) \cdot \log_5 \left( x^2 + ax + 6 \right) \geq 1$$,

which in turn is equivalent to the inequality

$$x^2 + ax + 5 \geq 4.$$

The last inequality for any $a$ has an infinite number of solutions; therefore, no $a$ from the interval under consideration satisfy the conditions of the problem.

Most applicants failed to cope with this task.
