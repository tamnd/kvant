Standard Features

In Pascal you can use all the standard functions. Partners: sin, cos, exp, ln, arctan and functions abs, sqr, sqrt, arcsin, odd, round, trunc, succ, pred.

$abs(x) = |x|$, $sqr(x) = x^2$, $sqrt(x) = \sqrt{x}$.

The result of the odd(x) function is true if $x$ is an odd number, and false if $x$ is even.

The round function rounds the value of a real number, and the trunc function discards its fractional part. For example, round (5.7) = 6, trunc (5.7) = 5.

The succ and pred functions apply to any scalar type (except real). The result of the function succ(x) is the value following $x$ in the type declaration, and the function pred(x) is the value preceding $x$.
