A cycle with termination conditions is described by my diagram:

In this case, the body of the loop is executed first, and then the conditions are checked. The loop exits when the condition is true. The peculiarity of this loop is that the body of the loop is always executed at least once, even if the conditions are immediately true.

Let us now write a program that calculates the values ​​of the function $F(n)=n!$, using a loop operator with termination conditions.

program fact2(output, input);
var f,k,n:integer;
begin
read(n); f:=1; k:=1;
repeat
f:=f*k; k:=k+1
until k>n;
writeln('n=',n,' n!=',f)
end.

Compare the conditions in these two programs! In the first case, the body of the loop is repeated if the condition is true, and in the second, a true condition is a sign of the end of the cycle.

A cycle with a parameter is described by my diagram:

The value of expression -1 is the starting value of the loop variable, and the value of expression -2 is its ending value. The type of the loop variable must be scalar (other than real). The operation of this loop operator is as follows. First, the loop variable is given an initial value, and if it is not greater than the end value, the body of the loop is executed. Then the loop variable takes the next value obtained using the functions `succ*()` (in the case of `to`) or `pred` (in the case of `downto`), and the body of the loop is executed again. In the most common case, when a loop variable takes values ​​like `integer`, its value changes to +1 (in the case of `to`) and -1 (in the case of `downto`). This happens until the value of the loop variable exceeds the final value.

Please note that in the first two types, the loop must contain an operator that changes the value of the loop variable (otherwise a loop will occur!), and in a loop with a parameter, the presence of such an operator leads to an error.
