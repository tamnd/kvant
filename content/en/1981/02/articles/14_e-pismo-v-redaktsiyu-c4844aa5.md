Degree with a real exponent.

In the textbook “Algebra and Beginning Analysis 10,” an exponential function with any real exponent is introduced (section 108). In fact, here too the task is to find

a “good” definition of a power with a real exponent, and the definition of the exponential function itself lists those of its properties that can be deduced from this “good” definition. What is a “good” definition of a degree with any real exponent?

For definiteness, let $a > 1$. If $x$ is a rational number, then $a^x$ has already been defined by us, and the function $y = a^x$, by virtue of the property $5^0$, returns to the set $Q$ of all rational numbers (for $0 < a < 1$ the function $y = a^x$ kills (property $6^0$) to the set $Q$).

In order to extend the function $y = a^x$ to the set $R$ of all real numbers, we first require only that this function be multirelative.

Let $a$ be an irrational number, and $r_1$ and $r_2$ be irrational numbers for which $r_1 < a < r_2$. Let's assume that we already know what $a^a$ is. By virtue of our requirement, the inequalities must be valid

$$a^{r_1} < a^{a^a} < a^{r_2}.$$

Thus, the number $a^a$ must be enclosed between any two numbers $a^{r_1}$ and $a^{r_2}$, where $r_1 < a < r_2$.

In calculus courses, it is proven that there is a unique number $b$ for which all the inequalities $a^{r_1} < b < a^{r_2}$ are true, where $r_1$ and $r_2$ are arbitrary rational numbers for which $r_1 < a < r_2$.

This allows the following definition:

On the limit 5. Let $a$ be irrational and $a > 0$. Then $a^a$ is the real number contained between any two numbers $a^{r_1}$ and $a^{r_2}$, where $r_1$ and $r_2$ are irrational and $r_1 < a < r_2$.

The scope of the school course does not allow us to prove the existence of the number $a^a$, and we will take it on faith. We limit ourselves to proving uniqueness.

To prove it, we need the important and in itself Bernoulli inequality $(1 + h)^n \geqslant 1 + nh$, where $n \in \mathbb{N}$ and $h \geqslant -1$.

Let's prove it using the method of mathematical induction.

For $n = 1$ this inequality is true $(1 + h) \geqslant 1 + h)$. Let us assume that $(1 + h)^k \geqslant 1 + kh$ and prove that $(1 + h)^{k+1} \geqslant 1 + (k+1)h$. We have $(1 + h)^{k+1} = (1 + h)(1 + h)^k \geqslant (1 + h)(1 + h)^k = 1 + hk + h^2k = 1 + h(k+1) + h^2k \geqslant 1 + h(k+1)$, which is what we needed to prove.

Let us now prove that $\lim_{n \to \infty} \sqrt[n]{a} = 1$ for $a > 0$.

Let $\varepsilon > 0$ and $a > 1^*$ be given, then $\sqrt[n]{a} = 1 + \varepsilon_n$, where $\varepsilon_n > 0$. Hence, applying Bernoulli's inequality, we obtain $a = (1 + \varepsilon_n)^n \geqslant 1 + n\varepsilon_n$. Therefore $0 < \varepsilon_n \leqslant \frac{a-1}{n}$. It is easy to see that $\frac{a-1}{n} < \varepsilon$ at $n > N = \left[ \frac{a-1}{\varepsilon} \right] + 1$.

We have thus proved that $\lim_{n \to \infty} \varepsilon_n = 0$, but this also means that $\lim_{n \to \infty} \sqrt[n]{a} = \lim_{n \to \infty} (1 + \varepsilon_n) = 1$.

Now let's move on to the proof of uniqueness.

Let there exist 2 numbers $\beta$ and $\gamma$ for which the inequalities $a^1 < \beta < a^2$ and $a^1 < \gamma < a^2$ are valid for any rational $r_1$ and $r_2$ for which $r_1 < a < r_2$. Let for definition $\beta > \gamma$.

Then $0 < \beta - \gamma < a^2 - a^1 = a^1(a^2 - r_1 - 1)$. It is clear that $a^1 < a^{[a]+1} = c$. For any $n \in \mathbb{N}$ there exist $r_1^{(n)}$ and $r_2^{(n)}$ such that $r_1^{(n)} < a < r_2^{(n)}$ and $r_2^{(n)} - r_1^{(n)} < \frac{1}{n}$.

For these $r_2^{(n)}$ and $r_2^{(n)}$ (by property $5^0$ for the rational exponent) $0 < \beta - \gamma < c\left(\frac{1}{n} - 1\right)$.

According to what was proven earlier, for any $\varepsilon > 0$ there is a $N$ such that for all $n > N$ the inequality $a^{\frac{1}{n}} - 1 < \frac{\varepsilon}{c}$ is valid. Therefore, for any $\varepsilon > 0$ the inequality $0 < \beta - \gamma < \varepsilon$ is valid, which is impossible.

It should be noted that when defining a degree with an irrational exponent, we moved away from the previously accepted scheme: we can build definitions based only on the need to preserve the property $1^0$ in an infinite number of ways.

More precisely, there are infinite multifunctions $y = f(x)$ such that $f(x) = a^x$ for $x \in \mathbb{Q}$ for which $f(x + y) = f(x) \cdot f(y)$.

Of all these functions, only one function we constructed $y = a^x$ will be monotonic (and continuous). All other functions of this family are arranged quite wildly. For example, any of them is not limited to any interval of the numerical axis.

How to calculate $2\sqrt{2}$?

Let's consider several decimal approximations $\sqrt{2}$ for deficiency and excess. These approximations satisfy the inequalities $1 < \sqrt{2} < 2; 1,4 < \sqrt{2} < 1,5; 1,41 < \sqrt{2} < 1,42$. Then, by our definition 5, the number $2\sqrt{2}$ must satisfy the inequalities $2^1 < 2\sqrt{2} < 2^2; 2^{1,4} < 2\sqrt{2} < 2^{1,5}; 2^{1,41} < 2\sqrt{2} < 2^{1,42}$, or $2 < 2\sqrt{2} < 4; 2,6 < 2\sqrt{2} < 2,9; 2,65 < 2\sqrt{2} < 2,68$.

The second of these inequalities allows us to find $2\sqrt{2}$ with an accuracy of up to integers, the third - with an accuracy of up to tens. It is understood that it is possible to obtain the value of $2\sqrt{2}$ with any given accuracy by taking appropriate approximations $\sqrt{2}$.
