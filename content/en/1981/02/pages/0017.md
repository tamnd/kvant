Thus, groupons (Z; +), (R; •) are commutative, but (R₀; :), of course, are not: for example, 8:4 ≠ 4:8!

Property A. Groupond (M;*) is called associative if for any a, b, c ∈ M

(a*b)*c = a*(b*c).

Apparently, all operations known to you have this property; examples of non-associative grouponds will appear below (see task 2).

Property E. An element e ∈ M is called neutral (they also say ed units, and for the operation of addition - zero) in a groupond (M; *) if for any a ∈ M

a*e = e*a = a.

We will say that the groupond (M; *) has “property E.” if it contains a neutral element. The calculation e = e*e' = e' shows that the neutral element is always unique.

For addition of numbers, the neutral element is the number 0, for multiplication - the number 1. Is there a neutral element in the group of all displacements of the plane (relative to the operation of composition of displacements)? Of course, there is - also an effective transformation.

Property I. Let (M; *) be a groupond with neutral element e. Then (M; *) has the property of inversion (they also say invertibility) if for any a ∈ M one can specify an inverse element, that is, an element a̅ ∈ M such that

a*a̅ = a*a = e.

To multiply numbers, for example, the element 1/a is used for the element a ≠ 0, and the element (-a) is used for addition. But for grouponds (N; +) the addition of natural numbers there is no property of inversion (why?)

Property C. Groupond (M; *) has the contractility property if for any a, b, c ∈ M

a*b = a*c ⇒ b = c
b*a = c*a ⇒ b = c.
