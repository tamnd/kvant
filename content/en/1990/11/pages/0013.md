$$f(\varphi_i/2\pi) = r_1f(\varphi_1/2\pi) + \dots + r_{i-1}f(\varphi_{i-1}/2\pi).$$
The function $f$ that we constructed is additive in the sense that if one of the numbers for which it is defined is equal to the sum of the other numbers (hereinafter with any rational coefficients), then the same is true for the values ​​of functions on these numbers.
