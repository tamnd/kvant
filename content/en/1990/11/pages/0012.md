"Theorem". There are non-linear additive functions. Moreover, for any irrational a there is an additive function f such that f(1)=0, and f(a)=1.

(If the function f were linear, then from f(1)=0 it would follow that f≠0.)

Of course, we will not prove the “theorem” (and we could not). However, we don’t need it, as we will eventually see. And to finish this conversation, we will give two more formulations of the statement, characteristic of non-constructive mathematics. From each of them we can derive our “theorem”.

In the set of real numbers there is an approach A such that every real number can be uniquely represented as a finite sum.

$$r_1 a_1 + \dots + r_n a_n$$

food $r_1, \dots, r_n$ are rational numbers, and $a_1, \dots, a_n \in A$.

The set of real numbers can be fulfilled; this means that in R one can introduce an order <, with respect to which in any set $B \subset R$ there is a minimal element, i.e., an element b such that $b < b'$ for any $b' \in B$ different from b. (The generic order < is not suitable: for example, the set of positive numbers does not have a minimal element.)

The last statement is often accepted as an additional axiom (in the form “every set can be satisfied”).

The proof of Lemma 2 is not very good

Using the “theorem,” our Lemma 2 is proven in two seconds. Here's the proof. Let $(l, \varphi)$ be a set with $l \neq 0$ and with $\varphi$ not commensurate with $l$. Let us choose an additive function f such that f(1)=0 and f(\varphi/2π)=1. Let us assign the number $l_1 f(\varphi_1/2π)+\dots+l_N f(\varphi_N/2π)$ to each set $(l_1, \varphi_1)$, ..., $(l_N, \varphi_N)$. This number does not change under transformations (1) - (5) from the definition of similarity of sets (I leave the obvious check to the reader). Thus, for similar sets these numbers are the same. But for the set $(l, \varphi)$ that number is $lf(\varphi/2π)=l \neq 0$, and for the empty set it is equal to 0 (the sum of zero terms). The lemma is proven.

Quite a good proof of Lemma 2

I said that in its content, constructive mathematics does not differ from ordinary mathematics. And Lemma 2 is a meaningful statement (at least, this is Dehn’s theorem). So it can be proven without a “theorem”? You can, here's the proof.

Let our set $(l, \varphi)$ be similar to the empty set. This means that from $(l, \varphi)$ we can go to the empty set by applying transformations (1) - (5) a certain number of times. At each step, some set is obtained. Let's write down on a piece of paper the second numbers (angles) from all the pairs included in all these sets. A finite list of numbers will appear on the piece of paper, including our $\varphi$. Let's add 2π to this list and write the resulting numbers in this order: first 2π, then $\varphi$, and then whatever you like:

$$2\pi, \varphi, \varphi_3, \varphi_4, \dots, \varphi_{M-1}, \varphi_M$$

(instead of 2π and $\varphi$ we will sometimes write $\varphi_1$ and $\varphi_2$ for consistency). Now underline in the list those numbers that are not represented as the sum of the previous ones with rational coefficients.
