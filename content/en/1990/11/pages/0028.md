M1229. Prove that for every natural number $m > 1$ the number
a) $4^m + 5$;
b) $8^m + 9$;
c) $a^m + a + 1$, where $a$ is an integer and is not divisible by 8; is not the square of an integer.

Remainders when divided by 4
(with odd $m > 1$):

| $a$ | $a^m$ | $N = a^m + a + 1$ |
| :--- | :--- | :--- |
| 1 | 1 | 3 |
| 2 | 0 | 3 |
| 3 | 3 | 3 |

Since $p - 1$ and $p + 2$ are of different parities, this is only possible for $p - 1 = 1$, $p = 2$, but then $p + 2 = 4$ and $3m - 2 = 2$, which is impossible for the integer $m$.

c) Here, if $m$ is even, the same idea works as in point a): the number $N = a^m + a + 1$ is found using k $a^m$; and for odd $m$, as in point 6), it is enough to deal with the remainders when dividing by powers of two.

Let $m = 2r$ first. Then

$$a^{2r} < a^{2r} + a + 1 < a^{2r} + 2a^r + 1 = (a^r + 1)^2,$$

i.e. $a^{2r} + a + 1$ is not a square.

Let now $m = 2r + 1$. Then, considering the various possible remainders 1, 2, 3 when dividing $a$ by 4, we are convinced that $N$ gives remainder 3 when divided by 4 (see the table in the margin), and with $n = 8k + 4$ the number $N = (8k + 4)^m + 8k + 4 + 1$ gives remainder 5 when divided by 8.

But a square can only give remainders 0, 1 or 4 when divided by 8. Indeed, with a whole $k$

$$(4k \pm 1)^2 = 16k^2 \pm 8k + 1, (4k \pm 2)^2 = 16k^2 \pm 8k + 4, (4k \pm 3)^2 = 16k^2 \pm 24k + 1, (4k)^2 = 16k^2.$$

Note that for $a$, square 8, the statement of the problem is not always true: for example, for $a = 72$ and $m = 3$ the number is $a^m + a + 1 = 611^2$. (From the general theorems of algebraic geometry it follows that for every $m > 3$ the equation $x^m + x + 1 = y^2$ has only a finite number of solutions in integers.)

R. Khairullaev
