Information and information

Weight competition
"Young Programmer"
The Association of Information Teachers, the Main Directorate of Public Education of the Krasnoyarsk Regional Executive Committee, and the HTTM “Special” Center are holding a “Young Programmer” competition for the best program created by schoolchildren for young children.

The competition accepts classical requirements, demonstration, educational, control programs in subjects, executive, game programs, etc., ready for use in grades 1-6.

When developing programs, one should focus on school personal computers.

The winners will receive prizes: radios, cameras, watches, libraries of literature on information, personal programs.

To participate in the competition, you must send the following materials before February 1, 1991: an application (according to the example provided) and a detailed program script. The script should contain the main ideas and a descriptive description of the program.

Bid
Full name
Home address
School number and address (SPTU)
Class
Machine type
Programming language
Name of the program (to whom and what is it intended for)
Scope of the program
Average program running time
Full name of information teacher (club leader, CPC teacher) who provided assistance in working on the program and teaching programming.

The authors of the scripts processed based on the results of the competition will be invited to Krasnoyarsk at the end of March 1991 to participate in the final type of the competition.

Send materials for the competition to the address: 660051, Krasnoyarsk, PO Box 11553,
Organizing committee of the “Young Programmer” competition.
