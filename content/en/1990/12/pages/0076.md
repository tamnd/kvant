4. The cells are divided into segments into which the segment [0;1] is divided by offset points. It is easy to check that if you mark points 9/23, 17/23 and 19/23, then in one move the grasshoppers will not be able to get into one cell (Fig. 24). With any number and any location of displaced points, in two moves the grasshoppers will be able to get into one cell of the greatest length. It is enough to prove this statement for a grasshopper located at point O. Let s be the length, α the left end of the cell with the greatest length (if there are several cells of length s, then consider any of them).

If the left end of the cell under consideration is located closer to point O than to the right end, i.e. if α < s (Fig. 25), then the grasshopper that jumps through point α will end up in cell [α; α + s] in one move (if α = 0, i.e. the grasshopper is already in the cell being considered, then not a single jump is required). Otherwise, when α ≥ s, consider the segment $$\frac{\alpha - s}{2}; \frac{\alpha + s}{2}$$ of length s (Fig. 26).

This segment contains at least one offset point β, since otherwise the cell containing this segment would have a length greater than s. Bent through point β, the grasshopper will end up at point 2β ∈ [α - s; α + s].

If this point does not lie in cell [α; α + s], then the second jump, this time through point α, will jump the grasshopper into cell [α; α + s].

7. Answer: 2k. If the number of vertices of a polygon is n, and the coloring satisfies the conditions of the problem, then the number of segments of each chain does not exceed n - 1. This statement follows from the lemma.

Lemma a. If some n sides and diagonals of a convex n-pleasure are colored, then there exists a closed broken line all of whose links are colored.

Proof. We will sequentially erase vertices from which exactly one colored segment emerges, and together with the vertex we will also erase the colored segment emerging from it. If at the same time new vertices of the indicated type appear, then we will do the same with it and with the segments emerging from them. Initially, the number of vertices is equal to the number of colored segments; at each step, both of these numbers are reduced by 1, so at any moment the number of unerased vertices is equal to the number of unerased colored segments. We will continue the erasing process as long as possible. Then either among the remaining vertices there are vertices from which at least two colored segments emerge, or all vertices and all colored segments are erased. Prove that the latter is impossible. As a result, several vertices remain, each of which has at least two colored segments. Take any such vertex A₁. Along the colored segment we will get from it to vertex A₂, from vertex A₂ to vertex A₃, and so on. In at most n steps such a path will be closed. The lemma is proven.

In total, the n-pleaser has $$\frac{n(n-1)}{2}$$ sides and diagonals, and there are no more than n - 1 segments of each chain.

Pozny $$\frac{n(n-1)}{2}$$ ≤ k(n-1), whence n ≤ 2k. For n = 2k the required coloring exists. Let's take the correct 2k-pleaser A₁A₂...A₂k and show the first flail to break A₁A₂kA₂k...A₂k. Use the second flail to steal a breaker, turning it through an angle π/k, and so on. Then each segment will be colored equally from k flails, and there will be no closed polylines of the same color.
