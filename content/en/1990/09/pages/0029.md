M1219*. Prove that for any $n$ positive numbers $x_1, x_2, \dots, x_n$ ($n > 1$) the inequality $(x_2 + \dots + x_n)^{x_1} + \dots + (x_1 + \dots + x_{i-1}) + x_{i+1} + \dots + x_n)^{x_i} + \dots + (x_1 + x_2 + \dots + x_{n-1})^{x_n} > n - 1$ is true.

For example, for any positive numbers $x, y, z$ the inequality $(x + y)^2 + (y + z)^x + (z + x)^y > 2$ holds.

Let us denote the sum on the left side of the inequality by $S$. If for some index $i$ we have $x_i \geqslant 1$, then each term of the sum $S$, except, perhaps, the $i$th term, is not less than 1; in addition, the $i$-th term is positive; from here the required inequality immediately follows.

Let now for each index $i$ we have $0 < x_i < 1$. Below, under the assumption that $x > 0$ and $0 < y < 1$, we will prove the inequality

$$x^y > \frac{x}{x + y}.$$

Assuming this inequality to be valid, we get

$$S > \frac{x_2 + \dots + x_n}{x_1 + \dots + x_n} + \dots + \frac{x_1 + \dots + x_{i-1} + x_{i+1} + \dots + x_n}{x_1 + \dots + x_n} + \dots + \frac{x_1 + \dots + x_{n-1}}{x_1 + \dots + x_n} = n - 1,$$

Q.E.D.

$$(1 + y/x)^a > 1 + ay/x = 1 + 1/x > 1/x.$$

Hence $\frac{y+x}{x} > \frac{1}{x^y}$ and $x^y > \frac{x}{x + y}$. So, inequality (1), and with it the inequality of our problem, is proven.

Let us now prove that we use the inequality named after Jacob Bernoulli: for $h > 0$, $a > 1$

$$(1 + h)^a > 1 + ah.$$

$$a(1 + h)^{a-1} > a,$$
