M1217. Prove for any natural number $n$ the equality $\frac{1}{n^2} + \left(\frac{1}{n} + \frac{1}{n-1}\right)^2 + \ldots + \left(\frac{1}{n} + \frac{1}{n-1} + \ldots + 1\right)^2 = 2n - \left(1 + \frac{1}{2} + \ldots + \frac{1}{n}\right)$

$(x_1 + \ldots + x_n)^2 = x_1^2 + \ldots + x_m^2 + 2x_1x_2 + \ldots + 2x_{m-1}x_m$

or, use the sign $\Sigma$ for the amount,

$$\left( \sum_{k=1}^{m} x_k \right)^2 = \sum_{k=1}^{m} x_k^2 + 2 \sum_{1 \leq k < j \leq m} x_k x_j.$$

Note that the fraction $1/k$ occurs in $k$ in the last parentheses on the left side. Therefore, after opening the brackets (according to the formula given in the margin), the fraction $1/k^2$ occurs $k$ times, and the fraction $1/(kl)$ for each $l > k$ also occurs $k$ times, and each $l$ corresponds to $l-1$ values ​​$k$ ($k=1, 2, \ldots, l-1$). Therefore, the sum on the left is

$$\sum_{k=1}^{n} \frac{k}{k^2} + 2 \sum_{l=1}^{n} \frac{k(l-1)}{kl} = \left(1 + \frac{1}{2} + \ldots + \frac{1}{n}\right) + 2 \left(1 - \frac{1}{1} + 1 - \frac{1}{2} + \ldots + 1 - \frac{1}{n}\right) = 2n - \left(1 + \frac{1}{2} + \ldots + \frac{1}{n}\right).$$

You can solve the problem more straightforwardly - by induction.

It is easy to check that the equality being proved holds for $n=1$ ($1=2-1$) and $n=2$ ($1/2^2 + (1/2+1/1)^2 = 4-1-1/2$). Now we prove it for any $n>2$; it is assumed that a similar equality is true for $n-1$:

$$\frac{1}{n^2} + \left(\frac{1}{n} + \frac{1}{n-1}\right)^2 + \ldots + \left(\frac{1}{n} + \frac{1}{n-1} + \ldots + 1\right)^2 = \frac{n}{n^2} + 2 \cdot \frac{1}{n} \cdot \left(\frac{1}{n-1} + \left(\frac{1}{n-1} + \frac{1}{n-2}\right) + \ldots$$

$$\ldots + \left(\frac{1}{n-1} + \frac{1}{n-2} + \ldots + 1\right)^2 + \left(\frac{1}{n-1} + \frac{1}{n-2}\right)^2 + \ldots$$

$$\ldots + \left(\frac{1}{n-1} + \ldots + 1\right)^2 = \frac{1}{n} + \frac{2}{n} \left(\frac{n-1}{n-1} + \frac{n-2}{n-2}\right) + \ldots$$
