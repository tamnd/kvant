$$\lambda_1^3 \lambda_2 + \lambda_2^3 \lambda_3 + \lambda_3 \lambda_1 = -1, \quad \lambda_1 \lambda_2 \lambda_3 = 1,$$
where
$$a_2 = \lambda_1^2 + \lambda_2^2 + \lambda_3^2 = (\lambda_1 + \lambda_2 + \lambda_3)^2 - 2(\lambda_1 \lambda_2 + \lambda_2 \lambda_3 + \lambda_3 \lambda_1) = 2;$$
$$a_3 = \lambda_1^3 + \lambda_2^3 + \lambda_3^3 = (\lambda_1 + \lambda_2 + \lambda_3)^3 - 3(\lambda_1 + \lambda_2 + \lambda_3)(\lambda_1 \lambda_2 + \lambda_2 \lambda_3 + \lambda_3 \lambda_1) + 3\lambda_1 \lambda_2 \lambda_3 = 3.$$

Therefore, $a_n = b_n$ for all $n$.
Now we note that
$$a_p = \lambda_1^p + \lambda_2^p + \lambda_3^p = (\lambda_1 + \lambda_2 + \lambda_3)^p - \Sigma C_p^{(k, l, m)} \lambda_1^k \lambda_2^l \lambda_3^m,$$

where the summation is over all sets $(k, l, m)$ of non-negative integers with a sum $k + l + m = p$ other than $(p, 0, 0), (0, p, 0)$ and $(0, 0, p)$, and
$$C_p^{(k, l, m)} = \frac{p!}{k!l!m!},$$

and prove that for prime $p$ the number $a_p$ is divisible by $p$.
It is clear that for the given set $(k, l, m)$ the coefficient $C_p^{(k, l, m)}$ is divisible by the prime $p$. Next, we select in the sum a group of terms that differ only in the permutation of exponents $k, l, m$. The coefficients $C_p^{(k, l, m)}$ are the same for all such terms, and the sum of the corresponding monomials $\lambda_1^k \lambda_2^l \lambda_3^m$ is the so-called symmetric polynomial in $\lambda_1, \lambda_2, \lambda_3$ (i.e., it does not change when rearranging the arguments). It is known that such a polynomial can always be represented as a certain polynomial with integer coefficients of the main symmetric functions $\sigma_1 = \lambda_1 + \lambda_2 + \lambda_3, \sigma_2 = \lambda_1 \lambda_2 + \lambda_2 \lambda_3 + \lambda_3 \lambda_1, \sigma_3 = \lambda_1 \lambda_2 \lambda_3$ - this is a special case of the main theorem on symmetric polynomials (see, for example, the book by V. G. Boltyansky, N. Ya. Vilenkin “Symmetry in Algebra”, M.: Nauka, 1987). Our numbers $\sigma_1 = 0, \sigma_2 = -1, \sigma_3 = 1$ are integers, so the sum of the terms of each group, and therefore the whole sum, is divisible by $p$. Thus, since $\lambda_1 + \lambda_2 + \lambda_3 = 0$, and $a_p$ are divisible by $p$.
