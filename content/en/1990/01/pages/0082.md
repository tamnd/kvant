2. The number $a_1$ cannot be represented exactly in a computer; the number $A_1 = a_1 + \varepsilon$ will be written instead. Further, if we assume that in further calculations there is no environmental error, then by calculating $A_2, A_3, \dots$ sequentially, we obtain $A_n = a_n + \varepsilon$, where $|\varepsilon| = |\varepsilon| \cdot n!$ (the initial error increases by $n!$ times). All this is confirmed when calculating on a computer - with this method of calculation, even using double precision, the number $A_{20}$ turns out to be negative! At the same time, it is easy to show by induction that

$$a_n = n! \left( \frac{1}{(n+1)!} - \frac{1}{(n+2)!} + \dots \right),$$

where

$$a_n = \frac{1}{n+1} - \frac{1}{(n+1)(n+2)} + \frac{1}{(n+1)(n+2)(n+3)} - \dots$$

and $0 < a_n < 1/(n+1)$. Therefore, in this problem it is better to use the backward count according to the formula $a_{n-1} = (1 - a_n)/n$, taking the number 0 as an approximation for the number $a_m$ far enough away, then the initial error will decrease and eventually become insignificant. Calculations show that the number $a_{m-20}$ will be found with six correct decimal places.
