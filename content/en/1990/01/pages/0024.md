Definition 3. Let $X$ and $Y$ be two metric spaces, $F$ be a mapping of the set $X$ into $Y$; $x_0$ is a point at $X$. Then $F$ is called non-prime at the point $x_0$ if for any positive number $\varepsilon$ there is a $\delta$ (depending on $\varepsilon$) such that all points from the $\delta$-neighborhood $x_0$ are mapped to the $\varepsilon$-neighborhood of the point $y_0 = F(x_0)$.

For example, any “school” function is a mapping of its domain of definition $E$ into a number line, non-prime at each point $E$. Here is an example of a non-primary mapping of a set of convex polygons (we talked about how to turn it into a metric space) into a number line: each polygon is assigned its area.

The following definitions help to construct a natural completion of any metric space - just as the set of rational numbers (or finite decimal fractions) is completed to the set $R$ of all real numbers.

Definition 4. A sequence $M_1, M_2, \dots$ of points $X$ is called funcdamal if for any $\varepsilon > 0$ there is a number $n$ such that $\rho(M_k, M_l) < \varepsilon$ for all $k \geqslant l \geqslant n$. A space $X$ is called complete if every funcdamal sequence in it has a limit.

Definition 5. Two sequences $M_1', M_2', \dots$ are said to be equivalent if for any $\varepsilon > 0$ there is a number $n$ such that $\rho(M_k', M_l') < \varepsilon$ for all $k \geqslant l \geqslant n$.

It turns out that if we take the classes of equivalent sequences as points, we can obtain a new space containing $X$, but this is necessarily complete. It is interesting that replenishing the space of some simple functions (say, polynomials) using metrics (7), (8) and (9) leads to a complete space that differs in the supply of “functions”.

An equally interesting addition is obtained for the $p$-adic metric (Example 4): it consists of “numbers” written in the $p$-ary system with “infinite left” lines of digits *).

The theory of metric spaces, which arose at the beginning of the 20th century in the works of Fréchet and Hausdorff, is now presented in the first chapters of textbooks with approximately such titles as “Elements of functional analysis”, “Introduction to the theory of sets and functions”, “Fundamentals of modern analysis”. Of course, most of this theory associated with the concept of limit is meaningful only for spaces with an infinite number of points.

But the general concept of “distance” is also useful for some problems about finite sets and graphs. In particular, the “word spacing” we talked about in Example 2 turns out to be a very useful tool in the rapidly developing fields of science: error-correcting code theory and molecular biology. However, these are topics for a separate discussion.
