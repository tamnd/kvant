Recall that $|a-b|=a-b$ if $a \geq b$ and $b-a$ if $b \geq a$, so in all cases $\rho(a,b)$ is equal to the length of the segment of the real line with endpoints $a$ and $b$.

Check that $\rho$ satisfies all those requirements of $1^\circ-3^\circ$.

In particular, the inequality $3^\circ$ takes the form

$$|a-c| \leq |a-b|+|b-c|.$$

(It becomes an equality if $b$ lies between $a$ and $c$).

Example 2 (“Hamming Metric”). $X$ - a set of words from some identical number of letters. The distance $\rho$ between the words $a$ and $b$ is the number of letters in which they differ (if they are written one below the other). For example, $\rho$ (plane, begetot) = 6; $\rho$ (adsorption, absorption) = 1; $\rho$ (absorption, aberration) = 3. Similar spacing between words is used in molecular biology. Macromolecules of DNA and RNA are specified by words from four types of chemical “letters” - nucleotides (and proteins - from twenty “letters” - amino acids). By comparing similar fragments of these “words”, biologists determine the speed and path of evolution. In this case, not only the simplest “Hamming metric” is used, but also more complex formulas for distance, allowing to take into account the possibility of dropping or inserting individual letters, as well as the degree of similarity of individual letters.

Example 3, which we already talked about a little above. Let's assume that we have a map of Moscow, which lists all the basics of urban transport and for each interval between stops it indicates how many minutes it takes a bus (tram, metro, trolleybus, respectively) to cover this interval. Using such a plan, for any two stops $a$ and $b$ one can find the values ​​$t(a,b)$ - the minimum time required to get from $a$ to $b$ (in our “model” we will not take into account the time spent transferring from one type of transport to another and waiting). Let's check whether the functions $t$ hold properties $1^\circ-3^\circ$; in other words, whether the set of all stops $X$ with distance $t$ is a metric space. Property $1^\circ$ is, as always, very indo; $3^\circ$ is also beyond doubt: it is clear that one can eat from $a$ to $c$ through $b$, so the minimum time $t(a,c)$ is completed no more than $t(a,b)+t(b,c)$. But property $2^\circ$, especially now that there are many one-way streets in Moscow, can, of course, be violated.

Check that for the function

$$t'(a,b) = \frac{t(a,b)+t(b,a)}{2}$$

all properties $1^\circ-3^\circ$ are already fulfilled.

Example 4. Let $X$ be the set of natural numbers, $p$ be a fixed prime number. Let us set for any $a>b$ from $X$

$$\rho(a,b) = p^{-n},$$

where $n \geq 0$ is the most power of $p$ on which the difference $a-b$ is divided. This is the so-called $p$-adic metric, which has interesting applications in number theory; two numbers in it are close if their difference is divisible by a high power of the number $p$.
