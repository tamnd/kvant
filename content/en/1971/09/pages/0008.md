Computing machines operating in the positional number system can be said to imitate the behavior of a person counting with a “column”. In essence, all machines began with an imitation of what was seen, alive: the first “self-propelled vehicles” had “legs” (Fig. 9), and the first flying machines were planned to be made with flapping wings. It is possible that in the future, more advanced computers will work with modern number systems. It is still difficult to say what such systems should be, but attempts to look for new principles are already being made, and we will now talk about one of them.

The disadvantage of positional number systems (when used in machines) is inter-bit connections that delay the execution of operations: to obtain the final result in any digit, it is necessary that the previous (low-order) digit has already been processed. Non-positional systems (in other respects, as we know, are less convenient) allow you to work with each “digit” independently and separately.

One possible way of representing natural numbers, which can be considered a "non-positional number system", is the system of residual classes. In the system of residual classes, a number is represented by its remainders from division by the selected system of bases (“modules”).

When choosing one model $p$ different remainders from division by $p$ have $p$ integers taken in a row from the natural series. If there are several models, then the possibility of beginning numbers having representations expands.

Taking the corresponding remainders as symbols of the representation of the number, we obtain a non-positional number system, the digits of which are the remainders for each module depending on

efficiency. The numbers in each digit are different remainders, less than the modulus. The more a given module is selected, the larger the range of represented numbers and the more possible values ​​of the remainders (digits in a given digit). At the same time, all digits of a number in such a number system are completely independent of each other.

Arithmetic operations in such a system are very simple. For example, the remainder of dividing the sum of two numbers by a given module $p$ is equal to the sum of the remainders formed by the individual terms, if this sum is less than $p$, or $p$ less than this sum. A similar rule is true for the multiplication operation.

Consider as an example a system of residual classes defined by three modules $p_1=7, p_2=9, p_3=10$. The number $n$ in this system will be written in the form $(a, b, c)$, where $a, b, c$ is the correspondence of the remainder of dividing $n$ by $p_1, p_2, p_3$. This representation defines unique natural numbers in the range $0 \leq n \leq 629$, with possible values ​​of $a, b, c$ enclosed within $0 \leq a \leq 6, 0 \leq b \leq 8, 0 \leq c \leq 9$. For example:

$$5=(5, 5, 5); 20=(6, 2, 0);$$

Arithmetic operations:

$$(3, 2, 1)+(1, 4, 4)=(4, 6, 5);$$
$$(2, 5, 3)\times(2, 7, 6)=(4, 8, 8).$$

(In the decimal system, this equality goes to the corresponding one)

We do not at all claim, of course, that it is arithmetic that will still find application in the creation of new computers (if only for the reason that with this system it is difficult to compare numbers, which is necessary for many purposes). But it seems to be a simple and respectable example of the connection between “abstract” (and somewhat “old-fashioned” and quite traditional) theoretical-arithmetic laws with “numerical technical” problems of perfect machine mathematics.
