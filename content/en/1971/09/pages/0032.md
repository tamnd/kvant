For many years, linguists have been looking for a way out of this difficult situation. They came up with new, very cunning algorithms, witty models of language, and pictorial methods of describing it. We figured out how to simplify the processing process and how to improve the quality of translation. We met, discussed, argued. But let me ask, the reader, if the matter turns out to be so complicated, then why were the first experiments so successful?

The secret is simple. These experiments were carried out on very small material. And it is clear that for a small and very specific text there are easily all the exceptions and variants; stock up on the necessary rules for all cases that the text contains. And the text is translated. You can see this for yourself using the following problem as an example.

Task 3. Using a system of rules, sequences of Arabic numerals are translated into sequences of Roman numerals. At each step, one rule is applied, replacing one Arabic numeral with one Roman numeral. The following four types of rules are used:

non-contest:
for example, 2→III replace 2 with III;
single-contest singles:
a) 2(3)→III replace 2 with III,
6) (3) 2→III if after (before) 2 there is 3;
two-contest:
(3) 2(4)→III (replace 2 with III if there is 3 before 2 and 4 after)

Each sequence of Arabic numerals is corrected in the following order: first all double-contest, then single-contest double, then single and finally non-contest. Any set of rules of these types is called programming. The program may not contain all types of rules.

Numbered in Arabic numerals from 1 to 6 the following English (French, German) words:

lake, a, this, what, beautiful, is;
champ, un, ce, que, vert, sera;
Feld, das, was, grün, grüne, ist.

Task 1. Make a list of all sentences consisting of these words.
Task 2. Make a minimum list of Russian words necessary for translation from task 1 into Russian, and prove them in Roman numerals.
Task 3. Create a program for translating numerical sequences in such a way that each sequence of Arabic numerals corresponding to any sentence II from task 1 is translated into a sequence of Roman numerals corresponding to a Russian sentence, which is the correct translation of sentence II.

If this task is solved correctly, then a machine translation of all the sentences from task 1 into Russian has been carried out: all that remains is to write the proven words into the corresponding cells of machine memory and enter the program from task 3 into the machine. But this is not enough. It is necessary to come up with such rules, create such a processing program and compile a dictionary so that the machine can translate any text. And this is where all those difficulties emerge, a very small and not the most “difficult” part of which we managed to talk about.
