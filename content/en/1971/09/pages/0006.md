Before considering the circuits that make it possible to implement the operation of the adder in accordance with the table given, let’s get acquainted with the so-called logical operations *), defined on a set of two elements: 0 and 1.

1. The “or” operation (also called logical addition). The result of this operation is equal to one if at least one term is equal to one. Denoting this operation with the sign √, we get the table:

$$0\vee0=0, 0\vee1=1\vee0=1, 1\vee1=1.$$

2. Operation “and” (otherwise known as logical multiplication). Its result is one if both components are ones. This operation is denoted by ∧:

$$0\wedge0=0, 0\wedge1=1\wedge0=0, 1\wedge1=1.$$

3. The operation of “negation” is denoted by the sign ∗. It converts one to zero and vice versa:

$$\neg0=1, \neg1=0.$$

*) See, for example, «Kvant» No. 4, -1971, p. 14.
