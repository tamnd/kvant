Recall also that the rotation angle $\varphi$ varies in radians. Then the angular velocity changes in radians per second ($\dot{p}_{\text{rad}} / \text{сек}$). The unit of angular acceleration is radian divided by second squared ($\dot{p}_{\text{rad}} / \text{сек}^2$).

The description of the rotational motion, however, is incomplete if we know only the numerical values ​​of the above angular quantities. To fully describe rotation, you also need to know around which axis and in which direction (clockwise or counterclockwise) the body rotates. Both will be determined if we consider both the angle of rotation and angular velocity to be a kind of vector quantities. It is generally accepted that the vector $\varphi$, as well as the vector $\omega$, is directed along the rotation axis, so if a vector of one of these quantities is given, then the rotation axis is also given. For example, rotation is determined by the so-called gimlet-corkscrew rule or the screw rule (this is far from the only case in physics when one has to resort to the “services” of such a device). It is as follows: if you mentally rotate the hand of a gimlet in the same way as the body is rotated, then the direction of the translational movement of the gimlet will show the direction of the angular velocity vector $\omega$. If, for example, the red arrow on figure 1 represents the vector $\omega$ for a rotating disk, then this means that the disk is rotating as shown by the yellow arrow. As usual, the length of the vector on the depicted scale gives us the numerical value of the corresponding angular magnitude.
