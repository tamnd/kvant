They called their method the simplex method. We will now describe the geometric idea of ​​the simplex method as applied to our three-dimensional problem. In fact, when using the simplex method, the problem is transformed by introducing some additional unknowns, which makes it possible to simplify the solution process from an algebraic point of view. However, to preserve geometric clarity, we will not do this.

So let's start from the top
$$O = (0, 0, 0),$$

of whose existence we are sure, and consider the edges of the polyhedron $A$ emerging from this vertex. Let $P$ be the second end of one of these edges. Function value
$$f(x) = x_1 + x_2 + x_3$$

at point $P$ is greater than at O. Let us now consider all the edges of the polyhedron $A$ extending from point $P$. When moving from point $P$ along some of these edges, the value of function $x_1 + x_2 + x_3$ may kill or remain constant. We will immediately discard these edges and select one of the edges, when moving along which the value of the function $x_1 + x_2 + x_3$ increases. Let $P'$ be the second end of this edge. The value of the function $x_1 + x_2 + x_3$ at vertex $P'$ is greater than at vertex $P$. Let's consider all the edges leaving the point $P'$ and select some edge $P'P''$, when moving along which the value of the function $x_1 + x_2 + x_3$ increases, etc.

At each step we will obtain a vertex of the polyhedron $A$, in which the value of the function $x_1 + x_2 + x_3$ is greater than in the previous ones. In the end we will come to such a peak
$$M = (x_1^0, x_2^0, x_3^0),$$
that when moving along any edge emerging from this vertex, the values ​​of the function $x_1 + x_2 + x_3$ will not arise. This means that the plane
$$x_1 + x_2 + x_3 = x_1^0 + x_2^0 + x_3^0,$$

support to the polyhedron $A$ and $M$ is one of the solutions to the linear programming problem. To find other solutions, you need to find edges coming out of $M$ such that when moving along which the value of the function $x_1 + x_2 + x_3$ remains constant.

If there are no such edges, then $M$ is the only solution to the problem.

If there is one such edge, then the solutions to the problem are all points of this edge. If there are two edges, then all points of the face in which these edges lie serve as solutions.

Most often, three edges emanate from each vertex of the polyhedron $A$. In this case, at each step it is easier to check only two edges (since the edge on which the previous vertex lies can be immediately discarded). If along these common edges the function values ​​are at two vertex positions and select the one in which this value is greater. If there are more edges emanating from a vertex, along which the function values ​​are in two positions of the vertices, then select the one in which this value is greater. If there are more edges emanating from a vertex, along which the function values ​​are in two positions of the vertices, then select the one in which this value is greater. This method may turn out to be more economical from a computational point of view, since it does not require first finding the ends of all edges emanating from a given vertex.

All geometric concepts that turn out to be useful when considering linear programming problems with two and three variables (line, plane, parallelism, convex set, support straightness, etc.) can be formulated purely algebraically in the language of equations and inequalities. When using this language, unlike geometric, as a rule, there will be no significant differences between the cases of two, three and a large number of transformations.
