Obviously, the linear function $f(x) = x_1 + x_2 + x_3$ reaches a maximum on the polyhedron $A$ at all points of intersection of the polyhedron $A$ with the plane $x_1 + x_2 + x_3 = K_0$. As you can see, in the family of parallel planes given by equations (5), there are two planes supporting the polyhedron $A$, one of which corresponds to the minimum, and the other to the desired maximum of the function $x_1 + x_2 + x_3$ on $A$. The intersection of a convex polyhedron with a reference plane can consist of either a single vertex of the polygon, or points of some edge of the polyhedron, or points of some face of the polyhedron. Each of these three cases can happen in our situation.

Further, more than three planes intersect at a vertex; you can select three of these planes, the intersection of which consists only of this vertex. The coordinates of the intersection point of three planes can be found by solving the system of equations given by these planes.

So, you can search for the vertices of the polyhedron $A$ as follows. It is possible to compose all body triples of equations from $(n+3)$ equations (6). (The number of such tracks is $\frac{(n+3)(n+2)(n+1)}{6}$).

Each triple can be considered as a system of three linear equations with the third unknown. If a solution $(x_1, x_2, x_3)$ of this system exists and is unique, then it is necessary to check whether the remaining $n$ inequalities of system (2) are satisfied for the numbers $x_1, x_2, x_3$. If the inequalities are satisfied, then the point $(x_1, x_2, x_3)$ is the vertex of the polyhedron $A$. After this, to solve the linear programming problem, it is enough to compare the values ​​of the functions $f(x) = x_1 + x_2 + x_3$ in all the resulting vertices and select those in which this value is the most accurate. This procedure involves quite a lot of computational work, especially if $n$ is large enough.

In fact, the solutions to the majority of the system will not be the vertices of the polyhedron $A$, and, in addition, to solve a linear programming problem it is not necessary to know all the vertices of the polyhedron. Therefore, such an indefinite search is not used when solving a linear programming problem.
