Many readers «Kvant» apparently have some idea of ​​what electric computers can do. It is even more interesting to get acquainted with how they do it.

Note that different machines are not required to perform different tasks: electric computers are universal, that is, a new task does not require a new machine, but a new program for it. Programs, methods of composing and recording them will be discussed in this article.

Any electrical computer includes
1) input and output devices;
2) storage devices (in short: memory);
3) arithmetic devices (or simply arithmetic);
4) control device (control).

Input and output are intended for “communication” between a person and a machine. They allow you to “tell” the machine the source data and the method for processing it (that is, the program) and “learn” from the machine the results obtained. The machine's memory stores all the necessary information: initial data, intermediate and final results, and, of course, the program.

Arithmetic is used to perform operations on numbers that come there from memory (basically these are general arithmetic operations, which explains the term). Finally, the control manages the process of solving the problem itself: it recalls information about the next operation from memory and deciphers it, sends the necessary numbers from memory to arithmetic and sends the result back to memory.
