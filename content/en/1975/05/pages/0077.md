Let us apply this method in a number system with any base. Try to understand how it will look in the case of a system with base $q$. (Of course, this task applies only to those who know what a system with a base $q$ is. If you don’t know this, I advise you to read the article “Number Systems”, published in «Kvant» No. 6 for 1970.) By the way, on abacus you can also perform arbitrary operations with numbers not written in the decimal system. For example, when counting with double numbers, you need to use the leftmost bone in each row, with triple numbers - two

left bones and so on. When working with decimal numbers, you can bypass nine tiles, and all ten tiles are needed only for the same-quaternary number system.

A great practice exercise in abacus addition involves this number trick. You write the “magic” number 12,345,679 and ask someone present to name any number. Let's say the number 7 is named. Then you propose to multiply the magic number by 63. It turns out - presumably to everyone's amusement - that the product consists of only sevens (to determine the multiplier, you simply need to multiply the named number by 9).

Here's how to use this "magic" number for an abacus exercise. Put 12,345,679 on the accounts and add the same number to it eight times. If you did not make any mistakes during these additions, then you will receive a number on the abacus consisting of only units. Add the magic number nine more times to get a number of twos, and nine more times to get a number of threes. Finally, after 80 additions you should end up with a number that is all nines. This exercise is replaced by the fact that with its help it is easy to check the accuracy of work at each of the nine stages.

In addition to 12,345,679, there are also an infinite number of “magic” numbers. For example, $37 \times 3 \times d$, where $d$ is a single-digit number, consists of only $d$. The lowest magic number for seven is 15,873; for 13 - 8 547, for 99 - 1 122 334 455 667 789. Find the most constant smallest “magic” number for 17. Try to figure out for which numbers you can specify a “magic” number, and for which you cannot.
