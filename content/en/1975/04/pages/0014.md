$$M_2\left(\sqrt{\frac{y_2}{a}}, y_2\right) \text{ и } M'_2\left(\sqrt{\frac{y_2}{a'}}, y_2\right)$$
The one with the larger coefficient is closer to the axis of symmetry. This means that the smaller $a$, the wider the parabola, the larger $a$, the narrower the parabola. Figuratively, we can call the number $a$ the “thinness coefficient” of the parabola.

Disadvantages of analytical definition

The definition of parabolas as the graph of a quadratic function can be called analytical, since it uses computational tools *). With this definition, a coordinate system is added to the parabola, which is not at all necessary when first getting acquainted with the curve. Analytical
