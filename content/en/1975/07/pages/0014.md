Such features are called knot invariants *).

Most of the known invariants are quite difficult to define and calculate.

The most studied and convenient of algebraic invariants - the knot group - is calculated according to precisely described rules, which, in principle, can be memorized by any high school student; however, to understand both these rules and (which, of course, is more important) the very definition of node groups, you need to know the beginning of topology and algebra calculations. Using the node group, one usually proves that a node is non-trivial or that two nodes are not equivalent.

*) Invariant (a word of Latin origin) - unchanging, independent of form.

It is all the more interesting to get acquainted with the simplest numerical invariants, including the minimum number of crossings and the genus of the knot. For fairly simple nodes, the values ​​of these invariants can be found immediately from the node diagram; but it is usually very difficult to prove that the found number is the value of the invariant.

A. Minimum number of node crossings

From all the diagrams (see § 2) of node B, we choose the one for which the number of crossings is minimal. This number M (B) is called the minimum number of crossings of node B.

Pravante has 4.1. Prove that M(A) = 0 if and only if the node A is trivalent.

2. Prove that there are no nodes A for which M(A) = 1 or M(A) = 2.

3. In § 5 it was already mentioned (although I did not prove it) that a circle, a clover leaf and an eight are not pairwise equivalent. Using this, prove that the equalities M (A) = 3 and M (B) = 4 are satisfied if and only if node A is equivalent to a klever leaf, and node B is equivalent to an eight. Thus, we obtained comprehensive information about nodes with a minimum number of crossings not exceeding 4.
