## Incident at the Olympics

The school Olympiad has just ended. The first task is always the easiest, but this time there was controversy even over the answer. The condition of the first problem said: *Find all values ​​of the parameter a for which the equation* $x^2 - |x| + a = 0$ *has a single root.*

“I solved the problem like this,” said student Krestikov. — It is known that $x^2 = |x|^2$, so instead of the given

This equation can be written as follows:

$$|x|^2 - |x| + a = 0.$$

Since it is square with respect to $|x|$, there can only be a single root in the case when the discriminant is equal to zero, that is, for $a = \frac{1}{4}$. So, $a = \frac{1}{4}$.

“Not at all,” said student Nulikov. “Look how I decided.” Let this equation have root $x_0$. It is clear that $-x_0$ will also be its root. And in order for there to be a unique root, it is necessary that $x_0 = -x_0$. This is only possible with

$x_0 = 0$. Substituting this value of $x$ into the equation, we see that $a = 0$, not $\frac{1}{4}$!
