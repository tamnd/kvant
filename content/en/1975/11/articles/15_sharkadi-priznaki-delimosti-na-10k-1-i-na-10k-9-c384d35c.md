⟦folio 44⟧

Several signs of divisibility

Justify the statements made below.

1. Add up all the digits of the number that are in even places, counting from the right. Add the number of tens of the resulting number with the decimal number of units of this number and with the sum of the digits in the odd places of the initial number. The result will also have the same remainders when divided by 3, 9, 11, 33 and 99 as the original number.

A. Vaimtkavicius.

2. Test for divisibility by numbers 10k+1. Cross out the last digit of this number and subtract this digit multiplied by k from the resulting number. With the resulting number, continue the same operation, and so on. If after a few steps a zero is obtained, then the number is divided by 10k+1. Write out the crossed out numbers from right to left. The resulting number is equal to the quotient. If zero is not obtained, the number is not divisible by 10k+1.

3. Test for divisibility by numbers 10k+9. Cross out the last digit of this number and add this digit multiplied by k+1 to the resulting number. With the resulting number, continue the same operation, and so on. If after a few steps a zero is obtained, then the number is divided by 10k+9. Write down all the crossed out digits from right to left and subtract the resulting n-digit number from 10^n. The result will be equal to the quotient.

If the number 10k+9 is not obtained, then this number is not divisible by 10k+9.

B. Sharkady.
