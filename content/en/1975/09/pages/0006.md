The values ​​of the same quantities, changed in the moving reporting system, will be denoted with the characters $(E_x', B_x')$, etc.). The relative theory gives the following relationships between these values:

$$E_x' = E_x, \quad B_x' = B_x;$$

$$E_y' = \frac{E_y - vB_z}{\sqrt{1 - v^2/c^2}},$$

$$E_z' = \frac{E_z + vB_y}{\sqrt{1 - v^2/c^2}};$$

$$B_y' = \frac{B_y + \frac{v}{c^2}E_z}{\sqrt{1 - v^2/c^2}},$$

$$B_z' = \frac{B_z - \frac{v}{c^2}E_y}{\sqrt{1 - v^2/c^2}}.$$

We see that the values ​​of the directivity of the electric field and the magnetic field induction turn out to be different in different reporting systems. So, if in the system $K$ there is no magnetic field $(B_x = B_y = B_z = 0)$, then the electric field in the driving system of the report returns $1/\sqrt{1 - v^2/c^2}$ times and at the same time a magnetic field appears in it. the direction of the fields also changes. For example, if in system $K$ the electric field is directed along the $Y$ axis, then in $K'$ it may also have a projection onto the $Z$ axis (at $B_y \neq 0$).

Let's consider this example. Let us assume that in a stationary reporting system $(K)$ has a magnet that has created a magnetic field $B$, the induction lines of which are directed along the $Z$ axis, and there is no electric field. Then $B_z = B$, $B_x = B_y = 0$ and, in addition, $E_x = E_y = E_z = 0$. If $v \ll c$, then we can neglect $v^2/c^2$ in comparison with one and put $\sqrt{1 - v^2/c^2} = 1$. According to the first of formulas (3), we find that in the driving system of the report the electric field returns,

$$E_y = \frac{E_y' + vB_z'}{\sqrt{1 - v^2/c^2}}, \quad E_z = \frac{E_z' - vB_y'}{\sqrt{1 - v^2/c^2}};$$

$$B_y = \frac{B_y' - \frac{v}{c^2}E_z'}{\sqrt{1 - v^2/c^2}}, \quad B_z = \frac{B_z' + \frac{v}{c^2}E_y'}{\sqrt{1 - v^2/c^2}}.$$
