Proof of Lemma 1. Let us prove Lemma 1 by contradiction. Let equation (4) have a root $q$ in the field $Q$. Then, by Lemma 2, the number $q$ satisfies the system of equations
$$x^3 + ax^2 + bx + c = 0,$$
$$x^2 + dx + e = 0.$$
(4') Multiplying equation (4') by $(x + a - d)$, subtract it from equation (4). We get $[b - e - (a - d)d]x + [c - (a - d)e] = 0$. Let's denote the first bracket by $f$, and the second by $g$. Then $fq + g = 0$. If $f \neq 0$, then $q = -g/f$ belongs to the field $P$, which contradicts the condition. If $f = 0$, then $g = 0$, which means
$$x^3 + ax^2 + bx + c - (x + a - d) \times (x^2 + dx + e) = fx + g = 0$$
that is
$$x^3 + ax^2 + bx + c = (x + a - d) + (x^2 + dx + e).$$
No then equation (4) has a root $q = d - a$ belonging to the field $P$, and this is a question of the condition.

The resulting contradiction proves Lemma 1, and with it Theorem 2.
