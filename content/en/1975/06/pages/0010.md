9. Proof of Theorem 2

Let's divide the basic operations into simple ones - complex ones, subtraction, multiplication and division, and complex ones - extracting the square root.

Let there be a certain set of numbers. Let's consider all the numbers that can be obtained from them using a finite number of simple operations.

Definition. If we denote the original set by $M$, then the resulting set $P$ is called the field generated by $M$.

It is clear that if the numbers $z$ and $t$ belong to the field $P$, then the numbers $z + t$, $z - t$, $zt$ and $z/t$ (with $t \neq 0$) also belong to $P$.

Examples. A. The set $M$, consisting of one number 1, generates a field of rational numbers.

B. The set $M$, consisting of all rational numbers and the number $\sqrt{2}$, generates a field $P$, which includes all numbers of the form $a + b\sqrt{2}$ (where $a$ and $b$ are rational) and only them. Check this by paying special attention to the division. Note that the same field $P$ is generated by two numbers: 1 and $\sqrt{2}$.

Exercise 10. Does $\sqrt{3}$ belong to field $P$ from Example B?

Let $x$ be some number that can be expressed in terms of 1 using a finite number of base actions. This means that there are numbers $x_1, \ldots, x_n$, where $x_1 = 1$, $x_n = x$, and each number $x_k$ ($1 < k \leq n$) is expressed through the previous ones using one basic action. For example, for $x = \sqrt{2} - 5\sqrt{3}$ you can take $x_1 = 1$, $x_2 = 1 + 1 = 2$, $x_3 = \sqrt{2}$, $x_4 = 1 + 2 = 3$, $x_5 = \sqrt{3}$, $x_6 = 2 + 3 = 5$, $x_7 = 5\sqrt{3}$, $x_8 = \sqrt{2} - 5\sqrt{3} = x$.

Let's construct a chain of fields $P_1, \ldots, P_n$, where $P_k$ is the field generated by the set of numbers $x_1, \ldots, x_k$. In this chain, for each field $P_k$ there are two possibilities:

1. If $x_k$ belongs to $P_{k-1}$, then $P_k$ is the same as $P_{k-1}$.
2. If $x_k$ does not belong to $P_{k-1}$, then $P_k$ is generated by a set, which is obtained by adding the number $x_k$ to the field $P_{k-1}$ (in this case, $x_k^2$ necessarily belongs to $P_{k-1}$).

From the above it is clear that to prove Theorem 2 it is enough to establish the following.

Lemma 1. Let the number $s$ not belong to the field $P$, $s^2$ belong to $P$, and $Q$ be the field generated by the set, which is obtained by adding the number $s$ to $P$. Let the equation

$$x^3 + ax^2 + bx + c = 0$$

with coefficients belonging to $P$ has no roots in the field $P$. Then it has no roots in the field $Q$.

Before proving this lemma, let us describe how the field $Q$ is structured.

Lemma 2. Any number $q$ from the field $Q$

1) represented as $q = p_1 + p_2s$, where $p_1$ and $p_2$ belong to $P$,
2) satisfies the quadratic equation $x^2 + dx + e = 0$ with coefficients $d$ and $e$ belonging to $P$.

Proof of Lemma 2.

1) It is clear that all numbers of the form $p_1 + p_2s$ belong to $Q$. To prove that there are no other numbers in $Q$, it is enough to check that simple operations on numbers of the form $p_1 + p_2s$ again belong to numbers of the same type. This follows from the formula

$$(p_1 + p_2s) \pm (r_1 + r_2s) = (p_1 \pm r_1) + (p_2 \pm r_2)s,$$

$$(p_1 + p_2s) \cdot (r_1 + r_2s) = (p_1r_1 + p_2r_2s^2) + (p_1r_2 + p_2r_1)s$$
