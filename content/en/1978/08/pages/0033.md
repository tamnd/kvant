But (this is where you have to be a little patient!)
$$\sin 3\beta = \sin (2\beta + \beta) = \sin 2\beta \cos \beta + \cos 2\beta \sin \beta = 2\sin \beta \cos^2 \beta + (1 - 2\sin^2 \beta) \sin \beta = 2\sin \beta (1 - \sin^2 \beta) + \sin \beta - 2\sin^3 \beta = 3\sin \beta - 4\sin^3 \beta.$$

The last expression can be further transformed as follows:
$$\sin 3\beta = 3\sin \beta - 4\sin^3\beta = 4\sin \beta \left[ \frac{3}{4} - \sin^2 \beta \right] = 4\sin \beta \left[ \left( \frac{\sqrt{3}}{2} \right)^2 - \sin^2 \beta \right] = 4\sin \beta \left[ \sin^2 60^\circ - \sin^2 \beta \right] = 4\sin \beta (\sin 60^\circ + \sin \beta) (\sin 60^\circ - \sin \beta) = 4\sin \beta \cdot 2\sin \frac{60^\circ + \beta}{2} \times \cos \frac{60^\circ - \beta}{2} \cdot 2\cos \frac{60^\circ + \beta}{2} \sin \frac{60^\circ - \beta}{2} = 4\sin \beta 2\sin \frac{60^\circ + \beta}{2} \cos \frac{60^\circ + \beta}{2} \times 2\sin \frac{60^\circ - \beta}{2} \cos \frac{60^\circ - \beta}{2} = 4\sin \beta \sin (60^\circ + \beta) \sin (60^\circ - \beta).$$

Substituting this expression for sin 3β into the formula for n, we get $n = 4d \sin \alpha \sin \beta \sin (60^\circ + \beta)$.

It is proved in exactly the same way that
$$m = 4d \sin \alpha \sin \beta \sin (60^\circ + \alpha).$$

Let us now apply, as we intended, the cosine theorem to $\triangle CXY$:
$$z^2 = |XY|^2 = m^2 + n^2 - 2mn \cos \gamma = 16d^2 \sin^2 \alpha \sin^2 \beta [\sin^2 (60^\circ + \alpha) + \sin^2 (60^\circ + \beta) - 2\sin (60^\circ + \alpha)] \times \sin (60^\circ + \beta) \cos \gamma.$$

Note now that $(60^\circ + \alpha) + (60^\circ + \beta) + \gamma = 120^\circ + (\alpha + \beta + \gamma) = 120^\circ + 60^\circ = 180^\circ$; therefore there is $\triangle EFG$ with angles $\widehat{E} = 60^\circ + \alpha$, $\widehat{F} = 60^\circ + \beta$ and $\widehat{G} = \gamma$ (Fig. 7).

Let us assume that the diameter δ of the circle circumscribed around this triangle is equal to 1. Then, by virtue of the sine theorem, the sides of the triangle will be equal
$$e = |FG| = \sin (60^\circ + \alpha), f = |EG| = \sin (60^\circ + \beta) и g = |EF| = \sin \gamma.$$
Applying the cosine theorem to this $\triangle EFG$, we find that
$$\sin^2 (60^\circ + \alpha) + \sin^2 (60^\circ + \beta) - 2\sin (60^\circ + \alpha) \sin (60^\circ + \beta) \cos \gamma = e^2 + f^2 - 2ef \cos \gamma = g^2 = \sin^2 \gamma.$$
Thus, we get that
$$z^2 = 16d^2 \sin^2 \alpha \sin^2 \beta \sin^2 \gamma$$
and, therefore,
$$z = 4d \sin \alpha \sin \beta \sin \gamma.$$
But expressions for length y = |XZ| and x = |YZ| segments XZ and YZ are obtained from the expression for the length z of the segment [XY] by cyclically rearranging the angles α, β and γ. And since the angles α, β and γ enter the expression for z symmetrically, then x = y = z = 4d \sin \alpha \sin \beta \sin \gamma - and, therefore, $\triangle XYZ$ from the side of length x, y and z is equilateral.
