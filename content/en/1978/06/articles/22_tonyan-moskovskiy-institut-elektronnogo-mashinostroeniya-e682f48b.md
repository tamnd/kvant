Moscow Institute of Electronic Engineering

Mathematics

Option 1
1. What does $a \geq b$ mean? Prove that if $a > b$ and $b \geq c$, then $a > c$.
2. Find the area of ​​triangle $ABC$ if the coordinates of its vertices are given: $A (3; -1)$, $B (1; -3)$, $C (-6; 6)$. Indicate all plane movements that cause triangle $ABC$ to map onto itself.
3. Solve the equation
$$\sqrt{1 - \sqrt{2}} \sin x + 2 \cos x = 0.$$
4. Solve inequality
$$4^x - 2^{x+1} - 3 < 0.$$
Is it true that $\sqrt{2}$ is its solution?
5. Let $f(x) = f_1(x) + f_2(x)$, where $f_1(x) = 2x - \sqrt{9 - x^2}$, $f_2(x) = \log_1(x^2 + x - 2)$.
Find the domain of definition of the functions $f(x)$, as well as the highest and highest values ​​of the functions $f_2(x)$ on the interval [3; 6].

Option 2
1. The surgical department employs 40 doctors. In how many ways can they form a brigade consisting of:
a) surgeon and assistant;
b) a surgeon and 4 of his assistants?
2. The points $A (-6; 3)$, $B (-7; 7)$, $C (-3; 6)$ and $D (-2; 2)$ are given on the plane. Prove that the quadrilateral $ABCD$ is a rhombus and calculate its area. Indicate all movements of the plane at which the rhombus $ABCD$ is mapped onto itself.
3. Solve the equation
$$\sqrt{4 - \sqrt{3}} \cos x + \frac{3 \sqrt{2}}{2} \sin x = 0.$$
4. Solve inequality
$$\frac{2^{x+1} - 5 \cdot 3^x}{2^x - 3^{x+1}} < 1.$$
Is it true that $\lg \frac{1}{32}$ is its solution?
5. The function $f$ is given by the formula
$$f(x) = \frac{|3x - 4| + 2x^2 - 4x - 1}{|2x + 1| - 2};$$

a) find the domain of definition of the functions $f$;
b) find an arbitrary function $f$ in the interval $- \infty; -2 [$; what is $f' (-4)$ equal to?
b) does the function $f$ have a limit at $x \rightarrow \frac{1}{2}$ and at $x \rightarrow -\frac{3}{2}$?
d) at what value $a$ is the function $g$ specified by the rule
$$g(x) = \begin{cases} f(x), \text{ если } x \neq \frac{1}{2}, \\ a, \text{ если } x = \frac{1}{2}, \end{cases}$$

has an arbitrary one at the point $x = \frac{1}{2}$?
Option 3
1. Given a system of inequalities
$$\begin{cases} 2x - y > a, \\ 3x + 2y > 3a. \end{cases}$$
a) for $a = 0$ one solution of the system would be indicated;
b) is it true that all solutions of this system satisfy the inequality $5x + y > 4a$?
b) is it true that all solutions of this system satisfy the inequality $x + 3y > 2a$?
2. When the coordinate plane is rotated through an angle $\alpha$ with the center at point $M$, point $A (2; 3)$ goes to $A_1 (5; 2)$, and $B (2; 5)$ to $B_1 (7; 2)$. Find the image of point $C (2; 4)$. Find the image of another point (your choice). Find the magnitude of the angle $\alpha$ and the coordinates of the point $M$.
3. Solve the equation
$$\sqrt{3 - 5 \cos x - 7 \sin^2 x} + \cos x = 0.$$
4. Solve inequality
$$\frac{x - 1}{9} - 3^{x-1} \log_2 56 + \log_2 7 < 0.$$
Is it true that $\frac{1}{\lg 9}$ is its solution?
5. The function $f$ is given by the formula
$$f(x) = a \ln x - 3x^2, \text{ где } a > 0.$$
a) Find the maximum value and monotonicity intervals of the functions $f$;
6) for $a = 32$ find at least one solution to the inequality
$$f(x) > 0;$$
b) for which $a$ does the inequality $f(x) > 0$ have at least one solution?
d) prove that for $a < 300$ the graph of function $f$ does not intersect with the graph of functions $g$ given by the formula
$$g(x) = \frac{18a - 3x^2}{2}.$$
Is this statement true for $a = 400$?
