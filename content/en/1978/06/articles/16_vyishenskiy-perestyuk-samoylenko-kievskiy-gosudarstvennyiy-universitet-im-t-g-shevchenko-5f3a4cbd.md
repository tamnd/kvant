Written exam option
Faculty of Mechanics and Mathematics

1. A cylinder is inscribed in a regular quadrangular paramid, the side faces of which are inclined to the plane of the base at an angle φ (one base of the cylinder lies in the plane of the base of the paramid, and the circle of its second base has one common point with each side face). The radius of the base of the cylinder and its height are equal to r. Calculate the volume of the paramid. At what value of the angle φ is the volume of the paramid the smallest?

2. Calculate the area of ​​a figure bounded by function graphs

$$y = \frac{|4 - x^2|}{4} \text{ и } y = 7 - |x|.$$

3. Solve inequality

$$\sqrt{\log_2^2 x + \log_1 x^2 - 3} > \sqrt{5}(\log_4 x^2 - 3).$$

4. How many four-digit numbers are there whose decimal notation contains no more than two different digits?

Faculty of Physics

1. A regular triangular paramid with height H is described around a ball of radius r. Calculate the area of ​​the lateral surface of the paramid. At what H is this area the smallest? Find the smallest area value.

2. For what values ​​of x is the derivative function

$$y = \sin 2x + 10\cos x - 6x$$

equal to zero?

3. Find the limit

$$\lim_{n \to \infty} \frac{n\sqrt{1 + 3 + 5 + \dots + (2n - 1)}}{2n^2 + n + 1}.$$

4. Two mutually perpendicular lines are given on a plane. Find the set of all those planes, the product of the distances from which to the given lines is equal to the sum of these distances.

Oral exam assignment

1. Solve the equation

$$\sin |x| = |\sin x|.$$

2. Solve inequality

$$\sqrt{4 - x^2} + \frac{1}{x} \geq 0.$$

3. How many roots does the equation have?

$$x^5 = 5x + 2a$$

depending on parameter a?

4. How many solutions does the equation system have?

$$\begin{cases} |x| + |y| = 1, \\ x^2 + y^2 = a \end{cases}$$

depending on parameter a?

5. Draw a point set in a rectilinear coordinate system

$$\begin{cases} (x; y) | \log \left( |x| - \frac{1}{2} \right) (x^2 + y^2) \leq \log \left( |x| - \frac{1}{2} \right)^4 \end{cases}$$

6. Find all values ​​of a for which the plurality

$$\{(x; y) | x^2 + y^2 + 2x \leq 1 \} \cap \{(x; y) | x - y + a = 0\}$$

contains only one point. Find this point.

7. Graph the function

$$y = \begin{cases} 1 - \sqrt{1 - x^2}, \text{ если } x \leq 1, \\ 1 + \log \frac{1}{2} x, \text{ если } x > 1. \end{cases}$$

8. Prove that the function

$$f(x) = \frac{2}{3} x^9 - x^6 + 2x^3 - 3x^2 + 6x - 1$$

increases monotonically on R.

9. Find all values ​​of a for which the function

$$f(x) = \frac{a^2 - 1}{3} x^3 + (a - 1) x^2 + 2x + 1$$

increases for all x ∈ R.

10. Let x₁ and x₂ be the correspondence, the maximum point and the minimum point

$$f(x) = 2x^3 - 9ax^2 + 12a^2x + 1.$$

At what a x₁² = x₂²?

11. For what a function

$$f(x) = \frac{a}{3} x^3 + (a + 2) x^2 + (a - 1) x + 2$$

has a negative minimum point?

12. At what values ​​of x is formed zero from first-different functions

$$f(x) = \pi \sin \pi x + 2x - 4,$$

which at x = 1 has the value 3?

13. Calculate the area of ​​a figure bounded by graphs of functions

$$y = 2 + \sin x \text{ и } y = 1 + \cos^2 x$$

on the interval [0; π].
