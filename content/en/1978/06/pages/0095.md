4. This equation is equivalent to a “mixed system”

$$\begin{cases} \sqrt{2x} = ax + 1, \\ x \neq \frac{1}{2}. \end{cases}$$

(1)

System (1) is equal to system

$$\begin{cases} 2x = (ax + 1)^2, \\ x \neq \frac{1}{2}, \\ ax + 1 > 0. \end{cases}$$

For $a = 0$, the equation $a^2x^2 + 2(a - 1)x + 1 = 0$ has a single root $x = \frac{1}{2}$. Therefore, for $a = 0$ system (2) has no solutions.

Let now $a \neq 0$. In this case, for $a > \frac{1}{2}$, equation $a^2x^2 + 2(a - 1)x + 1 = 0$, and therefore system (2), have no solutions.

For $a = \frac{1}{2}$ system (2) has a unique solution.

So let $a < \frac{1}{2}$ and $a \neq 0$. Let's put

$$x_1 = \frac{1 - a + \sqrt{1 - 2a}}{a^2},$$

$$x_2 = \frac{1 - a - \sqrt{1 - 2a}}{a^2}.$$

Then

$$ax_1 + 1 = \frac{1 + \sqrt{1 - 2a}}{a},$$

$$ax_2 + 1 = \frac{1 - \sqrt{1 - 2a}}{a}.$$

Substituting the equation $a^2x^2 + 2(a - 1)x + 1 = 0$ "forbidden root" $x = \frac{1}{2}$, we get $a = 0$ or $a = -4$. We have $a \neq 0$. At $a = -4$ we have $x_1 = \frac{1}{2}, x_2 = \frac{1}{8}$.

For $a \in \mathbb{R}$ $0; \frac{1}{2} \left[ \text{имеем } x_1 \neq \frac{1}{2}, ax_1 + 1 > 0 \text{ и } x_2 \neq \frac{1}{2}, ax_2 + 1 > 0 \right.$ it means that for such $a$ system (2) has 2 solutions.

At $a < 0$ $ax_1 + 1 < 0$, $ax_2 + 1 > 0$. We have already noted above that for $a \neq 0$ we have $x_2 \neq \frac{1}{2}$.

Answer. $\left\{ \frac{1}{2} \right\} \cup \left\{ -\infty; 0 \right\}$.
