M511. Inside the quadrilateral $ABCD$ there is a point $M$ such that $ABMD \leftarrow$ is a parallelogram. Prove that if $CBM = CDM$ then $ACD = CDM$. (8-9 grades)

Yu. Mikheev

M512. Let $f(x) = x^3 - x + 1$. Prove that for any positive integer $m > 1$ the numbers $m, f(m), f(f(m))$, $f(f(f(m)))$, ... are pairwise coprime. (10 grades)

A. Kolotov

M513*. Prove that there is a number $A$ such that at least 1978 pairwise incongruent squares can be written in the graph of the function $y = A \sin x$. (A square is called inscribed if all its vertices belong to the graph.) (10 cells)

V. Fedogov

M514*. Prove that there exists an infinite bounded sequence $\{x_n\}$ such that for any distinct $m$ and $k$ the following inequality holds:
$$|x_m - x_k| \geq |m - k|^{-1}.$$ (9, 10 grades)

S. Konyazin

M515. A finite set $K_0$ is given. To it are added all the points that can be obtained by symmetrically reflecting one point of this set relative to another. The resulting set is denoted $K_1$. Similarly, from the set $K_1$ we get $K_2$, from $K_2 \leftarrow K_3$, etc.

a) Let the set $K_0$ consist of $d$ in $x$ points $A$ and $B$ at a distance $1$. For what minimum $n$ in the set $K_n$ there is a point located at a distance of 10000 from the point $A$?

b) Let $K_0$ be a three-point $K_0 \leftarrow$ set of quadrilateral with area 1. Find the area of ​​the smallest convex polygon containing the set $K_n$ ($n = 1, 2 \ldots$). (8 grades)

In the next three paragraphs $K_0 \leftarrow$ is the set of a quadrilateral with area 1.

b) Consider the smallest convex polygon containing all the points of the polygon $K_1$. How many and what kind of faces does this polygon have?
