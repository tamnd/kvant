Polish mathematician Jan Łukasiewicz proposed a convenient way to find the double number corresponding to a given tree (Fig. 4). Let's draw a tree with four top branches. The ends of these branches are marked with zeros, and the cubic vertices are marked with ones. Let's imagine a worm climbing up the trunk and walking around the entire tree along the dotted line (Fig. 4). At each vertex of the worm there is a mark. However, the announced label is not called a second time. In our example, the worm will announce the labels 1101000, giving the same double number that corresponds to the placement of brackets in the expression corresponding to this tree.

In 1964, it was discovered that the number of arbitrary rooted trees with $n$ edges is also equal to the $n$ Catalan number. Such trees have only $n$ vertices, not counting the root, but the vertices can have any degree.

There are many ways to establish a one-to-one correspondence between such trees and rooted cubic trees. The simplest method was indicated by Frank Barnhart (Fig.5). Let's redraw the cubic trees so that each edge from the top is vertical upward or horizontal to the right.

Let's imagine that each horizontal edge (at figure 5 is the blue line) contracts to a point and disappears. If there is a cubic vertex at the right end of a horizontal edge, it is transferred to the left and merges with the vertex at the left end. All vertical edges remain distinct. This simple transformation takes all rooted cubic trees from $n$. End vertices into rooted trees with $n$ edges.

A worm crawling any tree from this new set (see figure 5, the right tree in each pala) will name the same double number as on the original tree if it changes its algorithm as follows. He starts not from the root, but from the lower peak. Every time the worm goes up an edge, it writes 1, and when it goes down, it writes 0.
