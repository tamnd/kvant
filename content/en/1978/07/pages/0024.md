Very simple recurrent formulas are obtained by placing one more unit in front of the row 1, 2, 5, 14, ... (We get the row 1, 1, 2, 5, 14...) Let $k$ be the last calculated Catalan number, and $n$ the number of the next number. Then this number is calculated by the formula

$$\frac{k (4n - 6)}{n}.$$

Euler's contemporary Johann Andreas von Segner obtained a mysterious recurrent formula for the Catalan sequence of the form 1, 1, 2, 5, ... Let's write all the already found Catalan numbers in a series, and raise them and write the same numbers in reverse order. Multiply each upper number by the corresponding lower number and add the resulting product; the result will be the next Catalan number. For example,

$$\frac{x \cdot 112514}{145211} = \frac{14+5+4+5+14}{42}$$

Euler's problem of polygon triangulation is in a sense isomorphic to problems that would seem to be completely unrelated to it. Eugene Charles Catalan himself, the Belgian mathematician after whom the sequence is named, solved the following problem in 1838. Let us have a string of $n$ letters arranged in a given order. It is necessary to arrange $n-1$ a pair of brackets in such a way that there are exactly two “expressions” inside each pair. These paired expressions can be either two adjacent letters, or a letter and an adjacent expression in parentheses, or two adjacent expressions. In how many ways can parentheses be placed?

For two letters $a, b$, there is only one possibility: $(ab)$. For three letters there are already two such possibilities: $((ab) c)$ and $(a (bc))$. For four letters, the number of ways increases to five: $((ab) (cd)), (((ab) c) d), (a (b (cd))), (a ((bc) d))$ and $((a (bc)) d)$.
