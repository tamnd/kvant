Let us now consider examples of calculating the limits of irrational functions. The following statements are used here:

A) The function $y = \sqrt{x}$ is continuous at any point $x > 0$ *).

B) If the function $f$ is continuous at the point $a$ and $f(a) > 0$, then the function $y = \sqrt{f(x)}$ is also continuous at the point $a$.

B) If the function $f$ is continuous at the point $a$ and $f(a) > 0$, then the function $y = \sqrt[n]{f(x)}$ is also continuous at the point $a$.

Let us prove statement B). To do this, we need, given a number $\varepsilon_0 > 0$, to find a number $\delta_0 > 0$ such that for any $x$ from the punctured $\delta_0$-neighborhood of the point $a$

$$| \sqrt{f(a)} - \sqrt{f(x)} | < \varepsilon_0.$$

Since the function $f$ is continuous at the point $a$, for $\varepsilon_1 = \sqrt{f(a)}\varepsilon_0 > 0$ there is a $\delta_1 > 0$ such that for any point $x$ from the punctured $\delta_1$-neighborhood of the point $a$

$$| f(x) - f(a) | < \sqrt{f(a)}\varepsilon_0.$$

As the exclusive number $\delta_0$ we take the above number $\delta_1$. Then

$$| \sqrt{f(x)} - \sqrt{f(a)} | = \frac{| f(x) - f(a)|}{\sqrt{f(x)} + \sqrt{f(a)}} \leqslant \frac{| f(x) - f(a)|}{\sqrt{f(a)}} < \frac{\sqrt{f(a)}\varepsilon_0}{\sqrt{f(a)}} = \varepsilon_0,$$

and continuity has been proven. Note that from B) it immediately follows A) (put $f(x) = x$).

We do not provide a proof of statement B), which is technically more complex.
