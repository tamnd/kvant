Of these cases, the natural one is, of course, the one where the function is defined at the point $a$ and takes on a value there that coincides with its limit at $x \rightarrow a$ (Fig. 3). This is also the function that is considered most often. They are called functions continuous at the point $a$.

So, the function $f$ is called continuous at the point $a$ if
$$\lim_{x \rightarrow a} f(x) = f(a).$$
If the function $f$ is defined in some punctured neighborhood of the point $a$ and equality (2) is not satisfied for one reason or another, the function $f$ is called discontinuous at the point $a$.

Thus, a function $f$ defined in a punctured neighborhood of the point $a$ will be discontinuous at the point $a$ if
1) $f$ is not defined at the point $a$ itself (for example, the function $f(x) = \frac{\sin x}{x}$ is discontinuous at point 0; see also Fig. 4);
2) the limit $\lim_{x \rightarrow a} f(x)$ exists, but is not equal to $f(a)$ (it is for this reason that the functions on figure 5 are discontinuous at the point $a$).
3) the limit $\lim_{x \rightarrow a} f(x)$ does not exist (for example, the function $f(x) = \frac{|x|}{x}$ and $f(x) = \frac{1}{x}$ are discontinuous at point 0; see also figure 6 and 7).
