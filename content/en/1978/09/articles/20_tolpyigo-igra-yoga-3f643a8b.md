Yoga game

The yoga game *) is intended for one person.

It consists of the following:

The 33-field board has the shape shown at figure 1; A chip is placed on each field, then one chip is removed; on each move, you can rip any chip through any neighboring one (horizontally or vertically) onto an empty field - in this case, the rummaged chip is removed; a whole toy - all the chips are off the board except one.

It is not difficult to check that, no matter what kind of chip we initially remove, it is possible to remove all the chips except one. From the symmetry messages it is clear that the check is sufficient for the case when the counters d1, d2, d3, d4, e1, e2, e3 are initially removed (Fig. 1 on page 3 of the cover). However, some of these cases are related to each other.

Let the d3 chip be removed first. Let us prove that when there is only one chip left on the board, it will be on one of the squares a3, d3, g3, d6.

Let's paint the board in three colors, as in figure 2. It is easy to notice that with each move the number of chips of some two colors decreases by 1, and the number of the third color increases by 1 (Fig. 3). This means that after each move the parity of the number of chips of each color is reversed.

In the initial position, we have 11 chips on the syn fields, 11 on the red fields and 10 on the white fields. We want one chip left - for this we need to make 31 moves. When the parity changes 31 times, we will have an even number of chips, an even number of red chips, and an odd number of white chips. Consequently, the only cooling chip will be on the white field.

tasks

1. On which fields can a chip remain if we first take the chip from field c1?

2. Let's paint the board as in figure 5. First, remove the chip from field c3. a) What is the number of “white” (i.e. standing on white fields) chips that must be eaten in order to destroy all the “black” chips? 6) What number of “black” chips must be eaten to destroy all “white” chips?

3. There are 81 chips placed in an 11×11 square, as in figure 6. Prove that, acting according to the rules of the game “yoga”, it is impossible to ensure that only one chip remains.

4. 64 pieces were placed on the chessboard and a piece was removed from square a1; on each move, you can rip any chip through two adjacent ones (horizontally or vertically) onto an empty field, removing both rummaged chips from the board. What number of chips can be achieved and how will these chips be located? How will the answer change if you fill all 64 fields with chips and add another field (empty) to the board next to cell a1?
