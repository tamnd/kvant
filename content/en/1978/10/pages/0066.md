⟦folio 64⟧

$$a + b = \lim_{n \to \infty} x_n + \lim_{n \to \infty} y_n.$$

The theorem has been proven.

Natasha's mistake is that for the number $\varepsilon$ she took the specific value 0.1 and moved from inequality (3) to inequality (4). She simply had to solve inequality (3), treating $\varepsilon$ as a parameter. Solving inequality (3), we obtain $\frac{2}{n} < \varepsilon$, whence $n > \frac{2}{\varepsilon}$. For the number $N$, let’s take some natural number no less than $\frac{2}{\varepsilon}$, that is, $N \geq \frac{2}{\varepsilon}$. Then for all $n > N$ will satisfy inequality (3). The number $N$ found in this way depends on $\varepsilon$. For each specific value $\varepsilon$ it is now easy to find “its own” number $N$. For example, for $\varepsilon = 0,1$ you can take $N = 20$, for $\varepsilon = 0,001 - N = 2000$, etc.

Note 1. If there is no number $N$, there is no need to find the minimum number, it is only important to indicate some one, starting from which inequality (5) will be satisfied. Therefore, finding it can be done “roughly”, “approximately”. Let's show this with an example.

Let it be necessary to prove that $\lim_{n \to \infty} \frac{n^2}{n^4 + 16} = 0$. Let $\varepsilon > 0$ be an arbitrary number. To find $N$ we need to solve the inequality

$$\left| \frac{n^2}{n^4 + 16} - 0 \right| = \frac{n^2}{n^4 + 16} < \varepsilon.$$

But this inequality is unwieldy. Therefore, we make an estimate: we discard the term 16 in the denominator of the fraction, replace the fraction $\frac{n^2}{n^4 + 16}$ with another $\frac{n^2}{n^4} = \frac{1}{n^2}$, which is obviously greater than the first, and solve the inequality

$$\frac{1}{n^2} < \varepsilon.$$

Hence $n > \frac{1}{\sqrt{\varepsilon}}$. If the natural number $N$ is chosen greater than $\frac{1}{\sqrt{\varepsilon}}$, that is, $N \geq \frac{1}{\sqrt{\varepsilon}}$, then inequality (9) will satisfy all $n > N$. Then $n > N$ will even more so satisfy inequality (8). Therefore, equality is required to be proven.

Note 2. One should not, however, think that $N$ necessarily changes when $\varepsilon$ changes. For example, for constant sequences the choice of number $N$ does not depend at all on the number $\varepsilon > 0$. Indeed, let $x_n = c$, where $c$ is a constant number. Then $\lim_{n \to \infty} x_n = c$. Let's prove it; let $\varepsilon > 0$ be an arbitrary number. Let us find a number $N$ such that for all $n > N$ the inequality $|x_n - c| < \varepsilon$ holds. But this inequality is always true, since $|x_n - c| = 0$. Therefore, the number $N$ can be taken as any natural number, in particular 1.
