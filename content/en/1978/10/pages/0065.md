What's the matter?
Natasha believed that the found number $N = 20$ was suitable for all $\varepsilon > 0$. But it turned out that it provides the necessary “closeness” of the members of the sequence $(x_n)$ to the number 5 only for the numbers $\varepsilon \geq 0,1$. For numbers $0 < \varepsilon < 0,1$ it is already “small”. For example, for $\varepsilon = 0,001$ the number $N$ can be taken as the natural number 2000. Indeed,

$$|x_{2001} - 5| = \left| \frac{5 \cdot 2001 - 2}{2001} - 5 \right| = \frac{2}{2001} \approx 0,0009,$$
which is less than 0.001. In other words, the inequality $|x_n - 5| < 0,001$ will hold for all $n > N = 2000$.

From a misinterpretation of the definition of a sequence limit. For example, his (“Algebra and the beginnings of analysis 9”, paragraph 21).

The number $a$ is called *the limit of the sequence* $(x_n)$ if for any positive number $\varepsilon$ there is a natural number $N$ such that for all $n > N$ the inequality holds
$$|x_n - a| < \varepsilon.$$ (5)

We have already seen that this is not the case with the sequence $x_n = \frac{5n - 2}{5}$. For $\varepsilon = 0,1$ the number $N$ is 20, and for $\varepsilon = 0,001$ this number is already “small”, for it 2000 is suitable, and for $\varepsilon = 0,000001 - N = 2000000$.

For a given sequence, the number $N$ depends on the number $\varepsilon$, that is, for each $\varepsilon > 0$ one should find “its own” number $N$ such that for $n > N$ inequality (5) is satisfied. Thus, the phrase “for any positive number $\varepsilon$ will find $N$” does not mean that it will find $N$ suitable for all positive numbers, but only for one, arbitrarily taken from the set of all positive real numbers. $\varepsilon$ is a randomly chosen number! Therefore, once $N$ is selected, changing $\varepsilon$ is not possible, no matter how much we would like to do so.
