5. Let $[KN] \parallel (SAD)$, $K \in [BD]$, $N \in [SC]$ (Fig. 6). Let's denote $|DK|:|DB|$ by $x$. Then $0 \leq x \leq 1$. Let's draw the segment $[KP]$ parallel to $[AD]$ ($P \in [DC]$). Since $[KNP] \parallel (ASD)$, we have $(PN) \parallel (SD)$. From the similarity of triangles $DKP$ and $DBC$ we obtain $|PK| = xa$, $|DP| = xa$. Since $|PC| = (1 - x)a$, from the similarity of triangles $PCN$ and $DCS$ we find $|PN| = 2(1 - x)a$. From $\triangle ASD$ cos $\widehat{SDA} = \frac{1}{4}$. Since $\widehat{NPK} = \widehat{SDA}$, we get cos $\widehat{NPK} = \frac{1}{4}$. From $\triangle KNP$ using the cosine theorem we find

$$|KN|^2 = (6x^2 - 9x + 4)a^2.$$ (1)

It is easy to see that the converse is also true: for any $x \in [0, 1]$ there is a segment $|KN|$ parallel to the plane $(SAD)$ such that $K \in [BD]$, $N \in [SC]$ and $|DK|:|DB| = x$. Thus, equality (1) defines the square of the length of the segment $KN$ as a function defined on [0;1]. Using an arbitrary function, find the smallest value of this function on the interval [0;1], we get $\min |KN|^2 = \frac{5}{8}a^2$. However, since the function we are studying is square, its smallest value can be found without an arbitrary one, if we take advantage of the fact that the function $\alpha x^2 + \beta x + \gamma$, which has $\alpha > 0$, takes the smallest value for

$$x = -\frac{\beta}{2\alpha}.$$ Answer. 1) $|MN| = \sqrt{\frac{5}{3}}a$; 2) $\min |KN| = \sqrt{\frac{5}{8}}a$.
