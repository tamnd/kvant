Having solved several problems, we will notice that all the resulting numbers have no more digits, and the leftmost - ninth - digit of the board is intended for the sign of the number: “-” lights up in it if the result is a negative number.

The calculator can calculate the values ​​of expressions with multiple operations. So, to add several numbers, you need to type the first addend, press the “+” key, then type the second addend, press “+” again, etc., and at the very end press “=”. The “,” and “/—/” keys are used to enter decimal fractions and change the sign of a number. If you need to type a decimal fraction, then first type its signs up to the decimal point, then press the “,” key, and then its remaining signs. To make the number sign “minus” first, you need to press the “/—/” key. For example, the table shows how to dial the number - 48.587.

So, the calculator can perform any arithmetic operations: it does it silently and almost instantly. Those who have to work on arithmetic will appreciate the advantages of “Electronics”.
But this is not all that can be considered about the device. It also quickly calculates the values ​​of many functions. From figure it is clear that in addition to the symbol placed indefinitely on the key, a certain designation is written above each key. Basically, these are designations of functions: logarithmic, trigonometric, etc. In order to calculate the values ​​of these functions, you need to use the “F” key.

Let, for example, you want to calculate $\sqrt{20,25}$. To do this, dial the number 20.25; it will be displayed on the display. Then you need to press the “F” and “V^-” keys (“V^-” is the same key as “9”), and then display the result on the display - the number 4.5.

Pay attention to the sequence of key symbols used to solve this problem:

«2» «0» «,» «2» «5» «F» «V^-»
