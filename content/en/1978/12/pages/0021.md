It turns out that using the concept of the definition of an integral (see “Algebra and Principles of Analysis 10” or «Kvant», 1977, No. 5) it is possible to prove that on a given interval one or another function vanishes.

Statement 3. If $\int_a^b f(t)dt = 0$ and the function $f$ are continuous on the interval $[a; b]$, then on this interval it takes values ​​of only one sign (see the remark at the end of paragraph 2). From the definition of the integral it follows that if the function $f$ is positive at all points of the segment $[a; b]$, then the interval from it on this segment is positive, and if $f$ is negative on $[a; b]$, then the interval from it is also negative.

Statement 3 has been proven.

Example. Let us prove that for any $\alpha, \beta, \gamma$ the function $f(t) = \alpha \cos t + \beta \cos 2t + \gamma \cos 7t$ has zero on the interval $[0; 2\pi]$. Indeed, one of the antiderivatives for the function cos $nt$ is the function $\frac{1}{n}\sin nt$. According to the Newton-Leibniz formula

$$\int_0^{2\pi} (\alpha \cos t + \beta \cos 2t + \gamma \cos 7t) dt = \left( \alpha \sin t + \frac{1}{2} \beta \sin 2t + \frac{1}{7} \gamma \sin 7t \right) \bigg|_0^2 = 0,$$

so the existence of zero for functions $\alpha \cos t + \beta \cos 2t + \gamma \cos 7t$ on the interval $[0; 2\pi]$ follows from Statement 3.

Lemma. a) Let $u, v$ be two mutually perpendicular vectors of the same length $R$ in space. Then the end of the vector

$$\vec{w}(t) = u \cos \omega t + v \sin \omega t$$

$$|\vec{w}(t)|^2 = |u|^2 (\cos \omega t)^2 + |v|^2 (\sin \omega t)^2 = R^2.$$
