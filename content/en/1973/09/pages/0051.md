Grade 9, task 3. The conditions of the problem also imply the following inequalities: $-1 \leq c \leq 1$; $-1 \leq a + b + c \leq 1$; $-1 \leq a - b + c \leq 1$. From the last two inequalities it follows that $-1 \leq a + c \leq 1$ and that $-1 \leq b \leq 1$. We will assume that $a \geq 0$. Indeed, if $a < 0$, then replace $a$, $b$ and $c$ with $-a$, $-b$ and $-c$ respectively; the new values ​​also satisfy the conditions of the problem, and the new $a$ (equal to $-a$) will be positive.

Let us now consider several cases.

1. $c \geq 0$. Then $|cx^2 + bx + a| \leq c + |b| + a$ at $|x| \leq 1$. But $c + |b| + a \leq 1$ (since $|b|$ is either $b$, or $-b$), and even more so $|cx^2 + bx + a| < 2$ with $|x| \leq 1$.

2. $c < 0$. Then $a + c \leq cx^2 + a \leq a$, Hence $a + c - |b| \leq cx^2 + a + bx \leq a + |b|$. But $-1 \leq a + c - |b|$, and $a + |b| \leq 1 - c \leq 2$. Thus, inequality $|cx^2 + bx + a| \leq 2$ always holds. In retrospect, we see that if for some $x_0$ the equality $|cx^2 + bx + a| = 2$ is satisfied, then $c = -1$, $cx^2 + bx + a = 2$ and $x_0 = 0$ (recall that we have $a \geq 0$), hence $a = 2$ and $b = 0$ (since $a + c = 1$).
