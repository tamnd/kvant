For $n = 1$ our statement is obviously true. (This is not surprising, however: if only one card is turned up with the number up, then, of course, we have one number in front of us.)

Let us now prove that if the statement $Y_n$ is true for $n = k$ (where $k$ is any integer from 1 to 99), then it is also true for $n = k + 1$.

Place the card number up $k + 1$ on the table. One card (let's call it $A$) is the symmetry of the table for a moment. There will be $k$ cards left on the table. On them (by induction assumption) the same number is written (some number $X$).

So, on all the cards - except, perhaps, $A$ - the number $X$ is written.

Let us now replace one of the $k$ cards on the table with the $A$ card. There are still $k$ cards on the table, which means, by induction, they all have the same number written on them (which we denoted above as $X$). Including the number $X$ written on the card $A$, which we first sat down and now returned to the table.

So, on the card $A$ the number $X$ is also written.

This means that all $n$ cards ($n = k + 1$) have the number $X$ written on them, which is what needed to be proven.

Thus, in terms of § 1, the statement $Y_1$ is true, and every true statement $Y_h$ ($1 \leq k \leq 99$) is followed by a true statement $Y_{k+1}$. Therefore, all statements $Y_n$ are true ($1 \leq n \leq 100$). And no matter how parasitic our trick with cards is, it is now bound to always work - this has been strictly proven!
