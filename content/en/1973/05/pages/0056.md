7.3. Given a linear inequality
$$\frac{8(2x+1)}{5} < 3x+2.$$
a) Solve the inequality in the domain of real numbers.
b) Specify the set (list the elements of the set):
1) the set $M_1$ of solutions to the inequality in the domain of natural numbers;
2) the set $M_2$ of solutions to the inequality in the domain of integers subject to the condition $-4 < x < 1$;
3) the set $M$ of all elements included in both the set $M_1$ and the set $M_2$.
