⟦folio 20⟧

The 1969 measurement is significantly less than in the 1963 measurements.

These measurements well illustrate the relationship that exists between the values ​​of fundamental constants: a significant change in the value of one of them entails noticeable changes in the values ​​of the remaining quantities.

It is also interesting to observe how our value of fundamental constants changes as physics develops. As a typical example, we present on figure 2 a graph that shows how the acceptance of the value of the electron mass has changed in the period after 1950. The values ​​of $m_e$ are indicated near each point (in units of $10^{-31}$ ke). The vertical bars indicate the errors assigned to this value.

The ordinate axis shows the relative deviations of the values ​​of $m_e$ from the value adopted in 1969.

This graph clearly shows that no set of fundamental constants can be taken as the ultimate truth. We can hope that the 1969 values ​​are closer to the truth than previous ones. However, being realists, we cannot answer that it is possible that further significant changes in the numerical values ​​of the constants may be required in the future. Here it is entirely appropriate to cite the words of Goethe: “Only he who does not strive for anything makes no mistakes.”

WHAT should we expect in the future? Is it possible to continuously improve measurements in order to use them to obtain more and more accurate values ​​of constants? Will theories be further improved, benefiting from refined values ​​of constants, so that ever more rigorous comparisons between theory and experience can be made? The answer to all these questions is, of course, positive. It can be considered a general rule that when existing methods reach their limit of possibility, new phenomena are discovered and experiment and physical theory receive a new impetus.
