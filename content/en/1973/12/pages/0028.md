WHAT NUMBERS ARE MORE?
Yu.P. Lysov

Which numbers are greater - natural or even? Where are there more points - on a segment or a straight line? Is it possible to find a set that has more elements than the given set? By elucidating these natural questions, Georg Cantor was involved in mathematics and reasoning, from which set theory grew - the foundation of the main branches of modern mathematics *).

In this and one of the next lessons of the mathematical circle, we will try to answer the questions that Kantor posed to himself.

What do we do if we answer the question with iron: are there more girls or boys in the class? We usually do this: we list girls, boys, and then compare the two numbers obtained. This method makes it possible to compare different finite sets. But do we always use it?

Imagine that you enter the auditorium of a cinema theater after the third bell and try to find out what is more numerous - the audience or the audience. Looking into the hall, you notice that all the spectators are sitting, and at the same time several seats remained free. The answer to the question is clear - there is more creSEL.

You have established a correspondence between the audience and part of the creSEL. This principle of mutual correspondence puts us in a position to compare infinite sets. (However, a similar correspondence was established in the first example with girls and boys.)

About the limit 1. A one-to-one correspondence between sets A and B is a rule that corresponds to each element of set A

*) This is described in more detail in the article by L. A. Kaluzhnin. To the 100th anniversary of set theory Georg Cantor, p. 2.

We associate one specific element of the set B, so that each element of the set B is associated with a number - k, belonging to the set B. It is easy to see that this correspondence is one-to-one.

The constructed correspondence shows that set A has the same number of elements as B. The result obtained is in good agreement with our visual representations.

Task 2. Establish a one-to-one correspondence between set A of natural numbers and set B of four numbers.

Let us associate the natural number n with the number 2n.

We find that there are as many natural numbers (A) as there are four numbers (B). But set B is entirely contained in set A. Is there an error here? There is no error.
