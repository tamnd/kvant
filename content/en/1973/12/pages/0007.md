Let us have two finite sets $M_1$ and $M_2$. The elements of the first set will be denoted by dogs, and the elements of the second set by cats. To compare these sets, they do this: they extract one element from each set and compare them with each other, forming pairs (see figure).

If dogs and cats end at the same time, then we say that there is a one-to-one correspondence between the sets $M_1$ and $M_2$ and that these sets contain the same number of elements (that they are numerically equal or equivalent). It is easy to imagine a different situation: some elements of the set $M_1$ were left without a guide. Then we should assume that the set $M_1$ contains more elements than the set $M_2$. It is obvious that the described procedure for comparing finite sets does not require the concept of “natural number”. On the contrary, the concept of one-to-one correspondence seems to be simpler, and it is possible to define the concept of “natural number” based on it.

Mathematicians and logicians over the past centuries (G. Fregg, B. Russell and others) have proposed doing this on the basis of approximately the following reasoning.

Let us divide all finite sets into classes in such a way that each class contains those and only those sets that are equivalent to each other, regardless of the nature of the elements forming the given set. Then the general property that characterizes all finite sets from any class is defined as the number of elements in the sets of this class. So, for example, 5 is the general property that all finite sets have, equivalent to the set of fingers of my right hand. From the above it is clear how to compare the numbers defined in this way “by size”. Let $m_1$ and $m_2$ be two natural numbers, and $M_1$ and $M_2$ be two sets that characterize these numbers. If $M_1$ and $M_2$ are nonequivalent and there is a one-to-one correspondence between $M_1$ and some part of the set $M_2$, then $m_1 < m_2$. Thus, we defined the concept of “natural number” and the properties of these numbers ($n_1 = n_2; n_1 < n_2; n_1 > n_2$).
