the idea that in the same way all infinite sets can be divided into classes.

All sets included in the same class, that is, having the same power, are called equal power.

Then all sets included in one class correspond to a certain number, which is called the cardinal number or cardinality.

From this it is clear that power is a generalization of the concept of a natural number.

The simplest example of an infinite set is the set $N$ of all natural numbers. Pozny Cantor began to compare various infinite sets with the set $N$. It soon became clear that for many infinite sets it is quite easy to establish a one-to-one correspondence with this set. Consider, for example, $N_2$, the set of all positive even numbers. Despite the fact that $N_2$ is part of $N$, a one-to-one correspondence can be established between $N_2$ and $N$: the number $2n$, included in the set $N_2$, is comparable to the number $n$, included in the set $N_1$. It is clear that such a correspondence will be one-to-one. At first, it seemed paradoxical to be able to establish a one-to-one correspondence between a set and its part: after all, for finite sets such a situation is impossible. But debate on this issue arose quite quickly - it was established that for an infinite set $A$ one can always specify a subset $B$ such that a one-to-one correspondence can be established between $A$ and $B$. Dedekind even proposed to consider this the definition of an infinite set.

Even more surprising was the fact that there is a one-to-one correspondence between the set of all positive rational numbers and the set $N$. Nevertheless, specifying such a correspondence is not so difficult. Try to do it yourself *).

The question naturally arises: are there infinite sets for which one-to-one correspondence with $N$ is impossible?

If there were no such sets, then all infinite sets would be of equal power, and the concept of a cardinal number (for infinite sets) would lose all meaning—it would be the same for all infinite sets.

In the early 1970s, Cantor suspected that an infinite set, not equal to the set $N$ of natural numbers, was the set $R$ of all real numbers (or even the set of all real numbers of any interval - say, the set of all numbers of the interval [0, 1]). But how can this be proven? Indeed, in all the cases considered above, the proof of the state in finding some operators of a well-defined one-to-one mapping. In this case, it is necessary to establish that constructing such a mapping is impossible. Statements of this kind are called “impossibility theorems,” and their proof usually requires squaring the circle and trisecting an angle, or proving the impossibility of solving algebraic equations of degree greater than four using the operations of addition, multiplication, subtraction, division, and taking roots of various powers).
