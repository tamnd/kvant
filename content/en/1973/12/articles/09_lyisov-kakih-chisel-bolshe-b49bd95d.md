WHAT NUMBERS ARE MORE?
Yu.P. Lysov

In this and one of the next lessons of the mathematical circle, we will try to answer the questions that Kantor posed to himself.

What do we do if we answer the question with iron: are there more girls or boys in the class? We usually do this: we list girls, boys, and then compare the two numbers obtained. Этот способ дает возможность сравнивать различные конечные множества. Но всегда ли мы им пользовемся?

Вы установили соответствие между зрителями и частю креSEL. This principle of mutual correspondence puts us in a position to compare infinite sets. (However, a similar correspondence was established in the first example with girls and boys.)

Definition 3. A set is called countable if it is equivalent to the set of natural numbers, that is, the elements of this set can be calculated into a string in accordance with the numbers assigned to them.

In the set of integers, each element has two “neighbors”. Maybe a set in which not every element can have a “neighbor” will have more elements than a countable set? Consider, for example, the set of proper fractions. For any two fractions a and b (a < b) there is a proper fraction

The hypothesis arises that all infinite sets are equivalent to the set of natural numbers. However, this is not true. Cantor's greatest achievement was the solution to the following problem.

Task 6. Prove that it is impossible to establish a one-to-one correspondence between the set of natural numbers and the set of infinite sequences of 0 and 1.

The solution to this problem is given on p. 8, but if you haven't read it yet, try solving the problem yourself. (The author of the article knows a large number of schoolchildren who solved it.)

So, we are convinced of the existence of uncountable sets, but this is the topic of one of the next busy circles, and now we will get acquainted with several more countable sets.

Task 7. The set of all possible Russian words is countable (we, of course, assume that each word consists of a finite number of letters).

Task 8. The set of all possible finite sets of integers is countable.

If we take into account that any equation of degree n has no more than n roots, then the solution to the following problem is easily obtained.

Task 9. The set of numbers, each of which is a solution to some equation with integer coefficients, is countable.

The set of numbers from task 9 is called the set of algebraic

In conclusion, we present to your attention more difficult problems.

Task 10. The set M consists of eights lying on the plane and not intersecting each other (an eight is a pair of tangent circles, each of which can be of any size). Prove that M is finite or countable.

It is easy to see that by placing a non-intersecting letter “G” or “O” on a plane, one can obtain an odd set. Is there any other letter that has the same properties as the number eight?

Task 11. The set M consists of the letter “T” lying on a plane and not intersecting the letter. Prove that M is finite or countable.

Having solved the previous problem, you can easily say about each letter of the Russian alphabet whether this letter can be on the plane in an odd number, or whether in any arrangement it forms no more than a countable set.

One more word: “Ether is liquid matter, like air, but not much thinner than it...”

It was generally accepted that the entire Universe is filled with ether, which penetrates into all bodies and serves as a medium transmitting light, just as air is a medium transmitting sound. The entire 19th century (especially its end) was devoted to attempts to build a theory of the ether. Only at the beginning of the 20th century did Einstein show that the existence of the ether is an unnecessary hypothesis that can be discarded without any harm. And so it was done. False confidence in the need for a medium for the transmission of light was so widespread that the ether hypothesis was used.
