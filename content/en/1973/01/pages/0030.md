M143. Let us find the smallest natural number $n$ for which the following conditions are satisfied:

if $n$ is divisible by $p - 1$ and $p$ is prime, then $n$ is divisible by $p$.

Let $n$ satisfy this condition. Since $n$ is divisible by 1 = 2-1, it must be divisible by 2, but then it is divisible by 3 = 2+1, 7 = 2 3+1, and 43 = 2 3 7+1. Therefore $n$ must be divisible by 1806 = 2·3·7·43.

Therefore, the minimum $n$ (if it exists) is not less than 1806. On the other hand, for 1806 the conditions of the problem are satisfied 1, 2, 3, 6, 7, 14, 21, 42, 43, 86, 129, 301, 1806. (5)

Now increasing each of them by one, we get:

2, 3, 4, 7, 8, 15, 22, 43, 44, 87, 130, 302, 1807. (6)

All that remains is to display all prime numbers from set (6) and make sure that they are included in set (5) (1807 is not prime, it is divisible by 13).

Answer: $n = 1806$.

M145. And we promise to plan $B$ on average $\sqrt{2}$ rubles per day. They stipulated that on the $n$ day $A$ we will receive an integer $a_n$ rubles ($a_n$ is equal to 1 or 2) with the maximum that the amount received in the first $n$ days ($a_1 + a_2 + \dots + a_n$) be as close as possible to the number $n\sqrt{2}$. For example, $a_1 = 1$, $a_2 = 2$, $a_3 = 1$, $a_4 = 2$, $a_5 = 1$.

Prove that the sequence $a_1, a_2, a_3, \dots$ is non-periodic.

The idea of ​​the proof is as follows. Suppose that, starting from some day with number $N + 1$, this sequence is periodic and $T$ is a period, that is, $a_{N+1} + a_{N+2} = a_{N+1}$, $a_{N+2} + a_{N+3} = a_{N+2}$, etc. Then for every $T$ days following the day $N$, $B$ will receive the same integer.

$a_{N+1} + a_{N+2} + \dots + a_{N+T} = c$ (7) rubles. Therefore, on average (over a long period of time) he will receive $\frac{c}{T}$ rubles per day. But from the rule for constructing the sequence $a_n$, on average he should receive $\sqrt{2}$ rubles per day. We come to a contradiction: equality

$$\frac{c}{T} = \sqrt{2}$$

impossible, since $\sqrt{2}$ is irrational, and $c$ and $T$ are natural.

A similar idea was expressed by many of those who sent us a solution to this problem. But not everyone brought it to a rigorous proof. This proof might look something like this:

Let us denote $a_1 + a_2 + \dots + a_n$ by $s_n$. Since $n\sqrt{2}$ is irrational and $s_n - \text{ближайшее целое число } k\sqrt{2}$ (Fig. 6), then

$$|s_n - n\sqrt{2}| < 1/2.$$ (9)

It is assumed that for $n > N$ the sequence $a_n$ is periodic, and using notation (7), for any natural number $m$ we have

$$s_N + mT = s_N + mc.$$ (10)

Applying (9) to $n = N + mT$, taking into account (10) we obtain

$$|s_N + mc - N\sqrt{2} - mT\sqrt{2}| < 1/2,$$

whence, using the inequality $|\alpha + \beta| \geq |\alpha| - |\beta|$ and doing on $mT$, we get

$$\left| \frac{c}{T} - \sqrt{2} \right| < \frac{1}{2mT} + \left| \frac{s_N - N\sqrt{2}}{mT} \right| < \frac{1}{mT}.$$
