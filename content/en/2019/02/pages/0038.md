If the number n < 1000, then it is convenient to use the following test for the divisibility of the number n = 10a + b by 7 and 13, where the number a is obtained by discarding the last digit of the number n: The number n = 10a + b is divisible by 7 if and only if the sum 3a + b is divisible by 7. The number n = 10a + b is divisible by 13 if and only if the difference 3a – b is divisible by 13. Proof of each from the indicated characteristics it follows from the identities n = 10a + b = 7a + (3a + b) =

= 13a – (3a – b). For numbers n > 1000, it is convenient to use the following criterion: The number n = 1000a + b is divisible by 7 (by 13) if and only if the difference between the number a, representing the number n without the last three digits, and the number b, written with the last three digits of the number n (in the same order), is divisible by 7 (respectively, by 13). The proof is based on the fact that 1001 is divisible by 7, by 11, by 13, and on the identity n = 1000a + b = 1001a – (a – b).

But how do you find out the key and what to do if you forget it? Recovering the key is quite simple. We write 1 above the first digit of this number from the right. Then we multiply 1 by 10, divide by 7 and write the resulting remainder 3 above the second digit from the right. We do the same further. We multiply 3 by 10, divide by 7 and write the remainder 2 above the third number from the right. We multiply 2 by 10, divide by 7 and write the remainder 6 above the fourth digit from the right. If you've ever been told that the remainder 6 is the same as the remainder (–1) (since 6 = 7 + (–1)), then you can also write (–1). We multiply 6 (or (–1)) by 10, divide by 7 and write the remainder 4 (or (–3)) above the fifth digit from the right. We multiply 4 (or (–3)) by 10, divide by 7 and write the remainder 5 (or (–2)) above the sixth digit from the right. We multiply 5 (or (–2) by 10, divide by 7 and write the remainder 1 above the seventh digit from the right. The circle is closed. You know very well that when divided by 7, you get exactly 6 non-zero remainders. That is why the key fits into 6 numbers.
