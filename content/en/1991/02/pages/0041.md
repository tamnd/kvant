Prove that if $\angle HAB = HCB$, $\angle HBA = \angle HCA$, then the point $H$ is the ortcenter of the acute triangle $ABC$. Since $\angle BAN = \angle BCN$, then $\angle HAB = \angle BAN$, similarly, $\angle HBA = \angle ABN$, whence $C_1H \perp AB$. Prove that $\angle AA_1C = 90^\circ$. Let's denote $\angle HAC = \alpha$, $\angle HAC_1 = \beta$, $\angle HBA = \gamma$. Since $\triangle ACC_1$ is straight-headed, $\alpha + \beta + \gamma = 90^\circ$. Using the fact that $\triangle CC_1B$ is straight-headed, prove that $\angle HBC = \alpha$. Let's denote it by $\angle AA_1B = x$.

Considering $\triangle AA_1B$, we get $x + \alpha + \beta + \gamma = 180^\circ$. Hence $x = 90^\circ$.
