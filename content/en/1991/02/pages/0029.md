M1241 — M1245, F1253 — F1257

M1241. There are 1990 piles consisting of corresponding 1, 2, 3, ..., 1990 stones. In one step you can select the same number of stones from any set of piles. In what minimum number of steps can all the stones be selected?

Answer: 11. When solving this problem, it is convenient to assume that we have 1990 boxes containing 1, 2, ..., 1990 stones. After each throwing of stones, we will divide the boxes into groups containing the same number of stones. Let there be $n$ groups of boxes at some points (some of them may already be empty). The next throwing out of stones is done like this: we select several boxes belonging to some $k$ groups and throw out the same number of stones from them. As a result, boxes that belonged to different groups before discarding will still contain different numbers of stones, and boxes from which nothing is thrown away will remain in the same groups where they were before. Thus, if at the beginning there were only $n$ groups of boxes, then after the next ejection the number of groups will be no less than $\max \{n, n-k\} \geqslant \frac{1}{2} n$. So, at each step the number of groups of boxes decreases by no more than 2 times.

If at the beginning there were 1990 different groups of boxes, then at the next step there will be no less than 995, then 498, 249, 125, 63, 32, 16, 8, 4, 2, 1. The last group may already consist of empty boxes. So, the total number of throws is at least 11.
