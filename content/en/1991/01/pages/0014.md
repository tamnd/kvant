Try to deform the “eight” into a “zero”. Did it work? Then along the way you are bound to have an obstruction (Fig. 3). Is it possible to deform so that the curve remains smooth? It looks like you can't. How can this be strictly proven? The first thought is to count the number of self-intersections of the curve or the number of areas into which the curve divides the plane. But these numbers may change. We have already seen in figure 1 how the figure-eight curve has lost a couple of self-intersection points. That's it, a couple! This means that the parity of the number of self-intersections remains unchanged. (True, at the first moment two points turned into one, but it should be considered as a merged pair.) The same goes for the area number: they form and disappear in pairs. So, “eight” and “zero” belong to different types. maybe there are only two types of curves? Nothing of the kind.

There are infinitely many different types of closed curves on the plane.

To prove our first theorem, we assign a natural number to each closed curve on the plane. Consider a point moving along a curve (its velocity vector touches the curve at each instant of time). Let it not

which time the point will complete the curve and return to its initial position. We will call the number of revolutions of the curve the number of full revolutions that the velocity vector of this point makes. (It doesn't matter which direction the vector rotates. It depends on the direction the point moves along the curve.)

The number of revolutions is invariant, that is, it does not change when the curve is deformed. After all, this number cannot change abruptly with a “small movement” of the curve, and the deformation is a whole number of such “movements.” Therefore, curves with different numbers of revolutions belong to different types.

Exercise 1. Design a curve for each direction of a given number of revolutions.

There are many different numbers of the infinite, which means there are also curves. The theorem has been proven.

In fact, the number of revolutions is the only invariant of a plane curve. This means that two curves with the same speeds belong to the same type. Try to come up with a proof yourself, and if it doesn’t work, experiment. As a last resort, read «Kvant» No. 4 for 1983. And we’d better remember that the Earth is a ball.
