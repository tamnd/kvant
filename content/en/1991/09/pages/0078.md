5. If you replace all the numbers in the specified table with numbers ±1 in accordance with the signs of the original numbers, then the table will still satisfy the conditions of the problem. The table $m \times n$, in which the numbers ±1 are located and each number is equal to the product of its neighbors, is called suitable. Let us prove that any suitable table $m \times 15$, where $m=1, 3, 7, 15$, is filled with only ones, i.e. trival.
Indeed, it is directly verified that a suitable table $1 \times 15$ belongs: it is completely specified by some of the extreme numbers, one of which is necessarily equal to 1. Let us assume that there is a suitable non-trivial table $15 \times 15$. If it is symmetrical with respect to the middle row, then in this row each number coincides with the product of its horizontal neighbors and, therefore, as noted above, is equal to 1. Then above this row there is a suitable table $7 \times 15$, and non-trivial (otherwise the whole table is trival). If the table $15 \times 15$ is not symmetrical about the middle row, then each number in its upper part of size $7 \times 15$ is multiplied by a number that is symmetrical about the middle row. The resulting table $7 \times 15$ will be suitable and again nontrivial (otherwise everything is a symmetrine table). So, from the existence of a suitable nontrivial table $15 \times 15$ we deduced the existence of such a table $7 \times 15$. Let us similarly find a suitable nontrivial table $3 \times 15$, and then $1 \times 15$. Contradiction.
