M1283. The square $99 \times 99$ is divided into three types of figures (Fig. 1). a) Prove that there are no less than 199 figures of the first type.
b) Give an example of a partition when the number of figures of the first type is 199.

a) Let us prove that (for any $n \geqslant 4$) when filling the square $(2n-1) \times (2n-1)$ with figures of these three types of figures of the 1st type - corner ones - there will be at least $4n-1$. In particular, for $n=50$ we obtain the required estimate 199.

By coloring the board cell $(2n-1) \times (2n-1)$ in four colors 1, 2, 3, 4, as shown in figure 2. Let $a_i$ be the number of corners that do not contain a cell of color $i$ ($i=1, 2, 3, 4$), i.e., containing one cell each of other colors; $b$ is the total number of figures of the other two types, each of which contains one cell of different colors. Since the total number of cells of the 1st color is $n^2$, the 2nd, 3rd - $n(n-1)$ each and the 4th - $(n-1)^2$, then

$$a_2 + a_3 + a_4 + b = n^2,$$
$$a_1 + a_2 + a_4 + b = a_1 + a_3 + a_4 + b = n(n-1),$$
$$a_1 + a_2 + a_3 + b = (n-1)^2,$$

where

$$a_4 - a_1 = 2n-1, \quad a_3 - a_1 = a_2 - a_1 = n$$

and (since $a_1 \geqslant 0$) $a_2 = a_3 \geqslant n$, $a_4 \geqslant 2n-1$, so

$$a_1 + a_2 + a_3 + a_4 \geqslant n + n + 2n-1 = 4n-1.$$

Here is a shorter argument that involves only the total number $a = a_1 + a_2 + a_3 + a_4$ of corners and the number $b$ of figures of the other two types. Since $3a + 4b = (2n-1)^2$ and each figure contains at most one cell of the 1st color, then $a + b \geqslant n^2$, therefore

$$4a \geqslant 4n^2 - 4b = 4n^2 - (2n-1)^2 + 3a = 4n-1 \geqslant 3a,$$

where

$$a \geqslant 4n-1.$$

(Note that from our estimates in point a) it follows that $b=n^2-a_2-a_3-a_4 \leqslant n^2-4n+1$, and this number at $1 \leqslant n < 4$ is negative, so filling is possible only starting from $n=4$, i.e. from the square $7 \times 7$.
