fold the cards in reverse order. Prove that a) $M(9) \leq 5$, 6) $M(52) \leq 27$, 8)*$M(52) \geq 17$, 9)*$M(52) \geq 27$. Find $M(n)$ for any $n > 2$.

Specify ..., $a, b, ..., c, d, ...$ and insert it between $p$ and $q$, then the connections $ab, cd$ and $pq$ are destroyed. To move the cards in reverse order, you need to destroy all $n - 1$ connections. Hence, for the number of necessary steps $s$ we obtain the estimate

$$3s \geq n - 1.$$

To get the estimate $s \geq (n + 1)/2$, we will reason a little differently. We will assume that connections of two types are possible between neighboring cards: “>” or “<” (“larger” or “smaller”), and in $s$ operations all $n - 1$ connections of the “<” type must turn into the opposite “>”. Note that at each step the number of connections “>” can appear no more than 2. In fact, immediately 3 connections “<” can turn into “>” only when moving from

...$a, b, ..., c, d, ..., p, q, ...$

To

...$a, d, ..., p, b, ..., c, q, ...$

in the event that

$$a < b, c < d, p < q, a > d, p > b, c > q.$$

But these six inequalities are incompatible: they imply

$$a < b < p < q < c < d < a — противоречие.$$

Further, at the first step, only one connection can be transformed from “<” to “>”: after all, here either $a < b < c < d < p < q$ or $p < q < a < b < c < d$, and in this case only one of the three inequalities is satisfied

$$a > d, p > b, c > q.$$

The situation is exactly the same at the last step, after which a set of $n - 1$ connections “>” is obtained (in general it is not difficult to see that reverse transitions are completely similar to direct ones, only the signs “<” and “>” change their roles).

So, for the number $s$ of step inequalities we obtain the estimate

$$1 + 2(s - 2) + 1 \geq n - 1,$$

where

$$s \geq (n + 1)/2.$$
