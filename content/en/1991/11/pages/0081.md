To perform task 6), if the text is deciphered in an ambiguous way, it is enough at each step to remove code words from the set $A$ in the following sequence: first one at a time, then two at a time, etc. The process ends if, as a result of removing the corresponding code words, it is possible to determine that there is no ambiguous decryption.

The execution of task c) (the decryption process) is carried out by brute force and backtracking by sequentially comparing the symbols of the decrypted text with the code words. If the initial part of the text coincides with any code word, a new record is formed by removing this part from the first analogous text, etc. The process ends if the entire text was able to be decrypted, otherwise decryption is repeated, but the sequence of comparison of code words with the initial parts of the records generated at each stage changes.
