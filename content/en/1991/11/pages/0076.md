3. Answer: $2^s$, where $s$ is any natural number such that $2^s \geq n$.
After each move, non-negative integer numbers will be written on the board. If the sum and difference of two such numbers is an odd number $d$, then these numbers themselves are divisible by $d$. Therefore, if the number $k$ was divisible by the even number $d > 1$, then all the numbers originally written on the board would be divisible by $d$, which is impossible, since there is 1 among them. Therefore, the number $k$ does not have odd prime factors, i.e. $k = 2^s$. Since after each move the maximum number written on the board does not decrease, then $k \geq n$. Let us prove that we can obtain any value of $k = 2^s \geq n$. In one move, from the pair $(2^a, 2^a)$ we get the pair $(0, 2^{a+1})$, and from the pair $(0, 2^c)$ - the pair $(2^c, 2^c)$, so if a set of powers of two with exponents is written on the board, does not exceed the sum $s_0$, such that among the numbers included in the set there are two equal numbers less than $2^{80}$, then in a few moves you can get numbers all equal to $2^{80}$.
Individually by $n$ we will show that from the set 1, 2, ..., $n$ we can always obtain the indicated set of powers of two, and as $s_0$ we can take any natural number satisfying the inequality $2^{80} \geq n$. With $n \leq 8$ the statement is verified directly. Let us assume that it is true for all $n$, satisfying inequality $8 \leq n \leq l$, and prove its validity for $n = l + 1$. Let $l + 1 = 2^m + b$, where $1 \leq b \leq 2^m$, $m \geq 3$. (1) 1, 2, ..., $2^m - b - 1$ (this group does not contain any numbers if $b = 2^m$ and $b = 2^m - 1$).
(2) 2, 4, ..., $2^b$ (obtained from the differences $|p - q|$).
(3) $2^m, 2^{m+1}, ..., 2^{m+1}$ (derived from the sums $p + q$ and the number $2^m$).
