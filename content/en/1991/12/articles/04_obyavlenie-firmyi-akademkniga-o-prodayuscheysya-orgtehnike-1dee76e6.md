What about lasers? How do they manage to bypass formula (8)? The answer lies in the design of lasers. Schematically, a laser can be imagined as two mirrors, one of which is clear and the other is translucent. Between the mirrors there is an active medium (gas or solid), the energy state of the atoms of which corresponds to special “laser” conditions. In an active medium, radiation is excited by external influences (light, electrical discharge, chemical reactions). As a result of the interaction of the excited radiation with the active medium and mirrors, the same beam of radiation as narrow as an angle breaks out of the laser, which, with the appropriate characteristics, can burn anything at a considerable distance.

Why does he turn out like this? We have already said that any extended light source is a collection of luminous points, by which we can mean atoms and groups of atoms. In a common source, all these elementary emitters emit photons at different times, not paying attention to each other. In a laser, on the contrary, all atoms emit accordingly, synchronously, or, to put it in basic terms, homoherently. All photons here have the same frequency and, most importantly, the same phase. We can assume that all atoms of the active medium of the laser act as one atom, which has returned to itself the energy of all its components. A common source can be used in a rocket with many engines, which are directed at random, in a crooked way and in the wrong direction. Such a rocket wastes most of its power in vain. In a laser rocket, all engines are directed in one direction, which provides its extraordinary properties. The wave fronts of an electromagnetic wave emanating from a common source are equal to the chaotic menus. The wavefronts of the laser beam are regular and clearly formed.

What do they look like? This is the most important and fundamental point. Stop if we just limit the size of a plane wave, as it immediately becomes divergent due to diffraction at this size. The wavefront of the laser beam is, of course, limited by the transverse dimensions of the active medium. $$N = a_n q_n + a_{n-1} q_{n-1} + \dots + a_2 q_2 + a_1 q_1 + a_0$$

$$a_n a_{n-1} \dots a_2 a_1 a_0.$$
It is assumed that the “digits” $a_k$ are obtained in the same way (algorithm) as described above.

From this description it is clear that in a given basis each natural number $N$ is written in a unique way. Further, since the “highest digit” $a_n$ is obtained as the quotient of the number $N$ divided by $q_n$, which by convention is less than $q_{n+1}$ (for otherwise we would start with the division of $N$ by $q_{n+1}$, and not by $q_n$!), then $a_n < q_{n+1}/q_n$. Therefore, if the quotient $q_{n+1}/q_n$ is contained between the integers $A$ and $A-1$:
$$A-1 < \frac{q_{n+1}}{q_n} \leq A,$$

$$a_n=0, \text{ или } 1, \text{ или } 2, \dots, \text{ или } A-1.$$

$$r_{n-1} < q_n,$$
That

Number systems
with a given base

This is the name given to number systems with a base.

$$q_0 = d^0 = 1, q_1 = d^1 = d, q_2 = d^2,$$
$$q_3 = d^3, q_4 = d^4, \dots$$
(2)

where $d$ is any integer greater than one. This number is called the base of the number system.

These systems include the general decimal system with the base $d = 10$, the Vilis hexadesimal ($d = 60$) and the double number system ($d = 2$), which has recently been widely used in connection with the needs of computer technology. In the case of an arbitrary base $d$ one speaks of a “$d$-ary” number system.

In the $d$-ary number system, the entry

$$N = \langle a_n a_{n-1} \dots a_2 a_1 a_0 \rangle$$

has the following meaning:

$$N = a_n d^n + a_{n-1} d^{n-1} + \dots + a_2 d^2 + a_1 d + a_0.$$

It is clear that each digit in a number written in the $d$-ary number system can take only $d$ values: 0, or 1, or 2, or 3, ..., or $d-1$.

In particular, if $d = 10$ and, therefore, the basis of the number system has the form

$$q_0 = 1, q_1 = 10, q_2 = 100, q_3 = 1000, \dots$$

we come to the common decimal number system (counting in units, then tens, then hundreds, thousands, tens of thousands, etc.); in it all numbers take values ​​not exceeding 9.

The simplest of all $d$-ary number systems is obviously the double number system with a basis

$$q_0 = 1, q_1 = 2, q_2 = 4,$$
$$q_3 = 8, q_4 = 16, \dots$$

This number system knows only two digits 0 and 1. Here is a record of the first 15 natural numbers in this system:

$$\begin{array}{c c c c c}
1 = 1 & 6 = 110 & 11 = 1011 \\
2 = 10 & 7 = 111 & 12 = 1100 \\
3 = 11 & 8 = 1000 & 13 = 1101 \\
4 = 100 & 9 = 1001 & 14 = 1110 \\
5 = 101 & 10 = 1010 & 15 = 1111.
\end{array}$$

When using this number system, all calculations become quite lengthy, but extremely simple. If we always used this particular number system, then schoolchildren would only have to fill out the following “multiplication table”:

$$0 \cdot 0 = 0, 0 \cdot 1 = 1 \cdot 0 = 0, 1 \cdot 1 = 1$$

(and the “addition table”, related to the equality $1 + 1 = 10$, - after all, the number “10” is a common two!). The binary number system has numerous applications in science and technology; in particular, it underlies the design of modern electronic calculating machines*).

Number systems
with other bases

Number systems with bases not formed by geometric progression 1, d, $d^2$, $d^3$, ..., do not have the same type of applications. But they are useful for solving some mathematical problems.

$$q_0 = 1, q_1 = 20, q_2 = 18q_1 (= 18 \cdot 20),$$
$$q_3 = 20q_2 (= 18 \cdot 20^2),$$
$$q_4 = 20q_3 (= 18 \cdot 20^3),$$

This number system is similar to the two-digit number system in everything, differing from it only in one respect: in it the second from the end digit in the notation $N = \langle a_n a_{n-1} \dots a_2 a_1 a_0 \rangle$ of an arbitrary number (which we are accustomed to place horizontally, and not from top to bottom, like Maya)

$$q_3 = d_2q_2, q_4 = d_3q_3, \dots,$$
