Number systems
with other bases

Number systems with bases not formed by geometric progression 1, d, $d^2$, $d^3$, ..., do not have the same type of applications. But they are useful for solving some mathematical problems.
Let's look at several examples of such number systems.

1° Mayan system. Above we have already talked about the Mayan number system, the basis of which had the form
$$q_0 = 1, q_1 = 20, q_2 = 18q_1 (= 18 \cdot 20),$$
$$q_3 = 20q_2 (= 18 \cdot 20^2),$$
$$q_4 = 20q_3 (= 18 \cdot 20^3),$$

This number system is similar to the two-digit number system in everything, differing from it only in one respect: in it the second from the end digit in the notation $N = \langle a_n a_{n-1} \dots a_2 a_1 a_0 \rangle$ of an arbitrary number (which we are accustomed to place horizontally, and not from top to bottom, like Maya)

$$a_1 < \frac{q_2}{q_1} = \frac{18 \cdot 20}{20} = 18,$$

while all other digits can have 20 values: 0, 1, 2, ..., 19.

The situation will be similar in a number system with a basis in which $q_{n+1}$ is divisible by $q_n$ without remainder for all $n = 0, 1, 2, ...$:

$$q_0 = 1, q_1 = d_0, q_2 = d_1q_1 (= d_1d_0)$$
$$q_3 = d_2q_2, q_4 = d_3q_3, \dots,$$

where $d_0, d_1, d_2, d_3, ...$ are any positive integers greater than 1, different or identical. In such a number system, the numbers are written

$$N = \langle a_n a_{n-1} \dots a_2 a_1 a_0 \rangle$$

the first digit from the end $a_0$ can take $d_0$ values ​​0, 1, 2, ..., $d_0 - 1$, the next digit $a_1$ can take $d_1$ values ​​from 0 to $d_1 - 1$, digit $a_2$ can take values ​​from 0 to $d_2 - 1$, etc.

Moreover, in the number system with basis (3), as well as in the d-ary number system (in which our system is reversed in the case of $d_0 = d_1 = d_2 = ... = d$), any entry makes sense

$$N = \langle a_n a_{n-1} \dots a_2 a_1 a_0 \rangle,$$

where $a_0, a_1, a_2, ..., a_n$ are natural numbers as well as $a_0 < d_0, a_1 < d_1, a_2 < d_2$, etc. In fact, it is easy to check that when inverting a number

$$N = a_n q_n + a_{n-1} q_{n-1} + \dots + a_2 q_2 + a_1 q_1 + a_0$$

in our number system using the method of “continuous division” (see above p. 16) the numbers are obtained

$$a_n, a_{n-1}, a_{n-2}, \dots, a_1, a_0.$$

We will show that such a favorable situation is not a general law using the example of one procedure of the “number system”.

2° “Even” number system. Taking all even numbers (and the number $q_0 = 1$) as the basis of the number system:

$$q_0 = 1, q_1 = 2, q_2 = 4, q_3 = 6,$$
$$q_4 = 8, q_5 = 10, q_6 = 12, \dots$$

Since here

$$\frac{q_1}{q_0} = q_1 = 2$$

And

$$\frac{q_{n+1}}{q_n} = \frac{2(n+1)}{2n} = \frac{n+1}{n} = 1 + \frac{1}{n} < 2$$

for all $n > 1$, then this number system, like double, knows only two “digits”: 0 and 1. The conditions are to designate numbers written in this “even” number system in red. Then, very indo,

$$2 = 10, 3 = 11, 4 = 100, 5 = 101,$$
$$6 = 1000, 7 = 1001, 8 = 10000,$$
$$9 = 10001$$, etc.
