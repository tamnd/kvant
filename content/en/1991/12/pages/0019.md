4112011.

Number systems related to those discussed in the last two examples (i.e., the decimal number system and the “cashier system”) are called positional (we will talk about the meaning of this expression below). Instead of cumbersome recording
$$N = a_n q_n + a_{n-1} q_{n-1} + \dots + a_2 q_2 + a_1 q_1 + a_0$$
in a positional number system with basis (1), it is convenient to use a more compact notation from $n+1$ “digits”:
$$a_n a_{n-1} \dots a_2 a_1 a_0.$$
It is assumed that the “digits” $a_k$ are obtained in the same way (algorithm) as described above.

From this description it is clear that in a given basis each natural number $N$ is written in a unique way. Further, since the “highest digit” $a_n$ is obtained as the quotient of the number $N$ divided by $q_n$, which by convention is less than $q_{n+1}$ (for otherwise we would start with the division of $N$ by $q_{n+1}$, and not by $q_n$!), then $a_n < q_{n+1}/q_n$. Therefore, if the quotient $q_{n+1}/q_n$ is contained between the integers $A$ and $A-1$:
$$A-1 < \frac{q_{n+1}}{q_n} \leq A,$$
“digit” $a_n$ does not exceed $A-1$, i.e. it can take $A$ value:
$$a_n=0, \text{ или } 1, \text{ или } 2, \dots, \text{ или } A-1.$$
(However, for the “highest” digit of the number, the values ​​$a_n=0$ can also be excluded.) Similarly, the digit $a_{n-1}$ is obtained by dividing the “first” remainder $r_{n-1}$ by $q_{n-1}$. But since
$$r_{n-1} < q_n,$$
That
$$a_{n-1} < \frac{q_n}{q_{n-1}}.$$
This reasoning can be extended to all other numbers. In particular, since the last digit $a_0$ simply coincides with the “last” remainder $r_0$ resulting from division by $q_1$, then $a_0$ can take $q_1$ values:
$$a_0=0, \text{ или } 1, \text{ или } 2, \dots, \text{ или } q_1-1.$$
