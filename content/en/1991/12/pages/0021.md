Number systems
with a given base

This is the name given to number systems with a base.

$$q_0 = d^0 = 1, q_1 = d^1 = d, q_2 = d^2,$$
$$q_3 = d^3, q_4 = d^4, \dots$$
(2)

where $d$ is any integer greater than one. This number is called the base of the number system.

These systems include the general decimal system with the base $d = 10$, the Vilis hexadesimal ($d = 60$) and the double number system ($d = 2$), which has recently been widely used in connection with the needs of computer technology. In the case of an arbitrary base $d$ one speaks of a “$d$-ary” number system.

In the $d$-ary number system, the entry

$$N = \langle a_n a_{n-1} \dots a_2 a_1 a_0 \rangle$$

has the following meaning:

$$N = a_n d^n + a_{n-1} d^{n-1} + \dots + a_2 d^2 + a_1 d + a_0.$$

It is clear that each digit in a number written in the $d$-ary number system can take only $d$ values: 0, or 1, or 2, or 3, ..., or $d-1$.

In particular, if $d = 10$ and, therefore, the basis of the number system has the form

$$q_0 = 1, q_1 = 10, q_2 = 100, q_3 = 1000, \dots$$

we come to the common decimal number system (counting in units, then tens, then hundreds, thousands, tens of thousands, etc.); in it all numbers take values ​​not exceeding 9.

The simplest of all $d$-ary number systems is obviously the double number system with a basis

$$q_0 = 1, q_1 = 2, q_2 = 4,$$
$$q_3 = 8, q_4 = 16, \dots$$

This number system knows only two digits 0 and 1. Here is a record of the first 15 natural numbers in this system:

$$\begin{array}{c c c c c}
1 = 1 & 6 = 110 & 11 = 1011 \\
2 = 10 & 7 = 111 & 12 = 1100 \\
3 = 11 & 8 = 1000 & 13 = 1101 \\
4 = 100 & 9 = 1001 & 14 = 1110 \\
5 = 101 & 10 = 1010 & 15 = 1111.
\end{array}$$

When using this number system, all calculations become quite lengthy, but extremely simple. If we always used this particular number system, then schoolchildren would only have to fill out the following “multiplication table”:

$$0 \cdot 0 = 0, 0 \cdot 1 = 1 \cdot 0 = 0, 1 \cdot 1 = 1$$

(and the “addition table”, related to the equality $1 + 1 = 10$, - after all, the number “10” is a common two!). The binary number system has numerous applications in science and technology; in particular, it underlies the design of modern electronic calculating machines*).
