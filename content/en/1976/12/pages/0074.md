6. a) Note that the function $f(x) = \cos x \cdot \cos(\sqrt{2}x)$ takes the value $y = 1$ only for $x = 0$. In fact,

$$\cos x \cdot \cos \sqrt{2}x = 1 \Leftrightarrow \left[ \begin{array}{l} \cos x = 1, \\ \cos \sqrt{2}x = 1 \\ \cos x = -1, \\ \cos \sqrt{2}x = -1 \end{array} \right].$$

In the first case we have: $x = 2\pi m$ and $\sqrt{2}x = -2\pi n$, where $m, n \in \mathbb{Z}$. If $x \neq 0$ satisfies this general relation (for some $m$ and $n$), then after dividing the second equation by the first we obtain:

$$\sqrt{2} = \frac{n}{m}, \text{ т. е. } \sqrt{2} = \text{рациональное число.}$$

The contradiction shows that the first system has a unique solution $x = 0$. The second system has no solution at all, which is proven in a similar way.

So, $f(x) = 1$ only for $x = 0$, and therefore the function $f$ cannot be periodic (otherwise $f(T) = f(0) = 1$!).

6) The expression for the function $f(x) = \cos x + \cos \sqrt{2}x$ can be converted to the form

$$f(x) = 2 \cos \frac{x + \sqrt{2}x}{2} \cos \frac{x - \sqrt{2}x}{2} = 2 \cos \frac{1 + \sqrt{2}}{2} x \cdot \cos \frac{1 - \sqrt{2}}{2} x.$$

Further, as in problem a), it is proved that $f(x) = 2$ only for $x = 0$, and therefore $f$ is not periodic. (Note that $\frac{1 + \sqrt{2}}{1 - \sqrt{2}}$ is irrational. Prove this by contradiction.)

Another way is to immediately notice that $f(x) = 2$ only if $\cos x = \cos \sqrt{2}x = 1$; Thus, the problem is reduced to one that has already been dealt with.

c) Let us note, first of all, that the reasoning for point a) for the function $f(x) = \sin x \times \sin \sqrt{2}x$ does not pass (try it!). Therefore it is different.

Consider the null function $f$, that is, $x$ as well as $f(x) = 0$.

We have:

$$\sin x \cdot \sin \sqrt{2}x = 0 \Leftrightarrow \sin x = 0$$

or $\sin \sqrt{2}x = 0$

that is, $x = a_m = \pi m$ or $x = b_n = \frac{\pi n}{\sqrt{2}}$, where $m, n \in \mathbb{Z}$.

Let us assume that the function $f$ is periodic with period $T \neq 0$. Since $f(T) = f(0 + T) = f(0) = 0$ is either $T = a_m$ or $T = b_n$ (for some $m_0, n_0$ other than 0).

Let us first consider the case $T = a_m$.

Since $f(b_1 + T) = f(b_1) = 0$, the number $b_1 + T = b_1 + a_m$ must equal either $a_m$ or $b_n$. In the first case

$$b_1 + a_m = a_m, \text{ т. е. } \frac{\pi}{\sqrt{2}} + \pi m = \pi m,$$

whence $\frac{1}{\sqrt{2}} = m - m_0$ and $\sqrt{2} = \frac{1}{m - m_0} \in \mathbb{Q}$ are a contradiction. In the second case

$$b_1 + a_m = b_n, \text{ т. е. } \frac{\pi}{\sqrt{2}} + \pi m_0 = \frac{\pi n}{\sqrt{2}},$$

whence $\frac{n - 1}{\sqrt{2}} = m_0$ and $\sqrt{2} = \frac{n - 1}{m_0} \in \mathbb{Q}$ are again a contradiction.

In a similar way, we arrive at a contradiction in the case when $T = b_n$ (consider it yourself).
