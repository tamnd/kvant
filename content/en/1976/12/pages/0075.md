The distance of the numbers $a_m = a + mT$ and $b_n = b + nT$, where $m$ and $n$ are integers, and put $f(a_m) = f(a) = A$ and $f(b_n) = f(b) = B$ for any $m, n \in \mathbb{Z}$ (see Fig. 3). If these relations define a function, i.e. it cannot serve such that $x = a_m = b_n$ and $f(x) = A \neq f(x) = B$, then this function will be periodic with the smallest period $T$ (cf. example 3°). If for some $m$ and $n$ they are still $a_m = b_n$, then the original function (given at two points) cannot be extended to a periodic one with period $T$ (explain). The ratio $a_m = b_n$ means that $a + mT = b + nT$, i.e. $(m-n)T = b-a$ and $T = \frac{b-a}{k}, k = m-n \in \mathbb{N}$.

So, our function can be extended to a periodic one with the smallest positive period $T$ for any $T > 0$ except $T = (b-a)/k$, where $k \in \mathbb{N}$. (Try to analyze the same problem in a similar way in the case where $f(a) = f(b)$, i.e. $A = B$!).
