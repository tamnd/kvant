$$D(f) = \{x \mid x \geq 0\},$$

and if $T > 0$, then $x_0 = T/2 \in D(f)$, but $x_0 - T = -T/2 < 0$ and does not belong to $D(f)$; The case $T < 0$ (Fig. 7) is treated similarly.

7°. The quadratic function $f(x) = x^2$ is defined in 础у: $D(f) = R$, - and therefore condition (A) is satisfied for it for any $T$. If, for some $T \neq 0$, condition ($B_0$) is also satisfied, then for any $x \in R$ the correspondence $x^2 = (x + T)^2$ must be true. Taking $x = 0$, we get: $0^2 = (0 + T)^2$, i.e. $T^2 = 0$, or $T = 0$, in contradiction with the condition $T \neq 0$. Consequently, condition ($B_0$) is not satisfied for any $T \neq 0$, and the function $f(x) = x^2$ is non-periodic.

8°. The function $f(x) = \cos x$ (Fig. 8) is known to be periodic: its period is, for example, $T_0 = 2\pi$. This is the smallest period, since $\cos x = 1$ only at $x = 2\pi n$, $n \in \mathbb{Z}$, i.e., value 1 of the function $f$ is repeated after 2π; therefore, $f$ cannot have a period less than 2π (otherwise the function would take the value 1 at points less than 2π apart from each other).
