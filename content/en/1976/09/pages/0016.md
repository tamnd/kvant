Note that for a sufficiently large $x$ the expression $x^3 + px + q$ depends positively, and for a sufficiently large negative modulus $x$ it depends negatively. Now we can schematically draw the graph of the function $y = x^3 + px + q$ (Fig. 2a)-c).

These schematic graphs reflect only the zones of increasing and decreasing function $y = x^3 + px + q$ and also the fact that $y > 0$ for sufficiently large $x$ and $y < 0$ for negative $x$ sufficiently large in absolute value. But these schematic graphs are already enough to judge the number of solutions to the equation. We see that:

1) the equation has one solution if $p > 0$; or if $p < 0$ and the function values ​​at points $-\sqrt{-p/3}, \sqrt{-p/3}$ have the same signs - Fig. 2a) and 2c).

2) if $p < 0$ and the values ​​of the function at points $-\sqrt{-p/3}, \sqrt{-p/3}$ have opposite signs, then the equation has three solutions - Fig. 26).

This result can be formulated in a more convenient form. In order to find out whether the values ​​of the function at points $-\sqrt{-p/3}, \sqrt{-p/3}$ have the same or opposite signs, you can calculate these values ​​and variables: positive, then the signs of the corresponding one, and if it is negative, then different. Let's do this calculation:

$$\left[(-\sqrt{-p/3})^3 + p(-\sqrt{-p/3}) + q\right] \times \left[(\sqrt{-p/3})^3 + p\sqrt{-p/3} + q\right] = \left[p/3\sqrt{-p/3} - p\sqrt{-p/3} + q\right] \times \left[-p/3\sqrt{-p/3} + p\sqrt{-p/3} + q\right] = \left(q - 2/3p\sqrt{-p/3}\right) \times \left(q + 2/3p\sqrt{-p/3}\right) = q^2 + 4/27p^3.$$

So, if $p < 0$ and $q^2 + \frac{4}{27}p^3 > 0$, then there is one solution, and if $p < 0$ and $q^2 + \frac{4}{27}p^3 < 0$, then there are three solutions. Noting that if $p > 0$, then $q^2 + \frac{4}{27}p^3 > 0$ is already wound up, we can formulate the result as follows:

$$q^2 + \frac{4}{27}p^3 > 0, \text{мо уравнение}$$
(2) we have one solution.
$$q^2 + \frac{4}{27}p^3 < 0, \text{мо уравнение}$$
(2) we have three solutions*).

5. Unexpected conclusion

Have you noticed that we have a satisfying weis? After all, the expression $q^2 + \frac{4}{27}p^3$ differs only by an insignificant (from the point of view of sign) set from the dangerous radical expression in formula (3):

$$q^2 + \frac{4}{27}p^3 = 4\left(\frac{q^2}{4} + \frac{p^3}{27}\right).$$

This means that precisely when the equation has three solutions, the radical expression is negative, and the formula does not give it either (we saw this in an example, but now it is clear that this is not accidental). If the equation has only one solution, then our formula gives it.

So, the phenomenon we observed in paragraph 2 has received its explanation. All that remains is to see whether it is still possible to squeeze something out of our formula when the equation has three solutions and there is a negative number under the square root.

*) We have always left without consideration the case when something goes to zero. In fact, if $q^2 + \frac{4}{27}p^3 = 0$, then the equation has two solutions, with the only exception: if $p = q = 0$, then there is obviously one solution.
