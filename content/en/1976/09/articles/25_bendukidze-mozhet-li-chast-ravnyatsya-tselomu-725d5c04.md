Right. This is the first thing that comes to mind. Of course, crossing in principle solves the issue, but if you approach the critical matter, it turns out that the crossing method is not the best. Besides the fact that it cannot be applied to infinite sets, it also has other disadvantages.

Firstly, when crossing, we receive extra information that we don’t need - we are not at all interested in how many elements are in each of the given sets, we only need to find out whether they are equally distributed in the sets or not.

Let's see how this can be done. Let us be given two sets: $A$ and $B$. Whether they are finished or not is irrelevant. The set $A$ is said to be one-to-one mapped to the set $B$ if there is a correspondence in which each element $A$ corresponds to a specific element $B$ of the set $B$, and each element $B$ corresponds to a unique $a$. It is clear that then from the elements of the set $A$ and $B$ one can make pairs $(a, b)$ subject to the specified conditions, then $A$ is one-to-one mapped onto $B$. Let me give you an example. Let

$$A = \{m, o, p, e\}, \quad B = \{1, 2, 3, 4\}.$$

Let's make pairs $(m, 1), (o, 2), (p, 3), (e, 4)$. They satisfy the above conditions, i.e. $A$ is one-to-one mapped onto $B$.

As a second example, let's take the segment [0, 1] and the segment [a, b], where a and b are arbitrary numbers. These segments (they are treated as a set of numbers) turn out to be equivalent, although the segment [a, b] may turn out to be many times longer (or shorter) than the segment [0, 1]. This equivalence can be proven, for example, like this. Let us consider the function $y = a + (b - a)x$ from the domain [0, 1]. As x changes in the domain of definition (from 0 to 1), y will change from a to b, i.e., the set of values ​​of this function will be [a, b]. And since at the same time

$$x = \frac{y - a}{b - a},$$

then each y will correspond to only one x.
