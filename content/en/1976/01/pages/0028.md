Theorem 2. Number

$$\alpha = c_0 + \frac{c_1}{10} + \frac{c_2}{10^{21}} + \frac{c_3}{10^{31}} + \dots + \frac{c_k}{10^{k1}} + \dots,$$

food $c_0$ is an arbitrary integer, and $c_1, c_2, \dots$ take one of the values ​​0, 1, 2,..., 9 and are not equal to zero in a row, starting from a certain point - prescendent.

Proof. Let's put

$$c_0 + \frac{c_1}{10} + \frac{c_2}{10^{21}} + \dots + \frac{c_k}{10^{k1}} = \frac{p}{q}.$$

Then

$$\alpha - \frac{p}{q} = \frac{c_k+1}{10^{(k+1)1}} + \frac{c_k+2}{10^{(k+2)1}} + \dots > 0,$$

and since $q = 10^{k1}$, then

$$\alpha - \frac{p}{q} = \frac{c_k+1}{q^{k+1}} + \frac{c_k+2}{q^{(k+1)(k+2)}} + \dots.$$

From here

$$\alpha - \frac{p}{q} \leqslant 9 \left( \frac{1}{q^{k+1}} + \frac{1}{q^{(k+1)(k+2)}} + \dots \right) < \frac{9}{(q-1)q^k}.$$

To prove the transcendence of the number $\alpha$, let us assume the opposite—that it is algebraic; then $\alpha$ satisfies equation (1), the coefficients of which are integers. Let us denote by $d$ the shortest distance from the root $\alpha$ to the other real roots of the equation.

Putting $A = |\alpha| + d$, we calculate the number $M$ using formula (5) and choose the natural number $k$ so large that the following three inequalities are simultaneously satisfied:

$$k > n, \frac{9}{(q-1)q^k} < d,$$

$$\frac{9}{(q-1)q^{k-n}} < \frac{1}{M}.$$

Due to inequality (9) and the average from condition (10), $\frac{p}{q}$ is less than $d$ from $\alpha$, and therefore $\frac{p}{q}$ is not a root of equation (1). Because

$$\left| \frac{p}{q} \right| = \left| \alpha - \left( \alpha - \frac{p}{q} \right) \right| \leqslant \leqslant |\alpha| + \left| \alpha - \frac{p}{q} \right| < |\alpha| + d = A,$$

then the conditions of Theorem 1 are satisfied, and therefore,

$$\left| \alpha - \frac{p}{q} \right| \geqslant \frac{1}{Mq^n}.$$

On the other hand, from inequality (9) and the last from condition (10)

$$\left| \alpha - \frac{p}{q} \right| < \frac{1}{Mq^n}.$$

Thus, the assumption that $\alpha$ is an algebraic number led to contradictory inequalities (11) and (12). Therefore, $\alpha$ is a transcendental number.

So, Theorem 2 allows us to construct transcendental numbers. Namely, a transcendental number can be obtained from any infinite fraction in which not all digits, starting with some, are zeros, using the following method: you need to put the $k$th digit after the decimal point in place with the number $k!$, and fill the remaining places with hylas. For example, from the number 0.314159... the following transcendental number is obtained:

$$0,3100040 \dots 010 \dots 050 \dots$$
