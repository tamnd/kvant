What did Stela define?

To find out who is right, let’s open Stepin’s geometry textbook. A trapezoid in this textbook is defined as a trapezoid that has two properties:

(1) there is a pair of parallel sides;
(2) there is a pair of opposite sides.

With this definition, only the set $T$ on figure 1 consists of trapezoids. All parallelograms (set $P$ on figure 1) are not trapezoids. But Stela “lost” the second property included in the definition of a trapezoid. And since every parallelogram has a pair of parallel sides, then all parallelograms must be attributed to the set $C$ “Steppe trapezoids”.

Thus, Stela, together with the set $T$, received the set $C = T \cup \Pi$. Excluding any property from the definition of a concept can lead to a new concept!

In this case, the concept of a cross-section having a pair of parallel sides has been obtained. The fact that such artificers do not have a special purpose does not matter.

As you have probably already noticed, there is an interesting relationship between the set $T$ of trapezoids and the set $C$ of four-artists having property (1): $T \subset C$. Instead of such a notation *) we can say: the set of cheaters possessing property (1) is wider,

4. Styopa Moshkin's new mistake

Foreseen, Pyotr Ivanovich included in Stepa’s written work the task of defining a trapezoid. Styopa clearly noted that the definition of a trapezoid includes two properties. He also noted that there is no need to indicate “extra” properties in the definition. Taking all this into account, he quickly wrote: *a right-handed land is a polygon with two properties*:

(1) there is a pair of parallel sides;
(2) there is a pair of non-parallel sides.

Central symmetry with center $O$ can be defined as a movement in which the point $O$ is not moved away ($O \rightarrow O$), and any other point $A$ is mapped onto a point $A_1$ different from $A$, which is $O \in [AA_1]$.
