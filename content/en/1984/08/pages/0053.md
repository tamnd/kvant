**M865. Let $[a, b]$ denote the least common multiple of the integers $a$ and $b$. Prove that for any $n+1$ numbers $a_0 < a_1 < ... < a_n$ the following inequality holds:

$$\frac{1}{[a_0, a_1]} + \frac{1}{[a_1, a_2]} + ... + \frac{1}{[a_{n-1}, a_n]} \leq 1 - \frac{1}{2^n},$$
if $a) n=2; b) n=3; \theta)^{*} n$ is any natural number.

**For small $n$ the problem can be solved using brute force.**

a) Since $[a, b] \geq 2a$ for $a < b$, and $a_0 \geq 1, a_1 \geq 2$, the inequalities $\frac{1}{[a_0, a_1]} \leq \frac{1}{2}, \frac{1}{[a_1, a_2]} \leq \frac{1}{4}$ and $\frac{1}{[a_0, a_1]} \leq \frac{1}{[a_0, a_1]} + \frac{1}{[a_1, a_2]} \leq \frac{1}{2} + \frac{1}{4} = \frac{3}{4}$ are valid.

b) If $a_2 \geq 4$, then, as in point a), $\frac{1}{[a_0, a_1]} \leq \frac{1}{2}, \frac{1}{[a_1, a_2]} \leq \frac{1}{4}, \frac{1}{[a_2, a_3]} \leq \frac{1}{8}$, if $a_2=3$, then $a_0=1$, $a_1=2$, $[a_0, a_1] = 2$, $[a_1, a_2] = 6$, $[a_2, a_3] \geq 6$, and $\frac{1}{[a_0, a_1]} + \frac{1}{[a_1, a_2]} + \frac{1}{[a_2, a_3]} \leq \frac{1}{2} + \frac{1}{6} + \frac{1}{6} < \frac{7}{8}$.

c) We will carry out the proof using the method of mathematical induction. At $n=1$ our inequality is very interesting. Let us now assume that it is true for $n=k$ and prove it for $n=k+1$. Let's consider two cases

1) Let $a_{k+1} \geq 2^{k+1}$, then $[a_k, a_{k+1}] \geq a_{k+1} \geq 2^{k+1}$ and by induction

$$\left( \frac{1}{[a_0, a_1]} + ... + \frac{1}{[a_{k-1}, a_k]} \right) + \frac{1}{[a_k, a_{k+1}]} \leq \left( 1 - \frac{1}{2^k} \right) + \frac{1}{2^{k+1}} = 1 - \frac{1}{2^{k+1}}.$$

2) In the case where $a_{k+1} < 2^{k+1}$, we use the identity $[a, b] = ab/(a, b)$, where $(a, b)$ is the most common divisor of the numbers $a$ and $b$. Since $b-a$ is divisible by $(a, b)$, and therefore $(a, b) \leq b-a$ (at $b>a$), this identity implies that $1/[a, b] \leq (b-a)/ab = 1/a-1/b$. That's why

$$\frac{1}{[a_0, a_1]} + \frac{1}{[a_1, a_2]} + ... + \frac{1}{[a_k, a_{k+1}]} \leq \left( \frac{1}{a_0} - \frac{1}{a_1} \right) + \left( \frac{1}{a_1} - \frac{1}{a_2} \right) + ... + \left( \frac{1}{a_k} - \frac{1}{a_{k+1}} \right) = \frac{1}{a_0} - \frac{1}{a_{k+1}} < 1 - \frac{1}{2^{k+1}}$$

Q.E.D.

Note that this estimate is exact: for any $n$, equality is achieved for the sequence $a_0=1, a_1=2, ..., a_n=2^n$.
