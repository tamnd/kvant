**Where did Petya and Vova go wrong?**

Both students are wrong. Let there be a system of equations
$$\begin{cases} j_1(x, y) = g_1(x, y), \\ j_2(x, y) = g_2(x, y). \end{cases}$$

Petya got the system
$$\begin{cases} j_1(x, y) = g_1(x, y), \\ j_1(x, y) j_2(x, y) = g_1(x, y) g_2(x, y). \end{cases}$$

Systems of equations (1) and (2), generally speaking, are unequal. It is clear that any solution to system (1) is a solution to system (2). The converse is not true in the general case: any solution to system $j_1(x, y) = g_1(x, y) = 0$ is a solution to system (2), but may not be a solution to equation $j_2(x, y) = g_2(x, y)$, and, consequently, not a solution to system (1).

Vova made a similar mistake. If the guys checked, they would get the correct answer: $(1; 0)$.
