c) Answer: most angles $\alpha, \beta, \gamma$ can apply any value in the interval $[\pi/2; \pi]$.

We have already shown in the solution to point 6) that the most angle cannot be acute, but can be right ($\gamma = \pi/2$). Let us now show that it can apply any value from $\pi/2$ to $\pi$, or more precisely, that for any $\alpha, \pi/2 < \alpha < \pi$, the equation is relative to $\beta$
$$\sin^2 \alpha + \sin^2 \beta = \sin(\alpha + \beta)$$
has a solution in the interval $0 < \beta < \pi - \alpha$ (so $\gamma = \pi - (\alpha + \beta) > 0$). Both sides of this equation are continuous functions of $\beta$, and for $\beta = 0$ the left side is less than the right side $(\sin^2 \alpha < \sin \alpha),$ and for $\beta = \pi - \alpha$ it is greater than $(2 \sin^2 \alpha > 0)$. Therefore, at some point $\beta, 0 < \beta < \pi - \alpha$, the values ​​of both parts coincide. This point will be the root of the equation.

The reader is invited to independently continue the study of our equation: prove that the angle $\gamma$ cannot be obtuse (to do this, you need to multiply the given correspondence by the square of the diameter of the circumscribed circle, obtain from it the inequality for the sides of the triangle using the theorem of sines and show that $\cos \gamma \leq 0$); check that the angles $\alpha, \beta$ and $\gamma$ not $\pi/2$ can be given by the beautiful formulas given in the margins (of course, statement 6) and c) immediately follow from these formulas.

**M859. Find the smallest positive number and also that for any quadratic trinomial $f(x)$ satisfying the inequality $|f(x)| \leq 1$ for $0 \leq x \leq 1$, the inequality $|f'(1)| \leq a$ holds.**

ANSWER: $a = 8$. Let the function $f(x) = Ax^2 + Bx + C$ satisfy the conditions of the problem. Note that $f'(1) = 2A + B, f(0) = C, f(1) = A + B + C$ and $f(1/2) = A/4 + B/2 + C$, and therefore $f'(1) = 3f(1) - 4f(1/2) + f(0)$. Hence,

$$|f'(1)| \leq 3 |f(1)| + 4 |f(1/2)| + |f(0)| \leq 8,$$

moreover, these inequalities turn into equalities for $f(0) = f(1) = 1, f(1/2) = -1$, that is, for the function $f_0(x) = 8x^2 - 8x + 1$ see figure. And since this function satisfies the inequality $|f_0(x)| \leq 1$ for $0 \leq x \leq 1$ (its graph is a parabola with the vertex at the point $x = 1/2$ - the minimum point), the number 8 in our estimate $|f'(1)|$ is impossible.

In fact, in the solution we will use the fact that a polynomial of $n$ degree, and therefore its product, is uniquely determined by its values ​​at $n+1$ points (at $n=2$). Try solving this problem for cubic polynomials yourself. Note that for an arbitrary degree $n$, the estimate in the problem will be given by the so-called Chebyshev polynomials, which can be read about in the article by N. Vasiliev and A. Zelevinsky “Chebyshev polynomials and recurrence relations” («Kvant», 1982, No. 1, p. 12).

V. P. Pikulin
