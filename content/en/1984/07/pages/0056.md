M857. Among the 1984 first natural numbers (from 1 to 1984), we note those that can be represented as the sum of fifths of non-negative integers of the power of two (that is, the fifths of not necessarily different numbers 1, 2, 4, 8, ...). Which numbers are greater: offset or not offset?

ANSWER: There are more offset numbers.

Since $2^n + 2^n = 2^{n+1}$, the sum of several powers of two can always be rewritten so that they are all different, and the number of terms can be reduced, for example $4 + 2 + 2 = 4 + 4 + 2 = 8 + 2$. Consequently, any canceled number is the sum of no more than five different terms of the form $2^n$, where $n = 0, 1, ..., 10$ ($2^{11} = 2048 > 1984$).

Let us find the number $N$ of such sums, that is, the set of different powers of two $n_1, ..., n_k$ ($0 \leq n_i \leq 10, 1 \leq k \leq 5$). Each set of $n_1, ..., n_k$ corresponds one-to-one to a set made up of all numbers from 0 to 10 except $n_1, ..., n_k$, so the number of $N_k$ sets of $k$ numbers is equal to the number of $11 - k$ numbers, and $N = N_1 + ... + N_5 = N_{10} + ... + N_6 = (N_1 + N_2 + ... + N_{10})/2$.
