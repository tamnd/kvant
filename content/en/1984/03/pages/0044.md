b) Prove that for any positive numbers $a, b, c$ the following inequality holds:

$$a^3b + b^3c + c^3a \geqslant a^2bc + b^2ca + c^2ab.$$

It is clear that the equality $(\vec{u} \cdot \vec{v})^2 = |\vec{u}|^2 |\vec{v}|^2$ is possible when the vectors $\vec{u}$ and $\vec{v}$ are collinear, that is, $\frac{a^3b}{c} = \frac{b^3c}{a} = \frac{c^3a}{b}$ or $a = b = c$.

There is also a short proof using complete squares:

$$a^3b + b^3c + c^3a - a^2bc - b^2ca - c^2ab = (a^3b - 2a^2bc + c^2ab) + (b^3c - 2b^2ca + a^2bc) + (c^3a - 2c^2ab + b^2ca) = ab(a-c)^2 + bc(b-a)^2 + ca(c-b)^2 \geqslant 0.$$
