**M837***. Let $a, b, c$ be positive integers, each two of which are coprime. Prove that the largest integer that cannot be represented as

$$xbc + yca + zab$$

(food $x, y, z$ are non-negative integers), equals

$$2abc - ab - bc - ca.$$

It is convenient to consider a more general problem at once:

let $a_1, a_2, \dots, a_n$ be natural polar coprime numbers. Let us call the natural number $u$ “red” if it can be represented in the form

$$u = a_1a_2\dots a_n \left( \frac{x_1}{a_1} + \dots + \frac{x_n}{a_n} \right),$$

(1)

food $x_1, x_2, \dots, x_n$ — non-negative integers, $u$ “blue” — otherwise. What is the largest number?

(In our problem $n = 3$.)

It is one of the shortest solutions to this problem based on the following two statements:

1) any integer $u$ admits a unique representation (1), where $x_1, x_2, \dots, x_n$ are integers, and $0 \leq x_2 \leq a_2 - 1$, ..., $0 \leq x_n \leq a_n - 1$, $x_1$ can be any (we will call such a representation standard);

2) the integer $u$ is red if and only if its standard representation is $x_1 \geq 0$.

From the last statement it is clear that the largest number $m$ has the standard representation $c x_1 = -1$, $x_2 = a_2 - 1$, ..., $x_n = a_n - 1$, that is

$$m = a_1a_2\dots a_n \left( n - 1 - \frac{1}{a_1} - \dots - \frac{1}{a_n} \right).$$

Let us prove these statements by induction, starting from the case $n = 2$. In this case, 1) turns into this very useful lemma (below $a_1 = a, a_2 = b$):

if the natural numbers $a$ and $b$ are coprime, then any integer can be uniquely represented in the form

$$u = bx + ay,$$

(2)

food $x, y$ - whole, $0 \leq y \leq b - 1$.

To prove it, we note that all remainders of the division $b$ of the numbers $0, a, 2a, \dots, (b - 1)a$ by $b$ are different (otherwise it would turn out that some number is of the form $(k - l)a$, where

0 ≤ l < k ≤ b - 1, is divisible by b, which is impossible), and therefore exactly one of them, ay, gives the same remainder as the number u, that is, u - ay = bx for some purposes x and y, 0 ≤ y ≤ b - 1.

Statement 2) for n = 2 is almost obvious: if the number u is red, that is, it has representation (2) with x ≥ 0, y ≥ 0, then in its standard representation the coefficient for b will be non-negative (if y = qb + r, where q ≥ 0, 0 ≤ r ≤ b - 1, then u = bx + ay = b(x + aq) + ar).

Thus, in this case, the most subtractable number will be m = b · (-1) + a · (b - 1) = ab - a - b.

Let us now show how to use the same lemma to make the transition from n = 2 to n = 3 (thus problem M837 will be solved; in the general case, the transition from n to n + 1 is performed in a similar way). Let us rewrite the representation of the form (1) of the number u, as shown in the margin. Since c and ab are mutually prime, by the lemma we can find (in a unique way) the integers v and z, 0 ≤ z ≤ c - 1, such that u = cv + abz, and then x and y, 0 ≤ y ≤ b - 1, such that v = bx + ay. This proves statement 1) for n = 3. To prove 2) it is enough to note that red u corresponds to red v, and the standard representation of u corresponds to the standard representation of v, in which x ≥ 0.

On figure there are red and blue numbers for a = 2, b = 3, c = 5; here m = 29. It can be seen that they are located symmetrically relative to the point m/2; if u is a red number, then m - u is blue. From our solution it is easy to deduce that this will be the case in the general case (for any a, b, c): the red numbers are all possible values of the function u(x,y,z) = bcx + cay + abz on the set of points in space with integer coordinates (x, y, z), where x ≥ 0, 0 ≤ y ≤ b - 1, 0 ≤ z ≤ c - 1, blue - its values on set x ≤ -1, 0 ≤ y ≤ b - 1, 0 ≤ z ≤ c - 1. These sets are symmetric, and the function u is linear, therefore its values on these sets are located symmetrically.

F848. A ball rolls along a main horizontal circular iron of length l. The speed of the ball is known with an accuracy of $\varepsilon = \pm 5\%$. For what values ​​of v can we say with certainty that after time t after the ball is at point A (see figure), it is not at point B?

Since the speed of the ball is known with an accuracy of $\varepsilon$, then for any moment of time it is possible to indicate not a point, but a certain area on the circle within which the ball is located. The front boundary of this area moves at a speed of $v + \varepsilon v = v(1 + \varepsilon)$, and the rear boundary moves at a speed of $v(1 - \varepsilon)$. After time t after the ball was at point A, the length of the segment will be 2vet. The fact that the ball is not currently at point B means that point B does not fall inside this region, that is (see figure).

$$2v\varepsilon - \frac{3l}{4} < v(1 + \varepsilon)\tau - nl < \frac{l}{4},$$

where $n$ is the number of complete revolutions of the ball in a circle during time t. From here we find $l$. From here there is a ball, “spreading” at a speed of 2ev. During this time, the ball will make $n = vt/l = 1/2\varepsilon$ full revolutions. So the problem makes sense for $n < \frac{1}{2\varepsilon} = \frac{1}{2(1/20)} = 10$.
