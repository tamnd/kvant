8.3. From the equality $\overrightarrow{A_1}\overrightarrow{B_1} + \overrightarrow{B_1}\overrightarrow{B_2} = \overrightarrow{A_1}\overrightarrow{A_2} + \overrightarrow{A_2}\overrightarrow{B_2}$ it follows
$$-\overrightarrow{A_1}\overrightarrow{A_2} + \overrightarrow{B_1}\overrightarrow{B_2} = \overrightarrow{A_2}\overrightarrow{B_2} - \overrightarrow{A_1}\overrightarrow{B_1}.$$
Similarly, $\overrightarrow{C_1}\overrightarrow{A_1} + \overrightarrow{A_1}\overrightarrow{A_2} = \overrightarrow{C_1}\overrightarrow{C_2} + \overrightarrow{C_2}\overrightarrow{A_2}$ implies
$$-\overrightarrow{A_1}\overrightarrow{A_2} + \overrightarrow{C_1}\overrightarrow{C_2} = \overrightarrow{A_2}\overrightarrow{C_2} - \overrightarrow{A_1}\overrightarrow{C_1}.$$
Using the conditions of the problem and these equalities, we obtain:
$$\overrightarrow{AB} = \overrightarrow{AO} + \overrightarrow{OB} = -\overrightarrow{OA} + \overrightarrow{OB} = -\overrightarrow{A_1}\overrightarrow{A_2} + \overrightarrow{B_1}\overrightarrow{B_2} =
= -\overrightarrow{A_1}\overrightarrow{B_1} + \overrightarrow{A_2}\overrightarrow{B_2},$$
$$\overrightarrow{AC} = \overrightarrow{AO} + \overrightarrow{OC} = -\overrightarrow{OA} + \overrightarrow{OC} = -\overrightarrow{A_1}\overrightarrow{A_2} + \overrightarrow{C_1}\overrightarrow{C_2} =
= -\overrightarrow{A_1}\overrightarrow{C_1} + \overrightarrow{A_2}\overrightarrow{C_2}.$$
We will use $\overrightarrow{a}'$ to denote the vector obtained from the vector $\overrightarrow{a}$ by rotating it by $60^\circ$ counterclockwise. It is clear that $(k\overrightarrow{a})' = k\overrightarrow{a}'$ and $(\overrightarrow{a} + \overrightarrow{b})' = \overrightarrow{a}' + \overrightarrow{b}'$. Since (Fig. 11) $\overrightarrow{A_1}\overrightarrow{B_1} = (\overrightarrow{A_1}\overrightarrow{C_1})'$, $\overrightarrow{A_2}\overrightarrow{B_2} = (\overrightarrow{A_2}\overrightarrow{C_2})'$, we get, $(\overrightarrow{AC})' = (-\overrightarrow{A_1}\overrightarrow{C_1} + \overrightarrow{A_2}\overrightarrow{C_2})' = -(\overrightarrow{A_1}\overrightarrow{C_1})' + (\overrightarrow{A_2}\overrightarrow{C_2})' = -\overrightarrow{A_1}\overrightarrow{B_1} + \overrightarrow{A_2}\overrightarrow{B_2} = \overrightarrow{AB}$. We see that the vector $\overrightarrow{AB}$ is obtained from the vector $\overrightarrow{AC}$ by rotating it by $60^\circ$. This means that $ABC$ is an equilateral triangle.
