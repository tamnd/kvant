Let's solve the problem immediately in general form. Let $f$ be a piecewise linear function with breaks at points with abscissas $a_1, \dots, a_m$ and let $k_0, k_1, \dots, k_m$ be the angular coefficients of the links of its graph on the intervals $] -\infty; a_1]$, $[a_1; a_2]$, ..., $[a_m; \infty$ [. Let us show that it can be uniquely represented in the form

$$f(x) = kx + b + c_1|x-a_1| + \dots + c_m|x-a_m|.$$

(1)

This can be done by “opening the models” on each of the $m+1$ intervals, equating the coefficient of $x$ in the resulting expression for $f(x)$ to the corresponding $k_i$ and solving the resulting system of equations for $k, c_1, \dots, c_m$. But you can immediately find the values ​​of $c_1, \dots, c_m$.

Let $l_i(x)$ be a linear function coinciding with $f(x)$ on the $i$-th interval; its slope is $k_i$. If the function $f(x)$ is representable in the form (1), that is, $f(x) = c_i|x-a_i| + h(x)$, where $h(x)$ is a function linear on the interval $[a_{i-1}; a_{i+1}]$, then on this interval $l_{i-1}(x) = c_i(a_i-x)+h(x)$, $l_i(x) = c_i(x-a_i)+h(x)$, and the slope of the difference $l_i(x) - l_{i-1}(x) = 2c_i x$ is equal to $k_i - k_{i-1}$. Therefore, equalities $c_i = (k_i - k_{i-1})/2, i=1, 2, \dots, m$ must hold. Conversely, if they are fulfilled, then the function $c_1|x-a_1| + \dots + c_m|x-a_m|$ has breaks at the same points as $f$, and the change in the angular coefficient when passing through any of these points for both functions will be the same. Therefore, the difference of these functions is a linear function $kx+b$. The angular coefficients of the left and right parts of (1) at $x>a_m$ are equal to $k_m$ and $k+c_1+...+c_m=k+(k_m-k_1)/2$, respectively, therefore $k=(k_1+k_m)/2$. The value of $b$ can be found by substituting into (1) any specific value of $x$, for example $x=0$.

The coefficients $k_0, \dots, k_9$ for the function $f_0$ are written above its graph (Fig. 2). Substituting them into the resulting formulas, we find the above answer.

d) Answer: If in the notation of the function $f$, considered in the problem, the sign of the model appears $n$ times, then the number of breaks $m(f)$ in its graph does not exceed $2^n-1$.

We will prove this statement by induction on $n$. For $n=0$ it is obvious (the linear function has no kinks). Let it be true if the number of the model is less than $n$, and the notation of the function $f$ includes $n$ of the model. Then this function can be represented in the form $f=|g|+h$, and the function $g$ is written with $n_1$ modules, and $h$ with $n_2$ modules, where $n_1+n_2=n-1$. By virtue of statement (1) and (2) to point a) and the assumption of induction

$$m(f) \leq m(|g|)+m(h) \leq 2m(g)+1+m(h) \leq 2 \cdot (2^{n_1}-1)+1+2^{n_2}-1=2^{n_1+1}+2^{n_2}-2 \leq 2^{n_1+n_2+1}-1=2^{n}-1,$$

since $2^{n_1+n_2+1}-2^{n_1+1}-2^{n_2}+1=(2^{n_1+1}-1)(2^{n_2}-1) \geq 0$.

The graph of the function $y=|...||x|-2^{n-2}|-2^{n-3}|...-1|$ (see Fig. 3 for $n=3$) has exactly $2^n-1$ break (for $n$ moduli in the function notation), so the estimate in the problem is exact.
