a) The graph of function $f_0$ is shown in red (Fig. 2). It is a broken line with a finite number of vertices - break points and two infinite extreme links; a function with such graphs is called Cousson-linear. Although this graph is constructed in a standard way, we will dwell on it in more detail - this allows us to make several substitutions that are useful in solving problem d).

Let $f(x) = |x-1| - 2|x| - 3|$, then $f_0(x) = |f(x)|$, and therefore the graph $f_0$ is obtained from the graph $f$ (black line on figure 2) by reflecting its part lying below the x-axis relative to this axis. It is clear that this rule for constructing a graph $|f|$ is valid for any function $f$. In particular, it follows from it that:

1) if $m(f)$ is the number of breaks of the Cousson-linear function $f$, then

$$m(|f|) \leq 2m(f) + 1.$$

(Indeed, when moving from $f$ to $|f|$, new breaks appear where the graph of the function $f$ intersects the $Ox$ axis, that is, no more than one on each link, and the number of links is 1 greater than the number of breaks $m(f)$.)

Further, the function $f$ is the sum of the functions $g(x) = |x-1|$ and $h(x) = -2|x| - 3|$, therefore it can have breaks only where at least one of the terms has a break, that is, at the points where the expressions under the model vanish: $x-1$, $x$ or $|x|-3$; these are points $-3, 0, 1$ and $3$. Exactly the same in general

2) for any Cousson-linear functions $g$ and $h$

$$m(g+h) \leq m(g) + m(h).$$

On each of the intervals $] -\infty; -3]$, $[-3; 0]$, $[0; 1]$, $[1; 3]$ and $[3; \infty[$ the functions $g, h$ and therefore $f$ are linear. “By opening the model”, we find that $f(x) = -x+1$ at $x \leq -3$, $f(x) = -3x-5$ at $-3 \leq x \leq 0$, etc., after which we can construct each link of the graph.
