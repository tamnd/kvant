Function selection $\varphi$

We will assume that equation (1) has a root $\xi$ on the given interval $[a, b]$ and that we have replaced this equation with the equivalent equation (2). Note that if condition (5) is not satisfied, the integration process (3) can be divergent (see Fig. 3).

It has been proven that the smaller the number $q$, the faster the interaction process (3) converges and the fewer successive approximations are required to obtain the final result. Therefore, when choosing the function $\varphi$, it is necessary to strive to ensure that the number $q$ is as small as possible. If we delete the function $\varphi$ so that the equation $\varphi'(\xi) = 0$ is satisfied, then iterazioni process (3) will converge very quickly.

But that's not all. It is imperative to take into account the convenience of calculations on this calculator. In order to reduce the time spent on computational work, the function $\varphi$ should be chosen so that the process of calculating the root according to formula (3) is integer. An integer computing process is a process that can be implemented on a given calculator without recording intermediate results.

In what follows we will construct only integer computational processes.
