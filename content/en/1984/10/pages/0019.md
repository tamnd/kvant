Let's show how this is done with an example. Suppose we need to calculate the positive root of the equation
$$x^5 - 10x^3 + 21x - 3 = 0.$$ (7)

Dividing the left side of the equation by $x$ and denoting $g(x) = 21 - 3/x$, we obtain the biquadratic equation $x^4 - 10x^2 + g(x) = 0$, solving which we find $x = \sqrt{5 \pm \sqrt{\frac{3}{x}} + 4}$.

Let's choose a working formula:
$$x_{n+1} = \sqrt{5 + \sqrt{\frac{3}{x_n}} + 4}, \quad n = 0, 1, 2, \dots$$

We carry out calculations on the “Elektronka BZ-14M”. Starting from $x_0 = 1$, we obtain the following series of successive approximations:
$$x_0 = 1, \quad x_3 = 2,694692,$$
$$x_1 = 2,765095, \quad x_4 = 2,694672,$$
$$x_2 = 2,693507, \quad x_5 = 2,694672.$$

Comparing the approximations $x_4$ and $x_5$, we see that equality (4) is satisfied up to $10^{-6}$. Therefore, the desired value of the root will be $x = 2,694672$ with the same accuracy. However, this still needs to be checked!

In a similar way, you can find the roots of other algebraic equations. We will write some of them here in general form:
1) $x^{2m+1} - ax \pm d = 0,$
2) $x^{2m+1} - 2ax^{2m} \pm bx \pm d = 0,$
3) $x^{2m+1} - 2ax^{2m+1} \pm bx \pm d = 0,$
$a > 0, \quad m = 0, \quad 1, \quad 2, \dots$

The described method for solving the equation is convenient in the sense that, as in the case of extracting roots, the initial approximation can be $x_0 = 1$.
