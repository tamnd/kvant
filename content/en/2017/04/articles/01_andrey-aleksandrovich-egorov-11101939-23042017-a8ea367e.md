$2^\circ$ (lemma about the fourth vertex of a parallelogram). If three vertices of a parallelogram are nodes of some lattice, then the fourth vertex is also a node of this lattice. $3^\circ$. If we draw a straight line through arbitrary two lattice nodes Q and R, then this straight line will pass through an infinite number of nodes (see Fig.1). In this case, all distances between neighboring nodes lying on a straight line will be equal. $4^\circ$. If a parallelogram with vertices at the nodes of a certain lattice does not contain other nodes on the sides and inside itself, then it generates this lattice.

It is clear that if the bullet trajectory passes through a node other than point A, then the hare sitting at this node will be killed. Therefore, only the case is interesting when node A is the only one on the bullet’s trajectory; it turns out that in this case some hare will be killed. The proof is contained in the following lemma. $5^\circ$ (lemma about the hunter and the hares). Let a ray l pass through node A of some lattice. Then there will be a node the distance from which to the ray l will be less than any predetermined number $\varepsilon$.

Proof. Let us denote the points of intersection of the ray l with the inclined straight lines of the grid by $A_{0} = A, A_{1}, A_{2},^{…}, A_{n},^{…}$ (see Fig. 3,a). Let us combine all the parallelograms on the right sides of which these points lie with the parallelogram ABCD, then each point $A_{n}$ will go to some point $A_{n} '$ on the side BC (see Fig. 3,b). For any $\varepsilon > 0$ there are points $A '_{m}$ and $A '_{m} +_{k}$ such that the distance between them is less than $\varepsilon$.

Now prove that the distance from the point $A_{k}$ to one of the lattice nodes is less than $\varepsilon$ (in particular, if $A '_{m}$ coincides with $A '_{m} +_{k}$, then $A_{k}$ will be a lattice node). Consequence. For any irrational number $\alpha > 0$ and any positive number $\varepsilon$ there are natural m and n such that $m \alpha - n < \varepsilon$.

Proof. Let us choose a Cartesian coordinate system on the plane and draw a straight line $y = \alpha x$. Due to the irrationality of $\alpha$, the only point with integer coordinates on this line will be the origin. Line $y = \alpha x$ intersects each vertical line x = m at point $( m, m\alpha )$. By Lemma $5^\circ$ there is a node ( m, n ) of the integer lattice such that the distance (vertical) from it to the point $( m, m\alpha )$ will be less than $\varepsilon$, which is what needed to be proved.

It is easy to see that among all possible pairwise distances between the nodes of any lattice there is a smallest one (prove it!). This property, together with the $2^\circ$ property of lattices, can be taken as the definition of lattices.
