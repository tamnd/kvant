There is a data set that is an N-dimensional array. The size of the array is known for each of the dimensions $M_{i}$, i=0...N – 1 (since these data are an array, it is more logical to number them from zero). But the contents of a multidimensional array, unfortunately, are represented in memory as a one-dimensional array. The order of elements is traditional, in ascending order of indices, starting from the left (for example, with N=2 and M={2,3} the elements of the original array will be located in the following order: [0,0], [0,1],[0,2], [1,0], [1,1], [1,2]). It is required to determine what the index in this one-dimensional array will be for an element that in a multidimensional array has indices $T_{i}$, i=1…N.
