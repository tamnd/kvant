M2490. There were 100 doors, each with its own key (unlocking only that door). The doors are numbered 1, 2, ......, 100, the keys are also numbered, but perhaps with errors: the key number matches the door number or differs by 1. In one attempt, you can select any key, any door and check whether this key fits this door. Is it possible to reliably find out which key opens which door by making no more than: a) 99 attempts; b) 75 attempts; c) 74 attempts? A. Lebedev, A. Shapovalov

Let's start with the proof of the following lemma. Lemma. Let players from N teams be lined up, each of which has at least N + 1 players. Then you can leave 2N players in the line, 2 from each team, so that any two players from the same team will stand next to each other. Proof. Induction on N. Base: for N = 1 the statement is obvious. Let's make the transition from N – 1 to N. Let's number the players in each team with the numbers 1, 2, ... from left to right. Among all the players with number 2, we will choose the one on the left. Let this be player $K_{2}$ playing for team K (here $K_{1}, K_{2}$, ... are all players of team K, numbered from left to right). Now let’s remove from the line all the players standing to the left of $K_{2}$, and the entire team K completely.
