4. The teacher is going to give the children the following type of problem. He will tell them that he has conceived a polynomial P(x) of degree 2017 with integer coefficients whose leading coefficient is 1. He will then report k integers $n_{1}, n_{2}$, … $, n_{k}$ and separately report the value of the expression $P ( n_{1} ) P ( n_{2} )$ … $P ( n_{k} )$. Using these data, children must find a polynomial that the teacher might have intended. At what minimum k can the teacher create a problem of this type so that the polynomial found by the children would necessarily coincide with what was planned? G. Zhukov
