Let us prove right away that the answer to question 6) is affirmative: if (for some $k > 1$) there is a $b = b_k$ such that $a(nk) \leq b \cdot a(n)$ for all $n$, then $a(n) \leq cn^u$ for some $c$ and $a$.

Let's put $a(1) = a$. Variable of a series of head inequalities on the fields, we obtain that (for any natural number $r$)
$$a(kr) \leq a \cdot br = a \cdot kr^u,$$
where $a = \log_k b$. For any $n$ we choose $r$ so that $kr^{-1} < n \leq kr$, that is, $\log_k n \leq r < \log_k n + 1$. Having obtained the monotonicity $a(n)$ and the second red identity in the margin, we obtain:
$$a(n) \leq a(kr) \leq a \cdot br < a \cdot b^{\log_k n + 1} = ab \cdot n^{\log_k b} = cn^u,$$
where $c = ab$.

Let us now construct an example showing that the answer to question c) is negative. It is not difficult to construct a sequence $a(n)$ that would have the property of multitypicality: $a(mn) = a(m)a(n)$ for all $m, n$, and at the same time (for any natural $r$) we would find $n$ such that $a(n) \geq n^r$. For example, you can put
$$a(n) = p_1^{i_1} p_2^{i_2} p_3^{i_3} \dots p_s^{i_s}$$
for $n = p_1^{i_1} p_2^{i_2} \dots p_s^{i_s}$ (where $p_1 = 2, p_2 = 3, p_3 = 5, \dots$ are sequential prime numbers); then for $m = \prod_{r=1}^{s} p_r^{i_r}$, $n = \prod_{r=1}^{s} p_r^{i_r}$ there will be $a(mn) = a(m)a(n) = \prod_{r=1}^{s} p_r^{i_r(i_r+i_r)}$ and for $n = p_r^k$ (for every natural $k$) $a(n) = p_r^k = n^r$.

For this sequence, the condition $a(n) \leq b_k a(n)$ will be satisfied, for example, at $b_k = a_k$. But for no $c$ and $a$ the estimate $a(n) \leq cn^a$ cannot be true for all $n$, since for $r > \alpha$ there are an infinite number of $n$ such that $a(n) \geq n^r > cn^a$ (for a sufficiently large $n$).
