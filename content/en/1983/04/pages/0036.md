On the other side,

$$-\frac{\pi}{2} \leq \arcsin(\sin x) \leq \frac{\pi}{2}.$$

From the inequality $\frac{\pi}{2} \leq x \leq \frac{3}{2} \pi$ it follows that

$$-\frac{\pi}{2} \leq \pi - x \leq \frac{\pi}{2}.$$

At $[-\frac{\pi}{2}; \frac{\pi}{2}]$ the sine is monotenous. So, $\arcsin(\sin x) = \pi - x$. So, $\arcsin(\sin x) =$

$$\begin{cases} x, & \text{если } -\frac{\pi}{2} \leq x \leq \frac{\pi}{2} \\ \pi - x, & \text{если } \frac{\pi}{2} \leq x \leq \frac{3}{2} \pi. \end{cases}$$

Since $\arcsin(\sin x)$ is a periodic function with period $2\pi$ (why?) and the segment $[-\frac{\pi}{2}; \frac{3}{2} \pi]$ has length $2\pi$, we can graph it (Fig. 7).

Problems involving calculations with “arcuses” are solved in a similar way.

Example 4. Let's calculate $A = \arcsin\frac{4}{\sqrt{65}} - \arccos\left(-\frac{11}{\sqrt{130}}\right)$.

First of all, $A = \arcsin\frac{4}{\sqrt{65}} - \left(\pi - \arccos\frac{11}{\sqrt{130}}\right) = \arcsin\frac{4}{\sqrt{65}} + \arccos\frac{11}{\sqrt{130}} - \pi$. Let us now evaluate the number $B = \arcsin\frac{4}{\sqrt{65}} + \arccos\frac{11}{\sqrt{130}}$. Since $\frac{4}{\sqrt{65}} > 0$ and $\frac{11}{\sqrt{130}} > 0$,

$$0 < \arcsin\frac{4}{\sqrt{65}} < \frac{\pi}{2}$$

$$0 < \arccos\frac{11}{\sqrt{130}} < \frac{\pi}{2}$$

Since on $[0; \pi]$ the sine is not monotenous, but the cosine is monotenous, we find cos $B$:

$$\cos B = \cos\left(\arcsin\frac{4}{\sqrt{65}} + \arccos\frac{11}{\sqrt{130}}\right) =$$

$$\cos\left(\arcsin\frac{4}{\sqrt{65}}\right) \times$$

$$\times \cos\left(\arccos\frac{11}{\sqrt{130}}\right) -$$

$$-\sin\left(\arcsin\frac{4}{\sqrt{65}}\right) \times$$

$$\times \sin\left(\arccos\frac{11}{\sqrt{130}}\right) =$$

$$\sqrt{1 - \left(\frac{4}{\sqrt{65}}\right)^2} \cdot \frac{11}{\sqrt{130}} -$$

$$-\frac{4}{\sqrt{65}} \cdot \sqrt{1 - \left(\frac{11}{\sqrt{130}}\right)^2} = \frac{\sqrt{2}}{2}$$.

From the correspondence between cos $B = \frac{\sqrt{2}}{2}$ and $0 < B < \pi$ it follows that $B = \arccos\frac{\sqrt{2}}{2} = \frac{\pi}{4}$. So, $A = B - \pi = -\frac{3}{4} \pi$.

Example 5. Let's compare the numbers $\arcsin\frac{2}{5}$ and $\arccos\frac{2}{5}$. Since $\frac{2}{5} > 0$,

$$0 < \arcsin\frac{2}{5} < \frac{\pi}{2}$$

$$0 < \arccos\frac{2}{5} < \frac{\pi}{2}$$
