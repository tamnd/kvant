Identities with “arcuses” are usually proven using the following method: first, the value of some trigonometric function φ (φ is sine, cosine or tangent) from both sides of the identity being proved is calculated

$$A = B$$

and it is verified that $\varphi(A) = \varphi(B)$, and, secondly, it is established that $A$ and $B$ are located on an interval where the chosen function φ is monotonic; then from the equality $\varphi(A) = \varphi(B)$ it follows that $A = B$.

Example 1. Let us prove that (4) is true for all $x \in [-1; 1]$. Let's calculate the cosine of both sides of equality (4):

$$\cos(\arccos(-x)) = -x,$$
$$\cos(\pi - \arccos x) = -\cos(\arccos x) = -x.$$

So, $\cos(\arccos(-x)) = \cos(\pi - \arccos x)$. By definition of arc cosine

$$0 \leq \arccos(-x) \leq \pi.$$

From the inequality $0 \leq \arccos x \leq \pi$ it follows that

$$0 \leq \pi - \arccos x \leq \pi.$$

At $[0; \pi]$ the cosine is monotonic. Hence,

$$\arccos(-x) = \pi - \arccos x.$$

If we chose sine as the calculated function, then, of course, we would also get the same values:

$$\sin(\arccos(-x)) = \sqrt{1 - \cos^2(\arccos(-x))} = \sqrt{1 - (-x)^2} = \sqrt{1 - x^2},$$
$$\sin(\pi - \arccos x) = \sin(\arccos x) = \sqrt{1 - \cos^2(\arccos x)} = \sqrt{1 - x^2}$$

(in both cases, “plus” is written before the root, since $0 \leq \arccos(-x) \leq \pi$ and $0 \leq \arccos x \leq \pi$, and on $[0; \pi]$ the sine is non-negative), but from the equality

$$\sin(\arccos(-x)) = \sin(\pi - x) = \sin(x).$$

Example 3. Let us prove that for $x \in \left[\frac{\pi}{2}; \frac{3}{2}\pi\right]$

$$\arcsin(\sin x) = \pi - x.$$

On the one side,

$$\sin(\arcsin(\sin x)) = \sin x,$$
$$\sin(\pi - x) = \sin x.$$
