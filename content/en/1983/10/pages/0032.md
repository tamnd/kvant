Often, tasks are proposed in one-day meetings, in which a description of a certain method of action is given and it is asked whether this or that result can be obtained as a result of these actions. The main method for solving such problems is to discover a property of the original object that does not change when performing the actions specified in the problem (this property is called an invariant). If the final object of the task does not have the found property, then it very/no cannot be obtained as a result of the described actions.
