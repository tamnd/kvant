Joseph Liouville (1809–1882)

Liouville's theorem (1844). If α is an algebraic number of degree n ≥ 2, then there is a number c > 0 such that for any p ∈ Z and q ∈ N
$$|\alpha - \frac{p}{q}| \geq \frac{c}{q^n}$$

(The meaning of the theorem is that the irrational algebraic number α cannot be “too good” approximated by rational fractions *). Therefore, if we find an irrational number that can be approximated "too well", it will not be algebraic.)

Proof. Let α be an algebraic number of degree n ≥ 2. Then there exists a polynomial with integer coefficients
$$P(x) = a_n x^n + a_{n-1} x^{n-1} + \dots + a_1 x + a_0, \ (a_n \neq 0),$$
that P(α) = 0. Let us denote by H the most of the models of the numbers |a_1|, |a_2|, ..., |a_n|. Let us show that the number

$$c = \frac{1}{n^2 H(1 + |\alpha|)^{n-1}}$$

has the required property. Note for further purposes that c < 1. Take arbitrary p ∈ Z and q ∈ N. Then

$$P\left(\frac{p}{q}\right) = \frac{a_n p^n + a_{n-1} p^{n-1} q + \dots + a_1 p q^{n-1} + a_0 q^n}{q^n} = \frac{a}{q^n}.$$

By Lemma $P\left(\frac{p}{q}\right) \neq 0$. This means a ≠ 0.

Since a ∈ Z, we have |α| ≥ 1. Therefore,

$$|P\left(\frac{p}{q}\right)| \geq \frac{1}{q^n}.$$

Since P(α) = 0, we get

$$\frac{1}{q^n} \leq |P\left(\frac{p}{q}\right)| = |P(α) - P\left(\frac{p}{q}\right)| = |a_n \left(a^n - \left(\frac{p}{q}\right)^n\right) + a_{n-1} \left(a^{n-1} - \left(\frac{p}{q}\right)^{n-1}\right) + \dots + a_1 \left(a - \frac{p}{q}\right)|.$$

If |α - \frac{p}{q}| ≥ 1, then |α - \frac{p}{q}| ≥ 1 ≥ \frac{1}{q^n} > \frac{c}{q^n}.

If |α - \frac{p}{q}| < 1, then |\frac{p}{q}| < |\alpha| + 1. Then for any 1 ≤ k ≤ n, k ∈ N, we obtain

$$|\alpha^k - \left(\frac{p}{q}\right)^k| = |\alpha - \frac{p}{q}| \cdot |\alpha^{k-1}| + \alpha^{k-2} \cdot \frac{p}{q} + \dots + \left(\frac{p}{q}\right)^{k-1} \leq \left| \alpha - \frac{p}{q} \right| k(|\alpha| + 1)^{k-1} \leq \left| \alpha - \frac{p}{q} \right| n(|\alpha| + 1)^{n-1}.$$

From here

$$\frac{1}{q^n} \leq |\alpha - \frac{p}{q}| n^2(|\alpha| + 1)^{n-1} H = |\alpha - \frac{p}{q}| \cdot \frac{1}{c}, |\alpha - \frac{p}{q}| \geq \frac{c}{q^n}.$$

The theorem has been proven.
