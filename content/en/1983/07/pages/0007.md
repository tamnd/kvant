Theorem. If $a - a$ is an allebraic number of degree $n$, then there is a number $c_0 > 0$ such that for any $p \in \mathbb{Z}$ and $q \in \mathbb{N}$ for which $a \neq p/q$, we have

$$\left| a - \frac{p}{q} \right| \geq \frac{c_0}{q^n}.$$

Proof. The case deg($\alpha$) $\geqslant 2$ was considered above. Let now deg($\alpha$) = 1, that is, $a = a/b$ ($a \in \mathbb{Z}$, $b \in \mathbb{N}$). then the number $c' = 1/b$ has the desired property. Indeed, if $a/b \neq p/q$, then $|pb - qa| \geqslant 1$. Hence,

$$\left| a - \frac{p}{q} \right| = \left| \frac{a}{b} - \frac{p}{q} \right| = \frac{|pb - qa|}{bq} \geqslant \frac{1}{bq} = \frac{c'}{q}.$$

Choosing as $c_0$ the smallest of the numbers $c$ and $c'$, we obtain the required inequality.

Liouville’s theorem can also be proven by studying the difference $P(\alpha) - P(p/q)$ using Lagrange’s theorem (“Algebra and principles of analysis 9-10”, paragraph 25). Try this!

Approximation of algebraic rational numbers

We will say that the number $a$ admits an approximation of order $m$ if for some constant $\gamma$ there are an infinite number of rational fractions $p/q$ satisfying the inequality

$$0 < \left| a - \frac{p}{q} \right| < \frac{\gamma}{q^m}.$$

Liouville's theorem shows that an allebraic number of degree $n$ does not admit an approximation of order $m$, then from (1) and (2) we obtain that for an infinite sequence of natural numbers $q$

$$\frac{c}{q^n} < \frac{\gamma}{q^m}, \frac{1}{q^{m-n}} > \frac{c}{\gamma},$$

and this inequality is impossible for $m > n$ and sufficiently large $q$.

Example of a transcendental number *)

We now have a means of constructing real numbers that are not algebraic. (Such numbers are called transcendental.) It is necessary to construct a number that can be approximated to an arbitrarily high order. We will specify such a number as an infinite decimal fraction: $\alpha = 0$, $a_1 a_2 a_3 \dots$, where $a_i = \begin{cases} 1, \text{ если } t = m! \text{ (m = 1, 2,...)}, \\ 0, \text{ если } t \neq m!. \end{cases}$

In particular,

$$a_1 = a_2 = a_6 = a_{24} = a_{120} = a_{720} = \dots = 1,$$

$$a_3 = a_4 = a_5 = a_7 = \dots = a_{23} = a_{25} = \dots = a_{119} = a_{121} = \dots = 0.$$

Then for any $m > 1$

$$\alpha = 0, a_1 \dots a_{(m-1)!} + 0, 0 \dots 0_{am!} = \frac{p_m}{q_m} + \beta_m,$$

Where

$$p_m = a_1 a_2 \dots a_{(m-1)!},$$

$$q_m = 10^{(m-1)!}, \beta_m = 0, 0 \dots 0_{am!} \dots,$$

$$0 < \beta_m = 10^{-m!} \cdot a_m! \dots =$$

$$= 10^{-m!} \cdot 1, \dots < 2 \cdot 10^{-m!} = \frac{2}{q_m^m}$$

Thus,

$$0 < \left| a - \frac{p_m}{q_m} \right| < \frac{2}{q_m^m}, \quad m = 1, 2, \dots,$$

which means that $a$ admits approximations of arbitrarily high order and therefore cannot be algebraic.
