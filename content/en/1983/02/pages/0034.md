All! Geometry is over - algebra begins (in which the applicant usually feels more confident). Let's collect the resulting equations in the system:

$$r = \frac{a}{2} \text{tg} \frac{a}{2}$$
$$(r + R)^2 - (R - r)^2 = \left( \frac{a \sqrt{2}}{2} \right)^2 \text{или } 8Rr = a^2$$
$$R = a \text{tg} \varphi$$
$$R = 2a \text{ctg} \alpha.$$

The dimensional quantities $R, r$ and $a$ are easily excluded from it, after which a system of two equations with unknowns $\varphi$ and $\alpha$ remains:

$$\begin{cases} 4 \text{tg} \varphi \text{tg} \frac{a}{2} = 1 \\ \text{tg} \varphi = 2 \text{ctg} \alpha. \end{cases}$$

We will leave the solution to this system to the readers. (Answer: $\text{tg} \varphi = \frac{\sqrt{3}}{6}$.)

Let's summarize. Solving steric problems with many formulas and connections between them can be divided into the following stages:

1. Construct a drawing - a general view of the configuration. There should be no auxiliary lines in the drawing: they only obscure the overall picture.

2. Enter variables that determine the dimensions of drawing elements. Don't be afraid if there are a lot of these variables: there should be enough of them to build each configuration element separately.

3. Select links of figures, use the general drawing and conditions of the problem.

4. Enter each of the links into a separate drawing and mark the drawings.

5. Choose such an angle (or such a section) for each connection so that all the segments and angles that are supposed to be connected to the equations are visible in full size. Mark the resulting drawing.

6. Write down the equations that are obtained from each connection of the figures. Do not rush to resolve them regarding each value.

7. Check the use of all conditions, the number of equations and unknowns, and the ability to find the value required by the condition.

8. Reduce the equations in the system and solve it, forgetting about geometry and using the techniques of algebra and trigonometry.

9. Check the solution. The technique for checking geometric solutions deserves a separate discussion*). Now we will get acquainted with one of its techniques - let’s estimate how well the drawings and the answer in our problem agree with each other.
