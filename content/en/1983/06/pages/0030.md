But this turned out to be beyond the power of Archimedes and his contemporaries...
In general, an equation of the form
$$x^2 - Dy^2 = 1,$$
(6)
where $D$ is a natural number that is not a square $^*$), is called Pell’s equation; Of course, this is a Diophantine equation, that is, an algebraic equation with integer coefficients, the solution of which is sought in the domain of integers.

How to solve Pell's equation?
The first thing that comes to mind is direct search: alternately substitute the numbers $x = 1, 2, 3, \dots$ into the formula $y = \sqrt{(x^2 - 1)/D}$ until the radical expression turns out to be an exact square. The futility of this approach is shown by the following remarkable example. Equation
$$x^2 - 991y^2 = 1$$
has a solution in integers, but among its solution $(x_0, y_0)$ the smallest (!) $x_0$ is equal to
379 516 400 906 811 930 638 014 896 080.
Further, on the most powerful computer it is not added to it by simple brute force!

It turns out that continued fractions provide a very convenient tool for solving Pell's equation. Let us describe the algorithm (without proof) for the solution.

For every natural number $D$ other than the square of an integer, equation (6) has an infinite number of solutions in positive integers $x, y$. All of them can be found using the formula
$$x + y\sqrt{D} = (x_0 + y_0\sqrt{D})^k,$$
$k = 1, 2, \dots$,
where $x_0, y_0$ is the solution with the smallest value $y$. To find the smallest solution $(x_0, y_0)$, you need to factor $\sqrt{D}$ into a whole fraction. If
$$\sqrt{D} = [a_0; a_1, \dots, a_n, 2a_0]$$
and $\frac{p_n}{q_n}$ is a suitable fraction of the number $\sqrt{D}$ with number $n$, then
$$p_n^2 - Dq_n^2 = (-1)^{n-1},$$
(7)
and if $n$ is odd (the length of the period is even), then
$$p_n = x_0, q_n = y_0$$
will be the smallest solution to the equation

Example 3. Let's distance the equation
$$x^2 - 7y^2 = 1.$$
From the expansion $\sqrt{7} = [2; 1, 1, 1, 4]$ we find
$$\frac{p_3}{q_3} = 2 + \frac{1}{|1|} + \frac{1}{|1|} + \frac{1}{|1|} = \frac{8}{3}.$$
Since the line of period is even, the smallest solution to the equation is $x_0 = 8, y_0 = 3$, and any solution in natural numbers is obtained by the formula
$$x + y\sqrt{7} = (8 + 3\sqrt{7})^k,$$
$k = 1, 2, \dots$
For $k = 2$ we have $x = 127, y = 48$.
Example 4. Solve the equation
$$x^2 - 13y^2 = 1.$$
Expanding $\sqrt{13}$ into a whole fraction, we get $\sqrt{13} = [3; 1, 1, 1, 1, 6]$
and $\frac{p_4}{q_4} = 3 + \frac{1}{|1|} + \frac{1}{|1|} + \frac{1}{|1|} + \frac{1}{|1|} = \frac{18}{5}$.
The length of the period is even, so the smallest solution is found by the formula
$$x_0 + y_0\sqrt{13} = (18 + 5\sqrt{13})^2 = 649 + 180\sqrt{13},$$
that is, $x_0 = 649, y_0 = 180$. The general solution has the form
$$x + y\sqrt{13} = (649 + 180\sqrt{13})^k,$$
$k = 1, 2, \dots$
