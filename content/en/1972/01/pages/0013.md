With respect to all transformations $T_k$, only the set of all roots $\{\varepsilon_1, \dots, \varepsilon_{16}\}$ is invariant.

The cardinal insight is that the group of roots is “better” the greater the number of transformations that leave this group invariant.

Let us introduce another numbering $T_{[l]}$ for $T_k$, as was done for $\varepsilon_k: T_{[l]} = T_k$, $k = 3^l$. In new notations

$$T_{[k]}^{\varepsilon_l} = \varepsilon_{[k+l]}, \quad T_{[m]}(T_{[k]}^{\varepsilon_l}) = T_{[m+k]}^{\varepsilon_l}$$

(the sum in square brackets must be modulo 16). The reader will, of course, discover an analogy with the transition to logarithms, which is not surprising, since $\varepsilon_{[l]} = \varepsilon_{3l}$.

Problem 3. Prove that if a certain set of roots is invariant under some $T_{[k]}$, where $k$ is odd, then this set is invariant under all transformations $T_{[m]}$, that is, if it is not empty, then it will coincide with the set of all roots.

Note. Show that if $k$ is odd, then there is a $m$ such that $km$ gives remainder 1 when divided by 16.

On the other hand, there are two groups of roots invariant under all $T_{[k]}$ with four $k$: roots $\varepsilon_l$ with four $l$ and four roots $l$. We denoted their amounts by $\sigma_{2,0}, \sigma_{2,1}$.

It is clear that $\sigma_{2,0} + \sigma_{2,1} = -1$. Let's explore $\sigma_{2,0} \cdot \sigma_{2,1}$. This product is the sum of pairwise products $\varepsilon_{[k]}^{\varepsilon_l}$, where $k$ is even, $l$ is odd, each of which is some root $\varepsilon_m$, and there are 64 terms in total. We will show that among them, each of the roots $\varepsilon_{[0]}, \varepsilon_{[1]}, \dots, \varepsilon_{[15]}$ occurs the same number of times (four times), resulting in $\sigma_{2,0} \cdot \sigma_{2,1} = -4$. Let us take advantage of the fact that the transformations $T_{[k]}$ preserve groups of roots when $k$ is even and transform them into one another when $k$ is odd. Each term in $\sigma_{2,0} \cdot \sigma_{2,1}$ is uniquely transformable into the form $\varepsilon_{[m]}^{\varepsilon_{[m+r]}}$, where $0 \leq m \leq 15$, $r = 1, 3, 5, 7$ (prove it!). Let's group terms with the same $r$. Popular sums will be of the form

$$\varepsilon_{[0]}^{\varepsilon_r} + \varepsilon_{[1]}^{\varepsilon_r} + \varepsilon_{[2]}^{\varepsilon_r} + \dots + \varepsilon_{[15]}^{\varepsilon_r} = T_{[0]}^{\varepsilon_{[0]}^{\varepsilon_r}} + T_{[1]}^{\varepsilon_{[0]}^{\varepsilon_r}} + \dots + T_{[15]}^{\varepsilon_{[0]}^{\varepsilon_r}} = \varepsilon_{[0]} + \dots + \varepsilon_{[15]} = -1,$$

where $\varepsilon_{[k]} = \varepsilon_{[0]}^{\varepsilon_{[r]}}$. We will use the fact that $T_{[m]}^{\varepsilon_{[k]}} \cdot T_{[m]}^{\varepsilon_{[l]}} = T_{[m]}(\varepsilon_{[k]}^{\varepsilon_{[l]}})$ and the already mentioned property $T_{[m]}$.

The values ​​of $\sigma_{2,0}, \sigma_{2,1}$ are found in Appendix 1.

Let's move on to the next step. We want to introduce into consideration new, smaller groups of roots that are invariant under some $T_{[k]}$. By analogy with Problem 3, it can be shown that in this case $k$ must necessarily be divisible by 4. Therefore, there are four groups of roots that are invariant with respect to all $T_{[4l]}$ and smaller than those already considered; Let's write down the sums of the roots in each group: $\sigma_{4,0}, \sigma_{4,1}, \sigma_{4,2}, \sigma_{4,3}$. We have already noted that

$$\sigma_{4,0} + \sigma_{4,2} = \sigma_{2,0}; \quad \sigma_{4,1} + \sigma_{4,3} = \sigma_{2,1}.$$

Let's calculate the product $\sigma_{4,0} \cdot \sigma_{4,2}$; it is represented as a sum of 16 terms of the form $\varepsilon_{[4k]}^{\varepsilon_{[4l+2]}}$, which such term is uniquely written in the form $\varepsilon_{[2m]}^{\varepsilon_{[2m+2r]}}, r = 1, 3, m = 0, 1, 2, 3, 4, 5, 6, 7$.

Let us group the terms with one $r$ and replace that $\varepsilon_{[0]}^{\varepsilon_{[2]}} = \varepsilon_{1} \varepsilon_{9} = \varepsilon_{10} = \varepsilon_{3}, \varepsilon_{[0]}^{\varepsilon_{6}} = \varepsilon_{1} \varepsilon_{15} = \varepsilon_{16} = \varepsilon_{8}$. For $r = 1$ we get the sum

$$T_{[0]}^{\varepsilon_{[3]}} + T_{[2]}^{\varepsilon_{[3]}} + \dots + T_{[14]}^{\varepsilon_{[3]}} = \sigma_{2,1};$$

at $r = 3$ — sum

$$\sum_{k} T_{[2k]}^{\varepsilon_{[8]}} = \sigma_{2,0},$$

that is, $\sigma_{4,0} \cdot \sigma_{4,2} = \sigma_{2,0} + \sigma_{2,1} = -1$. By solving quadratic equations, we found $\sigma_{4,0}, \sigma_{4,2}$.

In the last step we will consider groups of roots that are invariant under $T_{[8]}$; we will use them $\varepsilon_{[0]}^{\varepsilon_{[r+1]}} + \varepsilon_{[1]}^{\varepsilon_{[r+1]}} + \varepsilon_{[2]}^{\varepsilon_{[r+1]}} + \dots + \varepsilon_{[15]}^{\varepsilon_{[r+1]}} = T_{[0]}^{\varepsilon_{[0]}^{\varepsilon_{[r+1]}}} + T_{[1]}^{\varepsilon_{[0]}^{\varepsilon_{[r+1]}}} + \dots + T_{[15]}^{\varepsilon_{[0]}^{\varepsilon_{[r+1]}}} = \varepsilon_{[0]} + \dots + \varepsilon_{[15]} = -1$. This allows us to find $\sigma_{8,0} = 2 \cos \frac{2\pi}{17}$ and thereby complete the solution.
