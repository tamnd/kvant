So, we have explored how an image is obtained in a picture plane, but it turned out that it also depends on the point from which we look at it. So let's do this.

Let's call a kaleidoscope “physical rules” if the image in its picture plane does not depend on the point of observation, and “mathematical rules” if for any point X the picture plane different sequences of geometric reflections leading to point X give in it an image of the same point of the functional polygon.

Let us note the difference between the mathematical and physical concepts of the correctness of a kaleidoscope. Geometrically, we can deliver images to point X by any sequence of reflections. But not every image can be seen from at least one point inside the kaleidoscope. However, from the examples we gave at figure 7 - the image delivered along the blue path is visible at point X, but not along the red path. Here's another example.

Problem 2. Proving that in a kaleidoscope, the perpendicular section of which is an equilateral triangle with sides $R_1, R_2, R_3$ is impossible. make the sequence of reflections of the sowing ray: $R_1, R_2, R_1, R_3, R_2, R_3$.

Could it happen that the mathematical kaleidoscope is incorrect, that is, there is a point X and two sequences of reflections giving different images in X, but one of these images is visible from any point, and the second (or all the others) is never visible, that is, the physical kaleidoscope will be correct?

It turns out that this is not the case. It is absolutely clear that if the same image arrives at point X via geometric (reflections) via different routes, then it will be visible from any point. But at the same time, if from any observation point $T$ the same image is visible at point X, then exactly one image is obtained geometrically at point X. We will now proceed to prove the last statement and find all correct kaleidoscopes.
