Hole - magnifying glass

Since the hole acts similarly to a lens, all the formulas derived for an ideal lens must be valid for it, only together with the values ​​of the lens distance formula, you need to substitute the set of values ​​of the lens distance formula, expressed in millimeters.

From formula (2) it can be seen that the minimum value of the distance formula of a circular hole acting as a converging lens is $f' = \frac{D^2}{2\lambda}$. Therefore, when using the hole as a magnifying glass, the maximum magnification is

$$N = \frac{500\lambda}{D^2}.$$
