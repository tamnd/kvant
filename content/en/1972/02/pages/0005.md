Figure 1, can be divided into classes by color (Fig. 2, a), by shape (Fig. 2, b) or by some other characteristic. However, to divide a set into classes, we need not only the properties inherent in each element separately, but rules indicating whether two arbitrarily selected elements of a given set should be classified into the same or different classes. For example, all straight planes can be divided into classes if we agree to classify two straight lines into one class if and only if they are parallel. In the resulting partition, any two (not necessarily different *)) lines of the same class are parallel, and any two lines from different classes are not parallel. In this example, we do not use a property that each individual line has or does not have, but a property that refers to pairs of lines (whether a and b are parallel or not parallel).
