6. Ion the Quiet Method

N. Ya. Vilenkin in the book “Stories about Sets” told about the imaginary 1001st stellar voyage of Ion the Quiet, a famous hero written by the wonderful Polish writer Stanislaw Lem.

On this trip, Ion encountered the following problem: he needed to accommodate another traveler in a hotel, all of whose rooms were occupied. A particular challenge is that the hotel has an infinite number of rooms. Ion solves the problem this way: each hotel dormitory is given an order to move to a room with a number one unit larger than the number of its room. At the same time, all the former hotel dormitories provide housing (after all, the last room is not in the endless row!), and room No. 1 is freed up for a new traveler.

This method can be applied when solving problems of calculating circuits with an infinite number of elements. Note that although for specific physical purposes the number of elements is always finite, it can be so large that its approximation can be considered infinite.

For use, consider the following problem.

Problem 9. Find the resistance $R$ of a circuit section containing an infinite number of resistances (Fig. 9, a), each of which is equal to $r$.

Solution f. If we, using the idea of ​​Ion the Quiet, separate the first link from three resistances $ACDB$, then the circuit and its resistance do not change. Therefore, the circuit shown in figure 9, a, is equivalent to that presented in figure 9, 6. Now it is easy to find

$$R_{AB} = 2r + \frac{Rr}{R + r} = R,$$

whence $R = r(1 + \sqrt{3})$.

Other problems for circuits with an infinite number of resistances are solved similarly.
