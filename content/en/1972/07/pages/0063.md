4. $x = \frac{\pi}{3} + 2\pi n$. Note. The ODZ of the original equation is determined by the conditions: 1) $\cos x + 1 > 0$; 2) $\sin x > 0$; 3) $\sin x \neq \frac{\sqrt{2}}{2}$. Go to equation $1 + \cos x = 2\sin^2 x$
and expressing $\sin^2 x$ through $1 - \cos^2 x$, we obtain a set of equations: 1) $\cos x + 1 = 0$, 2) $\cos x = \frac{1}{2}$. From the solution we select only those that are included in the ODZ of the original equation, that is, $x = \frac{\pi}{3} + 2\pi n$.
Sweeping. If $2\sin^2 x$ is replaced by $1 - \cos 2x$, we obtain the equation $\cos x = -\cos 2x$, whence $x_1 = \pi + 2\pi n$, $x_2 = \frac{\pi}{3} + \frac{2}{3} \pi n$; $\sin x_1 = 0$ and therefore $x_1$ is not included in the ODZ, and from the solution of the series $\frac{\pi}{3} + \frac{2}{3} \pi n$ it is necessary to display those that are included in the ODZ. To do this, we divide the series $\frac{\pi}{3} + \frac{2}{3} \pi n$ into 3, as we say, elementary series:
$x_1 = \frac{\pi}{3} + 2\pi n; x_2 = -\frac{\pi}{3} + 2\pi n; x_3 = \pi + 2\pi n,$ of which only $\frac{\pi}{3} + 2\pi n$ is included in the ODZ.
