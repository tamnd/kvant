Task 5. We need to prove that $\overrightarrow{A_1} + \overrightarrow{A_3} + \overrightarrow{A_5} < 450^\circ$. For inscribed angles $A_1, A_3$ and $A_5$ the following equalities are true*)

$$\overrightarrow{A_1} = 180^\circ - \frac{\cup A_2 A_7}{2},$$

$$\overrightarrow{A_3} = 180^\circ - \frac{\cup A_4 A_2}{2},$$

$$\overrightarrow{A_5} = 180^\circ - \frac{\cup A_6 A_4}{2} \text{ (см. рис. 1)}.$$

Pozny

$$\overrightarrow{A_1} + \overrightarrow{A_3} + \overrightarrow{A_5} = 3 \cdot 180^\circ - \frac{\cup A_6 A_7}{2} = 2 \cdot 180^\circ + \frac{\cup A_7 A_6}{2}.$$

But the arc $A_7 A_6$ cannot be greater than positive, since otherwise the center of the circle $O$ would not lie inside our heptagon. Hence,

$$\overrightarrow{A_1} + \overrightarrow{A_3} + \overrightarrow{A_5} = 360^\circ + \frac{\cup A_7 A_6}{2} < 360^\circ + 90^\circ = 450^\circ.$$

Task 5. The easiest way to solve this problem is from the end - first agree to the answer, and then prove that it is correct. You can guess the answer using such messages. Let, for some values ​​of $x = x_0$ and $y = y_0$, the value $s$ be maximum and equal to $s_0$. Let's assume that the numbers $x_0, y_0 + \frac{1}{x_0}, \frac{1}{y_0}$ are not equal to each other. Let, for example, $s_0 < y_0 + \frac{1}{x_0}$. Let's increase $x_0$ a little like this,

For a new value of $x$ to be equal to $x'_0$, the inequality $s_0 < y_0 + \frac{1}{x'_0}$ is preserved.

After this, let’s decrease $y$ a little - again so that the new value $y$, equal to $y'_0$, preserves the inequality $s_0 < y'_0 + \frac{1}{x'_0}$.

We have arrived at such values ​​of $x'_0$ and $y'_0$ that for them $s$ is greater than $s_0$. The cases $s_0 < x_0$ and $s_0 < \frac{1}{y_0}$ are treated similarly. Therefore $x_0 = y_0 + \frac{1}{x_0} = \frac{1}{y_0} = s_0$, hence $x_0 = \sqrt{2}, y_0 = \sqrt{2}, s_0 = \sqrt{2}$. These arguments are not entirely rigorous, and the point here is not in the words “a little”, but in the fact that we assumed that there is a set $x_0, y_0$ for which $s$ belongs to the maximum value. (This fact is not very visible.) However, having proven the answer $s_0 = \sqrt{2}$, it is quite easy to complete the solution. Indeed, let for some values ​​$x_0, y_0, s > \sqrt{2}$. then $x_1 > \sqrt{2}, \frac{1}{y_1} > \sqrt{2}$, whence $\frac{1}{x_1} + y_1 < \frac{1}{\sqrt{2}} + \frac{1}{\sqrt{2}} < \sqrt{2}$, that is, s for this set is less than $\sqrt{2}$. The resulting contradiction shows that the maximum value of s is $\sqrt{2}$ and that it is achieved only at $x = \sqrt{2}, y = \sqrt{2}$.
