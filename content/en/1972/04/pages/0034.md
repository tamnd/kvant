Let us finally return to the question formulated at the beginning of the article: “Are there such maps on a torus with a number of countries greater than seven, in which every two countries have a common border?”

Let us show that it is enough to consider only those maps in which exactly three countries converge at each vertex.

Indeed, let more than three countries converge at each vertex of the desired map (see Fig. 4). It is easy to transform the map so that all vertices have exactly three countries, the number of countries remains the same, but the number of vertices increases. The method of such a restructuring is clearly visible from figure. In this case, those countries that had a common border (but not a vertex) will also have a common border.

Teller we will be present to the bill. Let the number of countries on the map be $n$ (that is, $C=n$), then, since each country has at least one border with each of $n-1$ others, then the number of borders for each country is at least $n-1$.

Each border belongs to exactly two countries, so the total number of borders is at least $\frac{n(n-1)}{2}$. So we got that $\Gamma \geq \frac{n(n-1)}{2}$. Let's count the number of vertices. At each vertex exactly three boundaries converge, and each boundary contains exactly 2 vertices. Therefore, twice the number of boundaries is equal to three times the number of vertices, or $2\Gamma = 3B$ or $B = \frac{2}{3}\Gamma$.

Let's substitute the resulting expression for $B$ into Euler's formula: $-\frac{\Gamma}{3} + C = 0$ or $\Gamma = 3C$.

Since $C=n$ and $\Gamma \geq \frac{n(n-1)}{2}$, then $3n \geq \frac{n(n-1)}{2}$ or $7n \geq n^2$.

Hence $n \leq 7$.

The proof is over.
