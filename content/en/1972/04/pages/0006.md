ARRANGEMENT
CUBES

N. B. Vasiliev

In this article, we discussed the solution to one of the problems offered to ninth- and tenth-classics students at last year’s All-Union Mathematical Olympiad in Riga (see «Kvant» No. 11, 1971). It was formulated like this.

Task. A cube with edge length $n$ is divided into $n^3$ unit cubes. Let's select several cubes and draw three straight lines parallel to the edges through the center of each of them. What is the smallest number of cubes that can be chosen such that a straight line drawn through them will cross out all the cubes?

a) Give the answer for small values ​​of $n$: for $n=2, 3, 4$.

b) Try to find the answer for $n=10$.

c) Solve the general problem. If you were unable to find the exact answer, prove some inequalities that estimate from above and below the number of marked cubes.

d) Note that this problem can be formulated as follows. Consider all possible sets $(x_1, x_2, x_3)$, where each of the letters $x_1, x_2, x_3$ takes one of $n$ values ​​1, 2, ..., $n$. What is the smallest number of sets that must be chosen so that for each of the remaining sets among the selected ones we find one that differs from it only in one place (by the value of only one of the coordinates $x_1, x_2, x_3$)? Try to find estimates for the number of sets in a more general problem, when sets of not three, but four or more letters are considered.

Formulation with rooks

In order not to be confused by the words “cube”, “cube” and “selected cube”, it is convenient to reformulate the problem in other terms. We call the entire cube $n \times n \times n$ a “spatial chessboard”, each of the cubes $1 \times 1 \times 1$ a “cell”, each chosen cube a “square occupied by a rook”.
