4. $\alpha_1 = -1$, $\alpha_2 = 0$. Solution. Let us rewrite the system of inequalities in the form

$$\begin{cases} x^2 + 4x + 3 - \alpha \leq 0, \\ x^2 - 2x - 3 + 6\alpha \leq 0. \end{cases}$$

If for some $\alpha$ the discriminant of at least one of the trinomials building on the left sides is negative, then this system has no solution (why?). Consequently, system (1) can have solutions only for such $\alpha$ for which the inequalities simultaneously hold

$$1 + \alpha \geq 0, \quad 4 - 6\alpha \geq 0,$$

that is, only at $-1 \leq \alpha \leq \frac{2}{3}$ (carry out the necessary calculations).

For $\alpha = -1$ system (1) really has a unique solution (check this). For $\alpha = \frac{2}{3}$ system (1) has no solution (prove this).

Let now $\alpha$ be some number from the interval $-1 < \alpha < \frac{2}{3}$. In this case, solutions to the first inequality of system (1)

is a segment

$$-2 - \sqrt{1 + \alpha} \leq x \leq -2 + \sqrt{1 + \alpha},$$

and the solution to the second inequality of this system is the segment

$$1 - \sqrt{4 - 6\alpha} \leq x \leq 1 + \sqrt{4 - 6\alpha}.$$

System (1) has a unique solution; segments (2) and (3) have only one common point.

Since $-2 - \sqrt{1 + \alpha} < 1 + \sqrt{4 - 6\alpha}$ (why?), then the left end of the segment (2) lies to the left of the right end of the segment (3), and the segments have a single common point only in one case - when the right end of the segment (2) coincides with the left end of the segment (3), that is, when

$$-2 + \sqrt{1 + \alpha} = 1 - \sqrt{4 - 6\alpha}.$$

Solving this irrational equation, we find the root $\alpha = 0$ (carry out the solution in detail).
