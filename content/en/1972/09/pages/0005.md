No. 1. Additive functions of the gap

The functions whose examples you have just seen are usually called set functions. We will call object functions functions of number, or numerical functions.

The simplest type of set function is the interval function, that is, a function whose domain of definition consists of segments of the number axis.

About the limit. The interval function $T$ is called additive if

$$T[a, b] + T[b, c] = T[a, c]$$

(1) for any pair of segments $[a, b]$ and $[b, c]$ from its domain of definition. (Through $T[a, b]$ denotes the number that the interval function $T$ assigns to the segment $[a, b]$.

We will assume that the domain of definition of the interval function consists of all segments $[a, b]$ contained in some fixed segment $[A, B]$.

Let us consider in more detail two examples of additive interval functions.

1°. Mass of a non-uniform rod

Imagine that there is a material rod located on the number axis from point $A$ to point $B$. Each segment $[a, b]$ of this rod is associated with the number $m[a, b]$ - the mass of this segment. The interval function $m$ obtained in this way is additive: $m[a, b] + m[b, c] = m[a, c]$, - if a segment of a rod is divided into two parts, then its mass is equal to the sum of the masses of these parts. In part, if the mass is distributed uniformly along the rod, that is, the rod is homogeneous, and $\lambda$ is its linear density (mass per unit length), then $m(a, b] = \lambda(b-a)$.

2°. Function increment

Let $F = F(x)$ be any function of a number defined on the interval $A \leq x \leq B$. Then the function

$$\Delta F[a, b] = F(b) - F(a)$$

(2) (that is, the function $\Delta F$, which assigns the number $\Delta F[a, b] = F(b) - F(a)$ to the interval $[a, b]$) is additive. Let's check this: if $a < b < c$, then

$$[F(b) - F(a)] + [F(c) - F(b)] = F(c) - F(a),$$

that is

$$\Delta F[a, b] + \Delta F[b, c] = \Delta F[a, c].$$

Exercise 1. Prove that for any additive function of the interval $T$ there is a function $F$ of the number such that $T = \Delta F$, that is, $T[a, b] = F(b) - F(a)$.

§ 2. Definition of the integral

How to calculate the value of additive functions of the interval?

Let's return to the example with the mass of the rod. If the rod is made up of several homogeneous pieces, then its mass is equal to $\lambda_1 l_1 + \lambda_2 l_2 + \ldots + \lambda_n l_n$, where $l_1, l_2, \ldots, l_n$ are the lengths of these pieces, $\lambda_1, \lambda_2, \ldots, \lambda_n$ are their densities (Fig. 1). In the general case, when the rod is inhomogeneous, it is divided into segments so small that on each of them it is divided into two parts, then its mass is equal to the sum of the masses of these parts. In part, if the mass is distributed uniformly along the rod, that is, the rod is homogeneous, and $\lambda$ is its linear density (mass per unit length), then $m(a, b] = \lambda(b-a)$.
