Table 5 is presented with a very small number of words. Zaliznyak not only obtained this solution intuitively, but also proved strictly mathematically that it is optimal if we want to minimize the number of rows in the table. This is what the task he set for himself looks like: There is a matrix of m rows and n columns, the elements of which are the signs +, – and 0. It is required to replace each of the zeros in the matrix with a plus or minus so that in the resulting matrix without zeros (let’s call it the resultant for this matrix) the number s of different rows is minimal. Readers interested in a complete solution are referred to the book by A.A. Zaliznyak “Russian nominal inflection” (M.: Nauka, 1967; reprint: M.: Languages ​​of Slavic Culture, 2002) and note that to solve this problem the author formulated and proved three theorems; This is not often found in linguistic works – but it turns out that it does!
