We built a so-called position graph. It is now clear that the problem is really asking whether there is a Hamiltonian path in this position graph. Note that in one step the parity of the number of people in the composition changes, which means that our position graph is bipartite. The calculation shows that there are 21 fewer “even” compositions than “odd” ones, and, according to Theorem 1, a Hamiltonian path does not exist.
