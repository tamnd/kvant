The proof of the bipolar theorem basically contains the idea contained in Minkowski's theorem. Proof of the bipolar theorem (Theorem 2). According to Minkowski's theorem, a convex closed set C coincides with the intersection of the half-planes containing it. Therefore, if C contains the origin, and the half-plane contains C, then the half-plane must also contain the origin. All half-planes containing the origin are divided into two important types. 1. Half-planes that do not contain an origin on the boundary line. In this case, the boundary line can be given by the equality px + qy = 1 (with a suitable choice of p and q), and the half-plane itself is given by the inequality px qy d 1. 2. Half-planes containing the origin on the boundary line. In this case, the boundary line can be given by the equality px + qy = 0 (with a suitable choice of p and q), and the half-plane itself is given by the inequality px qy d 0. Thus, the polar C q is exactly the set of all half-planes of the first type containing C. By definition,
