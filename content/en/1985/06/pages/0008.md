To “cook” a dumbbell, it is enough to divide one light package into two halves, into two packages. Then these halves need to be moved apart so that you get two wave packets flying in parallel. These two packages make up a dumbbell.

You can “prepare” a dumbbell, for example, using the system of mirrors shown in figure 3. The axis BB′ of the dumbbell crosses the line AA′ and is divided in half by this linear line. By rotating the entire system of mirrors around the AA′ axis, we can change the orientation of the dumbbell in the vertical plane; transverse axis AA′. In figure 3 the dumbbell is shown in a vertical position; rotate the mirror system 90° (in any direction relative to the AA′ axis), we get a horizontal dumbbell, etc.

The finished light dumbbell is placed into a vessel with muddy water. The packages that made up the dumbbell were flown into the vessel at the same time and photographed.
