bathroom pairs So, the number of matched pairs with a common vertex at point $A$ is

$$\frac{1}{2} (k^2 - k + (n - 1 - k)^2 - n + 1 + k) = \frac{1}{2} ((n - 1)^2 - (n - 1)) - k (n - 1 - k).$$

It is easy to see that the smallest value of this expression is achieved at $k = (n - 1)/2$ if $n$ is odd, and at $k = n/2$ or $k = n/2 - 1$ if $n$ is even, and are equal to $(n - 1)(n - 3)/4$ and $(n - 2)^2/4$, respectively.

Note that the arrows can always be arranged so that the specified “optimal” number of arrows comes out of each point. Indeed, let us imagine that the points $A_1$, ..., $A_n$ form a regular $n$-gon and place arrows on its sides and diagonals (not passing through its center) so that they specify the same direction around the center; on the diagonals passing through the center (they only have $n$ for even numbers), arrows can be placed arbitrarily. Then the number of arrows entering each vertex differs from the number of arrows leaving it by no more than 1.

Thus, the most number of oriented triangles for odd $n$ is

$$\frac{n(n - 1)(n - 2)}{6} - \frac{n}{2} \cdot \frac{(n - 1)(n - 3)}{4} = \frac{n(n^2 - 1)}{24},$$

and for even $n$

$$\frac{n(n - 1)(n - 2)}{6} - \frac{n}{2} \cdot \frac{(n - 2)^2}{4} = \frac{n(n^2 - 4)}{24}.$$

Here is a sketch of another solution. Let $k_i$ be the number of arrows emanating from point $A_i$, then the number of unoriented triangles is equal to the sum

$$\frac{k_1(k_1 - 1)}{2} + \dots + \frac{k_n(k_n - 1)}{2} = \frac{k_1^2 + \dots + k_n^2}{2} - \frac{n(n - 1)}{4}$$

(the number of all arrows is $k_1 + \dots + k_n = n(n - 1)/2$). If for a certain arrangement of arrows $k_i \geq k_j + 2$, for each there are two points, then you can change the directions of (at most two) arrows so that $k_i$ decreases and $k_j$ increases by 1; in this case, the sum of squares $k_1^2 + \dots + k_n^2$ will decrease. Therefore, for the “bullet” arrangement of arrows $|k_i - k_j| \leq 1$ for all $i, j$, and therefore $k_i = (n - 1)/2$ or $k_i = ((n - 1) \pm 1)/2$ (depending on the parity of $n$) for all $i$, from where it is easy to get the answer using (*).
