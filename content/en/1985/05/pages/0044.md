$$\angle AKB, \text{ то есть } \frac{1}{2} \angle B + \angle C = \frac{1}{2} \angle A + \angle C \text{ или } \angle A = \angle B; \text{ либо } \angle AMB + \angle AKB = 180^\circ, \text{ то есть } \angle A + \frac{1}{2} \angle B + \frac{1}{2} \angle A + \angle B = \frac{3}{2} (\angle A + \angle B) = 180^\circ \text{ или } \angle C = 180^\circ - (\angle A + \angle B) = 60^\circ.$$

M903. Is there a convex polyhedron such that any section of it by a plane not passing through the vertex is a polygon with a) even; b) an odd number of sides?

We denote by $a_1, a_2, \dots, a_n$ the first terms of the progressions into which the natural series is divided, and by $d_1, d_2, \dots, d_n$ their differences. The product of all differences is included in one of the progressions, that is, for some $i, 1 \leq i \leq n$, and some natural $k$

$$d_1 d_2 \dots d_n = a_i + k d_i.$$

From this equality it follows that $a_i$ is divisible by $d_i$.

A. V. Kelarev

a) Answer: exists. Let us show that the conditions of the problem are satisfied by any polyhedron from each vertex of which there is an even number of edges, for example, octahedр (see figure).

Let us consider an arbitrary section of such a polyhedron that does not pass through the vertices. Obviously, it can be read to be moved so that it becomes non-parallel to any of the edges of the polyhedron, and the number of its sides remains the same. We will now move the section plane in parallel. Then the number of its side will change only when crossing a vertex, and only one vertex will be traversed each time. If an even number of $n$ edges converge in it and $k$ of them intersected the section plane before passing through this vertex (and therefore, $n - k$ - after the transition; see figure), then the number of vertices of the section will transition to $n - 2k$ and, therefore, its parity will be preserved. And since at the end the cutting plane will not intersect any of the edges, the side number must remain even all the time, except when passing the vertices.

b) Answer: does not exist. From the solution to problem a) it follows that if all sections of a polyhedron that do not pass through the vertices have the same parity (in particular, odd), then an even number of edges emerge from each vertex. But then, as was shown there, the side number of any such section must be even.

N. V. Vasiliev, V. N. Dubrovsky
