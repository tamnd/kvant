Moreover, if $a_1 \geq a_2 \geq \dots \geq a_n$ and $k \geq 2$, then $a'_k > a_1$. Thus, from each solution it is possible to obtain new ones, with a larger maximum coordinate, and only one coordinate - the maximum - moves to the neighboring, “smaller” solution. This movement up the decision tree to smaller solutions cannot continue indefinitely, eventually reaching the root solution $a_1 \geq a_2 \geq \dots \geq a_n$, for which $a'_1 \geq a_1$, and no further ascent is possible (Fig. 5).

II. Wolfbein distinguishes three types of radical solutions: (I) $a_1 = a_2 = \dots = a_n$; this is, for $n = m$, solutions of the form (1, 1, ..., 1), for $n = 3$, $m = 1$ - a solution (3, 3, 3), for $n = 4$, $m = 1$ - (2, 2, 2, 2); there are no others.

(II) $a'_1 > a_1$; for example, for $n = 7$, $m = 5$ such a solution is (2, 1, ..., 1);

(III) $a'_1 = a_1$; for example, for $n = 11$, $m = 5$ such a solution is (4, 22, 1, ..., 1).

P. Wolfbein's reasoning is based on the following lemma proved by him: for a radical solution $a_1 \geq a_2 \geq \dots \geq a_n$ of type P or III, the inequality necessarily holds

$$ma_3 a_4 \dots a_n < n.$$

Equation (2) for $n = m$ (like equation (1), where $n = m = 3$) has only one root solution (1, 1, ..., 1), and from each of its solutions of the form $a_1 > a_2 > \dots > a_k > a_{k+1} = \dots = a_n = 1$ one goes down in a branching manner to $k$ different (not obtained from each other by rearranging coordinates) neighboring solutions. As for the general case $m \neq n$, P. Wolfbein obtained only some partial results here. The problem of a complete study of equation (2) in the general case still remains to be solved.

How to differentiate a function a fractional number of times

Marat Rovinsky, a 9th grade student at school No. 57 in Moscow, figured out how, for any real number $s$, to determine from the function $f(x)$ a new function $-f^{(s)}(x)$ - in such a way that:

1) If $s$ is a non-negative integer, then $f^{(s)}x$ is the $s$th arbitrary number at the point $x$.

2) $f^{-1}(x) = \int_0^x f(t)dt$.

3) If $f(x) = 0$ at $x \leq 0$, then $(f^{(s_1)})(s_2)(x) = f^{(s_1 + s_2)}$.

From properties 2 and 3 it follows that if $n$ is a natural number, then

$$f^{-(n)}(x) = \int_0^x \left( \int_0^x f(t)dt \right) dx_{n-1}.$$

For example,

$$f^{-(2)}(x) = \int_0^x \left( \int_0^x f(t)dt \right) dx_{n-1}.$$

— the expression in brackets is considered as a function of the variable $x_1$, which is then used for arbitrary interpretation.

As is known,

$$f'(x) = \lim_{h \to 0} \frac{f(x) - f(x-h)}{h}.$$

The starting point for Marat’s thinking was the formula

$$f^{(2)}(x) = \lim_{h \to 0} \frac{f(x) - 2f(x-h) + f(x-2h)}{h^2}.$$

It is not difficult to show (by induction) that

$$f^{(n)}(x) = \lim_{h \to 0} h^{-n} \sum_{k=0}^{n} (-1)^k C_n^k f(x-kh).$$

Let us recall («Kvant», 1986, No. 1, p. 23) that $C_n^k$ is the number of combinations of $n$ elements.
