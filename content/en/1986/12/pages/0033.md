6) The example given in part c) suggests that an inequality with a constant 2 on the right-hand side is close to equality when the numbers $a_i/i$ are approximately equal. Let's put $t_i = a_i/i$, $1 \leq i \leq n$. Then for any $m \leq n$ the following estimate is true:

$$\left( p_1 + \dots + p_N \right) \left( \frac{1}{p_1} + \dots + \frac{1}{p_N} \right) \geq
\geq N + \sum_{1 \leq i < j \leq N} \left( \frac{p_i}{p_j} + \frac{p_j}{p_i} \right) \geq
\geq N + \frac{N(N-1)}{2} \cdot 2 = N^2.$$

Cauchy-Bunyakovsky inequality:
$$\left( x_1^2 + \dots + x_n^2 \right) \left( y_1^2 + \dots + y_n^2 \right) \geq
\geq \left( x_1 y_1 + \dots + x_n y_n \right)^2$$

We have applied the inequality given in the margin for $N = \frac{m(m+1)}{2} = 1 + 2 + \dots + m$ numbers, among which $t_j$ is taken $j$ times; the same estimate can be obtained using the Cauchy-Bunyakovsky inequality for the sets $x_i = \sqrt{a_i}$ and $y_i = i/\sqrt{a_i}$, $1 \leq i \leq m$).

Let us add up all such estimates for $m$ from 1 to $n$; the coefficient for $1/a_i$ will be equal to
$$\beta_i = 4i^2 \left( \frac{1}{i(i+1)^2} + \frac{1}{(i+1)(i+1)^2} + \dots + \frac{1}{n(n+1)^2} \right).$$

And since
$$\frac{1}{j(j+1)^2} < \frac{1}{2} \frac{2j+1}{j^2(j+1)^2} = \frac{1}{2} \left( \frac{1}{j^2} - \frac{1}{(j+1)^2} \right),$$
fair assessment
$$\beta_i < 4i^2 \cdot \frac{1}{2} \left( \frac{1}{i^2} - \frac{1}{(n+1)^2} \right) < 2.$$

c) Put $a_i = i$. Then the left side of the inequality is equal to $2\left( \frac{1}{2} + \frac{1}{3} + \dots + \frac{1}{1+n} \right)$, and the right side is $c\left( 1 + \frac{1}{2} + \dots + \frac{1}{n} \right)$, where $c$ is the constant with which we want to replace 4. If $c \leq 2$, then their difference
$$2\left( \frac{1}{2} + \frac{1}{3} + \dots + \frac{1}{n+1} \right) - c\left( 1 + \frac{1}{2} + \dots + \frac{1}{n} \right) =
(2 - c)\left( \frac{1}{2} + \frac{1}{3} + \dots + \frac{1}{n} \right) + \frac{2}{n+1} - c$$

for a sufficiently large $n$ will be positive, since as $n$ increases the sum $\frac{1}{2} + \dots + \frac{1}{n}$ grows without limit.

This follows, for example, from the following estimate: for $n = 2^k$
$$\frac{1}{2} + \frac{1}{3} + \frac{1}{4} + \dots + \frac{1}{2^k} > \frac{1}{2} + \frac{1}{2^2} + \frac{1}{2^3} + \dots + \frac{1}{2^{k-1}} = \frac{k}{2}.$$
