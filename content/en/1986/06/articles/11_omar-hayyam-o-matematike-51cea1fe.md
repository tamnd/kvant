For $n=2$ the formulas are well known. Let $a_1, a_2, a_3, ..., a_n$ $a_{n+1}$ be the $n$th row of Pascal's triangle. Let us assume that the formulas $\cos nx = a_1\cos^n x - a_3\cos^{n-2}x\sin^2x + ...,$ $\sin nx = a_2\cos^{n-1}x\sin x - a_4\cos^{n-3}x\sin^3x + ...$ have already been proven. Using the formula for the cosine of the sum $\cos(n+1)x = \cos(nx+x) = \cos nx\cos x - \sin nx\sin x = (a_1\cos^n x - a_3\cos^{n-2}x\sin^2x + ...)\cos x - (a_2\cos^{n-1}x\sin x - a_4\cos^{n-3}x\sin^3x + ...)\sin x.$ Opening the brackets and rearranging the terms, we get:

$$\cos(n+1)x = a_1\cos^{n+1}x - (a_2+a_3)\cos^{n-1}x\sin^2x + (a_4+a_5)\cos^{n-3}x\sin^4x - ...$$

Similarly, using the formula $\sin(n+1)x = \sin nx\cos x + \cos nx\sin x$ we get $\sin(n+1)x = (a_1+a_2)\cos^n x\sin x - (a_3+a_4)\cos^{n-2}x\sin^2x + ....$ Since $a_1, a_1+a_2, a_2+a_3, a_3+a_4, ...$ is the $(n+1)$th row of Pascal’s triangle, we have proved the required formulas for $\cos(n+1)x$ and $\sin(n+1)x$.
