M962. Prove that for any polynomial P(x) with integer coefficients it is impossible to find distinct integers x1, x2, ..., xn (n ≥ 3) for which the equalities P(x1) = x2, P(x2) = x3, ..., P(xn-1) = xn, P(xn) = x1 hold.

◆

Let us show that if integers x1, ..., xn satisfy the equalities from the conditions of the problem, then among them it will find the same ones.

We use the following lemma: if P(x) is a polynomial with integer coefficients, b and c are distinct integers, then P(b) - P(c) is divisible by b−c. In this case, the inequality |b−c| ≤ |P(b)−P(c)|; Only this consequence will be used to solve the problem.

Since P(x1) = x2, P(x2) = x3, by Lemma |x1−x2| ≤ |x2−x3| ≤ |x3−x4| ≤ ... ≤ |xnx1| ≤ |x1−x2|, which means |x1−x2| = |x2−x3| = ... = |xn−x1|.

If n ≥ 3, it follows that among the numbers x1, x2, ..., xn will find equal ones: we can assume that x1 is the smallest of these numbers; Then

x2−x1 = |x1−x2| = |xn−x1| = xn−x1,

that is, xn = x2.
