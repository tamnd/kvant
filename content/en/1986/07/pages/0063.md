Having written the inequality in the form $x^2 - 3x + 1 < x - a < 3x - x^2 - 1,$, we obtain a system of inequalities $f(x) < 0, g(x) < 0,$ where $f(x) = x^2 - 4x + 1 + a, g(x) = x^2 - 2x + 1 - a.$ This system can have a solution only for positive discriminants of the trinomials $f(x)$ and $g(x),$, that is, for $0 < a < 3$.

$x_2 < x_4 < x_3 < x_1; x_4 < x_2 < x_3 < x_1; x_4 < x_2 < x_1 < x_3.$
