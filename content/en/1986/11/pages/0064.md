“switch places”: for example, when turning through an angle of 60° with the center at point A, marked with the number 0, any node with number 0 goes to node with number 0, any node with number 1 goes to node with number 2, node with number 2 goes to node with number 1.

Let's take a pierced regular triangle PQR with vertices at the lattice nodes. If its vertices P and Q are marked with the same numbers, then the vertex R will be marked with the same number (it is obtained from point Q by a rotation of 60° around point P).
Similarly, if at the vertices P and Q there are two different numbers, then at the vertex R there is a triangle.

Thus, the sum of the numbers at the vertices of a piercing regular triangle is always divisible by 3.
