**M945. Given a strictly increasing unbounded sequence of positive numbers $a_1, a_2, \dots$. Prove that for all sufficiently large $k$ the following inequality holds:

a) $\frac{a_1}{a_2} + \frac{a_2}{a_3} + \dots + \frac{a_k}{a_{k+1}} < k - 1$;
b) $\frac{a_1}{a_2} + \frac{a_2}{a_3} + \dots + \frac{a_k}{a_{k+1}} < k - 1985$.

**a), 6) Let**

$$s_k = \frac{a_1}{a_2} + \frac{a_2}{a_3} + \dots + \frac{a_k}{a_{k+1}}.$$

and prove that for any sufficiently large $k$ $s_k < k - 1/2$.

Since the sequence $a_1, a_2, \dots$ increases without limit, there is a $K$ such that $a_1/a_K < 1/2$, then for all $k \geq K$

$$k - s_k = \left(1 - \frac{a_1}{a_2}\right) + \left(1 - \frac{a_2}{a_3}\right) + \dots + \left(1 - \frac{-a_k}{a_{k+1}}\right)$$

$$> \frac{a_2 - a_1}{a_{k+1}} + \frac{a_3 - a_2}{a_{k+1}} + \dots + \frac{a_{k+1} - a_k}{a_{k+1}} = 1 - \frac{a_1}{a_{k+1}} > 1 - \frac{a_1}{a_K} > \frac{1}{2}$$

Applying this statement to the sequence $a_{m+1}, a_{m+2}, \dots$, we obtain that for all sufficiently large $k$, $k > m$,

$$s_k - s_m = \frac{a_{m+1}}{a_{m+2}} + \dots + \frac{a_k}{a_{k+1}} < k - m - \frac{1}{2}.$$

Let us now choose $k_1$ such that $s_{k_1} < k_1 - 1/2$, then $k_2 > k_1$ such that $s_{k_2} - s_{k_1} < k_2 - k_1 - 1/2$, then $k_3 > k_2$ such that $s_{k_3} - s_{k_2} < k_3 - k_2 - 1/2$, etc. Then for any $k \geq k_n$

$$s_k = \left(s_k - s_{k_n}\right) + \left(s_{k_n} - s_{k_{n-1}}\right) + \dots + \left(s_{k_2} - s_{k_1}\right) < (k - k_n) + \left(k_n - k_{n-1} - \frac{1}{2}\right) + \dots + \left(k_2 - k_1 - \frac{1}{2}\right) + k_1 - \frac{1}{2} = k - n/2.$$

This implies both statements of the problem: a) - for $n = 2, 6$) - for $n = 2 \cdot 1985$.
