it is possible to select initial data $a_1, \dots, a_n$, b such that applying algorithm A to them will require at least $\log_2(n+1)$ comparisons.

Proof. As $a_1, \dots, a_n$ we take any integers such that $a_1 < \dots < a_n$, and as b we will alternately compare $a_1, \dots, a_n, a_{n+1}$. Using $A_1$ with this variant of the initial data should give a match to the numbers 1, ..., $n+1$. The results of comparisons made by applying $A_1$ to any of these options can be written as a sequence of "yes" and "no" words. To study the values ​​of $a_1, \dots, a_n$ and different b, only comparisons of the form (1) are used. Therefore, if applying $A_1$ to the initial data $a_1, \dots, a_n$ b required exactly k comparisons, and the first k comparisons in the course of applying $A_1$ to other initial data $a_1, \dots, a_n, b'$ should produce the same results, then further applying $A_1$ to $a_1, \dots, a_n, b'$ will no longer require a comparison, and this will be the same as for the initial data $a_1, \dots, a_n, b$. Consequently, the averages of the resulting sequences “yes” and “no” do not coincide and neither one is the beginning of the other. Let $l$ be the number of elements in the longest of these sequences, that is, $n+1$, and not exceed the number of all sequences of length l, that is, $2^l$. So, $n+1 \leq 2^l$ and $l \geq \log_2(n+1)$. Since $l$ is an integer, then $l \geq \log_2(n+1)$.

A comparison of the two proven theorems shows that there is no algorithm for finding the location of an element that, for any initial data, would require less comparison than the $A_1$ algorithm. In this sense, $A_1$ is an optimal (guess) algorithm.

Problem 2. Let $a_1 < \dots < a_n$ and the average numbers $a_1, \dots, a_n$ be a number equal to b. We need to find t for which $a_t = b$. Give an algorithm for solving the problem that requires $\log_2 n$ comparison. Prove that this algorithm is optimal.

Problem 3. Consider two algorithms for choosing the smallest of unequal numbers. The first algorithm: find the lesser of the first two numbers, compare it with the third, take the lesser again, compare with the fourth, etc. The second algorithm (“Cup” or “Olympic” system): divide the numbers into pairs, skip the lesser of each pair to the next round. If one number does not have a pair, then this number is also skipped to the next round. In the next.type, repeat the same thing, and so on, until one number remains. Which of these algorithms requires less comparison?

Problem 4. Prove that there is no algorithm for choosing the smallest of n unequal numbers that would require fewer (n-1) comparisons. (The technique used in the proof of Theory 2 allows us to prove only that the comparison number in the worst case is not less than $\log_2 n$.)*

Let us now move on to the ordering problem, which is the task of arranging possibly unequal numbers in a row

$a_1, \dots, a_n$. The answer is important, in particular, for solving computer problems related to information retrieval (we have already seen that orderliness ensures fast search).

Algorithm $A_2$: order in turn the initial groups of numbers of a given set: $a_1; a_1, a_2; a_1, a_2, a_3; \dots; a_1, \dots, a_n$ - the last group coincides with the entire set; to move from an ordered group of i numbers to an ordered group of the (i+1)th number, you need to place $a_{i+1}$ in its place in the existing ordered group of i numbers - this place is determined using the $A_1$ algorithm.

Let us denote by $B(n)$ the comparison number required by $A_2$. We have $B(n) = \log_2 2^l + \dots + \log_2 n \leqslant \log_2 2^l + \dots + \log_2 n + (n-2) = (2) = \log_2 n! + (n-2) \leqslant n(\log_2 n + 1) - 2$.

Problem 5. Determine the comparison number required by the following ordering algorithm $a_1, \dots, a_n$, find the smallest number and put it in first place, then find the smallest average remainder and put it in second place, etc. (see Problems 3, 4).

Problem 6. It is assumed that the disordered set $a_1, \dots, a_n$ can contain equal numbers. Show that in this case the algorithm $A_2$ ensures that the given numbers are arranged in non-decreasing order.

The technique used in the proof of Theory 2 allows us to establish that for any ordering algorithm it is possible to select a set $a_1, \dots, a_n$, the application of this algorithm to which will require at least $\log_2 n!$ comparisons (such a set will be one of $n! = 1 \cdot 2 \cdot \dots \cdot n$ permutations of n arbitrary numbers). Together with (2) this shows that, in any case, $A_2$ is not far from the optimal comparison number (the same cannot be said about the algorithm from Problem 5): for example, $\lim_{n \to \infty} (B(n) / \log_2 n!) = 1$. Various authors have made attempts to prove the optimality of $A_2$ and even reported in print the supposedly found proof. Later we found out that $A_2$ is not optimal: this algorithm requires all comparisons to order five numbers, but in fact seven comparisons are enough. This is not a simple fact, although it can be formulated as a weighing problem.
