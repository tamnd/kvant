Transitivity theorem

Now the scheme for solving Problem 2 can be described as follows: there is a transfer (or transit) of the condition for the existence of an inscribed circle from two 4-broken lines (BD|AC) and (BD|CR) to the third 4-broken line (BD|RA). The same scheme works in this more general situation. Theorem 2 (transitivity theorem). Let 4-broken lines (AB|XY), (AB|YZ) and (AB|ZX) be given. Then i) if for two of them there are internally inscribed circles, then so does the third one; ii) if for (AB|XY) and (AB|YZ) there exist circles inscribed (XY)-externally and (YZ)-externally, respectively, and the 4-line (AB|ZX) is not central, then for it there exists a circle inscribed (ZX)-externally; iii) if for (AB|XY) and (AB|YZ) there are circles inscribed (AB)-externally, then for (AB|ZX) there is a circle inscribed internally; iii’) if for (AB|XY) there is an (AB)-externally inscribed circle, for (AB|ZX) there is an internally inscribed circle, and the 4-line (AB|YZ) is not central, then for it there is an (AB)-externally inscribed circle. Proof. Let us prove, for example, statement (ii). If circles can be inscribed in the broken lines (AB|XY) and (AB|YZ) in an (XY)-external and (YZ)-external manner, respectively, then by Theorem 1 we have

AX + BX = AY + BY, AY + BY = AZ + BZ. From here AX + BX = AZ + BZ, and we obtain (again by Theorem 1) that a circle can be inscribed in a (ZX)-external way into the broken line (AB|ZX).
