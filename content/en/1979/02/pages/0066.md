(cm. c. 22)

Since the function $F_1(x) = \frac{1}{2} \sin^2 x$ is an antiderivative of the function $f$, any other antiderivative of $f$—in particular, $F_2(x) = -\frac{1}{2} \cos^2 x$—has the form $F_1(x) + C$.

For $F_2$ the constant $C$ is found from the equality $-\frac{1}{2} \cos^2 x = \frac{1}{2} \sin^2 x + C$. Substituting, for example, $x = 0$, we get $C = -\frac{1}{2}$.

Of course, it is also true that any perwoform for $f$ has the form $F_2(x) + C$. Specifically, $F_1(x) = F_2(x) + \frac{1}{2}$.
