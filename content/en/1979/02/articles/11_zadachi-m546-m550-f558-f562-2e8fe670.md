M503. A set of 2n+1 numbers $a_0, a_1, a_2, \dots, a_{2n}$ poppies, which is $a_k \geq \frac{a_{k-1} + a_{k+1}}{2}$ for all $k=1, 2, \dots, 2n-1$. Proving inequality
$$\frac{a_1 + a_3 + a_5 + \dots + a_{2n-1}}{n} \geq \frac{a_0 + a_2 + a_4 + \dots + a_{2n}}{n+1} \quad (*)$$
and find out for which sets it turns into equality.

Let us first note that if this set is an arithmetic progression, then all the inequalities written in the problem statement turn into equalities. Below we will see that of the “convex” sets (that is, sets that have $a_k \geq \frac{a_{k-1} + a_{k+1}}{2}$ for all $k=1, 2, \dots, 2n-1$), only for an arithmetic progression does inequality (*) become an equality.

The numbers of an arbitrary “convex” set $\{a_k\}$ can be represented as the sum of the numbers $a_k = b_k + c_k$ of two sets $\{b_k\}$ and $\{c_k\}$, one of which, $\{b_k\}$, is an arithmetic progression with extreme terms $b_0 = a_0$ and $b_{2n} = a_{2n}$, and the other, $\{c_k\}$, is a “convex” set with zero extreme terms: $c_0 = c_{2n} = 0$.

Since inequality (*) turns into equality for the set $\{b_k\}$, it suffices to prove it for the set $\{c_k\}$. But for “convex” sets with zero extreme terms it is obtained indefinitely from the “convexity” condition: writing that $c_{2i-1} \geq \frac{c_{2i-2} + c_{2i}}{2}$ for all $i=1, \dots, n$, and adding these inequalities, we obtain:

$$c_1 + c_3 + \dots + c_{2n-1} \geq \frac{c_0}{2} + c_2 + c_4 + \dots +$$

$$+ c_{2n-2} + \frac{c_{2n}}{2} = c_0 + c_2 + \dots + c_{2n-2} + c_{2n}$$

(we took into account that $c_0 = c_{2n} = 0$), so

$$\frac{c_1 + c_3 + \dots + c_{2n-1}}{n} \geq \frac{c_0 + c_2 + \dots + c_{2n}}{n+1}$$

(**)

It remains only to prove that for convex sets inequality (*) can be an equality only for an arithmetic progression. To do this, it is enough to show that if $c_k \geq (c_{k-1} + c_{k+1})/2$, then either all $c_k$, $k = 0, \dots, 2n$ are equal to zero, or all $c_k$, $k = 1, \dots, 2n-1$ are positive (in the latter case, the right inequality in (**) is necessarily strict).

Let's choose the smallest $c_i$; let it not be on the edge: $i \neq 0, i \neq 2n$. then $c_i \leq c_{i-1}$ and $c_i \leq c_{i+1}$, whence $c_i \leq \frac{c_{i-1} + c_{i+1}}{2}$. But by condition $\{c_k\}$ is a “convex” set, which means $c_i = c_{i-1} = c_{i+1}$. Applying the same reasoning to $c_{i-1}$ (or to $c_{i+1}$), we find that $c_{i-2} = c_{i-1} = c_i$ (or $c_i = c_{i+1} = c_{i+2}$), etc. - until we reach the edges; we get $0 = c_1 = c_2 = \dots = c_{2n-1} = 0$. Therefore, if there are numbers $c_k$ other than zero, then the smallest common commensurate is on the edge (and is equal to zero), so for $k = 1, \dots, 2n-1$ we have $c_k > 0$.
