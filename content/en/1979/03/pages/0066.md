2. Let a, b, θ, ε be the number of bottles drunk, respectively, by Mass. Adams, Brown, Wilson and Green. Then
$$\begin{cases} a + 6 + \theta + \epsilon = 14, \\ a + 26 + 3\theta + 4\epsilon = 35. \end{cases}$$
Subtracting the first equation of the system from the second, we obtain:
$$6 + 2\theta + 3\epsilon = 21,$$ which means that $6 + 3\epsilon$ is an odd number. Given this remark, it is not difficult to find that $a=4, \theta=5, \epsilon=3$. Thus, the last name is Cecil-Adams, the last name of Anna is Brown, Dorotty-Wilson and Betty-Green.
