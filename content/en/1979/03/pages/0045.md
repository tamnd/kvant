⟦folio 43⟧

A. Savin

Number - letter - number

(let's practice mental arithmetic!)

To fill the cells of the crossword shown in figure 1 with numbers (unlike a crossword puzzle, it is made up not of words, but of numbers), you need to decipher the numbers x, y, z, u, v and perform several arithmetic operations on them. The required numbers must be placed in the crossumber cells.

All calculations are carried out “in your head”, using pencil and paper only to record the final results.

figure 2 shows the code used to write the numbers x, y, z, u and v; however, to decipher these numbers, you need to apply a different key for each number. Let's show this with an example.

Example.

Key: multiply by 2. 33—10—8—35—8—30—3—25—15—35—26—9—8—27—25—8—17. Let's multiply these numbers by 2 and read them using the code picture (Fig. 2):

66—20—16—70—16—60—6—50—30—70—52—18—16—54—50—16—34 THIS IS★VERY★ SIMPLE.

Now try to find these numbers.

Number x.
Key: add 7. 33—34—31—26—13—23.
Number y.
Key: divide by 3. 60—87—57—99—75—3.
Number z.
Key: clean out 6. 26—24—16—21—42—11—30—7—26—36.
Number u.
Key: Multiply by 2 and subtract 2. 9—21—6—26.
Number v.
Key: multiply by 3 and add 1. 6-18-5.

Having found the numbers x, y, z, u, v, we can fill the cells of the crossumber:

Horizontal
b) (x+z+v) v+u;
d) y:(x-u);
e) (v-u) · (z-x);
g) yz-(x+z) (x+u);
h) (x+u) y+z;
j) (z-x) (y+u):z;
l) xv;
m) y (y+u) : z+z.
