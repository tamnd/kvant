Where is the error?

In some schools, in some (ninth) grades, the problem was solved. The name of the lateral surface of a rectangular parallelinea if the area of ​​its base is 1 and the diagonal diagon is 2.

Let us denote the lengths of the sides of the base by $a$ and $b$, and the length of the side edge by $c$. Then the area $Q$ of the lateral surface will be equal to $2(a+b)c$. So, to solve the problem you need to find the lateral value of the expression

$$Q = 2(a+b)c.$$

(1)

It follows from the condition that the changes of the parallelepiped $a$, $b$ and $c$ are related by the equalities

$$\begin{cases} ab = 1, \\ a^2 + b^2 + c^2 = 4. \end{cases}$$

(2)

Let's write expression (1) as a function of one variable. In that school, in that class, two ways were proposed for this.

First way. From (2) $b = \frac{1}{a}$.

Then from (3) $c = \sqrt{4-a^2 - \frac{1}{a^2}}$

This means that the function whose greatest value needs to be found has the form

$$Q(a) = 2\left(a + \frac{1}{a}\right)\sqrt{4-a^2 - \frac{1}{a^2}}.$$

(4)

As expected, it can be arbitrary. Transforming it, we get

$$Q'(a) = -\frac{4(a-1)(a+1)(a^4-a^2+1)}{a^3\sqrt{-a^4+4a^2-1}}$$

The domain of definition of the function $Q(a)$ is a set

$$\left[-\sqrt{2+\sqrt{3}}; -\sqrt{2-\sqrt{3}}\right] \cup \left[\sqrt{2-\sqrt{3}}; \sqrt{2+}\sqrt{3}\right].$$

According to the meaning of the notation $a > 0$. Thus, we need to find the largest value of function (4) on the segment $\left[\sqrt{2-\sqrt{3}}; \sqrt{2+}\sqrt{3}\right]$. Using an objective method (“Algebra and beginning analysis 9”, paragraph 59) one can find

$$\max Q(a) = Q(1) = 4\sqrt{2}.$$

Second way. From (2) and (3) it easily follows

$$(a+b)^2 + c^2 = 6$$

(5)

or

$$a+b = \sqrt{6-c^2}.$$

(6)

From (1) and (6) we obtain

$$Q(c) = 2c\sqrt{6-c^2}.$$

(7)

Again, possibly arbitrary:

$$Q'(c) = \frac{6-2c^2}{\sqrt{6-c^2}}.$$

The domain of definition of the function $Q(c)$ is the segment $\left[-\sqrt{6}; \sqrt{6}\right]$. According to the meaning of the notation $c > 0$. Therefore, it will look for the largest value of function (7) on the interval $[0; \sqrt{6}]$. It is found in an object way

$$\max Q(c) = Q(\sqrt{3}) = 6.$$

It turned out that by choosing differently the variable through which we express the objective function u (1), we obtained the results.

In that school, in that class, they quickly figured out what was going on. What about you?
