⟦folio 57⟧

For example, if you type on the terminal of the robot RD-1 the instruction CALL CHANGE PROCEDURE;
then the robot begins to use, in numerical order, all the instructions included in the procedure: open the window, moisten the tripe, and so on.

The CHANGE procedure can be called shorter:
BRING CHANGE;
or simply:
:CHANGE;

The mechanism for working with numbers indicated before each instruction when describing procedures allows you to correct errors and insert missing parts of the program.

If you notice an error before typing the word FINISH, then to correct it you just need to re-type the prescription that needs to be corrected (along with the old number). It is recommended to supply the numbers not in a row, but, for example, after 10, so that there is space for inserting missing instructions.

If an error is replaced when the description of the procedure is already completed, it is necessary to type the instruction CORRECT THE PROCEDURE, the syntax diagram of which is given in its table.

After this, you can type the corrections again as if the description of the procedure was still ongoing. Having finished working with the procedure, you need to type the word FINISH again.

We will talk more about correcting procedure texts in the next lessons of our school.

The instructions included in the procedures are called statements. Unlike directions, which are executed immediately after typing on the terminal, operators are not executed, but for help after typing. A computer or robot will teach them to perform them only after the corresponding procedure is called.

Almost all statements, including procedure calls, can be used both as operators and as directives. However, there are exceptions: the directives FINISH, REMEMBER, CORRECT cannot be used as operators.

Task 3.2. Think over the systems of instructions for the robots “cook” and “driver”, and write two programs for them using procedures.

G. Zvenitsgorodsky
