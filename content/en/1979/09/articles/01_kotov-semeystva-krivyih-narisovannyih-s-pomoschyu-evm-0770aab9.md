On this cover page you see four families of curves drawn by the computer. Their equations in the polar coordinate system (see «Kvant», No. 7 for 1977) have the following form:

first family: $r = A [5 + 2\cos\varphi + 3|\cos\varphi^m\sin(\cos\varphi)] - B\sin^2 18\varphi\cos^8\varphi/2$
(curves from this family are also shown on the first page of the cover);

second family: $r = A(\cos\varphi + \sqrt{3 + \cos^2\varphi}) \times \cos^2 3,5\varphi - B\sin^2 60\varphi$;

third family: $r = A \cos 4\alpha + B, \varphi = \alpha - C \sin 4\alpha$ (here the curves are given in parametric form - each value of the parameter $\alpha$ corresponds to certain values ​​$r$ and $\varphi$, a given point on the plane; the parametric definition of curves was discussed in «Kvant» No. 8 for 1978 in the article by M. Bashmakov); fourth family $r = A(1 + \cos 3\varphi) + B\sin^2 3\varphi$. The values ​​of $A, B, C$ and $m$ are different for different curves. If desired, some of these curves can be recognized as plant leaves.

Yu. Kotov
