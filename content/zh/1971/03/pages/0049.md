⟦folio 47⟧

包括未知数模块的乘积，考虑两种情况。

a) 设 $xy \geq 0$。在这种情况下，系统的条件具有以下形式

$$\begin{cases} y^2 - xy + 2 = 0, \\ 8 - x^2 = (x + 2y)^2, \\ y^2 - xy + 2 = 0, \\ -8 + 2x^2 + 4xy + 4y^2 = 0. \end{cases}$$

将第一个方程乘以 4 并与第二个方程相加，我们得到 $2x^2 + 8y^2 = 0$，这仅适用于实数 $x = y = 0$。但所考虑的系统的这些未知值并不令人满意。

b) 现在让$xy < 0$。原始系统将采用以下形式

$$\begin{cases} y^2 + xy + 2 = 0, \\ 8 - x^2 = (x + 2y)^2 \\ y^2 + xy + 2 = 0, \\ 2x^2 + 4xy + 4y^2 - 8 = 0. \end{cases}$$

将第一个方程再次乘以 4，然后从第二个方程中减去它，我们得到 $x^2 = 8$，即 $x = \pm 2\sqrt{2}$。现在从第一个方程很容易找到$y: (y \pm \sqrt{2})^2 = 0$，因此$y = \mp \sqrt{2}$。

根据假设$xy < 0$。考虑到这一点，我们找到答案：

$$x = 2\sqrt{2}, y = -\sqrt{2}$$

或者

$$x = -2\sqrt{2}, y = \sqrt{2}$$

检查确认两对数字都是根。

这个例子也不包含任何技巧或窍门。它是为具有正常数学背景的学童设计的。解决这个例子时所犯的错误与对函数的绝对值（模）的概念不清楚以及无法正确写下答案有关。在这种情况下，要么不考虑两种情况，而将带有模型的方程简单地替换为一个或另一个不带模型的方程，或者得到的一组值$x$和$y$与条件$xy < 0$不相符，并出现不必要的答案。

3. 这个问题可以通过引入某些未知数以不同的方式解决。

令$t_A, t_B$和$t_C$分别为赛车手$A$、$B$和$C$跑一圈的时间（我们将路径长度设为1）。那么他们每个人的速度都是$\frac{1}{t_A}, \frac{1}{t_B}, \frac{1}{t_C}$。

请注意，在绝对速度相同的情况下，骑手之间的距离在整个运动过程中将保持不变。由于一个人的速度超过另一个人的速度，赛车手之间的距离缩短了。赛车手$A$相对于$B$的速度为$\frac{1}{t_A} - \frac{1}{t_B}$，$A$相对于$C$的速度为$\frac{1}{t_A} - \frac{1}{t_C}$，$B$相对于$C$的速度为$\frac{1}{t_B} - \frac{1}{t_C}$。

现在很容易将问题的条件翻译成方程语言。由于骑手$A$在完成第一圈时首先同意$B$，然后$A$在$t_B$小时内同意$B$。但是对于这个 $A$ 以相对速度 $\frac{1}{t_A} - \frac{1}{t_B}$ 覆盖圆的 $1/3$，这给出了等式

$$\left(\frac{1}{t_A} - \frac{1}{t_B}\right)t_B = \frac{1}{3}.$$

$A$和$C$之间的初始距离为$2/3$，$A$以$\frac{1}{t_A} - \frac{1}{t_C}$的相对速度在$t_B + \frac{1}{6}$小时内跑完；我们得到第二个方程：

$$\left(\frac{1}{t_A} - \frac{1}{t_C}\right)\left(t_B + \frac{1}{6}\right) = \frac{2}{3}.$$
