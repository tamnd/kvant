笔试
数学方面
1970 年在密歇根州立大学梅赫马特分校

N·N·科列斯尼科夫

1970年«Kvant»第2期发表了N.S.巴赫瓦洛夫和N.N.库兹涅佐夫关于1969年莫斯科国立大学数学笔试的文章。我不想重复那里关于这项考试性质的评论，我想强调它在 1970 年的一些特点。

向申请人提出的任务再次证实了这样的立场：根据学校课程的条件，任何申请人都可以成功解决问题，而不仅仅是数学学校的毕业生。你会发现这些问题并不包含“陷阱”或“陷阱”，而是需要对大学申请者数学课程的主要部分有清晰的了解，并具有一定的技术计算和解决简单方程、不等式和几何问题的技能。

当然，这种问题的“标准化”意味着对解决方案的评估要求更高，对解决方案的能力要求更高，而不仅仅是暗示解决方案。 1970年，完成任何两到三个问题的正确解决方案获得满意的分数（三分），任何四个问题的良好（四分），五个问题的优秀（五分）。分配了 4 个天文小时来解决该问题（一组五个问题 - 变体）。

让我们继续分析数学笔试的一个选项，简要关注机械与数学学院录取的学生在作业中遇到的最典型的错误。

包括未知数模块的乘积，考虑两种情况。

a) 设 $xy \geq 0$。在这种情况下，系统的条件具有以下形式

$$\begin{cases} y^2 - xy + 2 = 0, \\ 8 - x^2 = (x + 2y)^2, \\ y^2 - xy + 2 = 0, \\ -8 + 2x^2 + 4xy + 4y^2 = 0. \end{cases}$$

将第一个方程乘以 4 并与第二个方程相加，我们得到 $2x^2 + 8y^2 = 0$，这仅适用于实数 $x = y = 0$。但所考虑的系统的这些未知值并不令人满意。

b) 现在让$xy < 0$。原始系统将采用以下形式

$$\begin{cases} y^2 + xy + 2 = 0, \\ 8 - x^2 = (x + 2y)^2 \\ y^2 + xy + 2 = 0, \\ 2x^2 + 4xy + 4y^2 - 8 = 0. \end{cases}$$

将第一个方程再次乘以 4，然后从第二个方程中减去它，我们得到 $x^2 = 8$，即 $x = \pm 2\sqrt{2}$。现在从第一个方程很容易找到$y: (y \pm \sqrt{2})^2 = 0$，因此$y = \mp \sqrt{2}$。

根据假设$xy < 0$。考虑到这一点，我们找到答案：

$$x = 2\sqrt{2}, y = -\sqrt{2}$$

或者

$$x = -2\sqrt{2}, y = \sqrt{2}$$

检查确认两对数字都是根。

这个例子也不包含任何技巧或窍门。它是为具有正常数学背景的学童设计的。解决这个例子时所犯的错误与对函数的绝对值（模）的概念不清楚以及无法正确写下答案有关。在这种情况下，要么不考虑两种情况，而将带有模型的方程简单地替换为一个或另一个不带模型的方程，或者得到的一组值$x$和$y$与条件$xy < 0$不相符，并出现不必要的答案。

3. 这个问题可以通过引入某些未知数以不同的方式解决。

令$t_A, t_B$和$t_C$分别为赛车手$A$、$B$和$C$跑一圈的时间（我们将路径长度设为1）。那么他们每个人的速度都是$\frac{1}{t_A}, \frac{1}{t_B}, \frac{1}{t_C}$。

请注意，在绝对速度相同的情况下，骑手之间的距离在整个运动过程中将保持不变。由于一个人的速度超过另一个人的速度，赛车手之间的距离缩短了。赛车手$A$相对于$B$的速度为$\frac{1}{t_A} - \frac{1}{t_B}$，$A$相对于$C$的速度为$\frac{1}{t_A} - \frac{1}{t_C}$，$B$相对于$C$的速度为$\frac{1}{t_B} - \frac{1}{t_C}$。

现在很容易将问题的条件翻译成方程语言。由于骑手$A$在完成第一圈时首先同意$B$，然后$A$在$t_B$小时内同意$B$。但是对于这个 $A$ 以相对速度 $\frac{1}{t_A} - \frac{1}{t_B}$ 覆盖圆的 $1/3$，这给出了等式

$$\left(\frac{1}{t_A} - \frac{1}{t_B}\right)t_B = \frac{1}{3}.$$

$A$和$C$之间的初始距离为$2/3$，$A$以$\frac{1}{t_A} - \frac{1}{t_C}$的相对速度在$t_B + \frac{1}{6}$小时内跑完；我们得到第二个方程：

$$\left(\frac{1}{t_A} - \frac{1}{t_C}\right)\left(t_B + \frac{1}{6}\right) = \frac{2}{3}.$$

此外，据了解，

$$t_B + \frac{1}{24} = t_C.$$

4. 令$ABCD$ (图 2) 为给定的四边形，$O_1$ 和$O_2$ 为位于对角线$AC$ 和$DB$ 上的指定圆的中心。点 $K_1, L_1, M_1$ 分别是从边 $AD, AB, BC$ 到$O_1$ 的圆的切点，$K_2, L_2, M_2$ 是从边 $AD, CD, BC$ 到$O_2$ 的圆的切点。令 $B'$ 为从 $B$ 下降到 $AD$ 的高度的底数。

根据条件，圆相等且相互接触，这意味着它们的公切线$BC$和$AD$平行。现在我们将 $\Rightarrow BCA = \Rightarrow CAD$ 替换为横向角，并替换 $\Rightarrow CAD = \Rightarrow BAC$，因为 $AC$ 是平分线（$AB$ 和 $AD$ 是切线，$AC$ 通过圆心）。因此，$\Rightarrow BAC = \Rightarrow CAD$要求严格，$\Rightarrow ABC$等边，$AB=BC$。

所以，我们的四边形有 $BC \parallel AD, AB=CD$，因此，它要么是梯形，要么是等边四边形，要么是平行四边形。

平行四边形不合适，因为中心$O_1$和$O_2$必须位于四边形的中线上，但在平行四边形中，彼此相交的对角线被分成两半，也就是说，圆的中心必须重合，这与条件相矛盾。我们遵循新的 图 (图 3)。

5. 设 $B'$ 为从点 $B$ 到平面 $P$ (图 4) 的垂线的底边。根据条件

$$\Rightarrow BCB' = \varphi, OB = OA = r, CA = 2r, \\
\Rightarrow CBO = \frac{\pi}{2}.$$

求线段$AB$的长度可以例如从直角三角形$AB'B$求出，其边长很容易计算。请注意，$CB = CA = 2r$ 是从一点绘制的球的切线段。由此可见

$$BB' = CB \sin \varphi = 2r \sin \varphi.$$

三角形$AB'B$的边$AB'$等于从$O$到$BB'$的垂线$OO'$（$OA \parallel BB'$，垂直于一个平面；$BB' \perp AB'$，因为$AB'$位于平面$P$，垂直于$BB'$；$OO' \perp BB'$）通过构造；因此 $OO'B'A$ 是直的）。 $OO'$ 来自直角三角形$OO'B'$：

$$OO' = \sqrt{r^2 - (BO')^2},$$

$$BO' = |BB' - B'O'| = |BB' - OA| = |2r \sin \varphi - r|,$$

$$OO' = AB' = \sqrt{\sin \varphi - \sin^2 \varphi} \cdot 2r.$$

最后，由三角形$AB'B$求出$AB$：

$$AB = \sqrt{(AB')^2 + (B'B)^2} = 2r \sqrt{\sin \varphi}.$$

我们现在确信，解决这个立体测量问题（以及 1970 年提出的其他问题）的困难不会超过解决学校问题所遇到的困难。然而，每年都有很多数学笔试的申请者根本不关注解决立体测量问题，显然认为这些问题本质上是不可能解决的。

在申请人工作中遇到的错误中，值得注意的是，不清楚直线与平面的角度是多少。因此，在所分析的问题中，这个角度常常取$\Rightarrow BCA$。

当决定使用 $\Rightarrow CB'A$ 是直接的条件时也很常见，尽管在一般情况下这根本不是真的。
