解决方案

M26

假设我们的杂志每期都会有五个“Kvata”任务中的数学问题。让我们用$f(x, y)$表示$y$年第$x$期期刊的第一个任务的编号（例如，$f(6, 1970) = 26$）。写出所有 $x, y$ ($1 \leq x \leq 12, y \geq 1970$) 的 $f(x, y)$ 的通式。求解方程$f(x, y) = y$。

函数$f$满足以下条件：

1) $f(1, 1970) = 1$;
2) $f(x + 1, y) = f(x, y) + 5$ ($1 \leq x < 12$) - 每个月 $f(x, y)$ 增加 5；
3) $f(1, y + 1) = f(1, y) + 60$ - $f(x, y)$每年增加 60。

显然，该函数是由这些条件唯一确定的；例如，可以使用以下公式来指定：

$$f(x, y) = 5x + 60(y - 1970) - 4.$$

很容易验证$f(5, 2003) = 2001$； $f(6, 2003) = 2006$。因此，方程$f(x, y) = y$无解。

正确答案由来自日托米尔的E. Orlok、来自伊尔库茨克地区扎哈尔村的N. Ilyin、来自基辅的M. Perelmuter 和其他读者发送。

从上面可以清楚地看出，如果我们还引入以下函数：$f(k, x, y)$是第$y$年（$1 \leq k \leq 5, 1 \leq x \leq 12, y \geq 1970$）第$x$期期刊第$k$问题的编号，那么等式$f(k, x, y) = y$将是唯一的解决方案$k = 3, x = 5, y = 2003$ - 换句话说，如果我们的系统在此之前保持不变（仍然在每期中）数学上会有 5 个问题），那么 2003 年“Kvata”第 5 号任务中的第三个问题的编号为 M2003。 $f(k, x, y)$的一般公式也是：

$$f(k, x, y) = k + 5x + 60(y - 1970) - 5.$$

对于读者来说，更有用的是反函数给出的公式，通过给定的数字$n$，您可以找到提出该问题的年份$y$和期刊编号$x$。

为此，可以方便地使用以下符号：$[a]$是数字$a$的整数部分（不超过$a$的最大整数），$\{a\} = a - [a]$是数字$a$的小数部分。

检查一下

$$x = \left[ 12 \left\{ \frac{n - 1}{60} \right\} \right] + 1, y = \left[ \frac{n - 1}{60} \right] + 1970.$$

M27

证明如果$\frac{a}{b - c} + \frac{b}{c - a} + \frac{c}{a - b} = 0$则$\frac{a}{(b - c)^2} + \frac{b}{(c - a)^2} + \frac{c}{(a - b)^2} = 0$。

此声明源于此谎言：

$$\left( \frac{a}{b - c} + \frac{b}{c - a} + \frac{c}{a - b} \right)\left( \frac{1}{b - c} + \frac{1}{c - a} + \frac{1}{a - b} \right) = \frac{a}{(b - c)^2} + \frac{b}{(c - a)^2} + \frac{c}{(a - b)^2}.$$

为了证明这一点，只需将谎言左侧的两个和逐项相乘，并考虑到三个分数的总和就足够了

$$\frac{a}{b - c}\left( \frac{1}{c - a} + \frac{1}{a - b} \right) = \frac{ca - ab}{(a - b)(b - c)(c - a)},$$

$$\frac{b}{c - a}\left( \frac{1}{b - c} + \frac{1}{a - b} \right) = \frac{ab - bc}{(a - b)(b - c)(c - a)},$$

$$\frac{c}{a - b}\left( \frac{1}{b - c} + \frac{1}{c - a} \right) = \frac{bc - ca}{(a - b)(b - c)(c - a)}$$

等于零。

该决定由塔什干的 A. Shilitum 发出。来自图拉地区新莫斯科斯克的 B. Paiss 和来自布列斯特地区 Malorita 的 A. Izbitsky 发送了不太明确但也是正确的解决方案。

读完这样的人为解决方案后，当然可能会出现一个合理的问题：给定表达式必须乘以$\frac{1}{b-c} + \frac{1}{c-a} + \frac{1}{a-b}$的约定是什么？是否有可能提出一种通用的计算方法来解决此类问题？

这样解决这个问题会更自然。让我们将这些表达式写为两个多项式的比率：

$$\frac{a}{b-c} + \frac{b}{c-a} + \frac{c}{a-b} = \frac{p(a,b,c)}{(a-b)(b-c)(c-a)},$$

$$\frac{a}{(b-c)^2} + \frac{b}{(c-a)^2} + \frac{c}{(a-b)^2} = \frac{q(a,b,c)}{(a-b)^2(b-c)^2(c-a)^2}$$

（$p$ 将是三次多项式，$q$ 将是五次多项式）。我们必须证明，如果$p(a,b,c) = 0$，那么也有$q(a,b,c) = 0$。尝试证明多项式 $q$ 可以被多项式 $p$整除是很自然的，也就是说，找到一个多项式 $r=r(a,b,c)$ 使得 $q=pr$ （您可以证明任意数量变量中的多项式的一般定理：如果对于 $p$ 相等的所有变量值，$q$ 等于 0为零，同时多项式 $p$ 是连续的，也就是说，它不能被因式分解——在这种情况下它是——那么 $q$ 必须能被 $p$整除）。您可以用通常的方式除多项式 - 用“角”，将它们视为一个变量 $a$ 中的多项式（其系数包括字母 $b$ 和 $c$）；例如，$p$可以这样写：

$$p(a,b,c) = -a^3 + p_1(b,c)a^2 + p_2(b,c)a + p_3(b,c).$$

结果，我们当然会得到 $q=pr$，其中

$$r(a,b,c) = (a-b)(b-c)(c-a)\left(\frac{1}{a-b} + \frac{1}{b-c} + \frac{1}{c-a}\right) = -a^2 + ab + ac + bc - b^2 - c^2.$$

在这个例子中，这个解决方案的实施涉及非常困难的计算（在多项式$q(a,b,c)$中，即使在将类似项减少到剩余的21项之后！），但我们强烈建议读者考虑这个解决方案的所有细节，这适用于许多其他解决方案。

让我们从一个类似但更简单的任务开始。给定$n$个球，其中一个是放射性的；需要经过多少次检查才能识别出来？很容易指出一种方法，允许您在$k$检查中选择$n=2^k$球中的一个：首先，我们将所有球分成两堆相等的$2^{k-1}$球，我们检查其中一个，从而确定其中哪个包含放射性球，然后我们再次将这堆$2^{k-1}$球分成两半，依此类推。 - 每次检查球被减半的数量，经过$k$检查后我们会找到放射性球。显然，如果$n<2^k$，则$k$ 检查也足够了。因此，为了将一个放射性球与$n$隔离，执行$f_1(n)$测试就足够了，其中$f_1(n)$是$k$对应$n\leq 2^k$的最小整数（换句话说，$f_1(n)$是大于或等于$\log_2 n$的最小整数）。下面我们将看到，少于完成的检查数量是不够的。

让我们再次返回到 图 1。从单元格的最低行（对应于最后一个第五个检查）开始，$2^5=32$ 箭头延伸。一般来说，对于$k$检查，会有$2^k$。如果写在图表上的庞斯卡方法保证放射性球的隔离，那么这些箭头中的每一个仅对应于可能的答案选项之一：哪两个球是放射性的（但是，也许不同的箭头对应于相同的选项）。因此，不同可能答案选项的数量取决于不超过箭头的数量，即不超过$2^k$。

让我们这样表述这个主要信息：

如果可能的选项数量大于 $2^k$，则无法在 $k$ 检查中选择这些选项之一。

同样可以这样说：

如果有一种方法允许您在 $k$ 检查中从 $N$ 中选择一个选项，那么$N \leq 2^k$。

（最后一个不等式也可以写成：$k \geq f_1(N)$。）

当然，这条规则适用于任何需要根据多次检查的结果从$N$中选择一个选项的问题；唯一重要的是，每次检查都有两个可能的初始值：“有放射性”和“没有放射性”）。

特别是，从这个规则可以看出，在少于$f_1(n)$的检查中不可能从$n$中选择一个相同的放射性球：如果$f_1(n) = k$，则$2^{k-1} < n$，并且此问题中有$n$不同的选项（第一个球是放射性的，第二个球是放射性的，......，第$n$是放射性球）。

让我们再次回到有两个放射性球的问题。有多少种不同的选择？在 图 1 处，我们从 7 个球中选择 2 个球，选项数量为 21 个。一般来说，有 $C_n^2 = \frac{n(n-1)}{2}$ 个选项可以从 $n$ 中选择 2 个球。根据上面印在粉红色背景上的基本规则，如果在 $k$ 中检查可以从 $n$ 中选择 2 个球，则可以从 $\frac{n(n-1)}{2} \leq 2^k$ 中选择。

条件表示从$n$到$f_2(n)$选择2个球所需的最少检查次数。那么最后的不等式可以写成如下：

$$f_2(n) \geq f_1\left(\frac{n(n-1)}{2}\right).$$

从表中可以清楚地看出，对于某些 $n$（例如，$n=6$、$n=8$），这里可能存在严格的不等式。事实上，为了让$k$检查能够在$n$中找到2个放射性球，仅仅满足不等式$\frac{n(n-1)}{2} \leq 2^k$是不够的。还有必要的是，第一次检查结果应为“+”（自然放射性）的选项不应超过$2^{k-1}$，而结果应为“-”（无放射性）的选项也应不超过$2^{k-1}$ - 因为否则，根据基本规则，我们将无法在$k-1$检查时选择这些选项之一！同样，每个结果“++”（第一个检查“+”，第二个检查“+”）、“+—”、“+—”、“—”应对应不超过$2^{k-2}$选项等。

我们通常通过在参数的极值处使用它来检查答案。我们假设$S_2 \rightarrow S_1$。在这种情况下$T \rightarrow \infty$。这是可以理解的。整个系统通过上活塞面积为$S_1 - S_2$的桩上的水压保持平衡。如果$S_1 \rightarrow S_2$，那么该权益上的压力应该趋于无穷大。在这种情况下，线的张力也应趋于无穷大。

F39

半径为$r$、质量为$M$的行星被由分子量为$\mu$的气体组成的同样稠密的大气层包围。如果大气层高度为$h$，那么行星表面大气层的温度是多少？

让我们写出体积为 $V$、质量为 $m$ 的气体状态方程（门捷列夫-克拉佩龙方程）：

$$PV = \frac{m}{\mu} RT;$$

$P$ 是压力，$V$ 是气体体积，$R$ 是气体常数，$T$ 是温度。由于$\frac{m}{V} = \rho$，其中$\rho$是气体密度，我们可以将这个方程重写为$P = \frac{\rho}{\mu} RT$的形式。

因此$T = \frac{P\mu}{\rho R}$。

显然，为了找到行星表面的温度，我们需要找到其表面的压力。如果$\rho = \text{const}$，则$P = \rho gh$，其中$g$是给定行星上自由压力的加速度。我们去找他吧。

对于位于行星表面的质量为 $m$ 的物体，吸引力等于 $mg$。另一方面，根据万有引力定律，它等于$\gamma \frac{mM}{r^2}$。因此我们可以写成$mg = \gamma \frac{mM}{r^2}$。

因此$g = \gamma \frac{M}{r^2}$和$P = \rho \gamma \frac{M}{r^2} h$。

将$P$的表达式代入温度方程，我们得到

$$T = \frac{\gamma M\mu h}{r^2 R}.$$

 该问题的正确解决方案是由来自奥尔沙的 V. Malkov 和来自莫斯科的 A. Proskuryakov 发送的。

F40

如果氖气的能量为 $I = 21,5$ eV，并且电极与气体原子连续两次碰撞之间的平均距离为 $l = 0,4$ mm，则氖灯在电极之间的电势差为多少时会发光？电极呈大平板状，彼此之间的距离为 $d = 3$ mm。

如果电极之间的电位差为$U$，则它们之间的电场方向为$E = \frac{U}{d}$。在该场中，电子受到力 $F = E \cdot e$（e 是电子的电荷）的作用，产生加速度 $a = \frac{F}{m} = \frac{Ee}{m} = \frac{Ue}{dm}$，其中 $m$ 是电极的质量。

当电子与气体原子碰撞时，它会将能量转移给它并被放弃（我们假设碰撞是非弹性的）。原子的质量大于电极的质量。因此，在碰撞过程中，气体原子会转移能量$\frac{mv^2}{2}$，这是由其连续的斯托尔诺夫之间的电子获得的。该能量必须等于气体名义能量 $I$：

$$\frac{mv^2}{2} = I.$$

现在让我们求出电子获得的速度。如果耀斑时间为$t$，那么我们可以写成$v = a\tau = \frac{Ue}{md} t$和$l = \frac{a\tau^2}{2} = \frac{Ue\tau^2}{2md}$。从这些方程我们发现

$$v = \sqrt{\frac{2Uel}{md}}.$$

将这个表达式代入 $v$ 方程 (*)，我们得到

$$\frac{Uel}{d} = I.$$

因此$U = \frac{Id}{el} \approx 160\theta$。
