⟦folio 50⟧

外根的另一个来源是基本对数方法的使用

$$a^{\log_a b} = b \quad (b > 0, a > 0, a \neq 1)$$

在$a$和$b$包含未知数的情况下。

示例 9. 求解方程 $x^{\log_x(x^2+1)} = 2$。

解决方案。使用 toskedness (16)，我们得到 $x^2+1=2$，由此得到 $x_1=-1, x_2=1$。但$x=\pm 1$的值不能是对数的底，即不包含在ODZ中。因此该方程无解。

如果方程包含不同底数的对数，则必须使用以下公式从一个对数底数移至另一底数：

$$\log_b A = \frac{\log_a A}{\log_a b} \quad (A > 0, a > 0, b > 0, a \neq 1, b \neq 1)$$

及其特殊情况

$$\log_b a = \frac{1}{\log_a b} \quad (a > 0, b > 0, a \neq 1, b \neq 1).$$

例 10. 求解方程

$$\log_3 x \frac{3}{x} + \log_3^2 x = 1.$$

解决方案。我们找到 ODZ：$x > 0, x \neq \frac{1}{3}$。使用公式（17），我们转到第一项的底数 3；然后我们得到

$$\frac{\log_3 \frac{3}{x}}{\log_3(3x)} + \log_3^2 x = 1,$$ 或 $$\frac{1-\log_3 x}{1+\log_3 x} + \log_3^2 x = 1.$$

我们用$\log_3 x$来表示它。通过 $y$，那么方程的形式为

$$\frac{1-y}{1+y} + y^2 = 1$$ 或 $$y^3 + y^2 - 2y = 0,$$

我们在哪里可以找到$y_1=0, y_2=-2, y_3=1$。我们正在考虑三种可能性：

a) $\log_3 x=0, x_1=1$; b) $\log_3 x=1, x_3=3$.

例 11. 求解方程

$$20 \log_ax \sqrt{x} + 7 \log_a^2 x^3 = 3 \log_x x^2 \quad (a > 0, a \neq 1).$$

解决方案。我们找到 ODZ：$x > 0, x \neq \frac{1}{a}, x \neq \frac{1}{a^2}, x \neq \sqrt{a}$。由于$x > 0$，我们可以应用公式（8），得到

$$10 \log_ax x + 21 \log_a^2 x = 6 \log_x x.$$
