对数方程
V.V.戈德堡

对数方程通常称为对数符号下包含未知量的方程。
求解最简单的对数方程

$$\log_a x = b$$

(1)
基于对数的以下属性：如果两个（正）数字以相同底数 $a(a > 0, a \neq 1)$ 的对数相等，则这些数字本身也相等。

将方程（1）写成$\log_a x = \log_a a^b$的形式并使用指示的性质，我们得到答案：$x = a^b$。

该技术还适用于求解以下形式的更复杂的对数方程

$$\log_a f(x) = b.$$

(2)
对于方程（2），我们得到$f(x) = a^b$。

示例 1：求解方程

$$\log_5 [2 + \log_3(3+x)] = 0.$$

解决方案e.首先我们发现

$$2 + \log_3(3+x) = 5^0, \quad 2 + \log_3(3+x) = 1, \quad \log_3(3+x) = -1.$$

接下来我们找到：$3 + x = 3^{-1}, x = \frac{1}{3} - 3, x = -\frac{8}{3}$。

一些对数方程很容易成为最简单方程的性质。因此，形式的方程

$$f(\log_a x) = 0$$

(3)
通过替换 $\log_a x = y$，它们被添加到方程 $f(y) = 0$ 中。如果$y_1, \dots, y_k$是最后一个方程的根，那么我们得到一组简单的对数方程：

$$\log_a x = y_1, \dots, \log_a x = y_k.$$

示例 2. 求解方程 $\lg^3 x - \lg^2 x - 6 \lg x = 0$。

解决方案e.让我们用 $y$ 表示 $\lg x$。然后我们得到$y$的三次方程：

$$y^3 - y^2 - 6y = 0.$$

让我们来解决它：$y(y^2 - y - 6) = 0, y_1 = 0, y_2 = 3, y_3 = -2$。我们考虑三种可能的情况：

a). $\lg x = 0, x_1 = 1$; 6) $\lg x = 3, x_2 = 1000$; b) $\lg x = -2, x_3 = 0,01$.

如果指数-对数方程首先被多边形化，则它们类似于形式 (3) 的方程。
