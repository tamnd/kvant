⟦folio 49⟧

式(6′)和(7′)的左右部分以及式(6)和(7)对A和B有不同的限制：左边部分在A和B符号相同时有意义，而右边部分对于任意非零A和B有意义。

因此，“从左到右”使用公式（6'）和（7'）会导致方程的OA可能更宽。但这已经没有ODZ的存在那么奇怪了，或者说现在我们不能失去根，而只能获得一个结构。正如我们已经指出的，在这种情况下，有必要检查所得的解（有时检查它们是否包含在原始方程的 ODZ 中就足够了）。

例 7：解方程
$$\lg(x+1)^2 + \lg(x+9)^2 = 2\lg 9.$$ (12)

为了防止遇到一些错误，我们首先提出不正确的解决方案。

使用公式（8）我们发现$2\lg(x+1) + 2\lg(x+9) = 2\lg 9$，或者
$$\lg(x+1) + \lg(x+9) = \lg 9.$$ (13)

应用式(6)，得到数据
$$\lg[(x+1)(x+9)] = \lg 9,$$ (14)

从那里我们找到$(x+1)(x+9) = 9$，或$x^2 + 10x = 0$，然后$x_1 = 0, x_2 = -10$。经检验，根满足式(12)。

现在让我们给出方程（12）的正确解。

解决方案。我们求出方程（12）的ODZ：$x \neq -9, x \neq -1$。利用式(7′)可得$2\lg|x+1| + 2\lg|x+9| = 2\lg 9$，由此可得$\lg|(x+1)(x+9)| = \lg 9$，进一步可得$|x^2 + 10x+9| = 9$。

最后的等式在以下任一情况下成立：

a) $x^2 + 10x+9 = 9, x^2 + 10x = 0, x_1 = 0, x_2 = -10$;
b) $x^2 + 10x+9 = -9, x^2 + 10x+18 = 0, x_3 = -5 + \sqrt{7}, x_4 = -5 - \sqrt{7}$.

因此，方程(12)有四个根。

正如您显然已经证明的那样，上述错误解决方案中的错误是应用了公式（8），而不是（8′）。这可简化为具有更窄 ODZ 的方程 (13)：$x > -1$。在下一步中，该商被补偿：方程（14）的 ODZ 比方程（13）的 ODZ 更宽 - 这包括 $x > -1$ 和 $x < -9$。后者应该失去了根$x_2 = -10$，但结果$x_3, 4 = -5 \pm \sqrt{7}$失去了根。

例 8：解方程
$$\lg[(x-2)(x+3)] + \lg[(x+3)/(x-2)] = 1.$$ (15)

解决方案。让我们找到 ODZ：$(x-2)(x+3) > 0$，或$x < -3$ 和 $x > 2$。

使用公式(6′)和(7′)求解：
$$\lg|x-2| + \lg|x+3| + \lg|x+3| - \lg|x-2| = 1.$$

引入类似的项，我们得到$\lg|x+3| = 1/2$，从中我们发现：
$$|x+3| = \sqrt{10}, x+3 = \pm \sqrt{10}, x_1 = -3 + \sqrt{10}, x_2 = -3 - \sqrt{10}$$.

经检验，$x = -3 - \sqrt{10}$将是方程（15）的唯一解。

使用公式（6）和（7）我们可以得到
$$\lg(x-2) + \lg(x+3) + \lg(x+3) - \lg(x-2) = 1,$$
$$\lg(x+3) = \frac{1}{2}, x+3 = \sqrt{10}, x = -3 + \sqrt{10}.$$

通过这个解决方案，我们首先缩小了ODZ，这导致了根$x = -3 - \sqrt{10}$的丢失，然后，在消除相似项后，我们扩大了ODZ，这导致了根$x = -3 + \sqrt{10}$的构建。
