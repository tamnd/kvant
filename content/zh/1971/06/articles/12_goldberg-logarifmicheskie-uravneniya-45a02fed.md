对数方程
V.V.戈德堡

对数方程通常称为对数符号下包含未知量的方程。
求解最简单的对数方程

$$\log_a x = b$$

(1)
基于对数的以下属性：如果两个（正）数字以相同底数 $a(a > 0, a \neq 1)$ 的对数相等，则这些数字本身也相等。

将方程（1）写成$\log_a x = \log_a a^b$的形式并使用指示的性质，我们得到答案：$x = a^b$。

该技术还适用于求解以下形式的更复杂的对数方程

$$\log_a f(x) = b.$$

(2)
对于方程（2），我们得到$f(x) = a^b$。

示例 1：求解方程

$$\log_5 [2 + \log_3(3+x)] = 0.$$

解决方案e.首先我们发现

$$2 + \log_3(3+x) = 5^0, \quad 2 + \log_3(3+x) = 1, \quad \log_3(3+x) = -1.$$

接下来我们找到：$3 + x = 3^{-1}, x = \frac{1}{3} - 3, x = -\frac{8}{3}$。

一些对数方程很容易成为最简单方程的性质。因此，形式的方程

$$f(\log_a x) = 0$$

(3)
通过替换 $\log_a x = y$，它们被添加到方程 $f(y) = 0$ 中。如果$y_1, \dots, y_k$是最后一个方程的根，那么我们得到一组简单的对数方程：

$$\log_a x = y_1, \dots, \log_a x = y_k.$$

示例 2. 求解方程 $\lg^3 x - \lg^2 x - 6 \lg x = 0$。

解决方案e.让我们用 $y$ 表示 $\lg x$。然后我们得到$y$的三次方程：

$$y^3 - y^2 - 6y = 0.$$

让我们来解决它：$y(y^2 - y - 6) = 0, y_1 = 0, y_2 = 3, y_3 = -2$。我们考虑三种可能的情况：

a). $\lg x = 0, x_1 = 1$; 6) $\lg x = 3, x_2 = 1000$; b) $\lg x = -2, x_3 = 0,01$.

如果指数-对数方程首先被多边形化，则它们类似于形式 (3) 的方程。

技巧 3. 求解方程 $x^2 + \log_3 x = 3^8$。

解决方案。由于等式两边都是正数（ODZ：$x > 0$），我们将它们的对数以 3 为底：$\log_3 x^2 + \log_3 x = \log_3 3^8$，这意味着$(2 + \log_3 x) \log_3 x = 8$。用 $y$ 表示 $\log_3 x$，我们得到根为 $y_1 = -4, y_2 = 2$ 的二次方程 $y^2 + 2y - 8 = 0$。我们分两种情况来分析：

a) $\log_3 x = -4, x_1 = 1/81$ 6) $\log_3 x = 2, x_2 = 9$.

技巧 4. 求解方程 $9x^{\lg x} + 91x^{-\lg x} = 60$。

解决方案。让我们引入符号$x^{\lg x} = y$；那么 $x^{-\lg x} = \frac{1}{y}$，否则关于 $y$ 的性质方程为以下方程：$9y^2 - 60y + 91 = 0$。后者的根是$y_1 = \frac{13}{3}, y_2 = \frac{7}{3}$。我们正在考虑两种可能性：

a）$x^{\lg x} = \frac{13}{3}$；对数，我们得到$\lg x^{\lg x} = \lg \frac{13}{3}, \lg^2 x = \lg \frac{13}{3}$，由此得到$\lg x = \pm \sqrt{\lg \frac{13}{3}}, x_1 = 10^{\sqrt{\lg \frac{13}{3}}}, x_2 = 10^{-\sqrt{\lg \frac{13}{3}}}$；

b）$x^{\lg x} = \frac{7}{3}$；与第一种情况类似，我们找到$x_3 = 10^{\sqrt{\lg \frac{7}{3}}}, x_4 = 10^{-\sqrt{\lg \frac{7}{3}}}$。

求解对数方程时，求解以下类型的方程通常涉及属性问题

$$\log_a f(x) = \log_a g(x).$$

在这里，使用增强，我们需要进入方程

$$f(x) = g(x).$$

但应该记住，随着最大值的增加，我们正在扩展 ODZ 方程，因此可能会出现无关的根。因此，需要检查式(5)的各根是否包含在式(4)的ODZ中。

技巧 5. 求解方程 $\log_2(2x^2 - 2) = \log_2(5x - 4)$。

解决方案。寻找 ODZ：

$$\begin{cases} 2x^2 - 2 > 0, \\ 5x - 4 > 0, \end{cases}$$

即$$\begin{cases} x < -1, x > 1, \\ x > \frac{4}{5}. \end{cases}$$

因此，ODZ：$x > 1$。这个方程的效力，我们从 $x_1 = 2, x_2 = 1/2$ 得到 $2x^2 - 2 = 5x - 4$ 或 $2x^2 - 5x + 2 = 0$。

由于 $x_2 = 1/2$ 不包含在 ODZ 中，因此方程只有一个解：$x = 2$。

数字对数的以下性质是众所周知的：

$$\log_a(AB) = \log_a A + \log_a B \quad (A > 0, B > 0, a > 0, a \neq 1),$$

$$\log_a \frac{A}{B} = \log_a A - \log_a B \quad (A > 0, B > 0, a > 0, a \neq 1),$$

$$\log_a A^p = p \log_a A \quad (A > 0, p - \text{любое действительное число}),$$

$$\log_a q^p = \frac{p}{q} \log_a A \quad (A > 0, q \neq 0).$$

当表达式 $A$ 和 $B$ 包含未知数时，在求解对数方程时应如何使用对数的这些性质？

为了回答这个问题，我们注意到这些公式左右部分的ODZ是不同的：例如，公式（6）的右侧仅对$A > 0$和$B > 0$有意义，而该公式的左侧既对$A > 0$和$B > 0$定义，又对$A < 0$、$B < 0$定义。

同样，对于其他公式，左侧的 ODZ 可能会比右侧的 ODZ 宽（此时，公式（9）中需要考虑底数中包含的$a$的允许值。这意味着，如果我们“从右到左”使用公式（6）-（9），那么我们将得到一个由原方程推导出来的方程（其 ODZ 可能为同时，我们保证不会消耗根，但在这种情况下，我们可以获得根的构造，因此必须检查所有获得的根（如果根的构造只能作为使用公式（6）-（9）的结果出现，那么检查获得的根是否包含在原始方程的ODZ中就足够了）。

例 6：解方程

$$\log_{\frac{1}{6}}(x-1) + \log_{\frac{1}{6}}(5x+3) = -2.$$

解决方案。寻找 ODZ：

$$\begin{cases} x-1 > 0, \\ 5x+3 > 0. \end{cases} \quad \begin{cases} x > 1, \\ x > -\frac{3}{5}. \end{cases}$$

因此，ODZ 为：$x > 1$。

将式(6)代入等式左边，可得

$$\log_{\frac{1}{6}}[(x-1)(5x+3)] = -2,$$

我们找到 $(x-1)(5x+3) = 36$ 或 $5x^2-2x-39=0$。一元二次方程的根是$x_1=3$、$x_2=-13/5$。

由于根的构造只能通过公式（6）的使用而出现，因此检查所获得的解是否包含在公式（10）的ODZ中就足够了。因此，我们确信方程有唯一解$x=3$。请注意，值$x=-13/5$不是方程（10），而是方程（11）的解，其ODZ更宽：$x > 1$，$x < -3/5$。

如果求解对数方程时，需要“从左到右”使用公式（6）~（9），该怎么办？毕竟，如果以我们写出的形式使用这些公式，我们将得到一个方程，其 ODZ 可能比原始方程的 ODZ 更窄！但那样我们可能会失去一些根！

为了防止这种情况发生，我们必须使用更通用的公式：

$$\log_a(AB) = \log_a|A| + \log_a|B| \quad (AB > 0,a > 0,a \neq 1),$$

$$\log_a\frac{A}{B} = \log_a|A| - \log_a|B| \quad (AB > 0,a > 0,a \neq 1),$$

$$\log_aA^{2p} = 2p\log_a|A| \quad (A \neq 0,p - целое число),$$

$$\log_a^{2q}A = \frac{1}{2q}\log_a|A| \quad (A > 0,q \neq 0 - целое число).$$

例 7：解方程
$$\lg(x+1)^2 + \lg(x+9)^2 = 2\lg 9.$$ (12)

为了防止遇到一些错误，我们首先提出不正确的解决方案。

使用公式（8）我们发现$2\lg(x+1) + 2\lg(x+9) = 2\lg 9$，或者
$$\lg(x+1) + \lg(x+9) = \lg 9.$$ (13)

应用式(6)，得到数据
$$\lg[(x+1)(x+9)] = \lg 9,$$ (14)

从那里我们找到$(x+1)(x+9) = 9$，或$x^2 + 10x = 0$，然后$x_1 = 0, x_2 = -10$。经检验，根满足式(12)。

现在让我们给出方程（12）的正确解。

解决方案。我们求出方程（12）的ODZ：$x \neq -9, x \neq -1$。利用式(7′)可得$2\lg|x+1| + 2\lg|x+9| = 2\lg 9$，由此可得$\lg|(x+1)(x+9)| = \lg 9$，进一步可得$|x^2 + 10x+9| = 9$。

最后的等式在以下任一情况下成立：

a) $x^2 + 10x+9 = 9, x^2 + 10x = 0, x_1 = 0, x_2 = -10$;
b) $x^2 + 10x+9 = -9, x^2 + 10x+18 = 0, x_3 = -5 + \sqrt{7}, x_4 = -5 - \sqrt{7}$.

因此，方程(12)有四个根。

正如您显然已经证明的那样，上述错误解决方案中的错误是应用了公式（8），而不是（8′）。这可简化为具有更窄 ODZ 的方程 (13)：$x > -1$。在下一步中，该商被补偿：方程（14）的 ODZ 比方程（13）的 ODZ 更宽 - 这包括 $x > -1$ 和 $x < -9$。后者应该失去了根$x_2 = -10$，但结果$x_3, 4 = -5 \pm \sqrt{7}$失去了根。

例 8：解方程
$$\lg[(x-2)(x+3)] + \lg[(x+3)/(x-2)] = 1.$$ (15)

解决方案。让我们找到 ODZ：$(x-2)(x+3) > 0$，或$x < -3$ 和 $x > 2$。

使用公式(6′)和(7′)求解：
$$\lg|x-2| + \lg|x+3| + \lg|x+3| - \lg|x-2| = 1.$$

引入类似的项，我们得到$\lg|x+3| = 1/2$，从中我们发现：
$$|x+3| = \sqrt{10}, x+3 = \pm \sqrt{10}, x_1 = -3 + \sqrt{10}, x_2 = -3 - \sqrt{10}$$.

经检验，$x = -3 - \sqrt{10}$将是方程（15）的唯一解。

使用公式（6）和（7）我们可以得到
$$\lg(x-2) + \lg(x+3) + \lg(x+3) - \lg(x-2) = 1,$$
$$\lg(x+3) = \frac{1}{2}, x+3 = \sqrt{10}, x = -3 + \sqrt{10}.$$

通过这个解决方案，我们首先缩小了ODZ，这导致了根$x = -3 - \sqrt{10}$的丢失，然后，在消除相似项后，我们扩大了ODZ，这导致了根$x = -3 + \sqrt{10}$的构建。

外根的另一个来源是基本对数方法的使用

$$a^{\log_a b} = b \quad (b > 0, a > 0, a \neq 1)$$

在$a$和$b$包含未知数的情况下。

示例 9. 求解方程 $x^{\log_x(x^2+1)} = 2$。

解决方案。使用 toskedness (16)，我们得到 $x^2+1=2$，由此得到 $x_1=-1, x_2=1$。但$x=\pm 1$的值不能是对数的底，即不包含在ODZ中。因此该方程无解。

如果方程包含不同底数的对数，则必须使用以下公式从一个对数底数移至另一底数：

$$\log_b A = \frac{\log_a A}{\log_a b} \quad (A > 0, a > 0, b > 0, a \neq 1, b \neq 1)$$

及其特殊情况

$$\log_b a = \frac{1}{\log_a b} \quad (a > 0, b > 0, a \neq 1, b \neq 1).$$

求解对数方程时，有时使用以下公式会比较方便：

$$A^{\log_a B}=B^{\log_a A} (A>0, B>0, a>0, a\neq1).$$

公式（19）的证明非常简单：由于该公式两边都是正数，所以我们求$A^{\log_a B}$和$B^{\log_a A}$以$a$为底的对数。很容易验证这些对数等于同一个表达式$\log_a A \log_a B$；由对数相等我们推导出式(19)的有效性。
