设$l_1, l_2, \dots, l_n$为平面内的多条直线，其中有两条相交线。证明可以以独特的方式在点 $X_1, X_2, \dots, X_n$ 处选择这些线上的每一条，以便在点 $X_i$ 恢复到线 $l_i$ 的重新分配经过点 $X_{i+1}$（对于所有 $i=1, 2, \dots, n-1$），并且在点 $X_n$ 恢复到$l_n$的重新分配经过该点$X_1$。

要做到这一点，只需证明以下三个明显的陈述就足够了。

(1) 如果$l$和$l'$是两条直线，$p : l \rightarrow l'$是将每个点与其在$l'$上的投影关联起来的地图，则$p$是线性地图。

(2) 如果$p_1$和$p_2$是线性映射，则$p_1^\circ p_2$也是线性映射。

(3) 如果$p_1, p_2, \dots, p_n$是线性映射，则$f = p_1^\circ p_2^\circ \dots p_n^\circ$也是线性映射。

显然，(3) 由(2) 归纳推导出来。检查(2)：如果$p_1(x) = a_1x + b_1$和$p_2(x) = a_2x + b_2$，则$(p_1^\circ p_2)(x) = p_1(p_2(x)) = a_1a_2x + (a_1b_2 + b_1)$。为了证明(1)，检查这个公式：

$$p(x) = x \cos \alpha + c,$$

现在，要解决这个问题，只要证明线性方程 $x = ax + b$ 有解，而且只有一个。如果情况并非如此（即，如果没有解或多个解），则$a = 1$。让我们证明这不可能。请注意，对于每个投影 $p_k$: $l_{k+1} \rightarrow l_k$，任何两点之间的距离不会增加：

$$|p_k(x) - p_k(x')| \leq |x - x'|,$$

如果线 $l_{k+1}$ 和 $l_k$ 不平行，则严格递减。由此可见，对于任意两点 $x$ 和 $x'$

$$|f(x) - f(x')| < |x - x'|.$$

但如果$a = 1$，即$f(x) = x + b$，则$f$保留任意两点之间的距离（它只是将它们全部移动距离$b$）。我们之间产生了矛盾。证明是合法的。

解方程
$$\sqrt[3]{1-x} + \sqrt[3]{1+x} = p,$$
(1)
其中$p$是任意实数。

一个简单的解决方案尝试：对方程两边求三次方
$$2 + 3\sqrt[3]{1-x^2}\left(\sqrt[3]{1-x} + \sqrt[3]{1+x}\right) = p^3$$
(2)
并在这里替换原来的等式（1）：
$$2 + 3p\sqrt[3]{1-x^2} = p^3.$$ (3)
现在很容易找到 $x$：
$$x = \pm \sqrt{1 - \left(\frac{p^3 - 2}{3p}\right)^3}.$$ (4)
我们收到了许多收到答复的信件（以这种方式和其他方式）。还有相当多的字母，其中找到一组 $p$ 的值是正确的，其中公式（4）有意义：
$$p = -1, \quad 0 < p \leq 2.$$
有些人甚至注意到值$p = -1$应该被丢弃，因为公式$p$给出的值$x = 0$不合适。但并未证明对于所有$p$、$0 < p \leq 2$，式(4)给出的值$x$都是解。 （通常这样的证明是一个测试，但在这里很难做到。）并且必须证明这一点，因为并非上面执行的所有变换都保持等效：方程（2）不等于（3）。要看到这一点，请将 $x = 0$、$p = -1$ 代入 (2) 和 (3) 中。等式（3）将返回相同的位置，但（2）不会。因此，信件中关于这种变换是等价的陈述是不正确的。 （确实：尝试从（3）推导出（2）。你必须使用等式（1），即问题的条件，这是不可能的，因为这正是需要证明的。）如果是这样，那么可以构造其他根。

从方程。
$$u + v = p$$

$$u^3 + v^3 + 3uv(u + v) = p^3$$
(2)

**M73**

在彩票上，您需要标记 64 个单元格中的 8 个。在抽奖后，也选择了 64 个单元格中的 8 个单元格（我们认为所有这些可能性都是同等概率），结果恰好有 4 个单元格被猜中的概率是多少？ 5 个电池？...全部 8 个电池？

众所周知，64 个单元格中的 8 个可以按$C_{64}^8=\frac{64!}{8!56!}$ 方式选择（$n!$ 是从 1 到 $n$（含）的所有整数的乘积$^*$）。所有这些方法都同样可靠。因此，获得任何一种特定方式的概率是 $1/C_{64}^8$。现在我们需要计算该案例在什么时间恰好有 $k$ 个单元格 ($0\leqslant k\leqslant8$)。这种情况的数量等于方法的数量

$^*$) 例如，参见 N. Ya 的文章。 Vilenkin “组合学”，«Kvant» No. 1，1971。

图 6. 红细胞是胜利者；我们选择的 8 个单元格标有十字。就这个图$k=2$，$8-k=6$。

方法中，从 8 个标记的细胞中选择 $k$ 细胞，从 56 个未标记的细胞中选择 $8-k$ 细胞。因此它等于$C_{8}^k\cdot C_{56}^{8-k}$。要找到所需时间 $f_k$ - 准确猜测 $k$ 个单元格的概率，您需要将一种方法的概率乘以该数字。我们得到

$$f_k=\frac{C_{8}^k\cdot C_{56}^{8-k}}{C_{8}^4}.$$

因此，猜测 0,1,...,8 个单元格的概率与相应单元格的概率相等。

$$f_0=\frac{C_{8}^0\cdot C_{56}^8}{C_{8}^4},$$

$$f_1=\frac{C_{8}^1\cdot C_{56}^7}{C_{8}^4}, \dots, f_8=\frac{C_{8}^8\cdot C_{56}^0}{C_{8}^4}.$$

这九个数字的总和当然等于一。

从形式上看，问题是有解决方案的，但从实践的角度来看，情况还不是这样。我想想象一下，如果我们购买并填满十张彩票，那么猜测特定数量的单元格的机会有多大。为此，您需要以小数形式近似表示这些数字。这可以使用计算尺来完成；例如直接使用公式(1)。来自茹科夫斯基市的 A. Zlomnik 就是这样做的。我们将描述另一种在我们看来更简单的方法。

F79

进入船的水位与湖中的水位一致。如果你把一根木头扔进船上，哪里的水位会更高？

当将一根圆木放入船上时，船会投入湖中，您将获得额外体积的水$\Delta V = \frac{m}{\rho}$（$m$是圆木的质量，$\rho$是水的密度）。另一方面，由于原木漂浮在水中，因此船内水位的变化方式应与向船上添加质量等于原木质量、体积等于原木浸入部分体积（即$V = \frac{m}{\rho}$）的水的变化相同。 （我们可以在心里把圆木移走，然后把所得的水注满水，但船里的水位不会改变。）当把圆木扔进船里时，船里还会流出相同体积的水。因此，船内的水位将与船内的水位相同。

如果船壁的厚度可以忽略不计，则湖中的水位较低；如果船壁较厚，则湖中的水位会略高于湖中的水位。

$$a_y = \frac{F + F_tp \cos \varphi}{m} = \frac{F + F \cos \varphi}{m} = a.$$
