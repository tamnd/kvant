⟦folio 10⟧

我们发射点$A_4$。我们用$a_4$表示向量$\vec{OA}_4$，从点$A_3$我们把$a_4$放在一边，依此类推。

我们得到两条虚线：$A_1 A_3 A_5 \dots$和$A_2 A_4 A_6 \dots$，体积轴$l$（图3）。可能会发生点 $A_k$ 之一直接落在 $l$ 上 - 这是过程停止的地方。事实可能不会发生——那么这个过程将是无止境的。

统称为拉鼻子算法（ABH）。

现在让我们将所有结构投影到垂直于 $l$ 轴的直线上。轴 $l$ 本身将进入一个点，向量 $a_k$ 进入线段，我们用 $b_k (k=1, 2, 3, \dots)$ 表示。让我们获得我们已知的线段$b_1$和$b_2$的欧几里得算法。尤其，

$$\frac{b_1}{b_2} = \left[ m_1; m_2, m_3, m_4, \dots \right]$$

因此，

$$\frac{b_2}{b_1} = \left[ 0; m_1, m_2, m_3, \dots \right].$$

现在我们将展示如何使用 ABH 来解决我们的几何问题（参见§ 1）。让我们考虑§1中提到的格子，它的点对应于数字$\alpha$的近似值（我们可以方便地假设$0 < \alpha < 1$；显然，在证明Hurwitz-Borel定理时我们可以将自己限制为这样的数字）。

让我们将 ABH 指向向量 $a_1 = \vec{OA}_1$ 和 $a_2 = \vec{OA}_2$（我们的晶格就建立在这些向量上），以及轴 $l = OY$。结果是两条虚线$A_1 A_3 A_5 \dots$、$A_2 A_4 A_6 \dots$，实轴$OY$（图 4）。

ABH中出现的数字$m_1, m_2, \dots$无非是部分部分数字$\alpha$。更准确地说，将 $\alpha$ 展开为连分数如下所示：

$$\alpha = \left[ 0; m_1, m_2, \dots \right]$$

（回想一下$0 < \alpha < 1$）。

现在让我们证明折线的几个性质。

定理1.点$A_1, A_2, A_3, \dots$是格点。

这个断言的有效性从图 4就可以清楚地看出。它的完整证明基于第一部分的定理2。我们将细节留给读者。

定理2. 在虚线$A_1, A_3 A_5 \dots$和$A_2 A_4 A_6 \dots$之间（可能在图中的保护区内），晶格的力量是静音的。

证明。 ABH 由向量的顺序沉积组成：$A_1 B, BA_3; A_2 C, CA_4; A_3 D, DE; \dots$。对于每个这样的向量，我们构造一个平行四边形，其边是该向量和与其平行的向量。我们得到一系列平行四边形

$$OA_2 BA_1, OA_2 A_3 B, OA_2 CA_3, OCA_4 A_3, OA_4 DA_3, \dots$$
