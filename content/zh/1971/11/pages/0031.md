P. Ayulov、A. Brevdo、L. Brauzinsky、G. Vysotskaya、S. Grigoryan、A. Gordenko、I. Jabbarov、A. Kleyin、A. Kmizhnerman、I. Kochubeevsky、G. Levin、M. Preezer、E. Skryt、A. Slinkin、A. Chernyak 等人正确解决了该问题。除了该解决方案之外，还有许多其他与我们相似的解决方案，其中进行了归纳；在一些作品中，已经证明可以连续重新排列每一列，以便数字始终按升序出现在行中。

N·B·瓦西里耶夫

M72

解方程
$$\sqrt[3]{1-x} + \sqrt[3]{1+x} = p,$$
(1)
其中$p$是任意实数。

一个简单的解决方案尝试：对方程两边求三次方
$$2 + 3\sqrt[3]{1-x^2}\left(\sqrt[3]{1-x} + \sqrt[3]{1+x}\right) = p^3$$
(2)
并在这里替换原来的等式（1）：
$$2 + 3p\sqrt[3]{1-x^2} = p^3.$$ (3)
现在很容易找到 $x$：
$$x = \pm \sqrt{1 - \left(\frac{p^3 - 2}{3p}\right)^3}.$$ (4)
我们收到了许多收到答复的信件（以这种方式和其他方式）。还有相当多的字母，其中找到一组 $p$ 的值是正确的，其中公式（4）有意义：
$$p = -1, \quad 0 < p \leq 2.$$
有些人甚至注意到值$p = -1$应该被丢弃，因为公式$p$给出的值$x = 0$不合适。但并未证明对于所有$p$、$0 < p \leq 2$，式(4)给出的值$x$都是解。 （通常这样的证明是一个测试，但在这里很难做到。）并且必须证明这一点，因为并非上面执行的所有变换都保持等效：方程（2）不等于（3）。要看到这一点，请将 $x = 0$、$p = -1$ 代入 (2) 和 (3) 中。等式（3）将返回相同的位置，但（2）不会。因此，信件中关于这种变换是等价的陈述是不正确的。 （确实：尝试从（3）推导出（2）。你必须使用等式（1），即问题的条件，这是不可能的，因为这正是需要证明的。）如果是这样，那么可以构造其他根。

让我们更详细地检查我们对方程所做的转换。为了简洁起见，我们用 $\sqrt[3]{1-x} = u$ 和 $\sqrt[3]{1+x} = v$ 表示。

从方程。
$$u + v = p$$
我们继续讨论方程
$$u^3 + v^3 + 3uv(u + v) = p^3$$
(2)
使用等效变换（将对象提升为立方体）。下一步是将 $p$ 与 $u + v$ 一起代入方程
$$u^3 + v^3 + 3uvp = p^3,$$
(3)
我们将这样写：
$$u^3 + v^3 - p^3 + 3uvp = 0,$$
$$(u + v)^3 - p^3 - 3uv(u + v - p) = 0.$$
让我们应用两个立方之差的公式，然后将 $(u + v - p)$ 放在括号之外：
$$(u + v - p)(u^2 + v^2 + p^2 + up + pv - uv) = 0.$$ (3')
因此，我们设法将方程（3）写成这种形式（3'），从中很容易研究为什么它不等于（2）。很明显，当至少一个括号等于 0 时，(3') 的左侧等于 0：
1) $u + v - p = 0,$
2) $u^2 + v^2 + p^2 + up + pv - uv = 0.$
