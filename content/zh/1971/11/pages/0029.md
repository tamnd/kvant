让我们证明映射$f$是线性的：$f(x) = ax + b$。

要做到这一点，只需证明以下三个明显的陈述就足够了。

(1) 如果$l$和$l'$是两条直线，$p : l \rightarrow l'$是将每个点与其在$l'$上的投影关联起来的地图，则$p$是线性地图。

(2) 如果$p_1$和$p_2$是线性映射，则$p_1^\circ p_2$也是线性映射。

(3) 如果$p_1, p_2, \dots, p_n$是线性映射，则$f = p_1^\circ p_2^\circ \dots p_n^\circ$也是线性映射。

显然，(3) 由(2) 归纳推导出来。检查(2)：如果$p_1(x) = a_1x + b_1$和$p_2(x) = a_2x + b_2$，则$(p_1^\circ p_2)(x) = p_1(p_2(x)) = a_1a_2x + (a_1b_2 + b_1)$。为了证明(1)，检查这个公式：

$$p(x) = x \cos \alpha + c,$$

其中$\alpha$是$Ox$和$O'x'$轴正方向之间的角度，$c$是$Ox'$系统中点$p(O)$的坐标（图2；也考虑线$l$和$l_1$平行时的情况）。

现在，要解决这个问题，只要证明线性方程 $x = ax + b$ 有解，而且只有一个。如果情况并非如此（即，如果没有解或多个解），则$a = 1$。让我们证明这不可能。请注意，对于每个投影 $p_k$: $l_{k+1} \rightarrow l_k$，任何两点之间的距离不会增加：

$$|p_k(x) - p_k(x')| \leq |x - x'|,$$

如果线 $l_{k+1}$ 和 $l_k$ 不平行，则严格递减。由此可见，对于任意两点 $x$ 和 $x'$

$$|f(x) - f(x')| < |x - x'|.$$

但如果$a = 1$，即$f(x) = x + b$，则$f$保留任意两点之间的距离（它只是将它们全部移动距离$b$）。我们之间产生了矛盾。证明是合法的。

对于线不在平面上而是在空间中（它们也可以相交）的情况，问题 M70 和我们的解决方案已重新建立，没有任何更改。在这种情况下，$p_k$表示在空间中$l_k$线上的投影：对应于从该点下降到线$l_k$上的垂直底线的每个点的映射。

图 2. 将一条线上的每个点指定到另一条线上的投影的映射被写为线性函数。

图 3.点$X_1$，对于$f(X_1) = X_1$，实际上很容易找到逐次逼近的方法：从任意点$X$开始，降低与给定直线的垂线，并在点$X' = f(X)$$X'' = f(X')$的每个“循环”后找到连续的点，依此类推。不难证明，距离$|X - X_1|, |X' - X_1|, |X'' - X_1|$，...与$|a| < 1$形成无限递减的等比级数，这样通过多次重复构造，我们就可以以任意准确度找到点$X_1$的位置。类似的方法也常用于求解 $f(X) = X$ 形式的方程；当函数$f$减少任意两点之间的距离时将应用它。在我们的例子中，当$f$是一个有标签的线性函数时，可以准确地找到方程$f(X) = X$的解（想想如果$X, X'$和$X''$已知，如何找到点$X_1$）。
