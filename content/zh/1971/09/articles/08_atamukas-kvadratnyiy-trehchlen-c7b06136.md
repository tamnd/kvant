平方三线是一般形式的二阶多项式

$$ax^2 + bx + c, \quad a \neq 0.$$

在数学入学考试中，经常会出现与平方三角形直接或间接相关的问题。是的，这并不奇怪 - 在学校课程中，大量的空间和时间都被用来学习二次方程

$$ax^2 + bx + c = 0,$$

找出二次函数的性质

$$y = ax^2 + bx + c.$$

这个函数也存在于物理学中；例如，当描述倾斜于地平线的一点的材料的运动时。

当然，小学生都清楚所有与直角三角形相关的公式；他们还可以绘制二次函数的图形 - 抛物线。然而，当涉及到解决特定问题时，大多数工具都会尝试仅使用公式进行纯粹的分析。同时，几何考虑的使用常常使我们能够更容易、更快地获得答案。

我们将通过几个例子来展示在解决问题时同时使用代数和几何语言进行思考是多么重要。

为了检查您对正方形三棱柱的性质的熟悉程度，我们首先考虑这个问题（莫斯科国立大学的口语考试中提供了该问题）。

$$f(x) = ax^2 + bx + c.$$

由于该抛物线的分支向上，因此系数为 $a > 0$。 （证明一下！很多申请者是这样解释的：“课本上显示

在许多问题中，需要找出二次函数$f(x) = ax^2 + bx + c$在给定区间$(\alpha, \beta)$上的行为，描述该三角形的根相对于横坐标轴的固定点$x = \gamma$的位置等。在这些问题中，几何语言使解释变得简单明了（而且，相当严格！）。

2. 基于横坐标，指示间隔$\alpha < x < \beta$。对于 $a$、$b$ 和 $c$ 等式

$$ax^2 + bx + c = 0, \ a \neq 0, \ b^2 - 4ac > 0$$

这个区间只有一个根吗？

换句话说，我们需要找出函数$f(x) = ax^2 + bx + c$的图像在$a$、$b$和$c$中与x轴在区间$\alpha < x < \beta$上恰好相交一次。

如果试图用方三角形的根$x_1$和$x_2$的公式分析地解决这个问题，那么在数字$\alpha$和$\beta$之间只有一个根的条件就写得非常符合语法。几何方法使得可以以简单的形式立即获得该条件。

让我们想象一下满足任务中设置的条件的三角形图会如何表现；显然，图2 表示的四个位置之一是可能的。进一步请注意，在每种情况下，函数 $f(x)$ 在点 $\alpha$ 和 $\beta$ 处的值具有相反的符号，即

$$f(\alpha)f(\beta) < 0,$$

或者，更详细地说，

$$(a\alpha^2 + b\alpha + c)(a\beta^2 + b\beta + c) < 0.$$

对于方程 $ax^2 + bx + c = 0$（对于 $a \neq 0, b^2 - 4ac > 0$）来说，该条件在区间 $(\alpha, \beta)$ 上恰好有一个根是充分必要的。

所以这些图表帮助我们找到了这个条件。他们还提出了如何证明这个条件是必要和充分的。

必要性。设方程有两个根 $x_1$ 和 $x_2$ ($x_1 < x_2$)，有一个根位于区间内 $(\alpha, \beta)$，另一个在它之外。然后是其中一个数字 $\alpha, \beta$ 位于区间内 $(x_1, x_2)$，另一个在它之外。但学校教科书证明了函数的值 $f(x) = ax^2 + bx + c$ 区间外 $(x_1, x_2)$ 根与该区间内的函数值之间的符号相反。因此， $f(\alpha) f(\beta) < 0$.

有足够的吃的。让数字$f(\alpha)$和$f(\beta)$具有不同的符号。那么$b^2 - 4ac > 0$，方程$ax^2 + bx + c = 0$有两个根$x_1$和$x_2$，区间$(x_1, x_2)$内外的函数值符号相反。因此，只有一个数字$\alpha, \beta$位于区间$(x_1, x_2)$之内。但这又意味着只有一个数字 $x_1, x_2$ 位于区间 $(\alpha, \beta)$ 内。

显然，平方函数

$$y = ax^2 + bx + c, \quad a \neq 0, \quad b^2 - 4ac = 0,$$

只有一个根$x_0 = -\frac{b}{2a}$，并且它位于区间$(\alpha, \beta)$ if $\alpha < -\frac{b}{2a} < \beta$。

让我们应用刚才提出的信息来解决以下来自口语考试实践的问题。

3. 证明二次三项式

$$f(x) = (x - a)(x - b) + \lambda (x - c)(x - d)$$

如果已知数字 $c, d$ 中的一个恰好位于区间 $(a, b)$ 内，而另一个在其之外，则对于任何实数 $\lambda$ 都有实数根。

观察各种二次三项式的图形，很容易注意到一个重要的性质：二次三项式在线段$[\alpha, \beta]$上的最大值和最小值只能在以下三个点处实现：在点$x = -\frac{b}{2a}$，当然，如果它属于线段$[\alpha, \beta]$；在点$\alpha$；在点 $\beta$（位于线段的末端）。让我们证明一下；我们假设$a > 0$（情况$a < 0$以类似的方式分析）。

让我们从二次三项式中提取完整的平方：

$$f(x) = ax^2 + bx + c = a \left( x + \frac{b}{2a} \right)^2 + c - \frac{b^2}{4a}.$$

使用这种表示法，很容易证明对于$a > 0$，函数$f(x)$在点$x = -\frac{b}{2a}$处的绝对最小值等于$c - \frac{b^2}{4a}$；在间隔 $(-\infty, -\frac{b}{2a})$ 上，它单调杀死，在间隔 $(-\frac{b}{2a}, \infty)$ 上，它单调增加。

因为如果
$$\alpha \leq -\frac{b}{2a} \leq \beta,$$
那么线段$[\alpha, \beta]$上的函数$f(x)$在点$-\frac{b}{2a}$处取最小值$c - \frac{b^2}{4a}$（参见图3上的图1）。

由于单调性，最低值出现在区间的两端之一。

现在让点$-\frac{b}{2a}$位于线段$[\alpha, \beta]$之外（参见图3上的图2、3）。

那么线段 $[\alpha, \beta]$ 取单调性区间之一，因此，在其一端取最小值，在另一端取最大值。

现在尝试建立一个充要条件，使得二次方程$ax^2 + bx + c = 0$在给定区间$\alpha < x < \beta$上有两个根。

二次三项式的值得注意的性质将使我们更容易解决以下问题。

4. （密歇根州立大学，机制，1970）。对于参数$\alpha$的取值，不等式成立
$$\sin^6 x + \cos^6 x + \alpha \sin x \cos x \geq 0$$
对所有$x$都成立吗？

让我们变换一下不等式的左边：
$$(\sin^2 x)^3 + (\cos^2 x)^3 + \alpha \sin x \cos x =$$
$$= (\sin^2 x + \cos^2 x) (\sin^4 x - \sin^2 x \cos^2 x + \cos^4 x) + \alpha \sin x \cos x =$$
$$= [(\sin^2 x + \cos^2 x)^2 - 3 \sin^2 x \cos^2 x] + \alpha \sin x \cos x =$$
$$= 1 - \frac{3}{4} \sin^2 2x + \frac{\alpha}{2} \sin 2x.$$

让我们用 $y$ 表示 $\sin 2x$；显然，$-1 \leq y \leq 1$、$y^2$的系数为负，因此，在区间$[-1; 1]$上，平方三项式$-\frac{3}{4} y^2 + \frac{\alpha}{2} y + 1$的最小值出现在该区间的两端。

因此不等式
$$-\frac{3}{4} y^2 + \frac{\alpha}{2} y + 1 \geq 0$$
当且仅当三项式在区间末端非负时，整个区间 $[-1; 1]$ 成立：

$$\begin{cases} -\frac{3}{4} (-1)^2 + \frac{\alpha}{2} (-1) + 1 \geq 0, \\ -\frac{3}{4} \cdot 1^2 + \frac{\alpha}{2} 1 + 1 \geq 0 \end{cases}$$

即$\alpha \leq \frac{1}{2}$和$\alpha \geq -\frac{1}{2}$。

答案：这个不等式对于所有 $x$ 和 $-\frac{1}{2} \leq \alpha \leq \frac{1}{2}$ 都成立。

5. （路易斯安那州立大学，数学，1966 年）。火箭的飞行距离必须等于 $H$。它开始以恒定速度 $v$ 移动，并且随时可以开启附加运动，提供恒定加速度 $a$ ($a > 0$)，并一直工作到旅程结束。匀速行驶一段轨道上的燃油消耗与运动时间成正比，开启附加运动时与时间的平方成正比，比例系数$k_1$和$k_2$对应（$k_1, k_2 > 0$）。在附加运动打开的情况下，火箭应该移动多长时间才能使承诺的燃料消耗最少？

设$\tau$为火箭匀速运动的时间，$t$为启用附加运动的运动时间，$A$为燃料消耗。由等式可知：

$$H = v\tau + vt + \frac{at^2}{2}, \quad A = k_1\tau + k_2t^2$$

我们发现

$$\tau = \frac{1}{v} \left( H - vt - \frac{at^2}{2} \right), \quad A = \left( k_2 - \frac{ak_1}{2v} \right) t^2 - k_1t + \frac{k_1H}{v}.$$

注意$0 \leq t \leq t_0$，其中$t_0$是方程的正根

$$H = vt + \frac{at^2}{2}, \quad t_0 = \frac{-v + \sqrt{v^2 + 2aH}}{a}.$$

（如果从一开始就启用移动，则这是飞行时间。）我们需要找到在段 $[0, t_0]$ 上定义的函数 $A = A(t)$ (*) 的最小值。

1) $k_2 - \frac{ak_1}{2v} < 0$。抛物线 $A = A(t)$ 的顶点有横坐标

$$t^* = \frac{k_1}{2 \left( k_2 - \frac{ak_1}{2v} \right)} < 0.$$

抛物线位于 图 4 处。最小值位于 $t = t_0$ 处。

2) $k_2 - \frac{ak_1}{2v} = 0$； $A = -k_1t + \frac{k_1H}{v}$。最低为 $t = t_0$ (图 5)。

3) $k_2 - \frac{ak_1}{2v} > 0$。抛物线顶点横坐标

$$t^* = \frac{vk_1}{2vk_2 - ak_1} > 0.$$

如果 $t^* \leq t_0$，则最小值为 $t = t^*$ (图 6)。
如果 $t^* \geq t_0$，则最小值为 $t = t_0$ (图 7)。
答案：如果 $2vk_2 - ak_1 > 0$ 且

$$\frac{vk_1}{2vk_2 - ak_1} \leq \frac{-v + \sqrt{v^2 + 2aH}}{a},$$

那

$$t = \frac{vk_1}{2vk_2 - ak_1}.$$

如果 $2vk_2 - ak_1 \leq 0$ 或 $2vk_2 - ak_1 > 0$ 且

$$\frac{vk_1}{2vk_2 - ak_1} > \frac{-v + \sqrt{v^2 + 2aH}}{a},$$

那

$$t = \frac{-v + \sqrt{v^2 + 2aH}}{a}.$$
