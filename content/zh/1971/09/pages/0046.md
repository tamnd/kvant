因为如果
$$\alpha \leq -\frac{b}{2a} \leq \beta,$$
那么线段$[\alpha, \beta]$上的函数$f(x)$在点$-\frac{b}{2a}$处取最小值$c - \frac{b^2}{4a}$（参见图3上的图1）。

由于单调性，最低值出现在区间的两端之一。

现在让点$-\frac{b}{2a}$位于线段$[\alpha, \beta]$之外（参见图3上的图2、3）。

那么线段 $[\alpha, \beta]$ 取单调性区间之一，因此，在其一端取最小值，在另一端取最大值。

现在尝试建立一个充要条件，使得二次方程$ax^2 + bx + c = 0$在给定区间$\alpha < x < \beta$上有两个根。

二次三项式的值得注意的性质将使我们更容易解决以下问题。

4. （密歇根州立大学，机制，1970）。对于参数$\alpha$的取值，不等式成立
$$\sin^6 x + \cos^6 x + \alpha \sin x \cos x \geq 0$$
对所有$x$都成立吗？

让我们变换一下不等式的左边：
$$(\sin^2 x)^3 + (\cos^2 x)^3 + \alpha \sin x \cos x =$$
$$= (\sin^2 x + \cos^2 x) (\sin^4 x - \sin^2 x \cos^2 x + \cos^4 x) + \alpha \sin x \cos x =$$
$$= [(\sin^2 x + \cos^2 x)^2 - 3 \sin^2 x \cos^2 x] + \alpha \sin x \cos x =$$
$$= 1 - \frac{3}{4} \sin^2 2x + \frac{\alpha}{2} \sin 2x.$$

让我们用 $y$ 表示 $\sin 2x$；显然，$-1 \leq y \leq 1$、$y^2$的系数为负，因此，在区间$[-1; 1]$上，平方三项式$-\frac{3}{4} y^2 + \frac{\alpha}{2} y + 1$的最小值出现在该区间的两端。

因此不等式
$$-\frac{3}{4} y^2 + \frac{\alpha}{2} y + 1 \geq 0$$
当且仅当三项式在区间末端非负时，整个区间 $[-1; 1]$ 成立：

$$\begin{cases} -\frac{3}{4} (-1)^2 + \frac{\alpha}{2} (-1) + 1 \geq 0, \\ -\frac{3}{4} \cdot 1^2 + \frac{\alpha}{2} 1 + 1 \geq 0 \end{cases}$$

即$\alpha \leq \frac{1}{2}$和$\alpha \geq -\frac{1}{2}$。

答案：这个不等式对于所有 $x$ 和 $-\frac{1}{2} \leq \alpha \leq \frac{1}{2}$ 都成立。
