⟦folio 49⟧

也就是说，在落地的一瞬间，石头的速度与最初的速度相等，但方向相反。

方程（**）可以很容易地找到举起石头的时间$t_\pi$。由于在最大上升点，石头的速度为零，因此

$$0 = v_0 - gt_n.$$

因此$t_\pi = \frac{v_0}{g}$。举起石头所需的时间是飞行时间的一半。

我们看到两个方程——坐标和速度——使我们能够获得有关石头运动的任何问题的答案。这些是应该永远记住的。

我们再解决一个问题。

问题 2. 自由落体在最后一秒已经经过了 $1/3$ 路径。身体移动了多少秒（$n$）以及从什么高度（$h$）移动？

我们以投掷点为坐标原点，坐标轴垂直向下。那么根据规律，物体的坐标取决于时间

$$x = \frac{gt^2}{2}$$

($v_0 = 0, x_0 = 0, a = g$)。如果身体停留$n$秒，则下落时间为$n \cdot \tau$（$\tau = 1$秒），并且

$$h = \frac{gn^2\tau^2}{2}.$$

(1)

运动开始后$(n-1)\tau$时间后，身体坐标等于$\frac{2}{3}h$。这就是为什么

$$\frac{2}{3}h = \frac{g(n-1)^2\tau^2}{2}.$$

(2)

联立方程（1）和（2），我们发现：

$$n = \frac{\sqrt{3}}{\sqrt{3} - \sqrt{2}} \approx 5,45, \quad h \approx 145 \text{ м}.$$

可以选择另一种坐标系，例如与地球相关的坐标系和向上的坐标轴。那么物体的运动方程为：

$$x = h - \frac{gt^2}{2} \left( x_0 = h, v_0 = 0, a = -g \right).$$

这里是$t=n\tau$$x=0$，还有$t=(n-1)\tau$$x=\frac{1}{3}h$。

您可以再选择一种坐标系 - 原点位于投掷点，轴指向上方。在这个系统中

$$x = -\frac{gt^2}{2};$$

在$t=n\tau$$x=-h$，在$t=(n-1)\tau$$x=-\frac{2}{3}h$。

在这个问题中，坐标系的选择并不是很重要，但通常，成功选择坐标系可以显着简化解决方案。

例如，让我们解决以下问题。

问题 3. 如果第二滴水滴在 $t_0$ 时间后开始下落，两滴水滴之间的距离等于 $l$，那么两滴水滴从屋顶落下的时间间隔为 $\tau$ 是多少？

这个问题当然可以在屋顶相关的坐标系中解决（自己动手）。

但转到与第二次下降相关的坐标系会更方便。由于液滴相对于地面以相同的加速度下落，因此它们的相对加速度为零：液滴彼此相对一致。它们的相对速度等于第二滴分离时第一滴相对于地面的速度$v_0=g\tau$。第一个水滴在与第二个水滴相关的坐标系中的运动方程如下所示：

$$x = v_0 t + x_0,$$

其中$x_0 = \frac{gt^2}{2}$。在 $t=t_0$ $x=l$ 时，即

$$l = g\tau t_0 + \frac{gt^2}{2}.$$

解这个方程，我们得到答案：

$$\tau = \sqrt{t_0^2 + \frac{l}{g}} - t_0.$$

让我们解决另一个问题。
