2. 基于横坐标，指示间隔$\alpha < x < \beta$。对于 $a$、$b$ 和 $c$ 等式

$$ax^2 + bx + c = 0, \ a \neq 0, \ b^2 - 4ac > 0$$

这个区间只有一个根吗？

换句话说，我们需要找出函数$f(x) = ax^2 + bx + c$的图像在$a$、$b$和$c$中与x轴在区间$\alpha < x < \beta$上恰好相交一次。

如果试图用方三角形的根$x_1$和$x_2$的公式分析地解决这个问题，那么在数字$\alpha$和$\beta$之间只有一个根的条件就写得非常符合语法。几何方法使得可以以简单的形式立即获得该条件。

让我们想象一下满足任务中设置的条件的三角形图会如何表现；显然，图2 表示的四个位置之一是可能的。进一步请注意，在每种情况下，函数 $f(x)$ 在点 $\alpha$ 和 $\beta$ 处的值具有相反的符号，即

$$f(\alpha)f(\beta) < 0,$$

或者，更详细地说，

$$(a\alpha^2 + b\alpha + c)(a\beta^2 + b\beta + c) < 0.$$

对于方程 $ax^2 + bx + c = 0$（对于 $a \neq 0, b^2 - 4ac > 0$）来说，该条件在区间 $(\alpha, \beta)$ 上恰好有一个根是充分必要的。
