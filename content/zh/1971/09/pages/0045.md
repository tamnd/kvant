所以这些图表帮助我们找到了这个条件。他们还提出了如何证明这个条件是必要和充分的。

必要性。设方程有两个根 $x_1$ 和 $x_2$ ($x_1 < x_2$)，有一个根位于区间内 $(\alpha, \beta)$，另一个在它之外。然后是其中一个数字 $\alpha, \beta$ 位于区间内 $(x_1, x_2)$，另一个在它之外。但学校教科书证明了函数的值 $f(x) = ax^2 + bx + c$ 区间外 $(x_1, x_2)$ 根与该区间内的函数值之间的符号相反。因此， $f(\alpha) f(\beta) < 0$.

有足够的吃的。让数字$f(\alpha)$和$f(\beta)$具有不同的符号。那么$b^2 - 4ac > 0$，方程$ax^2 + bx + c = 0$有两个根$x_1$和$x_2$，区间$(x_1, x_2)$内外的函数值符号相反。因此，只有一个数字$\alpha, \beta$位于区间$(x_1, x_2)$之内。但这又意味着只有一个数字 $x_1, x_2$ 位于区间 $(\alpha, \beta)$ 内。

显然，平方函数

$$y = ax^2 + bx + c, \quad a \neq 0, \quad b^2 - 4ac = 0,$$

只有一个根$x_0 = -\frac{b}{2a}$，并且它位于区间$(\alpha, \beta)$ if $\alpha < -\frac{b}{2a} < \beta$。

让我们应用刚才提出的信息来解决以下来自口语考试实践的问题。

3. 证明二次三项式

$$f(x) = (x - a)(x - b) + \lambda (x - c)(x - d)$$

如果已知数字 $c, d$ 中的一个恰好位于区间 $(a, b)$ 内，而另一个在其之外，则对于任何实数 $\lambda$ 都有实数根。

观察各种二次三项式的图形，很容易注意到一个重要的性质：二次三项式在线段$[\alpha, \beta]$上的最大值和最小值只能在以下三个点处实现：在点$x = -\frac{b}{2a}$，当然，如果它属于线段$[\alpha, \beta]$；在点$\alpha$；在点 $\beta$（位于线段的末端）。让我们证明一下；我们假设$a > 0$（情况$a < 0$以类似的方式分析）。

让我们从二次三项式中提取完整的平方：

$$f(x) = ax^2 + bx + c = a \left( x + \frac{b}{2a} \right)^2 + c - \frac{b^2}{4a}.$$

使用这种表示法，很容易证明对于$a > 0$，函数$f(x)$在点$x = -\frac{b}{2a}$处的绝对最小值等于$c - \frac{b^2}{4a}$；在间隔 $(-\infty, -\frac{b}{2a})$ 上，它单调杀死，在间隔 $(-\frac{b}{2a}, \infty)$ 上，它单调增加。

*) 自己检查一下$f(\alpha) f(\beta) < 0$是否蕴含$b^2 - 4ac > 0$。
