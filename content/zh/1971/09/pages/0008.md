在位置数字系统中运行的计算机可以说是模仿人用“柱”计数的行为。本质上，所有机器都是从对所见事物的生动模仿开始的：第一批“自行式车辆”有“腿”（图9），第一批飞行器计划用扑翼来制造。未来，更先进的计算机可能会与现代数字系统一起工作。仍然很难说这样的系统应该是什么，但寻找新原则的尝试已经在进行，我们现在将讨论其中之一。

位置数字系统（当在机器中使用时）的缺点是位间连接会延迟操作的执行：要获得任何数字的最终结果，必须先处理前一个（低位）数字。非位置系统（据我们所知，在其他方面不太方便）允许您独立且单独地处理每个“数字”。

表示自然数的一种可能的方式，可以被认为是“非位置数系统”，是残差类系统。在残差类系统中，数字由其除以所选基数系统（“模块”）的余数表示。

当选择一个模型时，$p$除以$p$的不同余数具有从自然序列中连续取出的$p$整数。如果有多个模型，那么起始数字具有表示的可能性就会扩大。

将相应的余数作为数字表示的符号，我们得到一个非位置数系，其数字是每个模块的余数，取决于

效率。每个数字中的数字是不同的余数，小于模数。给定的模块选择的越多，表示的数字范围就越大，余数（给定数字中的数字）的可能值也就越多。同时，这样的数制中的所有数字都是完全相互独立的。

这种系统中的算术运算非常简单。例如，两个数之和除以给定模 $p$ 的余数等于各个项形成的余数之和，如果该和小于 $p$，或 $p$ 小于该和。类似的规则也适用于乘法运算。

以由三个模块$p_1=7, p_2=9, p_3=10$定义的残差类系统为例。本系统中的数字$n$将写成$(a, b, c)$的形式，其中$a, b, c$是$n$除以$p_1, p_2, p_3$的余数的对应关系。这种表示法定义了$0 \leq n \leq 629$范围内的唯一自然数，$a, b, c$的可能值包含在$0 \leq a \leq 6, 0 \leq b \leq 8, 0 \leq c \leq 9$内。例如：

$$5=(5, 5, 5); 20=(6, 2, 0);$$

算术运算：

$$(3, 2, 1)+(1, 4, 4)=(4, 6, 5);$$
$$(2, 5, 3)\times(2, 7, 6)=(4, 8, 8).$$

（在十进制系统中，这个等式对应于相应的一个）

当然，我们根本不声称算术仍然可以应用于创建新计算机（如果只是因为使用该系统很难比较数字，而这对于许多目的来说是必要的）。但这似乎是“抽象”（有点“过时”且相当传统）的理论算术定律与完美机器数学的“数值技术”问题之间联系的一个简单而值得尊敬的例子。
