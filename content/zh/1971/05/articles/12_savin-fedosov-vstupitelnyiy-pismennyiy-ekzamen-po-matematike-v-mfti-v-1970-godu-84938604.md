1970 年 MIPT 数学入学笔试

A. P. 萨文、B. V. 费多索夫

莫斯科物理技术学院数学入学考试中提出的问题一直吸引着教师和学校毕业生的关注，因为这些问题的水平比许多技术大学要高一些。

1970年，MIPT笔试题目的构成发生了一些变化。 1970 年，LET 包含五个问题（添加了一个简单问题），而不是通常提供的四个问题。这一系列任务显然会在未来继续下去。

您可以在已经出版了多个版本的《初等数学问题》文集中了解往年MIPT入学考试的问题。

我想指出的是，MIPT 数学入学考试的难度经常被夸大。事实上，在所有数学和物理考试（口语和笔试）之后，每个地方仍然有几个人的竞争，这一事实不言而喻。

为了让我们能够真正了解1970年数学笔试，我们将详细分析其中一个选项。

问题分析

1. 让我们用$v_1$表示自动扶梯的速度，$L$表示自动扶梯的长度，$v_2$表示乘客的速度。那么问题的条件将写成方程的形式：

$$\frac{L}{v_1 + v_2} = 24,$$

$$\frac{L}{v_2} = 42.$$

让我们变换一下这些方程：

$$\frac{v_1}{L} + \frac{v_2}{L} = \frac{1}{24}, \quad \frac{v_2}{L} = \frac{1}{42}.$$

从最后两个方程我们立即发现

$$\frac{v_1}{L} = \frac{1}{56},$$

所需时间为$\frac{L}{v_1}$，即56秒。

问题的“亮点”在于，从系统D到三个未知数的方程（1）和（2），只需求两个未知数$L$和$v_1$的比值即可。那些想要寻找$L$、$v_1$、$v_2$的申请人自然是做不到这一点。

2. 我们来变换一下这个方程：

$$tg 5x - tg 3x = tg 3x (1 + tg 3x tg 5x),$$

(1)

$$\frac{tg 5x - tg 3x}{1 + tg 3x \cdot tg 5x} = tg 3x.$$

在最后一个变换中，我们将方程（1）两边除以$1 + tg 3x \cdot tg 5x$。在这种情况下，我们可以失去方程（1）的根，即方程$1 + tg 3x tg 5x = 0$的根。对原方程进一步变换，可得

$$tg 2x = tg 3x,$$

在哪里

$$3x = 2x + k\pi \quad (k = 0, \pm 1, \pm 2, \ldots)$$

或者

$$x = k\pi \quad (k = 0, \pm 1, \pm 2, \ldots).$$

让我们检查一下方程 (1) 除以 $1 + tg 3x \cdot tg 5x$ 时是否丢失了任何根。设 $x_1$ 为方程的根

$$1 + tg 3x \cdot tg 5x = 0.$$

然后将$tg 5x_1 = -\frac{1}{tg 3x_1}$代入原方程，可得

$$-\frac{1}{tg 3x_1} - tg 3x_1 = 0$$

或者

$$tg^2 3x_1 = -1$$，这是不可能的。因此，没有失去根。

回答：

$$x = k\pi \quad (k = 0, \pm 1, \pm 2, \ldots).$$

4. 让我们考虑在由平面指示的四面体的截面 (图 2) 中获得的多边形。容易证明四边形 EFGH 和四边形 KLMN 都是直生的。让我们将平面 ABC 和 ACD 的两个角转到平面 (图 3) 上，并用 $x$ 表示线段 EF 的长度，用 $y$ 表示线段 LM 的长度。由于三角形ABC和ACD都是正三角形，并且直角三角形EFGH和KLMN的边分别平行于边AB和CD，因此线段KL成为线段LM的延续，并且线段FG成为线段EF的延续。如果我们用$a$表示四面体的边，那么显然$FG = a - x$和$KL = a - y$。正如您所看到的，梯形 EFLK 和 FGML 具有相同的高度。我们来找到他们吧。梯形 EFLK 的高度 $h$ 等于正三角形 EFC 和 KLC 的高度差，因此

$$h = x \frac{\sqrt{3}}{2} - (a - y) \frac{\sqrt{3}}{2} = \frac{\sqrt{3}}{2} (x + y - a).$$

让我们求出指定梯形的面积。梯形EFLK的面积为

$$\frac{EF + LK}{2} h = \frac{x + a - y}{2} h,$$

梯形FGML的面积等于

$$\frac{FG + ML}{2} h = \frac{a - x + y}{2} h.$$

使用指示区域之间的差异等于$s$的条件，我们得到

$$\frac{x + a - y}{2} h - \frac{a - x + y}{2} h = s$$

或者

$$s = h (x - y);$$

将找到的表达式替换为 $h$，我们得到

$$s = (x - y) (x + y - a) \frac{\sqrt{3}}{2}.$$

5. 让我们将第一个和第三个方程与通知的第二个方程相加。我们得到 $2x^2 + 2y^2 + 8z^2 + 4xy + 8xz + 8yz = 0$

减少 2，我们看到等式左边有一个完整的表达式 $x+y+2z$ 的平方，因此是 $z = -\frac{1}{2}(x+y)$。 (1)

从该系统的第二个方程中减去第三个方程，得到$x^2 + 4xz - y^2 - 8yz = 0$。让我们将找到的值 $z$ (1) $x^2 - 2x(x+y) - y^2 + 4y(x+y) = 0$ 代入其中。

打开括号并引入相似的项后，方程简化为$x^2 - 2xy - 3y^2 = 0$的形式。让我们通过 $y$ 表达 $x$：

$$x = y \pm 2y.$$

所以，要么$x = -y$，要么$x = 3y$。

让我们考虑第一种情况：$x = -y$。从方程（1）我们得到$z = 0$。然后从原系统的第三个方程得出$y^2 = 1$。

从这里我们找到$y$的两个值：$y = 1$或$y = -1$。

因此，对于第一种情况，我们得到两个解决方案：

$$x_1 = -1, y_1 = 1, z_1 = 0;$$

$$x_2 = 1, y_2 = -1, z_2 = 0.$$

让我们考虑第二种情况：$x = 3y$。从相同的方程（1）得出$z = -2y$。将$z$的值代入原系统的第三个方程，我们得到$-7y^2 = 1$。因此，在第二种情况下没有有效的解决方案。

仍然需要检查第一种情况下找到的解是否满足初始系统的方程。事实证明这是真的。因此，已经找到了该系统的两个有效解决方案。
