8. 答案包含解决方案的构建。它们是由于不正确使用替代方法而获得的。从第二个方程找到$x = \varphi(y)$，并将$x$代入第一个方程$\varphi(y)$，我们就离开了系统
$$\begin{cases} f(x, y) = 0, \\ g(x, y) = 0 \end{cases}$$
到系统
$$\begin{cases} f[\varphi(y), y] = 0, \\ f(x, y) = 0. \end{cases}$$
而不是进入系统
$$\begin{cases} f[\varphi(y), y] = 0, \\ x = \varphi(y) \end{cases}$$
（这里$x = \varphi(y)$是等价于方程$g(x, y) = 0$的方程）。换句话说，在从方程的第一次变换中找到$y$后，我们从第一个原始方程中找到$x$，但这应该是从第二个方程中完成的。那么我们就会得到正确的答案：如果$y = 4$，则$x = 5$，如果$y = \frac{112}{5}$，则$x = -\frac{113}{5}$。

9. 如果$a = 1$，则答案不正确。事实上，对于 $a = 1$ 系统采用以下形式
$$\begin{cases} x + y = 1, \\ x + y = 1, \end{cases}$$
尽管它有无限多个解，但仍然不是每对数字都满足它。例如，$x = 3$、$y = 4$对不是系统的解。该系统的解将是数字对$x = t$，$y = 1 - t$，其中$t$是任何实数。

该解的构造是由于代数加法的不小心使用造成的。系统
$$\begin{cases} f(x, y) = 0, \\ g(x, y) = 0 \end{cases}$$
系统是等价的
$$\begin{cases} a_1 f(x, y) + b_1 g(x, y) = 0, \\ a_2 f(x, y) + b_2 g(x, y) = 0, \end{cases}$$
如果$a_1 b_2 \neq a_2 b_1$（证明）。否则，正如我们的例子所示，就有可能诉诸构建的解决方案。不会失去根（为什么？）。
