2. 我们来变换一下这个方程：

$$tg 5x - tg 3x = tg 3x (1 + tg 3x tg 5x),$$

(1)

$$\frac{tg 5x - tg 3x}{1 + tg 3x \cdot tg 5x} = tg 3x.$$

在最后一个变换中，我们将方程（1）两边除以$1 + tg 3x \cdot tg 5x$。在这种情况下，我们可以失去方程（1）的根，即方程$1 + tg 3x tg 5x = 0$的根。对原方程进一步变换，可得

$$tg 2x = tg 3x,$$

在哪里

$$3x = 2x + k\pi \quad (k = 0, \pm 1, \pm 2, \ldots)$$

或者

$$x = k\pi \quad (k = 0, \pm 1, \pm 2, \ldots).$$

让我们检查一下方程 (1) 除以 $1 + tg 3x \cdot tg 5x$ 时是否丢失了任何根。设 $x_1$ 为方程的根

$$1 + tg 3x \cdot tg 5x = 0.$$

然后将$tg 5x_1 = -\frac{1}{tg 3x_1}$代入原方程，可得

$$-\frac{1}{tg 3x_1} - tg 3x_1 = 0$$

或者

$$tg^2 3x_1 = -1$$，这是不可能的。因此，没有失去根。

回答：

$$x = k\pi \quad (k = 0, \pm 1, \pm 2, \ldots).$$
