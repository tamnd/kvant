此时，系统的势能等于倾斜弹簧的势能，即$kx^2/2$，其中$x$是弹簧长度的变化（$x$可以为正值——则弹簧长度$l = l_0 - x$小于$l_0$，也可以为负值——则弹簧长度大于$l_0$）。系统的总能量等于动能和势能之和，即$mv^2 + kx^2/2$。由于系统通过力$F$获得了这种能量，我们可以写成

$$FL = mv^2 + \frac{kx^2}{2}.$$

(*)

$L$ 是弹簧长度达到极限时左侧立方体移动的距离 (图 6)：$L = S + \frac{l_0}{2} - \frac{(l_0 - x)}{2} = S + \frac{x}{2}$（$S$ 是系统质心移动的距离）。

$v$ 杯子的速度等于系统质心的速度。恒定的外力作用在系统上，系统以匀加速$a = F/2m$运动。因此，如果我们用 $t$ 表示从现在开始的时间

图 7.

运动开始，直到弹簧的长度等于$L$，然​​后是$v = at$和$L = \frac{at^2}{2} + \frac{x}{2}$。将这些$v$和$L$的表达式代入方程(*)，我们得到

$$F \left( \frac{at^2}{2} + \frac{x}{2} \right) = ma^2 t^2 + \frac{kx^2}{2}.$$

因此$\frac{F^2 t^2}{4m} + \frac{x}{2} F = \frac{F^2 t^2}{4m} + \frac{kx^2}{2}$或$Fx = kx^2$。因此，$x_1 = 0$，$x_2 = F/k$。

因此，组之间的最小距离为$l_{\min} = l_0 - x_2 = l_0 - \frac{F}{k}$，最大为$l_{\max} = l_0 - x_1 = l_0$。

从 20 米的距离拍摄老虎是很危险的。 1 毫米针孔相机需要多大尺寸才能使照片中的老虎看起来有条纹？虎皮上的条纹之间的距离是20厘米。

暗箱是一个责任之盒。放置在相机中的摄影胶片从被摄物体的每个点接收宽光束（图7）。为了使老虎在照片中呈现条纹，从老虎皮毛上相邻条纹的最近点落下的光线必须不相交。为此，胶片与答案的距离必须为$x$，大于$d/tg\alpha$。

因为

$$tg\alpha = \frac{l/2}{L + x},$$ 然后$x > \frac{2d(L + x)}{l}$。

因此$x > \frac{2dL}{l\left(1 - \frac{2d}{l}\right)}$。 $\frac{2d}{l} \ll 1$，因此，忽略$2d/l$与公式分母1的比较，我们得到$x > \frac{2dL}{l} = 20$厘米。腔室尺寸必须大于 20 厘米。
