结果表中负数的确切数量仅取决于数字 $x_i$ 和 $y_k$ 的奇偶性；在图1上，零与偶数放在一起，一与奇数放在一起。设$x$为$x_i$中奇数的个数； $y$ 是奇数 $y_k$ 的个数（在 图 $x = 5, y = 4$ 上）。那么，很容易计算，表中的负数总数将等于

$$x(100-y)+(100-x)y = 100x+100y-2xy,$$

其中 $x, y$ 是整数。

现在让我们回到我们的问题并证明答案是否定的，即不可能得到 1970 的负值。假设我们成功获得了 1970 个负值。那么$1970 = 100x+100y-2xy$，从哪里

$$xy - 50x - 50y + 2500 = 1515.$$

对左侧进行因式分解，我们得到

$$(x-50)(y-50) = 1515 = 15 \cdot 101.$$

我们有

$$-50 \leq x-50 \leq 50, -50 \leq y-50 \leq 50.$$

由于 101 是质数，因此 $x-50$ 或 $y-50$ 可以被 101 整除（毕竟，它们的乘积可以被 101 整除）。但根据前面的不等式，可以得出 $x-50$ 或 $y-50$ 等于 0。因此，我们有一个矛盾，证明恰好 1970 分钟获得不可能。

正确的解决方案是由 D. Grigoriev 发送的。

$$S_n > \frac{n}{2} (\log_2 n - 4)$$

对于任意$n$。

我们主要遵循列宁格勒的 D. Grigoriev 的决定。该解基于一个非常简单的考虑：$2^n$不能被1以外的奇数整除，这意味着$2^n$除以这样一个数字的余数不小于1。从这里很容易推导出，对于任何奇数$k > 1$，$2^n$除以$2^l k$的余数不小于$2^l$。事实上，让$2^{n-l}$除以$k$的余数等于$r$，即$2^{n-l} = mk + r$，其中$0 \leq r < k$，然后$2^n = m(2^l k) + 2^l r$，其中$0 \leq 2^l r < 2^l k$，即$2^n$除以$2^l k$的余数等于$2^l r$，又因为$r \neq 0$，那么这个余数不小于$2^l$。
