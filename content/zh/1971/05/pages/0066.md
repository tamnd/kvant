我们只需要解析几何中的一个事实：如果线段的两端有坐标 $(a_1, b_1)$ 和 $(a_2, b_2)$，则该线段的中间有坐标
$$\left(\frac{a_1 + a_2}{2}, \frac{b_1 + b_2}{2}\right).$$

让 Petya 在点 $(a, b)$ 转到舞台，然后在点 $(c, d)$ - 到露西的家，在点 $(e, f)$ - 到商店，在点 $(a_1, b_1)$ - 再次到舞台。让我们找到所有这些点的坐标，这些点是连接最后一个转折点与正方形相应顶点的线段的中点
$$c = \frac{a}{2}, d = \frac{b + 1}{2}, e = \frac{a}{4},$$
$$f = \frac{b + 1}{4};$$
$$a_1 = \frac{1}{2}\left(\frac{a}{4} + 1\right) = \frac{1}{8}(a + 4)$$
$$q_1 = \frac{1}{2}\left(\frac{b + 1}{4} + 1\right) = \frac{1}{8}(b + 5)$$
然后检查一下
$$a_1 - \frac{4}{7} = \frac{1}{8}(a - \frac{4}{7}),$$
$$b_1 - \frac{5}{7} = \frac{1}{8}(b - \frac{5}{7}).$$

这样，从转折点到舞台到点（4/7，5/7）的距离就形成了几何级数，并且在舞台-露西的房子-商店的方向上每“一圈”就减少8倍。这意味着 Petya 正在接近一个带有顶点坐标的三角形
$$\left(\frac{4}{7}, \frac{5}{7}\right), \left(\frac{2}{7}, \frac{6}{7}\right), \left(\frac{1}{7}, \frac{3}{7}\right)$$
