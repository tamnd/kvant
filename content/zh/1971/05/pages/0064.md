点$B$，其坐标为$(n, n^2)$。让我们定义$m < n$。让我们将点 $A$ 和 $B$ 的垂线放到横坐标轴上，并通过点 $A$ 画一条与该轴平行的直线。显然，$EF = CN = m^2$，因此$BC = BN - CN = n^2 - m^2$。三角形$ADE$和$ABC$相似，相似系数为

$$\frac{AE}{AC} = \frac{AE}{AE + EC} = \frac{m}{m + n}.$$

因此，

$$DE = \frac{m}{m + n} BC = \frac{m}{m + n} (n^2 - m^2) = m (n - m) = mn - m^2.$$

从这里

$$DF = DE + EF = (mn - m^2) + m^2 = mn.$$

情况$m > n$的处理方式类似。案例$m = n$非常相似。

抛物线 $y = ax^2$ 列线图的分析论证。通过点 $\left(-\frac{m}{\sqrt{a}}, m^2\right)$ 和 $\left(\frac{n}{\sqrt{a}}, n^2\right)$ 的直线由方程给出（在 $m + n \neq 0$）

$$y = m^2 \frac{x - \frac{n}{\sqrt{a}}}{-m - \frac{n}{\sqrt{a}}} + n^2 \frac{x - \frac{-m}{\sqrt{a}}}{n - \frac{-m}{\sqrt{a}}} = \frac{m^2 n + n^2 m}{m + n} = mn$$

它与纵坐标轴相交于点

$$y = m^2 \frac{\frac{-n}{\sqrt{a}}}{-m - \frac{n}{\sqrt{a}}} + n^2 \frac{\frac{-m}{\sqrt{a}}}{n - \frac{-m}{\sqrt{a}}} = \frac{m^2 n + n^2 m}{m + n} = mn$$

阅读“我们失去或找到什么？”一文。

1. 答案包含构造根，例如$x = 5\pi/6$；有些解丢失了，例如$x = 2\pi/3$。这一切都是表达式$\sqrt{4\sin^2 2x}$错误转换的结果。根据算术根的定义，

$$\sqrt{4\sin^2 2x} = 2|\sin 2x|$$

正确答案是$x = n\pi/2$和$x = \frac{\pi}{6} + \frac{n\pi}{2}$。

2. 答案包含根的构建。它们是通过将方程的所有部分乘以函数 $\sin x$ 得到的。方程 $\sin 8x = \sin x$ 的解显然也是 $x$，其中 $\sin x = 0$，而对于原始方程，如 $x$ 不是解（检查）。乘以函数也可能导致根丢失，因为这可能导致 OD3 干燥（举个例子！）。在此示例中，它没有这样做，因为函数 $\sin x$ 已明确定义。

正确答案是：$x = n\pi/9$，其中$n$是不是 9 的倍数的任何奇数，以及$x = m\pi/7$，其中$m$是不是 7 的倍数的任何奇数。

3. 发现的根是postronium。如果 $m = x$ 和数字 $m$ 满足不等式：$0 \leq m \leq \pi$，则使用数字 $x$ 的反余弦是不正确的。在这个例子中，$m = 5\pi/2 + 10k\pi$和$k$不满足这个不等式，那么根据arckosi$x$的定义，arckosi方程$x = 5\pi/2 + 10k\pi$无解。

4. OD3 查找错误。还需要要求对数$x - 1$的底不等于1，那么$x = 2$不包含在OD3*)中。

5. 词根$x = 0$是构造。它是通过在变换后的方程中将表示原方程左侧的表达式替换为其右侧而得到的。这样的转变，不可能导致断根。事实上，例 5 的“解”中的最后一个方程是原始方程的结果；如果满足原方程，则满足最后一个方程。正如本例所示，反之则不然。

6. 答案很奇怪。事实上，让$c = -1$，$a = -2$，$c = 2$，$b = c^2 = 1$。那么方程的形式为

$$\sqrt{x + 2\sqrt{x} + 1} + \sqrt{x} = -1$$

并且答案问题根本没有解（其左侧对于任何可接受的$x$都是正数）。接下来，让$c = 1$，$a = -2$，$b = 1$。那么方程的形式为

$$\sqrt{x - 2\sqrt{x} + 1} + \sqrt{x} = 1$$

例如，数字$x = 4$，又是一个需要回答的问题，不是一个解决方案。事实是，当“用平方法”求解时，得到的方程并不等于给定的方程，而是它的结果。必须检查收到的答复。

考试。将参数值代入方程，我们得到

$$\sqrt{x - 2c\sqrt{x} + c^2} = c - \sqrt{x}$$

或者

$$\sqrt{(\sqrt{x} - c)^2} = c - \sqrt{x}$$

从这里

$$|V\bar{x} - c| = c - \sqrt{x}$$
