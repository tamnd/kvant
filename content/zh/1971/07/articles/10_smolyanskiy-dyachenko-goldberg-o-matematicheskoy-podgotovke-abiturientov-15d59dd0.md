关于申请人的数学准备

1970年12月22日，在莫斯科钢铁及合金学院，院长办公室会同高等数学系召开莫斯科各中学数学教师会议，讨论技校申请者的数学训练问题。

负责人作了《关于申请者数学训练要求水平》的联合报告。高等数学系，I. E. Bazilevich教授和M. A. Akivis教授。报告指出，在大学学习高等数学课程时，特别经常使用学校数学课程的以下部分：代数和三角表达式的变换、函数及其图形的基本元素的性质、各类方程、等式和方程组或不等式组的解、实数绝对值和算术根的概念、几何基本定理和公式等。

然而，正是这些部分的例子，许多申请者和一年级学生都掌握不好。演讲者强调，许多申请人不知道如何正确、有效地格式化他们的作品，这与无法清晰和一致地思考有关。

报告最后制定了一些规定，实施后有利于提高申请者的数学训练水平：

a) 在整个中学数学教学中，应注意课程的逻辑有效性和连贯性；学生必须能够正确思考、推理并正确表述自己的想法；

b）在求解各种方程和不等式时，应使用可接受值区域的概念，并教会学生在某些变换过程中监控该区域的变化；

b) 应特别关注代数和三角表达式的技术要求；你应该被要求填写代数、三角学和几何的基本公式；

d) 应添加函数主要元素的属性和图形的实心值；求解方程和不等式时应使用这些属性；

d) 在解决几何问题时，学生必须能够正确绘图并对所有的构造和计算进行清晰的论证；

e) 目前学校的数学课程不包含一些在大学学习数学课程时需要了解的主题。其中包括连接理论、牛顿生物群落、贝佐特定理和二值方程的解。这些主题应包含在数学选修课中。此外，在这些课程中，您应该比程序提供的更深入地学习复数和反三角函数。

V.V.副教授的报告戈德堡强调了申请者在入学考试中最常犯的错误。

申请人的工作中，最多的错误发生在求解指数和对数方程，尤其是不等式时；含有绝对值符号下的未知数的方程和不等式；当写出对应于给定三角函数值的角度的一般形式时，尤其是在求解最简单的三角不等式时；当构造最简单的超越函数的图时。

经常会遇到逻辑性质的错误，尤其是在几何课程中：经常从定理到定理，从逆向定理到直接定理；将某些特定函数类别的属性转移到更一般的类别（据信中位数总是与平分线或三角形的高度等重合）；不懂数学归纳法；不认为需要证明某些函数的性质（三角函数、指数函数、对数函数）。

书面作品的扁平化设计再次引起了许多申请人的注意。当写下问题的解决方案时，没有逻辑顺序；遗漏了许多必要的论证（尤其是几何学方面的论证）。

演讲者指出了1970年申请人在解决书面作业时所犯的一些具体错误。

求解无理方程时

$$\sqrt[3]{x+1} + \sqrt[3]{3x+1} = \sqrt[3]{x-1}$$

许多申请者在立方后，将$$\sqrt[3]{x+1} + \sqrt[3]{3x+1}$$替换为$$\sqrt[3]{x-1}$$，从而得到构造根（$x=0$）。

在解决不平等问题时，通常会进行一些转换来构建解决方案。这些

通过核查很难放弃无关的决定，因为它们可以填补整个空白。

所以，解决不等式

$$x > \sqrt{2x+24}$$

通过平方，许多人得到了答案$x > 6$，$-12 < x < -4$，而没有替换第二个区间中的所有值$x$不满足这个不等式（如果注意到不等式$x > 0$是从条件得出的，这不会是偶然的）。求解不等式时

$$\left(x^2+x+1\right)^{\frac{x+5}{x+2}} \geq \left(x^2+x+1\right)^3$$

许多人正确地看到有必要考虑$x^2+x+1 > 1$和$0 < x^2+x+1 < 1$的情况，但他们忘记了，由于不等式并不严格，它的解不会是值$x$，对于$x^2+x+1=1$，即$x=0$和$x=-1$。

无法正确操作绝对值和根参数导致了许多错误。因此，例如，求解方程

$$\sqrt{1+\sin 2x} = \sqrt{2} \cos 3x,$$

在哪里

$$\pi < x < \frac{3}{2} \pi,$$

写了很多

$$\sqrt{1+\sin 2x} = \sin x + \cos x$$

而不是正确的

$$\sqrt{1+\sin 2x} = |\sin x + \cos x| = -\sin x - \cos x,$$

从$\pi < x < \frac{3}{2} \pi$开始。

简化表达式时

$$\left(a+x\right)^{\frac{1}{2}} - \frac{1}{2} + \left(a-x\right)^{\frac{1}{2}} - \frac{1}{2}$$

在 $x=4$ ($a-1$), $1 < a < 2$ 处，我们必须转换表达式 $\sqrt{(a-2)^2}$。

很多人写了
$$\sqrt{(a-2)^2} = a - 2$$
而不是正确的
$$\sqrt{(a-2)^2} = |a-2| = 2-a,$$
从$1 < a < 2$开始。
求解三角方程的主要缺点是三角公式的平坦值以及无法求解最简单的三角方程。
解方程
$$\frac{1 + tg x + \dots + tg^n x + \dots}{1 - tg x + \dots + (-1)^n tg^n x + \dots} = 1 + \sin 2x,$$
有些申请人甚至不知道如何处理这个等式的左边。那些看到两个无限递减几何级数的人正确地写道，如果 $|tg x| < 1$，即 $-\frac{\pi}{4} + k\pi < x < \frac{\pi}{4} + k\pi$，左边是有意义的，但是，在解出方程后，他们留下了两个系列的解：
$$x_1 = k\pi \text{ и } x_2 = -\frac{\pi}{4} + k\pi.$$
方程
$$3tg2x - 4tg3x = tg^23xtg2x$$
许多人通过用 $tgx$ 表示 $tg2x$ 和 $tg3x$ 来非理性地解决这个问题，从而得到 $tgx$ 的复杂代数方程。实现目标最快的方法也是转型：
$$3(tg2x - tg3x) = tg3x(1 + tg2xtg3x),$$
并且，由于 OD3 $1 + tg2xtg3x \neq 0,$
$$3\frac{tg2x - tg3x}{1 + tg2xtg3x} = tg3x,$$
或$-3tgx = tg3x.$

求解方程时
$$8\cos^4x = 3 + 5\cos 4x$$
一些申请人得出了 $cos x$ 的四次方程，但他们未能解决。如果我们将该方程简化为关于 $y = \cos 2x$ 的代数方程，这就不会是偶然的。
该解产生一个二次方程
$$2y^2 - y - 1 = 0.$$
在解决几何问题时，除了上述逻辑错误外，演讲者还指出了绘图的文盲（错误地绘制了圆锥体的主要部分，放置了一个球 - 关于这个问题，请参阅我们杂志 1970 年第 12 期 N.M. Beskin 的文章），不了解等边或面的参数的属性，无法用参数的相邻侧面之间的角度的两个角度构造线性角。或者找到球的内接参数和外接参数的中心。当数据是非线性元素（面积、体积）或某些元素之间存在对应关系（腿的总和、横向与总表面的比率等）时，申请人会遇到很大的困难。
会议最后，莫斯科数学会二级尺度分会科学秘书A. Ya。 Margulis 和教师发展研究所的高级数学方法学家 S. M. Gul 代表教师发言，教师部分指出了此类会议的绝对有用性，并希望将来能举行类似的会议。
