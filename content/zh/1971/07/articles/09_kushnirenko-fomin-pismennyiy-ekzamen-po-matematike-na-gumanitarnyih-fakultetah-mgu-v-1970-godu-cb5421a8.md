问题解决方案

1. 答：第一艘皮划艇在 230 秒内行驶了 1 公里。

2. 首先，我们证明对于$0,5 < x < 2,5$，不等式$3x - x^2 > 1$成立。确实，$3x - x^2 = \frac{9}{4} - \left( x - \frac{3}{2} \right)^2$，但在我们的限制下$\left( x - \frac{3}{2} \right)^2 < 1$，因此，$3x - x^2 > \frac{5}{4} > 1$。由于对数的底大于 1，因此不等式可以重写为 $3x - x^2 > 3a - ax$ 或

$$x (3 - x) > a (3 - x).$$

(*)

我们必须找到区间 $0,5 < x < 2,5$ 中的所有 $x$，它们是区间 $0 < a < 2$ 中所有 $a$ 的不等式 (*) 的解。对于区间 $0,5 < x < 2,5$ 中的任何 $x$，不等式 $3 - x > 0$ 成立，因此不等式 (*) 等价于不等式 $x > a$。

对于区间$0 < a < 2$中的所有$a$，所有$x \geq 2$都满足不等式$x > a$；考虑到不等式$0,5 < x < 2,5$，我们得到答案：$2 \leq x < 2,5$。

3. $1 + \cos x + \cos 2x = \sin x + \sin 2x + \sin 3x$,

$$\cos x (1 + 2 \cos x) = \sin 2x (1 + 2 \cos x), \quad \cos x (1 + 2 \cos x) (1 - 2 \sin x) = 0.$$

最后一个方程与原来的方程是等价的。我们将解决它并检查每个系列答案的条件$\frac{\pi}{2} < |3x - \frac{\pi}{2}| \leq \pi$。

一、$\cos x = 0$，$x = \frac{\pi}{2} + \pi k$。因此$\left| 3x - \frac{\pi}{2} \right| = \left| 3 \frac{\pi}{2} + 3\pi k - \frac{\pi}{2} \right| = |(3k + 1)\pi|$。对于$k = 0$$\left| 3x - \frac{\pi}{2} \right| = \pi$，也就是说，我们的条件是$\left(\frac{\pi}{2} < \pi \leq \pi\right)$，因此，$x = \frac{\pi}{2} + \pi \cdot 0 = \frac{\pi}{2}$就是问题的答案。如果$k \neq 0$，那么，很容易看出，$|(3k + 1)\pi| \geq 2\pi$，并且从$\frac{\pi}{2} + k\pi$形式的根系列中，只有$x = \frac{\pi}{2}$满足我们的条件。

二. $1 + 2\cos x = 0$、$\cos x = -\frac{1}{2}$、$x = \pm \frac{2\pi}{3} + 2k\pi$。因此$\left| 3x - \frac{\pi}{2} \right| = \left| \pm 2\pi + 6k\pi - \frac{\pi}{2} \right| = |(3k \pm 1)2\pi - \frac{\pi}{2}|$。

对于任何 $k$，最后一个表达式太大：

a) $k = 0$, $\left| (3k \pm 1)2\pi - \frac{\pi}{2} \right| = \left| \pm 2\pi - \frac{\pi}{2} \right| \geq \frac{3\pi}{2}$;

b) $k \neq 0$, $\left| (3k \pm 1)2\pi - \frac{\pi}{2} \right| \geq |(3k \pm 1)2\pi| - \left| \frac{\pi}{2} \right| \geq 4\pi - \frac{\pi}{2} = \frac{7}{2}\pi$.

三． 1 - 2 罪$x = 0$； a）$x = \frac{\pi}{6} + 2k\pi$； b) $x = \frac{5\pi}{6} + 2k\pi$。

a）$|3x - \frac{\pi}{2}| = |\frac{\pi}{2} + 6k\pi - \frac{\pi}{2}| = |6k\pi|$。若$k = 0$，则$|3x - \frac{\pi}{2}| = 0 < \frac{\pi}{2}$；如果$k \neq 0$，则$|3x - \frac{\pi}{2}| \geq |6\pi| > \pi$。

因此，方程 $\sin x = \frac{1}{2}$ 的解均不满足条件。答案：$x = \frac{\pi}{2}$。

7. 请注意，每种方法完全由 15 戈比硬币的数量决定。让我们看看这个数字可能是多少。由于总金额（496 戈比）是偶数，并且由 2 戈比硬币组成的任何金额也是偶数，因此 15 戈比硬币的数量也一定是偶数。另外，这个数字是非负数并且不会太大，因为无论以何种方式，15戈比硬币组成的数量都是非负数并且不超过496，即$0 \leq 2n \cdot 15 \leq 496$。很容易看出，15 戈比硬币没有其他数字：如果我们用偶数个 15 戈比硬币凑出不超过 496 戈比的任何金额，那么用 2 戈比硬币总能凑出不足的金额（偶数）。仍然需要解决整数不等式 $0 \leq 2n \cdot 15 \leq 496$ 或 $0 \leq n \leq 16 \frac{16}{30}$。显然，这个不等式有 17 个整数解：$n = 0, 1, 2, \dots, 16$。

答案：17种方式。

问题解决方案

1. 根据问题的条件，轮船是相同的，也就是说轮船在静水中的速度是相同的。让我们用 $v$ ($\kappa m/\mu$) 表示该速度。让我们用$v_0$（$\kappa m/\mu$）表示河流的速度，用$S$（$\kappa m$）表示$A$和$B$之间的距离。下面我们将以小时为单位测量时间，并省略所有数量的维度。比较船舶从出发时刻到回程相遇时刻（包括停泊）所花费的时间，我们组成一个由三个未知数方程组成的系统：

$$\begin{align*}
\frac{S}{v + v_0} + \frac{\frac{2S}{3}}{v - v_0} &= \frac{S}{v - v_0} + \frac{\frac{S}{3}}{v + v_0}, \\
\frac{S}{v + v_0} + \frac{S - 20}{v - v_0} + 1 &= \frac{S}{v - v_0} + \frac{20}{v + v_0}, \\
\frac{S}{v + v_0} + \frac{\frac{2S}{3} + 5}{v - v_0} &= \frac{S}{v - v_0} + \frac{\frac{S}{3} - 5}{v + v_0} + \frac{1}{2}.
\end{align*}$$

从第一个方程我们发现$v = 3v_0$，从第一个和第三个方程我们发现：$v_0 = 7,5$； $v = 22,5$。将这些值$v$和$v_0$代入第二个方程，我们找到$S = 30$，即$AK = 10$。这意味着第二艘轮船在$\frac{10}{30} = \frac{1}{3}$小时内从$A$到达$K$。答：河水流速为7.5$\kappa m/\mu$，第二艘船从$A$到$K$需要20分钟。

2. 不难证明原方程是二次方程。学校教科书中讨论了这种类型的方程。让我们输入$x^4 = t$。那么方程将被重写为$t^2 + at + 1 = 0$。令 $t_1$ 和 $t_2$ 为该方程的实根。很容易看出$t_1$和$t_2$一定是正数且不同。为了定义方便，假设$0 < t_1 < t_2$。那么原方程有以下根（按升序排列）：$x_1 = -\sqrt[4]{t_2}$、$x_2 = -\sqrt[4]{t_1}$、$x_3 = \sqrt[4]{t_1}$、$x_4 = \sqrt[4]{t_2}$。

这四个根要形成算术级数，$x_2-x_1=x_3-x_2=x_4-x_3$或$\sqrt[4]{t_2}-\sqrt[4]{t_1}=2\sqrt[4]{t_1}=\sqrt[4]{t_2}-\sqrt[4]{t_1}$即$2\sqrt[4]{t_1}=\sqrt[4]{t_2}-\sqrt[4]{t_1}, 3\sqrt[4]{t_1}=\sqrt[4]{t_2}, 81t_1=t_2$是充分必要的。

现在让我们使用维埃塔定理。如果$81t_1=t_2$，则$81t_1^2=t_1\cdot t_2$。

但根据维埃塔定理$t_1t_2=1$，因此$81t_1^2=1, t_1=\pm\frac{1}{9}, t_2=\pm9$。但我们要求$t_1$和$t_2$为正，所以$t_1=\frac{1}{9}, t_2=9$。因此，找到的$t_1$和$t_2$的值是唯一可能的。我们看看对于$a$的某些值是否可以得到这样的根。再次，根据 Vieta 定理，找到 $a=-(t_1+t_2)=-9\frac{1}{9}$。但有一个与维塔定理相反的定理，即如果$x_1x_2=q$和$x_1+x_2=-p$，则数字$x_1$和$x_2$是方程$x^2+px+q=0$的根。这意味着数字$\frac{1}{9}$和$9$确实是方程$t^2-\left(\frac{1}{9}+9\right)t+\frac{1}{9}\cdot 9=0$的根。

答案：$a=-9\frac{1}{9}$。
