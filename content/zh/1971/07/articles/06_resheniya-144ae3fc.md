M39

证明非负整数$x, y$满足方程$x^2 - mxy + y^2 = 1$（其中$m$是大于一的给定整数）当且仅当$x$和$y$是序列$\varphi_0 = 0, \varphi_1 = 1, \varphi_2 = m, \varphi_3 = m^2 - 1, \varphi_4 = m^3 - 2m, \varphi_5 = m^4 - 3m^2 + 1$，...的相邻项，其中$\varphi_{k+1} = m\varphi_k - \varphi_{k-1}$对于所有$k \ge 1$。

例如，方程的所有解

$$x^2 - 3xy + y^2 = 1$$

(1)

整数 $(x, y)$, $0 \leq x < y$ 是对

$$(0, 1), (1, 3), (3, 8), (8, 21), \dots$$

(2)

对于所有$k \ge 1$，由条件$\varphi_0 = 0, \varphi_1 = 1, \varphi_{k+1} = 3\varphi_k - \varphi_{k-1}$定义的序列$0, 1, 3, 8, 21, \dots$的相邻项。

让我们针对 $m = 3$ 求解此问题（对于其他 $m > 1$，解法类似。）我们必须证明，首先，所有数对 (2) 都满足方程 (1)，其次，没有其他非负数对满足该方程。 （请注意，解决方案的第二个也是更困难的部分在很大程度上被发信的读者忽视了。）

在序列(2)中，每对$(x, y)$后面跟着一对$(x_1, y_1)$，可以使用以下变换从$(x, y)$获得：

$$x_1 = y, y_1 = 3y - x.$$

(3)

我们用字母 $T$ 表示这个变换 $(x, y) \rightarrow (y, 3y - x)$。不难

检查如果对 $(x, y)$ 满足方程 (1)，则对 $(x_1, y_1) = T(x, y)$ 也满足它：

$$x_1^2 - 3x_1y_1 + y_1^2 = y^2 - 3y(3y - x) + (3y - x)^2 = y^2 - 3xy + x^2.$$

(4)

从这里可以立即清楚地看出，所有对（2）都满足方程（1）：毕竟，对（0, 1）满足它，并且所有其他对都是使用有限变换数$T$从它获得的。

现在让我们证明，在满足方程（1）的条件$0 \leq x < y$的情况下，整数中不存在其他解$(x, y)$。让 $(x_1, y_1)$ 成为这样的解决方案之一。让我们找到一对$(x, y)$，使用公式（3）从中获得$x_1$和$y_1$ - 为此，用$x_1$和$y_1$来表达$x$和$y$就足够了：

$$x = 3x_1 - y_1, y = x_1.$$

(5)

我们将用 $T^{-1}$ 来表示从 $(x_1, y_1)$ 到 $(x, y)$ 的转变（逆变换 *) 到 $T$。由等式（4）可知，如果$(x_1, y_1)$满足等式（1），则$(x, y) = T(x_1, y_1)$也满足。让我们证明，如果此外还有 $0 < x_1 < y_1$，那么

$$0 \leq x < y.$$

(6)

让我们用两种方式表示以下的等式 $x_1^2 - 3x_1y_1 + y_1^2 = 1$：

$$x_1^2 + y_1(y_1 - 3x_1) = 1,$$

$$x_1(x_1 - y_1) + y_1(y_1 - 2x_1) = 1.$$

(7)

从等式（7）可以立即得出（$x_1$和$y_1$为正！）$-x = y_1 - 3x_1 \leq 0$，如果$y_1 - 3x_1 = 0$，则$x_1 = 1$和$y_1 = 3$。反过来，从等式 (8) 可以得出 $y - x = y_1 - 2x_1 > 0$（毕竟，$x_1 - y_1$ 是负数）。不等式(6)已被证明。请注意，它们可以像这样重写：

$$0 \leq x < x_1,$$

(9)

从$x_1 = y$开始。因此，任何解$(x_1, y_1)$、$0 < x_1 < y_1$，在变换$T^{-1}$之后都会进入解$(x, y)$，其中$0 \leq x < y$。如果同时$x > 0$，那么我们可以应用$T^{-1}$一次或多次，获得新的（幅度更小的）解决方案。事实上，如（9）所示，整数$x$的大小随着每次变换而减小。因此，经过一定的有限步数后，我们必须停止，并且只有当我们获得解$(x, y)$时才能停止，该解有$x = 0$，因此有$y = 1$。因此，我们已经证明，对于有限数变换 $T^{-1}$，从每个解$(x_1, y_1)$ 都可以获得一个解 (0, 1)。由此可见，(0, 1) 中的每个解都经过有限数 $T$ 变换（即不存在与 (2) 不同的其他解。问题完全解决。

该解决方案可以更清楚地呈现如下。我们将像往常一样将一对数字 $(x, y)$ 表示为平面上的一个点。然后方程 $x^2 - 3xy + y^2 = 1$ 定义了平面上的一条曲线，称为“sperbola”。 （封面上有一整套双曲线，由方程 $x^2 - 3xy + y^2 = c$ 给出，参数 $c$ 的值不同，我们感兴趣的是黄色。）用整数解这个方程意味着用整数坐标表示双曲线上的所有点。然而，这样的点很容易指示：它是一个坐标为(0, 1)的黑点。正如我们所证明的，所有其余的（在角度$0 \leq x < y$内）都是通过连续应用变换$T : (x, y) \rightarrow (y, 3y - x)$从中获得的。 $T$平面的变换具有以下性质：

1) 将平面中的每条直线变换回直线（此类变换称为线性变换）。

M41

给定一个圆，它的直径 $AB$ 以及该直径上的一个点 $C$。在圆上构造两个点 $X$ 和 $Y$，相对于直径 $AB$ 对称，其中线 $YC$ 垂直于线 $XA$。

设$K$为线段$XY$和$AB$的交点；根据条件$XY \perp AB$和$XK = KY$。对于圆$\Rightarrow AXB = 90^\circ$上的任意点$X$。因此，要求$YC \perp AX$相当于以下每个条件：

$$YC \parallel BX, \Rightarrow YCB = \Rightarrow CBX,$$

$$\triangle CYK = \triangle KBX, \quad CK = KB.$$

这样，如果我们使用线段$CB$中间的$AB$垂线，我们就可以在其与圆的交点处得到所需的两个点（其中任意一个可以作为$X$，那么另一个就起到$Y$的作用）。

M42

一些十七位数字的数字以相反的顺序书写。结果数字被添加到原始数字中。证明它们的和至少有一位数字是偶数。

让我们通过 $n$ 证明该陈述对于任何 $(4n+1)$ 位数字都成立。在 $n=0$ 时，这是显而易见的。假设对于某些 $n$ 是假的，即存在一个数 $a_1 a_2 a_3 \dots a_{4n-1} a_{4n} a_{4n+1}$ 使得总共

$$\frac{a_1}{a_{4n+1}} + \frac{a_2}{a_{4n}} + \dots + \frac{a_{4n-1}}{a_{4n}} + \frac{a_{4n+1}}{a_{4n}}$$

所有数字都是奇数。那么$a_1 + a_{4n+1}$的数字之和是奇数，并且在箭头指示的位置将不会将单位转移到下一个数字。因此，在 $(4n-3)$ 位数字的总和中

$$\frac{a_3 \dots a_{4n-1}}{a_{4n-1} \dots a_3}$$

此外，所有数字都是奇数，因此，我们的陈述对于 $(n-1)$ 不成立。证明已经完成（想想为什么通常的“指示步骤”——“如果$n$为真，那么$(n+1)$为真”——可以用相反方向的步骤来代替：“如果$n$为假，那么$(n-1)$为假”！）。

请注意，已证明的陈述不能简化：对于位数为偶数或具有 $(4n+3)$ 形式的数字，问题的陈述可能不正确：

$$11 \ 112 \ 222 + 22 \ 221 \ 111 = 33 \ 333 \ 333, \ 72 \ 727 \ 262 \ 626 + 62 \ 626 \ 272 \ 727 = 135 \ 353 \ 535 \ 353.$$

M45

证明从任意 200 个整数中，您可以选择 100 个其总和可被 100 整除的整数。

尝试概括这个问题：证明从任何 $2n-1$ 整数中，我们可以选择 $n$，其总和可被 $n$整除，其中 $n \geqslant 2$。

引理。如果问题的陈述对于 $n = a$ 和 $n = b$ 成立，那么对于 $n = ab$ 也成立。

请注意，属性“整数$x_1, \ldots, x_n$的和$n$可被$n$整除”也可以表述为：“算术平均值$\frac{x_1 + \ldots + x_n}{n}$是一个整数。”

因此，给定任意 $2ab-1$ 整数。由于该陈述对于$n = b$和$2ab-1>2b-1$成立，因此从给定的$2ab-1$数字中我们可以选择$b$，其总和可被$b$整除。然后从剩余的数中（如果至少有$2b-1$）我们选择另一个具有此属性的$b$数，依此类推。

自从
$$2ab-1 = (2a-1)b + (b-1),$$
则重复此操作$2a-1$次，得到$2a-1$组$b$个数，其中$b$个数的算术平均值为整数。由于该陈述对于$n = a$成立，因此从这些$2a-1$算术意味着我们可以选择$a$，其总和可被$a$整除。很明显，构成相应 $a$ $b$ 数字集合的 $ab$ 数字都具有所需的属性：它们的总和可被 $ab$ 整除。引理已被证明（该引理以及问题是由 Yu. I. Nonin 发明的）。

因此，为了证明问题的陈述具有任意性$n = a_1a_2\ldots a_k$，只需证明单个因素$n = a_1$，$n = a_2$，...，$n = a_k$（并多次应用引理）即可。因此，了解如何证明数字 $n$ 的质因数的这个命题就足够了。例如，要证明$n = 100$，只需证明两个陈述即可：“从任意3个整数中选择2个其总和可被2整除”和“从任意9个整数中选择5个其总和可被5整除”。第一个是显而易见的，第二个可以通过不太长的搜索来证明。我们为读者提供了验证这一点的机会，并尝试提出一个立即适合任何简单 $n$ 的证明。不过，我们将在下一期期刊中提供此类证据。

由于万有引力相对于人的质心的力矩为零，只有当力$\vec{F}_p$通过人的质心时，人才会保持平衡，不会“翻倒”。
