⟦folio 58⟧

申请人的工作中，最多的错误发生在求解指数和对数方程，尤其是不等式时；含有绝对值符号下的未知数的方程和不等式；当写出对应于给定三角函数值的角度的一般形式时，尤其是在求解最简单的三角不等式时；当构造最简单的超越函数的图时。

经常会遇到逻辑性质的错误，尤其是在几何课程中：经常从定理到定理，从逆向定理到直接定理；将某些特定函数类别的属性转移到更一般的类别（据信中位数总是与平分线或三角形的高度等重合）；不懂数学归纳法；不认为需要证明某些函数的性质（三角函数、指数函数、对数函数）。

书面作品的扁平化设计再次引起了许多申请人的注意。当写下问题的解决方案时，没有逻辑顺序；遗漏了许多必要的论证（尤其是几何学方面的论证）。

演讲者指出了1970年申请人在解决书面作业时所犯的一些具体错误。

求解无理方程时

$$\sqrt[3]{x+1} + \sqrt[3]{3x+1} = \sqrt[3]{x-1}$$

许多申请者在立方后，将$$\sqrt[3]{x+1} + \sqrt[3]{3x+1}$$替换为$$\sqrt[3]{x-1}$$，从而得到构造根（$x=0$）。

在解决不平等问题时，通常会进行一些转换来构建解决方案。这些

通过核查很难放弃无关的决定，因为它们可以填补整个空白。

所以，解决不等式

$$x > \sqrt{2x+24}$$

通过平方，许多人得到了答案$x > 6$，$-12 < x < -4$，而没有替换第二个区间中的所有值$x$不满足这个不等式（如果注意到不等式$x > 0$是从条件得出的，这不会是偶然的）。求解不等式时

$$\left(x^2+x+1\right)^{\frac{x+5}{x+2}} \geq \left(x^2+x+1\right)^3$$

许多人正确地看到有必要考虑$x^2+x+1 > 1$和$0 < x^2+x+1 < 1$的情况，但他们忘记了，由于不等式并不严格，它的解不会是值$x$，对于$x^2+x+1=1$，即$x=0$和$x=-1$。

无法正确操作绝对值和根参数导致了许多错误。因此，例如，求解方程

$$\sqrt{1+\sin 2x} = \sqrt{2} \cos 3x,$$

在哪里

$$\pi < x < \frac{3}{2} \pi,$$

写了很多

$$\sqrt{1+\sin 2x} = \sin x + \cos x$$

而不是正确的

$$\sqrt{1+\sin 2x} = |\sin x + \cos x| = -\sin x - \cos x,$$

从$\pi < x < \frac{3}{2} \pi$开始。

简化表达式时

$$\left(a+x\right)^{\frac{1}{2}} - \frac{1}{2} + \left(a-x\right)^{\frac{1}{2}} - \frac{1}{2}$$

在 $x=4$ ($a-1$), $1 < a < 2$ 处，我们必须转换表达式 $\sqrt{(a-2)^2}$。
