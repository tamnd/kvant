检查如果对 $(x, y)$ 满足方程 (1)，则对 $(x_1, y_1) = T(x, y)$ 也满足它：

$$x_1^2 - 3x_1y_1 + y_1^2 = y^2 - 3y(3y - x) + (3y - x)^2 = y^2 - 3xy + x^2.$$

(4)

从这里可以立即清楚地看出，所有对（2）都满足方程（1）：毕竟，对（0, 1）满足它，并且所有其他对都是使用有限变换数$T$从它获得的。

现在让我们证明，在满足方程（1）的条件$0 \leq x < y$的情况下，整数中不存在其他解$(x, y)$。让 $(x_1, y_1)$ 成为这样的解决方案之一。让我们找到一对$(x, y)$，使用公式（3）从中获得$x_1$和$y_1$ - 为此，用$x_1$和$y_1$来表达$x$和$y$就足够了：

$$x = 3x_1 - y_1, y = x_1.$$

(5)

我们将用 $T^{-1}$ 来表示从 $(x_1, y_1)$ 到 $(x, y)$ 的转变（逆变换 *) 到 $T$。由等式（4）可知，如果$(x_1, y_1)$满足等式（1），则$(x, y) = T(x_1, y_1)$也满足。让我们证明，如果此外还有 $0 < x_1 < y_1$，那么

$$0 \leq x < y.$$

(6)

让我们用两种方式表示以下的等式 $x_1^2 - 3x_1y_1 + y_1^2 = 1$：

$$x_1^2 + y_1(y_1 - 3x_1) = 1,$$

$$x_1(x_1 - y_1) + y_1(y_1 - 2x_1) = 1.$$

(7)

从等式（7）可以立即得出（$x_1$和$y_1$为正！）$-x = y_1 - 3x_1 \leq 0$，如果$y_1 - 3x_1 = 0$，则$x_1 = 1$和$y_1 = 3$。反过来，从等式 (8) 可以得出 $y - x = y_1 - 2x_1 > 0$（毕竟，$x_1 - y_1$ 是负数）。不等式(6)已被证明。请注意，它们可以像这样重写：

$$0 \leq x < x_1,$$

(9)

从$x_1 = y$开始。因此，任何解$(x_1, y_1)$、$0 < x_1 < y_1$，在变换$T^{-1}$之后都会进入解$(x, y)$，其中$0 \leq x < y$。如果同时$x > 0$，那么我们可以应用$T^{-1}$一次或多次，获得新的（幅度更小的）解决方案。事实上，如（9）所示，整数$x$的大小随着每次变换而减小。因此，经过一定的有限步数后，我们必须停止，并且只有当我们获得解$(x, y)$时才能停止，该解有$x = 0$，因此有$y = 1$。因此，我们已经证明，对于有限数变换 $T^{-1}$，从每个解$(x_1, y_1)$ 都可以获得一个解 (0, 1)。由此可见，(0, 1) 中的每个解都经过有限数 $T$ 变换（即不存在与 (2) 不同的其他解。问题完全解决。

该解决方案可以更清楚地呈现如下。我们将像往常一样将一对数字 $(x, y)$ 表示为平面上的一个点。然后方程 $x^2 - 3xy + y^2 = 1$ 定义了平面上的一条曲线，称为“sperbola”。 （封面上有一整套双曲线，由方程 $x^2 - 3xy + y^2 = c$ 给出，参数 $c$ 的值不同，我们感兴趣的是黄色。）用整数解这个方程意味着用整数坐标表示双曲线上的所有点。然而，这样的点很容易指示：它是一个坐标为(0, 1)的黑点。正如我们所证明的，所有其余的（在角度$0 \leq x < y$内）都是通过连续应用变换$T : (x, y) \rightarrow (y, 3y - x)$从中获得的。 $T$平面的变换具有以下性质：

1) 将平面中的每条直线变换回直线（此类变换称为线性变换）。

*) A. N. Kolmogorov 的文章“什么是函数？”中讨论了逆变换的概念。 （«Kvant»第1号，1970）。
