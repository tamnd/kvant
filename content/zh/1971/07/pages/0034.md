Diana $BM$ 相交于一点。事实上，区分了角$\Rightarrow A = \alpha$一侧的（任意）线段$AC$，将垂线$CH$放到角的另一侧，并指定其与角$A$到$O$的平分线的交点，我们将找到角的第二条边与直线$OM$的交点$B$ （其中$M$是线段$AC$的中点），从而构造所需的三角形$ABC$；显然，给定 $\Rightarrow A$ 和 $AC$，它以独特的方式定义。请注意，在这种情况下，角度 $B$ 是锐角（因为点 $H$ - 高度的底边 - 位于边 $AB$ 上）。

让我们证明如果$\Rightarrow A < \frac{\pi}{4}$，则$\Rightarrow ACB > \frac{\pi}{2}$。让我们在直线 $AB$ 上绘制线段 $HB_1 = AH$。那么等腰三角形$AB_1C$的角$B_1$的平分线$B_1F$将经过点$O$。由于$\frac{AF}{FC} = \frac{AB_1}{B_1C} > 1$，点$M$位于$A$和$F$之间，因此$B_1$位于$A$和$B$和$\Rightarrow BCA > \Rightarrow B_1CA > \frac{\pi}{2}$之间。

在这个问题中，您可以获得更准确的结果：找到角度 $\alpha$ 的精确估计，前提是 $\Rightarrow ACB = \gamma < \frac{\pi}{2}$。为此，我们将 $\gamma$ 表示为 $\alpha$ 的函数。我们来画$HE \parallel BM$（E是$AC$上的点）。那么(图7)

$$\frac{EM}{MC} = \frac{HO}{OC} = \frac{AH}{AC} = \cos \alpha, \quad \frac{HB}{AH} = \frac{EM}{AE} = \frac{\cos \alpha}{1 - \cos \alpha}, \quad \frac{HB}{HC} = \frac{\cos^2 \alpha}{\sin \alpha (1 - \cos \alpha)},$$

$$\gamma = \gamma(\alpha) = \frac{\pi}{2} - \alpha + \arctg \frac{\cos^2 \alpha}{\sin \alpha (1 - \cos \alpha)}.$$

从这里可以清楚地看出，函数$\gamma = \gamma(\alpha)$在$0 < \alpha < \frac{\pi}{2}$上单调递减（$\alpha$越多，sin$\alpha$越大，cos$\alpha$越小，因此圆弧符号下的分数总是较小）。现在让我们找到 $\alpha$ 对应 $\gamma(\alpha) = \frac{\pi}{2}$。该属性方程为：$0 < \alpha < \frac{\pi}{2}, \sin^2 \alpha (1 - \cos \alpha) = \cos^3 \alpha$，因此 cos $\alpha = \frac{\sqrt{5} - 1}{2}$。所以，如果$\gamma < \frac{\pi}{2}$，则$\alpha > \alpha_0 = \arccos \frac{\sqrt{5} - 1}{2} \left( \alpha_0 > \frac{\pi}{4} \right)$，因为$\frac{\sqrt{5} - 1}{2} < \frac{\sqrt{2}}{2}$；从表中可以看出，$\alpha_0$ 对应的角度约为 $51^\circ 50'$）。
