⟦folio 51⟧

心理学部（全日制系）

选项1

1. 两艘相同的轮船从两个码头出发：第一艘轮船从下游$A$码头出发，第二艘从上游$B$码头出发。每一艘前往最终目的地的船都会在那里停留 45 分钟然后返回。如果轮船同时从起始点出发，则在返回途中会在$K$ 点相遇，该点距离 $A$ 的距离比$B$ 的距离近 2 倍。如果一艘轮船从 $A$ 出发，比第二艘轮船从 $B$ 出发晚 1 小时，那么在返回途中，它们会在 20 公里处从 $A$ 出发。如果一艘轮船从 $A$ 出发，比第二艘从 $B$ 出发早 30 分钟，则在返回途中，两艘轮船在 $K$ 上方 5 公里处会合。求河流的流速以及第二艘轮船从$A$到达$K$所需的时间。

2. 找到满足方程的 $a$ 的所有实数值

$$x^8 + ax^4 + 1 = 0$$

有 rfno 四个实根形成算术级数

3. 找到所有满足不等式的$x$

$$\log_{\cos x^2} \left( \frac{3}{x} - 2x \right) < \log_{\cos x^2} (2x - 1).$$

4. 将3个球放置在正三角形帕拉米德中，使得第1个球接触帕拉米德的所有侧面和第2个球，第2个球接触帕拉米德的侧面和第3个球，第3个球接触帕拉米德的侧面、底部和第2个球。如果对位聚酰胺的侧面以 $\alpha^2$ 角度与底座倾斜，则三个球占据其体积的几分之几？

问题解决方案

1. 根据问题的条件，轮船是相同的，也就是说轮船在静水中的速度是相同的。让我们用 $v$ ($\kappa m/\mu$) 表示该速度。让我们用$v_0$（$\kappa m/\mu$）表示河流的速度，用$S$（$\kappa m$）表示$A$和$B$之间的距离。下面我们将以小时为单位测量时间，并省略所有数量的维度。比较船舶从出发时刻到回程相遇时刻（包括停泊）所花费的时间，我们组成一个由三个未知数方程组成的系统：

$$\begin{align*}
\frac{S}{v + v_0} + \frac{\frac{2S}{3}}{v - v_0} &= \frac{S}{v - v_0} + \frac{\frac{S}{3}}{v + v_0}, \\
\frac{S}{v + v_0} + \frac{S - 20}{v - v_0} + 1 &= \frac{S}{v - v_0} + \frac{20}{v + v_0}, \\
\frac{S}{v + v_0} + \frac{\frac{2S}{3} + 5}{v - v_0} &= \frac{S}{v - v_0} + \frac{\frac{S}{3} - 5}{v + v_0} + \frac{1}{2}.
\end{align*}$$

从第一个方程我们发现$v = 3v_0$，从第一个和第三个方程我们发现：$v_0 = 7,5$； $v = 22,5$。将这些值$v$和$v_0$代入第二个方程，我们找到$S = 30$，即$AK = 10$。这意味着第二艘轮船在$\frac{10}{30} = \frac{1}{3}$小时内从$A$到达$K$。答：河水流速为7.5$\kappa m/\mu$，第二艘船从$A$到$K$需要20分钟。

2. 不难证明原方程是二次方程。学校教科书中讨论了这种类型的方程。让我们输入$x^4 = t$。那么方程将被重写为$t^2 + at + 1 = 0$。令 $t_1$ 和 $t_2$ 为该方程的实根。很容易看出$t_1$和$t_2$一定是正数且不同。为了定义方便，假设$0 < t_1 < t_2$。那么原方程有以下根（按升序排列）：$x_1 = -\sqrt[4]{t_2}$、$x_2 = -\sqrt[4]{t_1}$、$x_3 = \sqrt[4]{t_1}$、$x_4 = \sqrt[4]{t_2}$。
