注意，如果$p < 0$，即抛物线OLS的分支向上，那么如果$p$是偶数，则抛物线沿着黑色单元格，如果$p$是奇数，则沿着黄色单元格；如果$p > 0$，则反之亦然。此外，通过我们网格的直线和圆的每个交点（不包括直线$x = 0$上的切点），有两条抛物线经过；一个沿着黄色单元格移动，另一个沿着黑色单元格移动；一个是分支向上，另一个是向下。

解决这个问题的办法就是增加很多荣誉。有些人在他们的解决方案中使用抛物线的以下几何定义：抛物线是一组与给定点和给定线距离相等的点。本质上，问题 M68 的解决方案非常接近于证明抛物线的定义与学校课程中已知的抛物线定义的等价性（抛物线是正方形三角形的图形）。如果我们选择一个坐标系，使给定点为鼻坐标，给定直线为方程$y = c$，则点$(x, y)$到给定点和给定直线距离相等的条件可以写成方程$\sqrt{x^2 + y^2} = |y - c|$，相当于方程$y = -\frac{x^2}{2c} + \frac{c}{2}$。

M69

数字 76 有一个奇怪的特性：数字​​ $76^2 = 5776$ 的最后两位数字又给出了数字 76。

a) 还有其他类似的两位数吗？

b) 找到所有三位数$A$，使得$A^2$的最后三位数字组成$A$。

b) 是否存在无限的数字序列$a_1, a_2, a_3, \dots$，使得对于任何$n$，数字“$a_n a_{n-1} \dots a_2 a_1$”的平方是“...$a_n a_{n-1} \dots a_2 a_1$”？ （这里的引号表示数字的十进制表示法。对于所有$i > 1$，我们排除了明显的答案$a_i = O$。）

这个问题的答案如下：对于任何$n > 1$，恰好有两个这样的$n$位数$n > 1$，其平方为$A$（不包括很长的数字：0 ... 0000和0 ... 0001）， - 对于$n = 2$，它们是76和25，对于$n = 3$ - 376和625，$n = 4$ - 9376 和 0625，$n = 5$ - 09376 和 90625 等，因此 c) 点讨论了两个无限的数字序列：一个以数字 6, 7, 3, 9, 0, 1, ... 开头，另一个以数字 5, 2, 6, 0, 9, 8 开头， ...*)。

让我们从任务 a) 开始。找到我们需要的表示复数的两位数字的最简单方法如下。如果 $A^2$ 与 $A$ 是相同的两位数字，则 $A^2 - A = A$ (A - 1) 可被 100 = 25 4 整除，并且由于数字 $A$ 和 $(A - 1)$ 是互质的（没有大于 1 的公因数），因此其中一个必须能被 25 整除，另一个能被 4 整除。让我们尝试看看每个数字 25、50 和 75 是否适合角色 $A$ 或角色 $A - 1$（这两个数字都是两位数）。为此，您只需检查其相邻数字中哪些可以被 4 整除。这只会是 76 和 24，因此 $A$ 只能等于 25 和 76。

问题6可以类似地解决），但我们必须立即明白：如果数字$B = \langle a_{n-1} a_{n-2} \dots a_1 \rangle$的平方结果是数字“...$a_{n-1} a_{n-2} \dots a_1$”，那么可以通过一种独特的方式选择数字$a_n$，使得数字$A = \langle a_n a_{n-1} \dots a_1 \rangle$的平方结果是“...$a_n a_{n-1} \dots a_1$”。

让$B^2 = \langle ... b_n a_{n-1} a_{n-2} \dots a_1 \rangle$。然后$(n \geqslant 2 = > 2n > n + 1)$

$$A^2 = (10^n a_n + B)^2 = 10^{2n} a_n + 2 \cdot 10^n a_n B + B^2 = \langle ... c_n a_{n-1} a_{n-2} \dots a_1 \rangle,$$

其中$c_n$是数字$2a_n a_1 + b_n$的最后一位数字。我们必须选择$a_n$，使得$c_n$等于$a_n$，即$2a_n a_1 + b_n = a_n = (2a_1 - 1)a_n + b_n$能被10整除。显然，这可以通过一种独特的方式来完成。在我们感兴趣的函数$a_1 = 5$和$a_1 = 6$中，我们必须指出的$b_n \rightarrow a_n$函数特别简单：如果$a_1 = 5$，则$a_n = b_n$，如果$n = 6$，则$a_n = 10 - b_n$与$b_n > 0$，以及$a_n = 0$与$b_n = 0$。

Ya 在书中更详细地讨论了解决问题 M68 的方法。 I. Perel - 论“有趣的代数”，第 81-85 页。

*) 我们不排除数字“$a_n a_{n-1} \dots a_1$”，其中第一位数字$a_n$（或前几个数字）等于零。没有考虑过此类数字的读者自然应该只上到四位数9376和三位数625。
