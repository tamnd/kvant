3. 让所需的序列具有以下形式
$$k + 1, k + 2, \dots, n - 1, n$$
那么它的和可以表示为自然级数从1到$n$和从1到$k$的线段和之差，即
$$\frac{(n + 1)n}{2} - \frac{(k + 1)k}{2} = 1000$$
或$n^2 + n - k^2 - k = 2000$。
让我们将这个等式的左边分解为两个因数，将右边分解为质因数：
$$(n + k + 1)(n - k) = 2^4 \cdot 5^3$$
请注意，该等式左侧的因子 $n + k + 1$ 和 $n - k$ 不能为偶数，因为它们的总和 $2n + 1$ 为奇数。另外，第一个因素大于第二个因素。因此，我们得到了一组四个系统：
$$\begin{cases} n + k + 1 = 2000, \\ n - k = 1, \end{cases} \quad \begin{cases} n + k + 1 = 400, \\ n - k = 5, \end{cases} \quad \begin{cases} n + k + 1 = 80, \\ n - k = 25, \end{cases} \quad \begin{cases} n + k + 1 = 125, \\ n - k = 16. \end{cases}$$
这些系统中的第一个给出了由单数 1000 组成的三元“序列”。其余系统给出了序列：
198, 199, 200, 201, 202;
28, 29, ..., 51, 52;
54, 55, ..., 69, 70.

4. 让角度 $C$ 用于定义类型。那么$0 < B < \frac{\pi}{2} - A$，因此
$$\cos B > \cos \left( \frac{\pi}{2} - A \right) = \sin A > 0$$
因此$\cos^2 B > \sin^2 A$。

那么$\cos^2 A + \cos^2 B > \cos^2 A + \sin^2 A = 1$，即$\cos^2 A + \cos^2 B > 1$，更是如此
$$\cos^2 A + \cos^2 B + \cos^2 C > 1$$

辅助圆的考虑介绍（见1971年«Kvant»第1期）。然而，这个问题允许更短的解决方案（Galina Averbukh，$10^6$ 200 号学校班级，Alexey Vodovozov，$10^a$ 569 号学校班级）。

令三角形$ABC$ (图 3) 的中线$BD$、边线$BE$ 和高$BF$ 将角$B$ 分成四等分，每一等分表示为$\alpha$。然后
$$AF = h \ tg 3\alpha; DF = h \ tg 2\alpha$$
和$FC = h \ tg \alpha$。
下一个
$$AD = AF - DF = h \ (tg 3\alpha - tg 2\alpha)$$
$$DC = DF + FC = h \ (tg 2\alpha + tg \alpha)$$
但根据条件$AD = DC$，即
$$tg 3\alpha - tg 2\alpha = tg 2\alpha + tg \alpha$$
或者
$$2 \ tg 2\alpha = tg 3\alpha - tg \alpha$$
$$\frac{2 \sin 2\alpha}{\cos 2\alpha} = \frac{\sin 2\alpha}{\cos 3\alpha \cos \alpha}$$

由于 $\sin 2\alpha \neq 0$，则 $2 \cos 3\alpha \cos \alpha = \cos 2\alpha$ 或
$$\cos 2\alpha + \cos 4\alpha = \cos 2\alpha$$
即$\cos 4\alpha = 0$。
由此可见，角$B$属于。
