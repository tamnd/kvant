以下是一些示例，其中连续自然数的平方和 $k$ 等于以下自然数的平方和 $(k-1)$：
$$3^2+4^2=5^2, 36^2+37^2+38^2+39^2+40^2=41^2+42^2+43^2+44^2,$$
$$55^2+56^2+57^2+58^2+59^2+60^2=61^2+62^2+63^2+64^2+65^2.$$
找到一个涵盖所有此类情况的通用公式。

让我们证明对于每个自然数 $k$ 都恰好有一个自然数 $n$ 使得
$$(n-k+1)^2+(n-k+2)^2+\ldots+(n-1)^2+n^2=(n+1)^2+$$
$$+(n+2)^2+\ldots+(n+k-1)^2.$$

（注意等式右边$(k-1)$是被加数，左边是$k$）。等式（1）等价于：
$$n^2=[(n+1)^2-(n-k+1)^2]+[(n+2)^2-(n-k+2)^2]+\ldots$$
$$\ldots+[(n+k-1)^2-(n-1)^2]$$
$$n^2=k(2n-k+2)+k(2n-k+4)+\ldots+k(2n+k-2),$$
$$n^2=2k(k-1)n.$$

因此，所陈述的陈述被证明：当且仅当$n=2k^2-2k$时，满足自然$k$和$n$的等式（1）。 （从（3）到（4）时，我们利用等差数列$(2n-k+2)+(2n-k+4)+\ldots+(2n+k-2)$的$(k-1)$项之和等于$(k-1)\frac{(2n-k+2)(2n+k-2)}{2}=2(k-1)n$的事实，从而得到了排除公式。例如可以写成这样：
$$(2k^2-3k+1)^2+(2k^2-3k+2)^2+\ldots+(2k^2-2k)^2$$
$$=(2k^2-2k+1)^2+(2k^2-2k+2)^2+\ldots+(2k^2-k-1)^2,$$
其中$k$是任意自然数。条件中给出的例子是从中获得的，其中$k$等于2、4和5。

这个公式（或其他等价的公式）已经被很多人找到了——他们中的大多数人要么给出了接近我们的证明，要么在他们的计算中使用自然数平方和的公式（参见引理 1，第 17 页）。

M68

图 5 上描绘的网格线（另见《Kvat》第 2 期，1971 年的封面）由半径为 1、2、3、4... 的同心圆组成，中心位于点 $O$，一条穿过点 $O$ 的线 $l$，以及与该线平行的圆的所有可能的切线$l$。整个平面被这些线划分为单元，这些单元以棋盘图案着色。在图所示的粉红色点链中，每两个相邻的点是暗单元的相对顶点。证明这样一条无限链的所有点都位于同一条抛物线上（姿势权重 图 可以说是由黄色和深色抛物线编织而成）。

以直线$l$为轴$Ox$，点$O$为直线系坐标原点，如图5所示。条件中已经指定了比例单位。条件中讨论的线网格由半径为$n$、中心为$O$的圆（该圆的方程$x^2 + y^2 = n^2$）和直线$y = m$组成，其中$m$和$n$都是可能的整数； $n > 0$。因此，这些线的每个交点（或相切点）——网格的每个“节点”$(x, y)$——对应于特定的一对值$n = \sqrt{x^2 + y^2}$和$m = y$。请注意，当我们从一个粉红点移动到相邻的粉红点时，$m$和$n$都改变了1，因此它们的差值$n - m = \sqrt{x^2 + y^2} - y$保持不变；所有粉红点的差异为 6。

等式 $\sqrt{x^2 + y^2} - y = 6$ 等价于：$x^2 + y^2 = (y + 6)^2$； $y = \frac{x^2}{12} - 3$。因此，所有粉红色点都位于抛物线 $y = \frac{x^2}{12} - 3$ 上。

在我们用头部颜色绘制的另一个类似的点链中，当从一个点移动到相邻点时，$\sqrt{x^2 + y^2}$和$y$改变1，因此它们的总和保持不变：$\sqrt{x^2 + y^2} + y = 4$。这个方程经过点变换，就变成了抛物线$y = -\frac{x^2}{6} + \frac{3}{2}$的方程。

以同样的方式，可以证明任何无限的点链，其中相邻点是同一单元（或一个线段）的相反顶点，都位于抛物线$y = -\frac{x^2}{2p} + \frac{p}{2}$上，其中$p$是某个非零整数。相反，任何这些抛物线都包含无限的点链（这些点是抛物线与所有可能的直线 $y = m$ 的交点）。

注意，如果$p < 0$，即抛物线OLS的分支向上，那么如果$p$是偶数，则抛物线沿着黑色单元格，如果$p$是奇数，则沿着黄色单元格；如果$p > 0$，则反之亦然。此外，通过我们网格的直线和圆的每个交点（不包括直线$x = 0$上的切点），有两条抛物线经过；一个沿着黄色单元格移动，另一个沿着黑色单元格移动；一个是分支向上，另一个是向下。

解决这个问题的办法就是增加很多荣誉。有些人在他们的解决方案中使用抛物线的以下几何定义：抛物线是一组与给定点和给定线距离相等的点。本质上，问题 M68 的解决方案非常接近于证明抛物线的定义与学校课程中已知的抛物线定义的等价性（抛物线是正方形三角形的图形）。如果我们选择一个坐标系，使给定点为鼻坐标，给定直线为方程$y = c$，则点$(x, y)$到给定点和给定直线距离相等的条件可以写成方程$\sqrt{x^2 + y^2} = |y - c|$，相当于方程$y = -\frac{x^2}{2c} + \frac{c}{2}$。

如果矩阵和附着在篮筐上的球的最大偏离角度为$\alpha_0$ (图 7)，则它们距离平衡位置的高度为$h=R(1-\cos \alpha_0)$。在偏转角度 $\alpha$ 处，基体（以及带有球的篮圈）的动能等于角度 $\alpha_0$ 和角度 $\alpha$ 处的势能之差。对于我们得到的数学矩阵

$$v = \sqrt{2gR(\cos \alpha - \cos \alpha_0)}.$$

就像矩阵一样，篮筐的势能随着球的变化而变化。环本身的势能不变，但这种情况下的动能等于球$E_{\text{ш}} = \frac{mv^2}{2}$和环$E_0 = \frac{mv^2}{2}$的动能之和（环的动能参见A.K. Kikon的文章“Rotational sport of trees”，«Kvant»No.1，1971）。因此，对于有球的篮筐，根据能量守恒定律可以得出：

$$\frac{mv^2}{2} + \frac{mv^2}{2} = mgR(\cos \alpha - \cos \alpha_0),$$

和球速

$$v = \sqrt{gR(\cos \alpha - \cos \alpha_0)}.$$

在偏离平衡位置的任何角度，球的速度都比数学矩阵的速度小$\sqrt{2}$倍。因此，

⟦folio 42⟧

带球的环的振动周期是矩阵振动周期的 $\sqrt{2}$ 倍，等于

$$T = 2\pi \sqrt{\frac{2R}{g}}.$$

无论如何，你都可以解决这个问题。如果数学矩阵偏离平衡位置角度$\alpha$，那么它会通过重力的分量回到平衡位置，与矩阵的轨迹相切（图8）：

$$F = mg \sin \alpha.$$

由于角度$\alpha$小，则$\sin \alpha \approx \alpha \approx \frac{x}{R}$小，其中$x$是矩阵相对平衡位置的位移。从这里

$$F \approx mg \frac{x}{R}.$$

因此，对于矩阵加速度的切向分量，我们可以写出方程

$$mg \frac{x}{R} = ma$$ 或 $a = \frac{g}{R} x = cx,$

其中 $c = \frac{g}{R}$ 是给定矩阵的某个常数系数。矩阵振荡周期等于$2\pi \sqrt{\frac{R}{g}}$，即$2\pi/\sqrt{c}$。

对于附着在圆上并沿水平面振荡的重量，我们将获得类似的结果。该重物的运动方程为$kx = ma$，振荡周期为$T = 2\pi \sqrt{\frac{m}{k}}$。

在我们的例子中，使球返回平衡位置的力是相等的，如数学矩阵 $mg \frac{x}{R}$ 的情况一样，并且加速度 $a$ 传递给球和篮筐，即质量 $2m$。因此$mg \frac{x}{R} = 2ma$；这意味着$c = \frac{g}{2R}$，系统的振荡周期为$T = 2\pi \sqrt{\frac{2R}{g}}$。

如果将一个带球的环移至月球或放入盛有液体的容器中，则其振荡周期将以与数学矩阵的振荡周期完全相同的方式变化：在第一种情况下，由于自由落体加速度的变化，它会增加 $\sqrt{6}$ 倍 ($g_{\text{л}} = \frac{1}{6} g_3$)，在第二种情况下，它会减少 $\sqrt{1 - \frac{\rho}{\rho_T}}$ 倍（$\rho$ - 水的密度和$\rho_T$ - 密度球材料）由于阿基米德浮力的影响。

活塞下方气缸中的 20 氦气非常缓慢地从状态 I ($P_1 = 4,1$ amm, $V_1 = 32$ l) 转移到状态 II ($P_2 = 15,5$ amm, $V_2 = 9$ l)。如果压力与体积的关系图是一条直线（图！i），则每种具有最高温度的气体会更简单？

让我们在图上绘制等温线网格——双曲线$PV = \text{const} \frac{m}{\mu} RT$。气体温度越高，双曲线的顶点距离原点越远。因此，很明显，在过程 I-II 期间，气体达到如此高的温度，此时相应的双曲线不与线 I-II 相交，而只是接触它。

由于最高温度对应的坐标为$P$和$V$的点既位于双曲线上，又位于直线上，因此其坐标必须满足两个方程：

$$PV = \frac{m}{\mu} RT$$

和直线方程

$$P = \alpha V + \beta$$

（α 和 β 是常数。稍后我们将定义它们）。将第二个方程中的$P$代入第一个方程，我们得到$V$的二次方程：

$$\alpha V^2 + \beta V - \frac{m}{\mu} RT = 0.$$

由于双曲线和直线必须只有一个公共点，因此该方程只能有一个根，即其行列式必须等于 0：

$$\beta^2 + 4\alpha \frac{m}{\mu} RT = 0.$$

求解最后一个方程 $T$，我们发现

$$T = -\frac{\beta^2 \mu}{4\alpha m R}.$$

在此表达式中，您需要替换系数 $\alpha$ 和 $\beta$ 的值。由于点 I 和 II 属于同一条直线 $P = \alpha V + \beta$，因此$P_1 = \alpha V_1 + \beta$ 和 $P_2 = \alpha V_2 + \beta$。求解这个方程组，我们发现

$$\alpha = -\frac{P_2 - P_1}{V_1 - V_2}, \quad \beta = \frac{P_2 V_1 - P_1 V_2}{V_1 - V_2}.$$

波兹尼

$$T = \frac{(P_2 V_1 - P_1 V_2)^2 \mu}{4 (P_2 - P_1) (V_1 - V_2) m R}.$$

代入该表达式中包含的量的数值，我们得到

$$T \approx 490^\circ \text{ K}.$$
