奥运会由电子计算机进行

于。 I·索尔金，
N·B·什昆迪纳

今年1月至4月，莫斯科经济与统计学院首次举办了高中生数学奥林匹克竞赛，其中涉及电子计算机。奥运会分两轮举行。第二轮使用Minsk-22机器进行；只有成功完成第一轮的学童才可以参加。

第一轮比赛以缺席形式进行。来自莫斯科及莫斯科地区周边地区所有感兴趣的学童都参加了此次活动。解决第一类第五个问题，给出了一个月的期限（即到2月15日）。

3. 几个连续自然数的和是1000。找出所有这样的序列。
4. 证明对于钝角三角形，不等式 $\cos^2 A + \cos^2 B + \cos^2 C > 1$ 成立。

3. 让所需的序列具有以下形式
$$k + 1, k + 2, \dots, n - 1, n$$
那么它的和可以表示为自然级数从1到$n$和从1到$k$的线段和之差，即
$$\frac{(n + 1)n}{2} - \frac{(k + 1)k}{2} = 1000$$
或$n^2 + n - k^2 - k = 2000$。
让我们将这个等式的左边分解为两个因数，将右边分解为质因数：
$$(n + k + 1)(n - k) = 2^4 \cdot 5^3$$
请注意，该等式左侧的因子 $n + k + 1$ 和 $n - k$ 不能为偶数，因为它们的总和 $2n + 1$ 为奇数。另外，第一个因素大于第二个因素。因此，我们得到了一组四个系统：
$$\begin{cases} n + k + 1 = 2000, \\ n - k = 1, \end{cases} \quad \begin{cases} n + k + 1 = 400, \\ n - k = 5, \end{cases} \quad \begin{cases} n + k + 1 = 80, \\ n - k = 25, \end{cases} \quad \begin{cases} n + k + 1 = 125, \\ n - k = 16. \end{cases}$$
这些系统中的第一个给出了由单数 1000 组成的三元“序列”。其余系统给出了序列：
198, 199, 200, 201, 202;
28, 29, ..., 51, 52;
54, 55, ..., 69, 70.

4. 让角度 $C$ 用于定义类型。那么$0 < B < \frac{\pi}{2} - A$，因此
$$\cos B > \cos \left( \frac{\pi}{2} - A \right) = \sin A > 0$$
因此$\cos^2 B > \sin^2 A$。

那么$\cos^2 A + \cos^2 B > \cos^2 A + \sin^2 A = 1$，即$\cos^2 A + \cos^2 B > 1$，更是如此
$$\cos^2 A + \cos^2 B + \cos^2 C > 1$$

$$DC = DF + FC = h \ (tg 2\alpha + tg \alpha)$$

第二轮

4月25日，成功通过第一轮的40名孩子齐聚MESI继续“比赛”。

第二轮比赛中，奥组委的“成员”之一是明斯克22型电子绣花机。这位“成员”担负着主要工作。机器内存中存储了数千个任务。每个问题都配有一个特殊的代码，指示该问题所属的数学部分和难度（所有问题都来自不同的数学部分，具有相同的总难度）。

每位奥运会参赛者的机器被称为 Varnan。

截止时间后（4 小时 45 分钟），作品被分离到机器中进行检查*）。机器将问题的解决方案与属性进行比较，正确解决所有五个问题的人被宣布为获胜者。当奥林匹克参赛者逐渐熟悉该研究所时，机器完成了所有这些工作。

莫斯科学校的六名十年级学生获得了 MESI 证书和难忘的礼物：

*埃琳娜·萨维娜、维克多·扎克、谢尔盖·马佩诺夫、马克·里策尔、亚历山大·罗津、列昂尼德·捷列霍夫。

奥数机考是数学、物理计算机化考试工作的最后阶段。这项伟大的工作是在 MESI 校长 教授的领导下进行的。 M.A.科罗列娃，教授。 I. G. Venetsky 和技术科学博士 A. G. Morozov。
