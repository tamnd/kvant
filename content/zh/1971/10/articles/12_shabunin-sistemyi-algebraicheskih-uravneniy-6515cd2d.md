代数方程组

M.I.沙布宁

在大学入学考试中，首先提出了代数方程组；特别是，此类系统会出现方程组问题。考试经验表明，许多参加解方程组的学生的表现并不令人满意。

事实是，通常在学习时，寻找系统解决方案的问题被简单地理解为一系列“通常”代数变换的正式实现。同时，应该记住，某些变换示例可能会导致出现无关解或导致原始系统解的丢失。

如果没有适当的理由来证明系统的解，逻辑方程就是不完整的。特别是，我们可能无法弥补某些解决方案的损失。不幸的是，在申请人的工作中，有充分依据、精心呈现的系统决策极为罕见。

详细介绍与方程组相关的所有重要问题将需要太多篇幅 *)。因此，我们将仅限于介绍有关求解三个未知代数方程的基本理论原理，然后考虑几个例子。

首先，让我们回顾一些定义。

具有未知数的三个方程组可以写成以下形式

$$\begin{cases}
f_1(x, y, z) = 0, \\
f_2(x, y, z) = 0, \\
f_3(x, y, z) = 0
\end{cases}$$

或者，为简洁起见，省略未知数，形式为

$$\begin{cases}
f_1 = 0, \\
f_2 = 0, \\
f_3 = 0.
\end{cases}$$

我们将只考虑代数系统，即这样的

现在让我们制定求解方程组时最常用的几个属性。我们不会证明这些性质；使用给定的定义，读者可以轻松地自行验证必要的理由。

I. 让系统（1）的一个方程，以确定第一个，“分裂”成两个方程，例如，表示为形式
$$g_1(x, y, z) g_2(x, y, z) = 0,$$
其中 $g_1$ 和 $g_2$ 是 $x, y, z$ 中的多项式。那么系统(1)等价于以下两个系统的组合：
$$\begin{cases} g_1 = 0, \\ f_2 = 0, \\ f_3 = 0 \end{cases} \quad \text{и} \quad \begin{cases} g_2 = 0, \\ f_2 = 0, \\ f_3 = 0. \end{cases}$$

这个陈述可以很容易地推广到系统（1）的两个或三个方程“分解”成几个方程的情况。

二.如果方程（4）是系统（1）的结果，那么，当将方程（4）连接到系统（1）时，我们得到一个由四个方程组成的系统{{1}，{4}}，与原来的方程等效。

三．让方程（4）（系统（1）的结果）“分解”为两个方程：
$$F_1(x, y, z) \cdot F_2(x, y, z) = 0,$$
其中 $F_1$、$F_2$ 是 $x, y, z$ 中的多项式。那么系统(1)等价于以下两个系统的组合：
$$\begin{cases} f_1 = 0, \\ f_2 = 0, \\ f_3 = 0, \\ F_1 = 0 \end{cases} \quad \text{и} \quad \begin{cases} f_1 = 0, \\ f_2 = 0, \\ f_3 = 0, \\ F_2 = 0. \end{cases}$$

四．方程组 (1) 等价于以下每个系统：
$$\begin{cases} f_1 - f_2 = 0, \\ f_2 - f_3 = 0, \\ f_3 - f_4 = 0; \end{cases} \quad \text{и} \quad \begin{cases} f_1 - f_2 = 0, \\ f_2 - f_3 = 0, \\ f_3 - f_4 = 0; \end{cases}$$

$$\begin{cases} f_1 + f_2 = 0, \\ f_1 + f_3 = 0, \\ f_2 + f_3 = 0 \end{cases}$$

（将另一个数字乘以乘积添加到系统的一个方程中的能力）。

V. 令系统(1)的其中一个方程，例如其第一个方程$f_1(x, y, z) = 0$，等价于方程$x = \varphi(y, z)$——$y$和$z$的多项式。那么系统(1)等价于系统
$$\begin{cases} x = \varphi(y, z), \\ f_2[\varphi(y, z), y, z] = 0, \\ f_3[\varphi(y, z), y, z] = 0. \end{cases}$$
