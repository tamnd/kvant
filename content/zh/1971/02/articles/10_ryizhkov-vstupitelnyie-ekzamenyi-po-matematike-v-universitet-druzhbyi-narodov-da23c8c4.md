1. 这个问题有一个简单、相当自然的解决方案。让我们把复数 z 写成代数形式：$z = x + iy$；然后
$$z^2 + (1 + i)z = (x + iy)^2 + (1 + i)(x + iy) = x^2 + 2 ixy - y^2 + x + iy + ix - y = x^2 - y^2 + x - y + i(2xy + x + y).
$$
为了使这个数成为纯最小数，其实部等于零是必要且充分的（当然，零也适用于纯最小数）。我们有：
$$x^2 - y^2 + x - y = 0.$$

3. 立体测量问题是标准问题，但相当困难。问题不仅在于二面角问题并不总是以递减的方式解决，而且条件不给出单个角度值，而只给出两个这样的值之间的对应关系。一般来说，正四边形帕米达由一个线性尺寸和一个角度尺寸确定。线性尺寸dan是paramid的高度，并且角度尺寸一起表示两个角度之间的对应关系。

许多申请人已经解决了这个问题。换句话说，他们中的一些人根本没有理解问题的本质。将其中一个二面角指定为$\alpha$，另一个指定为$3\alpha$，他们就能够通过角度$\alpha$来表达体积，而不认为这个角度是由问题的条件决定的。

这是该问题的一种可能的解决方案。在 图 2 上，$\alpha$ 表示底边边缘处的二面角，$\beta$ 表示 Paramid 外侧边缘处的二面角，因此 $BK$ 和 $DK$ 是从底面顶点绘制的 Paramid 侧面的高度。在$\beta = 3\alpha$条件下。

为了方便起见，我们还引入了符号 $\gamma$ 来表示 paramid 底部的平面角； $a$表示底边，$h$表示侧面的高度，即paramid的边心线。

立即可以在角度$\alpha$和$\gamma$之间找到对应关系：从三角形$SOL$我们有$\frac{a}{2h} = \cos \alpha$；三角形$SLB$中的相同关系表示如下：$\frac{a}{2h} = \text{ctg} \gamma$。

因此，$\text{ctg} \gamma = \cos \alpha$。由于在考虑三角形 $ABK$ 时我们需要 sin $\gamma$，因此我们通过角度 $\alpha$ 的函数来表达该正弦：

$$\sin \gamma = \frac{1}{\sqrt{1 + \text{ctg}^2} \gamma} = \frac{1}{\sqrt{1 + \cos^2 \alpha}}.$$

现在，从三角形$ABK$我们有$BK = a \sin \gamma$，从三角形$BKD$$BK = \frac{a}{\sqrt{2} \sin \frac{\beta}{2}}$，从那里有$\sqrt{2} \sin \frac{\beta}{2} = \frac{1}{\sin \gamma}$或$\sqrt{2} \sin \frac{\beta}{2} = \sqrt{1 + \cos^2 \alpha}$。

因此$2 \sin^2 \frac{\beta}{2} = 1 + \cos^2 \alpha$或$1 - 2 \sin^2 \frac{\beta}{2} = -\cos^2 \alpha$，也就是说，明确地

$$\cos \beta = -\cos^2 \alpha.$$

四边形帕拉米德之间的这种有趣的对应关系。在我们的问题 $\beta = 3\alpha$ 中，因此要找到角度 $\alpha$，我们得到方程

$$\cos 3\alpha = -\cos^2 \alpha.$$

可以使用标准方法来解决。用角度函数 $\alpha$ 表达 cos $3\alpha$

$$\cos 3\alpha = 4 \cos^3 \alpha - 3 \cos \alpha,$$

我们得到

$$4 \cos^3 \alpha - 3 \cos \alpha = -\cos^2 \alpha.$$

为简洁起见，我们假设 cos $\alpha = u$，我们得出以下等式：

$$4 u^3 + u^2 - 3 u = 0.$$

4. 解方程非常简单：

$$\text{tg}(p + q) x = \frac{\text{tg} px + \text{tg} qx}{1 - \text{tg} px \text{tg} qx}.$$

这表明$\text{tg} px + \text{tg} qx = 0$或$\text{tg} px \cdot \text{tg} qx = 0$。因此，在三种情况下均满足该方程：

a) $\text{tg} px + \text{tg} qx = 0$，相当于$\sin (p + q) x = 0$； 6）$\text{tg} px = 0$； 8）$\text{tg} qx = 0$。因此，如果$p + q = 0$，或$p = 0$，或$q = 0$，它会去同一个地方；如果这三个等式都不满足，则方程满足三个系列解：

$$x = \frac{k\pi}{p + q}, \quad x = \frac{k\pi}{p}, \quad x = \frac{k\pi}{q}$$

($k = 0, \pm 1, \pm 2, \dots$).

在详细解决问题时，有必要查明某些指定的解决方案是否可以采用这些案例的形式，因为只有少数解决问题的方案清楚地表明了解决同一地点的所有三种情况。

5. 大部分问题都得到了解决，但往往是以一种繁琐或不合逻辑的方式解决的。让每辆自卸车一次分别清除$\frac{1}{x}, \frac{1}{y}, \frac{1}{z}$部分土壤。而且

$$\text{obщее количество ручента за единицу. Тогда условие задачи перешдает в виде системы}$$

$$\left\{ \frac{8}{x} + \frac{8}{y} + \frac{8}{z} = 1, \quad \frac{4}{x} + \frac{2}{y} + \frac{16}{z} = 1, \quad \frac{6}{x} + \frac{p}{y} + \frac{12}{z} = 1. \right.$$

这里第二辆自卸车$p$的行程次数未知； $x, y, z$ 也是未知的，但是我们不需要确定。通过一定量的数学观察，我们可以同意将前两个等式除法相加，并将所得方程两边除以 2。我们得到等式

$$\frac{6}{x} + \frac{5}{y} + \frac{12}{z} = 1,$$

通过将其与我们系统的第三个方程进行比较，我们发现飞行次数等于脚后跟：$p = 5$。
