两打
进展任务

要成功解决编程问题，您需要了解算术、几何和无限递减几何程序的定义，每个程序的承诺项的公式，程序的$n$项之和的公式，以及无限递减几何程序的项之和的定义和公式。此外，在编程问题中，很多时候需要使用程序的所谓特征。入学考试的经验表明，如果程序的$n$项与$n$项之和的公式情况比较好，那么特征属性就不能这么说了。因此，首先我们将关注这些属性。

算术程序的特征

序列 $a_1, a_2, \dots, a_n$, ... 是一个算术程序 moeda 和 molko moeda，当它的每个成员（除了第一个（以及最后一个，在有限序列的情况下）之外）都等于其邻居的算术平均值时。

证明。给定一个序列 $a_1, a_2, \dots, a_n$，... 让它成为一个算术程序。让我们证明$a_{k+1} = \frac{a_k + a_{k+2}}{2}$ ($k = 1, 2, 3, \dots$)。

事实上，$a_{k+1} - a_k = a_{k+2} - a_{k+1}$，从何而来$a_{k+1} = \frac{a_k + a_{k+2}}{2}$。

现在让$a_{k+1} = \frac{a_k + a_{k+2}}{2}$。那么$a_{k+1} - a_k = a_{k+2} - a_{k+1}$，即对于给定的序列，序列的后续成员和前一个成员之间的差异是恒定的，这意味着$a_1, a_2, \dots, a_n$，...是一个算术程序。

几何程序的特征

序列 $b_1, b_2, \dots, b_n$, ... 是一个几何规划 moeda 和 molko moeda，当它的每一项（除了第一项（以及最后一项，在有限序列的情况下）之外）都等于其相邻项（即 $b_2^{k+1} = b_k \cdot b_{k+2}$）的乘积。

证明。令序列 $b_1, b_2, \dots, b_n$, ... 为几何规划。那么$\frac{b_{k+1}}{b_k} = \frac{b_{k+2}}{b_{k+1}}$，由此而来的$b_2^{k+1} = b_k \cdot b_{k+2}$，这就是需要证明的。

相反，让$b_2^{k+1} = b_k \cdot b_{k+2}$。那么$\frac{b_{k+1}}{b_k} = \frac{b_{k+2}}{b_{k+1}}$，即给定序列的序列项与前一个常数的比值，这意味着$b_1, b_2, \dots, b_n$，...是一个几何规划。

算术级数

任务 1. 证明 $\frac{1}{a_1 a_2} + \frac{1}{a_2 a_3} + \dots + \frac{1}{a_n a_{n+1}} = \frac{n}{a_1 a_{n+1}}$。

解决方案。 $\frac{1}{a_1 a_2} = \frac{d}{a_1 a_2 d} = \frac{1}{d} \frac{a_2 - a_1}{a_1 a_2} = \frac{1}{d} \left( \frac{1}{a_1} - \frac{1}{a_2} \right)$。同样地

$$\frac{1}{a_2 a_3} = \frac{1}{d} \left( \frac{1}{a_2} - \frac{1}{a_3} \right), \dots, \frac{1}{a_n a_{n+1}} = \frac{1}{d} \left( \frac{1}{a_n} - \frac{1}{a_{n+1}} \right).$$

波兹尼

$$\frac{1}{a_1 a_2} + \frac{1}{a_2 a_3} + \dots + \frac{1}{a_n a_{n+1}} = \frac{1}{d} \left( \frac{1}{a_1} - \frac{1}{a_2} \right) +$$

$$+ \frac{1}{d} \left( \frac{1}{a_2} - \frac{1}{a_3} \right) + \dots + \frac{1}{d} \left( \frac{1}{a_n} - \frac{1}{a_{n+1}} \right) = \frac{1}{d} \left( \frac{1}{a_1} - \frac{1}{a_{n+1}} \right) =$$

$$= \frac{1}{d} \frac{a_{n+1} - a_1}{a_1 a_{n+1}} = \frac{1}{d} \frac{a_1 + dn - a_1}{a_1 a_{n+1}} = \frac{n}{a_1 a_{n+1}}.$$

任务 2. 序列 $u_1, u_2, \dots, u_n, \dots$ 具有以下属性：其前 $n$ 项的总和 $S_n$ 等于 $2n^2 + 3n$。证明这个数列是等差数列。

解决方案。利用算术级数的特征性质，我们得出结论，证明以下关系就足够了：$2u_{k+1} = u_k + u_{k+2}$，其中$k=1, 2, 3, \dots$。

我们注意到$u_{k+1} = S_{k+1} - S_k$。确实，$S_{k+1} - S_k = (u_1 + u_2 + \dots + u_k + u_{k+1}) - (u_1 + u_2 + \dots + u_k) = u_{k+1}$。方法，

$$u_{k+1} = [2(k+1)^2 + 3(k+1)] - (2k^2 + 3k) = 4k + 5.$$

类似地，$u_k = S_k - S_{k-1}$（特别是，我们假设$S_0 = 0$），因此$u_k = (2k^2 + 3k) - [2(k-1)^2 + 3(k-1)] = 4k + 1$，最后是$u_{k+2} = S_{k+2} - S_{k+1} = 4k + 9$。由于对于数字$u_k = 4k + 1$、$u_{k+1} = 4k + 5$、$u_{k+2} = 4k + 9$，分别满足$2u_{k+1} = u_k + u_{k+2}$，因此$u_1, u_2, \dots, u_n, \dots$是算术级数的证明是合法的。

任务 3. 证明关系 $\frac{S_n}{n} (m - p) + \frac{S_m}{m} (p - n) + \frac{S_p}{p} (n - m) = 0$ 对于算术级数成立。

解决方案。使用众所周知的 $S_n$ 公式 $S_n = \frac{a_1 + a_n}{2} n$ 以及$S_m$ 和 $S_p$ 的类似公式，我们将所证明的等式的左侧简化为以下形式

$$\frac{a_1 + a_n}{2} (m - p) + \frac{a_1 + a_m}{2} (p - n) + \frac{a_1 + a_p}{2} (n - m).$$

应用算术级数$a_n = a_1 + d(n-1)$到$a_n$的通项公式，并对$a_m, a_p$做同样的事情，我们得到

由于两个方括号中的和都等于0，那么整个表达式就等于0，这就是我们需要证明的。

任务 4：找到一个能被 45 整除且其数字构成等差数列的三位数。

解决方案e.令 $x$ 为所需数字的百位数字，$y$ 为十位数字，$z$ 为所需数字的个位数字。由于根据条件 $x, y, z$ 是算术级数，则

$$2y = x + z. \tag{1}$$

所需数字的形式为$100x + 10y + z$。由于根据条件它可以被 45 整除，那么

$$100x + 10y + z = 45p. \tag{2}$$

因此，所需的数量由条件（1）和（2）确定。

个位有两种可能：$z=0$ 或 $z=5$（这是根据所需数字能被 5 整除得出的）。考虑案例$z=0$。然后从（1）我们得到$x=2y$，从（2）我们得到$100x + 10y = 45p$，或$20x + 2y = 9p$，$20x + x = 9p$或$7x = 3p$。这意味着 $x$ 可以被 3 整除。此外，由于 $x$ 是偶数 ($x=2y$)，我们得出结论，$x$ 只有一种可能性：$x=6$。那么$y=3$，则所需数量为630。

现在让我们考虑第二种情况：$z=5$。在这种情况下，条件（1）和（2）采用相应的形式：

$$2y = x + 5; 100x + 10y + 5 = 45p.$$

最后一个等式转换为$20x + 2y + 1 = 9p$的形式，然后考虑等式$2y=x+5$，我们得到$21x+6=9p$或$7x+2=3p$。最后一个等式对于 $x=1, 4, 7$ 是可能的。但由于$x+5$是偶数（$x+5=2y$），$x$只剩下两种可能：$x=1, x=7$。第一种情况$y=3$，第二种情况$y=6$。第一种情况下所需的对应数为 135，第二种情况下为 765。因此，满足问题条件的是三个数：135、630、765。

**几何级数**

任务 5. 计算总和 $2 + 22 + 222 + \ldots + 222\ldots 2$

解决方案e. $2 + 22 + 222 + \ldots + 222\ldots 2 = 2[1 + (1+10) + (1+10+10^2) + \ldots + (1+10+10^2 + \ldots + 10^{n-1})] = 2[S_1 + S_2 + S_3 + \ldots + S_n]$，其中 $S_k$ 是几何级数 1、10、$10^2$、$10^3$、... ($k=1, 2, \ldots, n$) 的 $k$ 项之和。将公式$S_k = \frac{b_1(q^k - 1)}{q-1}$应用于几何级数的项之和，我们得到

任务 6. 证明序列 $u_1, u_2, u_3$，其中
$$u_1 = 9, \quad u_2 = 3^{\frac{1}{2}} \text{tg} x, \quad u_3 = \left(\frac{1}{9}\right)^{\cos 2x},$$
是几何级数当且仅当
$$x = \pi l, \quad x = \frac{\pi}{12} + \pi l, \quad x = \frac{5\pi}{12} + \pi l \quad (l = 0, \pm 1, \pm 2, \ldots).$$

解决方案。根据等比级数的特征性质，我们得出方程的求解性质问题
$$9^{\frac{1}{2}} \text{tg} x = 9\left(\frac{1}{9}\right)^{\cos 2x}$$

让我们对这个方程进行连续变换：
$$\frac{1}{2} \text{tg} x = 1 - \cos 2x,$$
$$\text{tg} x = 4 \sin^2 x, \quad \sin x (2 \sin 2x - 1) = 0 \quad (\cos x \neq 0).$$
因此，必须满足两个方程之一：
$$\sin x = 0, \quad \sin 2x = \frac{1}{2},$$

在哪里
$$x = \pi l, \quad x = \frac{\pi}{12} + \pi l, \quad x = \frac{5\pi}{12} + \pi l.$$

得到的级数只有它们满足方程(3)。因此，对于获得的值$x$并且仅对于它们$u_1, u_2, u_3$是几何级数。

任务 7. 数字 10、11、12 可以属于同一个等比级数吗？

解决方案和e。假设给定的数字是等比级数的项，第一项为$b_1$，分母为$q$。然后$10 = b_1 q^n, 11 = b_1 q^m, 12 = b_1 q^p$。从这些关系我们得到
$$\frac{11}{10} = q^{m-n}, \quad \frac{12}{10} = q^{p-n}$$

及以后
$$\left(\frac{11}{10}\right)^{p-n} = \left(\frac{12}{10}\right)^{m-n},$$
$$\frac{11^{p-n}}{12^{m-n}} = 10^{p-m}.$$

最后一个等式对于任何成对不同的自然数$n, m, p$都不能成立。这意味着数字 10、11、12 不能是同一等比级数的成员。

任务8.无限杀几何级数的项之和为9，其项的平方和为40.5。找出级数的第一项和能指。

解决方案。使用公式$S = \frac{b_1}{1-q}$求无限杀戮几何级数的项之和，我们得到$\frac{b_1}{1-q} = 9$。

考虑序列$b_1^2, b_2^2, \ldots, b_n^2, \ldots$。请注意，这是一个无限致命的几何级数，其中第一项为$b_1^2$，值为$q^2$。那么这个级数的项之和由公式 $\frac{b_1^2}{1-q^2}$ 确定，等于 40.5。

结果，问题归结为解决系统

$$\frac{b_1}{1-q} = 9, \quad \frac{b_1^2}{1-q^2} = 40,5.$$

从这个系统我们得到：$b_1 = 6, \quad q = \frac{1}{3}$。

混合进展问题

任务 9：已知偶数，前三个是等比数列，后三个是等差数列，极端数之和为 21，中间数之和为 18。

解决方案。设$a, b, c, d$为原数； $a, b, c$是等比级数，即$b^2=ac$； $b, c, d$是等差数列，所以$2c=b+d$。结果，我们得到以下方程组：

$$\begin{cases}
b^2=ac, \\
2c=b+d, \\
a+d=21, \\
b+c=18.
\end{cases}$$

求解这个系统，我们得到 $a=3, b=6, c=12, d=18$ 或

$$a = \frac{75}{4}, \quad b = \frac{45}{4}, \quad c = \frac{27}{4}, \quad d = \frac{9}{4}.$$

任务 10. 当数字形成等比级数时。如果第二个数字加 2，则所得数字形成等差数列。如果你将第三个数字增加 9，你将再次得到几何级数。找到这些数字。

解决方案。我们将问题的条件重写如下：

$$b_1, b_2, b_3 \text{ — геометрическая прогрессия;}$$
$$b_1, b_2+2, b_3 \text{ — арифметическая прогрессия;}$$
$$b_1, b_2+2, b_3+9 \text{ — геометрическая прогрессия.}$$

利用级数的特征，我们得到

$$\begin{cases}
2(b_2+2) = b_1+b_3, \\
(b_2+2)^2 = b_1(b_3+9).
\end{cases}$$
