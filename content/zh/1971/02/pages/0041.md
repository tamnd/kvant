应用算术级数$a_n = a_1 + d(n-1)$到$a_n$的通项公式，并对$a_m, a_p$做同样的事情，我们得到

$$\frac{1}{2} \left\{ [2a_1 + d(n-1)] (m-p) + [2a_1 + d(m-1)] (p-n) + [2a_1 + d(p-1)] (n-m) \right\}$$

及以后

$$\frac{1}{2} \left\{ 2a_1 [(m-p) + (p-n) + (n-m)] + d [(n-1)(m-p) + (m-1)(p-n) + (p-1)(n-m)] \right\}.$$

由于两个方括号中的和都等于0，那么整个表达式就等于0，这就是我们需要证明的。

任务 4：找到一个能被 45 整除且其数字构成等差数列的三位数。

解决方案e.令 $x$ 为所需数字的百位数字，$y$ 为十位数字，$z$ 为所需数字的个位数字。由于根据条件 $x, y, z$ 是算术级数，则

$$2y = x + z. \tag{1}$$

所需数字的形式为$100x + 10y + z$。由于根据条件它可以被 45 整除，那么

$$100x + 10y + z = 45p. \tag{2}$$

因此，所需的数量由条件（1）和（2）确定。

个位有两种可能：$z=0$ 或 $z=5$（这是根据所需数字能被 5 整除得出的）。考虑案例$z=0$。然后从（1）我们得到$x=2y$，从（2）我们得到$100x + 10y = 45p$，或$20x + 2y = 9p$，$20x + x = 9p$或$7x = 3p$。这意味着 $x$ 可以被 3 整除。此外，由于 $x$ 是偶数 ($x=2y$)，我们得出结论，$x$ 只有一种可能性：$x=6$。那么$y=3$，则所需数量为630。

现在让我们考虑第二种情况：$z=5$。在这种情况下，条件（1）和（2）采用相应的形式：

$$2y = x + 5; 100x + 10y + 5 = 45p.$$

最后一个等式转换为$20x + 2y + 1 = 9p$的形式，然后考虑等式$2y=x+5$，我们得到$21x+6=9p$或$7x+2=3p$。最后一个等式对于 $x=1, 4, 7$ 是可能的。但由于$x+5$是偶数（$x+5=2y$），$x$只剩下两种可能：$x=1, x=7$。第一种情况$y=3$，第二种情况$y=6$。第一种情况下所需的对应数为 135，第二种情况下为 765。因此，满足问题条件的是三个数：135、630、765。
