根据已证明的不等式，随着 $n$ 的增加，$P_n$ 值趋于零，$P_n \sqrt{n}$ 值介于 $\frac{1}{2}$ 和 $\frac{1}{2} \sqrt{\frac{3}{2}}$ 之间。可以证明（例如，参见 A. M. Yaglom 和 I. M. Yaglom 所著的《Non-elementary issues in anelementarypresentation》，GITTL, M., 1954 中的问题 145, 160, 161），$n \to \infty$ $P_n$ 趋向于等于 $\sqrt{\frac{1}{\pi}}$ 的极限。

**M24**

证明任何分数 $\frac{m}{n}$，其中 $0 < \frac{m}{n} < 1$，都可以表示为

$$\frac{m}{n} = \frac{1}{q_1} + \frac{1}{q_2} + \frac{1}{q_3} + \dots + \frac{1}{q_r},$$

其中 $0 < q_1 < q_2 < \dots < q_r$ 是整数，每个 $q_k$ ($k=2, 3, \dots, r$) 可被 $q_{k-1}$ 整除。

哪个分数 $\frac{m}{n}$ 可以整除，分母除以它们的最公约数，并用等于它的不可约分数代替。例如，$\frac{288}{504} = \frac{4.72}{7.72} = \frac{4}{7}$。接下来我们将只考虑这样的不可约分数。

让我们通过对 $m$ 的归纳来证明问题的陈述。对于 $m=1$ 来说，很明显：分数 $\frac{m}{n}$ 本身已经具有所需的形式。现在我们将证明，如果问题的陈述对于所有分子小于 $m$ 的分数都成立，那么对于分子等于 $m$ 的分数也成立。令 $\frac{m}{n}$ 为这样的分数 ($1 < m < n$)。将 $n$ 除以 $m$ 余数；你得到商（$d_0-1$）和余数（$m-k$），即

$$n = m (d_0-1) + (m-k) = md_0-k,$$

其中$d_0 > 1$和$0 < k < m$。让我们像这样重写 (1)：$md_0=n+k$，或者

$$\frac{m}{n} = \frac{1}{d_0} \left( 1 + \frac{k}{n} \right).$$

由于$0 < k < m$，分数$\frac{k}{n}$可以用所需的形式表示：

$$\frac{k}{n} = \frac{1}{d_1} + \frac{1}{d_1 d_2} + \dots + \frac{1}{d_1 d_2 \dots d_r},$$

其中$d_1, d_2, \dots, d_r$是一些大于1的自然数。从(2)和(3)我们得到

$$\frac{m}{n} = \frac{1}{d_0} + \frac{1}{d_0 d_1} + \frac{1}{d_0 d_1 d_2} + \dots + \frac{1}{d_0 d_1 d_2 \dots d_r}.$$

分数$\frac{m}{n}$以所需的形式呈现。

请注意，从我们对问题的解决方案中，不难提取出一个简单的算法 - 如何将任何给定分数表示为和 (3) 的规则。让我们用一个例子来演示一下。让我们得到分数 $\frac{5}{7}$：

$$7 = 2.5 - 3; \quad \frac{5}{7} = \frac{1}{2} \left( 1 + \frac{3}{7} \right);$$

$$7 = 3.3 - 2; \quad \frac{3}{7} = \frac{1}{3} \left( 1 + \frac{2}{7} \right);$$

$$7 = 4.2 - 1; \quad \frac{2}{7} = \frac{1}{4} \left( 1 + \frac{1}{7} \right).$$
