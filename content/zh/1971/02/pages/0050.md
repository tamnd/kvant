我们将这个差异重写为形式
$(x - y)(x + y + 1) = 0$
我们发现所需的轨迹由两条直线组成：$x - y = 0, x + y + 1 = 0$，如图 1所示。如果我们想用代数表达答案，那么我们将这些直线的方程写成$y = x$和$y = -x - 1$的形式。那么$z$所需的值将由两个等式给出：$z = (1 + i)x$或$z = x - (x + 1)i$。

申请人——通常试图解决这个例子的人——提出了这种方式，而不是这种合乎逻辑且几乎无需计算的解决方案。让我们把 $z^2 + (1 + i)z = bi$;右边$bi$是最小数。现在我们求解二次方程：

$$z = \frac{-(1 + i) \pm \sqrt{2i + 4bi}}{2}.$$

从某种意义上说，解决这个问题的方法是对等式的右边进行变换，这涉及到提取最小数的平方根；他们未能果断地应对这一问题，但正如我们所看到的，通过更成功的方法来完成这项任务，这是不需要的。
