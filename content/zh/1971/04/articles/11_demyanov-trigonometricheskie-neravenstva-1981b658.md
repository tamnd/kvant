我们将包含未知 $x$ 的三角不等式称为三角不等式，它是三角函数参数的一部分。解决三角不等式意味着一如既往地找到满足该不等式的所有未知值。

解决最简单的三角不等式不需要学校课程之外的任何特殊知识。即，在下面讨论的例子中，除了三角函数的性质外，仅使用了数的绝对值的概念（例4）、求解二次不等式的规则（例5-8）和对数函数的性质（例9、例10）。这些信息足以应对文章末尾给出的独立解决方案的示例。

然而，从一开始就必须注意一个基本点。在三角不等式中，三角函数的参数不被视为角度或弧，而是被视为实数。由于经验表明，许多高中毕业生对这个问题还没有完全清楚，让我们更详细地讨论一下。建议当前申请人在这方面仔细考虑以下内容。

一般来说，三角函数首先作为角度（更准确地说，甚至只是锐角）的函数引入。然后三角函数的参数的概念得到扩展 - 他们开始考虑弧函数。事实证明，不限制一圈内包含的弧（即具有从 $0^\circ$ 到 $360^\circ$ 的值），而是考虑其大小由任意度数（正数和负数）表示的弧是很方便的。有了对这个论证的理解，三角函数就变成了周期性的。下一步是从弧度测量转向弧度测量。最后，他提出了第 6 个数字的三角函数的概念。即，一个数的三角函数的值被理解为该弧的给定函数的值，其以弧度表示的值由该数表示。

在物理学中，数值参数的三角函数在描述各种周期性过程（即其特征以一定间隔完全重复的过程）时自然出现。这就是为什么在数学中建议考虑数值参数的三角函数。事实上，当我们构建三角函数图时，我们已经这样做了。事实上，我们沿着横坐标轴绘制实数的值。

示例 1. 求解不等式 $tg x < 1$。

解决方案。首先，我们将展示如何不“解决”这种不平等，也就是说，我们将分析该问题的一些错误答案。

另一位申请人注意到$tg \frac{\pi}{4} = 1$并且在值$x = \frac{\pi}{4}$附近函数$tg x$随着$x$的增加而增加，将答案写成以下形式：$x < \frac{\pi}{4}$。从答案的出现来看，我们可以说它是不正确的，因为它没有反映函数$y = tg x$的周期性。很容易指出满足条件$x < \frac{\pi}{4}$但不满足给定不等式的$x$的具体值。例如，对于$x = -\frac{2\pi}{3}$，我们有：$-\frac{2\pi}{3} < \frac{\pi}{4}$，但是$tg\left(-\frac{2\pi}{3}\right) = \sqrt{3} > 1$；在$x = -\frac{\pi}{2}$，不等式的谎言部分没有意义，因此，该值也不满足不等式，尽管再次$-\frac{\pi}{2} < \frac{\pi}{4}$。

也有申请人试图考虑频率，但同时又表现出无奈。也就是说，“答案”通常以以下形式给出：$x < \frac{\pi}{4} + k\pi$，其中$k = 0, \pm 1, \pm 2, \dots$。

这个“答案”更糟糕，因为它根本没有意义。很容易验证，对于所有$k = 0, \pm 1, \pm 2, \dots$，根本不存在满足条件$x < \frac{\pi}{4} + k\pi$的数字$x$。

为了得到正确的答案，考虑函数 $y = tg x$ (图 1) 的图形很有用，因为这将使推理在几何上更加清晰。

不等式 $tg x < 1$ 由那些且仅那些图形的对应点位于虚线水平线 $y = 1$ 下方的值 ​​$x$ 满足。此外，从图 1 可以清楚地看出，如果我们找到属于某个长度为$x$的特定区间的所有解，那么所有其他解将与通过向右或向左移动$\pi, 2\pi, 3\pi$等找到的解不同。其原因是数字$x$是函数$y = tg x$的周期。

为了尽可能简短地写下答案，建议选择长度为 $l$ 的初始区间，以便属于它的解依次填充某个连续区间。从图再次清楚地看出，如果例如从$-\frac{\pi}{2}$到$\frac{\pi}{2}$的间隔被视为初始间隔，则情况将会如此。在下面的示例 $y = 1$ 的这个区间上，图中的那些点对应于满足不等式 $-\frac{\pi}{2} < x < \frac{\pi}{4}$ 的值$x$。因此最终的答案是
$$-\frac{\pi}{2} + k\pi < x < \frac{\pi}{4} + k\pi$$
($k = 0, \pm 1, \pm 2, \dots$).

因此，答案是一组间隔，每个间隔都是以某个固定值$k$获得的。

所有其他示例的答案中的情况都是类似的。

示例 2：解决不等式
$$\sin x \geq -\frac{1}{2}.$$

解决方案。考虑函数的图形 $y = \sin x$ (图 2）。不等式 $\sin x \geq -\frac{1}{2}$ 满足这些值 $x$，图形的对应点不位于虚线下方 $y = -\frac{1}{2}$ （如果图点位于这条线上，则该值 $x$ 满足给定的不等式，因为它“不严格”，它允许左侧和右侧相等）。功能 $y = \sin x$ 有一个时期 $2\pi$。因此，我们首先考虑一些长度区间 $2\pi$，例如间隔 $-\frac{\pi}{2}$ 到 $\frac{3\pi}{2}$。从 图 2 显然不等式 $\sin x \geq -\frac{1}{2}$ 在此区间内满足以下值 $x$: $-\frac{\pi}{6} \leq x \leq \frac{7\pi}{6}$.

考虑到周期性，我们得到答案：
$$-\frac{\pi}{6} + 2k\pi \leq x \leq \frac{7\pi}{6} + 2k\pi$$
($k = 0, \pm 1, \pm 2, \dots$).

示例 3. 解决不等式
$$\cos(3x + 2) > -\frac{\sqrt{2}}{2}.$$

解决方案。让我们引入辅助未知数$t = 3x + 2$。那么对于$t$，我们得到不等式$\cos t > -\frac{\sqrt{2}}{2}$。由于它与示例 1 和 2 中的不等式完全相似（要解决它，您可以考虑函数 $y = \cos t$ 的图形），我们立即回答 $t$：
$$-\frac{3\pi}{4} + 2k\pi < t < \frac{3\pi}{4} + 2k\pi$$
($k = 0, \pm 1, \pm 2, \dots$).

示例 4. 解决不等式
$$|\sin x| > \frac{\sqrt{3}}{2}$$.

解决方案。将我们自己从横轴符号中解放出来，我们得到给定的不等式将由那些且仅那些满足不等式之一的 $x$ 值来满足
$$\sin x > \frac{\sqrt{3}}{2}, \sin x < -\frac{\sqrt{3}}{2}$$.

$$\frac{\pi}{3} + 2k\pi < x < \frac{2\pi}{3} + 2k\pi$$
($k = 0, \pm 1, \pm 2, \dots$),

此外，对于偶数$n$，我们获得第一个级数的积分，对于奇数$n$，我们获得第二级数的积分。

示例 8. 求解不等式 $12\sin^2 x - 19\sin x + 5 < 0$。

解决方案。通过删除$y = \sin x$，我们得到二次不等式$12y^2 - 19y + 5 < 0$，由此得到$\frac{1}{3} < y < \frac{5}{4}$。因此未知的$x$必须满足所有十六进制值​​$x$。因此，实际上只需要求解第二个不等式$\sin x > \frac{1}{3}$。很容易验证以下$x$的值满足它：
$$2k\pi + \text{arcsin} \frac{1}{3} < x < (2k + 1)\pi - \text{arcsin} \frac{1}{3}$$
