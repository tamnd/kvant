入学考试
数学方面
在MIEM
VA东彦

在莫斯科电子工程学院，数学考试对构建者提出了更高的要求。所有申请人的第一项考试是数学笔试。

我们已经在《量子》（1970年第5期）的页面中讨论了与1969年数学笔试有关的一些问题。这里我想谈谈1970年的考试。

下面是对一个选项的分析，指出了考试结构中最典型的错误。

最后会有一个1970年笔试的任务。

选项

1. 给定两个三角形，每个三角形的面积均为 50 cm²。第一个的底部比第二个的底部大 10 厘米。在每个限制内，是否可以更改第一个三角形的底边，以使三角形的高度差至少为 5/6 厘​​米？

2. 解方程

$$\sqrt{\frac{x^2+66^2}{x}} - \sqrt{x \sqrt{x^2+66^2}-x^2} = 5.$$

3. 解决不平等问题

$$\log \frac{1}{5} \sqrt{x^3+x^2+x-14} \log \frac{1}{4} (-x^2 + 5x - 6) < 0.$$

4. 解方程

$$\sqrt{3+2(2\sin x-\cos 2x)} + \sqrt{3-2(2\sin x+\cos 2x)} = 2.$$

5. 例如，其底面为锐角α的菱形，内接半径为R的球。示例的侧面以角度β倾斜于基底平面。查找体积示例。

变体任务分析

1. 让我们用 x 表示第一个三角形的底，那么第二个三角形的底将为 x−10，因此 x > 10。 (1)

第一个三角形的高度为 $$\frac{50}{x/2} = \frac{100}{x},$$，第二个三角形的高度为 $$\frac{100}{x-10}.$$

根据问题的条件，考虑到我们写的是$$\frac{100}{x-10} > \frac{100}{x},$$$$\frac{100}{x-10} - \frac{100}{x} \geq \frac{5}{6},$$并记住条件(1)，我们将其变换如下：

$$x^2 - 10x - 1200 \leq 0,$$ (2)

或者
$(x+30)(x-40) \leq 0,$
在哪里
$-30 \leq x \leq 40.$
如果我们现在考虑约束条件 (1)，我们会得到答案：$10 < x \leq 40.$
一些解决这个问题的申请人没有考虑字母$x$表示的是什么，并给出了不等式（2）的解作为答案。
2. 让我们引入新的未知数。让我们把
$$u = \sqrt{\frac{\sqrt{x^2+66^2}+x}{x}},$$
$$v = \sqrt{x\sqrt{x^2+66^2}-x^2}.$$
那么这个方程将被重写为以下形式
$$u-v = 5.$$ (1)
现在让我们注意到
$$u \geq 0, \quad v \geq 0$$ (2)
和
$$uv = \sqrt{\frac{\sqrt{x^2+66^2}+x}{x}} \times \sqrt{x\sqrt{x^2+66^2}-x^2} = \sqrt{(\sqrt{x^2+66^2}+x)}\sqrt{\sqrt{x^2+66^2}-x} = \sqrt{x^2+66^2}-x^2 = 66.$$
最后一个方程与 (1) 和 (2) 一起给出了一个混合系统
$$\begin{cases} uv = 66, \\ u-v = 5, \\ u \geq 0, \quad v \geq 0, \end{cases}$$
可以重写如下：
$$\begin{cases} u(-v) = -66, \\ u+(-v) = 5, \\ u \geq 0, \quad v \geq 0. \end{cases}$$
让我们回顾一下 Vieta 公式，并将 $u$ 与方程 $x^2-5x-66 = 0$ 的正根重合。因此，
$$u = \sqrt{\frac{\sqrt{x^2+66^2}+x}{x}} = 11,$$
在哪里
$$\sqrt{x^2+66^2}+x = 121x,$$
因此，
$$\sqrt{x^2+66^2} = 120x.$$
这表明$x \geq 0$。平方，我们得到方程
$$x^2+66^2 = 120^2x^2,$$ (3)
它来自哪里：
$$x = \frac{6}{\sqrt{119}}.$$
我们通过执行等效（受指定限制）转换找到了这个根，然后就不需要检查了。许多申请者都完成了这项任务，但也有许多作品的答案包含了根的构造，例如方程（3）的负根。
让我们再次提醒您：如果在求解方程时进行了非等价变换，那么检查找到的根是解决问题的一个组成部分，如果没有这种验证，解就不能被认为是正确的。
3. 有效值仅是$x$的那些值，其中$-x^2+5x-6 > 0$，即$2 < x < 3$，然后是$4 < x^2 < 9$和$8 < x^3 < 27$，因此$14 < x^3+x^2+x < 39$和$0 < x^3+x^2+x-14 < 25$。找到第一个对数的底数
$$0 < \frac{1}{5}\sqrt{x^3+x^2+x-14} < 1.$$
因此，
$$\log_{\frac{1}{4}}(-x^2+5x-6) > 1,$$
从那里我们得到答案：$2 < x < 2,5$或$2,5 < x < 3$。
4. 我们来变换一下第一个部首下的表达式：
$$3+2 \quad (2\sin x-\cos 2x) = 3+4\sin x + 4\sin^2x-2 = (2\sin x+1)^2,$$
类比的
$$3-2 (2\sin x+\cos 2x) = (2\sin x-1)^2.$$

5. 内切球 (图 1) 的中心$O'$是与参数的所有边等距的点，因此它位于参数的角度的所有两个边界的二等分平面的交点处。由于菱形的对角线是其内角的二等分线，因此穿过高度和对角线的平面是侧边处的二角角的二等分线（请自行检查）。根据条件，面与底相等，因此菱形$O'$对角线的交点就是高度$SO$的底。因此，球的中心$O'$位于参数的高度处。从$O'$点到参数横向边界的垂线位于经过高度$SO$和底高$FE$的平面内（FE经过点$O$），这很容易从三垂线定理推导出来。现在从直角三角形 $SOE$ ($O'O = O'O'' = R$, $\Rightarrow SEO = \alpha$) 我们发现
$$SO = OE \mathrm{tg} \beta = R \mathrm{tg} \beta \mathrm{ctg} \frac{\beta}{2}.$$
高度参数已经找到，剩下来确定底座的面积。
从直角三角形 $OO'E$ ($OO' = R$, $\Rightarrow O'EO = \frac{\beta}{2}$) 我们发现
$$OE = OO' \mathrm{ctg} \frac{\beta}{2} = R \mathrm{ctg} \frac{\beta}{2}.$$
接下来我们替换它
$$CD = \frac{FE}{\sin \alpha},$$
因此
$$S_{\text{ромба}} = \frac{FE^2}{\sin \alpha} = \frac{4OE^2}{\sin \alpha} = \frac{4R^2 \mathrm{ctg}^2 \frac{\beta}{2}}{\sin \alpha}.$$
对于体积参数我们得到最终的答案：
$$V = \frac{4}{3} R^3 \frac{\mathrm{ctg}^3 \frac{\beta}{3} \mathrm{tg} \beta}{\sin \alpha}.$$

关于口语考试的一些小知识

MIEM 的口语考试将根据门票进行。每张票包含两道理论题，严格按照申请考试大纲进行。每位考生大约需要 45 分钟来准备答案。在他回答了票上的问题后，他会收到票上未包含的理论和问题部分的附加问题，以测试他应用理论解决问题的能力。这些任务通常不需要计算。以下是此类问题和任务的示例以及一些评论。

1. 如果我们将两个周期小数相加，它们的和会再次成为周期小数吗？

通常正确的答案是：“是的，会的，因为周期小数是有理数，并且两个有理数之和也是有理数。”

这通常是正确的；只需要规定不仅可以得到周期小数，还可以得到有限小数，例如：0，(3)+0，(6)=1，因为$\frac{1}{3} + \frac{2}{3} = 1$。

下一个问题变得更加困难。

2. 如果第一个分数有 p 位数字的周期，第二个 q 位数字的周期，那么它们的和可以有什么周期？

通常，如果没有额外的帮助，申请人很难给出正确的答案。同时，对于“如果周期f(x)等于2π，周期g(x)等于3π，函数f(x)+g(x)的周期是多少？”的问题申请者通常给出正确答案：“6π”。同时，这两个问题本质上都与算术的同一部分相关：最小公倍数（LCM）和最大公约数（GCD）。原问题的正确答案是：总和的周期不超过数字p和q的最小公倍数。

我们邀请读者自己看几个例子，当总和的周期恰好等于最小公倍数时，以及当它小于这个公倍数时。

更困难的是两个周期小数的乘积的周期问题，其中第一个周期小数有 p 位，第二个有 q​​ 位。

我们只给出答案：乘积的周期不超过m(10^n−1)，其中m是数字p和q的最小公倍数，n是它们的GCD。考虑这个例子：0, (1)×0, (1) = 0, (012345679);这里p = q = 1，乘积的周期是9位。

3. 给定：tan α = a, $\frac{3\pi}{2} < \alpha < 2\pi$。

求 sin α。

我不止一次看到过这个例子的这样的“解决方案”。普谢特到达：

$$\sin^2 \alpha = \frac{1}{1 + \text{ctg}^2 \alpha},$$

在哪里

$$\sin \alpha = -\sqrt{\frac{1}{1 + \text{ctg}^2 \alpha}}$$

$$= -\sqrt{\frac{a^2}{1 + a^2}} = -\frac{a}{\sqrt{1 + a^2}},$$

并且只有在替换后，如果最后一个等式为真，则 IV 季度的 sin α 有正号，申请人才开始寻找解决方案中的错误。

4. 确定差异的符号

$$\left(\frac{3}{8}\right)^2 \sqrt{2} - 1.$$

这个问题提出了一个问题：$2^{\sqrt{3}}$是什么？许多详细讨论指数函数性质的申请人无法回答这个问题。

5. 求解方程$x^4 - 10x^2 + 169 = 0$。

显然让解决方案是这样的。

让我们用y表示$x^2$，然​​后我们得到方程$y^2 - 10y + 169 = 0$，其根是复数。为了确定x，考生继续推理，我们需要提取一个复数的根，而学校课程中没有规定这个动作。在此基础上，一些申请人得出这样的结论：入学考试提供的问题是只懂学校数学课程的人无法解决的。这个结论正确吗？是否有可能得出这样的结论，以代替仅仅使用高中没有学过的方法可以解决某些问题？难道不表明

这样一个关于其作者的微不足道的结论，以至于并非所有相反的陈述都是正确的？

然而，让我们回到我们的双二次方程。
$$x^4 + 2 \cdot 13 \cdot x^2 + 169 - 36x^2 = 0,$$
在哪里
$$(x^2 + 13)^2 - 36x^2 = 0,$$
这导致两个具有实数系数的二次方程：
$$x^2 - 6x + 13 = 0, \quad x^2 + 6x + 13 = 0.$$

试证明用上述方法表示的任意二次方程$x^4 + px^2 + q = 0$，其中$p^2 - 4q < 0$都可以化简为两个具有实数系数的二次方程。

6. 让我们画一个函数 $y = \arcsin(\sin x)$ 的图形。

该函数定义在区间 $-\infty < x < \infty$ 上。由于函数$z = \sin x$的周期性，函数$y = \arcsin z$也是周期性的，周期为$2\pi$，研究它就足够了，例如在线段$[-\frac{\pi}{2}, 3\pi/2]$上。

在线段 $[-\pi/2, \pi/2]$ sin $y = \sin x$ 和 $y = x$ 上；如果 $\frac{\pi}{2} \leq x \leq \frac{3\pi}{2}, -\frac{\pi}{2} \leq \pi - x \leq \frac{\pi}{2}$ 并且根据等式 sin $(\pi - x) = \sin x$ 可以得出 $y = \pi - x$。最终的图如图2所示。
