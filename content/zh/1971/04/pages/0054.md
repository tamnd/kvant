2. 让我们引入新的未知数。让我们把
$$u = \sqrt{\frac{\sqrt{x^2+66^2}+x}{x}},$$
$$v = \sqrt{x\sqrt{x^2+66^2}-x^2}.$$
那么这个方程将被重写为以下形式
$$u-v = 5.$$ (1)
现在让我们注意到
$$u \geq 0, \quad v \geq 0$$ (2)
和
$$uv = \sqrt{\frac{\sqrt{x^2+66^2}+x}{x}} \times \sqrt{x\sqrt{x^2+66^2}-x^2} = \sqrt{(\sqrt{x^2+66^2}+x)}\sqrt{\sqrt{x^2+66^2}-x} = \sqrt{x^2+66^2}-x^2 = 66.$$
最后一个方程与 (1) 和 (2) 一起给出了一个混合系统
$$\begin{cases} uv = 66, \\ u-v = 5, \\ u \geq 0, \quad v \geq 0, \end{cases}$$
可以重写如下：
$$\begin{cases} u(-v) = -66, \\ u+(-v) = 5, \\ u \geq 0, \quad v \geq 0. \end{cases}$$
让我们回顾一下 Vieta 公式，并将 $u$ 与方程 $x^2-5x-66 = 0$ 的正根重合。因此，
$$u = \sqrt{\frac{\sqrt{x^2+66^2}+x}{x}} = 11,$$
在哪里
$$\sqrt{x^2+66^2}+x = 121x,$$
因此，
$$\sqrt{x^2+66^2} = 120x.$$
这表明$x \geq 0$。平方，我们得到方程
$$x^2+66^2 = 120^2x^2,$$ (3)
它来自哪里：
$$x = \frac{6}{\sqrt{119}}.$$
我们通过执行等效（受指定限制）转换找到了这个根，然后就不需要检查了。许多申请者都完成了这项任务，但也有许多作品的答案包含了根的构造，例如方程（3）的负根。
让我们再次提醒您：如果在求解方程时进行了非等价变换，那么检查找到的根是解决问题的一个组成部分，如果没有这种验证，解就不能被认为是正确的。
3. 有效值仅是$x$的那些值，其中$-x^2+5x-6 > 0$，即$2 < x < 3$，然后是$4 < x^2 < 9$和$8 < x^3 < 27$，因此$14 < x^3+x^2+x < 39$和$0 < x^3+x^2+x-14 < 25$。找到第一个对数的底数
$$0 < \frac{1}{5}\sqrt{x^3+x^2+x-14} < 1.$$
因此，
$$\log_{\frac{1}{4}}(-x^2+5x-6) > 1,$$
从那里我们得到答案：$2 < x < 2,5$或$2,5 < x < 3$。
