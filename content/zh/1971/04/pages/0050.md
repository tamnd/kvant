$\frac{\pi}{4} \leq x \leq \frac{\pi}{3}$。考虑到周期性，我们得到最终答案：
$$\frac{\pi}{4} + k\pi \leq x \leq \frac{\pi}{3} + k\pi$$
($k = 0, \pm 1, \pm 2, \dots$).

到目前为止分析的所有示例都是经过选择的，以便答案包含像 $\frac{\pi}{6}, \frac{\pi}{4}, \frac{\pi}{3}$ 这样的参数的“圆形”值。

然而，原则上这完全没有必要，因为答案总是可以使用反三角函数的符号来写。要使用它，请考虑一个与示例 6 仅在数值系数值上不同的示例。

示例 7. 求解不等式 $\text{tg}^2 x - 5\text{tg} x + 6 \leq 0$。

解决方案。按照例 6 的方式逐字推理，我们得到不等式系统
$$\begin{cases} \text{tg} x \leq 3, \\ \text{tg} x \geq 2. \end{cases}$$

答案现在将写成以下形式
$$k\pi + \text{arctg} 2 \leq x \leq k\pi + \text{arctg} 3$$
($k = 0, \pm 1, \pm 2, \dots$).

示例 8. 求解不等式 $12\sin^2 x - 19\sin x + 5 < 0$。

解决方案。通过删除$y = \sin x$，我们得到二次不等式$12y^2 - 19y + 5 < 0$，由此得到$\frac{1}{3} < y < \frac{5}{4}$。因此未知的$x$必须满足所有十六进制值​​$x$。因此，实际上只需要求解第二个不等式$\sin x > \frac{1}{3}$。很容易验证以下$x$的值满足它：
$$2k\pi + \text{arcsin} \frac{1}{3} < x < (2k + 1)\pi - \text{arcsin} \frac{1}{3}$$
($k = 0, \pm 1, \pm 2, \dots$).

这是给定不等式的最终答案。如果在不等式$\sin x < \frac{5}{4}$的情况下，“表达式”$\text{arcsin} \frac{5}{4}$出现在“答案”中，那将是一个非常严重的错误。从$\frac{5}{4} > 1$开始，符号$\text{arcsin} \frac{5}{4}$就没有意义了。
