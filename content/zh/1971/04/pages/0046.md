⟦folio 44⟧

STV，我们先从最简单的例子开始。

示例 1. 求解不等式 $tg x < 1$。

解决方案。首先，我们将展示如何不“解决”这种不平等，也就是说，我们将分析该问题的一些错误答案。

另一位申请人注意到$tg \frac{\pi}{4} = 1$并且在值$x = \frac{\pi}{4}$附近函数$tg x$随着$x$的增加而增加，将答案写成以下形式：$x < \frac{\pi}{4}$。从答案的出现来看，我们可以说它是不正确的，因为它没有反映函数$y = tg x$的周期性。很容易指出满足条件$x < \frac{\pi}{4}$但不满足给定不等式的$x$的具体值。例如，对于$x = -\frac{2\pi}{3}$，我们有：$-\frac{2\pi}{3} < \frac{\pi}{4}$，但是$tg\left(-\frac{2\pi}{3}\right) = \sqrt{3} > 1$；在$x = -\frac{\pi}{2}$，不等式的谎言部分没有意义，因此，该值也不满足不等式，尽管再次$-\frac{\pi}{2} < \frac{\pi}{4}$。

也有申请人试图考虑频率，但同时又表现出无奈。也就是说，“答案”通常以以下形式给出：$x < \frac{\pi}{4} + k\pi$，其中$k = 0, \pm 1, \pm 2, \dots$。

这个“答案”更糟糕，因为它根本没有意义。很容易验证，对于所有$k = 0, \pm 1, \pm 2, \dots$，根本不存在满足条件$x < \frac{\pi}{4} + k\pi$的数字$x$。

为了得到正确的答案，考虑函数 $y = tg x$ (图 1) 的图形很有用，因为这将使推理在几何上更加清晰。

不等式 $tg x < 1$ 由那些且仅那些图形的对应点位于虚线水平线 $y = 1$ 下方的值 ​​$x$ 满足。此外，从图 1 可以清楚地看出，如果我们找到属于某个长度为$x$的特定区间的所有解，那么所有其他解将与通过向右或向左移动$\pi, 2\pi, 3\pi$等找到的解不同。其原因是数字$x$是函数$y = tg x$的周期。
