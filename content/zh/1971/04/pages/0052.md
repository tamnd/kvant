⟦folio 50⟧

满足以下$x$取值：首先，$1 < x < \frac{\pi}{2}$，其次
$$\frac{\pi}{4} + k\pi < x < \frac{\pi}{2} + k\pi$$
其中$k$为正整数，即$k = 1, 2, 3, \dots$。

收集考虑这两种情况时发现的所有$x$值，我们得到以下最终答案：

$$0 < x_1 < \frac{\pi}{4},$$
$$1 < x_2 < \frac{\pi}{2},$$
$$\frac{\pi}{4} + k\pi < x_3 < \frac{\pi}{2} + k\pi$$
($k = 1, 2, 3, \dots$).

总之，我们提供了许多独立解决方案的示例。

解决不等式：

1. $\cos x \geq \frac{1}{2}$.
2. $\sin 2x < \frac{1}{\sqrt{2}}$.
3. $\sin \frac{x}{5} \geq -\frac{1}{2}$.
4. $\lg(3x - 1) < \frac{1}{\sqrt{3}}$.
5. $|\lg x| \geq \sqrt{3}$.
6. $|\cos x| < \frac{1}{2}$.
7. $\sin^2 x < \frac{1}{4}$.
8. $\lg^2 x \geq \frac{1}{3}$.
9. $2\sin^2 x \leq \sin x$.
10. $2\cos^2 x + \cos x < 1$.
11. $\log_3(\lg x) \geq \frac{1}{2}$.
12. $\log_{\frac{1}{2}}(\cos x) \leq 1$.

风暴对抗风暴

一百多年前，发生了一场风暴，为世界创造了气象服务。

1854年11月14日，一场猛烈的风暴给参加围攻塞瓦斯托波尔的法国人和他们的战友造成了无法挽回的损失。法国得知此事后，感到非常沮丧。

巴黎天文台台长勒维耶得知巴拉克拉瓦湾风暴的消息后，要求当时从事气象观测的科学家向他提供前两天的资料。正如勒维耶预测的那样，巴拉克拉瓦风暴可以通过在大范围内分发数据来预测。这位科学家精确的计算和无可挑剔的逻辑说服了法国政府拨款建立国家气象服务。

自1857年起，其他州开始加入这一体系。俄罗斯于 1872 年出现了同义词地图。

奇怪的是，一些气象观测及其记录（当然是原始的）可以追溯到更早的时期。 1657 年至 1673 年秘密事务令的“每日记录”已经传到我们手中，但中断了很长时间。以下是这些条目的示例：

“1657年，1月30日，星期五。午餐前一天寒冷多风，但午餐后解冻，晚上有风。

2 月 4 日，星期三。那天天气暖和，风很大，入夜前半小时开始下雪，一直持续到凌晨五点，但夜晚却很暖和。

玛雅 31 周。雷声隆隆，闪电闪过，下起了雨，此后一直到晚上，风很大，夜色暖和。”
