⟦folio 47⟧

同时满足每个不等式$\cos x < \frac{\sqrt{3}}{2}$和$\cos x > -\frac{\sqrt{3}}{2}$。

由于函数$y = \cos x$有一个周期$2\pi$，我们首先考虑$-\pi$到$\pi$区间内的值$x$。让我们为这个积分构造一个函数 $y = \cos x$ (图 3) 的图形。系统

$$\begin{cases} \cos x < \frac{\sqrt{3}}{2}, \\ \cos x > -\frac{\sqrt{3}}{2} \end{cases}$$

满足这些值​​$x$，其中图形的相应点落在虚线$y = \frac{\sqrt{3}}{2}$上方和虚线$y = -\frac{\sqrt{3}}{2}$界定的水平带内。

从图可以看出，这有条件地满足$x$的以下含义：第一，$\frac{\pi}{6} < x < \frac{5\pi}{6}$，第二，$-\frac{5\pi}{6} < x < -\frac{\pi}{6}$。考虑到周期性，我们现在可以将答案写成两个系列的形式：

$$\frac{\pi}{6} + 2k\pi < x_1 < \frac{5\pi}{6} + 2k\pi$$

($k = 0, \pm 1, \pm 2, \dots$).

$- \frac{5\pi}{6} + 2m\pi < x_2 < - \frac{\pi}{6} + 2m\pi$

($m = 0, \pm 1, \pm 2, \dots$).

如示例 4 所示，这两个系列可以用一个公式组合：

$$\frac{\pi}{6} + n\pi < x < \frac{5\pi}{6} + n\pi$$

($n = 0, \pm 1, \pm 2, \dots$).

请注意，如果我们首先将不等式 $\cos^2 x < \frac{3}{4}$ 转换为以下形式，则可以更容易地求解

$$\frac{1 + \cos 2x}{2} < \frac{3}{4}$$

从哪里$\cos 2x < \frac{1}{2}$。投票$2x = t$，我们得到了

$$\frac{\pi}{3} + 2n\pi < t < \frac{5\pi}{3} + 2n\pi$$

($n = 0, \pm 1, \pm 2, \dots$).

从这里

$$\frac{\pi}{6} + n\pi < x < \frac{5\pi}{6} + n\pi$$

($n = 0, \pm 1, \pm 2, \dots$).

然而，第一种求解方法基于简化为二次不等式，具有更大的通用性，如下所示（示例 6、7、8）。
