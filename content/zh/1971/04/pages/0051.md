示例 10. 解决不等式
$$\log_x tg x > 0.$$

解决方案。这个例子比前面的例子更复杂，因为未知的$x$同时以两个不同的角色出现：既作为对数的底又作为三角函数的参数。正因为如此，我们必须将 $x$ 理解为 chi 和 s lo 的事实在这里就特别清楚了。

首先请注意，由于$x$是对数的底，因此$x > 0$和$x \neq 1$是必要的。由于对数的性质很大程度上取决于其底数是大于还是小于 1，因此我们将分别考虑这些情况。

首先让$0 < x < 1$。由于底数小于 1，正对数的数字介于 0 和 1 之间，因此我们得到不等式$0 < tg x < 1$。求解，我们得到
$$k\pi < x < \frac{\pi}{4} + k\pi$$
($k = 0, \pm 1, \pm 2, \dots$).

但我们仍然受到条件$0 < x < 1$的约束。从图 4 可以清楚地看出，不等式$0 < x < 1, 0 < tg x < 1$只能由以下值$x$同时满足：$0 < x < \frac{\pi}{4}$。

现在让$x > 1$。考虑到底数小于1，正对数有大于1的数字，我们得到$tg x > 1$，由此
$$\frac{\pi}{4} + k\pi < x < \frac{\pi}{2} + k\pi$$
($k = 0, \pm 1, \pm 2, \dots$).
