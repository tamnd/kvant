2. 一名学生在自动考官的陪同下参加考试。机器的屏幕上出现了五个问题，每个问题都需要回答“是”或“否”。
回答完所有问题后（为此，您需要按下相应的按钮），机器会给每个正确答案 1 分，给出考试的总分。该学生仔细地检查了所有问题，并悲伤地承认他不知道任何问题的答案。
他所有的知识都归结为以下几点：
1) 第一个问题和最后一个问题需要相反的答案；
2) 相反，第二个问题和第四个问题应该有相同的答案；
3) 前两个问题至少有一个需要回答“是”，然后第五个问题需要回答“否”。
此外，学生的经验告诉他，需要回答“是”的问题总是比需要回答“否”的问题多。
画面原来是悲伤的。但学生并没有绝望。他对这门学科了解甚少，但他非常擅长解决逻辑问题。叶子很快算了一笔账，他高兴地发现自己保证了4分，如果运气好的话，他就能得到全部5分。学生做了什么计算？

如何更轻松地分享？

如果较大的数字以 9 结尾，那么用较小的数字除以较大的数字最简单的方法是什么？

假设您需要将数字 a 除以数字 b，并且 a < b。设 b = 10c + 9。现在检查一下

$$\frac{a}{10c+9} = 10^{-1} \frac{a-p_1}{c+1} + \frac{a-p_1}{c+1} + 10p_1$$

其中$p_1$是$a$除以$c+1$的余数，所以$\frac{a-p_1}{c+1}$是整数。

令 $\frac{a}{b} = 0, \alpha_1 \alpha_2 \alpha_3 \dots$ 为商的十进制表示法。然后是$\alpha_1 = \frac{a-p_1}{c+1}$和$\alpha_1 + 10p_1 = 0, \alpha_2 \alpha_3 \dots$。

用$a_1$表示$\alpha_1 + 10p_1$，我们写出等式$\frac{a_1}{10c+9} = 0, \alpha_2 \alpha_3 \dots$，从中我们类似地找到$\alpha_2$等等。
