示例 4. 解决不等式
$$|\sin x| > \frac{\sqrt{3}}{2}$$.

解决方案。将我们自己从横轴符号中解放出来，我们得到给定的不等式将由那些且仅那些满足不等式之一的 $x$ 值来满足
$$\sin x > \frac{\sqrt{3}}{2}, \sin x < -\frac{\sqrt{3}}{2}$$.

使用例 1 和例 2 中的距离法求解它们，我们得到不等式 $\sin x > \frac{\sqrt{3}}{2}$ 的答案：
$$\frac{\pi}{3} + 2k\pi < x < \frac{2\pi}{3} + 2k\pi$$
($k = 0, \pm 1, \pm 2, \dots$),

对于不等式$\sin x < -\frac{\sqrt{3}}{2}$，答案是：
$$-\frac{2\pi}{3} + 2m\pi < x < -\frac{\pi}{3} + 2m\pi$$
($m = 0, \pm 1, \pm 2, \dots$).

因此，给定不等式的答案是
$$|\sin x| > \frac{\sqrt{3}}{2}$$可以写成两个“系列”：
$$\frac{\pi}{3} + 2k\pi < x_1 < \frac{2\pi}{3} + 2k\pi$$
($k = 0, \pm 1, \pm 2, \dots$),
$$-\frac{2\pi}{3} + 2m\pi < x_2 < -\frac{\pi}{3} + 2m\pi$$
($m = 0, \pm 1, \pm 2, \dots$).

请注意，自从
$$-\frac{2\pi}{3} = \frac{\pi}{3} - \pi$$
和
$$-\frac{\pi}{3} = \frac{2\pi}{3} - \pi$$,
第二个系列可以用不同的方式写
$$\frac{\pi}{3} + (2m - 1)\pi < x_2 < \frac{2\pi}{3} + (2m - 1)\pi$$
($m = 0, \pm 1, \pm 2, \dots$).

现在这两个系列都可以用一个公式组合起来：
$$\frac{\pi}{3} + n\pi < x < \frac{2\pi}{3} + n\pi$$
($n = 0, \pm 1, \pm 2, \dots$),

此外，对于偶数$n$，我们获得第一个级数的积分，对于奇数$n$，我们获得第二级数的积分。

示例 5. 解决不等式
$$\cos^2 x < \frac{3}{4}$$

解决方案。让我们引入辅助未知数$y = \cos x$。不平等将采取以下形式
$$y^2 < \frac{3}{4}$$
从这里
$$-\frac{\sqrt{3}}{2} < y < \frac{\sqrt{3}}{2}$$
或者
$$-\frac{\sqrt{3}}{2} < \cos x < \frac{\sqrt{3}}{2}$$

因此，给定的不平等已被简化为不平等系统
$$\left\{ \begin{array}{l}
\cos x < \frac{\sqrt{3}}{2} \\
\cos x > -\frac{\sqrt{3}}{2}
\end{array} \right.$$

我们强调当前情况与示例 4 中发生的情况之间的差异。其中，为了满足给定的不等式，有必要至少满足两个不等式之一
$$\sin x > \frac{\sqrt{3}}{2}$$ 或 $$\sin x < -\frac{\sqrt{3}}{2}$$
