为了尽可能简短地写下答案，建议选择长度为 $l$ 的初始区间，以便属于它的解依次填充某个连续区间。从图再次清楚地看出，如果例如从$-\frac{\pi}{2}$到$\frac{\pi}{2}$的间隔被视为初始间隔，则情况将会如此。在下面的示例 $y = 1$ 的这个区间上，图中的那些点对应于满足不等式 $-\frac{\pi}{2} < x < \frac{\pi}{4}$ 的值$x$。因此最终的答案是
$$-\frac{\pi}{2} + k\pi < x < \frac{\pi}{4} + k\pi$$
($k = 0, \pm 1, \pm 2, \dots$).

因此，答案是一组间隔，每个间隔都是以某个固定值$k$获得的。

所有其他示例的答案中的情况都是类似的。

示例 2：解决不等式
$$\sin x \geq -\frac{1}{2}.$$

解决方案。考虑函数的图形 $y = \sin x$ (图 2）。不等式 $\sin x \geq -\frac{1}{2}$ 满足这些值 $x$，图形的对应点不位于虚线下方 $y = -\frac{1}{2}$ （如果图点位于这条线上，则该值 $x$ 满足给定的不等式，因为它“不严格”，它允许左侧和右侧相等）。功能 $y = \sin x$ 有一个时期 $2\pi$。因此，我们首先考虑一些长度区间 $2\pi$，例如间隔 $-\frac{\pi}{2}$ 到 $\frac{3\pi}{2}$。从 图 2 显然不等式 $\sin x \geq -\frac{1}{2}$ 在此区间内满足以下值 $x$: $-\frac{\pi}{6} \leq x \leq \frac{7\pi}{6}$.

考虑到周期性，我们得到答案：
$$-\frac{\pi}{6} + 2k\pi \leq x \leq \frac{7\pi}{6} + 2k\pi$$
($k = 0, \pm 1, \pm 2, \dots$).

示例 3. 解决不等式
$$\cos(3x + 2) > -\frac{\sqrt{2}}{2}.$$

解决方案。让我们引入辅助未知数$t = 3x + 2$。那么对于$t$，我们得到不等式$\cos t > -\frac{\sqrt{2}}{2}$。由于它与示例 1 和 2 中的不等式完全相似（要解决它，您可以考虑函数 $y = \cos t$ 的图形），我们立即回答 $t$：
$$-\frac{3\pi}{4} + 2k\pi < t < \frac{3\pi}{4} + 2k\pi$$
($k = 0, \pm 1, \pm 2, \dots$).
