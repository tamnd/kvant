求解方程组和方程组的代入法

M.I.斯卡纳维

替换方法涉及从原始值移动到其他值。它允许您将方程的解简化为构造更简单的方程或研究类型的方程。必须使用这一方法的情况有很多种。不可能用任何一般性建议来涵盖它们。因此，能否成功选择合适的替代方案很大程度上取决于决策的优势，例如他的经验、独创性、直觉……所考虑的例子展示了替代方法的实际应用。

示例 1：求解方程
$$\frac{1}{x(x+2)} - \frac{1}{(x+1)^2} = \frac{1}{12}.$$

解决方案。位于该等式左侧的分数的差是一个分数，其分母是关于 $x$ 的四次多项式。在这种情况下，方程的模板处理将导致四次方程，这是求解器无法做到的。想了想之后，我们就会开始明白，选择替代品是有用的
$$x^2 + 2x = z,$$
(*)

因为它将给定的方程转换为一个更简单的方程：
$$\frac{1}{z} - \frac{1}{z+1} = \frac{1}{12}$$

对于$z$，我们得到一个根为$z_1=3$和$z_2=-4$的二次方程。代入 (*) 可得出 $x$ 的两个二次方程：
$$x^2 + 2x = 3$$
和
$$x^2 + 2x = -4.$$

从它们中我们找到这个方程的所有四个根：
$$x_1 = 1, x_2 = -3, x_3 = -1 + \sqrt{3}i,$$
$$x_4 = -1 - \sqrt{3}i$$

通过直接测试，我们确信它们各自的适用性。

示例 2：求解方程
$$4x^4 + 12x^3 - 47x^2 + 12x + 4 = 0.$$

解决方案。已经提出了一个所谓的倒数方程来求解——距其左侧两端等距的项的系数相等。对于倒数方程，已经开发了一种标准方法来将它们简化为较低阶的方程。通过观察如何将该方法应用于正在求解的方程，可以了解该方法的想法。注意到$x \neq 0$，我们将方程除以$x^2$；我们得到
$$4x^2 + 12x - 47 + \frac{12}{x} + \frac{4}{x^2} = 0.$$

现在您应该应用 grappirum 成员：
$$4\left(x^2 + \frac{1}{x^2}\right) + 12\left(x + \frac{1}{x}\right) - 47 = 0.$$
