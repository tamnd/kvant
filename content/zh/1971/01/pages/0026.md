⟦folio 24⟧

开普勒第一定律

现在我们可以考虑行星的运动。为简单起见，我们不会证明行星的轨道是椭圆，但是，假设这一点并使用运动力矩和能量守恒定律，我们将找到它并确保在引力场中沿着椭圆的运动不会违反守恒定律。

让我们注意行星的两个位置$A$和$A'$，相对于椭圆中心（图7）对称。我们也可以换一种说法：点$A$是行星在某个时间点的真实位置，而$A'$是通过将太阳转移到另一个焦点而从第一个点获得的，而行星保持在同一位置。

让我们写下能量守恒定律。用索引 1 标记点 $A$ 的数量，用索引 2 标记点 $A'$ 的数量，我们得到 $(E_1 = E_2 = E)^*$。

$$-E = \frac{mv_1^2}{2} - \gamma \frac{mM}{r_1} = \frac{mv_2^2}{2} - \gamma \frac{mM}{r_2}.$$

行星的角动量等于运动量$mv_1$（或$mv_2$）与“间隙”——撞击参数$\rho_1$（或$\rho_2$）的乘积，而总能量为$T + U = -E < 0$。

行星两个位置的角动量如何相同：
$$L = mv_1\rho_1 = mv_2\rho_2.$$
让我们计算行星在点 $A$ 和 $A'$ 处的动能的乘积：
$$T_1T_2 = \frac{mv_1^2}{2} \cdot \frac{mv_2^2}{2} = \left(-E + \frac{\alpha}{r_1}\right) \times \left(-E + \frac{\alpha}{r_2}\right).$$
（这里$\alpha = \gamma Mm$。）
将方程中的速度代入运动量矩的表达式，经过简单变换可得：
$$\frac{1}{4} \frac{L^4}{m^2\rho_1^2\rho_2^2} - E^2 = \frac{-\alpha(r_1 + r_2)E + \alpha^2}{r_1r_2}.$$

很容易看出，如果行星的轨道是椭圆形，则这个等式成立。事实上，为此你需要把
$$r_1 + r_2 = \frac{\alpha}{E} = 2a$$
和
$$\rho_1\rho_2 = \frac{L^2}{2mE} = b^2.$$

这两个等式只不过是上面给出的椭圆的两个定义。

因此，我们的轨迹是一个有半轴的椭圆：大
$$a = \gamma \frac{mM}{2E} \text{ и малой } b = \frac{L}{\sqrt{2mE}}.$$
