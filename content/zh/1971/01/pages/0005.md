平移运动的力学，但用角度量代替线性量。让我们提出一些平移运动的运动学公式并对这些旋转运动公式进行分析：

| 向前移动 | 旋转运动 |
| :--- | :--- |
| $S = vt$ | 制服$\varphi = \omega t$ |
| $v = v_0 + at$ | 匀加速$\omega = \omega_0 + \alpha t$ |
| $S = v_0 t + \frac{at^2}{2}$ | $\varphi = \omega_0 t + \frac{\alpha t^2}{2}$ |

还记得旋转角度 $\varphi$ 以弧度变化。然后角速度以弧度每秒变化 ($\dot{p}_{\text{rad}} / \text{сек}$)。角加速度的单位是弧度除以秒的平方（$\dot{p}_{\text{rad}} / \text{сек}^2$）。

然而，如果我们只知道上述角量的数值，则对旋转运动的描述是不完整的。为了完整地描述旋转，您还需要知道身体围绕哪个轴以及朝哪个方向（顺时针或逆时针）旋转。如果我们将旋转角度和角速度都视为一种矢量，则两者都将被确定。人们普遍认为矢量 $\varphi$ 以及矢量 $\omega$ 都沿着旋转轴，因此如果给定这些量之一的矢量，则也给定旋转轴。例如，旋转是由所谓的钻头螺旋法则或螺旋法则决定的（这远非物理学中必须求助于此类设备的“服务”的唯一情况）。如下：如果你在心里以与身体旋转相同的方式旋转手钻的手，那么手钻平移运动的方向将显示角速度矢量$\omega$的方向。例如，如果 图 1 上的红色箭头代表旋转圆盘的向量 $\omega$，则这意味着圆盘正在旋转，如黄色箭头所示。像往常一样，所描绘比例上的矢量长度为我们提供了相应角度幅度的数值。
