4. 让我们写出以下等式：

$$\frac{3 \left( \cos 2x + \frac{\cos 2x}{\sin 2x} \right)}{\cos 2x - \cos 2x} - 2 (\sin 2x + 1) = 0.$$ (1)

现在我们很容易确定 DL。事实上，在$\sin 2x = 0$$\frac{\cos 2x}{\sin 2x}$就失去了意义，而在$\cos 2x = 0$，分数的分母为零，整个分数就失去了意义。因此，ODZ 由条件$\sin 2x \neq 0$、$\cos 2x \neq 0$ 确定。经过 $\cos 2x$ 约简并化简后，方程（1）的形式为

$$3(\sin 2x + 1) - 2(\sin 2x + 1) (1 - \sin 2x) = 0$$ (2)

（分母是集合 $1 - \sin 2x$，自 $\cos 2x \neq 0$ 起，它不会在 ODZ 中消失）。去掉括号中的公因数后，方程（2）分成两部分：

1) $1 + 2 \sin 2x = 0$;
2) $1 + \sin 2x = 0$.

求解第一个方程，我们发现

$$\sin 2x = -\frac{1}{2}; x = (-1)^{n+1} \frac{\pi}{12} + \frac{\pi k}{2}$$

($k = 0, \pm 1, \pm 2, \dots$).

所有这些值都包含在 ODZ 中。

求解第二个方程，我们得到 $\sin 2x = -1$，从而得到 $\cos 2x = 0$，从而消除了 ODZ。

因此，原方程的解只是值

$$x = (-1)^{n+1} \frac{\pi}{12} + \frac{\pi k}{2}$$

($k = 0, \pm 1, \pm 2, \dots$).

在求解这个方程时，很多人没有考虑ODZ，而是将值$\cos 2x = 0$，即$x = -\frac{\pi}{4} + \pi k$包含在解中。
