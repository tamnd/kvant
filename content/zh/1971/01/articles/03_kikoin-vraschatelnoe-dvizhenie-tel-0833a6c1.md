⟦folio 1⟧

众所周知，任何身体都可以进行两种类型的运动——平移运动和治疗运动。其中第一个在学校物理课程中得到了足够详细的研究。但医疗运动“不幸”。由于时间不够，很少有人关注。与此同时，在自然和技术中，治愈运动并不比进步运动少见。在许多情况下，物体的实际运动是两种运动的组合。在其他情况下，平移运动甚至静止的身体都有治疗细节。这主要包括所有带轮子的设备 - 从独轮手推车和手推车到飞机和直升机。试着找到一台里面没有任何东西的机器！有人可能会说，像手表这样一种广泛使用的设备，是由彼此互锁的轮子“塞满”的。

旋转运动在自然界中并不罕见。回想一下行星及其卫星的复杂治愈运动、太阳以及可能还有其他恒星的治愈就足够了。顺便说一下，当应用于行星时，“旋转”一词是指行星的两种不同类型的运动。例如，他们说地球围绕太阳被治愈，但他们也谈论地球围绕其轴被治愈。那么，这些是相同的动作吗？是否可以说两者是同一个原理造成的呢？众所周知，地球绕太阳运行的轨迹接近于圆形，因为它受到朝向太阳的引力的影响。但是否可以说相同或相似的力迫使地球绕其轴进行治愈运动？显然不是。事实上，地球的运动可以被认为是平移运动和线性运动的组合——绕太阳的平移运动和绕穿过地球两极的轴的线性运动。

本文讨论身体的医学运动、它与平移运动的区别以及两者的相似之处。

医学运动电影

首先，让我们向读者介绍他们从学校物理课程中已经了解的有关医学运动的知识。让我们从定义开始。

身体的旋转运动是一种身体所有点都作圆周运动的运动类型，其中心位于同一条直线上——治疗轴。

如果治愈轴是固定的，那么身体作为一个整体是不会移动的，唯一随时间变化的就是旋转角度，这里的旋转角度与身体向前运动过程中某个点的运动起到同样的作用。

当物体旋转角度 φ 时，每个点都会经过一定的圆弧。如果我们用S表示弧的长度，那么S和φ的值之间有一个简单的关系

$$S = \varphi r,$$

其中$r$是该点到旋转轴的距离。距旋转轴不同距离 $r$ 的点描述了不同长度的弧，但角度 $\varphi$ 对于整个物体来说是相同的。

旋转运动力学的任务是，如果初始旋转角度已知，则能够在任何时候实现物体的一定旋转角度。为此，您需要知道旋转角度的快速变化，即转角速度，通常用字母$\omega$表示。对于以恒定角速度旋转的物体，

$$\omega = \frac{\varphi - \varphi_0}{t},$$

其中$\varphi - \varphi_0$是$t$秒时间内旋转角度的变化。

如果角速度一定，则任意时刻的旋转角度值很容易求得：

$$\varphi = \varphi_0 + \omega t;$$

如果初始旋转角度$\varphi_0$为零，则

$$\varphi = \omega t.$$

该表达式类似于匀速平移运动的公式$S = vt$。因此，旋转运动中的角速度与平移运动中的线速度$v$起着相同的作用。

角速度与线速度一样，可能不是恒定的。然后，为了求出任意时刻的速度，您需要知道角加速度，它与线性加速度$a$一样，被定义为角速度的快速变化。匀速旋转

$$\alpha = \frac{\omega - \omega_0}{t},$$

其中$\omega$和$\omega_0$是$t$秒的长时间段结束时和开始时的角速度值。

很容易找到角速度和加速度及其线性“双胞胎”$v$和$a$之间的联系。既然$\omega = \frac{\varphi}{t}$和$\varphi = \frac{S}{r}$，那么$\omega = \frac{S}{rt}$。

但$\frac{S}{t} = v$因此

$$\omega = \frac{v}{r} \text{ и } v = \omega r.$$

同理，从$\alpha = \frac{\omega - \omega_0}{t}$、$\omega = \frac{v}{r}$、$\omega_0 = \frac{v_0}{r}$开始，然后$\alpha = \frac{v - v_0}{rt}$。但$\frac{v - v_0}{t}$等于$a$的线加速度，所以

$$\alpha = \frac{a}{r} \text{ и } a = \alpha r.$$

因此，旋转体每个点的线性量$S$、$v$和$a$的数值等于相应的角度量值（它们与单个点相关，而是与整个物体相关）乘以该点的旋转半径$r$。

如果您使用数量 $\varphi$、$\omega$ 和 $\alpha$，那么您可以使用众所周知的运动公式来解决与物体旋转相关的问题

旋转运动的动力学

众所周知，平移运动动力学研究物体中出现加速度的原因，并使得确定其大小和方向成为可能。旋转动力学对于角加速度也有同样的作用。如果物体的平移运动的加速度是由施加在其上的力引起的，那么物体的角加速度加速的原因是施加在其上的力的扭矩。读者在八年级或九年级的物理课程中就已经熟悉它了。让我们回想一下，绕任何轴的力矩的数值等于施加到物体上的力与从该轴到力的作用线所画的垂线的长度的乘积。例如，如果将力 $F$ 施加到平盘的边缘（如 图 2 所示），其矢量位于圆盘平面内，则该力相对于垂直于圆盘平面并穿过点 $O$ 的轴的力矩等于 $Fr$。如果轴不是通过点 $O$，而是通过点 $O_1$，则相同力相对于新轴的力矩将不同：它将等于 $Fr_1$。如果如 图 3 所示施加相同的力，则其相对于穿过点 $O$ 的轴的力矩等于 0，因为力的作用线穿过该点。这种力不能引起绕轴旋转，也不能改变角加速度。但同样的力可以导致圆盘绕通过点 $O_1$ 的轴旋转。

正如平移运动物体的加速度除了取决于力之外，还取决于被加速物体的质量一样，旋转物体的加速度不仅取决于力矩，还取决于值 $mr^2$，可以说是质量的旋转“两倍”。这个量称为物体相对于轴的转动惯量。对于旋转运动来说，重要的不仅仅是质量。该质量距离旋转轴有多远也很重要。很明显，距旋转轴较远的小质量可以在给定的力矩下接收与位于轴附近的大质量相同的角加速度。

动量、角动量

因此，对于旋转运动，牛顿第二定律写为$M = I\alpha$，其中$M$是力矩，$I$是惯性矩，$\alpha$是物体的角加速度。

无角加速度用公式表示

$$\alpha = \frac{\omega - \omega_0}{t}.$$

因此，牛顿第二定律的公式可以写为

$$M = \frac{I\omega - I\omega_0}{t}.$$

在这种形式中，该公式意味着力矩等于单位时间值的变化$I\omega$。但是，众所周知，牛顿第二定律可以写成以下形式

$$F = \frac{mv - mv_0}{t},$$

其中 $mv$ 是称为物体动量或推动力的量。很明显，意味着$mv$在旋转运动膜片中也有一个类似物，这个类似物就是值$I\omega$。这是因为转动惯量$I$在旋转运动中的作用与质量在平移运动中的作用相同，并且角速度$\omega$取代了线速度$v$。因此，$L = I\omega$ 被称为物体的角动量或角动量。这也是一个矢量（与$\omega$、$F$、$\alpha$、$mv$、$M$相同），其方向与角速度矢量相同。与我们给出的与旋转运动相关的其他值类似，推进器的动量相对于不同的旋转轴是不同的。

如果物体具有这样的形状、大小或旋转半径，我们可以谈论点的旋转（例如，细杆上的球，绕太阳旋转的行星），那么冲动矩很容易与冲动联系起来。事实上，转动惯量$I$等于$mr^2$，角速度$\omega$等于$\frac{v}{r}$。这就是为什么

$$L = I\omega = \frac{mr^2v}{r} = rmv.$$

因此，点的冲量力矩的大小等于该点移动的圆的半径 $r$ 与冲量 $mv$ 的乘积。显然，对于任意形状的物体，这种简单的对应关系是不可能的。

身体相对于垂直旋转轴的惯性矩（手臂的质量接近该轴）。由于转动惯量$I$的减小不是通过外力而是通过内力实现的，因此动量$I\omega$无法改变。因此，角速度 $\omega$ 增加的次数与花样滑冰运动员设法减少惯性矩的次数相同。相反，在完成旋转之前，需要降低速度时，滑冰者张开双臂，增加身体的转动惯量。舞者在表演 pruet 时也会做同样的事情，杂技演员在表演翻筋斗等时也会做同样的事情。这种有趣的实验可以使用所谓的 Zhukovsky skama 进行。它是一个可以轻松绕垂直轴旋转的平台（图9）。站在这样的旋转平台上，你可以通过操纵双手来显着改变旋转的角速度。

角动量守恒不仅意味着$I\omega$的数值守恒。我们不能忘记角动量是一个矢量。因此，角动量守恒也就意味着其方向守恒。但正如我们所知，冲量的方向是沿着旋转轴的。因此，任何不受外力矩作用的旋转体都不能改变旋转轴的位置。这就是滚动轮、陀螺等稳定的“秘密”。这就是铁饼运动员投掷抛射物时会导致其旋转的原因。这使得圆盘能够飞行而不会翻滚。旋转体保持其旋转轴位置（在没有外力力矩的情况下）的能力在技术中得到广泛应用。所谓陀螺罗盘、各种稳定器等的使用就是基于这个性质。陀螺罗盘本质上是一个旋转体。如果在发射时安装入口以使焊缝朝向北方，那么它将保持最佳磁罗盘的方向，该方向受到船的铁壳和地球磁场变化的影响。陀螺稳定器有时安装在船体上，船体是由强大发动机驱动的重达数吨的巨大轮子。为了保持旋转轴的位置，这种稳定器改变了船舶的质量。陀螺仪稳定器在太空飞行技术和各种用途的自动设备中有着重要的应用。

旋转体的动能

旋转体是运动体，因为除了位于旋转轴上的点之外，其所有部件都在运动。因此它具有动能。为了表达动能，我们先从细杆上的小球的旋转开始，也就是一点的旋转。在这种情况下，动能可以写成一般形式

$$K = \frac{mv^2}{2},$$

其中$m$是球的质量，$v$是球的线速度。但从 $v = \omega r$ 开始，$K$ 的表达式可以写成以下形式

$$K = \frac{m\omega^2r^2}{2}.$$
