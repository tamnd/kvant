我们在本期杂志上发布的三种问题是为今年进入新西伯利亚州立大学物理系的学生准备的。每个任务的条件后面都有清晰的数字。第一个是解决了这个问题的人在进入的人中所占的百分比，第二个是没有进入的人，第三个是占申请者总数的百分比。括号内表示正确解决问题的分数。

为了获得满意的成绩，需要获得5-9分。如果算法得分至少为 17 分，则给出优秀分数。

选项1

1. 运动锤是一个挂在缆绳上的炮弹，它可以以足够的速度围绕自身旋转。如果运动员投掷前的握力为$n$乘以链球重量，求链球能飞出的最大距离。沿电缆从旋转轴到芯的距离为$l$。体育的影响力和体育的成长是有需求的。 90、53、66 (5)。

2. 固定一个矩形线框，其长度为$a$和$b$的边上有电流，使其可以绕水平边$a$（图1）自由旋转。边$a$的权重为$P_1$，边$b—P_2$。框架处于垂直均匀磁场中，感应强度为$B$。如果框架与地平线的倾斜角为 $\alpha$，求框架中电流的大小。

3. 宇宙体在重力的影响下向月球移动。在很远的距离上，军团相对于月球的速度为零。月球表面的重力加速度比地球上的重力加速度小$n=6$倍（$g_{\pi} = \frac{g}{6}$）。月球的半径$R$约为1700公里。如果我们假设发动机产生五倍过载（5$g$），那么在什么高度$h$应该打开制动发动机以实现软着陆？可以考虑制动过程中由于燃料排出而引起的船体质量变化以及月球引力对制动阶段距离的依赖性（$h$远小于$R$）。 83、14、39 (7)。

4. 在质量为 $M$ 且仅水平滑动的光滑楔子上，落下

质量球$m$ (图 3)。球弹性击中与地平线形成 $\alpha$ 角的面。击球前球的速度为 $v$，且垂直向下。求击球后楔块的速度。 Trenium可以忽略不计。 7, 2, 4 (7)。

解决方案

1. 当炮弹的发射角为 $45^\circ$ 时，其飞行范围最大。而且，那个$n \gg 1$。然后我们可以假设，当核展开时，线的张力赋予它向心加速度。在投掷$\frac{mv^2}{l} = nmg$的那一刻。这意味着运动员投掷时传给核心的速度等于 $v = \sqrt{lng}$。

现在不难发现炮弹的射程了。让我们写出其运动的运动学方程：

垂直$y = v_{\text{верт}} \cdot t - \frac{gt^2}{2}$，水平$x = v_{\text{гор}} \cdot t$。

倒地的瞬间$y=0$。将这个值代入第一个方程，我们就得到了原子核的飞行时间$t = \frac{2v_{\text{верт}}}{g} = \frac{v\sqrt{2}}{g}$。 （根$t=0$对应于投掷的时刻）。

在此期间，炮弹会飞行一段水平距离

$$x = v_{\text{гор}} \frac{v\sqrt{2}}{g} = \frac{v^2}{g} = nl.$$

2. 让我们写出作用在框架上的力矩总和等于零的条件，考虑到作用在框架两侧的磁场中的力矩彼此平衡（因为通过它们感应的电流是相反的）。 $P_1b \cos \alpha + 2P_2 \frac{b}{2} \cos \alpha - BIa \sin \alpha = 0$。

因此$I = (P_1 + P_2) \frac{\text{ctg} \alpha}{a}$。

3. 让我们写下飞船接近月球阶段的能量守恒定律。通过引力场与电场的类比，我们可以得出这样的结论：如果物体的势能被无限期地视为零，那么在距月球中心$H$的距离处，势能等于$-\gamma \frac{Mm}{H}$，其中$\gamma$是引力常数，$M$是月球的质量，$m$是质量身体的。如果月球表面没有势能，则$\Pi = \gamma \frac{Mm}{R} - \gamma \frac{Mm}{H}$。

在远离月球的地方，飞船只有势能$G \frac{Mm}{R}$，而在距离月球表面高度$h$的地方，它有动能$\frac{mv^2}{2}$和势能$\Pi = \gamma \frac{Mm}{R} - \gamma \frac{Mm}{R+h}$。

因此$\gamma \frac{Mm}{R} = \frac{mv^2}{2} + \gamma \frac{Mm}{R} - \gamma \frac{Mm}{R+h}$。

考虑到月球表面有 $\gamma \frac{Mm}{R^2} = mg_\pi$，因此有 $\gamma M = R^2g_\pi = \frac{1}{6} R^2g$，我们可以写成

$$\frac{v^2}{2} = \frac{1}{6} g \frac{R^2}{R+h}.$$

船舶制动时能量的变化等于发动机的功。由于发动机运行过程中会产生五倍的过载，因此其牵引力应等于5毫克。因为

$$5mgh = \frac{mv^2}{2} + mg_\pi h = \frac{mv^2}{2} + \frac{1}{6} mgh$$

（先$h \ll R$，然​​后$\Pi = \gamma \frac{Mm}{R} - \gamma \frac{Mm}{R+h} = \gamma \frac{Mmh}{(R+h)R} \approx \gamma \frac{Mm}{R^2} h = mg_\pi h$）。

因此$\frac{v^2}{2} = \frac{29}{6} gh$。

将$\frac{v^2}{2}$的表达式代入方程（1），我们得到$h \approx \frac{R}{29} \approx 59$公里。

4. 利用能量守恒定律以及系统水平方向和沿楔形动量分量守恒的条件，我们可以写出：

$$v_0^2 = v_x^2 + v_y^2, \quad mv_x = Mn,$$

$$v_0 \sin \alpha = v_x \cos \alpha - v_y \sin \alpha.$$

因此$u = -\frac{v_0 \sin 2\alpha}{M/m} + \sin^2 \alpha$。

解决方案

1. 时间比为
$$\frac{L}{c+u} + \frac{L}{c-u} = \frac{c}{\sqrt{c^2-u^2}}$$
（$L$ — 城市之间的距离）。如果风垂直于线 $M-H$ 吹，则飞机相对于空气的速度 $c$ 必须定向，使其与风速 $u$ 的总和沿着线 $M-H$ 定向。

2. 我们把玩具倾斜一个小角度$\alpha$，看看玩具的重心会发生什么变化。如果往下，平衡位置不稳定，玩具就会掉落；如果上升，则平衡位置稳定。

在我们的绘图（图 7）中，线$O'B$和$A'C$是垂直的，线段$O'C$是水平的。 $O'B=2R\cos \alpha, <A'O'D=\alpha, a <DO'C=90^\circ-\alpha$。因此 $<A'O'C=\alpha-(90^\circ-\alpha)=2\alpha-90^\circ$ 和
$$A'C = A'O'\sin(2\alpha-90^\circ) = -\frac{1}{2}R\cos 2\alpha.$$

我们来求一下重心的位移。
$$\Delta h = AD - O'B + A'C = \frac{3}{2}R - 2R\cos \alpha + \frac{R}{2}\cos 2\alpha = R(1-\cos \alpha)^2 > 0.$$

因此，我们看到玩具的重心下降了。 Vanka 插入物将从半球掉落。

3. 通过二极管的电流与电压的关系图可以简单地解读：在施加到二极管上的电压达到 +10 $\theta$ 之前，没有电流流过二极管。随着电压进一步增加，二极管相当于10$\omega$的电阻。

令交流电压随时间按规律$u(t) = 220\cos \frac{2\pi t}{T}$变化。如果我们考虑 e.m.c.电池，那么很明显，二极管在$u(t_1) = 210\theta$时打开，在电压再次下降到$u(t_2) = 210\theta$时关闭。也就是说，营业到$\cos \frac{2\pi t}{T} \geq \frac{210}{220}$。

一般来说，二极管开路的时间比例等于$\frac{t}{T} = \frac{1}{2\pi}\arccos \frac{21}{22}$。
