1969年我们系的数学笔试（报告见1970年«Kvant»第3号）有些不寻常。该州的不同寻常之处在于对莫斯科国立大学竞争性考试的一些模仿。结果，475名申请者中，有224人，即大约一半，论文写得不好，退出了进一步的“斗争”。这种交换申请人的方式似乎不适合师范学院；太多的考生最终与考官并不熟悉。

1970年，数学学院选拔委员会决定了几乎不同的道路。书面作业包括四项任务，以充分了解学生。
1. 应用三角学的立体问题。
2. 用物理或其他内容编写二次方程的任务。
3. 代数方程或不等式。
4. 三角方程。

所有任务不需要任何特殊知识或培训。但与此同时，他们假设对学校数学有透彻的了解，并且了解申请人的能力。分配了4个小时来完成书面作业。

在考核书面作业时，只有完成所有任务才给“五”； “四”——所有任务均已完成，但有轻微缺陷。例如，如果由于一组错误而未能解决第一个任务，则给出“两个”。同时，“三”的评级获得了更大的份额，并不排除申请人参与竞争。

1970年，数学系入学人数为508人，名额175个；比赛大约每个名额三人。

笔试报名的508人中，写“四”、“五”的有120人，写“三”的有233人，写“二”的有155人。
下面我们以书面作业选项为例进行分析，并指出申请人在解决该选项时常犯的典型错误。

选项

1. 圆锥体的母线长度为l，母线与底面的夹角为α。求以锐角 β 为菱形的底面外接圆锥体的原体的体积。
2. 在 n 小时内，拖拉机比马多犁地 p 公顷。如果拖拉机在 t 小时内比马快犁一公顷，那么一匹马在 n 小时内可以耕地多少赫勒，一台拖拉机在 n 小时内可以耕地多少赫勒。
3. 解决不平等问题
$$\sqrt{1+2x}-\sqrt{x+4}<1.$$
4. 解方程
$$\frac{3(\cos 2x+\mathrm{ctg} 2x)}{\mathrm{ctg} 2x-\cos 2x}-2(\sin 2x+1)=0.$$

正如您已经注意到的，在解决这个问题时，我必须解决直角三角形三次。申请人在这里也犯了错误。扎实的解直角三角形能力是成功解决大多数立体问题的先决条件。

2. 让拖拉机在 $n$ 小时内转动 $x$ ($2a$)，因此在 $\frac{n}{x}$ 小时内转动 $1$ ($2a$)。

一匹马需要$n$小时$(x-p)$（$2a$），$1$（$2a$）需要$\frac{n}{x-p}$小时。

根据问题的条件，$\frac{n}{x}$比$\frac{n}{x-p}$小$t$小时，即$\frac{n}{x} + t = \frac{n}{x-p}$（$x \neq 0, x \neq p$）。变换后我们得到方程$tx^2 - ptx - np = 0$。解决它，我们找到$x_{1,2} = \frac{pt \pm \sqrt{(pt)^2 + 4ptn}}{2t}$。

这两个根中哪一个满足问题的条件？根据条件，$n > 0, t > 0, p > 0$，所以$\sqrt{(pt)^2 + 4ptn}$有实值。 $(pt)^2 + 4ptn > (pt)^2$，因此$\sqrt{(pt)^2 + 4ptn} > pt$。

所以根

$$x_1 = \frac{pt + \sqrt{(pt)^2 + 4ptn}}{2t}$$

给出了问题的答案，拖拉机在 $n$ 小时内转动了多少公顷，一匹马在 $n$ 小时内转动了多少公顷

$$x - p = \frac{-pt + \sqrt{(pt)^2 + 4ptn}}{2t}$$.

方程的第二个根是负数并且根据问题的含义消失。

在根据$\frac{n}{x}, \frac{n}{x-p}, t$编制初始方程时，一些申请人出于某种原因进行了少减多的计算，得出了方程$\frac{n}{x-p} + t = \frac{n}{x}$。

这就是不注意的结果。

当解决具有特定物理或其他内容的问题时，你应该特别小心并经常检查你的计算。正式声明必须符合实际情况。另外，应该记住，此类问题的整体解决方案不是求解已编译的方程，而是获得任务中提出的问题的答案。

3. 让我们找出 $x$ (OD3) 可接受的值范围：

$$\begin{cases} 1 + 2x \geq 0 \\ x + 4 \geq 0 \end{cases}$$ 或 $$\begin{cases} x \geq -\frac{1}{2} \\ x \geq -4. \end{cases}$$

因此，OD3 由条件确定

$$x \geq -\frac{1}{2}.$$ (1)

我们将原来的不等式变换如下：

$$\sqrt{1 + 2x} < 1 + \sqrt{x + 4}.$$

在标记的OD3中，最后一个不等式两边都是非负的；将它们平方我们得到

$$\sqrt{x + 4} > \frac{x}{2} - 2.$$ (2)

不等式(2)左边为正，右边为负，左边为正。

1) $\frac{x}{2} - 2 < 0$因此

$$-\frac{1}{2} \leq x < 4.$$

对于这样的$x$值，不等式（2）负相关，左边为正。

2) $\frac{x}{2} - 2 \geq 0$ 并按条件

$$\sqrt{x + 4} > \frac{x}{2} - 2.$$

解决第一个不等式，我们得到 $x \geq 4$。为了解决第二个不等式，我们将两边都平方（可以这样做，

我们得到
$$x^2 - 12x < 0.$$ (3)

求解(3)，我们找到$0 < x < 12$。最后，在第二种情况下我们得到$4 \leq x < 12$。结合这两种情况，我们写出原始不等式的解：
$$-\frac{1}{2} \leq x < 12.$$

解决此类不等式时的一个典型错误是对不等式进行无争议的平方。众所周知，由此产生的不平等可能会与原来的不平等不同。因此，在求平方时，应考虑不等式的迹象，并在必要时考虑不同的情况。

4. 让我们写出以下等式：

$$\frac{3 \left( \cos 2x + \frac{\cos 2x}{\sin 2x} \right)}{\cos 2x - \cos 2x} - 2 (\sin 2x + 1) = 0.$$ (1)

现在我们很容易确定 DL。事实上，在$\sin 2x = 0$$\frac{\cos 2x}{\sin 2x}$就失去了意义，而在$\cos 2x = 0$，分数的分母为零，整个分数就失去了意义。因此，ODZ 由条件$\sin 2x \neq 0$、$\cos 2x \neq 0$ 确定。经过 $\cos 2x$ 约简并化简后，方程（1）的形式为

$$3(\sin 2x + 1) - 2(\sin 2x + 1) (1 - \sin 2x) = 0$$ (2)

（分母是集合 $1 - \sin 2x$，自 $\cos 2x \neq 0$ 起，它不会在 ODZ 中消失）。去掉括号中的公因数后，方程（2）分成两部分：

1) $1 + 2 \sin 2x = 0$;
2) $1 + \sin 2x = 0$.

求解第一个方程，我们发现

$$\sin 2x = -\frac{1}{2}; x = (-1)^{n+1} \frac{\pi}{12} + \frac{\pi k}{2}$$

($k = 0, \pm 1, \pm 2, \dots$).

所有这些值都包含在 ODZ 中。

求解第二个方程，我们得到 $\sin 2x = -1$，从而得到 $\cos 2x = 0$，从而消除了 ODZ。

因此，原方程的解只是值

$$x = (-1)^{n+1} \frac{\pi}{12} + \frac{\pi k}{2}$$

($k = 0, \pm 1, \pm 2, \dots$).

在求解这个方程时，很多人没有考虑ODZ，而是将值$\cos 2x = 0$，即$x = -\frac{\pi}{4} + \pi k$包含在解中。

有些人无法写出解决方案的一般形式。

该选项的68件作品中，3件作品被评为“五”，8件作品被评为“四”，39件作品被评为“三”，18件作品被评为“二”。

让我们注意申请人在解决其他选项中的问题时所犯的错误，以及在进行书面作业时的一般缺点。

在解决立体测量问题时，在许多情况下，绘图不成功（不清楚、脏）或根本不正确。发生这种情况是因为解决问题的人错误地想象或错误地描述了给定的图形、身体、剖面和其他元素的位置，特别是当涉及到描述或铭刻的身体时。

在许多情况下，绘图和随后的施工并没有附有必要的解释，并且没有对施工结果得出的结论给出任何理由。

绘图上的构造没有错误以及结论的证实导致解决立体问题的等级降低。

最后，关于极限的概念。这个最重要的概念在大多数情况下都停留在表面上。它甚至没有谈到应用限制。因此，学校数学课程中与极限概念相关的部分掌握得不够充分。
