⟦folio 20⟧

本文讨论了椭圆的一些属性和行星运动的不同定律，其中最重要的是开普勒定律。

重力
惯性定律现在看来是最基本、最自然的定律——力学的研究将从它开始。然而，为了理解它，有必要分散我们对眼前发生的事情的注意力。正常情况下，身体在水平面内的运动受到摩擦力和空气阻力的阻碍；当在垂直平面上移动时，空气阻力和重力作用在身体上。有必要适应他们的影响，至少在精神上。这花了很多年的时间。

只有理解了惯性定律——理想条件下的物体运动定律——才有可能考虑物体在力的作用下的运动。

地球上落体定律由伽利略（1564-1642）建立。他是第一个给自己设定任务，了解下落物体的速度在连续时间段内如何变化的人。因此，他将加速度引入力学，并确定所有落到地面的物体的加速度是相同且恒定的。但牛顿后来才明白加速度的原因是重力。

伽利略著作出版后的近几年，牛顿发现了万有引力定律（1687），根据该定律，重力不是恒定的，而是随着物体之间距离的增加而减小，即该距离的平方。

如果物理学在历史上是按照教科书上的顺序发展的，那么只有在牛顿的发现之后，才有可能继续研究行星运动定律。但科学的发展并不遵循教科书的逻辑。这些定律比牛顿早得多，是由与伽利略同时代的约翰内斯·开普勒（Johannes Kepler，1571-1630）制定的。

与现代小学生的知识相比，开普勒的力学意义极其贫乏。他不仅不知道牛顿定律（还没有被发现），而且对于什么是力也有非常模糊的概念。开普勒手中掌握的一切都是对天体运动的非常精确的古代观察，他的老师第谷·布拉赫（Tycho Brahe）已经进行了很多年*），而他自己也继续进行着。只有非凡的努力和对控制行星运动的简单定律的存在的信心，才使他发现了后来以他的名字命名的定律。

即使现在，开普勒定律也没有那么强大。这主要是因为普通读者对椭圆（行星运动的曲线）知之甚少。事实上，获得开普勒定律并不那​​么困难。为此，您需要使用两个力学定律：能量守恒定律（开普勒或牛顿都不知道）和角动量守恒定律。正如我们将看到的，后者相当于开普勒第二定律：在相同的时间内，行星半径矢量减慢的面积是相同的。

*) 第谷·布拉赫是最后用肉眼观察天体运动的天文学家之一。

能量守恒定律

在地球表面，重力为$mg$。如果我们将物体的势能引入引力场$U = mgh$（h是物体到地球的距离），那么我们可以说，当物体运动时，它的动能和势能之和$E = \frac{mv^2}{2} + mgh$不会改变。

然而，我们编写的 $U$ 表达式仅在物体到地球的距离很短时有效，此时 $h$ 与地球半径相比很小，并且重力可以被认为是恒定的。如果高度变大，则重力会随着距离的增加而减小。根据牛顿定律

$$|F| = \gamma \frac{mM}{R^2},$$

其中$\gamma$是万有引力常数，$M$是地球的质量，$R$是物体到地球中心的距离。

如果我们使用重力的精确表达式，那么势能必须用$U = -\gamma \frac{mM}{R}$代替。我们来看看吧。让我们记住，身体在运动过程中所做的功等于减少的量。

减少其势能。我们计算身体从地心 (图 2) $R_2$ 高度到$R_1$ 高度进给所做的功。为此，您需要计算身体势能的差异：

$$\text{работа} = U_2 - U_1 =$$

$$= \gamma m M \left( -\frac{1}{R_2} + \frac{1}{R_1} \right) =$$

$$= \gamma m M \left( \frac{R_2 - R_1}{R_1 R_2} \right).$$

如果 $R_2 - R_1 \ll R_1$ ($R_2 \approx R_1$)，则乘积 $R_1 R_2$ 可以替换为 $R^2$ - $R_1$ 和 $R_2$ 的几何平均值的平方（对于 $R_2 \approx R_1$：$R \approx R_2 \approx R_1$），$R_2 - R_1$ 可以替换为 $l$ - 路径经过的路径身体。那么最后一个公式的形式为

$$\text{работа} = \text{сила} \times \text{путь} = \gamma \frac{mM}{R^2} l.$$

重力的力路径

这意味着我们上面写的$U$的表达式是身体的真实势能。

现在我们需要以不同的方式写出身体总能量的公式：

$$E = \frac{mv^2}{2} - \gamma \frac{mM}{R} = m \left( \frac{v^2}{2} - \gamma \frac{M}{R} \right).$$

从这个定义中，我们可以推断出椭圆的一个有趣的“光学”属性：如果将光源放置在镜面椭圆*)的一个焦点处，那么从光源发出的所有光线将被收集在椭圆的另一个焦点处**)。这意味着从椭圆焦点到椭圆点的直线与椭圆切线之间的角度彼此相等 (图 4)。

让我们证明椭圆还有一个性质，甚至可以方便地将其作为椭圆的定义。为此，我们在点 $A$ 处绘制椭圆的切线 $t$ ，并将从椭圆的两个焦点到该切线的重新分布降低 (图 5)。我们将其中一个重新分布延伸到直线 $t$ 之外，到达等于 $N_2 F_2$ 的距离 $F'_2 N_2$。现在让我们将点 $F'_2$ 和 $F_1$ 与点 $A$ 连接起来。让我们证明$F'_2 AF_1$是一条直线。

从$\alpha_1 = \alpha_2$（根据构造）和$\alpha_1 = \alpha_3$（根据椭圆的光学性质）这一事实可以立即清楚地看出这一点。因此，$\alpha_2 = \alpha_3$和$F'_2 AF_1$是一条直线。

**) 证明椭圆的这一性质的最简单方法是使用费马原理（参见 «Kvant» No. 11, 1970）。

进一步，由于$AF'_2 = AF_2$，则$F_1 F'_2 = F_1 A + AF'_2 = F_1 A + AF_2$，即线段$F_1 F'_2$等于椭圆点到焦点的距离之和。我们将这个总和表示为$2a$。现在让我们将重新分布 $F_1 B$ 降低到线 $F'_2 F'_2$ 上，从两个直角三角形（棕色和黄色）计算边 $F_1 B$ 的长度，并将 $F_1 B$ 的两个表达式彼此相等：

$(2a)^2 - (\rho_1 + \rho_2)^2 = (2c)^2 - (\rho_2 - \rho_1)^2$.

打开括号，我们得到

$\rho_1 \rho_2 = a^2 - c^2$.

因此，乘积 $\rho_1 \rho_2$ 不依赖于绘制切线的点。让我们将其绘制在短半轴 (图 6) 的末端。在这种情况下$a^2 - b^2 = c^2$。因此$\rho_1 \rho_2 = b^2$。

于是，我们得到了主要定理：

从两个焦点到椭圆任意切线的距离的乘积是等于短半轴的平方的常数值。

开普勒第一定律

现在我们可以考虑行星的运动。为简单起见，我们不会证明行星的轨道是椭圆，但是，假设这一点并使用运动力矩和能量守恒定律，我们将找到它并确保在引力场中沿着椭圆的运动不会违反守恒定律。

让我们注意行星的两个位置$A$和$A'$，相对于椭圆中心（图7）对称。我们也可以换一种说法：点$A$是行星在某个时间点的真实位置，而$A'$是通过将太阳转移到另一个焦点而从第一个点获得的，而行星保持在同一位置。

让我们写下能量守恒定律。用索引 1 标记点 $A$ 的数量，用索引 2 标记点 $A'$ 的数量，我们得到 $(E_1 = E_2 = E)^*$。

$$-E = \frac{mv_1^2}{2} - \gamma \frac{mM}{r_1} = \frac{mv_2^2}{2} - \gamma \frac{mM}{r_2}.$$

行星的角动量等于运动量$mv_1$（或$mv_2$）与“间隙”——撞击参数$\rho_1$（或$\rho_2$）的乘积，而总能量为$T + U = -E < 0$。

行星两个位置的角动量如何相同：
$$L = mv_1\rho_1 = mv_2\rho_2.$$
让我们计算行星在点 $A$ 和 $A'$ 处的动能的乘积：
$$T_1T_2 = \frac{mv_1^2}{2} \cdot \frac{mv_2^2}{2} = \left(-E + \frac{\alpha}{r_1}\right) \times \left(-E + \frac{\alpha}{r_2}\right).$$
（这里$\alpha = \gamma Mm$。）
将方程中的速度代入运动量矩的表达式，经过简单变换可得：
$$\frac{1}{4} \frac{L^4}{m^2\rho_1^2\rho_2^2} - E^2 = \frac{-\alpha(r_1 + r_2)E + \alpha^2}{r_1r_2}.$$

很容易看出，如果行星的轨道是椭圆形，则这个等式成立。事实上，为此你需要把
$$r_1 + r_2 = \frac{\alpha}{E} = 2a$$
和
$$\rho_1\rho_2 = \frac{L^2}{2mE} = b^2.$$

这两个等式只不过是上面给出的椭圆的两个定义。

因此，我们的轨迹是一个有半轴的椭圆：大
$$a = \gamma \frac{mM}{2E} \text{ и малой } b = \frac{L}{\sqrt{2mE}}.$$

那么行星的速度将是无量纲的。速度是一个数字，显示行星速度包含多少次$v_0$：

$$\beta_1 = \frac{v_1}{v_0} \quad \text{и} \quad \beta_2 = \frac{v_2}{v_0}.$$

根据前面的速度$\beta_1$和$\beta_2$有关系

$$\beta_1 = \frac{1}{\beta_2}.$$

这是什么意思？如果一个粒子以$\beta$的速度在轨道上的某一点运动，那么在相对于轨道中心对称的点上，其速度将等于$\frac{1}{\beta}$

我们描述了行星的轨迹，指定了它在每个时刻的位置（坐标）。你可以用不同的方式来做——设置行星的速度。在这种情况下我们得到的曲线称为速度图（我们可以说这是速度空间中的轨迹）。由于线段$\beta_1$和$\beta_2$的乘积已经构建，行星的速度图是一个圆（图8）（记住定理：“在圆内给定一个点。那么对于通过该点的所有弦，该点划分弦的线段的长度的乘积是相同的”）。

如果我们将神图每个点的速度$\beta$替换为$\frac{1}{\beta}$，那么神图不会改变，而只是$180^\circ$处的表面速度。这种性质称为相对表面运动不变性。

如果行星的轨道是圆形的，则$\beta = 1$（证明它！）。在这种情况下，神图是一个圆心位于原点的圆。

流通期限

为了计算轨道周期——行星绕科隆公转一周或人造卫星绕地球一周的时间，有必要计算轨迹各部分的通过时间（单独计算，因为速度一直在变化），然后对所有部分求和。当然，这不能简单地做到，但一切困难都是可以规避的。

从开普勒第二定律我们知道，在 $\Delta t$ 时间内，行星的半径矢量“扫过”等于 $\frac{L}{2m} \Delta t$ 的面积（回想一下 $L = \text{const}$）。这意味着旋转周期可以通过椭圆面积除以“扫掠”的恒定速度来计算

$$T = \frac{S_{\text{эллипса}}}{L/2m}.$$

由于椭圆是由向一个方向倾斜的圆$\frac{b}{a}$乘$^*$）得到的，那么椭圆的面积等于

$$S_{\text{эллипса}} = S_{\text{крута}} \cdot \frac{b}{a} = \pi a^2 \frac{b}{a} = \pi ab.$$

从这些公式我们得到

$$T = \frac{2\pi ab}{L}.$$

但$b = \frac{L}{\sqrt{2Em}}$，因此

$$T = \pi a \sqrt{\frac{2m}{E}}$$

$^*$）参见 I. N. Bronstein 的文章《椭圆》（«Kvant» No. 9，1970）。

或者，在这里替换 $a \left( a = \gamma \frac{Mm}{2E} \right)$ 的表达式，并将 $\left( \frac{2E}{m} \right)^{3/2}$ 替换为 $v_0^3$，我们得到
$$T = 2\gamma M \frac{m}{2E} \sqrt{\frac{m}{2E}} = 2 \frac{\pi \gamma M}{v_0^3}.$$
从这个公式可以清楚地看出，轨道周期仅取决于值$v_0$。如果几颗相同的卫星从地球表面上方的同一点向不同方向释放，但速度相同$v_0$，那么所有卫星将同时（经过时间$T$）会聚在同一点。

开普勒第三定律
如果现在在行星公转周期的公式 (*) 中加上能量 $E$ 用更大的表情替换她的表情 $\left( E = \gamma \frac{mM}{2a} \right)$，然后我们得到
$$T = 2\pi a^{3/2} \frac{1}{\sqrt{\gamma M}}.$$
因此，$T^2$与$a^3$成正比，即行星轨道周期的平方与大半椭圆的立方成正比。这就是开普勒第三定律。
