可以证明，一般情况下，$q$向量的正则系统由从点$O$到正则$r$边形的顶点绘制的$q = dr$向量组成，因此在每个顶点有$d$相等的向量（如果我们在这里包括“双边形”——一对相反的向量，对应于$m = 2$）；此外，$\alpha$可以等于任何数字$\frac{2\pi l}{r}$，其中$l$和$r$互质，$0 < l < r$。我们把这句话留在最后，因为在证明中公式化地我们省略了如何构造正确的向量系统$b_i$的详细解释。但是，当然，理解“本质上”的证明，找出这一点是有用的。

M51

证明如果三个正数的乘积等于一，并且这些数的和严格大于它们的倒数和，则这些数中正好有一个大于一。

令 $a, b, c$ 为给定数字。那么$abc = 1$和$(a - 1)(b - 1)(c - 1) = abc - ab - bc - ac + a + b + c - 1 = a + b + c - \frac{1}{a} - \frac{1}{b} - \frac{1}{c} > 0$，因此$(a - 1), (b - 1), (c - 1)$三个数中，两个是负数，一个是正数（从$abc = 1$开始，三个数不可能都是正数）。

M52

这五个线段可以用任意三个线段组成一个三角形。证明这些三角形中至少有一个是锐角三角形。

如果$z < x + y$，则可以由线段$x \leq y \leq z$形成一个三角形；如果$z^2 < x^2 + y^2$，则该三角形将是锐角三角形。假设有五个线段 $a_1 \leq a_2 \leq a_3 \leq a_4 \leq a_5$ ，任意三个线段形成一个非锐角三角形。然后

$$a_5^2 \geq a_4^2 + a_3^2, \quad a_4^2 \geq a_3^2 + a_2^2, \quad a_3^2 \geq a_2^2 + a_1^2,$$

因此

$$a_5^2 \geq 2a_3^2 + a_2^2 \geq 3a_2^2 + 2a_1^2 \geq 2a_1a_2 + a_1^2 = (a_2 + a_1)^2,$$

也就是说，$a_5 \geq a_2 + a_1$，因此不可能由线段$a_1, a_2, a_5$形成三角形。
