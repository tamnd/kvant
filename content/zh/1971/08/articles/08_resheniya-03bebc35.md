M50

正 $n$ 边形的顶点以多种颜色显示（每种颜色只有一种颜色），因此相同颜色的点可作为正多边形的顶点。证明在这些多边形中找到相等的多边形。

假设通过着色去除一些正则$n$-gon的顶点，使得所有相同显示的顶点形成不同的正多边形：$m_1$-gon，$m_2$-gon，$m_3$-gon，...，其中$m_1 < m_2 < m_3 < ...$。这些数字中最小的$m_1$将在我们的推理中发挥特殊作用，我们将简单地用$m$来表示它。

让我们从 $O$ $n$ 边形的中心到其所有顶点绘制向量；让我们按顺序表示它们：$a_1, a_2, a_3, ..., a_n$ (图 1a)。然后

$$\vec{a}_1 \vec{a}_2 = \vec{a}_2 \vec{a}_3 = \ldots = \vec{a}_{n-1} \vec{a}_n = \vec{a}_n \vec{a}_1 = \frac{2\pi}{n}.$$

在这里和下面，$\vec{ab}$表示向量$a$必须逆时针旋转以使其与向量$b$重合的（最小非负）角度的大小；总是$0 \leqslant \vec{ab} < 2\pi$。

我们可以说，从点 $O$ 绘制的平面上的向量 $c_1, c_2, c_3, ..., c_q$ 形成一个规则系统，如果它们具有相等的长度并且彼此形成相等的角度：

$$\vec{c}_1 \vec{c}_2 = \vec{c}_2 \vec{c}_3 = \ldots = \vec{c}_{q-1} \vec{c}_q = \vec{c}_q \vec{c}_1 = \alpha > 0.$$

我们需要以下几乎非常重要的事实（其证明在解决方案的末尾给出）。

引理。形成正则系统的向量之和为零。

在使用引理之前，让我们对向量进行以下转换。我们假设向量 $a_1$ 指向 $m$ 边形的顶点之一。我们简单地将其表示为 $a$ 并计算与它的所有角度（正方向，即逆时针）。让我们用 $b_i$ 表示从 $a$ 旋转角度 $m \rightarrow aa_i$ 获得的向量（对于每个 $i=1,2,\dots,n$）。当处理我们刚刚构造的$a_i \rightarrow b_i$*）时（在图 1、$\delta$，为$m=3$描绘了这样的映射），向量之间的角度增加了$m$倍；更准确地说：如果$m \rightarrow a_i a_j < 2\pi$，则$\rightarrow b_i b_j = m \rightarrow a_i a_j$。因此，该映射再次将角度为$\alpha < \frac{2\pi}{m}$的正则向量系变换为正则向量系。特别是，所有向量 $b_1, b_2, \dots, b_n$ 的总和等于 0。

让我们用另一种方式计算这个总和：我们首先找到与每种颜色的顶点对应的向量的总和，然后将所有这些总和相加。我们首先考虑所有向量$a_i$，看看$m_h$边形的顶点，其中$m_h > m$。这是一个角度为 $\frac{2\pi}{m_h} < \frac{2\pi}{m}$ 的规则向量系统。映射后，它将再次形成一个正确的系统，并且所得向量之和将等于零。

现在考虑向量，看看 $m$ 边形的顶点。在这种情况下，相邻向量之间的角度等于 $\frac{2\pi}{m}$，映射后所有这些 $m$ 向量与 $a$ 向量重合，因此它们的总和将为 $m$（在 图 1 时，红色和黑色向量就是这种情况）。

所以，我们有一个矛盾：一方面，所有$b_i$的总和等于0，另一方面，它又等于$m$。因此我们的假设是不正确的。

M51

证明如果三个正数的乘积等于一，并且这些数的和严格大于它们的倒数和，则这些数中正好有一个大于一。

令 $a, b, c$ 为给定数字。那么$abc = 1$和$(a - 1)(b - 1)(c - 1) = abc - ab - bc - ac + a + b + c - 1 = a + b + c - \frac{1}{a} - \frac{1}{b} - \frac{1}{c} > 0$，因此$(a - 1), (b - 1), (c - 1)$三个数中，两个是负数，一个是正数（从$abc = 1$开始，三个数不可能都是正数）。

M52

这五个线段可以用任意三个线段组成一个三角形。证明这些三角形中至少有一个是锐角三角形。

如果$z < x + y$，则可以由线段$x \leq y \leq z$形成一个三角形；如果$z^2 < x^2 + y^2$，则该三角形将是锐角三角形。假设有五个线段 $a_1 \leq a_2 \leq a_3 \leq a_4 \leq a_5$ ，任意三个线段形成一个非锐角三角形。然后

也就是说，$a_5 \geq a_2 + a_1$，因此不可能由线段$a_1, a_2, a_5$形成三角形。
