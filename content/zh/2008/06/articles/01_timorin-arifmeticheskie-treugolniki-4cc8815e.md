练习 3.设 $a = x^{2} + y^{2}$，其中 x 和 y 互质。那么数字a的所有自然因数也都以这种形式表示。找出类似的陈述对于 $x_{+}^{2} 2 y^{2}, x_{+}^{2} 3 y^{2}, x_{+}^{2} 5 y^{2}$ 是否成立。

我们在本文中提到的理论是经典的，其存在归功于拉格朗日和高斯。然而，拉格朗日和高斯使用了不同的语言。他们研究了可由给定二次形式表示的整数的属性，即对于预定整数值 A、B、C 以及某些（任意）整数值 x 和 y，可表示为 $Ax^{2} +$ Bxy $+ Cy^{2}$。二次形式是表达式 $Ax^{2} +$ Bxy $+ Cy^{2}$ 本身，其中 x 和 y 被视为变量。这一切都始于费马，他描述了二次形式$x^{2} + y^{2}, x^{2} + 2 y^{2}$和$x^{2} + 3 y^{2}$的含义。

练习 4. 数字 7 可以表示为

$x_{+}^{2} y^{2}$ 对于某些整数 x 和 y？那么1007这个数字呢？如果 a 和 b 可以用这种方式表示，那么 a 也总是这样吗？那么对于 a + b 呢？

事实证明，存在大量代表相同数字的二次形式。拉格朗日和高斯发展了一种理论，使他们能够有效地枚举和使用这些类。

练习 5. 证明对于某些整数 x 和 y，a 可表示为 $x_{+}^{2} y^{2}$ 当且仅当对于某些整数 u 和 v 可以表示为 $5 u^{2} + 6 uv + 2 v^{2}$。

$ax^{2} + ( a + c - b ) xy + cy^{2}$.

总之，我们将指出进一步的理论可以朝哪个方向发展。这个方向确实正在积极发展，但人们主要使用不同的语言，更多的是代数语言。事实证明，不仅要考虑算术三角形，还要考虑具有方向的算术三角形。这意味着通过反射彼此产生的三角形被认为是不同的。通过旋转或平行平移彼此获得的三角形仍然可以识别。这是因为不离开飞机就无法进行反射。在我们的表示法中，三角形（a，b，c）与三角形（b，c，a）和（c，a，b）相同，但一般来说，与三角形（b，a，c）不同。等价和类的概念很容易转移到有向算术三角形。从高斯的结果可以看出，同一判别式的有向算术三角形在某种意义上可以相乘。乘法的结果仅取决于因子的等价类，而不取决于因子本身。该结果仅确定为等效的。因此，乘法实际上是对有向算术三角形类的运算，而不是对三角形本身的运算。乘法具有通常的性质：交换性（commutativity）和结合性（associativity）。此外，还可以将三角形相互分割，即存在乘法的逆运算。请注意，给定判别式的定向算术三角形的类别数量仍然是有限的。因此，有限集上存在一种自然且具有良好性质的乘法运算。这个运算对于数论非常重要。但其详细讨论已不再适合本文的格式。这里只是三角形乘法的一个显着性质：将边为 a 的三角形的类乘以边为 b 的三角形的类。然后生成的类包含一个边为 ab 的三角形！ 这意味着以下陈述（尝试证明它）：如果数字 a、b 和 c 是三个等价算术三角形的边，那么数字 abc 也是与数据等价的某个算术三角形的边。我不会列出供进一步阅读的参考文献列表（这会太长），而是简单地列出最重要的关键字。正如已经提到的，没有使用算术三角形的概念。相反，他们谈论的是二次形式的类。这些类相乘的运算称为组合。班级也被称为形成一个称为班级组的团体。有许多书籍和文章解释这些术语的含义并发展进一步的理论。
