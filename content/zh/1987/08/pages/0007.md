三次曲线

三角阶代数曲线或三次曲线是一组点 $(x, y)$, 满足 $P(x, y) = 0$， 在哪里 $P$ - 三角多项式： $P(x, y) = ax^3 + bx^2y + \dots + l$ （共10名成员）。请注意，该定义不依赖于坐标系的选择：当从一个坐标系移动到另一个坐标系时，即使是倾斜的，旧坐标也可以使用线性公式通过新坐标来表示

$$x = a_1x' + b_1y' + c_1, \quad y = a_2x' + b_2y' + c_2,$$

在新坐标中，曲线也将由三角多项式定义。

如果多项式 $P(x, y)$ 分解为较低（第一和第二）次多项式的乘积，则三次曲线称为可约曲线，否则为非传导曲线。我们有时会用字母 $\Omega$ 来表示这样的曲线 - 一些形状非常多样化的三次曲线具有正形式。例如，小$\varepsilon$（例如$\varepsilon = 0,001$）的曲线$(x + 1)(x^2 + y^2 - 1) + \varepsilon = 0$非常接近可简化曲线$(x + 1)(x^2 + y^2 - 1) = 0$，由直线$x = -1$和圆$x^2 + y^2 = 1$组成。如果将多项式展开为三个线性多项式的乘积：$P = L_0L_1L_2$，则曲线$P(x, y) = 0$将是三个直线$L_0 = 0$、$L_1 = 0$、$L_2 = 0$的并集。

事实证明，任何三角多项式都可以表示为两个这样的“强可约”多项式之和；从关于三次曲线上 9 个点的以下定理的证明可以清楚地看出这一点。

定理3.让三条直线与三个黑点相交。如果在某条三次曲线上使用三个黑点，那么第九讲就是在同一条三次曲线上。

在曲线可约化的特殊情况下，这产生了帕普斯和帕斯卡定理：如果曲线分裂成三条（黑色）直线，则定理 3 变成定理 1，如果分裂成一条直线和一条二阶曲线，则变成定理 2 和 2'。因此，在证明了定理 3 后，我们将同时获得所有先前的结果，并且在一般情况下立即获得！
