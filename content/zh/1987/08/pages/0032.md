求其速度：1）在电容器内部A点（见图ok）； 2）离开电容器后立即在B点。电容器充电至电位差U，其层间距离远小于极板的尺寸；电容器电荷远大于q。

$$A_A = q(\varphi_\infty - \varphi_A), A_B = q(\varphi_\infty - \varphi_B).$$

与电容器相距较远距离处的电势$\varphi_\infty$，我们通常将其设置为零。让我们找到势能 $\varphi_A$ 和 $\varphi_B$。

由于粒子$q$的电荷比电容器小得多，我们可以假设粒子实际上不会改变电容器的总电荷。电容器内部的场是均匀的，其强度为$E = U/d$，其中$d$是极板之间的距离。由于带负电和带正电的极板与电容器内部中心线$OO'$等距，因此该线上的电势$\varphi_{OO'}$为零。由于场是齐次的，对于点 $A, B$ 和 $C$ 我们可以写：

$$\varphi_A - \varphi_C = -E \frac{d}{2}, \varphi_B - \varphi_C = E \frac{d}{2}.$$

但是$\varphi_C = 0$，因此

$$\varphi_A = -\frac{Ed}{2} = -\frac{U}{2}, \varphi_B = \frac{U}{2}.$$

从这里开始$A_A$和$A_B$：

$$A_A = -q\varphi_A = \frac{qU}{2}, A_B = -q\varphi_B = -\frac{qU}{2}.$$

因此，

$$\Delta K_A = \frac{mv_A^2}{2} - \frac{mv^2}{2} = \frac{qU}{2},$$

$$\Delta K_B = \frac{mv_B^2}{2} - \frac{mv^2}{2} = -\frac{qU}{2},$$

从这里开始是：

$$v_A = \sqrt{v^2 + \frac{qU}{m}}, v_B = \sqrt{v^2 - \frac{qU}{m}}.$$

可以看出，如果$v^2 < \frac{qU}{m}$，则粒子根本不会流过电容器。

F1051。在感应强度为水平且等于B的磁场中，一个薄金属环以速度v滚动而不破裂，其中有一个长度为l的很小的间隙；矢量 B 垂直于环平面 (图 1)。求 AOS 角（见 图ok）等于 α 时的感应电动势。

找到电动势的直接方法是将环路分成小的（几乎是直线的）部分并对所有基本电动势求和。否则我们会做的。如果整体上有一个额外的回路，那么其中的电动势将等于零（电路闭合）。另一边，

$$0 = \mathcal{E}_0 + \mathcal{E}'$$

其中$\mathcal{E}_0$是所需的电势差，$\mathcal{E}'$是附加元件的感应电动势。因此，

$$\mathcal{E}_0 = -\mathcal{E}' = -uBl \sin \varphi$$

其中$u$是元素的速度，$l$是元素的长度，$\varphi$是向量$\vec{u}$与$\vec{B}$所成的角度。从图2可以看出，

$$u = 2v \sin \frac{\alpha}{2}, \varphi = \frac{\pi}{2} - \frac{\alpha}{2}.$$

因此，

$$\mathcal{E}_0 = -2Blv \sin \frac{\alpha}{2} \cos \frac{\alpha}{2} = -Blv \sin \alpha$$
