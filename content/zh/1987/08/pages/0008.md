在三次曲线上添加点

三次曲线的许多有趣的几何性质，以及它们在分析、数论、甚至组合学（编码理论）中的各种应用，都与点加法的运算有关。这种自然运算的存在是三次（不可约）曲线的特征，其几何定义基于以下事实：与曲线$\Omega$相交于两点的直线也必须有第三个交点。我们将看到定理 3 表达了该运算的一个显着性质 - 结合性：$A + (B + C) = (A + B) + C$。

曲线$\Omega$的两点$A, B$之和$A + B$定义如下。在 $\Omega$ 处选择某个“起点”$E$。使用两个点$A, B$，构造直线$AB$与$\Omega$交点的第三个点$D$，然后构造第三个交点。

图 7. 三次曲线上点相加的关联性。等式 $A + (B + C) = (A + B) + C$ 由 9 点定理得出。

曲线$y = x^3$（图 6）上的点相加起来特别简单：如果以坐标原点（0；0）为初始点$E$，那么横坐标为$x_1$和$x_2$的点之和就是横坐标为$x_1 + x_2!$的点。事实上，如果满足条件，三个点 $A(x_1; x_1^3), B(x_2; x_2^3), D(x_3; x_3^3)$ 位于同一条线上

$$\frac{x_1^3 - x_2^3}{x_1 - x_2} = \frac{x_2^3 - x_3^3}{x_2 - x_3},$$

简化后的形式为

$$x_1 + x_2 + x_3 = 0;$$

由于$E$是图$y = x^3$的对称中心，所以点$A + B$（直线$DE$与该图的第三个交点）的坐标为$(-x_3; -x_3^3)$，即横坐标$-x_3 = x_1 + x_2$。

为了对任意两点定义一个点的加法操作，有必要进行一些澄清：将与 $\Omega$ 的直线的切点考虑为双交点（对于交点 - 三重）交点，向曲线添加“无意义”点，丢弃出现在某些曲线上的“特殊”点。上一期«Kvant»第 10 篇 P. Solviev 对此进行了更详细的讨论。

对于这样的加法，曲线 $\Omega$ 上的点具有交换律 $A + B = B + A$ 非常/无（线 $AB$ 与线 $BA$ 重合）。但结合性并不那么容易证明。这可以使用定理 3 绘制 7 条直线 (图 7) 来完成。根据该定理，$A$与$B + C$以及$A + B$与$C$的连线的交点$X$位于$\Omega$上，因此

$$A + (B + C) = (A + B) + C = Y.$$
