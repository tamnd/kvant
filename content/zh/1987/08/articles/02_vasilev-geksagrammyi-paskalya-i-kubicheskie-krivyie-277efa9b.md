帕斯卡六角星
和三次曲线

物理和数学科学候选人
N·B·瓦西里耶夫

1640 年，布莱斯·帕斯卡（Blaise Pascal）（当时他十七岁）发现了内接于圆的六连杆闭合折线的非凡性质。在帕斯卡称之为“神秘六芒星”的新兴配置（图1）中，一些三个交点不可避免地位于同一条直线上。帕斯卡以海报的形式发表了他的发现，出版了五十份以分发和转发给个别科学家。帕斯卡的著作和杰拉德·笛沙格四年前出版的短篇著作《使用透视的一般方法之一的样本》为一门新的数学学科——投影几何奠定了基础。就在那时，人们意识到“古代知识并不是一切”（皮埃尔·费马的说法）——直到那时，古希腊几何学家的成就被认为是无与伦比的。

以最后一位古代几何学家之一的名字命名——亚历山大的帕普斯，他生活在公元三世纪。 e., - 关于六连折线的相关定理，类似于帕斯卡定理；这就是我们故事开始的地方。

我们不会详细讨论帕普斯和帕斯卡定理的几何证明和众多推论，而只会涉及一个重要主题 - 几何变换的使用，包括中心投影。我们的主要目标是表明“六角星”的性质只是与代数几何相关的更普遍事实的一部分，代数几何是 19 世纪和 20 世纪数学最深刻的分支之一。我们将看到，同样的事实也要求三次曲线上“点加法”运算的主要性质（其在数论中的应用将在上一期《Kwan》中讨论）。

从某种意义上说，“逆”定理也是成立的。

定理2'。如果红色轨迹与三条半线相交的黑点中，三个位于直线上，另外五个位于圆上，则该点也位于同一个圆上。

正如帕斯卡本人立即意识到的那样，他的定理可以得到显着的推广：除了圆之外，还可以出现椭圆、双曲线或抛物线，或者可以通过圆的中心投影获得这些曲线中的任何一条。因此，根据圆的帕斯卡配置，可以获得这些曲线中任何一条的配置。

所有这些曲线都称为二阶曲线，因为从中我们可以定义 $P(x, y) = 0$ 形式的方程，其中 $P$ 是二阶多项式：

$$P(x, y) = ax^2 + bxy + cy^2 + dx + ey + f.$$

奇怪的是，当多项式 $P$ 分解为两个线性因子时，帕斯卡定理对于退化情况仍然成立：在这种情况下，二阶 $P(x, y) = 0$ 变成了一对直线，帕斯卡定理变成了帕普斯定理。

帕斯卡圆定理有许多不同的证明（例如，参见 «Kvant» 1982，第 7 期，第 2 页，书籍 [1]、[2]、[3]）。

三次曲线

三角阶代数曲线或三次曲线是一组点 $(x, y)$, 满足 $P(x, y) = 0$， 在哪里 $P$ - 三角多项式： $P(x, y) = ax^3 + bx^2y + \dots + l$ （共10名成员）。请注意，该定义不依赖于坐标系的选择：当从一个坐标系移动到另一个坐标系时，即使是倾斜的，旧坐标也可以使用线性公式通过新坐标来表示

$$x = a_1x' + b_1y' + c_1, \quad y = a_2x' + b_2y' + c_2,$$

在新坐标中，曲线也将由三角多项式定义。

如果多项式 $P(x, y)$ 分解为较低（第一和第二）次多项式的乘积，则三次曲线称为可约曲线，否则为非传导曲线。我们有时会用字母 $\Omega$ 来表示这样的曲线 - 一些形状非常多样化的三次曲线具有正形式。例如，小$\varepsilon$（例如$\varepsilon = 0,001$）的曲线$(x + 1)(x^2 + y^2 - 1) + \varepsilon = 0$非常接近可简化曲线$(x + 1)(x^2 + y^2 - 1) = 0$，由直线$x = -1$和圆$x^2 + y^2 = 1$组成。如果将多项式展开为三个线性多项式的乘积：$P = L_0L_1L_2$，则曲线$P(x, y) = 0$将是三个直线$L_0 = 0$、$L_1 = 0$、$L_2 = 0$的并集。

事实证明，任何三角多项式都可以表示为两个这样的“强可约”多项式之和；从关于三次曲线上 9 个点的以下定理的证明可以清楚地看出这一点。

定理3.让三条直线与三个黑点相交。如果在某条三次曲线上使用三个黑点，那么第九讲就是在同一条三次曲线上。

在曲线可约化的特殊情况下，这产生了帕普斯和帕斯卡定理：如果曲线分裂成三条（黑色）直线，则定理 3 变成定理 1，如果分裂成一条直线和一条二阶曲线，则变成定理 2 和 2'。因此，在证明了定理 3 后，我们将同时获得所有先前的结果，并且在一般情况下立即获得！

在三次曲线上添加点

三次曲线的许多有趣的几何性质，以及它们在分析、数论、甚至组合学（编码理论）中的各种应用，都与点加法的运算有关。这种自然运算的存在是三次（不可约）曲线的特征，其几何定义基于以下事实：与曲线$\Omega$相交于两点的直线也必须有第三个交点。我们将看到定理 3 表达了该运算的一个显着性质 - 结合性：$A + (B + C) = (A + B) + C$。

在构建多角形的过程中出现的整数点的比例表明存在多角形的连续类似物；事实上，事实证明，任何可约或不可约三次曲线$\Omega$的点都可以与数值$t$相关联 - 在曲线$\Omega$上引入“良好的参数化” - 因此对于任何与参数$t_1, t_2, t_3$在三个点处与$\Omega$相交的直线，满足条件$t_1 + t_2 + t_3 = 0$。 （如果曲线 $\Omega$ 包含一个椭圆形，即 图 106 处的圆，则参数 $t$ 的值取决于加上“周期”的整数倍$T$，在绕椭圆形运行时，值 $t$ 会发生变化。）正如我们所看到的 (图 6)，在曲线上$y=x^3$“好参数”是点$(x, y)$的横坐标。我们再举一个例子。让$\Omega$由三条直线$AB, BC, CA$组成。分别位于这些线上的点 $M, N, L$ 位于同一条线上的条件具有以下形式

$$\frac{MA}{MB} \cdot \frac{NB}{NC} \cdot \frac{LC}{LA} = 1$$

（墨涅拉俄斯定理）。这里，每行上的“好参数”$t$可以被视为相应比率的对数：如果三个数字的乘积为1，那么它们的对数之和为0。同样，您可以明确地为其他可约和特殊三次曲线表示“好参数化”，例如$y^2=x^3$和“笛卡尔叶”$y^2=x^3-x^2$（参见本书的第一页） [6]）。

对于不可约不可约三次曲线，“良好参数化”的存在与点加法运算密切相关，其明确表达需要熟悉椭圆函数理论，这是一个美丽的数学分析领域，被许多 19 世纪最伟大的数学家研究过。

最近（1976年），美国数学家 F. Griffithist 指出，写了一篇“很好的参数化”——三阶标称曲线的一个特征：如果将参数为$t_1, t_2$和$t_3$的三条曲线位于平面上，则通过其中一个点可以画出一条与另外两点相交的直线，同时三个交点的参数始终满足条件$t_1+t_2+t_3=0$，那么这三部分都包含在一条三次曲线中。 （这是任何测谎仪都位于三次曲线上的陈述的连续模拟。）
