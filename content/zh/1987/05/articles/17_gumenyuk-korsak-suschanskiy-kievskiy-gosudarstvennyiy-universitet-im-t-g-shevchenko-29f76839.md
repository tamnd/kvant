⟦folio 55⟧

基辅国立大学
他们。舍甫琴科

数学
笔试
选项1
（力学与数学学院）

1. 正三角形棱体的高度等于$h$，其侧边与棱体底面的平面倾斜$\varphi$角度。求初级的体积。

2. 解决不等式
$$\log_3 x + 1 \geq 3 \log_2 x$$.

3. 解方程
$$\sqrt{\frac{1 + \sin x}{6}} + \sin x = 0.$$

4. 菱形$ABCD$的边等于$a$。点$M$和$N$分别是边$AB$和$CD$的中点，$E$是边$BC$的内点，线段$AE$和$MN$相交于点$O$。四边形$OECN$的面积与菱形$ABCD$的面积之比为$k$和$\cos A = \frac{4k - 1}{3}$。找到线段$ED$。对于$k$的每个值是否存在满足问题条件的菱形？

5. 求所有能被 15 整除且仅用数字 0.1 书写的七位数字的总和。

选项2
（放射物理系）

1. 解决不等式
$$\log_{25}(6 - x)\log_5 x < 1$$.

2. 解方程
$$\text{tg} x = \text{tg}^3\left(\frac{\pi}{4} - x/2\right).$$

3. 两个容器装有密度分别为 $d$ 和 $D$ 的液体。此外，它们的重量分别为$q$和$Q$公斤，包括船只本身的重量。如果每个容器的重量与其中所含液体的重量相同，求它们的体积比。

4. 半径为 2 的球接触三角形底面的所有边。球的中心位于 prim 内部，其高度位于距顶部 $2\sqrt{3}$ 的位置。证明首要性是正确的。求 prim 的高度。

5. 质点$M_1$沿轴$ox$向负方向以2m/s的速度移动，质点$M_2$沿直线$y = \sqrt{3}x$向矢量$(1, \sqrt{3})$方向以3m/s的速度移动。在初始时刻，点$M_1$的坐标为$(5; 0)$，点$M_2$的坐标为$(-\frac{3}{2}; -\frac{3\sqrt{3}}{2})$。在什么时间点之间的距离最小？

选项3
（化学系）

1. 从40吨矿石中冶炼出20吨含6%杂质的金属。如果金属不进入冶炼过程中形成的炉渣，那么矿石中所含的杂质百分比是多少？

2. 解方程
$$\sin 2x - \cos 2x = 1 - 2(\cos x - \sin x).$$

3. 解决不等式
$$2 \log_2^2 |x - 1| + \log^2 \frac{(x - 1)^2}{8} \leq 9.$$

4. 几何级数的前十一项之和是其后续十一项之和的 20%。第一个级数比第十一个级数少多少倍？

5. 这是两个具有同等理由的正确观点。其中第一个侧肋相对于底座平面的倾斜角度是第二个侧肋相对于底座平面的倾斜角度的两倍，并且第一侧肋的体积是第二侧肋的体积的4倍。求第一次灌注时侧肋相对于底座平面的倾斜角度。

选项4
（图书馆教员）

1. 解方程
$$\sin \frac{x}{2} + \cos x = 1.$$

2. 解决不等式
$$\log_0.5 \frac{x - 4}{2x + 5} > 1.$$

3. 三角形的底是$a$。求平分车前草并平行于底部的线段的长度。

4. 求解方程组
$$\begin{cases} x + y + z = 18, \\ y + z + x + y = 30, \\ z + x + y + z = 24. \end{cases}$$

5. 正四边形底面的二面角为$a$，底面的体积为$v$。求棱柱侧面的面积。
