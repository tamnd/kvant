关于随机游走

物理和数学科学候选人
S.I.索沃廖夫

在根据詹尼·罗达里的童话《西波里诺和他的朋友们》改编的广播中，侦探卡罗特先生按照以下原则寻找被找回的西波里诺：

“退一步，前进，
强盗不会离开我们。”

如果这个搜索原理的有效性不是从概率论定理得出的，那么作者可能会认为它是一个笑话。我们的笔记与这个定理和相关问题有关。

随意行走在荒野中

让我们标记线上的整数点，拿一枚硬币和一个筹码。假设在时间 0 点$a \in Z$ 处有一个令牌。我们来抛一枚硬币吧。如果它落在徽章上，则将筹码 1 向右移动，如果它落在尾部，则将筹码 1 向左移动。然后我们再次扔硬币，并按照这个规则进行操作，等等。如果硬币没有缺陷，那么芯片在$t$（$t = 0, 1, 2, \dots$）时刻站在$k \in Z$点，在下一个时刻$t + 1$以1/2的概率结束于点$k + 1$或以相同的概率结束于点$(k - 1)*$。

所描述的过程称为在从点 $a$ 开始的直线上的整数点集合 $Z$ 上的对称随机游走。这种行走称为对称，因为硬币有头和尾，权利相等。

稍微澄清 Gianni Rodari 童话故事中的情况，我们假设侦探 Carrot 在寻找 Cipollino 时，在集合 $Z$ 中执行对称随机游走（在硬币的帮助下）。

*) 事件$x$的概率$p(x)$是该事件发生可能性的某种数值特征。不可能事件的概率等于 0，可靠事件的概率等于 1，一般为 $0 \leq p(x) \leq 1$。在复杂的情况下，概率是通过公理确定的，但在本文中，公理理论将被少量的常识所取代。特别是，如果几个事件同样可能发生，那么它们的概率是相同的；例如，在非作弊的骰子上得到平分（或图案）的概率当然是 1/6，在非作弊的硬币上得到正面的概率是 1/2。

击中给定点的概率

让令牌从点 0 开始沿直线行走。一个有趣的问题是，在时间 $t$ 时，令牌最终到达位置 $k$ 的概率是多少。换句话说，$t$连线轨迹到达$(t; k)$点的概率是多少？让我们表示这个信念$P_t(k)$。所提出问题的答案取决于从点 $(0; 0)$ 到点 $(t; k)$ 的轨迹数 $S_t(k)$。

我们绘制的由数字$S_t(k)$组成的表格，就是所谓的帕斯卡三角形。它总是逐列生成条件 $S_0(0) > 1$ 和对应关系 (1)。例如：

$$\begin{align*}
S_1(-1) &= S_0(-2) + S_0(0) = 0 + 1 = 1, \\
S_1(1) &= S_0(0) + S_0(2) = 1 + 0 = 1, \\
S_2(-2) &= S_1(-3) + S_1(-1) = 0 + 1 = 1, \\
S_2(0) &= S_1(-1) + S_1(1) = 1 + 1 = 2, \\
S_2(2) &= S_1(1) + S_1(3) = 1 + 0 = 1,
\end{align*}$$

等等。

当然，$t$-链接轨迹的数量是$(t - 1)$-链接轨迹的两倍——毕竟，每个$(t - 1)$-链接轨迹都会生成两个$t$-链接轨迹。因此，有 2 个单连杆轨迹，4 个双连杆轨迹，依此类推，$t$-连杆轨迹 – $2^t$。

西波里诺会被抓住吗？

假设直线上的点 0 处有一个不均匀的 Cipollino，并且在点 $k$ 处有一座 Morkovu 桥。我们假设侦探在寻找 Cipollino 时，从时间 0 线上的点 $k$ 开始执行对称随机游走。 Morkova 的主人找到 Cipollino 的概率有多大，即他最终会到达 0 点吗？

我们将这个概率表示为$P(k)$。与任何概率一样，$P(k)$ 是其中的一部分：

$$0 \leq P(k) \leq 1.$$

请注意$P(0) > 1$（如果$k = 0$，则在时间 0 时侦探和 Cipollino 已处于同一点，

记住——一个可靠的事件，其概率等于1）。如果$k \neq 1$，那么由于侦探从点$k$出发，只有在离开点$k$后的下一时刻经过相邻点$k - 1$和$k + 1$才能到达点0，所以半和定律是有效的：

$$P(k) = \frac{1}{2} P(k - 1) + \frac{1}{2} P(k + 1).$$

这里考虑到每单位时间从点$k$到点$k - 1$的转变以概率$1/2$发生；从点$k$移动到点$k + 1$也是如此。

考虑具有直角笛卡尔坐标系 $xOy$ 的平面上的点 $M_k(k; p(k))$。由于连接点$(x_1; y_1)$和$(x_2; y_2)$的线段的中点是点$\left( \frac{x_1 + x_2}{2}; \frac{y_1 + y_2}{2} \right)$，因此显然点$M_k$（其中$k \neq 0$）是线段$M_k - 1M_k + 1$的中点。因此，点 $M_k$（其中 $k \geq 0$）位于一条射线上，点 $M_k$（其中 $k \leq 0$）位于一条射线上。这两条射线均从点 $M_0(0; 1)$（自 $P(0) > 1$ 起）发出，位于由 图 4 围成的条带 $0 \leq y \leq 1$（自 $0 \leq P(k) \leq 1$ 对于任何 $k$）。因此，它们构成直线 $y = 1$。所有点 $M_k(k; P(k))$ 都位于这条线上，因此 $P(k) \geq 1$ 对于任何 $k$。

所以，我们已经证明，侦探迟早会以 1 的概率找到 Cipollino，无论他从哪一点$k$开始徘徊！

在平面和太空中随机行走

考虑平面上的三角形网格；让我们拿一个芯片和一个（未变形的）芯片。我们将用数字 1、2、3、4、5、6 来表示网格上的六个方向运动，如 图 5 所示。让我们在网格的一个节点中放置一个芯片并投掷一个骰子。让我们按照骨骼指示对应的方向将芯片移动到相邻节点。然后我们再次掷骰子，并根据这个规则行动，等等。这个过程称为平面三角网格上的对称随机游走。

假设Cipollino隐藏在其中一个网格节点中，侦探Morkovu先生在网格上进行随机对称游走；他会找到西波里诺吗？事实证明，在这种情况下，侦探找到受害者的概率也是一。这也是概率论的一个数学定理，号称“条条大路通罗马”。我们不给出它的证明——它比直线上随机游走定理的证明要复杂一些。对于平坦的方形网格，结果将是相同的（您必须使用规则地形形状的“骰子”，而不是常规骰子）。

关于应用的两句话

本笔记的俏皮性质不应误导读者。随机游走理论是概率论的一个重要且非常有用的分支。它成功地应用于各种发展过程的研究（物理、化学甚至经济学）。特别是近年来，使用随机数传感器可以轻松地在计算机上模拟随机过程。它在使用所谓的蒙特卡罗方法实际寻找特定微分方程的解方面得到了有效且意想不到的应用。但这是一个单独故事的主题。
