他们让我进去。因此，艾哈迈斯纸莎草纸以一张表格开始，其中所有 2/n 形式的 dobis（从 2/5 到 2/99）都写为股份之和。该表还用于整数除法。例如，我们如何将 5 除以 21：

$$\frac{5}{21} = \frac{1}{21} + \frac{2}{21} + \frac{2}{21} = \frac{1}{21} + \left( \frac{1}{14} + \frac{1}{42} \right) + \left( \frac{1}{14} + \frac{1}{42} \right) = \frac{1}{21} + \frac{2}{14} + \frac{2}{42} = \frac{1}{7} + \frac{1}{7} + \frac{1}{7} + \frac{1}{42}.$$

埃及人还知道如何乘法和除法 dobi。但乘法时，你必须将分数乘以分数，然后，也许，再次使用表格。分裂的情况更加复杂。

维维隆人走了一条完全不同的道路。事实上，Vivilon 中的数字系统是十六进制 - 下一个数字的每个单位都比前一个数字大 60 倍。 Viviler，条目 14″ 42′ 38 表示数字 14·60²+42·60+38，即我们条目中的数字 52958（只有 Vivilonians 没有使用我们的数字，而是由 Klints 组成的其他名称）。这就是为什么维洛尼亚人的 dobis 不是十进制，而是十六进制。事实上，我们曾经并且现在使用这样的多比来表示时间和角度。例如，时间 3 小时 17 分 28 秒可以这样写：3.17′28″ 小时（读为 3 整，17 60 28 三千六百小时）。他们没有用“六十”、“三千六分”这样的词，而是简单地说：“第一小分数”、“第二小分数”。这就是我们的单词“分钟”（拉丁语“较小”）和“秒”（拉丁语“第二”）的来源。因此，维维隆式的“dobei”命名方式至今仍保留着其意义。
