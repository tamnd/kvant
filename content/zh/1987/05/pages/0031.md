⟦folio 29⟧

如果已知偶极子远离电容器的速度为 $v_0$，则计算电容器中心偶极子的速度。电容器极板之间的距离$d$，偶极子的质量$m$。忽略重力的影响。

电容场是电位的；因此，在电容器中，偶极子也会具有势能。该能量等于

$$W_\pi = (+q)\varphi_x + (-q)\varphi_x = q\frac{\varepsilon}{d}(x_+ - x_-) = -ql\frac{\varepsilon}{d},$$

其中$x_+$和$x_- = x_+ + l$是电荷$+q$和$-q$的坐标，$\varphi_x$和$\varphi_x$是坐标为$x_+$和$x_-$的点的电势；压印带电板上缺少坐标$x$（参见图ok）。通过选择这种参考点，将单位电荷从压印板移动到正电荷所做的功等于 $\varepsilon$。

由能量守恒定律我们求出偶极子所需的速度：

$$\frac{mv_0^2}{2} = \frac{mv^2}{2} - ql\frac{\varepsilon}{d},$$

在哪里

$$v = \left(v_0^2 + \frac{2ql\varepsilon}{md}\right)^{1/2}.$$

F1036。位于主水平地板上的质量为 $m = 20$ g 的物体连接到两根刚度为 $k = 10^4$ N/m 的相同弹性线上。将一根线固定在墙上，第二根线的自由端开始以 $v = 10$ m/s 的速度沿水平方向拉动。如果每根线在绝对伸长$\Delta l_{\text{np}} = 5$厘米时断裂，哪根线会断裂？假设胡克定律适用于螺纹，直到它们断裂为止；没有培训。

方便监控线的拉伸过程；它将从静止系统（图1）移动到坐标系，以$v/2$的速度向右塌陷；第一时刻的物体位于坐标原点（$x = 0$），以$v/2$的速度向左移动。

作用在本体上的弹力不取决于螺纹端部的运动，而仅取决于本体相对于初始初始位置$x$的位移：

$$F_x = -k(\Delta l + x) + k(\Delta l - x) = -2kx,$$

其中$\Delta l = (v/2)t$是主体混合等于$x$时螺纹混合端的绝对值。因此，身体将在第一个初始位置周围进行频率为 $\omega = \sqrt{2k/m} = 10^3$ Hz 的简谐振动。身体的混合随时间按规律变化

$$x = -\frac{v}{2\omega}\sin \omega t,$$

和线伸长率 -

$$\Delta l_1 = \frac{v}{2}t - \frac{v}{2\omega}\sin \omega t,$$

$$\Delta l_2 = \frac{v}{2}t + \frac{v}{2\omega}\sin \omega t.$$

由此可以清楚地看出，在振荡的四个半周期中 -

$$2n \frac{T}{2} < t < (2n + 1) \frac{T}{2} \left( T = \frac{2\pi}{\omega}, n = 0, 1, 2, \dots \right)$$

- 在奇数半周期内，线会拉伸得更厉害 - 第二个。

因此，如果满足条件，第二个线程将中断
