康维尔公式

Convel 公式允许我们在不计算任何概率的情况下找到任意 $B$ 和 $A$ 的 $d(B, A)$。为了解释这个公式，我们需要定义Convel多项式$K_{XY}(t)$字$X, Y$。

在图 2，单词$Y$在单词$X$下方写入六次，每个新单词$Y$与前一个相比向右移动一个位置（对于$n$字母单词，单词$Y$将被写入$X, n$次）。

单词 $Y$ 的每次移位都会被分配一个数字 1 或 0，具体取决于位于共同位置 $X$ 和 $Y$ 中位于彼此下方的所有字母是否重合。由 0 和 1 生成的单词（长度为 $n$）称为 $X$ 和 $Y$ 的相关性，并表示为 $\langle XY \rangle$。因此，例如，对于第二个班次$Y$，一般位置是相同的，因此在第二行图2处写入一个单元 - 单词$\langle XY \rangle$的第二个字母。

在我们的例子中
$$\langle XY \rangle = 010011.$$

一般来说，设$\langle XY \rangle = e_1 \dots e_n$（其中$e_i$是零或一）。那么单词$X, Y$的Convel多项式定义如下：
$$K_{XY}(t) = e_1 + e_2 t + \dots + e_n t^{n-1}.$$

在我们的例子中$K_{XY}(t) = t + t^4 + t^5$。一个非常奇怪的定义！无论如何，完全不清楚如何才能找到他。但它是有效的——Convel 的公式是基于它的：

$$d(B, A) = \frac{K_{AA}(1/2) - K_{AB}(1/2)}{K_{BB}(1/2) - K_{BA}(1/2)}.$$

当加德纳将这种不寻常的公式的选择归因于“超凡脱俗”的大满贯时，人们可以理解他：好吧，魔法，仅此而已！
