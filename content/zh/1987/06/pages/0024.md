M1029。在算术级数的项中，我们能够选择形成递增几何级数的项。证明

a) 请注意，线 AC 必须经过点 D$_1$ 和 E$_1$，相对于这些线 (图 1) 与 D 和 E 对称。由此得出以下构造：

我们相对于给定的线 OE 和 OD 反射点 D 和 E（O 是它们的交点）；穿过它们的图像 D$_1$ 和 E$_1$ 画一条直线，直到它在 C 点与 DO 相交，在 A 点与 EO 相交（如果是 D$_1=E_1$，则任意通过 D$_1$ 画一条直线，但要与射线 DO 和 EO 相交，图 2）；我们找到独占三角形的第三个顶点B作为直线AD和CE的交点。

这种构造并不总是可行：结果可能是 D$_1$E$_1$||DO、D$_1$E$_1$||EO 或 AD||CE。但即使在“构造”三角形的情况下，线 AE 和 CD 也可能不是其内角的平分线，而是其外角的平分线。来自平等

$$\angle DOE = \angle AOC = 180^\circ - \frac{1}{2} (\angle A + \angle C) = 90^\circ + \frac{1}{2} \angle B$$

由此可见，该问题仅适用于$\alpha = \angle DOE > 90^\circ$。但这个条件还不值得。另外，还需要保证A、C点存在，并且D、O、E点位于直线AC的同一侧。可以证明问题是可解的当且仅当

$$-2 \cos \alpha < DO : EO < -1/2 \cos \alpha \text{ при } \alpha \neq 120^\circ$$

（在这种情况下，解决方案是唯一的）或当

$$DO = EO, \alpha = 120^\circ$$

（在这种情况下 D$_1 = E_1$，解决了无穷多个）。我们将研究的细节留给读者。

b) 构造点 D$_1$ 和 E$_1$，如解决问题 a) 一样。三角形 DEE$_1$ 是规则三角形 ($\angle EDE_1 = 2\angle EDO = 60^\circ, DE = DE_1$)。如果 D$_1 = E_1$ (图 2)，则 DO 和 EO 是该三角形的二等分线，因此 O 是其中心，$\angle DOE = 120^\circ$。根据等式(1)，角B等于$60^\circ$。

现在让 D$_1 \neq E_1$ (图 3)。由于 EE$_1 = ED = ED_1$，三角形 D$_1$EE$_1$ 是等腰三角形，这意味着

$$\angle EE_1A = 180^\circ - \angle ED_1A = 180^\circ - \angle EDA$$

（这里我们利用点 E$_1$ 和 D$_1$ 位于角 AOC 内，即在 A 的一侧，因为角 DOE 是钝角）。从等式（2）可知，点 A、D、E 和 E$_1$ 位于同一圆上（图 3）。因此$\angle EAD = \angle EE_1D = 60^\circ$和$\angle BAC = 2\angle EAD = 120^\circ$。
