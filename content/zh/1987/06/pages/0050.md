⟦folio 48⟧

压力$p = p_1 + p_2$。在这种情况下，压力$p_1$和$p_2$是不同气体的分压，根据道尔顿定律，它们加起来就是总压力$p$。

让我们再次注意，道尔顿定律仅适用于分子结构无关紧要的理想气体。经验表明，在极高的压力（大约数十个大气压）下，会观察到与该定律的偏差。

如果我们为每种气体写出门捷列夫-克拉佩龙方程，那么根据气体混合物的道尔顿定律，我们可以得到

$$pV = \left( \frac{m_1}{M_1} + \frac{m_2}{M_2} + \dots + \frac{m_n}{M_n} \right) RT,$$

或者

$$pV = (v_1 + v_2 + \dots + v_n)RT,$$

其中 $v_i = m_i/M_i$ 是混合物中给定气体的摩尔数。这种对应关系称为气体混合物的状态方程。考虑阿伏加德罗定律，根据该定律，任何物质的一摩尔含有 $N_A = 6,02 \cdot 10^{23}$ 个分子（$N_A$ 是阿伏加德罗数），最后一个等式可以重写为

$$pV = \left( v_1 N_A + v_2 N_A + \dots + v_n N_A \right) \frac{R}{N_A} T = (N_1 + N_2 + \dots + N_n) kT = NkT.$$

这里$N_i = v_i N_A$是现有气体的分子数，$k = R/N_A = 1,38 \cdot 10^{-23}$J/K是玻尔兹曼常数。因此，事实证明，给定温度下气体混合物的压力仅取决于分子总数，而不取决于它们的类型。这是理想气体分子理论的主要结论之一。

让我们使用道尔顿定律和气体混合物的状态方程来考虑一些问题。所有这些不同年份的任务都提供给莫斯科物理技术学院笔试的申请者。

问题1. 将$m = 3$ g 水引入体积为$V = 10$ l 的容器中，充满压力为$p_1 = 10^5$ Pa、温度为$T_1 = 273$ K 的干燥空气。将容器加热到$T_2 = 373$ K 的温度。在此温度下潮湿空气的压力是多少？

容器中潮湿空气的压力是干燥空气和水蒸气的分压之和：

$$p = p_B + p_\pi.$$

同时

$$p_B = p_1 \frac{T_2}{T_1} = 1,37 \cdot 10^5 \text{ Pa}.$$

考虑蒸汽是摩尔质量为 $M = 18$ g/mol 的理想气体，并假设所有的水都会蒸发，我们发现

$$p_\pi = \frac{m}{M} \frac{RT_2}{V} = 0,52 \cdot 10^5 \text{ Pa}.$$

这个压力小于373K时的饱和蒸汽压，等于$p_\pi = 10^5$Pa。因此，蒸汽是不饱和的，我们的假设是正确的。

因此，

$$p = p_B + p_\pi = 1,89 \cdot 10^5 \text{ Pa}.$$

问题 2. 温度为 $T_1 = 300$ K 时体积恒定的容器含有 $v_1 = 1$ 摩尔氖气和 $v_2 = 2$ 摩尔氢气。容器内压力$p_1 = 10^5$Pa。当温度升高到$T_2 = 2400$K时，压力升高到$p_2 = 8,8 \cdot 10^5$Pa。哪部分氢分子离解成原子？

对于氖气和分子氢的混合物，在温度 $T_1$ 时，我们可以写出方程

$$p_1 V = (v_1 + v_2) RT_1,$$

其中$V$是容器的体积。

如果我们用$\alpha$表示氢解离度，即衰变分子数与解离前分子总数的比值，那么在$T_2$温度下，容器中有$v_1$摩尔氖、$(1 - \alpha) v_2$摩尔分子氢和$2\alpha v_2$摩尔原子氢。气体混合物的状态方程采用以下形式

$$p_2 V = (v_1 + v_2)(1 + \alpha) RT_2.$$
