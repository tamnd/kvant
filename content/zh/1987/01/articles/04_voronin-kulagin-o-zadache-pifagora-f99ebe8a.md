⟦folio 13⟧

看起来像
$$y = k(x + 1),$$
其中 $k$ 是直线的斜率。
因此，点$(x_2; y_2)$的坐标将满足方程组
$$\begin{cases} x^2 + y^2 = 1, \\ y = k(x + 1). \end{cases}$$
让我们求解该系统的 $x$ 和 $y$。将第二个方程中的值$y = k(x + 1)$代入系统的第一个方程中，我们得到
$$x^2 + k^2(x + 1)^2 = 1,$$
或者
$$(1 + k^2) \cdot x^2 + 2k^2 \cdot x + k^2 - 1 = 0.$$
若$x$满足上式，则$x$为直线$y = k(x + 1)$与圆$K$交点的横坐标，即$x = x_1 = -1$或$x = x_2$。由维埃塔定理可知
$$x_1 + x_2 = -\frac{2k^2}{1 + k^2},$$
在哪里
$$x_2 = \frac{1 - k^2}{1 + k^2}.$$
由于点 $(x_2; y_2)$ 位于直线 $y = k(x + 1)$ 上，
$$y_2 = \frac{2k}{1 + k^2}.$$
最后两个公式对应每个带点的数字$k$
$$(x_2; y_2) = \left(\frac{1 - k^2}{1 + k^2}; \frac{2k}{1 + k^2}\right),$$
躺在圆圈$x^2 + y^2 = 1$上。相反，位于圆 $K$ 上的每个点 $(x; y) \neq (-1; 0)$ 对应于斜率 $k$ 的一个且唯一的值：

$$k = \frac{y}{x + 1}.$$

这里注意，如果$k$是有理数，则点$(x_2; y_2)$由式（6）定义，具有有理坐标；反之，如果$x_2$和$y_2$是有理数，则由式（7）$k$是有理数。因此，

均匀半径圆的有理坐标点（$(-1; 0)$除外）与实直线的有理点之间建立一一对应关系。

通过强制量$k$遍历从$-\infty$到$+\infty$区间的所有有理值，我们将枚举单个半径的圆$K$上所有具有有理坐标的点（除了点$(-1; 0)$），从而找到毕达哥拉斯问题的所有原始解。

让我们给出相应的公式。设 $k = p/q, q > 0$，GCD $(p, q) = 1$。那么由式(6)可得

$$\left(x_2; y_2\right) = \left(\frac{q^2 - p^2}{q^2 + p^2}; \frac{2pq}{q^2 + p^2}\right).$$

我们基本上又得到了公式(*)！为了获得完全相同的结果，您所要做的就是对四个进行一些修改。

在$p$和$q$不同奇偶校验的情况下，公式(**)对应于原毕达哥拉斯三元组$(a, b, c) = (q^2 - p^2, 2pq, q^2 + p^2)$。如果$p$和$q$都是奇数，那么，传递给新变量$q_1 = (q + p)/2, p_1 = (q - p)/2$，GCD$(p, q) = 1$，我们得到$q^2 + p^2 = 2(q^2 + p^2), q^2 - p^2 = 4p_1q_1, 2pq = 2(q^2 - p^2)$。在 (**) 中减少 2 后我们得到

$$\left(x_2; y_2\right) = \left(\frac{2q_1p_1}{q_1^2 + p_1^2}; \frac{q_1^2 - p_1^2}{q_1^2 + p_1^2}\right).$$

注意，式(8)与式(**)的不同之处在于$x_2$和$y_2$的排列。如果发现$p_1$和$q_1$都是奇数，那么我们继续处理变量$q_2 = (p_1 + q_1)/2, p_2 = (q_1 - q_1)/2$、GCD$(q_2, p_2) = 1$等。结果，我们得到类型(**)的公式或类型(8)的公式，其中$p_1$和$q_1$具有不同的奇偶性，GCD$(p_2, q_2) = 1$。因此，有理点$(x_2; y_2) \neq (-1; 0)$对应的原解要么由(**)类型的公式给出，要么由(8)类型的公式给出，其中$p_1$和$q_1$是毕达哥拉斯方程的原解与公式(**)和(8)中圆的有理点$x^2 + y^2 = 1$(不包括点$(-1; 0)$)之间的一一对应关系遵循断言(*)。

有限截面的合理参数化

为了用方程 $x^2 + y^2 - 1 = 0$ 找到圆上的有理点，我们推导出公式（6）。它在参数$k$（取所有可能的实值）与圆上的点（除了点$(-1; 0)$）之间建立一一对应关系，并且圆上点的坐标$(x; y)$是$k$的有理函数。问题出现了：是否可以类似地定义其他曲线上的点，例如椭圆、抛物线或双曲线上的点？ （椭圆、抛物线和双曲线是有限截面；因此该截面的名称。）

要回答这个问题，请考虑由方程 $K(x, y) = 0$ 给出的平面中的曲线，其中 $K(x, y)$ 是$x$ 和 $y$ 的二次多项式。位于抛物线、椭圆和双曲线上的点满足这种对应关系。令 $(x_1; y_1)$ 为该曲线的某个不动点。让我们通过该点画一条直线，角度系数等于 $k$ (图 3)。我们将寻找曲线和直线的交点 $(x; y)$。这些点的 $(x; y)$ 坐标满足方程组
$$\begin{cases} K(x, y) = 0, \\ y - y_1 = k(x - x_1). \end{cases}$$

以与我们之前对圆相同的方式求解该系统的 $(x; y)$，我们表示第二个交点的坐标 $(x_2; y_2)$

直线 $y = y_1 + k(x - x_1)$ 与曲线 $K$ 通过参数 $k$。很容易检查您是否得到了类似的表达式
$$\left(x_2; y_2\right) = \left(\frac{A(k)}{C(k)}; \frac{B(k)}{C(k)}\right),$$
其中$A(k), B(k), C(k)$是参数$k$中次数不大于2的多项式。该公式指定了曲线$K$的有理参数化，即通过一个参数$k$的有理函数来表达曲线上一点的坐标。

公式（***）和公式（**）一样，可以求出曲线$K$上的整点。然而，现在我们对这个公式的另一种（完全出乎意料的）应用感兴趣，我们继续讨论。

在积分计算中的应用

事实证明，像这样看似无望的积分
$$I = \int \frac{dx}{\sqrt{x^2 + 3x - 4}},$$
如果我们使用适合所选曲线的合理参数化，则会采用。也就是说，如果在这种情况下我们采用曲线
$$K(x, y) = y^2 - (x^2 + 3x - 4),$$
请注意点 $(x_1; y_1) = (-4; 0)$ 位于曲线上
$$y(x) = \sqrt{x^2 + 3x - 4}$$
并考虑所有可能的直线
$$y = k(x + 4),$$
然后你得到以下参数化（自己计算！）：
$$\left(x; y\right) = \left(\frac{1 + 4k^2}{1 - k^2}; \frac{5k}{1 - k^2}\right).$$

然后 $dx = \frac{10k}{(1 - k^2)^2} dk$，因此（约简后）我们得到
$$I = \int \frac{dx}{\sqrt{x^2 + 3x - 4}} = \int \frac{dx}{y(x)} = \int \frac{2dk}{1 - k^2}.$$

最后一个积分很容易计算：
$$\int \frac{2dk}{1 - k^2} = \int \frac{dk}{1 - k} + \int \frac{dk}{1 + k} = \ln |1 + k| - \ln |1 - k| + C = \ln \left| \frac{1 + k}{1 - k} \right| + C.$$
