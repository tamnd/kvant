理论游览
问题1
1) 从狭缝$L$和$M$射出的两个波之间的路径差等于$d \sin \theta$，因此相位差为$\Delta \varphi = (2\pi d \sin \theta)/\lambda$。将振荡相加，我们得到
$y = a \cos (2\pi vt - 2\pi x/\lambda) + a \cos (2\pi vt - 2\pi x/\lambda + \Delta \varphi) = 2a \cos (\Delta \varphi/2) \cos (2\pi vt - 2\pi x/\lambda + \Delta \varphi/2)$.
如果我们表示 $\Delta \varphi/2 = \beta$，则所得振幅为 $A = 2a \cos \beta$。矢量图如图 4 所示。
2) 让我们使用矢量图 (图 5) 将 $N$ 狭缝的振动相加。所得多边形的所有边都等于$a$，边之间的角度等于$(\pi - 2\beta)$，因此，可以在多边形周围描述一个半径为$R$的圆。不难用几何方法证明
$R = a/(2 \sin \beta)$ 和 $A = a (\sin N \beta/\sin \beta)$。
原始波和结果波之间的相位差由角度 $\alpha$ 确定：
$\alpha = (\pi/2 - \beta) - (\pi/2 - N \beta) = (N - 1) \beta$.
3) 让我们将 sin $N \beta$ 和 1/sin $\beta$ 绘制为 $\beta$ 的函数，并在 $N = 8$ (图 6) 处以相同比例绘制。考虑到波的强度与振幅的平方成正比，我们将为$N = 8$（图 7）构建一个图$I = I_0 \sin^2 N \beta/\sin^2 \beta$（$I_0$是一个细胞的变化强度）。
4) 在主要最大值处，矢量图是一个矩形。此外，$2\beta = 2\pi n$，其中$n = 0, \pm 1, \pm 2, \dots$。所产生的波的应用是$Na$，强度是$I = N^2 I_0$。
5) 主要最大值的条件：
$\beta = \pi n$，或$(\pi d \sin \theta)/\lambda = \pi n$，
其中$n = 0, \pm 1, \pm 2, \dots$。从$|\sin \theta| \leq 1$开始，主极大值的数量不超过$2d/\lambda + 1$。
6) 对$\theta$的主极大值条件求微分，我们得到
$\lambda'(\theta) = (d \cos \theta)/n$.
因此，在$\Delta \lambda \ll \lambda$
$\Delta \lambda = (d \cos \theta) / n$,
$\theta = n \sqrt{1 + (\sqrt{1 - \lambda^2})^2}$.
