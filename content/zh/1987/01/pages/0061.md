2. 打开阀门后，发生气体运动过程，从而在气缸中建立相同的压力 $p_0$ 和温度 $T_0$。气体混合物的压力（根据道尔顿定律）由各组分的分压之和决定，混合物的温度由系统内能守恒定律决定。因此我们有

$$p_0 = \frac{(v_1 + v_2)RT_0}{(V_1 + V_2)},$$
$$v_1C_1T_1 + v_2C_2T_2 = (v_1C_1 + v_2C_2)T_0,$$

其中$v_1 = m_1/M_1$和$v_2 = m_2/M_2$是对应的氮气和氩气的摩尔数。气体$T_1$和$T_2$的初始温度由状态方程求得：

$$T_1 = p_1V_1/(Rv_1),$$
$$T_2 = p_2V_2/(Rv_2).$$

然后我们终于得到

$$T_0 = \frac{C_1p_1V_1 + C_2p_2V_2}{R(v_1C_1 + v_2C_2)} \approx 306\text{ K},$$
$$p_0 = \frac{(v_1 + v_2)RT_0}{V_1 + V_2} \approx 2,1 \cdot 10^6\text{ Pa}.$$

3. 我们对该问题的解决方案进行了详细分析，尽管更短的解决方案也是可能的。让我们首先证明，在重力和安培力的影响下移动的接触点将在平衡位置附近振荡。我们选择坐标轴向下的正方向（重力方向），以及绕线圈、导轨和触点形成的轮廓的正方向 - 逆时针方向（图 1）。假设在给定时刻，触点以速度$v$向下移动，触点中的电流$I$沿正方向流动，并且磁场$\vec{B}$垂直于平面图并远离我们。让我们写出接触运动方程：

$$mv' = mg - IBl,$$

其中$v'$表示时间上的任意速度，即触点的加速度（在上下文中选择电流方向的情况下，左手右侧的安培力会减慢触点的移动）。当触点移动时，任意闭环磁通量$\Phi = Blx$发生变化，并产生感应电动势$\mathcal{E} = -\Phi'$，该感应电动势与线圈中产生的左门土吉电动势$-LI'$相平衡：

$$\mathcal{E} - LI' = 0.$$

当触点向下移动时，通过电路的磁通量增加，上下文中产生的电动势导致上下文中出现电流，将其转化为磁通的增加，即制动触点的移动。选择绕过计数器的方向，这意味着根据欧姆定律，该 EMF 无效且符号为正。从 $|\mathcal{E}| = |\Phi'| = Blx' = Blv$ 开始，我们案例中的欧姆定律具有以下形式

$$Blv - LI' = 0.$$

将接触时间的运动方程相乘并用之前的等式代入 $I$，我们最终得到

$$v'' + \frac{B^2l^2}{mL}v = 0.$$

我们得到了接触速度$v$的振荡方程，因此证明了接触运动本质上是振荡的。我们不会求解这个微分方程，而是使用能量守恒定律。

假设此时触点已下降$x$，速度为$v$，电路中的电流为$I$。根据能量守恒定律，触点的势能转换为其动能并以磁场能的形式存储在电感器中：

$$mgx = mv^2/2 + LI^2/2.$$

当重力与安培力平衡时，接触速度在平衡位置$x_0$最大：

$$mg = BlI_0.$$

根据欧姆定律，电路中的电流与触点位移成正比，因此

$$Blx_0 = I_0L,$$

到平衡位置的重力功可写为：

$$mgx_0 = mg \frac{I_0L}{Bl} = L \left( \frac{mg}{Bl} \right)^2.$$

因此，能量守恒定律给出

$$L \left( \frac{mg}{Bl} \right)^2 = \frac{mv^2}{2} + \frac{L}{2} \left( \frac{mg}{Bl} \right)^2,$$

最后

$$B = g \frac{\sqrt{mL}}{v_0l}.$$

在解决这个相当复杂的问题时，许多申请人犯了一个物理错误，认为接触的动能是通过安培力而不是重力获得的。事实上，重力功的一侧转化为接触动能，另一侧转化为感应器中磁场的能量。
