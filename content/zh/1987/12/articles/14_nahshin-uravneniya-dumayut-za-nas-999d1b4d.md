⟦folio 44⟧

方程
为我们着想

V.A.纳克辛

物理学中任何计算问题的解决方案都由两部分组成：物理部分和数学部分。

当我们思考问题的条件，分析这种现象发生的物理定律，并构建适当的方程组时，我们就是物理学家。此后，物理学暂时淡出背景。现在我们是数学家，我们面临着不同的问题：如何最合理地求解所得方程组并找到答案？此外，答案必须以一般（文字）形式找到，以便等号一侧只有所需的数量（在字母名称中），而右侧是仅已知数量的组合（在相应的字母名称中也是如此）。

本文首发于1981年9月号«Kvant»。（注）

但现在已经得到了一般形式的答案，我们再次转向物理学：在替换数值数据之前，我们需要检查所需量的量纲，并从其合理性的角度分析答案。如果维度正确并且答案合理，您可以替换数据并进行计数。

所描述的解决方案阶段实际上是所有问题所固有的。然而，有时——本文将讨论的正是这种情况——经过计算后，会得到意想不到的荒谬结果，这表明决策不正确。例如，当问题的条件、直觉或常识都无法判断这个或那个过程正在朝哪个方向进行或最终结果是什么时，就会发生这种情况。

当开始解决问题时，我们被迫假设一些选择，并根据它创建一个方程组。如果答案被证明是荒谬的，你就不应该检查。我们只是不幸：我们的假设被证明是错误的。然而，我们仍然收到信息——该过程并没有朝着预期的方向发展。

⟦folio 45⟧

好吧，让我们说另一种选择等等。问题变成了一项小研究，方程变成了值得思考的事情。最终，他们不会让我们失望（当然，如果我们不让他们失望，也就是我们在制定决策时没有犯错误的话），会告诉我们过程的真实走向或者最终的结果。

让我们考虑几个具体任务。

问题1. 在粗糙斜面的顶部有一个块，通过该块抛出一根线。两个质量分别为 $m_1=3$ kg 和 $m_2=2$ kg 的物体连接到螺纹末端。当摩擦系数为$\mu=0,5$、平面与地平线的倾斜角为$\alpha=30^\circ$时，求系统的加速度以及羽毛体与平面之间的摩擦力。

系统在哪里加速？它到底在移动吗？从问题陈述中并不清楚。同时，了解这一点非常重要。因此，如果系统运动，就会发生滑动摩擦，该力的模型等于$F_{\text{rp}}=\mu N$（N 是法向反作用力的模型）。如果系统结束，则第一物体受到静摩擦力的影响，仅知道该静摩擦力不大于滑动摩擦力。

也许直觉会有所帮助？一方面，第一个物体比第二个物体重，但另一方面，第二个物体悬挂在空中，而第一个物体位于斜面上，而且还有一列火车。不，直觉对我们没有帮助，我们需要分析。让我们尝试将我们的担忧转移到方程式上。

假设木块顺时针旋转，即第二个物体以微小的加速度下降，第一个物体以相同的加速度沿平面上升。让我们描述作用在每个物体上的连杆（图1），并写出第二定律的方程组。牛顿在相应方向上的投影（对于第一个物体，这些是沿平面并垂直于平面的方向，对于第二个物体，这是垂直方向）：

$$\begin{align*}
T &= m_1 g \sin \alpha - \mu N = m_1 a, \\
N &= m_1 g \cos \alpha = 0, \\
m_2 g &= T = m_2 a.
\end{align*}$$

求解这个系统，我们得到

$$a = g \frac{m_2 - \mu m_1 \cos \alpha - m_1 \sin \alpha}{m_1 + m_2} \approx -1.6 \text{ m/c}^2$$

— 投影到所选方向的投影为负。这意味着我们的假设是错误的。

那么系统会发生什么呢？向相反的方向移动？又是带着什么样的诚意呢？

在这个地方，很多人都犯了一个错误，认为系统是用相同的加速模型（$\approx 1.6 \text{ m/c}^2$）向相反方向加速的。有时这可以被认为是有效的。例如，如果该系统中不存在摩擦力，则当选定的运动方向变为相反时，所有力的投影都会改变其符号，并且加速度的模数将相同，但符号相反。在我们的例子中，在新的假设下，摩擦力的投影仍然为负，因此相应的方程组将不同（图2）：

$$\begin{align*}
m_1 g \sin \alpha - T - \mu N = m_1 a, \\
N - m_1 g \cos \alpha = 0, \\
T - m_2 g = m_2 a.
\end{align*}$$

⟦folio 46⟧

从这里

$$a = g \frac{m_1 \sin \alpha - \mu m_1 \cos \alpha - m_2}{m_1 + m_2} \approx -3,6 \text{ m/c}^2.$$

加速度预测结果再次为负；因此，新的假设也是不正确的。

因此，这些方程为我们“思考”后得出系统没有加速的结论，即

$$a = 0.$$

这意味着要找到摩擦力，或更准确地说是静摩擦力，不能使用公式 $F_{\tau p} = \mu N$，该公式对于滑动摩擦力有效。

为了确定所需的力，让我们看看还有哪些其他力（或其投影）沿斜面方向作用在第一个物体上。这是弦力的投影，其模数等于$m_1 g \sin \alpha = 15 \text{ H}$，以及线张力，其模型可以从第二主体的静止状态找到：$T = m_2 g = 20 \text{ H}$。因此，静摩擦力沿平面向下，大小相等

$$F_{\tau p, n} = T - m_1 g \sin \alpha = 5 \text{ H}.$$

顺便说一句，不难验证，在这种情况下摩擦力$F_{\tau p, n} = 5 \text{ H}$确实小于$\mu N = \mu m_1 g \cos \alpha \approx 13 \text{ H}.$

问题 2. 在温度 $t_1 = -10^\circ \text{C}$ 下含有 $m_1 = 3$ kcal 的热量计在温度 $t_2 = 80^\circ \text{C}$ 下充满 $m_2 = 2$ kcal。热交换的结果将达到什么温度？不考虑热量计的热容量。

很明显，最终温度$t$在$-10$到$+80^\circ \text{C}$的范围内：

$$-10^\circ \text{C} < t < 80^\circ \text{C}.$$

因此，它可以大于$0^\circ \text{C}$（冰牵引温度）、小于该温度或等于该温度。不可能提前说出结果到底是什么。我们将“通过触摸”实现目标，通过可能的选择并依靠等式的意志。

我们假设 $t > 0^\circ \text{C}$，即热量计中只有水。然后冰分三个阶段接受特洛：本身是冰，从$-10$加热到$0^\circ \text{C}$，在$0^\circ \text{C}$变成水，并且已经是水，从$0^\circ \text{C}$加热到$t$。在这种情况下，只有当温度从$t_2$冷却到$t$时，水才会与身体分离。我们写出相应的热平衡方程：

$$c_1 m_1 (0 - t_1) + \lambda m_1 + c_2 m_1 (t - 0) + c_2 m_2 (t - t_2) = 0,$$

其中$c_1 = 2,1 \cdot 10^3$ J/(kg K)和$c_2 = 4,2 \cdot 10^3$ J/(kg K)是冰和水的比热容，$\lambda = 3,4 \cdot 10^5$ J/kg是冰的比热。从这里我们会发现

$$t = \frac{c_1 m_1 t_1 + c_2 m_2 t_2 - \lambda m_1}{c_2 (m_1 + m_2)}.$$

代入数值数据，我们得到$t < 0^\circ \text{C}$。这意味着我们的假设是错误的。

现在我们假设$t < 0^\circ \text{C}$。因此，我们的第二个假设也是错误的。

剩下的唯一选项是$t = 0^\circ \text{C}$。这将是问题的答案。

在这里，我们为读者预见到文档会有所增加：为什么作者选择所有最初假设都被证明是错误的示例，并且这两种繁琐的解决方案都会导致相对简单的结果（$a = 0, t = 0^\circ \text{C}$）？事实上，为什么不提前假设这些简单的选择呢？

这条道路是可行的，但它不会带来缓解。因此，在第一个问题中，假设静止并且没有静摩擦力的公式，我们将不得不创建一个由三个平衡方程组组成的系统，但是在解决它并找到摩擦力之后，我们必须检查滑动摩擦力是否真实。如果事实证明并非如此，您将必须重新开始执行上述所有解决方案。

在第二个问题中，假设$t = 0^\circ\text{C}$，我们必须确认这个热平衡方程，但不知道如何构造它。我们不知道哪一个达到零：“从下面”的冰或“从上面”的水，其结果是——一些（以及哪一部分）冰融化了，还是一些水结冰了？当然，您可以再次假设一些内容，但选项的数量不会比上述解决方案少，甚至更多。

问题 3. 在图 3 所示的图的所有分支中找到点。这里是$\mathcal{C}_1 = \mathcal{C}_2 = \mathcal{C} = 1\text{ B}$、$r_1 = r_2 = r = 1\text{ Om}$ 和$R_1 = R_2 = R_3 = R = 10\text{ Om}$。

让我们假设点 $I_1, I_2$ 和 $I_3$ 的方向如 图 3 所示，尽管我们不确定这一点。如果我们错了，相应的方程会纠正我们。*)

由于电荷不会在分支点（节点）处累积，因此单位时间内进入节点的电荷等于同一时间内离开节点的电荷，即

$$I_1 = I_2 + I_3.$$

让我们在图中选择两个简单的闭合轮廓，例如左和右，并选择其中的遍历方向，例如逆时针。根据能量守恒定律，电动势的代数和等于方向的代数和：

$$\mathcal{C} - \mathcal{C} = I_1R + I_1r + I_2r + I_2R,$$
$$-\mathcal{C} = -I_2R - I_2r + I_3R.$$

让我们将得到的方程组合到系统中，并用数值数据代替简单的方程：

$$I_1 = I_2 + I_3,$$
$$10I_1 + I_1 + I_2 + 10I_2 = 0,$$
$$10I_2 + I_2 - 10I_3 = 1.$$

解决这个系统后，我们发现

$$I_1 = -\frac{1}{31}A,$$
$$I_2 = \frac{1}{31}A,$$
$$I_3 = -\frac{2}{31}A.$$

第一和第三电流结果为负。这意味着我们对他们的方向的假设是错误的。我们正确地找到了数值，并且这些电流的方向与预期相反。

问题 4. 物体以初速度 $v_0 = 25\text{ m/c}$ 垂直向上抛掷。需要多长时间才能达到高度$h = 40\text{ m}$？

让我们写下众所周知的垂直向上抛体的坐标公式（我们认为向上方向为正）：

$$h = v_0t - \frac{gt^2}{2}.$$

求解 $t$，我们得到

$$t = \frac{v_0 \pm \sqrt{v_0^2 - 2gh}}{g}.$$

然而，当代入数值数据时，结果发现根下的表达式为负。这意味着什么？

事实证明，这个方程用它自己的语言告诉我们，这个物体根本达不到这样的高度。事实上，子梁的最大高度是$h_{\max} = v_0^2/2g \approx 31,5\text{ m}$，小于$h = 40\text{ m}$。

因此，有时会出乎意料地、无计划地“想到”一个方程。

练习

1. 质量为 $m = 10\text{ кг}$ 的均质杠杆位于距其左端 $l_1 = 25\text{ cm}$ 距离的支架上。杠杆长度$l = 1\text{ м}$。杠杆左端悬挂着一个质量为$m_1 = 2\text{ кг}$的质量。需要多大的力才能以与水平面成 $a = 30^\circ$ 的角度向下作用于右端，以使杠杆处于平衡状态？

2. 在热量计中，温度为 $t_1 = 0^\circ\text{C}$ 时有 $m_1 = 1\text{ кг}$ 冰，温度为 $t_2 = 100^\circ\text{C}$ 时有 $m_2 = 500\text{ г}$ 水蒸气。发生热传递后将达到什么温度？可以计算热量计的热容量。

3. 物体以初速度$v_0 = 15\text{ m/c}$垂直向上抛掷。 $t = 2\text{ с}$ 航班要飞行多远？自由落体加速度被认为等于$g = 10\text{ m/c}^2$。
