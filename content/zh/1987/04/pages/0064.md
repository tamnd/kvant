2. 如果函数$f(t) = \sin(2t + \theta)$ (图 10) 在某个区间上有极小点，则在该点处$f(t)$ 的值设置为等于$-1$。但在区间 $(t_0 - \varepsilon; t_0 + \varepsilon)$ 上，该函数不会在任何地方取值 $-1$（根据条件，该值是非负数）。因此，对于函数$\sin(2t + \theta)$，区间$(t_0 - \varepsilon; t_0 + \varepsilon)$上不存在最小点。因此，存在一个参数 $t_1$ 的值，要求的不等式为真。

3. 让我们将同样的“低运动”思想应用到选项二中。输入符号：$BAK_0 = t_0$，$S_{ACD} = \sigma$，我们看到$S_{\Pi_0} = \sigma + T(t_0)$，其中

$$T(t_0) = S_{AK_0}C + S_{CL_0D} + S_{DN_0A} = \frac{1}{2} AC^2 \cdot \sin(2t_0 + 2\lambda) - \frac{1}{2} CD^2 \sin(2t_0 + 2\lambda - 2\beta) + \frac{1}{2} AD^2 \sin(2t_0 + 2\lambda + 2\alpha).$$

根据问题 1，这个总和可以表示为

$$T(t_0) = \varrho \sin(2t_0 + \theta),$$

(*)

在哪里 $\varrho$ 和 $\theta$ 从 $t_0$ 不依赖 $\varrho > 0$。旋转参考线 $AK_0$ (图 11) 围绕一个点 $A$ 到一个小角度，我们确信在这种情况下，所描述的直线在其轮廓上仍然有点 $A$, $C$, $D$。更准确地说，你可以选择这么小的间隔 $(t_0 - \varepsilon; t_0 + \varepsilon)$角度是多少 $t(t = BAK)$ 属于参考直线对应的这个区间 $\Pi(FKLN)$ 会有一个顶部 $F$ 在这一点上 $A$，和内侧 $KL$ 和 $LN$ - 分别点 $C$ 和 $D$。很明显，

$$S_{\Pi} = \sigma + T(t), \quad T(t) = \varrho \sin(2t + \theta),$$

(**)

其中$\varrho$和$\theta$与公式(*)相同。但根据问题2的陈述，可以在区间$(t_0 - \varepsilon; t_0 + \varepsilon)$中选择一个角度$t$使得$\sin(2t + \theta) < \sin(2t_0 + \theta)$。

对于相应描述的直线$S_{\Pi} < S_{\Pi_0}$，即直线$P_0$在方案二中也不是最优的。

4. 令多边形$M$的顶点$A$、$C$、$D$、$E$位于所述直线$P_0$(图12)的轮廓上；设$AB$为边$M$，$t_0$为边$AK_0$的倾斜角。让我们稍微移动参考直线$AK_0$，然后将其绕顶点$A$旋转一个小角度。这样一来，直线$AK_0$将占据新的位置$AK$，并且角度$t_0$将略微增大（或减小）；我们用$t$表示它的新值。因此，直线 $P_0$ 会稍微旋转（并且可能会有些变形）；我们用 $P$ 表示新描述的直线。然而，如果旋转角度足够小（即，如果$t$与$t_0$相差足够大），则图片不会发生质变：四个顶点$A$、$C$、$D$、$E$仍然是参考直线$P_0$四个不同边的内点，其余顶点 $M$ 将位于 $P$ 内部。这样，问题将会加剧，直到角度 $t$ 保持在某个相当小的区间 $(t_0 - \varepsilon; t_0 + \varepsilon)$ 内。让我们用$\alpha$，$\beta$，$\gamma$，$\delta$，$\sigma$来表示辅助四边形$ACDE$的角度和面积，令$CAB = \lambda$。不难算出$S_{\Pi_0} = \sigma + T(t)$，其中$T(t_0) = \varrho \sin(2t + \theta)$，

其中$\varrho$和$\theta$是数字，不依赖于$t_0$（而仅依赖于多边形$M$的元素（更准确地说，取决于线段$AC$、$CD$、$DE$、$EA$的长度和角度$\alpha$， $\beta$、$\gamma$、$\delta$、$\sigma$）。我们同样发现$S_{\Pi} = \sigma + T(t)$，其中$T(t_0) = \varrho \sin(2t + \theta)$。

推理，和前面两个选项一样，我们得出$A$和$B$是非钝角；设 $F$ 为多边形 $M$ 最方便的顶点。
