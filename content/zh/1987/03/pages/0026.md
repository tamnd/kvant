M1013。两点 M 和 N 取于三角形 ABC 的边 AB 和 BC 上。经过M、B、N点的三条平行线与​​底AC相交于K、D、L点。证明梯形（或平行四边形）的面积不大于三角形ABD和DBC之一的面积。

M1014。令 $a_1, a_2, \dots, a_n$ 为不同的两两互质自然数。证明存在无限多个自然 b 使得数字 $b+a_1, b+a_2, \dots, b+a_n$ 也成对互质。

中国剩余定理
如果自然数 $p_1, p_2, \dots, p_m$ 互质，则对于任何一组自然数 $r_1, \dots, r_m, 0 \leq r_i < p_i (i=1, \dots, m)$ ，都存在一个数字 b，当除以 $p_i$ 时，对于所有 i 会得到余数 $r_i$。

我们用$\angle ADB = a, AD = a, BD = b, CD = c, AK = AD = k, CL = CD = l$来表示它。则MK：BD=k，NL：BD=l，即MK=kb，NL=lb，KL=KD+DL=(1-k)a+(1-l)c，又由于线MK和NL之间的距离等于KL sin$\alpha$，所以四边形KMNL的面积为$\frac{1}{2} (MK+NL) KL \sin \alpha = \frac{1}{2} (kb+lb) ((1-k)a + (1-l)c) \sin \alpha$。

让$a \geq c$来定义，那么最后一个表达式不超过$\frac{1}{2} b (k+l)(2-(k+l)) a \sin \alpha \leq \frac{1}{2} ab \sin \alpha$（因为对于所有x都是$x(2-x) \leq 1$），即三角形ADB的面积。

V·N·杜布罗夫斯基

找出问题的陈述对于哪些不同自然数的集合 $A = (a_1, \dots, a_n)$ 成立是很有趣的，即对于至少一个整数 b（因此对于无限的数字 b 集合），和 $a_1+b, \dots, a_n+b$ 成对互质。例如，如果集合$A$包含两个四边形，那么这样的集合不适合我们。一般来说，如果数字 $a_i$ 除以素数 $q$ 的余数中，每个可能的余数 0,1, ..., $q-1$ 至少出现两次，那么对于任何“移位”，至少有两个数字将被 $q$ 整除。由此可见，集合$A$必须满足以下条件：

集合 $A$ 中的数除以每个素数 $p$ 所得的余数中，至少有一个余数 $r_p, 0 \leq r_p < p$ 不得出现超过一次。

令 $D$ 为集合 $A$ 中最大数和最多数之间的差。对于每个素数$p \leq D$，我们找到余数$r_p < p$，当将数字$A$和$p$相除时，它最多出现一次。现在让我们选择数字$b$，当它除以每个素数$p \leq D$时，会为$r_p$$r_p^* (r_p^* = p-r_p$（对于$r_p > 0$）和$r_p^* = 0$（对于$r_p = 0$）提供额外的余数。那么数字$a_1+b, \dots, a_n+b$将成对互质，因为每个质数$p$最多可以除以其中一个：对于$p \leq D$，这是通过选择$b$来确保的，而对于$p > D$，它是自动完成的，因为数字$a_1, \dots, a_n$除以$p$的所有余数都会不同。
