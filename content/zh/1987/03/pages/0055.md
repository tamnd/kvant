⟦folio 53⟧

如果$0 < b \leq 1$，那么对于任何$y$，第二个不等式都将得到满足。如果$b > 1$，则$b^2 - 1 > 0$，然后不等式可以简化为$y \leq b/(b^2 - 1)$的形式。因此，由此产生的不平等系统分为两个：

$$\begin{cases} y \geq b^3 - b, \\ 0 < b \leq 1 \end{cases} \quad \begin{cases} y \geq b^3 - b, \\ y \leq b/(b^2 - 1), \\ b > 1. \end{cases}$$

两个系统中的第一个描述了由 图 6 阴影的区域，位于直线 $b = 1$ 下方，第二个描述了同一区域的其余部分。答案是有道理的。

所提出的求解方法可以让您确定：如果您可以解出不等式对应的方程，那么求解不等式不会造成任何困难。

选项1
（力学、数学和经济学院）
1. 解方程
$$3\sin^2 x = \cos 2x + 4\sin 2x.$$
2. 数字 $\log_2(3^x - 1)$、$\log_4(9 + 9^x - 7 \cdot 3^x)$ 和 $\log_2(3 - 3^x)$ 是某些算术级数的连续项。找到$x$。
3. 给定一个梯形 $ABCD$，底边为 $AD$，对角线为 $BD$ 和 $AC$。已知$AC = 3$、$BD = 4$、$\angle CAD = 2\angle BDA$。求梯形$ABCD$的面积。
4. 找到方程组中参数$a$的所有值
$$\begin{cases} ax + 3y = a^2 + 1, \\ (3a + 14)x + (a + 8)y = 5a^2 + 5 \end{cases}$$
没有解决办法。
5. 点$M$和$N$分别是正确四面体$SABC$的边$AC$和$SB$的中点。四面体的边长度为 1。在线 $AS$ 和 $CN$ 上，选择点 $P$ 和 $Q$，使得线 $PQ$ 与线 $BM$ 平行。求线段$PQ$的长度。

选项2
（地质与地球物理学院、自然科学学院）
1. 解方程
$$2\cos 2x + 5\cos^2 x = 8\sin 2x - 6.$$
2. 解方程
$$\log_2(2x - 2) + \log_4(x + 1)^2 = 2 + \log_2(x^2 + x - 3).$$
3. 三角形$ABC$的边$BC$的长度等于$a$，角$A$的大小等于$a$。点 $O$ 是三角形 $ABC$ 的内接圆的圆心。求通过点 $B$、$C$ 和 $O$ 的圆的半径。
4. 找到方程组中参数$a$的所有值
$$\begin{cases} 2ax + y = a^2 - 2a, \\ -10x + (a - 6)y = 10a - 5a^2 \end{cases}$$
没有解决办法。
5. 在正四面体$SABC$中，平面$a$穿过顶点$S$、$C$和边$AB$的中点$M$，平面$\beta$穿过顶点$B$和点$K$， $L$ - 对应于通过点 $B$、$C$ 和 $O$ 的投影的边 $SA$ 和 $SC$ 的中点。
4. 求直线 $l$ 与面平面 $ABC$ 之间的角度。
