⟦folio 25⟧

F1023。灯泡与架子的距离为 $l_1$，距地板的高度为 $l_2$。爆炸时，碎片以相同的速度$v$向各个方向飞散。求石头将击中地板上的圆的半径。认为用石头撞击天花板是abscilton urrusia，撞击地板是非弹性的；碎片没有到达墙壁。

让我们首先假设没有上限，在这种情况下，我们将找到地板上盐所在位置的最大半径。

我们引入一个以灯泡插座所在点为原点的坐标系（见图）。与地平线成$\alpha$角释放的盐在$t$时间后落到地面的条件如下：

$$\begin{cases}
-l_2 = vt \sin \alpha - \frac{gt^2}{2}, \\
R = vt \cos \alpha.
\end{cases}$$

显然，我们需要选择角度$\alpha$，使得$R$的值最大。让我们将该方程 (*) 转换为以下形式

$$\begin{cases}
\frac{gt}{2} - \frac{l_2}{t} = v \sin \alpha, \\
\frac{R}{t} = v \cos \alpha.
\end{cases}$$

因此，对于数量 $R$，我们得到不等式

$$R^2 = (v^2 + gl_2)t^2 - \frac{g^2 t^4}{4} - l_2^2 = \left(\frac{v^2 + gl_2}{g}\right)^2 - l_2^2 - \left(\frac{gt^2}{2} - \frac{v^2 + gl_2}{g}\right)^2 \leq \left(\frac{v^2 + gl_2}{g}\right)^2 - l_2^2.$$

因此，

$$R_{\max} = \frac{v}{g} \sqrt{v^2 + 2gl_2},$$

如此距离的飞行时间$t^*$盐

$$t^* = \frac{1}{g} \sqrt{2(gl_2 + v^2)};$$

我们将从方程中找到流出角度

$$\cos \alpha^* = \frac{R_{\max}}{vt^*} = \sqrt{\frac{v^2 + 2gl_2}{2(v^2 + gl_2)}}.$$

我们使用以下公式找到该轨迹高于灯泡插座水平面的高度 $h^*$

$$h^* = \frac{(v \sin \alpha^*)^2}{2g} = \frac{v^2}{2g} (1 - \cos^2 \alpha^*) = \frac{v^4}{4g(v^2 + gl_2)}.$$

现在让我们记住天花板。显然，如果$l_1 \geq h^*$，那么

$$R_{\max} = \frac{v}{g} \sqrt{v^2 + 2gl_2}.$$

在$l_1 < h^*$，即$l_1 < \frac{v^4}{4g(v^2 + gl_2)}$的情况下，地板上光点的最大半径将来自最大轨迹高度（在弹药筒水平之上）为$l_1$的碎片（它们的轨迹将与天花板相切）。为了证明这一点，只需考虑在点$A$处至少有一块从天花板反射的碎片就足够了。反射后，墨盒的水平面将在角度 OUTLET 处相交。因此，该碎片的轨迹将大于“切线”轨迹，并且它们永远不会相交。这意味着接触天花板的盐会比接触天花板的所有其他盐水平地溢出得更远。没有编织到天花板的碎片移动到地面时就无法移动。
