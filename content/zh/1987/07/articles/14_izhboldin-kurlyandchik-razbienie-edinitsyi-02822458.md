统一分裂

O.T.伊兹博尔丁，L.D.库尔扬奇克

有许多问题涉及自然数的倒数的数和。我们杂志曾多次讨论过这个话题：去年，“问题«Kvant»”中放置了两个这样的问题——M989和M1010（«Kvant»第6号和第10号）。第一个决定予以公布（见1986年«Kvant»第10号）；本文专门讨论第二个问题以及其他几个相关问题的解决方案。让我们回顾一下问题的表述。

序列$r_1, r_2, r_3, \dots$由条件决定

$$r_1 = 2, r_{n+1} = r_1 r_2 \dots r_n + 1,$$

所以$r_2 = 3, r_3 = 7, r_4 = 43, \dots$

a) 证明对于任意 $n$

$$\frac{1}{r_1} + \frac{1}{r_2} + \dots + \frac{1}{r_n} < 1.$$

6)* 令$n$自然数的倒数之和为1。证明这个和不大于

$$\frac{1}{r_1} + \frac{1}{r_2} + \dots + \frac{1}{r_n}.$$

本质上，这里需要的是通过 $1/n$ 形式的分数之和找到一个单位的最佳近似值（顺便说一句，这样的数字称为等分或埃及分数）。这个问题属于美国数学家凯洛格。 1915年，卡迈克教授报告了这一现象，并在其著作《丢番图分析》中引用了这一现象。 1922年，美国数学家柯蒂斯解决了这个问题。我们将给出另一个热门的较短解决方案。 （说到这个问题的历史，我们还得提一下，它在 1977 年由 Mir 出版社出版的《400 个精选问题》合集中作为第 70 号出版，但实际上并没有解决方案。）

$$r_{n+1} = (r_n - 1) r_n + 1$$

*) 问题还有第三点——解决问题 6) 的引理。我们稍后再提出。

或者
$$\frac{1}{r_{n+1}-1} = \frac{1}{(r_n-1)r_n} = \frac{1}{r_n-1} - \frac{1}{r_n}.$$
因此，
$$\frac{1}{r_1} + \frac{1}{r_2} + \dots + \frac{1}{r_n} = \left( \frac{1}{r_1-1} - \frac{1}{r_2-1} \right) + \left( \frac{1}{r_2-1} - \frac{1}{r_3-1} \right) + \dots + \left( \frac{1}{r_n-1} - \frac{1}{r_{n+1}-1} \right) = 1 - \frac{1}{r_{n+1}-1} < 1$$
（自 $r_1-1=1$ 起）。这证明了我们问题的陈述a)。在此过程中，我们证明了 $1/r_{n+1}$ 是 $r_n$ 的最低自然值，可以将其添加到总和 $1/r_1+...+1/r_n$ 中，使其保持小于 1（通过添加 $1/(r_{n+1}-1)$，我们已经精确地得到 1）。因此，在构建序列$1/r_n$时，每次都需要“咬掉尽可能大的一块”。

顺便说一句，让我们注意到数字$r_n$出现在另一个问题中，外部估计与我们的相去甚远：“描述所有$n$自然数的集合，使得它们中的任何$n-1$与一个的乘积可以被其余数整除。”自己检查一下数字$r_1, ..., r_n$是否满足这个条件。该问题的完整解决方案尚不清楚； A. Gein 的文章“On the way to a Solution”（Kvant, 1978, No. 7, p. 9）讨论了细节。

为什么序列$1/r_n$最准确？

设总和$1/a_1+...+1/a_n$，其中$a_1, ..., a_n$是自然数，$a_1 \leqslant a_2 \leqslant ... \leqslant a_n$是最准确的单位近似值；每个自然数 $n>1$ 的这种近似的存在性在问题 M989, c) 的解决中得到了证明（参见 «Kvant» No. 10, 1986, p. 36）。我们将 $\alpha_k=1/a_k$ 放在 $k=1, 2, ..., n-1$、$\alpha_n=1-\alpha_1-\alpha_2-...-\alpha_{n-1}$ 处。我们将证明数字集合$a_1, ..., a_n$满足以下条件：
$$\alpha_1 \geqslant \alpha_2 \geqslant ... \geqslant \alpha_n \geqslant 0,$$
$$\alpha_1+\alpha_2+...+\alpha_n=1,$$
$$\alpha_1...\alpha_k \leqslant \alpha_{k+1}+...+\alpha_n$$
在$k=1, 2, ..., n-1$。 (3)

这些是构成问题 M1010 的 c) 点的引理的条件。根据下面证明的这个引理，数字$a_n$，即我们的统一近似误差，不小于$1/(r_n-1)$，并且$a_n=1/(r_n-1)$仅适用于集合$a_k=1/r_k$，$k=1, ..., n-1$。因此，$a_k=r_k$，等价于语句6）。

那么，让我们检查 $a_1, ..., a_n$ 的条件 (1)–(3)。条件（2）非常indo；也很清楚$a_1 \geqslant a_2 \geqslant ... \geqslant a_{n-1}$。让我们证明$a_{n-1} \geqslant a_n$。由于我们首先考虑统一的最佳近似，

$$\frac{1}{a_1} + ... + \frac{1}{a_{n-1}} + \frac{1}{a_{n-1}-1} \geqslant 1.$$
因此，
$$a_{k+1} + ... + a_n = 1-\alpha_1-...-\alpha_k =$$
$$= 1-\frac{1}{a_1}-...-\frac{1}{a_k} = \frac{N}{a_1...a_k} =$$
$$= N \cdot \alpha_1 \cdot ... \cdot \alpha_k,$$
其中$N$是某个自然数，因此最后一个表达式不小于$a_1...a_k$。

引理的证明

我们必须证明集合($\alpha_1, ..., a_n$)中满足条件(1)-(3)且$a_n$最小的那个与集合$(1/r_1, ..., 1/r_{n-1}, 1/(r_n-1))$一致。

寻找元素积最小的集合会更方便；我们将看到它将有一个最小和最后一个元素。

因此，令 $\beta=(\beta_1, ..., \beta_n)$ 为满足条件 (1)–(3) 的集合中的一个，其中乘积 $\beta_1...\beta_n$ 最小（稍后我们将讨论为什么存在这样一个集合的问题）。让我们立即注意到 $\beta_n>0$，因此，根据 (2) $\beta_1<1$。 （如果$\beta_n=0$，那么从不等式（3）我们一致得到：对于$k=n-1$ - $\beta_n=0$，对于$k=n-2$ - $\beta_{n-2}=0$，等等；但是所有数字$\beta_i$不能等于0，因为它们加起来是1。）。

现在让我们证明对于集合 $\beta$ 所有不等式 (3) 都会变成等式。

对于(1)-(3)中的$n=2$，我们立即得到$\beta_1 \geqslant \beta_2 \geqslant 0$、$\beta_1+\beta_2=1$和$\beta_1 \leqslant \beta_2$，即$\beta_1=\beta_2=1/2$。让$n>2$。

让我们用函数 $f$ 和集合 $A$ 的例子来解释这个定理。首先，很明显，函数 $f$ 不是不连续的，即，其对应元素彼此相差足够小的两个集合的值将尽可能接近。其次，集合$A$是有限的，即其中包含的任何集合的元素$\alpha_i$的绝对值不超过某个固定数量；我们有$|\alpha_i| \leq 1$。最后，集合$A$是闭集；这意味着，如果集合$A$中的任意集合序列由$\alpha = (\alpha_1, \dots, \alpha_n)$组成（即，这些集合的第一个元素形成类似于$\alpha_1$的序列，第二个类似于$\alpha_2$等），则集合$\alpha$也属于集合$A$。集合$A$的封闭性确保了条件（1）-（3）中的所有不等式都是非历史的。

因此，实现最小值的定理为我们正在构建的结构提供了坚实的基础，从而完成了问题M1010的解决。必须将分析方法应用于这样的整数问题是很不寻常的。然而，文章开头提到的最初解决方案纯粹是算术。
