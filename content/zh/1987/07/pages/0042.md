M1035。在段 [0; 1]点$x_0, x_1, x_2, ..., x_n$依次移位。对于每个点 $x_k$ ($k=1, ..., n$)，它到最近放置的点的距离 $d_k$ 会发生变化。证明$d_1+d_2+...+d_n \leq 1 + \frac{\log_2 n}{2}$。

图 2. 移动点$x_2$时集合$x_0, x_1,...,x_n$的变换：每个值$x_2, 0 \leq x_2 \leq 1$对应一个水平线段，点$x_i$位于水平线段与蓝线的交点处。

图 3.

我们首先证明区间 [0; 上的任意点集 $x_0, x_1, ..., x_n$ 1]无需减少用量即可

$$s = d_1 + d_2 + ... + d_n,$$

变换为一个集合，其中前两个点是0和1，接下来的每个点是前面的点所划分的其中一个段的中间[0; 1]。显然，您可以将自己限制为不同点的集合（如果点 $x_i$ 与之前的点之一重合，您可以简单地将其划掉 - $d_i=0$ - 并在末尾添加一个新点）。但允许巧合对我们来说会很方便。

设 $x_i$ 为集合的最左边点，$x_k$ 为最右边点。显然，如果我们将$x_i$替换为0，将$x_k$替换为1，$s$不会减少。此外，使用$i \geq 1$，我们可以将$x_i=0$和$x_{i-1}$互换 - 在这种情况下，$d_{i-1}+d_i$的和只能增加（图1），其余的和$s$不会改变。因此，今后我们可以假设$x_0=0$和$x_1=1$。我们将进一步“改进”设置$x_0, ..., x_n$。让我们考虑点$x_2$。如果$x_2=x_0$或$x_2=x_1$，跳过它并转到$x_3$。现在让$x_2=x$，$0<x<1$。我们将沿着线段 [0; 移动点 $x_2=x$； 1]并且同时段之一[0; x] 或 [x; 1]连同落在其上的所有点$x_i$拉伸，另一个-撇去（图2）。很明显，那么线段 [0; 的点 $x_i$ 的数字总和 $d_i$ x] 将按比例更改为 $x$，对于线段 [x; 1] 与 1—x 成正比，因此总和作为 $x$ 的函数，将相等

$$s = 1 + \min(x, 1-x) + lx + r(1-x)$$

（$d_1=1, d_2=\min(x, 1-x), l$和$r$是常数）。该函数在区间 [0; 1/2]和[1/2； 1] 并且在点 $x=1/2$ (图 3) 处有一个扭结，因此其最大值在点 $0, 1/2, 1$ 之一处达到。让我们将 $x_2$ 移动到最大点，同时使用适当的工厂（或创建）线段 [0; 上的一组点 $x_i$ $x_2$]和[$x_2; 1$]。我们将获得一组点的总和$s$不小于第一个初始点，并且点$x_2$要么位于线段[$x_0; x_1$]（$x_2=1/2$）的中间，要么位于该线段的边缘。此外，如果 $x_3$ 与$x_0, x_1$、$x_2$ 中的任何一个点都不重合，请考虑$x_3$ 所在的线段 [$x_0; x_2$] 和 [$x_2; x_1$] 之一。如上，我们可以改变该线段上点$x_i$的集合，使得点$x_3$成为其中间或末端，并且$s$之和不减少。对以下点进行同样的操作，我们将得到一个集合，其中 $x_0=0$、$x_1=1$ 和每个下一个点要么与连接两个相邻点的线段的中间重合，要么与这些点之一重合。所有与之前的点重合的点都可以被划掉，之后剩下一组$k$点（$k \leq n$），满足解法开始时制定的条件。
