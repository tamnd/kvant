以下是构建原始对和原始毕达哥拉斯 troek 的家谱的方法。引入了三个变换$t_1, t_2$和$t_3$：

$$t_1(m, n) = (2m - n, m),$$
$$t_2(m, n) = (2m + n, m),$$
$$t_3(m, n) = (m + 2n, n).$$

使用这些变换，从对 (2, 1) 开始，构建一个家谱。这里，向上方向对应于变换$t_1$，水平方向对应于变换$t_2$，向下方向对应于变换$t_3$。

问题 10. 让 $(m, n)$ 使用对应关系 (4) 生成毕达哥拉斯三元组 $(X, Y, Z)$。由$t_1$$(m, n)$对生成的毕达哥拉斯三元组表示为$T_1(X, Y, Z)$；由$t_2$$(m, n)$对通过$T_2(X, Y, Z)$生成的三元组；最后，由$t_3$$(m, n)$到$T_3(X, Y, Z)$对生成的三元组。证明

$$T_1(X, Y, Z) = (X - 2Y + 2Z, 2X - Y + 2Z, 2X - 2Y + 3Z),$$
$$T_2(X, Y, Z) = (X + 2Y + 2Z, 2X + Y + 2Z, 2X + 2Y + 3Z),$$
$$T_3(X, Y, Z) = (-X + 2Y + 2Z, -2X + Y + 2Z, -2X + 2Y + 3Z).$$

现在，使用变换$T_1, T_2, T_3$，我们将构建另一个家谱，但它已经从三元组（3,4,5）开始。
