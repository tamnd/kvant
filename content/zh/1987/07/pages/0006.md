三阶曲线
坚持上面讨论的几何方法，我们的注意力不会集中在求解三次方程上，而是集中在以下等效问题上：三次方程给出的平面上的曲线的有理点是什么

$$f(x, y) = ax^3 + bx^2y + \dots + hx + iy + j = 0$$
具有整数系数？

所有这些曲线都可以分为两大类。第一类包括具有尖点的曲线（如曲线$y^2 = x^3$的点（0; 0））、自交点（图3），以及$f(x, y)$表示为$f(x, y) = f_1(x, y) \cdot f_2(x, y)$的曲线，

其中 $f_1(x, y), f_2(x, y)$ 是低次多项式 (图 4)。我们可以说这样的曲线是退化的。第二类由具有整数系数的三次非简并曲线形成 - 此类曲线称为椭圆形。我们感兴趣的正是这个（最一般的）类。我们将考虑以所谓的规范形式给出的椭圆曲线，即方程

$$y^2 = x^3 + ax^2 + bx + c$$
(6)

具有整数系数 $a, b$ 和 $c$，其中多项式 $P(x) = x^3 + ax^2 + bx + c$ 没有重根。

这并不违反一般性：任何三阶非奇异曲线$f(x, y) = 0$都可以通过某种变换简化为形式（6）；此外，如果系数$f(x, y)$是整数，则在曲线$f(x, y) = 0$上寻找有理点的问题可以简化为针对具有整数$a, b$和$c$的曲线（6）的类似问题。
