图 4. 彩色点是$s(n)$的值。

$$d_1 = 1, \quad d_2 = 1/2, \quad d_3 = d_4 = 1/4, \quad d_5 = \dots = d_8 = 1/8, \dots$$
(1) $(d_i = 2^{-m}$ for $2^{m-1} < i \leq 2^m$)，即对于点序列

$$0, 1, \frac{1}{2}, \frac{1}{4}, \frac{3}{4}, \frac{1}{8}, \frac{3}{8}, \frac{5}{8}, \frac{7}{8}, \frac{1}{16}, \dots$$

(2)

（具有相同值的分数可以按此顺序重新排列）。仍然需要估计序列 (1) 的总和 $s(n) = d_1 + \dots + d_n$。在 $n = 2^m + k, 0 \leq k < 2^m, m \geq 0$ 时，

$$s(n) = 1 + \frac{1}{2} + 2 \cdot \frac{1}{4} + 4 \cdot \frac{1}{8} + \dots + 2^{m-1} \cdot \frac{1}{2^m} + \frac{k}{2^{m+1}} =$$

$$= 1 + \frac{m}{2} + \frac{k}{2^{m+1}},$$

即$s(n) = 1 + (\log_2 n)/2$在$n = 2^m$，并且在从$2^m$到$2^{m+1}$的部分中，函数$s(n)$线性变化。由于 $\log_2 x$ 是凸函数，$s(n) \leq 1 + (\log_2 n)/2$ 对于所有自然的 $n$ (图 4)。

有趣的是，点（2）的最佳位置是由“贪婪”算法给出的（这是一个完全官方的术语）：在每一步都足以确保下一项的最大值，而不用担心接下来会发生什么。

F1043。在光滑的水平面上，旋转一根长度$l = 10$厘米的棍子以$v = 10$厘米/秒的速度滑动。如果距离墙壁 $L = 50$ 厘米，棍子与墙壁平行，则棍子将以多大的旋转速度撞击墙壁（参见 图 4）手指？

木棍中心移动到墙壁$L$距离所需的时间为

$$\tau = \frac{L}{v} = 5 \text{ с.}$$

为了使棍子击中手指的壁，在此期间它必须绕轴完成整数次旋转。因此，

$$\omega_n \tau = n\pi, \text{ где } n = 1, 2, 3, \dots,$$

在哪里

$$\omega_n = n \frac{\pi}{\tau}.$$

并不是所有获得的$\omega$值都会是问题的答案。如果手指的$\omega$足够大，在移动时，其一端会“卡”在墙上，手指来不及撞到它。为了找到扭曲值$\omega$满足的条件，我们注意到在撞击过程中，其末端$A$（见图4）的速度不能远离墙壁（否则，在同一时刻，点$A$“在”墙壁中，这是不可能的）。 $A$点的速度为摇杆中心运动速度与摇杆旋转线速度之和：

$$v_A = u - v = \frac{\omega l}{2} - v > 0.$$

从这里我们得到条件$\omega$：

$$\omega < \frac{2v}{l} = 2c^{-1}.$$

将这些条件与公式(*)进行比较，我们会发现适当的值$\omega_n$只是该值

$$\omega_1 = 0,63 \text{ c}^{-1}, \omega_2 = 1,26 \text{ c}^{-1}, \omega_3 = 1,89 \text{ c}^{-1}.$$
