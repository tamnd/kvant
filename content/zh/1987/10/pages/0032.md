例如，$T_2(x) = 2x^2 - 1$ (图 2)、$T_3(x) = 4x^3 - 3x$ (图 3)。请注意 $|T_m(x)| \leq 1$ 位于 $|x| \leq 1$。多项式$T_m(x)$称为切比雪夫多项式（参见N. Vasiliev和A. Zelevinsky的文章“切比雪夫多项式和递推关系”，«Kvant»第1期，1982）。在它的帮助下，我们将解决$k = m + 1$分的问题。

令$x_n, n = 0, \dots, k - 1$为线段$[-1; 1]$上不同点的任意集合$k$。任何次数为$k - 1$的多项式都由其在点$x = x_n$处的值$a_n$唯一确定，并且可以很容易地验证，可以将其写为和

$$\sum_{n=0}^{k-1} a_n \frac{(x-x_0)...(x-x_{n-1})(x-x_{n+1})...(x-x_k-1)}{(x_n-x_0)...(x_n-x_{n-1})(x_n-x_{n+1})...(x_n-x_{k-1})}.$$

让我们取$a_n = T_{k-1}(x_n)$，那么这个多项式将等同于$T_{k-1}(x)$。其首项系数 $2^{k-2}$ 是表达式之和

$$\frac{a_n}{|x_n-x_0|...|x_n-x_{n-1}||x_n-x_{n+1}|...|x_n-x_{k-1}|},$$

其中每个模数不超过

$$\frac{1}{|x_n-x_0|...|x_n-x_{n-1}||x_n-x_{n+1}|...|x_n-x_{k-1}|}$$

（自 $|a_n| = |T_{k-1}(x_n)| \leq 1$ 起）。但$n = 0, \dots, k - 1$处的数量(*)之和正是我们感兴趣的$S$之和；因此$S \geq 2^{k-2}$。

F1058。球沿着直头核心ASV的边缘（见图）以速度$v$滚动而不刺穿；距离$AB$等于球的半径。球上哪些点的速度最大？这个速度是多少？

根据问题的条件，球是 Katisyabin，因此在给定时刻在点 $A$ 和 $B$（参见 图）接触球的那些点的速度等于 0。考虑到球是一个abscilton刚体（这意味着球的任意两点之间的距离保持不变），我们得出的结论是，在给定时刻，位于线段$AB$上的球的所有点都是静止的。这意味着在每个时刻，球的运动都是相对于 $AB$ 轴的旋转。 （很明显，点 $A$ 和 $B$ - 球接触下巴的点 - 以速度 $v$ 移动）。

球上任意点的瞬时速度为$\omega$，其中$\omega$是旋转角速度，$\rho$是该点到轴$AB$的距离。球中心的速度（因此在图处）是$v$；从点 $o$ 到轴 $AB$ - $\rho_0 = |oc| = R\sqrt{3}/2$ 的距离。因此，

$$\omega = \frac{v}{\rho_0} = \frac{2v}{R\sqrt{3}}.$$

很明显，最大速度出现在距离 $AB$ 轴最远的点处。从几何角度考虑，很明显，在任何时刻，只有一个点距轴的距离最大 - 在 图 上，这是点 $d$。点$d$到旋转轴的距离为$\rho_d = \rho_0 + R = R(1 + \sqrt{3}/2)$，点$d$的速度为

$$v_d = v_{\max} = \omega \rho_d = \frac{2v}{R\sqrt{3}} R\left(1 + \frac{\sqrt{3}}{2}\right) = v \frac{2 + \sqrt{3}}{\sqrt{3}}.$$
