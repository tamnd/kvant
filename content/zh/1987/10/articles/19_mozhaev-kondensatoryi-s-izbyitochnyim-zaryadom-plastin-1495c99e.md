极板电荷“过多”的电容器

物理和数学科学候选人
V·V·莫扎耶夫

申请人在解决静电问题时所犯错误的许多特征是由于对导体电势和电荷之间关系的正式理解造成的。而且这些联系是多种多样的。例如，在导体上不存在电荷的情况下，导体之间可能存在电势差，或者相反，在电势差为零的情况下，导体可以带电。间隙选项也是可能的 - 导体上有电荷并且它们之间存在电位差。

后一种情况是指当两个孤立的导体（没有其他导体）带电时发生广泛燃烧

我们有相同大小的电荷，但符号相反。在这样的系统中，导体之间产生的电势差 $U$ 与导体上的电荷 $q$ 成正比：

$$U \sim q, \text{ или } q = CU,$$

(*)

其中$C$是比例系数，称为两个导体的电容。众所周知，$C$仅取决于导体的尺寸和形状、它们的相对位置以及环境的介电导率。

再次强调电势差和导体上的电荷之间的线性关系不是普遍存在的。仅当没有其他导体的影响并且两个给定导体上的电荷大小相等且符号相反时，它才被保留。换句话说，当离开一个导体的电场线的力在另一个导体上闭合时。这种系统的典型例子是电容器。看起来是两个导体，

现在让我们布置几个具体任务。所有这些都是在莫斯科物理技术学院入学考试期间的不同时间提供的。

问题 1. 两个不带电的金属板 2 和 3 位于扁平带电电容器 (图 1, a) 内。电容器中存在应变为$\vec{E}_0$的均匀电场。如果板 2 和板 3 之间的距离为 $d_2$，它们之间的电势差是多少？

在这个问题中，实现了第一种部分情况，即导体不带电，但它们之间存在电位差。

板 2 和 3 正式形成一个扁平电容器，但它们不是绝缘的 - 它们旁边还有其他板，甚至是带电的板。因此，如果理解板 2 和 3 之间的系数$C$，则对应关系：这些板上不带电荷，并且它们之间的电位差不为零。

让我们通过两种方式找到这种潜在的差异。首先，我们不会诉诸电容的概念，而仅使用电位差的定义。根据定义，极板 2 和极板 3 之间的电势差在数值上等于将单位极电荷从极板 2 移动到极板 3 的功。在外部场$\vec{E}_0$ 中，极板 2 和极板 3 上将发生电荷重新分布：极板的左侧表面带负电，右侧表面带正电（如图 1，a 所示）。显然，板之间的场仍然等于$\vec{E}_0$，并且它们上的表面电荷密度将等于$\sigma = \varepsilon_0 E_0$（尝试使用叠加原理和电场原理来证明这一点）。那么极板之间的电位差

$$\Delta \varphi_{23} = E_0 d_2,$$

其中$d_2$是板内表面之间的距离。

现在使用电容的概念找到这个电势差。我们的四个极板系统相当于 图 1, 6 中所示的三个串联扁平电容器系统。实际上，极板 2 和 3 中的每一个都可以分成两部分，在每个部分上保留自己的电荷，并且由于它们（两个部分）处于相同的电位，因此可以将它们短路。系统总容量

$$C_{14} = \frac{\varepsilon_0 S}{d_1 + d_2 + d_3},$$

其中$S$为每块极板的面积，总电位差

$$U_{14} = E_0 (d_1 + d_2 + d_3).$$

然后充电

$$q = C_{14} U_{14} = E_0 \varepsilon_0 S.$$

在串联连接中，电容器上的电荷相等，因此电容器 2-3 两端的电位差将等于

$$U_{23} = \frac{q}{C_{23}} = \frac{E_0 \varepsilon_0 S}{\varepsilon_0 S/d_2} = E_0 d_2.$$

问题 2. 让我们用导体将板 2 和 3 短路（如上一问题所述），并找出它们上是否出现电荷。

显然，如果将板 2 和板 3 短暂连接，则它们之间的电势差将为零，并且板上将出现大小相等但符号相反的电荷（图 2，a）。因此，在这个问题中，我们考虑第二种部分情况，即导体上有电荷，但没有电势差。

让我们使用相同的两种方法求出板 2 和板 3 上的电荷。由于极板之间的电势差为零，间隙2-3中的电场电压也为零。这个场是电容器与极板 2 和极板 3 上的电荷产生的场。假设极板 2 上有电荷 - $q$，极板 3 上有电荷 + $q$，并且电容器的场为 $\vec{E}_0$，则极板 2 和极板 3 之间的最终场将等于 $E_0 - q / (\varepsilon_0 S) = 0$。从这个条件我们发现

$$q = \varepsilon_0 SE_0.$$

这种情况的等效电路如图 2, b 所示。这是一个由两个串联电容器组成的系统。我们通过考虑板 1 和 2 形成的电容器来找到板 2 上的电荷：

$$q = C_{12} U_{12} = \frac{\varepsilon_0 S}{d_1} E_0 d_1 = \varepsilon_0 SE_0.$$

以完全相同的方式，您可以在板 3 上充电。

任务 3. 板 1 上有电荷 $q$，板 2 与板 1 距离 $d$ 不带电。这些板之间的电位差是多少？

正如您所看到的，在这种情况下，导体上存在任意电荷，并且导体之间存在电位差。

同样，我们将通过两种方式解决这个问题。在板 1 的电荷产生的场的影响下，板 2 的左侧将感应出负电荷，右侧将感应出负电荷。

与之前的问题不同，这里板之间还保持了等于 $\varepsilon$ 的电势差。

让我们用 $q_0$ 表示电容器右板上的初始电荷。我们假设它均匀分布在板的表面（内部和外部）上。电荷$q_0$的表面导致极板之间的空间中存在一个均匀电场，其方向与电势差相同

$$E_0 = \frac{q_0}{2\varepsilon_0S},$$

其中$S$是极板的面积，极板之间存在电位差

$$U_0 = E_0d = \frac{q_0d}{2\varepsilon_0S},$$

其中$d$是板之间的距离。

设$U_0 < \varepsilon$，则关闭按键后电容器开始充电。在其右侧板上，电荷将增加，而在左侧板上，电荷将以相反方向出现。
错误符号，其大小等于右侧板上的附加电荷（但不是其上的全部电荷！）。在这种情况下，电源将执行正功，为电容器板充电。极板将重新充电，直到电容器$U$两端的电势差等于电源$\varepsilon$的电动势。充电时让电荷 $q$ 流过电源，则电池电容器 EMF 上电压相等的条件为

$$\frac{q_0d}{2\varepsilon_0S} + \frac{q}{C} = \varepsilon.$$

考虑到$C = \varepsilon_0S/d$，我们得到

$$q = \varepsilon C + \frac{q_0}{2}.$$

现在让我们计算充电过程中电阻$R$释放的热量。源所做的功部分用于增加电容器板之间空间中的电场能量，部分用于加热电阻器：

$$\varepsilon q = \Delta W + Q.$$

我们通过体积电场能量密度等于$\varepsilon_0E^2/2$来计算电场能量。当钥匙$K$打开时，该能量等于

$$W_0 = \frac{q_0^2}{8\varepsilon_0S^2} Sd = \frac{q_0^2d}{8\varepsilon_0S} = \frac{q_0^2}{8C}.$$

电容器充电后，极板之间的电场能量将增加并等于

$$W = \frac{\varepsilon_0}{2} \left( \frac{q_0}{2\varepsilon_0S} + \frac{q}{Cd} \right)^2 Sd = \frac{q_0^2}{8C} + \frac{q_0q}{2C} + \frac{q^2}{2C}.$$

电场能量增加

$$\Delta W = W - W_0 = \frac{q(q_0 + q)}{2C}.$$

那么完整的能量平衡可以写为

$$\varepsilon q = \Delta W + Q = \frac{q(q_0 + q)}{2C} + Q,$$

从这里我们可以找到电阻器释放的热量：

$$Q = \varepsilon q - \frac{q(q_0 + q)}{2C}.$$
