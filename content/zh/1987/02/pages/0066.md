3. $\frac{a^3 \sqrt{6}}{2}, \frac{a^3 \sqrt{15}}{4}$。解决方案。让我们选择向量$\vec{AB} = \vec{m}, \vec{AC} = \vec{n}, \vec{BC}' = \vec{p}$作为基础，并用$t$表示向量$\vec{m}$和$\vec{n}$之间的角度的未知余弦。该表显示了该基向量的标量积。令 $B'H$ 为棱柱的高度。然后$B'H = \vec{BH} - \vec{BB'} = x\vec{m} + y\vec{n} - (\vec{m} - \vec{n} + \vec{p}) = (x - 1)\vec{m} + (y + 1)\vec{n} - \vec{p}$。独立的$x, y, t$是从方程组中找到的，由条件$B'H = \sqrt{3} \cdot BH, BH \cdot \vec{m} = 0, B'H \cdot \vec{n} = 0$获得。该系统有两个解：$x = 1, y = -1, t = 0$和$x = -\frac{1}{2}, y = -1, t = -\frac{\sqrt{6}}{4}$，从中找到棱柱体积的两个可能值。

4. $\frac{3 \sqrt{3}}{256} a^3$.

5. a）$\frac{a \sqrt{15}}{3}$； 6）$\frac{a \sqrt{10}}{4}$。解决方案。令 $O$ 为示例底部的中心。我们从向量 $\vec{OS} = \vec{m}, \vec{OB} = \vec{n}, \vec{OC} = \vec{p}$ 形成基础。这些向量成对互相垂直，并且很容易求出它们的长度； $|\vec{m}| = \frac{a \sqrt{7}}{\sqrt{2}}, |\vec{n}| = |\vec{p}| = \frac{a}{\sqrt{2}}$。让我们通过等式 $\vec{OM} = x\vec{n}$ $(-1 \leq x \leq 1)$ 和 $\vec{SN} = y \cdot \vec{SC} = y(\vec{p} - \vec{m}) (0 \leq y \leq 1)$ 定义线段 $BD$ 和 $SC$ 上点 $M$ 和 $N$ 的位置。然后$\vec{MN} = (1 - y)\vec{m} - x\vec{n} + y\vec{p}$。由于直线 $MN$ 与平面 $SAD, MN = z \cdot \vec{SA} + t \cdot \vec{SD} = -(z + t)\vec{m} - t\vec{n} - z\vec{p}$ 平行。比较向量$\vec{MN}$到基$(\vec{m}, \vec{n}, \vec{p})$的两次展开，我们得到方程组$1 - y = -z - t, x = t, y = -z$。让我们通过$x$表达$y, z$和$t$：$y = \frac{x + 1}{2}, z = -\frac{x + 1}{2}, t = x$。因此，$\vec{MN} = \frac{1}{2}((1 - x)\vec{m} - 2x\vec{n} + (x + 1)\vec{p})$，因此$MN = \frac{a}{2} \sqrt{6x^2 - 6x + 4}$。如果$DM:DB = 1:3$，则$x = -\frac{1}{3}, MN = \frac{a \sqrt{15}}{3}$。 $MN$ 在 $x = \frac{1}{2}$ 处取最小值。该值为$\frac{a \sqrt{10}}{4}$。
