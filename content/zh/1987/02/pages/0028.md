M1007。证明边长为 a、b、c 和 a₁、b₁、c₁ 的三角形相似当且仅当
$$\sqrt{a a_1} + \sqrt{b b_1} + \sqrt{c c_1} = \sqrt{(a_1 + b_1 + c_1)(a + b + c)}.$$

将所证明的等式两边平方并进行多次变换后，可简化为以下形式
$$(\sqrt{a b_1} - \sqrt{a_1 b})^2 + (\sqrt{c a_1} - \sqrt{c_1 a})^2 + (\sqrt{b c_1} - \sqrt{b_1 c})^2 = 0,$$
因此，它等价于等式$a/a_1 = b/b_1 = c/c_1$，即类似于三角形。

那么，可以得到另一个证明，左边等于坐标为$(\sqrt{a}, \sqrt{b}, \sqrt{c})$和$(\sqrt{a_1}, \sqrt{b_1}, \sqrt{c_1})$的向量的标量积，并且不能大于右边，右边等于这些向量的长度的乘积；仅当向量之间的角度为零时才可能相等，即它们彼此成比例。

本质上，在第二个论证中，我们使用所谓的柯西-布尼亚科夫斯基不等式：
$$x_1 y_1 + x_2 y_2 + \dots + x_n y_n \leq \sqrt{(x_1^2 + x_2^2 + \dots + x_n^2)(y_1^2 + y_2^2 + \dots + y_n^2)},$$
仅当数字集$(x_1, \dots, x_n)$和$(y_1, \dots, y_n)$成比例时（我们有$n=3$，$(x_1, x_2, x_3) = (\sqrt{a}, \sqrt{b}, \sqrt{c}), (y_1, y_2, y_3) = (\sqrt{a_1}, \sqrt{b_1}, \sqrt{c_1})$），它们才变成相等。
