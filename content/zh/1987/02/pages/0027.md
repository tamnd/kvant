让我们用$s$（$s=S_{CLPK}=S_{APL}$）表示三等分的面积，用$s_1$表示第四部分的面积。为了找到所需的关系$s_1/s$，我们通过使用引理的面积以两种方式表达点$L$和$K$划分边$AC$和$BC$的关系：

$$\frac{CL}{LA} = \frac{S_{CLB}}{S_{LAB}} = \frac{S_{CLP}}{S_{LAP}},$$

$$\frac{CK}{KB} = \frac{S_{CKA}}{S_{KBA}} = \frac{S_{CKP}}{S_{KBP}},$$

(*)

进汽区经过$s$、$s_1$、$x=S_{CPL}$。

在第一种情况 (图 3, a) 中，我们有：

$$\frac{2s}{s+s_1} = \frac{x}{s}, \frac{2s}{s+s_1} = \frac{s-x}{s}.$$

从这里很容易找到$x=s/2$，$s_1/s=3$。

在第二种情况 (图 3, b) 中，系统将写成如下：

$$\frac{s+s_1}{2s} = \frac{x}{s}, \frac{2s}{s+s_1} = \frac{s-x}{s}.$$

第一个方程给出 $x=(s+s_1)/2$；将这个表达式代入第二个方程，我们发现关系式$s_1/s$满足二次方程$(s_1/s)^2+4(s_1/s)-1=0$，即$s_1/s=\sqrt{5}-2$。

仍然需要检查我们是否将三角形 $ABC$ 的边除以比率

$$CL : LA=CK : KB=2s : (s+s_1)=1 : 2$$

在第一种情况下和

$$CL : LA=BK : KC=(s+s_1):2s=(\sqrt{5}-1)/2$$

在第二种情况下，那么分区的相应三个部分的大小确实是相等的。使用等式 (*)，这在第一种情况下很容易做到，而在第二种情况下则有些困难。对于第二种情况，我们将给出不同的推理，解释为什么数字$\alpha=(\sqrt{5}-1)/2$出现在我们的问题中。 （数字$\tau=\frac{1}{\alpha}=\frac{\sqrt{5}+1}{2}$是“黄金解”的意思。）请注意，我们的陈述正如我们所说的“仿射”，即它只包含在并行设计过程中保留的几何概念和数量：一条直线、一条直线的线段长度之比、面积相等等。（相反，诸如角度值、三角形边长之比或二元扇形等概念，在并行设计中不保留）投影 - 并且不包含在我们的声明中。）并且由于任何三角形都可以借助某种平行投影转换为给定形状的三角形（想想为什么！），因此仅检查我们的声明是否有一种最方便类型的三角形就足够了。作为这样一个“好”三角形，我们采用由两条对角线和正五边形 (图 4) 的边组成的三角形 $ABC$。不难证明，正五边形的边与其对角线之比为$\alpha$。从这里可以清楚地看出，在 图 4

$$CL : LA=BK : KC=BD : AC=\alpha;$$
