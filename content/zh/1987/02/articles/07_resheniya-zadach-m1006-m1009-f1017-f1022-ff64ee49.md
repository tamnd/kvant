a) 答案：他们不能。即使划分中只有三个三角形大小相等（我们不需要关于四边形面积大小的假设），那么根据引理，划分这个三角形的线段应该彼此分成两半（图2），即它们将是平行线的对角线。但这是不可能的，因为这个“平行四边形”的两个相对边位于相交的直线上——这个三角形的边。

b) 答案：四边形和任意两个分割三角形的面积可以相等；第4部分的面积与三个相等部分的面积之比可以等于3或$\sqrt{5}-2$。

M1007。证明边长为 a、b、c 和 a₁、b₁、c₁ 的三角形相似当且仅当
$$\sqrt{a a_1} + \sqrt{b b_1} + \sqrt{c c_1} = \sqrt{(a_1 + b_1 + c_1)(a + b + c)}.$$

将所证明的等式两边平方并进行多次变换后，可简化为以下形式
$$(\sqrt{a b_1} - \sqrt{a_1 b})^2 + (\sqrt{c a_1} - \sqrt{c_1 a})^2 + (\sqrt{b c_1} - \sqrt{b_1 c})^2 = 0,$$
因此，它等价于等式$a/a_1 = b/b_1 = c/c_1$，即类似于三角形。

那么，可以得到另一个证明，左边等于坐标为$(\sqrt{a}, \sqrt{b}, \sqrt{c})$和$(\sqrt{a_1}, \sqrt{b_1}, \sqrt{c_1})$的向量的标量积，并且不能大于右边，右边等于这些向量的长度的乘积；仅当向量之间的角度为零时才可能相等，即它们彼此成比例。

本质上，在第二个论证中，我们使用所谓的柯西-布尼亚科夫斯基不等式：
$$x_1 y_1 + x_2 y_2 + \dots + x_n y_n \leq \sqrt{(x_1^2 + x_2^2 + \dots + x_n^2)(y_1^2 + y_2^2 + \dots + y_n^2)},$$
仅当数字集$(x_1, \dots, x_n)$和$(y_1, \dots, y_n)$成比例时（我们有$n=3$，$(x_1, x_2, x_3) = (\sqrt{a}, \sqrt{b}, \sqrt{c}), (y_1, y_2, y_3) = (\sqrt{a_1}, \sqrt{b_1}, \sqrt{c_1})$），它们才变成相等。

F1019。将底面积为 S 的小圆柱形容器放入装有密度为 $\rho_1$ 液体的大容器中，其中留有长度为 l (图1) 的管子；容器壁彼此牢固地固定在一起。将密度为$\rho_2$（$\rho_2>\rho_1$）的有色液体倒入小容器中至高度H，使大、小容器中的液位重合。在某个时间点，密度为$\rho_2$的液体管中的孔将流入更大的容器，直到密度为$\rho_1$的液体在A点（图2）处的压力等于密度为$\rho_2$的液体的压力。从这个条件很容易找到第一次从小容器中流出的液体的质量。

为此，我们写下平衡条件（参见 图2）：

$$\rho_1g(H+l)=\rho_2g(h+l)=\rho_2g(H-\Delta h+l),$$

(1)

其中 $\Delta h=(H-h)$ 是小容器中液位的下降。从这里

乍一看，似乎在$A$点的压力均衡后，该过程应该停止；但事实并非如此。这种情况是不可持续的。假设密度为 $\rho_1$ 的液体流入管内的高度为 $\Delta x$ (图 3)；那么密度$\rho_1$液体一侧$A'$点的压力将大于密度$\rho_2$液体一侧$A'$点的压力。

事实上，密度为 $\rho_1$ 的液体一侧的$A'$ 点的压力将等于 $p_1 = \rho_1 g(H + l - \Delta x)$，密度为 $\rho_2 - p_2 = \rho_2 g(h + l - \Delta x)$ 的液体一侧的压力；这些压力之间的差异

$$\Delta p = p_1 - p_2 = (\rho_2 - \rho_1) g \cdot \Delta x$$

将使液体向上移动，因为 $\rho_1 g(H + l) = \rho_2 g(h + l)$ 是平衡条件（参见（1））。密度为 $\rho_1$ 的液体将处于小酱汁中，直到$B$ 点上方和下方的压力（参见图 3）相等。密度为 $\rho_1$ 的液体将漂浮在密度为 $\rho_2$ 的液体上方（根据问题的条件，它们不会混合）。

让我们写出$B$点的平衡条件：

$$\rho_1 g H = \rho_1 g \Delta h_1 + \rho_2 g h,$$

其中$\Delta h_1$是密度为$\rho_1$的液体的高度，该液体位于小酱汁中。

从（1）和（2）我们发现：$\Delta h_1 = \frac{\rho_2 - \rho_1}{\rho_1} l$，并且

$$\Delta m_1 = (\rho_2 - \rho_1) l s.$$

现在液体从一种酱汁流到另一种酱汁的原因已经清楚了，让我们在更一般的情况下写出平衡方程。让我们假设 $B$ 点的平衡发生在

$$\rho_1 g H = \rho_1 g h_1 + \rho_2 g h_2,$$

其中 $h_1$ 是密度为 $\rho_1$ 的液体高度，$h_2$ 是小酱汁 (图 4) 中密度为 $\rho_2$ 的液体高度。我们已经知道平衡位置是不稳定的，液体会从小酱中流出，直到$A$点的压力平衡，这意味着

$$\rho_1 g(H + l) = \rho_1 g h_1 + \rho_2 g(h'_2 + l).$$

从（3）和（4）我们得到： $\Delta h_2 = h_2 - h'_2 = \frac{\rho_2 - \rho_1}{\rho_2} l$，并且

$$\Delta m_2 = (\rho_2 - \rho_1) l s.$$

当$A$点压力相等时，位置不稳定，密度为$\rho_1$的液体会呈小酱状流出，直到$B$点压力相等，这意味着

$$\rho_1 g H = \rho_1 g h'_1 + \rho_2 g h'_2.$$

从（4）和（5）我们得到： $\Delta h_3 = h'_1 - h_1 = \frac{\rho_2 - \rho_1}{\rho_1} l$，并且

$$\Delta m_3 = (\rho_2 - \rho_1) l s = \Delta m_2.$$

这意味着每次都会有相同质量的液体从小酱汁中流出并流入文本中

$$\Delta m = (\rho_2 - \rho_1) l s.$$

欧拉循环定理的证明

让我们以任意方式沿着箭头从任意顶点 $A$ 出发，“燃烧我们身后的地方”——擦除我们已经遵循的箭头。由于箭头是有限的，在某些步骤我们会被卡住——我们会来到一个死胡同，没有出路。我们不能卡在顶点$B \neq A$，因为从$B$出来的箭头与进入$B$的箭头数量相同。这意味着死胡同是原始顶点$A$。

所以，我们的路径是循环$c$，从$A$开始和结束。由于我们立即擦除了我们所遵循的每个箭头，因此循环 $c$ 不会两次经过任何箭头。

如果环$c$包含有向图的所有箭头，则它是欧拉环，定理得证。

如果没有，那么在$c$经过的顶点中将会有一个顶点$A_1$，未擦除的箭头$s_1$从该顶点伸出（如果没有找到这样的顶点，我们的有向图就不会被断开，图3）。
