第一轮

问题 1（苏联）。对于自然数 X 和 Y，如果复式 X 可以从复式 Y 中删除 0、1 或大量数字得到，我们就说 X 包含在 Y 中。 （例如：X=1010 包含在 Y=1001100 中）。构造一个算法，给定两个自然数 A 和 B，找到 A 和 B 中同时出现的最大数 C。

问题 2（捷克斯洛伐克）。给定 n 张卡片，编号为 1, 2, 3, ..., n（每个数字仅出现一次）。构建一个算法，对于这些卡片的任意序列 A₁、A2、A₃、...、Aₙ，将找到按照卡片编号升序排列卡片所需的最大排列数。我们所说的排列是指交换任意两张牌的单位体积。例：对于序列1,5,3,2,4，需要进行两次排列：5号和2号，然后是4号和5号，然后得到有序序列1,2,3,4,5。

2轮

问题 3（NRV）。构造一个算法，将前 N² 个自然数 (N>2) 分配到 N 组中，以便同时满足以下三个条件：

1) 每组恰好包含 N 个数字；
2) 每个数字只属于一组；
3) 每组中的数字之和对于所有组都是相同的。

问题 4（捷克斯洛伐克）。距离下一场比赛。对于给定的固定自然数 N>1，玩家 A 选择一个不能被 N 超过的自然数 X。玩家 B 的目标是使用“数字 X 是否大于或等于 K？”形式的问题来猜测数字 X，其中 K 是某个自然数。对于玩家 B 的每个问题，玩家 A 都会钝化数字并且不改变数字 X。玩家 B 为每个答案向玩家 A 支付：2 卢布。回答“是”并摩擦 1 次。为“否”。确定给定 N 的最小总和 P(N)，足以保证任何数字 X 从 1 到 N 的等级。构造一个算法，玩家 B 以猜测数字 X 的方式提出问题，同时燃烧不超过 P(N) 卢布（即确定所问问题中 K 值的算法）。
