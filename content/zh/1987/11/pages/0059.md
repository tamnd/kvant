“全部”、“部分”和否定

1. 至少有一个白球。
2. 所有球都是白色的。
3. 所有球都是红色的。
4. 有些等边三角形不是直线的。
5. 班里的一些学生没有参加会议。
6. 会议上没有一个女孩。
7. 给定六边形的一些角是直角或锐角。
8. $A x^2$ 中至少有一个 $x$ 不超过 4。
9. 所有人都不是孩子。
10. 对于 $A x^2 - 2x + 1 \neq 0$ 中的所有 $x$。
11. 有些男人身高不超过2米。
12. 有些素数是偶数。
13. 对于至少一个素数$p$，数$2^p - 1$不是素数。
14. 错误的。可能有一个白球，其余的都是蓝色的。
15. 正确的。
16. 为了确保获得白球，您需要取出至少 20 个球。数量较少可能不够，或者可以先取出红球和黑球——总共有 19 个。为了确保获得所有三种颜色的球，您需要取出至少 22 个球；如果先抽出所有白球和黑球，21 可以抢；其中只有 21 个。
17. 我们需要给 31 个人打电话。少则不可能——可以假设只有三角形和好的三角形才会被带到黑板上（有$10 + 20 = 30$），并且每个答案不超过4。如果你给31个人打电话，那么其中至少有一个人是优秀的学生，并且会回答5。

第二十一届全联盟数学奥林匹克竞赛

八年级

1. 笔记。利用$x_1 + y_1 = x_2 + y_2 = ... = x_{10} + y_{10} = 9$和$x_1 + x_2 + ... + x_{10} = y_1 + y_2 + ... + y_{10}$这一事实。
2. 答案：1、2、4、8、16、32。说明。如果$x_1 \leq x_2 \leq ... \leq x_6$是重物的质量，那么使用这些重物可以平衡的每个质量都写成$\varepsilon_1 x_1 + \varepsilon_2 x_2 + ... + \varepsilon_6 x_6$的形式，其中$\varepsilon_i = 0,1$而不是全部$\varepsilon_i = 0$。这样的金额只有63个。因此，它们一定是不同的。显然，$x_1 = 1$，$x_2 = 2$，$x_3 = 4$。证明$x_k = 2^{k-1}$，那么在配重$x_1, ..., x_{10}$的帮助下最平衡的质量等于$x_1 + x_2 + ... + x_4 = 2^{k-1}$。因此$x_{k+1} = 2^k$。
3. 令 $A_1 A_2 A_3 \dots A_7$ 为给定的七边形，$B$ $A_1 A_2$ 与$A_3 A_4$、$A_1 A_2 = x$、$A_1 A_3 = y$、$A_1 A_4 = z$ 的交点。三角形$BA_3 A_4$与$(\angle A_1 BA_3 = \angle BA_3 A_4 = 3\pi/7)$等边，三角形$A_2 BA_3$和$A_1 BA_4$与$(A_2 A_3 \parallel A_1 A_4)$相似。从这里我们立即得到$\frac{y - x}{y} = \frac{x}{z}$，或$\frac{1}{x} = \frac{1}{y} + \frac{1}{z}$。
