M88

方程$x^3 + ax^2 + bx + c = 0$的系数必须满足什么条件才能使其三个根形成等差数列？

让我们马上给出答案吧。所需的匹配是$c = \frac{ab}{3} - \frac{2}{27} a^3$（或者，相同的是，其中一个根必须等于$-\frac{a}{3}$）。事实上，让 $x_1, x_2$ 和 $x_3$ 成为我们方程的根。那么根据Vieta定理，

$$x_1 + x_2 + x_3 = -a.$$

另一方面，为了使 $x_1, x_2, x_3$ 形成算术级数，有必要且充分：

$$x_1 + x_3 = 2x_2.$$

姿势$x_1 + x_2 + x_3 = 3x_2$，打开$x_2 = -\frac{a}{3}$。尝试推导四次方程形成算术级数的条件。

F92

质量环$m$立在质量板$M$（图10）上。板与箍之间的摩擦系数为$k$。棋盘放在光滑的桌子上。如果用 $F$ 的力拉动环，木板会以多大的加速度移动？

让我们写下圆环和板的运动方程（牛顿定律方程二）。

在水平方向上，有两个力作用在环上 - 板与环之间的力 $F$ 和踩踏力 $F_{TP}$（参见 图 10）。身体的重心（在本例中为环的中心）移动，就好像作用在身体上的所有力都施加到了它身上。因此我们可以写成

$$ma_1 = F - F_{TP}$$

（$a_1$是圆环中心的加速度）。
