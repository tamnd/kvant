在指向折射率为 $n$ 的液体的容器侧壁上，连续有一个小半径$r$ 的孔。一束细光束沿着孔的轴线从容器水平射出。孔上方的液体必须达到什么水平$h$，才能使光线从射流中射出而不会经历内反射？

忽略射流截面的变化；假设液体的折射率足够大。

与水面成最大角度时，一束光线落在$A$ scab (图 12) 点。此时光束不会经历全内反射的入射角 $\alpha$ 必须满足以下条件：

$$\sin \alpha = \frac{1}{n}.$$

这是根据光折射定律（$\frac{\sin \alpha}{\sin \beta} = \frac{1}{n}$）和角度为$\beta = 90^\circ$的条件得出的。射流在点 $A$ 处的切线与水平面形成$\gamma = 90^\circ - \alpha$ 角。因此，如果射流在点$A$处的切线与地平线形成$\gamma$角，使得cos$\gamma = \frac{1}{n}$，则光线将从痂中射出，而不会经历内反射。

但液体表面的切线是孔上边缘出现的粒子轨迹的切线。因此切线方向

$$\cos \gamma = \frac{v_2}{v_1} = \frac{\sqrt{4gr}}{\sqrt{2gh}} = \sqrt{\frac{r}{h}}.$$

现在用 tg $\gamma$ 来表达 cos $\gamma$ —

$$\cos \gamma = \frac{1}{\sqrt{1 + tg^2 \gamma}}$$

考虑到 cos $\gamma = \frac{1}{n}$，我们得到

$$\frac{1}{n} = \frac{1}{\sqrt{1 + 2\frac{r}{h}}}.$$

从这里

$$h = 2r/(n^2 - 1).$$
