1. 等效节点法

该方法背后的思想是将电路中具有相同电势的不同节点视为一个节点。在这种情况下，所得“粘合”节点的电势等于原始节点的总电势。

如果等效节点通过导体（无电阻）连接，则电路的所有节点和分支中的电气状况不会改变，因为没有电流流过该导体。

让我们看一下例子。

任务 1. 找到与 图 1、$a$ 所示电路部分等效的电阻（图中的所有电阻都相同且等于 $r$）。

解决方案。很容易理解，节点 1、2 和 3 具有相等的电势。事实上，从对称信息可以清楚地看出，流过支路 A-1、A-2 和 A-3 的电流是相同的。因此，由于这些支路的电阻相等，其上的电位降也相同，节点1、2、3的电位也相同。

类似地，可以证明节点4、5和6也具有相等的电势（等效）。

显然，如果等效节点1、2、3连接在一起，电路电阻不会改变。如果连接后三个等效节点，电路的电阻不会改变。

完成此操作后，我们获得了与此等效的电路 (图 1, 6)。该电路的电阻不难发现：$AN$段的电阻为$\frac{1}{3} r \left( \frac{1}{R_{AN}} = \frac{1}{r} + \frac{1}{r} \right)$，$NM$段的电阻为$\frac{1}{6} r$，$MB$段的电阻为$\frac{1}{3} r$。因此$R_{AB} = \frac{5}{6} r$。

3. 节点“复制”的方法

该方法也与等效节点方法密切相关。如果用一个（连接节点）替换几个等效节点会产生等效电路，那么用几个等效节点反向替换一个节点将不会违反电路其余部分的电气条件。

让我们给出适合这种变换的电路示例。

任务 5. 求 图 5, a 中所示电路部分的电阻。

让我们用托盘节点替换节点$O$； $O_1$、$O_2$ 和 $O_3$（图 5，b）。然而，我们仍然需要证明这些电路是等效的。对于电路等效，节点 $O_1$、$O_2$ 和 $O_3$ 必须等效。但这非常印度，因为势差 $\varphi_{O_2}$ - $\varphi_A$ 等于点 $A$ 和 $B$ 势差的一半：$\varphi_{O_2} - \varphi_A = \frac{1}{2} u_{AB}$。

同样，从包含电阻的对称性报告中，不难发现$\varphi_{O_1} - \varphi_A = \frac{1}{2} u_{AB}$和$\varphi_{O_3} - \varphi_A = \frac{1}{2} u_{AB}$。因此，$\varphi_{O_1} = \varphi_{O_2} = \varphi_{O_3}$，即节点$O_1$、$O_2$、$O_3$是等价的。现在找到电路电阻并不困难。它等于 0.8 $r$ (图 5, θ)。

5. 循环法

解决问题的递归方法是一步步解决问题的一般方法，在第$n$步时需要使用前面步骤得到的结果。当电路具有重复结构且电阻数量较多时，递归方法在计算电路电阻问题中尤其方便。

任务 8. 求 图 8, a 中所示电路的电阻，其中 $r_1 = \frac{r}{2}, r_2 = \frac{r}{2}, r_3 = r_4 = r_5 = r_6 = r$。

解决方案。让我们重新画一下链条，如图8、6所示。显然，计算必须从$B$末端开始进行。将电阻$r_3, r_6$和$r_2$替换为等效电阻$R = r_2 + \frac{r_3 r_6}{r_3 + r_6} = r$，得到图8，c所示电路。现在，电阻$R, r_5$和$r_1$可以再次替换为等效的$R_1 = r_1 + \frac{R r_5}{R + r_5} = r$（图8，g）。电路的总电阻为

$$\frac{R_1 r_4}{R_1 + r_4} = \frac{r}{2}.$$
