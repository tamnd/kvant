部分地，如果 $a$ 可被 $m$整除，则 $a \equiv 0$ (mod $m$)。一致性（1）相当于$a$和$b$除以$m$时有相同的余数。让我们回想一下，$a$除以$m$的余数意味着$r$、$0 \leq r < m$，这样$a = mq + r$，其中$q$是一个整数。这个条件$r$是唯一确定的。留数也称为模留数$m$。我们用 $Z_m$ 表示它们的总数 $\{0,1,\dots,m-1\}$。

与变量相加可以得到模数的比较，如$a \equiv c$(mod$m$)、$b \equiv d$(mod$m$)，则$a + b \equiv c + d$(mod$m$)、$ab \equiv cd$(mod$m$)。这个很容易直接检查。如果$a - c$和$b - d$能被$m$整除，那么它们的和$a - c + b - d = (a + b) - (c + d)$能被$m$整除，以及表达式

$$ab - cd = ab - cb + bc - cd = b(a - c) + c(b - d).$$

用余数的语言来说，这意味着和$a + b$的余数仅取决于余数$r_1$和$r_2$，并且与数$r_1 + r_2$的余数一致；同样，余数$ab$仅取决于$r_1$和$r_2$，并且等于余数$r_1r_2$。因此，集合$Z_m$中出现的运算将被称为相应的加法和乘法模$m$（或$m$算术中的加法和乘法）。

因此，要对$Z_m$执行这些操作之一，您需要按照通常的意义执行这些操作，并在结果除以$m$时取余数。 $Z_m$（普通差的余数）中的减法以类似的方式定义。立即验证，$m$-算术减法是加法的逆运算，即

$$a + b = c \iff c - b = a;$$

$$a, b, c \in Z_m$$（证明）。

注意

$$0 - a = m - a \in Z_m;$$

$$a - b = a + (m - b).$$
