任务5.我们需要证明$\overrightarrow{A_1} + \overrightarrow{A_3} + \overrightarrow{A_5} < 450^\circ$。对于内切角 $A_1, A_3$ 和 $A_5$，以下等式成立*)

$$\overrightarrow{A_1} = 180^\circ - \frac{\cup A_2 A_7}{2},$$

$$\overrightarrow{A_3} = 180^\circ - \frac{\cup A_4 A_2}{2},$$

$$\overrightarrow{A_5} = 180^\circ - \frac{\cup A_6 A_4}{2} \text{ (см. рис. 1)}.$$

波兹尼

$$\overrightarrow{A_1} + \overrightarrow{A_3} + \overrightarrow{A_5} = 3 \cdot 180^\circ - \frac{\cup A_6 A_7}{2} = 2 \cdot 180^\circ + \frac{\cup A_7 A_6}{2}.$$

但弧 $A_7 A_6$ 不能大于正数，否则圆心 $O$ 不会位于我们的七边形内部。因此，

$$\overrightarrow{A_1} + \overrightarrow{A_3} + \overrightarrow{A_5} = 360^\circ + \frac{\cup A_7 A_6}{2} < 360^\circ + 90^\circ = 450^\circ.$$

九年级

任务5.解决这个问题最简单的方法是从最后开始——首先同意答案，然后证明它是正确的。您可以使用此类消息猜测答案。假设，对于$x = x_0$和$y = y_0$的某些值，$s$的值最大并且等于$s_0$。我们假设数字 $x_0, y_0 + \frac{1}{x_0}, \frac{1}{y_0}$ 彼此不相等。例如，$s_0 < y_0 + \frac{1}{x_0}$。让我们像这样增加$x_0$一点，

*) 倒计时是可选的，逆时针方向。

为了使 $x$ 的新值等于 $x'_0$，不等式 $s_0 < y_0 + \frac{1}{x'_0}$ 被保留。

之后，让我们再次稍微减小$y$，以便新值$y$等于$y'_0$，保留不等式$s_0 < y'_0 + \frac{1}{x'_0}$。

我们已经得到了 $x'_0$ 和 $y'_0$ 的值，对于它们来说 $s$ 大于 $s_0$。情况$s_0 < x_0$和$s_0 < \frac{1}{y_0}$的处理方式类似。因此$x_0 = y_0 + \frac{1}{x_0} = \frac{1}{y_0} = s_0$，因此$x_0 = \sqrt{2}, y_0 = \sqrt{2}, s_0 = \sqrt{2}$。这些论证并不完全严谨，这里的重点不在于“一点”，而在于我们假设存在一个集合$x_0, y_0$，其中$s$属于最大值。 （这个事实不是很明显。）但是，在证明了答案$s_0 = \sqrt{2}$之后，完成解决方案是相当容易的。事实上，让一些值$x_0, y_0, s > \sqrt{2}$。那么$x_1 > \sqrt{2}, \frac{1}{y_1} > \sqrt{2}$，由此$\frac{1}{x_1} + y_1 < \frac{1}{\sqrt{2}} + \frac{1}{\sqrt{2}} < \sqrt{2}$，即这个集合的s小于$\sqrt{2}$。由此产生的矛盾表明 s 的最大值为$\sqrt{2}$，并且只有在$x = \sqrt{2}, y = \sqrt{2}$ 时才能实现。
