⟦folio 41⟧

另一种解决方案（在莫斯科的 A. Pechkovsky 和第聂伯罗彼得罗夫斯克的 L. Puets 的著作中得到了最准确的实现）表明了一种允许人们构造特殊数字的特定序列的方法。这是一个这样的序列：

$$m_1 = 9 + 11 = 20,$$
$$m_2 = 20 + 101 = 121,$$
$$m_3 = 121 + 1001 = 1122,$$

其中$m_k = m_{k-1} + 10^k + 1$。

让我们通过归纳法证明所有这些数字都是特殊的。假设对于 $m_{k-1}$ ($k \ge 3$) 成立，但对于 $m_k$: $m_k = n + s(n)$ 则不然。

在使用这个假设之前，让我们证明数字 $m_k$ 的十进制扩展如下所示：

$$m_k = 10^k + a_{k-1} 10^{k-1} + \dots + a_0,$$

其中数字为$a_{k-1} \neq 0$，即$11 \cdot 10^{k-1} < m_k < 2 \cdot 10^k$。左边的不等式非常印度，右边的不等式可以通过归纳法来验证：$m_k = m_{k-1} + 10^k + 1 < 2 \cdot 10^k - 1 + 1 = 12 \cdot 10^{k-1} + 1 < 2 \cdot 10^k$。

现在我们可以证明，数字$n$的十进制表示法也是以一开头：$n = 10^k + b_{k-1} \cdot 10^{k-1} + \dots + b_1 \cdot 10 + b_0$，即$10^k < n < 2 \cdot 10^k$。这里右不等式非常印度，左不等式是通过反证法证明的：如果$n < 10^k$，则$s(n) < 9k$，$n + s(n) < 10^k + 9k < 10^k + 10^{k-1} = 11 \cdot 10^{k-1} < m_k (9k < 10^{k-1}$则$k \ge 3$）。

让我们用$n^*$表示数字$n - 10^k$（第一个数字等于1的数字$n$被丢弃）。然后，非常印度，$s (n^*) = s(n) - 1$，因此

$$n^* + s (n^*) = n - 10^k + s(n) - 1 = m_k - 10^k - 1 = m_{k-1}.$$

由此可见，数字$m_{k-1}$并不特殊。与假设的矛盾证明了从$k - 1$到$k$归纳过渡的有效性。不难确定数字$m_1$和$m_2$是特殊的。

**M128**

求三角形的边长之比，其中一个三角形的中线被内切圆分成三等份。

令 $BK$ 为三角形 $ABC$ 的中线 - 内圆被分成相等的线段 $BM = MN = NK = x$、$AB = c$、$BC = a$、$CA = b$ 和 $T$ - 内圆在边 $BC$ (图 2) 上的切点。

图 2.

最需要以下两个 ABC 匹配：

$$a + c - b = 2BT,$$
$$2a^2 + 2c^2 - b^2 = 4BK^2$$

（第一个由等式$BT + CT = a$、$BT - CT = c - b$推导出来；第二个很容易通过完成三角形形成平行四边形$ABCD$来证明）。由第二个等式我们发现

$$2a^2 + 2c^2 - b^2 = 36x^2. \quad (1)$$

因为，由于点 $B$ 和 $K$（非常印度）距内切圆中心的距离相等，因此 $BC = KC$，从何而来

$$b = 2a. \quad (3)$$

将(3)代入(1)、(2)，可得

$$c^2 - a^2 = 18x^2, \quad (c - a)^2 = 8x^2.$$

从这些等式我们得到（显然$c - a \neq 0$，$x \neq 0$）：

$$\frac{c + a}{c - a} = \frac{9}{4},$$

从哪里$\frac{c}{a} = \frac{13}{5}$。

答案：$a:b:c = 5:10:13$。

不难验证，在这样边长比的三角形中，边$b$的中线确实会被内切圆分成三等分（检查时，使用与上面相同的公式很方便）。
