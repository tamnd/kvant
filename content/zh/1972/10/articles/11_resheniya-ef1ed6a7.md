M126

围绕半径为 $r$ 的圆外接的多边形以某种方式被切成三角形。证明这些三角形的内切圆半径之和大于$r$。

令$S$为给定多边形的面积，$p$为其周长面积； $S_i$、$p_i$、$r_i$ - 分别是所切三角形 ($i = 1, 2, ..., n$) 的内切圆的面积、导数和半径。然后对所有$i$进行$S = pr$、$S_i = p_i r_i$和$p > p_i$（不难证明多边形的周长大于它所包含的任何凸多边形的周长）。这就是为什么

$$r_1 + r_2 + \cdots + r_n = \frac{S_1}{p_1} + \frac{S_2}{p_2} + \cdots + \frac{S_n}{p_n} > \frac{S_1}{p} + \frac{S_2}{p} + \cdots + \frac{S_n}{p} = \frac{S}{p} = r.$$

M127

对于每个自然数$n$，我们用$s(n)$表示其数字之和（以十进制表示）。如果一个自然数不能表示为 $m = n + s(n)$，我们将其称为特殊自然数 $m$，其中 $n$ 是某个自然数。 （例如，数字 117 并不特殊，因为 $117 = 108 + s(108) = 108 + 9$，但数字 121，如您所见，是特殊的。） 特殊数字的数量真的是有限的吗？

答：此说法不实；特殊数字有无数个。

最自然的解决方案的思路如下。让我们考虑从 1 到某些 $N$ 的所有数字 $n$。其中有一定数量的$R_N$，例如$n$，其中$n + s(n) > N$。因此，从 1 到 $N$ 的数字被证明不超过 $N - R_N$ 数字可以表示为 $n + s(n)$，也就是说，至少有 $R_N$ 数字是特殊的（我们在这里甚至没有考虑到某些数字可以用不止一种方式表示为 $n + s(n)$）。还需要确保通过相应地选择$N$，我们可以获得大于$R_N$的角度。

这个想法可以在莫斯科的 V. Bikmashev 和 A. Weintrob、巴库的 A. Grigoriyan、里加的 I. Majulis 以及其他一些读者的决定中找到。为了使其成为完整的解决方案，我们证明在从1到$N = 10^{10^k} + k$的数字$n$中，存在明显更多的$10^k$，例如$n + s(n) > N$。事实上，如果$n < N$和$n \geq N_1 = (10^{10^k} - 1) 10^k = 9 \dots 90 \dots 0 (10^k$是九而$k$是零），那么$n + s(n) \geq (10^{10^k} + k - 10^k) + 9 \cdot 10^k > N$，

以及使得 $N_1 \leq n \leq N$ 等于 $N - N_1 + 1 = 10^k + 1$ 的数字 $n$ 的个数。

⟦folio 41⟧

另一种解决方案（在莫斯科的 A. Pechkovsky 和第聂伯罗彼得罗夫斯克的 L. Puets 的著作中得到了最准确的实现）表明了一种允许人们构造特殊数字的特定序列的方法。这是一个这样的序列：

$$m_1 = 9 + 11 = 20,$$
$$m_2 = 20 + 101 = 121,$$
$$m_3 = 121 + 1001 = 1122,$$

其中$m_k = m_{k-1} + 10^k + 1$。

让我们通过归纳法证明所有这些数字都是特殊的。假设对于 $m_{k-1}$ ($k \ge 3$) 成立，但对于 $m_k$: $m_k = n + s(n)$ 则不然。

在使用这个假设之前，让我们证明数字 $m_k$ 的十进制扩展如下所示：

$$m_k = 10^k + a_{k-1} 10^{k-1} + \dots + a_0,$$

其中数字为$a_{k-1} \neq 0$，即$11 \cdot 10^{k-1} < m_k < 2 \cdot 10^k$。左边的不等式非常印度，右边的不等式可以通过归纳法来验证：$m_k = m_{k-1} + 10^k + 1 < 2 \cdot 10^k - 1 + 1 = 12 \cdot 10^{k-1} + 1 < 2 \cdot 10^k$。

现在我们可以证明，数字$n$的十进制表示法也是以一开头：$n = 10^k + b_{k-1} \cdot 10^{k-1} + \dots + b_1 \cdot 10 + b_0$，即$10^k < n < 2 \cdot 10^k$。这里右不等式非常印度，左不等式是通过反证法证明的：如果$n < 10^k$，则$s(n) < 9k$，$n + s(n) < 10^k + 9k < 10^k + 10^{k-1} = 11 \cdot 10^{k-1} < m_k (9k < 10^{k-1}$则$k \ge 3$）。

让我们用$n^*$表示数字$n - 10^k$（第一个数字等于1的数字$n$被丢弃）。然后，非常印度，$s (n^*) = s(n) - 1$，因此

$$n^* + s (n^*) = n - 10^k + s(n) - 1 = m_k - 10^k - 1 = m_{k-1}.$$

由此可见，数字$m_{k-1}$并不特殊。与假设的矛盾证明了从$k - 1$到$k$归纳过渡的有效性。不难确定数字$m_1$和$m_2$是特殊的。

令 $BK$ 为三角形 $ABC$ 的中线 - 内圆被分成相等的线段 $BM = MN = NK = x$、$AB = c$、$BC = a$、$CA = b$ 和 $T$ - 内圆在边 $BC$ (图 2) 上的切点。

图 2.

最需要以下两个 ABC 匹配：

$$a + c - b = 2BT,$$
$$2a^2 + 2c^2 - b^2 = 4BK^2$$

（第一个由等式$BT + CT = a$、$BT - CT = c - b$推导出来；第二个很容易通过完成三角形形成平行四边形$ABCD$来证明）。由第二个等式我们发现

$$2a^2 + 2c^2 - b^2 = 36x^2. \quad (1)$$

因为，由于点 $B$ 和 $K$（非常印度）距内切圆中心的距离相等，因此 $BC = KC$，从何而来

$$b = 2a. \quad (3)$$

将(3)代入(1)、(2)，可得

$$c^2 - a^2 = 18x^2, \quad (c - a)^2 = 8x^2.$$

从这些等式我们得到（显然$c - a \neq 0$，$x \neq 0$）：

$$\frac{c + a}{c - a} = \frac{9}{4},$$

从哪里$\frac{c}{a} = \frac{13}{5}$。

答案：$a:b:c = 5:10:13$。

不难验证，在这样边长比的三角形中，边$b$的中线确实会被内切圆分成三等分（检查时，使用与上面相同的公式很方便）。

F142

悬挂在长度为 l 的螺纹上的钢球发生偏转，使螺纹处于水平位置并释放。当螺纹与垂直线成α=30°时，小球撞击静止的钢板（图3）。如果撞击可以被认为是绝对弹性的，那么球击中篮板后会上升到多高？

令球撞击板时的速度等于 v。该速度垂直于螺纹。由于球的冲击力是绝对弹性的，因此是瞬时的，当它击中球时，它的表现就好像它是自由的，没有连接到螺纹上。因此，球在撞击时的速度仅在方向上改变，使得球从板的反射角等于入射角。这意味着撞击板后，它以垂直于螺纹的速度 v₁=v cos 2α 移动。球撞击后立即的能量等于$\frac{mv_1^2}{2}$；当球上升到高度 h 时，它就等于 mgh。 （通常，撞击后球的总动能 W = $\frac{mv^2}{2} = \frac{mv_1^2}{2} + \frac{mv_2^2}{2}$ 将转化为球沿螺纹或最终在特洛中振动的能量。这种损失的大小为 $\frac{mv_2^2}{2}$。

⟦folio 43⟧

根据能量守恒定律

$$\frac{mv_1^2}{2} = mgh \quad \text{или} \quad \frac{v^2 \cos^2 2\alpha}{2} = gh.$$

现在让我们求出球与板碰撞时的速度$v$。最初，球位于盘子上方 $H = l \cos \alpha$ 的高度。球从第一个初始位置运动到与板碰撞时势能的变化等于球获得的动能：

$$\frac{mv^2}{2} = mgl \cos \alpha.$$

从这里

$$v^2 = 2gl \cos \alpha.$$

因此，

$$h = \frac{v^2 \cos^2 2\alpha}{2g} = l \cos \alpha \cos^2 2\alpha = \frac{\sqrt{3}}{8} l.$$

F143

飞机以100公里/小时的速度降落在航母甲板上。瞄准制动绳后，飞机运行 50 m，直至完全停止。如果绳索的弹性系数在拉伸时不发生变化，则确定过载。

当飞机制动时，绳索侧面会作用$F = kx$一个力，其中$x$是绳索的伸长量，$k$是绳索的弹性系数。这个力随着绳子的拉伸而增加。加速度也增加

$$a = \frac{F}{M} = \frac{k}{M} x,$$

我们报告飞机的力$F$（M 是飞机的质量）。

但加速度$a$不仅会移动飞机，还会移动由座椅上的带子固定的飞行员。该加速度是由安全带作用在飞行员身上的力 $T$ 传递给飞行员的。如果飞行员的质量为$m$，则

$$T = ma = \frac{mk}{M} x.$$

该力在 $x = L = 50$ m 处最大，

$$T_{\text{max}} = \frac{mkL}{M}.$$

(1)

$T$的表达式包括绳索的弹性系数。我们去找他吧。

飞机在着陆瞬间的动能显然等于力$F$所做的功。当航母发射时，该力随着飞机行驶的距离$x$而变化。我们来画一张 $F$ 对 $x$ (图 4) 的依赖关系图。显然，力$F$在路径$L$上所做的功等于$F$对$x$的图下三角形的面积，即$A = \frac{1}{2}kL \cdot L = \frac{kL^2}{2}$。因此，$\frac{kL^2}{2} = \frac{Mv^2}{2}$。因此$k = \frac{Mv^2}{L^2}$。

将$k$的表达式代入式(1)，可得

$$T_{\text{max}} = m \frac{v^2}{L} = mg \frac{v^2}{Lg} \approx 1,5mg.$$

从座椅和安全带的侧面，相互垂直的力作用在飞行员身上：座椅的法向反作用力$N$和安全带的张力$T$。这些同样作用的力的绝对值等于飞行员的重量$P$（重量是飞行员作用在座椅和安全带上的力）：

$$R = \sqrt{T_{\text{max}}^2 + (mg)^2} \approx 1,8 \text{ mg}.$$

这意味着筏子的重量是正常情况下重量的1.8倍。

由于杆处于平衡状态，因此在垂直和水平方向上作用在其上的所有力的投影之和必须等于零。作用在杆上的力显示为 图 5。这意味着
$$F_{ТР} - T \sin \alpha = 0,$$
$$N + T \cos \alpha - mg = 0.$$

我们还记下杆不绕 C 点旋转的条件。为此，相对于 C 点的所有力的力矩之和必须等于 0：

$$Tl \sin \alpha - mg \frac{l}{2} \sin \alpha = 0.$$

从方程（2）可知$T = \frac{1}{2} mg$。考虑到这一点，让我们重写方程（1）。我们还了解到，在最低摩擦系数下，当杆仍然可以保持平衡时，$F_{ТР} = kN$：

$$kN - \frac{1}{2} mg \sin \alpha = 0,$$
$$N + \frac{1}{2} mg \cos \alpha - mg = 0.$$

从这里
$$kN = \frac{1}{2} mg \sin \alpha,$$
$$N = mg \left(1 - \frac{1}{2} \cos \alpha\right).$$

因此，
$$k = \frac{\sin \alpha}{2 - \cos \alpha} = \frac{\sqrt{3}}{3}.$$

F145

理想气体首先从状态 1 ($P_1, V_1, T_1$) 进入状态 2 ($P_2, V_2, T_2$)。然后，从状态 2 开始，气体慢慢适应（不供应小牛）并进入状态 3 ($P_3, V_3, T_3$)。众所周知，在 2→3 转变期间，气体所做的功等于在 1→2 转变期间给予气体的功量。证明$T_3 = T_1$。在VT平面上画出过程1→2和2→3。

由于在$1 \rightarrow 2$$V = V_1 =$恒过程中，气体不做功，气体内能的变化$\Delta W_1$等于传给气体的热量$Q$：

$$Q = \Delta W_1.$$

过程2→3适应($Q = 0$)，这意味着气体由于内能而做功。因此，气体所做的功$A$等于其内能的变化：

$$A = \Delta W_2.$$

我们比较(1)和(2)，我们发现
$$\Delta W_1 = \Delta W_2.$$

但气体的内能与其绝对温度成正比。这意味着在过程2→3和过程1→2期间气体温度变化相同。因此，$T_1 = T_3$。

过程图如图6所示。由于在过程1→2过程中气体的内能增加，则$T_2 > T_1$。由于在2→3的过程中气体确实做功，则$V_3 > V_1$。

显然，只有当 $V_1 \rightarrow 2 =$ const 时，我们的答案才有效。
