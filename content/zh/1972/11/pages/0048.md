让我们证明$n$是整数的平方。让我们输入$m = x_1 + x_2 + \dots + x_n$。那么$m$是一个整数，

$$m^2 = (x_1 + x_2 + \dots + x_n)^2 = (x_1^2 + x_2^2 + \dots + x_n^2) + (x_1x_2 + x_2x_3 + \dots + x_nx_1) + (x_1x_3 + x_2x_4 + \dots + x_{n-1} \times x_1 + x_nx_2) + \dots + x_nx_{n-1}).$$

由问题条件可知，在这个等式右边，第一个括号中的数字之和等于$n$，而任何其他括号中的数字之和等于0。因此，$n = m^2$。问题a)已经解决。

让我们确定对于哪个$n$，我们可以选择满足问题条件的数字$x_1, \dots, x_n$。由���题 M93可知，$n$必须能被4整除；这意味着 $n$ 是偶数的平方。如果$n=4$，则可以选择以下数字：$x_1=x_2=x_3=1$、$x_4=-1$。 $n$ 的下一个可能值是 16。

让我们证明对于 $n=16$ 这样的数字 $x_1, \dots, x_{16}$ 是无法选择的。

让我们假设给出的数字$x_1, \dots, x_{16}$满足问题的条件，并尝试得出矛盾。

让$m = x_1 + \dots + x_{16}$。我们可以假设$m \geq 0$（否则我们可以用$-x_i$替换所有数字$x_i$而不违反问题的条件），如图所示，$m^2 = n = 16$，即$m=4$。

如果数字$x_i$中的$p$等于$1$且$q$等于$-1$，则

$$p + q = n = 16 \text{ и } p - q = m = 4.$$
所以，$p=10$，$q=6$。

我们假设数字 $x_i$ 写在正 16 边形的顶点上。让我们用星号标记那些数字为 $-1$ 的顶点（总共 6 颗星）。让我们将整个图片旋转完整旋转 ($k=1, 2, \dots, 15$) 的 $\frac{k}{16}$ 部分。

让我们证明，在这种情况下，恰好有 2 颗星星会到达星星相等的顶点。事实上，让$r$等于$-1$的数字移动到$-1$所在的位置。那么$x_1x_{k+1} + x_2x_{k+2} + \dots + x_{16-k+1}x_1$的总和将是$(6-r)$项，其中第一个因子是$-1$和第二个$+1$，以及$(6-r)$项，其中第二个因子是$-1$和第一个$+1$；这意味着有 $2(6-r)$ 项等于 $-1$。

由于和为0，则$2(6-r) = 8$，即$r=2$。

现在我们可以将我们的问题重新表述如下：是否可以将 6 颗星放在正 16 边形的顶点上，使得其中两颗星位于相对的顶点，并且对于从 1 到 7 的任何数字 $k$ ，都会有相等的 $k$ （在多度计两点之间的距离下，长度小于连接它们的弧，并且将整个圆的长度取为 16 部分；我们将 $X$ 和 $Y$ 表示为 $(XY)$。

让我们用 $A$ 和 $B$ 表示由星号偏移的完全相反的点，并用 $C, D, E, F$ 表示其他偏移点。让我们计算点 $A, B, C, D, E, F$ 之间所有距离的总和。距离 8 出现一次，距离 1 到 7 出现两次——总和为 $2(1+2+3+4+5+6+7)+8=64$。

让我们看看点 $C, D, E, F$ 之间的距离是多少。由于$(AX) + (BX) = 8$适用于任意点$X$，因此点$C, D, E, F$之间的所有距离之和$\Sigma$等于$64 - (AB) - 4 \cdot 8 = 24$。此外，如果点$C, D, E, F$之间实现了某个距离$k$，则这意味着$(AC), (AD), (AE), (AF) и (BC), (BD), (BE), (BF)$在数字中出现的次数少于两次；但$(8-k)$出现的次数少于两次，即$(8-k)$也被实现为点之间的距离$C, D, E, F$。让我们看看如何定位点$C, D, E, F$。很容易检查两种情况都是可能的。

1) 一些三个点（例如，$C, D, E$）形成一个包含圆心的三角形。让$F$位于$C$和$D$之间。然后

$$(CD) + (DE) + (CE) = 16,$$
$$(CF) + (DF) = (CD),$$

并且，此外，$(EF)$大于$(CE)$或$(DE)$。由于$(CD) + (DE) > 8$和$(CD) + (CE) > 8$，然后是$\Sigma = (CD) + (DE) + (CE) + (CF) + (DF) + (EF) = 16 + (CD) + (EF) > 24$，尽管如我们之前所示，这个总和应该等于24。这意味着第一个案例是新的。

2) 点 $C, D, E, F$ 位于特定直径的一侧。让它们按照以下顺序$C, D, E, F$排列在圆圈周围。然后$(CD) + (DF) = (CF) + (CE) + (DF) + (EF) = 16$（$3(CF) + (DE)$之和）。所以，$3(CF) + (DE) = 24$。从$CF > DE$开始，然后$(CF) = 7$，$(DE) = 3$。如果$(CD) = 1$，则$(DF) = 6$；但同时，点$C, D, E, F$之间的距离$2 = 8 - 6$并未实现，这与之前的证明相矛盾。如果$(CD) = 2$，那么尽管$(CF) = 7$，距离1也没有实现。如果$(CD) = 3$则$(EF) = 1$，这种情况与$(CD) = 1$没有什么不同。
