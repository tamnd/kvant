每种颜色的细胞数量相等。

但是，另一方面，这样的棋盘上总是有彩色的对角线

$$r_2 + r_1 - 1 \leq \frac{k}{2} + \frac{k}{2} - 1 < k,$$

这样它就不会包含至少一种用于着色的颜色的单个单元格。矛盾！

因此，当且仅当至少有一个数字 $m, n$ 能被 $k$ 整除时，棋盘 $m \times n$ 可以用线性 $k$-minо 进行布局。

这个问题可以通过使用不同的颜色来解决。

第二个解决方案。

假设没有一个数字 $m, n$ 可以被 $k$ 整除，并且棋盘 $m \times n$ 采用线性 $k$-min® 布局。

将余数 $m$ 和 $n$ 除以 $k$：

$$m = kq_1 + r_1; \quad 0 < r_1 < k,$$
$$n = kq_2 + r_2; \quad 0 < r_2 < k.$$

使用如下颜色为板$k$着色：第一列 - 第一种颜色，第二 - 第二种，...，$k$th - $k$，$(k+1)$th - 第 1，等等，$m$th - $r_1$颜色 (图9)。

以这种方式着色的棋盘具有以下属性：如果线性$k$-min®垂直放置在棋盘上，那么它将覆盖$k$相同颜色的单元格，如果水平放置，它将恰好覆盖每种颜色的一个单元格。该板的布局应为 $k$-minо；这就是为什么

$$S_1 \equiv S_2 \equiv \dots \equiv S_k \pmod{k},$$

其中 $S_1(l=1, 2, \dots, k)$ 是一个数字

$$S_{r_1} - S_{r_1+1} = n;$$

跟随，

$$S_{r_1} - S_{r_1+1} \equiv r_2 \pmod{k},$$

所以

$$S_{r_1} \neq S_{r_1+1} \pmod{k}.$$

第三个解决方案。

假设棋盘 $m \times n$ 按线性 $k$-minо 布局，并且

$$m = kq + r_1; \quad 0 < r_1 < k;$$
$$n \equiv r_2 \pmod{k}; \quad 0 < r_2 < k.$$

这么说吧 $k$-米诺“成长自 $l$th 列”如果它是水平的并且开始于 $l$第 列 (图 10).

让我们用$t_l$表示从第$l$列开始增长的$k$-minо的数量。根据假设，棋盘布局为$k$-min®；这就是为什么

$$t_1 \equiv r_2 \pmod{k},$$
$$t_2 \equiv 0 \pmod{k},$$
$$t_3 \equiv 0 \pmod{k},$$
$$\dots$$
$$t_k \equiv 0 \pmod{k},$$
$$t_{k+1} \equiv r_2 \pmod{k},$$
$$t_{k+2} \equiv 0 \pmod{k},$$
$$\dots$$
$$t_{kq+1} \equiv r_2 \pmod{k}.$$

*) $m: k$ 和往常一样，意味着 $m$ 可以被 $k$ 整除。
