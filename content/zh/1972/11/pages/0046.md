图 3.

必须位于集合$V$的边界上；它们都不能在 $V$ 内：毕竟，$V$ 包含在每个条纹 $\Pi_{ij}$ 中。

现在用两个词就可以得到问题a)的解决方案。在这种情况下，$V$是一个凸$n$边形，顶点为$A_1, A_2, \dots, A_n$。它的角度之和等于$180^\circ (n - 2)$，并且如果每个角度不大于$90^\circ$，则

$$180^\circ (n - 2) \leq 90^\circ n,$$

从哪里$n \leq 4$。

很多读者都发来了飞机上问题的解决方案。空间问题要困难得多，我们还没有收到任何读者的完整证明。让我们介绍一个由著名几何学家 L. Danzer 和 B. Grionbachum (1962) 首先发现的解决方案。

让我们考虑一下，除了多面体$V$（这里$V$可以理解为给定$n$点$A_1, A_2, \dots, A_n$的凸包或所有$n (n - 1)/2$条纹$\Pi_{ij}$的交集——公共部分），还有多面体：

$$V_i, \text{ получищеся из } V \text{ сдигом на вектор } \overrightarrow{A_1 A_i} (i = 1, 2, \dots, n); V_1, \text{ размещется, совпадает с } V), \text{ и } V', \text{ получищеся из } V \text{ расстоянием (гомотетей) с коэффициентом 2 и центром в точке } A_1.$$

我们来证明以下三个命题。

1. 由向量$\overrightarrow{A_i A_j}$从$V$得到的多面体与$V$没有公共内点（即只能在边界上与$V$相交）。

2. 没有两个多面体$V_1, V_2, \dots, V_n$有共同的内点。

3. 所有$V_i$都包含在$V'$中。

我们来证明 1°。当转移到$\overrightarrow{A_i A_j}$时，条纹$\Pi_{ij}$转变为一个新的条纹，它与它没有共同的内部点——这两个条纹只有一个共同的边界平面。但$V$包含在$\Pi_{ij}$中，所以1°更真实。

1° 发生 2° 变化：通过移位到向量 $\overrightarrow{A_i A_j}$ (图 4) 来替换从 $V_i$ 获得的 $V_j$ 就足够了。

图 4.

$$3^\circ \text{ следует из более общого факта: если } ABC \text{ — три точки выпуклого многогранника, } W \text{ и } W' \text{ — многогранник, полученный из } W \text{ растяжением в 2 раза с центром в точке } A, \text{ то четыряя вершина } D \text{ параллелограмма } ABDC \text{ (то есть точка, получшаяся из } C \text{ сдигром на вектор } \overrightarrow{AB}) \text{ принадлежит } W'.$$

这个事实很容易证明：点$K$，从该点拉伸时，得到$D$——线段$AD$的中点——同时也是线段$BC$的中点，因此它属于$W$（毕竟多面体$W$是凸的），因此$D$属于$W'$（图5）。

因此，命题2°和命题3°得证。令 $v$ 为多面体 $V$ 的体积。那么$V_i$各点的体积为$v$，$V'$的体积为$8 v$。从2°和3°显然可以得出$nv \leq 8 v$，由此得出$n \leq 8$。

让我们注意到，我们已经解决了第十三届国际奥林匹克竞赛中提出的问题（参见1971年“Quant”第12期，第54页，问题2）：显然，问题M130 6）整个问题，国际评审团认为这对奥林匹克竞赛来说太难了，只包括了后半部分。

与经过验证的陈述相关，将会出现一些问题，这些问题不再能够以我们所讨论的美丽的、而是人为的方式来解决。例如，空间中最纯净的点是哪里？
