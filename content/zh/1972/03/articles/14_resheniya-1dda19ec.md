M90
证明如果$x_1 < x_2 < x_3 \dots$是自然数，那么
$$\frac{\sqrt{x_2-x_1}}{x_2} + \frac{\sqrt{x_3-x_2}}{x_3} + \dots + \frac{\sqrt{x_n-x_{n-1}}}{x_n} < 1 + \frac{1}{2} + \frac{1}{3} + \dots + \frac{1}{n^2} + \frac{1}{n^3} + \frac{1}{n^4}.$$

我们首先假设$x_n \leq n^2$。然后
$$\frac{\sqrt{x_i-x_{i-1}}}{x_i} \leq \frac{x_i-x_{i-1}}{x_i} = \frac{1}{x_i} + \frac{1}{x_i} + \dots + \frac{1}{x_i}.$$
$$x_i - x_{i-1} \text{ слагаемых}$$

最后的总和显然没有超过包含相同项数的总和
$$\frac{1}{x_{i-1}+1} + \frac{1}{x_{i-1}+2} + \dots + \frac{1}{x_i} + \frac{1}{x_i-1} + \frac{1}{x_i}.$$

没有然后
$$\sum_{i=1}^{n} \frac{\sqrt{x_i-x_{i-1}}}{x_i} < \frac{1}{x_0+1} + \dots + \frac{1}{x_1} + \frac{1}{x_1+1} + \dots + \frac{1}{x_i} + \dots + \frac{1}{x_{n-1}+1} + \dots + \frac{1}{x_n} < \frac{1}{2} + \frac{1}{3} + \dots + \frac{1}{n^2} < 1 + \frac{1}{2} + \frac{1}{3} + \dots + \frac{1}{n^2}.$$
现在假设数字$x_0, x_1, x_2, \dots, x_n$中有大于$n^2$的数。若$x_i > n^2$，则
$$\frac{\sqrt{x_i-x_{i-1}}}{x_i} < \frac{\sqrt{x_i}}{x_i} = \frac{1}{\sqrt{x_i}} < \frac{1}{n}.$$
因此，值$x_i$大于$n^2$的项小于$\frac{1}{n}$。
因此，所有这些项（不超过 $n$）的总和小于 1。但如上所示，其余项的总和小于 $\frac{1}{2} + \frac{1}{3} + \dots + \frac{1}{n^2}$，这就完成了不等式的证明(*)

F101

一个球悬挂在一个刚度为 $k$ 的非常细的悬挂弹簧上。起初弹簧没有被拉伸。球移动时的最大速度是多少？球的质量为$m$。

让我们写出球的运动方程。有两个力作用在其上：重力$mg$和弹簧张力$F = kx$，其中$x$是弹簧的变形。根据牛顿第二定律

$$mg - kx = ma.$$

从这个方程可以看出，球的加速度 $a$ 最初向下并减小，然后在 $x = \frac{mg}{k}$ 处为零，然后再次返回，但向上。

当球的加速度向下时，球的速度会返回；当球的加速度向上时，速度会减小。因此，球的速度在$x = \frac{mg}{k}$时最大。

为了找到它，我们写下了能量守恒定律。如果球落到距离$x$，则其势能减少$mgx$，动能增加$\frac{mv^2}{2}$（之前等于0）。球势能的一小部分（等于 $\frac{kx^2}{2}$）用于增加弹簧变形的势能。这就是为什么

$$mgx = \frac{kx^2}{2} + \frac{mv^2}{2}.$$

因此，对于 $x = \frac{mg}{k}$ 我们得到

$$v_{\text{max}} = g \sqrt{\frac{m}{k}}.$$

F102

氧气和氦气在密封容器中均匀混合。然后在容器壁上打一个洞。从它发出的分子束的成分是什么？

气体分子的能量仅取决于其温度。由于容器中的气体处于平衡状态且温度相同，因此

$$\frac{m_{\text{O}_2}v_{\text{O}_2}^2}{2} = \frac{m_{\text{He}}v_{\text{He}}^2}{2},$$

$$x_{\max} = \frac{2v_0^2 \sin \alpha \cos \alpha}{g} = \frac{v_0^2 \sin 2\alpha}{g}.$$

这是 sin $2\alpha=1$ 处（即 $\alpha=45^\circ$ 处）最大值的表达式。

我们来画一个弹丸飞行距离对 $\alpha$ (图 12) 的依赖关系图。对于弹丸离去角的小偏差 $\Delta \alpha$，依赖图 $x_{\max}(\alpha)$ 可以用直线代替 - 实际图 $x_{\max}(\alpha)$ 的切线。这条切线的斜率越大，对于相同的弹丸出发角误差$\Delta \alpha$，弹丸射程的误差就越大。

从 图 12 可以清楚地看出，在小射弹离去角时，切线与地平线（相对于 $0\alpha$ 轴）的倾斜角大于大弹丸离去角时的倾角。这意味着，在小弹丸出射角时，改变弹丸出射角时射程的变化要大于在大弹丸出射角时的射程变化，而使用管角为$40^\circ$的箭，射弹的精度将高于$30^\circ$角的箭。

使用公式可以得到相同的结果。设弹丸出射角误差较小，为$\Delta \alpha$。那么弹丸射程内的误差$\Delta x$为

$$\Delta x = \frac{v_0^2}{g} \sin 2\alpha - \frac{v_0^2}{g} \sin [2(\alpha + \Delta \alpha)] = 2 \frac{v_0^2}{g} \cos(2\alpha + \Delta \alpha) \sin \Delta \alpha \approx 2 \frac{v_0^2}{g} \cos 2\alpha \cdot \Delta \alpha.$$

因此，$\Delta x$与$\Delta \alpha$成比例，但比例系数取决于$\alpha$。角度$\alpha$越小，则越大。

在一个封闭的容器中，有几滴不同大小的液体。很长一段时间后，他会发生什么？

液滴表面的饱和蒸气压取决于其半径。让我们展示一下。

让我们想象一个封闭的容器，其中有一个毛细管，一种不可润湿的液体。点 $B$ 处的压力比点 $A$ (图 13) 处的压力大 $\rho_{\pi}gh$：

$$P_B = P_A + \rho_{\pi}gh,$$

其中$h$是毛细管和容器中的液位差，$\rho_{\pi}$是蒸汽密度。

由于毛细管中的液膜在两个力的作用下处于平衡状态：张力表面力等于$2\pi r\sigma$（σ为张力表面系数，r为毛细管半径）和深度$h$等于$\rho_{\pi}gh \cdot \pi r^2$（$\rho_{\pi}gh$为液体密度）的流体压力，则$2\pi r\delta = \pi \rho_{\pi}ghr^2$。

从这里

$$h = \frac{2\sigma}{\rho_{\pi}gr}$$

和

$$P_B = P_A + \frac{2\sigma}{r} \frac{\rho_{\pi}}{r_{\pi}}.$$

因此，液滴的半径越小，液体表面上方的压力就越大。这意味着，如果蒸汽在小水滴表面上方饱和，那么在大水滴表面上方则不会饱和。这会导致蒸汽在大水滴上凝结，从而影响小水滴表面的蒸汽压力。这反过来又导致小水滴蒸发。结果，一段时间后，容器中只剩下一大滴。

从最一般的推理中也可以得到同样的结果。我们假设容器中有液体（液体表面是平坦的）并且有一滴。
