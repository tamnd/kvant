⟦folio 37⟧

考虑多项式 $F(x) = A_n(x) - 2^{n-1}D_n(x)$。它的次数小于 $(n-1)$，因为多项式 $A_n(x)$ 和 $2^{n-1}D_n(x)$ 的 $x^{n-1}$ 系数相等。这意味着 $F(x)$ 等同于 0，或者 $F(x)$ 的根小于 $(n-1)$。

考虑点 $x_1 = -\frac{\pi}{n}, x_2 = -\frac{2\pi}{n}, \ldots, x_{n-1} = -\frac{\pi(n-1)}{n}$ 和路径 $t_i = \cos x_i$。显然$f(x_i) = 0$，因此$D_n(t_i) = 0$；另外，$\sin(n \cdot x_i) = 0$、$\sin x_i \neq 0$表示$A_n(\cos x_i) = A_n(t_i) = 0$。请注意，所有点 $t_i$ 都是不同的，因为 cos $x$ 返回线段 $[-\pi, 0]$ 上。

因此，多项式 $F(x)$ 在 $(n-1)$ 点 $t_1, t_2, \ldots, t_{n-1}$ 处消失，因此 $F(x)$ 是同零。因此，$A_n = 2^{n-1}D_n$，即

$$\sin x \cdot \sin \left(x + \frac{\pi}{n}\right) \times \cdots \times \sin \left(x + \frac{\pi(n-1)}{n}\right) = \frac{1}{2^{n-1}} \sin nx.$$

现在让我们回忆一下如何证明$k$次多项式最多有$k$个根。对于 $k = 1$ 来说这是显而易见的。令该陈述对于 $k = l-1$ 成立，并令路径 $P(t) = a_l t^l + a_{l-1} t^{l-1} + \ldots + a_1 t + a_0$ 为$l$ ($a_l \neq 0$) 次多项式。令$\alpha$为多项式$P$的根（如果$P$无根，则一切都被证明）：$P(\alpha) = a_l \alpha^l + \ldots + a_0 = 0$。因此$P(t) = P(t) - P(\alpha) = a_l (t^l - \alpha^l) + a_{l-1} (t^{l-1} - \alpha^{l-1}) + \ldots + a_1 (t - \alpha).$ 很容易检查$t^l - \alpha^l = (t - \alpha)(t^{l-1} + \alpha t^{l-2} + \alpha^2 t^{l-3} + \ldots + \alpha^{i-2} t + \alpha^{i-1}).$ 因此$P(t) = (t - \alpha)[a_l (t^{l-1} + \ldots + \alpha^{l-1}) + a_{l-1} (t^{l-2} + \ldots + \alpha^{l-2}) + \ldots + a_1] = (t - \alpha) H(t)$，其中$H(t)$ 是$l-1$ 次的非八进制多项式。

根据假设，$H(t)$至多有$(l-1)$根。这意味着 $P$ 最多有 $l$ 根（$\alpha$ 和多项式 $H(t)$ 的根）。

我们的说法已被所有$k$证明。

**M136**

七匹三匹马能否从采石场增加 50 块石头，其重量分别为 370 克、372 克、374 克、……、468 克（均构成相差 2 克的算术级数）？

答：不。

如果要加大石子的话，三轮车上就得放8块石子，但即使是最轻的8块石子也有重量。

$$370 + 372 + 374 + 376 + 384 + 382 + 380 + 378 = 4.754 = 3016$$

公斤 - 超过三吨。
