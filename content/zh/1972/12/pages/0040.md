很长且面积很大 (图 1)，那么显然足以证明凸四边形的不等式 a)、6)。因此，我们将仅考虑凸四边形。

所以，凸四边形$ABCD$(图2)$AB = a, BC = b, CD = c, DA = d$内的路径，$ABCD$的面积为$S$。三角形的面积始终不超过其两条边的乘积的一半（图3）。这就是为什么

$$2S(\Delta ABC) \leq ab \text{ и } 2S(\Delta CDA) \leq cd. \tag{1}$$

添加这些不等式，我们得到

$$2S \leq ab + cd. \tag{2}$$

这里的等式是在一般不等式（1）中同时实现的情况下实现的，即当且仅当元素$B$和$D$都齐平时。当然，在这种情况下，四边形$ABCD$可以写成圆形（对角线$AC$是直径）。由上可知，$2S = ab + cd$可以由线段$a, b, c, d$组成，当且仅当它们的长度满足条件

$$a^2 + b^2 = c^2 + d^2. \tag{3}$$

问题6）有点困难。它可以通过应用三角形面积的各种公式来“正面”解决。但也有一个非常简单的几何解决方案。

让我们像以前一样，将四边形对角线 $BD$ 切成两个三角形，其中一个 - 比如说三角形 $BCD$ - “将其翻转到相反的一侧”，然后再次将边 $BD$ 应用于三角形 $BAD$。换句话说，我们将 $\triangle BCD$ 替换为三角形 $BC'D$，相对于穿过线段 $BD$ (图 4) 中间的垂直线对称。显然四边形$S$的面积不会改变。但现在我们可以使用问题a)的结果：

$$2S \leq AB \cdot BC' + C'D \cdot DA$$

或者

$$2S \leq ac + bd. \tag{4}$$

如果“重建”四边形 $ABC'D$ 具有直角 $B$ 和 $D$，即，如果原始四边形 $ABCD$ 具有对角线 $BD$ 与每对相对边形成的角度，加起来为 $90^\circ$，则可以实现 (4) 中的相等：

$$\angle ABD + \angle BDC = \angle ADB + \angle DBC = 90^\circ \tag{5}$$

当然，从这里可以得出$\angle ABC + \angle ADC = 180^\circ$，即四边形$ABCD$是内接的（这从$\angle A + \angle C = \angle A + \angle C' = 180^\circ$的事实也可以清楚地看出）。 （请注意，四边形

$$2S = ac + bd, \tag{6}$$

可以由线段 $a; b, c, d$ 组成当且仅当

$$a^2 + c^2 = b^2 + d^2; \tag{7}$$

这是从应用于 $ABC'D$ 的 (3) 得出的。

还有一点注意。您不认为等式（6）的充要条件（5）是“非等距的”吗？毕竟，在 (6) 中，两对相反的顶点平等参与 - 为什么对角线 $BD$ 比 $AC$ 更好？当然，她也好不了多少。我们现在将看到条件（5）可以用对称性代替，因此，正如通常的情况一样，更简单。
