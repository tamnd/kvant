M135
证明对于每个自然数$n>1$，相同的公式都成立

$$\sin x \sin \left( x + \frac{\pi}{n} \right) \sin \left( x + \frac{2\pi}{n} \right) \times \cdots$$
$$\cdots \times \sin \left( x + \frac{(n-1)\pi}{n} \right) = c_n \sin nx,$$
其中$c_n$是某个数字（取决于$n$），并找到$c_n$。

首先我们证明以下引理。
引理。 $$\sin nx = \sin x \cdot A_n (\cos x),$$
food $A_n (x)$ 是 $(n-1)$ 次非共性多项式，第一个系数为 $2^{n-1}$、$$\cos nx = B (\cos x),$$
food $B_n (x)$ 是$n$ 次非共性多项式，第一个系数为$2^{n-1}$。

很明显，对于$n=1$，引理的陈述是正确的。令 $n=k$ 成立。然后

$$\sin (k+1) x = \sin x \cdot \cos kx + \cos x \cdot \sin kx = \sin x \cdot \left( B_k (\cos x) + \cos x \cdot A_k (\cos x) \right);$$
$$\cos (k+1) x = \cos x \cdot \cos kx - \sin x \cdot \sin kx = \cos x \cdot B_k (\cos x) + \left( \cos^2 x - 1 \right) A_k (\cos x).$$

由此可见，$A_{k+1} (x) = B_k (x) + x A_k (x)$和$B_{k+1} (x) = x B_k (x) + \left( x^2 - 1 \right) A_k (x)$是第一系数等于多项式$A_k (n)$和$B_k (n)$的第一系数之和的多项式，即第一系数等于$2^{k-1} + 2^{k-1} = 2^k$。引理已得证。

让我们输入$f(x) = \sin \left( x + \frac{\pi}{n} \right) \times \cdots \times \sin \left( x + \frac{\pi (n-1)}{n} \right)$。 Struppirum 成对项的形式为 $\sin \left( x + \frac{\pi i}{n} \right)$ 和 $$\sin \left( x + \frac{\pi (n-i)}{n} \right),$$，其中 $0 < i < \frac{n}{2}$。

如果 $n$ 是偶数，那么乘积仍然有项

$$\sin \left( x + \frac{\pi \frac{n}{2}}{n} \right) = \sin \left( x + \frac{\pi}{2} \right) = \cos x.$$

让我们转换成对的乘积：

$$\sin \left( x + \frac{\pi i}{n} \right) \cdot \sin \left( x + \frac{\pi (n-i)}{n} \right) = \frac{1}{2} \left( -\cos (2x + \pi) + \cos \left( \frac{2\pi i}{n} - \pi \right) \right) = \frac{1}{2} \left( \cos 2x - \cos \frac{2\pi i}{n} \right) = \frac{1}{2} \left( 2 \cos^2 x - 1 - \cos \frac{2\pi i}{n} \right) = \cos^2 x - d_i,$$
其中 $d_i$ 是一些常数。

因此，$f(x) = D_n (\cos x)$，其中$D_n (x)$是第一个系数为1的$(n-1)$次非科莫多项式。

我们仍然需要证明$A_n (x) = 2^{n-1} D_n (x)$（特别是，从这里可以得出问题条件下的常数$c_n$等于$\frac{1}{2^{n-1}}$）。

为此，我们使用 $k$ 次多项式最多有 $k$ 个不同根的理论。 （我们将在下面回顾它是如何证明的。）

考虑多项式 $F(x) = A_n(x) - 2^{n-1}D_n(x)$。它的次数小于 $(n-1)$，因为多项式 $A_n(x)$ 和 $2^{n-1}D_n(x)$ 的 $x^{n-1}$ 系数相等。这意味着 $F(x)$ 等同于 0，或者 $F(x)$ 的根小于 $(n-1)$。

考虑点 $x_1 = -\frac{\pi}{n}, x_2 = -\frac{2\pi}{n}, \ldots, x_{n-1} = -\frac{\pi(n-1)}{n}$ 和路径 $t_i = \cos x_i$。显然$f(x_i) = 0$，因此$D_n(t_i) = 0$；另外，$\sin(n \cdot x_i) = 0$、$\sin x_i \neq 0$表示$A_n(\cos x_i) = A_n(t_i) = 0$。请注意，所有点 $t_i$ 都是不同的，因为 cos $x$ 返回线段 $[-\pi, 0]$ 上。

因此，多项式 $F(x)$ 在 $(n-1)$ 点 $t_1, t_2, \ldots, t_{n-1}$ 处消失，因此 $F(x)$ 是同零。因此，$A_n = 2^{n-1}D_n$，即

$$\sin x \cdot \sin \left(x + \frac{\pi}{n}\right) \times \cdots \times \sin \left(x + \frac{\pi(n-1)}{n}\right) = \frac{1}{2^{n-1}} \sin nx.$$

现在让我们回忆一下如何证明$k$次多项式最多有$k$个根。对于 $k = 1$ 来说这是显而易见的。令该陈述对于 $k = l-1$ 成立，并令路径 $P(t) = a_l t^l + a_{l-1} t^{l-1} + \ldots + a_1 t + a_0$ 为$l$ ($a_l \neq 0$) 次多项式。令$\alpha$为多项式$P$的根（如果$P$无根，则一切都被证明）：$P(\alpha) = a_l \alpha^l + \ldots + a_0 = 0$。因此$P(t) = P(t) - P(\alpha) = a_l (t^l - \alpha^l) + a_{l-1} (t^{l-1} - \alpha^{l-1}) + \ldots + a_1 (t - \alpha).$ 很容易检查$t^l - \alpha^l = (t - \alpha)(t^{l-1} + \alpha t^{l-2} + \alpha^2 t^{l-3} + \ldots + \alpha^{i-2} t + \alpha^{i-1}).$ 因此$P(t) = (t - \alpha)[a_l (t^{l-1} + \ldots + \alpha^{l-1}) + a_{l-1} (t^{l-2} + \ldots + \alpha^{l-2}) + \ldots + a_1] = (t - \alpha) H(t)$，其中$H(t)$ 是$l-1$ 次的非八进制多项式。

根据假设，$H(t)$至多有$(l-1)$根。这意味着 $P$ 最多有 $l$ 根（$\alpha$ 和多项式 $H(t)$ 的根）。

我们的说法已被所有$k$证明。

F153
为什么流经平坦、均质土壤的河流会弯曲？
为简单起见，考虑一条沿赤道流动的河流。

河流之所以蜿蜒流动，是因为其直流不稳定。这意味着，如果流动的河流意外形成小弯道或不规则处，例如，由于一棵树落入水中，那么由此产生的河流弯道将会增加。为了弄清楚为什么会发生这种情况，让我们考虑一下。 。 。一杯茶，里面漂浮着茶块。如果你用勺子在玻璃杯中“旋转”茶，使液体旋转，然后将勺子从玻璃杯中取出，那么过了一会儿，所有茶块都会沿着玻璃杯的轴线聚集。这与此有关。

当液体在玻璃杯中旋转时，液体的每一部分都受到周围其他部分的力作用，使得该力与重力的合力水平指向并赋予颗粒向心加速度

$$a = \omega^2 R,$$

其中 $\omega$ 是流体的旋转角速度，$R$ 是零件距旋转轴的距离。距离$R$越大，质点的加速度越大，这意味着其他部分作用在该部分上的力的水平分力应该越大。因此，旋转液体的表面呈抛物线形状。 （回想一下，从其他部分作用在位于表面附近的液体颗粒上的力是垂直于表面的。否则，该力的分力，抛物线到表面，将导致液体颗粒的运动。）由于液体表面的这种形状，在距天相同距离处，液体中的压力随着它接近玻璃堆叠而增加。

当勺子从玻璃杯中取出后，玻璃杯壁和底部的液体粒子的速度由于摩擦而开始降低。在这种情况下，粘液作用在这些颗粒上的加速度大于向心加速度，玻璃中会产生流体流动，如图7所示。由于摩擦，该电流在表面的速度小于其在一定深度的速度。该流动将块带到液体的旋转轴。

类似的循环流影响也发生在河流转弯处 (图 8)。这些沙粒从白天和受扰动的河岸输送到其内岸。因此，环流增加了河流的弯曲度，侵蚀了未受干扰的河岸。此外，侵蚀——对河岸和白天的破坏——在受干扰的河岸附近被证明更为严重。因此，到河流为止，其剖面如图 图 9 所示。
