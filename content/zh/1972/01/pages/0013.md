对于所有变换$T_k$，只有所有根$\{\varepsilon_1, \dots, \varepsilon_{16}\}$的集合是不变的。

最重要的见解是，使根组保持不变的变换次数越多，根组就“越好”。

让我们为$T_k$引入另一种编号$T_{[l]}$，就像对$\varepsilon_k: T_{[l]} = T_k$、$k = 3^l$所做的那样。以新的符号表示

$$T_{[k]}^{\varepsilon_l} = \varepsilon_{[k+l]}, \quad T_{[m]}(T_{[k]}^{\varepsilon_l}) = T_{[m+k]}^{\varepsilon_l}$$

（方括号中的总和必须以 16 为模）。当然，读者会发现与对数过渡的类比，这并不奇怪，因为 $\varepsilon_{[l]} = \varepsilon_{3l}$ 。

问题3.证明如果某个根的集合在某些$T_{[k]}$下不变，其中$k$为奇数，那么这个集合在所有变换$T_{[m]}$下不变，也就是说，如果它不为空，那么它将与所有根的集合重合。

笔记。证明如果 $k$ 是奇数，则存在 $m$，使得 $km$ 除以 16 时余数为 1。

另一方面，在所有$T_{[k]}$下有两组不变的根，具有四个$k$：具有四个$l$的根$\varepsilon_l$和四个$l$。我们用 $\sigma_{2,0}, \sigma_{2,1}$ 表示它们的数量。

很明显 $\sigma_{2,0} + \sigma_{2,1} = -1$。让我们来探索一下 $\sigma_{2,0} \cdot \sigma_{2,1}$。该乘积是两两乘积之和 $\varepsilon_{[k]}^{\varepsilon_l}$， 在哪里 $k$ - 甚至， $l$ -奇数，每个都是一些根 $\varepsilon_m$，总共 64 项。我们将证明其中每个根 $\varepsilon_{[0]}, \varepsilon_{[1]}, \dots, \varepsilon_{[15]}$ 发生相同次数（四次），结果 $\sigma_{2,0} \cdot \sigma_{2,1} = -4$。让我们利用以下事实： $T_{[k]}$ 保留根群时 $k$ 甚至并将它们转换成另一种 $k$  $\sigma_{2,0} \cdot \sigma_{2,1}$ 可以明显地转化为以下形式 $\varepsilon_{[m]}^{\varepsilon_{[m+r]}}$， 在哪里 $0 \leq m \leq 15$, $r = 1, 3, 5, 7$ (prove it!).让我们将相同的术语分组 $r$。流行的总和将是以下形式

$$\varepsilon_{[0]}^{\varepsilon_r} + \varepsilon_{[1]}^{\varepsilon_r} + \varepsilon_{[2]}^{\varepsilon_r} + \dots + \varepsilon_{[15]}^{\varepsilon_r} = T_{[0]}^{\varepsilon_{[0]}^{\varepsilon_r}} + T_{[1]}^{\varepsilon_{[0]}^{\varepsilon_r}} + \dots + T_{[15]}^{\varepsilon_{[0]}^{\varepsilon_r}} = \varepsilon_{[0]} + \dots + \varepsilon_{[15]} = -1,$$

其中$\varepsilon_{[k]} = \varepsilon_{[0]}^{\varepsilon_{[r]}}$。我们将使用$T_{[m]}^{\varepsilon_{[k]}} \cdot T_{[m]}^{\varepsilon_{[l]}} = T_{[m]}(\varepsilon_{[k]}^{\varepsilon_{[l]}})$和已经提到的属性$T_{[m]}$这一事实。

$\sigma_{2,0}, \sigma_{2,1}$的值见附录1。

让我们继续下一步。我们想引入新的、较小的根组，这些根组在某些 $T_{[k]}$ 下保持不变。类比问题3，可以看出，在这种情况下，$k$一定能被4整除。因此，有四组根对于所有$T_{[4l]}$都是不变的，并且比已经考虑的那些都小；让我们写下每组中的根的总和：$\sigma_{4,0}, \sigma_{4,1}, \sigma_{4,2}, \sigma_{4,3}$。我们已经注意到

$$\sigma_{4,0} + \sigma_{4,2} = \sigma_{2,0}; \quad \sigma_{4,1} + \sigma_{4,3} = \sigma_{2,1}.$$

我们来计算乘积$\sigma_{4,0} \cdot \sigma_{4,2}$；它表示为 $\varepsilon_{[4k]}^{\varepsilon_{[4l+2]}}$ 形式的 16 项之和，该项唯一地写为 $\varepsilon_{[2m]}^{\varepsilon_{[2m+2r]}}, r = 1, 3, m = 0, 1, 2, 3, 4, 5, 6, 7$ 形式。

让我们用一个 $r$ 将这些项分组并替换 $\varepsilon_{[0]}^{\varepsilon_{[2]}} = \varepsilon_{1} \varepsilon_{9} = \varepsilon_{10} = \varepsilon_{3}, \varepsilon_{[0]}^{\varepsilon_{6}} = \varepsilon_{1} \varepsilon_{15} = \varepsilon_{16} = \varepsilon_{8}$。对于$r = 1$，我们得到总和

$$T_{[0]}^{\varepsilon_{[3]}} + T_{[2]}^{\varepsilon_{[3]}} + \dots + T_{[14]}^{\varepsilon_{[3]}} = \sigma_{2,1};$$

在 $r = 3$ — 总和

$$\sum_{k} T_{[2k]}^{\varepsilon_{[8]}} = \sigma_{2,0},$$

即$\sigma_{4,0} \cdot \sigma_{4,2} = \sigma_{2,0} + \sigma_{2,1} = -1$。通过解二次方程，我们找到$\sigma_{4,0}, \sigma_{4,2}$。

在最后一步中，我们将考虑在 $T_{[8]}$ 下不变的根组；我们将使用它们$\varepsilon_{[0]}^{\varepsilon_{[r+1]}} + \varepsilon_{[1]}^{\varepsilon_{[r+1]}} + \varepsilon_{[2]}^{\varepsilon_{[r+1]}} + \dots + \varepsilon_{[15]}^{\varepsilon_{[r+1]}} = T_{[0]}^{\varepsilon_{[0]}^{\varepsilon_{[r+1]}}} + T_{[1]}^{\varepsilon_{[0]}^{\varepsilon_{[r+1]}}} + \dots + T_{[15]}^{\varepsilon_{[0]}^{\varepsilon_{[r+1]}}} = \varepsilon_{[0]} + \dots + \varepsilon_{[15]} = -1$。这使我们能够找到$\sigma_{8,0} = 2 \cos \frac{2\pi}{17}$，从而完成解决方案。
