⟦folio 60⟧

入学考试的选择
1971 年数学

莫斯科国立大学
以 M.V. 命名罗蒙诺索夫

力学与数学学院

1. 解方程：
$$x^2 \log_3(x^2) - (2x^2 + 3) \log_9(2x + 3) = 3 \log_3\left(\frac{x}{2x + 3}\right).$$
2. 从线段 $0 \leq x \leq \pi$ 中找到满足不等式的所有 $x$
$$\sin 2x + \sin x - \sqrt{2} \cos x < \frac{1}{\sqrt{2}}.$$
3. 四棱锥的侧面是相等的等边三角形，棱锥的底部有一个菱形，其中一条对角线的长度是另一条对角线的两倍。如果已知侧面面积为6，且中间侧边有两条边形成钝角，求金字塔的体积$V$。
4. 找到不等式系统中$\alpha$的所有值
$$\begin{cases} x^2 + 4x + 3 \leq \alpha, \\ x^2 - 2x \leq 3 - 6\alpha \end{cases}$$
有独特的解决方案。
5. 可以在内接四边形 $ABCD$ 内切一个圆，并可以围绕它画一个圆。对角线$AC$将四边形的面积分成两半。如果内切圆的半径为$r$，四边形的周长为$p$，求对角线$BD$的长度。

语言学院结构与应用语言学系

1. 四名语言学家（各自独立）从事数学文本处理。它们中的每一个都具有恒定的随机性。如果前三个工作一小时，第四个工作两个小时，那么它们总共可以处理 26 页的文本。如果第三个工作两个小时，其余每个工作一个小时，那么将处理 32 页文本。如果第二个工作两个小时，其他每个工作一个小时，那么将处理 40 页文本。如果第一页运行三个小时，第二页运行 5 小时，第三页运行 7 小时，将处理多少页文本？
2. 矩形的长边是$d$。绘制一个圆，圆心位于矩形的一个顶点，半径等于其短边。从矩形中删除与所得圆的公共部分。
长度小于边长的值是多少时，剩余部分的面积最大？
3. 确定不等式有多少个整数解
$$(n^2 - 2)(n^2 - 22)(n^2 - 52)(n^2 - 152) < 0.$$
4. 确定对于任何实数 $x$，不等式 $\log_{a(a+1)}(|x|+4) > 1$ 都适用于哪个 $a$。
5. 复数的平均值 $z$ 找到所有满足以下条件的数
$$\log_2(1 + |z^2 - i|) + \log_{16}\frac{1}{(1 + |z^2 + i|)^4} = 0.$$
6. 探索并求解方程组：
$$\begin{cases} x^7y^{31} = a, \\ x^2y^9 = b. \end{cases}$$
7. 证明如果$p$和$q$是整数，且$p^2 - 7q^2 = 2pq$，则$p=q=0$。
