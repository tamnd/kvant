⟦folio 24⟧

下面 O. Anderson 教授给出了研究样本中声音传播速度 $v_{3B}$（公里/秒）：

| 月球岩石和奶酪 | 声速$v_{3B}$（公里/秒） |
| :--- | :--- |
| 月球岩石样本 10 017 | 1,84 |
| 挪威奶酪 | 1,83 |
| 意大利奶酪 | 1,75 |
| 意大利奶酪（Primsky） | 1,75 |
| 佛蒙特奶酪 | 1,72 |
| 瑞士奶酪 | 1,65 |
| 威斯康星奶酪 | 1,57 |
| 月球岩石样本 10,046 | 1,25 |

从表中可以看出，对于该物理参数，奶酪的指标与月球岩石样品的指标一致。因此，我们可以假设奶酪是月球土壤的陆地类似物。不幸的是，从上表中尚不清楚哪种类型的奶酪发挥了这一作用。然而，这个谜题是有可能解开的。

包裹被扔到月球上后，月球土壤的地震振动不像所有规则所预期的那样在几秒钟内消失，而是在十分钟内消失。我认为这可能是由于某些单宁空洞的存在造成的，但其来源尚不清楚。但奶酪（至少在某些品种中）一定有洞！重新计算到合适的大小，无法理解的效果就会得到充分的解释。而且。由于最大的洞是在瑞士奶酪中发现的，所以奶酪类型的问题终于解决了。

所以，月球不是由铸铁制成的，而是由瑞士奶酪制成的。因此，科学家的建议是——仔细审查所有民间传说和所有儿童的计算。最好将其委托给计算机。

M.A.科雷茨，
