⟦folio 22⟧

我们得到的骰子

$$\bar{f}_a(x, y) \leq \frac{1}{a+2}.$$

在问题的$a=1$（第6点））

$$\bar{f}_1(x, y) \leq \frac{1}{3}.$$

在这种情况下

$$\cos \varphi = \frac{1}{2} \text{ и } \varphi = 60^\circ,$$

因此，红色网格由 $\frac{\sqrt{3}}{3}$ 边上的正六边形组成，并且等式

$$\bar{f}_1(x, y) = \frac{1}{3}$$

是在这些六边形的顶点处实现的，其坐标由以下两个公式给出：

$$\left( \frac{1}{3} + m, \frac{1}{3} + n \right),$$

$$\left( -\frac{1}{3} + m, -\frac{1}{3} + n \right),$$

其中$m$和$n$是任意整数。

有了$a=0$和$a=2$，问题就大大简化了。

图 7.

确实，$f_0(x, y) = x^2 + y^2$。我们所有的参数保持不变（我们可以假设 $\varphi = \frac{\pi}{2}$ 并且坐标系 $Oxy$ 结果是矩形（参见 图 7）），只有与六边形一起我们才能得到正方形和估计值 $\bar{f}_0(x, y) \leq \frac{1}{2}$。 $a=2$的情况，当$f_2(x, y) = (x+y)^2$时，需要单独分析，这里$\bar{f}_2(x, y)$等于数字$x+y$与最接近的整数之差的平方，所以$\bar{f}_2(x, y)$的最大值等于$\frac{1}{4}$。

因此，估计 (*) $\bar{f}_a(x, y) \leq \frac{1}{a+2}$ 对于 $a=0, a=2$ 也成立。

仍有待考虑$a>2$的情况。让我们证明，对于每个点 $(x, y)$ ，最小数 $f_a(x-m, y-n)$ 都不存在。

事实上，令$a=2+\varepsilon$，其中$\varepsilon>0$。让我们固定点 $(x, y)$ 并考虑 $f_{2+\varepsilon}(x-k, y+k)$，其中 $k$ 是某个整数：

$$f_{2+\varepsilon}(x-k, y+k) = (x-k)^2 + 2(x-k)(y+k) + (y+k)^2 + \varepsilon(x-k)(y+k) - \varepsilon k^2 + \varepsilon(x-y)k + (x+y)^2 + \varepsilon xy.$$

我们得到了关于$k$的二次三项式，其第一个系数小于零。因此，随着$k$趋向于$+\infty$，这个量将趋向于$-\infty$，也就是说，它可以小于任何负数。因此，$\bar{f}_a(x, y)$ 在$a>2$ 处未定义。

问题条件下对$a$更自然的约束不是$a \geq 0$，而是$-2 \leq a \leq 2$。

对于负 $a(-2 < a < 0)$，解将不做任何改变地转移：我们遵循 $a=2$ cos $\varphi$ 并取角度 $\frac{\pi}{2} < \varphi < \pi$。

由于在这种情况下获得的筛法与角度 $\psi = \pi-\varphi$ 相同，因此我们也获得与锐角相同的估计，即 $\bar{f}_a(x, y) \leq \frac{1}{2+|a|}$。
