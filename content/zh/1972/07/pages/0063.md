将$\sin^2 x$通过$1 - \cos^2 x$表示，我们得到一组方程：1) $\cos x + 1 = 0$, 2) $\cos x = \frac{1}{2}$。从解中，我们仅选择包含在原方程 ODZ 中的解，即 $x = \frac{\pi}{3} + 2\pi n$。
扫地。若将$2\sin^2 x$替换为$1 - \cos 2x$，可得方程$\cos x = -\cos 2x$，由此可得$x_1 = \pi + 2\pi n$、$x_2 = \frac{\pi}{3} + \frac{2}{3} \pi n$； $\sin x_1 = 0$ 因此 $x_1$ 不包含在 ODZ 中，并且根据系列 $\frac{\pi}{3} + \frac{2}{3} \pi n$ 的解，有必要显示那些包含在 ODZ 中的内容。为此，我们将级数 $\frac{\pi}{3} + \frac{2}{3} \pi n$ 分为 3 个，正如我们所说的，基本级数：
$x_1 = \frac{\pi}{3} + 2\pi n; x_2 = -\frac{\pi}{3} + 2\pi n; x_3 = \pi + 2\pi n,$，其中只有$\frac{\pi}{3} + 2\pi n$包含在ODZ中。
