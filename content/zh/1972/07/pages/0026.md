物体同时参与两个相互垂直的振荡时的轨迹由控制系统描述

$$x = A_1 \sin (\omega_1 t + \varphi_1),$$
$$y = A_2 \sin (\omega_2 t + \varphi_2),$$

其中$x$和$y$是身体位移在$X$和$Y$轴上的投影。

为了简单起见，我们假设$\varphi_1 = \varphi_2 = 0$和$\omega_1 = \omega_2 = \omega$。然后

$$x = A_1 \sin \omega t,$$
$$y = A_2 \sin \omega t.$$

这意味着$y = \frac{A_2}{A_1} x$；因此，对应关系(2)描述了一条直线段。与轴 $X$ 的倾斜角度 $\alpha$ 由以下方程给出

$$tg \alpha = \frac{A_2}{A_1}.$$

现在让$\varphi_1 = \varphi_1' + \frac{3\pi}{2}$。然后

$$x = A_1 \cos (\omega_1 t + \varphi_1'),$$
$$y = A_2 \sin (\omega_2 t + \varphi_2).$$

我们先分析最简单的情况，当$A_1 = A_2$、$\varphi_1' = \varphi_2 = 0$、$\omega_1 = \omega_2 = \omega$时，即

$$x = A \cos \omega t,$$
$$y = A \sin \omega t.$$

由该方程定义的坐标为 $x$ 和 $y$ 的点描述了半径为 $A$ 的圆。确实，$x^2 + y^2 = A^2 \cos^2 = \omega t + A^2 \sin^2 \omega t = A^2$。这意味着运动轨迹是一个圆。
