解决方案。这个问题可以使用平面测量来解决，但是我们忠于主题，将使用三角学来分析这个问题的解决方案（我们建议读者尝试找到平面测量的解决方案）。让我们用 $\alpha$ 表示三角形的一个角，$2\alpha$ 表示另一个角，以及对边分别表示 $x$ 和 $x+2$ (图 8)。

根据正弦定理$\frac{x}{\sin \alpha} =$
$$\frac{5}{\sin(180^\circ - 3\alpha)} = \frac{x+2}{\sin 2a};$$ 从这里$x = \frac{5\sin \alpha}{\sin 3\alpha},$
$x+2 = \frac{5\sin 2\alpha}{\sin 3\alpha}$.

Teler 问题简化为求解三角方程 $\frac{5\sin 2\alpha}{\sin 3\alpha} - \frac{5\sin \alpha}{\sin 3\alpha} = 2$。应用公式$\sin 3\alpha = 3\sin \alpha - 4\sin^3\alpha$，我们得到$\frac{10\cos \alpha}{3-4\sin^2\alpha} - \frac{5}{3-4\sin^2\alpha} = 2$，进一步得到$8\cos^2\alpha - 10\cos \alpha + 3 = 0; \quad (\cos \alpha)_1 = \frac{3}{4},$
$(\cos \alpha)_2 = \frac{1}{2}$。但根据问题的意思，$\alpha < 60^\circ$，因此，$\cos \alpha > \frac{1}{2}$。因此，从查到的值来看，$\cos \alpha = \frac{3}{4}$是合适的。

我们还有$\sin \alpha = \sqrt{1-\cos^2\alpha} = \frac{\sqrt{7}}{4}, \quad x = \frac{5}{3-4\sin^2\alpha} = 4, \quad x+2 = 6$。

练习

1. 在三角形$ABC$中，角$A$等于$\alpha$，边$BC$等于$\alpha$。如果 $AD$ 和高度 $AE$ 之间的角度为 $\beta$，求平分线 $AD$ 的长度。

2. 直线的底是等边梯形，其锐角等于$\alpha$，面积等于$S$。所有侧面均与基面倾斜$\beta$角度。求直线的体积。

3. 圆锥体的母线等于$l$，并与高度成$\alpha$角。通过圆锥的两条母线绘制一个平面，两条母线之间的角度等于 $\beta$。求从该平面到圆锥内切球中心的距离。

4. 三角形的高等于$6\text{ cm}$，将三角形的角按$2:1$的比例划分，并将边分成几部分，其中较小的部分等于$3\text{ cm}$。确定三角形的边。

5. 一个正三角形 $ABC$ 内接于一个圆。在弧 $BC$ 上取任意点 $M$ 并通过弦连接到三角形的顶点。证明$MA = MB + MC$。

6. 证明梯形对角线的平方和等于其底边与各边平方和的乘积的两倍。

7. 三角形的平面角等于三角形的对应角。

8. 给定一个三角形$ABC$，在$AC$边上取一个点$E$，以便$AE:EC = a$，在$AB$边上取一个点$D$，以便$AD:DB = b$。进行了$CD$和$BE$段。求所得四边形的面积与给定三角形面积的比率（MIET，1970）。

9. 两个相互垂直的直径$AB$和$CD$画成一个圆。弦 $AE$ 与 $CD$ 相交于点 $K$，使得 $CK:KD = 2:1$。弦 $EC$ 与 $AB$ 相交于点 $M$。证明 $AM:MB = 3:1$ (图 9)。
