在 1972 年的«Kvant» No. 1 中，我们已经讨论过使用最简单的物理设备之一 - 磁铁 *) 进行的实验。在本文中，我们将讨论更多可以在家进行的实验。

物体的简单振动是物体与平衡位置的偏差$x$按规律变化的振动

$$x = a \sin(\omega t + \varphi),$$

其中 $a$ 是振幅，$\omega$ 是频率，$\varphi$ 是振荡的初始相位。

这种振动称为谐波。谐波振动是由数学摆、弹簧上的重物、电路中的方向来执行的。

在本文中，我们将考虑物体同时参与两个简谐振动的情况。如果两个振荡都沿一条直线发生，则物体的运动方程将由两个运动方程之和表示：

$$x = A_1 \sin(\omega_1 t + \varphi_1) + A_2 \sin(\omega_2 t + \varphi_2).$$

绘制物体相对于平衡位置的位移随时间变化的图表并不困难。为此，您需要添加与第一次和第二次运动相对应的曲线坐标。 图 1 显示了两个谐波振荡（黑色正弦曲线）相加的示例。红线对应于突破摆动的结果。它不再和谐。

通过在两个相互重新分布的方向上添加振荡可以获得更复杂的轨迹。这种振荡的一个例子是物体的运动，如图2所示。在这种情况下，轨迹的类型取决于相互重新分配振荡的频率、幅度和相位的对应关系。这些轨迹被称为利萨如图形，以法国物理学家利萨如的名字命名，他于 1863 年首次描述了它们。利萨如使用的设置

物体同时参与两个相互垂直的振荡时的轨迹由控制系统描述

$$x = A_1 \sin (\omega_1 t + \varphi_1),$$
$$y = A_2 \sin (\omega_2 t + \varphi_2),$$

其中$x$和$y$是身体位移在$X$和$Y$轴上的投影。

为了简单起见，我们假设$\varphi_1 = \varphi_2 = 0$和$\omega_1 = \omega_2 = \omega$。然后

$$x = A_1 \sin \omega t,$$
$$y = A_2 \sin \omega t.$$

这意味着$y = \frac{A_2}{A_1} x$；因此，对应关系(2)描述了一条直线段。与轴 $X$ 的倾斜角度 $\alpha$ 由以下方程给出

$$tg \alpha = \frac{A_2}{A_1}.$$

现在让$\varphi_1 = \varphi_1' + \frac{3\pi}{2}$。然后

$$x = A_1 \cos (\omega_1 t + \varphi_1'),$$
$$y = A_2 \sin (\omega_2 t + \varphi_2).$$

我们先分析最简单的情况，当$A_1 = A_2$、$\varphi_1' = \varphi_2 = 0$、$\omega_1 = \omega_2 = \omega$时，即

$$x = A \cos \omega t,$$
$$y = A \sin \omega t.$$

由该方程定义的坐标为 $x$ 和 $y$ 的点描述了半径为 $A$ 的圆。确实，$x^2 + y^2 = A^2 \cos^2 = \omega t + A^2 \sin^2 \omega t = A^2$。这意味着运动轨迹是一个圆。

在什么情况下我们会得到未关闭的数字？能找到一般模式吗？让我们考虑以下形式的方程
$$x = A_1 \cos p\omega t,$$
$$y = A_2 \sin q\omega t.$$

首先，我们注意到，在曲线沿同一轨迹折回的点处，物体沿 $X$ 和 $Y$ 轴的速度同时变为零。毕竟，正是在这种情况下，沿着曲线惊叹的身体停下来，然后开始向后惊叹。若$x = A_1 \cos p\omega t$，则
$$v_x = \frac{A_1 \cos p\omega t_2 - A_1 \cos p\omega t_1}{t_2 - t_1} =$$
$$-2A_1 \sin \frac{p\omega t_2 + p\omega t_1}{2} \sin \frac{p\omega t_2 - p\omega t_1}{2} = \frac{t_2 - t_1}{t_2 - t_1}.$$

当$t_2 \approx t_1 = t$（$t_2 - t_1$差值较小）时，$\sin \frac{p\omega t_2 - p\omega t_1}{2} \approx \frac{p\omega t_2 - p\omega t_1}{2}$。

因此
$$v_x = -A_1 p\omega \sin p\omega t.$$
类似地，对于 $v_y$ 我们得到
$$v_y = A_2 q\omega \cos q\omega t.$$

让我们看看速度 $v_x$ 和 $v_y$ 何时变为零。
$$v_x = 0, \text{ если } p\omega t = k\pi,$$
$$v_y = 0, \text{ если } q\omega t = \frac{\pi}{2} + m\pi.$$

从这些条件可以清楚地看出，利萨如图形并不是封闭的

可以在示波器屏幕上观察到李萨如图案。在垂直扫描上，应用一种简谐振动，在水平扫描上，应用另一种简谐振动。它们的总和可以采取多种形式。为此，改变示波器板上交流电压的频率就足够了。

你们每个人都可以制作自己的非常简单的设备来观察和拍摄利萨如图形。取一把普通金属尺，将其弯曲，使尺子的一半平面与另一半平面不同（参见图9）。

将尺子的一端放在虎钳中。如果你现在摆动尺子的自由端，它会在空中描绘出复杂的图形。这些将是利萨如图形。

标尺自由端的运动由标尺两部分的独立振动组成。然而 - 从虎钳到弯曲，第二个 - 从弯曲到末端。尺子可变平面各部分在此段上的振动。由于尺子的偏转角度为$\frac{\pi}{2}$，因此振动是相互交替的。尺子末端的轨迹类型取决于尺子的长度和宽度以及弯曲的位置。

您可以使用同一把尺子来获得不同的形状。要改变垂直和水平振动之间的对应关系，只需将尺子夹在虎钳的不同位置即可。

由于振动频率取决于尺子的长度，因此通过改变尺子各部分长度之间的对应关系，您将改变尺子末端相互交替振动的频率之间的对应关系。在这种情况下，您将得到标尺末端的不同轨迹。

要形成接收图形，您需要将一个小手电筒灯泡连接到自由端。灯泡通过沿着标尺 (图 9) 延伸的电线连接到电池。通过将复杂的磁铁放置在暗室中，我们可以在尺子中产生振荡。曝光时间要足够长。您可以通过使用不同曝光进行多次实验来确定它。
