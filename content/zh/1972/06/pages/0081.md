2. 带电球的能量为$\Pi = \frac{c\varphi^2}{2} = \frac{R\varphi^2}{2}$（C 为容量，R 为球的半径）。在放电期间，该能量以物体的形式释放。用卡路里来表示能量，我们得到： $\Pi \approx 0,13$ cal。

3. 当壳层半径增加少量$\Delta x$时，电子力做功$\Delta A = 4\pi R^2 f \Delta x$，其中$f$是单位面积的力。由于电子能量的损失而完成了功：

$$\frac{Q^2}{2R} - \frac{Q^2}{2(R + \Delta x)} = \frac{Q^2 \Delta x}{2R(R + \Delta x)}.$$

根据能量守恒定律：$4\pi R^2 f \Delta x = \frac{Q^2 \Delta x}{2R(R + \Delta x)}$。考虑到$\Delta x \ll R$，我们得到$f = \frac{Q^2}{8\pi R^4} = 2\pi \sigma^2$，其中$\sigma = \frac{Q}{4\pi R^2}$是表面电荷密度。

4. 液滴的电势为 $\varphi_1 = \frac{q}{r}$，其中 $q$ 是电荷，$r$ 是液滴的半径。大跌幅的可能性是$\varphi = \frac{Nq}{R} = \frac{N\varphi_1 r}{R}$。显然$\frac{4\pi}{3} r^3 N = \frac{4\pi}{3} R^3$。因此$\frac{r}{R} = \frac{1}{\sqrt{N}}$和$\varphi = \frac{N\varphi_1}{\sqrt{N}} = N^{2/3}\varphi_1$。

5. $A = q_2 (\varphi_2 - \varphi_1) = q_1 q_2 \left( \frac{1}{R_2} - \frac{1}{R_1} \right) = 25$ 尔格。
