让我们考虑一下差异
$$f_1(x) - f_2(x) = f_3(x).$$
(1)

注意$p_1 - p_2 \neq 0$，因为如果$p_1 - p_2 = 0$，则$R = (q_1 - q_2)^2 \geq 0$，这与条件相矛盾。因此，方程$f_3(x) = 0$有根$\gamma = -\frac{q_1 - q_2}{p_1 - p_2}$，当然，$f_3(x)$可以写成如下：
$$f_3(x) = (p_1 - p_2)(x - \gamma).$$
(2)

此外，由(1)可知，
$$f_1(\gamma) = f_2(\gamma).$$
(3)

现在平方三项式$f_2(x)$（乘以系数$(p_1 - p_2)^2$“除以余数”再乘以$f_3(x)$，即我们写下恒等式
$$(p_1 - p_2)^2 f_2(x) = f_3(x) g(x) + R.$$

我们使用相同的字母$R$并非偶然：余数等于问题条件中给出的表达式$R$的名称。真的吗，
$$(p_1 - p_2)^2 (x^2 + p_2x + q_2) = [(p_1 - p_2)x + (q_1 - q_2)][(p_1 - p_2)x + (p_1 - p_2)p_2 - (q_1 - q_2)] + (q_1 - q_2)^2 + (p_1 - p_2)(p_1q_2 - p_2q_1).$$

将$\gamma$代入式(4)，可得（考虑$f_3(\gamma) = 0$）：
$$(p_1 - p_2)^2 f_2(\gamma) = R < 0.$$

波兹尼$f_1(\gamma) = f_2(\gamma) < 0$。因此（根据性质（1））两个方程都有两个实根。让我们用$\alpha_1, \beta_1$和$\alpha_2, \beta_2$表示它们的对应关系。然后
$$f_2(x) = (x - \alpha_2)(x - \beta_2).$$
(6)

现在，依次使用（1）、（2）、（6）和（5），我们得到：
$$f_1(\alpha_2) f_1(\beta_2) = f_3(\alpha_2) f_3(\beta_2) = (p_1 - p_2)^2 (\alpha_2 - \gamma)(\beta_2 - \gamma) = (p_1 - p_2)^2 f_2(\gamma) = R < 0,$$
(7)

由此可见（根据性质（2））方程的根相交。

使用图表，问题的结果和我们解决方案中的主要对应关系（5）可以用两个词来解释（图2）。我们的解决方案的代数背景更深。

从我们的解和 图 2 可以看出，当二次三项式 $f_1$ 和 $f_2$ 有共同根（或重合）时，$R = 0$ 模型是相似的。这种诽谤可以用在此类问题中：数字$\lambda$和$\mu$必须满足什么条件才能使方程$x^2 + \lambda x - 1 = 0$和$x^2 + \mu x - \lambda x + \mu = 0$有根？将值$p_1 = \lambda$、$q_1 = -1$、$p_2 = \mu - \lambda$、$q_2 = \mu$代入表达式$R$即可，所需条件已就绪：
$$(\mu + 1)^2 + (2\lambda - \mu)(\mu - \lambda + \mu\lambda) = 0.$$

事实证明，对于两个任意次数的多项式
$$f_1(x) = a_1x^n + b_1x^{n-1} + \dots + c_1,$$
$$f_2(x) = a_2x^m + b_2x^{m-1} + \dots + c_2$$

可以在 $a_1, a_2, b_1, b_2, \dots, c_1, c_2$ 中写出一个多项式 $R$，使得当 $f_1$ 和 $f_2$ 具有公约数时满足条件 $R = 0$（$x$ 中的 1 次或更高次数的多项式）。 $R$称为多项式$f_1$和$f_2$的结果。

在高等代数课程中，结果的紧凑表示以由系数 $f_1$ 和 $f_2$ 组成的“行列式”的形式给出。

当 $f_1$ 和 $f_2$ 分解为线性因子时，结果的概念变得特​​别任意：
$$f_1 = a_1(x - \alpha_1)(x - \beta_1) \dots (x - \gamma_1),$$
$$f_2 = a_2(x - \alpha_2)(x - \beta_2) \dots (x - \gamma_2)$$
