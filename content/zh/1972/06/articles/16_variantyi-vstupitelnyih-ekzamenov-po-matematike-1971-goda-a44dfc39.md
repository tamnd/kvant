⟦folio 51⟧

莫斯科国立大学以 M.V. 命名罗蒙诺索夫

物理学院

1. 解方程：
$$3tg x (7 + \cos 2x) = 2 (\cos 2x - 1).$$
2. 解决不平等问题
$$\log_3^2 x + 2 \log_9 (x^2) < 2.$$
3. 一辆汽车从 A 点行驶到 C 点。从 A 点到 B 点（位于 A 和 C 之间），行驶速度为 48 公里/小时。在 B 点，他将速度降低 1 公里/小时 (0 < a < 48)，并以此速度从 B 到 C 行驶了三分之一的路程。从 B 到 C 的其余路程，他以比初始速度 48 公里/小时高 2a 公里/小时的速度行驶。当 a 值为多少时，自动最快的路径会从 B 移动到 C？
4. 一个球体内接于一个以 S 为顶点、以 ABCD 为底的正四边形矩形。底边等于a，边等于$\frac{a \sqrt{5}}{2}$。在 DSC 面的小角 SE 上，取点 M，使得 SM = ME。求直线 AM 与内接于矩形球体的两点之间的距离。
5. 五边形ABCDE内接于一个圆。点M、Q、N和P是从顶点E垂下的垂线的底，对应于边AB、BC、CD（或其延伸）和对角线AD。已知EP=d，三角形MQE的面积与三角形PNE的面积之比等于k。求线段 EM 的长度。

心理学学院

1. 不使用表格进行计算
$$\frac{\log_2 24}{\log_9 2} - \frac{\log_2 192}{\log_{12} 2}.$$
2. 给定一个立方体，其底面为 ABCD，侧边为 AA'、BB'、CC'、DD'。在相应线段 AM 和 B'N 的边 AB 和 BB' 的延续上，长度 AM = $\frac{1}{2}$ AB 且 B'N = 2B'B ($BM = \frac{3}{2} AB; BN = 3BB'$)。我们必须在边 CC' 上的什么位置选择点 P，以便通过点 M、N 和 P 绘制的平面所截得的立方体的截面是四边形？
3. 查找 x 的所有值，其中
$$\min \left\{ 1 - x^2, \frac{1-x}{2} \right\} > \frac{1}{2}.$$
4. 一个工人生产了一定数量的 A 和 B 类零件，并且他生产的 A 件比 B 件多。如果他生产 A 件的 2 倍，那么零件总数将小于 32 个，如果他生产 B 件的 2 倍，那么零件总数将大于 28 个。A 生产了多少个零件，B 生产了多少个零件？

5. 方程对于 a 的取值
$$\sin^2 3x - \left(a + \frac{1}{2}\right) \sin 3x + \frac{a}{2} = 0$$
恰好有三个根位于线段 $\frac{2\pi}{3} \leq x \leq \pi$ 上？

莫斯科铁路运输工程师学院

专业：
工业与土木工程、交通实例、交通经济学、铁路建设

1. 挖掘机必须在规定时间内（不超过一个月）挖出一个容积为12万立方米的坑。如果他每天多清除 100 立方米的土壤，完成所有工作将比按计划挖$1/3$坑所需的时间多花 14 天。挖这个坑花了多长时间？

2. 解方程
$$\frac{24}{x^2 + 2x - 8} - \frac{15}{x^2 + 2x - 3} = 2.$$
3. 圆的弦长是10厘米。通过弦的一端绘制圆的切线，通过另一端绘制平行于切线的割线。如果割线的内线段是 12 厘米，请确定圆的半径。
4. 证明准确性
$$4 \cos \left(\frac{\pi}{6} - \alpha\right) \sin \left(\frac{\pi}{3} - \alpha\right) = \frac{\sin 3\alpha}{\sin \alpha}.$$

⟦folio 52⟧

专业：自动化、远程机械和通信、交通电气化、桥梁和隧道

1. 两个人必须做一些工作。一开始，第一个工作了2个小时，然后第二个加入了，他们一起工作了1个小时。之后，第二个人在3个小时内完成了剩下的工作。如果第一个完成工作比第二个少 2 小时，那么每个人能完成整个工作需要多长时间？

2. 解决系统

$$\begin{cases} x^2 + y^2 = 4 + \frac{y}{2}, \\ \log_3 (x + 2y) + \log_3 (x - 2y) = 1. \end{cases}$$

3. 一个圆内接于一个边长为 20 厘米的菱形。如果菱形的一条对角线比另一条对角线大 $\frac{4}{3}$ 倍，求圆的面积。

4. 解方程

$$\sin^4 x + \cos^4 x - 2 \sin 2x - \frac{3}{4} \sin^2 2x = 0.$$

专业：应用数学、自动化控制系统、电子计算机

1. 三个国营农场并不位于同一条直线上。从第一个到第三个到第二个的距离是它们之间路径长度的四倍。 a 上从第一个到第二个到第三个的距离就是直线路径的长度。从第二个到第三个经过第一个的距离是185公里。指定的国有农场位置在 a 值的范围内是可能的？

2. 解方程

$$1 - 2x - x^2 = tg^2 (x + y) + ctg^2 (x + y).$$

3. 直立平行六面体的对角线等于 d，并与底面形成角度 α，与侧面之一形成角度 β。确定平行六面体的体积。

4. 解方程

$$\sqrt{1 - 2 \sin 4x} + \sqrt{6} \cos 2x = 0.$$

乌拉尔国立大学

Matematiko机械学院

1. 数字 1 + $\sqrt{2}$ 是方程的根

$$x^3 + ax^2 + bx + 2 = 0.$$

求方程的系数 a、b 及其所有根，前提是 a 和 b 是有理数。

2. 三角形AOB在其平面内绕点O旋转90°，顶点A移动到顶点A1，B移动到B1。证明在三角形OAB1中，到边AB1的中线垂直于A1B，在三角形OA1B中，到边A1B的中线垂直于AB1。

3. 在 x 和 y 为多少时不等式发生？

$$\log_3 x + \log_3 3 + 2 \cos y \leq 0?$$

4. 找出系统的所有参数a和b的值

$$\begin{cases} x + y = a, \\ \lg x + \lg y + \lg x \lg y = b \end{cases}$$

有一个解决方案。

5. 解方程

$$\log_3 x + \log_3 3 + 2 \cos y \leq 0?$$

6. 找出系统的所有参数a和b的值

$$\begin{cases} x + y = a, \\ \lg x + \lg y + \lg x \lg y = b \end{cases}$$

有一个解决方案。

7. 在环城铁路上，从 A1 点出发，沿着 A2、A3、...、An 路线行驶，然后再沿 A1、A2、A3、...、An 路线行驶，依此类推。已知相邻点之间的每个后续阶段将以比前一阶段的平均速度大 q 倍的平均速度行驶。确定完成 m 个整圈所需的时间比第一个圈所花费的时间长多少倍。

8. 通过位于半径为 r 的圆内的点 M，绘制直径 AB 和弦 CD，使得 $\Rightarrow BMD = \alpha$，$\Rightarrow BDM = \beta$。求三角形MBD的面积。

3. 解决不等式：

$$\log_3 (x^3 + 1) \log (x + 1) x > 2.$$

4. 方程对于 a 的取值

$$\frac{\sin x - 1}{\sin x - 2} + a = \frac{2 - \sin x}{3 - \sin x}$$

有解决办法吗？寻找解决方案。

莫斯科工程物理学院

选项1

1. 一个两位数除以各位数字之和，结果是商 4 余 3。如果这个数字除以各位数字的乘积，结果是商 3 余 5。求这个数。

2. 在以a和b为底的梯形中，通过对角线的交点画一条与底平行的直线。求该直线被梯形各边截断的线段的长度。

3. 解决不平等问题

$$\sqrt{x} + \sqrt{x + 7} + 2 \sqrt{x^2 + 7x} < 35 - 2x.$$

4. 解方程

$$\cos (\pi \sqrt{x - 4}) \cos (\pi \sqrt{x}) = 1.$$
