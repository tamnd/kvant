解决静电问题（潜力）

G.雅.米亚基舍夫

电势或电势差的概念给静电学课程带来了主要困难。

静电力的功等于势能的变化，但符号相反：

$$\Delta A = -(\Pi_2 - \Pi_1) = -\Delta \Pi,$$

其中$\Pi_1$和$\Pi_2$是初始和最终能量值。由于功与力成正比，而力又与场作用的电荷$q$成正比，因此场中电荷的能量为$\Pi \sim q$。因此，比率$\frac{\Pi}{q}$不依赖于电荷，可以视为场的特征。这种特性称为潜力：

$$\varphi = \frac{\Pi}{q}.$$

由此可见

$$\Delta A = -q(\varphi_2 - \varphi_1).$$

强场到由小段 $\Delta l$ 指定的任意电压的投影与该段两端的电势差相关，公式如下：

$$E_l = -\frac{\Delta \varphi}{\Delta l}.$$

电势差的概念非常复杂，因为功不是通过电势本身来表达，而是通过电势差来表达（公式（2））。因此，向势添加任何常数都不会改变工作量，因此不会改变任何具有物理意义的东西。势能被确定为任意常数，就像势能 *) 一样。

与场强一样，电势的大小取决于静电荷在空间中的分布。特别是，SI 系统中均匀带电无限平面的电势由以下公式确定

$$\varphi = \frac{\sigma}{\varepsilon_0}x + c,$$

其中$\sigma$是表面电荷密度，$x$是到平面的距离，$c$是任意常数。由于平面场电压为$E = \frac{\sigma}{\varepsilon_0}$，式(4)可改写为

$$\varphi = Ex + c.$$

点电荷的电势可以使用库仑定律和电势差公式（2）求得。但这是一项相当艰巨的任务。证明这一点要容易得多，将点电荷的势计算为

*）这很难想象。毕竟，如果我们知道每个点的电势，那么每个点的静电场电压也就确定了。但同时，给定点的势能可以是任何值，因为它被确定在一个常数内。

这里的要点是这样的。一点上的电势可以被认为等于任何值，但是当从给定点移动到另一个点时，无论多近，电势的变化都是确定的，因为电势对坐标$\varphi(x, y, z)$的依赖性是已知的。如果电势在这种偏差下根本没有变化，那么此时它等于零。知道了任意点处电势变化的性质，您总是可以使用公式（3）找到该点处的场电压的大小和电压。

形式

$$\varphi = \frac{q}{r} + c,$$

式中$c$为任意常数，可利用式(2)得到库仑定律。这意味着在学校物理课程中未经证明而给出的公式（6）实际上决定了 SGSE 系统中精确电荷的潜力。

事实上，对于一个非常小的段$\Delta r$，让精确电荷$q_2$混合在另一个精确电荷$q_1$的场中。则根据式(2)和式(6)可得

$$\Delta A = -q_2 \left( \varphi_2 - \varphi_1 \right) = -q_2 q_1 \times \left( \frac{1}{r + \Delta r} - \frac{1}{r} \right) = \frac{q_1 q_2 \Delta r}{r^2 + r \Delta r}.$$

由于$\Delta r$很小，那么$r^2 \gg r \Delta r$和

$$\Delta A = F \Delta r = \frac{q_1 q_2}{r^2} \Delta r.$$

因此，力$F$等于$\frac{q_1 q_2}{r^2}$，这就是库仑定律。这说明式(6)成立。

正如球形对称带电球的方向场与方向精确的电荷重合一样，带电球（球外）的电势也由式（6）确定。在国际单位制中

$$\varphi = \frac{q}{4 \pi \varepsilon_0 \varepsilon r} + c,$$

如果球处于介电常数$\varepsilon$的均匀电介质中。

要解决问题，充分理解基本公式的物理意义就足够了。此外，常常需要使用简单但非常重要的规定：闭合路径上的发电厂场的功为零并且发电厂中的所有导体点具有相同的电势。

任务 3. 彼此相距 $r$ 的两个精确电荷 $q_1$ 和 $q_2$ 相互作用的势能 Π 是多少？

解决方案e.根据电势（1）的定义和电势精确电荷的公式（6），

$$\Pi = \varphi_1 q_2 = \varphi_2 q_1 = \frac{q_1 q_2}{r} + c. \tag{8}$$

任务 4. 半径为 $R$ 的单个导电球携带电荷 $q$。球的能量是多少？

解决方案e.如果将式(7)中的任意常数设为0，则球在空状态下的势能

$$\varphi = \frac{q}{4\pi\varepsilon_0 R}.$$

球的自能并不等于 $\frac{q^2}{4\pi\varepsilon_0 R}$，乍一看似乎如此。

球的能量可以通过计算给球充电$q$所需做的功来求出。我们将通过将电荷从无穷远以相等的小部分向球移动来对球充电。在这种情况下，球的电势将从零线性增加到$\frac{q}{4\pi\varepsilon_0 R}$。平均潜力值$\frac{1}{2} \frac{q}{4\pi\varepsilon_0 R}$。因此，球的能量相等

$$\Pi = \frac{q^2}{8\pi\varepsilon_0 R}. \tag{9}$$

任务 5. 在距确切电荷 $q$ 距离 $d$ 处，有一个半径为 $R$ 的独立球。 $\varphi$球的潜力有多大？

解决方案e.球上所有点的潜力都是相同的。因此，要解决问题，找到球上某一点的潜力就足够了。最简单的方法就是找到球中心的潜力。它等于精确电荷 $q$ 在球中心产生的电势：

$$\varphi = \frac{q}{d} + \sum_i \frac{\Delta q_1}{r} = \frac{q}{d} + \frac{1}{r} \sum_i \Delta q_1 = \frac{q}{d}.$$

任务 6. 在半径为$r$、带有电荷$+Q$的空心导电球内，通过小孔引入带有电荷$-q$的物体。距球心 $R > r$ 处的点的电势是多少。

解决方案e.首先，我们将电荷$-q$放置在球体的中心。该电荷在外表面感应出电荷$-q$，在内表面上感应出电荷$+q$，且电荷分布均匀。距离 $R$ 处的点的电势等于 $\varphi_R = \frac{Q - q}{R}$（因为总电势称为电势等于 0）。

当带电体在球体内部移动时，电场汇合线会变形，但不会穿透导电球体。因此，所发现的电势值对于球内电荷 $-q$ 的任何位置都保持有效。
