§2. 定理的陈述

让我们立即检查一下实际情况，即有 128 名棋手，以及任意数量的棋手处于完美的分区中。我们用 n 来表示它。我们还引入以下符号。令N为任意数；对于某些整数 l，不等式 $2^l \geq N$ 成立。让我们用 l[N] 表示这些整数中最小的一个。

例子。

1. 由于 $2^3 < 10 < 2^4$，则 l[10] = 4。
2. 如果 $2^{k-1} < N \leq 2^k$，则 l [N] = k。
3. 很快我们就需要知道如果 N = 128·127，l[N] 等于多少。由于$128 = 2^7$和$2^6 < 127 < 2^7$，然后是$2^{13} < 128·127 < 2^{14}$，因此 l [128 127] = 14。

定理。要在n名棋手中确定1-20、2-20和3-20胜者，您需要奶酪不少于

$$P(n) = l[n(n-1)] + n-3$$
派对。

据他说。表述该定理的另一种方法如下。

允许最多检查 R 个游戏，其中

$$R < l[n(n-1)] + n-3.$$

然后（无论塞维诺尼亚执行什么规则）比赛的结果可能是这样的，即在 R 场比赛之后仍然无法确定第一、第二和第三名获胜者。

如果 n = 128，则 l[n(n-1)] = l[128·127] = 14（参见示例 3）。这意味着 P(128) = 14 + 128 - 3 = 139。 因此，从定理可知，要在 128 名棋手中确定第一名、第二名和第三名，至少需要 139 场比赛。在 139 场比赛中，它们可以使用 VOMI 规则来确定 - 所以 VOMI 规则很好！
