满足$a^2 + b^2 = c^2$的要求。
Polyag $\frac{a}{c} = x$和$\frac{b}{c} = y$，我们得到$x^2 + y^2 = 1$（$x$和$y$是有理数）。
因此$y^2 = (1 - x)(1 + x)$或$\frac{y}{1 + x} = \frac{1 - x}{y}$。我们用 $t = \frac{u}{v}$ 表示最后两个对应关系的一般（有理）值。然后是$y = t(1 + x)$和$(1 - x) = ty$，由此而来的$tx - y = -t$，$x + ty = 1$。

从这些等式依次可以得出
$$x = \frac{1 - t^2}{1 + t^2}, \quad y = \frac{2t}{1 + t^2},$$
或者，用 $\frac{a}{c}$ 代替 $x$，用 $\frac{b}{c}$ 代替 $y$，用 $\frac{u}{v}$ 代替 $t$，我们得到
$$\frac{a}{c} = \frac{v^2 - u^2}{u^2 + v^2}, \quad \frac{b}{c} = \frac{2uv}{u^2 + v^2}.$$

或者：$a = (v^2 - u^2)r$、$b = 2uvr$、$c = (u^2 + v^2)r$，其中$r$是某个有理比例系数。如果我们进一步假设$a, b, c$是互质的，那么很容易发现它们满足对应关系$a = v^2 - u^2$，$b = 2uv$，$c = u^2 + v^2$，其中$u$和$v$是互质且不同时为奇数的正整数。 （这些公式为古印度数学家所知，通常被称为“归纳公式”。）并且已经很容易证明（您自己遵循）数字$a, b$和$c$满足对应关系$a^2 + b^2 = c^2$。

通过考虑方程 $a^3 + b^3 = c^3$、$a^4 + b^4 = c^4$ 和一般的 $a^n + b^n = c^n$ 并提出用正整数求解它们的可能性问题，尝试概括寻找皮法德轨迹的问题是非常自然的。正是结合对毕达底轨迹的考虑，费马在亚历山大的杜芬特的书中做出了这样的评论：

对于 $n > 2$，方程 $a^n + b^n = c^n$ 不可解为整数 *)；

但他发现的这一事实的巧妙证明太长，无法放在本书的页边空白处……

现在大多数数学家对费马的这一说法相当怀疑。无论如何，在他随后提到的*）工作中，正是这个假设以费马大定理的名义进入了数学史。

尽管他继续研究问题本身，甚至解决了特殊情况$n = 4$，并为此开发了一种特殊的方法——所谓的方法——所谓的下降法，但他没有“机智证明”的余地。

Leonhard Euler (1707–1783) 证明了费马大定理的情况$n = 3, 4, 5, 7$。

对费马问题解决的最大贡献与德国数学家恩斯特·库默（Ernst Kummer，1810-1893）的名字有关。

可以证明（借助推理要素），要证明费马定理，考虑$a^p + b^p = c^p$形式的方程就足够了，其中$p$是素数，$a, b, c$是整数，但不一定是正数。

Kummer 证明了方程 $a^p + b^p = c^p$ 不允许满足某些“规律性”条件的所有质数指数 $p$ 的整数（非零）解，特别是对于所有 $3 < p < 100$。目前还不知道所有规则数的集合是否是无限的，但不规则数的集合被假设为无限的，即库默尔证明不起作用的数。

然而，库默尔关于费马大定理的工作的主要意义在于，库默尔“顺便”发展了数论的一个全新的重要分支——所谓的理论因式分解，这表明西蒙·弗拉格的同意迫使这些魔鬼彻底探究库默尔的工作。

近年来，出现了解决与费马大定理相关问题的几何方法。以下消息是此处的起点。如果方程 $x^p + y^p = z^p$ 有整数解，且 $z \neq 0$ 则方程 $\left(\frac{x}{z}\right)^p + \left(\frac{y}{z}\right)^p = 1$ 有有理数解，反之亦然。方程$x^p + y^p = 1$可以看作平面$xOy$上某条曲线的方程（类似于方程$x + y = 1$定义直线、方程$x^2 + y^2 = 1$定义圆等），其有理数解可以看作有理坐标的曲线上的点（简称：有理点）。应该立即注意到，曲线$x^p + y^p = 1$上存在有理点；一个简单的例子是点$(0, 1)$；这对应于费马方程的明显解。但这里直接涉及费马的以下定理：曲线$x^p + y^p = 1$的有理点的重数是有限的吗？当然，这是一个问题
