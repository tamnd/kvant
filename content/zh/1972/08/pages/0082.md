至“关于克拉文的问题”
(cm. cmp. 16, 25)

1. 该问题允许基于毕达哥拉斯定理提出有趣的几何解决方案。在 图 给出$n = 3$ 的解。

图 3.

红色虚线的长度是不等式的左边，对角线的长度是右边。仅当满足以下条件时才会出现等号：

$$x_1 = x_3 = \dots = x_{2n-1}; \quad x_2 = x_4 = \dots = x_{2n} \text{ и } x_1 + x_2 = 1.$$

在这种情况下，虚线与正方形的对角线合并。

2. 设置不等号就足够了

$$\sqrt[3]{10} - 2\sqrt{3} - \sqrt{8}.$$

为此，请使用身份

$$(\sqrt[3]{10}-2)(\sqrt[3]{100}+2\sqrt[3]{10}+4) = (3-\sqrt{8})(6+2\sqrt{8}) = 2.$$

3. 首先，我们将证明

$$x = \sqrt{2+V_2+\dots+V_2} < 2.$$

($n-1$部首)

事实上，通过将最后一个部首$\sqrt{2}$替换为2，我们增加了$x$，即

$$x < \sqrt{2+V_2+\dots+V_2} = \dots = \sqrt{2+2} = 2.$$

让我们将原来的不等式改写如下：

$$4(2-\sqrt{2+x}) > 2-x \text{ и далее}$$
$$(2-\sqrt{2+x})^2 > 0.$$

4. 笔记。预估金额

$$\frac{1}{5}\sqrt{5x+15} + \dots + \frac{1}{5}\sqrt{5x+15} +$$
$$\frac{1}{2}\sqrt{8-2x} + \frac{1}{2}\sqrt{8-2x}.$$

5. 笔记。确定哪个更大：$3-\sqrt[3]{18}$ 或$\sqrt[3]{2}-1$。

（答案：$\sqrt[3]{2}+\sqrt[3]{18}<4$。）

6. 笔记。使用不等式$\sqrt{2}>1$。

至问题M116

每个$n>3$的周长$P'/P$的比率可以取区间$(1/2, 1)$中的任意值。我们不会严格证明这一点，但仅限于描述该比率接近 $1/2$ 和 1 时的示例。如果多边形 $A_1, A_2, \dots, A_n$“退化为线段”，使得两个相邻顶点（例如 $A_1$ 和 $A_2$）接近线段的一端，其余顶点接近线段的另一端，则 $P'/P$ 接近 1；如果它“退化为一个线段”，使得$A_1$和$A_2$作为该线段的端点，并且所有其他顶点接近该线段的中间，则$P'/P$接近$1/2$。

每个$n>4$的面积比$S'/S$可以尽可能接近$1/2$：足以想象多边形“退化为三角形”，使得$A_1$和$A_2$作为三角形的两个顶点，而所有其他顶点都接近三角形的第三个顶点。对于每个 $n>5$，比率很容易接近 1，导致多边形退化为三角形，使得 $A_1$ 和 $A_2$ 接近一个顶点，$A_3$ 和 $A_4$ 接近另一个顶点，而其余顶点（至少其中两个！）接近第三个顶点。但对于 $n=5$ 来说，不可能接近 1。事实上，正如您可以证明的那样，第五个正方形的比率 $S'/S$ 不会超过 $3/4$。

至问题 M120

让操作 * 定义在三个元素 0、1、2 的集合中，如下所示：对于所有其他对 $a, b$，$1*2=1$ 和 $a*b=0$。然后对于任何三个元素$a, b$和$c$，$a*(b*c)=0$，但$(1*2)*2=1$。
