§ 1. 管理层的意见、机会和命运

甚至在完善之前，让四马俱乐部的管理层形成这样的观点：最强的棋手是A，第二好的是B，第三是C。并且让完善的目标是验证这实际上是真的。

这样的检查不能在少于 127 局的情况下进行，因为除了冠军之外，所有棋手都必须输掉至少一局。对于 127 场比赛，有可能： 125 个“局外人”（除了 A、B 和 C 之外的所有人）进行 124 场“淘汰赛”（每场比赛结束后，失败者被淘汰），然后获胜者与 C 比赛并输*)，C 输*) B 和 C 会输 *) A。事实上，甚至没有必要直接知道获胜者：他们可以被偶然猜到，所以有时（“如果你幸运的话”） 127场比赛决出三名胜者。

然而，我们会假设我们对国际象棋棋手的实力一无所知，并且我们“不知道”。此外，让我们想象邪恶命运（或对手的代理人 - 无论你想要什么）影响每场比赛的结果，以便完美的比赛尽可能持续下去。我们将证明，在这种情况下，无论**）轻率的塞文尼亚如何进行，都不可能在不到 139 场比赛的 128 名棋手中选出第一名、第二名和第三名获胜者。

*) 如果他赢了，那就意味着管理层错了，下一步该怎么做还不清楚。
**) 当然，根据第一章建议1-5。

§2. 定理的陈述

让我们立即检查一下实际情况，即有 128 名棋手，以及任意数量的棋手处于完美的分区中。我们用 n 来表示它。我们还引入以下符号。令N为任意数；对于某些整数 l，不等式 $2^l \geq N$ 成立。让我们用 l[N] 表示这些整数中最小的一个。

例子。

1. 由于 $2^3 < 10 < 2^4$，则 l[10] = 4。
2. 如果 $2^{k-1} < N \leq 2^k$，则 l [N] = k。
3. 很快我们就需要知道如果 N = 128·127，l[N] 等于多少。由于$128 = 2^7$和$2^6 < 127 < 2^7$，然后是$2^{13} < 128·127 < 2^{14}$，因此 l [128 127] = 14。

定理。要在n名棋手中确定1-20、2-20和3-20胜者，您需要奶酪不少于

$$P(n) = l[n(n-1)] + n-3$$
派对。

据他说。表述该定理的另一种方法如下。

允许最多检查 R 个游戏，其中

$$R < l[n(n-1)] + n-3.$$

然后（无论塞维诺尼亚执行什么规则）比赛的结果可能是这样的，即在 R 场比赛之后仍然无法确定第一、第二和第三名获胜者。

如果 n = 128，则 l[n(n-1)] = l[128·127] = 14（参见示例 3）。这意味着 P(128) = 14 + 128 - 3 = 139。 因此，从定理可知，要在 128 名棋手中确定第一名、第二名和第三名，至少需要 139 场比赛。在 139 场比赛中，它们可以使用 VOMI 规则来确定 - 所以 VOMI 规则很好！
