7. a) 让我们改造一下：

$$\frac{\mathrm{tg}(\alpha + \beta)}{\mathrm{tg} \alpha} = \frac{\sin(\alpha + \beta)}{\sin \alpha \cos(\alpha + \beta)} = \frac{\sin \beta + \sin(2\alpha + \beta)}{- \sin \beta + \sin(2\alpha + \beta)} = \frac{\sin \beta + 5 \sin \beta}{- \sin \beta + 5 \sin \beta} = \frac{6 \sin \beta}{4 \sin \beta} = \frac{3}{2}.$$

6) 我们有：$1 + \mathrm{tg} \frac{x+a}{2} \mathrm{tg} \frac{x-a}{2} = \frac{\cos \left( \frac{x+a}{2} - \frac{x-a}{2} \right)}{\cos \frac{x+a}{2} \cos \frac{x-a}{2}} = 2 \cos a: \left[ \cos \left( \frac{x+a}{2} - \frac{x-a}{2} \right) + \cos \left( \frac{x+a}{2} + \frac{x-a}{2} \right) \right] = \frac{2 \cos a}{\cos x + \cos a} = \frac{2 \cos a}{\cos a + \cos a \cos b} = \frac{2}{\cos b+1} = \frac{1}{\cos^2 \left( \frac{b}{2} \right)}.$

9. a) 用 $M$ 表示这个表达式，我们有 $\alpha \neq \pi k$：

$$M = \frac{2^n \sin \alpha \cos \alpha \cos 2\alpha}{2^n \sin \alpha} = \frac{2^{n-1} \sin 2\alpha \cos 2\alpha}{2^n \sin \alpha} = \dots = \frac{\cos 2^{n+1}\alpha}{2^n \sin \alpha}.$$
