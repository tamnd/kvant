M101

单个病毒进入由$n$个细菌组成的菌落。在第一分钟，它消灭了一个细菌，然后病毒分裂成两个新的细菌，同时剩余的每个细菌也分裂成两个新的细菌。下一分钟，出现的两种病毒消灭了两种细菌，然后病毒和所有其他细菌再次分裂，依此类推。

这个殖民地会无限期地生存还是最终会灭亡？

很容易查出细菌和病毒的数量会根据以下规律随时间变化：

| 时间（分钟） | 病毒数量 | 细菌数量 |
| :--- | :--- | :--- |
| 0 | 1 | $n$ |
| 1 | 2 | $2(n-1)$ |
| 2 | $2^2$ | $2^2(n-2)$ |
| 3 | $2^3$ | $2^3(n-3)$ |
| ... | ... | ... |
| $t$ | $2^t$ | $2^t(n-t)$ |
| $t+1$ | $2^{t+1}$ | $2^{t+1}(n-t-1)$ |
| ... | ... | ... |

从这里可以清楚地看出，在 $t=n$ 时，细菌数量将为零 - 菌落将死亡。

我们收到了大约 80 封包含该问题解决方案的信件，其中一封给出了错误答案。

M102

平面上由有限个点组成的集合具有以下性质：对于任意两个点 $A$ 和 $B$ 集合，存在一个点 $C$ 集合，使得三角形 $ABC$ 是等边三角形。

这样的集合可以包含多少个点？

让我们证明这样的集合只能包含三个点（当然，假设它包含多个点）。

让我们用字母 $\Gamma$ 来表示这个集合。

设$A$和$B$为集合$\Gamma$中的两个点，它们之间的距离称为$d$，点$P$必须位于以$A$为圆心、半径为$d$的圆内。同样，它必须位于半径为 $d$、圆心为 $B$ 和 $C$ 的圆内。因此，集合 $\Gamma$ 不会超出这些圆的公共部分 - 曲线“三角形”$T$ (图 1)。

此外，与点$P$和$A$一起，集合$\Gamma$必须属于两个点$Q$和$R$之一——等边三角形$APQ$和$APR$的顶点，即从$P$旋转$60^\circ$得到的点（在一个方向或另一个方向）大约 $A$ (图 2)。
