⟦folio 63⟧

根据三角形$SQA$和$SPE$的相似性，我们有
$$\frac{AQ}{PE} = \frac{SA}{SE},$$
(8)

并根据三角形 $SAC'$ 和 $SEC$ 的相似性
$$\frac{SA}{SE} = \frac{AC'}{EC}.$$
(9)

既然$AC' \perp SC$，那么$AC' < AC$，因此从(9)可以得出
$$\frac{SA}{SE} < \frac{AC}{EC}.$$
(10)

由(8)和(10)我们得到
$$\frac{AQ}{PE} < \frac{AC}{EC} \text{ или } \frac{AQ}{AC} < \frac{PE}{EC}.$$
(11)

三角形$ABC$是正确的，所以
$$\frac{AQ}{AC} = \sin 30^\circ = \frac{1}{2}.$$

那么从(11)可以得出
$$\sin \theta = \frac{PE}{EC} > \frac{1}{2},$$

即$\theta = 60^\circ$。由此可见，点$A_1$和$B_1$位于线段$EF$上，$P$是$A_1B_1$和$A_1B_1 < EF$的中点。

现在制作图(图3)并不困难。接受底边$AB$

图 3.

与识别的面 $A_1A_2SC$ 和 $B_1B_2SC$ 相交于点 $M$ 和 $N$。

让我们将 $x = MN$、$a = AB$、$b = A_1B_1$、$h$ 表示为直线度高度。让我们求直线 $SABC$ 及其位于直线内的部分的体积：

$$V_{SABC} = \frac{1}{6} ah \cdot QC,$$
$$V_{SMNC} = \frac{1}{6} hx \cdot QC,$$

在哪里
$$\frac{V_{SABC}}{V_{SMNC}} = \frac{x}{a}.$$
(12)

从三角形$MSN$和$B_1SA_1$的相似度我们发现
$$\frac{x}{b} = \frac{SQ}{SP}.$$
(13)

考虑三角形 $SPC$ (图 4)。让我们画一条直线$QL \parallel PC$。从三者的相似度来看

图 4.

我们有三角形 $SQL$ 和 $SPC$
$$\frac{SQ}{SP} = \frac{QL}{PC}.$$
(14)

接下来，$PC$是直线底边的高度，$PC = b \frac{\sqrt{3}}{2}$和$QL = QC \cdot \sin \alpha$。

角度 $\alpha$ 是一条直线的边 $SC$ 与底高 $QC$ 之间的角度。若$SF$为直线度高度，则
$$FC = \frac{a\sqrt{3}}{3}.$$
根据条件，$SC = \frac{2\sqrt{3}}{3} a$，从$\cos \alpha = \frac{1}{2}, \alpha = 60^\circ$，因此，
$$QL = \frac{a\sqrt{3}}{2} \cdot \sin 60^\circ = \frac{3a}{4}.$$

由(13)和(14)我们发现
$$\frac{x}{b} = \frac{SQ}{SP} = \frac{QL}{PC} = \frac{\sqrt{3}a}{2b},$$

从哪里$\frac{x}{a} = \frac{\sqrt{3}}{2}$。如下式（12）所示，这给出了所需的体积比。

回答。 $\frac{\sqrt{3}}{2}$。
