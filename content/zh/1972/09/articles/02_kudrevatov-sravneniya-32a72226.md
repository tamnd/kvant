让我们分别用字母$a$和$m$表示被除数和除数（我们将仅限于$m > 0$的情况），并分别用字母$q$和$r$表示商和余数。然后（参见图）$a = mq + r$，$0 \leq r < m$（余数除法的定义）。

如果$r = 0$，则$a = mq$，我们说“a可以被$m$整除”或“a是$m$的倍数”。这是用三只眼睛表示的：$a : m$；符号：表示“除以...”

在某些情况下，可整除的迹象有助于回答它是否可整除的问题。但在学校课程中，只考虑其中最简单的：被 2、3、5 和 9 整除的符号，例如被 7、11 整除，不在学校课程的范围之内。算术课上获得的知识不足以求出 $2^{25} + 1$ 除以 641、1971$^{1972}$ 除以 7、$22^{11} + 11^{22}$ 除以 3 的余数。这些以及许多其他问题都可以通过比较理论来回答，本文将讨论比较理论的要素。

因此，可以通过加、减和乘来获得相同模数的比较：

$$a \equiv b, c \equiv d \pmod{m} \Rightarrow a \pm c \equiv b \pm d, ac \equiv bd \pmod{m}.$$ (C)

这也引出了以下推论：
相同的数字可以添加到给定比较的一部分，它们可以乘以相同的数字，也可以提高到相同的自然幂，即

$$a \equiv b \pmod{m} \Rightarrow a + c \equiv b + c, ac \equiv bc, a^k \equiv b^k \pmod{m}.$$

3. 模比较和类划分

第2段中给出的比较性质使得可以相对简单地解决整除理论中的许多问题，这些问题在奥林匹克竞赛、竞赛等中经常遇到。让我们考虑其中的一些问题，但首先注意，在解决这些问题时，可以通过将它们划分为给定模数中可比较的数字类别来解决它们（在这种情况下，模型是根据情况选择的，或者是由问题本身的条件确定的）。

对于每个比较，x == a(mod m) 满足数字 x 的类别，当除以 m 时，得到余数 r(a, m)。对于每个 x 执行一次比较

$$x \equiv 0, x \equiv 1, x \equiv 2, \dots, x \equiv m - 2, x \equiv m - 1 \pmod{m}$$

或者，相同的是，等式之一

$$x = mt, x = 1 + mt, x = 2 + mt, \dots, x = m - 2 + mt, x = m - 1 + mt,$$

其中 t 是相应的整数。因此，每个整数属于 m 个类别之一；在给定模数中不可比较的数字属于不同的类别。

锻炼

5. 检查可比关系是否为等价关系，并将所有数字划分为可比较的类别，即证明

a) x ≡ x(mod m);
b) x ≡ y(mod m) ⇒ y ≡ x(mod m);
b) x ≡ y, y ≡ z(mod m) ⇒ x ≡ z(mod m).

M. M. Glukhov 的文章《集合的等价关系和划分》详细讨论了类划分，《Quant》第 2 期，1972 年。

4. 一些任务

为了在解决问题时更自由地使用“比较语言”，请考虑以下问题：哪些类（例如模 6 中的类）包含素数？素数 37 属于哪一类？哪些模 6 类包含数字的目标幂？

很容易看出类 x == 0(mod 6) 不包含素数：它由 6 的倍数的数字组成。类 x == 4(mod 6) 不包含素数，因为它由四个数字 4+6t = 2(2+3t) 组成（并且不包含数字 2）。 x == 2 和 x == 3(mod 6) 类各自包含一个素数：分别为 2 和 3。 x == 1, x == 5(mod 6) 类包含所有其他素数；例如，第一个包括 7 和 13，第二个包括 11 和 17。
