1. 在三角形中，上升圆和外接圆的感受点关于其中一条线对称。找到三角形的角。

让我们用 A 和 C 表示相对对称中心的边的两端，用 B 表示第三个顶点（参见 图 1）。设 O 和 D 为相应的挤压圆和外接圆的圆心。如果我们忽略它们对 AC 的重新分配，那么它们将落在一点 M - 线段 OD 的中间（这意味着 O 和 D 相对于 AC 对称）。我们需要找到三角形的角度：$\angle BAC = \alpha$、$\angle ABC = \beta$、$\angle BCA = \gamma$。

我们首先证明$\alpha = \gamma$。事实上，$AD = DC$（作为半径），

偏序$AM = MC$，开$\triangle AMO = \Delta CMO$。因此，$\angle OAM = \angle OCM$。但是$\angle OAM = \frac{\alpha}{2} \Rightarrow OCM = \frac{\gamma}{2}$（延伸到三角形的圆心位于其平分线的交点），偏序集$\alpha = \gamma$。

由此可见$AB = BC$，那么中位数$BM$也是高度，即O位于BM上。

可能，点 B、O、M 和 D 位于同一条直线上，并且由于 $BD = AD$（作为半径），因此$\angle BAD = \angle ABD = \frac{\beta}{2}$。

另一方面，$\triangle AOM = \Delta ADM$。这就是为什么

$\angle MAD = \angle MAO = \frac{\alpha}{2}$.

然后

$\angle BAD = \angle BAM + \angle MAD = \alpha + \frac{\alpha}{2} = \frac{3\alpha}{2}$.

所以，

$\frac{\beta}{2} = \frac{3\alpha}{2}, \beta = 3\alpha$.

对于波斯尼来说，三角形$ABC$的角和等于$5\alpha$，因此$\alpha = 36^\circ$、$\beta = 108^\circ$。

答案：$36^\circ, 108^\circ, 36^\circ$。

4. 是否存在至少一个数a使得数$\frac{1}{a} - \sqrt{15}$和$a + \sqrt{15}$都是整数？

令$a + \sqrt{15} = m$，$\frac{1}{a} - \sqrt{15} = n$。

让我们用第一个等式表达 a 并将其代入第二个等式：

$$\frac{1}{m - \sqrt{15}} - \sqrt{15} = n.$$

我们来转换一下：

$$16 - mn = (m - n) \sqrt{15}.$$

为了实现这个等式，满足以下条件就足够了：

$$\begin{cases} 16 - mn = 0, \\ m - n = 0. \end{cases}$$

（事实上​​，这是必要的，因为 m、n 都是整数，但你可能不知道这一点：毕竟我们只需要找到 a 的至少一个值。）

由此产生的系统可以很容易地解决：

$$m_1 = n_1 = 4, m_2 = n_2 = -4.$$

答：存在这样一个：例如$4 - \sqrt{15}$（实际上只有两个这样的数字）。

6. 还可以考虑四个非负整数，这样从 1 到 81 的每个数字都可以表示为四个数字的和 - 每个三元组中一个。

以下四种是合适的：

1, 2, 3
0, 3, 6
0, 9, 18
0, 27, 54.

让我们解释一下它们是如何发明的。以更通用的形式解决这个问题会更容易：提出 k 个非负整数三元组，这样从 1 到 3^k 的每个数字都可以表示为 k 个数字的和 - 每个三元组中一个。

对于 k=1，解决方案非常印度：一个三元组 1, 2, 3。让问题针对 k 个三元组来求解。如何选择另一个三元组来解决k+1问题？

第一个数字必须为零。然后，将其与从第一个三元组之一获取的 k 个数字的总和相加，我们得到从 1 到 3^k 的相同数字。

让我们取第二个数字等于 3^k。将它与 1 到 3^k 之间的数字相加，我们得到 3^k+1 到 2.3^k 之间的所有数字。

我们取第三个数字，等于 2.3^k。将其与相同的数字相加，我们得到从 2.3^k+1 到 3.3^k = 3^k+1 的所有数字。

因此，问题也是求解 k+1。这就是四人三人的建造方式。已经证明它们适用于每个k，包括k=4。
