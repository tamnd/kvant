从式(1)和式(2)中消去w，得

$$\left( \gamma \frac{MM_3}{R_1^2} - T \right) \frac{1}{MR_1} =$$

$$= \left( \gamma \frac{mM_3}{R_2^2} + T \right) \frac{1}{mR_2},$$

或者

$$\gamma M_3 \frac{R_2^3 - R_1^3}{R_1^2 R_2^2} = T \frac{mR_2 + mR_1}{mM}.$$

(3)

但是 $R_2 \approx R_1 \approx R$ 因此：

$$R_1 R_2 \approx R^2,$$

$$R_2^3 - R_1^3 = (R_2 - R_1) (R_2^2 + R_1^2 + R_1 R_2) \approx 3lR^2$$

（l是升降索的长度），

$$mR_2 + MR_1 = (m + M) R.$$

这意味着等式（3）可以写成如下：

$$3\gamma \frac{M_3}{R^2} l = TR \frac{m + M}{mM}.$$

从这里我们得到：

$$T = 3\gamma \frac{M_3}{R^2} \frac{l}{R} \frac{mM}{m + M}.$$

如果地球表面有一个质量为$m$的物体，那么它会受到力$F = \gamma \frac{mM_3}{R^2} = mg$的影响。这意味着自由落体的加速度$g$等于值$\gamma \frac{M_3}{R^2}$。因此，我们可以将升降索拉力的表达式改写如下：

$$T = 3 \frac{l}{R} \frac{mM}{m + M} g.$$

将数值$R, g, m$和$M$代入这个公式，我们发现

$$T \approx 0,03n.$$

F139

足球运动员以与地平线成 $\alpha$ 角度的速度 $v$ 击球，击中球的底角。如果足球运动员在足球场上的同一位置击球，并且球以与地平线相同的角度飞行，但速度比速度$v$大5%，那么它会击中上地平线。当球的高度为$h = 2m$且角度为$\alpha = 30^\circ$时，求球开始移动的速度。

让我们写下球运动的运动学方程。水平方向——沿$X$轴，球以$v_1 = v \cos \alpha$（图2）的速度匀速运动；其坐标$x$随时间规律变化

$$x = vt \cos \alpha.$$

沿着 $Y$ 轴（垂直），球以均匀加速度 $g$ 向下移动。这就是为什么

$$y = vt \sin \alpha - \frac{gt^2}{2}.$$

此时$t_0$落到地面$y = 0$和$x = l$，其中$l$是球的飞行范围。这就是为什么

$$l = vt_0 \cos \alpha,$$

$$0 = vt_0 \sin \alpha - \frac{gt^2}{2}.$$

如果球开始以比速度$v$大5%的速度移动，即以1.05$v$的速度移动，那么它的坐标$x$和$y$将随时间变化如下：

$$x = 1,05 vt \cos \alpha$$

和$$y = 1,05 vt \sin \alpha - \frac{gt^2}{2}.$$

当球撞击垂体上表面时，其坐标$x$等于$l$，坐标$y$等于垂体$h$的高度。因此，在击中盾牌的$t_1$瞬间，

$$l = 1,05 vt_1 \cos \alpha,$$

$$h = 1,05 vt_1 \sin \alpha - \frac{gt_1^2}{2}.$$

现在让我们求解方程组 (1) - (4)。由式(2)不难求出第一种情况下球的飞行时间$t_0$。由于$t_0 \neq 0$，然后将该方程除以$t_0$，我们发现：

$$t_0 = \frac{2v \sin \alpha}{g}.$$

接下来，将式（3）除以式（1），可得：

$$1 = 1,05 \frac{t_1}{t_0}.$$

从这里

$$t_1 = \frac{t_0}{1,05} = \frac{2v \sin \alpha}{1,05g}.$$

现在，将$t_1$的表达式代入式(4)，可得

$$v = \sqrt{\frac{gh}{0,2 \sin^2 \alpha}}.$$
