⟦folio 44⟧

图 5.

内部“黑匣子”的电路可以如图5所示。我们来确定这个电路的参数。

根据电路部分$U=IR$的欧姆定律，可以得出电路部分两端电势差的变化与通过该部分的电流的变化相关，根据：

$$\Delta U = R \Delta I.$$

这意味着电路部分的电阻等于

$$R = \frac{\Delta U}{\Delta I},$$

即，其大小等于漏极电压依赖图的斜率的正切。

在第一种情况下，当引脚 2 和 3 被替换时，当外部源的电压$U$变化时，“盒子”中的内容应该表现为两个并联电阻$R_1$和$R_2$，其总电阻为$2/3$欧姆。这就是为什么

$$\frac{R_1 R_2}{R_1 + R_2} = \frac{2}{3}$$

（电阻$R_1$和$R_2$必须以欧姆表示）。

另外，我们知道当$U=3\theta$时，外电路电流为零。这意味着当电流为零并且内部箱电路未连接到电源时，电阻$R_2$两端的电压降为3$\theta$。但在这种情况下，电阻$R_1$和$R_2$与电源串联，因此，通过它们的电流等于$\frac{E}{R_1 + R_2}$，电阻$R_2$两端的压降也相等

$$\frac{R_2 E}{R_1 + R_2} = 3(\theta).$$

在第二种情况下，盒子内部的行为应该像两个并联的电阻$R_2$和$R_3$，其总电阻为6欧姆。这就是为什么

$$\frac{R_2 R_3}{R_2 + R_3} = 6(om).$$

在第三种情况下，并联电阻$R_1$和$R_3$“连接”到外部源，它们的总电阻为2欧姆：

$$\frac{R_1 R_3}{R_1 + R_3} = 2(om).$$

此外，由于在这种情况下，$U=4\theta$处的电流为零，因此

$$\frac{R_3 E}{R_1 + R_3} = 4(\theta).$$

我们收到了一个由 5 个方程组成的系统，其中有 4 个未知数：$R_1, R_2, R_3$ 和 $E$。我们来检查一下是否兼容。将式（1）除以式（2），得：

$$\frac{E}{R_1} = 2(\theta/om).$$

类似地，将式（4）除以式（5），我们得到$E$和$R_1$之间完全相同的对应关系。这意味着我们的系统是协作的。

现在让我们找到电阻 $R_1, R_2$ 和 $R_3$。为此，我们需要求解三个方程组 (1)、(3) 和 (4)。首先，我们来交叉一下，“翻转”每一个方程：

$$\frac{R_1 + R_2}{R_1 R_2} = \frac{3}{2},$$ 或 $$\frac{1}{R_1} + \frac{1}{R_2} = \frac{3}{2},$$

$$\frac{R_2 + R_3}{R_2 R_3} = \frac{1}{6},$$ 或 $$\frac{1}{R_2} + \frac{1}{R_3} = \frac{1}{6},$$

$$\frac{R_1 + R_3}{R_1 R_3} = \frac{1}{2},$$ 或 $$\frac{1}{R_1} + \frac{1}{R_3} = \frac{1}{2}.$$

将$\frac{1}{R_1}, \frac{1}{R_2}$和$\frac{1}{R_3}$作为新的未知数并求解所得系统，我们发现：

$$\frac{1}{R_1} = \frac{1}{2}, \frac{1}{R_2} = \frac{1}{6} \text{ и } \frac{1}{R_3} = 0.$$

由此可见

$$R_1 = 2 \text{ ом}, R_2 = 6 \text{ ом}, R_3 = \infty \text{ и } E = 4 \text{ e}.$$
