入学考试的选择
1972 年数学

莫斯科国立大学以它的名字命名
M·V·罗蒙诺索娃

化学学院

1. 码头 $A$ 距码头 27 公里 $B$ 河流的下游。从码头出发 $A$ 向码头方向 $B$ 第一艘船出发，出发一小时后，第一艘船在码头与它会合 $B$ 第二艘船出发。船只在距码头 18 公里处交汇 $B$.

如果船只同时从 $A$ 和 $B$ 码头出发前往对方，则它们将在两小时和四小时内相遇。如果已知第一艘船在静水中的速度是河水流速的两倍，则求第一艘船的速度。

2. 解方程
$$\log_{x^2+6x+8}[\log_{2x^2+2x+3}(x^2-2x)] = 0.$$

3. 在梯形$ABCD$中，底边$AD$处的角度$A$和$D$分别为60°和30°。点$N$位于底$BC$和$BN:NC = 2$上。点$M$位于底$AD$上，线$MN$垂直于梯形的底，并将其面积分成两半。求出比率 $AM:MD$。

4. 三角形矩形$SABC$的底是直角三角形$ABC$，其顶点$B$为直角。边$SA$垂直于三角形$ABC$的平面。分别通过边$AC$和$BC$的中点$D$和$E$，绘制一个与边$SC$平行的平面，并在截面上形成四边形$DEFH$（点$F$位于边$SB$上）。如果已知$BC=a$、$AC=b$、$SA=h$，求四边形$DEFH$的面积。

5. 查找 $x$ 的所有值，其中表达式
$(\sin 4x + \sin 2x)(3\cos^2x + 2\sin 2x - 6\cos x)$ 正。

地理与土壤学院 生物学院

1. 两个车队各有28辆汽车，其中有11辆是日古利艾，其余的是莫斯科维奇。如果知道第一个车队中每辆日古利艾车上的莫斯科奇人数是第二个车队的两倍，那么每个车队中有多少个莫斯科奇？

2. 找到方程的所有解
$$\sqrt{3}\sin x + 2\cos x = \sqrt{3} + \sin 2x,$$
满足条件 0 < x < 2。

3. 找到 $x$ 不等式成立的所有值
$$\log_2 x - \log_x 32 < 4.$$

4. 查找所有数字 $x$ 和 $y$
$$\begin{cases} 2^{x+1} = y^2 + 4, \\ 2^{x-1} \leq y. \end{cases}$$

5. 通过三角形$ABC$的顶点$B$和$C$绘制一个圆，该圆与边$AB$相交于点$K$，边与$AC$相交于点$E$。找出$AE$，已知$AK = KB = a$、$BCK = \alpha$、$CBE = \beta$。

生物学院生物系

1. 一辆汽车从$A$点出发，一小时后一辆摩托车到达，追上汽车到达$B$点。这时，第二辆摩托车从$A$发出，以与第一辆摩托车相同的速度撞击。第二辆摩托车在汽车出发六小时后追上。摩托车从$A$点行驶到$B$点需要多长时间？

2. 简化表达式
$$tg 4x \cdot tg (40^\circ - 2x) + tg 4x \cdot tg (50^\circ - 2x) + tg (50^\circ - 2x) \cdot tg (40^\circ - 2x).$$

3. 解方程
$$5\sqrt{\log_3 x + \log_5 9} \log_5 3 = 3^{1 \log_3 1.8}.$$

4. 找到方程的所有解
$$\sin x + \sin (\log_3 x^3 \pi x) = \cos x - \cos \left(\log_3 \frac{x^3 \pi x}{x}\right).$$

5. 在三角形$ABC$中，书目$AD$和$BE$相交于点$O$。已知$BC = a$、$AC = b$、$AB = c$，求三角形$ABC$的面积与四边形$ODCE$的面积之比。
