$$f(x_1)(a_1 - a) + f(x_2)(a_2 - a_1) + \dots + f(x_n)(b - a_{n-1})$$
其中$a_1, a_2, \dots, a_{n-1}$是将线段$[a, b]$分成几部分的点，$x_1, x_2, \dots, x_n$是这些部分的点。该近似可以根据需要精确地进行。

上面写的金额称为Interral。显然，根据定义，内部值是随着划分变得越来越精细，内部值之和所趋向的极限。在我们对区间的定义中，没有使用极限的概念。从内部总和中也可以得出内部的名称。符号$\int \limits_a^b f(x) dx$是这样的：“interral from a to be ef from x to de x”。函数$f$称为子内部化，数字$a$和$b$分别是内部化的下限和上限。应该记住，正如$x \rightarrow x^2, t \rightarrow t^2, z \rightarrow z^2$是相同的函数一样，符号$\int \limits_a^b f(x) dx, \int \limits_a^b f(t) dt, \int \limits_a^b f(z) dz$表示相同的数字——函数$f$在线段$[a, b]$上的区间值。

§ 4. 积分公式

使用内部和来计算内部是一项相当麻烦的任务，而且结果是近似的。相反，他们这样做：计算几个标准的、经常遇到的内部函数，并尝试将其他内部函数简化为它们。我们将计算两个标准区间

$$\int \limits_a^b x_n dx \quad \int \limits_a^b \cos x dx \quad \text{и установим некоторые теоремы, позволяющие своить ряд интерралов к стандартным.}$$

1°计算$\int \limits_a^b x^n dx$。

考虑由公式给出的区间函数$T$
$$T[a, b] = \frac{b^{n+1} - a^{n+1}}{n+1}.$$

该函数是可加的：
$$T[a, b] + T[b, c] = \frac{b^{n+1} - a^{n+1}}{n+1} + \frac{c^{n+1} - b^{n+1}}{n+1} = \frac{c^{n+1} - a^{n+1}}{n+1} = T[a, c].$$

让我们证明$T$是数值函数$x \rightarrow x^n$的积分。为此，我们需要确定在每个线段 $[a, b]$ 上不等式 $(b - a) \min x^n \leq T[a, b] \leq (b - a) \max x^n$ 成立。让我们检查非负 $a$ 和 $b$ 的不等式。在这种情况下$\min x^n = a^n$，$\max x^n = b^n$，所以我们需要证明
$$(b - a) a^n \leq \frac{b^{n+1} - a^{n+1}}{n+1} \leq b^n (b - a)$$
或者
$$(n + 1) a^n (b - a) \leq b^{n+1} - a^{n+1} \leq (n + 1) b^n (b - a).$$

将$b^{n+1} - a^{n+1}$展开为集合并用$b - a > 0$消去，最后的不等式可以重写为
$$a^n + a^n + \dots + a^n \leq b^n + b^n + \dots + b^n.$$

这个不等式是有效的，因为中间部分的项不小于左侧的项，也不大于右侧的项。

因此，区间$T$的加函数是一个积分。
