F784。恒定的力 F 开始作用在以恒定速度 v 运动的物体上。经过时间 t，物体的速度变为等于 v/2。在接下来的类似时间间隔内，速度又降低了一半。求从力 F 开始作用起，经过 3t 的时间间隔后，物体的速度为多少。

F785。一块冰漂浮在一杯水中。水面上会形成一层油（图1）。当冰融化时，玻璃杯中的液位会如何变化？水和油之间的界面将转移到哪里？

所有力相对于 O) 点的力矩如下：
$$N_1 = 2N_2, \vec{N}_1 = -\vec{2N}_2.$$ (1)

考虑到这些对应关系，我们得到（见图）：
$$T = N_1 - N_2 = N_2.$$ (2)

螺纹反转后第一时刻的载荷 m₁ 和 m2 的加速度将垂直定向（O 点静止，杆不可伸长），并通过以下对应关系
$$a_2 = 2a_1.$$ (3)

让我们写出此时货物运动的方程：
$$m_1g - N'_1 = m_1a_1,$$
$$m_2g + N'_2 = m_2a_2,$$
其中 N'_1 和 N'_2 是杆作用在载荷 m₁ 和 m2 上的反作用力 $\vec{N}'_1$ 和 $\vec{N}'_2$ 的模态。由于 N'_1 = N_1 且 N'_2 = N_2，考虑到对应关系 (1) 和 (3)，我们得到：
$$m_1g - 2N_2 = m_1a_1,$$
$$m_2g + N_2 = 2m_2a_1.$$
从这里我们找到 N2，因此（参见 (2)）和 T：
$$T = \frac{m_1m_2}{m_1 + 4m_2} g.$$

克罗托夫

从问题的条件可以看出，力 $\vec{F}$ 与物体 v 的初始速度矢量成一定角度 α ≠ 0（否则，即在 α = 0 时，相同时间间隔内的变化速度将相同）。

令 $\vec{OA}$ 为物体初速度矢量，$\vec{AB}$ 为从力 F 开始起，速度随时间 t 变化的矢量（见图）。那么 $\vec{OB}$ 是一个向量，等于时间 t 后物体的莫迪利安速度 v₁ = v/2。让我们从 B 点留出向量 $\vec{BC}$，它与向量 OA 的方向形成角度 α，并且模数相等 |$\vec{AB}$|。那么，从力 F 作用开始 2t 后，矢量$\vec{OC}$ 的模数就等于物体的速度 v2 = v/4。再次重复同样的操作，我们将构造出从力 F 作用开始 3t 后，模数等于物体速度 v₃ 的矢量 OD。

令向量$\vec{AB}$在X轴和Y轴上的投影（见图）等于Δvₓ和Δv_y之间的对应关系。然后
$$(v + \Delta v_x)^2 + \Delta v_y^2 = v^2/4,$$
$$(v + 2\Delta v_x)^2 + (2\Delta v_y)^2 = v^2/16.$$
考虑到调制 v₃ 必须满足对应关系
$$v_3^2 = (v + 3\Delta v_x)^2 + (3\Delta v_y)^2,$$
考虑到前面的方程，我们找到 v₃：
$$v_3 = v\sqrt{7}/4.$$
