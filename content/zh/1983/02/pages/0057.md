最好不要比较实数是否相等，

因为我们几乎有百分之一百的概率得到“不相等”的结果。因此，任务 3 中的算子

if $a[i] = x$ then...
应替换为
if abs $(a[i] - x) < eps$ then...

其中 eps 是一个常量，例如 eps = 0.0001（取决于计算机的精度和您需要的精度）。然后，如果动作数相差不超过某个 ε，则认为它们相等。

在任务1中，如果$a = 0, b = 1, a h = 0,1$，那么我们不能保证我们会得到所有11个函数值：在$x$和$h$相加10次之后，我们可以得到一个比$b$小一点的值，或者比$b$多一点的值，在后一种情况下循环将不再适用。为了达到想要的结果，你需要要么用 while $(x < b + h/2)$ 的条件组织一个循环，要么提前计算循环$n := \text{round}((b - a)h)$的重复次数，并组织$i := o$到$n$的循环 do... 但是，这样的路径可能不会达到你想要的结果：如果$n$的值（所需的步数）足够大，那么当重复执行该运算符时$x := x + h$可能累积误差超过值$h$。那么通过while组织的循环会少执行一次（甚至几次）或多一次，而通过for组织的循环会执行所需的次数，但最后的值会远离$b$。为了弥补这一点，我们必须像这样组织循环：

$$n := \text{round}((b - a)/h);$$
for $i := 0$ to $n$ do
begin $x := a + i*h;$
writeln $(x, '**2 =', x**2)$
end;

（当然，这个程序会比较慢，因为每次计算参数值都需要大量的运算。）
