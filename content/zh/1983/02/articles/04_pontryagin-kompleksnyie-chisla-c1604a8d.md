复数

L.S.庞特里亚金院士

在这里，我首先非常简要地谈谈复数是如何在数学中产生并逐渐在数学中立足的。然后我给出复数的定义、它们的运算以及它们的几何解释。在此过程中，证明了和的余弦和正弦公式，这些公式与复数的乘法密切相关。

历史背景

从数学过程中我们知道，引入负数主要是为了始终可以进行减法运算（加法运算的逆运算）。出于类似的原因，数学中出现了复数。如果我们只考虑实数，那么提取平方根的操作（平方操作的逆操作）并不总是可能的，因为不可能提取负数的平方根。然而，这还不足以在数学中引入新的数字。事实证明，如果根据通常规则对出现负数平方根的表达式进行计算的乘积，则可以得到不再包含平方根的结果

复数的定义

我们假设我们知道实数。我们知道为它们定义了两种基本运算 - 加法和乘法 - 并且还有它们的逆运算 - 减法和除法。对于这些操作，将执行几个提取的规则，这些规则通常完全自动使用 - 所以我不会在这里制定它们。定义了加法和乘法运算及其逆减法和除法运算，并且满足适用于实数的对象规则的对象集合，在现代抽象代数中称为域。

因此，从现代抽象代数的角度来看，所有实数的集合R代表一个域。现在让我们为自己设定一个任务，扩展数字的概念，或者，

由于域$K$包含所有实数和元素$i$，并且由于其中可以进行加法和乘法运算，因此域$K$必须包含关于具有实数系数的$i$的所有可能的多项式，特别是所有一次多项式，即以下形式的表达式

$$z = x + yi = x + iy,$$

其中 $x$ 和 $y$ 是实数。这些表达式称为复数。我们将对它们的操作定义为对多项式的操作，并考虑条件（2）。复数的形式

$$z = x + 0i = x$$

是实数。复数的形式

$$z = 0 + yi = yi$$

这些数字称为最小数。

令$z_1 = x_1 + y_1 i$、$z_2 = x_2 + y_2 i$为两个复数。根据规定的规则，这些复数的和与积由等式确定

$$z_1 + z_2 = (x_1 + y_1 i) + (x_2 + y_2 i) =$$

$$= (x_1 + x_2) + (y_1 + y_2) i;$$

(3)

$$z_1 z_2 = (x_1 + y_1 i) (x_2 + y_2 i) =$$

$$= x_1 x_2 + (x_1 y_2 + y_1 x_2) i + y_1 y_2 i^2 =$$

$$= (x_1 x_2 - y_1 y_2) + (x_1 y_2 + y_1 x_2) i.$$

(4)

当获得最后一个相等时，我们使用结果

$$x_1 z_2 = x_1 x_2 + x_1 y_2 i.$$

(5)

从公式（3）和（4）可以看出，两个复数的和与积也是复数。

为了确保减法动作（加法动作的逆动作）存在，只要找到数$z$的逆数$-z$就足够了，为了确保除法是可能的，$z \neq 0$指示数$z^{-1}$（数$z = x + yi$的逆数）就足够了。很容易看出，这些数字是由公式给出的

$$-z = -x - yi,$$

$$z^{-1} = \frac{x}{x^2 + y^2} - \frac{y}{x^2 + y^2} i.$$

因此，每当 $z \neq 0$ 时，$z$ 的倒数$z^{-1}$ 就存在。

复数的几何表示

让我们用 $P$ 表示绘图平面，并在其上选择一个直角坐标系 (图 1)。我们将复数 $z = x + yi$ 放置在坐标为 $x, y$ 的点 $z = (x; y)$ 处。我们还用 $z$ 表示从原点 $O$ 到点 $z$ 的向量。因此，字母$z$同时表示一个复数，点$z$表示该复数，向量$z$对应于该复数。在这种情况下，实数的图像落在横坐标轴上 - 因此横坐标轴称为复变量 $P$ 平面的实轴，数字的数量落在纵坐标轴上 - 因此纵坐标轴称为复变量 $P$ 平面的最小轴。零落在原点。

向量 $z$ 的长度称为复数 $z = x + yi$ 的模，记作 $|z|$：

$$|z| = \sqrt{x^2 + y^2}.$$

满足条件$|z| = 1$的复数$z$形成一个以原点为圆心、半径为1的圆。数字 1 就位于这个圆上。从点 1 开始，我们沿圆逆时针方向切掉给定长度 $\varphi$ 的弧。我们用 $(\varphi)$ 表示这条弧的终点。如果$\varphi$是负数，则要得到$(\varphi)$，需要从点1顺时针方向减去弧长$|\varphi|$。众所周知，点$(\varphi)$的横坐标称为cos$\varphi$，纵坐标称为sin$\varphi$。因此，复数 $(\varphi)$ 由下式给出

$$(\varphi) = \cos \varphi + i \sin \varphi.$$

因此，任何复数$z$，根据模型等于1，都可以写成形式（6）。如果$z$是一个任意复数，其模型$|z| = \varphi$不同于0，那么根据模型$z/\varphi$是一个复数，等于1，因此可以写成形式（6）。来自平等

$$\frac{z}{\varphi} = \cos \varphi + i \sin \varphi$$

我们得到

$$z = \varphi(\cos \varphi + i \sin \varphi).$$

记录(7)称为复数的三角公式。数字$\varphi$称为复数的参数。如果复数 $z$ 的模型 $\varphi$ 非零，则参数 $\varphi$ 定义为项 $2\pi k$，其中 $k$ 是整数。如果复数的模型$\varphi$等于0，则公式（7）也成立，但此时复数的自变量根本没有定义。

数字$\varphi$和$\varphi$称为点$z$的极坐标。

现在让我们给出复数作用的几何来源。

从公式（3）和（5）可以看出，复数与实数相加和相乘，就像向量一样。

复数相加的几何意义非常明确：向量 $z_1 + z_2$ 是基于向量 $z_1$ 和 $z_2$ 构建的平行四边形的对角线。这导致了一个重要的不平等：

$$|z_1 + z_2| \leq |z_1| + |z_2|.$$

为了给出复数的几何源乘法，您需要使用向量或复数的旋转运算。将向量$z$逆时针旋转角度$\alpha$，我们得到一些新向量，记为$R_\alpha(z)$。从几何角度来看，旋转运算 $R_\alpha$ 具有以下性质：如果 $\alpha$ 是实数，则

$$R_\alpha(az) = aR_\alpha(z),$$

$$R_\alpha(z_1 + z_2) = R_\alpha(z_1) + R_\alpha(z_2).$$

从这两个公式可以看出，如果$a_1$和$a_2$是两个实数，那么就有对应关系

$$R_\alpha(a_1z_1 + a_2z_2) = a_1R_\alpha(z_1) + a_2R_\alpha(z_2).$$

还可以立即明确的是

$$R_\alpha(1) = \cos \alpha + i \sin \alpha.$$

现在让我们证明，将复数$z = x + yi$旋转角度$\alpha$相当于将其乘以复数$\cos \alpha + i \sin \alpha$，即

$$R_\alpha(z) = (\cos \alpha + i \sin \alpha)z.$$

为此，我们首先单独考虑通过角度 $d = \frac{\pi}{2}$ 的旋转。在这种情况下，$\cos d + i \sin d = i$，等式 (11) 的形式为$R_d(z) = iz$。一方面，有几何估计$R_d(1) = i$，$R_d(i) = -1$。另一方面，$i \cdot 1 = i$，$i \cdot i = -1$。因此，

$$R_d(1) = i \cdot 1, R_d(i) = i \cdot i.$$
