M821。解方程
$$x^3 + x^2 + x = -\frac{1}{3}.$$

让我们将方程重写为 $3x^3 + 3x^2 + 3x + 1 = 0$ 的形式；我们得到立方和：$(x+1)^3 + 2x^3 = 0$。我们把它写成$(x+1)^3 = -2x^3$的形式，两边开立方根：$x+1 = -x\sqrt[3]{2}$；因此$x = -\frac{1}{1 + \sqrt[3]{2}}$。

F834。一个质量为 $m_1 = 0,1$ kg 的球通过一根很长的失重线悬挂在天花板上，另一个质量为 $m_2 = 0,05$ kg 的球通过长度为 $l = 0,2$ m 的线固定在其上。下球在水平方向上的有效速度为 $v_0$。 $v_0$ 为多少时，球可以处于相同高度？

对于很长的面线，我们可以假设上球沿着水平直线移动。当两个球处于同一高度时，即底线处于水平位置时（见图），第二个球的速度的水平投影将等于第一个球的速度。这是因为连接它们的线的不可延伸性。为了使两个球处于相同高度时速度$v_0$的最小值，需要假设此时第二个球的速度的垂直投影为零（即普通球的速度$v$相等且水平方向）。

作用在系统上的所有外力（面线张力和重力）均垂直方向。因此，系统总动量的水平投影得以保留：

$$m_2 v_0 \min = (m_1 + m_2) v.$$

从这里

$$v = v_0 \min \frac{m_2}{(m_1 + m_2)}.$$

根据机械能守恒定律，

$$\frac{1}{2} m_2 v_0^2 \min = \frac{1}{2} (m_1 + m_2) v^2 + m_2 gl.$$

将找到的$v$表达式代入该方程，我们发现

$$v_0 \min = \sqrt{2 gl \left(1 + \frac{m_2}{m_1}\right)}.$$

代入数值数据，我们得到

$$v_0 \min = \sqrt{3 gl} \approx 2,4 \text{ m/c.}$$

在极限情况$m_2 \ll m_1$下，上球保持静止，为了让下球上升到高度$l$，需要给它一个速度$v_0 = \sqrt{2 gl}$。

F836。扁平电容器的 A 板是静止的，B 板通过弹簧固定在墙壁上并且可以移动，并保持与 A 板平行（见图）。关闭K键后，板B开始移动并停在新的平衡位置。同时，板之间的距离减小$a_1=10\%$。如果开关 K 短时间闭合，板之间的平衡距离会改变多少？假设在此时间内板 B 没有时间明显移动。

当开关$K$闭合时，电容器的方向保持恒定并等于电源的电动势$\mathcal{E}$。令电容器极板之间的初始距离（弹簧未拉伸时）等于$d$，则极板B达到新平衡位置时的位移等于$x_1=a_1d=0,1d$。电容器上的电荷将为

$$Q_1 = C_1 \mathcal{E} = \frac{\varepsilon_0 S \mathcal{E}}{(d-x_1)},$$

其中$S$是电容器极板的面积。例如，电容器$E_1=\mathcal{E}/(d-x_1)$中的场。该场由两块板创建，因此由一块板创建的场的方向为$E_1/2$。据此，对于作用在板$B$上的力，我们可以写成

$$\frac{E_1 Q_1}{2} = \frac{\varepsilon_0 S \mathcal{E}^2}{2(d-x_1)^2} = kx_1$$

（k 是弹簧刚度）。

现在让我们考虑当钥匙$K$短时间关闭时的情况。在这种情况下，电容器会被污染

$$Q_2 = \varepsilon_0 S \mathcal{E}/d$$

（板块没有时间移动），随后保持不变。令板在新的平衡位置上的位移$B$等于$x_2$。那么电容器中的磁场方向将为$E_2 = Q_2/C_2(d-x_2)$，其中$C_2=\varepsilon_0 S/(d-x_2)$。板$B$的平衡条件将写成以下形式

$$\frac{E_2 Q_2}{2} = \frac{Q_2^2}{2\varepsilon_0 S} = \frac{\varepsilon_0 S \mathcal{E}^2}{2d^2} = kx_2.$$

由式（1）和式（2）我们求出$x_2$：

$$x_2 = x_1 \left(\frac{d-x_1}{d}\right)^2 = 0,081d,$$

也就是说，电容器极板之间的距离减少$a_2=8,1\%$。
