⟦folio 30⟧

数学上这个定律看起来像这样。让我们用 $I$ 表示某些频率为 1000 Hz 的声音的强度，用 $I_0$ 表示相同频率的声音的阈值强度。那么用白色表示的声音响度$L$强度$I$等于

$$L_6 = \lg \frac{I}{I_0},$$

以分贝为单位 -

$$L_{\lambda 6} = 10 \lg \frac{I}{I_0}.$$

频率为 1000 Hz 的声音可能是一个人进行安静谈话和一个人大声尖叫时发出的声音的一部分。在第一种情况下，声音强度约为 $10^{-8}$ W/m²，在第二种情况下 - $10^{-4}$ W/m²，第一个声音的音量为 40 dB，第二个声音的音量为 80 dB。然而，这并不意味着尖叫的音量是安静谈话的两倍。据说这两种声音比另一种声音大 40 分贝。顺便注意一下，1dB的音量差是人耳能够满足的最小音量差。

响度的通用单位是背景。上述对数定律成立，并且不仅适用于频率为 1000 Hz 的声音。但对于其他频率，参考阈值的强度是不同的。因此，例如，在大约 100 Hz 的频率下，它等于 $10^{-8}$ W/m²，即是 1000 Hz 频率的 $10^4$ 倍。根据响度公式，这意味着如果某个声音的音量处于 1000 Hz 的频率，则该声音的强度处于 1000 Hz 频率的参考阈值。

总之，以下是常见声音的几个响度值：

| 参考阈值 | 0 背景 |
| :--- | :--- |
| 耳语 | 20 |
| 安静的谈话 | 40 |
| 正常对话 | 50 |
| 大声交谈 | 60 |
| 街道噪音 | 70 |
| 尖叫 | 80 |
| Motorica 噪音（不含黏土剂） | 100 |
| 飞机发动机噪音 | 120 |
| 大误差幅度 | 130个背景 |
