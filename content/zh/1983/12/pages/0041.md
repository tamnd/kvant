N·I·阿维洛夫

◆ 假设集合M位于数轴上，由线段[a1, b1], [a2, b2], ..., [ak, bk]组成，a1 < b1 < a2 < b2 < ... < bk；这些段的长度由相应的 δ1、δ2、...、δk 表示。对于每对数字 i 和 j (1 ≤ i ≤ j ≤ k)，我们用 Mij 表示端点位于线段 [ai, bi], [aj, bj] 上的线段长度集合。这些集合显然在数轴上形成线段，如果 i = j，其长度等于 δi；如果 i < j，则长度等于 δi + δj。根据问题条件，线段长度之和不小于1。因此，δ1 + (δ1 + δ2) + ... + (δ1 + δk) + δ2 + (δ2 + δ3) + (δ2 + δ4) + ... + δk ≥ 1。

在不等式左边写的和中，每个 δj (j = 1, ..., k) 出现 k 次。因此，根据需要，k (δ1 + δ2 + ... + δk) ≥ 1，因此 δ1 + δ2 + ... + δk ≥ 1/k。

我们需要的机械系统如图 2 所示。这是两个质量为 m1 和 m2 的杆，位于光滑的水平面上，并通过刚度为 k 的弹簧连接。每个杆都配有一侧，允许其自由地向右移动，但不允许其向后移动。初始时刻的杆坐标用 x1 和 x2' 表示，其中 x2' = l + x2，l 是未钉住弹簧的长度。

让我们建立振动系统中电气量和机械量之间的对应关系。
