在源头我们会得到

$$\lambda_e = \frac{h}{P_e} = \frac{h}{\sqrt{2mE_K}} \approx 1.24 \cdot 10^{-10} \text{ m}.$$

如果求解器不知道“现成的”康普顿公式，那么就必须从方程中寻找电子动量，该方程表达了能量和动量守恒定律。但随之而来的问题是，什么公式描述了电子——相对论公式还是经典公式。在这种情况下，两种解给出了相同的结果，但是从一开始就使用经典公式时，有必要给出电子是非相对论性的合理结论。我们为挑战者提供自行完成任务的机会。作为参考，我们指出，静止质量为 $m$ 的粒子的动能 $E_K$ 和动量 $P$ 在相对论情况下通过对应关系相关

$$P^2 c^2 = E_K (E_K + 2mc^2),$$

由此，对于$E_K \ll mc^2$，可以得到经典对应$E_K = P^2/(2m)$。

最后，让我们指出这项任务远远超出了我们学校课程的范围。

我们不会在这里介绍这个问题的解决方案，该问题未包含在官方 Limpida 分数中。我们将其提供给读者进行独立分析。

实验任务

1) 图 9 显示了两个图。在第一个中，两个电压表都串联连接到电源，在第二个中，仅使用一个电压表。让我们用$U_1$、$U_2$和$U'_1$表示电压表的读数，用$I_1$和$I_2$表示电路中的电流。然后

$$U_1 + U_2 = \mathcal{E} - I_1 r, \quad U'_1 = \mathcal{E} - I_2 r.$$

注意

$$\frac{U_1}{U'_1} = \frac{I_1}{I_2}.$$

从这些信件中我们得到

$$\mathcal{E} = \frac{U_2 U'_1}{U'_1 - U_1}.$$

因此，为了确定源电动势，使用两个电路就足够了。

2) 电压表和电阻盒可以通过两种方式连接到电源（图10）。假设在实验过程中弹匣的电阻$R$发生变化，并且在每个值$R$处，显示的电压表$U$缺失。在 $a$) 的情况下，通过公式连接

$$\frac{1}{U} = \frac{1}{\mathcal{E}} \left( 1 + r \left( \frac{1}{R_V} + \frac{1}{R} \right) \right),$$

其中$r$和$R_V$分别是电源和电压表的内阻。这表明数量 $1/U$ 对 $1/R$ 的依赖性是线性的。根据实验数据，可以构造相应的图(图11,a)。使用图形的斜率和与普通轴的交点，确定值

$$k_1 = \frac{r}{\mathcal{E}} \text{ и } b_1 = \frac{R_V + r}{\mathcal{E} R_V}.$$

对于$6$）我们有对应关系

$$\frac{1}{U} = \frac{R_V + r}{\mathcal{E} R_V} + \frac{R}{\mathcal{E} R_V}.$$

这里，量$1/U$和$R$之间的关系是线性的。根据实验数据构建相应的图(图11,b)，并由此确定

$$k_2 = \frac{1}{\mathcal{E} R_V} \text{ и } b_2 = \frac{R_V + r}{\mathcal{E} R_V}.$$

因此，通过实验我们可以找到以下参数：

$$k_1 = \frac{r}{\mathcal{E}}, \quad k_2 = \frac{1}{\mathcal{E} R_V} \text{ и } b = b_1 = b_2 = \frac{R_V + r}{\mathcal{E} R_V}.$$

从这里开始，对于 $\mathcal{E}$、$r$ 和 $R_V$，我们获得了各有两个正解的二次方程。因此，所提出的没有附加数据的方法不允许我们明确地确定排除的值。
