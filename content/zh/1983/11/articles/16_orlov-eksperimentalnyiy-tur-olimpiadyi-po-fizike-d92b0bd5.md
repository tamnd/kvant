物理奥林匹克实验之旅

教育科学候选人
奥尔洛夫

第十七届中小学生物理奥林匹克全能决赛最后一轮的实验任务在维尔纽斯的三所大学进行：八项经典在教育学院进行，九项经典在维尔纽斯大学进行。 V. Kapsuk，土木工程学院十年级学生。这些学院物理系的老师参与了习题的准备。特别值得注意的是拟议任务的作者：A. Kiveris、A. Medeišis、A. Brilingas 和 J. A. Semenov。

我们介绍了所有实验任务的条件以及奥林匹克学生提出的解决方案的选项。

八年级
任务1
1) 研究物体在装有水的管子中的运动速度与管子倾斜角度的依赖性，并绘制这种依赖性。
2) 估计身体和管壁与水之间的摩擦系数。
3) 假设物体在液体中移动时受到的阻力成正比

图 2.

速度：$F_c = \alpha v$，确定比例系数$\alpha$。

设备：装有水的玻璃管和身体（给出身体的体积和密度）、尺子、三脚架、秒表、方格纸、数学表。

实验表明，只有在管子达到某个最小倾角$\beta_0$后，身体才开始移动。让我们将牛顿第二定律应用到这个极限情况，该定律以坐标轴 (图 1) 的投影形式表示：

$$F_A \sin \beta_0 - F_{\tau p} - mg \sin \beta_0 = 0,$$
$$F_A \cos \beta_0 - mg \cos \beta_0 - N = 0.$$

考虑到$F_{\tau p} = \mu N$，我们得到

$$(F_A - mg) \sin \beta_0 = \mu (F_A - mg) \cos \beta_0,$$

由此我们可以求出物体与管壁与水之间的摩擦系数：

$$\mu = tg \beta_0.$$

当管子的倾斜角度$\beta$大于$\beta_0$时，物体开始匀速运动。但由于出现了与速度成正比的阻力，根据经验，身体很快就会达到恒定速度。通过公式$v = l/t$很容易确定，其中$l$是物体以稳定速度行驶的路径长度，$t$是运动时间。通过以这种方式测量物体在不同倾斜角$\beta$下的速度，可以构建依赖关系$v = v(\beta)$的实验图。在 图 2 中，该图显示为蓝色。

将实验曲线与理论曲线进行比较的学生可以获得加分。让我们写出关于物体以任意角度$\beta$和角度$\beta = \pi/2$运动的情况的牛顿第二定律：

$$(F_A - mg) \sin \beta - \mu (F_A - mg) \cos \beta - \alpha v = 0,$$
$$F_A - mg - \alpha v_{\pi/2} = 0.$$

从这里

$$v = v_{\pi/2} (\sin \beta - \mu \cos \beta) = v_{\pi/2} \frac{\sin(\beta - \beta_0)}{\cos \beta_0}.$$

从图形上看，这种依赖性显示在 图 2 黑线上。

对于垂直方向的物体，系数$\alpha$很容易确定：

$$\alpha = \frac{V(\rho_0 - \rho) g}{v_{\pi/2}}.$$

其中$V$是物体的体积，$\rho$和$\alpha$是水和相应物体的密度。

由于主体的不对称性，以及周围流动条件的不同，当管子翻转时，系数$\alpha$可能会变得不同。那些研究了这个并发现$\alpha$的两个含义的人会得到额外的分数。确实，正如经验所表明的那样，值的差异在测量误差范围内。

任务2
1) 确定弹簧刚度和玻璃与玻璃之间的摩擦系数。
2) 使用垂直“myakkoo 减震器”装置，确定球和弹簧第一次碰撞期间球的能量损失。

3) 对于球从管的顶部落到弹簧上的情况，绘制球的加速度在垂直轴上的投影图，作为距顶部点的距离的函数。

设备：稳定器弹簧、玻璃管、已知质量的稳定器球、直尺、方格纸。

确定弹簧刚度并不困难：$k = mg/\Delta l$，其中$\Delta l$是将球放置在弹簧上时弹簧的变形（为了稳定性，将弹簧放置在垂直玻璃管中）。为了使用公式$\mu = tg \beta_0$（其中$\beta_0$是开始滑动的最小倾斜角）确定稳定球在玻璃上的滑动摩擦系数，需要迫使球沿着玻璃滑动。为此，例如可以将球夹在弹簧线圈之间。有人利用弹簧稳定的特点，（用同样的方法）测定了弹簧在玻璃上的滑动摩擦系数。

大多数小狗通过表达式$\Delta E = mg(h_2 - h_1)$确定球的能量损失，其中$h_2$和$h_1$是球在桌子上方的最终和初始高度（即球与弹簧第一次碰撞之后和之前）。有些人通过弹簧的最大斜率来定义能量。

当绘制球加速度在垂直轴上从球到管顶部点 (图 3) 的距离 $x$ 的投影 $a_x$ 的依赖性时，主要缺点是该问题的纯理论解决方案：

$$a_x = g - \frac{k}{m} (x - x_0) = g - \frac{k}{m} \Delta x = g \left(1 - \frac{\Delta x}{\Delta l}\right).$$

事实上，考虑到调整后的比例，所有点都应该在更改相应值后绘制在图表上。

不幸的是，大多数小狗仅限于球落到弹簧上的一个周期，而球在与弹簧相互作用后弹开并上升到一个新的高度，再次下降，掉落弹簧，再次上升，等等，直到完全停止。有必要在图表上显示所有这些点。

整体评价8年级的作业，应该说很有趣，但是作业量很大。没有人完全完成所有任务。最好的成绩（2.1 分，满分 3 分）由 D. Kalavinskaya 和 G. Mechetsos（维尔纽斯）获得。典型的缺点是：仅执行一次测量、报告稀疏、缺乏实验数据表格以及测量误差的不正确确定（有时只是缺乏）。

九年级

任务1

确定未知液体的比热容。

设备：热衬容器（恒温器）、末端有气泡的毛细管、电阻器、装有水和非恒星液体的容器、更换圆筒、带端子的板、方格纸、原电池组、电容器、电线、板。

在完成本次作业时，同学们遇到了一些问题：

a) 没有温度计如何改变温度？

b) 没有秒表如何计算电流的能量？

b) 如何消除温控器的未知热容量？

d) 如何评估盛有液体的容器向周围空间的传热？

只有正确回答这些问题，才能选择最佳的工作方法。

a) 要测量温度，您需要制作气体温度计。为此，用手加热末端带有气泡的毛细管，并将毛细管末端放入水中，使毛细管水进入其中。水柱下气泡中的空气体积与毛细管所在介质的绝对温度成正比：

$$\frac{V}{V_0} = \frac{T}{T_0} \Rightarrow \Delta T = \frac{\Delta V}{V_0} T_0.$$

无法使用环境电流温度公式$W = U^2 t/R$，因为电阻值未知。

电阻$R$，没有秒表。为此，需要将电容器从外部电容$C$充电到外部电压$U$，然后将其放电到电阻器（图4）中，放入装有液体的恒温器中，并且该过程应重复$n$次。那么电流的能量

$$W = n \frac{CU^2}{2}.$$

c) 将电阻放入装有水的恒温器中，然后用具有比热的液体，将电容器放电一定次数，并写出每种情况的能量守恒定律：

$$n_1 CU^2/2 = C_T \Delta T_1 + c_B Q_B V_B \Delta T_1,$$
$$n_2 CU^2/2 = C_T \Delta T_2 + c_x Q_x V_x \Delta T_2,$$

其中$c_B$、$Q_B$、$V_B$为恒温器中水的比热、密度和体积，$c_x$、$Q_x$、$V_x$为液态液体的相应参数，$C_T$为恒温器的热热量。

为了简化，我们可以选择$n_1$和$n_2$的值，使得温度变化$\Delta T_1$和$\Delta T_2$在一般实验中相同（$\Delta T_1 = \Delta T_2 = \Delta T$）。您还可以将等体积的液体倒入恒温器中 ($V_B = V_x = V_\text{ж}$)。然后，排除恒温器的热量，我们得到液体的比热

$$c_x = c_B \frac{Q_B}{Q_x} - \frac{CU^2/2(n_1 - n_2)}{V_\text{ж} \Delta T_\text{ж}}.$$

然而（由于要达到相同的温升并不那么容易），更有利的做法是设置相同的电流能量，即相同的开关次数$n$。在这种情况下

$$c_x = c_B \frac{Q_B}{Q_x} + \frac{nCU^2/2}{Q_x V_\text{ж} \Delta T_2} - \frac{nCU^2/2}{Q_B V_\text{ж} \Delta T_1}.$$

如果两种方法都能正确估计液体（酒精）的比热，则认为它们是正确的。

d) 为了估计最佳开关次数（$n=1$ - 显然很少，$n>100$ - 显然很多），估计恒温器（即周围空间中的热传感器）中的液体明显冷却的时间是有用的。此外，为了确定电容器所需的开关频率，估计电容器的放电时间（即其电容和电阻器的电阻）也很重要。

在执行这项任务时，G. Baranauskaya (Shlya)、A. Korol (Novokuznetsk) 和 S. Orlov (莫斯科) 表现出了更好的结果。

缺点特点：忽视恒温器的热容量、电容器的单一放电以及液体进入容器的运动不足。

10年级
任务1
确定电流源的电动势和内阻。
设备：正在研究的电流源、具有已知电动势和已知内阻的电流源、镍铬合金丝螺旋、用于测量电流的更灵敏的非辐射装置、连接线。
该作业的第一部分与 9 年级的第二部分作业没有什么不同。
要测量电流源 $r_x$ 的未知内阻，应首先将带有分流器 ($R_1$) 和附加电阻 ($R_2$) 的检流计连接到所研究的电源，然后再连接到已知电源：
$$I_3 = \frac{\mathcal{E}_x}{r_x + \frac{R_r R_1}{R_r + R_1} + R_2}, \quad I_4 = \frac{\mathcal{E}_x}{r + \frac{R_r R_1}{R_r + R_1} + R_2}.$$
从这里开始，合理地忽略电阻$R_r R_1/(R_r + R_1)$（因为它远小于$R_2$），即可找到所需值$r_x$。
A. Gnilovskaya（列宁格勒）提出了同时确定$r_x$和$\mathcal{E}_x$的方法。将检流计连接到带有分流器的已知源，首先附加电阻，然后附加电阻$R$，使得第二种情况下检流计的读数比第一种情况小两倍：$I_2 = I_1/2$，我们得到$R = r$（从$R_r \ll R$开始）。现在，知道电阻 $R$ 的值，连接分流器和附加电阻 $R$，以及不将其连接到未知源：
$$I'_2 = \frac{\mathcal{E}_x}{r_x + R}, \quad I'_1 = \frac{\mathcal{E}_x}{r_x},$$
在哪里
$$r_x = \frac{I_2}{I_1 - I_2} R, \quad \mathcal{E}_x = I_1 r_x.$$

为了确定$\mathcal{E}_x$，需要知道当前$I_1$的绝对值。为此，您需要照射检流计，要知道当设备完全偏转而没有连接到已知源的附加电阻时，电流强度等于 $I = \mathcal{E}_x/r$。
