定理。如果 $a - a$ 是 $n$ 次的等数数，则存在一个数 $c_0 > 0$，使得对于任何 $p \in \mathbb{Z}$ 和 $q \in \mathbb{N}$ 其中 $a \neq p/q$，我们有

$$\left| a - \frac{p}{q} \right| \geq \frac{c_0}{q^n}.$$

证明。上面考虑了 deg($\alpha$) $\geqslant 2$ 的情况。现在让 deg($\alpha$) = 1，即 $a = a/b$ ($a \in \mathbb{Z}$, $b \in \mathbb{N}$)。那么数字 $c' = 1/b$ 具有所需的属性。事实上，如果$a/b \neq p/q$，则$|pb - qa| \geqslant 1$。因此，

$$\left| a - \frac{p}{q} \right| = \left| \frac{a}{b} - \frac{p}{q} \right| = \frac{|pb - qa|}{bq} \geqslant \frac{1}{bq} = \frac{c'}{q}.$$

选择$c$和$c'$中最小的一个作为$c_0$，我们就得到了所需的不等式。

刘维尔定理也可以通过使用拉格朗日定理研究差异 $P(\alpha) - P(p/q)$ 来证明（“代数和分析原理 9-10”，第 25 段）。试试这个！

代数有理数的近似

如果对于某个常数 $\gamma$ 存在无限多个有理分数 $p/q$ 满足不等式，我们会说数字 $a$ 承认 $m$ 阶的近似

$$0 < \left| a - \frac{p}{q} \right| < \frac{\gamma}{q^m}.$$

刘维尔定理表明，度数$n$的代数数不允许阶数为$m$的近似，那么从（1）和（2）我们可以得到对于无限自然数序列$q$

$$\frac{c}{q^n} < \frac{\gamma}{q^m}, \frac{1}{q^{m-n}} > \frac{c}{\gamma},$$

对于 $m > n$ 和足够大的 $q$ 来说，这种不等式是不可能的。

超越数的示例 *)

我们现在有一种构造非代数实数的方法。 （这样的数称为超越数。）有必要构造一个可以近似于任意高阶的数。我们将这样的数字指定为无限小数：$\alpha = 0$，$a_1 a_2 a_3 \dots$，其中$a_i = \begin{cases} 1, \text{ если } t = m! \text{ (m = 1, 2,...)}, \\ 0, \text{ если } t \neq m!. \end{cases}$

尤其，

$$a_1 = a_2 = a_6 = a_{24} = a_{120} = a_{720} = \dots = 1,$$

$$a_3 = a_4 = a_5 = a_7 = \dots = a_{23} = a_{25} = \dots = a_{119} = a_{121} = \dots = 0.$$

那么对于任意 $m > 1$

$$\alpha = 0, a_1 \dots a_{(m-1)!} + 0, 0 \dots 0_{am!} = \frac{p_m}{q_m} + \beta_m,$$

在哪里

$$p_m = a_1 a_2 \dots a_{(m-1)!},$$

$$q_m = 10^{(m-1)!}, \beta_m = 0, 0 \dots 0_{am!} \dots,$$

$$0 < \beta_m = 10^{-m!} \cdot a_m! \dots =$$

$$= 10^{-m!} \cdot 1, \dots < 2 \cdot 10^{-m!} = \frac{2}{q_m^m}$$

因此，

$$0 < \left| a - \frac{p_m}{q_m} \right| < \frac{2}{q_m^m}, \quad m = 1, 2, \dots,$$

这意味着 $a$ 允许任意高阶的近似，因此不能是代数。
