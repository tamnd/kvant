除以首项：$\frac{-2x^3}{x^2} = -2x$ - 我们得到商的下一项，等等）

我们很“幸运”——我们被无影无踪地分开了。因此，方程（2）被改写为
$$\frac{(x^2-x+1)(x^2-2x-2)}{(x+1)(x^2-x+1)} = \frac{2}{3x-1},
$$
$$\frac{x^2-2x-2}{x+1} = \frac{2}{3x-1}$$

并轻松匹配方程
$$x(x-3)(3x+2) = 0.$$
回答。 $\{0, 3, -\frac{2}{3}\}$。
$$\frac{2}{x+1} + \frac{4}{x-2} - \frac{2}{x} + x+4 = 0.$$ (3)

您可以立即去掉分母并因式分解所得四次方程的左侧。然而，直接对方程（3）的左侧进行因式分解会更容易。请注意，数字 1 是其根。在 $x=1$ 处，左侧的五项取值为 1、-4、-2、1 和 4。让我们通过从每一项中减去其在 $x=1$ 处的值来变换该方程：
$$\left(\frac{2}{x+1}-1\right) + \left(\frac{4}{x-2}+4\right) +
\left(-\frac{2}{x}+2\right) + (x-1) + (4-4) = 0$$
（添加项的总和为零）。让我们执行每个括号中的操作：
$$-\frac{x-1}{x+1} + \frac{4(x-1)}{x-2} + \frac{2(x-1)}{x} + (x-1) = 0.$$
因子$x-1$出现在每一项中。这并不奇怪 - 毕竟 $x=1$ 处每一项的值必须为零！现在问题已简化为求解方程
$$-\frac{1}{x+1} + \frac{4}{x-2} + \frac{2}{x} + 1 = 0.$$
不难猜出它的根源之一：$x=-2$并再次应用相同的示例：
$$\left(-\frac{1}{x+1}-1\right) + \left(\frac{4}{x-2}+1\right) +$$

$$+\left(\frac{2}{x}+1\right) + (1-1) = 0,$$
或者
$$-\frac{x+2}{x+1} + \frac{x+2}{x-2} + \frac{x+2}{x} = 0,$$
从哪里 $x=-2$ 或
$$-\frac{1}{x+1} + \frac{1}{x-2} + \frac{1}{x} = 0,$$
$$\frac{x^2+2x-2}{x(x+1)(x-2)} = 0.$$
求解二次方程，我们找到剩余的根。

回答。 $\{1, -2, -1-\sqrt{3}, -1+\sqrt{3}\}$。
$$(x^2+3x-2)^2 + 3(x^2+3x-2) - 2 = x.$$ (4)

请注意，如果 x 是方程的解
$$x^2+3x-2=x,$$
则满足式(4)。因此，我们知道方程（4）的两个根：$x_1 = -1-\sqrt{3}$和$x_2 = -1+\sqrt{3}$。打开括号并将$x$移至左侧，我们得到方程
$$x^4+6x^3+8x^2-4x-4=0.$$
它的左侧可以被$x-x_1$和$x-x_2$整除，因此也可以被$(x-x_1)(x-x_2) = x^2+2x-2$整除。以一种方式除以，我们得到 $(x^2+2x-2)(x^2+4x+2) = 0.$
回答。 $\{-1+\sqrt{3}, -1-\sqrt{3}, -2+\sqrt{2}, -2-\sqrt{2}\}$。

总之，我们求解方程组
$$\left\{ \begin{array}{l} (x+1)(13x-2y-15) - 2(y-1)(3y+2) = 0, \\ (x+1)(x+4y-15) - 28(y-1) = 0. \end{array} \right.$$ (5)

很容易看出对$(-1; 1)$满足它。找到另一双$(1; 0)$并不难。
