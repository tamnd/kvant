因式分解

物理和数学科学候选人 S. V. FOMIN

在学校里，你经常需要处理代数方程。六年级学生已经可以解线性方程了。在乡村课堂上，学生们学习了求解二次方程的公式。 16 世纪发现的用于求解三次方程和​​四次方程的相当繁琐的公式在实践中几乎没有什么用处（参见 S. G. Gindikin 的书“关于物理学家和数学家的故事”（M.，“Nauka”，1981））。一般情况下的五次及以上方程在 Radiacalx 中是不可解的。

然而，在许多情况下，$n>2$ 次方程很容易求解。大多数情况下，保理会有所帮助。从“数$a$是多项式$P(x)$的根当且仅当$P(x)$能被$x-a$整除”和代数基本定理（«Kvant»，1982年，第4期）得出结论，每个具有实数系数$n>2$的多项式在乘积中都是无序的一次因子和不可分解的平方三元组。

让我们解一些方程。

$$2x^3 - x^2 - 7x + 2 = 0.$$

(1)

等式(1)左边的多项式具有整数系数。很容易证明，如果这样的方程有一个整数根，那么这个根是自由项的除数（证明它！）。数字2是方程(1)的根。这意味着多项式 $2x^3 - x^2 - 7x + 2$ 可以被 $x-2$ 整除。显然，偏方程是二次方程

首项系数为 2 的多重三项式，所以

$$2x^3 - x^2 - 7x + 2 = (x-2)(2x^2 + Bx + C),$$

其中$B$和$C$是未知的显示系数。这个等式对于所有 $x$ 都成立。通过点击$x=0$，我们得到$-2C=2$，$C=-1$。例如，通过部署$x=1$，我们得到$-(B+1) = -4$、$B=3$。

因此，方程（1）被改写为

$$(x-2)(2x^2 + 3x - 1) = 0.$$

回答。 $\left\{2, \frac{-3+\sqrt{17}}{4}, \frac{3\sqrt{17}}{4}\right\}$

$$\frac{x^4 - 3x^3 + x^2 - 2}{x^3 + 1} = \frac{2}{3x-1}$$

如果我们立即去掉分母，我们就得到一个五次方程。因此，“让我们试着数数”——让我们尝试看看是否可以减少左边的分数。对其分母进行因式分解：

$$x^3 + 1 = (x+1)(x^2 - x + 1).$$

分子不能被第一个因子整除（毕竟数字 - 1 不是多项式 $x^4 - 3x^3 + x^2 - 2$ 的根）。让我们尝试将其除以 $x^2 - x + 1$。当然，您可以再次应用“不定系数法”：

$$x^4 - 3x^3 + x^2 - 2 = (x^2 - x + 1)(x^2 + Ax + B) + C.$$

请用“角”除法更容易——就像我们用多位数字除以多位数字的方式一样：

$$\frac{x^4 - 3x^3 + x^2 - 2}{x^4 - x^3 + x^2 - 2} = \frac{x^2 - x + 1}{x^2 - 2x - 2}$$

$$- \frac{2x^3 + 2x^2 - 2x}{2x^2 + 2x - 2}$$

$$- \frac{2x^2 + 2x - 2}{0}$$

（我们将被除数的首项除以除数的首项：$\frac{x^4}{x^2} = x^2$ - 这将是商的首项。然后我们将商的结果项乘以除数，并从除数中减去乘积。接下来，我们再次除差的首项

我们很“幸运”——我们被无影无踪地分开了。因此，方程（2）被改写为
$$\frac{(x^2-x+1)(x^2-2x-2)}{(x+1)(x^2-x+1)} = \frac{2}{3x-1},
$$
$$\frac{x^2-2x-2}{x+1} = \frac{2}{3x-1}$$

并轻松匹配方程
$$x(x-3)(3x+2) = 0.$$
回答。 $\{0, 3, -\frac{2}{3}\}$。
$$\frac{2}{x+1} + \frac{4}{x-2} - \frac{2}{x} + x+4 = 0.$$ (3)

您可以立即去掉分母并因式分解所得四次方程的左侧。然而，直接对方程（3）的左侧进行因式分解会更容易。请注意，数字 1 是其根。在 $x=1$ 处，左侧的五项取值为 1、-4、-2、1 和 4。让我们通过从每一项中减去其在 $x=1$ 处的值来变换该方程：
$$\left(\frac{2}{x+1}-1\right) + \left(\frac{4}{x-2}+4\right) +
\left(-\frac{2}{x}+2\right) + (x-1) + (4-4) = 0$$
（添加项的总和为零）。让我们执行每个括号中的操作：
$$-\frac{x-1}{x+1} + \frac{4(x-1)}{x-2} + \frac{2(x-1)}{x} + (x-1) = 0.$$
因子$x-1$出现在每一项中。这并不奇怪 - 毕竟 $x=1$ 处每一项的值必须为零！现在问题已简化为求解方程
$$-\frac{1}{x+1} + \frac{4}{x-2} + \frac{2}{x} + 1 = 0.$$
不难猜出它的根源之一：$x=-2$并再次应用相同的示例：
$$\left(-\frac{1}{x+1}-1\right) + \left(\frac{4}{x-2}+1\right) +$$

$$+\left(\frac{2}{x}+1\right) + (1-1) = 0,$$
或者
$$-\frac{x+2}{x+1} + \frac{x+2}{x-2} + \frac{x+2}{x} = 0,$$
从哪里 $x=-2$ 或
$$-\frac{1}{x+1} + \frac{1}{x-2} + \frac{1}{x} = 0,$$
$$\frac{x^2+2x-2}{x(x+1)(x-2)} = 0.$$
求解二次方程，我们找到剩余的根。

回答。 $\{1, -2, -1-\sqrt{3}, -1+\sqrt{3}\}$。
$$(x^2+3x-2)^2 + 3(x^2+3x-2) - 2 = x.$$ (4)

请注意，如果 x 是方程的解
$$x^2+3x-2=x,$$
则满足式(4)。因此，我们知道方程（4）的两个根：$x_1 = -1-\sqrt{3}$和$x_2 = -1+\sqrt{3}$。打开括号并将$x$移至左侧，我们得到方程
$$x^4+6x^3+8x^2-4x-4=0.$$
它的左侧可以被$x-x_1$和$x-x_2$整除，因此也可以被$(x-x_1)(x-x_2) = x^2+2x-2$整除。以一种方式除以，我们得到 $(x^2+2x-2)(x^2+4x+2) = 0.$
回答。 $\{-1+\sqrt{3}, -1-\sqrt{3}, -2+\sqrt{2}, -2-\sqrt{2}\}$。
