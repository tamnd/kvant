常数变为变量

S.S.沃兰德

解释 $12 \rightarrow \infty$ 解的渐近行为。

（G. J. Lipkin，摘自“物理学家在开玩笑”集，M.，“Mir”，1966 年）

在严肃的数学著作中，在现代不同的情况下经常会遇到以下想法：固定变量并改变常量。在这篇文章中，我们将展示这个想法如何解决���题 M7996）：

找到方程的两个解
$$3^x + 3^{x^2} = 2^x + 4^{x^2}$$

并证明他没有其他解。

这个显然有效的方程似乎不太适合用初等方法求解。显然，这种方程可以从单调性消息中求解。例如，考虑问题 M799a) 的解：找到方程 $3^{x+1} + 100 = 7^{x-1}$ 的一个解，并证明它没有其他解。

您要查找的根很容易猜到：$x=4$（检查一下！）。并且没有其他解，因为将方程两边同时除以 $3^{x-1}$：

$$9 + 100 \cdot 3^{-x+1} = (7/3)^{x-1},$$

我们在左侧得到一个减函数 $x$，在右侧得到一个增函数。

然而，将单调性消息应用于方程（1）似乎很困难（当然，尽管不能排除这种类型的更微妙的推理可能实现目标的可能性）。事实上，方程 (1) 有两个解 - $x=0$ 和 $x=1$。如何证明他没有其他解决方案？

让我们尝试利用方程左右两边具有正结构的事实 $a^x + b^x$，并且两部分的碱基之和相同 $(a+b=6)$ - 多亏了这个，方程才有解 $x=1$。让我们将方程（1）写成以下形式
$$3^x + (6-3)^{x^2} = 2^x + (6-2)^{x^2}$$

并考虑函数$f(t) = t^x + (6-t)^{x^2}$（这是决定性的一点：在原始方程中我们固定变量并开始改变常数）。我们必须证明等式（3），即$f(3) = f(2)$，对于$x \neq 0$和$x \neq 1$是不可能的。为此，只要确定对于 $x$ 的每个值（除了 0 和 1），函数 $f(t)$ 都是单调的，至少在区间 $2 \leq t \leq 3$ 上是这样。

让我们找到一个任意（相对于$t!$）函数$f: f'(t) = xt^{x-1} - x^2(6-t)^{x^2-1}$，并证明它在区间 [2; 上保留其符号。 3]（在$x \neq 0$；1）。让我们分别看三种情况 - $x<0$、$0 < x < 1$ 和 $x > 1$。

在$x < 0$，显然是$f'(t) < 0$；因此，$f(t)$也杀死了$f(2) > f(3)$。

对于$0 < x < 1$和$t \leq 3$，我们有$6-t \geq 3$和$x^2(6-t)^{x^2-1} < x(6-t)^{x^2-1} \leq x3^{x^2-1} < xt^{x^2-1}$，即$f'(t) > 0$和$f(3) > f(2)$。

最后，在$x > 1$和$t \leq 3$
$$x^2(6-t)^{x^2-1} > x(6-t)^{x^2-1} \geq x3^{x^2-1} > xt^{x^2-1}$$
即$f'(t) < 0$和$f(2) > f(3)$。

因此，方程（3）（或（1））除了0和1之外没有其他根。

以同样的方式，我们可以证明任何 $a^x + (2k-a)^{x^2} = b^x + (2k-b)^{x^2}$ 与 $0 < a < b \leq k$ 和 $k > 1$ 形式的方程恰好有两个解 - 0 和 1（在我们的问题 $b=k=3$、$a=2$ 中）。

让我们基于相同的想法提出另一个解决方案���题 M7996)。 （有些读者发现了）。

方程 (1) 不存在负根是因为在 $x < 0$ $3^x < 2^x$ 且同时$3^{x^2} < 4^{x^2}$。对于$0 < x < 1$，考虑函数$g(t) = (t+1)^{x-1} - t^{x-1}$。因为$g'(t) = x((t+1)^{x-1} - t^{x-1}) < 0$，函数$g(t)$会杀死。因此，$g(3) = 4^x - 3^x < g(2) = 3^x - 2^x$。从 $4^x - 4^{x^2} = 4^x(4^x - 1) > 3^x(3^x - 1) = 3^x - 3^{x^2}$ 开始，不等式成立
$$3^x - 2^x > 4^x - 3^x > 4^{x^2} - 3^{x^2}.$$

波兹尼$3^x + 3^{x^2} > 2^x + 4^{x^2}$。结构 $x > 1$ 可以用类似的方式分析 - 不同之处在于，在 (4) 中我们得到的是符号 <，而不是符号 >。

总之，让我们提出一个类似但更复杂的问题：

方程$3^x + 3^{x^2} = 4^x + 2^{x^2}$有多少个解？
