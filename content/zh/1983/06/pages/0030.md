一般来说，形式的方程
$$x^2 - Dy^2 = 1,$$
(6)
其中$D$是一个自然数，不是平方$^*$)，称为佩尔方程；当然，这是一个丢番图方程，即具有整数系数的代数方程，其解在整数域中寻求。

如何解佩尔方程？
首先想到的是直接查找：交替地将数字$x = 1, 2, 3, \dots$代入公式$y = \sqrt{(x^2 - 1)/D}$，直到根式表达式变成精确的平方。下面这个显着的例子表明了这种方法的徒劳。方程
$$x^2 - 991y^2 = 1$$
有整数解，但其解 $(x_0, y_0)$ 中最小的 (!) $x_0$ 等于
379 516 400 906 811 930 638 014 896 080.
此外，在最强大的计算机上，它不是通过简单的暴力添加的！

事实证明，连分数为求解佩尔方程提供了一个非常方便的工具。让我们描述解决方案的算法（无需证明）。

对于除了整数平方之外的每个自然数$D$，方程（6）有无数个正整数$x, y$的解。所有这些都可以使用公式找到
$$x + y\sqrt{D} = (x_0 + y_0\sqrt{D})^k,$$
$k = 1, 2, \dots$,
其中$x_0, y_0$是具有最小值$y$的解。要找到最小解 $(x_0, y_0)$，您需要将 $\sqrt{D}$ 分解为整数。如果
$$\sqrt{D} = [a_0; a_1, \dots, a_n, 2a_0]$$
并且$\frac{p_n}{q_n}$是数字$\sqrt{D}$与数字$n$的合适分数，那么
$$p_n^2 - Dq_n^2 = (-1)^{n-1},$$
(7)
如果 $n$ 是奇数（周期的长度是偶数），那么
$$p_n = x_0, q_n = y_0$$
将是方程的最小解

*) 如果 $D = m^2$, $m \in N$，则方程 (6) 没有整数解 - 想想为什么。

尼尼·佩拉.如果周期为奇数（$n$为偶数），则通过以下公式找到最小解
$$x_0 + y_0\sqrt{D} = (p_n + q_n\sqrt{D})^2.$$
示例 3. 让我们对等式进行距离计算
$$x^2 - 7y^2 = 1.$$
由展开$\sqrt{7} = [2; 1, 1, 1, 4]$我们发现
$$\frac{p_3}{q_3} = 2 + \frac{1}{|1|} + \frac{1}{|1|} + \frac{1}{|1|} = \frac{8}{3}.$$
由于周期线是偶数，所以方程的最小解是$x_0 = 8, y_0 = 3$，自然数中的任何解都可以通过以下公式获得
$$x + y\sqrt{7} = (8 + 3\sqrt{7})^k,$$
$k = 1, 2, \dots$
对于$k = 2$，我们有$x = 127, y = 48$。
例 4. 求解方程
$$x^2 - 13y^2 = 1.$$
将$\sqrt{13}$展开为整数，我们得到$\sqrt{13} = [3; 1, 1, 1, 1, 6]$
和$\frac{p_4}{q_4} = 3 + \frac{1}{|1|} + \frac{1}{|1|} + \frac{1}{|1|} + \frac{1}{|1|} = \frac{18}{5}$。
周期的长度是偶数，所以通过公式找到最小解
$$x_0 + y_0\sqrt{13} = (18 + 5\sqrt{13})^2 = 649 + 180\sqrt{13},$$
即$x_0 = 649, y_0 = 180$。通用解决方案的形式为
$$x + y\sqrt{13} = (649 + 180\sqrt{13})^k,$$
$k = 1, 2, \dots$
问题 14. 找到方程的最小解
$$x^2 - 61y^2 = 1.$$
答案：$y_0 = 226 153 980$。
请注意，由于 L. Euler，英国数学家 Pell (1610-1685) 的名字被错误地与方程 (6) 联系在一起。在佩尔之前，这个方程由他的同事 J. Wallis 和 W. Bronker，以及法国人 P. Fermat 考虑过。至于公牛的阿基米德问题，直到1880年才得到解决。最小的解（*）包含41位数字，阿基米德问题中的公牛总数为$10^{206 545}!$。*）
