⟦folio 42⟧

当然，用周围的空气加热，但是由于密度较小，它们不会下降。传热仅通过热传导进行，对于液体和气体来说这是非常小的。

这意味着在夏天绑住这样的结构会导热不良，周围的土壤会稍微变暖。

因此，我们得出结论：由耐用材料制成的连接必须充满液体或气体。

最后一个问题仍然存在 - 我到底应该用什么来填充连接？在冬天，这都是一样的，因为在漫长的寒冷时期，地面温度将有时间上升到环境温度。在夏季，重要的是尽可能减少土壤升温。这意味着有必要选择在接收主体时升温最少的主体。由公式可知

$$Q = cm(t_2 - t_1)$$

我们发现温度$(t_2 - t_1)$的变化不仅取决于接收到的热量$Q$，还取决于物体的远程热容$c$及其质量$m$。

液体的质量总是大于相同体积的气体的质量。从这些报告来看，流动性部门优先。现在让我们使用已经提到的参考书来比较比热：

| 物质 | 比热，kJ/(kg·K) |
| :--- | :--- |
| 汽油 | 1,4 |
| 水 | 4,2 |
| 空气 | 1 |
| 甘油 | 2,4 |
| 煤油 | 2,1 |
| 机油 | 1,9 |

事实证明，液体的比热大于气体。

因此，连接处必须充满液体。但哪一个呢？水虽然最便宜、最容易获得，但并不适合，因为它在冬天会结冰。甘油和机油在低温下会变稠，导致对流困难。剩下的就是汽油和煤油。这两种液体在低于 -50°C 的温度下都会结冰，因此每种液体都能“承受”严重的冬季霜冻。然而，我们仍然选择煤油，因为它比汽油具有更高的比热并且便宜。

最后，我们可以制定问题的最终答案。

因此，为了减少永久冻土上建造的房屋数量，建筑物必须建在高跷上；领带由耐用的固体材料制成，内部必须充满煤油。

请注意，这种加固冻结地基（减少地基下土壤供应）的方法并不是幻想，而是现实。它经过了详细的理论开发，并在“违反”自然法则的任意操作条件下进行了测试。请听 A.P. Nechaev 在《没有奇迹的奇迹》一书中所描述的：

“……茶炊端上来了，锅盖下冒出蒸汽，开始泡茶，结果水凉了！”

我们只需补充一下，所描述的事件发生在 19 世纪末，当时的茶炊与现代电动茶炊不同，是燃煤的。
