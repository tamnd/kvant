很容易得出以下性质：

1) 前$s$索引不超过$l$（其余相同）的方格$K(i_1, i_2, \dots, i_s, i_{s+1}, \dots, i_r)$和$K(i'_1, i'_2, \dots, i'_s, i_{s+1}, \dots, i_r)$是单值；特别是，给定 $p$ 和 $q$ ($p, q \geqslant 0, p+q < N$) 单元格 $b_i = K(1, \dots, 1, i, \dots, i, l+1, \dots, l+1)$ (1)

所有 $i=1, \dots, l$ 具有相同的颜色；

2) 连接正方形 $K(i_1, i_2, \dots, i_r)$ 和 $K(j_1, j_2, \dots, j_r)$ 中心的向量等于 $d_1 A_{i_1} \vec{A}_{j_1} + d_2 A_{i_2} \vec{A}_{j_2} + \dots + d_r A_{i_r} \vec{A}_{j_r}$；特别是，对于单元格$b_i$和$b_j$（参见（1）），它等于$(d_{p+1} + d_{p+2} + \dots + d_{N-q}) A_i A_j$。

现在我们距离目标已经不远了。考虑以下 $N+1$ 单元格：

$K(l+1, l+1, l+1, \dots, l+1), K(1, l+1, l+1, \dots, l+1), K(1, 1, l+1, \dots, l+1), \dots, K(1, 1, 1, \dots, 1)$。根据狄利克雷原理，其中至少有两个是明确的。为了确定这一点，假设存在单元格 $b_1 = K(1, 1, 1, l+1, \dots, l+1)$ 和 $b_{l+1} = K(1, l+1, l+1, l+1, \dots, l+1)$（参见 (1) 和 $p=1, q=N-3$）。然后，根据属性 1) 和 2)，可以得出单元格 $b_1, b_2, \dots, b_{l+1}$（其中 $b_i = K(1, i, i, l+1, \dots, l+1)$）形成所需的单链系列（系数为 $d_2 + d_3$）。着色定理被证明。

如果您对这个主题感兴趣，我们建议您参考 A. Ya 的书。 Khinchin 的《数论三颗珍珠》，提供了 Van Waerden 级数定理的详细证明。

练习

1. 表明着色定理允许我们解决问题 M750 的所有点。

2. 证明如果范瓦尔登定理中的“算术”一词被“几何”取代，那么它仍然成立。 （顺便说一句，范德瓦尔登本人专门证明了他的几何级数定理。）

3. 证明对于任何 $n$ 以及将自然级数划分为 $N$ 类，至少其中一个包含长度为 $n$ 的 $n$ 算术级数，其中第一个形成几何级数。

4. 举一个将自然序列划分为两个子集的示例，两个子集都不包含：

a) 无限等差数列；

b) 既不是无限算术级数，也不是无限几何级数。

5. 给出一个用两种颜色对单元格进行着色的示例，其中不存在无限组垂直线和无限组水平线，在它们的交点处获得单链接单元格的中心。

6. 证明对于任何$k$颜色的单元格着色，存在无限组垂直线$\{x_i\}$和无限组水平线$\{y_i\}$（$i=1, 2, 3, \dots$），使得在线$y_i$和$x_j$的交点处，其中$i \geqslant j$，获得单链接单元格的中心。

DNA左手螺旋

（关于开头，请参见第 31 页）
正如之前所认为的，存在 B 型的可能性。

问题来了，如果在一个长DNA分子中（记住普通的长分子含有十进制核苷酸）有一个序列为... CHCH ... 的部分，会发生什么？

实验表明，在确定条件时，这样的区域确实呈Z型，尽管其周围的DNA仍保持其正常形式。有证据表明这在细胞内也是可能的。

左手螺旋的发现及其在“工作”DNA中存在的可能性引起了人们的极大兴趣。现在世界各地的许多实验室都在研究一种新的形式，即相应的 DNA 片段转移到其中的条件。科学家们正在试图弄清楚 DNA 的 Z 型和一般结构改变其结构在细胞中该分子的工作中所起的作用。

毫无疑问，未来几年该领域将会有更多有趣的发现。
