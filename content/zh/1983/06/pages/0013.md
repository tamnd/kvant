她说，它们装在杯子里使用很方便，这使得这样的解释成为可能。为了大大简化，我们可以说计算器将负数视为“虚数”，当在正数领域不可行时，可以方便地在中间计算中使用负​​数作为减法的结果。同时，重要的是要确保它们不违反“卫生规则”：您可以相信最终的肯定答案。没有讨论负数与正解是否相等：在最终答案中，除了最简单的情况外，没有出现负数。他们名字的各种版本都表明了人们对他们的表达态度：“虚假”、“虚构”、“荒谬”、“不可能”、“最小”。

然而，后一个术语后来不得不“让位于”另一类数字，令人惊讶的是，它与负数的第一次认真考虑同时出现在欧洲数学中。这位历史学家兼数学家是杰罗拉莫·卡尔达诺（Gerolamo Cardano，1501-1576）的模仿者，卡尔达诺是一位聪明而有争议的人物，对幻想和神秘主义有着高度的嗜好，这长期以来一直把他引向错误的方向。然而，一个更加实际和谨慎的人当时几乎不会决定卡尔达诺的数学结构。

卡尔达诺的主要成果涉及三次方程求解公式的研究，该公式首先由费罗（1465-1526）获得，卡尔达诺从塔尔塔利亚（1500？-1577）那里学到了这一公式（更多详细信息，请参阅我的书“物理和数学的故事”（M.，“科学”，1981））。

回想一下，一般三次方程 $x^3 + ax^2 + bx + c = 0$ 可以通过替换 $x = y - \frac{a}{3}$ 简化为以下形式

$$x^3 + px + q = 0.$$  (1)

我们将寻找 $x = y_1 + y_2$ 形式的方程 (1) 的解。然后$x^3 = y_1^3 + y_2^3 + 3xy_1y_2$。与(1)比较，若$y_1$和$y_2$满足等式$3y_1y_2 = -p$、$y_1^3 + y_2^3 = -q$，则$x = y_1 + y_2$是式(1)的解。这样$y_1$、$y_2$很容易求：如果$t_1 = y_1^3$、$t_2 = y_2^3$，则根据维埃塔定理$t_1$和$t_2$是二元一次方程$t^2 + qt - \frac{p^3}{27} = 0$的根，

即$t_{1,2} = -\frac{q}{2} \pm \frac{q^2}{4} + \frac{p^3}{27}$，

在哪里

$$x = \sqrt[3]{\frac{-q}{2} + \sqrt{\frac{q^2}{4} + \frac{p^3}{27}}} + \sqrt{\frac{-q}{2} - \sqrt{\frac{q^2}{4} + \frac{p^3}{27}}}$$  (2)

公式（2）现在被称为卡尔达诺公式。

现在让我们记住，卡尔达诺以正数来考虑大小。 （此外，他不知道代数符号，这使得事情变得异常困难，特别是在试图制定一般规则时。但是，我们不会在这里模仿这种类型的困难。） Posmotu Cardano 单独研究方程

$$x^3 + ax = b,$$  (3)

$$x^3 = ax + b,$$  (4)

$$x^3 + b = ax,$$  (5)

其中$a$、$b$为正。他没有考虑第四种可能的公式类型$x^3 + ax + b = 0$，因为这样的方程非常印度，没有（正！）根。

Del Ferro 提出了求解 (3) 的规则。塔尔塔利亚重新发现了这条规则，并提出了决策规则（4）；他以一首诗的形式制定了这两条规则，并将其传达给卡尔达诺。

说起来，烤箱以 $x = \sqrt[3]{u} \mp \sqrt[3]{v}$ 的形式寻求解决方案（减去（3），加上（4）），其中分别为 $u \mp v = b$，$uv = \left(\frac{a}{3}\right)^3$（参见（2））。
