M806—M810; F818—F822

M806。 a) 证明如果
$$a_1 + \frac{a_2}{2} + \frac{a_3}{3} + \ldots + \frac{a_n}{n} = 0,$$
那么多项式 $a_n x^{n-1} + a_{n-1} x^{n-2} + \ldots + a_2 x + a_1$ 的根在 0 和 1 之间。

6) 证明如果对于某些 $p > 0$
$$\frac{a_1}{p+1} + \frac{a_2}{p+2} + \frac{a_3}{p+3} + \ldots + \frac{a_n}{p+n} = 0,$$
那么这个多项式也有一个介于 0 和 1 之间的根。

A. Gokhbere、M. Ovetsky，十年级学生，顿涅茨克

M807。 a) 从等边三角形内的任意点$M$，垂线$MK_1, MK_2, MK_3$落在其侧面上。证明向量之和$\vec{MK}_1 + \vec{MK}_2 + \vec{MK}_3$等于$\frac{3}{2} \cdot \vec{MO}$，其中$O$是三角形的中心。

6) 从任意点 $M$ 垂线 $MK_1, \ldots, MK_n$ 落到正则 $n$ 边形（或其延长线）的所有边上。证明
$$\vec{MK}_1 + \ldots + \vec{MK}_n = \frac{n}{2} \vec{MO},$$
其中$O$是$n$边形的中心。

c) 从等边三角形内的任意点$M$，删除其面上的垂线$MK_1, MK_2, MK_3, MK_4$。证明
$$\vec{MK}_1 + \vec{MK}_2 + \vec{MK}_3 + \vec{MK}_4 = \frac{4}{3} \vec{MO},$$
其中 $O$ 是三角形的中心。

V·V·普拉索洛夫
