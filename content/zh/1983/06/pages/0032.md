高于

$$\frac{1}{3} \sqrt{D} (\ln D)^{-1},$$

因此，随着$k$的增加而快速增长。对大量数值材料的观察支持这样的假设：存在无限多个数字 $D$，不能被素数的平方整除，对于任何固定的正 $\varepsilon$，连分数周期 $\sqrt{D}$ 的长度超过 $D^{\frac{1}{2}} - \varepsilon$。

上面使用的结果是$4k+1$形式的素数$p$的连分数$\sqrt{p}$的周期具有奇数长度，这一结果由Legendre于1785年证明。后来，德国数学家狄利克雷对数$D=p \cdot q$建立了类似的定理，其中$p, q$是满足一定条件的素数。直到最近，即 1980 年，美国数学家 Lagaris 发现了一种算法，可以在大约 $(\log D)^{5+\varepsilon}$ 运算中确定方程 (9) 的数项可解性，或者等效地确定 $\sqrt{D}$ 连分数长度的奇数。

特定数字的连分数

我们在上面看到了平方无理数，只有它们可以展开为周期连续分数。因此，二次无理数的连续分数的结构具有一定的清晰度。人们自然会问哪些类别的其他无理数具有同样良好的可见展开式到连分数。这个问题没有令人满意的答案。

例如，对于数字 $\sqrt[3]{2}$ do схх，不完全分式 $a_0, a_1, a_2, \dots, a_k$，...其扩展为连分式是否会受到限制仍然未知

$$\sqrt[3]{2} = a_0 + \frac{1}{|a_1|} + \frac{1}{|a_2|} + \dots$$

前几千个数字$a_0, a_1, \dots$是在电脑上计算出来的

以下是其中的第一个：

$$\sqrt[3]{2} = [1; 3, 1, 5, 1, 1, 4, 1, 1, 8, 1, 14, 1, 10, 2, 1, 4, 12, 2, 3, 2, 1, 3, 4, 1, 1, 2, 14, 3, 12, 1, 15, 3, 1, 4, 534, 1, 1, 5, 1, 1, 121, 1, 2, 2, 4, 10, 3, 2, 2, 41, 1, 1, 1, 3, 7, 2, 2, 9, 4, 1, 3, 7, 6, 1, 1, 2, 9, 2, 3, 3, 1, 1, 69, 1, 12, \dots]$$

从这个分解中可以清楚地看出，序列 $a_0, a_1, \dots$ 表现为有限序列，只有某些地方的“异常值”（例如 534、121）违反了此图。

此外，直到 cxx 为止，还没有一个代数数不是平方无理数，关于其连分式会有足够的信息。

特别令人感兴趣的是新沙克经典常数的连续分数展开式。已知展开为连分数的此类常数的数量非常少。

L. 欧拉发现了数 $e$ 展开为连分数

$$e = 2 + \frac{1}{|1|} + \frac{1}{|2|} + \frac{1}{|1|} + \frac{1}{|1|} + \frac{1}{|4|} + \dots,$$

其中不完全商$a_0, a_1, \dots$的转换定律为：

$$a_0 = 2, a_1 = 1, a_2 = 2, a_3 = 1, a_4 = 1, a_5 = 4, \dots, a_{3m} = a_{3m-2} = 1, a_{3m-1} = 2m, m = 1, 2, \dots$$

让我们提醒您

$$e = \lim_{n \to \infty} \left(1 + \frac{1}{n}\right)^n = \sum_{k=0}^{\infty} \frac{1}{k!} = 2,718281828459045 \dots$$

对应关系（10）的推导虽然并不困难，但并不简单。请注意，没有人知道数字 π 的相同“良好”连分式展开式。

我们在这里只讨论了发生连分数的问题的一小部分。事实上，它们的应用范围非常广泛，特别是当运算符用于分析函数分数时。这是一个丰富而复杂的数学领域，而且还远未完成。
