存在无穷多个 $n$ 使得 $a) \sigma(n) > 2n;$ $6) \sigma(n) > 3n.$ 证明对于任意 $n$ $\theta)^{*}$ $\sigma(n) < n(\log_{2}n + 2);$ $2) \sigma(n) < n(\ln n + 1).$

除数可以写成

$$\sigma(n) = \frac{n}{d_{1}} + \frac{n}{d_{2}} + \dots + \frac{n}{d_{s}} = n \left( \frac{1}{d_{1}} + \frac{1}{d_{2}} + \dots + \frac{1}{d_{s}} \right).$$

其中$d_{1}, \dots, d_{s}$都是数字$n.$的约数，因此，值$\sigma(n)/n$等于有限序列$1, 1/2, \dots, 1/n$中的几个数字的总和，并且这个总和中包含的小值数字越多，它就会越大。

a) 让我们证明$\sigma(n) > 2n$对于任何$n = 6k$，其中$k > 1$（当然，这样的数字有无穷多个）。由于 $n$ 可以被 1, 2, 3, 6 和 $k$整除，从 (1) 我们得到

$$\sigma(n) \geq n \left( 1 + \frac{1}{2} + \frac{1}{3} + \frac{1}{6} + \frac{1}{k} \right) > 2n.$$

6) 令 $n$ 为任意乘积 $1 \cdot 2 \cdot 3 \cdot \dots \cdot 16 = 16!$ 的倍数。那么 $n$ 可以被 1 到 16 之间的所有自然数整除（我们已经有足够的这些约数）并且凭借 (1)

$$\sigma(n) \geq n \left( 1 + \frac{1}{2} + \left( \frac{1}{3} + \frac{1}{4} \right) + \left( \frac{1}{5} + \dots + \frac{1}{8} \right) + \left( \frac{1}{9} + \dots + \frac{1}{16} \right) \right) > n \left( 1 + \frac{1}{2} + \frac{1}{4} \cdot 2 + \frac{1}{8} \cdot 4 + \frac{1}{16} \cdot 8 \right) = 3n.$$

类似地，我们可以证明，对于任何 $a$，不等式 $\sigma(n) > an$ 对于无限组数字$n.$ 成立。还要注意，正如更准确的估计所示，在我们对 $a = 3$ 的证明中，除数是 16！可以换成7！

b) 由式(1)可知

$$\sigma(n) \leq n \left( 1 + \frac{1}{2} + \dots + \frac{1}{n} \right).$$

让我们估计右边的总和。让$2^{k} \leq n < 2^{k+1}$，然​​后$k \leq \log_{2}n$和$1 + \dots + \frac{1}{n} < 1 + \left( \frac{1}{2} + \frac{1}{3} \right) + \left( \frac{1}{4} + \dots + \frac{1}{7} \right) + \dots + \left( \frac{1}{2^{k}} + \dots + \frac{1}{2^{k+1}-1} \right) + \frac{1}{2^{k+1}} < 1 + \frac{1}{2} \cdot 2 + \frac{1}{4} \cdot 4 + \dots + \frac{1}{2^{k}} \cdot 2^{k} + 1 = k+2$，即$\sigma(n) < n \cdot (k+2) \leq n(\log_{2}n+2).$

d) 让我们用积分来估计不等式 (2) 中的和 $\frac{1}{2} + \dots + \frac{1}{n}$，与 c) 点中的不同。其中每一项$1/k$都可以表示为一个矩形的面积，该矩形的底边是轴$Ox$的线段$[k-1; k]$（见图），而这个矩形位于双曲线$y = 1/x$下方。因此，$k = 2, \dots, n$所有矩形的总面积小于由双曲线$y = 1/x$、轴$Ox$以及直线$x = 1$和$x = n$围成的曲梯形。因此，

$$\frac{1}{2} + \dots + \frac{1}{n} < \int_{1}^{n} \frac{dx}{x} = \ln n,$$

因此 $\sigma(n) < n(\ln n+1).$
