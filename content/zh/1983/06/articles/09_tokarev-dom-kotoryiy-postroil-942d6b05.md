那个房子...
托卡列夫

16世纪意大利杰出建筑师安德里亚·帕拉杜（Andrea Palladu）认为，每座建筑都必须遵守三件事，没有这三件事，任何价值都无法值得认可。这就是蠕变（和便利）、美观和耐用。让我们把便利和美观的信息放在一边，谈谈耐久性，或者换句话说，谈谈建筑物的可靠性。

也许你们每个人都知道，任何结构的建造都是从打地基开始的。良好、坚实的基础是进一步成功的关键。但这意味着什么——坚实的基础？

许多问题需要专家来解决。其中之一就是反对基金会定居点的斗争。当永久冻土上出现结构时，会出现与此问题相关的特殊困难。在那里建造的房屋经常因下面土壤沉降导致地基不均匀沉降而出现裂缝。

是否有可能避免永久冻土上建造的房屋下土壤的解冻，或者至少减少解冻？

让我们尝试仅基于最简单的物理定律和模式的知识来解决这个问题。

首先我们来分析一下问题发生的条件。为什么房子下面的土壤会开始融化？显然，因为地基向其传递了一些热量。所以一切都与基础有关。那么，首先要做的就是减少地基与地面的接触面积。正是出于这个目的，任务开始建立在连接之上，放弃了通常的坚实基础。但事实证明这还不够。

还有什么方法可以将 prioctella 减少到地面上呢？在这种情况下，prioctella仅通过热传导进行传播；因此，材料的导热性能尽可能差。领带应该由什么材料制成？

为了量化各种物质的导热系数，需要用到一个特殊的物理量——导热系数。每种物质的情况都不同。金属的导热系数最高，液体的导热系数为非 VELICA，气体的导热系数更低。根据我们的推理，具体如何并不重要

确定导热系数并以什么单位进行测量。我们只对比较不同材料的导热能力感兴趣。因此，我们将利用参考书*)，编制一个相对导热系数小表，选择水的导热系数作为单位：

| 物质 | 相对导热率 | 物质 | 相对导热率 |
| :--- | :--- | :--- | :--- |
| 汽油 | 0,2 | 铁 | 122 |
| 脱脂棉 | 0,07 | 煤油 | 0,2 |
| 水 | 1 | 砖 | 1,1 |
| 空气 | 0,04 | 冰 | 3,7 |
| 毛毡 | 0,1 | 软木 | 0,07 |
| 树 | 0,2—0,6 | 酒精 | 0,3 |

让我们仔细看看这张表。在固体材料中，棉绒和软木的导热性最好，其次是木材和砖。然而，首先，连接必须牢固，因此并非所有列出的材料都适合。如果连接由金属（例如铁）制成，并且内部放置有棉绒、毛毡或其他含有大量空气的多孔物质，该怎么办？这就是出路！

因此，粘结剂必须由耐用的硬质材料制成，并填充某种多孔物质。

分析得到的结果，我们做出选择：由于导热系数低，连接指定的结构实际上会减少温暖季节从周围空气到组（即从上到下）的热量流动。那么在寒冷的情况下呢？最好确保在冬天，在严重霜冻期间，绑定有助于冷却该组（即，它向上传递热量）。这将增加该群体的强度并减少其在夏季解冻的程度。

让我们更清楚地阐明新鲜土壤以及夏季和冬季土壤中发生的物理过程。温暖季节，上部清新，与空气接触，升温。渐渐地，地里的新鲜部分也会升温。新鲜的下端以及相邻组的加热越少越好。冬季，上部通过与冷空气的接触而得到新鲜的冷却。下部逐渐冷却，周围的团团新鲜。组冷却的温度越低越好。

因此，将 due 与以下属性联系起来：

a) 若上部温度高于下部温度，则说明桩导热不良；

b) 如果上端比下端冷，则桩应导热良好。

或者换句话说：

从上到下的热传递应该是差的，而从下到上的热传递应该是好的。

众所周知，在固体中，热传导仅由于热导率而发生，而与方向无关。这意味着具有上述属性的键不能由固体制成。我们之前的模型 - 填充多孔材料的金属连接 - 不适合（多孔“内部”不仅在夏季更有效地传导热量，而且在冬季也能更有效地传导热量，此时需要对组进行良好的冷却）。

但是，如果耐用的外壳是新的、能够承受重载、充满液体或气体怎么办？在这种情况下，热量传递不仅通过热传导进行，还通过对流进行。这会导致什么？

在冬天，上层液体或气体会冷却，并且密度更大，会下沉。这个地方将被密度较小的低等象占据，而低等象又会冷却、下沉等。结果，新鲜的象和它周围的象群会吸收周围空气的温度，也就是说，它们会因自然霜冻而变冷。在夏季，上层液体或气体将

当然，用周围的空气加热，但是由于密度较小，它们不会下降。传热仅通过热传导进行，对于液体和气体来说这是非常小的。

这意味着在夏天绑住这样的结构会导热不良，周围的土壤会稍微变暖。

因此，我们得出结论：由耐用材料制成的连接必须充满液体或气体。

最后一个问题仍然存在 - 我到底应该用什么来填充连接？在冬天，这都是一样的，因为在漫长的寒冷时期，地面温度将有时间上升到环境温度。在夏季，重要的是尽可能减少土壤升温。这意味着有必要选择在接收主体时升温最少的主体。由公式可知

$$Q = cm(t_2 - t_1)$$

我们发现温度$(t_2 - t_1)$的变化不仅取决于接收到的热量$Q$，还取决于物体的远程热容$c$及其质量$m$。

液体的质量总是大于相同体积的气体的质量。从这些报告来看，流动性部门优先。现在让我们使用已经提到的参考书来比较比热：

| 物质 | 比热，kJ/(kg·K) |
| :--- | :--- |
| 汽油 | 1,4 |
| 水 | 4,2 |
| 空气 | 1 |
| 甘油 | 2,4 |
| 煤油 | 2,1 |
| 机油 | 1,9 |

事实证明，液体的比热大于气体。

因此，连接处必须充满液体。但哪一个呢？水虽然最便宜、最容易获得，但并不适合，因为它在冬天会结冰。甘油和机油在低温下会变稠，导致对流困难。剩下的就是汽油和煤油。这两种液体在低于 -50°C 的温度下都会结冰，因此每种液体都能“承受”严重的冬季霜冻。然而，我们仍然选择煤油，因为它比汽油具有更高的比热并且便宜。

最后，我们可以制定问题的最终答案。

因此，为了减少永久冻土上建造的房屋数量，建筑物必须建在高跷上；领带由耐用的固体材料制成，内部必须充满煤油。

请注意，这种加固冻结地基（减少地基下土壤供应）的方法并不是幻想，而是现实。它经过了详细的理论开发，并在“违反”自然法则的任意操作条件下进行了测试。请听 A.P. Nechaev 在《没有奇迹的奇迹》一书中所描述的：

“……茶炊端上来了，锅盖下冒出蒸汽，开始泡茶，结果水凉了！”

我们只需补充一下，所描述的事件发生在 19 世纪末，当时的茶炊与现代电动茶炊不同，是燃煤的。
