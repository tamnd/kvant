四元数的定义

四元数是实数$(x; y; u; v)$的四元数，可以方便地写为

$$q = x + yi + uj + vk,$$

当四元数相乘时，情况更加复杂。如果 $q_1$ 和 $q_2$ 是标量四元数，则它们的乘积 $q_1 q_2$ 也是标量四元数。在$q_1 = x$是标量四元数且$q_2 = r$是向量四元数的情况下，乘积$q_1 q_2 = x \cdot (y_i + uj + vk) = (xy)i + (xu)j + (xv)k$是向量四元数，并且乘法运算与空间中的向量$r$与实数$x$的乘法一致。

最后，如果两个四元数都是向量：

$$q_1 = r_1 = y_1 i + u_1 j + vk$$
$$q_2 = r_2 = y_2 i + u_2 j + v_2 k,$$

那

$$q_1 q_2 = -(y_1 y_2 + u_1 u_2 + v_1 v_2) + (u_1 v_2 - v_1 u_2) i + (v_1 y_2 - y_1 v_2) j + (y_1 u_2 - u_1 y_2) k.$$

从最后一个公式可以看出，乘积$q_1 q_2$的标量部分等于向量$r_1$和$r_2$符号相反的标量乘积$(r_1, r_2)$。向量部分 $q_1 q_2$ 是我们的老朋友 - 向量乘积 $r_1 \times r_2$，用坐标表示（参见（4））。

结合所有考虑的情况，我们得到了四元数相乘的通用公式。若$q_1 = x_1 + r_1$且$q_2 = x_2 + r_2$，则

$$q_1 q_2 = (x_1 x_2 - r_1 \cdot r_2) + (x_1 r_2 + x_2 r_1 + r_1 \times r_2)$$

三胞胎呢？

为什么汉密尔顿没有找到一种令人满意的三胞胎乘法？不是因为构建不够或努力——我们在上面已经注意到，构建“三维数字”的问题无法解决。事实上，已经证明不存在满足我们要求的空间中点相乘的过程（结合性、坐标加法的分配性、除以非零元素的可能性）。此外，现在已经知道何时可以进行这种乘法的所有情况。

正如德国数学家 F. G. Frobenus (1849-1917) 证明的那样，存在三种情况：一维（正实数）、二维（复数）和“四维”（四元数）。

汉密尔顿和他随后对四元数的依赖。四元数预计会产生与复数相同的结果，甚至更好。事实上，在四元数微积分的帮助下，人们发现了具有完美数学美感的公式，描述了许多重要的物理现象。但进一步发展代数和函数四元数微积分的希望并未实现。

对于四元数，关于具有四元数系数的多项式的根存在性的代数主要定理不成立，但另一方面，存在一个变量中具有四元数系数的多项式，其中任何四元数都是其根。

乐观主义让位于怀疑主义。本世纪初，数学家不再对四元数感兴趣。但随着时间的推移，物理学家坚持不懈地寻找与所谓的基本粒子自旋相关的一些效应的数学公式。当四元数在构建量子物理学中使用的各种空间几何变换中的作用被理解时，四元数重新获得了认可。四元数的几何性质是我们希望在未来讨论的一个特殊的大话题。
