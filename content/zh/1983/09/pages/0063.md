4. 证明在自然级数中紧接大于三的素数之后不可能存在精确的平方。

10年级

1. 提出一组 1982 个成对不同的整数 $\{a_1, a_2, \dots, a_{1982}\}$，使得总和集 $S = \{a_1 + a_2, a_1 + a_3, \dots, a_{1981} + a_{1982}\}$ 包含尽可能少的不同数字。证明你找到的$S$不能包含更少的不同数字。

2. 证明方形三角形$f(x) = ax^2 + bx + c$可以表示为两个单调递增多项式的差。

3. 矩形$ABCD$位于以点$A$为圆心、半径为1的四分之一圆内。矩形的最大可能面积是多少？

4. 令 $2a, a + b, c$ 为整数。证明对于任何整数$x$，数字$ax^2 + bx + c$也是一个整数。

区市游
（按该地区和斯维尔德洛夫斯克市的地区）

七年级

1. 有两个容量分别为 9 升和 11 升的桶。如何使用它们将 10 升湖水倒入较大的湖中？

2. 证明如果
$$\frac{1}{a} + \frac{1}{b} + \frac{1}{c} = \frac{1}{a+b+c},$$
然后$(a^3 + b^3)(a^3 + c^3)(b^3 + c^3) = 0$。

3. 两个 lutzes 从点 $O$ 出现。仅使用指南针检查它们之间的角度是否等于 $72^\circ$。

4. 找到所有满足等式 $2^m + 1 = n^2$ 的自然数 $m$ 和 $n$。

八年级

1. 令$n$和$k$为自然数（$k \leq n$），$[a; b], [a_1; b_1], [a_2; b_2], \dots, [a_n; b_n]$为数轴上的线段。已知对于任何点$x \in [a; b]$，包含点$x \in [a; b]$的线段$[a_i; b_i]$的数量等于$k$。证明对于任意 $i = 1, 2, 3, \dots, n$ $[a; b] \subset [a_i; b_i]$。 （假设对于任何 $i$ $[a; b] \cap [a_i; b_i]$ 都不为空。）

2. 证明$a^4 + b^4 \geqslant 1/8$如果$a + b \geqslant 1$。

3. 证明在凸四边形中，对角线长度之和大于连接对边中点的线段长度之和。

4. 自然数$n$使得数字$2n + 1$和$3n + 1$是某些自然数的平方。证明数字$n$能被8整除。

九年级

1. 玫瑰花呈圆形，直径100m。其中任意两棵树之间的距离大于10m。证明玫瑰树的数量不超过 121 棵。

2. 证明方程组
$$\begin{cases} x^3 + y^2 = 2, \\ x^2 + xy + y^2 - y = 0 \end{cases}$$
无实数解。

3. 设凸四边形$ABCD$中的点$M$和$N$为对角线$AC$和$BD$的中点。用向量 $AD$ 和 $CB$ 表达向量 $MN$。

4. 求一个四位自然数，其前两位和后两位相同，并且是该自然数的平方。

10年级

1. 给定一个数值区间 $a; b$ [ 和一系列区间 $]a_1; b_1|, ]a_2; b_2|, \dots, ]a_n; b_n|, вложенных в $a； b$. Извести, что для любой точки $x \in ]a; b$ [ число интервалов $]a_i; b_i|包含它是奇怪的。证明$n$是奇数。

2. 证明我的行动的观点

$$\frac{1}{\cos 0 \cos x} + \frac{1}{\cos x \cos 2x} + \dots + \frac{1}{\cos 9x \cos 10x} = \frac{\mathrm{tg} 10x}{\sin x}$$

3. 指出单位面积的对角线和最小的凸四边形必须满足哪些充分必要条件。

4. 找到所有满足等式 $2^m + 1 = n^{k+1}$ 的自然数 $m, n$ 和 $k$。
