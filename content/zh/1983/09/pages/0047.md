让我们解释一下 K 应该如何发挥才能获得这些位置。

a) 令 a 和 a' 分别为玩家 K 和 C (图 2) 着色的第一个单元格。在第二次移动中，K 个单元格 b 与 a 位于同一列，因此单元格 b 和 a 之间的距离大于 a' 和 a 之间的距离。响应移动 C 后，同一列的单元格 c 和 c₁ 之一（参见 图 2），例如 c，将保持不着色。第三步中它被 K 着色。类似地，在第四步中，K 个颜色单元格 d 或 d₁。假设他给 d 着色，然后考虑包含单元格 e、f、g 和 h 的列。例如，其中一个包含 e，不包含蓝色单元格，因为只有四个蓝色单元格，并且其中之一 - a' - 不包含在这些列中。通过给 e 着色，玩家 K 将获得位置 图 1, ​6（图 2 上的方格 a、b₁ c 和 e）。

6), c) 玩家 K 首先为一排的 N 个单元格着色，而不注意它们之间的距离（数字 N 取决于 k；我们将在下面澄清）。然后，在第一行下，K选择没有蓝色单元格的行，并将其中第一行红色单元格正下方的单元格着色（只要其中还有一些未着色的红色或蓝色）。在第二行下，K 选择第三个（没有蓝色单元格），并对第二行红色单元格下方的单元格进行着色，以此类推。以这种方式填充了 n 行（稍后我们将确定数字 n），K 必须选择一条沿着所有彩色单元格（红色和蓝色）下方的单元格对角线 (图 3) 穿过的直线 l，并在其上为正好位于最后一个第 n 行的单元格下方的 k + 1 个单元格着色。由于每个新的红细胞都有 k 个蓝色细胞，因此第 n 行有 k²+k+1 个红细胞就足够了。 （然后，响应于第 l 行的前 k 个单元格（由 K 着色），C 将为 k² 个单元格着色，之后至少还有一个未着色的单元格将保留在第 l 行第 n 行的红色单元格下方。）第 l 行的红色单元格，连同位于其上方的 n 行之一的单元格以及该线与第 l 行交叉点处的单元格 a (图 3)，并形成图 1 中所示的获胜“楔形”， a.只需选择这一行，使单元格 a 及其下面的所有单元格都不是蓝色的。如果线间隙 n 大于线 l 上及其下方的蓝色单元格的数量（例如，当 n=n²+k+1 时，不超过 (k+1)k=k²+k），则始终可以完成此操作。

因此，数字 N 必须足够大，以便玩家 K 可以按照指示的方式填充 n=k²+k+1 行，并为最后一行中的 n 个单元格着色。我们可以取N=(k+1)ⁿ·k+1。事实上，正如我们所看到的，为了让 K 将第 l 行上的 k+1 个单元格着色，需要将第 n 行中的 (k+1) k+1 个单元格着色为红色；同样证明，要发生这种情况，第 (n−1) 行必须包含 (k+1)²·k+1 个红细胞，第 (n−2) 行必须包含 (k+1)3·k+1，...，第一行必须包含 (k+1)ⁿ·k+1 个红细胞。
