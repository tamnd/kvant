问题解决方案

M806—M810; F818—F822

M806。 a) 证明如果$a_1 + \frac{a_2}{2} + \frac{a_3}{3} + \ldots + \frac{a_n}{n} = 0$，则多项式$a_n x^{n-1} + a_{n-1} x^{n-2} + \ldots + a_2 x + a_1$有0到1之间的根。

b) 证明如果对于某些 $p > 0$

$$\frac{a_1}{p+1} + \frac{a_2}{p+2} + \frac{a_3}{p+3} + \ldots + \frac{a_n}{p+n} = 0,$$

那么这个多项式也有一个介于 0 和 1 之间的根。

让我们首先证明以下陈述：如果可微函数$f(x)$在点$x = 0$和$x = 1$处变成域，那么它的导数必须在从零开始的某个内部点处变成域，因此，在位于线段[0;内的点$x_0$处取导数； 1]。

如果函数 $f(x)$ 在区间 [0; 上也有效等于 0，这一点是显而易见的。 1]。否则，我们将考虑在该段上取最大值和最小值的点。 （根据 Weierstrass 定理，这些点存在 - 参见教科书“代数与分析 9-10”，第 28 段 - 或者函数 $f(x)$，可微，是连续的。）但是，这些值必须为零，因此，取自线段 [0; 内的点 $x_0$； 1]。

因此，$x_0$是函数$f(x)$在区间[0;上的极值点1] [1，以及费马定理（“代数和分析入门 9-10”，第 26 段）$f'(x_0) = 0$。

让我们用已证明的说法来解决问题。

a) 考虑函数$f(x) = a_1 x + \frac{a_2}{2} x^2 + \ldots + \frac{a_n}{n} x^n$。

根据条件，$f(1) = a_1 + \frac{a_2}{2} + \ldots + \frac{a_n}{n} = 0$，此外，$f(0) = 0$。
