为了使释放的热量达到最大，必须满足以下条件：

1) 初始时刻身体的势能应尽可能最大；
2) 物体必须在碗的最低点同时碰撞；
3) 碰撞后物体的速度必须为零。
如果满足这些条件，则全部初始势能将转化为热量。

因此，物体在初始时刻必须位于碗上高于其最低点的高度 R 处。物体的位置必须使得它们在碰撞前的总动量等于0（然后碰撞后，塌陷的物体在碗的底部点保持静止）。由于身体在任意时刻的冲量值的比例为3：4：5，因此初始时刻身体的位置应该与图相同（图处显示俯视图）。系统中释放的尸体量最大，等于 4mgR。

循环效率 η 由循环期间气体所做的功 A 与在此期间提供给气体的热量 Q 的比率确定：

η = A/Q.

气体所做的功在数值上等于三角形ABC的面积（见图1）：

$$A = p_0 V_0 / 2$$

要找到 Q，请分别考虑循环的每个部分。 AB 区的 ishore 流程正在进行中。气体不做功，内能增加

$$\Delta U_{AB} = 3 / 2 R (T_B - T_A) = 3 / 2 p_0 V_0.$$

根据热力学第一定律，这种内能的增加是由于提供了一定量的热量而发生的

$$Q_{AB} = \Delta U_{AB} = 3 / 2 p_0 V_0.$$

在CA段，发生等压过程，气体被压缩，即做负功，气体的内能减少。因此，在该区域中气体被分离而不是被接收。

现在让我们看看 BC 部分发生了什么。在这里，气体膨胀，因此做正功。气体的内能先增大后减小。因此，直到某一时刻，气体从外部接收热量，然后将热量释放到外部。让我们用字母 D 表示“边界”点并找到它的参数。设点 O 为截面 BC (图 2) 的当前点及其参数 - p、V 和 T。在截面 BO 上，气体所做的功在数值上等于图 2 上阴影的梯形面积：

$$A_{BO} = (p_0 + p / 2) (V - V_0),$$

在这种情况下，其内能按数值变化

$$\Delta U_{BO} = 3 / 2 R (T - T_B) = 3 / 2 (pV - 2p_0V_0).$$

根据热力学第一定律，必须将一定量的热量传递给气体

$$Q_{BO} = A_{BO} + \Delta U_{BO} = (p_0 + p / 2) (V - V_0) + 3 / 2 (pV - 2p_0V_0).$$
