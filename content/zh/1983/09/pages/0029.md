3. 二元方程$x^2 - 2rx - 7r^2 = 0$的根$x_1$和$x_2$满足条件$x_1^2 + x_2^2 = 18$。找到$r$。

首先，我们用根的和与积来表示$x_1^2 + x_2^2$，然​​后使用维塔定理。我们有
$$x_1^2 + x_2^2 = (x_1 + x_2)^2 - 2x_1x_2 = (2r)^2 - 2 \cdot (-7r^2) = 18r^2.$$
因此，问题简化为求解方程$r^2 = 1$，从中得到$r_1 = 1$，$r_2 = -1$。

4. 求方程$f(x) = x^2 + px + q = 0$的根$x_1$和$x_2$绝对值大于1且符号不同的充要条件。

该解决方案基于使用已知的二次方程判别式和根公式，是劳动密集型且技术复杂的。如果使用几何考虑因素，这个问题很容易解决。

我们首先要找到必要的条件。设$x_1 < x_2$（根不同）。根据问题条件，$x_1 < -1$，$x_2 > 1$，即线段$[-1, 1]$位于区间$]x_1, x_2[$（图2）内。最后一个条件相当于以下不等式系统：
$$\begin{cases} f(-1) < 0, \\ f(1) < 0. \end{cases} \quad (1)$$
将 1 和 -1 代入 $f(x)$ 的表达式，我们得到必要条件：
$$\begin{cases} -p + q < -1, \\ p + q < -1. \end{cases} \quad (2)$$
找到的值$p$和$q$之间的联系可以通过在坐标平面$(p, q)$上描绘一组坐标满足所获得的不等式（图3）的点来方便地用图形表示。

让我们证明必要条件（2）是充分的，即当满足不等式（2）时，方三角形$f(x) = x^2 + px + q$有根$x_1$和$x_2$，使得$x_1 < -1$和$x_2 > 1$。由于条件（2）与条件（1）等效，因此在两个不同点$(x = 1$和$x = -1)$，函数$y = f(x)$取负值。由于$x^2$的系数为正，因此抛物线$y = f(x)$的分支有向

向上。因此，抛物线与$Ox$轴相交于两个不同的点$x_1$和$x_2$（$x_1 < x_2$），其中点$-1$和1位于区间$]x_1, x_2[$上，即$x_1 < -1$、$x_2 > 1$。

5. 查找 $r$ 中方程 $(r - 4)x^2 - 2(r - 3)x + r = 0$ 的根大于 -1 的所有值。

首先，我们单独考虑$r = 4$的情况。那么方程的形式为 $-2x + 4 = 0$，因此为 $x = 2$。由于$2 > -1$，值$r = 4$适合我们。

如果$r \neq 4$，则方程是二次方程。

让我们用更一般的形式来解决这个问题：我们将找到正方形三角形的根$f(x) = ax^2 + bx + c$存在且大于给定数$d$的充要条件。

几何解。根$x_1$和$x_2$一定存在，所以$(1) D = b^2 - 4ac \geq 0$。

$$-\frac{b}{2a} > d \quad (2)$$
