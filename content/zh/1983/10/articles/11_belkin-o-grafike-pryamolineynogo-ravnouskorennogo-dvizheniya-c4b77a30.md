其中 $n$ 是我们除以移动时间 $t$ 的间隔数。由于间隔 $\Delta t$ 很小，$n$ 很大，因此，在最后一个等式的右侧，与 $n$ 相比，我们可以忽略统一并假设

$$\Delta s_n = v_0 \Delta t + na (\Delta t)^2.$$

总位移$s$等于所有小位移$\Delta s_i$之和：

$$s = \Delta s_1 + \Delta s_2 + \Delta s_3 + \ldots + \Delta s_n,$$

或者

$$s = nv_0 \Delta t + a \Delta t^2 (1 + 2 + 3 + \ldots + n).$$

连续自然数的总和等于所得的极值项乘以它们的数量：

$$1 + 2 + 3 + \ldots + n = \frac{1+n}{2} n.$$

忽略与 $n$ 的统一，我们得到

$$1 + 2 + 3 + \ldots + n = \frac{n^2}{2}.$$

从这里

$$s = v_0 n \Delta t + \frac{a (n \Delta t)^2}{2}.$$

但是$n \Delta t = t$，还有$(n \Delta t)^2 = t^2$，最后

$$s = v_0 t + \frac{at^2}{2}.$$

关于匀加速直线运动的图

在研究机械运动时，他广泛使用显示物体坐标对时间的依赖性（运动图）和物体速度对时间的依赖性（速度图）的图形。这些图表就像相应的公式一样，完整地描述了运动，也就是说，它们可以让你随时确定坐标和速度。但图的优点是清晰（通过构建函数图，您可以“看到”该函数）。

教科书《物理8》提供了直线匀速运动的运动和速度图，以及直线匀加速运动的速度图。使用最后一张图，得出位移 $s$ 的公式，从而得出匀加速运动物体的坐标 $x$：

$$s = v_0 t + \frac{at^2}{2}, \quad x = x_0 + v_0 t + \frac{at^2}{2}.$$

然而，这些公式也可以通过直接计算获得（例如，参见注释“直线匀加速运动期间的运动”）。没有给出该案例的运动图表，但它似乎引起了相当大的兴趣。这就是我们将在本文中讨论的内容。

从最后一个公式可以看出，匀加速运动时的坐标表达式是一个二次三项式。一般情况下，$t$和$t^2$的系数以及自由项不等于0。表达这种函数的图形称为抛物线。它的类型和相对于坐标轴的位置取决于三个常数 - $x_0$、$v_0$ 和 $a$。例如，图 1 表示对应于方程的抛物线

$$x = 3 + 12t + 3t^2.$$

它描述了初始速度$v_0 = 12$米/秒和加速度$a = 6$米/秒²的直线匀加速运动。时间原点是物体坐标$x$（初始坐标）等于$x_0 = 3$米的时刻。这种运动的图形，严格来说，只是曲线的右侧部分，如图 1 处的实线所示。

但如果以一个沿同一直线、相同加速度、直到某一时刻的运动体为原点，那么它的运动图形也将是曲线的左边部分（如图1上的虚线所示）。

在数学中，证明了表达形式的二次三项式的抛物线

$$x = x_0 + v_0 t + \frac{at^2}{2},$$

通过坐标轴的平行平移可以转化为抛物线表达公式

$$x = \frac{a}{2} t^2.$$

就我们的情况而言，需要将 $t$ 轴沿 $X$ 轴移动到等于 $x_0 - v_0^2/2a$ 的距离，并将 $X$ 轴沿 $t$ 轴移动到等于 $-v_0/a$ 的距离。在图1和图2中，根据该规则交叉的轴用虚线示出。

这种轴的转移意味着现在将物体速度为零的时刻作为时间原点（当“来回”运动时必须存在这样的时刻），并选择该时刻物体所在的点作为坐标原点。轴平移后，抛物线变得关于相对轴$X$对称。现在$t$和$-t$时刻的坐标$x$的值是相同的，因为公式中只包含$t^2$，并且用$-t$替换$t$不会改变任何东西。
