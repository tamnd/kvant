把它写在表格里

$$a \leq \frac{l}{2} \sin \varphi.$$

我们实验的可能结果对应于坐标为 $(a; \varphi)$ 的平面上的一个点，位于由轴坐标和直线 $a = \frac{h}{2}$ 和 $\varphi = \frac{\pi}{2}$ (图 2) 围成的矩形内。

位于曲线$a = \frac{l}{2} \sin \varphi$下方的矩形点对应于针与直线的以下交点：位于该曲线上方的点对应于不发生交点的情况。现在问题可以表述如下：访问矩形$\{0 \leq \varphi \leq \pi/2; 0 \leq a \leq h/2\}$中的一个点；该点位于正弦曲线 $a = (l/2) \sin \varphi$ 下方的概率是多少？

这里的“随机”一词取代了针方程所有位置相等*)的要求。其结构意义可以通过不同的方式来归因。最简单的说法是，选定点落入给定边上的任何正方形$\{\varphi_1 \leq \varphi \leq \varphi_2; a_1 \leq a \leq a_2\}$（$\varphi_2 - \varphi_1 = a_2 - a_1 = d$）的概率并不取决于该正方形在矩形内的位置（当然，它取决于其边长$d$）。

例如，某个点位于 图 2 上的方格 $K_1$ 或 $K_2$ 内的概率是相同的。从这里很容易推断出进入矩形中任何图形内部的概率与其面积成正比，因此等于该面积与整个矩形面积的比率。

特别是，以所考虑的正弦曲线为界的新梯形的曲线面积等于

$$S_1 = \int_0^{\pi/2} \frac{l}{2} \sin \varphi d\varphi = \frac{l}{2} \left( -\cos \frac{\pi}{2} \right) - \left( -\cos 0 \right) = \frac{l}{2}.$$

并且由于矩形的面积$S$等于$\pi h/4$，避免获取值

$$p = \frac{S_1}{S} = \frac{2l}{\pi h}.$$

*）我们不想谈论“均匀置信度”，因为角度占据某个精确固定位置的概率简直为零。
