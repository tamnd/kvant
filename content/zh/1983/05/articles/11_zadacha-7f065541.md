水波或无线电波很容易表现出干扰现象。观察光学中的干涉图案并不容易，因为传统光源（不是激光）发出的振荡具有快速且随机变化的相位，因此是松散的。然而，如果将一个光源发出的光分成两束，然后将这些光束相互叠加，则可以获得相当清晰的干涉图案$^*$)。

注意，为了正确描述干扰现象，确定振荡相位差的误差必须明显小于$\pi$（否则将无法区分最大值和最小值）。在这种情况下，改变波程差的误差应远小于波长$\lambda$（对于光波，该误差应远小于0.1μm）。

问题 1. 由喇叭天线产生的频率为 $v$ 的平面电磁波垂直落在平面反射镜上。如果在屏幕和喇叭之间移动时改变电场方向，则确定反射波的振幅，由最大场振幅 $A_1$ 和最小场振幅 $A_2$ 固定。还确定两个相邻场最大值之间的距离。

在喇叭和反射屏之间的空间中，发生入射波和反射波的叠加。在最大点处，这些波引起的振荡的相位一致，因此，产生的出现次数与振幅一致

$$A_1 = A_{\text{пад}} + A_{\text{отр}}.$$

在最低点，入射波和反射波反相，振荡的总振幅等于

$$A_2 = A_{\text{пад}} - A_{\text{отр}}.$$

由这两个等式我们发现

$$A_{\text{отр}} = \left( A_1 - A_2 \right) / 2.$$

让入射波在坐标$x$处引起的振荡由表达式描述

$$a_{\text{пад}} = A_{\text{пад}} \cos \omega \left( t - \frac{x}{c} \right) = A_{\text{пад}} \cos \left( \omega t - \frac{2\pi}{\lambda} x \right).$$

如果从喇叭到屏幕的距离为 $l$，则反射波传播距离 $2l - x$ 到该点，反射波引起的振荡具有以下形式

$$a_{\text{отр}} = A_{\text{отр}} \cos \omega \left( t - \frac{2l - x}{c} \right) = A_{\text{отр}} \cos \left( \omega t + \frac{2\pi}{\lambda} x - \frac{4\pi l}{\lambda} \right).$$

（事实上​​，当波被反射时，振荡的相位可能会改变为相反的，但这不会影响我们进一步的推理。）

让两个相邻的最大值在坐标 $x_1$ 和 $x_2$ 的点处观察。这些点处的入射波和反射波引起的振荡之间的相位差分别相等

$$\left( \Delta \varphi \right)_1 = \left( \omega t - \frac{2\pi}{\lambda} x_1 \right) - \left( \omega t + \frac{2\pi}{\lambda} x_1 - \frac{4\pi}{\lambda} l \right) = - \frac{4\pi}{\lambda} x_1 + \frac{4\pi}{\lambda} l$$

和

$$\left( \Delta \varphi \right)_2 = - \frac{4\pi}{\lambda} x_2 + \frac{4\pi}{\lambda} l.$$
