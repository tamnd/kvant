关于连分数

物理和数学科学候选人
Y.V.涅斯特连科，
物理和数学博士
E.M.尼基申

有很多例子表明，一个被认为有前途和重要的科学方向并没有实现人们对其提出的希望；渐渐地，科学力量从中流失，方向本身就失去了意义。数学的这些领域之一是连分数理论。直到上世纪末，各种连分数经常出现在数学著作中。在上个世纪或更早的时候，关于连分数的重要定理已经被证明。希望如果我们能够理解连分数的结构，就有可能在数论和数学分析方面获得新的结果。这种希望只是部分合理，随后数学，特别是在数论领域，继续走上新的道路，使得连分数理论的问题被搁置一边。

但尽管如此，正如北部地带接受了它的征服者一样，公式简单、看似简单的连分数问题吸引了数学家，迫使他们一次又一次地寻找这个奇怪物体的模式。现代数学和物理学中的许多重要问题都会导致诸如连分数之类的对象。因此，他们所依赖的研究方法在解决广泛的问题时被证明是有用的。我们在这里只讨论与数论相关的问题，事实上，连分数理论就是在这些问题上产生的。

日历、齿轮和一点历史

一年有多少天？大家都知道，平年有365天，高年有366天。数字可以被 4 整除的年份被声明为闰年，例如 1904、1908、...、1980、1984、...、1996。但是，1800、1900、2100、2200 年不会被声明为高年份，但 2000、2400、2800 年将被声明为高年份。为什么？

日历的机制非常简单。地球绕地轴匀速自转，每天转一圈。地球绕太阳公转一圈是一年，这一年等于 365.24219878... 天。当然，我们可以说增加的0.242...天很小。然而，随着时间的推移，如果将一年等于 365 天，温度就会升高。在古代，当一天中的漫长一年的知识非常近似时，日益增长的误差达到了服务器的程度。公元前 46 年在罗马。 e.积压90天！

要在日历中建立正常年和高年的模式，您需要选择周期的长度$q$（之后重复所有周期性的）和周期中高年的数量$p$。让我们以$365+\alpha$的形式写出年份的值，其中$\alpha=0,242...$。必须选择自然数 $p$ 和 $q$，以便这些值

$$\beta = q\alpha - p$$

尽可能小，而$p$和$q$不是很大。事实上，只能选择自然数$q$，而$p$是接近$q\alpha$的整数。然后$q$年$365q+p$天就会过去。根据等式$365q+p=q(365+\alpha)-\beta$，在此期间地球将制造

$$q - \frac{\beta}{365+\alpha} \approx q$$

在这种情况下，在数学任务中出现错误对我们来说很重要：对于给定的数字$n$，如果可能的话，找到$p$和$q$，以便数字$\frac{p}{q}$尽可能接近给定值$\omega$（所需的角速度比）。显然，从储蓄消息中应该选择尽可能少的$p$和$q$。

欧几里得算法和连分式分解

设$p$、$q$为两个自然数。生产余数，我们会发现

$$p = a_0 q + q_1, \quad 0 < q_1 < q$$

$$q = a_1 q_1 + q_2, \quad 0 < q_2 < q_1$$

$$q_1 = a_2 q_2 + q_3, \quad 0 < q_3 < q_2$$

$$q_{k-2} = a_{k-1} q_{k-1} + q_k, \quad 0 < q_k < q_{k-1}$$

$$q_{k-1} = a_k q_k.$$

指定的一组操作称为欧几里得算法。可以证明，所得数$q_k$将是数$p$、$q$中最广泛的公实数。我们不需要这个事实，因此我们省略了证明*）。

从获得的等式可以得出

$$\frac{p}{q} = a_0 + \frac{q_1}{q} = a_0 + \frac{1}{a_1 + \frac{q_2}{q_1}} = \dots = a_0 + \frac{1}{a_1 + \frac{1}{a_2 + \dots + \frac{1}{a_k}}}.$$

这个过程也导致同样的结果。设 α 为实数。让我们把
$$\alpha = a_0 + \frac{1}{a_1}, a_0 - \text{целое},$$
其中$a_1 > 1$。如果$a_1$不是整数，那么我们将继续该过程。让我们将 $a_1$ 表示为 $a_1 = a_1 + \frac{1}{a_2}$，其中 $a_1$ 是正整数，$a_2 > 1$。因此，
$$\alpha = a_0 \frac{1}{a_1 + \frac{1}{a_2}}.$$
如果$a_2$不是整数，则可以继续该过程。因此，在第$k$步我们得到分数(1)的等式“多层”表示法是非常麻烦的，所以以后我们会经常使用以下更紧凑的特殊表示法：
$$\alpha = a_0 + \frac{1}{a_1} + \frac{1}{a_2} + \dots + \frac{1}{a_{k-1}} + \frac{1}{a_k},$$
其中$a_k > 1$。
不难证明，如果$\alpha = \frac{p}{q}$是一个有理数，那么对于某些$k$来说，$a_k$将是一个整数。

同样清楚的是，如果对于某些$k$获得整数$a_k$，则数字$a$是有理数。如果 $a$ 是无理数，那么所指示的过程将永远不会结束，并且会出现无限连分数
$$\alpha = a_0 + \frac{1}{|a_1|} + \frac{1}{|a_2|} + \dots +$$
$$\dots + \frac{1}{|a_{k-1}|} + \frac{1}{|a_k|} + \dots$$
这里的等号是任意的，因为不清楚右边的表达式的含义。为了赋予其意义，请考虑以下形式的有限和
$$\pi_k = a_0 + \frac{1}{a_1 + \dots} + \frac{1}{a_k},$$
称为合适的连分数 (2)。根据定义，假设等式 (2) 的右边由合适分数的极限表示：
$$\lim_{k \to \infty} \pi_k$$
现在让我们以一组问题的形式来表述连分数的那些性质，这些性质构成了它们的基本理论的基础，特别是建立了等式（2）。

连分数的基本性质
1. 令 $\pi_k = \frac{p_k}{q_k}$ 为连分数 (2) 的适当分数。证明递推关系的有效性：
$$p_0 = a_0, p_1 = a_0 a_1 + 1, \dots,$$
$$p_{k+1} = a_{k+1} p_k + p_{k-1}, \dots$$
$$q_0 = 1, q_1 = a_1, \dots,$$
$$q_{k+1} = a_{k+1} q_k + q_{k-1}, \dots$$
对于$k = 1, 2, 3, \dots$。
2. 设置以下比率：
a) $q_n p_{n-1} - p_n q_{n-1} = (-1)^n, n \geqslant 1$;
b) $q_k p_{k-2} - p_k q_{k-2} = (-1)^{k-1} a_k, k \geqslant 2$;
c) $\pi_{n-1} - \pi_n = \frac{(-1)^n}{q_n q_{n-1}}, n \geqslant 1$;
d) $\pi_{k-2} - \pi_k = \frac{(-1)^{k-1} a_k}{q_k q_{k-2}}, k \geqslant 2$.

3. 证明分数 $\pi_0, \pi_2, \pi_4, \dots$ 单调递增：
$$\pi_0 < \pi_2 < \pi_4 < \pi_6 < \dots,$$
分数 $\pi_1, \pi_3, \dots$ 单调递减：
$$\pi_1 > \pi_3 > \pi_5 > \dots$$

4. 让数字 $a_k$ 由等式 (1) 定义。证明合规性：
$$\alpha = \frac{p_{k-1}a_k + p_{k-2}}{q_{k-1}a_k + q_{k-2}}, k \geqslant 2.$$

5. 证明不等式
$$\frac{1}{2q_{n+1}} < |q_n\alpha - p_n| \leqslant \frac{1}{q_{n+1}}.$$

6. 证明
$$\lim_{k \to \infty} \pi_k = \alpha.$$
从问题1-6可以看出，分数$\pi_n$很好地逼近了数字$\alpha$。因此，根据问题 5 的估计和不等式 $q_{n+1} < q_n$ 可以得出，如果 $\alpha$ 是无理数，则不等式
$$\left| \alpha - \frac{p_n}{q_n} \right| < \frac{1}{q_n^2}$$
对于数字 $\alpha$ 的连分数的所有匹配分数 $\pi_n = \frac{p_k}{q_k}$ 都成立。

数值例子

数字 $\alpha$ 的连分数 (2) 有时表示为 $[a_0; a_1, a_2, \dots, a_k, \dots]$。可以证明，对于每个整数序列$a_0, a_1, a_2, \dots, (a_0 \geqslant 0$和$a_j \geqslant 1$（对于$j \geqslant 1$），都有一个唯一的正数$\alpha$，使得
$$\alpha = [a_0; a_1, a_2, \dots].$$
如果序列$a_0, a_1, a_2, \dots$已知，则可以轻松计算出匹配分数的序列$\pi_k = \frac{p_k}{q_k}$；使用问题 1 中的等式填写下表：

| $a$ | $a_0$ | $a_1$ | $a_2$ | ... | $a_{n-1}$ | $a_k$ | $a_{k+1}$ | $a_{k+2}$ | ... |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| $p$ | 1 | $a_0$ | $p_1$ | $p_2$ | ... | $p_{k-1}$ | $p_k$ | ... | ... |
| $q$ | 0 | 1 | $q_1$ | $q_2$ | ... | $q_{k-1}$ | $q_k$ | ... | ... |

示例 1. 求数字 $\sqrt{2}$ 的连分式分解。
我们有$a_0 = 1$，
$$a_1 = \frac{1}{\sqrt{2} - 1} = \sqrt{2} + 1, \quad a_1 = 2,$$
$$a_2 = \frac{1}{\sqrt{2} - 1} = \sqrt{2} + 1, \quad a_2 = 2.$$
很明显，在序列 $a_j, j = 1, 2, \dots$ 中，所有项都等于 $\sqrt{2} + 1$，而在序列 $a_j, j = 1, 2, \dots$ 中，所有项都等于 2。所以，
$$\sqrt{2} = [1; 2, 2, 2, \dots].$$
让我们计算 $\sqrt{2}$ 的几个合适的分数：

| $a$ | 1 | 2 | 2 | 2 | 2 | 2 | 2 | ... |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| $p$ | 1 | 1 | 3 | 7 | 17 | 41 | 99 | ... |
| $q$ | 0 | 1 | 2 | 5 | 12 | 29 | 70 | 169 | ... |

我们得到匹配分数的序列：$\frac{1}{1}, \frac{3}{2}, \frac{7}{5}, \frac{17}{12}, \frac{41}{29}, \frac{99}{70}, \dots$

由问题 5 可知
$$\left| \sqrt{2} - \frac{99}{70} \right| < \frac{1}{70 \cdot 169} < 10^{-4}.$$
