列宁格勒国立大学
他们。 A·A·日丹诺娃

Matematika
笔试
选项1
（数学与力学学院和应用数学学院 - 控制过程）

1. 对于什么$a$方程组
$$\begin{cases} y = \sin(a + \pi x) + \sin(a - \pi x) \\ 3 \sin a = \frac{1}{1 + y^2} \left( \frac{3}{2} + x + \frac{1}{2x^2} \right) \end{cases}$$
在$x \in \left[ 1; \frac{3}{2} \right], y \in \left[ -\infty; 0 \right]$区域有唯一的解决方案吗？

2. 解方程
$$2(\sin 3x + \cos x) = (\sin x + \cos x)^2 + (\sin 2x + \cos 2x)^2.$$

3. 解决不等式
$$\cos x + \sqrt{2 + \cos x} \leq 0.$$

4. 在凸五边形$ABCDE$中，边$AB, CD$的公共边$P, Q$和边$BC, DE$的公共边$S, T$通过线段$PQ$和$ST$连接。设$M$和$N$为连接线段$PQ$和$ST$。求线段$MN$的长度。

5. 给定一个立方体$ABCDA'B'C'D'$，边长为$a$。在边 $AA'$ 上取一个点 $E$，从而得到 $|AE| = \frac{1}{4} a$。求顶点与点$A'$重合，底面是通过点$D, E$和边$BB'$中点的截面的金字塔的体积。

选项2
（物理系）

1. 一名弓箭手站在岸边一个高度为 $H$ 的截止体积上方。箭头的初始速度矢量与地平线形成角度$a$，在顶点处等于$v$。飞行开始后$T$什么时间后，箭会到达水面上方$h$的高度？忽略箭头的大小和射手的高度。

2. 在什么 $x$ 函数处
$$f(x) = \sqrt{1 + \sqrt{2 + \sqrt{3 + \sqrt{4} + x}}} + \sqrt{1 + \sqrt{2 + \sqrt{3 + \sqrt{4} - x}}}$$

最有意义？

3. 给出方程的负根
$$\frac{1}{\sin x} + \frac{1}{\sin 2x} + \frac{1}{\sin 4x} = 0,$$
满足不平等
$$x^3 + 5x^2 - 3x - 3 > 0.$$

4. 计算tan 37°30′的值。

5. 在正四边形直线中，底边等于$a$，侧边与底面平面成$a$角。一个立方体内接于这条直线，使其四个顶点位于该直线的阿波法上，且底面属于该直线的底面。求立方体的体积。

选项3
（化学学院）

1. 将 2 cm$^3$ 三种物质混合，得到 16 g 混合物。已知4g第二物质占据的体积比4g第三物质大0.5cm$^3$。如果已知混合物中第二种物质的质量是第一种物质质量的两倍，求第三种物质的密度。

2. 直角三角形到斜边的高是 $h$。将较长的腿一分为二的最短长度是多少？

3. 解方程
$$8 \sin^2 x + \sin 2x = 5.$$

4. 求解方程组
$$\begin{cases} 3^x - 2^{y^2} = 77 \\ \frac{x}{3} - \frac{y^2}{2} = 7. \end{cases}$$

5. 解方程
$$13^{\frac{x}{13}} + 13^{\frac{x}{13}} - 1 + \dots = 15^{2x} + 15^{2x} - 1 + \dots$$

选项4
（经济学院、心理学院）

1. 蜡烛的长度相同，但粗细不同。第一根蜡烛比其他蜡烛早一个小时点燃，同时点燃。在某些时候，第一根和第二根蜡烛变得相同长度，两小时后第一根和第三根蜡烛变得相同长度。如果蜡烛的第二边是 8 小时，第三边是 12 小时，那么第一边是多少小时？假设蜡烛的速度不取决于燃烧的持续时间。

物理学院
选项1
1. 斜面与地平线成$\alpha$角的楔子可以沿水平面（图1）平移。应该用多大的力 $F$ 沿水平方向拉动线，以使木块沿楔子向上移动？木块和楔子将以多大的加速度移动？楔子的质量为$M$，块体的质量为$m$。摩擦力、螺纹质量和块质量声明。
2. 气体按照$pV^2 = const$定律膨胀还是受热或冷却？
3. 图2所示的电路已组装完毕。如果开关$K$打开，电压表读数将如何变化？假设电压表的电阻无限大。
4. 在平面单色波的路径上放置一块屏幕，在其$A$点放置一个指示器，记录屏幕单位面积上单位时间所带来的辐射能量。如果将一个聚光镜放置在距离屏幕$L$ 的位置，使$A$ 点位于其主光轴（图 3）上，仪器读数会改变多少次？绘制镜头固定焦距 $F$ 时所需值与 $L$ 以及固定 $L$ 时所需值与 $F$ 的依赖关系图。面对索赔时失去能量。
5. 理论问题。变压器。电力传输和分配。

选项2
1. 质量为 $m$ 的球沿着连接其中心的线以速度 $v$ 撞击质量为 $M$ 的静止球。移除后，第一个球的速度变为原来的一半。求去除后奥比哈尔的总动能与攻击球的初始动能之比。
2. 一摩尔单原子理想等容气体被冷却，使其压力降低 $n$ 倍。然后等压气体膨胀，其体积增加 $n$ 倍。如果已知在这些转变过程中传递给气体的总热量小于其初始内能的两倍，请确定数字$n$。
3. 电路已组装完毕，如图 4. 如果$K$ 钥匙闭合，即$A$ 和$B$ 点短路，电流表读数会如何变化？
4. 来自太阳的光线落在矩形的小平面镜上，反射后落在屏幕上，接收到的太阳光线不会落在屏幕上。屏幕上的发光点呈什么形状？
5. 理论问题。光的波动和量子特性的概念。

数学与力学学院、应用数学学院 - 控制过程、化学与地质学院
1. 沿着与地平线形成$\alpha$角的木框架，在绳子后面插入一个盒子。如果绳索与垂直方向成 $\beta$ 角时所需的力最小，则盒子的脚趾摩擦系数是多少？
2. 在时间 $t$ 内，质量体 $m$ 受到水平方向的恒定力 $F$ 的作用。物体在其所在水平面上的摩擦系数等于$\mu$。身体在停止前会移动多远？
3. 两颗质量分别为 $m_1$ 和 $m_2$ 的恒星以这样的方式运动，使得它们的中心之间的距离保持不变。确定恒星运动的性质（轨迹、速度、加速度），注意它们与其他天体的相互作用。
4. 质量为 $m=2\mathrm{kg}$ 的空气位于由可移动活塞封闭的气缸中。当空气等压加热$\Delta T=100$ K时，会做多少功？
5. 一摩尔氢气在恒压下加热。必须向氢气传递多少热量才能使其体积逸出？气体将做多少功？
