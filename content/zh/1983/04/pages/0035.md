具有“弧”的恒等式通常用以下方法证明：首先，计算被证明的恒等式两边的某个三角函数 φ（φ 是正弦、余弦或正切）的值

$$A = B$$

验证$\varphi(A) = \varphi(B)$，其次，成立$A$和$B$位于所选函数φ单调的区间上；那么从等式$\varphi(A) = \varphi(B)$可以得出$A = B$。

示例 1. 让我们证明 (4) 对于所有 $x \in [-1; 1]$ 都成立。我们来计算等式(4)两边的余弦：

$$\cos(\arccos(-x)) = -x,$$
$$\cos(\pi - \arccos x) = -\cos(\arccos x) = -x.$$

所以，$\cos(\arccos(-x)) = \cos(\pi - \arccos x)$。根据反余弦的定义

$$0 \leq \arccos(-x) \leq \pi.$$

根据不等式 $0 \leq \arccos x \leq \pi$ 可以得出

$$0 \leq \pi - \arccos x \leq \pi.$$

在 $[0; \pi]$ 处，余弦是单调的。因此，

$$\arccos(-x) = \pi - \arccos x.$$

如果我们选择正弦作为计算函数，那么我们当然也会得到相同的值：

$$\sin(\arccos(-x)) = \sqrt{1 - \cos^2(\arccos(-x))} = \sqrt{1 - (-x)^2} = \sqrt{1 - x^2},$$
$$\sin(\pi - \arccos x) = \sin(\arccos x) = \sqrt{1 - \cos^2(\arccos x)} = \sqrt{1 - x^2}$$

（在这两种情况下，“plus”都写在根之前，因为$0 \leq \arccos(-x) \leq \pi$和$0 \leq \arccos x \leq \pi$，并且在$[0; \pi]$上，正弦是非负的），但是从等式

$$\sin(\arccos(-x)) = \sin(\pi - x) = \sin(x).$$

示例 3. 让我们证明对于 $x \in \left[\frac{\pi}{2}; \frac{3}{2}\pi\right]$

$$\arcsin(\sin x) = \pi - x.$$

一方面，

$$\sin(\arcsin(\sin x)) = \sin x,$$
$$\sin(\pi - x) = \sin x.$$
