⟦folio 34⟧

另一边，

$$-\frac{\pi}{2} \leq \arcsin(\sin x) \leq \frac{\pi}{2}.$$

根据不等式 $\frac{\pi}{2} \leq x \leq \frac{3}{2} \pi$ 可以得出

$$-\frac{\pi}{2} \leq \pi - x \leq \frac{\pi}{2}.$$

在 $[-\frac{\pi}{2}; \frac{\pi}{2}]$ 处，正弦是单调的。所以，$\arcsin(\sin x) = \pi - x$。所以，$\arcsin(\sin x) =$

$$\begin{cases} x, & \text{если } -\frac{\pi}{2} \leq x \leq \frac{\pi}{2} \\ \pi - x, & \text{если } \frac{\pi}{2} \leq x \leq \frac{3}{2} \pi. \end{cases}$$

由于 $\arcsin(\sin x)$ 是一个周期函数，周期为 $2\pi$（为什么？）并且线段 $[-\frac{\pi}{2}; \frac{3}{2} \pi]$ 的长度为 $2\pi$，因此我们可以将其绘制成图表 (图 7)。

涉及“弧线”计算的问题以类似的方式解决。

示例 4. 让我们计算 $A = \arcsin\frac{4}{\sqrt{65}} - \arccos\left(-\frac{11}{\sqrt{130}}\right)$。

首先，$A = \arcsin\frac{4}{\sqrt{65}} - \left(\pi - \arccos\frac{11}{\sqrt{130}}\right) = \arcsin\frac{4}{\sqrt{65}} + \arccos\frac{11}{\sqrt{130}} - \pi$。现在让我们评估数字$B = \arcsin\frac{4}{\sqrt{65}} + \arccos\frac{11}{\sqrt{130}}$。从$\frac{4}{\sqrt{65}} > 0$和$\frac{11}{\sqrt{130}} > 0$开始，

$$0 < \arcsin\frac{4}{\sqrt{65}} < \frac{\pi}{2}$$

$$0 < \arccos\frac{11}{\sqrt{130}} < \frac{\pi}{2}$$

由于在 $[0; \pi]$ 上，正弦不是单调的，但余弦是单调的，所以我们找到 cos $B$：

$$\cos B = \cos\left(\arcsin\frac{4}{\sqrt{65}} + \arccos\frac{11}{\sqrt{130}}\right) =$$

$$\cos\left(\arcsin\frac{4}{\sqrt{65}}\right) \times$$

$$\times \cos\left(\arccos\frac{11}{\sqrt{130}}\right) -$$

$$-\sin\left(\arcsin\frac{4}{\sqrt{65}}\right) \times$$

$$\times \sin\left(\arccos\frac{11}{\sqrt{130}}\right) =$$

$$\sqrt{1 - \left(\frac{4}{\sqrt{65}}\right)^2} \cdot \frac{11}{\sqrt{130}} -$$

$$-\frac{4}{\sqrt{65}} \cdot \sqrt{1 - \left(\frac{11}{\sqrt{130}}\right)^2} = \frac{\sqrt{2}}{2}$$.

从cos$B = \frac{\sqrt{2}}{2}$和$0 < B < \pi$之间的对应关系可以得出$B = \arccos\frac{\sqrt{2}}{2} = \frac{\pi}{4}$。所以，$A = B - \pi = -\frac{3}{4} \pi$。

示例 5. 让我们比较数字 $\arcsin\frac{2}{5}$ 和 $\arccos\frac{2}{5}$。从$\frac{2}{5} > 0$开始，

$$0 < \arcsin\frac{2}{5} < \frac{\pi}{2}$$

$$0 < \arccos\frac{2}{5} < \frac{\pi}{2}$$
