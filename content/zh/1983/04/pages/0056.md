⟦folio 54⟧

莫斯科国立大学
他们。 M·V·罗蒙诺索娃

数学
笔试
选项1
（力学与数学学院）

1. 解方程
$$\log_2(x^2-3) - \log_2(6x-10) + 1 = 0.$$
2. 凸四边形 $ABCD$ 与以点 $O$ 为圆心、$|AO| = |OC| = 1, |BO| = |OD| = 2$ 的外接圆。求四边形 $ABCD$ 的周长。
3. 解方程
$$\sqrt{5 \sin x + \cos 2x} + 2 \cos x = 0.$$
4. 查找 $x$ 的所有值，其中表达式
$$\sqrt{3x^4-2-x^8} \cdot \sin(\pi(2x+16x^2))$$
有道理并且不会消失。
5. 给定一个顶点为$D$的三角形对$ABCD$，其面$ABD$和$ACD$是直角三角形，边$AD$垂直于底边$AK$和$|AD| = |AK|$的中线。不通过边$AD$和$BC$中点的平面截得的帕拉米德截面是底边$EF$和$GH$的平衡梯形$EFGH$，点$E$平分边$BD$，点$G$位于边上$AC$ 和 $|AG| = 3|GC|$。求梯形 $EFGH$ 平面与面 $BCD$ 平面的比率。

选项2
（力学与数学学院）
1. 解方程
$$\log_x(2x^2-3x-4) = 2.$$
2. 在半径为$r = 2$的圆内接的梯形$ABCD$中，对角线$AC$是比塞特角$BAD$，底边$AD$的长度是底边$BC$长度的两倍。求这个梯形的平面。
3. 解方程
$$\sqrt{2 \sin x \cdot \sin 2x} = \sqrt{5 \cos x + 4 \sin 2x}.$$
4. 查找 $x$ 的所有值，其中表达式

$$\sqrt{4x^4-3-x^8} \cdot (1-\cos(2\pi(2x+21x^2)))$$

有道理并且不会消失。
5. 在四边形$ABCDE$中，底$ABCD$是平行四边形，面$ADE$和$BCE$是直角三角形。边 $BC$ 垂直于面 $CDE$ 和 $|BC| = |EP|$ 的中线 $EP$。帕拉酰胺在平面上的截面是平衡梯形$GKHL$，其顶点$G, K, H, L$分别位于边$AE, BE, CE, DE$、$|GE| = 3|GA|$和$|CH| = |EH|$上。求梯形$GKHL$面积与面$ABE$面积之比。

选项3
（计算数学与控制论学院）
1. 哪个数字更大：$\sqrt{8}$ 或 $2^{2\log_2 5 + \log_2 \frac{9}{2}}$？
2. 查找函数 $y = 6 \cos^2 x + 6 \sin x - 2$ 在 $R$ 上取最大值的所有 $x$。
3. 解决不等式
$$\frac{\sqrt{2-x} + 4x-3}{x} \geq 2.$$
4. 该工厂拥有几台相同的冲床来冲压零件，每天生产 6,480 个零件。重建后，所有印刷机均更换为更随意但相同的印刷机，并且数量增加了三台。该工厂开始每天生产 11,200 个零件。最初有多少台印刷机？
5. 对于所有 $a$，求解方程
$$|x+3| - a|x-1| = 4$$
并确定哪个 $a$ 有两个解。
6. 以点 $O$ 为圆心，与三角形 $ABC$ 外接圆。圆在点$C$的切线与平分三角形角$B$的线在点$K$相交，角$BKC$等于三角形角$A$与角$C$之差的一半。边$AC$和$AB$的长度之和为$2+\sqrt{3}$，点$O$到边$AC$和$AB$的距离之和为2。求圆的半径。

选项4
（物理学院）
1. 解方程
$$\frac{1}{2} \cos \frac{x}{2} + \sqrt{2} \cos \frac{x}{4} = 0.$$
2. $a$的值是方程的解
$$10x-15a=13-5ax+2a$$
超过2个？
3. 已知$\log_b a = \sqrt{3}$。计算
$$\log \left(\frac{\sqrt{a}}{b}\right)\left(\frac{3\sqrt{a}}{\sqrt{b}}\right).$$
4. 解决不等式
$$5^x-3^{x+1} > 2(5^{x-1}-3^{x-2}).$$
