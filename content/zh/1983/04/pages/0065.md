$$|x| \leq -\frac{\sqrt{2}}{\gamma^3} z^2 + \frac{\sqrt{2}}{\gamma}$$
或者
$$\frac{\sqrt{2}}{\gamma^3} z^2 - \frac{\sqrt{2}}{\gamma} \leq x \leq -\frac{\sqrt{2}}{\gamma^3} z^2 + \frac{\sqrt{2}}{\gamma}$$
因此，我们需要估计$x = -\frac{\sqrt{2}}{\gamma^3} z^2 + \frac{\sqrt{2}}{\gamma}$和$x = \frac{\sqrt{2}}{\gamma^3} z^2 - \frac{\sqrt{2}}{\gamma}$对之间具有整数坐标的点数。

$-\frac{\sqrt{2}}{\gamma}$。如果$0 < \gamma \leq \frac{\sqrt{2}}{2}$，则$\frac{\sqrt{2}}{\gamma} \geq 2$ - 根据秩序（轴$x$），至少有 5 个排除点（图 7，a）。如果$\frac{\sqrt{2}}{2} < \gamma < 1$，则$1 < \frac{\sqrt{2}}{\gamma} < 2$ - 在抛物线之间（即，基于序数）正好有 3 个互斥点（图 7，b）。如果$1 \leq \gamma \leq \sqrt{2}$，则$\frac{\sqrt{2}}{\gamma} \geq 1$ - 抛物线之间恰好有 5 个互斥点 (图 7, c)。如果$\sqrt{2} < \gamma < 2$，则$\frac{\sqrt{2}}{\gamma} < 1$ - 抛物线之间（即以横坐标为基准）正好有3个互斥点（图 7，f）。最后，在$\gamma \geq 2$处，基于横坐标（图7，d）正好有5个排除点。
