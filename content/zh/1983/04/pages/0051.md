⟦folio 49⟧

F797。扁平电容器充满电介质，其介电导率取决于电容器上的电压$U$，根据定律$\varepsilon = \alpha U$，其中$\alpha = 0,1$$B^{-1}$。与电介质、电介质和电容并联，将一个“非线性”电容器（未充电）连接到一个充电至 $U_0 = 60$ V 电势差的普通电容器。电容器两端的电压是多少？

由于“非线性”电容器与普通电容器的不同之处仅在于其极板之间存在电介质，因此“非线性”电容器在其两端电压$U$下的电容等于

$$C = \varepsilon C_0 = \alpha UC_0,$$

其中$C_0$为普通电容器的容量。在这种情况下，“非线性”电容器上的电荷为

$$q_H = CU = \alpha C_0 U^2,$$

公共电容器上的电荷为

$$q = C_0 U$$

（并联电容器上的电压$U$相同）。

普通电容器的初始电荷等于

$$q_0 = C_0 U_0,$$

并根据电容器上任何电压$U$下的电荷守恒定律

$$q_H + q = q_0 \Rightarrow \alpha C_0 U^2 + C_0 U = C_0 U_0.$$

从这里可以找到电压$U$：

$$U = \frac{\sqrt{4\alpha U_0 + 1} - 1}{2\alpha} = 20 \text{ В.}$$

在线段 $[0; \frac{\pi}{2}]$ 上，正弦、余弦和正切都是单调的。例如，让我们计算所比较数字的余弦：

$$\cos \left( \arcsin \frac{2}{5} \right) = \sqrt{1 - \left( \frac{2}{5} \right)^2} = \frac{\sqrt{21}}{5},$$

$$\cos \left( \arccos \frac{2}{5} \right) = \frac{2}{5}.$$

由于在 $[0; \frac{\pi}{2}]$ 处余弦杀死了，根据不等式

$$\cos \left( \arcsin \frac{2}{5} \right) > \cos \left( \arccos \frac{2}{5} \right)$$

由此可见

$$\arcsin \frac{2}{5} < \arccos \frac{2}{5}.$$

示例 6. 让我们计算 $\arcsin(\sin 11)$。为此，首先将 $11$ 与 $\frac{\pi}{2}$ $k$ ($k \in \mathbb{Z}$) 进行比较。从不等式 $3 < \pi < 3,142$ ($\pi = 3,14159...$) 可以得出 $\frac{7}{2} \pi < 11 < 4\pi$。所以，$-\frac{\pi}{2} < 11 - 4\pi < 0 < \frac{\pi}{2}$。因此$\arcsin(\sin 11) = \arcsin(\sin(11 - 4\pi)) = 11 - 4\pi$。
