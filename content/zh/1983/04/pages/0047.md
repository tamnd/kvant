6) 让我们证明，对于任何自然数$n$，我们都可以找到如此小的数字$\alpha > 0$，使得具有差值$\alpha$的论证级数$1 + \frac{\alpha}{2}, \left(1 + \frac{\alpha}{2}\right) + \alpha, \dots, \left(1 + \frac{\alpha}{2}\right) + n\alpha$和具有值$1 + \alpha$的几何级数$1 + \alpha, (1 + \alpha)^2, \dots, (1 + \alpha)^n$满足问题的条件。

让我们使用恒等式$q^k - 1 = (q - 1)(q^{k-1} + q^{k-2} + \dots + 1)$。将 $q = 1 + \alpha$ 代入其中，我们得到所有 $k \ge 1$

$$(1 + \alpha)^k = 1 + \alpha((1 + \alpha)^{k-1} + (1 + \alpha)^{k-2} + \dots + 1).$$

让我们选择 $\alpha$ 比 $(1 + \alpha)^n < 1 + \frac{1}{2n}$ 小，然后对于所有 $k = 1, \dots, n$

$$(1 + \alpha)^{k-1} + (1 + \alpha)^{k-2} + \dots + 1 < k(1 + \frac{1}{2n}) \leq k + \frac{1}{2}.$$

有了这样的$\alpha$，凭借(*)，所有$k = 1, \dots, n$都满足不等式$(1 + \frac{\alpha}{2}) + (k - 1)\alpha < 1 + k\alpha < (1 + \alpha)^k < 1 + \alpha(k + \frac{1}{2}) = (1 + \frac{\alpha}{2}) + k\alpha$，也就是说，所指示的几何级数的第$k$项包含在论证级数的第$k$项和第$(k + 1)$项之间，这就是我们所要求的。
