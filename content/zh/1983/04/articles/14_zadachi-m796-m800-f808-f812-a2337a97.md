让我们立即证明问题 6) 的答案是肯定的：如果（对于某些 $k > 1$）存在 $b = b_k$，使得 $a(nk) \leq b \cdot a(n)$ 对于所有 $n$，则对于某些 $c$ 和 $a$ $a(n) \leq cn^u$。

$$a(kr) \leq a \cdot br = a \cdot kr^u,$$
其中$a = \log_k b$。对于任何$n$，我们选择$r$，从而得到$kr^{-1} < n \leq kr$，即$\log_k n \leq r < \log_k n + 1$。获得单调性$a(n)$和边缘中的第二个红色恒等式，我们获得：
$$a(n) \leq a(kr) \leq a \cdot br < a \cdot b^{\log_k n + 1} = ab \cdot n^{\log_k b} = cn^u,$$
其中$c = ab$。

现在让我们构建一个示例，表明问题 c) 的答案是否定的。构造一个序列$a(n)$并不困难，它具有多典型性：对于所有$m, n$都有$a(mn) = a(m)a(n)$，同时（对于任何自然的$r$）我们会找到$n$使得$a(n) \geq n^r$。例如，您可以将

设初始时刻直线的主光轴与镜面垂直线的夹角等于α，光斑位于该轴与屏幕的交点（图1处的B点），即经镜面反射后，光线平行于主光轴。短时间$\Delta t$后，镜子将旋转一个小角度$\Delta a = \omega \cdot \Delta t$。从镜子反射的光线相对于轴（图2）“旋转”角度$2\Delta a$，光点将位于屏幕上的C点。让我们求出时间点 $\Delta t$ 的位移 $|BC|$：

$$|BC| = |OB|tg 2\Delta a = Ftg 2\Delta a \approx 2F \cdot \Delta a$$

（我们利用了 $\Delta a$ 小且 tg $\Delta a \approx \Delta a$ 的事实）。知道了位移，我们就可以求出 B 点光点的瞬时速度：

$$v = \frac{|BC|}{\Delta t} = \frac{2F \cdot \Delta a}{\Delta t} = \frac{2F\omega \cdot \Delta t}{\Delta t} = 2F\omega.$$

F797。扁平电容器充满电介质，其介电导率取决于电容器上的电压$U$，根据定律$\varepsilon = \alpha U$，其中$\alpha = 0,1$$B^{-1}$。与电介质、电介质和电容并联，将一个“非线性”电容器（未充电）连接到一个充电至 $U_0 = 60$ V 电势差的普通电容器。电容器两端的电压是多少？

由于“非线性”电容器与普通电容器的不同之处仅在于其极板之间存在电介质，因此“非线性”电容器在其两端电压$U$下的电容等于

$$C = \varepsilon C_0 = \alpha UC_0,$$

其中$C_0$为普通电容器的容量。在这种情况下，“非线性”电容器上的电荷为

$$q_H = CU = \alpha C_0 U^2,$$

公共电容器上的电荷为

$$q = C_0 U$$

（并联电容器上的电压$U$相同）。

普通电容器的初始电荷等于

$$q_0 = C_0 U_0,$$

并根据电容器上任何电压$U$下的电荷守恒定律

$$q_H + q = q_0 \Rightarrow \alpha C_0 U^2 + C_0 U = C_0 U_0.$$

从这里可以找到电压$U$：

$$U = \frac{\sqrt{4\alpha U_0 + 1} - 1}{2\alpha} = 20 \text{ В.}$$

反三角函数

在线段 $[0; \frac{\pi}{2}]$ 上，正弦、余弦和正切都是单调的。例如，让我们计算所比较数字的余弦：

$$\cos \left( \arcsin \frac{2}{5} \right) = \sqrt{1 - \left( \frac{2}{5} \right)^2} = \frac{\sqrt{21}}{5},$$

$$\cos \left( \arccos \frac{2}{5} \right) = \frac{2}{5}.$$

由于在 $[0; \frac{\pi}{2}]$ 处余弦杀死了，根据不等式

$$\cos \left( \arcsin \frac{2}{5} \right) > \cos \left( \arccos \frac{2}{5} \right)$$

由此可见

$$\arcsin \frac{2}{5} < \arccos \frac{2}{5}.$$

示例 6. 让我们计算 $\arcsin(\sin 11)$。为此，首先将 $11$ 与 $\frac{\pi}{2}$ $k$ ($k \in \mathbb{Z}$) 进行比较。从不等式 $3 < \pi < 3,142$ ($\pi = 3,14159...$) 可以得出 $\frac{7}{2} \pi < 11 < 4\pi$。所以，$-\frac{\pi}{2} < 11 - 4\pi < 0 < \frac{\pi}{2}$。因此$\arcsin(\sin 11) = \arcsin(\sin(11 - 4\pi)) = 11 - 4\pi$。
