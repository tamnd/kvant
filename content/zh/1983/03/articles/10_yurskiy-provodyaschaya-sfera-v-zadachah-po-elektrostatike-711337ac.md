动力机械中的导电球问题

S.A.尤尔斯基

球面是最简单的几何形状之一。自然界中靠近其表面的地方有许多物体：太阳和地球、雨滴和花楸浆果，甚至我们想象中的电子都被画成小球。

球体是动力机械问题的一部分。这通常是由于球对称性允许在不影响物理内容的情况下大量使用许多数学计算。

在进行具体任务分析之前，我们先讨论一下动力机械的一些常见问题。

在孤立的物体系统中，无论发生什么变化，正电荷和负电荷的代数和都保持不变。

电相互作用可以定量描述。在最简单的情况下，两个电荷$q_1$和$q_2$位于真空中，彼此距离$r$，它们之间的相互作用力由库仑定律决定

$$F = k \frac{q_1 q_2}{r^2},$$

其中 $k$ 是数值系数，取决于单位制的选择。在 SI 中，它被写为 $k = 1 / (4\pi\varepsilon_0)$（这里 $\varepsilon_0$ 是电常数）。当然，不精确的电荷也会相互作用，但它们的相互作用强度不再由给定的公式决定。在这种情况下，带电体应该在心里被分成精确的电荷，找到每对电荷的相互作用力，然后将所有结果值相加。

如您所知，电荷通过它们产生的电场相互作用。为了定量描述该场，使用合并和能量特征：场强及其潜力。给定点的电场电压$\vec{E}$等于作用在该点的单位正电荷上的力，给定点的电势$\phi$等于场将单位正电荷从该点移动到无穷大所做的功，或者，同样，外力将单位正电荷从无穷大移动到给定点所做的功。我们所说的“无穷大”是指真正远离所有电荷并且其中不存在场的空间区域。

从上述电势的定义可以清楚地看出，只有所考虑的点之间的电势差才具有实际重要性，而不是点电势的绝对值。因此，潜在报告的开始可以任意选择。通常，无穷远点的电位或通过导体连接到地球的任何点（即接地点）的电位为零。对此，我们先来谈谈接地体。

地球是一个尺寸巨大的导电体。它具有显着的负电荷。大气中含有不同的正空间电荷，位于数十公里量级的高层中。在地球表面，场强约为 130 V/m。考虑到地球是一个导电球并且知道表面的场强，我们可以估计地球电荷的大小：

$$E = \frac{q}{4\pi\varepsilon_0 r^2}$$

和潜力

$$\varphi = \frac{q}{4\pi\varepsilon_0 r}.$$

所有实验事实都表明电场具有替代性质：源系统的电场是各个源的场的总和。换句话说，每个固定电荷的场独立于其他电荷的存在。为了找到某一点的强度，只需将各个电荷在该点产生的场的强度进行矢量相加就足够了。为了找到总电势，在给定点处单独计算每个电荷产生的场的电势的代数和就足够了，并且零电势点当然必须是所有电荷所共有的。这种求结果场的原理称为叠加原理。

通常使用张力线（场线）或使用等效电势面以图形方式描绘电场。力线始终垂直于等势面，因此，了解一张图片，您可以轻松获得另一张图片。

“导体”一词通常指的是导电体，即含有自由电荷的任何尺寸和形状的物体，最常见的是金属。在置于电场中的导体内部，电场方向始终为零，并且导体的所有点具有相同的电势。导体中不存在场并不意味着外部场不会渗透到导体中。恰恰相反，由于场渗透到导体中，电荷出现在其表面上，导体内部的场补偿了外部场。因此，导体中的自由电荷只能位于其表面。

为了表征导体积累电荷的能力，引入了一个特殊的物理量——电容。电容器具有很大的电容量——由两个导体（由一层薄薄的电介质隔开）组成的系统，两个导体带有相同但不同的电荷。电容器$C$的电容称为其中一个导体的电荷$q$与它们之间的电势差$\Delta \varphi$之比：$C = q / (\Delta \varphi)$。它取决于导体的尺寸、形状和相对位置，以及电介质的电性能。

$$E = \frac{q}{4\pi\varepsilon_0} r^2, \varphi = \frac{q}{4\pi\varepsilon_0} \left( \frac{1}{r} - \frac{1}{R_2} \right).$$

问题 4. 半径为 r 的不带电金属球围绕半径为 R 的导电壳，电势为 φ。如果球接地 (图 9)，壳电位等于多少？

接地前，外壳电位 φ 由一定的电荷 q 产生： φ = $\frac{q}{4\pi \varepsilon_0 R}$。由于球不带电，因此具有相同的电势。接地后，球的电位变为零。这意味着上面出现了某种电荷。其规模 $q'$ 我们发现，由电荷 q 和 q 产生的总电势 $q'$，在球表面上等于零：

$$\frac{q}{4\pi \varepsilon_0 R} + \frac{q'}{4\pi \varepsilon_0 r} = 0, \text{ и } q' = -\frac{r}{R} q.$$

现在很容易找到新的壳势，它是由相同的电荷 q 和 $q'$ 创建的：

$$\varphi' = \frac{q}{4\pi \varepsilon_0 R} + \frac{q'}{4\pi \varepsilon_0 R} = \frac{q(R-r)}{4\pi \varepsilon_0 R^2} = \frac{R-r}{R} \varphi.$$
