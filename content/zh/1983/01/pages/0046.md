⟦folio 44⟧

M760。对于闭合虚线 $A_1A_2...A_m$，其中 $m$ 为奇数，执行以下操作：其连线的中点通过一条线段连接 $m$（中间 $A_1A_2$ - 与中间 $A_3A_4$，$A_2A_3$ - 与 $A_4A_5$，...，$A_{m-1}A_m$ - 与 $A_1A_2$， $A_mA_1$ - 从$A_2A_3$）。对得到的断线再次执行相同的操作，等等。从 $m=5$ 处的任何$m$-链接断线$a$）证明这一点 - 分两步。
b) 在 $m=7$ - 分三步，
c) 对于任何奇数$m$ - 经过一定数量的步骤（取决于$m$），将获得一条折线，与第一个初始折线类似（进一步准备）。

我们固定一个任意点$O$（我们会在求解过程中指定它的位置），那么任意点$A$都可以由向量$\overrightarrow{OA}$ - 点$A$的向量来指定。如果我们用 $\bar{a}_1 = \overrightarrow{OA}_1$, ..., $\bar{a}_m = \overrightarrow{OA}_m$ 表示给定折线 $J$ 的顶点向量，则从 $J$ 作为给定运算指定的结果获得的折线 $J_1$ 的顶点向量相等
$$\frac{1}{2} (\bar{a}_1 + \bar{a}_2), \frac{1}{2} (\bar{a}_3 + \bar{a}_4), \dots$$
$$\dots, \frac{1}{2} (\bar{a}_m + \bar{a}_1), \frac{1}{2} (\bar{a}_2 + \bar{a}_3), \dots, \frac{1}{2} (\bar{a}_{m-1} + \bar{a}_m).$$

因为线段中间的向量等于其两端的结果向量。同理，下一条折线的顶点向量相等
$$\frac{1}{4} (\bar{a}_1 + \bar{a}_2 + \bar{a}_3 + \bar{a}_4), \frac{1}{4} (\bar{a}_5 + \bar{a}_6 + \bar{a}_7 + \bar{a}_8), \dots$$
$$\dots, \frac{1}{4} (\bar{a}_{m-3} + \bar{a}_{m-2} + \bar{a}_{m-1} + \bar{a}_m).$$

总而言之，要找到折线$J_k$的顶点向量，您需要写出折线$J$$2^k$次的顶点向量序列：
$$\bar{a}_1, \bar{a}_2, \dots \bar{a}_m, \bar{a}_1, \bar{a}_2, \dots, \bar{a}_m, \dots, \bar{a}_1, \bar{a}_2, \dots, \bar{a}_m,$$
将该行的前 $2^k$ 向量、接下来的 $2^k$ 向量相加，依此类推，然后将得到的每个 $m$ 总和除以 $2^k$。

a) 利用导出的规则，我们找到$m=5$的折线$J_2$的顶点向量：
$$\frac{1}{4} (\bar{a}_1 + \bar{a}_2 + \bar{a}_3 + \bar{a}_4), \frac{1}{4} (\bar{a}_5 + \bar{a}_1 + \bar{a}_2 + \bar{a}_3), \dots$$
$$\dots, \frac{1}{4} (\bar{a}_2 + \bar{a}_3 + \bar{a}_4 + \bar{a}_5)$$
或者，假设 $\bar{a}_1 + \bar{a}_2 + \bar{a}_3 + \bar{a}_4 + \bar{a}_5 = \bar{a}$：
$$\frac{1}{4} (\bar{a} - \bar{a}_5), \frac{1}{4} (\bar{a} - \bar{a}_4), \frac{1}{4} (\bar{a} - \bar{a}_3), \frac{1}{4} (\bar{a} - \bar{a}_2), \frac{1}{4} (\bar{a} - \bar{a}_1).$$

现在请注意，始终可以选择点 $O$，使得折线 $J$ 的顶点向量之和 $\bar{a}$ 等于 $\overrightarrow{O}$（参见解法末尾）。在这种情况下，折线$J_2$的顶点向量将等于$-\frac{1}{4} \bar{a}_5, -\frac{1}{4} \bar{a}_4, -\frac{1}{4} \bar{a}_3, -\frac{1}{4} \bar{a}_2, -\frac{1}{4} \bar{a}_1$，因此顶点本身已准备好。

折线$J$相对于点$O$的顶点，系数为$-1/4$（参见图）：折线$J_2$的第1个顶点对应于折线$J$的第5个顶点$A_5$，第2个 - 对应于$A_4$，第三名 - $A_3$，第四名 - $A_2$，第五名 - $A_1$。在这种情况下，连接顶点$J_2$的顺序将与相应顶点$J$相同，尽管它们的遍历方向相反。

b), c) 您始终可以选择 $k$，使得数字 $2^k-1$ 可以被奇数 $m$ 整除。 （特别是在任务 6 中）$m=7$ 和 $k=3$。事实上，数字 1、2、$2^2$、... 的平均值必须找到 duya、$2^l$ 和 $2^n$ ($l<n$)，它们除以 $m$ 时得到相同的余数。它们的差 $2^n-2^l=2^l(2^n-l-1)$ 可以被 $m$整除，没有余数。由于$m$是奇数，因此在$k=n-l$处，数字$2^k-1$可以被$m$整除；让$2^k-1=mp$。

然后$2^k=mp+1$，根据我们寻找折线$J_k$顶点向量的规则，它们表示为以下形式
$$\frac{1}{2^k} (p\bar{a} + \bar{a}_1), \frac{1}{2^k} (p\bar{a} + \bar{a}_2), \dots, \frac{1}{2^k} (p\bar{a} + \bar{a}_m),$$

其中$\bar{a}=\bar{a}_1+\dots+\bar{a}_m$。如果选择点$O$使得$\bar{a}=\overrightarrow{OA}_1+\dots+\overrightarrow{OA}_m=\overrightarrow{O}$，则折线$J_k$的顶点向量等于$2^{-k}\bar{a}_1, \dots, 2^{-k}\bar{a}_m$，因此它是由以制备中心$O$和系数$2^{-k}$为中心的折线$J$制备的。
