主要因素。首先，请注意，如果 $p$ 是素数，则 $\varphi(p) = p - 1$，因为所有数字 1、2、...、$(p - 1)$ 都与 $p$ 互质且小于它。设$n = p^\alpha$，其中$p$是素数，$\alpha > 1$。那么从$n$数中，在不超过$n$的情况下，我们必须排除那些能被$p$整除的数。所以数字

$$\frac{n}{p} = \frac{p^\alpha}{p} = p^{\alpha - 1},$$

姿势

$$\varphi(n) = n - \frac{n}{p} = n \left(1 - \frac{1}{p}\right).$$

现在让我们考虑具有两个不同质因数的数字$n = p_1^{\alpha_1} p_2^{\alpha_2}$。我们用图 4上的图来说明$\varphi(n)$的计数（对于$n = 18$继续到图3）：正方形代表从1到$n$的数字集合，红色和蓝色圆圈分别是能被$p_1$和$p_2$整除的数字集合，圆圈的交集是能被$p_1 p_2$整除的数字。

与 $n$ 互质的数字由正方形的阴影部分表示。为了确定它们的数量，我们必须排除$N_1 = n/p_1$“红色数字”，$N_2 = n/p_2$“蓝色”数字，并添加$N_{12} = n/p_1 p_2$位于圆圈交点的数字。因此，

$$\varphi(n) = N - N_1 - N_2 + N_{12} = n - \frac{n}{p_1} - \frac{n}{p_2} + \frac{n}{p_1 p_2} =$$

$$= n \left(1 - \frac{1}{p_1}\right) \left(1 - \frac{1}{p_2}\right).$$

图 5 将帮助我们分析数字$n = p_1^{\alpha_1} p_2^{\alpha_2}$在不同因数下的情况：正方形代表不超过它们的数字集合，圆圈代表能被$p_1$、$p_2$和$p_3$整除的数字集合；那么在圆圈中将有 $N_1 = \frac{n}{p_1}, N_2 = \frac{n}{p_2}$ 和 $N_3 = \frac{n}{p_3}$ 数字对应，在它们的成对交点中 - $N_{12} = \frac{n}{p_1 p_2}, N_{13} = \frac{n}{p_1 p_3}$ 和 $N_{23} = \frac{n}{p_2 p_3}$ 数字，并且在所有三个圆圈的交点中 - $N_{123} = \frac{n}{p_1 p_2 p_3}$ 数字（这些是可同时被 $p_1, p_2$ 和 $p_3$ 整除的数字，即$p_1 p_2 p_3$）。

我们必须计算有多少个数字包含在正方形中但不落入任何圆圈中。如果我们用$n$减去总和$(N_1 + N_2 + N_3)$，那么我们就减去恰好落入三个圆中的两个圆的数字两次，甚至减去落入所有三个圆的数字三次。
