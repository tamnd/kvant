剩下的就是解释如何找到我们需要的点$O$——相似中心。顶点向量之和可以写为
$$\bar{a} = \overrightarrow{OA}_1 + \overrightarrow{OA}_2 + \dots + \overrightarrow{OA}_m = \overrightarrow{OA}_1 + (\overrightarrow{OA}_1 + \overrightarrow{A}_1\overrightarrow{A}_2) + \dots$$
$$\dots + (\overrightarrow{OA}_1 + \overrightarrow{A}_1\overrightarrow{A}_m) = m \cdot \overrightarrow{OA}_1 + (\overrightarrow{A}_1\overrightarrow{A}_2 + \dots + \overrightarrow{A}_1\overrightarrow{A}_m),$$
posnomu，如果$\overrightarrow{A}_1\overrightarrow{O} = \frac{1}{m} (\overrightarrow{A}_1\overrightarrow{A}_2 + \dots + \overrightarrow{A}_1\overrightarrow{A}_m)$，则$\bar{a} = \overrightarrow{0}$。 （该点$O$是放置在点$A_1, A_2, \dots, A_m$处的相同质量的重心）。

**M763*。给定一个与菱形不同的平行四边形 ABCD。相对于对角线 AC 与直线 AB 对称的直线与相对于对角线 DB 与直线 DC 对称的直线相交于点 Q。如果关系 $|AC|:|BD| = k$ 已知，则求关系 $|QA|:|QD|$。

让我们输入$AQO = OQD = \varphi$，$QAO = \alpha$，$QDO = \beta$。然后$AOD = 2\pi - \alpha - \beta - 2\varphi$。同时，$AOD$是三角形ODC的外角，其中$OCD = OAB = \alpha$、$ODC = \beta$（见图）。因此，$AOD = \alpha + \beta$，即$2\pi - \alpha - \beta - 2\varphi = \alpha + \beta$。由此可见，$\alpha + \beta + \varphi = \pi$ 意味着$AOQ = \pi - \alpha - \varphi = \beta - ODQ$。由于三角形$AQO$和$OQD$对应的角相等，因此它们相似，相似系数为$|AO|:|OD| = |AC|:|BD| = k$。因此，

$$\frac{|QA|}{|QD|} = \frac{|QA|}{|QO|} \cdot \frac{|QO|}{|QD|} = k^2.$$

评论。这项看似人为的任务的起源值得探索。重点是$Q$是相似变换的不动点（两个可能的变换之一），它将点$A$到$O$，以及$O$到$D$。它可以表示为围绕点$Q$转动角度$\varphi$（在我们的图上 - 顺时针）并准备$H^k_Q$的组合。这种类型的变换称为子旋转数或螺旋相似度。因此，如果给定点$A, F(A) (= O)$和$F(F(A)) (= D)$，问题条件中描述的构造允许我们找到螺旋相似度$F$。第二次相似变换，取点$A$和$O$到$O$
