入口车间

以下是1982年高考公布的材料。

莫斯科物理技术学院

Matematika
笔试

选项1

1. 解决不等式
$$81^x + 3^{2x+1} > 54.$$
2. 梯形$ABCD\ BAD = 90^\circ, ADC = 30^\circ$。圆心位于线段 AD 上的圆与直线 AB、BC 和 CD 相切。如果知道圆的半径为R，求梯形的面积。
3. 求解方程组
$$\begin{cases} tg y - tg x = 1 + tg x \cdot tg y \\ \cos 2y + \sqrt{3} \cos 2x = -1. \end{cases}$$
4. 从点 $M(1; 1)$ 向双曲线 $y = \frac{k}{x}$ ($k < 0$) 的两条分支画切线，在点 A 和 B 处与这些分支相切，并且三角形 MAB 是正三角形。求系数k和三角形MAB的面积。
5. 在正六边形中，取$SABCDEF$（S为顶点），底边长度为2。菱形KLMFF的顶点K、M分别位于边AB、SD和$|KM| = 3$上，线段KL与边SB相交。求初级的体积。

选项2

1. 解方程
$$\log_3 x - \frac{2}{1 + \log_2 7} = \frac{6}{3 + \log_3 x}.$$
2. 解方程
$$\frac{\cos 3x}{\sin 3x - 2 \sin x} = tg x.$$
3. 等腰三角形$ABC$($\hat{C} = 90^\circ$)和三角形$DEF$排列成D点在AB边上，E点在AB边到A点的延长线上。线段KL是一般三角形的中线，四边形$DKLB$的面积是$\frac{5}{8}$三角形$ABC$的面积。找到$DEF$。
4. 求图形的面积，该面积在不等式组的坐标平面上指定

$$\begin{cases} x^2 + y^2 \geq 10 \\ 3x^2 - 4x - 32 \leq 0 \\ (3x - 2y)(3y - x + 10) \geq 0. \end{cases}$$

5. 在正确的例子$ABCA_1B_1C_1$中，侧边的长度为3。点M是边AC的中间，点N位于边$B_1C_1$上，点P属于面$AA_1B_1B$并且与平面ABC相距1的距离。已知直线PM和PN与平面$AA_1B_1B$和直线PN所成的角为30°。飞机$BB_1C_1C$。求初级的体积。

选项3

1. 解方程
$$\sqrt{\frac{x+5}{2x+1}} - \sqrt{5x-3} = 0.$$
2. 解决不等式
$$\log_2 - x \left( \frac{3-x}{4-x} \right) < 1.$$
3. 排列正方形$ABCD$和圆，使得圆在C点与直线AC相切，圆心与点D位于直线AC的同一侧。从D点画的圆的切线形成120°角。求面积与给定周长的圆面积之比。
4. 求解方程组
$$\begin{cases} 3 \cos(4x-2y) = \sqrt{2} \cos(2x-2y) \\ \sqrt{2} \sin(x+y) = 3 \sin(y-x). \end{cases}$$
5. 中心分别位于半径为 3 和 1 的点 $O_1$ 和 $O_2$ 的球体彼此接触。通过距离 $O_2$ 3 的点 M，画两条直线，每条直线都接触两个球体，切点位于 M 点一侧的直线上。如果已知其中一条与直线 $O_1O_2$ 形成 45° 角，则求切线之间的角度。

选项1

1. 狗 C 沿着路径 AB 以恒定速度 $v_0$ 运行，与水平张力线 MN (图 1) 形成角度 $\alpha = 60^\circ$。一条长度为 l 的轻型水平吊绳系在狗评估器上。电缆连接到质量为 m 的杆 K，该杆沿着电线滑动，没有任何摩擦。求当环和挡块与路径和电线的交点 T 距离相等时，电缆中的张力。
2. 将一摩尔理想气体在等压下加热，然后在等体积下转移至初始温度$T_0 = 300$K的状态。结果发现，Q=5000J的量转移到了该气体中。气体所占的体积变化了多少次？
