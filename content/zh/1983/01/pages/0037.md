⟦folio 35⟧

同时落入所有三个圆圈是不正确的：我们将它们的数字减去三次，然后再将它们添加三次。您必须从总和 $N - (N_1 + N_2 + N_3) + (N_{12} + N_{13} + N_{23})$ 中减去另一个 $N_{123}$。现在我们把这三个圆的并集所包含的所有数字都记住一次，得到下面的公式：

$$\varphi(n) = n - \frac{n}{p_1} - \frac{n}{p_2} - \frac{n}{p_3} + \frac{n}{p_1 p_2} + \frac{n}{p_1 p_3} + \frac{n}{p_2 p_3} - \frac{n}{p_1 p_2 p_3} = n \left(1 - \frac{1}{p_1}\right) \left(1 - \frac{1}{p_2}\right) \left(1 - \frac{1}{p_3}\right).$$

我们在这里遇到了这个承诺的计数规则的特殊情况。

包含和排除规则。给定集合$A$并选择其子集$k$。集合$A$中不包含在任何选定子集中的元素个数计算如下：从元素总数$A$减去所有$k$子集的元素个数，加上所有两两交集的元素个数，减去所有三重交集的元素个数，将所有交集的元素个数加4，依此类推，直到所有$k$的交集子集。

将此规则应用于计算 $\varphi(n)$，其中

$$n = p_1^{a_1} p_2^{a_2} \dots p_k^{a_k},$$

并使用代数恒等式

$$1 - x_1 - x_2 - \dots - x_k + x_1 x_2 + x_1 x_3 + \dots + x_{k-1} x_k - x_1 x_2 x_3 - \dots - x_{k-2} x_{k-1} x_k + \dots + (-1)^k x_1 x_2 \dots x_k = (1 - x_1) (1 - x_2) \dots (1 - x_k)$$

（其设备左侧正是按照“包含与排除”的规则），可以得到通式

$$\varphi(n) = n \left(1 - \frac{1}{p_1}\right) \left(1 - \frac{1}{p_2}\right) \dots \left(1 - \frac{1}{p_k}\right).$$

注意，上面写的代数恒等式也可以用来证明包含和排除的一般规则：通过设置$k$字母$x_1, x_2, \dots, x_k$中的几个$j$等于1，剩余的$(k - j)$等于0，我们得到（对于$0 < j \leq k$）右侧0，左侧表明交集元素正好是$j$子集相加并减去相同的次数。

总之，我们注意到上一节中的函数 $\varphi(n)$ 和函数 $d(n)$ 具有如此重要的性质，在数论中称为乘法：

如果 $a$ 和 $b$ 互质，则 $\varphi(ab) = \varphi(a) \cdot \varphi(b)$ 和 $d(ab) = d(a) d(b)$
