**M764**。证明每个方程$a) x^2 + y^2 = z^5$； $b) x^2 + y^2 + z^5 = t^7$ 有无数个自然数解。

**a) 让我们尝试在相同自然数 $a: x = a^k, y = a^e, z = a^m$ 的幂中寻找解（$k, e, m$ 是自然数）。

将这样的$x, y, z$代入方程，得到等式$a^{2k} + a^{3e} = a^{5m}$。很容易看出，对于 $2k \neq 3e$ 这样的等式是不可能的。因此$2a^{2k} = a^{5m}$。由此可知$a = 2$。

我们接近$x = 2^{3n}, y = 2^{2n}$，而$x^2 + y^2 = 2^{6n+1}$，因此，数字$6n+1$必须能被5整除。

由于 $6n+1$ 仅在 $n = 5s+4$ ($s \geq 0$) 处可被 5 整除，因此我们得到无穷级数的解：

$$x = 2^{15s+12}, y = 2^{10s+8}, z = 2^{6s+5}, s \in Z, s \geq 0.$$

b) 与 $a$) 类似地求解。我们需要寻找满足$x = 3^{15n}, y = 3^{10n}, z = 3^{6n}$的解决方案。代入方程后，我们得到$3^{30n+1} = t^7$，但对于$n = 7s+3$、$s \geq 0$、$s \in Z$，$30n+1$ 可以被 7 整除。我们得到了无穷级数的解$x = 3^{105s+45}, y = 3^{70s+30}, z = 3^{42s+18}, t = 3^{30s+13}$。

很容易看出，如果简单地从$b$中减去数字$a_1, a_2, \dots, a_n$的最小公倍数$M$，则方程$x^2 + x^2 + \dots + x^n = y^b$一般有无限多个整数解。如点$a$和$b$），可以以数字$n$的幂的形式寻求解决方案。

我们逼近$x_1 = n^{M_t}, \dots, x_n = n^{a_n}$，其中$t \in N$。将$x_1, x_2, \dots, x_n$代入方程后，我们得到等式$n^{M_t+1} = y^b$，并且由于$M$和$b$只是相减，因此存在无限多个$t$，其中$M_t+1$可以被$b$整除。

假设系统开始移动后的短时间内$\Delta t$，环下降到距$A$距离$\Delta x$，并获得速度$v$。此时箍的平移运动速度应等于$u = vtg\alpha$（$\Delta t$太小，以致角度$\alpha$几乎没有改变）。因此，圈上所有点的线速度是相同的。根据能量守恒定律，

（$Mu^2$是给定时刻每个环的总动能）。从这个等式我们发现，

$$a = g \frac{1}{1 + 4\frac{M}{m}tg^2\alpha}.$$

F779。一个由质量比等于二的两半组成的正方形位于粗糙的表面上。为了使正方形向前移动，表面平面必须与两半之间的界面成什么角度α？力的作用点位于正方形的边与界面的交点处。

让正方形向前移动，同时螺纹与直线AB形成角度α（见图nok）。作用在正方形左半部分的摩擦力与正方形的运动方向相反，并穿过左半部分的质心（我们假设法向压力均匀分布在正方形与水平面的接触面上）。该力的绝对值等于

$$F_1 = \mu m_1 g,$$

其中 μ 是摩擦系数，$m_1$ 是正方形左半部分的质量。作用在正方形右半部分的摩擦力穿过整个正方形的质心。因此，拉绳子的力的作用线必须穿过正方形的质心（图н上的点O），也就是说，绳子必须与线AB形成角度α，使得（参见图н）

$$tg \alpha = x/a.$$

$$\mu m_1 g \left( \frac{a}{2} - x \right) \cos \varphi = \mu m_2 g \left( \frac{a}{2} + x \right) \cos \varphi,$$

在哪里

$$x = \frac{a (m_1 - m_2)}{2 (m_1 + m_2)}.$$

考虑到 $m_1/m_2 = 2$，我们找到 tanα：

$$tg \alpha = \frac{x}{a} = \frac{1}{6}.$$

F780。一个高度为 2h 的圆柱形容器，被隔板等分，上部含有水（其密度 Q），下部含有大气压$p_0$ 的空气。隔板上有一个小孔，以便水开始流入容器的下部。当空气开始从孔中向上流动时，容器底部的水层有多厚？温度恒定。重物的力的加速度为g。

当容器底部的空气压力超过孔水平面的水压（即压力）时，空气开始向上穿过孔。

$$p = p_0 + \varrho g (h - x),$$

其中x是容器上部水位的降低，相应地，是容器下部水层的厚度。由于空气温度不变，根据波伊尔-马里奥特定律

$$p_0 h S = p (h - x) S,$$

其中S是容器底部的面积。

因此，

$$p_0 (h - x) + \varrho g (h - x)^2 = p_0 h,$$

在哪里

$$\varrho g x^2 - (2 \varrho g h + p_0) x + \varrho g h^2 = 0.$$

解这个方程，我们找到 x：

$$x = h + \frac{p_0}{2 \varrho g} \left( 1 - \sqrt{1 + \frac{4 \varrho g h}{p_0}} \right).$$

（解 x = h + \frac{p_0}{2 \varrho g} \left( 1 + \sqrt{1 + \frac{4 \varrho g h}{p_0}} \right) 不合适，因为 x < h 已完成。）

F781。在半径为 a 和 b 的两个独立金属同心球之间，距球中心距离 c 处存在精确的电荷 q。如果球体与细导体闭合，将流过细导体的电荷是多少？

起初，小球体没有带电。球体闭合后，新电荷被转移到其表面，该电荷不均匀地分布在其表面上。让我们表示该电荷的大小$q_1$。在这种情况下，大球体的内表面上将出现电荷$q_2$，并且该电荷在该表面上的分布也是不均匀的。由电荷 q 产生的场线终止于小球体和大球体的内表面。因此，$q_2$的电荷必须等于

$$q_2 = -(q + q_1).$$

由于这些漏极线不会仅穿过大球体来穿透干扰，因此该球体外表面上的电荷均匀分布，并且不会在内球体和外球体之间产生电场。这意味着，通过使内球和外球的电势相等（球体通过导体连接），可以忽略该电荷，并且可以将外球的电势视为等于0。那么球心的电势也将为零（小球内部没有场，小球的电势等于球心的电势）。

因此，

$$\frac{q_1}{4\pi\varepsilon_0 a} + \frac{q_2}{4\pi\varepsilon_0 b} + \frac{q}{4\pi\varepsilon_0 c} = 0.$$

代入$q_2 = -(q + q_1)$，由这个条件我们找到$q_1$：

$$q_1 = -q \frac{\frac{1}{c} - \frac{1}{b}}{\frac{1}{a} - \frac{1}{b}}.$$

显然，电荷$q_1$的大小不取决于球体的初始电荷，而仅由q的大小和系统的尺寸决定。所有“额外”电荷将位于大球体的外表面，决定了导体的整体电势。有趣的是，当电荷 q 移动时（随着 c 的变化），$q_1$ 的值（因此$q_2$ 和 $q_{\text{внешш}}$）都会发生变化；因此，外面的场也会发生变化。这种球形“屏幕”的内部场不取决于外部电荷的大小和位置。

F782。将电容器充电至 $U_0 = 100$ V 的电压，并连接一个电阻器。同时，在一定的时间间隔内，释放了$W_1 = 1$ J的小牛肉，在同一时间间隔内，释放了$W_2 = 0,3$ J的能量。确定电容器的电容。

在第一个间隔结束时，让电容器两端的电压降至$U_1$。根据能量守恒定律，

$$\frac{CU_0^2}{2} = W_1 + \frac{CU_1^2}{2},$$

在哪里

$$U_1 = U_0 \sqrt{1 - \frac{2W_1}{CU_0^2}}.$$

很明显，如果电容器上的初始电压小于$U_0$ n 倍，那么在相同的时间间隔内，小牛肉将在电阻器上释放$n^2$ 倍小于$W_1$。这意味着

$$\frac{W_2}{W_1} = \frac{U_1^2}{U_0^2}$$

（$U_1$是下一个时间间隔的初始电压）。将之前得到的值$U_1$代入这个表达式，我们找到C：

$$C = \frac{2W_1}{U_0^2 \left(1 - \frac{W_2}{W_1}\right)} \approx 29 \text{ мкФ}.$$
