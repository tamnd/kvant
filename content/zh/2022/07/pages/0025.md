数学

您可能认识著名的 Thue-Morse 序列。

图埃-莫尔斯序列

Thue-Morse 序列包含在 OEIS 编号 A010060 中。百科全书使用该序列的更常见版本，其中出现数字 0 和 1，而不是 A 和 B。Thue-Morse 序列是通过按顺序向现有片段分配第二个同类片段而获得的，但其中所有元素都被其相反元素替换（0 到 1、1 到 0）。让我们从0开始：

0

01

0110

01101001

0110100110010110...

这个序列是自相似的：它与它自己的子序列一致，由每隔一个成员组成（以及第二个子序列 1001...，但元素被相反的元素替换）：

0110100110010110 …

0 1 1 0 1 0 0 1 …

这一观察结果提出了另一种获取序列的方法：从一串 0 开始，重复替换 0 o 01, 1 o 10。获得相同序列的另一种方法是计算 n 的二进制表示法中 1 的数量，然后将该数字除以 2 取余数。这将给出 Thue-Morse 序列的第 n 项（想想为什么）。这种方法还建议如何构建由数字 0、1、2 组成的 Thue-Morse 序列的类似物。您需要将数字 n 的三进制表示法中的数字相加，并取除以 3 的余数（您将得到 012120201... - OEIS 中的序列 A053838）；类似地，在具有任何其他基数的数字系统中书写。您可以用替换语言描述这些广义的 Thue-Morse 序列（想想如何）。

⟦column⟧

Thue-Morse 序列的特性之一是它的任何片段连续重复两次以上，但非连续重复也是可能的。这一特性导致人们从意想不到的角度重新发现了该序列。未来的国际象棋世界冠军、数学家Max Euwe指出，如果Thue-Morse序列中的0和1对应于某种不同的移动序列，使棋盘上的位置返回到原来的位置，那么这个序列将允许游戏无限期地继续下去。让我们回想一下，在20世纪初，国际象棋中有一条规则，根据该规则，当相同的走法连续重复3次时，就宣布平局。为了让 Eu​​we 的设计失效，现代规则要求游戏必须通过重复任意位置 3 次来完成。如果您尝试根据以下规则绘制一条由相同长度的链接组成的折线，就会出现图埃-莫尔斯序列的另一种应用，一方面美观，另一方面有趣。当 Thue-Morse 序列中出现 0 时，画一条链接并向左转动 60q；当遇到1时，我们保持原样，并将绘制下一个链接的方向更改为180q。因此，在第一个链接之后，在 60q 处有一个左转，在第二个链接之后，在 120q 处有一个右转（向左 60q，另一个 180q），等等。绘制至少十几个链接。会发生什么？请注意，Thue-Morse 序列也出现在体育节目中。感兴趣的读者可以通过访问 oeis.org 找到 Thue-Morse 序列的许多其他应用。我们将回到箭头。在文章[3]中证明了镜头的公平顺序确实是由 Thue-Morse 序列描述的。为此，我们首先证明，如果我们将序列的项分组为对，那么每对将有两个不同的值（AB BA BA AB...），然后我们通过归纳证明自相似性。
