来自牛顿定律和宇宙定律
伯努利王朝的代表之一提出了万有引力，物理学家开始考虑“作为一个整体”的宇宙模型。

在牛顿时代直到二十世纪，宇宙似乎是均匀的、各向同性的和静止的。同质性意味着相同的定律适用于宇宙的所有点，并且宇宙中没有任何一个点可以被坐标原点所包含 - 所有点都是平等的。各向同性意味着所有方向都是相等的 - 不存在单一方向。静止性被理解为宇宙作为一个整体的不变性，由此得出平均每个点都应该保持在其位置上，或者相同的是，宇宙中所有物体之间的距离应该保持不变。人们立即发现，只有空的宇宙才能具有这样的性质，即一个没有物质的宇宙，或者说，物质的密度为零的宇宙。

事实上，让我们假设宇宙中物质的密度为 ρ > 0。那么从同质性可以看出，宇宙中的物质按照这个密度均匀分布。现在让我们考虑某个点 A。假设这是我们所居住的宇宙中的一个点，地球或太阳系，我们将尝试确定宇宙中其余物质以什么力作用于质量为 m 的物质点 A。我们将遇到牛顿知道的两个事实。

1. 位于球体内部的物体，其表面上的物质均匀分布，不受任何力边界的影响（所有力都是平衡的、复杂的）。

2. 物质均匀分布在表面上的球体作用于球体外部的质量为 m 的物体，就好像质量集中在球体的中心一样。因此，球也是如此，其物质的密度仅取决于半径（球对称分布）。

任务 1. 证明这些事实。

现在让我们选择距离 A 点为 R 的点 B。根据同质性，我们可以选择任何点。将宇宙分成以A点为圆心的球体。根据第一个事实，物质在半径为R的球体外部作用的力为零，集中在以A为中心、半径为R的球体中的物质将作用在B上

$$F = -G \frac{mM_{AB}}{R^2}.$$

这意味着点$B$相对于点$A$应该经历生根，即移动，这与静止性相矛盾，并且直到二十世纪才出现，与宇宙的单回路性质相矛盾。

二十世纪对这一矛盾做出了自己的修正：爱因斯坦和庞加莱建立了广义相对论（GTR），亚历山大·弗里德曼从广义相对论中汲取了现在所谓的“现代宇宙学标准模型”——宇宙作为一个整体的模型。1事实证明，这个模型包含三个根本不同的模型，并找出我们生活的世界中的哪一个回到了我们身边。此外，所有三个模型在宇宙物质密度$\rho > 0$下都是非平稳的。

同质性又如何呢？在所有三个模型中，从观测点 $A$ 可见的星系退行速度与到 $A$ 的距离成正比。这是否与同质性相矛盾？

答：完全一样！

在进一步阅读之前尝试自己解决这个问题。我们将在这里提出这个问题的解决方案，因为我们需要这个事实。要记住的主要一点是距离（位移）就像速度一样，是一个矢量。

我们选择一颗测试星$C$。令 $\vec{v}_{AB}$ 和 $\vec{v}_{AC}$ 分别为恒星 $B$ 和 $C$ 的速度，$\vec{v}_{AB} = H \cdot \overrightarrow{AB}, \vec{v}_{AC} = H \cdot \overrightarrow{AC}$，其中 $H$ 是比例系数，即哈勃常数，传统上用这个字母表示，以纪念替补的美国天文学家埃德温·哈勃。2

$$\vec{v}_{BC} = \vec{v}_{AC} - \vec{v}_{AB} = H \cdot \overrightarrow{AC} - H \cdot \overrightarrow{AB} = H \cdot (\overrightarrow{AC} - \overrightarrow{AB}) = H \cdot \overrightarrow{BC}.$$

因此，在识别出恒星$B$的行星后，宇航员将看到所有恒星都以与其距离成正比的速度远离恒星$B$。并且比例系数是相同的——$H$。

但是，如果在牛顿静止模型中，我们假设星系在每个时刻都以与它们之间的距离成正比的速度相互远离呢？这相当于相对距离保持不变。

因此，我们宇宙中的物体必须满足的第一个方程是

$$R' = H \cdot R,$$

阿尔伯特·爱因斯坦

变化率是$x$和$x''$，即二阶导数是变量$x$的加速度。

观察点$A$的位置，并考虑距离$R = R(t)$、质量为$m_B$的点$B$的运动。让我们用 $M_0$ 表示以点 $A$ 为中心、半径为 $R$ 的球的质量。有必要考虑这样一个球的事实是从牛顿已知的事实 1 和 2 得出的。半径$R = R(t)$改变了，但我们相信这个球内物质的质量$M_0$不变，即物质既不出现也不消失。以点 $A$ 为中心、半径为 $R$ 的球作用在 $B$ 上的力等于

$$F = -G \frac{m_B M_0}{R^2}, \quad F = m_B R''.$$

所以我们需要求解微分方程

$$R'' = -\frac{GM_0}{R^2}.$$

牛顿如何解这个方程？他要做的第一件事就是用微分重写它：

$$\frac{dR'}{dt} = -\frac{GM_0}{R^2}, \quad \text{или} \quad dR' = -\frac{GM_0 dt}{R^2}.$$

然后我将两边乘以 $R'$：

$$R' dR' = -GM_0 \frac{R' dt}{R^2},$$

在左右差速器下行驶$R'$：

$$d \frac{(R')^2}{2} = -GM_0 \frac{dR}{R^2},$$

得到一个可积分的方程，并对它进行积分：

$$(R')^2 = 2GM_0 \frac{1}{R} + c.$$

因此，

$$R' = \pm \sqrt{\frac{2GM_0}{R}} + c.$$

该方程是能量守恒定律除以$m_B$。请注意，$c$是无穷远速度的平方，即在$R = \infty$时的速度，并且一般来说，这个积分常数对于每个对象$B$来说可以是不同的。另外，$c$也可以为负数。从物理上讲，这意味着物体 $B$ 无法到达无穷远，并且位于由等式 $0 = \frac{2GM_0}{R_k} + c$ 定义的有限距离 $R_k$ 处，其中 $c < 0$ 回头并开始接近。尽管 $R_k$ 对于不同的对象可能有所不同，但对于每个人来说，发生这种情况的时刻都是相同的 - 这是 $H$ 变为零的时刻。

在最后一个方程中，根的符号的选择与时间参数$t$的符号的选择有关，因此我们将只考虑平面的符号并引入常数$c_1 = 2GM_0$。现在让我们分离变量并积分：

$$\frac{dR}{dt} = \sqrt{\frac{2GM_0}{R}} + c,$$

$$dt = \frac{1}{\sqrt{\frac{c_1}{R}} + c} dR,$$

$$t + t_0 = \int \sqrt{\frac{R}{cR + c_1}} dR.$$

常数$t_0$与时间不存在的选择相关，可以认为等于0。

亨利·庞加莱

右边的积分是通过替换 $u^2 = \frac{R}{cR + c_1}$ 得到的。让我们通过新变量 $u$ 来表达旧变量 $R$：

$$R = \frac{c_1 u^2}{1 - cu^2},$$

让我们找到 $dR$：

$$dR = \frac{c_1}{c} d \frac{1}{1 - cu^2}$$

从 $dt$ 与 $dR$ 连接的方程我们得到

$$t = \frac{c_1}{c} \int u d\left(\frac{1}{1 - cu^2}\right),$$

或者，通过部分整合，

$$t = \frac{c_1}{c} \left(\frac{u}{1 - cu^2} - \int \frac{du}{1 - cu^2}\right).$$

最后一个积分是表格形式的，取决于 $c$ 的符号：

$$t = \begin{cases} \frac{c_1}{c} \left(\frac{u}{1 - cu^2} - \frac{1}{2\sqrt{c}} \ln \left| \frac{1 + \sqrt{cu}}{1 - \sqrt{cu}} \right|\right), & \text{ если } c > 0, \\ \frac{2}{3} \frac{1}{\sqrt{c_1}} \left(R^{3/2}\right), & \text{ если } c = 0, \\ \frac{c_1}{c} \left(\frac{u}{1 - cu^2} - \frac{1}{\sqrt{|c|}} \mathrm{arctg}\left(\sqrt{|c|} u\right)\right), & \text{ если } c < 0. \end{cases}$$

记住替换$u = \sqrt{\frac{R}{cR + c_1}}$，我们得到

$$\begin{cases} \frac{c_1}{c} \left(\frac{\sqrt{R(cR + c_1)}}{c_1} - \frac{1}{2\sqrt{c}} \ln \left| \frac{\sqrt{cR + c_1} + \sqrt{cR}}{\sqrt{cR + c_1} - \sqrt{cR}} \right|\right), \\ \text{ если } c > 0, \\ \frac{2}{3} \frac{1}{\sqrt{c_1}} \left(R^{3/2}\right), \text{ если } c = 0, \\ \frac{c_1}{c} \left(\frac{\sqrt{R(cR + c_1)}}{c_1} - \frac{1}{2\sqrt{c}} \ln \left| \frac{\sqrt{cR + c_1} + \sqrt{cR}}{\sqrt{cR + c_1} - \sqrt{cR}} \right|\right), \\ \text{ если } c < 0. \end{cases}$$

当然，牛顿可以轻松处理所有的计算。

现在我们有两个任务：

1) 证明我们已经得到了精确的弗里德曼解；
2) 表明我们的决定是一致的。

第2部分

• 最简单的情况是$c = 0$。我们得到

$$t = \frac{2}{3} \frac{1}{\sqrt{c_1}} \left(R^{3/2}\right),$$

$$R = \left(\frac{3}{2} \sqrt{c_1}\right)^{2/3} t^{2/3},$$

$$R' = \left(\frac{3}{2} \sqrt{c_1}\right)^{2/3} \cdot \frac{2}{3} t^{-1/3},$$

$$H = \frac{2}{3} t^{-1}.$$

从最后一个等式可以看出，$H$不依赖于任何常数，而只依赖于时间。这意味着空间中的所有点都是相同的。在这种情况下，可以轻松计算平均密度对时间的依赖性：

$$\rho = \frac{1}{6\pi G} t^{-2}.$$

第三部分

请注意，我们从未使用过宇宙不同点之间的任何联系。所有的不确定性都在于我们无法确定不同初始点的常数$c$之间的关系。即使我们在不同的时间考虑点$A$，我们也不能说常数$c$是否相同。但是我们对宇宙还有另一个假设，在这种情况下可以称为关于宇宙状态的假设。这是假设宇宙的密度在初始时间点相同。

问题 4. 证明密度的变化由方程给出
$$\rho' = -3\rho \frac{R'}{R} = -3\rho H.$$

从问题 4 可以看出，如果在某个时刻，密度 $\rho$ 和 CONSTANTA $H$ 在所有点上都相同，那么在下一个时刻密度将相同。

现在让我们回到所得到的等式$R' = HR$，$R'' = -\frac{GM_0}{R^2}$。对第一个方程对时间求导，我们发现
$$R' = HR$$
$$R'' = H'R + HR'$$
$$R'' = H'R + H^2R.$$

将下面的表达式代入最后一个方程
$$R'' = -\frac{GM_0}{R^2},$$
我们得到
$$-\frac{4}{3}\pi G\rho R = H'R + H^2R,$$
或$H' + H^2 + \frac{4}{3}\pi G\rho = 0,$
在哪里
$$\rho = \frac{H' + H^2}{-\frac{4}{3}\pi G}.$$

从最后一个表达式可以看出，如果在某个时间点，密度 $\rho$ 和 CONSTANTA $H$ 在所有点上都相同，那么在下一刻 CONSTANTA $H$ 将到处都相同。

最后，我们再次对方程$H' + H^2 + \frac{4}{3}\pi G\rho = 0$微分：
$$H'' + 2HH' + \frac{4}{3}\pi G\rho' = 0.$$
在这里代入$\rho' = -3\rho H$和$\rho = \frac{H' + H^2}{-\frac{4}{3}\pi G}$，我们得到满足$H$的常系数微分方程（非线性）：
$$H'' + 5HH' + 3H^3 = 0.$$

弗里德曼模型中的哈勃 CONSTANTA 满足相同的微分方程（解是相同的！）。

结论

在文章的最后我想发表以下评论。

• 从上面的内容可以看出，进行上述所有计算没有困难——牛顿已经可以做到。但这不会发生，因为从心理学上来说，二十世纪之前的物理学家无法想象世界可以是同质的、各向同性的和非静止的。

• 在牛顿模型中存在相同的整个宇宙模型这一事实表明牛顿万有引力定律是广义相对论的极限。

• 弗里德曼的模型和哈勃的发现打破了心理障碍。什么是非静止宇宙变得很清楚。

• 在所有弗里德曼模型中，$R(t)$ 是三维齐次流形的曲率半径。封闭模型是一个三维球体。相反，您可以想象一个膨胀或塌陷的二维球体或气球。在这种情况下，生活在这个空间中的人会看到镜片移除的速度与距离成正比。只需要补充一点，一个人总是想要想象任何被扔进欧几里得空间的变化。多样性可以在没有任何欲望的情况下存在。很难习惯这一点，但这是可能的。

$$H = \frac{2}{3} t^{-1},$$

• 哈勃常数的微分方程的系数与我们空间的维度有关。
