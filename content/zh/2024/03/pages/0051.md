$R = R_* (1 - \cos \eta)$,
$t = \frac{R_*}{v_\infty} (\eta - \sin \eta)$.

该模型称为封闭模型。

因此，在开放或封闭模型的情况下，我们发现对于可观察对象$A$，可观察对象$B$将按照广义相对论中的弗里德曼模型之一表现。这样，我们就完成了第一个任务。那第二个呢？

第三部分

请注意，我们从未使用过宇宙不同点之间的任何联系。所有的不确定性都在于我们无法确定不同初始点的常数$c$之间的关系。即使我们在不同的时间考虑点$A$，我们也不能说常数$c$是否相同。但是我们对宇宙还有另一个假设，在这种情况下可以称为关于宇宙状态的假设。这是假设宇宙的密度在初始时间点相同。

问题 4. 证明密度的变化由方程给出
$$\rho' = -3\rho \frac{R'}{R} = -3\rho H.$$

从问题 4 可以看出，如果在某个时刻，密度 $\rho$ 和 CONSTANTA $H$ 在所有点上都相同，那么在下一个时刻密度将相同。

现在让我们回到所得到的等式$R' = HR$，$R'' = -\frac{GM_0}{R^2}$。对第一个方程对时间求导，我们发现
$$R' = HR$$
$$R'' = H'R + HR'$$
$$R'' = H'R + H^2R.$$

将下面的表达式代入最后一个方程
$$R'' = -\frac{GM_0}{R^2},$$
我们得到
$$-\frac{4}{3}\pi G\rho R = H'R + H^2R,$$
或$H' + H^2 + \frac{4}{3}\pi G\rho = 0,$
在哪里
$$\rho = \frac{H' + H^2}{-\frac{4}{3}\pi G}.$$

从最后一个表达式可以看出，如果在某个时间点，密度 $\rho$ 和 CONSTANTA $H$ 在所有点上都相同，那么在下一刻 CONSTANTA $H$ 将到处都相同。

最后，我们再次对方程$H' + H^2 + \frac{4}{3}\pi G\rho = 0$微分：
$$H'' + 2HH' + \frac{4}{3}\pi G\rho' = 0.$$
在这里代入$\rho' = -3\rho H$和$\rho = \frac{H' + H^2}{-\frac{4}{3}\pi G}$，我们得到满足$H$的常系数微分方程（非线性）：
$$H'' + 5HH' + 3H^3 = 0.$$

弗里德曼模型中的哈勃 CONSTANTA 满足相同的微分方程（解是相同的！）。

结论

在文章的最后我想发表以下评论。

• 从上面的内容可以看出，进行上述所有计算没有困难——牛顿已经可以做到。但这不会发生，因为从心理学上来说，二十世纪之前的物理学家无法想象世界可以是同质的、各向同性的和非静止的。

• 在牛顿模型中存在相同的整个宇宙模型这一事实表明牛顿万有引力定律是广义相对论的极限。

• 弗里德曼的模型和哈勃的发现打破了心理障碍。什么是非静止宇宙变得很清楚。
