b.另一个非线性电容器将与电阻$R$的电阻串联连接到频率为$n$的矩形脉冲发生器，其端子之间的方向在多晶硅周期期间等于$U_0$，并且在第二个多晶硅周期期间等于$-U_0$。在已建立的模式下，电容器 $q$ 的一个极板的电荷根据极板 $U$ 之间的方向而变化，如图 3 处的图表所示。 磁滞回线的参数，指定为

图上所示的等于 $U_1 = 0,1U_0$、$U_2 = 0,25U_0$、$q_1 = 2CU_1$、$q_2 = q_1 + 0,1CU_0$。 $U_0$和$C$的值已知，还有$nRC \ll 1$。求一段时间内发电机电路消耗的平均功率以及电阻器释放的平均功率。使用参数$C, U_0, n$表达你的答案。

解决方案

一个。首先考虑要点 $\gamma$ 依赖图 $U_y(U_x)$。公平比率为：

$$100u = \frac{q^{(\gamma)}}{C_0}, u = \frac{R_2}{R_1 + R_2}\left(E^{(\gamma)}d + 100u\right),$$

其中 $q^{(\gamma)} - заряд эталонного конденсатора, $E^{(\gamma)} 是给定时刻介电板中的场方向。根据该条件可得出以下不等式：

$$\frac{100R_2}{R_1 + R_2} \ll 1,$$

$u$的姿势比可以写成如下：

$$u = \frac{R_2}{R_1 + R_2}E^{(\gamma)}d.$$

因此，点 $\gamma$ 处的方向 $U_x = 100u$ 与参考电容器的电荷 $q^{(\gamma)}$ 成比例，因此（因为电容器的电荷相等），也与非线性电容器的电荷成比例。 $U_y = u$在$\gamma$点的方向与非线性电容器上的方向成正比。从这里我们得到了唯一的方向性：

$$E^{(\gamma)} = \frac{C_0u}{S\varepsilon_0}.$$

场电荷的表面密度可以从以下关系式中找到

$$\frac{q^{(\gamma)}}{S\varepsilon_0} - \frac{\left|\sigma_{\pi}^{(\gamma)}\right|}{\varepsilon_0} = E^{(\gamma)}.$$

让我们将电荷和场方向的表达式代入这个关系中，经过几次变换，我们得到了唯一的表面密度：

$$\left|\sigma_{\pi}^{(\gamma)}\right| = \frac{100C_0u}{S} - \frac{C_0u}{S} = \frac{99C_0u}{S}.$$

现在考虑点$\beta$。容易看出，在图上该点对应的状态下，非线性电容器和普通电容器上的方向之和等于0。这个事实由方程反映

$$\left(\frac{C_0b}{S\varepsilon_0} - \frac{\left|\sigma_{\pi}^{(\beta)}\right|}{\varepsilon_0}\right)d - b = 0,$$

因为在这种情况下非线性电容器的电荷等于$C_0b$（直到符号）。根据该条件可得出以下不等式：

$$\frac{C_0d}{S\varepsilon_0} \gg 1,$$

因此，忽略方程中的最后一项，我们得到了表面的消除。
