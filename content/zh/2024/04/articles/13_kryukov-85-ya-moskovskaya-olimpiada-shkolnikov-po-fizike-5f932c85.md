从哪里$v = \sqrt{\frac{3}{2} gL(1 - \cos \alpha)}$。

$T_2 = T_{B2}$的值可以从牛顿第二定律获得，写成投影到

$$\text{osc } y: \frac{Mv^2}{3L/4} = T_2 - Mg, \text{откуда}$$

$$T_2 = \frac{4M}{3L} \frac{3}{2} gL (1 - \cos \alpha) + Mg = Mg (3 - 2 \cos \alpha).$$

在这种情况下，张力$T_2$相对于轴线$O$的力矩也将是最大的。因此，附着在杆的$A$点上的螺纹张力也将是最大的，这可以从力矩方程中找到，相对于轴点：$T_{Amax} \frac{L}{4} = mg \frac{L}{4} + T_2 \frac{3L}{4}$。考虑到上述$T_2$的表达式，我们有$T_{Amax} = mg + 3Mg (3 - 2 \cos \alpha)$。因此，所需的关系等于
$$\frac{T_{Amax}}{T_A} = \frac{mg + 3Mg (3 - 2 \cos \alpha)}{mg + 3Mg \sin \alpha} = \frac{1 + 18 (3 - \sqrt{3})}{10} \approx 2.4.$$

3. 从问题的情况可以清楚地看出，气体最初是等压压缩的。在这里它释放出一定的热量。然后气体在接收大量热量的情况下被等容加热。利用热力学第一定律，我们可以计算出气体在等压过程中放出的热量：
$$Q_p = \Delta U_p + A_p = \frac{5}{2} vR (T_{min} - T_H),$$
其中$v$是气体物质的量，$T_H$是气体的初始温度。该热量是负值。现在让我们计算气体在等容过程中接收的热量：
$$Q_V = \Delta U_V = \frac{3}{2} vR (T_K - T_{min}),$$
其中$T_K$是最终气体温度。提供的热量总量等于辅助过程中的外力。
$$A_{ad} = A = \frac{3}{2} vR (T_K - T_H).$$

使用两种气体状态的 Mendeleev-Clapeyron 方程，我们得到
$$p_H V_H = vRT_H, p_H V_K = vRT_{min},$$ 从$\frac{V_H}{V_K} = \frac{T_H}{T_{min}}$ 出发。

结合书面方程并考虑$\frac{V_H}{V_K} = 10$，我们发现
$$Q = A - 9vRT_{min} = 10 \text{ кДж.}$$

2. 管内初始压力$p_0$等于干燥空气分压$p_1$与饱和水蒸气分压$p_{\text{нас}}$之和，即$p_0 = p_1 + p_{\text{нас}}$，由此得出$p_1 = p_0 - p_{\text{нас}}$。用$p_2$表示管部分浸入水中后管内干燥空气的压力，根据波义耳-马里奥特定律我们有$p_1lS = p_2\left(\frac{l}{2} + h\right)S$，其中$S$是管的横截面积。因此$p_2 = p_1\frac{2l}{l+2h}$。根据管中水柱的平衡条件，可得出 $p_2 + p_{\text{нас}} = \rho_0gh + p_0$。循环书面表达式，我们得出方程

$$\left(p_0 - p_{\text{нас}}\right)\frac{2l}{l+2h} + p_{\text{нас}} = \rho_0gh + p_0,$$

解决这个问题，我们得到

$$p_{\text{нас}} = p_0 - \rho_0gh\frac{l+2h}{l-2h} = 14,5 \text{ кПа.}$$

3. 电荷重新分配后，球的电势将相等：$\varphi_1 = \varphi_2$。封闭在壳内的第一个球的电势$\varphi_1$由球本身在其表面产生的势场和壳在球所在位置产生的势场组成：$\varphi_1 = \varphi_{\text{III}} + \varphi_{\text{O6}}$。由于壳是导电的，并且连接到几乎无限的电荷源，因此在其内表面上会感应出电荷，该电荷在模型中等于内部球的电荷，但符号相反。如果第一个球的电荷变成$q_1$，那么炮弹的电荷就变成$-q_1$，因此，

$$\varphi_{\text{III}} = \frac{q_1}{4\pi\varepsilon_0r} \text{ и } \varphi_{\text{O6}} = \frac{-q_1}{4\pi\varepsilon_0R}.$$

第二个球的潜力是$\varphi_2 = \frac{q_2}{4\pi\varepsilon_0r}$。现在我们可以写出等式

$$\frac{q_1}{4\pi\varepsilon_0r} - \frac{q_1}{4\pi\varepsilon_0R} = \frac{q_2}{4\pi\varepsilon_0r}.$$

从这里我们得到

$$R = \frac{q_1}{q_1 - q_2} r = 3 \text{ см.}$$

4. 当散射光落在液体表面时，切向入射的光线将产生最大折射角。结果，在液体中形成光线发散锥体，该锥体受到限制角$\sin \alpha = \frac{1}{n}$的限制。当从底部的镜子反射时，圆锥体的角度不会改变，因此

$$R = 2htg\alpha = \frac{2h\sin \alpha}{\sqrt{1 - \sin^2 \alpha}} = \frac{2h}{\sqrt{n^2 - 1}} \approx 8,94 \text{ см.}$$

5. 当电路中的电流达到其局部最大值时，线圈的自感电动势为零。此时此刻的电流强度为$I = \frac{U}{R}$。弱阻尼量的周期可以认为等于

$$T = 2\pi\sqrt{LC}$$。有效电流值$I_{\text{д}} = \frac{I}{\sqrt{2}}$。那么在很短的时间间隔（周期）内释放的热量可以认为等于
