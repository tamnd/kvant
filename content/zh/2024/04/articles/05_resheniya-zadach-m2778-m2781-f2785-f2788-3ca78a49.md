M2779。证明对于每个自然$k$，都存在一个自然$n$，使得

$$\text{НОК}(1,2,3,\dots,n) = \text{НОК}(1,2,3,\dots,n,n+1,\dots,n+k).$$

如果从前 $n (n \geq 2)$ 自然数 1, 2, ..., $n$ 的序列中，我们只留下素数的幂（包括第一次幂，即素数本身），并划掉剩余的数，那么这些数的 LCM 保持不变，即等于 LCM(1,2,3,...,n)。事实上，如果我们划掉数字$n = p_1^{\alpha_1} p_2^{\alpha_2} \dots p_k^{\alpha_k}$，其中$k \geq 2$（和$p_i$是包含在指数$\alpha_i \geq 1$展开式中的各种素数），那么剩余数字的最小公倍数将被$n$整除，因为数字$p_1^{\alpha_1}, p_2^{\alpha_2}, \dots, p_k^{\alpha_k}$在余数级中。

这意味着等式成立

$$\text{НОК}(1,2,3,\dots,n) = \text{НОК}(1,2,3,\dots,n,n+1,\dots,n+k),$$

数字$n+1, n+2, \dots, n+k$没有素数的幂（包括第一次幂）就足够了（事实上也是必要的）。

这可以通过如下方式实现。取$2k$不同素数$p_1, p_2, \dots, p_{2k}$。根据中国剩余定理，可以选择一个自然数$n$，同时满足以下条件：$n \equiv -1 (\bmod p_1 p_{k+1})$，$n \equiv -2 (\bmod p_2 p_{k+2})$，...，$n \equiv -k (\bmod p_k p_{2k})$。

那么对于每个 $i=1, 2, \dots, k$，$n+i$ 都可以被 $p_i p_{i+k}$整除，因此不是素数的幂。这样就完成了问题的解决。

请注意，相同的推理可用于证明关于 $n$ 存在的更强的陈述，其中没有一个数字 $n+1, n+2, \dots, n+k$ 是素数或精确幂（大于 1）。

总之，我们可以说函数$f(n) = \text{НОK}(1,2,3,\dots,n)$在数论中起着重要的作用。显然$f(n+1)$可以被$f(n)$整除，并且很容易确定$\frac{f(n+1)}{f(n)}$部分只能等于1或素数。函数 $g(n) = \ln f(n)$ 称为切比雪夫函数。已知它具有线性增长，因此$g(n) = n(1 + \alpha(n))$，其中$\lim_{n \to \infty} \alpha(n) = 0$。

让我们证明，当从 A 点移动到 B 点，然后从 B 移动到 C 时，电势是相同的（为了确定这一点，我们假设所有电荷都是正的）。

第一种方式。均匀带电球体中任意点的零场可以表示为两个半球场的叠加（我们用垂直于该点所在直径的大圆平面切割球体）。由此产生的两个半球创建大小相等的方向矢量，其总和在球体任意直径的所有点处都等于零。这意味着半球场的方向性 $E$ 在对称轴上的任意两点上都是相同的，每一个点都位于距半球中心任意距离 $d < R$ 处。因此半球$\varphi_A - \varphi_B = \varphi_B - \varphi_C$。

第二种方式。如果在一个球体上加上一个半球，那么根据叠加原理，球体中心的电势将增加一倍，等于$2\varphi_B$。球体内的场为零，因此 A 点的电势也将等于 $2\varphi_B$。该电势将是此时左半球创建的电势 $\varphi_A$ 与右半球（添加的）创建的电势之和。由于对称性，右半球的贡献等于左半球在 C 点产生的电势，即 $\varphi_C$。因此，我们获得对应关系$2\varphi_B = \varphi_A + \varphi_C$，因此$\varphi_A - \varphi_B = \varphi_B - \varphi_C$。进一步，根据质点动能变化定理，我们有

$$\frac{mv_B^2}{2} = q(\varphi_A - \varphi_B),$$

$$\frac{mv_C^2}{2} = q(\varphi_A - \varphi_B + \varphi_B - \varphi_C).$$

如下：

$$v_C = \sqrt{2}v_B.$$
