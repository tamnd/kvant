7-9年级

1. 让我们写出时间 $t_1$ 和 $t_1 + t_2$ 所覆盖的路径部分的运动学方程：
$$s = v_0 t_1 - \frac{g t_1^2}{2}, 2s = v_0 \left( t_1 + t_2 \right) - \frac{g \left( t_1 + t_2 \right)^2}{2},$$
其中$s$是两个相同部分的长度，$v_0$是石头的初速度。求解这些方程，我们得到
$$v_0 = \frac{2g t_1^2 - g \left( t_1 + t_2 \right)^2}{2 \left( t_1 - t_2 \right)}.$$

那么撞击地面之前的总飞行时间等于
$$t_{\text{пол}} = \frac{2 t_1^2 - \left( t_1 + t_2 \right)^2}{t_1 - t_2} = 7\text{с}.$$

2. 正六边形的面积由公式$S_{\text{ш}} = \frac{3\sqrt{3}}{2} a^2$确定，其中$a$是六边形的边长。直棱柱的体积为$V = \frac{3\sqrt{3}}{2} a^2 h$，其中$h$是棱柱的高度。棱镜底部施加的压力将由比率 $p_1 = \frac{mg}{S_{\text{ш}}} = \frac{2mg}{3\sqrt{3} a^2}$ 决定。从这里我们找到六边形的边：$a = \sqrt{\frac{2mg}{3\sqrt{3} p_1}}$。

棱镜侧面所施加的压力由关系式$p_2 = \frac{mg}{ah}$决定，由此可求出棱镜的高度：$h = \sqrt{\frac{3\sqrt{3}}{2} m g p_1} \frac{1}{p_2}$。现在我们来计算棱镜材料的密度：
$$\rho = \frac{m}{V} = \frac{m}{S_{\text{ш}} h} = \sqrt{\frac{2 p_1}{3\sqrt{3} m g}} \frac{p_2}{g} = 8160 \text{ кг/м}^3.$$

3. 水沸腾冷却到最终温度时放出的热量：$Q_{\text{отд}} = c_B m_B \left( t_B - t_K \right)$。当加热到最终温度时勺子、杯子和茶叶所接收的热量：
$$Q_{\text{пол}} = c_\phi m_\phi \left( t_K - t_\phi \right) + c_c m_c \left( t_K - t_1 \right) + c_B m_3 \left( t_K - t_1 \right).$$
让我们写出热平衡方程$Q_{\text{отд}} = Q_{\text{пол}}$：
$$c_B m_B \left( t_B - t_K \right) = c_\phi m_\phi \left( t_K - t_\phi \right) + c_c m_c \left( t_K - t_1 \right) + c_B m_3 \left( t_K - t_1 \right).$$
从这里开始是
$$m_\phi = \frac{c_B m_B \left( t_B - t_K \right) - c_c m_c \left( t_K - t_1 \right) - c_B m_3 \left( t_K - t_1 \right)}{c_\phi \left( t_K - t_\phi \right)} = 0,2 \text{ кг}.$$
