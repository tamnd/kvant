格鲁佐夫

F2787。 A、B、C 点位于均匀带电半球的对称轴上（参见图）：A 点大于半球的“底部”，B 点位于半球的中心，C 点距 B 点为半球半径。从 A 点开始，我们以零初始速度启动带电粒子。所有电荷的符号都是相同的。在 B 点，粒子以速度 $v_B$ 移动。我们来求 $v_C$ 粒子在 C 点的速度。

让我们证明，当从 A 点移动到 B 点，然后从 B 移动到 C 时，电势是相同的（为了确定这一点，我们假设所有电荷都是正的）。

第一种方式。均匀带电球体中任意点的零场可以表示为两个半球场的叠加（我们用垂直于该点所在直径的大圆平面切割球体）。由此产生的两个半球创建大小相等的方向矢量，其总和在球体任意直径的所有点处都等于零。这意味着半球场的方向性 $E$ 在对称轴上的任意两点上都是相同的，每一个点都位于距半球中心任意距离 $d < R$ 处。因此半球$\varphi_A - \varphi_B = \varphi_B - \varphi_C$。

第二种方式。如果在一个球体上加上一个半球，那么根据叠加原理，球体中心的电势将增加一倍，等于$2\varphi_B$。球体内的场为零，因此 A 点的电势也将等于 $2\varphi_B$。该电势将是此时左半球创建的电势 $\varphi_A$ 与右半球（添加的）创建的电势之和。由于对称性，右半球的贡献等于左半球在 C 点产生的电势，即 $\varphi_C$。因此，我们获得对应关系$2\varphi_B = \varphi_A + \varphi_C$，因此$\varphi_A - \varphi_B = \varphi_B - \varphi_C$。进一步，根据质点动能变化定理，我们有

$$\frac{mv_B^2}{2} = q(\varphi_A - \varphi_B),$$

$$\frac{mv_C^2}{2} = q(\varphi_A - \varphi_B + \varphi_B - \varphi_C).$$

如下：

$$v_C = \sqrt{2}v_B.$$

笔记。建议读者研究通过构造球体和半球体的场的叠加来解决静电问题的示例。这样的问题发表在2000年的«Kvant»第6期期刊上（问题F1762，其作者是G. Grigoryan）。
