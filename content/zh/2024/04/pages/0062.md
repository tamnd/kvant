5. 在初始时刻，$A$和$B$之间的电压为零。因此，流经包括保险丝在内的电路元件的电流明显小于$I_\Pi$。由于保险丝的电阻可以忽略不计，因此没有电流流过与$\Pi_1$并联的电阻$R_1$和$R_2$。 图 21,a 中给出了与原始电路等效的电路。 $AB$部分的总电阻等于$R/3$。在这种情况下，流过保险丝$\Pi_1$的电流$I$将由表达式$I = \frac{U_{AB}}{R/3} = \frac{3U(t)}{R} = \frac{3at}{R}$确定。系统中电流的分布如图21，b所示。电流$I$在$\Pi_1$时刻达到标称值
$t_1 = \frac{I_\Pi R}{3a} = 4$ 分钟

此时，保险丝$\Pi_1$烧断，等效电路如图21,c所示。在这种情况下，$AB$部分的总电阻$R^*_{AB}$将等于$R^*_{AB} = \frac{R}{2} + \frac{R}{3} = \frac{5R}{6}$。流过电阻的电流等于$I^* = \frac{U_{AB}}{R^*_{AB}} = \frac{6a(\tau + t_1)}{5R}$，其中$\tau$是从烧断$\Pi_1$那一刻起缺失的时间。由于电路的对称性，$I_{AD} = I_{AC} = \frac{I^*}{2}$、$I_{DB} = \frac{2I^*}{3}$、$I_{CB} = \frac{I^*}{3}$。那么流过保险丝$\Pi_2$的电流$I_{CD}$将等于$I_{CD} = I_{AC} - I_{CB} = \frac{I^*}{6} = \frac{a(\tau + t_1)}{5R}$。烧毁$\Pi_1$后$\tau$时间后，通过$\Pi_2$的电流变为标称值，等于
$\tau = \frac{5I_\Pi R}{a} - t_1 = \frac{14I_\Pi R}{3a} = 56$ 分钟

$t_2 = \tau + t_1 = 60$ 分钟
