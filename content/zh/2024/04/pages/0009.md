类似地，可以证明，在$n = 5k + p$、$p = 1, 2, 3, 4$的情况下，也存在所考虑类型的刚性填料。这一说法的确切验证再次留给读者作为练习。此外，根据陈述 2，所有这些布置中的孔数将至少为 $\left\lfloor n^2/5 \right\rfloor$。

因此，我们证明了$H_{\max}(n + 2) \geq \left\lfloor n^2/5 \right\rfloor$。现在让我们证明$H_{\max}(n + 2) \leq \left\lfloor n^2/5 \right\rfloor$。给定一块尺寸为$10k \times 10k$、$k \in \mathbb{N}$的木板；因此，其核心尺寸为 $(10k - 2) \times (10k - 2)$。这种尺寸的核心可以铺有$(10k - 1)(2k - 1)$尺寸$2 \times 5$的矩形、$2k - 1$尺寸$5 \times 3$的矩形和一个$3 \times 3$的正方形。例如，尺寸为 $8 \times 8$ 的核心可以按照 图 14 所示进行平铺。记住 图 14。用矩形和正方形平铺核心 $8 \times 8$

由于对此类矩形和刚性铺设的正方形中的孔数量的限制，我们得出板$10k \times 10k$的任何刚性铺设所包含的孔数不超过$2(5k - 1)(2k - 1) + 3(2k - 1) + 2 = \left\lfloor (10k - 2)^2/5 \right\rfloor$。同样，可以证明任意刚性板布局$(10k + p) \times (10k + p)$、$k \in \mathbb{N}$、$p = 1, 2, \dots, 9$中的孔数不超过$\left\lfloor (10k + p - 2)^2/5 \right\rfloor$，并且还可以证明$H_{\max}(7) \leq 5$、$H_{\max}(8) \leq 8$、$H_{\max}(9) \leq 10$。我们将验证留给读者作为练习。

因此，$\left\lfloor n^2/5 \right\rfloor \leq H_{\max}(n + 2) \leq \left\lfloor n^2/5 \right\rfloor$。考虑到陈述 1，我们得到

$$H_{\max}(n + 2) = \begin{cases} \left\lfloor \frac{n^2}{5} \right\rfloor, & n \equiv 0, 2, 3 (\text{mod } 5); \\ \left\lfloor \frac{n^2}{5} \right\rfloor, & n \equiv 1, 4 (\text{mod } 5), \end{cases}$$

结论

我们分析了 DOMino 在板$n \times n$上的最小刚性放置问题。它可以被视为一个有趣的谜题，但也许这里提出的对象和概念最终会在数学范围之外找到应用。自然地，会出现这个问题的概括。您可以使用 DOM 隐藏不同形状和大小的平面形状。您可以一起使用不同形状的方板。最后，你可以尝试转移到另一个维度，考虑“砖块”在“盒子”中的刚性放置。
