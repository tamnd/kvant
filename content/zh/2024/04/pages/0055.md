9. $(1,1,1)$.
我们看到$a = b = c = 1$满足条件。将会进一步证明，没有其他答案。

让我们首先提出$s = (a^2 + 1)(b^2 + 1)(c^2 + 1)$可以被$pqr$整除，其中$p = a + bc, q = b + ca, r = c + ab$（在某种程度上，如果我们另外提出$p, q, r$是不同的，则这可以从条件得出）。

请注意，三个因子 $a^2 + 1, b^2 + 1, c^2 + 1$ 之一不能除以两个数字 $p, q, r$ 的乘积，因为它小于该乘积。事实上，例如，考虑$pq = (a + bc)(b + ca)$。从打开括号我们可以看出

$$pq > c^2(ab) + ab \geq c^2 + 1, pq > b^2c + ab \geq b^2 + 1$$

类似地$pq > a^2 + 1$。这意味着每个因子 $a^2 + 1, b^2 + 1, c^2 + 1$ 必须能被数字 $p, q, r$ 之一整除。为了定义方便，让 $a$ 成为数字 $a, b, c$ 中最小的一个。然后$a^2 \leq bc$和$1 \leq a$，所以只有在$a^2 = bc$和$a = 1$的情况下，即$a = b = c = 1$的情况下，$a^2 + 1$才能除以$p = bc + a$。此外，$a^2 \leq ac$和$1 \leq b$，因此仅在$a^2 = ac$和$b = 1$的情况下，即在$a = b = c = 1$的情况下，$a^2 + 1$才能除以$q = ac + b$。同样，如果存在 $a = b = c = 1$，则 $a^2 + 1$ 只能除以 $r = ab + c$。

现在让三个数字中的两个$p, q, r$重合，比如$p = q$。然后

$$0 = q - p = b + ca - a - bc = (a - b)(c - 1).$$

所以，要么$a = b$，要么$c = 1$。第一种情况发生在$a = b = 1$，否则$p = a + bc = a + ac = a(a + c)$是合数，这就产生了矛盾。因此，在任何情况下，环境$a, b, c$都存在，比如说$c = 1$。
