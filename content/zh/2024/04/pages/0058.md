3. 加热水所需的热量为$Q_1 = cm_1(t_2 - t_1)$。燃烧燃气加热第一台锅炉时释放的热量为$Q_2 = q(m_2 - m_3)$，加热第二台锅炉时释放的热量为$Q_3 = q(m_3 - m_4)$。使用第一个锅炉时加热系统的效率为$\eta_1 = \frac{Q_1}{Q_2}$，使用第二个锅炉时为$\eta_2 = \frac{Q_1}{Q_3}$。

5. 铜的电阻率对温度的线性依赖性，称为加热元件的$R$，可以表示为$R(T) = R_0(1 + \alpha(T - T_0))$，其中$R_0$是加热元件在$T_0$温度下的电阻，$\alpha$是电阻温度系数。让水温在$\tau$时间内从$T_1$变化到$T_2$，则根据能量守恒定律和焦耳楞次定律，对应关系$mc(T_2 - T_1) = \frac{U^2}{R_{\text{cp}}}\tau$成立，其中$c$为水的比热，$m$为水的质量，$U$为电源电压，
$$R_{\text{cp}} = \frac{R(T_1) + R(T_2)}{2} = R_0\left(1 + \frac{\alpha}{2}(T_1 + T_2)\right).$$

这里$T_0 = 0^\circ\text{C}$。设$\tau_1$为$T$到$T + \Delta T$的加热时间，$\tau_2$为$T + \Delta T$到$T + 2\Delta T$的加热时间。然后
$$\tau_1 = \frac{mcR_0\Delta T}{U^2}\left(1 + \frac{\alpha}{2}(2T + \Delta T)\right),$$
$$\tau_2 = \frac{mcR_0\Delta T}{U^2}\left(1 + \frac{\alpha}{2}(2T + 3\Delta T)\right).$$

根据问题的条件我们有
$$\frac{\tau_2}{\tau_1} = \frac{1 + \frac{\alpha}{2}(2T + 3\Delta T)}{1 + \frac{\alpha}{2}(2T + \Delta T)} = 1 + \frac{p}{100}.$$
从这些等式我们发现
$$\Delta T = \left(\frac{1}{\alpha} + T\right)\frac{2p}{200 - p}.$$
