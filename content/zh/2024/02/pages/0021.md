我们将概述此方法的基本版本。请阅读文章 [5]，了解有关二次求解方法的更多信息。

在因式分解方法中，我们推广了费马方法，选择一个数字$x$使得$x^2 (\bmod r)$是一个平方。然而，这样的数字很难得到。前进的关键是观察到，如果我们对不同的 $x$ 取多个 $x^2 (\bmod r)$ 值，其中没有一个是正方形，那么它们的乘积可能已经是正方形了。

例如，我们对数字 1411 进行展开。考虑对 1411 求模的平方：

$$38^2 (\bmod 1411) = 33,$$
$$39^2 (\bmod 1411) = 110,$$
$$40^2 (\bmod 1411) = 189,$$
$$41^2 (\bmod 1411) = 270,$$
$$44^2 (\bmod 1411) = 525,$$
$$49^2 (\bmod 1411) = 990.$$

得到的结果都不是正方形，但乘积$33 \times 189 \times 270$的结果是$980110 = 990^2$。所以，$(33 \times 189 \times 270)^2 = 990^2$，可以得出

$$(33 \times 189 \times 270 - 990) (33 \times 189 \times 270 + 990)$$

- 对 1411 的某个倍数进行因式分解。然后

$$1411 = \text{НОД}(1411, 33 \times 189 \times 270 - 990) \times \text{НОД}(1411, 33 \times 189 \times 270 + 990).$$

锻炼。证明如果$r$整除$x^2 - y^2 = (x - y)(x + y)$，则

$$r = \text{НОД}(r, x - y) \cdot \text{НОД}(r, x + y).$$

如何检查给定的数字中是否有几个乘积得出平方？即使在我们的例子中，完成各种工作也太费力了。我们使用基于因子分解的方法：

$$33 = 3^1 \cdot 11^1,$$
$$110 = 2^1 \cdot 5^1 \cdot 11^1,$$
$$189 = 3^3 \cdot 7^1,$$

$$270 = 2^1 \cdot 3^3 \cdot 5^1,$$
$$525 = 3^1 \cdot 5^2 \cdot 7^1,$$
$$990 = 2^1 \cdot 3^2 \cdot 5^1 \cdot 11^1.$$

请注意，数字相乘时，其展开式中包含的素数的指数会相加。因此，考虑指数向量是很方便的 - 这是一个坐标为输入素数幂的向量。数字相乘相当于指标向量相加。在我们的例子中，向量的形式为

$$\vec{a}_1 = \{0, 1, 0, 0, 1\};$$
$$\vec{a}_2 = \{1, 0, 1, 0, 1\};$$
$$\vec{a}_3 = \{0, 3, 0, 1, 0\};$$
$$\vec{a}_4 = \{1, 3, 1, 0, 0\};$$
$$\vec{a}_5 = \{0, 1, 2, 1, 0\};$$
$$\vec{a}_6 = \{1, 2, 1, 0, 1\}.$$

当且仅当所有幂都是偶数时，数字的乘积才是平方。由于我们只对奇偶校验感兴趣，因此我们将考虑坐标模 2：

$$\vec{a}_1 = \{0, 1, 0, 0, 1\};$$
$$\vec{a}_2 = \{1, 0, 1, 0, 1\};$$
$$\vec{a}_3 = \{0, 1, 0, 1, 0\};$$
$$\vec{a}_4 = \{1, 1, 1, 0, 0\};$$
$$\vec{a}_5 = \{0, 1, 0, 1, 0\};$$
$$\vec{a}_6 = \{1, 0, 1, 0, 1\}.$$

我们的任务是找到这些向量的线性组合，给出向量$\{0, 0, 0, 0, 0\}$，即这样的非零$\alpha_1$，...，$\alpha_6$

$$\alpha_1 \vec{a}_1 + \dots + \alpha_6 \vec{a}_6 = \{0, 0, 0, 0, 0\}.$$
