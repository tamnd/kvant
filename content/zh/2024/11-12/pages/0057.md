5. $3C_{20000}^4 - 2C_{10000}^2$.

设$O$为矩形的中心，线段$l_1$和$l_2$为矩形的中线；为了确定这一点，我们假设中线 $l_1$ 是水平的，$l_2$ 是垂直的。让我们用$A_1$表示相对对称性$l_1$，用$A_2$相对对称$l_2$，用$B$表示相对对称$O$。为了表示集合中元素的数量，我们将使用模数。根据包含和排除公式

$$|A_1 \cup A_2 \cup B| = |A_1| + |A_2| + |B| - |A_1 \cap A_2| - |A_1 \cap B| - |A_2 \cap B| + |A_1 \cap A_2 \cap B|.$$

要获得$A_1$中包含的任何颜色，只需在矩形的上半部分（即$l_1$上方）选择四个任意单元格即可，然后通过这四个选定单元格相对于$l_1$的对称性来获得下半部分的单元格。由于矩形的上半部分只有 20,000 个单元格，因此$|A_1| = C_{20000}^4$。 $A_2$ 或 $B$ 的任何颜色都可以通过从矩形上半部分的 20000 个单元格中选择 4 个单元格来获得（您需要分别相对于 $l_2$ 或 $O$ 反映它们）。因此$|A_2| = |B| = |A_2 \cap B| = |A_1 \cap A_2 \cap B|$。

获得具有所有对称性的任何颜色。所以，$|A_1 \cap A_2 \cap B| = C_{10000}^2$，因此$|A_1 \cap A_2| = C_{10000}^2$，$|A_2 \cap B| = C_{10000}^2$，$|A_1 \cap B| = C_{10000}^2$，因此$|A_1 \cup A_2 \cup B| = 3C_{20000}^4 - 2C_{10000}^2$。

6. $(26;34;35), (26;34;25), (-27;-19;-18), (-27;-19;-28)$.

由于$(a-c)(b-c) = p^2$，其中$p - \text{простое}, a - c < b - c$（由于$a < b$），以下两个选项是可能的：

$$\begin{cases} a - c = 1, \\ b - c = p^2 \end{cases}$$ 或 $$\begin{cases} a - c = -p^2, \\ b - c = -1. \end{cases}$$ (*)

从第二个等式中减去第一个等式，一般情况下我们得到$b - a = p^2 - 1$。考虑将 $p$ 除以 3 的可能性：

- $p = 3k + 1$ - 那么 $p^2 - 1 = 9k^2 + 6k = 3(3k^2 - 2k)$ 可以被 3 整除；
- $p = 3k + 2$ - 那么$p^2 - 1 = 9k^2 + 12k + 3 = 3(3k^2 + 4k + 1)$也能被3整除；
- $p = 3k$ - 然后$p^2 - 1 = 9k^2 - 1$ 并且不能被 3 整除。

由于数字$b - a$不是3的倍数，因此只有第三种情况是可能的。但由于$p$是质数，$p = 3$。所以，$b - a = 8$。在这里加上条件中给出的方程$a^2 + b = 710$，我们得到一个具有两个未知数$a$和$b$的系统。解决它，我们找到$a = 26$，$b = 34$或$a = -27$，$b = -19$。基于系统（*），对于每对$(a;b)$，有两个合适的值$c$。这是$c = a + p^2 = a + 9$或$c = a - 1$。

总共有 4 个三元组$(a;b;c)$，满足条件：$(26;34;35), (26;34;25), (-27;-19;-18), (-27;-19;-28)$。
