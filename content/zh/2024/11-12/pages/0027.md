当连接第一个源时，电流$I_{11}$的方向将变为相反，而电流的大小将保持不变。现在让我们用跳线替换第一个源。让我们分别用$I_{12}$和$I_{22}$（图3）表示流过第一和第二源的电流强度。如果电流强度$I_{12}$不为零，则在改变其极性时维持通过第一源的总电流值是不可能的。这意味着当前强度$I_{1}$为零。这只有在座位平衡的情况下才有可能实现。那么我们就可以得到电阻之间的对应关系：
$$\frac{R_1}{R_2} = \frac{R_3}{R_4}.$$
请注意，此条件也是当第二个源被跳线 $CD$ 替换时平衡第一个源连接位置的条件。这意味着当前$I_{21}$也为零。由此我们可以得出结论，流过第一和第二源的电流强度仅由相应源的 EMF 值及其连接的极性决定。因此，当第一个源极的连接极性改变时流过第二个源极的电流强度$I'_2$等于
$$I'_2 = I_2 = 2 \text{ A}.$$
2) a) 和 b) 情况下的电流 $I_{2a}$ 和 $I_{26}$ 的大小分别由连接到第二个电源端子 $C$ 和 $D$ 的位置的电阻决定：
$$I_{2a} = \frac{\varepsilon_2}{r_a}, I_{26} = \frac{\varepsilon_2}{r_6}.$$
由于站点是平衡的，移除跳线$AB$不会改变节点$C$和$D$之间的站点电阻。那么站点电阻$r_a$和$r_6$将相同并且等于等效源的电阻
$$r_0 = \frac{R_2 R_4}{R_2 + R_4} + \frac{R_1 R_3}{R_1 + R_3},$$
求解第一个点时发现，即$I_{2a} = I_{26}$。由于$I_2 = \varepsilon_2/r_0$，那么
$$I_{2a} = I_{26} = I_2 = 2 \text{ A}.$$
3) 分别流经第一和第二源的电流强度$I_1$和$I_2$由表达式确定
$$\varepsilon_1 = I_1 \left( \frac{R_1 R_2}{R_1 + R_2} + \frac{R_3 R_4}{R_3 + R_4} \right),$$
$$\varepsilon_2 = I_2 \left( \frac{R_2 R_4}{R_2 + R_4} + \frac{R_1 R_3}{R_1 + R_3} \right).$$
让我们引入两个符号：$R_1 = kR_2, R_4 = \alpha R_2$。那么 $R_3 = \alpha kR_2$ 以及当前的强度 $I_1$ 和 $I_2$ 我们有
$$I_1 = \frac{\varepsilon_1}{R_2} \frac{1+k}{k(1+\alpha)}, I_2 = \frac{\varepsilon_2}{R_2} \frac{1+\alpha}{\alpha(1+k)},$$
$$I_1 I_2 = \frac{\varepsilon_1 \varepsilon_2}{R_2^2 \alpha k}, \alpha k = \frac{\varepsilon_1 \varepsilon_2}{I_1 I_2 R_2^2} = 4.$$
请注意，从问题条件可以看出
$$\frac{\varepsilon_1}{I_1} = \frac{\varepsilon_2}{I_2}.$$
从这个对应关系以及$I_1$和$I_2$的表达式我们得到
$$\frac{\alpha(1+k)}{1+\alpha} = \frac{k(1+\alpha)}{1+k}, \alpha(1+k)^2 = k(1+\alpha)^2,$$
$$\alpha + 2\alpha k + k^2\alpha = k + 2\alpha k + \alpha^2k,$$
$$\alpha + 4k = k + 4\alpha, \alpha = k.$$
鉴于$\alpha k = 4$，我们有$k = \alpha = 2$。然后
$$R_1 = R_4 = 2R_2 = 6 \text{ Om}, R_3 = 4R_2 = 12 \text{ Om}.$$
