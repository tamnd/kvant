1. $x = 18, x = 0$.
令 $b_1, b_2, b_3, \dots$ 为给定的几何级数，$q$ 为其分母。然后$b_7 = b_1q^6, b_9 = b_1q^8, b_{15} = b_1q^{14}$，可知$b_9^4 = b_7^3b_{15}, a b_7, b_9$和$b_{15}$是同号数（很容易看出这些条件足以使这些数成为具有相应数的等比级数的成员）。方法，
$$\left(x + 3\right)^4 = \left(\sqrt{25x - 9}\left(x - 6\right)\right)^3 \cdot \sqrt{\frac{25x - 9}{(x - 6)^3}},$$
在 ODZ 中等价于方程
$$\left(x + 3\right)^4 = \left(25x - 9\right)^2.$$
因此$\left(x^2 + 6x + 9\right)^2 = \left(25x - 9\right)^2$，即$x^2 + 6x + 9 = \pm (25x - 9)$，我们得到$x = 1, 18, -31, 0$。值$x = 1$不属于ODZ（根式表达式为负）。值$x = -31$不合适，因为它是$b_7 > 0, b_9 < 0, b_{15} > 0$，这是不可能的。

2. $(-2 - 2\sqrt{2}; 5; 0), \left(\frac{\sqrt{11} - 4}{2}; 5; 0\right)$.
让我们考虑系统的第二个方程。它的左侧仅取决于$y$，右侧仅取决于$z$。我们来比较一下他们的很多。很容易看出函数$f(z) = \sqrt{81 - z^2}$的值集就是线段$[0; 9]$。让$h(y) = |y + 4| + 4|y - 5|$。让我们检查 $h(y)$ 的多音调。为了揭示模型，需要考虑几个差距；每个人都$h(y) - \text{линейная функция}$。它是增加还是杀死，完全取决于$y$的符号。在第一项中，$y$ 处的系数比第二项中的系数更加建模。因此，$y$处的系数符号由第二个模型的展开方式决定。这意味着$h(y)$在$y \ge 5$返回并在$y \leq 5$杀死。由此可见，$y = 5$为最小值点，$h(y)$的最小值为$h(5) = 9$。从$\min h(y) = \max f(z) = 9$开始，由第二个方程可得$f(z) = 9 \Leftrightarrow z = 0$和$h(y) = 9 \Leftrightarrow y = 5$。

将$y$和$z$代入第一个方程，我们得到$\sqrt{x + 5} - \sqrt{1 - x} + 4 = 2\sqrt{5 - 4x - x^2}$。
我们用$t = \sqrt{x + 5} - \sqrt{1 - x}$来表示它。通过两边平方，我们得到$t^2 = x + 5 - 2\sqrt{(x + 5)(1 - x)} + 1 - x,$，由此得到$2\sqrt{5 - 4x - x^2} = 6 - t^2$。方程变为$t + 4 = 6 - t^2$。解决它，我们找到$t = -2$或$t = 1$。
若$t = 1$，则$\sqrt{x + 5} = \sqrt{1 - x} + 1$；平方并带相似的，我们得到$2x + 3 = 2\sqrt{1 - x}$，相当于系统
$$\begin{cases} (2x + 3)^2 = 4(1 - x), \\ 2x + 3 \ge 0, \end{cases}$$
从哪里$x = \frac{\sqrt{11} - 4}{2}$。
对于$t = -2$，我们有$\sqrt{x + 5} + 2 = \sqrt{1 - x}$，从中我们得到$x = -2 - 2\sqrt{2}$。
因此，系统有两种解决方案。
