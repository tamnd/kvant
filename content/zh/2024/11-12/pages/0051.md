2. 让我们用字母 A、B、C 表示白色权重，用字母 a、b、c 表示黑色权重。我们先来比较一下A和a。有三个选项。

I. 两个重量的质量相等。然后他们给出正确的一对。现在让我们权衡 B 和 b。如果相等，则这是第二对，C和c是第三对；否则B和c是第二对，b和C是第三对。

二.其中一个重物重了 2 克。例如，让白色的重量更重。那么A的质量为103克，a的质量为101克。现在将重物 A 和 B 放在一个碗上，将 C 和 b 放在第二个碗上。让我们制作一个表格，列出这些重量的可能质量，并找出碗之间的质量差（如果左边的碗交叉，我们认为它是正数，如果右边的碗交叉，我们认为它是正数）：

| A | B | C | b | 不同之处 |
| :--- | :--- | :--- | :--- | :--- |
| 103 | 101 | 102 | 102 | 0 |
| 103 | 101 | 102 | 103 | -1 |
| 103 | 102 | 101 | 102 | 2 |
| 103 | 102 | 101 | 103 | 1 |

我们看到差异使我们能够明确地恢复权重 B、C、b 的质量，但随后我们确定所有权重并根据参数分配它们。

三．其中一个重物重了 1 克。例如，让白色的重量更重。那么要么 A = 103 和 a = 102，要么 A = 102 和 a = 101。让我们将重物 A 和 a 放在一个碗上，B 和 b 放在第二个碗上，再次看看差异的可能性：

| A | a | B | b | 不同之处 |
| :--- | :--- | :--- | :--- | :--- |
| 103 | 102 | 101 | 101 | 3 |
| 103 | 102 | 101 | 103 | 1 |
| 103 | 102 | 102 | 101 | 2 |
| 103 | 102 | 102 | 103 | 0 |
| 102 | 101 | 101 | 102 | 0 |
| 102 | 101 | 101 | 103 | -1 |
| 102 | 101 | 103 | 102 | -2 |
| 102 | 101 | 103 | 103 | -3 |

两种情况的差异是相同的，但同时 A = b、B = a（这意味着 C = c）——分布参数权重相同。在其他情况下，所有权重再次被唯一确定，并且我们将它们成对添加。

3. $C_{98}^{49} = \frac{98!}{49!49!}$方式。

考虑两个 50x50 的正方形：左上角和右下角。它们只有一个共同的正方形——中央的那个。这两个方格总共有100个偏移方格，总共有99个偏移方格。因此，中心正方形是偏移的，并且这两个正方形之外没有偏移单元。 （图3也有类似的情况，但对于9边和5边的方格来说，总数分别是99和50。）再看右上角和左下角的类似方格，偏移单元格只能在中心列和中心行形成的“十字”中（图4）。
