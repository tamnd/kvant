由此产生的定律描述了从距离孔$r_0$的距离处以无初速度发射的珠子的运动，并且可以随时找到这样的珠子的坐标向量，即具有恒定长度$\frac{\omega_2}{\omega_1 + \omega_2} r_0$的向量$\frac{\omega_2}{\omega_1 + \omega_2} \vec{r}_1(t)$（以角速度$\omega_1$顺时针旋转）和具有恒定长度$\frac{\omega_1}{\omega_1 + \omega_2} r_0$的向量$\frac{\omega_1}{\omega_1 + \omega_2} \vec{r}_2(t)$（以角速度旋转）的总和从相同的初始位置 (图 2) 逆时针方向移动$\omega_2$ 速度。请注意，这些向量之间的角度在时间 $t$ 等于 $\varphi(t) = (\omega_1 + \omega_2) t$。因此，根据硬币定理，此时珠子到孔的距离满足方程
$$r^2(t) = \left( \frac{\omega_2}{\omega_1 + \omega_2} r_0 \right)^2 + \left( \frac{\omega_1}{\omega_1 + \omega_2} r_0 \right)^2 + 2 \frac{\omega_2}{\omega_1 + \omega_2} r_0 \frac{\omega_1}{\omega_1 + \omega_2} r_0 \cos \left( (\omega_1 + \omega_2) t \right).$$
方法，
$$r(t) = \frac{r_0}{\omega_1 + \omega_2} \sqrt{\omega_1^2 + \omega_2^2 + 2\omega_1\omega_2 \cos \left( (\omega_1 + \omega_2) t \right)}.$$
因此，珠子到平衡位置的距离变化的循环频率等于$\omega_1 + \omega_2 = 2\sqrt{\omega_0^2 + \Omega^2}$，取最小值
$$r_{\min} = \frac{\omega_1 - \omega_2}{\omega_1 + \omega_2} r_0 = \frac{\Omega}{\sqrt{\omega_0^2 + \Omega^2}} r_0$$
距离一次
$$t_n = \frac{\pi}{\sqrt{\omega_0^2 + \Omega^2}} \left( n + \frac{1}{2} \right),$$，其中$n = 0, 1, 2, \dots$。

请注意，要找到$r_{\min}$，无需研究距离$r(t)$的变化规律：只要理解当叠加的“分量”向量的向量指向相反方向时，从珠子到孔的距离最小就足够了。那么很明显$r_{\min}$等于他们模型的差。

3) 从$r(t)$的公式可以看出，珠子到孔的最大距离等于初始值：$r_{\max} = r_0$，此时已达到
$$t'_n = \frac{\pi}{\sqrt{\omega_0^2 + \Omega^2}} n,$$，其中$n = 0, 1, 2, \dots$。

正如你所看到的，这是发布后第一次发生这种情况
$$\tau = \frac{\pi}{\sqrt{\omega_0^2 + \Omega^2}}.$$

4) 通过这样的参数对应关系，$\Omega^2 = \omega_0^2/8$，因此，$\omega_1 = \omega_0\sqrt{2}$和$\omega_2 = \omega_0/\sqrt{2}$。这意味着角速度之比为$\omega_1: \omega_2 = 2:1$，即一般运动是周期性的，并且轨迹是闭合的。在这种情况下
$$\vec{r}(t) = \frac{1}{3}\vec{r}_1(t) + \frac{2}{3}\vec{r}_2(t),$$
总和为$\vec{r}(t)$的向量的长度等于$r_0/3$和$2r_0/3$，距离变化规律如下：
$$r(t) = \frac{r_0}{3}\sqrt{5 + 4\cos(3\omega_2 t)}.$$
很明显，运动周期是运动两个分量的周期的最小公倍数，在我们的例子中等于小于频率$\omega_2$的周期。因此，珠子在被释放后第一次发现自己处于时间的起点。
$$T_1 = \frac{2\pi}{\omega_2} = \frac{2\pi\sqrt{2}}{\omega_0} = 2\pi\sqrt{\frac{2m}{k}},$$
以及距洞的距离的变化周期
$$T = \frac{2\pi}{\omega_1 + \omega_2} = \frac{2\pi\sqrt{2}}{3\omega_0} = \frac{1}{3}T_1.$$
