除法本身，具有质量 $m$ 和电荷 $q$ 的粒子在均匀重力场 $\vec{g}$ 和与其垂直的磁场 $\vec{B}$ 中的运动方程
$$m\vec{a} = q[\vec{v} \times \vec{B}] + m\vec{g}$$
过渡到漂移系统后，其中 $\vec{a}' = \vec{a}$、$\vec{v}' = \vec{v} - \vec{v}_{\pi}$ 的形式为
$$m\vec{a}' = q[\vec{v}' \times \vec{B}] + q[\vec{v}_{\pi} \times \vec{B}] + m\vec{g} = q[\vec{v}' \times \vec{B}]$$
换句话说，仅磁场中的运动方程就变为 - 重力场消失，因为漂移速度被精确选择为 $q[\vec{v}_{\pi} \times \vec{B}] + m\vec{g} = 0$。
从实验描述可以看出，粒子的初速度始终指向水平轴；我们将进一步将其视为轴 $x$，沿方向 $\vec{v}_{\pi}$ 行进。这里有两种可能的情况。
a) 速度$\vec{v}_0$与$\vec{v}_{\pi}$匹配。在漂移系统中，在 $v_0 < v_{\pi}$ 处，粒子以速度 $V = v_{\pi} - v_0$ 相对于 $x'$ 轴开始。让我们将轴 $y$ 垂直向上。很明显，当以漂移速度移动时，洛伦兹力是垂直方向的；在这种情况下，它在轨迹的初始部分向下指向（在半径为 $R = \frac{mV}{qB}$ 的圆上）。因此，该系统中的粒子运动定律不存在，并采用以下形式
$$x'(t) = -R \sin \omega t$$
$$y'(t) = H - R + R \cos \omega t$$
（其中$H$是初始高度，频率$\omega = \frac{qB}{m}$），并且在与行星相连的系统中没有
$$x(t) = x'(t) + v_{\pi}t = R\left(\frac{\omega t}{1 - z} - \sin \omega t\right)$$
$$y(t) = y'(t) = H - R(1 - \cos \omega t).$$
这里引入无量纲变量$z = v_0/v_{\pi}$。
请注意，为了分析飞行范围对初始速度值的依赖性，可以方便地将半径 $R$ 写为给定实验和此无量纲变量的常数：
$$R = \frac{m^2g}{q^2B^2} - \frac{mv_0}{qB} = \frac{q}{\omega^2}\left(1 - \frac{v_0}{v_{\pi}}\right) = \frac{g}{\omega^2}(1 - z).$$
另一个方便的无量纲变量是$h = \frac{H}{R} = \frac{\omega^2H}{q(1 - z)}$。正如您所看到的，频率仅在 $h \leq 2$ 时到达行星表面，即在下落 $t_{\pi}$ 的时刻
$$\cos \omega t_{\pi} = \cos \varphi = 1 - h, \sin \varphi = \sqrt{h(2 - h)},$$
可能值的范围是$0 < \varphi \leq \pi$。这意味着撞击点的坐标是
$$x(t_{\pi}) = \frac{g}{\omega^2}\left(\varphi - (1 - z)\sin \varphi\right).$$
这个函数随着$\varphi$的增加而单调增加，并且在区间边缘——$\varphi = \pi$处达到最大飞行范围，即每次需要选择$H = 2R$。所以，在$0 \leq v_0x < v_{\pi}$
$$L_{\max} = \pi \frac{g}{\omega^2}.$$
如果$v_0x > v_{\pi}$，那么在漂移系统中，运动初始阶段的洛伦兹层是向上的，即在旋转过程中，粒子在初始位置上方转动（一般网络中的$v_0x = v_{\pi}$旋转——粒子沿直线移动）。这意味着对于任何 $H > 0$ 粒子不会落在“民意调查”上。
6) 速度$\vec{v}_0$与$\vec{v}_{\pi}$方向相反。
在这种情况下，在漂移系统中，粒子以速度 $V = v_0 + v_{\pi}$ 相对于 $x'$ 轴开始。
上一段中的漂移系统和静止残差系统中的粒子运动定律：
$$x(t) = x'(t) + v_{\pi}t = R\left(\frac{\omega t}{1 + z} - \sin \omega t\right),$$
$$y(t) = y'(t) = H - R(1 - \cos \omega t)$$
和
$$R = \frac{mv_0}{qB} + \frac{m^2g}{q^2B^2} = \frac{g}{\omega^2}\left(1 + \frac{v_0}{v_{\pi}}\right) = \frac{g}{\omega^2}(1 + z).$$
与情况 a) 一样，
$$\cos \omega t_{\pi} = \cos \varphi = 1 - h, \sin \varphi = \sqrt{h(2 - h)}, 0 < \varphi \leq \pi.$$
然而，在情况 6)
$$x(t_{\pi}) = \frac{g}{\omega^2}\left(\varphi - (1 + z)\sin \varphi\right),$$
我们发现，首先，粒子沿 $x$ 轴距发射点的距离在负 $x$ 区域中增加，在 $\cos \varphi = (1 + z)^{-1}$ 处达到最大值，然后减小到零并再次增长 - 已经在正 $x$ 区域中。负$x$区域内粒子的最大偏差为
$$(-x)_{\max} = \frac{g}{\omega^2}\left(\sqrt{z(2 + z)} - \arccos \frac{1}{1 + z}\right).$$
正 $x$ 区域中的最大偏差对应于 $\varphi = \pi$ 并等于
$$x_{\max} = \pi \frac{g}{\omega^2}.$$
为了确保最大飞行范围，您需要选择$H$，它对应于这些值中的较大值。分析 $(-x)_{\max}$ 表达式中的函数行为，我们确定对于较小的 $z$，选择 $H = 2R$ 更有利，而对于$z > z_{\max}$，从高度 $H = \frac{g}{\omega^2}z$ 发射粒子更有利。响应速度的“临界”值$z_{\max}$，即方程的根
$$\sqrt{z(2 + z)} - \arccos \frac{1}{1 + z} = \pi.$$
