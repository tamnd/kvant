LXV国际数学奥林匹克竞赛

1（由 I. Chasovskikh 决定）。所有偶数$\alpha$。
令$2m$为偶数。然后我们注意到数字$\alpha$和$\alpha + 2m$满足（或不满足）联立问题的条件。事实上，$\left\lfloor k(\beta + 2m)\right\rfloor - \left\lfloor k\beta\right\rfloor = 2mk$，因此数字$\alpha + 2m$和$\alpha$的条件之和的差将等于$2m(1 + 2 + \ldots + n) = mn(n + 1)$，它可以被$n$整除（对于任何自然数$n$）。
剩下的就是找到所有满足条件的$\alpha \in [0;2)$。显然$\alpha = 0$是合适的。
让我们证明$\alpha \in (0;1)$不合适。
$n = 2, 3, \ldots$ 的$\left[\frac{1}{n}; \frac{1}{n - 1}\right)$ 形式的接收覆盖区间 (0;1)，因此存在一个自然的 $n \geq 2$ 使得$\frac{1}{n} \leq \alpha < \frac{1}{n - 1}$。然后$(n - 1)\alpha < 1 \leq n\alpha < 2$（从$\frac{n}{n - 1} \leq 2$开始最后一个不等式成立）。方法，
$$\left\lfloor \alpha \right\rfloor = \left\lfloor 2\alpha \right\rfloor = \ldots = \left\lfloor (n - 1)\alpha \right\rfloor = 0, a \left\lfloor n\alpha \right\rfloor = 1.$$
因此，对于数据$\alpha$和$n$，问题陈述中的总和将等于1，它不能被$n$整除。
