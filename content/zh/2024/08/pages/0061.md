证明$\angle YPX = 180^\circ - \angle CVB$，或$\angle YPX = \angle VCB + \angle VBC$。
接下来，从圆$(ABCP)$以及$AB$和$VY$的平行度我们有$\angle PCB = \angle PAB = \angle AVY$。根据所得到的角度 $\angle PCB = \angle AVY$ 相等，可以得出点 $C, P, V, Y$ 位于同一个圆上。因此$\angle YPV = \angle YCV = \angle BCV$。同样，$\angle XPV = \angle CBV$。将所得的两个等式相加，我们就得到了所需的等式 $\angle YPX = \angle VCB + \angle VBC$。

5. N. Panonin 在本期杂志上的文章中给出了这个问题的解决方案。

6（由 I. Chasovskikh 决定）。 $c = 2$。
1) 假设 $f(x) = 0$ 对于某些 $x \neq 0$。代入条件$y = x$得到$f(x + f(x)) = f(x) + x$，或$f(x + 0) = x + 0$，$f(x) = x$，由此得到$0 = x$，即$f(x) \neq 0$在$x \neq 0$。
2) 我们假设$f(0) \neq 0$。将$x = -f(y)$代入条件，我们得到
$$\begin{cases} f(0) = y + f(x), \\ f(y + f(x)) = 0. \end{cases}$$
从这里，代入$y = f(0)$，我们得出
$$\begin{cases} f(x) = 0, \\ f(y + f(x)) = 0. \end{cases}$$
3) 特别是，在第 2) 点中，我们看到 $f$ 恰好取值 0，但考虑到 1)，我们有 $f(0) = 0$。
4) 再次考虑到$f(0) = 0$，我们看一下2）中代入$x = -f(y)$后得到的条件：
$$\begin{cases} f(0) = y + f(x), \\ f(y + f(x)) = 0. \end{cases}$$
我们看到无论如何$y + f(x) = 0$，开$y = -f(x)$。最后一个等式对于所有 $y$ 都成立。
5) 让我们介绍一下函数$h(y) = -f(y)$。在第 4) 点中，我们推导出所有 $y$ 都有 $h(h(y)) = y$，即 $h - \text{инволюция}$。下面我们将使用这个，例如移动$h(a) = b \Leftrightarrow h(b) = a$时。
6) 让我们用 $h$ 重写初始条件，我们得到
$$\begin{cases} -h(x - h(y)) = -h(x) + y, \\ -h(-h(x) + y) = x - h(y). \end{cases}$$
让我们以$h(x) - y = h(x - h(y))$的形式重写第一个等式。
让我们以$h(-h(x) + y) = h(y) - x$的形式重写第二个等式，揭示从$h - \text{инволюция}$开始，它遵循$-h(x) + y = h(h(y) - x)$或$h(x) - y = -h(h(y) - x)$。
我们有
$$\begin{cases} h(x) - y = h(x - h(y)), \\ h(x) - y = -h(h(y) - x). \end{cases}$$
我们用 $h(y)$ 替换 $y$ ，反之亦然，我们得到
$$\begin{cases} h(x) - h(y) = h(x - y), \\ h(x) - h(y) = -h(-(x - y)). \end{cases}$$
7) 让我们修复$a \in \mathbb{Q}$。观察 6) $x = a + y$，我们发现 $f(a + x) - f(x)$ 最多可以取两个不同的值。
8) 假设$c > 2$，然​​后找到两个不同的放射数$r_1$和$r_2$，使得$f(r_1) + f(-r_1)$和$f(r_2) + f(-r_2)$是不同的非零数。那么$h(r_1) + h(-r_1)$和$h(r_2) + h(-r_2)$也是不同的非零数。我们可以假设$r_i$为正（否则我们可以用$-r_i$替换$r_i$）。让我们将 $r_1$ 和 $r_2$ 表示为具有相同值的分数：$r_1 = \frac{q_1}{s}, r_2 = \frac{q_2}{s}$，其中 $q_1, q_2$ 和 $s$ 是自然分数。
9) 考虑（两个方向无穷大）序列$d_i = h\left(\frac{i + 1}{s}\right) - h\left(\frac{i}{s}\right)$。根据7），对于$a = \frac{1}{s}$，值$d_i$最多可以取两个值，我们称它们为$b$和$m$，因此序列...，$d_{-2}, d_{-1}, d_0, d_1, ...$是字符$b$和$m$的序列。
