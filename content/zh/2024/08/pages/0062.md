$$\left(d_{-q_1}, \dots, d_{-2}, d_{-1}\right),$$

注意
$$h(r_2) + h(-r_2) = \left(h\left(\frac{q_2}{s}\right) - h(0)\right) - \left(h(0) - h\left(\frac{-q_2}{s}\right)\right) = \left(d_0 + d_1 + \dots + d_{q_2-1}\right) - \left(d_{-q_2} + \dots + d_{-2} + d_{-1}\right) = (\delta - \gamma)(b - m).$$

这个表达式不等于 0，但是另外，正如我们从 11) 知道的，$|\delta - \gamma| \leq 1$。同样地，
$$h(r_1) + h(-r_1) = (\beta - \alpha)(b - m),$$

其中$0 < |\beta - \alpha| \leq 1$。由于$h(r_2) + h(-r_2) \neq h(r_1) + h(-r_1)$，表达式$\delta - \gamma$、$\beta - \alpha$中恰好有一个等于1，另一个等于-1；对于定义，令$\delta - \gamma = 1$，$\beta - \alpha = -1$。

序列（长度$q_1 + q_2$）（$d_{-q_1}, \dots, d_{-1}, d_0, \dots, d_{q_2-1}$）中的字符数$b$等于相应的$\alpha + \delta$和$\beta + \gamma$。但这些数量之间的差异是 $(\alpha + \delta) - (\beta + \gamma) = (\delta - \gamma) - (\beta - \alpha) = 2$，这与第 11) 点中的 $t = q_1 + q_2$ 相矛盾。
