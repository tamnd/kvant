输入字符串中第二个数字的最小可能值。

答案：$\frac{49S}{50}$。

让$x_1 \ge x_2 \ge \dots \ge x_m > 0 > x_{m+1} \ge x_{m+2} \ge \dots \ge x_n - \text{dанные числа. По условию } x_1 + x_2 + \dots + x_m = S = -(x_{m+1} + x_{m+2} + \dots + x_n)$。
如果$m \ge n/2 = 50$，则$x_m$不超过数字$x_1, x_2, \dots, x_m$的算术平均值，因此$x_m \leq \frac{S}{m} \leq \frac{S}{50}$。然后我们估计总和$S'$，即$S$之后的第二大总和，如下所示：
$$S' \ge x_1 + x_2 + \dots + x_{m-1} = S - x_m \ge S - \frac{S}{50} = \frac{49S}{50}.$$
否则$m \leq n/2$，则$n - m \ge n/2$，因此$x_{m+1}$不小于数字$x_{m+1}, \dots, x_n$的算术平均值，因此$x_{m+1} \ge -\frac{S}{n-m} \ge -\frac{S}{50}$。然后我们像这样评估$S'$：$S' \ge x_1 + x_2 + \dots + x_m + x_{m+1} = S + x_{m+1} \ge S - \frac{S}{50} = \frac{49S}{50}$。
剩下举个例子，知道数据$\frac{S}{50}$就够了，剩下的50就等于$-\frac{S}{50}$。

对于压力相对于下边缘的力矩，我们发现液层的重心下降了 $\frac{a}{3}$ (图 2.6)：

$$2k\Delta x\delta x \geq \frac{\rho a^2\delta x}{2} g \frac{a}{3},$$ 或 $k\Delta x \geq \frac{\rho ga^3}{12}$。

在充满水的水族箱中，水压力$F_\pi = \frac{1}{2}\rho ga^3$作用在侧壁上。为了解决这个问题，必须确定该力的作用点。

由于同一水平面的水平水压相同，显然该点将位于垂直线的中间。垂直方向上，压力从顶部的零到底部的$\rho ga$线性分布。众所周知，三角形的重心位于其中线的交点处。使用我们案例中的垂直压力分布以及大量相同宽度的条带的高度分布，其中平行于底面在心智中切割成等边三角形，我们可以指出，力的施加点位于距容器底部 $a/3$ 的距离处。

可以使用积分对力和力矩进行严格的数学计算。让我们将压力定义为距离液体表面的深度 $y$ 的函数：$p(y) = \rho gy$。总水压力：

$$F_\pi = \int_0^a p(y)ady = \frac{\rho ga^3}{2}$$.

相对于上螺栓的力矩：

$$M_B = \int_0^a yp(y)ady = \frac{\rho ga^4}{3}$$.

相对于下夹具的力矩：

$$M_H = \int_0^a (a-y)p(y)ady = \frac{\rho ga^4}{6}$$.

不存在泄漏的条件可以写成不等式：

$$3k\Delta x \geq \frac{\rho ga^3}{2}$$（以合力方向为条件），

$$k\Delta x \cdot a \geq \frac{\rho ga^4}{3}$$（不围绕顶部边缘旋转），

$$2k\Delta x \cdot a \geq \frac{\rho ga^4}{6}$$（不围绕底边旋转）。
