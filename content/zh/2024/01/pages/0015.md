根据这些数字，计算所选数字的总和，并将所有所得总和按非递增顺序计算到一行中。该行中的第一个数字等于 S。
输入字符串中第二个数字的最小可能值。

答案：$\frac{49S}{50}$。

让$x_1 \ge x_2 \ge \dots \ge x_m > 0 > x_{m+1} \ge x_{m+2} \ge \dots \ge x_n - \text{dанные числа. По условию } x_1 + x_2 + \dots + x_m = S = -(x_{m+1} + x_{m+2} + \dots + x_n)$。
如果$m \ge n/2 = 50$，则$x_m$不超过数字$x_1, x_2, \dots, x_m$的算术平均值，因此$x_m \leq \frac{S}{m} \leq \frac{S}{50}$。然后我们估计总和$S'$，即$S$之后的第二大总和，如下所示：
$$S' \ge x_1 + x_2 + \dots + x_{m-1} = S - x_m \ge S - \frac{S}{50} = \frac{49S}{50}.$$
否则$m \leq n/2$，则$n - m \ge n/2$，因此$x_{m+1}$不小于数字$x_{m+1}, \dots, x_n$的算术平均值，因此$x_{m+1} \ge -\frac{S}{n-m} \ge -\frac{S}{50}$。然后我们像这样评估$S'$：$S' \ge x_1 + x_2 + \dots + x_m + x_{m+1} = S + x_{m+1} \ge S - \frac{S}{50} = \frac{49S}{50}$。
剩下举个例子，知道数据$\frac{S}{50}$就够了，剩下的50就等于$-\frac{S}{50}$。
A·戈洛瓦诺夫

M2763。给出了预期的数字$k \ge 2$。证明具有主题数字和的预期数字除以 $k$ 时给出所有可能的余数。

我们假设$k \ge 2$。让我们证明数字之和为偶数的数字和数字之和为奇数的数字都具有所需的属性。 $S(n)$表示数字$n$的各位数字之和。现在我们可以假设$k$不能被10整除（否则它将在各位数和的奇偶校验中实现所有模$k/10$的余数，然后将最后一位数字以各种方式相加）。
如果假设$k$中的数字是9，那么11$k$中就不再有1了。让我们用$l$表示倒数第二位不是9的数字$k$和11$k$。让$c$是$l$的最后一位数字，$t$是$l$中的位数。
如果$S(l)$是奇数，那么任何余数$a$都可以实现为$a$和$\bar{a}$，这些数具有不同奇偶性的数字之和。
如果$S(l)$是偶数，那么对于给定的余数$a$，我们选择一个$(t+1)$位数字$M$，从数字10-$c$开始，除以$k$时得到余数$a$（有这样的事情！）。那么和$M + 10^t l$将恰好有一个进位，因此数字$M$和$M + 10^t l$具有不同的数字和奇偶性，并且当除以$k$时都给出余数$a$。
这样，我们的命题就得到了证明，解题也得到了证明。
您可以估计给定结构中的数字有多大，并了解在问题的条件下，数字和为偶数且不超过 $200k^2$ 的自然数就足够了。正是在这个成功的表述中，这个问题在 Optimida 向国际数学 Optimis 团队候选人训练营的参与者提出。
P.科兹洛夫、I.博尔多夫
