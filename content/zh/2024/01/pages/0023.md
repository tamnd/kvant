1) 让我们使用守恒定律
冲击时的冲量和能量：

$$m\vec{v}_0 = m\vec{v}_1 + m\vec{v}_2,$$

$$\frac{mv_0^2}{2} = \frac{mv_1^2}{2} + \frac{mv_2^2}{2}.$$

让我们对第一个等式求平方并
我们得到

$$v_0^2 = v_1^2 + v_2^2 + 2\vec{v}_1 \cdot \vec{v}_2.$$

由第二个等式可知

$$\vec{v}_1 \perp \vec{v}_2.$$

由于$v_1^2 + v_2^2 = v_0^2$和$\vec{v}_0 = \vec{v}_1 + \vec{v}_2$，那么
速度三角形是矩形，内切于直径为 $v_0$ (图 2) 的圆。

图 2

我们先引入一个起点坐标系
$yx$，其中轴 $y$ 垂直方向
顶部，$x$ 轴水平方向。
下面，$v_{x(i)}$和$v_{y(i)}$的意思
分别调制水平和
垂直组件 组件
撞击后第$i$号球的速度。
注意$v_{x(1)} = v_{x(2)} = v_x$。

让我们找到下一个$i$球：

$$t_i = \frac{2v_y(i)}{g}, l_i = v_x t_i = \frac{2v_x v_y(i)}{g}.$$

对于撞击点之间的距离
我们有球

$$l = l_1 + l_2 = \frac{2v_x \left(v_y(1) + v_y(2)\right)}{g} = \frac{2v_0 v_x}{g}.$$

因此，最大值$v_x$的入射点之间的距离等于圆的半径，或$v_0/2$。因此，

$$l_{\max} = \frac{v_0^2}{g}.$$

2) 其中一个球的最大值对应于乘积$v_x v_y(i)$的最大值，因此对于普通球来说也是一样的。几何乘积$v_x v_y$是边$v_x$和$v_y$的矩形面积。反过来，这个面积等于等边$v = \sqrt{v_x^2 + v_y^2}$、底$2v_x$（图3）的等边三角形的面积。

图 3

该三角形内接于半径为 $v_0/2$ 的圆。半径为$R$的圆内接的三角形的最大面积在等边三角形的情况下达到，并且等于$\frac{3\sqrt{3}R^2}{4}$，因此，

$$\left(v_x v_y\right)_{\max} = \frac{3\sqrt{3}v_0^2}{16},$$

在哪里

$$l_{i(\max)} = \frac{3\sqrt{3}v_0^2}{8g}.$$
