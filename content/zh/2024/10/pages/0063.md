飞机。让$x$轴沿着斜面向上，坐标原点与水平面和斜面的边界兼容。根据定律$x(t) = v_0 t - \frac{at^2}{2}$和$v(t) = v_0 - at$，坐标$x$和物体速度$v$分别取决于时间。
在时间 $\tau$ – 冰球停止的那一刻 – 可以记录
$$x(\tau) = v_0 \tau - \frac{a \tau^2}{2} = l, \quad v(\tau) = v_0 - a \tau = 0.$$
求解这个方程组，我们找到冰球的初始速度：$v_0 = \frac{2l}{\tau}$和它移动的加速度：$a = \frac{2l}{\tau^2}$。另一方面，利用牛顿第二定律投影到$x$轴上，即方程
$$-ma = -mg \sin \alpha - \mu mg \cos \alpha,$$
我们得到
$$a = g \sin \alpha + \mu g \cos \alpha.$$
将加速度$a$的两个表达式等同起来，我们可以找到摩擦系数：
$$\mu = \frac{1}{\cos \alpha} \left( \frac{2l}{g \tau^2} - \sin \alpha \right)$$
我们最终会得到
$$v_1 = 2 \sqrt{g l \sin \alpha - \frac{l^2}{\tau^2}} = 4 \sqrt{6} \text{ m/c} \approx 10 \text{ m/c}.$$
2. 我们将坐标系的$x$轴沿斜面向下，将坐标原点与平衡位置的棋盘下边缘坐标连接起来。平衡位置的特征是弹簧的初始斜率$x_H$，即$(M + m)g \sin \alpha = kx_H$。根据情况，将装有立方体的板沿斜面向下移动，释放弹簧，并以零速度释放。如果在此之后带有立方体的板子振动，在此期间立方体不沿着板子滑动，那么这些振动将是谐波的，因为板子和立方体将作为一个整体移动。带有立方体投影到 $x$ 轴上的板的运动方程具有以下形式
$$(M + m)x'' = (M + m)g \sin \alpha - k(x_H + x),$$
或$(M + m)x'' + kx = 0.$
由此可见，带有立方体的板会以圆周频率 $\omega_0 = \sqrt{\frac{k}{M + m}}$ 进行简谐振动。当木板和立方体之间振荡时，它按照方程 $mx'' = mg \sin \alpha - F_{\tau p}(t)$ 起作用。该方程中的摩擦力就是恢复力。它取决于时间，并且当板的运动方向改变时改变符号。最大力值

摩擦发生在板的最低位置：
$$|F_{\tau p}^{\max}| = mg \sin \alpha + m |x_{\max}''|.$$
这里$|x_{\max}''|$是带有立方体的板的最大加速度，等于$\omega_0^2 A$，其中$A$是板所需的最大位移（振荡幅度）。
同时，立方体与棋盘之间的摩擦力，如果立方体不沿着棋盘滑动，则不会超过滑动摩擦力的值，即$|F_{\tau p}^{\max}| \leq \mu mg \cos \alpha$。因此，以下不等式必须成立：
$$mg \sin \alpha + m \omega_0^2 A \leq \mu mg \cos \alpha.$$
这个不等式使得可以找到在系统中出现振荡期间立方体不会沿着板滑动的板的最大位移：
$$A = \frac{(m + M)g}{k} (\mu \cos \alpha - \sin \alpha) \approx 0,15M.$$

分子物理学和热力学

1. 根据问题的条件，$V_2 = nV_1$，$V_3 = kV_2 = nkV_1$。使用过程方程1-2，我们得到$p_2 = np_1$，并且由于$pV = vRT$，因此$T_2 = n^2T_1$。类似地，使用过程方程 2-3，我们得到 $T_3 = kT_2 = n^2kT_1$。热机循环的效率为$\eta = \frac{A}{Q^+}$，其中$A$是每个循环气体所做的功，$Q^+$是每个循环气体接收的热量。对于这个周期，使用上面获得的对应关系，我们有
$$A = \frac{1}{2}(p_2 - p_1)(V_3 - V_2) = \frac{1}{2}p_1V_1n(n - 1)(k - 1),$$
$$Q^+ = Q_{12} + Q_{23} = \Delta U_{12} + A_{12} + Q_{23}.$$
这里第1-2节中气体内能的变化等于
$$\Delta U_{12} = C_V(T_2 - T_1) = \frac{3}{2}vRT_1(n^2 - 1),$$
2-3 段中气体接收的科利热等于
$$Q_{23} = C_p(T_3 - T_2) = \frac{5}{2}vRT_1n^2(k - 1).$$
最后我们得到
$$Q^+ = 2vRT_1(n^2 - 1) + \frac{5}{2}vRT_1n^2(k - 1),$$
$\eta = \frac{n(n - 1)(k - 1)}{4(n^2 - 1) + 5n^2(k - 1)} = \frac{1}{13} \approx 0,077.$
