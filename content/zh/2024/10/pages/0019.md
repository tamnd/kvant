M2805。有限集$A$实数
墙数被称为重要的，如果
对于 $A$ 中任意两个不同的数字
你可以从 $A$ 中选择一个素数
罂粟到这三个数字之一
等于论证平均值
另外两个。最多p
有一个显着的集合，共同
由 $n$ 个数字组成？

示例：$A = \{0, 2, 3, 4, 6\}$。易于检查
满足显着性条件。

假设有一个显着集$A$
这样$n = |A| > 5$。无需乞求社会，
我们可以假设 1 和 -1 是最多的
大多数数字从 $A$ （到这种情况
可以通过选择数字直接受
我的新开始报告和单曲
部分;很明显，问题的情况取决于此
不适合）。所以所有的数字
集合$A$位于区间$[-1; 1]$上。

接下来，让 $a_1 < a_2 < \dots < a_k$ 都是数字
从区间$(-1; 0)$集合$A$，类似
从逻辑上讲，让 $b_1 < b_2 < \dots < b_l$ 都是数字
从区间$(0; 1)$开始设置$A$。笔记
以及数字$-1$和$b_i$的条件，我们得到，
数字 $b_i' = \frac{-1 + b_i}{2}$ 位于 $A$，因为
找到另外两个可能的数字
在 $[-1; 1]$ 之外（事实上，$2b_i - (-1) > 1$ 和
$2 \cdot (-1) - b_i < -1$）。同时$b_1' < b_2' < \dots < b_l'$
与区间 $(-1; 0)$ 不同的数字。这意味着每个 $b_i'$ 必须与某些
那么$a_j$，我们不断地得到，
$b_1' \ge a_1, b_2' \ge a_2, \dots, b_l' \ge a_l$，特别是，
我们看到$l \ge k$。同样，使用
数$a_i$和1的条件，我们得到
$a_1' = \frac{a_i + 1}{2} \in A$。同时$a_1' < a_2' < \dots < a_i'$
区间 $(0; 1)$ 中的数字与
不知何故$b_j$。我们一致得到，
$a_1' \ge b_1, a_2' \ge b_2, \dots, a_k' \ge b_k$，特别是，
我们看到$k \ge l$。

比较两个结论，我们得到
必然 $k = l$ 并且所有由此产生的不相等
属性必须转换为等式：$b_i' = a_i$
和 $a_i' = b_i$ 对于所有 $i = 1, 2, \dots, k$。替代
$b_i'$和$a_i'$的表达式，我们得到系统
$a_i$ 和 $b_i$ 的方程：

$$\frac{-1 + b_i}{2} = a_i, \frac{a_i + 1}{2} = b_i.$$

求解这个系统，我们发现$a_i = -\frac{1}{3},$
$b_i = \frac{1}{3}$。这意味着没有间隔数
$(-1; 0)$ 和 $(0; 1)$，不包括点 $\pm \frac{1}{3}$，
不能属于集合$A$。下一个
因此，$A \subset \{-1, 1, 0, -\frac{1}{3}, \frac{1}{3}\}$，这意味着
$|A| \leq 5$，以及解题。

让我们提供另一种可能性来证明
评估部门。再次让$-1, 1 \in A$，在-
$-1$和$1$是$A$的最小和最大数。让我们假设在许多
事实上，$A$是数字$x$，与$\pm 1, 0, \pm \frac{1}{3}$不同。
不求一般性，令 $x > 0$；让我们把
$x = \frac{1}{3} + d$。应用条件$k - 1$和$x$，我们得到

$$y = \frac{-1 + x}{2} = \frac{-1}{3} + \frac{d}{2} \in A,$$

同时$y \in (-1; 0)$。然后，将条件应用于$y$和$1$，我们得到

$$z = \frac{y + 1}{2} = \frac{1}{3} + \frac{d}{4} \in A.$$

我们看到$z$，就像$x$一样，都是谎言
在区间$(0; 1)$且不等于$\frac{1}{3}$。但$z$与$\frac{1}{3}$比$x$更重要。继续这样
进一步，我们从 $A$ 得到无限的数字序列。矛盾。
（矛盾可以立即获得
第一步，如果选择$x \in A \cap (0; 1)$，
其中不等于$\frac{1}{3}$且最接近$\frac{1}{3}$
数字。）
