3. 球受到来自码头的反作用力 $\vec{N}_1$ 和重力 $M\vec{g}$ 的作用。这些力在垂直轴上的投影的总和等于零，因为球将结束：
$$Mg - 2N_1\sin \alpha = 0.$$
每个码头都受到来自球 $\vec{N}_2 = -\vec{N}_1$ 的反作用力、重力 $m\vec{g}$ 和线的张力 $\vec{T}$ 的作用。重力作用点位于码头中部，反力作用点距码头与地面接触点$R\mathrm{ctg}\alpha$距离。作用在 doku 上相对于与地板接触点的力的力矩总和为零，即
$$T\cos \alpha \cdot l - N_1R\mathrm{ctg}\alpha - mg\sin \alpha \cdot \frac{l}{2} = 0.$$
最后我们得到
$$T = \frac{mg\mathrm{tg}\alpha}{2} + \frac{MgR}{2l\sin^2\alpha}.$$
4. 在初始位置，库仑相互作用力等于$F = k\frac{q^2}{L^2}$，其中$k$是比例系数，$q$是每个珠子的电荷，并且珠子的相互作用势能等于$U_1 = k\frac{q^2}{L} = FL$。为了使珠子碰撞，相互作用力必须大于摩擦力。如果珠子之间的距离减小到某个值 $l$ 使得$F_{\mathrm{tp}} = k\frac{q^2}{l^2}$，就会发生这种情况。那么该位置的珠子的潜在相互作用能为$U_2 = k\frac{q^2}{l} = F_{\mathrm{tp}}l$。让我们写出珠子这两个位置的能量守恒定律，考虑到传递给每个珠子的动能 $T$ 以及在这些位置之间移动时摩擦力所做的功：
$$U_1 + 2T = U_2 + F_{\mathrm{tp}}(L - l),$$
我们可以从哪里找到它？
$$T = \frac{(F_{\mathrm{tp}} - F)L}{2}.$$
5. 框架的其余部分受到线的张力和重力的影响。后者可以表示为整个框架的重力的矢量和，等于$Mg$（这里$M$是整个框架的质量），向下并施加到框架的中心，以及切割件的重力等于$1/4Mg$，向上并施加到侧面的中间。设框架的边长为$a$。相对于悬挂点，线的拉力强度为零，线的拉力强度分别等于$\frac{a}{2}\sin \alpha$和$\frac{a}{2}(\cos \alpha + \sin \alpha)$。
对于姿势，相对于悬挂点的力矩相等将写成以下形式
$$Mg\frac{a}{2}\sin \alpha = \frac{1}{4}Mg\frac{a}{2}(\cos \alpha + \sin \alpha).$$
因此$ctg\alpha = 3$，$\alpha = \arctg 3$。

1. 让我们表示 $t_1 = 40$ h，$t_2 = 60$ h。地球参考系中完整的赤道天体对应的角度为$2\pi$弧度，飞行器的角速度为$\omega_1 = \frac{2\pi}{t_1}$、$\omega_2 = \frac{2\pi}{t_2}$。当沿相反方向移动时，相对角速度等于这些速度的总和。波兹尼飞机将在一段时间后相遇
$$t = \frac{2\pi}{\omega_1 + \omega_2} = \frac{t_1t_2}{t_1 + t_2} = 24$$小时。
2. 根据道尔顿定律，活塞下方的压力等于气体$p$和饱和水蒸气$p_\pi$的分压之和。在初始时刻$p_0 = p + p_\pi$。活塞抬起后，由于温度恒定，饱和水蒸气的压力没有变化，水因蒸发而被抽出以维持压力。与此同时，活塞下方的压力减半。 Pozny $\frac{p_0}{2} = p_1 + p_\pi$，其中 $p_1$ 是最终气体压力。从这里我们会发现
$$p_\pi = p - 2p_1.$$
在恒定温度下，气体压力与其所占体积的乘积保持恒定。在横截面恒定的垂直管道的情况下，所占的体积与活塞的高度成正比，因此
$$pH = p_1H_1.$$
从这里表达 $p_1$ 并代入前面的方程，我们得到
$$p_\pi = \left(1 - \frac{H}{H_1}\right)p.$$

4. 通过跳线和母线形成的电路的磁通量Ф随时间变化导致感应电动势$\varepsilon = -\frac{\Delta\Phi}{\Delta t} = -L_1L_2\frac{\Delta B}{\Delta t} = -L_1L_2\frac{B_0}{\tau}$和电流$I = \frac{|\varepsilon|}{R}$的出现。在磁场中，根据安培定律，电流流过的跳线会受到等于 $F = ILB$ 的安培力的作用，并沿着母线向下引导。当这个力达到所需值时，上跳线开始沿着轮胎向下移动。从这里我们得到
$$F = \frac{L_1^2L_2B_0^2}{R\tau^2}t.$$
