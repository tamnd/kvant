1. B-2 型，100 m。
在无风天气下，第一款和第二款机型的飞行距离相差$x = v_1t_1 - v_2t_2 = l - ut$。这里$v_1$和$v_2$是这些模型在无风天气下的速度，$t_1$和$t_2$分别是第一个和第二个模型在空中停留的时间（以秒为单位），$u$是风速。 A-1 型在空中的停留时间比 B-2 型少$t$ 秒，A-1 型飞得更远$l$ 米。
对于$u = 4$、$t = 150$和$l = 500$，我们得到$x = 500 - 600 = -100 < 0$。这意味着B-2模型将飞行更远100米。

3. 4051.
因为，一方面，$f(x + 6) \leq f(x + 3) + 6 \leq f(x) + 12$，另一方面，$f(x + 6) \geq f(x + 4) + 4 \geq f(x + 2) + 8 \geq f(x) + 12$，然后$f(x + 6) = f(x) + 12$，而且，所有不等式都变成了等式。因此$f(x + 3) = f(x) + 6$、$f(x + 2) = f(x) + 4$和$f(x + 1) = f(x) + 2$。还有$f(0) = 3$、$f(1) + 5$、$f(2) = 7$。
因此，$x$的整数值所需的函数是函数$f(x) = 3 + 2x$。所以，$f(2024) = 3 + 2024 \cdot 2 = 4051$。

4. $x = \pm \arccos \frac{\pi}{6} + \pi n, n \in \mathbb{Z}$；根之和为$4\pi - \arccos \frac{\pi}{6}$。
将乘积转换为总和后，我们得到
$$\cos 2x + \cos(2\cos x) = \frac{\pi^2}{18} - \frac{1}{2}.$$
令$t = \cos x$，则等式左边等于$f(t) = 2t^2 - 1 + \cos 2t$。
函数$f$返回[0;1]（因为$f'(t) = 2(2t - \sin 2t) > 0$对于$t > 0$）并且是偶数，并且$f\left(\frac{\pi}{6}\right) = \frac{\pi^2}{18} - \frac{1}{2}$。因此，方程 $f(t) = \frac{\pi^2}{18} - \frac{1}{2}$ 的根在区间 [-1; 1] 是数字$t = \pm \frac{\pi}{6}$。返回变量$x$，我们找到$x = \pm \arccos \frac{\pi}{6} + \pi n, n \in \mathbb{Z}$。
由于$\frac{\pi}{4} = \arccos \frac{\sqrt{2}}{2} < \arccos \frac{\pi}{6} < \arccos \frac{1}{2} = \frac{\pi}{3}$，则所指示的线段包含三个根，其总和等于$4\pi - \arccos \frac{\pi}{6}$。
