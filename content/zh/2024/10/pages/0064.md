α是非参与者常数系数。根据门捷列夫-克拉佩龙方程，$pV = vRT$，因此在此过程中$p \sim V$。气体所做的功可以通过计算$p$与$V$图下的面积来求得。梯形的面积是
$$\frac{1}{2}(p_1 + p_2)(V_2 - V_1) = \frac{1}{2}(p_1V_2 - p_1V_1 + p_2V_2 - p_2V_1).$$
既然$p \sim V$，那么$p_1V_2 = p_2V_1$并且
$$A = \frac{1}{2}(p_2V_2 - p_1V_1) = \frac{1}{2}vR\Delta T.$$
内能的变化为$\Delta U = \frac{3}{2}vR\Delta T$。根据热力学第一定律$Q = \Delta U + A$。在这个过程中
$$Q = \Delta U + \frac{\Delta U}{3} = \frac{4}{3}\Delta U,$$
在哪里
$$\Delta U = \frac{3}{4}Q = 15\text{Дж.}$$

1. 让我们写出三个带电粒子系统的总能量守恒定律，其中粒子的初始位置和相邻粒子之间的距离减半后：
$$3\frac{q^2}{4\pi\varepsilon_0l} + 3\frac{mv_0^2}{2} = 3\frac{q^2}{4\pi\varepsilon_0(l/2)} + 3\frac{m(v_0/2)^2}{2}.$$
同样，对于粒子的初始位置和最终位置，考虑到在最短距离处粒子速度将变成场，我们写
$$3\frac{q^2}{4\pi\varepsilon_0l} + 3\frac{mv_0^2}{2} = 3\frac{q^2}{4\pi\varepsilon_0r_{\min}}.$$
从这里我们得到
$$r_{\min} = \frac{3}{7}l = 12\text{ см.}$$

2. 将未充电的串联电容器连接到源极 (图 23,a) 后，电容器的电荷变得相同并等于 $q_0 = \frac{C_1C_2}{C_1 + C_2}U$，其中$U = \exists\Delta C$ 为源极。切换电容器 (图 23,b) 后，电容器的电荷变得等于 $q_1$ 和 $q_2$，对此以下等式有效：
$$-q_1 + q_2 = 2q_0 \text{ и } \frac{q_1}{C_1} + \frac{q_2}{C_2} = U.$$
从这里开始是
$$q_2 = \frac{C_1C_2(C_1 + 3C_2)}{(C_1 + C_2)^2}U \approx 19\text{ мкКл.}$$
