2. 令 $V$ 为容器的体积，$v_0$ 为容器中物质的初始量，$\Delta v$ 为从大气进入容器的物质量。让我们写出注入前后容器中气体的状态方程：

$$p_0V = v_0RT_0, \quad p_1V = (v_0 + \Delta v)RT_1.$$

令泵内气压等于$p_B$，$dV_B$为泵内colibe物质$dV$中部分空气所占据的体积。当将指定部分的空气泵入容器时，泵会执行机械功 $\delta A_H = p_BdV_B$。但根据门捷列夫-克拉佩龙方程$p_BdV_B = RT_0dV$，因此$\delta A_H = RT_0dV$。因此，泵的总机械功为

$$A_H = \Delta vRT_0.$$

让我们写下一个系统的热力学第一定律，该系统由最初位于容器中并由泵泵入其中的气体组成：

$$A_H + U_0 + U_1 = U_K.$$

这里$U_0 = v_0C_VT_0$是最初位于容器中的空气的初始内能，$U_1 = \Delta vC_VT_0$是泵入容器阶段的泵送空气的内能之和，$U_K = (v_0 + \Delta v)C_VT_1$是所考虑的系统的最终内能。定体积空气的摩尔热为$C_V = 5R/2$。从这里

$$\Delta vRT_0 + \frac{5v_0RT_0}{2} + \frac{5\Delta vRT_0}{2} = \frac{5(v_0 + \Delta v)RT_1}{2}.$$

因此，

$$\frac{T_1}{T_0} = \frac{5v_0 + 7\Delta v}{5(v_0 + \Delta v)} = \frac{p_1}{p_0}\frac{v_0}{(v_0 + \Delta v)}, \frac{\Delta v}{v_0} = \frac{5}{7}\left(\frac{p_1}{p_0} - 1\right).$$

对于玉米片加工完成后和开始前容器中空气物质含量的比率，我们有

$$\frac{v_K}{v_0} = 1 + \frac{\Delta v}{v_0},$$ 从$\frac{v_K}{v_0} = \frac{2}{7} + \frac{5p_1}{7p_0}$ 出发。

对于相对温度$T_1/T_0$，我们有

$$\frac{T_1}{T_0} = \frac{p_1}{p_0}\frac{v_0}{v_K},$$ 然后$T_1 = \frac{T_0}{2p_0/7 + \frac{5}{7}}.$

3. 令 $\vec{T}$ 为作用在螺纹附着点上的力，其大小等于螺纹在给定点处的张力。那么，由于系统处于平衡状态，

$$\vec{T} + m\vec{g} + \lambda L\vec{E} = 0.$$

我们引入坐标系$xy$，其中$x$轴水平向右，$y$轴垂直向上。那么从平衡条件

$$E_y = \frac{mg}{\lambda L}, E_x = \frac{T}{\lambda L}.$$

让我们连接负载附着点处的线张力$T_0 = mg$和线附着点处的$T$。让我们考虑长度为 $dl$ 的线的无穷小元素。其平衡条件可写为：

$$\left(\vec{T} + d\vec{T}\right) - \vec{T} + \vec{E}\lambda dl = 0.$$

Proceria 在螺纹切线方向上，我们得到

$$dT + \lambda E_\parallel dl = 0.$$

让螺纹的切线与垂直线形成角度 $\varphi$。然后

$$E_\parallel = E\cos \varphi - E\sin \varphi,$$

在哪里

$$dT + E_y\lambda dl\cos \varphi - E_x\lambda dl\sin \varphi = 0.$$

但是$dl\cos \varphi = dy$和$dl\sin \varphi = -dx$，所以

$$dT + E_y\lambda dy + E_x\lambda dx = 0.$$

总结一下，我们得到

$$T - T_0 = T - mg = -E_y\lambda(y - y_0) - E_x\lambda(x - x_0).$$

从$y - y_0 = H$和$x - x_0 = -s$开始，我们有

$$T - mg = \lambda\left(E_xs - E_yH\right).$$

从$T = \lambda LE_x$之后就没有了

$$\lambda LE_x - mg = \lambda\left(sE_x - HE_y\right) = \lambda sE_x - \lambda H\frac{mg}{\lambda L},$$

$$E_x = \frac{mg}{\lambda L}\frac{L - H}{L - s}.$$

对于电厂场的方向性我们得到

$$E = \sqrt{E_x^2 + E_y^2} = \frac{mg}{\lambda L}\sqrt{1 + \left(\frac{L - H}{L - s}\right)^2}.$$
