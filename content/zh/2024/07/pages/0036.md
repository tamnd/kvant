火肉汁也是Poncelet定理，根据该定理，如果从某个三角形出发，内圆$\Omega$和内圆$\omega$都保留，则存在一族顶点在$\Omega$上的三角形，其内圆与$\omega$（图3）重合。是的，这样的问题有无限多个解，但所有这些三角形只有相同的点$O$和$I$。我们有一个点 $H$，或者说，一个半周长（并且可以证明，在 Poncelet 三角形集合中，只有一个具有给定点 $H$ 和给定的半周长，除非 $O$ 和 $I$ 重合）。看来剩下的就是在$\Omega$处构建原始三角形的一个顶点了，工作就完成了。但建设并没有成功。正如我们现在所知，它不可能成功！

那么，让我们展示如何从三角形 $HIO$ 开始，用圆周和尺子构造圆 $\Omega$ 和 $\omega$。我们有这些圆的中心。剩下的就是构建它们的半径。为此，我们将使用表达三角形 $HIO$ 到 $R$、$r$ 和 $p$ 边长的公式（参见 [8]）。我们来获取系统

$$\begin{cases} OH^2 = 9R^2 + 8Rr + 2r^2 - 2p^2, \\ IH^2 = 4R^2 + 4Rr + 3r^2 - p^2, \\ OI^2 = R^2 - 2Rr, \end{cases}$$

在哪里

$$R^2 = \frac{OI^4}{2\left(OI^2 + IH^2\right) - OH^2},$$

$$r = \frac{R^2 - OI^2}{2R},$$

$F(x) = (x - a)(x - b)(x - c) = 0,$

其中$a$是从三角形顶点$A$到切点绘制的切线段的长度，$b$和$c$的定义类似（图4）。在[8]中表明，三角方程的形式为

$$F(x) = x^3 - px^2 + \left(r^2 + 4Rr\right)x - r^2p = 0.$$

练习 1. 确保这一点。

系统中$OH, IH, OI$的公式表明，相反，给定$R$、$r$和$p$，可以重建三角形$HIO$的边。

事实证明，从点 $H, I, O$ 和从给定点 $R, r$ 和 $p$ 重建三角形的问题本质上是等价的。如果有一个从点$H, I, O$重建三角形的算法，那么我们可以很容易地获得从给定的$R, r$和$p$构造三角形的算法：首先，使用$R, r$和$p$构造三角形$HIO$，然后使用现有的重建算法。

接下来，我们将给出一个根据给定的$R, r$和$p$无法用圆规和尺子重建三角形的具体例子。这将完成我们的证明。让我们输入 $R = 18$、$r = 8$、$p = 45$。

练习 2. a) 证明对于 $R > 2r$ 存在具有给定 $R$ 和 $r$ 的三角形。

6) 证明存在一个具有 $R = 18$、$r = 8$、$p = 45$ 的三角形。

我们使用“三角方程”（参见[8]）

$$F(x) = (x - a)(x - b)(x - c) = 0,$$

其中$a$是从三角形顶点$A$到切点绘制的切线段的长度，$b$和$c$的定义类似（图4）。在[8]中表明，三角方程的形式为

$$F(x) = x^3 - px^2 + \left(r^2 + 4Rr\right)x - r^2p = 0.$$

练习 3. 证明对于 $R = 18$、$r = 8$、$p = 45$，三角方程没有有理根。
