$$2CQ = CQ + CP = (b - AQ) + (a - PB) = b + a - (AR + BR) = a + b - c,$$

$$2RM = (AM - AR) + (BR - BM) = BR - AR = (BP + PC) - (AQ + QC) = a - b.$$

根据割线的性质

$$a + b - c = 2\sqrt{CQ^2} = 2\sqrt{CK \cdot CL} = 2\sqrt{2\sqrt{3} \cdot (2\sqrt{3} + 4\sqrt{3})} = 12,$$

$$a - b = 2\sqrt{RM^2} = 2\sqrt{ML \cdot MK} = 2\sqrt{2\sqrt{3} \cdot (2\sqrt{3} + 4\sqrt{3})} = 12,$$

从哪里$a = 12 + b, c = 2b$。考虑相对于 $M$ 点对称 $C$，我们得到一个边长为 $a$ 和 $b$ 以及对角线长度为 $c$ 和 $2CM = 16\sqrt{3}$ 的平行四边形。使用平行四边形的类比，我们得到$2(a^2 + b^2) = c^2 + (16\sqrt{3})^2$，考虑到之前的对应关系，给出

$$2\left((b + 12)^2 + b^2\right) = (2b)^2 + 768, 48b = 480, b = 10.$$
