$$Ae^{x+y} + B - \left(Ae^x + B\right)^2 = e^x \left(Ae^x + B + Ae^y + B\right).$$

让我们以多项式的形式重写 $e^x$ 中的最后一个等式：

$$A(A + 1)e^{2x} + 2B(A + 1)e^x + B(B - 1) = 0.$$

等式必须对所有$x$成立。当且仅当 $e^{2x}, e^x$ 的系数和自由项等于 0 时，才会发生这种情况。最后一个属性可以通过三种方式实现：

1) $A = 0, B = 0$; 2) $A = -1, B = 0$; 3) $A = -1, B = 1$.

相应地，我们得到问题的三个解：$f(x) = 0, f(x) = -e^x, f(x) = -e^x + 1$。

9. 4.

ODZ 方程 – 段 [0;4]。正值$\sqrt{x} + \sqrt{4-x}$具有平方$4 + 2\sqrt{x(4-x)} \ge 4$。因此$\sqrt{x} + \sqrt{4-x} \ge 2$。

函数$(5-x)(6-x)$严格在区间[0;4]上杀死，并在点$x = 4$处取值2。方程的解只能是$x = 4$。直接检查表明 $x = 4$ 是方程的解。

10. $(-\infty; 0) \cup \left\{\frac{1}{4}\right\}$.

让我们对方程进行平方：

$$\begin{cases} y^2 = x - a, \\ x^2 = y - a. \end{cases}$$

现在让我们用一个方程减去另一个方程：

$$y^2 - x^2 = x - y,$$ 从$(y - x)(x + y + 1) = 0$ 出发。

由于直接从原系统的方程 $x \ge 0, y \ge 0$ 得出，那么第二组非零，结果是 $x = y$ 并且系统被释放为一个方程

$$x^2 = x - a, x^2 - x + a = 0.$$

我们需要找到这个方程有唯一非负解的$a$的值。二次方程$x^2 - x + a = 0$的判别式是$D = 1 - 4a$。如果$D = 0$，则$a = \frac{1}{4}$和$x = \frac{1}{2}$是方程的唯一解，并且该解是非负的。如果$a > \frac{1}{4}$，则$D < 0$，无解。如果$0 \leq a < \frac{1}{4}$，则方程有两个非负解。如果$a < 0$，则方程有两个不同符号的根。假设方程有一个非负根如果$a \in (-\infty; 0) \cup \left\{\frac{1}{4}\right\}$。
