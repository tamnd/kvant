3. 当左边第二个垂直部分充满水后，水将开始流入第三个弯头，填充第三个和第四个之间的下面的跳线，并将第三个弯头中的空气与大气“隔断”。形成空气“塞子”，其中的压力 $p$ 将随着第四个弯头的填充而增加。让我们写下管的第一和第二垂直部分 (图 23) 的平衡条件（压力相等）：
$$p_0 + \rho g H = p + \rho g l,$$
对于第三个和第四个：
$$p_0 + \rho g l = p + \rho g (l - x).$$
从这里我们得到
$$H - l = x.$$
由于管内的空气开始从对应于一个垂直截面的体积中撇走，那么，根据波义耳-马里奥特定律
$$p_0 l S = px S.$$
从最后两个等式我们发现
$$p = \frac{p_0 l}{H - l}.$$
我们将其代入管前两部分的平衡条件并得到
$$p_0 + \rho g H = \frac{p_0 l}{H - l} + \rho g l,$$
或者
$$\rho g (H - l)^2 + p_0 (H - l) - p_0 l = 0.$$
为了方便起见，我们将 $p_0 / g = l_0$ 表示为，求解二次方程，只留下具有物理意义的正根：
$$H = l + \frac{1}{2} \left( \sqrt{l_0^2 + 4l_0 l} - l_0 \right).$$

浇水量可由充满水的管道总长度确定：
$$V = S (H + 3l - x) = 4Sl.$$

1. 令$v_0$为码头$a$和$b$在与码头$c$碰撞之前的速度，$m$为每个码头的质量。由于码头$a$和$b$之间没有摩擦力，而码头$b$和$c$在碰撞时被紧固，则碰撞后码头$a$的速度等于$v_0$，码头$b$和$c$的速度为$v_0 / 2$（来自动量守恒定律）。让我们在速度$v_0$方向引入轴$x$。由于水平面是光滑的，系统的质心以恒定速度$v_{\text{цм}} = 2v_0 / 3$移动。在撞击瞬间，系统的质心比码头中心$a$超前了$L / 3$，而当码头$a$完全位于码头$c$上时，系统的质心落后于码头中心同样的$L / 3$。然后移动码头$a$我们得到
$$\Delta x = \Delta x_{\text{цм}} + \frac{2L}{3} = \frac{2(v_0 \tau + L)}{3},$$
其中$\tau$是码头$a$相对于码头$b$和$c$的移动时间。接下来，我们将码头$b$和$c$组合成一个质量体$2m$，并用索引2来表征它。我们将用索引1来表征木板$a$。让$\vec{F}$是作用在第一个物体和第二个物体上的摩擦力，$x$是它们在撞击后的相对位移。请注意，摩擦仅发生在码头 $a$ 和 $c$ 重叠的区域。滑动摩擦力的大小与支撑表面粗糙部分的法向反作用力成正比，因此$F_x = -\mu mgx / L$。让我们为每个物体写出牛顿第二定律：
$$m\vec{a}_1 = \vec{F}, \ 2m\vec{a}_2 = -\vec{F},$$
在哪里
$$\vec{a}_1 - \vec{a}_2 = \vec{a}_{\text{отн}} = \frac{\vec{F}}{m} + \frac{\vec{F}}{2m} = \frac{3\vec{F}}{2m}.$$
然后我们得到变量$x$的运动方程：
$$x'' = -\frac{3\mu gx}{2L}.$$
这是循环频率$\omega = \sqrt{3\mu g / (2L)}$的简谐振动方程。其通解的形式为
$$x(t) = A \sin (\omega t + \varphi_0).$$
让我们根据初始条件确定$A$和$\varphi_0$：
$$x(0) = A \sin \varphi_0 = 0, \quad \varphi_0 = 0,$$
$$x'(0) = \frac{v_0}{2} = \omega A \cos \varphi_0, \quad \text{или} \quad A = \frac{v_0}{2\omega}.$$
