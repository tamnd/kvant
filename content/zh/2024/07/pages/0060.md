1. 令自由压力的加速度等于$g$，并以与垂直方向$\alpha$的角度以$v_0(\alpha)$的速度发射子弹。然后
$$a_n = \omega v_0(\alpha) = g_n = g \sin \alpha, \quad v_0(\alpha) = \frac{g \sin \alpha}{\omega}.$$
让我们引入坐标轴$y'$，垂直于幻灯片表面。抛射加速度在该轴上的投影等于$g_{y'} = -g \cos \varphi$。那么对于弹丸的飞行时间我们有
$$t = -\frac{2v_{0y'}}{g_{y'}} = \frac{2v_{0y'}}{g \cos \varphi}.$$
弹丸的最大可能飞行时间对应于最大值$v_{0y'}$。我们引入一个坐标系$xy$，原点位于枪的位置，轴$x$指向右侧，轴$y$垂直向上。然后
$$v_0 = \frac{g \sin \alpha}{\omega} = \frac{g}{\omega} \frac{v_{0x}}{v_0}, \quad v^2 = v_{0x}^2 + v_{0y}^2 = \frac{g v_{0x}}{omega},$$
在哪里
$$\left(v_{0x} - \frac{g}{2\omega}\right)^2 + v_{0y}^2 = \left(\frac{g}{2\omega}\right)^2.$$
因此，速度矢量$\vec{v}_0$的端点轨迹是圆（图22）。从几何图可以看出，最大飞行时间对应于最大值$v_{0y'}$，当速度矢量的末端位于从圆心到滑动表面方向的垂线上时，可以实现该最大值。我们得到
$$v_{0y'(\max)} = \frac{g(1 - \sin \varphi)}{2\omega},$$ 从 $t_{\max} = \frac{1 - \sin \varphi}{\omega \cos \varphi} \approx 1,15$ s 开始。

2. 让我们确定滚筒与垫圈 1 碰撞后的速度。由于垫圈和滚筒之间没有空间，因此所有垫圈都被集中移除，所有物体的运动保持平移，并且物体速度在垂直于中心线的轴上的投影在碰撞期间保持恒定。让我们沿着中心线引入一个轴 $y$，从垫圈 1 指向滚筒的中心。令 $\alpha$ 为圆盘 1 的速度矢量与中心线之间的角度。让我们写出在 $y$ 轴上投影的动量守恒定律和能量守恒定律：
$$mv_0 \cos \alpha = Mv_{M1} + mv_{1y},$$
$$\frac{mv_0^2 \cos^2 \alpha}{2} + \frac{mv_0^2 \sin^2 \alpha}{2} =$$
$$= \frac{mv_{1y}^2}{2} + \frac{mv_0^2 \sin^2 \alpha}{2} + \frac{Mv_{M1}^2}{2},$$
我们从哪里找到它？
$$v_{M1} = v_0 \cos \alpha + v_{1y} = 2v_0 \cos \alpha - \frac{Mv_{M1}}{m} = \frac{2mv_0 \cos \alpha}{m + M}.$$
让我们获得垫圈 2 和滚筒之间存在间隙的条件。如果引入从垫圈 2 指向滚筒中心的轴 $z$，则碰撞条件将是滚筒相对于垫圈 2 的速度在轴 $z$ 上的投影将为负，即
$$v_{z(\text{отн})} = -v_{M1} \cos 2\alpha - v_0 \cos \alpha =$$
$$= -v_0 \cos \alpha \cdot \left(1 + \frac{2m \cos 2\alpha}{m + M}\right) < 0.$$
由于 cos $\alpha > 0$，这个条件可以写成如下：
$$1 + \frac{2m \cos 2\alpha}{m + M} = 1 + \frac{2m(2 \cos^2 \alpha - 1)}{m + M} > 0,$$
$$\cos \alpha = \frac{s}{2R} > \sqrt{\frac{1}{4}(1 - \frac{M}{m})} = \frac{1}{2\sqrt{2}},$$ 或 $s > \frac{R}{\sqrt{2}}.$
$s_1 = R/2$ 时不满足此条件，因此滚筒和垫圈 2 之间不会发生碰撞，即$v_{M1} = u_1$，或
$$u_1 = \frac{mv_0}{m + M} \frac{s_1}{R} = \frac{v_0}{3}, v_0 = 3u_1.$$
在$s_2 = R$时，滚筒和洗衣机之间的碰撞次数为2，而在$\alpha_2 = 60^\circ$时。在以速度$\vec{v}_{M1}$移动的缺席系统中，到该距离的属性内容较早。在该缺席系统中，垫圈 2 的速度在轴 $z$ 上的投影
$$v_{2z} = v_0 \cos \alpha + v_{M1} \cos 2\alpha = \frac{v_0}{2} + \frac{2v_0}{3} \left(-\frac{1}{2}\right) = \frac{v_0}{6}.$$
撞击后滚筒立即速度
$$v_{M2} = \frac{2mv_{2y'}}{m + M} = \frac{2v_0}{9}.$$
