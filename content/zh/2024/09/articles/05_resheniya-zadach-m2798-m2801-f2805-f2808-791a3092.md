M2799。给定一个自然数n。 Ilya 提出了几个不同的 n 次多项式（具有实数系数）。 Sasha 可能设想了几个不同的 n 次多项式。 Lenya 知道 n；他的目标是找出 Ila 和 Sasha 是否有相同的多项式对。 Lenya 选择一组 k 个实数 $x_1 < x_2 < \dots < x_k$ 并报告这些数字。作为回应，Ilya 填写了一个 2×k 表：对于每个 i = 1, 2, ..., k，他在第 i 列的两个单元格中写入一对数字 $P(x_i)$、$Q(x_i)$（以两个可能的顺序中的任何一个），其中 P 和 Q 是他设想的多项式。 Sashi 也同样填写了该表。 Lenya（看表）在 k 最小的时候可以肯定添加目标？

答案：2n+1。

让我们证明，对于 k = 2n（对于 k < 2n 更是如此），Lenya 将无法唯一确定 P、Q 对。让他将集合称为 $x_1 < x_2 < \dots < x_{2n}$。让我们把

$$A = (x - x_1)(x - x_2) \dots (x - x_n),$$
$$B = (x - x_{n+1})(x - x_{n+2}) \dots (x - x_{2n}),$$

所以 $A(x_i) = 0$ 对于 i = 1, 2, ..., n 和 $B(x_i) = 0$ 对于 i = n + 1, n + 2, ..., 2n。那么，如果 Ilya 想要 $P_1 = A + 2B$ 和 $Q_1 = -A - 2B$，那么在表的第 i 列中，将有数字 $\pm 2B(x_i)$（表示 i = 1, 2, ..., n）和数字 $\pm A(x_i)$（表示 i = n + 1, n + 2, ..., 2n）。但同一张桌子适合$P_2 = A - 2B$和$Q_2 = -A + 2B$对；萨西应该能猜到。

另一方面，我们将证明，对于 k = 2n + 1，Ilya 表最多可以满足一对多项式 P、Q。假设相反，也有两对：$P_1$、$Q_1$ 和 $P_2$、$Q_2$。那么 $P_2$ 与 $P_1$ 或 $Q_1$ 一致，至少对于参数的 n + 1 个不同值，例如与 $P_1$ 一致。因此，$P_1$和$P_2$是相同的多项式（因为它们的差异是最多n次的多项式，具有至少n + 1个不同的根）。从本例的表中我们发现$Q_1$和$Q_2$的值在2n+1个点处重合，然后是$Q_1 = Q_2$。
