如何找到错误
邦达罗夫

如您所知，没有人能免受错误的影响。即使是那些深入了解物理、甚至数量的人也是科学家。

1905年，阿尔伯特·爱因斯坦在他的博士论文中提出了一种确定分子半径和阿伏加德罗常数的新理论方法。论文获得批准，爱因斯坦成为一名医生。正如我们后来发现的那样，爱因斯坦本人和他的对手都没有注意到计算中的一个严重错误。仅仅几年后，正如爱因斯坦的一位传记作者 [1] 所写的那样，这个“基本但并非微不足道”的错误才被发现，因为实验结果与从论文中导出的方程获得的值存在偏差。

本文不会谈论物理史上的案例，而是谈论小学生在统一国家考试、优化和其他测试中解决物理问题时所犯的错误。在这种情况下，我们假设学生能够成功理解分配给他的问题的物理定律，写出解决方案所需的所有方程，但在达到最终结果的过程中在数学转换或计算中犯了错误。现在他的主要问题是识别和消除错误假设。我们将只关注字母答案的分析。对于每一个问题，都会提供几种可能的答案，其中肯定会有一个正确的答案。

因此，我们的目标是能够识别所有不正确的答案，而无需以非总统方式解决问题，仅依靠对条件中描述的流程模式的深入理解。以下是实现这一目标的主要帮助者的“名称”：维度、对称性、特殊情况。

让我们从一个七年级学生的知识就足够解决的问题开始。

任务 1. Gonchik.edem 位于高速公路上，并由沿高速公路波动的气象标志引导。当我们通过下一个区块的mismo时，赛车手会连续跳跃到速度$v_1, v_2, v_3, v_4$。平均速度$v_{\text{cp}}$metequivla 是多少？

解决该问题的方法是众所周知的。设柱之间的距离为$l$。那么平均速度$v_{\text{cp}}$定义为整个路径$4l$与其通过时间$t$的比率，其中$t = l/v_1 + l/v_2 + l/v_3 + l/v_4$。换句话说，剩下的就是将$4l$除以$(l/v_1 + l/v_2 + l/v_3 + l/v_4)$，再减少$l$，目标就达成了：

$$v_{\text{cp}} = \frac{4}{\frac{1}{v_1} + \frac{1}{v_2} + \frac{1}{v_3} + \frac{1}{v_4}}.$$

如果想要继续变换以减少分数的“故事”，则可能会出现数学错误。以下是一些可能的答案，您需要从中选择唯一正确的一个：

A、$v_{cp} = \frac{4v_1v_2v_3v_4}{v_1 + v_2 + v_3 + v_4}$；

五、$v_{cp} = \frac{4v_1v_2v_3v_4}{v_1v_2v_3 + v_1v_2v_4 + v_1v_3v_4}$；

C. $v_{cp} = \frac{4v_1v_2v_3v_4}{v_1v_2v_3 + v_1v_2v_4 + v_1v_3v_4 + v_2v_3v_4}$;

D. $v_{cp} = \frac{v_1v_2v_3v_4}{v_1v_2v_3 + v_1v_2v_4 + v_1v_3v_4 + v_2v_3v_4}$.

通常，答案 A 和 B 通常首先被丢弃。显然，答案 A 未通过尺寸测试。事实上，这个公式的左边是速度（m/s）的量纲，右边是速度（m/s）立方的量纲。答案 B 的惊人之处在于它的不对称性。请注意，在该分数的分母中，数量 $v_1$ 出现了 3 次，而数量 $v_2$、$v_3$ 和 $v_4$ 仅出现了 2 次。但在问题的条件下，所有速度都是相等的，因此它们都不应该在答案中脱颖而出。让我们概括一下这个观察结果：如果任务条件存在某种对称性，那么答案中必然会出现某种对称性。 1 在情况 B 中，没有观察到这一点，并且这个答案不可能是正确的。

因此，我们只剩下最后两个答案，每个答案都成功通过了维度和对称性测试。现在让我们考虑这样一种特殊情况，此时答案是非常一致的。让所有路段的驾驶员具有相同的速度$v_1 = v_2 = v_3 = v_4 = v$，在这种情况下显然等于平均速度。让我们注意答案 C 和 D 中对相同且相等 v 的所有速度。因此，答案 C 的正确表达式是 $v_{cp} = v$，答案 D 的反直觉表达式是 $v_{cp} = v/4$。

这样，所有错误答案都已被丢弃，我们找到了正确答案C。经过仔细的数学变换，我们将确保答案C是由公式（*）得出的。

细心的读者无疑会注意到，在可能的答案中，最常见的错误答案不是：

E. $v_{cp} = \frac{v_1 + v_2 + v_3 + v_4}{4}$.

这并非偶然，因为我们将只考虑那些不是偶然（随机）获得的答案，而是深入理解问题中描述的物理过程的结果，尽管存在数学错误。显然，解中所写的方程很难得出答案E。

然而，让我们尝试检查分析并确保答案 E 不可能是正确的。同样，一个特殊情况将帮助我们：让它在锅的前三个部分保持不变：$v_1 = v_2 = v_3 = v$，而在最后一个部分它非常小：$v_4 \rightarrow 0$。摩托车手整个行程的平均速度应该是多少？很明显，由于$v_4$速度低，运动时间$t$变得非常大（在极限中趋于无穷大：$t \rightarrow \infty$）。这意味着从平均速度（$v_{cp} = s/t$）的定义来看，它应该像$v_4$一样非常小。请注意，在$v_4 \rightarrow 0$正确答案C的情况下，平均速度也非常小。但在这种情况下，答案 E 给出了令人难以置信的结果：$v_{cp} = 3v/4$。 （很明显，对于分析，可以假设任何其他部分的速度较低。）

让我们考虑计算平均速度的另一个问题，其中路径的各个部分具有不同的长度。

A. $v_{cp} = \frac{2v_1v_2}{v_1 + v_2}$;

B. $v_{cp} = \frac{v_1 + 2v_2}{3}$;

C. $v_{cp} = \frac{2v_1 + v_2}{3v_1v_2}$;

D. $v_{\text{cp}} = \frac{3v_1v_2}{2v_1 + v_2}$;
E. $v_{\text{cp}} = \frac{3v_1v_2}{v_1 + 2v_2}$.

我们分析这个问题的答案与上一个问题类似。从检查维度开始，很容易注意到，在情况C中，在解决问题时，在最终的表达式中，显然他们忘记了将分数翻转过来。波兹尼这个答案不可能是正确的。唯一对称的答案 A 是不合适的，因为对称性不存在于条件中，因此不应出现在答案中。答案B被丢弃的原因与上一题中答案E相同：在速度非常低的情况下，例如在第一部分中，平均速度也应该非常小。然而，当将$v_1 \rightarrow 0$代入公式时，我们得到的是$v_{\text{cp}} = 2v_2/3$，而不是$v_{\text{cp}} \rightarrow 0$。

仍然需要在两个位置（答案 D 和 E）之间做出选择，这两个位置成功地通过了允许前三个答案错误出现的所有测试。可惜的是，速度相等的特殊情况在过去的问题中帮助了我们，但也不会帮助我们。事实上，对于 $v_1 = v_2 = v$，两个公式都给出了正确的结果：$v_{\text{cp}} = v$。好吧，让我们尝试另一个特殊情况：第二部分的速度非常高（在极限情况下$v_2 \rightarrow \infty$）。那么公式D的分母可以通过与非常大的值$v_2$相比较小的值$2v_1$忽略不计，从而得出答案

$$v_{\text{cp}} = \frac{3v_1v_2}{2v_1 + v_2} \approx \frac{3v_1v_2}{v_2} = 3v_1.$$

让我们确保答案 D 在我们的特定情况下应该是正确的。三分之一的路线是自动化的，移动缓慢，然后接下来的三分之二几乎是瞬间冲过去，几乎不花时间。换句话说，在这种情况下，自动车辆以$v_1$的速度惊叹于第一路段，走完路径$l$的前三分之一的时间，自动车辆将能够走完整个路径$3l$。为此，非常印度，它的速度$v_{\text{cp}}$必须比前三分之一的速度$v_1$大。

自己对公式 E 进行类似的推理，并证明这会导致错误结果$3v_1/2$。

现在让我们通过解决问题来根据对答案的分析来检查我们的结论。令路径权重等于$3l$，并且始终等于$t$。那么平均速度

$$v_{\text{cp}} = \frac{3l}{t} = \frac{3l}{\frac{l}{v_1} + \frac{2l}{v_2}} = \frac{3v_1v_2}{2v_1 + v_2}.$$

这是正确的。

因此，我们确信，检测答案（以及中间公式）中可能存在的错误的工作说明是三种主要的验证方法：维度、对称性和特殊情况。当然，最重要的还是第一个：维度。在它的帮助下，大多数类型的错误都可以被检测到。

而在这里，大概有以下含义。食物百合 至少有一名学生开始失去身高和体温。同时，在解决问题时，经常会出现维数错误。而且，在某些情况下，检测它们不需要很高的条件。以下是几乎所有检查学生作业的人都遇到过的类似表达方式：

1) $s + v/t$; 2) $m - M^2$;
3) $I + R/U$; 4) $(F - m)a$.

显然，如果您想准确地解决问题，尺寸检查应该是您不变的伴侣。

请注意，通过上述所有检查并不能保证答案的正确性。这些检查只允许您丢弃新的响应。但是，根据这个，它也非常有用。

问题 8. 向水平面上质量为 $m$ 的粉笔施加一个力 $\vec{F}$，与地平线 (图 4) 成$\alpha$ 角向上。主体与表面之间的索赔系数$\mu$。求物体的加速度$a$。

解决这个问题，看起来并不困难。让我们将牛顿第二定律的方程写成水平轴和垂直轴的投影：

$$F \cos \alpha - F_{\text{tp}} = ma,$$
$$N + F \sin \alpha - mg = 0.$$

我们在滑动$F_{\text{tp}} = \mu N$时了解到这一点。然后是身体所需的加速度

$$a = \frac{F \cos \alpha - \mu (mg - F \sin \alpha)}{m}.$$

答案已收到，但是......这是不正确的。让我们尝试通过重新阅读条件并分析我们的解决方案来找到错误。它们之间有没有不一致的地方？很明显，在较小的力值$F$时，身体尚未开始移动，保持静止状态。为了确定摩擦力的大小，我们使用公式 $F_{\text{tp}} = \mu N$，假设物体正在滑动。这就是为什么当将 $F = 0$ 代入我们的答案时，我们得到了尴尬的 $a = -\mu g$。

但这还不是全部！当力值$F$很大时会发生什么？请注意，随着$F$的增长，正常支撑反作用力$N$减小，在$F = mg/\sin \alpha$时变为零，即身体脱离支撑。两种力同时消失：$\vec{N}$和$\vec{F}_{\text{tp}}$，身体在剩下的两种力：$\vec{F}$和$\vec{m}\vec{g}$的影响下移动。加速度可以通过将牛顿第二定律方程写成矢量形式来求出：$\vec{F} + \vec{m}\vec{g} = m\vec{a}$。从 图 5 使用余弦定理 $(ma)^2 = F^2 + (mg)^2 - 2Fmg \sin \alpha$ 可以很容易地找到物体加速度模型：

$$a = \frac{\sqrt{F^2 + (mg)^2 - 2Fmg \sin \alpha}}{m}.$$

在分析答案的时候，有时会不由自主地遇到一个矛盾的情况。只有深刻理解物理定律的适用性本质才能在一定程度上帮助摆脱困境。让我们以以下问题为例来看看这个问题。

问题 9. 质量为 $m_1 = 2$ kg 的球，以 $v = 3$ m/s 的速度移动，与质量为 $m_2 = 3$ kg 的静止球碰撞。我们在两个球之间产生中心撞击，从而使进攻的球停止。撞击时释放了多少扫帚$Q$？

一般来说，解决这个问题不会造成严重的困难。事实上，很明显，动量守恒定律的标准应用
$$m_1v = m_2u$$
和能量守恒定律
$$Q = \frac{m_1v^2}{2} - \frac{m_2u^2}{2},$$
我们很快就得出答案
$$Q = \frac{m_1v^2}{2}\left(1 - \frac{m_1}{m_2}\right) = \frac{(m_2 - m_1)m_1v^2}{2m_2} = 3 \text{ Дж.}$$

如果你养成了分析收到的答案的习惯，你一定会注意括号里的“减号”。事实证明，如果球的质量相等，则撞击时不应释放热量。此外，如果我们假设入射球比静止球重，我们会得到更外部的结果。确实，对于$m_1 > m_2$$Q < 0$。事实证明，在这种情况下，在撞击时，热量不仅没有释放，而且可以说被“泵入”球系统中。我们得到的答案和物理意义之间存在矛盾。

让我们尝试找出原因。为此，我们找不到比守恒定律更好的帮助。如果入射球的动量等于$p$，则碰撞后第二个球具有相同的动量。系统的初始能量位于第一个球处，等于$E_1 = p^2/(2m_1)$。碰撞后，传递给第二个球的能量：$E_2 = p^2/(2m_2)$。通过这种形式的表示法，可以立即清楚地看出，如果球的质量相等，则它们的动能也相等，这意味着物体不会在系统中释放。这就是相同质量的球在绝对弹性冲击中应该发生的情况。同样明显的是，如果一个较重的球在这种条件下击中，那么它就不能停留（否则这将导致违反能量守恒定律）。因此，导致我们在分析答案时感到困惑的特殊情况（$m_1 > m_2$）是根本不可能的，因为它与问题的条件相矛盾，即来球在撞击后立即离开。
