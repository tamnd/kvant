块在斜面上。很容易证明，在$\mu < tg\alpha$处，块沿着平面向下滑动，在$\mu > tg\alpha$处，它相对于平面保持静止，在$\mu = tg\alpha$处，它要么躺在平面上（在$v_0 = 0$处），要么均匀滑动（在$v_0 \neq 0$处）。为了进一步分析答案，我们将移动楔子变成静止斜面：$a = 0$。从答案 D 可以得出$\mu = tg\alpha$。而答案 B 则产生荒谬的 $\mu = -tg\alpha$。我们邀请读者自己找出 $\mu < tg\alpha$ 加速度的正确表达式 D 中减号出现的物理本质是什么。

现在让我们简单地解决这个问题。由于根据条件，木块相对于楔块作匀速运动，因此楔块和木块相对于地面的加速度相同。让我们将 $x$ 轴水平放置，将 $y$ 轴垂直放置。然后，根据牛顿第二定律，块在这些轴上的投影

$$ma = F_{\text{tp}} \cos \alpha - N \sin \alpha,$$
$$0 = F_{\text{tp}} \sin \alpha + N \cos \alpha - mg.$$

考虑到滑动$F_{\text{tp}} = \mu N$时，我们得到

$$ma = N (\mu \cos \alpha - \sin \alpha),$$
$$mg = N (\mu \sin \alpha + \cos \alpha).$$

将第一个方程除以第二个方程，我们有

$$\frac{a}{g} = \frac{\mu \cos \alpha - \sin \alpha}{\mu \sin \alpha + \cos \alpha},$$

在哪里

$$a = \frac{g (\mu - tg\alpha)}{\mu tg\alpha + 1} \approx 0,17 \text{ m/c}^2.$$

当答案经过多个阶段的验证并且看起来非常合理，但其中一个特殊情况与答案相矛盾的情况并不常见。如果我们没有注意可接受值的范围，这可能会起作用。例如，乍一看，这是一项有些挑战性的任务。

问题 8. 向水平面上质量为 $m$ 的粉笔施加一个力 $\vec{F}$，与地平线 (图 4) 成$\alpha$ 角向上。主体与表面之间的索赔系数$\mu$。求物体的加速度$a$。

解决这个问题，看起来并不困难。让我们将牛顿第二定律的方程写成水平轴和垂直轴的投影：

$$F \cos \alpha - F_{\text{tp}} = ma,$$
$$N + F \sin \alpha - mg = 0.$$

我们在滑动$F_{\text{tp}} = \mu N$时了解到这一点。然后是身体所需的加速度

$$a = \frac{F \cos \alpha - \mu (mg - F \sin \alpha)}{m}.$$

答案已收到，但是......这是不正确的。让我们尝试通过重新阅读条件并分析我们的解决方案来找到错误。它们之间有没有不一致的地方？很明显，在较小的力值$F$时，身体尚未开始移动，保持静止状态。为了确定摩擦力的大小，我们使用公式 $F_{\text{tp}} = \mu N$，假设物体正在滑动。这就是为什么当将 $F = 0$ 代入我们的答案时，我们得到了尴尬的 $a = -\mu g$。

但这还不是全部！当力值$F$很大时会发生什么？请注意，随着$F$的增长，正常支撑反作用力$N$减小，在$F = mg/\sin \alpha$时变为零，即身体脱离支撑。两种力同时消失：$\vec{N}$和$\vec{F}_{\text{tp}}$，身体在剩下的两种力：$\vec{F}$和$\vec{m}\vec{g}$的影响下移动。加速度可以通过将牛顿第二定律方程写成矢量形式来求出：$\vec{F} + \vec{m}\vec{g} = m\vec{a}$。从 图 5 使用余弦定理 $(ma)^2 = F^2 + (mg)^2 - 2Fmg \sin \alpha$ 可以很容易地找到物体加速度模型：

$$a = \frac{\sqrt{F^2 + (mg)^2 - 2Fmg \sin \alpha}}{m}.$$

如果需要，可以使用正弦定理找到物体加速度指向地平线的角度。
