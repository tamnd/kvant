现在我们终于可以写出正确答案了：
$$a = 0 \text{ при } 0 \leq F \leq \frac{mg}{\cos \alpha + \mu \sin \alpha},$$
$$a = \frac{F \cos \alpha - \mu (mg - F \sin \alpha)}{m}$$
在 $$\frac{mg}{\cos \alpha + \mu \sin \alpha} < F \leq \frac{mg}{\sin \alpha},$$
$$a = \frac{\sqrt{F^2 + (mg)^2 - 2Fmg \sin \alpha}}{m} \text{ при } F \geq \frac{mg}{\sin \alpha}.$$
在分析答案的时候，有时会不由自主地遇到一个矛盾的情况。只有深刻理解物理定律的适用性本质才能在一定程度上帮助摆脱困境。让我们以以下问题为例来看看这个问题。

问题 9. 质量为 $m_1 = 2$ kg 的球，以 $v = 3$ m/s 的速度移动，与质量为 $m_2 = 3$ kg 的静止球碰撞。我们在两个球之间产生中心撞击，从而使进攻的球停止。撞击时释放了多少扫帚$Q$？

一般来说，解决这个问题不会造成严重的困难。事实上，很明显，动量守恒定律的标准应用
$$m_1v = m_2u$$
和能量守恒定律
$$Q = \frac{m_1v^2}{2} - \frac{m_2u^2}{2},$$
我们很快就得出答案
$$Q = \frac{m_1v^2}{2}\left(1 - \frac{m_1}{m_2}\right) = \frac{(m_2 - m_1)m_1v^2}{2m_2} = 3 \text{ Дж.}$$

如果你养成了分析收到的答案的习惯，你一定会注意括号里的“减号”。事实证明，如果球的质量相等，则撞击时不应释放热量。此外，如果我们假设入射球比静止球重，我们会得到更外部的结果。确实，对于$m_1 > m_2$$Q < 0$。事实证明，在这种情况下，在撞击时，热量不仅没有释放，而且可以说被“泵入”球系统中。我们得到的答案和物理意义之间存在矛盾。

让我们尝试找出原因。为此，我们找不到比守恒定律更好的帮助。如果入射球的动量等于$p$，则碰撞后第二个球具有相同的动量。系统的初始能量位于第一个球处，等于$E_1 = p^2/(2m_1)$。碰撞后，传递给第二个球的能量：$E_2 = p^2/(2m_2)$。通过这种形式的表示法，可以立即清楚地看出，如果球的质量相等，则它们的动能也相等，这意味着物体不会在系统中释放。这就是相同质量的球在绝对弹性冲击中应该发生的情况。同样明显的是，如果一个较重的球在这种条件下击中，那么它就不能停留（否则这将导致违反能量守恒定律）。因此，导致我们在分析答案时感到困惑的特殊情况（$m_1 > m_2$）是根本不可能的，因为它与问题的条件相矛盾，即来球在撞击后立即离开。
