**M490.** $p$ 是素数奇数。给定 $p-1$ 不能被$p$整除的整数。证明通过将其中一些数字替换为相反数，您可以得到 $p-1$ 个整数，其总和可被 $p$ 整除。

如果数字$a$和$b$除以$p$时得到相同的余数，我们将写$a \equiv b$（众所周知，在这种情况下，他们说$a$可与$b$模$p$相比较 - 请参阅«Kvant»No.1中的文章“余数的比较和类别”） 10）。那么很明显，如果$p$是奇素数，那么就存在一个整数$s$、$0 \leqslant 2s < p-1$使得$2s \equiv a_1 + \dots + a_{p-1}$（仔细想想！）。

对于证明，我们需要一个引理，该引理已在 «Kvant» («Kvant», 1971, No. 8, p. 43) 中发表过一次：

⟦folio 25⟧

引理。令数据$r$为数$b_1, b_2, \dots, b_r$的个数，不除以$p$； $0 < r < p$、$p$ - 简单。然后，通过除以 $p$ 时的各个余数，可以从这些数字中得出至少 $r + 1$ 总和（在这种情况下，允许取“空项集”的总和，该总和被视为等于零，“从一项”、“两项”、...、所有 $r$ 项的总和）。

我们将在下面给出这个引理的证明，现在我们将展示如何在它的帮助下解决我们的问题。

凭借引理，从数字 $a_1, \dots, a_{p-1}$ 可以形成至少 $p$ 和，当除以 $p$ 时，它们给出不同的余数。由于除以$p$时不同余数的总和正好是$p$份：$0, 1, \dots, p - 1$，因此在这些和中，有一个和除以$p$时给出余数$s$。让这个总和$a_{i_1} + \dots + a_{i_k}$；然后$a_{i_1} + \dots + a_{i_k} \equiv s$。现在让我们取所有不包括和 $a_{i_1} + \dots + a_{i_k}$ 中的项的其他数字；令这些数字为$a_{j_1}, \dots, a_{j_l}$。从$a_{1} + \dots + a_{p-1} \equiv 2s$和$a_{i_1} + \dots + a_{i_k} \equiv s$开始，我们得到$a_{j_1} + \dots + a_{j_l} \equiv s$。将数字$a_{j_1}, \dots, a_{j_l}$反转，我们得到数字$a_{i_1} + \dots + a_{i_k} - a_{j_1} - \dots - a_{j_l}$，相当于零模$p$，即可以被$p$整除。

为了完成问题的解决，我们留下了一个引理。让我们通过归纳法来做到这一点。

对于$r = 1$，引理的陈述是显而易见的。让我们假设 $r = k < p - 1$ 为真，$r = k + 1$ 为假，我们就得出了矛盾。因此，让 $k$ 项 $b_1, b_2, \dots, b_k$ 的和除以 $p$ $k + 1$ 得到不同的余数 $0, s_1, \dots, s_k$。那么，由于添加$b_{k+1}$后，它们的和的次数和项数不应增加，因此所有对$p$取模的和$0 + b_{k+1}, s_1 + b_{k+1}, \dots, s_k + b_{k+1}$都包含在集合$\{0, s_1, \dots, s_k\}$中。换句话说，如果将 $b_{k+1}$ 添加到该集合的任何元素，您将再次获得同一集合的元素。因此，这个集合是完整的并且包含元素$0, b_{k+1}, 2b_{k+1}, \dots, (p - 1)b_{k+1}$。但很明显，所有这些元素都是不同的（模$p$）：差$ib_{k+1} - jb_{k+1} = (i - j)b_{k+1}$（其中$0 < i - j < p$）不能除以$p$，因为$p$是素数。这意味着集合$\{0, s_1, \dots, s_k\}$包含所有$p$不同元素，尽管我们假设$k + 1 < p$。引理已得证。

如果由一滴水银分隔的水$V_1$和$V_2$的体积取决于温度，则该装置可以用作温度计。

让我们首先考虑当设备水平放置时，$V_1$是否依赖于$T$（以及$V_2$依赖于$T$）。如果一滴水银在$T$的温度下处于平衡状态，那么它左边和右边的压力应该是相同的：$p_1 = p_2$。让我们分别用$m_1$和$m_2$表示水滴左侧和右侧的水质量，并用$\mu$表示水的摩尔质量。然后

$$p_1 = \frac{m_1}{\mu V_1} RT, \quad p_2 = \frac{m_2}{\mu V_2} RT,$$

所以对于 $p_1 = p_2$ 我们有：

$$\frac{m_1}{V_1} = \frac{m_2}{V_2},$$ 或 $$\frac{V_1}{V_2} = \frac{m_1}{m_2}.$$

我们看到，当设备水平放置时，$V_1/V_2$不依赖于$T$。总和 $V_1+V_2$ 也是常数。因此，$V_1$和$V_2$都不依赖于温度$^*$）。该设备不能用作温度计。

当设备垂直放置时，液滴下方的压力必须高于其上方的压力，从而满足以下条件：

$$p_1s = p_2s + mg,$$

其中$m$是水滴的质量，$s$是管的横截面积，$p_1$和$p_2$分别是水滴下方和上方的水压。将$p_1$和$p_2$代入(2)式(1)，可得

$$\frac{m_1}{V_1} - \frac{m_2}{V_2} = \frac{mg\mu}{sRT}.$$

由于 $V_1+V_2$ 是常量，在这种情况下 $V_1$ 和 $V_2$ 都取决于温度。该装置可以用作温度计。
