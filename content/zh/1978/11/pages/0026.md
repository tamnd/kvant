对于任何 $n=1, 2, 3, \dots$ 证明所有这些序列都有极限并找到它。

则$A, B, C$点的重心在该轴上的投影坐标等于原点投影坐标的算术平均值，即$\frac{a' + b' + c'}{3}$。 （还要注意，线段中间的投影坐标在 y 总和中等于线段两端投影的坐标。）由于对于直线上的任意三个点$a, b, c$，我们可以选择平面上的三个点，其投影是点$a, b, c$，因此根据该陈述在平面上的有效性，可以得出该陈述在线上为真。

现在很容易给出数字 $d = \frac{a + b + c}{3}$ 是这些序列的一般极限的分析证明。要做到这一点，显然足以证明 $|a_n - d| = 2 |a_{n+1} - d|$、$|b_n - d| = 2 |b_{n+1} - d|$、$|c_n - d| = 2 |c_{n+1} - d|$（每一步序列都接近极限两倍）。

请注意，对于任意 $n$

$$a_{n+1} + b_{n+1} + c_{n+1} = \frac{b_n + c_n}{2} + \frac{c_n + a_n}{2} + \frac{a_n + b_n}{2} = a_n + b_n + c_n.$$

这表明对于任何 $n$ 都有 $d = \frac{a_n + b_n + c_n}{3}$。

我们有：

$$|a_n - d| = \left| a_n - \frac{a_n + b_n + c_n}{3} \right| = \left| \frac{2a_n - b_n - c_n}{3} \right| = \left| \frac{b_n + c_n - 2a_n}{3} \right| = 2 \left| \frac{b_n + c_n}{2} - \frac{a_n + b_n + c_n}{3} \right| = 2 |a_{n+1} - d|.$$

以同样的方式检查其他两个相等性。

总之，我们注意到以下几点。数字中的算术平均值被视为一种运算，是非关联的（即，一般来说，

$$\frac{a + b}{2} + c \neq \frac{a + b + c}{2}),$$

一般来说，三个数字的算术平均值并不表示为一次取两个数字的算术平均值的有限组合（证明一下！）。然而，正如我们所看到的，使用传递转移，三个数字的算术平均值可以通过两个数字的算术平均值来表达。类似的极限关系涉及任何整数 $k \geqslant 2$ 的算术 $k + 1$ 和 $k$ 数。
