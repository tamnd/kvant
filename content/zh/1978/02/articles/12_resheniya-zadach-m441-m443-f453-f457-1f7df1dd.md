M441。在凸 2n 空间内取点 P。通过每个顶点和点 P 绘制一条直线。让我们证明多边形有一条边，所绘制的线与该边都没有公共点（也许该边的端点除外）。

图 1.

在内部，如果一条直线的交点与多边形的顶点不重合，我们就说一条直线与多边形 M 的一条边相交。

可能有两种情况：1）点 P 属于多边形 M 的某个对角线 AB； 2) 点 P 不属于多边形 M 的任何对角线。

第一种情况，直线PA和PB与(AB)重合，不与M的任何边相交，并且通过点P与M的其余2n-2个顶点的直线最多相交2n-2条边。因此，多边形M的至少两条边不与任何所绘制的线相交。

现在让 P 不位于 M 的任何对角线上。取多边形 M 的对角线 AB，将其边界划分为两条 n 连折线 Γ1 和 Г2，并将 2n 边形 M 划分为两个凸 (n+1) 边形 M1 和 M2 (图 1)。假设P在M1内部；设C为多边形M2的任意顶点（与A和B不同）。由于M1和M2位于(AB)的相对侧，P∈M1，C∈M2并且多边形M是凸多边形，因此线PC和AB在某个点K∈[AB]相交（参见图1）。穿过多边形 M1 的内点并在边 AB 上与其边界相交于点 K 的线 PC 在不在 AB 上的另一点处与 M1 的边界相交，即与 Г1 相交。因此，穿过顶点 Г2（除了 A 和 B）的任何直线都与凸多边形 M 的边界相交于两点：顶点 Г2 和位于 Г1 上的点（可能与顶点 Г1 重合）。因此，任何直线都不与折线Г2的线段相交。

以类似的方式证明，线AP和BP也不与折线Γ2的线段相交。

因此，n+1条直线与多边形M的至多n条边相交（虚线Γ1的链接）。剩余的n-1条直线不能与多边形M的多于n-1条边相交（虚线Γ2的链接）。因此，(虚线 Γ2 的连接线中的)至少一侧不与通过点 P 和多边形 M 的顶点绘制的任何一条线相交。

G·古列维什

让我们像这样重写总和 $a_1 + a_2 + a_3 + \dots + a_{p-1}$：

$$(a_1 + a_{p-1}) + (a_2 + a_{p-2}) + \dots + (a_{\frac{p-1}{2}} + a_{\frac{p+1}{2}})$$

（$p-1$是偶数；最后的和中有$\frac{p-1}{2}$括号内的表达式）。让我们考虑表达式 $a_i + a_{p-i}$ 之一，用括号括起来。很容易看出

$$i^p + (p-i)^p = p^p - C_p^1 \cdot i \cdot p^{p-1} + \dots + C_p^{p-1} \cdot i^{p-1} \cdot p = p^2 l$$

— 可被 $p^2$整除（自 $C_p^{p-1} = p$；$p > 2$，$1 \leq i \leq p-1$）。因此$a_i + a_{p-i}$可以被$p^2$整除；并且从$a_i < p^2$、$a_{p-i} < p^2$开始，然后对于所有$i = 1, \dots, p-1$都是$a_i + a_{p-i} = p^2$。所以，

$$a_1 + a_2 + \dots + a_{p-1} = (a_1 + a_{p-1}) + \dots +$$

$$+ (a_{\frac{p-1}{2}} + a_{\frac{p+1}{2}}) = p^2 \cdot \frac{p-1}{2} = (p^3 - p^2)/2$$

这就是所说的。

F454。如果方向$U_0 = 220$V应用于未暴露的变压器的初级绕组，则次级绕组上的方向将为$U_1 = 127$V。连接到该变压器的次级绕组的$R = 10$欧姆方向在$U_0 = 220$V处的$U$方向是什么？变压器初级绕组的有功电阻为$r_1 = 2$欧姆，次级绕组为$r_2 = 1$欧姆。摩卡发生器的内阻为零。

让我们表示电动势的有效值。未暴露变压器的初级绕组中通过$E_1$发生感应，次级绕组则通过$E_2$发生感应。很明显

$$\frac{E_1}{E_2} = \frac{n_1}{n_2} = k,$$

其中 $n_1$ 是初级绕组的匝数，$n_2$ - 次级绕组的匝数，$k = n_1/n_2$ 是变压系数。由于在非外部变压器中

$$E_1 = U_0 \text{ и } E_2 = U_1,$$

那

$$k = \frac{E_1}{E_2} = \frac{U_0}{U_1} = \sqrt{3}.$$

当变压器带负载时，即次级绕组接有电阻$R$，电流流过初级绕组

$$I_1 = \frac{U_0 - E_1'}{r_1},$$

以及在次级绕组上——

$$I_2 = \frac{E_2'}{R + r_2}.$$

这里$E_1'$和$E_2'$是电动势的有效值。负载变压器的初级和次级绕组中的感应。

变压器的效率几乎等于unity。这意味着变压器初级绕组中的功率等于传输到次级电路的功率：

$$I_1 E_1' = I_2 E_2'.$$

然后

$$\frac{I_2}{I_1} = \frac{E_1'}{E_2'} = k.$$

我们将方程（1）、（2）和（3）合并到系统中：

$$\begin{align*}
I_1 &= \frac{U_0 - E_1'}{r_1} \\
I_2 &= \frac{E_2'}{R + r_2} \\
\frac{I_2}{I_1} &= k,
\end{align*}$$

在哪里

$$I_2 = \frac{k U_0}{r_1 + k^2 (R + r_2)},$$

和

$$U_2 = I_2 R = \frac{k U_0 R}{r_1 + k^2 (R + r_2)} \approx 110 \text{ B}.$$

F455。输电线路中的功率损耗是消费者接收到的功率的5%。您需要如何改变单声道的线路输入电压和消费者电阻，以便在消费者接收到相同功率的情况下，线路中的消耗减少到 1%？

消费者接收到的功率等于

$$P = I_0^2 R = \frac{U_0^2}{(R + r)^2} R,$$

其中 $I_0$ 是输电线路中的电流，$r$ 是线路电阻，$R$ 是用电设备电阻，$U_0$ 是线路输入电压。这个力量根据条件必须保持不变。因此，

$$\frac{U_0^2}{(R + r)^2} R = \frac{U_1^2}{(R_1 + r)^2} R_1,$$

其中 $U_1$ 是线路输入处的新电压，$R_1$ 是新的用电电阻。让我们用$\alpha$表示电线中损耗的功率与消费者接收到的功率的比率。然后

$$\alpha_1 = \frac{I_0^2 r}{I_0^2 R} = \frac{r}{R} = 0.05, \quad \alpha_2 = \frac{r}{R_1} = 0.01.$$

因此$R = \frac{r}{\alpha_1}$和$R_1 = \frac{r}{\alpha_2}$。

因此，

$$\frac{R_1}{R} = \frac{\alpha_1}{\alpha_2} = 5,$$

$$\frac{U_1}{U_0} = \frac{R_1 + r}{R + r} \sqrt{\frac{R}{R_1}} =$$

$$= \frac{r \left(1 + \frac{1}{\alpha_1}\right)}{r \left(1 + \frac{1}{\alpha_2}\right)} \sqrt{\frac{\alpha_2}{\alpha_1}} = \frac{1 + \alpha_2}{1 + \alpha_1} \sqrt{\frac{\alpha_1}{\alpha_2}} \approx \sqrt{5}.$$

I·斯洛博杰茨基

F456。单声道宇宙飞船在地球上需要达到的最低速度是多少才能到达太阳？飞船飞向太阳的时间是几点？

我们想象一下，一艘宇宙飞船从地球发射，其速度略小于地球反向运动的速度。飞船的轨迹将是一个椭圆形，其焦点之一是太阳。飞船相对于太阳的初始速度越低，其轨道就越长。在该速度的特定值下，运动中的飞船将接触太阳表面。换句话说，飞船轨道近日点的高度将等于太阳。太阳的半径大约比地球轨道半径小200倍，因此飞船椭圆轨道接触太阳的小带比大带小得多。为了进行估计，我们可以假设小增益简单地等于零。有了这个假设，飞船的轨迹就变成了一条直线，将飞船的发射点与太阳连接起来，也就是说，飞船撞击了太阳，自由落体到了太阳上。因此，在初始时刻，船相对于太阳的速度应为零。为了满足这个条件，飞船必须以与地球速度相反的绝对速度在地球上通信，但方向相反。

地球轨道半径约为$1,5 \cdot 10^{11}$米，地球绕太阳公转的周期为$\sim 3,15 \cdot 10^{7}$秒。因此，地球的轨道速度为

$$v = \frac{2\pi \cdot 1,5 \cdot 10^{11}}{3,15 \cdot 10^7} \approx 3 \cdot 10^4 \text{ м/с}.$$

这个速度必须在地球上达到（图8）。

F457。两个扁平空气电容器具有相同的极板并具有相同的电荷。第一个电容器极板之间的距离是第二个电容器极板之间距离的两倍。如果将第二个电容器留在第一个 Mak 的极板之间，系统电场的能量将如何变化，如图 9、a 和 6 所示？

充电电容器的电场能量等于

$$W = \frac{\varepsilon_0 \varepsilon E^2}{2} V,$$

其中$\varepsilon_0$是电常数，$\varepsilon$是介质的介电常数，$\vec{E}$是电场方向，$V$是电场所占据的体积。

让我们求两个空气电容器（$\varepsilon=1$）系统电场的初始能量$W_0$。由于电容器上的电荷相同，因此第一个电容器中的场方向与第二个电容器中的场方向相同。让我们用$E_0$表示它的绝对值。设第一个电容器的体积为$V_0$，第二个电容器的体积为$V_0/2$。然后

$$W_0 = \frac{\varepsilon_0 E^2}{2} V_0 + \frac{\varepsilon_0 E^2}{2} \frac{V_0}{2} = \frac{3}{4} \varepsilon_0 E^2 V_0.$$

将电容器一个放入另一个之后，板间电场方向的绝对值将变得不同。对于情况 a) (图 9, a)

$$E_1 = E_3 = E_0, \quad E_2 = 2E_0.$$

对应关系会发生变化，系统的能量也会发生变化：

$$W = \frac{\varepsilon_0 E^2}{2} (V_1 + V_3) + \frac{\varepsilon_0 E^2}{2} V_2 = \frac{5}{4} \varepsilon_0 E^2 V_0.$$

从这里

$$\frac{W}{W_0} = \frac{5}{3}.$$

情况 b) (图 9, b)

$$E_1 = E_3 = E_0, \quad E_2 = 0.$$

然后

$$W = \frac{\varepsilon_0 E^2}{2} (V_1 + V_3) = \frac{1}{4} \varepsilon_0 E^2 V_0,$$

和

$$\frac{W}{W_0} = \frac{1}{3}.$$
