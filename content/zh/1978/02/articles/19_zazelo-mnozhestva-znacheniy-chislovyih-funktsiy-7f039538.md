数值函数的值集

回想一下，数值函数$f$的值集合$E(f)$称为所有$a \in \mathbb{R}$的集合，其中至少存在一个$x \in D(f)$使得$f(x) = a$。我们可以换一种说法：$E(f)$ 由方程 $f(x) = a$ 至少有一个解的那些 $a$ 组成。在简单的情况下，可以检查这个方程，从而找到 $E(f)$。

示例 1. 查找函数值集合

$$f(x) = \frac{2x}{1+x^2}.$$

方程$f(x) = a$改写为$ax^2 - 2x + a = 0$；对于$a = 0$，它由$x = 0$满足，对于$a \neq 0$，我们有一个二次方程，它仅对判别式为非负的那些$a$有解：$D = 4 - 4a^2 \geq 0$，即$a^2 \leq 1$或$a \in [-1; 1]$（和$a \neq 0$）。所以方程 $f(x) = a$ 有解当且仅当 $a \in [-1; 1]$，所以$E(f) = [-1; 1]$。注意，我们同时找到了函数$f$ - $\min f = -1$、$\max f = 1$的最小值和最大值。

示例 2. 查找函数值集

$$f(x) = 2\cos x + \cos 2x.$$

让我们将$f(x)$重写为$f(x) = 2\cos x + 2\cos^2 x - 1 = 2z^2 + 2z - 1$的形式，其中$z$表示函数$\cos x$。从$z \in [-1; 1]$开始，剩下的就是找出二次函数$g(z) = 2z^2 + 2z - 1$在区间$[-1; 1]$上的值的集合是什么。函数$g(z)$的图形是一条抛物线，其顶点位于横坐标$z_0 = -1/2$（解释）处，其分支向上。我们有：$g(z_0) = -3/2$、$g(-1) = -1$、$g(1) = 3$。如果我们绘制二次三项式的图，那么很明显，线段 $[-1; 1]$ 上的一组值$g$（或者方程 $g(z) = a$ 至少有一个根 $z \in [-1; 1]$ 的$a$ 的集合）是线段 $[-3/2; 3]$。因此，函数$f(x) = 2\cos x + \cos 2x$的值集是线段$[-3/2; 3]$。回来我们找到了$\min f = -3/2$和$\max f = 3$。

在没有多个形式的函数值的情况下

$$f(x) = A\cos x + B\sin x$$

您可以用 $t = tg(x/2)$ 表达 cos $x$ 和 sin $x$（参见“代数和元素”10”，第 91 段），然后检查所得方程（相对于 $t$ 它将是二次方程）。

然而，这样可以更快更容易地完成：

$$A\cos x + B\sin x = \sqrt{A^2 + B^2} \times \left( \frac{A}{\sqrt{A^2 + B^2}} \cos x + \frac{B}{\sqrt{A^2 + B^2}} \sin x \right);$$

因为

$$\left( \frac{A}{\sqrt{A^2 + B^2}} \right)^2 + \left( \frac{B}{\sqrt{A^2 + B^2}} \right)^2 = 1,$$

有一个值 $\alpha$ 使得
$$\cos \alpha = \frac{A}{\sqrt{A^2 + B^2}}, \sin \alpha = \frac{B}{\sqrt{A^2 + B^2}}$$
（解释）因此
$$A \cos x + B \sin x = \sqrt{A^2 + B^2} \left( \cos x \cos \alpha + \sin x \sin \alpha \right) = \sqrt{A^2 + B^2} \cos (x - \alpha)$$.

因此，函数$f(x) = A \cos x + B \sin x$的值集是段$[-\sqrt{A^2 + B^2}, \sqrt{A^2 + B^2}]$，这同样适用于$A \cos \omega x + B \sin \omega x$形式的函数，其中$\omega \neq 0$。

任务 6. 指定以下函数的值集：

a) $\cos x - \sin x + 1; 6)$ $3 \cos \frac{x}{2} + 4 \sin \frac{x}{2};$
b) $\cos^2 x - \sin x \cos x$.

事实上，在所有分析的例子和给定的问题中，方程$f(x) = a$的解都可以明确地写出来，即参数$a$的方程$f(x) = a$被“求解”（简化为线性、二次或简单的指数、对数和三角方程）。因此，无需使用任意函数即可找到所考虑的函数的最小值和最大值（此外，这里使用任意函数的研究通常比代数研究更麻烦）。在方程 $f(x) = a$ 没有提交给非总统解决方案（“未解决”）的情况下，采取相反的路线是合理的，我们现在将对此进行描述。

例3（本题摘自《1977年大学数学入学考试近似选项》，«Kvant»，1977年，第6期，第89页）。让我们找到函数值的集合

$$f(x) = \sin x \cdot \cos 2x$$

表示$\sin x = z$，我们可以写：$f(x) = g(z) = z (1 - 2z^2) = z - 2z^3$。如例2，性质的问题是找到函数$g$在线段$[-1; 1]$上的值集。请注意，方程是 $g(z) = a - кубическое$，我们无法求解。让我们找出函数$g$在线段$[-1; 1]$上的最小值和最大值。根据研究线段上函数的一般方案（参见“代数与基础分析9”，第59段），我们找到函数的临界点：$g'(z) = 1 - 6z^2 = 0$在$z^2 = 1/6$，即$z = \pm \sqrt{1/6}$；两个临界点都属于线段$[-1; 1]$，其中函数的值如下：

$$g(\sqrt{1/6}) = \sqrt{6}/9, g(-\sqrt{1/6}) = -\sqrt{6}/9.$$

将这些值与段末尾的值进行比较 - $g(-1) = 1$ 和 $g(1) = 1$ - 我们得到：$\min(z - 2z^3) = -1, \max(z - 2z^3) = 1.$

由于函数$g$总是不连续的，所以它自然会得出$g$取最小和最大之间的任意值，即$E(g) = E(f) = [-1; 1]$。为了证明这一点，我们将使用一个关于连续单调函数的值集的重要定理：

如果函数$F$不是不连续的，并且在区间$[a; b]$上增加（或减少），则函数$F$在该区间上取的值的集合也是一个区间：$[F(a); F(b)]$（如果$F$正在减少，则为$[F(b); F(a)]$）。

教科书《代数与入门分析10》第84段给出了该定理的更一般和完整的表述（无证明）。回到我们的函数，我们发现$g$在线段$[-\sqrt{1/6}; \sqrt{1/6}]$上增加，在线段$[-1; -\sqrt{1/6}], [\sqrt{1/6}, 1]$上减少。

根据最后一个定理，这些线段上的集合$g$将有对应的线段$[-\sqrt{6}/9; \sqrt{6}/9], [-\sqrt{6}/9; 1]$和$[-1; \sqrt{6}/9]$；

它们的并集给出了函数$g$在整个区间$[-1; 1] - E(g) = [-1; 1]$上的值集。
