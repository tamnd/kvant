F454。如果方向$U_0 = 220$V应用于未暴露的变压器的初级绕组，则次级绕组上的方向将为$U_1 = 127$V。连接到该变压器的次级绕组的$R = 10$欧姆方向在$U_0 = 220$V处的$U$方向是什么？变压器初级绕组的有功电阻为$r_1 = 2$欧姆，次级绕组为$r_2 = 1$欧姆。摩卡发生器的内阻为零。

让我们表示电动势的有效值。未暴露变压器的初级绕组中通过$E_1$发生感应，次级绕组则通过$E_2$发生感应。很明显

$$\frac{E_1}{E_2} = \frac{n_1}{n_2} = k,$$

其中 $n_1$ 是初级绕组的匝数，$n_2$ - 次级绕组的匝数，$k = n_1/n_2$ 是变压系数。由于在非外部变压器中

$$E_1 = U_0 \text{ и } E_2 = U_1,$$

那

$$k = \frac{E_1}{E_2} = \frac{U_0}{U_1} = \sqrt{3}.$$

当变压器带负载时，即次级绕组接有电阻$R$，电流流过初级绕组

$$I_1 = \frac{U_0 - E_1'}{r_1},$$

以及在次级绕组上——

$$I_2 = \frac{E_2'}{R + r_2}.$$

这里$E_1'$和$E_2'$是电动势的有效值。负载变压器的初级和次级绕组中的感应。

变压器的效率几乎等于unity。这意味着变压器初级绕组中的功率等于传输到次级电路的功率：

$$I_1 E_1' = I_2 E_2'.$$

然后

$$\frac{I_2}{I_1} = \frac{E_1'}{E_2'} = k.$$

我们将方程（1）、（2）和（3）合并到系统中：

$$\begin{align*}
I_1 &= \frac{U_0 - E_1'}{r_1} \\
I_2 &= \frac{E_2'}{R + r_2} \\
\frac{I_2}{I_1} &= k,
\end{align*}$$

在哪里

$$I_2 = \frac{k U_0}{r_1 + k^2 (R + r_2)},$$

和

$$U_2 = I_2 R = \frac{k U_0 R}{r_1 + k^2 (R + r_2)} \approx 110 \text{ B}.$$
