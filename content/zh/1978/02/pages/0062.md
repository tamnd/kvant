令$P$和$Q$分别为线$SE$和$CD$上的点，使得$PQ \perp SE$和$PQ \perp CD$。那么所需的距离就是$|PQ|$。让我们用$\alpha$和$\beta$表示确定点$P$和$Q$位置的数字：$\overrightarrow{SP} = \alpha \overrightarrow{SE}$，$\overrightarrow{CQ} = \beta \overrightarrow{CD}$。

$$\overrightarrow{PQ} = \overrightarrow{PS} + \overrightarrow{SC} + \overrightarrow{CQ}.$$

让我们找到向量 $\overrightarrow{PS}$、$\overrightarrow{SC}$ 和 $\overrightarrow{CQ}$ 在所选坐标系中的坐标。 $\overrightarrow{PS} = -\overrightarrow{SP} = (-\alpha) \overrightarrow{SE}$。从$|CE| = |EB|$和$|BD| = |DA|$开始，$\overrightarrow{SE} = \left( \frac{|CD|}{2}; \frac{|AB|}{4} \right)$； $-|SC|$。 $|CD| = \sqrt{|AC|^2 - |AD|^2} = 2\sqrt{6}$。所以，$\overrightarrow{SE} = (\sqrt{6}; \sqrt{2}; -2)$。

因此，$\overrightarrow{PS} = (-\sqrt{6}\alpha; -\sqrt{2}\alpha; 2\alpha)$。显然$\overrightarrow{SC} = (0; 0; -2)$。从$\overrightarrow{CD} = (2\sqrt{6}; 0; 0)$开始，$\overrightarrow{CQ} = (2\sqrt{6}\beta; 0; 0)$。

所以，

$$\overrightarrow{PQ} = (-\sqrt{6}\alpha + 2\sqrt{6}\beta; -\sqrt{2}\alpha; 2\alpha - 2).$$

我们将从条件$\overrightarrow{PQ} \cdot \overrightarrow{SE} = 0$和$\overrightarrow{PQ} \cdot \overrightarrow{CD} = 0$求出未知数$\alpha$和$\beta$。

$$\begin{cases} (-\sqrt{6}\alpha + 2\sqrt{6}\beta) \sqrt{6} + (-\sqrt{2}\alpha) \sqrt{2} + (2\alpha - 2)(-2) = 0 \\ (-\sqrt{6}\alpha + 2\sqrt{6}\beta) 2\sqrt{6} + (-\sqrt{2}\alpha) \cdot 0 + (2\alpha - 2) \cdot 0 = 0. \end{cases}$$

从系统的第二个方程$-\sqrt{6}\alpha + 2\sqrt{6}\beta = 0$（这可以预测：从$\overrightarrow{PQ} \perp \overrightarrow{CD}$开始，向量$\overrightarrow{PQ}$的第一个坐标是0）。然后根据第一个方程$\alpha = \frac{2}{3}$。所以，$\beta = \frac{1}{3}$。所以，

$$\overrightarrow{PQ} = \left( 0; -\frac{2\sqrt{2}}{3}; -\frac{2}{3} \right).$$

所以，$|PQ| = \sqrt{0^2 + \left(-\frac{2\sqrt{2}}{3}\right)^2 + \left(-\frac{2}{3}\right)^2} = \frac{2}{\sqrt{3}}$。

从$\overrightarrow{SE} = (\sqrt{6}; \sqrt{2}; -2)$我们得到$|\overrightarrow{SE}| = 2\sqrt{3}$。
