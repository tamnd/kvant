通常，方格纸用于绘制具有给定笛卡尔坐标的点。就我们的目的而言，最好使用三线纸，即在纸上绘制三个平行线系统，将其分成小的等边三角形。让我们在这样的纸上画一个大的等边三角形 ABC，其边沿网格线延伸。对于该平面上的任意点 P，我们将数字 x、y、z 分别定义为从该点到直线 BC、CA 和 AB 的距离，并且对于这些直线中的每一条，如果该点位于该直线与三角形 ABC 的同一侧，则距离将为正，否则将被印记。我们将所得的数字 (x, y, z) 点称为尿液 P 相对于三角形 ABC 的三线坐标。请注意，坐标中的点描述了涉及三个变量且总和恒定的情况。如果这些量 x、y 或 z 之一保持不变，而另外两个发生变化，则点 (x, y, z) 沿平行于三角形 ABC 的一条边的直线移动。特别地，坐标 BC、CA 和 AB 所在的直线由以下方程描述

$$x = 0, y = 0, z = 0,$$

顶点 A、B、C 的坐标为 (h, 0, 0)、(0, h, 0)、(0, 0, h)。

这正是当 h 升液体倒入以下容器中时会出现的情况：第一个容器中有 x 升，第二个容器中有 y 升，第三个容器中有 z 升。逐渐地，液体从第二个容器输注到第三个容器对应于具有三线坐标(x,y,z)的点相对于高度等于h的三角形ABC的移动，沿着直线x=const在对应于y减小和z增大的方向上的移动。如果每个容器总共可以容纳 h 升（我们用符号 [h; h, h, h] 表示这种情况），那么每个坐标 x、y、z 可以取 0 到 h 之间的任何值，并且通过某种方式将液体从一个容器倒入另一个容器可以到达的点集 - 我们将这个集合称为操作区域 - 由不等式给出。

$$0 \leq x \leq h, 0 \leq y \leq h, 0 \leq z \leq h,$$
