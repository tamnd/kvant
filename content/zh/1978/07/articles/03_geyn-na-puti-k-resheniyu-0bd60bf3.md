通过分析$n = 2, 3$和4处问题的答案，我们只能创建关于这些答案的结构的假设，而根本不能创建关于如何解决问题的假设。现在让我们看看如何获​​得 $n = 3$ 的这些答案。

令 $(x, y, z)$ 为三个数字问题的某个解。那么等式必须成立

$$\begin{cases} xy + 1 = k_1z, \\ xz + 1 = k_2y, \\ yz + 1 = k_3x, \end{cases}$$

其中 $k_1, k_2, k_3$ 是一些自然数。

将这些比率相乘，我们得到

$$xyz (xyz + x + y + z) + xy + xz + yz + 1 = k_1k_2k_3xyz.$$

由此可知 $xy + xz + yz + 1$ 可以被 $xyz$整除，即

$$xy + xz + yz + 1 = Axyz,$$

其中$A$是自然数。将这个等式两边除以 $xyz$，我们得到

$$\frac{1}{x} + \frac{1}{y} + \frac{1}{z} = A. \quad (1)$$

因此，$n = 3$问题的任何解都满足方程（1）。将我们与分母分开，很容易看出相反的情况成立：如果$x, y, z$是满足某些自然$A$方程（1）的自然数，那么$(x, y, z)$是$n = 3$问题的解。

(1)左边对$x, y, z$的最小值取最大值；如果$2 \leq x < y < z$，那么

$$A \leq \frac{1}{2} + \frac{1}{3} + \frac{1}{4} + \frac{27}{24} < 2.$$

因此，$A = 1$和$x, y, z$满足方程

$$\frac{1}{x} + \frac{1}{y} + \frac{1}{z} = 1.$$

嗯，第一步是很自然的。根据整除性的定义，我们使用了几个模糊的词——一个数字被分成具体的、熟悉的物体。确实，以前不存在的新未知数$k_1, k_2, k_3$已经出现，但这是对“某些定义”的普遍报应。第二步是完全可以理解的——摆脱“额外”未知数的愿望（通过从系统转向单个方程）。

对任意 $n$ 执行类似的操作后，我们再次获得以下形式的方程

$$\frac{1}{x_1} + \frac{1}{x_2} + \dots + \frac{1}{x_n} + \frac{1}{x_1 \dots x_n} = A, \quad (2)$$

其中$A$是自然数。同样，相反的情况也很容易验证：

如果 $x_1, x_2, \dots, x_n$ 是满足某些自然 $A$ 方程 (2) 的自然数，则集合 $(x_1, x_2, \dots, x_n)$ 是我们问题的解。

因此，原问题等价于在所有可能的自然数$A$的最小数中找到方程（2）的解的问题。晋升当然不容易，但“只要一点点……就已经很好了！”
