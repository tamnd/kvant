我们将通过归纳法进行证明 $k = m + n$。因为 $x_1 + x_2 + \dots + x_m \geq m, y_1 + y_2 + \dots + y_n \geq n$，则 mn > m，mn > n，开 $m \geq 2, n \geq 2, k \geq 4$。如果 $k = 4$， 那是 $m = n = 2, x_1 + x_2 = y_1 + y_2 < 4$，那么至少有一个数字 $x_1, x_2$ 等于 1 且至少有一个数字 $y_1, y_2$ 等于 1。所以对于 $k = 4$ 问题的陈述是正确的。让我们假设该陈述已被证明 $m = n = k$，我们将证明这一点 $m + n = k + 1$.

令 $x_1$ 为最多的数字 $x_1, x_2, \dots, x_m, y_1$ 为最多的数字 $y_1, \dots, y_n$ ($m + n = k + 1$)。如果$x_1 = y_1$，则划掉$x_1$和$y_1$。让$x_1 > y_1$。距离平等

$$(x_1 - y_1) + x_2 + \dots + x_m = y_2 + \dots + y_n,$$

(*) 包含所有 $m + n - 1 = k$ 项。为了引入归纳命题，我们需要检查$y_2 + \dots + y_n < m(n - 1)$。让我们输入$S = y_1 + y_2 + \dots + y_n$。然后 $y_1 \geq \frac{S}{n}$ 因此

$$y_2 + \dots + y_n < S - \frac{S}{n} = S \cdot \frac{n - 1}{n}.$$

从$S < mn$开始，然后$y_2 + \dots + y_n < mn \cdot \frac{n - 1}{n} = m(n - 1)$。

通过划掉等式（*）中的一些项，从而再次得到正确的等式（这可以通过归纳假设来完成）；我们得到排除或左侧包含差值 $x_1 - y_1$ 的等式。在后一种情况下，您需要将$y_1$转移到正确的部分。

空了，我们就直接，$x_1$。让我们证明$O_2 \in S_1$。事实上，很明显，这个点就是$(x_1; x_2) \in S_1$。从$O \in S_1$开始，$(x; y)$中的每个点$0 \leq x \leq x_1$、$0 \leq y \leq x_1$都属于$S_1$。特别是$(x_2; y_2) \in S_1$，这是所需要的。

现在让我们描述正确的“标记”方块。令$K_1$为给定的1000个方格中最多的（下文中，如果最多的不是几个，我们取其中之一）。令 $K_2$ 为给定族中中心位于 $K_1$ 之外的那些正方形中最大的一个； $K_3$ 是给定族中大多数在 $K_1$ 和 $K_2$ 等之外有中心的正方形。此过程以构造正方形 $K_n$ 结束，使得集合 $M$ 没有位于 $K_1$、...、$K_n$（有限正方形总数）之外的点。以这种方式标记的正方形$K_1$，...，$K_n$满足问题的许多条件：它们覆盖了集合$M$。要证明他们满足第二个条件，只要验证他们五个人没有共同点就足够了。事实上，根据引理，如果找到这样的点，则其中一个标记的正方形将包含另一个标记的正方形的中心。需要注意的是，我们选择的正方形的情况并非如此。事实上，如果$i < j$，那么通过构造$K_j$的中心位于$K_i$之外；而且，$K_j$不大于$K_i$，因此，中心$K_i$也在$K_j$之外。

$$|\Delta (mv_y)| = F\Delta t.$$

F479。要确定圆柱体 I 的未知体积$V_1$，请组装图 5 所示的图。圆柱体 II 的体积为$V_2$ 和$V_2 \leq V_1$。首先，系统被抽压至 $p_0$ 压力，接近于零。然后关闭水龙头 B 并向气缸 II 充入气体至压力 $p_0$。此后，关闭阀门 A，打开阀门 B，用压力表 C 测量系统$p_1$ 中建立的压力。然后，在阀门 B 关闭的情况下，将气瓶移至压力$p_a$，打开阀门 B，测量系统$p_2$ 中建立的压力。该操作重复n次。证明比率 $\frac{p_n - p_0}{np_a}$ 等于且等于 $\frac{V_2}{V_1 + V_2}$。

根据实验条件，利用Boyle-Marport定律，得到n个方程组
$$p_0 V_1 + p_a V_2 = p_1 (V_1 + V_2),$$
$$p_1 V_1 + p_a V_2 = p_2 (V_1 + V_2),$$
$$p_{n-1} V_1 + p_a V_2 = p_n (V_1 + V_2).$$
该系统允许所有$p_i$（$i = 1, 2, \dots, n$）都用$p_0$和$p_a$来表示。真的吗，
$$p_i = \frac{p_{i-1} V_1 + p_a V_2}{V_1 + V_2},$$
在哪里
$$p_i - p_a = \frac{V_1}{V_1 + V_2} (p_{i-1} - p_a) = \alpha (p_{i-1} - p_a),$$
其中$\alpha = \frac{V_1}{V_1 + V_2}$。因此，
$$p_{i-1} - p_a = \alpha (p_{i-2} - p_a), p_{i-2} - p_a = \alpha (p_{i-3} - p_a)$$等
因此，$p_n - p_a = \alpha^n (p_0 - p_a)$，从哪里
$$p_n = p_a + \alpha^n (p_0 - p_a),$$
$$p_n - p_0 = (p_a - p_0)(1 - \alpha^n).$$
但是$1 - \alpha^n = (1 - \alpha)(1 + \alpha + \alpha^2 + \dots + \alpha^{n-1}) \approx n \frac{V_2}{V_1 + V_2}$（因为$V_1 \gg V_2$，因此$\alpha$接近于1）。方法，
$$p_n - p_0 \approx (p_a - p_0) n \frac{V_2}{V_1 + V_2},$$
$$\frac{p_n - p_0}{n (p_a - p_0)} \approx \frac{V_2}{V_1 + V_2}.$$
若$p_0 \ll p_a$，则
$$\frac{p_n - p_0}{np_a} \approx \frac{V_2}{V_1 + V_2}.$$

F480。该船由喷水器驱动，以$u$的速度从船体喷射出一串水。每秒都会释放出大量的水$m$，这些水是从河流中抽取的。船的航速是$k$、$n$、$d$。最大移动量？摩擦力和水的阻力提出了要求。

发动机在短时间内 $\Delta t$ 所做的总功 $A$ 等于船舶发动机喷出的水所传递的动能。由于这段时间释放的水的质量等于$\mu \Delta t$，则

$$A = \frac{(\mu \Delta t) u^2}{2}.$$

这段时间所做的有用功等于船舶动能的变化。若船的质量为$M$，则

$$A_{\text{пол}} = \frac{M (v + \Delta v)^2}{2} - \frac{M v^2}{2} = M v \Delta v,$$

其中$v$是船速的绝对值。忽略小方​​块$(\Delta v)^2$，我们得到$A_{\text{пол}} = M v \Delta v$。为了找到 $M \Delta v$，您可以使用动量守恒定律。由于摩擦力和阻力很小，水船系统的冲量不会改变。因此，

$$M v = M (v + \Delta v) - \mu \Delta t (u - v).$$

从这里

$$M \Delta v = \mu \Delta t (u - v).$$

发动机效率等于

$$\eta = \frac{A_{\text{пол}}}{A} = \frac{2 M v \Delta v}{(\mu \Delta t) u^2} = \frac{2 (u - v) v}{u^2}.$$

这是 $v = \frac{u}{2}$ 处最大值的表达式。
