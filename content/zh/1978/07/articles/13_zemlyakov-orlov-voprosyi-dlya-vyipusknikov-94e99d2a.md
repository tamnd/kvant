问题
对于毕业生

“......是时候找出世界上的一座建筑，去哪里或转向是一个问题，而不是答案。”

以下问题主要针对那些今年从 X 级毕业并计划进入大学的人 - 在考试前检查一下自己！您每次需要从五个答案（a、6、c、d 或 e）中选择唯一正确的一个。

数学

1. 图 1 (a, 6, c, d, e) 上的哪条线是方程 $2x + 3y + 1 = 0$ 的图形？

2. 以下哪组是不等式$\log_{1/3} x > 0$的解组？

a) $|0; +\infty[; 6)$ $|1; +\infty[; b)$ $|1/3; +\infty[; r)$ $|0; 1[; d)$ $|0; 1/3[$.

3. 对于$a$的什么值，对应$\exp(\ln(\ln a)) = a$有效？

a) 在任何情况下； 6) 对于任何； b）在$a > 0$； d) 在$a > 1$； e) 在$a > e$。

4. 单圆 (图 2) 上指示的点 (a, 6, c, d) 中哪一个对应于值 $\varphi = 1820^\circ$？

d) 未指出所需点。

5. 将数字 $c = \cos 1000^\circ$、$s = \sin 1000^\circ$、$t = \tg 1000^\circ$ 按升序排列。

a）$t < c < s$； 6) $c < s < t$; b）$t < < s < c$； d）$s < c < t$； d) $s < t < c$。

6. 任意函数$f(x) = \sin(x^2)$的值是多少？

a）$2\sin x$； 6) $\sin 2x$; b）$\cos 2x$； d）$2x\sin(x^2)$； d) $2x\cos(x^2)$。

7. 以下哪个函数是函数 $f(x) = -\cos 2x$ 的反导函数？

a）$-\sin 2x$； 6) $-2\sin 2x$; b）$-\frac{1}{2}\sin 2x$； d）$\frac{1}{2}\sin 2x$； d) $2\sin 2x$。

8. 对于函数 $f(x) = e^{x^2}$，其图形经过点 $(c; 0)$，其中 $c$ 是给定数，有多少个反导数？

a) 无； 6) 一个； b) 两个； d) 无穷多个； d) 答案取决于 $c$ 的值。

9. 两个向量的标量积为 -1。这些向量之间的角度 $\varphi$ 的值可能是多少？

a）$\varphi = 0^\circ$； 6) $\varphi = 90^\circ$; b）$\varphi = 180^\circ$； d）$0^\circ \leqslant \varphi \leqslant 90^\circ$； d) $90^\circ < \varphi \leqslant 180^\circ$。
