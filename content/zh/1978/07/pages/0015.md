所以，引理2的起源至少被澄清了。确实，我们没有获得新的解，并且仍然不清楚不是通过应用引理 1 和 2 形成的解从何而来（例如，$n = 5$问题的解 (2, 3, 7, 47, 395)）。又死路一条？在我们放弃我们选择的道路之前，让我们再三考虑。我们是否已经用尽了我们方法的所有可能性？谁阻止我们添加至少两个数字？我们来试试吧。

我们首先假设$(x_1, \dots, x_k)$是$n = k$问题的解。然后

$$\frac{1}{x_1} + \dots + \frac{1}{x_k} + \frac{1}{f_k} = A.$$ (3)

让$(x_1, \dots, x_k, x_{k+1}, x_{k+2})$作为$n = k + 2$和$x_{k+1} \neq 1, x_{k+2} \neq 1$问题的解。事实证明，在这种情况下也是如此

$$\frac{1}{x_1} + \dots + \frac{1}{x_k} + \frac{1}{x_{k+1}} + \frac{1}{x_{k+2}} + \frac{1}{f_k x_{k+1} x_{k+2}} = A$$ (4)

具有相同的$A$。

因此，

$$\frac{1}{x_{k+1}} + \frac{1}{x_{k+2}} + \frac{1}{f_k x_{k+1} x_{k+2}} = \frac{1}{f_k},$$ (5)

在哪里

$$x_{k+2} = f_k + \frac{f_k^2 + 1}{x_{k+1} - f_k}.$$ (6)

由于$x_{k+2}$必须是整数，因此$d = x_{k+1} - f_k$是$f_k^2 + 1$的约数。所以，

$$\begin{cases} x_{k+1} = f_k + d, \\ x_{k+2} = f_k + \frac{f_k^2 + 1}{d}. \end{cases}$$ (7)

现在让我们用$d$表示数字$f_k^2 + 1$的任意约数，并通过等式（7）定义数字$x_{k+1}, x_{k+2}$。那么对于数字 $f_k, x_{k+1}, x_{k+2}$ (6) 满足，因此满足 (5)。由(3)和(5)得出(4)。这意味着扩展集$(x_1, \dots, x_k, x_{k+1}, x_{k+2})$是我们问题$n = k + 2$的解决方案。所以，我们已经证明了这一点。

引理 3. 令 $(x_1, \dots, x_k)$ 为$n = k, f_k = x_1 \dots x_k$ 问题的解，$d$ 为 $f_k^2 + 1$ 的除数。那么集合$(x_1, \dots, x_k, f_k + d, f_k + \frac{f_k^2 + 1}{d})$就是$n = k + 2$问题的解。反之亦然：如果$n = k$问题的解我们将两个数$n = k$相加，我们将两个不等于1的数相加，那么相加的数满足等式（7）。

因此，如果$n = k + 2$问题的解是通过将两个数与$n = k$问题的解相加获得的，那么它要么由引理2形成，要么由引理3形成。

$y f_k^2 + 1$ 的两个约数始终为 1 和 $f_k^2 + 1$。然而，很容易看出，对于这样的除数，与引理 2 相比，引理 3 并没有给出任何新内容。但是，如果 $f_k^2 + 1$ 不是素数，那么引理 3 会产生一系列新的解决方案$(x_{k+3}$ 可以使用引理 2 再次构造，等等）。例如，对于解 (2, 3, 7)，我们有 $f_k^2 + 1 = 1765 = 5 \cdot 353$，通过引理 3，我们可以得到解 (2, 3, 7, 47, 395)，我们在第 1 段中提到过。同样，通过引理 3，我们可以从解 (2, 3, 7, 43) 得到解 (2, 3, 7, 43, 1823, 193,667）（此处$f_k^2 + 1 = 3261637 = 17 \cdot 191861$）。
