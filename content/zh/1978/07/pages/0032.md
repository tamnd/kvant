该案[h； a、b、c]。这里，三个给定容器的容量为 a、b、c 且 h≥a>b>c。让我们设定任务：您需要量出一定量的 d 升液体，将大量液体从一个容器倒入另一个容器中；同时，我们切掉少量，要么完全清空一个容器，要么将另一个容器装满（也许我的其他容器也会同时发生）。运算域现在由不等式指定

$$0 \leq x \leq a, \ 0 \leq y \leq b, \ 0 \leq z \leq c,$$

通常定义由六条直线界定的规则或不规则六边形

$$x = 0, \ x = a, \ y = 0, \ y = b, \ z = 0, \ z = c.$$

但在某些情况下，这个区域可以变成五边形、梯形、平行四边形，或者（正如我们已经看到的）覆盖整个等边三角形。

我们假设数字 a、b、c、h 和 d 是整数。
