(2) $A = 1$。由于我们可以假设 $2 \leqslant x_1 < x_2 < \dots < x_n$，因此对于 $A$，我们得到了估计：

$$A = \frac{1}{x_1} + \dots + \frac{1}{x_n} + \frac{1}{x_1 \dots x_n} \leqslant \frac{1}{2} + \frac{1}{3} + \dots + \frac{1}{n} + \frac{1}{n!}.$$

然而，对于$n = 14$，右侧的总和已经大于2。但也许从这个估计仍然可以得出结论，$A$的值是有限的，因此只能取有限数量的值？但事实并非如此：总和$\frac{1}{2} + \dots + \frac{1}{n}$随着$n$的增加而无限制地增加。

练习1.证明它。

显然我们的估算方法过于粗略。有可能连累他吗？例如，很明显，解中包含的所有数字都是互质的。因此，特别是，如果$x_1 = 2$，则$x_3 > 4$。

让我们证明，总和 $\frac{1}{x_1} + \dots + \frac{1}{x_n} + \frac{1}{x_1 \dots x_n}$ 可以通过数字 $\frac{1}{2} + \frac{1}{3} + \frac{1}{5} + \dots + \frac{1}{p} + \frac{1}{2 \cdot 3 \cdot 5 \cdot \dots p}$ 来估计，其中 $p$ 只是一个数字。

事实上，让我们用 $p_i$ 来表示数字 $x_i$ 的某个素因数。请注意$p_i \leqslant x_i$。由于数字 $x_i$ 是成对素数，因此所有 $p_i$ 都是不同的。我们将考虑按尺寸排序。然后$2 \leqslant p_1, 3 \leqslant p_2, 5 \leqslant p_3$，等等。将$x_i$替换为$p_i$，我们就得到了所需的估计。

也许素数的倒数之和不超过某个素数$M$？这意味着$A < M + 1$。事实证明，这不是真的：随着数量的增加，总和 $\frac{1}{2} + \frac{1}{3} + \dots + \frac{1}{p}$ 无限增加*)。尽管如此，我们还是得到了一个估计值，使我们能够对所有 $n \leqslant 58$ 表示 $A = 1$。虽然没有多少安慰，但至少很清楚为什么在分析答案时，我们没有找到具有常数 $A = 2$ 的解决方案：不太可能有人会想到同时考虑 60 个数字的问题。

谁能预先知道哪条路会通向成功？耐心（但不是固执）是研究的原则。让我们再次回到旅程的起点。我们现在已经掌握了针对特殊情况的答案分析和解决问题的方法。引理 1 和 2 值得关注 - 它们至少包含一些用于寻找解决方案的算法。他们提出了什么方法？两个引理都讨论了如何从$n = k$问题的解获得$n = k + 1$问题的解。这种方法我们很熟悉（记住数学归纳法）。让我们尝试一下，假设解决问题是针对$n = k$，来解决$n = k + 1$。

因此，路径$(x_1, \dots, x_k)$是$n = k$问题的解决方案。让我们用 $f_k$ 表示乘积 $x_1 \dots x_k$。然后$\frac{1}{x_1} + \frac{1}{x_2} + \dots + \frac{1}{x_k} + \frac{1}{f_k} = A$。

如果用集合$x_1, \dots, x_k$对数$x_{k+1}$进行补集来解决$n = k + 1$和$x_{k+1} \neq 1$的问题，则有对应关系：

$$\frac{1}{x_1} + \dots + \frac{1}{x_k} + \frac{1}{x_{k+1}} + \frac{1}{f_k x_{k+1}} = A$$

具有相同的$A$（仔细考虑一下）。

使这两个等式的左侧相等并丢弃相同的段，我们得到

$$\frac{1}{x_{k+1}} + \frac{1}{f_k x_{k+1}} = \frac{1}{f_k};$$

跟随，$x_{k+1} = f_k + 1$。这正是解决方案的获得方式
