M463。给定自然数$x_1, x_2, \dots, x_m, y_1, y_2, \dots, y_n$。总和 $x_1 + x_2 + \dots + x_m$ 和 $y_1 + y_2 + \dots + y_n$ 彼此相等且小于 mn。证明在等式 $x_1 + x_2 + \dots + x_m = y_1 + y_2 + \dots + y_n$ 中，您可以删除一些最大项以再次获得真正的等式。

$$4 + 5 + 5 = 1 + 1 + 6 + 6 \quad (\text{неЛЬЗЯ}),$$
$$3 + 3 + 4 + 5 = 1 + 1 + 6 + 7 \quad (\text{МОЖНО})$$

让我们用 $\alpha$ 表示 Paramid 的高度与侧边缘形成的角度，用 $A, B, C, D$ 表示切割平面与侧边缘和高度的交点，用 $H$ 表示 Paramid 的顶点（图 1）。显然，长度$a, b, c$和$d$之间一定存在某种对应关系：毕竟，单个平面经过$A, B, C$这三个点，因此$d$可以通过$a, b$和$c$来表示。通过角$\alpha$表达每个三角形$AHC$和$BHD$中的公平分线$HK$的长度以及它们的边长：$a, c$（一个）和$b, d$（另一个）并将结果相等，可以获得这样的对应关系。这正是获得三角形等式的方法。

为了获得三角形 $AHC$ 中平分线 $l = |HK|$ 长度所需的公式，我们使用 $S(AHC) = S(AHK) + S(KHC)$ (图 2)。乘以 2，我们得到

$$ac \sin 2\alpha = al \sin \alpha + cl \sin \alpha,$$

在哪里

$$\frac{2\cos \alpha}{l} = \frac{1}{a} + \frac{1}{c}.$$

类似地从三角形$BHC$

$$\frac{2\cos \alpha}{l} = \frac{1}{b} + \frac{1}{d}.$$

从这里

$$\frac{1}{a} + \frac{1}{c} = \frac{1}{b} + \frac{1}{d}.$$

我们将通过归纳法进行证明 $k = m + n$。因为 $x_1 + x_2 + \dots + x_m \geq m, y_1 + y_2 + \dots + y_n \geq n$，则 mn > m，mn > n，开 $m \geq 2, n \geq 2, k \geq 4$。如果 $k = 4$， 那是 $m = n = 2, x_1 + x_2 = y_1 + y_2 < 4$，那么至少有一个数字 $x_1, x_2$ 等于 1 且至少有一个数字 $y_1, y_2$ 等于 1。所以对于 $k = 4$ 问题的陈述是正确的。让我们假设该陈述已被证明 $m = n = k$，我们将证明这一点 $m + n = k + 1$.

令 $x_1$ 为最多的数字 $x_1, x_2, \dots, x_m, y_1$ 为最多的数字 $y_1, \dots, y_n$ ($m + n = k + 1$)。如果$x_1 = y_1$，则划掉$x_1$和$y_1$。让$x_1 > y_1$。距离平等

$$(x_1 - y_1) + x_2 + \dots + x_m = y_2 + \dots + y_n,$$

(*) 包含所有 $m + n - 1 = k$ 项。为了引入归纳命题，我们需要检查$y_2 + \dots + y_n < m(n - 1)$。让我们输入$S = y_1 + y_2 + \dots + y_n$。然后 $y_1 \geq \frac{S}{n}$ 因此

$$y_2 + \dots + y_n < S - \frac{S}{n} = S \cdot \frac{n - 1}{n}.$$

从$S < mn$开始，然后$y_2 + \dots + y_n < mn \cdot \frac{n - 1}{n} = m(n - 1)$。

通过划掉等式（*）中的一些项，从而再次得到正确的等式（这可以通过归纳假设来完成）；我们得到排除或左侧包含差值 $x_1 - y_1$ 的等式。在后一种情况下，您需要将$y_1$转移到正确的部分。
