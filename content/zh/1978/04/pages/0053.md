我们得出两个方程：
$$x = a - bx^2; \quad b(x + a - bx^2) = 1.$$

进一步的解决方案非常印度。您只需要记住，该解决方案是关于带有参数的方程，并且它仔细遵循计算对参数有效的条件。最终的答案应该是这样的：
如果$ab < -1/4$，则无根；
如果$ab = -1/4$，则有一个根：$x = -1/2b$；
如果$-1/4 < ab < 0$，则有两个根：
$$x_1 = \frac{-1 - \sqrt{1 + 4ab}}{2b} \quad \text{и}$$
$$x_2 = \frac{-1 + \sqrt{1 + 4ab}}{2b};$$
如果$b = 0$，则有一个根：$x = a$；
如果$a = 0$但$b \neq 0$，则有两个根：$x = 0$和$x = -1/2$；
如果$0 < ab < 3/4$，则有两个根：$x_1$和$x_2$；
如果$ab = 3/4$，则有三个根：$x_1, x_2$和$x = 1/2b$；
如果$ab > 3/4$，则有四个根：$x_1, x_2,$
$$x_3 = \frac{1 - \sqrt{4ab - 3}}{2b} \quad \text{и}$$
$$x_4 = \frac{1 + \sqrt{4ab - 3}}{2b}.$$

当然，上述消息也适用于所考虑的方程不包含任何参数的情况。

示例 4：求解方程
$$x^2 + \sqrt{x + 5} = 5.$$

为了求解这个方程，可以方便地引入辅助未知数$z = \sqrt{x + 5}$并进入方程组$x^2 + z = 5, x + 5 = z^2$。经过估计变换后，我们得到两个无理方程
$$\sqrt{x + 5} + x = 0; \sqrt{x + 5} = x + 1,$$
由此我们得到方程(13)的两个根：
$$x_1 = \frac{1 - \sqrt{21}}{2}, \quad x_2 = \frac{\sqrt{17} - 1}{2}.$$

读者发给Shimich的方程中，很多都是通过因式分解来求解的。然而，“看到”导致期望结果的分组并不总是那么容易。下面提到的第一个方程是由 A. Ermilov（科洛姆纳，莫斯科地区）提出的，接下来的两个方程是由 L. Slukin（利佩茨克）提出的，最后一个也是最困难的，由十年级学生 Seidazim Mirtsev（阿塞拜疆苏联 Neftechala 地区 Khilly 村）提出。
