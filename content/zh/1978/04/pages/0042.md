F·巴尔梅涅夫

数学观察

当今已知的数字的特性很大程度上是通过观察发现的。

伦纳德·欧拉

通常如何研究自然法则？

物理学家、化学家和生物学家进行实验。然后他们检查测量结果，注意模式并得出某些结论。

令人惊讶的是，数学家在他们的科学工作中经常使用观察结果以及自然观察结果。为了深入理解“学校”数学并解决复杂的问题，你需要学会观察数学。

这是科学史上的一个有趣的事实。杰出数学家 K. Gauss 和 A. Kolmogorov 在童年时也遇到过类似的问题：十岁的高斯被要求求和 1 + 2 + 3 + ... + 98 + 99 + 100，六岁的柯尔莫哥洛夫被要求求和 1 + 3 + 5 + ... + 95 + 97。高斯几乎立即解决了他的问题，注意到 1 + 99 = 2 + 98 = 3 + 97 = ... 柯尔莫哥洛夫计算了 1 + 3、1 + 3 + 5、1 + 3 + 5 + 7 的和，注意到 1 = 1²、1 + 3 = 2²、1 + 3 + 5 = 3²、1 + 3 + 5 + 7 = 4²，并且很快找到了答案。

如何解决这个问题：

找到 311²² 的最后两位数字？

难道我们真的不应该计算311的28次方吗？当然不是！只需注意数字 3111 的最后两位数字是 11，数字 311² 是 21，311³ 是 31，...；所以 311²² 的最后两位数字是 81。

让我们考虑另一个类似的问题：

数字 7⁵1 是哪两位数字？

我们首先找到数字 71、72、73、7⁴ 和 7⁵ 的最后两位数字。很容易看出 7^ 只有一位数字 - 7；我们这样写：07； 7²有49，7³有43（49乘7的乘积的最后两位），7⁴有01，所以7⁵又有最后两位07。我们看到7的幂的最后两位相交，形成一个周期为4的所谓周期序列：07,49,43,01,07,49， 43、01、07、49、...
