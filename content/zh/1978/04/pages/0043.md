三，看看七的立方结果是哪两位数字：数字$7^{51}$和$7^3$具有相同的最后两位数字。所以答案是：$7^{51}$的最后两位数字是43。

让我们再解决一个与前面的问题不同的问题。

对于哪些数字，不等式成立：
$$|a| + |b| > |a + b|$$

让我们看几个例子。为此，请填写下表中的几行：

| a | b | |a|+|b| | |a+b| |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| -3 | 2 | 5 | 1 | | | |
| -7 | -1 | 8 | 8 | | | |
| 0 | -4 | 4 | 4 | | | |
| 4 | 0 | 4 | 4 | | | |
| 2 | 3 | 5 | 5 | | | |
| 7 | -1 | 8 | 6 | | | |

看看这张表，不再难猜出最后一个问题的答案应该是什么：只有当这两个数字不为零且具有不同值时，两个数字的绝对值之和才大于这些数字之和的绝对值。

当然，任何“猜测”或假设都需要严格的数学证明。我们把这个留给我们的读者。

2. 一个圆圈内有 60 个正负单位（并且两者都有）。已知任意三个连续数的乘积都是-1。求所有数字的总和。

3. 将边长为 3 厘米的正方体切成边长为 1 厘米的正方体，需要进行多少次切割？

总之，我们建议读者避免根据观察结果仓促下结论。为了证明一个陈述，你需要确保它在合并的每个部分都是正确的；同时，为了验证任何陈述，只要证明它在至少一种特定情况下是不正确的（正如数学家所说，带一个反证）就足够了。让我们解释一下我们的意思。

考虑一组 $m = n^2 + 3n + 1$ 形式的数字，其中 $n$ 是任何自然数。对于值$n = 1, 2, 3, 4$和5我们得到$m = 5, 11, 19, 29$和41，即$m$的前五个值是素数。我们是否可以得出结论，集合中的任何元素都是素数（对于任何自然数$n$）？当然不是：在 $n = 6$ 处我们已经得到了复合值 $m = 55$。

任务2。
4. 设$A$为$6n-1$形式的数集，$P$为素数集。陈述：如果 $n \in N$，$A \subset P$ 是真还是假？

5. 对于任何整数$n$，不等式$4n^2 + 40n + 99 > 0$都有效吗？

有时很难找到一个对位来定义一般性陈述。碰巧证明相应的反飞机的存在比建造它更容易。

例如，很明显，如果 100 名学童获得 101 个 terrad，并且每个学生至少获得 1 个 terrad，则有一个学童获得 2 个 terrad。

我们在上一个例子中得出结论的推理技术称为“狄利克雷普里茨”，通常应用于解决问题。让我们用它来解决以下问题：

证明您可以从 101 个数字中选择两个，其差可以被 100 整除。

事实上，除以 100 时，余数可能会得到以下数字之一：0、1、2、...、99 - 这些是不同的数字。因此，对于 101 个数，肯定有两个数除以 100 时余数相等。因此，它们的差除以 100。
