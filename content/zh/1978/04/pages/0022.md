相反，使用$n$维几何，我们可以证明内容的总数不可能是无限的；根据这个方案，这个问题于1971年被其作者、莫斯科国立大学教授亚亚解决了。 G.西奈半岛。我们将提出其他不需要多维几何知识的解决方案；该解决方案的想法是由莫斯科国立大学物理与数学学院的学生（现为莫斯科物理技术学院的学生）A. Avdeev 提出的；后来基辅大学学生 A. Reznikov 和 MSU 研究生 G. Galperin 也发现了类似的解决方案。

$1^\circ$。我们将通过归纳法对球的数量进行推理。在第 2 节中，证明对于$n = 3$，碰撞次数是有限的。让我们假设对于一组$k < n$球中的任何初始条件，在从0到$T$（其中$T$可以等于$+\infty$）的时间内，只会发生有限数量的碰撞。让我们假设对于每个初始条件 $n$，球在从 0 到 $T$ 的时间内变得无限多次。让我们按照球沿着 $Ox$ 轴的顺序调整球的大小，但从右到左。在每个时刻，考虑右侧球的总implus $k$：

$$P_k = m_1 v_1 + m_2 v_2 + \dots + m_k v_k (k = 1, 2, \dots, n)$$

每次配对碰撞时，$P_k$的值只能增加：事实上，如果$k$左侧或$(k+1)$右侧的球被打，$P_k$不会改变；如果第 $k$ 个球面向第 $(k+1)$ 个球，则第 $P_k$ 个球增加，（对于第 $(k+1)$ 个球，仅在右侧给出第 $k$ 个球）。

现在让我们用 $v_i^{(s)}$ 表示按顺序发生第 $s$ 次碰撞后第 $i$ 球的速度（其中第 $i$ 球可能不参与），用 $P_k^{(s)}$ 表示第 $s$ 次碰撞后的附加值 $P_k$。从上式可以看出，对于每个 $k$，序列 $P_k^{(s)}$ ($s = 1, 2, \dots$) 是非递减的。

另一方面，在所有碰撞期间，所有球的总动能守恒：

$$\frac{1}{2} \left( m_1 v_1^2 + m_2 v_2^2 + \dots + m_n v_n^2 \right) = E = \text{const.}$$

由此可见，对于任何时刻的每个$i$，速度都是有限的：

$$m_i v_i^2 \leq 2E \text{ и } |v_i| \leq \sqrt{2E/m} \leq \sqrt{2E/m},$$

其中$m$是质量$m_1, \dots, m_n$中最小的。这意味着每个序列 $P_k^{(s)}$ 的有界性：

$$|P_k^{(s)}| \leq m_1 |v_1^{(s)}| + \dots + m_k |v_k^{(s)}| \leq (m_1 + \dots + m_k) \sqrt{2E/m}.$$

因此，对于每个 $k$，序列 $P_k^{(s)}$ 是单调且有界的，因此，根据 Weierstrass 定理，所有这些序列在 $s \to \infty$ 都有一个极限。但是$P_1^{(s)} = m_1 v_1^{(s)}$，所以有一个限制$v_1^{(s)} = w_1$。接下来，$P_2^{(s)} = m_1 v_1^{(s)} + m_2 v_2^{(s)}$，所以有一个限制$v_2^{(s)} = w_2$（解释一下）。继续这个推理，我们推断出所有球都存在速度限制：

$$\lim_{s \to \infty} v_k^{(s)} = w_k (k = 1, 2, \dots, n).$$
