⟦folio 21⟧

$$m_k \left( \left(v_k^{(s)}\right)^2 - \left(v_k^{(s-1)}\right)^2 \right) = m_{k+1} \left( \left(v_{k+1}^{(s-1)}\right)^2 - \left(v_{k+1}^{(s)}\right)^2 \right).$$

将最后一个等式除以倒数第二个等式，我们得到对应关系
$$v_k^{(s)} + v_{k+1}^{(s-1)} = v_{k+1}^{(s-1)} + v_{k+1}^{(s)}.$$

它对无限次碰撞有效，并且可以达到 $s \to \infty$ 的极限。因此，为了限制速度，我们将有：$2w_k = 2w_{k+1}$，因此$w_k = w_{k+1}$。因此，所有最大速度彼此相等，$w_1 = w_2 = \dots = w_n = w$。

$3^\circ$。设 $v_1^0, \dots, v_n^0$ 为初始速度；那么根据动量守恒定律可以得出
$$m_1 v_1^0 + \dots + m_n v_n^0 = m_1 v_1^0 + \dots + m_n v_n^0$$
对于任意$s$。因此，传递到 $s \to \infty$ 处的极限，我们得到
$$m_1 v_1 + \dots + m_n v_n = (m_1 + \dots + m_n)w$$
其中$w$是所有速度的一般极限。因此，
$$w = \frac{m_1 v_1 + \dots + m_n v_n}{m_1 + \dots + m_n},$$
即$w$是所有球质心的运动速度。

让我们继续讨论质心系，即坐标参考系，它相对于原始参考系以$w$的速度移动。本系统中所有极限速度均为0；因此，质心系统的极限能量等于0。由于质心系统也是惯性的，能量守恒定律在其中成立，因此质心系统中小球的初始总能量等于0。这只能是当质心系统中所有初始速度都等于0时，即在原始参考系中所有初始速度都等于$w$时；但在相同的初始速度下，球之间根本不会发生碰撞——这是一个矛盾。

读者在证明初速度一致时没有考虑向质心系的转变，可以直接通过计算看出$\sum_{i=1}^{n} m_i \left(v_i^s - w\right)^2$值是守恒的（并且在$s \to \infty$处应该趋于0）。

请注意，莫斯科数学家 L. Wasserstein 和 G. Galperin 将上述推理推广到平面或空间中的球彼此绝对弹性碰撞的情况，并证明了碰撞次数的有限性。
