读者建议

编辑部«Kvant»不断收到来自小学生、老师和单纯的数学爱好者关于“申请者实习”部分主题的来信。
其中许多涉及部分问题，编辑会亲自回复作者的此类信件。但在许多信件中，讨论了学校课程的各种理论问题，提出了解决某些类型问题的方法，报告了有用的方法论评论和有趣的问题。
我们认为，向读者«Kvant»介绍此类信件的内容是有用的。
由于考虑到不可能完整地发表这些信件，编辑们决定根据信件作者的想法和建议编写一些材料，并附上必要的补充意见。我们希望筛选中提出的问题能够对申请大学有所帮助。

一如既往，社论邮件中有很多关于各种代数和三角方程和系统的信件。除了不是特别感兴趣的标准问题外，许多信件的作者还提出了其解决方案包含“热情”的方程——有必要找到一条非标准转换路径并表明对未知事物的成功替代。

这是一个方程，求解的思路是由我们的读者 M. Levin（塔林）向编辑报告的。

示例 1：求解方程

$$\sqrt{x^2 - 9x + 24} - \sqrt{6x^2 - 59x + 149} = 5 - x.$$ (1)

申请人通常通过找到未知数的可接受值的范围来开始求解无理方程。必须记住，这个操作（有时非常麻烦）并不总是需要求解方程。在许多情况下，从原始方程转向其结果，并在最后进行检查，或者更好的是转向等效方程，会更有利可图且更容易。

很明显，求解无理方程的标准示例 - 求幂 - 当应用于方程（1）时将导致耗时的计算，并且没有明显的成功希望。因此，尝试检查其他转换。

由于值$x=5$，非常印度，是方程（1）的根，那么当找到它的其他根时，我们将假设$x\neq 5$。我们将方程 (1) 两边同时除以 5 - x：

$$\frac{1}{5-x}\sqrt{x^2 - 9x + 24} - \frac{1}{5-x}\sqrt{6x^2 - 59x + 149} = 1,$$ (2)

让我们看看如果在根号下输入因子 $\frac{1}{5-x}$ 会发生什么。因为，正如代数所知，

$$a = \sqrt{a^2} \text{ при } a > 0;$$

$$a = -\sqrt{a^2} \text{ при } a < 0,$$

两种情况应分别考虑：$5-x>0$和$5-x<0$。

若$5-x>0$，即求方程（1）满足条件$x<5$的根，则方程（2）可改写为

$$\sqrt{\frac{x^2 - 9x + 24}{(5-x)^2}} - \sqrt{\frac{6x^2 - 59x + 149}{(5-x)^2}} = 1.$$ (3)

在第一个根的符号下，我们选择整个部分：

$$\frac{x^2 - 9x + 24}{(5-x)^2} = \frac{(x^2 - 10x + 25) + (x - 1)}{(5-x)^2} = 1 + \frac{x-1}{(5-x)^2}.$$

类似地，我们将分数变换到二次根的符号下；因此，方程（3）将写成以下形式

$$\sqrt{1 + \frac{x-1}{(5-x)^2}} - \sqrt{6 + \frac{x-1}{(5-x)^2}} = 1.$$

现在已经很清楚了，建议进行替换

$$\frac{x-1}{(5-x)^2} = y,$$

(4)

之后剩下的就是求解方程

$$\sqrt{1+y} - \sqrt{6+y} = 1.$$

使用一般方法，我们可以很容易地验证这个方程无根。

如果$5-x<0$，即如果我们寻找满足条件$x>5$的方程（1）的根，那么方程（2）很容易验证，可以简化为以下形式

$$-\sqrt{1 + \frac{x-1}{(5-x)^2}} + \sqrt{6 + \frac{x-1}{(5-x)^2}} = 1.$$

将式(4)代入后可得方程

$$\sqrt{6+y} = 1 + \sqrt{1+y},$$

其根是$y=3$。根据(4)，该值$y$对应于$x_1=4$和$x_2=19/3$。值$x=4$因不满足条件$5-x<0$而应被丢弃，并且值$x=19/3$是原始方程(1)的根，因为该方程在集合$x>5$上等价于方程(5)。此后的替换允许我们通过将指定值替换到原始方程中来避免未表示的检查。

因此，方程（1）有两个根：$x_1=5$和$x_2=19/3$。

下面的方程与前一个类似的方程一致（通过简单的替换），由我们的读者 A. Smolyakov（斯塔夫罗波尔边疆区 Neftekumsk）编辑。

1. 解方程

$$\frac{1}{|\cos x|} + \sqrt{6} (\lg x + 1) = 8 \sqrt{\lg x}.$$

«Kvant»，1977 年，第 3 期，第 14 页。 56-57讨论了求解方程的一种方法

$$\sqrt[3]{8x+4} - \sqrt[3]{8x-4} = 2,$$

(6)

谁用了方程两边的立方。九年级学生 Nikolai Kim（乌兹别克斯坦苏联 Sredne-Chirsky 区以 Ya. M. Sverdlov 命名的集体农场）对此出版物做出了回应。我们的读者建议以不同的方式求解方程（6）——通过引入辅助未知数。

我们引入辅助未知数$u$和$v$如下：

$$\sqrt[3]{8x+4} = u, \sqrt[3]{8x-4} = v.$$

然后，根据根的定义并基于等式（6），我们可以写出一个方程组

$$u^3 = 8x+4, v^3 = 8x-4, u-v=2,$$

(7) 且未知数$u$和$v$必须满足立方等于$a$的非负数；参见“代数 8”，第 24 段）。

方程组（7）很容易求解。事实上，如果从第一个方程中减去第二个方程：$u^3 - v^3 = 8$，然​​后使用第三个方程消除，例如，$u$，你会得到一个二次方程$v^2+2v=0$，其根为$v_1=0, v_2=-2$。使用系统（7）的第二个方程的第一个根，我们找到$x=1/2$；由于不满足条件（8），第二个根必须被丢弃。因此，原方程(6)有单根$x=1/2$。

细心的读者会很容易注意到，所提出的方法是基于一个众所周知且经常使用的想法 - 找到给定方程的未知数的成功替代。正如我们所看到的，在求解无理方程时，有时引入几个辅助未知数会很方便。

2. 求方程的根

$$\sqrt[3]{24+x} + \sqrt{12-x} = 6.$$

学生们了解到，方程通常是通过将其转换为“最简单”形式（例如，二次方程）来求解的。同时，在数学应用实例中，有时会提出问题，而解决问题首先需要逻辑推理。在这些问题中，通常，你需要“看到”使用已知函数的某些属性的可能性，应用熟悉的不等式等。在这些问题上，不仅要检查在学校学习的构造规则和公式的含义，还要检查它们的一般数学发展水平。

我们的读者 N. Belevsky（哈尔科夫）向编辑发送了两个方程组，在求解方程组时，逻辑结论发挥着重要作用。

示例 2. 求解方程组

$$\begin{cases} z^2 + 1 = 2\sqrt{xy}, \\ x^2 - 1 = 2yz\sqrt{1-4xy}. \end{cases}$$

乍一看，这个系统看起来相当奇怪：有三个未知数，但只有两个方程。但这种情况也算是一种“提示”——我们不要急于改造系统的方程，而应该首先尝试研究它们的性质。

如果将系统(9)的方程改写为$z^2 = 2\sqrt{xy} - 1$，那么，由于左边有一个非负表达式，我们可以得出$2\sqrt{xy} - 1 \geq 0$，由此

$$1 - 4xy \leq 0.$$

另一方面，从系统（9）的第二个方程可以清楚地看出，未知数$x$和$y$的允许值必须满足不等式

$$1 - 4xy \geq 0.$$

比较对应关系（10）和（11）表明系统（9）的解只能是三元数$(x, y, z)$使得$4xy = 1$。但是，从系统的第一个方程我们得到$z = 0$，从第二个方程得出$x_1 = 1$，$x_2 = -1$。

这样，我们就得到了两个三元组$x_1 = 1$，$y_1 = 1/4$，$z_1 = 0$； $x_2 = -1$、$y_2 = -1/4$、$z_2 = 0$，单独即可求解系统 (9)。我们强调，从执行的计算来看，并不意味着找到的三元组确实是系统（9）的解；这一事实必须通过直接代入原始系统来证明。

我们将第二个系统作为方程提供给读者。

示例 3：求解方程

$$x = a - b(a - bx^2)^2.$$

如果您打开括号并注意到更好的方程可以被视为二次相对 $a$，则这个方程（相对未知数 $x$ 的四次方）很容易求解。然而，一种稍微不同的消除疑惑的方法也能实现这一目标。

让我们引入辅助未知数$z = a - bx^2$。然后，您需要求解方程组，而不是方程 (12)

$$x = a - bz^2, \quad z = a - bx^2.$$

从系统的第一个方程中减去第二个方程，我们得到等式$x = z$，$b(x + z) = 1$；排除辅助未知数后

我们得出两个方程：
$$x = a - bx^2; \quad b(x + a - bx^2) = 1.$$

进一步的解决方案非常印度。您只需要记住，该解决方案是关于带有参数的方程，并且它仔细遵循计算对参数有效的条件。最终的答案应该是这样的：
如果$ab < -1/4$，则无根；
如果$ab = -1/4$，则有一个根：$x = -1/2b$；
如果$-1/4 < ab < 0$，则有两个根：
$$x_1 = \frac{-1 - \sqrt{1 + 4ab}}{2b} \quad \text{и}$$
$$x_2 = \frac{-1 + \sqrt{1 + 4ab}}{2b};$$
如果$b = 0$，则有一个根：$x = a$；
如果$a = 0$但$b \neq 0$，则有两个根：$x = 0$和$x = -1/2$；
如果$0 < ab < 3/4$，则有两个根：$x_1$和$x_2$；
如果$ab = 3/4$，则有三个根：$x_1, x_2$和$x = 1/2b$；
如果$ab > 3/4$，则有四个根：$x_1, x_2,$
$$x_3 = \frac{1 - \sqrt{4ab - 3}}{2b} \quad \text{и}$$
$$x_4 = \frac{1 + \sqrt{4ab - 3}}{2b}.$$

当然，上述消息也适用于所考虑的方程不包含任何参数的情况。
