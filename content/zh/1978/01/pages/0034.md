（例如 $a_1, a_2, \dots, a_n$ - 实数 $k_1, k_2, \dots, k_n$ - 自然数）最多有 $n$ 正根。

c) 证明方程
$$ax^k(x+1)^p + bx^l(x+1)^q + cx^m(x+1)^r = 1$$
（食物 $a, b, c$ - 实数 $k, l, m, p, q, r$ - 自然数）的正根不超过 14 个。

图 5.

将方程 $(1')$ 乘以 $(-a_n x^k n^{-1})$，我们得到方程
$$b_1 x^{k_1}-k_n + b_2 x^{k_2}-k_n + \dots + b_{n-1} x^{k_n-1}-k_n = 1$$
（有超过 $n-1$ 个正根）。对方程 $(2)$ 两边求导，可得方程
$$\bar{b}_1 x^{k_1}-k_n-1 + \bar{b}_2 x^{k_2}-k_n-1 + \dots + \bar{b}_{n-1} x^{k_n-1}-k_n-1 = 0$$
（有超过 $n-2$ 个正根）。执行这些步骤$n-1$次后，我们得出方程
$$\alpha x^m = 1, (m = k_1-k_2),$$

由于对方程 $(1)$ 所做的假设，它必须有多个正根。但这是不可能的；这意味着原始方程 $(1)$ 不能有超过 $n$ 个正根。问题6)的陈述已被证明。

让我们继续讨论问题 c)。我们需要以下事实。

令 $P_m(x)$ 为$x$ 次$m$ 的多项式。那么任意表达式 $x^k(x+1)^p P_m(x)$ 的形式为
$$x^{k-1}(x+1)^{p-1} P_{m+1}(x),$$，其中$P_{m+1}(x)$是$x$次数$m+1$的多项式（$k$和$p$是任何实数）。真的吗，

$$(x^k(x+1)^p P_m(x))' = kx^{k-1}(x+1)^p P_m(x) +$$
$$+ px^k(x+1)^{p-1} P_m(x) + x^k(x+1)^p P'_m(x) =$$
$$= x^{k-1}(x+1)^{p-1} [k(x+1)P_m(x) + pxP_m(x) +$$
$$+ x(x+1)P'_m(x)] = x^{k-1}(x+1)^{p-1} P_{m+1}(x),$$

其中 $P_{m+1}(x)$ 是次数为 $m+1$ 的多项式，写在方括号中（回想一下，多项式 $P'_m(x)$ 的次数等于 $m-1$）。

现在假设方程
$$ax^k(x+1)^p + bx^l(x+1)^q + cx^m(x+1)^r = 1$$
（有超过 14 个正根）。那么，就像问题6）一样，将其两部分微分得到的方程有超过13个正根。该方程将具有以下形式（参见上面证明的微分）：

$$x^{k-1}(x+1)^{p-1} A_1(x) + x^{l-1}(x+1)^{q-1} B_1(x) +$$
$$+ x^{m-1}(x+1)^{r-1} C_1(x) = 0$$
（数字$k, p, l, q, m, r$可以是任何实数；$A_1(x), B_1(x), C_1(x)$是一次多项式）。

将方程两边$(4')$除以$x^{m-1}(x+1)^{r-1}$（这是一个“合法”运算：我们只对正根感兴趣！），我们得到方程
$$x^{k-m}(x+1)^{p-r} A_1(x) + x^{l-m}(x+1)^{q-r} B_1(x) + C_1(x) = 0$$
（有超过 13 个正根）。将等式$(4'')$两边展开两次，得到等式
$$x^{k-m-2}(x+1)^{p-r-2} A_3(x) + x^{l-m-2}(x+1)^{q-r-2} B_3(x) = 0$$
（有超过 11 个正根（想想看！）将方程两边 $(5)$ 除以 $x^{l-m-2}(x+1)^{q-r-2}$ 得到方程
$$x^{k-l}(x+1)^{p-q} A_3(x) + B_3(x) = 0$$
（有超过 12 个正根）。将方程两边扩大$(5')$$x^{l-m-2}(x+1)^{q-r-2}$，得方程
$$x^{k-l}(x+1)^{p-q} A_3(x) + B_3(x) = 0$$
