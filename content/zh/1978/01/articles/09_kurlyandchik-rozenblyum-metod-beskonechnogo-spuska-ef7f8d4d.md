无限下降法

哪个无理数本身是“旧的”？毫无疑问，$\sqrt{2}$。我们不知道到底是谁第一个证明了这个数字的不合理性，但我们确信它是这样做的。

第一个的证明

让我们假设数字$\sqrt{2}$是无理数。从几何角度来说，这意味着长度为$c$的正方形的对角线与其长度$a$的边相当，也就是说，它将找到长度为$d$的线段以及整数$m$和$n$，使得$c=dm$，$a=dn$。让我们在对角线 $AC$ 上标记 $m-1$ 点，在边 $DC$ 上标记 $n-1$ 点，将这些线段分成长度为 $d$ 的片段。让我们把$|AC|$处的线段$AK: |AK|=|AD|;$和$|DC|$处的线段$DE: |DE|=|KC|$放在一边。点$K$和$E$将落入偏移点

证明二

$\sqrt{2}$的无理数意味着方程$x^2=2y^2$在自然数$x, y$中无解。假设存在这样的解，$x=m$、$y=n$就是其中之一。

从方程可知$m$是偶数，$m=2m_1$。将$m=2m_1$代入方程，可得$n^2=2m_1^2$，即$x=n$、$y=m_1$也是解。让我们注意$n<m$，$m_1<n$。现在很清楚$n$是偶数，$n=2n_1$，因此$m_1^2=2n_1^2$。因此

立刻，$x = m_1, y = n_1$是方程的解，$m_1 < n, n_1 < m_1$。我们可以用同样的方式进一步构建，获得方程的越来越小的解。但这里已经存在矛盾了。毕竟，所有数字$m, n, m_1, n_1, \dots$都是自然数，$m > n > m_1 > n_1 > \dots$，并且不可能存在自然数的无限递减序列！这意味着我们的假设是错误的，$\sqrt{2}$是无理数。

这两个论点本质上都遵循相同的模式：假设问题有解决方案，我们构建了某种无尽的过程，而根据问题的真正含义，这个过程应该在某个地方结束。这种方法称为无限下降法$^*$。

通常，下降法以更简单的形式使用。假设我们已经添加了该过程的自然结束，我们发现它无法“停​​止”。

证明三

令 $x = m, y = n$ 为方程 $x^2 = 2y^2$ 的解，其中 $x$ 尽可能最小。数字 $m$ 必须是偶数，$m = 2m_1$，因此 $x = n, y = m_1$ 也是我们方程的解。然而，$m > n$，这与选择解决方案$m, n$作为“最小”相矛盾。

从这个版本的证明可以清楚地看出，下降法是数学归纳法的平均方法。这两种方法都基于这样一个事实：任何无限的自然数集都具有最小元素。下降法对于证明定理的“否定”最为方便。

问题中的下降法

问题1.证明自然数方程的不可解性

$$8x^4 + 4y^4 + 2z^4 = t^4.$$

*) 无限下降法显然是由一位古希腊数学家发明的。我们有理由相信费马正是试图用这种方法来证明他的大定理。

解决方案。假设有一个解，$x = m, y = n, z = p, t = r$是$x$最小的解。从方程中我们可以看出$r$是偶数，$r = 2r_1$。

将这个解代入方程并乘以 2，我们得到

$$4m^4 + 2n^4 + p^4 = 8r_1^4.$$

现在很清楚$p$是偶数，$p = 2p_1$，因此

$$2m^4 + n^4 + 8p_1^4 = 4r_1^4.$$

然后它的工作方式相同：$n = 2n_1$，$m^4 + 8n_1^4 + 4p_1^4 = 2r_1^4$。

最后，$m = 2m_1$，$8m_1^4 + 4n_1^4 + 2p_1^4 = r_1^4$。

因此，$x = m_1, y = n_1, z = p_1, t = r_1$是我们方程的解。但它是$m_1 < m$！我们收到了一个矛盾，选择解决方案$m, n, p, r$为“最小”。

让我们把问题考虑得更复杂一些。

问题2.证明自然数方程的不可解性

$$x^2 + y^2 + z^2 + u^2 = 2xyzu.$$

解决方案。令 $x, y, z, u$ 为解。

由于$x^2 + y^2 + z^2 + u^2$是偶数，那么平均数$x, y, z, u$是奇数的偶数个，即要么是偶数，要么是两个，要么是零。如果所有数字都是奇数，则 $x^2 + y^2 + z^2 + u^2$ 不能被 4 整除，$2xyzu$ 也不能被 4 整除。如果只有两个奇数，则$x^2 + y^2 + z^2 + u^2$不能被4整除，但$2xyzu$可以被4整除。因此所有数字，即$x = 2x_1, y = 2y_1, z = 2z_1, u = 2u_1$。将这些值代入方程，我们得到

$$x_1^2 + y_1^2 + z_1^2 + u_1^2 = 8x_1y_1z_1u_1.$$

和之前一样，我们看到所有偶数都不可能是奇数，否则$x_1^2 + y_1^2 + z_1^2 + u_1^2$不能被8整除。同样，偶数也不可能是奇数，或者偶数则$x_1^2 + y_1^2 + z_1^2 + u_1^2$不能被8整除。所以，我们得到所有数字都是奇数，即

$$x_1 = 2x_2, y_1 = 2y_2, z_1 = 2z_2, u_1 = 2u_2.$$

这是一个具有无限多个解的方程，但使用相同的方法对其进行研究。

问题 3. 求方程的所有自然数解

$$x^2 - 2y^2 = 1.$$

解决方案e.显然，$x_1 = 3, y_1 = 2$是该方程的解。让我们证明，如果x，y对是一个解，那么3x + 4y对； 2x + 3y 也是一个解决方案。以下是阐述

$$(3x + 4y)^2 - 2(2x + 3y)^2 = x^2 - 2y^2.$$

因此，

$$x_2 = 3 \cdot 3 + 4 \cdot 2 = 17,$$

$$y_2 = 2 \cdot 3 + 3 \cdot 2 = 12;$$

$$x_3 = 99, y_3 = 70,$$等等。

我们表示解的无限序列$x_1, y_1; x_2, y_2; \dots$现在让我们证明没有其他数字满足该方程。

设 x, y 为某个解。在这种情况下，3x - 4y、3y - 2x 也是一个解决方案，或者

$$(3x - 4y)^2 - 2(3y - 2x)^2 = x^2 - 2y^2.$$

从条件 9 = 9x^2 - 18y^2 > -2y^2 可以得出 3x > 4y；对于 y > 2，从条件 4 = 4x^2 - 8y^2 < y^2 可以得出 3y > 2x。也就是说，对于 y > 2，从解 x、y 我们得到自然数解 $x^{(1)}, y^{(1)}$ 和 $x^{(1)} < x, y^{(1)} < y$。由于这个过程不能无限地继续下去（任何非空自然数集都有一个最小的元素！），那么有一天我们会得到解$x^{(n)}, y^{(n)}$，其中$y^{(n)} \leqslant 2$。既然$y^{(n)}$显然不能等于1，那么$y^{(n)} = 2$。所以，$x^{(n)} = 3$。

这意味着数字 x 和 y 属于之前构建的序列。

到目前为止我们只考虑了方程。让我们用“文本”方法来解决这个问题。

问题 4. 有 2n + 1 个数字，每个数字的重量均为整数克。已知其中任意2n个都可以分解为多个权重，每个权重n个，从而达到平衡。证明所有数字的权重相等。

解决方案e.很明显，所有权重同时具有偶数或奇数权重：任何 2n 个权重的权重都是偶数。现在让我们从最轻的重量（或者最轻的重量，如果有多个重量）的重量中减去所有重量的重量。新的权重系统非常印度化，也满足了问题的条件，并且权重中存在零权重的“权重”。因此，我们再次发现所有权重的权重是偶数，依此类推。从“无限下降”可知，所有“权重”均为零，这意味着所有初始权重具有相同的权重。

无限下降的思想使我们能够解决几何组合器的非几何问题。

问题 5. 是否可以将一个立方体切成不同的 Neotorko 杯子？

解决方案e.让我们首先说一句话​​。将正方形 P 分成有限个不同的正方形。那么最小的正方形不与正方形P的边界相邻。

现在我们假设立方体Q已经被切割成不同的立方体Q_j；设 P 为 Q 的一个面。与 P 相邻的立方体 Q_j 将 P 划分为两两不同的正方形。设P_1是这些正方形中最小的，Q_1是对应于P的边界的，因此它被大正方形包围。相应的立方体形成一个“井”，立方体 Q_1 位于其中。

问题 6. 给定一张终端纸。证明对于 $n \neq 4$ 不存在顶点位于节点的正则 $n$ 街道。事实上，令 $a$ 为该三角形的边长；那么根据毕达哥拉斯定理$a^2$是一个整数。三角形的面积为$\frac{a^2 \sqrt{3}}{4}$，即无理数。另一方面，非常重要的是任何在节点处具有顶点的多边形的面积是有理数的。

由于正六边形可以写成顶点位于其顶点的正三角形，因此对于 $n=6$ 也可证明该命题。

让$n \neq 3,4,6$。让我们假设 $P_1, P_2, \dots, P_n$ 是一个 $n$-walker，其顶点位于节点处。让我们从点 $P_1, P_2, \dots, P_n$ 绘制对应于向量 $\overrightarrow{P_2}P_3; \overrightarrow{P_3}P_4; \dots, \overrightarrow{P_1}P_2$ (图 2) 的向量。新的点将再次落入格子节点中，并在第一个相等的格子内形成规则的 $n$ 空间。通过新的$n$-撤退，您可以无休止地建造相同的东西。然而，$n$步行器的边长的平方是一个整数，并且在我们的构造中它一直在减小！
