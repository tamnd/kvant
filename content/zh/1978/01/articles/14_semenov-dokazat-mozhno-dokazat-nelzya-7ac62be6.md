⟦folio 38⟧

E·谢苗诺夫
你能证明吗？
- 这是无法证明的！

- 爸爸，啊，爸爸！松鼠吃松子吗？
- 是的，女儿。
- 雪松是草的一种吗？
- 你在说什么啊，塔纽莎！雪松是一棵树！
- 如果我的松鼠不是木偶，而是真人，我会把它带到森林里，如果这只松鼠跳到某棵树上，那么它就是一棵雪松。
（摘自小谭雨莎的对话）

很难说我们在什么年龄开始从事证据工作。也许从我们开始犯错误并试图讲述错误的时候开始，当我们把我们的娃娃变成童话故事中的英雄，将儿童的幻想“与成人的现实”混合在一起的时候。刚才引用的对话就是一个例子。您可能注意到，小塔尼娅的谈话包含（也许是她一生中的第一个）证据。看，她相信：
1) 松鼠吃松子；
2) 雪松是一棵树；
3) 一只松鼠爬上了这棵树。

在此基础上，塔尼娅选择这棵树是雪松。诚然，塔尼娅的结论是错误的。为了使这个选择正确，还需要一个条件：

4) 如果这棵树不是雪松，那么松鼠就不会爬上那棵树（否则：在所有树中，松鼠会爬到雪松上）。

然而，让我们从另一面看一下塔尼诺的证明。她列出了三种可以使用的条件。是否有可能基于它们而不使用任何其他条件来证明最终的选择？ - 当然不是！反驳又怎样？ - 也不！可能松鼠爬上的树是雪松，那么结论是正确的，但松鼠也可能在岸上有权力，那么结论就是错误的。数学家会说塔尼娅的结论与她的三个条件无关。

然而……即使年纪较大，我们有时也会犯类似的错误。您还有疑问吗？然后听听这个故事

⟦folio 39⟧

当我们六年级学生斯特帕·莫什金（Stepa Moshkin）和他的朋友们学习几何时，就发生了这样的事情。

1. 斯乔帕和他的朋友们正在寻找证据

——距离的第三个属性很可疑！为什么它在没有证据的情况下给出？它们中的每一个都可以使用距离的前两个属性来证明！ ——斯乔帕若有所思地说。

第二天，斯乔帕的所有朋友都被他的想法迷住了，都这么做了。他们的努力没有针对性：很快就发现了一些证据。

首先，让我们提醒读者距离的属性。正如你所记得的，他们一共有三个。

1. 如果 A 点到 B 点的距离不同则为正，如果相同则为零：

$$|AB| > 0, \text{ если } A \neq B, \text{ и } |AB| = 0, \text{ если } A = B.$$

2. A 点到 B 点的距离等于 B 点到 A 点的距离：

$$|AB| = |BA|.$$

3. 对于任意三点 A、B、C，A 到 C 的距离不大于（小于或等于）A 到 B 和 B 到 C 的距离之和：

$$|AC| \leq |AB| + |BC|.$$

现在来了解一下斯乔帕和他的朋友们的证明之一。

需要证明对于任意三点A、B、C，有以下不等式成立：

$$|AC| \leq |AB| + |BC|.$$

假设它不是罂粟。让

$$|AC| > |AB| + |BC|.$$

(*) 由于 A、B、C 是任意三点，因此我们可以假设，例如，B 点与 C 重合，A 点与 B 不同：B = C，A ≠ B。在这种情况下 |BC| = 0（无属性 1），然后从 (*) 我们得到 |AC| > |AB|。另一方面，由于 B 点和 C 点重合，|AC| = |AB|。我们遇到了一个矛盾：|AC| > |AB|和|AC| = |AB|。因此，假设|AC| > |AB| + |BC|，不正确。当然，我们仍然是|AC| ≤|AB| + |BC|，即满足性质3！

斯乔帕·莫什金和他的朋友们很高兴。距离第三属性的证明已经找到了！而且，这个证明只使用了第一个属性！因此，一个新的想法是：是否不可能使用距离的第一个属性来证明距离的第二个属性？ “数学社”斯蒂奥帕·莫什金满意地开始工作。如果没有彼得·伊万诺维奇，我们不知道这一切会在何时、如何结束。

2. 没有证据！

在下一堂几何课上，斯乔帕和他的朋友们向彼得·伊万诺维奇介绍了他们发现的证据。他认真地听着他们的话，说道。

- 你知道，你的每一项证据都存在错误。但这还不是最重要的。我可以在不提供你的证据的情况下给出这样的答案。您无法使用距离的前两个属性来证明第三个属性！

- 如何！ -斯乔帕惊呼道。 - 这是不可能的！而如果之前——

⟦folio 40⟧

证据是别人提出来的吗？……嗯，比如十年级的学生？……还是某个科学家、院士？！

- 朋友们，没有科学家会这样做，因为他事先知道这种记录是不可能的。如果一个十年级的学生足够了解数学，他就不会做出这样的尝试。

每个人都用责备的目光看着斯乔帕。他必须让他们参与到这件毫无希望的事情中来。浪费了这么多时间！还有如此悲伤的结局。我们无法同意立即联系彼得·伊万诺维奇！

- 别难过！ - 彼得·伊万诺维奇说。 - 你并不孤单地遭遇“失败”。两千多年来，世界上许多著名和才华横溢的数学家都记录了欧几里得的并行公理。此外，尼古拉·伊万诺维奇·洛巴切夫斯基首先尝试这样做。并且直到过去才确定不可能根据欧几里得的其他公理来证明该公理。现在将你几天的劳动与两千年的劳动进行比较！您是否发现，与许多毕生致力于证明并行性公理的数学家的努力相比，您的服务是多么微不足道？

3. 难道无法证明吗？ - 为什么？

- 但是，你怎么能发现证明是不可能的呢？ ——班上所有的学生都同时发言，甚至包括那些不是在寻找距离第三属性文件的学生。

“首先，”彼得·伊万诺维奇开始说道，“不要认为距离是借助尺子获得的强制性的东西。”毕竟，距离公理对此没有任何说明！为什么不假设距离可以在交通的帮助下改变，比如以度为单位呢？距离公理禁止这样做吗？是的，您将首先以分钟为单位更改距离 - 从家到学校 10 分钟。因此，现在我们将构建一个模型，其中距离的属性 1 和 2 将得到满足，但属性 3 将不会得到满足。

想象一下这样一个奇妙的情况。城市（位面）居住着极其懒惰的生物。他们不去上班、不去看电影、不互相拜访，他们只是互相打电话。而且，从A点到B点、从B点到A点只需3分钟。从A、B出发，1分钟内即可到达任意地点。从A、B以外的任意地点出发，也可以在1分钟内到达任意其他地点。从任何一点你都可以在零时间内“到达”它。

对于这种懒人来说，从一个点到另一个点的距离就是从第一个点调用到第二个点所需的时间。

查看这座奇妙城市的跑步距离。你看到了吗？第一次和第二次处决，但第三次 - 没有。例如，$|AB| > |AC| + |CB|$，从$|AB| = 3$开始，$|AC| + |CB| = 1+1=2$。

⟦folio 41⟧

“好了，现在我们可以得出结论了。”老师说道。 ——“用前两个性质证明距离的第三个性质”是什么意思？

“这意味着证明如果性质1和性质2满足，那么性质3也满足。”斯乔帕立即为大家解答。

— 在考虑模型时，满足属性 1 和 2，但不满足属性 3。这意味着不可能用性质1和2来证明性质3！属性 3 独立于属性 1 和 2。

4. 新型号

您可能很想知道 Styopa 和他的朋友是否已经使用距离的第一个属性证明了距离的第二个属性？这样的证据存在吗？

接受“教训”后，斯乔帕·莫什金的“数学会”开始行动更加谨慎。其成员意识到，做数学不仅涉及证明证明，还涉及发现：它们是否存在？首先，这些人决定尝试建立一个模型，在该模型中，距离的第一个属性可以满足，但第二个属性则不能。幸运的是，没有证据证明第二个属性是基于第一个属性的。他们很幸运。这是他们构建的“电话”模型：$|AB| = 2, |BA| = 1, |AC| = |CA| = |BC| = |CB| = 1$。显然，该模型中的所有点都满足距离的第一个属性。然而，对于这一点

$A$和$B$不满足第二个性质：$|AB| \neq |BA|$。因此，距离的第二个属性独立于第一个属性。

5. 结语

这就是发生在六年级学生斯特帕·莫什金身上的另一个故事的结局。你认为他在这之后平静下来了吗？错误的！ Styopa为你准备了任务！

敦促
1. 找出距离第三个性质的“证明”中的错误。
2. 找出 Stepa 和他的朋友建立的模型是否满足距离的第三个属性。
3. 取两个不同的点$A$和$B$。我们假设$|AB| = 1, |BA| = 3$。考虑任何其他非重合点之间的距离等于 1，重合点之间的距离为 0。使用此模型，独立于第一个属性证明距离的第二个和第三个属性。
4. 通过构建适当的模型来证明距离的第二个属性独立于第三个属性。
5. 画一个三角形$ABC$使得$\hat{C} = 100^\circ, \hat{A} = 30^\circ, \hat{B} = 50^\circ$。对于三角形两个顶点之间的距离，在第三个顶点处形成角度的技巧是：$|AB| = 100, |AC| = 50, |BC| = 30$。任何其他不同点之间的距离将被视为等于 1，重合点之间的距离将被视为等于 0。使用此模型使用距离的前两个属性独立证明第三个属性。
