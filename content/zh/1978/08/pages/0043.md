⟦folio 41⟧

仅对半径为 $R$ 的球所带的电荷有用（没有带电层在其内部产生电场）。该电荷 $Q_1 = \frac{4}{3} \pi R^3$ 产生强度为 $E = \frac{Q_1}{4 \pi \varepsilon_0 R^2} = \frac{\rho R}{3 \varepsilon_0}$ 的场。

带电球场的 $E$ 与 $R$ 的关系图显示在 图 7 黑线上。

球外部带电球的场电势等于放置在球中心的确切电荷 $Q$ 的场电势：$\varphi = \frac{Q}{4 \pi \varepsilon_0 R} = \frac{\rho R_0^3}{3 \varepsilon_0 R}$。

在球的表面$\varphi = \frac{\rho R_0^2}{3 \varepsilon_0}$，当它接近球的中心时，电势增加​​：电场从球内考虑的点穿过其表面上的单位电荷所做的功被添加。该功等于所考虑区域的平均场强乘以单位电荷的移动。由于球内的张力呈线性变化，

$$E_{cp} = \frac{E_R + E_{R0}}{2} = \frac{\rho (R + R_0)}{6 \varepsilon_0}.$$

那么球内的场势等于

$$\varphi = \frac{\rho R_0^2}{3 \varepsilon_0} + E_{cp} (R_0 - R) = \frac{\rho R_0^2}{3 \varepsilon_0} + \frac{\rho (R_0^2 - R^2)}{6 \varepsilon_0} = \frac{\rho (3 R_0^2 - R^2)}{6 \varepsilon_0}.$$

对应的图形如图8黑线所示。

为了构建系统势$\varphi$场对$R$的依赖性图，需要将分别为球体和球体的场构建的图相加。在 图 8 处，该图的结果用红线显示。

仍然需要找到球体上 $q$ 电荷的大小。由于球体发生了位移，因此其电势为零。这意味着在球体表面上，在 $R = r$ 处，系统的场势为零：

$$\frac{q}{4 \pi \varepsilon_0 r} + \frac{\rho R_0^2}{3 \varepsilon_0} + \frac{\rho (R_0^2 - r^2)}{6 \varepsilon_0} = 0.$$

从这里

$$q = -\frac{2}{3} \pi r \left( 3 R_0^2 - r^2 \right).$$

◆

让我们考虑最简单的弹簧摆：质量负载 $M$，连接到刚度弹簧 $k$。当这样的摆振荡时，满足能量守恒定律：

$$\frac{M v^2}{2} + \frac{k x^2}{2} = \text{const},$$

其中$v$是速度，$x$是负载的混合。在这种振荡期间，也满足系数守恒定律

$$T = 2 \pi \sqrt{\frac{M}{k}}.$$
