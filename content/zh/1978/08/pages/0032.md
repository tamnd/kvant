图 5.

三角形 ABC 的 AC 边，BC 边上的 Q 点。

我们来求角度$PY_1X_1$和$QX_1Y_1$的值。由于$Z\hat{X}_1Y_1 = 60^\circ$（等边三角形的内角）、$Z\hat{X}_1B = X_1\hat{Z}U + X_1\hat{U}Z = 30^\circ + (30^\circ + \gamma)$（外角$\Delta ZX_1U$）和$Q\hat{X}_1B \cong Z\hat{X}_1B$（这些角关于直线BU对称），

$$Q\hat{X}_1Y_1 = 360^\circ - 60^\circ - (60^\circ + \gamma) - (60^\circ + \gamma) = 180^\circ - 2\gamma.$$

等式$PY_1X_1 = 180^\circ - 2\gamma$以完全相同的方式证明。

因此，$P\hat{Y}_1X_1 = Q\hat{X}_1Y_1$；另外，$[PY_1] \cong [Y_1Z] \cong [ZX_1] \cong [X_1Q]$（相对于直线 AU 的前两个对称线段，以及相对于直线 BU 的后两个对称线段）。由此可见，四边形 $PY_1X_1Q$ 是等边葡萄形（角 $Y_1$ 和 $X_1$ 等于 $180^\circ - 2\gamma$，因此角 P 和 Q 等于 $2\gamma$）。

现在让我们围绕梯形 $PY_1X_1Q$ 描述一个圆。由于该圆的弦$[PY_1]$、$[Y_1X_1]$和$[X_1Q]$全等，因此这些弦所对的内接角也全等；因此$P\hat{QY}_1 = Y_1\hat{PX}_1 = \hat{X}_1PQ = \gamma$。但是$P\hat{CQ} = 3\gamma$；

以位姿方式围绕 $PY_1X_1Q$ 描述的圆 S 也将经过点 C。 现在，从圆 S 的每个 $PY_1$、$Y_1X_1$ 和 $X_1Q$ 的全等（减去全等弦）可以得出 $P\hat{CY}_1 = Y_1\hat{CX}_1 = X_1\hat{CQ} = \gamma$，这意味着 $\Delta X_1Y_1Z$ 与 $\Delta XYZ$ 重合。

这样就完成了莫利定理的证明。

第二个证明（计算-它接近 M. Satyanarayan 的证明）。我们继续假设$\hat{A} = 3\alpha$，$\hat{B} = 3\beta$，$\hat{C} = 3\gamma$；我们用 a、b 和 c 表示三角形 ABC 的边 BC、CA 和 AB 的长度，用 d (图 6) 表示其外接圆的直径。

让我们尝试计算三角形 XYZ 的边 $[XY]$ 的长度 $|XY| = z$。为此，我们首先要找到线段 $|CX| = m$ 和 $|CY| = n$；之后，由$\Delta CXY$通过余弦定理即可求出$|XY|$。为了计算 m 和 n，我们使用正弦定理。将这个定理从边 $|AC| = b$ 和 $|CY| = n$ 以及角度 $\hat{A} = \alpha$、$\hat{C} = \gamma$ 和 $\hat{Y} = 180^\circ - (\alpha + \gamma) = 180^\circ - (60^\circ - \beta) = 120^\circ + \beta$ 应用于$\Delta AYC$（这里我们再次使用估计的等式 $\alpha + \beta + \gamma = 60^\circ$），我们得到

$$\frac{n}{\sin \alpha} = \frac{b}{\sin (120^\circ + \beta)}$$

或者

$$n = b \sin \alpha / \sin (120^\circ + \beta).$$

但凭借相同的正弦定理（我们现在将其应用于“大”$\Delta ABC$）

$$b / \sin \hat{B} = d$$

或者

$$b = d \sin \hat{B} = d \sin 3\beta.$$

POS 那

$$n = d \sin \alpha \sin 3\beta / \sin (120^\circ + \beta) = d \sin \alpha \sin 3\beta / \sin (60^\circ - \beta).$$
