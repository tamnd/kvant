费马做出了这样的推理。令 $x = x + \varepsilon$ 为 $x$ 的新值。那么函数$z$的新值$z$可以表示为
$$z = (x + \varepsilon)(C - x - \varepsilon) = Cx - x^2 - 2x\varepsilon + C\varepsilon - \varepsilon^2.$$
让我们找出 $z$ 和 $z$ 之间的差异。
$$z - z = -2x\varepsilon + C\varepsilon - \varepsilon^2.$$
$z - z$ 与 $\varepsilon$ 之比是角度 $\varphi$ (图 3) 的正切：
$$tg\varphi = \frac{z - z}{\varepsilon} = \frac{-2x\varepsilon + C\varepsilon - \varepsilon^2}{\varepsilon} = C - 2x - \varepsilon.$$

如果 $\varepsilon$ 非常小，则割线 $AB$ 与曲线 $z = x(C - x)$ 在点 $x$ 的切线无法区分。切线$\varphi$成为切线与水平面的倾斜角的正切。为了获得该切线的倾斜角的正切，我们将 $\varepsilon = 0$ 放入最后一个表达式中；我们会得到
$$tg\varphi = C - 2x.$$
仍然需要将该切线等于零（因为在最大点处切线是水平的 - 参见 图 3）：
$$C - 2x = 0,$$
我们得到解决方案：$x = C/2$。事实上，对于给定的总和，当两个数字彼此相等时，两个数字的乘积变得最大。或者，用几何学的语言来说，在所有给定周长的矩形中，正方形的面积最大。

应该做什么？在公式 (*) 中，必须达到 $\varepsilon \rightarrow 0$ 处的极限：

$$tg\varphi = \lim_{\varepsilon \rightarrow 0} \frac{-2x\varepsilon + C\varepsilon - \varepsilon^2}{\varepsilon} = C - 2x.$$

莱布尼茨通过$z'$调用数量$\lim_{\varepsilon \rightarrow 0} \frac{z - z}{\varepsilon}$。在我们的例子中，将 $z'$ 等于零，我们得到相同的结果：$x = C/2$。因此，从算法的角度来看，费马的方法类似于将任意一等于零，但这种方法缺乏严谨性。
