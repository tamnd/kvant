研究$P(x, y, \dots) = 0$形式方程的整数解的数论领域称为丢番图分析，其中$P(x, y, \dots)$是具有整数系数的多个变量的多项式，这些方程本身也称为丢番图分析。

它们以著名的希腊数学家丢番图 (Diophantus) 命名，他生活在公元 3 世纪，撰写了第一篇关于此类方程的论文。

尽管丢番图方程是数学最古老的领域之一，

解决这些问题的通用方法最近才出现。在经典著作中，主要考虑线性和二次丢番图方程。由于其他数学领域（主要是几何学和拓扑学）对数论的广泛参与，更复杂方程的求解在过去 20-25 年中取得了巨大进步。用 N. Bourbaki 的话来说，“……经典几何……正在变成所有数学的通用语言，具有非凡的灵活性和便利性。”几何不仅提供语言，还提供它的构造和直觉。

我们将再次使用圆的例子来展示第二个。让我们在圆上取两个有理点 - 例如 $P_1$ (3/5, 4/5) 和 $P_2$ (5/13, 12/13)。设$\alpha_1$和$\alpha_2$为点$P_1$和$P_2$对应的角度。对应于角度 $\alpha_1 + \alpha_2$ 的点也将是有理数，因为

$$\cos(\alpha_1 + \alpha_2) = \cos \alpha_1 \cos \alpha_2 - \sin \alpha_1 \sin \alpha_2, \sin(\alpha_1 + \alpha_2) = \sin \alpha_1 \cos \alpha_2 + \cos \alpha_1 \sin \alpha_2.$$

这样，我们就可以利用公式$(u_1; v_1) \oplus (u_2; v_2) = (u_1 u_2 - v_1 v_2; u_1 v_2 + u_2 v_1)$在圆上“添加”有理点，得到新的有理点。圆的这一特性是许多美丽问题的基础。

事实证明，还存在具有以下性质的曲线：其上的点可以“相加”，有理点的“和”就是有理点。对于这样的曲线，有时可以从两个有理点“拉伸”出一系列新的有理点。

我们以曲线为例

$$y^2 + y = x^3 - x.$$

问题7.证明这条曲线不是有理数。

让我们在这条曲线上取两点并通过它们画一条直线。这条直线将与我们的曲线再相交于一点 (图 6)。事实上，如果我们将所画的直线方程写成$y = kx + b$的形式，并将$y$代入曲线方程中，我们就得到了相对$x$的三次方程。当这个方程的根对应于直线和我们的三次曲线的三个交点的横坐标时。设$P_1(x_1; y_1), P_2(x_2; y_2), P_3(x_3; y_3)$为直线$y = kx + b$和曲线$y^2 + y = x^3 - x$的三个交点。有一封信函

$$x_1 + x_2 + x_3 = \left(\frac{y_1 - y_2}{x_1 - x_2}\right)^2.$$

为了证明这一点，我们将 $y = kx + b$ 代入曲线方程中。我们得到方程$x^3 - k^2 x^2 - (2kb + k + 1)x - b^2 - b = 0$。可以证明$x^3 - k^2 x^2 - (2kb + k + 1)x - b^2 - b = (x - x_1)(x - x_2)(x - x_3)$。因此，$x_1 + x_2 + x_3 = k^2$。通过点 $P_1(x_1, y_1)$ 和 $P_2(x_2, y_2)$ 的直线的斜率 $k$ 为 $\frac{y_1 - y_2}{x_1 - x_2}$。因此我们得到(*)。

给定$y_3 = kx_3 + b$，$b = \frac{y_2 x_1 - y_1 x_2}{x_1 - x_2}$，我们看到如果前两个点的坐标是有理数，则第三个交点的坐标也是有理数。这使得获得有理数方程 $y^2 + y = x^3 - x$ 的新解成为可能。

因此，我们的曲线上有四个有理点：

$$P_1(0; 0), \quad P'_1(0; -1),$$
$$P_2(1; -1), \quad P'_2(1; 0).$$

现在我们启动“传送带”。让我们通过 $P_1$ 和 $P'_2$ 画一条直线——这是 $x$ 轴。它在另一个明显的点 $P_3(-1; 0)$ 处与我们的曲线相交。加上对称点$P'_3(-1; -1)$，我们就有了原始曲线的六个点。让我们连接点 $P'_3$ 和 $P_1$。我们得到直线$y=x$。第三个交点很容易找到：代入$y=x$，得到三次方程$x^3-x^2-2x=0$，改变两个根。使用 (*)，我们获得一个新点 $P_4(2; 2)$ - 原方程的非明显解。让我们继续这个过程。要获得点 $P_5$，请通过点 $P'_4(2; -3)$ 和 $P_1$ 画一条直线。很容易检查结果将是点$P_5(1/4; -3/8)$。使用 图 7 可以很容易地追踪构造新点的过程。使用公式（*）的计算也很简单。结果，我们得到了表中所示的一系列点。

前三个问题非常难。让我告诉你，我们的点序列是无限的，所有具有有理坐标的点都可以在其中找到。

与其骂人，我再举一个例子。让我们看一下非常相似的曲线$y^2 + y = x^3 - x^2$。与我们构造的配置类似的配置在第三步中声明 - 参见图 8。有趣的是，这条曲线没有其他有理数点，并且方程$y^2 + y = x^3 - x^2$除了四个平凡的有理数解之外没有有理数解。

我们已经触及了现代数论中最困难的问题之一。

众所周知，在任何立方曲线上都有有限数量的点，从这些点开始所描述的过程，我们可以获得其所有有理点。大约五十年前就已经证明了这一点，但仍然没有找到这些点的通用方法。

确定绘制直线或输送无限结构的过程是否会循环的方法是已知的。最近，已经证明最终配置可以有超过 11 个点，并且所有情况（除了 10 个点的情况）都会发生并得到很好的研究。

在大多数已知的曲线上，构造所有有理点的起点数量很少 - 一个或两个。然而，有一个假设，对于任何 $n$ ，都存在需要 $n$ 点来构造所有解的曲线。到目前为止，示例已针对 $n \leqslant 7$ 构建。

最后，最后一点：如果在我们的曲线 $y^2 + y = x^3 - x$ 示例中，我们稍微改变一下符号 - 我们将 $A_1$ 一起写成 $P_1$、$A_{-1}$（而不是 $A'_1$、$A_k$ 一起写，$P'_k$ 和 $A_{-k}$ 一起写成 $P_k$（对于$k \geqslant 2$），而给出的“加法”则有些棘手（两点的“和”不是直线与曲线的第三个交点，而是相对于直线$y = -\frac{1}{2}$对称的点），我们得到公式

$$A_m \oplus A_n = A_{m+n},$$

对所有整数 $m, n$ 有效。
