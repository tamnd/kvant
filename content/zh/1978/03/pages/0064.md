1. 第一种方式。对于 $f(x) = x^5$，第二个任意值等于 $f''(x) = 20x^3$，因此在 $x > 0$ 处，切线 $k(x) = 5x^4$ 的斜率增加。只有图$6,\alpha$满足这个条件。

第二种方式。由于方程$x^5 = kx$最多有三个解（$x = 0; \sqrt[4]{k}; -\sqrt[4]{k}$），因此直线$y = kx$与图$y = x^5$最多相交于三个点。图 6、6、8 可以与直线 $y = kx$ 相交于更多的点。

2. 第一种方式。如果$f(x) = x^\alpha$，则$f''(x) = \alpha (\alpha-1) x^{\alpha-2}$，因此，在$\alpha > 1$的情况下，切线的角度系数在$x > 0$处增加，在$0 < \alpha < 1$的情况下杀死，分别对应于图7,a和7,b。

第二种方式。图形$y = x^\alpha$与直线$y = x$的交点与坐标原点不同，坐标为(1; 1)。如果$\alpha > 1$，则根据不等式$0 < x < 1$可得出$x^\alpha < x$；在$0 < \alpha < 1$的情况下，相反，从$0 < x < 1$跟随$x^\alpha > x$（解释）。因此，如果在区间 $]0; 1[$ 上，图 $y = x^\alpha$ 低于 bisertrix $y = x$，则为 $\alpha > 1$，如果高于，则为 $0 < \alpha < 1$。
