大身体悖论

当解决考虑质量显着不同的物体相互作用的问题时，通常会忽略质量较大的物体的能量变化。而这种忽视往往被证明是正确的。然而，有必要清楚地了解何时可以进行这种假设，何时不能进行这种假设。

为了澄清这个问题，请考虑以悖论形式提出的许多问题。

问题 1. 一块质量为 $m$ 的石头从高度$h$ 落到地球上。 1）让我们写下能量守恒定律，考虑到与石头-地球系统的质心相关的报告系统中石头的运动。当石头落到地球上时，其所有势能$mgh$已转化为动能$\frac{mv^2}{2}$：

$$mgh = \frac{mv^2}{2},$$

其中$v$是石头撞击地球之前的速度。

2) 让我们写下能量守恒定律，考虑与以恒定速度向下移动的电梯相关的报告系统的运动

在本文中，我们将质量比与其相互作用的其他物体的质量大许多倍的物体称为“大”物体。

相对于地球的高度$v$。在这个系统中，地球具有动能$\frac{Mv^2}{2}$（M是地球的质量），石头在初始时刻具有动能$\frac{mv^2}{2}$和势能$mgh$。当石头落到地球上时，它的动能和势能都等于零，因此对于所有系统我们可以写：

$$\frac{Mv^2}{2} + \frac{mv^2}{2} + mgh = \frac{Mv^2}{2} \Rightarrow \frac{mv^2}{2} + mgh = 0.$$

事实证明，能量守恒定律在“电梯”系统中不成立，但在报告系统中成立，电梯相对于报告系统以恒定速度移动。悖论？！

问题 2. 一颗质量为 $m$ 的子弹，以$v$ 的速度飞行，击中山腰并被困在其中。

在地球静止的报告系统中应用能量守恒定律，我们发现子弹能量的变化：

$$\Delta K_1 = 0 - \frac{mv^2}{2} = -\frac{mv^2}{2}.$$

我们将考虑与机枪相关的报告系统中子弹的运动，机枪以与子弹相同方向的速度 $u$ 移动。那么子弹的动能变化等于

$$\Delta K_2 = \frac{mu^2}{2} - \frac{m(|\vec{v} - \vec{u}|)^2}{2} = -\frac{mv^2}{2} + m|\vec{v}||\vec{u}|.$$

3) 在与机枪相关的参考系中，机枪以速度 $\vec{u}$ 沿与子弹运动方向相反的方向移动，

$$\Delta K_3 = \frac{mu^2}{2} - \frac{m(|\vec{v} + \vec{u}|)^2}{2} = -\frac{mv^2}{2} - m|\vec{v}||\vec{u}|.$$

子弹的部分动能去了哪里？当子弹突然减速时，会产生热量；换句话说，子弹的能量转化为热量：$|\Delta K| = Q$。我们可以改变释放的热量（例如，子弹准确地击中热量计）。然而，根据我们的推理，如果我们进行相同的更改三次，我们应该得到不同的结果：$Q_1 \neq Q_2 \neq Q_3$。悖论？！

人们可以想到更多类似的问题，其中“悖论”的出现只是因为所考虑的物体系统不是封闭的，并且在所有推理中都没有考虑到这一点。在上面的问题 2 中，系统不包括像地球这样的“大”天体。而在任务1的第2）点中，虽然它包含在地球系统中，但它的能量变化被认为等于零。在第 1 段）中，地球能量根本没有出现，但是，任何读者可能会说这里的所有内容都写得正确。

怎么了？为什么我们在选择某些参考系时会得到完全正确的结果，而在选择其他参考系时却会出现悖论？求解问题时应该选择哪个参考系，这样才可以忽略掉更多的质量，从而简化问题的求解？为了回答这些问题，让我们回到“悖论”问题，“绝对严格”地进行所有推理。

问题1.1）在与石地天体系统质心相关的参考系中，在地球结束的初始时刻，系统的全部能量等于石头的势能。当石头落到地球上时，系统的能量等于$\frac{mv^2}{2} + \frac{Mu^2}{2}$，其中$\vec{v}$是石头在地球引力影响下移动的速度，$\vec{u}$是地球在石头重力影响下移动的速度。我们来求速度$\vec{u}$，利用动量守恒定律：

$$m|\vec{v}| - M|\vec{u}| = 0,$$

在哪里

$$|\vec{u}| = \frac{m}{M}|\vec{v}|.$$

现在我们写出系统的能量守恒定律：

$$mgh = \frac{mv^2}{2} + \frac{M|\vec{v}|^2}{2} = \frac{mv^2}{2}\left(1 + \frac{m}{M}\right).$$

这个条目是“绝对严格的”。然而，很明显，在所有实现中，问题（关于地球上物体的下落）$m \ll M$和值$\frac{m}{M}$与1相比都不小，因此可以忽略不计。那么在与石地体系统质心相关的参考系中，能量守恒定律将写成如下：

$$mgh = \frac{mv^2}{2}.$$

2) 在“电梯”参考系中，石地系统的总能量等于$mgh + \frac{mv^2}{2} + \frac{Mu^2}{2}$，在石头落下的瞬间，系统的能量等于$\frac{Mu^2}{2}$，其中$\vec{u}$是速度。

地球的生长到现在为止。利用动量守恒定律 -

$$m \overrightarrow{v} + M \overrightarrow{v} = M \overrightarrow{u},$$

让我们找到 $\overrightarrow{u}$：

$$\overrightarrow{u} = \left| \overrightarrow{v} \right| \left( 1 + \frac{m}{M} \right).$$

所以，石头落下瞬间系统的能量等于

$$\frac{M u^2}{2} = \frac{M v^2}{2} + mv^2 + \frac{m}{M} \cdot \frac{m v^2}{2}.$$

我们之前认为地球的能量不变，石头落下的那一刻等于$\frac{M v^2}{2}$，即我们忽略了$\frac{M u^2}{2} - \frac{M v^2}{2} = mv^2 + \frac{m}{M} \cdot \frac{m v^2}{2}$，它大于石头的动能。显然，这是我们的错误，导致了悖论。 “严格”系统的能量守恒定律应写成如下：

$$m g h + \frac{m v^2}{2} + \frac{M v^2}{2} = \frac{M v^2}{2} + mv^2 + \frac{m}{M} \cdot \frac{m v^2}{2}.$$

利用“大”体条件，即考虑到$m \ll M$，我们可以忽略$\frac{m}{M} \cdot \frac{m v^2}{2}$，然后根据能量守恒定律我们发现

$$m g h = \frac{m v^2}{2}!$$

因此，在与石头质心相关的参考系——地球系统中，“大”体——地球——最初被抛弃，“大”体的能量变化可以忽略不计。在“电梯”系统中，“大”体地球的初速度为$v$，其能量的变化堪比一块石头的能量变化，而且变化不容忽视。

现在让我们转向问题2。

问题2.所考虑的截止系统中子弹动能的变化是不同的：

$$\Delta K_1 = -\frac{mv^2}{2},$$
$$\Delta K_2 = -\frac{mv^2}{2} + m |\vec{v}| |\vec{u}|,$$
$$\Delta K_3 = -\frac{mv^2}{2} - m |\vec{v}| |\vec{u}|.$$

根据动能定理-$A = \Delta K$-外力的作用，从山的侧面作用在子弹上的力，也是不同的。换句话说，各系统相对运动的结果被外力的相对做功所切断，因而非封闭物体系统的动能变化也是相对的。

我们在这个问题中遇到的悖论是由记录错误引起的

$$Q = -\Delta K.$$

该表达式仅对封闭的物体系统有效，因为对于此类系统，系统中所有物体的动能变化相对于任何惯性截止系统都是不变的（即不变）。

所以在问题2中，释放的物体量为$Q = |\Delta K_\pi| + |\Delta K_3|$，其中$\Delta K_\pi$和$\Delta K_3$是子弹和地球动能的变化。然而，第1)点得到的答案是正确的，这就是释放的热量，无论我们在哪个系统中解决问题：

$$Q = |\Delta K_1| = \frac{mv^2}{2}.$$

我们来证明一下这个说法。为此，让我们严格执行之前的所有推理：

1) 在地球（山）最初结束的截止系统中，系统的能量等于子弹的动能$\frac{mv^2}{2}$。当子弹击中一座山时，地球获得一定的速度$\vec{u}$，我们可以从动量守恒定律中找到：$M |\vec{u}| = m |\vec{v}|$，因此是$|\vec{u}| = \frac{m}{M} |\vec{v}|$。因此，地球获得动能$\Delta K'_3 = \frac{Mu^2}{2}$，所有系统的能量守恒定律必须写成以下形式

$$|\Delta K_\pi| = \frac{mv^2}{2} = \frac{m}{M} \cdot \frac{mv^2}{2} + Q,$$

或者

$$Q = \frac{mv^2}{2} - \frac{m}{M} \cdot \frac{mv^2}{2}.$$

使用“更大”物体的条件 - $m \ll M$，我们得到

$$Q = \frac{mv^2}{2} = |\Delta K_1|!$$

2) 在与机枪相关的截止系统中，机枪以与子弹相同方向移动的速度$\vec{u}$，地球的动能变化值$\Delta K'_3$。这种变化是由于其速度从 $|\vec{u}|$ 值降低到 $|\vec{u} - \Delta \vec{u}|$ 值而引起的。

值 $\Delta u$ 可以通过应用惯性截止系统中的子弹地球系统的动量守恒定律来确定，该系统与其质心相关（惯性截止系统的相对相对速度的变化！）：

$$M |\vec{u}| = m |\vec{v}|, \quad \Delta u = \frac{m}{M} |\vec{v}|.$$

$$\frac{m(v + u)^2}{2} = \frac{mu^2}{2} + m|\vec{v}||\vec{u}| + Q.$$

因此，表达式$Q = \Delta K$只对封闭的物体系统有效（即当$\Delta K$是整个系统的能量变化时），而对于开放的物体系统来说是正确的，当这个系统被考虑在“大”物体最初结束的报告系统中时。

总之，我们邀请您自己找出以下“悖论”。

1. 汽车$A$相对于地球以速度$v$移动。机器速度加倍后，动能也相应增加

$$\Delta K_1 = \frac{m(2v)^2}{2} - \frac{mv^2}{2} = \frac{3}{2}mv^2.$$

从位于自动机器中的观察者的角度来看 $B$，以相同的速度移动 $v$ 并与自动方向相同 $A$，自动改变动能 $A$ 将是平等的

$$\Delta K_2 = \frac{mv^2}{2} - 0 = \frac{mv^2}{2}.$$

对于位于自动机$B$中的观察者，其以与自动机$A$相同的绝对速度移动，但方向相反，自动机$A$的动能变化将等于

$$\Delta K_3 = \frac{m(3v)^2}{2} - \frac{m(2v)^2}{2} = \frac{5}{2}mv^2.$$

结果乍一看很奇怪：自动$A$的乏燃料量不变，但自动$A$的动能变化在不同的报告系统中有所不同。这与能量守恒定律有矛盾吗？

2. 一颗质量为$m$、以速度$v$移动的子弹击中以相同方向速度$u$移动的沙平台并被卡在那里。让我们找出在这种情况下释放的 Tellot 数量。

在与地球相关的报告系统中，

$$Q_1 = \frac{mv^2}{2} - \frac{mu^2}{2} = \frac{m}{2}(v^2 - u^2).$$

在平台关联的举报系统中，

$$Q_2 = \frac{m}{2}(v - u)^2.$$

事实证明，这是一个悖论：也许一颗子弹会在一个报告系统中融化，但在另一个报告系统中却不会？

3. 实际上安装的大炮可以以$u$的速度轻松地向飞行方向发射炮弹。

1) 让抛射体相对于报告系统以$u$的速度移动，获得$v$的速度。由于老化粉末气体的能量 $\Pi$，动能 $\frac{mv^2}{2}$ 被赋予弹丸：

$$\Pi = \frac{mv^2}{2}.$$

2) 相对于地球相关的报告框架，抛射体速度为 $v + u$，因此

$$\Pi = \frac{m(v + u)^2}{2} - \frac{mu^2}{2}.$$

由于值 $\Pi$ 对于报告系统而言是不变的，因此根据上述考虑可以得出：

$$v^2 + u^2 = (v + u)^2.$$
