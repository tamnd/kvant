丢番图方程模素数

“尊敬的狄奥尼修斯，知道我们热切地想学习如何解决有关数字的问题，我试图从这门科学的基础上解释我们的本质和力量。

也许这个主题对我来说似乎很难，因为我们还不熟悉它，初学者也不愿意指望成功。但首先，通过你的勤奋和我的错误，或者对科学的热情热爱，可以帮助你快速学习。”

以此奉献精神，亚历山大的丢番图算术开始了。

在这本书中，丢番图（他大概生活在 3 世纪）总结并扩展了他之前在求解整数或有理数的不定（即具有多个变量）代数方程方面积累的经验。从那时起，这些方程被称为丢番图方程。

以下是此类方程的示例：
$$x^2 + y^2 = z^2, \quad x^2 = y^3 + 5y + 7.$$

对丢番图方程的兴趣显然与人类的本质有关——保存下来的文献揭示了它在数千年深处的痕迹。即使在古巴比伦，他们也在寻找毕达哥拉斯项目——整数解$x^2 + y^2 = z^2$。

丢番图的“算术”奠定了现代数论的基础。自费马时代（17世纪）以来，丢番图方程已成为最杰出的数学家深入研究的主题，并引起所有数字爱好者的不懈兴趣，其兴趣不亚于可敬的狄奥尼修斯。

奉献中提到的任务的力量已经增强并且正在增强。丢番图方程理论与现代数学的几乎所有领域都有联系。

丢番图只在一件事上犯了错误——这个主题没有变得可理解。

也许最后一个抱有这种希望的人是著名的德国数学家大卫希尔伯特。 1900年，他在第二届国际数学家竞赛的报告中提出了来自不同数学领域的23道问题。第十个问题表述如下：表明在有限次数的安装操作之后，可以确定给定的丢番图方程是否可以整数解的方法。

1969年，长期的研究以对该问题的否定解决方案结束：事实证明，其表述中提到的通用方法根本不存在*)。

关于丢番图方程，还提出了更简单的问题。当解决这些问题时，非常漂亮的理论出现了。我们讨论了其中之一——丢番图方程模素数理论——在这个国家的起源。为了让您清楚地了解这个故事，我们建议您重新阅读文章“残基的比较和类别”（第 10 期）和“简单模数的比较”（第 11 期）。

**Chevalley 和 Varnin 定理**

知道集合 $F_{13}$ 可以让我们知道应该选择哪个比较模型来研究方程（3）。

如果方程没有三个变量，而是四个或五个，会发生什么？如果方程的次数不是 3，而是 4、5 或 6，会发生什么？我们认为，如果变量x的数量被告知，那么我们证明根据某种模型考虑它来求解原始方程的不可能性的机会就会减少；如果其程度被告知，它们就会成长。这个直观的消息可以进一步细化。

以下显着的切瓦利定理是有效的：考虑集合 $R(x_1, x_2, \dots, x_n)$，其系数位于集合 $F_p$ 中；设$x_1 = x_2 = \dots = x_n = 0$为方程$R(x_1, x_2, \dots, x_n) = 0$的解；如果集合 $R(x_1, x_2, \dots, x_n)$ 的次数小于 n，则方程 $R(x_1, x_2, \dots, x_n) = 0$ 有非零解。

Chevalley 定理紧接着 Varnin 定理：如果次数乘法 $R(x_1, x_2, \dots, x_n) = 0$ 等于 0 或 $\ge p$。但第一种情况被排除，因为方程有零解。这意味着他至少还有 p - 1 个解。

Varnin 定理的证明既简单又漂亮，所以我们就在这里给出它，但我们先说一下。

**关于一些等于零的金额**

集合 $F_p$ 中所有元素的总和 $\bar{b}_1 + \bar{b}_2 + \dots + \bar{b}_p$ 是多少？让我们将所有项乘以 $F_p$ 中的某个元素 $\bar{a}$，不等于 0 和 1。然后将总和乘以相同的元素：$\bar{a} \bar{b}_1 + \bar{a} \bar{b}_2 + \dots + \bar{a} \bar{b}_p = \bar{a} (\bar{b}_1 + \bar{b}_2 + \dots + \bar{b}_p)$。另一方面，当集合$F_p$的所有元素乘以某个元素（$\neq 0$）时，我们再次得到$F_p$中的所有元素；因此$\bar{b}_1 + \bar{b}_2 + \dots + \bar{b}_p = \bar{a} (\bar{b}_1 + \bar{b}_2 + \dots + \bar{b}_p)$。所以，$\bar{b}_1 + \bar{b}_2 + \dots + \bar{b}_p = 0$。

集合 $F_p$ 元素的平方和 $\bar{b}_1^2 + \bar{b}_2^2 + \dots + \bar{b}_p^2$ 是多少？让我们再次将所有元素乘以某个元素$\bar{a} (\neq 0, 1)$。然后，由于与之前相同的原因，金额保持不变：$(\bar{a} \bar{b}_1)^2 + (\bar{a} \bar{b}_2)^2 + \dots + (\bar{a} \bar{b}_p)^2 = \bar{b}_1^2 + \bar{b}_2^2 + \dots + \bar{b}_p^2$；另一方面$(\bar{a} \bar{b}_1)^2 + (\bar{a} \bar{b}_2)^2 + \dots + (\bar{a} \bar{b}_p)^2 = \bar{a}^2 (b_1^2 + \dots + \bar{b}_p^2)$。如果$\bar{a}^2 \neq 0, 1$，则$b_1^2 + \bar{b}_2^2 + \dots + \bar{b}_p^2 = 0$。

一般来说：如果集合$F_p$中有一个元素$\bar{a}$使得$\bar{a}^k \neq 0, 1$，那么$F_p$中所有元素的$k$幂之和等于0。

很明显，如果 $\bar{a}^k = 1$ 对于第一个多项式 $\bar{a}$ 从 $F_p$，那么更是如此 $\bar{b}_k = 1$ 对于所有其他元素 $\bar{b} \neq 0$。如果 $\bar{a}^k = 1$ 当且仅当 k 能被 p - 1 整除。特别是，如果 $0 < k < p - 1$， 那 $\bar{a}^k \neq 1$ k 次方之和为 0。 $\bar{0}^{p-1} + \bar{1}^{p-1} + \dots + \bar{p-1}^{p-1} = \bar{p-1}$, 一个 $x^p = x$ 为了 $x \in F_p$ （费马小定理），我们找到了元素的 k 次方之和 $F_p$ 对于任意 k ≠ 0：

$$\bar{b}_1^k + \bar{b}_2^k + \dots \bar{b}_p^k =$$

$$= \begin{cases} 0, \text{ если } k \neq 0 (\text{mod } p - 1), \\ p - 1, \text{ если } k \equiv 0 (\text{mod } p - 1) \text{ и } k \neq 0. \end{cases}$$

华林定理的证明

让我们用 $m$ 表示多项式 $R(x_1, x_2, \dots, x_n)$ 的次数，用 $N(R)$ 表示方程 $R(x_1, x_2, \dots, x_n) = 0$ 的解数。我们需要从条件$m < n$推出$N(R)$能被$p$整除。

在长度为$n$的$F_p$中所有可能的有序元素集合的集合$M$中，考虑方程$R(x_1, x_2, \dots, x_n) = 0$的解的子集$M_R$。子集$M_R$由集合$\langle \bar{c}_1, \bar{c}_2, \dots, \bar{c}_n \rangle$组成，其中$R(\bar{c}_1, \bar{c}_2, \dots, \bar{c}_n) = 0$。

考虑功能 $f_R$，对于每个元素 $\langle \bar{c}_1, \bar{c}_2, \dots, \bar{c}_n \rangle \in M$ 匹配数字 1 如果 $\langle \bar{c}_1, \bar{c}_2, \dots, \bar{c}_n \rangle \in M_R$，并且数字 0 如果 $c \langle \bar{c}_1, \bar{c}_2, \dots, \bar{c}_n \rangle \notin M_R$.

（在某个集合$M$上定义的函数，在某个子集$A \subset M$上取值1，在$M$的其余元素上取值0，称为子集$A$的特征函数。因此，函数$f_R$是子集$M_R$的特征函数。）从函数$f_R$的定义来看，方程 $R(x_1, x_2, \dots, x_n) = 0$ 的解 $N(R)$ 等于函数 $f_R$ 在集合 $M$ 的所有元素上的值之和。这个陈述似乎没有给 $f_R$ 的定义添加任何内容。然而，读者会发现用函数$f_R$替换集合$M_R$是证明的关键。

现在让我们考虑函数$f_R$，它与函数$f_R$的不同之处在于，它不是数字1和0，而是取$F_p$相应值$\bar{1}$和$\bar{0}$的解和非解。函数$f_R$在所有集合$\langle \bar{c}_1, \bar{c}_2, \dots, \bar{c}_n \rangle$上的$S(\bar{f}_R)$值之和等于数字$N(R)$的残差类$N(R)$（mod$p$）。因此，要证明华林定理，只要验证$S(\bar{f}_R) = \bar{0}$就足够了。

使用费马小定理，我们将函数 $f_R$ 表示为多项式。为此，请考虑多项式 $Q(x_1, x_2, \dots, x_n) = \bar{1} - R(x_1, x_2, \dots, x_n)^{p-1}$。如果$R(\bar{c}_1, \bar{c}_2, \dots, \bar{c}_n) \neq 0$，则费马小定理$R(\bar{c}_1, \bar{c}_2, \dots, \bar{c}_n) = \bar{0}$。如果$R(\bar{c}_1, \bar{c}_2, \dots, \bar{c}_n) = \bar{0}$，则$R(\bar{c}_1, \bar{c}_2, \dots, \bar{c}_n)^{p-1} = \bar{0}$和$Q(\bar{c}_1, \bar{c}_2, \dots, \bar{c}_n) = \bar{1}$。因此$f_R = Q$。

多项式 $Q(x_1, x_2, \dots, x_n)$ 是单项式的和：$Q = q_1 + q_2 + \dots + q_l$。

我们只需检查所有集合 $\langle \bar{c}_1, \bar{c}_2, \dots, \bar{c}_n \rangle$ 上每个单项式 $q_1, q_2, \dots, q_l$ 的值之和等于 $\bar{0}$ 就足够了。那么$S(f_R) = S(Q)$的总和将等于$\bar{0}$，因为$S(Q) = S(q_1) + S(q_2) + \dots + S(q_l)$。

以单项式 $q_1 = x_1^{k_1} x_2^{k_2} \dots x_t^{k_t}$ 为例。多项式$Q$的次数等于$(p - 1) m$。因此，单项式$q_1$的次数小于$(p - 1) n$（根据定理$m < n$的条件）。所以，$k_1 + k_2 + \dots + k_t < (p - 1) n$。从这个不等式可以得出，无论是$t < n$还是在$k_1, k_2, \dots, k_t$中，都有一个指数$k_i$，其中$0 < k_i < p - 1$。现在，等式 $S(q_1) = \bar{0}$ 由上一节末尾形成的结果得出。

与 Waring 定理不同，Weyl-Lang 定理的证明在一般情况下非常困难。

让我们考虑方程 $R(x_1, x_2, \dots, x_n) = 0$ 的一个非常特殊的情况：当多项式 $R$ 为一阶时：$R(x_1, x_2, \dots, x_n) = a_1x_1 + a_2x_2 + \dots + a_nx_n + b$（尽管假设其中一个系数 $a_i$ 不为 0）。很容易看出，在这种情况下$N(R) = p^{n-1}$。事实上，我们可以假设（如果需要，重新排列，未知，即）$a_1 \neq 0$；然后，给$x_2, \dots, x_n$来自$F_p$的所有可能值，并放入$x_1 = -a_1^{-1}(a_2x_2 + \dots + a_nx_n + b)$，我们得到解决方案。

Weyl–Lang 定理可以细化：对于大 $p$
$$|N(R) - p^{n-1}| < c \cdot p^{\frac{n-1}{2}},$$
其中 $c$ 是系数数，取决于多项式 $R$。

韦尔的最初证明是基于他发现的看似遥远的问题之间的深层联系：简单模数中方程$R(x_1, x_2, \dots, x_n) = 0$的解数的离散甚至有限问题，以及该方程复数解的连续多项式的几何结构，即复数$\langle d_1, d_2, \dots, d_n \rangle$的复数集合$R(d_1, d_2, \dots, d_n) = 0$。

最近，斯维尔多夫数学家 S. A. Stepanov 提出了一个基本的（没有使用间接方法）但非常复杂的 Weyl-Lang 定理证明。
