将充电至电压$U$。电容器电荷将增加
$$\Delta q = C_1 (U - U'_1) = \frac{n^2 + 1}{(n + 1)^2} C_1 U.$$
因此，电容器$C_1$从电池接收的总电荷$Q$等于
$$Q = q_1 + \Delta q = \frac{2 n^2 + n + 1}{(n + 1)^2} C_1 U.$$
电容器获得的能量等于
$$\Pi = \frac{C_1 U^2}{2}.$$
将电容器充电至电压 $U$ 时，电池所做的功 $A$ 等于
$$A = QU = \frac{2 n^2 + n + 1}{(n + 1)^2} C_1 U^2.$$
所以效率是
$$\eta = \frac{\Pi}{A} = \frac{(n + 1)^2}{2 (2 n^2 + n + 1)}.$$
为了使 $\eta$ 的值大于 1/2，需要满足以下不等式
$$\frac{(n + 1)^2}{2 n^2 + n + 1} > 1.$$
从这里我们发现$n < 1$。
因此，通过将电容器$C_1$充电至电压$U$，我们可以更有效地利用电池（$\eta > \frac{1}{2}$），如果在上述过程中我们另外使用电容器$C_2$，其容量小于$C_1$。
熟悉使用任意极值求极值方法的人可以在描述过程中发现$\eta = \eta_{\max}$位于$n = 1/3$（$\eta_{\max} \approx 57\%$）。
使用不是一个，而是两个、三个或更多附加电容器，您可以想出许多不同的充电方法。通过足够多的附加电容器，可以使效率尽可能接近所需的统一。
二.让我们描述另一种可以实现接近于1的效率的充电方法。
