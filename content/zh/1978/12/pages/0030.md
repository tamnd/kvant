根据上述标准，如果满足等式$S_{LMPQ} = S_{LNTS}$，则点$L$属于直线$CR$。让我们证明事实确实如此。

由于点$C$属于平行四边形$AFQD$和$ABSE$的对角线（参见图5），因此我们有：$S_{AGCH} = S_{CNQP}$和$S_{AGCH} = S_{CMST}$。因此$S_{CNQP} = S_{CMST}$，因此$S_{LMPQ} = S_{LNTS}$，这就是所需要的。该决定是合法的。

M493。证明不平等
$0,785n^2 - n < \sqrt{n^2 - 1} + \sqrt{n^2 - 2^2} + \dots + \sqrt{n^2 - (n - 1)^2} < 0,79n^2$.

图 7.

让我们取单位半径的四分之一圆：$O$是圆心，$[OA]$是半径，$|OA| = 1$（图6）。让我们将线段$OA$分成$n$拥塞部分（$n$是任意自然数）。在得到的第一个$n - 1$分割线段上（从点$O$开始计数），我们构造一条长直线，以便在最高处，所有矩形的上顶点都位于圆弧$BA$上，限制我们的“四分之一圆”（参见图6）。我们得到$n - 1$个矩形，其面积之和小于单位半径圆的四分之一，即小于$\frac{\pi}{4} < 0,79$。

由于这个金额是相等的
$$\frac{1}{n} \sqrt{1 - \left(\frac{1}{n}\right)^2} + \frac{1}{n} \sqrt{1 - \left(\frac{2}{n}\right)^2} + \dots +$$
$$+ \frac{1}{n} \sqrt{1 - \left(\frac{n - 1}{n}\right)^2} = \frac{1}{n^2} \left(\sqrt{n^2 - 1} + \sqrt{n^2 - 2^2} + \dots + \sqrt{n^2 - (n - 1)^2}\right),$$

根据上述内容，正确的不平等随之而来。

为了证明左不等式，我们进行如下操作。现在让我们在分割过程中接收到 $[OA]$ 的所有线段上构造一个矩形，总共 $n$ 矩形，并且使矩形的所有左上角顶点都位于圆的弧 $BA$ 上 (图 7)。我们将得到图所示的7步图形，其面积已经超过单位半径圆的四分之六，即超过$\frac{\pi}{4} > 0,785$。

阶梯图形的面积等于底长为$\frac{1}{n}$、高为长的矩形的面积$n$之和
$$1, \sqrt{1 - \left(\frac{1}{n}\right)^2}, \sqrt{1 - \left(\frac{2}{n}\right)^2}, \dots, \sqrt{1 - \left(\frac{n - 1}{n}\right)^2}$$

分别：
$$\frac{1}{n} \left(1 + \sqrt{\frac{n^2 - 1}{n^2}} + \sqrt{\frac{n^2 - 2^2}{n^2}} + \dots + \sqrt{\frac{n^2 - (n - 1)^2}{n^2}}\right).$$

所以，
$$\frac{1}{n^2} \left(n + \sqrt{n^2 - 1} + \sqrt{n^2 - 2^2} + \dots + \sqrt{n^2 - (n - 1)^2}\right) > 0,785,$$

在哪里
$$0,785n^2 - n < \sqrt{n^2 - 1} + \sqrt{n^2 - 2^2} + \dots + \sqrt{n^2 - (n - 1)^2}.$$
