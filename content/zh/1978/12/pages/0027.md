引理 1. 如果数字 $k$ 和 $n$ 互质，则数字 $k, 2k, 3k, \dots, (n-1)$ $k$ 除以 $n$ 会得到不同的余数。

引理 2. 如果数字 $l$ 和 $m$ 除以 $n$ 时得到相同的余数，则多项式 $x^l - x^m$ 可被多项式 $1 + x + \dots + x^{n-1}$整除。

引理1通过反证法证明了该方法。事实上，如果对于某些$i$和$j$（$0 < i < j < n$），数字$ik$和$jk$除以$n$时得到相同的余数，那么数字$(j-i)$$k$完全可以被$n$整除。但数字$j-i < n$；这意味着数字$k$和$n$必须有除1以外的公约数，这与互质矛盾。

由于除以的不同余数（不是零！）的数量 $n$ 等于 $n-1$，从引理 1 可以看出，如果数字 $k$ 和 $n$ 互质，那么除以的余数中 $n$ 数字 $k, 2k, \dots, (n-1)$ $k$ 所有数字来自 $1$ 到 $n-1$ 见面一次。

让我们证明引理 2。设 $l > m$ 和 $l = m+pn$。多项式 $x^m - x^l = (1-x^{pn})x^m$ 可被 $1-x^n$整除：

$$1-x^{pn} = (1-x^n) (1+x^n+x^{2n}+\dots+x^{(p-1)n}),$$

并且 $1-x^n$ 可以被 $(1-x)$整除，并且

$$(1-x^n) = (1-x) (1+x+x^2+\dots+x^{n-1}).$$

这暗示了引理 2 的陈述。

现在让我们继续证明多项式$1+x^k + \dots + x^{(n-1)k}$可以被$1+x + \dots + x^{n-1}$整除。让我们用$k_i$表示数字$ik$除以$n$的余数。然后，根据引理 2，多项式 $(x^k - x^{k_1}) + (x^{2k} - x^{k_2}) + \dots + (x^{(n-1)k} - x^{k_{n-1}})$ 可被多项式 $1+x + \dots + x^{n-1}$整除。需要注意的是，根据引理 1 的推论，多项式 $1+x^{k_1} + x^{k_2} + \dots + x^{k_{n-1}}$ 与多项式 $1+x + \dots + x^{n-1}$ 一致，因此可以被它整除。因此，

$$1+x^k + x^{2k} + \dots + x^{(n-1)k} = (1+x + \dots + x^{n-1}) \times (c_0 + c_1x + c_2x^2 + \dots + c_px^p),$$

其中 $p = (k-1)(n-1)$ 和 $c_0, c_1, \dots, c_p$ 是一些数字。因此，

$$a_1^k + a_2^k + \dots + a_n^k = a_1^k (1+q^k + \dots + q^{(n-1)k}) = a_1^k (1+q + \dots + q^{n-1}) (c_0 + c_1q + c_2q^2 + \dots + c_pq^p) = (a_1 + a_2 + \dots + a_n) \times (c_0 a_1^{k-1} + c_1 a_1^{k-1} q + \dots + c_p a_1^{k-1} q^p).$$

要完成定理的证明，只要证明数字$a_1^{k-1}q, a_1^{k-1}q^2, \dots, a_1^{k-1}q^p$是整数就足够了。事实上，数字 $a_1^{k-1}q$ 是一个整数，因为它表示为整数的乘积：$a_1^{k-1}q = a_1^{k-2}a_2$。同样，$a_1^{k-1}q^2 = a_1^{k-2}a_3$，$\dots, a_1^{k-1}q^p = (a_1q^{n-1})^{k-1} = a_n^{k-1}$。
