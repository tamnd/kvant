问题解决方案
M491—M493; F503, F505—F507

M491。几何切割的距离，所有的部分都用数字填充。 （例如，16、24、36、54、81。）
a) 证明三个连续切入目标的平方和可以被这些目标的总和整除。
b) 在什么自然n值下，n个连续切入目标的平方和除以这n个目标的总和？

我们将首先解决问题 M491 - 我们将证明 a) 点中的陈述并回答第 6) 点中的问题，然后我们将制定一个陈述，问题的两点都将遵循该陈述。

a) 让我们表示穿过$a_1, a_2, a_3$的三个连续目标（所有$a_i$都是数字目标）。从$a_1 a_3 = a_2^2$开始，我们得到
$$\left( a_1 + a_2 + a_3 \right)^2 = \left( a_1^2 + a_2^2 + a_3^2 \right) + 2 a_2 \left( a_1 + a_2 + a_3 \right),$$
跟随
$$a_1^2 + a_2^2 + a_3^2 = \left( a_1 + a_2 + a_3 \right) \left( a_1 - a_2 + a_3 \right)$$
——这是需要证明的。

6) 很容易给出一个几何切割的例子，其中四个连续目标的平方和不能除以这些目标的总和：对于切割 1, 2, 4, 8, 16, ...，总和 $1^2 + 2^2 + 4^2 + 8^2 = 85$ 不能被总和 $1 + 2 + 4 + 8 = 15$整除。一般来说，对于这个等级，前 2k 个目标 $1 + 2^2 + 2^4 + \dots + 2^{4k-2} = (2^{4k} - 1)/3$ 的平方和不能被这些目标 $1 + 2 + 2^2 + \dots + 2^{2k-1} = 2^{2k} - 1$ 的总和整除，因为 $2^{2k} + 1$ 不能被 3 或某个 $k$ 整除。因此，即使$n$也不合适。如果 $n$ 是奇数 ($n = 2k + 1$)，则 $n$ 的平方和在所学切割上始终为偶数，必然除以这些目标的总和。该陈述是真实的并且是从演示中得出的
$$a_1^2 + a_2^2 + \dots + a_{2k+1}^2 = \left( a_1 + a_2 + \dots + a_{2k+1} \right) \times \left( a_1 - a_2 + a_3 - a_4 + \dots - a_{2k} + a_{2k+1} \right),$$
这很容易证明，例如通过归纳法。

现在我们来阐述并证明上面提到的说法。

定理。如果数字$k$和$n$互质，则连续切割目标的$k-x$幂$n$之和（所有这些都是该数字的组成部分）必然除以这些目标的总和。

（由于数字 3 和 2 互质，该陈述暗示了问题 M491 的 a) 点和 b) 点的答案 - 对于奇数 $n$。）
证明。让我们用 $a_1, a_2, \dots, a_n$ 表示这些 $n$ 连续切割目标。我们想要证明 $a_1^k + a_2^k + \dots + a_n^k$ 可以被 $a_1 + a_2 + \dots + a_n$ 整除（假设 $k$ 和 $n$ 互质）。令 $q$ 为切割的分母。然后
$$a_1 + a_2 + \dots + a_n = a_1 (1 + q + \dots + q^{n-1}),$$
$$a_1^k + a_2^k + \dots + a_n^k = a_1^k (1 + q^k + \dots + q^{(n-1)} k).$$
让我们证明，如果 $k$ 和 $n$ 互质，则多项式 $1 + x^k + \dots + x^{n-1}$ 可以被多项式 $1 + x + \dots + x^{n-1}$整除。*）在证明中，我们需要两个辅助引理。

*) 在此处以及下文中，当谈到多项式的整除性时，我们的意思是商的所有系数都是整数。
