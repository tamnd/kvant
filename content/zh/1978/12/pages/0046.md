任务 2. 确定施加轴向力 $\vec{F}_1$ 和 $\vec{F}_2$ ($|\vec{F}_1| = 20\text{kH}, |\vec{F}_2| = 30\text{kH}$) 的钢阶梯杆 (图 4, a) 的伸长率。杆截面的长度等于$l_1 = 1\text{m}$和$l_2 = 2\text{m}$，横截面等于相应的$S_1 = 1\text{cm}^2$和$S_2 = 2\text{cm}^2$，模数$I\text{Онеа} E = 2 \cdot 10^5\text{MH/m}^2$。杆不是失重的。

显然，阶梯杆的总伸长率等于其各截面伸长率之和：
$$\Delta l = \Delta l_1 + \Delta l_2.$$
为了确定$\Delta l_1$和$\Delta l_2$，我们找到分别在杆的下部和上部产生的纵向弹力$\vec{N}_1$和$\vec{N}_2$。

按平面 $I$ 计算杆，并写出杆被切断部分在轴 $X$ 上的投影的条件（图 4，b）：
$$N_1 + F_1 = 0.$$
从这里
$$N_1 = -F_1 = |\vec{F}_1| = 20\text{kH}.$$
我们用同样的方法求$\vec{N}_2$。让我们画出剖面$II$并写出关系

对应于截止部分的平衡条件 (图 4, e)：
$$N_2 + F_1 + F_2 = 0,$$
或者
$$N_2 = -F_1 - F_2 = |\vec{F}_1| - |\vec{F}_2| = -10\text{kH}.$$
$y$ $N_2$ 的负号表示纵向力$\vec{N}_2$ 方向向下；因此，在上半部分中提到了杆。

根据胡克定律，
$$\Delta l_1 = \frac{N_1 l_1}{ES_1}, \quad \Delta l_2 = \frac{N_2 l_2}{ES_2},$$
和
$$\Delta l = \Delta l_1 + \Delta l_2 = \frac{1}{E} \left( \frac{N_1 l_1}{S_1} + \frac{N_2 l_2}{S_2} \right) = 0,5 \cdot 10^{-3}\text{m} = 0,5\text{mm}.$$
问题 3. 质量为 $m = 2$ t 的负载支撑两根相同的圆钢杆，在节点 $A$ 处铰接连接，并与垂直方向 (图 5) 形成角度 $\alpha = 60^\circ$。如果我们允许钢 $\sigma_{\text{доп}} = 160\text{MH/m}^2$​​ 承受应力，请确定每根杆的横截面直径。

考虑节点$A$。三个力作用在其上：负载重量 $\vec{P}$ ($|\vec{P}| = m|\vec{g}|$) 以及杆的反作用力 $\vec{R}_1$ 和 $\vec{R}_2$。让我们记下节点$A$在坐标轴$X$和$Y$上的投影的条件：
$$-|\vec{R}_1| \sin \alpha + |\vec{R}_2| \sin \alpha = 0,$$
$$|\vec{R}_1| \cos \alpha + |\vec{R}_2| \cos \alpha - m|\vec{g}| = 0.$$
从这里
$$|\vec{R}_1| = |\vec{R}_2| = |\vec{R}| = \frac{m|\vec{g}|}{2\cos \alpha}.$$
