事实证明，使用积分定义的概念（参见“代数与分析原理 10”或«Kvant»，1977 年，第 5 期）可以证明在给定区间内一个或另一个函数消失。

陈述3.如果$\int_a^b f(t)dt = 0$和函数$f$在区间$[a; b]$上连续，那么在这个区间上它只取一个符号的值（见第2段末尾的注释）。从积分的定义可以看出，如果函数$f$在线段$[a; b]$的所有点上都为正，则在该线段上距它的间隔为正，如果$f$在$[a; b]$上为负，则距它在该线段上的间隔也为负。

命题3已被证明。

例子。让我们证明对于任何$\alpha, \beta, \gamma$，函数$f(t) = \alpha \cos t + \beta \cos 2t + \gamma \cos 7t$在区间$[0; 2\pi]$上为零。事实上，函数 cos $nt$ 的反导数之一是函数 $\frac{1}{n}\sin nt$。根据牛顿-莱布尼茨公式

$$\int_0^{2\pi} (\alpha \cos t + \beta \cos 2t + \gamma \cos 7t) dt = \left( \alpha \sin t + \frac{1}{2} \beta \sin 2t + \frac{1}{7} \gamma \sin 7t \right) \bigg|_0^2 = 0,$$

因此，从语句 3 可以得出，函数 $\alpha \cos t + \beta \cos 2t + \gamma \cos 7t$ 在区间 $[0; 2\pi]$ 上存在零。

回到我们的问题，我们看到，要证明压扁矩的存在，只需证明：

$$\int_0^{2\pi} V(t)dt = 0.$$

5. 最有趣的案例：
$\omega_1 = 2, \omega_2 = 3, \omega_3 = 4$

在本节中，使用陈述3，我们将证明在$\omega_1 = 2, \omega_2 = 3, \omega_3 = 4$的情况下，压扁矩总是存在。

让我们找到函数$V(t)$的一般形式。为此，我们需要找到点 $P_i(t)$ ($i = 1, 2, 3$) 的坐标 $x_i(t), y_i(t), z_i(t)$ 作为时间函数的一般形式。现在我们将证明点 $P_i(t)$ 的每个坐标都执行简谐振动，即具有$\alpha \sin \omega_i t + \beta \cos \omega_i t$ 的形式。 (***)

公式 (***) 直接由以下引理得出：

引理。 a) 令$u, v$为空间中两个相互垂直且长度相同$R$的向量。然后向量的末尾

$$\vec{w}(t) = u \cos \omega t + v \sin \omega t$$

以角速度 $\omega$ 沿着半径为 $R$ 且位于该圆所属平面内的圆均匀绘制，则有两个相互垂直且长度相同的向量 $u, v$，使得

$$\vec{OP}(t) = u \cos \omega t + v \sin \omega t.$$

证明a) 由于向量$u \cos \omega t$和$v \sin \omega t$相互垂直，根据毕达哥拉斯定理

$$|\vec{w}(t)|^2 = |u|^2 (\cos \omega t)^2 + |v|^2 (\sin \omega t)^2 = R^2.$$

因此，矢量$\vec{w}(t)$的末端沿着半径为$R$的圆移动。

向量$\vec{w}(t)$末端的速度是向量

$$v \omega \cos \omega t - u \omega \sin \omega t,$$

因此每个时刻的速度大小是相同的
