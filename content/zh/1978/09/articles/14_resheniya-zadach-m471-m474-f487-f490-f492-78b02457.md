M473。有两组无 n 个 cir，每组中的 cir 按质量递增的顺序排列。表明

a) 2n - 1 个秤重和所有 2n 个秤重可以按照其质量递增的顺序排列；

在解决方案中，我们将使用以下非常重要的信息：如果两个翅膀中的每一个都将给定图形的面积分成两半，那么它们必然相交。假设已经找到了所需的圆。让我们画一条直线 $O_1O_2$ 连接给定的圆 $\gamma_1$ 和 $\gamma_2$ (图 1)。它将图形$G_1$的面积分成两半。但$\gamma$也将这个区域分成两半。这意味着$G_1$$\gamma$和$(O_1O_2)$内部有一个交点。同样，它们在$G_2$和$G_3$内部都有交点。我们发现圆和直线相交的点超过两个点——这是一个矛盾。这意味着这样的圆$G$不可能存在。

我们邀请您思考一个具有类似表述的问题（该问题是由来自沃罗涅日的读者 V. Kalmykov 发送给我们的）。

两个同心圆由两个区域界定：一个环和一个小于半径的圆。证明不存在将这两个区域的面积均分为两半的圆。

S·福明

立方体$K$的每条边上必须至少有一个点属于多面体$T$，否则立方体这条边方向上的投影$T$与立方体相应的边界不重合。让我们在立方体$K$的每条边上选择多面体$T$的一个点（其中一些可能是立方体的顶点）。令 $C$ 为它们的凸包 (图 4)。从多面体$T$的凸性可以得出$C \subset T$。将立方体的边长设置为1，我们计算出立方体$K$附加的$K \setminus C$多面体$C$的体积。

$K \setminus C$ 是立方体 $K$ (图 2) 角度处的所有三个角直线的并集。让我们将这些直线分成几对——立方体的四个垂直边各有一对直线。每对直线的体积之和不超过$\frac{1}{3} h S_1 + \frac{1}{3} (1-h) S_2$（见图2）。

从$S_1 \leqslant \frac{1}{2}, S_2 \leqslant \frac{1}{2}$开始，我们得到$\frac{1}{3} h S_1 + \frac{1}{3} (1-h) S_2 \leqslant \frac{1}{3} \cdot \frac{1}{2} (h + (1-h)) = \frac{1}{6}$。

因此体积$(K \setminus C) \leqslant 4 \cdot \frac{1}{6} = \frac{2}{3}$，因此体积$T \geqslant$体积$C \geqslant 1 - \frac{2}{3} = \frac{1}{3}$。

请注意，估计 $1/3$ 是准确的：顶点是立方体的四个不相邻顶点的四面体的体积是立方体的体积$1/3$。

F487。在两个尺度上形成甲虫：从距离$d_1 = 3F$，食物$F$ - 镜头焦距，以及从距离$d_2 = 5F$。必须改变镜头光圈的直径多少次才能使两种情况下胶片上的图像质量相同？考虑到这两种情况下的透镜直径都远小于 $F$。

图 3.

让我们用$B$表示甲虫单位表面积在单个立体角内发出的光通量（表面亮度）。然后光通量从区域$S_0$(图3)落到相机镜头上

$$\Phi = BS_0\Omega = BS_0 \frac{S_\pi}{d^2}.$$

这里$\Omega = \frac{S_\pi}{d^2}$是立体角（其实这个等式并不是精确的，而是近似的），$S_\pi$是镜头光圈的面积，$d$是相机到甲虫的距离。

经过镜头后，光通量照射到照相胶片上，在其上形成图像。此图像的照明

$$E = \frac{\Phi}{S} = \frac{BS_0S_\pi}{d^2S},$$

其中$S$是甲虫表面选定区域的图像区域。我们去找她吧。

由于镜头的线性放大倍数为$f/d$（f为镜头到像的距离），所以像与物体的面积关系

$$\frac{S}{S_0} = \left( \frac{f}{d} \right)^2.$$

根据透镜公式，$\frac{1}{d} + \frac{1}{f} = \frac{1}{F}$，由此

$$f = \frac{Fd}{d - F},$$ 和 $\frac{f}{d} = \frac{F}{d - F}$。

因此，图像照明

$$E = \frac{BS_\pi}{d^2} \frac{S_0}{S} = \frac{BS_\pi(d - F)^2}{d^2F^2}.$$

根据问题的条件，在两个尺度拍摄甲虫时，图像的光照应该是相同的：

$$\frac{BS_\pi(d_1 - F)^2}{d_1^2F^2} = \frac{BS_\pi(d_2 - F)^2}{d_2^2F^2}.$$

从这里

$$\frac{S_{\pi 2}}{S_{\pi 1}} = \frac{(d_1 - F)^2 d_2^2}{(d_2 - F)^2 d_1^2} = \frac{25}{36},$$ 和

$$\frac{D_{\pi 2}}{D_{\pi 1}} = \frac{5}{6}.$$

电子进入磁场，具有动能

$$E_k = \frac{mv^2}{2} = eU$$

（$e = 1,6.10^{-19}$ C 是电子的电荷，$m = 9,1.10^{-31}$ kg 是电子的质量），即以一定速度

$$|\vec{v}| = \sqrt{2U \frac{e}{m}}.$$

1) 如果磁场垂直于平面 图，则电子沿与 T 点处的直线 TT' 相切的圆运动。由于向心加速度是通过洛伦兹力传递给电子的，因此该圆的半径 R 为

$$|\vec{F}_{\perp}| = e |\vec{v}| |\vec{B}| = \frac{mv^2}{R}.$$

从这里

$$|\vec{B}| = \frac{m |\vec{v}|}{eR} = \frac{1}{R} \sqrt{2U \frac{m}{e}}.$$

从 图 6 可以清楚地看出，如果 $R = \frac{d}{2 \sin \alpha}$，电子将撞击 M 点，即，当

$$|\vec{B}| = \frac{2 \sin \alpha}{d} \sqrt{2U \frac{m}{e}} \approx 3,4 \cdot 10^{-3} \text{ T}.$$

2) 如果磁场沿着直线 TM 方向，则电子将以螺旋形运动，其轴平行于直线 TM (图 7)。事实上，电子速度在直线 TM $v_1 = |\vec{v}| \cos \alpha$ 上的投影不会改变。在垂直于直线TM的平面内，电子将以绝对值做圆周运动，速度等于$v_2 = |\vec{v}| \sin \alpha$。

绕其轴完整旋转一圈后，电子将穿过直线 TM。如果电子速度在直线 TM 上的投影 $v_1$ 等于 0，那么，沿着半径为 $R_1$ 的圆旋转一周后，电子将返回到点 T。在我们的例子中，它们将在彼此间隔 $l = v_1 \tau$ 的点处与直线 TM 相交，其中 $\tau$ 是电子旋转一圈的时间：

$$\tau = \frac{2 \pi R_1}{v_2}.$$

为了让电子到达M点，长度$|TM|$必须等于整数$l$，即

$$d = kl = kv_1 \tau = 2 \pi k R_1 \frac{v_1}{v_2} = 2 \pi k R_1 \text{ ctg} \alpha (k - \text{целое}).$$

由于$\|\vec{F}_1\| = \mu \|\vec{N}_1\|$，必须满足条件$\mu \|\vec{N}_1\| \geq \|\vec{F}\|$。

很容易看出，当满足条件（2）时，不会将大圆柱体与小圆柱体进行检查。为了使大圆柱体不被校核，绕其轴线的所有力的力矩之和必须等于零。这仅仅意味着气缸之间的摩擦力模型应该等于$\|\vec{F}\|$。

现在让我们找出力 $\vec{N}_1$ 和 $\vec{N}_2$ 是什么。由于大圆柱体处于平衡状态，因此力 $\vec{F}_1$、$\vec{N}_1$ 和 $\vec{F}$ 的水平投影之和必须等于 0：

$$\|\vec{N}_1\| \sin \alpha - \|\vec{F}\| - \|\vec{F}\| \cos \alpha = 0.$$

从这里

$$\|\vec{N}_1\| = \frac{\|\vec{F}\| (1 + \cos \alpha)}{\sin \alpha}.$$

将这个值$\|\vec{N}_1\|$代入不等式(3)，我们发现必须满足条件

$$\mu \geq \frac{\sin \alpha}{1 + \cos \alpha}.$$

为了找到$\vec{N}_2$，只需将作用在整个系统上的所有力的垂直投影之和归零就足够了。这给出了

$$\|\vec{N}_2\| = (m_1 + m_2) \|\vec{g}\|.$$

因为，当一个大圆柱体处于平衡状态时，相对于通过点$K$的水平轴的所有力的力矩之和也必须等于0，则

$$m_1 \|\vec{g}\| |KL| = \|\vec{F}\| |KM|,$$

或者

$$m_1 \|\vec{g}\| R \sin \alpha = \|\vec{F}\| (R + R \cos \alpha).$$

从这里

$$\|\vec{F}\| = m_1 \|\vec{g}\| \frac{\sin \alpha}{1 + \cos \alpha}.$$

将$\|\vec{F}\|$的表达式和上面找到的$\|\vec{N}_2\|$的表达式代入不等式（1），我们得到

$$\mu \geq \frac{m_1}{m_1 + m_2} \frac{\sin \alpha}{1 + \cos \alpha}.$$

这意味着 $\mu$ 必须大于不等式 (4) 和 (6) 右侧表达式中最大的一个。显然，要实现这一点，必须满足条件（4），即

$$\mu \geq \frac{\sin \alpha}{1 + \cos \alpha}.$$

由于$\cos \alpha = \frac{OP}{OO'} = \frac{R - r}{R + r} = \frac{D - d}{D + d}$和$\sin \alpha = \frac{2 \sqrt{Dd}}{D + d}$，那么

$$\mu \geq \frac{2 \sqrt{Dd}}{(1 + \frac{D - d}{D + d}) (D + d)} = \sqrt{\frac{d}{D}},$$

$$|\vec{F}| = \sqrt{\frac{d}{D}} m_1 \|\vec{g}\|.$$
