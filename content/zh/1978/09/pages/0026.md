6) 设$M_0 = (p_0; q_0)$为平面$\pi$的不动点，$M = (p; q)$为变点； $f_0(x) = \cos^2 x + p_0 \cos x + q_0$，$f(x) = \cos^2 x + p \cos x + q$。对于给定点 $M$ 和 $M_0$，我们设置

$$d(M, M_0) = \max_{[0; \pi]} |f(x) - f_0(x)|.$$

让我们找到点 $M = (p; q) \in \pi$ 最大化的集合

1) $d(M, M_0) = 1$;
2) $d(M, (2; 2)) = d(M, (-2; -2))$.

2. 用于求解方程 $x^2 + px + q = 0$ 的列线图

让我们在相平面$\pi$上绘制相当多的根直线$ap + q + a^2 = 0$，给定参数$a$，例如值0； ±0.5； ±1； ±1.5； ±2； ±2.5； ±3； ±3.5。

在每条绘制的线旁边，我们写下相应的值 $a$ (图 3)。由此产生的直线“网络”称为半原子数（用于求解二次方程）。

为了使用构建的列线图找到给定方程$x^2 + px + q = 0$的根，需要确定哪些根线穿过相应的点$(p; q) \in \pi$。

例如，让我们求解方程 $x^2 + 0,5x - 3 = 0$。通过点$(0,5; -3)$有使用$a = -2$和$a = 1,5$的根线；因此，数字$-2$和$1,5$是我们方程的根。

现在让我们考虑方程$x^2 + x - 3 = 0$。它对应于相平面上的点$(1; -3)$。通过该点的根线未绘制在我们的列线图上。在这种情况下，我们将这样做。请注意，点$(1; -3)$位于由$a = -2,5$处的根线形成的四边形$ABCD$内部； $a = -2$； $a = 1$ 和 $a = 1,5$ (图 3)。
