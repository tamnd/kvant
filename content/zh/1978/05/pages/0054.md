⟦folio 52⟧

物理学院

1. 将交流电压施加到垂直放置的扁平电容器的极板上，产生强烈的 $E = A \cos \omega t$ 电场。找出运动定律并构建一个位于电容器极板之间的电子运动曲线图，同时考虑到重力。在初始时刻，电子结束并与最近的板相距$l$。电子的质量为$m$，电荷为$e$，$l$非常大，以至于电子在任何时候都无法到达电容器的极板。

2. 找到三个正数，使其乘积最大，前提是第一个和第二个数之和为$a$，第一个和第三个数之和为$2a$。

3. 找到方程的解

$$6 \text{tg} x + \frac{5}{\text{tg} 3x} = \text{tg} 2x,$$

属于积分的有哪些

$$\int -\frac{\pi}{2}; \frac{\pi}{2} \Bigg[.$$

4. 你可以用多少种方法将 $n$ 个相同的球放入 $k$ 个盒子中？

5. 三个球接触边长为 $a$、$b$ 和 $c$ 的三角形平面，并且成对地相互接触。求出球的半径。

经济学院、化学学院、心理学院经济控制论系、国民经济规划系

1. 在积分 $]0; 1[$ 中找到不等式成立的那些 $x$ 的子集

$$\left(\frac{1}{81}\right)^8 + \log_a x > \left(\frac{1}{3}\right)^{2a} x.$$

2. 找到方程的所有解

$$8 \cos x + 6 \sin x - \cos 2x - 7 = 0,$$

位于区间$[0; 2\pi]$。

3. 小于$10^4$且十进制中所有数字都不同的正整数有多少个？

4. 给定一个由线 $y = 0$、$x = a$ ($a > 0$) 和 $y = x^3$ 界定的弯曲梯形。平面梯形的多少部分是由直线$y = x^3$在点$x = \frac{2a}{3}$处的切线与该梯形相切的三角形的面积？

5. 确定半径为 $R$ 且具有最大侧表面积的球内切圆锥体的高度。最大的侧表面积是多少？

生物与地理学院

1. 解决不平等问题

$$\sqrt{x+3} - \sqrt{x-1} > \sqrt{2x-1}.$$

2. 找到方程的所有解

$$\frac{3(1-\sin 3x)}{\sin x - \cos 2x} = 2 \cos 2x - 7,$$

位于积分$]-\pi; \pi[$中。

3. 有多少个小于$10^4$且能被4整除的正整数，在十进制中只出现数字0、1、2、3、5，并且相同的数字不重复？

4. 在函数$y = (x+1)\sqrt{x}$的图形上，在斜率等于2的点处画一条切线，并且该切线不经过原点。找到该切线与坐标轴的交点。

5. 为了使圆锥体的体积最大，在给定侧表面积$S$的情况下，圆锥体的底面半径应该是多少？

地质学院、经济学院政治经济系

1. 解决不平等问题

$$\sqrt{x^2+x} > 1-2x.$$

2. 找到方程的所有解

$$\sin 7x + \cos^2 2x + \sin x,$$

位于积分$]-\frac{\pi}{4}; \frac{\pi}{4}[$中。

3. 解方程

$$\sqrt{2-\log_x 9} = -\frac{\sqrt{12}}{\log_3 x}.$$

4. 计算位于第一象限且以线 $xy = 4$、$x = y$、$y = 2x$ 为界的三角形的法线面积。

5. 向量$a$，向量数$b = (12; -16; -15)$，与轴$Oz$形成锐角。给定 $|a| = 100$，求它的坐标。
