$$\frac{1}{\|\cos x\|} = \sqrt{1 + \mathrm{tg}^2 x}$$

代入 $tg x = y$ 得到方程
$$\sqrt{1 + y^2} + \sqrt{6} (1 + y) = 8 \sqrt{y}.$$

为了求解最后一个方程，改变未知数$\frac{y+1}{\sqrt{y}} = z$是很方便的。

2. $x_1 = -24, x_2 = 3$。笔记。输入辅助未知数$u = \sqrt[3]{24+x}, v = \sqrt{12-x}$，到达系统
$$u + v = 6, u^3 + v^2 = 36$$

并从中排除$v$。

3. $x = y = z = 2$。笔记。请注意，系统的第二个方程可以重写为
$$(\sqrt{x} - \sqrt{y})^2 + (\sqrt{y} - \sqrt{z})^2 = 0,$$
由此可见$x = y = z$。

4. $x = 1$.

5. $x_1 = 1, x_2, 3 = \frac{1}{2} (-1 \pm \sqrt{5})$.

笔记。

$$x^3 - 2x + 1 = (x^3 - x^2) + (x^2 - 2x + 1).$$

6. $x_{1,2} = \frac{1}{2} (-3 \pm \sqrt{13})$.

笔记。

$$x^4 + 4x^3 + 3x^2 + 2x - 1 = (x^4 + 4x^3 + 4x^2) - (x^2 - 2x + 1).$$

7. $x_{1,2} = 1 \pm \sqrt{2}$。笔记。将该方程的左侧等于两个平方三项式 $(x^2 + ax + b)(x^2 + cx + d)$ 与未确定系数的乘积，并匹配这些系数。

8. $m:n \cos \alpha$。笔记。让在$AD$边上绘制的高度$BE$与对角线$AC$相交于点$K$。注意$\triangle AKE \sim \triangle CKB$；从三角形 $AEB$ 中找出数量 $|AE|$。

9. $2(2 - \sqrt{3}) a$。笔记。令 $L$ 为其中一个半圆的中心，$O$ 为所需圆的中心。让我们用$T$表示穿过点$O$的线的交点，该线平行于点$L$所在的正方形的边，半圆的半径垂直于正方形的所述边。将毕达哥拉斯定理应用于三角形 $LTO$。

10. arctg $(tg \alpha \cos \varphi)$。笔记。令 $M$ 为平面 $P$ 中从点 $B$ 到二面角边的垂线的底，$N$ 为平面 $Q$ 中从点 $C$ 到边的垂线的底。然后

$$\overrightarrow{AB} = \overrightarrow{AM} + \overrightarrow{MB}, \overrightarrow{AC} = \overrightarrow{AN} + \overrightarrow{NC}.$$

计算点积 $\overrightarrow{AB} \cdot \overrightarrow{AC}$ 并利用 $[AB] \perp [AC]$ 的事实。

11. $2/3 R(1 + 2 \cos \alpha)$。笔记。令 $SABC$ 为给定的参数； $[SH]$ — 其高度，降低至边缘 $ABC$；点$O$是外接球的中心；点$M$是侧边$[SA]$的中间。证明点 $O$ 位于高度 $[SH]$ 且$[OM] \perp [SA]$。画面$SAB$的边心$[SD]$并构造直角三角形$HDA$。引入一个辅助角度
$$\widehat{ASH} = x$$；然后从三角形 $SHA, HDA$ 和 $SDA$
$$\sin x = \frac{\sin \alpha/2}{\cos 30^\circ}.$$

接下来，从三角形$SMO$表达$|SM|$，并从三角形$SHA$找到$|SH|$。

12. $\frac{d^3}{3 \sin \frac{3\alpha}{2}}$。笔记。令 $SABC$ 为给定的参数，$[SH]$ 其高度落在$ABC$ 面上。画面$ASB$的边心$[SD]$，并证明从点$D$到边$[SC]$所画的垂线$[DM]$的长度等于$d$。我们引入一个辅助角$\widehat{ASH} = x$；然后从三角形 $SHA, SDA$ 和 $HDA$
$$\cos x = \frac{\sin \alpha/2}{\cos 30^\circ}.$$

接下来，注意$\widehat{SCD} = x$，并使用辅助角分别从三角形$CMD, HDA$和$SHC$表达$|CD|$、$|AD|$和$|SH|$。

13. 反正弦$\left(\frac{2}{\sqrt{3}} \cos \frac{\alpha}{2}\right)$。笔记。令 $SABC$ 为给定的参数。让我们构造线性角 $\angle AMC$ 和 $\angle SNC$ 二面角；证明平面$AMC$和$SNC$的交线$(CD)$垂直于平面$ASB$。显示 $\widehat{DCA} = \alpha/2$ 并标记 $\widehat{SNC} = x$。然后从三角形$ADC, NDC$和$ANC$
$$\cos \frac{\alpha}{2} = \frac{|CD|}{|CA|} = \frac{|CD|}{|CN|} = \frac{\sin x}{1/\cos 30^\circ}.$$
