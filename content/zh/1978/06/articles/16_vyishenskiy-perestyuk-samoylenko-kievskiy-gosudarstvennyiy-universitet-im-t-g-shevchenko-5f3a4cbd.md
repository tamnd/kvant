Matematika

笔试选项
力学与数学学院

1. 圆柱体内接于正四边形帕拉米德，其侧面与底面倾斜角 φ（圆柱的一个底面位于帕拉米德底面的平面内，其第二个底面的圆与各侧面各有一个公共点）。圆柱体底面半径和高度等于r。计算对位酰胺的体积。在角度 φ 为多少时，帕拉酰胺的体积最小？

2. 计算由函数图包围的图形的面积

$$y = \frac{|4 - x^2|}{4} \text{ и } y = 7 - |x|.$$

3. 解决不平等问题

$$\sqrt{\log_2^2 x + \log_1 x^2 - 3} > \sqrt{5}(\log_4 x^2 - 3).$$

4. 有多少个四位数字的十进制数不超过两个不同的数字？

物理学院

1. 围绕半径为 r 的球描述了高度为 H 的正三角形参数。计算paramid的侧面面积。在 H 为多少时，该面积最小？求最小面积值。

2. x 的导函数是对于什么值

$$y = \sin 2x + 10\cos x - 6x$$

等于零？

3. 找到极限

$$\lim_{n \to \infty} \frac{n\sqrt{1 + 3 + 5 + \dots + (2n - 1)}}{2n^2 + n + 1}.$$

4. 在平面上给出两条相互垂直的直线。找到所有这些平面的集合，到给定线的距离的乘积等于这些距离的总和。

口试作业

1. 解方程

$$\sin |x| = |\sin x|.$$

2. 解决不平等问题

$$\sqrt{4 - x^2} + \frac{1}{x} \geq 0.$$

3. 方程有多少个根？

$$x^5 = 5x + 2a$$

取决于参数 a?

4. 方程组有多少个解？

$$\begin{cases} |x| + |y| = 1, \\ x^2 + y^2 = a \end{cases}$$

取决于参数 a?

5. 在直线坐标系中绘制点集

$$\begin{cases} (x; y) | \log \left( |x| - \frac{1}{2} \right) (x^2 + y^2) \leq \log \left( |x| - \frac{1}{2} \right)^4 \end{cases}$$

6. 查找a的所有值，其中多个

$$\{(x; y) | x^2 + y^2 + 2x \leq 1 \} \cap \{(x; y) | x - y + a = 0\}$$

仅包含一个点。找到这个点。

7. 绘制函数图

$$y = \begin{cases} 1 - \sqrt{1 - x^2}, \text{ если } x \leq 1, \\ 1 + \log \frac{1}{2} x, \text{ если } x > 1. \end{cases}$$

8. 证明函数

$$f(x) = \frac{2}{3} x^9 - x^6 + 2x^3 - 3x^2 + 6x - 1$$

R 上单调增加。

9. 查找函数对应的 a 的所有值

$$f(x) = \frac{a^2 - 1}{3} x^3 + (a - 1) x^2 + 2x + 1$$

对于所有 x ∈ R 都会增加。

10. 设x₁和x2为对应关系，最大点和最小点

$$f(x) = 2x^3 - 9ax^2 + 12a^2x + 1.$$

当 x₁² = x²² 时？

11. 为了什么功能

$$f(x) = \frac{a}{3} x^3 + (a + 2) x^2 + (a - 1) x + 2$$

有负的最低点吗？

12. x 的什么值从第一个不同的函数形成零

$$f(x) = \pi \sin \pi x + 2x - 4,$$

x = 1 时哪个值为 3？

13. 计算由函数图界定的图形的面积

$$y = 2 + \sin x \text{ и } y = 1 + \cos^2 x$$

在区间 [0; π]。
