4. 这个方程相当于一个“混合系统”

$$\begin{cases} \sqrt{2x} = ax + 1, \\ x \neq \frac{1}{2}. \end{cases}$$

(1)

系统 (1) 等于系统

$$\begin{cases} 2x = (ax + 1)^2, \\ x \neq \frac{1}{2}, \\ ax + 1 > 0. \end{cases}$$

对于 $a = 0$，方程 $a^2x^2 + 2(a - 1)x + 1 = 0$ 有一个根 $x = \frac{1}{2}$。因此，对于$a = 0$系统(2)无解。

现在让$a \neq 0$。在这种情况下，对于 $a > \frac{1}{2}$，方程 $a^2x^2 + 2(a - 1)x + 1 = 0$ 以及系统 (2) 无解。

对于$a = \frac{1}{2}$系统(2)有唯一解。

所以让$a < \frac{1}{2}$和$a \neq 0$。让我们把

$$x_1 = \frac{1 - a + \sqrt{1 - 2a}}{a^2},$$

$$x_2 = \frac{1 - a - \sqrt{1 - 2a}}{a^2}.$$

然后

$$ax_1 + 1 = \frac{1 + \sqrt{1 - 2a}}{a},$$

$$ax_2 + 1 = \frac{1 - \sqrt{1 - 2a}}{a}.$$

代入方程$a^2x^2 + 2(a - 1)x + 1 = 0$“禁根”$x = \frac{1}{2}$，我们得到$a = 0$或$a = -4$。我们有$a \neq 0$。在$a = -4$，我们有$x_1 = \frac{1}{2}, x_2 = \frac{1}{8}$。

对于$a \in \mathbb{R}$$0; \frac{1}{2} \left[ \text{имеем } x_1 \neq \frac{1}{2}, ax_1 + 1 > 0 \text{ и } x_2 \neq \frac{1}{2}, ax_2 + 1 > 0 \right.$，这意味着对于这样的$a$系统（2）有2个解。

在$a < 0$$ax_1 + 1 < 0$、$ax_2 + 1 > 0$。我们在上面已经注意到，对于$a \neq 0$，我们有$x_2 \neq \frac{1}{2}$。

回答。 $\left\{ \frac{1}{2} \right\} \cup \left\{ -\infty; 0 \right\}$。
