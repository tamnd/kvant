选项1
1. $a \geq b$是什么意思？证明如果$a > b$和$b \geq c$，则$a > c$。
2. 如果给定三角形 $A (3; -1)$、$B (1; -3)$、$C (-6; 6)$ 的坐标，求三角形 $ABC$ 的面积。指出导致三角形 $ABC$ 映射到自身的所有平面运动。
3. 解方程
$$\sqrt{1 - \sqrt{2}} \sin x + 2 \cos x = 0.$$
4. 解决不平等问题
$$4^x - 2^{x+1} - 3 < 0.$$
$\sqrt{2}$真的是它的解吗？
5. 令$f(x) = f_1(x) + f_2(x)$，其中$f_1(x) = 2x - \sqrt{9 - x^2}$，$f_2(x) = \log_1(x^2 + x - 2)$。
求函数$f(x)$的定义域，以及函数$f_2(x)$在区间[3;上的最高值和最高值； 6]。

选项2
1. 外科有40名医生。他们可以通过多少种方式组成一个旅，其中包括：
a) 外科医生和助理；
b) 一名外科医生和他的 4 名助手？
2. 点 $A (-6; 3)$、$B (-7; 7)$、$C (-3; 6)$ 和 $D (-2; 2)$ 在平面上给出。证明四边形$ABCD$是菱形并计算其面积。指示菱形 $ABCD$ 映射到其自身的平面的所有运动。
3. 解方程
$$\sqrt{4 - \sqrt{3}} \cos x + \frac{3 \sqrt{2}}{2} \sin x = 0.$$
4. 解决不平等问题
$$\frac{2^{x+1} - 5 \cdot 3^x}{2^x - 3^{x+1}} < 1.$$
$\lg \frac{1}{32}$真的是它的解吗？
5. 函数 $f$ 由以下公式给出
$$f(x) = \frac{|3x - 4| + 2x^2 - 4x - 1}{|2x + 1| - 2};$$

a) 求函数$f$的定义域；
b) 在区间$- \infty; -2 [$内找到任意函数$f$； $f' (-4)$等于什么？
b) 函数$f$在$x \rightarrow \frac{1}{2}$和$x \rightarrow -\frac{3}{2}$有极限吗？
d) 规则指定的函数$g$处于什么值$a$
$$g(x) = \begin{cases} f(x), \text{ если } x \neq \frac{1}{2}, \\ a, \text{ если } x = \frac{1}{2}, \end{cases}$$

在点 $x = \frac{1}{2}$ 处有任意一个吗？
选项3

$$\begin{cases} 2x - y > a, \\ 3x + 2y > 3a. \end{cases}$$
a) 对于$a = 0$，将指示系统的一个解；
b) 该系统的所有解都满足不等式$5x + y > 4a$吗？
b) 该系统的所有解都满足不等式$x + 3y > 2a$吗？
2. 当坐标平面以点$M$为中心旋转$\alpha$角度时，点$A (2; 3)$转到$A_1 (5; 2)$，$B (2; 5)$转到$B_1 (7; 2)$。求点$C (2; 4)$的图像。找到另一个点的图像（您的选择）。求角度 $\alpha$ 的大小和点 $M$ 的坐标。
3. 解方程
$$\sqrt{3 - 5 \cos x - 7 \sin^2 x} + \cos x = 0.$$
4. 解决不平等问题

$\frac{1}{\lg 9}$真的是它的解吗？
5. 函数 $f$ 由以下公式给出
$$f(x) = a \ln x - 3x^2, \text{ где } a > 0.$$
a) 求函数$f$的最大值和单调区间；
