⟦folio 20⟧

英雄们又分析了十条路线。每条都有794公里长！你可以想象我们的英雄有多么尴尬。但如果他们知道对于给定的距离矩阵，所有旅行通常都具有相同的长度，他们会更加惊讶。

为什么？打开棺材很简单：所有数字 5 都是通过将数字 48、55、66、38、61、42、50 和 37 加在一起得到的。例如，在第三行中，总和为 66+48=114、66+55=121、0、66+38=104 等。因为在计算路线长度时，我们在时间，并且表 5 的每一行和每一列只有一个数字，那么任何类型的长度结果都等于预期数字总和的两倍（八个预期数字的总和为 397，794 = 397 × 2）。

问题出现了：是否不可能描述任意两轮具有相同长度的所有距离矩阵？事实证明，这是可能的：对于任何这样的矩阵，都需要找到数字$a_1, a_2, \dots, a_k$和数字$b_1, b_2, \dots, b_k$，使得从城市$x$到城市$y$（$x \neq y$）的距离$c_{xy}$等于总和$a_x + b_y$。

让我们以三个城市的情况来证明这个定理。

设 $c$ 为两轮每一轮的长度：
$$c = c_{12} + c_{23} + c_{31} = c_{13} + c_{21} + c_{32}.$$
让我们从这些关系中表达$c_{31}$和$c_{32}$：
$$c_{31} = c - c_{12} - c_{23},$$
$$c_{32} = c - c_{13} - c_{21}.$$
我们需要求解方程组
$$x_1 + y_2 = c_{12}, x_1 + y_3 = c_{13},$$
$$x_2 + y_1 = c_{21}, x_2 + y_3 = c_{23},$$
$$x_3 + y_1 = c - c_{12} - c_{23},$$
$$x_3 + y_2 = c - c_{13} - c_{21}.$$
我们给未知数$y_3$一个任意值$d$。那么从前五个方程可以发现$x_1 = c_{13} - d, x_2 = c_{23} - d, y_2 = c_{12} - c_{13} + d, y_1 = c_{21} - c_{23} + d,$
$$x_3 = c - c_{12} - c_{23} - c_{21} + c_{23} - d = c - d - c_{12} - c_{21}.$$
在这种情况下，也满足第六等式。输入$d = 0$，我们得到一组具有我们需要的属性的$a_1 = c_{13}, a_2 = c_{23}, a_3 = c - c_{12} - c_{21}, b_1 = c_{21} - c_{23}, b_2 = c_{12} - c_{13}, b_3 = 0$数字。

上述定理对于旅行推销员的分配理论研究来说是非常典型的。各种特殊情况在其中发挥着重要作用。 （所有旅行的长度一致也是一种特殊情况。但是，权重很窄。）对于特殊情况，有时不仅很难构建快速工作的方法（在这种情况下我们谈论的是可解的情况），而且找出最佳旅行可以有多少长度也是很困难的。

读者可以通过解决以下问题继续探索旅行商问题的可解决案例。在其中一些游戏中，决定在棋盘上旅行，棋子充当旅行推销员。在这种情况下，我们不会讨论旅行商的类型，而是讨论马、车等类型。棋子沿着棋盘的所有方格继续游览一次，并以返回到初始方格结束。
