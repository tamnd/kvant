c) 很容易检查对于任何 $n$
$$c_{n+1} \leq \frac{3}{2} c_n, c_{n+1} - 1 \geq \frac{3}{2} (c_n - 1).$$

波塞托姆
$$\frac{c_n - 1}{(3/2)^n} \leq \frac{c_{n+1} - 1}{(3/2)^{n+1}} < \frac{c_{n+1}}{(3/2)^{n+1}} \leq \frac{c_n}{(3/2)^n}.$$

线段 $\left[ \frac{c_n - 1}{(3/2)^n}; \frac{c_n}{(3/2)^n} \right]$ 的长度等于 $(2/3)^n$， - 它
趋向于零，即 $n \to \infty$，因此所有这些线段都有一个共同点。让我们用$\gamma$来表示它。

从$\gamma$的定义可以得出$(3/2)^n \gamma \in [c_n - 1; c_n]$。
此外，对于任何 $N$ 来说，等式 $(3/2)^N \gamma = c_N$ 都是不可能的：由此可以得出，$(3/2)^n \gamma = c_n$ 对于任何
整数 $n \geq N$，或 $c_{n+1} = \frac{3}{2} c_n$ 对于任何整数 $n \geq N$，

这与上面所说的相矛盾。这意味着$[(3/2)^n \gamma] = c_n - 1$，这就是需要证明的。

在解决这个问题时，我们使用了可收缩线段的重要原理，根据该原理，平面线段的顺序
$$[a_1; b_1] \supset [a_2; b_2] \supset [a_3; b_3] \supset \dots,$$

长度$|a_n - b_n|$趋于0，我们总是有一个唯一的实数；该原则（或任何等效原则）被视为公理。它清楚地表达了数轴“密度”的非常特殊的性质，即它没有“孔”。这个原理可以根据单调有界序列极限的维尔斯特拉斯定理来证明。

在我们的问题中，很容易指出前几个$n$的第$n$线段的右端，从而近似计算$\gamma$；例如，有两位小数：$\gamma \approx 0,81$。

**M481。在自然数序列$a_1, a_2, a_3, \dots$中，每一项$a_{k+1}$等于数字$b$的十进制数$a_k (k \geq 1)$的平方和。让我们证明，对于任何 $a_1$，数字 1 或数字 89 都会以这个序列结束。**

很明显，对于足够大的 $x$，数字 $x$ 的数字的平方和（我们将其表示为 $f(x)$）明显小于数字 $x$ 本身。所以，如果$x$是一个四位数，即$10^3 \leq x < 10^4$，那么$f(x) \leq 4.9^2 = 364 < 10^3 \leq x$。一般来说，如果$10^{n-1} \leq x < 10^n$和$n > 3$，则$f(x) \leq 81n < 10^{n-1}$。 （最后一个不等式很容易通过归纳法证明：$81n < 10^{n-1} \Rightarrow 81 (n + 1) = 81n + 81 < 10^{n-1} + 81 < 10^n$。）让我们证明，对于任何三位数$x$，也存在$f(x) < x$。如果数字$x$的第一位数字等于$p > 1$，则$f(x) < p^2 + 2 \cdot 81 = 162 + p^2 < 100p$（这对于每个$p = 2, 3, 4, \dots, 9$很容易验证）。如果第一个数字 $x$ 是 1，第二个数字 $q$，则 $f(x) \leq 1 + q^2 + 81 < 100 + 10q \leq x$ 对于任何 $q = 1, 2, \dots, 9$。
