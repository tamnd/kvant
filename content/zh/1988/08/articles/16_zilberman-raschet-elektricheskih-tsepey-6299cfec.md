电路计算

A·R·齐伯曼

有多种方法可以计算由电池和电阻器组成的电路。它们中的几乎任何一个（具有简单的变量符号）也适用于电池和电容器电路。 （如果您对完整的数字有信心，那么您还可以计算任何交流电电路。）本文将研究两种使用电阻器和电容器计算直流电路的简单方法。

第一种方法适用于相对简单的电路。让我们给出一个由电池和几个电阻器组成的电路。对于电路分支中的计算，我们首先系统地简化电路，然后并联或串联电阻及其等效物。将电路简化到可以很容易找到其中的电流后，我们进行相反的过程，找到原始元件的电流。这个方法你从白发年级就已经很熟悉了。

让我们看几个例子。

问题1. 在图1所示电路中，求流经跳线AB的电流。

让我们用并联电阻 1 和 3 以及 2 和 4 替换为等效电阻来简化电路。结果是一个具有公共电阻的简单电路

$$R = \frac{R_1 R_3}{R_1 + R_3} + \frac{R_2 R_4}{R_2 + R_4}$$

和总电流

$$I = \frac{U}{R} = \frac{U}{R_1 R_3 + R_2 R_4}.$$

电阻1和3两端的电压相等，即$I_1:I_3 = R_3:R_1$。但是$I_1 + I_3 = I$。然后

$$I_1 = I \frac{R_3}{R_1 + R_3}, \quad I_3 = I \frac{R_1}{R_1 + R_3}.$$
同样地
$$I_2 = I \frac{R_4}{R_2 + R_4}, \quad I_4 = I \frac{R_2}{R_2 + R_4}.$$
现在让我们找到通过跳线$AB$的电流：
$$I_{AB} = I_1 - I_2 = \frac{U(R_2R_3 - R_1R_4)}{R_1R_3(R_2 + R_4) + R_2R_4(R_1 + R_3)}.$$
从结果表达式可以清楚地看出，在条件 $R_1:R_2=R_3:R_4$ 下，通过跳线的电流为零。这通常用于精确测量未知电阻。
所考虑的方法虽然简单，但是非常麻烦。此外，它不是通用的——并不是每个方案都可以这样简化。例如，如果将 图 1 上的跳线替换为电阻，则所得电路既不包含并联电阻，也不包含串联电阻。
第二种更方便的计算方法是基于对随后编译的方程的未知数的合理选择。
考虑包含电阻器和电流源 (图 2) 的电路的无分支部分。根据能量守恒定律，该段电流等于
$$I = \frac{\varphi_A - \varphi_B - \mathcal{E}}{R + r},$$
由此可以清楚地看出，要找到每个分支中的电流，只要知道其末端的电势（更准确地说，电势差）就足够了。链的无分支部分的连接点称为节点，因此该方法的名称为节点势法。
因此，我们选择电路节点的电势作为未知量。将其中之一的电位设置为任意 - 相等是很方便的

让我们以这个问题为例。
任务 2. 求通过连接到电动势 $\mathcal{E}_1$ 和 $\mathcal{E}_2$ 以及内阻 $r_1$ 和 $r_2$ (图 3) 的并联电池的电压 $R$ 的电流。
我们重新绘制一下图 4 所示的图，并设置$\varphi_A = 0$。现在只需设置$B$点的电位即可表示电路中的所有电流。对于节点$B$：
$$\frac{\mathcal{E}_1 - \varphi_B}{r_1} + \frac{\mathcal{E}_2 - \varphi_B}{r_2} = \frac{\varphi_B}{R},$$
$B$点的势能从何而来？
$$\varphi_B = \frac{\mathcal{E}_1/r_1 + \mathcal{E}_2/r_2}{1/r_1 + 1/r_2 + 1/R},$$
和电压电流
$$I = \frac{\varphi_B}{R} = \frac{\mathcal{E}_1 r_2 + \mathcal{E}_2 r_1}{R(r_1 + r_2) + r_1 r_2}.$$

问题3. 在图 5所示电路中，求A点和B点之间的电阻。

最简单的思考方法是：将具有给定电压 U 的电池连接到这些点，找到通过电池的电流，并使用公式 $R = U/I$ 计算总电阻。让我们画出结果图 (图 6) 并放入 $\varphi_A = 0$。则已知 B 点的电势：$\varphi_B = U$。让我们用 $\varphi_1$ 表示 C 点的电势，用 $\varphi_2$ 表示 D 点的电势。我们为节点 C 写两个方程：

$$-(U - \varphi) C_1 + \varphi C_2 + \varphi C_3 = 0,$$

从哪里$\varphi = \frac{C_1 U}{C_1 + C_2 + C_3}.$
