$$OQ = \frac{d}{2(2m+1)} \text{ и } PQ = \sqrt{QA \cdot QC} = \frac{d\sqrt{m(m+1)}}{2m+1},$$

我们发现三角形的平方

$$BO - PQ = \frac{d}{2} \left(1 - \frac{2\sqrt{m(m+1)}}{2m+1}\right) = \frac{d(2m+1 - 2\sqrt{m(m+1)})}{2(2m+1)} = \frac{OQ}{2m+1 + 2\sqrt{m(m+1)}} \leq \frac{OQ}{3 + 2\sqrt{2}} < \frac{OQ}{2}.$$

M1097。等边三角形的顶点坐标是整数。证明底数的平方是偶数。

平行地，与给定的三角形$ABC$相交，其中$AB = BC$，使得顶点$A$落在原点。那么顶点$B$和$C$的坐标$(b_1, b_2)$和$(c_1, c_2)$将保持不变。根据用坐标写成的等式$AB^2 = BC^2$：

$$b_1^2 + b_2^2 = (b_1 - c_1)^2 + (b_2 - c_2)^2,$$

由此可见 $AC^2 = c_1^2 + c_2^2 = 2(b_1c_1 + b_2c_2)$ 是偶数。

M1098。圆上有 $n$ 个点，连续编号为 1、2、...、$n$。两个划入下一个山脉。每个人轮流画一条和弦，将点与四分之一的数字连接起来。每个和弦不应与之前绘制的那些有公共点（远端）。发出最后一个和弦的人获胜。找出哪位玩家（初学者或其搭档）有获胜策略（每个$n = 4, 5, 6, 7, \dots$）。

答案：当$n$是4的倍数，以及当$n$是奇数时，第一个（起始）玩家获胜，当$n = 4k + 2$（$k$整数）时，第二个玩家获胜。

可以方便地假设偶数点和奇数点由不同的颜色（例如白色和黑色）表示，并且这些点将圆分成相等的部分。

在所有情况下，获胜策略的主要思想是利用对称性。

第一个玩家在 $n = 4k$ 的策略是通过移动检查直径，然后通过绘制相对于该直径对称的弦来响应第二个玩家的每个移动 - 请参阅图 1。（这样的移动是可能的，因为第一个玩家的每次移动之后，位置将相对于直径对称。这里重要的是，直径相对的点具有相同的颜色，并且相对于点的直径对称 -也是。）
