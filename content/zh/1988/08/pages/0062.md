$$I = \frac{\mathcal{E}_{\text{экв}}}{R + r_{\text{экв}}}.$$

如果它有效，那么这将是这两个问题的答案。在我们的例子中，一切都很简单：

$$I = \frac{(\mathcal{E}_1 r_2 + \mathcal{E}_2 r_1) / (r_1 + r_2)}{R + r_1 r_2 / (r_1 + r_2)},$$

$$\mathcal{E}_{\text{экв}} = \frac{\mathcal{E}_1 r_2 + \mathcal{E}_2 r_1}{r_1 + r_2}, \quad r_{\text{экв}} = \frac{r_1 r_2}{r_1 + r_2}.$$

（请注意，通过两根电线连接到外部电路的任何电池和电阻器系统都可以用等效电池代替。这一点的证明超出了学校课程的范围。）

现在让我们解决一个更复杂的问题。

问题3. 在图 5所示电路中，求A点和B点之间的电阻。

最简单的思考方法是：将具有给定电压 U 的电池连接到这些点，找到通过电池的电流，并使用公式 $R = U/I$ 计算总电阻。让我们画出结果图 (图 6) 并放入 $\varphi_A = 0$。则已知 B 点的电势：$\varphi_B = U$。让我们用 $\varphi_1$ 表示 C 点的电势，用 $\varphi_2$ 表示 D 点的电势。我们为节点 C 写两个方程：

$$-(U - \varphi) C_1 + \varphi C_2 + \varphi C_3 = 0,$$

从哪里$\varphi = \frac{C_1 U}{C_1 + C_2 + C_3}.$
