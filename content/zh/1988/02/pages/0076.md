1. $k = 1$（$A = B$）或$k = 100$（$B = 0$）。解决方案。令 $k = (100A + B)/(100B + A)$ 为整数。显而易见的答案是$k = 1$，$A = B$。让$k \neq 1$，$A \neq B$。然后$A/B = (100k - 1)/(100 - k)$；数$k \neq 100$。是否可以减少分数$(100k - 1)/(100 - k)$，使分子和分母都小于100？如果可能的话，分数$(100k - 1)/(100 - k) - 1 = 101(k - 1)/(100 - k)$也可以用类似的方式减少。但是 100-k 和 101 没有公约数，因为 101 是素数，并且 100-k < 100。因此，约简后我们得到了 $101 \cdot a/b$ 形式的不可约分数，其分子大于 100 - 这是一个矛盾。剩下的情况就是$k = 100$，对于$B = 0$。

2. $104^2 + 72^2 = 120^2 + 40^2 = 16000$。解决方案。偶数的平方能被4整除，奇数的平方除以4余数为1。因此，如果$x^2 + y^2 = 16000$，则$x = 2m, y = 2n$。然后是$m^2 + n^2 = 4000$，类似的还有$m = 2m_1$、$n = 2n_1$、$m_1^2 + n_1^2 = 1000$、$m_1 = 2m_2$、$n_1 = 2n_2$、$m_2^2 + n_2^2 = 250 = 4 \cdot 62 + 2$。这意味着$m_2$和$n_2$都是奇数，并且如果$m_2 \geq n_2$则$125 \leq m_2^2 < 250$。然而，在这个间隙中正好有两个奇数的方格：$m_2 = 13$和$m_2 = 15$。这给出了一个简单的答案。

3. $x = 2$、$y = 1$、$z = 3$。笔记。所有方程之和得出等式 $x^2 + y^2 + z^2 + 2z^2 + x^2 + zx^2 = 48$，打开括号并考虑计算出的等式后，它们的乘积得出 $(xyz)^2(48 + 2xyz) = 2160$。记作$t = xyz$，我们得到三次方程$t^3 + 24t^2 - 1080 = 0$，其根为$t_1 = 6$。方程$t^3 + 24t^2 - 1080 = (t - 6)(t^2 + 30t + 180) = 0$还有两个根：$t_2, t_3 = -15 \pm 3\sqrt{5}$，这不适合我们，因为我们正在寻找系统的正解。通过替换$xy = \frac{6}{z}$、$yz = \frac{6}{x}$、$zx = \frac{6}{y}$，将原始系统简化为线性系统，由此得到$y = x/2$、$z = 3x/2$。
