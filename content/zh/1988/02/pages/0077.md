10. 当其中一项等于 999 时，总和 $\frac{a}{c} + \frac{b}{d}$ 最大。解。让$\frac{a}{c} \geq \frac{b}{d}$。那么$\frac{b}{d} \leq \frac{a+b}{c+d} \leq \frac{a}{c}$，即$\frac{b}{d} \leq 1$。让$a \leq 998$，然后$\frac{a}{c} \leq 998$，所以$\frac{a}{c} + \frac{b}{d} \leq 999$。但如果$\frac{a}{c} = 999$（在$a = 999$、$c = 1$），则$\frac{a}{c} + \frac{b}{d} > 999$。

11. $0,9 < x_1 < 1; -1,1 < x_2 < -1; -1000 < x_3 < -999,9$。解决方案。 $f(x) = 0,001x^3 + x^2 - 1 = f_1(x) + f_2(x)$，其中$f_1(x) = 0,001x^3, f_2(x) = x^2 - 1$。 $f_2(x) = 0$的根是$(+1)$和$(-1)$，以及$|x| < 2, |f_1(x)| < 0,01$。因此，两个根$f(x)$等于$x_1 \approx +1, x_2 \approx -1: f(+1) = 0,001 > 0, f(0,9) < 0 \Rightarrow 0,9 < x_1 < 1$，同样，$-1,1 < x_2 < -1$。现在让我们注意到方程 $0,001x^3 + x^2 = 0$ 有一个根 $(-1000)$、$f(-1000) = -1 < 0$ 和 $f(-999,9) > 0$，因此有 $-1000 < x_3 < -999,9$。
