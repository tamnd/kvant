移动立方体$\Delta x_2$。我们有
$$\Delta x_2 = \Delta x_1 \text{tg} \alpha.$$
将等式两边同时除以$\Delta t$，我们得到
$$v_2 = v_1 \text{tg} \alpha.$$
由于该对应关系在任意时刻都有效，因此可以得出所需的对应关系
$$a_2 = a_1 \text{tg} \alpha.$$ (3)
我们将这种获得运动学连接的方法称为直接方法。
2) 获得必要连接的另一种方法是基于切换到当前的报告系统，其中联系条件变得微不足道。在与识别相关的报告系统中（参见图 1, 6），立方体$\vec{v}_{\text{отн}}$的速度沿着其表面，即与垂直方向成$\alpha$角度。写出速度加法定律
$$\vec{v}_2 = \vec{v}_{\text{отн}} + \vec{v}_1$$
从相应的向量三角形我们得到
$$v_2 = v_1 \text{tg} \alpha, \text{и } a_2 = a_1 \text{tg} \alpha.$$
我们一起求解方程（1）—（3）并发现
$$a_1 = \frac{m_1}{m_1 + m_2 \text{tg}^2 \alpha} g,$$
$$a_2 = \frac{m_1 \text{tg} \alpha}{m_1 + m_2 \text{tg}^2 \alpha} g.$$
在这个问题中，第二种方法看起来有些人为。然而，在某些情况下，正确选择报告系统可以显着简化运动通信问题。这是一个例子。
问题 2. 一个高度为 $h$、倾斜角为 $\alpha$ 的楔子立在水平面 (图 2) 上。楔块质量$m_1$。从楔子的顶部开始

允许质量为 $m_2$ 的块无摩擦地滑动。求楔块的加速度和木块的滑动时间。
让我们从牛顿第二定律开始。让我们以向量形式写下楔形在水平方向上的投影，以及条形的投影：
$$N \sin \alpha = m_1 a_1,$$
$$\vec{N}_{21} + m_2 \vec{g} = m_2 \vec{a}_2.$$ (5)
和以前一样，$\vec{N}_{12} = -\vec{N}_{21}, N_{12} = N$。块体轴线方向的选择与运动学连接问题的解决相关。
加速度之间的运动学关系应反映这样的事实：在运动过程中，块始终保持在楔块的表面上。事实证明，将其写成一个直接方程是很困难的。相反，让我们转到与楔子相关的报告系统。在该系统中，块的速度 $\vec{v}_{\text{отн}}$ 及其加速度 $\vec{a}_{\text{отн}}$ 沿着楔子定向。那么根据速度加法定律
$$\vec{v}_2 = \vec{v}_{\text{отн}} + \vec{v}_1$$我们得到加速度加法定律（见图2）
$$\vec{a}_2 = \vec{a}_{\text{отн}} + \vec{a}_1.$$ (6)
由此可见，从未知数$a_1$和$a_2$移动到未知数$a_1$和$a_{\text{отн}}$更加方便，从而解决了运动学连接问题。将式（6）代入式（5），并将该式投影到沿楔面方向和垂直于楔面方向，可得
$$m_2 g \sin \alpha = m_2 (a_{\text{отн}} - a_1 \cos \alpha),$$
$$N - m_2 g \cos \alpha = -m_2 a_1 \sin \alpha.$$ (5′′)
由式(4)、(5′′)可知
$$a_1 = \frac{m_2 \sin \alpha \cos \alpha}{m_1 + m_2 \sin^2 \alpha} g,$$
$$a_{\text{отн}} = \frac{(m_1 + m_2) \sin \alpha}{m_1 + m_2 \sin^2 \alpha} g.$$
