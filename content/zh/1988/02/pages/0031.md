M1067。证明对于满足条件 $x^2 + y^2 + z^2 = 1$ 的非负数 x, y, z，我们有不等式

$$\frac{x}{1-x^2} + \frac{y}{1-y^2} + \frac{z}{1-z^2} \geq \frac{3\sqrt{3}}{2}.$$

让我们证明一下

$$\frac{t}{1-t^2} \geq \frac{3\sqrt{3}}{2} t^2$$

与所有$t, 0 \leq t < 1$。在这个区间上，不等式(*)等价于不等式

$$f(t) = \frac{3\sqrt{3}}{2} t(1-t^2) \leq 1,$$

这是通过函数 $f(t)$ 的标准研究来证明的。 （导数$f'(t) = \frac{3\sqrt{3}}{2}(1-3t^2)$在[0; 1]上有唯一根$t = 1/\sqrt{3}$，并且$f(0) = f(1) = 0 < f(1/\sqrt{3}) = 1$。因此$1/\sqrt{3}$是$f(t)$在[0; 1]上的极大点。）。

凭借(*)，左边证明了不等式不等式，即

$$\frac{3\sqrt{3}}{2}(x^2 + y^2 + z^2) = \frac{3\sqrt{3}}{2};$$

只有在$x = y = z = 1/\sqrt{3}$时才能实现平等。
