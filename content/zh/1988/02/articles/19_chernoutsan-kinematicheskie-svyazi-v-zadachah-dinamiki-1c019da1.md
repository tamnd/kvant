动态问题中的运动连接

物理和数学科学候选人
A.I.切尔努特桑

在力学问题中，经常会出现身体运动不自由的情况。约束可以由硬表面、不可延伸的螺纹、刚性杆等创建。在最简单的情况下，我们会自动考虑这些约束，通常甚至不需要规定它们的存在。例如，我们引导平面上物体的加速度沿着平面（考虑到固体表面的存在），我们认为拖船和驳船的速度相同（考虑到牢不可破的电缆的存在）等。然而，有时有必要以特殊控制的形式表达这些限制，我们将其称为“运动学耦合”。让我们从这个任务开始吧。

问题1.求质量为$m_1$的棱柱和质量为$m_2$的立方体的加速度，如图1，​​a。第三个例子。

让我们写下每个物体的牛顿第二定律（投影到与相应加速度一致的方向）：

$$m_1 g - N \sin \alpha = m_1 a_1,$$

$$N \cos \alpha = m_2 a_2.$$

我们教的是根据牛顿第三定律，$\vec{N}_{12} = -\vec{N}_{21}$，即$N_{12} = N_{21} = N$。写出的两个方程包含三个未知数。第三个方程，$a_1$和$a_2$之间的运动学关系，应该反映立方体和棱柱始终保持相互接触的事实。这可以通过多种方式来完成。

1) 让我们考虑系统的两个接近位置，间隔时间间隔 $\Delta t$ (图 1, 6)。在三角形$ABC$中，边$AB$等于棱镜变量$\Delta x_1$，边$BC$等于

移动立方体$\Delta x_2$。我们有
$$\Delta x_2 = \Delta x_1 \text{tg} \alpha.$$
将等式两边同时除以$\Delta t$，我们得到
$$v_2 = v_1 \text{tg} \alpha.$$
由于该对应关系在任意时刻都有效，因此可以得出所需的对应关系
$$a_2 = a_1 \text{tg} \alpha.$$ (3)
我们将这种获得运动学连接的方法称为直接方法。
2) 获得必要连接的另一种方法是基于切换到当前的报告系统，其中联系条件变得微不足道。在与识别相关的报告系统中（参见图 1, 6），立方体$\vec{v}_{\text{отн}}$的速度沿着其表面，即与垂直方向成$\alpha$角度。写出速度加法定律
$$\vec{v}_2 = \vec{v}_{\text{отн}} + \vec{v}_1$$
从相应的向量三角形我们得到
$$v_2 = v_1 \text{tg} \alpha, \text{и } a_2 = a_1 \text{tg} \alpha.$$
我们一起求解方程（1）—（3）并发现
$$a_1 = \frac{m_1}{m_1 + m_2 \text{tg}^2 \alpha} g,$$
$$a_2 = \frac{m_1 \text{tg} \alpha}{m_1 + m_2 \text{tg}^2 \alpha} g.$$
在这个问题中，第二种方法看起来有些人为。然而，在某些情况下，正确选择报告系统可以显着简化运动通信问题。这是一个例子。
问题 2. 一个高度为 $h$、倾斜角为 $\alpha$ 的楔子立在水平面 (图 2) 上。楔块质量$m_1$。从楔子的顶部开始

允许质量为 $m_2$ 的块无摩擦地滑动。求楔块的加速度和木块的滑动时间。
让我们从牛顿第二定律开始。让我们以向量形式写下楔形在水平方向上的投影，以及条形的投影：
$$N \sin \alpha = m_1 a_1,$$
$$\vec{N}_{21} + m_2 \vec{g} = m_2 \vec{a}_2.$$ (5)
和以前一样，$\vec{N}_{12} = -\vec{N}_{21}, N_{12} = N$。块体轴线方向的选择与运动学连接问题的解决相关。
加速度之间的运动学关系应反映这样的事实：在运动过程中，块始终保持在楔块的表面上。事实证明，将其写成一个直接方程是很困难的。相反，让我们转到与楔子相关的报告系统。在该系统中，块的速度 $\vec{v}_{\text{отн}}$ 及其加速度 $\vec{a}_{\text{отн}}$ 沿着楔子定向。那么根据速度加法定律
$$\vec{v}_2 = \vec{v}_{\text{отн}} + \vec{v}_1$$我们得到加速度加法定律（见图2）
$$\vec{a}_2 = \vec{a}_{\text{отн}} + \vec{a}_1.$$ (6)
由此可见，从未知数$a_1$和$a_2$移动到未知数$a_1$和$a_{\text{отн}}$更加方便，从而解决了运动学连接问题。将式（6）代入式（5），并将该式投影到沿楔面方向和垂直于楔面方向，可得
$$m_2 g \sin \alpha = m_2 (a_{\text{отн}} - a_1 \cos \alpha),$$
$$N - m_2 g \cos \alpha = -m_2 a_1 \sin \alpha.$$ (5′′)
由式(4)、(5′′)可知
$$a_1 = \frac{m_2 \sin \alpha \cos \alpha}{m_1 + m_2 \sin^2 \alpha} g,$$
$$a_{\text{отн}} = \frac{(m_1 + m_2) \sin \alpha}{m_1 + m_2 \sin^2 \alpha} g.$$

要回答问题的第二个问题，我们不需要寻找$a_2$，因为滑动时间精确地用$a_{\text{отн}}$表示：

$$\frac{a_{\text{отн}} t^2}{2} = \frac{h}{\sin \alpha}.$$

从这里开始是

$$t = \sqrt{\frac{2h}{a_{\text{отн}} \sin \alpha}} = \sqrt{\frac{2h(m_1 + m_2 \sin^2 \alpha)}{(m_1 + m_2) \sin^2 \alpha g}}.$$

如前所述，对运动的限制不仅可以通过所考虑的物体的直接接触来确定，还可以通过系统中存在的连接元件（杆、螺纹等）来确定。在大多数情况下，即使在条件中没有指定，连接元件也被认为是理想的，即螺纹 - 失重且不可拉伸，杆 - 失重且绝对刚性，对于块而言，除了失重之外，还假设轴没有摩擦。 （事实上​​，“失重”一词意味着与系统中其他物体的质量相比，给定元素的质量可以忽略不计，“无质量”一词意味着与系统物体的运动相比，元素的移除很小，等等。）在查看具体示例之前，让我们看看理想的连接元素会产生什么结果。让我们考虑三种特殊情况。

1. 线失重。让我们为质量为 $\Delta m_{\text{н}}$ (图 3, a) 的螺纹段写出牛顿第二定律：

$$T - T' = \Delta m_{\text{н}} a.$$

由于$\Delta m_{\text{н}} = 0$，则$T = T'$，即张力沿线不变。

2. 移动块失重且其轴上没有摩擦。要松开没有摩擦力的失重块，不需要扭矩。由此可见，同一根线在块两侧的张力是相同的（图3，b），此外还有$T' - 2T = 0$，即$T' = 2T$。

3. 杆失重。该条件意味着作用在杆上的力的总和和力矩的总和等于零。例如，如果两个力施加到一根杆上，则它们模数相等、方向相反并沿杆作用 (图 3, c)。 （与线不同，杆不仅可以拉伸，还可以弯曲。）

螺纹和杆的不可延伸性和刚性导致了运动连接的出现，我们将在下面的任务中单独分析。

最后的声明需要承诺。可以证明，即使非常刚性的杆（或其他元件）发生很小的变形，其变形$E_p = kx^2/2$的势能也可能很大 - 毕竟，它与杆$k$的刚度成正比。但如果我们考虑到变形过程中产生的力$F = kx$仍然有限，为$k \rightarrow \infty$（由附着在杆上的物体的运动决定），那么在$k$处的势能$E_p = F^2/(2k)$就会非常小。

由能量守恒定律我们得到

$$mg(l-y) = \frac{mv_1^2}{2} + \frac{mv_2^2}{2},$$

(16)

其中$y = l \sin \alpha$是第二个载荷在力矩距离处的坐标。要获得运动学连接，您可以使用直接方法，如上一个任务中所做的那样（自己做）。从这些消息中可以获得更快、更顺畅的运动通信。由于负载之间的距离保持不变，因此在每个时刻，第一个负载“远离”第二个负载的速度等于第二个负载“接近”第一个负载的速度。换句话说，任何时刻杆上负载速度的投影都是相同的（参见 图 7, a）：

$$v_1 \cos \alpha = v_2 \sin \alpha.$$

(17)

将式(17)代入式(16)可得

$$v_1 = \sqrt{2gl \sin^2 \alpha (1 - \sin \alpha)},$$

$$v_2 = \sqrt{2gl \cos^2 \alpha (1 - \sin \alpha)}.$$

在刚体运动学中，经常使用将复杂运动“分解”为平移和旋转。为了演示该方法，我们应用它来获得运动学关系（17）。在与第一负载相关的参考系中，杆执行纯旋转运动。这意味着在该系统中，第二个负载$v_{0\mathrm{T}}$的速度垂直于杆。应用速度$v_2 = v_{0\mathrm{T}} + v_1$加法定律（参见图7，b），我们得到对应关系（17）。

看起来找到的速度表达式提供了问题的完整解决方案。然而，这个问题包含了一个互惠的方法，我们将详细分析。

如果第二重物不能从垂直墙上撕下来，那么解决方案就完成了。 （为此，例如，可以将重物放置在光滑的软管上，并且杆应铰接在其上）。然而，在我们的问题版本中（参见 图 7, a），在某个角度，第二个荷载将与垂直墙分离，之后找到的答案将不适用。事实上，系统的水平动量仅由第一载荷的运动决定，其速度根据$v_1$的表达式增加到一定角度，然后开始减小。这意味着在某个时刻作用在系统上的外部水平力必须改变方向。但只有一种水平力——垂直墙的反作用力，它不能改变其方向。因此，在墙壁的反作用力变为零的时刻，第二载荷与墙壁分离。将$v_1$的表达式对时间求导，我们发现$v_1$在$\sin \alpha = 2/3$处达到最大值。以 $\alpha = \arcsin (2/3)$ 的角度，杆将从垂直壁上脱离。
