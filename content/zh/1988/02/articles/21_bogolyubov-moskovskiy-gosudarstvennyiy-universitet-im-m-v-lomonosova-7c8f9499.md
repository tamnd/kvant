我们将寻找圆锥体 $SO$ 的高度作为线段 $SP$、$PL$ 和 $LO$ 的长度之和。从直角三角形$PLA$
$$PL = \sqrt{PA^2 - LA^2} = \sqrt{PA^2 - OM^2},$$
通过将球投影到圆锥体底面的平面上，我们发现线段$OM$的值与第一个问题完全相同（参见图1）。我们得到$PL = 2r\sqrt{6}/3$。

由三角形$SEP$和$PLA$的相似性
$$SP = \frac{PE \cdot PA}{LA} = r\sqrt{3}.$$
从$LO = r$开始，最终结果为$SO = r(\sqrt{3} + 2\sqrt{6}/3 + 1)$。

1. 公式$\frac{a}{c} = \frac{b}{d} \left(2 - \frac{b}{d}\right)$可以简化为$\frac{a}{c} = 1 - \left(\frac{b}{d} - 1\right)^2$的形式。由于任何数字的平方都是非负数，因此公式右侧不大于 1，因此 $a \leq c$ （和 $c$ 是正数）。

2. 原来的等式$\frac{a}{b} - \frac{c}{d} = \frac{a-c}{b-d}$可以简化为以下形式

$$ad^2 = 2bcd - b^2c.$$

(1) 通过反证法设$(a, b) = 1$和$(c, d) = 1$（符号$(x, y)$表示数字$x$和$y$的最大公约数）。让我们用$(a, c) = A, (b, d) = B$来表示它。然后是$a = aA, c = cA, b = bB, d = dB$，其中$(a, c) = 1$和$(b, d) = 1$。将这些表达式代入(1)，然后减少$AB^2$，我们得到

$$\bar{a}\bar{d}^2 = 2\bar{b}\bar{c}\bar{d} - \bar{b}^2\bar{c}.$$

右边能被$b$整除。因此$\bar{a}\bar{d}^2$可以被$b$整除。但是$(\bar{a}, \bar{b}) = 1$和$(\bar{d}^2, \bar{b}) = 1$。因此，$\bar{b} = 1$。同理，证明$\bar{d} = 1$。因此$b = d$，并且根据（1），$a = c$。但后来

$$\frac{a}{b} - \frac{c}{d} = \frac{a}{b} - \frac{a}{b} \neq \frac{a-a}{b-b},$$

因为你不能除以零。

$$\frac{ab}{bc} = \frac{10a+b}{10b+c} = \frac{a}{c}.$$

从这里

$$9ac = 9ab + b(a-c).$$

(2) 因此，$b(a-c)$能被9整除。由于$a$和$c$都是非零数字，所以$|a-c| \leq 8$。因此，$a-c=0$ 或$b$ 都可以被 3 整除。在第一种情况下，从 (2) 可以看出，$b=a$ 是相同的。残差如下： a) $b=3, c = \frac{10a}{3a+1}$； b）$b=6; c = \frac{20a}{3a+2}$； c) $b=9; c = \frac{10a}{a+1}$。
