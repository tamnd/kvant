问题的解决方案
M1070, M1072—M1075,*) F1084—F1087

我们将考虑四边形的几个正交投影，并利用以下事实：三角形沿边或沿中线的投影和平行四边形沿边或对角线的投影都是线段，其长度以相应图形的面积和边、中线或对角线的长度表示（图1）。

设ABCD(图2)。每个割平面都穿过其 4 条边的中点，因此沿着由面的中线界定的平行四边形与其相交。平行于边 DA、DB、DC 的截面面积用 $s_a$、$s_b$、$s_c$ 表示，面 ABC、BCD、CDA、DAB 的面积用 $S_D$、$S_A$、$S_B$、$S_C$ 表示。让我们沿着边缘 CD (图 3) 投影 tegradr。结果是一个三角形 ABC（我们对点项目和点本身保留相同的名称）。让我们在其中画出与 AB 平行的中线 KL（这是截面 $s_c$ 的投影）和中线 CM（这是我们 tegradr 的三角形截面 CDM 的投影；M 是边 AB 的中点）。在平行四边形 CLMK (图 3) 中，边和对角线相等

$$CL = KM = CB / 2 = S_A / l,$$
$$CK = LM = CA / 2 = S_B / l,$$
$$KL = 2s_c / l, \quad CM = 2S_1 / l,$$

其中$l = CD$、$S_1$是$\triangle CDM$的面积。写出 CLMK 的“平行四边形等式”（对角线的平方和等于边的平方和），我们得到

$$2(S_A^2 + S_B^2) = 4s_c^2 + 4S_1^2.$$

等式用类似的方法证明

$$2(S_C^2 + S_D^2) = 4s_c^2 + 4S_2^2,$$

其中$S_2$是穿过边CD中间N的三角形截面ABN的面积。最后，我们沿其“中线”MN (图4) 正交投影 tegradr。结果是平行四边形 ACBD（对角线 AB 和 CD 相交，分为两半）。该平行四边形的对角线是三角形截面$S_1$和$S_2$的投影，即$AB = 2S_2 / m$、$CD = 2S_1 / m$，其中$m = MN$，中间的线是截面$s_a$和$s_b$的投影，并且，由于边是中线，$AD = 2s_a / m$， $AC = 2s_b / m$。让我们再次使用平行四边形等式：

$$2(4s_a^2 + 4s_b^2) = 4S_1^2 + 4S_2^2.$$

根据(1)、(2)、(3)，问题的表述如下：

$$S_A^2 + S_B^2 + S_C^2 + S_D^2 = 4(s_a^2 + s_b^2 + s_c^2).$$
