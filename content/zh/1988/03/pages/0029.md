F1084。如果将镍币按在冷冻的玻璃上一段时间，玻璃上就会沿着镍币的边缘融化一个圆圈。为什么？

当我们将镍币压在玻璃上时，它会从我们的手上加热。它加热并融化霜。硬币主要在边缘接触，那里变厚。硬币的其余部分和霜之间有一个气隙。空气的导热系数远小于金属的导热系数。因此，它首先“变暖”并沿着环、沿着硬币的边缘解冻。此后，硬币“躺在”其整个表面上，并且硬币的整个区域都发生熔化。

F1085。 图 1 描述了对理想气体执行的过程并将其从状态 B 转移。在图表上找到气体温度升高（降低）的过程部分。

让我们考虑曲线上过程中两个相当接近的点$C$和$D$，并写出从点$C$过渡到点$D$期间气体温度变化的表达式：

$$\Delta T_{CD} = T_C - T_D = \frac{M}{mR}((p + \Delta p)(V + \Delta V) - pV) \approx \frac{M}{mR}(p \cdot \Delta V + V \cdot \Delta p).$$

令 $\Delta T_{CD} \approx 0$ （这意味着点 $C$ 和 $D$ 位于同一条等温线上，或者在转变过程中 $C \rightarrow D$ 气体温度经过极值（最大值或最小值））。然后

$$\frac{p}{V} = -\frac{\Delta p}{\Delta V}.$$

(*)

从 图 1 可以清楚地看出 $\frac{p}{V} = \text{ctg } \alpha$，并且在足够近的点 $C$ 和 $D$

$$\frac{\Delta p}{\Delta V} = \text{tg } \beta' \approx \text{tg } \beta'' \approx \text{tg } \beta = -\text{ctg } \gamma.$$

因此，从 (*) 可以得出

$$\text{ctg } \alpha = \text{ctg } \gamma, \text{ или } \alpha = \gamma.$$

现在让我们假设在曲线上的某个点$AB$$\alpha < \gamma$。然后$\text{ctg } \alpha > \text{ctg } \gamma$，并以相反的顺序重复上述推理，我们得到$\Delta T_{CD} > 0$。因此，气体经过该点时温度升高。反之亦然：如果在某个点$\alpha > \gamma$，则$\Delta T_{CD} < 0$，并且在这种情况下气体温度会降低。

在图上找到点$M_1$、$M_2$和$M_3$，其中$\alpha = \gamma$（参见图2），我们发现在过程部分$AM_1$和$M_2M_3$，其中$\alpha < \gamma$，气体温度升高，在部分$M_1M_2$和$M_3B$ ($\alpha > \gamma$) - 减少。
