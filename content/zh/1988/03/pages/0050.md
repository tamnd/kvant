比例系数等于其组成函数的比例系数的乘积的线性函数。

确实，让
$$F(x) = f(g(x)) \text{ и } f(x) = k_1 x + b_1, \quad g(x) = k_2 x + b_2.$$
然后
$$F(x) = k_1 (k_2 x + b_2) + b_1 = k_1 k_2 x + k_1 b_2 + b_1 = kx + b,$$
其中$k = k_1 k_2, b = k_1 b_2 + b_1$。

显然，对于由任意数量的线性函数组成的复杂函数，该陈述成立。

线性函数的图

定理。线性函数$y = kx + b$的图像是一条直线。

读者可以使用类似的直角三角形轻松证明该定理。然而，在不使用细分理论的情况下，依靠线性函数的单调性构造证明并不困难。

设$y = kx + b$，我们将考虑图表上横坐标为$0, x_1, 2x_1, 3x_1, \dots$的点。让我们证明这些点位于同一条线上。证明的思想从图 1 就很清楚了。所有粉红色三角形都是相等的，并且所考虑的级数中任意点的角度之和为$180^\circ$，因为直角三角形的锐角之和为$90^\circ$，并且直线上每个点的第三个角。因此，三角形的斜边彼此连续并形成一条直线。同理，图中横坐标为$0, x_1/n, 2x_1/n, \dots, nx_1/n$的点位于一条直线上，并且与上一张图重合，或者包含横坐标为$x_1 = nx_1/n$的点。自然数$n$可以取尽可能大的值，使得找到的直线$L$包含图上横坐标尽可能密集的点。

让我们证明图形的所有点都位于同一条直线 $L$ 上。我们假设图形的点 $(x_0, y_0)$ 位于直线 $L$ 上方。 （如果该点位于下方，则推理类似。）然后，和之前一样，我们将确保在连接点$(0, b)$和点$(x_0, y_0)$的直线$L'$上，横坐标为$0, x_0/m, 2x_0/m$，...的图形点尽可能密集。因此，在这个假设下，函数$y = kx + b$的图像上的点将尽可能“共轭”从线$L$到线$L'$的部分，但由于线性函数的单调性，这是不可能的。因此，图表上的任何点都位于先前构建的线上。

相反，这条线的任何点$(x_2, y_2)$都属于图$y = kx + b$。事实上，点$(x_2, kx_2 + b)$是图上的一个点，并且根据已经证明的事实，它属于一条直线，并且因为在不平行于纵坐标轴的直线上只有一个点的横坐标为$x_2$，然后是$y_2 = kx_2 + b$。

由上面证明的定理可知，正比例图（$b=0$）是一条过原点的直线。

在解决问题时，人们常常不得不求助于线性函数图定理的逆：任何不平行于纵坐标轴的直线都是某个线性函数的图。

让我们证明一下。

让这条线穿过点 $(x_0, y_0)$ 和 $(x_1, y_1)$，其中 $x_0 \neq x_1$ (图 2)。您始终可以选择 $y = kx + b$ 形式的方程，其中将求解数字对 $(x_0, y_0)$ 和 $(x_1, y_1)$：

$$\begin{cases} y_0 = kx_0 + b, \\ y_1 = kx_1 + b. \end{cases}$$

为此，只需将
$$k = \frac{y_0 - y_1}{x_0 - x_1}, \quad b = y_0 - \frac{y_0 - y_1}{x_0 - x_1} x_0.$$
直线 - 线性函数的图形
$$y = \frac{y_0 - y_1}{x_0 - x_1} x + y_0 - \frac{y_0 - y_1}{x_0 - x_1} x_0 -$$
经过点$(x_0, y_0)$和$(x_1, y_1)$；这是唯一一条穿过这两点的线，也就是说它与这条线重合，这就证明了我们的说法。
