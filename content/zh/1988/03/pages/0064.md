解决方案。让我们考虑一下我们自己的 prima 部分（图 2 和 3）。根据问题的条件，自 $d > 0$ 起，点 $P$ 位于点 $S$ 的高度或其延长线上，但与点 $S$ 不重合。让我们用$AD = a, SO = h$来表示它。然后$AO = \frac{a}{\sqrt{2}}, h = \frac{a \text{ ctg } \alpha}{\sqrt{2}}$。点$P$可以位于prima的底部上方（甚至可能高于点$S$），也可以位于该底部下方。因此，要么$AE \perp SC$，要么$AE \perp SA$。从$\triangle AOP$我们得到$OP = \frac{a \text{ tg } \alpha}{\sqrt{2}}, AP = \frac{a}{\sqrt{2} \cos \alpha}$。

根据点$P$的位置，我们有：$d = |AE - AP| = |a \sqrt{2} \cos \alpha - \frac{a}{\sqrt{2} \cos \alpha}| = \frac{a |\cos 2\alpha|}{\sqrt{2} \cos \alpha}$或$d = AP = \frac{d}{\sqrt{2} \cos \alpha}$，即$a = \frac{d \sqrt{2} \cos \alpha}{|\cos 2\alpha|}$或$a = d \sqrt{2} \cos \alpha$。但在所有情况下都是$2R = h + x = \frac{a}{\sqrt{2}} (\text{ctg } \alpha - \text{tg } \alpha) = \frac{a \sqrt{2}}{\sin 2\alpha}$，因此要么是$R = \frac{d}{2 \sin \alpha}|\cos 2\alpha|$，要么是$R = \frac{d}{2 \sin \alpha}$。
