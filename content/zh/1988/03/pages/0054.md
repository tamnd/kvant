⟦folio 52⟧

用 BASIC 编写的程序可以让您立即看到它是非结构化的：每一行都以数字（标签）开头，并且经常遇到诸如 GOTO 90 或 GOSUB 210（通过标签转移控制）之类的命令。

是否有可能将学校算法语言中实现的结构方法与用非结构语言 BASIC 编写程序联系起来？事实证明这是可能的。本文的目的是准确展示它是如何做到这一点的。更准确地说，我们只是在开发一种技术，使我们能够“自动”将用学校算法语言编写的程序翻译成 BASIC 语言。

同时，我们不会努力用 BASIC 编写与用学校算法语言编写的算法相对应的最佳（例如，最短）程序。例如，我们将输入一些执行器（计算机）不需要的附加行（以单词 REM 开头），但要确保生成的程序的结构及其可读性。

我们假设读者熟悉（至少在一般意义上）学校算法语言和 BASIC 语言。我们相信我们已经得到了一个用算法语言编写的现成程序；我们的目标是将其转化为 BASIC。该程序可能包含以下学校算法语言的基本结构： 1）变量类型和CONSTANT； 2）表格； 3）赋值运算符； 4）分行经营者； 5）循环运算符； 6）输入输出运算符； 7) 算法标题； 8）输出子程序、传递参数的方法。

让我们按顺序说明这些结构是如何翻译的。

1) 学校算法语言中变量和CONSTANT的类型有以下几种：自然、整数、实数和文字。在 BASIC 中，没有描述变量的类型，而是通过变量名后面的符号来指示：% - 整数， - 文字，无符号 - 实数。湾中的自然变量-

没有类似的，我们将使用整个的。翻译时，我们会在注释中留下类型描述（以 REM 开头），并且在程序中，在整型变量和文字变量的名称后面分别放置 % 和 % 。例如，如果程序包含

nat i，整个k，东西a，lit t
然后我们写（我们用字母 n 表示行号）

n REM NAT I、目标 K、体重 A、LIT T
在程序中我们使用变量 I %, N %, A, T ↵。

2) 桌子也分为三种类型。 BASIC 中索引的最小值为 0。如果程序包含表

int tab x [0:10], int tab k [0:3, 0:5]
我们写（省略行号）

REM 体重选项卡 X [0:10]
对象选项卡 K [0:3, 0:5]
DIM X (10), K % (3,5)

请注意，以 REM 一词开头的行不会影响算法的使用（尽管它已输入计算机并出现在程序打印输出中）。我们编写它是为了提供比下一个翻译行给出的变量更详细、更清晰的描述。

3) 算法语言的赋值运算符（符号：=）通过等号（=）翻译成BASIC。例如，字符串 x:=x+1 被翻译为 X=X+1。

4) 建议将分支运算符翻译如下：

if 条件 IF（NOT 条件）THEN n1
然后第 1 集转到 n2
否则 n1 REM ELSE
第2集
全部 n2 REM 全部
或缩写形式（不带inchae）
if 条件 IF（NOT 条件）THEN n
然后系列n REM ALL
这里 cond 是条件，n1,n2,n 是行号。

5) 循环运算符（while循环）建议按照以下方案进行翻译：

while 转换 n1 IF（非转换）THEN n2
无气 转到 n1
GOTO n1系列
ki n2 循环结束
