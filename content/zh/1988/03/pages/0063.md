选项2
1. 摩擦力 (μmg cos α) 与重力和外力 ($\sqrt{F^2_{\min}} + (mg \sin \alpha)^2$) 相等。使力相等，我们得到
$$F_{\min} = mg \sqrt{\mu^2 \cos^2 \alpha - \sin^2 \alpha} \text{ при } \mu \geqslant tg \alpha,$$
$$F_{\min} = 0 \text{ при } \mu < tg \alpha.$$
2. 根据电荷守恒定律$2CU = Q_1 + Q_2$、电容器极板电位差相等$Q_1/(2C) = Q_2/C$以及能量守恒定律$2\frac{Mv^2}{2} = 2\frac{CU^2}{2} - \left(\frac{Q_1^2}{2(2C)} + \frac{Q_2^2}{2C}\right)$，我们有
$$v = \sqrt{\frac{CU^2}{3M}}.$$
3. 从左活塞的平衡条件来看，其左侧和右侧的压力$p_1$必须相同。那么在蒸汽开始凝结之前左右隔室的体积应该是相同的。因此，当$p_1 \leqslant 2p_0$时，每个隔室的长度为$(2L-a)/2 = L-a/2$，并且左活塞在$a \leqslant L$时的位移为$x = a/2$。
随着右侧活塞的进一步插入，水蒸气凝结，并且两个隔室中相同的压力将是恒定的并且等于$2p_0$。这意味着活塞之间的距离$l$将是恒定的并且等于$L/2$（根据波义耳-马里奥特定律$p_0L = 2p_0l$，因此$l = L/2$）。从这里开始（相当于冷凝水的体积）
$$x = 2L - a - L/2 = 3L/2 - a \text{ при } L \leqslant a \leqslant 3L/2.$$
最后，
$$\text{при } a > 3L/2 \text{ x} = L.$$
4. 左斧头$F$在路径$s$（刀柄尺寸）上的滚动力的功等于$Fs \sim mv^2/2$，其中$m$是斧头的质量，$v$是它的速度。我们假设斧头和手一样，在奔跑时以与海苔大致相同的速度移动。因此，
$$F \sim mv^2/(2s) \sim 5 \cdot 10^3 \text{ H}$$
$m \sim 1$ kg、$s \sim 10^{-2}$ m 和 $v \sim 10$ m/s。

选项3
1. 从一摩尔气体的门捷列夫-克拉佩龙方程 - $pV = RT$ - 可以得出，等角线与温度轴的倾角 $\alpha$ 为 $tg \alpha = p/T = R/V$。因此，最大斜率对应于最小体积，反之亦然：
$$V_{\min} = RT_1/p_2, V_{\max} = RT_2/p_1.$$
2. 假设电容器的极板上有电荷$q$，则极板上将保留电荷$Q - q$，另一极板上将出现电荷$Q - q$，半径为$R$的极板上将出现电荷$+q$（根据电荷守恒定律）。使电容器板之间和球之间的电势差相等，我们得到
$$4\pi \varepsilon_0 q/C = (Q - q)/r - q/R,$$
在哪里
$$q = \frac{Q}{1 + r(1/R + 4\pi \varepsilon_0/C)}.$$
3. 由于珠子的速度 $v$ 恒定，因此摩擦力 $\mu N$ 由“滚动”力 $mg \sin \alpha$ 平衡。由牛顿第二定律我们得到
$$\left(\frac{mv^2 \cos^2 \alpha}{R}\right)^2 + (mg \cos \alpha)^2 = N^2 = \left(\frac{mg \sin \alpha}{\mu}\right)^2.$$
从这里
$$v = \sqrt{Rg} \cos \alpha \left(\left(\frac{\sin \alpha}{\mu}\right)^2 - \cos^2 \alpha\right)^{1/4} \text{ при } tg \alpha > \mu.$$
4. 根据能量守恒定律按数量级粗略估计得出：$mv^2_{\pi,T}/2 + mgl/2 \sim Fh$，其中$F \sim (M_{\psi,\pi}/2)g$是站立的人一条腿的压力。因此$v_{\pi,T} \sim \sqrt{(Mh/m-l)g}, v_x/v_{\pi,T} = 2$（自$v = \omega r$），即
$$v_x \sim 2 \sqrt{(Mh/m-l)g} \sim 15 \text{ м/c}$$
在 $M/m \sim 70$、$h \sim 0,1$ 米、$l \approx 1,5$ 米、$g = 10 \text{ м/c}^2$。
5. 首先，薄金属容器迅速升温，体积增大，因此液位下降。然后液体本身升温，体积增加，管中的液位上升。
