⟦folio 32⟧

美妙的数字。
斐波那契数列

斐波那契数是数字序列 1, 1, 2, 3, 5, 8, 13, 21, ... 的元素，其中从第三个开始的每个数字都是前两个数字的总和： $f_n = f_{n-1} + f_{n-2}$

这些数字是由塔利班数学家比萨的列奥纳多（斐波那契）在《算盘书》（1202）中引入的。他将它们作为一对切磨机家族的数量来获得，前提是每对切磨机每月都会生产一对新的切磨机。

事实证明，斐波那契数列出现在生活的各个领域。例如，如果您沿着一条分为 $n$ 个方格的路径行走，每次移动到下一个方格或穿过一个方格，那么通过这样一条路径的方法数为 $f_n$。

斐波那契数列呈螺旋状，并且一个方向和另一个方向的螺旋数不同 - 它们是连续的斐波那契数（例如，可以有 34 和 55 个螺旋）。在菠萝果实中也观察到同样的情况，通常有 8 和 14 个螺旋。

喜欢比例：

$$f_1 + f_2 + \dots + f_n = f_{n+2} - 1;$$
$$f_1 + f_2 + \dots + f_n^2 = f_n f_{n+1};$$
$$f_1 - f_2 + \dots + (-1)^{n+1} f_n^2 = 1 + (-1)^n f_{n+1} = f_n + 2 f_{n-1} - f_n f_{n-1} = (-1)^n;$$
$$f_n + m = f_{n-1} f_m + f_n f_{m+1};$$

$$f_1 x + f_2 x^2 + \dots + f_n x^n + \dots = \frac{x}{1-x-x^2},$$
$$\frac{f_1}{2} + \frac{f_2}{4} + \dots + \frac{f_n}{2^n} = 2;$$

$$1 = 1, 1 + \frac{1}{1} = \frac{2}{1}, 1 + \frac{1}{1+1} = \frac{3}{2},$$
$$1 + \frac{1}{1+1} = \frac{5}{3}, \dots,$$
$$1 + \frac{1}{1+1} = \tau.$$

人们发现，$a/b$形式的分数，对应于距离杆上片材的螺旋排列，通常是连续斐波那契数的比率。对于山毛榉和榛木，该比例为 2/3，对于橡木和杏，该比例为 3/5，对于杨树和梨，该比例为 5/8，对于杏仁和杏仁，该比例为 8/13，等等。
