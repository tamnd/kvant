质心是什么

如果你以与地平线成一定角度的方向扔一块石头，它就会沿抛物线运动。如果你扔一根长棍子并适当地扭转它会怎么样？当然，棍子的不同点以不同的方式移动，描述了相当复杂的轨迹，但棍子的整体运动有点类似于石头的运动：上升、顶部位置、下降。而且，如果我们忽略空气阻力，那么木棍某一特定点的运动就和一块石头沿抛物线自由飞行的运动没有什么不同。该点是棒的质心。

任何物体、任何物体系统都存在质心。它具有显着的特性，本文将向您介绍其中一些特性。

让我们首先确定质心的位置。让我们考虑一个质量为 $m_1, ..., m_n$ 的质点系统。知道了它们的坐标，如何找到这个“最重要的点”的坐标呢？答案如下：

$$x_{\mu m} = \frac{m_1 x_1 + m_2 x_2 + ... + m_n x_n}{m_1 + m_2 + ... + m_n},$$

坐标 $y_{\mu m}$ 和 $z_{\mu m}$ 类似。当我们考虑其直径特性时，稍后会清楚为什么以这种方式确定质心。现在，我们通过讨论几个相关问题来熟悉表达式（1）。

a) 对于质量为$m_1$和$m_2$的两点，$x_{\mu m}$的表达式有明确的含义：质心位于

6) 该点的所有材料绝对平等地“参与”质心的某个位置。这意味着如果质量的位置相对于某个点对称，那么该点将是质心。例如，同质球的质心与其中心重合（圆柱体、立方体等也同样）。

c) 还有一件事。事实证明（试图证明这一点），如果我们隔离系统的某些距离，并将该部分的整个质量集中在一点（其质心），则质心的位置不会改变。例如，布线三角形的质心与位于边中间的三点系统的质心重合（这些点的质量等于相应边的质量）。

现在让我们转向最重要的事情——质心物理特性的研究。

让点在短时间内$\Delta t$移动到$s_1$，...，$s_n$。那么，由(1)式可知，质心位移将等于

$$\vec{s}_{\mu M} = \frac{m_1 s_1 + m_2 s_2 + \ldots + m_n s_n}{m_1 + m_2 + \ldots + m_n}$$

（回想一下，位移矢量在轴上的投影等于相应坐标的变化）。将位移除以 $\Delta t$，我们得到质心的速度：

$$\vec{v}_{\mu M} = \frac{m_1 \vec{v}_1 + m_2 \vec{v}_2 + \ldots + m_n \vec{v}_n}{m_1 + m_2 + \ldots + m_n}$$

它的成本只不过是系统的全部冲动$\vec{P}$。因此，式(2)可以写成形式

$$\vec{P} = (m_1 + m_2 + \ldots + m_n) \vec{v}_{\mu M}.$$

因此，第一个属性：如果系统的整个质量在精神上集中在质心，那么该假想点的动量将等于系统的总动量。由此得出什么结论呢？例如，我们知道封闭系统的动量是守恒的。这意味着如果系统是封闭的，其质心$\vec{v}_{\mu M}$的速度保持恒定。

让我们看一个例子。一根长度为 $l$ 的均匀细棒垂直立在光滑的地板上 (图 2)。她被释放，之后她就崩溃了。如何找出棍子下端在落下时收缩了多少？引力场中的一根棍子并不是一个封闭的系统；但是，由于只有垂直力作用在其上，因此其动量的水平投影不会改变，在我们的例子中它仍然为零。这意味着质心不会在水平方向混合，即棒的中心会落到原来的位置，其下端会移动$l/2$。

让我们继续讨论质心的性质。让我们考虑质量为 $m_1$ 和 $m_2$ 的两个点材料的系统。让这个系统不被封闭，即每个物体都受到内部和外部力量的作用。根据牛顿第二定律，我们写出每个点的动量随时间的变化$\Delta t$：

$$m_1 \Delta \vec{v}_1 = (\vec{F}_1 + \vec{F}_{12}) \Delta t,$$

$$m_2 \Delta \vec{v}_2 = (\vec{F}_2 + \vec{F}_{21}) \Delta t,$$
