数学
笔试
选项1
（力学、数学和经济学院）

1. 解方程
$$\frac{3 - 5 \sin \left(x + \frac{\pi}{3}\right) - 6 \cos 2x}{5} = x - \frac{\pi}{3}.$$
2. 解决不等式
$$\frac{1}{\log_2 \frac{4}{x}} > \frac{1}{\log_2 \frac{x}{2}} - 1.$$
3. 从点 $A$ 到半径为 $R$ 的圆，绘制切线 $AM$（$M$ 是切点）。通过点$A$的割线与圆相交于点$K$和$L$，$L$是线段$AK$的中点，$AMK$角等于$60^\circ$。求三角形$AMK$的面积。
4. 参数$a$取什么值时可以求解不等式组
$$x^2 + (a+4)x + 4a \leq y,$$
$$3x + y - (2a+4) \leq 0$$
包含轴 $Ox$ 的线段 $[-2; -1]$？
5. 点$M$是单个立方体$ABCDA'B'C'D'$的边$AD$的中间。通过重新分配给它的线段 $B'M$ 的中间绘制一个平面。求从立方体中心到该平面的距离。
选项2
（物理学院）
1. 找到方程 $\sin x + \cos 3x = 0$ 满足不等式的所有解
$$\sin \frac{x}{2} + \cos \frac{x}{2} > 0.$$
2. 解决不等式
$$\frac{1}{\log_2 \left(x^2 - x + 1\right)} + 1 \geq \frac{\log_2 \left(x + 3\right)}{\log_2 \left(x^2 - x + 1\right)}.$$
3. 半径分别为 3 和 4、圆心距离为 5 的两个圆相交于点 $A$ 和 $B$。通过点 $B$ 绘制一条线，与圆在点 $C$ 和 $D$ 相交，使得 $CD = 8$ 和 $B$ 位于 $C$ 和 $D$ 之间。求三角形$ACD$的面积。
4. Prinayaka 在点 $A$ 处接触抛物线 $y = -x^2 + 2x + 2$，并在 $B$ 处与 $Ox$ 轴相交，在 $C$ 处与 $Oy$ 轴相交。已知点$A$位于坐标平面的第1四分之一，$2AB = AC$。求正切方程。

5. 在三角形paramid$SABC$中，边$AB, BC$和$BS$的长度为2并且相互垂直。通过边$AC$和$SB$的中点绘制一个平面，与边$AB$相交，并与面$ABS$和$ABC$的平面形成相等的角度。求这些角度的大小。

选项3
（自然科学与地质学院-地球物理学院）

1. 解方程
$$(13x^2 + 2x - 14) \cdot \arccos x = 0.$$
2. 解方程
$$2^2 \sin 2x - 2 \cos 2x + 3 - \left(\frac{1}{6}\right) \cos 2x - \sin 2x - \log_6 14 + 3^2 \sin 2x - 2 \cos 2x + 1 = 0.$$
3. 锐角$30^\circ$、周长为6的梯形，在直线高为多少时，它的平面最大？
4. 铜合金与低铝的重量比为2：1、3：1、5：1三种。其中，重 12 公斤的一块以 4:1 的铜比例熔合。如果第一块的质量是第二块的质量的两倍，求每个原始块的质量。
5. Paramida $ABCD$ 已给出。边$DC$重新分布到底面$ABC, AB = 3\sqrt{3}, BC = 3$的平面上，角度$ACB$等于$\pi/3, DC = \sqrt{13}$。绘制一个半径为 5、中心位于顶点 $D$ 的球体。求球体与底面 $ABC$ 的交线长度。

物理
笔试
物理学院
每个变体都是三种类型的五个任务的状态。
前三个任务是计算任务，难度各异：从标准任务到相对复杂的任务，需要独创性、深厚的知识以及理解不寻常或传统物理情况的能力。
第四个任务是评估任务。为了解决这个问题，需要获得所考虑的物理现象，制定该现象的简单（因为只需要估计）物理模型，选择合理的物理量数值，最后获得或多或少符合现实的数值结果。问题的文本支持申请人可以选择解决问题所需的数量及其数值。
第五个任务是演示任务，您需要解释课堂上演示的物理现象。这里重要的是要了解各种因素的本质现象和环境，以突出主要因素。
从演示结束开始，给了五个小时的时间来解决问题。
每个问题的文本后面的括号中标明了解决该问题的人的百分比。

选项1

1. 在长度为 2L、横截面为 $S$、两端封闭的管道中间有一个活塞。活塞的左侧和右侧有不同的气体，压力相同$p$。如果活塞变得可渗透其中一种气体，活塞会移动多少？活塞对管道的摩擦力为$F$。假设气体的温度是恒定的。 (51%)

2. 横截面恒定的窄管在 $l$ 侧形成正方形，固定在垂直平面 (图 1) 上。管内充满等体积的密度为$\rho_1$和$\rho_2$的两种液体，且不会相互渗透。最初，较稠密的液体充满了管子的上部。在某个时刻，液体开始移动。找出他们的最大速度。没有摩擦。自由压力加速度$g$。 （55%）。

3. 半径为 $R$ 的金属丝环沿其直径有一个导电跳线。左右收到的包括电容器$C_1$和$C_2$。将环放置在磁场中，磁场的感应强度为 $B(t) = B_0 t / T$，该磁场随时间线性增加，垂直于其平面。在某个时刻，跳线被移除，然后场停止变化。找出电容器上的电荷。 (29%)

4. 估计穿着轻便舒适的宇航服的宇航员在月球上行走的速度有多快。 (37%)

5. 两个相同的瓶子装满了水。将一根管子插入其中一个，用手指封闭其计数管。芽同时被消化，同时反应管打开。水从带有管子的瓶子中流出的速度明显更快。解释一下这个现象。 (91%)

选项2

1. 质量为 $m$ (图 2) 的垫圈位于与地平线形成角度 $\alpha$ 的平面上。为使冰球移动，必须在水平方向上沿平面向冰球施加的最小力是多少？摩擦系数为$\mu$。 (49%)

2. 每个连接器的两个电容$C$的平行板电容器并联并充电至电压$U$。其中一个电容器的极板可以自由地相互移动。求并联电容器之间的间隙减半时它们的速度。每条平行线的质量为 $M$。不考虑重力。 (55%)

3. 在圆柱形管道中，从封闭端到右侧距离 $L$ 和 $2L$ 处，有两个活塞，它们可以超越

无摩擦地颤动。左侧隔室含有压力为 $p_0$ 的水蒸气，右侧隔室含有相同压力的空气。水的饱和蒸气压为$2p_0$。将右侧活塞缓慢旋入距离$a$。左活塞将移动多远？水蒸气和空气的温度被认为是恒定的。 (39%)

4. 伐木工人用斧头敲击圆木。斧头被卡住了，进入了方块的一半（图3）。估计移除斧头的力量。 (36%)

5. 激光束落在一块透明的平行平面板上，该板的一个表面经过涂漆，以便能够向各个方向散射光。在盘子上可以看到下面的图片：中心有一个亮点，一个边界清晰的黑圆圈，圆圈后面有一个光晕。解释一下这个现象。 (27%)

选项3

1. 一摩尔气体在坐标 $p$、$T$ 中的循环行程图形成直角 ABCD (图 4)，其边 BC 和 AD 对应压力 $p_2$ 和 $p_1$，AB 和 CD 对应温度 $T_1$ 和 $T_2$。求气体的最大和最小体积。气体常数为$R$。 (83%)

2. 半径为$r$和$R$的两个导电球彼此远离，并连接到电容器$C$的极板。半径为$r$的球，他们报告了电荷 问：另一个球上有什么电荷？留丝容量。 (33%)

3. 使用细接线螺钉，垂直站立，将珠子从内向外滑到接线上。半径的半径等于$R$，布线与水平面的倾斜角等于$a$。当珠子与钢丝之间的摩擦系数为$\mu$时，求珠子的稳定速度。自由压力加速度$g$。 (36%)

4. 一名男子不小心用耙子的牙齿踩到了躺着的动物。估计耙子击中他额头的速度。 (39%)

5. 将一根细管插入装有有色液体的金属容器中，以便在管的突出部分可以看到柱子。如果将容器放在加热的瓷砖上，管中的液柱会先下降，然后上升。解释一下这个现象。 (59%)
