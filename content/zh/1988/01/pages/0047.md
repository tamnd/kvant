⟦folio 45⟧

如果我们稍微改变问题的条件就会出现问题。
问题3'。用自然数求解系统

$$\begin{cases} \frac{1}{x} + \frac{1}{y} + \frac{1}{z} = 1, \\ x \leqslant y \leqslant z. \end{cases}$$

问题3'的解决方案。明显地，

$$\frac{1}{x} \geqslant \frac{1}{y} \geqslant \frac{1}{z}.$$

我们首先假设$x > 3$。然后

$$\frac{1}{3} > \frac{1}{x} \geqslant \frac{1}{y} \geqslant \frac{1}{z},$$

在哪里

$$\frac{1}{x} + \frac{1}{y} + \frac{1}{z} < \frac{1}{3} + \frac{1}{3} + \frac{1}{3},$$

这与条件相反。因此，$x$ 不能等于 1、2 和 3 以外的任何值。（看看我们显着减少了搜索量！）
1) $x = 1$。然后

$$\frac{1}{y} + \frac{1}{z} = 0,$$

切罗不可能。
2) $x = 2$。然后

$$\frac{1}{y} + \frac{1}{z} = \frac{1}{2}.$$

若$y > 4$，则

$$\frac{1}{4} > \frac{1}{y} \geqslant \frac{1}{z},$$

在哪里

$$\frac{1}{y} + \frac{1}{z} < \frac{1}{4} + \frac{1}{4},$$

切罗不可能。所以，$y$不能等于2、3和4以外的任何值。代入这些值中的每一个，我们发现$y = 2$不合适，另外两个值给出两个答案：(2,3,6)和(2,4,4)。
3) $x = 3$。然后

$$\frac{1}{y} + \frac{1}{z} = \frac{2}{3}.$$

若$y > 3$，则

$$\frac{1}{3} > \frac{1}{y} \geqslant \frac{1}{z},$$

在哪里

$$\frac{1}{y} + \frac{1}{z} < \frac{1}{3} + \frac{1}{3},$$

切罗不可能。因此，在这种情况下，我们只需要考虑 $y$ 的一个值 3，这给出了另一个答案：(3, 3, 3)。

所有案件均已解决。问题3'的解决方案。它有三个答案：(2,3,6)，(2,4,4)，(3,3,3)。

相比之下，问题 3 有一个不同的答案列表，这些答案是由所有这些可能的排列产生的。这是问题3的答案：

(2, 3, 6), (2, 6, 3), (3, 2, 6),
(3, 6, 2), (6, 2, 3), (6, 3, 2),
(2, 4, 4), (4, 2, 4), (4, 4, 2), (3, 3, 3).

（在每个答案中，第一个数字是值 $x$，第二个数字是值 $y$，第三个数字是值 $z$。）

在我们迄今为止解决的问题中，有必要找到满足给定条件的所有答案。为了证明这样的对象不存在，需要将所有情况分开或者进行一般推理。为了证明这样一个物体的存在，只要举一个例子就足够了。这里有两个此类问题。

问题4. 已知对于两个三角形$ABC$和$A'B'C'$，满足以下三个条件：

$$\angle A = \angle A', AB = A'B', BC = B'C'.$$

三角形$ABC$和$A'B'C'$可以不相等吗？

答：可以。
