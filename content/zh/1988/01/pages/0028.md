让$\bar{P} = m\bar{M} = n\bar{N}$，$\bar{A} = \alpha\bar{D}$，$\bar{B} = \beta\bar{E}$，$\bar{C} = \gamma\bar{F}$（即$m = SP:SM$，$n = SP:SN$等）。让我们将向量$\bar{P}$展开为非共平面向量$\bar{A}$、$\bar{B}$、$\bar{C}$：

$$\bar{P} = x\bar{A} + y\bar{B} + z\bar{C}.$$

(1)

戈尔达

$$x + y + z = 1.$$

(2)

实向量$\bar{AP}$位于$ABC$平面，因此对于某些$y_1$和$z_1$$\bar{AP} = y_1\bar{AB} + z_1\bar{AC} = y_1(\bar{B} - \bar{A}) + z_1(\bar{C} - \bar{A})$，因此$\bar{P} = \bar{A} + \bar{AP} = (1 - y_1 - z_1) \times \bar{A} + y_1\bar{B} + z_1\bar{C}$。并且由于（1）中的系数是唯一确定的，$y_1 = y$，$z_1 = z$，$x = 1 - y - z$。因此，等式 (2) 是点 $P$ 位于平面 $ABC$ 的必要（也是充分）条件。

让我们为平面 $DEF$ 中的点 $N$ 和位于三个平面 - $ABF$、$BCD$ 和 $CAE$ 中的点 $M$ 写出这个条件。从$n\bar{N} = \bar{P} = x\alpha\bar{D} + y\beta\bar{E} + z\gamma\bar{F}$展开我们得到$x\alpha/n + y\beta/n + z\gamma/n = 1$，即

$$x\alpha + y\beta + z\gamma = n;$$

(3)

从扩展 $m\bar{M} = \bar{P} = x\bar{A} + y\bar{B} + z\gamma\bar{F}$ - 什么

$$x + y + z = m.$$

同样，还有两个等式：

$$\alpha x + y + z = m,$$

$$x + \beta y + z = m.$$

添加最后三个等式并考虑 (2) 和 (3)，我们发现

$$n + 2 = 3m.$$

剩下的就是通过$m$和$n$来表达规范条件下各段的关系：

$$\frac{PN}{NS} : \frac{PM}{MS} = \frac{PS - NS}{NS} : \frac{PS - MS}{MS} = \frac{n - 1}{m - 1} = \frac{3m - 3}{m - 1} = 3.$$
