1. 西瓜在半径为 $R$ 的圆上运动，速度为 $v$，等于飞机的速度，并且具有指向圆心 (图 5) 的向心加速度 $a = v^2/R$。西瓜受到重力$mg$的力和弹簧秤$F = 15mg/16$的弹力的作用。牛顿第二定律的方程以径向方向的投影形式表示，其形式为 $mg - F = ma$。将$F$和$a$的表达式代入最后一个等式，经过简单变换后得到

$$v = \sqrt{gR}/4 \approx 2 \text{ km/c.}$$

2. 为了找到温度升高的循环部分，我们绘制了一系列等温线 (图 6)。现在您可以清楚地看到第 2-3 部分和第 1-4 部分（通道 1-2 的一部分）中的温度正在上升。此外，温度$T_4$是过程1-2的最大值。

令$T_3$为点3处的气体温度，$p_1$和$p_2$为点1和点2处的压力。让我们用$T_1$和$p_1$来表达$T_3$和$p_2$。对于点 3 和 1 $V_3/T_3 = V_1/T_1$，打开 $T_3 = T_1V_3/V_1$。根据条件$V_3/V_1 = 5/2$，因此$T_3 = 5T_1/2$。对于点 2 和点 1 $p_2V_3 = p_1V_1$，因此$p_2 = p_1V_1/V_3 = 2p_1/5$。

使用第 2-3 节的热力学第一定律，我们找到热过程的数量 1-2：

$$Q_{23} = \frac{3}{2} R(T_3 - T_1) = \frac{9}{4} RT_1.$$

为了确定温度$T_4$、压力$p_4$和体积$V_4$，我们将过程1-2的直线方程写成$p = AV + B$形式，其中$A = (p_1 - p_2)/(V_1 - V_3) = -2p_1/(5V_1)$、$B = (p_2V_1 - p_1V_3)/(V_1 - V_3) = 7p_1/5$。因此，所需的直线方程

$$p = -\frac{2}{5} p_1 \frac{V}{V_1} + \frac{7}{5} p_1.$$

使用针对一摩尔气体编写的 Mendleev-Clapeyron 方程 $pV = RT$ 从该方程中排除压力 $p$，我们得到过程 1-2 中温度对体积的依赖性：

$$T = -\frac{2}{5} \frac{p_1}{V_1} V^2 + \frac{7}{5} \frac{p_1}{R} V.$$

对这种依赖性的极值的研究表明，温度在$V = V_4 = 7V_1/4$处达到最大值，并且等于$T = T_4 = 49T_1/40$。同时$p_4 = RT_4/V_4 = 7p_1/10$。

根据热力学第一定律，第1-4节中供给气体的热量和能量，$A$是气体的功。自从

$$\Delta U = \frac{3}{2} R(T_4 - T_1) = \frac{27}{80} RT_1,$$

$$A = \frac{p_1 + p_4}{2} (V_4 - V_1) = \frac{51}{80} p_1V_1 = \frac{51}{80} RT_1,$$

我们有

$$Q_{14} = \frac{27}{80} RT_1 + \frac{51}{80} RT_1 = \frac{39}{40} RT_1.$$

在温度升高的区域中添加到气体的最终总热量等于

$$Q = Q_{23} + Q_{14} = \frac{129}{40} RT_1 \approx 8 \text{ кДж.}$$

3. 令$R$为一个电压表的电阻，$r$为电源的内阻。当开关闭合时，通过电压表$V_1$的电流为$\mathcal{E}/(R + r)$，其两端的电压为$\mathcal{E}/(R + r)$。根据问题$\mathcal{E}/(R + r) = 0,8\mathcal{E}$的条件。

因此$r = R/4$。当钥匙打开时，电压表读数相同且相等

$$U = \frac{\mathcal{E}}{2R + r} R = \frac{4}{9}\mathcal{E}.$$

4. 令 $\vec{P}_1$ 为单位时间内入射到板上的光子动量，$\vec{P}_2$ 为单位时间反射光子的动量，$\vec{P}$ 为板在同一时间内接收到的动量 (图 7)。显然$P_1 = W/c$，$P_2 = 0,4P_1 = 0,4W/c$。根据动量守恒定律
