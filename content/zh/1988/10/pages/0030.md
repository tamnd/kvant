这种不等式在值的循环排列下不会改变​​$a, b, c$。我们有：

$$\frac{2b-a}{c} + \left( \frac{2}{a} - \frac{1}{b} \right)c = (2b-a)f(c),$$

其中$f(x) = 1/x + x/ab$。从$2b-a \geq b+c-a > 0$开始，函数$f(x)$在$0 < x \leq \sqrt{ab}$处杀死（$a > b$的$f(x)$图在图处给出）和$f(a) = f(b) = 1/a + 1/b$在$c \leq \min(a, b) \leq \sqrt{ab}$处

$$(2b-a)f(c) \geq (2b-a)\left( \frac{1}{a} + \frac{1}{b} \right) = \frac{2b}{a} - \frac{a}{b} + 1.$$

由此可见，不等式（*）左边不小于$\frac{2a}{b} - \frac{b}{a} + \frac{2b}{a} - \frac{a}{b} + 1 = \frac{a}{b} + \frac{b}{a} + 1$，而且这个数非常大，不小于3。

M1108。在凸零线 ($n > 4$) 中，没有任何三个对角线经过多边形内的同一点。可以检查其中的最大对角线数量是多少，以便将零叶分割成的所有部分都变成三角形？

答案：$[3n/2] - 4$（其中$[x]$是$x$的整数部分）。 图 1 处给出的划分表明，满足问题条件的对角线的最大数量$f(n)$对于$n = 2m$至少为$3m - 4 = [3n/2] - 4$，对于$n = 2m + 1$至少为$3m - 3 = [3n/2] - 4$。现在还有待证明的是

$$f(n) \leq [3n/2] - 4.$$

为此，我们需要以下引理。如果 $n$ 边形 ($n \geq 5$) 的某些对角线将其分成三角形，则这些对角线中至少有一条不与其他对角线相交。 （我们不考虑多边形顶点的交点。）

为了证明引理，我们注意到没有一条对角线可以与多个对角线相交：否则，与相邻交点之间的对角线部分相邻的分区之一不会是三角形，因为其角度之和将大于 $180^\circ$ (图 2)。现在让我们假设任何对角线与其他一条对角线相交，并且仅与一条对角线相交。令 $AC$ 和 $BD$ 为相交的对角线 (图 3)。由于$n \geq 5$，四边形$ABCD$的至少一条边（例如$AB$）是给定$n$边形的对角线（而不是边）。对角线$AB$包含在我们的集合中，否则折线$AOB$（其中$O$是$AC$和$BD$的交点）将不是三角形。因此，有一条对角线相交$AB$。但这条对角线还必须与$AC$或$BD$相交，这与上面的说法相矛盾。

使用引理，可以通过关于$n$的归纳法证明不等式（*）（对于$n = 3$和$n = 4$这是显而易见的）。让它证明所有$k, 3 \leq k < n$，其中$n \geq 5$。考虑一个 $n$ 边形被对角线分割成一个三角形
