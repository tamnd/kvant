最终方程（1）的形式为：

$$y = \frac{\omega_1^2}{2g}(x^2 - k^2l^2).$$

这是一个抛物线方程；这里$\omega_1$表示日间区域$k$部分曝光的角速度。

为了确定$\omega_1$，我们使用液体的不可压缩性。旋转过程中液体的初始体积$V = 2lh_0a$将均匀分布在旋转轴的两侧：$V/2 = Sa$，其中$S$是液体表面下方的面积，即平面的一部分，位于线段$y=f(x)$线段$kl \leq x \leq l$上的函数图形下方。曲线梯形的这个面积对应于$kl$到$l$范围内取的某个区间：

$$S = \int_{kl}^{l} ydx = \frac{\omega_1^2}{2g}\left(\int_{kl}^{l} x^2dx - k^2l^2 \int_{kl}^{l} dx\right) =$$

$$= \frac{\omega_1^2l^3}{6g}(1 - 3k^2 + 2k^3).$$

现在从平等

$$lh_0a = a \frac{\omega_1^2l^3}{6g}(1 - 3k^2 + 2k^3)$$

我们得到

$$\omega_1 = \frac{1}{l} \sqrt{\frac{6gh_0}{1 - 3k^2 + 3k^3}}.$$

旋转过程中底部压力不发生变化。依然与灌入海湾的重液的力量相等。侧壁上的压力返回。让我们展示一下。

让我们在心里选择一个高度为 $h$ 的薄壁液体柱。从其垂直平衡条件可知，该柱下底处的流体压力等于 $p_h = \rho gh$（参见 图 2）。但液体中给定点的压力是各向同性的（帕斯卡定律）。因此，当凹部线性旋转时，壁上的流体压力取决于深度。如果侧壁附近的液体以$\omega_1$的速度旋转时上升到$H$的高度，则作用在壁上的压力可以用平均压力$p_{cp} = \rho gH/2$来表示：

$$F_1 = p_{cp}Ha = \frac{\rho ga}{2}H^2.$$

$$F_0 = \frac{\rho ga}{2}h_0^2.$$

这样，压力就会增加$n = (H/h_0)^2$倍。

F1120。为了比较不同材料的导热系数，建议使用以下方法。将由所研究的材料制成的两个相同的圆柱体放置在热板上（参见图）。一次将一件放置在圆筒上。在最有可能出现熔化物的地方，该圆柱体具有更好的导热性。这个方法正确吗？

不幸的是，这种比较热导率的简单方法不能被认为是正确的。原因如下。

当然，圆柱形样品的上部加热到跳跃熔化温度所需的时间越短，导热系数越大。然而，这个时间还取决于圆筒材料的热容量——热容量越大，将样品加热到适当温度所需的时间（大量热量）就越长。因此，由高导热率材料制成的气缸比由低导热率和导热率稍低的材料制成的气缸升温得更慢。例如，在高压和铁的情况下，正是发生这种情况。

事实证明，所提出的方法可以比较材料的其他热特性，即它们的热扩散率。这也是表征物质温度变化速率的重要物理量。导热系数与导热系数与导热系数之比成正比。

让我们考虑这个问题的两种解决方案。

第一个解决方案是通用的。

单位时间内电子所带来的总能量为

$$W = n \frac{mv^2}{2}.$$

流过电阻的电流$I = ne$（个数

电子数量等于同一时间落在球上的电子数量），这样能量在电阻器中转化为热量（每单位时间）

$$P = I^2 R = (ne)^2 R.$$

根据能量守恒定律，单位时间内每个球释放的热量等于

$$Q = W - P = n \frac{mv^2}{2} - (ne)^2 R = \frac{nmv^2}{2} \left(1 - n \frac{2e^2R}{mv^2}\right).$$

球电位（更准确地说，是球与地面之间的电位差）

$$\varphi = IR = neR.$$

另一边，

$$\varphi = k \frac{q}{Q}.$$

因此，球的电荷

$$q = \frac{\varphi_Q}{k} = \frac{neR_Q}{k} = 4\pi\varepsilon_0 neR_Q.$$

请注意，如果电子的动能大于克服球的斥力所花费的功，则电子会击中球：

$$\frac{mv^2}{2} > e\varphi.$$

代入$\varphi = neR$，我们将这个条件变换为以下形式：

$$n < \frac{mv^2}{2e^2R}.$$

在这种情况下，定义$Q$的括号中的表达式为正：$Q > 0$。由此可见，条件中数字的选择不能任意。

如果最初撞击球的电子数量大于$n$，则球的电势逐渐增加，以致在某个时刻最初的部分电子停止撞击球（由于电子排斥）。如果最初球的电势大于或等于 $\varphi$，则电子不会撞击球，电荷会从球上流出，直到建立问题中描述的状态。

第二种方案可以让你更深刻的感受到源头的电子力量是什么。

让我们将我们的系统想象为一个电气目标，由具有 EMF $\mathcal{E}$ 和零内阻的源以及两个串联“电阻器”组成。其中一个阻力为球的有效阻力$R_{\text{шар}}$，另一个为已知阻力$R$。我们将电流源称为加速电子的装置（例如众所周知的电子枪）。这里电子获得能量$mv^2/2 = e\mathcal{E}$。因此源的电动势等于

$$\mathcal{E} = \frac{mv^2}{2e}.$$

F1122。在沙漠中观察海洋世界的著名案例。这样的海市蜃楼会在距离观察者多远的地方出现？考虑沙漠地层中的光速按照$c(z) = c_0(1 - az)$规律变化，其中$c_0$是地球表面的光速，$z$是地表以上的高度。

空气中光速（及其折射率）随高度的变化导致光线弯曲（折射）。*）这种现象导致沙漠中出现海市蜃楼。

让观察到的$h$站在地面上的高度（见图）。让我们考虑从点 $A$ 发出的光线。与垂直线成$\alpha_0$角的射线接触地球表面，然后上升。角度 $\alpha > \alpha_0$ 对应于同样向上的光线。以 $\alpha < \alpha_0$ 角度射来的光线落在地面上。利用光线的可逆性，我们可以得出观察者看到地球的角度为$\alpha_0$，从天空的$\alpha_0$开始。但由于光束到达了被观察的空间，对他来说，他似乎看到了头部（毕竟，人认为光的传播是直线的）。

现在我们来求所需的距离$H$。

根据层状介质的广义光折射定律，

$$\frac{\sin \alpha_0}{\sin \beta_0} = \frac{c(h)}{c_0},$$

其中 $c(h)$ 是$h$ 高度处的光速，$\beta_0$ 是所研究的光束与地球表面垂直线的角度。
