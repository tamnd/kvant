4. 1988.证明。令数字2$^{1987}$包含$n$位数字，数字5$^{1987}$包含$k$位数字。然后

$$10^{n-1} < 2^{1987} < 10^n \text{ и } 10^{k-1} < 5^{1987} < 10^k.$$

因此$10^{n+k-2} < 10^{1987} < 10^{n+k}$，意味着$k+n-2 < 1987 < k+n$，即1987=k+n-1，因此$k+n=1988$。
