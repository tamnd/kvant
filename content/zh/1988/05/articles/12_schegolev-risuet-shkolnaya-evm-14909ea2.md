学校电脑绘图

A·G·舍戈列夫

您可以根据预先设定的场景以交互方式与配备有显示器的学校计算机进行交互（例如，参见 V. A. Kaimin 的文章«Kvant»，1986，第 10、11 期）。在这种情况下，计算机及其用户交换文本和数字数据的片段。同时，大多数学校的微型计算机不仅可以“打印”，还可以在屏幕上“绘图”，即具有图形功能。

为了使图像出现在屏幕上，我们必须向表演者（学校计算机）指示需要在哪里绘制以及绘制什么。因此，首先需要商定一个坐标系。

微型计算机中采用的坐标系与您在学校数学课程中了解的坐标系不同。坐标原点（O点）位于左上角，横坐标和纵坐标方向如图1所示。屏幕字段是一组点，每个点都有特定的颜色，任何点的坐标都是整数x，y（对于雅马哈计算机屏幕）0≤x≤255，0≤y≤191。

就像房子是用砖砌成的一样，我们会用最简单的元素“建造”任何复杂的图像。为此，我们用以下图形命令来补充熟悉的学校算法语言：

1) point (x, y), color — 显示坐标为 (x, y) 的颜色 color 的点；
2) 从 (x1, y1) 到 (x2, y2) 的线段，

color — 以颜色 color 绘制连接坐标 (x1, y1) 和 (x2, y2) 的线段；
3) Circle(x, y), r, color — 绘制一个半径为 r、中心位于 (x, y) 点的圆 color color；
4) Bus (x, y), r, om α 到 β, color — 绘制圆弧 (x, y), r, 颜色从角度 α 到角度 β (图 2);
5) 在 (x, y) 上绘制，颜色 — 点 (x, y) 以及由该点包围的相同颜色的闭合线内的圆上的颜色（屏幕边框可以用作该线的一部分）；如果没有这样的轮廓，整个屏幕都会被覆盖。
事实证明，列出的命令完全足以描绘相当复杂的图形。例如，小提琴 klion 的图像可以表示为一组不同半径的线段和弧，平滑地相互转换 (图 3)。
为了方便构建经常重复的元素，我们引入了另外两个命令：
6) frame from (x1, y1) to (x2, y2), color — 绘制一个矩形框，其边与屏幕的边平行，颜色；矩形由两个对角顶点的坐标 (x1, y1), (x2, y2) (图 4) 定义；
7) 框架 - 从 (x1, y1) 填充到 (x2, y2)，颜色 - 使用颜色颜色绘制框架 6) 及其内部区域。
使用图形命令编写的算法可以翻译成任何具有适当工具的编程语言。这就是雅马哈计算机上采用的 MSX-BASIC 语言中操作员 1) - 7) 的记录。
1) N PSET (X, Y), C (点)
2) N 线 (X1, Y1) - (X2, Y2), C（线段）
3) N 圆（X、Y）、R、C（圆）
4) N CIRCLE (X, Y), R, C, A, B（圆弧；角度 A 和 B - 以半径表示）
5) N 油漆 (X, Y), C (油漆)
6) N 线(X1, Y1) - (X2, Y2), C, B（框架）
7) N LINE(X1, Y1) - (X2, Y2), C, BF（填充框）。
蓝色突出显示变化的元素，可以是数字（常量），也可以是变量名称。 N - 数字（需要对 BASIC 中的运算符进行编号），C - 1 到 15 之间的整数，指示需要在此对象上绘制的颜色：
1 - 黑色，6 - 深红色，
2 - 中绿色，7 - 蓝色，
3 - 浅灰色，8 - 中红色，
4 - 深蓝色，9 - 浅红色，
5 - 浅蓝色，10 - 深黄色，
11 - 浅黄色，
12 - 深绿色，
13 - 粉红色，
14 - 灰色，
15 - 白色。
例如，BASIC 运算符 20 PSET(50, 100), 6 将导致屏幕上出现坐标 x=50, y=100 的深红点。
另外，使用图形命令将计算机切换到图形模式，该命令在 BASIC 中将写为 SCREEN 2。
