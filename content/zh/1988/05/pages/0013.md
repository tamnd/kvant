球体$S$。在这种情况下，我们取很小的半径，使得球体$S$穿过接近中心顶点$O$的多面体的边和面，不接触多面体的任何其他边和面。很明显，多面体的各面形成多面角，其顶点$O$在球体$S$上切出一个凸（球形）多边形$M$，其角度等于多面体的二面角。如果在另一个多面体的对应顶点$O'$处画一个半径相同的球体$S'$，则在其上切出一个多边形$M'$，其边长等于多边形$M$的对应边。边相等源自柯西定理的条件：成对相等的面必须收敛于多面体的相应顶点。

这就是引理 1 发挥作用的地方。我们假设柯西唯一性定理是错误的；这意味着至少有一条边被“+”或“-”符号偏移，并且根据引理1，如果偏移边接近某个顶点，则绕该顶点时边的符号变化次数至少为4。

看来从这句简单的话到定理的证明还有很长的路要走。但在这里，柯西发现了一个意想不到的机智举动，之后证明就变成了技术问题。事实证明以下说法是正确的。

引理 2. 让闭凸多面体上的一些边被 + 或 - 号偏移。让我们选择至少一条偏移边接近的多面体的所有顶点。然后，在选定的顶点中，当围绕一对相邻边所遇到的顶点遍历时以及围绕相应的面遍历时，总会找到这样的顶点，反之亦然（图7）。

让我们用 $\Gamma_n$ 表示多面体 $n$ 棱面的数量，$n \geqslant 3$。然后

$$\Gamma = \Gamma_3 + \Gamma_4 + \Gamma_5 + \Gamma_6 + \dots$$

(1)

显然，遍历$n$边形时，符号变化的次数不超过$n$，如果$n$是奇数，则不超过$n-1$。这就是为什么

$$N \leqslant 2\Gamma_3 + 4\Gamma_4 + 4\Gamma_5 + 6\Gamma_6 + 6\Gamma_7 + \dots$$

(2)

由于每条边属于两个面，那么

$$2P = 3\Gamma_3 + 4\Gamma_4 + 5\Gamma_5 + 6\Gamma_6 + \dots$$

$$4B - 8 = 4P - 4\Gamma.$$
