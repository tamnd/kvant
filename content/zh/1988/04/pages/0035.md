令 y 为满足 f(y) 合数的最小非负整数。设 p 表示 f(y) 的最小素因数，则 f(y) ≥ p²。下面我们将证明如果 y ≤ q - 2，则 p ≥ 2y + 1，因此

$$y^2 + y + q \geq (2y + 1)^2 = 4y^2 + 4y + 1,$$

因此 y² < q/3，即 y < √q/3。

因此，还需要证明 p ≥ 2y + 1 对于 y ≤ q - 2。

让我们假设相反的情况：p ≤ 2y 并考虑差异

$$f(y) - f(x) = (y - x)(y + x + 1).$$

当x从0变为y - 1时，表达式y - x取值y, y - 1, ..., 1，y + x + 1取值y + 1, y + 2, ..., 2y。因此，对于某些 x，0 ≤ x ≤ y - 1，数字 f(y) - f(x) 可被 p 整除。但由于 y 和 p 的选择，f(y) 可被 p 整除，并且 f(x) 是素数，因此 f(x) 必须等于 p。同时，y - x < y + x + 1 ≤ q + x - 1 < q + x + x² = f(x)，

F1088。失重叶片以 f = 10 rpm 的速度固定在失重悬架中，使其可以相对于上台阶自由摆动 (图 1)。一只质量为 m = 30 kg 的猴子开始从树叶上爬下来。当叶片的垂直位置不再稳定时，距悬架的距离 l 是多少？

让叶子偏离垂直线一个小角度a。此时，猴子的运动将被视为以~lα（图2）为半径的圆周运动。猴子的向心加速度 -

$$a = (2\pi f)^2 l\alpha.$$

这种加速度可以通过来自叶子侧面的反作用力 T 传递给她 - 这是唯一在水平面上具有投影 F 的力。如果 F > ma，那么猴子（带着叶子）将恢复垂直 - 叶子的垂直位置将是稳定的。

从考虑的丝 (图 2) 可以看出，F = mga。从条件来看

$$mg\alpha > m(2\pi f)^2 l\alpha$$

我们发现：

$$l < g/(2\pi f)^2 = 10 \text{ m}.$$

当l大于10 m时，平衡不稳定。
