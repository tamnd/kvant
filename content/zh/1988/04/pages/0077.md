12. $x \geq -\frac{1}{4}$。证明。到 $f_{n+1}(x)$ 已经确定，还需要确定 $f_n(x)$ 这样就可以了 $x+f_n(x) \geq 0$。我们首先假设 $x \geq -\frac{1}{4}$。如果 $f_n(x) > \frac{1}{2}$， 那 $f_{n+1}(x) = \sqrt{x+f_n(x)} > \sqrt{-\frac{1}{4}+\frac{1}{2}} = \sqrt{\frac{1}{4}} = \frac{1}{2}$，即和 $f_{n+1}(x) > \frac{1}{2}$。因为 $f_0(x)=1 > \frac{1}{2}$，那么根据已经证明的 $f_1(x) > \frac{1}{2}, f_2(x) > \frac{1}{2}, f_3(x) > \frac{1}{2}, \dots$， IE。 $f_n(x) > \frac{1}{2}$ 和 $x+f_n(x) > -\frac{1}{4} + \frac{1}{2} > 0$ 在任何 $n$;因此，与 $x \geq -\frac{1}{4}$ 全部 $f_n(x)$ 定义的。现在就让它 $x < -\frac{1}{4}$。这就是为什么 $x + \frac{1}{4} = -a$;然后 $a > 0$。显然，对于任意 $y \geq 0$ 不平等是真实的 $\sqrt{y} \leq y + \frac{1}{4}$ （真的吗， $y - \sqrt{y} + \frac{1}{4} = \left(\sqrt{y} - \frac{1}{2}\right)^2 \geq 0$）。所以如果 $f_{n+1}(x)$ 定义，那么 $f_{n+1}(x) = \sqrt{x+f_n(x)} \leq x+f_n(x) + \frac{1}{4} = f_n(x) - a$，因此， $f_{n+1}(x) \leq f_0(x) - (n+1)a = 1 - (n+1)a$，从中可以清楚地看出，对于足够大的 $n$ 数字 $f_{n+1}(x)$，如果定义的话，必须为负数，这是不可能的。

15. $a = \frac{1}{5}, b = \frac{49}{40}$；公式$\sqrt{x} \approx \frac{1}{5} x + \frac{49}{40}$ 与$4 \leq x \leq 9$ 允许误差不超过$\frac{1}{40}$。解决方案。让我们画出函数 $y = \sqrt{x}, y = ax + b$ 和 $y = \sqrt{x} - ax - b$ (图 7) 的图形。生成的函数$y = \sqrt{x} - ax - b$等于$\frac{1}{2\sqrt{x}} - a$，并在单点$x = \frac{1}{4a^2}$处消失。该函数可以在点 $\frac{1}{4a^2}$ 和线段的末端达到极值。这些点的值为$4a - b + 2, \frac{1}{4a} - b, -9a - b + 3$。最大误差等于三个数的最大绝对值。如果所有三个绝对值都相同，则此误差将最小（证明！）；在这种情况下，中间的数字将为正，极端的数字将为负（参见图7）。所以，

$$4a + b - 2 = \frac{1}{4a} - b = 9a + b - 3,$$

从哪里$a = \frac{1}{5}, b = \frac{49}{40}$;在这种情况下，最大误差为$4a + b - 2 = \frac{4}{5} + \frac{49}{40} - 2 = \frac{1}{40}$。示例：$\sqrt{5} \approx \frac{1}{5} \cdot 5 + \frac{49}{40} = 2,225$；其实$\sqrt{5} = 2,236$...
