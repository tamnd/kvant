F1092。找到位于厚平面玻璃板前表面距离 L 处、背面中间的确切源图像的位置（参见图）。垂直于板表面观察图像。板厚d，叠层折射率n。

在 图 处，图像在板上构建。从图可以看出，图像位于印版后面，距前表面的距离为$x = \frac{l}{\varphi} - L = L + \frac{2d}{n}$。

选定的学校作业

八年级
1. 求解方程组
   $x_1 + x_1x_2 = 1,$
   $x_2 + x_2x_3 = 1,$
   $x_{99} + x_{99}x_{100} = 1,$
   $x_{100} + x_{100}x_1 = 1$.

2. 证明存在一个自然数，其三次方结束于 1987 年。

3. 给定 3 个正整数。它们的最大公约数是 1，即任意两个约数除以第三个约数的和。找到这些数字。

4. 给出三个正数$x, y, z$。什么条件下存在一个高长为$x, y, z$的三角形？

5. 一本书描述了这样一个案例。一个橡皮球击中房间的门，在墙壁上反射，然后在另一面墙上反射，没有击中任何物体，就准确地击中了它飞进来的门。这可能吗？

九年级
6. 求解方程组
   $\sin x + \sin y = \sqrt{2} \sin a,$
   $\cos x + \cos y = \sqrt{2} \cos a$.

7. 二元方程$x^2 + px - q = 0$有解。数字 $p$ 和 $q$ 发生变化，每个变化不超过其绝对值的 1%。众所周知，更好的方程是：

有一个解决方案。能否保证新方程的最大解与旧方程的最大解的差异不超过后者绝对值的 10%？

8. 容纳四个半径为 1 且不重叠的圆的圆的最大半径是多少？

9. 给定四个长度$a, b, c, d$的线段。在什么条件下可以用它们构造一条封闭的自相交折线，且该折线的三个顶点不在同一条直线上？

10. 画出函数的图形
    $y = |1 - |1 - |1 - |1 - |x|$.

十年级
11. 求解正整数方程 $x^y = 48 261 724 457$。

12. 求函数的一般定义域
    $f_n(x) = \sqrt{x + \sqrt{x + \ldots + \sqrt{x + 1}}}$.

13. 给定一个多面体，其平面截面的边数不超过 4 条。证明这是一个四分体。

14. 原始圆柱体和直圆锥体有一个共同的底座。它们各自的体积都等于1。求它们公共部分的体积。

15. 对于$a$和$b$，公式$\sqrt{x} \approx ax + b$保证$4 \leq x \leq 9$的最准确。换句话说，$a$和$b$是表达式$|\sqrt{x} - (ax + b)|$在$4 \leq x \leq 9$的最准确值？
