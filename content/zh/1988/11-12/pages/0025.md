⟦folio 23⟧

Posny 的公式 $q > 0$ 为 $(x, y) = (1, 0) + (2, 1) + \dots + (q-1, q-2) + (m+q, m+q-1)$，$q = 0$、$m > 0$ 为 $(m, m) = (1, 0) + (m-1, m)$，将 $(x, y)$ 表示为不同生成元之和。

证明条件的必要性也很容易。让
$x = r_1 + \dots + r_a + s_1 + \dots + s_b$
$y = r_1 + \dots + r_a - a + s_1 + \dots + s_b + b$
可摆姿势$x - y = a - b$。让我们把 $q = x - y$ 和
$m = (r_1 - q) + (r_2 - (q - 1)) + \dots$
$\dots + (r_q - 1) + r_{q+1} + \dots + r_a +$
$+ s_1 + \dots + s_b = x + y - q(q + 1)/2$
（这里我们再次使用算术级数之和的公式）。从不等式 (4) 可以得出 $r_a \geq 1, r_{a-1} \geq 2, r_{a-2} \geq 3, \dots$ 以及一般的 $r_i \geq q - i + 1$。 Pozny $m \geq 0$，即 $(x, y)$ 是 (3) 形式的向量，这正是所需要的。

用几何术语来说，陈述 6) 意味着这个数

$$N(x, y)$$ 仅取决于抛物线上的数$m$，而不取决于抛物线上点的数$q$。

令 $T(m, q)$ 为向量 (3) 的表示集合，作为不同生成器的总和，$t(m, q)$ 为此类表示的数量。如果我们证明对于任何整数$q$，等式$t(m, q) = t(m, q - 1)$成立（这意味着$t(m, q)$以及$N(x, y)$，不依赖于$q$），问题就会得到解决。我们在集合$T(m, q)$上方留出满足不等式（4）的序列对集合，使得$r_1 + \dots + r_a + s_1 + \dots + s_b = m + q(q + 1)/2$对应于$q = a - b$。我们将这样的一对写成$(r_1, \dots, r_a | s_1, \dots, s_b)$的形式。

考虑由公式给出的从集合$T(m, q)$到集合$T(m, q - 1)$的映射$\varphi$
$$\varphi(r_1, \dots, r_a | s_1, \dots, s_b) = \begin{cases} (r_1 - 1, \dots, r_a - 1 | s_1 + 1, \dots, s_b + 1, 0), \\ \text{если } r_a > 1, \\ (r_1 - 1, \dots, r_{a-1} - 1 | s_1 + 1, \dots, s_b + 1), \\ \text{если } r_a = 1. \end{cases}$$

练习 6. 检查 $\varphi(r_1, \dots, r_a | s_1, \dots, s_b) \in T(m, q - 1)$。

为了证明$\varphi$是一对一映射，我们构造逆映射$\psi$：$T(m, q - 1) \rightarrow T(m, q)$，读取$\varphi$给出的规则，我们如下：

$$\psi(r_1, \dots, r_a | s_1, \dots, s_b) = \begin{cases} (r_1 + 1, \dots, r_a + 1, 1 | s_1 - 1, \dots, s_b - 1), \\ \text{если } s_b > 0, \\ (r_1 + 1, \dots, r_a + 1 | s_1 - 1, \dots, s_b - 1), \\ \text{если } s_b = 0. \end{cases}$$

构造的映射是互逆的，因此$\varphi$是一一对应的。如前所述，这意味着 $t(m, q) = t(m, q - 1)$。

要了解如何计算 $N(x, y)$ 的值，请在数字 $t(m, q)$ 和 $p(m)$ 之间设置。

陈述：$t(m, q) = p(m)$。

我们已经知道$t(m, q) = t(m, 0)$，所以证明$t(m, 0) = p(m)$就足够了。让我们使用一个简单而有用的图形工具，称为尤尼斯图。
