⟦folio 33⟧

自杂志创刊以来，我们一直在逐期运行此版块。其中发布的问题是非标准的，但它们的解决方案不需要超出学校课程范围的知识。最困难的任务标有星号。创建任务后，我们承诺指出是谁向我们建议的。当然，并非所有这些问题都是第一次发表。

本期问题的解决方案应在 1989 年 2 月 1 日之前发送至地址：103006 Russia K-6, st.高尔基，32/1，«Kvant»。不同数量或不同科目（数学和物理）问题的解决方案被分配在不同的信封中。在信封的“收件人”栏中写下：“问题 «Kvant» 编号 11-12-88”以及您要发送其解决方案的问题编号，例如“M1131”或“F1143”。在“...发件人地址”栏中，请分别写下您的名字和姓氏。附上一个写有您地址的信封（您将在这个信封中收到决策验证的结果）。

提议发表的每个原始问题的条件都与该问题的解决方案一起放在一个单独的信封中，一式两份（在信封上写着：“问题«Kvant»，物理学中的一个新问题”或“......数学中的一个新问题”）。

在每封信的开头，请注明学校编号和您将就读的班级。

任务 M1131 - M1135 是预期的。

任务
M1131—M1140, F1143—F1147

M1131。令$n$为自然数，$A_1, A_2, ..., A_{2n+1}$为某个集合$B$的子集。我们假设
a) 每个集合 $A_i$ ($i=1, 2, ..., 2n+1$) 恰好包含 $2n$ 个元素；
b) 每个集合 $A_i \cap A_j$ ($1 \leq i < j \leq 2n+1$) 只包含一个元素；
b) 集合 $B$ 中的任何元素至少属于集合 $A_i$ ($i=1, 2, ..., 2n+1$) 中的两个。
对于 $n$ 的什么值，可以为集合 $B$ 的每个元素分配数字之一 - 0 或 1 - 以便集合 $A_1, A_2, ..., A_{2n+1}$ 中的每个元素恰好包含与数字 0 相对应的 $n$ 元素？

M1132。函数$f$定义在正整数集合上并满足以下条件：
$$f(1) = 1, f(3) = 3, f(2n) = f(n),$$
$$f(4n+1) = 2f(2n+1) - f(n),$$
$$f(4n+3) = 3f(2n+1) - 2f(n).$$
求 $f(n) = n$ 和 $1 \leq n \leq 1988$ 的 $n$ 的所有值的个数。

M1133。证明不等式的解集
$$\sum_{k=1}^{70} \frac{k}{x-k} \geq \frac{5}{4}$$

是长度总和为 1988 的不相交区间的并集。

M1134。设 $AD$ 为直角三角形 $ABC$、$\angle A = 90^\circ$ 的高度。通过三角形 $ABD$ 和 $ACD$ 内切圆的圆心的直线分别与边 $AB$ 和 $AC$ 相交于点 $K$ 和 $L$。证明不等式$S_{ABC} \geq 2S_{AKL}$。

M1135。令$a$和$b$为正整数，使得$a^2 + b^2$可被$ab + 1$整除而无余数。证明$\frac{a^2 + b^2}{ab + 1}$是整数的平方。

M1136*。证明非负数不等式$A, M, S$
$$3 + (A + M + S) + \left(\frac{1}{A} + \frac{1}{M} + \frac{1}{S}\right) + \left(\frac{A}{M} + \frac{M}{S} + \frac{S}{A}\right) \geq \frac{3(A + 1)(M + 1)(S + 1)}{AMS + 1}.$$

D·P·马夫洛

作者将这个问题献给今年庆祝的美国数学会 (AMS) 成立 100 周年。

M1137。在凸 $n$ 边形中，所有角度都相等，并且从位于 $n$ 边形内部的某个点开始，其所有边都以相等的角度可见。证明这个$n$边形是规则的。

K·P·科哈斯
