（等式两边同时除以未知数$x$，然​​后用二次根式求解方程），可用于计算一些高次代数方程的正根。

让我们通过一个例子来展示这是如何完成的。假设我们需要计算方程的正根
$$x^5 - 10x^3 + 21x - 3 = 0.$$ (7)

将方程左边除以$x$并表示$g(x) = 21 - 3/x$，我们得到二元二次方程$x^4 - 10x^2 + g(x) = 0$，求解得到$x = \sqrt{5 \pm \sqrt{\frac{3}{x}} + 4}$。

让我们选择一个可行的公式：
$$x_{n+1} = \sqrt{5 + \sqrt{\frac{3}{x_n}} + 4}, \quad n = 0, 1, 2, \dots$$

我们在“Elektronka BZ-14M”上进行计算。从$x_0 = 1$开始，我们得到以下一系列逐次逼近：
$$x_0 = 1, \quad x_3 = 2,694692,$$
$$x_1 = 2,765095, \quad x_4 = 2,694672,$$
$$x_2 = 2,693507, \quad x_5 = 2,694672.$$

比较近似值$x_4$和$x_5$，我们发现直到$10^{-6}$满足等式（4）。因此，在相同精度下，根的期望值将为$x = 2,694672$。不过，这仍然需要检查！

以类似的方式，你可以找到其他代数方程的根。我们将以一般形式写其中一些：
1) $x^{2m+1} - ax \pm d = 0,$
2) $x^{2m+1} - 2ax^{2m} \pm bx \pm d = 0,$
3) $x^{2m+1} - 2ax^{2m+1} \pm bx \pm d = 0,$
$a > 0, \quad m = 0, \quad 1, \quad 2, \dots$

所描述的求解方程的方法很方便，因为在提取根的情况下，初始近似值可以是$x_0 = 1$。
