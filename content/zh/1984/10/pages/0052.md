$$N_2 \cos \alpha + N_1 \sin \alpha - mg \cos \alpha - f_{1y} = 0,$$
或者
$$N_2 \cos \alpha + N_1 \sin \alpha - mg \cos \alpha - Mg \cos \alpha = 0. \quad (2)$$
由式(1)和(2)我们求出$N_1$和$N_2$：
$$N_1 = Ma \cos \alpha, \quad N_2 = (M+m)g - Ma \sin \alpha.$$
让我们写出第二个条件，考虑相对于点 $B$ (图 3) 的力矩：

$$N_2 l \cos \alpha - mg \frac{l}{2} \cos \alpha - f_{1x} \sin \beta = 0,$$
其中$x$是此时甲虫的坐标。考虑到$f_1 \sin \beta = f_{1y} = Mg \cos \alpha$，并代入找到的值​​$N_1$和$N_2$，我们得到

$$Mgl - Mal \sin \alpha + mg \frac{l}{2} - Mgx = 0.$$

让我们将这个方程改写如下：

$$x - l \frac{2M+m}{2M} = -a \frac{l \sin \alpha}{g} \quad (3)$$

并引入符号$x - l \frac{2M+m}{2M} = z$、$\frac{g}{l \sin \alpha} = \omega^2$。给定$a = x'' = \left( z + l \frac{2M+m}{2M} \right)'' = z''$，式(3)可写为：

$$z'' = -\omega^2 z.$$

我们得到的方程就是简谐振动方程。在一般情况下，此类方程的解写成以下形式

$$z(t) = A \sin \omega t + B \cos \omega t, \quad (4)$$

构造的$A$和$B$是从初始条件中找到的。在我们的例子中，初始条件（$t=0$）是：

$$x(t_0) = z(t_0) + l \frac{2M+m}{2M} = 0 \Rightarrow z(t_0) = -l \frac{2M+m}{2M},$$

$$x'(t_0) = v_0 \Rightarrow z'(t_0) = v_0.$$

将$t=0$和$z(t_0)$代入式(4)，可得

$$B = -l \frac{2M+m}{2M}.$$

对式（4）求微分，代入$t=0$和$z'(t_0)$，可得：

$$A = \frac{v_0}{\omega}.$$

因此，

$$z(t) = \frac{v_0}{\omega} \sin \omega t - l \frac{2M+m}{2M} \cos \omega t,$$

因此

$$x(t) = \frac{v_0}{\omega} \sin \omega t + l \frac{2M+m}{2M} (1 - \cos \omega t). \quad (5)$$
