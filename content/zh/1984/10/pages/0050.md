将位于高度为 $h_t$（参见 图1）的球面表面，压实到地面。让我们求出这些碎片的质量 $m(t)$。

令$m_0$为所有碎片的质量（弹丸的质量）；然后

$$m(t) = m_0 \frac{S(h_t)}{S(R_t)} = m_0 \frac{2\pi R_t h_t}{4\pi R_t^2} = m_0 \frac{h_t}{R_t},$$

其中$S(h_t)$是高度为$h_t$的球段面积，$S(R_t)$是$t$时刻整个球体的面积。代入$R_t = v_0 t$和$h_t = ut + gt^2/2 + v_0 t - H$（参见图1），我们得到

$$m(t) = m_0 \left( \frac{u + v_0}{2v_0} + \frac{gt}{4v_0} - \frac{H}{2v_0 t} \right).$$

所得公式对于时间间隔 $t_1 \leq t \leq t_2$ 是正确的，其中 $t_1$ 是爆炸后到碎片开始落到地面所经过的时间，$t_2$ 是爆炸后碎片落到地面所经过的时间。我们来求一下$t_1$和$t_2$的值。

第一个落到地面的碎片将是在$A$点速度等于$|\vec{u} + \vec{v}_0| = u + v_0$的碎片；因此，

$$(u + v_0) t_1 + \frac{gt_1^2}{2} = H,$$

在哪里

$$t_1 = \frac{\sqrt{2gH + (u + v_0)^2} - (u + v_0)}{g}.$$

从条件中找到时间$t_2$

$$(u - v_0) t_2 + \frac{gt_2^2}{2} = H,$$

在哪里

$$t_2 = \frac{\sqrt{2gH + (u - v_0)^2} - (u - v_0)}{g}.$$

让我们回到公式（1）。给定时间碎片落到地面的频率是任意$m'(t)$的值的概念：

$$m'(t) = \frac{m_0 g}{4v_0} + \frac{m_0 H}{2v_0 t^2}.$$

显然，$t$越小，$m'(t)$的值就越大。因此，最常见的是，在炮弹爆炸后$t_1$时间（见（2））后，碎片会掉落到地面。

I.I.索洛多夫尼科夫

F884。 N.E.茹科夫斯基问题。甲虫沿着放置在光滑地板和光滑垂直墙壁上的当地（非螺纹）吸管飞行（图1）。秸秆是均质的，其长度为l，质量为m；甲虫质量 M (M>m)。吸管与地平线形成角度a。甲虫在 B 点的初速度等于 v_0。甲虫应该如何移动才能保留稻草

设在某一时刻甲虫沿吸管飞行的加速度等于a。甲虫受到来自吸管的重力 $Mg$ 和反作用力 $\vec{f}$ 的作用。让我们找到力$\vec{f}$的方向。

让我们写出甲虫的运动方程：

$$Mg + \vec{f} = M\vec{a},$$

或者，在 X 和 Y 轴上的投影（参见 图1）：

$$Ma = Mg \sin \alpha + f_x, \quad f_y - Mg \cos \alpha = 0.$$
