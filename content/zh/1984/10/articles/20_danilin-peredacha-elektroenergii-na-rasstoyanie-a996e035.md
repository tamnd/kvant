远距离输电

物理和数学科学候选人
V.A.达尼林

目前，电能从发电机到消费者的传输主要通过使用交流电的电线进行。在这种情况下，必然会发生能量损失，这主要是由于电线的加热造成的。可以通过减少电源线中的电流来减少损耗，即通过增加发电机输出端的电压（以便传输的功率保持不变）。

为了让消费者直接使用电能，必须降低线路末端（即消费者输入端）的电压。

在交流电的情况下，使用变压器来升高和降低电压。

交流发电机如何工作？变压器的工作原理是什么？什么决定了电源线的损耗？申请人可能会因重复“电能的生产、传输和使用”主题而提出这些问题和类似的问题。我们将使用几个特定任务的示例来讨论其中一些。几乎所有的人都曾一度被莫斯科物理技术学院录取参加高级考试。

问题 1. 将电压从 $U_1=100$ V 增加到 $U_2=3300$ V 的变压器具有环形闭合铁芯 (图 1)。一根电线穿过铁丝网，其末端连接到电压表。电压表显示电压为$U=0,5$V。变压器每个绕组有多少匝？

在闭环磁芯中，实际上整个磁场都集中在其中，磁通量在其所有部分都是相同的。磁芯上的任何匝数，无论属于哪个绕组，感应电动势的瞬时值都是相同的，因为根据电磁感应定律，它是由磁芯中磁通量的变化率决定的：$e=-\frac{\Delta\Phi}{\Delta t}$。

如果变压器绕组包含$n_1$和$n_2$匝数，则这些绕组中的感应电动势等于相应的$e_1=n_1e$和$e_2=n_2e$。

显然变压器绕组的有功电阻很小，可以忽略不计。对于连接电压表的电线也可以这样说。那么在任何时刻，等式$u=-e, u_1=-e_1, u_2=-e_2$都是有效的。

这里$u$是电线末端的瞬时电压值，$u_1$是初级绕组上的电压，$u_2$是变压器开路次级绕组上的电压。

由于所有电动势都发生在同一相，因此它们的比率可以用相应有效值的比率来代替，因此，考虑到前面的等式，可以用有效电压值的比率来代替：

$$\frac{e_1}{e} = \frac{\varepsilon_1}{\varepsilon} = \frac{U_1}{U}, \frac{e_2}{e} = \frac{\varepsilon_2}{\varepsilon} = \frac{U_2}{U}.$$

从这里我们可以找到每个绕组的匝数：

$$n_1 = \frac{e_1}{e} = \frac{U_1}{U} = 200,$$

$$n_2 = \frac{e_2}{e} = \frac{U_2}{U} = 6600.$$

任务 2. 发电机产生的电力通过电线传输给消费者。导线电阻$r$，负载电阻$R$，发电机电压$U$。确定输电线路的效率，即提供给负载的功率与发电机提供的总功率之比。在多大的负载电阻下，最大有用功率是多少？

根据完整电路的欧姆定律，线路中的电流

$$I = \frac{U}{r + R}.$$

发电机功率

$$P = UI = \frac{U^2}{r + R},$$

分配给负载的功率，

$$P_H = I^2 R = \frac{U^2 R}{(r + R)^2}.$$

效率系数

$$\eta = \frac{P_H}{P} = \frac{U^2 R(r + R)}{(r + R)^2 U^2} = \frac{R}{r + R}.$$

当$R$减小到零并且当$R$无限增加时，$P_H$值减小到零。这意味着在某个中间值$R = R_M$，有用功率应达到其最大值。

让我们检查函数 $P_H(R)$ 的最大值。为此，我们找到 $P_H(R)$ 对 $R$ 的导数并将其等于零：

$$P'_H(R) = U^2 \frac{(r - R)}{(r + R)^3} = 0.$$

由此我们得知，如果$R = r$，则分配给负载的功率最大。同时$P_{H\max} = U^2/(4r)$。在这种情况下，线路效率为$\eta = 1/2$——一半的发电机功率被无用地浪费了。

任务 3. 电源线可以在两个不同的发电机电压$U_1$和$U_2$以及相应的负载电阻$R_1$和$R_2$下运行。这些连接点的电源线上的功率需求比为 $\alpha$。确定比率$U_2/U_1$，前提是两个合并中发电机的功率相同。

让电源线的电阻等于 $r$ - 该值不会改变。发电机输出的总功率为

$$P = UI = \frac{U^2}{r + R},$$

其中$I$是电路中的电流。热损失功率

$$P_n = I^2 r = \frac{U^2}{(R + r)^2} r.$$

$U$和$R$不同值的功耗之比等于

$$\frac{U_1^2}{(R_1 + r)^2} r : \frac{U_2^2}{(R_2 + r)^2} r = \alpha.$$

根据问题的条件，在两次合并中发电机产生相同的功率：

$$\frac{U_1^2}{R_1 + r} = \frac{U_2^2}{R_2 + r}.$$

从最后两封信函可以看出

$$\frac{U_1^2(R_2 + r)^2}{U_2^2(R_1 + r)^2} = \alpha, \frac{U_1^2}{U_2^2} = \frac{R_1 + r}{R_2 + r}.$$

在哪里

$$\frac{U_2}{U_1} = \sqrt{\alpha}.$$

以这个问题为例，可以看出传输能量的电压对输电线路热损失的大小影响有多大。将电压提高$\alpha$倍就足够了，损耗就会减少$\alpha^2$倍。

$r=100$ 欧姆 (图 2)。建立固定模式后，按键打开。求出现在绕组末端的电压幅值与电源电动势的关系。

在稳定状态下，恒定电流流过变压器绕组

$$I = \frac{\varepsilon}{r},$$

绕组上的电压以及电容器上的电压为零。

当钥匙$K$打开时，磁通量发生变化，从而在绕组末端产生电压。其幅度可以通过考虑由电感器$L$和电容器$C$组成的电路中的振荡来找到。直流电流动期间存储在线圈中的能量将在四分之一振荡周期后转换为充电电容器的能量：

$$\frac{LI^2}{2} = \frac{CU_m^2}{2}.$$

因此，电容器上以及变压器绕组两端的电压幅度等于

$$U_m = \sqrt{\frac{L}{Cr}} \varepsilon = 100 \varepsilon.$$

正如你所看到的，重量超载很大。实际上，当流过线圈的电流在与其连接的电容器的电容值较低时被关闭时，总是会发生这种情况。
