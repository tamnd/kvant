在任何学校教科书中，有关指数函数和数字 e 的主题的介绍都包含未经证实的陈述、简要陈述的段落。这是由主题的复杂性来解释的。在这里，我们将讨论这些概念的不同方法，探索它们的含义以及与微分方程的联系。用这种表示方法，还存在未经证实的陈述（名词的一般定理和微分方程的唯一性以及连续函数取中间值的性质）。然而，这些未经证实的陈述具有简单的视觉意义，并且对于所有数学都具有根本重要性。

1. 关于物体在阻力环境中坠落的问题

下降的跳伞者受到重力和空气阻力的影响（微分方程的剩余可能性和连续函数取中间值的性质）。空气阻力可以认为与速度$v$成正比，即大小等于$qv$（系数$q$主要取决于降落伞的直径和形状）。因此，

$$ma = mg - qv,$$

其中$a = v'$为加速度值（$qv$前面的负号是因为空气阻力作用与下落方向相反；图1）。除以 $m$ 我们得到

$$v' = -\frac{q}{m} v + g.$$ (1)

对应关系(1)是一个线性微分方程：未知函数$v = v(t)$的导数（需要根据该方程确定）表示为该未知函数的一次多项式。用 $y = y(x)$ 表示未知函数，用 $a$ 和 $b$ 表示系数，我们将微分方程写成以下形式

$$y' = ay + b.$$ (2)

该微分方程不仅描述了物体在阻力介质中的下落，还描述了多维物理过程。

2. 存在唯一性定理

定理1. 无论实数$x_0, y_0$是多少，都只有一个函数$y = y(x)$，它是方程（2）的解并且满足相应的方程$y(x_0) = y_0$。该解是在整条数轴上定义的。

关系 $y(x_0) = y_0$ 称为 naal 条件。因此，定理 1 意味着对于任何给定的最终条件，方程 (2) 都有一个解（而且是一个唯一的解）。

我们来介绍这个定理的几何理论，并考虑$a = 1$，$b = 2$时的特殊情况，即取方程

$$y' = y + 2.$$ (3)

在$y = 0$（在$x$轴上）的点处，根据（3），我们有$y' = 2$，即原函数$y(x)$的图形在这些点处的切线斜率应等于2。让我们在横坐标轴的点上画短线来勾勒出切线（图2）的方向。进一步，对于$y = 1$，根据式(3)，有$y' = 3$，即在直线$y = 1$的各点处，原函数图的切线斜率必须等于3；让我们用短划线标记直线 $y = 1$ 点处的切线方向。然后我们可以在平行于 x 轴 (图 2) 的其他线上标记线。现在，这个“方向场”的“场线”的行为变得清晰起来。在每个点，“力线”都与相应的线相切，即其切线的角度系数为$y'$，由于线的构造，该角度系数等于$y + 2$。这意味着“场线”是满足方程（3）的函数的图形。从图中可以清楚地看出，通过每个点$(x_0; y_0)$都有一条“力线”，而且只有一条。这清楚地证实了定理1的有效性。其证明

满足微分方程$y'=y$和初始条件$y(0)=1$的函数称为指数函数，用符号expr表示。

注意到方程$y'=y$是方程(2)的偏随机方程；因此，根据定理1，其初始条件$y(0)=1$的解存在且唯一确定，且该解的定义域（即指数）是一条直线。

直接从定义得出指数是可微函数并且其导数与同一函数一致（因为它是方程 $y'=y$ 的解）：

$$\text{exp } x' = \text{exp } x.$$  (4)

定理2.函数expr的值为正数，即expr$>0$，对于任何实数$x$。

证明。让我们假设 expr $x_0=0$ 对于某些$x_0$。那么函数$y=\text{exp } x$满足方程$y'=y$和条件$y(x_0)=0$。函数$y\equiv 0$还满足方程$y'=y$和条件$y(x_0)=0$。而且，函数$y=\text{exp } x$和$y\equiv 0$是不同的（例如expr$0=1$，即expr$0\neq 0$）。但事实证明，方程$y'=y$在初始条件$y(x_0)=0$下有两个不同的解，这与定理1相矛盾。因此，等式表达式$x=0$对于任何$x$都不成立。

现在让我们假设对于某些 $x_1$，我们有 expr $x_1<0$。函数 expr 是可微的，因此是连续的；因此，在取不同符号值的两个点之间（$\text{exp } x_1<0$，expr$0=1$），该函数必须消失（图3）。但正如我们所见，这是不可能的。

因此，指数既不能取零值，也不能取负值；因此对于任何$x\in R$，expr $x>0$。

结果。指数是递增函数。

定理 3. 对于任意 p, q ∈ R 我们有

$$\exp(p+q) = \exp p \cdot \exp q.$$ (5)

证明。考虑函数 y = exp(p+x)。我们有

$$y' = (\exp(p+x))' = \exp(p+x) = y$$

也就是说，这个函数也满足方程y'=y。在这种情况下 y(0) = exp p。根据定理 1，所考虑的函数是一致的：

证明。继续应用式(5)，我们发现
$$\exp 2x = \exp (x+x) = \exp x \cdot \exp x = (\exp x)^2,$$
$$\exp 3x = \exp (2x+x) = \exp 2x \cdot \exp x = (\exp x)^2 \cdot \exp x = (\exp x)^3$$
等等 所以，对于自然的 $n$ 我们有
$$\exp nx = (\exp x)^n,$$
从哪里$\exp x = (\exp nx)^{1/n}$。这里的字段是$x=m/n$（其中$m$是自然数），我们得到
$$\exp \frac{m}{n} = (\exp m)^{1/n} = (\exp m \cdot 1)^{1/n} = \left((\exp 1)^m\right)^{1/n} = (\exp 1)^{m/n} = e^{m/n}$$
这意味着对于正有理数$x=m/n$，所证明的引理是有效的。很容易检查它对于负有理数（以及$x=0$）仍然有效。
根据定义，条件是假设对应关系（7）对于任何实数$x$都有效。换句话说，我们假设$e^x$只是$\exp x$的另一种书写形式（对于有理$x$，这种书写形式凭借已证明的引理与带有有理指数的可理解公式是一致的）。当使用这种表示法时，公式（5）采用熟悉的形式$e^{p+q} = e^p e^q$。请注意，在数学文献中使用了两种书写指数的公式：$y=e^x$ 和 $y=\exp x$。

6. 求解微分方程

在编写微分方程的解时，经常使用符号 $e^x$ 而不是 $\exp x$。我们将坚持这一传统。

定理 4. 对于 $a \neq 0$，初始条件为 $y(0)=y_0$ 的微分方程 (2) 的解具有以下形式
$$y = -\frac{b}{a} + ce^{ax},$$
(8)
$$e\delta e = b/a + y_0.$$
证明。由于（根据定理 1）消除了唯一的一个，因此只需检查函数（8）（对于$c$的指定值）满足方程（2）和所需的初始条件就足够了。我们有
$$y' = (ce^{ax})' = c(e^{ax})' = cae^{ax} = a(ce^{ax}) = a(y + \frac{b}{a}) = ay + b,$$
也就是说，函数（8）确实满足方程（2）（对于常数$c$的任何值）。下一个，
$$y(0) = -\frac{b}{a} + ce^0 = -\frac{b}{a} + c = -\frac{b}{a} + \left(\frac{b}{a} + y_0\right) = y_0.$$
这意味着对于指定值$c$，函数$y$也满足所需的初始条件。

已证明的定理有望应用如下。术语 $y = -b/a$ 很容易记住：如果 $y'$ 等于 0，则获得它；此外，(2) 中未知函数的系数 $a$ 成为指数中自变量的系数。至于常态$c$，它的值（如定理4所示）通常不会被记住，并且在每个特定示例中$c$都是使用初始条件找到的。

例1. 在时刻$t$，一块岩石中存在的放射性物质的质量$m(t)$随着时间的推移而减小，即导数$m'(t)$（衰变率）为负。如果需要，放射性物质的量，衰变率与放射性物质的质量成正比：
$$m' = -km$$
（其中系数$k > 0$取决于放射性物质的类型）。如果在初始时刻$t=0$可用放射性物质的质量等于$m_0$，求质量$m(t)$随时间的变化规律。

解决方案。根据定理 4，我们有 $m(t) = ce^{-kt}$。代入$t=0$，我们得到$m_0 = ce^0$，因此$c = m_0$。最终结果是$m(t) = m_0e^{-kt}$。

例2. 多长时间$T$后，放射性物质的量会减少一半？

解决方案。我们需要从方程$m_0/2 = m_0e^{-kT}$中找到$T$，即$e^{-kT} = 1/2$或$e^{kT} = 2$。这对应于以下平衡：$\ln 2 = kT$，因此$T = (\ln 2)/k \approx 0.7/k$。

值$T = (\ln 2)/k$称为半衰期。取决于$k$（即放射性物质）；例如，镭$T \approx 1600$年。

示例 3. 求物体在阻力介质中下落的定律，已知在 $t=0$ 时下落速度等于 $v_0$。

解决方案。由式（1）由定理4可知：

$$v(t) = \frac{mg}{q} + ce^{-\frac{q}{m}t}.$$

代入$t=0$，我们得到$v_0=mg/q+ce^0$，因此$c=v_0-mg/q$。这样，我们最终就有了

$$v(t) = \frac{mg}{q} + \left(v_0 - \frac{mg}{q}\right)e^{-\frac{q}{m}t}.$$

从$e^{-\frac{q}{m}t} \to 0$到$t \to \infty$，然后$v(t) \to mg/q$，就变成了，下降率逐渐建立。例如，跳远运动员高速下落，打开降落伞后，很快获得近似恒定的速度$mg/q$（取决于降落伞的质量和降落伞的参数）。这样可以计算降落伞，以便安全着陆。
