$$\begin{align*}
(1-z) (1+z) &= 1-z^2, \\
(1-z^2) (1+z^2) &= 1-z^4, \\
(1-z^4) (1+z^4) &= 1-z^8,
\end{align*}$$

乘以并减少公因数后，他得到

$$1-z (1+z) (1+z^2) (1+z^4) (1+z^8) \cdot \dots = 1,$$

即$(1-z) \alpha(z) = 1$，从哪里

$$\alpha(z) = \frac{1}{1-z} = 1+z+z^2+z^3+z^4+\dots$$

（这里写的是著名的几何级数总和*）。 (3)与(2)的比较表明，对于所有$k$，$A_k = 1$，即任何整数克的负载都可以以独特的方式以1、2、4、...、$2^m$、...克的数字表示。

号码划分问题

这就是欧拉所说的以下问题：找到方程的正整数解的数量

$$x_1 + \dots + x_m = k,$$

(4)

food $m$ 和 $k$ 是固定的自然数。这里另一个意想不到的表达导致了目标，即

$$\beta(z) = (1+z+z^2+z^3+z^4+\dots)^m.$$

展开括号后，$\beta(z)$可写为

$$\beta(z) = 1+B_1z+B_2z^2+B_3z^3+\dots$$

(6)

$B_k$等于什么？尝试自己回答这个问题，记住$B_k$是$z^k$的系数。是的，当然：系数$B_k$等于从（5）右边的每个括号中选择一个整数指标的方式数，即$B_k$等于式（4）的正整数解的数量！

欧拉的问题简化为计算$B_k$。

为此，请记住几何级数的公式，您可以写

$$\beta(z) = (1-z)^{-m} = 1+B_1z+B_2z^2+B_3z^3+\dots$$

(7)

区分这个等式

$$m(1-z)^{-m-1} = B_1+2B_2z+3B_3z^2+\dots$$

代入$z=0$，我们得到$B_1=m$。

再次微分并再次代入$z=0$，我们得到$B_2=m(m+1)/2$。以完全相同的方式继续下去（即继续方程（7）$k$次并代入$z=0$），根据欧拉，我们得到方程（4）的解数，形式为

$$B_k = \frac{m(m+1) \cdot \dots \cdot (m+k-1)}{n!}$$

兑换问题

卢布可以用多少种方式兑换 1、2、3、5、10 戈比的硬币？这个问题可以用不同的方式表述：方程有多少个非负整数解？

$$x_1+2x_2+3x_3+5x_4+10x_5=100?$$

在更一般的形式中，“交换问题”提出如下：方程有多少个非负整数解？

$$a_1x_1+a_2x_2+\dots+a_mx_m=n,$$

(8)

如果$a_i$是正整数并且$n$是固定自然数怎么办？

考虑表达式

$$\gamma(z) = (1+z^a_1+z^a_2+z^a_3+\dots) \times (1+z^a_2+z^a_2+z^a_3+\dots) \times (1+z^a_m+z^a_m+z^a_m+\dots) = 1+C_1z+C_2z^2+C_3z^3+\dots$$

如果你理解了前面的推理，你马上就会说$C_n$这个数等于方程（8）的解的个数。但如何找到$C_n$呢？使用无限递减几何级数之和的公式（例如，$1+z^a_1+z^a_2+\dots=1/(1-z^a_1))$，您可以用以下形式表示 $\gamma(z)$）

$$\gamma(z) = \frac{1}{(1-z^a_1)(1-z^a_2)\dots(1-z^a_m)},$$

但从这里并不能立即清楚在一般情况下如何获得$C_n$。然而，对于较小的$n$，公式（9）已经足以找到$C_n$。

四平方问题

每个整数都可以表示为四个整数的平方和，如果可以，有多少种方式？换句话说，方程有多少个整数解？

$$x_1^2+x_2^2+x_3^2+x_4^2=m,$$

(10)

food $m$ 是给定的自然数吗？

这项任务比前面的任务要求更高，尽管它像它们一样归结为计算某个“无限多项式”的系数。即，把

$$\delta(z) = \frac{1 + 2z + 2z^4 + 2z^9 + 2z^{16} + \dots}{1 + D_1z + D_2z^2 + D_3z^3 + \dots},$$

容易理解，式（10）所需解的个数等于$D_m$。对$m$次微分，代入$z=0$，可得$D_m$的形式

$$D_m = \frac{1}{m!} \frac{d^m}{dz^m} \left( \delta(z) \right) |_{z=0}$$

其中$\frac{d^m}{dz^m}$表示对$m$阶求导，符号$|_{z=0}$表示$z$一起需要用0代替。对于小的$m$，$D_m$可以用这个公式来计算，但一般来说并不容易。原来数论中的问题从分析上已经还原为某种问题，但后者仍然需要解决！

根据德国数学家 K. G. Jacobi（1804-1851）的结果，得出了一个非凡的 $\delta(z)$ 公式

$$\delta(z) = 1 + 8 \sum_{m \neq 4k} \frac{mz^m}{1 - z^m},$$

印度数学家 S. Ramanujan (1887-1920) 也收到了该书。由此我们可以推断方程（10）总是可解的，并找出该方程的解数。

方法讨论

现在让我们尝试了解一般方法的组成，该方法在所分析的问题中效果出奇地好。在它们中的每一个中，都考虑了包含字母$z$的某个“无限表达式”（两个人的无限乘积 - (1)，无限和的有限幂 - (5) 和 (11)，无限和的乘积 - (9)）。此外，这个表达式被写成“$z$中的无穷多项式”的形式，即形式

$$\alpha(z) = A_0 + A_1z + A_2z^2 + A_3z^3 + \dots + A_nz^n + \dots,$$

事实证明，系数$A_k$提供了解决问题的关键。然后可以通过对无限表达式进行各种运算来计算系数$A_k$：对它们进行算术运算，对它们进行微分，根据几何级数公式进行变换......

人们很自然地会问：我们正在考虑的无限表达式是什么，对它们执行的操作是否合法？该方法的作者莱昂哈德·欧拉（Leonhard Euler）显然没有对这些问题考虑太多——他将无限表达式视为有限表达式，对他来说重要的是获得结果。同时，对无穷大的粗心处理也会带来出错的危险。

自命不凡的例子

考虑两个“无限多项式”

$$\alpha(z) = 1 - z + z^2 - z^3 + z^4 - \dots,$$

$$\beta(z) = -1 + z - z^2 + z^3 - z^4 + \dots$$

并计算无穷总和

$$S(z) = \alpha(z) + \beta(z) + \alpha(z) + \alpha(z) + \dots$$

如果我们将 $S(z)$ 中的项成对分组，从第一对开始，我们得到

$$S(z) = [\alpha(z) + \beta(z)] + [\alpha(z) + \beta(z)] + \dots = \alpha(z) + 0 + 0 + \dots = \alpha(z)!$$

不是，如果你以不同的方式分组，你可以获得

$$S(z) = \alpha(z) + [\beta(z) + \alpha(z)] + [\beta(z) + \alpha(z)] + \dots = \alpha(z) + 0 + 0 + \dots = \alpha(z)!$$

如果你改变这些项的顺序，你可能会得到一个更奇怪的结果，例如，$S(z) = 17z^{17}$（想想这是如何做到的）。

也许是时候给出无限表达式的精确定义并找出对它们的合法操作了。

正式学位系列

相邻的形式幂称为表达式

$$\alpha(z) = a_0 + a_1z + a_2z^2 + \dots + a_nz^n + \dots,$$

其中$a_i$是实数（级数（12）的系数），$z$是简单符号（级数的形式变量）。数学家还说$\alpha(z)$是系数序列$a_0, a_1, \dots, a_n, \dots$的生成函数。然而，人们不应该认为在我们考虑的一般情况下，$\alpha(z)$是一般意义上的变量$z$的函数。当我们说$\alpha(z)$是序列$a_0, a_1, \dots, a_n, \dots$的生成函数时，它仅意味着$\alpha(z)$是（12）正确部分中形式表达式的简写符号。

对于熟悉级数（教育）幂概念的读者，需要强调的是，可以考虑形式级数（12）（对于某些$z$甚至对于所有$z$），但同时等式（12）仍然合法：毕竟，$\alpha(z)$并不表示给定值$z$的级数之和，而是表示形式级数本身。

德国杰出数学家维尔斯特拉斯（K. Weierstrass，1815-1897）发展了级数幂并将其置于不同的逻辑基础上，他只考虑级数的降幂，并批评欧拉犯下了“无限多项式”的诡计。我们在这里所触及的形式幂级数的现代代数理论已经得到实现，但本质上它更接近欧拉的“朴素”方法，而不是魏尔斯特拉斯分析理论的结构。

形式幂级数可以进行加法和乘法。除了级数$\alpha(x)$（见（12））之外，让我们给出一个正式的

动力系列
$$\beta(z) = b_0 + b_1z + b_2z^2 + \dots + b_nz^n + \dots$$
(13)

然后这些级数的和与积由自然公式确定：
$$\alpha(z) + \beta(z) = (a_0 + b_0) + (a_1 + b_1)z + \dots + (a_n + b_n)z^n + \dots,$$
$$\alpha(z) \cdot \beta(z) = a_0b_0 + (a_1b_0 + a_2b_1)z + (a_0b_2 + a_1b_1 + a_2b_0)z^2 + \dots$$
(14)
（这些动作的执行规则类似于有限多项式加法和乘法的常用规则）。顺便说一下，请注意，普通多项式可以被视为形式幂级数的一种特殊情况 - 一种标称幂级数，其中从某些系数开始，所有系数都等于 0。在这种情况下，通常的多项式加法和乘法当然将与它们作为形式幂级数的加法和乘法一致。

此外，形式幂级数可以微分和内化。根据定义
$$\frac{d}{d(z)} (\alpha(z)) = (\alpha(z))' = a_1 + 2a_2z + 3a_3z^2 + \dots + na_nz^{n-1} + \dots,$$
$$\int \alpha(z) = \int_0^z \alpha(x)dx = a_0z + \frac{a_1}{2}z^2 + \frac{a_2}{3}z^3 + \dots + \frac{a_n}{n+1}z^{n+1} + \dots$$

对于以这种方式定义的无穷级数的加法和乘法，将满足类似于数或多项式的性质。即，满足交换律、组合律和分配律。

与整数一样，您可以从任何形式级数中减去任何其他级数，并再次获得形式幂级数。形式幂级数域中的除法并不总是可能的，就像两个整数的除法并不总是可能的一样。比如不能在“零”上做，即不能在一行上做
$$0 = 0 + 0 \cdot z + 0 \cdot z^2 + \dots + 0 \cdot z^n + \dots$$
无法划分“单位”，即一系列
$$1 = 1 + 0 \cdot z + 0 \cdot z^2 + \dots + 0 \cdot z^n + \dots$$
每行
$$z = 0 + 1 \cdot z + 0 \cdot z^2 + \dots + 0 \cdot z^n + \dots$$

事实上，假设有一个系列
$$\alpha(z) = a_0 + a_1z + a_2z^2 + \dots,$$
其中$\alpha(z) \cdot z = 1$，或者，
$$\left(a_0 + a_1z + a_2z^2 + \dots\right) \times \left(0 + 1 \cdot z + 0 \cdot z^2 + \dots\right) = 1 + 0 \cdot z + 0 \cdot z^2 + \dots$$

但从式（14）可以得出$a_0 \cdot 0 = 1$，这当然是不可能的。

类似地，可以证明$\alpha(z) = a_0 + a_1z + a_2z^2 + \dots$能被$z^n$整除当且仅当$a_0 = a_1 = a_2 = \dots = a_{n-1} = 0$。

很容易检验只要$a_0 \neq 0$，1就可以被$\alpha(z)$整除，并且系数是通过一系列独特的定义获得的。

例如，让我们找出“单位”除以系列 1-z 的结果。让$(1-z)(a_0 + a_1z + a_2z^2 + \dots) = 1 + 0 \cdot z + 0z^2 + \dots$

然后，打开括号并使相同幂$z$的系数相等，我们得到一个等式系统
$$1 \cdot a_0 = 1, a_1 - a_0 = 0, a_2 - a_1 = 0, \dots, a_n - a_{n-1} = 0, \dots,$$
$a_0 = a_1 = \dots = a_n = \dots = 1$来自哪里，即
$$\frac{1}{1-z} = 1 + z + z^2 + z^3 + \dots + z^n + \dots$$

我们已经以不同的名称使用了这个公式（参见上面的（3）和第 10 页的注释）；这里这个公式是形式幂级数的真正等式（并且条件$|z| < 1$与之无关）。

无限的总和和乘积

学之初解决问题，劳作无穷；无限和也同样有用（特别是，形式幂级数可以被视为无限数字和）。为了避免混淆，我们对这些概念给出了必要的定义。

令 $\alpha_1(z), \alpha_2(z), \dots, \alpha_k(z), \dots$ 为形式幂级数序列（特别是多项式）。我们想要定义一个无限和和一个无限乘积：
$$\left(\alpha_1(z)\right) + \left(\alpha_2(z)\right) + \dots + \left(\alpha_k(z)\right) + \dots,$$
(15)
$$\left(\alpha_1(z)\right) \cdot \left(\alpha_2(z)\right) \cdot \dots \cdot \left(\alpha_k(z)\right) \cdot \dots$$
(16)

与上面的方式相同，即打开括号并引入类似的

纽约会员。然而，这样的定义并不适合一般情况。事实上，如果，例如，在“无限产品”中

$$(1+z)(1+z) \cdot \dots \cdot (1+z) \cdot \dots$$

我们开始打开括号并添加类似的系数，我们将立即看到系数（例如，$z^2$）随着我们打开括号而增长并继续增长。这个例子与之前分析的工作有根本的不同

$$(1+z)(1+z^2)(1+z^4) \cdot \dots$$

$$\dots \cdot (1+z^{2m}) \cdot \dots$$

其中初始系数是逐渐设置和改变的，因为在“远”括号中不存在具有“低”程度的形式变量的单项式。

因此，只有在打开括号并引入相似项时系数稳定，才可以确定无限和 (15) 和无限乘积 (16) - 就像以这种方式获得的系数的形式幂级数一样。

“稳定”的精确定义是这样的：对于每个自然数$d$，都有一个自然数$n$，使得对于$n \geq N$，级数$a_n(z)$不包含$z$小于$d$的幂。

我们对形式幂级数理论的简短探讨到此结束。我们建议读者此时停止阅读，返回到文章开头的示例，并确保它们没有使用无限多项式执行复杂的技巧，而是使用形式幂级数执行完全合法的运算。

生成函数

细心的读者在分解文章开头的示例时可能会注意到，该方法的成功与以紧凑形式编写形式幂级数 $a(z)$ 的生成函数的能力相关。因此，例如序列 1, 1, 1, ... 的生成函数可以写为 $1/(1-z)$，或者

$$\frac{1}{1-z} = 1+z+z^2+\dots+z^n+... \tag{17}$$

从这个对应关系出发，可以得到许多其他特定的生成函数。例如，将(17)两边乘以$z$并微分，我们得到

$$\left( \frac{z}{1-z} \right)' = 1+2z+3z^2+\dots+(n+1)z^n+... \tag{18}$$

这意味着函数 $(z(1-z))' = 1/(1-z)^2$ 正在为序列 1, 2, 3, 4, ... 生成。

乘以$z$并再次微分，我们得到

$$\frac{1+z}{(1-z)^3} = 1+2^2z+3^2z^2+\dots+(n+1)^2z^n+... \tag{19}$$

我们找到了序列 $1^2, 2^2, 3^2, 4^2$ 的生成函数的显式表达式，...

熟练用“角”除多项式的读者可以通过另一种方式得到对应关系（19），即用多项式$1+z$除以多项式$1-3z+3z^2-z^3$。

再次从 (17) 开始，但现在积分，我们得到

$$\int_0^z \frac{dx}{1-x} = \int_0^1 dx + \int_0^z xdx + \dots + \int_0^z x^ndx + \dots,$$

$$-\ln(1-z) = z + \frac{z^2}{2} + \frac{z^3}{3} + \dots$$

我们看到序列 1, 1/2, 1/3, ... 的生成函数将是函数 $-\ln(1-z)/z$。

让我们仅限于这些例子并继续讨论通过生成函数的方法解决的问题。
