⟦folio 36⟧

顽皮的任务

来自数学口语考试

本笔记将提出几个来自数学口语考试练习的简单问题。但头脑空空的人不会看不起他们，也不会扫除那些用错误解决了他们的人。决定口试并不像在家中坐在餐桌旁那么容易：意志、不熟悉的考官、申请人的压力以及责任往往会导致匆忙、失去必要的谨慎，有时甚至会导致“突然”的不可挽回的错误。为了避免它们，你需要像对待困难的问题一样认真地对待口语考试中提出的简单问题。不要放弃计算 - 通过提前思考一点，您可以避免失败或简化解决方案的过程，从而提高自己在考官章节中的地位。

在口语考试中，我喜欢出这样的题：求解方程 sin x = π/3。

很多时候申请人会立即写信

$$x = (-1)^k \arcsin \frac{\pi}{3} + k\pi, \quad k \in \mathbb{Z},$$

并回答问题：“那么他会有多少个决定？” - 他回答说：“无数。”有时它会像这样延续之前的等式：

$$x = (-1)^k \frac{\sqrt{3}}{2} + k\pi, \quad k = 0, \pm 1, \pm 2, \dots,$$

(!)

坐在桌边的读者可能很久以前就说过，π/3 > 1，因此这个方程无解。在考试环境中展示这种沟通水平和冷静非常重要。我希望我的考试库中的其他简单任务（带有一些技巧）能够帮助您解决此问题。我建议您自己解决这些问题，然后查看有关它们的评论，并且仅在必要时查看杂志末尾的“答案、说明、解决方案”部分。如果有很多错误，请练习 - 本文末尾有一些额外的任务。

任务
1. 求解方程 sin √x = -1。
2. 求解 x 的不等式 ax + b ≥ 0。
3. 解决系统

$$\begin{cases} |x - y| = x + y, \\ |x + y| = x - y. \end{cases}$$

4. 求解不等式 x sin 3x > 3x。
5. 求解不等式 √4 + 3x - x² > -2。
6. 求解 x 不等式

$$\frac{x^2 - 2x + 2^{|x|}}{x^2 - 1} < 0.$$

7. log2 3 和 log₅ 8 哪个更大？
8. 绘制函数图

$$y = \lim_{n \to \infty} \frac{x^n}{1+x^n}, \quad x \in [0; +\infty].$$

9. 在AB段上，正如在直径上一样，构造了一个半电路。 C点和D点将半帧分成三个拥挤的部分。证明以弦AC、AD和弦CD为界的图F的面积adb等于半框面积的三分之一。
10. 给出了四个桶，其中三个是钝的。证明包含锐线顶点的非三角形的对角线大于其他对角线。
11. 计算所有向量的和，每个向量的起点位于正则 n 重的中心，结束点位于该 n 重的顶点。
12. 是否有25条边的流形？
13. 在三辐条SABC的底边，从边d开始有一个正三角形ABC，边SA、SB、SC的长度分别等于a、b，相应的边长为a、b。在侧边SA、SB和SC上，分别选择点P、Q和R，使得|SP|:|SA| = |SQ|:|SB| = |RC|:|SC| = 1:2。平面 PQR 与 SABC paramda 的体积有何关系？

对任务的评论
1. 出于某种原因，许多申请人说这个方程没有解，因为函数 y = √x 不取负值。解决方案很容易找到。
2. “答案”x ≥ b/a 不完整！
3. 许多申请者花费很长时间在氧气平面上绘制区域并寻找它们的交点，但他们经常犯错误。利用系统的对称性。
4. 这里又是属性 |sin x|让生活更轻松。 ≤ 1。
