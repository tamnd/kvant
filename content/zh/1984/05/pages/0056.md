数学
笔试
选项1
（力学、数学、物理、经济学院）
1. 解方程
$$1 + 2\sqrt{2} \sin \left( x + \frac{\pi}{4} \right) = 2 \sin x.$$
2. 对于不等式的解中参数$a$的取值
$$\log_2 (x - 100) - \log_2 \frac{|x - 101|}{(105 - x)} + \log_2 \frac{|x - 103|}{(105 - x)} > a$$
包含单个整数？
3. 两个圆心之间的距离是5r。其中一个圆的半径为 $r$，第二个圆的半径为 7r。大圆的弦与小圆相切，并除以接触点，比例为 1:6。求这个和弦的长度。
4. 给定一个立方体 $ABCD'B'C'D'$，其底边为 $ABCD$，侧边为 $AA'$、$BB'$、$CC'$ 和 $DD'$。由于$\alpha$垂直于线$A'C'$，并且平面$\beta$平行于线$CD'$。平面 $a$ 和 $b$ 之间可能的最小角度是多少？
5. 将整数 $B$ 将最后一位移至第一位，得到九位整数 $A$，用十进制表示。此外，已知数字$B$与数字18和$B > 22222222$互质。找到满足这些条件的数字 $A$ 的最大和最小平均值。
如果两个自然数除了一个之外没有公约数，则称它们互质。
选项2
（地质地球物理、自然科学系）
1. 解方程
$$\sin 2x \cos x = \tg 3x \sin \left( x + \frac{\pi}{6} \right) - \cos 2x \sin x.$$
2. 在三角形$ABC$中，内切圆的半径为$\frac{10}{3}$，角$C$的余弦为$\frac{5}{13}$，三角形的面积为60。求三角形的边。
3. 沿着一条老线400米长的跑道，两名跑步者（高级和初学者）同时出发。放电速度为每分钟200m，比初学者的速度快20秒。在此期间，初学者超越了放电者。如果已知跑步者在运动过程中的速度不变且恒定，那么卸料器的速度是多少，以便他可以在不停留停止的情况下首先完成该距离？
4. 对于任何动作数$x$，参数$a$取什么值时不等式
$$\log_2 (a^2 - 2) [ (a^2 - 1)x^2 + 2x + 2] > 1?$$
5. 给定一个长方体 $ABCDA'B'C'D'$，其底边是一个边长为 3 的正方形 $ABCD$，侧边 $AA'$、$BB'$、$CC'$ 和 $DD'$ 的长度为 5。等边三角形在空间中的位置使得其一个顶点与该三角形的顶点 $C$ 重合。平行六面体，另外两行分别分解为$BB'$和$C'D'$行。求这个三角形的中位线长度。

物理学院
每个选项由三种类型的五个任务组成。
前三个任务是计算任务，难度各异：从标准任务到相对复杂的任务，需要独创性、深厚的知识以及理解非特权或传统物理情况的能力。
第四个任务是评估任务。为了解决这个问题，我们必须尝试考虑一种物理现象，为这种现象制定一个简单的（因为只需要估计）物理模型，选择结果、物理量的数值，最后获得或多或少符合现实的数值结果。问题的文本支持申请人可以选择解决问题所需的物理量及其数值。
第五个任务是演示任务，您需要解释课堂上演示的物理现象。这里重要的是要尽量突出各种因素的主要现象和环境。
从演示结束开始，给了五个小时的时间来解决问题。
