容易理解，式（10）所需解的个数等于$D_m$。对$m$次微分，代入$z=0$，可得$D_m$的形式

$$D_m = \frac{1}{m!} \frac{d^m}{dz^m} \left( \delta(z) \right) |_{z=0}$$

其中$\frac{d^m}{dz^m}$表示对$m$阶求导，符号$|_{z=0}$表示$z$一起需要用0代替。对于小的$m$，$D_m$可以用这个公式来计算，但一般来说并不容易。原来数论中的问题从分析上已经还原为某种问题，但后者仍然需要解决！

根据德国数学家 K. G. Jacobi（1804-1851）的结果，得出了一个非凡的 $\delta(z)$ 公式

$$\delta(z) = 1 + 8 \sum_{m \neq 4k} \frac{mz^m}{1 - z^m},$$

印度数学家 S. Ramanujan (1887-1920) 也收到了该书。由此我们可以推断方程（10）总是可解的，并找出该方程的解数。

方法讨论

现在让我们尝试了解一般方法的组成，该方法在所分析的问题中效果出奇地好。在它们中的每一个中，都考虑了包含字母$z$的某个“无限表达式”（两个人的无限乘积 - (1)，无限和的有限幂 - (5) 和 (11)，无限和的乘积 - (9)）。此外，这个表达式被写成“$z$中的无穷多项式”的形式，即形式

$$\alpha(z) = A_0 + A_1z + A_2z^2 + A_3z^3 + \dots + A_nz^n + \dots,$$

事实证明，系数$A_k$提供了解决问题的关键。然后可以通过对无限表达式进行各种运算来计算系数$A_k$：对它们进行算术运算，对它们进行微分，根据几何级数公式进行变换......

人们很自然地会问：我们正在考虑的无限表达式是什么，对它们执行的操作是否合法？该方法的作者莱昂哈德·欧拉（Leonhard Euler）显然没有对这些问题考虑太多——他将无限表达式视为有限表达式，对他来说重要的是获得结果。同时，对无穷大的粗心处理也会带来出错的危险。

自命不凡的例子

考虑两个“无限多项式”

$$\alpha(z) = 1 - z + z^2 - z^3 + z^4 - \dots,$$

$$\beta(z) = -1 + z - z^2 + z^3 - z^4 + \dots$$

并计算无穷总和

$$S(z) = \alpha(z) + \beta(z) + \alpha(z) + \alpha(z) + \dots$$

如果我们将 $S(z)$ 中的项成对分组，从第一对开始，我们得到

$$S(z) = [\alpha(z) + \beta(z)] + [\alpha(z) + \beta(z)] + \dots = \alpha(z) + 0 + 0 + \dots = \alpha(z)!$$

不是，如果你以不同的方式分组，你可以获得

$$S(z) = \alpha(z) + [\beta(z) + \alpha(z)] + [\beta(z) + \alpha(z)] + \dots = \alpha(z) + 0 + 0 + \dots = \alpha(z)!$$

如果你改变这些项的顺序，你可能会得到一个更奇怪的结果，例如，$S(z) = 17z^{17}$（想想这是如何做到的）。

也许是时候给出无限表达式的精确定义并找出对它们的合法操作了。

正式学位系列

相邻的形式幂称为表达式

$$\alpha(z) = a_0 + a_1z + a_2z^2 + \dots + a_nz^n + \dots,$$

其中$a_i$是实数（级数（12）的系数），$z$是简单符号（级数的形式变量）。数学家还说$\alpha(z)$是系数序列$a_0, a_1, \dots, a_n, \dots$的生成函数。然而，人们不应该认为在我们考虑的一般情况下，$\alpha(z)$是一般意义上的变量$z$的函数。当我们说$\alpha(z)$是序列$a_0, a_1, \dots, a_n, \dots$的生成函数时，它仅意味着$\alpha(z)$是（12）正确部分中形式表达式的简写符号。

对于熟悉级数（教育）幂概念的读者，需要强调的是，可以考虑形式级数（12）（对于某些$z$甚至对于所有$z$），但同时等式（12）仍然合法：毕竟，$\alpha(z)$并不表示给定值$z$的级数之和，而是表示形式级数本身。

德国杰出数学家维尔斯特拉斯（K. Weierstrass，1815-1897）发展了级数幂并将其置于不同的逻辑基础上，他只考虑级数的降幂，并批评欧拉犯下了“无限多项式”的诡计。我们在这里所触及的形式幂级数的现代代数理论已经得到实现，但本质上它更接近欧拉的“朴素”方法，而不是魏尔斯特拉斯分析理论的结构。
