⟦folio 14⟧

动力系列
$$\beta(z) = b_0 + b_1z + b_2z^2 + \dots + b_nz^n + \dots$$
(13)

然后这些级数的和与积由自然公式确定：
$$\alpha(z) + \beta(z) = (a_0 + b_0) + (a_1 + b_1)z + \dots + (a_n + b_n)z^n + \dots,$$
$$\alpha(z) \cdot \beta(z) = a_0b_0 + (a_1b_0 + a_2b_1)z + (a_0b_2 + a_1b_1 + a_2b_0)z^2 + \dots$$
(14)
（这些动作的执行规则类似于有限多项式加法和乘法的常用规则）。顺便说一下，请注意，普通多项式可以被视为形式幂级数的一种特殊情况 - 一种标称幂级数，其中从某些系数开始，所有系数都等于 0。在这种情况下，通常的多项式加法和乘法当然将与它们作为形式幂级数的加法和乘法一致。

此外，形式幂级数可以微分和内化。根据定义
$$\frac{d}{d(z)} (\alpha(z)) = (\alpha(z))' = a_1 + 2a_2z + 3a_3z^2 + \dots + na_nz^{n-1} + \dots,$$
$$\int \alpha(z) = \int_0^z \alpha(x)dx = a_0z + \frac{a_1}{2}z^2 + \frac{a_2}{3}z^3 + \dots + \frac{a_n}{n+1}z^{n+1} + \dots$$

对于以这种方式定义的无穷级数的加法和乘法，将满足类似于数或多项式的性质。即，满足交换律、组合律和分配律。

与整数一样，您可以从任何形式级数中减去任何其他级数，并再次获得形式幂级数。形式幂级数域中的除法并不总是可能的，就像两个整数的除法并不总是可能的一样。比如不能在“零”上做，即不能在一行上做
$$0 = 0 + 0 \cdot z + 0 \cdot z^2 + \dots + 0 \cdot z^n + \dots$$
无法划分“单位”，即一系列
$$1 = 1 + 0 \cdot z + 0 \cdot z^2 + \dots + 0 \cdot z^n + \dots$$
每行
$$z = 0 + 1 \cdot z + 0 \cdot z^2 + \dots + 0 \cdot z^n + \dots$$

事实上，假设有一个系列
$$\alpha(z) = a_0 + a_1z + a_2z^2 + \dots,$$
其中$\alpha(z) \cdot z = 1$，或者，
$$\left(a_0 + a_1z + a_2z^2 + \dots\right) \times \left(0 + 1 \cdot z + 0 \cdot z^2 + \dots\right) = 1 + 0 \cdot z + 0 \cdot z^2 + \dots$$

但从式（14）可以得出$a_0 \cdot 0 = 1$，这当然是不可能的。

类似地，可以证明$\alpha(z) = a_0 + a_1z + a_2z^2 + \dots$能被$z^n$整除当且仅当$a_0 = a_1 = a_2 = \dots = a_{n-1} = 0$。

很容易检验只要$a_0 \neq 0$，1就可以被$\alpha(z)$整除，并且系数是通过一系列独特的定义获得的。

例如，让我们找出“单位”除以系列 1-z 的结果。让$(1-z)(a_0 + a_1z + a_2z^2 + \dots) = 1 + 0 \cdot z + 0z^2 + \dots$

然后，打开括号并使相同幂$z$的系数相等，我们得到一个等式系统
$$1 \cdot a_0 = 1, a_1 - a_0 = 0, a_2 - a_1 = 0, \dots, a_n - a_{n-1} = 0, \dots,$$
$a_0 = a_1 = \dots = a_n = \dots = 1$来自哪里，即
$$\frac{1}{1-z} = 1 + z + z^2 + z^3 + \dots + z^n + \dots$$

我们已经以不同的名称使用了这个公式（参见上面的（3）和第 10 页的注释）；这里这个公式是形式幂级数的真正等式（并且条件$|z| < 1$与之无关）。

无限的总和和乘积

学之初解决问题，劳作无穷；无限和也同样有用（特别是，形式幂级数可以被视为无限数字和）。为了避免混淆，我们对这些概念给出了必要的定义。

令 $\alpha_1(z), \alpha_2(z), \dots, \alpha_k(z), \dots$ 为形式幂级数序列（特别是多项式）。我们想要定义一个无限和和一个无限乘积：
$$\left(\alpha_1(z)\right) + \left(\alpha_2(z)\right) + \dots + \left(\alpha_k(z)\right) + \dots,$$
(15)
$$\left(\alpha_1(z)\right) \cdot \left(\alpha_2(z)\right) \cdot \dots \cdot \left(\alpha_k(z)\right) \cdot \dots$$
(16)
