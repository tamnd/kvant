⟦folio 23⟧

振动，本身以相同的频率并沿着相同的直线振动。让我们这样说：连接到弹簧的物体在平台上振荡，该平台本身相对于固定报告系统振荡。

假设我们需要添加这两个振荡：

$$x_1 = A_1 \cos(\omega t + \varphi_0),$$
$$x_2 = A_2 \cos(\omega t + \varphi_0).$$

从书面公式可以看出，振荡的幅度（$A_1$和$A_2$）和初始相位（$\varphi_01$和$\varphi_02$）可能不同。为了弄清楚相加后会发生什么，让我们描绘与旋转器添加的振荡相对应的半径向量 $\vec{A}_1$ 和 $\vec{A}_2$，就好像它们在初始时刻进入一样，并显示其末端移动的圆（图 4；为简单起见，不完整的圆显示在 图）。显然，所产生的破坏振荡将以相同的频率 $\omega$ 发生，但具有不同的幅度和不同的初始相位：

$$x = A \cos(\omega t + \varphi_0).$$

如果我们根据平行四边形规则将向量$\vec{A}_1$和$\vec{A}_2$相加，我们就得到值$A$和$\varphi_0$。平行四边形$A = |\vec{A}|$的对角线是总振荡的幅度，矢量$\vec{A}$与轴$X$形成的角度$\varphi_0$是该振荡的初始相位。

根据著名的余弦定理，我们可以写出

$$A^2 = A_1^2 + A_2^2 - 2A_1A_2 \cos OA_1A,$$

其中$OA_1A = 180^\circ - A_2OA_1 = 180^\circ - (\varphi_02 - \varphi_01)$。由于$\cos(180^\circ - (\varphi_02 - \varphi_01)) = -\cos(\varphi_02 - \varphi_01)$，那么

$$A^2 = A_1^2 + A_2^2 + 2A_1A_2 \cos(\varphi_02 - \varphi_01).$$

因此，两个振荡相加的结果取决于振荡分量的相位差。由于振荡以相同的频率发生，因此任意时刻振荡的相位差$\varphi_2 - \varphi_1$等于初始相位差$\varphi_02 - \varphi_01$。

两个极端案例特别令人感兴趣：

1) 相位差$\varphi_2 - \varphi_1 = 0$（或$2\pi$、$4\pi$等）。任何时候相位都相同的振荡称为同相振荡。在这种情况下，$\cos(\varphi_02 - \varphi_01) = \cos(\varphi_2 - \varphi_1) = 0$、$A^2 = A_1^2 + A_2^2 + 2A_1A_2$或$A = A_1 + A_2$ - 所得振荡的振幅等于相加振荡的振幅之和。换句话说，振荡是由加法产生的。

2) 相位差$\varphi_2 - \varphi_1 = \pi$（或$3\pi$、$5\pi$等）。这种振荡被认为具有相反的相位（反相振荡）。在这种情况下，$\cos(\varphi_02 - \varphi_01) = \cos(\varphi_2 - \varphi_1) = -1$、$A^2 = A_1^2 + A_2^2 - 2A_1A_2$或$A = A_1 - A_2$ - 所产生的振荡被削弱：振幅等于分量振荡的振幅之差。如果$A_1 = A_2$，则所得振荡的幅度为零，也就是说，根本不存在振荡：一个振荡“熄灭”了另一个振荡。

在这种状态下，振动最重要的特性之一是，当增加振动时，它们可以被压缩或减弱。该属性在波过程中起着重要作用（“Physics 10”，§ 36）。

从 图 4 很容易获得最终振荡的初始相位 $\varphi_0$ 的值：

$$tg \varphi_0 = \frac{A_1 \sin \varphi_01 + A_2 \sin \varphi_02}{A_1 \cos \varphi_01 + A_2 \cos \varphi_02}.$$
