Vieta 定理和辅助多项式

L.D.库尔扬奇克，
物理和数学科学候选人
S.V.福明

大多数问题，无论怎样，都可以归结为寻找代数方程的根。但有时——这将在我们国家讨论——为了解决问题，相反，构造一个其根是给定的已知数的多项式是有用的。与引入辅助多项式相关的技术使我们能够解决几个看起来完全不同的问题。他们的平均值是问题«Kvant»的���题 M879和M882，也是上届国际奥林匹克竞赛的问题之一。

令$u$和$v$为两个实数。如何构造根为$u$和$v$的二次三项式？最简单的方法是考虑多项式
$$P(t)=(t-u)(t-v)=t^2+pt+q.$$
其系数为：
$$p=-(u+v), q=uv,$$
(1) 即和（带负号）与原数的乘积。式(1)称为Vieta公式。教科书中的两个定理与之相关：
如果二次方程$t^2+pt+q=0$有根$u$和$v$，则满足等式（1）（Vieta定理）；
数字$u$和$v$是二次方程$t^2-(u+v)t+uv=0$（逆定理）的根。
让我们举几个逆维塔定理应用的例子。让我们从一个非常简单的任务开始。
问题 1. 建立一个整数系数的二次方程，其根为数字 $2+\sqrt{3}$。
与许多其他问题一样，该问题的解决方案可以基于以下事实：具有“共轭”根 $a+b\sqrt{d}$ 和 $a-b\sqrt{d}$（其中 $a, b$ 和 $d$ 是整数）的二次方程有

整数系数*)。当然，这一事实可以直接从 Vieta 的公式（1）得出。

所以，原方程有根$t_1=2+\sqrt{3}$和$t_2=2-\sqrt{3}$，所以它的系数相等：$p=-(t_1+t_2)=-4$，$q=t_1t_2=1$。

答案：$t^2-4t+1=0$。

问题 2. 数 $t_1=\sqrt{37}-\sqrt{20}$ 是不等式 $t^2+9t-17>0$ 的解吗？

解决方案。让我们创建一个二次方程，其根是数字 $t_1$ 和 $t_2=-\sqrt{37}-\sqrt{20}$：
$$t^2+2\sqrt{20}t-17=0.$$
由于$2\sqrt{20}=\sqrt{80}<9$，不等式$t_1^2+9t_1-17>t_1^2+2\sqrt{20}t_1-17=0$成立。

答案：数字$t_1$就是这个不等式的解。

如果您首先构造一个在该点消失的多项式，则计算给定点处的函数值通常会被简化。这是一个典型的例子。

问题 3. 如果 $u=2+\sqrt{3}$ 则计算 $u^4-5u^3+6u^2-5u$。

解决方案。让我们记住问题1的结果：$u^2-4u+1=0$或$u^2=4u-1$。利用这个关系，我们用 $u$ $u^3$ 和 $u^4$ 的幂来线性表达它：
$$u^3=u^2\cdot u=(4u-1)u=4u^2-u=4(4u-1)-u=15u-4,$$
$$u^4=u^3\cdot u=(15u-4)u=15u^2-4u=15(4u-1)-4u=56u-15.$$
因此$u^4-5u^3+6u^2-5u=56u-15-5(15u-4)+6(4u-1)-5u=-1$。

答案：-1。

与上解同样操作，任意在$u=a+b\sqrt{d}$点具有整数系数的多项式的值都可以表示为$ku+l$（$a, b, d, k, l$为整数）。
问题 4. 证明数字 $(7+\sqrt{48})^{13}+(7-\sqrt{48})^{13}$ 是整数并且能被 14 整除。

解决方案。数字 $u=7+\sqrt{48}$ 和 $v=7-\sqrt{48}$ 是平方三项式 $t^2-14t+1$ 的根。使用公式$u^2=14u-1$和$v^2=14v-1$，我们获得值$a_n=u^n+v^n$的“递归关系”：

* （读者会在 N. Vaguten 的文章“共轭数”（Kvant，1980，第 2 期，第 26 页）中找到许多与这个想法相关的漂亮例子。

$$a_0 = 2$$
$$a_1 = u + v = 14$$
$$a_2 = u^2 + v^2 = (14u - 1) + (14v - 1) = 14a_1 - a_0$$
$$a_3 = u^3 + v^3 = u(14u - 1) + v(14v - 1) = 14a_2 - a_1$$
$$a_n = u^n + v^n = u^{n-2}(14u - 1) + v^{n-2}(14v - 1) = 14a_{n-1} - a_{n-2}.$$

从这些关系可以看出，所有数字 $a_n$ 都是整数。另外，如果$n$是奇数，则$a_n$能被14整除。这个命题可以通过归纳法证明：如果$a_{n-2}$能被14整除，那么$a_n$能被14整除。

问题 5. 如果 $u = \sqrt{2} + 1$ 则求 $u^8 + \frac{1}{u^8}$。

Vieta 公式与二次三项式的公式 (1) 类似，也可以写成 $n$ 次多项式

$$P(t) = (t - x_1)(t - x_2) \dots (t - x_n) = t^n + a_1 t^{n-1} + a_2 t^{n-2} + \dots + a_n$$

有根$x_1, \dots, x_n$。为此，您需要打开括号，引入相似的项，并使左侧和右侧的系数等于 $t$ 的相同幂。

让我们明确地为三次多项式写出这些公式

$$P(t) = (t - x)(t - y)(t - z) = t^3 + pt^2 + qt + r$$

有根 $x, y$ 和 $z$：

$$p = -x - y - z$$
$$q = xy + yz + zx$$
$$r = -xyz$$

现在让我们继续讨论使用辅助多项式的最有趣的示例 - 它们与多项式由多个（至少三个）根构造时的情况精确相关。

问题6. 数$x, y, z$满足关系：

$$x + y + z = a, \frac{1}{x} + \frac{1}{y} + \frac{1}{z} = \frac{1}{a}.$$

证明这些数中至少有一个等于 $a$。

解决方案。让我们接受公式（2）。在我们的例子中$p = -a$，$q = xyz/a = -r/a$。这就是为什么

$$P(t) = t^3 - at^2 - \frac{r}{a} t + r = (t - a)\left(t^2 - \frac{r}{a}\right).$$

因此，数字$a$是多项式$P(t)$的根，因此与数字$x, y, z$之一重合。

问题7. (M882) 三个整数$u, v$和$w$之和为零。证明数字$2u^4 + 2v^4 + 2w^4$是整数的平方。

解决方案。令 $P(t) = t^3 + pt^2 + qt + r$ 为多项式，其根为数字 $u, v$ 和 $w$。根据维埃塔定理，$p = -(u + v + w) = 0$。我们有：

$$u^3 + qu + r = 0$$
$$v^3 + qv + r = 0$$
$$w^3 + qw + r = 0.$$

为了获得在条件下起作用的表达式，我们将这些方程分别乘以 $2u, 2v$ 和 $2w$，然后添加：

$$2u^4 + 2v^4 + 2w^4 + 2q(u^2 + v^2 + w^2) = 0$$

（我们使用什么$u + v + w = 0$）。但是$u^2 + v^2 + w^2 = (u + v + w)^2 - 2q = -2q$，因此$2u^4 + 2v^4 + 2w^4 = (2q)^2$。

前面包含的问题可以通过定义以类似的方式解决

$$x^3 + px^2 + qx + r = 0$$
$$y^3 + py^2 + qy + r = 0$$
$$z^3 + pz^2 + qz + r = 0$$,

然后我们将使用Vieta的公式（2）和上一个问题中已经遇到的推导

$$x^2 + y^2 + z^2 = (x + y + z)^2 - 2(xy + yz + zx) = p^2 - 2q.$$

我们得到

$$x^3 + y^3 + z^3 + p(p^2 - 2q) - qp + 3r = 0,$$

在哪里

$$x^3 + y^3 + z^3 - 3xyz = -p(p^2 - 3q) = (x + y + z)(x^2 + y^2 + z^2 - xy - yz - zx)$$.

评论。表达式 $x^2 + y^2 + z^2 - xy - yz - zx$ 是非负的（自 $(x - y)^2 + (y - z)^2 + (z - x)^2 \geq 0)$ 起）。因此，根据已证明的事实，它遵循不等式

$$\frac{a + b + c}{3} \geq \sqrt[3]{abc}$$

(3)

对于三个非负数的算术平均和几何平均：在这个定义中放入$x = \sqrt[3]{a}$、$y = \sqrt[3]{b}$、$z = \sqrt[3]{c}$就足够了。

现在让我们看看在求解方程组时如何使用辅助多项式。

问题9. 解决系统

$$\begin{cases} x + y + z = 2 \\ x^2 + y^2 + z^2 = 14 \\ x^3 + y^3 + z^3 = 20. \end{cases}$$

解决方案。按照我们的方法，我们引入多项式

$$P(t) = (t - x)(t - y)(t - z) = t^3 + pt^2 + qt + r.$$

由维塔定理

$$p = -(x + y + z) = -2$$
$$q = xy + yz + zx = \frac{(x + y + z)^2 - (x^2 + y^2 + z^2)}{2} = -5.$$

要找到系数 $r$，请将系统方程分别乘以 $q$、$p$ 和 $1$，然后将它们相加。从$P(x) = P(y) = P(z) = 0$开始，我们得到：

$$-3r = 2q + 14p + 20 = -10 - 28 + 20 = -18.$$

所以，$P(t) = t^3 - 2t^2 - 5t + 6$。这是一个整数系数多项式，其首项系数为 1。因此，任何等于 $P(t)$ 的整数系数必定是自由数的约数。在这种情况下，所有三个根都是整数（数字 6 的除数是 1、-2 和 3$^*$）。因此，$\{x, y, z\} = \{1, -2, 3\}$。

$\cdot$) 原则上，求解（或找到）至少一个根，然后使用多项式展开就足够了。我们在 S. V. Fomin 的文章“分解为多项式”（Kvant，1983，第 7 期，第 23 页）中更详细地使用了这一点。
