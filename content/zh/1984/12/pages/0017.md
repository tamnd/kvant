问题 5. 如果 $u = \sqrt{2} + 1$ 则求 $u^8 + \frac{1}{u^8}$。

Vieta 公式与二次三项式的公式 (1) 类似，也可以写成 $n$ 次多项式

$$P(t) = (t - x_1)(t - x_2) \dots (t - x_n) = t^n + a_1 t^{n-1} + a_2 t^{n-2} + \dots + a_n$$

有根$x_1, \dots, x_n$。为此，您需要打开括号，引入相似的项，并使左侧和右侧的系数等于 $t$ 的相同幂。

让我们明确地为三次多项式写出这些公式

$$P(t) = (t - x)(t - y)(t - z) = t^3 + pt^2 + qt + r$$

有根 $x, y$ 和 $z$：

$$p = -x - y - z$$
$$q = xy + yz + zx$$
$$r = -xyz$$

现在让我们继续讨论使用辅助多项式的最有趣的示例 - 它们与多项式由多个（至少三个）根构造时的情况精确相关。

问题6. 数$x, y, z$满足关系：

$$x + y + z = a, \frac{1}{x} + \frac{1}{y} + \frac{1}{z} = \frac{1}{a}.$$

证明这些数中至少有一个等于 $a$。

解决方案。让我们接受公式（2）。在我们的例子中$p = -a$，$q = xyz/a = -r/a$。这就是为什么

$$P(t) = t^3 - at^2 - \frac{r}{a} t + r = (t - a)\left(t^2 - \frac{r}{a}\right).$$

因此，数字$a$是多项式$P(t)$的根，因此与数字$x, y, z$之一重合。

问题7. (M882) 三个整数$u, v$和$w$之和为零。证明数字$2u^4 + 2v^4 + 2w^4$是整数的平方。

解决方案。令 $P(t) = t^3 + pt^2 + qt + r$ 为多项式，其根为数字 $u, v$ 和 $w$。根据维埃塔定理，$p = -(u + v + w) = 0$。我们有：

$$u^3 + qu + r = 0$$
$$v^3 + qv + r = 0$$
$$w^3 + qw + r = 0.$$

为了获得在条件下起作用的表达式，我们将这些方程分别乘以 $2u, 2v$ 和 $2w$，然后添加：

$$2u^4 + 2v^4 + 2w^4 + 2q(u^2 + v^2 + w^2) = 0$$

（我们使用什么$u + v + w = 0$）。但是$u^2 + v^2 + w^2 = (u + v + w)^2 - 2q = -2q$，因此$2u^4 + 2v^4 + 2w^4 = (2q)^2$。

前面包含的问题可以通过定义以类似的方式解决

$$x^3 + px^2 + qx + r = 0$$
$$y^3 + py^2 + qy + r = 0$$
$$z^3 + pz^2 + qz + r = 0$$,

然后我们将使用Vieta的公式（2）和上一个问题中已经遇到的推导

$$x^2 + y^2 + z^2 = (x + y + z)^2 - 2(xy + yz + zx) = p^2 - 2q.$$

我们得到

$$x^3 + y^3 + z^3 + p(p^2 - 2q) - qp + 3r = 0,$$

在哪里

$$x^3 + y^3 + z^3 - 3xyz = -p(p^2 - 3q) = (x + y + z)(x^2 + y^2 + z^2 - xy - yz - zx)$$.

评论。表达式 $x^2 + y^2 + z^2 - xy - yz - zx$ 是非负的（自 $(x - y)^2 + (y - z)^2 + (z - x)^2 \geq 0)$ 起）。因此，根据已证明的事实，它遵循不等式

$$\frac{a + b + c}{3} \geq \sqrt[3]{abc}$$

问题9. 解决系统

$$\begin{cases} x + y + z = 2 \\ x^2 + y^2 + z^2 = 14 \\ x^3 + y^3 + z^3 = 20. \end{cases}$$

解决方案。按照我们的方法，我们引入多项式

$$P(t) = (t - x)(t - y)(t - z) = t^3 + pt^2 + qt + r.$$

由维塔定理

$$p = -(x + y + z) = -2$$
$$q = xy + yz + zx = \frac{(x + y + z)^2 - (x^2 + y^2 + z^2)}{2} = -5.$$

要找到系数 $r$，请将系统方程分别乘以 $q$、$p$ 和 $1$，然后将它们相加。从$P(x) = P(y) = P(z) = 0$开始，我们得到：

$$-3r = 2q + 14p + 20 = -10 - 28 + 20 = -18.$$

所以，$P(t) = t^3 - 2t^2 - 5t + 6$。这是一个整数系数多项式，其首项系数为 1。因此，任何等于 $P(t)$ 的整数系数必定是自由数的约数。在这种情况下，所有三个根都是整数（数字 6 的除数是 1、-2 和 3$^*$）。因此，$\{x, y, z\} = \{1, -2, 3\}$。

$\cdot$) 原则上，求解（或找到）至少一个根，然后使用多项式展开就足够了。我们在 S. V. Fomin 的文章“分解为多项式”（Kvant，1983，第 7 期，第 23 页）中更详细地使用了这一点。
