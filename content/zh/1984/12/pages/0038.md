为了便于定义，令 $MA$ 为从点 $M$ 到等边梯形$ABCD$ (图 1) 顶点的最大距离。根据三角不等式 $MA \leq AC + MC$ 和 $BD \leq MB + MD$，并且对于平面上的任何点 $M$，这些不等式中至少有一个成立。添加不等式并学习$AC = BD$，我们得到$MA \leq MB + MC + MD$。

这个解有一个红色的几何解释：通过将三角形$AMC$和$BMD$相互应用，使它们的等边$AC$和$BD$对齐，我们得到一个四边形（图2）；问题的陈述将与它的每条边都小于其他边的事实相一致（在一个或两个三角形$AMC$，$BMD$退化为线段的情况下，这一陈述也成立）。

◆ 使用条件$a + b + c = 0$，我们得到$a^4 + b^4 + c^4 = a^2(b + c)^2 + b^2(c + a)^2 + c^2(a + b)^2 = 2(a^2b^2 + b^2c^2 + c^2a^2) + 2abc(a + b + c) = (a^2 + b^2 + c^2)^2 - a^4 - b^4 - c^4$，由此得出$2a^4 + 2b^4 + 2c^4 = (a^2 + b^2 + c^2)^2$。

L.D. Kurlyandchik，S.V.福明

◆ a) 答案：4 种颜色。 图 2 中给出了用 4 种颜色为方格平面着色的示例，其中距离为 b 的任何两个单元都被赋予不同的颜色。

为了证明用更少的颜色是不可能的，考虑图3中所示的4个单元就足够了。它们中的任意两个彼此相距6，因此它们都应该是不同的颜色。

b) 答案：8 种颜色。证明方案重复了a)点：我们需要给出一个8色的例子
