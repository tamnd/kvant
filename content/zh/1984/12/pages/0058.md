Vieta 暗示数字 $x, y, z$ 是$t^3 - t^2 - t + r = 0$ ($xy + yz + zx = ((x + y + z)^2 - x^2 - y^2 - z^2)/2 = -1$) 形式的多项式的根。从这里开始，与解决问题 3 和 4 类似，我们在 $t = x, y, z$ 处得到$t^5 = (3 - r)t^2 - (2 - r)t - 2r$。将这三个等式相加，利用原方程组的第三个方程，我们发现$r = 1$，即数字$x, y$和$z$，是多项式$t^3 - t^2 - t + 1 = (t - 1)^2(t + 1)$的根。

**Petya 和 Vova 哪里出了问题？**

两个学生都错了。设一个方程组
$$\begin{cases} j_1(x, y) = g_1(x, y), \\ j_2(x, y) = g_2(x, y). \end{cases}$$

Petya得到了系统
$$\begin{cases} j_1(x, y) = g_1(x, y), \\ j_1(x, y) j_2(x, y) = g_1(x, y) g_2(x, y). \end{cases}$$

一般来说，方程组（1）和（2）是不相等的。显然，系统（1）的任何解都是系统（2）的解。在一般情况下，反之则不然：系统 $j_1(x, y) = g_1(x, y) = 0$ 的任何解都是系统 (2) 的解，但可能不是方程 $j_2(x, y) = g_2(x, y)$ 的解，因此也不是系统 (1) 的解。

沃瓦也犯过类似的错误。如果这些人检查，他们会得到正确答案：$(1; 0)$。

**第二十五届国际数学奥林匹克竞赛**

1. 由于$x, y, z$为正数且其和为1，因此每个数都不会超过1。因此$xy + xz + yz - 2xyz = xy(1 - z) + xz(1 - y) + yz \ge 0$。我们可以假设$x \leq y \leq z$；那么很容易证明$x \leq \frac{1}{3}, y \leq \frac{1}{2}, z \geq \frac{1}{3}$。从显而易见的角度来看
$$xz = \frac{1}{3}(x + z - \frac{1}{3}) + (x - \frac{1}{3})(z - \frac{1}{3})$$
从$x - \frac{1}{3} \leq 0$和$z - \frac{1}{3} \geq 0$可以得出$xz \leq \frac{1}{3}(x + z - \frac{1}{3}) = \frac{1}{3}(\frac{2}{3} - y)$。利用这个不等式和不等式$y \leq \frac{1}{2}$，我们得到
$$xy + xz + yz - 2xyz = (x + z)y + xz(1 - 2y) \leq \frac{1}{3}(y + z)y + \frac{1}{3}(2\frac{3}{2} - y)(1 - 2y) = \frac{2}{9} - \frac{2}{9}y - \frac{1}{3}$$
