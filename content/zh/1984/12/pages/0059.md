5. 不等式左边可以改写为：

$$\frac{p}{n} < \frac{d}{n(n-3)/2}.$$

这个陈述可以理解为：凸多边形边长的算术平均值小于其对角线长度的算术平均值，这重复了问题M846的表述，其解决方案放在第7页«Kvant»1984年第7期。 53.

让我们证明不等式的第二部分。首先考虑边数为奇数的情况：$n = 2k + 1$。请注意，连接两个依次排列的顶点的对角线的长度小于以这三个顶点为端点的边的长度之和。因此，$d_2$是这些对角线长度的总和，小于$2p$，$d_3$是跨越两个位于多边形周界上的顶点的对角线长度的总和，小于$3p$，...，$d_k < kp$。但总和是$d_2 + d_3 + ... + d_k = d$，总和是$2p + 3p + ... + kp = (k + 2)(k - 1)p/2$。考虑到$n = 2k + 1$，我们得到$(k + 2)(k - 1)p/2 = \left( \frac{n}{2} \right) \left( \frac{n+1}{2} \right) - 2)p/2$。这就证明了不等式。

在 $n = 2k$ 的情况下，将出现“直径”对角线，在其一侧和另一侧有 $k-1$ 顶点。应该注意的是，它们每个的长度都小于$p/2$，因此小于$d_k < kp/2$。同时$d_2 + d_3 + ... + d_k < p(2+3 + ... + (k-1)) = (k-2) \times (k+1)p/2$。

最后我们得到

$$d < \frac{kp}{2} + \frac{(k-2)(k+1)p}{2} = \frac{p}{2} \left( \frac{n}{2} \right) \left( \frac{n+1}{2} \right) - 2).$$
