8.3.根据等式 $\overrightarrow{A_1}\overrightarrow{B_1} + \overrightarrow{B_1}\overrightarrow{B_2} = \overrightarrow{A_1}\overrightarrow{A_2} + \overrightarrow{A_2}\overrightarrow{B_2}$ 可以得出
$$-\overrightarrow{A_1}\overrightarrow{A_2} + \overrightarrow{B_1}\overrightarrow{B_2} = \overrightarrow{A_2}\overrightarrow{B_2} - \overrightarrow{A_1}\overrightarrow{B_1}.$$
类似地，$\overrightarrow{C_1}\overrightarrow{A_1} + \overrightarrow{A_1}\overrightarrow{A_2} = \overrightarrow{C_1}\overrightarrow{C_2} + \overrightarrow{C_2}\overrightarrow{A_2}$意味着
$$-\overrightarrow{A_1}\overrightarrow{A_2} + \overrightarrow{C_1}\overrightarrow{C_2} = \overrightarrow{A_2}\overrightarrow{C_2} - \overrightarrow{A_1}\overrightarrow{C_1}.$$
利用问题的条件和这些等式，我们得到：
$$\overrightarrow{AB} = \overrightarrow{AO} + \overrightarrow{OB} = -\overrightarrow{OA} + \overrightarrow{OB} = -\overrightarrow{A_1}\overrightarrow{A_2} + \overrightarrow{B_1}\overrightarrow{B_2} =
= -\overrightarrow{A_1}\overrightarrow{B_1} + \overrightarrow{A_2}\overrightarrow{B_2},$$
$$\overrightarrow{AC} = \overrightarrow{AO} + \overrightarrow{OC} = -\overrightarrow{OA} + \overrightarrow{OC} = -\overrightarrow{A_1}\overrightarrow{A_2} + \overrightarrow{C_1}\overrightarrow{C_2} =
= -\overrightarrow{A_1}\overrightarrow{C_1} + \overrightarrow{A_2}\overrightarrow{C_2}.$$
我们用$\overrightarrow{a}'$来表示从向量$\overrightarrow{a}$逆时针旋转$60^\circ$得到的向量。显然$(k\overrightarrow{a})' = k\overrightarrow{a}'$和$(\overrightarrow{a} + \overrightarrow{b})' = \overrightarrow{a}' + \overrightarrow{b}'$。由于 (图 11) $\overrightarrow{A_1}\overrightarrow{B_1} = (\overrightarrow{A_1}\overrightarrow{C_1})'$, $\overrightarrow{A_2}\overrightarrow{B_2} = (\overrightarrow{A_2}\overrightarrow{C_2})'$，我们得到$(\overrightarrow{AC})' = (-\overrightarrow{A_1}\overrightarrow{C_1} + \overrightarrow{A_2}\overrightarrow{C_2})' = -(\overrightarrow{A_1}\overrightarrow{C_1})' + (\overrightarrow{A_2}\overrightarrow{C_2})' = -\overrightarrow{A_1}\overrightarrow{B_1} + \overrightarrow{A_2}\overrightarrow{B_2} = \overrightarrow{AB}$。我们看到向量$\overrightarrow{AB}$是由向量$\overrightarrow{AC}$旋转$60^\circ$得到的。这意味着$ABC$是等边三角形。

8.4.满足问题条件的尺寸为$m \times n$的矩形头，如果数字$m$和$n$具有相同的奇偶性，则可以进行倾斜，否则不能进行倾斜。

第 1 次哀鸣。 $m$ 和 $n$ 是奇数。然后我们可以骨架化一个矩形针迹尺寸 $1 \times n$ - 具有所需的属性 (图 12)，然后以相同的方式从这些针迹中骨架化原始矩形头部尺寸 $m \times n$ (图 13)。

第二次哀鸣。 $m$ 和 $n$ 是偶数。让我们考虑奇数边长分别为 $(m-1) \times (n-1), 1 \times (n-1), (m-1) \times 1$ 和 $1 \times 1$ 的矩形头，如 图 14 所示（已经证明，矩形头也可以是倾斜的）。我们将这些矩形头的尺寸 $m \times n$ 粘合在一起，如 图 15 所示。

第三次哀鸣。数字$m$和$n$具有不同的奇偶性，以确定$m - \text{четно}, n - \text{четно}$。假设我们制作了一个尺寸为$m \times n$的矩形头部，其侧面涂有不同的颜色。让我们考虑矩形头部的一条边，其长度为奇数。例如，让它是红色的。我们来数一下红边$u$和$v$的总数，里面有一个偶数，因为另一小块的红边与一小块的每个红边都是直的。因此，红边总数是奇数。所有的小字母都非常印度化，使用的数量与红边的数量完全相同，即奇数。另一方面，它们的数量是$mn$，即偶数。我们之间产生了矛盾。
