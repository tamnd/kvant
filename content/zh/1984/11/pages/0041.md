M880*。在序列 1, 0, 1, 0, 1, 0, ... 中，从第七项开始的每一项都等于前面各项之​​和的最后一位。证明这个序列不包含连续的六个数字：0, 1, 0, 1, 0, 1。

这个问题可以示意性地表示如下：给定某个集合的变换（一组六位数；六个$(x_1, \dots, x_6)$与$(x_2, \dots, x_6, x_7)$相关联，其中$x_7$是总和$x_1 + \dots + x_6$的最后一位）；需要证明，通过重复这种变换，从集合的一个给定“点”（6$(1, 0, 1, 0, 1, 0)$）不可能获得另一个（6$(0, 1, 0, 1, 0, 1)$）。通常，此类求解问题可以通过找到不变量来解决，即在给定变换下不变的值：只要确定两个给定“点”的不变量值不同就足够了*)。

在我们的例子中，数字$s(x_1, \dots, x_6) = 2x_1 + 4x_2 + 6x_3 + 8x_4 + 10x_5 + 12x_6$的最后一位可以作为这样的值。事实上，简单计算一下，差值$s(x_2, \dots, x_7) - s(x_1, \dots, x_6)$（以下简称$x_1 + \dots + x_6$）等于$10x_7 + 2(x_7 - (x_1 + \dots + x_6))$，即完全为零。

*）我们不止一次讨论过不变量：例如，参见 A. Khodulev 的文章“Dispersal of Physeks”（«Kvant»，1982，No.7，p.28）；还有有关此主题的其他文章的链接。许多关于不变量的问题可以在第 1983 页的«Kvant» No. 10 中找到。 30.
