⟦folio 54⟧

拍摄于容量$C_0$的电容器上。很容易证明，在 $n$ 切换后，电荷 $q_n = (C_x / (C_x + C_0))^n q_0$ 仍保留在未知电容器上。如下所示：

$$\frac{C_x}{C_x + C_0} = \sqrt[n]{\frac{q_n}{q_0}} = \sqrt[n]{\frac{I_n}{I_0}}, \quad C_x = \frac{C_0}{1 / \sqrt[n]{\frac{I_n}{I_0}} - 1}.$$

其中$I_n$是$n$切换按键$K_2$后毫安表针的下降。

I. Linduen（列宁格勒）发现了另一个有趣的解决方案。他根据图 5 组装了一个电路。电阻器的电阻比预先确定为：$R_2/R_1 = 2$，他使用$n$ 容量为$C_0$ 的已充电电容器的连接，为容量为$C_x$ 的电容器充电。在这种情况下，选择切换开关$K$的数量，使得当连接毫安表时，没有电流流过它。这意味着未知电容器两端的电压已达到$U_n = U_0 R_1 / (R_1 + R_2) = U_0 / 3$。很容易证明$U_n = U_0 (\alpha^n - 1) / \alpha^n$，其中$\alpha = 1 + C_0 / C_x$，因此

$$C_x = \frac{C_0}{\sqrt{3/2} - 1}.$$

Lindwen 提出的方法只有在以较小的误差确定电阻器的电阻时才能提供良好的精度。使用毫安表变化的电流比率来确定比率 $R_2/R_1$ 会产生 10% 量级的误差，这会在计算未知电容 $C_x$ 时导致误差 $\sim 100\%$。通过交换电阻器并再次重复实验，可以显着提高变化的准确性。

在图6所示的电路中，$K_2$开关$n$开关后，未知电容器上的方向从值$U_0$减小到$U_n$：

$$U_n = \beta^n U_0,$$

从这里

$$\beta^n = \frac{U_n}{U_0} = \frac{R_1}{R_1 + R_2}.$$

交换电阻后，在$n$切换后，毫安表的读数如之前的实验一样将等于零，我们得到

$$U_m = \beta^m U_0,$$

在哪里

$$\beta^m = \frac{U_m}{U_0} = \frac{R_2}{R_1 + R_2}.$$

很明显

$$\beta^n + \beta^m = 1, \beta < 1.$$

让我们以图形方式求解这个方程。为此，我们将绘制依赖关系 $\beta^n(\beta)$ 和 $1 - \beta^m(\beta)$ (图 7)。图的交点给出了 $\beta$ 的值，因此也给出了 $C_x$ 的值：

$$C_x = C_0 \frac{\beta}{1 - \beta}.$$
