M858。对于某个三角形的条件的α、β、γ的值，有以下关系：
$$\sin^2 \alpha + \sin^2 \beta = \sin \gamma.$$
a) 如果已知三角形是等边三角形（距离所有情况），求 α、β、γ。
b) 三角形可以是锐角三角形吗？
b) 三角形的最大角可以取什么值？

与整个集合 {0, 1, ..., 11}) 重合的集合，$N = (2^{11} - 2)/2 = 1023$。对于熟悉组合学入门的读者，我们使用最简单的组合数 $C_n^k$ 在页边空白中重复此计算。

现在我们注意到任何可取消的数都可以唯一地分解为2的各种幂的和。 （这是通过矛盾证明的：如果α是至少有两次展开式的最小数，而$2^{n_1} + ... + 2^{n_k} = 2^{m_1} + ... + 2^{m_l}$，其中$n_1 < ... < n_k$，$m_1 < ... < m_l$，那么显然是$n_1 \neq m_1$，例如$n_1 > m_1$；但是$a/2^{m_1} = 2^{n_1 - m_1} + ... + 2^{n_k - m_1}$是偶数，同时$a/2^{m_1} = 1 + 2^{m_2 - m_1} + ... + 2^{m_l - m_1}$是奇数。矛盾。）

因此，假设任何被消去的数字都是 2 的幂（即大于 4）的跟数（不一定不同）与 $2^6 + 2^7 + 2^8 + 2^9 + 2^{10} = 1984$ 之和，我们得到被消去的数字的数量为 $N - 4 = 1019 > 1984 - 1019$。

◆ a) 答案：要么α = β = π/4，γ = π/2，要么γ 且α 或β 角之一等于arcsin($\sqrt{2} - 1$)/2，第三个角为π - 2 arcsin($\sqrt{2} - 1$)/2。

考虑两种情况就足够了：α = β 和 α = γ。第一种情况，条件是取三角形的最大角？

$$2 \sin^2 \alpha = \sin(\pi - 2\alpha) = \sin 2\alpha = 2 \sin \alpha \cos \alpha$$

并且，由于sin α ≠ 0，所以sin α = cos α，即α = π/4 ($\beta = \pi/4$，γ = π/2)。

在第二种情况下，我们有$\sin^2 \alpha + \sin^2 2\alpha = \sin \alpha$或$4 \sin^2 \alpha (1 - \sin^2 \alpha) = \sin \alpha (1 - \sin \alpha)$。约简 sin α (1 - sin α) (0 < sin α < 1)，得到方程 4 sin α + 4 sin² α = 1，即 sin α = ($\sqrt{2} - 1$)/2。

b) 答案：不能。我们将通过反证法来进行证明。我们假设α和β是锐角。由条件$\sin^2 \alpha + \sin^2 \beta = \sin(\pi - (\alpha + \beta)) = \sin \alpha \cos \beta + \sin \beta \cos \alpha$可知

$$\sin \alpha (\sin \alpha - \cos \beta) = \sin \beta (\cos \alpha - \sin \beta).$$

假设sin α > cos β，则凭借(*) cos α > sin β（sin α 和sin β 均为正）。由于 β 是锐角，因此两个不等式都可以平方：$\sin^2 \alpha > \cos^2 \beta$、$\cos^2 \alpha > \sin^2 \beta$。添加这些不等式，我们得到矛盾：1 = $\sin^2 \alpha + \cos^2 \alpha > \cos^2 \beta + \sin^2 \beta = 1$。同样证明sin α < cos β 的情况是不可能的。仍然需要假设 sin α = cos β。但 α = π/2 – β，角度 γ = π - ($\alpha + \beta$) 是一条直线。

这样，我们就证明了三个角不可能同时都是锐角。请注意，角度 α 和 β 不能是直角（对于 α = π/2 sin γ = 1 + sin² β > 1），但如果角度 γ 是直角，则任何锐角 α 和 β= 都满足等式 (*)，从而满足问题的条件
