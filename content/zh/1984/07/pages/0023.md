主要定理

现在我们可以忘记导致我们写出丢失域（$a_n, b_n$）的书面表达式的所有考虑因素，并立即形成以下主要定理。

定理1.设$u = \frac{1+\sqrt{5}}{2}$，$v = u^2 = u + 1 = \frac{3+\sqrt{5}}{2}$。当且仅当存在一个自然数$n$使得$a = [nu], b = [nv]$时，字段$(a, b)$（其中$b > a$）正在丢失。如果这样的自然$n$不存在，则该位置获胜。

证明。考虑点的顺序

$$(a_1, b_1), (a_2, b_2), \dots, (a_n, b_n), \dots,$$

其中$a_n = [nu], b_n = [nv]$，并证明该序列满足属性1和2（参见第19页）。我们从属性 1 开始。

首先，我们确保所有数字 $a_1, b_1, a_2, b_2, \dots$ 都是不同的。数字 $a_i = [iu]$ 不同，$u > 1$ 也不同。出于同样的原因（$v > 1$），数字$b_j = [jv]$是不同的。假设有两个数字 $a_j$ 和 $b_j$ 相同。这意味着$[iu] = [jv] = k$。因此，$iu = k + \delta$，其中$0 < \delta_1 < 1$，$jv = k + \delta_2$，其中$0 < \delta_2 < 1$。将第一个等式除以$u$，将第二个等式除以$v$，然后将所得等式相加，得到等式

$$i + j = \frac{k}{u} + \frac{k}{v} + \frac{\delta_1}{u} + \frac{\delta_2}{v} = k + \frac{\delta_1}{u} + \frac{\delta_2}{v},$$

由此可见

$$0 < i + j - k = \frac{\delta_1}{u} + \frac{\delta_2}{v} < \frac{1}{u} + \frac{1}{v} = 1,$$

这是不可能的，因为数字 $i + j - k$ 是一个整数。

现在我们将证明每个自然数都出现在序列$a_1, b_1, a_2, b_2, \dots, a_n, b_n, \dots$中。

令$N$为任意自然数。

正好有$\left[ \frac{N}{u} \right]$个数$a_i = [iu]$，小于$N$。 （这些是带有数字 $i = 1, 2, \dots, \left[ \frac{N}{u} \right]$ 的数字。）恰好是数字 $b_j = [jv]$ 中的 $\left[ \frac{N}{v} \right]$，小于 $N$。 （带有$j = 1, 2, \dots, \left[ \frac{N}{v} \right]$的数字。）总共有$a_i$和$b_j$，小于$N$，有$\left[ \frac{N}{u} \right] + \left[ \frac{N}{v} \right]$，由于$\frac{N}{u}$和$\frac{N}{v}$不是整数，$\frac{N}{u} - 1 + \frac{N}{v} < \left[ \frac{N}{u} \right] + \left[ \frac{N}{v} \right] < \frac{N}{u} + \frac{N}{v}$，即

$$N - 2 < \left[ \frac{N}{u} \right] + \left[ \frac{N}{v} \right] < N.$$

因此，$\left[ \frac{N}{u} \right] + \left[ \frac{N}{v} \right] = N - 1$。但这意味着$a_i$和$b_j$形式的数的数量小于$N$，与自然数的数量（小于$N$）一样多。由于数字 $a_i$ 和 $b_j$ 都是不同的，因此序列 $(a_1 b_1), (a_2 b_2), \dots, (a_n b_n)$, ... 的属性 1 被证明。

性质2可以很容易证明：

$$b_n - a_n = [vn] - [un] = [(u + 1)n] - [vn] - [un] = [nu] + n - [un] = n.$$

至此，主定理得到完全证明。

斐波那契数列出现

根据主定理，要确定数字$n$的失败对，必须将$n$乘以一个无限小数形式给出的无理数。您可能不清楚这种乘法，特别是如果您没有加法机。如何通常仅通过自然数运算来确定丢失对$(a_n, b_n)$？

丢失对的以下属性可以用于此目的：

3. 如果$(a_n, b_n)$是任意对，则$(b_n - 1, a_n + b_n - 1)$和$(b_n + 1, a_n + b_n + 2)$对也是任意的。

此外，基于初始字段$(0, 0)$或第一个字段$(1, 2)$，我们可以使用属性3构造所有丢失对。

我们来概述一下财产证明3。

练习 2. 证明丢失对 $(a_n, b_n)$ 和 $(a_{n+1}, b_{n+1}): 2 \leq b_{n+1} - b_n \leq 3$ 以及 $1 \leq a_{n+1} - a_n \leq 2$。

从练习 2 的结果可以看出，数字 $b_n - 1$ 和 $b_n + 1$ 并不是大量的失败对。根据性质1，存在$k$和$l$使得$a_k = b_n - 1$，$a_l = b_n + 1$。让我们看看 $k$ 和 $l$ 等于什么。

根据性质 2，任何对的数字在该对的较大数字和较小数字之间是相等的。

另一方面，根据性质 1，任何取消对 $(a_k, b_k)$ 的数量及其等式都小于数量 $a_k$ 和所有非零对 $b_l < a_k$ 的数量。在$a_l = b_n - 1$处，小于数字$a_l$的数字$b_l$的个数是$n - 1$。这意味着$k = b_n - 1 - (n - 1) = a_n$。因此，$(b_n - 1, b + a_n - 1)$对被标记。

练习 3. 证明对于每个可取消对 $(a_n, b_n)$，对 $(b_n + 1, a_n + b_n + 2)$ 都是可取消的。

练习 4. 证明通过顺序应用性质 3 描述的几个操作，可以从对 $(0, 0)$ 或对 $(1, 2)$ 获得任何优秀的对 $(a_n, b_n)$。
