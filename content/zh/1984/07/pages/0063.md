当通过线圈的电流变为零时，电容器的能量将等于电池所做的功。因此，此时的干燥剂是由条件决定的

$$\frac{q_0^2}{2C} = U_0 q_0,$$

在哪里

$$q_0 = 2CU_0.$$

让我们找到连接电容器后通过线圈的最大电流。最大电流条件为$I' = 0$，即$\delta_{инд} = -LI' = 0$；这意味着在电流最大时，电容器的方向为$U_0$，并“补偿”电池的方向（图1）。由能量守恒定律可知——

$$U_0 CU_0 = \frac{CU_0^2}{2} + \frac{LI_0^2}{2}$$

— 求最大电流值：

$$I_0 = U_0 \sqrt{\frac{C}{L}}.$$

让我们考虑切换后的电路 (图 2)。通过线圈的电流为零（只有当线圈的能量为零时，它才能“不受惩罚地”与电路断开）。当电流达到所需的最大值$I_1$时，流向电容器的方向将等于$U_0$；这意味着此时电荷$3CU_0$将流经链条，根据能量守恒定律，

$$U_0 3CU_0 + C \frac{(2U_0)^2}{2} = \frac{CU_0^2}{2} + \frac{LI_1^2}{2}.$$

从这里

$$I_1 = 3U_0 \sqrt{\frac{C}{L}}.$$

在下一次、第二次切换之前，当通过线圈的电流为零时，电容器上会有电荷$q_1$，与第一种情况一样，我们可以从条件中找到

$$U_0 (2CU_0 + q_1) + C \frac{(2U_0)^2}{2} = \frac{q_1^2}{2C}.$$

从这里

$$q_1^2 - 2CU_0 q_1 - 8C^2 U_0^2 = 0 \Rightarrow q_1 = CU_0 \pm 3CU_0.$$

根 - $2CU_0$ 不合适（想想它对应什么情况）。所以，$q_1 = 4CU_0$。
