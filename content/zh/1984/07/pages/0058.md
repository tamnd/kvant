$$\frac{\alpha + \beta}{2} = \frac{tg^2 \alpha - \beta}{2} \text{ или}$$
$$\alpha = \arctg p^2 + \arctg p, \quad \beta = \arctg p^2 - \arctg p, \quad \gamma = \pi - 2 \arctg p^2,$$
其中 $p$ 是任何大于 1 的数字。

$$\pi/2 - \alpha \text{ (в этом случае } \cos \alpha - \sin \beta = \sin \alpha - \cos \beta = 0).$$

c) 答案：大多数角度$\alpha, \beta, \gamma$可以应用区间$[\pi/2; \pi]$内的任何值。

我们已经在第 6）点的解中证明了最大角不能是锐角，但可以是直角（$\gamma = \pi/2$）。现在让我们证明它可以应用从 $\pi/2$ 到 $\pi$ 的任何值，或者更准确地说，对于任何 $\alpha, \pi/2 < \alpha < \pi$，该方程是相对于 $\beta$
$$\sin^2 \alpha + \sin^2 \beta = \sin(\alpha + \beta)$$
在区间 $0 < \beta < \pi - \alpha$ 内有一个解（因此 $\gamma = \pi - (\alpha + \beta) > 0$）。该方程两边都是$\beta$的连续函数，对于$\beta = 0$来说，左边小于右边$(\sin^2 \alpha < \sin \alpha),$，对于$\beta = \pi - \alpha$来说，它大于$(2 \sin^2 \alpha > 0)$。因此，在某个点$\beta, 0 < \beta < \pi - \alpha$，两部分的值是重合的。该点将是方程的根。

请读者独立继续研究我们的方程：证明角$\gamma$不能是钝角（为此，你需要将给定的对应乘以外接圆直径的平方，从中利用正弦定理得出三角形边的不等式，并证明$\cos \gamma \leq 0$）；检查角度 $\alpha, \beta$ 和 $\gamma$ 而不是 $\pi/2$ 可以通过页边空白处给出的漂亮公式给出（当然，陈述 6）和 c） 紧随这些公式。

**M859。找到最小的正数，并且对于任何满足 $0 \leq x \leq 1$ 的不等式 $|f(x)| \leq 1$ 的二次三项式 $f(x)$，不等式 $|f'(1)| \leq a$ 成立。**

答案：$a = 8$。令函数$f(x) = Ax^2 + Bx + C$满足问题的条件。请注意$f'(1) = 2A + B, f(0) = C, f(1) = A + B + C$ 和$f(1/2) = A/4 + B/2 + C$，因此$f'(1) = 3f(1) - 4f(1/2) + f(0)$。因此，

$$|f'(1)| \leq 3 |f(1)| + 4 |f(1/2)| + |f(0)| \leq 8,$$

此外，这些不等式转化为$f(0) = f(1) = 1, f(1/2) = -1$的等式，即函数$f_0(x) = 8x^2 - 8x + 1$参见图。并且由于该函数满足$0 \leq x \leq 1$的不等式$|f_0(x)| \leq 1$（其图形是一个抛物线，顶点位于点$x = 1/2$ - 最小点），因此我们估计的$|f'(1)|$中的数字8是不可能的。

事实上，在解决方案中，我们将使用这样一个事实：$n$ 次多项式及其乘积是由其在 $n+1$ 点（$n=2$）处的值唯一确定的。尝试自己解决三次多项式的这个问题。请注意，对于任意次数 $n$，问题中的估计将由所谓的切比雪夫多项式给出，可以在 N. Vasiliev 和 A. Zelevinsky 的文章“切比雪夫多项式和递归关系”（«Kvant»，1982，第 1 期，第 12 页）中阅读。
