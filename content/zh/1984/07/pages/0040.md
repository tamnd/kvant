三角形几何最美丽的定理之一指出，三角形的中点、高的底边以及连接高与顶点的交点的线段的中点都位于一个圆上 - 所谓的“九点圆”（参见 «Kvant» 1981，第 8 期，第 34 页）。但它会给人留下更深刻的印象。

费尔巴哈定理。九个点的圆与四个“非凡”的圆相接触——内接圆和三个外圆。

我们只针对内切圆来证明这个定理（其余的可以类似地解决 - 参见问题8），并且我们只要知道九点圆经过三角形$ABC$的中点$A_1, B_1$和$C_1$边就足够了。

三角形$A_1B_1C_1$与三角形$ABC$相似1/2，所以它的外接圆半径为$R/2$；让我们用 $F$ 表示它的中心。可以方便地写出并证明该圆与内接圆相接触的条件为：

$$|FZ|^2 = \left(\frac{R}{2} - r\right)^2.$$

让我们将质量$a, b, c$放置在三角形的顶点$ABC$处（它们的质心将是点$Z$），将每个质量分为两部分：$a = (p-b) + (p-c), b = (p-c) + (p-a), c = (p-a) + (p-b)$并将这些部分成对分组，如图6所示；质心保持在原位。系统$(p-a)B, (p-a)C$的质心在点$A_1$，系统$(p-b)A, (p-b)C$在点$B_1$，系统$(p-c)A, (p-c)B$在点$C_1$，因此，点$Z$是系统$(p-a)A, (p-b)B_1, (p-c)C_1$的质心（我们同时将分组后得到的质量减半）。让我们求出该系统相对于点 $F$ 和 $Z$ 的转动惯量：

$$I_F = ((p-a) + (p-b)) + (p-c)) \cdot \left(\frac{R}{2}\right)^2 = \frac{R^2}{a} \cdot p,$$

$$I_Z = \frac{1}{p} ((p-a)(p-b)\left(\frac{c}{2}\right)^2) + (p-b)(p-c)\left(\frac{a}{2}\right)^2) + (p-a)(p-b)\left(\frac{b}{2}\right)^2).$$

问题 7. 证明对于任意三角形，点 $(p-a)(p-b)c^2 + (p-b)(p-c)a^2 + (p-c)(p-a)b^2 = abcp^2 - 4S^2$ 为真。

使用该问题的当前操作（其解决方案在日志末尾给出），完成证明非常容易：使用公式（5）

$$|FZ|^2 = \frac{I_F - I_Z}{P} = \frac{R^2}{4} - \frac{abc}{4p} + \frac{S^2}{p^2} = \frac{R^2}{4} - \frac{abc}{4Rp} R + \left(\frac{S}{p}\right)^2 = \frac{R^2}{4} - rR + r^2 = \left(\frac{R}{2} - r\right)^2,$$

这就是所需要的。
