2) 让质量为$m_1$，...，$m_n$的$n$粒子$A_1$，...，$A_n$相对于某个报告系统$S$以速度$\vec{v}_1$，...，$\vec{v}_n$均匀直线运动。然后它们的质心在$S$系统中以$\vec{v}_0 = (m_1\vec{v}_1 + \dots + m_n\vec{v}_n) / m$（$m = m_1 + \dots + m_n$）的速度移动。根据速度相加规则，质点静止坐标系中粒子的速度$A_i$等于$\vec{u}_i = \vec{v}_i - \vec{v}_0$。设$E$和$E_0$为$S$系统和质心系统中所有部分的总动能，即$E = \frac{m_1v_1^2}{2} + \dots + \frac{m_nv_n^2}{2}$、$E_0 = \frac{m_1u_1^2}{2} + \dots + \frac{m_nu_n^2}{2}$。利用(8)中的$x_i = \vec{v}_i$、$c_i = m_i/2$，可得Könz动能定理：

$$E = E_0 + \frac{mv_0^2}{2}$$

（零件系统的总动能等于它们相对于平面质心的运动能量；质心的运动能量）。

3) 假设在一些随机结果的实验​​中，测量了某个值$X$，例如，他们扔一个针状骰子并确定掉落的点数。让我们假设，根据实验的结果，值$X$可以取$n$值$x_1$，...，$x_n$（在骰子的示例中 - 6个值1、2、...、6），并且值$x_i$以概率$p_i$被接受（数字$p_i$是非负数并且加起来 1；在我们的例子中，非常 indo，所有值都有相同的可能性，即 $p_1 = p_2 = \dots = p_6 = 1/6$）。数字 $p_1x_1 + \dots + p_nx_n$ 称为随机 $X$ 的平均值（或数学期望），并表示为 $MX$（在我们的示例中为 $MX = (1 + \dots + 6)/6 = 3,5$）。因此，从概率论的角度来看，式（8）中的表达式（$c_i = p_i$，$c = \Sigma p_i = 1$）可以解释如下*）：

$$p_1x_1^2 + \dots + p_nx_n^2 = MX^2$$

— 随机变量 $X^2$ 的平均值，或者正如他们所说，随机变量 $X$ 的二阶矩（又是“矩”！）； $y_i = x_i - x_0 = x_i - MX$ — 随机值$X$与平均值的偏差；

$$p_1y_1^2 + \dots + p_ny_n^2 = MX(X - MX)^2$$

— 与 $MX$ 的平方偏差$X$ 的平均值；这是随机变量的一个非常重要的特性，表示其围绕平均值“分散”的程度，称为离散度，记为$DX$； $x_0^2 = (MX)^2$。

结果，(8) 就变成了一个计算方差的公式，所有概率论教科书中都有这个公式（尽管没有任何响亮的名字）：

$$DX = MX^2 - (MX)^2$$
