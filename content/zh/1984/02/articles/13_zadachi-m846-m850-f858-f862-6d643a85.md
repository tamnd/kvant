$$\varrho_1 = \varrho_0 + a \left( H - \frac{a}{2} \right), \quad \varrho_n = \varrho_0 + a \left( H + \frac{a}{2} \right),$$

其中 $a$ 是立方体边的长度。因此，

$$P = gS \cdot \Delta h \cdot n \frac{\varrho_1 + \varrho_n}{2} = gSa(\varrho_0 + aH) = gV(\varrho_0 + aH).$$

现在从立方体的平衡条件 -

$$mg = gV(\varrho_0 + aH)$$

——让我们来看看它的沉浸深度：

$$H = \frac{m - \varrho_0 V}{aV}.$$

以类似的方式，您可以找到球的浸入深度。因此，您将确保球浸入混合物中的深度与立方体相同。

从上面的解可以清楚地看出，如果质量$m$和体积$V$的物体具有这样的形状，即距物体的某个点$O$相同垂直距离处截取的水平截面的面积相等，则当物体完全浸入混合物中时，点$O$将位于深度$H = \frac{m - \varrho_0 V}{aV}$。

L·G·马尔科维奇

F845。半径为 $R$ 的自动轮的腔室内出现了一个小凸起。如果卡美克与相机之间的摩擦系数为$\mu$，自动卡美克会以多少速度随轮子旋转？

三种力作用于内室 kameik（参见图）：重力$mg$、法向反作用力$\vec{N}$ 和摩擦力$\vec{F}$。为了使 kameik 与轮子一起旋转，这些力必须赋予其向心加速度 $v^2/R$，其中 $v$ 是轮子旋转的线速度，等于自动运动的速度（轮子旋转而不打滑）。

让我们写出 kameika 在轴 $X$ 和 $Y$ 上的投影的运动方程（参见 图）：

$$F = mg \sin (\pi - a) = 0,$$

$$N + mg \cos (\pi - a) = mv^2/R.$$

由式（1）可知：

$$F = mg \sin a.$$

摩擦力的绝对值不能大于$\mu N$，因此$N \geqslant F/\mu$。从等式(2)可以看出，最小值$v$对应于$N = \frac{F}{\mu} = \frac{m}{\mu} g \sin a$。考虑到这一点，我们得到：

$$v_{\text{min}}^2 = Rg \left( \frac{\sin a}{\mu} - \cos a \right).$$

当任意函数$f(a) = \frac{\sin a}{\mu} - \cos a$等于0时，括号内的表达式最小，即

$$\frac{\cos a}{\mu} + \sin a = 0 \Rightarrow -\mu = \text{ctg} a.$$

然后

$$\sin a = \frac{1}{\sqrt{1 + \text{ctg}^2 a}} = \frac{1}{\sqrt{1 + \mu^2}}.$$
