⟦folio 54⟧

A、B、C 点处的三面角，线段 OA 和 OB 长度相等，线段 OC 比线段 OA 短。已知平面α与面OAB之间的二粒角的大小等于β。两个球位于平面α的相对侧，使得每个球接触三面角和平面α的所有面。寻找：
1) 穿过球中心的直线与杆面 OAB 平面之间的角度，
2) 指定球的半径之比。

选项4
（化学学院）

1. 找到方程的所有解
$$\cos \left(2x + \frac{\pi}{4}\right) + \cos \left(2x - \frac{\pi}{4}\right) + 4 \sin x = 2 + \sqrt{2} (1 - \sin x).$$
2. 解决不等式
$$\left(\sqrt{x^2 - 4x + 3} + 1\right) \log_5 \left(\frac{x}{5}\right) + \frac{1}{x} \left(\sqrt{8x - 2x^2 - 6} + 1\right) \leq 0.$$
3. 具有下底$ABC$和侧边$AA', BB', CC'$的三棱柱$ABCA'B'C'$被通过点E、F、C的平面剖切，其中E点位于边AA'的中间，点F位于边BB'和$|BF|:|FB'| = 1:2$上。如果已知棱柱的体积等于V，则求棱柱$ABCA'B'C'$的切割平面与该棱柱下底之间所围成的部分的体积。
4. 找到函数 $y = 1 + \cos x$ 的图形上位于 $0 \leq x \leq \pi$ 处且距直线 $x\sqrt{3} + 2y + 4 = 0$ 最短距离的点的坐标。
5. 变量x、y的值为实数。找出方程组中n的所有整数值
$$\left\{ \begin{array}{l} 6x^2 + 24y(x + y) + 2(3n - 2)x + 4(3n - 2)y + 3 = 0, \\ 4(x^2 + y^2) + (4n + 2)y + 2n^2 = 8xy + (4n + 2)x + \frac{5}{2} \end{array} \right.$$
有一个解决方案。给定找到的n的整数值，找到该系统的所有解。

选项5
（生物学院）

1. 解方程
$$4 \cos^3 x + 3\sqrt{2} \sin 2x = 8 \cos x.$$
2. 查找 x 的任意函数的所有值
$$y(x) = 3x^3 \cdot \ln x - 36x \cdot \ln x - 7x^3 + 108x$$
等于零。
3. 解决不等式
$$8 + 6|3 - \sqrt{x + 5}| > x.$$
4. 梯形$ABCD$的面积为6。设E为该梯形的延长侧边的交点。过点 E 与对角梯形的交点画一条直线，小底 BC 交于点 P，大底 AD 交于点 Q。点 F 位于线段 EC 上，$|EF|:|FC| = |EP|:|EQ| = 1:3$。求三角形EPF的面积。

5. 查找 b 的所有值，同时满足两个不等式
$$2b \cdot \cos 2(x - y) + 8b^2 \cdot \cos(x - y) + 8b^2(b + 1) + 5b < 0,$$
$$x^2 + y^2 + 1 > 2bx + 2y + b - b^2$$
对于任何 x 和 y 都成立。

选项6
（邮政科学学院）

1. 该领域分为三个部分。白天，第一块地的一半和第二块地的 3/4 被犁了，占整个田地四分之一的第三块地也被完全犁了。每天犁地的面积是第二块地面积的两倍。一天被清洗的面积占面积的几分之几？
2. 解方程
$$\cos \left(x + \frac{\pi}{3}\right) + \sin \left(x + \frac{\pi}{6}\right) - \cos 2x = 1.$$
3. 找到满足方程组的实数 x 和 y
$$\left\{ \begin{array}{l} x + 2y + 1 = 3, \\ 4x + 4y = 32. \end{array} \right.$$
4. 在三角形ABC中，角ABC的平分线与边AC交于点K。已知|BC| = 2, |KC| = 1, |BK| =$\frac{3\sqrt{2}}{2}$。求三角形ABC的面积。
5. 找到满足条件 2 < α < 5 的所有 α 值，其中方程
$$\log_2(3 - |\sin \alpha|) = \cos \left(\pi x - \frac{\pi}{6}\right)$$
关于 x 至少有一个满足条件 2 ≤ x ≤ 3 的解。

选项7
（地理系）

1. 解方程
$$\cos^2 2x - 5 \sin^2 x + 1 = 0.$$
2. 解决不等式
$$\log_2(\sqrt{x^2 - 4x} + \sqrt{x + 1}) + 1.$$
3. 以直角三角形 ABC 的边 AC 为直径，作一个圆，与斜边 AB 相交于 K 点。如果边 AC 的长度等于 b，且角 ABC 的值等于 β，则求三角形 CKB 的面积。
4. 解决系统
$$\left\{ \begin{array}{l} 2|x^2 - 2x - 3| - \log_2 3 = 3^{-y - 4}, \\ 4|y| - |y - 1| + (y + 3)^2 \leq 8. \end{array} \right.$$
5. 三角线和ABCD的每条边的长度均为1。取边AB上的点P、边BC上的点Q和边CD上的点R，使得线段AP的长度为$\frac{1}{2}$，线段BQ的长度为$\frac{1}{3}$，线段CR的长度为$\frac{1}{3}$。平面 PQR 与线 AD 相交于点 S。求线 SP 和 SQ 之间的角度。
