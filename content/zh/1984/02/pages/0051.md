为了找到马蹄莲被放置的时间，让我们想象一下，同时马蹄莲从轮子的每个点隐藏起来，并考虑这些马蹄莲在报告系统中以加速度 $g$ 下落的运动。在这个系统中，愈伤组织靠惯性以$v = \omega R$的速度移动。时间$t$后，它们将位于半径为圆的圆上

$$r = \sqrt{R^2 + v^2 t^2}$$

（图2）。为了在连接到地面的固定报告系统中找到审美干扰镜的位置，必须将该圆降低一段距离

$$s = gt^2/2$$.

显然，在$r + s = H$时刻，马蹄莲一定到达地面上的$B$点。从条件来看

$$\sqrt{R^2 + v^2 t^2} + \frac{gt^2}{2} = H$$

我们发现：

$$t_{\text{пад}}^2 = \frac{2}{g^2} \left((v^2 + gH) \pm \sqrt{v^4 + 2gHv^2 + g^2R^2}\right).$$

在这个公式中，只有减号决定了我们，因为第二个根对应于位于圆的点$N$的马蹄莲到达点$B$（参见图2），并且该马蹄莲被轮子延迟。代入$v = \omega R$，我们发现：

$$t_{\text{пад}} = \sqrt{2(\omega^2 R^2 + gH - R \sqrt{\omega^4 R^2 + 2gH\omega^2 + g^2R^2})}$$

(*)

知道马蹄莲到达$B$点所需的时间，就很容易找到它与轮子分离的点。事实上，在下降的报告系统中，这个马蹄莲在分离后的$t = t_{\text{пад}}$时间后，应该结束在圆圈的$M$点（参见图2）。因此，它在点 $A$ 处脱落，使得

$$tg a = \frac{vt_{\text{пад}}}{R} = \omega t_{\text{пад}},$$

其中$t_{\text{пад}}$由公式(*)定义。
