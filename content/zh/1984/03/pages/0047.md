F848。球沿着长度为 l 的主水平圆铁滚动。已知球的速度，精度为 $\varepsilon = \pm 5\%$。对于v的什么值，我们可以肯定地说，经过时间t后，球在A点（参见图），而不是在B点？

由于球的速度已知的精度为$\varepsilon$，因此在任何时刻都可以指示的不是一个点，而是球所在圆上的某个区域。该区域前边界以$v + \varepsilon v = v(1 + \varepsilon)$的速度移动，后边界以$v(1 - \varepsilon)$的速度移动。球到达 A 点后经过时间 t，该线段的长度将为 2vet。球当前不在 B 点意味着 B 点没有落在该区域内，即（参见图）。

$$2v\varepsilon - \frac{3l}{4} < v(1 + \varepsilon)\tau - nl < \frac{l}{4},$$

其中 $n$ 是 t 时间内球绕一圈的完整转数。从这里我们找到$l$。从这里开始有一个球，以 2ev 的速度“扩散”。因此，在时间$t = l/2ev$之后（此时区域将始终是圆形），无法确定球的位置。在此期间，球将转 $n = vt/l = 1/2\varepsilon$ 整圈。所以这个问题对于 $n < \frac{1}{2\varepsilon} = \frac{1}{2(1/20)} = 10$ 来说是有意义的。

回答：

$$\frac{l\left(n - \frac{3}{4}\right)}{(1 - \varepsilon)\tau} < v < \frac{l\left(n + \frac{1}{4}\right)}{(1 + \varepsilon)\tau},$$，其中$n = 1, 2, \dots, 9$。

F849。干温度计位于心理计室，显示温度$t_1 = 18^\circ C$，湿温度计显示$t_2 = t - \Delta t = 15^\circ C$。请勿使用桌子；确定房间内的相对湿度。所示温度下饱和空气的蒸气压分别为 $p_1 = 15,5$ mm Hg。艺术。和 $p_2 = 12,8$ 毫米汞柱。艺术。水蒸发的摩尔温度为$L = 4,07 \cdot 10^4$J/mol；空气温度为 $c = 20,8$ J/(mol· deg)（体积恒定）。

让我们表示房间内的蒸汽分压$p_n$；然后我们排除相对湿度 -

$$\varphi = \frac{p_n}{p_1} 100\%.$$

为了找到 $p_n$，我们使用能量守恒定律。让我们在心里选择一个房间的体积$V_1$，其中包含给定质量的干燥空气$M$和一定量的蒸汽$m_1$，并将其移至湿温度计。其中，含有相同量干燥空气的体积用$V_2$表示，该体积中的蒸汽量用$m_2$表示。房间内的空气密度几乎是相同的，因此这种运动不需要气压以外的任何力做功，我们将它们的功考虑在内。

压力做功 -

$$A = p(V_1 - V_2).$$

空气从温度$T_1$冷却到温度$T_2$，其内能减少

$$\Delta U = cv \cdot \Delta T = c \frac{M}{\mu_B} \cdot \Delta T.$$

冷却过程中蒸汽内能的减少可以明显地与该值进行比较，因为在此温度下空气中的蒸汽很小（$p_n \ll p$）。

当“不足”的水蒸发时，热量就会被吸收

$$\Delta Q = L \frac{m_2 - m_1}{\mu_n}.$$

让我们写下能量平衡：

$$p(V_1 - V_2) + c \frac{M}{\mu_B} \cdot \Delta T = L \frac{m_2 - m_1}{\mu_n}.$$ (*)

使用门捷列夫-克拉佩龙方程，我们发现：

$$V_1 = \frac{MRT_1}{(p - p_n)\mu_B} + \frac{m_1RT_1}{p_n\mu_n}, \quad m_1 = M \frac{p_n}{p} \frac{\mu_n}{\mu_B},$$

$$V_2 = \frac{MR(T_1 - \Delta T)}{(p - p_2)\mu_B} + \frac{m_2R(T_1 - \Delta T)}{p_2\mu_n}, \quad m_2 = M \frac{p_2}{p} \frac{\mu_n}{\mu_B}.$$
