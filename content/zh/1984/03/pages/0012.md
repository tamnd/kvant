三次抛物线
L.S.庞特里亚金院士

要理解本文，您需要能够计算多项式的导数，并了解以下定理：如果在区间 $a_1 \leq x \leq a_2$ 上定义的函数 $f(x)$，在区间 $a_1 < x < a_2$ 上具有正导数，并且可能在区间两端的导数等于 0，则它在整个区间 $a_1 \leq x \leq a_2^*$ 上返回。

所以对于满足条件的两点$x_1, x_2$

$$a_1 \leq x_1 < x_2 \leq a_2$$

(1)

存在不平等

$$f(x_1) < f(x_2).$$

$$f''(x) = \left(f'(x)\right)'.$$
