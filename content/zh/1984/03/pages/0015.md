⟦folio 13⟧

案例$h''(x_0) < 0$正在分析中。那么函数$h(x)$在点$x_0$处有最大值，因此$h(x) \leq h(x_0) = 0$；因此，即使在$h''(x_0) < 0$，函数$h(x)$的图形也不会在点$x_0$处从横坐标轴的一侧传递到另一侧。

所以只剩下一种可能性：$h''(x_0) = 0$。

接下来，我们有
$$0 = h''(x_0) = f''(x_0) - K''(x_0) = f''(x_0),$$
(28)

从$K''(x) = 0$开始。至此，式(28)得证。

然而，我们不应该认为这个等式是点$x_0$成为函数$f(x)$图形的拐点的充分条件。

要求读者证明点 $a$ 是一个真正的拐点，如果
$$f''(x_0) = 0, f'''(x_0) \neq 0,$$
(29)

所以条件(29)是点$a$成为拐点的充分条件。

现在让我们回到三次抛物线（6）。让我们计算第二个任意函数 (6)。我们有
$$f''(x) = (x^3 - px)'' = 6x.$$ (30)

我们已经确定原点是三次抛物线 (2) 的拐点。第二任意函数(2)的表达式(25)表明原点是三次抛物线的唯一拐点，因为第二任意函数(25)仅在$x = 0$处消失。

第三任意函数（6）由公式定义（见（4））
$$f'''(x) = 6.$$

因此，在三次抛物线 (6) 的点 $x = 0$ 处，满足函数 (29)，这部分暗示点 $x = 0$ 是拐点。

现在让我们处理一般三次抛物线（5）。让我们首先找出多项式（5）有多少个实根。

考虑等式(14)
$$x^3 - px = c.$$

正如已经提到的，对于 $p < 0$，这个方程只有一个实数根。对于 $p = 0$，该方程也只有一个实数根，但 $c = 0$ 的情况除外，它具有三重根 $x = 0$。如果$c = 0$，方程（14）有三个根在
$$f(x_2) \leq c \leq f(x_1)$$
（参见（15）），其中
$$f(x_1) = \frac{2}{3}p\sqrt{\frac{p}{3}}, \quad f(x_2) = -\frac{2}{3}p\sqrt{\frac{p}{3}},$$
（见（12）），因此不等式（15）可以写成以下形式
$$|c| \leq \frac{2}{3}p\sqrt{\frac{p}{3}},$$
(31)

对于区间 (31) 中的极值$c$，有一个单根和一个双根。在线段(31)之外，方程(14)只有一个实根。

多项式 (5) 可以简化为以下形式
$$\eta = f(\xi) = \xi^3 - p\xi$$
(32)

变量替换
$$x = \xi + \alpha, \quad y = \eta + \beta.$$ (33)

这种替换意味着坐标系的平行移动。

将式(33)代入，我们得到
$$\eta = \xi^3 + (3\alpha + a_1)\xi^2 + (3\alpha^2 + 2a_1\alpha + a_2)\xi + (\alpha^3 + a_1\alpha^2 + a_2\alpha + a_3) - \beta.$$ (34)

为了将多项式(5)化简为(32)式，只要满足条件即可
$$3\alpha + a_1 = 0, \quad \alpha^3 + a_1\alpha^2 + a_2\alpha + a_3 - \beta = 0.$$ (35)

从系统 (35) 的第一个方程我们有
$$\alpha = -\frac{a_1}{3}.$$ (36)

将$a$的方程代入系统(35)的第二个方程，我们得到
$$\beta = \frac{2a_1^3}{27} - \frac{a_1a_2}{3} + a_3.$$ (37)

假设$\alpha$和$\beta$由公式(36)和(37)给出，我们可以将(34)重写为
$$\eta = f(\xi) = \xi^3 - p\xi,$$
(38)

在哪里
$$p = \frac{a_1^2}{3} - a_2.$$ (39)

三次抛物线(5)的几何形状与抛物线(38)的几何公式​​一致。后者取决于数量 $p$ (39) 的符号。
