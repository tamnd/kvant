1. 让我们考虑两种极限情况：1）当负载不再沿着棱镜滑动时； 2）当负载尚未相对棱镜向上移动时。两种情况下作用在负载上的力如 图 7. a 和 b 所示。它们是重力 $m\vec{g}$、棱镜反作用力 $\vec{N}$ 和摩擦力 $\vec{F}_{\text{тр}}$ ($F_{\text{тр}} = \mu N$)。在第一种和第二种情况下，我们分别用 $\vec{a}_1$ 和 $\vec{a}_2$ 表示棱镜的加速度，从而表示载荷。让我们将力和加速度投影到水平和垂直坐标轴上，并写出相应的负载运动方程。对于情况 1)，我们得到：
$$N \sin \alpha - \mu N \cos \alpha = ma_1,$$
$$N \cos \alpha + \mu N \sin \alpha - mg = 0,$$
在哪里
$$a_1 = g \frac{\text{tg} \alpha - \mu}{1 + \mu \text{tg} \alpha} = 4 \text{ m/c}^2.$$
情况 2 也类似）
$$N \sin \alpha + \mu N \cos \alpha = ma_2,$$
$$N \cos \alpha - \mu N \sin \alpha - mg = 0,$$
和
$$a_2 = g \frac{\text{tg} \alpha + \mu}{1 - \mu \text{tg} \alpha} = 11.5 \text{ m/c}^2.$$
因此，棱镜必须以加速度 $\vec{a}$ 移动，使得
$$4 \text{ m/c}^2 = a_1 \leqslant a \leqslant a_2 = 11.5 \text{ m/c}^2.$$
2. 从能量守恒定律
$$\frac{m\omega^2(l_1^2 + l_2^2)}{2} = mg(l_1 - l_2)$$
我们求出系统的角速度$\omega$：
$$\omega = \sqrt{\frac{2g(l_1 - l_2)}{l_1^2 + l_2^2}} \approx 2.8 \text{ c}^{-1}.$$
3. 从运动学对应关系中可以找到球撞击墙壁瞬间的速度$v$
$$v^2 = (v_0 \cos \alpha)^2 + (v_0 \sin \alpha - gt)^2,$$
$$l = v_0 \cos \alpha \cdot t.$$
那么根据能量守恒定律
$$\frac{mv^2}{2} = cm\Delta T$$
让我们求出球温度的增量$\Delta T$：
$$\Delta T = \frac{(v_0 \cos \alpha)^2 + (v_0 \sin \alpha - gt)/(v_0 \cos \alpha))^2}{2c} \approx 8 \cdot 10^{-3} \text{ K}.$$
4. 让我们写出汞化合物的牛顿第二定律：
$$m\omega^2 = p_0 S - p S.$$
这里$m = qlS$是水银的质量，$\omega$是管子旋转的角速度，$b$是水银滴移动的圆的半径（$l$与$b$相比可以忽略不计），$S$是管子的横截面积，$p$是管子内的气压，我们发现来自波义耳定律 - 马里奥塔$p_0 dS = pbS$。从这里我们得到
$$\omega = \sqrt{\frac{p_0}{qlb} \left(1 - \frac{d}{b}\right)} \approx 25 \text{ c}^{-1}.$$

6. 电动机的效率等于其机械功率与电动机从发电机消耗的功率之比。根据能量守恒定律，总功率 $\mathcal{E}I$，由发电机消耗，包括机械能 $P_{\text{м}}$ 电动机和热能 $I^2(R + r)$，在电动机和发电机中释放：
$$\mathcal{E}I = P_{\text{м}} + I^2(R + r).$$

$$P_{\text{м}} = \mathcal{E}I - I^2(R + r).$$

$$P_{\text{п}} = UI = (\mathcal{E}I - Ir) I.$$

$$\eta = \frac{P_{\text{м}}}{P_{\text{п}}} = 1 - \frac{IR}{\mathcal{E}I - Ir} = 0.9 = 90\%.$$
