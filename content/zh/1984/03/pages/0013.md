(6) 则$(-x, -y)$点也满足该方程。确切地说，我们有
$$(-y) = (-x)^3 - p(-x).$$
(7)
因此，与点$(x, y)$一起，相对于坐标原点与之对称的点$(-x, -y)$也属于直线$L$。
我们进一步求直线$L$与横坐标轴的交点，即方程的根
$$x^3 - px = 0.$$ (8)
这个方程有三个根
$$x = 0, x = \pm \sqrt{p}.$$ (9)
$p < 0$ 处的最后两个根是最小值，因此没有一般的几何意义。对于 $p > 0$，(9) 的三个根都不同，因此，$L$ 线与 x 轴存在三个交点。在$p = 0$，三个根合并为一个三重根$x = 0$。
导函数（6）由下式给出
$$f'(x) = 3x^2 - p.$$ (10)
研究该函数对于不同值的符号 $x$，我们可以打破这条线 $L$ 分为增函数和减函数的区域 $f(x)$ 并找出最大点和最小点。对于这两个整数，我们应该找到方程的根
$$f'(x) = 3x^2 - p = 0.$$ (11)
对于负 $p$，函数 $f'(x)$（参见 (10)）对于 $x$ 的任何值都为正，因此，函数 $f(x)$ 在整个变化$x$: $-\infty < x < \infty$ 过程中增加。
在 $p = 0$ 功能 $f'(x)$ （参见（10））所有值均为正 $x \neq 0$。因此，它随着 $-\infty < x < 0, 0 < x < \infty$。因为在这些部分的第一部分中，函数 $f(x)$ 负数，第二个正数，那么它将在整个变化过程中增加 $-\infty$ 到 $\infty$.
在$f'(x) = 0$所在的点$x = 0$，函数$f(x)$也增加。因此，对于$x = 0$，其中$f'(x) = 0$，函数$x^3$既没有最大值也没有最小值。
当$p$为正数时，方程(11)有两个根
$$x_1 = -\sqrt{p/3}, x_2 = \sqrt{p/3}.$$ (12)
您应该检查函数 $f(x)$ 在点 $x_1$ 和 $x_2$ 处是否有最大值或最小值。相同的点$x_1$和$x_2$将整个变化范围$x$分为几个部分：

$$-\infty < x \leq x_1, x_1 \leq x \leq x_2, x_2 \leq x < \infty.$$ (13)

在第一部分中，函数 $f'(x)$ 为正，在第二部分中为负，在第三部分中又为正。因此，函数$f(x)$在第一部分增加，在第二部分减少，在第三部分增加。
从这里可以清楚地看出，点$x_1$是极大点，点$x_2$是极小点。因此，根据$p$的值，三次抛物线（6）具有三种显着不同的形式：第一个$p < 0$、第二个$p = 0$、第三个$p > 0$。在 图 1 中，三次抛物线在所有三种情况下均被描绘。
