⟦folio 14⟧

多项式 $g(x)$ 和 $f(\xi)$ 通过以下关系式相关
$$f(\xi) = g(x) - \beta.$$
因此，多项式$g(x)$的根数等于多项式$f(\xi) + \beta$的根数，或者相等于方程$f(\xi) = -\beta$的根数。但我们已经知道这个数字（见（14））。
因此，对于$p < 0$（参见（38）），多项式$g(x)$有一个实数根，对于$p = 0$，多项式$g(x)$也有一个实数根，除了值$\beta$（参见（37））等于0的情况。
考虑$p > 0$的情况。如果数量$\beta$（见（37））满足条件
$$|\beta| \leq \frac{2}{3\sqrt{3}} p^{3/2} \tag{40}$$
（参见（31）），则多项式$g(x)$有三个实根，并且在线段（40）的末端两个根合并为一个。将对应关系（37）和（39）中的值$\beta$和$p$代入（40）并对所得对应关系进行平方，我们得到条件
$$\left( \frac{2a_1^3}{27} - \frac{a_1a_2}{3} + a_3 \right)^2 \leq \frac{4}{27} \left( \frac{a_1^2}{3} - a_2 \right)^3. \tag{41}$$

所得到的条件是从多项式 $g(x)$ 的三个实根开始的完整准则，因为当满足该条件时，$p < 0$ 的情况被排除。毕竟，$p < 0$ 的第一个不等式 (41) 是负数，而左边是正方形，不可能是负数。

现在让我们指出研究四次多项式图的方法
$$y = h(x) = x^4 + b_1x^3 + b_2x^2 + b_3x + b_4.$$
为了阐明它的行为，您应该研究多项式的行为
$$h'(x) = 4x^3 + 3b_1x^2 + 2b_2x + b_3.$$
这个多项式已经有3次了，它有多少个实根的问题已经解决了。
由于多项式$h(x)$无限增加，当$x \rightarrow +\infty$和$x \rightarrow -\infty^*$时保持正值，那么如果多项式$h'(x)$只有一个实根，则多项式$h(x)$只有一个最小值。如果多项式 $h'(x)$ 有三个不同的实根，则多项式 $h(x)$ 有两个最小值和一个最大值。在这两种情况下，函数 $h(x)$ 的图形形式为 dan on 图 3, a, b，而在两个实根合二为一的情况下，图形的形式为 图 3, c。

* * *

总之，我给出求解三次方程（14）的卡丹公式（1501-1576），即方程
$$x^3 - px = c. \tag{42}$$

一旦得到解，我们就可以根据公式（37）和（39）替换$p$和$c$。由此，我们可以得到多项式(5)的所有求根公式。

求解方程(42)，任意用两个新的未知数$u$和$v$之和替换变量，即
$$x = u + v. \tag{43}$$

我们将用一些额外的对应关系连接新的未知数 $u$ 和 $v$。将$x = u + v$代入式(42)，可得
$$u^3 + v^3 + (3uv - p)(u + v) = c. \tag{44}$$

*) 也就是说，当 $x$ 绝对值增加时，保持正值 ($x \rightarrow +\infty$) 并保持负值 ($x \rightarrow -\infty$)。 （编者注）
