不是其他两个的算术平均值）。让我们证明，从集合 $1, 2, \dots, 5 \cdot 3^k$ ($k \geqslant 0$) 中，我们可以选择一个由 $4 \cdot 2^k$ 数字组成的“好”子集 $X_k$。

在图上，显示了所需集合的归纳构造的第一步：$X_0 = \{1, 2, 4, 5\}$和$X_{k+1} = X_k \cup Y_k$，其中集合$Y_k$是从$X_k$通过$2a_k$上的二元获得的，$a_k$是$X_k$中最大的数。因此，$a_{k+1} = 3a_k$和$a_k = 5 \cdot 3^k$，即$X_k \subset \{1, 2, \dots, 5 \cdot 3^k\}$，此外，在每一步中，我们的“好”集合中的数字数量都会被删除，即，$X_k$由$4 \cdot 2^k$数字组成。让我们通过归纳法证明所有集合 $X_k$ 都是“好”的。对于 $X_0$ 来说这是显而易见的。让我们检查一下 $X_{k+1}$ 中两个数字的算术平均值是否不包含在 $X_{k+1}$ 中。由于通过集合$X_k$以及$Y_k$“好”的归纳假设，我们可以假设其中一个数字$x$包含在$X_k$中，另一个$y$包含在$Y_k$中。然后$0 < x \leqslant a_k$，$2a_k < y \leqslant 3a_k$，因此$a_k < (x + y)/2 \leqslant 2a_k$，但是从$a_k + 1$到$2a_k$的数字通过构造不包含在$X_{k+1}$中。

**M840.** a) 证明如果 $a, b, c$ 是三角形边的中位数，则不等式成立

$$a^2b(a-b) + b^2c(b-c) + c^2a(c-a) \geqslant 0.$$

找出在什么情况下它会变成平等。

b) 证明对于任何正数$a, b, c$，以下不等式成立：

$$a^3b + b^3c + c^3a \geqslant a^2bc + b^2ca + c^2ab.$$

显然，当向量$\vec{u}$和$\vec{v}$共线时，即$\frac{a^3b}{c} = \frac{b^3c}{a} = \frac{c^3a}{b}$或$a = b = c$，等式$(\vec{u} \cdot \vec{v})^2 = |\vec{u}|^2 |\vec{v}|^2$是可能的。

还有一个使用完整平方的简短证明：

$$a^3b + b^3c + c^3a - a^2bc - b^2ca - c^2ab = (a^3b - 2a^2bc + c^2ab) + (b^3c - 2b^2ca + a^2bc) + (c^3a - 2c^2ab + b^2ca) = ab(a-c)^2 + bc(b-a)^2 + ca(c-b)^2 \geqslant 0.$$

a) 让我们提出两种解决方案。

第一个解决方案使用变量$x + y = c$、$y + z = a$、$z + x = b$（$x, y, z$是三角形各边被内切圆的切点划分的线段）。可以验证，经过此替换，a)部分的不等式被简化为形式

$$xy^3 + yz^3 + zx^3 \geqslant x^2yz + y^2zx + z^2xy,$$

正如我们上面证明的，这个不等式对于任何不定 $x, y, z$ 都是有效的。
