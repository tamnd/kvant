反过来，在电流$I$流过的框架上，安培力（与洛伦兹力性质相同）将作用：$\vec{F}_1$作用于框架的上侧（$F_1 = B(z)Ia$），$\vec{F}_2$作用于下侧（$F_2 = B(z+a)Ia$）。

我们来求电流强度$I$，根据欧姆定律，它与框架中产生的感应电动势和框架的电阻有关。在这种情况下，感应电动势是洛伦兹力沿着框架的闭环移动单个正电荷的功：

$$\mathcal{E}_i = \frac{A}{e} = \frac{f_1 a - f_2 a}{e} = \frac{ev_z B(z)a - ev_z B(z+a)a}{e} = v_z ka^2.$$

然后

$$I = \frac{\mathcal{E}_i}{R} = \frac{v_z ka^2}{R}.$$

整个框架在运动过程中受到三个力的作用：重力$m\vec{g}$和磁力$\vec{F}_1$和$\vec{F}_2$。在建立的模式下，框架运动方程将具有以下形式

$$m\vec{g} + \vec{F}_1 + \vec{F}_2 = 0,$$

或者

$$mg - B(z)Ia + B(z+a)Ia = mg - \frac{k^2 a^4 v_z}{R} = 0.$$

从这里我们找到帧速度的既定值：

$$v_{zyst} = \frac{mgR}{k^2 a^4}.$$

问题 4*)。当电流$I$通过长度为$L$、半径$R$和大量匝数$N$的螺线管时，螺线管节点内部会产生感应强度为$B = \mu_0 NI/L$（$\mu_0$是磁常数）的均匀磁场。磁感应线平行于螺线管的轴线。如果导线上的最大设计负载为 $F_{np}$，请确定电磁线圈将断开的电流值。

首先，我们注意到，任务条件谈到螺线管的大量匝数并非巧合，也就是说，这意味着绕组长度远大于螺线管节点的横截面直径。只有在这种情况下，我们才能假设螺线管内部的磁场是均匀的，并且感应

$$*) Это задача повышенной трудности.$$

整个螺线管的磁场可以忽略不计。这意味着在靠近通电环形线圈表面的螺极内部，磁感应矢量垂直于线圈平面且等于$\mu_0 NI/L$，而在外部磁感应矢量为零。

现在让我们直接转向问题。显然，由于磁场的作用，螺线管绕组可能会发生破裂。问题出现了：为了正确计算作用在载流线圈元件上的力，应该取什么磁感应强度？

大多数解决这个问题的申请人都错误地拿走了全部的归纳金额。事实上，螺线管线圈内部和外部的磁场都是线圈本身和所有其他线圈产生的磁场的叠加。令该匝创建的归纳模型等于$B_1$，并且对于所有其他匝等于$B_{N-1}$。利用叠加原理，我们可以写出：

$$B_1 - B_{N-1} = 0 \text{ — снаружи стороны},$$

$$B_1 + B_{N-1} = \mu_0 NI/L \text{ — внутри соленода.}$$

从这些等式我们得到$B_{N-1} = \mu_0 NI/(2L)$。因此，每匝所在的磁场感应等于螺极节点中磁场感应的一半。我们必须用这个值来计算作用在线圈元件上的力。
