考虑等式(14)
$$x^3 - px = c.$$

正如已经提到的，对于 $p < 0$，这个方程只有一个实数根。对于 $p = 0$，该方程也只有一个实数根，但 $c = 0$ 的情况除外，它具有三重根 $x = 0$。如果$c = 0$，方程（14）有三个根在
$$f(x_2) \leq c \leq f(x_1)$$
（参见（15）），其中
$$f(x_1) = \frac{2}{3}p\sqrt{\frac{p}{3}}, \quad f(x_2) = -\frac{2}{3}p\sqrt{\frac{p}{3}},$$
（见（12）），因此不等式（15）可以写成以下形式
$$|c| \leq \frac{2}{3}p\sqrt{\frac{p}{3}},$$
(31)

对于区间 (31) 中的极值$c$，有一个单根和一个双根。在线段(31)之外，方程(14)只有一个实根。

多项式 (5) 可以简化为以下形式
$$\eta = f(\xi) = \xi^3 - p\xi$$
(32)

变量替换
$$x = \xi + \alpha, \quad y = \eta + \beta.$$ (33)

这种替换意味着坐标系的平行移动。

将式(33)代入，我们得到
$$\eta = \xi^3 + (3\alpha + a_1)\xi^2 + (3\alpha^2 + 2a_1\alpha + a_2)\xi + (\alpha^3 + a_1\alpha^2 + a_2\alpha + a_3) - \beta.$$ (34)

为了将多项式(5)化简为(32)式，只要满足条件即可
$$3\alpha + a_1 = 0, \quad \alpha^3 + a_1\alpha^2 + a_2\alpha + a_3 - \beta = 0.$$ (35)

从系统 (35) 的第一个方程我们有
$$\alpha = -\frac{a_1}{3}.$$ (36)

将$a$的方程代入系统(35)的第二个方程，我们得到
$$\beta = \frac{2a_1^3}{27} - \frac{a_1a_2}{3} + a_3.$$ (37)

假设$\alpha$和$\beta$由公式(36)和(37)给出，我们可以将(34)重写为
$$\eta = f(\xi) = \xi^3 - p\xi,$$

$$p = \frac{a_1^2}{3} - a_2.$$ (39)

多项式 $g(x)$ 和 $f(\xi)$ 通过以下关系式相关
$$f(\xi) = g(x) - \beta.$$
因此，多项式$g(x)$的根数等于多项式$f(\xi) + \beta$的根数，或者相等于方程$f(\xi) = -\beta$的根数。但我们已经知道这个数字（见（14））。
因此，对于$p < 0$（参见（38）），多项式$g(x)$有一个实数根，对于$p = 0$，多项式$g(x)$也有一个实数根，除了值$\beta$（参见（37））等于0的情况。
考虑$p > 0$的情况。如果数量$\beta$（见（37））满足条件
$$|\beta| \leq \frac{2}{3\sqrt{3}} p^{3/2} \tag{40}$$
（参见（31）），则多项式$g(x)$有三个实根，并且在线段（40）的末端两个根合并为一个。将对应关系（37）和（39）中的值$\beta$和$p$代入（40）并对所得对应关系进行平方，我们得到条件
$$\left( \frac{2a_1^3}{27} - \frac{a_1a_2}{3} + a_3 \right)^2 \leq \frac{4}{27} \left( \frac{a_1^2}{3} - a_2 \right)^3. \tag{41}$$

所得到的条件是从多项式 $g(x)$ 的三个实根开始的完整准则，因为当满足该条件时，$p < 0$ 的情况被排除。毕竟，$p < 0$ 的第一个不等式 (41) 是负数，而左边是正方形，不可能是负数。

总之，我给出求解三次方程（14）的卡丹公式（1501-1576），即方程
$$x^3 - px = c. \tag{42}$$

一旦得到解，我们就可以根据公式（37）和（39）替换$p$和$c$。由此，我们可以得到多项式(5)的所有求根公式。

求解方程(42)，任意用两个新的未知数$u$和$v$之和替换变量，即
$$x = u + v. \tag{43}$$

我们将用一些额外的对应关系连接新的未知数 $u$ 和 $v$。将$x = u + v$代入式(42)，可得
$$u^3 + v^3 + (3uv - p)(u + v) = c. \tag{44}$$
