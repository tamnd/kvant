**M865。令$[a, b]$表示整数$a$和$b$的最小公倍数。证明对于任意 $n+1$ 数 $a_0 < a_1 < ... < a_n$，以下不等式成立：

$$\frac{1}{[a_0, a_1]} + \frac{1}{[a_1, a_2]} + ... + \frac{1}{[a_{n-1}, a_n]} \leq 1 - \frac{1}{2^n},$$
如果 $a) n=2; b) n=3; \theta)^{*} n$ 是任意自然数。

**对于小$n$，可以使用暴力解决问题。**

a) 由于$a < b$和$a_0 \geq 1, a_1 \geq 2$有$[a, b] \geq 2a$，因此不等式$\frac{1}{[a_0, a_1]} \leq \frac{1}{2}, \frac{1}{[a_1, a_2]} \leq \frac{1}{4}$和$\frac{1}{[a_0, a_1]} \leq \frac{1}{[a_0, a_1]} + \frac{1}{[a_1, a_2]} \leq \frac{1}{2} + \frac{1}{4} = \frac{3}{4}$有效。

b) 如果$a_2 \geq 4$，则如a)点所示，$\frac{1}{[a_0, a_1]} \leq \frac{1}{2}, \frac{1}{[a_1, a_2]} \leq \frac{1}{4}, \frac{1}{[a_2, a_3]} \leq \frac{1}{8}$，如果$a_2=3$，则$a_0=1$，$a_1=2$，$[a_0, a_1] = 2$，$[a_1, a_2] = 6$，$[a_2, a_3] \geq 6$，$\frac{1}{[a_0, a_1]} + \frac{1}{[a_1, a_2]} + \frac{1}{[a_2, a_3]} \leq \frac{1}{2} + \frac{1}{6} + \frac{1}{6} < \frac{7}{8}$。

c) 用数学归纳法进行证明。在$n=1$，我们的不平等非常有趣。现在让我们假设对于 $n=k$ 成立，并证明对于 $n=k+1$ 也是如此。让我们考虑两种情况

1) 令 $a_{k+1} \geq 2^{k+1}$，然​​后$[a_k, a_{k+1}] \geq a_{k+1} \geq 2^{k+1}$ 并通过归纳法

$$\left( \frac{1}{[a_0, a_1]} + ... + \frac{1}{[a_{k-1}, a_k]} \right) + \frac{1}{[a_k, a_{k+1}]} \leq \left( 1 - \frac{1}{2^k} \right) + \frac{1}{2^{k+1}} = 1 - \frac{1}{2^{k+1}}.$$

2) 在$a_{k+1} < 2^{k+1}$的情况下，我们使用恒等式$[a, b] = ab/(a, b)$，其中$(a, b)$是数字$a$和$b$的最公约数。由于$b-a$可被$(a, b)$整除，因此$(a, b) \leq b-a$（在$b>a$），这个恒等式意味着$1/[a, b] \leq (b-a)/ab = 1/a-1/b$。这就是为什么

$$\frac{1}{[a_0, a_1]} + \frac{1}{[a_1, a_2]} + ... + \frac{1}{[a_k, a_{k+1}]} \leq \left( \frac{1}{a_0} - \frac{1}{a_1} \right) + \left( \frac{1}{a_1} - \frac{1}{a_2} \right) + ... + \left( \frac{1}{a_k} - \frac{1}{a_{k+1}} \right) = \frac{1}{a_0} - \frac{1}{a_{k+1}} < 1 - \frac{1}{2^{k+1}}$$

Q.E.D.

请注意，此估计是精确的：对于任何 $n$，序列 $a_0=1, a_1=2, ..., a_n=2^n$ 都实现相等。
