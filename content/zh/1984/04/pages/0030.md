⟦folio 28⟧

选定的学校问题

在此背景下，“School in Kvant”版块将发布与学校课程相关的数学作业。与《Kvant习题册》不同的是，这里我们将放置相当知名的问题——“学校数学课”。他们的解决方案（通常很短，但并不总是很方便！）将在同一期期刊的末尾发表。通过系统地分析这些问题，您将熟悉许多有用的技巧，这些技巧对您在学校考试和考试、申请大学或参加奥林匹克竞赛时有用。我们希望教师和准备成为教师的学生都能对《学校问题精选》感兴趣。

八年级
1. 因式分解表达式：
a) $a^4 + 4b^4$;
b) $a^4 + b^4$.
2. 证明手榴弹有 4 个点——底边的中点、对角线的交点、侧面延长线的交点——都在同一条直线上。
3. a) 在平面上给出两条平行线和其中一条平行线的线段$AB$。使用一把尺子构建线段 $AB$ 的中点。
4. 方程$|x| + |y| \leq 1$在坐标平面上定义什么图形？
5. 当挖掘机要把坟墓挖出来的时候。起初，第一台挖掘机的工作时间相当于第二台和第三台挖掘机挖一半沟槽的时间。然后，第二台挖掘机的工作时间与第一台和第三台挖掘机挖一半沟槽所需的时间一样长。最后，在此之后，第三台挖掘机的工作时间与第一台和第二台挖掘机挖一半沟槽的时间一样长。这项工作的结果是，挖掘机挖出了整个沟渠。如果他们一起工作而不是单独工作，他们挖壕沟的速度会快多少倍？

九年级
6. 让$a + 4b = 2$。乘积$ab$可以取的最大值是多少？

8. 让函数$f(x)$由公式给出
$$f(x) = (x^2 + 5x - 8)^{100} \cdot x^5.$$
(1)

如果我们执行公式（1）右侧所示的所有操作以及下面给出的项，则函数$f(x)$将被写为多项式：
$$f(x) = a_0x^{205} + a_1x^{204} + a_2x^{203} + \dots + a_{204}x + a_{205},$$
(2)
其中 $a_0, a_1, a_2, \dots, a_{205}$ 是一些数字（多项式的系数）。
a) 求所有系数的总和
$$S = a_0 + a_1 + a_2 + \dots + a_{204} + a_{205}$$
表示多项式的奇次幂$x$。
b) 求系数之和
$$S_4 = a_1 + a_3 + a_5 + \dots + a_{205}.$$
9. 证明在整个数轴上定义的任何函数 $f(x)$ 都可以表示为偶函数和奇函数的和。
10. 设从顶点绘制的地形（任意三角形直线）中的高通过位于底边的三角形高的交点。证明：
a) 三角形的相交边互相垂直；
b) 对应边界高度的三角形直线交点的剩余高度；
b) 三角形的所有四个高均交于一点；
g) 每对交叉边的长度平方和相同。
