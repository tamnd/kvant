问题3.从已知温度$T_1$的初始状态，牛奶理想地通过两种方式烘焙到具有相同温度的状态（图3）。其中一种方法是，首先将扎扎等压加热至$T_2 = 2T_1$的温度，然后等压冷却。在另一种情况下，扎扎首先等压冷却，然后等压加热。找出两种情况下提供给垫片的热量的差异。

此问题的解决方法与上一问题类似：
$$Q_1 = vC_p(T_2 - T_1) + vC_v(T_1 - T_2),$$
$$Q_2 = vC_v(T_3 - T_1) + vC_p(T_1 - T_3),$$
和
$$Q_1 - Q_2 = vR(T_2 + T_3 - 2T_1).$$
取过程1和过程2等压段的状态方程$pV = vRT$，我们可以找到温度$T_1$、$T_2$和$T_3$之间的关系：
$$p_1 = \frac{vRT_1}{V_1} = \frac{vRT_2}{V_2}, \quad p_2 = \frac{vRT_3}{V_1} = \frac{vRT_1}{V_2},$$
在哪里
$$T_1^2 = T_2T_3.$$
根据条件$T_2 = 2T_1$，因此$T_3 = T_1/2$。最后我们得到
$$Q_1 - Q_2 = vRT_3 = vRT_1/2.$$
问题 4. 摩尔按照定律 $pV^2 = const$ 理想分布。确定该过程中 zaz 的摩尔温度。
如前所述，摩尔温度
$$C = C_V + \frac{p}{v} \frac{\Delta V}{\Delta T}.$$

由状态方程$pV = vRT$和过程方程$pV^2 = const$我们得到
$$VT = const.$$
这个等式对于任何 $V$ 和 $T$ 都有效，因此
$$(V + \Delta V)(T + \Delta T) = VT.$$
打开括号并忽略小项$\Delta V\Delta T$，我们找到体积变化$\Delta V$与温度变化$\Delta T$的比率：
$$V\Delta T + T\Delta V = 0, \text{ или } \frac{\Delta V}{\Delta T} = -\frac{V}{T}.$$
那么最终的摩尔热容就是
$$C = C_V - \frac{pV}{vT} = C_V - R.$$
很容易验证，在膨胀过程中，根据定律$pV^2 = const$冷却（这直接从条件$VT = const$得出）。由于其内部能量，膨胀做功（$A' > 0$）并向周围物体提供一定量的热量（$Q < 0$）。
问题 5. 理想情况下，将一颗鼹鼠放置在带有可移动非等角活塞的圆柱体中，用弹簧固定在底部，弹簧的张力达到胡克定律 (图 4)。考虑外部压力为零并忽略压力压力，确定 zaz 的热容量。
令$p$为气体压力，$V = Sx$为气体所占的体积，其中$S$为圆柱体的横截面，$x$为拉伸弹簧的长度。让我们用 $k$ 表示弹簧刚度并记下活塞条件：
$$pS = kx, \text{ или } pS^2 = kV.$$
从最后一个公式可以看出，压力$\Delta p$和体积$\Delta V$的变化与以下关系有关
$$\Delta p = \frac{k}{S^2}\Delta V = \frac{p}{V}\Delta V.$$
从状态方程$pV = vRT$，对任何$p, V, T$有效，我们发现
$$(p + \Delta p)(V + \Delta V) = vR(T + \Delta T).$$
打开最后一个等式中的括号并忽略$\Delta p\Delta V$形式的小项，我们得到
$$p\Delta V + V\Delta p = vR\Delta T,$$
或者，给定连接 $\Delta p$ 和 $\Delta V,$
$$\frac{p}{v} \frac{\Delta V}{\Delta T} = \frac{R}{2}.$$
