9. 当平面镜旋转角度α时，光线以什么表面角从平面镜反射？

10. 水体的每个深度都等于H。它的真实深度是多少？

该出版物由 A. S. Kondratev、S. A. Nazarov 编写

以 M. I. 加里宁命名的列宁格勒理工学院

数学
笔试
选项1
（技术图书馆教员）
1. 解方程
$$2\sin^2 x + \mathrm{tg}^2 x = 2.$$
2. 等比级数前三项的乘积是 1728，它们的和是 63。求这个级数的第一项和分母。
3. 求增减函数$f(x) = \sqrt{2}\left(\frac{\lg^2 x + 1}{2\lg x} - 1\right)^{1/2}\left(\frac{\lg^2 x + 1}{2\lg x} + 1\right)^{1/2}\lg x$的定义域和区间。
4. 在三角形ABC中，平行于边AB的中线与角B的平分线交于点P，设K为与边BC的内切圆的切点。如果$|AB| = 18, |AC| = 12$和$|BC| = 11$，则用单位长度的向量$\vec{e}_1$和$\vec{e}_2$表示向量$\overrightarrow{KP}$，并分别与$\overrightarrow{AB}$和$\overrightarrow{CA}$互相关。
选项2
（物理机械和无线电科学系）
1. 解方程
$$8^{\frac{2}{x}} = (\log_2 16)(2^{\frac{x+3}{x}} - 3).$$
2. 解方程
$$\frac{\sqrt{52-x^2}}{2-x} = 1.$$
3. 给定函数 $f(x) = \mathrm{tg}\left(x - \frac{3\pi}{4}\right) \times (1-\sin 2x) - \cos 2x - 1.$
求函数$y = f'(x)$的定义域；证明$f'(x) = 0$在所有点$D(f'(x))$和$f(\sqrt{7})$都等于整数。
4. 设二次方程
$$(3a+2)x^2 + (a-1)x + 4a+3 = 0$$
有根$x_1, x_2$。找到所有$a(a \in R)$使得$x_1$和$x_2$满足条件$x_1 < -1 < x_2 < 1$。

物理
口试作业
1. 汽车从静止开始移动，快速加速，一段时间后达到$v = 10$米/秒的速度。此后，电机关闭并自动减速，直至完全停止。求整条路线上的自主速度。
2. 火箭垂直向上飞行，并先后分两等份喷出热气体。气体相对于火箭流出的速度是恒定的并且等于u。火箭到达最高高度之前被移除的部分之间的时间间隔应该是多少？假设燃料浪费会立即发生。空气阻力具有挑战性。
3. 当气泡从湖底上升到水面时，其体积增加3倍。求湖的深度。
4. 在体积为 $V = 0,04$ m3 的圆柱体中，有压力为 $p = 1,5 \cdot 10^5$ Pa、温度为 $T = 300$ K 的气体。求气球内有多少个气体分子。
5. 将三个相同的负载粒子（每个粒子的质量为 m，电荷为 q）放置在直角三角形 $r_0$ 边的顶点处。然后粒子同时被释放，之后它们在库仑排斥力的影响下开始对称地散射。求：1）各部分的速度取决于粒子之间的距离r； 2) 当零件彼此相距非常远的距离时，库仑力作用在每个粒子上所做的功。
6. 两节电动势和内阻为 r 的相同电池并联和串联，功率 P = 16 W 均通过外部电阻释放，其阻值为 R。如果仅连接其中一节电池，则通过该电阻释放多少功率？
7. 具有长度为 l 的滑桥的半规则 ACDE 电路处于垂直于电路平面的单模磁场中（参见 图 1）。
