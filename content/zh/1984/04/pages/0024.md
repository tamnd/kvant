16. 在四边形$ABCD$中，线段$KL$连接两个对边，线段$MN$连接另外两个对边，线段$PQ$连接两条对角线。证明线段 $KL, MN$ 和 $PQ$ 相交于一点 $Z$ 并且它们都在这一点平分。

17. 在四边形$ABCD$中，三角形$BCD, ACD, ABD, ABC$中线的交点用$A', B', C', D'$表示。证明每个线段 $AA', BB', CC', DD'$ 都经过点 $Z$（距离在问题的限制范围内），并以 3:1 的比例除以该点（从四边形的顶点算起）。

18. 四边形由三段组成，每段将一个顶点与相对边中线的交点连接起来。证明这三个线段相交于一点$Z$，并且它们都在这一点平分。

19. 在四边形$A_1A_2A_3A_4A_5A_6$的四边形中，它们的中点$B_1, B_2, B_3, B_4, B_5, B_6$依次偏移。三角形$B_1B_3B_5$中线的交点与三角形$B_2B_4B_6$中线的交点重合吗？

20. 在六边形 $A_1A_2A_3A_4A_5A_6$ 的边上，它们的中点 $B_1, B_2, B_3, B_4, B_5, B_6$ 依次偏移。三角形$B_1B_3B_5$中线的交点与三角形$B_2B_4B_6$中线的交点重合吗？

21. 给定六个点，其中没有三个点属于同一条线。三角形的中线与其中每个点或三个点处的顶点的交点通过线段连接到三角形中线与其他三个点处的顶点的交点。以这种方式证明所有 10 个可能的线段都有一个共同的中点。

22. 四边形$ABCD$的对边$AB$和$DC$由点$M$和$N$以相同的比例$k$分开（即$\overrightarrow{AM} = k\overrightarrow{MB}$、$\overrightarrow{DN} = k\overrightarrow{NC}$）； $P$和$Q$是边$AD$和$BC$的中点。在每个比率中，每个线段 $MN$ 和 $PQ$ 是否除以它们的交点？

23. 空间闭合折线$ABCD$的相对链接$AB$和$DC$分别由点$M, N, P, Q$分开，比例为$\alpha : \beta$、$\beta : \gamma, \gamma : \delta, \delta : \alpha$，其中$\alpha, \beta, \gamma, \delta$为正数。证明点$M, N, P, Q$位于同一平面内。在每个比率中，线段$MP$和$NQ$除以它们的交点？

25. 闭合空间折线$A_1A_2 \dots A_{2n}A_1$的每条连线与平面$\alpha$相交于一点，并且连线$A_iA_{i+1}$被交点$c$除以平面$\alpha$，关系为$k_i (i=1, 2, \dots, 2n-1)$。在每个关系中，连线$A_{2n}A_1$被交点$c$除以平面$\alpha$？

26. 在三角形$ABC$的边上还取点$M$和$N$，即$\overrightarrow{CN} = \alpha\overrightarrow{CA}, \overrightarrow{CM} = \beta\overrightarrow{CB}$。设 $S$ 为线 $AM$ 和 $BN$ 的交点。计算比率 $|AS|:|AM|, |BS|:|BN|$。

27. 在三角形$KLM$的边$KL$和$LM$上，还取点$A$和$B$，即$|LA| = 3|AK|, |BJ| = 4|BM|$。计算三角形$KLM$和$KLC$的面积比，其中$C$是线$AM$和$KB$的交点。

28. 在三角形$ABC$的边$AB, BC, CA$上，还取点$C_1, A_1, B_1$，即$|AC_1| = \frac{1}{3}|AB|, |BA_1| = \frac{1}{3}|BC|, |CB_1| = \frac{1}{3}|CA|$。当线段$AA_1, BB_1, CC_1$相交时，形成三角形$A_2B_2C_2$。求三角形 $A_2B_2C_2$ 和 $ABC$ 的面积比。

笔记。在每个关系上，线段$BB_1$和$CC_1$（同样，对于点$B_2$和$C_2$）。

29. 平行四边形$ABCD$的面积为1。点$M$以3:5的比例划分边$BC$。计算四边形$CMPD$的面积，其中$P$是线$AM$和$BD$的交点。

30. 在平行四边形$ABCD$的边$AB$上取点$M$，剪掉这条边的$\frac{1}{n}$部分，即$|AM| = \frac{1}{n}|AB|$。对角线 $AC$ 被直线 $DM$ 切掉了哪一部分？

31. 一个圆内接于三角形 $ABC$ 并在点 $A', B', C'$ 处分别与边 $BC, CA, AB$ 相切。证明线段 $AA', BB'$ 和 $CC'$ 相交于一点。笔记。让我们介绍一下符号：$|AC'| = |AB'| = p, |BC'| = |BA'| = q, |CA'| = |CB'| = r$ (图 6)。让我们用质量 $1/p, 1/q, 1/r$ 加载顶点 $A, B, C$。确保$C'$是点$\frac{1}{p} A$和$\frac{1}{q} B$两种材料的重心，因此（根据质量分组定理）点$\frac{1}{p} A, \frac{1}{q} B, \frac{1}{r} C$的材料系统的重心$Z$位于线段$CC'$上。同样检查$Z \in [AA']$和$Z \in [BB']$。

32. 圆内接于角 $PAQ$ 并在点 $P$ 和 $Q$ 处与角的边相切。线 $BC$ ($B \in [AP], Q \in [AQ]$) 与圆相交于点 $T$。线 $BQ$ 和 $CP$ 相交于点 $M$。点 $M, T, A$ 位于同一条直线上吗？

33. 在三角形$ABC$的边上或在它们选择的纵向边上还有点$A_1, B_1, C_1$，即$\overrightarrow{BA_1} = \alpha\overrightarrow{A_1C}, \overrightarrow{CB_1} = \beta\overrightarrow{A_1A}, \overrightarrow{AC_1} = \gamma\overrightarrow{C_1B}$。证明如果$\alpha\beta\gamma = -1$，则点$A_1, B_1, C_1$位于同一条直线上（墨涅劳斯定理）。

笔记。四个材质系统点的距离$1A, \gamma B, (-1)A, \alpha\gamma C$。

34. 证明如果上一问题的符号满足等式$\alpha\beta\gamma = 1$，则直线$AA_1, BB_1, CC_1$相交于一点或平行（塞瓦定理）。

笔记。用质量 $1, \gamma, \alpha\gamma$ 加载顶点 $A, B, C$，并证明对于 $1 + \gamma + \alpha\gamma \neq 0$，这三个点材质的质心属于每条线 $AA_1, BB_1, CC_1$。

35. 平行四边形$ABCD$的底面$\alpha$分别截取侧边$SA, SB, SC$的线段，分别为一半、三分之二、四分之三（从顶点$S$开始计算）。它从四个侧肋上切掉什么部分？
