理想气体的热容

物理和数学科学博士
S.M.科泽尔。
物理和数学科学候选人
A.A.谢罗诺夫

根据热力学第一定律（热过程中能量守恒定律和能量转换定律）确定热容量。根据该定律，传递到物体（或物体系统）的热量$Q$会改变其内能$\Delta U$并对外部物体做功$A'$：

$$Q = \Delta U + A'.$$

对于均质体，可以方便地谈论一摩尔物质的热容。摩尔比热$C$是一摩尔物质加热1度时所接受的热量。如果在加热过程中，一定量的物质$v = m/M$（这里$m$是质量，$M$是物质的摩尔质量）传递了$Q$的热量，其温度从$T_1$变为$T_2$，则

$$C = \frac{Q}{v(T_2-T_1)} = \frac{Q}{(m/M)(T_2-T_1)}$$

在国际单位制 (SI) 中，摩尔比热以 J/(K mol) 表示。

与摩尔热容$C$一起，可以确定比热$c$，即物质每单位质量的热量。显然$c = C/M$。

知道物质在给定热力学过程中的热量，就很容易求出身体接收到的热量：

$$Q = mc(T_2-T_1) = \frac{m}{M} C(T_2-T_1) = vC(T_2-T_1).$$

理解对外部物体所做的功 $A'$ 取决于传热过程发生的条件非常重要。因此，热量不仅由物质的性质决定，而且还由热力学过程的类型决定。

例如，在气体等温膨胀（$T = \text{const}$）期间，向其提供物体，但其温度保持不变。从定义可知，等温过程中气体的热量无限大。在这种情况下，传递到系统的所有定量热量都用于做功：$Q = A'$。如果同一种气体参与非绝热过程，则其温度会发生变化，并且气体接收的热量为零。因此，在非绝热过程中，热比为零，气体对外部物体所做的功$A'$是由于内能：$A' = -\Delta U$而完成的。

因此，气体的热量取决于热力学过程。加热温度保持不变的过程通常称为多变过程。多变过程的例子，例如等温和非绝热过程，也是等容（$V = \text{const}$）和等压（$p = \text{const}$）过程。相应的摩尔热容用$C_V$和$C_p$表示。更详细地距离这些过程 (图 1)。

现在让我们找出 $C_p$ 和 $C_V$ 之间的连接数。从分子动力学理论可知，理想气体的内能与其绝对温度成正比。物理 9 教科书显示，对于单原子气体 $U = 3/2 RvT$（其中 $R$ 是通用气体常数）。对于等容过程$A' = 0$，$Q = \Delta U = C_V v (T_2 - T_1)$。由此可见，对于单原子气体，定体积下的摩尔比热为 $C_V = 3/2 R$。

气体在等压分布下所做的功由以下公式计算
$$A' = p (V_2 - V_1) = p \Delta V.$$
如果在所考虑的热力学过程中压力发生变化，则也可以应用该公式，但仅适用于该过程的非常小的部分，其中体积变化$\Delta V$很小，因此压力$p$可以近似认为是恒定的。我们可以将热力学温定律写为
$$Q = C_V v (T_2 - T_1) + p (V_2 - V_1) = C_V v \Delta T + p \Delta V.$$
由此，利用摩尔热容的定义，我们得到任意过程中理想气体的热容公式：
$$C = \frac{Q}{v (T_2 - T_1)} = C_V + \frac{p}{v} \frac{\Delta V}{\Delta T}.$$
该式中体积$\Delta V$和温度$\Delta T$的变化与理想气体状态方程$pV = vRT$和气体参与的热过程方程相关。特别是对于等压过程
$$p (V_2 - V_1) = vR (T_2 - T_1),$$ 或 $\frac{\Delta V}{\Delta T} = \frac{vR}{p}$。
因此，在 $p = const$ 的过程中，一摩尔理想气体的热量 $C_p$ 为
$$C_p = C_V + R.$$
对于单原子气体$C_p = 5/2 R$。

请注意，固体和液体的热容 $C_p$ 和 $C_V$ 彼此相差不大。这是因为当固体或液体被加热时，它们的体积变化很小，因此在正常条件下（即在大气压或接近大气压下），分配过程中所做的实际功为零。在这种情况下，比热等于物体加热一度时内能的变化。

问题 1. 一定量的理想气体在恒压 $p = 1$ atm 下从温度 $T_1 = 300$ K 加热到温度 $T_2 = 400$ K。如果气体的初始体积为 $V_1 = 3$ l，在此过程中气体做了什么功？

令$v$为给定量的物质，$C_V$和$C_p$分别为恒定体积和压力下气体的摩尔热容。

提供给气体的热量
$$Q = v C_p (T_2 - T_1),$$
以及气体内能的增加
$$\Delta U = v C_V (T_2 - T_1).$$
根据热力学第一定律，气体$A'$所做的功为
$$A' = Q - \Delta U = v (C_p - C_V) (T_2 - T_1) = v R (T_2 - T_1).$$
从理想气体的状态方程我们发现
$$vR = pV_1/T_1,$$
最后我们得到了天然气工作
$$A' = pV_1 (T_2/T_1 - 1) = 100 \text{ Дж.}$$

当然，给出的解决方案并不是唯一可能的解决方案。在这个问题中，您可以绕过热量的概念，直接使用计算等压过程中气体做功的公式。

问题2. 一摩尔理想气体从温度$T_1 = 100$ K 的状态开始等容分布，然后等容分布到初始温度（图 2）的状态。如果为了将气体从初始状态转变为最终状态，必须向其提供热量 $Q = 831 \text{ Дж?}$，则气体的体积会变化多少次？

热量在等压部分供给气体，并在等容部分除去：
$$Q = v C_p (T_2 - T_1) + v C_V (T_1 - T_2) = v R (T_2 - T_1).$$

问题3.从已知温度$T_1$的初始状态，牛奶理想地通过两种方式烘焙到具有相同温度的状态（图3）。其中一种方法是，首先将扎扎等压加热至$T_2 = 2T_1$的温度，然后等压冷却。在另一种情况下，扎扎首先等压冷却，然后等压加热。找出两种情况下提供给垫片的热量的差异。

此问题的解决方法与上一问题类似：
$$Q_1 = vC_p(T_2 - T_1) + vC_v(T_1 - T_2),$$
$$Q_2 = vC_v(T_3 - T_1) + vC_p(T_1 - T_3),$$
和
$$Q_1 - Q_2 = vR(T_2 + T_3 - 2T_1).$$
取过程1和过程2等压段的状态方程$pV = vRT$，我们可以找到温度$T_1$、$T_2$和$T_3$之间的关系：
$$p_1 = \frac{vRT_1}{V_1} = \frac{vRT_2}{V_2}, \quad p_2 = \frac{vRT_3}{V_1} = \frac{vRT_1}{V_2},$$
在哪里
$$T_1^2 = T_2T_3.$$
根据条件$T_2 = 2T_1$，因此$T_3 = T_1/2$。最后我们得到
$$Q_1 - Q_2 = vRT_3 = vRT_1/2.$$
问题 4. 摩尔按照定律 $pV^2 = const$ 理想分布。确定该过程中 zaz 的摩尔温度。
如前所述，摩尔温度
$$C = C_V + \frac{p}{v} \frac{\Delta V}{\Delta T}.$$

由状态方程$pV = vRT$和过程方程$pV^2 = const$我们得到
$$VT = const.$$
这个等式对于任何 $V$ 和 $T$ 都有效，因此
$$(V + \Delta V)(T + \Delta T) = VT.$$
打开括号并忽略小项$\Delta V\Delta T$，我们找到体积变化$\Delta V$与温度变化$\Delta T$的比率：
$$V\Delta T + T\Delta V = 0, \text{ или } \frac{\Delta V}{\Delta T} = -\frac{V}{T}.$$
那么最终的摩尔热容就是
$$C = C_V - \frac{pV}{vT} = C_V - R.$$
很容易验证，在膨胀过程中，根据定律$pV^2 = const$冷却（这直接从条件$VT = const$得出）。由于其内部能量，膨胀做功（$A' > 0$）并向周围物体提供一定量的热量（$Q < 0$）。
问题 5. 理想情况下，将一颗鼹鼠放置在带有可移动非等角活塞的圆柱体中，用弹簧固定在底部，弹簧的张力达到胡克定律 (图 4)。考虑外部压力为零并忽略压力压力，确定 zaz 的热容量。
令$p$为气体压力，$V = Sx$为气体所占的体积，其中$S$为圆柱体的横截面，$x$为拉伸弹簧的长度。让我们用 $k$ 表示弹簧刚度并记下活塞条件：
$$pS = kx, \text{ или } pS^2 = kV.$$
从最后一个公式可以看出，压力$\Delta p$和体积$\Delta V$的变化与以下关系有关
$$\Delta p = \frac{k}{S^2}\Delta V = \frac{p}{V}\Delta V.$$
从状态方程$pV = vRT$，对任何$p, V, T$有效，我们发现
$$(p + \Delta p)(V + \Delta V) = vR(T + \Delta T).$$
打开最后一个等式中的括号并忽略$\Delta p\Delta V$形式的小项，我们得到
$$p\Delta V + V\Delta p = vR\Delta T,$$
或者，给定连接 $\Delta p$ 和 $\Delta V,$
$$\frac{p}{v} \frac{\Delta V}{\Delta T} = \frac{R}{2}.$$
