分析的例子还表明，如果一个构造问题有多个解，那么构造程序给出了所有这些解。这种说法在一般情况下也是成立的。

一个值得尊敬的例子：二次方程的一个根的几何构造自动导致第二个根的构造。

因此，我们来到下一个prin和pu。

使用圆规和直尺解决的每个施工问题都有一个 2' 解决方案。

伽罗瓦理论给出了这一说法的严格证明，本文无法给出。然而，这个命题本身看起来非常简单，完全可以被古代数学家发现。问题来了，为什么这个发现是在上个世纪才发现的，尽管几千年前就已经有许多证实的例子了？ （例如上面提到的阿波罗问题就有8个解。）

可能的原因之一是缺乏现代“机器”建设的问题。另一个原因是将每个问题与同一类型任务的目标一起单独考虑（例如为每个 n 构造正则 n 边形的问题）。

也许这个话题会引起数学史学家的关注，他们会更有用地向我们解释这次“失去机会”的原因。

4. 正多边形

让我们回到我们的主要任务。我们想知道什么时候可以使用圆规和直尺构造正多边形。上一段的推理表明了查看这个问题有多少个解决方案的想法。要得到答案，就需要明确建设任务。也就是说，你需要

**图 5.**

固定正n边形的大小和位置（当然，否则解的数量将是无限的，前提是至少有一个解）。因此，我们假设 n 边形内接于给定的圆 o，其圆心为 O，其顶点之一的位置固定为 A₀。需要确定剩余顶点的位置A₁，A2，...，Aₙ−1。当然，找到点A₁的位置就足够了——绘制连续的弧A₀A₁，我们得到点A2、A₃、A₄等。

当 n = 6 时，这个问题最容易解决。已知正内接六边形的边长等于给定圆的半径。因此，“程序”需要如下所示（图5）：

1. 使用指南针，构建一个半径为 |OA₀| 的圆 ω₁从A₀点开始。
2. 让我们标记圆 ω 和 ω₁ 的交点 A₁。

我们看到这个程序产生了两个不同的答案，但相应的六边形 A₀A₁′A2′A₃′A4′A₅′ 和 A₀A₁′A2′A₃′A4′A₅′ 仅在顶点编号顺序上有所不同。

在 n = 3 和 n = 4 的情况下观察到相同的情况。更有趣的是 n = 5 和 n = 10 的情况。构造正五边形的方法在 A. Savin 的文章“如何绘制五角星”（«Kvant»，1976 年，第 1 期）中描述。我们将在这里考虑 n = 10 的情况。
