$$x = \frac{2abc}{ab + ac + bc}.$$

V·贝隆奇金

当电流流过第一个线圈时，磁芯中会产生磁场。载流导体产生的磁场感应始终与导体中的电流成正比。它还取决于导体的配置和介质的磁导率。

从 symmetrina 的报告中可以清楚地看出，在 toron 中，圆上所有点的磁场感应绝对值相同，其中心与 toronad 的中心重合（参见 图 22）。此外，旋涡的横截面较小。因此，龙卷风内部的场可以被认为是均匀的。针对这种情况进行的严格计算得出

$$|\vec{B}| = \mu_0 \frac{n_1 I_1}{\pi d},$$

其中$\mu_0 = 4 \cdot 10^{-7} \text{ eH/m}$是磁常数，$\mu$是磁芯材料的磁导率。

通过面积$S$横截面的磁感应通量等于

$$\Phi = \left| \vec{B} \right| S = \mu_0 \mu \frac{n_1 I_1}{\pi d} S.$$

当第一线圈电路断开时，磁通量将减少。让流量在短时间内$\Delta t$减少$\Delta \Phi$。在第二个线圈中将产生感应电动势

$$|\mathcal{E}_2| = n_2 \frac{|\Delta \Phi|}{\Delta t}$$

他会得到这样的

$$I_2 = \frac{|\mathcal{E}_2|}{R} = \frac{n_2}{R} \frac{|\Delta \Phi|}{\Delta t}.$$

在$\Delta t$时间内通过检流计出售电荷

$$\Delta q = I_2 \Delta t = \frac{n_2}{R} |\Delta \Phi|.$$

通过第二个线圈电路的全部电荷由磁感应通量的完全变化决定：

$$q = \Sigma \Delta q = \frac{n_2}{R} \Sigma |\Delta \Phi| = \frac{n_2}{R} \Phi =$$

$$= \frac{n_1 n_2 \mu_0 \mu I_1 S}{\pi d R}.$$

从这里

$$\mu = \frac{q \pi d R}{n_1 n_2 \mu_0 I_1 S} = 1000.$$

这些定律和当前问题的解决方案需要新的数学方法。

伽利略 伽利略是动力学的创始人，他是最早考虑创造新方法来理解世界的人之一。他思考了下落物体的速度如何变化，磁铁根据什么规律振荡，位于滚轮边缘的点如何移动。

为了描述数学运动的物理定律，有必要引入变量的概念。这是由生活在 16 世纪末和 17 世纪上半叶的法国生理学家和数学家笛卡尔完成的。

“数学的转折点是笛卡尔大小变量。因此，运动和辩证法进入了数学。” （F.恩格斯）。

为了记录数量之间的关系，笛卡尔使用字母，并将未知量和已知量之间的关系以方程的形式表达。

通过选择某些测量单位，您可以用数字表达所有研究的量。因此，数量之间的依赖性变成了数字之间的依赖性。例如，如果测量距离和时间投影的单位是米和秒，那么物体自由落体运动的路径对时间的依赖性将由公式 $s=1/2 gt^2$ 表示，其中 $g=9.81$。当数字$t$改变时，数字$s$改变，因此该公式将数值变量$t$和$s$相互连接。

然而，长期以来人们避免谈论数值变量，而是谈论幅度变量。为了区分变量和长度测量，数字不是1、2、3，而是1m、2m、3cm等；而且，虽然3cm和0.03m用不同的数字3和0.03来表示，但仍然3cm=0.03m。

笛卡尔的数学发现为研究曲线提供了一般方法。现在，几何考虑的位置，即希腊数学家中流行的表格，被代数所取代。

术语的诞生

在科学中，经常会出现“长时间”或另一个概念，但它只是隐含地出现，没有特定的目的——科学家用自己的方式称之为。因此，相同的计算会被一遍又一遍地重复。新术语的引入导致了相应概念的澄清，将其从随机和不重要的事物中解放出来，并识别了各个科学领域中彼此独立进行的计算中的共同特征。

自1673年以来，德国著名哲学家和数学家戈特弗里德·威廉·莱本就试图在他的手稿中使用“函数”一词。然而，他在非常狭隘的意义上使用了这个术语，他只谈论曲线的切线段、它们在坐标轴上的投影以及“对给定图形执行某种功能的其他类型的线”（来自拉丁语“functus”-执行）。

约翰·伯努尔（Johann Bernul）是莱布尼茨的第一批学生之一，他给出了一个不受几何术语约束的定函数：“变量的函数称为轮子，它以任何方式由这个量和常数形成。”这个定义让莱布尼茨很高兴：他猜测，对几何术语的背离标志着数学的新时代——将函数作为独立对象进行研究，而且是基于数字，而不是基于几何。

在伯努利时代，“以什么角度的方式”被理解为论证运算、根提取运算、三角测量和反三角测量、指数和对数“运算”以​​及它们的各种组合。这些函数现在被称为“初级”（它们现在在学校教授）。

在 17 世纪，尤其是 18 世纪，数学家开始考虑通过对函数的无限个元素求和而获得的函数。这导致了正在研究的函数类别的扩展。 18 世纪最杰出的数学家之一、圣彼得堡科学院院士伦纳德·欧拉 (Leonard Euler) 将函数定义为：“当某些量依赖于其他量，而当后者发生变化时，它们本身也会发生变化，则前者称为后者的函数。”在他的一部作品中，他甚至将函数的图形描述为由“手的自由运动”绘制的曲线。

函数概念之争

什么是函数以及函数的概念及其解析表达式如何相互关联的问题引起了数学家的注意，这一问题与 18 世纪最著名的科学家——欧拉、达朗贝尔、伯努利等人——参与的争论有关。

在解决结构振动问题时，欧拉和达朗贝尔得到了包含某个函数的答案。这个函数与原来的振荡结构公式有关。欧拉认为结构相对平衡位置的初始偏差可以在结构的不同部分用不同的公式指定，例如：

$$y = \begin{cases} ax, \text{ если } 0 \leq x < \frac{l}{2}, \\ a(l-x), \text{ если } \frac{l}{2} \leq x < l \end{cases}$$

（l是结构的长度）。达朗贝尔认为这样的功能是不被允许的。
