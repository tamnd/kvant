将$\varphi(1-x)$和$\varphi(x)$相加，我们得到：

$$\varphi(x) + \varphi(1-x) = \frac{a^{2x+k} + a^{k+1}}{a^{2x} + a} = a^k.$$

令所需总和等于$S$。然后

$$S = \varphi(0) + \varphi\left(\frac{1}{n}\right) + \ldots + \varphi\left(\frac{n-1}{n}\right) + \varphi(1),$$

$$S = \varphi(1) + \varphi\left(\frac{n-1}{n}\right) + \ldots + \varphi\left(\frac{1}{n}\right) + \varphi(0).$$

添加这两个等式并考虑到

$$\varphi(0) + \varphi(1) = \varphi\left(\frac{1}{n}\right) + \varphi\left(\frac{n-1}{n}\right) = \ldots =$$

$$= \varphi(x) + \varphi(1-x) = a^k,$$

我们得到

$$2S = (n+1)a^k,$$

即$S = \frac{1}{2}(n+1)a^k$。

所以���题 M393中的答案是：

$$S = \frac{1}{2}(n+1).$$

依次抛开向量$\vec{MN} = \vec{a}, \vec{NP} = \vec{b}, \vec{PQ} = \vec{c}, \vec{QM} = \vec{d}$，我们得到一条闭合折线（自$\vec{a} + \vec{b} + \vec{c} + \vec{d} = 0$）。通过改变向量$\vec{a}, \vec{b}, \vec{c}, \vec{d}$的顺序，可以获得多条这样的折线。让我们证明这些断线之间存在自剖。为此，我们选取​​一条虚线。如果它的一个顶点（例如$Q$）位于由三个顶点（图 4，a）形成的三角形$MNP$内部，则我们将向量$\vec{QQ'} = \vec{MN}$放在一边。由于在这种情况下$\vec{Q}'N = \vec{QM}$，折线$MNPQ$可以用自切折线$NPQQ'$代替（图4，b）。如果$MNPQ$是一条凸折线，那么首先进行图5所示的构造。

因此，设$\vec{MN} = \vec{a}, \vec{NP} = \vec{b}, \vec{PQ} = \vec{c}, \vec{QM} = \vec{d}$，线段$NP$和$QM$有一个公共点$R$（图6）。然后$|MR| + |PR| \geq |PM|, |NR| + |QR| \geq |QN|$，从$|MR| + |PR| + |NR| + |QR| \geq |PM| + |QN|$。但是$|PM| = |PQ + QM| = |c + d|,$

$$|b| + |d| \geq |a + d| + |c + d|.$$
