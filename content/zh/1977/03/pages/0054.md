4. 一个正四面体包含在一个半径为$R$的球中，因此它的三个顶点属于球体，第四个顶点位于距球心$d$的距离。找到四面体的边。
5. 证明两个轴对称且轴平行的复合是平行平移。
L.萨多夫斯基、E.舒瓦洛娃

二.对于其他大学院系。

1. 求函数定义域：
a) $y = \lg(x - 1) - \arcsin \frac{x}{3}$;
b) $y = \sqrt{\frac{x - 1}{x + 1}}$;
c) $y = \frac{\sqrt{x^2 - 10x + 9}}{\log_2(x + 1)}$;
d) $y = \lg(1 - \lg(x^2 - 5x + 14))$.

2. 给定函数$f(x) = x^4 + 5x^2 + 1$。证明$f\left(\frac{1}{x}\right) = \frac{f(x)}{x^4}$。

3. $f(x) = x^2$。寻找：
a) $\frac{f(b) - f(a)}{b - a}$;
b) $\frac{f(a + h) - f(a - h)}{2h}$.

4. 给定函数$f(x) = \lg \frac{1 - x}{1 + x}$。证明$f(a) + f(b) = f\left(\frac{a + b}{1 + ab}\right)$。

5. 计算函数的极限：
a) $\lim_{x \to 5} \frac{x^2 - 7x + 10}{x^2 - 9x + 20}$;
b) $\lim_{x \to 1} \frac{3x^4 - 4x^2 + 1}{x^3 - x^2 - x + 1}$;
c) $\lim_{x \to 0} \frac{\sqrt{1 + x} - \sqrt{1 - x}}{x}$.

6. 求下列函数的极值，并指出它们达到什么值$x$：
a) $y = 2x^2 + 4x + 7$;
b) $y = |8x^2 - 8x - 6|$.

7. 求函数$y = \sin 2x - x$在区间$\left[-\frac{\pi}{2}, \frac{\pi}{2}\right]$上的最多和最多的值。

8. 求函数$y = 2\sin x + \sin 2x$在区间$\left[0, \frac{3\pi}{2}\right]$上的最多和最多的值。

9. 在所有总表面积为 $48\pi cm^2$ 的圆柱体中，找到体积最大的圆柱体。

10. 要求制作一个无盖刚性盒子，底面为最大体积的方形，其表面积等于$12cm^2$。确定盒子的尺寸。

11. 在二项式展开式中
$$\left(\frac{1}{2}a^2b - 2ab^2\right)^n$$
如果展开式第三项的二项式系数与第五项的二项式系数之比为2，则分四项计算。

12. 证明公式的数学归纳法：
a) $1.2 + 2.3 + 3.4 + 4.5 + \dots + n(n + 1) = \frac{1}{3}n(n + 1)(n + 2)$;
b) $\frac{1}{1.2} + \frac{1}{2.3} + \dots + \frac{1}{n(n + 1)} = \frac{n}{(n + 1)}$.

13. 数字 1、2、3、4、5、6、7、8、9 组成所有可能的不包含相同数字的数字。同时包含数字 2、4 和 5 的数字有多少个？

14. 十二名学生有两种监控他们作业的选择。有多少种方式可以让他们坐成两排，使得相邻的人没有相同的选择，但相邻的人有相同的选择？

15. 在三角形$ABC$中，点$O$是三个中线的交点。证明$\overrightarrow{OA} + \overrightarrow{OB} + \overrightarrow{OC} = \overrightarrow{0}$。

16. 底半径为 1 厘米、高 3 厘米的圆柱体内接于球，因此其底边是球的截面。求球体表面积与圆柱体表面积之比。

17. 半圆被两个半径分成三个全等的扇形。求围绕半圆直径表达这些扇形所获得的函数的体积比。

18. 给定一个梯形 $ABCD$，其中 $\overrightarrow{BAD} = 60^\circ$。通过平面的大底面，与边 $AB$ 成角度 $45^\circ$。求给定梯形的平面与其在该平面上的投影面积之比。

19. 三角形$ABC$，其$\hat{A} = 45^\circ$，$\hat{B} = 60^\circ$，内接于以$O$为圆心的单位圆。计算点积：
1) $\overrightarrow{OB} \cdot \overrightarrow{OC}$;
2) $\overrightarrow{OC} \cdot \overrightarrow{OA}$;
3) $\overrightarrow{OA} \cdot \overrightarrow{OB}$.

B. Trenotsin、N. Kvacheva
