F402。焦距为 $F = -0,6$ m 的发散透镜的位置使其其中一个焦点与内镜中的条纹重合。如果已知系统会产生放置在镜头前任意距离的物体的实像，则镜子的焦距 $F'$ 是多少？图像是由光线经过镜子反射后第二次穿过镜头而形成的。

$$\frac{I_2}{I_1} = \frac{R}{r_2}.$$

另一方面，$\varphi_A = \varphi_C + I_1 r_G$（$r_G$是检流计的电阻）和$\varphi_B = \varphi_C + I_2 r_1$。所以
$$\varphi_C + I_1 r_G = \varphi_C + I_2 r_1,$$

在哪里
$$\frac{I_1}{I_2} = \frac{r_G}{r_1}.$$

比较式(1)和式(2)，可得：
$$\frac{R}{r_2} = \frac{r_G}{r_1},$$

或者
$$r_G = \frac{r_1}{r_2} R.$$

知道了电阻$r_1$、$r_2$、$R$，就可以求出检流计的电阻$r_G$。

◆
发散透镜总是产生实际光源的最小图像。因此，为了使系统产生有效的图像，光线从镜子反射后获得的中间图像必须是镜头的最小光源，即它必须位于镜头的右侧。

事实上，根据最小光源情况下发散透镜的公式
$$-\frac{1}{d} + \frac{1}{f} = -\frac{1}{F}$$

由此可见
$$f = \frac{dF}{F - d}.$$

（回想一下，$d$是从镜头到光源的距离，$f$是从镜头到图像的距离，$F$是镜头的焦距。）从（1）可以清楚地看出，如果$d$为正且不超过$F$，则$f \geq 0$。

因此，镜子 (图 14) 之后的光源的中间图像 $S_2$ 必须位于镜子的右侧，距离 $f_2$，使得
$$F \leq f_2 \leq 2F.$$

镜子的光源是中间图像 $S_1$ - 光源 $S$ 的最小图像，由透镜在光线第一次折射后给出（参见 图 14）。根据本例的透镜公式
$$\frac{1}{d_1} - \frac{1}{f_1} = -\frac{1}{F}$$

- 我们发现
$$f_1 = \frac{d_1 F}{d_1 + F}.$$
