当每个球连接到远程导体时，其电势 F 保持恒定，球的电势变得等于 F。

第一个球上出现的电荷$Q_1$等于

$$Q_1 = C\varphi,$$

其中$C$是球的容量。

第二个球的电势 Ф 由距第一个球 ($\varphi_1 = \frac{Q_1}{l}$) $l$ 处的电荷 $Q_1$ 产生的场电势和电荷 $Q_2$ ($\varphi_2 = \frac{Q_2}{C}$) 的“自身”场电势组成：

$$\varphi = \varphi_1 + \varphi_2 = \frac{Q_1}{l} + \frac{Q_2}{C}.$$

第三个球的电势 Ф 等于

$$\varphi = \frac{Q_1}{l} + \frac{Q_2}{l} + \frac{Q_3}{C},$$

其中$\frac{Q_1}{l}$、$\frac{Q_2}{l}$是$Q_1$和$Q_2$电荷场在距离$l$处的相应电势，$\frac{Q_3}{C}$是“自己的”电荷场$Q_3$的电势。

从等式（2），使用等式（1），我们找到 $l$：

$$l = \frac{Q_1 C}{Q_1 - Q_2}.$$

将$l$的表达式代入等式(3)，我们得到$Q_3$：

$$Q_3 = C \left[ \varphi - \frac{Q_1 + Q_2}{l} \right] = \frac{Q_2^2}{Q_1}.$$
