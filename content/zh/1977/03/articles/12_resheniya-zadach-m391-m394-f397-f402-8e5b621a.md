M391。 a) 在序列$x_0, x_1, x_2, \dots$中，$x_0$和$x_1$是自然数且小于1000，其余每个数都等于前两个数之差的模。证明数字 $x_1, x_2, \dots, x_{1500}$ 之一等于 0。

b) 序列$x_0, x_1, x_2, \dots$中，$x_0$和$x_1$是自然数且小于1000，并且每个数$x_2, x_3, \dots$等于前两个数之差的横坐标值中的最小者。证明$x_{20}=0$。

a) 让我们通过对所有自然数$n$的归纳来证明，如果在这样的序列中$x_0$和$x_1$小于2$n$，那么其中一个数字$x_1, x_2, \dots, x_{3n}$等于0（在问题$n=500$的条件下）。

案例$n=1$很容易检查。让该命题被证明为所有 $n$，小于 1。从$x_0 \leqslant 2n-1$、$x_1 \leqslant 2n-1$、$x_2 \geqslant 1$开始，然后是$x_3 \leqslant 2n-2$和$x_4 \leqslant 2n-3$。如果$x_3 < 2n-2$和$x_4 < 2n-2$，那么一切都遵循归纳假设。如果$x_3=2n-2$，则$x_2=1$，$x_1=2n-1$，$x_0=2n-2$。本案的说法还有待证明。我们有：
$x_3=2n-2$, $x_4=2n-3$, $x_5=1$, $x_6=2n-4$, $x_7=2n-5$, $x_8=1$, ..., $x_{3k}=2n-2k$, ..., $x_{3n}=0$.

b) 首先，我们按降序重新排列术语 $x_0, x_1$ 和 $x_2$。生成的序列可能与原始序列仅在前三项的顺序上有所不同（请自行查看）。此外，它，非常印度，杀死：定义术语$x_k$，我们有用于确定术语$x_{k-1}$的所有差异，加上$x_{k-1}$和序列的其余术语（具有较低数字）之间的差异。

现在让我们注意对于任何整数 $k>0$
$x_k \geqslant x_{k+1}+x_{k+2}$.

否则我们就会
$x_{k+2}>x_k-x_{k+1}=|x_k-x_{k+1}|$，这是不可能的。

我们假设$x_{20} \geqslant 1$。那么，当然是$x_{19} \geqslant 1$，通过（*）我们有：$x_{18} \geqslant x_{19}+x_{20} \geqslant 2$，$x_{17} \geqslant x_{18}+x_{19} \geqslant 2+1=3$，$x_{16} \geqslant x_{17}+x_{18} \geqslant 3+2=5$，...，$x_0 \geqslant x_1+x_2 \geqslant 4181+6765=10946>10000$，这与问题相反。

M392。根据这些恒定速度的近似剂量，做出决定。一开始他们并不在同一条直线上。证明它们在同一条线上最多不超过两次。

我们针对这个问题提出了两种解决方案。第一个（几何）使用典型的物理学技术：过渡到驾驶报告系统；第二个（解析）可以使用向量的“伪标量积”来简单地编写。

一、我们将点$P, Q, R$在同一直线上的条件写成：$R \in (PQ)$（在$P \neq Q$）。

让我们转到与其中一个解相关的坐标系。那么问题就会简化为：在平面上给定一个不动点$A$；证明如果点$P$和$Q$平滑且均匀地移动，则适当的$A \in (PQ)$出现的次数不会超过两次（如果已知在初始时刻$t=0$它不会发生）。

令在某个时间点$t_1$解$P$和$Q$位于点$B$和$C$，使得$A \in (BC)$。让我们介绍另一个“虚构”解$Q'$：$Q'$位于$t=t_1$点$B$，并平行于解路径$Q$移动，使其始终为$A \in (QQ')$（图 1，​​a）。显然，条件$A \in (PQ), A \in (PQ')$和$Q' \in (AP)$是等价的*)。显然，$Q'$匀速运动。因此，直线$PQ'$保持相同的方向 - 它平行于自身移动 - 并且只能在某个时刻$t_2$（与$t_1$不同）通过点$A$（图 1，o）。 （初始条件排除了点$P$和$Q'$始终重合或沿直线$AB$移动的可能性。）

不难举出例子来说明实数的三个解可以在同一条直线上出现两次、一次或根本不出现。在继续讨论解决方案二之前，让我们在没有证据的情况下注意到一个事实，我们的问题很容易由此得出。如果两点 $P$ 和 $Q$ 沿两条线均匀移动，则所有线 $PQ$ 要么通过一个点，要么平行于一个方向，或者（这是一般情况） - 接触一条抛物线 - 这一系列线的“包络线”（图 2）。很明显，通过平面的每个点$A$，最多有两条该族的直线。

二.让我们介绍一下坐标系$Oxy$。坐标为$(v_x; v_y)$和$(w_x; w_y)$共线（平行于一个方向）的两个向量$v$和$w$的条件显然可以写成：$v_x w_y = v_y w_x$。让我们介绍一下符号

$$[v, w] = v_x w_y - v_y w_x.$$ (1)

一对向量 $(v, w) \rightarrow [v, w]$ 的数值函数具有以下属性（很容易验证）：

$$[\lambda v, w] = [v, \lambda w] = \lambda [v, w];$$
$$[v + w, u] = [v, u] + [w, u],$$
$$[u, v + w] = [u, v] + [u, w]$$ (2)

对于任何向量 $u, v, w$ 和任何数字 $\lambda$。如前所述，$[v, w] = 0$当且仅当$v$和$w$共线。 （值$[v, w]$有一个简单的几何意义：它的模型等于平行四边形的面积，其线由向量$v$和$w$表示，符号取决于$(v, w)$对的“方向”，$[v, w] = -[w, v]$（图3）；但我们不需要这些属性。）

现在让我们直接着手解决问题。令$P, Q$和$R$匀速直线运动。然后

$$\vec{RP} = \vec{a} + t \vec{v}, \quad \vec{RQ} = \vec{b} + t \vec{w},$$ (3)

其中$t$是时间，$\vec{a}, \vec{b}, \vec{v}, \vec{w}$是独立于$t$的向量。不难得到式(3)的公式，利用这样的事实：如果某个点$M$以$\vec{u}$的速度移动，则$\vec{OM} = \vec{OM}_0 + t \vec{u}$，其中$\vec{M}_0$是$M$在$t = 0$的位置，$O$是平面上的固定点。考虑到(1) - (3)，条件$R \in (PQ)$可以写成如下：

$$[v, w] t^2 + ([a, w] + [b, v]) t + [a, b] = 0.$$ (4)

我们已经得到了$t$的二次方程。虽然它的一些系数可以变成0，但是对于$t = 0$，如条件(4)所述，它不满足，所以(4)不一样。因此，$R \in (PQ)$最多有两个$t$值。

$$+ \varphi\left(\frac{2}{n}\right) + \dots + \varphi(1),$$

让我们找到 $\varphi(1-x)$ 的表达式：

$$\varphi(1-x) = \frac{a^{-2x+k+2}}{a^{-2x+2}+a} = \frac{a^{k+1}}{a^{2x}+a}.$$

将$\varphi(1-x)$和$\varphi(x)$相加，我们得到：

$$\varphi(x) + \varphi(1-x) = \frac{a^{2x+k} + a^{k+1}}{a^{2x} + a} = a^k.$$

令所需总和等于$S$。然后

$$S = \varphi(0) + \varphi\left(\frac{1}{n}\right) + \ldots + \varphi\left(\frac{n-1}{n}\right) + \varphi(1),$$

$$S = \varphi(1) + \varphi\left(\frac{n-1}{n}\right) + \ldots + \varphi\left(\frac{1}{n}\right) + \varphi(0).$$

添加这两个等式并考虑到

$$\varphi(0) + \varphi(1) = \varphi\left(\frac{1}{n}\right) + \varphi\left(\frac{n-1}{n}\right) = \ldots =$$

$$= \varphi(x) + \varphi(1-x) = a^k,$$

我们得到

$$2S = (n+1)a^k,$$

即$S = \frac{1}{2}(n+1)a^k$。

所以���题 M393中的答案是：

$$S = \frac{1}{2}(n+1).$$

F397。以下是 Lematic annaram 的草稿。大平板的上表面在0℃的恒温下烧成，下表面在100℃的温度下烧成。发明者声称，通过浸入塑料，我们将像飞艇一样在空中翱翔。解释，因此。估算面积为 1 m² 的罂粟板在 20°C 气温下的升力的数量级。

入射到板上的空气分子的均方根速度等于$\bar{v}_{\text{cp.кв.}} = \sqrt{\frac{3kT}{m}}$，其中$T$是空气温度，$m$是分子的质量。垂直于板表面的$OY$轴上的分子设计速度的平均绝对值等于$\bar{v}_y \approx \frac{\bar{v}_{\text{cp.кв.}}}{\sqrt{3}} = \sqrt{\frac{kT}{m}}$。

当与板碰撞时，分子的“温度”变得等于板的温度。这意味着从顶面反射后

$$\bar{v}'_y = \sqrt{\frac{kT_1}{m}},$$

从上表面反射后

$$\bar{v}'_y = \sqrt{\frac{kT_2}{m}}.$$

因此，落在板下表面的分子动量的投影$p_y$在碰撞时会发生以下值的变化：

$$\Delta p'_y = m \left( \sqrt{\frac{kT}{m}} + \sqrt{\frac{kT_1}{m}} \right),$$

和一个落在上表面的分子 - 按值

$$\Delta p''_y = m \left( \sqrt{\frac{kT}{m}} + \sqrt{\frac{kT_2}{m}} \right).$$

在时间 $\Delta t$ 期间，距板距离等于 $\bar{v}_y \Delta t$ 的分子到达每个表面。这些分子的数量为$N = nv_y s \Delta t$，其中$n$是单位体积的分子数量，$s$是板的面积。

根据牛顿第二定律和第三定律，向上方向作用在板上的力的绝对大小等于每单位时间分子冲量投影的变化。板的底面受到向上的力 (图 7)

$$|\vec{F}_1| = \frac{N \Delta p'_y}{\Delta t} = m n \bar{v}_y s \left( \sqrt{\frac{kT_1}{m}} + \sqrt{\frac{kT}{m}} \right),$$

在顶部 - 向下的力

$$|\vec{F}_2| = \frac{N \Delta p''_y}{\Delta t} = m n \bar{v}_y s \left( \sqrt{\frac{kT_2}{m}} + \sqrt{\frac{kT}{m}} \right).$$

从$T_1 > T_2$开始，$\vec{F}_1$和$\vec{F}_2$的相等前导$\vec{R}$方向向上并且绝对值相等

$$|\vec{R}| = |\vec{F}_1| - |\vec{F}_2| = m n \bar{v}_y s \left( \sqrt{\frac{kT_1}{m}} - \sqrt{\frac{kT_2}{m}} \right) = nsk \sqrt{T} \left( \sqrt{T_1} - \sqrt{T_2} \right).$$

在压力$p$和温度$T$下，体积$V$空气中包含的分子数等于$N_V = v \cdot N_A$，其中$v$是体积$V$中的空气分子数，$N_A$是阿博加德罗数。但是$v = \frac{M}{\mu} = \frac{pV}{RT}$。所以单位体积的分子数

$$n = \frac{p}{RT} N_A.$$

$$\frac{1}{2F} \leqslant \frac{1}{d_2} \leqslant \frac{1}{F},$$

因此镜子的焦距$F'$必须满足以下条件

$$\frac{1}{2F} + \frac{1}{F} \leqslant \frac{1}{F'} \leqslant \frac{1}{F} + \frac{1}{2F}.$$

因此，$\frac{1}{F'} = \frac{3}{2F}$，或

$$F' = \frac{2}{3} F = 0,4 \text{ m}.$$
