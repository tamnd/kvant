VZMSH问题的解决方案

在本期中，我们发布了 1977 年 VZMSH 介绍性工作中的一些问题的解决方案（«Kvant»，1977 年，第 1 期，第 53 页）。

问题1.两个分数的等式，其分子和分母都是两位数，数字用字母代替：相同-相同，不同-不同：

$$\frac{KY}{PE} = \frac{KA}{KY}.$$

每个字母代表什么数字（足以给出所有可能的答案）？

解决方案。让我们用 $\frac{y}{x}$ 表示等于 $\frac{KY}{PE}$ 的不可约分数。换句话说，令 $\frac{KY}{PE} = \frac{y}{x}$ 和自然数 $x$ 和 $y$ 除了 1 之外没有其他公约数。因此，$PE = ax$ 和 $KY = ay$，同时还有 $KY = bx$ 和 $KA = by$。然后$ay = bx$，从这里开始，因为$x$和$y$没有公约数，$a = cx$，$b = cy$。因此，$KY = cxy$、$KA = cy^2$、$PE = cx^2$，其中$c$、$x$、$y$ 是自然数。

一方面，$|KY - KA| = |Y - A|$和$Y \neq A$。所以，$0 < |KY - KA| < 10$。另一方面，$KY - KA = cy(x - y)$。因此，

$$0 < cy|x - y| < 10.$$

(1) 因此 $c < 10$。由于$PE = cx^2$和$P \neq 0$，我们得到$x > 1$。我们同样得出$y > 1$的结论。 $y \geq 2$ 和 (1) 意味着 $c < 5$。所以，$1 \leq c \leq 4$。我们先看看$c = 2, 3, 4$的可能性。考虑到没有公约数$y$和$y$以及不等式（1），我们得到$c, y$和$x$的九个选项（见表）。检查表明这些选项都不合适。现在让$c = 1$。不等式 (1) 的形式为 $0 < y|x - y| < 10.$

(2) 从$KA = y^2$、$PE = x^2$开始，我们有$4 \leq x \leq 9$和$4 \leq y \leq 9$。从$y \geq 4$和(2)开始，它遵循$0 < |x - y| \leq 2$。所以，$|x - y| = 1$或$|x - y| = 2$。让我们证明$|x - y| \neq 2$。如果$y \geq 5$，则从(2)$|x - y| < 2$。如果$y = 4$和$|x - y| = 2$，那么$x = 6$与缺乏公约数$y$和$y$是矛盾的。所以，$|x - y| = 1$。因此$4 \leq x \leq 8$和$y = x + 1$或$5 \leq x \leq 9$和$y = x - 1$。检查所有 10 个选项会给出三个可能的答案：

1) $KY = 20$, $KA = 25$, $PE = 16$;
2) $KY = 30$, $KA = 36$, $PE = 25$;
3) $KY = 42$, $KA = 49$, $PE = 36$.
