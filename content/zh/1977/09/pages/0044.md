根据这些等式，可以得出矢量 $\vec{T}_1$ 连接三角形 $ABC$ 的顶点 $A$ 与点 $E$，矢量 $\vec{T}_2$ 连接点 $E$ 与点 $A$。

三角形$AEC$中有$\widehat{ACE} = \alpha$和$\widehat{CAE} = 90^\circ - \beta$，三角形$ABE$中有$\widehat{ABE} = 90^\circ - \alpha$和$\widehat{BAE} = \beta$。根据正弦定理

$$\frac{T}{\sin \alpha} = \frac{m_1 |\vec{g}|}{\sin (90^\circ - \beta)} = \frac{m_1 |\vec{g}|}{\cos \beta}, \quad \frac{m_2 |\vec{g}|}{\sin \beta} = \frac{T}{\sin (90^\circ - \alpha)} = \frac{T}{\cos \alpha}.$$

一起求解这些方程，我们发现

$$tg \beta = \frac{m_2}{m_1} \text{ctg} \alpha = 3\sqrt{3}, \quad \beta \approx 79^\circ;$$

$$T = m_1 |\vec{g}| \frac{\sin \alpha}{\cos \beta} \approx 2.7 \text{ H.}$$

现在让我们看看找到的平衡位置是否稳定。如果系统在该位置的势能最小，即负载系统的重心处于最低位置，则平衡位置是稳定的。为了查明这个条件是否满足，我们找到系统的重心坐标。

让我们用 $a$ 表示线三角形 (图 16) 的边 $DK$ 的长度，用 $l$ 表示螺纹的长度。系统的重心（点$O$）按比例$\frac{m_2}{m_1}$划分螺纹长度。

因此，它与左侧权重的距离为$b = \frac{m_2}{m_1 + m_2} l$。从图 16 可以清楚地看出$y_0 = (a - l \cos \beta) \sin \alpha - b \sin (\beta - \alpha) = a \sin \alpha - l (\cos \beta \sin \alpha) + \frac{m_2}{m_1 + m_2} \sin (\beta - \alpha))$。

当最大表达式为时，该表达式为最小

$$y_1 = \cos \beta \sin \alpha + \frac{m_2}{m_1 + m_2} \sin (\beta - \alpha).$$

我们来变换一下表达式 (*)：

$$y_1 = \cos \beta \sin \alpha + \frac{m_2}{m_1 + m_2} (\sin \beta \cos \alpha - \cos \beta \sin \alpha) = \frac{m_2}{m_1 + m_2} \sin \beta \cos \alpha + \frac{m_1}{m_1 + m_2} \cos \beta \sin \alpha = \sin (\beta + \varphi),$$

其中 $\sin \varphi = \frac{m_1}{m_1 + m_2} \sin \alpha$、$\cos \varphi = \frac{m_2}{m_1 + m_2} \cos \alpha$ 和 $tg \varphi = \frac{m_1}{m_2} \text{tg} \alpha$。

显然，表达式 (*) 的最大值为

$$\beta + \varphi = \frac{\pi}{2},$$ 或 $tg \beta = \text{ctg} \varphi = \frac{m_2}{m_1} \text{ctg} \alpha$。

因此，找到的平衡位置是稳定的。任何需要区分该值 $\beta$ 和表达式 (*) 的极值（最大）条件的人都可以。
