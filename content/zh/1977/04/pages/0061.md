⟦folio 59⟧

从八年级开始，该部门开始独立工作。协会的每个成员都会收到一个特定的主题和一名科学顾问，并被分配到一个科学机构。

分段工作分两个方向进行：
1. 理论课程、科学家讲座、研讨会、学生研究主题报告、杰出科学家报告。
2. 在科学顾问的指导下进行研究工作。

部分根据研究主题分为几组。例如，物理部分分为以下几组：理论物理、半导体物理、电子学和电子器件、原子核物理、光辐射和光谱学、普通物理、脉冲和气体电子学、固态物理。这些小组在苏联科学院应用物理研究所、国家物理大学和基希讷乌理工学院电物理学院的基础上开展工作。数学部分分为几组：数理逻辑、现代代数问题、应用数学和编程、几何变换、数学来源。他们在苏联科学院数学研究所、基希讷乌国立大学数学系以及理工学院和农业学院数学系的基础上开展工作。

该学会的所有成员都有会员卡，其中记载了他们的个人研究工作计划，并注明（由该部门的科学主管签署）工作的进展情况。最杰出的社会成员在毕业时会收到推荐信，这为他们进入摩尔多瓦高等教育机构相关专业提供了一定的优势。

超过 150 名科学家、大学教师和研究生与科学界的前辈一起工作，让他们参与科学研究。

VIITORUL 学会生活中的重要活动是一年一度的共和学生科学和创意会议。除了学会成员之外，著名科学家以及其他专家邀请的小学生也在其中学习。

因此，在基希讷乌举行的第三届城市会议上，以“能力、工作、天赋”为座右铭，宣读了 20 份关于各种物理问题的报告和 7 份数学问题的报告，并举办了数学奥林匹克竞赛。例如，其中的报告有：“电子顺磁共振方法在方解石研究中的应用”、“动力机械中的图像方法”、“火花放电及其在技术中的应用”、“液滴的形成及其与液体表面相互作用的研究”、“求圆的重心”、“删除其最后一组$a_1$的解决方案，$a \otimes b$表示通过赋值形成的数右边的$a$是数字$b$（在此表示法中为$a = a_n \otimes a_{n-1} \otimes \dots \otimes a_2 \otimes a_1$）。

证明对于任意自然数 $a$ 和奇自然数 $b$ 以下陈述成立：

a) $ab = (\dots(b' \otimes a_n + b') \otimes a_{n-1} + b') \otimes a_2 + b') \otimes a_1$

（这里$a_i$是分区组$a, i=1, 2, \dots, n$）；

b) 当且仅当非循环序列项 $c_1 = a, c_2 = c'_1 - b', c_3 = c_2 - b', \dots, c_{k+1} = c'_k - b', \dots$ 等于 0 时，$a$ 才能被$b$整除；此外，如果$c_{n+1} = 0$，则$a:b = (c_n)_1 \otimes (c_{n-1})_1 \otimes \dots \otimes (c_1)_1$。
