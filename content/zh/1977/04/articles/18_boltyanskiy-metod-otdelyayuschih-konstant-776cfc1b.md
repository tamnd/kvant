在大多数情况下，大学申请者笔试的做法包括从找到某些函数所接受的一组值开始就可以方便地解决问题。该问题没有其他解决方案，并且从获得的结果中立即得出答案；在其他情况下，一组函数值的值大大减少了工作量，指示了到达答案的最短路径。

解方程

分离常数的方法不仅可以用来证明缺陷，而且在某些情况下还可以用来求解方程，而且不是近似解，而是精确解。

例 4. 方程 $x^2 - 2x\sin x - 2\cos x + 2 = 0$ 的解。 (4) 我们将方程写成以下形式

$$(x - \sin x)^2 = -(1 - \cos x)^2,$$

也就是说，采用 $f(x) = g(x)$ 的形式，其中

$$f(x) = (x - \sin x)^2,$$

$$g(x) = -(1 - \cos x)^2.$$

显然，对于任何$x \in \mathbb{R}$，不等式$f(x) \geq 0$、$g(x) \leq 0$都是有效的。由此可见，某个数$x_0$只能满足等式$f(x_0) = g(x_0)$，即为方程（4）的根，如果满足等式$f(x_0) = 0$、$g(x_0) = 0$，即$x_0$是系统的解

$$\begin{cases} x - \sin x = 0, \\ 1 - \cos x = 0. \end{cases}$$

该方程组的第二个方程有根$x = 2k\pi (k = 0, \pm 1, \pm 2, \ldots)$，其中只有根$x = 0$满足第一个方程。因此，原方程有一个单根$x = 0$。

例 5. 求解方程

$$x^3 - 2x^2 + x + 1 = \sqrt{\sin \frac{\pi x}{2}}.$$ (5)

这个方程可以写成 $f(x) = g(x)$，其中

$$f(x) = x^2 - 2x^2 + x + 1,$$

$$g(x) = \sqrt{\sin \frac{\pi x}{2}}.$$

由于 $f(x) = 1 + x(x - 1)^2$，那么 $f(x) \geq 1$ 对于所有 $x \geq 0$。同时，$g(x) \leq 1$对于所有$x$属于函数$g(x)$的定义域。因此，在射线$x \geq 0$上，数字$c = 1$是函数$f(x)$和$g(x)$的分离常数。由此可见，非负数$x_1 = 1$、$x_2 = 0$，其中只有$x_1$满足第二个方程。因此，方程（5）只有一个非负根$x_1 = 1$。

现在让我们看看是否有任何负根。由于在 $-2 < x < 0$ 处函数 $g(x)$ 未定义，因此必须仅在射线 $x \leq -2$ 上求负根。但对于$x \leq -2$，根据函数$\sqrt{x}$的定义，我们有$f(x) = 1 + x(x - 1)^2 \leq 1 - 2 \cdot 3^2 = -17$和$g(x) \geq 0$。因此，射线 $x \leq -2$ 上$f(x)$ 和 $g(x)$ 的分隔符（在定义函数 $g(x)$ 的那些点 $x$ 处）例如是数字 $c = -10$。因此，考虑非负根方程，即$x_1 = 1$是方程（5）的唯一根。
