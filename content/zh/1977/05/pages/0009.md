⟦folio 7⟧

对于所有负数$\Delta x$，除非$-\delta < \Delta x < 0$。因此，对于任何 $\varepsilon > 0$ 都存在一个 $\delta > 0$，使得对于 $0 < |\Delta x| < \delta$ 不等式 (*) 成立。根据极限的定义，这意味着

$$\lim_{\Delta x \to 0} \frac{\Delta S(x)}{\Delta x} = f(x),$$

IE。

$$S'(x) = f(x).$$

已证明的等式使我们能够计算函数$F$的面积。令 $\varphi$ 为函数 $f$ 的反导数。由于$S$也是该函数的反导数，因此$\varphi$和$S$相差一个常数，即存在一个数$c$，使得对于任何$x \in [a, b]$都有$\varphi(x) = S(x) + c$。

因此，

$$\varphi(b) - \varphi(a) = (S(b) + c) - (S(a) + c) = S(b) - S(a) = S(F)$$

（因为$S(a) = 0$和$S(b)$是整个函数$F$的面积）。因此，如果$\varphi$是函数$f$的某个反导数，那么差值$\varphi(b) - \varphi(a)$就等于函数$F$的面积，即$S(F) = \int_a^b f(x) dx$。

例如，如果 $F$ 是一个由抛物线 $y = x^2$ 和直线 $y = 0$、$x = b$ (图 11) 围成的“曲线三角形”，则通过线段 $[0, b]$ 的点 $x$ 并平行于纵坐标轴的直线从此“三角形”切出$F$ 是长度为 $x^2$ 的线段，即本例中的$f(x) = x^2$。对于函数$f(x) = x^2$，反导数之一是函数$\varphi(x) = \frac{1}{3} x^3$。因此，函数$F$的面积可以通过公式求出

$$S(F) = \varphi(b) - \varphi(0) = \frac{1}{3} b^3.$$

请注意，从满足“三角形”$F$面积的矩形$ABCD$（图 12）面积中减去，我们就得到了抛物线段的面积，因此等于$\frac{4}{3} b^3$。正如您所看到的，借助反导数，我们只需使用基于穷举法的复杂计算即可获得阿基米德得出的结果 *)。今天的小学生所知道的比伟大的阿基米德所知道的要多得多！
