示例 7. 求函数 $f$ 的反导数可由以下公式给出

$$F(x) = \int_a^x f(t) \, dt$$

（“代数和分析的开端 10”，第 102 段）。

这样的话，我们放入$a = 1$，那么我们就需要计算区间

$$F(x) = \int_1^x \ln t \, dt.$$

如果$x > 1$，那么这个区间等于函数的面积，红色偏移图 12。让我们相对于直线$y = t$反映它；那么它将显示在函数 (图 13) 中，受$t = 0, t = \ln x$线以及函数$y = x$和$y = e^t$（$y = \ln t$的反函数）的图形限制。该函数的面积根据式（3）等于

$$\int_0^{\ln x} |e^t - x| \, dt.$$

由于$e^t \leq x$是$0 \leq t \leq \ln x$，我们得到

$$F(x) = \int_1^x \ln t \, dt = \int_0^{\ln x} (x - e^t) \, dt = (xt - e^t) \bigg|_0^{\ln x} = x \ln x - x + 1.$$

$x \geq 1$ 函数$f(x) = \ln x$ 的反导数的一般形式如下：

$$F(x) = x(\ln x - 1) + C,$$

其中 $C$ 是任意常数。通过对函数$F$求微分，我们可以验证它是函数$f$的实反导数，也是$x \in ]0; 1]$的实反导数。
