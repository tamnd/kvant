直接下山坡：

$$M|\vec{g}| \sin \alpha - \mu(M+m)|\vec{g}| \cos \alpha + |\vec{F}| = 0,$$

这里$\vec{F}$是人与雪橇之间的相互作用力，$\vec{a}$是人的加速度。从这些方程

$$a = \frac{(M+m)|\vec{g}|}{m}(\sin \alpha - \mu \cos \alpha) \approx -3 \text{ m/сек}^2,$$

也就是说，人必须在雪橇上以加速度$3 \text{ m/сек}^2$向上移动。

2. 根据热力学第一定律，在膨胀过程中必须传递给气体的热量$Q$等于气体的功$A$。由于体积的相对增加很小，我们可以假设膨胀过程中的压力按照线性规律减小。然后

$$A = p_{\text{cp}} \Delta V = \frac{1}{2}(p_1 + p_2) \Delta V.$$

来自波义耳-马里奥特定律

$$p_2 = \frac{p_1 V_1}{V_1 + \Delta V} = p_1 \frac{1}{1 + \frac{\Delta V}{V_1}} \approx p_1 \left(1 - \frac{\Delta V}{V_1}\right).$$

因此，

$$Q = A \approx p_1 \Delta V \left(1 - \frac{\Delta V}{2V_1}\right) = \frac{m}{\mu} RT \frac{\Delta V}{V_1} \left(1 - \frac{1}{2} \frac{\Delta V}{V_1}\right) \approx 4,88 \text{ дж.}$$

3. 在稳定状态下，作用于磁场中自由电荷的$\vec{F}_M$由发电厂通过力$\vec{F}_3$进行补偿：

$$|\vec{F}_M| = |\vec{F}_3|, \text{ или } q|\vec{v}||\vec{B}| = q \frac{U}{d}.$$

从这里

$$|\vec{v}| = \frac{U}{|\vec{B}| d} = 2 \text{ m/сек.}$$

4. 位于棱镜底座 (图 2) 区域 AD 下方的文本部分通过面 BC 将不可见。由三角形 ACD 根据正弦定理 $\frac{l}{\sin(90^\circ + \beta)} = \frac{a}{\sin \gamma}$，其中 $a = (1 - \alpha) \sqrt{2}l$、$\sin \beta = \frac{1}{n}$、$\gamma = 45^\circ - \beta$。从这里我们可以找到折射率 $n$：

$$n = \sqrt{1 + \frac{1}{(2\alpha - 1)^2}} \approx 1,6.$$

门票2

1. 在与碰撞原子质心相关的参考系中，总动量为零：

$$m_\alpha \left( |\vec{v}_\alpha| - |\vec{v}| \right) + m_\gamma \left( |\vec{v}_\gamma| - |\vec{v}| \right) = 0,$$

其中$m_\alpha = 3m_\gamma$和$|\vec{v}_\alpha| = 2|\vec{v}_\gamma|$。因此质心的速度

$$|\vec{v}| = \frac{m_\alpha |\vec{v}_\alpha| + m_\gamma |\vec{v}_\gamma|}{m_\alpha + m_\gamma} = \frac{5}{8} |\vec{v}_\alpha| = 625 \text{ m/сек}.$$

2. 每次与移动活塞碰撞后，气体分子的速度都会降低 $2|\vec{v}|$。可能发生多少次碰撞？让我们用$t$表示第一次和第二次碰撞之间的时间，然后

$$t = \frac{2H - x}{|\vec{v}|} = \frac{2H - x}{|\vec{v}| - 2|\vec{v}|},$$

其中$x = |\vec{u}| t$是相应的活塞变化。从这里

$$x = \frac{2|\vec{u}|}{|\vec{v}| - 3|\vec{u}|} H = \frac{2}{5} H < \frac{3}{5} H,$$

因此，有些分子会经历两次碰撞，第二次碰撞后它们的速度为$\|\vec{v}_2\| \geq |\vec{v}| - 4|\vec{u}| = 100 \text{ m/сек}$。类似地，可以证明第三次碰撞是不可能的。因此，最后

$$100 \text{ m/сек} \leq |\vec{v}_2| \leq 200 \text{ m/сек}.$$

3. 电容器板与带电板产生的电场相互作用。该场的电压为$|\vec{E}| = \frac{Q}{2\varepsilon_0 S}$。电容器$q$的电荷产生自己的电场$|\vec{E}_1| = \frac{q}{\varepsilon_0 S} = \frac{\mathcal{E}}{d - d_1}$，来自$q = \frac{\mathcal{E}}{\varepsilon_0 S} / d - d_1$。
