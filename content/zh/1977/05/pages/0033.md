⟦folio 31⟧

例 2. 求直线 $y = x$、$y = 1/x$、$y = 0$、$x = e$ 所围成的图形的面积。

该图 (图 3) 可以视为由 x 轴、直线 $x = 0$ 和 $x = e$ 以及函数图为界的弯曲非线性梯形，位于线段 [0; 1] 等于 $x$，并且在区间 [1; $e$]等于$1/x$。然而，不可能为这样的函数编写转换。

可能我们将曲线$x = 1$给出的非线性梯形分成两部分（图3）。使用公式 (1) 可以立即找到它们的面积：

$$S_1 = \int_0^1 x dx, \quad S_2 = \int_1^e \frac{1}{x} dx.$$

由于函数 $f_1(x) = x$ 的变换是函数 $F_1(x) = x^2/2$，而函数 $f_2(x) = 1/x$ 的变换是（对于 $x > 0$）函数 $F_2(x) = \ln x$，则

$$S_1 = \int_0^1 x dx = \frac{x^2}{2} \bigg|_0^1 = \frac{1}{2},$$

$$S_2 = \int_1^e \frac{1}{x} dx = \ln x \bigg|_1^e = 1,$$

以及面积可加性的性质

$$S = S_1 + S_2 = 1 + \frac{1}{2} = \frac{3}{2}.$$

不变性

对于更复杂的问题，面积的另一个属性会有所帮助，称为相对位移不变性：全等函数具有相等的面积。

示例 3. 求由线包围的图形的面积

$$y = \sqrt{x}, \quad y = 2, \quad x = 0.$$
