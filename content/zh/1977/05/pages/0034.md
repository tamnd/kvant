面积的可加性和不变性不仅使求曲线梯形的面积变得更加容易，而且还可以让你求出更复杂图形的面积，例如，由某些函数的图形和从上往下围成的面积，以及“双曲线梯形”的蓝色区域。

例 4. 求直线 $y = x^2 + 2, y = 1 - x^2, x = 0, x = 1$ 所围成的图形的面积。

由直线 $x = 0, x = 1, y = 0$（x 轴）和函数 $y = 1 - x^2$ 的图形界定的曲线梯形将该图与由直线 $x = 0, x = 1, y = 0$ 和函数 $y = x^2 + 2$ 的图形界定的曲线梯形 (图 6, a) 互补。换句话说，条件中给出的图形可以被认为是两个曲线梯形（图6，b，θ）的差。因此面积

$$S = \int_0^1 (x^2 + 2) dx - \int_0^1 (1 - x^2) dx = \left( \frac{x^3}{3} + 2x \right) \bigg|_0^1 - \left( x - \frac{x^3}{3} \right) \bigg|_0^1 = \frac{7}{3} - \frac{2}{3} = \frac{5}{3}.$$

这个推理可以很容易地概括如下。

令$f$和$g$是定义在区间$[a; b]$上的两个连续函数，并令不等式$f(x) \geq g(x)$对于所有$x \in [a; b]$成立。

那么由函数 $y = f(x), y = g(x)$ 的图形和直线 $x = a, x = b$ (图 7) 所围成的图形面积等于

$$S = \int_a^b f(x) dx - \int_a^b g(x) dx.$$

并且由于两个函数（在同一线段上）的区间之差等于它们之间的区间差（“代数与分析入门 10”，第 106 页），$S$ 的表达式可以写成如下：

$$S = \int_a^b (f(x) - g(x)) dx. \tag{2}$$

如果 $g(x) \geq 0$ 在 $x \in [a; b]$，则公式 (2) 的推导方式与示例 4 相同。如果在某些点 $g(x) < 0$，则我们向两个函数添加相同的常数 $k$，我们选择的常数太大，使得函数 $y = f(x) + k$ 和 $y = g(x) + k$ 的图形位于横坐标轴 (图8) 上方。 图 7 处的图形是由 图 8 处的图形平行平移得到的，因此也有面积。公式(2)应用于图8处的图形：

$$S = \int_a^b \left[ (f(x) + k) - (g(x) + k) \right] dx.$$

但

$$(f(x) + k) - (g(x) + k) = f(x) - g(x).$$

由此我们得到图7上的图的公式(2)。
