面积和积分

从本期发表的V. Boltyansky的文章《论面积和体积的概念》中，您了解了面积的定义和各种计算方法。其中最普遍的是积分微积分的使用。本文将讨论这种方法（适用于十年级学生）。但首先，我们建议您看一下教科书“代数和分析的开端 10”，然后再看一下第 97-102 段以及第 14 页的反导数表。 219.

面积是一个积分

考虑 图 1 上的弯曲梯形。该图以连续非负函数 $y = f(x)$ 的图形为界，定义在线段 $[a; b]$、线 $x = a, x = b$ 和 x 轴 $y = 0$ 上。它的面积$S$等于

$$F(b) - F(a),$$

其中 $F$ 是函数 $f$ 的一些反导数（“代数和分析原理 10”，第 100 页）。记住积分的定义（“代数和 Na-

分析开始10”，第101段），计算面积的公式可以改写如下：

$$S = \int_{a}^{b} f(x) dx.$$

例1.图形的最大面积受到x轴、直线$x = -1, x = 1$和函数图形$y = 1 - x^2$(图2)的限制，因此，根据公式(1)，其面积

$$S = \int_{-1}^{1} (1 - x^2) dx.$$

由于函数 $f(x) = 1 - x^2$ 的反导数是函数

$$F(x) = x - \frac{x^3}{3},$$

那

$$S = \left( x - \frac{x^3}{3} \right) \bigg|_{-1}^{1} = \frac{4}{3}.$$

您会看到，在这个例子中，我们不必诉诸任何技巧；为了解决这个问题，事实证明使用现成的公式就足够了。但情况并非总是如此。

例 2. 求直线 $y = x$、$y = 1/x$、$y = 0$、$x = e$ 所围成的图形的面积。

该图 (图 3) 可以视为由 x 轴、直线 $x = 0$ 和 $x = e$ 以及函数图为界的弯曲非线性梯形，位于线段 [0; 1] 等于 $x$，并且在区间 [1; $e$]等于$1/x$。然而，不可能为这样的函数编写转换。

可能我们将曲线$x = 1$给出的非线性梯形分成两部分（图3）。使用公式 (1) 可以立即找到它们的面积：

$$S_1 = \int_0^1 x dx, \quad S_2 = \int_1^e \frac{1}{x} dx.$$

由于函数 $f_1(x) = x$ 的变换是函数 $F_1(x) = x^2/2$，而函数 $f_2(x) = 1/x$ 的变换是（对于 $x > 0$）函数 $F_2(x) = \ln x$，则

$$S_1 = \int_0^1 x dx = \frac{x^2}{2} \bigg|_0^1 = \frac{1}{2},$$

$$S_2 = \int_1^e \frac{1}{x} dx = \ln x \bigg|_1^e = 1,$$

以及面积可加性的性质

$$S = S_1 + S_2 = 1 + \frac{1}{2} = \frac{3}{2}.$$

不变性

对于更复杂的问题，面积的另一个属性会有所帮助，称为相对位移不变性：全等函数具有相等的面积。

示例 3. 求由线包围的图形的面积

$$y = \sqrt{x}, \quad y = 2, \quad x = 0.$$

面积的可加性和不变性不仅使求曲线梯形的面积变得更加容易，而且还可以让你求出更复杂图形的面积，例如，由某些函数的图形和从上往下围成的面积，以及“双曲线梯形”的蓝色区域。

例 4. 求直线 $y = x^2 + 2, y = 1 - x^2, x = 0, x = 1$ 所围成的图形的面积。

由直线 $x = 0, x = 1, y = 0$（x 轴）和函数 $y = 1 - x^2$ 的图形界定的曲线梯形将该图与由直线 $x = 0, x = 1, y = 0$ 和函数 $y = x^2 + 2$ 的图形界定的曲线梯形 (图 6, a) 互补。换句话说，条件中给出的图形可以被认为是两个曲线梯形（图6，b，θ）的差。因此面积

$$S = \int_0^1 (x^2 + 2) dx - \int_0^1 (1 - x^2) dx = \left( \frac{x^3}{3} + 2x \right) \bigg|_0^1 - \left( x - \frac{x^3}{3} \right) \bigg|_0^1 = \frac{7}{3} - \frac{2}{3} = \frac{5}{3}.$$

这个推理可以很容易地概括如下。

令$f$和$g$是定义在区间$[a; b]$上的两个连续函数，并令不等式$f(x) \geq g(x)$对于所有$x \in [a; b]$成立。

那么由函数 $y = f(x), y = g(x)$ 的图形和直线 $x = a, x = b$ (图 7) 所围成的图形面积等于

$$S = \int_a^b f(x) dx - \int_a^b g(x) dx.$$

并且由于两个函数（在同一线段上）的区间之差等于它们之间的区间差（“代数与分析入门 10”，第 106 页），$S$ 的表达式可以写成如下：

$$S = \int_a^b (f(x) - g(x)) dx. \tag{2}$$

如果 $g(x) \geq 0$ 在 $x \in [a; b]$，则公式 (2) 的推导方式与示例 4 相同。如果在某些点 $g(x) < 0$，则我们向两个函数添加相同的常数 $k$，我们选择的常数太大，使得函数 $y = f(x) + k$ 和 $y = g(x) + k$ 的图形位于横坐标轴 (图8) 上方。 图 7 处的图形是由 图 8 处的图形平行平移得到的，因此也有面积。公式(2)应用于图8处的图形：

$$S = \int_a^b \left[ (f(x) + k) - (g(x) + k) \right] dx.$$

但

$$(f(x) + k) - (g(x) + k) = f(x) - g(x).$$

由此我们得到图7上的图的公式(2)。

如果在线段 $[a; b]$ 上定义的连续函数$f$ 和 $g$ 的图相交，并且在位置 $f(x) > g(x)$ 和位置 $g(x) > f(x)$ (图 9) 处，则

由函数图像 $f$ 和 $g$ 以及线 $x = a$、$x = b$ 界定的函数结构等于

$$S = \int_{a}^{b} |f(x) - g(x)| \, dx. \tag{3}$$

这个公式概括了公式（2）（自己证明一下）。

示例 5. 查找行 $y = x^3 - 3x$ 和 $y = x$ 之间包含的函数的面积 $S$。

这些线在坐标为 $(-2; -2)$、$(0; 0)$ 和 $(2; 2)$ (图 10) 的点处相交，$(x^3 - 3x) - x = x^3 - 4x$ 和 $|x^3 - 4x| = x^3 - 4x$ 在 $-2 \leq x \leq 0$ 处，$|x^3 - 4x| = 4x - x^3$ 在 $0 \leq x \leq 2$ 处。因此，根据式（3）

$$S = \int_{-2}^{2} |(x^3 - 3x) - x| \, dx =$$

$$= \int_{-2}^{2} |x^3 - 4x| \, dx = \int_{-2}^{0} (x^3 - 4x) \, dx +$$

$$+ \int_{0}^{2} (4x - x^3) \, dx = \left( \frac{x^4}{4} - 2x^2 \right) \bigg|_{-2}^{0} +$$

$$+ \left( 2x^2 - \frac{x^4}{4} \right) \bigg|_{0}^{2} = 4 + 4 = 8.$$

注意到 图 10 处的函数相对于原点对称，我们可以获得该问题的更短解：

$$S = 2 \int_{0}^{2} |(x^3 - 3x) - x| \, dx =$$

$$= 2 \int_{0}^{2} |x^3 - 4x| \, dx = 2 \int_{0}^{2} (4x - x^3) \, dx =$$

$$= 2 \cdot \left( 2x^2 - \frac{x^4}{4} \right) \bigg|_{0}^{2} = 2 \cdot 4 = 8.$$

积分计算

到目前为止，我们已经使用积分来解决一个几何问题——计算面积。现在我们将几何消息应用到积分的计算中。

示例 6. 计算积分

$$\int_{0}^{1} \sqrt{1 - x^2} \, dx.$$

示例 7. 求函数 $f$ 的反导数可由以下公式给出

$$F(x) = \int_a^x f(t) \, dt$$

（“代数和分析的开端 10”，第 102 段）。

这样的话，我们放入$a = 1$，那么我们就需要计算区间

$$F(x) = \int_1^x \ln t \, dt.$$

如果$x > 1$，那么这个区间等于函数的面积，红色偏移图 12。让我们相对于直线$y = t$反映它；那么它将显示在函数 (图 13) 中，受$t = 0, t = \ln x$线以及函数$y = x$和$y = e^t$（$y = \ln t$的反函数）的图形限制。该函数的面积根据式（3）等于

$$\int_0^{\ln x} |e^t - x| \, dt.$$

由于$e^t \leq x$是$0 \leq t \leq \ln x$，我们得到

$$F(x) = \int_1^x \ln t \, dt = \int_0^{\ln x} (x - e^t) \, dt = (xt - e^t) \bigg|_0^{\ln x} = x \ln x - x + 1.$$

$x \geq 1$ 函数$f(x) = \ln x$ 的反导数的一般形式如下：

$$F(x) = x(\ln x - 1) + C,$$

其中 $C$ 是任意常数。通过对函数$F$求微分，我们可以验证它是函数$f$的实反导数，也是$x \in ]0; 1]$的实反导数。
