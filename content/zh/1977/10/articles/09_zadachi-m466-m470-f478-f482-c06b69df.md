F438。均匀的棒位于粗糙的球形空腔内。棒的长度等于球体的半径。时间因子为$\mu$。用一根棍子组成的地平线的最佳点是什么？

显然，当通过木棍与球体的接触点所画的大圆平面垂直时，木棍与地平线所成的角为$\alpha$。

在此平面中，杆受到重力$Mq$、球体法向反作用力$\vec{N}_1$和$\vec{N}_2$以及摩擦力$\vec{F}_1$和$\vec{F}_2$（图7）的作用。

如果这些力在任何方向上的投影之和以及相对于任何固定轴的力的力矩之和为零，则棒处于静止状态。让我们写下棒在其方向投影中的平衡条件：

$$|\vec{N}_1| \cos \varphi - |\vec{N}_2| \cos \varphi + |\vec{F}_1| \sin \varphi + |\vec{F}_2| \sin \varphi - |\vec{Mg}| \sin \alpha = 0.$$

将力投射到方向上，重新分配到棍子上，我们得到

$$|\vec{N}_1| \sin \varphi + |\vec{N}_2| \sin \varphi - |\vec{F}_1| \cos \varphi + |\vec{F}_2| \cos \varphi - |\vec{Mg}| \cos \alpha = 0.$$

可以很方便地写出相对于轴、重新分布到绘图平面和通过中心的球体的力矩方程：

$$|\vec{F}_1| R + |\vec{F}_2| R - |\vec{Mg}| R \sin \varphi \sin \alpha = 0.$$

这里$\varphi = \pi/3$、$R$是棒的长度，等于球体的半径。对于距离地平线最近的点，您可以在其方向上投影一根棍子：

$$|\vec{F}_1| = \mu |\vec{N}_1| \text{ и } |\vec{F}_2| = \mu |\vec{N}_2|.$$

解出方程的结果跟系统后，我们发现

$$tg \alpha_{\text{max}} = \frac{\mu}{\sin^2 \varphi - \mu^2 \cos^2 \varphi} = \frac{4\mu}{3 - \mu^2},$$

$$\alpha_{\text{max}} = \arctg \frac{4\mu}{3 - \mu^2}.$$

这个问题可以用所谓的“三力定理”以同样的方式解决：如果一个物体在三个不平行的力的作用下处于平衡状态，那么这些力的作用线相交于一点。

在我们的例子中，施加到棍子上的三个力是重力 $\vec{Mg}$ 以及由此产生的反作用力 $\vec{R}_1 = \vec{F}_1 + \vec{N}_1$ 和 $\vec{R}_2 = \vec{F}_2 + \vec{N}_2$ (图 8)。由于棒头最大角度$\alpha_{\text{max}}$处的力特雷米亚最大，因此力$\vec{R}_1$和$\vec{R}_2$与在接触点处绘制的球体半径构成相同的角度$\beta = \arctg \mu$（特雷米亚角）。

让我们考虑三角形$ACB$，其中棒是底边，力作用线的交点$C$是对边顶点。重力的线性作用将上述三角形一分为二，公共边长为$l$（三角形的中线$ACB$），混凝土底长为$R/2$。将正弦定理应用于每个三角形，我们得到

$$\frac{\sin(\pi/2 + \alpha - \varphi - \beta)}{R/2} = -\frac{\sin(\varphi + \beta)}{l}$$

和

$$\frac{\sin(\pi/2 - \alpha - \varphi + \beta)}{R/2} = \frac{\sin(\varphi - \beta)}{l},$$

其中$tg \beta = \mu$和$\varphi = \pi/3$。

将这两个方程相除，我们得到

$$\frac{\cos(\alpha - \varphi - \beta)}{\cos(\alpha + \varphi - \beta)} = \frac{\sin(\varphi + \beta)}{\sin(\varphi - \beta)},$$

从中我们会发现

$$tg \alpha = \frac{(1 + tg^2 \varphi) tg \beta}{tg^2 \varphi - tg^2 \beta} = \frac{4\mu}{3 - \mu^2}.$$

V·科皮洛夫

F440。如果表面温度为 $T = 300$ K，则估计在多大的最小半径下它将形成主要由分级剂和氮气组成的封闭气氛。该物质的平均密度等于 $\rho = 4 \cdot 10^3$ kg/m3。

让我们考虑大气中的一个分子。如果该分子的动能不超过该分子在平面引力场中的势能，则该分子将保持在靠近平面表面的位置：

$$\frac{mv^2}{2} \leqslant \gamma \frac{mM}{r}.$$

这里$m$是分子的质量，$v^2$是其速度的均方，$\gamma$是万有引力常数，$M$是平面质量，$r$是其半径。可以使用动能和势能按数量级检查计划的最小半径的估计：

$$\frac{mv^2}{2} \approx \gamma \frac{mM}{r_{\min}}.$$

气体分子的均方速度与气体温度 $T$ 的对应关系为

$$\overline{v^2} = \frac{3kT}{m} = \frac{3RT}{\mu},$$

其中$k$是玻尔兹曼常数，$R$是通用气体常数，$\mu$是气体的摩尔质量。平面的质量可以通过平面物质的密度平均值$\rho$与其最小半径来表示：

$$M = \frac{4}{3} \pi r_{\min}^3 \rho.$$

那么对应关系（1）可以改写如下：

$$\frac{3RT}{2\mu} \approx \frac{4}{3} \gamma \pi r_{\min}^2 \rho,$$

在哪里

$$r_{\min} \approx \sqrt{\frac{9RT}{8\gamma \pi \mu}}.$$

从公式 (2) 可以看出，$r_{\min}$ 取决于（其他条件相同）$\mu$ 的摩尔质量：$\mu$ 越大，$r_{\min}$ 越小。根据问题的条件，大气主要由类物质和氮气组成，其摩尔质量等于相应的 $\mu_k = 32 \cdot 10^{-3}$ kg/mol 和 $\mu_a = 28 \cdot 10^{-3}$ kg/mol。显然，假设大气仅由氮气组成，要估计计划的最小半径，找到 $r_{\min}$ 就足够了。

所以，

$$r_{\min} \approx \sqrt{\frac{9RT}{8\gamma \pi \mu_a}} \approx 3 \cdot 10^5 \text{ м} = 300 \text{ км}.$$

图 11.

由于电容器极板很大，当电荷 q 平行于极板平面移动时，其上感应的电荷不会改变（我们忽略边缘效应）。这意味着，即使电荷 q 沿着平行于电容器极板的平面均匀“涂抹”并且最初位于距左极板距离 $\frac{1}{3} d$ 的位置，极板的电荷也不会改变。

让我们用 $q_1$ 表示电容器左极板的电荷。那么右边极板的电荷（根据电荷守恒定律）等于$-q_1$。电容器极板的电荷$q_1$和$-q_1$在极板之间产生强度$|\vec{E}_1| = \frac{q_1}{\varepsilon_0 S}$的静电场（$S$是每个极板的面积），位于电容器内部的带有电荷$q$的极板产生强度$|\vec{E}| = \frac{q}{2\varepsilon_0 S}$（图11）的电场。在板的一侧，定向场的方向一致，而在另一侧，它们彼此相反。因此，电容器极板之间的电势差$\Delta\varphi$等于

$$\Delta\varphi = \left( |\vec{E}_1| - |\vec{E}| \right) \frac{1}{3} d + \left( |\vec{E}_1| + |\vec{E}| \right) \frac{2}{3} d.$$

另一方面，由于电容器板是闭合的，因此它们之间的方向为零：$\Delta\varphi = 0$。因此，

$$\frac{1}{3} d \left( \frac{q_1}{\varepsilon_0 S} - \frac{q}{2\varepsilon_0 S} \right) + \frac{2}{3} d \left( \frac{q_1}{\varepsilon_0 S} + \frac{q}{2\varepsilon_0 S} \right) = 0.$$

从这个方程我们找到电荷 $q_1$：

$$q_1 = -\frac{1}{6} q.$$

同样，当中间极板（电荷 q）与电容器左极板距离 $\frac{2}{3} d$ 时，您可以找到电容器左极板的电荷 $q'_1$：

$$q'_1 = \frac{1}{6} q.$$

因此，当内部电容器沿着连接电容器板的导体移动电荷 q（或带电板）时，电荷会通过

$$\Delta q = q'_1 - q_1 = \frac{1}{3} q.$$
