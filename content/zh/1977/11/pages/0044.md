证明如果集合 $M$ 是凸的，则集合 $tM$（即点集 $t\beta$，其中 $\beta \in M$）也是凸的。

定义。如果还存在非负数$t_1, t_2, \dots, t_n$，例如$t_1 + t_2 + \dots + t_n = 1$和$\beta = t_1\beta_1 + t_2\beta_2 + \dots + t_n\beta_n$，则点$\beta$称为点$\beta_1, \beta_2, \dots, \beta_n$的凸组合。

定理。凸包集 $M$ 由 $M$ 中所有可能的凸点组合组成。

证明。让我们用 $Q$ 表示来自 $M$ 的点的凸组合集。如果$\gamma$和$\delta$是任意点，则$t\gamma + (1-t)\delta$形式的点集（其中$0 \leq t \leq 1$）与端点为$\gamma$、$\delta$的线段重合。从这里很容易推断出 $Q$ 是凸集（这样做！）。另外，非常/不，$M \subset Q$。因此，巧合$M \subset Q$。现在让我们通过对$n$的归纳证明，$M$中的点的任何凸组合$t_1\beta_1 + t_2\beta_2 + \dots + t_n\beta_n(t_1 + t_2 + \dots + t_n = 1)$都接受重合$M$。这意味着 $Q \subset \text{conv } M$。对于$n = 1$，相应的语句采用以下形式：if $\beta \in M$，则$\beta \in \text{conv } M$。根据凸包的定义这是正确的。现在让来自$M$的点的所有凸组合$n$接受重合$M$。让我们证明凸组合$\delta = t_1\beta_1 + t_2\beta_2 + \dots + t_n\beta_n + t_{n+1}\beta_{n+1}$（其中$\beta_1, \beta_2, \dots, \beta_n, \beta_{n+1}$是来自$M$的点）也采用$M$：

$$\delta = (1 - t_{n+1}) \left[ \frac{t_1}{1 - t_{n+1}}\beta_1 + \frac{t_2}{1 - t_{n+1}}\beta_2 + \dots + \frac{t_n}{1 - t_{n+1}}\beta_n \right] + t_{n+1}\beta_{n+1}.$$

从 $t_1 + t_2 + \dots + t_n + t_{n+1} = 1$ 可以得出

$$\frac{t_1}{1 - t_{n+1}} + \frac{t_2}{1 - t_{n+1}} + \dots + \frac{t_n}{1 - t_{n+1}} = 1.$$

由归纳假设

$$\eta = \frac{t_1}{1 - t_{n+1}}\beta_1 + \frac{t_2}{1 - t_{n+1}}\beta_2 + \dots + \frac{t_n}{1 - t_{n+1}}\beta_n \in \text{conv } M.$$

从 (4) 可知，点 $\delta$ 位于端点 $\eta$ 和 $\beta_{n+1}$ 的线段上。由于$\beta_{n+1} \in M \subset \text{conv } M$和卷积$M$是凸集，我们得到$\delta \in \text{conv } M$。定理已被证明。

因此，卷积$M$中的每个点都是$M$中某个端点的凸组合。如果集合$M$是有限的，那么我们可以假设来自$M$的每个点都是来自$M$的所有点的凸组合。
