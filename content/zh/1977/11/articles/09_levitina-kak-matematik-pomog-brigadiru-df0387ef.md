数学家如何帮助准将

本文的主要目标是表明实践中出现的最简单的问题自然会引出数学的基本概念。

1. 领班接到任务

我们的工头带领一个 10 人的团队，必须装载位于两个仓库的砖块。第一个仓库有4000块砖，第二个仓库有8000块。仓库的布置方式是，第一个仓库必须至少有六名工人同时装货，第二个仓库可以有三到六名工人同时装载。工头需要分配工人，以便在最短的时间内完成所有工作。

准将能做什么？例如，这样：首先将所有工人发送到第一个仓库，装载后，将最大允许数量的六名工人转移到第二个仓库。为简单起见，我们假设每个工人需要一小时来切割一些砖块。那么团队按照这个时间表完成所有工作的时间就非常长，等于$\frac{4}{10} + \frac{8}{6} = 1\frac{11}{15}$（小时）。

这样的工作安排是最好的吗？如果是这样，为什么？如果不是，离最佳状态还有多远？准将本人无法回答这些问题。你呢？尝试一下 - 那么您在以下段落中阅读有关准将与数学家会面的段落会更有趣，准将将其任务转向了这次会面。

2. 数学家创建问题模型

在解决问题之前，数学家必须创建其数学模型。

如果我们用$u$和$v$表示第一和第二仓库中的数量，那么对于每个时刻，数字$u$和$v$满足以下条件：

1) $u \in \mathbb{Z}$ 和 $v \in \mathbb{Z}$,
2) $6 \leq u \leq 10$ 或 $u=0$,
3) $3 \leq v \leq 6$ 或 $v=0$,
4) $u + v \leq 10$.

以下十三种操作模式满足这些条件：$\langle 6,4 \rangle$（第一个仓库 6 人，第二个仓库 4 人）、$\langle 7,3 \rangle$、$\langle 6,3 \rangle$、$\langle 10,0 \rangle$、$\langle 9,0 \rangle$、$\langle 8,0 \rangle$、$\langle 7,0 \rangle$、$\langle 6,0 \rangle$、$\langle 0,0 \rangle$、 $\langle 0,3 \rangle$、$\langle 0,4 \rangle$、$\langle 0,5 \rangle$ 和 $\langle 0,6 \rangle$。让我们将它们表示为坐标平面 (图 1) 上的点。

各种操作模式的应用顺序并不重要。例如，如果工头先派六名工人到第二个仓库卸货，然后再派整个团队到第一个仓库，那么工作就会在同样的 $1\frac{11}{15}$ 小时内完成。因此，我们可以假设加载的组织方式如下：首先$t_1$小时，应用模式$\alpha_1$，然后$t_2$小时 - 模式$\alpha_2$，依此类推。在这种情况下，$t_i$可能等于0，即可以不使用模式$\alpha_i$。例如，当步骤1中的远距离加载时，只有$t_4 = \frac{4}{10}$和$t_{13} = \frac{8}{6}$不等于0。

我们忽略了从一个仓库到另一个仓库的转换时间。那么总加载时间$t$将等于

$$t = t_1 + t_2 + \dots + t_{12} + t_{13}. \tag{1}$$

3. 数学家解决了一个问题

首先，数学家要求完成一项任务：他将限制自己寻找集合$A_1$，因为任何集合$A_t$都会准备一个集合$A_1$，其准备系数为$t$和准备中心 - 坐标原点。

让我们证明集合$A_1$是某些点$\alpha_1, \alpha_2, \ldots, \alpha_{13}$的凸包。

证明如果集合 $M$ 是凸的，则集合 $tM$（即点集 $t\beta$，其中 $\beta \in M$）也是凸的。

定义。如果还存在非负数$t_1, t_2, \dots, t_n$，例如$t_1 + t_2 + \dots + t_n = 1$和$\beta = t_1\beta_1 + t_2\beta_2 + \dots + t_n\beta_n$，则点$\beta$称为点$\beta_1, \beta_2, \dots, \beta_n$的凸组合。

定理。凸包集 $M$ 由 $M$ 中所有可能的凸点组合组成。

证明。让我们用 $Q$ 表示来自 $M$ 的点的凸组合集。如果$\gamma$和$\delta$是任意点，则$t\gamma + (1-t)\delta$形式的点集（其中$0 \leq t \leq 1$）与端点为$\gamma$、$\delta$的线段重合。从这里很容易推断出 $Q$ 是凸集（这样做！）。另外，非常/不，$M \subset Q$。因此，巧合$M \subset Q$。现在让我们通过对$n$的归纳证明，$M$中的点的任何凸组合$t_1\beta_1 + t_2\beta_2 + \dots + t_n\beta_n(t_1 + t_2 + \dots + t_n = 1)$都接受重合$M$。这意味着 $Q \subset \text{conv } M$。对于$n = 1$，相应的语句采用以下形式：if $\beta \in M$，则$\beta \in \text{conv } M$。根据凸包的定义这是正确的。现在让来自$M$的点的所有凸组合$n$接受重合$M$。让我们证明凸组合$\delta = t_1\beta_1 + t_2\beta_2 + \dots + t_n\beta_n + t_{n+1}\beta_{n+1}$（其中$\beta_1, \beta_2, \dots, \beta_n, \beta_{n+1}$是来自$M$的点）也采用$M$：

$$\delta = (1 - t_{n+1}) \left[ \frac{t_1}{1 - t_{n+1}}\beta_1 + \frac{t_2}{1 - t_{n+1}}\beta_2 + \dots + \frac{t_n}{1 - t_{n+1}}\beta_n \right] + t_{n+1}\beta_{n+1}.$$

从 $t_1 + t_2 + \dots + t_n + t_{n+1} = 1$ 可以得出

$$\frac{t_1}{1 - t_{n+1}} + \frac{t_2}{1 - t_{n+1}} + \dots + \frac{t_n}{1 - t_{n+1}} = 1.$$

由归纳假设

$$\eta = \frac{t_1}{1 - t_{n+1}}\beta_1 + \frac{t_2}{1 - t_{n+1}}\beta_2 + \dots + \frac{t_n}{1 - t_{n+1}}\beta_n \in \text{conv } M.$$

从 (4) 可知，点 $\delta$ 位于端点 $\eta$ 和 $\beta_{n+1}$ 的线段上。由于$\beta_{n+1} \in M \subset \text{conv } M$和卷积$M$是凸集，我们得到$\delta \in \text{conv } M$。定理已被证明。

因此，卷积$M$中的每个点都是$M$中某个端点的凸组合。如果集合$M$是有限的，那么我们可以假设来自$M$的每个点都是来自$M$的所有点的凸组合。

事实证明，对于每个点$\beta$平面上的任意集合$M$，重合集$M$可以作为$M$中三个点$\beta_1, \beta_2, \beta_3$的凸组合获得（当然，对于不同的$\beta$，一般来说，点$\beta_1, \beta_2, \beta_3$是不同的）。这个定理，或者更确切地说，它的 $n$ 维类似物，被称为*卡梅多里定理*。尝试证明一下！

根据定义，可达性集$A_1$由所有可能的点$t_1\alpha_1 + t_2\alpha_2 + \dots + t_{13}\alpha_{13}$组成，其中$t_1 + t_2 + \dots + t_{13} = 1$（第2项）。换句话说，$A_1$由点$\alpha_1, \alpha_2, \dots, \alpha_{13}$所有可能的凸组合组成。根据已证明的定理

$$A_1 = \text{conv} \{ \alpha_1, \alpha_2, \dots, \alpha_{13} \}.$$
