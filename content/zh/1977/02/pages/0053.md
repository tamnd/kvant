图 1.

同时，三个力作用在冰球上，即，与冰球相互作用的力完全相同。不能谈论任何其他力——推、投掷、运动、惯性等，不幸的是，申请人经常指出这些力。

由于所有相互作用都是固定的（不随时间变化），因此出现了两种解决方法 - 动态方法和能量方法。让我们用几种方法来解决这个问题。

1. 动态方法。首先我们画一个示意图（图1）。让我们选择一个坐标系 (XOY)，记下冰球的初始 ($x_0=0, v_0$) 和最终 ($x=|\vec{s}|, v=0$) 状态参数以及作用在其上的力 ($mg, \vec{N}, \vec{F}_{\text{tp}}$)。当然，Tsaibu 将被视为一个重要点。

让我们在 OX 和 OY 轴上的投影中写出位移模型 $|\vec{s}|$ 的已知表达式：

$$|\vec{s}| = x = \frac{v_0^2}{2|\vec{a}|}$$

和牛顿第二定律：

$$|\vec{a}| = \frac{|\vec{F}_{\text{tp}}|}{m}, |\vec{N}| - m|\vec{g}| = 0.$$

考虑耦合方程

$$|\vec{F}_{\text{tp}}| = \mu |\vec{N}|$$

我们得到

$$|\vec{s}| = x = \frac{v_0^2}{2|\vec{a}|} = \frac{v_0^2 m}{2|\vec{F}_{\text{tp}}|} = \frac{v_0^2}{2\mu |\vec{g}|}.$$

二.能量法。让我们考虑封闭系统冰球-地球-冰。滑动摩擦力作用在该系统内部。在这种情况下，系统机械能的变化等于摩擦力的功：

$$(K + \Pi) - (K_0 + \Pi_0) = A_{\text{tp}}.$$

相对于静止的地球（和冰），系统初始时刻的动能等于冰球的动能：

$$K_0 = \frac{mv_0^2}{2},$$

在最后一刻它等于零：

$$K = 0.$$

冰球与地球之间相互作用的势能自然不存在于地球表面，因此

$$\Pi_0 = \Pi = 0.$$

摩擦力做功

$$A_{\text{tp}} = |\vec{F}_{\text{tp}}| |\vec{s}| \cos \alpha = -\mu m |\vec{g}| |\vec{s}|,$$

从$\alpha = 180^\circ$开始。

然后最后

$$0 - \frac{mv_0^2}{2} = -\mu m |\vec{g}| |\vec{s}|, \text{ и } |\vec{s}| = \frac{v_0^2}{2\mu |\vec{g}|}.$$

如果冰不包含在物体之间的相互作用系统中，那么它将不再是封闭的。支撑反作用力和摩擦力是该系统的外力，它们的功等于系统机械能的变化。由于力$\vec{N}$与位移$s$之间的角度等于$90^\circ$，因此该力所做的功为零，与之前一样

$$K - K_0 = A_{\text{tp}}$$

（你已经说过了$\Pi = \Pi_0 = 0$）。

如果我们只考虑冰球，那么作用在冰球上的所有力都将是外部的。根据动能定理，这些力所做的功等于冰球动能的变化。重力做功与支撑反作用力做功一样为零，因此机械能变化的表达式与前面的类似。
