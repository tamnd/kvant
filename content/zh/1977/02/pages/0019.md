同意，如果允许您在每个单元格中放置不超过一只野兔，那么您将无法在 5 个单元格中放置 6 只野兔，并且一般来说，对于任何自然数 n，您将无法在 n 个单元格中放置 n + 1 只野兔。我们可以换种说法：如果 n 个单元格包含 n + 1 只或更多野兔，那么我们将找到一个包含至少两只野兔的单元格。

让我们用符号 p₁，...，pₙ+1 表示野兔，用 q₁，...，qₙ 表示细胞。那么将野兔放入单元格中的每种方法都可以被视为集合 P = {p₁, ..., pₙ+1} 到集合 Q = {q₁, ..., qₙ} 的某种映射 (图 1)：野兔 pᵢ ∈ P 与该野兔所在的单元格 qᵢ ∈ Q 相关联（作为其“图像”）。因此，上述关于笼中野兔的陈述具有以下数学含义：对于包含 n + 1 个元素的集合 P 到包含 n 个元素的集合 Q 的任何映射，集合 P 中存在两个具有相同图像的元素。

该陈述称为狄利克雷原理*)。使用数学归纳法很容易证明。根据不成文的传统，世界各地的数学家在考虑狄利克雷原理时，不使用集合和映射的语言，也不使用任何其他对象（即兔子和细胞）来解释其含义。

尽管狄利克雷原理简单而伟大，但它经常用于证明定理和解决问题。
