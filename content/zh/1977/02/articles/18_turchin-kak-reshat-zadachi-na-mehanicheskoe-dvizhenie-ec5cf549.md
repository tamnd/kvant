如何解决机械运动问题

大家知道，力学的主要任务就是随时确定身体的位置。要解决这个问题，即要找到所选报告系统中主体的坐标，需要知道主体的初始坐标和变量。通过知道物体在每个时刻的初始速度和加速度就可以找到变量。如果作用在物体上的力已知，并且这些力不随时间变化，则物体的加速度直接由牛顿第二定律（迪亚马纳基本定律）确定。因此，这种解决机械运动问题的方法称为钻石法。

当作用在物体上的力不恒定时，牛顿第二定律的应用会遇到巨大的数学困难。在这种情况下，使用守恒定律是很方便的，尤其是能量和动量守恒定律，这些定律适用于封闭（孤立）的物体系统。在这种情况下，能量守恒定律的具体类型取决于系统主体之间作用的力。

例如，如果这些是重力或弹力，则系统的总机械能保持不变。在存在摩擦的情况下，机械能不守恒，其变化量等于摩擦力的平衡。结果，系统的内能增加，因此总能量当然不会改变。或者这样一个例子 - 在库仑力的影响下电场中运动的带电部分。在这种情况下，机械能和电能的总和是守恒的。

如果系统不是孤立的，那么能量和动量可能不守恒，能量的变化等于作用在系统上的外力的等值。

因此，在解决机械运动问题时，不仅可以使用钻石法，还可以使用基于能量守恒定律和变化定律的能量法。选择哪种解决方法取决于系统中包含的物体（或物体和场）之间的相互作用类型，以及给定问题的条件。

现在我们来看几个问题。

任务1.被棍子击中后，冰球获得速度$v_0$并开始在冰面上滑动。确定冰球在停止前行驶的距离。我们不考虑空气阻力，保持力恒定，冰球在冰上的时间系数等于μ。

当冰球移动时，它与地球和冰相互作用。由于我们对冰球沿着地球表面的运动感兴趣，因此在这个问题的条件下很自然地考虑地球和冰是静止的。

冰球与其他天体（例如，与月亮、太阳等）的基本存在。不过，我们不会过多考虑它们。

让我们分析冰球与地球和冰的相互作用。冰球和地球之间存在花岗岩相互作用，其衡量标准是冰球的引力$mg$（用冰球的质量$m$表示）。用冰代替冰球可以用支撑反作用力（弹力）$\vec{N}$和滑动摩擦力$\vec{F}_{\text{тр}}$来表征。因此

同时，三个力作用在冰球上，即，与冰球相互作用的力完全相同。不能谈论任何其他力——推、投掷、运动、惯性等，不幸的是，申请人经常指出这些力。

由于所有相互作用都是固定的（不随时间变化），因此出现了两种解决方法 - 动态方法和能量方法。让我们用几种方法来解决这个问题。

1. 动态方法。首先我们画一个示意图（图1）。让我们选择一个坐标系 (XOY)，记下冰球的初始 ($x_0=0, v_0$) 和最终 ($x=|\vec{s}|, v=0$) 状态参数以及作用在其上的力 ($mg, \vec{N}, \vec{F}_{\text{tp}}$)。当然，Tsaibu 将被视为一个重要点。

让我们在 OX 和 OY 轴上的投影中写出位移模型 $|\vec{s}|$ 的已知表达式：

$$|\vec{s}| = x = \frac{v_0^2}{2|\vec{a}|}$$

和牛顿第二定律：

$$|\vec{a}| = \frac{|\vec{F}_{\text{tp}}|}{m}, |\vec{N}| - m|\vec{g}| = 0.$$

考虑耦合方程

$$|\vec{F}_{\text{tp}}| = \mu |\vec{N}|$$

我们得到

$$|\vec{s}| = x = \frac{v_0^2}{2|\vec{a}|} = \frac{v_0^2 m}{2|\vec{F}_{\text{tp}}|} = \frac{v_0^2}{2\mu |\vec{g}|}.$$

二.能量法。让我们考虑封闭系统冰球-地球-冰。滑动摩擦力作用在该系统内部。在这种情况下，系统机械能的变化等于摩擦力的功：

$$(K + \Pi) - (K_0 + \Pi_0) = A_{\text{tp}}.$$

相对于静止的地球（和冰），系统初始时刻的动能等于冰球的动能：

$$K_0 = \frac{mv_0^2}{2},$$

在最后一刻它等于零：

$$K = 0.$$

冰球与地球之间相互作用的势能自然不存在于地球表面，因此

$$\Pi_0 = \Pi = 0.$$

摩擦力做功

$$A_{\text{tp}} = |\vec{F}_{\text{tp}}| |\vec{s}| \cos \alpha = -\mu m |\vec{g}| |\vec{s}|,$$

从$\alpha = 180^\circ$开始。

然后最后

$$0 - \frac{mv_0^2}{2} = -\mu m |\vec{g}| |\vec{s}|, \text{ и } |\vec{s}| = \frac{v_0^2}{2\mu |\vec{g}|}.$$

如果冰不包含在物体之间的相互作用系统中，那么它将不再是封闭的。支撑反作用力和摩擦力是该系统的外力，它们的功等于系统机械能的变化。由于力$\vec{N}$与位移$s$之间的角度等于$90^\circ$，因此该力所做的功为零，与之前一样

$$K - K_0 = A_{\text{tp}}$$

（你已经说过了$\Pi = \Pi_0 = 0$）。

如果我们只考虑冰球，那么作用在冰球上的所有力都将是外部的。根据动能定理，这些力所做的功等于冰球动能的变化。重力做功与支撑反作用力做功一样为零，因此机械能变化的表达式与前面的类似。
