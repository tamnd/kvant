我会满足条件
$$0 = T - T \in D(f_1),$$
这显然不是真的。

我们假设函数 $f_2(x)$ 是周期函数 $T$。取一个整数 $n$ 使得
$$x^* = \frac{1}{2} + nT > 1.$$
然后 $x^* \in D(f_2)$，根据性质 I
$$x^* - nT = \frac{1}{2} \in D(f_2),$$
这是不正确的。

功能 $f_3(x)$ 定义在段上 $[-1,1]$ 因此，由于属性 I，它不是周期性的。

示例 2. 证明函数的非周期性
$$f_1(x) = \frac{3x^2 - x + 2}{x^2 + x + 1}, \quad f_2(x) = \cos x + \cos(x\sqrt{2}) + \cos(x\sqrt{3}),$$
$$f_3(x) = 2x - \cos x.$$
方程
$$\frac{3x^2 - x + 2}{x^2 + x + 1} = a$$
（很容易看出，其中$a \in \mathbb{R}$可以有不超过两个根。因此，函数$f_1(x)$在不超过两个点处取每个值，因此，根据属性II，它不是周期性的。

$x = 0$ 处的函数 $f_2(x)$ 取值为 3。求解方程
$$\cos x + \cos(x\sqrt{2}) + \cos(x\sqrt{3}) = 3.$$
(10)

由于$|\cos t| \leq 1$，则方程(11)等价于系统
$$\begin{cases} \cos x = 1, \\ \cos(x\sqrt{2}) = 1, \\ \cos(x\sqrt{3}) = 1. \end{cases}$$

但是系统的第一个方程在$x = 2k\pi$处满足，第二个在$x = \frac{2n\pi}{\sqrt{2}}(k, n \in \mathbb{Z})$处满足，因为很容易看出这两个值系列$x$只有一个共同点$x = 0$，这显然满足系统的第三个方程。因此，方程(10)只有一个根。换句话说，函数 $f_2(x)$ 仅取值 3 一次，并且根据属性 II，它不是周期性的。

我们来计算导数函数$f_3(x)$：
$$f_3'(x) = 2 + \sin x.$$
我们看到对于任何$x \in \mathbb{R}$都有$f_3'(x) > 0$，因此，函数$f_3(x)$在整个数轴上递增；根据性质 II，它不是周期性的。

示例 3. 判断函数是否是周期性的
$$f(x) = \{x\} + \sin x.$$
为了解决这个问题，我们使用与属性III关联的路径。我们假设 $f(x)$ 是一个周期为 $T > 0$ 的周期函数。那么对于 $x$ 的任意值，等式
$$\{x + T\} + \sin(x + T) = \{x\} + \sin x.$$
特别是，对于$x = 0$，没有$\{T\} + \sin T = 0,$ (11)，对于$x = -T$，我们得到
$$0 = \{-T\} - \sin T.$$ (12)
将等式（11）和（12）相加，我们得到等式
$$\{T\} + \{-T\} = 0.$$
回想一下，任何数字 $x$ 的小数部分 $\{x\}$ 都是非负数。因此，只有当$\{T\} = \{-T\} = 0$（即$T$是整数）时，最后一个相等才可能。此外，如果$\{T\} = 0$，则根据等式（11）得出$\sin T = 0$，即$T = k\pi$，$k \in \mathbb{Z}$。同时，任何整数$k \neq 0$的数$k\pi$都不是整数，因为$\pi$是无理数，因此方程（11）和（12）只有一个公共根$T = 0$。因此，函数 $f(x)$ 不是周期性的。

示例 4. 证明该函数是非周期性的
$$f(x) = 2x \cos(x^2).$$
我们假设函数 $f(x)$ - 定期和 $T > 0$ - 她的经期。因为 $f(x)$ 定义在整个数轴上并且 $|f(x)| \leq 2T$ 在 $x \in [0, T]$，则根据性质 IV 对于任意 $x \in \mathbb{R}$
$$|f(x)| = |2x \cos(x^2)| \leq 2T.$$
然而，这种不等式并不成立。
