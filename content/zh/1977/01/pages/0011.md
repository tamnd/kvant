⟦folio 9⟧

微弱而遥远的星云 M.83 只是仙女座大型河外星云 M.31 的“后方”景象。但这个假设消失了，因为很快天文学中可用的距离就比到 M.83 和 M.31 的距离之和要大得多。这意味着，如果一条线是闭合的并且具有有限长度，那么该长度要大得多。

与平面测量一样，在球体上问题的解决方案通常归结为一系列三角形的距离。球形三角形由三个顶点组成，这三个顶点通过最短的弧线成对连接 - 这些是它的边。但在球体上也存在双极，例如由两条经线连接的两个极。

让我们证明球面三角形的内角和总是大于 π*)。为此，如果已知球面三角形 ABC 的角度 Å、B、C（以弧度为单位）的值，我们可以计算球面三角形 ABC 的面积 S_{ABC}。

为了清楚起见，我们将构建绘图，使 A 点落入已验证的球体条带 (图 7) 中。我们先计算一下比边的面积S_{AA'}，如果将边AB和AC延伸到与A点相反的A'点，就可以得到这个面积。令整个球面的面积等于S。显然，S_{AA'} = S·Å/2π（因为角度为2π的比边，非常/不，面积等于S - 这是整个球面的面积）球体）。同样，继续角 B 的边，我们得到面积为 S_{BB'} = S·К/2π 的对角线，角 C 将导致面积为 S_{CC'} = S·К/2π 的对角线。在相反方向上继续相同角度的边，我们获得相同区域的附加对角线。这些双臂巨龙将覆盖球体的哪一部分？很明显，它们将覆盖整个球体，并且三角形 ABC 和 A'B'C' 将被覆盖三次（为了清楚起见，请在平面上对三角形 ABC 进行此构造！）。所以，

*) 两条相交曲线之间的大角（或简称为角度）是在曲线交点处绘制的这些曲线的切线之间的角度。

$$\frac{2S}{2\pi} \hat{A} + \frac{2S}{2\pi} \hat{B} + \frac{2S}{2\pi} \hat{C} = S + 4S_{ABC};$$

从这里

$$S_{ABC} = \frac{S}{4\pi} (\hat{A} + \hat{B} + \hat{C} - \pi).$$

三角形的面积原来与所谓的“球余量”成正比

$$\varepsilon = \hat{A} + \hat{B} + \hat{C} - \pi.$$

注意，S和S_{ABC}都是正数，这意味着ε的余量是正数，换句话说，球面三角形的内角和总是大于π。

有趣的是，在罗巴切夫斯基平面上，三角形的内角和总是小于π，而其面积与“缺陷”成正比δ=π—(Å+B+C)。

在球体上的几何中，三角形等号的相同符号在多角几何中是有效的（在一条边和两个角上，在两侧和它们之间的角上，在这些边上），但还有一个：在三个角上 - 球体上没有相似的三角形！ （证据与测算法中的证据相同。）

练习

1（留着很长的胡子）。给定一个尺寸为 30×12×12 的直角平行六面体。找到点 A 和 A' 之间沿其表面的最短路径，点 A 和 A' 相对于平行六面体的中心对称位于中间垂直面的正方形面上（为清楚起见，我们将 30x12 面视为地板和天花板），点 A - 位于地板上方的高度 1，A' - 位于地板下方的高度 1。相信很多人会大喊：“最短路径的长度是 42！”然而，事实并非如此——有一条明显更短的路径！找到他。

2. 克拉斯诺尔斯克和莫斯科几乎位于同一纬线（北纬 56°）。知道它们的经度（93°和38°）和地球半径（6370公里），找出最短路径比沿平行线的路径短多少。

3. 证明：

a) 球面 n 边形 A1A2...An 的角度 Å1 + Å2 + ... + Ån 之和始终大于 (n-2)π；

b) 球形n边形A1A2...An的面积与多余的ε = Å1 + Å2 + ... + Ån - (n-2)π成正比。

4. 证明球面三角形的边长之和大于平面上三角形ABC的长度！

5. 证明球面三角形三边相等的检验。
