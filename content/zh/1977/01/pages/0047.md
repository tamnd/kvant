五、如果周期函数可微，则其乘积是具有相同周期的周期函数。

这个属性证明了这一点。首先，根据任意周期函数的定义，如果周期为 T 的周期函数 f(x) 在某个点 x 处具有任意 f'(x)，那么它在点 x + T 处也具有任意 f'(x)。换句话说，如果 x ∈ D(f')，则 x + T ∈ D(f')。仍有待确保

$$f'(x + T) = f'(x)$$

对于 x ∈ D(f')。让我们用 g(x) 表示函数 f(x + T)，并将其视为具有“内部”函数 x + T 和“外部”函数 f(x) 的复杂函数。然后，根据任意复函数的公式，我们将有

$$g'(x) = f'(x + T) \cdot (x + T)' = f'(x + T).$$

但由于周期性 g(x) = f(x)，所以

$$g'(x) = f'(x).$$

从等式（5）和（6）得出等式（4）。因此，f'(x) 是周期为 T 的周期函数。

六．如果 f(x) 是在整个数轴上定义的周期函数并从常数中省略，则当 x → 0 时，函数 f\left(\frac{1}{x}\right) 没有极限。

该属性可以从几个图形考虑中获得。让x趋于零，同时保持正值；那么表达式 1/x 无限制地增加。由于周期函数 f 随着自变量的增加而“振荡”，因此函数 g(x) = f\left(\frac{1}{x}\right) 在点 x = 0 附近“振荡”，因此当 x → 0 时没有极限。

我们将通过矛盾对我们的财产的表述进行严格的证明。我们假设

$$\lim_{x \to 0} g(x) = A.$$

首先，让我们确保函数 g(x) 在至少一个点 x > 0 处取与 A 不同的值。事实上，如果对于任何 x > 0，g(x) = A，则 f(x) = g\left(\frac{1}{x}\right) = A

对于所有 x > 0。但是从函数 f(x) 的周期性可以看出，f(x) 在所有数轴上都是常数，这与条件相矛盾。

因此，存在一个点 x₀ > 0 使得

$$g(x₀) = \alpha \neq A.$$
