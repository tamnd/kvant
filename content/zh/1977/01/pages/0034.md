在 图 10 处，可以用 图 12 所示的等效电路代替。在这种情况下 (图 12, a)
$$R_{AB} = R_{BC} = R + R_1 \text{ и } R_{AC} = 2R.$$

图 12.

我们将几个并联或串联的电阻依次替换为一个电阻，即可找到电阻$R_{A'B'}$和$R_{A'C'}$。对于参与者$A'B'$（图13）
$$R_{A'B'} = 2r + R^{***} = 2r + \frac{rR^{**}}{r + R^{**}} =$$
$$= 2r + \frac{r(R + R^*)}{r + R + R^*} = 2r + r \frac{R^2 + 2R_1R + R_1r + Rr}{(r + R)^2 + 2(r + R)R_1}.$$

在计算电阻$R_{A'C'}$时，我们考虑到点$O$和$E$（图14）由于电路对称，具有相同的电位，因此可以简单地排除电阻$R_1$。结果我们得到
$$R_{A'C'} = 2r + R' = 2r + \frac{2rR}{r + R}.$$
从$R_{AC} = R_{A'C'}$开始，
$$2R = 2r + \frac{2rR}{r + R},$$
在哪里
$$R = \frac{1}{2}r(1 + \sqrt{5}).$$
