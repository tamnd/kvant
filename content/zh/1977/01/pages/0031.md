1）。令 $ab$ 为偶数。

a) 如果$a$和$b$具有不同的奇偶性（一个是偶数，另一个不是偶数），则$a^2 + b^2 = 2N + 1$。然后我们放入$c = N$，$d = N + 1$。我们得到
$$d^2 - c^2 = (d + c)(d - c) = 2N + 1 = a^2 + b^2.$$

6) 如果$a$和$b$都是偶数，则$a^2 + b^2 = 4N$。在这种情况下，我们放置$d = N + 1$，$c = N - 1$。然后
$$d^2 - c^2 = (d + c)(d - c) = 2N \cdot 2 = a^2 + b^2.$$

2）。令 $ab$ 为奇数：$ab = 2n + 1$。那么$a$和$b$都是奇数，它们的和是偶数：$a + b = 2m$。我们有：
$$a^2 + b^2 = (a + b)^2 - 2ab = 4m^2 - 4n - 2,$$
也就是说，$a^2 + b^2$ 能被 2 整除，但不能被 4 整除。因此，$a^2 + b^2 \neq d^2 - c^2$ 不能被任何自然数 $c$ 和 $d$ 整除：如果 $c$ 和 $d$ 具有相同的奇偶性（均为偶数或均为奇数），则 $d^2 - c^2 = (d + c)(d - c)$ 能被 4 整除，并且如果$d$和$c$具有不同的奇偶性，那么$d^2 - c^2$不能被2整除。

M·杰弗

我们的解决方案将表明，对于具有公共顶点的规则 $n$ 边形，以及通常对于类似的内接 $n$ 边形 $OAB \dots Z$ 和 $OA_1B_1 \dots Z_1$，类似的陈述是正确的。

我们来描述一下两者 $n$- 圆的边形。让它们相交于点 $O$ 和 $L$ (图 3）。如果是直的 $l$，经过 $L$, 匀速旋转 $L$ 与角速度 $\omega$，然后是第二个交点 $M$ 和 $M_1$ 直接的 $l$ 两个圆都以角速度均匀地沿其圆移动 $2\omega$ （gradle值不同 $\overline{OM}$ 和 $\overline{OM}_1$ 两倍度数 $\widehat{MLO} = \widehat{M_1LO}$）。所以重点是 $M_1$ 越过高峰 $O$, $A_1$, $B_1$, ..., $Z_1$ 多边形 $OA_1B_1 \dots Z_1$ 就在那些时刻 $M$ 分别经过顶点 $O$, $A$, $B$, ..., $Z$ 多边形 $OAB \dots Z$。由此可见，一切都是直的 $AA_1$, $BB_1$, ..., $ZZ_1$ 相交于一点 - 一点 $L$，外接圆的第二个交点 $(рис. 4)$.

N·瓦西里耶夫

在问题陈述中，多边形 $OA_1B_1 \dots Z_1$ 的每个顶点 $O$、$A_1$、$B_1$、...、$Z_1$ 的速度准确地给出了 $M$ 分别经过顶点 $O$、$A$、$B$、...、 $Z$多边形$OAB \dots Z$。从这里可以清楚地看出，所有线 $AA_1$、$BB_1$、...、$ZZ_1$ 都相交于一点 - 点 $L$，这是围绕 $(рис. 4)$ 外接圆的第二个交点。

该条件需要找到一个相对坐标系（例如，与马戏表演场相关联）。该速度通常称为绝对速度。

根据该条件，要求求出当它们都在经过圆心的直线上时，在点：a)$A_1$和$A_2$处，其速度大小相对于它们之一所关联的运动坐标系的相对速度； b) $A_1$ 和$B_2$； c) $B_1$和$B_2$； e) $B_1$ 和 $A_2$ (图 5)。
