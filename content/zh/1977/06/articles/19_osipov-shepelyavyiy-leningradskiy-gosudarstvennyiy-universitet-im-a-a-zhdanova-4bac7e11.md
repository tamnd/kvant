1976年

列宁格勒
州立大学
他们。 A·A·日丹诺娃

列宁格勒国立大学详细描述于 «Kvant» 1975 年第 6 期和 1976 年第 4 期。本期我们介绍 1976 年列宁格勒国立大学各院系数学笔试入学考试的选择。

数学与力学学院和应用数学学院 - 控制过程

1. 一束$p$信息（$6um$是信息量的单位）首先被输入到控制装置中，然后这些信息由控制装置按照给定的程序进行处理，然后将得到的新信息输出到打印装置。如果已知信息处理速度等于$c$束/秒且小于信息输入和输出速度之和的3倍，并且输入和输出处的信息量相同，则以处理和发布信息为例，确定控制论装置运行的最短可能持续时间。

2. 解决不平等问题
$$\sqrt{2(x - \sqrt{x^2 - a^2})} > \frac{x + a}{5\sqrt{x - a}}$$
对于参数$a$的所有值。

3. 解方程
$$\sin x + \sqrt{\sin x + \sin 2x - \cos x} = \cos x.$$

4. 给定一个等边三角形 $ABC$，边长为 $a$。在边$AB$、$BC$和$CA$上，等长的线段$AA', BB'$和$CC'$沿$AB$、$BC$和$CA$方向布置，使得三角形$A'B'C'$的面积比三角形面积小$k$倍$ABC$。求指定线段的长度。

5. 给定一个半径为$R$、中心在点$O$、直径为$AB$的圆。通过位于 $O$ 和 $A$ 之间的点 $P$，绘制垂直于直径 $AB$ 的弦 $CD$。已知，绕直径旋转半径$OC$得到的表面积与圆弧$AC$旋转得到的球段之和，等于圆弧$CB$旋转得到的球段面积。找到$|OP|$。

物理学院

1. 月球车接近悬崖，初始时刻速度为$v$，加速度为$a$（$a \geqslant 0$），到体积的距离为$S$（沿月球车移动的直线计算）。从初始时刻算起，什么时间之后，地球必须发出打开刹车的命令（在这种情况下，小车的加速度等于$a_1$），以便小车停在体积的边缘？地球到月球的距离是$L$，无线电信号的传播速度是$c$。

2. 在正四边形对$ABCDH$中，底边的长度为$a$，边长$b$，平行于底$AC$和边$DH$的对角线画一个平面。求该平面的首要性所产生的图形的最大可能面积。

3. 求方程的根
$$2(\sin x - \cos x + 1) \times
\times \left(2\cos^2 \frac{x}{2} + \sin x \cdot \mathrm{tg} x - 1\right) +
\sin \frac{x}{2} \cdot \cos \frac{x}{2} = 0,$$
位于区间$|x| < 10$。

4. 解决不平等问题
$$\log_{x+2}(x^2 - 2x + p) \geqslant 2$$
对于参数$p$的所有值。

5. 求解方程组
$$\begin{cases}
x + \frac{1}{y} = 1, \\
xy^2 + \frac{1}{x^2y} = 1 + \frac{y}{x}.
\end{cases}$$

化学、心理和经济能力

1. 在使用原电池的最初时刻，内部电极之一含有20e的纯钌。因此，与第二天的增长百分比相比，第一天的恢复率减少了 5%。如果已知第二天纯芦丁的量为 1.648 e，则确定第一天纯芦丁增加的百分比。

2. 解决不平等问题
$$\log_a(x - 1) + \log_a x > 2.$$
3. 解方程
$$\frac{\sin 2x}{2} = \frac{\sin^3 x + 3\cos^3 x}{\sin x + 3\cos x}.$$

4. 给定一个三角形 $ABC$，边长为 $|BC| = a$、$|AC| = b$、$|AB| = c$。通过位于边$AB$上的点$D$，绘制与边$BC$和$AC$平行的直线； $E$和$F$是这些线与边$AC$和$BC$的交点。已知$|DE| = |DF|$。找到$|AD|$。
