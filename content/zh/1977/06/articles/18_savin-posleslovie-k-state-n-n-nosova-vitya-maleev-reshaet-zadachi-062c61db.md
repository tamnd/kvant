后果
自从尼古拉·诺索夫写下了精彩的诗《维蒂亚·马列夫在学校和家里》以来，学校的数学教学发生了很大的变化。现在这门学科叫数学，而不是论证，内容也发生了变化。现在的三年级或四年级学生将不再为坚果问题而苦恼。他将用“x”表示女孩拥有的坚果数量，然后男孩将拥有“2x”坚果。因此，总共有“3x”个坚果，已知有 120 个。这意味着 3x = 120，因此 x = 40，2x = 80。解决问题。

至于“锯子和斧子”的问题，万能的“x”也可以来救援。让我们回顾一下简化后问题的最终形式：
“12把斧子和3把锯子要84卢布，12把斧子和5把锯子要100卢布。”让我们用“x”表示锯子的成本，那么根据第一个条件，12把斧子的成本为84 - 3x卢布，一把斧头（84 - 3x）：12卢布。现在让我们写出第二个条件：
$$12 \cdot (84 - 3x) : 12 + 5x = 100$$
或者
$$84 - 3x + 5x = 100,$$
由此 x = 8（卢布）。再次，标准方法通过 SEL 来救援，无需太多思考即可实现目标。

然而，你不觉得瓦尼亚·帕霍莫夫对城市的解决方案更漂亮吗？她以简单而优雅的逻辑推理吸引了我们，最终解决了问题。尝试不仅以标准方式（使用方程）解决问题，而且还可以简单地使用逻辑推理。请告诉我们 3-5 年级教科书中的哪些问题使用逻辑比使用方程更容易解​​决。

处于平衡状态的液体和与其碰撞的蒸气不断地交换其分子。在给定时间内交换的分子数量是多少？在给定时间内有多少分子离开液体并返回？

平均每单位时间内有相同数量的分子 $z_0$ 落入单位表面积，并且 $z$ 分子进入其中。当$z_0 = z$时，液体和蒸气之间发生平衡。

计算 $z_0$ 的值是很困难的，因为我们不确切地知道蒸汽和液体分子之间的吸引力的值。但计算$z$的值非常简单。事实上，到达液体表面的每个蒸气分子都会渗透到液体内部；因此，$z$等于单位时间内液体单位表面积下落的分子数。我们来找出这个数字。

回想一下，比率 $\frac{N}{V}$ 决定了给定温度下蒸汽的压力 $p$：

$$p = \frac{N}{V} kT. \tag{2}$$

若蒸汽饱和，则根据式(1)，$\frac{N}{V} = \frac{2z_0}{|\bar{v}_x|}$，则蒸汽压力等于

$$p_H = \frac{2z_0 k T}{|\bar{v}_x|}. \tag{3}$$

因此，我们得出的结论是，饱和蒸汽的实际压力并不取决于它所占据的体积，并且在给定温度下完全定义为给定液体的特征值。

饱和蒸气压与体积的独立性似乎与气体状态方程（2）相矛盾，从该方程可以看出，在恒定温度$T$下，气体压力与其所占据的体积$V$成反比。也许气体状态方程不适用于饱和蒸汽？

实际上，并不矛盾，式(2)也不适用。

从方程（2）可知，只要$N$恒定，即气体质量不变，气体的压力$p$与其体积成反比。但对于饱和蒸汽来说，这个条件不满足。当饱和蒸汽的体积变化时，其质量也会变化。事实上，如果你改变饱和蒸汽，使其体积从值$V$减小到某个值$V_1$，则比率$N/V_1$将立即减小。那么从式（1）可以看出，从气态返回液态的分子数$z$会减少，并且会超过$z_0$数

“蒸发”分子。结果，蒸气分子的数量$N$开始减少。当它减少到这样一个值$N_1$时

$$\frac{N_1}{V_1} = \frac{N}{V},$$

平衡将会恢复。但随后，根据式（2），蒸汽的压力$p$也将恢复。这就是实验中发生的情况。

$$\frac{N_1}{V_1} = \frac{N}{V},$$

如何解释如此巨大的差异？

让我们再次讨论气体的状态方程

$$p = \frac{N}{V} kT.$$

从这个方程可以清楚地看出，当分子密度$N/V$不随温度变化时，则蒸气压与温度$T$成正比。实验中观察到的饱和蒸气压$p$对温度的“更陡峭”依赖性只能通过以下事实来解释：随着温度的升高，计算和比率$\frac{N}{V}$，即蒸气密度的计算。

为什么温度升高会导致饱和蒸汽密度增加？因为随着液体温度的升高，其动能大于蒸发功的分子比例急剧回升。这意味着随着温度的升高，从液体中蒸发的 $z_0$ 分子数量急剧增加。这反过来又导致蒸气分子密度$\frac{N}{V}$及其压力$p$增加。

诚然，随着温度升高，蒸气分子的速度也会增加，即值$|\bar{v}_x|$增加，但与密度$\frac{N}{V}$的增加相比，这种增加很小。

饱和蒸气压随温度升高而升高，主要是由于液体转化为蒸汽的量增加。

显然，如果密闭容器中的液体完全蒸发，则蒸气变得不饱和，并且随着进一步加热，其压力$p$与温度$T$成比例增加。饱和水蒸气可转化为饱和水蒸气。为此，必须对其进行冷却。随着温度升高，蒸气压将与温度成比例下降，直到开始冷凝 - 容器壁上会出现露水形式的小液滴。这意味着蒸汽变得饱和。达到饱和的温度称为露点。

由于$O$是相互垂直的线$AB$和$CD$的交点，因此它位于以线段$O_1O_2$为直径的半圆上。让我们输入参数$\alpha = \widehat{BO_1O_2}$。然后$x = |OO_1| - |BO_1| = 2r \cos \alpha - r$，$y = 2r \sin \alpha - r$，$z^2 = x^2 + y^2 = 6 - 4 (\sin \alpha + \cos \alpha)$；类似于 $t^2 = 6 + 4 (\sin \alpha + \cos \alpha)$，从何而来

$$u^2 = \frac{3 - 2(\sin \alpha + \cos \alpha)}{3 + 2(\sin \alpha + \cos \alpha)} = \frac{3 - 2\sqrt{2}\sin(\alpha + \frac{\pi}{4})}{3 + 2\sqrt{2}\sin(\alpha + \frac{\pi}{4})},$$

和 $\alpha \in [\pi/6; \pi/3]$，因为四边形 $ABCD$ 是凸的。容易看出，函数$u(\alpha)$在$\alpha = \pi/4$处取最小值，在$\alpha = \pi/3$和$\alpha = \pi/6$处取最高值，其中$u(\pi/4) = \frac{1}{3 + 2\sqrt{2}} u(\pi/6) = \frac{1}{\sqrt{11 + 6\sqrt{3}}}$，即约$u \in [0, 171; 0, 217]$。

因此，在问题陈述中表述几何句子时，比率$\frac{|BC|}{|AD|}$不能取值1/3。

例7. 参数的底是菱形，边长为$a$。已知从顶部参数到底部相对两侧的高度长度等于$h$。参数 maxim 的最大音量是多少？

令$NABCD$为给定参数，$[NL]$和$[NM]$为面$ABN$和$CDN$的高度，$[NO]$为等边三角形$LNM$（图2）的高度。然后$(AB)_\perp(NL)$和$(AB)_\perp(NM)$，因此$(AB)_\perp(LM)$和$(AB)_\perp(NO)$。因此，$[LM]$是菱形$ABCD$的高度，$[NO]$是参数的高度。

根据条件$|AB| = a, |NL| = |MN| = h$。让我们先放入$|LM| = 2|LO| = x$，然后放入$S_{ABCD} = ax, |NO| = \sqrt{h^2 - \frac{x^2}{4}}$，$V$参数的体积等于

$$V(x) = \frac{1}{6} a \sqrt{(4h^2 - x^2)x^2}.$$

因此，问题已简化为在函数$V$的线段$[0; a]$上找到最大值，它与函数同时到达

$$f(x) = -x^4 + 4h^2x^2.$$

由于$f'(x) = -4x^3 + 8h^2x$，那么，将导数等于零，我们得到方程

$$x(x^2 - 2h^2) = 0$$

对于临界点，我们只能对$x = h\sqrt{2}$感兴趣。

当且仅当$a \geq h\sqrt{2}$时，点$h\sqrt{2}$属于区间$[0; a]$。我们首先假设这个条件得到满足。比较函数$f(x)$在找到点和区间$[0; a]$结束时的值，我们得出结论，函数$f(x)$在$x = h\sqrt{2}$处呈现最大值。因此，如果$a \geq h\sqrt{2}$，那么

$$V_{\max} = \frac{1}{6} a^2 \sqrt{4h^2 - a^2}.$$

最终答案将如下所示：

$$V_{\max} = \begin{cases} \frac{1}{3} ah^2, \text{ если } a \geq h\sqrt{2}; \\ \frac{1}{6} a^2 \sqrt{4h^2 - a^2}, \text{ если } a < h\sqrt{2}. \end{cases}$$
