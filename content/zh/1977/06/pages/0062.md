... > z_N，$z_i = 1 - x - y_i$（并行$\Pi_x, \tau$，即数字$x$，对我们来说是固定的）。经证明，无论是在$\Pi_y$还是在$\Pi_z$，$f$都有不小于$\frac{\varepsilon}{2}$的间隙，因此，从南到北穿过这些$2N$平行线，我们得到$f > \frac{2}{\varepsilon} \cdot \frac{\varepsilon}{2} = 1$（因为$f$非负），这是不可能的。这意味着 $f$ 在至少一条平行线上不是常数的假设是不正确的。

因此，$f$实际上仅依赖于$x$，其中$0 \leq x \leq 1$，并且我们可以从在球体上定义的函数$f$转到在$[0, 1]$上定义的函数$g$：$g(x) = f(X)$，其中$X \in \Pi_x$。上面我们证明了如果$x + y + z = 1$则$g(x) + g(y) + g(z) = 1$。但很容易报告$g(x) + g(1 - x) = 1$；因此$1 - g[1 - (x + y)] = g(x + y)$。从这里我们得到

$$g(x) + g(y) = g(x + y)$$

对于所有$x$和$y$，使得$x + y \leq 1$，$x \geq 0$，$y \geq 0$。

问题d)的解决方案

解决问题c)，我们证明了$g(x) \leq g(y)$ if $x \leq y$。另外，$g(1) = 1$。让我们证明单调（非递减）和有界函数

$$g(x) = x$$

teler 已经可以任意 $x$ 了。记住$g(x) = f(X)$，其中$X \in \Pi_x$，对于所有$X \in \Pi_x$，我们得到$f(X) = x$，即函数$f(M)$与问题a）中讨论的函数一致。
