不难发现，方程（6）的根将是且仅是方程的那些根

$$3 + \sqrt{x} = (3 - x)^2,$$

(7)

满足不等式$0 \leq x \leq 3$，即$x \in [0; 3]$。将方程（7）结合起来，得到一个更通用的方程，参数为

$$a + \sqrt{x} = (a - x)^2,$$

(8)

与式(7)在$a = 3$处一致。将方程 (8) 写成二次相对 $a$：

$$a^2 - a(2x + 1) + (x^2 - \sqrt{x}) = 0,$$

我们很容易得到两个方程：

$$x + \sqrt{x} + 1 - a = 0, \quad x - \sqrt{x} - a = 0,$$

或者，假设 $a = 3$，

$$x + \sqrt{x} - 2 = 0, \quad x - \sqrt{x} - 3 = 0.$$

解出这些方程并显示满足条件$x \in [0; 3]$的根，我们找到方程（6）的根：$x = 1$。
