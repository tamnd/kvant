示例 3：求解方程
$$x^2 - \sqrt{a-x} = a.$$

将这个方程重写为 $x^2 - a = \sqrt{a-x}$ 形式后，我们立即得出结论 *) 我们必须求解该方程
$$(x^2 - a)^2 = a - x$$
(2)
并反转满足方程的那些根
$$x^2 - a \geq 0.$$ (3)

方程（2）可以看作是相对$a$的平方：
$$a^2 - a(2x^2 + 1) + (x^4 + x) = 0,$$
从那里$a = x^2 + x$或$a = x^2 - x + 1$。

方程
$$x^2 + x - a = 0$$
(4)
有根在 $a \in [-1/4; \infty]$：
$$x_1 = \frac{-1 - \sqrt{1 + 4a}}{2},$$
$$x_2 = \frac{-1 + \sqrt{1 + 4a}}{2},$$

$x_1 = x_2$ 位于 $a = -1/4$。由于对于根$x_{1,2}$，根据方程（4），我们有
$$x^2 - a = -x,$$
那么不等式(3)的验证就是不等式$-x \geq 0$验证的证据，对于$x_1$对于所有$a \in [-1/4; \infty]$都有效，而对于$x_2$只对$a \in [-1/4; 0]$有效。

方程
$$x^2 - x + 1 - a = 0$$
(5)
有根在 $a \in [3/4; \infty]$：
$$x_3 = \frac{1 - \sqrt{4a - 3}}{2},$$
$$x_4 = \frac{1 + \sqrt{4a - 3}}{2},$$

*) 例如，参见 G.V.多罗费耶夫，M.K.波塔波夫，N.Kh. Rozov，“大学申请者数学手册”（M.，“Nauka”，1976 年，第 176-177 页）。

$x_3 = x_4$ 位于 $a = 3/4$。由于对于根$x_{3,4}$，根据方程（5），我们有
$$x^2 - a = x - 1,$$
那么不等式（3）的验证是不等式$x - 1 \geq 0$验证的见证，对于$x_3$对于任何$a$来说都是假的，而对于$x_4$对于$a \in [1; \infty]$来说它是满足的。

总结一下，让我们写下答案：
在 $a \in ] -\infty; -1/4[$ 处没有根；
对于$a = -1/4$一个根：$x = -1/2$；
对于 $a \in ] -1/4; 0]$ 两个根：$x = x_1, x = x_2$；
对于$a \in ] 0; 1[$一个根：$x = x_1$；
在 $a \in ] 1, \infty[$ 有两个根：$x = x_1, x = x_4$。

在下一个问题中，可以成功地应用相同的方法来求解方程组。

示例 4. 求解方程组
$$\begin{cases} ax^2 + 2by = a, \\ by^2 + 2ax = b. \end{cases}$$

显然，如果$a = b = 0$，则任何一对数字$(x, y)$都满足系统。如果$b = 0$但$a \neq 0$或如果$a = 0$但$b \neq 0$，则系统无解。最后，$a \neq 0$和$b \neq 0$。然后，将系统的第一个方程表示为$y$，并将其代入第二个方程，我们得到一个相对于$x$的四次方程，其参数为$a$和$b$，可以将其视为二次相对$b$：
$$4b^2 - 2b \cdot 4ax - a^2(1 - x^2)^2 = 0.$$
从这里我们找到两个方程：
$$b = \frac{a(1 + x)^2}{2}, \quad b = -\frac{a(1 - x)^2}{2}.$$
