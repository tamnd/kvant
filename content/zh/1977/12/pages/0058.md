以 $|\vec{v}| = 8000$ m/s 的速度运动时，会在轨道上出现 Lenitsa 吗？

根据动量守恒定律
$$\left(m_p + m_k\right)\vec{v} = m_p\vec{v}_p + m_k\vec{v}_k.$$
除了，
$$\vec{v}_k - \vec{v}_p = v_{0TH}.$$
从这两个关系我们得到
$$\left|\vec{v}_k\right| = \left|\vec{v}\right| + \frac{m_p}{m_k + m_p} \left|\vec{v}_{0TH}\right| = 8005 \text{ м/с},
$$
$$\left|\vec{v}_p\right| = \left|\vec{v}_k\right| - \left|\vec{v}_{0TH}\right| = 7999.9 \text{ м/с}.$$
这个问题也可以通过在飞行方向上以$v$速度移动的报告系统来解决。在这方面我们要注意，如果动量在一个惯性参考系中守恒，那么它在任何其他惯性参考系中也守恒。

动量守恒定律是喷气推进的基础。从火箭中喷出的气体带走了动量。该冲量必须通过火箭气体系统其余部分的冲量的相同模量变化来补偿。

任务 6. 产品从质量为 $M$ 的火箭中弹出，并以相对于火箭的速度 $u$ 分类为相同质量 $m$ 的部分。忽略重力的影响，让我们确定第 $n$ 部分离开后火箭达到的速度。

令 $\vec{v}_1$ 为释放第一部分气体后火箭相对于地球的速度。根据动量守恒定律
$$\left(M - m\right)\vec{v}_1 + m\left(u + \vec{v}_1\right) = 0,$$
其中$\vec{u} + \vec{v}_1$是火箭-气体系统分离时第一部分气体相对于地球的速度，此时火箭已经达到$\vec{v}_1$的速度。从这里
$$\vec{v}_1 = -\frac{m}{M}\vec{u}.$$
现在让我们求第二部分离开后火箭的速度$\vec{v}_2$。在报告系统中，数据包以$\vec{v}_1$的速度移动，在第二部分离开之前是静止的，释放后它的速度为$\vec{v}_2$。利用前面的公式，将$M \rightarrow M - m$、$\vec{v}_1 - \vec{v}_2$替换进去，我们得到
$$\vec{v}_2' = -\frac{mu}{M - m}.$$
那么 $\vec{v}_2$ 将等于
$$\vec{v}_2 = \vec{v}_2' + \vec{v}_1 = -mu \left(\frac{1}{M} + \frac{1}{M - m}\right).$$
继续这个过程，不难得到
$$\vec{v}_n = -mu \left(\frac{1}{M} + \frac{1}{M - m} + \dots + \frac{1}{M - (n - 1)m}\right).$$
如果我们引入系统质心（惯性中心）的概念，动量守恒定律可以给出另一种形式，从而简化许多问题的解决。根据定义，质心坐标（点 $c$）与组成系统的粒子的质量和坐标相关，遵循以下关系：

$$x_c = \frac{m_1x_1 + m_2x_2 + \dots + m_nx_n}{m_1 + m_2 + \dots + m_n} = \sum_{i=1}^{n} m_i x_i$$
$$y_c = \sum_{i=1}^{n} m_i y_i$$
$$z_c = \sum_{i=1}^{n} m_i z_i.$$

需要注意的是，均匀重力场中系统的质心与重心重合。

为了弄清楚质心的物理意义，我们来计算它的速度$\vec{v}_c$，或者更确切地说，是这个速度的投影。根据定义
$$v_{cx} = \lim_{\Delta t \to 0} \frac{\Delta x_c}{\Delta t}.$$
在这个公式中
