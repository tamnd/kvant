该系统由重物、绳子和块组成，不是封闭的。从外部看，系统受到负载$m_1g$和$m_2g$的重力以及从悬挂侧施加到块上的力的影响，该力等于绳子$T$的双倍张力（参见图8）。让我们将系统的运动方程写成垂直轴$Y$（向下）的投影：

$$\left(m_1 + m_2\right)a_c = \left(m_1 + m_2\right)\left|g\right| - 2\left|T\right|.$$

力 $T$ 可以通过分别写出每个负载的运动方程来求出（记住 $a_1 = -a_2 = a$）：

$$m_1a = m_1\left|g\right| - \left|T\right|,$$
$$-m_2a = m_2\left|g\right| - \left|T\right|,$$

在哪里

$$a = \frac{m_1 - m_2}{m_1 + m_2}\left|g\right|,$$
$$\left|T\right| = \frac{2m_1m_2}{m_1 + m_2}\left|g\right|.$$

将结果值 $\left|T\right|$ 代入我们的原始方程，我们发现

$$a_c = \left(\frac{m_1 - m_2}{m_1 + m_2}\right)^2\left|g\right|.$$

这个问题可以用另一种方式解决。它直接从质心的定义得出

$$\vec{a}_c = \frac{m_1a_1 + m_2a_2}{m_1 + m_2}$$

（这里$\vec{a}_c$是质心的加速度，$a_1$和$a_2$分别是负载$m_1$和$m_2$的加速度），或投影。

图 9.

轴在轴 $Y$ 上：

$$a_c = \frac{m_1a_1 + m_2a_2}{m_1 + m_2}.$$

考虑到

$$a_1 = -a_2 = a = \frac{m_1 - m_2}{m_1 + m_2}\left|g\right|,$$

我们得到

$$a_c = \left(\frac{m_1 - m_2}{m_1 + m_2}\right)^2\left|g\right|.$$

在纱线处

1. 两个人站在冰鞋上，彼此之间的距离为$l$。其中一个扔出一个质量为$m$的球，另一个在一段时间后捡起它$t$。如果抛球者的质量为 $M$，他将以多少速度滑动？

2. 沿着底部角度$\alpha$的楔子，可以在光滑的水平桌面上移动，上链自动笔以相对常数$u$移动。楔块的速度有多高，楔块上的压力有多大？楔块重量$M$，自动$m$。当楔子积累时，汽车就会移动。

3. 质量为 $M$ 的体操运动员，携带质量为 $m$ 的负载，以与地平线成 $\alpha$ 的角度以初始速度 $v_0$ 跳跃。当他们到达最大高度时，他以相对于自己$u$的水平速度将负载抛回。投掷重物后跳跃距离增加了多少？

4. 射弹由枪以初始速度 $v_0$ 与水平面成 $\alpha$ 角抛出。在抛物线轨迹的最高点，抛射体分裂成质量分别为 $m_1$ 和 $m_2$ 的两块碎片。爆炸后，质量为$m_1$的碎片垂直落下，初速度为$u$。开始计算第二个碎片的运动方程。

5. 一艘质量为$M$的船一动不动地停在湖里。在船尾和船头，相距$l$，有质量为$m_1$和$m_2$（$m_1 > m_2$）的渔民。渔民们换地方。船移动了多少？忽略防水性。

6. 在质量为$M$的静止木筏边缘，有$n$个男孩，每个男孩的质量为$m$。男孩们以相对于木筏相同的水平速度$u$跳跃后开始木筏的速度： a) 同时； b) 逐行。什么情况下筏的速度会更大？忽略防水性。

7. 推车上有两个水箱，通过带有水龙头的管子连接。其中一个装满了水（图9）。当您打开水龙头时，水流入另一个水箱。描述小车运动的性质。
