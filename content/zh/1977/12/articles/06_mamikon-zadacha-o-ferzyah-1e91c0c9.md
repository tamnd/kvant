皇后问题

1. 问题陈述
在一般的 8x8 棋盘上，可以放置 5 个皇后，使它们覆盖棋盘的所有方格。四个皇后还不够（证明这一点！）。 3x3 棋盘将在中心方格上放置一个皇后。对于 6x6 的棋盘，其磁场是相等的。所以，$F(11) \leq 5$。从图2可以看出$F(10) \leq 5$和$F(9) \leq 5$。

找到大 $n$ 的精确 $F(n)$ 是相当困难的。此外，一台完美的快速运行计算机无法在合理的时间内完成在 20x20 棋盘上放置 10 个皇后的所有选项。

对于波兹尼来说，至少找到 $F(n)$ 的估计（上限和下限）似乎很有趣。这将是我们对皇后问题的表述。

2. 分数
如果在棋盘$n \times n$上，我们沿着主对角线之一放置$n$皇后，然后删除最外面的两个皇后，那么剩下的$n-2$皇后也将是棋盘的所有正方形。方法，

$$F(n) \leq n-2.$$

如果在 $F(n)$ 皇后排列中，每个方格都被占领，则棋盘边缘上没有一个皇后，则形成棋盘的 $4(n-1)$ 边缘方格必须是该框架内部的皇后。由于每个皇后都处于同一方向，因此该帧恰好有 8 个单元格。即使所有皇后都在框架的不同方格中，那么也需要有 $$\frac{4(n-1)}{8} = \frac{n-1}{2}$$

3. $\langle k, l \rangle = \text{решетка}$
我们将皇后放在一个无限棋盘上，用$\langle k, l \rangle$马的左步（通常的国际象棋马是$\langle 2, 1 \rangle$马），即：先将皇后放在任意一个格子上；然后我们再放置四个皇后，如图3所示；我们将对每个放置的皇后做同样的事情，等等。由此产生的无限数量皇后的排列称为皇后$\langle k, l \rangle$-格子。每个 $\langle k, l \rangle$ 格子都是一个方形格子，相对于棋盘 (图 4) 旋转。

沿着行$^*$）移动，我们会定期遇到皇后。让我们用 $W_p$ 表示沿行的晶格周期的长度。例如，对于 $\langle 3, 1 \rangle$ 晶格 $W_p = 10$ (图 4)。

沿着对角线移动，我们也会周期性地遇到皇后。让我们用 $W_\partial$ 表示晶格周期的对角线长度。对于 $\langle 3, 1 \rangle$ 晶格 $W_\partial = 5$ (图 4)。

练习

1. 对于$\langle k, l \rangle$晶格$W_p = \frac{k^2 + l^2}{d}$，其中$d$是数字$k$和$l$的最公约数。
2. 对于$\langle k, l \rangle$晶格$W_\partial = \frac{k^2 + l^2}{c}$，其中$c$是数字$k + l$和$k - l$的最公约数。
3. 如果$k$和$l$是不同奇偶校验的互质数，则$W_p = W_\partial = k^2 + l^2$。
4. $W' \langle tk, tl \rangle$晶格的周期和$W \langle k, l \rangle$晶格的周期通过关系$W_p = tW_p$和$W_\partial = tW_\partial$相关。

4. 基本皇后设置
设$k$和$l$为不同奇偶校验的互质数。让我们考虑 $\langle k, l \rangle$ 格子。对于她来说，两个周期 $W_p, W_\partial$ 都等于 $W_0 = k^2 + l^2$（练习 3）。

6. 额外的皇后

在第 4 段末尾，我们注意到棋盘的所有四个对角线都是基本设置的皇后。因此，仍然只考虑奇数对角线。

整盘不含主对角线和角“单方”对角线（与中央皇后搏动）的奇数对角线数量为2（$W_0-1$）；在主对角线的一侧将有 $W_0-1$，而在一个八分圆中将有两倍：$\frac{W_0-1}{2}$。

该数字与基本设置中皇后的数量一致，位于突出显示方向的主对角线的一侧。 图 上阴影的每个皇后都会将 7 放在穿过八分圆 $O$ 的奇数对角线上。因此，在八角形的奇数对角线中，存在“空”对角线（其上没有皇后），非常印度，与角三角形$T$中的皇后一样多。我们用 $\varphi(n)$ 来表示这个数字。

考虑八角形 $O$ 的空对角线之一。将其补充为对称的十字形图形 (图 8)。由于单元格对称，该图的其他三个对角线上也没有皇后。要捕获该图形的单元格，只需在中心水平线（图 8）的对称单元格$A$和$B$中放置两个额外的皇后即可。

7. 皇后区和广场

为了从上面估计角三角形$T$（图7）中皇后的数量$\varphi(n)$，回想一下功能距离皇后位于长度$\sqrt{(2k)^2 + (2l)^2} = 2\sqrt{k^2 + l^2}$（棋盘正方形的长度取为1）一侧的格子节点处，相对于棋盘（图4, 6）旋转。

让我们移动这个格子，使皇后位于正方形的中心（图9）。那么三角形$T$中皇后的数量将不会超过中心位于$T$的“移位方块”的数量。由于每个这样的正方形完全位于三角形$T$的$\frac{d}{2}$邻域内（图10；$d$是正方形对角线的长度），因此它们的数量不会超过正方形面积相对于该邻域面积的比例。

练习 5. 平面图形 $F$ 的 $\varepsilon$ 邻域是半径为 $e$ 且中心位于图形 $F$ 的每个点的圆的并集。证明凸多边形的$\varepsilon$邻域面积等于$S + P\varepsilon + \pi e^2$，其中$S$是多边形的面积，$P$是其周长。

三角形$T$的长度等于$\frac{n}{2}$。构造格子的正方形边长是 $2\sqrt{k^2 + l^2} = 2\sqrt{\frac{n-1}{2}} = \sqrt{2}\sqrt{n-1}$。

这意味着所需的面积比等于
$$\frac{n^2}{8} + \left(1 + \frac{\sqrt{2}}{2}\right)n\sqrt{n-1} + \pi(n-1) \over 2(n-1)$$.

从 $W_0 = k^2 + l^2 = \frac{n-1}{2}$ 开始，从 (3)
$$F(n) \leqslant \frac{5}{8}n + \left(1 + \frac{\sqrt{2}}{2}\right)\frac{n}{\sqrt{n-1}} + \frac{1}{8(n-1)} + \pi - \frac{3}{8}.$$

由于$\frac{n}{\sqrt{n-1}} < 2\sqrt{n}$和$\frac{1}{8(n-1)} < 1$，以及$n \geqslant 2$和$1 + \frac{\sqrt{2}}{2} < 2$，我们得到$2(k^2 + l^2) + 1$单元格一侧的板，其中$k$和$l$是不同奇偶校验的相对素数，最终的上界：
$$F(n) \leqslant \frac{5}{8}n + 4\sqrt{n} + 5.$$

8. 定制板

现在让我们有一个板$n \times n$，其中$n \geqslant 11$。让我们取一个自然的$m$，这样$8m^2 + 3 \leqslant n < 8(m+1)^2 + 3$。从$n \geqslant 11$开始，就有这样一个$m$。请注意$8m^2 + 3 = 2[(2m)^2 + 1^2] + 1 = 2(k^2 + l^2) + 1$，其中$k = 2m, l = 1$。
