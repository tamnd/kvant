埃尔多斯-塞克雷斯问题：故事的延续

V. 科舍列夫，A. 赖戈罗德斯基

再次上路

今年«Kvant»第2期，发表了我们的文章“The Erdős-Szekeres Problem on Convex Polygons”[1]。在那里，我们讲述了组合几何中最美丽、最流行的问题之一的令人惊奇（有时甚至是浪漫）的故事 - 这个故事开始于 75 年前，但距离结束还很远。想要正确理解我们在本文中讨论的内容的起源的读者当然必须用上述文章来武装自己，因为在这里我们只会回顾“前系列”的简要总结，然后我们将进入对我们来说根本上是全新的、迄今为止尚未探索的领域。因此，我们研究的主要对象是平面上一般位置的点集。回想一下，这些都是没有三个元素位于同一行的集合。我们的目标是为每个自然数 n 找到函数 g(n) 的值，我们假设该函数等于最小的 g，这样在基数为 g 的平面上设置的任何一般位置中，必然有 n 个点是凸 n 边形的顶点。首先，我们讨论了函数 g(n) 对于 $n \in { 3,4,5,6 }$ 的行为，并发现每次 $g ( n ) = 2^{n} -^{2} + 1$ 时都是如此。然后我们确信，一般来说，对于所有 $n \ge 3$，g(n) 的值都是有限的，而且，对于 $n \ge 5$，$g ( n ) \le 4^{n}$，更准确地说，$g ( n ) \le C_{2} nn --_{5}^{2} + 1$。最后，我们再次证明了对于任何 $n g ( n ) \ge 2^{n} -^{2} + 1$。基本上就是这样。然而，事实证明，这只是旅程的开始。重点不仅在于函数 g(n) 的确切形式仍然未知（我们只能相信，根据问题的作者，$g ( n ) = 2^{n} -^{2} + 1 );$，重点还在于原始问题允许许多非常自然、同样美丽的概括，以及正如他们在科学中通常所说的修改。我们现在将讨论它们。

凸多边形和空多边形

鄂尔多斯-塞克雷斯问题的修正

在这篇出色的文章 [2] 发表近半个世纪后，或更准确地说是在 1978 年，P. Erdős 提议稍微修改原始问题的条件，当时该问题已成为经典。
