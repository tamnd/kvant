绘图中使用的正交投影可以认为是相对于直线的压缩。如果两个非垂直平面$\pi$和$\pi ¢$沿直线l相交，则平面$\pi$上任一点X到l的距离与其在$\pi ¢$上的投影X⟧的投影X⟧的比是常数。另外，X和X∨在l上的投影显然是重合的。因此，如果我们将 $\pi$ 和 $\pi ¢$ 视为同一平面的两个副本，则正交投影将是相对于 l 的压缩，其系数等于平面之间角度的余弦。然而事实证明，任何仿射变换在某种意义上都是相对于直线的收缩。更准确地说，以下定理是正确的。定理2.任何仿射变换都可以表示为关于直线的压缩和相似度的组合。证明。让我们在平面上取一个任意的方格。这种仿射变换将其变换成平行四边形的格子。如果这些平行四边形是矩形，则定理是显而易见的。否则，考虑晶格 OACB 的某个正方形。设对应的平行四边形O ´ A ´ C ´ B ´ 中的角A ´ O ´ B ´ 为锐角。我们将围绕 O 点旋转正方形晶格。平行四边形 O ￠A ￠C ￠B ￠将绕 O￠旋转，改变其形状。当正方格子旋转直角时，点A′将转到B′，B′将到达与O′A′C′B′相邻的平行四边形的顶点，并且A′O′B′将变成钝角（图6）。因此有

问题8.证明仿射变换将给定圆变换为圆是相似的。解决方案。让我们围绕给定的圆描述一个正方形并旋转它，以便该变换将其转换为矩形。圆，即给定圆的图像，将内切在该矩形中。但除了正方形以外，圆不能内接于长方形。因此，这种变换将正方形晶格变换为正方形晶格，因此是相似的。让我们举两个更有趣的仿射变换的例子。让我们在平面上选择一个坐标系，并考虑一个将坐标为 ( x, y ) 的点转换为点 ( x ´, y ´ ) 的变换，其中 x ´ = kx, y ´ = y k, k > 0。此变换是仿射变换，因为它可以表示为对坐标轴的两次压缩的组合。另外，显然xy = x ′ y ′。这意味着任何具有方程 xy = c 的双曲线都会进入自身，并且通过选择参数 k 的值，您可以将双曲线的任何点转移到任何其他点 (图7)。因此，在这种变换的影响下，每条这样的双曲线似乎都在自行滑动，就像它们在绕坐标原点$окруж-^{Рис.} 7$旋转的作用下，用方程$x^{2} + y^{2} = R^{2}$自行滑动一样。因此，这种变换称为双曲旋转。问题9.双曲线的切线与坐标轴相交于X、Y点。证明三角形OXY的面积不依赖于切点。笔记。证明双曲旋转保留面积。问题10 一条直线与双曲线相交于A、B 点，与坐标轴相交于X、Y 点。证明AX = BY。解决方案。使用双曲线旋转，我们将 A、B 点变换为相对于角度 XOY 的平分线对称的点 A 、 B 。然后，使用相对于平分线的对称性，我们交换点 A 、 B ，并通过反双曲旋转将它们转移到点 B、A。结果，线段 AX 和 BY 将相互变换，并且它们的关系将被保留，这只有在 AX = BY 时才可能实现。考虑到这个问题的退化情况，当直线接触双曲线时，我们发现切点将线段 XY 一分为二。 现在让我们考虑一个将点 ( x, y ) 转换为点 ( x ￠, y ￠ ) 的变换，其中 x ￠ = x + v 2, y ￠ = vx +
