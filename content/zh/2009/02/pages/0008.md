科万特 2009/No.2

凸多边形上的 Erdős-Szekeres 问题

V. 科舍列夫，A. 赖戈罗德斯基

临别赠言

我们想在本文中讨论的问题理所当然地被认为是组合几何的珍珠之一。其公式的异常简单性使得有关它的故事对于小学生来说很容易理解，而其解决方案的非平凡性质及其与数学其他领域的众多联系立即将感兴趣的听众带到现代组合数学的最前沿。这个问题出现在1934年，尽管与普遍看法相反，快速计数的能力并不是数学家的显着特征，但我们每个人都会立刻意识到，今年正好是她诞生75周年。不是圆约吗？好吧，让我们庆祝一下吧。

第一步

问题陈述

让我们考虑平面上的一些有限点 X 的集合，并提出以下问题：在集合 X 中是否总是存在三个点是三角形的顶点？乍一看，这个问题似乎很荒谬。显然，如果X中只有一两个点，那么就没有什么可谈的；如果 X ³ 3（X 的基数不小于 3），那么看起来集合中的任何三个元素都可以作为三角形的顶点。事情就是这样，但又不完全是这样：如果集合 X 中的三个点位于同一条线上怎么办？那么谈论一个有顶点的三角形就不太合适了。如果我们的集合中的所有点都“串”在一条直线上，这种情况绝对不好。简而言之，这个问题的答案出乎意料地是否定的。然而，如果我们从一开始就假设集合 X 中没有三个点在同一条线上，那么自然逻辑就成立了，在 X 3 的条件下，我们可以保证 X 中存在三角形。好了，我们已经把三角形整理出来了。那么$выпуклыми^{1}$四边形又如何呢，你——

凸五边形等？理论上，我们希望得到与三角形情况相同形式的答案，即：对于每个 n O ¥, n ³ 3，希望找到这样一个“边界”值 $g ( n ) О^{¥}$，使得在每个不包含同一直线上的三元组且至少有 g ( n ) 个元素的集合 X 中，有 n 个凸 n 边形的顶点，因此对于 g ( n ) - 1 ，所描述的属性不是满意。这里g(3)=3，g(4)、g(5)等等于什么？一般来说，这些数量是否存在（或者更确切地说，它们是有限的）吗？毕竟，对于任何 m 来说，很可能存在一个大小为 m 的集合 X，其中不存在凸十边形的顶点。谁知道？我们现在要研究的 Erdős-Szekeres 问题正是在于找到 g ( n ) 的值。下面我们将告诉您很多有关它的有趣的事情，但现在我们将做一个小记录。为了阐明这个问题，事实证明，假设集合 X 不包含同一直线上的三元组点是非常重要的。事实上，这样的性质在几何中很常见，因此专门为它发明了一个术语：具有这种性质的集合 X 被称为处于一般位置。该术语的起源是由于以下事实：在某种自然意义上，平面上“几乎所有”集合都处于一般位置 - 因此具有普遍性。不过，我们不会在这里给出更详细的评论，否则我们就会离我们的主线太远了。最主要的是，从现在开始，当考虑平面上的点集时，我们将假设它们处于一般位置：我们根本不关心其他集。
