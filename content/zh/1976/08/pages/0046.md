F364。摩托车在顶角为 2α 的圆锥体外表面上以速度 v（图 9）沿着半径为 R 的水平圆沿圆锥体表面移动时，刀具的摩擦系数应为多少？

图 9.

我们将把摩托车手视为一个质点，从而消除与其倾覆稳定性相关的所有问题。作用在摩托车手上的力如图 9 所示。它们是重力mg、反作用力N 和摩擦力F_TP。

让我们写下在水平轴和垂直轴上的投影的牛顿第二定律：

$$F_{Tp} \sin \alpha - N \cos \alpha = m \frac{v^2}{R},$$

$$F_{Tp} \cos \alpha + N \sin \alpha - mg = 0.$$

橡胶对锥体外表面的干摩擦力

$$F_{Tp} \leq kN.$$

求解所得系统，我们发现

$$k \geq \frac{gR + v^2 \mathrm{tg} \alpha}{gR \mathrm{tg} \alpha - v^2},$$

如果$v < \sqrt{gR \mathrm{tg} \alpha}$。否则，摩托车将无法绕半径为R的圆运动。

F365。求出如 图 10 所示连接的电容器系统的 emkosti。

图 10.

让我们用 $U_i$ 和 $q_i = C_i U_i$ 表示带有 emkomnost $C_i$ (图 11) 的电容器上的电压和电荷。如果该电容器系统连接到电动势为 $\delta$ 的电池，则系统的总电容

$$C_{06ш} = \frac{q_1 + q_2}{\mathcal{E}} = \frac{C_1 U_1 + C_2 U_2}{\mathcal{E}}.$$

(*)

让我们写下下面的对应关系（参见图11）：

$$U_1 + U_2 = \mathcal{E},$$

(1)

$$U_4 + U_5 = \mathcal{E},$$

(2)

$$U_1 + U_3 + U_5 = \mathcal{E}.$$

考虑到 emkomnost $C_3$ 电容器上电荷的预期极性，为电路的选定部分编写的电荷守恒定律（参见 图 11）给出

$$q_1 - q_2 - q_3 = 0, \quad q_3 + q_4 - q_5 = 0.$$

这些方程在代入相应的载重值后，可简化为以下形式

$$U_1 - 2U_2 - 3U_3 = 0,$$

(4)

$$3U_3 + 2U_4 - U_5 = 0.$$

通过求解方程组（1）-（5），我们可以找到电压$U_1$和$U_2$：

$$U_1 = \frac{5}{9} \mathcal{E}, \quad U_2 = \frac{4}{9} \mathcal{E}.$$

最后，根据表达式(*)，我们有

$$C_{06ш} = \frac{C_1 U_1 + C_2 U_2}{\mathcal{E}} = \frac{13}{9} C.$$
