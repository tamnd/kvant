M354。是否可以考虑在规则 (2n + 1) 结的各边的顶点和中点处的数字 1, 2, 3, ..., $4n + 2$，以便每条边的末端和中间的三个数字的总和对于所有边都相同？

让我们以 $n = 3, n = 8$ 为例，

图 1.

回答。能。

我们给出一种排列方法。在多边形边的中点，我们按顺序放置从 1 到 $2n + 1$ 的数字。此消息可帮助您排列剩余的数字$2n + 2, \dots, 4n + 2$。让我们求每边末尾和中间的三个数字的总和 $S$。显然，$S = \frac{\Sigma + \Sigma'}{2n + 1}$，其中$\Sigma = 1 + 2 + \dots + (4n + 2) = (2n + 1) \times (4n + 3)$是所有写入的数字之和，$\Sigma' = (2n + 2) + \dots + (4n + 2) = (2n + 1) (3n + 2)$是需要放在顶点的数字之和；因此$S = 7n + 5$。现在让我们将数字 $4n + 2$ 放在顶点上，这对于中间有数字 1 和 2 的边是常见的，然后将数字 $4n + 1, 4n, \dots, 2n + 2$ 一个接一个地放在顶点上，将数字 $4n + 2$ 的顶点视为第一个顶点 - 参见 图 1（在此 图 上，所有点都位于同一个圆上；黑点是“中点”，红色的是“顶点”）。让我们证明，通过这种方式，所需的数字将被放置在每个顶点（毫无疑问，这将是数字$2n + 2$，...，$4n + 2$）。事实上，经过$n$步之后，我们首先会到达与初始顶点相邻的顶点，而数字$(4n + 2) - n = 3n + 2$将被放置在这个顶点上，因此中间有一个的一侧的数字之和恰好是$(3n + 2) + 1 + (4n + 2) = 7n + 5$。现在还没有非常准确的金额
