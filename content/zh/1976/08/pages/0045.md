偶数的平方是$1936 = 44^2$，奇数最接近1977的平方是$2025 = 45^2$。因此，总和$|a_1 + a_2 + \ldots + a_{1975}|$取最小值$\frac{1936 - 1976}{2} = 20$（该值是针对具有$|a_{1976}| = 44$的序列$\{a_i\}$实现的），总和$|a_1 + a_2 + \ldots + a_{1976}|$取最小值$\frac{2025 - 1977}{2} = 24$（对于具有$|a_{1977}| = 45$的序列$\{a_i\}$）。

V·戈卢比亚特尼科夫

F362。层状电容器由面积为 S 的三个金属平行板组成。板之间的空间填充有介电特性 $\varepsilon_1$ 和 $\varepsilon_2$ 以及电阻率 $\rho_1$ 和 $\rho_2$ 的电介质。介电层厚度$d_1$和$d_2$。电容器处于恒定电压U下。确定电路中恒定电流下中间极板的电荷。

图 7.

F363。将线缠绕在圆筒上，如图7所示。线的右端以$v_1$的速度拉动，左端以$v_2$的速度拉动。圆柱体绕其轴线旋转的速度是多少？圆柱体的半径为R。

图 8.

这种层状电容器是两个电容器的组合。让我们通过$E_1$和$E_2$表示它们中的电场方向，分别表示其板上的电荷密度表面 - $\sigma_1$和$\sigma_2$以及电容器的方向 - 通过$U_1$和$U_2$。

中极板两侧的电荷符号不同，所以中极板的电荷等于

$$q = (\sigma_2 - \sigma_1) S.$$

对于电荷的平稳分布，您可以使用静电学公式。然后

$$E_1 = \frac{\sigma_1}{\varepsilon_0 \varepsilon_1}, \quad E_2 = \frac{\sigma_2}{\varepsilon_0 \varepsilon_2},$$

$$U_1 = E_1 d_1, \quad U_2 = E_2 d_2, \quad U_1 + U_2 = U.$$

另一方面，对于电流，电容器可以被视为具有相应电阻$R_1 = \rho_1 d_1 / S$和$R_2 = \rho_2 d_2 / S$的导体。根据欧姆定律

$$U_1 = I \frac{\rho_1 d_1}{S} \quad \text{и} \quad U_2 = I \frac{\rho_2 d_2}{S}.$$

求解所得的水方程组后，我们发现

$$q = \frac{\varepsilon_2 \rho_2 - \varepsilon_1 \rho_1}{d_2 \rho_2 + d_1 \rho_1} \varepsilon_0 US.$$

图7示出了一种将线缠绕在滚筒上的方法，其中滚筒可以绕其轴线旋转。让我们用 $\omega$ 表示该旋转的角速度。反过来，圆柱轴平行于自身均匀移动。我们用 $v$ 来表示它的速度。

圆柱体表面1点和2点的速度可以表示为圆柱体平移运动的线速度$\omega R$与速度$v$的代数和（图8）：

$$v_1 = v + \omega R, v_2 = v - \omega R.$$

从这里

$$\omega = \frac{|v_1 - v_2|}{2R}$$

（注意$v_1$和$v_2$有不同的符号）。
