(cm. «Kvant» № 7)

1. a) 根据向量减法规则$\vec{CD} = \vec{OD} - \vec{OC}$。如果点 $O$ 和 $D$ 不重合，则点 $A, O, B$ 和 $D$ 是菱形的顶点。在这两种情况下$\vec{OD} = \vec{OA} + \vec{OB}$。因此，$\vec{CD} = \vec{OA} + \vec{OB} - \vec{OC}$。

为了计算 $|CD|$，我们对这个等式进行平方。让我们求向量 $\vec{OA}$ 和 $\vec{OB}$ 的标量积。我们有$\vec{AB} = \vec{OB} - \vec{OA}$，即$|AB|^2 = |OA|^2 + |OB|^2 - 2\vec{OA} \cdot \vec{OB}$，由此而来$2\vec{OA} \cdot \vec{OB} = 2R^2 - c^2$。

同样地

$$2\vec{OB} \cdot \vec{OC} = 2R^2 - a^2,$$

$$2\vec{OC} \cdot \vec{OA} = 2R^2 - b^2.$$

然后我们得到

$$|CD|^2 = 3R^2 + (2R^2 - c^2) - (2R^2 - a^2) - (2R^2 - b^2) = R^2 + a^2 + b^2 - c^2.$$

6) 由a)可知

$$R^2 + a^2 + b^2 - c^2 \ge 0.$$

使用公式 $a = 2R \sin \hat{A}$ 和 cos $2\hat{A} = 1 - 2\sin^2 \hat{A}$，我们得到所需的不等式。

当且仅当 $|CD| = 0$ 时，即当 $\hat{A} = \hat{B} = 30^\circ$ 和 $\hat{C} = 120^\circ$ 时，等式成立。

2. a) 证明

$$\overrightarrow{OG} = \frac{1}{3} (\overrightarrow{OA} + \overrightarrow{OB} + \overrightarrow{OC}).$$

3. a) 注意。 $\vec{DM} = \vec{OA} + \vec{OB} + \vec{OC} - \vec{OD}$。计算出向量 $DM$ 的标量平方，即可得到公式

$$|DM|^2 = 4R^2 + a^2 + b^2 + c^2 - (a_1^2 + b_1^2 + c_1^2),$$

其中 $a = |DA|$、$b = |DB|$、$c = |DC|$、$a_1 = |BC|$、$b_1 = |CA|$、$c_1 = |AB|$、$R = |OA|$。
