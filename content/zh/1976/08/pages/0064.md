前往文章“Priitsip Ferma”
1. 反射定律的推导（参见图1）。
当光在均匀介质中传播时，最短时间的路径对应于最短路径。让光从 A 点落到 B 点，在 O 点经镜子反射。令其透射的光等于
$$l = AO + OB = \sqrt{a^2 + x^2} + \sqrt{b^2 + (c - x)^2}.$$
为了找到函数 t(x) 的最小值，我们需要求 l(x) 对 x 的导数，并且

$$\frac{dl}{dx} = \frac{2x}{2\sqrt{a^2 + x^2}} + \frac{-2(c - x)}{2\sqrt{b^2 + (c - x)^2}} = 0,$$
$$\frac{x}{\sqrt{a^2 + x^2}} = \frac{c - x}{\sqrt{b^2 + (c - x)^2}};$$
$$\sin \alpha = \sin \beta, \quad \alpha = \beta.$$

2. 折射定律的推导（见图2）：
$$t = \frac{l_1}{v_1} + \frac{l_2}{v_2};$$
$$l_1 = \sqrt{a^2 + x^2};$$
$$l_2 = \sqrt{b^2 + (c - x)^2};$$
$$t = \frac{1}{v_1} \sqrt{a^2 + x^2} + \frac{1}{v_2} \sqrt{b^2 + (c - x)^2};$$
$$\frac{dt}{dx} = \frac{1}{v_1} \frac{2x}{2\sqrt{a^2 + x^2}} + \frac{1}{v_2} \frac{-2(c - x)}{2\sqrt{b^2 + (c - x)^2}} = 0;$$
$$\frac{1}{v_1} \frac{x}{\sqrt{a^2 + x^2}} = \frac{1}{v_2} \frac{c - x}{\sqrt{b^2 + (c - x)^2}};$$
$$\sin \alpha = \sin \beta,$$
或者
$$\frac{\sin \alpha}{\sin \beta} = \frac{v_1}{v_2}.$$

转至文章“粉末人物实验”
1. 当你用一只手的手指握住电子纸的叶子，用另一只手的手指将牙膏涂抹在纸上时，你身体的电位就等于电子纸的电位。因此，两根手指与电子纸之间的电位差为零，不会形成粉末图形。
2. 为了形成粉末图形，手指和电子纸之间需要可变的电位差。如果电路中根本没有电流，并且枪管中只有这种电势差，那么活塞的形状将全部相等。这就是为什么可以使用粉末图形来检测网络相导体中的电流。
