电气多极

周围空间中某个点上的精确电荷所产生的静电场的电势与该电荷到该点的距离成反比（参见统计末尾的附录）。每一个都是集中在某一区域的任何一组电荷，远离该区域，都会产生与距离成反比的电势。然而，这个结论在一般情况下并不成立。事实证明，通过按一定顺序排列电荷，可以获得与距离的任意整数次方成反比的电势。

为了确信这一不寻常的性质，我们只需要一个数学陈述：如果值 $|x|$ 小于 1，则对应关系为真

$$\frac{1}{1-x} = 1 + x + x^2 + x^3 + x^4 + \dots$$

(1)

这是无限递减几何级数之和的常见表达式。

让我们继续考虑各种静电荷系统。在距确切电荷 $q$ 距离 $r$ 处，该电荷产生的电势 φ 的大小与距离 $\varphi = \frac{kq}{\varepsilon r}$ 成反比。比例系数$k$取决于单位制的选择。在 SI $k = \frac{1}{4\pi\varepsilon_0}$ 中。我们选择$k = 1$（SGSE系统）的单位系统会更方便。另外，我们假设所有电荷都处于真空中，即$\varepsilon = 1$。

例如，考虑位于同一条直线上且彼此相距一定距离 (图 1) 的三个电荷。设$AB = a$、$AC = b$，电荷大小为$q$、$nq$和$mq$，其中$n$和$m$是一些数字。让我们找到点 $D$ 处的电势，该点位于线段 $AC$ 的延续上，距点 $A$ 距离 $r$，并且距离所有三个电荷都足够远。从数学上来说，最后一个条件可以写成$r \gg a + b$。根据电场叠加原理，$D$点的电势$φ$等于各电荷产生的场电势的代数和：

$$\varphi = \frac{q}{r} + \frac{nq}{r-a} + \frac{mq}{r-b} = \frac{q}{r} \left( 1 + \frac{n}{1-a} + \frac{m}{1-b} \right).$$

$$\varphi = \frac{q}{r} \left[ 1 + n \left( 1 + \frac{a}{r} + \frac{a^2}{r^2} \right) + \frac{a^3}{r^3} + \dots \right] + m \left( 1 + \frac{b}{r} + \frac{b^2}{r^2} + \frac{b^3}{r^3} + \dots \right) = \frac{q + nq + mq}{r} + q \frac{na^2 + mb^2}{r^3} + q \frac{na^3 + mb^3}{r^4} + \dots.$$
