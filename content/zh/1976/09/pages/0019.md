⟦folio 17⟧

卡丹公式和几何

A·雷兹尼科夫

您熟悉如何使用二次方程 $x^2 + px + q = 0$ 的系数来确定它有多少个实根。如果$p^2 - 4q > 0$，则有两个根，如果$p^2 - 4q = 0$，则有一个根，最后，如果$p^2 - 4q < 0$，则没有根。

在本期第 14 页中。在图14中，对于三次方程$x^3 + px + q = 0$导出了类似的条件。利用这个条件，你可以得到一个巧妙的不等式来连接任意三角形的元素。这是如何完成的。

令$ABC$为边为$a, b, c$的三角形； $p$是它的半周长，$S$是它的面积，$R, r, r_a, r_b, r_c$是外接圆、内接圆和外圆的半径。事实证明，以下关系是正确的：

$$r_a + r_b + r_c = 4R + r, \quad r_a r_b + r_b r_c + r_c r_a = p^2, \quad r_a r_b r_c = p S.$$ (1)

等式 (1) 意味着数字 $r_a, r_b, r_c$ 是以下方程的根：

$$x^3 - (4R + r)x^2 + p^2 x - p S = 0.$$ (2)

这是因为 $r_a, r_b, r_c$ 是多项式 $(x - r_a)(x - r_b)(x - r_c) = x^3 - (r_a + r_b + r_c)x^2 + (r_a r_b + r_b r_c + r_c r_a)x - r_a r_b r_c$ 的根。

写下方程（2）的所有三个根*）有效的条件，经过多次变换并使用公式$S = pr$，我们得到以下不等式：

$$\left[ p^2 - (2R^2 + 10Rr - r^2) \right]^2 \leq 4R (R - 2r)^3$$ (3)

由(3)可知

$$R \geq 2r$$ (4)

所以呢

$$\left| p^2 - (2R^2 + 10Rr - r^2) \right| \leq 2 \sqrt{R(R - 2r)^3}$$ (5)

当两个数$r_a, r_b, r_c$相等时，即当三角形是等边时，（3）和（5）中相等。

战斗

1. 证明式(1)。为此，请推导 $S: S = rp = r_a(p - a) = r_b(p - b) = r_c(p - c) = \frac{abc}{4R} = \sqrt{p(p - a)(p - b)(p - c)}$ 的以下表达式。

2. 找出在(4)中实现平等的条件。

3. 证明$16Rr - 5r^2 \leq p \leq 4R^2 + 4Rr + 3r^2$。

4. 研究哪些等边三角形的数字 $p^2 - (2R^2 + 10Rr - r^2)$ 是非负数。

*) 参见第 17 页。 14. 要使用此处给出的条件，请继续替换$x = y + \frac{4R + r}{3}$。
