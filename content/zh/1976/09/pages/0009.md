⟦folio 7⟧

卡尔达诺在他 1545 年出版的著作《伟大的艺术或代数规则》中收录了他所知道的有关三次方程的所有内容。

在序言中，卡尔达诺阐述了这个问题的历史：“......在我们这个时代，西波·德尔·费罗发现了一个公式，根据这个公式，未知平面的立方等于一个数字。这是非常美丽和精彩的工作。由于这种艺术超越了所有人类的毅力和凡人头脑的所有清晰度，它必须被视为来自天堂的礼物，以及精神力量的能力，这是一个如此微弱的发现，一个能够实现它的人可以期望实现一切。他，来自布雷西亚的尼科洛·塔塔利亚，我们的朋友，被邀请与德尔·费罗的学生安东尼奥·马里奥·菲奥雷一起作曲，为了不被击败，他决定解决同样的问题，过了很长时间，他让我醒悟到了卢卡·帕乔利的话，他说这种方程没有通用的解决方案，尽管我自己已经有了很多很多的发现，但我仍然没有对找到我所做的事情感到绝望。然而，当我收到这一章并添加它的解决方案时，我发现可以用它做更多的事情；并且我对我的事情越来越有信心，随着使用，我进一步发现，部分是我自己，部分是我以前的学生洛多维科·法拉利。

在现代化的形式中，卡尔达诺找到方程（1）的解的方式可以表述如下。我们将寻找 $x = \beta - \alpha$ 形式的方程 (1) 的解。然后 $x + \alpha = \beta$ 和

$$x^3 + 3x^2\alpha + 3x\alpha^2 + \alpha^3 = \beta^3.$$ (4)

由于$3x^2\alpha + 3x\alpha^2 = 3x\alpha(x + \alpha) = 3x\alpha\beta$，等式(4)可以重写为

$$x^3 + 3\alpha\beta x = \beta^3 - \alpha^3.$$ (5)

我们来一一尝试 $\langle a, b \rangle$ 所以选一对 $\langle \alpha, \beta \rangle$使得 (5) 与 (1) 一致。为此，夫妻双方必须 $\langle \alpha, \beta \rangle$ 是系统的解决方案

$$\begin{cases} 3\alpha\beta = a, \\ \beta^3 - \alpha^3 = b \end{cases}$$

或同等系统

$$\begin{cases} \beta^3 \cdot (-\alpha^3) = -\frac{a^3}{27}, \\ \beta^3 + (-\alpha^3) = b. \end{cases}$$

根据维塔定理，$^*)$$\beta^3$和$-\alpha^3$将是相交二次方程$y^2 - by - \frac{a^3}{27} = 0$的根。由于我们正在寻找方程（1）的正根，$\beta > \alpha$。所以，$\beta^3 = \frac{b}{2} + \sqrt{\frac{b^2}{4} + \frac{a^3}{27}}$和$-\alpha^3 = \frac{b}{2} - \sqrt{\frac{b^2}{4} + \frac{a^3}{27}}$。因此，

$$x = \sqrt[3]{\frac{b}{2} + \sqrt{\frac{b^2}{4} + \frac{a^3}{27}}} - \sqrt[3]{\frac{b}{2} + \sqrt{\frac{b^2}{4} + \frac{a^3}{27}}}.$$

对于正数$a$和$b$，根$x$也是正数。

上述计算仅在意识形态方面遵循卡尔达诺的推理流程。他自己用几何语言论证：如果将$\beta = \alpha + x$边的立方体用与面平行的平面切割成边$\alpha$边的立方体和边$x$边的立方体，那么除了两个立方体外，边$\langle \alpha, \alpha, x \rangle$边还有长方体，边$\langle \alpha, x, x \rangle$边还有三个长方体；各卷之间分别给出 (4)；转到(5)，不同类型的平行六面体成对组合。

“自从我意识到塔尔塔利亚给我的部门是他借助几何证明发现的，我就认为这是通向所有其他部门的王道。”

$^*)$ 维埃特本人（1540-1603）比卡尔达诺生活得晚，但他的定理的特殊情况（在学校中称为维埃特定理）基本上是卡尔达诺知道的。
