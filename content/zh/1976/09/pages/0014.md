这么简单的方程。所以这个结果可以作为资产写入我们的公式中。
第二个例子：$x^3 + 3x - 4 = 0$。
式（3）给出：
$$x = \sqrt[3]{2 + \sqrt{5}} + \sqrt[3]{2 - \sqrt{5}}.$$
答案就比较麻烦了。这个数字可以通过表格近似得出，表格越准确，结果就越接近1。原因很简单：这个数字等于一*)。但这从公式中看不出来，这是公式的一个缺点：毕竟，当求解具有整数系数的二次方程时，我们立即看到解是否是异调的。
第三个例子：$(x + 1) \times (x + 2)(x - 3) = 0$。
很明显，这个方程有三个解：-1、-2 和 3。但是让我们尝试使用该公式来求解它。打开括号
$$x^3 - 7x - 6 = 0$$
并应用公式（3）：
$$x = \sqrt[3]{3 + \sqrt{-\frac{100}{27}}} + \sqrt[3]{3 - \sqrt{-\frac{100}{27}}}.$$
平方根符号是负数。当求解二次方程时遇到类似的情况时，我们得出的结论是该方程无解（“方程无实解”，更指定的人会说；但在这种情况下，教育没有多大帮助）。然而，我们知道解方程甚至有三个。在这种情况下，我们的公式被简单地检查了。

*) 证明：统一在很大程度上是我们方程的根，而我们的方程只有一个解 - 请参阅下面的第 4 点。

这些例子和其他类似的例子表明，公式（3）不受欢迎的原因不在于它的麻烦（其实不是那么麻烦！），而是在于它的不可靠性：有时它根本不给出解，有时它给出的形式并不令人满意。

这个结论总体来说是正确的。

让我们试着弄清楚我们的公式能给出什么，不能给出什么。让我们从最简单的开始。

3. 定理

如果表达式$\frac{q^2}{4} + \frac{p^3}{27}$非负，则式(3)右边就是式(2)的解。

证明。让我们把
$$\alpha = \sqrt[3]{-\frac{q}{2} + \sqrt{\frac{q^2}{4} + \frac{p^3}{27}}},$$
$$\beta = \sqrt[3]{-\frac{q}{2} - \sqrt{\frac{q^2}{4} + \frac{p^3}{27}}}.$$

显然，式(3)右边正好等于和$\alpha + \beta$。并且乘积 $\alpha \beta$ 等于 $-\frac{p}{3}$：

$$\sqrt[3]{-\frac{q}{2} + \sqrt{\frac{q^2}{4} + \frac{p^3}{27}}} \times \sqrt[3]{-\frac{q}{2} - \sqrt{\frac{q^2}{4} + \frac{p^3}{27}}} = \sqrt[3]{(-\frac{q}{2})^2 - (\frac{q^2}{4} + \frac{p^3}{27})} = \sqrt[3]{-\frac{p^3}{27}} = -\frac{p}{3}.$$
