3. SIZ 估计是根据算术平均值和几何平均值的不等式得出的。确实，$x_{n+1} = \frac{x_n^3}{5} + \frac{1}{15x_n} + \frac{1}{15x_n} \geq 4\sqrt[4]{\frac{1}{5\cdot15\cdot15}} = \frac{4\sqrt[4]{3}}{15} > \frac{1}{3} > \frac{1}{5}$。

为了获得上限，我们求解不等式 $x_n > x_{n+1}$。我们有：

$$x_n > \frac{x_n^4+1}{5x_n} \text{ или } x_n^4 - 5x_n^2 + 1 < 0,$$

即 $$\frac{5-\sqrt{21}}{2} < x_n^2 < \frac{5+\sqrt{21}}{2},$$

因为

$$x_n > 0, \text{ получаем, что если } \sqrt{\frac{5-\sqrt{21}}{2}} < x_n < \sqrt{\frac{5+\sqrt{21}}{2}}, \text{ то } x_n > x_{n+1}.$$

这意味着，如果$1 \leq x_n \leq 2$，则$x_{n+1}$小于2。如果$x_n < 1$（由于$x_1 = 2$，因此$x_n > 2$的情况不存在），则$x_{n+1} < 2$。

由此可见，对于所有$n > 1$，$x_n < 2$，午夜不等式得到证明。
