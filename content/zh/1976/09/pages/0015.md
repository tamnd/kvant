4. 方程（2）有多少个解？

这是一个自然的问题：毕竟，求解一个方程意味着找到它的所有解，为此了解它有多少个解是有用的。

让我们首先了解函数 $y = x^3 + px + q$ 返回什么值 $x$，以及它在什么值时杀死 *)。为此，请比较函数在点 $x$ 和点 $x + \delta$ 的值，其中 $\delta$ 是一个小正数（参见 图 1）。更重要的是：

$$x^3 + px + q$$

或者

$$(x + \delta)^3 + p(x + \delta) + q?$$

我们计算差异：

$$(x + \delta)^3 + p(x + \delta) - (x^3 + px + q) = \delta (3x^2 + p + 3\delta x + \delta^2).$$

该差值的符号由加法 $3x^2 + p + 3\delta x + \delta^2$ 的符号决定（自 $\delta > 0$ 起）。至于这个金额，那么：

1) 如果$3x^2 + p > 0$，那么对于足够小的$\delta$，它是正数；
2) 如果$3x^2 + p < 0$，那么对于足够小的$\delta$，它是负数。

因此：

1) 如果$3x^2 + p > 0$，则函数$y = x^3 + px + q$不够充分

2) 如果$3x^2 + p < 0$，那么它就会杀死。此外，众所周知，

1) 如果$p > 0$，则对于所有$x$，$3x^2 + p > 0$；
2) 如果$p < 0$，则$3x^2 + p > 0$代表$x > \sqrt{-p/3}$和$x < -\sqrt{-p/3}$，$3x^2 + p < 0$代表$-\sqrt{-p/3} < x < \sqrt{-p/3}$。

波兹尼

1) 如果$p > 0$，则函数$y = x^3 + px + q$返回所有$x$；
2) 如果$p < 0$，则函数$y = x^3 + px + q$在$x < -\sqrt{-p/3}$返回，在$-\sqrt{-p/3} < x < \sqrt{-p/3}$杀死，并在$x > \sqrt{-p/3}$再次返回。
