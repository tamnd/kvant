⟦folio 14⟧

请注意，对于足够大的 $x$，表达式 $x^3 + px + q$ 正相关，而对于足够大的负模数 $x$，它负相关。现在我们可以示意性地画出函数$y = x^3 + px + q$(图2a)-c)的图形。

这些示意图仅反映了递增和递减函数$y = x^3 + px + q$的区域，以及$y > 0$对于足够大的$x$和$y < 0$对于负$x$的绝对值足够大的事实。但这些示意图已经足以判断方程的解数了。我们看到：

1) 如果 $p > 0$，则方程有一个解；或者如果 $p < 0$ 和点 $-\sqrt{-p/3}, \sqrt{-p/3}$ 处的函数值具有相同的符号 - 图 2a) 和 2c)。

2) 如果 $p < 0$ 和函数在点 $-\sqrt{-p/3}, \sqrt{-p/3}$ 处的值具有相反的符号，则方程有三个解 - 图 26)。

这个结果可以用更方便的形式表示。为了找出函数在点$-\sqrt{-p/3}, \sqrt{-p/3}$处的值是否具有相同或相反的符号，可以计算这些值和变量：正数，则对应的符号，如果是负数，则不同。我们来计算一下：

$$\left[(-\sqrt{-p/3})^3 + p(-\sqrt{-p/3}) + q\right] \times \left[(\sqrt{-p/3})^3 + p\sqrt{-p/3} + q\right] = \left[p/3\sqrt{-p/3} - p\sqrt{-p/3} + q\right] \times \left[-p/3\sqrt{-p/3} + p\sqrt{-p/3} + q\right] = \left(q - 2/3p\sqrt{-p/3}\right) \times \left(q + 2/3p\sqrt{-p/3}\right) = q^2 + 4/27p^3.$$

因此，如果$p < 0$和$q^2 + \frac{4}{27}p^3 > 0$，则有一种解，如果$p < 0$和$q^2 + \frac{4}{27}p^3 < 0$，则有三种解。注意到如果$p > 0$，那么$q^2 + \frac{4}{27}p^3 > 0$已经上紧，我们可以将结果表述如下：

$$q^2 + \frac{4}{27}p^3 > 0, \text{мо уравнение}$$
(2) 我们有一个解决方案。
$$q^2 + \frac{4}{27}p^3 < 0, \text{мо уравнение}$$
(2) 我们有三种解决方案*)。

5. 意想不到的结论

你有没有注意到我们有一个令人满意的weis？毕竟，表达式 $q^2 + \frac{4}{27}p^3$ 与公式 (3) 中的危险根式表达式仅相差一个微不足道的（从符号的角度来看）集合：

$$q^2 + \frac{4}{27}p^3 = 4\left(\frac{q^2}{4} + \frac{p^3}{27}\right).$$

这意味着，恰好当方程有三个解时，根式表达式为负，并且公式也没有给出它（我们在示例中看到了这一点，但现在很明显这不是偶然的）。如果方程只有一个解，那么我们的公式就给出了它。

所以，我们在第2段中观察到的现象已经得到了解释。剩下的就是看看当方程有三个解并且平方根下有一个负数时，是否仍然可以从我们的公式中挤出一些东西。

*）我们总是不考虑某些东西变为零的情况。事实上，如果$q^2 + \frac{4}{27}p^3 = 0$，那么方程有两个解，唯一的例外：如果$p = q = 0$，那么显然有一个解。
