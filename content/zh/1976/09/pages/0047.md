$$a = c + \beta + s, \quad (9_1)$$
$$b = f + \beta + \delta + s, \quad (9_2)$$
$$d = f + \beta + 2s - q, \quad (9_3)$$
$$e = c + \beta + \delta + 2s. \quad (9_4)$$

可见$b + e > a + d > c + f$，即$k > g > h$。现在从方程$(8_8)$

$$n = c + f + h + 2\beta + 2\delta + 3s, \quad (9_5)$$

以及从$(8_7)$和$(8_9)$

$$g = h + 2\delta + q, \quad (9_6)$$
$$k = h + 2\beta + 2\delta + 3s. \quad (9_7)$$

因此，如果非负整数 (*) 满足系统 (1)，则存在一组非负整数 $\beta, \delta, s, q, c, f, h$ ($\beta > 0, \delta > 0, s > 0, 0 < q < 3s, q \leqslant f + \beta + 2s, c \geqslant 0, f \geqslant 0, h \geqslant 0$)，使得数字 (*) 通过对应关系 (9) 与它们相关。

相反，不难验证（例如，通过直接代入）对于满足所列条件的任意整数$\beta, \delta, s, q, c, f, h$，定义公式（9）的数字（*）将满足系统（1）。因此，对于所有可能的这样的“参数”集合$\beta, \delta, s, q, c, f, h$，可以获得三个棋手问题的所有解决方案。

“这是一个解决难题的好方法。”老师说。 - 但是“所有的末端都小心地留在输入中。”您如何同意系统中的两个方程是其他方程的结果，您应该将方程 $(8_5)$ 和 $(8_6)$ 相加并找到 $\frac{1}{3}(p + q)$？

在解决问题的过程中，我展示了这个等式的正确性，以及最终解决方案不需要的计算分钟数。等式$\alpha = \beta + \delta + q$也是如此。另外，在寻找解决方案时，我遇到了表达式$\frac{1}{3}(\alpha + \beta + \gamma + \delta)$（见（7）），它应该是一个自然数。但这个表达式等于$\beta + \delta + \frac{1}{3}(p + q)$。所以$\frac{1}{3}(p + q)$一定是一个整数。为了在最终解决方案中展示这一点，我逐项添加了等式 $(8_5)$ 和 $(8_6)$。
