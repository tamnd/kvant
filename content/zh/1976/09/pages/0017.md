6. 复数有帮助吗？

下面写的所有内容都是为熟悉复数的读者准备的。

然而，“熟悉”复数，本质上无非就是使用某些词语的习惯。复数在数学中的出现方式与稍早的负数或分数非常相似。由于不是每个实数都可以有平方根，因此可以方便地用一个新数$i$来补充数字的供应，该新数的平方等于-1（同样，如果要进行通用减法运算，请引入负数）。与$i$一起，引入了$a + bi$形式的数，其中$a$和$b$是实数，并且约定对这些数的运算按照以下规则进行：

$$(a + bi) + (c + di) = a + bi + c + di = (a + c) + (b + d)i,$$
$$(a + bi)(c + di) = ac + adi + bci + bdi^2 = (ac - bd) + (ad + bc)i$$

（在上一个等式中我们教导了$i^2 = -1$）。所构造的数字称为复数；数$a$和$b$称为对应的实数和最小数$a + bi$；两个复数相等当且仅当它们的实部相等并且它们的最小部分相等。我们还给出莫伊弗公式（我们将在下面需要它）：

$$(\cos \alpha + i \sin \alpha)(\cos \beta + i \sin \beta) = \cos (\alpha + \beta) + i \sin (\alpha + \beta),$$

这是复数变分公式和众所周知的三角计量公式的直接推论。

让我们回到公式（3）。在 $\frac{q^2}{4} + \frac{p^3}{27} < 0$ 的情况下，您可以尝试使用它来找到方程（2）的解，从复数中提取立方根。

取复数$a + bi$的立方根意味着求解方程

$$(x + iy)^3 = a + bi,$$

即方程$x^3 - 3xy^2 + i(3x^2y - y^3) = a + bi$。最后一个相等意味着

$$\begin{cases} x^3 - 3xy^2 = a, \\ 3x^2y - y^3 = b. \end{cases}$$

该系统再次以各种方式简化为三次方程。例如，像这样：

$$y^2 = \frac{x^3 - a}{3x} (\text{из первого уравнения}),$$

$$y \left( 3x^2 - \frac{x^3 - a}{3x} \right) = b,$$

$$y = \frac{3bx}{8x^3 + a},$$

$$x^3 - 3x \cdot \frac{9b^2x^2}{(8x^3 + a)^2} = a,$$

$$(x^3 - a)(8x^3 + a)^2 - 27b^2x^3 = 0,$$

或者，假设 $x^3 = z,$

$$(z - a)(8z + a)^2 - 27b^2z = 0. \quad (4)$$

当然，我们可以再次转向公式（3）。但事实证明，将此公式应用于方程（4）总是会产生负平方根。然而，这并不奇怪，因为很容易证明，复数的立方根是有意义的。

因此，式(3)不能这样使用。但是，在它的帮助下，您仍然可以找到方程（2）的根的近似值。为此，除了平方根表和立方根表外，还需要三角函数表并应用莫伊弗公式，从中得出：

$$\cos \alpha + i \sin \alpha = \left( \cos \frac{\alpha}{3} + i \sin \frac{\alpha}{3} \right)^3.$$
