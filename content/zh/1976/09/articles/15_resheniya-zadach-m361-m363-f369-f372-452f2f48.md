M361。两个陶瓷到下一个陶瓷。 $m \times n$ 单元格的矩形在方格纸上突出显示。每个人轮流划掉一些水平行中的所有单元格。注意，划掉一列（行）后，剩余的单元格可以认为位于列（行）数减一的矩形中。从 图 1 可以清楚地看出，根据哪个特定列（或行）被划掉，因此我们可以假设这是最外面的列（或行）之一。

让我们证明，如果原始矩形中的行和列的数字$m$和$n$具有不同的奇偶性，那么如果玩得正确，初学者获胜。

初学者的策略是这样的：他划掉一行或一列，这样他就剩下一个行数为偶数、列数为偶数的矩形（因为在原始矩形中行数和列数具有不同的奇偶性，所以他总是可以这样做）。在第二局游戏的任何一步之后，都会留下一个较小的矩形，其中的列数和行数再次具有不同的奇偶性。初学者再划掉一行或一列，这样就剩下一个行数和列数为偶数的矩形，以此类推。最后，第二步之后，游戏剩下一个只有一行或一列的矩形，划过的初学者获胜。

请注意，如果初始矩形中只有一列（或行），则初学者通过划掉该列（行）来获胜。

根据上述推理，如果 $m$ 和 $n$ 具有相同的奇偶性，并且它们都不等于 1，那么第二个玩家获胜，因为无论走哪一步，先发手都会留下一个矩形，其中行数和列数具有不同的奇偶性。

M363。两条具有平行轴的抛物线相交于点 $A_0$ 和 $B_0$。在第一个上，我们取点 $A_1$，$A_2$，... $A_{2n}$；第二个有点 $B_1$、$B_2$、... $B_{2n}$，因此 $A_0A_1 \parallel B_0B_1$、$A_1A_2 \parallel B_1B_2$、... $A_{2n-1}A_{2n} \parallel B_{2n-1}B_{2n}$。让我们证明$A_{2n}B_0 \parallel B_{2n}A_0$。

令 $y = px^2 + qx + r$ 和 $y = p'x^2 + q'x + r'$ 为给定抛物线 (图 7) 的方程。如果$a_i, b_i$是点$A_i, B_i$的横坐标，则第一条抛物线的弦$A_iA_j$的角度系数由以下公式给出

$$\frac{(pa_i^2 + qa_i + r) - (pa_j^2 + qa_j + r)}{a_i - a_j} = p(a_i + a_j) + q,$$

类似地，第二抛物线的弦$B_iB_j$的角度系数由公式$p'(b_i + b_j) + q'$给出。

由条件可知

$$p(a_0 + a_1) + q = p'(b_0 + b_1) + q',$$

$$p(a_1 + a_2) + q = p'(b_1 + b_2) + q',$$

$$p(a_{2n-1} + a_{2n}) + q = p'(b_{2n+1} + b_{2n}) + q'$$

由于$A_0B_0$是抛物线的公共弦，那么$p(a_0 + b_0) + q = p'(a_0 + b_0) + q'$。 (*)

将逐项等式 (1), (3), ..., (2n - 1) 乘以 -1，并与等式 (*), (2), (4), ..., (2n) 相加，我们得到 $p(a_{2n} + b_0) + q = p'(b_{2n} + a_0) + q'$。

这意味着$A_{2n}B_0 \parallel B_{2n}A_0$。

由于球 A 和 C 通过螺纹连接，因此它们作为一个整体沿 X 轴移动。让我们写出球系统的运动方程，将作用在系统上的外力投射到 X 轴上。这些是力 F2 和 F1，即球 A 和 C 与球 B 之间的相互作用力。力 F2 垂直于 X 轴，其在该轴上的投影等于 0。力 F1 在 X 轴上的投影等于 F1 sin α。因此，

$$F_1 \sin \alpha = 2 m a_x.$$

因此球 A 和 C 的加速度在 X 轴上的投影相等

$$a_{Ax} = a_{Cx} = a_x = \frac{F_1}{2m} \sin \alpha = \frac{q^2}{8\pi\varepsilon_0 ml^2} \sin \alpha.$$

类似地，对于同样由螺纹连接的球 A 和 B 的系统，我们得到

$$a_{Ay} = a_{By} = \frac{F_1}{2m} \cos \alpha = \frac{q^2}{8\pi\varepsilon_0 ml^2} \cos \alpha.$$

那么球A的加速度绝对值等于

$$a_A = \sqrt{a_{Ax}^2 + a_{Ay}^2} = \frac{q^2}{8\pi\varepsilon_0 ml^2}.$$

矢量 a_A 与 X 轴形成角度 β，使得

$$tg\beta = \frac{a_{Ay}}{a_{Ax}} = ctg\alpha.$$

现在考虑球 B。让我们写下它沿 X 轴的运动方程。螺纹AB的张力和球A作用的力沿Y轴方向，它们在X轴上的投影等于0。因此，

$$a_{Bx} = \frac{F_1}{m} \sin \alpha = \frac{q^2}{4\pi\varepsilon_0 ml^2} \sin \alpha.$$

那么球B的加速度模型

$$a_B = \sqrt{a_{Bx}^2 + a_{By}^2} = \frac{q^2}{8\pi\varepsilon_0 ml^2} \sqrt{1 + 3 \sin^2 \alpha}$$

$$\varGamma = \frac{F_2}{F_1} \frac{f_1 - F_1}{l - f_1 - F_2}.$$
