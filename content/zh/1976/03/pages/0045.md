让我们找到数字 $A = \sum_{k=1}^{7} a_k$ 的最可能值，使得最后一个不等式仍然成立。不难证明（我们将在下面这样做）

$$\sum_{k=1}^{7} a_k^2 \geq \frac{1}{7} \left( \sum_{k=1}^{7} a_k \right)^2 = \frac{1}{7} A^2;$$

那么根据不等式 (**) 可以得出

$$\frac{1}{7} A^2 - A \leq \sum_{k=1}^{7} a_k^2 - \sum_{k=1}^{7} a_h \leq 42,$$

或$$\frac{1}{7} A^2 - A \leq 42,$$或$$A^2 - 7A \leq 294,$$，即$(A - 21)(A + 14) \leq 0$，由此而来$A \leq 21$。

$13 \times 13$方格的证明以类似的方式进行，我们建议读者自行完成所有计算。

现在我们将证明（对于任何$n \geq 1$，$a_k \geq 0$，$k = 1, 2, \dots, n$）不等式

$$\sum_{k=1}^{n} a_k^2 \geq \frac{1}{n} \left( \sum_{k=1}^{n} a_k \right)^2.$$

为了计算方便，我们放入$na = \sum_{k=1}^{n} a_k$并证明$\sum_{k=1}^{n} a_k^2 \geq na^2$。让我们用$\varepsilon_k: \varepsilon_k = a_k - a$表示数字$a_k$与数字$a_k$的平均值$a$之间的差。然后

$$na = \sum_{k=1}^{n} a_k = \sum_{k=1}^{n} (a + \varepsilon_k) = na + \sum_{k=1}^{n} \varepsilon_k,$$

因此

$$\sum_{k=1}^{n} \varepsilon_k = 0.$$

由此可知：

$$\sum_{k=1}^{n} a_k^2 = \sum_{k=1}^{n} (a + \varepsilon_k)^2 =$$

$$= \sum_{k=1}^{n} a^2 + 2a \sum_{k=1}^{n} \varepsilon_k + \sum_{k=1}^{n} \varepsilon_k^2 = na^2 + \sum_{k=1}^{n} \varepsilon_k^2 \geq na^2.$$

总结来说，有一句话。在任务条件下，我们默默地忽略了这样一个事实：$7 \times 7$、$13 \times 13$（通常是$(m^2 + m + 1) \times (m^2 + m + 1)$，其中$m = 2, 3, \dots$）单元格的规则正方形可以实现美丽的几何解释。例如，图 5 上的表格可以被认为是图 7 上七个点和七条直线的关联表（虚线曲线...$A \dots B \dots C \dots$）
