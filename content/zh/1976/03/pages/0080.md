2. 让我们将不等式变换如下：
$$\frac{\log_3(3 - 3^{1-x})}{x - 1} \geq 0.$$

这个不等式相当于两个不等式系统的组合：

a) $\left\{ \begin{array}{l} x - 1 > 0, \\ 3 - 3^{1-x} \geq 1; \end{array} \right.$

b) $\left\{ \begin{array}{l} x - 1 < 0, \\ 0 < 3 - 3^{1-x} \leq 1. \end{array} \right.$

在第一种情况下
$$\left\{ \begin{array}{l} x > 1 \\ x \geq 1 - \log_3 2, \end{array} \right.$$
从哪里$x > 1$。

在第二种情况下
$$\left\{ \begin{array}{l} x < 1, \\ 0 < x \leq \log_3 \frac{3}{2}, \end{array} \right.$$
从哪里$0 < x \leq \log_3 \frac{3}{2}$。

回答。 $0 < x \leq \log_3 \frac{3}{2}, 1 < x$。

4. $V_1: V_B = 1:2, V_2: V_B = 1:3$。笔记。从行人密码出来的那一刻到自行车离开的那一刻，时间过去了$\tau = \frac{5S}{6(v_1 + v_2)}$，直到第一个带自行车的行人密码安装完毕$t = \frac{4S}{9v_2}$。

根据第一个内置行人和自行车的条件，我们得到
$$t \cdot v_1 + (t - \tau) \cdot v_B = S.$$

从同一个人同时完成运动的条件我们得到
$$\frac{S}{v_1} = \frac{S}{v_B} + \tau.$$
