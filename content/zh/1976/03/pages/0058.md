⟦folio 56⟧

不平等$3t^2 - t - 2 \leqslant 0$。满足$-\frac{2}{3} \leqslant t \leqslant 1$。不等式 $3x^2 \geqslant -\frac{2}{3}$ 对于任何实数 $x$ 都有效。让我们将1表示为$3^0$，然后根据定理3的不等式$3x^2 \leqslant 3^0$我们可以找到$x \leqslant -2$。

在求解指数和对数不等式时，经常使用积分方法。

问题 13（莫斯科矿业学院，1975 年）。解决不平等问题
$$\log_2^4 x - \log_0.5^2 \frac{x^3}{8} + 9 \log_2 \frac{32}{x^2} <
< 4\log_0.5^2 x.$$
不等式的 ODZ 具有 $x > 0$ 的形式。请注意，在 ODZ
$$\log_0.5 \frac{x^3}{8} = \log_2 \frac{8}{x^3} = 3(1 - \log_2 x),$$
$$\log_2 \frac{32}{x^2} = 5 - 2\log_2 x,$$
$$\log_0.5 x = -\log_2 x,$$
理论上，原始不等式等价于：
$$\log_2^4 x - 13 \log_2^2 x + 36 < 0.$$
代入$\log_2 x = t$，因式分解后得到不等式$(t + 3)(t + 2)(t - 2)(t - 3) < 0$。他的解决方案（参见图4）：$-3 < t < -2$，$2 < t < 3$。让我们返回到原始变量：$-3 < \log_2 x < -2$、$2 < \log_2 x < 3$，其中：$0,125 < x < 0,25$ 和 $4 < x < 8$。

问题 14（莫斯科电子工程学院，1974 年）。解决不平等问题
$$0,3^{\log_0.25 \log_2 \frac{3x+6}{x^2+2}} > 1.$$
根据定理 3，这个不等式
$$\log_0.25 \log_2 \frac{3x+6}{x^2+2} < 0,$$
最后一个是不等式$\log_2 \frac{3x+6}{x^2+2} > 1$，由此而来$\frac{3x+6}{x^2+2} > 2$。两边乘以$x^2 + 2$（这个表达式对于任何实数$x$都是正数），我们得到$2x^2 - 3x - 2 < 0$或$2(x+0,5)(x-2) < 0$，因此$-0,5 < x < 2$。

求解以对数或幂为底的包含参数或未知数的不等式时，需要分别考虑底值的积分$(0; 1)$和$(1; +\infty)$。

问题 15（莫斯科大地测量研究所，航空摄影和制图工程师，1975 年）。解决不平等问题
$$(x^2 - x + 2)^{\log_0.6 \frac{2x-3}{x+1}} > 1.$$
由于度 $x^2 - x + 2$ 的底数对于任何实数值 $x$ 都是正的（检查！），这个不等式相当于系统的总体
$$\left\{ \begin{array}{l l} x^2 - x + 2 < 1, \\ \log_0.6 \frac{2x-3}{x+1} < 0, \\ \log_0.6 \frac{2x-3}{x+1} > 0. \end{array} \right.$$
在所有实数集合上，不等式 $x^2 - x + 2 < 1$ 无解，并且不等式 $x^2 - x + 2 > 1$ 满足任意 $x$（证明一下！）。因此系统无解，第二个不等式
$$\log_0.6 \frac{2x-3}{x+1} > 0, \text{ т. е. } 0 < \frac{2x-3}{x+1} < 1.$$
