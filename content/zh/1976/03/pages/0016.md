相对于 p 素数的 P 对称性。对于射线，这是一般轴对称，并获得反演*)。 （例如，关于 n 素数 $L(-1,1)$ 的 n 对称性是相对于以 $O=(0;0)$ 为半径的圆的倒转；它需要一个与中心 $O$ 不同的点 $A$，到位于射线 $OA$ 上的点 $A'$，使得 $|OA| \cdot |OA'|=1$）。我们知道，在反演过程中，圆和直线变成圆或直线，并且角度的值被保留。在 Poincaria 语言中，这意味着，例如，对于 n-prima $L(-1,1)$，n-prima $L(\alpha,\beta)$ 进入 n-prima $L\left(\frac{1}{\alpha},\frac{1}{\beta}\right)$ 的 n 对称性。特别是，在 $\alpha \neq \infty$ 处获得的 n 素数 $L(\alpha,0)$ 被变换为 n 素数 $L\left(\frac{1}{\alpha},\infty\right)$，即射线。因此，n 对称性将 Poincaria 纳入自身，n 素数纳入 n 素数。单独检查（我们省略此检查）n 对称性不会改变 n 距离$\rho$。 （然而，在 Poincaria 中，任何将 n 素数转换为 n 素数的变换都会保留 $\rho$（这里没有现成的）；这是罗巴切夫斯基几何和欧几里得几何之间最重要的区别。）

*) 请参阅 A. Savin 的文章“Inversion and the Circle of Apollonius”，«Kvant»，1971 年，第 8 期，或解决方案���题 M305，«Kvant»，1975 年，第 9 期。

通过组合 n 对称性可以获得的 n 位移已经存在，以便将任何 n 素数转换为任何 n 素数；此外，第一个 n 素数的任何给定点都可以与第二个 n 素数的给定点组合，任何 n 射线与另一个 n 射线组合（证明它！）。这意味着这些n个运动可以组合任意n个长度相等的n段，并且我们得到这些段是n全等的。可以证明所有 n 次运动属性都如所描述的那样。

通过 n 次平移，角度会转换为欧几里得意义上的等于它的角度（因为这对于平行平移、现成的、轴对称和反转都是正确的）。因此，庞卡利亚的角度全等概念与欧几里得的角度全等概念并没有什么不同。考虑到这种情况，庞加里就像我们一样，将证明三角形全等的两个符号：通过两条边和它们之间的角度，以及通过一条边和连接到它的两个角。三角形的证明在这些边上更加复杂：毕竟，我们对该标准的证明使用了圆最多相交两个点的事实。幸运的是，事实证明，n 圆与塞几里得圆重合（完全位于上半平面），只是它们的 n 中心与一般圆不重合（这是一个相当复杂的问题）
