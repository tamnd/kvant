对数公式的最佳示例如下：

$$\log_a xy = \log_a |x| + \log_a |y|,$$
(1a)
$$\log_a \frac{x}{y} = \log_a |x| - \log_a |y|,$$
(2a)

$$\log_a x^p = p \log_a |x| (p - \text{четное}).$$
(3a)

现在公式(1a)和(2a)的右侧定义为$x \neq 0$和$y \neq 0$。坐标平面上的所有点都满足这些条件，但位于轴 (图 3) 上的点除外，并且当从表达式 $\log_a xy$ 移动到表达式 $\log_a |x| + \log_a |y|$ 时，未知数的 ODZ 不存在，但会扩展（比较 图 2 和 图 3）。排除了失去解的可能性，但可能会出现根的构建。在等式(3a)中，左右两侧的ODZ重合：$x \neq 0$。

避免更改 ODZ 的第二种方法是从一个方程转移到等效方程组或方程组（不等式）。因此，方程$\log_a \frac{x}{y} = c$等价于方程组$\log_a x - \log_a y = c$、$\log_a (-x) - \log_a (-y) = c$。

问题 2. 求解方程

$$\lg (x + 10) + \frac{1}{2} \lg x^2 = 2 - \lg 4.$$

未知的 ODZ：$x > -10, x \neq 0$。从$\frac{1}{2} \lg x^2 = \lg |x|$开始，我们将方程简化为$\lg (x + 10) + \lg |x| + \lg 4 = 2$形式，从而得到$\lg [4 |x| (x + 10)] = \lg 100$。根据定理 2，最后一个方程等价于：

$$4 |x| (x + 10) = 100$$

（从 $100 > 0$ 开始，不等式成立）。考虑两种情况并求解相应方程：

a) $x > 0, x^2 + 10x - 25 = 0$,
b) $-10 < x < 0, x^2 + 10x + 25 = 0$，我们找到两个根：$x_1 = -5 + 5\sqrt{2}, x_2 = -5$。

通常，方程或方程组的解可以通过引入新变量来简化。

任务 3（ZIL 工厂技术学院，1974 年）。解方程

$$\left( \sqrt{7 + \sqrt{48}} \right)^x + \left( \sqrt{7 - \sqrt{48}} \right)^x = 14.$$

让我们表示$\left( \sqrt{7 + \sqrt{48}} \right)^x = u$，$\left( \sqrt{7 - \sqrt{48}} \right)^x = v$。然后系统

$$\left\{ \begin{array}{l} u + v = 14, \\ uv = 1 \end{array} \right.$$

在 $u > 0, v > 0$ 处将等价于原始方程。她的解决方案：

$$u_1 = 7 + \sqrt{48}, v_1 = 7 - \sqrt{48};$$
$$u_2 = 7 - \sqrt{48}, v_2 = 7 + \sqrt{48}.$$

让我们把$u_2$和$v_2$写成这样的形式：$u_2 = (7 + \sqrt{48})^{-1}, v_2 = (7 - \sqrt{48})^{-1}$。返回原始变量，我们找到$x_1 = 2, x_2 = -2$。

$[f(x)]^{\phi(x)} = [g(x)]^{h(x)}$ 形式的方程通常使用定理 2 求解，即对方程取一定底数的对数。

问题 4（莫斯科地质研究所，1975 年）。解方程

$$x^{\lg^2 x^2 - 3\lg x - 4,5} = 10^{-2\lg x}.$$

未知的 ODZ：$x > 0$。考虑到这一点，原方程等价于方程

$$\lg \left( x^{\lg^2 x^2 - 3\lg x - 4,5} \right) = \lg \left( 10^{-2\lg x} \right),$$

通过替换，$\lg x = t$与三次方：$t (8t^2 - 6t - 5) = 0$重合，根为$t_1 = 0, t_2 = 1, 25$和$t_3 = -0, 5$。返回原始变量，我们发现：$x_1 = 1, x_2 = 10\sqrt[4]{10}$和$x_3 = \sqrt[10]{10}$。
