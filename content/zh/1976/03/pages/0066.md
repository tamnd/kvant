物理学院

1. 解方程
$$2\sin(x + 3) \cos(4x - 1) + \sin(3x - 4) = 0.$$
2. 解方程
$$\log \frac{1}{6}(x + 3) = \left(\frac{1}{2}\right)^{\log_4(x^2 + 5x + 12)}$$
3. 解决不平等问题
$$(2 - 5^x)(7x^2 - 10x + 3) < 0.$$
4. 在直角三角形$ABC$中，角$ACB$是直角。令$E$为角$ABC$的二边与边$AC$的交点；点$D$是边$AB$的中点，$O$是线段$BE$和$CD$的交点。通过点 $O$ 绘制垂直于线 $BO$ 的垂线，直到它与边 $BC$ 相交于点 $F$。已知$FC = b$、$OC = \frac{3b}{2}$。求三角形$ABC$的面积。
5. 两个相等的三角形$KLM$和$KLN$有公共边$KL$、$\Rightarrow KLM = \Rightarrow LKN = \pi/3$、$KL = a$、$LM = KN = 6a$。平面 $KLM$ 和 $KLN$ 相互垂直。球接触线段 $LM$ 和 $KN$ 的中点。求它的半径。

生物学院

1. 第一天，两名工人在相同的时间工作，制造相同的零件。与此同时，这名工人比第二名工人多生产了30个零件。第二天，工人的劳动生产率提高了1.2倍，比第一天提前了1个小时完成工作。第二天第二个工人每小时的产量比第一天少了 5 个零件，但工作量比第一天多了 7/6 倍。据了解，第二天每个工人就生产了420个零件。第一天第二个工人每小时生产多少个零件？
2. 找到二次方程的参数$p$的所有值
$$(4x)^2 + \left(2\frac{1}{p} + 4 - 24\right)x + 1 = 0$$
仅有一个解。
3. 凸四边形$ABCD$内接于圆，其边长$AB$为圆的直径。对角线 $AC$ 和 $BD$ 相交于点 $M$。已知$BC = 3$、$CM = \frac{3}{4}$、三角形$ABC$的面积第二大于三角形$ACD$的面积。求线段 $AM$ 的长度。
4. 解方程
$$|\sin x + 2\sin 2x + \sin 3x| = 1 + 2\cos x + \cos 2x$$
5. 找到所有满足不等式的整数$n$
$$\log \left(2\log \frac{\pi}{5} - n + 13\right) \leq 0.$$

化学学院

1. 解决不平等问题
$$\frac{3}{2}x + \sqrt{x} < 8.3^{2x + 3}\sqrt{x} + 3^{x + 4}\sqrt{x} + 2.$$
2. 这两个地雷在第一方中得到了改进。第二矿3月产量比一矿2月产量少400$m$。第一矿井 1 月产量等于 3 月产量，等于第二矿井 2 月产量。根据前两个月的结果，第一矿的产量比第二矿少了1000$m$。多出多少？是第一座矿山 1 月份的产量还是第二座矿山 1 月份的产量？据了解，如果第二矿1月产量等于3月产量，那么第二矿1月、2月、3月的产量将比第一矿同月产量多1300$m$。
3. 在三角形$ABC$中，角度$ACB$的余弦等于$\frac{2}{3}$、$AC = 3$、$BC = 9$。点$D$位于$BC$边，使得$CD = 3$。求三角形$ACD$外接圆的面积与三角形$ABD$外接圆的面积之比。
4. 半径为$R$的球接触三角形矩形底边中边的所有侧面。连接直线顶点与球中心的线段被与直线底边的交点分成两半。求直线的体积。
5. 查找系统所对应的参数$a$的所有值
$$\begin{cases} \sin(3a - 3y) + 3\sin x = 0, \\ 2\log_4(a - y) + 2\log_4(2\sqrt{y}) = \log_2\sqrt{y} + 3\log_8(2x) \end{cases}$$
有四个解。
