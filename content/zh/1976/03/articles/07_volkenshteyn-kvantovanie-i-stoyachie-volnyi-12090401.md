量化和波结构

M·沃尔基尼坦

量子力学是研究微粒（原子、电子、中子等）运动规律的科学。这就是微观世界的物理学。它解释了许多重要的现象——放射性衰变、金属的导电性和化学键的性质。但首先，量子力学解释了原子的线光谱——它回答了为什么原子只能发射或吸收光波振荡的一百个特定频率的光的问题。量子力学表明，原子中的电子只能具有固定的、可变的能量值。物理学家通常说电子位于离散能级$E_1$、$E_2$、...——原子中电子的能量是量子化的。当电子从一个能级传递到另一个能级时，原子就会吸收或发射光。在第一种情况下，电子从较低能量的能级移动到较高能量的能级，在第二种情况下，反之亦然。发射（或吸收）光波的频率由玻尔频率的条件决定。

$$v_{nn'} = \frac{E_n - E_{n'}}{h},$$

(1)

其中$E_n$、$E_{n'}$是能级，$n$、$n'$是表征这些能级的量子数值。

量子力学的主要任务之一是找到给定粒子系统（特别是原子）的量子化能量值。根据式（1），解决这样的问题意味着同时计算系统的光谱，即确定该系统发出的光的频率集合。这个问题的严格解决方案归结为求解量子力学的基本方程，即所谓的薛定谔方程。这是一个分部微分方程

二阶导数，学生无法解决它。然而，基于相当简单的考虑，无需求解薛定谔方程即可获得许多与能量量子化相关的有趣结果。

只有在微观粒子的波动性这一概念出现之后，微观世界中发生的事件才变得可以解释。这个想法最早是由德布罗意提出的。他提出，除了微粒特性之外，物质粒子还具有波动特性，并且它们之间存在明确的联系。以速度 $v$ 运动且动量 $p=mv$ 的粒子对应于波-

$$n \frac{\lambda}{2} = L,$$

或者

$$\lambda_n = \frac{2L}{n},$$

其中 $n=1, 2, 3, \dots$ (图 1)。

使用结构上的驻波模型，我们将尝试找到量子力学的几个问题的量子化条件。

电子
“在潜力盒子里”

让我们假设电子可以在没有任何力的作用下沿着长度$L$的线段自由移动。换句话说，这个区间内电子的势能为零。在该段的边界处，电子的势能返回到无穷大。电子的行为就像重体的行为一样，能够沿着具有无限高垂直壁的盒子的底部自由移动，并从其壁上弹性反射。问，电子能量的价值有哪些可能性？

如果结构的端部是固定的，则驻波的节点必然位于其上，并且驻波不会传播到结构的边界之外。同样，盒子里的重体也无法超出其极限，因为这需要无限的能量。电子在“盒子”中以速度$v$运动对应于德布罗意波$\lambda = \frac{h}{mv}$。由于电子不能超出段$L$的边界（它从“盒子”的壁上弹性反射），因此德布罗意波必须从

⟦folio 28⟧

盒子的墙壁。因此，与电子运动相对应的波型可以表示为稳定的德布罗意汇波。节点必须位于线段$L$的末端，并且在线段本身上它们必须包含整数个半波（图2），即它们必须满足条件

$$\lambda = \frac{h}{mv} = \frac{2L}{n} \quad (n = 1, 2, 3, \dots).$$

由此可见，盒子内电子的速度是量子化的：

$$v_n = \frac{h}{m\lambda_n} = \frac{nh}{2mL} \quad (n = 1, 2, 3, \dots).$$

对应关系是量子化的，其动能也是量子化的。在盒子内，电子的势能为零，因此总能量与动能一致：

$$E = \frac{mv^2}{2}.$$

在这里代入速度值的可能性（3），我们发现

$$E_n = \frac{n^2h^2}{8mL^2} \quad (n = 1, 2, 3, \dots).$$

乍一看，这个结果似乎出人意料。这意味着重体在壁无限高的盒子中移动的能量必须被量子化。然而，即使对于非常小的粒子，只有当“盒子”的尺寸达到原子数量级时，量子化才会变得明显。事实上，对于质量为 $m = 9,8 \cdot 10^{-28} e$ 的电子，放置在长度为 $L = 1$ cm 的盒子中，可能的能量值为

$$E_n = n^2 \frac{(6,62 \cdot 10^{-34})^2}{8 \cdot 9,8 \cdot 10^{-31} \cdot 10^{-4}} \approx n^2 \cdot 5,6 \cdot 10^{-34} \partial x = n^2 \cdot 3,5 \cdot 10^{-15} \partial v$$

以及相邻层之间的“距离”

$$\Delta E_n = E_{n+1} - E_n = (2n+1) \cdot 3,5 \cdot 10^{-15} \partial v.$$

这些是非常大的“距离”，并且能谱是真实的。

我们通过类比弦振荡得到的能量量子化条件（4）被证明是完全严格的——它与该问题的薛定谔方程的解所给出的条件完全一致。我们将返回公式（4）并展示从中得出的有趣结果。现在，让我们转向另一个问题。

谐波振荡器

让我们考虑一下谐振子的量化。这是受到力 $f = -kx$ 影响的粒子的名称，该力与粒子与平衡位置的偏差 $x$ 成正比，并且倾向于使粒子返回到该位置。

比例系数 $k$ 是一个常数，表征其他力作用的系统的其他属性。例如，对于壁球，$k$ 是壁球的刚度。

$$v = \frac{1}{2\pi} \sqrt{\frac{k}{m}}. \quad (5)$$

谐振子在任何时刻（对于与平衡位置的任何偏差$x$）的能量由势能$\Pi = \frac{kx^2}{2}$和动能$K = \frac{mv_x^2}{2}$组成，即

$$E = \frac{kx^2}{2} + \frac{mv_x^2}{2}.$$

如果一个微粒发生振荡，那么它的总能量就会被量子化。让我们找到量化条件。

振子势能的图形是抛物线 $\Pi = \frac{kx^2}{2}$ (图 4)。

以最大偏差$x_0$振荡的微粒本质上是沿着长度$2x_0$的线段移动，并且该移动的速度取决于坐标$x$（$v = \sqrt{\frac{k}{x}(x_0^2 - x^2)}$）。

因此，粒子对应的德布罗意波长不会保持恒定。这是解决问题的重要条件。为了简化解决方案，我们将做出一些假设 - 假设在整个线段上的点$x_0$和$-x_0$之间，粒子的总能量等于动能。

我们所做的假设意味着振荡器可以被视为“势盒”中的粒子，其“深度”为$\frac{kx_0^2}{2}$（参见图3）。在“墙壁”上，总能量等于势能，即

$$E = \frac{kx_0^2}{2}.$$

因此，墙之间的距离

$$L = 2x_0 = 2\sqrt{\frac{2E}{k}}.$$

事实上，“盒子”内部在整个段$L$的动能是恒定的$\left(\frac{mv^2}{2} = \frac{kx_0^2}{2}\right)$，这意味着“盒子”内部粒子的速度是恒定的。这样的粒子对应于德布罗意驻波，其长度由条件决定。

$$\lambda_n = \frac{2L}{n} = \frac{4}{n}\sqrt{\frac{2E}{k}}.$$

因此，粒子速度的可能值为

$$v_n = \frac{nh}{4m}\sqrt{\frac{k}{2E}}.$$

让我们找出振荡器能量的可能值：

$$E = \frac{mv^2}{2} = \frac{m}{2}\left(\frac{nh}{4m}\sqrt{\frac{k}{2E}}\right)^2,$$

在哪里

$$E_n = \frac{nh}{8}\sqrt{\frac{k}{m}},$$

或者，考虑到（5），

$$E_n = \frac{\pi}{4}nhv \quad (n = 0, 1, 2, \dots).$$

使用薛定谔方程解决该问题的第二个解的形式为

$$E_n = nhv + \frac{1}{2}hv (n=0, 1, 2, \dots).$$

氢原子

让我们考虑另一个问题——关于氢原子能量的量子化。这个问题首先由尼尔斯·玻尔解决。他使用所谓的行星模型计算了氢原子的光谱。尽管计算出的电子能量与观测到的光谱相匹配，但该模型不允许计算原子的其他特征。

根据现代量子力学概念，行星模型只能非常有条件地反映电子的实际行为。在这种氢中，单个电子似乎在原子核周围形成电子云——负电荷云，其密度表征了在原子内给定区域中找到电子的概率。在原子未激发状态下，最大密度球体的半径约为 0.53 Å。 （在行星模型中这个距离

对应于最小电子轨道半径~0.53 A。）
正如我们已经说过的，有关原子电子层结构和性质的问题可以通过求解给定系统的薛定谔方程来回答。我们将尝试解决氢原子能量的量子化问题，而不使用行星模型或薛定谔方程——我们仍然将自己局限于与固定端弦振动的机械类比。

电子由于与原子核相互作用而产生的势能等于

$$\Pi = -\frac{e^2}{r},$$

图 5a.

其中$e$是电子电荷值，$r$是原子中最可能存在电子的球体半径（即电子云密度最高的球体半径）。

相关性 $\Pi(r)$ 的图形（势能曲线）具有双曲线的形式 (图 5a)。我们可以假设，对于给定的$r$值，电子在线性尺寸等于$r$的区域内的原子中移动。

我们假设在该区域的“边界”处，电子的所有能量都等于其势能，即

$$E = \Pi = -\frac{e^2}{r}.$$

线段“内部”，每个点 $x$ 的电子能量由动能和势能组成：

$$E = \frac{mv^2(x)}{2} + \Pi(x) = -\frac{e^2}{r}.$$

电子速度在$r$段内变化；因此，电子对应的德布罗意波长将不是恒定的。这就为问题的解决提供了条件。为了原谅他，我们将做出以下假设：我们将假设电子的速度是恒定的。例如，让速度的大小等于值 $v(r/2)$。

由于$\Pi(r/2) = -\frac{2e^2}{r}$，那么从(9)我们找到值$v = v(r/2)$

$$v = \sqrt{\frac{2e^2}{mr}} = \sqrt{\frac{-2E}{m}}.$$

我们所做的假设本质上意味着我们将原子中的电子表示为“势盒”中的粒子，其“深度”为$-\frac{e^2}{r}$，“宽度”为$r$（参见图 5a）。这样的粒子对应于德布罗意波的结构，其长度也许由条件决定

$$\lambda_n = \frac{2r}{n} = -\frac{2e^2}{nE}.$$

因此，电子速度的可能性

$$v_n = \frac{h}{m\lambda_n} = -\frac{hnE}{2me^2}.$$

根据式（10），电子的总能量可用其速度来表示：$E = -\frac{mv^2}{2}$。将值$v_n$的可能性代入(11)，我们得到

$$E = -\frac{mv_n^2}{2} = -\frac{h^2n^2E^2}{8me^4}.$$

因此，电子能量值的可能性为

$$E_n = -\frac{8me^4}{n^2h^2} \quad (n = 1, 2, 3, \ldots).$$

该问题的第二个解（薛定谔方程的解）具有以下形式

$$E_n = -\frac{2\pi^2me^4}{n^2h^2} \quad (n = 1, 2, 3, \ldots).$$

解（12）和（13）仅在数值因素上有所不同。所以我们得到的解定性地正确描述了氢原子的光谱。随着量子数 $n$ (图 56) 的增加，原子中的电子能级变得更加接近。不同级别的能量值之间的关系为

$$E_1:E_2:E_3:\ldots = 1:\frac{1}{4}:\frac{1}{9}:\ldots$$

随着$n$的增加，计算电子能量（回想一下$E_n < 0$），在$n \to \infty$（$r \to \infty$）时它变为零。电子从原子中被移除。自由电子的能量为正，其可能值的谱是连续的。

因此，我们案例研究中德布罗意驻波的报告有助于解释系统能量的量子化。

金属分子模型

现在让我们回到一个具有无限壁的潜在盒子。与其他问题不同，我们在这里得到了严格的解决方案。我们不禁要问，这样的模式在哪里可以找到呢？在分子理论中。

有限化合物的分子，其中碳-碳双键与单键共轭，即与单键交替，具有移动电子。每个双键都有两个移动电子（称为 pi 电子）。这些电子可以沿着键合系统自由移动，但是，当然，为了离开分子，电子必须获得非常高的能量。

其分子含有大量共轭键（即π电子）的感染表现出：这意味着，与大多数有限的非声子化合物不同，这些物质吸收光谱可见区域的光。共轭键越大，即π电子越大，共轭键也越大，正是这样的物质。例如，在具有共轭键的碳氢化合物系列中，波长$\lambda$对应于较长波长的吸收，列于表中。
