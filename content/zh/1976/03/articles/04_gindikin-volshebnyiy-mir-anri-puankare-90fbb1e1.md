## 亨利·庞加莱的魔法世界

我描述了一个想象的世界，其中的居民不可避免地会创造出罗巴切夫斯基的几何学。

A·庞加莱

当今天讲述罗巴切夫斯基几何的历史时，人们可能会得到这样的印象：如果非欧几里得几何的创造者证明了它的一致性，那么它就会被接受。然而，最令批评者不安的并不是缺乏这些证据。人们习惯于几何学处理我们的真实空间，并且这个空间是由欧几里得几何学描述的。高斯将几何学与其他数学分支区分开来，认为它像力学一样是一门实验科学，这是一个特点。但与此同时，高斯就像洛巴切夫斯基和博莱艾一样，明白，首先，逻辑上和谐的几何构造是可能的，其背后不存在物理现实——“想象的”几何；其次，在天文尺度上，欧几里德几何在我们的世界中占主导地位，这并不是无可争议的。然而，只有少数数学家才能理解的东西，对于非专业人士来说是完全无法理解的。他们根据几何直觉的欧几里得标准来衡量罗巴切夫斯基几何的陈述，并获得了取之不尽用之不竭的智慧源泉。 NG车尔尼雪夫斯基在流亡中写给他的儿子们的信中说，整个喀山都在嘲笑罗巴切夫斯基：“什么是‘光线曲率’或‘弯曲空间’？没有平行线公理，什么是几何学？他将这与‘使靴子变方’和‘从顶部拔出根’进行比较，并说这就像‘用俄语写没有动词’一样荒谬（这里是费特的：‘沙沙声，胆怯的呼吸，夜莺的颤音”，事实证明，他们也“笑得腰疼”）。

当第一个模型出现时，非欧几何的发展进入了一个新阶段。我们现在将这些模型视为证明罗巴切夫斯基几何一致性的一种手段；但他们的非凡之处还不仅仅在于这一点。即使在有利的眼光下，罗巴切夫斯基的几何也显得过于复杂，与数学的其他部分脱节，而凯莱-克莱因模型表明，它自然地出现在当时非常流行的射影几何的大道上！另一方面，考虑一个模型，其基本概念是从熟悉的欧几里得几何图像构建的，使得用更直观的模型取代非欧几里得几何的形式公理化表示成为可能。

另一种模型是由亨利·庞加莱（Henri Poincaré）发明的，用于处理复变量函数理论中的纯分析问题。他意外地发现，他身上出现的转变可以解释为罗巴切夫斯基平面上的位移。这一发现给他留下了如此深刻的印象，以至于许多年后，他回忆起自己是如何想到这一点的：当他在库坦斯游览时爬上一辆公共汽车的台阶时，“似乎没有任何先前的想法”。十年后，庞加莱对他的模型做出了非凡的补充——他为其奠定了“物理”基础。本文致力于讲述庞加莱模型的故事。

### 物理学之旅

我们的几何概念有物理前提。例如，我们将光线视为直线。射向我们的光线仍然呈直线，即使它沿途发生了折射（例如，从空气进入水中）。为了消除这种错觉，你需要进行一个实验，或者从外部观察正在发生的事情。

⟦figure⟧
图 1

让我们在上半平面 ($y\gt0$) 上有一个光学非均匀介质，其中光速根据定律 $c(x,y)=y$ 变化（无论光线的方向如何）。根据费马原理，两点之间的光路是光需要最短传播时间的路径。在我们的环境中（其中$c(x,y)=y$）两点之间的光将沿着这样的曲线$L$（图1）传播，其中
$$
\dfrac{\sin\alpha(y)}y=k,\tag1
$$
式中，$\alpha(y)$为纵坐标$y$点处$L$所画的切线与垂线所成的角； $k$ 是曲线 $L$ 上所有点的固定数。显然，所有以$x$轴（即垂直于该轴）为圆心的圆都满足条件（1）；对于每个这样的圆$k=\dfrac1r$，其中$r$是它的半径。使用 $k=0$ 我们得到垂直直线。可以证明，不存在其他满足条件（1）的曲线；对此还有一个物理解释（例如：光从给定点沿给定方向沿着单一路径传播）。

垂直于 $x$ 轴的圆和垂直直线（或者更确切地说，它们位于上半平面的部分）将在我们的故事中发挥主要作用。

### “庞卡利亚”及其几何学

庞加莱世界（让我们称其为纪念其创造者 *Poincaria*）是没有边界 $y=0$ 的上半平面 $\{(x,y){,}~y\gt0\}$（这很重要！）。居住在庞卡利亚（*庞卡利亚*）的生物感知为“直的”上半圆，其中心位于 $x$ 轴（没有末端！）和垂直射线 (图 2)。我们将这些线称为 n 线。对于庞卡利亚人来说，P 线似乎是无限的（光沿着它们传播无限的时间），并且 P 线的末端，就像 $x$-s 的整个轴一样，是不可见的。所以，庞卡利亚人相信他们的庞卡利亚在各个方向上都是无限的。我们将 n 行的不可见点称为“无穷远点”；对于射线，我们将认为点 $\infty$（无穷远）是其无限远的点之一。 P 线由一对无限远的点唯一确定（为什么？）；所以我们将它们区分开来，并用$L(\alpha,\beta)$表示，其中$\alpha$、$\beta$是实数（其中之一可以是$\infty$）——$x$轴上无限远点的坐标。

让我们尝试与庞卡利亚人一起构建他们的空间几何结构。就像我们一样，当生活在欧几里得空间中时，有些陈述对于庞卡利亚人来说似乎是显而易见的；他们在没有证据的情况下接受它们（公理），并从中推导出更复杂的陈述（定理）。对于我们来说，从外部看庞卡利亚，所有这些陈述看起来都与庞卡利亚不同（例如，半圆或射线对我们来说是直的！），因此我们将庞卡利亚的表述“翻译”为我们自己的“平淡”欧几里得语言，并用我们自己的方式证明它。

例如，Poincarians 知道一条 n 线穿过两个不同的点，而且它是唯一的一个。对我们来说，这意味着通过半平面的两个不同点，会穿过一个垂直于 $x$ 轴的半圆，或一条垂直射线（证明一下！）；请参见图 2。请注意，该陈述的物理解释（即两点之间的光沿单一路径传播）对于庞卡里亚人和我们来说是相同的（但是，对于几何学而言，该解释没有证据力）。不难验证，在庞卡利亚中，所有关于点和线的相对位置以及线上点的顺序的欧几里得几何公理都是有效的。 （要习惯庞卡利亚，请理解 n 线段、n 半平面，n 线将庞卡利亚划分为 n 线段，以便一个 n 半平面中连接点的 n 线段不与边界 n 线相交，但不同 n 半平面中连接点的 n 线段确实相交；绘制 n 三角形、n 多边形；如果您了解“普通”凸性，请考虑一下 p 凸性， 图 3，*a* 和 *b* 会对您有所帮助。）

当考虑一对 n 线的相对位置时，庞卡利亚几何和欧几里得几何之间的差异就显现出来了。我们已经知道两条不同的 n 线最多可以相交于一点。如果它们不相交，则它们在无穷远处有一个公共点（不可见！），或者即使在不可见的边界上也没有公共点。在第一种情况下，我们将这样的 n 行称为 *parallels*，在第二种情况下 - *superparallels*。如果有一条 n 线 $L(\alpha,\beta$)，那么穿过它外面的点时，只会经过两条平行的 $L(\alpha,\beta)$ n 线（分别对应于无限远的点 $\alpha$ 和 $\beta$；图 4）以及位于平行线之间的无数条超平行线。因此，在庞卡利亚中，相似公理是不公平的（然而，对于我们观察者来说，这并不奇怪——毕竟，庞卡利亚人不知道他们的“直接”公理是“不真实的”！）；这让我们希望庞卡利亚几何将成为罗巴切夫斯基几何。

### 距离和移动

从光学的角度来看，最自然的做法是，将光从点$A$传播到点$B$的时间视为Poincaria中两点$A$和$B$之间的距离：那么n条直线将是其上的点之间的最短线。从物理角度考虑，以这种方式定义的距离 $\rho(A,B)$ 具有欧几里得距离的通常属性：

1. $\rho(A,B)=\rho(B,A)$;
2. 如果$A$、$B$、$C$与$B\in[AC]$位于同一条n线上，则$\rho(A,B)+\rho(B,C)=\rho(A,C)$（光沿n线从$A$传播到$C$，并穿过点$B$）；
3. 对于任何点$A$，$B$，$C$：$\rho(A,B)+\rho(B,C)=\rho(A,C)$ - *三角不等式*，并且仅当$B\in[AC]$时才相等（如果不满足此不等式，则光沿p断线$ABC$传播所需的时间比沿n直线$AC$传播所需的时间更少 - 最快的方式，这不能是）。

对于庞卡莱学派来说，引入的距离$\rho$是主要的（注意相对于光以单位速度传播的距离），他们没有理由用其他任何东西来表达$\rho$；我们很自然地通过欧几里得距离来表达$\rho$。这并不容易：你必须处理光的不均匀运动，并且要计算它所花费的时间，你需要计算积分。因此，我们只给出最终答案：
$$
\rho(A,B)=\ln\dfrac{r'+r}{r'-r},\tag2
$$
其中$r$是点$A$和$B$之间的欧氏距离，$r'$是点$A$和点$B'$之间的欧氏距离，相对于轴$x$与点$B$对称；对数以 $e$ 为底（使用不同的对数底，我们可以得到 $\rho$ 直到一个常数因子）。欧几里得距离的显着之处在于，有许多平面变换可以保留它。这种转变称为*运动*。让我们看看 Poincaria (n-*translations*) 中的位移是什么样的 - 保留 $\rho$ 的转换，因此将 n 行转换为 n 行。

让我们从不留下任何一个点的转换开始。首先，这些是沿 $x$ 轴的常见*平行平移*：$T_a(x,y)=(x+a,y)$。这些并行传输保留了欧几里德距离和光速$c(x,y)=y$，因此光在两点$A$和$B$之间传播所需的时间，即n距离$\rho(A,B)$，当然，n线转换为n线。另一方面，*同位*$F_b(x,y)=(bx,by)$、$b\gt0$，按比例改变欧几里德距离和光速$c(x,y)$，也不会改变光所花费的时间，即n距离$\rho(A,B)$。因此，对我们来说似乎是同位语（中心在 $x$-s 轴上），对庞卡莱人来说似乎是位移。使用指示的 n 次移动，您可以将任意点平移到任意点。例如，点 $(x_0;y_0)$ 通过 n 次移动 $\left(\dfrac{x-x_0}{y_0},\dfrac y{y_0}\right)$ 到达点 $(0;1)$。关于引入的 n 位移 - 让我们称它们为 n-*shifts* - n 直线分为两类：半圆可以单独相互转换，射线可以单独转换（为什么？）。

现在让我们解释一下，如何利用n-位移和引入的n-距离$\rho$的属性，我们可以简单地获得公式（2），通过欧几里德距离表达$\rho$，在特定情况下，当$A$和$B$都在$y$轴上时：$A=(0;y_1)$，$B=(0;y_2)$。让我们把 $\rho(A,B)=\phi(y_1,y_2)$ 放进去，找出函数 $\phi$ 的形式。由于 $\rho$ 保留在以 $O$ 为中心的欧几里得同位之下，则 $$
\phi(by_1,by_2)=\phi(y_1,y_2).\tag{*}
$$

另外，如果$C=(0;y_3)$是$y$轴上的升温点，那么根据上面所说
$$
\phi(y_1,y_2)+\phi(y_2,y_3)=\phi(y_1,y_3).\tag{**}
$$
根据 （*）
$$
\phi(y_1,y_2)=\psi{\left(\dfrac{y_1}{y_2}\right)}=\psi(z_1),\quad
\phi(y_2,y_3)=\psi{\left(\dfrac{y_2}{y_3}\right)}=\psi(z_2),\quad
\phi(y_1,y_3)=\psi{\left(\dfrac{y_1}{y_3}\right)}=\psi(z_3).
$$

考虑到关系式 (**) 和最后三个等式，我们得到
$$
\psi(z_1\cdot z_2)=\psi(z_1)+\psi(z_2),
$$
因此，假设函数$\psi$足够“好”（参见A. Lopshitz的文章“Functional Equations”，«Kvant»，1975年，第1期），$\psi(z)=k\ln z$，其中$k$是直接计算的常数因子。

找到的 n 位移仍然不够：我们没有可以将一种类型（半圆）的 n 条线转换为另一种类型（射线）的 n 条直线的转换。为此，我们添加相对于 n 条线的 n-*对称*。对于射线来说，这是通常的“轴对称”，对于半圆来说，这是反转。 （例如，相对于 n 线 $L(-1,1)$ 的 n 对称性是相对于以 $O=(0;0)$ 为半径的圆的反演；它采用与中心 $O$ 不同的点 $A$ 到位于射线 OA 上的点 $A'$，使得 $|OA|\cdot|OA'|=1$）。我们知道，在反演过程中，圆和直线变成圆或直线，并且角度的值被保留。在 Poincaria 语言中，这意味着，例如，相对于 n 线 $L(-1,1)$ 对称，n 线 $L(\alpha,\beta)$ 进入 n 线 $L{\left(\dfrac1\alpha,\dfrac1\beta\right)}$。特别是，n 线$L(\alpha,0)$（$\alpha\ne\infty$ 的半圆）被变换为n 线$L{\left(\dfrac1\alpha,\infty\right)}$（射线）。因此，n 对称性将 Poincaria 纳入自身，n 线纳入 n 线。单独检查（我们省略此检查）n 对称性不会改变 n 距离$\rho$。 （然而，在庞卡利亚中，任何将 n 线转化为 n 线的变换都会保留 $\rho$（这里没有同调）；这是罗巴切夫斯基几何和欧几里得几何之间最重要的区别。）

通过将 n 位移与 n 对称性相结合可以获得的 n 位移已经足以将任何 n 线变换为任何 n 线；此外，第一个 n 线的任何给定点可以与第二个 n 线的给定点组合，任何 n 射线与另一个 n 射线组合（证明它！）。这意味着这些n个运动可以组合任意n个长度相等的n段，并且我们得到这些段是n全等的。可以看出，所有 n 位移都减少到所描述的那些。

通过 n 次平移，角度会转换为欧几里得意义上的等于它的角度（因为对于平行平移、同调、轴对称和倒转来说都是如此）。因此，庞卡利亚中角度全等的概念与欧几里得没有什么不同。考虑到这种情况，庞卡利亚人就像我们一样，将证明三角形全等的两个符号：通过两条边和它们之间的角，以及通过一条边和与它相邻的两个角。证明三角形全等的第三个标准（三边）时，情况会更加复杂：毕竟，我们对该标准的证明使用了圆最多相交两个点的事实。幸运的是，事实证明，n 圆与欧几里得圆重合（完全位于上半平面），只是它们的 n 中心与通常的圆不重合（这是一个相当困难的事实），因此一切都符合 Poincaria 的三边全等符号。然而，在 Poincaria 中，三角形全等还有另一个标志：*具有成对全等角的三角形是全等的*！ （将此陈述翻译成欧几里得几何语言并尝试证明它；参见图 5和问题4。）这意味着Poincaria中三角形的面积（就像三角形本身一样）由其角度$\alpha$、$\beta$和$\gamma$的值决定。在罗巴切夫斯基几何中，三角形的内角和小于$\pi$。值$\pi-(\alpha+\beta+\gamma)$称为*三角形缺陷*。可以看出，三角形缺陷的行为与区域相同；更准确地说：如果给定的三角形被穿过其顶点的直线切割，则其面积将等于所得三角形的面积之和；对于任何三角形的缺陷也是如此：它等于所得三角形的缺陷之和 (图 6)。由此我们可以得出洛巴切夫斯基几何中三角形的面积与缺陷$\pi-\alpha-\beta-\gamma$成正比。

### 凤凰木中的固体

到目前为止，在我们所有的几何考虑中，我们仅以光学前提为指导。这里必须强调的是，庞加莱几何被证明是非欧几里得几何，并不是因为庞加莱的光学定律与我们的不同：我们在自己的世界中构建（*模型*）庞加莱几何，并且不改变物理定律！庞卡利亚人的视错觉可以用他们世界的光学异质性来解释。

当然，虽然直线最亮的实现是光束，但我们仍然不使用光的传播时间来测量长度 - 为此我们有一把尺子。买一把尺子和一把庞卡莱也许是值得的。当然，庞卡利亚人会制作一把“p-*直*”的尺子；但是，如果庞卡利亚人将这样的尺子从一个地方移动到另一个地方，那么对他来说，它将不再显得“直”（s-直）。从庞卡莱观点来看，当刚体移动时，其形状会发生变化。庞卡莱人对此应如何反应？显然，刚体的概念必须以某种方式与庞卡利亚几何学联系起来，否则庞卡利亚人将不得不相信超自然力量的存在。亨利·庞加莱想出了一个巧妙的方法来摆脱这种看似绝望的局面：*他利用了物体的热膨胀现象*。

令庞卡利亚中的所有物体具有相同的热膨胀系数和零导热系数，并且物体的大小与绝对温度$T$成正比。 （请注意，在这些条件下，庞卡莱学无法使用普通温度计测量温度，因为这种测量涉及比较具有不同热膨胀系数的物体的膨胀。）刚体的特征在于，当在恒温介质中移动时，其任意两个点 $A$ 和 $B$ 之间的距离 $r(A,B)$（欧几里德）保持不变。但如果物体从温度$T_1$的区域移动到温度$T_2$的区域，则其点之间的距离将乘以$\dfrac{T_2}{T_1}$，换句话说，比率$\dfrac{r(A,B)}T$将保持不变。如果身体立即发现自己处于不同温度的区域会发生什么？在这些条件下将保持什么价值？例如，让一个足够大的固体在介质中移动，其中某条线 $m$ 的一侧温度为 $T_1$，另一侧为 $T_2$；设 $A$ 为物体位于温度 $T_1$ 区域的点，$B$ 为物体位于温度 $T_2$ 区域的点。让我们画一条断线，其端点为点 $A$ 和 $B$，顶点 $C$ 位于线 $m$ 上。让我们表示 $|AC|=r_1$、$|CB|=r_2$ 并考虑值 $\dfrac{r_1}{T_1}+\dfrac{r_2}{T_2}$。事实证明，当在这样的温度环境中移动时，沿着所有顶点在直线$m$上的折线，并在两个给定点$A$和$B$处结束，数量$\dfrac{r_1}{T_1}+\dfrac{r_2}{T_2}$的最小值被保留！接下来，我们可以重复与应用费马原理时完全相同的推理，例如推导斯涅尔折射定律，我们将得到所需的最小值将对应于$\dfrac{\sin\alpha_1}{T_1}=\dfrac{\sin\alpha_2}{T_2}$的折线，其中$\alpha_i$是折线对应的连线与直线法线$m$的夹角。

现在，让 Poincaria 点 $(x;y)$ 的绝对温度 $T(x,y)=y$ 持续保持。然后，由于所选择的温度状态，在固体（在我们的意义上！）运动过程中，将保留n-距离，而不是欧几里德距离，并且从庞卡里亚人的角度来看（毕竟，他们感觉不到温差！）在这种介质中运动的物体的尺寸被保留，即它是n-固体。剩下需要注意的是，所有物体都具有较小的热容，并且移动缓慢以达到热平衡，并且庞卡莱人无法察觉温度的变化。结果，庞卡莱人不仅看不到世界的边界，而且永远无法到达它：当接近边界时，温度趋于绝对零，因此物体的大小将趋于零，而物体之间的比例不会改变。亨利·庞加莱（Henri Poincaré）试图排除庞加莱学派了解他们的非欧几里得世界仅仅是在我们的欧几里得世界中构建的所有可能性。但他预见到了一切吗？如果您发现任何未开发的庞卡莱特征，请写信给我们。
