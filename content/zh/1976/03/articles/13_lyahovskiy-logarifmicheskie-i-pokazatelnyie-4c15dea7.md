对数和指数...

竞争性大学考试中提供的大多数数学任务都涉及求解方程和不等式。

对于最简单的问题，例如二次方程和线性方程组，有通用的求解方法。在大多数情况下，没有规则允许通过对方程的系数顺序执行算术运算和初等运算来求解方程。因此，在研究指数和对数方程以及不等式时，仅考虑部分解。

方程

求解方程时，广泛使用方程两边的变换。

关于极限 1. 如果一个方程的所有根都是另一个方程的根，则第二个方程称为第一个方程的结果。

关于极限2。如果两个方程具有相同的根，则它们被称为来自一组未知值的等价（equivalent）

属于这个集合，也就是说，如果它们中的每一个都是另一个的结果。

很自然地，只应用这样的变换，其中每个后续方程在它们之间的距离上等于前一个方程（下面，除非另有说明，我们指的是所有实数的集合）。那么最后一个方程的解也将是原方程的根。

然而，这种解决方案并不总是可行。否则，用不等价的结果替换方程，然后检查根，看看其中是否存在构造的根。

让我们首先回顾一下几个基本定理。

定理1. 对于$a > 0, a \neq 1$，方程$a^{f(x)} = a^{\varphi(x)}$等价于方程$f(x) = \varphi(x)$。

定理 2. 对于 $a > 0, a \neq 1$，方程 $\log_a f(x) = \log_a \varphi(x)$ 等价于任何系统

$$\begin{cases} f(x) = \varphi(x), \\ f(x) > 0, \\ \varphi(x) > 0. \end{cases}$$

请注意，如果根的构造仅作为扩大未知数的允许值（APV）范围的结果出现，那么您可以通过检查它们是否包含在APV中，或者直接将它们代入原始方程或代入与原始方程等效的方程，将它们与原始方程的根分开。如果不是由于ODZ的扩展而可能出现多余的根，则需要代入原方程或中间方程中可能出现这些根的解中进行检查。

在大多数随机情况下，求解对数或指数方程的主要困难是变换原始方程，直到可以应用定理 1 或 2。但在这样做时，必须仔细监视 ODZ 的变化。忽视这一点往往会导致决策失误。

因此，例如使用对数公式
$$\log_a xy=\log_a x+\log_a y,$$
$$\log_a \frac{x}{y}=\log_a x-\log_a y,$$
$$\log_a x^p=p\log_a x,$$
申请者经常忘记他们的左侧和右侧的 ODZ 并不重合。

事实上，匹配零件规则（1）和（2）是针对值$x>0$和$y>0$定义的。这个不等式由填充第一个坐标角 (图 1) 的点的坐标来满足。同时，当符号$x$和$y$重合时，对应关系（1）和（2）的左侧才有意义。

因此，例如，当从表达式$\log_a xy$移动到表达式$\log_a x+\log_a y$时，ODZ存在（在第三坐标角处），这可能导致解的丢失。

等式(3)的右侧仅针对$x>0$定义，左侧的ODZ取决于指数$p$。如果 $p$ 是整数，则等式 (3) 的左边对于负 $x$ 也有意义。因此，从表达式$\log_a x^p$移动到表达式$p\log_a x$也会导致解的丢失。

对数公式的最佳示例如下：

$$\log_a xy = \log_a |x| + \log_a |y|,$$
(1a)
$$\log_a \frac{x}{y} = \log_a |x| - \log_a |y|,$$
(2a)

$$\log_a x^p = p \log_a |x| (p - \text{четное}).$$
(3a)

现在公式(1a)和(2a)的右侧定义为$x \neq 0$和$y \neq 0$。坐标平面上的所有点都满足这些条件，但位于轴 (图 3) 上的点除外，并且当从表达式 $\log_a xy$ 移动到表达式 $\log_a |x| + \log_a |y|$ 时，未知数的 ODZ 不存在，但会扩展（比较 图 2 和 图 3）。排除了失去解的可能性，但可能会出现根的构建。在等式(3a)中，左右两侧的ODZ重合：$x \neq 0$。

避免更改 ODZ 的第二种方法是从一个方程转移到等效方程组或方程组（不等式）。因此，方程$\log_a \frac{x}{y} = c$等价于方程组$\log_a x - \log_a y = c$、$\log_a (-x) - \log_a (-y) = c$。

问题 2. 求解方程

$$\lg (x + 10) + \frac{1}{2} \lg x^2 = 2 - \lg 4.$$

未知的 ODZ：$x > -10, x \neq 0$。从$\frac{1}{2} \lg x^2 = \lg |x|$开始，我们将方程简化为$\lg (x + 10) + \lg |x| + \lg 4 = 2$形式，从而得到$\lg [4 |x| (x + 10)] = \lg 100$。根据定理 2，最后一个方程等价于：

$$4 |x| (x + 10) = 100$$

（从 $100 > 0$ 开始，不等式成立）。考虑两种情况并求解相应方程：

a) $x > 0, x^2 + 10x - 25 = 0$,
b) $-10 < x < 0, x^2 + 10x + 25 = 0$，我们找到两个根：$x_1 = -5 + 5\sqrt{2}, x_2 = -5$。

通常，方程或方程组的解可以通过引入新变量来简化。

任务 3（ZIL 工厂技术学院，1974 年）。解方程

$$\left( \sqrt{7 + \sqrt{48}} \right)^x + \left( \sqrt{7 - \sqrt{48}} \right)^x = 14.$$

让我们表示$\left( \sqrt{7 + \sqrt{48}} \right)^x = u$，$\left( \sqrt{7 - \sqrt{48}} \right)^x = v$。然后系统

$$\left\{ \begin{array}{l} u + v = 14, \\ uv = 1 \end{array} \right.$$

在 $u > 0, v > 0$ 处将等价于原始方程。她的解决方案：

$$u_1 = 7 + \sqrt{48}, v_1 = 7 - \sqrt{48};$$
$$u_2 = 7 - \sqrt{48}, v_2 = 7 + \sqrt{48}.$$

让我们把$u_2$和$v_2$写成这样的形式：$u_2 = (7 + \sqrt{48})^{-1}, v_2 = (7 - \sqrt{48})^{-1}$。返回原始变量，我们找到$x_1 = 2, x_2 = -2$。

$[f(x)]^{\phi(x)} = [g(x)]^{h(x)}$ 形式的方程通常使用定理 2 求解，即对方程取一定底数的对数。

问题 4（莫斯科地质研究所，1975 年）。解方程

$$x^{\lg^2 x^2 - 3\lg x - 4,5} = 10^{-2\lg x}.$$

未知的 ODZ：$x > 0$。考虑到这一点，原方程等价于方程

$$\lg \left( x^{\lg^2 x^2 - 3\lg x - 4,5} \right) = \lg \left( 10^{-2\lg x} \right),$$

通过替换，$\lg x = t$与三次方：$t (8t^2 - 6t - 5) = 0$重合，根为$t_1 = 0, t_2 = 1, 25$和$t_3 = -0, 5$。返回原始变量，我们发现：$x_1 = 1, x_2 = 10\sqrt[4]{10}$和$x_3 = \sqrt[10]{10}$。

$$\left\{ \begin{array}{l} (x + y)^{\frac{1}{x-y}} = 2\sqrt{3}, \\ (x + y) \cdot 2^{y-x} = 3. \end{array} \right.$$

问题 6（MIPT，1975）。解方程
$$9^{\log_3(1 - 2x)} = 5x^2 - 5$$.

让我们变换方程的左侧，考虑基本对数恒等式和次数的属性：$9^{\log_3(1 - 2x)} = (3^2)^{\log_3(1 - 2x)} = [3^{\log_3(1 - 2x)}]^2 = (1 - 2x)^2$。方程 $(1 - 2x)^2 = 5x^2 - 5$ 是与原方程不等价的结果。事实上，它的第一个根$x_1 = -2 - \sqrt{10}$满足原始方程，因为它包含在ODZ中，并且构造的第二个根$x_2 = -2 + \sqrt{10}$是在替换表达式$9^{\log_3(1 - 2x)}$时扩展ODZ的结果，这在$x < 0,5$处是有意义的，而表达式$(1 - 2x)^2$为参数的任何值定义。

问题 7（MIPT，1974 年；MAI，1975 年）。解方程
$$\log_3(\log_2 x - 9) = 2 + \log_3(1 - 4 \log_2 x)$$.

由于$2 + \log_3(1 - 4 \log_2 x) = \log_3[9(1 - 4 \log_2 x)]$，则理论上

$$\begin{cases} \log_2 x - 9 = 9(1 - 4 \log_2 x), \\ \log_2 x - 9 > 0. \end{cases}$$

从$\log_2 x = t$开始，我们得到系统

其解是$t = 12$，因此$x = 4096$。请注意，如果我们将方程限制在不等式的混合系统中，那么就会出现构造的根 $x = 64$ 。

问题 8（密歇根州立大学地理系，1972 年；ZIL 植物技术学院，1974 年）。求解系统方程
$$\begin{cases} 2\log_4 x^2 + \log_0.2 y^3 = -1, \\ 2\log_4 x^4 - \log_0.2 y = 5. \end{cases}$$

在未知数的允许值区域内，由条件 $x \neq 0$ 和 $y > 0$ 确定，该系统等价于
$$\begin{cases} 4\log_4 |x| + 3\log_0.2 y = -1, \\ 8\log_4 |x| - \log_0.2 y = 5, \end{cases}$$

线性相对 $\log_4 |x|$ 和 $\log_0.2 y$。该系统有唯一解$\log_4 |x| = 0,5$、$\log_0.2 y = -1$，因此有$x = \pm 2$、$y = 5$。如果我们忽略模型的符号，那么在取对数时解（-2；5）将会丢失。

有时使用公式 $b^{\log_a c} = c^{\log_a b}$ 很有用，该公式对于正数 $a$、$b$ 和 $c$ 以及$a \neq 1$ 有效。真的吗，
$b^{\log_a c} = (a^{\log_a b})^{\log_a c} = (a^{\log_a c})^{\log_a b} = c^{\log_a b}$

问题 9（莫斯科矿业学院，1975 年）。解方程
$$5^{\lg x} = 50 - x^{\lg 5}$$.

让我们找到 ODZ：$x > 0$。根据所考虑的公式$x^{\lg 5} = 5^{\lg x}$，因此原方程等于单独方程$2 \cdot 5^{\lg x} = 50$，从而得到$5^{\lg x} = 5^2$、$\lg x = 2$、$x = 100$。

问题 10（莫斯科电子技术学院，1975 年）。如果已知$xy$、$x^x$、$\frac{1}{y}$是几何过程的连续项，$a$ log$_x(y+1)$、$-0.5$、$\log_x(2-y)$是算术过程，求$x$和$y$。

问题条件可以写成以下形式
$$\begin{cases} x^{2x} = xy \cdot \frac{1}{y}, \\ \log_x(y+1) + \log_x(2-y) = -1. \end{cases}$$

找到您自己的系统解决方案。答案：$x = 0,5$； $y = 1$。

任务 11（路易斯安那州立大学心理学系，1970 年）。解方程
$$\log_{\sqrt{2-x^2}}(2x^2+a) = 4.$$

这是一个带有参数的方程。解决它意味着指出在参数的什么值下存在解决方案以及它们是什么。在求解此类方程时，检查方程的等价性起着特别重要的作用，因为验证通常很困难。

代入 $x^2 = t$，我们将方程简化为以下形式
$$\log_{\sqrt{2-t}}(2t+a) = 4.$$

最后一个方程与 $t \geq 0$ 的原始方程等效（受变化 $x^2 = t$ 影响）。在ODZ中，我们定义对应关系$2-t > 0$、$2-t \neq 1$、$2t+a > 0$，它等价于方程$2t+a=(2-t)^2$，其根为$t_1=3+\sqrt{5+a}$、$t_2=3-\sqrt{5+a}$。这些根存在于$a \geq -5$。根$t_1$不包含在任意$a$处的ODZ中，并且根$t_2$包含在$-4 < a < -1$和$a > -1$处。不等式 $t_2 \geq 0$ 对于 $a \leq 4$ 成立（检查！）。回到原始变量，我们得到：
$$x = \pm \sqrt{3-\sqrt{5+a}}$$

在$-4 < a < -1$、$-1 < a \leq 4$；对于剩余的$a$，没有解决方案。

不平等现象

求解不等式所需的基本定义与方程的相应定义几乎相同。上面所说的关于改变 ODZ 的变换也适用于不平等。然而，求解不等式有其自身的特点，需要充分了解其中包含的函数的性质。特别是，必须记住，指数函数和对数函数的性质对于大于或小于 1 的基数是不同的：对于 $a > 1$，函数 $y = a^x$ 和 $y = \log_a x$ 单调递增，对于 $0 < a < 1$，函数 $y = a^x$ 和 $y = \log_a x$ 单调递减。

从这些性质可以得出重要的定理。

定理3. $0 < a < 1$ 的不等式$a^{f(x)} < a^{\varphi(x)}$ 等价于不等式$f(x) > \varphi(x)$，$a > 1$ 等价于不等式$f(x) < \varphi(x)$。

定理 4. $0 < a < 1$ 的不等式 $\log_a f(x) < \log_a \varphi(x)$ 等价于不等式系统
$$\begin{cases} f(x) > \varphi(x), \\ \varphi(x) > 0, \\ a \neq 1 \text{ и } a > 1 \end{cases}$$

$\log_a f(x) > c$ 和 $a^{f(x)} > d$ ($d > 0$) 形式的不等式；一起 > 可以表示 $\leq$，<, <=) 可以使用公式 $c = \log_a a^c$ 和 $d = a^{\log_a d}$ 得出定理 3 和 4 中考虑的形式。

在求解指数和对数不等式时，经常使用积分方法。

问题 13（莫斯科矿业学院，1975 年）。解决不平等问题
$$\log_2^4 x - \log_0.5^2 \frac{x^3}{8} + 9 \log_2 \frac{32}{x^2} <

不等式的 ODZ 具有 $x > 0$ 的形式。请注意，在 ODZ
$$\log_0.5 \frac{x^3}{8} = \log_2 \frac{8}{x^3} = 3(1 - \log_2 x),$$
$$\log_2 \frac{32}{x^2} = 5 - 2\log_2 x,$$
$$\log_0.5 x = -\log_2 x,$$
理论上，原始不等式等价于：
$$\log_2^4 x - 13 \log_2^2 x + 36 < 0.$$
代入$\log_2 x = t$，因式分解后得到不等式$(t + 3)(t + 2)(t - 2)(t - 3) < 0$。他的解决方案（参见图4）：$-3 < t < -2$，$2 < t < 3$。让我们返回到原始变量：$-3 < \log_2 x < -2$、$2 < \log_2 x < 3$，其中：$0,125 < x < 0,25$ 和 $4 < x < 8$。

问题 14（莫斯科电子工程学院，1974 年）。解决不平等问题
$$0,3^{\log_0.25 \log_2 \frac{3x+6}{x^2+2}} > 1.$$
根据定理 3，这个不等式
$$\log_0.25 \log_2 \frac{3x+6}{x^2+2} < 0,$$
最后一个是不等式$\log_2 \frac{3x+6}{x^2+2} > 1$，由此而来$\frac{3x+6}{x^2+2} > 2$。两边乘以$x^2 + 2$（这个表达式对于任何实数$x$都是正数），我们得到$2x^2 - 3x - 2 < 0$或$2(x+0,5)(x-2) < 0$，因此$-0,5 < x < 2$。

求解以对数或幂为底的包含参数或未知数的不等式时，需要分别考虑底值的积分$(0; 1)$和$(1; +\infty)$。

问题 15（莫斯科大地测量研究所，航空摄影和制图工程师，1975 年）。解决不平等问题
$$(x^2 - x + 2)^{\log_0.6 \frac{2x-3}{x+1}} > 1.$$
由于度 $x^2 - x + 2$ 的底数对于任何实数值 $x$ 都是正的（检查！），这个不等式相当于系统的总体
$$\left\{ \begin{array}{l l} x^2 - x + 2 < 1, \\ \log_0.6 \frac{2x-3}{x+1} < 0, \\ \log_0.6 \frac{2x-3}{x+1} > 0. \end{array} \right.$$
在所有实数集合上，不等式 $x^2 - x + 2 < 1$ 无解，并且不等式 $x^2 - x + 2 > 1$ 满足任意 $x$（证明一下！）。因此系统无解，第二个不等式
$$\log_0.6 \frac{2x-3}{x+1} > 0, \text{ т. е. } 0 < \frac{2x-3}{x+1} < 1.$$

$$\log_{a+x}[x(a-x)]<\log_{a+x}x$$
