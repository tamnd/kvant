让我们把这些点连接起来......

数学可以通过不同的方式来研究。你可以听讲座，也可以只看一本书，连续阅读：定义、定理、证明。或者你可以采取更积极的行动：只阅读定理的定义和陈述，把书放在一边，自己想出证明。第一种方法允许目标移动得更快。但是，那些只坚持这种信息技术方法的人的误解，经常会通过技术和方法来获得相关结果。读者不知道他会错过多少有趣、迷人、有用的东西，注定自己会成为一个被动的真理感知者。

第二种方法虽然需要更多的时间，但可以让你深入理解数学理论，教你在给定的背景下突出什么是最重要的，可以长时间记住自己工作中获得的结果，培养小学生的数学能力，为他们应用数学知识开辟新的途径。因此，正是这种方法——对已知真理的独立发现（有时违反了以前未知的真理的发现）决定了数学研讨会、学校和圈子在工作中的使用。

在“数学圈”版块发表的文章中，读者所要做的正是这种积极的工作。文章内容的重要部分通常以任务的形式呈现。其中一些问题在文本中得到了解决，但大多数问题（无论是在讲座中还是在困难的问题中）都留给读者独立决定。这些问题的简要解决方案、说明或答案有时会放在杂志的最后几页，但我们建议您尝试在没有提示的情况下解决问题。

通常，我们的“数学俱乐部”面向 8 至 9 年级的学生，有时也面向 7 年级的学生。有关本节的意见和建议的信件应使用信封上的“数学圈”发送。

如果这个线性组合中的系数之和等于1，我们将称该线性组合为归一化。将来，我们将主要使用归一化的点线性组合，而不是每次都对此进行限制。

$n$点的归一化线性组合的概念具有简单的机械含义：让点$A_1, A_2, \dots, A_n$包含质量$\mu_1 > 0, \mu_2 > 0, \dots, \mu_n > 0$和$\mu_1 + \mu_2 + \dots + \mu_n = 1$。线性组合 $\mu_1 A_1 + \mu_2 A_2 + \dots + \mu_n A_n$ 是 $n$ 质量系统的重心 C（参见练习 14）*)。

然后$H = \lambda E = \lambda \left( \frac{1}{2} B + \frac{1}{2} C \right) = \frac{\lambda}{2} B + \frac{\lambda}{2} C$

（我们不知道数字$\lambda$等于什么）。另一方面，H点位于线BK上；因此$H = \alpha B + \beta K = \alpha B + (1 - \alpha) K$，即$H = \alpha B + \frac{1 - \alpha}{2} C$。

$$\begin{cases} \frac{\lambda}{2} = \alpha, \\ \frac{\lambda}{2} = \frac{1 - \alpha}{2}. \end{cases}$$

解决这个系统后，我们得到$\lambda = \frac{2}{3}$，$\alpha = \frac{1}{3}$，由此得到$\beta = \frac{2}{3}$。这些系数值给出了以下线段长度比率：$|AH| : |HE| = 2:1$、$|BH| : |HK| = 2:1$。仍有待证明 H 属于三角形的中线。从$H = \frac{2}{3} E$开始，然后$H = \frac{1}{3} (B + C)$。但是$B = 2T$，其中T是边AB的中点。因此$H = \frac{1}{3} (2T + C)$，即$H = \frac{2}{3} T + \frac{1}{3} C$。系数之和为1，均为正，因此H是线段CT上按2:1的比例划分的点。
