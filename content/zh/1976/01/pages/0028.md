定理 2. 数

$$\alpha = c_0 + \frac{c_1}{10} + \frac{c_2}{10^{21}} + \frac{c_3}{10^{31}} + \dots + \frac{c_k}{10^{k1}} + \dots,$$

food $c_0$ 是任意整数，$c_1, c_2, \dots$ 取值 0, 1, 2,..., 9 之一并且从某一点开始连续不等于 0 - 先行。

证明。让我们把

$$c_0 + \frac{c_1}{10} + \frac{c_2}{10^{21}} + \dots + \frac{c_k}{10^{k1}} = \frac{p}{q}.$$

然后

$$\alpha - \frac{p}{q} = \frac{c_k+1}{10^{(k+1)1}} + \frac{c_k+2}{10^{(k+2)1}} + \dots > 0,$$

并且从 $q = 10^{k1}$ 开始，那么

$$\alpha - \frac{p}{q} = \frac{c_k+1}{q^{k+1}} + \frac{c_k+2}{q^{(k+1)(k+2)}} + \dots.$$

从这里

$$\alpha - \frac{p}{q} \leqslant 9 \left( \frac{1}{q^{k+1}} + \frac{1}{q^{(k+1)(k+2)}} + \dots \right) < \frac{9}{(q-1)q^k}.$$

为了证明数$\alpha$的超越性，让我们假设相反的数——它是代数的；则$\alpha$满足式(1)，其系数为整数。让我们用 $d$ 表示从根 $\alpha$ 到方程其他实根的最短距离。

代入$A = |\alpha| + d$，利用公式（5）计算出数$M$，并选择足够大的自然数$k$，使得同时满足以下三个不等式：

$$k > n, \frac{9}{(q-1)q^k} < d,$$

$$\frac{9}{(q-1)q^{k-n}} < \frac{1}{M}.$$

由于不等式（9）和条件（10）的平均值，$\frac{p}{q}$小于$\alpha$的$d$，因此$\frac{p}{q}$不是等式（1）的根。因为

$$\left| \frac{p}{q} \right| = \left| \alpha - \left( \alpha - \frac{p}{q} \right) \right| \leqslant \leqslant |\alpha| + \left| \alpha - \frac{p}{q} \right| < |\alpha| + d = A,$$

则满足定理1的条件，因此，

$$\left| \alpha - \frac{p}{q} \right| \geqslant \frac{1}{Mq^n}.$$

另一方面，根据不等式（9）和条件（10）的最后一个

$$\left| \alpha - \frac{p}{q} \right| < \frac{1}{Mq^n}.$$

因此，$\alpha$是代数数的假设导致了矛盾的不等式（11）和（12）。因此，$\alpha$是超越数。

因此，定理 2 允许我们构造超越数。即，可以从任意无限分数中得到一个超越数，其中从某些数字开始，并非所有数字都是零，使用以下方法：将小数点后第$k$位与数字$k!$放在一起，并用hylas填充其余位置。例如，从数字 0.314159... 获得以下超越数：

$$0,3100040 \dots 010 \dots 050 \dots$$
