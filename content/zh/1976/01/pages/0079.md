1. 从能量守恒定律
$$\frac{m + m'}{2} v_1^2 = \frac{m + m'}{2} v_2^2,$$
其中$m = V\rho_0$（V 是棒的体积），
$m'_1 = V\rho \frac{r^2}{R_1^2 - r^2}$（ρ – 水密度），
$m'_2 = V\rho \frac{r^2}{R_2^2 - r^2}$，我们发现
$$v_2 = v_1 \sqrt{\frac{\rho_0(R_1^2 - r^2) + \rho r^2}{\rho_0(R_2^2 - r^2) + \rho r^2}}.$$
2. $T = 2\pi \sqrt{\frac{m + 2/3\pi R^3\rho}{\pi r^2\rho g}}$。 （关于该问题的解决方案，例如，参见«Kvant»，1974年，第6期，第36页。只需将m替换为$m + m' = m + \frac{1}{2}V\dot{\rho}$即可。）
3. 让我们写下关于杆、在杆和管壁之间移动的水的质量 $m_1 = \pi(R^2 - r^2)l\rho$ 以及剩余的静止水质量 $m_2 = \pi R^2(L - l)\rho$ 的牛顿第二定律：

$$ma = F_{BbT1} + F_{BbT2} - mg,$$
$$-m_1a_1 = -m_1g - F_{BbT1} - F_1,$$
$$0 = -m_2g - F_{BbT2} + F_1 + F.$$

这里$F_{BbT1}(F_{BbT2})$是运动（静止）水作用在杆上的力，$F_1$是运动和静止水之间的相互作用力，$F$是管底部作用在静止水上的力。将所有三个方程相加后，我们消除了力 $F_{BbT1}, F_{BbT2}$ 和 $F_1$。请注意$\frac{a_1}{a} = \frac{v_1}{v} = \frac{r^2}{R^2 - r^2}$。然后经过简单的变换我们得到：

$$F = (m + m_1 + m_2)g - a(V\rho - m) = \pi(R^2L - r^2l)\rho g + mg - \frac{(V\rho - m)^2}{m + \frac{V\rho r^2}{R^2 - r^2}}.$$

这说明水压在底部的力（数值上等于力F）小于水和杆的总重量。此外，当杆漂浮（$V\rho > m$）和下沉（$m > V\rho$）时都是如此。
