如果$a=c$，则三角形$ABC$是等边三角形：$a=b=c$（自$a \leq b \leq c$），我们将此条件作为条件$2b^2=a^2+c^2$的特例获得。

容易看出，如果$2b^2=a^2+c^2$，则条件(2)也成立。因此，如果三角形$ABC$的长度$a, b$和$c$（$a \leq b \leq c$）边通过关系$2b^2=a^2+c^2$相关，则该三角形类似于由其中线组成的三角形。

c) 同样，我们需要找出三角形 $ABC$ 的哪些边和由其 bissertrices 生成的三角形可以相似（假设这些三角形相似）。例如，我们有什么$a \leq b \leq c$。那么让我们证明$l_a \geq l_b \geq l_c$。

让我们用$a, b$和$c$来表达$l_a, l_b$和$l_c$。根据三角形内角的余弦定理和比塞特里定理，我们有 (图 10)：

$$l_a^2 = c^2 + \left( \frac{ac}{b+c} \right)^2 - 2c \frac{ac}{b+c} \cos B = c^2 + \left( \frac{ac}{b+c} \right)^2 - \frac{2ac^2}{b+c} \cdot \frac{a^2+c^2-b^2}{2ac} = bc \left[ 1 - \frac{a^2}{(b+c)^2} \right].$$

$$l_b^2 = ac \left[ 1 - \frac{b^2}{(a+c)^2} \right] и l_c^2 = ab \left[ 1 - \frac{c^2}{(a+b)^2} \right].$$

自从 $a \leq b$，我们得到 $b+c \geq a+c$， 那是 $\frac{a}{(b+c)^2} \leq \frac{b}{(a+c)^2}$， 和 $\frac{a^2b}{(b+c)^2} \leq \frac{ab^2}{(a+c)^2}$;因此， $c \left[ b - \frac{a^2b}{(b+c)^2} \right] \geq c \left[ a - \frac{ab^2}{(a+c)^2} \right],$ 那是 $l_a \geq l_b$。不等式 $l_b \geq l_c$ 类似地证明。

所以如果一个三角形 $ABC$ ($a \leq b \leq c$) 类似于 bissertisse 三角形，则必须满足等式 $l_c:l_b:l_a = a:b:c$， 那是 $\frac{l_c}{l_a} = \frac{a}{c}$ 和 $\frac{l_b}{l_a} = \frac{b}{c}$.

如果 $\frac{l_c}{l_a} = \frac{a}{c}$， 那 $al_a = cl_c$。但类似的关系始终适用于身高： $ah_a = ch_c$ （见a点）。方法 （图 11)、直角三角形 $AH_aL_a$ 和 $CH_cL_c$， 在哪里 $|AH_a| = h_a$, $|AL_a| = l_a$, $|CH_c| = h_c$, $|CL_c| = l_c$，相似，且边长 $h_a, h_c$ 和 $i_a, l_c$ 他们有类似的。因此，边所形成的角 $AH_a$, $AL_a$ 和 $CH_c$, $CL_c$，将相等： $H_a\widehat{AL_a} = H_c\widehat{CL_c}$。让我们计算一下这些角度。
