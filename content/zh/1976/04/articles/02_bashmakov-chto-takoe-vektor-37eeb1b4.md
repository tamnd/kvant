什么是向量？

“向量”这个词出现在数学、物理和应用学科中。这些词表示完全不同的、彼此不相似的对象。因此，在学校几何教科书中，矢量的概念与平行传输（平面或空间）的概念结合在一起。在物理学中，当描述一系列量时，他们说它们具有矢量特征——例如机械运动的速度、吸引力、磁场的方向。允许所有这些对象被称为相同的共同点是什么？您需要如何构建数学理论才能获得同时满足数学和物理需求的概念？这就是文章所讲的内容。

1. 向量空间

数学有一种通过描述新概念的属性来定义新概念的奇妙方法。例如，大多数书籍不是直接定义实数是什么（使用小数或其他东西），而是列出它们的基本属性，这些属性将在将来使用。这种方法被称为公理化，在现代数学中非常常见。学校几何课程的结构与此完全相同。他们将与向量进行类似的构建 - 他们列出了所有向量固有的一般属性，这些属性在数学及其应用中都可以找到。

与往常一样，使用公理化方法，我们将定义的不是单个孤立的“向量”，而是向量的整体 - 向量空间。

向量空间是具有满足特定要求的两个运算的集合M *)。然而，这些运算（通常称为加法）将第三个元素分配给集合 M 的每对元素 a、b（该元素称为元素 a 和 b 的和，表示 a + b）。第二个操作为集合 M 的每个元素 a 和每个实数 λ 分配集合 M 的一个元素，称为元素 a 和数 λ 的乘积（这个“乘积”用 λa 表示）。

让我们列出这些操作必须满足的要求（向量空间公理）：

1°。向量的加法遵循组合（结合）和交换（交换）定律：
$$x + (y + z) = (x + y) + z;$$
$$x + y = y + x.$$

2°。存在一个零向量：0，使得 x + 0 = x。

3°。对于每个向量，都有一个向量与原始向量的和为零向量。
$$4^\circ. (\lambda_1 \lambda_2)x = \lambda_1(\lambda_2x).$$
$$5^\circ. (\lambda_1 + \lambda_2)x = \lambda_1x + \lambda_2x.$$
$$6^\circ. \lambda(x + y) = \lambda x + \lambda y.$$
$$7^\circ. 1 \cdot x = x.$$

这里x，y，z是任意向量，$\lambda, \lambda_1$和$\lambda_2$是任何实数。

1. 线性函数
让我们考虑所有可能的线性函数（给定所有实数的集合 R）。每个这样的函数都等于：$x \rightarrow ax + b$。显然，两个线性函数的和又是一个线性函数。同样，如果将线性函数乘以一个数字，则会再次得到线性函数。此外，满足所有公理$1^\circ - 7^\circ$，因此具有这些运算的线性函数集合是向量空间。

2. 并行传输
让我们考虑平面的所有平行平移的集合。它们可以相加、依次执行、乘以数字。这是你在学校遇到的向量空间。

3. 行距
考虑实数的固定长度字符串$n$：$(a_1, a_2, \dots, a_n)$。让我们定义添加字符串并将它们逐个元素乘以数字：
$$(a_1, a_2, \dots, a_n) + (b_1, b_2, \dots, b_n) = (a_1 + b_1, a_2 + b_2, \dots, a_n + b_n);$$
$\lambda (a_1, a_2, \dots, a_n) = (\lambda a_1, \lambda a_2, \dots, \lambda a_n)$。显然，长度为$n$的字符串通过这样定义的操作形成了一个向量空间。

4. 方形三层公寓
平方三元组$\{ax^2 + bx + c\}$（数字$a, b, c$也可以是零）也形成了一个向量空间，与多项式相加和乘以数字的一般运算有关。

5. 多项式
具有相同运算的所有多项式的集合也形成向量空间。

3. 坐标

让我们回到第一个例子——线性函数的向量空间。

让我们考虑两个函数：
$$f_1: x \rightarrow x,$$
$$f_2: x \rightarrow 1.$$

任何函数$f: x \rightarrow ax+b$都可以表示为这些函数的线性组合：$f=af_1+bf_2$。数字对$(a, b)$称为线性函数$f$的坐标。

值得注意的是，当添加线性函数时，它们的坐标像线一样加起来：
$$f_1: x \rightarrow ax+b \leftrightarrow (a, b),$$
$$f_2: x \rightarrow cx+d \leftrightarrow (c, d),$$
$$f_1+f_2: x \rightarrow (a+c)x+(b+d) \leftrightarrow (a+c,b+d);$$
但
$$(a+c,b+d)=(a,b)+(c,d).$$

我们再举几个例子。在平面平行平移的向量空间中，可以选择两个平行平移（例如，变成两个长度为1的非平行向量），任意平移都分解为这两个平行平移；这种展开的系数称为相应转移的坐标。

考虑长度为 $n=4$ 字符串的向量空间
$$f_1=(1,0,0,0), f_2=(0,1,0,0),$$
$$f_3=(0,0,1,0), f_4=(0,0,0,1).$$

我们可以将任何字符串 $f=(a_1,a_2,a_3,a_4)$ 表示为
$$f=a_1f_1+a_2f_2+a_3f_3+a_4b_4;$$
数字$(a_1,a_2,a_3,a_4)$称为行$f$的坐标。

在平方三项式的向量空间中，对于任意三项式 $f=ax^2+bx+c$ 我们有：
$$f=af_1+bf_2+cf_3,$$
$$f_1=x, f_2=x^2, \dots, f_n=x^n, \dots.$$

然后任意多项式$F$都可以写成所选多项式的有限线性组合；将多项式 $F$ 展开为多项式 $f_0, f_1, \dots$ 的系数是其坐标：
$$F(x)=a_mx^m+a_{m-1}x^{m-1}+...$$
$$...+a_1x+a_0=a_mf_m+a_{m-1}f_{m-1}+...$$
$$...+a_1f_1+a_0f_0 \leftrightarrow (a_m,a_{m-1},...,a_1,a_0).$$

现在我们可以问一些问题。如何在给定空间中选择一个向量系统，该空间的任何向量都可以分解为该向量系统？什么时候可以选择这些系统作为最终系统？分解在多大程度上是唯一的？展开系数与不同的向量系统有何关系？

这些问题的答案由称为线性代数的数学分支提供。以下是一些结果的快速浏览。

1. 反演向量空间有有限维和无限维。在有限维系统中，存在有限的向量系统，空间中的任何向量都可以扩展到其中。在我们的示例中，线性函数、二次三项式、字符串、平行平移和自由向量的空间是有限维的。所有多项式和所有函数的空间都是无限维的。

2. 对于有限维空间，我们可以指定最小数 $n$ ，使得空间中的任何向量都可以扩展到 $n$ 个向量。这个数$n$称为空间的维数。因此，线性函数的空间的维度为 2，即平方三项式的空间
