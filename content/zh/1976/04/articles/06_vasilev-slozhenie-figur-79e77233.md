§ 2. 凸多边形的半和

回想一下，如果对于 F 中的任意两个点 P 和 Q，整个线段 [PQ] 都包含在 F 中，则称一组点 F 为凸点。

你可能已经注意到，求凸图形的半和比非凸图形更重要，如果 F 和 G 是凸图形，那么 F*G 也是凸图形。

我们用 $F_\sigma$ 表示支持集。

设F和G为两个凸多边形，$σ_F$和$σ_G$为同一方向的支撑半平面，$F_\sigma$和$G_\sigma$对应的支撑多边形集。很容易找到半和F*G的同方向支持集：它等于支持多边形$F_\sigma$和$G_\sigma$的半和，即

$$(F * G)_\sigma = F_\sigma * G_\sigma.$$

事实上(图6)，任何线段PQ的中点M，其中P∈F，Q∈G，位于半平面$σ_F * σ_G = \sigma_F * G$内，并且点M可以落在半平面$σ_F * G$的边界直线上当且仅当P∈F_\sigma$ и Q ∈ G_\sigma$时。

§4.图形总和的面积

图形$F$的面积将用$S_F$表示。相似图形面积定理指出：

$$S_{\lambda F} = \lambda^2 S_F.$$

让我们看看关于总和的面积以及一般情况下两个图形的线性组合可以说些什么。让我们从特殊情况开始，$F$和$G$是矩形$a \times b$和$c \times d$，并且长度$a$和$c$的边平行。那么 $\lambda F + \mu G$ 就是矩形 $(\lambda a + \mu c) \times (\lambda b + \mu d)$ 并且

$$S_{\lambda F + \mu G} = (\lambda a + \mu c)(\lambda b + \mu d) = \lambda^2 ab + \mu^2 cd + \lambda \mu (ad + bc) \geq \lambda^2 ab + \mu^2 cd + 2\lambda \mu \sqrt{abcd} = (\lambda \sqrt{ab} + \mu \sqrt{cd})^2,$$

那是

$$S_{\lambda F + \mu G} \geq (\lambda \sqrt{S_F} + \mu \sqrt{S_G})^2.$$

（我们使用了不等式$p + q \geq 2\sqrt{pq}$）。对于给定的$S_F$和$S_G$，不可能获得除不等式（2）之外的对$S_{\lambda F} + \mu G$值的任何限制。事实上，代入 (2) $b = a$、$c = ke$、$d = e|k$（$k$ 是某个正数），我们得到：$S_F = a^2$、$S_G = e^2$、$S_{\lambda F} + \mu G = \lambda^2 a^2 + \mu^2 e^2 + \lambda \mu e \left( k + \frac{1}{k} \right) = (\lambda a + \mu e)^2 + \left( k + \frac{1}{k} - 2 \right) \lambda \mu e$。

$a$、$e$和$\lambda$、$\mu$固定，第二个括号取任意非负值（取决于$k$），因此$S_{\lambda F} + \mu G$可以取任意值，不小于$(\lambda \sqrt{S_F} + \mu \sqrt{S_G})^2$。

现在我们终于可以给出���题 M330中问题的答案了：面积$S_1$和$S_2$所得的凸多边形的面积可以取任何大于或等于$(\sqrt{S_1} + \sqrt{S_2})^2/4$的值。

结果面积不能取更小的值这一事实由以下显着定理得出。

布伦-闵可夫斯基定理。对于任何两个凸数$F$、$G$和任何正数$\lambda$、$\mu$，执行不等(2)。

证明。首先，利用相似性考虑和公式（1），很容易简化为给定图形面积相等的情况，并对线性组合进行归一化。对于这种情况，不等式（2）看起来非常简单：

$$\text{если } S_F = S_G = S \text{ и } \lambda + \mu = 1, \text{ то } S_{\lambda F} + \mu G \geq S.$$

$$F^* = \sqrt{S/S_F} F, \quad G^* = \sqrt{S/S_G} G.$$

然后
$$\lambda F + \mu G = \lambda \sqrt{S_F/S} F^* + \mu \sqrt{S_G/S} G^* = \left( \lambda \sqrt{S_F/S} + \mu \sqrt{S_G/S} \right) \left( \lambda^* F^* + \mu^* G^* \right),$$
其中$\lambda^* + \mu^* = 1$。将 (3) 代入$\lambda^* F^* + \mu^* G^*$，我们得到 (2)：
$$\sqrt{S_{\lambda F} + \mu G} \geq \left( \lambda \sqrt{S_F/S} + \mu \sqrt{S_G/S} \right) \sqrt{S} = \lambda \sqrt{S_F} + \mu \sqrt{S_G}.$$

这是用于证明不等式 (3) 的主要信息。如果图形F被水平线$l$分为两部分：上$F_B$和下$F_H$，类似地，另一条水平线$m$的G被分为$G_B$和$G_H$两部分，则集合$\lambda F_B + \mu G_B$和$\lambda F_H + \mu G_H$彼此不重叠：第一个位于该线之上$\lambda l + \mu m$，下面是第二个。

现在简单来说证明就可以这样完成了。

我们将多边形$F$和$G$分成$N$窄水平条，并从上到下按顺序编号：$F_1 \cup F_2 \cup ... \cup F_N = F$，$G_1 \cup G_2 \cup ... \cup G_N = G$。每条带可以被认为是面积$S/N$的直线（如果$N$很大，这个“直到任意小的ε”不会影响图形$F$、$G$和$\lambda F + \mu G$的面积）。但对于边平行的矩形，主要的不等式（2）已经被证明，因此每个$\lambda F_i + \mu G_i$、$i=1,2,...,N$（我们只添加相同数字的条带！）的面积不小于$S/N$。并且由于这些$N$条带彼此不重叠，并且当然包含在$\lambda F + \mu G$中，因此$S_{\lambda F} + \mu G$的面积不小于$S$。

至此，Brunn-Minkowski 不等式得证。我们在此仅介绍其后果之一。这也是算子定理的替代：任何周长为$P$的图形的面积不再是

高于周长$P$的泥土面积。让我们用凸多边形$F$来证明它。使用问题 8 的符号和结果，我们将 Brunn 不等式应用于总和 $F + K$（K 是单位半径的圆）。我们得到：

$$\sqrt{S + P + \pi} \geq \sqrt{S} + \sqrt{\pi},$$

或者，简化后，$S \leq P^2/4\pi$。这就是我们想要的不平等！
