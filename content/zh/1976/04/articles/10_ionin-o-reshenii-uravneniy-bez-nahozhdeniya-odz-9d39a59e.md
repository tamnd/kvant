许多申请人通过找到可接受值的范围（ADV）开始求解方程或不等式，即确定该方程或不等式的同时左侧和右侧的一组数字。然而，应该记住，并非在所有情况下都需要寻找 ODZ。

例如，如果在求解过程中使用等价变换，那么寻找ODZ就是浪费时间。

实施例 3（MINCH 和 GP，1974）。解决不平等问题
$$\log_2 \log_3 \frac{x+2}{x-2} < \log_{1/2} \log_{1/3} \frac{x-2}{x+2}.$$ (4)

在这里找到 ODZ 需要解决不等式系统

$$\begin{cases} x \neq 2, \\ \frac{x+2}{x-2} > 0, \\ \log_3 \frac{x+2}{x-2} > 0, \\ x \neq -2, \\ \frac{x-2}{x+2} > 0, \\ \log_{1/3} \frac{x-2}{x+2} > 0, \end{cases}$$

这是一项相当艰巨的任务。同时，无需求 ODZ，因为根据不等式 (4)，我们可以得出等价不等式：

$$\log_2 \log_3 \frac{x+2}{x-2} < -\log_2 \log_3 \frac{x+2}{x-2};$$

$$\log_2 \log_3 \frac{x+2}{x-2} < 0;$$

$$0 < \log_3 \frac{x+2}{x-2} < 1;$$

$$1 < \frac{x+2}{x-2} < 3,$$

$$1 < 1 + \frac{4}{x-2} < 3,$$

$$0 < \frac{2}{x-2} < 1,$$

$$\frac{x-2}{x+2} > 1,$$

从那里我们得到解决方案：$x > 4$。

很多时候，在求解无理方程时，找到 ODZ 是不必要的。所以，将方程两边同时平方
$$\sqrt{f(x)} = g(x),$$ (5)

我们得出方程
$$f(x) = |g(x)|^2,$$ (6)

其结果是不等式$f(x) \geq 0$。因此，方程(6)的根总是包含在方程(5)的ODZ中。

实施例 4（密歇根州立大学，物理学家，1968 年）。对于参数 a 的每个值，找到方程的所有解

$$\sqrt{a(2^x - 2) + 1} = 1 - 2^x.$$

在这里找到 ODZ 需要用参数 $a(2^x - 2) + 1 \geq 0$ 求解不等式，但没有这个就可以完成通常的任务。使用$t = 2^x$，我们将这个方程重写为以下形式

$$\sqrt{at - 2a + 1} = 1 - t.$$ (7)

将方程 (7) 的两个时钟部分平方后，我们得到

$$at - 2a + 1 = (1 - t)^2,$$ (8)

从哪里$t_1 = a, t_2 = 2$。对于找到的根，无需检查不等式$at - 2a + 1 \geq 0$的有效性 - 它是等式（8）的结果。只需要检查条件$1 - t \geq 0$（保证式（7）和（8）等价）和条件$t > 0$（由式$t = 2^x$推出）的满足情况；这两个条件都可以毫无困难地验证。

答案：对于$a \leq 0$和$a > 1$没有解；对于$0 < a \leq 1$，有唯一解$x = \log_2 a$。

通常，在求解方程和不等式时，可以“不完全”找到 ODZ，这不是直接对未知数施加必要的限制，而是对未知数的某些表达式施加必要的限制。

示例 5（路易斯安那州立大学，数学，1966 年）。解方程

$$tg \frac{2\pi x}{1 + x + x^2} = \sqrt{3}.$$

《模范》申请人从寻找 ODZ 开始，将面临求解一组方程的需要

$$\frac{2\pi x}{1 + x + x^2} = \frac{\pi}{2} + k\pi$$

($k = 0, \pm 1, \pm 2, \dots$) 来确定未知数的“禁止”值。同时，只要知道 DZ 用术语描述什么就足够了

$$\frac{2\pi x}{1 + x + x^2} \neq \frac{\pi}{2} + k\pi$$ (9)

($k = 0, \pm 1, \pm 2, \dots$)。事实上，原方程与方程组有着不可分割的关系

$$\frac{2\pi x}{1 + x + x^2} = \frac{\pi}{3} + n\pi$$

($n = 0, \pm 1, \pm 2, \dots$)，其根当然满足条件(9)。

使用上述示例，您可以确保 ODZ 的实际计算不是求解方程和不等式的强制要素 - 也仅在确实必要时才进行以下计算。

实施例 6（MIPT，1970）。一名地铁乘客在 24 秒内走下自动扶梯。如果乘客以相同的速度行走，但在静止的自动扶梯上，他可以在 42 秒内下降。他站在自动扶梯的台阶上需要多少秒才能下降？

如果我们用l表示自动扶梯的长度，用v₁和v2表示自动扶梯和乘客的速度，那么创建一个未知数的两个方程组并不困难，从中可以确定初始比率l/v₁（参见«Kvant»，1971年，第5期，第46-47页）。

七年级学生 D. Feofanov（阿拉木图）提供了该问题的算术解决方案。当乘客和自动扶梯同时移动时，乘客在1秒内下降自动扶梯长度的1/24。但在 1 秒内，乘客自己从固定自动扶梯下降到其长度的 1/42。因此，自动扶梯的果冻在 1 秒内移动了自动扶梯长度的$\frac{1}{24} - \frac{1}{42} = \frac{1}{56}$部分，然后在 56 秒内卖掉了它的长度。

例 7. 如果已知，求 sin 2α

$$3 \mathrm{tg}^2 \alpha - 10 \mathrm{tg} \alpha + 3 = 0$$

并且 uol α 满足不等式

$$\frac{5}{4} \pi < \alpha < \frac{3}{2} \pi.$$

国立技术大学（莫斯科）的学生 T. Antipova 向编辑发送了针对这个问题的一个有趣的解决方案。让我们将条件中给出的等式重写为以下形式

$$10 \mathrm{tg} \alpha = 3 (\mathrm{tg}^2 \alpha + 1).$$

从$\mathrm{tg}^2 \alpha + 1 \neq 0$开始，我们从这里得到

$$\frac{2 \mathrm{tg} \alpha}{1 + \mathrm{tg}^2 \alpha} = \frac{3}{5}.$$

如果我们通过给定参数的正切回忆正弦表达式

$$\sin x = \frac{2 \mathrm{tg} \frac{x}{2}}{1 + \mathrm{tg}^2 \frac{x}{2}},$$

那么我们立即发现：sin 2α = $\frac{3}{5}$。请注意，条件 5π/4 < α < 3π/2 被证明是不必要的。
