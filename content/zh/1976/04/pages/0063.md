3. 在没有热损失的情况下，蒸馏器的性能仅由加热器的功率决定。事实上，蒸发（蒸馏）水的质量$\Delta m$取决于释放的热量：$\Delta m \lambda = U^2 \Delta t/R$。

这里$\lambda$是水汽化比热，$R$是加热器的电阻，$U$是蒸馏器所连接的网络的电压。然后$q = \frac{\Delta m}{\Delta t} = \frac{U^2}{R \lambda}$。

让我们分别计算每个螺旋的蒸馏器性能：$q_1 = \frac{U^2}{R_1 \lambda}$ 和 $q_2 = \frac{U^2}{R_2 \lambda}$，对于串联螺旋 ($R_3 = R_1 + R_2$)：$q_3 = \frac{U^2}{(R_1 + R_2) \lambda}$，对于并联螺旋 $\left( R_4 = \frac{R_1 R_2}{R_1 + R_2} \right)$：

$$q_4 = \frac{U^2 (R_1 + R_2)}{R_1 R_2 \lambda}.$$

因此$\frac{q_4}{q_3} = \frac{(R_1 + R_2)^2}{R_1 R_2} = \frac{(q_1 + q_2)^2}{q_1 q_2} = 4,5$。

4. 当线圈中的磁通量发生变化时，会产生电感应力$\mathcal{E}_i = -\frac{\Delta \phi}{\Delta t}$，并且闭合线圈中流过电流$l = \frac{\mathcal{E}_i}{R} = -\frac{1}{R} \frac{\Delta \phi}{\Delta t}$。

根据问题的条件，磁场会杀死均匀的磁场。这意味着线圈中流过恒定电流，因此流过的电荷值为$q = l \Delta t = -\frac{1}{R} \Delta \phi$。

磁通量变化$\Delta \phi = \Phi_2 - \Phi_1 = -BSN = -BN \pi d^2/4$。

$$q = \frac{B \pi d^2 N}{4 R} \approx 5.10^{-3} \kappa.$$

5. 我们将距相机镜头的距离表示为 $d$，将镜头到屏幕的距离表示为 $f$。镜头线性放大倍数$\Gamma = \frac{f}{d e}$。另外，$d + f = L$。因此$d = \frac{L}{1 + \Gamma}$和$f = \frac{\Gamma L}{1 + \Gamma}$。

现在，使用线性公式

$$\frac{1}{F} = \frac{1}{d} + \frac{1}{f},$$

让我们使用公式计算镜头距离：$F = \frac{df}{d + f} = \frac{\Gamma L}{(1 + \Gamma)^2}$，其中$\Gamma = \frac{4 m}{4.10^{-3} m} = \frac{3 m}{18.10^{-3} m} \approx 166,7$。

最后$F = \frac{\Gamma L}{(1 + \Gamma)^2} \approx 10 \text{ cm}$。
