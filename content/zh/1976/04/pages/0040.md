$$I' = I_1 + I_2.$$

因此，
$$U_R = \frac{2\mathcal{E}R}{2r + R} \text{ при } R \geq 2r,$$

F351。在弱冲击的情况下，球对墙壁的作用是它的变形 x，它远小于球的半径 R，并且通过良好的近似，球内的气压 p 在冲击过程中可能不会改变。

忽略轮胎的弹性，估计球撞击墙壁的时间。当球的质量为 m = 0.5 kg、球内压力为 p = 2 atm、半径 R = 12.5 cm 时，对结进行数值计算。

让我们看看在击球过程中影响球的梦想。它们是来自墙壁的反作用力 N 和大气压力 Fa。

根据牛顿第三定律，从球的左侧到墙壁Fd，力N在数值上相等且方向相反。由于球胎的弹性可以忽略不计，则
$$N = F_d = pS = p\pi r^2$$
（$S = \pi r^2$——球与墙壁接触的面积，见图16）。力 N 垂直于墙壁，即水平向右。

为了求大气压，将球与周围影响的接触面的体积分成面积为$\Delta s_i$的小区域。每个区域都受到大气压力$\Delta F_i$（图17）的影响，方向垂直于表面，且绝对值相等$\Delta F_i = p_0 \Delta s_i$（$p_0$—​​大气压力）。由于对称性，很明显，所有力$\Delta F_i$的垂直过程加起来为零，因此球$= \sum \Delta F_i$的平衡方向水平向左且大小相等（参见图17）
$$F_a = \sum \Delta F_i \cos \alpha = p_0 \sum \Delta s_i \cos \alpha.$$
值$\Delta s_i \cos \alpha$是平面的投影，$\sum \Delta s_i \cos \alpha$是这些过程的总和，等于球与周围影响的接触平面的投影，
$$\sum \Delta s_i \cos \alpha = \pi r^2, \text{ и } F_a = p_0 \pi r^2.$$
现在我们来求一下梦想的绝对值 F = N + Fa：
$$F = N - F_a = (p - p_0) \pi r^2 = (p - p_0) \pi [R^2 - (R - x)^2] = (p - p_0) \pi (2Rx - x^2).$$
由于球 x 的变形与其半径 R 相比较小，因此与值 2Rx 相比，可以忽略值$x^2$。那么 F = 2πR (p - p_0) x，或者考虑到该力的方向与变形相反，
$$F = -2\pi R (p - p_0) x = -kx.$$
因此，力F与变形x的大小成正比（$k = 2\pi R (p - p_0)$是比例系数；在冲击过程中它不发生变化），即它本质上是弹性的。在这种睡眠的影响下，身体会以$T = 2\pi \sqrt{\frac{m}{k}}$周期振荡，其中m是体重。
