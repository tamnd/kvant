例 3. “半和”$F*G$（定义 1）正好是$\frac{1}{2}(F_1 + F_2)$：毕竟，条件$\vec{OM} = \frac{1}{2}(\vec{OP} + \vec{OQ})$ 表明$M$ 是线段$[PQ]$ 的中点。

我们将这个数字称为$\lambda F + \mu G$，其中$\lambda$和$\mu$是正数，是数字$F$和$G$的线性组合。

示例 4. 矩形 $a \times b$ 和 $c \times d$ 的线性组合 $\lambda F + \mu G$，其边 $a$ 和 $c$ 平行（如示例 2），矩形 $(\lambda a + \mu c) \times (\lambda b + \mu d)$。

问题 5. 我们在问题 2-4 中需要找到的图形 $F$ 和 $G$ 的线性组合 $\lambda F + \mu G$ 是什么样的？

问题 6. 证明所引入操作的以下性质：
1°) $F_1 + F_2 = F_2 + F_1$;
2°) $(F_1 + F_2) + F_3 = F_1 + (F_2 + F_3)$;
3°) $\lambda(\mu F) = (\lambda \mu) F$;
4°) $\lambda(F_1 + F_2) = \lambda F_1 + \lambda F_2$;
5°）如果$F_1 \subset F_2$，$G_1 \subset G_2$，则$\lambda F_1 + \mu G_1 \subset \lambda F_2 + \mu G_2$；
6°) $\lambda F + \mu F \supset (\lambda + \mu) F$;如果 $F$ 是凸的，则 $\lambda F + \mu F = (\lambda + \mu) F$；
7°) $\lambda(F \cup G) = \lambda F \cup \lambda G$ 和 $H + (F \cup G) = (H + F) \cup (H + G)$；
8°) $\lambda(F \cap G) = \lambda F \cap \lambda G$ 和 $H + (F \cap G) \subset (H + F) \cap (H + G)$；

9°）如果$\lambda + \mu = 1$，则线性组合$\lambda F + \mu G$不依赖于$O$“极点”所在的位置。

一般来说，随着极点$O$的不同选择以及数据的并行传输，图形$F$和$G$，线性组合$\lambda F + \mu G$会发生变化，但不存在 - 它只是进行并行重新分配。因此，如果通过并行变换相互接收的两个图形的条件没有不同，被认为是等效的，那么您无法指示选择条纹的位置 - 结果 $\lambda F + \mu G$ 将被唯一确定。

请注意，任何线性组合$\lambda F + \mu G$数字$F$和$G$都是由“归一化”组合$\frac{\lambda}{\lambda + \mu} F + \frac{\mu}{\lambda + \mu} G$（使得坐标的系数之和等于1）乘以数字$(\lambda + \mu)$得到的，即刚刚准备好的。因此，线性组合为 $c \lambda + \mu \neq 1$。他们不会给你新的形状。

让我们描述一种想象两个凸多边形 $F$ 和 $G$ 的所有归一化线性组合的方法。让我们将其中一个（不转弯）相交成一个平行平面，并构造一个“凸包”$F$和$G$ - 一个凸多边形，其所有顶点都与顶点$F$和$G$重合（例如，图5上的正八边形 - 上下三角形的凸包；它的“中间”部分”是这些三角形的一半和）。然后，平行于 $F$ 和 $G$ 的平面多边形的截面仅给出线性组合 $\lambda F + \mu G$，其中 $\lambda + \mu = 1$；比率$\lambda/\mu$等于从切割平面到平面$F$和$G$的距离之比。
