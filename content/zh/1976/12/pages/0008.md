⟦folio 6⟧

这是一个由 1 组成的集合，我们得到一组 n 个数字，其中任意 n - 1 个数字的乘积与 1 相加，然后除以其余的数字。

引理的表述很麻烦，但证明却很简单。只要使用一个数字乘以一不会改变该数字的事实，以及任何数字都可以被一整除的事实就足够了。

第二个引理更有意义。

引理 2. 令数字 $a_1, a_2, \dots, a_n$ 具有以下性质：其中任意 $(n-1)$ 与 1 的乘积可被其余数整除。然后，将数字 $a_{n+1} = a_1 a_2 \dots a_n + 1$ 添加到它们中，我们得到一组数字，其中任意 n 个数字的乘积与单位之和除以其余数字。

为了证明这一点，您需要检查两个陈述。

第一个是前 n 个数字的乘积可以被 $a_{n+1}$ 整除 - 由数字 $a_{n+1}$ 的定义得出。

第二种是产品中包含数字$a_{n+1}$的情况。让我们用 $A_i$ 表示没有 $a_i$ 的前 n - 1 个数字的乘积：我们必须证明 $A_i a_{n+1} + 1$ 可以被 $a_i$ 整除。为此，只需注意$a_{n+1} = a_i A_i + 1$即可；那么$A_i a_{n+1} + 1 = A_i (A_i a_i + 1) + 1 = a_i A_i^2 + (A_i + 1)$，第一项除以$a_i$，括号内的第二项也能被引理的命题整除。

从这些引理可以看出，在数字问题中，将有以下解决方案：$(1, 1, 1), (1, 1, 2), (1, 2, 3), (2, 3, 7)$；有四个数字$(1, 1, 1, 1), (1, 1, 1, 2), (1, 1, 2, 3), (1, 2, 3, 7), (2, 3, 7, 43)$的问题。是否还有其他解决方案还有待观察。

显然，不存在包含 $n=3$ 单位的新解（通过删除其中一个单位，根据引理 1，我们将获得具有两个数字的问题的新解，但其中没有其他解）。现在让 $(x, y, z)$ 成为三个数问题的某个解。很容易证明这些数中的任何两个都必须互质。让$2 \leq x < y < z$。

我们来写一下对应关系：

$$\begin{align*}
xy + 1 &= k_1 z, \\
xz + 1 &= k_2 y, \\
yz + 1 &= k_3 x.
\end{align*}$$

这里$k_1, k_2, k_3$是自然数。改变这些对应关系，我们得到：$xyz(xyz + x + y + z) + xy + yz + xz + 1 = k_1 k_2 k_3 xyz$。

由此可见 $xy + yz + xz + 1$ 可以被 $xyz$整除，即

$$xy + yz + xz + 1 = Axyz,$$

其中$A$是自然数。将这个等式两边除以 $xyz$，我们得到

$$\frac{1}{x} + \frac{1}{y} + \frac{1}{z} + \frac{1}{xyz} = A.$$

$A$的最小值将在$x, y, z$的最小值处获得，即在$x=2, y=3, z=4$（实际上是$z \geq 5$）。从这里

$$A \leq \frac{1}{2} + \frac{1}{3} + \frac{1}{4} + \frac{1}{2 \cdot 3 \cdot 4} = \frac{27}{24},$$

由于$A$是自然数，因此它等于1。因此，我们需要找到所有自然数$x, y$和$z$，使得$2 \leq x < y < z$和

$$\frac{1}{x} + \frac{1}{y} + \frac{1}{z} + \frac{1}{xyz} = 1.$$

让我们证明$x=2$。事实上，如果$x \geq 3$，则$y \geq 4, z \geq 5$，因此，

$$1 = \frac{1}{x} + \frac{1}{y} + \frac{1}{z} + \frac{1}{xyz} \leq \frac{1}{3} + \frac{1}{4} + \frac{1}{5} + \frac{1}{3 \cdot 4 \cdot 5} = \frac{48}{60}.$$

我们收到了矛盾。所以，$x=2$。那么信件是这样写的：

$$1 = \frac{1}{2} + \frac{1}{y} + \frac{1}{z} + \frac{1}{2yz}.$$

从这里表达$y$，我们得到

$$y = 2 + \frac{5}{z - 2}.$$

这意味着$z-2$是数字5的约数，即$z=3$或$z=7$。第一种情况是$y=7$，第二种情况是$y=3$。

所以，$(2, 3, 7)$是三个不包含单位的数问题的唯一解，因此，我们写下了这个问题的所有解。
