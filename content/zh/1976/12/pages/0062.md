第十八届国际小学生数学奥林匹克竞赛题
第一天
1. 平凸四边形的面积为32$cm^2$，两条对边和一条对角线的长度之和为16$cm$。表示另一条对角线的线可以取的所有值。 （捷克斯洛伐克，5分。）
2. 令$P_1(x) = x^2 - 2$，$P_k(x) = P_1(P_{k-1}(x))(k=2, 3, \dots)$。证明对于任何自然数$n$，方程$P_n(x) = x$的所有根都是实数且不同的。 （芬兰，7分。）
3. Primogols 盒子可以完全填充单个立方体（立方体的边缘与盒子的边缘平行）。如果我们用体积为 2 且边与盒子的边缘平行的立方体填充盒子，那么此类立方体的最大数量将仅填充盒子体积的 40%。指出属于这种情况的所有盒子的内部尺寸 ($\sqrt[3]{2} \approx 1,2599$)。 （荷兰，8分。）
第二天
4. 求几个自然数的乘积可以取的最大值，其和为 1976。（美国，6 分。）
5. 在具有 $q=2p$ 未知数的 $p$ 方程组中
$$\begin{cases} a_{11}x_1 + \dots + a_{1q}x_q = 0, \\ a_{p1}x_1 + \dots + a_{pq}x_q = 0 \end{cases}$$
系数$a_{ij} \in \{ -1, 0, 1 \}$。证明该系统存在一个解 $(x_1, x_2, \dots, x_q)$，使得所有 $x$ 都是整数，对于某些 $j (1 \leq j \leq q)$ $x_j \neq 0$ 以及所有 $j (1 \leq j \leq q)$ $|x_j| \leq q$。 （荷兰，7分。）
6. 序列$\{u_n\}$定义如下：$u_0 = 2$、$u_1 = 5/2$、$u_{n+1} = u_n(u_{n-1}^2 - 2)^{-1}u_1 (n \geq 1)$。证明$n \geq 1$
$$[u_n] = 2^{(2^n - (-1)^n)/3},$$
其中$[x]$是不超过$x$的最大整数。 （英国，7分。）

第九届奥林匹克运动会
在物理学中
7月1日至7日，第九届国际中小学生物理奥林匹克竞赛在布达佩斯举行。此类奥林匹克竞赛于1967年开始举办。第一届国际奥林匹克竞赛是在波兰人民资源协会的倡议下组织的。来自保加利亚、匈牙利、波兰、罗马尼亚和捷克斯洛伐克五个社会主义国家的小学生参加了比赛。早在接下来的 1968 年，来自德国民主资源中心、苏联和南斯拉夫的学生就加入了这些国家的奥林匹克运动会参赛者行列。此后，我国代表队参加了历届奥运会。 1970年，莫斯科举办了第四届国际物理奥林匹克竞赛的学生。
奥林匹克竞赛包括解决三个理论问题和进行一项实验工作。理论和实验之旅在不同的日子举行。您有 5 个小时的时间来解决问题并完成实验。所有的问题都是由奥运会主办国准备的。这个国家也提供了工作验证，但验证结果最终要由各小组领导人组成的国际委员会批准。国际主席
