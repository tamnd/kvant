M378。证明存在无限多个不能用以下形式表示的多维数
a) $x^3 + y^3 + z^3$，其中$x, y, z$为整数；
b) $x_1^n + x_2^n + \dots + x_n^n$，其中$x_1, \dots, x_n$不是自然数。
b) 证明任意有理数都可以表示为$x^3 + y^3 + z^3$，其中$x, y, z$不是有理数。

并将点 $K$ 与顶点 $B$ 连接起来。从线段 $BK$ 的中间 $O$ 开始，我们构造一条垂线；该垂直线与边 $AC$ 的交点将是所需的点 $[OD] \perp [BK]$ 和 $O$ - $[BK]$ 的中间；因此$|BD| = |DK|$。

问题是否总有解决方案还有待查明。在三角形$ABD$中：$|AD| + |BD| > |AB|$，即$P_{\triangle ABC} = |AD| + |BD| + |AB| > 2 |AB|$。因此，如果$|BC| > 2 |AB|$，问题就有解。

◆

a) 很容易检查，如果$x$是一个整数，那么$x^3$，或$x^3 + 1$，或$x^3 - 1$可以被9整除。事实上，如果$x = 3k$，那么这是显而易见的；如果$x = 3k + 1$，则$x^3 - 1 = (x - 1)^3 + 3x(x - 1) = (3k)^3 + 9kx$；如果$x = 3k - 1$，则$x^3 + 1 = (x + 1)^3 + 3x(x + 1) = (3k)^3 + 9kx$。否则，我们的说法可以表述如下：当一个整数的立方除以9时，余数只能是0、1和-1。从这里可以立即看出，三个立方之和除以 9 的余数只能是 0、±1、±2、±3。因此，所有数字$9k \neq 4$不能表示为三个整数立方之和。

b) 取所有小于数字$N^n$的自然数（其中$N > 1$是某个自然数）。如果$a = x_1^n + x_2^n + \dots + x_n^n$（其中$x_i$是自然数）和$a < N^n$，则$x_i \leqslant N - 1$。从$n$数字$x_1, \dots, x_n$，每个数字都可以属于$(N - 1)$值​​$(1, 2, \dots, N - 1)$，可以组成$(N - 1)^n$集合（例如，参见“Quant”，1971年，第1期，N. Ya. Vilenkin“组合学”的文章）。这些集合的数的$n$次方所组成的和中，会有相同的；所以$x_1^n + x_2^n + \dots + x_n^n$形式的数字$a$的个数，小于$N^n$，不超过$(N - 1)^n$。因此，小于$N^n$的$[N^n - (N - 1)^n] = A_N$自然数不能表示为$n$自然数的$n$次方之和。由于$A_N > N^{n-1}$和$n > 1$，数字$A_N$可以作为角。由此可见，有无数个自然数无法用$x_1^n + x_2^n + \dots + x_n^n$的形式表示。

b) c) 段中陈述的证明最早于 1825 年获得。看起来很神奇：对于有理数$a$，它的表示形式直接写为有理数的三个立方之和：

$$a = \left( \frac{a^3 - 3^6}{3^2 a^2 + 3^4 a + 3^6} \right)^3 + \left( \frac{-a^3 + 3^6 a + 3^6}{3^2 a^2 + 3^4 a + 3^6} \right)^3 + \left( \frac{a^2 + 3^4 a}{3^2 a^2 + 3^4 a + 3^6} \right)^3.$$

然而，尚不清楚如何“想出”这样一个公式（不过，也许我们的一位读者已经成功了）。我们只能建议您检查一下这个公式是否正确。

然而，数学家研究三个立方之和的问题并不是为了得到公式（*）；就其本身而言，虽然看起来令人印象深刻，但并不是很受人尊敬。更重要的是了解这个身份背后“隐藏”的是什么。但这是一个完全专业化的问题；它涉及数学最困难的分支之一——代数几何。
