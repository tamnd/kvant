6. a) 请注意，函数 $f(x) = \cos x \cdot \cos(\sqrt{2}x)$ 仅对 $x = 0$ 取值 $y = 1$。实际上，

$$\cos x \cdot \cos \sqrt{2}x = 1 \Leftrightarrow \left[ \begin{array}{l} \cos x = 1, \\ \cos \sqrt{2}x = 1 \\ \cos x = -1, \\ \cos \sqrt{2}x = -1 \end{array} \right].$$

在第一种情况下，我们有：$x = 2\pi m$和$\sqrt{2}x = -2\pi n$，其中$m, n \in \mathbb{Z}$。如果$x \neq 0$满足这个一般关系（对于某些$m$和$n$），那么将第二个方程除以第一个方程后我们得到：

$$\sqrt{2} = \frac{n}{m}, \text{ т. е. } \sqrt{2} = \text{рациональное число.}$$

矛盾表明第一个系统有唯一解$x = 0$。第二个系统根本无解，用类似的方法证明。

因此，$f(x) = 1$仅适用于$x = 0$，因此函数$f$不能是周期性的（否则$f(T) = f(0) = 1$！）。

6) 函数 $f(x) = \cos x + \cos \sqrt{2}x$ 的表达式可以转换为以下形式

$$f(x) = 2 \cos \frac{x + \sqrt{2}x}{2} \cos \frac{x - \sqrt{2}x}{2} = 2 \cos \frac{1 + \sqrt{2}}{2} x \cdot \cos \frac{1 - \sqrt{2}}{2} x.$$

进一步，如问题a），证明$f(x) = 2$仅适用于$x = 0$，因此$f$不是周期性的。 （注意$\frac{1 + \sqrt{2}}{1 - \sqrt{2}}$是无理数。用反证法证明。）

另一种方法是立即注意到仅当$\cos x = \cos \sqrt{2}x = 1$时才存在$f(x) = 2$；这样，问题就简化为已经解决的问题了。

c) 首先让我们注意，对于函数 $f(x) = \sin x \times \sin \sqrt{2}x$ 的 a) 点的推理没有通过（尝试一下！）。因此它是不同的。

考虑空函数$f$，即$x$以及$f(x) = 0$。

我们有：

$$\sin x \cdot \sin \sqrt{2}x = 0 \Leftrightarrow \sin x = 0$$

或$\sin \sqrt{2}x = 0$

即，$x = a_m = \pi m$ 或 $x = b_n = \frac{\pi n}{\sqrt{2}}$，其中 $m, n \in \mathbb{Z}$。

我们假设函数 $f$ 是周期函数 $T \neq 0$。因为$f(T) = f(0 + T) = f(0) = 0$要么是$T = a_m$，要么是$T = b_n$（对于除0之外的某些$m_0, n_0$）。

我们首先考虑$T = a_m$的情况。

由于$f(b_1 + T) = f(b_1) = 0$，数字$b_1 + T = b_1 + a_m$必须等于$a_m$或$b_n$。在第一种情况下

$$b_1 + a_m = a_m, \text{ т. е. } \frac{\pi}{\sqrt{2}} + \pi m = \pi m,$$

因此$\frac{1}{\sqrt{2}} = m - m_0$和$\sqrt{2} = \frac{1}{m - m_0} \in \mathbb{Q}$是矛盾的。在第二种情况下

$$b_1 + a_m = b_n, \text{ т. е. } \frac{\pi}{\sqrt{2}} + \pi m_0 = \frac{\pi n}{\sqrt{2}},$$

由此$\frac{n - 1}{\sqrt{2}} = m_0$和$\sqrt{2} = \frac{n - 1}{m_0} \in \mathbb{Q}$又是一个矛盾。

类似地，当$T = b_n$时，我们会得出矛盾（你自己考虑一下）。

$$f(x) = 2 \sin \frac{1 + \sqrt{2}}{2} x \cdot \cos \frac{1 - \sqrt{2}}{2} x.$$
