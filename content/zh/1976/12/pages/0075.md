切斯科伊！例子：

$$f(x) = \sin x + \sin \sqrt{2}x,$$
$$g(x) = 1 - \sin(\sqrt{2}x),$$
$$f(x) + g(x) = 1 + \sin x.$$

8. 图 2 a) 和 6) 显示了如何将该函数定义为周期为 4 且具有任意周期 $T \geqslant 9$ 的周期性函数。

9. 让$T > 0$。数字$a_m = a + mT$和$b_n = b + nT$的距离，其中$m$和$n$是整数，并为任何$m, n \in \mathbb{Z}$放置$f(a_m) = f(a) = A$和$f(b_n) = f(b) = B$（参见图3）。如果这些关系定义了一个函数，即它不能满足$x = a_m = b_n$和$f(x) = A \neq f(x) = B$，那么这个函数将是周期性的，具有最小周期$T$（参见示例3°）。如果对于某些$m$和$n$，它们仍然是$a_m = b_n$，则原始函数（在两点给出）不能扩展到周期为$T$的周期函数（解释）。比率$a_m = b_n$意味着$a + mT = b + nT$，即$(m-n)T = b-a$和$T = \frac{b-a}{k}, k = m-n \in \mathbb{N}$。

因此，我们的函数可以扩展为一个周期函数，对于任何$T > 0$（除了$T = (b-a)/k$（其中$k \in \mathbb{N}$））具有最小正周期$T$。 （尝试在$f(a) = f(b)$，即$A = B$的情况下以类似的方式分析同一问题！）。

10. a) 这样的函数不存在。事实上，假设相反，在这样一个函数$f$的周期中，我们将有无理数$T_1 = \sqrt{2}$和$T_2 = 2 - \sqrt{2}$。但是，根据定理 1 的证明，它们的和$T_1 + T_2$，即理性上不是数字 2，将是周期$f$，这与条件相反。

6) 这样的函数是存在的 - 例如，所谓的狄利克雷函数：

$$D(x) = \begin{cases} 0 \text{ при рациональном } x, \\ 1 \text{ при irrationalном } x \end{cases}$$
