让我们使用已知的公式来变换 $\cos^2 x$：

$$f(x) = \cos^2 x = \frac{\cos 2x + 1}{2}.$$

函数$y = \cos 2x$是周期函数$\pi$（请解释）；因此，函数$(1/2) \cos 2x$和$(1/2) \cos 2x + 1/2 = f(x)$都有一个周期$\pi$。由于函数$f$的值1重复到$\pi$（见上文），因此数字$\pi$将是$f$的最小周期。

使用归约公式可以得到同样的结果：$\cos(x + \pi) = -\cos x$，因此$\cos^2(x + \pi) = (-\cos x)^2 = \cos^2 x$。

$11^\circ$。一般说明。如果函数 $f(x)$ 是周期函数 $T$，则任何以下形式的复函数

$$F(x) = af(Ax + B) + b$$

（$A \neq 0, B, a, b$ - 常数）

是周期性的，其周期为数字$T' = T/A$。 （证明这一点；参见 X，第 175 页。）例如，$a \cos(Ax + B) + b$ 形式的函数是周期性的，周期为 $2\pi/A$。

令周期函数$f$和$g$具有相应的最小正周期$T_1$和$T_2$，以及$T_1 \neq T_2$。

问题。在什么情况下函数$f$和$g$有一个共同的（当然不是最小的）周期$T$？

回答。若$f$和$g$为公共周期$T$，则由定理1$T = mT_1 = nT_2$，其中$m$和$n$为整数；由此可知 $T_2/T_1 = m/n$ 是有理数。相反，如果关系$T_2/T_1$是有理数$T_2/T_1 = m/n$，则$mT_1 = nT_2 = T$是函数$f$和$g$的公共周期。

我们所有的推理都表明了这个陈述的有效性。

定理2. 如果函数$f$和$g$的最小正周期相等，即关系$T_2/T_1$是有理数，则$u$这些函数$f(x) + g(x)$的和是周期的。

事实证明，如果定义的连续函数$f$和$g$的最小周期之比起到最小的作用，那么函数$f + g$将是连续的。对于周期函数的乘积也可以这样说（我们将仅限于给出一些相关的例子；所述陈述的一般证明是相当复杂的）。
