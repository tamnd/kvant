安排和换位

有一天，我在翻儿子的课本《数学-5》时，遇到了下面的问题*)。

《儿童百科全书》各卷的顺序是：1、2、6、10、3、8、4、7、9、5。如果你能把相邻的两卷，在不改变顺序的情况下并排放置在一个新的地方（在开头、结尾或两卷之间），该如何排列它们呢？

很快我就找到了解决方案。它被描绘在图1上。但我很早以前就养成了分析已解决问题的习惯，立刻就产生了一个问题：“如果不是别的呢？”我立即想到了一种不依赖于卷的最初排列的重新排列方法。首先，将第一个卷及其右侧的卷放在开头，然后将第二个卷及其右侧的卷放在第一个卷的后面，依此类推。如果所需的卷位于行的末尾，则应首先取出任何尚未安装的卷，并将它们重新排列到行的末尾，然后才能重新排列所需的卷。

由于数的个数是由另一个数通过奇数次转置得到的，不可能通过偶数次转置得到。

仍有待查明任务中描述的操作是否对应于偶数或奇数换位。将一卷移动到新位置相当于一系列换位：首先使用最近的卷，然后使用下一个卷，依此类推，直到它到达新位置。同样，移动下一个卷相当于一系列与第一种情况相同卷的换位。总的换位次数将等于移动一卷时换位次数的两倍，因此我们的操作相当于偶数次换位。

因此，作业中指定的操作的某些体积距离可以订购，但其他体积距离则不能订购。特别地，距离1、2、3、4、5、6、7、8、10、9是由距离1、2、3、4、5、6、7、8、9、10经过奇数次转置得到的，因此运算距离无法转换成距离1、2、3、4、5、6、7、8、10、9。

请注意，在我们的推理中，我们忽略了有 10 卷这一事实。如果取得同样的成功，这些推理可以对任何其他数量的卷进行。

但我们同时重新排列两卷这一事实非常重要。事实上，如果我们一次重新排列一个卷，那么对于任何初始距离，通过这样的操作，我们都可以按顺序排列卷。如果重新排列三卷会怎样？四个呢？...

这些问题中有一半可以立即得到答案。偶数卷的重新排列对应偶数次换位；因此，通过这样的操作，不可能将一种排列转换为另一种排列，这是由奇数次换位产生的。

一个还是多个？

找到整数自然数，使得它们中的任意三个与 1 的乘积之和可被整数整除。

首先想到的就是取所有的数都等于1。这样的实数的四倍就满足了问题的条件。还有其他解决方案吗？我在某处看到过这个任务。我打开 I. L. Babinskaya 所著的《数学优化问题》（M.，“Hayka”，1975 年），在第 142 号下找到了它。我正在寻找答案。我读到——“例如，1、2、3、7。”这个答案对我来说并不困难。对我来说，这相当于回答“例如，2”这个问题：“方程 $x^2 - 5x + 6 = 0?$ 的根是什么。”

不...我在其他地方看到过类似的任务。嗯，当然，“莫斯科数学优化问题集”（M.，“Prosveshchenie”，1965），第 11 页。 70，问题215。就是这样。

215. 数字$a, b, c$的三元组名称，与1不同，怎么样

任意两个三元组相加的乘积除以素数。

答案是一组：2、3、7。

不是吗，答案与我们临时问题的答案非常相似，尽管这里我们谈论的不是四个数字，而是三个数字。两个数字会发生什么？对于哪些数字对，每个数字的总和可以除以另一个数字？一个针对五年级学生的四个数字的问题，一个针对 7-10 年级学生的问题……但是，让我们鼓起勇气并提出解决方案。

如果这两个数字之一是 1，那么第二个数字必须是数字 2 的约数：要么是 1，要么是 2。很容易检查两对 (1, 1) 和 (1, 2) 是否满足问题的条件。

不让任何数字等于 1。那么，显然，这些数字是互质的。让$a < b$，然​​后$a + 1 \leq b$，但是$a + 1$可以被$b$整除，因此$a + 1 \geq b$。由此可见$a + 1 = b$。由于$b + 1$可被$a$整除，$a + 2$可被$a$整除，因此2可被$a$整除，并且由于$a \neq 1$，则$a = 2$、$b = 3$。

因此，存在三对数字，其中一对数字的和可被另一对数字整除：(1, 1)、(2, 1)、(3, 2)。

这个问题的一个相当简单的解决方案让我想到尝试立即解决一般问题：

“找到 $n$ 个数字，使得它们中的任何 $n - 1$ 相加后的乘积可以被余数整除。”

引理的表述很麻烦，但证明却很简单。只要使用一个数字乘以一不会改变该数字的事实，以及任何数字都可以被一整除的事实就足够了。

第二个引理更有意义。

引理 2. 令数字 $a_1, a_2, \dots, a_n$ 具有以下性质：其中任意 $(n-1)$ 与 1 的乘积可被其余数整除。然后，将数字 $a_{n+1} = a_1 a_2 \dots a_n + 1$ 添加到它们中，我们得到一组数字，其中任意 n 个数字的乘积与单位之和除以其余数字。

为了证明这一点，您需要检查两个陈述。

第一个是前 n 个数字的乘积可以被 $a_{n+1}$ 整除 - 由数字 $a_{n+1}$ 的定义得出。

第二种是产品中包含数字$a_{n+1}$的情况。让我们用 $A_i$ 表示没有 $a_i$ 的前 n - 1 个数字的乘积：我们必须证明 $A_i a_{n+1} + 1$ 可以被 $a_i$ 整除。为此，只需注意$a_{n+1} = a_i A_i + 1$即可；那么$A_i a_{n+1} + 1 = A_i (A_i a_i + 1) + 1 = a_i A_i^2 + (A_i + 1)$，第一项除以$a_i$，括号内的第二项也能被引理的命题整除。

从这些引理可以看出，在数字问题中，将有以下解决方案：$(1, 1, 1), (1, 1, 2), (1, 2, 3), (2, 3, 7)$；有四个数字$(1, 1, 1, 1), (1, 1, 1, 2), (1, 1, 2, 3), (1, 2, 3, 7), (2, 3, 7, 43)$的问题。是否还有其他解决方案还有待观察。

显然，不存在包含 $n=3$ 单位的新解（通过删除其中一个单位，根据引理 1，我们将获得具有两个数字的问题的新解，但其中没有其他解）。现在让 $(x, y, z)$ 成为三个数问题的某个解。很容易证明这些数中的任何两个都必须互质。让$2 \leq x < y < z$。

我们来写一下对应关系：

$$\begin{align*}
xy + 1 &= k_1 z, \\
xz + 1 &= k_2 y, \\
yz + 1 &= k_3 x.
\end{align*}$$

这里$k_1, k_2, k_3$是自然数。改变这些对应关系，我们得到：$xyz(xyz + x + y + z) + xy + yz + xz + 1 = k_1 k_2 k_3 xyz$。

由此可见 $xy + yz + xz + 1$ 可以被 $xyz$整除，即

$$xy + yz + xz + 1 = Axyz,$$

其中$A$是自然数。将这个等式两边除以 $xyz$，我们得到

$$\frac{1}{x} + \frac{1}{y} + \frac{1}{z} + \frac{1}{xyz} = A.$$

$A$的最小值将在$x, y, z$的最小值处获得，即在$x=2, y=3, z=4$（实际上是$z \geq 5$）。从这里

$$A \leq \frac{1}{2} + \frac{1}{3} + \frac{1}{4} + \frac{1}{2 \cdot 3 \cdot 4} = \frac{27}{24},$$

由于$A$是自然数，因此它等于1。因此，我们需要找到所有自然数$x, y$和$z$，使得$2 \leq x < y < z$和

$$\frac{1}{x} + \frac{1}{y} + \frac{1}{z} + \frac{1}{xyz} = 1.$$

让我们证明$x=2$。事实上，如果$x \geq 3$，则$y \geq 4, z \geq 5$，因此，

$$1 = \frac{1}{x} + \frac{1}{y} + \frac{1}{z} + \frac{1}{xyz} \leq \frac{1}{3} + \frac{1}{4} + \frac{1}{5} + \frac{1}{3 \cdot 4 \cdot 5} = \frac{48}{60}.$$

我们收到了矛盾。所以，$x=2$。那么信件是这样写的：

$$1 = \frac{1}{2} + \frac{1}{y} + \frac{1}{z} + \frac{1}{2yz}.$$

从这里表达$y$，我们得到

$$y = 2 + \frac{5}{z - 2}.$$

这意味着$z-2$是数字5的约数，即$z=3$或$z=7$。第一种情况是$y=7$，第二种情况是$y=3$。

所以，$(2, 3, 7)$是三个不包含单位的数问题的唯一解，因此，我们写下了这个问题的所有解。

让我们尝试一下 $k$ 格的排列：首先，我们将 $m$ 格穿过每个厘米，然后穿过 $(m+1)$（厘米），再次穿过 $(m+1)$（厘米），依此类推，直到我们放置完所有 $k$ 格。现在让我们考虑一把右端距离最后一个刻度 $(m+1)$ (cm) 的尺子。这把尺子$l$的长度可以通过$k$和$m$来表示：$l = m + (k-m)(m+1) + m+1 = -m^2 + m(k+1) + (k+1)$。

使用余数$s = p(m+1) + q$的除法公式，很容易证明对于任何$m$，除法的排列也满足问题的条件。
