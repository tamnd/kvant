⟦folio 40⟧

M329。凸n空间放置在边长为1的正方形中。让我们证明找到n线的三个顶点A、B、C并且三角形ABC的面积小于8/n²。

图 5.

让我们用 $a_1, a_2, \dots, a_n$ 表示 n 开口器的边长，用 $\alpha_1, \dots, \alpha_n$ 表示其外角的值。令 $S_i$ 为第 i 个三角形的面积（从边 $a_i$ 和 $a_{i+1}$ - 参见 图 5、$i = 1, 2, \dots, n-1$），$S_n$ 为从边 $a_n$、$a_1$ 开始的三角形面积。我们有：$2S_i = a_i a_{i+1} \sin \alpha_i$、$i = 1, \dots, n-1$、$2S_n = a_n a_1 \sin \alpha_n$。令 $S$ 为这些三角形面积中最小的。然后

$$2S \leq a_i a_{i+1} \sin \alpha_i,$$

在哪里

$$(2S)^n \leq \prod_{i=1}^{n} a_i^2 \prod_{i=1}^{n} \sin \alpha_i < \prod_{i=1}^{n} a_i^{2*}).$$

那是

$$2S < \left( \prod_{i=1}^{n} a_i \right)^{2/n}.$$

但

$$\left( \prod_{i=1}^{n} a_i \right)^{\frac{1}{n}} = \sqrt[n]{a_1 \cdots a_n} \leq \frac{a_1 + \cdots + a_n^{**}}{n} = \frac{\sum_{i=1}^{n} a_i}{n},$$

姿势

$$2S < \left( \frac{\sum_{i=1}^{n} a_i}{n} \right)^2.$$

令 $p_i$ 和 $q_i$ 为 n 间隔物的第 i 条边在正方形的垂直和水平边上的投影长度。那么$a_i \leq p_i + q_i$，即$\sum_{i=1}^{n} a_i \leq \sum_{i=1}^{n} p_i + \sum_{i=1}^{n} q_i \leq 4$。

波塞托姆

$$2S < \left( \frac{4}{n} \right)^2,$$

在哪里

$$S < \frac{8}{n^2}.$$

由此产生的估计相当粗略 - 我们从一开始就放弃了 $\prod_{i=1}^{n} \sin \alpha_i$，将此产品估计为一个。让我们澄清一下这个评估。我们有：

$$(2S)^n \leq \prod_{i=1}^{n} a_i^2 \prod_{i=1}^{n} \sin \alpha_i,$$

那是

$$2S \leq \left( \prod_{i=1}^{n} a_i \right)^{2/n} \cdot \left( \prod_{i=1}^{n} \sin \alpha_i \right)^{1/n} \leq \frac{16}{n^2} \cdot \frac{\sum_{i=1}^{n} \sin \alpha_i}{n}.$$

*) 这里$\Pi$是产品的符号：$\prod_{i=1}^{n} a_i = a_1 \cdots a_n$。
**) 我们使用了算术平均数和几何平均数的不等式。
