$$k = \frac{a}{|AH|} = \frac{a'}{|A'H|} = \frac{|KH|}{h}.$$

然后

$$a - a' = k(|AH| - |A'H|) = 2k|KH| = 2k^2h.$$

从$\triangle ABH$：

$$|AB|^2 + |BH|^2 = |AH|^2,$$

IE。

$$|AB|^2 + \left(\frac{|AB|}{2}\right)^2 = |AH|^2,$$

或者

$$k^2 + \left(\frac{k}{2}\right)^2 = 1,$$

在哪里

$$k^2 = \frac{4}{5},$$

因此 $a - a' = \frac{8}{5}h.$

◆ 当球与静止的球拍弹性碰撞时，球的速度腹骨值不改变，但方向改变。在这种情况下，速度分量 $v_y$ (图 7, a) 保持恒定 ($v_y' = v_y$)，并且分量 $v_x$ 改变方向为相反 ($v_x' = -v_x$)。

根据问题的条件，球拍的速度必须使得球以$\beta = 30^\circ$角度反射（对于静止观察者），即它必须满足条件（参见图7，b）。

$$\frac{|v_y'|}{|v_x'|} = \mathrm{tg} \beta = \frac{1}{\sqrt{3}}.$$ (*)

修剪后，球与移动的球拍碰撞时速度如何变化。为此，考虑与球拍相关的坐标系中的运动，相对于固定坐标系以恒定速度$w$运动（由于球拍的质量远大于球，因此碰撞后球拍的速度实际上不会改变）。由于系统具有惯性，根据“入射角等于反射角”的定律，会发生反射。
该系统中球在碰撞前的速度等于$u = v$ - $w$（参见图 7、$\theta$）。速度分量$u_x$和$u_y$等于相应的$u_x = v_x - w$、$u_y = v_y$。碰撞期间，$u_y$ 分量保持不变 ($u_y' = u_y = v_y$)，$u_x$ 分量改变方向至相反方向：$u_x' = -u_x = -v_x + w$。

F340。一颗质量为 $m=10$ kg 的地球卫星在大气层高层的圆形轨道上运行，会受到稀薄空气的阻力。阻力$F=5 \cdot 10^{-4}$n。确定卫星绕地球旋转一圈期间速度会发生多少变化。与地球半径相比，卫星在地球表面上方的飞行高度被认为很小。

质量为$m$的卫星在半径为$R$的轨道上运行时，其总能量$E$加上其动能$K = \frac{m v^2}{2} = \gamma \frac{m M}{2 R}$（卫星在圆形地球轨道上的速度为$\sqrt{\gamma \frac{M}{R}}$，其中$R$是地球半径）和势能$\Pi = -\gamma \frac{m M}{R}$（“负”号是由于吸引力的性质造成的）卫星和地球之间：随着物体越来越近，势能减小）。因此，

$$E = K + \Pi = -\gamma \frac{m M}{2 R}.$$

由于阻力的作用，卫星的能量发生变化，因此轨道半径发生变化。让我们计算每转半径的变化。

卫星每转一圈的能量变化值$\Delta E$，数值上等于路径上阻力做的功$2\pi R$，即$\Delta E = -2\pi RF$。因此，

$$\Delta E = -\gamma \frac{m M}{2 (R + \Delta R)} + \gamma \frac{m M}{2 R} = \gamma \frac{m M}{2} \frac{\Delta R}{(R + \Delta R) R}.$$

假设$|\Delta R| \ll R$，我们可以写

$$\gamma \frac{m M}{2} \frac{\Delta R}{R^2} = -2\pi RF.$$

考虑到$\gamma \frac{M}{R^2} = g$，我们最终得到

$$\Delta R = -\frac{4\pi RF}{g m} \approx -4 \cdot 10^2 m$$

($g = 9,8 \text{ m/сек}^2$, $R \approx 6,4 \cdot 10^6 \text{ m}$).

显然我们所做的假设$|\Delta R| \ll R$是正确的。

因此，由于阻力的作用，卫星轨道半径减小。因此，卫星的速度增加。我们来看看速度的变化，

卫星在半径$R + \Delta R$轨道上的动能等于

$$K_{R+\Delta R} = \frac{m (v + \Delta v)^2}{2} = \gamma \frac{m M}{2 (R + \Delta R)}.$$

如果我们考虑到当电路闭合时，导电液体的自由电荷具有垂直于板的速度分量，则这个悖论很容易解决。因此，洛伦兹力的一个分量出现，其方向与速度 v 相反。因此洛伦兹力的总功由其两个分量的功组成。而这个总工作量为零。让我们确认一下这一点。

由于垂直于极板的洛伦兹力分量的作用，电容器内部的电荷从一个极板移动到另一极板。该组件的含义

$$F_1 = qvB.$$
单位时间内力$F_1$所做的功（即功率）等于

$$N_1 = F_1v_1 = qvBv_1,$$

其中$v_1$是垂直于板的电荷速度分量。

对抗速度 v 的洛伦兹力分量大小相等

$$F_2 = qv_1B.$$

$$N_2 = -F_2v_1 = -qv_1Bv$$

（力$F_2$充当制动力，因此其功为负）。

因此，洛伦兹力的功（如果我们考虑力的所有分量）实际上为零：

$$N_1 + N_2 = 0.$$
该电路中的能源显然是一个通过电容器吸入液体的泵。该泵必须不断做功，因为阻力作用在液体上，所有这些功最终都会转化为回路中释放的热量。
