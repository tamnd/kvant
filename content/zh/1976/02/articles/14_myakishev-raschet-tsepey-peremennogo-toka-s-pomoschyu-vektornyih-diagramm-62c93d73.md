交流电路的计算比直流电路复杂得多。然而，如果电流的方向和强度按照谐波定律变化，则有一种相当简单且直观的电路计算方法——矢量图法。我们想在这篇文章中向读者介绍他。

描述振荡电路中受迫振荡的方程

工业交流电是强制电磁振荡。如果链末端的方向$u = u(t)$按照调和定律变化
$$u = U_0 \cos \omega t,$$
(1)
那么电流强度 $i$ 也会以相同频率 $\omega$ 谐波变化，但在一般情况下，电流相对于方向异相恒定值 $\varphi$：
$$i = I_0 \cos (\omega t + \varphi).$$
(2)

然而，在电路闭合后的第一时刻，电流振荡的形状要复杂得多。当闭合时，电路似乎受到“推力”，如果它有自己的振荡频率$\omega_0$，则其中会产生自由电磁振荡。这些振荡叠加在频率为$\omega$的受迫振荡上，但由于电路中存在有源电阻$R$（能量以热的形式释放）而逐渐衰减。只有在自由振荡消失后，才能认为受迫振荡已建立。公式（2）中的当前振幅$I_0$是已建立的机械振荡的振幅（有关这方面的更多详细信息，请参见例如G. Ya. Myakishchev的文章“Forced Mechanical Oscillations”，«Kvant»，1974年，第11号）。

一个相当简单但非常重要的特殊情况是由具有有源电阻$R$、电感器$L$和电容器$C$（图1）的串联导体组成的电路中的受迫振荡。这种电路称为串联振荡电路。令链条两端的方向$u$按照式（1）所描述的规律变化；那么电路中的电流强度$i$按照式(2)变化。电流幅度$I_0$和相移$\varphi$是多少？

众所周知，描述该电路中强制电流振荡的方程具有以下形式：
$$L \frac{\Delta i}{\Delta t} + Ri + \frac{q}{C} = U_0 \cos \omega t.$$ (3)
这里$q$是电容器的电荷。 （这

该方程类似于描述受迫机械振动的方程，例如负载的外部振动。）

等式(3)可以如下使用。在任何时刻，电路两端的总电压 ($u = U_0 \cos \omega t$) 等于有源电阻 ($u_R = Ri$)、电感器 ($u_L = L \frac{\Delta i}{\Delta t}$) 和电容器 ($u_C = \frac{q}{C}$) 两端的电压之和：

$$u_L + u_R + u_C = u.$$ (4)

所有三个电压以相同的频率振荡，但具有不同的幅度并且彼此异相。

为了找到电流强度的振荡幅度以及电流和电压之间的相移，您需要能够添加异相的谐波振荡。为此，您需要知道电压幅度 $u_R$、$u_L$ 和 $u_C$，以及这些电压相对于电流强度的相移。这将在接下来的三段中讨论。

有源电阻两端的电压

电路最简单的情况是仅包含有源电阻 $R$。对于这样的链，基本方程（3）将具有以下形式：

$$Ri = U_0 \cos \omega t.$$ (5)

从这里

$$i = \frac{U_0}{R} \cos \omega t = I_0 \cos \omega t.$$ (6)

电压幅值与电流幅值有对应关系

$$U_0 = I_0 R.$$ (7)

有源电阻上的电流和电压波动是同相的。请注意，等式（7）与直流欧姆定律没有什么不同。

感抗电压

让目标由一个电感为 $L$ 的线圈组成。我们忽略线圈的有源电阻。在这种情况下，我们将有一个更简单的方程，而不是方程（3）

$$L \frac{\Delta i}{\Delta t} = U_0 \cos \omega t,$$

或者

$$\frac{\Delta i}{\Delta t} = \frac{U_0}{L} \cos \omega t.$$ (8)

现在电流的变化率（$\frac{\Delta i}{\Delta t}$）执行谐波振荡，与电压振荡同相。这些振荡的幅度为 $\frac{U_0}{L}$。

为了表达电流强度，可以用电路中的电磁振荡和外部负载的机械振荡进行类比。众所周知，电流强度$i$对应于负载$v$的振荡速度，电流强度$\frac{\Delta i}{\Delta t}$对应于负载$a$的加速度。但速度波动滞后于加速度波动$\pi/2$，且速度幅值$v_0$与加速度幅值$a_0$存在对应关系$v_0 = a_0/\omega$。对于任何性质的简谐振动都是如此。因此，如果电流的变化率满足式（8），则电流随时间的变化规律

$$i = \frac{U_0}{L \omega} \cos \left(\omega t - \frac{\pi}{2}\right) = I_0 \cos \left(\omega t - \frac{\pi}{2}\right).$$ (9)

电压幅值与电流幅值有对应关系

$$U_0 = I_0 L \omega = I_0 R_L.$$ (10)

量$R_L = L \omega$称为感抗。

因此，根据式（1）和（9），感抗上的电流功率比同相电压滞后π/2。

电容电压

让我们考虑一个由电容器 C 组成的电路。我们要求电路的有源电阻和电感。该电路中的受迫振荡将由方程描述

$$\frac{q}{C} = U_0 \cos \omega t. \tag{11}$$

电容器电荷与电压同相振荡，这些振荡的幅度为 $U_0 C$：

$$q = U_0 C \cos \omega t. \tag{12}$$

在电磁振荡的情况下，电荷对应于进行机械振荡的物体的坐标，电流强度，即电荷的变化率（$i = \frac{\Delta q}{\Delta t}$），类似于该物体的速度。由于对于任何简谐振动，该量的速度振幅比该量本身的振幅大 $\omega$ 倍，并且速度与该量异相 π/2，因此在我们的例子中

$$i = \frac{\Delta q}{\Delta t} = U_0 C \cos \left( \omega t + \frac{\pi}{2} \right) = I_0 \cos \left( \omega t + \frac{\pi}{2} \right). \tag{13}$$

因此，电路的功率由电容器上的电压π/2决定，或者，同样地，由断路器的电压π/2决定。

电压幅值为

$$U_0 = \frac{I_0}{C \omega} = I_0 R_C, \tag{14}$$

其中$R_C = \frac{1}{C \omega}$是电容器的电阻，称为电容。

使用矢量图添加简谐振动

谐波振荡可以通过不同的方式添加（分析、图形等）。但在振荡频率相同的部分情况下，采用矢量图法最为方便。这个方法由什么组成？

从十年级物理课程中我们知道，以恒定角速度 $\omega$ 旋转的矢量在任意方向上的投影会产生简谐振动。如果向量$x_0$的模型等于$x_0$，则其在轴$OX$上的投影等于$x = x_0 \cos \varphi$（图2）。向量$x_0$匀速旋转，角度$\varphi$随时间按规律变化

$$\varphi = \omega t + \varphi_0,$$

其中$\varphi_0$是初始时间$t=0$时角度$\varphi$的值。因此，旋转矢量的投影根据以下定律振荡

$$x = x_0 \cos \left( \omega t + \varphi_0 \right). \tag{15}$$

串联振荡电路的矢量图

让我们再次回到图1所示的电路，并为其构建电流和电压的矢量图。这使我们能够确定电路中电流的幅度以及电流强度和施加电压之间的 cdwg 相位。

给定时间的电流强度在电路的所有部分都是相同的*)。因此，以电流强度对应的矢量$I_0$为基础构建矢量图是很方便的。可以任意定向。对于方向，我们用垂直箭头 (图 4) 描绘向量 $I_0$。

为了找到总电压（参见公式（4）），您需要添加三个向量：$U_{0R}$、$U_{0L}$ 和 $U_{0C}$。首先，将向量$U_{0L}$和$U_{0C}$（图5）相加很方便。该和的模数为 $|U_{0L} + U_{0C}| = I_0\left(L\omega - \frac{1}{C\omega}\right)$，

如果$L\omega > \frac{1}{C\omega}$。 图 5 中描述的正是这种情况。之后，将矢量$U_{0L} + U_{0C}$ 与矢量$U_{0R}$ 相加，我们得到矢量$U_0$，描述了电路两端的电压波动。

三角形ABD是直角三角形。根据毕达哥拉斯定理

$$U_0^2 = U_{0R}^2 + \left(U_{0L} - U_{0C}\right)^2 = I_0^2 R^2 + I_0^2 \left(L\omega - \frac{1}{C\omega}\right)^2.$$

因此电流幅度

$$I_0 = \frac{U_0}{\sqrt{R^2 + \left(L\omega - \frac{1}{C\omega}\right)^2}} = \frac{U_0}{Z},$$

其中$Z = \sqrt{R^2 + \left(L\omega - \frac{1}{C\omega}\right)^2}$是电路的总电阻。电流和电压之间的相移等于矢量 $U_0$ 和 $I_0$ 之间的角度 $\varphi$。从三角形ABD

$$tg\varphi = \frac{L\omega - \frac{1}{C\omega}}{R}.$$

图 5 描述了电流强度与电压同相滞后的情况（在$L\omega < \frac{1}{C\omega}$ 时电流强度将超前于电压同相）。

公式（17）和（18）完整地描述了串联振荡电路中的受迫振荡。让我们看一个特殊情况作为例子。

振荡电路中的电流强度在$L\omega = \frac{1}{C\omega}$处达到最大值$I_0 = \frac{U_0}{R}$，即当施加到电路的电压频率等于电路振荡的固有频率$\omega_0 = \frac{1}{\sqrt{LC}}$时。正如他们所说，共鸣随之而来。谐振时，电压$u_L$和$u_C$幅值相同，但反相振荡，因此它们随时相互抵消。谐振情况的相量图如图 6 所示。电流和施加电压之间的相移变为零。有源电阻处的烧灼结果等于电路两端的电压：$u_R = iR = U_0\cos\omega t$。串联振荡电路中的谐振通常称为电压谐振。事实上，在实际电路中，电感和电容电阻总是大于有源电阻，并且在谐振时，电压幅值$U_{0L}$和$U_{0C}$结果是施加电压$U_0$的大幅值。
