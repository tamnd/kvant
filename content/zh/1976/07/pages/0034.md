为了证明 c) 点，我们将使用可理解的向量标量积：$a \cdot b = |a| \cdot |b| \cos(\alpha, \beta)$（有关其属性，请参阅第 21 页）。从定义可以看出，单位向量的乘积等于它们之间角度的余弦。让我们用$e_a, e_b, e_c$和$e_d$分别表示与向量$a, b, c$和$d$具有相同方向的单位向量。很容易看出

$$\cos \alpha + \cos \beta + \cos \gamma + \cos \phi + \cos \psi = -\frac{1}{2}((e_a + e_b + e_c + e_d) \cdot (e_a + e_b + e_c + e_d)) + 2 = -\frac{1}{2}k \cdot k + 2 = -\frac{|k|^2}{2} + 2,$$

(1)

其中$k = e_a + e_b + e_c + e_d$。

从等式（1）可知，四面体两个角的余弦之和不超过 2，且等于 2 当且仅当 $k = e_a + e_b + e_c + e_d = 0$。但由于$a + b + c + d = 0$总是，在$k = 0$的情况下，我们得到向量$a, b, c$和$d$的长度相等，即所有面的大小相等。从四面体的面大小相等可知它们是拥挤的（参见解���题 M319，«Kvant»，1975，第 12 号）。因此，要完成c)点命题的证明，还需要证明等式(1)左边的余弦之和为正，即$|k| < 2$。

为了方便起见，我们假设$|a| = 1, |b| \leq 1, |c| \leq 1$和$|d| \leq 1$。然后$e_a = a, |k| = |a + b + c + d| + (e_b - b) + (e_c - c) + (e_d - d)| \leq |e_b - b| + |e_c - c| + |e_d - d| = 3 - |b| - |c| - |d| \leq 3 - |b + c + d| = 3 - |a| = 2$。仅当所有向量 $a, b, c$ 和 $d$ 共线时，才会出现相等；因为事实并非如此，$|k| < 2$，并且 c) 点中的所有陈述均已证明。

为了证明点 d)，我们注意到条件 $|AB| + |CD| = |BC| + |DA|$ 对于球接触边缘$AB, BC, CD$ 和 $DA$ 的存在是必要且充分的（这个事实的证明类似于证明充分条件 $|AB| + |CD| = |BC| + |DA|$ 的必要性，以便可以围绕平坦四边形 $ABCD$ 描述圆）。令 $O$ 为该球的中心（假设点 $O$ 在四面体内部）。我们有 (图 5)：

$$(n.l. OAB, \hat{n.l. ABC}) = (n.l. OBC, \hat{n.l. ABC}),$$
$$(n.l. OAB, \hat{n.l. ABD}) = (n.l. OAD, \hat{n.l. ABD}),$$
$$(n.l. ODC, \hat{n.l. BCD}) = (n.l. OBC, \hat{n.l. BCD}),$$
$$(n.l. ODC, \hat{n.l. ACD}) = (n.l. OAD, \hat{n.l. ACD}).$$

添加这些等式，我们得到语句 d)。

当点$O$在四面体内部时的情况类似地处理。
