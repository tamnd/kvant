$$L(x, t) = 0 \cdot x + 1 \cdot t = t. \tag{9}$$
我们有一个线性规划问题。让我们将其简化为 OZLP。
系统(8)等价于系统
$$\begin{cases} 2x + 9t - 45 \geq 0, \\ -2x + 45t - 25 \geq 0. \end{cases} \tag{10}$$

让我们用$y_1$表示$2x + 9t - 45$，用$y_2$表示$-2x + 45t - 25$。然后是$2x + 9t - 45 = y_1$、$-2x + 45t - 25 = y_2$和$y_1 \geq 0, y_2 \geq 0$。现在我们可以将我们的任务表述如下：找到满足方程组的变量 $x, t, y_1, y_2$ 的非负值
$$\begin{cases} 2x + 9t - y_1 = 45, \\ -2x + 45t - y_2 = 25 \end{cases} \tag{11}$$

并最小化目标函数$L(x, t, y_1, y_2) = t$。这已经是一个 OZLP。让我们使用单纯形法来解决它。

让我们选择$y_1$和$y_2$作为基本变量（系统（11）对于它们而言最容易求解）并用自由变量$x, t$来表达它们：
$$\begin{cases} y_1 = 2x + 9t - 45, \\ y_2 = -2x + 45t - 25. \end{cases} \tag{12}$$

将自由变量设置为零，我们得到系统（12）和（11）的解：
$$x^{(1)} = t^{(1)} = 0, y_1^{(1)} = -45, y_2^{(1)} = -25.$$
该解决方案无效。

现在让我们选择另外两个变量作为基础变量，例如$t$和$y_2$。 （线性规划理论中，有一种方法指示如何选择新的自由变量以逼近可行解域。这里不介绍这种方法。）让我们对它们求解系统（11）：
$$\begin{cases} t = -\frac{2}{9}x + \frac{1}{9}y_1 + 5, \\ y_2 = -12x + 5y_1 + 200. \end{cases} \tag{13}$$

将自由变量设置为零，我们得到系统（13）和（11）的解：
$$x^{(2)} = y_1^{(2)} = 0, t^{(2)} = 5, y_2^{(2)} = 200. \tag{14}$$

解(14)已经可以接受。为了检查它是否是最优的，我们用自由变量$x$和$y_1$来表达目标函数$L$。来自（9）和（13）
$$L(x, t, y_1, y_2) = -\frac{2}{9}x + \frac{1}{9}y_1 + 5. \tag{15}$$

解 (14) 的目标函数 $L$ 的值等于 5。

由于（15）中$x$的系数为负，解（14）不是最优的：通过增加变量$x$的值，我们将减少目标函数$L$的值。

在系统(13)的一般方程中，$x$的系数为负。因此，变量$x$的值的增加被描述为$t$和$y_2$。这种增加可能会使它们变成负值。从系统（13）的第一个方程可以看出，变量$x$的值可以增加到$-5 / \left(-\frac{2}{9}\right) = \frac{45}{2} = 22 \frac{1}{2}$（通过该值$x$和$y_1 = 0$，我们得到$t = 0$；随着$x$的进一步增加，变量$t$的值变为负）；从第二个到 $-\frac{200}{12} = \frac{50}{3} = 16 \frac{2}{3}$。因此，随着变量$x$的值增加，变量$y_2$也将变为零：它处于比$t$“更受威胁”的位置。
