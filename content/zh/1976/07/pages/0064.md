选项1

1. $3a^3 \text{tg} \alpha/4$.

2. $x = y = -9$。笔记。从系统的第二个方程我们得到方程：$\left( \sqrt{\frac{x}{y}} \right)^2 + 4 \sqrt{\frac{x}{y}} + 3 = 0$对于$y > 0$（该方程无解）和$\left( \sqrt{\frac{x}{y}} \right)^2 - 4 \sqrt{\frac{x}{y}} + 3 = 0$对于$y < 0$，

从那里$x = 9y$或$x = y$。剩下的就是将这些表达式代入系统的第一个方程并考虑另一种情况$y = 0$。

3. a) $2 \text{km/час};$ b) $4 \text{час} < t < 8 \text{час}$。笔记。让我们输入$AC = s$，拖拉机下降时的速度将用$v$表示；那么上升的速度就是$v - 1$。根据条件

$$\begin{cases} \frac{s}{v - 1} + \frac{8 - s}{v} = t_1, \\ \frac{8 - s}{v - 1} + \frac{s}{v} = t_2, \end{cases}$$

从那里$(t_1 + t_2)v^2 - (t_1 + t_2 + 16)v + 8 = 0$，

自$0 < s < 8$以来$v = 2 (\text{km/час}).$现在$t_1 = 4 + \frac{s}{2}$和$4 < t_1 < 8$。

选项2

1. $a^3 \text{tg} \alpha/16$.

2. $x = -7/10, y = -63/40$。笔记。将系统的第一个方程乘以 8，第二个方程乘以 -3，然后相加，我们得到 $3x - 4\sqrt{xy} - 4y = 0$，

从那里$x = 4y > 0$或$x = \frac{4}{9}y < 0$。

3. a) $15 \text{km/час};$ b) $t_1 > 1/3 (\text{час}).$ 注意。由于 $t_2 > t_1$，rukvov $ADB$ 必须短于 rukvov $ACB$；让我们用$s$表示它的长度，用$v$表示船在静水中的速度。然后

$$\begin{cases} \frac{s + 6}{v + 3} + \frac{s}{v - 3} = t_1, \\ \frac{s}{v + 3} + \frac{s + 6}{v - 3} = t_2. \end{cases}$$

因此$(t_2 - t_1)(v^2 - 9) = 36$，$v = 15 (\text{km/час}),$$t_1 = \frac{5s}{36} + \frac{1}{3},$$s > 0$。

选项3

1. $a^3 \sqrt{3} \text{ctg} \frac{\alpha}{2} / 2$.

2. a) $\pm \sqrt{8}, \pm \sqrt{23};$ b) $-64,32 < \alpha_1 - 14\alpha_2 < -64,31$.

3. $35 \text{km/час}.$ 注意。如果部分路径的平均速度等于整个路径的平均速度，则路径其余部分的平均速度相同。设 $s - \text{dлина треться участа}, v - \text{средняя скорость};$ 那么

$$v = \frac{7s}{\frac{6s}{v - 2} + \frac{s}{2v - 15}},$$

从哪里$v_1 = 35$，$v_2 = 6 (\text{km/час}).$

选项4

1. $4a^3 \cos^2 \alpha \sqrt{-\cos 2\alpha} / 3$.

2. a) $\pm \sqrt{31}, \pm \sqrt{29};$ b) $-39,16 < \alpha_1 + 8\alpha_2 < -39,15$.

3. $150 \text{km/час}.$ 注意。令 $v - \text{средняя скорость экспресса}, s - \text{dлина второго участа}.$ 那么

$$\frac{s}{\frac{5}{9}s + \frac{4}{9}s} = v,$$

从哪里$v = 120 (\text{km/час}).$
