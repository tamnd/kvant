⟦folio 9⟧

在研究带电导体产生的恒定（不随时间变化）电场时，首先应记住导体内部电场的方向为零。导体中的电荷立即分布在其表面上。因此，电气工程的问题通常与寻找导体外部的电场和确定导体表面上的电荷分布有关。

让我们列出几个典型的电网问题。

任务 1. 精确的电荷 q 位于距半径为 r (图 1) 的替代球形导体表面距离 d 处。确定该表面上感应的电荷 q'。

任务 2. 将强大的电荷 q (图 2) 放置在两个替代的同心球之间，该同心球的表面计算出半径为 r₁ 和 r2。从电荷到球面的距离等于相应的 d1 和 d2。球体上感应的电荷为 q'1 和 q'2。

任务 3. 精确的电荷 q 位于距导电替代无限平面 (图 3) 距离 d₁ 和 d2 处。即在这些平面上感应的电荷 q'1 和 q'2。

解决此类问题的观察方法在数学物理的相应部分中研究，这不包括在学校课程中。然而，有一些相对简单的私有方法可以让你在不超出初等数学限制的情况下解决电网问题（例如，图像方法，在G. Myakishev的文章“电网场”中提到；参见«Kvant»，1975年，第4期）。在这里我们将看看其中之一

这些方法基于互惠定理（或原理）。

这个定理的本质是什么？它可以表述如下：如果在$n$导体的系统中，不存在导体$q_1, q_2, \dots, q_n$，则存在相应的电荷$\varphi_1, \varphi_2, \dots, \varphi_n$，并且带有电荷$q'_1, q'_2, \dots, q'_n$的导体等于$\varphi'_1, \varphi'_2, \dots, \varphi'_n$，则等式为真

$$\sum_{i=1}^{n} q_i \varphi'_i = \sum_{i=1}^{n} q'_i \varphi_i.$$ (1)

让我们证明情况确实如此。

根据叠加原理，导体的电势与电荷线性相关。或者，相反，导体上的电荷与电势线性相关。让我们首先考虑一种特殊情况——接地导电表面内有两个带电导体 1 和 2 (图 4)。让我们将第二根导体连接到接地导体，然后该导体的电位将为零（参见图 4，a）。第一导体的电势用$\varphi_1$表示。每个导体上的电荷必须与 $\varphi_1$ 成比例，即

$$\Delta q_1 = C_{11} \varphi_1 \quad \text{и} \quad \Delta q_2 = C_{21} \varphi_1.$$ (2)

这里$\Delta q_1$和$\Delta q_2$分别是第一和第二导体上的电荷，$C_{11}$和$C_{21}$是称为电容系数的常数，取决于导体的形状和相对位置。 $C_{11}$和$C_{21}$描述了第一个电荷

$$q_i = C_{i1} \varphi_1 + C_{i2} \varphi_2 + \dots + C_{in} \varphi_n = \sum_{k=1}^{n} C_{ik} \varphi_k \quad (i=1, 2, \dots, n).$$ (3)

这里，电容系数$C_{ik}$表征了第$i$个导体的电荷，当除了第$k$个导体之外的所有导体

接地，第 $k$ 导体的电位等于 1。现在让第 $i$ 个导体的电荷等于 $q'_i$，其电势为 $\varphi'_i$。让我们将等式 (4) 项乘以 $\varphi'_i$：

$$q'_i \varphi'_i = \sum_{k=1}^{n} C_{ik} \varphi_k \varphi'_i,$$

然后将 $i$ 从 1 到 $n$ 的所有值的等式两边求和：

$$\sum_{i=1}^{n} q'_i \varphi'_i = \sum_{i,k=1}^{n} C_{ik} \varphi_k \varphi'_i.$$

但

$$\sum_{i,k=1}^{n} C_{ik} \varphi_k \varphi'_i = \sum_{i,k=1}^{n} C_{ik} \varphi'_i \varphi_k = \sum_{i=1}^{n} q'_i \varphi'_i$$

（因为$i$和$k$取1到$n$的所有值），所以我们最终得到

$$\sum_{i=1}^{n} q'_i \varphi'_i = \sum_{i=1}^{n} q'_i \varphi'_i.$$

因此，由于等式（1）和（5）相同，互易定理得到证明。

在应用互易定理解决上述问题之前，我们考虑另外两个问题。

附加问题 1. 有一个导体系统，除第 $i$ 外，所有导体均接地，且第 $i$ 导体的电位为 $\varphi'_i$ (图 5)。在系统的某些点$A$，功率等于$\varphi$。确定感应电荷$q'_i$

$$q \varphi + q'_i \varphi'_i = 0,$$

在哪里

$$q'_i = -q \frac{\varphi}{\varphi'_i}.$$

附加问题2。在封闭的导电表面1中，我们放置抽屉柜$\varphi_1$，我们找到导体2（图6）。我们将其设置为等于$\varphi_2$，并将位于导体之间的点$A$设置为等于$\varphi$。如果导体接地，则求导体上感应的电荷 $q'_1$ 和 $q'_2$，并将电荷 $q$ 放置在点 $A$ 处。

我们的系统有两种状态：
a) $A$点电荷为零，其电势为$q$，导体电势为$\varphi_1$和$\varphi_2$（见图6，a）；
b) $A$ 点的电荷等于$q$，导体电势为零，其上感应的电荷等于$q'_1$ 和$q'_2$（见图 6，b）。

为简单起见，在这里和进一步我们将讨论电荷和潜在功率 $A$，这意味着此时存在导体（如问题 1 中所做的那样）。

由互易定理
$$q'_1 \varphi_1 + q'_2 \varphi_2 + q \varphi = 0. \tag{6}$$

当然，仅凭这种相等性不可能找到两种感应电荷。然而，我们也可以使用在第二种情况下替换导电率$1$的条件。这意味着外部没有电场，这意味着位于替代电导率内部的所有电荷的代数和等于零，即
$$q'_1 + q'_2 + q = 0. \tag{7}$$

联立方程(6)和(7)可得
$$q'_1 = q \frac{\varphi_2 - \varphi}{\varphi_1 - \varphi_2}$$
和
$$q_2 = -q \frac{\varphi_1 - \varphi}{\varphi_1 - \varphi_2}.$$

现在我们可以回到主要任务了。为了解决它们，我们将使用互易定理。基于该定理应用的方法有些形式化，但非常简单方便。全部困难仅在于明智地选择所考虑的系统的两种状态并为它们写出等式（1）。

问题解决1. 根据问题条件，精确的电荷$q$ 位于距替换的电荷$q'$ 所在的导电球一定距离处（对应1）。

让我们假设球面没有被替换并且具有电势$\varphi_0$，但电荷$q$没有。那么在它的位置上场势等于
$$\varphi = \varphi_0 \frac{r}{r + d} (r - \text{радис сферической поверхности}, d - \text{расстояние от заряда } q \text{ до этой поверхности}).$$ 这是系统的第二个状态。

让我们为系统的这两种状态写出互易定理：
$$q \varphi + q' \varphi_0 = 0,$$
或者
$$q' = -q \frac{\varphi}{\varphi_0} = -q \frac{r}{r + d}.$$

所得结果可应用于电荷$q'$位于无限导电平面上的情况。事实上，无限平面可以被视为具有无限大半径的球面，即
$$r \rightarrow \infty.$$ 因此，在 $r \rightarrow \infty$ 的极限内，我们有
$$q' = -q \frac{r}{r + d} = -q \frac{1}{1 + d/r} = -q,$$
也就是说，在无限平面上感应的电荷值相等，但无论该电荷位于何处，点与点之间的值相反。

问题2的解法 根据问题的条件，系统的第一状态如下：电荷$q$位于电荷$q'_1$和$q'_2$所在的替代球形导体之间的给定点。

作为第二种状态，让我们考虑当外球体被替换时的情况，内球体具有电势$\varphi_1$，电荷$q$不存在，但在其位置上场电势为$q$。

根据附加问题1的解，我们得到
$$q'_1 = -q \frac{\varphi}{\varphi_1}. \tag{8}$$

当接地表面内的电荷代数和为零时，我们发现外球体上感应的电荷$q'_2$：

$$q'_1 + q'_2 + q = 0.$$ (9)

因此，我们只需找到关系$\varphi/\varphi_1$即可。假设当外球体接地且内球体有电势$\varphi_1$时，内球体上的电荷为$q_0$。显然，在这种情况下，外球体上将感应出电荷$-q_0$。让我们用电荷$q_0$和$-q_0$来表达潜力$\varphi$和$\varphi_1$：

$$\varphi = \frac{q_0}{r_1 + d_1} + \frac{-q_0}{r_2},$$

$$\varphi_1 = \frac{q_0}{r_1} + \frac{-q_0}{r_2}.$$ (10)

最后根据等式（8）-（10）我们得到：

$$q'_1 = -q \frac{r_1 d_2}{(r_1 + d_1)(d_1 + d_2)},$$

$$q'_2 = -q \frac{r_2 d_1}{(r_1 + d_1)(d_1 + d_2)}.$$

$$q'_1 = -q \frac{r_1 d_2}{(r_1 + d_1)(d_1 + d_2)} = -q \frac{d_2}{(1 + d_1/r_1)(d_1 + d_2)},$$

$$q'_2 = -q \frac{r_2 d_1}{(r_1 + d_1)(d_1 + d_2)} = -q \frac{d_1}{(1 - d_2/r_2)(d_1 + d_2)}.$$

$$q'_1 = -q \frac{d_2}{d_1 + d_2},$$

$$q'_2 = -q \frac{d_1}{d_1 + d_2}.$$
