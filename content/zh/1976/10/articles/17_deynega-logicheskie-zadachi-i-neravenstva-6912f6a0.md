逻辑问题和不等式

完成作业后，五年级学生 Voloda 开始解决教科书“Matematika，5”（M.，1976）中的第 1291 号逻辑问题，该问题是数学圈的作业。她在这里。

三名选手参加了现代赛跑：阿夫杰耶夫、瓦西里耶夫和谢苗诺夫。首先，一位观众说阿夫杰耶夫将是第一个到达的，第二个是谢苗诺夫不会是最后一个到达的，第三个是瓦西里耶夫不会是第一个到达的。比赛结束后，发现一名观众离开了，另外两名观众犯了错误。歌声是怎样结束的？

时间一天天过去，沃洛达依然没能解决问题。最后，他向姐姐娜塔莎寻求帮助。

- 你自己想想吧！ ——姐姐说，只管自己的事。

- 所以我一直在想...拜托...我不经常求助于你...

“好吧，”娜塔莎说。 “但是让我们用不等式来解决这个问题吧。”美好的？

- 我不介意，但是怎么样 - 不平等？老师没有那样表现，我们解决了逻辑问题...... - 沃洛达很惊讶。

- 所以呢？我们将以自己的方式做出决定。首先，我们用 a 来表示阿夫杰耶夫所占据的位置，用 b 来表示瓦西里耶夫所占据的位置，用 c 来表示谢苗诺夫所占据的位置。参赛者共有三名，因此他们每个人都可以获得第一、第二或第三名。

这意味着a、b和c只能等于1、2或3。想想这个如何写成不等式的形式？ a 位于哪些自然数之间？乙？ c？

沃洛达想了想，写下了：1≤a≤3、1≤b≤3、1≤c≤3。

“是啊，”姐姐说。 “现在让我们试着用 a、b 和 c 的量写下问题的条件。”问题说“阿夫杰耶夫将首先到达”，因此 a = 1。然后“谢苗诺夫不会是最后一个”，这意味着他可以获得第一或第二名，因此，正如您自己已经同意的那样，我们写 c = 1 或 c = 2。如何使用不等式来表达这一点？

“我明白，”沃洛达说。 “我们必须这样写：1 ≤ c ≤ 2。那么‘瓦西里耶夫不会先到达’这句话将类似地写成：2 ≤ b ≤ 3。”

- 非常好。让我们写下我们聚集在一起的一切：

$$\begin{cases}
(1) a = 1, \\
(2) 1 \leq c \leq 2, \\
(3) 2 \leq b \leq 3.
\end{cases}$$

我们将这样的记录称为“系统”。但这个系统还没有表达问题的全部内容。例如，我们还没有使用“一个观众离开，另外两个人犯了错误”这一事实。我们如何使用不等式来写入这些数据？

- 不平等？...我无法想象...

看。 “猜”和“错”这两个词表达了相反的逻辑“动作”；它们互相反映：
“猜对了”——“没有错”
“我错了”——“我没有猜到。”
正如我们所看到的，这是使用私有 NOT 完成的。
至于我们的任务，让我们创建一个表：

| 直接陈述 | 相反的说法 |
| :--- | :--- |
| 并且等于$B(A=B)$ | A不等于$B(A \neq B)$； $A > B$ 或 $A < B$ |
| 还有更多$B(A > B)$ | 不再$B(A \leq B)$ |
| 并且小于$B(A < B)$ | 并且不少于$B(A \geq B)$ |
| 相反的说法 | 直接陈述 |

娜塔莎继续说，利用这张表，我们可以将“三个观众中的一个猜到了跑步者占据的位置，而另外两个猜错了”这句话翻译成不等式的语言。我们自己尝试一下吧。
沃洛佳完成了这项任务，我们展示了他的笔记。
如果观众我猜对了，而观众II和III猜错了（见系统（*））：

$$\begin{cases} a = 1, \\ c = 3, \\ b = 1. \end{cases}$$

如果观众 II 猜对了，而观众 I 和 III 猜错了：

$$\begin{cases} 2 \leq a \leq 3, \\ 1 \leq c \leq 2, \\ b = 1. \end{cases}$$

如果观众 III 猜对了，而观众 I 和 II 猜错了：

$$\begin{cases} 2 \leq a \leq 3, \\ c = 3, \\ 2 \leq b \leq 3. \end{cases}$$

⟦folio 59⟧

红色连衣裙，朋友 - 白色，高级 - 蓝色。当被问到每个女孩穿什么样的衣服时，她们给出了答案：安雅（Anya）穿红色，瓦里亚（Varya）不是红色，克拉瓦（Klava）不是蓝色。在这个答案中，三个陈述之一是正确的，两个是错误的。每个女孩都穿什么衣服？

- 还有不平等的帮助吗？ - 沃洛达问道。
- 当然！ ——姐姐回答道。
“但我不知道哪个更大——蓝色、红色还是白色，”沃洛达愤愤不平，“总的来说，这是一项完全不同的任务，与之前的任务完全不同。”
“好吧，我给你一点帮助。”娜塔莎说道。 “我们来数一下颜色吧。”红色空色将是第一个，白色将是第二个，蓝色将是第三个。
“啊……那我大概可以解决这个问题了。”沃洛达略一犹豫后说道。 “我将用 a 表示 Anya 棋盘的颜色，用 b 表示 Varya 棋盘的颜色，用 c 表示 Klava 棋盘的颜色。”现在我将使用不等式写出条件
$$\begin{cases} a=1, \\ 2 \leq b \leq 3, \\ 1 \leq c \leq 2, \end{cases}$$

- 看，娜塔莎！但结果是同一个系统！同样，我们需要考虑三种情况，其中一种说法为真，另两种说法为假。这意味着在不解决问题的情况下，我可以立即说a=3，b=1，c=2。安雅（Anya）穿着蓝色连衣裙，瓦里亚（Varya）穿着红色连衣裙，而克拉瓦（Klava）穿着白色连衣裙！

“完全正确。”姐姐回答道。 “也许数学最重要的优势就在这里显现出来：用数学语言写出的完全不同的问题可以变成同一个问题。”因此，解决了其中一个问题后，我们就得到了其余问题的解决方案。当你长大后，你会发现物理、化学、经济学、生物学的各种问题往往都是同一个数学问题。
