这三个问题的答案都是肯定的。让我们举一些例子来说明一些事情是可以如此随机的。

a) 两个数字：2 和-1。

b) 八个数字：4/5、4/5、-1/10、-1/10、...、-1/10。

它们的和是 1，立方和是 $2 \cdot (4/5)^3 - 6 \cdot (1/10)^3 = 1,018$。以下示例基于相同的想法 - 比较正数并向其添加负数 - 数量较大，但数量较小。

b) 让我们制作一个系列

$$1 + (-1/2) + (-1/2) + 1/2 + (-1/4) + (-1/4) + (1/2) + (-1/4) + (-1/4) + \dots$$

如下：在求和 1 + (-1/2) + (-1/2) 之后，我们输入 2^3 = 8 个和 $1/2$ + (-1/4) + (-1/4)，然后 3^3 = 27 个和 $1/3$ + (-1/6) + (-1/6)，...，$n^3$ 和 $(1/n) + (-1/2n) + (-1/2n)$，依此类推。该级数收敛且其和等于 0，因为其第一项的和 $N$，其中 3 ($1 + 2^3 + 3^3 + \dots + n^3$) ≤ $N \leq 3$ [1 + 2^3 + 3^3 + ... + ($n + 1$)]，不大于 $1/(n+1)$（即，它要么为零，要么 $1/(n+1)$，要么$1/(n+1)$）。相应的立方体行发散。事实上，$(1/n)^3 + (-1/2n)^3 + (-1/2n)^3 = 3/4n^3$之和的$n^3$之和等于$3/4$，因此级数的前3项（$1 + 2^3 + \dots + n^3$）之和等于$3n/4$。

当然，如果在问题陈述中所有数字都假设为正数，那么所有三个问题的答案都将为负数。

B·科洛索夫

a) 让我们假设$k(k+1)(k+2)=u^n$，$n>1$。数字$k+1$与数字$k$和$k+2$互质；因此$k+1=m^n$，$k(k+2)=k^2+2k=l^n$（这是关于自然数分解为质因数的唯一性的算术基本定理的结果）。那么$(k+1)^2=k^2+2k+1=m^2n$，即$(m^2)^n — l^n = 1$，是一个矛盾：$(a^n - b^n) = (a - b)(a^{n-1} + a^{n-2}b + \dots + b^{n-1}) \neq 1$。这意味着三个连续自然数的乘积不能是自然数的幂。

b) 让我们证明在这种情况下答案是否定的。让我们假设相反的情况：假设对于某些$k(k+1)(k+2)=u^n$。
