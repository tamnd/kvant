M370。令 $a, b, c$ 为正数的三元组。让我们用它们组成一个新的轨道：
$$|a - b|, |b - c|, |c - a|,$$

让我们引入以下符号：$\widehat{ABO} = \widehat{ACO} = \alpha = 90^\circ - \widehat{A}$；
$\widehat{BAO} = \widehat{BCO} = \beta = 90^\circ - \widehat{B}$，$\widehat{CAO} = \widehat{CBO} = \gamma = 90^\circ - \widehat{C}$。假设点 $B_1$ 与圆 $\omega$ 的切线 $B_1C_1$ 与直线 $B_1O$ 之间的角度等于 $\beta$ (图 3)。让我们从点 $C_1 - [C_1A_1]$ 画一条到 $\omega$ 的切线。让我们证明$B_1A_1$也是切线，即$C_1\widehat{B_1A_1} = 2\beta$。考虑四边形 $AC_1OB_1$。从$C_1AO = C_1B_1O = \beta$开始可以在它周围画一个圆。由四边形$AC_1OB_1$内接，可知角$OAB_1$和$OC_1B_1$相等，即：$OAB_1 = OC_1B_1 = \gamma$。因此$B_1\widehat{C_1A_1} = 2\gamma$。类似地，证明了可以围绕四边形$C_1BA_1O$：$OC_1A_1 = OBA_1 = \gamma$描述圆。这又意味着角度 $C_1BO$ 和 $C_1A_1O$ 相等：$C_1\widehat{BO} = C_1\widehat{A_1O} = \alpha$。

现在让我们考虑四边形$B_1OA_1C$。让我们证明可以围绕它描述一个圆。确实，$B_1\widehat{OA_1} = 2\pi - (B_1OC_1 + C_1OA_1) = \alpha + \beta + 2\gamma$，所以$B_1\widehat{OA_1} + \widehat{C_1} = 2(\alpha + \beta + \gamma) = \pi$。因此，角 $OB_1A_1$ 和 $OC_1A_1$ 相等，内接于同一个弦 $OA_1$：$OB_1A_1 = OCA_1 = \beta$，因此$C_1\widehat{B_1A_1} = 2\beta$。同样，证明$C_1\widehat{A_1B_1} = 2\alpha$，即$B_1A_1$确实是一条切线（而$A_1B_1C_1$就是我们想要的三角形）。

剩下的就是构造一个点 $B_1$，从该点可以以角度 $2\beta$ 看到圆 $\omega$。我们假设切线 $B_1C_1$ 已经存在。让我们将圆的半径 $\omega$ 绘制到接触点。如果半径为$r$，则线段$B_1O$的长度为$r/\sin \beta$。因此，我们可以通过三角形$ABC$的边$AC$与圆$C$中心在半径为$r/\sin \beta$的点$O$相交得到点$B_1$。

该圆与 $[AC]$ 相交的哪一点 $B_1$（可以有两个、一个或没有这样的点）对应于所需的三角形 $A_1B_1C_1$：

所以，我们已经弄清楚如何构造一个三角形$A_1B_1C_1$，其角$A_1, B_1, C_1$分别为$2\alpha, 2\beta$和$2\gamma$。事实证明我们的问题没有其他解决办法。事实上，我们将证明，从所需三角形 $A_1B_1C_1$ 的顶点 $B_1$ 来看，圆 $\omega$ 在角度 $2\beta$ 处可见。

设 $B' \in [AC]$，并设 $C'B'O < \beta$（$C'B'$ 与 $\omega$ 相切）。通过点 $A, C'$ 和 $O$ (图 4) 画圆；那么点$B'$位于该圆之外并且$B'C'O < \gamma$（确保这是真的）。如果$A' \in [BC]$和$C'A'$与$\omega$相切，则$B'C'A' < 2\gamma$。同样，$C'A'B' < 2\alpha$，因此假设存在的三角形$A'B'C'$（顶点$B'$与$B_1$不同）中的角度总和小于$2\alpha + 2\beta + 2\gamma = \pi$ - 这是一个矛盾。 $C'B'O > \beta$时的情况类似处理。
