逻辑问题和不等式

完成作业后，五年级学生 Voloda 开始解决教科书“Matematika，5”（M.，1976）中的第 1291 号逻辑问题，该问题是数学圈的作业。她在这里。

三名选手参加了现代赛跑：阿夫杰耶夫、瓦西里耶夫和谢苗诺夫。首先，一位观众说阿夫杰耶夫将是第一个到达的，第二个是谢苗诺夫不会是最后一个到达的，第三个是瓦西里耶夫不会是第一个到达的。比赛结束后，发现一名观众离开了，另外两名观众犯了错误。歌声是怎样结束的？

时间一天天过去，沃洛达依然没能解决问题。最后，他向姐姐娜塔莎寻求帮助。

- 你自己想想吧！ ——姐姐说，只管自己的事。

- 所以我一直在想...拜托...我不经常求助于你...

“好吧，”娜塔莎说。 “但是让我们用不等式来解决这个问题吧。”美好的？

- 我不介意，但是怎么样 - 不平等？老师没有那样表现，我们解决了逻辑问题...... - 沃洛达很惊讶。

- 所以呢？我们将以自己的方式做出决定。首先，我们用 a 来表示阿夫杰耶夫所占据的位置，用 b 来表示瓦西里耶夫所占据的位置，用 c 来表示谢苗诺夫所占据的位置。参赛者共有三名，因此他们每个人都可以获得第一、第二或第三名。

这意味着a、b和c只能等于1、2或3。想想这个如何写成不等式的形式？ a 位于哪些自然数之间？乙？ c？

沃洛达想了想，写下了：1≤a≤3、1≤b≤3、1≤c≤3。

“是啊，”姐姐说。 “现在让我们试着用 a、b 和 c 的量写下问题的条件。”问题说“阿夫杰耶夫将首先到达”，因此 a = 1。然后“谢苗诺夫不会是最后一个”，这意味着他可以获得第一或第二名，因此，正如您自己已经同意的那样，我们写 c = 1 或 c = 2。如何使用不等式来表达这一点？

“我明白，”沃洛达说。 “我们必须这样写：1 ≤ c ≤ 2。那么‘瓦西里耶夫不会先到达’这句话将类似地写成：2 ≤ b ≤ 3。”

- 非常好。让我们写下我们聚集在一起的一切：

$$\begin{cases}
(1) a = 1, \\
(2) 1 \leq c \leq 2, \\
(3) 2 \leq b \leq 3.
\end{cases}$$

我们将这样的记录称为“系统”。但这个系统还没有表达问题的全部内容。例如，我们还没有使用“一个观众离开，另外两个人犯了错误”这一事实。我们如何使用不等式来写入这些数据？

- 不平等？...我无法想象...
