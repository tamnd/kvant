6) 让我们举一个例子来说明 0 可能不会出现在任何三元组中。让我们从三元组 ($\lambda, \lambda^2, \lambda^3$) 开始，其中选择$\lambda$，以便下一个三元组中的数字

$$|\lambda^2 - \lambda|, |\lambda^3 - \lambda^2|, |\lambda^3 - \lambda|$$

与前三者的数量成正比。由于$\lambda^2 - \lambda = \lambda(\lambda - 1), \lambda^3 - \lambda^2 = \lambda^2(\lambda - 1), \lambda^3 - \lambda = (\lambda^2 + \lambda)(\lambda - 1)$，为此我们取$\lambda$等于方程$\lambda^2 + \lambda = \lambda^3$的正根：即$\lambda = (1 + \sqrt{5})/2$。在这种情况下，第 $n$ 个三元组将如下所示：$\lambda(\lambda - 1)^{n-1}, \lambda^2(\lambda - 1)^{n-1}, \lambda^3(\lambda - 1)^{n-1}$（这很容易使用归纳法进行检查），因此没有一个数字等于 0。

让我们用$v_0$表示第一个（受影响的）球的初始速度，用$v_1$和$v_2$表示第一个和第二个球在最大变形时刻的速度。根据能量守恒定律

$$\frac{mv_0^2}{2} = \frac{mv_1^2}{2} + \frac{mv_2^2}{2} + \Pi,$$

其中$m$为每个球的质量，$\Pi$为球弹性变形势能的最大值。

让我们引入坐标系$XOY$，并找到速度$v_1$和$v_2$在相应坐标轴上的投影。当远离时，我们将沿着连接球中心的线引导 $OX$ 轴 (图 5)。沿着这个方向，球之间将发生一般的LOB弹性冲击。由于球系统是孤立的，因此系统动量在 $OX$ 轴上的投影得以保留。在初始时刻，该投影等于 $mv_0 \cos \alpha$。当球的变形最大时，它们的速度在$OX$轴上的投影是相同的：$v_{1x} = v_{2x} = v_x$。

由动量守恒定律

$$mv_0 \cos \alpha = 2mv_x,$$

或者

$$v_{1x} = v_{2x} = v_x = \frac{1}{2} v_0 \cos \alpha.$$

由于球绝对光滑，因此不会发生沿 $OY$ 轴的相互作用。第一个球的速度在该轴上的投影不会改变：

$$v_{1y} = v_{0y} = v_0 \sin \alpha,$$

第二个球的速度投影保持为零：

$$v_{2y} = 0.$$

因此，能量守恒定律可以写成如下：

$$\frac{mv_0^2}{2} = \frac{m(v_1^2 + v_2^2)}{2} + \frac{m(v_2^2 + v_1^2)}{2} + \Pi,$$

或者

$$\frac{mv_0^2}{2} = \frac{mv_0^2 \cos^2 \alpha}{4} + \frac{mv_0^2 \sin^2 \alpha}{2} + \Pi.$$
