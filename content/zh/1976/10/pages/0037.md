推理与任务 a) 中的相同：我们构造两个接近的数，每个数都必须是 $n$ 次方，以及矛盾的方法。 $n = 2$ 和 $n \ge 3$ 的距离是分开的。

一、$n = 2$。我们有$(k^2 + 3k)(k^2 + 3k + 2) = u^2$。用$y$表示$k^2 + 3k + 1$，我们得到等式$y^2 - 1 = u^2$，这对于自然数$u$和$y$来说是不可能的。

二. $n \ge 3$。请注意，数字 $k + 1$ 或 $k + 2$ 与其他三个数字互质。

1) 令数字$k + 1$与$k$、$k + 2$和$k + 3$互质。然后（参见a点的解决方案））$k + 1 = m^n$，$k(k + 2)(k + 3) = l^n$。我们有$k = m^n - 1$、$k + 2 = m^n + 1$、$k + 3 = m^n + 2$；意思是$(m^n - 1)(m^n + 1)(m^n + 2) = m^{3n} + 2m^{2n} - m^n - 2 = l^n$。因为$m \ge 2$和$n \ge 3$，$2m^{2n} - m^n - 2 > 0$，也就是$l^n > (m^3)^n$，或者$l > m^3$。另一方面，$(m^3 + 1)^n > m^{3n} + nm^{3n-3} > m^{3n} + 2m^{2n} - m^n - 2 = l^n$，来自$l < m^3 + 1$。所以一定有$m^3 < l < m^3 + 1$，这对于自然数$m$和$l$来说是不可能的。

2) 如果数字$k + 2$与$k$、$k + 1$和$k + 3$互质，则$k + 2 = m^n$、$k(k + 1)(k + 3) = l^n$或$(m^n - 2)(m^n - 1)(m^n + 1) = l^n$，即$l^n = m^{3n} - 2m^{2n} - m^n - 2 = l^n$，由此产生$l < m^3 + 1$。所以一定有$m^3 < l < m^3 + 1$，这对于自然数$m$和$n$来说是不可能的。因此，$l < m^3$。

现在让我们比较$l$和$m^3 - 1$。为此，我们注意以下事项。从$m^3 > 4$开始，我们有$m^{3n-3} > 4m^{3n-6}$；以及自$n \ge 3$以来的$3n - 6 \ge n$。因此$m^{3n-3} > 3m^{3n-6} + m^n$。现在让我们估计 $(m^3)^n$ 和 $(m^3 - 1)^n: (m^3)^n - (m^3 - 1)^n = m^{3n-3} + m^{3n-6} (m^3 - 1) + m^{3n-9} (m^6 - 2m^3 + 1) + \dots + (m^3 - 1)^{n-1} > 3m^{3n-3} - 3m^{3n-6} > 2m^{3n-3} + m^n > 2m^{2n} + m^n - 2 = (m^3)^n - l^n$ 之间的差异。

因此$(m^3 - 1)^n < l^n$，即$m^3 - 1 < l < m^3$，不可能，因为$m$和$l$是自然的。

由此产生的矛盾证明了我们的假设：四个连续自然数的乘积不能等于一个自然数的幂。

M368。证明三个半径为 1 的直立圆柱体的交点（其描述成对相互垂直（但不一定相交））包含在某个半径为 $\sqrt{3}/2$ 的球内

作业中讨论的空间函数，三个圆柱体的交集，是相当难以想象的。但这不是必要的：解决问题很简单，如果把它翻译成代数的语言——使用坐标法。

让我们选择一个坐标系，如下所示：构造一个直平行六面体，其三个边沿着圆柱体的轴（为此，您需要通过每个圆柱体的轴绘制两个平面，与其他两个圆柱体的轴平行）；让我们将坐标原点放置在该平行六面体的中心，并将轴平行于其边缘 (图 2)。那么如果点 $(x, y, z)$ 属于圆柱体的内部，则不等式成立

$$(x - a)^2 + (y + b)^2 \leq 1, (y - b)^2 + (z + c)^2 \leq 1, (z - c)^2 + (x + a)^2 \leq 1$$

（2a、2b 和 2c 是构造的平行六面体的边的长度）。添加这些不等式，对于圆柱相交的内点$(x, y, z)$，我们得到

$$(x^2 + y^2 + z^2) + (a^2 + b^2 + c^2) \leq 3/2,$$

即$x^2 + y^2 + z^2 \leq 3/2$，这是需要证明的。
