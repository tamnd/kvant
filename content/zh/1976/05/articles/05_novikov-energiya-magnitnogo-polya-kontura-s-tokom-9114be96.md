通过分析电磁感应很容易理解，电流的磁场具有最大的能量。让我们用图所示的图在心里进行一下实验。如果移动电阻滑块使电阻器的电阻减小，则电路中的电流应该增加。电流值越大，该电流产生的磁场感应值就越大。随着磁场增加，通过载流电路所界定的平面的磁感应矢量的通量增加。但根据法拉第定律，当电路中的磁感应通量发生变化时，就会产生自感电动势，其大小等于

$$E_{is} = -\frac{\Delta \Phi}{\Delta t},$$

其中$\Delta \Phi$是磁感应通量随时间$\Delta t$的变化。由该$3. d. c.$产生的感应电流产生磁场，其感应方向与主电流的磁场感应方向相反。因此，所创建的磁场的磁通量倾向于补偿主磁场的磁通量的变化，即，它实际上倾向于保持主电流恒定。为了抵消这种效应，必须针对自感应电动势做一些工作。我们来计算一下这项工作。

如果在时间$\Delta t$期间电流从值$I$增加到值$I + \Delta I$，同时出现$\mathcal{E}_{is}$，则电流源相对于该值$3. d. c.$的功等于

$$\Delta A = -\mathcal{E}_{is}I\Delta t.$$

将这里的表达式（1）替换为$3. d. c.$自减，我们得到

$$\Delta A = \frac{\Delta \Phi}{\Delta t}I\Delta t = I\Delta \Phi.$$

现在请记住，每个电路都可以用某个值 $L$ 来表征，称为自感系数或电感。 $L$的值通常被定义为磁通量$\Phi$与引起该令牌的令牌$I$的力的大小相关的公式中的比例系数，即

$$\Phi = LI.$$

因此，如果电流改变值$\Delta I$，则磁感通量改变值

$$\Delta \Phi = L \Delta I.$$

因此，我们可以将式（2）写成如下：

$$\Delta A = LI \Delta I = \Phi \Delta I.$$

很容易看出环中应该产生电流。为了明白这一点，让我们概括地回顾一下固体金属的结构。金属物质的原子位于晶格的底部，仅在平衡附近进行微小的振动。我们可以认为晶格形成了金属体的坚固框架。与离子相反，金属中的传导电子可以在晶格位点之间的空间中自由混合，形成一种带电气体。

现在让我们再次转向我们的金属环。我们可以将其想象为一组相互插入的两个环，类似于图4中的描述。这里的蓝色指的是晶格，红色指的是电子气。起初，当圆环以恒定速度旋转时，晶格和带电气体均等地参与了这种运动。当该层减速时，可以说，$F$应用于环的固体框架，即晶格。仅当电子与晶格直接相互作用时，电子气才应开始减速。这种相互作用决定了金属的电阻。因此，为了简单起见，我们可以完全跳过它们，例如，考虑到我们的环在制动之前被冷却到如此低的温度，以至于金属进入超导状态，即其电阻变得等于零。

因此，当环减速时，金属中的传导电子开始围绕晶格移动。离子和电子运动速度的差异导致了电流的出现。让我们计算一下当前值。

让我们用$v_i$表示晶格电子的速度，用$v_e$表示传导电子的定向运动的速度。那么，在时间 $\Delta t$ 内流经环截面$s$的总电荷由包围在长度$v_i \Delta t$的弧内的晶格电荷和包围在长度$v_e \Delta t$的弧内的电气体电荷组成（参见图4）。如果我们用$Q$表示晶格中所有电子的总电荷，那么环中传导电子的总电荷将等于-$Q$（因为金属环作为一个整体是带电的）。因此，电荷按照其方向，$Q \frac{v_i \Delta t}{l}$和$-Q \frac{v_e \Delta t}{l}$，其中$l$是环的长度。现在我们可以求出单位时间内金属环的总能量，即计算环中的电流：

$$I = \frac{1}{\Delta t} \left[ Q \frac{v_i \Delta t}{l} - Q \frac{v_e \Delta t}{l} \right] = \frac{Q}{l} \left(v_i - v_e\right).$$

为了更清楚地想象晶格和传导电子（电子气）运动的动力学，在心理上将它们分开并单独考虑是很方便的。在 图 5, a 上，与直径相关的晶格的所有运动均单独显示（蓝色环），在 图 5, b 上 - 与直径相关的电子气的所有运动（红色环）。现在我们可以轻松地写出应用于晶格和电子的牛顿定律。令蓝色环和红色环的质量等于相应的$M$和$m$，以及它们的加速度$a_i$和$a_e$。然后

$$Ma_i = QE - F, \quad (9)$$

$$ma_e = -QE,$$

其中$E$是强涡旋电场。让我们计算一下这个张力的值。

由于涡流场力沿环移动单个电荷所做的功等于 e。 d.s.自感应，即 $El = \mathcal{E}_{is}$，则

$$E = \frac{\mathcal{E}_{is}}{l} = -\frac{1}{l} \frac{\Delta \Phi}{\Delta t} = -\frac{L}{l} \frac{\Delta I}{\Delta t} = -\frac{QL}{l^2} \left( \frac{\Delta v_i}{\Delta t} - \frac{\Delta v_e}{\Delta t} \right) = -\frac{QL}{l^2} \left( a_i - a_e \right).$$

因此，晶格和电子气的运动方程（9）将如下：

$$Ma_i = -\mu \left( a_i - a_e \right) - F, \quad (10)$$

为了简洁起见，我们引入符号 $\mu = \frac{Q^2 L}{l^2}$。对$a_i$和$a_e$求解系统(10)，我们得到环的制动加速度：

$$a_i = -\frac{F}{M + \frac{m\mu}{m + \mu}}; \quad a_e = \frac{\mu}{m + \mu} a_i. \quad (11)$$

负号表示在制动过程中，晶格和电子气都会被替换。

知道了加速度，我们就可以求出从制动开始到 kolyz 晶格停止的那一刻所经过的时间：

$$t = -\frac{v_0}{a_i} = \frac{v_0}{F} \left( M + \frac{m\mu}{m+\mu} \right).$$

现在很容易找到电子在制动结束时的速度$v_e = v$：

$$v = v_0 + a_e t = \frac{m}{m+\mu} v_0.$$

因此，轮子中电流的最终值（$v_e = v$、$v_i = 0$）等于

$$I = -\frac{Q}{l} v = -\frac{Q}{l} \frac{m}{m+\mu} v_0.$$

现在我们可以继续解决一开始提出的问题：确定车轮制动时产生的电流磁场的能量。为此，可以方便地利用能量守恒定律。

在初始时刻（$t = 0$），kolys的全部能量由电子和晶格的动能组成，即

$$E_0 = \frac{mv_0^2}{2} + \frac{Mv_0^2}{2}.$$

制动过程中，部分能量用于对抗力$F$。这种能量“损失”显然等于 $\Delta E = A = FS$，其中 $S$ 是制动期间环（晶格）任意点所经过的路径：

$$S = v_0 t + \frac{a_i t^2}{2} = \frac{v_0^2}{2F} \left( M + \frac{m\mu}{m+\mu} \right).$$

所以

$$A = \frac{v_0^2}{2} \left( M + \frac{m\mu}{m+\mu} \right).$$

车轮制动过程中产生的电子电流感应出磁场。因此，在制动结束时，当晶格的速度为零时，车轮的能量由电子的动能组成

$$K_e = \frac{mv^2}{2} = \frac{mv_0^2}{2} \left( \frac{m}{m+\mu} \right)^2$$

和磁场能量$W_M$。根据能量守恒定律

$$E_0 = K_e + W_M + A,$$

在哪里

$$W_M = E_0 - A - K_e = \frac{Mv_0^2}{2} + \frac{mv_0^2}{2} - \frac{v_0^2}{2} \left( M + \frac{m\mu}{m+\mu} \right) - \frac{mv_0^2}{2} \left( \frac{m}{m+\mu} \right)^2 = \frac{mv_0^2}{2} \frac{m\mu}{(m+\mu)^2}.$$

将值$\mu$代入该表达式并考虑$\frac{mv_0}{m+\mu} = -I \frac{l}{Q}$（参见（14）），我们得到

$$W_M = I^2 \frac{l^2}{Q^2} \frac{Q^2 L}{2l^2} = \frac{LI^2}{2}.$$

因此，我们再次得出先前获得的电流$I$电路的磁能表达式。

最后让我们注意到一个有趣的情况。众所周知，两个正数的算术平均值不能小于这些数的几何平均值，即$m + \mu \geq 2\sqrt{m\mu}$，因此$\frac{m\mu}{(m+\mu)^2} \leq \frac{1}{4}$。因此，由式（15）我们可以得出：

$$W_M \leq \frac{1}{4} \frac{mv_0^2}{2}.$$

由此，我们得出结论：当对第一绕未绞合电路进行制动时，传导电子定向运动的初始动能中不超过25%可以转化为电流磁场的能量。该限制不取决于电路电感的值。
