⟦folio 11⟧

是否有可能理解根据万有引力定律相互作用的物体如何运动？例如，行星如何运动？假设在某些初始时刻，我们知道 $n$ 行星的确切坐标及其速度，并且已知每个行星仅受其余 ($n-1$) 行星的引力影响。根据这些初始条件，有必要确定未来行星的运动。

支配这一运动的定律是熟悉的牛顿第二定律和万有引力定律。使用immi，你可以想象行星的运动。对于由两个物体组成的系统（$n=2$），这个问题首先由牛顿解决。在这种情况下，可以根据初始条件随时以任何精度确定系统的状态（物体的坐标、速度等）。

但当科学家开始研究由多个物体组成的系统时，他们在纯数学表征方面遇到了巨大的困难。对于案例 $n=3$ 来说，在一般情况下不可能获得问题的精确解。直到中午，尽管世界各地的数学家经过两百五十年的努力，仍然无法用已知的数学手段准确地解决这个问题。这就是为什么“问题$n$体”——力学中的这个问题被称为——引起了数学家的注意。

另一个动机是$n$天体问题对于天体力学和航天学的巨大重要性。因此，与其相关的著作总数达到两千，并且每年出现15-20项新研究也就不足为奇了。

⟦folio 12⟧

现在有许多方法可以近似解决$n$物体的问题，允许每个特定的物体系统在给定的特定初始条件下以任何有限时间内练习所需的精度构建运动轨迹。

这些方法的有效性和可靠性尚未经过多次测试，特别是在计算航天器和行星际站的轨迹时。

正是利用这些方法，亚当斯和勒维耶“笔尖”发现了海王星。

拉格朗日问题

因此，问题 $n$ 的解恰好没有实体。但对于某些“特殊”初始条件下的部分情况$n = 3$，法国著名数学家拉格朗日在200年前就找到了精确解。

它的解——被称为$n$体问题的拉格朗日解——是目前已知的该问题的唯一精确解。

在本文中，我们将考虑拉格朗日问题的最简单部分。

质量三角形

让三个质量为$m_1, m_2, m_3$的物体做同心圆旋转，圆心在点$O$（见图1）。物体轨道半径分别为$r_1, r_2$和$r_3$，物体之间的距离$R_1, R_2, R_3$远大于物体的尺寸。每个点的向心加速度是由邻近点作用在其上的重力赋予的，即等于这些力之和（矢量！）的力。让我们写出物体的运动方程：

$$\begin{align*}
F_{12} + F_{13} &= m_1 a_1, \\
F_{21} + F_{23} &= m_2 a_2, \\
F_{31} + F_{32} &= m_3 a_3.
\end{align*}$$

这里$|F_{ij}| = \gamma \frac{m_i m_j}{r_{ij}^2}$是物体$m_j$作用于物体$m_i$的牛顿力值。由于所有物体以相同的角速度$\omega$旋转（根据问题的条件），那么

$$a_1 = -\omega^2 r_1, \quad a_2 = -\omega^2 r_2, \quad a_3 = -\omega^2 r_3,$$

我们所有进一步的推理都将纯粹是“算术”，乍一看它们似乎与问题无关。但正是它们将引导我们解决问题（或者更确切地说，问题的第一部分）——它们将允许我们确定物体的配置。

让我们逐项添加系统 (1) 中的等式：

$$F_{12} + F_{13} + F_{21} + F_{23} + F_{31} + F_{32} = m_1 a_1 + m_2 a_2 + m_3 a_3 = -\omega^2 (m_1 r_1 + m_2 r_2 + m_3 r_3).$$

这个等式的左边等于零——毕竟，根据牛顿第三定律，封闭系统中所有内力的总和等于零。 （左边可以这样写：

$$\sum_{i,j=1}^{3} F_{ij} + \sum_{i,j=1}^{3} F_{ji} = 0, \text{ так как } F_{ij} = -F_{ji}.$$

所以我们有

$$m_1 r_1 + m_2 r_2 + m_3 r_3 = 0$$

（自 $\omega \neq 0$ 起）。等式（2）本质上指定了旋转中心的位置：它位于这样一个点$O$，使得物体$m_1, m_2, m_3$相对于该点的半径向量必须满足条件（2）。

$$(m_1 + m_2 + m_3) r_1 = m_2 R_3 + m_3 R_2.$$

从这里

$$r_1 = \frac{m_2}{m_1 + m_2 + m_3} R_3 + \frac{m_3}{m_1 + m_2 + m_3} R_2$$

运动稳定性

但是我们找到这三个物体的所有配置了吗？不，我们还没有分析物体直线排列的情况；还有一种类似的结构，三个物体可以一体旋转。事实证明这个配置不稳定。一旦偏离直线“移动”一点，力量的协调就立即被打乱，偏差开始加大。

三角形构型稳定吗？并非总是如此。 1843年，加肖首先确定了拉格朗日三角形稳定的条件。他表明，如果大物体（位于三角形底部）的质量使得它们的比率（较小质量与较大质量的比率）足够小并且满足条件，则该构型将是稳定的

$$\frac{(m_1 + m_2)^2}{m_1 m_2} > 27.$$

如果一个质量远小于$m_1$和$m_2$的宇宙粒子，以相对较低的速度运动，意外地撞到等边三角形的顶点，其底边的质量为$m_1$和$m_2$，那么它就会发现自己被“困住”了。在这种情况下，粒子可以在顶部附近描述非常复杂的轨迹

朗格朗日三角形，但整个构型将作为一个整体旋转。

木星的质量比太阳的质量小一千倍。与它们中的任何一个相比，特洛伊木马的总质量可以忽略不计。稳定条件得到了很大程度的满足。地月系统也存在这种不等式：质量相差 81 倍。

这个条件如何推导出来呢？也许有一个简单的结论，但这个问题仍然很复杂，无论如何，需要专门讨论。

练习

1. 文章没有计算质量三角形的旋转角速度。证明$\omega^2 = \gamma \frac{m_1 + m_2 + m_3}{R^3}$，其中$R$是质量之间的距离。

2. 我们认为质量三角形是“刚性的”。但事实证明，如果速度矢量的大小与到旋转中心的距离成正比，并且都以相同的角度指向连接物体和中心的线段，那么物体的构型在任何时候都保持与初始构型相似。等边三角形旋转后会拉伸或收缩。尝试证明一下。
