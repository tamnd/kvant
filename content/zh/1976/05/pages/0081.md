4. $x_1, x_2 = 2 \pm \sqrt{6}, \quad x_3 = 2, \quad x_4 = -1$.

$$x^2 + \frac{4}{x^2} = 5 \left( x - \frac{2}{x} \right).$$

11. $0, 31 \leqslant x < 5 + 2\sqrt{6}$。笔记。不等式相当于两个系统的组合：

12. $x_1 = k\pi, x_2 = \frac{5\pi}{4} + 2k\pi$ ($k = 0, \pm 1, \pm 2, \dots$).

13. $x = \frac{5\pi}{6} + 2k\pi$（$k = 0, \pm 1, \pm 2, \dots$）。笔记。 ODZ 中的该方程等价于方程

$$1 - \cos x - \sin x = \cos 2x - \sin 2x,$$

（简化为形式）

$$(\cos x + \sin x)(2 \sin x - 1) = 0.$$

方程 $\cos x + \sin x = 0$ 的根不包含在原方程的 ODZ 中：对于它们中的每一个，由于对应关系（4），我们有 $\cos 2x - \sin 2x = 1 - (\cos x + \sin x) = 1$，并且在 ODZ 中必须满足条件 $\cos 2x - \sin 2x \neq 1$。如果$\sin x = 1/2$，则$\cos x = \sqrt{3}/2$或$\cos x = -\sqrt{3}/2$。在第一种情况下

$$1 - \cos x - \sin x = \frac{1}{2} - \frac{\sqrt{3}}{2} < 0,$$

而在 ODZ 中，必须满足条件 $1 - \cos x - \sin x > 0$。在第二种情况下，满足定义 ODZ 的条件。

14. $NF: FM = \sqrt{3}$。笔记。将中心线延伸经过点 $M$，直到与一个圆在点 $L$ 相交，并超出点 $N$，直到与另一圆在点 $K$ 相交。证明 CLKB 是直的。使用相交弦段定理得出的等式：$PF \cdot FQ = LF \cdot FN, PF \cdot FQ = MF \cdot FK$。

15. $S_{\triangle AOB}: S_{\triangle ABC} = (9 + \sqrt{3}): 26$.

笔记。绘制高度：$SD$ – 侧面$ASC$、$SF$ – 侧面$CSB$、$SE$ – 侧面$ASB$；将点 $D, F, E$ 与点 $O$ 连接。证明$SD = SF = SE$和点$O$是三角形$ABC$的内接圆的圆心。证明$\triangle SDC = \triangle SFC, \triangle SFB = \triangle SEB, \triangle SEA = \triangle SDA$，并计算所有侧面的所有平面角。用侧面的长度或高度来表示线段$AE = AD, BE = BF, CF = CD$。编写平面三角形$AOB$和$ABC$的表达式，用$r$表示三角形$ABC$内切圆的半径。

16. $MN = 1/7$。笔记。请注意$MN = DM - DN$。要计算 $DM$ 和 $DN$，请使用以下几何事实：如果一个圆内切于三角形 $PQR$，并在点 $A, B, C$ 处接触三角形对应边 $PQ, QR, RP$，则为 $AQ = QB = p - PR, BR = RC = p - PQ, CP = PA = p - QR$，其中 $p$ 是三角形 $PQR$ 的多边形。
