⟦folio 32⟧

负号表示在制动过程中，晶格和电子气都会被替换。

知道了加速度，我们就可以求出从制动开始到 kolyz 晶格停止的那一刻所经过的时间：

$$t = -\frac{v_0}{a_i} = \frac{v_0}{F} \left( M + \frac{m\mu}{m+\mu} \right).$$

现在很容易找到电子在制动结束时的速度$v_e = v$：

$$v = v_0 + a_e t = \frac{m}{m+\mu} v_0.$$

因此，轮子中电流的最终值（$v_e = v$、$v_i = 0$）等于

$$I = -\frac{Q}{l} v = -\frac{Q}{l} \frac{m}{m+\mu} v_0.$$

现在我们可以继续解决一开始提出的问题：确定车轮制动时产生的电流磁场的能量。为此，可以方便地利用能量守恒定律。

在初始时刻（$t = 0$），kolys的全部能量由电子和晶格的动能组成，即

$$E_0 = \frac{mv_0^2}{2} + \frac{Mv_0^2}{2}.$$

制动过程中，部分能量用于对抗力$F$。这种能量“损失”显然等于 $\Delta E = A = FS$，其中 $S$ 是制动期间环（晶格）任意点所经过的路径：

$$S = v_0 t + \frac{a_i t^2}{2} = \frac{v_0^2}{2F} \left( M + \frac{m\mu}{m+\mu} \right).$$

所以

$$A = \frac{v_0^2}{2} \left( M + \frac{m\mu}{m+\mu} \right).$$

车轮制动过程中产生的电子电流感应出磁场。因此，在制动结束时，当晶格的速度为零时，车轮的能量由电子的动能组成

$$K_e = \frac{mv^2}{2} = \frac{mv_0^2}{2} \left( \frac{m}{m+\mu} \right)^2$$

和磁场能量$W_M$。根据能量守恒定律

$$E_0 = K_e + W_M + A,$$

在哪里

$$W_M = E_0 - A - K_e = \frac{Mv_0^2}{2} + \frac{mv_0^2}{2} - \frac{v_0^2}{2} \left( M + \frac{m\mu}{m+\mu} \right) - \frac{mv_0^2}{2} \left( \frac{m}{m+\mu} \right)^2 = \frac{mv_0^2}{2} \frac{m\mu}{(m+\mu)^2}.$$

将值$\mu$代入该表达式并考虑$\frac{mv_0}{m+\mu} = -I \frac{l}{Q}$（参见（14）），我们得到

$$W_M = I^2 \frac{l^2}{Q^2} \frac{Q^2 L}{2l^2} = \frac{LI^2}{2}.$$

因此，我们再次得出先前获得的电流$I$电路的磁能表达式。

最后让我们注意到一个有趣的情况。众所周知，两个正数的算术平均值不能小于这些数的几何平均值，即$m + \mu \geq 2\sqrt{m\mu}$，因此$\frac{m\mu}{(m+\mu)^2} \leq \frac{1}{4}$。因此，由式（15）我们可以得出：

$$W_M \leq \frac{1}{4} \frac{mv_0^2}{2}.$$

由此，我们得出结论：当对第一绕未绞合电路进行制动时，传导电子定向运动的初始动能中不超过25%可以转化为电流磁场的能量。该限制不取决于电路电感的值。
