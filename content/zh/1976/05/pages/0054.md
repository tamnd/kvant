> 从$\frac{\alpha_1}{\beta_1} < \frac{\alpha}{\beta}, \frac{\alpha_2}{\beta_2} < \frac{\alpha}{\beta}$得出$\frac{\alpha}{\beta}; 2^\circ$，得出$\frac{\alpha_1 + \alpha_2}{\beta_1 + \beta_2} < \frac{\alpha}{\beta}$（参见图3）。这就是为什么

$$\frac{a_{i_1} + b_{j_1}}{p_{i_1} + q_{j_1}} > \frac{a_{i_1} + a_{i_2} + b_{j_1} + b_{j_2}}{p_{i_1} + p_{i_2} + q_{j_1} + q_{j_2}},$$

$$\frac{a_{i_2} + b_{j_2}}{p_{i_2} + q_{j_2}} > \frac{a_{i_1} + a_{i_2} + b_{j_1} + b_{j_2}}{p_{i_1} + p_{i_2} + q_{j_1} + q_{j_2}},$$

这意味着

$$\frac{a_{i_1} + a_{i_2} + b_{j_1} + b_{j_2}}{p_{i_1} + p_{i_2} + q_{j_1} + q_{j_2}} > \frac{a_{i_1} + a_{i_2} + b_{j_1} + b_{j_2}}{p_{i_1} + p_{i_2} + q_{j_1} + q_{j_2}},$$

这是不可能的。得到了矛盾。因此，任何表$2 \times 2$都有一个鞍单元，并且问题6）的陈述是从a）点得出的。

L·利曼斯

让我们再给出第 6) 点的一个独立于 a) 的证明。

让我们考虑两个函数：

$$f(t) = \max_i (a_i - p_i t),$$

和

$$g(t) = \max_j (q_j t - b_j),$$

为所有 $t$ 定义。 （这样的函数称为分段线性；它们的图形是折线。）函数 $f$ 是严格消杀，函数 $g$ 是严格递增（因为数字 $p_i$ 和 $q_j$ 是正数）。因此，存在一个数 $t_0$ 使得 $f(t_0) = g(t_0)$ — 图 4。

让我们证明这个数字 $t_0$ 是我们表中的一个元素。事实上，对于某些索引 $i_0, j_0$，我们有：

$$a_{i_0} - p_{i_0} t_0 = q_{j_0} t_0 - b_{j_0},$$

在哪里

$$t_0 = \frac{a_{i_0} + b_{j_0}}{p_{i_0} + q_{j_0}}.$$

让我们证明这个元素$t_0$是我们表的鞍形元素。根据函数$f$的定义可以得出：

$$a_i - p_i t_0 \leq a_{i_0} - p_{i_0} t_0 = q_{j_0} t_0 - b_{j_0},$$

因此，

$$t_0 \geq \frac{a_i + b_{j_0}}{p_i + q_{j_0}},$$

即元素$t_0$不小于与其同一列的数字（与数字$j_0$）。根据函数 $g$ 的定义可以得出：

$$q_j t_0 - b_j \leq q_{j_0} t_0 - b_{j_0} = a_{i_0} - p_{i_0} t_0,$$

在哪里

$$t_0 \leq \frac{a_{i_0} + b_{j_0}}{p_{i_0} + q_{j_0}},$$

即元素$t_0$不大于与其同一行的数字（与数字$i_0$）。证明是合法的。
