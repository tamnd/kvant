图 2.
其中$r_i$是点$m_i$相对于旋转中心$O$的半径向量。 （物体之间的距离远大于物体的大小，因此物体可以被视为点）。

我们所有进一步的推理都将纯粹是“算术”，乍一看它们似乎与问题无关。但正是它们将引导我们解决问题（或者更确切地说，问题的第一部分）——它们将允许我们确定物体的配置。

让我们逐项添加系统 (1) 中的等式：

$$F_{12} + F_{13} + F_{21} + F_{23} + F_{31} + F_{32} = m_1 a_1 + m_2 a_2 + m_3 a_3 = -\omega^2 (m_1 r_1 + m_2 r_2 + m_3 r_3).$$

这个等式的左边等于零——毕竟，根据牛顿第三定律，封闭系统中所有内力的总和等于零。 （左边可以这样写：

$$\sum_{i,j=1}^{3} F_{ij} + \sum_{i,j=1}^{3} F_{ji} = 0, \text{ так как } F_{ij} = -F_{ji}.$$

所以我们有

$$m_1 r_1 + m_2 r_2 + m_3 r_3 = 0$$

（自 $\omega \neq 0$ 起）。等式（2）本质上指定了旋转中心的位置：它位于这样一个点$O$，使得物体$m_1, m_2, m_3$相对于该点的半径向量必须满足条件（2）。

让我们引入向量$R_2$和$R_3$，如图2所示。然后

$$r_1 = r_2 + R_3,$$

$$r_1 = r_3 + R_2.$$

图 3.
让我们用向量 $R_2$ 和 $R_3$ 来表达向量 $r_1$。为此，请将 (3) 中的第一个等式乘以 $m_2$，将第二个等式乘以 $m_3$，然后将所得等式逐项相加：

$$m_2 r_1 + m_3 r_1 = m_2 r_2 + m_3 r_3 = -m_1 r_1$$

（这是从（2）得出的），我们有：

$$(m_1 + m_2 + m_3) r_1 = m_2 R_3 + m_3 R_2.$$

从这里

$$r_1 = \frac{m_2}{m_1 + m_2 + m_3} R_3 + \frac{m_3}{m_1 + m_2 + m_3} R_2$$

因此，向量 $r_1$ 是与质量三角形的边 $R_2$ 和 $R_3$ 平行的向量 $\rho_2 = \frac{m_3}{m_1 + m_2 + m_3} R_2$ 和 $\rho_3 = \frac{m_2}{m_1 + m_2 + m_3} R_3$ 之和。

现在让我们在质量三角形图上描绘作用在物体$m_1$上的力的矢量（参见图3）。 $F_{12}$是身体$m_2$作用的力，$F_{13}$是身体$m_3$作用的力。这些力沿着质量三角形的边 $R_3$ 和 $R_2$ 方向。它们的结果沿着矢量$r_1$指向点$O$（物体加速度矢量$m_1$指向旋转中心）。但这意味着力的平行四边形和基于向量$\rho_2$和$\rho_3$构建的平行四边形是相似的！然后
