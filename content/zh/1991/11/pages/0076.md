每次移动后，棋盘上都会写下非负整数。如果两个这样的数字的和与差是奇数$d$，那么这些数字本身可以被$d$整除。因此，如果数字$k$能被偶数$d > 1$整除，那么原来写在黑板上的所有数字都可以被$d$整除，这是不可能的，因为其中有1。因此，数字$k$没有奇质因数，即$k = 2^s$。由于每次移动后，棋盘上写的最大数字不会减少，因此$k \geq n$。让我们证明我们可以获得任意的$k = 2^s \geq n$值。一步中，从$(2^a, 2^a)$我们得到对$(0, 2^{a+1})$，从$(0, 2^c)$到$(2^c, 2^c)$，所以如果一组带指数的二的幂写在棋盘上，不超过总和$s_0$，使得该组中包含的数字中有两个相等的数字小于$2^{80}$，那么几步操作就可以得到全部等于$2^{80}$的数字。
通过 $n$，我们将证明从集合 1, 2, ..., $n$ 中，我们总是可以获得指定的 2 的幂集，并且作为 $s_0$，我们可以取任何满足不等式 $2^{80} \geq n$ 的自然数。使用 $n \leq 8$ 可以直接验证该语句。让我们假设它对于所有$n$都成立，满足不等式$8 \leq n \leq l$，并证明它对于$n = l + 1$的有效性。令$l + 1 = 2^m + b$，其中$1 \leq b \leq 2^m$，$m \geq 3$。将条件中指定的变换应用于数字$p = 2^m + u$、$q = 2^m - u$（对于$1 \leq u \leq b$，$1 \leq u \leq b - 1$如果$b = 2^m$）的参数，我们得到由以下三组数字组成的集合：
(1) 1, 2, ..., $2^m - b - 1$（如果$b = 2^m$ 和 $b = 2^m - 1$，则该组不包含任何数字）。
(2) 2, 4, ..., $2^b$（从差$|p - q|$获得）。
(3) $2^m, 2^{m+1}, ..., 2^{m+1}$（由和$p + q$和数$2^m$得出）。
