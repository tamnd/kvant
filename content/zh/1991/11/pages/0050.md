方程的等价性要求它也是第二个方程的根。

对于 $x = \frac{\pi}{3}$ 我们得到
$$-1 + a^2 = \frac{5a}{2} - 2,$$
因此，答案的竞争者是$a = 2$和$a = 1/2$。

在$a = 2$，第一个方程的形式为
$$\sin 2x + 2 = \sin x + 4 \cos x,$$
第二个 -
$$\cos 2x - 5 \cos x + 3 = 0.$$

读者自己很容易看出，最后两个方程都等价于方程$\cos x = 1/2$。

在 $a = 1/2$ 处，第一个方程变为：
$$\sin 2x + 1/2 = \sin x + \cos x,$$
第二个是这样的：
$$2 \cos 2x + \frac{1}{4} = \frac{5}{2} \cos x - 2.$$

显然，第一个$x = -\frac{\pi}{3}$的根不是第二个的根。

答案：$a = 2$。
