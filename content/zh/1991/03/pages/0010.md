$$\lambda = \frac{2\pi \hbar}{mv},$$
其中$m$是粒子的质量，$v$是粒子的速度。电子能量的离散值是根据整数个波必须适合电子移动轨道的长度的条件获得的。如果轨道半径为$r$，则电子的$n$态对应于条件$2\pi r = \lambda n$（$n=1, 2, \ldots$）或$mv_n = \hbar n/r$。从这里不难求出$n$态的动能：

$$W_n = m v_n^2 / 2 = \hbar^2 n^2 / 2 m r^2.$$

电子的总能量是动能和核场势能之和，为负值，等于$U = -Ze^2 / r$。氢原子中电子的总能量为

$$E_n(r) = \hbar^2 n^2 / 2 m r^2 - e^2 / r.$$

在我们的推导中，我们假设轨道半径 $r$ 具有固定值。根据量子力学，轨道半径“分散”在经典轨道源附近。作为半径的估计，我们可以取值 $r$，它对应于最小能量 $E(r)$。

为了找到最小值 $E(r)$，我们进行如下操作。让我们将 $E(r)$ 的表达式重写如下：

$$E = A x^2 - B x.$$

我们使用以下名称：$x = 1 / r$、$A = h^2 n^2 / 2 m$、$B = e^2$。可以看出，对于$x_1 = 0$和$x_2 = B / A$，$E$的值为零。积分里面$|x_1, x_2| E$是负数。该积分内部的某个位置存在最小值 $E$。为了便于估计，我们假设$E_{\min}$对应于积分中间的值$x$，即$x = B / 2 A$。匹配，$r = 1 / x = 2 A / B$，即

$$r_n = \frac{\hbar^2 n^2}{me^2}.$$

（请注意，对于 $n = 1$，此表达式给出了最佳状态下原子半径的正确估计。）将 $r_n$ 的该值代入 $E_n(r)$ 的表达式中，得出

$$E_n = - \frac{me^4}{\hbar^2} \frac{1}{2 n^2},$$

即，匹配 (**)! 的表达式！

实际上，电子可以以不同的概率位于距原子核的任意距离处。我们的简化在于假设该距离已定义，等于$r$，并且是从最小能量条件找到的。当然，我们是作为一个团体来行动的。因此，您不能相信此公式的前向数字因子，即使它恰好是正确的。但其他一切都可以相信！还有集合$me^4 / \hbar^2$，最重要的是，对“量子数”$n$的依赖。

精确的解决方案需要量子力学基本方程（薛定谔方程）的值和非常复杂的（根据学校概念）数学。当结果精确到未知的数值因子时，我们得到的是定性解决方案，但准确地传达了对问题参数的依赖性的本质。定性解决方案使得获得准确的解决方案变得非常容易，因为该现象的主要特征已被阐明。此外，如果有一个高质量的解决方案，但无法通过分析获得精确的解决方案，那么使用计算机就可以在不损失理解问题的情况下完成该解决方案。
