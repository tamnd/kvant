在体积$V$中，氧气的摩尔数为$v_{\kappa} = p_{\kappa}V/(RT)$，氦气的摩尔数为$v_{\mathrm{r}} = p_{\mathrm{r}}V/(RT)$，混合物的总质量为$m = m_{\kappa} + m_{\mathrm{r}} = M_{\kappa}v_{\kappa} + M_{\mathrm{r}}v_{\mathrm{r}}$。那么混合物的摩尔质量
$$M = (p_{\kappa}M_{\kappa} + p_{\mathrm{r}}M_{\mathrm{r}})/(p_{\kappa} + p_{\mathrm{r}}) = 9,6 \text{ г/моль}.$$
因此，音调的音高将增加 $\sqrt{29/9,6} = 1,74$ 倍（您得到“Buratino 的声音”），并且音调的频率变为等于 3480 Hz。

在第一种情况下，链可以重新绘制为图2所示，其中$\rho$是图3所示的半无限链的阻力。从对应关系
$$r + \frac{R\rho}{R + \rho} = \rho$$
容易得到
$$\rho = r(1 + \sqrt{1 + 4R/r})/2.$$
那么两个相邻节点$A$和$B$之间的电阻变化将等于
$$R_1 = R_{AB} = \frac{2R\rho r}{2R\rho + rR + r\rho} = \frac{2Rr}{\rho + 2R}.$$
如果节点 $A$ 和 $B$ 彼此相距很远，则可以如图 4 和 5 所示更换电路。因此
$$R_{\infty} = R_{AB} = \frac{2\rho R}{2R + \rho}.$$
