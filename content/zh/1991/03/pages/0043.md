由此以及 Bezout 定理可知，$n$ 次方程恰好有 $n$ 个根（它们的平均值可以是多个）。
早在 16 世纪，法国数学家 F. Viète（1540-1603）就发现了多项式 $x^n + a_1x^{n-1} + \dots + a_{n-1}x + a_n = 0$ 的根与其系数之间的对应关系：
$$x_1 + x_2 + \dots + x_n = -a_1,$$
$$x_1x_2 + x_2x_3 + \dots +$$
$$\dots + x_{n-1}x_n = a_2,$$
$$x_1x_2 \dots x_n = (-1)^n a.$$

容易看出该多项式的次数为$n$。

如果某些（或全部）根是复数，则所谓的维埃塔公式也成立。您知道 Vieta 的二次三项式 $x^2 + px + q$ 公式：
$$x_1 + x_2 = -p,$$
$$x_1x_2 = q.$$

多项式是数学中最简单、研究最多的函数。

保证相应的多项式总是可以写出。它曾由 I. Newoton (1643-1727) 提出，被称为“牛顿积分多项式”。在给定点 $x_0, x_1, \dots, x_n$ 该多项式采用给定值 ​​$y_0, y_1, \dots, y_n$。

这个多项式
$$\frac{(x-x_1)(x-x_2) \dots (x-x_n)}{(x_0-x_1)(x_0-x_2) \dots (x_0-x_n)} +$$
$$\frac{(x-x_0)(x-x_2) \dots (x-x_n)}{(x_1-x_0)(x_1-x_2) \dots (x_1-x_n)} +$$
$$\frac{(x-x_0)(x-x_1) \dots (x-x_{n-1})}{(x_n-x_0)(x_n-x_1) \dots (x_n-x_{n-1})}.$$

如果我们想在点 $x_0$ 的邻域中使用某个函数 $f(x)$，那么用多项式进行近似非常有用
$$f(x_0) + \frac{f'(x_0)}{1!} (x-x_0) +$$
$$+ \frac{f''(x_0)}{2!} (x-x_0)^2 + \dots$$
$$+ \frac{f^{(n)}(x_0)}{n!} (x-x_0)^n,$$
由英国数学家W.泰勒（1685-1731）提出。

杰出的数学家，特别是 K. Weierstrass (1815-1897) 和 P. L. Chebyshev (1821-1894)，处理了使用多项式逼近线段上给定函数的问题，其中多项式在每个点的值的函数值不超过给定数字，例如 0.001。 “切比雪夫多项式”是众所周知的。
这些是 $x^n + a_1x^{n-1} + \dots + a_{n-1}x + a_n$ 形式的多项式，其值与零的偏差最小（请注意，$x^n$ 的系数为 1）。切比雪夫证明了这样的多项式是多项式$T_n(x) = \frac{1}{2} \cos(n \arccos x)$。

在数学中，也考虑多个变量的多项式

尼赫。因此，两个变量的一次多项式由表达式 $ax + by + c$ 描述，两个变量的第二次多项式由表达式 $ax^2 + bxy + cy^2 + dx + ey + f$ 描述。如果我们将该表达式等于零，我们就得到了二阶曲线方程。这些包括圆、椭圆、双曲线和抛物线。
