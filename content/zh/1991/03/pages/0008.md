中间有波腹的浴（基音）、有一个波节、两个波节等（泛音）。因此，弦是一组不同频率的振荡器。类似的例子是风琴管中的空气柱。当空气在某些点不移动时（类似于琴弦振动中的节点），它可以以较低的频率（基音）或较高的频率振动。

所有振荡器的一般性质如下：无论系统的振荡系统（即围绕平衡位置振荡）的具体装置如何，系统在任何时刻的能量都可以写成以下形式

$$E = \gamma q^2 / 2 + \beta q'^2 / 2,$$

(*) 其中$q$是表征偏离平衡位置的量，$q'$是值$q$随时间的变化率（即$q' = \Delta q / \Delta t$，其中$\Delta t$是一小段时间）。

$\Pi = \gamma q^2 / 2$项是振荡器的势能；系数$\gamma$称为振荡器的刚度。项$K = \beta q'^2 / 2$是振荡器的动能；系数$\beta$称为振子质量。 （记住最简单的振荡器的能量如何书写 - 外部重量 - 你就会明白为什么 $\gamma$ 被称为刚度，而 $\beta$ 被称为振荡器的质量。）

无论振荡器的结构如何具体，其振荡的角度部分$\omega = 2\pi / T$通过刚度$\gamma$和质量$\beta$表示如下：

$$\omega = \sqrt{\gamma / \beta}.$$

引入“广义”振子，其坐标不一定是距平衡位置的距离，但可以具有任何意义，只要能量具有与表达式（*）中$E$相同的结构，就可以让我们得出关于振荡系统增加的结论，而无需考虑其中过程的物理性质和起源。

为了清楚起见，我们举另一个振荡器的例子，它与上面给出的所有例子都不相似。假设有一个电感器 $L$ 由良好的导电线制成，其末端连接到电容器 $C$，有收费 $Q_0$。电路中会发生电磁振荡。如果线圈由超导体制成（这需要低温），则振荡实际上将是无阻尼的。

这种系统的能量由两项组成：线圈中磁场的能量和电容器中电场的能量。电容器电场的能量与当前位于电容器极板上的电荷$Q$的平方成正比：$\Pi = \frac{1}{C} Q^2 / 2$。线圈磁场的能量与当前流过线圈的电流$I$的平方成正比：$K = LI^2 / 2$。但电流强度等于电容器电荷随时间的变化率：$I = Q'$。因此，线圈的磁场能量为$K = LQ'^2 / 2$。

因此，系统任意时刻的能量等于

$$E = \frac{1}{C} Q^2 / 2 + LQ'^2 / 2.$$
