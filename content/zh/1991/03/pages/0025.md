向右水平移动。很明显，当路径的延续经过支撑点（图 3 上的点$D$）时，该速度将达到最大。随着进一步的移动，力矩$T$将变得冻结，一段时间后线圈将停止并回滚。

为了计算线圈的最大速度，我们使用能量守恒定律——线圈的动能等于外力的力。这里唯一的能量来源是实验者，他用$F$的力拉动线的末端。该力所做的功等于

$$A = F \Delta l,$$

其中$\Delta l$是当线圈从初始位置移动到我们感兴趣的位置时穿过孔拉伸的螺纹长度。让我们通过比较初始位置和最终位置中螺纹的“自由”长度来找到$\Delta l$（参见图3）。

设点$O$为初始时刻线的末端，点$G$为最终时刻线与卷轴的接触点。为了在初始时刻找到这一点的延续，我们在心里将线圈卷回。在这种情况下，线将部分缠绕在线圈上，点$G$将移动到点$G_1$（中间点$G_2$是通过将线圈从最终位置平行转移到初始位置而从$G$获得的）。因此，所考虑的螺纹部分在最终位置的长度为$BO + OG$，在初始位置为$OC + CG_1$。将这两个表达式等价，我们发现

$$\Delta l = BO = OC + CG_1 - OG.$$

让我们计算一下这里包含的所有数量。直接从 图 3 我们得到

$$OC = h - R, OG = OD - DG = h / \cos \alpha - R \cos \alpha.$$

剩下的就是计算卷绕在卷轴上的线的长度。我们把这个长度分成两部分：

$$\cup CG_1 = \cup CG_2 + \cup G_1 G_2.$$

当卷材从最终位置滚动到初始位置时，其旋转角度等于

$$\beta = \angle G_1 E_1 G_2 = \frac{EE_1}{R} = \frac{AD - r}{R} = \frac{h tg \alpha - r}{R}.$$

对于姿势，从 $G_1$ 到 $G_2$ 区域内的线长度为

$$\cup G_1 G_2 = r \beta = r \frac{h tg \alpha - r}{R}.$$

同时

$$\angle CE_1 G_2 = \angle EDG = \alpha,$$

可摆姿势的

$$\cup CG_2 = r \alpha.$$

最后我们得到

$$\Delta l = h - R + \frac{r}{R} (h tg \alpha - r) + r \alpha - \frac{h}{\cos \alpha} + R \cos \alpha,$$
