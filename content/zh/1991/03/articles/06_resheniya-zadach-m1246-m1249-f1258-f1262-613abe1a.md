M1248。一个段包含几个完全覆盖它的较小段。
a) 证明这些线段的任何位置，丢弃任何位置——右或左——那么剩余的位置将至少覆盖原始线段长度的三倍。

首先让我们注意，可以排除完全包含在其他段中的段。接下来，以任意顺序对段进行编号后，我们将依次对每个段执行以下操作：将其替换为中间相同的最小段，以便这些段仍然覆盖原始段。 （在这种情况下，所选择的项会减少，它们的并集只会变得更小。）重复这些操作，我们得到一个系统，其中每个线段可以有公共内部点（沿线段相交），而其他点不超过一个。这样，整个原始段就被分成了几块，每块都被其中包含的一个或两个段覆盖。因此，仅针对两个段的情况证明该命题就足够了。这两种情况都不难。

F1259。哨子发出频率$f_0 = 2000 \Gamma$的声音。如果气温从 20 摄氏度上升到 40 摄氏度，声音的频率会如何变化？在水下工作时，在 1.5 个大气压下供应绿色和氧气的呼吸混合物时，气钟会发出什么声音？假设氧气分压为 0.3 atm。在这钟声中，一个人说话的语气会发生怎样的变化？是否有必要重新安排作品，使钟内的声音与外面的声音相同？

哨声的频率由哨声的大小（依赖性 - 逆）和声速（依赖性 - 正）决定。如果前老古人在从20摄氏度加热到40摄氏度时改变了哨子的大小，那么一切都是由声速（与绝对温度的平方根成正比）增加313/293 = 1.033倍决定的。这意味着频率将变为2066 Hz。当然，差异不是很大，但对于乐器来说是完全不可接受的——尤其是在管弦乐队中。在构造两台仪器时，会采取特殊措施，以便当温度在指定范围内变化时，设置实际上不会改变。自己思考一下如何才能实现这一目标。

第二个问题稍微复杂一些。让我们记住，我们通常呼吸的是氧气（摩尔质量为 32 g/mol）和氮气（28 g/mol）的混合物。氮气较多，所得气体混合物的平均摩尔质量为 29 g/mol。氦气和氧气的混合物的摩尔质量明显较低，因此混合物中的声速会更大，人类讲话的音调会更高（毕竟发声器官的“尺寸”保持不变）。仍然需要找到氧气和氦气混合物的摩尔质量。可以这样做。

F1262。异步运动的电风扇连接到 220 V 网络，转速为 1800 rpm。为了使其嗡嗡声不那么大，它通过自耦变压器连接到 127 V 电压。它会以什么速度旋转？考虑风扇叶片上的负载是由“鼠轮”电流的过流效应决定的。

在单相电机中，磁场的旋转是由于流经两个相互垂直的定子绕组的等幅正弦交流电的 90° 相移而实现的。

在这种情况下，磁场的 x 分量等于 $B_x = B_0 \cos \omega t$，y 分量等于 $B_y = B_0 \sin \omega t$，产生的磁场 $\bar{B}_0$ 在 XY 平面中逆时针旋转，频率为 $\omega$ 电源电流 (图 1)。

让我们考虑作用在转子上的力，为简单起见，将其视为从侧面 $a$ 和 $b$ 的矩形金属框架。首先，我们讨论以旋转轴 OZ 为轴的框架在 YZ 平面内闭合不动，并且位于 XY 平面内的磁场感应矢量 $\bar{B}_0$ 以频率 $\omega_0$ 逆时针（图 2）绕框架轴旋转的情况。垂直于框架平面的场分量等于

$$B_\perp = B_0 \cos \omega_0 t,$$

平行线 -

$$B_\parallel = B_0 \sin \omega_0 t.$$

磁通量，任意框架，等于

$$\Phi = B_\perp S = B_0 S \cos \omega_0 t,$$

其中$S = ab$是框架的面积。框架中产生的感应电动势为

$$\delta_i = -\Phi'(t) = B_0 S \omega_0 \sin \omega_0 t,$$

帧中的电流为

$$I = \delta_i / R = B_0 S \omega_0 / R \sin \omega_0 t,$$

其中$R$是全能阻力。相对于框架轴线的扭矩仅由垂直于 YZ 平面的安培力的分量产生，作用于平行于轴线的侧面 -

$$F_{1\perp} = F_{2\perp} = F = B_\parallel Ib = B_0^2 b S \omega_0 / R \sin^2 \omega_0 t.$$

这些力的总力矩

$$M = 2 F a / 2 = B_0^2 S^2 \omega_0 / R \sin^2 \omega_0 t.$$

$T = 2 \pi / \omega_0$ 期间的平均值为

$$\bar{M} = B_0^2 S^2 \omega_0 / (2 R).$$

由于上述物理过程仅由场和框架旋转的相互方向和相对角速度决定，因此，在场后面框架以框架频率$\omega$旋转的情况下，通过简单地替换$\omega_0 \rightarrow \omega_0 - \omega$即可获得框架退绕力矩的表达式：

$$\bar{M}_p = B_0^2 S^2 (\omega_0 - \omega) / (2R).$$

在$\omega = 0$处，当框架静止时，感应电流和安培力的幅值最大。在$\omega = \omega_0$，当框架与磁场同步旋转时，感应电动势、电流和扭矩为零，只有在电机轴上没有负载的情况下才会发生这种情况。

由于该装置，特别是在我们的风扇中，转子可以表示为多个框架的组合，然而，在这种情况下，力的旋转力矩将与定子内部磁场感应幅度的平方以及磁场和转子的旋转频率的差值成正比。磁场感应强度$B_0$的最大值与流过定子绕组的交流电流的幅值$I$成正比，并且根据条件，该值与网络中的方向$U$成正比。波兹尼

$$\bar{M}_p \sim B_0^2 (\omega_0 - \omega) \sim I_0^2 (\omega_0 - \omega) \sim U^2 (\omega_0 - \omega).$$

从圆频率过渡到普通频率，我们得到以下形式的表达式

$$\bar{M}_p = \alpha U^2 (v_0 - v),$$

其中$\alpha$是常数比例系数。

现在让我们考虑导致制动减速的力的作用，在我们的例子中，这是由影响力驱动的流动引起的。让风扇产生面积为 $S$、以速度 $v$ 移动的空气射流。然后，在短时间内$\Delta t$，大量空气$\Delta m = \rho Sv \Delta t$流入气流中，其中$\rho$是空气密度。该空气的机械能变化为

$$\Delta E_k = \Delta m v^2 / 2 = \rho Sv^3 \Delta t / 2,$$

风扇产生的机械功率等于

$$N = \Delta E_k / \Delta t = \rho Sv^3 / 2.$$

由于（根据运动学信息）射流的速度与叶片的旋转频率成正比，并且功率与力矩通过对应关系 $N = M\omega$ 相关，对于作用在风扇叶片上的力的制动力矩，我们得到

$$M_T \sim \omega^2,$$ 或 $M_T = \beta v^2,$
