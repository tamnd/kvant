新西伯利亚国立大学以该大学的名字命名。列宁共青团

数学
笔试
选项1
（力学、数学和经济学院）
1. 求解方程组
$$\begin{cases} 2x \cdot 7^y = 112, \\ 2x - 7y = 1. \end{cases}$$
2. 找到方程的最小正根
$$6 \sin^2 x = 5 - 13 \cos x + 3 \cos 2x$$
3. 在边长为 $AB=14$、$AC=15$、$BC=13$ 的三角形 $ABC$ 中，通过高度 $CH$ 的底边，绘制与线 $AC$ 和 $BC$ 平行的线，这些线与三角形的边 $BC$ 和 $AC$ 相交于点 $M$ 和$N$。线 $MN$ 与边 $AB$ 的延长线相交于点 $D$。求线段$BD$的长度。
4. 解决不等式
$$\frac{x - 1}{(x + 1) \log_3 (x^2 + x + 1/2)} \geq 0.$$
5. 立方体$ABCDA'B'C'D'$的边等于$2a$。线段 $PQ$ 的端点位于线 $AB'$ 和 $BC'$ 上，与线 $CD'$ 相交于点 $O$ 并被该点一分为二。求线段$PQ$的长度。

选项2
（物理学院）
1. 解方程
$$1 - 8 \cos^2 x = 9 \sin 2x + 3 \cos 2x$$
2. 解决不等式
$$|x^2 + 2x - 24| > 6x + 8$$
3. 围绕等边三角形 $ABC$ ($AB=BC$)，角 $B$ 等于 $30^\circ$，外接圆 $S$，半径为 $R$，$AD$ 是从点 $A$ 引出的直径。求与给定三角形的边 $AC$ 相切的圆的半径、直径 $AD$ 和圆 $S$。
4. 在坐标平面上，给出一条抛物线$y = x^2/2 + x + 13/2$和一条与该抛物线平行的线$y = 6x$的切线。

求一个三角形的面积，其顶点为：切点、切线与x轴的交点以及给定抛物线的顶点。
5. 在正四边形直线$SABCD$中，通过顶点$A$和边$SC$的中间，在与底$ABCD$的对角线$BD$平行的平面上画出截面。已知截面积为9，截平面与底面成$60^\circ$角。求这条直线的体积。

选项3
（自然科学和地质地球物理学院）
1. 解方程
$$\log_2 x + \log_2 x = \log_8 x + 16$$
2. 找到方程的最小正根
$$2 \cos^2 x = 1 - 7 \sin x - 2 \cos 2x$$
3. 直线$l_1$在外部与圆$O_1$和$O_2$相切（即圆位于直线$l_1$的同一侧），切点之间的距离为24。直线$l_2$是内公切线（即圆位于直线$l_2$的相对两侧），距离在这种情况下，切点之间的距离等于 7。圆 $O_1$ 和 $O_2$ 之间的最小距离是 1。找到半径圆。
4. 解决不等式
$$\frac{\sqrt{3x + 22}}{x + 4} < 1$$
5. 在三角形直线$ABC'A'B'C'$的底边有一个边为$\sqrt{3}$的正三角形$ABC$，边长为4。令$K$为对角线$BC'$与$B'C$侧面$BB'C'C$的交点。一个球体，其中心属于与面 $ABC$、$AA'B'B$、$AA'C'C$ 和线 $A'K$ 相切的线。求球体的半径。

第四个任务是评估任务。为了解决这个问题，您需要了解所考虑的物理现象，形成该现象的简单（因为只需要估计）物理模型，选择物理量的维度数值，最后获得或多或少符合现实的数值结果。在问题的正文中，我假设申请人可以自己选择解决问题所需的数量及其数值。

第五个任务是演示任务，您需要解释课堂上演示的物理现象。这里重要的是要了解本质现象并突出各种因素中的主要因素。

从演示完成开始，给了五个小时的时间来解决问题。

每个问题的文本后面的括号中标明了解决该问题的人的平均百分比。

选项1
1. 首先放置两个相同的均匀充电的薄烧瓶，使其在点 $O$ (图 1) 处成直角。然后将烧瓶合并。 $O$ 点（通常位于距环中心一定半径的距离）处，电场方向会改变多少次？ (68%)
2. 飞机沿着响应墙移动。与飞机运动方向成什么角度，飞行员会捕捉到从这面墙反射的回声？声速为$v$，飞机的速度为$u$。 （78%）。
3. 弹簧枪的枪管与光滑地板成 $45^\circ$ 角。弹丸的质量等于枪的质量。确定从未连接的大炮和固定的大炮发射时弹丸上升高度之间的比率。 (32%)
4. 估计当在近地圆形轨道上移动的 Kkaley 飞船上称重 1 公斤的物体时，弹簧秤所指示的最大重量是多少。 (13%)
5. 激光束瞄准 Ortec 玻璃块的末端，而在块后面的屏幕上可以观察到一个亮点 (图 2)。用湿布触摸块的某个地方后，屏幕上的光点消失。用干布涂抹则没有此效果。解释一下这个现象。 (64%)

2. 将中间弯曲的导电板 (图 3) 插入扁平电容器中，板之间的距离为 $d_0$。从该板块到附近板块的距离$d_1$。电容器的电容量变化了多少次？ (44%)
3. 如果一个球从 $h$ 的高度落到硬地板上，那么它会弹到 $h/3$ 的高度。两个这样的球并排悬挂在长度为 $l$ 的螺纹上。带有一个球的螺纹与垂直方向偏转$90^\circ$角度，然后球被释放。球碰撞后，螺纹会偏转什么角度？ (28%)
