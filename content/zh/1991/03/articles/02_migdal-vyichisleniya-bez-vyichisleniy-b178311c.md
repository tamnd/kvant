如果说数学是避免计算的艺术，那么理论物理就是没有数学的计算的艺术。

作为题词给出的声明是物理学家和数学家之间争论的结果，需要澄清。此外，没有数学就无法完成物理学中最简单的计算。然而，在理论物理学家工作的第一个也是最重要的阶段，当现象的物理图景建立起来时，数学就退居幕后，只扮演辅助角色。但在谈论物理和数学之间的联系之前，你应该知道什么是理论物理。

一、物理学家如何工作？

实验家和理论家

物理学家有两种类型——实验家和理论家，而这两种职业几乎从未结合在一个人身上。实验物理学家研究物理量之间的对应关系，或者更严肃地说，发现自然规律，使用实验装置，即使用设备产生物理量的变化。为此，您需要深入了解正在研究的现象（以便知道改变什么以及如何改变）。理论物理学家仅使用纸和笔来研究自然，即可观察量之间的推理对应关系，依赖于先前发现的实验和理论自然定律。这两个职业分开的原因不仅在于它们每个人都需要自己的特殊知识：一种情况是测量方法的知识，另一种情况是掌握数学仪器。主要原因是这些职业对应着不同的思维特征和不同的直觉形式。直觉，即潜意识中找到正确路径的能力，起着至关重要的作用，尤其是在工作的第一阶段。不幸的是，直觉的天赋并不是立即产生的，而是作为努力工作的结果，作为解决许多科学问题的奖励。

由于理论物理学比实验物理学处理更抽象的概念，因此理论物理学需要更抽象形式的直觉，有时接近数学的直觉。在上个世纪，当物理学还没有如此专业化时，许多物理学家将这两个职业结合起来。于是，从理论上获得了描述所有电磁现象的方程的麦克斯韦也参与到了实验中。发现实验电磁波的赫兹也是一位优秀的理论家。然而，每个专业都有力地表明了哪个专业是主要专业：对麦克斯韦来说是理论物理学，对赫兹来说是实验物理学。

要使用毕达哥拉斯定理的证明，请使用维度消息。从维度可以看出，直角三角形的面积 $S$ 可以写成斜边的平方与锐角之一的新函数：$S = c^2 f(\alpha)$ 的乘积。以类似的方式，您可以想象如果省略直角的高度，将获得两个相似的直角三角形的面积。对于这些三角形，斜边的作用由原始三角形的类别扮演。这就是为什么

$$T = C \sqrt{m/k}.$$

这种系统的能量由两项组成：线圈中磁场的能量和电容器中电场的能量。电容器电场的能量与当前位于电容器极板上的电荷$Q$的平方成正比：$\Pi = \frac{1}{C} Q^2 / 2$。线圈磁场的能量与当前流过线圈的电流$I$的平方成正比：$K = LI^2 / 2$。但电流强度等于电容器电荷随时间的变化率：$I = Q'$。因此，线圈的磁场能量为$K = LQ'^2 / 2$。

因此，系统任意时刻的能量等于

$$E = \frac{1}{C} Q^2 / 2 + LQ'^2 / 2.$$

振荡器 - 无论它代表向外振荡的负载，还是电子振荡电路。
让我们用 $q$ 表示振荡器的广义坐标。让我们写下振荡器的能量：

$$E = \gamma q^2 / 2 + \beta q'^2 / 2.$$

可以想象，振荡器是一种质量$\beta$的某种“粒子”，以刚度$\gamma$向外振动。为了形成该物体的量子力学基本思想，我们引入与“粒子”相关的波过程的波长$\lambda$：

$$\lambda = 2\pi \hbar / \beta q'.$$

分母是“质量”与其速度的乘积。由于速度随着粒子的移动而变化，因此波长也会变化 - 它是平衡位置的最小值，并且在“粒子”速度较低的那些区域中增长。

让“粒子”在$-q_0$到$q_0$的区域内移动。 （强调$2q_0$不是振荡器振荡的范围，而是其坐标“颤抖”的区域。）为了形成驻波，“长度”$2q_0$必须包含整数半波：$2q_0 = (n+1)\lambda / 2$（$n=0, 1, 2, \dots$）。作为速度的估计，我们取$q = q_0$处的速度值，即$(q'_0 = 2\pi \hbar / \beta \lambda = \pi \hbar (n+1) / 2\beta q_0)$。将这个值代入动能表达式，我们发现

$$W_n = \frac{\pi^2 \hbar^2}{8\beta} \frac{(n+1)^2}{q_0^2}.$$

对于我们获得的总能量

$$E_n(q_0) = \frac{(\pi \hbar)^2}{8\beta} \frac{(n+1)^2}{q_0^2} + \frac{\gamma q_0^2}{2}.$$

对于较小的 $q_0$ 值，由于第一项，能量较高；对于较大的 $q_0$ 值，由于第二项，能量较高。如果两项相等，则获得给出最低能量的适用值$q_0$。从这个条件我们发现

$$q_0^2 = \frac{\pi \hbar (n+1)}{2\sqrt{\beta \gamma}}.$$

代入能量表达式，我们得到

$$E_n = \frac{\pi}{2} \hbar \sqrt{\gamma / \beta} (n+1) = \frac{\pi}{2} \hbar \omega (n+1) \quad (n=0, 1, 2, \dots).$$

量$\omega = \sqrt{\gamma / \beta}$代表经典振荡器的振荡频率。

能量的精确计算得出表达式

$$E_n = \hbar \omega (n + \frac{1}{2}).$$

因此，我们在数值因子上犯了错误（$\pi/2$而不是1），以及最低状态下的能量数值，即$n=0$（$\frac{\pi}{2} \hbar \omega$而不是$\frac{1}{2} \hbar \omega$）。但其他一切都很顺利！现在已经获得了结果，我们应该考虑我们用什么来获得它，以及从我们获得的振荡器能量和值 $q_0^2$ 的表达式中得出什么结论。

首先，我们将最初与电子相关的量子力学原理应用于振荡器，但对其结构并不感兴趣。当然，很自然地预期对于质量与电子质量不同的其他粒子来说，一般原理应该是相同的。事实上，这样的概括已经通过实验得到了非常准确的证实。但为什么这些原理可以应用于像振荡电路这样的东西，其中“坐标”的作用是由电容器板上的电荷发挥的呢？这里我们提出一个在 20 世纪理论物理学中广泛使用的重要假设。如果两个系统的能量同样取决于坐标和速度，那么这些系统具有相同的属性，尽管“坐标”和“速度”在这些系统中可能具有完全不同的含义。

现在让我们考虑一下什么会向我们展示对我们有用的结果。它们如何转化为经典力学公式？首先，我们发现能量并不是间歇性变化的，而是以$\hbar \omega$数量级变化。确实，$\hbar$的值非常小，对于一般的宏观光振荡器来说，这种能量的突然变化实际上是观察不到的。然而，在一些特殊的宏观系统中，不连续性起着一定的作用（例如激光）。对于许多类型的振荡器，我们获得的振荡器能量表达式的正确性已经得到了高精度的验证。

量子振荡器还有一个更重要的特性，我们也获得了这一特性。当能量最小时，经典振荡器处于平衡位置；同时，处于最高能量状态的量子振荡器会产生振荡（称为“零振荡”）。这些振荡的动能和势能的量级为$\hbar \omega$。在这种情况下，振荡坐标的平均值为零，并且平方坐标的平均值由上面的$q^2$公式给出。量子振荡器的这一显着特性已经在实验中得到了充分的检验，并在现代物理学中发挥着重要作用。

如果我们将固体中的声音振荡视为一组量子振荡器，那么我们会发现，在绝对零温度下，固体中的原子并不是静止的，而是进行零振荡。而这一事实也被低温光散射实验所证实！如果我们将可以在真空中传播的电磁波视为一组振荡器，那么我们会得出这样的结论：在真空中，即使其中没​​有粒子或量子，也应该找到电磁场的零振荡。而这些振荡也是在测试过程中发现的！但这是一个更复杂的问题，需要详细讨论。

理解是在工作过程中产生的

我们将介绍几个难以理解的词：量子化、与粒子相关的波动过程、量子振荡器等。然后我们开始行动，而不是真正的他们的概念。尽管如此，我们发现氢原子的能量如何取决于量子数$n$；他们了解到量子振荡器在最高能态下振荡，甚至开始将振荡器的量子化结果应用到真空中电磁场的振荡中。这些行动的结果是，至少产生了部分理解。

所以，理解是在工作过程中产生的。毕竟，如果我们在开始计算之前就试图获得完全的理解，那么什么都行不通。理解不是突然产生的，而是随着你工作的进展而产生的。相反，随着理解的加深，工作也会取得进展。

为了获得更深入的理解，你需要自己解决这方面的物理问题。被动学习只能让我们对通过独立工作发现的美丽有一个模糊的概念。
