tereyki $U_0 = 4,5$ 问：较低的安培数表示什么？ $R_x$等于什么？

现在很容易找到流过下安培的电流：

$$I_H r = I_c r + (I_B + I_c) R_x,$$

在哪里

$$I_H = 3 I_B + 4 I_c = 19 \text{ мА.}$$

知道了电池的所有点和电压，就可以确定电阻器的阻值并利用欧姆定律

$$I_H r + (I_H + I_c + I_B) R_x = U_0,$$

在哪里

$$R_x = \frac{U_0}{4/3 I_H + I_c + I_B} = 148,3 \text{ Ом.}$$

A·齐伯曼

F1251。在图1所示的电路中，设置电流后，按键立即从位置1转移到位置2。假设线圈是理想的，确定拐点后电阻$R$上释放的热量。源电动势$E$，内阻$r$。

图 1.

设置电流后，在将钥匙扔过线圈 $L_1$ 和 $L_2$ 之前，电流流动

$$I = \mathcal{E} / r.$$

由于线圈是理想的（其绕组的欧姆电阻为零），因此电阻器$R$两端的电压降以及通过电阻器的电流为零。钥匙从位置 1 瞬时转移到位置 2 意味着在转移过程中线圈中的电流实际上没有时间改变。

传输密钥后，电流电路的形式如图2所示。电流的初始值等于：

$$I_1(0) = I_2(0) = I = \mathcal{E} / r,$$

$$I_3(0) = 0.$$

根据闭环 $abcd$ 的欧姆定律（对于任意时刻 $t$），我们有

$$L_1 \frac{dI_1}{dt} = 0 \Rightarrow I_1 = \text{const.}$$

从 $I_1 = I_2 + I_3$ 开始，我们得到

$$\frac{dI_1}{dt} = \frac{dI_2}{dt} + \frac{dI_3}{dt} = 0.$$

由于电阻$R$的存在，电流$I_2$会减小，即衰减。在这种情况下，电流 $I_2$ 的减少量将在数值上等于电流 $I_3$ 的增加量（自 $dI_2 = -dI_3$ 起）。当电流$I_2$降至零时，电流$I_3$将等于电流$I_2$的初始值（$I_2(0) = \mathcal{E} / r$）。

在新建立的模式下，电流在电路中流动

$$I_1(\infty) = I_3(\infty) = \mathcal{E} / r, I_2(\infty) = 0.$$
