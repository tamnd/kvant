A·托利沃

M1237。令三角形$ABC$内的点$O$使得$\overrightarrow{OK} + \overrightarrow{OM} + \overrightarrow{ON} = \overrightarrow{0}$，其中$K, M, N$是从三角形$O$到边$AB, BC, CA$的重分配基。证明不等式

$$\frac{OK + OM + ON}{AB + BC + CA} \leq \frac{1}{2\sqrt{3}}.$$

由于点$O$的条件，线段$OK, OM, ON$可以平行移动，从而形成三角形（参见图）。旋转$90^\circ$后，该三角形的边将与三角形$ABC$的边平行，因此这些三角形相似。我们用$k$：$k = OK/AB = OM/BC = ON/CA$表示相似系数。则证明不等式左边等于$k$。另一方面，将三角形$ABC$的面积$S$表示为三角形$AOB, BOC$和$COA$的面积之和，我们得到

$$2S = a \cdot OK + b \cdot OM + c \cdot ON = k(a^2 + b^2 + c^2),$$

其中$a, b, c$是边$\triangle ABC$的长度。因此，问题就简化为证明不等式

$$S \leq \frac{a^2 + b^2 + c^2}{4\sqrt{3}}.$$

让我们使用海伦公式以及三个数字的算术平均值和几何平均值之间的不等式（字母 $p$ 作为一般字母表示半周长）来展示这一相当著名的不等式的证明之一：

$$S = \sqrt{p(p - a)(p - b)(p - c)} \leq \leq \sqrt{p((p - a + p - b + p - c)/3)^3} = p^2/3\sqrt{3} \leq \leq (a^2 + b^2 + c^2)/4\sqrt{3}$$
