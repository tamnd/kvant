理想气体的功和能量变化
A·谢罗诺夫

在本文中，我们将重点讨论以理想气体为主要特征的热过程的一些特征。

众所周知，气体可以由于外部热源或其内部能量而做功。但在任何过程中，都满足热力学的基本对应关系——能量守恒定律，或者说热力学第一定律。我们把它写成表格

$$Q = \Delta U + A$$

— 提供给气体的热量$Q$改变其内能$\Delta U$，并且气体抵抗外力做功$A$。

理想气体的内能$U$仅取决于温度$T$，并且是其状态的函数。因此，对于一摩尔单原子气体$U = 3/2RT$，其中$R$是通用气体常数。因此，内能的任何（无限小和有限）变化仅由最终状态和初始状态之间的温差决定：

$$\Delta U = \frac{3}{2} R \Delta T$$

并且不依赖于从一种状态转换到另一种状态的方法。即使气体由于非平衡、难以想象的过程而从初始平衡状态转移到最终平衡状态，这一点仍然成立。

基本功 $\Delta A$，有时也被称为，根据定义等于压力 $p$ 和两个相邻平衡状态下气体体积的微小变化 $\Delta V$ 的乘积：

$$\Delta A = p \Delta V.$$

对于某些逆过程中体积从 $V_1$ 到 $V_2$ 的有限变化，功 $A$ 在数值上等于气体压力与体积曲线 $p = p(V)$ 下的面积，受到等容$V_1$ 和 $V_2$ 的限制。从数学上讲，这个面积等于

$$A = \int_{V_1}^{V_2} p(V) dV.$$

对于闭式循环，气体的功由形成该循环的内部$p(V)$的面积决定。体积变化有限的气体的功，就像封闭循环中气体的功一样，取决于函数 $p(V)$ 的类型。

逆过程中供给气体的热量$Q$可以通过已知的对应关系，通过气体的热容量$C$和微小的温度变化$\Delta T$来表示

$$Q = C \Delta T.$$

问题 1. 求一摩尔理想气体在由压力与体积和等容线 (图 1) 的线性关系的两个部分组成的循环中所做的功。点 2 和 3 位于等温线上，直线 1-3 通过原点。设置温度 $T_1$ 和 $T_2 = T_3$。

等容线 1-2 的工作为零。第2-3部分的工作等于梯形的面积。表示$V_3/V_2 = \beta$并考虑到$p_2V_2 = p_3V_3 = RT_2$，我们有
$$A_{23} = \frac{p_2 + p_3}{2}(V_3 - V_2) = \frac{p_2V_3 - p_3V_2}{2} = RT_2 \frac{\beta^2 - 1}{2\beta}.$$
第3-1段的功也等于梯形的面积。由于线 1-3 通过原点，因此 $p_1/V_1 = p_3/V_3$，我们得到
$$A_{31} = \frac{p_1 + p_3}{2}(V_3 - V_1) = \frac{p_3V_3 - p_1V_1}{2} = \frac{R}{2}(T_2 - T_1).$$
条件$p_1/V_1 = p_3/V_3$意味着$T_1/V_1^2 = T_1/V_2^2 = T_2/V_3^2$。因此，作品$A_{23}$最终可以写成形式
$$A_{23} = RT_2 \frac{T_2/T_1 - 1}{2\sqrt{T_2/T_1}} = \frac{R}{2} \sqrt{\frac{T_2}{T_1}}(T_2 - T_1).$$
循环中所需的功等于
$$A_\pi = A_{23} - A_{31} = \frac{R}{2}(T_2 - T_1)(\sqrt{\frac{T_2}{T_1}} - 1).$$

请注意，对于连接等温线点的直线 2-3 的部分以及等温线本身，气体的功仅由体积比决定。气体沿着穿过图上坐标原点$pV$的任意直线截面的功仅由最终状态和初始状态之间的温差决定。

问题 2. 求压力与体积呈线性关系的过程中气体的摩尔热。

让我们将能量守恒定律写成以下形式
$$C\Delta T = C_V\Delta T + p\Delta V.$$
根据条件$p = \alpha V + \beta$，其中$\alpha$和$\beta$是常数。考虑到气体的状态方程，我们发现
$$RT = \alpha V^2 + \beta V.$$
从这里我们发现温度的微小变化$\Delta T$与基本功$p\Delta V$之间的联系：
$$R\Delta T = (2\alpha V + \beta)\Delta V.$$
最后我们得到所需的热容
$$C = C_V + \frac{p\Delta V}{\Delta T} = C_V + R \frac{\alpha V + \beta}{2\alpha V + \beta}.$$
可以看出，热量是可变的，并且通过直线$\alpha$的负角系数，可以改变其符号。这意味着应该谨慎处理这些领域（例如，在需要提高效率的问题中）。建议读者根据平面$pV$上截面的位置独立监测热容量的变化。我们将限制自己替换为，对于穿过坐标原点（$\beta = 0$）的任意直线，热容是恒定的并且等于$C_V + R/2$。
