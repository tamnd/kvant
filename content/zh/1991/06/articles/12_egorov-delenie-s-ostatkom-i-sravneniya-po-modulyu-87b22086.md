余数除法和模比较

1990 年 9 月 3 日，我需要找出 1991 年 12 月 20 日是星期几。我手头没有日历，所以我必须做一些计算。我知道9月3日是星期一，从1990年9月3日到1991年12月20日

27+31+30+20+365=473天，即67整周再加4天（473=67·7+4）。因此，1991 年 12 月 20 日是星期五。

通过对一个多位数进行平方，学生得到答案 46,991,075。老师一看笔记本，立刻说道：“答案不对！”他是怎么理解这一点的呢？

练习 1. 考虑一个整数的平方是否可以变成数字 75。

稍后我们将看到这个简单问题和许多其他问题的解决方案是基于可除性消息。然而，首先我们需要记住什么是余数除法。

除法有余数

定义。将自然数a除以自然数b并有余数意味着将a写成a=qb+r的形式，其中q和r是非负整数，并且r<b。数字 q 称为商，a r 是 a 除以 b 的余数。

在实践中，余数除法以一般方式进行，即“除以角度”。例如：

$$\frac{179}{14} \frac{14}{12}$$

这里余数是11，商是12：179=12·14+11。

请注意，在这个定义中，我们不要求 a 大于 b。例如，您可以将 5 除以 7：5=0·7+5。一般来说，如果a<b，则a=0·b+a，即在这种情况下q=0，r=a。

扫地。您可以定义任意整数 a 的余数除以任意整数 b≠0，如下所示：将 a 除以 b 余数意味着将 a 表示为 a=qb+r，其中 q 是整数，a 0≤r≤|b|。例如，a=-15，b=7：-15=(-3)·7+6；其中a=-224，b=-9：-224=15·(-9)+1，等等。

如果余数为零，即a=qb，则称a可被b整除。

下面的简单观察非常重要。如果 a 和 b 可被 c 整除，则对于任何整数 k 和 l，数字 ka+lb 可被 c 整除。

模比较
我们立即规定下面要讨论的数字都是整数，这样以后就不再具体说明了。我们再考虑一个问题。

任务2.数字$2^{999}$以什么数字结尾？

解决方案。让我们写下 2 的连续幂：
2, 4, 8, 16, 32, 64,...
很容易看出，这些数字的最后一位数字在 4 之后重复，因此数字 $2^n$ 的最后一位数字仅取决于指数 $n$ 除以 4 时得到的余数。从 $999=996+3=4 \cdot 249+3$ 开始，我们问题的答案是：8。

在这个例子中，整个指数集被分为 4 类，由 $4k, 4k+1, 4k+2, 4k+3$ 形式的数字 $n$ 组成。

此外，对于任何自然数$m$，所有整数（不仅是正整数！）都分为$m$类。每类由除以 $m$ 时得到相同余数的数字组成。

这些是课程：
0) $a=km$ 形式的数字$a$，
1) -a-a=km+1,
$m-1)$ — а — а=km+m-1。

显然，任何数字都属于上述类别之一。在这种情况下，同一类的任意两个数的差可以被$m$整除，但是不同类的两个数的差不能被$m$整除。

定义。如果整数$a$和$b$之差可被自然数$m$整除，则$a$和$b$在模数上具有可比性。

模$m$的数的可比性写成如下：

$a \equiv b(\text{mod } m)$.

当且仅当数字 $a$ 和 $b$ 模 $m$ 具有可比性时，它们属于同一类，也就是说，它们除以 $m$ 时得到相同的余数。换句话说，$a \equiv b(\text{mod } m)$ 表示$a=b+km$，其中$k$ 是整数。例如，$27 \equiv 7(\text{mod } 10)$、$78 \equiv 6(\text{mod } 24)$、$6 \equiv 0(\text{mod } 3)$、$25 \equiv -4(\text{mod } 29)$。

比较特性
比较用它们的属性来填充一般等式：
1) 如果$a \equiv b(\text{mod } m)$和$b \equiv c(\text{mod } m)$，则$a \equiv c(\text{mod } m)$。
2) $a+c \equiv b+d(\text{mod } m)$.
3) $a-c \equiv b-d(\text{mod } m)$.
4) $ac \equiv bd(\text{mod } m)$.
也就是说，比较像一般的等式一样，可以进行加法、减法和变量。

问题 3. 除以 3 个数字求余数
$$N = (1^2 + 1)(2^2 + 1)(3^2 + 1)...(1000^2 + 1).$$

解决方案。从上面的评论可以看出
$$N \equiv (1^2 + 1)^{333} \cdot (2^2 + 1)^{333} \cdot (3^2 + 1)^{333} \equiv 2^{333} \cdot 2^{333} \cdot 1^{333} \equiv 2^{666} \equiv (2^2)^{333} \equiv 1^{333} \equiv 1.$$

问题 4. 对于什么自然数 $n$ 来说，数字 $8n + 3$ 可以被 13 整除（参见问题 1）？

解决方案。让我们利用比较的性质写出以下整数对应关系：
令$8n + 3 \equiv 0(\text{mod } 13)$，则
$$8n \equiv -3(\text{mod } 13),$$
$$8 \times 8n \equiv -24(\text{mod } 13),$$
$$-n \equiv -24 \equiv -11(\text{mod } 13).$$

$n \equiv 11(\text{mod } 13)$来自哪里。

最后，当且仅当 $n = 13k + 11$ 时，$8n + 3$ 才能被 13 整除。
