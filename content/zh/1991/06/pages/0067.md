15（5）。求构成等比级数的四个数之和，其中第三项比第一项大 9，第二项比第四项大 18。
16（3）。求所有能被 4 整除的三位数自然数的和，除以 3 余数为 2。
17（9）。如果三角形的边用构成等比级数的整数表示，则确定三角形的边，并且这些数的乘积为 216。
18（7）。如果 $a_4 + a_8 + a_{11} + a_{13} = 16$，求算术级数 $a_1, a_2, a_3, \dots$ 前十七项的总和。
19（7）。找到所有能被 45 整除的 $74s3t$ 形式的五位数字（s 和 t 是数字）。

20. 计算：
a) (5). $\lg 1000^2 + \lg 0,001^2,8$;
b) (8). $\frac{1}{2} \log_5 3 + \log_5 \sqrt{15} - \frac{1}{3} \log_5 \frac{27}{25}$;
b) (9). $\left( \frac{\lg 125 - 2 \lg 2}{\lg 3^4 + \lg 0,2} \right)^2$;
r) (5). $\sin^2 32^\circ + \cos 32^\circ \sin 58^\circ - 2,5$;
d) (9). $\sqrt{5} \cos (\mathrm{arctg} 0,75)$;
e) (9). $\cos 72^\circ - \sin 54^\circ$.

21. 证明等式：
a) (9). $\sin \frac{3\pi}{10} \sin \frac{\pi}{10} = \frac{1}{4}$;
b) (9). $\tg (\arcsin x) = \frac{x}{\sqrt{1-x^2}}$;
b) (9). $\left( \frac{2}{\sqrt{3} - 1} + \frac{3}{\sqrt{3} - 2} + \frac{15}{3 - \sqrt{3}} \right) \times (\sqrt{3} + 5)^{-1} = \frac{1}{2}$;
r) (9). $\frac{1 - 4 \sin^2 \alpha \cos^2 \alpha}{(\sin \alpha + \cos \alpha)^2} + 2 \sin \alpha \cos \alpha = 1$;
d) (9). $\frac{(\tg \frac{\pi}{4} + \tg \alpha) \sin \left( \frac{\pi}{4} - \alpha \right)}{\tg \frac{\pi}{4} - \tg \alpha} = \sin \left( \frac{\pi}{4} + \alpha \right)$;
e) (9). $\sqrt{\frac{1}{2} + \frac{1}{2} \sqrt{\frac{1}{2} + \frac{1}{2}} \cos \alpha} = \sin \frac{\alpha}{4}$
在$\pi < \alpha < 2\pi$。

22. 简化表达式：
a) (5). $\frac{x^2 - \sqrt{x}}{(x \sqrt{x} + x + \sqrt{x})(\sqrt{x} - 1)} + 2$;
b) (11). $\frac{1 - x^2}{2((1 - \sqrt{x})^2 + 2 \sqrt{x})(1 - x)}$;
b) (11). $\left( \frac{1}{(a^0,5 + b^0,5)^{-2}} - \left( \frac{a^0,5 - b^0,5}{a^{1,5} - b^{1,5}} \right)^{-1} \right)^2 (ab)^{-0,5}$;
r) (8). $\frac{a \sqrt{a} + b \sqrt{b}}{\sqrt{a} + \sqrt{b}}: \sqrt{(a + b)^2 - 4ab} - \left( 1 + \sqrt{\frac{a}{b}} \right)^{-1}$
在$b > a > 0$；
d) (9). $\left( \frac{3 - x}{\sqrt{3} - \sqrt{x}} - \frac{3^{3/2} - x^{3/2}}{3 - x} \right)^2 \times 10^{-\log_0,1(3 + 2 \sqrt{3x} + x)}$;
e) (9). $\left( \frac{\sqrt{4} a^{-3} - 1}{4 a^{-1} - 1} + \sqrt{4} a^{-1} \right)^{1/2} \times \left( a^{-1/2} - \frac{\sqrt{4} a^{-3} + 1}{4 a^{-1} - 1} \right) (a^{-0,5} - a)^{-1}$;
g）（9）。 $\frac{\sqrt{2} (x - a)}{2x - a} - \left( \left( \frac{\sqrt{x}}{\sqrt{2x} + \sqrt{a}} \right)^2 + \left( \frac{\sqrt{2x} + \sqrt{a}}{2 \sqrt{a}} \right)^{-1} \right)^{1/2}$
并计算其在$a = 0,32, x = 0,08$处的值；
h）（11）。 $\left( \frac{\sqrt{a} + \sqrt{a} - b}{\sqrt{a} - \sqrt{a} - b} - \frac{\sqrt{a} - \sqrt{a} - b}{\sqrt{a} + \sqrt{a} - b} \right): \sqrt{\frac{a - b}{a}}$,
计算其在$a = 8, b = 1$处的值；
一）（9）。 $\frac{4 a^{0,25} + b c^{1,5}}{(4 + c^{1,5}) (a^{0,25} - b)} + \frac{a^{1/4} c^{3/2} - 4b}{(4 - c^{1,5}) (a^{3/2} - b)}$；
j）（9）。 $\left( \frac{a}{\sqrt{a} + \sqrt{2}} - 2 (\sqrt{a} + \sqrt{2})^{-1} \right) \times \left( \frac{a \sqrt{a} - 2 \sqrt{2}}{\sqrt{a} + \sqrt{2} + \frac{2}{\sqrt{a}}} \right)^{-1} \cdot 7 \log_{49} a$；
