答案：6) 9. 图 2 中给出了一个例子。

让我们证明陈述a)。让平面上点$A_1, A_2, \dots, A_7$的分布$a$最多重复$k$次。让我们用$n_i$表示从点$A_i$出现的长度$a$的数量。不失一般性，可以假设$n_1 \geq n_2 \geq \dots \geq n_7$。

注意$n_1 + n_2 \leq 9$。确实，否则，在一个以$A_1$和$A_2$为圆心，半径为$a$为7个点的圆上，至少会找到$n_1 + (n_2 - 2) \geq 8$个点，这是不可能的。

显然，从点$A_1, A_2, A_3, A_4$开始，任意两点之间的距离不等于$a$。令 $A_i A_j \neq a$ ($i \neq j$)。在这种情况下，在以 $A_i, A_j$ 为圆心、半径为 $a$ 的圆上，最多会找到 $n_i + n_j - 2$ 个点，因为点 $A_i$ 和 $A_j$ 不在指示的圆上，这意味着 $n_i + n_j - 2 + 2 \leq 7$。因此$n_3 + n_4 \leq n_i + n_j \leq 7$，因此我们有$n_4 \leq 3$，从而$n_7 \leq n_6 \leq n_5 \leq 3$。

因为
$$k = \frac{1}{2} \left( (n_1 + n_2) + (n_3 + n_4) + n_5 + n_6 + n_7 \right) \leq \frac{1}{2} (9 + 7 + 3 + 3 + 3),$$

从哪里$k \leq 12$。

该示例非常相似（图 1），在正六边形中，从边$a$开始，顶点为$a$，中心重复 12 次。所以，$k = 12$。

对于问题 6) 类似的推理给出了估计
$$k \leq \frac{1}{2} (8 + 6 + 3 + 3) \leq 10.$$

然而，很容易验证集合$n_1 = 5, n_2 = \dots = n_6 = 3$和$n_1 = n_2 = 4, n_3 = \dots = n_6 = 3$是不可能的（在后一种情况下，因为点$A_i$是唯一不位于以$A_1 - n_i \leq 2$为中心、半径为$a$的圆上的点）。
