在此期间。因此，列出了 $I$ 中的空数，即
$I = \{x_1, x_2, \ldots\}$，其中
$$x_1 = 0, x_{11}x_{12} \ldots x_1 n \ldots,$$
$$x_2 = 0, x_{21}x_{22} \ldots x_2 n \ldots,$$
......

和 $x_{ij}$ 取从零到九的值，并且不存在从某个点开始有一个零的数字。

考虑小数$\alpha = 0, y_1y_2 \ldots$，其中如果$x_{ii} \neq 1$则为$y_i = 1$，如果$x_{ii} = 1$则为$y_i = 2$（此过程称为对角线，因为我们考虑对角线上的数字$x_{ii}$并更改它们）。数字$\alpha$，被放置，占用$I$。如果$I$可以枚举，那么$\alpha$一定有某个数字，比如$N$，即$\alpha = x_N$。但$\alpha = 0, x_{N1} \ldots x_{NN}$，情况并非如此，或者根据构造，$y_N \neq \bar{x}_{NN}$。

由此产生的矛盾证明了定理。

那么维度可能与点数有关吗？毕竟，很明显，正方形中的点比线段中的点多，立方体中的点比正方形中的点多。但不！康托尔证明了线段和正方形中所有点的数量相同的定理。

正是关于这个定理，有人说：“我理解这个，但我不相信它！”

定理3.线段$I$和正方形$I^2$大小相等。

让我们概述一下这个定理的证明。考虑一个由点 $(x_1; x_2), 0 \leqslant x_1 \leqslant 1, 0 \leqslant x_2 \leqslant 1$ 组成的正方形 $I^2$。和之前一样，让我们​​将数字 $x_1$ 和 $x_2$ 分解为小数，其中最后的小数部分是通过 9 写成的：

$$x_1 = 0, \alpha_1 \ldots \alpha_n \ldots,$$
$$x_2 = 0, \beta_1 \ldots \beta_n \ldots,$$

并按照苍白$(x_1; x_2)$的数字放入

$$y = 0, \alpha_1 \beta_1 \alpha_2 \beta_2 \ldots \alpha_n \beta_n \ldots.$$

在这种情况下，不同的参数对应不同的数字，即所有对的集合相当于段$I$的某个子集，因此$I^2$的基数不会超过段$I$的基数。另一方面，$I^2$的幂不小于$I$的幂（正方形包含多少个角段），所以$I$和$I^2$是等价的。

这里我们隐含地使用了子集的基数不大于集合本身的基数这一说法，并且基数可以进行比较。

5. 证明线段$I$等价于庞加莱系统。

他写道：“什么是$n$维度的对立性，它与更多或更少维数的对立性有何不同？首先让我们回顾一下康托尔学派最近获得的一些结果。直线和平面*上的点之间建立一一对应关系是可能的。只要我们不把自己束缚在直线上的两个接近的点对应于平面和另一边上的接近的点的条件下，这是可能的。”

从这些话中可以清楚地看出，庞加莱认为不可能有一个映射 $x \rightarrow F(x)$ 可以将线段 $I$ 映射到正方形上，并且同时在两个方向上都是一对一且连续的（即映射本身及其逆必须是连续的）。我们继续数数吧。

“我想将维数的定义建立在截面的概念上。让我们想象一条封闭的曲线，即一维的相反。如果我们在这条曲线上标记出禁止交叉的任何点，那么曲线将被切成两部分，并且在不穿过给定点的情况下不可能从一个部分移动到另一部分。

*) 这正是定理 3 中讨论的内容。
