所有类均以 $m$ 为模进行设置，即对于每个余数 0, 1, 2, ..., $m-1$，恰好有一个数字 (*) 可以与它​​以 $m$ 为模进行比较。

我们已经证明了一个比定理 1 更强的命题。
练习
23. 找到 $p, p+2, p+4$ 形式的所有素数三元组。
24. 找到一个最大长度差为 6 并且由素数组成的有限算术级数。
25. 十五个素数组成等差数列，差为$d$。
证明$d > 30000$。

现在我们应用定理1来证明所谓的中国剩余定理。这个定理在2000多年前的中国古代就已为人所知。

定理 2. 令数据$n$ 为成对互质数$m_1, m_2, ..., m_n$ 和数$r_1, r_2, ..., r_n$，使得$0 \leqslant r_i \leqslant m_i-1$ ($i=1, 2, ..., n$)。然后有一个数字 $N$ 除以 $m_i$ 得到余数 $r_i$。

换句话说，$N \equiv r_i(\text{mod } m_i)$对于所有$i=1, 2, ..., n$。

证明。让我们通过$n$应用归纳法。对于$n=1$，定理的陈述是显而易见的。令定理对于 $n=k$ 有效。然后有一个数字$M$，使得$M \equiv r_i(\text{mod } m_i)$对应$i=1, 2, ..., k$。

让$d=m_1m_2...m_{k-1}$。

让我们看看数字
$M, M+d, M+2d, ..., M+(m_k-1)d$.

由于$d$与$m_k$互质，根据定理1的证明可知，在所写的数字中，有一个数字$N$除以$m_k$时得到余数$r_k$。同时，当数字$N$除以$m_1, m_2, ..., m_{k-1}$时，分别得到余数$r_1, r_2, ..., r_{k-1}$。

定理已被证明。
最后，还有一个定理。
定理 3. 对于任何成对互质数 $m_1, m_2, ..., m_n$ 和余数 $r_1, r_2, ..., r_n$ 模 $m_1, m_2, ..., m_n$，有 $n$ 连续数 $a, a+1, ..., a+n-1$ 使得 $a \equiv r_1(\text{mod } m_1), a+1 \equiv r_2(\text{mod } m_2), ..., a+n-1 \equiv r_n(\text{mod } m_n)$。

换句话说，对于任何成对互质模$m_1, m_2, ..., m_n$，都有$n$连续自然数除以这些数字时给出相应的任何有向余数。

证明。根据中国剩余定理，存在 $a$ 使得
$a \equiv r_1(\text{mod } m_1),$
$a \equiv r_2-1(\text{mod } m_2),$
$a \equiv r_n-n+1(\text{mod } m_n)$.

但是数字$a, a+1, ..., a+n-1$满足定理的条件。
