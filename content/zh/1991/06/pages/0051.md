余数除法和模比较

（开头部分请参见第 36 页）

$(ak)n \equiv n \equiv bk(\text{mod } m)$,
从我们立即得到的地方
$n = bk + ml$,
其中$l$是任意整数。
那么问题来了，在特定情况下如何求$k$呢？

对于不太大的$m$，这个问题可以很简单地解决（通过简单的选择）。我们将在下一篇文章中讨论这个问题以及许多其他问题的一般解决方案。

任务 5. 解决比较问题
$32n \equiv 7(\text{mod } 37)$.

解决方案。从$32 \equiv -5(\text{mod } 37)$开始，我们来比较
$5n \equiv -7 \equiv 30(\text{mod } 37)$

或者
$n \equiv 6(\text{mod } 37)$

针对证据比较的解决方案，求解具有整数整数系数的线性方程的问题。

任务 6. 找到满足方程 $7x-23y=131$ 的所有整数对 $x$、$y$。

解决方案。从$23 \equiv 2(\text{mod } 7)$开始，我们得到比较$2y \equiv -131(\text{mod } 7)$或$2y \equiv 9 \equiv 2(\text{mod } 7)$，因此$y \equiv 1(\text{mod } 7)$。

所以$y=7k+1$，其中$k$是一个整数。现在你可以轻松找到$x$：

$7x-23(7k+1)=131$,

在哪里
$7x=154+23 \cdot 7k$,

IE。
$x=22+23k$.

总之，我们建议您解几个方程。
