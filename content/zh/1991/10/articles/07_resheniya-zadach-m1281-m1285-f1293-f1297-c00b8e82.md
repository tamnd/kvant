数 $a-1$ 和 $b-1$ 的算术平均值和几何平均值之间的不等式
$$a-1+b-1 \geqslant 2\sqrt{(a-1)(b-1)} > 2.$$
因此$a+b > 4$。
2. 这个条件等价于$a$和$b$的调和平均值大于2：
$$\left(\frac{a-1+b-1}{2}\right)^{-1} = \frac{2ab}{a+b} > 2.$$
但算术平均值不小于调和平均值：
$$\frac{a+b}{2} \geqslant \frac{2ab}{a+b},$$ 因为$(a-b)^2 \geqslant 0.$
因此$a+b > 4$。
3. 将这些条件除以 $a$ 和 $b$，我们得到
$$a > \frac{a}{b} + 1, \quad b > \frac{b}{a} + 1,$$
在哪里
$$a+b > \frac{a}{b} + \frac{b}{a} + 2 \geqslant 4.$$
4. 继续上面的条件，有明显的不等式
$$\frac{(a+b)^2}{4} \geqslant ab > a+b,$$ 对于$S=a+b$，我们得到$S^2/4 > S$，或$S^2 > 4S$，由此（自$S > 0$）$S > 4$。

以相反的顺序折叠卡片。证明a) $M(9) \leq 5$, 6) $M(52) \leq 27$, 8)*$M(52) \geq 17$, 9)*$M(52) \geq 27$。找到任意 $n > 2$ 的 $M(n)$。

指定...，$a, b, ..., c, d, ...$并将其插入$p$和$q$之间，则$ab, cd$和$pq$的连接被破坏。要以相反的顺序移动卡片，您需要销毁所有 $n - 1$ 连接。因此，对于必要步骤数$s$，我们得到了估计

$$3s \geq n - 1.$$

为了得到估计值 $s \geq (n + 1)/2$，我们的推理方式略有不同。我们假设相邻卡片之间可能有两种类型的连接：“>”或“<”（“更大”或“更小”），并且在$s$操作中，所有“<”类型的$n - 1$连接必须变成相反的“>”。请注意，在每一步中，连接“>”的数量不能超过 2 个。事实上，只有当从

...$a, b, ..., c, d, ..., p, q, ...$

到

...$a, d, ..., p, b, ..., c, q, ...$

如果

$$a < b, c < d, p < q, a > d, p > b, c > q.$$

但这六个不等式是互不相容的：它们意味着

$$a < b < p < q < c < d < a — противоречие.$$

此外，在第一步中，只有一个连接可以从“<”转换为“>”：毕竟，这里要么是$a < b < c < d < p < q$，要么是$p < q < a < b < c < d$，在这种情况下，三个不等式中只满足一个

$$a > d, p > b, c > q.$$

最后一步的情况完全相同，得到一组$n - 1$连接“>”（一般不难看出，反向转换与直接转换完全相似，只是符号“<”和“>”改变了角色）。

因此，对于步长不等式的数量 $s$，我们得到了估计

$$1 + 2(s - 2) + 1 \geq n - 1,$$

在哪里

$$s \geq (n + 1)/2.$$

F1294。薄金属板的一侧被太阳照亮。当空气温度为 $T_0$ 时，被照射面的温度为 $T_1$，相对面的温度为 $T_2$。如果采用双层厚度的板材，温度是多少？

热量从板的每一侧辐射。总功率输出为

$$W = a(T_1 - T_0) + a(T_2 - T_0)$$

（a为比例系数）。该板从太阳接收相同的能量。对于两倍厚的板，我们得到

$$W' = a(T_3 - T_0) + a(T_4 - T_0).$$

在热平衡中，热流从照明侧传播到相对侧，因此通过板的任何横截面，热流都相同并且等于空气从未照明侧（即，

$$a(T_2 - T_0) = k \frac{T_1 - T_2}{d}$$

（k为比例系数，d为板厚）。对于双厚度板 -

$$a(T_4 - T_0) = k \frac{T_3 - T_4}{2d}.$$

经过简单的变换我们发现

$$T_3 = T_0 + (T_1 + T_2 - 2T_0)(2T_1 - T_2 - T_0)/(2(T_1 - T_0))$$,

$$T_4 = T_0 + (T_2 - T_0)(T_1 + T_2 - 2T_0)/(2(T_1 - T_0)).$$

F1297。精确的光源平行于焦距$F$的集线主光轴移动。当他脸上的图像的速度与光源的速度相等时，他发现自己距直线有多远？ Distance from the main optical axis of the line to the source $H=F/4$.

设从源到直线的距离为$d$，从直线到图像的距离为$f$，我们写出直线公式：

$$\frac{1}{d} + \frac{1}{f} = \frac{1}{F}.$$

在很短的时间$\Delta t$内，从光源到直线的距离将减少$\Delta d=v_0\Delta t$，从直线到图像的距离将增加$\Delta f=u\cos \alpha \times \Delta t$。然后（见图）

$$\frac{1}{d-v_0\Delta t} + \frac{1}{f+u\cos \alpha \cdot \Delta t} = \frac{1}{d} + \frac{1}{f},$$

或者

$$\frac{v_0\Delta t}{d^2} = \frac{u\cos \alpha \cdot \Delta t}{f^2}.$$
