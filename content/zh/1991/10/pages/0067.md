我们直接进入程序。它适用于 MK-61，它适合并且所有程序都与该系列兼容。要启动它，将程序输入PMC后，必须手动执行以下操作。

按B/O键，拨初始奇数正整数，不小于5。然后按C/P键。指示器上将出现零。这是拨打 Blitz 序列号计数器初始值的邀请。您可以拨打一个。如果您确切地知道旧一对 Blitzes 的序列号，则拨打 Blitzes 中较小的一个作为初始奇数，然后在 C/P 和零出现之后，即为该已知序列号。

然后按C/P键，当副枪停止时，指示器上将出现双数字中的第一个数字。按C/P键后，会出现第二个，下一个C/P后，会出现这一对双胞胎的相对序列号。新按下 C/P 键将导致新双胞胎的出现，依此类推。

4.5小时，每项任务10分。任务编号后面的括号中标明提出该任务的国家。

第一天

1（阿根廷）。设 f 是在非负整数集合上定义的函数，并满足以下两个条件：

1) 如果 n = 2^i - 1（i = 0,1,2,...），则 f(n) = 0。
2) 如果 n ≠ 2^i - 1（i = 0,1,2,...），则 f(n + 1) = f(n) - 1。
a) 证明对于任何整数 n ≥ 0，都有一个整数 k ≥ 0 使得 f(n) + n = 2^k - 1。
b) 求 f(2^1990)。

2（哥伦比亚）。在三角形ABC中，I点是画在其中的圆的圆心，D、E和F分别是该圆与边BC、CA和AB的切点。令P为直线AD与曲线圆的另一个交点，M为线段EF的中点。证明点 P、I、M 和 D 位于同一个圆或直线上。

3（西班牙）。令 f(x) = (x + b)^2 - c 为多项式，其中 b 和 c 为整数。表明

a) 如果 p 是素数，并且 c 可被 p 整除但不能被 p^2 整除，则对于所有整数 n，数字 f(n) 不能被 p^2 整除，
b) 如果 q 是不等于 2 的质数，使得 c 不能被 q 整除，并且对于某个整数 n，f(n) 可被 q 整除，则对于任何整数 r，都存在一个整数 n'，使得 f(n') 可被 q' 整除。

第二天

4（委内瑞拉）。设 AB 为圆 c₁ 的直径。令 t 在 B 点接触该圆。设 M 为圆 c₁ 上的任意点，与 A 和 B 不同。让我们构造一个与圆 c₁ 在点 M 和线 t 相切的圆 c2。

a) 求圆 c2 与直线 t 的切点 P，如果点 M 是变量，则求圆 c2 的圆心轨迹。

b) 证明有一个圆与所有圆 c2 正交。

5（墨西哥）。设 A 和 B 是大小为 n × n 的子体的对边顶点，分为单位正方形 (n ≥ 1)。在每个正方形中绘制一条与线 AB 平行的对角线，因此必须有 2n² 个相等的三角形。切屑沿着圆盘上的线段从A移动到B，当经过三角形的边时，谷物被放置在其中。每个段不超过一次。在路径的尽头，结果表明每个 2n² 三角形恰好包含 2 个颗粒。 n取什么值时可能出现这种情况？

6（乌拉圭）。令 f(x) 为具有有理系数的三次多项式。证明如果函数 f(x) 的图形接触 x 轴，则多项式 f(x) 的所有三个根都是有理数。
