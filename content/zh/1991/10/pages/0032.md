以相反的顺序折叠卡片。证明a) $M(9) \leq 5$, 6) $M(52) \leq 27$, 8)*$M(52) \geq 17$, 9)*$M(52) \geq 27$。找到任意 $n > 2$ 的 $M(n)$。

指定...，$a, b, ..., c, d, ...$并将其插入$p$和$q$之间，则$ab, cd$和$pq$的连接被破坏。要以相反的顺序移动卡片，您需要销毁所有 $n - 1$ 连接。因此，对于必要的步骤数$s$，我们得到了估计

$$3s \geq n - 1.$$

为了得到估计值 $s \geq (n + 1)/2$，我们的推理方式略有不同。我们假设相邻卡片之间可能有两种类型的连接：“>”或“<”（“更大”或“更小”），并且在$s$操作中，所有“<”类型的$n - 1$连接必须变成相反的“>”。请注意，在每一步中，连接“>”的数量不能超过 2 个。事实上，只有当从

...$a, b, ..., c, d, ..., p, q, ...$

到

...$a, d, ..., p, b, ..., c, q, ...$

如果

$$a < b, c < d, p < q, a > d, p > b, c > q.$$

但这六个不等式是互不相容的：它们意味着

$$a < b < p < q < c < d < a — противоречие.$$

此外，在第一步中，只有一个连接可以从“<”转换为“>”：毕竟，这里要么是$a < b < c < d < p < q$，要么是$p < q < a < b < c < d$，在这种情况下，三个不等式中只满足一个

$$a > d, p > b, c > q.$$

最后一步的情况完全相同，得到一组$n - 1$连接“>”（一般不难看出，反向转换与直接转换完全相似，只是符号“<”和“>”改变了角色）。

因此，对于步长不等式的数量 $s$，我们得到了估计

$$1 + 2(s - 2) + 1 \geq n - 1,$$

在哪里

$$s \geq (n + 1)/2.$$
