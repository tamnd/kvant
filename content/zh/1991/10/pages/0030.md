a) 让我们证明（对于任何$n \geqslant 4$）当用第一类的这三种类型的图形（角图形）填充正方形$(2n-1) \times (2n-1)$时，将至少有$4n-1$。特别是，对于 $n=50$，我们获得所需的估计值 199。

给板单元着色 $(2n-1) \times (2n-1)$ 有四种颜色 1、2、3、4，如图所示 图 2.让 $a_i$ — 不包含颜色单元的角的数量 $i$ ($i=1, 2, 3, 4$)，即包含一个其他颜色的单元格； $b$ - 其他两种类型的图形总数，每种类型包含一个不同颜色的单元格。由于第一种颜色的细胞总数是 $n^2$、第二、第三 - 由 $n(n-1)$ 和第四个 - $(n-1)^2$， 那

$$a_2 + a_3 + a_4 + b = n^2,$$
$$a_1 + a_2 + a_4 + b = a_1 + a_3 + a_4 + b = n(n-1),$$
$$a_1 + a_2 + a_3 + b = (n-1)^2,$$

在哪里

$$a_4 - a_1 = 2n-1, \quad a_3 - a_1 = a_2 - a_1 = n$$

和（从$a_1 \geqslant 0$）$a_2 = a_3 \geqslant n$，$a_4 \geqslant 2n-1$，所以

$$a_1 + a_2 + a_3 + a_4 \geqslant n + n + 2n-1 = 4n-1.$$

这是一个较短的论证，仅涉及角的总数$a = a_1 + a_2 + a_3 + a_4$和其他两种类型的图形的数量$b$。由于 $3a + 4b = (2n-1)^2$ 并且每个图形最多包含第 1 种颜色的一个单元格，则 $a + b \geqslant n^2$，因此

$$4a \geqslant 4n^2 - 4b = 4n^2 - (2n-1)^2 + 3a = 4n-1 \geqslant 3a,$$

在哪里

$$a \geqslant 4n-1.$$

6) 图 3 展示了如何使用类型 2 或 3 的一个图形和 $15=4 \cdot 4-1$ 角*来填充正方形 $7 \times 7$，图 4 展示了如何从用 $4n-1$ 角填充正方形 $(2n-1) \times (2n-1)$ 到用 $4(n+1)-1=4n+3$ 角填充正方形 $(2n+1) \times (2n+1)$。 （请注意，根据我们对 a 点的估计）可以得出 $b=n^2-a_2-a_3-a_4 \leqslant n^2-4n+1$，而 $1 \leqslant n < 4$ 处的数字为负数，因此只能从 $n=4$ 开始填充，即从正方形 $7 \times 7$ 开始。
