从坐标原点到除点 (0; 0) $(m; n)$ $(m$ 和 $n$ 为整数之外的整数点阵的任意点。令该距离等于$\hat{d}$，并在格点$(\hat{m}; \hat{n})$处实现，使得
$$a\hat{m}^2 + 2b\hat{m} + c\hat{n}^2 = \hat{d}^2.$$ (4)

平面上满足不等式的点集$(x; y)$
$$ax^2 + 2bxy + cy^2 \leq \hat{d}^2,$$
是一个椭圆。从我们的构造可以看出，如果这个椭圆准备被压缩两次，然后将这个“压缩”的椭圆（与自身平行）以中心扩展为整数晶格的点，那么所有得到的椭圆，如果相交，也只会在边界点处。

不难理解（参见图），椭圆与顶点为$(0; 0), (1; 0)$和$(1; 1)$的三角形相交所占据的面积等于整个椭圆面积的一半。它——这个面积——等于
$$\frac{\pi \hat{d}^2}{4} \det \binom{a}{b} = \frac{\pi \hat{d}^2}{4} (ac - b^2) = \frac{\pi \hat{d}^2}{4}$$

我们的读者雅。格罗岑斯基（Grozensky）在研究整数平方序列时得出：
$$x^2 = 2(x - 1)^2 - (x - 2)^2 + 2.$$
然后对于立方体他发现
$$x^3 = 3(x - 1)^3 - 3(x - 2)^3 + (x - 3)^3 + 6,$$
对于四倍幂 -
$$x^4 = 4(x - 1)^4 - 6(x - 2)^4 + 4(x - 3)^4 - (x - 4)^4 + 24.$$
他在信中询问是否存在普遍依赖性

$$x^n = n(x - 1)^n + A_1(x - 2)^n + \dots + A_k(x - k)^n + \dots + A_n(x - n)^n + n!$$

实际上存在这样一个公式：
$$x^n - C_1^n(x - 1)^n + C_2^n(x - 2)^n - \dots + (-1)^k C_k^n(x - k)^n + \dots + (-1)^n(x - 1)^n = n!$$
其中 $C_k^n$ 是生物平面系数
$$\left( C_k^n = \frac{n!}{k!(n - k)!} \right).$$
