$$y = x^2 + 1,$$
让我们将方程简化为以下形式
$$\frac{y(y + 2x) + x^2}{y^2 - x^2} = \frac{y}{x}.$$

替换$y/x = t$后我们得到方程
$$\frac{t(t + 2) + 1}{t^2 - 1} = t,$$ 或 $t + 1 = t(t - 1),$
有根$t_{1,2} = 1 \pm \sqrt{2}$。
所以，$\frac{x^2 + 1}{x} = 1 \pm \sqrt{2},$
即 $x^2 - (1 \pm \sqrt{2})x + 1 = 0$，从我们得到

答案：$(1 + \sqrt{2} \pm \sqrt{2\sqrt{2} - 1})/2.$

在求解方程组时，引入额外的未知数特别有用。

问题8.解决系统
$$\begin{cases}
2x^2 + xy = 1, \\
\frac{9x^2}{2(1-x)^4} = 1 + \frac{3xy}{2(1-x)^2}.
\end{cases}$$

解决方案。在系统的第二个方程中，可以方便地表示
$$z = \frac{3x}{(1-x)^2}.$$

然后
$$z^2 = 2 + zy.$$ (4)

现在，将第一个方程除以 $x^2$，我们将其简化为以下形式
$$\left(\frac{1}{x}\right)^2 = 2 + \left(\frac{1}{x}\right)y$$ (5)

$(x \neq 0)$。接下来：将式（4）减去式（5），得到
$$\left(z - \frac{1}{x}\right)\left(z + \frac{1}{x}\right) = \left(z - \frac{1}{x}\right)y,$$
从 $z = 1/x$ 或 $z + 1/x = y$ 开始。在第一种情况下我们得到
$$\frac{3x}{(1-x)^2} = \frac{1}{x},$$即$x = \frac{1}{2}(-1 \pm \sqrt{3}),$
$y = 2.$

在第二种情况下，$xz + 1 = xy$与原系统的第一个方程一起给出$2x^2 + xz + 1 = 1$。既然$x \neq 0$，那么$2x + z = 0$，即

$$\frac{3x}{(1-x)^2} + 2x = 0.$$

该方程没有非零根。
答案：$((-1 \pm \sqrt{3})/2; 2).$
