图 4 所示图中的电视$R$，关闭钥匙$K$ 后？在开关闭合之前，容量为$C_1$的电容器上有电荷$q_1$，容量为$C_2$的电容器上有$q_2$电荷。

根据能量守恒定律，释放的热量将等于开关闭合前$K$与闭合后电容器的能量之差，即初始能量与最终能量之差：

$$Q = W_{\text{н}} - W_{\text{к}}.$$

在钥匙关闭之前，集中在电容器中的总能量等于

$$W_{\text{н}} = \frac{q_1^2}{2C_1} + \frac{q_2^2}{2C_2}.$$

为了找到开关闭合并建立新的稳态后电容器的能量，我们必须找到电容器上的新电荷。让电荷$q$离开电容$C_1$的电容器，并且其上的新电荷等于$q_1 - q$。根据总电荷守恒定律，容量为$C_2$的电容器极板上将建立电荷$q_2 + q$。停止电荷流动的条件是电容器上的方向相等：

$$\frac{q_1 - q}{C_1} = \frac{q_2 + q}{C_2}.$$

解这个方程，我们得到

$$q = \frac{q_1 C_2 - q_2 C_1}{C_1 + C_2}.$$

那么电容器上的新电荷将相等

$$q'_1 = \frac{C_1}{C_1 + C_2} (q_1 + q_2)$$

和

$$q'_2 = \frac{C_2}{C_1 + C_2} (q_1 + q_2),$$

电容器中的新能量储备将为

$$W_{\text{к}} = \frac{q_1^2}{2C_1} + \frac{q'_2^2}{2C_2} = \frac{(q_1 + q_2)^2}{2(C_1 + C_2)},$$

释放的热量是

$$Q = W_{\text{н}} - W_{\text{к}} = \frac{(q_1 C_2 - q_2 C_1)^2}{2C_1 C_2 (C_1 + C_2)}.$$

从结果表达式可以看出，$Q$不依赖于$R$。抵抗力的作用是什么？事实证明，它的大小影响能量耗散（耗散）的速率——$R$越小，放热越剧烈，相应的放电时间也会减少。

问题 4. 要在扁平空气充电电容器的间隙中留下另一个充满电介质且电介质含量为 $\varepsilon$ (图 5) 的扁平充电电容器，需要做哪些工作？电容器$Q_1$和$Q_2$上的电荷，每个极板的面积$S$，极板之间的距离$d_1$和$d_2$（$d_1 > d_2$）。

为了解决这个问题，可以使用能量法。显然，将带有电荷 $Q_2$ 的电容器引入带有电荷 $Q_1$ 的电容器中的功将等于最终位置和初始位置的电容器电场能量之差：

$$A = W_{\text{к}} - W_{\text{н}}.$$

在初始状态下，电容器彼此隔离，它们的总能量等于

$$W_{\text{н}} = \frac{q_1^2}{2C_1} + \frac{q_2^2}{2C_2} = \frac{Q_1^2 d_1}{2 \varepsilon_0 S} + \frac{Q_2^2 d_2}{2 \varepsilon_0 S}.$$
