8. 在时间τ期间，体积$V = Sv\tau$的气体将通过管道横截面。将$V$代入气体状态方程
$$pV = \frac{m}{M} RT,$$
我们来求一下流速：
$$v = \frac{mRT}{MpS\tau} = 2 \text{ m/c}.$$

9. 最终压力$p'$等于单原子和双原子气体在容器体积中产生的分压$p_1$和$p_2$之和。让我们从状态方程中找到这些压力以及初始压力 $p_0$
$$p_0V = \frac{m}{M_2}RT, p_1V = \frac{m_1}{M_1}RT, p_2V = \frac{m_2}{M_2}RT,$$
其中$m_1 = m_2 = m/2, M_1 = M_2/2$。从这些方程我们得到
$$p' = p_1 + p_2 = 1,5p_0.$$

10. 当容器受热不均匀时，气体通过连接管从一个容器流到另一个容器，从而平衡压力。让我们写出加热前后容器中气体的状态方程：
$$pV = \frac{m}{M}RT, p'V = \frac{m_1}{M}RT_1,$$
$$p'V = \frac{m_2}{M}RT_2, p'V = \frac{m_3}{M}RT,$$
其中$p'$是系统中的最终压力。表达气体的质量并将其代入总质量守恒定律
$$m_1 + m_2 + m_3 = 3m,$$
我们得到
$$\frac{p'}{p} = \frac{3}{T} \left( \frac{1}{T_1} + \frac{1}{T_2} + \frac{1}{T} \right)^{-1} = 2.$$

11. 让我们写下能量守恒定律
$$\frac{kx_0^2}{2} + \frac{mv_0^2}{2} = \frac{kA^2}{2},$$
其中等式右边是灯泡的总能量，等于极限位置（$x = A$）的势能。考虑到$k/m = \omega^2$，我们得到
$$A = \left( x_0^2 + \frac{v_0^2}{\omega^2} \right)^{1/2} = 5 \text{ cm}.$$

12. 作用在磁铁上的不是外力$mg$，而是合力$F = mg + qE$。将这个力写成$F = mg'$的形式，其中$g' = g + qE/m$，我们看到$g'$起到了自由落体有效加速的作用，通过它可以表达烧瓶数学矩阵的一部分：$\omega = \sqrt{g'/l}$。比率 $\omega$ 至

$$\omega_0 = \sqrt{\frac{g'}{g}} = \sqrt{1 + \frac{qE}{mg}} = 3.$$

13. 我们将从方程$1/C_2 = 1/C_1 + 1/(C_1/3)$找到电路中电容器的新电容$C_2$。与初始值$C_1$相比，电容将减少4倍，即频率$v = 1/2\pi\sqrt{LC}$将增加2倍。

14. 根据条件$q^2(t)/2C = Li^2(t)/2$，其中$q(t) = q_0 \cos \omega t, i(t) = q'(t) = -q_0 \omega \sin \omega t$。考虑到$\omega = 1/\sqrt{LC}$，我们得到$tg \omega t = 1$，即$t = \pi/4 \omega = \pi\sqrt{LC}/4 \approx 31,4$μs。

15. 最小条件的形式为 $L_2 - L_1 = \lambda/2 + k\lambda$，其中 $k = 0, 1, \dots$。在频率等于 $v = v/\lambda = v(k+1/2)/(L_2 - L_1)$ 时满足此条件。最小频率为 $v_{\min} = v/2(L_2 - L_1) = 1$ kHz。
