M1276。对于给定的弦 MN，距离圆是三角形 ABC，其底边是该圆不与 MN 相交的直径 AB，边 AC 和 BC 通过弦 MN 的端点 M 和 N。证明所有这样的三角形ABC的高，省略顶点A和B，因此第三个高通过它们的交点H，并且点C、M、N和H位于同一个直径为CH的圆δ上。设 P 为该圆的中心。请注意，当直径 AB 移动时，三角形的角度 C 的值保持不变 - 它在弧线 AB 和 MN 之间发生半不同的变化，弧线 AB 和 MN 的大小是恒定的（参见 图）。由于弦 MN 不动，圆 δ（沿着它的点 C 和与其直径相反的点 H 移动），因此它的中心 P 也保持不变：直径 CH（我们感兴趣的高度部分）只是绕点 P 旋转。

M1277。证明（对于正 $a_1, a_2, \dots, a_n$）不等式
$$\sqrt{\frac{a_1+a_2}{a_3}} + \sqrt{\frac{a_2+a_3}{a_4}} + \dots + \sqrt{\frac{a_{n-1}+a_n}{a_1}} + \sqrt{\frac{a_n+a_1}{a_2}} \geqslant n\sqrt{2}.$$

由不等式$x^2+y^2 \geqslant 2xy$（两个数$x^2$和$y^2$的算术平均值与几何平均值之间的不等式）可知，所证明的不等式左边不小于
$$\sqrt{2}\left(\frac{4}{\sqrt{a_1a_2}} + \frac{4}{\sqrt{a_2a_3}} + \dots + \frac{4}{\sqrt{a_{n-1}a_n}} + \frac{4}{\sqrt{a_na_1}}\right).$$

由于括号内根的乘积$n$等于1，根据柯西关于$n$数的算术平均值和几何平均值的定理（该定理在今年杂志第三期中详细讨论过），它们的总和不小于$n$。因此必然存在不平等。

V. 森德罗夫、L. Kurlyandchik

M1278。有n个实数$x_1, x_2, \dots, x_n$满足条件$x_1 + x_2 + \dots + x_n = 0$和$x_1^2 + x_2^2 + \dots + x_n^2 = 1$。证明对于某些人来说 $x_i x_j \leq -1/n$ 是 $i, j$。

让我们首先考虑“极端”情况，当数字仅取两个不同的值时：其中$k$等于$a < 0$，其余$(n-k)$等于$b > 0$。然后$ka + (n-k)b = 0$，即$ka = -(n-k)b$和$ka^2 + (n-k)b^2 = -(n-k)ab - kab = 1$，由此而来$ab = -1/n$。让我们尝试通过“开发”变量来将一般情况简化为这种情况。请注意，如果我们将数字对 $u, v$ $(u < v)$ 替换为 $u - t, v + t$ $(t > 0)$，那么总和不会改变，但平方和会增加：

$$(u - t)^2 + (v + t)^2 = u^2 + v^2 + 2t(v - u) + t^2.$$

令 $a < 0$ 为给定 $n$ 数 $x_1, x_2, \dots, x_n$ 中最小的，$b > 0$ 为最大。如果该集合中除 $a$ 和 $b$ 之外还有两个数字，请将它们分开而不更改总和，以便其中一个等于极数 $a$ 或 $b$ 之一。经过几次运算，我们得到一组$n$数字，其中除了一个（我们称之为$c$）之外的所有数字都等于$a$（令它们为$k$）或$b$（$m = n - k - 1$），其总和为0，且平方和不小于1：

$$ka + c + mb = 0,$$

$$ka^2 + c^2 + mb^2 = -(c + mb)a + c^2 - (ka + c)b \geq 1.$$

从$a \leq c < b$开始，$ca - c + cb - ab = (c - a)(b - c) > 0$。将这个不等式添加到前一个不等式中，我们得到所需的：

$$-(m + k + 1)ab = -nab > 1,$$

或$ab < -1/n$。

（从这个证明可以清楚地看出，只有在一开始考虑的“极端”情况下才能实现平等。）

该问题也有直接的代数解。对于任意 $i, 1 \leq i \leq n$

$$(x_i - a)(x_i - b) \leq 0.$$

总结这些不等式，我们得到

$$\sum_{i \leq 1}^{n} x_i^2 - (a + b) \sum_{i=1}^{n} x_i + nab \leq 0$$

(*)

但是$\sum_{i \leq 1}^{n} x_i^2 = 1$，$\sum_{i=1}^{n} x_i = 0$，所以(*)变成了$nab \leq -1$。

N.瓦西里耶夫、E.斯托洛夫

M1280*。证明在小数 1/3$^{100}$ 的周期内发生以下情况：
a) 至少20个连续的相同数字；
b) 数字序列 123456789。

我们将证明一个明显更强的陈述：任何 46 位数字的序列都将出现在小数 1/3$^{100}$ 的周期内。

注意$3 \cdot 9^9 > 10^9$（你可以直接检查这个，或者你可以使用$(1 + 1/k)^k < 3)$，所以$3^{100} = 3^{95} \cdot 3^5 = 3^{5 \cdot 19} \times 243 > 10^{45} + 2 = 10^{47}$；知道3的对数，很容易检查这个估计是否相当准确：我们的分数1/3$^{100}$正好以47个零开始（这使得问题a的公式答案）微不足道；然而，相对容易证明在20周期甚至所有其他数字中0 以外的值将连续出现 45 次）。

我们首先通过$n$上的指示证明小数1/3$^n$的周期长度等于$3^{n-2}$（在$n \geqslant 2$处）。对于$n=2$，这是正确的：$1/9 = 0,11111...$ 让$1/3^n = A_n/(10^{3n-2} - 1)$（其中$A_n$是自然数）不为3（这意味着小数1/3$^n$的长度为$3^{n-2}$）。然后是$10^{3n-2} - 1 = 3^n A_n$和$10^{3n-1} - 1 = 10^{(3n-2)} - 1 = (10^{3n-2} - 1)(10^{2 \cdot 3n-2} + 10^{3n-2} + 1)$。第二个括号除以 9 显然余数为 3；令其等于$9B_n + 3$，则

$$10^{3n-1} - 1 = (10^{3n-2} - 1)(9B_n + 3) = 3^{n+1} A_n(3B_n + 1) = 3^{n+1} A_n$$

其中 $A_{n+1}$ 不能被 3 整除，因此 $1/3^{n+1}$ 的周期长度为 $3^{n-1}$。 （请注意，通过指示，也很容易验证 $A_n$ 除以 3 时余数为 1。）作为一个小缺陷，我们将使用它来展示为什么在我们的分数 1/3$^{100}$ 中会有一组连续的相同数字。事实上，具有足够大的 $n$ 的周期 $A_n$ 以一系列零开始。当移动到$A_{n+2}$时 - 可以通过用一列将九个$A_n$除以9来获得 - 在$(k+1)$-第$A_n$的开头，我们将得到一系列数字$k$（其中$k=0,1,...,8$）。奇怪的是，如果当前的$n$很大，即级数的长度超过9，我们可以通过将级数...11111...除以9，明确指示数字012345679在数字$A_{n+4}$中将连续出现的位置（这是周期1/81），但由于缺少8，这些消息稍微不足以解决问题6）。

F1288。在一个直径为20m、天花板高度为3.2m的大圆形房间的中央，有一个边长为3m的立方体形状的大型保险箱。使用位于地板上的玩具弹射器，我们想将一块鹅卵石扔到保险箱“屋顶”的中间，这样鹅卵石就不会接触到天花板。为此所需的最低速度是多少？房间的天花板高度是多少才可能实现这一点？

考虑相反的情况会更方便——从我们想要击中的点扔一个石子，并确保它不会碰到天花板并击中地板（而不是墙壁）。当然，你需要平行于边缘扔石子，而不是沿着对角线。

让我们考虑一条接触卵石边缘并几乎定义天花板的轨迹，即它的上点正好位于中间。对于这个轨迹，我们可以计算出石子在投掷瞬间的速度的投影：

$$v_b = \sqrt{2g(H-a)} \approx 2 \text{ м/c}, \quad v_r = \frac{a}{4} \sqrt{\frac{g}{2(H-a)}} \approx 1,87 \text{ м/c},$$

其中$H=3,2 \text{ м}, a=3 \text{ м}$。

现在很容易找到卵石落到地板上时的最小速度：

$$v_{\min}^2 = v_r^2 + v_b^2 + 2ga = \frac{ga^2}{32(H-a)} + 2gH, \quad v_{\min} \approx 8,2 \text{ м/c}$$

如果降低天花板的高度，则速度会增加，并且在一定高度时，卵石会撞击地板的边缘。这将发生在天花板高度

$$H^* = a + \frac{a}{(2d/a)^2 - 1} \approx a + \frac{a}{151,1} \approx 3 \text{ м} + 2,0 \text{ см.}$$
