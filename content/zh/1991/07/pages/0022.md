6) 对于任意 $n$，获得$k(n)$ 的分数。估计值 $(\sqrt{8n+1} + 1)/2 \leq k(n) \leq \sqrt{4n+5} - 1$ 已知。尝试证明这些不等式，如果可以的话，找到更准确的估计。

问题1和问题2很相似，似乎密切相关。唯一的区别是，在一种情况下考虑圆，而在另一种情况下考虑线段。将关于任务 2 的所有已知信息转移到任务 1 的想法将立即出现。

为了简洁起见，我们将根据问题 2 的条件放置的长度为 $n$ 的线段称为长度为 $n$ 的万能尺。

在A. Savin的文章“从学校问题到问题”（«Kvant»，1976年第12期）中，我概述了这个问题的解决方案。上限 - $k(n) \leq \sqrt{4n+5} - 1$ - 是通过以下任意长度 $n$ 的万能尺的构造获得的：

$$\frac{1, 1, ..., 1}{m \text{ раз}}, \frac{m+1, m+1, ..., m+1}{l \text{ раз}}.$$

如果$n < m+l(m+1)$，则最后一段相应地比$(m+1)$短，而标尺保持通用。

很快我就成功地为一些$n$设计了尺子。

$$L_1 = \begin{cases} 1, 2, 2, 5, \\ 3, 1, 2 \end{cases}$$

$$L_2 = 1, 2, \begin{cases} 2, 2, 7, 7, \\ 5, 5, 1, 2, 2 \end{cases}$$

$$L_3 = 1, 2, 2, 2, \begin{cases} 2, 9, 9, 9, \\ 7, 7, 7, 1, 2, 2, 2 \end{cases}$$

$$L_l = 1, \begin{cases} 2, ..., 2, \\ (l+1) \text{ раз} \end{cases}$$

$$2l+1, ..., 2l+1, 1, \begin{cases} 2, ..., 2, \\ l \text{ раз} \end{cases}$$

括号内的线段可以连续重复几次，新长度的尺子仍然是通用的。

万能序列和万能标尺

我无法将获得的结果扩展到问题 1。但是还有另一个问题与前两个问题很接近：

问题 3（M400，«Kvant» No. 8，1976）：我们将自然数序列称为 $a_1, a_2, ..., a_k$ 项的部分，从中我们可以获得任何 $n$ 数字序列，其中每个数字 1, 2, ..., $n$ 出现一次。对于任意的$n$，指定最短的$(n, k)$通用序列。

(4.12)-通用序列的示例是：1, 2, 3, 4, 1, 2, 3, 1, 4, 2, 1, 3。

期刊中给出的解决方案提出了一种构建通用序列的特定结构的方法，该结构给出了数字 $k(n)$ 的以下估计：

$$(n(n+1))/2 + n - 2 \leq k(n) \leq n^2 - 2n + 4.$$

研究任务。构建以提高您的成绩 (1)。

万能标尺在非重复段中从 1 更改为 $n$，那么通用序列是所有不重合的排列
