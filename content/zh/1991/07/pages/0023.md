1, 2, ..., n.问题 3 的一对立即出现

问题 4（新）。 k个点将圆分成k条弧，弧长为自然数。将一个圆划分为一个全域 (n, k)，如果删除其中的部分弧，就可以得到任意 n 条弧的序列，其中长度为 1, 2, ..., n 的弧各出现一次。对于任意数字 n，指示存在圆的 (n, k) 万分分的最小 k。

事实证明，问题 M400 的解决方案中提出的数字 k(n) 的构造和估计也适用于问题 4。

研究任务。圆的某些 (n, k) 万分法的构造使我们可以假设，如果 n 为偶数，则 k(n)=k²/2；如果 n 为奇数，则 k(n)=(k²-1)/2。证明或测试这个假设。

通用统治者的二元亲戚

结果证明它们是问题 M574 的两个变体（«Kvant»，1979 年第 7 期）：

问题 5. 数字 0 和 1 的有限序列 a₁, a2, ..., aₙ 必须满足以下条件：对于从 1 到 n-1 的任意整数 k，其和 C(k)=a₁aₙ+a2aₙ+aₙ-kaₙ 是奇数。证明对于未燃烧的 n<1000 存在这样的序列。

问题6（M574，环形版本）。指示 n 的值，其中存在围绕圆的数字 0 和 1 的序列 a₁、a2、...、aₙ，使得对于任何 k(1≤k≤(n-1))，间隔为 k 的项的成对乘积之和，即 C(k)=a₁aₙ+a2aₙ+...+aₙ-kaₙ，奇数。

问题5彻底解决。它的解（«Kvant»No.6, 1980）不仅指出了存在排除双序列（为简洁起见，我们称其为n序列）的所有n值，而且还给出了几种构造它的方法。

我将（无需证明）提供其中之一。

令 A=a₁, a2, ..., aₙ 为满足问题条件的某个序列（例如，A=1101）。那么由三组 A 和它们之间的两组零组成的序列 B=A 00...0 A 00...0 A=b₁, ..., b₇n-3 也满足它。在我们的例子中，B=1101 000 1101 000000000 1101。

问题6的解决方案未知。
