逆问题

已知与给定定理相反的定理是其条件为给定定理的结论的定理，而结论为给定定理的条件。我们以“直接”定理的形式提出六个问题。它们都很简单，小学生都知道。自己证明这些“直接”定理的逆命题。你会发现逆定理的所有证明都比“直接”定理的证明困难得多。

直接定理

1. 在梯形中，连接底边中点的线段将梯形分成两个相等的图形。

2. 在平行四边形中，对边中点之间的距离之和等于其周长的一半。

3. 如果点$H$是锐角三角形$ABC$的垂心（高的交点），则$\angle HBA = \angle HCA, \angle HAB = \angle HCB$。

4. 如果点 $O$ 是三角形 $ABC$ 的外接圆的圆心，则$\angle OAB = \angle OBA = \angle OBC = \angle OCB = \angle OCA = \angle OAC$。

5. 在等边三角形中，三角形的内切圆的中心位于欧拉直线上。 （欧拉直线是包含垂心、中线交点和三角形外接圆中心的直线。）

6. 在等边三角形中，底角的三边相等。

证明逆定理的指导

1. 在四边形$ABCD$中，点$M$是$AD$的中点，点$N$是$BC$的中点。证明$S_{ABN} = S_{DCN}$。那么$AD \parallel BC$，即$ABCD$是梯形。

2. 证明四边形 $ABCD$ 是平行四边形 (图 1)。令点 $M, N, E$ 分别为线段 $AB, DC$ 和 $AC$ 的中点。然后是$AD \parallel EN$、$EN = \frac{1}{2} AD, BC \parallel ME$、$ME = \frac{1}{2} BC$。从$MN \leq ME + EN$开始，然后$MN \leq \frac{AD + BC}{2}$。令$L$和$K$为$BC$和$AD$的中点。同样，$LK \leq \frac{AB + CD}{2}$。按条件$MN + LK =$
