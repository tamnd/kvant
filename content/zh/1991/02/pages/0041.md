3. 围绕三角形 $ABC$ 画一个圆，并绘制一条线段 $CC_1$，直到与它相交于点 $N$ (图 2)。证明如果$\angle HAB = HCB$，$\angle HBA = \angle HCA$，则点$H$是锐角三角形$ABC$的三重心。从$\angle BAN = \angle BCN$开始，然后是$\angle HAB = \angle BAN$，类似地，$\angle HBA = \angle ABN$，从$C_1H \perp AB$开始。证明$\angle AA_1C = 90^\circ$。让我们表示 $\angle HAC = \alpha$、$\angle HAC_1 = \beta$、$\angle HBA = \gamma$。因为$\triangle ACC_1$是直脑袋，所以$\alpha + \beta + \gamma = 90^\circ$。利用$\triangle CC_1B$是直头的事实，证明$\angle HBC = \alpha$。我们用$\angle AA_1B = x$来表示它。

考虑$\triangle AA_1B$，我们得到$x + \alpha + \beta + \gamma = 180^\circ$。因此$x = 90^\circ$。

4. 证明点$O$是三角形$ABC$(图3)的外接圆的圆心。让我们用 $\alpha_1, \alpha_2, \beta_1, \beta_2, \gamma_1, \gamma_2$ 表示条件中给出的角度。为了确定，我们将数$\alpha_1 > \alpha_2$、$\beta_1 > \beta_2$、$\gamma_1 > \gamma_2$。然后从形成的三角形中我们得到$OB > OA, OC > OB, OA > OC$。 $OB > OC$从何而来——我们得到了相反的结果。

5. 证明如果三角形内切圆$I$的圆心属于欧拉线，则该三角形是等边三角形。令$O$为外接圆圆心，$I$为内切圆圆心，$H$为垂心，$M$边$BC$的中点，$W_1$角$BAC$的平分线与三角形外接圆$ABC$的交点， $W_2$是角$ABC$的平分线与外接圆（图4）的交点。考虑相似的三角形$OW_1I$和$HAI, OW_2I$和$HBI$。从$OW_1 = OW_2$开始，然后是$AH = BH$，因此$AC = BC$。
