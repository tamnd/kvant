我们假设数字 $a_1, a_2, ..., a_{n-1}, a_n$ 包含在一个循环中：

$$a_{n+1} = a_1, a_{n+2} = a_2, ...$$

请注意，条件中指定的转换在重复时（在同一位置）将返回到原始序列。这表明其背后隐藏着两个数字的某种排列 - 我们现在将看到情况确实如此。

考虑部分和的序列 $B$：

$$b_1 = c + a_1,$$
$$b_2 = c + a_1 + a_2,$$
$$b_3 = c + a_1 + a_2 + a_3,$$
$$b_3 = c + a_1 + a_2 + a_3,$$

F1305。在图1电路中，电池电压为$U_0 = 10$V，电容器的电容为$C = 1$uF，扎巴诺表的电阻为$R = 1$kOhm。每秒十次，电容器与电路断开并立即重新连接，反转其端子。 zalbano 仪表显示的电流是多少？当电容器的电容量增加到1000μF时，电流变化多少倍？在这样的切换频率下，扎巴诺表针实际上不会移动。

对于给定的 $R$ 和 $C$ 值，在 $\tau = 0,1$ 秒的时间内，电容器每次都有时间几乎完全充电 - 每个间隔结束时的电荷量相等

$$q = CU_0.$$

这意味着在时间 $\tau$ 期间，电荷流过 zalbano 计

$$q_G = q - (-q) = 2q = 2CU_0,$$

通过扎巴诺计的平均电流（这是磁电装置显示的）结果等于

$$I_{cp} = \frac{q_G}{\tau} = \frac{2CU_0}{\tau} = 2 \cdot 10^{-4} \text{A}.$$

对于大电容器值 $C' = 1000$ µF，该过程看起来有所不同 - 在时间 $\tau$ 期间，电容器上的电压 $U$ 发生变化，但变化非常小：

$$\Delta U \approx \frac{I\tau}{C'} = \frac{U_0\tau}{C'R} = 1\text{B} \ll U_0.$$

很明显，电容器上的电压在零附近波动，并且几乎呈线性变化（图2）。因此，这种情况下的平均电流等于

$$I'_{cp} = I = \frac{U_0}{R} = 10^{-2} \text{A},$$

流动比率为

$$\frac{I'_{cp}}{I_{cp}} = \frac{10^{-2} \text{A}}{2 \cdot 10^{-4} \text{A}} = 50.$$

导致非加速盘下落的制动力是由盘中的傅科感应电流与电磁铁绕组中的电流的相互作用产生的。在所有磁盘大小相同的情况下，我们可以假设这个力

$$F \sim I_{\text{ннд}} I_{\text{обм}} \sim \frac{\mathcal{E}_{\text{ннд}}}{\rho} I_{\text{обм}}.$$

忽略傅科电流引起的总场的扭曲，对于感应电动势，我们可以写成

$$\mathcal{E}_{\text{ннд}} \sim \frac{\Delta B}{\Delta h} v \sim I_{\text{обм}} v,$$

其中$\Delta B/\Delta h$是磁场感应随高度的变化率。

所以，

$$F \sim \frac{I_{\text{обм}} v}{\rho} I_{\text{обм}} = \frac{I_{\text{обм}}^2 v}{\rho}.$$

对于稳定运动，等式成立

$$F - mg = 0.$$

由此，引入材料的密度$d$，我们得到对应关系

$$\frac{I_{\text{обм}}^2 v}{\rho d} = \text{const}$$
