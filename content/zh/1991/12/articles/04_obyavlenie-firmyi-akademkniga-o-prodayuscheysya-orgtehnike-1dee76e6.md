那么激光呢？他们如何设法绕过公式（8）？答案在于激光器的设计。从原理上讲，激光可以想象为两面镜子，其中一面是透明的，另一面是半透明的。镜子之间有一种活性介质（气体或固体），其原子的能量状态对应于特殊的“激光”条件。在活性介质中，辐射受到外部影响（光、放电、化学反应）的激发。由于受激辐射与活性介质和镜子相互作用，从激光中射出同样狭窄的辐射束，具有适当的特性，可以燃烧相当远距离的任何东西。

他为什么会变成这样？我们已经说过，任何扩展的光源都是发光点的集合，我们可以用它来表示原子和原子团。在一个公共源中，所有这些基本发射器在不同时间发射光子，彼此不关注。相反，在激光中，所有原子都相应地同步发射，或者用基本术语来说，均匀地发射。这里的所有光子都具有相同的频率，最重要的是，具有相同的相位。我们可以假设激光活性介质的所有原子都充当一个原子，该原子已将其所有组件的能量返回给自身。公共源可用于具有多个发动机的火箭，这些发动机以随机、弯曲的方式和错误的方向引导。这样的火箭白白浪费了大部分能量。在激光火箭中，所有发动机都指向一个方向，这提供了其非凡的性能。从公共源发出的电磁波的波前等于混沌菜单。激光束的波前规则且形状清晰。

他们长什么样子？这是最重要、最根本的一点。人们可能会认为它们代表平面，因此代表光线（垂直于波前）——理想的平行线，不会发散，传播到无穷远。然而实际上，不存在平行光线。理想的平坦波前应具有无限的横向尺寸。如果我们只是限制平面波的大小，请停止，因为它会由于这种大小的衍射而立即发散。当然，激光束的波前受到活性介质的横向尺寸的限制。如果它位于激光器和飞机之间的某个地方（顺便说一句，这种情况经常发生），那么它已经接近远处的飞机了。

数字系统
具有给定的基数

这是具有基数的数字系统的名称。

$$q_0 = d^0 = 1, q_1 = d^1 = d, q_2 = d^2,$$
$$q_3 = d^3, q_4 = d^4, \dots$$
(2)

其中 $d$ 是任何大于 1 的整数。这个数字称为数字系统的基数。

这些系统包括以$d = 10$为基数的通用十进制、Vilis十六进制（$d = 60$）和双数系统（$d = 2$），最近随着计算机技术的需要而被广泛使用。在任意基数$d$的情况下，我们称之为“$d$元”数字系统。

在$d$进制数系统中，条目

$$N = \langle a_n a_{n-1} \dots a_2 a_1 a_0 \rangle$$

有以下含义：

$$N = a_n d^n + a_{n-1} d^{n-1} + \dots + a_2 d^2 + a_1 d + a_0.$$

显然，以$d$进制书写的数字中的每个数字只能采用$d$值：0、或1、或2、或3、...、或$d-1$。

特别是，如果 $d = 10$ ，因此数系的基础具有以下形式

$$q_0 = 1, q_1 = 10, q_2 = 100, q_3 = 1000, \dots$$

我们来到了常见的十进制数字系统（以单位计数，然后是十，然后是百，千，万等）；其中所有数字的取值不超过9。

所有 $d$ 进制数系中最简单的显然是有基的双数系

$$q_0 = 1, q_1 = 2, q_2 = 4,$$
$$q_3 = 8, q_4 = 16, \dots$$

这个数字系统只知道 0 和 1 这两个数字。下面是这个系统中前 15 个自然数的记录：

$$\begin{array}{c c c c c}
1 = 1 & 6 = 110 & 11 = 1011 \\
2 = 10 & 7 = 111 & 12 = 1100 \\
3 = 11 & 8 = 1000 & 13 = 1101 \\
4 = 100 & 9 = 1001 & 14 = 1110 \\
5 = 101 & 10 = 1010 & 15 = 1111.
\end{array}$$

当使用这个数字系统时，所有的计算都变得相当冗长，但又极其简单。如果我们一直使用这个特定的数字系统，那么小学生只需填写以下“乘法表”：

$$0 \cdot 0 = 0, 0 \cdot 1 = 1 \cdot 0 = 0, 1 \cdot 1 = 1$$

（还有“加法表”，与等式$1 + 1 = 10$相关，-毕竟数字“10”是常见的两个！）。二进制数系统在科学技术中有大量的应用；特别是，它是现代电子计算机器设计的基础*)。

数字系统
与其他基地

底数不是由等比级数 1、d、$d^2$、$d^3$、... 构成的数系没有相同类型的应用。但它们对于解决一些数学问题很有用。
让我们看一下这种数字系统的几个例子。

1°玛雅系统。上面我们已经讨论了玛雅数字系统，其基础具有以下形式
$$q_0 = 1, q_1 = 20, q_2 = 18q_1 (= 18 \cdot 20),$$
$$q_3 = 20q_2 (= 18 \cdot 20^2),$$
$$q_4 = 20q_3 (= 18 \cdot 20^3),$$

这个数字系统在所有方面都与两位数数字系统相似，仅在一个方面有所不同：它是任意数字的符号 $N = \langle a_n a_{n-1} \dots a_2 a_1 a_0 \rangle$ 中从末尾数起的第二个数字（我们习惯于水平放置，而不是像 Maya 那样从上到下放置）

$$a_1 < \frac{q_2}{q_1} = \frac{18 \cdot 20}{20} = 18,$$

而所有其他数字可以有 20 个值：0、1、2、...、19。

在数字系统中情况类似，其基础为 $q_{n+1}$ 除以 $q_n$ 毫无保留地为所有人 $n = 0, 1, 2, ...$:

$$q_0 = 1, q_1 = d_0, q_2 = d_1q_1 (= d_1d_0)$$
$$q_3 = d_2q_2, q_4 = d_3q_3, \dots,$$

其中 $d_0, d_1, d_2, d_3, ...$ 是任何大于 1 的正整数，不同或相同。在这样的数字系统中，数字被写成

$$N = \langle a_n a_{n-1} \dots a_2 a_1 a_0 \rangle$$

倒数第一个数字$a_0$可以取$d_0$值0, 1, 2, ..., $d_0 - 1$，下一个数字$a_1$可以取从0到$d_1 - 1$的$d_1$值，数字$a_2$可以取从0到$d_2 - 1$的值，等等。

此外，在以 (3) 为基数的数系中，以及在 d 进制数系中（我们的系统在 $d_0 = d_1 = d_2 = ... = d$ 的情况下是相反的），任何条目都是有意义的

$$N = \langle a_n a_{n-1} \dots a_2 a_1 a_0 \rangle,$$

其中$a_0, a_1, a_2, ..., a_n$是自然数以及$a_0 < d_0, a_1 < d_1, a_2 < d_2$等。事实上，在对数求逆时很容易检查到

$$N = a_n q_n + a_{n-1} q_{n-1} + \dots + a_2 q_2 + a_1 q_1 + a_0$$

在我们的数字系统中，使用“连续除法”的方法（见上文第 16 页）获得数字

$$a_n, a_{n-1}, a_{n-2}, \dots, a_1, a_0.$$

我们将以“数字系统”的一个程序为例来说明这种有利情况并不是一般规律。

2°“偶”数系统。以所有偶数（以及数字$q_0 = 1$）作为数系的基础：

$$q_0 = 1, q_1 = 2, q_2 = 4, q_3 = 6,$$
$$q_4 = 8, q_5 = 10, q_6 = 12, \dots$$

自从这里

$$\frac{q_1}{q_0} = q_1 = 2$$

和

$$\frac{q_{n+1}}{q_n} = \frac{2(n+1)}{2n} = \frac{n+1}{n} = 1 + \frac{1}{n} < 2$$

对于所有$n > 1$，那么这个数字系统就像double一样，只知道两个“数字”：0和1。条件是用红色指定这个“偶数”数字系统中写的数字。然后，非常印度，

$$2 = 10, 3 = 11, 4 = 100, 5 = 101,$$
$$6 = 1000, 7 = 1001, 8 = 10000,$$
$$9 = 10001$$等
