不久前，美国中西部的酒吧还被称为一种奇怪的游戏。事情是这样开始的。酒保把一个喝得醉醺醺的牛仔叫过来，把七枚一美元的硬币分成两堆——三美元和四美元——放在吧台上，并邀请那家伙赢：“如果你赌五个硬币，你就赢十二个。”牛仔数出了五枚硬币，把它们放在柜台上。这产生了第三堆硬币。游戏由玩家轮流从这些堆中取出硬币组成。您可以一次取走任意数量的硬币，但只能取一堆。拿走最后一枚硬币的人拿走了所有其他硬币。

DAT 立即涌向立管，竞相告诉牛仔他们认为应该拿走哪一堆硬币以及应该拿走多少枚硬币。您可以在玩三顶针时与我们创建类似的画面。只要“顶针”是施莱拉，他们的王牌就是花招，那么在“十二块钱”的游戏中，谁算得好谁就获胜。

让我们想象一下，一个必须迈出第一步的牛仔的思维过程：“我要拿一整堆。如果还剩下两块，会更容易玩。我应该拿哪一个？我要拿一小块，这样还剩下很多硬币。”

他拿了一堆三枚硬币。剩下两堆 - 4 和 5 个硬币。作为回应，调酒师从较大的一堆硬币中取出一枚硬币。你会得到两堆相同的硬币。牛仔从一堆硬币中取出一枚硬币，酒保从另一堆中取出一枚。牛仔从一堆硬币中取出两枚；酒保还从另一堆硬币中取出两枚硬币。每种口味还剩一枚硬币。牛仔唯一的选择就是拿走一枚硬币。酒保拿走了另一枚——最后一枚——并将所有剩余的硬币倒进柜台。

“我们再玩一次吧！” - 牛仔很兴奋，要求他再付五美元。

“随时为您服务，”酒保回答道，再次从他的 7 美元中取出分成两堆——3 美元和 4 美元。

“慢慢来，想一想，”他内心的声音告诉牛仔。 “好吧，”牛仔回答道，“上次我拿了一小堆，所以输了。如果我再拿一个怎么办？不行——调酒师会再次将另外两堆中的硬币平衡。让我从较大的一堆中拿一枚硬币。不！调酒师会再次排列两堆相等的硬币，拿一小堆。如果你拿两枚硬币怎么办？然后调酒师会拿走中间的一堆，然后又会出现两堆硬币数量相同的硬币。然后我拿一些硬币。”特勒，他将无法再做他该死的事情了！”牛仔动作自信，从一大堆硬币中取出三枚硬币，微笑地看着酒保。

他从中间的一堆硬币中取出三枚硬币，而 1、2 和 3 枚硬币则留在立管上。然后牛仔开始意识到他输了，因为无论他做什么，调酒师总是可以用相同数量的硬币形成两堆作为回应。牛仔低着头，在周围人的笑声中回到了自己的位置。对于这个家伙来说，一千年前中国圣贤就学会了玩这个游戏。

谁赢了：初学者还是他的伙伴？应该怎样玩才能获胜？事实证明，谁先走谁就赢了。为此，他必须从一小堆硬币中取出两枚硬币。任何其他举动都会失败。因此，共有三堆教育币 - 1、4 和 5 个硬币。 Teler，无论第二个玩家如何玩，从他的第二步开始，他要么可以形成两堆相同数量的硬币，要么可以形成三堆1、2和3的硬币。这里第二个玩家已经可以投降了。

所以，我们学会了玩“他”——这就是哈佛教授所说的这个游戏。

事实证明，在这里书写数字非常方便，不是用我们通常使用的十进制数字系统，而是用双数字系统，第一台计算机的创建者非常依赖双数字系统的简单性。

Let us recall that if in the decimal system any natural number is represented as $N = a_n 10^n + a_{n-1} 10^{n-1} + \dots + a_1 10^1 + a_0$, where $a_0, a_1, \dots, a_n$ are integers from 0 to 9, then in the double number system it is represented as $N = b_m 2^m + b_{m-1} 2^{m-1} + \dots + b_1 2^1 + b_0$.例如，$1991 = 1 \cdot 10^3 + 9 \cdot 10^2 + 9 \cdot 10^1 + 1 \cdot 10^0 = 1 \cdot 2^{10} + 1 \cdot 2^9 + 1 \cdot 2^8 + 1 \cdot 2^7 + 1 \cdot 2^6 + 0 \cdot 2^5 + 0 \cdot 2^4 + 0 \cdot 2^3 + 1 \cdot 2^2 + 1 \cdot 2^1 + 1 \times 2^5 = 111110001112$。 Index 2 indicates that this number is written in the double number system.

Let's try to add another number to them so that in each double digit the sum is even, i.e., the resulting system becomes correct.很容易看出，这可以用唯一的方法来完成：如果总和是奇数，我们在这个数字的数字上放 1，如果和是偶数，我们在这个数字的数字上放 0。 In this case, we should assign the number 1110000. Therefore, if we had a correct set of numbers, then when we replace one (exactly one!) number with another, the set will change to be correct. On the contrary, if a set of numbers is not correct, then it is not difficult to replace one of the numbers with a smaller one so that the resulting set is already correct.

我们来总结一下。 If the original set of numbers indicating the corresponding pile of stones is correct, then the player who takes the stones second will win, and if this set is not correct, then the beginner will win.在他的第一次和随后的每一次行动中，他都会从一堆石头中取出一定数量的石头，从而保留正确的一组。 Since the number of stones is always killing, and his partner always leaves him at least one stone, the beginner will win.
