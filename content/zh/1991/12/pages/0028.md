奥列夫科夫

图 3.

M1258。将 $n > 3$ 数字排列成圆圈，您可以执行以下操作：将连续数字 $x, y, z$ 的三连数替换为三连数 $x + y, -y, z + y$（完全按照该顺序）。

a) 使用这样的运算，是否可以从 20 个数字 1, 2, 3, ..., 9, 10, -1, -2, -3, ..., -9, -10 中获得集合 10, 9, ..., 3, 2, 1, -10, -9, ..., -3, -2, -1？

b) 证明对于圆上任意一组和为正的$n$数，可以得到一组且仅有一组$n$非负数。

我们假设数字 $a_1, a_2, ..., a_{n-1}, a_n$ 包含在一个循环中：

$$a_{n+1} = a_1, a_{n+2} = a_2, ...$$

请注意，条件中指定的转换在重复时（在同一位置）将返回到原始序列。这表明其背后隐藏着两个数字的某种排列 - 我们现在将看到情况确实如此。

考虑部分和的序列 $B$：

$$b_1 = c + a_1,$$
$$b_2 = c + a_1 + a_2,$$
$$b_3 = c + a_1 + a_2 + a_3,$$
$$b_3 = c + a_1 + a_2 + a_3,$$
$$b_n = c + a_1 + a_2 + ... + a_{n-1} + a_n,$$
$$b_{n+1} = c + a_1 + a_2 + ... + a_{n-1} + a_n + a_{n+1},$$

让我们看看这些数字如何随着指示的替换而变化。 （这里$c$是一个任意选择的常数，不起作用：我们不区分两个在$c$的选择上不同的序列 - 只有$b_k - b_{k-1} = a_k$的差异对我们来说很重要。）如果$x = a_{k-1}, y = a_k, z = a_{k+1}$更改为$x + y, -y, z + y$，则$b_{k-2} = d, b_{k-1} = d + x, b_k = d + x + y, b_{k+1} = d + x + y + z$（其中$d$是非负常数）更改为

$$d, d + x + y, d + x, d + x + y + z.$$

我们看到，在这种情况下，$b_k$和$b_{k-1}$只是改变了位置，其余的$b_i$没有改变。让我们考虑两种情况。

1) $a_1 + a_2 + ... + a_n$ 之和为 0（如 $a$ 的情况））。这里，数字$b_k$周期性地重复：$b_{n+1} = b_1, b_{n+2} = b_2$，并且继续$B$部分和的序列，我们得到对于任何整数$i$的$b_{i+n} = b_i$。因此，我们可以假设数字 $b_k$ 被写在一个圆圈中，并在预条件中表示出来。
