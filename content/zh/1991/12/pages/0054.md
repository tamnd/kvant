查尔斯·布顿大学。好吧，如果我们不是放 3、4 和 5 个硬币，而是放 3、4 和 6 个硬币，那么这次谁会赢：初学者还是第二步的人？毕竟，我们已经知道，如果一堆硬币中有 1、2 和 3 个，或者有 1、4 和 5 个硬币，那么第二个获胜。如果我们增加堆的数量怎么办？章。布顿在 1901 年出版的著作中回答了所有这些问题。

事实证明，在这里书写数字非常方便，不是用我们通常使用的十进制数字系统，而是用双数字系统，第一台计算机的创建者非常依赖双数字系统的简单性。

Let us recall that if in the decimal system any natural number is represented as $N = a_n 10^n + a_{n-1} 10^{n-1} + \dots + a_1 10^1 + a_0$, where $a_0, a_1, \dots, a_n$ are integers from 0 to 9, then in the double number system it is represented as $N = b_m 2^m + b_{m-1} 2^{m-1} + \dots + b_1 2^1 + b_0$.例如，$1991 = 1 \cdot 10^3 + 9 \cdot 10^2 + 9 \cdot 10^1 + 1 \cdot 10^0 = 1 \cdot 2^{10} + 1 \cdot 2^9 + 1 \cdot 2^8 + 1 \cdot 2^7 + 1 \cdot 2^6 + 0 \cdot 2^5 + 0 \cdot 2^4 + 0 \cdot 2^3 + 1 \cdot 2^2 + 1 \cdot 2^1 + 1 \times 2^5 = 111110001112$。索引2表示该数字是用双数系统书写的。

由于拥有无限数量的1zol币是相当困难的，所以未来我们将与石头中的币一起运营。章。 Bouton discovered an amazing pattern: let’s write numbers under each other in a column, expressing the number of pebbles in each pile in the double number system. If each digit contains an even number of units (we will call such a set of numbers correct), then in this case, if the game is played correctly, the one who goes second will win.否则，初学者就赢了。

验证这一点的正确性并不困难。让我们在双系统中写几个数字，一个在另一个下面，例如，

1010101
111001
11001
101

让我们尝试向它们添加另一个数字，以便每个两位数的总和都是偶数，即所得系统变得正确。很容易看出，这可以用唯一的方法来完成：如果总和是奇数，我们在这个数字的数字上放 1，如果和是偶数，我们在这个数字的数字上放 0。 In this case, we should assign the number 1110000. Therefore, if we had a correct set of numbers, then when we replace one (exactly one!) number with another, the set will change to be correct. On the contrary, if a set of numbers is not correct, then it is not difficult to replace one of the numbers with a smaller one so that the resulting set is already correct.

仍然需要注意的是，一组零是规则的，并且一组不规则的零至少包含一个零数。

我们来总结一下。如果指示相应石子堆的原始数字组正确，则第二个拿走石子的玩家获胜，如果这组数字不正确，则初学者获胜。在他的第一次和随后的每一次行动中，他都会从一堆石头中取出一定数量的石头，从而保留正确的一组。由于石子的数量总是致命的，而他的伙伴总是给他留下至少一颗石子，所以初学者将获胜。
