几乎与我们开始对话时使用的坐标方法相同：方程 y = x 将定义一条直线，不等式 y < x 和 y > x 将定义一个半平面。

练习 10. 让 x 和 y 表示到两条相交线的定向距离。证明任何线性方程定义直线，线性不等式定义半平面。

现在让我们再次进入三维空间。让我们考虑一个二面角，对于位于其内部的点，我们将使用 x 和 y 来表示到其面所在平面的距离。那么等式 y = x 定义了一个平分平面。对于三面角，可以在成对的面之间绘制三个平分面，这会将其分为六个区域（三面角），每个区域都由变量 x、y、z 的顺序指定，其中 x、y、z 是从三面角内的点到其面平面的距离。

练习 11：证明平分面将三面角正好分成六个区域。

让我们取一个平面角都等于$90^\circ$的三面角，并考虑与之相关的笛卡尔坐标系（以便三面角与第一个八分圆重合）。然后，二面角的平分面由方程 x = y、y = z、z = x 给出。他们将我们的三面角（第一个八分圆）分为六个区域（三面角），这些区域通过熟悉的不等式 x < y < z、x < z < y、y < x < z、y < z < < x、z < x < y、z < y < x 给出坐标。由于变量相等，这些面积是相等的数字。让我们从第一个八分圆切下一个单位立方体（其坐标由不等式 $0 \le x \le 1, 0 \le y \le 1, 0 \le z \le 1$ 给出）。平面 x = y, y = z, z = x 将我们的立方体分成六个相等的图形（相等 - 再次由于变量相等）。这些图形是相等的四面体。所以，我们已经将立方体漂亮地划分为六个相等的四面体。如果你沿着立方体大对角线的方向看，那么看起来就像在 图 11 中，平面 x = y、y = z、z = x 用红色虚线显示。

到任意集合的距离

在文章的第一部分中，我们讨论了到点的距离，在第二部分中，我们讨论了到线和平面的距离。更一般的说法：设 X, Y, ... 为任意集合，x, y, ... 分别为从任意点到集合 X, Y, ... 的距离。这里，从点 M 到集合 X 的距离是指距离 MN 的 $минимум^{2}$，其中 $N \in X$。如果 X 和 Y 不是平面上非常奇特的图形，那么作为方程 y = x 的一组解，我们通常会得到一条或多条曲线，并且不等式 y > x 和 y < x 的解是曲线将平面划分成的区域 (图12)。集合 y > x 和 y < x 可以称为广义 Voronoi 区域，或者按照 N. Dolbilin 的上述文章，集合 X 和 Y 的“影响区域”。A. Savin 给出了一个值得注意的解释（参见 图 12 “万花筒 «Kvant» No. 4 for 1994）：令 X 和 Y 为两个国家的领土，整个陆地面积分布在这两个国家之间（因此，不属于X国或Y国的一切都是海洋），X国和Y国之间的海洋边界需要公平划定。
