M2424。平面上有几条线有一个公共点 O。证明每条线都可以涂成红色或蓝色，使得平面上有一个与 O 不同的点，到所有红线的距离之和等于从它到所有蓝线的距离之和。

对于每条直线，它将平面划分成的两个半平面之一称为正，另一个称为负。让我们将点到直线的定向距离定义为带有加号或减号的距离，具体取决于该点是在正半平面还是负半平面。对于每个点 X，我们将 f(X) 定义为从点 X 到所有直线的定向距离之和。如果X和Y是关于O对称的两点，那么显然$f ( X ) = - f ( Y )$。让我们沿着以 O 为圆心的半圆从 X 点到 Y。由于函数 f 的连续性，半圆上有一个点 Z，其中 f ( Z ) = 0。如果我们将 Z 位于正半平面中的所有线涂成红色，将所有其余线涂成蓝色，则 Z 点将是所需的点。事实上，f ( X ) 是一个线性函数（对于任意位置的给定直线也是如此）。因此，如果至少有一点f为0，则存在一条整条直线，其所有点都具有这一性质。让我们提出另一种解决方案，其中明确指示所需的点（参见图）。让我们画一个有圆心的圆

对于每条线，标记与圆的两个交点之一。我们将这些点表示为$A_{1}, A_{2}$，…$, A_{n}$。让我们将单位点质量放置在点 $A_{i}$ 处，并让 M 表示该系统的质心。设一条直线 l 通过点 O 和 M（如果 M 与 O 重合，则 l 是穿过 O 的任意直线）。直线l将点质量集合分为两个子集；假设在线 l 的一侧有点 $A_{1}$、…$, A_{k}$，另一侧有点 $A_{k} +_{1}$、…$, A_{n}$。质量系统相对于直线 l 的力矩等于 0，因此（考虑到质量相等），点 $A_{1}$、… $, A_{k}$ 到直线 l 的距离之和等于点 $A_{k} +_{1}$、… $, A_{n}$ 到同一条直线的距离之和。令 N 为直线 l 与圆的交点。显然，$A_{i}$到直线l的距离等于N到直线$OA_{i}$的距离。然后将直线 $OA_{1}$, … $, OA_{k}$ 涂成红色，将直线 $OA_{k} +_{1}$, … $, OA_{n}$ – 涂成蓝色就足够了：从点 N 到红线的距离之和将等于从 N 到蓝线的距离之和。总之，我们将对第二个解决方案的绘图给出另一种机械解释。让我们想象一下，我们的圆是一个具有固定轴（O）的失重轮，它可以在垂直平面内自由旋转。分段 $OA_{i}$ 是车轮的失重辐条，其末端有单位质量。质量块受到垂直向下的重力作用。容易看出，点$A_{i}$到过O的垂线的距离与相对于旋转轴的力矩成正比。因此，问题的陈述与静态平衡位置的存在有关。 I.
