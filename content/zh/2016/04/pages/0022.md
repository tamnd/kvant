足球锦标赛和算术级数

2012年，在第25届莫斯科数学奥林匹克竞赛上，提出了以下问题。 75支球队参加了一轮足球锦标赛（胜3分，平1分，负0分）。如果没有两支球队积分相同，那么第一支球队和最后一支球队之间的最小积分差距是多少？由于相邻球队之间的最小差距是一分，显然第一队和最后一支球队之间的差距不能低于74分。然而，很难理解这个估计是否可以实现。为了找到答案，我们很自然地要从参加人数较少的锦标赛开始。参加过所有有 2 或 3 名参赛者的锦标赛后，很容易确定您要寻找的锦标赛不在其中。但为 4 支球队举办这样的锦标赛是可能的（表 1）。

对于命令数n的接下来的几个值的尝试也是成功的。因此，假设所有 n > 3 都存在相应的锦标赛。事实确实如此；更准确地说，以下陈述是正确的。对于任何 $n \ge 4$ ，都有 n 支球队参加的循环赛，其中球队得分 n – 2, n – 1, n, …, 2n – 3 分。我们用归纳法来证明一下。对于 n = 4，我们已经建立了所需的锦标赛。假设我们有 n 支球队参加的锦标赛，我们将展示如何向其中添加一支新球队。让我们按照分数降序对旧队进行排序，让新队对第一队获胜，对第二和第三队输球，对第四队获胜，对第五和第六队输，依此类推（周期为3），直到剩下一队、两队或三队比赛（取决于n除以3的余数）。在第一种情况下，新球队与最后一支球队打平。第二局与倒数第二队打平，输给倒数第三队，第三局与倒数第二队打平，输给倒数第三队，赢倒数第三队。通过直接计算，我们确信在所有三种情况下我们都得到了我们需要的点的分布。

各队自然得分 d 的差值 d 可以构成等差级数？为了完整起见，我们可以让 d 为 0，在这种情况下，所需的锦标赛显然存在（例如，如果所有比赛都以平局结束）。对于所有 n，情况 d = 3 是可能的（如果第一支球队战胜了所有人，第二支球队战胜了除第一支球队之外的所有人，等等）。同样清楚的是，差异不能大于 3（为什么？）。因此，我们接下来剩下的就是研究 d = 2 的情况。让我们从 n 的较小值重新开始。对于 n = 2 和 n = 3，不需要比赛，对于 n = 4，则需要比赛（表 2）。

但当 n = 5 时，不可能建立锦标赛。让我们证明这确实是不可能的。如果得分形成差为 2 的等差数列，则得分之和除以 5。由于五队比赛的总比赛数为 10 场，如果其中一支球队所有比赛均获胜，则得分之和为 30，并且每次平局将得分之和减 1。因此，0、5 或 10 场比赛必须以平局结束。如果没有平局，那么每支球队的积分都是3的倍数，不可能相差2分，而如果有10场平局，所有球队都得4分。考虑 5 次平局的情况。那么总分是25分，即球队必须得9分、7分、5分、3分和1分。但四场比赛拿到9分、7分、5分、1分只有一种方法：分别是三胜一负；两胜一平一负；一胜二平一负；一场平局，三场失利。由于总胜场数必须等于总负场数，因此剩下的球队必须胜负相等，而3分是不可能的。继续考虑较小的 n 值，我们确信，对于 n = 6、n = 7 和 n = 8，存在所需的锦标赛（表 3、4、5）。
