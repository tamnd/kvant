Szemeredi-Trotter 定理通常表述如下：平面上有 n 个点的集合 P，平面上有 m 个线的集合 L。让我们定义关联数 I ( P, L ) – 对 ( p, l ) 的数量，其中 p 是来自 P 的点，l 是来自 L 和 $p \in l$ 的直线。然后$I ( P, L )^{Щ} m^{2} 3 n^{2} 3 + m + n$。证明文中给出的表述确实是该陈述的直接结果。 7. 自己证明 $I ( P, L ) \le n + m^{2}$ 在上一个问题的表示法中。 8. 令 $f = f ( x, y ) = \sum_{i},_{j} a_{ij} x^{i} y^{j}$ 为两个变量的多项式。它的次数是单项式 $x^{i} y^{j}$ 的最大次数，其系数非零（单项式的次数就是 i + j）。让我们用 Z ( f ) = { ( x, y ) f ( x, y ) = 0 } 表示 – f 等于 0 的平面点的集合。这样的集合称为代数曲线（想想你知道的代数曲线的例子）。证明如果 f 的度不超过某个 D，则任何直线 l 要么完全包含在集合 Z(f) 中，要么与该集合最多有 D 个点相交。这是一个揭示集合的组合结构和代数结构之间联系的语句示例。 9. 使用上一个问题的表示法，证明如果 f 不为零，Z(f) 最多包含 D 条不同的线。
