奥运会

第四十二届全俄小学生数学奥林匹克竞赛地区赛段

第42届全俄数学奥林匹克地区赛于2016年2月5日至6日举行。根据比赛结果，全俄数学奥林匹克决赛阶段的参赛人员构成已经形成，因此地区赛的选项中包含了相当复杂的任务。 10年级和11年级的第8题是最难的。

任务

九年级

第一天

1. 给出二次三项式 $f_{1} ( x ), f_{2} ( x )$, … $, f_{100} ( x )$，$x^{2}$ 具有相同的系数，x 具有相同的系数，但自由项不同；它们每个都有两个根。对于每个三项式$f_{i} ( x )$，我们选择一个根并将其指定为$x_{i}$。总和$f_{2} ( x_{1} ) + f_{3} ( x_{2} ) + …^{…} + f 100 ( x 99 ) + f 1 ( x 100 )$可以取什么值？ N·阿加哈诺夫

2. 给定一个等腰三角形 ABC，AB = BC。在三角形ABC外接圆Ω中，画出直径$CC '$。通过点 $C '$ 与 BC 平行的直线分别与线段 AB 和 AC 相交于点 M 和 P。证明M是线段$C ' P$的中点。奥布霍夫

3. Petya 选择了几个连续的自然数，并用红色或蓝色铅笔（两种颜色都有）写下每个数字。所有红色数字的最小公倍数和所有蓝色数字的最小公倍数之和可以是 2 的幂吗？ O.德米特里耶夫、R.热诺达罗夫

4. 希罗国王有 11 块金属锭，肉眼无法区分；国王知道它们的质量（按某种顺序）是 1, 2, ..., 11 公斤。他还有一个袋子，如果你放入的重量超过 11 公斤，就会撕裂。阿基米德找出了所有锭的质量，并想向希罗证明第一个锭的质量为 1 公斤。他可以一步将几块金锭装入袋子中，并向 Hieron 证明袋子没有撕裂（你不能撕裂袋子！）。阿基米德最少对袋子加载多少次才能达到要求的结果？ I. 博格丹诺夫、K. 诺普

第二天

5. 班里有23名学生。这一年里，这个班的每个学生都庆祝了一次自己的生日，有一些（至少一个，但不是全部）同学参加。难道这个班的每两个学生都是在这样的庆祝活动中单独见面的吗？

⟦column⟧

有多少次？ （认为​​任何两个客人在每个假期会面，并且生日人会见了所有客人。） I. Bogdanov

6. 让我们称由自然数组成的非空（有限或无限）集合 A 为完备集，如果对于任何自然数 a 和 b（不一定不同且不一定位于 A 中），使得 a + b 位于 A 中，数字 ab 也位于 A 中。找到所有完整的自然数集。 N·阿加哈诺夫

7. 在白色表格$2016 \times 2016$中，一些单元格被涂成黑色。让我们称自然数 k 为幸运，如果 $k \le 2016$ 并且在表中每个边长为 k 的方格中恰好有 k 个着色的单元格。 （例如，如果所有格子都是黑色，那么只有数字 1 是幸运的。） 最多可以有多少个数字是幸运的？ E·巴卡耶夫

8. 给定一个凸四边形 ABCD，其中 $\angle$ DAB $= 90 ^\circ$。设 M 为 BC 边的中点。原来是$\angle$ ADC $= \angle$ BAM。证明$\angle$ ADB $= \angle$ CAM。 E·巴卡耶夫

10年级

第一天

1. 请参阅九年级的问题 1。

2. Petya 选择了 10 个连续的自然数，并用红色或蓝色铅笔（两种颜色都有）写下每个数字。所有红色数字的最小公倍数和所有蓝色数字的最小公倍数之和能否在 2016 年结束？ O.德米特里耶夫、R.热诺达罗夫

3. 在凸四边形ABCD的边AB上取点K和L（点K位于A和L之间），在边CD上取点M和N（点M在C和N之间）。已知 AK = KN = DN 且 BL = BC = CM。证明如果BCNK是内接四边形，则ADML也是内接四边形。 T.齐马诺夫、P.科热夫尼科夫

4. 给定一个方格表$100 \times 100$，其单元格被漆成黑色和白色。此外，所有列具有相同数量的黑色单元，而所有行具有不同数量的黑色单元。相邻彩色单元格对的最大可能数量是多少？伊·波格丹诺夫
