关于一项被遗忘的任务

A.托皮戈

有时也会发生这种情况：你正在努力解决某个问题，但它没有解决，然后你想出了一些新的、非常狡猾的方法来解决它。试想一下，它不再适合你了！这种看似完全无用的工作，往往会带来意想不到的好处……

首先，让我们提出两个问题。问题A. 证明从任意n 个整数中，您可以选择几个总和可被n 整除的整数。问题 B. 证明您可以从任意 (2n – 1) 个整数中选择 n 个其总和可被 n 整除的数字。问题 A 是众所周知的，可以使用狄利克雷原理来解决（“如果将（n + 1）只兔子放入 n 个单元中，则至少一个单元将包含至少两只兔子”）。也就是说，我们需要考虑数字$S_{0} = 0, S_{1} = a_{1}, S_{2} = a_{1} + a_{2}, S_{3} = a_{1} + a_{2} + a_{3}$，…，$S_{n} = a_{1} +^{…} + a_{n}$。这些“兔子”需要坐的“单元”的作用是由数字除以​​ n 得到的余数来扮演的。根据狄利克雷原理，其中两只“兔子”最终会被关在同一个“笼子”中，即除以 n 时得到相同的余数。因此，将它们的差除以n，这就是所要求的。相反，问题 B（曾经在 1970 年的期刊«Kvant» 上发表过，编号为M45）现在已被不应地遗忘。同时，不仅有一个精彩的数学事实，而且还有许多围绕其解决方案的美丽想法。确实，正如稍后将看到的，其中一些可以提供证据，而另一些则不能。然而，两者都是有用的：如果其中一些不足以解决这个问题，它们下次会派上用场。下面讨论的是问题B。但首先，让我们考虑几个类似类型的问题。

1. 还有两个任务
