数学圈

关于一项被遗忘的任务

A.托皮戈

有时也会发生这种情况：你正在努力解决某个问题，但它没有解决，然后你想出了一些新的、非常狡猾的方法来解决它。试想一下，它不再适合你了！这种看似完全无用的工作，往往会带来意想不到的好处……

S·博布罗夫。魔法双角兽

首先，让我们提出两个问题。问题A. 证明从任意n 个整数中，您可以选择几个总和可被n 整除的整数。问题 B. 证明您可以从任意 (2n – 1) 个整数中选择 n 个其总和可被 n 整除的数字。问题 A 是众所周知的，可以使用狄利克雷原理来解决（“如果将（n + 1）只兔子放入 n 个单元中，则至少一个单元将包含至少两只兔子”）。也就是说，我们需要考虑数字$S_{0} = 0, S_{1} = a_{1}, S_{2} = a_{1} + a_{2}, S_{3} = a_{1} + a_{2} + a_{3}$，…，$S_{n} = a_{1} +^{…} + a_{n}$。这些“兔子”需要坐的“单元”的作用是由数字除以​​ n 得到的余数来扮演的。根据狄利克雷原理，其中两只“兔子”最终会被关在同一个“笼子”中，即除以 n 时得到相同的余数。因此，将它们的差除以n，这就是所要求的。相反，问题 B（曾经在 1970 年的期刊«Kvant» 上发表过，编号为M45）现在已被不应地遗忘。同时，不仅有一个精彩的数学事实，而且还有许多围绕其解决方案的美丽想法。确实，正如稍后将看到的，其中一些可以提供证据，而另一些则不能。然而，两者都是有用的：如果其中一些不足以解决这个问题，它们下次会派上用场。下面讨论的是问题B。但首先，让我们考虑几个类似类型的问题。

1. 还有两个任务

问题 C. 给定 N – 1 个自然数 $a_{1},^{…}, a_{N} -_{1}$。它们都大于零且小于 N。已知，如果选择任意 k、0 < k < N，并且从该集合中选择任意 k 个数字，则它们的和不能被 N 整除。证明该集合中的所有数字都彼此相等。问题 D. 给定 100 个数字，每个数字都大于 0 且小于 94。证明可以从中选择几个数字，其总和除以 101 余数为 95。问题 C 的解决方案。假设 $a_{1} \ne a_{2}$。考虑总和 $S_{0} = a_{1}, S_{1} = a_{2}, S_{2} = a_{1} + a_{2}, S_{3} = a_{1} + a_{2} + a_{3},...$

…，$S_{N} -_{1} = a_{1} + a_{2} +$…$+ a_{N} -_{1}$。 （前两项和等于前两项，其余为从第一项到对应项的和）。假设这些和除以 N 时都没有余数为 0。因此，其中两个的余数相同，而且不是第一个和第二个。但随后将两个相应和的差除以 N，这与条件相矛盾。问题D的解决方案。让我们立即承认，我们将自己限制在数字101，部分是为了使公式更容易，部分是为了稍微“搅浑水”并稍微掩盖这个想法。事实上，在相当普遍的情况下，事实也是如此。也就是说，我们将数字 101 替换为任何素数 p，将数字 95 替换为 0 到 p 之间的任何数字，并证明从除以 p 时给出非零余数的 (p – 1) 个数字中，我们可以得出一个总和，该总和在除以 p 时给出任何预定的非零余数。让我们以任意方式排列这些数字。让我们选择任意 $k, 0 \le k \le ( p - 1 )$，并取前 k 个数字。让我们从它们中得出所有可能的和（一个数字或没有一个数字也是和；假设一组空数字的总和等于 0），并写下这些和除以 p 得到的所有不同的余数。特别是，在第一步（如果 k = 0）有一个和，并且它等于 0。对于任意 k，我们获得一些数字 $M_{1}$，… $, M_{n}$。如果其中已经有所有可能的遗迹，那么就没有什么可以证明的了。但愿事情不要这样。让我们添加到已经选择的 (k + 1) 数字（让它等于 r），并再次记下所有总和和所有余数。结果首先是数字 $M_{1}$, … $, M_{n}$（毕竟最后一个数字可能取不到），其次是数字 $M_{1} + r$, … $, M_{n} + r$ 除以 p 的余数。现在我们声称第二组中至少有一个数字没有出现在第一组中。事实上，我们假设相反。那么事实证明，如果余数 N 与 $M_{i}$ 之一重合，则余数 N + r 也与集合 ${ M_{i} }$ 中的某个其他数字重合。但余数 N + 2r = (N + r) + r 也与集合 ${ M_{i} }$ 中的其他数字一致，N + + 3r = (N + 2r) + r 也是如此，依此类推。从这里很容易得出，在 ${ M_{i} }$ 中，除以 p 的所有可能的余数都已经出现，并且我们假设情况并非如此。 因此，直到没有写出所有余数，不同数字的数量在每一步都会增加。由于步骤数等于 p，因此最迟在最后一步，不同残基的数量将至少为 p，这是必需的。由于第一步中出现了零和（根本没有数字），因此不能保证能够获得余数为 0 的和。事实上，如果我们使所有数字彼此相等，那么余数 0 就无法计算出来（根据问题 C，这是余数无法计算的唯一情况）。所有其他金额均以一种或另一种方式获得。

2. 问题 B：合数

现在让我们回到问题 B。为了方便起见，我们将其语句表示为 BC(n)（“和的选择”）；因此，符号 BC(21) 是“确实，从任意 41 个整数中我们可以选择 21 个其总和可被 21 整除的 21”这一陈述的缩写。
