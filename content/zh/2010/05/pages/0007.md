R是反转圆的半径（因此特殊圆将在D点和E点与反转粗圆成直角相交）。利用特殊圆 c 的割线 $OA^{∗} A$ 定理，我们可以找到 $OA^{∗} \cdot OA = OD^{2} = R^{2}$。

⟦figure⟧

图11。反转圆C穿过反转（粗体）圆的中心O

对于 A = D 的情况，我们找到 $OB \cdot OB^{∗} = R^{2}$。这证明了圆C反转后的图像与直线$C^{∗}$（连接圆C与反转圆的两个交点）重合。圆 C 太小而无法与反转圆相交的情况简化为膨胀情况（与中心 O 齐平）。当圆C进行这样的拟似，拉伸$\alpha$倍时，其反转时的图像也与圆心O进行拟似，即压缩a倍。因此，压缩后的图像是一条直线，这意味着即使在压缩之前，图像也是一条直线（只是不与反转圆相交）。当圆 c 在其所包围的圆中不包含反转中心 O (图12) 时，关于不通过反转中心的圆 c 的图像的定理特别容易证明。

⟦figure⟧

图12。不围绕反转中心 O 的圆 c 的反转

在这种情况下，可以从O点画两条切线到圆c。它们的长度相同：OD = = OE。通过与中心 O 相似地拉伸（或压缩）平面，我们可以将圆 c 变成一个相似的特殊圆，其切线长度 OD = OE = R 与长度重合

这个恒等式意味着特殊圆c的点A和$A^{∗}$在我们的反演过程中相互变换，使得特殊圆的图像与其自身重合。通过压缩特殊圆回到原始圆，我们看到这个压缩（原始）圆在反演过程中的图像是由特殊圆通过位似拉伸得到的。这意味着这个图像$c^{∗}$也是一个圆。当圆c围绕圆心O时，该定理也成立。但我不知道这么简单的证明。评论。特殊圆与$инвертирующей.^{4}$正交，在反转过程中，它们各自变成自身。因此，它们之间的角度在反转过程中得以保留。事实证明，反演变换还保留了任意两条曲线之间的角度（直到符号）。例如，从图13可以看出，其中穿过反转中心O的圆C与反转圆相交于点D（并且在反转期间成为直线DE）。
