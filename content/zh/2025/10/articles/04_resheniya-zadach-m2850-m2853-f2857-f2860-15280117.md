M2853。是否存在具有实数系数和旧系数 1 的非常数多项式 $P(x), Q(x), R(x)$ 并且每个多项式
$$P(Q(x)), Q(R(x)), R(P(x))$$
我们至少有一个实根，但没有多项式
$$Q(P(x)), R(Q(x)), P(R(x))$$
没有真正的根源？

答：不存在。
假设相反，并令多项式 $P, Q, R$ 也存在。
1) 设$x_0$为多项式$P(Q)$的根；那么$P(Q(x_0)) = 0$，这意味着$Q(x_0)$是多项式$P$的根。我们看到$P$有根，设$\alpha$为其最大根。
类似地，我们证明$Q$和$R$有根；让我们分别用 $\beta$ 和 $\gamma$ 表示它们的最大根。
2) 考虑方程 $P(x) = \beta$。如果它有根，那么这个根就是方程 $Q(P(x)) = 0$ 的根，根据条件，该方程无根。我们看到$\beta$不包含在多项式$P$的值集中。特别是，它截断了 $P$ 具有偶数次（因为奇数次多项式的值集是 $\mathbb{R}$）。所以，$P$是一个偶次多项式，首项系数为1，这意味着它的值集是$[a; +\infty)$形式的射线。此外，从上面可以得出$\beta < a$。按照$Q$和$R$的类似论证，我们知道它们的值的集合分别是光线$[b; +\infty)$和$[c; +\infty)$。此外，$\gamma < b$和$\alpha < c$。
3) 让我们回到$x_0$——多项式$P(Q)$的某个根。那么$Q(x_0)$就是多项式$P$的根。因此$Q(x_0) \leq \alpha$（因为$\alpha$是$P$的最大根）。另一方面，$Q(x_0)$属于集合$Q$，所以$Q(x_0) \geq b$。因此，$b \leq \alpha$。同样，$c \leq \beta$和$a \leq \gamma$。所以我们得到了
$$\beta < a \leq \gamma < b \leq \alpha < c \leq \beta.$$
因此$\beta < \beta$是一个矛盾。

F2858。两颗相同的小行星，质量为$m$，直径为$D$，彼此相距较远，并且沿平行直线具有相反方向的速度$v_0$，两颗小行星之间的距离为$d > D$。在什么最小值 $v_0$ 时小行星不会相撞？

利用能量守恒定律，我们将系统初始时刻的能量等同于最大压缩时刻的能量：
$$mv_0^2 = mv^2 - \frac{Gm^2}{\rho},$$
其中 $\rho$ 是小行星之间的最小距离。
由于相互作用力是中心的，因此每个小行星在运动过程中角动量是守恒的。请注意，每个小行星的速度垂直于从系统质心绘制的半径矢量，相对于该半径矢量，每个小行星的初始角动量等于
$$L = mv_0 \frac{d}{2}.$$
波兹尼 根据角动量守恒定律，
$$mv_0 \frac{d}{2} = mv \frac{\rho}{2},$$ 或 $\frac{v}{v_0} = \frac{d}{\rho}$。
将这个关系代入能量守恒定律，我们得到
$$v_0^2 \left(\frac{d^2}{\rho^2} - 1\right) = \frac{Gm}{\rho}.$$
从这里我们找到小行星之间的最小距离：
$$\rho = \frac{d}{\frac{Gm}{2dv_0^2} + \sqrt{\left(\frac{Gm}{2dv_0^2}\right)^2 + 1}} \ge D.$$
以最小的速度，这种关系变成平等
$$\frac{Gm}{2dv_0^2} + \sqrt{\left(\frac{Gm}{2dv_0^2}\right)^2 + 1} = \frac{d}{D},$$
在哪里
$$\left(\frac{d}{D}\right)^2 - 2 \frac{Gm}{2dv_0^2} \frac{d}{D} = 1.$$
最后我们得到
$$v_0 \min = \sqrt{\frac{GmD}{d^2 - D^2}}.$$
