乍一看，最好的办法似乎是将所有的水倒入一杯浓茶中。然而，只有当一个杯子中的茶浓度是另一个杯子中的茶浓度的四倍以上时，这种情况才成立。例如，如果初始浓度为 80% 和 25%，那么将所有水倒入第一个玻璃杯中，我们将得到 40% 的浓度，如果我们将水按大约 0.924:0.076 的比例分配在玻璃杯之间，则杯子中茶的浓度将增加到 40.2%。

问题解决

首先，我们来看看杯子里茶的浓度。我们将玻璃杯中液体的体积设为1，将倒入第$i$个玻璃杯中的水的体积记为$x_i$。然后，倒出后，玻璃杯中液体的体积将变为$1 + x_i$，因此茶的浓度将降低至$a_i / (1 + x_i)$。因此，从这个玻璃杯倒回杯子中的$x_i$液体量将含有$g_i(x_i) = a_i x_i / (1 + x_i)$茶，而杯子中承诺的茶浓度将是$g_1(x_1) + \ldots + g_n(x_n)$。因此，我们需要针对满足条件的$x_1, \ldots, x_n$的值找到函数$g_1(x_1) + \ldots + g_n(x_n)$的最大值
$$x_i \geq 0, x_1 + \ldots + x_n = 1.$$
检查了函数 $g_i(x_i)$ 的图形（参见 图），很容易看出这个函数是递增的，但它的导数 $g_i'(x_i) = a_j / (1 + x_i)^2$ 却很致命。最后一个属性意味着函数 $g_i$ 是可能的，因此它们的和将是凹函数。

我们不会给出凹函数的严格定义。我们只补充一点，几何凹性意味着连接函数图形上任意两点的线段位于图形下方。对于多个变量的凹函数也是如此。

凹函数具有以下重要性质。

**定理。** 在 Vi凸上定义的凹函数，由约束设置的闭合（即包含其边界）在单个点处达到其最大值。

就我们的问题而言，这意味着只有一组变量$(x_1, \ldots, x_n)$可以实现最大的茶浓度。探索其属性。

**引理 1.** 如果在最优集合中变量 $x_i, x_j$ 为正，则
$$g_i'(x_i) = g_j'(x_j).$$

**证明。** 让我们用 $c$ 表示总和 $x_i + x_j$ 并考虑函数 $h(x) = g_i(x) + g_j(c - x)$。它的导数是$h'(x) = g_i'(x) - g_j'(c - x)$。如果$g_i'(x_i) \neq \neq g_j'(x_j)$，则$h'(x_i) \neq 0$和函数$h$无法在点$x_i$处达到最大值。那么函数$g_1(x_1) + \ldots + g_n(x_n)$就无法在集合$(x_1, \ldots, x_n)$上达到最大值。

从引理 1 可以看出，对于所有正变量 $x_i$，乘积 $g_i'(x_i)$ 的值相等。让我们用$k$来表示它们的共同含义。

**引理 2.** 如果 $x_j = 0$，则 $g_j'(x_j) \leq k$。

引理2的证明与引理1的证明类似：如果$x_i > 0$、$x_j = 0$和$g_j'(x_j) > g_i'(x_i)$，那么通过增加$x_j$的值并减少$x_i$的值相同的量，我们可以增加$g_1(x_1) + \ldots + g_n(x_n)$的值。

根据引理1和引理2，考虑到$g_i'(x_i) < g_i'(0) = a_i$和$a_1 \geq a_2 \geq \ldots \geq a_n$，可以得出最优集合$(x_1, \ldots, x_n)$具有以下形式。对于一些$m \leq n$
$$x_1, \ldots, x_m > 0,$$
$$x_{m+1} = \ldots = x_n = 0,$$
$$x_1 + \ldots + x_m = 1,$$
$$g_i'(x_1) = \ldots = g_m'(x_m) \geq a_{m+1}.$$

剩下的就是确定值 $m$ 和变量 $x_1, \ldots, x_m$。像以前一样表示 $g_i'(x_1) = k$，我们得到
$$\frac{a_i}{(1 + x_i)^2} = k, \quad i = 1, \ldots, m,$$
$$x_i = \sqrt{\frac{a_i}{k}} - 1,$$
$$x_1 + \ldots + x_m = \frac{\sqrt{a_1} + \ldots + \sqrt{a_m}}{\sqrt{k}} - m = 1,$$
$$\sqrt{k} = \frac{\sqrt{a_1} + \ldots + \sqrt{a_m}}{m + 1},$$
$$x_i = \frac{(m + 1)\sqrt{a_i}}{\sqrt{a_1} + \ldots + \sqrt{a_m}} - 1.$$

另外，从条件来看 $x_m > 0$ 我们明白了 $\sqrt{a_m} > \left(\sqrt{a_1} + \ldots + \sqrt{a_m-1}\right)/m$，并从条件

讨论

最大限度地提高茶的浓度这一经过深思熟虑的问题看起来不太自然。然而，许多应用问题都是通过类似的数学模型来描述的。例如，需要在$n$个企业之间分配有限的资源，每个企业都有某种产品，如果第$i$个企业被分配资源$x_i$，那么从该企业获得的利润等于$g_i(x_i)$，其中$g_i$是一个递增且（通常）凹函数。那么最大化总近似值的问题与我们考虑的问题具有相同的形式，并且其解也满足引理1和引理2，因为在这些引理的证明中我们仅使用了凹函数$g_i$。此外，如果我们按照$g'_0(0)$值的降序对企业进行排序，那么最优解决方案将是在前$m$企业之间分配一些$m \leq n$的资源。

我们可以考虑一个更普遍的问题：有一定数量的$S$钱可以用来购买$n$产品，而$p_1, \ldots, p_n$产品的价格是固定的。每组$(x_1, \ldots, x_n)$产品都具有某种效用，如果我们固定除$x_i$之外的所有变量的值，那么效用将是$x_i$的递增但凹函数。该函数的任意函数称为$i$次乘积的*边际效用*。正式任务归结为找到一组最大化效用并满足条件的产品。

$x_j \geq 0$,
$p_1x_1 + \ldots + p_nx_n \leq S$.

特别是，当$p_1 = \ldots = p_n = 1$和集合$(x_1, \ldots, x_n)$的效用等于$g_1(x_1) + \ldots + g_n(x_n)$时，我们得到一个需要考虑的问题。按照与引理1的证明相同的方式进行论证，我们得到以下陈述。

**引理 1'.** 对于效用最大化捆绑，购买产品的边际效用与其价格成正比。

这种说法称为“边际效用价格”。通俗地说，花在每种产品上的最后一分钱都会产生相同的效用。一般来说，寻找在凸、闭、有界集合上定义的凹函数的最大值的问题称为“凸规划问题”。有很多方法可以有效解决此类问题。这些方法的一个重要部分是基于 *Kuhn-Tucker meorem*，它描述了最优解决方案的属性。我们的引理1和引理2的形成就是应用这个定理来考虑问题的结果。

$$\varphi_X = \sum_{\text{по отрезку}} \Delta \varphi_i = \sum_{\text{по отрезку}} \frac{k \lambda \Delta r_i}{r},$$

其中 $\Delta \varphi_i$ 是长度为 $\Delta r_i$ 的线段的一小部分所产生的电势。不幸的是，如果不积分就无法计算这个总和。利用高等数学的元素，我们得到

$$\varphi_X = \sum_{\text{по отрезку}} \frac{k \lambda \Delta r_i}{r} = \int_{a-L}^{a+L} k \lambda \frac{dr}{r} = k \lambda \ln \frac{a+L}{a-L} = \frac{kQ}{2L} \ln \frac{1+e}{1-e}.$$

最终的。传导椭球体的能量

最后，我们准备回答本文的主要问题：传导椭球体的能量是多少？显然，椭球体的能量等于

$$W_{\text{эллипсоида}} = \frac{\varphi Q}{2} = \frac{kQ^2}{2L} \ln \frac{1+e}{1-e}.$$

它与球体能量的不同之处在于

$$\frac{W_{\text{эллипсоида}}}{W_{\text{сферы}}} = \frac{R}{2L} \ln \frac{1+e}{1-e}$$

应用。简单情况下唯一性定理的证明

**定理** 设一个收费系统$\{q\} + \{q'\}$，其中

$$\{q\} = \{q_1, q_2, \ldots, q_n\}, \{q'\} = \{q'_1, q'_2, \ldots, q'_m\}.$$

让我们在心里画一个封闭的等势面 $S$ （此时势能取相同的值 $\varphi = \varphi_0$），将空间分为两个区域：I 和 II。这些地区有收费群体 $\{q\}$ 和 $\{q'\}$ 相应的（见 图 8).区域内的场仅由边界电势决定 $S$ 和收费 $\{q'\}$ 在这个区域。反之亦然，如果有一组费用 $\{q\}$ 和导电表面 $S$ 有潜力 $\varphi = \varphi_0$，然后为了计算场，我们可以用这样一组电荷替换这个表面 $\{q'\}$，连同费用 $\{q\}$ 在表面点创建 $S$ 所需潜力 $\varphi = \varphi_0$。虚拟费用 $\{q'\}$ 在这种情况下称为电荷图像 $\{q\}$.

**引理** 如果闭合等势面内没有电荷，则该面内的场为零。

**引理的证明。**假设相反。假设表面内有一个点，在该点处场方向不为零。因此，也有一条合并线穿过该点。但这条合并线不能在这个表面内开始和结束——那里没有电荷。这意味着它只能穿过这个表面。但如果它与表面相交，那么我们将考虑沿着闭合轮廓移动精确电荷的功：我们将沿着梅线行走（电场做了一些功），然后我们将通过沿着等势面行走来闭合轮廓（该部分电场的功为零）。我们发现了一个闭合电路，沿该电路的电场功不为零——这与电场势的条件相矛盾。

**定理证明。** 让我们证明，如果我们采用另一种扰动电荷分布$\{Q'\}$，保持表面电势$S$相同，则区域P中的场将不会改变。

假设存在两个电荷分布：$\{q\} + \{q'\}$ 和 $\{q\} + \{Q'\}$，由具有电势 $\varphi = \varphi_0$ 的相同等势面 $S$ 创建。让我们从第一个电荷分布中减去第二个电荷分布，即考虑分布

$$\left(\{q\} + \{q'\}\right) - \left(\{q\} + \{Q'\}\right).$$

很明显，当所有电荷乘以$(-1)$时，根据模型，空间中每个点的场方向保持不变，但方向变为相反。请注意，表面 $S$ 仍然保持等电位（而且，其上的电位为零）。该表面内没有电荷，因此其内部场的方向为零。因此，第一电荷分布$\left(\{q\} + \{q'\}\right)$的内部各点的方向性与第二电荷分布$\{q\} + \{Q'\}$的场方向一致，这是需要证明的。
