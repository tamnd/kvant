阶梯内的单元格的列数不超过行数。
选取梯子中的某个方格，$a$是其最右列的编号，$b$是最上面一行的编号，$c$是最下面一行的编号。由上可知$a \leq b \leq c$。此外，正方形的边长为$c - b + 1$，因此$a \geq c - b + 1$和$a + b \geq c + 1 > c$，即由长度为$a, b, c$的线段可以形成一个三角形。
使用类似的推理，我们可以证明相反的情况是正确的：如果给定一个边长为 $a \leq b \leq c \leq n$ 的三角形，那么在梯子中，您可以构造一个方格正方形，其中最右边的列有数字 $a$，最上面的行有数字$b$，最底行有数字$c$。这样，梯子中的正方形与边长不超过$n$的整数三角形之间就建立了一一对应关系，因此它们的数量相等。

13. $\frac{1}{4}$.
令 $p(X)$ 表示多边形 $X$ 的周期。 John 可以绘制四个大小为 $1 \times 4n$ 的矩形 $A_1, A_2, A_3, A_4$，每个矩形的公共单元分别是最外面的：右、下、左和上，以及一个大小为 $(2n - 1) \times (2n - 1)$ 的正方形 $B$，其中该单元位于中心。然后是$p(A_i) = 8n + 2$、$p(B) = 8n - 4$、$p(A_i \cap A_j) = 4$、$p(A_i \cap B) = 2n + 2$。如果 Sam 将正方形 $B$ 显示为红色，并将任何矩形显示为蓝色，他将获得最大周期比。所以，$\alpha \leq \frac{2n + 2}{8n - 4} = \frac{1}{4} + \frac{3}{8n - 4}$。如果$n$足够大，这个值可以和$\frac{1}{4}$一样大，所以Sam不能调用大于$\frac{1}{4}$的$\alpha$。
让我们向 Sam 展示如何进行，以便在任何情况下他都能获得不小于 $\frac{1}{4}$ 的周期比率。它可以突出显示绘制的矩形的最左、最上、最右和最下边（如果有多个矩形，则每个方向各有一条边）。对于每个矩形$K$，没有边会被突出显示； Sam 会将其显示为红色。不失一般性，我们假设所有五个矩形的公共单元距左侧最远$K$，它们之间的距离为$n - 1$。然后，Sam 将显示蓝色的矩形 $S$，其左侧被延长。矩形$K$的边不超过$2n - 1$，并且矩形$K$和$S$的交集的尺寸不小于$1 \times n$，因此$p(K) \leq 8n - 4$、$p(K \cap S) \geq 2n + 2$且这些周长之比不小于$\frac{2n + 2}{8n - 4} > \frac{1}{4}$。

14. 一定。
假设三角形$ABC$不相等。那么问题的条件就相当于三个线段$A'_A_0, B'_B_0, C'_C_0$之一（其中$A_0, B_0, C_0$分别是边$BC, CA, AB$的中点）等于另外两个线段之和。这些线段是九点圆的弦。
由于点 $A, C, A'$ 和 $C'$ 位于以 $B_0$ 为圆心的圆上，则$B_0A' = B_0C$。另外，$A_0B_0 \parallel AB$，因此九点圆的弦$A'_A_0$对着一条大小弧
$2\angle A'_B_0A_0 = 2|180^\circ - 2\angle C - \angle A| = 2|\angle B - \angle C|$.
类似地，弦$B'_B_0$和$C'_C_0$对着大小为$2|\angle C - \angle A|$和$2|\angle A - \angle B|$的弧。因此，其中一个等于其他两个的总和，即从三个指定的弦可以形成一个三角形。矛盾。
