问题解决

首先，我们来看看杯子里茶的浓度。我们将玻璃杯中液体的体积设为1，将倒入第$i$个玻璃杯中的水的体积记为$x_i$。然后，倒出后，玻璃杯中液体的体积将变为$1 + x_i$，因此茶的浓度将降低至$a_i / (1 + x_i)$。因此，从这个玻璃杯倒回杯子中的$x_i$液体量将含有$g_i(x_i) = a_i x_i / (1 + x_i)$茶，而杯子中承诺的茶浓度将是$g_1(x_1) + \ldots + g_n(x_n)$。因此，我们需要针对满足条件的$x_1, \ldots, x_n$的值找到函数$g_1(x_1) + \ldots + g_n(x_n)$的最大值
$$x_i \geq 0, x_1 + \ldots + x_n = 1.$$
检查了函数 $g_i(x_i)$ 的图形（参见 图），很容易看出这个函数是递增的，但它的导数 $g_i'(x_i) = a_j / (1 + x_i)^2$ 却很致命。最后一个属性意味着函数 $g_i$ 是可能的，因此它们的和将是凹函数。

我们不会给出凹函数的严格定义。我们只补充一点，几何凹性意味着连接函数图形上任意两点的线段位于图形下方。对于多个变量的凹函数也是如此。

凹函数具有以下重要性质。

**定理。** 在 Vi凸上定义的凹函数，由约束设置的闭合（即包含其边界）在单个点处达到其最大值。

就我们的问题而言，这意味着只有一组变量$(x_1, \ldots, x_n)$可以实现最大的茶浓度。探索其属性。

**引理 1.** 如果在最优集合中变量 $x_i, x_j$ 为正，则
$$g_i'(x_i) = g_j'(x_j).$$

**证明。** 让我们用 $c$ 表示总和 $x_i + x_j$ 并考虑函数 $h(x) = g_i(x) + g_j(c - x)$。它的导数是$h'(x) = g_i'(x) - g_j'(c - x)$。如果$g_i'(x_i) \neq \neq g_j'(x_j)$，则$h'(x_i) \neq 0$和函数$h$无法在点$x_i$处达到最大值。那么函数$g_1(x_1) + \ldots + g_n(x_n)$就无法在集合$(x_1, \ldots, x_n)$上达到最大值。

从引理 1 可以看出，对于所有正变量 $x_i$，乘积 $g_i'(x_i)$ 的值相等。让我们用$k$来表示它们的共同含义。

**引理 2.** 如果 $x_j = 0$，则 $g_j'(x_j) \leq k$。

引理2的证明与引理1的证明类似：如果$x_i > 0$、$x_j = 0$和$g_j'(x_j) > g_i'(x_i)$，那么通过增加$x_j$的值并减少$x_i$的值相同的量，我们可以增加$g_1(x_1) + \ldots + g_n(x_n)$的值。

根据引理1和引理2，考虑到$g_i'(x_i) < g_i'(0) = a_i$和$a_1 \geq a_2 \geq \ldots \geq a_n$，可以得出最优集合$(x_1, \ldots, x_n)$具有以下形式。对于一些$m \leq n$
$$x_1, \ldots, x_m > 0,$$
$$x_{m+1} = \ldots = x_n = 0,$$
$$x_1 + \ldots + x_m = 1,$$
$$g_i'(x_1) = \ldots = g_m'(x_m) \geq a_{m+1}.$$

剩下的就是确定值 $m$ 和变量 $x_1, \ldots, x_m$。像以前一样表示 $g_i'(x_1) = k$，我们得到
$$\frac{a_i}{(1 + x_i)^2} = k, \quad i = 1, \ldots, m,$$
$$x_i = \sqrt{\frac{a_i}{k}} - 1,$$
$$x_1 + \ldots + x_m = \frac{\sqrt{a_1} + \ldots + \sqrt{a_m}}{\sqrt{k}} - m = 1,$$
$$\sqrt{k} = \frac{\sqrt{a_1} + \ldots + \sqrt{a_m}}{m + 1},$$
$$x_i = \frac{(m + 1)\sqrt{a_i}}{\sqrt{a_1} + \ldots + \sqrt{a_m}} - 1.$$
