$\overline{R}$情况下的策略。请注意，每个圣人在猜测时所拥有的信息是其同事帽子的三种颜色（看到的或有条件的）。让智者假设他们戴的帽子是有颜色的

$$a = g(1), b = g(2), c = g(3), d = g(4),$$

其中 $g$ 是一些线性分数函数（1、2、3、4 是实数）。如果您自己猜出所有四个，那么这个假设是完全错误的。但我们有第一位圣人，以不猜测为代价，他实际上可以确保在任何颜色排列中实现这个属性——毕竟其他人看不到他的帽子，而只是听他说的话。为此，他只需查看同事帽子的颜色 $b, c, d$，然后选择一个线性分数函数 $g$，其中 $b = g(2), c = g(3), d = g(4)$。根据分数次线性函数定理，这样的函数存在且唯一。接下来，他计算颜色 $a = g(1)$ 并将其命名为他的答案。顺便请注意，$a$ 与任何颜色 $b, c$ 和 $d$ 都不重合，因为函数 $g$ 是双射的。从现在起，其他圣人都相信第一位圣人有一顶颜色为$a$的帽子。

剩下的圣人现在会如何猜测？第二位圣人看到颜色$c$和$d$并听到颜色$a$。它将尝试找到 $a = h(1), c = h(3), d = h(4)$ 的线性分数函数 $h$。由于只有一个这样的函数，并且第一位圣人向我们保证了$a = g(1), c = g(3), d = g(4)$，所以第一位圣人的搜索以找到唯一可能的函数$h = g$而结束。然后他会将$h(2) = g(2) = b$命名为他的颜色，即猜猜你的颜色！情况与其他智者类似：在寻找函数$h$（其中$a = h(1), b = h(2), d = h(4)$）时，第三个会找到相同的函数$g$，并且也会猜测他的颜色。四人也会以同样的方式行事。

圣人策略
九顶帽子

如果只有9顶帽子，智者该怎么办？对于这种情况，三位智者能猜出来吗？是的，如果他们在域 $\mathbb{F}_8$ 上使用分数线性函数。

让我们在最后一个字段 $\mathbb{F}_8$ 上再添加一个点，这将表示 $\infty$，并表示它 $\mathbb{F}_8 = \mathbb{F}_8 \cup \{\infty\}$。规则 (1)、(2)、(3) 允许您指定线性分数函数

$$f(x) = \frac{ax + b}{cx + d},$$，其中$a, b, c, d \in \mathbb{F}_8$作为从$\mathbb{F}_8$到$\mathbb{F}_8$的映射。线性分数函数定理对于情况 $\mathbb{F}_8$ 成立：集合 $\mathbb{F}_8$ 的任何三个不同点都可以映射到任何三个不同点，并且执行此操作的函数是唯一定义的。

现在，圣人们可以应用上一节中的策略，将集合 $\mathbb{F}_8$ 与 $\mathbb{R}$ 一起使用。与实数 1、2、3、4 一起，我们应该取四个元素$\mathbb{F}_8$，例如 1、$t$、$t + 1$、$t^2$。
