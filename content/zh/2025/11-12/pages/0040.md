1) 如果$c \notin l(a,b)$，那么我们在线段$l(a,b)$ (图 2) 上找到点$x = a \times b$（自动）。

Cesky $x \neq c$），之后在$l(x,c)$线上我们找到一个点$d$使得$c \times d = x$（它由收缩性属性唯一确定）。然后是$d \neq c$（否则会是$x = c \times d = c \times c = c$），还有$d \neq x$（否则从等式$c \times x = x$我们会发现$c = x$）。因此，在点$(a,b,c,d)$的有序四元组中，点$a$和$b$位于一条直线上，点$c$和$d$位于另一条线上，同时$a \times b = c \times d = x$，其中$x$是这些线的交点。让我们将四个 $(a,b,c,d)$ 添加到集合 $S$ 中。
