对于边长为$x, y, z$的直立平行六面体，其体积为$V = xyz$，表面积为$S = 2(xy + yz + zx)$。根据三个非负数$a, b, c$的均值不等式，我们有$\frac{a+b+c}{3} \geq (abc)^{1/3}$，并且仅对于$a = b = c$才实现相等。然后，利用这个不等式，我们得到
$$S = 2(xy + yz + zx) \geq 6(xyz)^{2/3} = 6V^{2/3}.$$
将这个估计应用于相同体积$V$的两个新盒子中的每一个，我们发现
$$6 = S_1 + S_2 \geq 12V^{2/3}.$$
因此，
$$V^{2/3} \leq \frac{1}{2} \Rightarrow V \leq \left(\frac{1}{2}\right)^{3/2} = \frac{1}{2\sqrt{2}}.$$
因此，两个相同盒子的体积最大可能不超过$\frac{1}{2\sqrt{2}}$。
现在我们举一个当$V = \frac{1}{2\sqrt{2}}$时的例子。 图 6 表明立方体的第 1 边的表面可以被切割成两个杯子的展开

4. 考虑数字 $x$ 和 $y$，其中
$$x + \frac{1}{x} = y - \frac{1}{y}.$$
让我们证明它们不可能是理性的。让我们假设相反的情况。让我们把
$$A = \left(y + \frac{1}{y}\right)^2, \quad B = \left(x - \frac{1}{x}\right).$$
然后
$$A - 4 = \left(y - \frac{1}{y}\right)^2 = \left(x + \frac{1}{x}\right)^2 = B + 4.$$
我们得到
$$A - B = 8, \quad A + B = 2B + 8 = 2\left(x + \frac{1}{x}\right)^2.$$
改变最后两个等式，我们有
$$A^2 - B^2 = (A - B)(A + B) = 8 \cdot 2\left(x + \frac{1}{x}\right)^2 = \left(4\left(x + \frac{1}{x}\right)\right)^2.$$
我们得到
$$\left(y + \frac{1}{y}\right)^4 - \left(x - \frac{1}{x}\right)^4 = A^2 - B^2 = \left(4\left(x + \frac{1}{x}\right)\right)^2.$$
左边是有理数四次方的差，右边是有理数的平方。但从条件我们知道，这个方程只有当其中一个数为零时才有解。因此，当这些数字之一等于零时，需要考虑三种情况。
方程$x + \frac{1}{x} = 0$和$y + \frac{1}{y} = 0$无解。仍然需要考虑情况$x - \frac{1}{x} = 0$。我们得到$x = 1$或$x = -1$，然后从等式$y - \frac{1}{y} = x + \frac{1}{x}$我们得到$y - \frac{1}{y} = 2$或$y - \frac{1}{y} = -2$。但这些方程的根是无理数的。
我们得到了一个矛盾。
因此，原方程没有有理解。

问题和任务
1. 由于冰的密度小于水的密度，因此冰的体积变成水的体积，并且分子之间的距离增加。
2. 真实气体具有更大的内能，因为它的分子除了动能之外，还具有潜在的相互作用能。
3. 当气体强烈滚动时，其分子间开始排斥，真实气体的压力将超过理想气体的压力；结果，乘积$pV$将随着体积的减小而增大。
4. 在气体中，动能远大于势能；在液体中，动能大致相同；在固体中，动能小于势能。
5. 从$E = \frac{3}{2}kT = \frac{m_0v^2}{2}$和$m_0 = \frac{M}{N_A}$之间的对应关系可以看出，分子平动运动的平均动能不取决于其质量，而仅取决于温度。相同温度下，较轻的分子的均方根速度较高。
6. 空气的压力和体积保持不变，从对应关系$pV = NkT$得出$\frac{N}{N_0} = \frac{T_0}{T} = \frac{288}{300} = 0,96$。这意味着分子数量减少了4%。
