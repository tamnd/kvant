$$\cos\varphi = \frac{1}{\sqrt{1 + \text{tg}^2\varphi}} = \frac{7}{9},$$

6. $r = 9$公里； $S = 576\arccos\frac{1}{8} - 162\pi - 27\sqrt{7}$。
让3G塔具有相同的范围$r$。大圆的半径为$R$，即大圆中心到弦$d$的距离。我们画点如图16：$O -$所示

大圆的中心，$C, D$ – 小圆的中心，$K$ – 小圆的接触点，$E$ – 圆与弦的接触点，$OP = d$ – 从中心到弦的指定距离。然后我们有
$$CE \perp AB, OP \perp AB, CE \parallel OP,$$
$$OP \cap (OAB) = G, CD \cap OG = K,$$
$$OC = R - r, CK = r,$$
$$OK = d + r \Rightarrow (R - r)^2 = r^2 + (d + r)^2 \Rightarrow$$
$$\Rightarrow r^2 + 2r(d + R) - (R^2 - d^2) = 0,$$
在哪里
$$r = -(R + d) + \sqrt{2R^2 + 2Rd}.$$
我们来计算一下网段中不属于3G直放站覆盖范围的部分的面积。令$\angle AOP = \alpha$，$S_c = S_{\text{сеч}}$。然后
$$\cos\alpha = \frac{OP}{OA} = \frac{d}{R} \Rightarrow \sin\alpha = \sqrt{1 - \left(\frac{d}{R}\right)^2} \Rightarrow$$
$$\Rightarrow \sin 2\alpha = 2\frac{d}{R} \sqrt{1 - \left(\frac{d}{R}\right)^2} \Rightarrow$$
$$\Rightarrow S = S_c - 2S_k = \frac{1}{2}R^2(2\alpha - \sin 2\alpha) - 2\pi r^2 =$$
$$= \frac{1}{2}R^2(2\alpha - 2\frac{d}{R}\sqrt{1 - \left(\frac{d}{R}\right)^2}) - 2\pi r^2.$$
让我们代入值$R = 24, d = 3$，然​​后
$$r = -(24 + 3) + \sqrt{2 \cdot 24 \cdot (24 + 3)} = 9,$$
$$\cos\alpha = \frac{1}{8}, \sin\alpha = \frac{3\sqrt{7}}{8}, \alpha = \arccos \frac{1}{8},$$
所需的平面等于
$$S = \frac{1}{2}24^2\left(2\arccos \frac{1}{8} - 2 \cdot \frac{1}{8} \cdot \frac{3\sqrt{7}}{8}\right) - 2\pi \cdot 81 =$$
$$= 576\arccos \frac{1}{8} - 162\pi - 27\sqrt{7}.$$
