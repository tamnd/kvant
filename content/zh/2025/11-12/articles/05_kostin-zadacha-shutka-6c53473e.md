第一步是询问多项式 $x^{2027}$。
方程 $P(x) = x^{2027}$ 必须至少有一个实数根，因为该方程的根是奇数次多项式 $x^{2027} - P(x)$ 的根。对于最后一步，我们可以指定$a$，这样在$x > a$$P(x) < x^{2027}$将得到满足（事实上，作为$a$，我们可以取方程的最根）。
类似地，在第二步中我们询问多项式$-x^{2027}$。对于最后两个动作，我们将知道$M$，从而满足所有$x > M$$-x^{2027} < P(x) < x^{2027}$。
使用此信息，对于第三步，我们将选择一个多项式 $Q$，使得方程 $P(x) = Q(x)$ 取决于至少有 2026 个根。然后，在给我们这些根$x_1 < x_2 < ... < x_{2026} < ...$之后，我们将$P$恢复为唯一的$\leq 2025$次数多项式，在点$x_i$处取值$Q(x_i)$。
（这样的多项式 $P$ 确实是唯一的：如果存在另一个具有此属性的多项式 $P_1$，那么 $\leq 2025$ 次的非零多项式 $P - P_1$ 将至少有 2026 个根 - 这是一个矛盾。）
当选择$Q$时，我们将使用以下众所周知的事实：对于任何数字$x_1 < x_2 < ... < x_n$和$y_1 < y_2 < ... < y_n$，都存在一个多项式$R$，使得$R(x_i) = y_i$对于所有$i = 1, 2, ..., n$。 （这样的多项式$R$可以构造为积分拉格朗日多项式；事实上，存在一个唯一的这样的$\leq n - 1$次多项式。）
那么，让我们描述一下如何选择$Q$（知道$x > M$$-x^{2027} < P(x) < x^{2027}$是满足的）。令$x_1 < x_2 < ... < x_{2027} -$为任何大于$M$的数；我们也把
$$y_i = (-1)^i x_i^{2027}$$ 为 $i = 1, 2, ..., 2027$。
对于所有选定的$x_i$和$y_i$、$i = 1, 2, ..., 2027$，令$Q$为$Q(x_i) = y_i$。 $y_i$的选择是这样的：如果$i$是偶数，则执行$Q(x_i) > P(x_i)$，如果$i$是奇数，则执行$Q(x_i) < P(x_i)$。然后，在每个积分 $(x_i; x_{i+1})$ 的末尾（其中 $i = 1, 2, ..., 2026$，多项式 $P - Q$ 取不同符号的值，因此（根据连续函数的区间值定理），在区间 $(x_i; x_{i+1})$ 上有根。因此，我们证明了所需的：方程 $P(x) - Q(x) = 0$ （或等效地，$P(x) = Q(x)$）至少有2026 根，解决问题。
可以证明两次移动不足以保证多项式的恢复。

F2861。正好中午，从A码头到B码头，相机和海船抵达了河边的位置。相机和船相对于水的速度分别为 $v_1 = 40$ km/h 和 $v_2 = 25$ km/h。河流变迁速度为$u = 5$公里/小时。当摄像机扫清整条路线时，河面上笼罩着一层浓雾，船长决定不再冒险，淹没了大雾。相机继续前进，但地点不同，没有移向海岸。雾气飘荡持续了30分钟，直到雾气散去。此后，相机在不改变运动方向的情况下，以相对于水的原始速度继续其路径。一直以来，莫里斯蒂姆都在自己承担风险的情况下继续驾驶船，没有放慢速度。相机和船同时抵达B码头。
a) 摄像机和船什么时候开到B码头的？
b) 移动过程中相机和船之间的最大距离（沿河）是多少？

让我们引入以下符号：$t_1$ – 雾前运动时间，$t$ – 雾中运动时间，$t_2$ – 雾后运动时间。根据问题的条件，我们得到如下方程组：

$$\begin{align*}
(v_1 + u)t_1 &= \frac{1}{3}(v_2 + u)(t_1 + t + t_2), \\
(v_1 + u)(t_1 + t_2) + ut &= (v_2 + u)(t_1 + t + t_2).
\end{align*}$$

为了简化计算，让我们代入速度的数值。经过简单变换后，方程组将采用以下形式

$$\begin{align*}
7t_1 - 2t_2 &= 2t, \\
3t_1 - 3t_2 &= 5t.
\end{align*}$$

求解系统，我们发现

$$t_1 = \frac{16}{27}t, t_2 = \frac{29}{27}t.$$

考虑到这一点，我们求出从 A 码头到 B 码头的整个移动时间：

$$T = t_1 + t + t_2 = \frac{8}{3}t = 80 \text{ мин} = 1 \text{ ч} 20 \text{ мин}.$$

因此，快艇和小船将于13点20分抵达B号码头。

江面上雾气弥漫的那一刻，船与船之间的距离

$$s_1 = (v_1 - v_2)t_1 \approx 4,4 \text{ км},$$

当雾散去时——

$$s_2 = v_2(t_1 + t) - v_1t_1 \approx 8,1 \text{ км}.$$

因此，移动过程中船与船之间的最大距离约为8.1公里。
