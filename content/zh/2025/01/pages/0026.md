在相同的三个位置上有颜色为 1、2、3 的单元格（按此顺序）。这唯一地填充了三个连续的列。进一步，从这三列向左向右移动，我们了解到根据第二行，第一行和第三行以同样的方式恢复。因此，我们已经证明，在我们的假设中，第一行和第三行的颜色相同。类似地，它显示所有具有四个数字的线的颜色相同，并且所有具有奇数的线的颜色相同。那么对于我们来说（即在条件允许的情况下）指定前两行的颜色是完全正确的，因此在第一行（然后也在第二行）中存在至少 3 种颜色的单元格。我们首先来数一下将两条线正确着色为 4 种颜色的方法有多少种。让我们首先为两个单元格的第一列着色 - 这可以通过 12 种方式完成，然后对于每个后续列，将唯一确定其单元格的一组两种颜色，并且可以通过 2 种方式绘制该列。共有$12 \cdot 2^{n-1} = 3 \cdot 2^{n+1}$种方式。让我们减去“额外”方式的数量 - 其中至少一条线（事实上，两条线）恰好包含 2 种不同的颜色；这样的方法就会有$6 \cdot 2^2 = 24$个（计数与情况1类似）。总的来说，在第二种情况下，我们得到了 $3 \cdot 2^{n+1} - 24$ 方法。总结第一种情况和第二种情况的方法，我们得到$2 \cdot 3 \cdot 2^{n+1} - 24 = 3 \cdot 2^{n+2} - 24$种方法。

M2811。连续自然数$a_1, a_2, \dots, a_{100}$是Poppy，$a_1 = 1$和每个自然数$n = 1, 2, \dots, 100$（$a_1 + a_2 + \dots + a_n$）（$\frac{1}{a_1} + \frac{1}{a_2} + \dots + \frac{1}{a_n}$）都是整数。 $a_{100}$ 可以取的最大有效值是多少？

答案：$2^{98}$。

示例：$a_1 = 1, a_2 = 1, a_3 = 2, a_4 = 2^2, a_5 = 2^3, \dots, a_{100} = 2^{98}$。

年级。让我们证明对于所有 $i$，$a_i$ 是 $s_{i-1} = a_1 + \dots + a_{i-1}$ 的约数。这就足够了。事实上，然后通过$i$的指示，我们证明了对$i \geq 2$的一对估计$s_{i-1} \leq 2^{i-2}, a_i \leq 2^{i-2}$。过渡$i \rightarrow i+1$结果如下：

$s_i \leq s_{i-1} + a_i \leq s_{i-1} + s_{i-1} \leq 2^{i-2} + 2^{i-2} = 2^{i-1}; a_{i+1} \leq s_i \leq 2^{i-1}$.

那么，让我们证明一下。

根据数量

$$l = \left(a_1 + \dots + a_i\right)\left(\frac{1}{a_1} + \dots + \frac{1}{a_i}\right)$$

和

$$k = \left(a_1 + \dots + a_{i-1}\right)\left(\frac{1}{a_1} + \dots + \frac{1}{a_{i-1}}\right)$$

是完整的。然后是号码

$$l - k - 1 = a_i\left(\frac{1}{a_1} + \dots + \frac{1}{a_{i-1}}\right) + \left(a_1 + \dots + a_{i-1}\right)\frac{1}{a_i}$$

- 所有的。让我们看看这个等式右边的两项：

$$\alpha = a_i\left(\frac{1}{a_1} + \dots + \frac{1}{a_{i-1}}\right) \text{ и } \beta = \left(a_1 + \dots + a_{i-1}\right)\frac{1}{a_i}.$$

数字$\alpha$和$\beta$是有理数，且$\alpha + \beta$之和是整数。这意味着分数 $\alpha$ 和 $\beta$ 在不可约符号中具有相同的（自然）分母。此外，如果这些分母大于 1，那么乘积 $\alpha \beta$ 就不是整数，但对我们来说 $\alpha \beta = k$ 是一个整数。这意味着分数$\alpha$和$\beta$的不可约表示法中的分母等于1，即$\alpha$和$\beta$是整数。但这完成了解决方案，因为我们需要证明 $\beta = \left(a_1 + \dots + a_{i-1}\right)\frac{1}{a_i} - \text{ целое число}.$
