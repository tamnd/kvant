总之，我们会回答，我们的说法可以通过其他方法来证明。有一个使用笛沙格对偶对合定理的简短证明。另一种方法是考虑我们的四边形具有属性 (*) 的点集 $X$。事实证明，这个集合是一条三次曲线——即所谓的焦点立方体。这个立方体有许多有趣而美丽的特性；我们的陈述也可以从它们中推断出来。

陈光雄、P. Kozhevnikov

M2814。正数 $a, b, c$ 使得 $b + c = a^2$。找出表达式的含义

$$\frac{\sqrt{a + \sqrt{b}} + \sqrt{a + \sqrt{c}}}{\sqrt{a - \sqrt{b}} + \sqrt{a - \sqrt{c}}}.$$

答案：$\sqrt{2} + 1$。

让我们使用众所周知的双根式转换公式（可以通过平方轻松证明）。在我们的符号中，即考虑到等式 $c = a^2 - b$，该公式的形式为

$$\sqrt{a + \sqrt{b}} = \frac{1}{\sqrt{2}} \left( \sqrt{a + \sqrt{c}} + \sqrt{a - \sqrt{c}} \right),$$

或者

$$\sqrt{a + \sqrt{c}} + \sqrt{a - \sqrt{c}} = \sqrt{2} \cdot \sqrt{a + \sqrt{b}}.$$ (1)

类似地（请注意，$b$和$c$在我们的推理中是等价的）：

$$\sqrt{a + \sqrt{b}} + \sqrt{a - \sqrt{b}} = \sqrt{2} \cdot \sqrt{a + \sqrt{c}}.$$ (2)

让我们表示$X = \sqrt{a + \sqrt{b}} + \sqrt{a + \sqrt{c}}$和$Y = \sqrt{a - \sqrt{b}} + \sqrt{a - \sqrt{c}}$，这样$\frac{X}{Y}$就是我们需要的表达式。将(1)和(2)相加，得到$X + Y = \sqrt{2}X$，打开$\frac{X}{Y} + 1 = \sqrt{2} \frac{X}{Y}$和$\frac{X}{Y} = \frac{1}{\sqrt{2} - 1} = \sqrt{2} + 1$。

P·科热夫尼科夫

M2815。有一组 2n funk $n$ 不同的水泥，每种水泥有两个 funk。这些功能随机排列在一行中。证明同一水泥连续出现两个相邻函数的概率大于1/2。

让我们考虑 $2n$ funkki $n$ 不同 tsemet 的所有可能系列，每个 tsemet 两个 funkki。如果一个系列不包含两个相邻的单链接 funkek，我们将称之为“不成功”。我们认为剩余的行*成功*。我们需要证明不成功的行数小于funkecks的数量，并且这一对不在前两个位置。

就拿一次不成功的排来说吧。让第一个函数的颜色为$A$。让我们找到第二个函数$A$，让它位于第$k$位置（$k \geq 3$，因为我们的系列不成功）。让我们重新排列循环中的第一个 $k-1$ funkek，以便两个颜色函数 $A$ 相邻。 （例如，$ABCBDADC \rightarrow BCBDAADC$、$ABACDBDC \rightarrow BAACDBDC$等）在此之后，我们得到了一个有趣的级数，其中恰好存在一对相邻的颜色函数$A$。因此，我们将每个不成功的系列与一个有趣的系列相匹配。在这种情况下，使用一个有趣的级数，可以明确地重建与之比较的不成功级数：即，可以找到一对（单壁）单链接相邻函数，并将左侧的函数移动到第一位（通过沿循环移动其余函数）。

因此，有多少有趣的行，就有多少不成功的行。但非常有一些令人惊讶的系列并不有趣，例如，$AA$形式的系列...因此，不成功系列的数量严格小于循环中的函数数量）。
