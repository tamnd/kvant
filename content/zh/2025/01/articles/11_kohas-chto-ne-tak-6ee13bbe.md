怎么了？
科哈斯

– 晚上好，亲爱的电视观众，你们在看《怎么了？》节目吗？它由我主持，石像鬼，第一频道的科学观察员。在我们的计划中，我们发展了伪科学神话和流行的误解。我们的手机提示 Kkhu 提出了这样的问题：“平方和公式有什么问题？”这个问题由充分性专家 Woodpecker Spyatel 回答。拜托了，大师。
- 大家好！我是啄木鸟斯皮特尔，我已经告诉你为什么这个公式
$$\left(a + b\right)^2 = a^2 + b^2 + 2ab$$
甚至比实际看起来更荒谬。我有一个大的方形房间，即正方形。里面有一个保险箱和一张桌子。因此，我们在一个广场上，即在房间里，有一个安全的公寓。但根据这个公式，这和一个正方形的保险箱是一样的——是的，没错，保险箱确实是在一个正方形里，即在房间里，平放在一个正方形里，这个也在那里，因为桌子也在房间里，最后，除此之外，桌子上还有一个平的保险箱。正如你所说，很明显：如果你把保险箱放在桌子上两次，他就会两次把它送出去！简直是无稽之谈！

细心的老师或忧郁的老师会反对我说“2ab”是某种简化，更微妙的观察表明它只是 ab + ba，但正如你所理解的，这不会改变任何东西：桌子上的保险箱已经更好了，它没有那么痛苦，但一旦桌子上的保险箱仍然存在！

– 非常感谢你，但是亲爱的啄木鸟，你能最后继续回答我们的电话提示 Kkhu 的问题吗？毕竟，直到那时，亲爱的斯皮特尔，您的讲座更多地提到了总和的平方公式，而不是平方和的公式。

– 再次大家好，朋友们！我还是啄木鸟斯皮特尔，我旁边的是

节目“怎么了？”中的电话石像鬼仍然很烦人，但出于某种原因很受欢迎。我们正在讨论平方和公式！那么，让我们仔细看看这个公式
$$\left(a^2 + b^2\right)\left(p^2 + q^2\right) = \left(ap - bq\right)^2 + \left(aq + bp\right)^2.$$
虽然……我们为什么要考虑它？它被称为婆罗门笈多身份。一切都清楚了，婆罗摩笈多已经考虑过了，所以我们一起考虑一下这个公式
$$\left(a^2 + b^2 + c^2 + d^2\right)\left(p^2 + q^2 + r^2 + s^2\right) =
\left(ap + bq + cr + ds\right)^2 + \left(aq - bp + cs - dr\right)^2 +
\left(ar - bs - cp + dq\right)^2 + \left(as + br - cq - dp\right)^2.$$
它被称为欧拉四方恒等式。假设 Primo 是一种迷幻配方。严格来说，应该问：“她怎么了？”很少有读者能够读完这个公式。例如，并不是每个人都会注意到 dp 之前的最后一个括号中有分钟这一事实。很少有人意识到 cq 之前最后一个括号中的分钟确实是必要的。但你知道，这里还有一些保留，我想把颜色加厚一点，让情况变得更糟，所以一起讨论这个公式，我们最好继续在所有方格中进行恒等！
——大师，你又得意忘形了！令我惊讶的是，我们奇怪的电话人员 Kkhu 发送了这个奇怪的问题，却没有问我们这些公式！
– 亲爱的精密科学爱好者！我仍然是啄木鸟斯皮特尔，“出了什么问题？”的专家。程序，所以我是石像鬼，他的举止很糟糕，试图不恰当地、不恰当地打断我们，而我们正在讨论平方和公式的奇怪之处！所以，让我们考虑一下平方和
$$1^2 + 2^2 + 3^2 + \ldots + n^2.$$
这个数额等于多少？事实证明，除了“这等于这个”这个天真而直接的答案之外，这个问题还有一个简单且看似非常明确的答案：
$$1^2 + 2^2 + 3^2 + \ldots + n^2 = \frac{n(n+1)(2n+1)}{6}.$$

这个公式有什么问题吗？好吧，我该怎么告诉你……使用这个公式，任何人都可以立即找到前一百个自然数的平方和。或者几乎立刻……或者一百一十五。或者一百一十五分半。或者，如果完全无法忍受，大约一百一十五分钟……呃……半！不错吧？让我们扪心自问，我们并不清楚为什么：需要添加多少个自然数的平方才能得到 -5 作为答案？并且，做出等式
$$\frac{x(x+1)(2x+1)}{6} = -5,$$
我们马上就能找到答案：$x = -3$，也就是说，我们需要取-3个方格！很奇怪，不是吗？
- 是的，是的，非常奇怪。这里不对劲。
- 这些都是这个公式向我们呈现的惊人的可能性。她如何证明这一点？当然是通过归纳法。如果我们假设对于 $n = k$ 这个公式是正确的，即
$$1^2 + 2^2 + 3^2 + \ldots + k^2 = \frac{k(k+1)(2k+1)}{6},$$
那么为了证明归纳转换，我们只需要检查相同的公式对于 $n = k+1$ 是否成立：
$$1^2 + 2^2 + 3^2 + \ldots + k^2 + (k+1)^2 = \frac{(k+1)((k+1)+1)(2(k+1)+1)}{6}.$$
这已经很简单了，因为通过应用归纳假设，我们可以像这样变换左侧的和：
$$1^2 + 2^2 + 3^2 + \ldots + k^2 + (k+1)^2 = \frac{k(k+1)(2k+1)}{6} + (k+1)^2.$$
现在，任何患者案例，甚至是 Typon Kkhu 本人，都可以毫不费力地验证所得表达式等于公式（1）右侧：
$$\frac{k(k+1)(2k+1)}{6} + (k+1)^2 = \frac{(k+1)((k+1)+1)(2(k+1)+1)}{6}$$

这样就完成了证明。要进行检查，只需将等式 (2) 乘以 6 并打开括号即可。

所有这些都是正确的，但我想提请您注意一个功能：以完全相同的方式，我们可以证明平方和等于其他表达式，例如
$$\frac{(2n^2+1)(2n+3)}{12}.$$
为了做到这一点，我们将理性地一起检查等式（2）
$$\frac{(2k^2+1)(2k+3)}{12} + (k+1)^2 = \frac{(2(k+1)^2+1)(2(k+1)+3)}{12}.$$
我不会用这个测试吓跑我们的电视迷，我只是说这是另一个非常简单的左括号练习。
- 如果我理解正确的话，老师，在平方和公式中，右边有问题。从某种意义上说，在应用该公式时，我们不应该纠缠于这样一个事实：正确的部分恰好等于
$$\frac{n(n+1)(2n+1)}{6},$$ 但你应该做好准备，因为它等于其他东西，而且完全不同！但这是非常不方便的！我们的 telefitel Tipon Kkhu 怎么能使用这个公式呢？
- 但他不能！而且他不需要使用任何东西！没有Kkhu类型！我，啄木鸟斯皮亚特尔，亲自用这个笔名注册了我们的电话，并问了这个愚蠢的问题！
- 你的意思是……啊啊啊！！！亲爱的电视观众，我们的节目《怎么了？》中似乎出现了这样的情况。一切又出了问题！
在今天的节目中，在我们的专家啄木鸟 Spyatla 的帮助下，错误的电话接线员针对错误的公式提出了错误的问题，我们欠这个公式错误的证明。这让事情变得更清楚了吗？几乎没有。石像鬼在你身边，你看了最精彩、最创新的进阶节目《怎么了？》下周见！

问题来了：在这种情况下是唯一的解决方案吗？很容易证明事实并非如此。例如，在上面的解决方案中，我们可以“翻转”右上角的正方形$2 \times 2$，即颜色就像正方形的另一条对角线一样。显然，这样我们就会得到一个新的解决方案。

事实上，这种“国际象棋四子棋”出现在与网格平行的一侧的矩形顶点处，例如在 图 6 上，是解决方案唯一性的唯一解决方案。事实证明，如果在没有“国际象棋四子棋”的情况下以某种方式构建着色，那么构建的解决方案就是该问题的唯一解决方案。

看来，如果我们提出一个通用的着色算法，问题就可以得到彻底解决：首先我们检查解存在的条件，然后我们建立它与算法的一致性，然后我们从平行于网格的一侧检查矩形所有顶点的着色，以获得唯一解的信息。

该算法确实存在。然而，它一点也不简单，我们不会在这里介绍它（可以阅读例如[1]中的算法描述）。让我们仔细考虑一下这样一个事实：从某种意义上说，它的存在和运作“很快”。

我们现在考虑的问题将出现在离散断层扫描中，例如，它用于图像处理、医学，甚至信息安全问题。这个问题有一个相当自然的根源：事实上，我们谈论的是穿过物体的“普伦特根射线”，其输出只是一些过程；需要恢复物体本身的结构。

让我们回到人工智能提出的任务。有算法可以解决吗？当然，有一个算法：至少，您可以简单地遍历所有可能的情况。然而，我们对是否存在“快速”算法这一问题的答案相当感兴趣。

事实是，有些问题可以“快速”解决，他们说这些是P类问题，而有些问题可以“快速”验证，它们属于NP类（这些问题的严格定义可以阅读，例如[2]）。显然，如果一个问题可以“快速”解决，那么只需查看其“快速”解决方案就可以“快速”验证它。因此，任何来自P类的问题也属于NP类。但NP类的问题是否真的存在于P类中仍然未知。大多数人仍然认为 NP 中存在相当复杂的问题，无法“快速”解决。

在算法理论中，引入了“快速”算法的严格定义，但直观的理解对我们来说就足够了。为了更清楚地了解我们正在讨论的任务类型，让我们看一些示例。

例如，给定两个整数。有必要找到它们的最大公约数。您可以使用欧几里德算法。在每一步中，我们都会用所写数字的差异替换更多的数字。一旦数字相等，我们就停止。所得数字将是最大公约数。这个任务就在P。

让我们看另一个例子。假设有一些整数M和一些数字S的多重集（其中元素可以重复的集合）。需要检查M中是否存在数字的子集加起来等于S。目前还没有快速算法来找到所需的子集。因此，我们不知道这个问题是否出在P上。​​但是，我们可以肯定地说问题出在NP上。如果给我们一组数字，那么我们只需要确保我们没有被欺骗，确实得到了一个子集M，并且给我们的数字之和等于S。由于可以快速检查解，所以问题出在NP上。此外，还有一类NP完全问题，即最“难”的NP问题。如果你找到一个“快速”算法来解决至少其中一些问题，这将自动意味着对于任何 NP 问题都有一个“快速”算法。而我们考虑的问题恰恰是NP完全问题。请注意，找到总和为 S 的子集 M 的任务本质上是人工智能提出的游戏的一个特例。只是在这种情况下，游戏是在一个棋盘上进行的，棋盘的一侧等于1。因此，如果存在一个好的算法，那么人们很可能很难猜到它，对于现代人工智能来说更是如此。剩下的就是以某种方式整理出选项。此类问题通常是 NP 完全问题。例如，数独也在其中。所以你可以确定，当生成一个新的关卡时，棋盘上的数字是随机出现的，“解决方案”也是随机选择的。因此，有些关卡很可能不会有唯一正确的组合，这当然不是很好。毕竟，当你做出决定时，你将不得不在某个时刻随机行动。让我们总结一下我们的推理：人工智能必须与（人类）智能一起使用，而不是希望它完美。不过，他能给一个有思想的人这么多的深思熟虑，真是太好了。预
