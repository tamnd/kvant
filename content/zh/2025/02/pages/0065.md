1. 撞击后，球会以$v$的速度水平弹起。将球从 $t \approx 0,32$ s 处垂直移动 $\Delta y = 0,5H + b = \frac{gt^2}{2}$。总飞行时间$T$可由公式$H + b = \frac{gT^2}{2}$求得，其中$T \approx 0,45$秒。那么球的进一步飞行距离为 $L = vT \approx 2,7$ 米。

2. 喷射的反作用力$F = \frac{\Delta m}{\Delta t}v = \rho Sv^2$。根据球相对悬浮力矩$\rho \frac{L}{2}Sg \sin \alpha = \rho Sv^2$，我们找到$\sin \alpha = \frac{2v^2}{gL}$。由于正弦总是小于 1，稳定平衡仅对 $v \leq \sqrt{\frac{gL}{2}}$ 有效。

3. 1) 随着质量 $M$ 从零开始增加，块的顶部首先开始移动，然后是 $M_{\min} = \frac{\mu m}{1 + \mu} = \frac{m}{6}$。

2) 当下块与工作台之间的摩擦力达到滑动摩擦力$F_{\text{tp2}} = \mu N_2$时，下块开始滑动。让我们写出所有三个物体在垂直轴和水平轴上的投影的运动方程：

$$Mg - T = Ma, N + T - mg = 0,$$
$$T - \mu N = ma, N_2 - N - mg = 0,$$
$$T - \mu N - \mu N_2 = 0.$$

从这里我们找到$M_{\min} = \frac{3\mu m}{1 - \mu^2} = \frac{5m}{8}$。

4. 由于这些设备是理想的，我们可以用开路代替电压表，用跳线代替电流表。利用节点中的潜力 (图 9)。可以看出，由于电位相等，没有电流流过电阻$OC$。这意味着电流表$A_1$中不会有电流，即$I_1 = 0$。

从 图 可以清楚地看出，第一个电压表上的电位差为 $U_1 = \varepsilon = 5$ V。在这种情况下，正极触点处的电位较大，这意味着电压表读数将为正。

因此，通过第二个电流表，它是由流经节点$B$的电流确定的。沿$BC$没有电流流过，这意味着流过电流表$A_2$的电流将等于流过电阻$BA$的电流$I$。该电流根据节点$B$和$F$的基尔霍夫规则确定：$I = 2\varepsilon \cdot 2r = 1$mA，即通过电流表$A_2$的电流将等于$I_2 = 1$mA。但由于它流向电流表的负极接点，因此电流符号为“-”。最终答案：$I_2 = -1$mA。

电压表$V_2$上的电压定义为节点$O$和$A$之间的电位差。这意味着$Ir = \varepsilon$可以找到$A$点的势能。它将等于 $\varepsilon$。这意味着节点之间的电位差将为 $U_2 = -\varepsilon = -5$ V。
