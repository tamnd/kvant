我们从容器底部“切掉”一条细线（我们假设壁厚为零）。镜头的焦距为
$$F = \frac{R}{n-1}.$$
厚度为 $x$ 的水层将图像移动 $\Delta f = x \frac{n-1}{n}$ 量（沿光线路径）。为了计算图像坐标，它使用以下形式的细线公式
$$\frac{1}{f} = \frac{1}{d} + \frac{1}{F}.$$
该公式对于任何镜头（聚光、散射）都有效。这些量用它们在坐标系中的符号代入该公式，坐标系的起点与透镜的光学中心对齐。
水盘“移位”后的距离$d$等于
$$d = x - x \frac{n-1}{n} = \frac{x}{n}.$$

我们计算图像坐标（在“工作”坐标系中，直线的焦点为$-\frac{R}{n-1}$）：

$$f = \frac{dF}{d+F} = \frac{\frac{x}{n} \left( -\frac{R}{n-1} \right)}{\frac{x}{n} - \frac{R}{n-1}} = -R \frac{x}{x(n-1)-nR}.$$

图像移动的速度在时间上被确定为任意的：

$$v = \frac{df}{dt} = -R \frac{x(n-1)-nR-(n-1)x}{\left(x(n-1)-nR\right)^2} \frac{dx}{dt} = R^2 \frac{n}{\left(x(n-1)-nR\right)^2} \frac{dx}{dt}.$$

让我们写下关卡的速度：

$$\mu = -\frac{dm}{dt} = -\rho \frac{dV}{dt} = -\rho \pi R^2 \frac{dx}{dt},$$

$$\frac{dx}{dt} = -\frac{\mu}{\rho \pi R^2}.$$

结果我们得到

$$v = R^2 \frac{n}{\left(x(n-1)-nR\right)^2} \left( -\frac{\mu}{\rho \pi R^2} \right).$$

现在我们来确定图像的坐标及其在$x = R$处的运动速度：

$$f = R, \quad v = -n \frac{\mu}{\rho \pi R^2}.$$

我们来总结一下。最小图像 ($F = \frac{R}{n-1} = 3R, d = \frac{3}{4}R$)。图像坐标与源坐标一致。图像速度是水平移动速度$n$倍。一个美丽的结果，这是由于半球的光学特性。
