M2830。输入是面值为 a 和 b dyblons 的硬币，其中 a 和 b 是给定的相互观察的自然数，其中 $a < b < 100$。如果使用不超过 1000 个硬币可以收集到 n 个 dybloons 的总和，则非负整数 n 称为远程。查找远程号码的数量。

答案：$1001b - \frac{b(b-1)}{2}$。

如果该套装至少使用了 b 个 dybloons 的硬币，我们可以用 a 枚 b dybloons 的硬币替换它们。在这种情况下，面额数量不会改变，但硬币总数会减少。因此，从任何一组此类替换中，都可以获得相同数量的一组，其中不超过 $(b-1)$ 个 dyblon 硬币。因此，进一步我们只考虑其中有 0 到 $b-1$ 个 dyblon 硬币的集合。

请注意，具有不同数量的硬币和 dyblon 的选项显然会给出不同的金额，因为它们除以 b 时具有不同的余额。 （事实上​​，如果 $0 \leq i < j \leq b-1$ 是 dybloons 上的硬币数量，那么相应的总和除以 b 会得到与 $ia$ 和 $ja$ 相同的余数。但是 $ja-ia = (j-i)a$ 不能被 b 整除，因为 a 和 b 是互质的，a $0 < j-i < b$。

让我们用 dybloons 来固定 k 个硬币的数量。然后你可以向其中添加 0,1,...,1000-k 个 b dyblon 硬币，显然，所有得到的金额都会不同。我们看到对于给定的 k，我们有 $(1001-k)$ 个选项。

对$k = 0,1,...,b-1$求和，我们得到选项总数：

$$1001 + (1001-1) + (1001-2) + \dots + (1001-(b-1)) = 1001b - (1+2+\dots+(b-1)) = 1001b - \frac{b(b-1)}{2}.$$

由于过程2-1是任意选择的（对条件中指定的热量供应和温度变化进行限制），$Q_{132}$的值对应于在这种转变期间可以提供的热量的最大值。类似地，可以看出，最小可能热量对应于气体首先从状态1等温膨胀到状态4，然后经历绝热膨胀，从状态4移动到状态2的过程。
让我们用另一种方式——使用熵的概念来分析过程$A$和$B$的本质。过程$A$和$B$以这样的方式进行：在整个过程中气体的温度不降低并且热量不从气体中带走，这意味着这些过程中的熵不能降低。提供的热量$\delta Q$和熵的变化$dS$之间存在以下关系
$$\delta Q = TdS.$$

过程$A$以最大可能的热量输入进行，这意味着在此过程中所有热量输入必须在最大可能的温度下传递，这对应于气体首先从状态1等温压缩到状态3，然后等温膨胀，从状态3移动到状态2的过程。过程$B$以尽可能最小的热量输入进行，这意味着在此过程中提供的所有热量必须在尽可能最低的温度下传递，之后系统必须在没有供热的情况下转移到状态2。这对应于气体首先从状态 1 等温膨胀到状态 4，然后绝热膨胀，从状态 4 移动到状态 2 的过程。
让我们继续计算点 3 和点 4 对应的体积。绝热过程中连接变量 $T$ 和 $V$ 的方程具有以下形式
$$TV^{\gamma-1} = \text{const},$$
其中 $\gamma$ 是 adinabata 指标。在单原子理想气体的情况下，$\gamma = 5/3$和$TV^{2/3} = \text{const}$。对于进程$A$
$$TV^{2/3} = 2T\left(V_{A}^{\min}\right)^{2/3}, V_{A}^{\min} = \frac{V}{2\sqrt{2}}.$$
显然$V_{A}^{\max} = 2V$。对于进程$B$
$$2T \cdot (2V)^{2/3} = T\left(V_{B}^{\max}\right)^{2/3}, V_{B}^{\max} = 4\sqrt{2}V.$$
当然，$V_{B}^{\min} = V$。
这些过程中的热量是通过等温线提供的。等温过程中的热量等于气体所做的功。对于进程$A$
$$Q_{A} = 2vRT \ln \frac{V_{2}}{V_{3}} = 5vRT \ln 2,$$
对于进程$B$
$$Q_{B} = 2vRT \ln \frac{V_{4}}{V_{1}} = \frac{5}{2}vRT \ln 2.$$
