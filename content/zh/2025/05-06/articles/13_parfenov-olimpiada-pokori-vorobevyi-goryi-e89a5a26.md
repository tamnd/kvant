4. 有8只蚂蚁。

3. 该任务是一个部分开放模型的任务。在分析冲击时，我们必须尽量考虑部分变形和内容时间的小，这使得我们可以忽略所有有限力冲击期间对物体的作用。因此，我们只需要考虑非常大的力——反作用力。考虑到所有物体的首要条件，我们得出的结论是，这些是法向反作用力 - 杆之间 $N_1$ 以及水平杆与表面 $N_2$ 之间。撞击后垂直杆运动的性质表明，垂直杆与表面之间的反作用力仍然有限。法向反作用力总是在这些表面上重新分布，并且可以在冲击过程中发生变化，以满足接触体运动过程中出现的连接条件。反作用力连接条件的具体类型取决于物体的弹性属性，并且在所提出的问题中存在不同的物体。杆的弹性特性是相同的，但表面的弹性特性可能与它们不同：使我们能够得出关于弹性特性对应关系的结论的条件中的唯一信息包含在“杆的变形非常小，但同时比表面的变形大得多”这句话中。这使我们可以假设表面材料的刚度远大于杆材料的刚度，因此力变化过程$N_2$比$N_1$快得多。然后我们得出的结论是，在撞击过程中，变化$N_2$调整为变化$N_1$，使得与水平杆点的非常小的位移相比，表面点的位移可以忽略不计。 Pozny，在我们的模型框架内，我们假设水平杆与表面分离之前，该杆与表面接触点的垂直分量应保持为零（尽管由于力$N_2$的作用，该杆质心速度的垂直分量应向上）。

在撞击过程中，垂直杆上作用有一个“非常大”的力 - 水平杆一侧的法向反作用力 $N_1'$ (图 18)。从冲击的几何形状可以立即清楚地看出，该力相对于垂直杆的质心的力矩不为零，并且该杆在冲击后开始逆时针旋转。在这种冲击开始期间（转弯开始之前），杆之间的法向反作用力必须沿着它们的接触表面重新分布，以便它们集中在水平杆上边缘与垂直杆上边缘的接触点处。因此，如果$N_1$是冲击时间$\Delta t$期间杆之间相互作用力的平均值，则冲击后质心速度和垂直杆的旋转角速度满足关系式

$$mv_1 = N_1 \Delta t, I \omega_1 = l N_1 \Delta t.$$

这里$m$是每根杆的质量，穿过质心的水平旋转轴每侧的转动惯量为$I = \frac{1}{12} m \left( a^2 + L^2 \right) = \frac{53}{48} ma^2$，肩部反力为$l = \frac{L}{2} - a = \frac{3}{4} a$。

水平杆用

$$mv_{2x} = mv_0 - N_1 \Delta t, mv_{2y} = N_2 \Delta t, I \omega_2 = \frac{a}{2} N_1 \Delta t - \frac{L}{2} N_2 \Delta t.$$

如您所见，该杆与表面的接触点的连接条件

$$v_{2y} - \omega_2 \frac{L}{2} = \left( \frac{N_2}{m} - \frac{L}{2I} \left( \frac{a}{2} N_1 - \frac{L}{2} N_2 \right) \right) \Delta t = 0$$

只能通过撞击后沿图所示方向旋转水平杆来完成，它给我们带来了非常大的反作用力：

$$N_2 \left( 1 + \frac{mL^2}{4I} \right) - N_1 \frac{maL}{4I} = 0,$$

$$N_2 = \frac{maL}{4I + mL^2} N_1 = \frac{3aL}{a^2 + 4L^2} N_1 = \varepsilon N_1.$$

计算得出$\varepsilon = 0,21$。给定这种耦合条件，我们可以用冲击后垂直杆质心的速度来表达所有最终速度和角速度：

$$\omega_1 = \frac{ml}{I} v_1 = \frac{36}{53a} v_1, v_{2x} = v_0 - v_1,$$

$$v_{2y} = \varepsilon v_1 = \frac{21}{100} v_1, \omega_2 = \frac{2}{L} v_{2y} = \frac{4\varepsilon}{7a} v_1 = \frac{3}{25a} v_1.$$

将这些关系代入能量守恒定律

$$\frac{mv_0^2}{2} = \frac{m}{2} \left( v_1^2 + v_{2x}^2 + v_{2y}^2 \right) + \frac{I}{2} \left( \omega_1^2 + \omega_2^2 \right)$$

我们发现

$$v_1 = \frac{5300}{6809} v_0 \approx 0,778v_0.$$
