3. 令$P(x) = ax^2 + bx + c,$和$Q(x) = ux^2 + vx + w.$让在$k$和$m$分钟处画的直线相交于横坐标点$x_0$（和$p_k \neq p_m).$）这意味着$p_kx_0 + q_k = p_mx_0 + q_m,$或
$$x_0 = \frac{q_m - q_k}{p_k - p_m} = \frac{u(m^2 - k^2) + v(m - k)}{a(k^2 - m^2) + b(k - m)} = -\frac{u(k + m) + v}{a(k + m) + b}.$$ (1)

现在让在第$k$、第$m_1$和第$m_2$分钟绘制的直线相交于一点。请注意，方形三角形 $P(x)$ 最多属于每个值两次，因此不失一般性，我们可以假设 $p_k$ 与 $p_l$ 和 $p_m$ 不同。那么得到的公式意味着
$$\frac{u(k + m_1) + v}{a(k + m_1) + b} = \frac{u(k + m_2) + v}{a(k + m_2) + b}.$$ (2)

乘以分母并消去相似项，我们得到
$$(k + m_1)(ub - av) = (k + m_2)(ub - av),$$
在 $m_1 \neq m_2$ 意味着 $ub - av = 0.$ 因此，等式 (1) 一般对于所有值 $m_1$ 和 $m_2,$ 都成立，因此对于所有可能的值 $m_1$ 和 $m_2,$ 都满足等式 (2)，这意味着在任意时刻 $m_1$ 和 $m_2,$ 绘制的直线相交同一点的$k$条直线。

上述推理可能仅在$m,$时刻与$p_k = p_m.$时刻不相等，但是，由于我们已经知道所有其他直线相交于一点，所以我们现在也可以对其他三个时刻使用相同的推理，所需的时刻已经成立。
