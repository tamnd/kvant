由此我们得到$u_{n+1} = u_n/2 + 1/(2u_n)$，
那些。序列$u_n$是通过方程$x^2 - 1 = 0$的牛顿法得到的。
然而，无需任何计算就可以看出这一点。让我们对函数图 $f(x) = x^2 - a$ 使用系数 $a^{-1/2}$ 在所有方向上进行均匀滚动或拉伸。通过这种变换，图将变成函数$f_1(x) = x^2 - 1$的图，而牛顿法的几何描述不会改变：切线将变成切线。

因此，考虑$f_1$的牛顿法就足够了。从得到答案的角度来看，这并不有趣：我们已经知道 $\sqrt{1}$ 等于什么。但是，另一方面，如果我们设置 $a = 1$，牛顿法对于任意数字 $a$ 的收敛性质不会改变。

为了明确地将 $u_n$ 写为 $u_1$ 的函数，我们还需要进行一次替换。考虑转型

$$h(u) = \frac{u - 1}{u + 1},$$

它将方程 $f_1 = 0$ 的根“发送”到场和无穷大：$h(1) = 0$、$h(-1) = \infty$。让我们输入$v_n = h(u_n)$，然后

$$v_{n+1} = \frac{u_n + u_n^{-1} - 2}{u_n + u_n^{-1} + 2} = \frac{(u_n - 1)^2}{(u_n + 1)^2} = v_n^2.$$

在第一个等式中，我们使用了定义的$v_{n+1} = h(u_{n+1})$，以及$u_n$的循环对应关系；第二个等式是通过公式的简单等同变换获得的。

我们看到 $v_n$ 满足一个非常简单的循环对应关系

$$v_{n+1} = v_n^2.$$

知道了$v_1$，现在可以根据$n$轻松找到$v_n$，即$v_n = v_1^{2n-1}$。回到$u_n$和$x_n$，我们得到以下公式：

$$u_n = h^{-1} \left( h(u_1)^{2n-1} \right),$$

$$x_n = \sqrt{a} h^{-1} \left( h \left( x_1 / \sqrt{a} \right)^{2n-1} \right).$$

这里$h^{-1}$表示变换$h$的逆变换，即具有以下属性的变换：如果您先应用$h$，然后应用$h^{-1}$，或者先应用$h^{-1}$，然后$h$，您还将获得一个子变换。

当然，我们可以明确地写出$h^{-1}$的公式，并获得$x_n$的更明确的表达式（我们建议读者这样做）。然而，即使不进行任何计算，也不难注意到，无论是变换$h$的应用，还是均匀滚动或拉伸的应用，对于牛顿法连续迭代趋于极限值的速度都没有显着影响。首先，我们对$v_n$的特征和收敛速度进行估计，然后将该结果转移到序列$x_n$。

**定理。** 如果 $|v_1| < 1$，则序列 $v_n$ 超指数快速收敛到 0，即比任何几何切割都快。如果 $|v_1| > 1$，则序列 $v_n$ 会以超指数速度逃逸到无穷大。最后，如果$|v_1| = 1$，则序列$v_n$既不收敛于零，也不收敛于无穷大。

这就是从 $v_n$ 到 $x_n$ 时该定理得出的结果。

**推论。** 如果$x_1 > 0$，则序列$x_n$超指数快速收敛到$\sqrt{a}$，如果$x_1 < 0$，则序列$x_n$超指数快速收敛到$-\sqrt{a}$。并且仅当$x_1 = 0$时，序列$x_n$未定义（或者我们可以放入$x_2 = \infty$，并且所有后续项都可以等于$\infty$）。
