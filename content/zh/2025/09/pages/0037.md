看看 3 周期排列，即 $x, y, z, x, y, z, x, y, z, x,$ 形式的排列，其中 $x + y + z \leq 7$。但有了这样的安排就很容易理解了：
$$S = 4x + 3y + 3z \leq
\leq x + 3(x + y + z) \leq 5 + 3 \cdot 7 = 26.$$
例如，用$x = 5, y = 2, z = 0$获得$S = 26$的示例。

“解”中的第二部分是正确的：如果矩形$1 \times 3$中的所有和都彼此相等，则排列是3周期的。事实上，让距离为3的某对单元格包含数字$a$和$d$，并让它们之间的两个单元格包含数字$b$和$c$，即存在一个片段$a, b, c, d$；那么根据和$a + b + c = b + c + d$相等的条件，有$a = d$。然后通过 3 个周期的安排，就很容易弄清楚了。

但根据最初的推理（简化为3周期排列）肯定有问题......首先，让我们做一个应该已经建立的观察：有许多3周期排列，其中所有矩形$1 \times 3$中的总和等于7，但$S < 26$，甚至是非周期排列，其中任何三个连续的总和可以“战胜”这种排列，也有少于7个数字。最重要的是，短语“必须使矩形中的所有和$1 \times 3$最大可能”包含一个严重错误：3-周期性并不是达到最大值$S = 26$的必要条件。在下一个练习中，我们邀请读者寻找相关示例。

b) 非周期性排列，其中$S = 26$。

因此，在给定的“解决方案”中存在数学错误，纠正这些错误显然比“从头开始”解决问题 1a 更困难。顺便说一句，目前，当被要求提供问题 1a 的解决方案时，人工智能如果不够强大且训练有素，就会产生错误的推理，有点类似于“解决方案”中给出的推理。

然而，事实是，在问题1a的条件下，在最大总和$S$的排列中，有必要找到一个3周期的正确排列。现在我们将在更一般的情况下证明这个事实（见下面的问题1），但最重要的是，我们不仅仅是证明它，而是学习如何以特定的方式从任意排列中获得周期排列，而不违反问题的条件，也不减少总和$S$。这将是 A. Abzalov 提议的节奏。当然，如果没有这个，问题1很容易解决（类似于练习1），但是很快，当解决更困难的问题2和3时，我们将能够真正体会到这一步的用处。
