1) 在新的非周期排列中，任意矩形 1×a 中的数字之和将等于 x，这意味着新的排列是可接受的。

2) 现在让我们估算一下新安排的总金额。让我们分别对位于 xk+1, ..., xk+a 左侧的矩形 1×k 进行此操作（对于位于右侧的矩形，证明类似）。在原始排列中，前 k+a 个位置包含数字 x1、x2、...、xk+a。让我们用 y1, y2, ..., yk+a 表示新的 a 周期排列 (图 2) 中这些位置的数字。

将 k 除以 a 并得到余数：k = ta + r (0 ≤ r < a)。由于总和 x 最大，我们有

$$x_1 + \dots + x_a \leq x = y_1 + \dots + y_a$$
$$x_{a+1} + \dots + x_{2a} \leq x = y_{a+1} + \dots + y_{2a}$$
...,
$$x_{(t-1)a+1} + \dots + x_{ta} \leq x = y_{(t-1)a+1} + \dots + y_{ta}$$
$$x_{ta+1} + \dots + x_{ta+a} \leq x = y_{ta+1} + \dots + y_{ta+a}$$.

在最后一个等式中，我们删除了相同的弱项
xk+1 = yk+1, ..., xta+a = yta+a 然后我们添加所有等式。我们得到了我们需要的：

$$x_1 + \dots + x_k \leq y_1 + \dots + y_k$$.

引理1得到证明。
