这与我们在“一维”引理 1 中考虑的序列变换完全一致！这意味着我们已经知道（从引理 1 的证明），通过这样的变换，总和 $x_1 + x_2 + \ldots + x_B = S$ 不会减少。引理2得证。

因此，使用引理 2，我们转向了一种新的可接受的排列，它是 $b$ 水平周期性的。通过最终的排列，我们执行引理 2 中类似的“垂直”步骤，并获得垂直方向上 $a$ 周期的排列。但是，很容易看出，当执行第二步时，$b$水平周期性将被保留。因此，问题 2 的解决方案的主要部分——还原为 $(a,b)$ 周期排列——已经完成。

仅针对$(a,b)$-周期性可接受的安排，仍然需要找到总和$S$的最大值。让我们通过一个具有特定参数值的示例（如图 4）来看看，这并不困难。

例子。让$A = 9, B = 11, a = 2, b = 3, m = 3, s = 10$。

设前两行和前三列的交点处有一个数字$x_{11}, x_{12}, x_{13}, x_{21}, x_{22}, x_{23}$，则所有单元格中的数字都根据$(2,3)$周期性确定。我们看到表中$x_{11}$和$x_{12}$出现$5 \cdot 4 = 20$次，$x_{13}$出现$5 \cdot 3 = 15$次，$x_{21}$和$x_{22}$出现$4 \cdot 4 = 16$次，$x_{23}$出现$4 \cdot 3 = 12$次。然后

$$S = 20x_{11} + 20x_{12} + 16x_{21} +$$

$$+ 16x_{22} + 15x_{13} + 12x_{23}.$$

(*)

$$A = 9, B = 11, a = 2, b = 3, m = 3, s = 10$$

该表达式必须在约束 $0 \leq x_{ij} \leq 3$ 和 $x_{11} + x_{12} + x_{13} + x_{21} + x_{22} + x_{23} \leq s = 10$ 下最大化。这已经很清楚了：总和 $s = 10$ 必须是“分布式”的，按照和 (*) 中系数的降序排列变量的最大可能值。具体来说，在我们的例子中，最大 $S$ 在 $x_{11} = x_{12} = 3, x_{13} = x_{23} = 0$ 和 $x_{21} + x_{22} = 4$ 处实现（这 4 如何在 $x_{21}$ 和 $x_{22}$ 之间分配并不重要，因为总和 (*) 中的系数对于它们来说是相等的；例如，$x_{21} = x_{22} = 2$ 或 $x_{21} = 3, x_{22} = 1$）。所以$S$的最大值是184。

练习 8. 在问题 2 中，结合引理 2 的表转换，您可以尝试执行以下操作：

选择总和最大的矩形$a \times b$，并从该矩形开始继续排列数字$(a,b)$-句点。举例说明这样的变换可以减少总和$S$（即这样的变换对解不起作用）。
