屏幕亮度将增加的积分。对于还使用以下值的计算：
$F = 4$米，$\lambda = 650$纳米，$D = 5$厘米。
蓝色，原来的线是理想的：它具有数学特性（来自一个源的光线，通过其不同点的乘积，同时到达一个新的交点），并且当通过其焦点时，光波改变为$\pi$。所有不直接从光源落到半线上的光线形成光阑。

透镜的每一半都会产生一个图像 (图 2)，可以使用薄透镜公式找到到该图像的距离。令 $l -$ 为所需距离，然后根据等式
$$\frac{1}{F} = \frac{1}{d} + \frac{1}{f} \text{ и } l = d + f$$
我们得到
$$l = \frac{d^2}{d - F}.$$
从光源到镜头上半部和下半部图像的距离 $l_1$ 和 $l_2$ 相等
$$l_1 = \frac{16F}{3} \text{ и } l_2 = 4F.$$
对于 $L_1 = 3F$ 和 $L_2 = 6F$，光束位于主光轴的相对两侧，因此均匀照明的图像以两个不同半径的半圆 (图 3) 的形式出现在屏幕上，

图 3

其大小可以通过考虑相似的三角形来获得。在这两种情况下，下半圆的半径都小于上半圆的半径。对于$L_1 = 3F$，半径比为
$$\frac{r_B}{r_H} = \frac{l_1 - L_1}{l_1 - d_1} \frac{l_2 - d_2}{l_2 - L_1} = \frac{7}{6},$$
对于 $L_2 = 6F -$
$$\frac{r_B}{r_H} = \frac{L_2 - l_2}{l_2 - d_2} \frac{l_1 - d_1}{L_2 - l_1} = 6.$$
当将屏幕从距离$2F$向右移动时，很容易注意到在某个位置，半圆的半径将在$2F$到$l_2$的范围内重合。
所需距离$L_3$由反映三角形两个相似系数相等的比例求得：
$$\frac{l_1 - d_1}{L_3 - d_1} = \frac{l_2 - d_2}{L_3 - d_2},$$
$$L_3 = \frac{d_2 l_1 - d_1 l_2}{l_1 - l_2 - d_1 + d_2} = \frac{8F}{3}.$$
如果将屏幕固定在距光源 $L_4 = 40F/9$ 的位置，则来自半线的光束在屏幕的上半平面中彼此完全重叠。
光源$S$在位置$l_1$和$l_2$的图像可以被视为两个有限辅助光源$S_1$和$S_2$，由于光波通过$S_1$处的焦点，它们在主光轴上的交点处的相位相差$\pi$。因此，在半圆的中心有一个黑点（图4）。
