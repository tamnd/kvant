3. 倒水后，右膝盖的空气被压缩，所以大量的空气停留在$x$的高度。本表中的气压$p_x$可根据波义耳-马里奥特定律求得
$$p_a(hS) = p_x(xS).$$
现在我们将在距离底部 $h - x$ 的高度（空气从右弯头开始）处缝合管子不同弯头中的压力相等，用压力 $p_x$ 代替：
$$p_a + \rho gx = p_a \frac{h}{x}.$$
从这里我们会发现
$$x = \left(-2 \pm 2\sqrt{2}\right)h.$$
我们选择正根（列的大小不能为负）。压缩空气从下方压在塞子上，大气从上方压在塞子上。推动插头的合力等于
$$F_{\text{вытт}} = \left(p_a + \rho gx - p_a\right)S = \rho gxS = 2\rho ghS\left(\sqrt{2} - 1\right).$$
为了承受软木塞的冲击力，你需要用力
$$F = F_0 - F_{\text{вытт}} = F_0 - 2\rho ghS\left(\sqrt{2} - 1\right).$$
如果该值小于零，插头会自行飞出。
4. 活塞将环分成两个独立的部分。让我们在初始位置表示上段$p_1$、下段$p_2$的压力，在最终位置表示上段$p'_2$、下段$p'_1$的压力。在初始位置，作用在每个活塞上的压力差通过沿管方向的重力投射来补偿：
$$(p_2 - p_1)S = mg\sin 30^\circ.$$
在最终位置，作用在每个活塞上的压力差由重力补偿：
$$(p'_1 - p'_2)S = mg.$$
从为每个部分编写的波义耳-马里奥特定律，我们得到
$$p'_1 = \frac{(5/6)}{(3/6)}p_1 = \frac{5}{3}p_1, p'_2 = \frac{(1/6)}{(3/6)}p_2 = \frac{1}{3}p_2.$$
从这里我们会发现
$$p'_1 = \frac{35}{24}\frac{mg}{S}.$$
5. 令点 $A$ 与地面的距离为 $L_1$。只有地板和点 $A$ 之间的绳索部分被拉伸。这部分绳索的刚度等于
$$k_1 = k\frac{L_0}{L_1},$$
该部分的最大伸长率为
$$\Delta x = L_0 - L_1.$$
权重跳出答案的条件有以下形式
$$F_{\text{тр}} + mg = F_{\text{упр}} = k_1\Delta x = k\left(L_0/L_1\right)\left(L_0 - L_1\right),$$
从这里开始，考虑到 $F_{\text{тр}} = 3mg$，我们得到
$$L_1 = \frac{kL_0^2}{4mg + kL_0}.$$
绳索在斜坡上不起作用，因此重物的最大举升高度$H$由能量守恒定律可求得
$$mgH = k_1\frac{\Delta x^2}{2}.$$
最后我们得到
$$H = \frac{8mgL_0}{4mg + kL_0}.$$
如果$kL_0 \geq 4mg$，该公式有效，否则$H = L_0$。

| 阴谋 | 角度尺寸 | 长度$L$ | 体积$V = SL$ | 压力 |
| :--- | :--- | :--- | :--- | :--- |
| 1 | $60^\circ = \frac{\pi}{3}$ | $L_1 = \frac{\pi a}{3}$ | $V_1 = \frac{\pi a S}{3}$ | $p_1$ |
| 2 | $300^\circ = \frac{5\pi}{3}$ | $L_2 = \frac{5\pi a}{3}$ | $V_2 = \frac{5\pi a S}{3}$ | $p_2$ |

$$p_1V_1 = p_2V_2 = p_0(\pi aS),$$
