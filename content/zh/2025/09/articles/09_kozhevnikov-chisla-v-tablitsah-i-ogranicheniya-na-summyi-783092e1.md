“解”中的第二部分是正确的：如果矩形$1 \times 3$中的所有和都彼此相等，则排列是3周期的。事实上，让距离为3的某对单元格包含数字$a$和$d$，并让它们之间的两个单元格包含数字$b$和$c$，即存在一个片段$a, b, c, d$；那么根据和$a + b + c = b + c + d$相等的条件，有$a = d$。然后通过 3 个周期的安排，就很容易弄清楚了。

但根据最初的推理（简化为3周期排列）肯定有问题......首先，让我们做一个应该已经建立的观察：有许多3周期排列，其中所有矩形$1 \times 3$中的总和等于7，但$S < 26$，甚至是非周期排列，其中任何三个连续的总和可以“战胜”这种排列，也有少于7个数字。最重要的是，短语“必须使矩形中的所有和$1 \times 3$最大可能”包含一个严重错误：3-周期性并不是达到最大值$S = 26$的必要条件。在下一个练习中，我们邀请读者寻找相关示例。

给定一个自然数$N$。在立方体 $(2N + 1)^3$ 的单位杯中，数字 0 或 1 被排列，使得在任何立方体 $2 \times 2 \times 2$ 中，数字的总和不超过 4。所有数字的最大和 $S$ 是多少？

这几乎是问题 3 的一个特例，不同之处在于，在任务 3 中，我们允许排列给定段中的实数，但这里仅是来自有限集 $\{0,1\}$ 的数字。但这从根本上不会改变任何东西：如果离散集$\{0,1\}$被段$\{0;1\}$替换，那么估计中的推理保持不变，并且在最佳示例中，数字仍然是整数：0或1。

因此，在这个问题中，与任务 3 一样，我们表明只能针对 $(2,2,2)$ 周期性排列来寻找 $S$ 的最大值。为了画布，我们用$(2,2,2)$周期安排来进行充分的推理并得到答案。

令角杯$2 \times 2 \times 2$中的$(2,2,2)$周期排列值等于数字$x_{ijk}$，其中$i, j, k$是三个方向的层数，$i,j,k \in \{1,2\}$（这8个数字完全决定了$(2,2,2)$周期排列）。我们看到$x_{111}$在一个大立方体中出现了$(N + 1)^3$次，$x_{211}, x_{121}, x_{112}$出现了$N(N + 1)^2$次，$x_{221}, x_{122}, x_{212} - \text{по } N^2(N + 1)$次，最后，$x_{222}$出现了$N^3$次。然后我们最大化线性表达式

$$S = (N + 1)^3 x_{111} +$$

$$+ N(N + 1)^2 (x_{211} + x_{121} + x_{112}) +$$

$$+ N^2(N + 1)(x_{221} + x_{122} + x_{212}) + N^3x_{222}$$

在给定的限制下：所有变量都来自$[0;1]$段，并且它们的总和不超过4。该表达式中的系数排序如下：

$$(N + 1)^3 > N(N + 1)^2 > N^2(N + 1) > N^3,$$

姿势$S$达到最大值

$$S = (N + 1)^3 + 3N(N + 1)^2$$

在

$$x_{111} = x_{211} = x_{112} = x_{121} = 1,$$

$$x_{221} = x_{122} = x_{212} = x_{222} = 0.$$
