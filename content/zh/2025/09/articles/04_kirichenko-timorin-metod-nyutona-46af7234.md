如何在没有计算器的情况下将数字$\sqrt{2}$数到小数点后十位

阿里斯托马科斯是毕达哥拉斯的传奇学生。正是他发现了二的根是无理数。就古希腊术语而言，他的结果更接近于几何而不是代数。他发现正方形的对角线和它的边不成比例。这一不幸的发现终结了毕达哥拉斯关于世界由自然数统治的最初想法。据传说，由于这种对基础的颠覆，阿里斯托马科斯被他的毕多哥拉斯学友私刑处死。这一情节在马尔可夫·奇科特最近的历史侦探小说《杀死毕达哥拉斯》中得到了意想不到的诠释。奥比亚-

让我们从上面和下面最明显的评级开始：$1 < \sqrt{2} < 2$。 Markov Chikota 的 Aristomakh 从 7/5 开始，但这并不是最明显的近似值 - 要得到它，您已经需要计算一些东西。基本思想是这样的：如果已经获得了两个近似值，一个来自上方，一个来自下方，那么我们就可以采用我们所得到的结果，并希望通过这种方式我们能够获得更好的近似值。换句话说，如果$a < \sqrt{2} < b$，那么下一个近似值将是$\frac{a+b}{2}$。下一个近似值 - 让我们用 $c$ 表示它 - 从一侧（从上方或下方）接近根，但 $2/c$ 是从另一侧的近似值。因此，如果我们从一对数字$\{a, b\}$开始，两边都逼近数字$\sqrt{2}$，那么下一对就可以取$\left\{\frac{a+b}{2}, \frac{4}{a+b}\right\}$，一般来说，这个新的近似值比旧的更好。例如，如果最初是$ab = 2$，那么我们用它们的参数均值和调和平均值替换数字$a$和$b$：两个均值都位于线段$[a;b]$上，因此我们获得更小的线段$[a';b']$，仍然包含所需的根。此外，对应关系$ab = 2$是可解释的，即重复相同的过程，直到近似的质量令人满意。

现在让我们讨论一种更通用的方法来寻找某些方程的解的逐次逼近，刚刚已经写出了该方程的一个特殊情况。该方法属于艾萨克·牛顿，并以他的名字命名：牛顿法。

让我们想要找到方程 $f(x) = 0$ 的解 $x_0$，并得到所需根 $x_0$ 的初始近似值 $x_1$。一般来说，只有当我们对初始近似值进行足够好的猜测时，该方法才有效。如果函数 $f$ 可微，则在点 $x_1$ 附近，值 $f(x)$ 可以写为

$$f(x) = f(x_1) + f'(x_1)(x - x_1) + \ldots,$$

其中$f'(x_1)$是点$x_1$的乘积，多项式表示与$x - x_1$相比较小的项。

考虑 $x$ 的线性函数

$$g(x) = f(x_1) + f'(x_1)(x - x_1).$$

在数学分析过程中，证明该函数在点 $x_1$ 的邻域内比所有其他线性函数更好地逼近函数 $f$。该函数的系数$f(x_1), f'(x_1)$是依赖于$x_1$的数字，但不依赖于$x$。因此，导数 $f'(x_1)$ 是最佳线性近似的斜率。

牛顿法的思想很简单，就像一切天才一样。函数 $f$ 可能非常复杂 - 复杂到人们甚至不清楚如何求解方程的显式解。另一方面，任何线性方程都不难显式求解，并且函数 $f$ 可以在一定精度下用其线性近似代替。例如，如果在第$n$步已经获得了下一个近似值$x_n$，那么下一步应该是将非线性方程$f(x) = 0$替换为线性方程

$$f(x_n) + f'(x_n)(x - x_n) = 0.$$

如果 $x_n$ 接近 $x_0$，则后者足够接近前者。我们用 $x_{n+1}$ 表示线性方程的解，并根据相同的方案继续该过程。我们得到满足递推关系的序列$x_n$

$$x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)}.$$

让我们用 $N_f$ 表示由公式定义的函数

$$N_f(z) = z - \frac{f(z)}{f'(z)}.$$

该函数取决于$f$，这反映在符号中； $f$称为`отображением Ньютона`。借助牛顿法，找到方程根 $f(x) = 0$ 的近似值表明重复应用相同的运算

$$z \mapsto N_f(z).$$

如果函数$f$由一个简单的公式给出，那么$N_f$并不太复杂。让我们把它放在一起

为什么以及如何工作

让我们更详细地讨论牛顿法，因为它适用于求给定精度的平方根。也就是说，我们想要了解在 $n$ 步中我们距离所需的根有多近。对于任意动作非负值 $a$，我们将考虑左侧 $f(x) = x^2 - a$ 的方程。函数$f(x)$的图像是抛物线。它与 $x$ 轴相交于两点，或者，如果是 $a = 0$，则相交于一个多重点。牛顿法允许以下几何描述。让我们从任意点 $x_1$ 开始。让我们在点 $(x_1; f(x_1))$ (图 1) 处绘制函数 $f(x)$ 的图像的切线。让我们用 $x_2$ 表示转变点

与轴 $x$ 相切的部分，然后对 $x_2$ 和 $x_1$ 重复相同的操作。作为所描述的迭代过程的结果，将获得点$x_1, x_2, \dots, x_n$...的序列。

如果我们从所需根的右侧开始，即从点$x_1 > \sqrt{a}$开始，那么点$x_n$的序列随着$n$的增加而单调杀死，这与牛顿法的几何描述非常相似。如果初始点$x_1$位于区间$(0; \sqrt{a})$上，那么首先我们得到点$x_2 > \sqrt{a}$，然后是单调递减序列$x_2, x_3, \dots$。因此，在初始值$x_1$选择为正的所有情况下，序列$x_n$的项从第二项开始越来越接近所需的根。我想更准确地估计从$x_n$到$\sqrt{a}$的距离。为此，请考虑序列 $u_n = x_n / \sqrt{a}$。知道了序列$x_n$是如何求值的，我们就可以找到$u_n$的递推关系。事实上，本例中的牛顿图 $N_f(z)$ 具有以下形式

$$N_f(z) = z - \frac{z^2 - a}{2z} = \frac{z}{2} + \frac{a}{2z},$$

方法，

$$x_{n+1} = \frac{x_n}{2} + \frac{a}{2x_n}.$$

因此，考虑$f_1$的牛顿法就足够了。从得到答案的角度来看，这并不有趣：我们已经知道 $\sqrt{1}$ 等于什么。但是，另一方面，如果我们设置 $a = 1$，牛顿法对于任意数字 $a$ 的收敛性质不会改变。

为了明确地将 $u_n$ 写为 $u_1$ 的函数，我们还需要进行一次替换。考虑转型

$$h(u) = \frac{u - 1}{u + 1},$$

它将方程 $f_1 = 0$ 的根“发送”到场和无穷大：$h(1) = 0$、$h(-1) = \infty$。让我们输入$v_n = h(u_n)$，然后

$$v_{n+1} = \frac{u_n + u_n^{-1} - 2}{u_n + u_n^{-1} + 2} = \frac{(u_n - 1)^2}{(u_n + 1)^2} = v_n^2.$$

在第一个等式中，我们使用了定义的$v_{n+1} = h(u_{n+1})$，以及$u_n$的循环对应关系；第二个等式是通过公式的简单等同变换获得的。

我们看到 $v_n$ 满足一个非常简单的循环对应关系

$$v_{n+1} = v_n^2.$$

知道了$v_1$，现在可以根据$n$轻松找到$v_n$，即$v_n = v_1^{2n-1}$。回到$u_n$和$x_n$，我们得到以下公式：

$$u_n = h^{-1} \left( h(u_1)^{2n-1} \right),$$

$$x_n = \sqrt{a} h^{-1} \left( h \left( x_1 / \sqrt{a} \right)^{2n-1} \right).$$

这里$h^{-1}$表示变换$h$的逆变换，即具有以下属性的变换：如果您先应用$h$，然后应用$h^{-1}$，或者先应用$h^{-1}$，然后$h$，您还将获得一个子变换。

当然，我们可以明确地写出$h^{-1}$的公式，并获得$x_n$的更明确的表达式（我们建议读者这样做）。然而，即使不进行任何计算，也不难注意到，无论是变换$h$的应用，还是均匀滚动或拉伸的应用，对于牛顿法连续迭代趋于极限值的速度都没有显着影响。首先，我们对$v_n$的特征和收敛速度进行估计，然后将该结果转移到序列$x_n$。

**定理。** 如果 $|v_1| < 1$，则序列 $v_n$ 超指数快速收敛到 0，即比任何几何切割都快。如果 $|v_1| > 1$，则序列 $v_n$ 会以超指数速度逃逸到无穷大。最后，如果$|v_1| = 1$，则序列$v_n$既不收敛于零，也不收敛于无穷大。

这就是从 $v_n$ 到 $x_n$ 时该定理得出的结果。

**推论。** 如果$x_1 > 0$，则序列$x_n$超指数快速收敛到$\sqrt{a}$，如果$x_1 < 0$，则序列$x_n$超指数快速收敛到$-\sqrt{a}$。并且仅当$x_1 = 0$时，序列$x_n$未定义（或者我们可以放入$x_2 = \infty$，并且所有后续项都可以等于$\infty$）。

平方结尾为 987654321 的数字

考虑以下问题：找到一个自然数$k$，使得数字$k^2$的十进制表示法的最后9位数字是987654321。在这个问题中，你可以猜测答案，然后从一般消息中证明它的合理性，但我们会更加系统地采取行动，并且我们考虑的方法不仅适用于这组特定的数字。考虑到算术领域的问题，它似乎与一般的近似计算主题，特别是牛顿法无关。但它是有联系的，而且是最直接的。你只需要创造性地解释“近似”这个词。

接近是一个与“接近”同根的词。一般来说，如果两个数字的十进制开头有许多相同的数字，则两个数字很接近。我们需要对接近度有一个非标准的理解：如果两个自然数的十进制展开式有许多相同的数字，即（相同）如果两个给定数字的差可以被更大的 10 次方整除，则两个自然数是接近的。然后，所提出的问题可以重新表述如下：找到一个自然数$k$，其十进制平方接近于数字$b = 987654321$。

当我们尝试使用牛顿法近似求方程$x^2 - a = 0$的根时，我们实际上是在做以下任务：找到平方接近通常意义上的$a$的数字$x$。现在我们想要找到在十年意义上平方接近 $b$ 的数字 $k$。因此，两个问题之间的类比是可见的，我们可以尝试找到算术问题的类似解决方案。

您需要从一些近似值开始，例如，从平方以 1 结尾的数字开始。在我们的例子中，我们可以采用 $k_1 = 1$。接下来，我们将寻找下一个近似值 $k_2$，以便 $k_1 - k_2$ 可以被 10 整除，从而使数字 $k_2^2$ 为 21。让我们将 $k_2$ 写为 $k_1 + 10m_1$，然后

$$k_2^2 = k_1^2 + 20k_1m_1 + \dots,$$

其中省略号表示与已写内容相比的下一个小阶项（当然是十年意义上的！）。将此公式与展开式进行比较

$$f(x) = f(x_1) + f'(x_1)(x - x_1).$$

我们希望$k_2^2$接近21，因此要求满足$k_1^2 + 20k_1m_1 = 21$模100，即左右两边的差能被100整除。在我们的例子中，结果证明$20m_1 = 20$模100或$m_1 = 1$模5。例如，$m_1 = 1$适合我们。因此，下一个近似值是 $k_2 = 11$，这个数字的平方实际上以 21 为结束。所描述的过程与牛顿方法的类比应该是显而易见的。该过程可以继续：我们以 $k_2 + 100m_2$ 的形式查找 $k_3$，并要求模数满足等式 $k_2^2 + 200k_2m_2 = 321$

（部分规则写为$n$二），可以通过当前对应关系$x_{n+1} = 1 + \frac{1}{1 + x_n}$与初始条件$x_0 = 1$等价指定。为什么这个序列收敛到 $\sqrt{2}$ 以及收敛速度有多快？这可以使用上面描述的相同替换$v = \frac{x - \sqrt{2}}{x + \sqrt{2}}$来理解。替换的意义就是将根$x = \pm \sqrt{2}$送到$v = 0, \infty$，牛顿图写为$v \mapsto v^2$。序列$x_n$变成序列$v_n$，并且$x_n$上的当前匹配根据$v_n$重写如下：

$$v_{n+1} = \lambda v_n, \quad v_0 = \lambda, \quad \lambda = \frac{1 - \sqrt{2}}{1 + \sqrt{2}},$$

由此紧接着$v_n = \lambda^{n+1}$。数字 $\lambda$ 是负数，并且模小于一。这意味着序列 $v_n$ 以指数方式收敛到零，并且符号交替 - 这意味着 $x_n$ 以指数速率趋向于 $\sqrt{2}$，随着 $n$ 加一，值 $x_n - \sqrt{2}$ 不断改变符号。就变量$v$而言，牛顿映射的作用类似于平方，因此将$v_n$发送到$v_{2n+1}$——事实上，如果$v_n = \lambda^{n+1}$则$v_n^2 = \lambda^{2n+2} = v_{2n+1}$。返回到变量$x$，我们可以得出结论，在牛顿法的每次迭代中都达到了$N_f(x_n) = x_{2n+1}$，即二的数量。请注意，通过直接计算原始变量 $x$ 会更难以获得此结论。

该方程的度量：$x^2 + 1 = 0$。该方程不存在 $x$ 的实际值。看看牛顿方法在这种情况下的作用很有趣。牛顿法试图找到根，但没有根。结果是*混沌二帕米学*，即应用牛顿方法产生的点序列不显示任何明显的模式，但表现得好像是随机的。

用$f_{-1}(x)$表示$x^2 + 1$，我们制定了牛顿图$N = N_{f-1}$的一些性质。

• 可以选择一个初始值$x_1$，由相应的$x_{n+1} = N(x_n)$给出的循环序列$x_n$在角度方向上接近任何实数，即对于每个$a \in \mathbb{R}$和每个$\varepsilon > 0$，都有一个具有属性$a - \varepsilon < x_n < a + \varepsilon$的$n$。

• 对于每个自然数$m > 0$，都有一个初始值$x_1$，对于该初始值，序列$x_n$ 结果是周期为$m$ 的周期性序列，即$x_{n+m} = x_n$ 与所有$n \ge 1$。

如果$x_1$仅以一定的精度已知，那么对于大$n$，关于$x_n$就无话可说：任何给定点$c \in \mathbb{R}$的任何邻域，无论角度有多小，都将在整条线上的地图$N$的足够高迭代的作用下进行映射。

我们把这些性质的证明留给读者作为一个不太简单的练习。

从现在开始，我们从实数转向复数内的复数。求解复数方程很有用。此外，在复数平面中，上述大部分内容都得到了简化。例如，相同次数的实多项式可以有不同数量的根，而一些高次多项式（例如 100 次）根本没有根。复数多项式总是有根，并且它们的数量（包括重数）始终等于多项式的次数。这意味着，随着给定次数的多项式的系数平滑变化，其根可以合并（相互穿过），但不能凭空出现，也不能消失得无影无踪。 $d > 0$ 次多项式始终至少有一个根的说法称为“代数基本定理”。我们不会在这里讨论这个深层定理的证明，但请注意，考虑多重性的根数的陈述是它的一个简单结果。
