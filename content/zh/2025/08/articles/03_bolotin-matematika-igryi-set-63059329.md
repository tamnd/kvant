证明。考虑任意一对卡片。请注意，只有一张牌与给定的一对牌一起构成一组。让我们考虑一个任意的符号。如果前两张牌在此基础上一致，那么第三张牌也必须在此基础上与它们一致。例如，如果前两张牌是红色的，那么第三张牌也必须是红色的。如果前两张牌的此属性不同，则第三张牌的此属性也必须不同。例如，如果第一张牌是红色，第二张牌是蓝色，那么第三张牌一定是绿色。

因此，任何一对牌都可以唯一地扩展到一个集合，并且任何集合都是从三对中获得的。有$C_{81}^2$对不同的卡片，这意味着组数为
$$\frac{C_{81}^2}{3} = \frac{81 \cdot 80}{3 \cdot 2} = 1080.$$
请注意，三张不同卡牌的总组数
$$C_{81}^3 = \frac{81 \cdot 80 \cdot 79}{3!} = 85320.$$
那么集合的份额就是$\frac{1080}{85320} = \frac{1}{79} \approx 0,012658$，即七十九张特罗克牌中只有一张构成一个集合。

就足够了：在 21 张牌中，总有 3 张可以组成一组。 1971年，意大利数学家朱塞佩·佩莱格里诺证明了这一事实。但证明比较困难，所以这里不给出。

请注意，佩莱格里诺甚至在“Set”游戏被发明之前就证明了它的一些内容！事实上，类似的问题以前在数学中也曾独立出现过。

那么，让我们用数学形式化这个问题。让我们对数字 0, 1, 2 的每个特征的每个值进行编码。然后每张卡片可以表示为向量 $\vec{x} = (x_1; x_2; x_3; x_4)$，其中 $x_i$ 取值 0, 1, 2，而 $x_1$ 编码数量，$x_2$ – 图形，$x_3$ – 颜色，$x_4$ – 填充。现在您可以确定添加卡片了。也就是说，我们将对应于地图的两个坐标向量相加，模 3：
$$(x_1; \ldots; x_4) + (y_1; \ldots; y_4) = (x_1 + y_1 \pmod{3}; \ldots; x_4 + y_4 \pmod{3}).$$
纸牌的计算和纸牌乘以数字的定义类似。

陈述 3. 证明当 $\vec{x} + \vec{y} + \vec{z} = (0; 0; 0; 0)$ 时，$\vec{x}, \vec{y}, \vec{z}$ 卡片构成 Mogda 和 Molko Mogda 家族。检查该条件是否等同于以下两个条件：
$$\vec{x} + \vec{z} = 2\vec{y} \text{ и } \vec{y} - \vec{x} = \vec{z} - \vec{y}.$$
证明。让$\vec{x}, \vec{y}, \vec{z}$组成一个集合。让我们考虑第一个坐标 $x_1, y_1, z_1$。如果它们匹配，那么
$$x_1 + y_1 + z_1 \equiv 3x_1 \equiv 0 \pmod{3}.$$
如果它们都不同，那么
$$x_1 + y_1 + z_1 \equiv 0 + 1 + 2 \equiv 0 \pmod{3}.$$
其余坐标的推理类似，即$\vec{x} + \vec{y} + \vec{z} = (0; 0; 0; 0)$。
相反，设$\vec{x} + \vec{y} + \vec{z} = (0; 0; 0; 0)$。让我们看一下第一个坐标。假设它们之间存在巧合。不失一般性，我们假设$x_1 = y_1$。然后
$$z_1 \equiv 0 - x_1 - y_1 \equiv -2x_1 \equiv x_1 \pmod{3}.$$
那些。所有向量的第一个坐标都重合。因此，要么向量的第一个坐标重合，要么没有两个向量是相同的。其余坐标的推理类似。但这个条件意味着这些牌组成了一套。

等价
$$\vec{x} + \vec{y} + \vec{z} = (0; 0; 0; 0) \Leftrightarrow \vec{x} + \vec{z} = 2\vec{y}$$
$-1 \equiv 2 \pmod{3}$等于强度
$$\vec{x} + \vec{z} = 2\vec{y} \Leftrightarrow \vec{y} - \vec{x} = \vec{z} - \vec{y}$$
明显的。该说法已被证明。

请注意，最后一个条件意味着 $\vec{x}, \vec{y}, \vec{z}$ 形成算术级数。

目前已知的最佳下界约为 2.2202^n。
除了较低的估计之外，较高的估计也很有趣。正如我们所看到的，下界的阶数为 $c^n$，其中 $c$ 是某个常数。当然，估计的上限$r(n) \leq 3^n$（许多具有$n$特征的卡片，每个卡片只属于三个值）具有相同的形式。然而，在 1987 年，有人假设 $r(n) \leq c^n$，其中 $c < 3$。著名数学家陶哲轩称这个猜想是他最喜欢的开放问题。然而，获得的第一个上限估计如下所示：

$$r(n) \leq \frac{2 \cdot 3^n}{n}.$$

确保这样的分数低于$c^n$，其中$c < 3$。这一估计数次被改进，但直到 2016 年，上述假设才得到充分证明。目前已知的最佳上限约为 2.756^n。 $r(n)$ 的确切行为仍然是一个悬而未决的问题。

我们考虑的问题是加法组合学中的一个经典问题（来自英语addition -addition）。非正式地，加法组合学处理组合结构和加法结构之间的连接位置；有时这个系列中会添加乘法结构（来自英语乘法-乘法）。这些概念不是结构化的，但为了理解我们正在讨论的内容，让我们看一个例子。

自然数集是“加法”定义的：它的第一个元素等于 1，每个下一个元素都是前一个元素加 1。另一方面，凭借算术基本定理，大于 1 的自然数可以唯一地分解为素数的乘积。因此，从某种意义上说，素数形成了自然数的乘法结构，而每个数的大小（一的加法次数）形成了加法结构。混合加法和乘法结构通常会导致数学家多年来一直在思考的复杂问题。例如，出现以下问题：

• 关于乘法结构的加法问题：
  - 第 $n$ 个质数 $p_n$ 的大小如何表现？
  - 关于相邻素数之间的差 $p_{n+1} - p_n$ 你能说什么？

第一个问题涉及素数分布定理和黎曼假设，这是希尔伯特为数不多的未解决问题之一。关于第二个问题，直到2013年才证明了某个常数$C$的存在性，使得对于无数对$p_{n+1} - p_n \leq C$。后来证明，$C$可以等于246。著名的素孪生猜想说，$C = 2$也可以。

• 关于加法结构的乘法问题：
  - 如何将数字$n$分解为质因数？
  - 数字 $n$ 和 $n+1$ 的质因数分解有何关系？

第一个问题与算法理论有关。目前，还没有一个“足够快”的算法可以将数字分解为质因数。然而，有 Agrawal Kayal Saxena 测试，它可以让你“足够快地”检查一个数字是否是素数，还有一个量子（需要在量子套件上计算）Shor 算法，可以“足够快地”将一个数字分解为素数因子。第二个问题与科拉茨假设有关，埃尔多斯表示，数学家尚未准备好应对此类问题。

游戏“Set”表现为一个组合对象——我们研究了具有某些特征的卡片，这些特征具有不同的含义。然而，3已经表明，集合的形成问题可以用加法结构来提出。另一方面，我们也看到了纯粹的几何解释，其中集合在 Neokoto 空间中是直的。

一个简单的儿童游戏背后竟然隐藏着如此有趣且不同的数学！
