M2842。黑板上写着几个（多个）连续的自然数。罂粟有可能既是所有四个自然数的和又是所有四个自然数的和吗？

答：不可以。
设偶数个数字，即 $2k$ 个数字，从数字 $n$ 开始。那么条件中指定的两个和之一等于$S_1 = n + (n + 2) + \dots + (n + 2k - 2) = (2n + 2k - 2)k/2 = (n + k - 1)k$。另一个总和等于$S_2 = S_1 + k = (n + k)k$。
如果写入奇数个数字，即以数字 $n$ 开头的 $2k + 1$ 个数字，则其中一个和等于
$$S_1 = (n + 1) + (n + 3) + \dots + (n + 2k - 1) = (n + 1 + (n + 2k - 1))k/2 = (n + k)k.$$

其他金额相等
$$S_2 = n + (n + 2) + \dots + (n + 2k) = S_1 + n + k = (n + k)(k + 1).$$
无论哪种情况，商 $\frac{S_2}{S_1}$ 都等于两个连续自然数的比率 $\frac{m + 1}{m}$。如果我们假设 $S_1$ 和 $S_2$ 是完全平方数，我们将证明这是不可能的。令 $S_1 = m_1^2$、$S_2 = m_2^2$ 和 $\frac{u}{v}$ 为分数 $\frac{m_2}{m_1}$ 的不可约表示。
那么$\frac{u^2}{v^2}$是分数$\frac{m_2^2}{m_1^2} = \frac{S_2}{S_1} = \frac{m + 1}{m}$的不可约表示。由于分数$\frac{m + 1}{m}$是不可约的，$v^2 = m$和$u^2 = m + 1$必须满足，即两个连续的自然数是完全平方数，这是不可能的。
