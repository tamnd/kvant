我们找到任意两个端子之间电阻的一般公式：

所以，
$$R_{20} = \frac{2 \cdot 10}{20} \text{ Ом} = 1 \text{ Ом}.$$
问题7. 容量为$C_0 = 20$ µF 的电容器充电到$U_0 = 400$ V 的差值，并连接到容量为$C = 1$ µF 的电容器，结果后者被充电。断开 emton 电容器，以相同的方式在电容器 ($C = 1$ uF)、物体等之间使用第二个电容器充电。然后将电容器串联。以最大方式获得的最大差值是多少？

原电容的初始电荷为$q_0 = C_0 U_0$。连接第一个电容器后，电荷$q_0$将分布在电容器$C_0$和$C$之间。稀释后，公共电容器之间会产生电位差
$$U_1 = \frac{q_0}{C_0 + C} = \frac{C_0 U_0}{C_0 + C}.$$
容量为$C_0$的电容器上的剩余电荷等于
$$q_1 = C_0 U_1 = \frac{C_0^2 U_0}{C_0 + C}.$$
当给第二个电容充电时，公共电容（电容$C_0$和$C$）的方向变得相等
$$U_2 = \frac{q_1}{C_0 + C} = U_0 \left( \frac{C_0}{C_0 + C} \right)^2,$$
连接第三个电容器后 -
$$U_3 = U_0 \left( \frac{C_0}{C_0 + C} \right)^3.$$
明显地，
$$U_n = U_0 \left( \frac{C_0}{C_0 + C} \right)^n.$$
接下来，我们以无穷数的形式写出最大电势差的公式

由几何级数的成员组成的系列：
$$U = U_1 + U_2 + U_3 + \dots + U_n =$$
$$= U_0 \left( \frac{C_0}{C_0 + C} + \left( \frac{C_0}{C_0 + C} \right)^2 + \left( \frac{C_0}{C_0 + C} \right)^3 + \dots + \left( \frac{C_0}{C_0 + C} \right)^n \right).$$
总结这个几何级数，我们得到
$$U = \frac{C_0 U_0}{C} = 8000 \text{ В}.$$
任务8.墙后的声音（噪音）强度为10 W/m²（阈值更多是估计的）。该移位装置由具有声音治疗功能的材料制成。如果每 1 毫米材料的声强杀死 10%，那么墙壁的厚度应该是多少，才能使房间保持允许的声强率 $10^{-10}$ W/m²？

在心里将墙分成 1 毫米厚的层。经过第一层后，声音完整性为
$$I_1 = I_0 (1 - \beta),$$ 其中 $I_0 = 10 \text{ Вт/м}^2, \beta = 0,1.$
同理，通过第二层后
$$I_2 = I_1 (1 - \beta) = I_0 (1 - \beta)^2,$$
通过第三层后
$$I_3 = I_2 (1 - \beta) = I_0 (1 - \beta)^3.$$
然后对于第$n$层
$$I_n = I_0 (1 - \beta)^n.$$
从这里
$$n = \frac{\lg \frac{I_n}{I_0}}{\lg (1 - \beta)} = \frac{\lg 10^{-11}}{\lg (1 - 0,1)} \approx 240.$$
因此，所需壁厚为240mm。
