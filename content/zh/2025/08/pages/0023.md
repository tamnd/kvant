将$dr$的方程乘以2并与$dy$的方程相加，我们得到
$$2dr + dy = 0, \ 2r + y = \text{const.}$$

让我们计算运动开始时 ($r_A = l, y_A = 0$) 的这个常数，从 $r(y) = l - y/2$ 开始。在到达对岸的那一刻
$$y_B = l, \ r_B = \frac{l}{2}.$$

在$t_1$时刻，从几何角度考虑，我们可以写成$r \cos \alpha = l - y$。将依赖关系$r(y)$和此时角度$\alpha$的值代入，我们得到
$$\frac{1}{2}\left(l - \frac{y_1}{2}\right) = l - y_1, \ y_1 = \frac{2}{3}l, \ r_1 = \frac{2}{3}l.$$

为了确定轨迹的曲率半径，我们找到所需点的速度和加速度。相对于岸边的速度等于河中水的速度$\vec{u}$与船相对于水的速度$\vec{u}_{\pi}$之和：$\vec{v} = \vec{u} + \vec{u}_{\pi}$。平方后我们得到
$$v = \sqrt{\vec{u}^2 + \vec{u}_{\pi}^2} + 2(\vec{u} \cdot \vec{u}_{\pi}) =$$
$$= \sqrt{u^2 + 4u^2 + 4u^2} \cos \angle(\vec{u}, \vec{u}_{\pi}) =$$
$$= u \sqrt{5 + 4 \cos \angle(\vec{u}, \vec{u}_{\pi})}.$$

对于起点$\angle(\vec{u}, \vec{u}_{\pi}) = \pi$，则速度为$v_A = u$。在时间 $t_1$ 的时刻，该角度等于 $\pi - \alpha$，则速度等于 $v_1 = u\sqrt{3}$。

船的速度等于水和船相对于水的速度的矢量和。水流的速度无论大小还是方向都不会改变。船的速度并不改变大小，而是改变方向。船的速度矢量的模导数等于矢量$\vec{u}_{\pi}$的旋转角速度与该矢量的模的乘积。我们得到船的加速度的表达式：
$$\vec{a}_{a6c} = \frac{d}{dt}(\vec{u} + \vec{u}_{\pi}) = \frac{d\vec{u}}{dt} + \frac{d\vec{u}_{\pi}}{dt} = \vec{a}_{\pi},$$
$$a_{\pi} = 2u \cdot \omega_{\alpha} = 2u \frac{d\alpha}{dt}.$$

要找到任意角度 $\alpha$，需要将垂直于线段 $BC$ 的速度分量除以距离 $r$：
$$v_{\perp} = 2u - u \cos \alpha,$$
$$\frac{d\alpha}{dt} = \omega_{\alpha} = \frac{2u - u \cos \alpha}{r}.$$

在离开点$A$角度$\alpha = 0$的时刻，因此
$$\frac{d\alpha}{dt} = \frac{u}{l}, \ a_A = \frac{2u^2}{l}.$$

在时间$t_1$角度$\alpha = \pi/3$，这意味着
$$\frac{d\alpha}{dt} = \frac{3u/2}{2l/3} = \frac{9u}{4l}, \ a_1 = \frac{9u^2}{2l}.$$

在出发点，速度和加速度相互垂直，因此轨迹的曲率半径可以为：
$$R_A = \frac{v_A^2}{a_A} = \frac{l}{2}.$$

对于时间$t_1$，我们找到加速度在垂直于运动速度的方向上的投影，即在轴$x$上：
$$a_{1x} = a_1 \sin \alpha = \frac{9u^2 \sqrt{3}}{4l},$$

那么此时轨迹的曲率半径
$$R_1 = \frac{v_1^2}{a_{1x}} = \frac{4\sqrt{3}l}{9}.$$
