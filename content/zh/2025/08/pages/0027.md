沿 A₃ - A₁ 方向的电路链路将电路转换为自身，因此
$$\varphi_{A3} - \varphi_{B3} = \varphi_{A2} - \varphi_{B2} = \varphi_{A1} - \varphi_{B1} = \Delta\varphi,$$
还有
$$\varphi_{A4} - \varphi_{B3} = \varphi_{A3} - \varphi_{B2} = \varphi_{A2} - \varphi_{B1} = \Delta\varphi'.$$
让我们翻转链，以便节点 A₃ 和 B2，以及节点 A2 和 B₃ 交换位置 (图 3)。

图 3

既然链条已经传递到自身，那么
$$\varphi_{B2} - \varphi_{A2} = \varphi_{B3} - \varphi_{A3} = \varphi_{B4} - \varphi_{A4} = \Delta\varphi,$$
$$\varphi_{B1} - \varphi_{A2} = \varphi_{B2} - \varphi_{A3} = \varphi_{B3} - \varphi_{A4} = \Delta\varphi'.$$
由此可见
$$\Delta\varphi = -\Delta\varphi' = -\Delta\varphi',$$ 或
$$\Delta\varphi = 0 \text{ и } \Delta\varphi' = 0.$$
考虑到这一点，我们发现电动势为 ε 的电源系统产生的电势在电路的所有节点上都是相同的。
