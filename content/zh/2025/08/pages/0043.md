第三——深度
从第二次撞击点起$h_3 = v_3 t + \frac{gt^2}{2}$
等等。基于归纳推理，我们为物体速度的垂直分量写出以下值：
$v_1 = 0, v_2 = gt, v_3 = 2gt, \dots, v_n = (n-1)gt,$
其中 $n$ 是罢工次数。很明显
$h_1 + h_2 + \dots + h_n = H,$ 或
$(v_1 + v_2 + \dots + v_n)t + n \frac{gt^2}{2} = H.$
接下来我们依次
$(g + 2gt + 3gt + \dots + (n-1)gt)t + n \frac{gt^2}{2} = H,$
$gt^2 (1 + 2 + 3 + \dots + (n-1)) + n \frac{gt^2}{2} = H,$
...
$\frac{gt^2}{2} n (n-1) + n \frac{gt^2}{2} = H.$
从这里我们得到
$n = \sqrt{\frac{2H}{gt^2}} = \frac{v_0}{d} \sqrt{\frac{2H}{g}} \approx 90,3.$
由于罢工次数是自然数，则$n = 90$。身体会撞击裂缝的墙壁90次。
问题 3. 我们从 $h = 0,1$ 米的高度自由落体到一块与地平线成 $\alpha = 30^\circ$ 角的斜板上。我们通过跳跃沿着棋盘移动（图2）。考虑动作的力量和球击球板的十分之一。球与板的冲击力是绝对弹性的。
让我们找出第一次和第二次 ($L_{1,2}$)、第二次和第三次 ($L_{2,3}$)、第三次和第四次 ($L_{3,4}$) 次命中的点之间的距离。为了方便起见，我们将坐标轴沿着棋盘并垂直于棋盘 (图 3)。在这种情况下，$x$和$y$轴上的球加速度投影将分别相等
$a_x = g_x = g \sin \alpha$ 和 $a_y = g_y = -g \cos \alpha.$
球第一次与板碰撞时的速度为$v_0 = \sqrt{2gh}$。球第一次撞击后的初速度等于$v_0$，并与轴线$y$形成角度$\alpha$，球速度的投影相等
$v_{0x} = v_0 \sin \alpha$ 和 $v_{0y} = v_0 \cos \alpha.$
球第一次和第二次撞击板的点之间的距离为
$L_{1,2} = (v_0 \sin \alpha) t_1 + \frac{(g \sin \alpha) t_1^2}{2},$
其中$t_1$是球的飞行时间。这个时间由等式给出
$(v_0 \cos \alpha) t_1 - \frac{(g \cos \alpha) t_1^2}{2} = 0.$
从这里
$t_1 = \frac{2v_0}{g}$ 和 $L_{1,2} = 8h \sin \alpha.$
第二次碰撞时球的速度由等式确定
$v_{1x} = v_{0x} + a_x t_1 = v_0 \sin \alpha + (g \sin \alpha) t_1 = 3v_0 \sin \alpha,$
$v_{1y} = v_{0y} + a_y t_1 = v_0 \cos \alpha - (g \cos \alpha) t_1 = -v_0 \cos \alpha.$
第二次碰撞后，这些速度相等
$v_{2x} = v_{1x}, v_{2y} = -v_{1y} = v_0 \cos \alpha = v_0y.$
第二次和第三次碰撞点之间的距离为
$L_{2,3} = (3v_0 \sin \alpha) t_2 + \frac{(g \sin \alpha) t_2^2}{2},$
其中 $t_2$ 是飞行时间。由于沿 $y$ 轴的初始速度与第一次碰撞时相同，因此$t_2 = t_1$。这就是为什么
$L_{2,3} = 16h \sin \alpha.$
类似地，可以证明
$L_{3,4} = 24h \sin \alpha.$
根据归纳法，我们写出
$L_{n,n+1} = 8nh \sin \alpha.$
因此，
$L_{9,10} = 8 \cdot 9 \cdot 0,1 \cdot \sin 30^\circ$米= 3.6 m。
