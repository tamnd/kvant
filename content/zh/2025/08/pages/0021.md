形式为$\vec{a} = (\alpha; \beta; \gamma)$、$\vec{b} = (\beta; \gamma; \alpha)$、$\vec{c} = (\gamma; \alpha; \beta)$。
从几何角度来说，这意味着当围绕轴 $x = y = z$ 旋转（角度 $120^\circ$）时，向量 $\vec{a}, \vec{b}, \vec{c}$ 会在一个循环中相互变换；因此，我们已经确保满足条件（3），以及所有三对向量之间的角度相等。接下来我们选择$\alpha, \beta, \gamma$，条件为$\vec{a} \perp \vec{b}$，相当于$\vec{a} \cdot \vec{b} = 0$，或者，在坐标中，
$$\alpha \beta + \beta \gamma + \gamma \alpha = 0 \Leftrightarrow \frac{1}{\alpha} + \frac{1}{\beta} + \frac{1}{\gamma} = 0.$$
例如，$\alpha = -n$、$\beta = n + 1$、$\gamma = n(n + 1)$ 都是合适的。从几何描述中可以清楚地看出，没有两个等点向量共线这一事实（当然，很容易直接验证）。
在继续下一个方法之前，请注意，可以通过仅需要向量的有理坐标来削弱条件（1）。事实上，如果$\vec{a}, \vec{b}, \vec{c}$有有理坐标，那么它们可以乘以合适的自然数，使得它们的所有坐标都变成整数。接下来，您可以使用条件（3），要求向量的长度等于1，即$\vec{a}, \vec{b}, \vec{c}$是位于单位球体$x^2 + y^2 + z^2 = 1$上的点的半径向量。
（事实上​​，可以证明，满足条件（2）和（3）的每个（非零）向量$\vec{a}, \vec{b}, \vec{c}$的长度等于自然数，这意味着通过乘以有理数，这些向量可以变成长度为1的向量。）
因此，我们构造满足以下条件的向量 $\vec{a}, \vec{b}, \vec{c}$ 的三元组：
$$(1') \vec{a}, \vec{b}, \vec{c}$$及有理坐标法；
$$(2) \vec{a}, \vec{b}, \vec{c}$$ 成对正交；
$$(3') |\vec{a}| = |\vec{b}| = |\vec{c}| = 1.$$
方法 3（由 M. Pravolov 建议）。我们将反映向量$\vec{e}_1(1; 0; 0)$、$\vec{e}_2(0; 1; 0)$、$\vec{e}_3(0; 0; 1)$相对于$Ax + By + Cz = 0$形式的平面，其中系数$A$、$B$、$C$是有理数。很明显，反射后矢量将满足条件（2）和（3'）。条件（1'）按比例分配

系数的有效性也将得到满足。事实上，当相对于平面 $Ax + By + Cz = 0$ 反射时，矢量 $\vec{v}$ 会变换为矢量 $\vec{v}' = \vec{v} - 2\frac{\vec{v} \cdot \vec{n}}{\vec{n} \cdot \vec{n}} \vec{n}$，其中 $\vec{n} = (A, B, C)$（平面的法向矢量）。我们看到，如果$\vec{v}$和$\vec{n}$有有理坐标，那么$\vec{v}'$也有。
显然，我们可以选择指示类型 $Ax + By + Cz = 0$ 的无限一组平面，以便矢量轨迹的结果集不包含比例矢量。这解决了我们的问题。
事实上，所指示的反射序列可以从三元组$\vec{e}_1, \vec{e}_2, \vec{e}_3$任何满足条件(1')、(2)、(3')的三元组获得。
方法 4（由 D. Makarov 建议）。我们将使用众所周知的说法：在平面$Oxy$上，在圆$x^2 + y^2 = 1$的任何弧上，都有无数个具有有理坐标的点。 （例如，这可以从毕达哥拉斯三元组的描述中推断出来。）
让我们围绕$\vec{e}_3(0; 0; 1)$（相同角度）旋转向量$\vec{e}_1(1; 0; 0)$和$\vec{e}_2(0; 1; 0)$，使它们成为具有有理坐标的向量$\vec{e}_1'$和$\vec{e}_2'$（根据声明，这是可能的）。让我们输入$\vec{e}_3' = \vec{e}_3$。
原点$O$和单位向量$\vec{e}_1', \vec{e}_2', \vec{e}_3'$定义了一个新的直接坐标系，其中有理坐标的点在原坐标系中也有有理坐标。 （其实不难理解，对于新坐标系和原坐标系来说，具有有理坐标的点集是相同的。）接下来，我们将对向量$\vec{e}_1''$、$\vec{e}_2''$、$\vec{e}_3''$进行类似的旋转。很明显（根据该陈述），可以选择一种旋转，使得向量 $\vec{e}_1''$、$\vec{e}_2''$、$\vec{e}_3''$ 都不与任何向量 $\vec{e}_1', \vec{e}_2', \vec{e}_3'$ 平行。
