类似地，我们可以分别考虑仅具有 EMF 2$\epsilon$ 的源系统和仅具有 EMF 3$\epsilon$ 的源系统，并且关闭所有其他源的 EMF。因此，所考虑的每个系统中任意两个电路节点之间的电势差为零，并且根据叠加方法，所得到的任意两个电路节点之间的电势差也为零。这意味着每种类型源的正极和负极之间的电位差是相等的并且
$$\varphi_+ - \varphi_- = 0.$$
让我们为任意一对相邻节点写出欧姆定律，其之间的电路部分包含电动势$\epsilon$：
$$\left( \varphi_+ - \varphi_- \right) + \epsilon = I_1 r.$$
这里，正值$I_1$对应于沿作用方向$\epsilon$流动的电流。从 $\varphi_+ - \varphi_- = 0$ 开始，当前的 $I_1$ 对于任何此类部分都是相同的。同样，对于包含 EMF 2$\epsilon$ 和 3$\epsilon$ 的电路部分，
$$\left( \varphi_+ - \varphi_- \right) + 2\epsilon = I_2 r,
\quad \left( \varphi_+ - \varphi_- \right) + 3\epsilon = I_3 r.$$
因此，
$$I_1 = \frac{\epsilon}{r}, I_2 = \frac{2\epsilon}{r}, I_3 = \frac{3\epsilon}{r}.$$
让我们将任意类型源上具有两个相邻（最近）端子的无限电路视为具有电动势 $\epsilon_{\text{эквивалентной}}$ 和内阻 $r_{\text{эквивалентной}}$ (图 4) 的等效源。
等效源的电动势为$\epsilon_{\text{эквивалентной}} = 0$，因为两个相邻端子之间的电位差为零。等效源$r_{\text{эквивалентной}}$的内阻定义为无限网格中两个相邻（最近）节点之间的电阻（电动势关闭）。为此，我们将再次使用覆盖方法。让我们首先考虑一个具有内部源电阻的无限网格，其中力电流$I_0$流入其中一个节点并传播到无穷大。在最接近给定节点的分支中，电流强度将相同（由于对称性）并且等于 $I_+ = I_0/6$。然后考虑相同的无限网格，其中力电流$I_0$从相邻节点流出。类似地，在该电路中，最靠近给定节点的支路中的电流将相同并且等于$I_- = I_0/6$。接下来我们考虑这两种情况的叠加。那么阻力$r$处的方向等于$(I_+ + I_-)r$，因此，
$$r_{\text{эквивалентной}} = \frac{(I_+ + I_-)r}{I_0} = \frac{r}{3}.$$
因此，当使用任何两个相邻（最接近）的节点时，电路的行为就像一个电阻为 $r_{\text{эквивалентной}} = r/3$ 的电阻器。因此，仪表的读数不取决于其连接的极性。考虑到这一点，我们得到仪表读数的答案：
$$R_1 = \frac{r}{3}, R_2 = \frac{r}{3}, R_3 = \frac{r}{3}.$$
这些结果与仪表的极性无关。
上一段中的等效源可以表示为一个具有 EMF 2$\epsilon$ 和电阻 $r$ 的源（根据情况替换为另一个源）和一个具有 EMF $\epsilon^*$ 和电阻 $r^*$ 的源的并联连接，相当于电路的其余部分（图 5）。考虑到对于等效源$\epsilon_{\text{эквивалентной}} = 0$和$r_{\text{эквивалентной}} = r/3$，我们找到$\epsilon^*$和$r^*$。电阻通过以下关系相关
$$\frac{1}{r_{\text{эквивалентной}}} = \frac{1}{r} + \frac{1}{r^*},$$
从哪里$r^* = r/2$。将所考虑的电源并联连接和等效电源的短路电流等同起来，我们得出对应关系
$$\frac{\epsilon^*}{r^*} - \frac{2\epsilon}{r} = \frac{\epsilon_{\text{эквивалентной}}}{r_{\text{эквивалентной}}},$$
$\epsilon^* = \epsilon$来自哪里。
