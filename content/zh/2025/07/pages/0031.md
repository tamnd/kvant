让我们证明引理。
引理。设抛物线上有六个点$A, B, C, A', B', C'$，其横坐标分别为$a, b, c, a', b', c'$。让$a' - a = b' - b = c' - c$。然后$S_{ABC} = S_{A'B'C'}$。
证明。不失一般性，我们假设$a < b < c$。令 $A_1, B_1, C_1$ 为点 $A, B, C$ 在轴 $Ox$ 上的投影
（参见图）。然后 $S_{ABC}$ 用矩形梯形的面积来表示：
$$S_{ABC} = S_{ACC_1A_1} - S_{ABB_1A_1} - S_{BCC_1B_1}.$$
根据梯形面积公式，
$$S_{ACC_1A_1} = \frac{(AA_1 + CC_1) \cdot A_1C_1}{2} = \frac{(a^2 + c^2)(c - a)}{2}.$$
我们类似地表达其他梯形的面积adb，变换后我们得到
$$S_{ABC} = \frac{a^2c - ac^2 + c^2b - b^2c + b^2a - ba^2}{2} = \frac{(c - a)(c - b)(b - a)}{2}.$$
从 $c' - a' = c - a, c' - b' = c - b, b' - a' = b - a$ 开始，我们得到与 $S_{A'B'C'}$ 相同的表达式。引理已得证。
请注意，引理可以通过另一种方式证明，使用闭合折线$AB'CA'BC'$中相对链接的平行性，或使用所谓的抛物线旋转（例如，参见«Kvant»第2期，2017年文章“有哪些转弯”）。
