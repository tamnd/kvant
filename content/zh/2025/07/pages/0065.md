以下是铰链相对轴的力矩平衡的条件：
$$mg \frac{L}{2} \sin \alpha - NL \sin \alpha - \mu NL \cos \alpha = 0,$$
$$F_{\text{тр}} = \frac{\mu mg}{2} \frac{\text{tg} \alpha}{\text{tg} \alpha + \mu}.$$
当该力的作用带走车轮的所有动能时，车轮将停止：
$$F_{\text{тр}} \cdot 2\pi Rn_1 = \frac{I}{2} \omega_0^2, n_1 = \frac{I \omega_0^2}{2\pi \mu mg R} \frac{\text{tg} \alpha + \mu}{\text{tg} \alpha},$$
其中$I$是车轮相对于对称轴的转动惯量。在第二个实验中（当初始旋转方向改变时），轮和杆之间的摩擦力方向变为相反，并且在给定方程中只有$\mu$项的符号发生变化。因此，在这种情况下，停止前车轮转数等于
$$n_2 = \frac{I \omega_0^2}{2\pi \mu mg R} \frac{\text{tg} \alpha - \mu}{\text{tg} \alpha} = \frac{\text{tg} \alpha - \mu}{\text{tg} \alpha + \mu} n_1 = 35.$$

$$r_{\perp} = x \text{tg}(\alpha/2) \approx \alpha x/2.$$ 因此，拉帕斯压力

3. 当钥匙关闭且阻尼器移动时，会改变包含电容器和阻尼器的电路的面积，这将导致磁通量的变化以及电路中感应电动势的出现
$$\varepsilon_i = -\frac{d\Phi}{dt} = -Bl \frac{dx}{dt} = -Blv.$$
这里，$x$轴向下，$v$是阻尼器的下降速度。我们将电容器的电荷$q$视为正电荷并产生感应电流。那么电容充电电流
$$I = \frac{dq}{dt} = \frac{\varepsilon_i - U_C}{R} = \frac{Blv}{R} - \frac{q}{CR}$$

（很明显，在没有感应电动势的情况下，充电的电容器将会放电）。从条件可以看出，电路电阻可以认为等于阻尼器电阻：$R \approx \rho \frac{l}{ld} = \frac{\rho}{d}$。所以
$$\frac{dq}{dt} = \frac{Bld}{\rho} v - \frac{d}{\rho C} q.$$
根据楞次规则，很明显，作用在流过阻尼器的感应点上的安培力应该减慢其运动。此外，导轨的低电阻使我们可以假设电流$I$沿高度和$F_{\text{Аx}} = -IBl$均匀分布在阻尼器中。阻尼器运动方程
$$m \frac{dv}{dt} = mg - IBl$$
考虑到其质量 $m = \tau l^2 d$ 被简化为以下形式
$$\frac{dv}{dt} = g - \frac{B}{\tau ld} \frac{dq}{dt}.$$
根据条件，从运动一开始，阻尼器（之前已移动）从其所在位置开始以恒定的加速度运动
$$\frac{dv}{dt} = g - \frac{B}{\tau ld} I = \frac{g}{2},$$即$v(t) = \frac{g}{2} t.$
阻尼器相应的运动规律为
$$x(t) = \frac{g}{4} t^2.$$
另外，根据目前的实力，可以发现
$$q(t) = q_0 + It = q_0 + \frac{\tau ldg}{2B} t.$$
当将改变阻尼器速度和电容器电荷的定律代入电路中电流强度的方程时，应该得到相同的结果，即对于任何时刻
$$\frac{\tau ldg}{2B} = \frac{Bldg}{2\rho} t - \frac{d}{\rho C} \left( q_0 + \frac{\tau ldg}{2B} t \right),$$
它来自哪里？
$$q_0 = -\frac{\rho \tau lCg}{2B}, C = \frac{d\tau}{B^2}.$$
