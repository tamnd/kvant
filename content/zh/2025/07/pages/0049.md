引力相互作用-
这些元素对物体在外太空的运动有一定的影响。万有引力定律和动力学定律使阐明天体运动的本质、解释恒星系统的动力学、计算航天器的运行轨迹、估计天体的质量成为可能。结果就是行星运动的实验定律——开普勒定律。此外，在它们的基础上，还获得了称为运动积分的重要概括。

让我们详细讨论一些关键的概括和结论，它们构成了中心力场运动描述的基础。在两个物体的引力相互作用中，它们的质心被认为是重心，并且带与其相关联，即描述运动的半径矢量的起点。当物体的质量相差几个数量级时，重心被认为是大质量物体的质心，与之相关的报告系统被认为是智能的。作用在第二物体上的重力和描述其运动的半径矢量是共线矢量。它们描述力矩的矢量积等于零。并且根据旋转运动的动态方程，第二物体相对于重心的角动量是恒定的：

$$\vec{M} = \left[ \vec{r} \times \vec{F} \right] = 0, \quad \vec{M} = \frac{d\vec{L}}{dt} = 0,$$

$$\vec{L} = \left[ \vec{r} \times m\vec{v} \right] = \text{const}, \quad \left[ \vec{r} \times \vec{v} \right] = \text{const}.$$

乘积 $$\vec{r} \times \vec{v} = \vec{s}_0$$ 称为扇形速度 $$\vec{s}_0 = 2\vec{S}_t$$，其中 $$S_t$$ 是半径矢量径向扫过的面积

在身体的中央场移动。 $$S_t$$恒常性是开普勒第二定律的内容。上述推导称为面积积分。本质上，它表达了自$$L = 2mS_t$$以来的角动量守恒定律。

如果输入目标参数$$b = r\sin \alpha$$，即从重心到动量矢量方向绘制的垂线的长度，那么我们对轨迹上两点的标量形式的结论将如下所示：

$$v_0b_0 = v_1b_1 = 2S_t = \text{const.}$$

引力场的保守性质使我们能够引入场的能量特性和另一个运动积分——能量积分。让我们将引力场$$m\frac{dv}{dt} = \frac{GMm}{r^2}$$的逐项基本diamkick方程乘以表达式$$v = \frac{dr}{dt}$$并进行变换。结果我们得到

$$\frac{d}{dt}\left(\frac{v^2}{2} - \frac{GM}{r}\right) = 0, \quad \frac{v^2}{2} - \frac{GM}{r} = E_0 = \text{const.}$$

第二项表示单位质量在引力场中的势能，即重势，整个表达式就是能量守恒定律。在一般形式中，对于两个轨迹点我们可以写

$$\frac{mv_1^2}{2} - \frac{GMm}{r_1} = \frac{mv_2^2}{2} - \frac{GMm}{r_2}.$$

单一质量体的总能量决定了轨道的性质。对于主半球$$a$$的椭圆轨道，它等于

$$E_0 = -\frac{GM}{2a}.$$

考虑到这一点，能量积分的形式为

$$v^2 = GM\left(\frac{2}{r} - \frac{1}{a}\right).$$

它将物体在距重心给定距离处的速度与轨道的大半球联系起来，并广泛用于计算轨迹。
