卡瓦列里原理和横截面积条件

辛普森公式不仅适用于棱柱体，还适用于学校几何学中的“圆形体”——圆柱体、圆锥体，而且出人意料地还适用于球（球的支撑平面是任意两个平行的切平面）。要进行检查，您可以使用教科书中已知的其对象的公式。例如，对于半径为 $R$ 的球，我们有

$$H = 2R, S_H = S_B = 0, S_{cp} = \pi R^2,$$

$$V = \frac{2R}{6} \left( 0 + 4\pi R^2 + 0 \right) = \frac{4}{3} \pi R^3.$$

但更有趣（更进一步有用）的标准是，我们没有打开课本，我们不知道公式，我们可以直接证明辛普森公式对这些物体的适用性。在这里，卡瓦列里原则对我们有帮助，在许多情况下取代了内在化。例如，它由什么组成（参见 [1]–[3]）。

普里西普·卡瓦列里。如果平行于该平面的任意平面被两个面积相等的物体相交，则这两个物体的体积相等。

凭借该原理，选择与圆柱体、圆锥体或球体一起分别满足卡瓦列里原理的条件的棱柱就足够了。

在圆柱体或圆锥体的情况下，一切都很简单：对于这种棱柱体，可以分别采用具有相同高度和相同底面积的棱柱或帕拉酰胺。球的情况稍微复杂一些。首先，我们找到平面 $\alpha(h)$ (图 4, a) 的截面面积$S_{III}(h)$，该平面与支撑平面平行，距下平面$h$。设球的半径为$R$。然后

$$S_{III}(h) = \pi r^2 = \pi \left( R^2 - (R - h)^2 \right) = \pi h (2R - h).$$

通用特征

设多条线段$A_iB_i$、$i = 1, 2, ..., n$连接平面$\alpha$的点$A_i$与平面$\beta$的点$B_i$平行，且线段不成对相交，但端点可以重合。让我们用$C_i$表示线段$A_iB_i$与平行于$\alpha$和$\beta$的任意平面$\gamma$的交点（以及$\alpha$和$\beta$之间的位置）。如果对于所有这样的平面$\gamma$，闭合折线$C_1...C_n$没有自交，则有界多边形的并集将被称为具有侧边$A_iB_i$的广义特征。让我们证明以下定理。

定理 3. 辛普森公式可以应用于任何推广。

证明。足以证明$C_1...C_n$部分的面积与其在$\alpha$以上的高度呈二次方关系。让我们想象一下，平面$\gamma$从$\alpha$匀速运动到$\beta$。那么每个点$C_i$都会从$A_i$均匀移动到$B_i$。将一段投影在$\alpha$上，得到一个与其相等的多边形，该多边形的每个顶点从$A_i$沿某条直线匀速移动到投影$B_i$。事实证明，在这种情况下，多边形的定向面积 $[C_1...C_n]$ 呈二次方（或可能呈线性）变化。为了不分散注意力，我们将在最后证明这个关键事实，现在我们只证明$[C_1...C_n]$是多边形的面积，如果按顺序$C_1, C_2, ..., C_n, C_1$逆时针遍历其边界，则用平面符号表示，如果顺时针则用负号表示。由于当从 $\alpha$ 移动到 $\beta$ 时，截面 $C_1...C_n$ 仍然是多边形，因此其（普通）面积始终为正，这意味着定向面积 $[C_1...C_n]$ 在移动时不会消失，因此保留其符号。因此，其绝对值（等于总面积）也呈二次方变化，由此根据定理2，辛普森公式适用于推广。定理3得证。

特别是，定理 3 将辛普森公式扩展到非凸性质。但不仅如此。所获得的结果允许人们几乎无需计算就可以找到除多边形之外的相当奇特的物体的体积。

$$\overrightarrow{O'A_1} \vee \overrightarrow{O'A_2} + \ldots + \overrightarrow{O'A_n} \vee \overrightarrow{O'A_1} =$$
$$= \overrightarrow{O'O} \vee \left( \overrightarrow{A_1A_2} + \ldots + \overrightarrow{A_nA_1} \right) + \overrightarrow{OA_1} \vee \overrightarrow{OA_2} + \ldots$$
$$\ldots + \overrightarrow{OA_n} \vee \overrightarrow{OA_1}.$$
由于$\overrightarrow{A_1A_2} + \ldots + \overrightarrow{A_nA_1} = 0$，右边等于$\overrightarrow{OA_1} \vee \overrightarrow{OA_2} + \ldots + \overrightarrow{OA_n} \vee \overrightarrow{OA_1}$，这意味着定义是正确的。
特别是，在三角形 $ABC$ 的情况下，$O = A$ 处的定义超出了我们开始时使用的公式：
$$[ABC] = \frac{1}{2} \overrightarrow{AB} \vee \overrightarrow{AC}.$$
当点$A_1, A_2, \ldots, A_n$沿直线匀速移动时，有向面积$[A_1A_2 \ldots A_n]$由时间上次数不大于2的多项式表示，这一事实直接从定义得出：上面我们对任何两个顶点移动的三角形都证明了这一点，$[A_1A_2 \ldots A_n]$是三角形$OA_1A_2, OA_2A_3, \ldots$的有向面积之和。引理1得到证明。

练习

7. 证明平行四边形$ABCD$的有向面积等于$\overrightarrow{AB} \vee \overrightarrow{AD}$，对于任意四边形它是$[ABCD] = \frac{1}{2} \overrightarrow{AC} \vee \overrightarrow{BD}.$

8. 三角形的顶点沿着这些直线以恒定的速度移动；在时刻 $t$ 他们位于点 $A_t, B_t, C_t$。证明如果三角形$A_1B_1C_1$与三角形$A_0B_0C_0$相似并且这些三角形方向相反，则
$$[A_tB_tC_t] = (1-t)^2 [A_0B_0C_0] + t^2 [A_1B_1C_1].$$
还需要证明我们使用的与辛普森公式相关的另一个性质。

引理2.多边形的“总”面积等于其有向面积的绝对值。

证明。我们将限制在多边形$A_1A_2 \ldots A_n$的情况，其中有一个点$O$，从该点可以看到所有边（图11），包括多边形。让我们写下$[A_1A_2 \ldots A_n]$相对于这一点的定义。线段 $OA_i$ 将多边形分割成 $n$ 个三角形，因此其（总）面积 $S$ 等于它们面积之和。另一方面，任何两个相邻的三角形$OA_{i-1}A_i$和$OA_iA_{i+1}$位于$OA_i$的相对侧，因此具有相同的方向。因此，它们的定向区域的符号是相同的，因此
$$\|[A_1A_2 \ldots A_n]\| = \|[OA_1A_2]\| + \ldots + \|[OA_nA_1]\| = S.$$
一般情况下的证明是通过归纳法使用众所周知的定理进行的，即任何多边形都有一条完全位于其内部的对角线。如果我们写下多边形被这样一条对角线分成两部分的面积的定义，那么我们就得到两个三角形面积的和，并且与对角线相邻的三角形的面积在每个和中出现一次，但符号不同。当这些项相加时，它们会相互抵消，剩余的三角形形成原始多边形的总和。我们把细节留给读者。
