从这里开始，即对于$n > N$，不等式$\left| \sin \left( n^2 \right) - l \right| < \frac{1}{10}$成立。简而言之，对于所有大的$n$，数字$x_n = n^2$、$x_{n+1} = (n+1)^2$和$x_{n+2} = (n+2)^2$应该位于可见臂上的某个位置（图6）。但对于我们结合 图 5 讨论的 $n$ 值，这是不可能的，因为三角形 $x_n x_{n+1} x_{n+2}$ 不可能真正变窄。矛盾。定理已被证明。

序列没有限制但行为非常简单的情况并不罕见。特别是当它由具有不同限制的多个序列“粘合在一起”时，就会发生这种情况。例如，$x_n = (-1)^n$。对于这个序列，如果我们只考虑偶数$n$，则$\lim_{k \to +\infty} x_{2k} = 1$；如果我们只考虑奇数$n$，则$\lim_{k \to +\infty} x_{2k+1} = -1$。一般情况下，我们会接受这个定义。

操作。给定序列$\{x_n\}$。让我们选择自然数序列 $n_1 < n_2 < n_3 < \ldots$ 的可能性，并考虑具有所选数字的序列成员：

$$x_{n_1}, x_{n_2}, x_{n_3}, \ldots$$

我们得到序列$x_n$的子序列。它可以被认为是一个独立序列，其中第一项等于$x_{n_1}$，第二项等于$x_{n_2}$，依此类推。这个新序列指定如下：$\{x_n\}$。如果它有极限$\lim_{k \to +\infty} x_n = l$，则数$l$称为序列$x_n$的部分极限。

不难看出，如果一个序列$\{x_n\}$有一组有限的部分极限$L = \{l_1, l_2, \ldots, l_m\}$，那么它就具有受某个极限限制的性质。也就是说，对于任何 $\varepsilon > 0$ 都存在一个数字 $N$，使得对于每个 $n > N$ 至少有一个不等式成立：

$$|x_n - l_1| < \varepsilon, \ldots, |x_n - l_m| < \varepsilon$$

（对于小$\varepsilon$，只有其中一个满足）。

任何序列也可以分为$m$子序列，每个子序列都趋向于自己的极限。换句话说，这样的序列的项可以写成以下形式

$$x_n = \varphi_n + \varepsilon_n, \text{ где } \varphi_n \in L, \varepsilon_n \rightarrow 0.$$

序列极限的存在是一个非常强的性质。任意实序列，即使是有限序列，也不一定有极限。此外，它值得替换，因为根据数学分析标准课程证明的博尔扎诺-魏尔斯特拉斯定理，每个有界实数序列都至少有一个部分极限。另一方面，部分执行限制的集合可能是无限的。例如，读者可以证明以下定理。

**定理 3.** 如果 $A$ 和 $B$ 是实数 $u$ 关系 $\frac{A}{\pi}$ 是无理数，则序列 $\{\sin (An + B)\}$ 在区间 $[-1;1]$ 上处处都是 Lomp。

特别是，区间$[-1;1]$中的任何数字都是序列$\{\sin n\}$的部分极限。

顺便请注意，当研究$\{\sin x_n\}$形式的序列的部分极限时，公式中正弦的存在并不是很重要，重点在于序列$\{x_n \mod 2\pi\}$的属性。
