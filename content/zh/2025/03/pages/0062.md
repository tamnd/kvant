让我们回忆一下球加速度的 $a_n$ 分量。
让我们将牛顿第二定律写成垂直轴上的投影：
$$ma_\tau = mg, a_\tau = g.$$
为了找到加速度的法向分量，我们使用向心加速度的公式：
$$a_n = \frac{u^2}{L}.$$
接下来，我们写出加速度在楔块斜面法线上的投影的运动学关系方程：
$$0 = a_\tau \cos \alpha - a_n \sin \alpha, a_\tau = a_n \mathrm{tg} \alpha,$$
$$g = \frac{u^2}{L} \mathrm{tg} \alpha, u^2 = g L \mathrm{tg} \alpha.$$
考虑到$u = v \mathrm{tg} \alpha$，我们最终得到
$$v = \sqrt{\frac{g L}{\mathrm{tg}^3 \alpha}} = \sqrt{g L \mathrm{tg}^3 \alpha}.$$
4. 1) 在$\Delta t$$\Delta m_0 = \mu_0 \Delta t$时间内气体被移除，即$\Delta Q = \Delta m_0 q$能量被释放。只有$\eta$部分用于加热水：$\Delta Q_\pi = \eta \Delta Q$。那么有用的力量
$$P = \frac{\Delta Q_\pi}{\Delta t} = \eta \mu_0 q \approx 2,3 \text{ кВт}.$$
2) 请注意，在第 1-2 部分中，水的质量没有变化（没有蒸发或流动），即该部分是垂直的。让我们用 $M$ 表示点 1 处水的质量。第 2-3 节中描述蒸发的方程：
$$P \tau_{23} = \left( M - \frac{M}{4} \right) L = \frac{3 M}{4} L.$$
第 3-1 节中描述加水量的方程式：
$$\mu \tau_{31} = M - \frac{M}{4} = \frac{3 M}{4}.$$
考虑到$\tau_{23} = \tau_{31}$，我们得到
$$\mu = \frac{P}{L} = \mu_0 \frac{\eta q}{L} = 1,0 \text{ г/c}.$$
3) 第3-1节中的热平衡方程（$t_{100} = 100^\circ \text{C}$是水的沸点，$c$是水的比热，$m$和$t$是本节中水的当前质量和温度）：
$$c \frac{M}{4} \left( t_{100} - t \right) = c \left( m - \frac{M}{4} \right) \left( t - t_x \right),$$
在哪里
$$t (m) = t_x + \frac{M}{4} \left( t_{100} - t_x \right) \frac{1}{m}.$$
最后一个公式显示了第 3-1 节的线性。点1的水温为
$$t_1 = t (M) = t_x + \left( t_{100} - t_x \right) / 4 = \left( t_{100} + 3 t_x \right) / 4 = 40^\circ \text{C}.$$
该图是一个直角三角形，顶点为 (1; 40)、(1; 100)、(4; 100)。

4) 第 1-2 节中描述加热的方程：
$$P \tau_{12} = c M \left( t_{100} - t_1 \right).$$
然后
$$\frac{\tau_{23}}{\tau_{12}} = \frac{3 L}{4 c \left( t_{100} - t_1 \right)} \approx 6,9.$$
5. 1) 有必要分析两种可能的连接选项（图11）并计算每种连接选项的瓦特表读数。对于左侧电路，安培表 ($I_1$) 和瓦特表 ($U_1$) 的读数：
$$I_1 = \frac{U}{R + r_A}, U_1 = U.$$
根据条件，瓦特表读数等于电流表和瓦特表读数的乘积：
$$P'_1 = I_1 U_1 = \frac{U^2}{R + r_A}.$$
在正确电路的情况下，安培表（$I_2$）和瓦特表（$U_2$）的读数：
$$I_2 = \frac{U}{r_A}, I_V = \frac{U}{R + R_V}, U_2 = I_V R_V = \frac{U R_V}{R + R_V}.$$
然后
$$P'_2 = I_2 U_2 = \frac{U^2}{R + R_V} \frac{R_V}{r_A}.$$
瓦特表读数的比率允许您使用源：
$$k = \frac{P'_1}{P'_2} = \frac{R + R_V}{R + r_A} \frac{r_A}{R_V}.$$
让我们表达瓦特计所需的内阻；
$$R_V = \frac{R}{k \frac{R + r_A}{r_A} - 1}.$$
现在我们替换数值。如果$k = 100/1 = 100$，则$R_V \approx 5,0 \cdot 10^{-2} \text{ OM}$。结果发现该值小于安培器的电阻，这意味着这个答案是不正确的。如果$k = 1/100 = 0,01$，则$R_V = 50 \text{ kOm}$。合理的结果。
