正在检查的三角形——我们同意称之为基本三角形。每个阶段都有自己的存在区域，即允许给定阶段的重心位置的集合。相（1234）的面积用符号$\Gamma_{0}$表示。设$\Gamma_{3}$为相(123)的面积，$\Gamma_{4}$为相(124)的面积。让我们使用 图 中所示的坐标轴 X 和 Y。让我们用x和y表示“桌子+重量”系统的重心直角坐标。设a为点2的横坐标，b为点3的纵坐标。根据静力学定律，我们立即得到

$( F_{3} + F_{4} ) b = Py$,

$( F_{2} + F_{3} ) a = Px$,

$F_{1} + F_{2} + F_{3} + F_{4} = P$.

实际上，由于腿的可压缩性，这些等式是近似的。然而，如果桌腿在空载和负载状态下的长度差异不超过几毫米，并且连接桌腿连接点的矩形的边a和b约为一米，则可以使用它们。因此，例如，如果由于制造误差而导致两条腿的长度差异为三毫米，那么这将使它们末端之间的距离改变不到二百分之一毫米。 （这很容易通过使用毕达哥拉斯定理来验证。）因此，可以以等于矩形1234的高精度来考虑以腿接触地板的点为顶点的四边形。结果，腿与垂直方向的偏差结果约为弧度的万分之一。我们最后获得的关系式与力学规定的精确关系式之间的差异同样很小。如果桌腿的制造材料足够坚硬，并且它们的卸载长度彼此之间差异足够小，那么我们估计的假设就得到满足。因此，将来我们不会对与桌腿两端之间的距离变化相关的影响感兴趣。如何找到可能相的区域？静力学定律的类型并不取决于表格所处的阶段。这些差异以其他方式影响我们。因此，在阶段(1234)中，所有四个力都是正的，并且在其余阶段中，力之一为零，因为只有三个腿接触地板。例如，在阶段（123）

$F_{i} > 0$ 对于 i = 1, 2, 3 和 $F_{4} = 0$。

精神上伸展腿 4，使所有四条腿的末端位于同一平面 - 地板平面。因此，我们的不等式意味着在延伸之前，第 4 条腿的下端高于地板。这个条件与从静力学定律获得的三个方程一起，使我们能够找到相位面积 (123)。表问题表明，在研究物理对象的过程中，有时需要显着修改其属性的描述，放弃过于简化的模型，转而采用更现实的模型。在我们考虑的情况下，原来的简单模型结果是不完整的——它不允许我们找到唯一正确的解决方案。然而，这只是硬币的一方面。如果你不看它的另一面，你可能会错误地认为简化表示（对象模型）对于缺乏经验的研究人员来说是陷阱。文章的篇幅不允许我们充分地阐述这个想法，因此我们将仅限于两个例子，以免完全没有根据。开普勒定律为我们提供了行星围绕太阳运动的最简单的图像：行星沿椭圆形运动。其他行星的存在在某种程度上使这幅图景变得模糊，但这只有天文学家感兴趣。如果你愿意的话，开普勒定律非常民主。事实上，如果这些定律仍然作为原材料保留在科学家的手稿中，作为处理观测结果的第一近似值，而期刊和教科书中只包含精炼的公式，那么公众会对我们的太阳系了解多少？而科学家们自己“也会过得很艰难”。让我们记住，海王星是由于观察到天王星运动与开普勒定律的偏差而被发现的，而这种偏差无法用当时已知的所有其他行星的影响来解释。第二个例子是小振荡理论。科学技术赋予了自然频率和振荡、频率多重性及其分裂、频谱、泛音等基本概念。同时，如果不参考明显近似的小振荡理论，所有这些概念都是不可能的，或者至少是非常困难的。 该理论本身是相关微分方程组线性化的结果，即“毫不客气地”丢弃平方、立方和所有更高阶的正在研究的系统与其平衡状态的小偏差。结论——有意识地转向近似模型可能会非常富有成效。
