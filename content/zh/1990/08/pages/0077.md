陷入了深处。然后将管子的顶部封闭并取出 (图 3)。格鲁特·斯托尼克会在幼虫中停留多久？大气压力 $p_0 = 750$ mm pt.艺术。

让我们忽略毛细管现象并假设核心非常缓慢地流出管。然后，核心很可能会流出，直到管内外的气压差与剩余核心柱的力平衡。从这里我们找到管内的压力：$p = p_0 - \rho gx$，其中$x$是剩余核心芯的所需长度。另一方面，可以从波义耳-马里奥特定律找到相同的压力（我们假设温度恒定）

$$p_0 \frac{l}{2} S = p(l - x)S.$$

从一般方程中消去 $p$，我们得到

$$p_0 \frac{l}{2} = (p_0 - \rho gx)(l - x).$$

考虑到大气压力以地面毫米数为单位，可以简化该方程（在此类问题中，这实际上更方便）。代入$p_0 = \rho gH$，其中$H = 750$ mm，我们得到二次方程

$$x^2 - (H + l)x + \frac{Hl}{2} = 0.$$

该方程的较大根会改变管的长度，不适合我们。第二个根仍然是：

$$x = \frac{H + l - \sqrt{H^2 + l^2}}{2} = 0,25$$ 毫米 = 25 厘米。

问题 4. 在一个尺寸相同的连通圆柱形接头中，其中一个密封，另一个打开，放置一个 rtul。容器内的地面高度相同，密封容器充满空气的部分的长度为$l_0$，大气压力$p_0$，以地柱的毫米为单位换算为$H$。如果密封容器中空气的绝对温度加倍，容器中的空气水平会有什么差异？

该问题的解决方案与上一问题的解决方案类似，唯一的区别是波伊尔-马里奥特定律必须替换为奥贝迪安气体定律，因为气体的温度会发生变化：

$$\frac{p_0 l_0}{T} = \frac{p(l_0 + x)}{2T}.$$

这里 $x$ 是密封容器中地面下降的距离 (图 4)。敞口容器中的水位上升相同的量（容器的直径相同），因此流体静力方程的形式为

$$p = p_0 + 2\rho gx.$$

因此，代入$p_0 = \rho gH$，我们得到二次方程

$$2x^2 + (H + 2l_0)x - Hl_0 = 0.$$

该方程的一个根为负，不能作为问题的答案。因此我们得到

$$x = (\sqrt{(H + 2l_0)^2 + 8Hl_0} - (H + 2l_0))/4.$$

因此，血管中所需的 gru 水平差异等于

$$h = 2x.$$
