气体定律和机械平衡

D·亚历山德罗夫

通常会针对个别主题开发学校物理课程，例如“动力学基础”、“气体定律”、“静电学”等。匹配问题和物理问题通常属于同一分类。这到底好不好？

凭借一定的经验，这种“分布”可以帮助申请人（即使在快速熟悉问题的条件之后）估计哪些物理定律将有助于解决问题。然而，在入学考试中，经常会出现一些很难归因于任何特定主题的问题。这可能会导致某些困难，从而无法解决通常简单的任务。

在本文中，我们将考虑一系列乍一看可以称为“gas”的任务。事实上，在处理他们的解时，除了气体定律之外，你还会遇到其他定律，主要是机械平衡定律。

任务1. 一个气球从温暖的房间（$t_1 = +27^\circ C$）带到寒冷的房间（$t_2 = -23^\circ C$），在空中自由漂浮一段时间。确定球橡胶壳的质量。这是直径$d = 40$厘米，空气摩尔质量$M = 29 \text{ г/mоль}$，大气压力$p_0 = 10^5 \text{ Pa}$。外壳的弹性可以说。

从表面上看，这是一个基于气体定律的普遍问题。这种印象是在条件条件下实现的——除了门捷列夫-克拉佩龙方程（理想气体的状态方程）之外，没有其他地方可以替代它们。另一方面，令人非常惊讶的是，从这个方程中无法找到壳的质量。生活怎么样？

让我们更仔细地再次阅读问题的条件；有时，最有价值的信息不是在数字中，而是在文字中。让我们注意两个短语：“气球......在空气中自由漂浮”和“外壳的弹性可以声称”。第一句陈述了球的机械平衡条件：橡胶壳的重力和球内的暖空气与浮力（阿基米德力）平衡。根据阿基米德定律，这个力等于液体或气体的重量占浸没在其中的物体的体积。第二个短语表示球内外气压相等。

因此，让我们写下球的整个平衡条件 (图 1) 的要求：

$$m_0 g + m_1 g = m_2 g,$$

其中 $m_0$ 是所需的橡胶壳质量，$m_1$ 和 $m_2$ 是热质量

问题2. 薄壁玻璃应该切入水中多深，然后倒置才累？玻璃的质量为$m = 100$g，体积为$V = 200$ml，大气压力为$p_0 = 10^5$Pa。

我们假设玻璃浸入的速度非常慢。在这种情况下，玻璃杯和填充其中的水在每个时刻都处于平衡状态。显然，为此，必须向玻璃施加一个力，平衡阿基米德力和重力的总和。在水面附近，这个力应该向下，因为从问题条件的数据可以看出，玻璃体积中水的质量大于玻璃本身的质量，因此，初始时刻的阿基米德力大于重力。当你潜水时，浮力会减小 - 它与玻璃中所需冲击的体积成正比，并且它会减小，因为冲击会压缩来自水的所有冲击。我们需要找到阿基米德力与重力大小相等的深度。当玻璃浸入稍深的深度时，如果没有外部帮助，它就会疲劳。

现在我们进行相应的计算。玻璃在水中的平衡条件为 (图 2)

$$mg = F_A, \text{ где } F_A = \rho gV_1.$$

锁定冲击的体积 $V_1$ 可以从波义耳-马里奥特定律（制造过程方程）中找到，因为温度可以被认为是恒定的（这隐含在问题的条件中，尽管没有明确说明）：

$$p_0V = (p_0 + \rho gh)V_1,$$

其中 $h$ 是所需的玻璃浸入深度，$\rho$ 是水的密度。

将所有方程放在一起，我们得到

$$mg = \frac{p_0\rho gV}{p_0 + \rho gh},$$

在哪里

$$h = \frac{p_0}{\rho g} \left( \frac{\rho V}{m} - 1 \right) = 10 \text{ м}.$$

顺便请注意，10 m 高的水柱压力恰好对应于正常大气压，大约等于 $10^5$ Pa。

让我们忽略毛细管现象并假设核心非常缓慢地流出管。然后，核心很可能会流出，直到管内外的气压差与剩余核心柱的力平衡。从这里我们找到管内的压力：$p = p_0 - \rho gx$，其中$x$是剩余核心芯的所需长度。另一方面，可以从波义耳-马里奥特定律找到相同的压力（我们假设温度恒定）

$$p_0 \frac{l}{2} S = p(l - x)S.$$

从一般方程中消去 $p$，我们得到

$$p_0 \frac{l}{2} = (p_0 - \rho gx)(l - x).$$

考虑到大气压力以地面毫米数为单位，可以简化该方程（在此类问题中，这实际上更方便）。代入$p_0 = \rho gH$，其中$H = 750$ mm，我们得到二次方程

$$x^2 - (H + l)x + \frac{Hl}{2} = 0.$$

该方程的较大根会改变管的长度，不适合我们。第二个根仍然是：

$$x = \frac{H + l - \sqrt{H^2 + l^2}}{2} = 0,25$$ 毫米 = 25 厘米。

问题 4. 在一个尺寸相同的连通圆柱形接头中，其中一个密封，另一个打开，放置一个 rtul。容器内的地面高度相同，密封容器充满空气的部分的长度为$l_0$，大气压力$p_0$，以地柱的毫米为单位换算为$H$。如果密封容器中空气的绝对温度加倍，容器中的空气水平会有什么差异？

该问题的解决方案与上一问题的解决方案类似，唯一的区别是波伊尔-马里奥特定律必须替换为奥贝迪安气体定律，因为气体的温度会发生变化：

$$\frac{p_0 l_0}{T} = \frac{p(l_0 + x)}{2T}.$$

这里 $x$ 是密封容器中地面下降的距离 (图 4)。敞口容器中的水位上升相同的量（容器的直径相同），因此流体静力方程的形式为

$$p = p_0 + 2\rho gx.$$

因此，代入$p_0 = \rho gH$，我们得到二次方程

$$2x^2 + (H + 2l_0)x - Hl_0 = 0.$$

该方程的一个根为负，不能作为问题的答案。因此我们得到

$$x = (\sqrt{(H + 2l_0)^2 + 8Hl_0} - (H + 2l_0))/4.$$

因此，血管中所需的 gru 水平差异等于

$$h = 2x.$$
