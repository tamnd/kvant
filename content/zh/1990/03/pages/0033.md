M1189。平面上有n条直线，其中没有三条经过同一点，也没有两条平行。证明在这些线将平面划分成的每个部分中，您可以放置​​一个不同于 0 且不超过模 n 的整数，以便在这些线的任何一侧上的数字之和等于 0。

让我们给出问题的最短解决方案。它基于以下事实：数据直线将平面划分成的每个部分都可以用黑色或白色涂料涂漆，使得面部的公共部分的区域具有不同的颜色。 （这种着色可以“通过归纳”获得：当在其有界半平面之一中添加一条线时，所有颜色都被相反的颜色替换。）

直线的每个交点都是四个角的顶点——两个白角和两个黑角。让我们在其中写入数字+1（白色）和-1（黑色）。显然，在由任何给定直线界定的每个半平面中，这些数字的总和等于 0。

现在，对于每个区域，我们将写在角上的数字相加 - 这些将是所需的非零整数：由于每个凸区域的边数不超过 n 个，因此它的角数不超过 n 个。

因此，我们证明了以下定理：如果在n条直线划分平面的每个区域中，写一个整数，其绝对值等于其角度的数量，并且相邻（沿线段或射线）区域的数字的符号不同，则在n条直线中的任何一条直线的每一侧，这些数字的总和等于0。

N·康斯坦丁诺夫

M1190*。 a) 证明如果2n×2n个单元格的表格中有3n个星星，那么可以划掉n行n列，这样所有的星星都被划掉了。
b) 证明在一个 2n×2n 单元格的表格中，您可以排列 3n+1 个星星，以便在划掉任何 n 行和 n 列后，至少保留一颗星星。

a) 划掉星号最多的 n 行。其中不能少于 2n 个星号 - 这意味着在这 n 行之一中，星号不超过 1 个，那么其余 n 行中星号不超过 1 个，因此总共少于 2n+n=3n 个星号。所以，至少有2n颗星被划掉了；剩余的（不超过 n 个）星号可以通过划掉相应的列来删除。
b) 按图所示放置星星：2n - 对角线，另一个 n - 在第 i 行与第 (i+1) 列的交叉点（i=1, 2, ..., n），最后一颗 - 在第 (n+1) 行与第 1 列的交叉点。假设我们通过划掉 n 行和 n 列设法删除了所有这些星号。让其中的 k≤n-1 行（以及 n-1-k 列）到达底部 (n-1) 颗星，即到达最后 n-1 行和列。然后将前n+1行中的n-k行划掉。其余线分为几个区域：从p1,...,pr线(r≥1)开始，p1+...+pr=(n+1)-(n-k)=k+1。 （这里我们假设第一行在第（n+1）行之后。）在这些区域中将有（p1+1）+（p2+1）+...+（pr+1）=k+r+1>k+1颗星星，站在不同的列中。还剩 n-(n-1-k)=k+1 列。因此，通过划掉列，无法删除所有星号。
