这个问题是 Pirankevich 问题的一个特例：对于给定的数字 $m, l, p, q$，($p < m, q < l$) 找到最多的数字$k$，使得放置在$m$行和$l$列的表格单元格中的任何$k$星可以通过划掉一些$p$行和$q$列来删除。 （在我们的问题中，证明对于$m = l = 2n$，$p = q = n$，答案是$k = 3n$。）

F1198。半径为 $R$ 的管道中充满沙子，高度为 $H$ ($H > 200R$)。沙子密度$ρ$。求沙子压力作用在管子底部的最小力。已知这个坡度在水平面上形成一个山丘，其底部的极限角度为$\gamma_0$（图1），并且这个角度很小（$\gamma_0 \sim 0,1$弧度）。沙子与管道材料之间的静摩擦系数为rsgen$\mu$。

我们首先求沙子与沙子的摩擦系数$\mu'$。让我们考虑底角为 $\gamma$ (图 2) 的山坡上的沙子。三个力作用在其上：重力$mg$、法向斜坡反作用力$N$和静摩擦力$F_{tp}$。从这些力的矢量和为零的条件（平衡条件），我们很容易发现

$$N = mg \cos \gamma, F_{tp} = mg \sin \gamma = N \text{tg} \gamma.$$
另一方面，$F_{tp}_{\max} = \mu' N$。因此，

$$\mu' = \left( F_{tp} / N \right)_{\max} = \text{tg} \gamma_0 \approx \gamma_0,$$

其中 $\gamma_0 \ll 1$ 是底部的极限（最大）角度。

现在让我们考虑一根充满沙子的管道。让我们选择一层厚度为$dz$（图3；此处轴$Z$向下，$z = H$对应于管道底部）的薄沙层。该层受到重力$dm \cdot g$、墙壁的摩擦力$F_{tp}$、沙子上部的压力$F_1 = \pi R^2 p(z)$以及下部的压力$F_2 = \pi R^2 p(z + dz)$。这里$dm = \rho \pi R^2 dz$是所考虑的层的质量，$p(z)$是$z$级别的沙压力，$p(z + dz)$是$z + dz$级别的压力。显然，如果摩擦力向上并且值最大，底部上的压力将最小。
