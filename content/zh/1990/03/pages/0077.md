新西伯利亚国立大学以该大学的名字命名。列宁共青团
数学
选项1
1. 上午 8 点、下午 4 点
2. arctg $\frac{5 \pm \sqrt{46}}{7} + \pi n, n \in Z$。笔记。替代$y = \mathrm{tg} x$。
3. $6\sqrt{55}$。笔记。从$\angle PAE = \angle APE$开始，然后$AE = PE$。同样，$DF = QF$。因此，这个梯形是一个平衡梯形。
4. -4、-8。笔记。函数$y = |a - 2x| - |x + 3|$在点$x = \frac{a}{2}$达到最小值，而$y = -\left| \frac{a}{2} + 3 \right|$。原方程有唯一解当且仅当$y = -1$。
5. 1:1。笔记。设$E$和$F$分别为该平面与$AB$和$A'B$的交点； $BO$ – 垂直于平面$CB'E$。三角形$BFO$是矩形，$\angle BFO = 60^\circ$。让$BE = x$。然后$BF = \frac{x\sqrt{2}}{x + 1}$，$BO = \frac{x}{\sqrt{1 + 2x^2}}$。从等式$BO = BF \cdot \sin 60^\circ$我们得到$x$的方程。

选项2
1. 67 212、67 716。注。如果一个数能被 4 和 9 整除，则该数能被 36 整除。从能被 9 整除的测试可知，$14 + m + n$ 能被 9 整除，而数 $10 + n$ 能被 4 整除。
2. $\frac{\pi}{3} + 2\pi n, n \in Z$。笔记。该方程相当于系统$2\sin^2 x = 5\cos x - 1$，sin $x \geq 0$。
3. $10\sqrt{3}$。笔记。设 $L, M, N$ 为三角形 $ABC$ 内接圆的切点，分别在边 $AB, BC$ 和 $AC$ 上。然后$BC = 2\cdot \frac{7}{\sqrt{3}} \cos 60^\circ = 7$，$AL = AK = \sqrt{3}$ sttg $30^\circ = 3$。三角形的半周长$ABC$等于
$$\frac{AL + BL + BM + MC + CK + KA}{2} = AL + BC = 10.$$
4. $6 < x < 8, x \neq 2\pi, x \neq \frac{\pi}{2} + 2\pi$。笔记。这个不等式相当于系统
$$\begin{cases} x^2 - 14x + 73 > 0, \\ x^2 - 14x + 73 < 32, \\ x \neq k\pi, x \neq \frac{\pi}{2} + n\pi, k, n \in Z. \end{cases}$$
从哪里$6 < x < 8, x \neq 2\pi, x \neq \frac{\pi}{2} + 2\pi$。

5. $\frac{2}{\sqrt{41}}$。笔记。平行于 $BM$ 并穿过点 $A$ 的直线与斯通子 $CB$ 和 $CD$ 的延长线相交于相应的点 $L$ 和 $K$ 处。线$LN$与边$BB'$相交于点$P$，线段$BQ$垂直于$KL$。直角三角形$PBQ$的高度$BH$垂直于直线$AN$和$BM$。

我们从$BH = \frac{2}{\sqrt{41}}$找到$PB = \frac{1}{3}, BQ = \frac{2\sqrt{5}}{5}$。

选项3
1. 3公斤、7公斤。
2. $(-1)^n \frac{\pi}{6} + \pi n, n \in Z$.
3. $8 + 2\sqrt{7}$。笔记。在三角形$BOC$中，$O$是中线的交点，我们依次找到$BO = \frac{2}{3}BM, CO = \frac{2}{3}CN$。
接下来是$OH' = \frac{1}{3}AH$，之后我们找到线段$BH', CH'$和边$BC$。
4. $4 \leq x < 29$。笔记。进行更改 $y = \sqrt{x} - 4$，然后求解由此产生的不等式 $y$。
5. arctg $\frac{4}{\sqrt{5}}$。笔记。让点$N$由条件$MN \parallel BC, CN \parallel BM, K$给出 - 点$N$在平面$ABCD, L$上的投影 - 点$K$在直线$AC$上的投影。所需角度等于角度 $KNL$，并根据腿 $KN = 1, KL = \frac{4}{\sqrt{5}}$ 计算。

物理
选项1
1. 在没有外力的情况下，我们有： $-ma_1 + Ma + ma_2 = 0$，因此
$$a = (a_1 - a_2)m/M.$$
2. 连接后，每个圆盘的外表面上都会有相同的电荷$q = (q_1 - q_2)/2$，位于表面平面$\sigma = (q_1 - q_2)/(2\pi R^2)$。配合表面上不会有电荷。稍微稀释后，电荷分布几乎保持不变。一个圆盘产生的场强为
$$E = \sigma/(2\varepsilon_0) = (q_1 - q_2)/(4\pi\varepsilon_0R^2).$$
一个圆盘的场以力作用于另一个圆盘的电荷
$$F = qE = (q_1 - q_2)^2/(8\pi\varepsilon_0R^2).$$
3. 根据法拉第定律，由于穿过三角形整个平面的磁通量的变化，会出现$\Theta D C = \Delta \Phi/\Delta t = \alpha ab$。根据欧姆定律$\Theta = IR = I \cdot 2\rho(a + b)$，其中$\rho$是导线单位长度的电阻。从这里
$$I = \frac{\alpha ab}{2\rho(a + b)}.$$
