V·乔贾耶夫

F1200。桌子上有两个一模一样的杯子，其中一个盛满了热茶。茶温$t_0$。茶需要冷却到$t_k$的温度。这可以通过两种方式完成：

1) 立即将茶倒入第二个玻璃杯中，等待其冷却至$t_k$的温度；
2) 冷却，直到茶冷却到一定温度$t_1$，这样倒入第二个玻璃杯后，温度立即变成$t_k$。

哪条路最快？众所周知，玻璃的传热与玻璃与环境的温差成正比；茶和玻璃杯之间的热传递发生得非常快。玻璃杯的热容是$C_0$，茶的热容是$C$。

让我们用$T$来表示茶与环境之间的温差：

$$T = t_{\text{чай}} - t_{\text{окр.ср.}}$$

为了简洁起见，我们将其称为 $T$ 温度。那么根据问题的条件，茶的温度$T$随时间$\tau$的变化方程可以写成以下形式

$$dT/d\tau = -\alpha T,$$

(*)

其中$\alpha > 0$是常数比例系数。从问题的条件还可以得出，如果在将茶从一个玻璃杯倒入另一个玻璃杯之前，温度为$T$，则倒茶后温度将变为$CT/(C+C_0) = \beta T$，其中$\beta$是常数系数。

现在考虑过程 1) 和 2)。对于第一个过程，我们写下初始条件：

$$T^{(1)}(0) = \beta T_0$$（输血后立即）

以及温度随时间变化的方程：

$$dT^{(1)}/d\tau = -\alpha T^{(1)}$$.

对于第二个过程，我们引入一个新变量$T' = \beta T^{(2)}$并写出相应的等式：

$$T'(0) = \beta T_0,$$

$$dT'/d\tau = \beta dT^{(2)}/d\tau = \beta (-\alpha T^{(2)}) = -\alpha T'$$.

相同的方程和相同的初始条件对应相同的解。因此，在任意时刻$T$

$$T'(\tau) = T^{(1)}(\tau).$$

令在某个时刻$T_k$第一道工序的茶温达到$T_k$，即

$$T^{(1)}(\tau_k) = T_k.$$

让我们看看如果在时间 $T_k$ 将茶从一个玻璃杯倒到另一个玻璃杯中，第二个过程的温度是多少：

$$T^{(2)}(\tau_k)_{\text{после}} = \beta T^{(2)}(\tau_k)_{\text{до}} = \beta T'(\tau_k)/\beta = T'(\tau_k) = T^{(1)}(\tau_k) = T_k.$$

所以，我们发现一般的凉茶方法都需要同样的时间。因此，您可以在0到$T_k$的范围内随时将茶从一个玻璃杯倒到另一个玻璃杯中（参见图）。
