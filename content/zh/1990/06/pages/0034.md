M1204*。点 A、B、C 在平面上给出，即三个圆的中心。每个圆均匀膨胀（所有圆的半径以相同的速率增加）。一旦两个圆相互接触，它们就会“弹出”——它们的半径减小到 0——并开始膨胀。如果距离AB、BC、CA都是整数，那么这个过程是周期性的吗？

研究如果三角形 ABC 是 a) 等边形，则该过程如何发展； b) 等距； b*) 边长为 3、4、5 的矩形。初始状态可以是任意的（不仅是“零”）。

图 1.

我们将考虑一般情况：气泡的初始半径是任意的。

a) 三角形ABC是等边三角形。第一次破裂后，两个气泡的半径将为零。第二次弹出将打破所有三个气泡。然后该过程将定期重复。

6-1) 三角形ABC是等边三角形，底比边小。然后，在第一次或第二次拍手时，两个气泡将破裂，其中心位于三角形的底部。此外，它们的半径将相等 (图 1)。很快，所有三个气泡将同时破裂，之后周期性过程开始。一个周期（周期）内拍手的次数取决于边长与底边长度的比率。

现在让我们从更一般的角度来看剩下的情况：6-2）（底边大于边）和c）。我们看到，在这些情况下，该过程通常不会是周期性的。

让我们分别用a、b和c表示线段BC、AC和AB的长度。让我们定义$a \leq b < c$。 （我们已经考虑过选项$b = c$。）请注意，中心位于 A 点和 B 点的气泡（简称：气泡 A 和 B）只能在过程的一开始接触。此后，气泡C参与每次拍击。因此，数量$c$的具体值不起任何作用（只要满足条件$b < c$）。同样清楚的是，重要的不是长度 $a$ 和 $b$ 本身，而是它们的比率 $r = b/a$。因此，我们将进一步考虑边长为$BC = 1$、$AC = r \geq 1$、底边为$AB > r$的三角形ABC。

让我们用$x$和$y$表示任意拍击后气泡A和B的半径。然而，将会有下一次拍手，具体取决于哪一个更大——与气泡相对的一侧的长度，或者另一侧与该气泡的半径之间的差。因此，量$x$和$y$的变换按照表1所示的规则进行。

表1

| 目前状态 | 转换 |
| :--- | :--- |
| 1 $y = 0, r - x > 1$ | $x_{\text{HOB}} = x + \frac{1}{2}, y_{\text{HOB}} = 0$ |
| 2 $y = 0, r - x = 1$ | $y_{\text{HOB}} = 0, x_{\text{HOB}} = 0$ |
| 3 $y = 0, r - x < 1$ | $y_{\text{HOB}} = (r - x)/2, x_{\text{HOB}} = 0$ |
| 4 $x = 0, 1 - y < r, y \neq 0$ | $x_{\text{HOB}} = (1 - y)/2, y_{\text{HOB}} = 0$ |

这里$x_{\text{HOB}}$和$y_{\text{HOB}}$是下一次拍手后立即的$x$和$y$的新值。选项$x = 0, 1 - y \geq r$未包含在表中，因为它不可能与$r > 1$一起使用，并且在这种情况下
