定理（博尔扎诺-维尔斯特拉斯）。如果函数 $y = f(x)$ 被定义并且在区间 $[a; b]$、$f(a) < 0$、$f(b) > 0$ 上连续，则方程 $f(x) = 0$ 的根属于区间 $(a; b)$。

这个定理在数学分析过程中得到了证明。不过，它的含义很明确：图 4 所示的连续曲线必然与$Ox$ 轴相交。我们将来会多次使用它。

特别是，如果给定函数在区间 $[a; b]$ 上返回或终止，则方程 $f(x) = 0$ 具有属于区间 $(a; b)$ 的唯一根。

现在让我们检查方程（3）。它相当于等式

$$\ln a = \frac{\ln x}{x}.$$  (3')

让我们绘制函数 $h(x) = \frac{\ln x}{x}$。从$h' = \frac{1 - \ln x}{x^2}$开始，函数$h$在$x < e$处返回并在$x > e$处终止，并且在点$x = e$处达到最大值$\frac{1}{e}$（图5，a）。因此，方程（3'）如果$\ln a > \frac{1}{e}$（即在$a > e^{\frac{1}{e}}$）则无根，并且在$a = e^{\frac{1}{e}}$有单根$x = e$。练习

3. 证明对于$0 < \ln a < \frac{1}{e}$，即对于$1 < a < e^{\frac{1}{e}}$，方程(3')恰好有两个根。

4. 使用图 5 的图形，并证明函数$y = x^{\frac{1}{x}}$ 的图形具有图 5, b 所示的形式，并检查方程$x^{\frac{1}{x}} = a$。

5. 绘制函数 $y = x^x$ 并检查方程 $x^x = a$。

因此，最后，对于$1 < a < e^{\frac{1}{e}}$方程（2）恰好有两个根，对于$a = e^{\frac{1}{e}}$它有一个根$x = e$并且对于$a > e^{\frac{1}{e}}$没有根。
