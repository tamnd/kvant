让我们首先证明以下引理：当且仅当周长$P_{XBY}$等于$2BT$时，内切于角$XBY$且在点$T$和$T'$与其边相切的圆将位于三角形$XBY$（图1）的外部。

如果圆接触直线 $XY$，则从一点切线定理立即得出等式 $P_{XBY} = 2BT$（参见 图 1）。相反，如果$P_{XBY} = 2BT$，则三角形$XBY$的外圆在距$B$距离$P_{XBY}/2$的点处与直线$BX$相接触，即在点$T$处，因此与给定圆重合。

现在已知 $AM + AN = CM + CN$ (图 2)。那么三角形$ABN$和$MBC$的周长相等（它们的差为$(AB - BM) + AN - CM + (BN - BC) = AM + AN - CM - CN = 0)$。因此，三角形$ABN$的外圆$\omega$也会接触线段$MC$，因此（见图2），

$$2MT = 2BT - 2BM = P_{BMC} - 2BM = CB + CM - BM.$$

另一方面，$\omega$是三角形$AMO$的外圆，因此，

$$2MT = P_{AMO} = OM + MA + AO.$$

将等式右边的差等于零，我们得到：

$$CB + (CM - OM) - (BM + MA) - AO = CB + CO - AB - AO = 0,$$

Q.E.D.

类似地证明了问题的第二个等式隐含了第一个等式，并且它们都等价于第三个等式$BM + OM = BN + ON$。注意，对于四边形$OMBN$（图 2）的“客观”异形圆的存在性，除了众所周知的条件$OM + BN = ON + BM$之外，还有两个等价条件：$AM + MC = AN + NC$和$AO + BC = CO + BA$；这一事实被用于解决问题 M1025 («Kvant», 1987, No. 5, p. 26)。
