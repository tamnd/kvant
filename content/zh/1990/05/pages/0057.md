由电阻率$\varrho$的任何均质材料制成。我们用 $l$ 来表示它的长度。让我们想象这个导体由串联的几个部分组成，例如三个。设它们的长度为 $l_1, l_2$ 和 $l_3$ (图 2)。很明显
$$l = l_1 + l_2 + l_3.$$
让我们将该等式两边乘以比率 $\varrho/S$：
$$\varrho \frac{l}{S} = \varrho \frac{l_1}{S} + \varrho \frac{l_2}{S} + \varrho \frac{l_3}{S}.$$
但$\varrho l/S = R$是整个导体的电阻，$\varrho l_1/S = R_1$、$\varrho l_2/S = R_2$和$\varrho l_3/S = R_3$分别是其第一、第二和第三部分的电阻。因此，
$$R = R_1 + R_2 + R_3.$$ (2)
这是计算串联导体时的总电阻所需的公式。
现在想象同一个导体由多个（例如三个）并联部件组成，其横截面为 $S_1, S_2$ 和 $S_3$ (图 3)。与之前的案例类似，
$$S = S_1 + S_2 + S_3,$$
或者，乘以公因数$1/(\varrho l)$后，
$$\frac{S}{\varrho l} = \frac{S_1}{\varrho l} + \frac{S_2}{\varrho l} + \frac{S_3}{\varrho l}.$$
图 2.
图 3.

根据式（1），
$$\frac{S}{\varrho l} = \frac{1}{R}, \frac{S_1}{\varrho l} = \frac{1}{R_1}, \frac{S_2}{\varrho l} = \frac{1}{R_2} \text{ и } \frac{S_3}{\varrho l} = \frac{1}{R_3},$$
我们以一种可摆姿势的方式得到它
$$\frac{1}{R} = \frac{1}{R_1} + \frac{1}{R_2} + \frac{1}{R_3}.$$ (3)

使用这个公式，您可以找到并联导体时的总电阻。
此处仅针对特定类型导体的特定情况推导公式（2）和（3）——第一种情况中材料相同、横截面相同，第二种情况中长度相同。然而，它们也适用于最一般的情况。

M·马林奇克
