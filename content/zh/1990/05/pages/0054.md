然而，让我们回到第一个例子（参见图1）。事实上，摩擦力仅在运动开始时才显着，因此让我们考虑一下当理想物体的相互水平运动大于 $l$ 时会发生什么。上半身上升到犁沟的顶部，开始下降，其势能转化为动能，在下降结束时冲击下一个犁沟的上升边缘。如果在这种情况下再次能够将动能完全转换成势能，即能够将上半身提升到下一个犁沟的顶部，那么上半身的进一步运动可以在不施加额外的力的情况下进行。这将意味着摩擦力消失了。如果这种情况没有发生，那么，尽管完全不存在作为物质特性的摩擦，但摩擦力仍然存在。

让我们更详细地考虑上半身撞击下一个犁沟边缘时的速度变化 dk (图 3)。我们假设条件是理想的，并且在冲击过程中没有能量损失（即发生绝对弹性冲击）。在这种情况下，以下定律成立：入射角等于反射角；在这种情况下，角度是从垂直于发生碰撞的表面测量的，即，在我们的例子中，从垂直于凹槽上升边缘的角度测量的（参见图 3上的角度$\gamma$）。

让我们用 $\vec{v}_1$ 表示下降结束时的速度（它沿着从犁沟下降的平面），用 $\vec{v}_2$ 表示撞击后的速度。让我们将这些速度分解为沿 $X$ 和 $Y$ 轴的分量，分别指向水平和垂直方向*)：

$$v_{1x} = v_1 \cos \alpha, \quad v_{1y} = v_1 \sin \alpha,$$
$$v_{2x} = v_2 \cos \varphi, \quad v_{2y} = v_2 \sin \varphi.$$

从图 3 我们找到角度$\alpha$和$\varphi$之间的对应关系：

$$\varphi = \pi - \alpha - 2\gamma,$$
$$\gamma = \pi - \pi/2 - 2\alpha = \pi/2 - 2\alpha,$$
在哪里
$$\varphi = 3\alpha.$$

让我们使用参考书中已知的三角测量公式
$$\cos 3\alpha = 4 \cos^3 \alpha - 3 \cos \alpha,$$
$$\sin 3\alpha = -4 \sin^3 \alpha + 3 \sin \alpha,$$
$$\cos^2 \alpha + \sin^2 \alpha = 1$$

并写出撞击前后的相对对应关系：

$$\frac{v_{2x}}{v_{1x}} = \frac{\cos 3\alpha}{\cos \alpha} = 1 - 4 \sin^2 \alpha,$$
$$\frac{v_{2y}}{v_{1y}} = \frac{\sin 3\alpha}{\sin \alpha} = -(1 - 4 \cos^2 \alpha).$$

在能量守恒的条件下，上半身在撞击下半身后，只有当速度矢量$\vec{v}_2$沿着沟槽dk的平面向上时，才会准确地上升到下一个沟槽dk的顶部，并且速度值与撞击前相同。 Thisomy 满足条件

$$\frac{v_{2x}}{v_{1x}} = 1 \text{ и } \frac{v_{2y}}{v_{1y}} = -1.$$
