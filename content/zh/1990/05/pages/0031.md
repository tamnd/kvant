mitsey，我们将增加单词开头的单位数量，在几个这样的步骤中我们将获得单词 (*)。）

让我们证明在我们的问题中每个单词都被简化为以下形式

$$1...1 \underbrace{0...0}_{a} \underbrace{1}_{b} \underbrace{0...0}_{b}$$

（或者，顺便说一句，全部为零）。如果这种类型尚未实现，那么我们将选择段 0...010...01（或 0...011）到单词中，从第一个单词开始，到其后的第二个单元结束。翻转这个片段，我们将增加单词开头的个数。只要第一个零的右边至少有两个就可以做到这一点。

(**) 形式的单词数等于整数对 $(a, b)$ 的数量，其中 $a \geq 0, b \geq 0, a + b \leq 9$，即 $1 + 2 + ... + 9 = 45$ (图 1)。

仍有待证明单词（**）之间没有同义词。为此，请注意，每次反转时，我们的操作都会保留其右侧有偶数个 1 的零的数量以及奇数个 1 之前的零的数量（这些数字是不变量*）。此外，如果你标记原始单词的任何一个零，并计算反转前后其后面的 1 的数量，结果会发现这个数字保留了奇偶性：“偶”零仍然是“偶”，“奇”零仍然是“奇”。这对于零来说是明显的，保持静止。对于被翻转的段上的零，这是因为从所选零开始的该字段的单元数与其右侧具有相同的奇偶性（图2）。由于对于单词 (**)，指示的不变量等于 $a$（“奇数”零的数量）和 $b$（“偶数”零的数量），因此不同 $a$ 和 $b$ 的此类单词不能是同义的。

M1199。证明如果方程$ax^2 + (c-b)x + (e-d) = 0$有大于1的根，则方程$ax^4 + bx^3 + cx^2 + dx + e = 0$至少有一个根。

令方程根$ax^2 + (c-b)x + (e-d) = 0$等于$x = t^2$，其中$t > 0$；然后

$$at^4 + ct^2 + e = bt^2 + d.$$

让我们输入$f(x) = ax^4 + bx^3 + cx^2 + dx + e$。从前面的等式可以得出，数字

$$f(t) = (at^4 + ct^2 + e) + t(bt^2 + d),$$

$$f(-t) = (at^4 + ct^2 + e) - t(bt^2 + d)$$

有不同的符号（因为$t > 1$，符号决定了第二项——模数大）。因此，在区间$[-t, t]$上，方程$f(x) = 0$必须有根。 （我们在这里使用这样一个事实：在线段末端取不同符号值的连续函数必须在某个点消失。）

D·福明
