关于导体的电子电阻
正如您所知，导体的电阻取决于其制造材料、导体的尺寸和形状。因此，例如，对于恒定横截面 $S$ 和长度 $l$ 的均质导体，电阻

$$R = \rho \frac{l}{S},$$

其中$\rho$是比电子电阻。有时，不谈论导体的电阻，而是谈论其倒数——电子电导率，会更方便。

第一个试图弄清楚直接电子电流通过导体的意义的物理学家是来自科隆的一位谦虚的教师乔治·西蒙·欧姆（Georg Simon Ohm，1789-1854）。 1826 年，欧姆发表了他的第一个实验结果。

当然，欧姆没有现代化的高精度电子测量仪器和可靠的电流源可供使用，因此欧姆一路上必须解决许多复杂的实际问题。

因此，欧姆在他的第一个实验中使用伏打柱作为电流源，这是两种不同金属（例如银和锌）的交错层，由浸泡在盐栅中的纸隔开。与此同时，他注意到电流电路中的电流强度随着时间的推移会明显导致死亡。显然，在这种情况下建立这种定量模式几乎毫无意义。当欧姆熟悉1821年发现热电效应的塞贝克（Thomas Johann Seebeck (1770-1831) - 德国物理学家）的作品时，他开始在他的第一个实验中使用热元件，该元件可以产生非常稳定的电流。在欧姆设置中，其图如下所示

在了解了奥斯特（Hans Kristin Oersted，1777-1851 - 丹麦物理学家）于 1820 年发现电流对磁针的影响的实验后，欧姆决定通过位于载流导体附近的磁针的偏转角度来表征电流的强度。为此，将导体放置在磁子午线平面中（参见图1），在导体中没有电流的情况下，磁针6位于其上方并与其平行，并且悬挂箭头的略实心的线7不变形。当电流流过导体时，磁针离开磁子午线平面并扭曲悬浮液。欧姆转动固定了悬架上端的头8，使箭头再次与载流导体平行，并测量旋转角度。该角度被视为电流磁作用的特征。

为了研究各种金属的电导率，欧姆采用了相同截面、但由不同材料制成的电线，并将它们一根一根地连接到电路中。作为一名伊顿教授，他选择了一定长度的铜线，以其电导率作为1000个常规单位，测量磁针与载流导体平行时磁头的旋转角度。然后，他在电路中加入了其他金属的接线，并将它们缩短，直到头部的旋转角度与该接线的情况相同。根据获得的长度，可以判断相应材料的电导率。因此，欧姆发现金的电导率是574常规单位，银是356，锌是333等。

然后欧姆检查了由相同金属制成但厚度不同的电线，并以与确定各种金属的电导率相同的方式对其进行处理。他发现，如果由相同材料制成的导线的长度与其横截面的相对面积之比，即这些导线的$l/S$相同，那么它们的电阻是相同的。结果发现，电阻$R$与这个比率：$R \sim l/S$成正比。比例系数$q$的输入取决于物料的性质；您可以为接线电阻写出对应关系（1）。现在让我们展示如何根据此对应关系获得您已知的用于计算串联或并联导体系统的总电阻的公式。

由电阻率$\varrho$的任何均质材料制成。我们用 $l$ 来表示它的长度。让我们想象这个导体由串联的几个部分组成，例如三个。设它们的长度为 $l_1, l_2$ 和 $l_3$ (图 2)。很明显
$$l = l_1 + l_2 + l_3.$$
让我们将该等式两边乘以比率 $\varrho/S$：
$$\varrho \frac{l}{S} = \varrho \frac{l_1}{S} + \varrho \frac{l_2}{S} + \varrho \frac{l_3}{S}.$$
但$\varrho l/S = R$是整个导体的电阻，$\varrho l_1/S = R_1$、$\varrho l_2/S = R_2$和$\varrho l_3/S = R_3$分别是其第一、第二和第三部分的电阻。因此，
$$R = R_1 + R_2 + R_3.$$ (2)
这是计算串联导体时的总电阻所需的公式。
现在想象同一个导体由多个（例如三个）并联部件组成，其横截面为 $S_1, S_2$ 和 $S_3$ (图 3)。与之前的案例类似，
$$S = S_1 + S_2 + S_3,$$
或者，乘以公因数$1/(\varrho l)$后，
$$\frac{S}{\varrho l} = \frac{S_1}{\varrho l} + \frac{S_2}{\varrho l} + \frac{S_3}{\varrho l}.$$

根据式（1），
$$\frac{S}{\varrho l} = \frac{1}{R}, \frac{S_1}{\varrho l} = \frac{1}{R_1}, \frac{S_2}{\varrho l} = \frac{1}{R_2} \text{ и } \frac{S_3}{\varrho l} = \frac{1}{R_3},$$
我们以一种可摆姿势的方式得到它
$$\frac{1}{R} = \frac{1}{R_1} + \frac{1}{R_2} + \frac{1}{R_3}.$$ (3)

使用这个公式，您可以找到并联导体时的总电阻。
此处仅针对特定类型导体的特定情况推导公式（2）和（3）——第一种情况中材料相同、横截面相同，第二种情况中长度相同。然而，它们也适用于最一般的情况。
