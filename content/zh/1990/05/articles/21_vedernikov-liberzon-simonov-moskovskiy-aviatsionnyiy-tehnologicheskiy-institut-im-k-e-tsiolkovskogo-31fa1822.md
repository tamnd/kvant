莫斯科航空技术学院得名。 K·E·齐奥尔科夫斯基

数学

笔试

选项1

1. 解方程
$$6 + 4\sqrt{3} - x = 5x.$$

2. 解决不等式
$$\frac{4}{\lg 10x} - \frac{5}{\lg 100x} \ge 0.$$

3. 解方程
$$\sin 3x - 4 \sin x \cos x = 0.$$

4. 容积为1200立方米的水池有两条管道：供水和排水。如果两个管道同时打开，水池将在 60 小时内充满。如果只有一根管子打开，那么向水池注水比将水排空要少两个小时。每根水管每小时输送多少水？

5. 如果三角形的两条边分别为 1 和 $\sqrt{13}$，且第三条边的中位数为 2，则确定三角形的面积。

选项2

1. 解决不等式
$$x^2 + 2x - 4 \leq x + 2.$$

2. 解方程
$$x + \log_2(9 - 2^x) = 3.$$

3. 解方程
$$\sin^3 x + \cos^3 x = \cos 2x.$$

4. 从$A$到$B$，旅客列车需3分钟，货运列车需12分钟。货运列车从$A$行驶到$B$期间，客运列车多行驶了288公里。如果每趟列车的速度提高10公里/小时，则客运列车从$A$到$B$的距离只需2分钟，货运列车则需要24分钟。确定从 $A$ 到 $B$ 的距离。

5. 绘制到斜边的直角三角形的中线将其分成周长为 $p_1$ 和 $p_2$ 的两个三角形。找出三角形的边。

选项3

1. 解方程
$$|x - 2| = 3x - 4.$$

2. 解决不等式
$$\frac{1}{3^x + 1} + \frac{1}{3^x - 3} \leq 0.$$

3. 解方程
$$1 + \sin 2x = \sin x + \cos x.$$

4. 一名游客6点钟出发，第二名游客7点钟接他。八点钟，他们集合，马不停蹄，继续赶路。如果第一个到达第二个出发地点，比第二个到达第一个出发地点晚 28 分钟，他们每个人在整个旅程中花费了多少时间？每个杆都以恒定速度停止。

5. 将直角三角形中线的交点从对应于 3 和 4 的距离处的直角三角形的边上移开。找到从该点到斜边的距离。

轨道之间的侧向$l=2$米。 $t=2$ 秒后，坦克将与初始移动方向成什么角度移动？

2. 一只青蛙坐在 $l=0,8$ 米长的码头末端。木板漂浮在池塘表面。青蛙必须以什么最低速度跳跃才能在跳跃后到达码头的另一端？青蛙和码头的质量相同。让我们对水提出一个主张。

3. 一辆发动机运转的汽车，初始速度为$v=72$公里/小时，正在上坡行驶，其表面与地平线成$\alpha=30^\circ$角。如果路面摩擦系数为$\mu=0,4$，能自动翻越多高的山峰？

4. 腔室中充满了温度为$t=27^\circ\text{C}$的氢气和氧气的混合物。室内气体的分压相同。房间被密封并发生爆炸。氢气与氧气化合反应完成后，室内压力立即变为原来的两倍。此时室内温度是多少？

5. 多少质量的水通过半径为 $r=0,25$ mm 且被其润湿的中心管上升？水的表面张力系数$\sigma=0,073$N/m。

6. 带电球在真空中彼此距离 $r=60$ cm，被 $F=0,3$ N 的力吸引。球的总电荷为 $Q=4$ µC。确定每个球的电荷。电常数$\varepsilon_0=8,85 \cdot 10^{-12}$F/m。

7. 电动机由电动势为 $\varepsilon=12$ V 的电池供电。如果当电枢完全制动时，电流 $I_2=3$ A 流过电路，当电流 $I_1=2$ A 流过电动机的绕组时，电动机会产生多大功率？

8. 如果电容器的最大电荷为$q_m=1$ µC，电路中的最大电流为$I_m=10$ A，则确定电路的谐振频率。

9. 两个焦距为 $F=30$ cm 的镜头放置时相距 $l=15$ cm。系统在物体的哪些位置产生有效图像？

10. 在以 0.6 秒（光速）速度飞行的中性粒子衰变过程中，形成了两个声子。最小光子角是多少？
