关于一个奇妙的方程式

物理和数学科学博士候选人 Y. SIDOROV

让我们从一个问题开始，据传闻，这个问题曾经在口试期间向申请人提出过。

方程有多少个根？

$$\left( \frac{1}{16} \right)^x = \log_{\frac{1}{16}} x?$$

如果你画出函数 $y = a^x$ 和 $y = \log_a x$ 对于 $0 < a < 1$ (图 1) 的图形，看起来这些图形必然相交于一点，而这一点位于直线 $y = x$ 上。

然而，很明显方程（1）有两个根：$x = \frac{1}{2}$和$x = \frac{1}{4}$（通过替换检查），并且与这些根对应的图的交点并不位于直线$y = x$上。因此，方程(1)至少有三个根。

这一事实让大多数高中毕业生感到惊讶，不幸的是，许多老师也感到惊讶，尽管这个问题相当“古老”，并且经常作为例子给出，表明必须非常谨慎地使用解方程的图形方法。问题的错误解法的秘密很简单：图1显示了非常粗略的图形草图，这导致了关于方程（1）的根数的错误结论。

我们将研究一般方程：
$$a^x = \log_a x$$
对于$a$的不同值（当然，这里是$a > 0, a \neq 1$）。

请注意，对于任何 $a$ 方程 (2) 等价于方程
$$a^{a^x} = x.$$

与方程（2'）一起，我们考虑方程
$$a^x = x.$$

设$x_0$为方程(3)的根。

那么$a^{a^x} = a^{x_0} = x_0$，即$x_0$也是方程（2'）和（2）的根。

因此，如果方程（3）至少有一个根，则方程（2）也有根。

让我们再补充一点。在$a > 1$，函数$f(x) = a^x$增加。式(2')可以写成：$f(f(x)) = x$，式(3)的形式为$f(x) = x$。

引理。如果函数 $y = f(x)$ 递增，则方程 $f(f(x)) = x$ 和 $f(x) = x$ 等价。

证明。令$x_0$为方程$f(x) = x$的根。然后$f(f(x_0)) = f(x_0) = x_0$，所以$x_0$是第一个方程的根。相反，设$f(f(x_0)) = x_0$和$x_0 \neq f(x_0)$。那么$x_0 > f(x_0)$或$x_0 < f(x_0)$，由于函数$f$是递增的，我们发现在第一种情况下是$f(x_0) > f(f(x_0)) = x_0$，在第二种情况下是$f(x_0) < f(f(x_0)) = x_0$。矛盾。

从引理和前面的评论来看，(2) 等价于方程 $a^x = x$。

定理（博尔扎诺-维尔斯特拉斯）。如果函数 $y = f(x)$ 被定义并且在区间 $[a; b]$、$f(a) < 0$、$f(b) > 0$ 上连续，则方程 $f(x) = 0$ 的根属于区间 $(a; b)$。

这个定理在数学分析过程中得到了证明。不过，它的含义很明确：图 4 所示的连续曲线必然与$Ox$ 轴相交。我们将来会多次使用它。

特别是，如果给定函数在区间 $[a; b]$ 上返回或终止，则方程 $f(x) = 0$ 具有属于区间 $(a; b)$ 的唯一根。

现在让我们检查方程（3）。它相当于等式

$$\ln a = \frac{\ln x}{x}.$$  (3')

让我们绘制函数 $h(x) = \frac{\ln x}{x}$。从$h' = \frac{1 - \ln x}{x^2}$开始，函数$h$在$x < e$处返回并在$x > e$处终止，并且在点$x = e$处达到最大值$\frac{1}{e}$（图5，a）。因此，方程（3'）如果$\ln a > \frac{1}{e}$（即在$a > e^{\frac{1}{e}}$）则无根，并且在$a = e^{\frac{1}{e}}$有单根$x = e$。练习

3. 证明对于$0 < \ln a < \frac{1}{e}$，即对于$1 < a < e^{\frac{1}{e}}$，方程(3')恰好有两个根。

对于 0 < a < 1，方程 $a^x = x$ 有一个根 $x_0$。
考虑功能
$$f(x) = a^x - \log_a x$$
并研究她的行为。为此，我们计算其导数
$$f'(x) = a^x \ln a - \frac{1}{x \ln a} = \frac{xa^x \ln^2 a - 1}{x \ln a}.$$
现在让我们考虑所得分数的分子 $\varphi(x) = xa^x \ln^2 a - 1$。对于所有$x > 0$，它的分母都是负数，因此符号$f'(x)$与符号$\varphi(x)$相反。
练习 6. 证明函数 $\varphi(x)$ 在 $x < -\frac{1}{\ln a}$ 处递减，在 $x > -\frac{1}{\ln a}$ 处返回，并在 $x = -\frac{1}{\ln a}$ 处取得最高值 $\varphi_{\max}$。
从练习 6 可以看出，如果 $\varphi_{\max} \leq 0$ 对于所有 $x$，则函数 $f(x)$ 对所有 $x > 0$ 返回，因此 $x_0$ 是方程 (2) (图 6, a, b) 的唯一根。

求解不等式$\varphi_{\max} = -\frac{\ln a}{e} - 1 \leq 0$，我们得到$a \geq e^{-e}$。因此，对于 $e^{-e} \leq a < 1$，方程 (2) 恰好有一个根 $x = x_0$。

如果$0 < a < e^{-e}$，则$\varphi_{\max} > 0$，并且函数$\varphi$的图形具有图 6，c所示的形式。为了证明这一点，只要注意到$\varphi(0) = -1$和$\varphi(1) < 0$就足够了。 $e^{-e} < a < 1$和$a = e^{-e}$的函数$f(x) = a^x - \log_a x$图如图7、a、b所示。
