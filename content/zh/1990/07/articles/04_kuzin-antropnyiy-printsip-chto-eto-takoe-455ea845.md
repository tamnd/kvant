人择原理 -
这是什么？

A·库津

小介绍

我的文章致力于科学试图回答一个永恒的问题。这个问题：在这个巨大的世界里，一个小人物有什么意义吗？他是谁——宇宙发展的目标、创造的领导者，还是随机的、原则上与其他自然过程没有什么不同的东西？人类的出现是整个宇宙发展的结果还是某种随机的转变？生命是否已经适应了“对此一无所知”的外部条件，或者这些条件本身是否适应了生命的出现？

长期以来，科学没有事实来以合理的方式回答这些问题（尽管不乏非理性的答案）。科学所掌握的有关世界的信息是零散的；宇宙发展的全貌是不可见的。但几乎清晰的几个世纪的有组织的服务数据正在结出硕果。现在我们可以谈论有关世界的科学图景和宇宙整体观的一切。哦，还有很多我们不知道的事情！因此，人们不应该认为这个答案是最终的；这并不是“谴责”一个人成为造物之冠的司法判决。斯克雷皮克关于科学知识局限性的看法总是正确的。问题是永恒的，因为它们无法一劳永逸地得到解答。

科学阐述世界和人的问题

人择原理是思想实验的产物。实验是这样的：我们在心理上改变一些自然法则，同时思考一个人是否可以存在？当然，在回答这个问题时，我们必须关注一个人身上重要的东西——毕竟，很明显，当世界其他地方发生变化时，我们不能指望他完全不变。请注意，如果我们说一个人的两个主要品质是理性和自由，那么我们就不会误解，没有这两个品质他就不能被视为一个人。自由是保持自我的能力，也就是说，不完全由特定时刻周围的事物决定，而是从内部、从自己开始行动。理性是自由的条件，因为没有它，就不可能对环境做出积极的反应（从这个意义上说，动物也有理性）。但自然科学还没有准备好在其一般表述中处理有关理性和自由的问题。我们需要在这个全球性问题中找到一些他们可以坚持的东西。这是这个烘焙。

只有复杂的存在物才能主动抵抗环境、理解环境并改变其存在的传达需求。复杂程度可以定量地表征，这就是自然科学所做的。

人择原理回答了这个问题：是否每一种精神世界秩序都以逐渐复杂的结构的出现为前提？

我强调，这种结构的出现只是人类出现的必要条件，而非充分条件。但对这一必要条件的分析已经为我们理解进化过程提供了很多帮助。

让我们从这个角度来思考宇宙的演化。

根据现代概念，宇宙在时间和空间上是有限的，即它的年龄是有限的（大约150亿年），它的体积也是有限的。科学家估计宇宙中粒子的数量是巨大的，但仍然是有限的$N \sim 10^{80}$。宇宙从一个极其倾斜的高温状态“开始”，初始曲率半径为$\sim 10^{-34}$厘米。从那时起，宇宙一直在不断膨胀，就像一个充满空气的气球，而“填充”宇宙的星系、恒星、星云（物质）正在彼此远离，就像气球上的图案一样。物质、空间、时间是相互依存的；他们一起开始，所以诸如“宇宙出现之前发生了什么？”之类的问题。或者“如果你到达边缘，你会看到什么？”的表述不正确。 “在此之前，没有时间，不可能到达宇宙的极限，就像你无法到达地球的极限一样。

在“开始”后的最初时刻，温度非常高，无法形成稳定的结构。此外，基本粒子不断地相互转化。随着它的膨胀，温度下降并形成稳定的粒子——电子、质子、中子。这是第一个结构，第一个令人惊讶的情况与其外观有关。情况是这样的：在最初沸腾的大锅中，粒子和反粒子的数量相等，但当它们保留下来时，对称性被打破，粒子的数量$N_i$竟然大于反粒子的数量$N_a$。因此，物质与反行列的英国性并不完整，并非所有物质都转化为光。奇妙的是，$(N_i - N_a)/N_i \sim 10^{-9}$，即只有十亿个粒子没有变成光（我们在另一个场合也遇到过这个数字）。

进一步剩余，形成最简单元素的原子 - 氢和凝胶。它们需要稳定的质子才能存在。众所周知，质子$m_p$和中子$m_n$的质量相差不大：$m_n - m_p \approx 2,5$$m_e$（$m_e$是电子的质量）。较重的中子仅存在 16 分钟，然后衰变成质子、电子和电子反中微子：

$$n \rightarrow p + e^{-} + \tilde{v}_e.$$

在原子核内部，核物质的密度和动能是部分的，会发生象征性的反应。因此，在原子核内部，中子处于动态平衡状态。如果中子比质子轻，质子就会衰变 -

$$p \rightarrow e^{+} + n + v_e$$

（е$^+$是正电子，$v_e$是中微子），而作为恒星主要燃料和生命所需主要水的氢将不存在。

但元素原子的形成路径是有保证的。请注意，目前只有最简单的——氢气和凝胶。它们在各处同时合成，对于合成较重元素的原子核，它们需要特殊的条件：为了合成此类原子核，需要最简单的稳定原子核作为起始材料和这些原子核只能聚变的高温，并且这些温度必须持续很长一段时间（数十亿年） - 热核反应不会很快进行。但仅仅过了数十亿年，甚至数十万年，宇宙就已经处于一种充满当前重量的状态——其中的平均密度和温度都非常低。这样的条件有利于原子的存在（毕竟在高温下，电子不会停留在原子核附近），但不适合其原子核的合成。

甚至更小的情况——原恒星。 （请注意，当宇宙还没有膨胀太多时，引力必须“有时间”形成恒星。）随着原恒星的压缩，其中的温度会升高，直到已经开始的热核反应，伴随着强大的能量释放，离开锄星。

重要的是，第一颗恒星主要由氢组成（年轻宇宙中氢与氦的比例约为 3:1）——这正是因为质子比中子轻，因此质子数量较多，并且完全形成氦。氦星会非常热，并且寿命不会很长，不足以在其行星上发生生物进化。

“炼金术”转变发生在恒星深处——轻元素的原子核碰撞、融合并变成较重元素的原子核。这里的条件过程是由核和电磁相互作用力的非常微妙的“调整”决定的。如果没有这种调整，从凝胶到碳和氧再到铁的反应链可能会在第一个环节被破坏。

$$3^4\text{He} \rightarrow ^{12}\text{C} + 2\gamma$$

$$2^4\text{He} + (99 \pm 6)\text{кэВ} \rightarrow ^8\text{Be}$$

$$^8\text{Be} + ^4\text{He} \rightarrow ^{12}\text{C} + 2\gamma$$

作为给定的。这是最简单的例子：任何电荷都是电子电荷的倍数，这一事实用公式 $Q = Ne$ 表示（N 是整数）。这里的参数是电子电荷$e$。或者另一个例子：两个质量$m_1$和$m_2$的吸引力为

$$F = G \frac{m_1 m_2}{r_1^2}.$$

这里的参数是引力常数$G$。又如：背景能量与其频率$\omega$：$E = \hbar \omega$成正比。该参数是普朗克常数$\hbar$。

$e, \hbar, G, c$（光速）等量在物理学中被称为世界常数。就其本身而言，这些常数的数值一无所知，因为它们从一种单位制转移到另一种单位制时会发生变化。但它们的无量纲组合具有普遍意义。例如，您可以从 $e, \hbar$ 和 $c$ 组成唯一的无量纲组合 - 数字 $\alpha = e^2 / \hbar c \approx 1 / 137$。这个数字称为精细结构常数；它表征了电磁相互作用的“强度”。原子中的电子和自由电子之间相互作用的特征能量只是对静止能量$m_e c^2$的一个小修正（在某种程度上是$\alpha$的数量级）。例如，原子序数$Z$的原子中电子的能量为

$$E \sim m_e c^2 (Z \alpha)^2.$$

由于$\alpha$很小，电子转变为其他粒子的过程不太可能。 $\alpha$的小保证了电子相反结构——原子、固体的稳定性。 $Z \gtrsim \alpha^{-1} = 137$的重原子是不稳定的：原子核表面附近的电磁场被压缩，以至于开始产生电子-正电子对，这些电子-正电子对屏蔽了原子核的“多余”电荷，使其值小于$e \alpha^{-1}$的值。

类似的无量纲常数可以写为所有相互作用过程——强（S）、弱（W）和引力（G）。对于最后一张

$$\alpha_G = G m_p^2 / \hbar c \sim 10^{-39} (m_p - \text{масса протона}).$$

已知$\alpha_S \sim 15$，$\alpha_W \sim 10^{-5}$。这两种相互作用仅发生在原子核半径数量级的距离处。

因此，四个交互作用是四个自由参数 $\alpha_k$ ($k \rightarrow e, G, S, W$)。除此之外，我们还可以添加空间维度 $d = 3$、宇宙中的部分数量 $N \sim 10^{80}$、光子数量与部分数量之比 $S \sim 10^9$ 以及电子和质子质量之比 $m_e / m_p \approx 1 / 1837$。最后一个数字原则上应该通过$\alpha$、$\alpha_S$和$\alpha_W$来表达，但我们还不知道如何做到这一点。一般来说，物理学家的梦想是从一个数字中推导出所有命名的数字。但目前这还只是一个梦想。

为了使生命成为可能，自由参数之间必须满足许多对应关系。我举几个例子，只是为了说明。

成功处理恒星的宇宙最佳膨胀率确保符合以下关系

$$N \alpha_G^2 \sim 1.$$

像太阳这样不太热也不太冷的恒星存在的可能性取决于对应关系。

$$\alpha_G \sim \alpha^{12} (m_e / m_p)^4.$$

为了使中微子流（它们仅参与弱相互作用）能够摆脱超新星的外壳，必要条件是

$$\alpha_W^4 \sim \alpha_G (m_p / m_e)^6.$$

为了在引力不稳定性有时间发展之前在宇宙演化过程中形成原子，宇宙变得便宜，这是满足对应关系所必需的

$$S \sim \alpha^{-2} (m_p / m_e),$$

$$S \leq \alpha^{10} (m_p / m_e) \alpha_G^{-1}.$$
