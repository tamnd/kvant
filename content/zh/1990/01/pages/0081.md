$$3a(\sin^2 x - \cos^2 x) + (a^2 + 9)(\cos x - \sin x) = 0,$$
从 $sin x = \cos x$ 或
$$3a(\sin x + \cos x) = a^2 + 9.$$ (*)

方程 (*) 在任何 $a$ 处都没有根，因为
$$\left| \frac{a^2 + 9}{3a} \right| = \left| \frac{a}{3} + \frac{3}{a} \right| \geq 2 > \sqrt{2},$$
和
$$|sin x + cos x| \leq \sqrt{2}.$$

还需要考虑条件$a \cos x \neq 3$、$a \sin x \neq 3$。

1. 令 $(N, M)$ 为使用允许的变换从$(1,1)$ 对获得的一对数字。我们可以重建它的整个史前史，因为$(a, b)$对（其中$a \geq b$）只能从$(a - b, b)$对获得。通过执行相反的过程，我们迟早会得到$(1,1)$对，并可以计算出所需的变换次数。仅当$N$和$M$互质时，才能从对$(1,1)$获得对$(N, M)$。否则，执行相反的过程，我们仍保留在$(L, 0)$，其中$L > 1$。 $(N, i)$和$(N, N - i)$对在逆变换之后给出相同的$(N - i, i)$。
经过这些替换，搜索是如何进行的就很清楚了：对于每对$(N, i)$，其中$1 \leq i < [N/2]$，需要执行所有逆变换并比较这些变换的数量。
