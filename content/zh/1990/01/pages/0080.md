$$\frac{(24 - 16a)x^2 + (18 - 12a)x + (3 - 2a) = 0}{(3 - 2a)(8x^2 + 6x + 1)} = 0.$$

因此，如果 $a$ 是所需值，则 $a = \frac{3}{2}$ 或两个给定方程的公共根就是二次方程 $8x^2 + 6x + 1 = 0$ 的根，即一些数字 $x_1 = -\frac{1}{2}, x_2 = -\frac{1}{4}$。

将$x_1$和$x_2$中的每一个数字代入一般方程，我们得到两个期望值$a$，对应于$a_1 = \frac{3}{16}$和$a_2 = \frac{297}{128}$。

将 $a = \frac{3}{2}$ 代入这些方程，我们得到以下方程组：
$$\begin{cases} 22x^4 + 33x^3 - 24x^2 - 3x + 2 = 0, \\ 11x^4 + 33x^3 + 21x^2 - 3x - 2 = 0. \end{cases}$$

从第一个方程中减去第二个方程，我们得到双二次方程$11x^4 - 45x^2 + 4 = 0$，求解该方程我们找到$x$的四个可能值：$-2, 2, -\frac{1}{\sqrt{11}}, \frac{1}{\sqrt{11}}$。

检查发现值$x = 2$是一个构造，其他三个值满足条件。
