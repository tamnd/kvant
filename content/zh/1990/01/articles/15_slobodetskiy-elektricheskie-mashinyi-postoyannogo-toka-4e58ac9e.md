在本文中我们不会详细讨论各种电机的结构。我们将使用两个基本定律——欧姆定律和能量守恒定律来研究电动机和发电机（发电机是电流感应发电机的旧称）的运行。

文章主要由问题和解答组成。在撰写文章时，在阅读答案之前，请尝试自己回答问题。此外，您将无法执行此操作；思考这个问题无疑会发挥作用，因此最好填写正确的答案。

电动机

所有电动机（或者换句话说，电动机）都必须具有相同的基本部件。首先，这是一个电感器和一个锚。电感器是磁场源。当电流通过电枢绕组时，位于磁场中的电枢旋转。这样，电能就转化为机械能。例如，如果将电机轴连接到机床，则可以启动机器。

问题。独立励磁的直流电机（其中电感器是永磁体或电磁体，其绕组独立于电枢绕组供电）。对于连接到直流电源的这种电机的电枢电路，欧姆定律是如何写的？

回答。在电枢的电路中，存在两个电动势——电流源方向$U$和电枢绕组在电感器磁场中旋转时产生的感应电动势$E_n$。此外，根据楞次定律，感应电动势的符号与电流源的方向相反。因此，欧姆定律将写成这样：

$$U - E_n = IR,$$

(I) 其中$I$是电路中的电流，$R$是电枢绕组和引线的总电阻。

问题。对于这样的电路，能量守恒定律是如何写的？

回答。从源消耗的能量$W_n = UIt$消耗在焦耳热上，焦耳热在电阻$R$处释放，并用于执行有用功$A$。因此，根据能量守恒定律，

$$UIt = I^2Rt + A,$$

或对于容量

$$UI = I^2R + P.$$

(II) 从等式(I)和(II)可以得到许多重要的结果。

问题。有用功率$P$是多少？

回答。将等式两边（I）乘以当前的$I$，我们得到

$$UI - E_n I = I^2R,$$

或者

$$UI = I^2R + E_n I.$$

将得到的等式与等式（II）进行比较，我们可以立即注意到：

$$P = E_n I,$$

即，电机的有用功率等于感应电动势和电流的乘积。

在常数 $U$ 和 $R$ 下，电流值取决于感应电动势：

$$I = \frac{U - E_n}{R}.$$

根据电磁感应定律，电枢绕组中产生的感应电动势与通过该绕组的磁通量$\Delta \Phi/\Delta t$的变化率成正比：

$$E_n \sim \frac{\Delta \Phi}{\Delta t}.$$

反过来，磁通量的变化率与电枢旋转角速度$\omega$成正比。因此，

$$E_n \sim \omega,$$

$$E_n = k\omega,$$

其中$k$是比例系数。 $E_n$ 与 $\omega$ 的图表如图 1 所示。

现在让我们看看电枢电路中的电流和运动的有用功率如何取决于$\omega$。由欧姆定律可知

$$I = \frac{U - E_n}{R} = \frac{U - k\omega}{R}$$

并根据能量守恒定律

$$P = UI - I^2R = E_n I = \frac{kU\omega - (k\omega)^2}{R}.$$

问题。反过来，锚的旋转速度取决于发动机负载。如何？

回答。电感器磁场中作用在电枢上的电力与流过绕组的电流成正比。这些力的力矩也与电流成正比，即$M_s = k_1 I$，

其中比例因子$k_1$取决于电机设计。因为

$$I = \frac{U - k \omega}{R},$$

那

$$M_s = k_1 \frac{U - k \omega}{R},$$

也就是说，作用在电枢上的电力的总力矩线性地取决于电枢的旋转角速度。电枢旋转角速度低时，力矩大；随着角速度的增加，它减小并在以下位置处变为零

$$\omega = \frac{U}{k}.$$

另一方面，机械力的力矩，即所谓的负载力矩$M$，作用在电机轴上。例如，如果发动机均匀地提升绳索上的负载，则负载力矩等于绳索的张力（等于负载的重量）与轴的半径的乘积。在设定模式下，电机电枢以$\omega$的速度非常快地旋转，此时作用在电枢上的电力力矩等于负载力矩。事实上，例如，让锚的旋转速度小于$\omega$。在这种情况下，电子力的力矩大于负载力矩，因此电枢的旋转角速度将增加。如果电枢的旋转角速度大于$\omega$，则电力力矩小于负载力矩。这将导致锚的旋转速度降低至$\omega$。

因此，也确定了锚的旋转角速度，其中

$$M_s = M,$$

或者

$$k_1 \frac{U - k \omega}{R} = M,$$

在哪里

$$\omega = \frac{k_1 U - MR}{k_1 k},$$

即，电枢的旋转角速度线性地取决于负载力矩。

因此，负载决定了电枢绕组中的电流及其旋转的角速度。

我们来考虑一下这个问题。

任务 1. 将电动鼓风机连接到恒压源。在 $n_1 = 1000$ rpm 的速度下，电枢电路中的电流等于 $I_1 = 10$ A，在 $n_2 = 900$ rpm 的速度下，它等于 $I_2 = 15$ A。 求发动机冷态（空载）转数。

由于$I = (U - k \omega) / R$和$\omega = 2\pi n$，那么

$$I_1 = \frac{U - 2\pi n_1}{R}$$

和

$$I_2 = \frac{U - 2\pi n_2}{R}.$$

在冷模式$I_3 = 0$，所以

$$U - 2\pi n_3 = 0.$$

一起求解这些方程，我们发现

$$n_3 = \frac{I_2 n_1 - I_1 n_2}{I_2 - I_1} = \frac{15 \cdot 1000 - 10 \cdot 900}{5} \frac{\text{об}}{(\text{мин})} = 1200 \text{ об/мин}.$$

电机的可逆性
所有直流电机都是可以想象的。如果将恒定电压施加到机器的端子上，电枢将旋转，执行机械功，即我们将得到电动机。另一方面，如果您在另一台机器的帮助下旋转电枢，则电机将作为产生电流的迪亚莫机器工作。

问题。假设同一台机器以相同的速度旋转，一次作为迪亚莫机器工作，另一次作为电机工作。对于这两种情况下电枢中产生的感应电动势可以说什么呢？

回答。由于感应电动势仅取决于电枢的设计和电枢的旋转角速度，因此两种情况下的感应电动势将相同。

问题。如果diamo机和电机的捕捉转速不同怎么办？

回答。在这种情况下，感应电动势的比率将等于电枢的旋转角速度的比率。

问题。我们已经讨论了欧姆定律和电机能量守恒定律，并写下了相应的等式（I）和（II）。对于 Diamo 机器来说，类似的等式会是什么样子？

回答。设diamo机电路的电阻等于R，则根据欧姆定律，

$$E_{\pi} = I_{\pi} R,$$

其中$E_{\pi}$是diamo机器的感应电动势，$I_{\pi}$是电流。此外，如果我们忽略能量损失（例如，在训练期间），那么我们可以将能量守恒定律写如下：

$$P_{\pi} = E_{\pi} I_{\pi}.$$

这里$P_{\pi}$是电枢旋转所消耗的机械功率，$E_{\pi} I_{\pi}$是由diamo机器产生的电力。

现在让我们解决几个问题。

问题 2. 具有独立励磁功能的直流电动机，连接到电压为 U = 24 V 的电池电路，总电路电阻为 R = 20 欧姆，在电路中的电流 I = 0.2 A 时产生 $n_1 = 600$ rpm。作为 diamo 机器运行时，同一电机在 $n_2 = 1400$ rpm 时会产生什么电动势？

diamo-machine 产生的电动势等于

$$E_{\pi} = \frac{n_2}{n_1} E_{\pi},$$

其中$E_{\pi}$是电机电枢绕组在转速为$n_1 \neq 600$rpm时产生的感应电动势。由欧姆定律可知：

$$E_{\pi} = U - IR.$$

因为

$$E_{\pi} = \frac{n_2}{n_1} (U - IR) = \frac{1400}{600} (24 - 0,2 \cdot 20) B \approx 46,7 B.$$

问题 3. 质量为 m 的负载悬挂在缠绕在独立励磁 diamo 电机电枢轴上的螺纹上。螺纹从轴上展开，使负载以恒定速度 $v_1$ 下降。迪亚莫机接近电阻R。如果迪亚莫机作为电动机连接在具有电压U和相同电路电阻R的直流电路中，相同的负载将以什么速度$v_2$向上上升？

以速度$v_2$提升质量为m的负载的电机的功率等于$mgv_2$。根据欧姆定律和能量守恒定律可以得出：

$$U - E_{\pi} = IR$$

和

$$UI = I^2 R + mgv_2,$$

其中 I 是电流，$E_{\pi}$ 是电枢绕组中的感应电动势。该电动势与钻石机的感应电动势有关，关系式如下：

$$\frac{E_{\pi}}{E_{\pi}} = \frac{v_2}{v_1}.$$

现在让我们写下欧姆定律和迪亚莫机器的能量守恒定律：

$$E_{\pi} = I_{\pi} R$$

问题 4. 具有独立励磁（带有永磁体）的直流电动机使用缠绕在电动机轴上的螺纹以速度 $v_1$ 提升负载。在没有负载的情况下，不一致的线程以速度$v_0$上升。如果电枢电路发生短路，导致电枢绕组短路，相同的负载以什么速度$v_2$下降？忽略轴承中的摩擦。

绕组短路后，电动机变成发电机，发电机电枢中的电流$I$将与机器作为电动机工作时相同。事实上，在这两种情况下，相同的负载均匀地移动（上升或下降）。因此，电感器磁场作用在电枢上且与电流大小成比例的力矩等于负载的重力力矩。当提升不兼容的螺纹时（在空闲模式下），负载扭矩为零，因此电流$I_0 = 0$。让我们为这三种情况写出欧姆定律：

使用电机提升负载时
$$U - E_{\pi} = IR,$$
其中$U$是电机端子上的电压；
当降低负载时，当电机像发电机一样工作时，
$$E_{\pi} = IR;$$

当电机空转时，
$$U - E_{\pi}' = 0.$$
对于三个 emf $E_{\pi}$、$E_{\pi}'$ 和 $E_{\pi}$，可以写出以下对应关系：
$$E_{\pi} = \frac{v_1}{v_2} E_{\pi}$$
和
$$E_{\pi}' = U = \frac{v_0}{v_2} E_{\pi}.$$
终于找到了
$$v_2 = v_0 - v_1.$$
