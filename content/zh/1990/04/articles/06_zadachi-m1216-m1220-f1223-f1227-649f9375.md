M1217。对于任意自然数n，证明相等
$$\frac{1}{n^2} + \left( \frac{1}{n} + \frac{1}{n-1} \right)^2 + \dots + \left( \frac{1}{n} + \frac{1}{n-1} + \dots + 1 \right)^2 = 2n - \left( 1 + \frac{1}{2} + \dots + \frac{1}{n} \right).$$

V·米哈伊洛夫（保加利亚）

M1219*。证明对于任意 n 个正数 $x_1, x_2, \dots, x_n$ ($n > 1$)，以下不等式成立：
$$(x_2 + \dots + x_n)^{x_1} + \dots + (x_1 + \dots + x_{i-1} + x_{i+1} + \dots + x_n)^{x_i} + \dots + (x_1 + x_2 + \dots + x_{n-1})^{x_n} > n - 1.$$
例如，对于任何正数 $x, y, z$ 不等式
$$(x + y)^2 + (y + z)^x + (z + x)^y > 2.$$
A·米哈伊洛夫

M1220*。让我们通过以下条件定义序列$b_n$：$b_1 = 0, b_2 = 2, b_3 = 3, b_{n+1} = b_{n-1} + b_{n-2}$ for $n \geqslant 3$。证明当 p 为素数时，数 $b_p$ 能被 p 整除。
