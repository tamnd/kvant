在我们对田野中绿化数量的观察中，我们注意到绿化数量定期发生变化（为简单起见，为空，这将是有一天）。
这段时间（任意一天）的绿化量变化$\Delta K_t$与当天可用绿化量$K_t$的比率将是一个常数值，等于感知绿化量变化的阈值：

$$\frac{\Delta K_t}{K_t} = \delta_\pi^K.$$

从这个关系我们可以得到绿化量变化率的方程

$$v_t = \frac{\Delta K_t}{\Delta t} = \frac{\delta_\pi^K K_t}{t_\pi} = CK,$$

(1)

其中$C = \delta_\pi^K / t_\pi$是一个常数值，等于给定田地中绿化量变化达到阈值的时间（对我们来说这是一天）对绿化量变化的感知阈值。

结果表达式表明，绿化数量的增长率与现有绿化的数量成正比。 （在描述原子核的放射性衰变时，可以得到类似的表达式。在这种情况下，衰变率，即每单位时间衰变的原子核数量，与剩余原子核的数量成正比。但是，与植物的生长不同，对于方程右侧的原子核衰变，类似于（1），有一个负号，因为第一个初始原子核的数量随着时间的推移而减少。）在所有情况下，当任何数量的变化率与就数量本身而言，所考虑的数量对时间的依赖性具有指数特征。在我们的例子中，这意味着到时间 $t$ 时，绿色植物的数量可以计算为

$$K_t = K_0 e^{Ct},$$

(2)

其中$K_0$是$t = 0$和$e = 2,718$处绿化量的初始值。

时间依赖性（2），可以进行以下推理调整。设在初始时刻$t_0 = 0$，绿化量的值等于$K_0$，我们感兴趣的是时间$t$之后的值$K_t$。将时间间隔$0 - t$分成$N$等长的$\tau (\tau = t/N)$时间段，我们将记录$t_0 + \tau$、$t_0 + 2\tau$等时间段的绿化量。

在初始时刻$t_0 = 0$之后的时间$t$之后，绿色植物的数量可以计算为

$$K_1 = K_0 + \Delta K_0 = K_0 + v_0 \tau = K_0 + K_0 C \tau = K_0 (1 + C \tau)$$

（在这个时间间隔内，我们假设增长率是恒定且相等的（参见（1））$v_0 = CK_0$）；同样，在时间$2\tau$之后

$$K_2 = K_1 + \Delta K_1 = K_1 + v_1 \tau = K_1 + CK_1 \tau = K_1 (1 + C \tau) = K_0 (1 + C \tau)^2$$

（增长率恒定且等于$v_1 = CK_1$）。在时间$t = N\tau$之后我们感兴趣的值$K_t$可以找到为

$$K_t = K_N = K_0 (1 + C \tau)^N = K_0 \left(1 + \frac{Ct}{N}\right)^N = K_0 \left(1 + \frac{1}{M}\right)^{M C t} = K_0 \left(1 + \frac{1}{M}\right)^{M C t},$$

其中我们引入了符号 $M = Ct/N$（M 是无量纲量）。

在某些情况下，极地气象站现在正在使用为工作人员输送绿色蔬菜的装置，其填充名称为“Nugget - Arctic”。这些设备的安装很简单。尺寸为 $0,5 \times 1,5$ 米的植物会自动保持植物生长所需物质的恒定水平。镜面反射器上方有一盏强力电灯。正在生长的植物在塑料盒中沿着浴缸移动，其根部轻轻接触营养物质。盒子“装载”有种子并安装在浴槽的一侧。随着植物的发育，它们被移至浴池的另一边，逐渐将它们分开，使植物的叶子始终形成连续的绿色覆盖物，但不要重叠太多（图7）。这种带有分离盒的输送机有两个优点。首先，光线不会被浪费，因为它只落在植物的叶子上。其次，进行蔬菜连续生产。

当然，使用大型传送带（实验室已经使用了10米、20米甚至更长的传送带）需要实现包埋盒移动的自动化。比如说在船上，小“金块”区域由厨师监控。他给磁带充电，根据需要移动它们并收割农作物。

有了一个能够很好地描述植物根据外部条件（以及植物本身的特征）生长的模型，您就可以获得盒子沿着传送带$l = l(t)$移动的规律，其中叶子之间没有间隙，并确定安装盒子之间的时间t。我们建议您自己解决这个农业物理问题。
