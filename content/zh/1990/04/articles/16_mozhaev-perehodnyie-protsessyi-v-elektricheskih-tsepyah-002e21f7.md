当电路闭合或断开或其参数发生变化时，系统从一种设定状态转变为另一种设定状态。我们将在此转换期间给定电路中发生的情况称为转换过程。

我们将考虑运行恒定电动势源的电路。

稳态可以是稳态或非稳态。在第一种情况下，电路所有元件中的电流、电荷和电压随着时间的推移保持恒定。在静态模式的情况下，电路中的电流或例如周期性电容器上的电荷随时间变化，即系统处于振荡模式。显然，这只有在系统中没有能量耗散（即部分能量以热的形式耗散）时才有可能。在存在损失的情况下，系统将始终进入固定已建立状态

现在让我们继续考虑具体的例子。

问题 1. 有一个最简单的电路：恒定 EMF $E_0$ 源和电阻为 $R$ (图 1) 的电阻器形式的电压。求闭合开关$K$后电路中的电流与时间的关系。

让我们在关闭钥匙后的任意时间点写出该电路的欧姆定律：

$$E_0 = I(t)R.$$

该方程的解具有以下形式

$$I(t) = E_0/R = \text{const.}$$

因此，在电路中，钥匙关闭后的任何时间它都保持恒定并等于$E_0/R$，即在瞬时系统中建立了稳态模式。事实上，即使在这样一个理想化的系统中（电路中完全没有电感和电阻），达到稳态模式所需的时间虽然很小，但不为零，这与电磁波的有限衰减速度有关。但闭路欧姆定律“不知道”这一点，也无法描述必须考虑这一点的速度范围。我们自然不会考虑它们。

问题 2. 电路包含一个电阻为 $R$ 的电阻器和一个电阻为 $C$ (图 2) 的电容器。电容器两端的电压如何随时间变化？

让我们对这种情况应用欧姆定律：

$$E_0 = U(t) + I(t)R,$$

其中$U(t)$是任意时刻电容器两端的电压（闭合开关$K$后），$I(t)$是电路中的电流。使用连接$I(t) = \Delta(CU)/\Delta t$，我们将欧姆定律写成以下形式

$$RC \frac{\Delta U(t)}{\Delta t} + U(t) = E_0.$$

该方程描述了开关$K$闭合后任意时刻电容器电压对时间的依赖性。我们引入一个新变量$U^*(t) = U(t) - E_0$，那么欧姆定律将如下所示：

$$\frac{\Delta U^*(t)}{\Delta t} = -\frac{1}{RC} U^*(t).$$

这类方程描述了许多众所周知的过程，例如，原子核的放射性衰变，当对物体施加阻力时，物体的速度对时间的依赖性，与物体的速度成正比，即某个值随时间的变化率与给定时刻的该值成正比的过程。在我们的例子中，变化率 $U^*(t)$ 与该值本身成正比，比例系数为 - $1/(RC)$。减号意味着$U^*(t)$会随着时间的推移而杀人。我们将在这里提出这样一个方程的解，但仅用于教育目的：

$$U^*(t) = Ae^{-t/(RC)},$$

其中 $A$ 是从初始条件中找到的某个常数。在关闭钥匙$K$的瞬间，电容器上的电压等于：

$$U(0) = 0, \text{ следовательно, } U^*(0) = U(0) - E_0 = -E_0 \text{ и } A = -E_0.$$

电容器电压对时间的最终依赖关系为：

$$U(t) = E_0(1 - e^{-t/(RC)}).$$

问题 3. 距离发生器包含一个电阻为 $R$ 的电阻器和一个电感器 $L$ (图 4)。求闭合开关$K$后电路中的电流与时间的关系。

给定电路的欧姆定律具有以下形式

$$E_0 - L \frac{\Delta I(t)}{\Delta t} = I(t)R.$$

我们引入一个新变量$I^*(t) = I(t) - E_0/R$并得到

$$\frac{\Delta I^*(t)}{\Delta t} = -\frac{R}{L} I^*(t).$$

这是我们已经熟悉的方程式；我们以这种形式寻找它的解决方案

$$I^*(t) = Ae^{-Rt/L},$$

其中 $A$ 是从初始条件中找到的某个常数。合上钥匙$K$瞬间，电路中的电流为零：$I(0) = 0$；因此$I^*(0) = I(0) - E_0/R = -E_0/R$和$A = -E_0/R$。然后

$$I(t) = \frac{E_0}{R}(1 - e^{-Rt/L}).$$

我们得到了依赖$I(t)$，它与上一个案例中的依赖$U(t)$完全相似。在这种情况下，达到稳态模式的恒定时间等于$\tau = L/R$ - $R$越小，系统越达到稳定状态，并且当$R$趋于零时，$\tau$趋于无穷大。在 $R = 0$ 欧姆定律的形式为

$$E_0 - L \frac{\Delta I(t)}{\Delta t} = 0,$$

这个方程的解是

$$I(t) = \frac{E_0}{L} t,$$

也就是说，电路中的电流将随时间线性增加，并且无法达到稳态模式。实际上，电流的增加将受到源的有限能量储备的限制。 图 5 显示了 $I(t)$ 对于某个最终值 $L/R$ 的图表。

$$\mathcal{E} = I_R(t)R + (I_R(t) + I_L(t))r. \tag{1}$$

对于包含线圈和电阻器的计数器，类似的方程将具有以下形式
$$L \frac{\Delta I_L(t)}{\Delta t} = I_R(t)R. \tag{2}$$

在初始时刻，关闭按键$K(t=0)$后，电流为$I_L(0)=0$。根据第一个方程（该方程对于 $t=0$ 也有效），可以得出闭合开关后立即通过电阻器的电流等于 $I_R(0) = \mathcal{E}/(R+r)$。知道了点本身，我们就可以找到它们在初始时刻的变化率
$$\frac{\Delta I_L}{\Delta t} \bigg|_{t=0} \neq \frac{\Delta I_R}{\Delta t} \bigg|_{t=0}.$$

由式(2)可知
$$L \frac{\Delta I_L}{\Delta t} \bigg|_{t=0} = I_R(0)R = \frac{\mathcal{E}}{R+r} > 0,$$
也就是说，通过线圈的电流随着时间的推移而增加。由于 $\mathcal{E}$ 不依赖于时间，因此从方程（1）可以得出：
$$\frac{\Delta I_R(t)}{\Delta t} (R+r) + \frac{\Delta I_L(t)}{\Delta t} r=0,$$
而此时$t=0$

$$\frac{\Delta I_R}{\Delta t} \bigg|_{t=0} = -\frac{\Delta I_L}{\Delta t} \frac{r}{R+r} = -\frac{\mathcal{E}R}{(R+r)^2L} < 0$$

- 通过电阻器的电流以一定的有限速率减小。

该系统失调，因此趋于某种静止状态。两个方程都满足稳态解
$$I_R=0, I_L=\mathcal{E}/r.$$

因此，通过电阻器的电流减小并渐近趋于零，而通过线圈的电流增加并趋于值$\mathcal{E}/r$。依赖关系$I_R(t)$和$I_L(t)$如图7所示。

为了找到流经电阻器的总电荷 $Q_R$，我们将方程 (2) 重写为以下形式
$$L \Delta I_L(t)=RI_R(t)\Delta t.$$

这里$I_R(t)\Delta t$是短时间内流过电阻的电荷$\Delta Q_R$$\Delta t$；因此，
$$L \Delta I_L(t)=R\Delta Q_R.$$

从该方程可以看出，流过线圈的电流变化与流过电阻器的电荷之间的关系不依赖于时间，即在任何时间间隔内都保持不变。在建立稳定状态的整个过程中
$$L(I_L(\infty)-I_L(0))=RQ_R.$$

考虑到$I_L(\infty)=\mathcal{E}/r$这一事实，流经电阻器的总电荷将等于
$$Q_R = \frac{\mathcal{E}L}{Rr}.$$
