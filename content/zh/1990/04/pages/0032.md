自杂志创刊以来，我们一直在逐期运行此版块。其中发布的问题是非标准的，但它们的解决方案不需要超出学校课程范围的知识。最困难的任务标有星号。创建任务后，我们承诺表明谁向我们提出了该任务。当然，并非所有这些问题都是第一次发表。

本期问题的解决方案应在 1990 年 6 月 15 日之前发送至以下地址：103006，Moscow K-6，st.高尔基，32/1，«Kvant»。使用不同的信封发送不同期刊或不同学科（数学和物理）问题的解决方案。在信封的“收件人”栏中写上：“习题书«Kvant»第4—90号”以及您要发送其答案的习题编号，例如“M1216”或“F1223”。在“...发件人地址”栏中，请分别填写您的名字和姓氏。附上一个写有您地址的信封（您将在这个信封中收到决定审核的结果）。

请将拟出版的每个原始问题的条件连同您对该问题的解决方案一式两份装在一个单独的信封中（在信封上注明：“问题书«Kvant»，物理新问题”或“......数学新问题”）。

请在每封信的开头注明学校编号和您就读的班级。

M1216—M1220, F1223—F1227

M1216。已知锐角三角形ABC的内角AD等于边AC并垂直于线段OH，求锐角三角形ABC的内角，其中O为外接圆圆心，H为三角形ABC高的交点。

K. Nistorecky（罗马尼亚）

M1217。对于任意自然数n，证明相等
$$\frac{1}{n^2} + \left( \frac{1}{n} + \frac{1}{n-1} \right)^2 + \dots + \left( \frac{1}{n} + \frac{1}{n-1} + \dots + 1 \right)^2 = 2n - \left( 1 + \frac{1}{2} + \dots + \frac{1}{n} \right).$$
于。缅族

M1218。在线段AC上取点B，作圆弧：$\overline{AC} = \alpha$和$\overline{BC} = \beta$，它们的度数之和等于$\alpha + \beta = 360^\circ$，与直线AC位于同一半平面内。任意圆弧 AB 与它们相交于点 K 和 L (图 1)。证明可以在同一点清洗空调。

V·米哈伊洛夫（保加利亚）

M1219*。证明对于任意 n 个正数 $x_1, x_2, \dots, x_n$ ($n > 1$)，以下不等式成立：
$$(x_2 + \dots + x_n)^{x_1} + \dots + (x_1 + \dots + x_{i-1} + x_{i+1} + \dots + x_n)^{x_i} + \dots + (x_1 + x_2 + \dots + x_{n-1})^{x_n} > n - 1.$$
例如，对于任何正数 $x, y, z$ 不等式
$$(x + y)^2 + (y + z)^x + (z + x)^y > 2.$$
A·米哈伊洛夫

M1220*。让我们通过以下条件定义序列$b_n$：$b_1 = 0, b_2 = 2, b_3 = 3, b_{n+1} = b_{n-1} + b_{n-2}$ for $n \geqslant 3$。证明当 p 为素数时，数 $b_p$ 能被 p 整除。
D·福明

F1223。排出输送机的水平面由偏心轮驱动，偏心轮绕固定水平轴O和O'（图2）同步旋转。位于表面上的零件将以多大的偏心轮旋转角速度学习移动？当偏心轮顺时针旋转时，它们会朝什么方向移动？零件表面摩擦系数k，偏心半径r。
