环面$\bar{u}_1$，对称$\bar{u}$，等于$(x_1; y_1; z_1) = \left( \frac{2(y+z)-x}{3}; \frac{2(z+x)-y}{3}; \frac{2(x+y)-z}{3} \right)$，相等条件可写为$x_1/a = y_1/b = z_1/c$。顺便说一句，这些消息提出了该问题的纯代数解决方案：要证明不等式，使用柯西不等式就足够了
$$\sqrt{(a^2+b^2+c^2)(x_1^2+y_1^2+z_1^2)} \geq ax_1 + by_1 + cz_1$$
替换上面的表达式$x_1, y_1, z_1$到$x, y, z$。

V.杜布罗夫斯基、V.Kyrtoazhe

M1194。 a) 从区域$S$的左直线ABCD内的点$M$，绘制三角形AMB、BMC、CMD、DMA的bic扇区ME、MF、MG、MH。证明四边形 EFGH 的面积$S_0$满足不等式
$$\frac{3}{8} S < S_0 \leq \frac{1}{2} S$$

b) 对于哪些点$M$，等式$S_0 = S/2$成立？

如果点 $M$ 位于左边的中线之一，那么显然，$S_0 = S/2$ (图 1)。让我们证明对于所有其他点 $M$
$$\frac{3}{8} S < S_0 < \frac{1}{2} S$$

令$A$为最靠近点$M$的直左顶点（唯一确定；图2）。让我们证明$AE < BG < BC/2$。显然，这些不等式等价于：$AE^2/ED^2 < BG^2/GC^2 < 1$。将 bic 扇区划分线段 $AD$ 和 $BC$ 的关系替换为三角形 $AMD$ 和 $BMC$ 对应边的关系，我们得到不等式
$$\frac{AM^2}{MD^2} < \frac{BM^2}{MC^2} < 1.$$ (1)

令 $x, x_1, y$ 和 $y_1$ 为从点 $M$ 到边 $AD, BC, AB$ 和 $CD$ 的距离 (图 3)，则
$$\frac{AM^2}{MD^2} = \frac{x^2+y^2}{x^2+y_1^2} = 1 - \frac{y_1^2-y^2}{x^2+y_1^2}, \frac{BM^2}{MC^2} = 1 - \frac{y_1^2-y^2}{x^2+y_1^2}.$$
因此，由于 $x_1 < x_1$，$y < y_1$，不等式 (1) 随之而来。同理，证明$AF < DH < DC/2$。让我们通过点 $E$ 和 $G$ 画出与 $AB$ 平行的线，并通过点 $F$ 和 $H$ 画出与 $AD$ 平行的线。这些线限制了直线$A_1B_1C_1D_1$区域$s$（参见图2）。根据已证明的不等式，三角形 $EFA_1, FGD_1, GHC_1$ 和 $HEB_1$ 在一层中覆盖了四边形 EFGH，但直线 $A_1B_1C_1D_1$ 除外，它被覆盖了两次。因此，这些三角形的面积之和为$S_0 + s$。将面积$S_0$与三角形$AEF, BFG, CGH$和$DHE$的面积之和相加，我们就得到了整条给定直线的面积$S$。因此，$2S_0 + s = S$，即$S_0 = (S - s)/2$。仍然需要注意的是$0 < s < S/4$（正确的不等式源自$FD_1 = BG < BC/2, EA_1 = DH < DC/2)$。
