来自编辑。我们的读者E. Golberg（列宁格勒）提出了一个建议，即可以将$S_0$面积的较低估计中的数字3/8替换为$\sqrt{2} - 1 = 0,414...$，并且该估计已经是精确的（当$ABCD$是正方形并且$M$是其顶点之一时，就实现了相等）。确实，他只证明了不等式$S_0 > 0,4S$（$3/8 < 0,4 < \sqrt{2} - 1$）。我们概述了它的证明，让读者有机会重建中间计算，以及证实或反驳所陈述的假设。令$M$到$A, B, C, D$的距离等于$a, b, c, d$，则不等式$S_0 > 0,4S$可表示为

$$1 - \frac{1}{2} \left( \frac{a^2}{(a + b)(d + a)} + \frac{b^2}{(b + c)(a + b)} + \frac{c^2}{(c + d)(b + c)} + \frac{d^2}{(d + a)(c + d)} \right) > 0,4,$$

或者

$$5(bd - ac)^2 < (a + b)(b + c)(c + d)(d + a).$$

如果$a$是四个距离中最小的（图2），则$a \leq b \leq d \leq c$和$ac \leq bd$（见（1））；另外，$a^2 + c^2 = b^2 + d^2$。不等式（2）源自这些纯代数关系。

M1195。序列 $x_1, x_2, \dots$ 使得对于任何自然数 $m$ 和 $n$

$$|x_{m+n} - x_m - x_n| < \frac{1}{(m+n)}.$$

证明这个数列是等差数列。

根据条件，对于任何自然$n$和$k$

$$|(x_{n+1} - x_n) - (x_{k+1} - x_k)| = |(x_{n+k+1} - x_n - x_{k+1}) - (x_{n+k+1} - x_{n+1} - x_k)| \leq |x_{n+k+1} - x_n - x_{k+1}| + |x_{n+k+1} - x_{n+1} - x_k| < \frac{2}{n+k+1} < \frac{2}{n}.$$

固定$k$和$n$趋于无穷大，我们得到序列$x_{n+1} - x_n$有等于$x_{k+1} - x_k$的极限。

这里任何人都不能选择$k$，因此$x_{k+1} - x_k$之差不依赖于$k$，即$x_k$是一个算术级数。
