4. $\frac{b + \sqrt{b^2 + 8a^2}}{2b}$ 解决方案。令 $\angle EAB = \angle DAE = \alpha$ (图 3)。然后由$AB = a \cos 2\alpha = b \cos \alpha$我们得到方程$a(2\cos^2\alpha - 1) = b \cos \alpha$来确定$\cos \alpha$。考虑到$\alpha$是锐角，我们写
$$\cos \alpha = \frac{b + \sqrt{b^2 + 8a^2}}{4a}.$$
三角形$ADB$的面积$S_1$与三角形$AEB$的面积$S_2$之比为
$$\frac{S_1}{S_2} = \frac{2a}{b} \cos \alpha = \frac{b + \sqrt{b^2 + 8a^2}}{2b}.$$
5. $\frac{4\sqrt{3}}{9} H^3 \text{ ctg}^2\alpha$。解决方案。令 $ASC$ 为垂直于底面 (图 4) 的侧面，$SD$ 为直线的高度。由于底边$ABC$与边$SAB$和$SBC$之间的角度等于$\alpha$，因此点$D$到$AB$和$BC$的距离相等，即$D$是$AC$的中点。

4. $\left[\frac{1}{4}; \frac{1}{2}\right]$。笔记。对于$a = 0$和$a < 0$，第一个不等式的可能解是无限的，因此不能包含在区间$(-2; 0)$中。对于$a > 0$，第一个不等式等价于以下不等式
$$(x + 2)\left(x - \frac{2a - 1}{a}\right) < 0.$$
为了使这个不等式的解满足条件，有$-2 \leq \frac{2a - 1}{a} \leq 0$是充分必要的。
5. $\frac{3\pi}{32}$。笔记。让我们通过球的中心和基台底座侧面的中间绘制基台的截面 (图 5)。在点$F$和$G$，球分别接触底面和侧面。根据三角形$SFE$和$SOG$的相似度，我们有$EF/8R = R/SG$。从$SG = \sqrt{49R^2 - R^2}$开始，然后$EF = 2\sqrt{3R}/3$。因此，基台的体积为$V = 128R^3/9$。
