在此过程中关闭钥匙$K$后，根据欧姆定律，包含源和线圈的电路的时刻$t$可以写成

$$E - L \frac{\Delta I_L(t)}{\Delta t} = 0.$$

由于初始电流为 $I_L(0) = 0$，因此通过电感器的电流 $I_L(t)$ 的依赖性将具有以下形式

$$I_L(t) = \frac{E}{L} t,$$

即电流与时间呈线性关系，并且在时间 $\tau$ 之后将相等

$$I_L(\tau) = \frac{E}{L} \tau.$$

因此，通过二极管，显然，这段时间它将等于零。

考虑开关 $K$ 闭合后（经过时间 $\tau$）后包含线圈、二极管和电容器的电路。该计数器的欧姆定律如下所示：

$$-L \frac{\Delta I_K}{\Delta t} = U(t),$$

其中 $I_K$ 是电路中的电流（参见 图 8），$U(t)$ 是电容器两端的电压。考虑到连接$I_K = \Delta(CU)/\Delta t = CU'$，该对立方程可简化为以下形式

$$U'' + \frac{1}{LC} U = 0.$$

该方程描述了电路中的谐波振荡，因此我们以以下形式寻找该方程的解

$$U(t) = A \cos \omega_0 t + B \sin \omega_0 t,$$

其中$A$和$B$是常数，$\omega_0 = 1/\sqrt{LC}$。我们将从钥匙$K$关闭的那一刻开始计算时间。 $t = 0$ 电容器两端电压$U(0) = 0,$

由此可见$A = 0$。另一方面，从初始条件$I_K(0) = I_L(\tau) = \mathcal{E} \tau/L$，$I_K(0) = C \frac{\Delta U}{\Delta t} \bigg|_{t=0} = B \omega_0 C$；因此$B = \mathcal{E} \tau/(\mathcal{LC} \omega_0) = \mathcal{E} \tau \omega_0$。我们得到最终结果

$$U(t) = \mathcal{E} \tau \omega_0 \sin \left( \frac{1}{\sqrt{LC}} t \right).$$

但这并不适用于任何时刻，而仅适用于区间 $0 \leq t \leq T/4$，其中 $T = 2\pi \sqrt{LC}$。在 $t > T/4$ 时，电容器两端的电压将保持恒定并等于 $\mathcal{E} \tau \omega_0$。 $U(t)$的图形如图9所示。
