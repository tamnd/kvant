反思
关于弥撒

物理和数学科学博士
Y·斯莫罗丁斯基

您读过一本物理教科书，当然知道如何比较两个物体的质量。让您继续您的研究操作并确保两个物体 A 和 B 具有相同的质量。用$m(A)$和$m(B)$表示物体的质量，我们可以将这个结果写成等式的形式

$$m(A) = m(B).$$

现在想象一下，我们将其中一个物体（例如物体 B）的质量与第三个物体（物体 C）的质量进行比较，发现物体 C 的质量与物体 B 的质量相同。换句话说，我们从经验中确信：

$$m(B) = m(C).$$

现在让我们问：是否可以从等式 (*) 和 (**) 得出物体 C 与物体 A 具有相同质量的结论，即

$$m(C) = m(A)?$$

这似乎是显而易见的。参考基本逻辑定律甚至算术定律就足够了，根据该定律，语句 (?) 由语句 (*) 和 (**) 得出。但让我们尝试证明，如果$m(A) = m(B)$和$m(B) = m(C)$，则$m(C) = m(A)$。

物理学中的“证明”是什么意思？这是为了通过经验验证这个说法（假设）

不违背任何已知的（经过经验证明、检验的）法律。在这种情况下，必须遵守某些“游戏规则”。第一条规则是你不能使用“显然”这个词。

那么，让我们来证明一下。让我们在心里进行这样一个实验（E. Mach* 讨论过））。让我们弯曲一圈金属丝，并在其上放置三个球 A、B 和 C。这些球的质量满足等式 (*) 和 (**)。现在让我们推球 A，给它速度 $\vec{u}$。如果没有摩擦，则球将沿着环移动，而不改变速度（模数），直到与球 B 碰撞。碰撞后，球 A 将停止，B 开始以与碰撞前球 A 移动的速度 $u$（再次模数）相同的速度移动。 （如果我们事先不知道 A 和 B 的质量相同，那么我们可以通过比较碰撞前后 A 和 B 的速度来找出这一点 - 这是很好的方法，或者通过检查球 A 是否停止了。**））

在移动过程中，经过一段时间后，B 球会与 C 球发生碰撞。我们也可以想象碰撞的结果：B会停下来，而C开始以$u$的速度移动（毕竟是$m(B) = m(C)$）。

下一个事件将是球 C 与球 A 的碰撞。我们还没有通过实验验证$m(C) = m(A)$，因此我们无法提前声明 A 开始以与它最初移动相同的速度$u$ 移动。为了得出这个结论，我们必须借助能量守恒定律。*）

*) 恩斯特·马克斯 (Ernst Max) (1838-1916) - 一位重要的奥地利物理学家和物理科学家。他研究了力学、声学和光学。

**) 这些陈述并不明显。他们可以通过球 A 和 B 是相同的事实来证明其合理性。但我们不要屈服！

***）必须承认，当我们争论球A和B在碰撞后滚动时，我们可以平等地使用能量（或动量）守恒定律：A停止，B“接管”A的速度。虽然这是“显而易见的”，但没有守恒定律就无法证明。 （小心“显然”这个词！）

如果碰撞后 A 球的速度大于 $u$，那么 A 会将这个更大的速度传给 B 球，这样就可以无中生有地获得能量：每次与 C 球碰撞后，A 球都会移动得越来越快！

如果速度 A 小于$u$，那么球最终会停止，它们的动能会消失得无影无踪（回想一下，球的移动没有​​摩擦）。这两个结论都是错误的，因此球 A 与 C 碰撞后将以速度$u$ 的速度移动的说法是正确的。

现在一切都已就绪。满足能量守恒定律，碰撞后的球A的速度$A \rightarrow B$、$B \rightarrow C$、$C \rightarrow A$恢复到原来的值。

我们看到，对于严格的证明来说，仅仅有逻辑是不够的；还需要有足够的证据。有必要借助物理定律——能量守恒定律。没有这个就不可能说$m(C) = m(A)$！

但出于实际目的，并非所有地方都需要严格的定义。在被冒犯的生活中，我们有足够多的不那么严格但更容易理解的定义。

牛顿在他的伟大著作《自然物理学的数学原理》的第一页中解释了质量的含义：“材料的数量是与其密度和体积成正比的量度”*。如果我们毫不犹豫地假设材料的数量表示牛顿质量，那么这样的定义仅代表内容：为了找出密度$\varrho$，需要将质量$m$除以体积$V$，因此公式$m = \varrho V$是公式$\varrho = m/V$的推论。我必须说，很多人都是这样认为的。
*）由于这个定义几乎总是有错误，我们用牛顿写的语言来呈现它 - 用良好的拉丁语（毕竟，他们现在在文法学校教授拉丁语）：“Definitio I. Quantitas materiae est mensura ejusdem orta ex illius densitate et magnitudine conjunctim。”

他们不明白牛顿说的话。那是一个错误。我们必须理解牛顿所写的意义，而不是在琐碎的不合逻辑中发现它。在引入动量概念之前定义了质量，却不知道能量守恒定律的存在（“能量”的概念是在一百多年后出现的），牛顿发现自己陷入了困境。他找到了唯一的出路，提出了他的 Definitio。

牛顿本人没有使用质量这个词，并且在他的定义中包含了不同的含义。在 17 世纪和 18 世纪，人们相信所有物体都由相同的非常小的粒子组成 - 它们被称为单子。单子都是一样的，不同的物体之间的区别仅在于其中单子的密度不同。单子是什么样子，有什么性质，无法从实验中得知；但当时的科学家对实验并不十分担心；他们相信，仅通过推理就可以发现自然法则。莱布尼茨、欧拉等科学家研究了单子理论。

德国哲学家克里斯坦·沃尔夫（Christan Wolf）是莱布尼茨思想的普及者，被认为是单子方面的主要专家。几乎整个欧洲都在学习沃尔夫的教科书。 《罗蒙诺索夫山口》是沃尔夫的教科书之一，也是俄罗斯第一本物理教科书。然后每个人都知道单子，他们说，甚至普鲁士宫廷的宫女也喜欢谈论它们。因此，对于18世纪的读者来说，使用牛顿的定义是有意义的。

当然，单子理论很久以前就来自科学。在 19 世纪，他们已经讨论了具有不同化学和物理性质的原子，但令人惊讶的是，在我们的 20 世纪，回到牛顿的想法是有用的，并说物体的质量与核子（它包含的中子和质子）的数量成正比，甚至与物体的体积和“核子密度”（1 cm3 中核子的平均数量）成正比。

造成这样的决定的可能性有哪些？中子的质量比质子的质量大约0.2%。当然，我们可以通过分别计算中子和质子来考虑这一差异。但是，另一方面，在许多情况下，十分之一的误差并不会困扰我们（至少在解决学校问题时）。

一个更根本的错误是由于原子核中的核子比自由状态下的核子“更轻”。事实是，粒子（原子核）的束缚系统的能量小于这些粒子在自由状态下的总能量。为了将原子核分裂成其组成核子，需要消耗等于这些能量之差的能量（称为结合能）。而且由于能量和质量之间存在联系，用爱因斯坦的公式 - $E = mc^2$ 来表达， - 能量的差异代表了质量的差异。这意味着原子核的质量小于其组成核子的质量之和。质量的减少相当大，几乎达到 1%（更准确地说，0.6-0.8%）。

我们知道氢*)的原子质量等于1.0078原子质量单位，而主要铀同位素的原子质量等于238 amu，即小于构成该同位素核的92个质子和146个中子的质量之和。您可以对“结合能”进行调整，但不应使任务复杂化。

所以，牛顿的定义就是区分什么不是“空”。这个概念是正确的，它确定的质量误差小于百分之一。

事实证明，语标并不那么容易，当然，这部分问题没有根本性的困难。测量的想法是最简单的——你需要将元素样本的质量（以千克为单位）除以该样本中的原子数量。困难在于必须“一块一块”地数原子。今天的物理学家和化学家都需要这种精度。

我们不会详细谈论进行任意计算的巧妙实验。让我们补充一下，为此他们制造了一个非常好的晶体，非常精确地测量了它的尺寸，然后，使用 RENT 的分析，确定了原子之间的距离......每个操作都需要极大的独创性 - 毕竟，我们谈论的是非常高的精度。

在质量问题中，这是最困难的部分。

最后还有一点要注意。
在流行书籍中，甚至在教科书中，有一个早就应该被抛弃的概念。从中没有任何好处，只是按照旧习惯生活。这个概念是运动物体的质量，随着速度的增加而增加。事实上，运动物体的质量永远不会改变，改变的是它的能量（例如，加速器中质子的能量）。使用公式 $m = E/c^2$ 计算质量。物理学家已经很长时间没有使用这样的质量了，并且仅用能量来进行所有计算。质量现在仅称为“静止质量”——静止粒子的质量。在元素粒子表中收集了静止质量的值（尽管省略了“静止”一词）。

试着记住“质量随着速度的增长而增长”——这句话现在已经没有什么意义了。能量随速度增加。
