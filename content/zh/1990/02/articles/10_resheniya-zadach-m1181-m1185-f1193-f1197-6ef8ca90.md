M1182。在一些玫瑰中，有n≥3只椋鸟，并且椋鸟之间的距离各不相同。每只都包含一只黄色椋鸟。每时每刻，都有一些椋鸟离开自己的椋鸟，飞向其他椋鸟，这样，每只椋鸟中又含有一只椋鸟。此外，如果每对八哥之间的距离小于另一对之间的距离（一只八哥可以算在不同的对中），那么在飞行后，第一对八哥之间的距离会大于第二对八哥之间的距离。在什么条件下这可能？

答案：n=3。
让我们证明任何八哥要么留在原地，要么与其他八哥交换位置。

让八哥从$A_1$飞到$A_2$，从$A_2$飞到$A_3$，等等。八哥的数量是有限的，因此在序列$A_1, A_2, A_3$，...重复开始，$A_1$将首先重复（如果，比如说，$A_3$再次出现，那么在它之前应该有$A_2$，并且在$A_2$—$A_1$之前，即$A_1$再次出现得更早）。让我们假设$A_i \neq A_1$位于$1 < i \leq k$、$A_{k+1} = A_1$，并且最小的距离$A_1A_2, A_2A_3, ..., A_kA_1$例如为$A_1A_2$。根据$A_1A_2$小于所有其他距离$A_iA_{i+1}$的事实，根据条件$A_2A_3$大于所有其他距离$A_iA_{i+1}$，因此$A_3A_4$小于所有其他距离$A_iA_{i+1}$，即$A_3A_4 = A_1A_2$。但所有距离 $A_iA_j$ 都不同，因此 $A_3 = A_1$。换句话说，如果八哥已经离开$A_1$，那么它会与$A_2$的八哥交换位置。

$$2x_1^2 = 1, x_1 = x_2 = \sqrt{2}/2.$$

对于几何鉴赏家来说，这些数字会让人产生这样的想法：随机数$n = 2$、$n = 3$和$n = 4$在某种程度上与相应的角度$45^\circ$、$36^\circ$和$30^\circ$相关。事实上，我们将看到（参见图 2），对于任何$n$，都存在与角度$\alpha = 180^\circ/(n + 2)$相关的系统的解。从第一句话就可以看出这个解决方案是独一无二的。

让我们构造一个等边三角形$A_0OA_n$，边为$A_0O = OA_n = 1$，底角为$\alpha = 180^\circ/(n + 2)$；基于$A_0A_n$，我们标记点$A_1, A_2, ..., A_{n-1}$，以便从顶点$O$以相等的角度$\alpha$可以看到线段$A_0A_1, A_1A_2, ..., A_{n-1}A_n$。让我们证明这些线段$x_1, x_2, ..., x_n$的长度满足我们的系统。方便地通过点$O$绘制另一条射线OP，平行于$A_0A_n$（$\angle POA_0 = \alpha$）。三角形$A_0OA_k$和$A_nA_{k-1}O$相似（$\angle A_0 = \angle A_n = \alpha$、$\angle A_0OA_k = k\alpha = \angle POA_{k-1} = \angle OA_{k-1}A_n$），第一个三角形的边$A_0O = 1$和$A_0A_k = x_1 + ... + x_k$对应于第二个三角形的边$A_{k-1}A_n = x_k + ... + x_n$和$OA_n = 1$，从中我们得到方程

F1193。太空中有一个立方体。此时面ABCD为水平面（图1），A点和B点的速度垂直向下且模v相等。已知此时C点的速度模2v。此时其他立方体的最大速度是多少？

考虑点 C。很容易报告，在给定时刻，该点的速度矢量是垂直的（这是因为点 C 的速度的平移分量和垂直分量都是垂直的）。在这种情况下，C点的速度矢量可以向上（情况a）和向下（情况6）。

让我们从情况a)开始。显然，BC 线上有一点，其给定时刻的速度为零。事实上，如果立方体所有点的速度的平移分量等于 v 且指向下方，则点 C 的垂直分量等于 3v 且指向垂直向上。然后，在距离 B 点 $a/3$ 处（其中 $a$ 是立方体边长），将有一个点 O，其速度的垂直分量等于 v 且方向向上。因此，给定时刻 O 点的总速度为零。该点称为交换旋转中心。但如果 O 点在给定时刻不移动，那么距 O 点最大距离的点将具有最大速度。显然E点满足这个条件。自从
$$\frac{v_E}{v_C} = \frac{OE}{OC} \quad \text{и} \quad OE = \sqrt{a^2 + \left(\frac{2}{3} a\right)^2} = \frac{\sqrt{13}}{3} a,$$
我们得到
$$v_E = v_C \frac{OE}{OC} = v \sqrt{13} \approx 3,6v.$$

F1194。毛细管由两根内径为$d_1$和$d_2$（参见图）的细玻璃管组成。里面有大量质量为 M 的水。如果液体“渗入”薄部分，则小枝毛细管水平放置；如果垂直安装，如果水从其中流出，则小枝毛细管水平放置。什么情况下毛细管轴线与立管之间会出现一部分在粗管，一部分在细管？水的表面张力系数 σ，水的密度 Q。润湿被认为是完全的。

A·齐伯曼

F1195。一根高度为$H=1$米、横截面积为$S=50$厘米$^2$的垂直管道，两端开口。管道底部安装功率$N=100$W的加热器。管道中向上流动的速度是多少？假设加热器没有点燃管道的横截面。大气压$p_0=1$ atm，外界温度为室温。定体积空气的摩尔热为 $C_V=2,5$ R，其中 $R$ 是通用气体常数。

显然，加热导致空气密度下降，作用在热空气上的阿基米德力将其向上提升，即管道中出现空气向上流动。

让我们把问题分成两部分。

1) 设管道内空气密度$\rho$，周围空气密度$p_0$（$\rho < p_0$）。空气在管道中均匀运动的速度是多少？

让我们表示管道上端的压力（参见图）$p_0$。然后，在下端附近，管道内的压力将为$p_0 + \rho gH$，管道外的压力为$p_0 + \rho gH > p_0 + \rho gH$。事实证明，在管道底部孔附近，速度为零的压力被吸入管道中，压力下降，速度增加到某个值$v$。让我们使用伯努利方程来找到它：

$$\rho \frac{v^2}{2} + p = \text{const},$$ 或 $$\frac{\rho v^2}{2} + p_0 + \rho gH = p_0 + \rho gH,$$

我们从哪里得到它

$$v = \sqrt{2 \frac{\rho_0 - \rho}{\rho}} gH.$$

2) 知道加热器的功率$N$，我们就可以找到比率$(\rho_0 - \rho)/\rho$。

气流$\rho vS$（每单位时间的质量）或$\frac{\rho}{M} vS$（每单位时间的物质量）通过加热器。加热是在恒定压力下进行的，因此

$$N = \frac{\rho}{M} vSC_p \Delta T,$$

其中 $C_p = C_V + R = 7/2$ R 和 $\Delta T$ 等于管道内部（加热器之后）与外部的温差。在恒定压力和 $\Delta T/T \ll 1$ 下

$$\frac{\rho_0 - \rho}{\rho} = - \frac{\Delta \rho}{\rho} \approx \frac{\Delta T}{T}.$$

因此，

$$v^2 = 2 \frac{\rho_0 - \rho}{\rho} gH = 2 \frac{\Delta T}{T} gH = \frac{2NMgH}{T\rho vSC_p},$$

或者

$$v^3 = \frac{2NMgH}{T\rho SC_p} = \frac{2NgHR}{pSC_p} = \frac{4}{7} \frac{NgH}{pS} \approx \frac{4}{7} \frac{NgH}{p_0S}.$$
