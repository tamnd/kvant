力学问题的参考系

物理和数学科学候选人 A. CHERNOUTSAN

一名男子在A点下方的船上发生溢漏事故，心不在焉地将帽子掉进河里，但他没有注意到这一点，继续逆水划行。 15分钟后，他发现丢失后，调转船头，在同样的黑暗中划船，在距离A地1公里的B地下面找到了帽子。河水的流速是多少？

我们从这个非常古老且已经很经典的问题开始讨论参考系并非偶然。它清楚地说明了这样一个事实：参考系统（R.O.）的成功选择可以显着简化，有时甚至使许多物理问题的解决变得简单。

事实上，为了在我们的示例中找到水流的速度，我们需要找出帽子在不同位置之间移动需要多长时间（因为帽子的速度等于水的速度）。让我们继续讨论 S.O.与帽子相关。里面的水是静止的，两个方向的船的速度是相同的。这意味着船回到帽子处所需的时间等于离开帽子处所需的时间，即 15 分钟。那么从丢帽子到抓帽子的总时间为30分钟，水流的速度为1公里/0.5小时=2公里/小时。

当从一个系统移动到另一个系统时，描述物体机械运动的许多物理量（例如速度 v、加速度 a 等）会发生变化。在这种情况下，满足相应量的已知加法定律：

$$\vec{v}_1 = \vec{v}_{12} + \vec{v}_2, \quad \vec{a}_1 = \vec{a}_{12} + \vec{a}_2.$$

现在我们来看几个具体问题。首先 - 从运动学角度。让我们立即注意到，在运动学框架内，所有 SO（静止、匀速运动或加速、旋转等）都是相等的； S.O.的选择仅由便利性和常识决定。

问题1.河流的速度为$\vec{u}$，船在静水中的速度为$\vec{v}_{ОТH}$。船上的人应该保持怎样的航向，才能尽可能少地被水流冲走？

显然，这里讨论两个 S.O. 是合理的。提供最小方法的要求与 S.O.与地面相关 - 船速 $\vec{v}$ 与垂直于海岸线之间的角度应最小。在 S.O.与水相关，给定船的速度$\vec{v}_{ОТH}$，需要找到该速度的方向，例如速度$\vec{v}_{ОТH}$与垂直于海岸线的角度$\alpha$。毕竟，“保持航向”意味着设定船体的方向，并且它与该 S.O. 中船速的方向一致。那里的水是静止的。

*) 所有这些问题都在注释“相对运动”（«Kvant»，1989，第 9 期）中进行了更详细的讨论。

问题的条件没有说明值$u$和$v_{ОТH}$之间的对应关系。让我们考虑两种选择。

1) $v_{ОТH} > u$。在这种情况下，可以确保船垂直于海岸移动（同样，完全不能）。让我们写下速度加法

$$\vec{v} = \vec{v}_{ОТH} + \vec{u}$$

并将其画在 图 1 上。从直角三角形我们得到

$$\sin \alpha = u/v_{ОТH}.$$

2) $v_{ОТH} < u$。在这种情况下，表达速度加法的等式如图2所示。当航向改变时，矢量$\vec{v}_{ОТH}$的末端由半圆描述。矢量 $\vec{v}$ 与垂直于海岸线之间的最小角度对应于该矢量接触半圆的条件。从这里我们得到

$$\sin \alpha = v_{ОТH}/u.$$

所以，对于 $v_{ОТH} > u$ sin $\alpha = u/v_{ОТH}$；对于$v_{ОТH} < u$罪$\alpha = v_{ОТH}/u$（自己检查一下$v_{ОТH} = u$情况）。

当考虑多个物体的自由落体时，使用与这些物体之一相关的 SO 会很方便。在其中，所有其他物体将直线且均匀地移动（我们不考虑空气阻力）。这个例子通常被称为“Baron Monchhausen 方法”（你明白为什么吗？）。我们将在下一个问题中使用它。

问题 4. 两个小物体沿着主水平面移动，由一根长度为 l 的失重且不可分割的线连接起来。在某个时刻，质量体 $m_1$ 处于静止状态，而质量体 $m_2$ 的速度 v 垂直于螺纹 (图 4, a)。此时，拧紧螺纹。

该物体系统的质心位于距第一个物体 $R_1 = m_2 l / (m_1 + m_2)$ 距离的螺纹上，并以速度 $v_\pi = m_2 v / (m_1 + m_2)$ 相对于平面移动。让我们选择质心静止的 SO。其中，物体 $m_1$ 和 $m_2$ 绕固定质心 (图 4, b) 做匀速圆周运动，而第一个物体相对于该 S.O. 的速度为大小等于 $v_\pi$。

根据牛顿第二定律，作用在第一物体上的线的张力等于

$$F = m_1 v_\pi^2 / R_1.$$

从哪里，代入$R_1$和$v_\pi$的表达式，我们最终发现

$$F = \frac{m_1 m_2 v^2}{(m_1 + m_2) l}.$$

在许多情况下，当搬到 S.O.与质心相关，当前问题的解决方案被简化，这使得首先将所有给定问题转移到这个 S.O. 中是有意义的。并得到结果，然后将其返回给原来的S.O.例如，考虑两个关于球的绝对弹性冲击的问题。

问题 5. 两个质量分别为 $m_1$ 和 $m_2$ 的球，分别以 $v_1$ 和 $v_2$ 的速度运动，经历绝对弹性 LOB 冲击。撞击后小球的速度是多少？

在与质心相关的 SO 中，球在撞击之前和之后的总冲击力均为零。如果您只需将球的速度方向更改为相反的方向，就很容易证明动量和能量这两个守恒定律都是正确的。我们写出相应的公式：

球在质心处的初始速度等于

$$u_1 = v_1 - v_\pi = v_1 - \frac{m_1 v_1 + m_2 v_2}{m_1 + m_2} = \frac{m_2 (v_1 - v_\pi)}{m_1 + m_2}, u_2 = \frac{m_1 (v_2 - v_\pi)}{m_1 + m_2};$$

S.O. 处球的最终速度质心 -

$$u'_1 = -u_1, u'_2 = -u_2;$$

球相对于地面的最终速度为

$$v'_1 = u'_1 + v_\pi = -\frac{m_2 (v_1 - v_\pi)}{m_1 + m_2} + \frac{m_1 v_1 + m_2 v_2}{m_1 + m_2} = \frac{(m_1 - m_2) v_1 + 2 m_2 v_2}{m_1 + m_2}, v'_2 = u'_2 + v_\pi = \frac{(m_2 - m_1) v_2 + 2 m_1 v_1}{m_1 + m_2}.$$
