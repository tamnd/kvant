在本笔记中，我们将讨论以下形式的代数方程
$a_nx^n + a_{n-1}x^{n-1} + \dots + a_1x + a_0 = 0$. (1)

在学校，方程也只能求解值$n \leqslant 2$。然而，在某些情况下，使用特殊技术可以获得二次以上的方程。我们将在这里展示其中的一些。

一、定理。设方程(1)中的所有系数$a_n, \dots, a_0$均为整数，并令不可约分数$p/q$为该方程的根。那么它的分子$p$是自由项$a_0$的约数，它的分母$q$是首项系数$a_n$的约数。

证明。让我们将$x = p/q$代入方程（1）。我们会得到
$a_np^n + a_{n-1}p^{n-1}q + \dots + a_1pq^{n-1} + a_0q^n = 0$.

除最后一项外，所有项均包含因子 $p$。但最后一项也可以被 $p$ 整除，因为它等于其余项的总和（带有负号）。由于分数$p/q$不能被$p$整除，这意味着最后一项$a_0q^n$要能被$p$整除，自由项$a_0$必须能被$p$整除。定理的第一个陈述得到证明。第二个可以用类似的方法证明。

使用这个定理，我们可以找到任何具有整数系数（如果有）的方程的所有有理根。为此，只需列出所有除数即可

二.现在假设我们已经知道方程的一个根。 （现在我们如何识别它并不重要。）我们如何使用它来找到其余的根？多项式除法的过程将通过在过程中添加多位数来帮助我们。让我们用一个例子来展示这是如何完成的。让我们给出方程

$$x^3 - 2x + 1 = 0.$$

根据前面的定理，如果这个方程有有理根，那么只有1或-1。通过检查，我们确保数字 1 确实是根。

现在我们需要对方程左侧的多项式进行因式分解。这可以通过巧妙地对项进行分组来完成，但还有一种不需要契约的可靠方法：将我们的多项式除以一个角除以 $x - 1$。 图 1 显示了这是如何完成的。

$$\begin{array}{c}
x^3 - 2x + 1 \\
x^3 - x^2 \\
x^2 - 2x + 1 \\
x^2 - x \\
- x + 1 \\
- x + 1 \\
0
\end{array}$$

Puc. 1.

在这种情况下，余数为零，所以我们敢于写下恒等式

$$x^3 - 2x + 1 = (x - 1)(x^2 + x - 1).$$

但是，一般来说，多项式相除时会得到余数。另一个除法示例如 图 2 所示。余数为 2。我们知道这一点

$$\begin{array}{c}
x^3 - 2x + 1 \\
x^3 + x^2 \\
- x^2 - 2x + 1 \\
- x^2 - x \\
- x + 1 \\
- x + 1 \\
0
\end{array}$$

Puc. 2.

读到有一个身份

$$x^3 - 2x + 1 = (x + 1)(x^2 - x - 1) + 2.$$

余数是次数小于除数次数的多项式。特别是，如果除数是 $x - x_0$ 形式的二项式，则余数是一个数字。我们感兴趣的正是这个案例。

现在让我们继续讨论一般定义。

将多项式$P(x)$除以二项式$x - x_0$意味着找到一个多项式$Q(x)$和一个数$R$，从而获得恒等式

$$P(x) = (x - x_0)Q(x) + R.$$

(2)

您可以以任何方式搜索它们，例如用角分隔。下面的定理告诉我们除以二项式 $x - x_0$ 时的余数是多少。

贝佐特定理。多项式 $P(x)$ 除以二项式 $x - x_0$ 的余数为 $P(x_0)$。特别是，当且仅当数字 $x_0$ 是多项式 $P(x)$ 的根时，该余数才等于 0。

证明。我们将 $x = x_0$ 代入恒等式 (2) 并得到

$$P(x_0) = R,$$

这构成了定理的第一个陈述。从这个等式我们可以看出，如果 $P(x_0)$ 等于 0，即 $x_0$ 是 $P(x)$ 的根，$R$ 就等于 0。

因此，如果我们知道数字 $x_0$ 是多项式 $P(x)$ 的根，我们将其除以 $x - x_0$，提前知道（感谢贝佐特定理）余数将为零。因此，我们将创建该方程的解来求解另一个较小次数的方程。有时通过这种方式可以完全求解方程，即找到它的所有根。

三．求解方程时有用的另一个例子是变量替换。最有趣的情况是倒数方程。如果距两端距离相等的方程 (1) 的系数相等，则方程 (1) 称为倒数：

$$a_{n-k} = a_k$$ 对于从 0 到 $n$ 的所有 $k$。

$$x + \frac{1}{x} = t.$$ (3)

让我们使用返回的四次方程的示例来展示如何应用此替换：

$$ax^4 + bx^3 + cx^2 + bx + a = 0,$$，其中$a \neq 0$。

让我们将它除以 $x^2$ 并重写如下：

$$a \left(x^2 + \frac{1}{x^2}\right) + b \left(x + \frac{1}{x}\right) + c = 0.$$

让我们平方等式 (3)：

$$t^2 = \left(x + \frac{1}{x}\right)^2 = x^2 + \frac{1}{x^2} + 2,$$

IE。

$$x^2 + \frac{1}{x^2} = t^2 - 2.$$

引入一个新变量$t$，我们得到一个二次方程

$$a(t^2 - 2) + bt + c = 0.$$

对于奇数次的循环多项式，它们都可以被$x + 1$整除，除法后得到偶数次的循环多项式。让我们使用返回的五次方程的示例来说明这一点

$$ax^5 + bx^4 + cx^3 + bx + a = 0.$$

容易看出，$x = -1$是这个方程的根，因此，根据贝佐特定理，方程左边的多项式可以被$x + 1$整除。然而，除法的结果也可以通过对项进行分组来获得：

$$a(x^5 + 1) + bx(x^3 + 1) + cx^2(x + 1) = 0.$$

众所周知，$x^3 + 1$和$x^5 + 1$都可以被$x + 1$整除：

$$x^3 + 1 = (x + 1)(x^2 - x + 1),$$

$$x^5 + 1 = (x + 1)(x^4 - x^3 + x^2 - x + 1).$$

一般来说，对于任何 $k$，$x^{2k+1} + 1$ 都可以被 $x + 1$ 整除：

$$x^{2k+1} + 1 = (x + 1)(x^{2k} - x^{2k-1} + \dots - x + 1)$$

（“平坦”和“缺点”交叉）。
