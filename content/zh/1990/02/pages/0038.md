2) 从方程的数据可以立即得出$x_1 = x_n$，$x_2 = x_{n-1}$，$x_3 = x_{n-2}$，...：事实上，从第一个和最后一个可以清楚地看到$x_1 = x_n = 1/s$，从第二个和倒数第二个到$x_1 + x_2 = 1/(s - x_1) = 1/(s - x_n) = x_{n-1} + x_n$，即$x_2 = x_{n-1}$等。这种对称性从图1中立即可见，因为双曲线相对于 bisserris $y = s - x$ 头部对称。

第二句话让我们可以简单地写出小$n$的解决方案。

a）$n = 3$。然后$s = 2x_1 + x_2 = x_1 + s_1$。从方程 $x_1(x_1 + s_1) = 1$, $s_1^2 = 1$ 我们找到 $s_1 = 1$, $x_1^2 + x_1 - 1 = 0$，从哪里（从$x_1 > 0$开始）

$$x_1 = \frac{\sqrt{5} - 1}{2}, x_2 = 1 - x_1 = \frac{3 - \sqrt{5}}{2}, x_3 = x_1.$$

6) $n = 4$。然后$s = 2x_1 + 2x_2 = 2s_1$。从方程$2x_1s_1 = 1$，$s_1(2s_1 - x_1) = 1$我们找到$2s_1^2 = 1 + x_1s_1 = 3/2$，$s_1 = \sqrt{3}/2$，从哪里

$$x_1 = \frac{\sqrt{3}}{3}, x_2 = \frac{\sqrt{3}}{2} - \frac{\sqrt{3}}{3} = \frac{\sqrt{3}}{6}, x_3 = x_2, x_4 = x_1.$$

请注意，对于$n = 2$，可以立即找到答案：

$$2x_1^2 = 1, x_1 = x_2 = \sqrt{2}/2.$$

对于几何鉴赏家来说，这些数字会让人产生这样的想法：随机数$n = 2$、$n = 3$和$n = 4$在某种程度上与相应的角度$45^\circ$、$36^\circ$和$30^\circ$相关。事实上，我们将看到（参见图 2），对于任何$n$，都存在与角度$\alpha = 180^\circ/(n + 2)$相关的系统的解。从第一句话就可以看出这个解决方案是独一无二的。

让我们构造一个等边三角形$A_0OA_n$，边为$A_0O = OA_n = 1$，底角为$\alpha = 180^\circ/(n + 2)$；基于$A_0A_n$，我们标记点$A_1, A_2, ..., A_{n-1}$，以便从顶点$O$以相等的角度$\alpha$可以看到线段$A_0A_1, A_1A_2, ..., A_{n-1}A_n$。让我们证明这些线段$x_1, x_2, ..., x_n$的长度满足我们的系统。方便地通过点$O$绘制另一条射线OP，平行于$A_0A_n$（$\angle POA_0 = \alpha$）。三角形$A_0OA_k$和$A_nA_{k-1}O$相似（$\angle A_0 = \angle A_n = \alpha$、$\angle A_0OA_k = k\alpha = \angle POA_{k-1} = \angle OA_{k-1}A_n$），第一个三角形的边$A_0O = 1$和$A_0A_k = x_1 + ... + x_k$对应于第二个三角形的边$A_{k-1}A_n = x_k + ... + x_n$和$OA_n = 1$，从中我们得到方程

$$(x_1 + ... + x_k)(x_k + ... + x_n) = 1.$$

因此，解的存在性被证明。利用正弦定理，很容易得到显式公式：由于$OA_0 = 1$，

$$\angle A_0OA_k = k\alpha, \angle A_0A_kO = 180^\circ - \angle POA_k = 180^\circ - (k + 1)\alpha,$$

从$\Delta OA_{k-1}A_k$和$\Delta OA_0A_k$我们得到。
