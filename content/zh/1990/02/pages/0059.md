$$x + \frac{1}{x} = t.$$ (3)

让我们使用返回的四次方程的示例来展示如何应用此替换：

$$ax^4 + bx^3 + cx^2 + bx + a = 0,$$，其中$a \neq 0$。

让我们将它除以 $x^2$ 并重写如下：

$$a \left(x^2 + \frac{1}{x^2}\right) + b \left(x + \frac{1}{x}\right) + c = 0.$$

让我们平方等式 (3)：

$$t^2 = \left(x + \frac{1}{x}\right)^2 = x^2 + \frac{1}{x^2} + 2,$$

IE。

$$x^2 + \frac{1}{x^2} = t^2 - 2.$$

引入一个新变量$t$，我们得到一个二次方程

$$a(t^2 - 2) + bt + c = 0.$$

对于奇数次的循环多项式，它们都可以被$x + 1$整除，除法后得到偶数次的循环多项式。让我们使用返回的五次方程的示例来说明这一点

$$ax^5 + bx^4 + cx^3 + bx + a = 0.$$

容易看出，$x = -1$是这个方程的根，因此，根据贝佐特定理，方程左边的多项式可以被$x + 1$整除。然而，除法的结果也可以通过对项进行分组来获得：

$$a(x^5 + 1) + bx(x^3 + 1) + cx^2(x + 1) = 0.$$

众所周知，$x^3 + 1$和$x^5 + 1$都可以被$x + 1$整除：

$$x^3 + 1 = (x + 1)(x^2 - x + 1),$$

$$x^5 + 1 = (x + 1)(x^4 - x^3 + x^2 - x + 1).$$

一般来说，对于任何 $k$，$x^{2k+1} + 1$ 都可以被 $x + 1$ 整除：

$$x^{2k+1} + 1 = (x + 1)(x^{2k} - x^{2k-1} + \dots - x + 1)$$

（“平坦”和“缺点”交叉）。

至此我们就建立了理论。要了解如何使用它，请解决以下问题。

函授学校式作业

当函授数学学院（后来成为全联盟数学学院）创建时，测试优化和大规模研究的传统已经跨越了几十年。当然，这一传统对 VZMSH 的创建有很大帮助，但与此同时，它无法完全转移到远程学习环境中。奥林匹克竞赛一直旨在发现尚未具备数学文化的有才华的孩子。典型的优化问题是一个需要沟通但不存在技术困难的棘手问题，如果已经弄清楚了，则可以简单地编写其解决方案。这是问题优化的一个成功示例：“证明任何三角形paramid都有一条边，使得与其相邻的所有四个平面角都是锐角。”仅对一个短语即可给予积极评价（“平-s-减”）：“让我们取最长的肋骨。”

函授学校正是一所以培养数学文化为目标的学校。从优化的角度来看，它需要的任务是“丑陋的”，在写出需要计算、列举案例和一点独立研究的解决方案时遇到了困难。必须完成下一个任务的 VZMSH 学生本月必须系统地工作。函授学校还要求不适合优化或考试的任务。
