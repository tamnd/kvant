选项9
（经济学院）

1. 求函数的定义域
$$y = \frac{\sqrt{25 - x^2}}{\sqrt{x^2 - 2x - 8}}.$$

2. 计算
$$\frac{\log_3 42}{\log_{126} 3} - \frac{\log_3 378}{\log_{14} 3}.$$

3. 解方程
$$|x + 1| - |x - 3| = 6 = x.$$

4. 找到方程的所有解
$$\text{tg}(3\sin x) = -1,$$
满足条件$\frac{\pi}{2} < x < \frac{3}{2}\pi$。

5. 该圆经过三角形 $ABC$ 的顶点 $A$ 和 $C$，与边 $AB$ 相交于点 $D$，与边 $BC$ 相交于点 $E$。如果$CE = 1$、$BE = CD = 4$、$AD = BD = 4:1$，求角度$ACB$的值。

6. 解方程用于数字目的
$$9x^2y^2 + 9xy^2 + 6x^2y + x^2 + 2y^2 + 18xy + 5x + 7y + 6 = 0.$$

选项10
（心理学学院）

1. 解决不等式
$$x + 3 < \frac{1}{x + 1}.$$

2. 找到方程的所有解
$$\left| \cos^2 \frac{x}{2} - \frac{1}{3} \right| = 3\cos x + 1.$$

3. 找到方程组的所有解
$$\begin{cases} 2\log_x 8 + 3y = 24, \\ -2(\log_x 0,5)^3 + y = 8. \end{cases}$$

4. 在四边形$MNPQ$中有两个不相交的圆，其中一个与边$MN$、$NP$和$PQ$相接触，另一个与边$MN$、$MQ$和$PQ$相接触。点$B$和$A$分别位于边$MN$和$PQ$上，并且线段$AB$都接触两个圆。如果 $NP = b$ 和四边形的周长 $BAQM$ 比四边形 $ABNP$ 的周长大 $2p$，求边长 $MQ$。

5. 对于参数$a$的每个值，找到不等式的所有解
$$x + 2a - \sqrt{3ax + 4a^2} > 0.$$

选项11
（学院应用社会学系）

1. 解决不等式
$$\frac{x^2 - 5x + 4}{5 - x} > 0.$$

2. 解方程
$$\log_{\frac{1}{3}}(11 + x) = 2\log_{\frac{1}{3}}(\sqrt{x} + 1 + 2).$$

3. 距离逼近的阿喀琉斯还剩6米，乌龟意识到自己必须摆脱追击，它注定要离开。如果乌龟的速度比阿喀琉斯的速度小 17 倍，追逐过程中它们之间的距离减少了 9 倍，并且它们的运动是在一条直线上，那么自追逐开始以来，乌龟走了多远？

4. 求函数的最小值
$$y(x) = \frac{3}{4}|x| - x^3$$
在线段 $[-0, 7; +0, 7]$ 上。

5. 找到 $(\alpha, \beta)$ 的所有值对，其中每个值都有方程组
$$\begin{cases} 8x + (\alpha^2 + \alpha\beta + \beta^2)y = 4, \\ (\alpha - \beta)x + 26y = 2 \end{cases}$$
有无穷多个解。

（结构与应用线性系）

1. 解方程
$$2\cos(2x - \frac{\pi}{3}) + 1 = \cos(x + \frac{\pi}{3}).$$

2. 解决不等式
$$\sqrt{2x^2 + x} > 1 + 2x.$$

3. 解方程
$$\log_{2x+2}(2x^2 - 8x + 6) = 2.$$

4. 在以 $O$ 为圆心的圆中，移动 $AB$ 与半径 $OC$ 相交于点 $D$，角度 $CDA$ 等于 $\frac{2\pi}{3}$。求与线段 $AD$、$DC$ 和其他线段 $AC$ 相切的圆的半径，如果$OC = 2$、$OD = \sqrt{3}$。

5. 找到 $a$ 的所有值，使得每个值都有一个唯一的三元组 $(x, y, z)$ 满足等式 $x + y + z = x^2 + 4y^2$ 和 $x + 2y + 3z = a$。
