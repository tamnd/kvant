另一个是水平的，速度为$v_2$。移动过程中石块之间的最小距离是多少？石块的初始速度位于同一垂直平面内。

让我们选择 S.O.与第一块石头相关。那么第二块石头将以一定速度匀速直线运动（$\vec{a}_{21} = \vec{a}_2 - \vec{a}_1 = \vec{g} - \vec{g} = 0$）
$$\vec{v}_{\text{отн}} = \vec{v}_2 - \vec{v}_1.$$
从 图 3 很容易找到石子之间的最小距离：

$$d = l \sin \alpha = \frac{l v_1}{\sqrt{v_1^2 + v_2^2}}.$$

我们还要注意，石头之间的距离可以很容易地从 图 3 找到：

$$t = \frac{l \cos \alpha}{v_{\text{отн}}} = \frac{l \cos \alpha}{\sqrt{v_1^2 + v_2^2}} = \frac{l v_2}{v_1^2 + v_2^2}.$$

此时此刻，第一块石头必须不落地。即它必须满足条件
$$\frac{l v_2}{v_1^2 + v_2^2} \leq \sqrt{\frac{2h}{g}}.$$

可能会出现以下问题：我们找到了 S.O. 中石头之间的最小距离。与下面的石头有关；也许在与地球相关的S.O.中，答案会有所不同？不，那不是真的。两个移动点之间的距离是指所谓的不变量，即从一个系统移动到另一个系统时其值不会改变的量。以下是经典力学中其他不变量的示例：固有量之间的倒转时间、物体的大小、它们在空间中的方向等。

问题 3. 质量为 M、长度为 l 的小车位于主水平面上。车上有两个人，质量分别为$m_1$和$m_2$。如果两个人交换位置，小车会移动多远？

一方面，我们对小车相对于地面的运动感兴趣；另一方面，我们知道人的最终运动不是相对于地面，而是相对于车。怎么会这样呢？

我们假设所有物体（人和车）的运动是均匀的，并且我们将移动到 S.O.，其速度等于车在某个时刻$v_T$的速度。相对于这个SO，所有物体的初始速度都等于-$v_T$。让我们写出封闭系统“车-人”的动量守恒定律：

$$-v_T(m_1 + m_2 + M) = v_1_{\text{отн}} m_1 + v_2_{\text{отн}} m_2.$$

将该方程乘以$\Delta t$，我们就可以找到相应运动之间的联系：

$$s_T(m_1 + m_2 + M) = -s_1_{\text{отн}} m_1 - s_2_{\text{отн}} m_2.$$

显然，所有运动的总位移之间都存在相同的联系。考虑$s_1_{\text{отн}} = l$和$s_2_{\text{отн}} = -l$，我们得到

$$s_T = \frac{m_2 l - m_1 l}{m_1 + m_2 + M} = l \frac{m_2 - m_1}{m_1 + m_2 + M}.$$

这个问题在 S.O. 中也可以轻松解决。与系统的质心相关（请自行查看）*。例如，质心的坐标和速度可以通过以下公式求得

$$x_\text{ц} = \frac{m_1 x_1 + m_2 x_2 + ... + m_n x_n}{m_1 + m_2 + ... + m_n},$$

$$\vec{v}_\text{ц} = \frac{m_1 \vec{v}_1 + m_2 \vec{v}_2 + ... + m_n \vec{v}_n}{m_1 + m_2 + ... + m_n}.$$

从第二个等式可以清楚地看出，如果物体系统是封闭的，则群众的速度保持恒定。因此，与封闭系统质心相关的 SO 是惯性的。

*) 您可以了解更多关于质心的属性，例如，从注释“什么是质心”（«Kvant»，1988，第3期）。
