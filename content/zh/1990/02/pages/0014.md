乘以实数 $k$ 对应于以中心 $O$ 和系数 $k$ 为中心的相似性。

任意复数的乘法基于数字

$$i^2 = -1.$$

使用它，我们得到

$$(x_1 + iy_1)(x_2 + iy_2) = (x_1x_2 - y_1y_2) + i(x_1y_2 + x_2y_1).$$

复数除法也可以定义为乘法的逆运算。每当 $z_2 \neq 0$ 时，表达式 $z_1/z_2$ 就具有明确的含义，并由以下公式定义

$$\frac{x_1 + iy_1}{x_2 + iy_2} = \frac{(x_1 + iy_1)(x_2 - iy_2)}{(x_2 + iy_2)(x_2 - iy_2)} = \frac{x_1x_2 + y_1y_2}{x_2^2 + y_2^2} + i \frac{x_2y_1 - x_1y_2}{x_2^2 + y_2^2}.$$

尤其，

$$\frac{1}{x + iy} = \frac{x - iy}{x^2 + y^2}.$$

复数$\bar{z} = x - iy$称为数$z = x + iy$的共轭。显然，每个复数都与其共轭：$\bar{z} = z$共轭，并且点$\bar{z}$和$z$关于实轴彼此对称。

对于复数，您可以执行参数的所有四种运算，并且那些允许嫁接变换（将项从等式的一部分转移到另一部分、减少相似项、将它们移出括号）的代数对应关系是正确的。在数学语言中，这意味着复数形成一个域。

解方程
由于希望使解决代数方程的理论更加和谐，即以下形式的方程，数学中出现了历史复数

$$P(z) = 0,$$

其中$P(z)$是$n$次的代数多项式；

$$P(z) = z^n + a_{n-1}z^{n-1} + \dots + a_1z + a_0.$$

方程（1）或多项式（2）的根是同一个东西，是值$z$，其中（1）为真。解方程意味着找到它的所有根。

为了找到多项式的所有根，很容易提前知道有多少个。通过构建合适的定义系统，数学家成功地创造了一种情况，即多项式的根数始终等于其次数。让我们用二次方程的例子来展示他们是如何做到这一点的。考虑具有实数系数的简化二次方程

$$z^2 + pz + q = 0.$$

众所周知，它的根由以下公式表示

$$z_{1,2} = \frac{-p \pm \sqrt{D}}{2},$$

其中判别式$D = p^2 - 4q$。但是，只要我们只处理实数，这个公式在 $D < 0$ 处就失去了意义，并且我们的方程没有根。结果不同：非复曲面二次方程有两个根，非复曲面二次方程没有。这种不同的出版物引起了数学家的不满，从而促进了复数理论的发展。在复数领域，公式（4）对于 $D < 0$ 也有意义，其形式为

$$z_{1,2} = \frac{-p \pm i\sqrt{-D}}{2}.$$

将这些表达式代入式(3)，很容易验证是否得到了真正的等式。
