M1220*。让我们通过以下条件定义序列$b_n$：$b_1 = 0, b_2 = 2, b_3 = 3, b_{n+1} = b_{n-1} + b_{n-2}$ for $n \geq 3$。证明当 p 为素数时，数 $b_p$ 能被$p$整除。

我们给出两个解决方案。第一个基于数字$b_n$的组合解释。

让我们将一个圆被点 $A_0, A_1, \dots, A_{n-1}$ 分成 $n$ 等份，并考虑将其划分为由两部分或三部分组成的弧；让我们称它们为“合适的$n$分区”。令 $a_n$ 为此类分区的数量。那么显然$a_1 = 0, a_2 = 2, a_3 = 3$。让我们证明$a_{n+1} = a_{n-1} + a_{n-2}$适用于$n \geq 3$，因此$a_n = b_n$适用于所有$n$。为此，我们为每个合适的 $(n+1)$ 分区分配一个 $(n-1)$ 分区或 $(n-2)$ 分区，并表明所得到的对应关系是一对一的。

Strachem 到任意合适 $(n+1)$ 分区的友元点，该点顺时针遍历时遵循包含 $A_0$ 的弧线。 （如果点 $A_0$ 恰好位于两条弧之间，则减去从该点开始的指定遍历方向的弧；参见 图。）要将 $(n-1)$-或 $(n-2)$-分区恢复为原始 $(n+1)$-分区，只需创建一条与包含 $A_0$ 的弧后面的两个或三个部分相对应的弧（并且如果 $A_0$ 是两个弧的边界，则在这些弧之间）。由于我们通信的可逆性，它是一对一的。

现在让我们考虑所有适合素数 $p$ 的 $p$ 分区。让我们将通过角度 $2\pi k/p, k = 0, 1, \dots, p - 1$ 旋转而获得的那些组合为一组。请注意，在 $k_1 \neq k_2$ 处旋转 $2\pi k_1/p$ 和 $2\pi k_2/p$ 会将这些分区转换为不同的分区。 （否则，我们将得到一个在 $2\pi k/p$ 旋转下变换为自身的分区，其中 $k = k_1 - k_2$，因此在所有 $(2\pi k/p) \cdot n, n = 0, 1, \dots, p - 1$ 旋转下变换为自身。但是对于简单的 $p$，其中一个旋转与 $2\pi/p$ 旋转一致，并且这样的旋转不能将其自身转换为任何合适的分区。）因此，在每个石斑鱼中 $p$划分，因此 $b_p = a_p$ 可以被 $p$整除。

第二种解决方案是纯粹的代数解决方案，但使用了一些超出学校课程范围的事实。

令$\lambda_1, \lambda_2, \lambda_3$为方程$t^3 - t - 1 = 0$的三个根（其中两个是复数）。那么每个序列$\lambda_1^n, \lambda_2^n, \lambda_3^n$，以及它们的和$a_n = \lambda_1^n + \lambda_2^n + \lambda_3^n$，满足对应关系$a_{n+1} = a_{n-1} + a_{n-2}$。此外，根据维埃塔定理（通过打开等式$(t - \lambda_1)(t - \lambda_2)(t - \lambda_3) = t^3 - t - 1$中的括号产生）
