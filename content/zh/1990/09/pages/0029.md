V·杜布罗夫斯基

M1219*。证明对于任何 $n$ 正数 $x_1, x_2, \dots, x_n$ ($n > 1$)，不等式 $(x_2 + \dots + x_n)^{x_1} + \dots + (x_1 + \dots + x_{i-1}) + x_{i+1} + \dots + x_n)^{x_i} + \dots + (x_1 + x_2 + \dots + x_{n-1})^{x_n} > n - 1$ 成立。

例如，对于任何正数$x, y, z$，不等式$(x + y)^2 + (y + z)^x + (z + x)^y > 2$成立。

让我们用 $S$ 表示不等式左边的总和。如果对于某个索引 $i$，我们有 $x_i \geqslant 1$，则总和 $S$ 的每一项（也许除了第 $i$ 项）不小于 1；另外，第$i$项为正；从这里开始，所需的不平等立即出现。

现在对于每个索引$i$，我们有$0 < x_i < 1$。下面，在$x > 0$和$0 < y < 1$的假设下，我们将证明不等式

$$x^y > \frac{x}{x + y}.$$

假设这个不等式成立，我们得到

$$S > \frac{x_2 + \dots + x_n}{x_1 + \dots + x_n} + \dots + \frac{x_1 + \dots + x_{i-1} + x_{i+1} + \dots + x_n}{x_1 + \dots + x_n} + \dots + \frac{x_1 + \dots + x_{n-1}}{x_1 + \dots + x_n} = n - 1,$$

Q.E.D.

让我们回到不等式（1）。设 $x > 0$ 和 $0 < y < 1$；让我们输入$a = 1/y$。利用著名的伯努利不等式，我们得到

$$(1 + y/x)^a > 1 + ay/x = 1 + 1/x > 1/x.$$

因此$\frac{y+x}{x} > \frac{1}{x^y}$和$x^y > \frac{x}{x + y}$。因此，不等式（1）以及我们问题的不等式都得到了证明。

现在让我们证明我们使用以雅各布·伯努利命名的不等式：对于$h > 0$，$a > 1$

$$(1 + h)^a > 1 + ah.$$

如果$h = 0$，则(2)两边都等于1。因此，只要保证左侧的导数大于规则即可：随着$h$的增加，左侧增长得更快。我们有：

$$a(1 + h)^{a-1} > a,$$

从$a - 1 > 0$和$1 + h > 1$开始。 （可以证明，伯努利不等式（2）对于$a$和$h$的任意值有效，例如$0 \neq h > -1$和$a > 1$。顺便说一句，对于$a > 1$和$h = -1$，不等式（2）保持不变，对于$a = 1$或$h = 0$，它变成相等。）
