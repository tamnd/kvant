模 3 和 l 系统的运算
上一段构建的3系统有许多红色性质（由美国科学家理查德·汉明在20世纪40年代发现），需要稍微题外话来解释。
我们正在处理的向量，其分量可以从集合 $Z_3 = \{0,1,2\}$ 中获取值。 $Z_3$ 的元素可以以这样的方式相加和相乘，结果将再次是来自同一集合的元素。要做到这一点，执行一般的加法或乘法就足够了，找到结果除以 3 的余数（正如他们所说，对 3 取模）。例如，$5 \equiv 2(\text{mod } 3), -2 \equiv 1(\text{mod } 3)$。
使用这些操作，我们可以定义三元向量的加法。我们将向量$a$和$b$的和定义为向量$c$，其每个坐标是向量$a$和$b$对应坐标的模3之和。例如，$(0,1,1,2) + (1,2,1,1) = (1,0,2,0)$。让我们将一个向量和一个三进制数$v \in Z_3$的乘积定义为一个向量，其坐标是通过向量的坐标乘以$v$模3得到的。例如，$2 \cdot (1,0,2,2) = (2,0,1,1)$。在数学中，这种带有定义的数字的加法和乘法运算的向量集合称为向量空间。

练习 2. 检查上一段中介绍的 3 系统 $C_0$ 是否具有以下属性：对于任何向量 $a \in C_0$ 和常数 $v \in Z_3$，乘积 $va$ 也取 $C_0$；对于任意两个向量$a, b \in C_0$，它们的和也是来自$C_0$的向量。这样的系统称为线性系统。

模 3 运算使我们能够对 3 系统$C_0$ 进行简要描述。首先，请注意，来自 $C_0$ 的向量的第一个坐标 $(x_1, x_2)$ 可以是任意一对三进制数。我们将这一对称为向量的三进制数。剩余两个坐标$x_3$和$x_4$的值可以使用以下规则计算（动作模3）：

$$x_3 = x_1 + x_2, \quad x_4 = x_1 + 2x_2$$

假设您按照$C_0$系统填写卡片。官方报纸公布了包含在发行量中的比赛结果（向量$y$）。如何快速找到获胜卡（它的存在是由系统的属性决定的）？一个显而易见但有时不是最好的方法是将抽奖结果与所有已完成的卡片进行比较并找到最优秀的分数。

为了描述更快的方法，将方程（1）重新排列为等效形式：

$$x_1 + x_2 + 2x_3 = 0, \quad x_1 + 2x_2 + 2x_4 = 0.$$

我们的方法将基于系统$C_0$的每个坐标的坐标满足方程（2）的事实。如果$y$满足(2)，则属于$C_0$系统，通过其三进制数可以找到其对应的卡。否则，$y$ 与同一坐标中的某个向量 $c = (c_1, c_2, c_3, c_4) \in C_0$ 不同。设其数为$j$。让我们找到 $S_1 = y_1 + y_2 + 2y_3$ 和 $S_2 = y_1 + 2y_2 + 2y_4$。
