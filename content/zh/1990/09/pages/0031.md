$$a_1 = \lambda_1 + \lambda_2 + \lambda_3 = 0,$$
$$\lambda_1^3 \lambda_2 + \lambda_2^3 \lambda_3 + \lambda_3 \lambda_1 = -1, \quad \lambda_1 \lambda_2 \lambda_3 = 1,$$
在哪里
$$a_2 = \lambda_1^2 + \lambda_2^2 + \lambda_3^2 = (\lambda_1 + \lambda_2 + \lambda_3)^2 - 2(\lambda_1 \lambda_2 + \lambda_2 \lambda_3 + \lambda_3 \lambda_1) = 2;$$
$$a_3 = \lambda_1^3 + \lambda_2^3 + \lambda_3^3 = (\lambda_1 + \lambda_2 + \lambda_3)^3 - 3(\lambda_1 + \lambda_2 + \lambda_3)(\lambda_1 \lambda_2 + \lambda_2 \lambda_3 + \lambda_3 \lambda_1) + 3\lambda_1 \lambda_2 \lambda_3 = 3.$$

因此，$a_n = b_n$ 对于所有$n$。
现在我们注意到
$$a_p = \lambda_1^p + \lambda_2^p + \lambda_3^p = (\lambda_1 + \lambda_2 + \lambda_3)^p - \Sigma C_p^{(k, l, m)} \lambda_1^k \lambda_2^l \lambda_3^m,$$

其中求和是对除 $(p, 0, 0), (0, p, 0)$ 和 $(0, 0, p)$ 以外总和为 $k + l + m = p$ 的所有非负整数集合 $(k, l, m)$ 求和，并且
$$C_p^{(k, l, m)} = \frac{p!}{k!l!m!},$$

并证明对于素数$p$，数$a_p$可被$p$整除。
很明显，对于给定的集合$(k, l, m)$，系数$C_p^{(k, l, m)}$可以被素数$p$整除。接下来，我们在求和中选择一组仅在指数$k, l, m$的排列上不同的项。对于所有这些项，系数 $C_p^{(k, l, m)}$ 都是相同的，并且相应的单项式 $\lambda_1^k \lambda_2^l \lambda_3^m$ 的和是 $\lambda_1, \lambda_2, \lambda_3$ 中所谓的对称多项式（即，重新排列参数时它不会改变）。众所周知，这样的多项式总是可以表示为具有主要对称函数 $\sigma_1 = \lambda_1 + \lambda_2 + \lambda_3, \sigma_2 = \lambda_1 \lambda_2 + \lambda_2 \lambda_3 + \lambda_3 \lambda_1, \sigma_3 = \lambda_1 \lambda_2 \lambda_3$ 整数系数的某个多项式 - 这是对称多项式主要定理的一个特例（例如，参见 V. G. Boltyansky, N. Ya. Vilenkin 的书“Symmetry in Algebra”, M.: Nauka, 1987）。我们的数字$\sigma_1 = 0, \sigma_2 = -1, \sigma_3 = 1$是整数，因此每组项的总和以及整个总和可以被$p$整除。因此，因为$\lambda_1 + \lambda_2 + \lambda_3 = 0$和$a_p$可以被$p$整除。

D.福明，N.瓦西里耶夫
