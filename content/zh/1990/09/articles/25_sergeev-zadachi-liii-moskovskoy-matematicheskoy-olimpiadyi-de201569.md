莫斯科数学奥林匹克任务LIII

第十三届莫斯科数学奥林匹克决赛于 1990 年 3 月 4 日在莫斯科大学举行。超过1000名8至11年级的学生参加了此次活动。以下是此类任务（分配了 4 小时来解决这些任务）。

八年级
1. 证明如果$0 < a_1 < a_2 < ... < a_8 < a_9$，则
$$\frac{a_1 + a_2 + ... + a_9}{a_3 + a_6 + a_9} < 3.$$
A、复选标记
2. 当$m, n$是自然数时，数$m(n+9)(m+2n^2+3)$可以有的不同质因数的最小数量是多少？
A·斯皮瓦克
3. 8、9、10 和 11 年级的优胜者被邀请参加奥运会预选赛，总共 11 人。是否可以将他们安排在圆桌旁，使得坐在一排的任意五个学生中都有所有四个班级的代表？
S·科尼亚钦
4. 在内切于圆的四边形$ABCD$中，通过顶点$A, B$和对角线的交点，绘制一个圆，该圆与边$BC$相交于点$E$。证明如果$AB=AD$则$CE=CD$。
B·普罗塔索夫
5. 记分板由 64 个灯泡组成，由 64 个 konkammies 控制；每个灯泡都是新鲜制作的。打开一次开关后，您可以同时按下任意一组开关并记录哪些灯被关闭。最少需要多少个开关，你才能找出板上所有的灯，哪个灯是由哪辆电车打开的？
S·加什科夫
九年级
1. 在一组七个男孩中，每个男孩至少有三个兄弟。证明七人都是兄弟。
S·科尼亚钦
2. 证明从 53 个不同的自然数中，总和不超过 1990，总有可能选出 2 个加起来等于 53 的数字。
S·科尼亚钦
3. 在这个圆中，有一个点偏移半径为1。通过它绘制各种路径，并通过路径的两端绘制半径为2的圆。证明所有画出的圆都接触某个固定的圆。

B·普罗塔索夫
4. 共有 8 枚硬币，其中 2 枚是假币：一枚比真币轻，一枚比真币重。是否可以在没有秤的情况下通过秤 3 次称重来确定哪一个更重：2 个假币或 2 个真币，或者它们的重量相同？
谢尔盖夫
5. 有理数的小数表示法的周期长度为$n$。这个数的平方的小数表示法的最长周期是多少？
S·加什科夫
10年级
1. 是否可以将一个正方形切成3个两两不同且两两相似的三角形？
S·科尼亚钦
2. 找到所有满足等式的素数$p, q, r$
$$p^q + q^r = r.$$
B·库库什金
3. 证明对于参数$a, b, c$的所有值，都存在一个满足不等式的数$x$
$$a \cos x + b \cos 3x + c \cos 9x \geq \frac{|a| + |b| + |c|}{2}.$$
S·加什科夫
4. 圆中四个点的相对位置在什么位置时，这些点之间所有成对距离的乘积最大？
A·斯皮瓦克
5. 点 $A, B, C, D$ 位于空间中，因此从点 $A$ 和 $C$ 以角度 $\alpha$ 可以看到线段 $BD$，从点 $B$ 和 $D$ 以角度 $\beta$ 可以看到线段 $AC$。如果 $AB \neq CD$ 则求关系 $AC:BD$。
H·鲍尔辛
11年级
1. 求表达式的最大值
$$x \sqrt{1-y^2} + y \sqrt{1-x^2}.$$
谢尔盖夫
2. 证明如果函数$f(x)$定义在区间$[0; 1]$上，是连续的并且满足恒等式$f(f(x)) = x^2$，则有效估计为$x^2 < f(x) < x$、$x \in (0; 1)$。举一个这样的函数的例子。
谢尔盖夫
3. 在三角形 $ABC$ 中，绘制中线 $BD$ 和 bissertrix $BE$。 $BD$ 是三角形 $BCE$ 中的比塞特里克斯，$BE$ 是三角形 $ABD$ 中的中线，这是否是随机的？
B·库库什金
4. 证明对于任何奇数，都存在它的倍数，其十进制表示法仅由奇数位组成。
谢尔盖夫
5. 空间中四个点的什么位置可以作为对应于某个四面体的四个面的任意点的投影？
B·普罗塔索夫
