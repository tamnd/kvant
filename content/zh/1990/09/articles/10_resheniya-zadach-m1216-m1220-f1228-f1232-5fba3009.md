答案：$\angle A=60^\circ, \angle B=45^\circ, \angle C=75^\circ$。

让我们使用这样一个事实：在任何三角形中（在问题的表示法中）$\angle CAH=\angle BAO$（因此$\angle HAD=\angle OAD$；图 1）。事实上，$\angle CAH=90^\circ-\angle ACB, \angle BAO=90^\circ-\angle AEB$，其中$E$是从$A$绘制的直径的第二端，角度$ACB$和$AEB$位于公共弧$AB$上。

M1220*。让我们通过以下条件定义序列$b_n$：$b_1 = 0, b_2 = 2, b_3 = 3, b_{n+1} = b_{n-1} + b_{n-2}$ for $n \geq 3$。证明当 p 为素数时，数 $b_p$ 能被$p$整除。

我们给出两个解决方案。第一个基于数字$b_n$的组合解释。

让我们将一个圆被点 $A_0, A_1, \dots, A_{n-1}$ 分成 $n$ 等份，并考虑将其划分为由两部分或三部分组成的弧；让我们称它们为“合适的$n$分区”。令 $a_n$ 为此类分区的数量。那么显然$a_1 = 0, a_2 = 2, a_3 = 3$。让我们证明$a_{n+1} = a_{n-1} + a_{n-2}$适用于$n \geq 3$，因此$a_n = b_n$适用于所有$n$。为此，我们为每个合适的 $(n+1)$ 分区分配一个 $(n-1)$ 分区或 $(n-2)$ 分区，并表明所得到的对应关系是一对一的。

Strachem 到任意合适 $(n+1)$ 分区的友元点，该点顺时针遍历时遵循包含 $A_0$ 的弧线。 （如果点 $A_0$ 恰好位于两条弧之间，则减去从该点开始的指定遍历方向的弧；参见 图。）要将 $(n-1)$-或 $(n-2)$-分区恢复为原始 $(n+1)$-分区，只需创建一条与包含 $A_0$ 的弧后面的两个或三个部分相对应的弧（并且如果 $A_0$ 是两个弧的边界，则在这些弧之间）。由于我们通信的可逆性，它是一对一的。

现在让我们考虑所有适合素数 $p$ 的 $p$ 分区。让我们将通过角度 $2\pi k/p, k = 0, 1, \dots, p - 1$ 旋转而获得的那些组合为一组。请注意，在 $k_1 \neq k_2$ 处旋转 $2\pi k_1/p$ 和 $2\pi k_2/p$ 会将这些分区转换为不同的分区。 （否则，我们将得到一个在 $2\pi k/p$ 旋转下变换为自身的分区，其中 $k = k_1 - k_2$，因此在所有 $(2\pi k/p) \cdot n, n = 0, 1, \dots, p - 1$ 旋转下变换为自身。但是对于简单的 $p$，其中一个旋转与 $2\pi/p$ 旋转一致，并且这样的旋转不能将其自身转换为任何合适的分区。）因此，在每个石斑鱼中 $p$划分，因此 $b_p = a_p$ 可以被 $p$整除。

彼此相距遥远的领域都意识到克服相互影响是可能的。显然，“重新安排”费用时的最小工作量并不取决于这种重新安排的方法。重要的是，在球体 1 的中心（其外半径$R_1=R$）有一个电荷 2Q，在球体 2 的中心（$R_2=3R$）有一个电荷 Q。因此，我们将电荷 Q 从第二个球体转移到第一个球体就足够了。完美功的极小性意味着感应电荷沿球体运动期间不可能发生能量耗散。

我们将以连续的无限小部分 dq 进行电荷 Q 从球体 2 到球体 1 的转移。假设在某个任意时刻我们已经将电荷 q 转移到第一个球体。那么在球体 1 的中心将有一个电荷 $Q+q$，在球体 2 的中心将有一个电荷 2Q-q。让我们找出转移下一部分电荷 dq 所需的功 dA。位于球体中心的每个电荷（$Q+q$ 或 2Q-q）的电场将被视为场的叠加：距球体中心所有有意义距离 r 的点电荷的场，以及球体 1 的区域 $R_1-\delta \leq r \leq R_1$（$\delta=R/20$ 是球体的厚度）和$R_2-\delta \leq r \leq R_2$ 区域中具有相反符号的相同电荷的场对于球体 2，则工作 dA 将由两部分组成：在点电荷 $Q+q$ 和 2Q-q 场中移动电荷 dq 的工作，以及在$R_1-\delta \leq r \leq R_1$ 和 $R_2-\delta \leq r \leq R_2$ 区域中移动该电荷的工作，其中场由点电荷 - ($Q+q$) 和 -($2Q-q$) 创建。

让我们用$dA_1$表示工作的第一部分，用$dA_2$表示第二部分。很容易报告（这是根据空间对称性得出的）：
$$dA_1 = 0.$$
功$dA_2$可以写成
$$dA_2 = \frac{2Q - q}{4\pi\varepsilon_0} \left( \frac{1}{R_2 - \delta} - \frac{1}{R_2} \right) dq + \frac{Q + q}{4\pi\varepsilon_0} \left( \frac{1}{R_1} - \frac{1}{R_1 - \delta} \right) dq.$$
这里我们使用电势 $\varphi(r)$ 的表达式来表示精确的电荷 $q$：
$$\varphi(r) = \frac{q}{4\pi\varepsilon_0 r}.$$
对所有费用进行求和（沿着 $dq$ 从 0 到 $q$ 进行积分），我们将找到所需的功 $A$。在计算工作时，我们使用
$$\int_0^Q dq = Q \text{ и } \int_0^Q q dq = \frac{Q^2}{2}.$$
最后我们得到
$$A = A_2 = \frac{3Q^2\delta}{8\pi\varepsilon_0} \left( \frac{1}{R_2(R_2 - \delta)} - \frac{1}{R_1(R_1 - \delta)} \right).$$
以一般形式找到答案总是有用的，因为这可以让您检查对所获得结果的分析。例如，在这种情况下，很明显，在$\delta \rightarrow 0$处，功也应该趋向于零，如我们的表达式所示。在 $R_1 = R_2$ 时，功也必须为零，这也是从我们的解决方案中得出的。
根据问题的条件，$\delta$远小于$R_1$和$R_2$，因此我们可以将得到的解写成形式
$$A = \frac{3Q^2\delta}{8\pi\varepsilon_0} \frac{R_1^2 - R_2^2}{R_1^2 R_2^2}.$$
当替换给定值$R_1, R_2$和$\delta$时，我们得到
$$A = -\frac{79}{4484} \frac{Q^2}{\pi\varepsilon_0 R} \approx -\frac{1}{60} \frac{Q^2}{\pi\varepsilon_0 R}.$$
解决这个问题的另一种可能的方法是能源。让我们考虑一下近似情况 ($\delta \ll R$)。让我们写下系统在初始状态下的能量：
$$W_H = W_1 - \frac{\varepsilon_0 E_1^2}{2} 4\pi R_1^2 \delta + W_2 - \frac{\varepsilon_0 E_2^2}{2} 4\pi R_2^2 \delta.$$
这里$W_1$和$W_2$是精确电荷$Q$和$2Q$的电场能量，$E_1 \approx Q/(4\pi\varepsilon_0 R_1^2)$是电荷$Q$在距离$R_1 - \delta \leq r \leq R_1$处的电场强度，$E_2 \approx 2Q/(4\pi\varepsilon_0 R_2^2)$是电荷$2Q$在距离处的场强$R_2 - \delta \leq r \leq R_2$。替换后我们得到
$$W_H \approx W_1 - \frac{Q_2\delta}{8\pi\varepsilon_0 R_1^2} + W_2 - \frac{Q^2\delta}{2\pi\varepsilon_0 R_2^2}.$$

F1231。两个带有铁氧体磁芯的圆柱形线圈彼此靠近放置并串联。其中一个的电感为1 mH，另一个为2 mH，串联线圈的修正电感为3.6 mH。在不改变线圈相对位置的情况下，将它们并联切换（参见图）。我们现在要改变什么电感？

如果线圈距离较远，则它们之间的相互影响可以忽略不计。那么磁通量将由大小决定

$$\Phi = L_1 I + L_2 I = (L_1 + L_2) I,$$

也就是说，所得的电感将等于线圈的电感之和。在我们的例子中，情况并非如此：

$$L_{06\pi} = 3,6 \text{ мГн} > L_1 + L_2,$$

这意味着总磁通量的很大一部分是一个线圈的电流通过另一个线圈的匝所产生的“互”通量。换句话说，

$$\Phi_{06\pi} = L_1 I + L_2 I + MI + MI = (L_1 + L_2 + 2M) I.$$

这里，字母$M$表示“互感”（更准确地说，互感系数）——一个线圈中的电流与另一个线圈的任意匝数的磁通量之间的比例系数（线圈的电感catapti也称为“自感系数”）。实际上，存在两个互感系数：第一个线圈的电流与第二个线圈中的磁通之间以及第二个线圈的电流与第一个线圈中的磁通之间。这些赔率总是相同的。对于具有不同匝数的相同匝数的线圈，这种等式很容易证明（尝试一下），在一般情况下很难做到这一点 - 然而，事实本身是众所周知的。

现在让我们求互感系数：

$$M = (L_{06\pi} - L_1 - L_2) / 2 = 0,3 \text{ мГн.}$$

当切换线圈两端时，它们的相对位置不会改变，这意味着“互感”保持不变，尽管互磁通的贡献可以是正的或负的（取决于电线的连接顺序）。当收到答案时，我们会考虑两种可能的选择，数$M = \pm 0,3 \text{ мГн.}$。

因此，我们将并联后的线圈点表示为$I_1$和$I_2$。感应电动势的传导方式相同；这意味着磁通量相同：

$$\Phi_1 = L_1 I_1 + MI_2, \quad \Phi_2 = L_2 I_2 + MI_1, \quad \Phi_1 = \Phi_2, \quad I_1 + I_2 = I_{06\pi}.$$

现在您可以表示流过总电流的任何流量以及它们之间的比例系数 - 这将是变化后的电感值：

F1232。距地球很远的地方有一颗行星 DVK-1，BK-0010SH 卫星围绕该行星以圆形轨道运行。该卫星有一个发射恒定频率信号的无线电台。该信号在地球上被接收，但是，会发生中断 - 45 分钟内有信号，因此 45 分钟内没有信号，因此 45 分钟内有信号，等等。问题并不限于此 - 接收到的信号的频率根据 图 ($\Delta f = 3 \cdot 10^4$ Hz) 所示的规律相对于平均值 $f_0 = 1,5 \cdot 10^9$ Hz 发生变化。假设地球-行星部分位于卫星轨道平面内，则可以求出 DVK-1 的质量。

行星卫星的轨道周期非常多
$$T = 2 \cdot 45 \text{ мин} = 90 \text{ мин}.$$
一半的时间卫星被行星隐藏；一半的时间卫星被行星遮挡。这意味着他飞得非常接近其表面。接收信号频率的变化是由于多普勒效应造成的：
$$\frac{\Delta f}{f_0} = \frac{v}{c}.$$
这里$v$是卫星的速度，$c$是信号传播的速度（光速）。
另一方面，从力学的对应关系来看
$$T = \frac{2\pi R}{v} \ln \frac{mv^2}{R} = G \frac{mM}{R^2},$$
其中$R$是半径，$M$是行星的质量，$G$是花岗岩常数。
经过简单变换后，得出行星的质量：
$$M = \left( c \frac{\Delta f}{f_0} \right)^3 \frac{T}{2\pi G} \approx 2,8 \cdot 10^{24} \text{ кг}.$$
