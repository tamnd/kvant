3) 场电压在球表面达到最大值。我们通过球的潜力来表达：

$$E(R) = \frac{1}{4\pi\varepsilon_0} \frac{q}{R^2} = \frac{\varphi_m}{R}.$$

可以看出，在相同电位下，小球表面的场电压更大。 （这意味着，例如，在小球附近，空气击穿发生在较低的电位。）

此外，导体表面的场电压仅取决于表面电荷密度$\sigma$：

$$E(R) = \frac{1}{\varepsilon_0} \frac{q}{4\pi R^2} = \frac{\sigma}{\varepsilon_0}.$$

这种对应关系对于任何形状的导体都有效——从某一导电部分开始的电源线数量与该部分的电荷成正比。 （特别是，它适用于扁平电容器的场。由于该场是由两个板创建的，因此一个板（即均匀充电平面）的场等于 $\sigma/(2\varepsilon_0)$。）

4) 请注意，球的电势与其电荷成正比（公式（3））。对于任意形状的单个导体，同样的说法也成立：

$$\varphi \sim q, \quad \varphi = \frac{1}{C} q,$$

其中$C$是导体的电容量（电容），它取决于导体的形状和尺寸。 （例如，球体的容量为 $C = 4\pi\varepsilon_0R$。）

为了证明$\varphi$和$q$的比例关系，我们使用唯一性定理——一个非常重要的定理，确实是发电厂的“魔杖”。它指出导体上的电荷只有一种平衡分布是必要的，即 $\vec{E} = 0$ 位于所有导体内部的分布（前提是给定所有导体的电荷或其电势）。 （免费费用几乎立即找到其平衡位置并非没有原因 - 毕竟，他们并没有面临痛苦的选择！）

让唯一的导体在被赋予电荷$q$时获得电势$\varphi$。让我们另外向该导体施加相同的电荷$q$，并确保导体的电势加倍。如果电荷的第二部分以与第一部分完全相同的方式分布在表面上，则导体内部的电压保持为零（每个部分的贡献为零）。这正是比较的方式 - 毕竟，只有“好的”分布！这意味着新的电荷部分在导体上产生相同的电势 $\varphi$，最终电势将等于 $2\varphi$。

问题2. 两个相距较远的导电球，其半径分别为$R_1$和$R_2$，分别携带电荷$q_1$和$q_2$。用电线连接后，球的电位和电荷是多少？

解决方案。连接后，两个球与接线一起形成单个导体。因此，在平衡状态下，球的电势必须彼此相等：

$$\varphi'_1 = \varphi'_2 = \varphi'$$，或$$\frac{1}{4\pi\varepsilon_0} \frac{q'_1}{R_1} = \frac{1}{4\pi\varepsilon_0} \frac{q'_2}{R_2},$$

也就是说，球的电荷与其半径成正比（连接后球的电荷和电势被笔划抵消）。由于电荷仅沿着布线在球与球之间移动，而不会从外部进入系统并且不会离开系统，因此满足电荷守恒定律：

$$q_1 + q_2 = q'_1 + q'_2$$

（我们忽略接线上的电荷）。求解所得方程，我们发现

$$q'_1 = (q_1 + q_2) \frac{R_1}{R_1 + R_2}, q'_2 = (q_1 + q_2) \frac{R_2}{R_1 + R_2},$$

$$\varphi' = \frac{1}{4\pi\varepsilon_0} \frac{q_1 + q_2}{R_1 + R_2}.$$

讨论 1) 通过布线两个彼此远离的任意形状、具有电容 $C_1$ 和 $C_2$ 的导体来连接问题的解决方案看起来完全相同：

$$q'_1 = (q_1 + q_2) \frac{C_1}{C_1 + C_2}, q'_2 = (q_1 + q_2) \frac{C_2}{C_1 + C_2},$$

$$\varphi' = \frac{q_1 + q_2}{C_1 + C_2}.$$
