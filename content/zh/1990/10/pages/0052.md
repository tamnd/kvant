[5]。那么圆锥体的母线——射线 $OU'$ (图 2)——位于 $O_1$ 下方。

[6]。圆锥体$OV'$ (图 2) 的母线位于$O_1$ 上方（易于计数）。

[7！！]。从最后两个陈述和连续性消息可以看出，$O_2$上的现有点$E$使得射线$OE$在点$E'$“产生”圆$O_1$，

[8] 因此从$E$到$E'$的距离等于$\sqrt{3} - \sqrt{2}$，即$\rho \leqslant \sqrt{3} - \sqrt{2}$。

[9]。因此，$\rho = \sqrt{3} - \sqrt{2}$。

很棒的红色解决方案，不是吗？如果你自己找到它，你会更喜欢它。奥赛上解决这个问题的人还不算少，五到十个人，而且都是这样解决的，几何级数。但我们前面有一条不同的道路。

但在继续讨论类似的解决方案之前，我必须向您介绍一种由拉格朗日发现的用于研究极值问题的非常重要的分析方法（我在上述书中用了很大一部分内容来介绍这种方法 - 请参阅当天的故事）。正是在拉格朗日的帮助下，我站出来在一定条件下连接变量$x, y, z$，$u$的部分类似的。例如，

$$f_1(x, y, z, u) = 0,$$
$$f_2(x, y, z, u) = 0,$$
其中$f_1$和$f_2$是函数数据。

然后（拉格朗日说）如果存在解，则可以使用以下方法找到解。

令$\lambda_0, \lambda_1$和$\lambda_2$是一些（我们还不知道的）数字，不全等于0。

考虑功能

$$L = \lambda_0 f_0 + \lambda_1 f_1 + \lambda_2 f_2.$$

令$L_x, L_y, L_z$和$L_u$为变量$x, y, z, u$中$L$的任意函数。然后，函数 $f_0$ 达到最小值（最大值）的点 $(x_0, y_0, z_0, u_0)$ 由方程组给出

$$\begin{cases} f_1(x, y, z, u) = 0, \\ f_2(x, y, z, u) = 0, \\ L_x = L_y = L_z = L_u = 0. \end{cases}$$

（请注意，这是一个包含 7 个未知数的 6 个方程组，从中可以找到数字 $x_0, y_0, z_0, u_0$ 和 $\lambda_0, \lambda_1, \lambda_2$。）

这个例子是通用的，技术上非常简单，并且对于它的应用来说，除了任意概念之外不需要任何东西。让我们用它来解决我们的问题。

解决方案二（分析）。

[1]。圆$O_2$表示为$x = \cos \varphi, y = \sin \varphi, z = -1, -\pi \leqslant \varphi \leqslant \pi$。

[2]。我们将圆$O_1$定义为球体$x^2 + y^2 + z^2 = 3$与平面$x - y + z = -1$的交点。

[3]。 Teler 的问题表述如下。求函数的最小值

$$f_0(x, y, z, \varphi) = (x - \cos \varphi)^2 + (y - \sin \varphi)^2 + (z + 1)^2$$

在条件下

$$f_1(x, y, z) = x - y + z + 1 = 0,$$
$$f_2(x, y, z) = x^2 + y^2 + z^2 - 3 = 0.$$

[4]。很容易理解，考虑扇区$-\frac{\pi}{2} \leqslant \varphi \leqslant \frac{\pi}{2}$就足够了。

[5]。让我们构造拉格朗日函数

$$L = \lambda_0 ((x - \cos \varphi)^2 + (y - \sin \varphi)^2 + (z + 1)^2) + \lambda_1 (x - y + z + 1) + \lambda_2 (x^2 + y^2 + z^2 - 3)$$

并计算其任意值：

$$L_\varphi = 2\lambda_0 ((x - \cos \varphi) \sin \varphi) - (y - \sin \varphi) \cos \varphi) = 0,$$

$$L_x = 2\lambda_0 (x - \cos \varphi) + \lambda_1 + 2\lambda_2 x = 0,$$

$$L_y = 2\lambda_0 (y - \sin \varphi) - \lambda_1 + 2\lambda_2 y = 0,$$

$$L_z = 2\lambda_0 (z + 1) + \lambda_1 + 2\lambda_2 z = 0.$$
