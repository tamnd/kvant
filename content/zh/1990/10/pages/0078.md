8. a) 令 $a_1, a_2, \dots, a_n$ 为这些向量，$S = a_1 + a_2 + \dots + a_n$ 它们的和。让我们取任意一组 $p$ 向量 $\vec{a}_{i1}, \vec{a}_{i2}, \dots, \vec{a}_{ip-1}, \vec{a}_i$。根据问题$|\vec{a}_{i1} + \vec{a}_{i2} + \dots + \vec{a}_{ip-1}| = |\vec{S}|\vec{a}_{i1} - \vec{a}_{i2} - \dots - \vec{a}_{ip-1} - \vec{a}_i$的条件。由此可见$|\vec{S}|^2 = 2(\vec{S}, \vec{a}_{i1} + \vec{a}_{i2} + \dots + \vec{a}_{ip-1} + \vec{a}_i)$。类似地，对于集合$\vec{a}_{i1}, \vec{a}_{i2}, \dots, \vec{a}_{ip-1}, \vec{a}_j$，等式$|\vec{S}|^2 = 2(\vec{S}, \vec{a}_{i1} + \vec{a}_{i2} + \dots + \vec{a}_{ip-1} + \vec{a}_j)$成立。因此，对于任何$i, j, t$，$(\vec{S}, \vec{a}_i - \vec{a}_j) = 0$。即标量积 $(\vec{S}, \vec{a}_i) = k$ 不依赖于 $i$。因此$|\vec{S}|^2 = (\vec{S}, \vec{a}_1 + \dots + \vec{a}_n) = nk$。另一方面，$|\vec{S}|^2 = 2(\vec{S}, \vec{a}_{i1} + \vec{a}_{i2} + \dots + \vec{a}_{ip-1} + \vec{a}_j)$。因此，$nk = 2pk$、$(n - 2p)k = 0$、$k = 0$、$p \neq \frac{n}{2}$。因此，$|\vec{S}| = 0$，$\vec{S} = \vec{0}$。
