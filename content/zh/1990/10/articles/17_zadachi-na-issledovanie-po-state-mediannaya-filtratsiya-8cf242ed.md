统计“中值过滤”的研究任务

（参见第 8 页）

1. 证明如果序列$x_n$在窗口宽度$2k+1$的中值滤波器下是不变的，并且其项至少取三个不同的值，那么它在任何具有较小窗口宽度的中值滤波器下都是不变的。

标记 e 时。第二个条件是必不可少的。例如，“锯”$x_n=(-1)^n$对于具有偶数$k$的滤波器是不变的，并且对于具有奇数$k$的滤波器来说是非不变的。

2. 通过在相应序列的左侧和右侧重复极端元素，有限序列可以继续到无限。证明如果序列长度为$l$，则$\left[\frac{l-1}{2}\right]$应用窗口宽度$2k+1$的中值滤波器后，得到不变序列（这里[]是数字的整数部分）。

检查序列继续的方式是否重要（例如，在 $l=2$ 处）。

3. 递归中值滤波器是从滤波后的序列中取出滑动窗口的前$k$个数的中值滤波器，即将序列$x_n$变换为序列$y_n=m(y_{n-k}, y_{n-k+1}, \dots, y_{n-1}x_n, x_{n+1}, \dots, x_{n+k})$（$n<0$时认为是$x_n \equiv x_0$）。

a) 证明序列在递归中值滤波器下不变当且仅当它在一般中值滤波器下不变。

b) 证明任何序列经过递归中值滤波器一次后变得不变。

4. 我们会说序列$x_n$的中点等于$a$，如果对于任何$\varepsilon>0$存在$M$，使得对于任何$n$和$m>M$

$$|m(x_{n-m}, x_{n-m+1}, \dots, x_n, \dots, x_{n+m-1}, x_{n+m}) - a| < \varepsilon.$$

证明中值滤波器保留中点，即从滤波器输出的$x_n$获得的序列具有相同的中点$a$。

5. 我们会说序列$x_n$具有级别$a$，如果对于任何$\varepsilon>0$存在$M$，使得对于任何$n$和$m>M$

$$|x_{n-m}+x_{n-m+1}+\dots+x_n+\dots+x_{n+m-1}+x_{n+m}| - a| < \varepsilon.$$

a) 中值滤波器，b) 滑动条件是否能保持一致性水平？

或分析——谁赢了？还有于。涅斯特连科原来是这场纠纷的目击者。我的对手是热心的几何学家，我必须这么做。但我的对手仍然没有取得明显的胜利。我的书《关于最大值和最小值的故事》（图书馆«Kvant»，第 56 期，M.，Nauka，1986 年，第 134-139 页）对此进行了描述。然后（正如作者本人告诉我的）Yu。内斯特连科开始寻找一个问题，让几何幻想能够以明显的优势战胜分析的乏味。而他真的想出了这个办法！该问题在 1985 年第 19 届全联盟学童奥林匹克竞赛中提出。以下是其措辞。

给定一个立方体$ABCD_1B_1C_1D_1$，从第二面开始。让我们画两个圆：一个外接于由不相邻顶点$AB_1C$形成的三角形，另一个外接于面$ABCD$。需要找到这些圆之间的最小距离（图1）。

事实上 - 现在我们将看到这一点 - 它可以“用两个词”来解决，但找到它们是相当困难的（特别是在奥林匹克或考试的背景下）。我们将在文章末尾讨论这个有趣的话题，现在让我们继续讨论解决方案。

首先，亲语言的“两个词”。小圆位于半径为$\sqrt{2}$、圆心位于立方体中心的球面上，大圆位于半径为$\sqrt{3}$且同心的球面上，这意味着圆之间的最短距离不小于$\sqrt{3} - \sqrt{2}$。但是，顶点位于包含小圆的立方体中心的圆锥体的较大球体上的轨迹与大圆（图2）相交（这很容易理解），即不同圆上有两个点，它们之间的距离为$\sqrt{3} - \sqrt{2}$。

这意味着最小距离等于$\sqrt{3} - \sqrt{2}$！一切都已经被证明了。但是，考虑到进一步的比较，让我们更详细地描述这“两个词”。因此，我们提出两种解决方案供您考虑 - 几何解决方案和解析解决方案。为了让您更容易比较这些解决方案的“优点”和“缺点”，我们用方括号中的数字显示了每个解决方案的要点（“移动”、“步骤”-如您所愿）。如果某个举动对我们来说像是一种“洞察”，我们会将其放在数字旁边！ （甚至！！）。

很棒的红色解决方案，不是吗？如果你自己找到它，你会更喜欢它。奥赛上解决这个问题的人还不算少，五到十个人，而且都是这样解决的，几何级数。但我们前面有一条不同的道路。

但在继续讨论类似的解决方案之前，我必须向您介绍一种由拉格朗日发现的用于研究极值问题的非常重要的分析方法（我在上述书中用了很大一部分内容来介绍这种方法 - 请参阅当天的故事）。正是在拉格朗日的帮助下，我站出来在一定条件下连接变量$x, y, z$，$u$的部分类似的。例如，

$$f_1(x, y, z, u) = 0,$$
$$f_2(x, y, z, u) = 0,$$
其中$f_1$和$f_2$是函数数据。

然后（拉格朗日说）如果存在解，则可以使用以下方法找到解。

令$\lambda_0, \lambda_1$和$\lambda_2$是一些（我们还不知道的）数字，不全等于0。

考虑功能

$$L = \lambda_0 f_0 + \lambda_1 f_1 + \lambda_2 f_2.$$

令$L_x, L_y, L_z$和$L_u$为变量$x, y, z, u$中$L$的任意函数。然后，函数 $f_0$ 达到最小值（最大值）的点 $(x_0, y_0, z_0, u_0)$ 由方程组给出

$$\begin{cases} f_1(x, y, z, u) = 0, \\ f_2(x, y, z, u) = 0, \\ L_x = L_y = L_z = L_u = 0. \end{cases}$$

（请注意，这是一个包含 7 个未知数的 6 个方程组，从中可以找到数字 $x_0, y_0, z_0, u_0$ 和 $\lambda_0, \lambda_1, \lambda_2$。）

这个例子是通用的，技术上非常简单，并且对于它的应用来说，除了任意概念之外不需要任何东西。让我们用它来解决我们的问题。

解决方案二（分析）。

[1]。圆$O_2$表示为$x = \cos \varphi, y = \sin \varphi, z = -1, -\pi \leqslant \varphi \leqslant \pi$。

[2]。我们将圆$O_1$定义为球体$x^2 + y^2 + z^2 = 3$与平面$x - y + z = -1$的交点。

[3]。 Teler 的问题表述如下。求函数的最小值

$$f_0(x, y, z, \varphi) = (x - \cos \varphi)^2 + (y - \sin \varphi)^2 + (z + 1)^2$$

在条件下

$$f_1(x, y, z) = x - y + z + 1 = 0,$$
$$f_2(x, y, z) = x^2 + y^2 + z^2 - 3 = 0.$$

[4]。很容易理解，考虑扇区$-\frac{\pi}{2} \leqslant \varphi \leqslant \frac{\pi}{2}$就足够了。

[5]。让我们构造拉格朗日函数

$$L = \lambda_0 ((x - \cos \varphi)^2 + (y - \sin \varphi)^2 + (z + 1)^2) + \lambda_1 (x - y + z + 1) + \lambda_2 (x^2 + y^2 + z^2 - 3)$$

并计算其任意值：

$$L_\varphi = 2\lambda_0 ((x - \cos \varphi) \sin \varphi) - (y - \sin \varphi) \cos \varphi) = 0,$$

$$L_x = 2\lambda_0 (x - \cos \varphi) + \lambda_1 + 2\lambda_2 x = 0,$$

$$L_y = 2\lambda_0 (y - \sin \varphi) - \lambda_1 + 2\lambda_2 y = 0,$$

$$L_z = 2\lambda_0 (z + 1) + \lambda_1 + 2\lambda_2 z = 0.$$
