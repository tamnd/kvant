让我们绘制向量 $\vec{U}$ - 它将描绘 $C_x$ 处的电压。现在，您可以通过 $L$ 和 $C_x$（它们方向相反）绘制电流矢量以及总电流 $I_0$ - 它从源流经电容器 $C$。然后我们描绘 $C$ 处的电压矢量，最后描绘链路输入处的总电压矢量 - $C$ 和 $C_x$ 处的电压之和（当然，考虑到符号）。

现在来一点算术：
$$I_L = U / (\omega L), I_C_x = U \omega C_x, I_0 = U / (\omega L) - U \omega C_x, U_0 = I_0 / (\omega C) - U = I_0 / (\omega C_x).$$

整个电路的电压和电流幅值之间的关系与电容器$C_x$相同。从这里您可以找到$C_x$，只是更方便地将与其相关的电阻$X = 1 / (\omega C_x)$作为未知量进行距离。关于它，我们得到方程
$$X^2 - X / (\omega C) + L / C = 0,$$

在哪里
$$X = 1 / (2 \omega C) \pm \sqrt{1 / (4 \omega^2 C^2) - L / C} = 1 / (\omega C) (0,5 \pm \sqrt{0,25 - \omega^2 LC}),$$
$$X_1 = 1 / (1,25 \omega C), X_2 = 1 / (9 \omega C),$$
$$C_{x1} = 1,125 C, C_{x2} = 9 C.$$

可以看出，有两个答案是可能的——满足问题条件的两个电容值。当然，这个结果并不明显，需要验证。例如，您可以构建矢量图来获取特定值并确保一切都按顺序进行。我做到了并且确信了，也尝试一下。

还有一件事：由电阻器组成的无限目标具有非常特定的电阻 - 不可能有多个答案。
