M1229。证明对于每个自然数$m > 1$
a) $4^m + 5$;
b) $8^m + 9$;
c) $a^m + a + 1$，其中$a$是整数且不能被8整除；不是整数的平方。

除以4的余数
（奇数$m > 1$）：

| $a$ | $a^m$ | $N = a^m + a + 1$ |
| :--- | :--- | :--- |
| 1 | 1 | 3 |
| 2 | 0 | 3 |
| 3 | 3 | 3 |

由于$p - 1$和$p + 2$具有不同的奇偶性，因此这仅对于$p - 1 = 1$、$p = 2$是可能的，但是对于$p + 2 = 4$和$3m - 2 = 2$来说，这对于整数$m$是不可能的。

c) 这里，如果 $m$ 是偶数，则与 a) 中的想法相同：使用 k $a^m$ 找到数字 $N = a^m + a + 1$；对于奇数$m$，如第6点），处理除以2的幂时的余数就足够了。

首先让$m = 2r$。然后

$$a^{2r} < a^{2r} + a + 1 < a^{2r} + 2a^r + 1 = (a^r + 1)^2,$$

即 $a^{2r} + a + 1$ 不是正方形。

现在让$m = 2r + 1$。然后，考虑$a$除以4时各种可能的余数1、2、3，我们确信$N$除以4时得到余数3（参见页边空白中的表格），而对于$n = 8k + 4$，数字$N = (8k + 4)^m + 8k + 4 + 1$除以8时得到余数5。

但是平方除以 8 后只能得到余数 0、1 或 4。事实上，对于整个 $k$

$$(4k \pm 1)^2 = 16k^2 \pm 8k + 1, (4k \pm 2)^2 = 16k^2 \pm 8k + 4, (4k \pm 3)^2 = 16k^2 \pm 24k + 1, (4k)^2 = 16k^2.$$

请注意，对于$a$，方格8，问题的陈述并不总是正确的：例如，对于$a = 72$和$m = 3$，数字是$a^m + a + 1 = 611^2$。 （根据代数几何的一般定理，对于每个$m > 3$，方程$x^m + x + 1 = y^2$只有有限数量的整数解。）
