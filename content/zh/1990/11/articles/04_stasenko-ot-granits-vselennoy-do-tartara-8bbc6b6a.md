让我们来回答这个问题：根据我们现代的物理概念和他们对时间尺度的陈述，古希腊姿势可以得到什么样的宇宙大小的数值估计？
和他一样，研究范围也分为两个阶段：第一阶段——从天上到人间，持续$t_1=9$天；第二阶段——前往地狱，同样持续$t_2=9$天。 （当然，“天”这个词我们指的是“天”——铁砧不可能在白天下落而不沿着鼻子移动。）同时，我们必须记住最重要的事情——作用在铁砧上的力。在太空中，万有引力将占主导地位，而当浸入地球大气层时，还必须考虑空气阻力。此外，由于没有人会被问到塔耳塔洛斯位于哪里，我们会认为它位于地球的正中心（没有更远的地方），显然，必须以某种方式确保进入铁砧 - 例如，通过挖掘一个特殊的地雷，以节省公共资金，严格径向。所以，第一阶段是

从天上到地上

众所周知，作用在地球外部距离其中心 $r$ 的质量体 $m_H$ 上的引力等于

$$F = -G \frac{M_\oplus m_H}{r^2} = -m_H g_\oplus \frac{R^2_\oplus}{r^2},$$

其中$R_\oplus$是地球半径，$g_\oplus = \frac{GM_\oplus}{R^2_\oplus}$是地球表面的重力加速度。那么我们将物体移动一小段距离$dr > 0$必须做的功等于

$$dA = \frac{GM_\oplus m_H}{r^2} dr.$$

这意味着当从地球表面（$r = R_\oplus$）移动到“赫西奥德宇宙”（$r = R_\Gamma$）的边界时，我们必须做功

$$A = \int_{r=R_\oplus}^{R_\Gamma} \frac{GM_\oplus m_H}{r^2} dr = GM_\oplus m_H \left( \frac{1}{R_\oplus} - \frac{1}{R_\Gamma} \right).$$

如果现在让这个物体有机会从距离$r = R_\Gamma$自由落体到地球表面，那么我们消耗的所有能量都将转化为物体的动能。让我们这样写：

$$\frac{m_H v^2_\oplus}{2} - 0 = GM_\oplus m_H \left( \frac{1}{R_\oplus} - \frac{1}{R_\Gamma} \right).$$

（$v_\oplus$是物体在地球表面的速度，左边的零表示物体没有初速度。）

根据类似的推理，我们得出在任何距离$r < R_\Gamma$，能量守恒定律都可以写成以下形式

$$\frac{v^2(r)}{2} = GM_\oplus \left( \frac{1}{r} - \frac{1}{R_\Gamma} \right) = g_\oplus R^2_\oplus \left( \frac{1}{r} - \frac{1}{R_\Gamma} \right)$$

（我们减少了质量$m_H$）。所有这些都可以（尽管不一定）写成以下形式

$$\frac{v^2(r)}{2} + \varphi(r) = 0 + \varphi(R_\Gamma),$$

其中引入函数$\varphi(r) = -g_\oplus R^2_\oplus \frac{1}{r}$，称为势能，并考虑到初始速度$v_\Gamma = 0$。在这样的

动能和势能（每单位质量）之和的守恒定律已经完全清楚。

您还可以在 图 (图 1) 上描绘重力加速度 $g(r) = g_{\oplus} R^2_{\oplus}/r^2$ 和$r > R_{\oplus}$ 处的势能 $\varphi(r)$ 的依赖性；同样的图也显示了$r < R_{\oplus}$地球内部的变化——所有这些都是非常熟悉的图片，在«Kvant»中讨论过很多次（例如，参见第3-90号，第49页）。

因此，在地球之外的任意一点，铁砧从半径为 $G_{\text{есиода}} R_{\Gamma}$ 的“高度”自由落体将具有一定的速度

$$v(r) = v_{\text{II}} \sqrt{\frac{1}{r/R_{\oplus}} - \frac{1}{R_{\Gamma}/R_{\oplus}}} = -\frac{dr}{dt},$$

其中$v_{\text{II}} = \sqrt{2g_{\oplus} R_{\oplus}} = \sqrt{-2\varphi_{\oplus}}$是第二逃逸速度*。要确定距此处所需的距离 $R_{\Gamma}$，您需要能够进行积分

$$\frac{1}{v_{\text{II}}} \int_{r=R_{\Gamma}}^{R_{\oplus}} \frac{dr}{\sqrt{\frac{1}{r/R_{\oplus}} - \frac{1}{R_{\Gamma}/R_{\oplus}}}} = -t_1.$$ (1)

但是，您可以在不进行积分的情况下（如果它很无聊）进行一些粗略的估计。举例来说，众所周知，月球绕地球运行大约 28 天，同时落在地球上。 （记住：Newot 在这里看到了一个苹果掉落的类比。）因此，从点 $P$ 到点 $Q$ (图 2) 它将在 28/4 = 7 天后到达。也许这个数值接近赫西奥德对“九天”的估计并非没有道理？如果这其中有什么值得怀疑的话，那么“赫西奥德的宇宙”的大小应该与月球轨道半径相当（$\approx 380$千公里$\approx 60$$R_{\oplus}$）。

此外，我们的积分 (1) 可以写成无量纲形式，以所需半径 $R_{\Gamma}$ 的单位表示线性尺寸：

$$\left(\frac{R_{\Gamma}}{R_{\oplus}}\right)^{3/2} \int_{r=R_{\oplus}}^{R_{\Gamma}} \frac{\sqrt{r/R_{\Gamma}}}{\sqrt{1-r/R_{\Gamma}}} d\left(\frac{r}{R_{\Gamma}}\right) = \frac{v_{\text{II}} t_1}{R_{\oplus}}.$$ (2)

然后，用某个（无量纲！）量 $C$ 表示积分，我们得到

$$\left(\frac{R_{\Gamma}}{R_{\oplus}}\right)^{3/2} = \frac{v_{\text{II}} t_1}{CR_{\oplus}}.$$ (3)

由于$v_{\text{II}}/CR_{\oplus}$也是一个常数，这种以$R_{\Gamma}^3 \sim t_1^2$形式书写的对应关系已经很容易让人想起开普勒第三定律，即行星大条纹椭圆的立方与其绕太阳公转时间的平方的比例。无论如何，感觉我们都在围绕着同样的想法。代入(3) $v_{\text{II}} = 11,2 \cdot 10^3$ m/s, $t_1 = 9 \cdot 24 \cdot 3600$ s $7,8 \cdot 10^5$ s, $R_{\oplus} = 6,4 \cdot 10^6$ m，可得

$$\frac{R_{\Gamma}}{R_{\oplus}} = \frac{123}{C^{2/3}}.$$

如果我们假设（2）中的无量纲积分（用$C$表示）为一阶（这个君子协议在维度和相似性理论中总是被接受），那么我们可以说所需的半径比地球半径$R_{\Gamma} = 10^2 R_{\oplus}$大两个数量级，这与月球故事中的阶数相同。

想要进一步阐明赫西奥德宇宙的维度，就必须经历计算等式（2）中积分的过程。我们跟踪变量$r/R_{\Gamma} = \sin^2 \theta$的变化，则

$$\sqrt{1 - \frac{r}{R_{\Gamma}}} = \sqrt{1 - \sin^2 \theta} = \cos \theta,$$

$$\frac{dr}{R_{\Gamma}} = 2 \sin \theta \cos \theta d\theta,$$

然而，让铁砧飞得更远——

从地球表面到塔尔塔罗斯

这里一切都更加复杂。根据赫西奥德的说法，铁砧是如何进一步下落的？他知道存在作为抑制环境的存在吗？让我们尝试在赫西奥德本人的帮助下回答这个问题。

让我们考虑两种情况：

1) 作为所谓的塔尔塔罗斯入口的竖井中没有空气，根据我们的假设，塔尔塔罗斯距地球表面的距离不比其中心远。

因此，让物体在$t = 0$时刻飞过地球表面，进入一个延伸到其中心的轴。让我们写出仅在重力影响下物体的运动方程。在均质行星内，该力与距中心的距离 $F = -m_{\text{н}} g_{\oplus} r / R_{\oplus}$ 成正比，因此

$$m_{\text{н}} r'' = -m_{\text{н}} g_{\oplus} r / R_{\oplus},$$

或者

$$r'' + \frac{g_{\oplus}}{R_{\oplus}} r = 0 \quad (0 < r < R_{\oplus}).$$

这是频率为$\omega = \sqrt{g_{\oplus}/R_{\oplus}}$的简谐振动方程，其解为

$$r(t) = A \cos \omega t + B \sin \omega t$$

我们指定，我们学习初始条件：对于$t = 0$，我们有

$$r = R_{\oplus}, v(R_{\oplus}) = \frac{dr}{dt} \Bigg|_{t=C} = -v_{\Pi}.$$

我们得到

$$r(t) = R_{\oplus} \cos \omega t - \frac{v_{\Pi}}{\omega} \sin \omega t.$$

在地球中心$r = 0$的地方，身体会在$t = t_2$时间（坠落锻造的第二个时间段）后出现。

从这里我们得到

$$0 = R_{\oplus} \cos \omega t_2 - \frac{v_{\Pi}}{\omega} \sin \omega t_2,$$

$$tg \omega t_2 = \frac{R_{\oplus}}{v_{\Pi}} \omega = \frac{1}{\sqrt{2}},$$

$$t_2 = \frac{1}{\omega} \arctg \frac{1}{\sqrt{2}} = \sqrt{\frac{R_{\oplus}}{g_{\oplus}}} \arctg \frac{1}{\sqrt{2}}.$$

让我们记住这一点

$$g_{\oplus} = G \frac{M_{\oplus}}{R_{\oplus}^2} = G \frac{4}{3} \pi R_{\oplus}^3 \langle \rho \rangle = \frac{4}{3} \pi GR_{\oplus} \langle \rho \rangle,$$

其中$\langle \rho \rangle$是地球物质的平均密度，对于$t_2$我们得到

$$t_2 = \frac{1}{\sqrt{\langle \rho \rangle}} \sqrt{\frac{3}{4\pi G}} \arctg \frac{1}{\sqrt{2}}.$$

2) 还有空气。

然后，在运动方程 (4) 中，您需要写下空气阻力（除以砧的质量）而不是右侧的零 - 该力与空气密度、物体速度的平方及其尺寸（或横截面积 $S_\perp$）的平方成正比，并且还与阿基米德力成正比，该力可能是由于空气密度 $Q$ 随着深度不可避免地增加而增加的。我们得到

$$\frac{dv}{dt} + \frac{g_\oplus}{R_\oplus} r = \frac{\rho(r)v^2(r)S_\perp}{m_H} C_c + \frac{\rho(r)}{\rho^0} \frac{g_\oplus}{R_\oplus} r. \tag{5}$$

这里$\rho^0$是砧座的空气密度（$m_H = \rho^0 V_H$，$V_H$是其体积），还引入了无量纲阻力系数$C_c$，尽管它取决于许多参数，但具有单位量级的值。但即使它被认为是恒定的，一个重要的问题仍然存在：空气密度$\rho$如何取决于轴的深度$R_\oplus - r$（或距中心$r$的距离）？

众所周知，空气密度取决于距地球的高度$h = r - R_\oplus$，可以用玻尔兹曼气压公式来描述

$$\rho(h) = \rho_\oplus e^{-mgh/(kT)},$$

其中，$T$是大气温度（假设为常数），$m$是分子质量，$k$是玻尔兹曼常数，$\rho_\oplus \sim 1 \text{ кг/м}^3$是$\rho$在地球表面的值（“在海平面”；参见图3）。但是指数符号是什么意思呢？ - 这是两种能量值的比率：势能（海平面为零标记）$mgh$和分子热运动能量$kT$。假设我们制作一个具有相同温度$T$ ($T \sim 300$ K) 的墙壁的竖井，并且在某个深度，重力加速度可以被认为大约等于$g_\oplus$（实际上它会随着深度而死亡（参见图 1），但我们还不打算太深地平坦）。在这些假设下，式（5）是正确的。我们获得深度值 $h_* < 0$，在该深度值下空气将滚落至密度 $\rho_*$ 以至于其分子发生碰撞。能否称为液体是相态热力学的问题；为了谨慎起见（并非徒劳），我们将在标志中使用“液体”空气一词。我们假设这个密度 $\rho_*$ 与水的密度 ($\sim 10^3 \text{ кг/м}^3$) 相当。然后从(5)我们得到$\rho_* = \rho(h_*) = \rho_\oplus e^{-mg\phi/h/(kT)} \sim 10^3 \text{ кг/м}^3$，$h_* = \frac{kT}{mg_\oplus} \ln \frac{\rho_\oplus}{\rho_*} = \frac{RT}{M_g_\oplus} \ln \frac{\rho_\oplus}{\rho_*} = \frac{8,31 \cdot 300}{29 \cdot 10^{-3} \cdot 10} \ln 10^{-3} \text{ м} \approx -60 \cdot 10^3 \text{ м}$。

（显然，在这个深度（大约是地球半径的百分之一），重力加速度变化很小。）

它不会熔化，不会散架，不会燃烧（毕竟，这个铁砧，你必须想像，属于铁匠之神赫菲斯托斯），它会进一步进入空气越来越稠密的竖井，然后，从深度$h_*$开始（从$r_* = R_\oplus - h_*$开始），它几乎会在“液体”空气中移动。很明显，铁砧将在大约一秒的时间内穿过特征厚度约为10公里的大气层。再过几十（或几百？）秒，它将在矿井的凝结空气中移动，直到最后，几乎所有的动能都将被阻力的作用吸收。这种对铁砧“适应”新的运动条件（或者，正如他们在科学领域中所说的，松弛时间）的时间长度的示范性忽视，只是表明我们希望这段时间与$t_1$和$t_2$相比很短，并且我们不愿意浪费我们的精力和政府文件来证明这一点（然而，这并不是很困难）。

在重力、阿基米德力和空气阻力平衡的条件下，密度为$\rho_*$的“液态”空气中已经发生了进一步的运动，因此从方程（5）我们得到

$$\frac{\rho_* v^2(r) S_\perp C_c}{m_H} = \frac{g_\oplus}{R_\oplus} r \left(1 - \frac{\rho_*}{\rho^0}\right),$$

在哪里

$$v(r) = \sqrt{r} \frac{v_{\text{II}}}{R_\oplus \sqrt{2}} \sqrt{\frac{\rho^0}{\rho_*}} - 1 \sqrt{\frac{m_H}{\rho^0 S_\perp C_c}} = - \frac{dr}{dt},$$

因此

$$\int_0^t \frac{v_{\text{II}}}{R_\oplus \sqrt{2}} \sqrt{\frac{\rho^0}{\rho_*}} - 1 \sqrt{\frac{m_H}{\rho^0 S_\perp C_c}} dt = - \int_0^t \frac{dr}{\sqrt{r}}.$$

从这里我们得到铁砧“淹没”到地心的时间

$$t_2 = \frac{R_\oplus^{3/2} 2\sqrt{2}}{v_{\text{II}} \sqrt{\rho^0 / \rho_*} - 1 \sqrt{V_H / (S_\perp C_c)}}.$$

我们可以通过取 $ \rho^0 / \rho_* - 1 \sim 10, V_H / S_\perp \sim 1$ m, $C_c \sim 1$ 来估计这个数量的阶数；我们得到$ t_2 \sim 10^6$s，这很容易让人想起赫西奥德的“9天”。

当然，如果有计算机的话，也可以解方程（5）。对我们来说重要的是，古代诗人赫西奥德的话语让我们能够讨论几个物理概念，并表明位置和物理之间的距离并不遥远。
