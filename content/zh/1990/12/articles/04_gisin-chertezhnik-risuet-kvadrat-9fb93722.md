绘图员
画一个正方形

物理和数学科学候选人
五、GISIN

有时，计算机科学中看似非常简单的问题会导致有趣的数学问题。我们将考虑 A. P. Ershov (1988) 编辑的计算机科学教科书中的一个这样的问题。

首先，让我们回顾一下绘图员的描述 - 一种设计用于在坐标平面上绘制 图 的设备。绘图员有一支可以沿着平面移动的笔。如果笔落下，就会留下痕迹。绘图员可以执行4个命令：“抬笔”、“放下笔”、“移至点$(x; y)$”、“移至向量$(d_x; d_y)$”。绘图员命令中的点和向量的坐标以有限小数的形式写入。据信，在绘图员开始工作之前，平面是干净的，笔已抬起并位于坐标原点。要获得图，您需要向绘图员发出一系列命令。例如，如果您命令：

移动到点$(1; 1)$；放下笔；按向量 $(0; -2)$ 移位；按向量 $(-2; 0)$ 移位；按向量 $(0; 2)$ 移位；按向量 $(2; 0)$ 移位；举起笔

那么执行后，将从边 2 开始绘制一个正方形，并以原点为中心（§4 中的问题 1）。一个自然的问题出现了：绘图员能否绘制任何边长为 2、中心位于原点且与我们的正方形不重合的正方形？

显然，任何此类正方形的顶点坐标都以有限小数表示。相反，如果以原点为中心的正方形至少有一个顶点的坐标为有限小数（例如$(x; y)$），则其余顶点的坐标（即$(x; y)$、$(-y; x)$、$(-x; -y)$、$(y; -x)$）和所有边向量的坐标（即$(-x - y; x - y)$、 $(-x + y; -x - y)$, $(x + y; -x + y)$, $(x - y; x + y)$) - 图 1. 同样，如果四个向量中至少有一个具有有限的十进制坐标，则其余向量和所有顶点都具有有限的十进制坐标。因此，当且仅当其至少一个顶点或至少一个边向量的坐标是有限小数时，可以使用我们的绘图员构造一个以原点为中心的正方形。

我们不考虑向量，而是考虑一半向量会更方便。如果正方形的边长等于 2，那么它的一半就等于 1。因此，所有正方形都是我们问题的解

我们必须简单地找到 $a^2 + b^2 = 1$ 的所有 $(a; b)$ 有限小数对。另一种方法是找到以原点为圆心的单位圆上的所有点，这些点的坐标是有限小数。

四个这样的点立即可见：$(\pm 1; 0)$和$(0; \pm 1)$。但它们对应的是我们的广场。还有别的吗？是的，例如，$a = 0,6$、$b = 0,8$（或$a = \pm 0,6$、$b = \pm 0,8$、或$a = \pm 0,8$、$b = \pm 0,6$）。还有什么？正如简单的几何推理所示，还有更多。

我们圆上任意点的坐标是$(\cos \varphi; \sin \varphi)$，其中$\varphi$是$OX$轴的正方向与我们点的半径向量之间的角度，而不是逆时针。这意味着我们想要找到所有角度 $\varphi$ 以及 $\cos \varphi$ 和 $\sin \varphi$ 是有限小数。现在我们也有小数角了。

引理。如果$\varphi_1$和$\varphi_2$是小数角，则$\varphi_1 + \varphi_2$和$\varphi_1 - \varphi_2$也是小数角。

证明。从公式$\cos(\varphi_1 \pm \varphi_2) = \cos \varphi_1 \cos \varphi_2 - \sin \varphi_1 \sin \varphi_2$、$\sin(\varphi_1 \pm \varphi_2) = \sin \varphi_1 \cos \varphi_2 \pm \cos \varphi_1 \sin \varphi_2$可以立即清楚地看出这一点。

结果。如果 $\varphi_1$ 和 $\varphi_2$ 是小数角度，则 $k_1 \varphi_1 + k_2 \varphi_2$ 是任何整数 $k_1$ 和 $k_2$ 的小数角度。

点$(0,6; 0,8)$对应于角度$\varphi_0$，其中$\cos \varphi_0 = 0,6$、$\sin \varphi_0 = 0,8$。角度 $\varphi_0$ 是十进制。但根据已证明，$2\varphi_0$也是小数角。根据众所周知的公式$\cos 2\varphi_0 = 0,6^2 - 0,8^2 = -0,28$，$\sin 2\varphi_0 = 2 \cdot 0,6 \cdot 0,8 = 0,96$。因此，这是圆点的另一种方法：$(-0,28; 0,96)$。或者你可以拿$(0,28; 0,96)$，一般来说$(\pm 0,28; \pm 0,96)$或$(\pm 0,96; \pm 0,28)$。您还可以取$3\varphi_0$，$4\varphi_0$，...然后我们不要忘记点$(\pm 1; 0)$和$(0; \pm 1)$。它们对应于角度$0, \frac{\pi}{2}, \pi, \frac{3\pi}{2}$，即角度$\frac{l\pi}{2}$和$l = 0,1,2,3$。这意味着我们知道十进制角度的质量：这些都是角度

$k\varphi_0 + \frac{l\pi}{2}$ (*)

具有任何整数$k$和$l = 0,1,2,3$（您可以说“具有任何整数$l$”，但如果$l$更改为4，角度将更改为$2\pi$，即它将给出相同的旋转）。但也许这还不是全部？不，仅此而已。我们还将考虑该定理。

定理1.所有小数角都是(*)形式，并且所有角(*)($c l = 0,1,2,3$)都是不同的。

稍后我们将证明这个定理。现在让我们注意，我们的绘图员可以构建的正方形是通过围绕原点旋转十进制角度 $\varphi$ 从统计数据开头描述的正方形获得的。 图2 显示由原始正方形和旋转正方形的边中点形成的正方形。从原点到顶点的单位向量是十分之一。此外，由于将矢量旋转角度 $\pi/2$ 会将每个正方形变换为其自身，因此以下定理被证明是正确的。

定理 2. 边长为 2、中心位于原点的正方形（可以使用绘图员构造）是从第一个类似正方形通过向一个方向或另一个方向旋转角度 $\varphi_0, 2\varphi_0, 3\varphi_0$ 获得的正方形，...所有这些正方形都是不同的。

（回想一下，旋转角度 - φ 是沿相反方向旋转角度 φ。）
现在我们从绘图问题转向定理 1 的证明。
定理1的证明。
令$\alpha$为小数角，$\cos \alpha = A/10^n$、$\sin \alpha = B/10^n$，其中$A$和$B$为整数。然后
$$\left(\frac{A}{10^n}\right)^2 + \left(\frac{B}{10^n}\right)^2 = 1, A^2 + B^2 = (10^n)^2 = 10^{2n}.$$
让我们用$C$表示数字$A, B$和$10^n$的最公约数并设置$a = A/C, b = B/C$；我们有：
$$a^2 + b^2 = (10^n/C)^2.$$
数字$10^n/C$必须是奇数，这意味着它是五的幂。事实上，如果$10^n/C$是偶数，那么$a$和$b$不能都是偶数；但如果其中一个是偶数，另一个是奇数，那么和$a^2 + b^2$是奇数，$10^n/C$也是奇数，但如果$a$和$b$都是奇数，那么$a^2$和$b^2$除以4时余数为1，这与数字$(10^n/C)^2$是偶数的事实相反能被4整除。
所以我们必须用整数解方程
$$a^2 + b^2 = 5^{2m}.$$
我们的目标是证明这些解决方案对于以下内容是详尽无遗的：
$$a = 5^m \cos \alpha, b = 5^m \sin \alpha,$$
其中$\alpha = k \varphi_0 + \frac{l \pi}{2}$（并且$m$是整数，使得$a$和$b$是整数）。换句话说，
$$a = 5^m \cos \left(k \varphi_0 + \frac{l \pi}{2}\right) = \left\{ \begin{array}{l} \text{или } \pm 5^m \cos \left(\pm k \varphi_0\right), \\ \text{или } \pm 5^m \sin \left(\pm k \varphi_0\right) \end{array} \right.$$
$b$ 也类似。
让我们假设对于 $m < m_0$ 方程的所有整数解都具有指定的形式。让我们求解方程 $a, b$
$$a^2 + b^2 = 5^{2m}.$$
我们可以假设 $a$ 和 $b$ 不是 de-
能被 5 整除（如果 $a$ 能被 5 整除，那么 $b$ 也能被 5 整除，然后 $a' = a/5, b' = b/5$ 是一个类似方程的解，其中 $5^{2(m-1)}$ 而不是 $5^{2m}$，并且通过假设它具有所需的形式）。让我们以 $a = 5^m \cdot \cos \alpha, b = 5^m \cdot \sin \alpha$ 的形式写出我们的解决方案，并考虑数字 $3a + 4b, 3a - 4b$。他们的乘积 $9a^2 - 16b^2 = 9(a^2 + b^2) - 25b^2 = 9 \cdot 5^{2m} - 25b^2$ 能被 $5^2$ 整除，但不能被 $5^3$ 整除；它们的和 $6a$ 不能被 5 整除。这意味着这些数字之一（用 $3a + 4b$ 来确定）可以被 $5^2$ 整除。让我们输入$a' = \frac{3a + 4b}{5^2}$。这是一个不能被 5 整除的整数。我们还输入 $b' = a + b - 7a' = \frac{4a - 3b}{5^2}$。然后
$$(a')^2 + (b')^2 = \frac{9a^2 + 12ab + 16b^2 + 16a^2 - 12ab + 9b^2}{5^4} = \frac{25(a^2 + b^2)}{5^4} = 5^{2m+2-4} = 5^{2(m-1)}.$$
这意味着 $a'$, $b'$ 是我们类型方程的解，其中 $5^{2(m-1)}$ 而不是 $5^{2m}$，即
$$a' = 5^{m-1} \cos \beta, b' = 5^{m-1} \sin \beta,$$
其中 $\beta$ 的形式为 $q \varphi_0 + \frac{r \pi}{2}, r = 0, 1, 2, 3.$
但同时
$$a' = \frac{3a + 4b}{5^2} = 5^{m-1} \cdot \left(\frac{3}{5} \cos \alpha + \frac{4}{5} \sin \alpha\right) = 5^{m-1} (\cos \varphi_0 \cos \alpha + \sin \varphi_0 \sin \alpha) = 5^{m-1} \cos (\alpha - \varphi_0)$$
并且，类似地，
$$b' = 5^{m-1} \sin (\alpha - \varphi_0).$$
这意味着$\beta = \alpha - \varphi_0, \alpha = \beta + \varphi_0$，我们的解也具有所需的形式。定理已被证明。
