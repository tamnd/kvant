（1905-1988），总结了迅速发展的理论。三十年代，学校俱乐部在这里开始流行。面向小学生的通俗文学出现了。让我们列出杰出科学家的名字：Lazar Aronovich Lyusternik（1899-1981）和 Lev Genrikhovich Shnirelman（1905-1938），他们致力于凸几何的文章和流行小册子，我们还要提到机械和数学学生 David Shklyarsky，他在圆活动中做出了革命。他的圈子不是建立在报告上，而是建立在问题的解决方案上，其中许多问题都来自凸几何。尽管看起来很奇怪，闵可夫斯基创建凸集理论的动机是数论。读者可以阅读«Kvant»中的文章[6]，其中明可夫斯基利用凸性性质证明了素数只有在除以四时余数为一的情况下才能表示为两个平方和的说法（数论第一个显着定理之一）。

双极定理的证明基本上包含了闵可夫斯基定理所包含的思想。双极定理的证明（定理 2）。根据闵可夫斯基定理，凸闭集 C 与包含它的半平面的交点重合。因此，如果C包含原点，并且半平面包含C，则半平面也必须包含原点。所有包含原点的半平面都分为两种重要类型。 1. 边界线上不包含原点的半平面。在这种情况下，边界线可以由等式 px + qy = 1 给出（适当选择 p 和 q），半平面本身由不等式 px qy d 1 给出。 2. 包含边界线上原点的半平面。在这种情况下，边界线可以由等式 px + qy = 0 给出（适当选择 p 和 q），半平面本身由不等式 px qy d 0 给出。因此，极坐标 C q 正是包含 C 的第一类型的所有半平面的集合。根据定义，

双极性是集合 C qq ^ x； y：对于所有 p，px qy d 1； q C q `.因此，双极 C qq 包含这样的点 x； y，位于 C 的第一种类型的每个半平面中。每个这样的半平面都包含 C。因此，C C qq 。然而，形式上，等式 C = C qq 尚未得到证明，因为根据闵可夫斯基定理，集合 C 与包含它的所有半平面的交集重合，并且双极 C qq 是仅第一类型半平面的交集。然而，如果不使用第二种类型的半平面，我们就没有获得任何新点。事实上，如果点x； y 不在C 中，那么它可以与C 严格分离，并且分界线不能包含坐标原点，因为它位于C 中。因此，C = C qq 。相反的陈述 - 如果 C = C qq，则集合 C 是凸且闭的 - 可以非常简单地证明。事实上，双极是集合 D = C q 的极坐标，因此是凸且闭的。
