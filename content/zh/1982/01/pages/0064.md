选项1

1. 众所周知，当两个物体碰撞时，当物体在碰撞后以相同的速度移动时，它们运动动能的最大损失发生在绝对非弹性碰撞期间。这部分动能可以转化为其他类型的能量，特别是可以用来激发其中一个钢原子。随后，当原子从激发态跃迁到基态时，可以发射光子。当电子从第一能级移动到第二能级（$n=1$，$m=2$）时，达到基态原子的最小激发能$E_{\text{min}}$。例如，从中移除电子所需的感应能量原子对应于从第一能级到无限远能级（$n=1$，$m \to \infty$）的跃迁。因此，从问题条件可知，辐射频率公式中的常数$R$等于感应能$E_{\text{in}}$除以普朗克常数$h$，最小激发能量原子等于

$$E_{\text{min}} = hR \left(1 - \frac{1}{2^2}\right) = \frac{3}{4} E_{\text{in}}.$$

现在，根据能量和动量守恒定律，我们可以得到入射氢原子的最小动能$mv_0^2/2$：

$$\frac{mv_0^2}{2} = 2 \frac{mv^2}{2} + E_{\text{min}},$$

$$mv_0 = 2mv,$$

在哪里

$$\frac{mv_0^2}{2} = 2E_{\text{min}} = \frac{3}{2} E_{\text{in}} = 20, 4 \text{эВ}.$$

在解决这个问题时，许多科学家犯了一个典型的错误，即原子感应能的物理意义难以理解，他们认为原子感应能是原子激发的最小能量。其他人在正确找到激发能的最小值后，没有考虑动量守恒定律，认为碰撞过程中入射原子的所有动能都转化为激发能，然后辐射出去。

2. 平衡条件是第一容器和第二容器中的氢气分压相等。令 $p$ 为第一个容器中的初始压力。它由凝胶和氢气的分压组成。由于气体的质量和温度相同，因此凝胶和氢气的压力比与其摩尔质量成反比。因此，

$$p_{\text{He}} + p_{\text{H}_2} = p,$$

$$\frac{p_{\text{He}}}{p_{\text{H}_2}} = \frac{\mu_{\text{H}_2}}{\mu_{\text{He}}} = \frac{1}{2},$$

在哪里

$$p_{\text{He}} = \frac{p}{3}, p_{\text{H}_2} = \frac{2p}{3}.$$

为了使第一个容器中的总压力为初始压力的一半，氢气的分压必须降低到值$p'_{\text{H}_2} = p/6$。由于氢气的压力与其所占的体积成反比，我们得到

$$\frac{p_{\text{H}_2}}{p'_{\text{H}_2}} = \frac{V_1 + V_2}{V_1}, \text{ и } \frac{V_2}{V_1} = 3.$$

该状态的多混合吸收器的特征错误在于他们认为第二容器中的氢气与第一容器中的氢气和凝胶相等是平衡条件。

3. 一般情况下，电容器极板之间的相互作用力由其中一个极板的强场与另一极板的电荷的乘积决定。

在没有电介质的情况下，电容器中的场为$E_1 = U/d$，其极板上的电荷为$q_1 = \varepsilon_0 US/d$，其中$d$是极板之间的距离，$S$是极板面积，$\varepsilon_0$是电常数。考虑到一个板的磁场是电容器中磁场的一半，对于板之间的相互作用力，我们得到

$$F_1 = \frac{q_1 E_1}{2} = \frac{\varepsilon_0 SU^2}{2d^2}.$$

添加电介质后，得到的电容器可以认为是两个串联的电容器，其中一个电容器充满了食物容量为$\varepsilon$的电介质，并且两者极板之间的距离等于$d/2$。由于电压保持恒定，改变电容会导致极板上电荷的变化，进而改变电容器中的场。所得电容器的容量为 $C_2 = 2\varepsilon_0 S/d$ ($1 + \varepsilon$)（这是根据等式$1/C_2 = d/2 \varepsilon_0 S + d/2 \varepsilon_0 S$得出的）；对电容器$q_2 = UC_2 = 2\varepsilon_0 SU/d$ ($1 + \varepsilon$) 充电；字段$E_2 = q_2/S\varepsilon_0 = 2\varepsilon U/d$（$1 + \varepsilon$）；相互作用力

$$F_2 = \frac{Q_2 E_2}{2} = \frac{2\varepsilon_0^2 SU^2}{d^2(1 + \varepsilon)^2}.$$

力量关系

$$\frac{F_2}{F_1} = \frac{4\varepsilon^2}{(1 + \varepsilon)^2} = 2,25.$$

许多申请人错误地将极板相互作用计算为两个精确电荷的相互作用。有些人还认为，当添加电介质时，板附近的场不会改变。
