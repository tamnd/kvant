⟦folio 14⟧

除了确定 $|x| \leq 1$ 的多项式 $T_n$ 和 $U_n$ 值的三角公式 $2^\circ$ 之外，对于 $|x| > 1$，还有看起来完全不同的恒等式：

$$3^\circ. \quad T_n(x) = \frac{(x + \sqrt{x^2 - 1})^n + (x - \sqrt{x^2 - 1})^n}{2},$$

$$U_n(x) = \frac{(x + \sqrt{x^2 - 1})^{n+1} - (x - \sqrt{x^2 - 1})^{n+1}}{\sqrt{x^2 - 1}}.$$

多项式 $T_n$ 和 $U_n$ 的根可从以下一对恒等式中看出：

$$4^\circ. \quad T_n(x) = 2^{n-1} \left( x - \cos \frac{\pi}{2n} \right) \left( x - \cos \frac{3\pi}{2n} \right) \dots \left( x - \cos \frac{(2n-1)\pi}{2n} \right),$$

$$U_n(x) = 2^n \left( x - \cos \frac{\pi}{n+1} \right) \left( x - \cos \frac{2\pi}{n+1} \right) \dots \left( x - \cos \frac{n\pi}{n+1} \right).$$

因此，多项式$T_n(x)$的根和极值点是直径为$[-1; 1]$的直角$4n$边形的顶点除以该直径（图1）的投影。

下面我们将与其他人一起证明对应关系 $2^\circ - 4^\circ$ 并使用他们的例子说明代数变换的一些重要方法。

上面写的任何一个公式都可以作为切比雪夫多项式的定义，但我们更方便地将其基于它们之间的简单循环关系（如表 1 的标题中所述），并从中推导出所有公式。

下面我们建议通过改变尺度来处理从$T_n$和$U_n$获得的多项式（参见图1）：$P_n(x) = U_n(x/2)$，$Q_n(x) = 2T_n(x/2)$；段 $[-1; 1]$ 在 $T_n$ 和 $U_n$ 中扮演的角色现在将由段 $[-2; 2]$ 扮演。新多项式的好处是它们具有整数系数，并且它们的首项系数等于 1。（当然，以“反向”形式重写的转换公式：$P_n(2x) = U_n(x)$、$Q_n(2x) = 2T_n(x)$，允许我们随时返回到多项式$U_n$和$T_n$。）通常，我们将证明以下内容： $P_n$，向读者提供$Q_n$的类似性质作为练习。我们敦促他用铅笔和纸武装自己，详细地进行所有计算，首先计算特定的小值​​$n = 2, 3, 4, \dots$（直到一切变得清晰）。

递归关系和归纳

让我们把 $P_0(x) = 1$、$P_1(x) = x$ 和

$$P_{n+1}(x) = x \cdot P_n(x) - P_{n-1}(x).$$

(1)

让我们写下这个序列的前几项。以下$P_0(x) = 1$和$P_1(x) = x$是

$$P_2(x) = x^2 - 1,$$

$$P_3(x) = x(x^2 - 1) - x = x^3 - 2x,$$

$$P_4(x) = x(x^3 - 2x) - (x^2 - 1) = x^4 - 3x^2 + 1,$$

$$P_5(x) = x(x^4 - 3x^2 + 1) - (x^3 - 2x) = x^5 - 4x^3 + 3x$$

等等（对于 $P_{12}$ 以内的多项式，您可以查看表 2 中的结果）。

多项式$P_n(x)$出现在不同的情况下。例如，考虑分数

$$R_1(x) = x, \quad R_2(x) = x - \frac{1}{x}, \quad R_3(x) = x - \frac{1}{x - \frac{1}{x}},$$

$$R_4(x) = x - \frac{1}{x - \frac{1}{x}}, \quad R_5(x) = x - \frac{1}{x - \frac{1}{x}}, \dots$$
