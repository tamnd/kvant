由弹簧的弹力决定，即
$$kx = \frac{U_x^2 \varepsilon_0 S}{2(d-x)^2}.$$
从这里我们找到$U_x^2$：
$$U_x^2 = \frac{2k}{\varepsilon_0 S} x (d-x)^2.$$
显然，最大值$U_{\max}$对应于函数$f(x) = x(x-d)^2$的最大值。函数$f(x) = x(d-x)^2$的图形如图2所示。我们来找出最大值对应的值$x$：
$$f'(x) = 3x^2 - 4dx + d^2 = 0,$$
$$x_1 = d$$对应$f(x)$的最小值，$x_2 = \frac{d}{3}$对应$f_{\max}(x) = \frac{4}{27} d^3$的最大值。
因此，
$$U_{\max}^2 = \frac{8kd^3}{27\varepsilon_0 S}, \quad |U_{\max}| = \frac{2d}{3} \sqrt{\frac{2kd}{3\varepsilon_0 S}}.$$
D·巴甫洛夫

F697。在折射率为 $n_0 > 1$ 和 $n_1 = 1$ 的两种介质之间，存在一个高度为 $h = H \left(1 - \frac{1}{n_0^2}\right)$ 的不均匀层，其中 $H = \text{const}$，其中折射率根据定律 $n = n_0 \sqrt{1 - \frac{y}{H}}$ 随高度变化（参见 图）。光束从折射率$n_0$的介质进入非均匀层。在 el $a_0$ 的值是多少时，光束的入口点和出口点之间的距离最大？

根据光折射定律，随着介质折射率的变化，光束偏离法线的角度 φ 也会发生变化（到具有不同 $n$ 值的介质截面条件之间的界面），并且
$$n \sin \varphi = n \cos \alpha = n_0 \sin \varphi_0 = n_0 \cos \alpha_0 = \text{const}, \quad \text{где } \alpha = \frac{\pi}{2} - \varphi$$
为了求非均匀介质中射线的轨迹，我们可以用以下类比：一个质量为$m$（物体的尺寸极小）的物体沿着射线的轨迹运动，物体在纵坐标$y$处的速度等于$v(y) = v_0 n_y$（$v_0$是物体在纵坐标0处的初速度值）。然后，界面上的速度投影（水平投影）保持恒定。如果同时有一个恒定的力 $F = \frac{mv_0^2}{2H}$ 作用在该点上，垂直指向轨迹的任意点
$$\frac{m(v(y))^2}{2} = \frac{mv_0^2}{2} - m \frac{v_0^2}{2H} y.$$
可以看出，对于给定的变化规律$n(y)$，光线的轨迹与与地平线成一定角度抛出并在“重力”$F = mv_0^2/2H$影响下移动的物体的轨迹一致。因此，为了回答问题中提出的问题，我们可以使用此类运动的公式，并考虑到我们案例中的“自由落体加速度”等于“g”=$v_0^2/2H$。
因此，如果光束以角度 $\varphi_0 = 45^\circ$ 进入非均匀介质，光束的入口点和出口点之间的距离 $l$ 将最大。同时
$$I_{\max} = \frac{2vA_0^2 \sin \alpha_0 \cos \alpha_0}{v_0^2/2H} = 2H$$（自 $\alpha_0 = \frac{\pi}{2} - \varphi_0 = 45^\circ$ 起）。
为了使光束不进入$\alpha_0 = 45^\circ$处的上部均匀介质，非均匀区域的高度$h$必须满足条件$h \geq \frac{H}{2}$。否则($h < \frac{H}{2}$)，光束的入口点和出口点之间的最大距离对应于角度$\alpha'$，在该角度上轨迹的高度等于$h'$，即轨迹接触界面的上边界。这个角度$\alpha'$是从条件中找到的
$$n_0 \cos \alpha' = n(y = h') \cos 0^\circ = n_0 \sqrt{1 - \frac{h'}{H}};$$
$$\cos \alpha' = \sqrt{1 - \frac{h'}{H}}.$$
P·卡卢埃尼
