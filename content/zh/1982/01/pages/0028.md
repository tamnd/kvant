问题解决方案

M681 — M685; F692 — F697

让我们立即提出问题 6）的解决方案，按照 W. Sierpinski（大量此类问题包含在他的《初等数论》一书中）：让我们构造一个自然数的无限序列 $(a_n)$，使得对于任何 $n$，其前 $n$ 项的平方和是奇数的平方。我们取$a_1=3, a_2=4$；如果前 $n$ 成员已被选中并且

$$a_1^2 + a_2^2 + \ldots + a_n^2 = (2k+1)^2,$$

让我们输入$a_{n+1}=2k^2+2k$。从点

$$(2k+1)^2 + (2k^2+2k)^2 = (2k^2+2k+1)^2$$

我们明白了

$$a_1^2 + a_2^2 + \ldots + a_n^2 + a_{n+1}^2 = (2k^2+2k+1)^2$$

- 又是奇数的平方。

该序列的前五项是 3, 4, 12, 84, 3612：

$$3^2 + 4^2 = 5^2, 3^2 + 4^2 + 12^2 = 13^2,$$

$$3^2 + 4^2 + 12^2 + 84^2 = 85^2,$$

$$3^2 + 4^2 + 12^2 + 84^2 + 3612^2 = 3613^2.$$

问题的解决也隐含着余信中所指出的一个事实。来自列宁格勒的马卡洛夫：对于任何$n$，都有$\frac{n(n+1)}{2}$自然数$a_1, a_2, \ldots, a_{\frac{n(n+1)}{2}}$，使得

$$a_1^2 = a_2^2 + a_3^2 = a_4^2 + a_5^2 + a_6^2 = \ldots = a_{\frac{n(n-1)}{2}}^2 + 1 + \ldots + a_{\frac{n(n+1)}{2}}^2$$

我们和这封信的作者一样，不知道是否所有的数字$a_1, a_2, \ldots, a_{\frac{n(n+1)}{2}}$都可以不同。

N·瓦西里耶夫

M682。在三角形$\Delta$内，您需要放置三角形$\Delta_1$，以便在三角形$\Delta_1$的边上构建的三个正方形中的每一个都有两个顶点位于三角形$\Delta$的不同边上（图1）。

a) 证明三角形$\Delta$的中线垂直于三角形$\Delta_1$的边。

b) 任何人都可以建造吗？

a) 容易看出，从三个头部三角形（参见图 1），借助将三角形$\Delta_1$的顶点转移到某个点$O$的三个平行平移，可以构造一个三角形$\Delta$，类似于原始三角形$\Delta$（图2）。连接三角形$\Delta$顶点与点$O$的线段将三角形$\Delta$分成三个相等的三角形，每个三角形的面积等于三角形$\Delta_1$的面积。因此，$O$是三角形$\Delta$中线的交点（$O$到三角形$\Delta_1$任意边的距离）。
