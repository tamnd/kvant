切比雪夫多项式和递推关系

人们普遍认为数学家是一个不断从事最复杂算术计算的人（在更复杂的版本中，写出并转换长度和复杂的公式）。读者«Kvant»深知“没有公式”的数学是美丽而重要的；这种观点仍然有其道理。从必要的角度看待公式、改造它们、发现新公式以及找到它们之间的联系的能力是数学家工作的重要组成部分。在本文中，我们将研究一些与“切比雪夫多项式”序列含义相关的有趣公式（其中一些公式在 ���题 M488 - «Kvant»，1978 年，第 2 期中被提议证明），以及它们背后的一般数学思想。

介绍。两个显着的多项式序列

将要讨论的多项式存在于分析、计算数学和代数的许多问题中。它们出现在 1854 年俄罗斯数学家 Pafnutya Lvovich Chebyshev 与这个问题相关的著作中。

考虑给定次数 $n$ 且首项系数为 1 的所有可能多项式；其中哪一个在线段 $[-1; 1]$ 上偏离零最少，即对于每个多项式 $F_n(x) = x^n + \dots$ 的数量

$$c_n = \max_{[-1; 1]} |F_n(x)|$$

最小的？

事实证明，这是 $\bar{T}_n(x) = \frac{1}{2^{n-1}} T_n(x)$ - 表 1 左列的多项式除以首项系数。例如，在平方三项式中，它是$x^2 - \frac{1}{2}$（它与零的偏差$c_2$等于$\frac{1}{2}$，对于任何其他平方三项式$x^2 + px + q$，它都更大）；在三次多项式中，它是$x^3 - \frac{3}{4} x$（对于它$c_3 = \frac{1}{4}$）；一般来说，多项式 $\bar{T}_n(x)$ 与零 $c_n = \frac{1}{2^{n-1}}$ 的偏差小于任何其他 $n.*$ 次多项式 $F_n(x) = x^n + \dots$ 的偏差。

生成函数、级数幂和系数

在本节中，我们将向您介绍一种非常富有成效的方法，广泛应用于数学的各个分支——分析、组合学、概率论——生成函数的方法。这种方法有时允许您将序列的各个成员（如“砖块”）组装成一个完整的“建筑物”，并立即获取有关整个序列的信息。

让我们得到序列$a_0, a_1, a_2, \dots$。让我们给出它的生成函数表达式

$$f(z) = a_0 + a_1z + a_2z^2 + \dots = \sum_{n \ge 0} a_nz^n.$$

这种数学表达式称为级数的公式幂。这些级数可以像一般多项式一样进行加法、减法和变量操作，一个级数可以除以另一个级数（如果除数级数的自由项不为 0），任何级数都可以逐项微分和积分 - 所有这些运算都可以使用，

⟦folio 18⟧

从已经研究的序列中获得新的序列。通常可以从定义序列的递推关系中找到其生成函数的简单公式，并从生成函数中提取序列项的公式或关系。

对于有限序列 $a_0, a_1, a_2, \dots, a_n$，生成函数是多项式 $f(z) = a_0 + a_1z + \dots + a_nz^n$。例如，多项式 $f_n(z) = (1+z)^n$ 用作 biompaul 系数 $C_n^0, C_n^1, \dots, C_n^n$（帕斯卡三角形第 $n$ 行的项）的生成函数（表 2）：

$$\sum_{0 < k < n} C_n^k z^n = (1+z)^n.$$ (6)

对这个恒等式微分$k$次，然后代入$z=0$，我们找到$C_n^k = n(n-1) \dots (n-k+1)/1 \cdot 2 \cdot \dots \cdot k$。

打开括号并隔离下一个恒等式$(1+z)(1+z)^n = (1+z)^{n+1}$中$z^m$的系数，写成以下形式

$$(1+z) \left( \sum_{0 < k < n} C_n^k z^k \right) = \sum_{0 < k < n+1} C_{n+1}^k z^k,$$

我们得到了重要的关系$C_n^m + C_n^{m-1} = C_{n+1}^m$。

无限序列的平均值有一个特别简单、容易“崩溃”的函数，可以产生几何级数$b_0=b, b_n=qb_{n-1}$。将每个$b_n$的总$f(z) = \sum_{n>0} b_n z^n = b + \sum_{n>1} b_n z^n$替换为$qb_{n-1}$，我们得到$f(z) = b + qz \sum_{n>1} b_{n-1} z^{n-1} = b + qzf(z)$，由此得到$f(z)(1-qz) = b$，即

$$f(z) = \sum_{n>0} b_n z = \frac{b}{1-qz}.$$ (7)

当然，这是一个众所周知的无限几何级数（在$|qz|<1$）的总和公式。但使用相同的技术，我们也可以获得多项式序列$P_n(x)$的生成函数。

让我们输入$\Phi(z) = \sum_{n>0} P_n(x) z^n = 1+xz+\sum_{n>2} P_n(x) z^n$。 （这里$x$起到了参数的作用，下面为了简洁起见，我们将$P_n(x), P_{n-1}(x), \dots$合写为$P_n, P_{n-1}, \dots$。）根据（1），我们将$n \geqslant 2$处的每个$P_n$替换为$xP_{n-1}-P_{n-2}$。然后

$$\Phi(z) = 1+xz + \sum_{n>2} xP_{n-1} z^n - \sum_{n>2} P_{n-2} z^n =$$

$$= 1+xz+xz \cdot \sum_{n>2} P_{n-1} z^{n-1} - z^2 \cdot \sum_{n>2} P_{n-2} z^{n-2} =$$

$$= 1+xz+xz(\Phi(z)-1)-z^2\Phi(z).$$

因此，$\Phi(z) \cdot (z^2-xz+1) = 1$ 和

$$\Phi(z) = \frac{1}{z^2-xz+1}.$$ (8)

这个简单的公式隐藏了我们迄今为止一直在研究的所有棘手的多项式$P_n$序列！我们将通过两种不同的方式“拉出”隐藏在其中的个体$P_n$。

1) 对于 $|x|>2$，二次方程 $z^2-xz+1=0$ 有两个根：

$$u = \frac{x+\sqrt{x^2-4}}{2}, \quad v = \frac{x-\sqrt{x^2-4}}{2}.$$ (9)

从$z^2-xz+1=(z-u)(z-v)$，考虑到$uv=1$，我们得到

⟦folio 19⟧

$$\Phi(z) = \frac{1}{(u-z)(v-z)} = \left( \frac{1}{v-z} - \frac{1}{u-z} \right) \frac{1}{u-v} = \left( \frac{u}{1-zu} - \frac{v}{1-zw} \right) \frac{1}{u-v} = \sum_{n \geq 0} \frac{u^{n+1}-v^{n+1}}{u-v} z^n,$$

即$P_n(x) = \left( u^{n+1}-v^{n+1} \right) / (u-v)$；这就是式（3）。

2) 让我们从 (8) 中找到每个多项式 $P_n(x)$ 的各个系数。这是这样完成的：

$$\Phi(z) = \frac{1}{1-(xz-z^2)} = \sum_{k>0} \left( xz-z^2 \right)^k = \sum_{k>0} \left( \sum_{0<j<k} (-1)^j C_k^j x^{k-j} z^{k+j} \right) = \sum_{n>0} z^n \left( \sum_{j} (-1)^j C_{n-j}^j \cdot x^{n-2j} \right)$$

（我们使用无限几何级数之和的公式 (7)、牛顿生物群系 (6) 并确定了 $z^n$ 的系数，这就是我们需要的 $P_n(x)$）。因此，

$$P_n(x) = \sum_{j} (-1)^j C_{n-j}^j x^{n-2j}$$

（例如：$P_6(x) = C_6^0 x^6 - C_5^1 x^4 + C_4^2 x^2 - C_3^3 = x^6 - 5x^4 + 6x^2 - 1$）。

当然，可以在没有任意函数的情况下证明现成的公式（3）和（10） - 最引人注目的是它们是如何从简短的公式（8）中几乎自行产生的。

我们执行的所有无限级数运算的合理性（当然是必要的）可以通过以下方式进行检查：如果需要，根据数值$z$的模型，所考虑的所有级数都收敛（如$|z| < 1/|q|$的（7）），也就是说，它们代表$z$的实函数，或者通过检查某些公式化的运算加法、乘法等。（级数的每个系数表示为有限数量的其他，并且 $z$ 只是一个字母！）所有通常的定律都得到满足。您可以在书籍[3]、[4]、[6]中了解更多关于任意函数和幂级数的方法。
