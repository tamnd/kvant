具有非线性元件的电路

计算任何电路时，主要任务是确定电路所有部分的电流和电压。各段电流与电压的关系称为该段的电流电压特性。一方面，它是由在电场影响下物质中电荷运动过程中发生的物理过程引起的，另一方面是由电路本身的设计（即其元件的连接）引起的。

例如，对于金属导体，会出现最简单的线性电流-电压特性：

$$U = IR,$$

其中$R$是电压和电流之间的比例系数，称为电阻。电阻由导体的材料、尺寸和温度决定。

然而，有许多设备和元件的物理和设计特征导致电流和电压之间存在非线性关系。

任务 5. 找出金属导体的电流和电压之间的关系，同时考虑其电阻对温度的依赖性。传热到环境中的速率被认为与导体和环境之间的温差成正比。

电流和电压之间的通常关系$U = IR$假设电阻$R$取决于温度，是在导体温度$T$下测得的。但这个温度，一般来说，和环境的温度$T_0$是有差别的。结果，在导体和介质之间发生热传递，并且在小温差$T - T_0$时，随时间$\Delta t$输出的热量由以下对应关系给出

$$\frac{\Delta Q_{\text{пер}}}{\Delta t} = C (T - T_0),$$

其中$C$是常数比例系数。

当电流流动时，导体发热。 （从微观角度来看，这是由于电场影响下导体中运动的电子数量较多，晶格的纳米数较多，缺陷较多，成本较低。）$\Delta t$时间内导体中输出的热量与导体中的电流$I$、导体的电阻$R$以及导体上的电压$U$有关。它：

$$\frac{\Delta Q_{\text{выд}}}{\Delta t} = I^2 R = \frac{U^2}{R_0 (1 + \alpha (T - T_0))}.$$

这里$R_0$是导体$T_0$温度下的电阻，$\alpha$是电阻的温度系数。 （如果温度$T_0$接近$0^\circ C$并且差值$T - T_0$很小，那么电阻对温度的依赖性确实可以表示为$R = R_0 (1 + \alpha (T - T_0))$。）

导体将被加热，直到导体中主体的释放速率等于热量释放到环境中的速率。

$$\frac{\Delta Q_{\text{выд}}}{\Delta t} = \frac{\Delta Q_{\text{пер}}}{\Delta t},$$

或者

$$\frac{U^2}{R_0 (1 + \alpha (T - T_0))} = C (T - T_0).$$

因此温差

$$T - T_0 = \frac{-R_0 C + (R_0^2 C^2 + 4 U^2 \alpha R_0 C)^{1/2}}{2 \alpha R_0 C},$$

电流和电压之间的关系是

$$I = \frac{U}{R_0 (1 + \alpha (T - T_0))} = \frac{U}{R_0 \left(1 + \frac{(R_0^2 C^2 + 4 U^2 \alpha R_0 C)^{1/2} - R_0 C}{2 R_0 C}\right)}$$

（负值$T - T_0$被丢弃，因为它没有物理意义）。

我们来分析一下结果。很容易看出，在$U^2 \ll R_0 C / (4 \alpha)$，它实际上也始终取决于，因为对加热引起的电阻的修正总是很小。
