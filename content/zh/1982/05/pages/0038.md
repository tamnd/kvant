对象 $S$ 的图像 $S_2$ 位于第一条线前面，距离第二条线 $d$ 的距离是多少？如果这两条线之间的距离 $l$ 变为零，这两条线的光学系统是什么？

显然，问题的解决在于将透镜公式依次应用于透镜$\varLambda_1$和$\varLambda_2$。首先我们要注意的是，这个公式只是表达的不是对应的距离，而是它们的倒数，因此运算起来很方便。否则，正如经验所示，计算的繁琐常常会导致错误的结果。

对于第一行，公式给出

$$\frac{1}{f_1} = \frac{1}{F_1} - \frac{1}{d_1} = \frac{1}{F_1} - \frac{1}{d},$$

其中$f_1$是到图像$S_1$的距离。该中间图像表示距离 $d_2 = l - f_1$ 处的第二条线。第二次应用透镜公式，我们得到了期望的结果：

$$\frac{1}{f_2} = \frac{1}{F_2} - \frac{1}{d_2} = \frac{1}{F_2} - \frac{1}{l - f_1} =$$

$$= \frac{1}{F_2} + \frac{\frac{1}{f_1}}{1 - l \frac{1}{f_1}} = \frac{1}{F_2} + \frac{\frac{1}{F_1} - \frac{1}{d}}{1 - l \left(\frac{1}{F_1} - \frac{1}{d}\right)}.$$

从这里，原则上可以求出距离$f_2$本身。

如果镜片紧密折叠，即$l = 0$，则所得表达式简化为：

$$\frac{1}{f_2} = \frac{1}{F_2} + \frac{1}{F_1} - \frac{1}{d}.$$

为了找到这样一个系统的距离公式，我们输入 $d \to \infty$。

$$\frac{1}{f_2} = \frac{1}{F_{\text{системы}}} = \frac{1}{F_1} + \frac{1}{F_2},$$

或者

$$D_{\text{системы}} = D_1 + D_2$$

— 两条紧密折叠在一起的细线的光学系统等于它们的光焦度之和。这个结果可以推广到大量行的情况。
