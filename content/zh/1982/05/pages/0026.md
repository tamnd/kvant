换句话说，
$$S_{n-k-1} < (m-1)^2 < m^2 < S_{n-k} < (m+1)^2 < S_{n-k+1} < \dots$$
$$\dots < (m+k-1)^2 < S_{n-1} < (m+k)^2 < S_n < (m+k+1)^2.$$

然后$p_{n-k} = S_{n-k} - S_{n-k-1} > m^2 - (m-1)^2 = 2m-1$。显然，对于$s \geq 2$，$n-k \geq 12$和$p_{s+1} > p_s + 2$，我们得到$p_{n+1} > p_{n-k} + 2(k+1) > 2(m+k) + 1$。因此，$S_{n+1} = S_n + p_{n+1} > (m+k)^2 + 2(m+k) + 1 = (m+k+1)^2$。因此，$S_n < (m+k+1)^2 < S_{n+1}$，即区间$]S_n; S_{n+1}$[包含一个精确的平方。

**M704。平行四边形是围绕正方形描述的（正方形的顶点位于平行四边形的不同边上）。证明从平行四边形的顶点到正方形各边的垂线形成一个新的正方形 (图 1)。**

**答案：** $\left\{ \left(\frac{1}{3}, \frac{1}{2}, 1\right), \left(-\frac{1}{3}, -\frac{1}{2}, -1\right) \right\}$。

解决方案。由于$\frac{x}{3(1+x^2)} = \frac{y}{4(1+y^2)} = \frac{z}{5(1+z^2)}$，数字$x, y$和$z$具有相同的符号，如果$(x, y, z)$是系统的解，那么$(-x, -y, -z)$就是它的解，因此只能求正解。

公式 $\sin 2\varphi = \frac{2tg\varphi}{1+tg^2\varphi}$ 被用于区间 $]0; \pi[$ 以及 $\tg \frac{\alpha}{2} = x, \tg \frac{\beta}{2} = y, \tg \frac{\gamma}{2} = z$ 的心理角 $\alpha, \beta, \gamma$。则(1)变为方程$\frac{\sin \alpha}{3} = \frac{\sin \beta}{4} = \frac{\sin \gamma}{5}$。

从系统的第二个方程我们得到$\frac{1}{z} = \frac{x+y}{1-xy}$（显然是$xy \neq 1, z \neq 0$），在新的符号中其形式为$\text{ctg} \frac{\gamma}{2} = \text{tg} \frac{\alpha+\beta}{2}$，或者

$$\text{ctg} \left(\frac{\pi}{2} - \frac{\gamma}{2}\right) = \text{tg} \frac{\alpha+\beta}{2}.$$

当且仅当$\frac{\pi}{2} - \frac{\gamma}{2} = \frac{\alpha+\beta}{2}$（即$\alpha + \beta + \gamma = \pi$）时，所选限制下的$\alpha, \beta, \gamma$的最后一个等式才是可能的。

因此，我们得到$\alpha, \beta$和$\gamma$是边长比为3:4:5的三角形的角（见（2））。这是一个直角三角形，有$\gamma = \frac{\pi}{2}$、$\sin \alpha = \frac{3}{5}$、$\sin \beta = \frac{4}{5}$（见图），即$\text{ctg} \frac{\alpha}{2} = \frac{1}{3}$、$\text{ctg} \frac{\beta}{2} = \frac{1}{2}$、$\text{ctg} \frac{\gamma}{2} = 1$。

一些读者纯粹用代数方法解决了这个系统，但这样的解决方案比给出的解决方案要长得多。
