在 d 的什么值下图像有效，在什么值下图像最小（距离情况 l=0）？

来自光源的光线照射到透镜上，在透镜中折射，然后从镜子反射并再次被透镜折射。

经过透镜第一次折射后，光线会聚于点$S_1$。我们根据透镜公式求出线段$f_1$的大小：

$$\frac{1}{f_1} = \frac{1}{F} - \frac{1}{d_1} = \frac{1}{F} - \frac{1}{d}.$$

点$S_1$在平面镜中的图像将是点$S_2$，与点$S_1$距镜子的距离相同，但位于其另一侧。这个距离是$d_2 = f_2 = l - f_1$。

从镜子反射后，光线再次落在透镜上，就好像来自距离透镜一定距离的点 $S_2$

$$d_3 = l + (l - f_1) = 2l - f_1.$$

经过透镜第二次折射后，光线（或其延续）将在距其 $f_3$ 的距离处会聚，并且

$$\frac{1}{f_3} = \frac{1}{F} - \frac{1}{d_3} = \frac{1}{F} - \frac{1}{2l - f_1} =$$

$$= \frac{1}{F} - \frac{\frac{1}{f_1}}{2l \frac{1}{f_1} - 1} = \frac{1}{F} - \frac{\frac{1}{F} - \frac{1}{d}}{2l \left(\frac{1}{F} - \frac{1}{d}\right) - 1} =$$

$$= \frac{2l \left(\frac{1}{F} - \frac{1}{d}\right) + \frac{F}{d} - 2}{F \left(2l \left(\frac{1}{F} - \frac{1}{d}\right) - 1\right)}.$$

因此所需数量

$$f_3 = \frac{F \left(2l \left(\frac{1}{F} - \frac{1}{d}\right) - 1\right)}{2l \left(\frac{1}{F} - \frac{1}{d}\right) + \frac{F}{d} - 2}.$$

现在让我们分析一下生成的图像何时有效以及何时最小。显然，如果点$S_2$位于镜头与其右焦点之间，即$d_3 < F$，则最终图像最小。因此，点 $S_1$ 必须位于镜子的右侧，距镜子的距离为 $d_2 > l - F$，距透镜的距离为 $f_1 > 2l - F$。然后根据透镜公式我们得到

$$\frac{1}{d} = \frac{1}{F} - \frac{1}{f_1},$$

伊利

$$d = \frac{Ff_1}{f_1 - F} < \frac{F(2l - F)}{2(l - F)}$$

— 在光源距镜头 $S$ 的距离下，其图像将是最小的。

特别是，当$l = 0$时，图像对于值$d < F/2$来说是最小的，对于$d > F/2$来说是有效的。

问题 3. 厚透镜由折射率为 $n = 1,5$ 的叠层制成。其第一凸面的半径为$R_1 = 20$厘米，既凸又凸的第二表面的半径为$R_2 = 5$厘米。如果已知透镜使平行光束平行，则求透镜的厚度。

由于镜片较厚，因此不适用薄镜片公式。为了解决这个问题，我们必须无限地利用光的折射定律。

让我们考虑入射在透镜双光轴之间的第一个球形界面上的平行光束。折射后，光线会汇聚在光轴上的某一点。我们来找到这个点的位置。

为此，我们从光束中选择一条光线 - 光线 $AB$，距轴的距离为 $h$，并在折射后找到其与轴的交点 $S$ (图 5, a)。让我们将半径 $OB$ 绘制到光束的入射点。那么$\alpha$就是入射角，$\beta$就是折射角，根据折射定律，

$$\frac{\sin \alpha}{\sin \beta} = n,$$ 或 $\sin \beta = \frac{\sin \alpha}{n}$。

从三角形COB

$$\sin \alpha = \frac{h}{R_1},$$ 和 $\sin \beta = \frac{\sin \alpha}{n} = \frac{h}{nR_1}$。
