光学系统

光学系统通常被称为一组各种光学元件：透镜、镜子、棱镜、平行平面板等。它们的作用基于最简单的几何光学定律——光的反射和折射定律。

多光系统的主要元件是薄透镜和平面镜（统计数据中讨论的正是此类系统）。让我们回顾一下将光的反射和折射定律应用于它们的主要结果。

对于薄透镜，该公式有效

$$\frac{1}{d} + \frac{1}{f} = \frac{1}{F},$$

这样您就可以根据已知的物体到镜头的距离 $d$ 以及镜头的焦距 $F$ 求出镜头到图像的距离 $f$。要使用这个公式，您必须仔细遵循符号规则。因此，应该记住，焦距 $F$ 对于会聚透镜始终为正，对于发散透镜始终为负。 （这就是为什么会聚透镜也称为正透镜，而发散透镜也称为负透镜。）对于（真实）物体或其图像的实现，距离$d$被认为是正的，之前使用一些其他光学元件获得并定位于

对象 $S$ 的图像 $S_2$ 位于第一条线前面，距离第二条线 $d$ 的距离是多少？如果这两条线之间的距离 $l$ 变为零，这两条线的光学系统是什么？

显然，问题的解决在于将透镜公式依次应用于透镜$\varLambda_1$和$\varLambda_2$。首先我们要注意的是，这个公式只是表达的不是对应的距离，而是它们的倒数，因此运算起来很方便。否则，正如经验所示，计算的繁琐常常会导致错误的结果。

对于第一行，公式给出

$$\frac{1}{f_1} = \frac{1}{F_1} - \frac{1}{d_1} = \frac{1}{F_1} - \frac{1}{d},$$

其中$f_1$是到图像$S_1$的距离。该中间图像表示距离 $d_2 = l - f_1$ 处的第二条线。第二次应用透镜公式，我们得到了期望的结果：

$$\frac{1}{f_2} = \frac{1}{F_2} - \frac{1}{d_2} = \frac{1}{F_2} - \frac{1}{l - f_1} =$$

$$= \frac{1}{F_2} + \frac{\frac{1}{f_1}}{1 - l \frac{1}{f_1}} = \frac{1}{F_2} + \frac{\frac{1}{F_1} - \frac{1}{d}}{1 - l \left(\frac{1}{F_1} - \frac{1}{d}\right)}.$$

从这里，原则上可以求出距离$f_2$本身。

如果镜片紧密折叠，即$l = 0$，则所得表达式简化为：

$$\frac{1}{f_2} = \frac{1}{F_2} + \frac{1}{F_1} - \frac{1}{d}.$$

为了找到这样一个系统的距离公式，我们输入 $d \to \infty$。

$$\frac{1}{f_2} = \frac{1}{F_{\text{системы}}} = \frac{1}{F_1} + \frac{1}{F_2},$$

或者

$$D_{\text{системы}} = D_1 + D_2$$

— 两条紧密折叠在一起的细线的光学系统等于它们的光焦度之和。这个结果可以推广到大量行的情况。

在 d 的什么值下图像有效，在什么值下图像最小（距离情况 l=0）？

来自光源的光线照射到透镜上，在透镜中折射，然后从镜子反射并再次被透镜折射。

经过透镜第一次折射后，光线会聚于点$S_1$。我们根据透镜公式求出线段$f_1$的大小：

$$\frac{1}{f_1} = \frac{1}{F} - \frac{1}{d_1} = \frac{1}{F} - \frac{1}{d}.$$

点$S_1$在平面镜中的图像将是点$S_2$，与点$S_1$距镜子的距离相同，但位于其另一侧。这个距离是$d_2 = f_2 = l - f_1$。

从镜子反射后，光线再次落在透镜上，就好像来自距离透镜一定距离的点 $S_2$

$$d_3 = l + (l - f_1) = 2l - f_1.$$

经过透镜第二次折射后，光线（或其延续）将在距其 $f_3$ 的距离处会聚，并且

$$\frac{1}{f_3} = \frac{1}{F} - \frac{1}{d_3} = \frac{1}{F} - \frac{1}{2l - f_1} =$$

$$= \frac{1}{F} - \frac{\frac{1}{f_1}}{2l \frac{1}{f_1} - 1} = \frac{1}{F} - \frac{\frac{1}{F} - \frac{1}{d}}{2l \left(\frac{1}{F} - \frac{1}{d}\right) - 1} =$$

$$= \frac{2l \left(\frac{1}{F} - \frac{1}{d}\right) + \frac{F}{d} - 2}{F \left(2l \left(\frac{1}{F} - \frac{1}{d}\right) - 1\right)}.$$

因此所需数量

$$f_3 = \frac{F \left(2l \left(\frac{1}{F} - \frac{1}{d}\right) - 1\right)}{2l \left(\frac{1}{F} - \frac{1}{d}\right) + \frac{F}{d} - 2}.$$

现在让我们分析一下生成的图像何时有效以及何时最小。显然，如果点$S_2$位于镜头与其右焦点之间，即$d_3 < F$，则最终图像最小。因此，点 $S_1$ 必须位于镜子的右侧，距镜子的距离为 $d_2 > l - F$，距透镜的距离为 $f_1 > 2l - F$。然后根据透镜公式我们得到

$$\frac{1}{d} = \frac{1}{F} - \frac{1}{f_1},$$

伊利

$$d = \frac{Ff_1}{f_1 - F} < \frac{F(2l - F)}{2(l - F)}$$

— 在光源距镜头 $S$ 的距离下，其图像将是最小的。

特别是，当$l = 0$时，图像对于值$d < F/2$来说是最小的，对于$d > F/2$来说是有效的。

由于镜片较厚，因此不适用薄镜片公式。为了解决这个问题，我们必须无限地利用光的折射定律。

让我们考虑入射在透镜双光轴之间的第一个球形界面上的平行光束。折射后，光线会汇聚在光轴上的某一点。我们来找到这个点的位置。

$$\frac{\sin \alpha}{\sin \beta} = n,$$ 或 $\sin \beta = \frac{\sin \alpha}{n}$。

问题4.求焦距等于物体焦距的聚焦线的望远镜的聚焦区域。聚焦线的移动范围是多少？没有聚焦线但具有相同聚焦区域的镜筒长度应该是多少？

当镜筒设置为无限远时，聚焦线不应以任何方式干扰镜头产生的图像；因此，它必须位于获得图像的位置，即物体和目镜的公共焦平面中。

聚焦线距离该平面越远，镜头产生的图像移动得越多。在极端情况下，可以将线紧紧地拧到镜头上。让我们找出望远镜聚焦的最小距离$d$。

由于两条相同的线（聚焦线和镜头）扭曲在一起，它们的总焦距将等于物体焦距的一半，即$F_{06}/2$。这些线的系统创建的图像应在$f=F_{06}$的距离处接收。然后根据细线公式我们求出$d$：

$$\frac{1}{d} + \frac{1}{F_{06}} = \frac{2}{F_{06}}, \text{ и } d=F_{06}.$$

因此，望远镜可以聚焦于距离望远镜 $d=F_{06}$ 到 $d \to \infty$ 的物体。在这种情况下，聚焦线直接从物体移动到物体和目镜的公共焦平面，即移动到等于$F_{06}$的距离。

显然，没有聚焦线的望远镜不可能有这么大的聚焦极限，因为为此，管线必须无限大。
