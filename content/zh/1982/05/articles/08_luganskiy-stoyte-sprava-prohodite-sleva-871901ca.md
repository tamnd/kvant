“站在右边，从左边过去……”

如果您生活在大城市，那里有地铁——最方便、最可靠的城市交通方式，那么您当然已经多次听到这句话，通过扬声器放大，在隧道拱门下大声响起。当然，你们中的许多人，在执行某项重要任务时迟到了，并没有停止踩上自动扶梯，而是像脚跟踩在台阶上一样冲下去，像一个回转运动员一样在右侧的故事和左侧的通道之间移动。但很多时候，你无法控制地向前移动，向下某处会遇到一大群人，出于某种原因，他们不想向左或向右通过。您甚至可能已经注意到，在高峰时段，永远移动的灯塔上挤满了人，尽管自动扶梯服务员真心实意地坦白，但他们却不想通过。让我们不要再担心乘客的无知，以研究者的客观眼光来看待这一情况。但首先，这是一个例子。

让我们考虑一条移动的传送带（传送带），传送带上的一些物体彼此之间的距离大致相同。设 $n$ 个物体放置在一个单位的胶带线上；值$n$称为浓度。对于物体沿线排列的情况，可以这样调用：

液体线密度。它的尺寸为 1/m，或者，如果您愿意，也可以是 1/cm、1/km、1/yard - 取决于长度单位的选择。进一步，让磁带以观察到的$v$mismo 速度移动，从而对这些对象进行计数。 （然而，这种观察到的作用也可以通过带有 photozem 的电子计数器来发挥，类似于地铁站自动售票中使用的计数器）。问题来了：单位时间内会记录观察到多少个物体？这个问题很容易回答。在 $t$ Mismo 时间内，观察到产品并具有 1/s 的尺寸（或 1/分钟、1/年 - 取决于长度单位的选择）。我们用字母 F 表示流量（这是大写希腊字母“Phi”）。所以，

$$\Phi = nv.$$

现在，让我们想象一下，我们的运输工具的长度是有限的，并且位于其传送带上的物体，从一个到末端，落到以不同速度 $v'$ 移动的另一运输工具的传送带上。显然，可以观察到，站在第二辆车附近，在单位时间内，它计数的穿过与第一辆车观察到的相同数量的物体的数量相同。如果它们的数量较少，那么您可以保证沿途某个地方的一些煤渣杀手也会有类似的物体。如果发现有重要的添加，则会将其他对象放置在第二个磁带上。因此，两个观察者注册的流$\Phi = nv$和$\Phi' = n'v'$必须彼此相等：

$$nv = n'v'.$$

从这里可以立即清楚地看出，$n'$物体在第二个物体上的浓度

传送带将与第一个传送带不同，即

$$n' = n \frac{v}{v'}$$

如果速度$v'$小于速度$v$，则浓度$n'$将大于浓度$n$。甚至可能更好的是，在第二次运输的传送带上，物体将无法无间隔地安装，而是会堆叠在一起。

当然，您知道，对于观察到的完美来说，物体是否在以 $v$ 的速度移动的传送带上，或者它们是否沿着静止的传送带（地板、人行道）以 $v$ 的速度独立移动，都是无关紧要的。唯一重要的是它们相对于记录流量的观察对象的速度等于 $v$。因此，流量是一个取决于其变化的坐标系的量。因此，如果被观察者本人在另一条传送带上，以相同的速度 $v$ 平行于第一条传送带移动，则相对速度 $v_{\text{отн}}$ ，因此观察到的可变流量 $\Phi = nv_{\text{отн}}$ 将等于零。

现在是时候回到高峰时段自动扶梯上会发生什么的问题了。右侧站立乘客流量等于$\Phi_1 = n_1v_9$，其中$n_1$为站立乘客集中度，$v_9$为扶梯速度。左侧经过的乘客流量等于$\Phi_2 = n_2(v_9 + v_n)$，其中$n_2$是步行乘客的集中度，$v_n$是行人相对于自动扶梯的速度，$v_9 + v_n$是步行乘客相对于静止可观测量的速度。当然，在下降结束时，两组乘客开始以相同的速度$v_n$移动。然而，右流不会发生任何重大变化，因为$v_n$约等于$v_9$。但是，位于自动扶梯左侧的乘客现在的移动速度（相对于固定墙壁）大约是以前的两倍，并且根据前面所说，该群体中乘客的集中度应该大约是以前的两倍。

由于多种原因，人们不喜欢紧密地走在一起，因此，如果人们在自动扶梯上行走时保持比在平台上行走时大一倍的距离，或者下方的人流能够向两侧扩展，那么左侧的人流就可以正常移动。在高峰时段，由于人数众多，这两种选择通常都无法实现。这就是为什么乘坐自动扶梯的人更明智地在右侧和左侧建造。不然下面肯定会拥堵。

在我们看来，现在您不会因为自动扶梯意外延误而生气，而是会尝试提前大约五分钟离开家。

当然，流程的概念不仅与案件的审议有关，而且与案件的审理有关。它在物理学中应用非常广泛。

设一束粒子在空间中以相同方向、相同速度$v$运动。在线性情况下，光束每单位体积的粒子数也称为浓度$n$（或体积密度），尺寸为$1/\text{m}^3$。乘积 $\Phi = nv$ 现在的尺寸为 $1/(m^2 \cdot c)$，等于每秒通过垂直于光束运动方向的单位截面积的粒子数。因此，$\Phi$ 称为粒子通量密度；通过将其值乘以光束的横截面积，我们就得到了光束中粒子的总流量。

如果每个运动部件都具有某种属性，并且该属性随之“转移”，那么建议引入该属性的磁通密度的概念

$$\Phi_a = anv$$

其中 $a$ 是给定属性的特征量。例如，$a = m$是流中单个粒子的质量，那么$\Phi_m = mnv$是质量流密度（其维数是$\kappa/(\text{m}^2 \cdot c)$）。或者，

若$a = q$为各部分所带电子电荷，则$\Phi_q = qnv$为电子电荷通量密度（电子量）。量$\Phi_q$，其尺寸为$KL/(m^2 \cdot c)$，也称为电子流密度，因为电子流的强度是每单位时间通过导体横截面的电子量。 （这也可以从维度消息：$KL/(m^2 \cdot c) = (KL/c)/m^2 = A/m^2$得出。）其他通量密度（能量、动量等）的确定方式类似。

现在让我们考虑几个具体问题，以帮助您更好地理解流量或密度的概念。

1. 尝试估计高速公路的容量，即一小时内可以沿着给定道路通过的自动驾驶车辆的最大数量。

在设计道路和正确组织交通时，尤其是在大城市和主要国际高速公路上，此类计算是必要的。

假设高速公路是双向的，每个方向的交通都发生在两条车道上，最大允许速度为 $v = 60$ km/h（例如，莫斯科自动环路的交通状况）。我们感兴趣的是自动化的流动，即观察到单位时间内不动的自动化的数量。利用上面得到的公式，我们将写出$\Phi = Nnv$，其中$N=4$是车道总数，$n$是道路单位长度的汽车数量，可以与自动机器之间的距离$L$相关联：$n = 1/L$。因此，$\Phi = Nv/L$。自动机器操作手册建议保持自动机器之间的距离（以米为单位）等于以公里/小时表示的速度的一半。在我们的例子中，速度为 $v = 60$ km/h $L = 30$ m，高速公路容量为

$$\Phi = N \frac{v}{L} = 8000 \text{ 1/ч.}$$

2. 人们站在向下的自动扶梯上，彼此之间的距离为$L = 1$米。每个客流量将被规定：
a) 站在自动扶梯底部的值班人员； b) 站在另一部向上移动的自动扶梯上观看？自动扶梯的运行速度取$v = 2$米/秒。

我们已经说过，流程取决于报告系统，在本例中取决于观察者。相对于自动扶梯上的值班人员，乘客下降的速度等于自动扶梯的速度，因此

$$\Phi_1 = nv = \frac{v}{L} = 2 \text{ } 1/\text{c}.$$

从位于以速度 $v$ 上升的自动扶梯上的观察者的角度来看，乘客流量将是原来的两倍，因为相对于自动扶梯，流量速度为 $v_{\text{отн}} = 2v$，并且流量将增加一倍。

$$\Phi_2 = nv_{\text{отн}} = 2nv = 4 \text{ } 1/\text{c}.$$

3. 一辆承载能力为 $M = 2$ t 的卡车使用运输工具装载 arbuzami。阿尔布兹的平均重量为 $m = 5$ kg，运输速度为 $v = 0,5$ 米/秒，传送带上阿尔布兹之间的距离为 $L = 0,75$ 米。找到加载时间。

在这种情况下，我们正在处理质量流量。根据定义，它等于$\Phi_m = mnv = mv/L$。然后是所需的加载时间

$$t = \frac{M}{\Phi_m} = \frac{ML}{mv} = 600 \quad c = 10 \text{ мин.}$$

4. 估计电流流过金属导体时电子在金属导体中的运动速度。

我们将从以下事实出发：根据正确的安全预防措施，允许通过电线传递密度高达$10 \text{ A}/\text{mm}^2 = 10^7 \text{ A}/\text{m}^2$的电流，并具有自然冷却效果。因此，我们要讨论的是电流密度，即电荷$\Phi_q = qnv$的磁通密度，其中$q$是一个载流子的电荷，$n$是载流子的浓度，$v$是它们稳定运动的速度
