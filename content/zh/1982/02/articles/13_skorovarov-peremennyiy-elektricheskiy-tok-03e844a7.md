交流电

交流电广泛应用于工业（工厂和工厂）和一般照明网络中。

众所周知，内置电流满足欧姆定律——电路均匀部分的电流强度与施加的电压成正比。在交流电路中，电流也取决于源电压，但根据更复杂的定律，因为电压和电流随时间变化。电压变化的规律可能很复杂，但最广泛和实际的应用是电压根据谐波规律变化的情况。例如，像这样：

$$u = U_m \cos \omega t,$$

其中$U_m$是电压幅度，$\omega$是循环频率，$\omega t = \varphi$是振荡相位。请注意，在我国，所有地区采用的频率是$v = \omega/2\pi = 50$ Hz。

交流电路由电流源和各种元件组成，例如储能灯、电气设备、电容器、线圈、电动机和变压器。

研究交流电的主要任务是电路的计算，即确定给定电流源电压和给定电路元件参数下的电流强度。

一般情况下，电路中的电流与源电压一样，根据谐波定律随时间变化

$$i = I_m \cos(\omega t + \varphi).$$

电流幅度 $I_m$ 以及电流和电压之间的相移 $\varphi$ 取决于给定电路的参数。

让我们首先考虑最简单的电路，由电源和一个元件（有源电阻、电容器或线圈）组成。当连接有源电阻时，电路中将出现交流电，其幅值等于电压幅值除以有源电阻：$I_{RM} = U_m/R$，且相位与电压相位一致。在带有电容器的电路中，同相电流决定了$\pi/2$处的电压以及电流$I_{CM} = U_m \omega C$的幅值，其中$C$是电容器的电容。电感为$L$的线圈中产生的电流比电压相位滞后$\pi/2$，其幅度为$I_{LM} = U_m / (\omega L)$。

首先，考虑电路的一部分，其中包含电阻为 $R_1$ 的电阻器和电阻为 $C$ 的电容器 em 的并联连接。让我们为其构建一个矢量图，考虑到本节中的电压 $U_1$ 已知 (图 2, b)。我们发现电路中的电流等于通过第一个电阻和电容器的电流之和：

$$\overrightarrow{I} = \overrightarrow{I_{R1}} + \overrightarrow{I_C}.$$

该电流的幅度等于

$$I = \sqrt{I_{R1}^2 + I_C^2} = \sqrt{\left(\frac{U_1}{R_1}\right)^2 + \left(U_1 \omega C\right)^2} = U_1 \sqrt{\frac{1}{R_1^2} + (\omega C)^2}.$$

同样的电流流过阻值为$R_2$的电阻，因此其两端的电压相等

$$U_2 = IR_2.$$

显然，$U_1$和$U_2$的矢量和等于源端电压$\overrightarrow{U}$：

$$\overrightarrow{U}_1 + \overrightarrow{U}_2 = \overrightarrow{U}.$$

让我们将向量 $\overrightarrow{U}_2$ 投影到坐标轴 $X$ 和 $Y$ 上并找到

$$U_{2x} = U_1 \frac{R_1}{R_2}, \quad U_{2y} = U_1 R_1 \omega C.$$

从矢量图可以看出

$$U^2 = \left(U_1 + U_{2x}\right)^2 + U_{2y}^2,$$

或者

$$U = U_1 \sqrt{\left(1 + \frac{R_1}{R_2}\right)^2 + \left(R_1 \omega C\right)^2}.$$

最后，由等式（1）和（2）我们得到

$$I = U \sqrt{\frac{1 + \left(R_2 \omega C\right)^2}{\left(R_1 + R_2\right)^2 + \left(R_1 R_2 \omega C\right)^2}}.$$

电路中释放的功率具有非常重要的实际意义。在直流电的情况下，对于电路的任何一段，功率由电压和电流的乘积决定。交流功率取决于电流和电压的有效值，以及本节中电流和电压之间的相移：

$$P = UI \cos \varphi,$$

其中 cos φ 是功率因数。

如您所知，为了从直流电源获得最大功率，您需要连接一个电阻等于电源内阻的负载。交流电源也有内阻，它不仅是有源的，而且是感性的。了解需要连接什么样的负载才能在交流电路中获得最大有功功率是很有趣的。这个问题的答案由以下问题给出：

让我们用 $\mathcal{E}$ 表示电源的电动势，用 $R_{\mathrm{H}}$ 表示有源电压电阻，并用 $C$ 表示电容器的电容。那么电流就会在电路中流动

$$I = \frac{\mathcal{E}}{\sqrt{(R_{\mathrm{H}}+R)^{2} + (\omega L-1/\omega C)^{2}}},$$

并且将在负载处释放有功功率

$$P = U_{\mathrm{H}} I \cos \varphi = I^{2} R_{\mathrm{H}} = \frac{\mathcal{E}^{2} R_{\mathrm{H}}}{(R_{\mathrm{H}}+R)^{2} + (\omega L-1/\omega C)^{2}}.$$

显然，对于任何 $R_{\mathrm{H}}$ 值，幂都是最大的，否则相等

$$\omega L - \frac{1}{\omega C} = 0.$$

这意味着电容器的电容必须等于

$$C = \frac{1}{\omega^{2} L}.$$

在这种情况下，功率是相等的

$$P = \frac{\mathcal{E}^{2} R_{\mathrm{H}}}{(R_{\mathrm{H}}+R)^{2}}.$$

为了找到取决于电阻 $R_{\mathrm{H}}$ 的最大功率，我们将 $P$ 到 $R_{\mathrm{H}}$ 的导数等于零：

$$P'(R_{\mathrm{H}}) = \frac{\mathcal{E}^{2} ((R_{\mathrm{H}}+R)^{2} - 2 R_{\mathrm{H}} (R_{\mathrm{H}}+R))}{(R_{\mathrm{H}}+R)^{4}} = 0.$$

从这里

$$R_{\mathrm{H}} = R, \quad P_{\text{max}} = \frac{\mathcal{E}^{2}}{4 R}.$$

请注意，我们获得了与内置电流完全相同的关系。

变压器在交流电路中占有特殊的地位。这是一种将电能从一个电路传输到另一个电路，同时转换电流和电压的装置。这就是“transformer”这个名字的由来，即“转换器”。变压器的工作原理是基于电磁感应现象，因此只能在交流电下工作。

变压器由一个封闭的铁磁芯组成，其上缠绕着两个（有时更多）铜线线圈。线圈通常称为变压器绕组。然而，其中，初级连接到电源，另一个（次级）连接到负载。 （但是，绕组的这种分离是有条件的，因为根据操作模式，连接可能是相反的。）线圈可以以两种方式缠绕在磁芯上：沿一个方向或沿不同方向。据此，绕组上的电压将以同相或反相变化。确定绕组末端的工作条件并假设在任何时候每个绕组首尾之间的电压具有相同的极性。在图片和图纸中，绕组的起点通常标有星号。

使用真实变压器计算电路非常困难。控制无序，即所谓理想变压器。 （注意，理想变压器和实际变压器的计算结果实际上是一致的。）首先，我们假设绕组没有有源电阻，因此绕组中的前电压为零，满足等式

$$\frac{U_{1}}{U_{2}} = \frac{\mathcal{E}_{1}}{\mathcal{E}_{2}} = \frac{n_{1}}{n_{2}} = K.$$

这里$U_{1}$和$U_{2}$是电压，$\mathcal{E}_{1}$和$\mathcal{E}_{2}$是感应电动势，$n_{1}$和$n_{2}$是相应的初级和次级绕组的匝数； $K = n_{1}/n_{2}$——变换系数。其次，我们不会考虑不仅在绕组中而且在变压器铁芯中由于发热而造成的能量损失。这意味着进入初级绕组的功率等于离开次级绕组到负载的功率，或者换句话说，输入功率和输出功率之和为零：

$$U_{1} I_{1} + U_{2} I_{2} = 0,$$

其中$I_{1}$和$I_{2}$是相应绕组的初级和次级绕组中的电流。
