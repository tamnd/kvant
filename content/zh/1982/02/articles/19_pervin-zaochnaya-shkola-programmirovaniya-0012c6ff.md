第 18 课：文件

什么是文件？
文件是相同类型元素的小集合，其数量是不确定的。

文件类型由以下语法图描述：

```
file of min
```

type 是文件元素的一般类型。我们将其称为基本的。有一种称为文本的标准文件类型（即，任何程序都存在且不受其中的描述）文件类型。它的基本类型是 char。文本类型的文件称为文本文件。

文件的元素被认为是按顺序排列的，即与向量的元素相同。文件与向量的不同之处，首先在于它的大小可以改变，其次在于访问其元素的方式完全不同：不可能访问文件的任意元素；它的元素从头到尾只能连续查看，每次只能看到一个元素。每个文件f都有一个关联变量，表示f↑；它的类型与基本文件类型相同。它称为该文件的缓冲区或缓冲区变量。缓冲区只能容纳一个文件元素；

该元素的值用作缓冲区值。缓冲区就像一个窗口，您可以通过它查看文件，逐个选择元素。

如果文件被查看到最后（或者如果它完全是空的），那么我们将认为它已完成。如果文件已完成，则其缓冲区的值未定义。

文件处理程序
可以通过调用标准逻辑函数来检查文件f是否完成

eof(f)
如果 f 完成，则生成值 true，否则生成 false*)。

假设我们需要查看文件 f。为此，您必须首先调用标准过程

reset(f)
（“重置”是“返回”的意思）。作为其执行的结果，缓冲区 f↑ 的值将成为文件的第一个元素（如果文件不为空）。

您可以使用标准过程调用从一个文件元素移动到下一个文件元素

get(f)
（“get”的意思是“取得”）。执行后，f↑ 将包含下一个元素的值（如果有）。 （如果没有下一个元素，则文件将完成。） get 过程不能应用于已经完成的文件。

让我们看一个例子。令 f1 和 f2 为基类型为 real 的文件，arovno 和 b 为布尔类型的变量。如果f1和f2的内容相同（即这些文件具有相同的长度，可能为零，并且它们对应的元素成对相等），则变量equals需要设置为true，否则设置为false。

*) eof 是英文单词 end of file 的缩写。

write (output, x)
