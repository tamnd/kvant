这当然是一个熟悉的抛物线方程。请注意，第二个射弹相对于地面的轨迹方程将完全相同。

2) 在这种情况下，报告系统的开始必须与飞机相关联。相对于它，弹头的初速度等于$u$，因此弹头的横坐标会按照$x = ut$的规律变化。垂直坐标仍为 $y = gt^2/2$ 形式。因此，将变换作为变化，我们得到弹头相对于飞行器运动的轨迹方程：

$$y = \frac{gx^2}{2u^2}.$$

显然，在这里，抛射体的轨迹也是抛物线。

3) 为了描述第一个射弹相对于第二个射弹的运动，我们将使用与第一个射弹相同的报告系统，也就是说，我们将坐标原点放置在第一次射击时平面所在的点。

让我们写出第一个弹头的坐标 $x_i$ 和 $y_i$ 及其相应的速度投影 $v_{1x}$ 和 $v_{1y}$ 的方程：

$$x_i = (u + v)t, \quad y_i = \frac{gt^2}{2},$$

$$v_{1x} = u + v, \quad v_{1y} = gt.$$

这里时间$t$是从第一次射击的那一刻开始计算的，但根据问题的意思它不小于射击之间的间隔$t$，即$t \geq \tau$。

第二次充电的类似方程如下：

$$x_2 = v\tau + (u + v)(t - \tau), \quad y_2 = \frac{g(t - \tau)^2}{2},$$

$$v_{2x} = u + v, \quad v_{2y} = g(t - \tau).$$

如果观察到与第二个段塞的连接，则相对于它，第一个段塞的坐标（或松紧度的投影）等于固定报告系统中第一和第二段塞的相应坐标（或相应的松紧度投影）的差：

$$x_{1OTH} = x_1 - x_2 = (u + v)t - v\tau - (u + v)(t - \tau) = u\tau,$$

$$y_{1OTH} = y_1 - y_2 = \frac{gt^2}{2} - \frac{g(t - \tau)^2}{2} = g\tau - \frac{g\tau^2}{2},$$

$$v_{1OTH} = v_{1x} - v_{2x} = (u + v) - (u + v) = 0,$$

$$v_{1OTH} = v_{1y} - v_{2y} = gt - g(t - \tau) = g\tau.$$

因此，两次射击后，抛射体以相同的速度水平移动，因此它们之间的距离不会改变并保持等于 $x_{1OTH} = u\tau$。在垂直方向上，第一个弹丸借助$v_{1OTH} = g\tau$相对于第二个弹丸移动，因此弹丸之间的距离根据$y_{1OTH} = g\tau - g\tau^2/2$定律随水流变化。
