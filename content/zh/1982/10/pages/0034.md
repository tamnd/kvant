⟦folio 32⟧

M742。在 a) 圆上，b) 半径为 1 的球体上有 n 个点。证明它们之间的两两距离的平方和不大于$n^2$。

M743。全国有N个城市。 a) 任意两个城市之间有飞机或轮船直接通信。证明仅使用一种交通方式，您可以从任何城市到达任何其他城市（也许需要转乘）。 b) 任意两个城市之间有飞机、火车或轮船直接交通。证明您可以选择至少 N/2 个城市和三种交通方式之一，以便使用其中一种，您可以从任何选定的城市到达任何其他选定的城市。 c) 举例证明b)中的数字N/2不可能被更普遍地代替。

图 1.

a), b) 令 $O$ 为给定圆（球体）的中心，$X_1, X_2, \dots, X_n$ 为给定点，$\vec{x}_i = \vec{O}X_i$ ($i=1, 2, \dots, n$)，$s$ 为点之间成对距离的平方和。那么，从$|X_iX_j|^2 = (\vec{x}_j - \vec{x}_i)^2$开始，

$$2s = (\vec{x}_1 - \vec{x}_1)^2 + (\vec{x}_1 - \vec{x}_2)^2 + \dots + (\vec{x}_1 - \vec{x}_n)^2 +$$

$$+ (\vec{x}_2 - \vec{x}_1)^2 + (\vec{x}_2 - \vec{x}_2)^2 + \dots + (\vec{x}_2 - \vec{x}_n)^2 + \dots +$$

$$+ (\vec{x}_n - \vec{x}_1)^2 + (\vec{x}_n - \vec{x}_2)^2 + \dots + (\vec{x}_n - \vec{x}_n)^2 =$$

$$= 2n(\vec{x}_1^2 + \vec{x}_2^2 + \dots + \vec{x}_n^2) -$$

$$-2[(\vec{x}_1\vec{x}_1 + \vec{x}_1\vec{x}_2 + \dots + \vec{x}_1\vec{x}_n) + (\vec{x}_2\vec{x}_1 + \vec{x}_2\vec{x}_2 + \dots +$$

$$\dots + \vec{x}_2\vec{x}_n) + \dots + (\vec{x}_n\vec{x}_1 + \vec{x}_n\vec{x}_2 + \dots + \vec{x}_n\vec{x}_n)] =$$

$$= 2n(\vec{x}_1^2 + \vec{x}_2^2 + \dots + \vec{x}_n^2) - 2\vec{x} \cdot \vec{x},$$

其中$\vec{x} = \vec{x}_1 + \vec{x}_2 + \dots + \vec{x}_n$。因此$s = n^2 - |\vec{x}|^2 \leq n^2$，当且仅当$\vec{x}_1 + \vec{x}_2 + \dots + \vec{x}_n = \vec{0}$时才实现平等。

点 $X_i$ 之间的成对距离平方和的所得公式是一个非常特殊的拉格朗日公式，用于精确质量系统的所谓“惯性矩”。有关转动惯量、拉格朗日公式及其在几何中的应用的更多信息，可以阅读 M. Balk 和 N. Grigoriev 的文章“力学有助于几何”（«Kvant»，1973 年，第 11 期）和 Z. Skopets“两个点系统的中心之间的距离”（«Kvant»，1975 年，第 3 期）。

a) 该命题可以通过$N$的归纳法轻松证明。对于两个城市来说这是显而易见的。让我们对 $N+1$ 个城市进行证明，假设对于 $N$ 个城市也是如此。

令$\Gamma$为$N+1$城市之一，则根据归纳假设，其余$N$城市通过一种交通方式连接，例如通过水路。如果这$N$城市中至少有一个与$\Gamma$城市有直接联系，那么一切就清楚了。否则，这些城市与城市$\Gamma$有飞机连接，因此也与其中任何其他城市有飞机连接（在$\Gamma$转机）。

b) 让我们将问题重新表述如下：

给定 $N$ 点，每两个点由红色、黑色或黑色线段连接。如果可以通过仅查看红色（蓝色或黑色）段来绕过其中一些点，我们会说其中一些点形成红色（蓝色或黑色）连接。很容易证明可以选择包含比$A$更多的点的连接词，并且$C \cup D$是黑色连接词。由于连接词$A = A_0 \cup C$和$B = B_0 \cup C$中的点数不小于连接词$C \cup D$中的点数，因此集合$A_0$和$B_0$不为空。因此，所有数据$N$点被分为两个束$A_0 \cup B_0$和$C \cup D$。然而，其中必须至少包含$N/2$个点，这与最大连接词$A$中的点数小于$N/2$的事实相矛盾。

由此产生的矛盾证明了6）。
