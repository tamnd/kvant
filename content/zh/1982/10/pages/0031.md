M739 — M745; F748 — F757

M739。证明对于左侧有意义的任何 $x$ 值，等式成立

$$\begin{align*}
tg x + tg \left( x + \frac{\pi}{3} \right) + \\
+ tg \left( x + \frac{2\pi}{3} \right) &: \begin{align*}
tg x \times \\
\times tg \left( x + \frac{\pi}{3} \right) \times \\
\times tg \left( x + \frac{2\pi}{3} \right) \end{align*}
= -3;
\end{align*}$$

$$\begin{align*}
tg x + tg \left( x + \frac{\pi}{n} \right) + \dots \\
\dots + tg \left( x + \frac{(n-1)\pi}{n} \right) &: \begin{align*}
tg x \cdot tg \left( x + \frac{\pi}{n} \right) \times \dots \\
\dots \times tg \left( x + \frac{(n-1)\pi}{n} \right) \end{align*}
= c_n
\end{align*}$$

食物$n$是奇数，$n > 0$，$c_n$是常数（取决于$n$）。
c) 为每个奇数 $n$ 找到 $c_n$。

a) 输入$tg x = z$、$tg(\pi/3) = \sqrt{3} = t$，然后输入$tg(2\pi/3) = -t$。使用总和的正切公式，我们得到（在 $zt \neq \pm 1$）

$$\begin{align*}
tg x + tg \left( x + \frac{\pi}{3} \right) + tg \left( x + \frac{2\pi}{3} \right) &= \frac{z + \frac{z+t}{1-zt} + \frac{z-t}{1+zt}}{z \cdot \frac{z+t}{1-zt} \cdot \frac{z-t}{1+zt}} = \\
&= \frac{z (1-z^2 t^2) + 2z + 2zt^2}{z (z^2-t^2)} = \frac{-3z^3 + 9z}{z^3 - 3z} = -3.
\end{align*}$$

6) 使用归约公式$tg(x+\pi) = -tg(\pi-x) = tg x$和奇数$n$，很容易验证分数的分子和分母

$$f(x) = \frac{tg x + tg \left( x + \frac{\pi}{n} \right) + \dots + tg \left( x + \frac{n-1}{n}\pi \right)}{tg x \cdot tg \left( x + \frac{\pi}{n} \right) \cdot \dots \cdot tg \left( x + \frac{n-1}{n}\pi \right)} = c_n$$

在区间 [0; 的相同点处转向 0 $\pi$ [: 0, $\frac{\pi}{n}$, $\frac{2\pi}{n}$, ..., $\frac{n-1}{n}$ $\pi$（并失去其含义 - “转向无穷大” - 也在相同的点$\frac{\pi}{2n}$，$\frac{3\pi}{2n}$，...，$\frac{2n-1}{2n}$ $\pi$，我们进一步将其排除在考虑之外）。让我们输入 $tg x = z$、$tg \pi/k = t_k$ ($k=0, 1, \dots, n-1$)。分数$f(x)$的分子和分母可以通过将$tg(x+\pi/k/n)$替换为$(z+t_k)/(1-zt_k)$来表示，作为$z$多项式的比率：

$$z + \frac{z+t_1}{1-zt_1} + \dots + \frac{z+t_{n-1}}{1-zt_{n-1}} = \frac{S_1(z)}{R(z)},$$

$$z \cdot \frac{z+t_1}{1-zt_1} \cdot \dots \cdot \frac{z+t_{n-1}}{1-zt_{n-1}} = \frac{S_2(z)}{R(z)},$$

其中 $R(z) = (1-zt_1) \dots (1-zt_{n-1})$，并且多项式 $S_1(z)$ 和 $S_2(z)$ 的次数为 $n$ 且具有相同的根 $t_0=0$、$t_1$、$t_2$、...、$t_{n-1}$。分数 $f(x)$，即 $S_1(z)/S_2(z)$，是一个常数，这一事实可以直接从以下引理得出：

引理。如果次数为 $n$ 的多项式 $az^n + bz^{n-1} + \dots + d = p(z)$ 有 $n$ 个不同的根 $z_0$、$z_1$、...、$z_{n-1}$，则它仅有效等于 $a(z-z_0)(z-z_1) \dots (z-z_{n-1})$。

引理的证明可以通过多项式$p(z)$的次数$n$归纳来验证。对于$n=1$，很明显：$az+b=a(z-z_0)$，其中$z_0=-b/a$。令 $p(z)$ 为 $n+1$ 次多项式，首项系数为 $a$，根为 $z_0$、$z_1$、...、$z_{n-1}$。然后是$p(z)=p(z)-p(z_n)=az^n+bz^{n-1}+\dots+d-(az_n^n+bz^{n-1}+\dots+d)=a(z^n-z_n^n)+b(z^{n-1}-z_n^n)+\dots=(z-z_n)^q(z)$，其中$q(z)$是一个新多项式，其前导系数为$a$，根为$z_0$，$z_1$，...，$z_{n-1}$。由归纳假设$p(z)=(z-z_0)\cdot a(z-z_0)(z-z_1)$。 $\dots(z-z_{n-1})=a(z-z_0)(z-z_1)\dots(z-z_{n-1})$，即引理的陈述对于$n+1$次数的多项式也成立。 （证明使用了身份

$$z^k-a^k=(z-a)(z^{k-1}+z^{k-2}a+\dots+z a^{k-2}+a^{k-1}),$$

由此可知$z^k-a^k$可被$z-a$整除。

c) 找到任何具有显着难度的（奇数）$n$ 的常数$c_n$。答案：$c_n=(-1)^{\frac{n-1}{2}}n$，即$c_3=-3$、$c_5=5$、$c_7=-7$等。我们提到的所有解决方案都使用与多项式根相关的消息。
