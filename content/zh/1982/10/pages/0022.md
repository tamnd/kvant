⟦folio 20⟧

为了澄清这个估计，我们引入事件概率的概念。我们感兴趣的事件可能发生的方式数量与同等可能选项总数的比率$p$称为该事件的概率。显然$0 \leq p \leq 1$。

在我们的例子（$n=2, m=10$）中，我们用$p_0$表示零个参与者去喝柠檬水的事件的概率，用$p_1$表示第一个参与者去喝柠檬水的概率。然后$p_0 = \frac{61}{121} \approx 0,504, p_1 = \frac{60}{121} \approx 0,496$。

不难计算出，在$n=2$和$n=3$单手“投掷”的情况下，玩家被选中的机会是相同的，分别等于$\frac{1}{2}$和$\frac{1}{3}$，而在$n=4$$p_0=0,248, p_1=p_3=0,25, p_2=0,252$的情况下。随着$n$的增加，选项的选择变得越来越成功。我们根据以下消息，使用 $n=100$ 的计算机进行了此操作。

让我们用$\Pi_m^n(N)$表示数字$N$的表示量，以整数非负项之和$n$的形式表示，其中每一项都不超过数字$m$（在这种情况下，项顺序不同的表示被认为是不同的！）。我们还用 $\Pi_i$ 表示第 $i$ 个参与者选择的投掷手指方法的数量，$\Pi$ 表示投掷手指选项的总数，$p_i$ 表示选择第 $i$ 个参与者的概率。因此，$p_i = \frac{\Pi_i}{\Pi}$。

数字$\Pi_i$和$\Pi$很容易用$\Pi_m^n(N)$来表示。由于手指投掷的最大可能次数是 $mn$，

$$\Pi = \sum_{k=0}^{mn} \Pi_m^n(k).$$

由于选择权落在第 $i$ 个参与者身上，如果“伸出手指”的数量为 $i+kn$，并且显然是 $k \leq m$（请注意，对于 $N > mn$ $\Pi_m^n(N)=0$），

$$\Pi_i = \sum_{k=0}^{m} \Pi_m^n(i+kn).$$

(1)

数字$\Pi_m^n(N)$可以使用简单的递推公式来计算。我们感兴趣的数字$N$的表示形式数量，其中第一项为0，显然等于$\Pi_m^{n-1}(N)$；第一项为 1 的此类表示的数量等于 $\Pi_m^{n-1}(N-1)$；其中第一项为 2 - $\Pi_m^{n-1}(N-2)$；等等。由于第一项取值 0, 1, 2, ..., $m$, $\Pi_m^n(N) = \Pi_m^{n-1}(N) + \Pi_m^{n-1}(N-1) + \dots + \Pi_m^{n-1}(N-m) = \sum_{k=0}^{m} \Pi_m^{n-1}(N-k)$ (2)

（在这个总和中，neokotryan 项可以等于 0：如果 $N$ 是“小”，那么，从 neokotryan $k$ 开始，可能是 $N-k<0$ - 然后 $\Pi_m^{n-1}(N-k)=0$；另外，如果 $N$ 是“大”，那么，直到 neokotryan $k$，可能是 $N-k>m$ ($n-1$) - 然后还有$\Pi_m^{n-1}(N-k)=0$)。

计算出所有$0 \leq k < N$的$\Pi_m^2(k)$后，我们然后使用（2）找到$\Pi_m^3(N)$，依此类推。

关系式（2）还允许我们证明$n=m+1$所有参与者的机会是平等的。真的吗，

$$\Pi_i = \sum_{k=0}^{m} \Pi_m^n(i+kn) = \sum_{k=0}^{m} \left[ \Pi_m^{n-1}(i+kn) + \right. + \left. \Pi_m^{n-1}(i+kn-1) + \right. + \dots + \left. \Pi_m^{n-1}(i+kn-m) \right] = \sum_{k=0}^{m} \left\{ \Pi_m^n(i+km+k) + \right. + \left. \Pi_m^n(i+km+k-1) + \right. + \dots + \left. \Pi_m^n(i+km+k-m) \right\}.$$

每个 $k$ 的“大括号”看起来像

$$\Pi_m^n(a) + \Pi_m^n(a-1) + \Pi_m^n(a-2) + \dots$$

原来“大括号”与$k$相邻“连接”：与$k=t$的“大括号”中第一项等于$\Pi_m^n(i+tm+t)$，最后一项弱
