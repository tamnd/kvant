什么是波？

当向水中扔石头时，观察它们形成的圆圈；否则这样的投掷将是空洞的乐趣。
科兹马·普鲁特科夫。水果部分

波的概念对我们来说似乎很有趣，我们直观地将它与某种运动联系起来。如果我们把一块石头扔进水里，水面就会产生波浪。但如果此时有一根树枝漂浮在水面上，那么我们会注意到它在波的传播方向上根本没有混合，而是上下振荡运动。波传播时什么在移动？让我们看几个例子。

他们说，彼得一世的女儿伊丽莎白皇后希望在新首都圣彼得堡的彼得保罗要塞进行炮火齐射，以纪念她加冕的庄严时刻。根据法律，俄罗斯沙皇的加冕典礼在莫斯科圣母升天大教堂举行。如今，从莫斯科向列宁格勒传输任何信息都很简单：只需发送无线电信号，大炮就会准时开火。那么当族长将王冠戴在皇后头上的那一刻，就需要想出另一种方式来通知。

从莫斯科大教堂到圣彼得堡要塞的整个路线（约650公里），士兵之间的部署距离为直接可视距离（约100 m）。为此，很容易计算，她增加了大约6500名士兵。每个士兵手里都拿着一面旗帜。加冕的那一刻，第一个士兵挥舞着旗帜，下一个士兵也重复了他的动作，然后是其他人。人类的反应时间是十秒，因此，10-20分钟后，有关加冕的已知信息应该到达彼得保罗要塞的炮兵那里。

是什么从莫斯科搬到了圣彼得堡？每个士兵都站在自己的位置上。他唯一做的就是挥舞旗帜。用科学的语言来说，我们可以说，通过举起和放下手中的旗帜，他改变了他的状态一段时间。这种状态的变化沿着士兵的链条移动。

空间中状态变化的变量称为波。

1905年，圣彼得堡爆发了罢工，随后印出一封信，罢工浪潮蔓延到整个俄罗斯，并到达最远的边境。在这种情况下，工人辞去工厂工作并提出政治和经济要求的情况蔓延开来。

这是谣言如何传播的一个例子。众所周知，哪怕是一个人发出的谣言，也能在短时间内传遍整座城市。这明显少于此人拜访（或呼叫）城市中所有人所需的时间。很明显，听力携带者本身可能无法混合。照明状态将是混合的。这正是他们所说的——一股谣言正在整个城市蔓延。

最后让我们看一个物理例子。台球桌上有一排球链（图1，a）。另一个球击中它，使其速度沿着链条移动。撞击后，球将离开，最后一个球将弹开（图1，b）。我们向第一个球传递动量，最后一个球接收它。发生这种情况是因为变形波沿着球链传播。撞击后，第一个球被压扁，并使相邻的球、下一个球变形，以此类推。左侧和右侧的任何中间球都受到大小相等但方向相反的弹力作用（图1，c），并且它保持在原位。仅作用在一侧的弹力向最后一个球施加冲击力，使其反弹。

这种在弹性介质中传播的变形波称为声波。结果，由于撞击，声波穿过球链。它可以在任何弹性体中传播。例如，如果用锤子从一端敲击一根固定杆（图2，a），则变形波（声波）将沿着杆传播。当该波到达杆的另一端时，那里最高的球将弹开（图2，b）。同样，您可以在液体或气体中激发声波，当然，使用活塞而不是锤子更方便。

让我们尝试找出声波在弹性体中传播的机制。特别是，我们将找出波传播速度取决于什么。首先，我们来解决弹性体模型的简化问题。我们假设有一整套质量为 $m$ 的球，由刚度为 $k$ (图 3) 的弹簧连接。与球相比，球的尺寸较小

它们之间的距离，并且与球的质量相比，弹簧的质量可以忽略不计。本质上，这是同一条胆球链，我们在其中“分离”了惯性（质量）和弹性（刚度）。

该模型已接近在实体中实现。在晶格中，原子的排列方式使得在平衡状态下，所有其他原子作用在每个原子上的力的矢量和等于零。当原子偏离平衡位置时，会产生张力和排斥力，类似于弹力*)。

让我们给一些球，例如左边的第一个球，沿着链条施加一个脉冲（推动它）。然后，就像胆球的例子一样，弹性变形波将沿着链条传播，一段时间后将到达链条的右端。由于最后一个球通过弹簧连接到链条上，因此它根本无法弹开。拉伸的弹簧将迫使其返回，然后，由于其惯性，球将缩回弹簧。现在变形波将从右向左传播。在这种情况下，他们说波从链的末端反射并开始沿相反方向传播。出于同样的原因，它会从另一端反射回来等等。这些反射波是我们考虑的条件，为了摆脱它们，我们会考虑一条“无限”（即没有末端）的链。它可以通过将大量球组成的链封闭成一个环（图4）来实现。沿着这样一条“无限”的链条，弹性变形的波会绕圈移动，不会产生反射，直到消失。

*) 在原子之间距离较远时，主要作用是张力，在距离较近时，主要作用是排斥力（量子力学禁止原子相互刺穿）。仅在某个平衡距离（大约等于原子的大小）处，原子之间的相互作用力才变为零。

让其中一个球偏离其平衡位置（例如，顺时针扫动它）并释放它。然后，在与之相连的弹簧的作用下，球在空间中的位置就会周期性地改变。这种运动称为振荡。

振动在自然和技术中发挥着重要作用。时钟中的摆锤进行振荡运动；家用电器中，电流、电压波动；昼夜、季节的变化也是地球运动引起的振荡过程。全旋转机构会引起基础振动，设计时必须考虑到这一点。

最简单的振荡运动是简谐振动，当物体偏离平衡位置的位移按照规律随时间变化时

$$\alpha = \alpha_m \sin(2\pi t/T) = \alpha_m \sin 2\pi vt = \alpha_m \sin \omega t,$$

其中，对于摆动链，$\alpha$ 是球相对于平衡位置的角度偏差。如您所见，简谐振动由两个量（参数）来表征：最大偏差（振幅）$\alpha_m$和振荡周期$T$（振荡完全重复的时间间隔）。频率v等于单位时间内振荡的次数，引入循环频率$\omega = 2\pi v$是为了简化振荡运动的数学记录，而值$\varphi = \omega t$决定了球在给定时间$t$的位置，称为振荡相位。

让我们举个例子。让小球在$T = 4$s时间内进行一次完整的振荡；初始时刻处于平衡位置，最大偏差为$\alpha_m = 0,1$rad。然后，如果它执行简谐振动，则偏差对时间的依赖性由以下公式给出

$$\alpha = 0,1 \sin(\pi t/2).$$

波长越短，到达相邻球的相位偏移就越大。当相邻球之间的相移等于 n 时，出现最大“差异”。在这种情况下，球反相振荡 (图 6)，并且对应于长度 $\lambda_{\min} = 2a$。

让我们计算对应于最小波长的振荡发生的频率（这使我们能够估计波在链中传播的速度）。如果我们假设中间的球按照规律振荡
$$\alpha_n = \alpha_m \sin \omega t$$
那么前一个球的振动由以下公式描述
$$\alpha_{n-1} = \alpha_m \sin (\omega t + \pi),$$
以及随后的一个——
$$\alpha_{n+1} = \alpha_m \sin (\omega t - \pi).$$

知道弹簧两端如何移动，就很容易发现它们的变形如何随时间变化，并使用胡克定律$F = kx$来计算作用在中间球上的弹力。合力
$$F = kx_m (\sin (\omega t - \pi) - \sin \omega t) + \sin (\omega t + \pi) - \sin \omega t) = -4kx_m \sin \omega t$$
其中$x_m = R\alpha_m$是球的最大线性偏差（$R$是链条闭合的球的半径）。正如您所看到的，中间的球就像连接到单个弹簧一样振荡，但刚度增加了四倍。将$k_0 = 4k$值代入公式（*），我们发现最小长度$\lambda_{\min} = 2a$的波沿链传播时，振荡频率为$\omega = 2\sqrt{k/m}$。这是闭合链中球的最大振动频率。

因此，固体也具有原子振动的最大频率。

波的传播速度是多少？如果振荡频率为$\omega$，则其周期为$T = 2\pi/\omega$。以传播速度 $v$，波在时间 $T$ 内传播 $l = vT = 2\pi v/\omega$。该路径等于波长，因为时间偏移 $T$ 周期，振荡将同相发生。因此，
$$\lambda = vT = 2\pi v/\omega,$$
因此
$$v = \frac{\lambda \omega}{2\pi} = \frac{2}{\pi} a \sqrt{\frac{k}{m}}.$$

较长波的传播速度和振荡频率是多少？例如，可以用相同的方式对它们进行计数（尽管这是一个稍微困难的任务）。事实证明，随着波长的增加，振荡频率降低，波的传播速度增加，但只是略有增加。对于长波长 ($\lambda \gg a$)，传播速度变得恒定并且等于
$$v_0 = a \sqrt{\frac{k}{m}}.$$

因此，我们以良好的精度导出的表达式给出了波在其他波长的连接球链中的传播速度。

让我们回到固体。声波在其中的传播速度由什么决定？通过对一串球进行分析，我们可以了解到速度取决于材料的弹性特性、构成该物质的原子的质量以及它们之间的距离。原子之间的距离越小，质量越大，物质的密度$q$就越大。我们模型中的刚度 $k$ 可以认为是成比例的

$$v = \sqrt{\frac{E}{\rho}}.$$

例如，对于钢，使用此公式我们可以得到 $v \approx 5000$ m/s。因此，我们能够理解声音在弹性体中传播的现象，即构成这些物体的原子位移振荡的传播。

其他物理量的振动也可以在空间中传播。如果电场强度和磁场强度的值周期性变化，则表示电磁波正在传播。温度波动可以传播——温度波，物质中磁场感应的波动——磁化波等等。形象地说，现代物理学的整个大厦都充满了不同类型的波。

应用

让我们想象一下，枪放在沿环直径 (图 7) 的杆 AB 上。弹簧的一端连接到球，另一端固定在杆 A 的边缘。球可以沿着杆自由移动，在平衡状态下位于环 O 的中心。让我们以角速度 $\omega_0$ 在水平面中旋转木桩。然后球就会脱离中心。如果其位移等于 $r$，则根据胡克定律，从弹簧一侧将向球施加等于 $F = k_0 r$ 的力，并指向环的中心。根据牛顿第二定律，该力必须产生向心加速度 $a_ii = \omega_0^2 r$：

$$m\omega_0^2 r = k_0 r.$$

因此，为了使环旋转时球处于稳定状态，需要旋转速度等于$\omega_0 = \sqrt{k_0/m}$。

在这种情况下，球在固定轴上的投影执行简谐振动，其循环频率等于旋转角速度。例如，$x = r \sin \omega_0 t$。因此，质量球$m$外部刚度$k_0$的简谐振动频率由以下公式确定

$$\omega_0 = \sqrt{\frac{k_0}{m}}.$$
