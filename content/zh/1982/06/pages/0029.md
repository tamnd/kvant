⟦folio 27⟧

由于第 $m$ 个数据包的前 $b_m$ 数字之和等于
$(2b_m + 1) + (4b_m + 1) + \dots + (2b_m^2 + 1) = b_m^3 + b_m^2 + b_m > b_m^3 + 1,$
也就是说，大于第$m$个数据包的最大数，因此大于$a$，我们得到$k < b_m$。
这就是为什么
$$r = k + (d_1 + \dots + d_l) < b_m + (d_1 + \dots + d_l) < 2b_m.$$
但是$a - r = (c_1 + \dots + c_k) - k = (c_1 - 1) + \dots + (c_k - 1)$。由于第$m$个数据包中的每个数字除以$2b_m$时余数为1，因此数字$c_1 - 1, c_2 - 1, \dots, c_k - 1$可被$2b_m$整除，因此$a - r$可被$2b_m$整除。由于本例中$r < 2b_m$，$r$等于$a$除以$2b_m$的余数，即$r = 1$；意味着$k + d_1 + \dots + d_l = 1$，这是不可能的。从这里我们得出结论，所构造的序列 $(a_n)$ 中没有一个成员等于其他几个成员的总和。

现在让我们检查 $a_n \leq 100n^{7/2}$ 对于任何 $n$。
在 $n = 1$ 时，这是显而易见的。如果$a_n$在第二个数据包中，则$a_n \leq 1001 < 100 \cdot 2^{7/2} \leq 100n^{7/2}$。让$a_n$位于第$m$个数据包和$m \geq 3$中。我们将$a_m$表示为$2kb_m + 1$($1 \leq k \leq b_m^2/2$)，距离分两种情况。
$1^\circ$. $k \leq b_m^2 - 1$.
然后
$$a_n \leq 2b_m^2 - 1b_m + 1 < 3b_m^2 - 1b_m = 3b_m - 1 = 3 \cdot 2^{7/2} \cdot (b_m^2 - 1/2)^{7/2}.$$
但是$b_m^2 - 1/2 < n$，因为$b_m^2 - 1/2$是第$(m - 1)$个数据包中的项数。因此$a_n \leq 3 \cdot 2^{7/2} \cdot n^{7/2} < 100n^{7/2}$。
$2^\circ$. $k > b_m^2 - 1$.
显然，第$m$个数据包中$a_n$的数量没有超过其在序列中的数量，即$k \leq n$。这就是为什么
$$a_n = 2kb_m + 1 < 3kb_m = 3k(b_m^2 - 1)^{5/2} < 3k \cdot k^{5/2} \leq 3n^{7/2}.$$
因此，对于所有$n$，不等式$a_n \leq 100n^{7/2}$都得到证明。 $n = 1$和$n = 2$的不等式$a_n \leq n^{10}$可以直接验证，而对于$n > 2$则可以得出以下事实：
$$a_n \leq 100n^{7/2} < 3^{13/2} \cdot n^{7/2} \leq n^{13/2} \cdot n^{7/2}.$$
为了节省空间，我们没有给出提供问题 c) 解决方案但不解决问题 d) 的更简单的序列示例。
e) 这个问题的答案是否定的：这样的序列不存在。

让我们证明序列 $(a_n)$ 中的至少一项使得所有 $n = 1, 2, \dots$ 的 $a_n < 100n^{3/2}$ 等于其他几项之和。 （当然，这里的数字100可以用任何常数代替；我们证明中的指数3/2要求它小于$(\sqrt{5} + 1)/2$）。

考虑一个具有 $10^{30}$ 行和 $10^{18}$ 列的直头表。让我们将 $10^{30} + 1$ 到 $2 \cdot 10^{30}$ 的数字分配给它的行，将 1 到 $10^{18}$ 的数字分配给它的列。在第$n$行和第$k$列的交叉处，我们写下数字$c_{n,k} = (a_1 + a_2 + \dots + a_k) + a_n$。不超过$a_1 + \dots + a_{10^18} + a_2 \cdot 10^{30} \leq 100 + 100 \cdot 2^{3/2} + \dots + 100 \cdot (10^{18})^{3/2} + 100 \cdot (2 \cdot 10^{30})^{3/2} < 100 \cdot (10^{18})^{3/2} \cdot 10^{18} + 100 \cdot (10^{30})^{3/2} \cdot 2^{3/2} = 10^{47} + 10^{47} \times 2^{3/2} < 4 \cdot 10^{47}$。

由于该表包含 $10^{48}$ 个数字，每个数字都可以小于 $4 \cdot 10^{47}$ 个值，因此这些数字中的任何两个都重合。例如，$c_{n,k} = c_{m,l}$。由于第 $n$ 行中所有数字都是不同的，$n \neq m$。我们可以假设$n > m$（$m > n$的情况类似）。等式 $c_{n,k} = c_{m,l}$ 意味着
$$(a_1 + \dots + a_k) + a_n = (a_1 + \dots + a_l) + a_m,$$
从那里$k < l$和$a_n = (a_{k+1} + \dots + a_l) + a_m$。由于在这种情况下$l \leq 10^{18} < m$，我们得到$a_n$表示为序列的其他几项之和。

当然，$(\sqrt{5} + 1)/2$和$7/2$之间的差距还是相当大的。也许一位读者设法缩短了它。显然，对于 shizu 来说，比 $C \cdot n^{(\sqrt{5} + 1)/2}$ 更好的分数尚不清楚。

正如匈牙利数学家 P. Erdős 告诉我们的那样，他曾经也研究过数列 $(a_n)$ 的问题，其中没有一个数等于某些数之和。
