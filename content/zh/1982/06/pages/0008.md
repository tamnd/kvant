图 6.

链中的空间，长度为$\lambda_1 = L$。下一个较短的波，$\lambda_2 = L/2$，下一个$\lambda_3 = L/3$，等等。可以在链中传播的最短波是多少？

波长越短，到达相邻球的相位偏移就越大。当相邻球之间的相移等于 n 时，出现最大“差异”。在这种情况下，球反相振荡 (图 6)，并且对应于长度 $\lambda_{\min} = 2a$。

让我们计算对应于最小波长的振荡发生的频率（这使我们能够估计波在链中传播的速度）。如果我们假设中间的球按照规律振荡
$$\alpha_n = \alpha_m \sin \omega t$$
那么前一个球的振动由以下公式描述
$$\alpha_{n-1} = \alpha_m \sin (\omega t + \pi),$$
以及随后的一个——
$$\alpha_{n+1} = \alpha_m \sin (\omega t - \pi).$$

知道弹簧两端如何移动，就很容易发现它们的变形如何随时间变化，并使用胡克定律$F = kx$来计算作用在中间球上的弹力。合力
$$F = kx_m (\sin (\omega t - \pi) - \sin \omega t) + \sin (\omega t + \pi) - \sin \omega t) = -4kx_m \sin \omega t$$
其中$x_m = R\alpha_m$是球的最大线性偏差（$R$是链条闭合的球的半径）。正如您所看到的，中间的球就像连接到单个弹簧一样振荡，但刚度增加了四倍。将$k_0 = 4k$值代入公式（*），我们发现最小长度$\lambda_{\min} = 2a$的波沿链传播时，振荡频率为$\omega = 2\sqrt{k/m}$。这是闭合链中球的最大振动频率。

因此，固体也具有原子振动的最大频率。

波的传播速度是多少？如果振荡频率为$\omega$，则其周期为$T = 2\pi/\omega$。以传播速度 $v$，波在时间 $T$ 内传播 $l = vT = 2\pi v/\omega$。该路径等于波长，因为时间偏移 $T$ 周期，振荡将同相发生。因此，
$$\lambda = vT = 2\pi v/\omega,$$
因此
$$v = \frac{\lambda \omega}{2\pi} = \frac{2}{\pi} a \sqrt{\frac{k}{m}}.$$

较长波的传播速度和振荡频率是多少？例如，可以用相同的方式对它们进行计数（尽管这是一个稍微困难的任务）。事实证明，随着波长的增加，振荡频率降低，波的传播速度增加，但只是略有增加。对于长波长 ($\lambda \gg a$)，传播速度变得恒定并且等于
$$v_0 = a \sqrt{\frac{k}{m}}.$$

因此，我们以良好的精度导出的表达式给出了波在其他波长的连接球链中的传播速度。
