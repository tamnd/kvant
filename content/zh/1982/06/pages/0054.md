（开头部分请参见第 38 页）

这次我们将使用垂直于 $(BC_1D)$ 的向量和向量 $\overrightarrow{BD}_1$ 之间的角度 $\beta$ 找到所需的角度 $\alpha$。根据定义（“几何 9-10”，第 37 节）$0^\circ \leq \alpha \leq 90^\circ$。显然（第 39 页上的图 3），$\alpha = 90^\circ$ - $\beta$ 或$\alpha = 90^\circ$ - $(180^\circ$ - $\beta)$ = $\beta$ - $90^\circ$。因此$\sin \alpha = |\cos \beta|$。回答。弧$\sin \frac{\sqrt{6}}{9}$。

问题 9（MEPhI，1981）。平面$\alpha$和$\beta$的方程为$2x + 3y + 4z - 8 = 0$和$4x + y + 3z - 6 = 0$、$p = \alpha \cap \beta$。 a) 确定直线$p$与平面$xOy$、$yOz$的交点坐标。 b) 确定直线$p$ 和平面$xOz$ 之间的数量。

点$A = p \cap xOy$的坐标就是系统的解
$$\begin{cases}
2x + 3y + 4z - 8 = 0 \\
4x + y + 3z - 6 = 0 \\
z = 0.
\end{cases}$$

点$B = p \cap yOz$的坐标——系统解
$$\begin{cases}
2x + 3y + 4z - 8 = 0 \\
4x + y + 3z - 6 = 0 \\
x = 0.
\end{cases}$$

现在，如果 $\alpha$ 是所需的角度，$\beta$ 是向量 $\overrightarrow{AB}$ 和 $\overrightarrow{n} = (1; 0; 1)$ 之间的角度，则 $\sin \alpha = |\cos \beta|$。回答。 a) $A(1; 2; 0)$、$B(0; 0; 2)$。 b) 弧$\sin \frac{2}{3}$。
