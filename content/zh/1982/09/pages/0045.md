考虑区间 $\varphi_0 \leqslant \varphi \leqslant \pi + \varphi_0$ 上的函数 $L(\varphi)$，其中 $L(\varphi_0) \neq L$。在这种情况下，数字$p$、$q$和$m$不会改变（点0和π必须算作1）。所以$m$是偶数。

让我们证明$p = q$。让我们将直线 $y = L$ 向上移动距离 $\varepsilon$ (图 2)。如果$\varepsilon$足够小，那么函数$L(\varphi)$的图形与直线$y = L$的交点的每个“目标”点将在直线$y = L + \varepsilon$上有一个“目标”点，每个$q$最小点将“分裂为两个”，并且最大点将消失。图形和直线的交点总数将等于$m + 2q$，并且由于它不能增加，因此$m + 2q \leqslant m + p + q$，即$q \leqslant p$。同理，证明$q \geqslant p$。因此，$p = q$，而$m + p + q$是偶数。

c) 考虑 $\triangle ABC$。让 $c$ - 他的最侧面， $c \geqslant b \geqslant a$ （有关符号，请参见 图 3）。报春花 $l_0$ 垂直绘制边 $AB$。三角形高的方向 $ABC$ 对应值 $\varphi = 0$, $\varphi = \alpha$ 和 $\varphi = \pi - \beta$。因此，在该段 $0 \leqslant \varphi \leqslant \alpha$ 三角形到直线的投影 $l_\varphi$ 与侧面的投影重合 $BC$， 那是 $L(\varphi) = L_a(\varphi) = a \left| \cos \left( \varphi - \left( \frac{\pi}{2} - \beta \right) \right) \right|$，在段上 $[\alpha; \pi - \beta]$ - 带侧面投影 $AB: L(\varphi) = L_c(\varphi) = c \left| \cos \varphi \right|$，并且在段上 $[\pi - \beta; \pi]$ - 带侧面投影 $AC: L(\varphi) = L_b(\varphi) = b \left| \cos \left( \varphi - \left( \frac{\pi}{2} + \alpha \right) \right) \right|$.

如果三角形是钝角三角形或矩形，那么 $\alpha + \beta = \pi - \gamma \leqslant \frac{\pi}{2}$，因此，很容易检查，函数的最大点 $L_a(\varphi)$ 和 $L_b(\varphi) - \frac{\pi}{2} - \beta$ 和 $\frac{\pi}{2} + \alpha$ 落入段 $[\alpha; \pi - \beta]$, 其上 $L(\varphi) = L_c(\varphi)$。在这种情况下，函数 $L(\varphi)$ 该段的第一个回报 $[0; \frac{\pi}{2}]$ 从 $h_c$ 到 $c$然后杀掉 $c$ 到 $h_c$ (图 4).

每个值的取值不超过两次。如果$\triangle ABC$是锐角，则$a + \beta > \frac{\pi}{2}$以及函数$L_a(\varphi)$和$L_b(\varphi)$的最大值落在线段$[0; \alpha]$和$[\pi - \beta; \pi]$内。因此，函数 $L(\varphi)$ 具有三个最大值和六个单调区间 (图 5)。从$h_c \leqslant h_b < a \leqslant b \leqslant c$开始，区间$h_b; a$中的任何值[函数$L(\varphi)$至少需要四次——在单调性的前三个和最后一个区间（参见图5）。我们还要注意，如果 $h_a < a$，则区间 $h_a; a$ 中的任何值都会被取六次 - 在函数 $L(\varphi)$ 的每个单调区间上取一次。

V·普拉索洛夫

◆ 以最小初速度$v_0$抛出的石子，足以使石子飞过墙壁，其轨迹如图所示，在A点和B点，轨迹接触到墙壁的边缘；石头在 A 点的速度 $v$ 与地平线形成$\alpha = 45^\circ$ 角。石头从A点飞到B点的时间$t$由条件决定
$$v_y = v \sin \alpha = gt/2 \Rightarrow t = 2v (\sin \alpha)/g.$$

速度$v$的大小与钝角壁$l$有对应关系
$$l = v_x t = 2v \cos \alpha \cdot v (\sin \alpha)/g = v^2/g \Rightarrow v = \sqrt{gl}.$$

根据能量守恒定律可以找到$v_0$和$v$之间的联系：
$$\frac{mv_0^2}{2} + mgh = \frac{mv^2}{2} + mgH,$$
在哪里
$$v_0 = \sqrt{v^2 + 2g(H - h)} = \sqrt{g(l + 2H - 2h)}.$$
