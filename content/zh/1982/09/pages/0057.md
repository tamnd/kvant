第二个抛物线位于 $A$ 和 $B$ 之间的部分上有一点，整个部分位于横坐标轴上。

现在让抛物线有一个公共点，并且该点的路径位于 x 轴下方。由于它位于 x 轴下方，因此它位于每个抛物线的根之间。这意味着每个抛物线的一个根位于另一个抛物线“内部”，第二个根位于其“外部”，即根交替。

因此，图 1 上抛物线的位置均匀地散布着根。这三条线在点 $x_0$ 处的值均为负值。让我们写下这个事实，例如，对于前三个长度：$x_0^2 + mx_0 + n < 0$，或者

$$\left(\frac{q-n}{m-p}\right)^2 + m \left(\frac{q-n}{m-p}\right) + n < 0.$$

这是系数 $m, n, p, q$ 之间所需的对应关系。你可以通过它：

$$(q-n)^2 + (m-p)(mq-np) < 0.$$

检查如果在第二个三行中替换 $x_0$ 会发生什么。

$$\begin{cases}
x_1^3 + Ax_1^2 + Bx_1 + C = 0 \\
C = 0 \\
-x_1^3 + Ax_1^2 - Bx_1 + C = 0
\end{cases}$$

从哪里$A = C = 0$;这意味着 $g(x) = x^3 + Bx$ 是一个奇函数。
