函数 $g$ 在点 0 右侧的某个区间上为负（为什么？）。但对于大的$x$（正如数学家所说，“关于平坦度”）$g(x) > 0$。这意味着在点 0 右侧的某处，多项式 $g(x)$（连续函数！）有一个根 $x_1$。由于函数 $g$ 是奇数，因此 $g(-x_1) = -g(x_1) = 0$。因此，多项式 $g(x)$ 有根 $x_1, 0, -x_1$，形成算术级数。这意味着给定多项式 $f(x)$ 的根 $a, \beta, \gamma$ 也形成算术级数。

所以，条件“$g$为奇数且$g'(0) < 0$”，即
$$\begin{cases} A = 0 \\ C = 0 \\ B < 0 \end{cases}$$

形成算术级数的三个根的存在同样是排他性的。
