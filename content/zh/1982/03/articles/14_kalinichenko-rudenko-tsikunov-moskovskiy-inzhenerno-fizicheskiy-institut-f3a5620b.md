数学
笔试

选项1

1. 有铜和银两种合金，第一种合金中铜的百分比（按重量计）比第二种合金高 45%。通过将一块含有6kg铜的第一合金与一块含有12kg铜的第二合金熔合，获得了含有p％铜的铸锭。确定第一种合金中银的百分比。

2. 在正三角形中，取 $SABC |SC| = l$ 且边 $[SC]$ 与底面平面形成大小为 $\alpha$ 的角。在平台高度$[SO]$处，取点$S_1$，使得从该点到顶点$S$和到点$C_1, A_1, B_1$的距离之和为边$[AB], [BC], [CA]$的中点。位于池塘底部的三角形具有最小值。确定洗涤体积$S_1A_1B_1C_1$。

3. 找出 $a \in R$ 不等式成立的所有值

$$\sum_{-1}^{2a} \frac{dx}{x+a} \geq \log_a(2^{\log_2 e}).$$

4. 找到 $f'(x)$ 和函数的临界点

$$f(x) = \frac{2}{3} \sqrt{\sin^3 2x} + x + 0,25 \sin 4x + \ln \frac{1}{3}.$$

选项2

1. 从位于直线路径上的同一点，两个行人代码以不同但恒定的速度同时向同一方向发送。两个小时后，他们之间的距离是$s$公里。此后，行人的行走速度加快，每公里路程减少10分钟。又过了2个小时，两人的距离变成了3公里。确定行人在前 2 小时移动期间所走的路径。

2. 一个正六边形棱柱内接于一个母线$l$、高$H$的直立圆锥体，使得棱柱的下底面位于圆锥底面的平面内，上底面的顶点属于有限曲面。如果已知该棱柱的总表面积是所有可能的最大表面积，则求该棱柱底面积。

3. 计算积分 $I_1 = \int_4^8 \frac{dx}{2x}$ 和 $I_2 = \int_4^{169} \frac{dx}{\sqrt{1-x}}$ 并确定差值 $I_2 - I_1$ 的符号（无需表格的帮助）。

4. 找到 $f'(x)$ 和函数的临界点

$$f(x) = 5x + \ln 2 + \log_2 \sin^3 \frac{x}{3} + 3 \log \frac{1}{2} \left( \sin \frac{4}{3} x - \sin \frac{2}{3} x \right).$$

3. 电容为$C_1 = 20$ µF 和$C_2 = 60$ µF 的电容器分别充电至$U_1$ 和$U_2$ 电压。然后，电容器的负极板与电阻可以忽略不计的导体连接，正极板通过$R = 80$欧姆（图3）的电阻连接。当钥匙$K$闭合时，电阻上流过电流$I = 0,2$A。当电流在电路中流动时，电阻器会释放多少热量？

4. Puukok 质子位于单线磁场区域，指示为 $B = 0,1$ T。磁场方向垂直于束流速度。在这个场中，质子沿着半径为 $r = 0,2$ m 的圆弧移动并落在接地的插头上。求目标中释放的热功率。光束中的电流为 $I = 0,1$ mA。质子的比电荷（荷质比）$e/m = 10^8$ C/kg。
