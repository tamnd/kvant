◆ 平面上的有限点集可以分别有 0、1、2、3 个“几乎对称中心”（参见 图 1, a）。让我们证明平面上的有限集 M 不能有超过三个“几乎对称中心”。

首先，我们注意到集合 M 具有有限数量的“几乎对称中心”，因为它们只能是连接集合 M 的点的线段的中点。现在让我们选择一条直线，在投影时，集合 M 的点及其“几乎对称中心”不会合并。由于投影到一条直线上时，对称中心会回到对称中心，因此足以证明我们对位于同一直线上的有限点集的陈述。

考虑坐标为 $x_1 < x_2 < \dots < x_n$ 的线上的一组点。如果我们扔掉第一个点，那么剩下的集合的对称中心只能是坐标$(x_2 + x_n)/2$的点；如果我们扔掉最后一个，那么只有坐标为$(x_1 + x_{n-1})/2$的点；最后，如果我们扔掉一些非极值点，那么剩下的集合的对称中心只能是坐标$(x_1 + x_n)/2$的点（参见图2；在图2处，我们扔掉了中间点——剩下的集合的对称中心落入其中）。这意味着一条线上的有限点集，以及平面上的任何有限点集，不能有超过三个“几乎对称中心”。

M714。 N个好友同时获知N条新闻，每人获知一条新闻。他们开始互相打电话并交换消息。每次谈话持续一小时。您可以在一次通话中传达尽可能多的新闻。每个人至少需要多少小时才能了解所有新闻？考虑三种情况：a) N=64、6) N=55、b) N=100。

让我们用$T(N)$表示$N$朋友能够交换新闻的最短小时数。有趣的是，函数$T=T(N)$不是单调的。这可以通过查找小 $N$ 的 $T(N)$ 值来发现 - 它们在页边的表格中给出；旁边的图 1处显示了一个方法，可以让$N=4, 5, 6$和8在$T(N)$小时内找到所有新闻。当然，为了解决这个问题，我们不仅要指出一种在$T(N)$小时内交换消息的方法，而且还要证明这不可能在更少的时间内完成——以获得$T(N)$的估计。我们会向她学习。

让我们考虑一个任意的新闻项目。第一个小时之后，认识她的朋友不超过两个，第二个小时之后，认识她的朋友不超过四个，……，之后 $k$点钟——没有了 $2^k$ 朋友们。因此，如果之后 $T$ 所有时间 $N$ 朋友们知道了所有的消息，那么 $2^T \geq N$ 和 $T \geq \log_2 N$。因为 $T$ 是一个整数，那么 $T \geq \log_2 N$。 （这里有十个 $\Gamma a$ 表示不小于的最小整数 $a$。现在，这个名称的使用越来越频繁，特别是在应用数学和计算数学领域；此外，对于一般整数部分 - “向下舍入” - 而不是指定 $[a]$ 使用符号 $[a]$。） 如果 $N$ 是奇数，那么有一个 $N$ 朋友们-让我们用 $A$, - 在第一个小时内不参与对话的人。将上述推理应用于该新闻 $a$，一开始只知道 $A$，我们至少可以交换您需要的所有新闻 $1 + \log_2 N$ 小时。

让我们证明找到的估计

$$T(N) = \begin{cases} \Gamma \log_2 N, & \text{ если } N \text{ четно}, \\ \Gamma \log_2 N + 1, & \text{ если } N \text{ нечетно} \end{cases}$$

是可以实现的，也就是说，我们将证明可以以这样的方式组织新闻交换，即在$T(N)$小时后所有朋友都会知道所有新闻。我们来看三个案例。

1°。最简单的方法就是提出一种在$k$小时内交换$N=2^k$消息的方法。

让我们将一组 $k$ 数字 0 和 1（“二进制数”）与每个晶簇关联起来；从$(0,0, ..., 0)$到$(1,1, ..., 1)$的各种这样的集合只是$2^k$。让号码仅在一个 $t$ 位置不同的一对朋友在第 $t$ 小时互相交谈。那么，如果两个朋友的号码相差$t_1, t_2, ..., t_s$位（$1 \leq t_1 < t_2 < ... < t_s \leq k$），那么通过在$t_1$、$t_2$、...、$t_s$点通话，他们就会知道彼此的消息。 （$N=4$ 和 $N=8$ 的方法如图 1 所示。）

另一种方法适用于任何偶数$N$，在下面的第 3° 点中描述。

M717。给定自然数$n$和$r$，$1 \leq r \leq n$。由 $r$ 个数字组成的 $[1, 2, \dots, n]$ 子集的整个乘法距离，以及每个选择中最小的数字。证明所有选定数字的算术平均值是$\frac{n+1}{r+1}$。 （例如，对于$n=3$、$r=2$，我们得到三个子集$[1, 2], [1, 3], [2, 3]$，算术平均值为$(1 + 1+2)/3 = 4/3$。）

◆ 首先，请注意集合$[1, 2, \dots, n]$ 有$C_n^r = \frac{n!}{r!(n-r)!}$ 个由$r$ 个数字组成的子集。我们将展示数字 $C_n^k$) 的两个属性，我们需要它们来解决我们的问题：
$$1^\circ. C_n^k + C_n^{k+1} = C_n^{k+1};$$
$$2^\circ. C_n^k + C_n^{k-1} + \dots + C_k^k = C_n^{k+1}.$$

我们将由$r$数字组成的集合$[1, 2, \dots, n]$的子集称为$r$子集。很容易说集合$[1, 2, \dots, n]$的$r$子集的最小元素只能是数字1, 2, ..., $(n-r+1)$。此外，数字$k$对于$C_n^{k-1}$这样的子集来说是最小的（事实上，数字$k$是最小元素的每个$r$子集都包含$k$和$r-1$，来自集合$[k+1, k+2, \dots, n]$的元素，由$n-k$元素组成）。因此所有选定数字的总和等于
$$S = 1 \cdot C_n^{r-1} + 2 \cdot C_n^{r-1} + \dots + (n-r+1) C_n^{r-1},$$
(*)

我们需要证明算术平均值$\frac{S}{C_n^r}$（总共有$C_n^r r$子集）等于$(n+1)/(r+1)$，或者$S = C_n^r \cdot (n+1)/(r+1) = C_n^{r+1}$。

利用$C_n^{k-1} = C_n^k - C_n^{k-1}$（参见$1^\circ$）这一事实，我们将总和$S$变换如下：
$$S = 1 \cdot C_n^{r-1} + 2 \cdot C_n^{r-1} + \dots + (n-r+1) C_n^{r-1} =$$
