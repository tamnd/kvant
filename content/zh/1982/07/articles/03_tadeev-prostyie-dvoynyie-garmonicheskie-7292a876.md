简单、双重、和谐

现在没有人确切知道 1640 年 17 岁的布莱斯·帕斯卡（关于他的一生，请参阅 S.G. Gindikin 的小册子“关于物理学家和数学家的故事”（M.，“Nauka”，1981））是如何提出以他的名字命名的定理的。也许，出于某种原因，继续画圆内切六边形的边，他只是注意到交点 M、N 和 K 位于同一条直线上（参见屏幕保护程序）。可以听到吗？年轻人又拿了一个六边形，但M、N、K点却顽固地落在一条直线上。

我们不知道他的灵魂中升起了什么样的情感。只知道他很快就继续证明了他发现的红色事实，并立即将其推广。然后……然后从定理中，就像从一种丰度中一样，得出了一个推论。随后，帕斯卡定理成为数学新分支——射影几何最重要的规定之一，并在大地测量学和制图学中得到了有趣的应用。

在本文中，我们将证明帕斯卡圆定理，并讨论一些使我们能够推广它的“设计概念”。

简单的关系

令 l 线上给出点 A、B 和 C (图 1)。对于共线向量 $\vec{AC}$ 和 $\vec{CB}$，存在一个（单数）数 $\lambda$，使得 $\vec{AC} = \lambda \cdot \vec{CB}$。这个数$\lambda$称为A、B、C点的简比；用(ABC)表示。当B点和C点重合时，简单关系（ABC）没有定义。从定义中可以清楚地看出

$$|(ABC)| = \frac{|\vec{AC}|}{|\vec{CB}|}.$$

更准确地说，$(ABC) = \frac{|\vec{AC}|}{|\vec{CB}|}$，如果 C 点

双重关系

让点 $A, B, C$ 和 $D$ (图 4) 在线 $l$ 上给出。数$\frac{(ABC)}{(ABD)}$称为点$A, B, C, D$的双倍（或复数或非调和）比；用$(ABCD)$表示。因此，

$$|(ABCD)| = \frac{|\overrightarrow{AC}|}{|\overrightarrow{CB}|} : \frac{|\overrightarrow{AD}|}{|\overrightarrow{DB}|}.$$

当点$A$和$D$重合时，$(ABD) = 0$（见（1））；在这种情况下，双重关系 $(ABCD)$ 未定义。当然，$B = C$ 也是未定义的。对于$B = D$，很自然地放入$(ABCD) = 0$。

古希腊科学家除了算术（$a - b = c - d$）和几何（$\frac{a}{b} = \frac{c}{d}$）之外，还考虑了调和比例：

$$\frac{1}{a} - \frac{1}{b} = \frac{1}{c} - \frac{1}{d}$$（该等式由点$A, B, C, D$的调和四元组的坐标$a, b, c, d$满足）。在$b = c$的情况下（在这种情况下比例被称为连续），获得算术平均值$b = \frac{a+d}{2}$、几何平均值$b = \sqrt{ad}$和调和平均值$b = \frac{2ad}{a+d}$。

据传说，就连毕达哥拉斯在研究音乐数学理论时也发现，在音符$do, mi, colb$（大三音符的组成部分）的相同张力下发声的琴弦长度与数字1、$\frac{4}{5}, \frac{2}{3}$成正比。但$\frac{4}{5}$是数字1和$\frac{2}{3}$的调和平均值。这就是和谐概念进入数学的地方。
