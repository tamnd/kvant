在时间 T 之后，它与蓝球的距离是多少？

连接蓝色和绿色球将位于直线 NN' 上。

因此，在红球离开后的时间T之后，球将位于点a'、b'、c'。我们从三角形 c′a′A 求出红球和蓝球之间的距离：

$$|c′a′| = \sqrt{|a′A|^2 + |Ac′|^2} = l\sqrt{1 + \pi\sqrt{3}(1 + \pi\sqrt{3})}.$$

V·格里戈里耶夫

F729。长度为 l 的传送带以速度 v0 移动。为了使由于立方体和传送带之间的摩擦功而释放的物体量最大，必须以什么速度推动质量为 m 的立方体来抵抗传送带的运动？如果摩擦系数为 μ 并且满足条件 v₀² < 2μlg，则该物体的最大数量是多少？

图 1.

如果立方体相对于运输装置移动了最大距离，则释放的物体数量将是最大的。为此，在滚轮 A 处，立方体相对于地面的速度必须为零。立方体应有的初速度（地面比）由条件决定

$$-v + at = 0, \quad l = vt - \frac{at^2}{2},$$

其中 a = µg 是摩擦力赋予立方体的加速度。从这里

$$v = \sqrt{2\mu g l};$$

立方体沿传送带移动至滚筒 A 的时间 -

$$t = \sqrt{2l/\mu g}.$$

在停止之前，立方体将沿着磁带的路径移动

$$s_1 = l + v_0 t = l + v_0 \sqrt{2l/\mu g}.$$

接下来，立方体开始匀速向右移动。滑移停止的时间为 τ = v₀/a = v₀/μg。在这段时间里，立方体相对于地面会移动一段距离

$$s = a\tau^2/2 = v₀^2/2\mu g.$$

因为，根据问题的条件，v₀ < √2μgl，那么在时间 τ 内，立方体不会从传送带上滑落，即 s < l。

在此期间，立方体相对于传送带行进的路径等于

$$s_2 = \left| \frac{v_0^2}{2a} - v_0 \tau \right| = \frac{v_0^2}{2\mu g}.$$

立方体相对于磁带的完整路径是

$$S = s_1 + s_2 = l + v_0 \sqrt{\frac{2l}{\mu g}} + \frac{v_0^2}{2\mu g}.$$

由于摩擦功释放的细粒量等于

$$Q = \mu mgS = \frac{m}{2}(v_0 + \sqrt{2l\mu g})^2.$$
