其中$P = a + b + c$。我们已经使用了明显的不等式$\frac{u}{v} + \frac{v}{u} \geq 2$三次，这变成了$u = v$的等式。至此，我们证明了不等式
$$f = \frac{a}{x} + \frac{b}{y} + \frac{c}{z} \geq \frac{P^2}{2S}$$

对于任何$x, y, z$（例如$ax + by + cz = 2S$）都成立，并且对于$x = y = z$来说是等式，因此表达式$f$的最小值是在我们三角形的内接圆的中心实现的：正是在这一点$x = y = z = \frac{2S}{P}$。

N·瓦西里耶夫

M717。给定自然数$n$和$r$，$1 \leq r \leq n$。由 $r$ 个数字组成的 $[1, 2, \dots, n]$ 子集的整个乘法距离，以及每个选择中最小的数字。证明所有选定数字的算术平均值是$\frac{n+1}{r+1}$。 （例如，对于$n=3$、$r=2$，我们得到三个子集$[1, 2], [1, 3], [2, 3]$，算术平均值为$(1 + 1+2)/3 = 4/3$。）

◆ 首先，请注意集合$[1, 2, \dots, n]$ 有$C_n^r = \frac{n!}{r!(n-r)!}$ 个由$r$ 个数字组成的子集。我们将展示数字 $C_n^k$) 的两个属性，我们需要它们来解决我们的问题：
$$1^\circ. C_n^k + C_n^{k+1} = C_n^{k+1};$$
$$2^\circ. C_n^k + C_n^{k-1} + \dots + C_k^k = C_n^{k+1}.$$

我们将由$r$数字组成的集合$[1, 2, \dots, n]$的子集称为$r$子集。很容易说集合$[1, 2, \dots, n]$的$r$子集的最小元素只能是数字1, 2, ..., $(n-r+1)$。此外，数字$k$对于$C_n^{k-1}$这样的子集来说是最小的（事实上，数字$k$是最小元素的每个$r$子集都包含$k$和$r-1$，来自集合$[k+1, k+2, \dots, n]$的元素，由$n-k$元素组成）。因此所有选定数字的总和等于
$$S = 1 \cdot C_n^{r-1} + 2 \cdot C_n^{r-1} + \dots + (n-r+1) C_n^{r-1},$$
(*)

我们需要证明算术平均值$\frac{S}{C_n^r}$（总共有$C_n^r r$子集）等于$(n+1)/(r+1)$，或者$S = C_n^r \cdot (n+1)/(r+1) = C_n^{r+1}$。

利用$C_n^{k-1} = C_n^k - C_n^{k-1}$（参见$1^\circ$）这一事实，我们将总和$S$变换如下：
$$S = 1 \cdot C_n^{r-1} + 2 \cdot C_n^{r-1} + \dots + (n-r+1) C_n^{r-1} =$$
$$= 1 \cdot (C_n^r - C_n^{r-1}) + 2 \cdot (C_n^{r-1} - C_n^{r-2}) + \dots + (n-r) (C_n^{r+1} - C_n^{r+1}) + (n-r+1) C_n^{r+1} =$$
$$= C_n^r + C_n^{r+1} + \dots + C_n^{r+1},$$

考虑到属性$2^\circ$，我们根据需要获得$S = C_n^{r+1}$。

这个问题也可以通过考虑集合$[1, 2, \dots, n+1]$并注意归纳来解决
$$S(n+1, r) = S(n, r) + S(n, r-1)$$
(**)

（参见图2）；这里$S(m, k)$表示集合$[1, 2, \dots, m]$的$k$子集的最小数之和。

假设已证明平等
$$S(n, r) = C_n^{r+1}, S(n, r-1) = C_n^{r+1}$$

对于集合$[1, 2, \dots, n]$的$r$-和$(r-1)$-子集（归纳基础包含在问题的条件中），考虑到（**）和属性$1^\circ$，我们得到，
$$S(n+1, r) = C_n^{r+1} + C_n^{r+1} = C_n^{r+1},$$

这就是所需要的。
