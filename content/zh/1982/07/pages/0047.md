2°。令$2^{k-1} < N < 2^k$、$N$为奇数。然后$\Gamma \log_2 N = k$，$N = 2^{k-1} + r$，其中$0 < r < 2^{k-1}$。我们将向您展示如何让您的所有朋友在 $k+1$ 小时内找到所有新闻。让我们将$N$朋友分成两组：第一组由$2^{k-1}$朋友组成，第二组由$r$朋友组成。在第一个小时内，第二组中的每个朋友都与第一组中的一些朋友交谈。在接下来的$k-1$小时$2^{k-1}$第一组的朋友之间交换消息，如第1°段所述；这样一来，他们每个人都会知道所有的消息。最后，在每一组的最后一个小时，第二组的一位朋友再次与第一组的一位朋友交谈，导致第二组的所有朋友也都知道了所有的消息。

3°。设$2^{k-1} < N \leq 2^k$、$N = 2m$为偶数。然后是$\Gamma \log_2 N = k$和$2^{k-2} < m \leq 2^{k-1}$。我们将向您展示如何让您的所有朋友在 $k$ 小时内找到所有新闻。

考虑由矩形朋友放置的两个常规 $m$ 边形（参见 图 2，其中 $m=6$）。我们假设每个顶点都是朋友之一（不同的顶点是不同的朋友）。如果两个朋友在某个时刻 $t$ 的最大 $m$ 边形的顶点的图像是矩形朋友（例如，在 $t=0$ 处，图 2 上的顶点 $A$ 和 $B$）。让$a$成为一些新闻。 （我们将为代表在时间$t$知道新闻$a$的朋友的顶点着色。）让所有在时间$t=0$的邻居朋友在第一个小时内互相交谈（参见$t=1$处的图2）。将来，在第$t$小时（$t=2, 3, ..., k$）开始之前，我们将顶部$m$-gon顺时针旋转到角度$2^{t-1} \cdot \frac{180^\circ}{m}$，并假设在第$t$小时所有此时成为邻居的朋友都在说话（在图2时显示新闻传播） $a$ 第一、二、三小时后）。此类对话的结果将是，在 $t$ 小时后，每个最大 $m$ 边形的 $2^{t-1}$ 顶点都会被着色。从$m \leq 2^{k-1}$开始，$k$小时后，所有naikhm将被涂漆。这样，$k$小时后，所有$N$的朋友都会知道$a$的消息。

我们的说法已得到充分证明。

因此，我们问题中的a)、6)点的答案分别是：$T(64) = 6$小时、$T(55) = 7$小时和$T(100) = 7$小时。
