⟦folio 44⟧

M714。 N个好友同时获知N条新闻，每人获知一条新闻。他们开始互相打电话并交换消息。每次谈话持续一小时。您可以在一次通话中传达尽可能多的新闻。每个人至少需要多少小时才能了解所有新闻？考虑三种情况：a) N=64、6) N=55、b) N=100。

让我们用$T(N)$表示$N$朋友能够交换新闻的最短小时数。有趣的是，函数$T=T(N)$不是单调的。这可以通过查找小 $N$ 的 $T(N)$ 值来发现 - 它们在页边的表格中给出；旁边的图 1处显示了一个方法，可以让$N=4, 5, 6$和8在$T(N)$小时内找到所有新闻。当然，为了解决这个问题，我们不仅要指出一种在$T(N)$小时内交换消息的方法，而且还要证明这不可能在更少的时间内完成——以获得$T(N)$的估计。我们会向她学习。

让我们考虑一个任意的新闻项目。第一个小时之后，认识她的朋友不超过两个，第二个小时之后，认识她的朋友不超过四个，……，之后 $k$点钟——没有了 $2^k$ 朋友们。因此，如果之后 $T$ 所有时间 $N$ 朋友们知道了所有的消息，那么 $2^T \geq N$ 和 $T \geq \log_2 N$。因为 $T$ 是一个整数，那么 $T \geq \log_2 N$。 （这里有十个 $\Gamma a$ 表示不小于的最小整数 $a$。现在，这个名称的使用越来越频繁，特别是在应用数学和计算数学领域；此外，对于一般整数部分 - “向下舍入” - 而不是指定 $[a]$ 使用符号 $[a]$。） 如果 $N$ 是奇数，那么有一个 $N$ 朋友们-让我们用 $A$, - 在第一个小时内不参与对话的人。将上述推理应用于该新闻 $a$，一开始只知道 $A$，我们至少可以交换您需要的所有新闻 $1 + \log_2 N$ 小时。

让我们证明找到的估计

$$T(N) = \begin{cases} \Gamma \log_2 N, & \text{ если } N \text{ четно}, \\ \Gamma \log_2 N + 1, & \text{ если } N \text{ нечетно} \end{cases}$$

是可以实现的，也就是说，我们将证明可以以这样的方式组织新闻交换，即在$T(N)$小时后所有朋友都会知道所有新闻。我们来看三个案例。

1°。最简单的方法就是提出一种在$k$小时内交换$N=2^k$消息的方法。

让我们将一组 $k$ 数字 0 和 1（“二进制数”）与每个晶簇关联起来；从$(0,0, ..., 0)$到$(1,1, ..., 1)$的各种这样的集合只是$2^k$。让号码仅在一个 $t$ 位置不同的一对朋友在第 $t$ 小时互相交谈。那么，如果两个朋友的号码相差$t_1, t_2, ..., t_s$位（$1 \leq t_1 < t_2 < ... < t_s \leq k$），那么通过在$t_1$、$t_2$、...、$t_s$点通话，他们就会知道彼此的消息。 （$N=4$ 和 $N=8$ 的方法如图 1 所示。）

另一种方法适用于任何偶数$N$，在下面的第 3° 点中描述。
