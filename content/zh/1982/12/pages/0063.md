2. 答案：三个数字。解决方案。让我们写下前几个术语
$$(a_n) = 1, 2, 3, 5, 8, 13, ...$$
$$(b_n) = 2, 1, 3, 4, 7, 11, ...$$

我们看到数字 1、2、3 出现在两个序列中。现在让我们证明第二个序列的所有成员（从 $b_4$ 开始）不会出现在第一个序列中，而且都包含在其相邻成员之间的字符串中：
$$n \geq 4$$
$$a_{n-1} < b_n < a_n.$$

为此，我们将 $n=4$ 和 $n=5$ (*) 替换为 true，并且如果 (*) 对于两个相邻值$n=k$ 和 $k+1$ 为 true，则 (*) 对于 $n=k+2$ 也将为 true：添加不等式

$$b_k < b_{k+1} < a_{k+1},$$
$$a_{k-1} < b_k < a_k$$
