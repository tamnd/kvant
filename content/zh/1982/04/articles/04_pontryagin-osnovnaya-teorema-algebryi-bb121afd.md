复变量的复函数

如果一个复数变量$w$的数值可以通过知道另一个复数变量$z$的数值而求得，则变量$w$称为变量$z$的函数，写成以下形式

$$w = f(z).$$

如果复数变量$z$的复数函数$f(z)$是任意的，则称为解析函数。解析函数理论现在是数学最重要的分支之一。在这里，我们只对一种非常特殊类型的分析函数感兴趣，即多项式。

考虑多项式

$$w = f(z) = z^n + a_1 z^{(n-1)} + \dots + a_{(n-1)} z + a_n,$$

其中 $a_1, a_2, \dots, a_n$ 是复系数，$n$ 是一个非负整数，称为多项式的次数。我们研究的目标是证明正次数多项式（6）有根，即方程

$$f(z) = 0,$$

其中 $f(z)$ 是多项式 (6)，$n > 0$ 有解。为了证明这一点，我们考虑一条闭合路径

$$f(r(\cos \alpha + i \sin \alpha)); 0 \leqslant \alpha \leqslant 2\pi,$$

哪个点$f(z)$描述了点$z$何时描述了一条闭合路径

$$r(\cos \alpha + i \sin \alpha); 0 \leqslant \alpha \leqslant 2\pi.$$

多项式$f(z)$的自由项$a_n$等于0的情况不需要考虑，因为在这种情况下多项式$f(z)$有一个非常强的根$z = 0$。因此我们假设$a_n \neq 0$。闭合路径 (7) 取决于参数$r$，当参数$r$改变时，它就会变形。在$r = 0$处，数字$z$为0，路径$f(z)$由固定点$a_n$组成。因此，它在$r = 0$处的索引为0。我们将证明，如果我们取$r$足够大，则路径(7)的索引为$n$。但根据$n \neq 0$的假设，因此，当$r$从大值变为零时，路径（7）发生变形，经过某个值$r$的坐标原点，这意味着在某个值$z$，函数$f(z)$将消失，即该多项式的根存在（图） 7).

为了证明对于足够大的 $r$，闭合路径 (7) 的索引等于 $n$，我们将这条路径延续到一条更简单的路径，其索引很容易计算。

首先，我们将多项式$f$分解为两个之和

$$f(z) = z^n + g(z),$$

其中 $g(z)$ 由下式给出

$$g(z) = a_1 z^{n-1} + a_2 z^{n-2} + \dots + a_{n-1} z + a_n.$$

多项式 $g(z)$ 是明确定义的数字，那么它们都不会超过某个常数 $C$ 的模。根据上一篇文章（参见«Kvant»，1982，第3期）证明的不等式（8），扩展到任意数量的项，可以得出对于$|z| > 1$

$$|g(z)| \leqslant nC|z^{n-1}|.$$

考虑多项式 $f(z, s)$，取决于参数 $s$、$0 \leqslant s \leqslant 1$，由以下公式给出：

$$f(z, s) = z^n + sg(z).$$

我们有平等

$$z^n = f(z, s) - sg(z),$$

在哪里

$$|z^n| \leqslant |f(z, s)| + |-sg(z)| \leqslant |f(z, s)| + nC|z^{n-1}| \leqslant |f(z, s)| + nC|z^{n-1}|,$$

（见（8））。如下：
$$|f(z, s)| \geq |z^n| - nC |z^{n-1}|.$$

让我们用 $r$ 表示 $|z|$，那么最后一个不等式的形式为
$$|f(z, s)| \geq r^n - nCr^{n-1} = r^{n-1}(r - Cn).$$

因此，在 $r > Cn$ 处，先前不等式的右侧部分为正。因此，函数 $f(z, s)$ 的模型对于 $S$ 的任何值都不会消失，除非 $0 \leq s \leq 1$。

现在让我们注意这样一个事实：在 $s = 0$ 时，多项式 $f(z, s)$ 变成了我们已知的多项式 $z^n$。当$z$描述圆$r(\cos \alpha + i \sin \alpha)$时，路径索引$z^n$已经被我们计算出来了（见（5））。它等于$n$。在$s = 1$处，多项式$f(z, s)$变成多项式$f(z)$，并且由它确定的路径(7)的索引也等于$n$。因此，我们证明了由多项式$f(z)$确定的路径索引（7）在$r > Cn$处等于$n$。由此，如上所述，多项式 $f(z)$ 在某个值 $z$ 处消失，其中 $|z| < Cn$。

这样，代数的主要定理就得到了证明。

多项式除法

当正整数 $a$ 除以正整数 $b$ 时，我们得到等式
$$a = bh + k,$$
其中$h$和$k$是非负整数，$k < b$。数字$h$称为商，$k$是数字$a$除以数字$b$的余数。

一种将数字除以算术的好方法。但就像整数一样，多项式也可以被彼此整除。我们将从两个多项式开始
$$a(z) = a_0 z^p + a_1 z^{p-1} + \dots + a_p,$$
$$b(z) = b_0 z^q + b_1 z^{q-1} + \dots + b_q.$$

我们在这里假设数字$a_0$和$b_0$不等于0，因此多项式$a(z)$的次数为$p$，多项式$b(z)$的次数为$q$。将多项式$a(z)$除以多项式$b(z)$，我们可以得到以下等式，类似于等式（9）：
$$a(z) = b(z)h(z) + k(z),$$
(10)

其中多项式 $k(z)$ 的次数小于 $q$。多项式$h(z)$和$k(z)$分别称为多项式$a(z)$除以多项式$b(z)$时的商和余数。

如果$k(z) = 0$，则多项式$a(z)$可被多项式$b(z)$整除，$h(z)$是它们相除的商。

等式（9）在算术中得到证明，而等式（10）必须在代数中得到证明。但多项式除法并不包含在当前的学校课程中。为了证明（10），我们必须构造满足这个等式的多项式$h(z)$和$k(z)$。这个构建的过程就是一个非常重要的算法。我们来描述一下。

如果$p < q$，则满足$h(z) = 0$、$k(z) = a(z)$，且满足等式(10)。

现在，我们将在 $p \geq q$ 的假设下构造多项式 $h(z)$ 和 $k(z)$。首先我们构造等式
$$a(z) = b(z)h_1(z) + a_1(z),$$
(11)
其中构造小于 $p$ 的多项式 $a_1(z)$。为此，我们将
$$h_1(z) = \frac{a_0}{b_0}z^{(p-q)}.$$

那么区别
$$a(z) - b(z)h_1(z) = a_1(z)$$
具有小于 $p$ 的次数，因为在该多项式中，$z^p$ 的系数为零，并且该多项式中包含的其余次数 $z$ 远小于 $p$。由此，构造等式(11)。

如果多项式 $a_1(z)$ 的次数小于 $q$，则等式 (11) 已经是等式 (10)。在相反的情况下，我们将构造等式 (11) 时应用于多项式 $a(z)$ 的相同过程应用于多项式 $a_1(z)$。然后我们就得到了平等

$$a_1(z) = b(z)h_2(z) + a_2(z),$$

并且多项式$a_2(z)$的次数已经小于多项式$a_1(z)$的次数。如果多项式$a_2(z)$的次数已经小于$q$，则将最后一个等式中的$a_1(z)$代入等式（11），我们得到

$$a(z) = b(z)(h_1(z) + h_2(z)) + a_2(z),$$

这已经是等式（10）。如果多项式$a_2(z)$也有大于$q$的次数，那么我们将继续构造，最终我们将证明所需的等式（10）。

这里我们描述了多项式$a(z)$除以多项式$b(z)$的过程，即求出等式（10）中包含的多项式$h(z)$和$k(z)$。现在让我们证明它们是由多项式$a(z)$和$b(z)$唯一确定的。让我们假设，如果我们违反等式（10），我们有等式

$$a(z) = b(z)h_0(z) + k_0(z),$$

并且多项式$k_0(z)$的次数小于$q$。从等式（10）减去等式（12），我们得到

$$b(z)(h(z) - h_0(z)) = k_0(z) - k(z).$$

由于多项式$b(z)$的次数等于$q$，而多项式$k_0(z) - k(z)$的次数小于$q$，所以最后的等式只能在条件$h(z) - h_0(z) = 0$下成立，因此$k(z) - k_0(z) = 0$。

具有任意复系数的多项式

现在，根据代数基本定理，具有复系数的多项式$f(z)$的根将用$z_1$表示。让我们证明多项式 $f(z)$ 可以被二元变量 $(z - z_1)$整除。根据上一节中描述的规则，将多项式$f(z)$除以一次多项式$(z - z_1)$，我们得到一个商，用$f_1(z)$表示，以及零次多项式形式的一些余数，即用$k$表示。因此我们有

$$f(z) = f_1(z)(z - z_1) + k.$$

由于$f(z_1) = 0$，然​​后将$z = z_1$带入之前的等式中，我们得到$k = 0$。

所以多项式 $f(z)$ 除以 $(z - z_1)$ 我们有

$$f(z) = (z - z_1)f_1(z),$$

其中 $f_1(z)$ 是 $n-1$ 次多项式，显然以 $z^{n-1}$ 项开头。如果$n > 1$，则$n-1 > 0$；那么多项式$f_1(z)$将是正数，并且根据之前的证明，有一些根$z_2$。因此，根据刚才的证明，多项式$f_1(z)$可以分为

$$f_1(z) = (z - z_2)f_2(z).$$

(13)

继续这个过程，我们得到$f(z)$分解为$n$线性多项式

$$f(z) = (z - z_1)(z - z_2) \dots (z - z_n).$$

数字$z_1, z_2, \dots, z_n$是多项式$f(z)$的根，而多项式$f(z)$显然没有其他根。然而，结果可能是同一个根在此扩展中出现了多次。将彼此相等的根分组，我们得到分解

$$f(z) = (z - z_1)^{k_1}(z - z_2)^{k_2} \dots (z - z_q)^{k_q},$$

其中所有根 $z_1, z_2, \dots, z_q$ 都是不同的。数$k_1$称为根$z_1$的重数，数$k_2$称为根$z_2$的重数，依此类推，数$k_q$称为根$z_q$的重数。因此，多项式$f(z)$的不同根的数量可能小于$n$。然而，如果我们考虑每个根的重数，那么重数之和恰好是 $n$。从这个意义上说，多项式 $f(z)$ 恰好有 $n$ 根。

多项式可以表达一些有趣的附加信息。

为了考虑具有实数系数的多项式，我们引入了数字$\bar{z}$的概念，即给定复数$z$的复共轭。正是如果
$$z = x + iy,$$
那么根据定义，数
$$\bar{z} = x - iy$$
(14)

称为 $z$ 的复共轭。因此，与数$z$共轭的数$\bar{z}$是数$z$相对于实数轴的镜像。

如果
$$z = r(\cos \alpha + i \sin \alpha),$$
那
$$\bar{z} = r(\cos \alpha - i \sin \alpha) = r(\cos (-\alpha) + i \sin (-\alpha)).$$
(15)

因此，两个复共轭数的自变量仅在符号上不同。由式(14)可得
$$\bar{z}_1 + \bar{z}_2 = \bar{z}_1 + \bar{z}_2.$$
由式(15)可知
$$\bar{z}_1 \bar{z}_2 = \bar{z}_1 \cdot \bar{z}_2.$$
还要注意的是，等式
$$\bar{z} = z$$
当且仅当$z$是实数时成立。

从前面的三个公式很容易看出，对于具有实数系数的多项式$f(z)$，等式成立
$$\bar{f}(\bar{z}) = f(\bar{z}).$$
从这个等式可以看出，如果 $z_1$ 是具有实数系数的多项式 $f(z)$ 的根，则 $\bar{z}_1$ 也是它的根。如果$z_1$是实数，那么这个说法就没有意义。如果 $z_1$ 不是实数，则该语句表明存在不同的根 $\bar{z}_1$ 以及根 $z_1$。因此，如果$z_1$不是实数，则多项式$f_1(z)$（参见（13））有一个除数$(z - \bar{z}_1)$，我们得到因式分解

$$f(z) = (z - z_1)(z - \bar{z}_1)f_2(z).$$
波利亚加在这种平等中
$$z_1 = x_1 + iy_1,$$
我们得到
$$f(z) = (z^2 - 2x_1z + x_1^2 + y_1^2)f_2(z).$$

因此，我们看到多项式$f(z)$有一个实数二次因子$z^2 - 2x_1z + x_1^2 + y_1^2$。因此，多项式 $f_2(z)$ 也是具有实系数的多项式，因为它是通过将多项式 $f(z)$ 除以实二次三项式获得的。因此，这个多项式 $f_2(z)$ 具有复数根，并且也是成对共轭的。如果他找到的根等于已经找到的根$z_1$，那么他也会找到一个根$\bar{z}_1$。因此，在这种情况下，从多项式 $f_2(z)$ 中提取一个二次因子，等于前一个二次因子。由此可见，实系数多项式$f(z)$的复数根的重数等于共轭根的重数，从而得到多项式$f(z)$分解为实数因子：

$$f(z) = (z^2 - 2x_1z + x_1^2 + y_1^2)^{k_1} \dots (z^2 - 2x_pz + x_p^2 + y_p^2)^{k_p} \times (z - z_{p+1})^{k_{p+1}} \dots (z - z_q)^{k_q}.$$

请注意，形式的二次因子
$$z^2 - 2x_i z + x_i^2 + y_i^2, \quad i = 1, 2, \dots, p,$$
其中所有$y_i$不等于0，不能再分解为实因数。
