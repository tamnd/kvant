如果多项式 $a_1(z)$ 的次数小于 $q$，则等式 (11) 已经是等式 (10)。在相反的情况下，我们将构造等式 (11) 时应用于多项式 $a(z)$ 的相同过程应用于多项式 $a_1(z)$。然后我们就得到了平等

$$a_1(z) = b(z)h_2(z) + a_2(z),$$

并且多项式$a_2(z)$的次数已经小于多项式$a_1(z)$的次数。如果多项式$a_2(z)$的次数已经小于$q$，则将最后一个等式中的$a_1(z)$代入等式（11），我们得到

$$a(z) = b(z)(h_1(z) + h_2(z)) + a_2(z),$$

这已经是等式（10）。如果多项式$a_2(z)$也有大于$q$的次数，那么我们将继续构造，最终我们将证明所需的等式（10）。

这里我们描述了多项式$a(z)$除以多项式$b(z)$的过程，即求出等式（10）中包含的多项式$h(z)$和$k(z)$。现在让我们证明它们是由多项式$a(z)$和$b(z)$唯一确定的。让我们假设，如果我们违反等式（10），我们有等式

$$a(z) = b(z)h_0(z) + k_0(z),$$

并且多项式$k_0(z)$的次数小于$q$。从等式（10）减去等式（12），我们得到

$$b(z)(h(z) - h_0(z)) = k_0(z) - k(z).$$

由于多项式$b(z)$的次数等于$q$，而多项式$k_0(z) - k(z)$的次数小于$q$，所以最后的等式只能在条件$h(z) - h_0(z) = 0$下成立，因此$k(z) - k_0(z) = 0$。

具有任意复系数的多项式

现在，根据代数基本定理，具有复系数的多项式$f(z)$的根将用$z_1$表示。让我们证明多项式 $f(z)$ 可以被二元变量 $(z - z_1)$整除。根据上一节中描述的规则，将多项式$f(z)$除以一次多项式$(z - z_1)$，我们得到一个商，用$f_1(z)$表示，以及零次多项式形式的一些余数，即用$k$表示。因此我们有

$$f(z) = f_1(z)(z - z_1) + k.$$

由于$f(z_1) = 0$，然​​后将$z = z_1$带入之前的等式中，我们得到$k = 0$。

所以多项式 $f(z)$ 除以 $(z - z_1)$ 我们有

$$f(z) = (z - z_1)f_1(z),$$

其中 $f_1(z)$ 是 $n-1$ 次多项式，显然以 $z^{n-1}$ 项开头。如果$n > 1$，则$n-1 > 0$；那么多项式$f_1(z)$将是正数，并且根据之前的证明，有一些根$z_2$。因此，根据刚才的证明，多项式$f_1(z)$可以分为

$$f_1(z) = (z - z_2)f_2(z).$$

继续这个过程，我们得到$f(z)$分解为$n$线性多项式

$$f(z) = (z - z_1)(z - z_2) \dots (z - z_n).$$

数字$z_1, z_2, \dots, z_n$是多项式$f(z)$的根，而多项式$f(z)$显然没有其他根。然而，结果可能是同一个根在此扩展中出现了多次。将彼此相等的根分组，我们得到分解

$$f(z) = (z - z_1)^{k_1}(z - z_2)^{k_2} \dots (z - z_q)^{k_q},$$

其中所有根 $z_1, z_2, \dots, z_q$ 都是不同的。数$k_1$称为根$z_1$的重数，数$k_2$称为根$z_2$的重数，依此类推，数$k_q$称为根$z_q$的重数。因此，多项式$f(z)$的不同根的数量可能小于$n$。然而，如果我们考虑每个根的重数，那么重数之和恰好是 $n$。从这个意义上说，多项式 $f(z)$ 恰好有 $n$ 根。
