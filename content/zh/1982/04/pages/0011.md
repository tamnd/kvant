⟦folio 9⟧

多项式可以表达一些有趣的附加信息。

为了考虑具有实数系数的多项式，我们引入了数字$\bar{z}$的概念，即给定复数$z$的复共轭。正是如果
$$z = x + iy,$$
那么根据定义，数
$$\bar{z} = x - iy$$
(14)

称为 $z$ 的复共轭。因此，与数$z$共轭的数$\bar{z}$是数$z$相对于实数轴的镜像。

如果
$$z = r(\cos \alpha + i \sin \alpha),$$
那
$$\bar{z} = r(\cos \alpha - i \sin \alpha) = r(\cos (-\alpha) + i \sin (-\alpha)).$$
(15)

因此，两个复共轭数的自变量仅在符号上不同。由式(14)可得
$$\bar{z}_1 + \bar{z}_2 = \bar{z}_1 + \bar{z}_2.$$
由式(15)可知
$$\bar{z}_1 \bar{z}_2 = \bar{z}_1 \cdot \bar{z}_2.$$
还要注意的是，等式
$$\bar{z} = z$$
当且仅当$z$是实数时成立。

从前面的三个公式很容易看出，对于具有实数系数的多项式$f(z)$，等式成立
$$\bar{f}(\bar{z}) = f(\bar{z}).$$
从这个等式可以看出，如果 $z_1$ 是具有实数系数的多项式 $f(z)$ 的根，则 $\bar{z}_1$ 也是它的根。如果$z_1$是实数，那么这个说法就没有意义。如果 $z_1$ 不是实数，则该语句表明存在不同的根 $\bar{z}_1$ 以及根 $z_1$。因此，如果$z_1$不是实数，则多项式$f_1(z)$（参见（13））有一个除数$(z - \bar{z}_1)$，我们得到因式分解

$$f(z) = (z - z_1)(z - \bar{z}_1)f_2(z).$$
波利亚加在这种平等中
$$z_1 = x_1 + iy_1,$$
我们得到
$$f(z) = (z^2 - 2x_1z + x_1^2 + y_1^2)f_2(z).$$

因此，我们看到多项式$f(z)$有一个实数二次因子$z^2 - 2x_1z + x_1^2 + y_1^2$。因此，多项式 $f_2(z)$ 也是具有实系数的多项式，因为它是通过将多项式 $f(z)$ 除以实二次三项式获得的。因此，这个多项式 $f_2(z)$ 具有复数根，并且也是成对共轭的。如果他找到的根等于已经找到的根$z_1$，那么他也会找到一个根$\bar{z}_1$。因此，在这种情况下，从多项式 $f_2(z)$ 中提取一个二次因子，等于前一个二次因子。由此可见，实系数多项式$f(z)$的复数根的重数等于共轭根的重数，从而得到多项式$f(z)$分解为实数因子：

$$f(z) = (z^2 - 2x_1z + x_1^2 + y_1^2)^{k_1} \dots (z^2 - 2x_pz + x_p^2 + y_p^2)^{k_p} \times (z - z_{p+1})^{k_{p+1}} \dots (z - z_q)^{k_q}.$$

请注意，形式的二次因子
$$z^2 - 2x_i z + x_i^2 + y_i^2, \quad i = 1, 2, \dots, p,$$
其中所有$y_i$不等于0，不能再分解为实因数。
