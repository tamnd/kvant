具有固定旋转轴的物体的平衡条件是作用在该物体上的力的力矩的代数和等于零。相对于支撑轴，力矩产生两个力：应用于杆的重心的重力$m\vec{g}$，以及应用于浸入水中的杆的部分的重心的阿基米德力$\vec{F}_A$。

让我们用$l$表示杆的长度，用$S$表示其横截面面积，用$x$表示杆浸入水中的长度部分。那么杆的重力为$mg = \varrho_1 l S g$，阿基米德力为$F_A = \varrho_2 x l S g$。这些力的臂分别为 $l/2$ cos $\alpha$ 和 $l(1-x/2)$ cos $\alpha$。

杆相对于支撑轴的平衡条件具有以下形式

$$mg \frac{l}{2} \cos \alpha - F_A l \left(1 - \frac{x}{2}\right) \cos \alpha = 0.$$

将力的表达式替换为期望值 $x$ 后，我们得到一个二次方程

$$x^2 - 2x + \frac{\varrho_1}{\varrho_2} = 0.$$

这个方程的根相等

$$x_{1,2} = 1 \pm \sqrt{1 - \frac{\varrho_1}{\varrho_2}},$$

或者

$$x_1 = 1,45 \text{ и } x_2 = 0,55.$$

显然，杆的长度不能超过1，所以第一个根没有物理意义。

因此，杆长度的 0.55 倍浸入水中。

问题 8. 将长度为 $L = 125$ cm 的玻璃管与威兹的密封端垂直放置。高度为 $h$ 的大核心到达管子的开口上边缘，将管子中的空气与大气分开。将管子小心地用威兹的开口端翻转，并倒出一些芯。如果大气压为 $p_a = 75$ cm pt，求管内剩余地面的高度。艺术。解决$a) h = 60$厘米处的问题； $b) h = 40$见

让我们将波义耳-马里奥特定律应用于管内空气的体积：

$$p_1 V_1 = p_2 V_2.$$

初始状态下，其压力为大气压力与高度为$h$的核心压力之和：

$$p_1 = p_a + \varrho gh, \text{ или } p_1 = \varrho g (H + h),$$

其中$\varrho$是土壤的密度，$H$是土柱的高度，产生与大气相等的压力。在这种情况下，空气占据的体积等于$V_1 = (L - h) S$，其中$S$是毛坯的横截面密度。

让我们用$x$表示重新定向后保留在管中的芯的高度。然后

$$p_2 = p_a - \varrho g x = \varrho g (H - x)$$

和$V_2 = (L - x) S.$

将压力和体积的相应值代入波义耳-马里奥特定律的表达式，我们得到寻找期望值$x$的方程：

$$\varrho g (H + h) (L - h) S = = \varrho g (H - x) (L - x) S,$$

或者

$$x^2 - (H + L) x + h (H + h - L) = 0.$$

这个方程的根相等

$$x_{1,2} = \frac{H + L}{2} \left(1 \pm \sqrt{1 - \frac{4h (H + h - L)}{(H + L)^2}}\right).$$

让我们针对问题中指定的两种情况进行数值计算。

a) 对于 $h = 60$ cm，我们得到 $x_1 \approx 197$ cm 和 $x_2 \approx 3$ cm。显然，第一根不满足问题的条件 - 留在管中的幼虫斯托尼克的高度不能超过其原始高度（更不用说它不能超过幼虫的长度）。第二根回答了问题中提出的问题，即管内剩余的芯子高度约为3厘米。
