$$x_{M1,2} = \frac{mg}{k} \left( 1 \pm \sqrt{1 + \frac{2k(H-l_0)}{mg}} \right).$$

问题中提出的问题的答案是第一个，正根

$$x_{M1} = \frac{mg}{k} \left( 1 + \sqrt{1 + \frac{2k(H-l_0)}{mg}} \right).$$

第二个根是负数，但它并非没有物理意义，很容易成立。让我们想象一下，身体一接触弹簧，它就会向弹簧飘去，并发生振动。达到最大值后，坐骨变形减小，进而转变为拉伸变形。其最大值用负根表示，​​即等于

$$|x_{M2}| = \frac{mg}{k} \left| 1 - \sqrt{1 + \frac{2K(H-l_0)}{mg}} \right|.$$

总之，我们将讨论其中一个根没有物理意义的问题。

问题 6. 一根长度为 $l = 15$ cm 的细棒沿着收集线的主光轴放置，使得透镜和最靠近它的棒尖端之间的距离改变其焦距。在这种情况下，面部中杆端部的图像位于距杆 $f_1 = 36$ cm 和 $f_2 = 60$ cm 的位置。求直线的焦距。

让我们构建面部 (图 2) 中杆 $AB$ 的图像 $A'B'$。从 图 2 可以清楚地看出，最靠近面部的杆端部（点 $B$）的图像比距离杆端部更远的图像（点 $A$）距离线更远。在该问题中，给定距离为$f_1 = |OA'|$和$f_2 = |OB'|$； therefore, $d_1 = |OA|$, $d_2 = |OB|$, rod alina $l = d_1 - d_2$.

从透镜公式来看 $\frac{1}{d} + \frac{1}{f} = \frac{1}{F}$ 我们有 $d = \frac{fF}{f - F}$.

然后

$$l = d_1 - d_2 = \frac{f_1F}{f_1 - F} - \frac{f_2F}{f_2 - F}.$$

图 2.

这是确定所需焦距 $F$ 的方程式。让我们将其简化为二次方程的标准形式：

$$(f_2 - f_1 - l)F^2 + l(f_1 + f_2)F - lf_1f_2 = 0$$

并找到根：

$$F_{1,2} = \frac{-l(f_1 + f_2) \pm \sqrt{l(f_2 - f_1)(4f_1f_2 + lf_2 - lf_1)}}{2(f_2 - f_1 - l)}$$

代入数值并进行适当的计算，我们得到 $F_1 = 20$ cm 和 $F_2 = -180$ cm。第二个根 - 负 - 没有物理意义，因为连线的焦距为正。因此，所需的线焦距为 $F = 20$ cm。
