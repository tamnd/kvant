速度v，从各个方向，就像飞机发出的声音一样，它们以蘑菇采摘机的速度分散开来。我们形成...一个张角为 $\alpha =$ arcsin ( c v ) 的马赫锥 (图4)，其中 c 是蘑菇采摘机的速度，v 是公共汽车的速度。圆锥体内的每一点都会有两个蘑菇采摘器，在最边缘会有一个，而在边缘之外就没有人了。马赫锥体将是旅客可以搭乘巴士的区域。证明？请。任何位于马赫锥内部或边缘的旅客都可以搭乘巴士。为此，他只需沿着与其中一名蘑菇采摘者到达给定点的方向相反的方向即可。此外，当公共汽车即将驶近时，旅行者就会出现在路上。同样，不难证明，站在我们构建的马赫锥之外的旅行者永远不会赶上公共汽车（您自己进行证明）。所以，我们问题的答案是：总线的可达区域是马赫锥，顶点位于总线，顶点的角度为 $2 \alpha = 2$ arcsin ( c v )。位于该锥体内的每个旅行者都有一个选择 - 他有两条路径，他可以在公交车到达时准确地进入道路，并且他也可以选择它们之间的任何路径。确实，在这种情况下，他将不得不等待公共汽车一段时间。对于站在圆锥体母线上的旅行者来说，返回只有一个选择——他必须垂直于这条母线。
