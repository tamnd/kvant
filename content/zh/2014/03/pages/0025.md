问题工人

让积分 $I_{a}, I_{b}, I_{c}$ – 外圆中心分别与边 BC、CA、AB 相切（参见 图）。既然直 $CI_{c}$ 和 $I_{a} I_{b}$ 是内角ACB和外角ACB的平分线，则直线 $I_{c} C$ – 三角形的高度 $I_{a} I_{b} I_{c}$。同样，直 $I_{a} A$ 和 $I_{b} B$ 是它的高度。因此，三角形 ABC 是三角形的直角三角形（即，顶点位于高的底边的三角形） $I_{a} I_{b} I_{c}$。由于 I 点是三角形的重心 $I_{a} I_{b} I_{c}$，那么三角形 ABC 也是三角形的直角三角形 $II_{a} I_{b}$。请注意以下几点 $A, B, I_{a}, I_{b}$ 位于同一个圆上（直径 $I_{a} I_{b} ),$ 因此三角形 $II_{a} I_{b}$ 和 IAB 通过相似变换组合 - 相对于角度 AIB 的平分线对称，然后与中心 I 相似。因此，圆 (ABC)（围绕三角形的直角三角形外接） $II_{a} I_{b} )$ 以及三角形AIB的直角三角形的外接圆通过相同的相似变换组合。这意味着它们的中心是 O 和 $O_{C}$，和射线 $IO_{C}$ 和IO通过相同的变换相互转换。因此，要点 $E_{C}$ 位于 IO 线上。同样，点 $E_{A}$ 和 $E_{B}$ 躺在IO线上。 S·伊利亚索夫

$M2333^{*}$。图是有限的顶点集，一些顶点对通过边连接。如果图的每个顶点都被分配了 m 个给定颜色中的一种，使得由边连接的任何两个顶点都被着色为不同的颜色，则称该图被正确着色为 m 种颜色。将某个图的顶点分为三个集合 A、B、C，使得集合 A 中的顶点与集合 C 中的顶点不通过边连接。已知，如果从图中删除集合 C 的所有顶点（连同出边），则所得的图可以正确地以 k 种颜色着色，如果从中删除集合 A 中的所有顶点，则可以以 n 种颜色正确着色。这样的图表可以保证正确着色的最小颜色数是多少？

“广达”

⟦column⟧

回答。 k + n – 1。让我们证明，在 k + n – 1 颜色中，所有顶点始终可以正确着色。让我们用 n 种颜色给 B » C 上色，将其中一种颜色称为第一种颜色，并让 D 为用第一种颜色着色的 B 中所有顶点的集合。现在让我们用 k 种颜色对 A » D 进行着色（同时我们对集合 D 中的顶点重新着色），使用第一种颜色作为其中一种颜色（并采用与已使用的 n 种颜色不同的剩余 k – 1 种颜色）。我们对 A » D 中未包含的顶点保持相同的着色。由于 A » D 中没有顶点通过边与 C 中的顶点以第一种颜色着色（从 D – 由于 B » C 在 n 种颜色中的正确着色，从 A – 根据条件），我们获得了 k + n – 1 种颜色的图的正确着色。现在我们将证明更少的颜色可能还不够。让我们将 kn 个点排列成 n 行 k 列的矩形。我们将这个集合设为B。在底部添加零行k个点，将其视为A，在左侧添加零列，将其视为C。使用B中的边，连接不在任何行或列中的任意两个点。在 A 中，我们用边连接每两个点，在 C 中也是如此。此外，我们通过边将 A 中的每个点与 B 中不位于同一列的所有点连接起来，并且将 C 中的每个点与 B 中不位于同一行的所有点连接起来。 A » B 的 k 种颜色（列）和 C » B 的 n 种颜色（行）的正确着色是显而易见的。让我们证明结果图不能用少于 k + n – 1 种颜色着色。假设有 k + n – 2 种颜色的常规着色 A » B » C。由于集合 A 的点被涂上 k 种不同的颜色，集合 C 的点被涂上 n 种不同的颜色，因此这两个集合的点都有 $m \ge 2$ 种颜色（我们称它们为公共颜色）。让我们标记这些点所在的行和列；在它们的交点处有集合B的$m^{2}$个点。注意，m种常见颜色中的每一种最多只能对这$m^{2}$个点中的一个进行着色，即位于相应列和行的交点处的点。因此，在这$m^{2}$点中，有$m^{2} - m$点被涂成不同的颜色。 这些不能是普通颜色，但也不能是用于对集合 A 和 C 的点进行着色的其他颜色，因为标记的行和列中的点通过边连接到此类颜色的所有点。总共使用了 k + n – m 种颜色对 A 和 C 中的点进行着色。从上述$m^{2} - m$ 点中，可以选择 m 个点，其中没有两个点位于同一行或列。这 m 个点中的每两个点都由一条边连接，因此它们至少有 m 种颜色。事实证明总共至少使用了 k + n 种颜色。矛盾。伊·波格丹诺夫
