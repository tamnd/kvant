让我们用 $w_k$ 表示第 $k$ 个单词。根据条件中指定的规则，从单词$w_k$得到单词$w_{k+1}$。利用这一点，我们可以通过归纳证明，对于$k > 1$，单词$w_{k+1}$由重复两次的单词$w_k$和$w_{k-1}$组成（对于$k = 2$和$k = 3$，这显示在页边空白中）：

$$w_{k+1} = w_k w_{k-1}.$$

事实上，将我们的规则应用于对应关系 (*)，我们从 $w_k$ 获得 $w_{k+1}$，从 $w_{k-1}$ 获得 $w_k$，因此，如果此对应关系适用于某些 $k$，则类似的对应关系也适用于 $k+1$：

$$w_{k+2} = w_{k+1} w_{k+1} w_k.$$

因此，对于所有$k > 1$，对应关系（*）被证明。

从这里开始，特别是语句a)：每个单词$w_k$是单词$w_{k+1}$的开头；因此所有$w_k$都是无限词$w = AABAABAAAB$的初始片段...

令$a_k$和$b_k$为单词$w_k$中的字母$A$和$B$的数量，$s_k = a_k + b_k$为单词$w_k$中的所有字母的数量。转移规则和等式（*）表示对应

$$b_{k+1} = a_k, a_{k+1} = 2a_k + b_k,$$

(1)

$$a_{k+1} = 2a_k + a_{k-1} (a_1 = 1, a_2 = 2),$$

(2)

$$s_{k+1} = 2s_k + s_{k-1} (s_1 = 1, s_k = 3).$$

它们使得找到序列 $a_k$、$b_k = a_{k-1}$ 和 $s_k$ ($k = 1, 2, 3, \dots$) 的第一项成为可能 - 见表。

让我们用$N_A(m)$表示第$m$第一个字母$A$出现的位置的编号。如果$a_n \leq m < a_{n+1}$，那么第$m$个字母$A$第一次出现在单词$w_{n+1}$中，并且从（*）很容易看出，

$$N_A(m) = \begin{cases} s_n + N_A(m - a_n), & \text{ если } m \leq 2a_n; \\ 2s_n + N_A(m - 2a_n), & \text{ если } 2a_n < m \leq a_{n+1}. \end{cases}$$

使用这些等式规则，我们找到问题 6) 的答案：

$$N_A(1988) = 2 \cdot 1393 + N_A(1988 - 2 \cdot 985) = 2786 + N_A(18) = 2786 + 17 + N_A(18 - 12) = 2803 + 7 + N_A(1) = 2811.$$

（这里使用的值是$a_9 = 985$，$s_9 = 1393$；$a_4 = 12$，$s_4 = 17$；$a_3 = 5$，$s_3 = 7$；$N_A(1) = 1$。）

使用该序列的几何表示证明 $w$ 是非周期的（参见第 30 页的 图）。在方格纸上我们画一条折线，其链接对应于序列字母$w$；字母$A$是向上的线段，字母$B$是向右的线段。可以看出，点$(b_k; a_k)$位于这条虚线上，对应于单词$w_k$ - 初始线段$w$ ($k = 1, 2, 3, \dots$) - 位于穿过初始点的一条直线附近。让我们证明这一点并找到这条线的斜率$\tau$（斜率）。
