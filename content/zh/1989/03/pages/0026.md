我们将解决与平行六面体相关的参考系中的问题，即我们将考虑平行六面体静止：那么我们必须在该参考系上获得速度$\bar{w} = \bar{v} - \bar{u}$。速度矢量 $\bar{w}$ 在坐标轴上的投影将为 $w_x = v_x - u, w_y = v_y, w_z = v_z$（u 是矢量 $\bar{u}$ 的长度）。需要确定在$\tau = l/u$时间内有多少滴$N$落在平行六面体上，以及在$u$时值$N$最小。

很明显，在时间$\tau$，所有的水滴都会落在平行六面体上，从这里到平行六面体的侧面，距离不大于$\tau \cdot |\bar{w}|$，方向与向量$\bar{w}$相反，即所有水滴位于图上红线所画的物体体积内。 3. 如何求这个物体的体积？容易注意到，这个体由三个棱柱组成，其底面积分别等于$S_\pi, S_B$和$S_B$，高分别为向量$\tau \cdot \bar{w}$在轴$Ox, Oy$和$Oz$上的投影的横坐标值。因此，该物体的体积等于

$$\tau(|w_x|S_\pi + |w_y|S_B + |w_z|S_B) = \tau(|v_x - u|S_\pi + v_y S_B + v_z S_B),$$

所需滴数$N$等于$\tau k(|v_x - u|S_\pi + v_y S_B + v_z S_B)$。

考虑到$\tau = l/u$，我们得到$N$对$u$的依赖关系：

$$N = kl \frac{|v_x - u|S_\pi + v_y S_B + v_z S_B}{u}.$$

现在让我们找到一个 $N$ 最小的 $u > 0$。

让我们继续解决方案

由于数量$k$和$l$是恒定的，为了方便我们将使用数量进行操作

$$\psi = \frac{N}{kl} = \frac{|v_x - u|S_\pi + v_y S_B + v_z S_B}{u}.$$

让我们考虑两种情况：

1. $v_x \leq 0$（即将到来的死亡）。

在这种情况下，$v_x - u < 0$，函数$\psi$采用以下形式：

$$\psi = \frac{(u - v_x)S_\pi + v_y S_B + v_z S_B}{u} = S_\pi + \frac{-v_x S_\pi + v_y S_B + v_z S_B}{u}.$$

从 $v_x \leq 0$ 开始，分数的分子为正，函数 $\psi(u)$ 在区间 $(0; +\infty)$ 上终止。函数$\psi$与$u$的关系图如图4所示。我们看到，虽然$\psi$随着$u$的增加而死亡，但它仍然总是$\psi > S_\pi$，$\psi \rightarrow S_\pi$在$u \rightarrow \infty$。因此，在遭遇迎面而来的撞击时，“毫不犹豫”理论的支持者似乎是错误的：跑得越快，淋湿的就越少。奥达纳-
