⟦folio 69⟧

莫斯科航空学院以它的名字命名。谢尔戈·奥尔忠尼启则

数学
笔试
选项1
1. 等差数列的首项尾部之和比其后续项尾部之和小 50。等差数列的第十项比第二项大多少？
2. 找到函数的临界点
$$f(x) = \sin 2x + 2 \cos \left( \frac{\pi}{2} - x \right).$$
3. 解决不等式
$$\sqrt{\lg x} + \sqrt{25 - \lg x} \leq 7.$$
4. 直角三角形的面积为$P$，其内切圆的面积为$Q$。求这个三角形的外接圆的面积。
5. 求解方程组
$$\begin{cases} 2x^2 + xy = 1, \\ \frac{9x^2}{2(1-x)^4} = 1 + \frac{3xy}{2(1-x)^2}. \end{cases}$$
6. 在直角三棱柱$ABCA'B'C'$中，通过点$B, C$和$A'$绘制剖面，其面积为$S$，剖面到顶点$B'$的距离为$h$。求棱柱的体积。

选项2
1. 解方程
$$\cos \left( x - \frac{\pi}{3} \right) + \cos^2 2x = 1 - \cos^2 \left( \frac{\pi}{2} - 2x \right).$$
2. 如果从第十三项开始，递减几何级数的两个十二项之和是其前两个十二项之和的 40%，则求该级数的第三项与其第十五项之比。
3. 求函数的定义域
$$f(x) = \sqrt{\log_{3x+1} \frac{x-2}{x-4}}.$$
4. 侧边长度为 1 的正四边形帕米达的最大体积是多少？

5. 求系统的所有解
$$\begin{cases} 5x^2 + 8xy + 4y^2 = 4 + 4x, \\ \sin^2(\pi x) + \sin^2(\pi y) = 0. \end{cases}$$
6. 点 $O(0; 0), A(0; 1), B(2; 0), C(4; 0)$ 在坐标平面上给出。找到点 $M$ 的坐标 $(x; y)$，使得角度 OMA 等于角度 CMB，角度 MAO 等于角度 MBC。

物理
笔试
选项1
1. 圆柱体上缠绕有一根线，其末端固定在斜面（图1）顶点的支架上。圆柱体与平面之间的摩擦系数为$\mu$。在角度 $\alpha$ 的最大值为多少时，圆柱体不会从斜面滚下？
2. 质量为 $m$ 的球由两个弹簧悬挂，其刚度为 $k_1$ 和 $k_2$ (图 2)。求球振动的频率。如果互换弹簧，频率会改变吗？
3. 在体积为$V_1 = 0,25$l、温度为$t_1 = 20^\circ\text{C}$的装有水的容器中，放置$m_2 = 50$g温度为$t_2 = 400^\circ\text{C}$的熔融铅。热传递的结果将达到什么温度？容器中残留的水有哪一部分？水的比热为$c_1 = 4,2 \cdot 10^3\text{Дж/(кг}\cdot\text{К)}$，铅的熔点为$t_{\pi\pi} = 327^\circ\text{C}$，其比温度为$\lambda = 0,226 \cdot 10^5\text{Дж/кг}$，认为熔体和固体铅的比热相同，等于$c_2 = 1,3 \times 10^2\text{Дж/(кг}\cdot\text{К)}$。忽略热量损失。
4. 带有电荷$q$的粒子将加速到能量$W$并飞入与其板平行的扁平电容器中。电容器的电荷为$Q$，容量为$C$，极板之间的距离为$d$。最初，颗粒与板的距离相同。每个板应该有多长，以便颗粒不会落在其表面上？
5. 摄影师想从侧面拍摄测试运动员的终点线。相机物体到最近跑步者的距离为$d = 10$米。相机物体的焦距为$F = 100$毫米。胶片上图像轮廓的模糊度不应超过$\Delta l = 0,1$毫米。如果运动员以大约 $v = 10$ m/s 的速度完成比赛，请估计暴露时间。
6. 一些金属的红色 photofect 边框 $\lambda_{\max} = 2750\text{Å}$。引起光效应的最小光子能量值是多少？
