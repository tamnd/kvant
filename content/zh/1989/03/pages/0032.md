吹到$k > 1$
$$t_{k+1} = \frac{a_{k+1}}{a_k} = 2 + \frac{a_{k-1}}{a_k} = 2 + \frac{1}{t_k}.$$
(4)

让我们用 $\tau$ 表示方程的正根
$$\tau = 2 + \frac{1}{\tau} \Leftrightarrow \tau^2 - 2\tau - 1 = 0,$$
即$\tau = \sqrt{2} + 1$。然后
$$t_{k+1} - \tau = t_{k+1} - 1 - \sqrt{2} = \frac{1}{t_k} + 1 - \sqrt{2} = \frac{1}{t_k} - \frac{1}{\tau} = \frac{\tau - t_k}{t_k\tau},$$
在哪里
$$a_{k+1} - \tau b_{k+1} = (t_{k+1} - \tau) a_k = \frac{(\tau - t_k) a_k}{t_k\tau} = \frac{\tau b_k - a_k}{\tau} = \frac{\tau b_k - a_k}{\sqrt{2} + 1},$$
所以
$$|a_{k+1} - \tau b_{k+1}| < |\tau b_k - a_k|/2.$$

因此，当从$k$移动到$k+1$时，从点$(b_k; a_k)$到直线$y = \tau x$的垂直距离增加了一倍多（并且震级符号$a_k - \tau b_k$以英寸为单位）。如果序列$w$是（至少从某个位置开始）周期性的，并且周期内有$p$个字母$A$和$q$字母$B$，那么整个构造的折线将包含在某个条带中，该条带的边缘将具有斜率$p/q$。但直线$y = \tau x$完全离开这条带并远离它，因为数字$\tau = 1 + \sqrt{2}$是无理数并且不等于$p/q$。因此，从某个$k$开始的折线点$(b_k; a_k)$并不完全位于这样的条带中。由此可见序列$w$没有句点。

这个证明不需要格子纸和破纸的帮助就可以呈现。简而言之，如果前$n$字母$w$中有$\alpha(n)$字母$A$和$\beta(n)$字母$B$，则对于周期序列$w$，极限$\lim \frac{\alpha(n)}{\beta(n)}$必须等于有理数；另一方面，对于其序列$t_k = \alpha(s_k)/\beta(s_k) = a_k/b_k$，由式（4）可知极限只能等于$\sqrt{2} + 1$（由（5）很容易看出该极限的存在）。

请注意，我们可以从字母 $A$ 和 $B$ 中辨别出数字 $\sqrt{2} + 1$ 和序列 $w$（以及单词 $w_k$）之间更深层的联系。重点在于，由于（4）

$$t_k = \frac{a_k}{b_k} = 2 + \frac{1}{2 + \frac{1}{2 + \dots + \frac{1}{2}}},$$

即 $t_k$ 是无限连分数的所谓“合适分数”

$$\tau = 1 + \sqrt{2} = 2 + \frac{1}{2 + \frac{1}{2 + \dots}};$$
