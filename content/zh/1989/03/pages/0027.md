但随后又揭示了另一个乍一看非常出乎意料的事实：由于$\psi > S_{\pi}$对于任何$u$，$N = kl\psi$总是大于$klS_{\pi}$。这意味着无论你跑得多快（甚至以子弹的速度飞行），“最小剂量”仍应等于$klS_{\pi}$，这是保证的。所以那些不喜欢匆忙的人的推理似乎有一定的逻辑。

2. $v_x > 0$（下雨）。

这里有两个区间需要考虑：

1) $0 < u \leq v_x$。然后$|v_x - u| = v_x - u$，并且

$$\psi = \frac{v_x S_{\pi} + v_y S_B + v_z S_B}{u} - S_{\pi}.$$

该函数在间隔 $(0; v_x]$ 处终止并在 $u = v_x$ 处达到最小值：

$$\psi |_{u = v_x} = \frac{v_y S_B + v_z S_B}{v_x}.$$

2) $u > v_x$。然后$|v_x - u| = u - v_x$，并且

$$\psi = \frac{-v_x S_{\pi} + v_y S_B + v_z S_B}{u} + S_{\pi}.$$

这里不再可能立即说出当$u$增加时$\psi$如何表现。它取决于分数 $A = -v_x S_{\pi} + v_y S_B + v_z S_B$ 的分子。如果$A > 0$，那么$\psi(u)$是段$(v_x; +\infty)$上的kill函数，如果$A < 0$在这个区间上递增，如果$A = 0$，那么$\psi = S_{\pi}$在这个区间上是const。

所有$u \in (0; +\infty)$的依赖图$\psi(u)$显示在图5上。可以看出，在从0到$v_x$的部分中，对于所有三种情况$(A > 0, A = 0$和$A < 0)$，曲线具有相同的外观，并且在$u = v_x$处断裂之后，它们是不同的。

由此得出什么结论呢？事实是，被认为是不真实的“慢走”理论的支持者的论点在某些情况下被证明是出乎意料的有力和有意义，但更多关于这一点在下面。

结论

分析了图4和图5的计算结果和图表，我们就可以彻底回答如何逃盘的问题了。

因此，如果牌面是反击的，那么你需要尽快跑去抢断。如果棋盘是顺风的，那么首先你需要在心里估计$A = -v_x S_{\pi} + v_y S_B + v_z S_B$的值。如果结果是$A > 0$，那么在这种情况下，建议抓紧时间。如果$A = 0$，你可以以任何超过$v_x$的速度移动，你都会同样被淋湿。好吧，如果 $A < 0$ - 您需要严格以等于 $v_x$ 的速度跑步 - 那么您会弄湿最少。

比如说，如果$v_y = 0$（顺风的情况），则不等式$A < 0$等价于不等式$v_x S_{\pi} > v_z S_B$。由于对于又高又瘦的人来说，$S_{\pi}$明显大于$S_B$，因此这种不等式对于相对较小的“行人”$v_x$也适用。这样的人，如果他开始偷窃，使水滴的轨迹看起来与他垂直，那么他就有机会保持干燥。这称为“液滴之间的滑动”。
