问题陈述
以及必要的简化

让我们制定问题的条件：

一个男人站在街上。突然开始下雨。该人前往距离他最近的避难所，距离为 l。为了尽可能少地被淋湿，他应该以什么速度打动？

图 2.

任务已经定了，但是以这种形式，拜托，我们解决不了。确实，人是一种形状复杂的生物，当他移动时，他也在不断地改变他的形状（重新排列他的腿，挥动他的手臂......）。因此，进行准确的计算是一项极其困难的任务。因此，除了求解它的近似之外别无选择，因此我们重新表述该问题：

一个合适的平行物体，其面部面积为$S_B$、$S_B$和$S_J$（来自单词“侧面”、“顶部”和“前部”），以垂直于面部$S_J$的速度快速移动。同时，正在下雨，每一滴雨滴的速度为 v (图 1)（矢量 v 不一定垂直向下 - 雨也可以是倾斜的）。单位体积的雨滴数为k。问题是：在平行物体移动距离l的时间内，会有多少个水滴N落到平行物体上，在速度i为多少时，这个值N最小？

让我们开始讨论解决方案

我们引入一个空间坐标系$Oxyz$：轴$Oz$垂直向下，轴$Ox$指向矢量$\bar{u}$方向，轴$Oy$垂直于平面$Oxz$，因此下落雨滴v的速度矢量在轴$Oy$上的投影是非负的（图2）。由于给出了向量 v，我们可以假设向量 v 在坐标轴上的投影是已知的。我们称它们为 $v_x$、$v_y$ 和 $v_z$。对于这些预测可以说些什么？当然是$v_y \geq 0$（我是这样选择的

到轴$Oy$）。另外，$v_z > 0$（只能从上到下）。但$v_x$的值可以是正值（传递收入），也可以是负值（反收入），甚至可以为零。

我们将解决与平行六面体相关的参考系中的问题，即我们将考虑平行六面体静止：那么我们必须在该参考系上获得速度$\bar{w} = \bar{v} - \bar{u}$。速度矢量 $\bar{w}$ 在坐标轴上的投影将为 $w_x = v_x - u, w_y = v_y, w_z = v_z$（u 是矢量 $\bar{u}$ 的长度）。需要确定在$\tau = l/u$时间内有多少滴$N$落在平行六面体上，以及在$u$时值$N$最小。

很明显，在时间$\tau$，所有的水滴都会落在平行六面体上，从这里到平行六面体的侧面，距离不大于$\tau \cdot |\bar{w}|$，方向与向量$\bar{w}$相反，即所有水滴位于图上红线所画的物体体积内。 3. 如何求这个物体的体积？容易注意到，这个体由三个棱柱组成，其底面积分别等于$S_\pi, S_B$和$S_B$，高分别为向量$\tau \cdot \bar{w}$在轴$Ox, Oy$和$Oz$上的投影的横坐标值。因此，该物体的体积等于

$$\tau(|w_x|S_\pi + |w_y|S_B + |w_z|S_B) = \tau(|v_x - u|S_\pi + v_y S_B + v_z S_B),$$

所需滴数$N$等于$\tau k(|v_x - u|S_\pi + v_y S_B + v_z S_B)$。

考虑到$\tau = l/u$，我们得到$N$对$u$的依赖关系：

$$N = kl \frac{|v_x - u|S_\pi + v_y S_B + v_z S_B}{u}.$$

现在让我们找到一个 $N$ 最小的 $u > 0$。

让我们继续解决方案

由于数量$k$和$l$是恒定的，为了方便我们将使用数量进行操作

$$\psi = \frac{N}{kl} = \frac{|v_x - u|S_\pi + v_y S_B + v_z S_B}{u}.$$

让我们考虑两种情况：

1. $v_x \leq 0$（即将到来的死亡）。

在这种情况下，$v_x - u < 0$，函数$\psi$采用以下形式：

$$\psi = \frac{(u - v_x)S_\pi + v_y S_B + v_z S_B}{u} = S_\pi + \frac{-v_x S_\pi + v_y S_B + v_z S_B}{u}.$$

从 $v_x \leq 0$ 开始，分数的分子为正，函数 $\psi(u)$ 在区间 $(0; +\infty)$ 上终止。函数$\psi$与$u$的关系图如图4所示。我们看到，虽然$\psi$随着$u$的增加而死亡，但它仍然总是$\psi > S_\pi$，$\psi \rightarrow S_\pi$在$u \rightarrow \infty$。因此，在遭遇迎面而来的撞击时，“毫不犹豫”理论的支持者似乎是错误的：跑得越快，淋湿的就越少。奥达纳-

但随后又揭示了另一个乍一看非常出乎意料的事实：由于$\psi > S_{\pi}$对于任何$u$，$N = kl\psi$总是大于$klS_{\pi}$。这意味着无论你跑得多快（甚至以子弹的速度飞行），“最小剂量”仍应等于$klS_{\pi}$，这是保证的。所以那些不喜欢匆忙的人的推理似乎有一定的逻辑。

2. $v_x > 0$（下雨）。

这里有两个区间需要考虑：

1) $0 < u \leq v_x$。然后$|v_x - u| = v_x - u$，并且

$$\psi = \frac{v_x S_{\pi} + v_y S_B + v_z S_B}{u} - S_{\pi}.$$

该函数在间隔 $(0; v_x]$ 处终止并在 $u = v_x$ 处达到最小值：

$$\psi |_{u = v_x} = \frac{v_y S_B + v_z S_B}{v_x}.$$

2) $u > v_x$。然后$|v_x - u| = u - v_x$，并且

$$\psi = \frac{-v_x S_{\pi} + v_y S_B + v_z S_B}{u} + S_{\pi}.$$

这里不再可能立即说出当$u$增加时$\psi$如何表现。它取决于分数 $A = -v_x S_{\pi} + v_y S_B + v_z S_B$ 的分子。如果$A > 0$，那么$\psi(u)$是段$(v_x; +\infty)$上的kill函数，如果$A < 0$在这个区间上递增，如果$A = 0$，那么$\psi = S_{\pi}$在这个区间上是const。

所有$u \in (0; +\infty)$的依赖图$\psi(u)$显示在图5上。可以看出，在从0到$v_x$的部分中，对于所有三种情况$(A > 0, A = 0$和$A < 0)$，曲线具有相同的外观，并且在$u = v_x$处断裂之后，它们是不同的。

由此得出什么结论呢？事实是，被认为是不真实的“慢走”理论的支持者的论点在某些情况下被证明是出乎意料的有力和有意义，但更多关于这一点在下面。

结论

分析了图4和图5的计算结果和图表，我们就可以彻底回答如何逃盘的问题了。

因此，如果牌面是反击的，那么你需要尽快跑去抢断。如果棋盘是顺风的，那么首先你需要在心里估计$A = -v_x S_{\pi} + v_y S_B + v_z S_B$的值。如果结果是$A > 0$，那么在这种情况下，建议抓紧时间。如果$A = 0$，你可以以任何超过$v_x$的速度移动，你都会同样被淋湿。好吧，如果 $A < 0$ - 您需要严格以等于 $v_x$ 的速度跑步 - 那么您会弄湿最少。

比如说，如果$v_y = 0$（顺风的情况），则不等式$A < 0$等价于不等式$v_x S_{\pi} > v_z S_B$。由于对于又高又瘦的人来说，$S_{\pi}$明显大于$S_B$，因此这种不等式对于相对较小的“行人”$v_x$也适用。这样的人，如果他开始偷窃，使水滴的轨迹看起来与他垂直，那么他就有机会保持干燥。这称为“液滴之间的滑动”。
