让我们用 $w_k$ 表示第 $k$ 个单词。根据条件中指定的规则，从单词$w_k$得到单词$w_{k+1}$。利用这一点，我们可以通过归纳证明，对于$k > 1$，单词$w_{k+1}$由重复两次的单词$w_k$和$w_{k-1}$组成（对于$k = 2$和$k = 3$，这显示在页边空白中）：

$$w_{k+1} = w_k w_{k-1}.$$

事实上，将我们的规则应用于对应关系 (*)，我们从 $w_k$ 获得 $w_{k+1}$，从 $w_{k-1}$ 获得 $w_k$，因此，如果此对应关系适用于某些 $k$，则类似的对应关系也适用于 $k+1$：

$$w_{k+2} = w_{k+1} w_{k+1} w_k.$$

因此，对于所有$k > 1$，对应关系（*）被证明。

从这里开始，特别是语句a)：每个单词$w_k$是单词$w_{k+1}$的开头；因此所有$w_k$都是无限词$w = AABAABAAAB$的初始片段...

令$a_k$和$b_k$为单词$w_k$中的字母$A$和$B$的数量，$s_k = a_k + b_k$为单词$w_k$中的所有字母的数量。转移规则和等式（*）表示对应

$$b_{k+1} = a_k, a_{k+1} = 2a_k + b_k,$$

(1)

$$a_{k+1} = 2a_k + a_{k-1} (a_1 = 1, a_2 = 2),$$

(2)

$$s_{k+1} = 2s_k + s_{k-1} (s_1 = 1, s_k = 3).$$

它们使得找到序列 $a_k$、$b_k = a_{k-1}$ 和 $s_k$ ($k = 1, 2, 3, \dots$) 的第一项成为可能 - 见表。

让我们用$N_A(m)$表示第$m$第一个字母$A$出现的位置的编号。如果$a_n \leq m < a_{n+1}$，那么第$m$个字母$A$第一次出现在单词$w_{n+1}$中，并且从（*）很容易看出，

$$N_A(m) = \begin{cases} s_n + N_A(m - a_n), & \text{ если } m \leq 2a_n; \\ 2s_n + N_A(m - 2a_n), & \text{ если } 2a_n < m \leq a_{n+1}. \end{cases}$$

使用这些等式规则，我们找到问题 6) 的答案：

$$N_A(1988) = 2 \cdot 1393 + N_A(1988 - 2 \cdot 985) = 2786 + N_A(18) = 2786 + 17 + N_A(18 - 12) = 2803 + 7 + N_A(1) = 2811.$$

所以
$$|a_{k+1} - \tau b_{k+1}| < |\tau b_k - a_k|/2.$$

因此，当从$k$移动到$k+1$时，从点$(b_k; a_k)$到直线$y = \tau x$的垂直距离增加了一倍多（并且震级符号$a_k - \tau b_k$以英寸为单位）。如果序列$w$是（至少从某个位置开始）周期性的，并且周期内有$p$个字母$A$和$q$字母$B$，那么整个构造的折线将包含在某个条带中，该条带的边缘将具有斜率$p/q$。但直线$y = \tau x$完全离开这条带并远离它，因为数字$\tau = 1 + \sqrt{2}$是无理数并且不等于$p/q$。因此，从某个$k$开始的折线点$(b_k; a_k)$并不完全位于这样的条带中。由此可见序列$w$没有句点。

这个证明不需要格子纸和破纸的帮助就可以呈现。简而言之，如果前$n$字母$w$中有$\alpha(n)$字母$A$和$\beta(n)$字母$B$，则对于周期序列$w$，极限$\lim \frac{\alpha(n)}{\beta(n)}$必须等于有理数；另一方面，对于其序列$t_k = \alpha(s_k)/\beta(s_k) = a_k/b_k$，由式（4）可知极限只能等于$\sqrt{2} + 1$（由（5）很容易看出该极限的存在）。

请注意，我们可以从字母 $A$ 和 $B$ 中辨别出数字 $\sqrt{2} + 1$ 和序列 $w$（以及单词 $w_k$）之间更深层的联系。重点在于，由于（4）

$$t_k = \frac{a_k}{b_k} = 2 + \frac{1}{2 + \frac{1}{2 + \dots + \frac{1}{2}}},$$

即 $t_k$ 是无限连分数的所谓“合适分数”

$$\tau = 1 + \sqrt{2} = 2 + \frac{1}{2 + \frac{1}{2 + \dots}};$$

因此，点 $(b_k; a_k)$ 对应于与线 $y = \tau x$ 相邻的格子节点，比具有较小坐标的节点更接近（参见 «Kvant»，1983，第 5 期；1971，

a) 答案：是的。首先我们来计算一下

$$a = \frac{1}{\sqrt{19}+88} = \frac{88-\sqrt{19}}{88^2-19},$$

然后我们获得序数$88-\sqrt{19}$（$88^2-19$项$a$之和）、$176=(88+\sqrt{19})+(88-\sqrt{19})$、$1/176$和$1$（$176$项$1/176$之和）。

$$\frac{1}{x} - \frac{2}{\frac{1}{1+x}+\frac{1}{1/x-y}} = xy^2.$$

它的左侧可以计算为“Cheburashka”。因此，从数字$x$可以得到$x^3$（与$y=x$），$x^5=x^3 \cdot x^2$，$x^7=x^5 \cdot x^2$，...，$x^{19}$，即从$\sqrt{19}88$可以得到$88$，然后是$1/88$和$1$。

b) 答案：不。对$a\sqrt{19}+b\sqrt{88}$形式的数与不同数$a$和$b$应用允许的运算，我们将再次获得相同类型的数（特别是$1/(a\sqrt{19}+b\sqrt{88})=(a\sqrt{19}-b\sqrt{88})/(19a^2-88b^2))$）。因此，不可能从数$\sqrt{19}+88$中获得一。

$$p_1 + p_{\text{н1}} + \rho_{\text{воды}} g(2\Delta h) = p_2 + p_{\text{н2}},$$

其中$p_1$和$p_2$是气压，$p_{\text{н1}}$和$p_{\text{н2}}$是饱和水蒸气压力。

气压很容易用大气压$p_0$来表示，并通过体积和温度进行修改：

$$p_1 = p_0 \frac{T_1}{T_0} \frac{h_0}{h_0 - \Delta h}, p_2 = p_0 \frac{T_2}{T_0} \frac{h_0}{h_0 + \Delta h}.$$

从这里我们发现气压的差异：

$$\Delta p_{\text{возд}} = p_1 - p_2 = p_0 \left( \frac{T_1}{T_0} \frac{1}{1 - \Delta h/h_0} - \frac{T_2}{T_0} \frac{1}{1 + \Delta h/h_0} \right) =$$

$$= \frac{p_0}{T_0} \frac{T_1 - T_2 + (T_1 + T_2)\Delta h/h_0}{1 - (\Delta h/h_0)^2} \approx \frac{p_0}{T_0} \left( T_1 - T_2 + (T_1 + T_2)\frac{\Delta h}{h_0} \right)$$

（这里我们教的是$\Delta h/h_0 \ll 1$）。

根据问题的条件，管子弯曲处的饱和蒸汽压之差等于高度为$H = 140$m的水柱的压力：

$$\Delta p_{\text{н}} = p_{\text{н2}} - p_{\text{н1}} = \rho_{\text{возд}} g H = \frac{p_0 M_{\text{возд}}}{RT_0} g H.$$

现在从平衡条件我们找到关系

$$\frac{\Delta h}{h_0} = \frac{T_2 - T_1 + M_{\text{возд}} g H/R}{T_1 + T_2 + 2 \rho_{\text{возд}} g h_0 T_0/p_0} \approx 7 \cdot 10^{-3}$$

和已确定的水位差

$$2\Delta h \approx 8,4 \cdot 10^{-3} \text{ м} = 0,84 \text{ см}$$

（这里我们取$T_0 = 273$ K，$p_0 = 10^5$ Pa，$h_0 = 60$ cm）。
