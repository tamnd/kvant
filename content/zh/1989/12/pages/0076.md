3. 让我们假设相反的情况，即

$$k > \frac{1}{2} + \sqrt{2n}.$$

让$P \in S$。根据条件，至少有 $k$ 点与 $P$ 等距。从它们可以形成至少$C_k^2$对点A和B，使得$AP = BP$。由于该陈述对于任何点$P \in S$都成立，因此在$S$中至少有$nC_k^2$对点A和B，其中S中的至少一个点位于线段AB的垂直平分线上。

我们有：

$$nC_k^2 = n \frac{k(k-1)}{2} \geq \frac{n}{2} \left( \sqrt{2n} + \frac{1}{2} \right) \left( \sqrt{2n} - \frac{1}{2} \right) = \frac{n}{2} \left( 2n - \frac{1}{4} \right) = n \left( n - \frac{1}{8} \right) > n(n-1) = 2C_k^2.$$

由于 $C_k^2$ 是 S 中所有不同点对的数量，根据已证明的不等式，存在一对点 A 和 B 以及点 $P_1$、$P_2$、...、$P_m$、$m > 2$，使得 $AP_i = BP_i$、$i = 1, 2, ...$、$m$。所以要点

$$P_1, P_2, ..., P_m, m > 2$$位于同一条线上，这与条件相矛盾。

4. 设满足条件的四边形$ABCD$和点$P$的数据如图7所示。容易证明，对于数据$AD = R$和$BC = r$，当直线CD是与以A点和B点为圆心的圆的公切线时，$h$的量取最大值$h_0$ （图8）。然后，利用毕达哥拉斯定理，我们很容易发现

$$CD = \sqrt{(R+r)^2 - (R-r)^2} = 2\sqrt{Rr}$$

和$CD = CM + MD = 2\sqrt{rh_0} + 2\sqrt{Rh_0}$。

因此$\sqrt{Rr} = \sqrt{rh_0} + \sqrt{Rh_0}$，最后是$\frac{1}{\sqrt{h}} \geq \frac{1}{\sqrt{h_0}} = \frac{1}{\sqrt{AD}} + \frac{1}{\sqrt{BC}}$。

5. 设$N = p_1p_2 \dots p_k$，其中$p_1, p_2, \dots, p_k$是不超过给定$n > 2$的所有质数。让我们看一下数字$N! + 1, N! + 2, ..., N! + n$。假设有 $1 \leq j \leq n$ 和一个素数 $p$，其中 $N! + j = p^m$。由于$N > n$，$N!$可被$j$整除，但随后$j = p^\alpha$（$\alpha < m$）和$p < n$。缩短$j$我们得到$p^{m-\alpha} = 1 + 2 \cdot 3 \dots (j-1)(j+1) \dots N$，这是不可能的。

6. 将数字 1, 2, ..., 2n 分成对：$(1; n+1), (2; n+2), ..., (n; 2n)$。如果至少一对的数字相邻，则排列将很方便。令 $A_k$ 为排列集合，其中数字 $n$ 和 $n+k$ 相邻。

令$|x|$为集合$X$中的元素数量。我们必须证明

$$\bigcup_{k=1}^{n} A_k > \frac{1}{2}(2n)!.$$

注意$\bigcup_{k=1}^{n} A_k \geq \sum_{k=1}^{n} |A_k| - \sum_{1 \leq i < j \leq n} |A_i \cap A_j|$。在 2n 个元素的排列中，可以通过 2n-1 种方式选择连接元素对，并且可以通过两种方式将数字 $k$ 和 $n+k$ 放置在这些位置。因此$|A_i \cap A_j| = 8(n-1)(2n-3)! = 4(2n-2)!$。

所以，$\sum_{i,j} |A_i \cap A_j| = 4C_k^2(2n-2)! = \frac{n-1}{2n-1} \times (2n)! < \frac{1}{2}(2n)!$。我们终于得到了$\sum_{k=1}^{n} |A_k| - \sum_{i,j} |A_i \cap A_j| > \frac{1}{2}(2n)!$。
