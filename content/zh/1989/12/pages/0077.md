任务1
a) 当饱和蒸气压等于大气压时发生沸腾：$p_i = p_0 \Rightarrow \ln(p_i/p_0) = 0$。从沸点公式$\ln(p_i/p_0) = a_i/T + b_i$我们得到

$$T_{\kappa i} = -a_i/b_i.$$ (*)

从表中可以得到$a_i$和$b_i$的数值：
$$a_A = -3748 \text{ K}, a_B = -5122 \text{ K}, b_A = 1072, b_B = 13,73.$$

最后

$$T_{\kappa A} \approx 350 \text{ K}, T_{\kappa B} \approx 373 \text{ K}.$$

b) 最初（原始图表上的第一个斜率），液体升温。表面没有蒸发。形成的气泡的距离由内部液体 $A$ 或内部液体 $B$ 或在它们的边界处的波动引导。如果它出现在$A$内部，则其中的压力为$p = p_A(T)$，如果在$B$内部，则为$p = p_B(T)$，如果在边界处，则为$p = p_A(T) + p_B(T)$。让在某个温度$T_x$
$$p_A(T_x) + p_B(T_x) = p_0.$$

在这种情况下，$p_A(T_x) < p_0$和$p_B(T_x) < p_0$，即$A$和$B$中的气泡将会消失，但不会在边界处消失。该气泡开始上升，应该到达液体表面，并且将观察到临界沸腾。从条件中查出温度$T_x$

$$p_A(T_x) + p_B(T_x) = p_0 \Rightarrow e^{a_A/T_x + b_A} + e^{a_B/T_x + b_B} = 1.$$

准确地求解这个方程是相当困难的。但由于条件要求精度为1K，因此可以使用计算器通过位置除法来求解该方程。我们得到$T_x = 340$ K。在这种沸腾过程中，$T = \text{const}$，这意味着第一个水平部分和$T_1 = T_x = 340$ K 对应于边界沸腾。体积为$V$的气泡带走质量为$m_A$的物质$A$和$m_B$的物质$B$：

$$\frac{p_A V}{T_x} = \frac{m_A}{M_A} R, \frac{p_B V}{T_x} = \frac{m_B}{M_B} R \Rightarrow \frac{m_A}{m_B} = \frac{p_A}{p_B} \frac{M_A}{M_B}.$$

将$T_x$代入方程(*)，可得到$p_A/p_B$的值，并求出$m_A/m_B = 22,4$，即$A$的质量减少速度是$B$质量的22.4倍。当$A$的物质用完时，$B$的物质的一部分会沸腾，剩下一部分：

$$\Delta m_B = m_B/m_A, m'_B = m(1 - m_B/m_A) = 95,5 \text{ г}.$$

现在边界沸腾已经结束，下一个倾斜部分对应于物质$B$切割到其沸腾温度。物质$B$的量不变，因此此时$\tau_1$$m_A = 0, m'_B = 95,5 \text{ г}$。显然，$T_2$是$B$物质的沸点，即$T_2 \approx 373$ K。

任务2
让我们考虑这些物体在与 $o$ 轴相关的惯性报告系统中的运动（它的存在是因为物体系统是孤立的）。由于物体的构型不会改变，根据动量守恒定律$\omega = \text{const}$。让我们表示向量 $\vec{P}_1\vec{P}_2 = a_{12}, \vec{P}_1\vec{P}_3 = a_{13}, \vec{P}_1\vec{O} = \vec{R}_1$，其中 $O$ 是质心 (图 9)。根据质心的定义

$$\vec{R}_1 = \frac{1}{M} (m_3\vec{a}_{13} + m_2\vec{a}_{12}),$$

其中$M = m_1 + m_2 + m_3$。让我们考虑质量 $m_1$。其加速度为

$$a_1 = \omega^2 \vec{R}_1 = \frac{\omega^2}{M} (m_3\vec{a}_{13} + m_2\vec{a}_{12}).$$

$m_2$ 和 $m_3$ 作用在 $m_1$ 上的力等于相应的

$$\vec{F}_{12} = G \frac{m_1 m_2}{a_{12}^2} \vec{a}_{12}, \vec{F}_{13} = G \frac{m_1 m_3}{a_{13}^2} \vec{a}_{13}.$$

根据牛顿第二定律

$$\vec{F}_{12} + \vec{F}_{13} = m_1\vec{a}_1,$$

IE。

$$\frac{m_2}{a_{12}^2} \vec{a}_{12} + \frac{m_3}{a_{13}^2} \vec{a}_{13} = \frac{\omega^2}{GM} m_2\vec{a}_{12} + \frac{\omega^2}{GM} m_3\vec{a}_{13}.$$

由于点 $P_1, P_2$ 和 $P_3$ 不在同一条直线上，因此向量 $a_{12}$ 和 $a_{13}$ 是非剪切邻点，前面的等式意味着

$$\frac{m_2}{a_{12}^2} \vec{a}_{12} = \frac{\omega^2}{GM} m_2\vec{a}_{12}, \frac{m_3}{a_{13}^2} \vec{a}_{13} = \frac{\omega^2}{GM} m_3\vec{a}_{13},$$

在哪里

$$a_{12} = \sqrt{\frac{GM}{\omega^2}}, a_{13} = \sqrt{\frac{GM}{\omega^2}}.$$

考虑点$P_2$或$P_3$，以此类推可得

$$a_{23} = \sqrt{\frac{GM}{\omega^2}}.$$

因此，必要条件是以下等式：

$$a_{12} = a_{13} = a_{23} = \sqrt{\frac{G}{\omega^2}} (m_1 + m_2 + m_3).$$
