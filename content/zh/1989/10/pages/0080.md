11. $\frac{p^3-p^2}{2}$。解：对于任何$m$，$m^p+(p-m)^p$之和可被$p^2$整除（证明见下文）。由于对于$m=1$、...、$p-1$，数字$m^p$和$(p-m)^p$本身不能被$p^2$整除，因此这些数字除以$p^2$的余数之和等于$p^2$。这意味着数字$1^p$、$2^p$、...、$(p-1)^p$除以$p^2$的余数之和，即$1^p$、$(p-1)^p$； $2^p$、$(p-2)^p$； ...（总共$\frac{p-1}{2}$对），等于$p^2\frac{p-1}{2}$。上述事实是牛顿二项式公式的推论。对于那些不知道这个公式的人，我们将提供更详细的证明。当打开$(p-m)^p=(p-m)...(p-m)$中的括号时，集合$p$将在$p+1$项中出现少于两次：$-m^p$和$p$乘以$pm^{p-1}$。因此，$m^p+(p-m)^p=m^p-m^p+p\cdot pm^{p-1}+(\text{число, делиеся на } p^2)$；这意味着 $m^p+(p-m)^p$ 可以被 $p^2$整除。

12. $\{(0, 2), (0, -2), (-2, -2), (-2, 2)\}$。解决方案。由于数字$x+1$与数字$x^2$互质，因此我们的等式仅适用于$x^2=x+1$、$x^2=-(x+1)$、$x+1=1$、$x+1=-1$或$x^2=0$。前两个方程没有整数解。所以，$x=0$或$x=-2$。

15. $0 \leq x \leq 4$。解决方案。首先，$|x| \leq 4$。进一步，既然$0 \leq \arcsin \frac{x^2-8}{8} + \frac{\pi}{2} \leq \pi$，那么$0 \leq \arcsin \frac{x}{4} \leq \frac{\pi}{2}$。所以，$0 \leq x \leq 4$。我们来计算该水平两侧的余弦：

$$\cos \left( \arcsin \frac{x^2-8}{8} + \frac{\pi}{2} \right) = -\sin \arcsin \frac{x^2-8}{8} = \frac{8-x^2}{8},$$

$$\cos \left( 2\arcsin \frac{x}{4} \right) = 1-2\sin^2\arcsin \frac{x}{4} = 1-2\left(\frac{x}{4}\right)^2 = \frac{8-x^2}{8}.$$
