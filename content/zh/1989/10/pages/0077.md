1. 最简单的例子是 6·1、6·2、6·3。一般来说，我们考虑级数 A, 2A, ..., $(2n - 1)A$，其中 A = 1·2·3·...·(2n - 1)。

2. 通过将数字 1 与其他数字交换，我们可以将 1 与数字 2 相加。然后我们可以分两步将 1、2 对与数字 3 相加（首​​先移动数字 2，然后移动数字 1）。现在，三元组 1、2、3 可以分三步与数字 4 相加。依此类推。结果，我们将得到这些数字的自然（单调）排序（顺时针或逆时针）。

3. 让我们分别用 K、M、P、T (图 14) 表示从 C 点到直线 AB、AE、DE 和 BD 的高度的底边。很明显，射线 CK 和 CP 位于射线 CT 和 CM 之间，并且四边形 KMPT 是凸的。因此，根据凸角定理，只要证明$\angle TKM + \angle MPT = 180^\circ$即可证明问题的陈述。让$\alpha = \angle DBC, \beta = \angle EAC$。显然，$\angle DCT = \alpha$（回想一下 CT ⊥ DB）和 $\angle MCE = \beta$。四个点 C、T、K、B 位于同一圆上，因为角 $\angle CTB$ 和 $\angle CKB$ 是直角。因此$\angle TKC = \angle TBC = \alpha$（这些角度相等，因为它们位于同一弧上）。类似地，$\angle CKM = \angle CAM = \beta$（点C、M、K、A位于同一圆上）、$\angle DPT = \angle DCT = \alpha$（点C、P、T、D位于同一圆上）、$\angle EPM = \angle ECM = \beta$（点E、M、P、C位于同一圆上）。因此，$\angle TKM + \angle TPM = (\alpha + \beta) + (180^\circ - \alpha - \beta) = 180^\circ$。这意味着所需的声明。

4. 从算术平均数和几何平均数的不等式来看，每个比值$\frac{a}{1 + a^2}, \frac{b}{1 + b^2}, \frac{c}{1 + c^2}$都不超过$\frac{1}{2}$。这意味着左翼不平等。让我们证明正确的不等式。让$x = 1 + a, y = 1 + b, z = 1 + c$。然后$x + y + z \leq 6$。将这个不等式除以 x, y, z 并将所得不等式相加，我们得到不等式

$$\left(1 + \frac{y}{x} + \frac{z}{x}\right) + \left(\frac{x}{y} + 1 + \frac{z}{y}\right) + \left(\frac{x}{z} + \frac{y}{z} + 1\right) \leq 6 \left(\frac{1}{x} + \frac{1}{y} + \frac{1}{z}\right),$$

从 $\frac{x}{y} + \frac{y}{x} \geq 2, \frac{y}{z} + \frac{z}{y} \geq 2, \frac{z}{x} + \frac{x}{z} \geq 2$ 开始，就得出了所需的不等式。
