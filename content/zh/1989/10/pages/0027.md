⟦folio 25⟧

Chitt，在完整区域中，余弦可能大于 1。

但我们偏离了 zeta 函数的故事及其意义。我们指定问题是求 ze(2), ze(4), ..., ze(2k), ... 的值，即级数的和。

$$1 + \frac{1}{2^2} + \frac{1}{3^2} + \dots + \frac{1}{n^2} + \dots,$$ (13)

$$1 + \frac{1}{2^4} + \frac{1}{3^4} + \dots + \frac{1}{n^4} + \dots$$ (14)

欧拉也解决了这个问题。为此，他接受了“是”并对无穷级数进行因式分解。他知道如果多项式$a_0x^n + a_1x^{n-1} + \dots + a_n$有根$x_1, x_2, \dots, x_n$，那么等式

$$a_0x^n + a_1x^{n-1} + \dots + a_n = a_n\left(1 - \frac{x}{x_1}\right) \times \left(1 - \frac{x}{x_2}\right) \dots \left(1 - \frac{x}{x_n}\right)$$ (15)

（毕竟，这个等式的两边在 $x = x_1, x_2, \dots, x_n$ 处消失，并且在 $x = 0$ 处两边都等于 $a_n$）。欧拉大胆地将这个公式应用到无穷级数上。由于函数$\frac{\sin x}{x}$在$\pm n\pi$形式的点处消失，其中$n$是自然数，他类比公式（15），写出

$$\frac{\sin x}{x} = \left(1 - \frac{x}{\pi}\right)\left(1 + \frac{x}{\pi}\right) \times \left(1 - \frac{x}{2\pi}\right)\left(1 + \frac{x}{2\pi}\right) \dots$$

（欧拉在这里还使用了$x = 0$的等式$\frac{\sin x}{x} = 1$，读者可能更愿意将其替换为$x \to 0$的极限$\frac{\sin x}{x}$的公式。但是欧拉并不害怕在“代数与分析”中抓住三元组！）在此之后，对连接项进行分组，欧拉得到：

$$\frac{\sin x}{x} = \left(1 - \frac{x^2}{\pi^2}\right)\left(1 - \frac{x^2}{2^2\pi^2}\right) \times \dots \times \left(1 - \frac{x^2}{n^2\pi^2}\right).$$ (16)

在这里，对欧拉出现的危险的无知很快就令人惊叹。不到一年后，德国数学家K.Weierstrass（1815-1897）严格证实了欧拉的解开。此外，他证明了如果任何（复）值$z$的函数$f(z)$是级数$a_0 + a_1z + \dots + a_nz^n + \dots$的和，那么它可以用类似于欧拉使用的方式进行因式分解。

由式(16)我们很容易得到级数(13)的和。只需要打开等式（16）右边的括号，然后根据公式（11）替换sin$x$，然​​后比较下一个和右边$x^2$的系数即可。让我们这样做吧。如果你打开最终产品中的括号

$$\left(1 - \frac{x^2}{\pi^2}\right)\left(1 - \frac{x^2}{4\pi^2}\right) \dots \left(1 - \frac{x^2}{n^2\pi^2}\right),$$

那么所得多项式的系数 $x^2$ 等于

$$-\frac{1}{\pi^2} - \frac{1}{4\pi^2} - \dots - \frac{1}{n^2\pi^2};$$

如果我们将$n$指向无穷大，则该系数将趋于无穷级数之和

$$-\frac{1}{\pi^2} - \frac{1}{4\pi^2} - \dots - \frac{1}{n^2\pi^2} - \dots,$$

即$k - \frac{1}{\pi^2} \zeta(2)$。 $\frac{\sin x}{x}$ 的级数中 $x^2$ 的系数等于 $-\frac{1}{3!} = -\frac{1}{6}$。比较 $x^2$ 的系数，我们得到了完全意想不到的等式

$$\zeta(2) = 1 + \frac{1}{2^2} + \frac{1}{3^2} + \dots + \frac{1}{n^2} + \dots = \frac{\pi^2}{6}.$$ (17)

类似地，比较$x^4$左右的系数并考虑等式（14）和（17），我们得到

$$\zeta(4) = 1 + \frac{1}{2^4} + \frac{1}{3^4} + \dots + \frac{1}{n^4} + \dots = \frac{\pi^4}{90}.$$ (18)
