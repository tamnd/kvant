关于放大图像

V.A.博迪克、F.V.谢纳曼

透镜（或更复杂的光学系统）中发光物体的图像的特征之一是其放大率。纵向增量和横向增量合理区分。例如，镜头以直角 ABC (图 1) 的形式给出物体的图像。然后纵向增加

$$\beta = \frac{f_B - f_A}{d_A - d_B},$$

和横向 -

$$\Gamma = \frac{B'C'}{BC} = \frac{H'}{H},$$

其中$d$为发光点到透镜的距离，$f$为透镜到该点像的距离，$H$为发光物体的横向尺寸，$H'$为其像的横向尺寸。

如果物体垂直于聚光透镜的光轴并且透镜创建其实际图像（图2），则横向放大倍率

$$\Gamma = \frac{H'}{H} = \frac{f}{d} = \frac{F}{d - F} = \frac{f - F}{F}. \tag{1}$$

如果会聚透镜产生迷你图像 (图 3)，则

$$\Gamma = \frac{H'}{H} = \frac{f}{d} = \frac{F}{F - d} = \frac{f + F}{F}. \tag{2}$$

使用漫射透镜时 (图 4)

$$\Gamma = \frac{H'}{H} = \frac{f}{d} = \frac{F}{F + d} = \frac{F - f}{F}. \tag{3}$$

让我们展示一下两个薄透镜系统的横向放大倍率如何相等。根据定义$\Gamma = H'/H$。将分子和分母乘以 $H_0$ -

现在我们来看看一些具体的任务。其中很多是莫斯科物理技术学院不同年份的入学考试券。

任务 1. 使用薄透镜，在屏幕上获得放大五倍的物体图像。在不改变镜头位置的情况下，屏幕沿光轴移动$l=30$ cm。为了获得清晰的图像，还必须移动物体。在这种情况下，图像比物体第二大。物体移动了多远？

在这两种情况下，物体的图像都是真实的（因为它是在屏幕上获得的），并且是由会聚透镜创建的。让我们写下第一种情况的透镜公式 -

$$\frac{1}{d} + \frac{1}{f} = \frac{1}{F}$$

对于第二个 (图 5) -

$$\frac{1}{d+x} + \frac{1}{f-l} = \frac{1}{F}.$$

在这里，我们教导屏幕向镜头移动，物体远离镜头。只有在这些条件下，第二种情况的增加才会小于第一种情况。

从书面方程中，考虑到$f/d=5$和$(f-l)/(d+x)=3$的增加，我们得到

$$\frac{5}{f} + \frac{1}{f} = \frac{3}{f-l} + \frac{1}{f-l}.$$

从这里

$$f=3l, \quad d=\frac{3}{5}l, \quad x=\frac{l}{15}=2\text{ см}.$$

如果屏幕没有移近镜头，而是远离镜头，则从放大倍率

$$\frac{1}{d} + \frac{1}{f} = \frac{1}{F} \quad \text{и} \quad \frac{1}{d-x} + \frac{1}{f+l} = \frac{1}{F}$$

问题2. 两条焦距为$F_1$和$F_2$的细收集线紧紧地压在一起。在主光轴上，有一条垂直于它的线，高度为H。该线到第一条线的距离为$F_1$。求出图像的高度。
首先，让我们求出两条紧靠在一起的细线系统的焦距。让光源位于第一条线的焦点处。然后，从它发出的光线将平行于主光轴，并会聚在第二条线的焦点处。将细线公式应用于系统
$$\frac{1}{F_1} + \frac{1}{F_2} = \frac{1}{F},$$
我们得到所需的焦距：
$$F = \frac{F_1 F_2}{F_1 + F_2}.$$
使用这个公式，我们可以找到蜡烛的横向放大率：
$$\Gamma = \frac{H'}{H} = \frac{F}{F_1 - F} = \frac{F_2}{F_1},$$
图像的高度是从哪里来的？
$$H' = H \frac{F_2}{F_1}.$$
问题 3. 平面镜被紧密地压在焦距为 F 的薄聚光面上。

损坏的物体距离线 2F。所描绘的物品有什么注意事项？
请注意，投射到线上的光线在被镜子反射后，会再次穿过该线。由于线很细并且紧紧地压在镜子上，我们用两条压线系统代替线镜系统，其焦距等于F/2。对于相当于该系统的线路，我们有
$$\Gamma = \frac{2F - F/2}{F/2} = 3.$$
问题 4. 正线创建了直径为 l 的月球图像。相同大小的月球图像是由负线创建的。如果这两条线彼此相邻（负线在前面），距离等于正线的焦距，那么月球图像的大小是多少？
设 α 为月球的角大小。那么月球的图像位于焦平面线中，并且在正线上具有尺寸 l = F_+ tan α 且 l = |F_-| tan α 为负 (图 6)。从这里我们得到
$$F_+ = |F_-|.$$

问题5. 两个会聚薄透镜——焦距F 1 = 5 cm 的L 1 和焦距F 2 = 3 cm的L 2 -以距离L一个位于另一个之后，使得它们的主光轴重合。物体位于透镜L 1 前方距离d 1 ＝15cm处。该系统可直接放大物体的图像。在什么 L 下这可能？

为了使物体的图像是直接的，需要L−f1>F2，其中f1是第一透镜与其中物体的图像之间的距离。从这里

$$L > F_2 + F_1 \frac{d_1}{d_1 - F_1} = 10,5 \text{ см.}$$

L 的第二个约束是通过增加来施加的：

$$\Gamma = \frac{F_1}{d_1 - F_1} \frac{F_2}{L - f_1 - F_2} > 1,$$

由此L<12cm。

最后

$$10,5 \text{ см} < L < 12 \text{ см.}$$

问题6. 使用薄透镜，获得三管ABCEDG（图7）的图像。圆棒AC的底面位于透镜的主光轴上，AB=BC。线段AB以放大倍数β 1 ＝6描绘，线段​​BC以放大倍数β 2 ＝3描绘。 BD 段显示的放大倍数是多少？

根据定义

$$\beta_1 = \frac{f_A - f_B}{d_B - d_A}.$$

我们用透镜公式来表达 f_A 和 f_B：

$$f_A = F \frac{d_A}{d_A - F}, \quad f_B = F \frac{d_B}{d_B - F}.$$

将f_A和f_B的表达式代入β₁的公式，我们得到

$$\beta_1 = \frac{F}{d_A - F} \frac{F}{d_B - F} = \Gamma_{AG} \Gamma_{BD}.$$

同样地，

$$\beta_2 = \Gamma_{BD} \Gamma_{CE},$$

$$\beta_3 = \Gamma_{AG} \Gamma_{CE},$$

其中 β₃ 是绘制线段 AC 的放大倍数。让我们表示AB=BC=a，那么

$$\beta_3 = \frac{\beta_1 a + \beta_2 a}{a + a} = \frac{\beta_1 + \beta_2}{2}.$$

变量 β1 和 β2，考虑等式 β₃=(\beta₁+\beta2)/2，我们得到

$$\beta_1 \beta_2 = \Gamma_{BD}^2 \frac{\beta_1 + \beta_2}{2},$$

在哪里

$$\Gamma_{BD} = \sqrt{\frac{2 \beta_1 \beta_2}{\beta_1 + \beta_2}} = 2.$$

请注意，例如，如果 AB → 0，则 β → Γ²。因此，物体的纵向和横向放大率是相互关联的。
