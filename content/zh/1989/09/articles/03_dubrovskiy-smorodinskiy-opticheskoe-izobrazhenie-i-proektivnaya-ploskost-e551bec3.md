图像和显示

为了使光学系统正常工作，从精确的光源（几何中心）发出的光束必须在穿过系统后再次变成中心光束。然后源的图像将出现在变换光束的中心。此外，图像可以通过两种方式创建：或者是离开光学系统的光线本身被收集在一个点上，然后它们就形成了真实的图像；此时放置电影屏幕或胶卷即可看到（图1，a）；或者系统出口处的光线形成发散光束，但它们的延续穿过一点 - 那么该图像称为

是最小的，尽管它正是可以直接看到的 (图 1, b)。最后，如果进入光学系统的光束是会聚的 (图 1, c)，那么我们就称之为最小源。系统质量越高，射线束公式就越准确。理想情况下，每个精确源（真实或最小）A都有一个精确图像$A'$（也可以是一种类型或另一种类型）。映射$p$出现，它将点$A$与点$A'$相关联。所以我们要找出设备如何显示这一点。

让我们从最简单的“光学系统”——平面镜开始。这里几乎没有什么需要解释的：很明显，映射 $p$ 是关于平面的对称性。这种映射可以考虑用于所有点，包括“穿过镜子”点：“穿过镜子”中的最小源在镜子前创建了真实图像（图2）。

中心投影和透镜公式

在收获我们在镜头方面的建设成果之前，我们将做出重要的保留。从一个光源发出的光线从主光轴（一条垂直于透镜穿过其中心的直线）向下传递时，被透镜聚焦到透镜上的一点。我们通过考虑整个平面上的映射 $p$ 来实现理想化。但事实并不会因此受到影响，因为我们所有的推理都可以在平面上的任何区域（无论多小）上重复，并获得相同的成功。

那么，让我们将我们的构造应用到镜头上。设$a$为主光轴，$a_1$为$a_1$平面内对应的直线，$P$投影$p_1$的中心。很明显，所有平行于 $a$ 的直线，通过此投影将变成通过直线 $a_1$ (图 6) 的同一点 $F_1$ 的直线 - 点 $P$ 沿直线 $a$ 到平面 $a_1$ 的平行投影。因此，平行于主轴的光束经过透镜后会聚在主轴 (图 7) 的点 $F'$，对应于点 $F_1$: $OF' = OF_1$，其中 $O$ 是透镜的中心。同样，从点$F$ - 沿直线$a_1$ 投影$P$ 到平面$\alpha$ 上的光线经过透镜后，变得平行于主轴。点$F$和$F_1$称为镜头的焦点。可以证明，对于单透镜系统，焦距$f = OF$和$f' = OF'$是相同的；对于更复杂的系统，它们可能会有所不同。

知道焦点的位置后，通过跟踪源自该点的两条光线（平行于轴的光线和穿过焦点 $F$ (图 8) 的光线），可以轻松构建不在主轴上的任何点 $A$ 的图像。这种结构是众所周知的。让我们再次强调，我们必然会走到这一步，本质上只是基于我们的“点图像假设”。 图 8 显示了点$B$ 的图像是如何在主轴上构建的。在这里，我们利用了这样一个事实：垂直于该轴的线 $AB$ 的图像是也垂直于该轴的线 $A'B'$，考虑到我们的中心投影，这一事实显而易见。使用中心投影可以轻松确定由理想线创建的图像的其他属性。

在这两种情况下，坐标变换都写为分数线性函数，即$y=(ax+b)/(cx+d)$形式的函数。相反，重写最后一个等式的形式

$$\left(y-\frac{a}{c}\right)\left(x+\frac{d}{c}\right)=\frac{bc-ad}{c^2},$$

与（2）类似，我们确信除线性（$c\neq 0$）和常数（$bc-ad\neq 0$）之外的任何分数线性函数都可以在几何上表示为一个坐标轴到另一个坐标轴的中心投影，以及上面投影的相应轴和中心。

平行投影很容易理解，用线性函数$y=ax+b$来表示。并且由于任意数量的线性函数和分数线性函数的组合将再次成为分数线性函数$^*$），因此直线的任何投影变换都由分数线性函数以坐标表示。

顺便说一下，从这里可以看出，直线的设计变换完全由三点的图像决定。事实上，使用这些点的坐标及其图像，可以为对应于线性分数函数的系数$a$、$b$、$c$、$d$编译三个方程。因此，系数将被指定为乘数，并且函数本身将被唯一指定。同理，知道两点$A$、$B$的坐标及其在平行投影下的图像$A'$、$B'$，就可以求出相应的线性函数，并借助它可以求出任意一点$C$的图像$C'$。然而，点 $C'$ 可以用更简单的方式构造：使用平行投影，该点划分线段的关系保持不变或不变，因此 $A'C':C'B'=AC:CB$。 （这里和下面我们假设线段是有向的；等式$AC:CB=k$意味着$\vec{AC}=k\vec{CB}$。）中心投影不保留关系$AC:CB$；畜栏保留了两种这样的关系。这个量称为四点的二倍比，表示为 (ABCD)，并且根据定义相等

$$\left(ABCD\right)=\frac{AC}{CB}:\frac{AD}{DB}.$$

*) 线性函数是分数线性函数的特例。

为了证明双重关系的不变性，考虑通过公共点 P (图 12) 的直线 a、b、c、d 以及与它们相交于点 A、B、C、D 的任意直线 l。让我们检查$(ABCD) = A_1C_1/B_1C_1$，其中 A_1、B_1、C_1 是与 d 平行的直线 l_1 与 a、b 和 c 的交点。显然，对于所有这些线，比率 A_1C_1/B_1C_1 是相同的，因此我们可以假设 l_1 通过 C，即 C_1 = C。根据三角形的相似性（读者可以轻松地在 图 12 上找到），我们有

$$\frac{AC}{AD} = \frac{A_1C}{PD}, \quad \frac{CB}{DB} = \frac{B_1C}{PD}.$$

然后

$$\frac{AC}{CB} : \frac{AD}{DB} = \frac{AC}{AD} : \frac{CB}{DB} = \frac{A_1C}{PD} : \frac{B_1C}{PD} = \frac{A_1C}{B_1C} = \frac{A_1C_1}{B_1C_1}.$$

因此，对于给定的线 a、b、c、d，双重关系 $(ABCD)$ 不依赖于线 l，这意味着它保留在中心投影下。

现在让我们知道点 A、B、C 在某种变换下的图像 A'、B' 和 C'。然后从对应关系$(A'B'C'D') = (ABCD)$或$A'D'/D'B' = (ABCD) \cdot (A'C'/C'B')$找到任意其他点D的图像D'。如果我们将这些等式写在坐标中，我们将得到另一个确认，即射影变换是由线性分数函数表示的，同时也找到了该函数的方法。作为练习，请读者通过直接计算检查双重关系相对于线性函数和函数 1/x 以及任何分数线性函数的不变性（因为任何分数线性函数也是复函数！）。

让我们再次回到镜头，其主光轴对应的投影变换p及其解析表达式——镜头公式。事实证明，这个公式也可以利用双重关系推导出来。假设在主轴上添加一个假想无限远的点 U，其坐标等于 ∞。条件是所有与轴平行的直线都经过该点。那么它应该被认为是函数F的图像，并且它自己的图像将是第二个函数F'。因此，我们知道变换 p 时三个点的去向：透镜中心 - p(O) = O、函数 - p(F) = U 和无限远点 - p(U) = F'。点O、F、F'和U的坐标分别等于0、f、f'和无穷大。如果r和r'是A点及其图像A'的坐标，则

$$(OFUA) = \frac{\infty - 0}{f - \infty} : \frac{r - 0}{f - r} = -\frac{f - r}{r} = 1 - \frac{f}{r},$$

$$(OUF'A') = \frac{f' - 0}{\infty - f} : \frac{r' - 0}{\infty - r'} = \frac{f'}{r'}.$$

使这些表达式相等（保留双倍比率！），我们得到透镜公式。证明这些三元组的有效性很容易：您只需达到等式 $(OBCA) = (OB'C'A')$ 的极限，即 B→F，OC→∞。然而，在下一节中我们看到，添加一个无限远的点具有深刻的含义，并且归因并不是纯粹形式上的接受，而是带有神秘感的边界。
