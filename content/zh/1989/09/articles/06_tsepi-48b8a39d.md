在数学中经常会遇到将后一个元素“依附”前一个元素的原理，例如在“连分数”中。任何正分数都可以以独特的方式写成以下形式：

$$\frac{p}{q} = a_0 + \frac{1}{a_1 + \frac{1}{a_2 + \dots + \frac{1}{a_n}}},$$

其中数字$a_1, a_2, \dots, a_n$是自然数，$a_0$是非负整数。例如，

$$\frac{13}{7} = 1 + \frac{1}{1 + \frac{1}{6}};$$

$$\frac{22}{7} = 3 + \frac{1}{7},$$

$$\frac{355}{113} = 3 + \frac{1}{7 + \frac{1}{16}}.$$

所有无理数也都表示为整数分数。所以，

$$\sqrt{2} = 1 + \frac{1}{2 + \frac{1}{2 + \dots}}$$

$$\frac{1 + \sqrt{5}}{2} = 1 + \frac{1}{1 + \frac{1}{1 + \dots}}$$

$$\pi = 3 + \frac{1}{7 + \frac{1}{15 + \frac{1}{1 + \dots}}}.$$
