⟦folio 8⟧

为了证明双重关系的不变性，考虑通过公共点 P (图 12) 的直线 a、b、c、d 以及与它们相交于点 A、B、C、D 的任意直线 l。让我们检查$(ABCD) = A_1C_1/B_1C_1$，其中 A_1、B_1、C_1 是与 d 平行的直线 l_1 与 a、b 和 c 的交点。显然，对于所有这些线，比率 A_1C_1/B_1C_1 是相同的，因此我们可以假设 l_1 通过 C，即 C_1 = C。根据三角形的相似性（读者可以轻松地在 图 12 上找到），我们有

$$\frac{AC}{AD} = \frac{A_1C}{PD}, \quad \frac{CB}{DB} = \frac{B_1C}{PD}.$$

然后

$$\frac{AC}{CB} : \frac{AD}{DB} = \frac{AC}{AD} : \frac{CB}{DB} = \frac{A_1C}{PD} : \frac{B_1C}{PD} = \frac{A_1C}{B_1C} = \frac{A_1C_1}{B_1C_1}.$$

因此，对于给定的线 a、b、c、d，双重关系 $(ABCD)$ 不依赖于线 l，这意味着它保留在中心投影下。

现在让我们知道点 A、B、C 在某种变换下的图像 A'、B' 和 C'。然后从对应关系$(A'B'C'D') = (ABCD)$或$A'D'/D'B' = (ABCD) \cdot (A'C'/C'B')$找到任意其他点D的图像D'。如果我们将这些等式写在坐标中，我们将得到另一个确认，即射影变换是由线性分数函数表示的，同时也找到了该函数的方法。作为练习，请读者通过直接计算检查双重关系相对于线性函数和函数 1/x 以及任何分数线性函数的不变性（因为任何分数线性函数也是复函数！）。

让我们再次回到镜头，其主光轴对应的投影变换p及其解析表达式——镜头公式。事实证明，这个公式也可以利用双重关系推导出来。假设在主轴上添加一个假想无限远的点 U，其坐标等于 ∞。条件是所有与轴平行的直线都经过该点。那么它应该被认为是函数F的图像，并且它自己的图像将是第二个函数F'。因此，我们知道变换 p 时三个点的去向：透镜中心 - p(O) = O、函数 - p(F) = U 和无限远点 - p(U) = F'。点O、F、F'和U的坐标分别等于0、f、f'和无穷大。如果r和r'是A点及其图像A'的坐标，则

$$(OFUA) = \frac{\infty - 0}{f - \infty} : \frac{r - 0}{f - r} = -\frac{f - r}{r} = 1 - \frac{f}{r},$$

$$(OUF'A') = \frac{f' - 0}{\infty - f} : \frac{r' - 0}{\infty - r'} = \frac{f'}{r'}.$$

使这些表达式相等（保留双倍比率！），我们得到透镜公式。证明这些三元组的有效性很容易：您只需达到等式 $(OBCA) = (OB'C'A')$ 的极限，即 B→F，OC→∞。然而，在下一节中我们看到，添加一个无限远的点具有深刻的含义，并且归因并不是纯粹形式上的接受，而是带有神秘感的边界。
