急刹车时，车轮不会自动移动，而是滑动（这是快速刹车的唯一方法）。那么根据牛顿第二定律可以得出

$$ma = F_{\text{тр}} = \mu mg, \quad \text{т. е. } a = \mu g,$$

其中$\mu$是滑动摩擦系数。

有两种可能的情况，分别如图 1 和图 2 所示。第一种情况：加速度$a_1$使得底部部分打开。在评估时，我们会假设身体是直的。那么制动前车身内的混凝土质量

$$M = \rho L H d,$$

其中$\rho$是溶液的密度，$d$、$H$和$L$是物体的宽度、高度和长度。从图1可以看出，$H/l = tg \alpha = a_1/g$、$l = Hg/a_1 \leq L$打开，即

$$a_1 = \mu_1 g \geq \frac{H}{L} g.$$

体内剩余混凝土重量

$$m_1 = \rho l \frac{H}{2} d = \rho \frac{H^2 d}{2 a_1} g.$$

因此，剩余混凝土的比例

$$\eta_1 = \frac{m_1}{M} = \frac{\rho H^2 d}{2 a_1 \rho L H d} = \frac{H}{L} \frac{g}{2 a_1} = \frac{H}{L} \frac{1}{2 \mu_1}$$

在$\mu_1 \geq \frac{H}{L}$。

第二种情况（见图2）：加速度$a_2$使得后挡板脱离砂浆深度$h = L tg \alpha = La_2/g$，那里的砂浆层深度为$H - h = H - La_2/g$。体内残留溶液的重量

$$m_2 = \rho L \left( H - L \frac{a_2}{2 g} \right) d,$$

以及剩余溶液的比例

$$\eta_2 = \frac{m_2}{M} = \frac{\rho L \left( H - La_2/(2 g) \right) d}{\rho L H} = 1 - \frac{L}{H} \frac{a_2}{2 g} = 1 - \frac{L}{H} \frac{\mu_2}{2}$$

在$\mu_2 < \frac{H}{L}$。

让我们进行数值估计。让我们输入 $H = 1$ m，$L = 5$ m，即 $H/L = 0,2$。然后在$\mu_1 \geq H/L = 0,2$，例如在$\mu_1 = 0,5$，我们有

$$\eta_1 = \frac{H}{L} \frac{1}{2 \mu_1} = \frac{1}{5} = 20 \%.$$

在$\mu_2 < H/L = 0,2$，例如在$\mu_2 = 0,1$，我们有

$$\eta_2 = 1 - \frac{L}{H} \frac{\mu_2}{2} = \frac{3}{4} = 75 \%.$$

如果制动不剧烈，即车轮晃动，则为滚动摩擦制动。在这种情况下 $\mu \approx 0,02$ 和

$$\eta_1 = 1 - \frac{L}{H} \frac{\mu}{2} \approx \frac{19}{20} \approx 95 \%.$$

所以，无论如何，身体都无法补充：损失是不可避免的。
