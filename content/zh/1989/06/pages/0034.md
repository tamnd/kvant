M1142。表$m \times n$填入mn个数字，使得每行每列这些数字形成一个等差数列。表节点处的四个数字之和等于 s。表中所有数字的总和是多少？

答案：$smn/4$。

令 $a_1, a_2, \dots, a_m$ 为顶行的数字，$b_1, b_2, \dots, b_m$ 为底行的数字。然后$a_1 + a_2 + \dots + a_m = (a_1 + a_m)m/2, b_1 + b_2 + \dots + b_m = (b_1 + b_m)m/2$。

各列中的数字之和为 $(a_1 + b_1)n/2, (a_2 + b_2)n/2, \dots, (a_m + b_m)n/2$。将这些总和相加，我们得到表中所有数字的总和：
$$(a_1 + b_1 + a_2 + b_2 + \dots + a_m + b_m)n/2 = (a_1 + a_m + b_1 + b_m)mn/4 = smn/4.$$

M1143。围成一圈的 101 个蘑菇的质量均为自然数，总质量为 300 克。证明可以从这组蘑菇中选择一个总质量为 200 克的排成一排的蘑菇。

让我们在圆上标记 300 个点，将其分为 300 个等份（每个$1^\circ 12'$），并将 $m$ 个等份的弧分配给每个质量为 $m$ 的蘑菇；这些弧的末端（以与蘑菇相同的顺序围绕圆排列）称为点，其余 300-101=199 个点称为黑色。让我们考虑所有内接于圆的等边三角形，其中一个具有红色顶点。如果每个顶点都有两个黑色顶点，那么总共至少有 $2 \cdot 101 = 202$ 个黑点。因此，它会找到一个两个顶点都是红色的三角形。末端位于这些红色顶点的较大弧线（$240^\circ$）对应于总质量为 200 克的蘑菇，较小的弧线（$210^\circ$）对应于总质量为 100 克的蘑菇。
