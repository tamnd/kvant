线性不等式的相关系统

给定一个具有$n$未知数$x_1, \dots, x_n$的线性不等式系统——我们将其称为“系统$S$”。下面，我们只考虑$\geq$类型的不等式。因此，系统$S$具有形式

$$\begin{cases} L_1 \geq 0, \\ L_2 \geq 0, \\ \dots \dots \\ L_m \geq 0, \end{cases}$$

其中每个 $L_i$ ($i=1, 2, \dots, m$) 是以下形式的表达式

$$a_1x_1 + a_2x_2 + \dots + a_nx_n + a.$$

在考虑 $S$ 系统时，出现两个主要问题：

a) 系统是否一致，即是否至少有一个解$x_1 = x_1^0, x_2 = x_2^0, \dots, x_n = x_n^0$；

b) 如果是，如何找到它的所有解？

考虑系统$S$的任何不等式。看起来像

$$a_1x_1 + a_2x_2 + \dots + a_nx_n + a \geq 0.$$ (*)

如果 $a_n = 0$，则保持不等式 (*) 不变。如果$a_n \neq 0$，那么根据$a_n$的符号，我们将其简化为$P_n \geq x_n$（对于$a_n \geq 0$）或$Q \leq x_n$（对于$a_n < 0$）的形式。因此，系统的任何不等式$S$都可以简化为三种类型$R \geq 0, P \geq x_n, Q \leq x_n$之一，其中$R, P$和$Q$是以下形式的表达式

$$b_1x_1 + b_2x_2 + \dots + b_{n-1}x_{n-1} + b,$$

即线性多项式，已经依赖于第 $(n-1)$ 个变量。

因此，系统$S$等于系统$S_1$：

$$P_1 \geq x_n,$$
$$P_2 \geq x_n,$$
$$P_p \geq x_n,$$

$$x_n \geq Q_1,$$
$$x_n \geq Q_2,$$
$$x_n \geq Q_q,$$

$S_1$

一般来说，该系统由三个块组成，由框架概述。当然，也不排除系统$S_1$不会有一个甚至两个区块。这取决于数字$a_n$的符号。

现在让我们以与考虑示例时相同的方式构建一个具有较少数量未知数的系统：

$$\begin{cases} P_\alpha \geq Q_\beta, \\ R_\gamma \geq 0, \end{cases}$$

其中$\alpha = 1, 2, \dots, p, \beta = 1, 2, \dots, q, \gamma = 1, 2, \dots, r$。

这个系统中有$pq + r$个不平等。

系统$S^{(1)}$相对于原始系统$S$称为`conuctвуошей`。

如果事实证明在系统$S_1$中缺少第一个或第二个块，那么伴随的系统将仅包含不等式$R_\gamma \geq 0$，如果缺少第三个块，则它将仅包含不等式$P_\alpha \geq Q_\beta$。最后，如果第一块和第三块或者第二块和第三块缺失，则根本不存在伴随系统。我们将认为它在这种情况下也是有效的，即来自不等式$0 \geq 0$的状态（或者更准确地说，来自不等式$0 \cdot x_1 + \dots + 0 \cdot x_n + 0 \geq 0$）。
