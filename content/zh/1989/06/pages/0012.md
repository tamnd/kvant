⟦folio 10⟧

对于第一部分，第二部分 - 仅第二部分，第三部分 - 4/5 的时间产生第一部分，1/5 的时间 - 产生第二部分。对于第三种类型的机器也是如此。

从表中可以看出，最优分配提供了显着的好处——额外 9 组！ - 无需额外费用。

为了找到远离最优的最优分布，需要将问题转化为数学语言。因此，我们有七台机器可供使用 - 第一台、第二台和第三台机器构成第一类型，第四台、第五台和第六台构成第二类，最后第七台构成第三类。需要指出每台机器必须生产第一个和第二个零件的时间比例。令 $\alpha_i$ 为第 $i$ 台机器生产第一个零件的时间分数，$\alpha'_i$ 为其生产第二个零件的时间分数。然后$\alpha_i \geq 0$，$\alpha'_i \geq 0$，$\alpha_i + \alpha'_i \leq 1$，$i = 1, 2, \dots, 7$。机器制造的第一批零件的数量将等于

$$10(\alpha_1 + \alpha_2 + \alpha_3) + 20(\alpha_4 + \alpha_5 + \alpha_6) + 30\alpha_7.$$

类似地，第二部分的数量等于

$$20(\alpha'_1 + \alpha'_2 + \alpha'_3) + 30(\alpha'_4 + \alpha'_5 + \alpha'_6) + 80\alpha'_7.$$

第一和第二部分的数量应该相同并且尽可能大。所以我们来解决这个问题：

找到最大数 $s$ 使得

$$s = 10(\alpha_1 + \alpha_2 + \alpha_3) + 20(\alpha_4 + \alpha_5 + \alpha_6) + 30\alpha_7,$$

并将其代入$s$的表达式中。我们得到

$$s = \frac{230}{3} + \left(20 - \frac{50}{3}\right)y + \left(30 - \frac{110}{3}\right)z = \frac{230}{3} + \frac{10}{3}y - \frac{20}{3}z.$$

现在很清楚，当$y = 3,$时，将获得总和的最大值
