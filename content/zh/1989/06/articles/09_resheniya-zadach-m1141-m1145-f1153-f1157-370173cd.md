M1142。表$m \times n$填入mn个数字，使得每行每列这些数字形成一个等差数列。表节点处的四个数字之和等于 s。表中所有数字的总和是多少？

答案：$smn/4$。

令 $a_1, a_2, \dots, a_m$ 为顶行的数字，$b_1, b_2, \dots, b_m$ 为底行的数字。然后$a_1 + a_2 + \dots + a_m = (a_1 + a_m)m/2, b_1 + b_2 + \dots + b_m = (b_1 + b_m)m/2$。

各列中的数字之和为 $(a_1 + b_1)n/2, (a_2 + b_2)n/2, \dots, (a_m + b_m)n/2$。将这些总和相加，我们得到表中所有数字的总和：
$$(a_1 + b_1 + a_2 + b_2 + \dots + a_m + b_m)n/2 = (a_1 + a_m + b_1 + b_m)mn/4 = smn/4.$$

M1144。令 $a_1, a_2, \dots, a_n$ 为非负数。哪个数字更大：

$$\sqrt{a_1^{1988} + a_2^{1988} + \dots + a_n^{1988}}$$

或者

$$\sqrt{a_1^{1989} + a_2^{1989} + \dots + a_n^{1989}}$$?

答案：如果至少有两个数字$a_i$不等于0（我们将来会假设），则第一个数字更大。

让我们立即证明更一般的陈述：多夜函数$f(\alpha) = (a_1^\alpha + \dots + a_n^\alpha)^{1/\alpha}$减少为$\alpha > 0$，即$f(\alpha) > f(\beta)$减少为$0 < \alpha < \beta$。

不失一般性，我们可以假设$a_1$是$a_i$、$a_1 > 0$的最一般数。让我们先放置$x_i = a_i/a_1$，然后放置$\alpha < \beta$

$$f(\alpha) = a_1(1 + x_2^\alpha + \dots + x_n^\alpha)^{1/\alpha} \geq a_1(1 + x_2^\beta + \dots + x_n^\beta)^{1/\beta} = f(\beta),$$

让我们用 KPL (图 1) 表示与角 BPC 相切的三角形，并用 I 表示其内切圆的圆心。三角形 ABC 和 ILK 是相似的。事实上，角度 ABC、CAL 和 ACL 中的每一个都等于弧 AC 角度值的一半（第一个角内接于圆并位于该弧上，另外两个角由该弧所对的弦及其两端的切线形成）。这就是为什么

$$\frac{S_{PKL}}{S_{ILK}} = \frac{h}{r} = \frac{2S}{KL} \cdot \frac{p}{S} = \frac{2p}{KL} = \frac{2BP}{KL},$$

$$\eta_1 = \frac{m_1}{M} = \frac{\rho H^2 d}{2 a_1 \rho L H d} = \frac{H}{L} \frac{g}{2 a_1} = \frac{H}{L} \frac{1}{2 \mu_1}$$

在$\mu_1 \geq \frac{H}{L}$。

$$m_2 = \rho L \left( H - L \frac{a_2}{2 g} \right) d,$$

$$\eta_2 = \frac{m_2}{M} = \frac{\rho L \left( H - La_2/(2 g) \right) d}{\rho L H} = 1 - \frac{L}{H} \frac{a_2}{2 g} = 1 - \frac{L}{H} \frac{\mu_2}{2}$$

在$\mu_2 < \frac{H}{L}$。

$$\eta_1 = 1 - \frac{L}{H} \frac{\mu}{2} \approx \frac{19}{20} \approx 95 \%.$$

F1154。两个相同的质量为 m 的立方体放在主水平桌上。其中一个杯子粘在桌子上（参见图nok）。如果对立方体施加水平力 F，则立方体会脱离桌面。在立方体之间有一个取之不尽用之不竭的自由弹簧，其刚度为 k。松散的立方体的速度为 v。碰撞后，立方体将以什么速度飞散？

让我们用$v_1$和$v_2$表示碰撞后杯子的速度。根据能量守恒定律我们有

$$\frac{mv^2}{2} = \frac{mv_1^2}{2} + \frac{mv_2^2}{2}.$$

当第二个立方体从桌子上移开后，两个杯子的系统（其间有一个取之不竭的弹簧）立即关闭。让我们写出它的动量守恒定律。让我们用 u 表示第二个立方体离开桌子后第一个立方体的速度。然后我们得到

$$mu = mv_2 - mv_1.$$

由能量守恒定律我们求出速度u

$$\frac{mv^2}{2} = \frac{mu^2}{2} + \frac{kx^2}{2},$$

其中$x = F/k$是分离时刻弹簧力的大小。

求解方程组（1）-（3），我们发现

$$v_1 = \frac{1}{2}(\sqrt{v^2 + F^2}/(km) - \sqrt{v^2 - F^2}/(km)),$$

$$v_2 = \frac{1}{2}(\sqrt{v^2 + F^2}/(km) + \sqrt{v^2 - F^2}/(km)).$$

考虑一些局部案例很有趣。

F1157。有两个半透明镜子，经测量，每个镜子透射大约 1/5 的光通量，并反射其余的光。如果两个镜子都站在平行光束的路径上，使得它们的平面垂直于光束，那么看起来它们应该透射 1/25 的入射光，而实际上光的衰减不是 25 倍，而是明显减少（大约 10 倍）。解释是，第二个镜子反射的光线返回到第一个镜子，被部分反射，落在第二个镜子上，增加了透射光束的强度。

令 $I$ 为初始光束的强度（参见 图；为清楚起见，倾斜显示入射光束）。那么通过第一面镜子的光强度将等于$i_0 = I/k$，其中$k$是镜子的衰减系数（$k = 5$根据问题条件）。随着连续的反射，镜子之间“捕获”的光的强度由于镜子的部分能量而逐渐减小，并且在足够大量的反射之后，几乎所有“捕获”的光将被释放，左右几乎相等。因此，透射光的总强度将等于

$$I' \approx \frac{i_0}{2} = \frac{I}{2k} = \frac{I}{10}.$$

该问题还提供了精确的解决方案。让我们写下镜子之间“捕获”的光强度在连续反射过程中如何变化：

$$i_1 = i_0 \left(1 - \frac{1}{k}\right)^2, \quad i_2 = i_1 \left(1 - \frac{1}{k}\right)^2 = i_0 \left(1 - \frac{1}{k}\right)^4,$$

每次落在镜子 2 上时，光线都会部分地从右侧射出：

$$I_1 = \frac{i_0}{k}, \quad I_2 = \frac{i_1}{k}, \quad I_3 = \frac{i_2}{k},$$

总透射光强度

$$I' = I_1 + I_2 + I_3 + \dots = \frac{1}{k} \left(i_0 + i_1 + i_2 + \dots\right) = \frac{i_0}{k} \left(1 + \left(1 - \frac{1}{k}\right)^2 + \left(1 - \frac{1}{k}\right)^4 + \dots\right)$$

表示值为 $q = (1 - 1/k)^2$ 的无限递减几何级数之和，因此

$$I' = \frac{i_0}{k} \frac{1}{1 - q} = \frac{i_0}{k} \frac{k^2}{k^2 - (k - 1)^2} = \frac{i_0 k}{2k - 1} = \frac{I}{2k - 1} = \frac{I}{9}.$$

在 $k = 5$ 处，精确解与近似解仅相差 10%。
