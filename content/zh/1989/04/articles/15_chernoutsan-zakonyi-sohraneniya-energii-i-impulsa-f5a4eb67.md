能量和动量守恒定律

物理和数学科学候选人
A.I.切尔努特桑

本文讨论联合使用能量和动量这两个守恒定律来解决各种物理问题。

在物理学的应用考试中，当申请人分别对每个守恒定律有很好的了解时，当申请人需要在一项任务的框架内将这些定律结合在一起时，就会遇到“心理”困难。此外，在我们看来，最常见的情况是，一个更简单的定律——动量守恒定律——加速了消失。写下相应的能量方程后，申请人不再记得冲量 - 并且......陷入了麻烦。然而，情况却有所不同。

让我们看几个具体的例子，看看能量和冲动的共同“努力”如何带来期望的结果。

问题 1. 两个由相同材料制成且质量分别为 $m_1$ 和 $m_2$ 的球以速度 $v_1$ 和 $v_2$ 相向运动。如果球材料的比热容为c，那么在绝对非弹性冲击后，球的温度会升高多少？

球的初始温度迅速增加其内能：

$$\Delta E_{\text{вн}} = c (m_1 + m_2) \Delta t.$$

许多申请者错误地认为这是内力受到打击的结果

⟦folio 61⟧

系统的全部初始动能$m_1 v_1^2/2 + m_2 v_2^2/2$都转化为初始能量。同时，他们忘记了球在撞击后不能保持不变，因为这与动量守恒定律相矛盾——一般来说，系统的初始动量$m_1 \vec{v}_1 + m_2 \vec{v}_2$不等于0。这意味着在计算能量时，需要考虑球在最终状态下的动能。

让我们用 $v$ 表示绝对非弹性撞击后球塌陷的速度，并写出能量和动量守恒定律，更准确地说，是动量在第一个球运动方向上的投影：

$$\frac{m_1 v_1^2}{2} + \frac{m_2 v_2^2}{2} = \frac{(m_1 + m_2) v^2}{2} + \Delta E_{\text{вн}},$$

$$m_1 v_1 - m_2 v_2 = (m_1 + m_2) v.$$

求解三个方程，我们得到所需的温度升高：

$$\Delta t = \frac{m_1 m_2 (v_1 + v_2)^2}{2 c (m_1 + m_2)^2}.$$

问题 2. 质量为 $M_1$ 和 $M_2$ 的处女瓦隆以速度 $v_1$ 和 $v_2$ 相向运动。当发生碰撞时，四个相同的缓冲弹簧滚落，之后帷幔分开。如果弹簧常数为 $k$，求每个弹簧的最大变形量。

在这个问题中，与上一个问题不同，您可以利用机械能守恒定律（假设摩擦力很小且弹簧是理想的），将滚子的初始能量等于弹簧变形$x$最大时系统的能量。在这种情况下，所需值 $x$ 将包含在弹簧弹簧变形的势能中：

$$E_p = 4 k x^2/2.$$

然而，除了这种能量之外，还需要考虑瓦隆的动能。

事实上，在最大接近时，滚子不会停止（不幸的是，许多申请人忘记了这一点），正如前一个问题一样，是根据动量守恒定律得出的。此时唯一的特点是，在弹簧最大变形时，滚子的速度相同：$v'_1 = v'_2 = v$。因此，能量和动量守恒定律（或者更确切地说，它的投影）如下所示：

$$\frac{M_1 v_1^2}{2} + \frac{M_2 v_2^2}{2} = \frac{(M_1 + M_2) v^2}{2} + 4 \frac{k x^2}{2},$$

$$M_1 v_1 - M_2 v_2 = (M_1 + M_2) v.$$

从这里我们得到

$$x = \frac{1}{2} \sqrt{\frac{M_1 M_2}{k (M_1 + M_2)}} (v_1 + v_2).$$

问题 3（弹道矩阵）。一块质量为 $M$ 的物体悬挂在长度为 $l$ 的平行螺纹上，被质量为 $m$ 的水平飞行子弹击中并卡在其中 (图 1)。由于冲击，每根螺纹都会偏转角度 $\alpha$。求弹簧的初始速度 v。螺纹被认为是理想的（失重且不可拉伸）。

从图可以看出，螺纹的偏转角度$\alpha$与木块上升的高度$h$有关：

$$h = l (1 - \cos \alpha),$$

高度$h$可以与块和子弹最终状态下的势能相关联：

$$E_p = (M + m) gh.$$

问题出现了：在这种情况下是否满足守恒定律？

机械能？换句话说，系统最终状态的能量是否等于其初始能量，即子弹的动能$mv^2/2$？答案当然是否定的。毕竟，我们知道，在非弹性撞击过程中，部分机械能转化为内能。

怎么会这样呢？让我们考虑系统的另一种中间状态 - 撞击结束后立即，此时子弹已经卡在块中，但乞丐仍然是垂直的。这种状态下系统的能量就是木块和子弹的动能：$E_k=(m+M)v'^2/2$，其中$v'$是它们的总速度。非弹性冲击结束后，不再有能量损失，我们可以写

$$E_k=E_p,$$

或者

$$\frac{(m+M)v'^2}{2}=(M+m)gh.$$

利用动量守恒定律，速度 $v'$ 可以与子弹的初速度相关联

$$mv=(m+M)v'.$$

根据最后两个方程，考虑到 $h$ 的表达式，我们有

$$v=2\left(1+\frac{M}{m}\right)\sqrt{gl}\sin \frac{a}{2}.$$

请注意，在这个问题中，动量守恒定律和能量守恒定律并不是同时起作用，而是好像依次起作用。事实证明，这并不那么容易理解，许多申请人仅利用能量守恒定律来解决此类问题，当然得到了错误的结果。

问题 4. 三个小负载球 - 每个球的质量为 $m$，电荷 $q$ - 被长度为 $l$ 的相同理想螺纹所包含，并形成等边三角形 (图 2)。其中一根线被切断，球开始移动。求中间球 (3) 移动时的最大速度。事实上，重力是可以转化的。

由于系统是封闭的，并且只有库仑相互作用力在其中起作用，因此能量守恒定律可以应用于该系统。在这种情况下，我们不会考虑球 1、3 和 2、3 的相互作用能，因为它在状态 a) 和 6) 中是相同的（参见 图 2）。那么能量守恒定律将具有形式

$$\frac{kq^2}{l}=\frac{kq^2}{r_{12}}+2\frac{mv^2}{2}+\frac{mV^2}{2}.$$

仅根据这个方程，不仅无法计算所需的速度$V$，而且无法了解何时达到最大值。然而，由于系统是封闭的，我们也可以应用动量守恒定律——三个球的总动量始终为零。对于脉冲的预测，我们得到

$$0=2mv-mV.$$

现在很明显，当球 1 和 2 彼此距离最远时，即当 $r_{12}=2l$ 时，速度 $V$ 将最大。求解相应方程，我们发现

$$V=q\sqrt{\frac{2}{3}\frac{k}{ml}}.$$

由于某种原因，许多小学生都习惯于解决动量守恒定律这个问题，这似乎不寻常甚至奇怪。

问题 5. 在位于主水平面上、长度为 $l$、质量为 $M$ 的块上，有一个质量为 $m$ (图 3) 的小物体。物体与木块之间的摩擦系数为$\mu$。以什么速度$v$

系统是否应该移动，以便在控制木块对墙壁的冲击后，身体从木块上掉下来？

物块对墙壁的冲击会导致其速度突然改变为相反的方向。碰撞过程中身体的速度不会改变，并且会开始沿着物块滑动。

让我们求出在滑动结束之前身体相对于木块移动的距离$x$。很明显，条件$x > l$将是物体从方块中掉落的条件。滑动摩擦力的功与距离$x$有关 -

$$A_{\text{тр}} = -\mu mgx,$$

反过来，它等于系统动能的变化：

$$A_{\text{тр}} = \frac{(m+M)v^2}{2} - \left(\frac{mv^2}{2} + \frac{Mv^2}{2}\right).$$

这里$v'$是物体相对于物块停止时物块与物体的速度。这个速度可以从动量守恒定律找到

$$Mv - mv = (M+m)v'.$$

将所有三个方程一起求解，我们得到

$$x = \frac{2Mv^2}{\mu g(M+m)}.$$

条件$x > l$可以求出初始速度：

$$v > \sqrt{\frac{1}{2}\mu g\left(1 + \frac{m}{M}\right)}.$$

为什么功$A_{\text{тр}}$等于力乘以物体相对于木块的位移的乘积似乎令人难以理解——毕竟，木块并不是静止不动的，因此会移动

物体相对于地面的运动不等于它相对于物块的位移。事实上，系统机械能的变化等于总功 $F_{\text{тр}}$ - 无论是在物体上还是在块上：

$$A_{\text{тр}} = \left(F_{\text{тр}}x\right) + \left(-F_{\text{тр}}x\right) = F_{\text{тр}}x.$$

总之，我们将分析计算核反应的问题。在这个问题中，动量守恒定律的矢量性质比前面的问题显得更加清晰。

问题6. 为了进行重和超重氢同位素（$^2H + ^3H = ^4He + n$）的合成反应，加速到能量$E = 2M\theta B$的作用核指向Tritz靶。探测器探测垂直于氘核束方向发射的中子。如果反应中释放能量$\Delta E = 14M\theta B$，请确定抵抗中子的能量。

该反应的能量守恒定律具有以下形式

$$\frac{m_{\text{д}}v_{\text{д}}^2}{2} = E = \frac{m_{\text{r}}v_{\text{r}}^2}{2} + \frac{m_{\text{н}}v_{\text{н}}^2}{2} - \Delta E$$

（下文中索引“d”表示氘，“g”表示氦，“n”表示中子）。动量守恒定律必须写成在 $X$ 轴（入射氘子速度方向）和 $Y$ 轴（受阻中子逃逸方向）上的投影：

$$m_{\text{д}}v_{\text{д}} = m_{\text{r}}v_{\text{rx}},$$

$$0 = m_{\text{н}}v_{\text{н}} - m_{\text{r}}v_{\text{ry}}.$$

考虑到$v^2_{\text{r}} = v^2_{\text{rx}} + v^2_{\text{ry}}$，我们得到

$$\frac{m_{\text{н}}v_{\text{н}}^2}{2} \left(1 + \frac{m_{\text{н}}}{m_{\text{r}}}\right) = \Delta E + \frac{m_{\text{д}}v_{\text{д}}^2}{2} \left(1 - \frac{m_{\text{д}}}{m_{\text{r}}}\right).$$

从这里，考虑到$m_{\text{н}}/m_{\text{r}} = 1/4$和$m_{\text{д}}/m_{\text{r}} = 1/2$，我们找到了抵抗中子的能量：

$$E_{\text{н}} = \frac{4}{5} \left(\Delta E + \frac{1}{2}E\right) = 12M\theta B.$$
