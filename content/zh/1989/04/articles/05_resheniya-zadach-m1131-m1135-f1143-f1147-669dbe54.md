M1132。函数$f$定义正整数集合并满足以下条件：
$$f(1) = 1, f(3) = 3, f(2n) = f(n),$$
$$f(4n+1) = 2f(2n+1) - f(n),$$

$$f(\bar{10}) = f(2) = f(1) = 1 = \bar{01},$$
$$f(\bar{11}) = f(3) = 3 = \bar{11}.$$

现在让我们证明双精度数系中$k$数字（$k>2$）数字$m$的陈述，假设它对于所有位数较少的数字都是正确的。距离三种可能的情况。

1) $m$ 是偶数：$m=2n = a_1 \dots a_{k-1} 0$。然后 $n = a_1 \dots a_{k-1}$ 和
$$f(m) = f(n) = a_{k-1} \dots a_1 = 0 a_{k-1} \dots a_1.$$

2) $m=4n+1 = a_1 \dots a_{k-2} 01$。然后 $n = a_1 \dots a_{k-2} 2n+1 = a_1 \dots a_{k-2} 1$ 和
$$f(m) = 2f(2n+1) - f(n) = f(2n+1) + (f(2n+1) - f(n)) = 1 a_{k-2} \dots a_1 + (1 a_{k-2} \dots a_1 - a_{k-2} \dots a_1) = 10 a_{k-2} \dots a_1.$$

在所有情况下，公式（*）都是正确的；因此它对于所有$m$都被证明了。

M1133。证明该组解不与长度总和为 1988 的区间相交。

$$\sum_{k=1}^{70} \frac{k}{x-k} \geq \frac{5}{4}$$

是长度总和等于 1988 的区间的合并不相交。

不等式的定义域是半线的并集 $(-\infty; 1)$, $(70; \infty)$ 和间隔 $(1; 2)$, $(2; 3)$, ..., $(69; 70)$。显然（参见页边空白中的近似图），在每个区间上，不等式的躺着部分是连续且单调杀死的：从 0 到 $-\infty$ 和来自 $\infty$ 到 0，分别在半线上和从 $\infty$ 到 $-\infty$ 每隔一段时间。因此，除了 $(-\infty; 1)$，它恰好在某一点取值 5/4。让我们按升序表示这些点 $x_1, x_2, \dots, x_{70}$，那么不等式的解集就是半皮特勒斯的并集 $(k; x_k)$, $k=1, 2, \dots, 70$。数字 $x_k$ 是多项式的根

$$\prod_{k=1}^{70} (x-k) - \frac{4}{5} \sum_{k=1}^{70} k \prod_{i \neq k} (x-i)^*.$$

根据Vieta定理（见«Kvant»，1987年，第4期，第40页），它们的和等于$x^{69}$的系数带负号，即

$$\sum_{k=1}^{70} k + \frac{4}{5} \sum_{k=1}^{70} k$$

因此，半凹坑长度的总和等于

$$\sum_{k=1}^{70} (x_k-k) = \frac{4}{5} \sum_{k=1}^{70} k=1988.$$

M1135。设 a 和 b 为正整数，使得 $a^2+b^2$ 可以被 ab+1 整除而没有余数。证明$\frac{a^2+b^2}{ab+1}$是整数的平方。

设a和b为自然数并且

$$\frac{a^2+b^2}{1+ab}=k.$$

那么b就是方程的根

$$x^2-kax+a^2-k=0.$$

如果 c 是该方程的二次根，k 是整数且 a<b，则

1) $(a^2+c^2)/(1+ac)=k$（由等式得出）；
2) c 是一个整数，因为 c=ka-b （Vieta 定理）；
3) c<a, т. к. bc=a^2-k<a^2 и b>a;
4) c≥0，因为

$$\left(\frac{1}{a}+c\right)\left(\frac{1}{b}+b\right)=\left(-\frac{1}{a}-c\right)\left(-\frac{1}{b}-b\right)=$$

$$=\left(-\frac{1}{a}\right)^2-ka\left(-\frac{1}{a}\right)+a^2-k=\frac{1}{a^2}+a^2>0,$$

因此整数c满足不等式$c>-1/a$。

如果c=0，则b=a^3。这是满足条件的 (a, b) 对的“主系列”；对于他们来说 k=a^2。如果c>0，则（a，b）对可以用具有相同比率k的对（c，a）代替，我们的推理再次适用，等等。在“下降”过程中，每次对的数量最多的减少，因此它必须以某个对（0，n）结束，该对位于“主系列”的对（n，n^3）之前；那么k=n^2。最后，如果原对(a,b)的个数相等，则只有当a=b=1时，比值k才为整数；那么k=1。

我们的推理允许我们从任何对 (0, n) 开始构造满足条件的无限对序列。例如，当 n=2, k=4 时，我们得到对 (0, 2), (2, 8), (8, 30), (30, 4 30−8)=(30, 112)...

负载滚动方向上速度分量$v_x$的振荡周期不变。此外，在大部分时间段内，水平速度分量为$v_y \gg v_x$。这意味着摩擦力也是水平方向的，并且物体沿 $X$ 轴的运动只会在滚动力的影响下发生：

$$v_x = at \quad \text{и} \quad t_x = \sqrt{2l/a}.$$

同时，摩擦力肯定会引入一个小的（由于$c^{-1}$很小）的修正。我们来评估一下。摩擦力的小幅值和沿轴 $X$ 的相应加速度分量由关系 $v_x/\sqrt{v_x^2+v_y^2}$ 确定：

$$b_x = b \frac{v_x}{\sqrt{v_x^2+v_y^2}} = b \frac{v_x}{\sqrt{v_x^2+\omega^2 L^2 \sin^2 \omega t}}.$$

在这种情况下，我们认为沿 $Y$ 轴的运动是纯谐波运动。事实上，由于摩擦力的存在，该运动将不同于谐波运动，但校正的顺序将使得它可以被忽略（这将在下面更详细地讨论）。

我们来计算平均值$b_x$：

$$\bar{b}_x = \frac{2\omega}{\pi} \int_{0}^{\pi/(2\omega)} bv_x/\sqrt{v_x^2+\omega^2 L^2 \sin^2 \omega t} \, dt.$$

对于$t$，其中$\omega L \sin \omega t \gg v_x$，velinium$v_x$可以忽略不计，因此

$$\bar{b}_x \approx \frac{2\omega}{\pi} \int_{v_x/(\omega^2 L)}^{\pi/(2\omega)} \frac{bv_x}{\omega L \sin \omega t} \, dt =$$

$$= \frac{2}{\pi\omega} \frac{bv_x}{L} \int_{v_x/(\omega L)}^{\pi/2} \frac{d\varphi}{\sin \varphi} = -\frac{2bv_x}{\pi\omega L} \ln \frac{v_x}{2\omega L}.$$

$$\bar{b}_x(t) = -\frac{2bat}{\pi\omega L} \ln \frac{at}{4\omega L}.$$
