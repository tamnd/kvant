M1132。函数$f$定义正整数集合并满足以下条件：
$$f(1) = 1, f(3) = 3, f(2n) = f(n),$$
$$f(4n+1) = 2f(2n+1) - f(n),$$
$$f(4n+3) = 3f(2n+1) - 2f(n).$$
求 $f(n) = n$ 和 $1 \leq n \leq 1988$ 的 $n$ 的所有值的个数。

如果给出集合 $B$ 的元素上的 0 和 1 的分布，使得每个集合 $A_i$ 中恰好有 $n$ 个“0 元素”，则“0 元素”的总数等于 $n(2n+1)/2$（它们每个都属于两个集合 $A_i$）。只有当$n$是偶数时，这个数字才是整数。

相反，对于集合 $B$ 的每个元素 $x$，距离是包含它的集合 $\{A_i, A_j\}$ 中唯一的一对，并且如果 $|i - j| \leq n/2$ 或 $|i - j| > 3n/2$，则为元素 $x$ 分配数字 0，如果 $n/2 < |i - j| \leq 3n/2$，则为 1。

对于甚至 $n$，我们在每个集合 $A_i$ 中恰好得到 $n$“0 元素”，这就是所需要的。

在解决这个问题时，主要考虑因素是正确理解条件。图形解释在这里非常有帮助（参见$n=4$的图1和2）：每个集合$A_i$由规则$(2n+1)$边形的顶点表示，并且集合$A_i$和$A_j$的唯一公共元素由连接相应顶点的线段表示，其中红色线段代表“0元素”，蓝色线段代表“0元素” “1-元素”；集合$B$与所有这些线段的集合一一对应。遵循我们在此图上的推理将会很有用。

答案：92。

让我们通过数字$m$的双重表示法$a_1 a_2 \dots a_{k-1} a_k$（$a_1=1$）中的数字$k$字符来证明
$$f(m) = a_k a_{k-1} \dots a_2 a_1.$$

对于$k=1$，我们有$f(1)=1$；对于 $k=2$ 我们有
$$f(\bar{10}) = f(2) = f(1) = 1 = \bar{01},$$
$$f(\bar{11}) = f(3) = 3 = \bar{11}.$$

现在让我们证明双精度数系中$k$数字（$k>2$）数字$m$的陈述，假设它对于所有位数较少的数字都是正确的。距离三种可能的情况。

1) $m$ 是偶数：$m=2n = a_1 \dots a_{k-1} 0$。然后 $n = a_1 \dots a_{k-1}$ 和
$$f(m) = f(n) = a_{k-1} \dots a_1 = 0 a_{k-1} \dots a_1.$$

2) $m=4n+1 = a_1 \dots a_{k-2} 01$。然后 $n = a_1 \dots a_{k-2} 2n+1 = a_1 \dots a_{k-2} 1$ 和
$$f(m) = 2f(2n+1) - f(n) = f(2n+1) + (f(2n+1) - f(n)) = 1 a_{k-2} \dots a_1 + (1 a_{k-2} \dots a_1 - a_{k-2} \dots a_1) = 10 a_{k-2} \dots a_1.$$
3) $m=4n+3 = a_1 \dots a_{k-2} 11$。然后 $n = a_1 \dots a_{k-2}$ 和
$$f(m) = 3f(2n+1) - 2f(n) = f(2n+1) + 2(f(2n+1) - f(n)) = 1 a_{k-2} \dots a_1 + 2(1 a_{k-2} \dots a_1 - a_{k-2} \dots a_1) = 11 a_{k-2} \dots a_1.$$

在所有情况下，公式（*）都是正确的；因此它对于所有$m$都被证明了。
