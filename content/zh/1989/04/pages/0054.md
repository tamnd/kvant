请注意，它不包含奇次幂$x$。如果我们将本乘积中的$x^2$替换为$t$，我们就得到了我们需要的多项式

$$Q(t) = (-1)^n a_n^2 (t - x_1^2) (t - x_2^2) \dots (t - x_n^2),$$

其根等于给定多项式 $P(x)$ 的根的平方。计算多项式 $Q(t)$ 的系数 $b_k$

$$Q(t) = b_0 + b_1 t + b_2 t^2 + \dots + b_{n-1} t^{n-1} + b_n t^n$$

您可以更改$P(x)$和$P(-x)$，为相同的幂$x$引入类似的术语（奇数幂将消失）并将$x^2, x^4, \dots$替换为$t, t^2, \dots$。

以下是 $n=3$ 和 $n=4$ 的系数 $b_k$ 的公式：

$$n = 3; a_0 + a_1 x + a_2 x^2 + a_3 x^3 = 0$$
$$b_0 = a_0 a_0$$
$$b_1 = a_0 a_2 - a_1 a_1 + a_2 a_0$$
$$b_2 = -a_1 a_3 + a_2 a_2 - a_3 a_1$$
$$b_3 = -a_3 a_3$$

$$n = 4; a_0 + a_1 x + a_2 x^2 + a_3 x^3 + a_4 x^4 = 0$$
$$b_0 = a_0 a_0$$
$$b_1 = a_0 a_2 - a_1 a_1 + a_2 a_0$$
$$b_2 = a_0 a_4 - a_1 a_3 + a_2 a_2 - a_3 a_1 + a_4 a_0$$
$$b_3 = a_2 a_4 - a_3 a_3 + a_4 a_2$$
$$b_4 = a_4 a_4$$

系数$b_k$的计算在计算机甚至可编程微型计算器上并不困难。计算完系数$b_k$后，将它们的值分配给系数$a_k$，计算新的$b_k$，依此类推，直到模数最大的根成为主导。

为了找到这个根的值，让我们回到公式

$$Q(t) = b_0 + b_1 t + \dots + b_{n-1} t^{n-1} + b_n t^n$$
$$Q(t) = b_n (t - t_1) (t - t_2) \dots (t - t_n).$$

如果打开括号和底行中的简化项，您应该得到顶行。因此，

$$b_{n-1} = -(t_1 + t_2 + \dots + t_n) b_n$$

或者

$$t_1 (1 + t_2/t_1 + t_3/t_1 + \dots + t_n/t_1) = -b_{n-1}/b_n.$$

如果根$t_1$的模数显着超过其他根，则括号中的表达式接近1并且近似

$$t_1 \approx -b_{n-1}/b_n.$$

有趣的是，Lobachevsky 方法也可以用来求方程剩余根的值（如果它们的模数都不同）。令根$t_2$小于$t_1$，但重要的一个超过其余的。然后在 $b_{n-2}$ 的表达式中

$$b_{n-2} = (t_1 t_2 + t_1 t_3 + \dots + t_2 t_3 + \dots) b_n$$

括号中，$t_1 t_2$起主要作用，我们可以近似假设$b_{n-2} \approx t_1 t_2 b_n$，由此

$$t_2 \approx -b_{n-2}/b_{n-1}.$$

与$t_k \approx -b_{n-k}/b_{n-k+1}$相同。

2. 使用罗巴切夫斯基方法获得的近似值很快就会收敛到精确解。在计算机或微计算器上计算时，需要设置一个迭代次数计数器（用$p$表示），并在每次迭代后加1。对于原方程的根$x_k$，它将是

$$|x_k| = t_k^{1/2^p},$$

因为多项式 $Q(t)$ 是通过 $p$ 迭代获得的（反复从多项式 $P$ 到多项式 $Q$ 并用它们的平方替换根）。仅当 $t_k > 0$ 时才应计算$|x_k|$。如果存在大小相等的根，或者在第一次迭代期间，$t_k$ 的值可能为负数。每次迭代后可以方便地在屏幕上显示根模型$x_k$的近似值并监控它们是如何建立的。罗巴切夫斯基正是通过手工计算想出了这种方法。
