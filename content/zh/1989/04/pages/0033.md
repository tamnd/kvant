我们在点 $N$ 处有抛物线。为了解决这个问题，我们只需要找到$R$。

让我们将珠子的运动与与水平面成一定角度的物体的运动进行比较。在这种情况下，我们将选择该运动的参数，使得主体的轨迹是与珠子的轨迹对称的抛物线（参见图2）。然后

$$u_x = \frac{OK}{t} \text{ и } t = \sqrt{\frac{2H}{g}},$$

其中$OK = \sqrt{L^2 - h^2}$和$H = (L + h)/2$。

身体在$N'$点的法向加速度

$$a'_n = g \cos \alpha = \frac{u^2}{R}.$$

考虑到$u^2 = u_x^2 + u_y^2$，其中$u_y^2 = 2g(H - y)$，我们得到

$$R = \frac{u^2}{a'_n} = \frac{2(L - y)}{\cos \alpha}. \tag{3}$$

让我们将方程 (1) - (3) 组合成一个系统，并找出珠子滑动的线的张力：

$$T = \frac{mgL}{2(L - y)}.$$

如果$T = T_0$，即当

$$y = L \left(1 - \frac{mg}{2T_0}\right)$$

注意

$$v = \sqrt{2gy} = \sqrt{2gL \left(1 - \frac{mg}{2T_0}\right)}.$$

$$0 \leq y \leq \frac{L + h}{2},$$

即 $$0 \leq L \left(1 - \frac{mg}{2T_0}\right) \leq \frac{L + h}{2}.$$

因此，如果满足条件

$$2 \geq \frac{mg}{T_0} \geq 1 - \frac{h}{L},$$

那么在断线的那一刻，珠子的速度是

$$v = \sqrt{2gL \left(1 - \frac{mg}{2T_0}\right)};$$

如果$mg/T_0 > 2$，水槽会在初始时刻破裂；如果$mg/T_0 < 1 - h/L$，则在珠子移动期间，线根本不会断裂。
