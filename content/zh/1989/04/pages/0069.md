列宁格勒国立大学

数学
笔试
选项1
（数学和力学学院、应用数学系 - 控制过程和物理）
1. 解方程
$$\frac{\sin x}{1+\cos x} + \frac{\cos x}{1+\sin x} = 2.$$
2. 解决不等式
$$3\sqrt{\log_3 x} - \log_3(3x) \leq 1.$$
3. 找到参数值$a$和$b$的所有对$(a, b)$，其中方程$x^2 - ax + a = 0$的所有实根也是方程$x^2 + b^2x - 8b = 0$的根。
4.1.在三角形$ABC$的边$AB$和$BC$上，分别选择点$D$和$E$。点$G$是平行于$BC$且经过$D$的直线与线段$AE$的交点，点$F$是线段$CD$与经过$E$且平行于$AB$的直线的交点。证明线段$GF$与底$AC$平行。
4.2.!)求满足方程的笛卡尔平面上那些点$(x, y)$所形成的图形的面积
$$|x+1| + |y| \leq 2, (x+2)^2 + y^2 \leq 1.$$
5. 将体积为$V$的球放置在直圆锥中。圆锥体积的最小值是多少？

选项2
（经济学院心理系、经济控制论系）
1. 数字$a, b, c$构成等差数列，数字$a-1, b-4, c-3$构成等比数列。我们还知道，几何级数的极端项的乘积比算术级数的中间项的乘积大 2。找到这些数字。
2. 解方程
$$\sqrt{5-x^2} = x+1.$$
3.1.求区间 $[0; 2\pi]$ 上不等式 $1+\cos 2x \geq \cos x (1+|1-2\cos x|)$ 的所有解。

3.2.*) 求解不等式$|1/2 - \cos x| \geq \cos x$。
4. 在等边三角形中，外接圆的半径为$R$，内切圆的半径为$r$。找到这些圆的中心之间的距离。
5. 在正三角形 Paramid $SABC$ 中，通过底边 $BC$ 的边绘制垂直于边 $SA$ 的截面。如果已知 Paramid 的高度是围绕底面外接圆的半径的两倍，则求该截面将 Paramid 分成的部分的体积比。

选项3
（化学学院）
1. 求一个三位数，如果你知道它的各位数字之和是12，并且用相同的数字以相反的顺序写出的数字比原数字的三倍小24。
2. 解方程
$$(7\cos^2 x - 2)\sqrt{2\cos x + 1} = 0.$$
3. 解决不等式
$$\sqrt{2x+3} - \sqrt{x} \geq \sqrt{3-x}.$$
4. 绘制函数图
$$f(x) = \frac{x^2-3|x|+4}{x}.$$
5. 在正三角形 Paramid 中，高度为 $H$，底边内接圆的半径为 $R$。求与球体中心的底面平面以及通过帕拉米德顶点和底面两侧中间所画的平面相切的球体的体积。

选项4
（图书馆学部、物理学院数学执照系）
1. 绘制函数图
$$f(x) = |x-1| - |x+3/2|.$$
2. 解方程
$$x-1 = \sqrt{x^4-x^3-x^2-2x+1}.$$
3. 解决不等式
$$\sin(\cos x) \geq 1/2.$$
4. 在数据平面上有一个凸四边形$ABCD$。求端点位于 $AB$ 和 $CD$ 的线段中点的轨迹。
5. 两个相等的正三角形帕拉酰胺$SABC$和$S'A'B'C'$排列成$S=S'$、底边$O$和$O'$的中心重合，并且角度$AOA'$等于$30^\circ$。求这两个帕拉米达一部分的体积，如果已知底边等于$a$，则帕拉米达的总高度为$h$。

*) 作业 4.2 由物理系提供。
