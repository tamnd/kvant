路径$A$和$B$是位于正方形内部的两个非零面积的图形，例如两个多边形。然后，随着$n$的增加，$(T^n(A) \cap B)/$面积与$(A)$面积之比趋向于集合$B$面积占整个正方形面积的分数。这意味着，对于较大的$n$，在$T$的影响下，以$n$步从$A$到达$B$的机会实际上不取决于$A$，即点的初始位置，但集合$B$仅取决于面积。

我们形成的属性称为*改变*。这意味着随着时间的推移，任何图形都会均匀分布在正方形上。

**一些公式。** 我想学习如何使用公式来描述面包师的变换。变换定义中涉及的减半表明双数系统在这种描述中可能有用。回想一下，区间 $[0;1)$ 中的每个数字 $\alpha$ 都可以写成 $0, \alpha_1 \alpha_2 \alpha_3...$，其中每个 $\alpha_i$ 等于 0 或 1。这种表示法意味着 $\alpha = \alpha_1/2 + \alpha_2/2^2 + \alpha_3/2^3 +...$；例如，1/2 在双精度制中可以写为 0.1，1/3 可以写为 0.010101... 这种表示法的几何意义如下。将区间$[0;1)$分成两半。如果$\alpha_1 = 0$，则数字$\alpha$位于区间的左半部分：$[0;1/2)$，如果$\alpha_1 = 1$，则位于右半部分：$[1/2;1)$。让 $\alpha_1 = 0$ 来确定。那么 $\alpha_2$ 表示$[0;1/2)$ 区间的哪一半位于 $\alpha$ - 左边 ($\alpha_2 = 0$) 或右边 ($\alpha_2 = 1$)。所有其他双输入数字都具有类似的含义。

**练习**

1. 证明$1/3 = 0,010101$...

提示：使用无限几何级数之和的公式：$q + q^2 + q^3 +... = q/(1-q)$。

2. 将 1/7 写成双分数。

3. 将 0.110110110... 写为目标分数。

让我们取单位正方形$K = \{(x;y):0 \leqslant x < 1, 0 \leqslant y < 1\}$中的点$m$，坐标为$(x;y)$，以双精度形式写为：$x = 0, x_1 x_2..., y = 0, y_1 y_2...$。让我们看看如果应用面包师变换，点 $m$ 的坐标的双重表示法会如何变化。如果$x_1 = 0$，即$m$位于正方形的左半部分，那么它的横坐标将加倍。正是由于这个原因，我们给十进制数加上了双精度数前缀：在十进制数系统中，将分数乘以 10 非常简单 - 只需将分数相对于小数点向左移动 1 个位置即可，而在双精度数系统中，乘以 2 的工作原理相同。

所以，点$T(m)$的横坐标等于0，$x_2 x_3...$。如果$x_1 = 1$，那么在面包师变换的第一阶段(图 2, b)，点$m$会走到横坐标$1, x_2 x_3...$的点，切割后(图 2, e)会向左移动1，所以此时$T(m)$点的横坐标等于0， $x_2 x_3...$。现在让我们跟踪点 $m$ 纵坐标的变化。第一阶段，减半：$y \rightarrow 0,0 y_1 y_2...$，然后保持不变（$x_1 = 0$）或增加 1/2（$x_1 = 1$）。这意味着我们可以写出点$T(m)$的纵坐标等于0，$x_1 y_1 y_2...$。为了清楚起见，我们将点$m$的坐标写在一行中，如下所示：

$$m \leftrightarrow (\dots y_3 y_2 y_1, x_1 x_2 x_3...).$$
