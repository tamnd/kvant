周期性过程的奇妙冒险

1. 引理的证明。对于每个未除以$q$的自然数$n$，我们计算$np$除以$q$时的余数。令 $r$ 为这些余数中最小的；部分是$Ap = Bq + r$，还有一些$A$和$B$。我们需要证明$r = 1$。假设$r > 1$，并将$q$除以$r$，余数：$q = mr + r'$、$r' < r$（和$r' > 0$，否则$p$和$q$都可以被$r$整除，并且不会互质）。然后是$A(m+1)p = B(m+1)q + mr + r = B(m+1)q + q + (r - r')$，这表明数$A(m+1)p$除以$q$的余数是$r - r' < r$，这与余数$r$的极小性相矛盾。引理已得证。

请注意，在已证明的引理中，$A$ 必然与 $q$ 互质，$B$ 与 $p$ 互质。

从引理推导该陈述。让$2^{a}5^{b}A = Bm' + 1$。然后

$$\frac{1}{m} = \frac{2^{a}5^{b}A - Bm'}{2^{a}5^{b}m'} = \frac{A}{m'} - \frac{B}{2^{a}5^{b}}.$$

在最后一个差值中，被减数是一个小数，其周期长度与$1/m'$相同（参见练习2），减数是一个有限小数，有$c$小数位（它等于$2^{c-a}B/10^c$或$5^{c-b}B/10^c$）。该声明立即随之而来。

2. 通过将小数$1/q$乘以$p$，它的周期只会减少。我们假设它已经减少了。设$A$和$B$使得$Ap = Bq + 1$。当分数 $p/q$ 乘以 $A$ 时，周期只会进一步减小。但在这种情况下，乘法结果为 $(Bq+1)/q = B+(1/q)$ - 周期的长度与原始分数的长度相同。矛盾。

3. 该分数可以被认为是不可约的。如果 $q$ 不能被 2 或 5 整除，那么这可以直接从文章中证明的推论得出（如果更具体，则可以使用练习 2）。如果它是可整除的，则将 $q$ 分成所有可能的二元和五元；让它变成$q'$。根据上面在求解练习 1 时证明的公式，我们的分数与某个值为 $q'$ 的分数具有相同的周期。

4. 设 $n_1$ 为构成可被 $p_1$ 整除的数字的最小图块数量，$n_2$ 为构成可被 $p_2$ 整除的数字的最小图块数量。此外，令$n$为数字$n_1$和$n_2$的最小公倍数。我们必须证明，首先，多个$n$图可以被$p_1p_2$整除，其次，由更少数量的图组成的数字不能被$p_1p_2$整除。但第一个已经很清楚了，第二个的证明方式和文章定理2一模一样。

6. 令 $p$ 为半周期素数。分数$1/p$的周期等于$(10^{p-1}-1)/p$。让我们对其进行平方并分隔最后 $p-1$ 数字：

$$\left(\frac{10^{p-1}-1}{p}\right)^2 = A \cdot 10^{p-1} + B, B < 10^{p-1}.$$

我们有

$$A + B = \frac{10^{p-1}-1}{p} \left(\frac{10^{p-1}-1}{p} - Ap\right).$$

因此，$A + B$ 除以分数$1/p$ 的周期。很容易理解，商不会超过$p$（证明留给读者），当且仅当分数$1/p$的周期本身能被$p$整除时，它才等于$p$；半周期$p$是否会发生这种情况，我们不知道。在这种情况下，$A + B$等于LOB与$10^{p-1}-1$。如果商小于$p$，则通过循环排列数字得到$A + B$。
