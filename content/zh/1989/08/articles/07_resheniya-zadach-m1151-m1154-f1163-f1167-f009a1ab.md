F1163。由于摩擦系数低，自动机不能在根模超过$a=0,5$m/$c^2$的冰上移动。根据执行条件，驾驶员需要在最短时间内从$A$点到达$B$点，该点位于垂直于自动速度方向（图1）的直线上。如果距离为 $AB=375$ 米，最低速度为 $v = 10$ 米/$c$，那么最短可能的时间是多少？在这种情况下，自动机器应该移动什么轨迹？当鱼位于$C$、$BC=200$米时，回答类似的问题。

让我们转向一个参考系统，其中自动机在初始时刻进行累加，并且点 $B$ 以恒定速度 $v$ 移动。在这个参考系中，与点$B$最快相遇的自动机非常长，并且必须沿着等于$a$的恒定根的特定直线移动。直线的方向由以下事实决定：在某些点 $D$ 必须发生碰撞。对于三角形 $ABD$ (图 2)，表示 $AB=b$，我们有

$$b^2 + (vt)^2 = \left(\frac{at^2}{2}\right)^2.$$

解这个方程，我们发现

$$t = \sqrt{\frac{2v^2}{a^2} + \sqrt{\left(\frac{2v^2}{a^2}\right)^2 + \frac{4b^2}{a^2}}} = 50 \text{ с.}$$

由于自动机的最佳运动是均匀加速的，因此其在与地球相关的参考系中的轨迹将是抛物线。

尽快到达$C$的策略与上面讨论的类似。然而，为了找到在点 $E$ (图 3) 相遇的时间，我们必须求解一般四边形的方程

$$b^2 + (vt+c)^2 = \left(\frac{at^2}{2}\right)^2,$$

⟦folio 36⟧

其中$c = BC$，或

$$t = \sqrt[4]{\frac{4}{a^2} \left(b^2 + (vt + c)^2\right)}.$$

该方程可以用积分法近似求解，其本质如下。假设我们需要求解 $f(t) = t$ 形式的方程。作为近似值，我们取一些值 $t = t_0$ 并组成序列

$$t_1 = f(t_0), \ t_2 = f(t_1), \ ..., \ t_n = f(t_{n-1}).$$

如果该数列有极限$S$，并且函数$f(t)$在点$S$连续，则$S$是方程(*)的根。

在我们的例子中，在条件 $t_0 = 0$ 下，序列将如下所示

$$t_1 = f(t_0), \ t_2 = f(t_1), \ ...$$

$$..., \ t_n = \sqrt[4]{\frac{4}{a^2} \left(b^2 + (vt_{n-1} + c)^2\right)}.$$

代入数值，我们得到结果

$$t \approx 59,2 \text{ с.}$$

此外，对序列进行更详细的研究表明，在 $n = 4$ 时，百分之一的准确度就足够了，每增加两个步骤（计算序列的后两项），准确度就会提高十倍。

对于解方程(*)时物理点任意位置的情况，其中$c = BC$前面可以加正负号，由于解可能不一致以及正确选择迭代的零次近似，必须注意一定的谨慎。

还有一点注意。当然，以恒定加速度矢量沿抛物线移动需要驾驶员具有相当大的速度。
