F1172。球体的内表面覆盖有反射系数为$r = 0,9$的漫反射器。漫反射器反射的光的角分布由朗伯定律描述：

$$\Delta N = \frac{N}{\pi} \cdot \cos \theta \cdot \Delta \Omega,$$

其中$N$是反射光子总数，$\Delta N$是小立体角$\Delta \Omega$（与反射区域法线形成角度$\theta$）内的反射光子数。精确的光源将在球体中心闪烁。有多少光子会通过球体中存在的非常小的排斥而逃逸？

S·A·霍罗佐夫

问题解决方案
M1136—M1140, F1148—F1152

M1136*。证明非负数 $A$、$M$、$S$ 的不等式
$$3 + (A + M + S) + \left( \frac{1}{A} + \frac{1}{M} + \frac{1}{S} \right) + \left( \frac{A}{M} + \frac{M}{S} + \frac{S}{A} \right) \geq \frac{3(A + 1)(M + 1)(S + 1)}{AMS + 1}.$$

人工（但也是熟练的！）权重相同变换的属性证明。将不等式左右两边的差乘以它们的公分母$AMS(AMS + 1)$以及项重排的乘积，我们得到
$$A^2M^2S^2(A + M + S) - 2AMS(AM + MS + SA) + (AM^2 + MS^2 + SA^2) + AMS(AM^2 + MS^2 + SA^2) - 2AMS(A + M + S) + (AM + MA + AS) = AM(M + 1)(SA - 1)^2 + MS(S + 1)(AM - 1)^2 + SA(A + 1)(MS - 1)^2 \geq 0,$$
而且，显然只有$A = M = S = 1$才能实现平等。该解决方案是由循环不等式方面的著名专家、新加坡的 P. H. Dinanada 教授向该问题的作者报告的。
