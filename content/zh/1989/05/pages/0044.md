方程的形式略有不同：

$$\frac{1}{d'} + \frac{1}{f'} = \frac{1}{F},$$
$$-\frac{1}{d''} + \frac{1}{f''} = -\frac{1}{f'-2L} + \frac{1}{d'} = \frac{1}{F}.$$

从这里我们得到

$$-\frac{1}{f'-2L} = \frac{1}{f'},$$

这只有在以下情况下才有可能

$$f' \rightarrow \infty,$$ 或 $d' = F$。

因此，对于所考虑的两种情况，我们可以写：

1) $\frac{1}{d_1} + \frac{1}{f_1} = \frac{1}{d_1} + \frac{1}{L} = \frac{1}{F}$，打开$d_1 = \frac{LF}{L-F}$，
2) $d_2 = F$.

根据条件，可得一元二次方程

$$d_1 - d_2 = l,$$即$l = \frac{LF}{L-F} - F,$

我们得到一个二次方程

$$F^2 + lF - lL = 0.$$

关于曲率

（参见第 14 页开头）

让我们滚球吧。拿一个网球。其表面开有狭窄形状的凹槽。在凹槽上标记一些点，然后将球放在桌子上，使该点位于桌子上。现在小心地沿着桌子滚动球，不要沿着凹槽滑动，直到放置的点再次回到桌子上。由于滚动，球将绕其轴线旋转一定角度。哪一个？

球沿闭合曲线滚动时的旋转等于球沿该曲线平行相交时切平面的旋转。根据高斯-邦尼定理，它也等于凹槽所限定的区域上的曲率积分。看看网球：凹槽将其划分的两个区域完全相同。我们知道，凹槽所限定的区域上的曲率积分是原来的一半，即等于 2n。因此，由于滚动，球将转动一个完整的角度，或者，同样的，它根本不会转动。尝试通过实验检查这个结果。
