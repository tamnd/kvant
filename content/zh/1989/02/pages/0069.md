⟦folio 67⟧

选项4
（化学系）

1. 解方程
$$2\log_7(x-2) = \log_7(x-10)^2 - 2.$$

2. 解方程
$$\sqrt{2} \cos x = \sqrt{-3} \sqrt{3} \sin x - 4.$$

3. 在函数 $y = 1 - 2x^2$ 的图中找到靠近点 $(1; \frac{3}{4})$ 的点。

4. 边长 $BC$ 等于 11 的三角形 $ABC$ 与边 $AB$ 相切的圆在点 $D$ 处内接。已知线段$AC$的长度等于线段$CD$的长度，并且角度$BAC$的余弦等于$\frac{1}{6}$。求边长$AC$。

5. 找到方程组等效的参数 $a$ 的所有值
$$\begin{cases} ax + 3y = 6a - 4, \\ x + y = 2a \end{cases}$$
和
$$\begin{cases} x^2 - 2y^4 - 6x + 8 = 0, \\ x^2 + y^2 - (2a+4)x + 2(a^2 + a + 2) = 0. \end{cases}$$

选项5
（布鲁斯学院）

1. 找到方程的指定正根
$$6\sin \frac{3x}{2} \sin \frac{x}{2} + 2\cos \frac{3x}{2} \cos \frac{x}{2} + 1 = 0.$$

2. 解决不等式
$$2\log_2 3 + \log_2 \left(3^x - 1 - \frac{1}{9}\right) < \log_2 2 6.$$

3. 两台不同功率的挖掘机以恒定的生产率工作，在 2 小时 24 分钟内挖出了一个给定体积的坑。第一台挖掘机单独工作时，比第二台挖掘机快 2 小时完成这项工作。找出第二台挖掘机单独工作所需的时间。

4. 三角形$ABC$的面积为$2\sqrt{3} - 3$，角$BAC$为$60^\circ$。与边 $AC$ 相切并延伸至边 $BA$ 和 $BC$ 的圆的半径为 $\sqrt{3}$。求给定三角形的角 $ABC$ 和 $BCA$。

5. 求解方程组
$$\begin{cases} \left(\sqrt{3} \cos \frac{\pi x}{4} + \sin \frac{\pi(x-2y)}{12}\right) \times \left(\sqrt{11-x^2-y^2}-4x-2y-6\right) = 0, \\ \frac{1}{2} + 2 \sin \frac{\pi x}{12} \cos \frac{\pi y}{6} = 2 \cos \frac{\pi x}{12} \sin \frac{\pi y}{6} + \sin^2 \frac{\pi x}{8}. \end{cases}$$

选项6
（军事学院）

1. 解方程
$$3 \sin x - 2 \text{ ctg } x = 0.$$

2. 在圆的直径 $MN$ 上，点 $R$ 偏移，并通过它绘制弦 $PQ$。已知角$MNP$和$NPR$分别为$60^\circ$和$13^\circ$，长度$PR$为3。求圆的直径。

3. 解方程
$$5 \cdot 4^x - 11 \cdot 6^x + 2 \cdot 9^x = 0.$$

4. 两种类型的动物饲料 - A 和 B - 蛋白质、脂肪和碳水化合物的重量含量不同。按重量计算，饲料 A 中的蛋白质含量比脂肪多 5/3 倍，碳水化合物含量比脂肪少 1.5 倍。饲料 B 所含的蛋白质和碳水化合物分别比脂肪少 7/2。是否可以通过混合饲料 A 和 B 制备出比脂肪含有 1.5 倍蛋白质和 5 倍碳水化合物的饲料？

5. 系统参数$p$取什么值
$$\begin{cases} x^2 + 2px + 4p^2 - 5p + 3 \geq 4\sin y - 3\cos y, \\ 0 \leq y \leq 2\pi \end{cases}$$有唯一解吗？

选项7
（动物学系）

1. 求函数的定义域
$$y = \log_2 x (x^2 + x - 2).$$

2. 解决不等式
$$2\log_2 3 + \log_2 \left(3^x - 1 - \frac{1}{9}\right) < \log_2 2 6.$$

3. 从$A$点到$C$点，距离$A$80公里，有一个机动清单飞了出来。与他同时，一名骑自行车的人从位于$A$和$C$之间、距离$C$ 5公里的点$B$驶出，一辆汽车从$C$点驶出。如果知道这件事发生在汽车追上自行车手 20 分钟后，并且摩托车手在遇到汽车之前在路上花费的时间是汽车超过骑车人之前的两倍，那么摩托车手和自行车手需要多长时间才能相遇？

4. 三角形Paramid $ABCD$ 沿四边形$EFGH$ 与平面$P$ 相交，使得顶点$E$ 和$F$ 位于边$AB$ 和$AC$ 上。边$EF$和$EH$的比等于3。已知平面$P$与相对边$AD$和$BC$平行，其比为$\frac{1}{3}$。求点 $E$ 分割边 $AB$ 的关系。

5. 证明对于所有 $x > 0$ 不等式
$$x^2 + x + 4\pi \cos x > 0.$$

选项8
（动物学系）

1. 解方程
$$(x - 2)(|x| + \sqrt{3} - 1 - \frac{1}{\sqrt{2}}) = 0.$$

2. 找出不等式的所有解
$$(x^2 + 8x + 15)\sqrt{x + 4} \geq 0.$$

3. 解方程
$$(2x^2 - 5x + 2)(\log_2 x (18x) + 1) = 0.$$

4. 点 $O$ 位于线段 $AB$ 上，因此$AO = 13, OB = 7$。以 $O$ 为圆心，画一个半径为 5 的圆。从 $A$ 和 $B$ 向其绘制切线，相交于点 $M$，切点位于线 $AB$ 的一侧。求圆角半径 $AMB$。
