⟦folio 27⟧

借助数千牛顿的力，您可以用它来确定$F_p$。如果没有这样的直径，请使用臂上悬挂负载的绞车。增加负载直至达到某个值$m_p$发生破裂。然后是$F_p = m_p g H / r$，其中$H$是绞车轴线到负载的距离，$r$是绞车卷筒的半径。

我们暂时先把这个问题搁置一边，继续上船吧。

血管。当船舶在水中移动时，来自水中作用在船舶上的阻力起着重要作用。可以写成这样的形式

$$F_c = \alpha \rho S u^2,$$

其中$u$是水相对于容器的速度，$\rho$是水的密度，$S$是容器浸入水中的部分的横截面积（横截面垂直于水流），$\alpha$是取决于容器周长的数值系数（$\alpha \lesssim 0,5$）。实际上，这个系数也取决于速度，但这种依赖性只有在平静的水面上才显着，我们不会考虑它。

起初我用这个公式进行了估算。但它们有多可靠呢？毕竟，我们对系数 $\alpha$ 和面积 $S$ 知之甚少。然后我说这两个参数可以合二为一，我称之为船只的有效长度。根据阿基米德定律，容器的质量为$M = \rho V$，其中$V$是容器浸入水中部分的体积，约等于$S$与容器沿水线长度$l$的乘积。我将容器的有效长度$l_{\alpha}$称为值$l / \alpha$。然后

$$F_c = \frac{M u^2}{l_{\alpha}}.$$

(7)

起初我对$l_{\alpha}$的评价相当严厉。由于$\alpha \lesssim 0,5$和船舶长度$l$通常至少为4 m，因此$l_{\alpha} \gtrsim 8$ m。但后来我意识到$l_{\alpha}$是可以改变的。

让我们在静水中将船加速到一定速度$v_0$，然​​后降低它。它在阻力作用下的进一步运动由牛顿第二定律描述：

$$Ma = - \frac{M v^2}{l_{\alpha}}.$$

在这种情况下，船舶沿路径$\Delta x$的动能变化等于该路径上的拖曳力的功，即

$$\Delta \left( \frac{M v^2}{2} \right) = - \left( \frac{M v^2}{l_{\alpha}} \right) \Delta x,$$

或者

$$\Delta \left( \frac{v^2}{2} \right) = - \frac{v^2}{l_{\alpha}} \Delta x.$$

我们现在寻找的速度不取决于时间，而是取决于行驶的距离 $x$。从能量方程可以清楚地看出，比率 $v / v_0$ 仅取决于 $x / l_{\alpha}$，即 $v / v_0 = f(x / l_{\alpha})$。一个简洁的解决方案给出了

$$v / v_0 = e^{-x / l_{\alpha}} \approx (2,7)^{-x / l_{\alpha}}.$$

*) 对于那些熟悉微分的人来说，请注意这个关系是能量平衡方程的解，可以重写为 $dv / v = -dx / l_{\alpha}$。
