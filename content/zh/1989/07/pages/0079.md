1. 令$x, y$和$z$分别为对应类型的第一、第二和第三类型的移动次数。然后必须进行$x + y + z = n^2 - 1$、$z = x$和$z + 1 = y$的比较。将它们加起来我们得到$3z + 2 = n^2$。但整数的平方除以 3 不能余 2。

2. 考虑函数 $f(n) = [n + \sqrt{n} + 0, 5]$ 并证明 $f(k^2 + z) = k^2 + k + z$ 对于 $-k + 1 \leq z \leq k$。既然$-k + 1 \leq z \leq k$，那么$-k + 1 + 0, 25 < z < k + 0, 25$，即$k^2 - k + 0, 25 < k^2 + z < k^2 + k + 0, 25$，即$k - 0, 5 < \sqrt{k^2 + z} < k + 0, 5$。

3. 设$z_1 = m + \alpha$和$z_2 = m + \alpha + 10^{-n}$，其中$m$是整数。当$m$足够大时，$z_2^2 - z_1^2 = 10^{-n}(2m + 2\alpha + 10^{-n})$大于1，因此$z_1^2$和$z_2^2$之间包含自然数$N$。显然$m + \alpha < \sqrt{N} < m + \alpha + 10^{-n}$。

4. 如果$a - c = b - d = 0$，它是平行四边形；如果 $|b - d| > |a - c|$，则为 $b \parallel d$ 的梯形；如果$|b - d| < |a - c|$，则为$a \parallel c$的梯形。

5. 设 $a, b, c, d$ 为四边形连续边的长度。因为对角线互相垂直，所以$a^2 + c^2 = b^2 + d^2$，因为四边形是外接四边形，所以$a + c = b + d$。如果$a = b$，则$c = d$，如果$a \neq b$，则$a + b = c + d$和$a + c = b + d$，即$a = d$和$b = c$。考虑到四边形是由圆外接的，我们发现其中一条对角线就是该圆的直径。

6. a) 设$a = (x_1 + x_2)/2$和$b = \sqrt{x_1 x_2}$。从$a = nb$开始，这个数是旋转的，这意味着它是自然数。数字$x_1$和$x_2$满足方程$x^2 - 2ax + b = 0$，因此它们等于$a \pm \sqrt{D}$，其中$D = 4a^2 - 4b^2 = 4b^2(n^2 - 1)$。仅当$n = 1$（即$D = 0$和$x_1 = x_2$）时，数字$D$才是完全平方数。

7. 从$2^n - 1 = 2^k(2^{n-k} - 1) + 2^k - 1$开始，数字$2^n - 1$除以$2^k$（其中$k < n$），得到余数$2^k - 1$。 $2^n$除以任何其他数字的余数比$2^n - 1$除以该数字的余数大1。小于$2^n$且不是$2^n$的约数的自然数等于$2^n - 1 - n$。因此$r(2^n) - r(2^{n-1}) = 2^n - 1 - n - \sum_{i=0}^{n-1} (2^i - 1) = 2^n - 1 - n - (2^n - 1) + n = 0$。
