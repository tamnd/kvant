9. 在数字 $p$ 的十进制表示法中，唯一可以找到的数字是 1、3、7 和 9；让我们假设它们都发生了。考虑数字 $a_1=1973, a_2=1937, a_3=1397, a_4=1739, a_5=3719, a_6=1793$ 和 $a_7=1379$。很容易检查$a_k$除以7的余数是7-k。通过重新排列数字，这个数$p$可以化简为$b \cdot 10^4 + a_k$的形式，其中$k$是$b \cdot 10^4$除以7的余数。$b \cdot 10^4 + a_k$能被7整除，得到矛盾。

而且。可以证明，在数字$p$的十进制表示中，不同的数字不超过两个。

10. 考虑排列序列中出现除了1、3和7之外的最后一位数字的情况就足够了。如果数字 1 和 7 没有排列，那么由于 7 除以 3 余数为 1，因此该序列将有无限多个可被 3 整除的数字。现在让我们假设 $a_k = p$ 是素数，$a_{k+n} = p \cdot 10^n + b_n$，其中 $b_n = 33 \dots 3 (n$ 是三元组）。在数字$b_1, \dots, b_{p+1}$中找到除以$p$时得到相同余数的数字$b_i$和$b_j$。数字 $b_i - b_j = 33 \dots 300 \dots 0 = b_{i-j} \cdot 10^j$ 可以被 $p$ 整除，因此 $a_{k+i-j}$ 可以被 $p$ 整除。

11. 令 $M$ 为给定圆的圆心，$O$ 为与钝角 $C$ 的三角形 $ABC$ 内切的圆的中心，$D$ 为直线 $CO$ 与给定圆的交点。在三角形$ADO$中，顶点$A$和$O$处的角度相等，因此$DO = AD$，因此$MO \geqslant DO - R = AD - R > R \sqrt{2} - R$。所需的 GMT 由不等式 $R(\sqrt{2} - 1) < MO < R$ 给出。

12. 首先假设三角形$APR$和$BPQ$的外接圆相交于点$O$，该点位于三角形$ABC$内部。从$\angle QOR = 360^\circ - \angle QOP - \angle POR = \angle A + \angle B = 180^\circ - \angle C$开始，点$O$也位于三角形$CQR$的外接圆上。设$O_a, O_b$和$O_c$为三角形$APR, BPQ$和$CQR$的外心。由于 $O_aO_b$ 和 $O_aO_c$ 是角度 $PO_aO$ 和 $RO_aO$ 的二等直角，因此$\angle O_bO_aO_c = \angle PO_aR/2 = \angle A$。当点$O$位于三角形$ABC$之外时的情况类似地处理。

13. 对于$p = 2$，这个陈述是显而易见的，所以我们假设$p$是奇数。让我们证明$(-3)^i = 2^i + 5z_i$。对于 $i = 0$ 来说这是显而易见的，但是对于 $(-3)^i + 1 = 2(-3)^i - 5(-3)^i = 2^{i+1} + 5(2z_i - (-3)^i)$ 来说。因此$2^p - (-3)^p = (2 - (-3)) \times \sum_{i=0}^{p-1} 2^{p-1-i}(-3)^i = 5 \sum_{i=0}^{p-1} 2^{p-1-i} \cdot 2^i + 25 \times \sum_{i=0}^{p-1} 2^{p-1-i} \cdot z_i = 5p2^{p-1} + 25z$。能被5整除但不能被25整除的数不能是自然数的幂。

14. 数字$a$的最后一位只能是以下数字之一：1、3、7和9。数字$a$的最后一位是1的情况很长。现在假设数字$a$的最后一位数字是3、7或9。那么$a + a^2 + a^3 + a^4$以零结尾，这意味着$a^k + a^{k+1} + a^{k+2} + a^{k+3}$也以零结尾。还需要检查数字$a + a^2$和$a + a^2 + a^3$不能以1结尾。但是数字$a + a^2$是偶数，$a + a^2 + a^3 = (1 + a + a^2 + a^3) - 1$。
