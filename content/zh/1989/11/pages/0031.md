这些力大小相同且方向相反，代表一对力，可产生相对于 $AB$ 轴的旋转力矩

$$\Delta M = \Delta F_1 l_{CD} = BI \Delta x l_{CD} = BI \Delta S,$$

其中$\Delta S$是图上阴影的轮廓部分的面积。

将整个环分成几对相似的小部分，这些部分相对于直径 $AB$ 对称。然后我们得到一个电流为 $I$ 的薄导电环，位于感应强度为 $B$ 的水平磁场中，将受到等于

$$M_{\text{магн}} = BIS = BI \pi R^2.$$

他绕水平轴$AB$旋转圆环。

当环处于提升边缘时，两个机械力将阻止其旋转：重力$mg$，施加在环的中心，垂直方向向下；法向反作用力$N$，施加在环与平面的接触点，垂直方向向上。由于圆环仍保持平衡，

$$mg - N = 0, \text{ т. е. } N = mg,$$

因此机械力形成了自己的一对力，从而产生了自己的扭矩

$$M_{\text{мек}} = mgR.$$

根据环的平衡，所有力的总力矩（在我们的例子中是磁力和机械力的力矩之和）等于零：

$$M_{\text{магн}} - M_{\text{мек}} = 0, \text{ или } BI \pi R^2 - mgR = 0.$$

从这里可以找到当前值：

$$I = \frac{mg}{\pi BR}.$$
