片材c上距a和b点距离等于a和b点之间距离的点的增长速度是v的两倍。此时片材上哪里有速度等于3v的点？

运动，向量$\vec{v}$和$\vec{v}_{\text{bp}}$相互垂直（图1）：

$$\vec{v}_c = \vec{v} + \vec{v}_{\text{bp}},$$
或$v_c^2 = v^2 + v_{\text{bp}}^2.$

从 $v_c = 2v$ 开始，我们得到

$$v_{\text{bp}} = \sqrt{3}v.$$

现在让我们求点 c 到直线 ab 的距离。 a、b、c 点是等边三角形 (图 2) 的顶点。我们用 l 来表示它的边，例如 ab。然后是我们感兴趣的距离

$$d = l \frac{\sqrt{3}}{2}.$$

显然，速度绝对值大于 v 3 倍的胶合板的所需点位于平行于 ab 轴且距 ab 轴一定距离 L 的两条直线上。为了找到这个距离，我们进行如下操作。类推c点，我们将所需点的速度表示为相互垂直的$\vec{v}$和$\vec{v}'_{\text{bp}}$速度之和：

$$(3v)^2 = v^2 + (v'_{\text{bp}})^2,$$

我们从哪里得到它

$$v'_{\text{bp}} = 2\sqrt{2}v.$$

现在我们来比较速度$v_{\text{bp}}$和$v'_{\text{bp}}$。一方面，

$$\frac{v_{\text{bp}}}{v'_{\text{bp}}} = \frac{\sqrt{3}v}{2\sqrt{2}v} = \frac{\sqrt{3}}{2\sqrt{2}},$$

另一方面 -

$$\frac{v_{\text{bp}}}{v'_{\text{bp}}} = \frac{d}{L} = \frac{l\sqrt{3}/2}{L}.$$

因此，

$$\frac{l\sqrt{3}/2}{L} = \frac{\sqrt{3}}{2\sqrt{2}},$$
和$L = l\sqrt{2}$。
