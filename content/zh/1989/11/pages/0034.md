这意味着通过$E$线段$A'B'$与线$AC$的交点。因为三角形$A'EC$角$A'EC$相等
$$\pi - (\alpha + (\pi - 2\beta)) =
= 2\beta - \alpha > \frac{2\pi}{3} - \alpha >
> \frac{2\pi}{3} - \frac{\pi}{8} > \frac{\pi}{2},
$$
点$C'$作为相对于$A'B'$对称的点$C$，位于直线$AC$下方。原来直线$A'C'$向左倾斜，即角$\angle A'DC$是锐角：$\angle A'DC = \pi - (2\alpha + (\pi - 2\beta)) = 2(\beta - \alpha) < 4\alpha < \pi/2$。从$\alpha$的条件可知，$F'AC$也是锐角。
让我们证明，在由线$AD$、$AF'$和$DA'$组成的构造三角形$AND$中，高度$H_1$降低到$AD$的底边占据线段$AC$。正如我们已经看到的，有效的是$\angle A'DA < 4\alpha = \angle F'AD$，因此只要注意到$CD < AC$就足够了。 （最后一个不等式成立，因为在三角形 $A'CD$
$$\angle A'DC = 2\beta - 2\alpha >
> 2\pi/3 - 2\alpha > \pi/2 - 2\alpha >
> 4\alpha - 2\alpha = 2\alpha = \angle CA'D,
$$
因此$AC = A'C > CD$。）
令 $H_2$ 和 $H_3$ 为三角形 $AND$ 边省略的高度的底。顶点 $A$ 和 $D$ 处的每个三角形角度 $AND$ 与 $\frac{\pi}{2}$ 的差异均小于 0.004（检查！），因此线段 $H_2H_3$ 将穿过点 $B$ 下面。图形$\Phi$由等于$\triangle ABC$的7个三角形组成（参见图4），将“手风琴式”放置在$\triangle ABC$上（如问题M1155的步骤6）。此时，$\Phi$中的周期轨迹$H_1H_2H_3$将根据需要转变为由15个链接组成的三角形$ABC$中的周期轨迹$l$。
请注意，构造的轨迹$l$是稳定的：这意味着，随着三角形$ABC$的轻微变形，它会变成接近$l$的15链接周期轨迹。
所描述的构造可以被推广。让我们从一个辅助三角形 $\Delta_0$ 开始，它有一个底边 $AC$ 和底边的锐角 $\alpha$、$\beta$，为此构造了一个三角形链
$$\Delta - 2l, \Delta - 1, \Delta_0, \Delta_1, \dots, \Delta_{2k},
$$
与水平线 $AC$ 和上半平面相交，并且链的相邻三角形具有公共边并且相对于它对称。由于相对于非平行轴应用两个连续线段的结果是旋转，因此三角形$\Delta - 2l$相对于$\Delta_0$旋转某个角度$n_1\alpha + n_2\beta + n_3\pi$；类似地，三角形$\Delta_2k$相对于三角形$\Delta_0$旋转角度$m_1\alpha + m_2\beta + m_3\pi$。假设链数对($n_1, n_2$)和($m_1, m_2$)不成比例，三角形$\Delta - 2l$和$\Delta_2k$的边垂直于线$AC$，并且除了$A$和$C$之外，链三角形没有其他顶点。事实证明，无论角度 $\alpha$ 和 $\beta$ 的变化多么小，都可以获得具有稳定周期轨迹的三角形 $ABC$。特别是，如果$\Delta_0$是一个直角三角形，其中$\alpha = \pi/8$、$\beta = 3\pi/8$，则从距离表示法获得三角形，而对于$\alpha = \pi/2k$、$\beta = \pi/2l$，则从«Kvant» No.3中的stata获得三角形（参见本文中的图12）。
