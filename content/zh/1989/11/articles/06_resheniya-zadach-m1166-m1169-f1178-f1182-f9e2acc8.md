M1167。对于任何不是第一位的数字$i$，有多少种数字$1, 2, ..., n$的排列，其中至少有一个数字$i-1$和$i+1$位于$i$的左侧？

答案：$2^{n-1}$。让数字$k$放在第一位。请注意，如果$k > 1$，则数字$k-1, k-2, ..., 1$在我们的排列中按降序排列（如果我们从左向右移动）。事实上，根据条件，数字 1 的左边应该有 2，2-1 或 3 的左边应该有 3，3-2 或 4 的左边应该有 4，等等。同样，数字 $k+1, k+2, ..., n$ 的$k < n$ 是升序的，因为$n$ 的左边应该有$n-1$，数字$n-1$左边是数字$n-2$，依此类推。因此，任何重新排列的排列都是由数字$1, 2, ..., k-1$占据的位置集合唯一确定的（如果是$k=1$，即对于排列$1, 2, ..., n$，这样的位置可能根本不存在）。这些集合的数量等于 $n-1$ 元素集合的子集数量 - 除第一个元素之外的所有位置，即 $2^{n-1}$。

F1180。连接到电池的灯泡燃烧三个小时，之后电池完全放电。我们用相同的材​​料制作了该电池的复制品，其线性尺寸是其两倍。当连接到这样的副本时，同一个灯泡会亮多久？电池的内阻远小于灯泡的内阻。

由于化学电流源的电动势仅由其化学成分决定，因此复制品的电动势将等于电池的电动势。令该电动势等于$\mathcal{E}$，灯泡的电阻为$R$，光源的内阻为$r$。那么电池电路中释放的总功率为$P_1 = \mathcal{E}^2 / (R + r_1)$，复制电路中为$P_2 = \mathcal{E}^2 / (R + r_2)$。由于$r_1 \ll R$，因此$r_2 \ll R$，

$$P_1 \approx P_2 \approx \frac{\mathcal{E}^2}{R}.$$

化学电流源通过消耗其中储存的化学物质的能量来工作。与电池相比，副本包含 $2^3 = 8$ 倍的试剂，因此在相同的电量下，它可以完成相同的工作量。这意味着连接到副本的灯泡将保持亮起 24 小时。

F1181。硬而薄的导电材料在不导电的水平表面上刺痛，并位于均匀磁场中，其感应线是水平的。环质量$m$，半径$R$，指数值$B$。必须通过多少电流才能使刺开始升起？

让我们看看环仍处于水平位置时的情况（参见 图；它显示了俯视图）。让我们在其上突出显示点 $C$ 和 $D$ 的大小，每个长度为 $\Delta l$ 的两个小部分，相对于环$AB$ 的直径对称放置。第一段受到垂直向下的力

$$\Delta F_1 = BI \Delta l \sin \alpha = BI \Delta x,$$

其中$\Delta x$是线段$\Delta l$在直径$AB$方向上的投影。第二节受到垂直向上的力

$$\Delta F_2 = BI \Delta l \sin \alpha = BI \Delta x.$$

这些力大小相同且方向相反，代表一对力，可产生相对于 $AB$ 轴的旋转力矩

$$\Delta M = \Delta F_1 l_{CD} = BI \Delta x l_{CD} = BI \Delta S,$$

其中$\Delta S$是图上阴影的轮廓部分的面积。

将整个环分成几对相似的小部分，这些部分相对于直径 $AB$ 对称。然后我们得到一个电流为 $I$ 的薄导电环，位于感应强度为 $B$ 的水平磁场中，将受到等于

$$M_{\text{магн}} = BIS = BI \pi R^2.$$

他绕水平轴$AB$旋转圆环。

当环处于提升边缘时，两个机械力将阻止其旋转：重力$mg$，施加在环的中心，垂直方向向下；法向反作用力$N$，施加在环与平面的接触点，垂直方向向上。由于圆环仍保持平衡，

$$mg - N = 0, \text{ т. е. } N = mg,$$

因此机械力形成了自己的一对力，从而产生了自己的扭矩

$$M_{\text{мек}} = mgR.$$

根据环的平衡，所有力的总力矩（在我们的例子中是磁力和机械力的力矩之和）等于零：

$$M_{\text{магн}} - M_{\text{мек}} = 0, \text{ или } BI \pi R^2 - mgR = 0.$$

从这里可以找到当前值：

$$I = \frac{mg}{\pi BR}.$$
