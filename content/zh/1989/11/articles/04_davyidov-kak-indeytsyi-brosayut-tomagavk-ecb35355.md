现在看来，孩子们对“印第安人问题”的兴趣已经下降了，比如我的孩子们将不再能够区分休伦人和科曼奇人，而告诉奥西奥拉是谁会受伤吗？然而，他们对北美原住民使用传统武器的惊人能力并没有无动于衷。

当我们开始定期去远足时，读者提出的形成斧头投掷理论基础的想法就诞生了。在空闲时间，我们从营地找到一棵枯树（我们的森林里有很多这样的树）可以使用，并试图用斧头砍它。这是一个值得注意的事实。事实证明，如果你站在距树一定距离的地方，投掷的斧头击中树（而不是弹开，击中斧头或手柄）的可能性会急剧增加。同时，只需要极少的磨练就能学会（当然，站在这个距离）击中一棵枯树，例如，这是一百次中的一次。为了理解这一现象，作者提出了下面提出的模型。我们将会看到，一个人要能够使用战斧，根本不需要生来就是印第安人；而是一个人。事实上，你所需要做的就是培养用眼睛估计距离的能力，其他一切都会水到渠成。

现在让我们继续考虑该模型。显然，问题自然一分为二。

首先，您只需能够将斧头击入杆子或干树即可；其次，建议用刀片击打，不要用枪托或斧头击打。我们假设读者能够解决第一个问题。

投掷时手的动作如下。持斧手以一定的角速度$\omega$在肘部旋转，在斧头质心速度指向水平方向的瞬间发生投掷。严格来说，如果我们希望斧头出现在柱子上的某个点，那么它在投掷瞬间的速度方向可能与水平方向不同。然而，我们给自己设定了一个更温和的任务：只需将战斧插入垂直立柱（无论在什么位置）。通过这一表述，人们可以声称并接受地球的决定。重力的影响会导致斧头在柱子中出现得稍微低一些。

在我们的模型中，人们相信——这一点非常重要——在扔斧头时不会扭曲斧头。出于所有的愿望，实际上有必要（读者可以根据自己的经验轻松验证这一点）在投掷的短时间内随着酸的移动而使战斧产生明显的额外旋转。因此，在投掷的那一刻，我们只需松开斧头，让它继续自由移动。

让我们输入以下参数（参见第 19 页上的 图）： $l$ - 从肘部手臂旋转中心到点 $B$（我们握住斧头的斧头上的某个位置）的距离； $a$——点$B$到点$M$的距离——轴的质心； $\alpha$是手和斧头形成的角度。 $\alpha$的角度可以在一定限度内改变，但$\alpha \approx \pi/2$时投掷最方便。在这种情况下，抛出的斧头质心的运动速度将描述以下形式：

$$v = \omega \sqrt{a^2 + l^2}.$$

现在让我们确定飞行战斧的旋转角速度。最简单的方法是进入报告系统，沿着斧头的质心以$v$的速度移动。在这个报告系统中，点$M$（质心）被掩埋，点$B$（与战斧的所有其他点一样）围绕它旋转；任意时刻$B$点的速度$u$垂直于斧头，等于$\omega_B a$，其中$\omega_B$是飞行战斧的旋转角速度。在固定报告系统中，投掷瞬间的点$B$具有速度$\omega l$，方向垂直于$l$，即沿着轴。因此，

$$u = \omega_B a = \sqrt{v^2 - (\omega l)^2}.$$

代入$v = \omega \sqrt{a^2 + l^2}$，我们得到

$$\omega_B a = \omega a, \text{ т. е. } \omega_B = \omega$$

投掷的战斧将以角速度 $\omega$ 旋转，等于投掷时手臂旋转的角速度。即使角度$\alpha$与$\pi/2$不同，这个结论仍然有效。所获得的结果尽管简单，但却非常重要。事实上，由此可见，战斧质心的平移速度与其旋转角速度的比率并不取决于“投掷力”（投掷时施加给斧头的冲量），并且等于 $v/\omega = \sqrt{a^2 + l^2}$。这意味着斧头旋转 $n$ 圈后飞行的距离 $L_n$ 也不取决于投掷的力量。考虑到斧头旋转$n$转所需的时间是$2\pi n/\omega$，我们找到$L_n$：

$$L_n = 2\pi n \sqrt{a^2 + l^2}.$$

我们得出了一个显着的结论：存在一个距离$L_n$的“范围”，为了在投掷时成功，你需要与目标保持一定的距离

$$L_n + \arctg (l/a)\sqrt{a^2 + l^2}$$

（第二项的出现是因为在投掷的瞬间，斧柄与垂直方向形成了等于$\arctg (l/a)$的角度）。

我们来估计一下“量子”$L_1$各元素的值，即斧头飞行一圈的距离。我们取$l = 33$厘米，$a = 20$厘米（作者用自己的手和他私人木匠的斧头测量）。计算得出$L_1 = 2,42$米。因此，从 2.82 m 的距离投掷斧头（请记住，对于 $L_1$，您还需要添加带有 arctigens 的项），旋转一圈，将击中目标。

经验表明，实际上无需任何训练，您就可以从 $L_1$ 和 $L_2$ 的距离成功击中目标。提升到下一个“量子水平”已经更加困难，但作者的许多熟人在没有明显增强的情况下，距离$L_4$（超过10 m）的距离相当于一棵枯树。

“这一切都太棒了，”读者会说。 “然而，印度人不仅能够在$L_n$距离内击中目标。他是如何做到这一点的呢？

似乎一切都很简单。我们的模型有一个参数 $a$，很容易更改：为此，只需在投掷战斧时抓住其手柄上的另一个位置即可。在这种情况下，“频谱”也会有所不同。因此，捕捉点$B$位置的变化导致“层次”$L_n$的模糊，并形成其自身的象征性“区域结构”。在这些允许区域之一内，您可以选择点 $B$ 的位置（或者相同的参数 $a$），并成功投掷。此外，如果您使用手柄足够长的战斧，则可以添加与连接级别$L_n$和$L_{n+1}$相对应的区域重叠。让我们估计一下所需的手柄长度

ki $b$。显然，为了使相邻区域重叠，必须执行以下任务：

$$2\pi n \sqrt{l^2 + b^2} = 2\pi (n + 1)\sqrt{l^2 + a_{\min}^2},$$

其中 $a_{\min}$ 是点 $B$ 到质心 $M$ 的最小距离。经验表明，如果$a$小于10厘米，扔斧头就不方便。因此，要估计 $b$，$a_{\min}$ 的值可取等于 10 cm。解最后一个方程，我们得到 $b$：

$$b = \frac{1}{n} \sqrt{(2n + 1)l^2 + (n + 1)^2a_{\min}^2}.$$

考虑这个表达式表明最长的轴需要重叠第一和第二区域，即$n = 1$。将$l = 33$厘米、$a_{\min} = 10$厘米、$n = 1$的值代入$b$的公式中，我们得到$b \approx 60$厘米。为了覆盖第二和第三区域（$n = 2$），拥有手柄长度$b = 40$厘米等的战斧就足够了。因此，为了能够从任何距离击中目标，$b$的值应该相当大。难怪印度战斧的柄这么长！

事实上，你可以使用更短的斧头长度：斧头可以被森林的上部和下部砍成一棵干树，这会导致允许区域的边界进一步缩小。笔者的经验表明，一把50厘米长的斧子就足够了。

因此，所考虑的模型表明，学习准确投掷战斧并不那么困难。您只需要估计到目标的距离并将斧头握在手柄上的适当位置即可。在这种情况下，可以通过在轴上标记与到目标的给定距离相对应的分区来对轴进行预编程。

但印第安人是如何投掷战斧的呢？他们很有可能以上述方式做到这一点。但也许他们也可以用刷子扭转斧子？作者不知道这一点，因为他不认识任何印第安人。剩下的就是发现有一天这样的相识确实会发生，即使那样，作者也不会错过发现这种奇妙艺术的更多秘密的机会。

战斧投掷是一项有趣的运动。也许他会在我们中间找到他的追随者，他们会组建一个协会，进行北方探险——谁知道呢？ ——它会被纳入奥运会项目吗？
