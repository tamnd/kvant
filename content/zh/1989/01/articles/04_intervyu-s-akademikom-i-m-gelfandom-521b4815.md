院士专访
I.M.格尔芬多姆

格尔凡德的数学研讨会45年来一直在莫斯科大学每周一晚上举行，该研讨会举世闻名。一年级学生和著名科学家都在研讨会上学习。这次研讨会培养了几代杰出的数学家。

伊斯雷尔·莫伊塞维奇是全俄函授数学学院的创始人及其科学委员会主席。这所学校的主要任务是帮助那些与莫斯科、列宁格勒和其他大城市的居民不同的学童，他们实际上被剥夺了数学文献和与科学家的接触。全能函授数学学校创建于25年前，是我国第一所此类学校；随后，其他函授学校也纷纷效仿开设。

与格尔凡德院士的会面一直被计划为一般采访«Kvant»。我们准备了我们认为读者和对话者都会感兴趣的问题。以色列·莫伊塞维奇（Israel Moiseevich）浏览了问题清单后指出，这些问题非常有趣，但他……不认为自己有能力回答这些问题。

b) 相同 - 对于方程根的平方和和立方和

$$x^n + a_1x^{n-1} + \dots + a_n = 0.$$

提示：使用 Vieta 的公式：

$$a_1 = -(x_1 + x_2 + \dots + x_n), \quad a_2 = x_1x_2 + x_1x_3 + \dots + x_n-1x_n, \quad a_3 = -(x_1x_2x_3 + x_1x_2x_4 + \dots + x_n-2x_nx_1x_n),$$ 其中 $x_1, x_2, \dots, x_n$ 是方程的根。

为了解决方程根的幂和如何通过其系数表示的一般问题，I. M. Gelfand 证明了牛顿公式：

$$p_k + a_1p_k-1 + a_2p_k-2 + \dots + a_k-1p_k = 0, \quad k \leq n, \quad p_k + a_1p_k-1 + a_2p_k-2 + \dots + a_np_k-n, \quad k > n.$$

这里$p_k$表示根$x_i^1 + x_i^2 + \dots + x_i^n$的$i$幂之和。

牛顿公式可以被视为 $p_i$ 和系数 $a_1, a_2, \dots, a_n$ 的线性方程组。如果你求解这个方程组，你将得到Variant公式，它通过其系数直接表达方程组的次数之和。在现代数学中，这种情况得到了很大的发展。
