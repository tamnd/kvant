如果将质量 $m$ 和电荷 $q$ 的自由精确频率放置在电容器的极板之间，频率是多少？也没有什么力气。声称“静电装置”的边际效应和强度。

$$ma = \frac{qU}{d}.$$

如果$U$按照调和律$U = U_0 \cos \omega t$变化，则
$$v = \left( qU_0 / (md\omega) \right) \sin \omega t,$$
$$x = -\left( qU_0 / (md\omega^2) \right) \cos \omega t,$$
$$I = -CU_0 \omega \sin \omega t.$$

根据能量守恒定律
$$W = U_0^2 \left( \frac{L}{2} (C\omega)^2 + \frac{m}{2} \left( \frac{q}{m\omega d} \right)^2 \right) \sin^2 \omega t +$$
$$+ U_0^2 \left( \frac{C}{2} + \frac{q^2}{m(\omega d)^2} \right) \cos^2 \omega t = \text{const.}$$

仅当 $\cos^2 \omega t$ 和 $\sin^2 \omega t$ 的系数相等时，这才有可能。从这里我们得到
$$\omega^2 = \omega_0^2 / 2 + \left( \left( \omega_0^2 / 2 \right) \right)^2 + \left( q\omega_0 / d \right)^2 / (mC)^{1/2}.$$

让我们评估在什么条件下可以应用一种“静电选择”*（如上所述）。该力的数量级等于$q^2 x / (\varepsilon_0 d^3)$，应该远小于“普通”静电力$qU/d$，因此
$$\frac{q^2}{\varepsilon_0 d^3 m\omega^2} \ll 1.$$

由于电容器极板的面积为 $S \gg d^2$ 和 $C = \varepsilon_0 S / d$，如果将粒子引入电容器不会极大地改变电路中的振荡频率，则公式 (*) 有效。

由于多普勒效应，反射信号的频率与发射器的频率不同。如果反射无线电伏特的物体的速度恰好指向雷达（或远离雷达），则会出现最大频移。

我们假设雷达发送重复频率为$f_0$的短无线电脉冲，而它接收到的脉冲频率为$f_1$。第 $n$ 和 $(n+1)$ 脉冲到达雷达天线的时间间隔等于
$$\frac{1}{f_1} = \frac{1}{f_0} + T_{n+1} - T_n,$$
其中，$T_n$是$n$脉冲从雷达到反射物体并返回的传播时间，$T_{n+1}$是$(n+1)$脉冲的传播时间。
