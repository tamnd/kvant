添加这些等式，我得到

$$F(n+1) - F(1) = S_0 + \frac{S_1}{2!} + \frac{S_2}{3!} + \dots,$$

其中 $S_0$ 是我感兴趣的金额，并且

$$S_1 = f'(1) + f'(2) + \dots + f'(n),$$

$$S_2 = f''(1) + f''(2) + \dots + f''(n),$$

然后我就写下了这个系统

$$F(n+1) - F(1) = S_0 + \frac{S_1}{2!} + \frac{S_2}{3!} + \frac{S_3}{4!} + \dots,$$

$$f(n+1) - f(1) = S_1 + \frac{S_2}{2!} + \frac{S_3}{3!} + \dots,$$

$$f'(n+1) - f'(1) = S_2 + \frac{S_3}{2!} + \dots,$$

即一个具有无限个未知数$S_0, S_1, S_2$的无限系统，...我已经提到卡根的书有无限个行列式，所以我能够使用“克莱默规则”来找到$S_0$：

$$S_0 = \frac{1}{1}$$

我将这个“分数”的分子扩展到第一列，得到

$$S_0 = B_0(F(n+1) - F(1)) + B_1(f(n+1) - f(1)) + B_2(f'(n+1) - f'(1)) + \dots,$$

(1)

其中 $B_0 = 1, B_1, B_2, \dots$ 是无限阶的数值行列式。得到的表达式称为欧拉-麦克劳林公式，但我当然不知道它。为了计算它，需要找到系数$B_0, B_1, B_2, \dots$。

为此，我应用了今天称为“功能性”的考虑因素。也就是说，利用系数$B_0, B_1, \dots$不依赖于$f$的事实，我选择了一个函数$f$，使得系统的左侧形成几何级数（我知道如何求和）。函数$f(x) = e^{\alpha x}$就适合这个，将其代入公式（1），我得到（计算一下！）

$$B_0 + \alpha B_1 + \alpha^2 B_2 + \dots = \frac{\alpha}{e^{\alpha}-1},$$

即，他获得了所需数字$B_0, B_1, B_2, \dots$的函数乘积（它们称为伯努利数，$f(x) = x^p$的多项式$S_0$称为伯努利多项式）。
