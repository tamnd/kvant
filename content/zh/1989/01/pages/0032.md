物理和数学科学候选人
V·L·古腾马赫

在现代情况下，经常会自然地出现同样的数学问题——从谜题到应用计算。今天我们几乎要讨论其中一项任务。

算术题

找到所有右边等式为的自然数四元组 (p, q, r, s)

$$\frac{1}{p} + \frac{1}{q} + \frac{1}{r} + \frac{1}{s} = 1.$$

我们假设$p \leq q \leq r \leq s$。那么最小的数 - $p$ - 不大于 4（否则为 $\frac{1}{p} + \frac{1}{q} + \frac{1}{r} + \frac{1}{s} < 1$），当然也不能小于 2。因此，我们需要考虑三种情况：$p=2$、$p=3$、$p=4$。

让$p=2$。然后$\frac{1}{q} + \frac{1}{r} + \frac{1}{s} = \frac{1}{2}$。让我们再次估计最小的数字 - $q$。它不能超过 6（否则 $\frac{1}{q} + \frac{1}{r} + \frac{1}{s} < \frac{1}{2}$）并且必须至少为 3。

现在将等式 $\frac{1}{q} + \frac{1}{r} + \frac{1}{s} = \frac{1}{2}$ 代入四种可能的情况
