3. $\frac{7}{\sqrt{3}}$。笔记。令$AK = a, \angle KAO = \varphi$、点$K'$为点$K$到直线$AC$ (图 1) 的正交投影。从问题的条件可以得出$OK' = 1$。然后

$$|a| < 1, \quad (3a - 4b + 15)(7a - 24b + 35) < 0.$$
该集合是一个顶点位于点 $A\left(1; \frac{9}{2}\right), B\left(1; \frac{7}{4}\right), C\left(-1; \frac{7}{6}\right), D(-1; 3)$ 和 $AB + CD = AD + BC$ 的引力。设圆心纵坐标为$b$。由于圆的半径等于1，直线$AD$与纵坐标轴相交于点$\left(0; \frac{15}{4}\right)$，所以$b$就是方程$\left(\frac{15}{4} - b\right)\cos \left(\arctg \frac{3}{4}\right) = 1$。
5. $\frac{63}{4}\sqrt{\frac{3}{2}}$。解决方案。在五边形 $KK_1K_2K_3K_4$ (图 2) $K_1K_2 \cos \angle KK_1M = \frac{7}{2} \cos (\arctg \sqrt{55}) = \frac{7}{4\sqrt{14}}$ 中。请注意，$KK_1 - K_2K_3 = \frac{7}{4\sqrt{14}}$因此是$(KK_3) \perp (KK_1)$。令 $AB = a, \angle CKK_1 = \varphi$、点 $K'_2$ 和 $K'_3$ 为点 $K_2$ 和 $K_3$ (图 3) 在平面 $ABC$ 上的正交投影。将正弦定理应用到三角形$KCK_1, AK'_2K'_2, KBK'_3$（考虑到$\angle K_1KK'_3$是一条直线），我们得到：
$$\frac{\sqrt{14}}{2} \sin \left(\frac{\pi}{3} + \varphi\right) = \frac{a}{2} \sin \frac{\pi}{3},$$
$$\frac{3}{8} \sqrt{14} \sin \left(\frac{\pi}{3} + \varphi\right) = AK'_2 \sin \frac{\pi}{3},$$
$$\frac{a}{2} \cos \varphi = (a - AK'_2) \sin \left(\frac{\pi}{6} + \varphi\right).$$
从(1)和(2)我们得到$AK'_2 = \frac{3}{8} a$，考虑到(3)，得出$\varphi = \arctg \frac{\sqrt{3}}{5}$。接下来我们找到$a = 3\sqrt{2}, K_1K'_2 = \frac{7}{2\sqrt{2}}$。线的高度为$\frac{7}{2\sqrt{2}}$。
