⟦folio 29⟧

动量和动能之间的另一个区别。也许物体动量最具替代性的性质是，一个封闭的物体系统的总冲量（即系统中所有物体的冲量的矢量和）在该系统物体的任何相互作用和任何运动下保持不变。这就是动量守恒定律（“Physics 8”，§ 51）。

它具有动能守恒的性质吗？让我们看一个简单的例子，从这个例子中我们会立即清楚地看出，在这种情况下动量和动能是不同的。

让两个相同的质量为$m$的钢球分别沿着光滑（无摩擦）的水平表面以相等的绝对速度$v$（参见图）移动。在某个时刻，球会接触，然后它们会继续相互接近一段时间，然后它们会停止一会儿，之后它们将开始发散，直到它们开始以相同的速度向相反的方向移动。

让我们看看两个球在碰撞前、碰撞中和碰撞后的总冲量和动能分别是多少。

碰撞前，两球的动量大小相等，方向相反，因此

$$\vec{P}_1 + \vec{P}_2 = (m\vec{v}) + (-m\vec{v}) = 0,$$

且球的动能相同且均等于 $mv^2/2$，因此

$$E_{k1} + E_{k2} = \frac{mv^2}{2} + \frac{mv^2}{2} = mv^2.$$

在碰撞期间，当两个球都静止时，它们的速度为零，因此，

$$\vec{P}_1 + \vec{P}_2 = 0,$$

$$E_{k1} + E_{k2} = 0.$$

碰撞后，球与碰撞前一样，以相同的绝对速度向相反方向移动，因此

$$\vec{P}_1 + \vec{P}_2 = -m\vec{v} + m\vec{v} = 0,$$

$$E_{k1} + E_{k2} = \frac{mv^2}{2} + \frac{mv^2}{2} = mv^2.$$

因此，两个球系统的总动量始终保持不变。碰撞前后的动能是相同的（这种碰撞称为弹性碰撞），但在碰撞过程中它发生了变化，以至于在某个时刻甚至暂时完全消失。这意味着存在动量守恒定律，但不存在动能守恒定律。

请注意，如果球不是由钢制成，而是由软粘土或橡皮泥制成，则在碰撞时它们会被切割、留下并且不再移动（这种碰撞称为绝对非弹性碰撞）。它们的总动量仍然为零，碰撞时的动能不会暂时消失，而是永远消失。

众所周知，能量守恒定律也存在，但不是动能守恒定律，而是总能量守恒定律，总能量包括其他形式的能量。因此，在我们的例子中，球体弹性碰撞过程中动能的暂时损失仅意味着此时动能完全转化为球体弹性变形的势能。碰撞结束，势能再次完全转化为动能。在非弹性撞击过程中，球的动能转化为内能（球升温），而内能不再转化回动能。
