积分法

本文适用于九年级和十年级学生。申请人在准备大学入学考试时也可以使用它。

在学校代数课程中，一个重要的地方是专门讨论不等式：首先是线性不等式，然后是二次不等式，然后是涉及对数、指数和三角函数的不等式。渐渐地，不平等就产生了——学校里学习的各种功能组合出现了。在本文中，我们将通过几个例子来说明解决不等式的一种重要方法，通常称为“积分法”。我们将在这里考虑不等式，其右侧部分等于零，左侧部分以具有已知常数符号区间的函数的乘积或部分形式呈现。积分方法基于以下思想：乘积（部分）的符号由因子（delim 和 divisor）的符号确定。

问题 1. 解决不平等问题

$$\frac{(2x-1)(x^2-x-2)}{3-x} < 0.$$

斜率非零的线性函数在通过根时会改变符号，并且在根的右侧，函数的符号与斜率的符号一致 (图 1)；具有正判别式的平方三项式在通过每个根时也会改变符号，并且在根的右侧，平方三项式的符号与其首项系数的符号一致（图2）。

这些消息导致了以下解决不等式的方案。

1. 我们找到每个“分量”的根：$x=\frac{1}{2}; x=-1, x=2; x=3$。

2. 数轴分为五个区间。在它们的最右边，因子与其首项系数的符号一致：$2x-1>0, x^2-x-2>0, 3-x<0$。

因此，该区间上的分数为负。

3. 当通过每个标记的根时，只有一个因子改变符号，因此分数的符号每次都会改变。考虑到这一点，我们在这些区间中放置了符号（如图3所示）。

4. 我们选择分数为负的区间。

回答：

$$]-\infty; -1[\cup]\frac{1}{2}; 2[\cup]3; +\infty.$$

问题 2. 解决不平等问题

$$\frac{4-x^2}{(5x-2)\lg x} \ge 0.$$

对数函数的极限。

1. 根“因子”：$x=2; x=0,4; x=1$ (图 4)。

2. 半轴$]0; +\infty[$分为四个区间。最右边的是$4-x^2<0, 5x-2>0, lgx>0$。因此，位于该区间的不等式部分为负。

3. 当通过每个根时，只有一个因子改变符号。考虑到这一点，我们在剩余的区间上放置了符号 (图 4)。

4. 我们已经解决了严格的不平等问题。剩下的就是将方程的根添加到结果组的解中

$$\frac{4-x^2}{(5x-2)lgx}=0,$$

即分数分子的根（包含在不等式定义域中）。

答案：$]0; 0,4[\cup]1; 2]$。

问题 3. 解决不平等问题

$$\frac{(10^x-2)(x^2-5x+7)}{x+3} \leq 0.$$

解如图 5 所示。分数分子中的平方三元组没有根，因此不会改变符号，这与其首项系数的符号一致。

答案：$]-3; lg2]$。

问题 4. 解决不平等问题

$$(x^2-2x-3)(6+x-x^2) \geq 0.$$

1. 求因子的根：$x=-1, x=3, x=-2, x=3$。

2. 对于$x>3$，不等式的左侧为负。

3. 当经过点$x=3$时，两个因子都改变符号（$x=3$是它们的共同根），因此乘积的符号不会改变。

当穿过其他两个根时，左侧（如前面的示例所示）会改变符号 (图 6)。

答案：$[-2; -1]\cup\{3\}$。

从这个问题可以清楚地看出，使用积分方法，有必要监视有多少因子在通过给定根时改变符号。因子可能在通过其根时不会改变符号（例如，判别式为零的平方三元组）。

解决以下问题的想法基于一个直观清晰的定理，数学分析课程中给出了该定理的确切证明：如果一个函数在某个区间上连续并且在该区间内没有根，则它在该区间内保留其符号。

任务 7. 解决不平等问题
$$\sqrt{x+2} > x.$$ (1)

函数 $y = \sqrt{x+2} - x$ 已定义且在区间 $[-2; +\infty]$ 上连续。

我们来求这个函数的根，也就是解方程
$$\sqrt{x+2} = x.$$ (2)

将方程(2)两边同时平方，得到根为$x = -1$、$x = 2$的二次方程$x^2 - x - 2 = 0$。检验发现方程(2)的根仅为$x = 2$。这一点将不等式(1)的定义域分为两个区间：$[-2; 2[$和$]2; +\infty[$。在每个区间上，函数 $y = \sqrt{x+2} - x$ 保留其符号，即该区间的所有点要么满足不等式 (1)，要么都不满足。因此，只需将每个区间中的一个点代入不等式（1）即可。我们选择点 $x = -2$ 和 $x = 7$。由于 $x = -2$ 满足不等式 (1)，但 $x = 7$ 不满足，因此不等式 (1) 的解集是区间 $[-2; 2[$ (图 9)。

答案：$[-2; 2]$。

问题 8. 解决不平等问题
$$x\sqrt{10-x^2} \geq x^2 - 6.$$

1. 函数$\sqrt{10-x^2}$的定义域：$[-\sqrt{10}; \sqrt{10}]$。

2. 我们解方程：
$$x\sqrt{10-x^2} = x^2 - 6,
x^2(10-x^2) = (x^2 - 6)^2;
x^4 - 11x^2 + 18 = 0.$$

我们得到四个根：$x = \pm \sqrt{2}, x = \pm 3$。检查留下两个根：$x = -\sqrt{2}, x = 3$ (图 10)。

3. 我们将数字 $x = -\sqrt{10}, x = 0, x = \sqrt{10}$ 代入不等式中。数 $x = 0$ 满足不等式，但数 $x = \pm \sqrt{10}$ 不满足。

答案：$[-\sqrt{2}; 3]$。

众所周知，线性、二次、幂、指数、对数和三角函数，以及它们的组合和使用算术运算从它们获得的函数，在它们的定义域中是不正确的。因此，积分法几乎可以用来解决学校课程中的所有不等式。积分方法允许您将不等式的解集表示为区间的并集，其边界是相应方程的根或定义不等式的域的边界点。

连续性的要求对于积分法的应用至关重要。你可以在下一个问题中验证这一点。

任务 9. 解决不平等问题
$$[x] \leq x - \frac{1}{2}.$$

让我们构建不等式 (图 11) 左侧和右侧的图。方程 $[x] = x - \frac{1}{2}$ 的根是 $k + \frac{1}{2}$ 形式的数字，其中 $k$ 是任意整数。同时，不等式的解集是$[k + \frac{1}{2}; k + 1]$形式的区间的并集，其边界点特别是既不是方程的根也不是定义域的边界点的所有整数。
