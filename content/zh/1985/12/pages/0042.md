光的干涉

物理和数学科学候选人
E·I·布蒂科夫

光的波动特性在干涉和衍射现象中最清楚地显现出来。这些现象是任何性质的波的特征。它们在实验上相对容易观察，例如声波或水面上的波浪，但要观察光的干涉或衍射，必须满足一定的条件。尤其是它们将在这个国家受到讨论。

光的干涉是指观察多束光束的过程，其中每个点处产生的光强度*)不等于各个光束的强度之和。在某些地方，强度大于总强度，而在另一些地方则小于总强度，也就是说，它们形成交替的亮区和暗区 - 出现干涉图案。

最简单的干涉例子是在波相加中观察到两个频率相同且振荡方向相同的单色波。因此，每个点都会以相同的频率和幅度发生振荡，并且随着时间的推移，该振荡是恒定的，但具体取决于该点的位置。

令折叠振动的振幅相同，则对于有效振动$E(t)$，我们得到

$$E(t) = E_1(t) + E_2(t) = a \cos(\omega t + \varphi_1) + a \cos(\omega t + \varphi_2) = 2a \cos \frac{\varphi_1 - \varphi_2}{2} \cos \left( \omega t + \frac{\varphi_1 + \varphi_2}{2} \right),$$

也就是说，振幅$A = 2a \left| \cos \frac{\varphi_1 - \varphi_2}{2} \right|$取决于所产生的振荡的相位差$\varphi_1 - \varphi_2$，并从每个波的双振幅$2a$（在振荡同相的点）到零（在反相振荡的点）取值。振动的能量，即光的强度$I$，与其振幅的平方成正比：$I \sim A^2$。从公式（1）可以看出，根据观测点的位置，所得强度$I$取值从零到单个波强度$I_0 \sim a^2$的四倍：

$$I = 4I_0 \cos^2 \frac{\varphi_1 - \varphi_2}{2} = 2I_0 (1 + \cos (\varphi_1 - \varphi_2)).$$

空间中对应于相同强度（部分、最大或最小）的点集形成表面，具体取决于光源的属性和位置。

问题 1. 两个完全相同的源彼此相距一定距离。在这种情况下，最大和最小强度具有什么形式？

给定点的相位差$\varphi_1 - \varphi_2$取决于来自同相源的波的路径差$l$：$l = l_1 - l_2$。如果路径差等于整数个波长：$l = k\lambda$ ($k = 0, 1, 2, ...$)，则波同相到达观察点，并且相加后会产生最大幅度的振荡。如果路径差等于奇数个半波：$l = (2k + 1)\lambda/2$，则波反相到达并相互“抵消”。因此，最大值和最小值之间的差异由条件$l_1 - l_2 = const$决定。
