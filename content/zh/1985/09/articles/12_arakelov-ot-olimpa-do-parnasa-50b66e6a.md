自然系列

传说自然数列——正整数的序列：1、2、3……——是普罗米修斯赋予人们的。但事实上，自然系列的发明是穆塞利曼最早也是最伟大的成就之一，是从实践中诞生的。自然系列出现的历史早在文字发明之前就开始了。过了好几个世纪才明白这个系列中没有最多的数字。很长一段时间以来，人们认为计数只在一定的限度内出现，超过这个限度，“主题”就开始了。例如，巴比伦人相信，存在着一个奇妙的数字“利维纳坦”，超出这个数字就会延伸出无法计算的数字。

直到公元前3世纪，古希腊数学家阿基米德在他的著作《Psammit》（《沙子的演算》）中表明，任意数量的沙子仍然可以被计算，因为自然级数可以无限延续，并且每个后续的数字都可以以某种方式书写和命名。因此，我们认识到自然数有无限多个。这个事实就是数学家所说的自然数集合是无限的。

那么，关于素数我们能说些什么——它们的集合是有限的还是无限的？欧几里得的《几何原本》（公元前 3 世纪）表明，不存在大多数公式

$$1 + 2 + 3 + \dots + n = \frac{1}{2} n (n + 1)$$

$$1^2 + 2^2 + 3^2 + \dots + n^2 = \frac{1}{6} n (n + 1) (2n + 1)$$

$$1^3 + 2^3 + 3^3 + \dots + n^3 = \frac{1}{4} n^2 (n + 1)^2$$

从奥林匹斯山到帕纳索斯山
从奥林匹斯山到帕纳索斯山，
致诸神的善良缪斯，
骑着佩萨斯的马，
我在五个小时内到达那里。

减速十英里，
悲伤的是我还有七个小时的路程
返回奥林巴斯，一个月
宙斯照亮了我的庇护所。
