锻炼
周年纪念日
莫斯科市
数学的
奥运会

今年莫斯科数学奥林匹克竞赛已举办第48届； 700多名小学生参加了活动。虽然数字并不“圆”，但本届奥运会可以理所当然地被视为周年纪念——第一届奥运会恰好是在 50 年前举办的。 1985年奥林匹克运动会最后一轮于3月24日在莫斯科大学举行。我们提出了那里提出的任务。

七年级
1. 找到$x$和$y$满足等式的所有值
$$xy + 1 = x + y.$$
2. 给定五个不同的正数，可以将其分为两组，使得这些组中的数之和相同。有多少种方法可以做到这一点？
3. 四个线段的长度$a, b, c, d$满足不等式$0 < a \leq b \leq c < d, d < a + b + c$。是否可以用这些线段拼成一个梯形？
4. 广场中央有一只扎特，四个角各有一只狼。如果狼只能以 zac 最大速度的 1.4 倍的最大速度沿着方格的边跑，那么 zac 能跑出方格吗？
5. 一个牛奶罐被带到了马塔津。卖家有所有没有重量的东西（你可以在秤的侧面放烧瓶），还有三个相同的烧瓶，其中两个是空的，第三个装有1升牛奶。如何将 85 升牛奶倒入一个烧瓶中而不需要称重？
八年级
1. 找到$x, y$和$z$满足等式的所有值
$$(x - y + z)^2 = x^2 - y^2 + z^2.$$
2. 数字 $a_1, a_2, \dots, a_{1985}$ 代表数字 1, 2, ..., 1985 按某种顺序重新排列。每个数字$a_k$乘以它的数字$k$，然后在获得的所有1985个产品中选择最大的一个。证明它不小于$993^2$。
3. 将一个纸方块放在一张纸上“放在笼子里”，其面积等于笼子面积的四倍。可以覆盖这个正方形的最少节点数是多少？ （节点是线性纸的交点；如果节点位于正方形的边界上，则认为它被覆盖。）
4. 切尔诺莫叔叔身后排着无数有钱人。证明他可以命令其中的一部分失败，从而使该行中剩下无限多个富人，并且它们都按高度顺序排列（不一定按高度降序排列）。

5. 证明如果三角形三等分线的长度都大于1，则其面积大于1/√3。

九年级
1. 找到$x, y$和$z$满足等式的所有值
$$\sqrt{x - y + z} = \sqrt{x} - \sqrt{y} + \sqrt{z}.$$
2. 一些国家有 1,985 个机场。一架飞机从他们每个人身上起飞，降落在发射场的一个飞机机场。难道1985年的所有飞机都停在了50个机场吗？ （地球可以认为是平的，路线是笔直的。）
3. 请参阅八年级问题 3。
4. 证明在任意 12 个人中你可以选择两个，并且在 10 个人中还剩下 5 个，因此这 5 个中的每一个都满足以下条件：要么他与所有一开始选择的人都是朋友，要么他与他们中的任何一个都不是朋友。
5. 证明任何数字$2^n$，其中$n=3, 4, 5, \dots$都可以表示为$2^n = 7x^2 + y^2$，其中$x$和$y$是奇数。

10年级
1. 解方程
$$\frac{x - 49}{50} + \frac{x - 50}{49} = \frac{49}{x - 50} + \frac{50}{x - 49}.$$
2. 请参阅七年级问题 3。
3. 让我们通过一个数字序列（如果有的话）的最短长度来定义给定数字的“复杂性”，该数字序列从零开始并以该数字结束，并且每个后续序列要么等于零$m/2^{50}$，其中$m=1, 3, 5, \dots, 2^{50}-1$，找到最“复杂性”的数字。
4. 数据 1985 个集合，每个集合由 45 个元素组成，任意两个集合的并集恰好包含 89 个元素。所有这些 1985 个集合的并集包含多少个元素？
5. 证明如果四面体交叉边之间的距离等于$h_1, h_2, h_3$，则四面体的体积不小于$h_1h_2h_3/3$。

八年级
1. 一个孔切克形状的桶，部分装满水，用两个相同的塞子封闭，对它们施加相等的力 (图1)。努力将颊部从一个地方移动到另一个地方，将其宽直径向下握住，然后慢慢地将颊部翻转过来，使其窄直径向下。此后，塞子飞出，水开始从桶中流出。插头为什么会出来？

2. 带有小链节的柔性链条连接两个小球，这两个小球比链条中的任何链节都要大得多。然而，其中一个球被固定在圆形光滑水平桌子的中心，而另一个球与一小段链条一起从其边缘发光。假设桌子的高度大于链条的长度，如果你想象系统本身，请确定球与地板的第一次接触点在哪里：1）在一个以桌子为“屋顶”的圆内； 2）在上述圈子之外； 3）在其边界上。特雷纳姆伪装者。

3. 身体开始沿着粗糙的斜面下滑，并在最低点撞击垂直于其运动方向的弹性壁。撞击之后，身体上升到原来高度的一半。假设速度模量在撞击过程中没有变化，请确定哪个花费的时间更长：上升或下降。多少次？

4. 悬挂在失重线上的小质量体$m$从平衡位置偏转角度$a$并释放。确定第一时刻线的张力。

5. 测功机由两个通过轻弹簧（图2）连接的圆柱体组成。如果对这些圆柱体施加力 $F_1$ 和 $F_2$，则直径读数为 $F$，求这些圆柱体的质量比。

九年级

1. 单轨列车的电机功率可达 $N=100$ kW。拖车开始在一侧移动并停止在另一侧。求出此操作所需的最短时间。车轮在轨道上的摩擦系数$\mu=0,2$。站间距离$l=800$米，车厢重量100公斤。移动时的空气阻力减少。

2. 如果第一次用氢气，第二次用氦气，与大气连通的气球的升力会变化多少次？球壳的质量是 pretenbrets。

3. 一根细密的封闭管充满密度为 $Q$ 的液体，并在水平面上绕穿过管端之一的轴 (图 3) 旋转。管内的液体压力由位于距旋转轴$l_1$和$l_2$距离处的两个压力表测量。当管子以角速度$\omega$匀速旋转时，压力表显示的差异$\Delta p=p_2-p_1$是多少？

4. 请参阅八年级问题 5。

5. 在高速公路的某些路段，车队中的自动驾驶车辆将速度从$v_1$降低到$v_2$。自动驾驶仪之间的初始距离应该是多少，以免它们被惊呆？每台机器的长度为$l$。

10年级

1. 该系统由两个容器 $A$ 和 $B$ 组成，通过一根细长管相互连接，并填充均匀液体 (图 4)。使用该系统进行了两个实验。在第一个实验中，容器 $A$ 被加热，在第二个实验中，容器 $B$ 被加热。这会导致液体流过管子吗？如果是的话，走哪条路？容器和管道受热时的膨胀以及系统的导热性是预膨胀的。

2. 将质量$M$的载荷瞄准垂直未变形梁的下端，无初速度释放，然后开始进行垂直谐波摆动。如果一只质量 $m$ 是负载质量 96% 的甲虫在没有推动的情况下落到负载上，振荡的周期和幅度会改变多少次？无推力着陆意味着在接触瞬间甲虫的速度和负载相同。考虑着陆情况：1) 在轨迹的最高点，2) 在轨迹的最低点。

3. 如图图5所示的装置，连接到电压为$U=220$V的交流网络上，电压表长期显示的电压是多少？

4. 请参阅九年级的问题 5。

5. 两个质量相同的小物体 $m$ 各自带有相同的电荷 $q$，并且彼此之间的距离为 $r$ (图 6)。首先，释放了1号本体。当它移开距离$2r$时，2号体也被释放。求距离较远的物体的速度。没有培训。
