浴室对 因此，在点 $A$ 处具有公共顶点的匹配对的数量为

$$\frac{1}{2} (k^2 - k + (n - 1 - k)^2 - n + 1 + k) = \frac{1}{2} ((n - 1)^2 - (n - 1)) - k (n - 1 - k).$$

很容易看出，如果$n$为奇数，则该表达式的最小值在$k = (n - 1)/2$处实现；如果$n$为偶数，则在$k = n/2$或$k = n/2 - 1$处实现，并且分别等于$(n - 1)(n - 3)/4$和$(n - 2)^2/4$。

请注意，箭头始终可以排列，以便指定的“最佳”数量的箭头从每个点出来。事实上，让我们想象点 $A_1$, ..., $A_n$ 形成一个规则的 $n$ 边形，并在其侧面和对角线上放置箭头（不穿过其中心），以便它们指定围绕中心的相同方向；在穿过中心的对角线上（偶数只有$n$），箭头可以任意放置。那么进入每个顶点的箭头数量与离开该顶点的箭头数量相差不超过 1。

因此，奇数 $n$ 的有向三角形的最多数量是

$$\frac{n(n - 1)(n - 2)}{6} - \frac{n}{2} \cdot \frac{(n - 1)(n - 3)}{4} = \frac{n(n^2 - 1)}{24},$$

甚至对于 $n$

$$\frac{n(n - 1)(n - 2)}{6} - \frac{n}{2} \cdot \frac{(n - 2)^2}{4} = \frac{n(n^2 - 4)}{24}.$$

这是另一个解决方案的草图。令 $k_i$ 为从点 $A_i$ 发出的箭头数量，则无向三角形的数量等于总和

$$\frac{k_1(k_1 - 1)}{2} + \dots + \frac{k_n(k_n - 1)}{2} = \frac{k_1^2 + \dots + k_n^2}{2} - \frac{n(n - 1)}{4}$$

（所有箭头的数量为$k_1 + \dots + k_n = n(n - 1)/2$）。如果对于某种箭头$k_i \geq k_j + 2$的排列，每个箭头都有两个点，那么你可以改变（最多两个）箭头的方向，使得$k_i$减少，$k_j$增加1；在这种情况下，平方和 $k_1^2 + \dots + k_n^2$ 将减少。因此，对于所有$i, j$的箭头$|k_i - k_j| \leq 1$的“子弹”排列，以及对于所有$i$的$k_i = (n - 1)/2$或$k_i = ((n - 1) \pm 1)/2$（取决于$n$的奇偶性），从这里很容易使用（*）得到答案。
