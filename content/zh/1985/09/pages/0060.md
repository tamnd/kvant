⟦folio 58⟧

锻炼
周年纪念日
莫斯科市
数学的
奥运会

今年莫斯科数学奥林匹克竞赛已举办第48届； 700多名小学生参加了活动。虽然数字并不“圆”，但本届奥运会可以理所当然地被视为周年纪念——第一届奥运会恰好是在 50 年前举办的。 1985年奥林匹克运动会最后一轮于3月24日在莫斯科大学举行。我们提出了那里提出的任务。

七年级
1. 找到$x$和$y$满足等式的所有值
$$xy + 1 = x + y.$$
2. 给定五个不同的正数，可以将其分为两组，使得这些组中的数之和相同。有多少种方法可以做到这一点？
3. 四个线段的长度$a, b, c, d$满足不等式$0 < a \leq b \leq c < d, d < a + b + c$。是否可以用这些线段拼成一个梯形？
4. 广场中央有一只扎特，四个角各有一只狼。如果狼只能以 zac 最大速度的 1.4 倍的最大速度沿着方格的边跑，那么 zac 能跑出方格吗？
5. 一个牛奶罐被带到了马塔津。卖家有所有没有重量的东西（你可以在秤的侧面放烧瓶），还有三个相同的烧瓶，其中两个是空的，第三个装有1升牛奶。如何将 85 升牛奶倒入一个烧瓶中而不需要称重？
八年级
1. 找到$x, y$和$z$满足等式的所有值
$$(x - y + z)^2 = x^2 - y^2 + z^2.$$
2. 数字 $a_1, a_2, \dots, a_{1985}$ 代表数字 1, 2, ..., 1985 按某种顺序重新排列。每个数字$a_k$乘以它的数字$k$，然后在获得的所有1985个产品中选择最大的一个。证明它不小于$993^2$。
3. 将一个纸方块放在一张纸上“放在笼子里”，其面积等于笼子面积的四倍。可以覆盖这个正方形的最少节点数是多少？ （节点是线性纸的交点；如果节点位于正方形的边界上，则认为它被覆盖。）
4. 切尔诺莫叔叔身后排着无数有钱人。证明他可以命令其中的一部分失败，从而使该行中剩下无限多个富人，并且它们都按高度顺序排列（不一定按高度降序排列）。

5. 证明如果三角形三等分线的长度都大于1，则其面积大于1/√3。

九年级
1. 找到$x, y$和$z$满足等式的所有值
$$\sqrt{x - y + z} = \sqrt{x} - \sqrt{y} + \sqrt{z}.$$
2. 一些国家有 1,985 个机场。一架飞机从他们每个人身上起飞，降落在发射场的一个飞机机场。难道1985年的所有飞机都停在了50个机场吗？ （地球可以认为是平的，路线是笔直的。）
3. 请参阅八年级问题 3。
4. 证明在任意 12 个人中你可以选择两个，并且在 10 个人中还剩下 5 个，因此这 5 个中的每一个都满足以下条件：要么他与所有一开始选择的人都是朋友，要么他与他们中的任何一个都不是朋友。
5. 证明任何数字$2^n$，其中$n=3, 4, 5, \dots$都可以表示为$2^n = 7x^2 + y^2$，其中$x$和$y$是奇数。

10年级
1. 解方程
$$\frac{x - 49}{50} + \frac{x - 50}{49} = \frac{49}{x - 50} + \frac{50}{x - 49}.$$
2. 请参阅七年级问题 3。
3. 让我们通过一个数字序列（如果有的话）的最短长度来定义给定数字的“复杂性”，该数字序列从零开始并以该数字结束，并且每个后续序列要么等于零$m/2^{50}$，其中$m=1, 3, 5, \dots, 2^{50}-1$，找到最“复杂性”的数字。
4. 数据 1985 个集合，每个集合由 45 个元素组成，任意两个集合的并集恰好包含 89 个元素。所有这些 1985 个集合的并集包含多少个元素？
5. 证明如果四面体交叉边之间的距离等于$h_1, h_2, h_3$，则四面体的体积不小于$h_1h_2h_3/3$。
