问题解决方案

M926 — M930; F938 — F942

用几何方法表示问题条件很方便。让我们在坐标平面$Oxy$上标记点$A(x; y)$和$B(u; v)$。角度 $AOB$ 是正确的，因为 $OA \cdot OB = xu + yv = 0$。另外，$OA^2 = x^2 + y^2 = 1$和$OB^2 = 1$，所以点$B$是由点$A$绕$O$旋转$\pm 90^\circ$（见图）和$x = \cos \alpha$、$y = \sin \alpha$得到，其中$\alpha$是向量之间的角度$OA$ 和轴$Ox$，即$u = \cos (\alpha \pm 90^\circ) = \pm \sin \alpha = \mp y$、$v = \sin (\alpha \pm 90^\circ) = \pm \cos \alpha = \pm x$。因此，

$$x^2 + u^2 = x^2 + y^2 = 1,$$
$$y^2 + v^2 = y^2 + x^2 = 1,$$
$$xy + uv = xy - xy = 0.$$

让我们再提出一种纯代数解。同样的动作

$$(x^2 + y^2 - 1)^2 + (u^2 + v^2 - 1)^2 + 2(xu + yv)^2 = x^4 + y^4 + u^4 + v^4 + 2 - 2(x^2 + y^2 + u^2 + v^2) + 2(x^2y^2 + u^2v^2 + x^2u^2 + y^2v^2) + 4xuyv = (x^2 + u^2 - 1)^2 + (y^2 + v^2 - 1)^2 + 2(xy + uv)^2$$

根据条件，左侧等于零；因此，右边也等于0，也就是说，所证明的三个等式都成立。

尝试将我们的问题推广到三维情况 - 证明如果空间中坐标为 $(x_1; x_2; x_3)$、$(y_1; y_2; y_3)$、$(z_1; z_2; z_3)$ 的三个长度为 1 的向量成对垂直，则向量 $(x_1; y_1; z_1)$、$(x_2; y_2; z_2)$ 和 $(x_3; y_3; z_3)$ 的长度也为 1 并且成对垂直。
