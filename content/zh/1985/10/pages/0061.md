14. $\sqrt{2164} \approx 46,52$。笔记。考虑平行六面体发展过程中连接$E$到$F$的路径。比较路径$|EF_1|, |EF_2|, |EF_3|, |EF_4|$就足够了（图7；我们可以假设侧面和包含$E$的正方形的展开是固定的，并考虑剩余正方形的展开的四种选择）。根据毕达哥拉斯定理，很容易计算出$|EF_1| = |EF_3| = \sqrt{46^2 + 14^2} = \sqrt{2312}; |EF_4| = \sqrt{42^2 + 20^2} = \sqrt{2164}$。此外，很多时候$|EF_2| = 50$。

15. $x = c$，其中$c$是$a$和$b$中的较小者。解决方案。让我们用$y^4$表示$a - x$，用$z^4$表示$b - x$，然后用$a + b - 2x = y^4 + z^4$表示。此后，方程写为$y + z = \sqrt[4]{y^4 + z^4}$。我们将等式两边分别求四次方；变换后我们得到方程$yz(2y^2 + 3yz + 2z^2) = 0$，从中可以得到$z = 0$，或者$y = 0$，或者$2y^2 + 3yz + 2z^2 = 0$。有了$z \neq 0$，方程$2y^2 + 3yz + 2z^2 = 0$可以写成$2\left(\frac{y}{z}\right)^2 + 3\left(\frac{y}{z}\right) + 2 = 0$。所得二次方程（相对于变量 $\frac{y}{z}$）无解。所以，要么是$y = 0$，从$x = a$，要么是$z = 0$，从$x = b$：检查表明，只有获得的两个值中较小的一个是合适的。
