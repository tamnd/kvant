让我们重复振动

A·R·齐伯曼

振荡发生在脱离稳定平衡状态的系统中。在许多实际的重要情况下，如果返回平衡位置的力与混合线性相关，则获得简谐振动。通常，当平衡受到轻微干扰时，这些都是“小”波动。

最简单的例子是数学矩阵在与垂直方向有小角度偏离的情况下的振荡。又如在没有其他力的情况下，负载在弹簧弹力的作用下发生振荡。有趣的是，即使振动不小，结果也是谐波的 - 只要弹簧遵守条件（胡克定律）$F=-kx$，其中$x$是弹簧的伸长量（负载从平衡位置的位移），$k$是弹簧的刚度，$F$是弹簧的弹力。

让我们更详细地看看这个例子。将质量块连接到水平弹簧上，水平弹簧的第二端固定，并放置在光滑的水平表面上。载荷的牛顿第二定律方程具有以下形式

$$mx''=-kx,$$

或者

$$x''+\frac{k}{m}x=0$$

(1)

（这里$m$是负载的质量，$x''$是其加速度，更准确地说，是加速度在水平轴$X$上的投影）。该方程的解是函数

$$x=x_m \cos(\sqrt{\frac{k}{m}}t+\varphi_0)=$$

$$=x_m \cos(\omega_0 t+\varphi_0),$$

(2)

其中 $x_m$ 是振幅，$\omega_0=\sqrt{k/m}$ 是固有频率，$\varphi_0$ 是振荡的初始相位。频率由振荡系统$(k$和$m)$的参数决定，振幅和初始相位取决于系统脱离平衡的精确程度，即时间$t_0=0$的初始时刻确定：

$$x_0=x(t_0)=x_m \cos(\sqrt{\frac{k}{m}}t+\varphi_0)=$$

$$=x_m \cos \varphi_0,$$

$$v_0=v(t_0)=x'(t_0)=$$

$$=-x_m \sqrt{\frac{k}{m}} \sin(\sqrt{\frac{k}{m}}t_0+\varphi_0)=$$

$$=-x_m \sqrt{\frac{k}{m}} \sin \varphi_0.$$

将第二个方程除以第一个方程，我们得到 $\varphi_0$：

$$tg \varphi_0=-\sqrt{\frac{m}{k}} \frac{v_0}{x_0}, \varphi_0=\arctg\left(-\sqrt{\frac{m}{k}} \frac{v_0}{x_0}\right).$$

找到值 $x_m$ 的最简单方法是使用平方和相加等式的常用方法排除三角函数：

$$x_0^2+\frac{m}{k}v_0^2=x_m^2, \quad x_m=\sqrt{x_0^2+\frac{m}{k}v_0^2}.$$

您可以将坐标$x(t_1)$和$x(t_2)$设置为“方便”的时刻$t_1$和$t_2$，或者速度$v(t_1)$和$v(t_2)$，或者坐标$x(t_1)$和速度$v(t_2)$等。唯一重要的是时刻$t_1$和$t_2$没有分开整数个半周期。

因此，知道系统的运动方程（方程（2））和两个附加数据，我们将完整地描述运动。例如，对于亲重力加速运动，也可以这样说——通过确定力来加速，再加上初始坐标和速度，这使我们能够绝对了解有关此类运动的一切。

在许多振动问题中都可以得到类似于方程（1）的方程——您只需要选择正确的变量即可。让我们用室外负载问题的几个条件来说明这一点。

任务 1. 负载 - 质量为 $M$ 的秤杯 - 增加了外部刚度 $k$，当将质量为 $m$ 的重物放入秤盘中时，会发生振动（它在撞击前经过路径 $h$ 并粘附在秤盘上）。描述杯子的运动。

让我们指向坐标轴$X$，并选择坐标原点0，如图1所示。考虑到一开始杯子处于平衡状态，我们写

$$Mg - k(l - l_0) = 0$$

（$l$是带悬杯的弹簧长度，$l_0$是不带悬杯的弹簧长度）。当偏离初始位置$x$时，当重物已粘在杯子上时，系统的运动方程为：

$$(M + m)g - k(l - l_0 + x) = (M + m)x''.$$

打开括号并考虑第一个方程，我们得到

$$x'' + \frac{k}{M + m}x = \frac{mg}{M + m}.$$

该方程与方程（1）非常相似，只是右侧部分发生干扰——它不等于0。发生这种情况的原因很清楚：我们将坐标原点放在了错误的位置，因为较重的杯子的平衡位置向下移动了距离$\Delta x = mg/k$。如果我们引入一个新变量

$$x_1 = x - \Delta x = x - \frac{mg}{k},$$

那么 $x_1$ 的方程几乎与 (1) 相同：

$$x_1'' + \frac{k}{M + m}x_1 = 0$$

（回想一下，通过这样的变量更改，$x_1$ 中的任意变量与 $x$ 中的任意变量都相同）。

系统谐波振荡的频率也可以从能量信息中找到。让我们使用理想振荡电路（无损耗）的示例来展示这一点。

让我们用 $q_m$ 表示最大负载（负载振荡幅度），用 $I_m$ 表示通过线圈的最大电流（电流振荡幅度）。电流是板在时间上的第一个任意负载，因此对于谐波振荡，该关系是有效的

$$I_m = q_m\omega_0.$$

当负载最大（$q = q_m$）时，电流为零，在$i = I_m$时，负载消失为零。让我们找到指定时间的电路能量并将它们相等：

$$\frac{q_m^2}{2C} = \frac{LI_m^2}{2},$$

或$$\frac{q_m^2}{2C} = \frac{Lq_m^2\omega_0^2}{2},$$

其中$C$是连续器的电容，$L$是线圈的电感。从这里

$$\omega_0 = \frac{1}{\sqrt{LC}}.$$

设块轴从平衡位置向下的最大位移为$x_m$，则系统在极限位置的总能量

$$W_1 = \frac{k(l-l_0+x_m)^2}{2} - Mgx_m - mg(2x_m).$$

表示木块轴经过$v_m$平衡位置时的速度，我们找到此时系统总能量的表达式：

$$W_2 = \frac{k(l-l_0)^2}{2} + \frac{1}{2} Mv_m^2 + \frac{1}{2} m(2v_m)^2.$$

对于本例中的简谐振动$v_m = x_m\omega_0$。因此，将能量$W_1$和$W_2$相等，经过简单变换我们得到

$$\frac{kx_m^2}{2} = \frac{Mx_m^2\omega_0^2}{2} + 2mx_m^2\omega_0^2,$$

在哪里

$$\omega_0 = \sqrt{\frac{k}{M+4m}}.$$

这个问题可以通过块中质量的不同分布来解决；为此，您只需将其旋转能量添加到块的平移运动能量中即可。例如，如果质量 $M$ 不集中在轴上，而是沿着以轴为中心、半径为 $r$ 的圆分布，则总动能

$$W_k = \frac{Mv^2}{2} + \frac{M(vr/R)^2}{2},$$

其中 $R$ 是块的半径。

有时，在明显不振荡的问题中会出现“振荡”方程。让我们看一个例子。

任务 4. 长度为 $l$ 的薄单荚块首先沿着 Eladian 水平台滑动，然后落在摩擦系数为 $u$ 的粗糙区域上。方块停在了一半，已经腐烂了。求木块的初速度和制动时间。

假设粗糙表面上有长度为 $x < l/2$ 的块的一部分。假设法向反作用力沿块均匀分布，我们求出摩擦力：

$$F_{\text{тр}} = -\mu mg \frac{x}{l}$$

和木块的加速度：

$$a = x'' = \frac{F_{\text{тр}}}{m} = -\mu g \frac{x}{l}.$$

我们得到了一个熟悉的方程

$$x'' + \frac{\mu g}{l} x = 0.$$

制动从$x=0$时刻开始，到速度$v=0$结束，正好对应“振荡”周期的四分之一；因此制动时间

$$\tau = \frac{1}{4} T = \frac{1}{4} \frac{2\pi}{\omega_0} = \frac{\pi}{2} \sqrt{\frac{l}{\mu g}}.$$

当然，不会有真正的振荡——停止后木块不会被推回（在没有滑动的情况下，特雷米亚的力将降至零）。

现在很容易写出坐标 $x$ 的表达式：

$$x = \frac{l}{2} \sin \sqrt{\frac{\mu g}{l}} t \quad (\text{при } 0 \leq t \leq \tau)$$

对于速度$v$：

$$v = x' = \frac{l}{2} \sqrt{\frac{\mu g}{l}} \cos \sqrt{\frac{\mu g}{l}} t$$

（在$0 \leq t \leq \tau$）。

从这里我们找到初始速度

$$v = v (t=0) = \frac{1}{2} \sqrt{\mu g l}.$$

可以通过提高速度来完成此任务，以便将整个块切割到工作台的粗糙部分上 - 然后在“谐波”制动之后，将发生正常制动。诀窍在于，现在“谐波”部分将不再占据周期的四分之一，而是更少。自己计算$v_0 = 2\sqrt{\mu g l}$处的制动时间（答案在第59页给出）。
