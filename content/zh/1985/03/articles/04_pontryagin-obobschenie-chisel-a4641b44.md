§6. 弗罗贝努斯定理

令 $L$ 为一组特定的量$x$，写成以下形式

$$x = x_0 + x_1 i_1 + x_2 i_2 + \dots + x_n i_n,$$

其中$x_0, x_1, x_2, \dots, x_n$是实数（值$x$的坐标），符号

$$i_1, i_2, \dots, i_n$$

称为最小单位。

$L$ 一起定义加法和乘法。令 $y$ 为聚合 $L$ 的其他值

$$y = y_0 + y_1 i_1 + \dots + y_n i_n.$$

当且仅当它们的坐标相等时，量 $x$ 和 $y$ 才被认为是相等的，即等式成立

$$x_0 = y_0, x_1 = y_1, \dots, x_n = y.$$

数量 $x$ 和 $y$ 的相加根据规则进行

$$x + y = (x_0 + y_0) + (x_1 + y_1) i_1 + \dots + (x_n + y_n) i_n.$$

因此，从 $L$ 开始的量按坐标相加。 $L$ 中的值也可以乘以任何实数，也是坐标方面的：

$$\lambda x = \lambda x_0 + (\lambda x_1) i_1 + \dots + (\lambda x_n) i_n.$$
