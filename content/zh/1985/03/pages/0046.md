⟦folio 44⟧

考虑到$x \neq 0$，我们得到依赖$a=f(x)$，它在每个要排序的区间上都有不同的相似表达式：

$$a = (-2x - 6)/x^2 = f_1(x) \text{ при } x < -1 \text{ и } a = (2x - 2)/x^2 = f_2(x) \text{ при } x \geq -1.$$

让我们在坐标系 $xOa$ (图 2) 中绘制这种依赖性。函数$f_1(x)$和$f_2(x)$的图形分别是“实心”蓝色和红色曲线。这些线的并集就是 $a=f(x)$ 图。 （蓝色和红色虚线是绘制间隔之外的依赖关系 $f_1(x)$ 和 $f_2(x)$ 的图形。选择解时可以在下面找到这些虚线。）蓝色和红色曲线在坐标 $(-1; -4)$ 的点处相交。

对函数$f_1(x)$和$f_2(x)$的检查表明（也可以在图2中看到）$\max f_1(x) = f_1(-6) = \frac{1}{6}$和$\max f_2(x) = f_2(2) = \frac{1}{2}$。

平行于$Ox$轴的直线与实线相交点的横坐标是方程（5）的解。

根据给定的 图 和上面的注释，可以得出方程（5）有：

a) 对于$a \in ]-\infty; -4]$，有两个解：$x_{1,2} = (1 \pm \sqrt{1-2a})/a$，由方程确定

$$ax^2 - 2x + 2 = 0.$$

6) 在 $a \in ]-4; 0[$ 有两个解：$x_1 = (-1 + \sqrt{1-6a})/a$ 和 $x_2 = (1 - \sqrt{1-2a})/a$
