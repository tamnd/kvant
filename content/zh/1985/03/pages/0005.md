在下一篇中。在 m 维向量空间中，任何 k 个向量的系统（其中 k > m）都是线性相关的。

现在让我们继续弗罗贝努斯定理证明的准备部分。包含在量集合 L 中的量，如果只有其坐标$x_0$不为零，其余都等于 0，则被认为是实数。让我们从L中选择满足以下条件的z值：$z^2$是一个非正实数，即它要么是负数，要么等于0。我们用 I 来表示这些量的集合。请注意，实数集合 R 和集合 I 只有一个共同元素 - 零。

现在让我们证明以下事实：

L 的每个值 x 可以表示为和

$$x = a + z, \quad a \in \mathbb{R}, \quad z \in I$$

以一种独特的方式。

为了证明这个说法，让我们创建一个值序列 x，从零开始到 n+1。由于序列 (60) 包含 n+2 个量，并且向量空间 L 的维数等于 n+1，因此量 (60) 是线性相关的。这意味着存在某个变量u的实系数多项式f(u)，其根为x，即满足条件

$$f(x) = 0.$$

由于 x 是多项式 f(u) 的根，因此数字 x 将是具有一阶或二阶实数系数的不可约多项式的根，如第 5 节末尾所证明的那样。如果该不可约多项式是一阶，即 u - a 形式，其中 a 是实数，则 x - a = 0，因此 x 是实数 a。如果不可约多项式 q(u) 具有二次且其根不是实数，那么它可以很容易地变换为以下形式

$$q(u) = (u-a)^2 + b,$$

其中 b 是正数。由于 x 是该多项式的根，因此 (x-a)^2=-b 并且 x 写成以下形式

$$x = a + z,$$

其中 a 是实数，z ∈ I，或 z^2=-b。至此，式(59)得证。

现在让我们证明展开式(59)中的项a和z是由数量x唯一确定的。在 x 是实数的情况下，这一说法很容易得到验证，因为此时 z=x-a，并且 R 和 I 只有一个共同元素 - 零，因此 z 为零。让我们假设，如果我们违反展开式（59），则会发生另一次展开：

赫尔曼·格拉斯曼（Hermann Grassmann，1809-1877 年），德国数学家、物理学家和语言学家，矢量空间一般概念和（与 A. Cayley 和 Y. Hamilton）四元数理论的创建者。

$$x = a_0 + z_0.$$

我们已经讨论过 z 或 z₀ 之一等于零的情况。在下文中，我们将假设它们都是非零的。对应（59）和（63）意味着相等

$$z = z_0 + (a_0 - a).$$

通过平方提高这个对应关系，我们得到

$$z^2 = z_0^2 + 2z_0(a_0 - a) + (a_0 - a)^2.$$

由于 z² 和 z₀² 是实数，因此从该对应关系可以得出乘积 z₀(a₀ - a) 是实数。由于 z₀ 不为零，因此只有当 a₀—a=0 时才有可能。由此，唯一展开式(59)成立。

请注意，对于集合 I 中的任何元素 z，它包括该元素与任何实数的乘积。除了元素 z≠0 之外，I 还包括与 z 相反的元素 z⁻1。让我们把它写成公式的形式：

$$\text{При } a \in \mathbb{R}, \quad z \in I \quad \text{имеем } az \in I.$$

$$\text{При } 0 \neq z \in I \quad \text{имеем } z^{-1} \in I.$$
