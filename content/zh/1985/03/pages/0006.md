$$\text{При } a \in \mathbb{R}, b \in \mathbb{R}; u \in I, v \in I \text{ имеем } au + bv \in I. \tag{67}$$

为了证明最后一个命题，我们考虑$a$和$b$不等于0的情况就足够了，因为这些数字中至少有一个等于0的情况包含在已经证明的命题（65）中。通过展开式 (59) 我们有

$$au + bv = z_1 + a_1, \text{ где } z_1 \in I, a_1 \in \mathbb{R}. \tag{68}$$

让我们平方对应关系（68）。然后我们会得到

$$a^2u^2 + b^2v^2 + ab(uv + vu) = 2a_1z_1 + a_1^2 + z_1^2. \tag{69}$$

通过展开式 (59) 我们有

$$uv + vu = z_0 + a_0, \text{ где } z_0 \in I, a_0 \in \mathbb{R}. \tag{70}$$

这里的值$z_0$和$a_0$不依赖于数字$a$和$b$，而只依赖于$u$和$v$。由于展开式（59）的唯一性，从（68）和（70）得出等式

$$abz_0 = 2a_1z_1. \tag{71}$$

并且由于数字 $a$ 和 $b$ 都被假定为非零。我们得到

$$z_0 = \frac{2a_1}{ab}z_1. \tag{72}$$

从最后一个等式可以得出，如果$z_0 \neq 0$，则$a_1 \neq 0$。 (73)

此外，$a_1 \neq 0$对于$a$和$b$的任何值，因为$z_0$不依赖于$a$和$b$。考虑到最后一个等式，我们可以将对应关系（68）重写为以下形式：

$$au + bv = cz_0 + d, \tag{74}$$

其中 $c = ab/(2a_1)$ 是非零实数。现在让我们选择两个数字$a'$和$b'$，与$a$和$b$不成比例，也就是说，不相等

$$\frac{a}{a'} = \frac{b}{b'}. \tag{75}$$

那么，根据已经证明的，我们有

$$a'u + b'v = c'z + d', \tag{76}$$

其中数字 $c'$ 不等于零。现在让我们从对应关系 (74) 中减去对应关系 (76)，再乘以实数 $a$，从而使等式 $c - ac' = 0$ 成立。然后我们就会有

$$a''u + b''v = d'', \tag{77}$$

其中 $a''$、$b''$ 和 $d''$ 是实数。或者，换句话说，

$$a''u = -b''v + d''. \tag{78}$$

由于这个等式的左侧属于$I$，因此这个等式的右侧必须包含来自$I$的元素（由于分解（59）的唯一性），即$d'' = 0$。我们得出的结论是向量$u$和$v$彼此成正比。对于这种情况，我们的陈述（67）至关重要。至此，命题(67)得证。
