⟦folio 40⟧

M898*。对于奇自然数$a < b < c < d$，以下条件成立：$ad = bc$、$a + d = 2^k$和$b + c = 2^m$，其中$k$和$m$是非环面自然数。证明$a) a = 1$；
b) 对于每个$m \geqslant 3$，有且只有一组数字$a, b, c, d, k$ 满足这些条件。

◆
a) 让我们首先确定$k > m$。根据数据，只有一组数字 $a, b, c, d, k$ 满足这些条件。

$$2^k - 2^m = a + d - (b + c) = a - b + d - \frac{ad}{b} = \frac{d}{b} (b - a) - (b - a) = (b - a) \left( \frac{d}{b} - 1 \right) > 0$$

（从$b > a$，$d > b$），因此$k > m$。

现在让我们证明$a + b = 2^{m-1}$。等式$ad = bc$可以重写为$a(2^k - a) = b(2^m - b)$，即$b^2 - a^2 = 2^m b - 2^k a = 2^m (b - 2^{k-m} a)$。因此，$b + a$和$b - a$的乘积可以被$2^m$整除（我们看到$2^{k-m}$是一个整数）。同时，它们的和是$2b$，而$b$是奇数，所以它们不能同时被4整除。由于这些数字是偶数，其中一个必须能被 $2^{m-1}$整除（而另一个只能被 $2^1$整除）。但是$b - a < b < (b + c)/2 = 2^{m-1}$，因此$a + b$可以被$2^{m-1}$整除。考虑到不等式$a + b < b + c = 2^m$，我们得出结论$a + b = 2^{m-1}$。

因此，$b = 2^{m-1} - a$ 是$c = 2^m - b = 2^{m-1} + a$，$ad = bc = 2^{2m-2} - a^2$ 因此是$a(a + d) = 2^{2m-2}$。由于 $a$ 是奇数，因此最后的等式仅适用于 $a = 1$。

b) 根据a)点末尾获得的结果，当且仅当对于$m \geqslant 3$有$a = 1$、$b = 2^{m-1} - 1$、$c = 2^{m-1} + 1$、$d = 2^{2m-2} - 1$、$k = 2m - 2$时，数字$a, b, c, d$和$k$满足问题的条件。
