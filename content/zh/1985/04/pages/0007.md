根式的近似计算

在根式的近似计算中，我们将区分“好”情况和“坏”情况。在“好”的情况下，平方根符号下面有一个与完美平方略有不同的数字；计算出的数字$\lambda$具有$\sqrt{a^2 + a^2}$的形式，其中$a$比$a^2$小。为了说明这种情况，请考虑以下示例。

示例 3. 让我们找到根 $\lambda = \sqrt{99}$ 值的近似值。

让我们将 $\lambda$ 表示为
$$\lambda = \sqrt{100-1} = 10\sqrt{1-0,01}$$
并考虑函数 $r(x) = \sqrt{1+x}$ 使得$\lambda = 10r(-0,01)$。让我们假设对于小 $x$ 有一个近似公式
$$r(x) = a + bx + cx^2 + o(x^2).$$

(3) 求$a, b$和$c$。首先，将$x$归零，得到：$a = 1$。现在让等式 (3) 两边都平方：
$$1 + x = a^2 + 2abx + (b^2 + 2ac)x^2 + o(x^2).$$

将最后一个等式两边相同幂$x$的系数相等，我们得到$a^2 = 1; 2ab = 1; b^2 + 2ac = 0$。考虑到$a = 1$，我们发现：$b = 1/2; c = -1/8$。所以，
$$\sqrt{1+x} = 1 + \frac{1}{2}x - \frac{1}{8}x^2 + o(x^2).$$

(4) 因此，
$$\lambda = 10r(-0,01) \approx 10(1-0,005 - 0,0000125) = 10(0,9949875) = 9,949875.$$

示例 4. 让我们找到根 $\mu = \sqrt{2}$ 值的近似值。

显然，我们发现的公式（4）对于$x = 1$给出了$\sqrt{2}$，完全不适合计算根，因为$x$并不小，我们无法计算出（4）右边的项快速减少。为了做出“好”的情况，我们选择两个比例为 2 的完整正方形。例如，这些正方形是 25 和 49。然后
$$\mu = \sqrt{2} = \frac{7}{5} \sqrt{\frac{50}{49}} = \frac{7}{5} v.$$
$v$ 的计算已经是一个“好的”情况，因为根号下有一个接近 1 的数字（完全平方数）。我们将 $v$ 写为：
$$v = (1-0,02)^{-\frac{1}{2}}$$
并考虑函数$S(x) = 1/\sqrt{1+x}$。然后$v = S(-0,02)$。让我们再次假设有一个如下形式的公式
$$S(x) = a + bx + cx^2 + o(x^2).$$
将$x$指向零，我们得到$a = 1$。我们将两边平方并乘以分母，
$$1 = (1+x)(a^2 + 2abx + (b^2 + 2ac)x^2 + o(x^2)),$$
$$1 = a^2 + (a^2 + 2ab)x + (b^2 + 2ab + 2ac) \times x^2 + o(x^2).$$
我们将最后一个等式两边相同幂$x$的系数相等，我们得到$a^2 = 1, a^2 + 2ab = 0, b^2 + 2ab + 2ac = 0$。考虑到$a = 1$，我们发现：$b = -1/2; c = 3/8$。所以，
$$\frac{1}{\sqrt{1+x}} = 1 - \frac{1}{2}x + \frac{3}{8}x^2 + o(x^2).$$

因此，
$$\mu = \sqrt{2} = (7/5)S(-0,02) \approx 1,4(1+0,01+0,00015) = 1,41421.$$
