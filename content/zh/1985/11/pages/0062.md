7. 让我们用 $(a_n, b_n, c_n, d_n)$ 表示 $(a, b, c, d)$ 按下 $n$ 按钮所产生的四次计数。请注意，在所有四个数字中，除了原始数字之外，所有四个数字的总和都等于零。令 $(a, b, c, d)$ 为任意四乘四和。然后
$$0 = (a + b + c + d)^2 = a^2 + b^2 + c^2 + d^2 + 2ab + 2ac + 2ad + 2bc + 2bd + 2cd.$$
现在让我们考虑通过按下按钮从中获得的四四$(a_1, b_1, c_1, d_1)$。为了她
$$a_1^2 + b_1^2 + c_1^2 + d_1^2 = (a - b)^2 + (b - c)^2 + (c - d)^2 + (d - a)^2 = 2(a^2 + b^2 + c^2 + d^2) - 2ab - 2bc - 2cd - 2ad = 3(a^2 + b^2 + c^2 + d^2) - 2ac - 2bd$$
并且，从$2ac \leqslant a^2 + c^2$和$2bd \leqslant b^2 + d^2$开始，
$$a_1^2 + b_1^2 + c_1^2 + d_1^2 \geqslant 2(a^2 + b^2 + c^2 + d^2).$$
在原来的四个中，$(x, y, z, t)$之和并不全部相等，因此$x_1^2 + y_1^2 + z_1^2 + t_1^2 > 0$。由于上面已经证明了
$$x_n^2 + y_n^2 + z_n^2 + t_n^2 \geqslant 2^{n-1}(x_1^2 + y_1^2 + z_1^2 + t_1^2).$$
由此可见，存在这样一个足够大的数$n$的四和，其中一个数的模数大于3·1985。如果这个数字是负数，那么在同一个四和中也会有一个大于 1985 的正数，因为其中所有数字的总和等于零。
