10年级

1. 解决不等式

$$|\sin x - \sin y| + \sin x \cdot \sin y \leq 0.$$

2. 在平面上画凸五边形ABCDE。我们构造点$A_1$，相对于点$B$与点$A$对称，点$B_1$，相对于$C$与点$B$对称，…，点$E_1$，相对于点$A$与点$E$对称，之后的对应关系五边形ABCDE。证明使用指南针和尺子，知道点 $A_1, B_1, C_1, D_1, E_1$ 的位置，可以重建五边形 ABCDE。

3. 序列$a_1, a_2, a_3, \dots$由以下规则给出：$n \geq 1$和$a_{4n+1} = 1$为$a_{2n} = a_n$，$n \geq 0$为$a_{4n+3} = 0$。证明这个数列没有周期。

4. 平面上有 $n$ 条直线 ($n > 2$)，将平面分为几个区域。其中一些区域是彩色的，没有两个彩色区域接触边界。证明彩色区域的数量不超过$(n^2 + n)/3$。

八年级

5. 有一个立方体，一个带有盖子的立方体盒子，尺寸相同，有六种颜色。立方体的每一面和盒子的一侧都漆成红色。证明可以将立方体放置在盒子中，使得立方体的每个面与盒子的不同颜色的面相邻。

6. 炸药$A_0A_5$将以$O$为中心的圆分成两个半圆。其中一根被分成五个相等的弧$A_0A_1, A_1A_2, A_2A_3, A_3A_4, A_4A_5$。线 $A_1A_4$ 与 $OA_2$ 和 $OA_3$ 相交于点 $M$ 和 $N$。证明线段$A_2A_3$和$MN$的长度之和等于圆的半径。

7. 学校数学社的学生制作了一台计算机，只需按一下按钮即可将四个数字（$a, b, c, d$）变成四个（$a - b, b - c, c - d, d - a$）。证明如果原始四元组中的所有数字并非都相等，则按下一定次数的按钮后将得到一个四元组，其中至少有一个数字大于 1985。

8. 数字 1, 2, 3, ..., $2n - 1$, $2n$ 分为两组 $n$ 数字。设$a_1 < a_2 < \dots < a_n$为第一组的数字，按升序排列，$b_1 > b_2 > \dots > b_n$为第二组的数字，按降序排列。证明

$$|a_1 - b_1| + |a_2 - b_2| + \dots + |a_n - b_n| = n^2.$$
