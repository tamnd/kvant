如果$k = k_A + k_B + k_C \leq 3n - 2$，那么对于三角形的某些两个顶点，例如$A$和$B$，这样的线段总数$k_A + k_B$不超过$2n - 2$。让我们丢弃这些点以及来自它们的所有线段（连同三角形 $ABC$ 的边）。我们得到一组由至少 $(n + 1)^2 + 1 - (2n - 2) - 3 = n^2 + 1$ 线段连接的点，根据电感提议，这些点形成至少 $n$ 三角形。

如果我们考虑的线段的$k \geq 3n - 1$和$k$形成边为$AB, BC$和$CA$的三角形，则$t \geq n$。事实上，让$2n + 2 - 3 = 2n - 1$与$A, B, C$不同的点中有$n_j$，使得$j$线段到达顶点$A, B, C$（$j = 0, 1, 2, 3$）。然后
$$n_1 + n_2 + n_3 \leq n_0 + n_1 + n_2 + n_3 = 2n - 1,$$
$$n_1 + 2n_2 + 3n_3 = k \geq 3n - 1,$$
跟随，$t = n_2 + 3n_3 \geq n_2 + 2n_3 \geq (3n - 1) - (2n - 1) \geq n$。

$$CD \leq C'D' < MN,$$
其中$C'D'$是线$CD$与$M_2$相交的线段，线段$C'D'$和$MN$的端点位于多边形$M_2$的两个相邻边上。
