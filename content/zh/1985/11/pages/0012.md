⟦folio 10⟧

正是这种基本的不等式使得惠更斯比阿基米德走得更远。

 下面我们将证明阿基米德和惠更斯的结果并考虑一些相关问题。

主要不等式的证明

我们将不等式(1)的证明分为几个步骤。我们将认为这个不等式的左侧是已知的，因此我们将仅证明第二个不等式的有效性。

1°。如果在圆 ACB 的某段扫描一个等边三角形 ABC，并在 A、B、C 点绘制圆的切线，如 图 4 所示，则

$$S_{ABC} < 2S_{KLM}.$$

(2) 有效，从对应关系$|KL| > |LC|$和$|LC| = |AL|$得出$|AK| < 2|KL|$。由于三角形 KLM 和 KAB 相似，因此它们的面积与对应边的平方成正比，因此确实有

$$S_{KAB} / S_{KLM} = |KA|^2 / |KL|^2 < 4,$$

从哪里$S_{KAB} < 4S_{KLM}$。

另一方面，等边三角形 KAB 和 ABC 有一个公共底 AB，因此它们的面积与它们的高度相关，或者（根据泰勒斯定理）与相应边的长度相关。因此，

$$\frac{S_{ABC}}{S_{KAB}} = \frac{|AL|}{|AK|},$$

并且，从$|AL| < (1/2)|AK|$开始，我们得到$S_{ABC} < (1/2)S_{KAB}$。

从这里和之前的面积不等式我们得到（2）。

2°。如果我们用$S_{cerm}$表示线段ACB的面积（见图4），那么

$$S_{cerm} \leq \frac{2}{3} S_{ABK}.$$

(3)

为了证明这个不等式，我们将使用以下消息。让我们分别用$S_0$和$A_0$表示三角形ABC和KLM的面积（参见图5）。现在让我们考虑弧 AC，用点 $C_1$ 将其分成两半，并以完全相同的方式构造面积 $S_2$ 和 $A_2$ 的三角形。点$C_3$——弧AC$^2$的中点——以类似的方式生成区域$S_3$和$A_3$的三角形。继续这个过程，我们得到两个正数序列$\{S_n\}$和$\{A_n\}$——对应三角形的面积。根据1°中的证明-见(2)，我们有：

$$S_0 < 2A_0, \quad S_1 < 2A_1, \quad S_2 < 2A_2, \quad S_3 < 2A_3, \dots, \quad S_n < 2A_n.$$

显然 (图6)

$$S_0 + 2S_1 + 2^2S_2 + 2^3S_3 + \dots + 2^nS_n + \dots = S_{cerm}$$
