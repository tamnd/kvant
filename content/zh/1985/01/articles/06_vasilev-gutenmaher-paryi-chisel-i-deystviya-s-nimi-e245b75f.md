N.V.瓦西里耶夫，

本文内容主要适合一年级学生阅读。但是，我们也推荐给高中生。本文讨论具有两个整数变量的方程的解。在这方面，考虑了数字对相乘的各种规则，包括复数的乘法。

1. 方程$ax - by = c$
整数
考虑方程
$$8x - 5y = 19.$$

以该方程为例，我们将演示一种求解 $ax - by = c$ 形式且整数 $a, b$ 和 $c$ 为整数的线性方程的方法。

由于$8 \cdot 3 - 5 \cdot 1 = 19$，数字对$x = 3, y = 1$是原方程的解。我们通过简单的选择找到了这个解决方案。

现在让我们展示如何在有了一个解决方案的情况下写下所有其他解决方案（它们的数量是无限的）。从方程$8x - 5y = 19$中减去等式$8 \cdot 3 - 5 \cdot 1 = 19$，我们得到$8(x - 3) - 5(y - 1) = 0$或$x - 3 = 5(y - 1)/8$。从最后一个等式可以清楚地看出，当且仅当$y - 1$能被8整除时，数字$x - 3$才是整数，即$y - 1 = 8n$，其中$n$是某个整数。将$y - 1 = 8n$代入分数$5(y - 1)/8$的分子并减去8，我们得到$x - 3 = 5n$。

因此，原方程的所有整数解都可以写成以下形式：

$$\begin{cases} x = 3 + 5n, \\ y = 1 + 8n, \end{cases}$$

或$(x/y) = \frac{3}{1} + n\frac{5}{8}$；

这里$n$是任意整数。

第二种类型的表示法将在下一段中详细解释，但现在我们注意到，相同的方法可以为任何方程 $ax - by = c$ 的所有整数解生成一个公式（其中 $a$ 和 $b$ 是互质数）：

$$(x/y) = \left( \frac{x_0}{y_0} \right) + n\left( \frac{b}{a} \right),$$

其中 $(x_0; y_0)$ 是其整数解之一。

为了解决下面提出的问题，必须牢记以下几点。如果整数$a$和$b$有公约数（1和-1除外），那么我们必须将所有整数方程除以它们的最大公约数。在$c$不能被它整除的情况下，方程显然没有完整的解，而在它可整除的情况下，则存在这样的解——你只需要选择一个解并使用公式（*）写出所有其他解。

对于任何数字$a$和$b$，有一种通用方法可以找到方程的一个解：该方法基于欧几里得算法（参见[1]和[5]）。

看起来很自然地引入乘法如下：

$$\binom{x_1}{y_1} \binom{x_2}{y_2} = \binom{x_1 x_2}{y_1 y_2}.$$

对于此类乘法，满足与数字乘法相同的所有属性：1) $uv = vu$，2) $u(vw) = (uv)w$，3) $(u + v)w = uw + vw$。 “一个”的角色是由很多$e = \binom{1}{1}$扮演的。

在文章的最后，我们将熟悉其他自然且更有意义的数字对相乘规则：

$$\binom{x_1}{y_1} \binom{x_2}{y_2} = \binom{x_1 x_2 - y_1 y_2}{x_1 y_2 + x_2 y_1}.$$

该规则是可替换的，因为它的逆运算（除以零）始终是可能的。

4. $p + q\sqrt{2}$ 形式的数字

让我们注意一个有趣的情况，即具有异质$p$和$q$形式的$p + q\sqrt{2}$形式的数字可以自然地与一对数字$(p; q)$相关联。此外，两个数 $p_1 + q_1\sqrt{2} = p_2 + q_2\sqrt{2}$ 相等当且仅当 $\binom{p_1}{q_1} = \binom{p_2}{q_2}$ 时发生。

事实上，令 $p_1 + q_1\sqrt{2} = p_2 + q_2\sqrt{2}$ 和 $q_1 \neq q_2$；那么事实证明 $\sqrt{2}$ 等于数字 $(p_1 - p_2)/(q_2 - q_1)$，但这是错误的。因此，等式$q_1 = q_2$一定成立；但从等式$p_1 + q_1\sqrt{2} = p_2 + q_2\sqrt{2}$我们立即得到$p_1 = p_2$。

数字$p_1 + q_1\sqrt{2}$和$p_2 + q_2\sqrt{2}$相加的规则与stolniki相同：
$$p_1 + q_1\sqrt{2} + (p_2 + q_2\sqrt{2}) = (p_1 + p_2) + (q_1 + q_2)\sqrt{2},$$
$$\binom{p_1}{q_1} + \binom{p_2}{q_2} = \binom{p_1 + p_2}{q_1 + q_2}.$$

现在变量数$p_1 + q_1\sqrt{2}$和$p_2 + q_2\sqrt{2}$：
$$p_1 + q_1\sqrt{2}(p_2 + q_2\sqrt{2}) = (p_1 + p_2) + (q_1 + q_2)\sqrt{2}.$$
结果，我们得到了相同形式的数字，并获得了有理复数 $p_1, q_1, p_2, q_2$ 的数字的新乘法规则：
$$\binom{p_1}{q_1}\binom{p_2}{q_2} = \binom{p_1 p_2 + 2 q_1 q_2}{p_1 q_2 + p_2 q_1}.$$

如果遵循这个规则，你可以将乘法 $x^2 - 2y^2 = 1$ 的解写成这样：
$$\binom{x_n}{y_n} = \binom{3}{2}^n$$（自己称量 stolnik $n$ 次）。

对于规则(3)，满足乘法的一般性质；这里 1 的角色由 stolnik $\binom{1}{0}$ 扮演，因为它对应于数字 $1 = 1 + 0\sqrt{2}$。

这些数字集合中一个有趣的对称性对数字$p + q\sqrt{2}$的运算有很大帮助：每个数字$a = p + q\sqrt{2}$对应于数字$\bar{a} = p - q\sqrt{2}$，这被称为与$a$的共轭。 （对于 stolniks，到共轭的转变只是第二个分量的符号 $y$ 的变化。）

配对操作具有以下属性：
$$\bar{a} + \bar{b} = \bar{a} + \bar{b}, \bar{a}\bar{b} = \bar{a}\bar{b}, \bar{a} = a.$$

但最重要的是共轭$(p + q\sqrt{2})(p - q\sqrt{2}) = p^2 - 2q^2$的乘积不再含有$\sqrt{2}$； $\bar{a}\bar{b}$是有理数。这允许您将 $p + q\sqrt{2}$ 形式的数字彼此相除，从而获得相同形式的数字。要将$\beta$除以$a$，只需将$\beta$乘以$\bar{a}$，然后将结果除以$\bar{a}\bar{b}$即可。

我们在求解乘法$x^2 - 2y^2 = 1$时已经使用了共轭数的参数。我们将左侧 $x^2 - 2y^2$ 表示为两个共轭数的乘积
$$a = x + y\sqrt{2}, \bar{a} = x - y\sqrt{2}.$$

现在让我们取两个数字$a = x_1 + y_1\sqrt{2}$和$\beta = x_2 + y_2\sqrt{2}$以及它们的共轭$\bar{a} = x_1 - y_1\sqrt{2}$和$\bar{b} = x_2 - y_2\sqrt{2}$。我们来看看产品$\alpha\bar{a}\beta\bar{b}$。按一定顺序执行计算 - 首先$\bar{a}\bar{b}$，然后$\beta\bar{b}$，然后$(\alpha\bar{a})(\beta\bar{b})$ - 我们得到：

5. Vieta 非凡的身份和成分

任意两对数字 $(a_1; b_1)$ 和 $(a_2; b_2)$ 通过丢番图已知的以下恒等式连接：
$$a_1^2 + b_1^2)(a_2^2 + b_2^2) = (a_1a_2 - b_1b_2)^2 + (a_1b_2 + a_2b_1)^2.$$

它由 $d = -1$ 的恒等式 (8) 获得，常用于代数和数论中。我们将在这里讨论它的另一个应用：一种有趣的方法，允许您从两个直角三角形获得一个新的直角三角形，其斜边等于它们斜边的乘积。

取一个由正方形 $a_1, b_1$ 和斜边 $c_1$ 组成的直角三角形，以及另一个由正方形 $a_2, b_2$ 和斜边 $c_2$ 组成的直角三角形。因为根据毕达哥拉斯定理
$$a_1^2 + b_1^2 = c_1^2$$ 和 $a_2^2 + b_2^2 = c_2^2,$
同样的事情（9）可以写成如下：
$$(c_1c_2)^2 = (a_1a_2 - b_1b_2)^2 + (a_1b_2 + a_2b_1)^2.$$

⟦folio 23⟧

从这个等式可以清楚地看出，存在一个由正方形 $|a_1a_2-b_1b_2|$、$a_1b_2+a_2b_1$ 和斜边 $c_1c_2$ 组成的直角三角形。显然，这是由法国数学家 Francois Viète 在 16 世纪首次注意到的（见[7]），所以我们将这种从两个直角三角形获得新直角三角形的方法称为“Viète 合成”。

让我们考虑两个相同的直角三角形，其正方形为$m, n$，并将$a_1=a_2=n$、$b_1=b_2=m$代入恒等式(9)。我们得到

$$(m^2+n^2)^2=(m^2-n^2)^2+(2mn)^2.$$

我们看到 Vieta 的组合产生了一个新的直角三角形，其中包含正方形 $|m^2-n^2|$、$2mn$ 和斜边 $m^2+n^2$。有趣的是，所有具有整数（互质）边 $a, b$、$c$ 的直角三角形 - 所谓的“毕达哥拉斯三元组” - 都可以使用这些公式获得

$$c=m^2+n^2, a=m^2-n^2, b=2mn, (10)$$

其中 $m$ 和 $n$ 是不同奇偶校验的（互质）自然数，$m>n$。

最重要的是，两个直角三角形的 Vieta 组合产生了一个新的直角三角形 (图 2)，其与正方形 $a_1b_2+a_2b_1$ 的角等于原三角形与正方形 $b_1$ 和 $b_2$ 的角 $\varphi$ 和 $\psi$ 之和 $\varphi+\psi$（如果$\varphi+\psi<90^\circ$；如果$\varphi+\psi>90^\circ$，那么这个角度等于$180^\circ-(\varphi+\psi)$）。因此，Vieta的构成可以被赋予一个几何数。两个直角三角形的维埃塔组合是斜边$c_1c_2$的直角三角形。显然，这是由法国数学家 Francois Viète 在 16 世纪首次注意到的（见[7]），所以我们将这种从两个直角三角形获得新直角三角形的方法称为“Viète 合成”。

让我们考虑两个相同的直角三角形，其正方形为$m, n$，并将$a_1=a_2=n$、$b_1=b_2=m$代入恒等式(9)。我们得到

$$(m^2+n^2)^2=(m^2-n^2)^2+(2mn)^2.$$

我们看到 Vieta 的组合产生了一个新的直角三角形，其中包含正方形 $|m^2-n^2|$、$2mn$ 和斜边 $m^2+n^2$。有趣的是，所有具有整数（互质）边 $a, b$、$c$ 的直角三角形 - 所谓的“毕达哥拉斯三元组” - 都可以使用这些公式获得

$$c=m^2+n^2, a=m^2-n^2, b=2mn, (10)$$

其中 $m$ 和 $n$ 是不同奇偶校验的（互质）自然数，$m>n$。

最重要的是，两个直角三角形的 Vieta 组合产生了一个新的直角三角形 (图 2)，其与正方形 $a_1b_2+a_2b_1$ 的角等于原三角形与正方形 $b_1$ 和 $b_2$ 的角 $\varphi$ 和 $\psi$ 之和 $\varphi+\psi$（如果$\varphi+\psi<90^\circ$；如果$\varphi+\psi>90^\circ$，那么这个角度等于$180^\circ-(\varphi+\psi)$）。因此，Vieta的构成可以被赋予一个几何数。 Vieta 由两个直角三角形组成的结果是顶点为 $a, b, c$ 的三角形的最新直线。

6. 复数$a+bi$

在前面的段落中，使用可见的数字$a+b\sqrt{d}$，我们得出恒等式（8），这对于任何$d$都是成立的。然后我们把恒等式$d=-1$放入其中；同时，表达式$a+b\sqrt{d}=a+b\sqrt{-1}$本身就失去了意义，因为数字中没有$\sqrt{-1}$——毕竟，任何数字的平方都是非负数。尽管如此，事实证明使用一个新的“最小”数字是明智的，其平方等于-1。它由字母 $i$ 表示（来自拉丁词 imaginary - 我的，想象的）。

$a+bi$ 形式的表达式称为复数，其中 $a$ 和 $b$ 是普通数。根据定义，两个复数相等当且仅当它们的分量相等：

⟦folio 24⟧

仅当 $a_1 = a_2$ 和 $b_1 = b_2$ 时，$a_1 + b_1 i = a_2 + b_2 i$。

复数的加法和乘法 $a + bi$ 其生成方式与生成以下形式的数字的方式相同 $a + b\sqrt{2}$ 与理性的 $a$ 和 $b$。然而，这里 $a$ 和 $b$ 可以是任何数字，并且 $i^2 = -1$。作为这些操作的结果，我们再次获得以下形式的表达式 $a + bi$:

$$(a_1 + b_1 i) + (a_2 + b_2 i) = (a_1 + a_2) + (b_1 + b_2) i,$$
$$(a_1 + b_1 i)(a_2 + b_2 i) = (a_1 a_2 - b_1 b_2) + (a_1 b_2 + a_2 b_1) i.$$

现在我们知道我们在第 2 段中指出的这么多乘法 (1) 是从哪里来的。这种乘法本质上已经在上一段中讨论过 - 作为 Vieta 的两个直角三角形的组合，其边为 $(a_1; b_1)$ 和 $(a_2; b_2)$。

零复数$0 = 0 + 0i$、单位$1 = 1 + 0i$和负单位$i = 0 + 1i$发挥着特殊作用。注意，如果复数$a + bi$的任意分量$a$或$b$等于0，则在写入时省略复数的相应部分。

在复数的世界里，我们可以除以零$0 = 0 + 0i$以外的任何数字。计算两个数字的商时，通过将数字 $c - di$ 与除法 $z = c + di$ 共轭来将这两个数字相乘是很方便的：

$$\frac{a + bi}{c + di} = \frac{(a + bi)(c - di)}{(c + di)(c - di)} = \left( \frac{ac + bd}{c^2 + d^2} \right) + \left( \frac{bc - ad}{c^2 + d^2} \right) i.$$

复数首先出现在代数中，解决三角形和高阶代数方程的问题。然而，复数的应用几乎涵盖了数学和物理的所有主要领域——几何、数论、数学分析和概率论、电学计算、流体动力学和量子力学。

我们获得复数作为实数对，通过规则（1）定义它们的乘法，满足自然条件 - 交换性、结合性、分配性。对于数学来说，对所有这些对进行分类的问题很有趣。事实证明，它们都符合通用方案：对$(x, y)$以“广义复数”的形式书写，计算中的$x + yj$和$j^2$被$r + sj (r, s$（固定数，见问题19）代替；这里可能存在三个本质上不同的仆人（其他仆人可以减少到这三个）：

$$(1) j^2 = 1$$

（我们详细研究的规则$j^2 = 2$就属于这种类型）； (2) $j^2 = 0$（奇怪的是，为列编写的相应乘法规则）：

$$\left( \frac{x_1}{y_1} \right) \left( \frac{x_2}{y_2} \right) = \left( \frac{x_1 x_2}{x_1 y_2 + x_2 y_1} \right)$$

是分数加法规则的逆转

$$\frac{y_1}{x_1} + \frac{y_2}{x_2} = \frac{y_1 x_2 + x_2 y_1}{x_1 x_2}$$

最后 (3) $j^2 = -1$ 是实复数。
