当且仅当它们的分量相等时，两个这么多才被认为是相等的：

$$\binom{x_1}{y_1} = \binom{x_2}{y_2},$$

仅当$\begin{cases} x_1 = x_2, \\ y_1 = y_2. \end{cases}$

添加两个这么多意味着添加它们的组件：

让$u = \binom{x_1}{y_1}, v = \binom{x_2}{y_2},$

然后$u + v = \binom{x_1 + x_2}{y_1 + y_2}$。

由于更改项的位置不会改变数字的总和：$a + b = b + a$，因此对于许多项也可以这样说：$u + v = v + u$。对于很多人来说，规则$(u + v) + w = u + (v + w)$也是正确的。

将多个 $u$ 乘以数字 $k$ 意味着将其两个分量乘以 $k$：

如果$u = \binom{x}{y},$则$ku = \binom{kx}{ky}$。

数字中的零$\binom{0}{0}$扮演着一种特殊的角色，类似于数字中的数字0所扮演的角色。如果这不会导致混淆，则也用“0”表示。对于 $u$ 的每个数，等式 $u + 0 = u$ 为真。

看起来很自然地引入乘法如下：

$$\binom{x_1}{y_1} \binom{x_2}{y_2} = \binom{x_1 x_2}{y_1 y_2}.$$

对于此类乘法，满足与数字乘法相同的所有属性：1) $uv = vu$，2) $u(vw) = (uv)w$，3) $(u + v)w = uw + vw$。 “一个”的角色是由很多$e = \binom{1}{1}$扮演的。

但与数字不同的是，除以零并不总是可能的。例如，如果$u = \binom{1}{0}$，则没有像$uv = e$那样多的$v$。

在文章的最后，我们将熟悉其他自然且更有意义的数字对相乘规则：

$$\binom{x_1}{y_1} \binom{x_2}{y_2} = \binom{x_1 x_2 - y_1 y_2}{x_1 y_2 + x_2 y_1}.$$

该规则是可替换的，因为它的逆运算（除以零）始终是可能的。
