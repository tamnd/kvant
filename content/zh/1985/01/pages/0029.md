缝制大于或小于 $I_1R_1$ 的作业。在本节中，电动势$\varepsilon_1$的电流源减小了电势差（内部外力做正功），因此我们可以写：

$$U_{AB} = \varphi_A - \varphi_B = I_1R_1 - \varepsilon_1.$$  (1)

在第 $BC$ 部分，一切都完全相同：

$$U_{BC} = \varphi_B - \varphi_C = I_2R_2 - \varepsilon_2.$$  (2)

在第$CD$部分的情况下，电流源与之前的源相比具有相反的极性，因此它不会减少，而是增加电势差（外部内力做负功）：

$$U_{CD} = \varphi_C - \varphi_D = I_3R_3 + \varepsilon_3.$$  (3)

在最后一节中，考虑了电路；根据我们的假设，电流从$A$点流向$D$点，读数与$AB$部分完全对应：

$$U_{AD} = I_4R_4 - \varepsilon_4,$$

或者，给定选定的遍历方向，

$$U_{DA} = \varphi_D - \varphi_A = -U_{AD} = -I_4R_4 + \varepsilon_4.$$  (4)

将等式(1)-(4)逐项相加，可得：

$$I_1R_1 + I_2R_2 + I_3R_3 - I_4R_4 = \varepsilon_1 + \varepsilon_2 - \varepsilon_3 - \varepsilon_4.$$  (5)

这个对应关系表达了​​基尔霍夫的第二条规则：对于任何闭合电路，给定方向的代数和等于电动势的代数和。

基尔霍夫规则没有表达电场的任何新特性，因此不能被视为物理定律。正如我们已经说过的，第一个是电荷守恒定律的结果，第二个是能量守恒定律的结果。然而，当分支电路中没有电流时，它们非常有用。

让我们回到图所示的图，并写下表达节点$A$、$B$、$C$、$F$和轮廓$ABCDA$、$AFDA$、$DFCD$的基尔霍夫规则的方程：

$$I_5 - I_1 - I_4 = 0,$$
$$I_1 - I_2 = 0,$$
$$I_2 - I_3 - I_6 = 0,$$

$$I_6 + I_7 - I_5 = 0,$$
$$I_1R_1 + I_2R_2 + I_3R_3 - I_4R_4 = \varepsilon_1 + \varepsilon_2 - \varepsilon_3 - \varepsilon_4,$$
$$-I_4R_4 - I_5R_5 - I_7R_7 = -\varepsilon_4,$$
$$I_7R_7 - I_6R_6 + I_3R_3 = -\varepsilon_3.$$  (6)

让我们再次注意写方程时加号或减号的选择。在电阻器方向下降之前，如果我们在本节中选择的电流方向与所选的旁路方向一致，则放置一个加号“plus”，否则放置一个加号“minus”。如果源在电路中产生的电流方向与绕过电路的方向一致，则源的电动势被视为“正”，反之则为“负”。

只有求解方程组后才能确定电流的真实方向：如果任何电流的结果值为正，则表明该电流的方向选择正确；反之，则表明该电流的方向选择正确。如果电流结果为负，则其真实方向与所选方向相反。

不难证明，通过应用基尔霍夫规则，总是可以获得与未知电流一样多的独立方程，即完全且明确地解决所提出的问题*)。

显微镜能做什么？

当制造“武装”眼睛的光学仪器时，自然会出现关于其最大能力的问题。例如，对于显微镜来说，这样的特性可以作为其通知。从几何光学的角度来看，与相应的目镜和物镜类似，显微镜可以做得尽可能大。然而，现实情况并非如此，其原因在于光的波动性。光线作为几何线性的想法就起作用了。

*) O. V. Lyashko 在本期杂志上发表的文章中给出了这一事实的详细数学证明。 （编者注）
