⟦folio 22⟧

数字$p_1 + q_1\sqrt{2}$和$p_2 + q_2\sqrt{2}$相加的规则与stolniki相同：
$$p_1 + q_1\sqrt{2} + (p_2 + q_2\sqrt{2}) = (p_1 + p_2) + (q_1 + q_2)\sqrt{2},$$
$$\binom{p_1}{q_1} + \binom{p_2}{q_2} = \binom{p_1 + p_2}{q_1 + q_2}.$$

现在变量数$p_1 + q_1\sqrt{2}$和$p_2 + q_2\sqrt{2}$：
$$p_1 + q_1\sqrt{2}(p_2 + q_2\sqrt{2}) = (p_1 + p_2) + (q_1 + q_2)\sqrt{2}.$$
结果，我们得到了相同形式的数字，并获得了有理复数 $p_1, q_1, p_2, q_2$ 的数字的新乘法规则：
$$\binom{p_1}{q_1}\binom{p_2}{q_2} = \binom{p_1 p_2 + 2 q_1 q_2}{p_1 q_2 + p_2 q_1}.$$

(3)

如果遵循这个规则，你可以将乘法 $x^2 - 2y^2 = 1$ 的解写成这样：
$$\binom{x_n}{y_n} = \binom{3}{2}^n$$（自己称量 stolnik $n$ 次）。

对于规则(3)，满足乘法的一般性质；这里 1 的角色由 stolnik $\binom{1}{0}$ 扮演，因为它对应于数字 $1 = 1 + 0\sqrt{2}$。

这些数字集合中一个有趣的对称性对数字$p + q\sqrt{2}$的运算有很大帮助：每个数字$a = p + q\sqrt{2}$对应于数字$\bar{a} = p - q\sqrt{2}$，这被称为与$a$的共轭。 （对于 stolniks，到共轭的转变只是第二个分量的符号 $y$ 的变化。）

配对操作具有以下属性：
$$\bar{a} + \bar{b} = \bar{a} + \bar{b}, \bar{a}\bar{b} = \bar{a}\bar{b}, \bar{a} = a.$$

但最重要的是共轭$(p + q\sqrt{2})(p - q\sqrt{2}) = p^2 - 2q^2$的乘积不再含有$\sqrt{2}$； $\bar{a}\bar{b}$是有理数。这允许您将 $p + q\sqrt{2}$ 形式的数字彼此相除，从而获得相同形式的数字。要将$\beta$除以$a$，只需将$\beta$乘以$\bar{a}$，然后将结果除以$\bar{a}\bar{b}$即可。

我们在求解乘法$x^2 - 2y^2 = 1$时已经使用了共轭数的参数。我们将左侧 $x^2 - 2y^2$ 表示为两个共轭数的乘积
$$a = x + y\sqrt{2}, \bar{a} = x - y\sqrt{2}.$$

现在让我们取两个数字$a = x_1 + y_1\sqrt{2}$和$\beta = x_2 + y_2\sqrt{2}$以及它们的共轭$\bar{a} = x_1 - y_1\sqrt{2}$和$\bar{b} = x_2 - y_2\sqrt{2}$。我们来看看产品$\alpha\bar{a}\beta\bar{b}$。按一定顺序执行计算 - 首先$\bar{a}\bar{b}$，然后$\beta\bar{b}$，然后$(\alpha\bar{a})(\beta\bar{b})$ - 我们得到：
$$\alpha\bar{a}\beta\bar{b} = (x_1^2 - 2y_1^2)(x_2^2 - 2y_2^2).$$

(4)

如果我们以不同的顺序计算相同的乘积$\alpha\bar{a}\beta\bar{b}$，那么我们得到
$$\alpha\bar{b} = (x_1x_2 + 2y_1y_2) + (x_1y_2 + x_2y_1)\sqrt{2},$$
$$\bar{a}\bar{b} = (x_1x_2 + 2y_1y_2) - (x_1y_2 + x_2y_1)\sqrt{2},$$
$$\alpha\bar{a}\beta\bar{b} = (x_1x_2 + 2y_1y_2)^2 = 2(x_1y_2 + x_2y_1)^2.$$

(5)

由等式(4)和(5)我们还得到$(x_1^2 - 2y_1^2)(x_2^2 - 2y_2^2) = (x_1x_2 + 2y_1y_2)^2 - 2(x_1y_2 + x_2y_1)^2.$

这也导致了更一般形式 $x^2 - 2y^2 = c$ 的乘法整数解之间的有趣联系。

如果整数对$(x_1; y_1)$满足等式$x_1^2 - 2y_1^2 = c_1$，并且整数对$(x_2; y_2)$满足等式$x_2^2 - 2y_2^2 = c_2$，则整数对$(x_1x_2 + 2y_1y_2; x_1y_2 + x_2y_1)$是乘法$x^2 - 2y^2 = c_1c_2$的解。

关于 $a + b\sqrt{2}$ 形式的数字的所有说法也适用于 $a + b\sqrt{d}$ 形式的数字，其中 $d$ 是素数（或自然数，不能被平方整除）。特别是对于$d = -1$也是如此；由此产生的身份将在下一点中发挥核心作用。

5. Vieta 非凡的身份和成分

任意两对数字 $(a_1; b_1)$ 和 $(a_2; b_2)$ 通过丢番图已知的以下恒等式连接：
$$a_1^2 + b_1^2)(a_2^2 + b_2^2) = (a_1a_2 - b_1b_2)^2 + (a_1b_2 + a_2b_1)^2.$$

它由 $d = -1$ 的恒等式 (8) 获得，常用于代数和数论中。我们将在这里讨论它的另一个应用：一种有趣的方法，允许您从两个直角三角形获得一个新的直角三角形，其斜边等于它们斜边的乘积。

取一个由正方形 $a_1, b_1$ 和斜边 $c_1$ 组成的直角三角形，以及另一个由正方形 $a_2, b_2$ 和斜边 $c_2$ 组成的直角三角形。因为根据毕达哥拉斯定理
$$a_1^2 + b_1^2 = c_1^2$$ 和 $a_2^2 + b_2^2 = c_2^2,$
同样的事情（9）可以写成如下：
$$(c_1c_2)^2 = (a_1a_2 - b_1b_2)^2 + (a_1b_2 + a_2b_1)^2.$$
