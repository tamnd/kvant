⟦folio 24⟧

仅当 $a_1 = a_2$ 和 $b_1 = b_2$ 时，$a_1 + b_1 i = a_2 + b_2 i$。

复数的加法和乘法 $a + bi$ 其生成方式与生成以下形式的数字的方式相同 $a + b\sqrt{2}$ 与理性的 $a$ 和 $b$。然而，这里 $a$ 和 $b$ 可以是任何数字，并且 $i^2 = -1$。作为这些操作的结果，我们再次获得以下形式的表达式 $a + bi$:

$$(a_1 + b_1 i) + (a_2 + b_2 i) = (a_1 + a_2) + (b_1 + b_2) i,$$
$$(a_1 + b_1 i)(a_2 + b_2 i) = (a_1 a_2 - b_1 b_2) + (a_1 b_2 + a_2 b_1) i.$$

现在我们知道我们在第 2 段中指出的这么多乘法 (1) 是从哪里来的。这种乘法本质上已经在上一段中讨论过 - 作为 Vieta 的两个直角三角形的组合，其边为 $(a_1; b_1)$ 和 $(a_2; b_2)$。

零复数$0 = 0 + 0i$、单位$1 = 1 + 0i$和负单位$i = 0 + 1i$发挥着特殊作用。注意，如果复数$a + bi$的任意分量$a$或$b$等于0，则在写入时省略复数的相应部分。

在复数的世界里，我们可以除以零$0 = 0 + 0i$以外的任何数字。计算两个数字的商时，通过将数字 $c - di$ 与除法 $z = c + di$ 共轭来将这两个数字相乘是很方便的：

$$\frac{a + bi}{c + di} = \frac{(a + bi)(c - di)}{(c + di)(c - di)} = \left( \frac{ac + bd}{c^2 + d^2} \right) + \left( \frac{bc - ad}{c^2 + d^2} \right) i.$$

复数首先出现在代数中，解决三角形和高阶代数方程的问题。然而，复数的应用几乎涵盖了数学和物理的所有主要领域——几何、数论、数学分析和概率论、电学计算、流体动力学和量子力学。

我们获得复数作为实数对，通过规则（1）定义它们的乘法，满足自然条件 - 交换性、结合性、分配性。对于数学来说，对所有这些对进行分类的问题很有趣。事实证明，它们都符合通用方案：对$(x, y)$以“广义复数”的形式书写，计算中的$x + yj$和$j^2$被$r + sj (r, s$（固定数，见问题19）代替；这里可能存在三个本质上不同的仆人（其他仆人可以减少到这三个）：

$$(1) j^2 = 1$$

（我们详细研究的规则$j^2 = 2$就属于这种类型）； (2) $j^2 = 0$（奇怪的是，为列编写的相应乘法规则）：

$$\left( \frac{x_1}{y_1} \right) \left( \frac{x_2}{y_2} \right) = \left( \frac{x_1 x_2}{x_1 y_2 + x_2 y_1} \right)$$

是分数加法规则的逆转

$$\frac{y_1}{x_1} + \frac{y_2}{x_2} = \frac{y_1 x_2 + x_2 y_1}{x_1 x_2}$$

最后 (3) $j^2 = -1$ 是实复数。
