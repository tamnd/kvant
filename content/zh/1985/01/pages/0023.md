⟦folio 21⟧

在日本想要进步是很困难的。

游戏数字$\sqrt{2}$在这里发挥了意想不到的作用。用户，使用恒等式$a^2 - b^2 = (a + b)(a - b)$，我们对方程左侧$x^2 - 2y^2 = 1$进行因式分解

$(x + y\sqrt{2}) (x - y\sqrt{2}) = 1$

并将我们的第一个解替换为自然数$x = 3, y = 2$：

$(3 + 2\sqrt{2}) (3 - 2\sqrt{2}) = 1.$

事实证明，如果使用恒等式$(a + b)^2 = a^2 + 2ab + b^2$，对数字$3 + 2\sqrt{2}$（或$3 - 2\sqrt{2}$）进行平方，就可以获得第二个解：

$(3 + 2\sqrt{2})^2 = 9 + 12\sqrt{2} + 8 = 17 + 12\sqrt{2},$

$(3 - 2\sqrt{2})^2 = 9 - 12\sqrt{2} + 8 = 17 - 12\sqrt{2}.$

(17; 12) 是第二个解。让我们按如下方式检查一下。让我们对正确的等式 (2) 两边进行平方：

$(3 + 2\sqrt{2})^2 (3 - 2\sqrt{2})^2 = 1$

我们得到

$(17 + 12\sqrt{2}) (17 - 12\sqrt{2}) = 1$，或

$17^2 - 2 \cdot 12^2 = 1.$

通过对数 $3 + 2\sqrt{2}$ 进行立方，可以得到以下新解：

$(3 + 2\sqrt{2})^3 = (3 + 2\sqrt{2})^2 (3 + 2\sqrt{2}) = 99 + 70\sqrt{2}.$

以完全相同的方式我们得到$(3 - 2\sqrt{2})^3 = 99 - 70\sqrt{2}$。由于$(3 + 2\sqrt{2})^3 (3 - 2\sqrt{2})^3 = 1$，我们有$(99 + 70\sqrt{2}) (99 - 70\sqrt{2}) = 99^2 - 70^2 \cdot 2 = 1$，即$(99; 70)$也是方程$x^2 - 2y^2 = 1.$的解

现在，获得新解的方法可能已经很明确了 - 我们必须继续对 $3 + 2\sqrt{2}$ 进行幂运算，也就是说，如果

$(3 + 2\sqrt{2})^n = x_n + y_n\sqrt{2},$

其中$x_n$和$y_n$是自然数，则$(x_n; y_n)$对是方程$x^2 - 2y^2 = 1$的解。可以证明该方法给出的所有解都是自然数。

现在让我们考虑这种形式的更一般的方程：

$x^2 - dy^2 = 1,$

其中$d$是一个非完全平方的自然数。

事实证明，它的所有自然数解都是用同样的方法得到的。至少猜出它的解 $(x_0; y_0)$ 并计算数字 $x_0 + y_0\sqrt{d}$ 的$n$ 次方：

$(x_0 + y_0\sqrt{d})^n = x_n + y_n\sqrt{d}.$

（最小解是解 $(x_0; y_0)$，对于任何其他解 $(x; y)$，不等式 $x_0 + y_0\sqrt{d} < x + y\sqrt{d}$ 都成立。）

对于任何数字 $d$ 都有一个基于将数字分解为整数分数来查找最小自然解的通用方法（参见 [1] 和 [2]）。

4. $p + q\sqrt{2}$ 形式的数字

让我们注意一个有趣的情况，即具有异质$p$和$q$形式的$p + q\sqrt{2}$形式的数字可以自然地与一对数字$(p; q)$相关联。此外，两个数 $p_1 + q_1\sqrt{2} = p_2 + q_2\sqrt{2}$ 相等当且仅当 $\binom{p_1}{q_1} = \binom{p_2}{q_2}$ 时发生。

事实上，令 $p_1 + q_1\sqrt{2} = p_2 + q_2\sqrt{2}$ 和 $q_1 \neq q_2$；那么事实证明 $\sqrt{2}$ 等于数字 $(p_1 - p_2)/(q_2 - q_1)$，但这是错误的。因此，等式$q_1 = q_2$一定成立；但从等式$p_1 + q_1\sqrt{2} = p_2 + q_2\sqrt{2}$我们立即得到$p_1 = p_2$。
