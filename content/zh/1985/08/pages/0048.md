$$z = nx^2y^2 - \frac{x^3 + y^3}{z^2} \geq nx^2y^2 - (x + y).$$

同时，显然$x^3 + y^3$可以被$z^2$整除，所以
$$x^3 + y^3 \geq z^2 \geq (nx^2y^2 - (x + y))^2,$$
因此，
$$n^2x^4y^4 < 2nx^2y^2(x + y) + x^3 + y^3.$$

两边除以$nx^3y^3$，我们得到所需的估计
$$nxy < 2\left(\frac{1}{x} + \frac{1}{y}\right) + \frac{1}{nx^3} + \frac{1}{ny^3}.$$

由此立即得出$x = 1$，因为对于$x \geq 2$（和$y \geq x$），不等式(*)的卧式部分不小于4，并且右侧小于3。让我们将值$x = 1$代入(*)：

$$ny < 2 + \frac{2}{y} + \frac{1}{n} + \frac{1}{ny^3}.$$

这个不等式仅适用于$y \leq 3$（对于$y \geq 4$，其右侧小于4）。回想一下，数字 $x^3 + y^3 = 1 + y^3$ 必须能被 $z^2$ 和 $z \geq y$ 整除；由此可见，$y = 1(1 + y^3 = 2)$为$z = 1$，$y = 2(1 + y^3 = 9)$为$z = 3$，$y = 3(1 + y^3 = 28)$没有合适的$z$值。剩下的就是将数字三元组 (1, 1, 1) 和 (1, 2, 3) 代入原方程，并发现第一种情况是$n = 3$，第二种情况是$n = 1$。

所以，答案是：对于 $n = 3$ $x = y = z = 1$，对于 $n = 1$，三元组 (1, 2, 3) 以及由此产生的所有排列都满足方程。

我们求解方程是为了帮助建立方程$x^2 + y^2 + z^2 = nxyz$的结构，该方程在今年«Kvant»第4期M. G. Kerin的文章《A. A. Markov的丢番图方程》中详细讨论过。有趣的是，这个方程也仅对$n = 1$和$n = 3$可解，但一般情况下其解的数量是无限的。在问题 M918 的解中可以找到数字 $(x + y + z = xyz)$ 的另一个类似方程。

F927。带电粒子通过闪烁计数器发出声音，闪烁计数器具有平行直线的形状，沿着其轨迹的闪烁体分子会发光。每个点的光均匀发射，即向各个方向均匀发射。如果闪烁体物质的折射率为$n = 1,6$，那么有多少部分光能会从闪烁体逃逸到空气中？注意闪烁体中灯光的位置。

请注意，圆锥体顶点处的 uresol 等于 $\Omega = 2\pi(1 - \cos \theta)$，其中 $\theta$ 是圆锥体轴与其所得轴之间的角度。

考虑从闪烁体内任意点发出的光束。

令 $\alpha$ 为该光线与平行平面一个面的法线 $\vec{N}$ 形成的角度，在地面上由其面 $A$ 确定，$\alpha_0 = \arcsin(1/n) \approx 39^\circ$ 为闪烁体-空气边界处光全反射的极限角。

让我们证明，对于任何折射率 $n > \sqrt{2}$ 的值，以下陈述都成立：

1. 以角度 $\alpha < \alpha_0$ 发射的光束肯定会从闪烁体射出，而且只能穿过$A$ 面。
2. 以角度 $\alpha > \alpha_0$ 发射的光线不能从面 $A$ 射出。
