平行板电容器的悖论

物理和数学科学博士
S.M.科泽尔

读者会说：“这能有什么悖论，毕竟这是一个如此简单的电气系统。”事实上，扁平电容器的制作过程是怎样的？从学校物理教科书中我们知道这是一个由两个相距很短的平行导电板组成的系统的名称，两个导电板之间有一个介电层。

如果电容器的极板（极板）连接到电池条上，则其中一个上会出现一定的电荷$+q$，而另一个上会出现一定的电荷$-q$。平行板电容器的电场主要在板之间的空间中含有宝贵的能量。该场是齐次的，即方向向量 $\vec{E}$ 在所有点上都相同。平行板电容器的电容由以下公式表示

$$C = \frac{q}{\Delta \varphi} = \frac{\varepsilon_0 \varepsilon S}{d},$$

其中$\Delta \varphi$是电容器极板之间的电位差，$S$是每个极板的面积，$d$是它们之间的距离。 $\varepsilon$是介质的介电常数，$\varepsilon_0$是电常数。

似乎一切都清楚了。与此同时，不少在考试中“遇见”平板电容器的考生也遇到了一定的困难。在很多情况下，他们依据众所周知的事实得出了相互矛盾的结果，从而出现了一种自相矛盾的情况。当然，如果您深入且非正式地了解静电定律，所有这些悖论都可以轻松解决。我们举几个具体的例子。

悖论 1. 考虑一个带电的扁平空气电容器。其极板之间的电位差

$$\Delta \varphi = \frac{q}{C} = \frac{qd}{\varepsilon_0 S}.$$

让我们注意，$\Delta \varphi$ 与电容器板之间的距离 $d$ 成正比。这意味着通过分离充电电容器的极板，我们可以增加它们之间的电位差。例如，通过将电容器充电至 10 V 的电势差，然后将间隙 $d$ 增加 $10^3$、$10^4$...倍，我们得到 $\Delta \varphi$ 等于、对应于 $10^4$ V、$10^5$ V 等。这是创建带电粒子加速器的简单而良好的方法！难道不是吗？

我们在这里显然遇到了与常识的矛盾，它告诉我们，再往前一步，我们就会违反物理学的基本原理之一——能量守恒定律。

然而，我们的推理正确与否？显然，申请者立即回答说这不可能，但并不是所有的人都指出了其物理原因。但事实上，一切都很简单。给定的扁平电容器电容公式仅对$d$较小的值有效，即当$d$明显小于极板的线性尺寸时。由于板之间的间隙较大，场不再均匀，并且电势差 $\Delta \varphi$ 不再线性依赖于 $d$。

我们在这里提出了一个非常重要的问题，即物理结果的适用范围。任何物理模型的适用性总是有限的。例如，不可能将理想气体模型应用于高压和低温下的真实气体。当平板电容器之间的距离足够大并且它们之间出现电场时，平板电容器的电容公式就停止“起作用”

异质。您不能直接应用库仑定律来确定平行板电容器板之间的电相互作用的强度。不幸的是，在这种情况下，申请人写下了公式$F = \frac{q^2}{4\pi\varepsilon_0 d^2}$，而力的正确表达式是$F = q \frac{E}{2} = \frac{q^2}{2\varepsilon_0 S}$（在这种情况下，力不依赖于距离$d$）。

现在让我们创建一个独立解决方案的问题。

问题 1. 尝试估计如果将带电扁平电容器的极板彼此之间的距离拉得更大，则它们之间的电势差会增加多少倍。板的线性尺寸$a = \sqrt{S}$和它们之间的初始距离$d$被认为是已知的。

请注意，这种难以精确计算的估计问题在物理学中发挥着重要作用。它们需要选择一个简化的物理模型，并允许人们按数量级估计现象的规模。

悖论 2. 让我们拿一个带电且绝缘的扁平电容器，在其极板上钻两个小分支 - 一个指向另一个。在这种情况下，电容器内部的磁场实际上不会改变并且保持均匀。让充电频率以较小的初始速度通过其中一根引线流入电容器，使电容器的电场对其加速（图1）。 （显然，为此，频率必须通过同一带电板中的响应来影响电容器。）

通过电容器后，该部分从另一个分支飞出，获得额外的能量 $\Delta W = q\Delta\varphi$。现在提出用磁场改变粒子的运动方向，使其重新飞进去

通过第一个分支进入电容器。让我们回想一下，磁场作用在移动带电粒子上的洛伦兹力不会做任何功，因为它垂直于粒子的速度矢量。

当再次飞过电容器时，粒子再次获得额外的能量$\Delta W$，在下一个循环中 - 另一个$\Delta W$，等等。我们“发明”了一种不需要能源的循环加速器。再多一点想象力——我们将设计一种不消耗能源的所谓发动机！

我们得出这个错误的结果是因为我们没有考虑静电场的基本属性之一——它的潜在性质。静电场的势能意味着，如果我们将带电体从空间中的一点转移到另一点，那么电力的功不取决于路径的形状，而仅取决于起点和终点的位置。由此可见，如果带电体沿着闭合轨迹移动，那么当返回到起点时，电力所做的总功将变为零。 （回想一下，引力场也具有相同的属性。）正是这个属性使我们能够引入势能和势能的概念。

在我们的例子中，当带电粒子在电容器内部移动时，电场会加速它，而在电容器外部它会减慢它的速度，当粒子接近第一个板中的响应时，其能量将恢复到之前的值。这意味着在所考虑的示例中，我们从根本上无法处理平板电容器外部的场。当然，板块之间存在明显的弱场，但在弱场中，粒子会穿过城市飞到更远的距离；结果，在电容器外部的减速场中，它恰好损失了电容器内部的加速场赋予它的能量。

散射）可能会导致根本上错误的结论。

学校教科书称，位于电容器外部的物体（包括导电物体）实际上对其电容没有影响。大多数情况都是这种情况。例如，让另一个导电的不带电极板“a”(图2)位于扁平电容器极板的后面。该板不会改变电容器内部的场，并且其电容保持不变。现在让我们将另一个极板放在电容器上 - “6”，并将其放置在电容器的第二个极板前面。并且这块板不会影响电容器的电容量。

现在让我们用导体连接外部不带电的板。我们的电容器似乎放置在导电盒内。会发生什么？

许多申请人认为，在这种情况下，电容器极板之间的场不会改变（因为外极板没有充电），因此电容器的电容也不会改变。同时，图2所示的电路，当外极板闭合时，相当于三个电容器的电路（图3）。如果极板之间的所有空间都相同，则这种复杂电容器的电动容量等于 $C = \frac{3}{2} C_0$，其中 $C_0$ 是初始电动容量。因此，骨骼发生变化，即增加1.5倍。这该如何解释呢？

事实证明一切的好处就是电容的解剖场。在其作用下，外极板发生电荷重新分布，导致上极板“a”带负电，下极板“6”带正电。 （顺便说一下，从 图 3 可以得出，如果外极板之一通过导体连接到给定电容器的其中一个极板，则电容量等于 $2 C_0$。）

悖论 4. 让我们有两个相同的电容器（而且不一定是扁平的），每个电容器的值为 $C$。其中一个收取费用$q_0$，另一个不收取费用。电容器中存储的电能等于

$$i = \frac{1}{R} \left( \frac{q_0 - q}{C} - \frac{q}{C} \right) = \frac{1}{RC} (q_0 - 2q).$$

如果我们考虑到，根据定义，电流等于一个电荷的变化

时间（电荷相对于时间的导数）：
$$i = \frac{dq}{dt},$$
然后我们得到方程
$$\frac{dq}{dt} + \frac{2}{RC} q = \frac{1}{RC} q_0.$$

不写电荷而是写电流更方便，所以我们对上面写的过程-过程对应关系在时间上进行微分：
$$\frac{di}{dt} + \frac{2}{RC} i = 0,$$
或$$\frac{di}{i} = -\frac{2}{RC} dt.$$

最后一个方程很容易积分。在这种情况下，所需积分的左侧范围是从第一个初始电流值 $i_0$ 到所考虑时刻的当前值 $i(t)$，右侧范围是从 0 到 $t$：
$$\ln i(t) - \ln i_0 = -\frac{2}{RC} t,$$
或者
$$i(t) = i_0 e^{-2t/(RC)}.$$

闭合开关后第一时刻的电流$i_0$值可以由以下物理消息确定：第一时刻左侧电容器充电至电位差$q_0 v/C$，右侧电容器未充电。因此，电阻两端的压降恰好为$q_0/C$。由此可知$i_0 = q_0/(CR)$。

函数$i(t)$的图形如图5所示。这样的函数称为指数。它们在解决身体问题时很常见。电流减少$e$倍的时间$t$称为系统的时间常数。在我们的例子中$t = CR/2$。电阻$R$越低，电流积分衰减越快。

现在我们只需计算焦耳热：
$$Q = \int_0^\infty i^2(t) R dt = \frac{q_0^2}{C^2 R} \int_0^\infty e^{-4t/(RC)} dt = \frac{q_0^2}{4C} = \frac{1}{2} W_1.$$

这样，悖论就解决了。不管$R$的值是多少，电容器的初始能量都转化为热量，而第二次能量在充电后以电容器的电能形式存储。不要对上述计算的一些复杂性感到困惑。考试期间不需要您进行此类计算。对我们来说，重要的是要证明严格的计算可以完全解决这个矛盾。

关于极限情况$R \rightarrow 0$还有待多说几句。如果我们将电容器与完美导体（超导体）连接起来会怎样？从形式上来说，我们的结果仍然有效，因为它根本不依赖于 $R$ 的值。但“丢失”的能量在哪里释放以及以什么形式释放呢？

当然，在这种极限情况下，不存在焦耳热，但电磁能的辐射开始发挥重要作用。随着电路中电流的快速变化，周围空间会产生交变电磁场，初始能量的一半会被电磁波带走。

需要注意的是，在这种情况下，需要考虑所连接电线的小电感。然后电路就变成一个具有小（但不是无限小！）衰减的振荡电路。电容器充电的过程本质上是振荡的，并且不能被周围空间中的电磁能辐射以任何方式改变。

问题2. 有一个未充电的电容器$C$ 和一个具有电动势$\mathcal{E}$ 的电池。让我们将电容器板连接到电池的两极。然后极板上会出现电荷$q = C\mathcal{E}$，电容器将获得电能$W = C\mathcal{E}^2/2$。此时，电池将做功$A = q\mathcal{E} = C\mathcal{E}^2$。我们看到$W = 1/2A$。第二个灌溉工作，一个完美的电池，去哪儿了？

悖论 5. 容量为 $C$ 的扁平空气电容器充满带有食物$\varepsilon$ 的介电液体，并充电至电压$U$。同时，电容器获得电能$W_1 = \varepsilon CU^2/2$。然后将电容器与电源断开，排干液体，然后放电。很容易报告，在放电过程中，释放了能量$W_2 = \varepsilon^2 CU/2 = \varepsilon W_1$（当液体排空时，电容器$q = \varepsilon CU$的电荷没有变化，容量变为等于$C$）。事实证明，当电容器放电时，更多

能量比充电时接收到的能量要多。例如，在 $\varepsilon=2W_2=2W_1$ 处。一个明显矛盾的情况出现了。

尽管对已去除电介质的电容器进行放电的问题在各种版本中是众所周知的，但许多申请人在试图解决该悖论时遇到了服务困难。这里的解释非常简单。

当从充电电容器中去除电介质时，必须进行一些外部正功，因为电介质总是被吸入较强电场的区域（极板之间）。由于外力的正功，电容器的电能将增加：

$$W_2 - W_1 = A_{\text{внеш}}.$$

在我们的例子中，液体电介质在重力的影响下从电容器中流出，因此电容器的能量将随着重力所做的功而增加。如果电容器始终连接到电源，则还需要考虑电池的运行：

$$W_2 - W_1 = A_{\text{внеш}} + A_{\text{бат}}.$$

这对应于在存在做功的外力的情况下隔离电容器（并且通常对于任何隔离静电系统）的能量守恒定律。

任务 3. 尝试独立求出当从与其极相连的电容器汲取磁导率为 $\varepsilon$ 的液体电介质时，外部功以及电动势为 $\varepsilon$ 的电池所做的功。冷凝器的空气容量为$C$。

如果系统中存在主动电阻，则还必须考虑 Joyle 热量。在这种情况下，可以方便地将能量守恒定律写成以下形式

$$A_{\text{бат}} - Q = \Delta W - A_{\text{внеш}}$$
