如何获得对称不等式

物理和数学科学候选人
S.V.德沃里亚尼诺夫，
教育科学候选人
E·A·亚西诺维

在代数和分析的许多问题中，在数学奥林匹克竞赛中，有时在考试中，有些问题需要证明多个变量的不等式。其中最简单的课程可供 5 至 6 年级的学生使用。许多数学统计学家、评论和专着都致力于介绍替代不等式的证明和一般定理的各种方法。我们的“数学圈”里积累了很多关于不等式的文章。

本说明描述了有关特殊形式的对称多项式（具有相同指数的所有可能的同年多项式之和）的不等式的缪尔黑德定理。这个定理于 1903 年得到证明，不仅因其普遍性和最终性而引人注目，而且还因为在近年来积极发展的理论和应用数学的各个分支中自然出现后，与之相关的组合概念（“杨氏图”及其比较 - “主化”）的出现。

介绍

我们将处理这种类型的不平等：

$$x^2 + y^2 \geq 2xy,$$
(1)
$$x^5 + y^5 \geq x^3y^2 + y^3x^2,$$
(2)
$$x^2 + y^2 + z^2 \geq xy + yz + zx,$$
(3)
$$x^3 + y^3 + z^3 \geq 3xyz,$$
(4)

$$x^2y^2 + y^2z^2 + z^2x^2 \geq x^2yz + y^2xz + z^2xy,$$
(5)
$$x^4 + y^4 + z^4 + w^4 \geq 4xyzw.$$
(6)

这些不等式对于其中包含的字母的所有非负值都有效。对于两个变量的情况，通过对项进行分组并因式分解也很容易证明不等式。例如，让我们证明对于任何非负 x 和 y 不等式 (2) 成立。为此，请考虑差异

$$x^5 + y^5 - x^3y^2 - y^3x^2 = x^3(x^2 - y^2) - y^3(x^2 - y^2) = (x^3 - y^3)(x^2 - y^2).$$

之后，乘积显然是非负的；对于 $x \geq y \geq 0$，两个括号均不小于 0；对于 $y \geq x \geq 0$，两个括号均不大于 0。

Vollee很难用冠或者大量变量来实现不等式的对称证明。让我们用一个例子（5）来演示总体想法。在这里，可以方便地将所有项交叉到不等式的左侧，将它们乘以 2，并将它们分为三组：

$$x^2(y^2 - 2yz + z^2) + y^2(x^2 - 2xz + z^2) + z^2(x^2 - 2xy + y^2) = x^2(y - z)^2 + y^2(x - z)^2 + z^2(x - y)^2 \geq 0.$$

练习 1. 尝试证明不等式 (1)、(3) 和 (6)。

要学习如何证明此类类型的各种不等式并制定一般定理，您需要熟悉非负新概念。现在我们将描述它们。

单项式的对称化

例如，

$$T_{(2;1;0)}(x, y, z) = x^2 y + y^2 x + z^2 x + x^2 z + z^2 y;$$

$$T_{(3;1;1)}(\dot{x}, y, z) = x^3 y z + y^3 x z + z^3 x y + x^3 z y + y^3 z x + z^3 y x;$$

$$T_{(2;2;2)}(x, y, z) = 6 x^2 y^2 z^2.$$

最后两个例子表明，当指数相等时，可以将相似的项添加到多项式$T_u$中并写得更短。

如果指标集$\alpha = (\alpha_1, \alpha_2, \dots, \alpha_n)$由$n$个数字组成，那么您需要绘制一个包含$n$方格的表格，并采用$n$变量$x_1, x_2, \dots, x_n$。而且，在多项式$T_u(x_1, \dots, x_n)$中，在相似单项式被约简之前，还会存在$n! = 1 \cdot 2 \cdot \dots \cdot n$单项式。

因此，对于每组整数$\alpha = (\alpha_1; \alpha_2; \dots; \alpha_n)$，其中$\alpha_1 \geqslant \alpha_2 \geqslant \alpha_3 \geqslant \dots \geqslant \alpha_n \geqslant 0$对应多项式$T_u$，是具有指数$\alpha_1, \alpha_2, \dots, \alpha_n$的单项式的“对称化”。

我们将每个这样的集合$\alpha$描述为$n$台阶的梯子：每个台阶的高度等于相应的指示器，宽度为1。在格子纸上画这样的梯子很方便；构成梯子的单元格（“砖块”）$1 \times 1$的总数等于$s = \alpha_1 + \dots + \alpha_n$ - 多项式$T_u$的次数。 图 2 显示了与我们的不等式中遇到的一些多项式 $T_u$ 相对应的梯子。

这些梯子的学名是“Young 图”（参见 [3]），可用于组合数学、代数和分析的各种问题。

**缪尔海德定理**

现在一切准备就绪，可以构成主定理了。

令 α=(α1;α2;...;αn) 和 β=(β1;β2;...;βn) 为两组具有相同总和的指标。如果 α>β，则对于所有非组织 x1, x2, ..., xn
Tα(x1, x2, ..., xn)>Tβ(x1, x2, ..., xn).
相反，如果这样的不等式成立，则α>β。

我们不会以一般形式给出该定理的公式化证明（可以在书籍[1]、[2]中找到——其中第二本书完全致力于“最大化”关系的各种版本及其应用和概括），而是我们将描述其主要思想并用具体例子进行演示。

定理第二部分的证明——条件 α>β 的必要性——源自一个简单的事实：对于一个变量 t 的两个多项式（具有正的主系数），对于较大的 t 值，阶数越大的多项式越大（参见练习 8）。

条件α>β充分性的证明基于两个想法。第一个是“倒砖”：两个集合α>β可以通过一个整数集合连接起来，使得这个整数中的相邻集合只有两处不同，这样从每个集合到下一个集合都可以移动，在相应的梯子上从一个台阶到另一个台阶“倾倒一块砖”。第二个是“对称分组”：相邻集合的多项式之差可以写为以下形式的相同组的总和（在所有参数 x，y 上）
(xp+r yq+p r xq−p r yq+p r)Z

三个非负数的算术平均值与几何平均值不相等

$$\frac{a_1 + a_2 + a_3}{3} \geq \sqrt[3]{a_1 a_2 a_3}$$

重新指定后，$a_1 = x^3$、$a_2 = y^3$、$a_3 = z^3$变为不等式（4），这在上面已经提到过。让我们展示如何使用 Muirhead 方法证明这一点。观察图 4 a)，我们发现我们需要证明两个不等式：

$$T_{(3; 0; 0)}(x, y, z) \geq \geq T_{(2; 1; 0)}(x, y, z)$$

让我们考虑第一个并弥补差异

$$R_1 = T_{(3; 0; 0)}(x, y, z) - T_{(2; 1; 0)}(x, y, z) = 2(x^3 + y^3 + z^3) - x^2y - y^2z - z^2x - x^2z - y^2x - z^2y.$$

现在让我们根据以下原则将项按 4 进行分组：对于每对变量，一组包括这些变量的指标从 (3, 0) 变为 (2, 1) 的项（此处集合中的总体指标 0 位于最后）。我们得到

$$R_1 = (y^3 + z^3 - y^2z) + (x^3 + y^3 - x^2y - y^2x) + (z^3 + x^3 - z^2x - x^2z) = (y^2 - z^2)(y - z) + (x^2 - y^2)(x - y) + (z^2 - x^2)(z - x) \geq 0$$

对于所有非负$x, y, z$。

现在我们来证明第二个不等式

$$R_2 = T_{(2; 1; 0)}(x, y, z) - T_{(1; 1; 1)}(x, y, z) = x^2y + y^2z + z^2x + x^2z + y^2z - 6xyz.$$

这里，在指数中，公共单位排在第二位，(2; 0) 变成(1, 1)。依此类推，我们得到：

$$R_2 = x(y^2 + z^2 - 2yz) + y(z^2 + x^2 - 2zx) + z(y^2 + z^2 - 2yz) = x(y - z)^2 + y(z - x)^2 + z(x - y)^2 \geq 0.$$

这证明了不等式（4）。

问题 M762 的解决方案。

在这个问题中（摘自“问题书«Kvant»第9期，1982），需要证明正$a, b, c$的不等式

$$a + b + c \leq \frac{a^2 + b^2}{2c} + \frac{b^2 + c^2}{2a} + \frac{c^2 + a^2}{2b} \leq \frac{a^3}{bc} + \frac{b^3}{ca} + \frac{c^3}{ab}.$$

读者提出了几种不同的方法来解决这些问题。其中之一是 Muirhead 方法（我们希望在下一期«Kvant» 中回到其他方法）。通过将这些不等式乘以 2abc，我们将它们简化为以下“Mirhead”形式：

$$2(a^4 + b^4 + c^4) \geq \geq a^3b + b^3a + b^3c + c^3a + a^3c,$$

$$a^3b + b^3a + b^3c + c^3a + a^3c \geq 2(a^2bc + b^2ac + c^2ab).$$

相应的杨氏图如 图 4, 6 所示。每个不等式左右两边的差可以如上所示写为三组四年生植物的总和。为了节省空间，我们将只写一组 - 其他两组是通过将字母 $a, b, c$ 替换为 $b, c, a$ 和 $c, a, b$ 来获得的。

证明（7）：

$$(a^4 + b^4 - a^3b - b^3a) + \dots = (a^3 - b^3)(a - b) + \dots \geq 0.$$

证明（8）：

$$(a^3b + c^3b - a^2cb - c^2ab) + \dots = b(a^2 - c^2)(a - c) + \dots \geq 0.$$

这样，M762的问题就解决了。
