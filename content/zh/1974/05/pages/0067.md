回答。将等式两边(I)乘以电流I，我们得到
$$UI - E_n I = I^2 R,$$
或者
$$UI = I^2 R + E_n I.$$
将得到的等式与等式（II）进行比较，我们可以立即注意到：
$$P = E_n I,$$
也就是说，电机的有用功率等于电动势的乘积。每电流感应。
问题。收到任何结果后，分析特殊情况的可能性总是有用的。我们可以假设电机的有用功率等于$E_n I$。我们看看什么情况下电机不会做机械功，即$P = 0$。电枢电路中会发生什么？
回答。如果 $E_n = 0$ 或 $I = 0$，乘积 $E_n I$ 可以为零。
不管怎样呃。 d.s.感应系数为零，穿过电枢绕组匝的磁通量不应改变。如果电枢电机被锁定，即不旋转，则这是可能的。在这种情况下，电流流过钳位电枢的绕组
$$I = \frac{U}{R}.$$
还有一种情况，当$I = 0$时，电机不做任何功。这不仅在电机未连接到电源时才有可能。根据欧姆定律，$I = 0$ 也适用于
$$E_n = U,$$
也就是说，电机以这样的速度旋转，例如d.s.感应的绝对值等于电流源的方向。在这种情况下，电机不消耗来自源的电力：由于$I = 0$，则功耗为$P_\pi = UI = 0$。电枢电机靠惯性旋转*)。

*) 这也源于以下事实：在 $I = 0$ 时，作用在电枢绕组上的电感器磁场中的力也为零。

问题。让我们回到公式(II)。由此可见，电动机的有用功率等于
$$P = UI - I^2 R.$$
P 与 moka I 的图表如何遵循？
回答。这是一条与 I 轴相交于点 $I = 0$ 和 $I = \frac{U}{R}$ (图1) 的抛物线。从 symmetrina 的消息中可以看出，电机的有用功率在 $I = U/2R$ 时最大，等于
$$P_{\max} = \frac{U^2}{4R}.$$
问题。如果开发功率最大，独立励磁电机的效率是多少？
回答。正如我们所见，电机的机械（有用）功率在 $I = \frac{U}{2R}$ 处最大，等于
$$P_{\max} = \frac{U^2}{4R}$$。电机从电源消耗的功率等于
$$P_\pi = UI = \frac{U^2}{2R}.$$
因此，所考虑案例的效率
$$\eta = \frac{P_{\max}}{P_\pi} = \frac{U^2 2R}{4R U^2} = \frac{1}{2}.$$
