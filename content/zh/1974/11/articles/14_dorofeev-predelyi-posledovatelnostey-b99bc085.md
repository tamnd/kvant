序列限制
G·V·多罗费耶夫

与“申请人实践”部分中发表的大多数文章不同，本文没有表明将提出哪个特定任务。
这并不难解释：学校课程中的极限概念仅用于理论目的，任何与极限相关的计算问题在学校都不会得到解决。因此，自然地，在向申请人提供的笔试选项中不存在此类任务。
然而，在口语考试的门票中，部分出现了限制的概念，尤其重要的是，全部出现了限制的概念。对于准备充分的读者，我们还建议您熟悉 M. L. Gerver 的文章“20 issues to the limit”（«Kvant»，1974 年，第 3 期）。

如果我们转向大学建设项目，那么我们只会在其中遇到一次“极限”一词——在第 1 节“算术、代数和初等函数”的第 5 段中。然而，你数一下程序中包含的十多个问题，其基础正是极限的概念。首先是与圆柱、圆锥、球体及其零件的周长、圆面积、表面积和体积有关的几何问题。另外，极限的概念用于确定无理数指数的正数的程度以及无限杀几何级数之和。

事实上，使用极限概念的问题清单要广泛得多；我们只给出了那些限制的使用是完全标准的并且为学童所熟悉的。例如，在证明三角形相似的主要引理、平行六面体直线面积和直线体积的公式、证明正数自然次数根的存在性、正数对数的存在性等方面都会用到极限的概念。我们在文章的最后详细讨论其中一个问题。

申请人经常有一个问题：他们需要多少关于序列极限的知识。同时，很多人认为没有必要知道任何关于极限的定理——毕竟在程序“基本公式和定理”部分中并没有提到极限的概念！

但也不完全是这样——在证明程序中包含的一些公式和定理时，显然使用了各种极限定理，因此至少需要知道这些定理的表述方式，稍后我将讨论证明。

例如，考虑计算无限杀戮几何级数的总和。众所周知，这样的直通之和就是顺序的极限S

刺激$(S_n)$，食物$S_n$ — 级数第一批成员的总和$n$：$S = \lim_{n \to \infty} S_n$。这就是金额的确定。并且为了证明这样的级数之和总是存在（毕竟，不是每个序列都有极限！），并且为了计算这个和，进行以下计算：

$$\lim_{n \to \infty} S_n = \lim_{n \to \infty} a_1 \frac{1-q^n}{1-q} =$$

$$= \lim_{n \to \infty} \left( \frac{a_1}{1-q} - \frac{a_1}{1-q} q^n \right) =$$

$$= \frac{a_1}{1-q} - \frac{a_1}{1-q} \lim_{n \to \infty} q^n = \frac{a_1}{1-q}.$$

此计算中使用以下定理：

(1) 如果序列 $(a_n)$ 有极限，则对于任意数 $c$
$$\lim_{n \to \infty} (c-a_n) = c - \lim_{n \to \infty} a_n;$$

(2) 如果序列$(a_n)$有极限，则对于任意数$c$
$$\lim_{n \to \infty} c a_n = c \lim_{n \to \infty} a_n;$$

(3) 对于任意数$q$，最大$|q| < 1$
$$\lim_{n \to \infty} q^n = 0.$$

另外请注意，在进行第一个变换时，与语句(1)一起，可以使用两个更“通用”性质的定理：两个序列之差的极限等于它们的极限之差，并且常数序列(c)（即所有项都等于同一个数字$c$的序列）的极限等于$c$：

(4) 如果序列$(a_n)$和$(b_n)$有极限，则
$$\lim_{n \to \infty} (a_n-b_n) = \lim_{n \to \infty} a_n - \lim_{n \to \infty} b_n;$$

(5) $$\lim_{n \to \infty} c = c.$$

请注意，在回答无限递减几何级数之和的问题时，会检查申请人对哪些定理以及他所使用的证明的具体位置的理解有多清楚——如果没有这样的解释，所做的计算看起来就像教科书上的“照片”，当然不能让审查员满意。

然而，这可能还不够，特别是当进入一所开设高等数学课程的大学时。事实上，如果我们仔细阅读给申请人提供的同一个程序，我们会发现申请人必须掌握第1节中提到的数学概念。而掌握意味着不仅能够制定定义，而且能够将其应用到最简单的情况中。不幸的是，除了陈述（4）之外，陈述（1）-（5）的证明可以完全描述为这样简单的情况：它们不需要人工计算，不需要独创性，并且任何知道和理解极限定义的人都可以理解。让我们看看这个证据。

首先让我们回想一下，如果对于任何正数$\varepsilon$，存在一个最大数$N$，使得序列中从$a_{N+1}$开始的所有成员都在数字$a-\varepsilon$和$a+\varepsilon$之间，则数字a被称为序列$(a_n)$的极限；换句话说，对于所有$n>N$，不等式$a-\varepsilon<a_n<a+\varepsilon$，或者相同的$|a_n-a|<\varepsilon$，都成立。

从这个定义，直接证明陈述$a=\lim_{n \to \infty} a_n$的方案立即如下：有必要表明，对于任意正数$\varepsilon$，如何找到具有所需性质的数$N$。在这种情况下，需要考虑的不是某个特定的数值$\varepsilon$（因为有时会涉及合并，“让我们取任意数字$\varepsilon$，例如$\varepsilon=1/2$），而是一个任意值，即考虑$\varepsilon$作为参数。

我们首先证明最简单的命题（5）。

给定一个具有公共项 $a_n=c$ 的序列。让我们取一个任意正数$\varepsilon$，并开始寻找一个数$N$，使得对于所有$n>N$，不等式$c-\varepsilon<a_n<c+\varepsilon$（即$c-\varepsilon<c+c+\varepsilon$）成立。您不必搜索很长时间 - 这种双重不等式始终为真（自 $\varepsilon>0$ 起​​），因此您可以将任何数字（特别是 1）作为 $N$。

现在我们来证明命题(3)。

设 $|q|<1$；让我们取一个任意数$\varepsilon>0$，然后开始寻找一个数$N$，使得对于所有$n>N$，不等式$-\varepsilon<q^n<\varepsilon$，或者，$|q^n|<\varepsilon$或$|q|^n<\varepsilon$都成立。最后一个不等式很容易解决：它适用于所有$n>\log|q| \varepsilon$（注意$|q|<1$）。因此，$N$可以是任何大于$[\log|q| \varepsilon]$的自然数，例如$1+[\log|q| \varepsilon]$。

在证明考试中所考虑的陈述时，无需复制上述所有方法论性质的解释；最好更简洁地检查证明：

“让$\varepsilon$是一个任意正数；让我们把$N=1+[\log|q| \varepsilon]$，moeda，如果$n>N$，那么$n>\log|q| \varepsilon$，也许$|q|^n<\varepsilon$，或$-\varepsilon<q^n<\varepsilon$。因此，$\lim_{n\to\infty} q^n=0$”。不用担心考官不明白这个$N$的值从何而来，或者会责备你“凭空”取这个值。

在讨论的示例中，我们实际上能够显式指定原始数字$N$。否则我们只能证明这样一个数的存在——这也足够了！

让我们证明命题(2)。

设 $\lim_{n\to\infty} a_n=a$；让我们取任意数$\varepsilon>0$，并寻找一个数$N$，使得对于任何数$n>N$，不等式$|ca_n-ca|<\varepsilon$或$|c|\cdot|a_n-a|<\varepsilon$成立。

由于$c=0$被证明的陈述显然是正确的（根据陈述（5）），我们将假设$c\neq0$并将上述不等式重写为以下形式

$$|a_n-a|<\frac{\varepsilon}{|c|}.$$

由于 $\varepsilon/|c|$ 是某个正数且 $a=\lim_{n\to\infty} a_n$，因此，根据极限的定义，存在一个数 $N'$ 使得对于 $n>N'$ 不等式 (*) 满足。让我们设置$N=N'$，那么对于$n>N$不等式（*）是有效的，因此等价的不等式$|ca_n-ca|<\varepsilon$。

因此，我们已经证明，对于任意$\varepsilon>0$，都存在一个数$N$，使得对于$n>N$，不等式$|ca_n-ca|<\varepsilon$成立，这意味着$\lim_{n\to\infty} ca_n=ca$，这就是我们需要证明的。

命题(4)的证明稍微复杂一些。我们将证明序列之和的类似陈述，将陈述（4）的证明留作练习。

让我们注意到，在关于极限的陈述的表述中，通常存在一个限制，即其中出现的序列有一个极限；如果没有这个限制，陈述(1)、(2)、(4)就毫无意义。为了防止这些限制悬而未决，了解并非每个序列都有限制是很有用的。

没有限制的序列的一个例子是序列

$$0, 1, 0, 1, 0, 1, \dots$$

事实上，假设相反，让这个序列有极限$a$。让我们放入$\varepsilon = 1/3$，然后我们必须找到$N$，使得序列中所有大于$N$的项都位于区间$(a-1/3, a+1/3)$内。因此，这些项之间的距离（在数值轴上）不超过2/3。然而，在我们的序列中存在项 0 和 1，无论相距多远，它们之间的距离都等于 1，即大于 2/3。

现在让我们找到具有公共项的序列的极限

$$c_n = \frac{1^2 + 2^2 + 3^2 + \dots + n^2}{6n^3},$$

使用阶梯体计算体积参数时使用。为了计算这个极限，我们变换 $c_n$ 的表达式：

$$c_n = \frac{n(n+1)(2n+1)}{6n^3} = \frac{(1 + \frac{1}{n})(2 + \frac{1}{n})}{6}.$$

现在这个极限的计算与乘积$d_n = \left(1 + \frac{1}{n}\right)\left(2 + \frac{1}{n}\right)$的极限的计算有关，对于这个过程我们使用以下语句：

(6) 如果序列$(a_n)$和$(b_n)$有极限，则

$$\lim_{n \to \infty} a_n b_n = \lim_{n \to \infty} a_n \cdot \lim_{n \to \infty} b_n.$$

然而，这个命题的证明比前面所有的命题都要复杂得多：它需要初步证明几个关于极限的定理。同时，我们的极限的计算可以直接进行，不需要使用这个一般定理。让我们证明这个极限等于 2（“你可以从直觉信息或基于相同的一般定理 6 猜到”这是如此——毕竟，为此没有必要证明它！）。有必要证明对于每个 $\varepsilon > 0$ 都有一个数字 $N$ 使得对于所有 $n > N$ 不等式

$$-\varepsilon < d_n - 2 < \varepsilon$$

$$-\varepsilon < \frac{3}{n} + \frac{1}{n^2} < \varepsilon.$$

显然，左不等式对于任何$n$都成立，而不等式$\frac{3}{n} + \frac{1}{n^2} < \varepsilon$并不难解，但我们将以倒过来的方式进行。从不等式$\frac{1}{n^2} \leq \frac{1}{n}$可以得出$\frac{3}{n} + \frac{1}{n^2} \leq \frac{4}{n}$，并且不等式$\frac{4}{n} < \varepsilon$对于所有$n > \frac{4}{\varepsilon}$都成立。

Pozny，如果我们取任何大于$\frac{4}{\varepsilon}$的自然数作为$N$，那么在$n > N$处将会有$n > \frac{4}{\varepsilon}$，即$\frac{4}{n} < \varepsilon$，因此

$$\frac{3}{n} + \frac{1}{n^2} \leq \frac{4}{n} < \varepsilon.$$

因此，对于任意的$\varepsilon > 0$，我们指示所需的数字$N$，因此$\lim_{n \to \infty} d_n = 2$和$\lim_{n \to \infty} c_n = 1/3$。

总之，让我们把注意力转向与极限概念相关的另一系列问题，即所谓的维尔斯特拉斯定理的应用。让我们回顾一下它的表述：每个单调递增的运算序列都有一个极限。对于单调递减序列，类似的说法也成立。

我们不会详细讨论该定理的标准应用（例如，确定圆的周长时）；我们将指出它的一些其他应用。

每个人都知道不能求负数的平方根，而且他们可以轻松证明这一点。大家都知道任何正数都可以开平方根，但是如何证明它存在呢？这是利用维尔斯特拉斯定理建立的。

事实上，给定一个正数$c$；那么存在一个非负整数 $a_0$ 使得

$$a_0^2 \leq c < (a_0 + 1)^2$$

（$a_0$ 是 $c$ 的平方根的整数近似值，不足时为 $a_0 + 1$ 的平方根）。接下来，我们可以找到一个从 0 到 9 的整数 $a_1$，使得

$$\left( a_0 + \frac{a_1}{10} \right)^2 \leq c < \left( a_0 + \frac{a_1 + 1}{10} \right)^2$$

（即以 1/10 的精度获得 $c$ 的平方根的近似值）。

继续这个过程，我们得到两个序列：

$$(a_n) = \left( a_0, a_0 + \frac{a_1}{10}, a_0 + \frac{a_1 + 1}{100}, \dots \right)$$

和

$$(b_n) = \left( a_0 + 1, a_0 + \frac{a_1 + 1}{10}, a_0 + \frac{a_1 + 1}{100}, \dots \right).$$

这些序列中的第一个是递增且有界的 - 它的所有项都小于，例如，$a_0 + 1$；根据维尔斯特拉斯定理，它有一定的极限$a$。第二个序列同样有一些限制$b$。凭借陈述（6）

$$\lim_{n \to \infty} a_n^2 = a^2, \lim_{n \to \infty} b_n^2 = b^2.$$

另一方面，这些序列的构造本身就存在不平等

$$a_n^2 \leq c < b_n^2,$$

由此可见（见练习 9）

$$a^2 \leq c \leq b^2.$$

最后，我们得到语句（4）和（3），我们得到

$$a - b = \lim_{n \to \infty} a_n - \lim_{n \to \infty} b_n =$$

$$= \lim_{n \to \infty} \left( a_n - b_n \right) = \lim_{n \to \infty} (1/10)^{n-1} = 0.$$

因此，$a = b$，因此$a^2 = c$。换句话说，$a$是$c$的平方根，我们要求该命题被证明。

我们看到，证明正数平方根的存在性这样一个“显而易见”的命题，实际上需要使用大量的极限定理。因此，它的结构证明（以及类似的陈述的证明：正数对数的存在性、无理数指数的正数幂的存在性、-1到1之间的任意数的反正弦值的存在性等）既不包含在学校课程中，也不包含在大学建设计划中。我们考虑这个问题只是为了表明证明这些陈述的真正困难，并给出证明它们的方法的基本想法。
