⟦folio 2⟧

力学中的基本运动方程是牛顿第二定律：

$$m a = F.$$

要找到物体在任何时刻的位置及其速度，只需知道力作为物体坐标和速度投影的函数，以及初始条件：初始时刻物体速度的坐标和投影就足够了。

最简单的情况是在恒定力$F = const$（特别是力可以为零）影响下的运动。那么加速度恒定（$a = const$）；使用众所周知的运动学方程可以轻松确定身体的坐标和速度。

对于自然界中非常常见并在技术中广泛使用的振荡运动，加速度不是恒定的。这使得解决机械问题变得非常困难。只有在与物体相对平衡位置的位移成正比的力作用下物体的自由简谐振动才能完全研究，而无需求助于高等数学。但已经考虑到与速度成正比的三分力，有必要改变微分方程。当作用系统上存在额外的外部周期性力时，受迫振荡问题（在数学上）更加困难。在这种情况下，在系统中观察到一个奇怪且实际重要的现象——共振。当外力的频率与系统的固有频率一致时，振动的幅度急剧增加。

然而，无需求解复杂的运动方程，就可以使用视觉物理信息来分析受迫振动的过程。特别是，我们可以理解为什么会观察到共振。这就是本文的主题。

但首先，让我们回顾一下有关自由谐振的一些基本规定。

自由简谐振荡

最简单的振荡系统是这样一种系统，其中力的作用与物体从平衡位置的位移成正比，方向与位移相反。当然，摩擦总是存在的。但如果它很小，那么在不太长的时间内，通过三种力量的作用，你就可以不复存在。此类系统包括：外部载荷、数学垫（小偏转角度）、漂浮在水面上且具有恒定横截面的物体等。对于定义，我们仅讨论向外载荷。有两种力作用在负载上：重力和弹簧的弹力。恒定的引力$F_T = mg$不会以任何方式影响振荡过程。它只会混淆负载的平衡位置。很容易排除

$$ma_x = -kx. \tag{1}$$

将该方程除以 $m$ 并引入符号 $\omega_0 = \sqrt{\frac{k}{m}}$，我们得到了描述具有循环频率 $\omega_0$ 的简谐振动的方程的普遍接受的形式：

$$a_x = -\omega_0^2 x. \tag{2}$$

这个方程的解，即找到函数$x = x(t)$，可以通过基本但相当漫长的方式获得。结果是：

$$x = x_0 \cos(\omega_0 t + \varphi_0). \tag{3}$$

这里$x_0$是振荡幅度，$\varphi_0$是初始相位。这些量是根据初始条件求得的。

显然，我们通过向下拉动并释放弹簧来激发弹簧上的重物的振动。此外，在初始时刻（$t = 0$）$x = x_0$和$v_x = 0$。这与$\varphi_0 = 0$相匹配。然后

$$x = x_0 \cos \omega_0 t. \tag{4}$$

加速度与坐标异相振荡（异相$\pi$），振幅为$a_0 = \omega_0^2 x_0$，即

$$a_x = \omega_0^2 x_0 \cos(\omega_0 t + \pi) = -\omega_0^2 x_0 \cos \omega_0 t. \tag{7}$$

这就是您需要了解进一步相对自由简谐振动的全部内容。

受迫振动的运动方程

让外部周期力 $F_x = F_0 \cos \omega t$ 作用在振荡系统上（在我们的示例中是弹簧上的负载）。此外，身体还受到弹力$F_y = -kx$和与速度成比例的摩擦力$F_{\tau p} = -\mu v_x^*$），其中$\mu$是摩擦系数。那么运动方程将写成这样：

$$ma_x = -kx - \mu v_x + F_0 \cos \omega t. \tag{8}$$

将除外部力之外的所有力穿过方程左侧，我们得到：

$$ma_x + \mu v_x + kx = F_0 \cos \omega t.$$

*）在身体低速运动时，我们确实可以假设摩擦力（或者换句话说，阻力）与速度成正比。

遵守这个方程的物体的运动是相当复杂的，尤其是在开始时，当它不是谐波的时候。

建立振荡

建立受迫简谐振动的机制可以如下完成。在外力的影响下，系统受到“推力”，从而产生频率$\omega_0$的自由振荡。随着时间的推移，摩擦系数$\mu$越大，自由振动消失得越快。但同时，作用系统中存在外部周期性力，导致其产生频率为$\omega$的振荡。这样，在一定时间内，系统中同时发生自由振荡和受迫振荡，即叠加原理适用于振荡运动。

受迫振荡的幅度随着时间的推移而增加 (图2)，直到建立某个固定值。当外力的功等于摩擦力的功时，即当从外部进入系统的能量等于系统内机械能的损失时，就会发生这种情况。

因此，只有在系统中建立振荡之后，自由振荡才会消失，只有频率为 $\omega$ 和振幅 $x_0$ 的受迫简谐振动仍然存在：

$$x = x_0 \cos (\omega t + \varphi_0).$$ (10)

从外部来看，自由振动和受迫振动的方程是相同的。但是，如果在自由振荡期间 $x_0$ 和 $\varphi_0$ 仅由初始条件决定，那么在受迫振荡期间，它们由系统本身和外力的参数决定（正如我们稍后将看到的）。首先，自然振动和受迫振动频率之间的对应关系起着重要作用。顺便请注意，受迫振荡情况下$\varphi_0$的值称为混合物振荡与外力之间的相移。

执行受迫振动的物体的速度和加速度由类似于自由振动的 (6) 和 (7) 的等式确定：

$$v_x = \omega x_0 \cos \left(\omega t + \varphi_0 + \frac{\pi}{2}\right),$$ (11)

$$a_x = -\omega^2 x_0 \cos (\omega t + \varphi_0).$$ (12)

由于速度总是表征坐标随时间快速变化，而加速度表征速度随时间快速变化，那么，知道了坐标对时间$x(t)$的依赖关系，我们就可以唯一确定函数$v_x(t)$和$a_x(t)$。

现在让我们继续解决主要问题。让我们找出受迫振荡的幅度 $x_0$ 和相移 $\varphi_0$ 取决于什么以及如何取决于。为此，请考虑三种限制情况。

低频受迫振荡

让我们再次重写方程（9）——受迫振动的运动方程：

$$a_x + \frac{\mu}{m} v_x + \omega_0^2 x = \frac{F_0}{m} \cos \omega t.$$

如果$\omega \ll \omega_0$，则该等式左侧的三项中最大的将是最后一项$\omega_0^2 x$。事实上，第一项的幅度与 $\omega^2 x_0$ 成正比，第二项与 $\omega x_0$ 成正比，最后一项与 $\omega_0^2 x_0$ 成正比。因此近似值（假设 $\omega \rightarrow 0$）

$$\omega_0^2 x = \frac{F_0}{m} \cos \omega t,$$

在哪里

$$x = \frac{F_0}{m \omega_0^2} \cos \omega t = \frac{F_0}{k} \cos \omega t.$$ (13)

坐标振动成比例，并且振动的相位与外力的相位一致。

*) 为了保证精度，需要一小部分。在存在摩擦的情况下，自由振动的固有频率$\omega_c$不等于$\omega_0 = \sqrt{\frac{k}{m}}$。事实上，它有点小：$\omega_c = \sqrt{\omega_0^2 - \frac{\mu^2}{4m^2}}$。但摩擦系数低（$\mu \rightarrow 0$）$\omega_c \approx \omega_0$。实际中最有趣的情况正是小摩擦的情况。因此，我们可以正确地认为系统振荡的固有频率等于$\omega_0 = \sqrt{\frac{k}{m}}$。

请注意，弹簧刚度越大，振动幅度越小。定性地，这种情况可以描述如下。在外力频率较低时，几乎会发生与恒定力作用在弹簧上相同的情况。根据胡克定律，位移与外力成正比增加，并且在任何时刻外力几乎完全被弹簧的弹力平衡。

从能量的角度来看，以周期性力作用于系统的外部物体将能量泵入振荡系统的条件是非常不利的。事实上：在四个周期中，当物体偏离平衡位置时，外力会做正功，因为物体的力和速度以及因此产生的位移都指向一个方向（图3）。但在接下来的四个周期中，当身体返回到平衡位置时，力和速度（因此位移）的方向相反（图4）。外力所做的功将为负值。在该时期的后半段也会出现同样的情况。一般来说，在工作期间，外力几乎为零。外力的功只有一小部分用来补偿摩擦力的功，因为$\omega \ll \omega_0$时物体的速度很小，因此摩擦力的大小也很小。

这里有一些微妙之处，有时让人很难理解事情的本质。如果从平衡位置开始的变化与任意时刻的力成正比，那么乍一看，功应该始终为正。但必须记住，功的符号取决于力的方向和位移方向（即速度）的重合，而不是坐标的符号。为了使工作是积极的，符号$F_x$和$x$不必匹配，但$F_x$和$\Delta x$（或$\frac{\Delta x}{\Delta t} = v_x$）具有相同的符号。

大型零件的受迫振动

对于等式（9）左边$\omega \gg \omega_0$的情况，在任何时刻，第一项最大，其幅度与频率的平方成正比。它将扮演主要角色，所以你可以这样写：

$$a_x = \frac{F_0}{m} \cos \omega t.$$

此时坐标不再与力同相，而是加速度，坐标的振荡将与外力的振荡反相。坐标振幅等于

$$x_0 = \frac{a_0}{\omega^2} = \frac{F_0}{m\omega^2}.$$

因此，身体振动按照规律传递

$$x = -\frac{F_0}{m\omega^2} \cos \omega t.$$ (14)

当$\omega \to \infty$（相当于条件$\omega \gg \omega_0$）$x_0 \to 0$时，即振荡幅度较小。这个结果是很自然的。力柱的方向是具有惯性的物体没有时间相对于平衡位置明显移动。

与前面的情况一样，当$\omega \ll \omega_0$时，外力一半时间做正功，另一半时间做负功。在一半的时间内，力和位移的方向相同，而在另一半的时间内，力和位移的方向相反。同样，几乎没有能量进入系统。

谐振

受迫振荡最有趣的部分是外部周期性力的频率与系统振荡的固有频率 ($\omega \approx \omega_0$) 一致的情况。

在这种情况下，第一个方程是（9），可以写成如下：

$$a_x = -\omega_0^2 x,$$

与第三项等于 $\omega_0^2 x$ 相互抵消。这两项在任何时刻的大小都相同，但符号相反，因为任何简谐振动的加速度和坐标都异相 π。

因此，方程（9）的形式为：

$$\mu v_x = F_0 \cos \omega_0 t.$$ (15)

这是一个简单的方程，包含了共振的本质。在任何时刻$\omega \approx \omega_0$（让我们再次强调，我们正在谈论稳定的受迫振荡），外力似乎会关闭游戏中的摩擦仆人。因此，加速度仅来自弹性。本质上，实现了一种非常小的情况：尽管有摩擦的影响，简谐振动在系统中存在任意长的时间。

从（15）可以清楚地看出，在共振期间，速度振荡的相位与外力的相位一致。在这些条件下，外力所做的功在整个长度上都是正的
