⟦folio 34⟧

昵称$S$退化为三角形$OAC$，多边形$P$和$Q$退化为平行四边形$OABC$和$OGEH$（图4）。条件是用与其面积相同的字母来表示多边形本身：$S$、$P$ 和 $Q$。 （可以想象，在图 4 上描绘了三个$n$边形（$n \geq 4$），其所有顶点（除了两个$S$和三个$P$和$Q$）都非常靠近点$O$。很明显，如果我们可以构造一个退化示例，其中$S^2 < PQ$，那么，如果我们“移动”它的轨迹，我们就可以得到一个真实的、非简并的$n$边形的例子。

我们假设顶点$O$，$A$，$B$，$C$是固定的，$E$可以沿着线段$AC$移动（在这种情况下，点$G$和$H$沿着线段$OA$和$OC$移动）。

请注意，如果$E$落在$OB$和$AC$的交点$E_0$，则四边形也会被$S^2 = PQ$细分。事实上，在这种情况下，$P/S$、$S/Q$的面积比以及$P$、$S$和$Q$被线$OB$划分成的三角形的相应面积比都等于相对的$\frac{|OA|}{|OG_0|} = \frac{|OB|}{|OE_0|} = \frac{|OC|}{|OH_0|}$（图5）。

现在我们来看看线段$AC$上的点$E$在什么位置，两个三角形$AGE$和$HEC$的面积之和最小。设$H'$为线$AB$和$CD$的交点，$G'$为线$CB$和$AD$（D为平行四边形$OADC$、图6的第四个顶点），$M_1$和$M_2$为面积三角形$AH'C$和$AG'C$。如果点$E$在相对$\frac{|AE|}{|EC|} = \frac{t}{1-t}$（$0 < t < 1$）中除线段$AC$，则三角形$AGE$和$HEC$的面积之和等于$M_1t^2 + M_2(1-t)^2 = (M_1 + M_2)t^2 - 2M_2t + M_2$ (6)

且在 $t = t^* = \frac{M_2}{M_1 + M_2}$ 处最小，即，对于相对于 $\frac{t^*}{1-t^*} = \frac{M_2}{M_1}$ 划分线段 $AC$ 的点 $E^*$。

并且四边形$OGEH$（在固定点$O$、$A$、$B$、$C$）在$E = E^*$位置处的面积$Q$最大。

练习5°。通过梯形 $ABCD$ 对角线 $AC$ 上的点 $E$ 画一条平行于梯形底边的直线，并在点 $G$ 和 $H$ 处与边 $AB$ 和 $CD$ 相交。在点$E$的什么位置，三角形$AGE$和$HEC$的面积之和最小？

回答。当$\frac{|AE|}{|EC|} = \frac{|AD|}{|BC|}$时，即点$E$与对角线交点（$|GE| = |EH|$）重合时。

所以，我们知道对于$E = E_0$，满足等式$Q = S^2/P$，而对于$E = E^*$，面积更大！

仅当对于三角形$ADC$内的点$B$的任何选择，点$E^*$与$E_0$重合时，我们才能尝试构建定义不等式（5）的示例，即等式

$$\frac{|AE_0|}{|E_0C|} = \frac{M_2}{M_1}$$ (7)

（其中$M_1 = S_{\triangle AH'C}$，$M_2 = S_{\triangle AG'C}$）。

看起来，为什么这些关系要相互联系呢？
