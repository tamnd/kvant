⟦folio 44⟧

图 3. 充满光的云球是您可以从中绘制到另一个球体的切线的云球。

M255。 AB 和 CD 是两个给定球的不同切线（A 和 C 属于同一球的表面，B 和 D 属于其他球的表面）。证明线段 AC 和 BD 在穿过球中心的直线上的投影相等。

令$O_1$和$O_2$为球的中心，$|O_1A| = |O_1C| = r_1$和$|O_2B| = |O_2D| = r_2$为球的半径，$|O_1O_2| = d$、$|AB| = l$、$|CD| = m$、$\Rightarrow AO_1O_2 = \varphi$、$\Rightarrow CO_1O_2 = \psi$。

则线段AC在直线$O_1O_2$上的投影长度等于
$$\|AO_1\| \cos \varphi - |CO_1| \cos \psi| = |r_1 \cos \varphi - r_1 \cos \varphi|.$$ (1)

根据 $\triangle AO_1O_2$ (图 3) 的余弦定理
$$|AO_2|^2 = r_1^2 + d^2 - 2r_1 d \cos \varphi.$$ (2)

由于角度 $ABO_2$（切线和半径之间）是直角，
$$|AO_2|^2 = |AB|^2 + |B_2O|^2 = l^2 + r_2^2.$$ (3)

由(2)和(3)我们得到
$$2dr_1 \cos \varphi = r_1^2 + d^2 - r_2^2 - l^2.$$ (4)

同样找到
$$2dr_1 \cos \psi = r_1^2 + d^2 - r_2^2 - m^2.$$ (5)

从 (1)、(4) 和 (5) 可以得出，线段 AC 在 $O_1O_2$ 上的投影具有长度
$$\frac{|l^2 - m^2|}{2d}.$$

显然，投影线段BD具有相同的长度。

让我们提出这个问题的另一种解决方案，它更清楚地揭示其几何背景。问题 M255 (图 4) 的平面模拟表明切线的位置应使其中点投影到直线 $O_1O_2$ 上的同一点，即两个给定球的切线的所有中点应位于同一平面内，垂直于分线。我们将证明一个更一般的陈述。

图 4. 若将中点AB、CD投影到同一点P，则线段AC、BD在线心上的投影相同。

定理。两个给定球的切线具有相同长度的所有点 M 位于同一平面内，垂直于分线 $O_1O_2$ 并在最高点 P 处相交 $O_1O_2$，其中
$$|PO_1|^2 - |PO_2|^2 = r_1^2 - r_2^2.$$ (6)

请注意，最后一个等式唯一地确定了点 P 在直线 $O_1O_2$ 上的位置：如果在直线 $O_1O_2$ 上我们选择一个坐标系，使得点 $O_1$ 和 $O_2$ 接收坐标 0 和 d，则点 P 的 x 坐标由方程 $x^2 - (x - d)^2 = r_1^2 - r_2^2$ 唯一确定：
$$x = \frac{r_1^2 - r_2^2 + d^2}{2d}.$$

现在我们来证明这个定理。这里最值得注意的是，我们可以立即转到平面问题：毕竟，从 M 点到每个球，我们可以画出许多（整个“圆锥体”）切线，非常印度，长度相等，并且我们总是可以选择其中位于平面 $MO_1O_2$ (图 5) 中的切线。在这个图 5中，从M点到每个球所画的所有切线的长度都是相同的。
