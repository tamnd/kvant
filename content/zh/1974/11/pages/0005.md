⟦folio 3⟧

如果参考系的原点与负载静止时因负载而变形的弹簧末端相结合 (图 1)，则可从运动方程得出。让我们将坐标轴$OX$垂直向下。那么只有在弹力$F_y = -kx$的作用下才会发生振荡，其中$k$是弹性系数，$x$是载荷离开平衡位置的位移。运动方程将写成如下：

$$ma_x = -kx. \tag{1}$$

将该方程除以 $m$ 并引入符号 $\omega_0 = \sqrt{\frac{k}{m}}$，我们得到了描述具有循环频率 $\omega_0$ 的简谐振动的方程的普遍接受的形式：

$$a_x = -\omega_0^2 x. \tag{2}$$

这个方程的解，即找到函数$x = x(t)$，可以通过基本但相当漫长的方式获得。结果是：

$$x = x_0 \cos(\omega_0 t + \varphi_0). \tag{3}$$

这里$x_0$是振荡幅度，$\varphi_0$是初始相位。这些量是根据初始条件求得的。

显然，我们通过向下拉动并释放弹簧来激发弹簧上的重物的振动。此外，在初始时刻（$t = 0$）$x = x_0$和$v_x = 0$。这与$\varphi_0 = 0$相匹配。然后

$$x = x_0 \cos \omega_0 t. \tag{4}$$

谐波振荡可以用等式来描述。

图 1.

新的三角测量函数余弦和正弦。我们可以这样写：

$$x = x_0 \sin(\omega_0 t + \varphi_0). \tag{5}$$

但在通常的初始条件下$\varphi_0 = \frac{\pi}{2}$，而不是零。因此，通过余弦写入是比较可取的，当然，您也可以使用正弦。

简谐振动时的速度也根据简谐定律而变化。其幅度等于$v_0 = \omega_0 x_0$，相对于坐标的相移等于$\frac{\pi}{2}$：

$$v_x = \omega_0 x_0 \cos\left(\omega_0 t + \frac{\pi}{2}\right) = -\omega_0 x_0 \sin \omega_0 t. \tag{6}$$

加速度与坐标异相振荡（异相$\pi$），振幅为$a_0 = \omega_0^2 x_0$，即

$$a_x = \omega_0^2 x_0 \cos(\omega_0 t + \pi) = -\omega_0^2 x_0 \cos \omega_0 t. \tag{7}$$

这就是您需要了解进一步相对自由简谐振动的全部内容。

受迫振动的运动方程

让外部周期力 $F_x = F_0 \cos \omega t$ 作用在振荡系统上（在我们的示例中是弹簧上的负载）。此外，身体还受到弹力$F_y = -kx$和与速度成比例的摩擦力$F_{\tau p} = -\mu v_x^*$），其中$\mu$是摩擦系数。那么运动方程将写成这样：

$$ma_x = -kx - \mu v_x + F_0 \cos \omega t. \tag{8}$$

将除外部力之外的所有力穿过方程左侧，我们得到：

$$ma_x + \mu v_x + kx = F_0 \cos \omega t.$$

*）在身体低速运动时，我们确实可以假设摩擦力（或者换句话说，阻力）与速度成正比。
