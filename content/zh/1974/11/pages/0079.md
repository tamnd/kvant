⟦folio 77⟧

三角形。是否可以检查另一条与底面不平行但具有相同属性的线？

新任务出现了。

问题6. 等边三角形的各条边与与给定三角形的一条平行线相交，使得两条边之间围成的线段等于该线所截下的与底边相邻的线段之和。

解决了这个问题，我们会发现我们找到了解决问题1的第五种方法，该方法如下。我们构造一个等边三角形 $A_1BC_1$ (图 4)，其角 $B$ 是给定的，$|A_1B| = |BC_1| = p$。我们画一条直线 $MN$ 使得 $BMN = \hat{A}$ （到 Iz 三角形的第二个给定角度）。接下来我们构建$\hat{BA}_1O = \frac{1}{2}BMN$和$\hat{BC}_1O = \frac{1}{2}BNM$，并通过点$O$我们绘制$(AC) \parallel (MN)$。三角形 $ABC$ 是倾斜的。

要找到第六种方法，假设解题三角形 $ABC$ 是倾斜的 (图 5)。我们先把$|AC_1| = 2p$放在一边，画出$(B_1C_1) \parallel [BC]$和$(BB_1) \parallel (AC_1)$。很容易验证$|BB_1| = |CC_1| = 2p - |AC| = |AB| + |BC|$。然后我们标记一个点$O$，使得$[BO] \cong [AB]$，然后$[OB_1] \cong [B_1C_1]$，因此$\hat{BA}O = \hat{AOB}$，以及$\hat{B}_1OC_1 = B_1C_1O$。考虑$(BB_1) \parallel (AC_1)$，我们得出结论：$[AO]$和$[C_1O]$是角$BAC_1$和$B_1C_1A$的平分线。

所有这些论点导致以下构造：$|AC_1| = 2p$、$\hat{BAC_1} = \hat{A}$和$B_1C_1A = \hat{C}$（$A$和$C$是伊兹斯基三角形的给定角度）。接下来，我们绘制角度 $\hat{BAC_1}$ 和 $B_1C_1A$ 的二等分线 $AO$ 和 $C_1O$，并通过它们的交点 $(O)$，我们绘制 $(BB_1) \parallel (AC_1)$，最后，$[BC] \parallel (B_1C_1)$。这样形成的三角形$ABC$是倾斜的。

练习

1. 将顶点无法到达的角分成两半。
2. 通过一个点和给定角度的不可到达的顶点绘制一条直线。
3. 将此部分分成三个相等的部分。
4. 如果三角形的中线等于其所画边的一半，则该三角形是直角三角形。
5. 证明在任意三角形中，高的底边、边的中点以及连接垂心与三角形顶点的线段的中点都在同一个圆上，圆心是连接外接圆中心与三角形垂心的线段的中点。 （这个圆称为第九点圆或欧拉圆。）
