⟦folio 62⟧

图 2.

椭圆轨道，长半轴为$a = (R + R_0)/2$。根据开普勒第三定律

$$\left(\frac{T_3}{T_K}\right)^2 = \left(\frac{a}{R}\right)^3,$$

其中$T_3$是椭圆轨道上卫星的公转周期，$T_K$是圆形轨道上的卫星公转周期。卫星在圆形轨道上的公转周期等于

$$T_K = \frac{2\pi R}{v} = \frac{2\pi R}{\sqrt{\gamma M}/R} = 2\pi R \sqrt{\frac{R}{\gamma M}}.$$

那么它在椭圆轨道上的公转周期等于

$$T_3 = 2\pi R \sqrt{\frac{R}{\gamma M}} \left(\frac{R + R_0}{2R}\right)^{3/2}.$$

从制动到着陆，卫星仅运行一半轨道（见图2）。这就是为什么

$$t = \frac{T_3}{2} = \pi R \sqrt{\frac{R}{\gamma M}} \left(\frac{R + R_0}{2R}\right)^{3/2} = \frac{\pi}{\sqrt{\gamma M}} \left(\frac{R + R_0}{2}\right)^{3/2}.$$

如果卫星到地球表面的距离不大，即$R \approx R_0$，则可以通过公式：

$$t = \frac{\pi}{R_0 \sqrt{g}} \left(\frac{R_0 + R}{2}\right)^{3/2}.$$

到目前为止，我们都忽略了大气中的摩擦力。现在让我们考虑一下卫星在大气层上层的减速情况。我们假设卫星的初始轨道是圆形的，制动台不是圆形的

如此之大以至于任何特定的转弯都可以被视为具有足够精度的圆。

卫星的总能量等于其动能和势能之和。卫星的势能是$-Mm\gamma/R$，动能是$mv^2/2$。但卫星在轨道上的速度为$v = \sqrt{\gamma M/R}$。那么卫星的动能

$$W_{\text{кин}} = \gamma \frac{mM}{2R},$$

也就是说，它仅由轨道半径决定，并且始终是势能的一半（绝对值）。卫星的总能量为负：

$$W_{\text{пол}} = -\frac{\gamma}{2} \frac{mM}{R}.$$

制动前让卫星在半径$R_1$的轨道上飞行并有速度

$$v_1 = \sqrt{\frac{\gamma M}{R_1}}.$$

卫星在上层大气层制动后，进入半径为$R_2$的轨道，小于$R_1$（由于制动不能飞得更高），动能等于$W_2 = \gamma mM/2R_2$；因此，它的速度由下式给出

$$v_2 = \sqrt{\frac{2W_2}{m}} = \sqrt{\frac{\gamma M}{R_2}}.$$

如果我们比较式（3）和（2），我们可以看到，由于制动，卫星的速度增加了（$R_2 < R_1$！）但这已经是轨道运动的规律，因为上面提到的总能量在动能和势能之间的比例分配。由式（1）可知，总能量随着轨道半径的减小而减小（为负），因此能量守恒定律根本不存在
