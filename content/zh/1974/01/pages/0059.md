问题 7（密歇根州立大学经济学院，1973 年）。

函数 $y = \frac{2+x}{x}$ 的图形与一条与 x 轴形成角度 $\alpha$ 的直线相交于两点。连接坐标原点与 Ox 轴上交点投影的线段长度之间的几何名称。

在这个问题中，最重要的是其条件的确切概念并用公式语言表达出来。

函数 $y = 1 + 2/x$ 的图像是一条双曲线（画图！）。因此，问题陈述中讨论的直线是倾斜的（即$\alpha \neq \pi/2, \alpha \neq 0$），并且该双曲线不能与垂直线或水平线在两点相交。换句话说，直线方程的形式为

$$y = x \mathrm{tg} \alpha + b,$$

$\mathrm{tg} \alpha \neq 0$。双曲线和直线相交于两点的事实意味着方程

$$\frac{2+x}{x} = x \mathrm{tg} \alpha + b,$$

或者，相同的是，方程 $x^2 + x (b - 1) \mathrm{tg} \alpha - 2 \mathrm{tg} \alpha = 0$ (4) 有两个不同的实根（因为 $x = 0$ 不是方程 (4) 的根）。问题陈述表明这一事实发生了。

若式(4)的根为$x_1$和$x_2$，则坐标原点与直线和双曲线交点在Ox轴上的投影的线段长度分别等于对应的$|x_1|$和$|x_2|$。因此，我们需要计算数量

$$\sqrt{|x_1| \cdot |x_2|} = \sqrt{|x_1 x_2|},$$

其中$x_1$和$x_2$是方程(4)的根。使用 Vieta 定理可以很容易地做到这一点：

$$\sqrt{|x_1 x_2|} = \sqrt{2 |\mathrm{ctg} \alpha|}.$$

现在让我们考虑几个与二次三项式无关的例子。

在许多与实数和复数模型相关的示例中，模型的几何解释提供了重要的帮助：$|x - y|$是形成复数的点之间的距离，特别是实数$x$和$y$。

问题 8. 求解方程 $|x + 2| + |x - 3| = 5$ ($x - \text{дейстимелевое число}$)。

在这个问题的几何语言中，它可以这样形成：找到数轴上到点$-2$和$3$的距离之和等于5的所有点。这个翻译立即解决了问题：事实上，线段$-2 \leq x \leq 3$上的任何点都具有这个属性，并且对于线段之外的任何点，距离之和大于5。

因此，该方程的解都是来自线段$-2 \leq x \leq 3$的$x$。

问题 9. 求解不等式 $\left| \frac{2x - 3}{2x + 5} \right| > 1$。

利用模型$\left| \frac{a}{b} \right| = \frac{|a|}{|b|}$的属性，我们将这些不等式重写为$|2x - 3| > |2x + 5|$、$2x + 5 \neq 0$的形式，并将问题表述如下：找到$2x$比$k = 3$和$x \neq -2, 5$更接近于$-5$的点$x$。这个条件就等于$2x < -1$，$x \neq -2, 5$，即$x < -2, 5$； $-2, 5 < x < 0, 5$。这就是这个不平等的解决方案。
