重新定义问题

小学生数学准备的重大缺陷之一是解决问题的方法过于直接，这在高等教育入学考试中经常明显地表现出来。在大多数情况下，申请者是如此执着于这个条件，执着于问题的这种表述，以至于他们不同意以稍微不同的方式看待问题，另一方面，试图用其他术语来表述它的条件，简而言之，寻找一种不停留在表面上的解决方法。

与此同时，正是对问题的重新表述，以新的方式表述，往往能够阐明问题的真正含义，并且是解决问题的直接途径。此外，申请人从不同角度、不同解释来考虑问题的能力，是其数学（通常是一般性）发展的最重要标志之一，也是其在大学继续深造的条件之一。必须强调的是，所说的不仅仅是数学。

当然，学童充分精通重新表述问题的基本技术，或者更准确地说，最自然的技术，因为这些技术是一般学校实践的一部分。因此，大多数申请者完全有能力解决所谓的“技术”问题，但解决此类问题的基础是典型的重新表述：问题以通用的“日常”语言编写的一组特定条件的形式给出，求解者通常会列出一些方程，有时是不等式，即将这些条件翻译成数学语言，然后用纯数学术语解决问题。相比之下，请记住，在较低年级，此类问题是直接解决的，具有相当狡猾的推理，但没有任何代数关系，而且想出解决方案也困难得多。

另一个例子是解决几何问题。如果问题可以转化为方程语言，如果数据和几何构型的未知元素之间的对应关系很容易写出来，那么通常来说，问题就可以毫无困难地解决。相反，如果这种解决问题的方法不适用，那么它就会困难得多——你需要想出纯粹的几何想法，而这是完全不同的事情——除了计算技术之外，你还需要良好的几何直觉、几何理解和更活跃的几何知识。

重新构建问题意味着什么？显然，严格来说，这个问题是不可能给出准确答案的。但命运就是问题表述的条件

是用另一种语言，用其他或多或少相似的术语编写的。重构技术如此多样，几乎不可能以合理的方式列出和描述它们，你只能在实践中掌握它们，解决足够数量的例子。

重新表述问题的最重要方法之一，其应用，粗略地说，是数学的实践、应用方面，是将真实的生活情境“翻译”成形式语言、精确的数学陈述的语言。在学校数学实践中，在升学考试的练习中，文字“翻译”成公式、简洁化的情况也经常出现。

因此，为了证明“函数$y = \cos x$在间隔$0 \leq x \leq \pi$上杀死”这一陈述，应该将其重新表述为“给定：$0 \leq x_1 < x_2 \leq \pi$；证明$\cos x_1 > \cos x_2$”。而“以$a$为底的数$N$的对数是一个数$\alpha$，使得$a^\alpha = N$”被重新表述为“$a^{\log_a N} = N$”，因此基本对数证明只是对数定义的形式化表示法。如果这一切都很好理解，那么“为什么$(\sqrt{a})^2 = a?$”、“为什么 sin (arcsin $x$) = $x$？”之类的“棘手”问题就会出现。 ETC。

另一方面，“反向翻译”也很重要——能够在某些形式平等的证明中看到其复杂的表达。例如，将公式$\sqrt[n]{a^m} = \left( \sqrt[n]{a} \right)^m$读作“$\left( \sqrt[n]{a} \right)^m$是$a^m$的$n$度数的根”，我们立即通过定义根，通过证明这个公式得到：

$$\left( \sqrt[n]{a} \right)^m = \left( \sqrt[n]{a} \right)^m = a^m.$$

对数的基本公式可以用同样的方法证明。一般来说，反函数的各种性质——根、对数、反三角函数——都是通过将相应的“直接”函数翻译成语言来精确证明的。

让我们看几个例子，这些例子显示了重新制定的有效性——有时是有针对性的，有时是意想不到的。

首先，与二次三项式有关的几个问题。

问题1. 对于什么a，方程$x^2 + ax + a = 0$的根大于1？

大多数申请者都认真地寻找根源来解决这个问题

$$x_1 = \frac{-a + \sqrt{a^2 - 4a}}{2},$$

$$x_2 = \frac{-a - \sqrt{a^2 - 4a}}{2}$$

并解决一个不等式系统 - 有时是两个（$D \geq 0, x_2 > 1$），如果他们同意$x_2$是一个较小的根，并且它大于1就足够了，并且通常是三个不等式：$D \geq 0, x_1 > 1, x_2 > 1$。

如果有一个很好的技术解决方案来解决非理性的不平等，那么这条道路当然可以达到目标。然而，如果你稍微退一步并应用维塔定理，你会立即发现所需的$a$值并不存在：这些根的乘积$a$必须大于1，并且它们的总和$(-a)$也将是正数。

有趣的是，如果在这个问题中你问：哪个 a 的根是正的，那么很多人都同意应用 Vieta 定理 - 毕竟，这是它的标准应用！

任务 2. 对于什么 a，不等式 $1 < x \leq 2$ 意味着不等式 $x^2 - 2ax + a < 0$？

问题的条件显然意味着三项式$f(x) = x^2 - 2ax + a$在线段$1 < x \leq 2$上为负，这相当于线段$1 < x \leq 2$位于该三项式的根之间的条件（因为$x^2$的系数为正）。但最后一个条件相当于线段的末端位于根部之间的事实，并且最后仍然报告该条件相当于不等式$f(1) \leq 0, f(2) < 0$系统，或者
$$\begin{cases} 1 - a \leq 0, \\ 4 - 3a < 0, \end{cases}$$
从哪里$a > 4/3$。

任务 3. 证明方程 $f(x) = (x - a)(x - b) + (x - a)(x - c) + (x - b) \times (x - c) = 0$ 对于任意 $a, b$, c 有实根。

很容易想象，这个问题的“直接”解决方案 - 打开括号并证明所得二次三项式的判别式为正 - 会带来巨大的计算困难，并且我们将使用这样的事实：二次三项式（具有正的前导系数）当且仅当它在至少一个点处取负值或零值时才具有实数根。很自然地查看其在点 $a, b, c$ 处的值 - 那么这三项中只剩下一项了。

我们有
$$f(c) = (c - a)(c - b);$$
所得乘积的符号取决于点 $a, b, c$ 在数值轴上的相对位置，如果 $c$ 位于 $a$ 和 $b$ 之间，则该乘积为负。但这三个数字中的一个位于其他两个之间，我们得到了解决方案：让，为了定义，$a \leq b \leq c$；那么$f(b) = (b - a)(b - c) \leq 0$，因此三项式在$b$点取负值或零值，因此有实根。

在所考虑的三个示例中，问题条件显然包含二次三项式，因此问题的重新表述与其条件相差不远。让我们看一些其他的例子。

任务 4（密歇根州立大学心理学系，1969 年）。证明$x^2 + 19y^2 + 6z^2 - 8xy - 4xz + 12yz > 0$如果$x^2 + y^2 + z^2 > 0$。

尝试在没有定义的情况下随机分组在这里很难成功，但在左侧看到关于$x$的平方三项式（带有“参数”$y$和$z$）就足够了，并且分组的方法变得完全清晰 - 隔离出一个完整的正方形。如果我们还注意到，经过这个变换，“自由项”将是关于 $y$ 的二次三项式（带有“参数”$z$），那么问题就可以被认为实际上已经解决了。

所以等式左边可以改写为
$$x - 4y - 2z)^2 + 3y^2 + 2z^2 - 4yz =
(x - 4y - 2z)^2 + 3\left(y - \frac{2}{3}z\right)^2 + \frac{2}{3}z^2,
$$
因此对于 $x, y, z$ 的所有值都是非负的。

可以为零吗？显然，只有当所有三项都等于 0 时，即同时满足等式时，才会发生这种情况
$$x - 4y - 2z = 0, y - \frac{2}{3}z = 0, z = 0.$$

但从这些等式可以立即得出$x = y = z = 0$，这与条件$x^2 + y^2 + z^2 > 0$相矛盾。至此，该命题得到完全证明。

问题 7（密歇根州立大学经济学院，1973 年）。

函数 $y = \frac{2+x}{x}$ 的图形与一条与 x 轴形成角度 $\alpha$ 的直线相交于两点。连接坐标原点与 Ox 轴上交点投影的线段长度之间的几何名称。

在这个问题中，最重要的是其条件的确切概念并用公式语言表达出来。

函数 $y = 1 + 2/x$ 的图像是一条双曲线（画图！）。因此，问题陈述中讨论的直线是倾斜的（即$\alpha \neq \pi/2, \alpha \neq 0$），并且该双曲线不能与垂直线或水平线在两点相交。换句话说，直线方程的形式为

$$y = x \mathrm{tg} \alpha + b,$$

$\mathrm{tg} \alpha \neq 0$。双曲线和直线相交于两点的事实意味着方程

$$\frac{2+x}{x} = x \mathrm{tg} \alpha + b,$$

或者，相同的是，方程 $x^2 + x (b - 1) \mathrm{tg} \alpha - 2 \mathrm{tg} \alpha = 0$ (4) 有两个不同的实根（因为 $x = 0$ 不是方程 (4) 的根）。问题陈述表明这一事实发生了。

若式(4)的根为$x_1$和$x_2$，则坐标原点与直线和双曲线交点在Ox轴上的投影的线段长度分别等于对应的$|x_1|$和$|x_2|$。因此，我们需要计算数量

$$\sqrt{|x_1| \cdot |x_2|} = \sqrt{|x_1 x_2|},$$

其中$x_1$和$x_2$是方程(4)的根。使用 Vieta 定理可以很容易地做到这一点：

$$\sqrt{|x_1 x_2|} = \sqrt{2 |\mathrm{ctg} \alpha|}.$$

在许多与实数和复数模型相关的示例中，模型的几何解释提供了重要的帮助：$|x - y|$是形成复数的点之间的距离，特别是实数$x$和$y$。

问题 8. 求解方程 $|x + 2| + |x - 3| = 5$ ($x - \text{дейстимелевое число}$)。

在这个问题的几何语言中，它可以这样形成：找到数轴上到点$-2$和$3$的距离之和等于5的所有点。这个翻译立即解决了问题：事实上，线段$-2 \leq x \leq 3$上的任何点都具有这个属性，并且对于线段之外的任何点，距离之和大于5。

因此，该方程的解都是来自线段$-2 \leq x \leq 3$的$x$。

问题 9. 求解不等式 $\left| \frac{2x - 3}{2x + 5} \right| > 1$。

利用模型$\left| \frac{a}{b} \right| = \frac{|a|}{|b|}$的属性，我们将这些不等式重写为$|2x - 3| > |2x + 5|$、$2x + 5 \neq 0$的形式，并将问题表述如下：找到$2x$比$k = 3$和$x \neq -2, 5$更接近于$-5$的点$x$。这个条件就等于$2x < -1$，$x \neq -2, 5$，即$x < -2, 5$； $-2, 5 < x < 0, 5$。这就是这个不平等的解决方案。

问题 11（密歇根州立大学心理学家学院，1971 年）。找到 $x$ 的所有值使得
$$\min \{2x - x^2, x - 1\} > -\frac{1}{2}.$$
众所周知，在问题的表述中使用表达式$A = \min \{2x - x^2, x - 1\}$可以理解为以下含义：对于任何固定的$x = x_0$，A意味着两个数字$2x_0 - x_0^2$和$x_0 - 1$中的较小者。

这个问题的“直接”解决方案需要考虑两次合并：$2x - x^2 \leq x - 1$和$x - 1 < 2x - x^2$。在每次合并中，您都需要求解二次不等式并显示其解，分别满足条件 $2x - x^2 > -1/2$ 和 $x - 1 > -1/2$。

同时，不难发现，当两个表达式大于$-1/2$时，两个表达式中的最小值都大于$-1/2$，因此问题的条件等价于一个不等式系统
$$\begin{cases} 2x - x^2 > -\frac{1}{2}, \\ x - 1 > -\frac{1}{2}, \end{cases}$$
解决这个问题似乎并不困难。结果将是答案：$\frac{1}{2} < x < \frac{2 + \sqrt{6}}{2}$。

问题 12（密歇根州立大学心理学家学院，1972 年）。找到不等式的所有整数解
$$x - 1 < \log_6 (x + 3).$$
ODZ不等式只包含$x > -3$，很容易无限验证数字$-2, -1, 0$和1是它的解。将下面的整数值代入$x$，我们发现它们都不是解，而且很容易注意到“越远越差”——随着$x$的增加，方程左右两边的差相等。因此，剩下的就是严格证明这个说法了。

换句话说，我们收到了以下任务：证明该函数
$$f(x) = x - \log_6 (x + 3)$$ - 返回。然而，这个任务相当困难，但我们只对参数的整数值感兴趣，所以我们只需要确保这个函数在加 1 时返回。我们有
$$f(x + 1) - f(x) = (x + 1) - \log_6 (x + 4) - x + \log_6 (x + 3) = \log_6 \frac{x + 3}{x + 4} + 1,$$
所以不平等 $f(x + 1) - f(x) > 0$ 相当于不平等 $\frac{x + 3}{x + 4} > \frac{1}{6}$，很容易看出，其中正 $x$ 显然是满足了。

因此，我们的不等式对于任何大于1的整数$x$都不成立，上面得到的值就是问题的解。
