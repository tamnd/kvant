将系统(16)的前两个方程相加，并考虑$(F_{12}\Delta s_1) + (F_{21}\Delta s_2)$为系统I相互作用能的变化，带负号，$(F_{13}\Delta s_1) + (F_{23}\Delta s_2)$为外力做功，可得

$$\Delta (K_1 + K_2) + \Delta I_1 = A_{\text{внешш}}.$$ (17)

一个熟悉的结果：系统机械能的变化等于外力的功。

根据系统第三方程 (16)

$$\Delta K_3 = A'.$$ (18)

其中 $A'$ 是系统 I 的力对系统 II 的功。

将方程（17）和（18）相加，我们有

$$\Delta (K_1 + K_2) + \Delta I_1 + \Delta K_3 = \Delta E_1 + \Delta E_{II} = A_{\text{внешш}} + A'.$$ (19)

这里$E_1 = K_1 + K_2 + \Pi_1$是第一个系统的总能量，$E_{II} = K_3$是第二个系统的能量。由此可见

$$A_{\text{внешш}} = -A'.$$

如果

$$\Delta E_1 = -\Delta E_{II},$$ (20)

也就是说，如果第一个系统的能量减少等于第二个系统的能量增加（反之亦然）。

系统与外部物体相互作用的势能

如果我们引入所考虑的系统相互作用势能的概念，则功相等的条件（等式（14））可以写成不同的形式。让我们以扩展形式重写方程（19），代入功$A_{\text{внешш}}$和$A'$的表达式：

$$\Delta E_1 + \Delta E_{II} = (F_{13}\Delta s_1) + (F_{23}\Delta s_2) + (F_{31}\Delta s_3) + (F_{32}\Delta s_3).$$ (21)

令系统 I 与系统 II 的相互作用力保持保守。然后$(F_{13}\Delta s_1) + (F_{31}\Delta s_3) = -\Delta I_{13},$和$(F_{23}\Delta s_2) + (F_{32}\Delta s_3) = -\Delta I_{23},$，其中$I_{13}$和$I_{23}$是物体1-3和2-3相互作用的势能。和

$$\Pi_{13} + \Pi_{23} = \Pi_{I-II}$$ (22)

代表系统 I - II 相互作用的势能。它可以称为系统I与外部物体3相互作用的势能。

现在我们将等式（22）写如下：

$$\Delta E_1 + \Delta E_{II} = -\Delta I_{I-II}.$$ (23)

这意味着$\Delta E_1 = -\Delta E_{II}$，因此在$\Delta I_{I-II} = 0$时，即系统相互作用势能不变时，也意味着$A_{\text{внешш}} = -A'$。

当它们相互作用的电机能量（延伸的传动带的能量）保持不变时。如果地球上有一块石头，相互作用的势能就会发生变化。因此，在第一种情况下$A_{\text{внешш}} = -A'$，在第二种情况下这个等式不成立。

力学中与速度相关的力是摩擦力。与所有力一样，摩擦力会改变系统的动能。而且，虽然摩擦力可以做正功，但系统内部摩擦力的总功始终是负的，它们减少了系统的动能。通过这个例子你就能明白为什么会发生这种情况。
