读者建议
N.Kh.罗佐夫

在一般社论邮件«Kvant»中，有许多信件讨论了学校数学和物理课程的某些理论问题，提出了解决某些类型问题的方法，并包含了方法论性质的个人评论和观察。尽管读者给出的信息和任务并不总是新颖和原创的，但我们认为，信中提出的许多问题是申请人感兴趣的。

因此，今天所需的文章发表在“申请人工作室”：编辑们正在出版数学材料选集，这些材料是根据读者来信的想法和建议编写的。我们希望这样的收藏能够提供及时的经验和想法。

在入学考试中，他们经常提供此类任务：找出（不使用表格）哪个更大：$\log_a M$或$\log_b N$，其中$a, b, M, N$是给定的数字，当然还有$a > 0, a \neq 1, b > 0, b \neq 1, M > 0, N > 0$。在“申请人研讨会”（见«Kvant»，1972年第3期）中已经给出了解决类似问题的例子。读者 V.A. Grubyan（别列兹尼基，彼尔姆地区）提请注意使用以下示例来比较两个数字的对数大小的可能性。

如果我们能找到一个整数 $k$ ，那么解决问题就非常简单了，比如说：

$$\log_a M < k, k < \log_b N.$$

因此，最有趣的情况是当

$$k - 1 < \log_a M < k,$$
$$k - 1 < \log_b N < k.$$

在这种情况下，应该努力选择一个自然数$n$，使得$n$和$n \log_b N$之间存在某个整数$p$。通过连续的试验来选择具有指定属性的数字$n$。

示例 1. 比较 $\log_3 4$ 和 $\log_7 10$。

很容易检查$1 < \log_3 4 < 2, 1 < \log_7 10 < 2$，但从这里并不清楚哪个建议的对数更大。让我们取$n = 2$；我们得到$2 \log_3 4 = \log_3 16, 2 \log_7 10 = \log_7 100$。由于 $2 < \log_3 16 < 3$ 和 $2 < \log_7 100 < 3$（请确保这一点！），因此值 $n = 2$ 不具有所需的属性。同样，我们检查值 $n = 3$ 是否不适合我们。

对于$n = 4$，我们得到：

$$4 \log_3 4 = \log_3 256, 4 \log_7 10 = \log_7 1000.$$

由于$3^5 = 243, 3^6 = 729$和$7^4 = 2401, 7^5 = 16807$，然后$5 < 4 \log_3 4 < 6, 4 < 4 \log_7 10 < 5$，因此值$n = 4$具有所需的属性（$p$的角色由数字5扮演）。从这里我们得到

$$\log_3 4 > \log_7 10.$$

示例 2. 两个数字中哪一个更大：$\log_{\sqrt{2}} \frac{6}{11}$ 或 $\log_{2/5}$？

直接验证两个数都在-2到-1之间。取 $n = 2$ 我们得到

$$2 \log_2 \frac{6}{11} = -\log_2 \frac{11^4}{6^4},$$

哪里容易找到什么
$$-4 < 2 \log_2 \frac{6}{11} < -3.$$

另一边，
$$2 \log_2 \pi = \log_2 \pi^2,$$
简单的计算表明
$$-3 < \log_2 \pi^2 < -2.$$

因此，$\log_2 \frac{6}{11} < \log_2 \pi$。

当然，选择所需的$n$所需的试验次数在不同的问题中是不同的（并且可能很大），但重要的是总会有这样一个$n$。也就是说，我们将证明以下陈述，这是所使用技术的理论基础：如果$\log_a M \neq \log_b N$，则存在一个自然数$n$，使得$n \log_a M$和$n \log_b N$之间存在某个整数。

设$\alpha = \log_a M$、$\beta = \log_b N$、$\alpha \neq \beta$。例如，让我们假设$\alpha > \beta$（$\alpha < \beta$的情况进行类似处理）。那么$\alpha - \beta$是一个正数，因此存在一个自然数$n$使得分数$1/n$小于这个正数：$\frac{1}{n} < \alpha - \beta$或$n\alpha - n\beta > 1$。但最后一个不等式意味着数字$n\alpha = n \log_a M$和$n\beta = n \log_b N$相差不止一，这意味着这些数字之间必须存在某个整数。

总之，让我们回忆一下确定数字（或表达式）$\alpha$和$\beta$之间不等号的一种通用方法：选择一个数字（表达式）$\gamma$很重要，例如，$\alpha < \gamma$同时也有$\gamma < \beta$。上面描述的本质上是这种方法的一种变体：这里$\gamma$的角色由数字$p/n$扮演。

如果我们应用成功的三角代换，某些问题的解决方案可以大大简化。在某些情况下，三角公式的灵活性可以促进变换、消除根式并获得更简单、更容易理解的表达式。我们的读者 V.V. 的来信中讨论了这个问题。 Pikan（基辅）和 D.P.多罗任（莫斯科地区巴甫洛夫斯卡亚斯洛博达）。

三角代换的本质是，将指定条件中出现的表达式中包含的变量$x$视为辅助变量角度$φ$的某个三角函数的值，并尝试选择该函数，以使所提出的表达式写得更紧凑。

示例 3：计算表达式的值
$$A = \left[ \frac{(x^2 + a^2)^{-1/4} + (x^2 - a^2)^{-1/4}}{(x^2 + a^2)^{-1/4} - (x^2 - a^2)^{-1/4}} \right]^{-3} \tag{1}$$

$$npu x = a \left( \frac{m^2 + n^2}{2mn} \right)^{1/2},$$
$$\varepsilon de a < 0, n > m > 0.$$

由于我们感兴趣的值$x$是负数，我们首先简化表达式（1），假设$x < a$。 （注意，（1）仅对$|x| > |a|$有意义，并证明条件中指定的值$x$不满足这个不等式！）。二项式$x^2 \pm a^2$的存在暗示了放置$x = a \mathrm{tg} \varphi$的想法，这使得我们可以在过程中编写这些二项式：

$$x^2 + a^2 = \frac{a^2}{\cos^2 \varphi},$$
$$x^2 - a^2 = -\frac{a^2 \cos 2\varphi}{\cos^2 \varphi}.$$

我们将三角代换应用于波兹尼：

$$x = a \mathrm{tg} \varphi, \frac{\pi}{4} < \varphi < \frac{\pi}{2}.$$

简单的变换表明，那么

$$A = \left( \frac{\sqrt{4 - \cos 2\varphi} - 1}{\sqrt{4 - \cos 2\varphi} + 1} \right)^3, \frac{\pi}{4} < \varphi < \frac{\pi}{2}.$$

进一步，很容易计算出，若$x = a \mathrm{tg} \varphi = a \left( \frac{m^2 + n^2}{2mn} \right)^{1/2}$，则

$$\cos 2\varphi = \frac{1 - \mathrm{tg}^2 \varphi}{1 + \mathrm{tg}^2 \varphi} = -\frac{(n - m)^2}{(n + m)^2},$$

然后在指定值$x$

$$A = \frac{(4n^2 - m^2) \sqrt{n^2 - m^2} - (4n^2 - 3m^2)n}{m^3}.$$

示例 4：求解方程

$$\sqrt{1 + \sqrt{1 - x^2}} \left[ \sqrt{(1 + x)^3} - \sqrt{(1 - x)^3} \right] = 2 + \sqrt{1 - x^2}.$$

该方程可接受的值范围是集合$|x| \leq 1$。如果我们使用三角代换$x = \cos \varphi, 0 \leq \varphi \leq \pi$，那么很容易检查从根式我们可以使用以下形式的原理

$$\left( \cos \frac{\varphi}{2} + \sin \frac{\varphi}{2} \right) \cdot 2\sqrt{2} \times \left( \cos^3 \frac{\varphi}{2} - \sin^3 \frac{\varphi}{2} \right) = 2 + \sin \varphi.$$

从这里，我们依次得到方程

$$\sqrt{2} \left( 1 + \frac{1}{2} \sin \varphi \right) \cos \varphi = 1 + \frac{1}{2} \sin \varphi$$

或者

$$\left( \sqrt{2} \cos \varphi - 1 \right) \left( 1 + \frac{1}{2} \sin \varphi \right) = 0,$$

仅控制在$\cos \varphi = \sqrt{2}/2$。因此，原方程有根$x = \sqrt{2}/2$。

示例 5. 查找函数的最小值和最大值

$$y = \frac{1 + x^4}{(1 + x^2)^2}.$$

该函数的参数遍及所有实数，因此我们可以将$x$视为辅助变量角度$\varphi$的正切值，在区间$-\pi/2 < \varphi < \pi/2$内变化。三角函数替换 $x = \mathrm{tg} \varphi, -\pi/2 < \varphi < \pi/2$ 与函数 (2) 一起可以研究该函数

$$y = 1 - \frac{1}{2} \sin^2 2\varphi$$

在$-\pi/2 < \varphi < \pi/2$。从$0 \leq \sin^2 2\varphi \leq 1$开始，显然函数(3)的最小值等于$\frac{1}{2}$，并在$\varphi = -\pi/4$和$\varphi = \pi/4$处实现，最大等于1，在$\varphi = 0$处实现。由此可知，函数(2)的最小值等于$\frac{1}{2}$，在$x = -1$和$x = 1$处实现，最大值等于1，在$x = 0$处实现。

请注意，已经讨论了使用三角代换来求解方程的示例。

在求解方程时，未知数的成功替换通常使我们能够考虑更简单的方程，而不是复杂的原始方程。然而，“看到”更换的必要性并不总是那么容易，只有现实、获得的经验以及最常见更换的含义才能提供帮助。

我们的读者 I.A.加夫里洛夫（Fryazino，莫斯科地区）在信中回顾了解决代数方程的一种替代方法。这些替代可以正确地称为“对称化”。

让我们用两个四次方程的例子来说明什么是“对称化”。

如果方程
$$(x-a)^4 + (x-b)^4 = c$$
输入新的未知数而不是未知数$x$
$$y = x - \frac{a+b}{2},$$
我们可以得到一个双二次方程。

很明显，对于任何$x$，数字$x - \frac{a+b}{2}$是线段的中点，端点位于点$x-a$和$x-b$。如果在方程中
$$(x-a)(x-b)(x-c)(x-d) = p$$ (4)
如果任何数字对$a, b, c, d$重合，例如$a-b = c-d$，则替换未知数
$$y = x - \frac{b+c}{2}$$
导出一个双二次方程（检查一下！）。请注意，如果 $a-b = c-d$，则二项式 $x-a - \frac{b+c}{2}$ 处于因子 $x-a, x-b, x-c, x-d$ 的某种“中心”位置，这可以从这些方程的数轴点的几何解释中清楚地看出（参见 图）。

“对称化”的思想被成功地应用于求解许多其他代数方程和方程组。
