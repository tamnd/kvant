如果不是 10 个数字而是 n，答案是什么？

我们将立即解决$n$数字的问题。让我们先做一些初步评论。

让我们用 $y_k$ 表示数字 $\frac{x_1+x_2+\cdots+x_k}{k}$，其中 $k=1, 2, \dots, n$。如果我们将某个数字 $a$ 添加到所有 $x_i$ 中，那么我们将得到数字 $y_i+a$，而不是数字 $y_i$。数字 $y_i$ 和数字 $y_i+a$ 的最大差值相同。因此，从集合$\{x_i\}$，使用选择方法$a$，我们可以转到集合$\{x_i'\}$，使得所有$x_i' \geq 0$，最小的$x_i$等于0，最大的等于1。下面我们将只考虑这样的集合。同样，如果将数字 $x_i$ 替换为 $1-x_i$，则 $y_i$ 将替换为 $1-y_i$。因此，从集合$\{x_i\}$可以转到集合$\{1-x_i\}$：数字$y_i$和数字$1-y_i$之间的最大差是相同的。

现在让我们解决问题a)。设$y_k$为$\{y_i\}$中最小的数，$y_l$为最大的数。如果$k < l$，那么

$$y_l - y_k = \frac{ky_k}{l} + \frac{x_{k+1}+\cdots+x_l}{l} - y_k = \frac{x_{k+1}+\cdots+x_l}{l} - \frac{l-k}{l} y_k \leq \frac{x_{k+1}+\cdots+x_l}{l} \leq \frac{l-k}{l} = 1 - \frac{k}{l} \leq 1 - \frac{1}{n}.$$

如果$l > k$，则$y_l - y_k = \frac{k-l}{k} y_l - \frac{y_{l+1}+\cdots+y_k}{k} \leq 1 - \frac{l}{k} \leq 1 - \frac{1}{n}$。因此，最大差异不超过 1 – $\frac{1}{n}$。具有这样差异的集合很容易表示：$x_1 = 0, x_2 = x_3 = \dots = x_n = 1$。

让我们继续解决问题 6)。让我们估计一下如果集合包含 $\{x_i\}$ $x_k = 1, x_l = 0$，最大差异是多少。我们假设$k < l$（如果不是这种情况，那么我们将从集合$\{x_i\}$移动到集合$\{1-x_i\}$）。

如果$k = 1$，则差值不小于$\frac{1}{n}$。

事实上，那么$y_1 = 1$和$y_n = \frac{x_1+x_2+\cdots+x_n}{n} \leq \frac{n-1}{n}$，因为都是$x_i < 1$，并且其中之一等于零。设$\Delta_1 = y_k - y_{k-1} = \frac{1}{k-1} - \frac{y_k}{k-1}, \Delta_2 = y_{l-1} - y_l = \frac{y_{l-1}}{l}$，如果$y_k \leq y_{l-1}$，则$\Delta_2 \geq \frac{y_k}{l}$。

让我们解决 3n 位数字序列的问题。为了避免混淆，我们将使用希腊字母来表示序列，使用拉丁字母来表示序列元素。令序列$\alpha$由3n位数字组成

$$\{a_1, a_2, \dots, a_{3n}\}.$$

$\alpha$的范围分为三个序列：

$$\alpha_1 = \{a_1, a_4, a_7, \dots, a_{3k+1}, \dots, a_{3(n-1)+1}\},$$

$$\alpha_2 = \{a_2, a_5, a_8, \dots, a_{3k+2}, \dots, a_{3(n-1)+2}\},$$

$$\alpha_3 = \{a_3, a_6, a_9, \dots, a_{3k}, \dots, a_{3n}\}.$$

我们将这样的开发标准称为。每个序列$\alpha_1, \alpha_2, \alpha_3$都是$n$数字的标准发展。令 $\beta$ 为任意序列。让 $|\beta|$ 表示序列 $\beta$ 中 1 的数量。

计算非等价序列的数量基于以下定理：

定理。令$\alpha$和$\beta$为长度为$3n$的两个序列，$(\alpha_1, \alpha_2, \alpha_3)$和$(\beta_1, \beta_2, \beta_3)$为其标准分区。

为了使序列$\alpha$和$\beta$等价，序列$\alpha_1$和$\beta_1, \alpha_2$以及$\beta_2, \alpha_3$和$\beta_3$包含与三元数$(|\alpha_1|, |\alpha_2|, |\alpha_3|)$对应的相同数量的1是必要且充分的。这些数字可以取 0 到 $n$ 之间的任何值。因此，长度$3n$的非等价序列的数量等于从0到$n$的不同有序整数三元组的数量。很容易看出这样的三元组的数量是$(n + 1)^3$。

定理的证明。让我们重新排列序列 $\alpha = \{a_1, a_2, \dots, a_{3n}\}$ 中的两个数字序列：$a_k, a_{k+1}, a_{k+2}$ 和 $a_{k+3}, a_{k+4}, a_{k+5}$。这种排列可以表示如下：首先放置数字$a_k$和$a_{k+3}$，然后放置数字$a_{k+1}$和$a_{k+4}$，最后放置数字$a_{k+2}$和$a_{k+5}$。数字$a_k$和$a_{k+3}$是标准制定同一序列$\alpha$的相邻数字；数字$a_{k+1}$和$a_{k+4}$是另一个，数字$a_{k+2}$和$a_{k+5}$是第三个。因此，在标准开发$\alpha$的每个子序列$\alpha_1, \alpha_2, \alpha_3$中，我们重新排列了两个相邻术语。这意味着如果序列$\beta$是由序列$\alpha$通过有限次数的排列得到的，即如果序列$\alpha$和$\beta$等价，那么标准制定的子集$\beta_1, \beta_2, \beta_3$本质上就是一个排列$\beta$
