本文使用了一些简单的逻辑运算：否定、猜想、析取、蕴涵。你们中的许多人都是从学校里了解到它们的——有些是从选修的数学课程中学到的，有些是从最普通的数学课程中学到的。是的，在 «Kvant» 中我谈到了它们 - 例如，参见 1971 年的 «Kvant» No. 4。

对于那些不知道逻辑运算的定义并且没有其他数字«Kvant»的人，我们在这里仅提供阅读和理解 A. Priyatel 的文章所需的最少信息。

回想一下，一个陈述是一个句子，对于它的正确或错误来说是有意义的。

可以使用逻辑运算从各种语句形成新的语句。当然，结果陈述的真实性问题取决于原始陈述是什么（真或假），当然也取决于逻辑运算本身。即：

1) 真命题的否定是假的，假命题的否定是真的。如果我们用字母A来表示原始语句，并且用符号“—”来表示否定操作（A读作“不是A”），那么我们的定义可以如下表给出：

| A | Ā |
| :--- | :--- |
| 和 | 我 |
| 我 | 和 |

（i - 缩写“真”，l - “假”）。

2) 两个真命题 A 和 B 的合取 (A ∧ B) 读作“A 和 B”）为真，如果其中至少一个为假，则合取为假：

| A | B | A ∧ B |
| :--- | :--- | :--- |
| 和 | 和 | 和 |
| 和 | 我 | 我 |
| 我 | 和 | l |
| 我 | l | l |

3) 两个陈述的析取（符号 A ∨ B 读作“A 或 B”）如果至少其中一个为真，则为真；如果两者都为假，则为假：

| A | B | A ∨ B |
| :--- | :--- | :--- |
| 和 | 和 | 和 |
| 和 | l | l |
| l | 和 | l |
| l | l | l |

4) 最后，如果 A 的结果为真且 B 的结论为假，则命题 A 和 B (A ⇒ B) 的蕴涵为“A bleibt B”、“从 A 得出 B”或“如果 A 则 B”）为假；在所有其他情况下，含义都是正确的：

| A | B | A ⇒ B |
| :--- | :--- | :--- |
| 和 | 和 | 和 |
| 和 | l | l |
| l | 和 | l |
| l | l | l |
