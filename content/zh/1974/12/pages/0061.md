⟦folio 59⟧

考虑梯形 $OO_1M_1M$ (图 9)，其中 $OM = 2(cm)$、$O_1M_1 = 1(cm)$、$KM = KM_1$ 作为接触截棱锥边缘的球的半径。和上一个问题一样，$CC_1 = CM + C_1M_1 = \frac{CD + C_1D_1}{2} = 3(cm)$。现在我们求出梯形$CC_1D_1D : M_1M = C_1E = \sqrt{CC_1^2 - (CM - C_1M_1)^2} = \sqrt{8}(cm)$的高度，以及梯形$OO_1M_1M : OO_1 = M_1N = \sqrt{M_1M^2 - (MO - M_1O_1)^2} = \sqrt{7}(cm)$的高度。

让我们用$x$表示$OK$，然​​后用$O_1K = \sqrt{7} - x$、$KM_1 = \sqrt{O_1K^2 + O_1M_1^2} = \sqrt{(\sqrt{7} - x)^2 + 1^2}$、$KM = \sqrt{x^2 + 2^2}$表示。但是$KM_1 = KM$，我们得到$x$的方程；求解，我们发现：$x = \frac{2}{\sqrt{7}}$。剩下的就是找到$KM = \sqrt{\frac{4}{7} + 4} = \sqrt{\frac{32}{7}}$和$KP = \sqrt{KM^2 - PM^2} = \frac{3\sqrt{14}}{7}(cm)$。

练习

1. （新西伯利亚州立大学）。球接触立方体的所有边缘。如果立方体的边长为 1 厘米，求立方体内部的表面积。
2. （新西伯利亚州立大学）。球接触立方体的所有边缘。如果立方体的边长为 $a$，则求球体和立方体对象的体积。
3. 在正四棱锥中，侧边与底面形成的角度等于 $45^\circ$。球的中心在哪里接触所有的边缘？
4. （新西伯利亚州立大学）。半径为 $R$ 的球接触正四面体的每条边。求其物体的体积。
5. （密歇根州立大学，机制，1966 年）。半径为 $r$ 的球接触三棱锥的所有边。球的中心位于金字塔内部，其高度距顶点 $r\sqrt{3}$ 。证明金字塔是正确的。求金字塔的高度。
6. （MIPT，1963）。正三棱锥的底边等于$a$，棱锥的侧边等于$b$。求接触金字塔所有边的球体的半径。
7. 正$n$棱锥的侧边与底面形成$a$角。如果球的底边是 $a$，那么球的中心与金字塔的所有边接触的距离是多少？
