⟦folio 47⟧

图 2. $p$越接近1，双曲线越接近圆，楼梯的台阶越多。

请注意，如果我们将 $x_1^2 + x_2^2 + \dots + x_n^2 - 1 + x_n^2 - px_1x_2 - px_2x_3 - \dots - px_n - 1x_n \geq 0$ (*) 放入不等式中

最后几个变量$x_k, x_{k+1}, \dots, x_n$等于0，那么我们就得到了与较小的$n$相对应的类似不等式。由此可见，如果 (*) 对于某些 $n$ 成立（对于所有 $x_1, x_2, \dots, x_n$），那么它对于更小的 $n$ 也成立。因此，对于每个固定的$p$，都有一个整数$N(p) \geq 2$，使得(*)对于$n < N(p)$成立，而对于$n \geq N(p)$则失败（对于某些$x_1, x_2, \dots, x_n$）； (*) 也可能适用于所有$n$（在这种情况下我们可以假设$N(p) = \infty$）。

最后一个案例发生在$p = 1$。事实上，在这种情况下（*）相当于非常强的不等式

$$x_1^2 + (x_1 - x_2)^2 + (x_2 - x_3)^2 + \dots + (x_{n-1} - x_n)^2 + x_n^2 \geq 0.$$

让$p = \frac{4}{3}$。那么对于 $n = 3$ (*) 等价于不等式

$$(3x_1 - 2x_2)^2 + x_2^2 + (2x_2 - 3x_3)^2 \geq 0,$$

并且对于$n = 4$不等式(*)被违反，例如，当$x_1 = x_4 = 2, x_2 = x_3 = 3$时（对于$n = 4$不等式(*)相当于：

$$(3x_1 - 2x_2)^2 - x_2^2 + 6(x_2 - x_3)^2 - x_3^2 + (2x_3 - 3x_4)^2 \geq 0;$$

这就是我们的示例的来源。）

让$p = \frac{4}{5}$。那么对于 $n = 4$ (*) 等价于不等式

$$(5x_1 - 3x_2)^2 + x_2^2 + 15(x_2 - x_3)^2 + x_3^2 + (3x_3 - 5x_4)^2 \geq 0,$$

对于 $n = 5$ 来说，它是一个不等式，例如，当 $x_1 = x_5 = 9, x_2 = x_4 = 15, x_3 = 16$ 时（如果我们将 (*) 变换为以下形式，这个例子就会自然出现

$$16(5x_1 - 3x_2)^2 + (16x_2 - 15x_3)^2 - 50x_3^2 + (15x_3 - 16x_4)^2 + 16(3x_4 - 5x_5)^2 \geq 0).$$

现在讨论一下，如何用任意的方式回答这个问题 $p > 0$。很容易证明 $N(p) = \infty$ 在任何 $p \in [0, 1]$ 和 $N(p)$ 当然每次 $p > 1$， 和 $N(p) = 2$ 在 $p > 2$。基本上每次 $p > 1$ 可以找到 $N(p)$，将左侧 (*) 转换为平方和（完全不需要关心对称公式以及系数是整数还是有理数；上面我们这样做是为了更简短地编写解决方案）。例如，您可以将 (*) 简化为以下形式

$$(s_1x_1 - t_1x_2)^2 + (s_2x_2 - t_2x_3)^2 + \dots + (s_{n-1}x_{n-1} - t_{n-1}x_n)^2 + r_nx_n^2,$$

始终如一地相信

$$t_k = p/2s_k, s_{k+1} = \sqrt{1 - t_k^2}$$

($s_1 = 1, k = 1, 2, \dots$)。然后$r_n = s_n^2 \geq 0$位于$n < N(p)$，$r_n < 0$位于$n = N(p)$。因此，$N(p) - 1$（（*）仍然成立的最大$n$）等于图形$s^2 + t^2 = 1$，$st = p/2$之间包含的“梯子”的步数，从点$s = 1$，$t = 0$，（图2）开始。令$p_k$为$p$的值，此时楼梯相对于比瑟里萨$s = t$对称（结束于点$s = 0$，$t = 1$）并包含$k$台阶；很明显，序列$p_1 = 2 > p_2 > p_3 > \dots$趋于1，$N(p) = k + 1$趋于$p_{k-1} \geq p > p_k$。

证明$p_2 = \sqrt{2}$并不难，但是下面的$p_k$已经从与高级代数方程相关的繁琐方程中找到了。
