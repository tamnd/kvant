M222。证明每个凸多边形都有两个边数相同的面。

假设凸多边形的任意两个面具有不同的边数。让我们考虑边数最少的面 G。让我们考虑边数最少的面 O。让我们考虑一下其他面中这种情况较少的面 C。这意味着这个剩余面的数量小于m（即使有1边形和2边形，我们也只能输入m-1个不同的多边形）。另一方面，面 Γ 恰好与多边形的其他 m 个面相邻（每边一个）。我们之间产生了矛盾。

按理说，某些两个面必定具有相同的边数。

给定的解决方案几乎逐字重复了以下众所周知的问题的解决方案（使用“狄利克雷原理”*））。

M223。如果一个自然数等于除该数本身之外的所有除数之和，则该自然数被称为完美数。 （例如，数字 28 是完全数：28 = 1 + 2 + 4 + 7 + 14。）证明完全数不可能是完全平方。

设 n = p₁ᵢ p2ᵢ ... pᵢᵢ m，其中 p₁, ..., pᵢ 是不同的素数，r₁, ..., rᵢ 是自然数（根据算术基本定理，每个整数 n > 1 都可以以唯一的方式表示为这种形式）。

n 的约数是以下形式的数字

p₁ᵢ p₂ᵢ ... pᵢᵢ m,

其中 0 ≤ k₁ ≤ r₁，...，0 ≤ kᵢ ≤ rᵢ。因此，n（包括1和n）的所有约数之和等于乘积

S = (1 + p₁ + ... + p₁ᵢ) ... (1 + pᵢ + ... + pᵢᵢ).

由于n是完全数，因此S必须等于2n，即它必须是偶数。但如果 n 是整数的平方，则所有指数 r₁, ..., rᵢ 都是偶数，因此平方是乘积 S 中的括号

$$\frac{(1 + p_i + p_i^2 + ... + p_i^{i-1})}{1 + r_i}$$

如果数字是奇数，则 S 是奇数。

我们得到了一个矛盾，这意味着完全数不可能是完全平方。

一些读者从公式 2p⁻1 (2p - 1) 得出他们的解决方案
