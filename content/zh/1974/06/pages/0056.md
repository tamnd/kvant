这些数字的编制模式令人震惊。可以证明，这种模式继续适用。这意味着，如果第$n$个三角形数由$T_n$表示，并且我们假设$T_1 = 1$，则以下公式将有效：

$$T_n = 1 + 2 + 3 + \dots + n.$$

看起来很简单，但显然不适合计算。为了给它一个更方便的计算形式，请注意，在等式右侧，距开头和结尾等距的项加起来为相同的数字，即$n + 1$。

现在一切都非常简单：我们将公式写两次，在第二种情况下，项的顺序相反：

$$T_n = 1 + 2 + 3 + \dots + (n - 2) + (n - 1) + n,$$

$$T_n = n + (n - 1) + (n - 2) + \dots + 3 + 2 + 1.$$

让我们将这两个等式添加到“列”中；然后在左边我们得到$2T_n$，在右边我们得到数字$n + 1$，取$n$次。那么，$2T_n = n(n + 1)$，从哪里来

$$T_n = \frac{1}{2}n(n + 1).$$

这里使用的计算方法让我们有机会简化一个相当繁琐的表达式。

对此，我想举一个传统的故事，讲的是一个叫卡尔的男孩，他用这种方法解决了类似的问题。

“有一天，卡尔就读的小学的一位老师，想让孩子们多忙一会儿，就给他们布置了一项艰巨的任务：将数字 1、2、3 等加起来，直到 100。学生们忙着计算……小卡尔注意到，数字 1 和 100、2 和 99、3 和 98 等成对的数字加起来是 101。他在心里计算出这样的数字有 50 对，于是在他的答案上写下了答案：板岩是5050，是老师送的，老师很惊讶……”

未来的证明，老师不应该感到惊讶：小卡尔后来成为了伟大的卡尔·弗里德里希·高斯，生前独断专行的“数学家之王”！
