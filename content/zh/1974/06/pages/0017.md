关于棋子的威力

E.雅。吉克

如果您知道如何下国际象棋，那么您可能知道可以安全地为三个棋子提供一个小棋子（马或象），为两个车提供一个皇后；一个马和一对棋子弥补了车的损失，等等。当然，棋子的真正强度取决于具体的位置：你可以很容易地举出一个棋子将杀敌方国王的例子，棋子被所有军队棋子包围。但很明显，国际象棋游戏中的每个棋子都有一定的平均强度。比较棋子的强弱时，一般将一个棋子的强弱作为一，通过它来表示其余棋子的强弱。在教科书中，通常提出以下比例：

$$F_{\pi} = 1, \quad F_K = F_C = 3, \quad F_{\pi} = 5, \quad F_{\phi} = 9$$

（我们用$F_x$来表示图形$x$的强度）。

这个尺度已经被国际象棋棋手的大量练习和经验所证实。然而，也有纯数学的方法来确定棋子的强度。最常见的方法之一与人物的移动性有关。例如，国王移动的距离（图1）从每个角方格他可以移动3步，从极端垂直和水平的非角区移动5步，最后，从棋盘的剩余区域国王可以移动到8个相邻区域中的任何一个。综上，我们得到棋盘上王可能走的步数；我们用 $S_{Kp}$ 表示这个数字：

$$S_{Kp} = 3.4 + 5.24 + 8.36 = 420.$$

从 图 2-6 可以找到其他数字的数字 $S_x$：

$$S_{\phi} = 21.28 + 23.20 + 25.12 + 27.4 = 1456,$$

$$S_{\pi} = 14.64 = 896,$$

$$S_C = 7.28 + 9.20 + 11.12 + 13.4 = 560,$$

$$S_K = 2.4 + 3.8 + 4.20 + 6.16 + 8.16 = 336,$$

$$S_{\pi} = 2.10 + 3.32 + 4.6 = 140.$$

现在，如果我们将 $S_x$ - 棋子可能移动的次数 $x$ - 除以 $N_x$ - 该棋子可以站立的方格数，我们就得到了棋盘上棋子的平均移动次数。 Izozem 根据数字 $x$ 的流动性得出数字 $P_x$：

$$P_x = \frac{S_x}{N_x}.$$

显然，$N_x = 64$适用于除棋子之外的所有棋子，$N_{\pi} = 48$。使用公式（*）我们发现：

$$P_{Kp} = 6,5625; \quad P_{\phi} = 22,75; \quad P_{\pi} = 14;$$

$$P_C = 8,75; \quad P_K = 5,25; \quad P_{\pi} = 2,5.$$

让我们假设一个人物的力量与其移动能力成正比。如上所述，将棋子 $F_{\pi}$ 的强度视为 1，我们通过它用以下公式表示其余棋子的强度

$$F_x = \frac{P_x}{P_{\pi}}.$$
