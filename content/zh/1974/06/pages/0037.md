图 6.

初始时刻，负载具有重力势能。当弹簧拉伸到最大的那一刻，弹簧变形的势能被储存在弹簧中（我们以带负载的销的最低位置作为高度计数的开始，所以在第二种情况下负载没有任何能量）。让我们将这些能量等同起来*)：

$$mg(h + \Delta x + x_0) = \frac{k(\Delta x + x_0)^2}{2},$$

在哪里

$$\Delta x = \frac{mg}{k}.$$

从这里

$$x_0 = \frac{mg}{k}\sqrt{1 + \frac{2kh}{mg}}$$

任务 3. 说出 图 b 中所示磁铁的振动名称。弹簧系数为$k_1$和$k_2$，负载质量为m。忽略弹簧的质量。

让我们首先考虑第一个 matnik (图 6, a)。例如，如果将负载从平衡位置向下移动 x 量，则上部弹簧将额外拉伸 x 长度，而下部弹簧也将保持 x 长度。但两个额外的弹簧力都是向上的，也就是说，它们将负载返回到位置

*) 这是可以做到的，因为杯子是失重的，并且带有负载的杯子的初始能量等于下落重物的能量。

图 7.

平衡，所以我们可以写：

$$ma = -k_1x - k_2x = -(k_1 + k_2)x.$$

根据matnik运动方程

$$a = -\omega^2x,$$

姿势

$$\omega = \sqrt{\frac{k_1 + k_2}{m}}.$$

在第二种情况（图 6，b）中，当负载从平衡位置向下位移 x 量时，两个弹簧都会拉伸，但它们的伸长量 $x_1$ 和 $x_2$ 会不同。然而

$$x_1 + x_2 = x.$$

由于弹簧不重，因此弹簧力必须相同*)：

$$k_1x_1 = k_2x_2.$$

因此，货物的运动规律：

$$ma = -k_1x_1 = -k_2x_2 = -\frac{k_1k_2}{k_1 + k_2}x,$$

在哪里

$$\omega = \sqrt{\frac{k_1k_2}{(k_1 + k_2)m}}.$$

注意，第一垫的振荡频率大于第二垫的振荡频率。

*) 例如，考虑第二个春天。力从第一个弹簧的侧面作用在其上 $F_1 = k_1x_1$，方向向上，力从负载侧面作用 $F_2$，根据牛顿第三定律，等于第二弹簧的弹簧并且方向向下（即， $F_2 = k_2x_2$）。让我们写出弹簧的运动方程： $m_2a_2 = F_2 - F_1 = k_2x_2 - k_1x_1$。由于弹簧是失重的，所以 $m_2 = 0$， 那 $k_2x_2 = k_1x_1$.
