列宁格勒国立大学

以列宁格勒列宁勋章和劳动红旗勋章命名的国立大学。 A. A. Zhdanova 在三个院系培养数学和物理学专家。

数学与力学学院设有专业：数学、力学、天文学和水电工程。

物理学院的学生接受的专业有：物理学、地球物理学、放射物理学和电子学。

应用数学学院 - 控制过程培养应用数学方面的专家。

数学与力学学院和应用数学学院的入学考试 - 控制过程在八月举行，物理学院的入学考试 - 七月举行。下面我们介绍 1973 年列宁格勒国立大学数学笔试和物理口试的任务。

数学

选项1
（数学与力学学院和应用数学学院 - 控制过程）

1. 机械拖拉机站必须向国营农场派遣一定数量的拖拉机来执行某项工作，据了解，10台拖拉机可以在12个工作日内完成这项工作。此外，据了解，国营农场在整个国营农场工作期间向维修队支付30卢布的费用。 1天，每台拖拉机4卢布。 80 科普。在国营农场工作 1 天并返回（工作期间，拖拉机在国营农场）。使用多少台拖拉机，工人完成所有工作的总报酬最少？工人的最低工资是多少？

2. 解方程
$(2 + a) \cos^2 x + \sin x \cos x = (1 - a) \sin^2 x$ 对于参数$a$的所有值。

3. 选择数字$b$，使得函数的最大值
$|-2x^2+x+b|$
区间$0 \leq x \leq 1$最小。

4. 在矩形$ABCD$中，我们有：$AB = a$，$AD = b$。在边 $AB$ 上找到 $\overrightarrow{CED} = \overrightarrow{AED}$ 的点 $E$。

5. 最终高度等于底座的直径。通过圆锥的某些母线画出与圆锥侧面相切的平面，并在该平面中通过圆锥的顶点画一条与母线成$\alpha$角的直线。求所画直线与底平面所成的角度。

选项2
（化学系、心理学系、经济系（政治经济学系除外））

1. 从装有$p$％酸溶液的$v$升容器中倒入一定量的溶液，并添加相同量的$q$％溶液($q < p$)。所得拉斯托洛夫的强度结果比拉斯托洛夫的强度小 $k$ 倍，如果将 $q$% 拉斯托洛夫倒入在一起时，您使用 2 倍强度的拉斯塔，则会获得该强度。 $q$% 的光栅花费了多少？

2. 解决不平等问题
$$\sqrt{x+2\sqrt{x-1}}+\sqrt{x-2\sqrt{x-1}} > \frac{x}{2}.$$

3. 解方程
$(\cos 2x+\cos x+1)^2 = 2(2\cos x+1)(\cos 2x-\cos x).$

4. 在等边三角形 $ABC$ ($AB=BC$) 中，绘制中线 $AD$。如果顶点 $B$ 处的角度等于 $\alpha$，则求角 $BAD$。

5. 在正三角形primina中，提取靠近底边描述的圆的$r$和侧面与底平面的倾斜角$\alpha$。求外接球的半径。

选项3
（地质学院、经济学院政治经济系）

1. 工作计划是在几天内生产 260 个零件。前两天他按计划工作，在接下来的几天工作中他超出了计划，每天比计划多生产 10 个零件。因此，在截止日期前 2 天已经制造了 268 个零件。一天应按计划生产多少零件？

2. 解方程
$$2\log_2x \mathrm{tg} x + \log_t x \sin x = 3.$$

3. 在平面上，求坐标$x$和$y$满足方程的点的轨迹
$$x = |x-y|^2 + y.$$

4. 求梯形的面积，如果梯形的底边分别为6厘米和11厘米，一边长为4厘米，底边的内角和为$\pi/2$。

选项4

（生物与力学学院）

1. 两条相等的四边形线在空间中的位置使得它们的底边重合，并且它们的顶点位于底边公共平面的相对两侧。已知底边的边长等于$a$，顶点处的平面角等于$\alpha$。求这些直线形成的六边形内切球的半径。

2. 解决不平等问题
$$\sqrt{\frac{1+x}{1-x}} + \frac{\sqrt{1-x}}{2\sqrt{1+x}-1} \geq 0.$$

3. 解方程
$$\log_{g} x (2+4\cos^2 x) = 2.$$

4. 对于周长为 18 厘米的三角形内接的圆，平行于三角形的底画一条切线。边之间的切线段是 2 厘米。找到三角形的底边。

5. 在正三角形中，底边等于$a$，侧边等于$l$。通过底座的中心，有一个平面平行于底座的一侧并平行于相对的侧边。求截面积。

物理

（数学与力学学院、应用数学学院 - 控制过程、物理学院）

1. 一颗质量为$m$的铅弹，以$v$的速度飞行，击中质量为$M$的铅球的初始位置并卡在其中（爱击）。子弹和球的质量比是多少时它们会加热到最高温度？

2. 一个非常轻的阶梯叶的下端用绳子连接。求当重量为$P$的电工爬到梯子中间时，它的拉力$T$。地板非常光滑。叶子的每一面都与地板形成 $\alpha$ 角度。

3. 在一个有隔板（图1）的盒子里，正常条件下有一摩尔单原子理想气体。紧接在隔板后面有一个夹具，其活塞处于自由状态，位于空隙中。弹簧弹性系数$k$。分区被移除。如果没有与外部环境的热相互作用，系统中的压力、温度和体积将如何建立？在新的平衡位置，夹具不会被压缩至失效。活塞面积$S$。可以要求活塞的热容量。

4. 将$m \cdot e$水倒入碟子中，将薄壁加热玻璃倒置放在上面。玻璃连同其中的影响必须被加热到什么绝对温度$T_1$（最低），以便冷却到周围空气的温度$T_0$后，所有的水都会被吸入其中？大气压$p_a$，玻璃横截面积$S$，高​​度$h$，水比重$d$。倒入的水的体积小于玻璃杯的体积。考虑了玻璃的蒸发、表面张力和膨胀现象。碟子很宽，因此倒入水的高度很小。

5. 当用 e 转动连接到电池的可变电容器的调节旋钮时，求出电力所做的机械功。 d.s. $E = 300$c．在这种情况下，容量从$C_1 = 10$ mf 变为$C_2 = 100$ mf。

6. 通过用光照射金属球，我们观察到照片效果。如果在球上放置正电荷$q$，光电效应的红色边框会如何变化？球的半径为$R_0$。在距球中心 $R \gg R_0$ 的距离处发射注册电子。
