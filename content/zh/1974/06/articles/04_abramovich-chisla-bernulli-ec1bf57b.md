自古以来，数学家们就试图解开奇妙数字世界的秘密。这个世界以其多样性、严格性和完善性的法律而吸引人。这里有“伟人”，也有“侏儒”，有一般的“勤劳者”，也有l、e这样的“名人”。但数列的世界更加多样化。这是一个自然数序列
1, 2, 3, ...,
以及充满深奥秘密的素数序列
2, 3, 5, 7, ...,
和一系列“二项式系数”
$C_1^1, C_2^1, C_2^2, C_3^1, C_3^2, C_3^3, ...,$

当求 2, 3, 4, ...“二项式”$a + b$ 次方时出现：
$(a + b)^k = a^k + C_k^1 a^{k-1} b + C_k^2 a^{k-2} b^2 + \ldots + C_k^{k-1} a b^{k-1} + b^k.$

数字 $C_k^m$ 是一个令人着迷的数学分支的基本工具：组合学 $^*$。我们这个国家也需要他们。例如，它们可以非常简单地计算 - 使用公式
$$C_k^m = \frac{k(k-1)(k-2)\ldots(k-m+1)}{1 \cdot 2 \ldots m},$$

$1 \leq m \leq k$，用它你可以轻松推导出它们最重要的属性：
$$C_k^{m-1} + C_k^m = C_k^{m+1}$$

（帕斯卡定理）。公式（2）也可以重写为这种更“紧凑”的形式：
$$C_k^m = \frac{k!}{m!(k-m)!},$$

其中 $n! = 1 \cdot 2 \cdot \ldots n$ 位于 $n > 0$；值为 0！结果等于一（符号 ! 称为因子）。公式 (2*) 立即隐含了二项式系数的又一个性质：
$$C_k^m = C_k^{k-m}.$$

$^*$ N. Ya 的书中描述了这门科学。 Vilenkin 有一个明确的标题，M.，“科学”，1969 年。

2. 具有奇数的伯努利数

定理。除了$B_1$之外的所有奇数伯努利数都等于0：$B_{2m+1} = 0$在$m \geqslant 1$。

为了证明这一点，我们使用等式（1）；将其应用到差$(1+a)^{2m} - (1-a)^{2m}$：

$$(1+a)^{2m} - (1-a)^{2m} = 2 \left( C_{2m}^1 a + C_{2m}^3 a^3 + C_{2m}^5 a^5 + \ldots + C_{2m}^{2m-1} a^{2m-1} \right).$$

将$a = 1, 2, \ldots, n$放在这里，将得到的结果相加，我们得到：

$$(S_{2m}(n) + (n+1)^{2m} - 1) - (S_{2m}(n) - n^{2m}) = (n+1)^{2m} + n^{2m} - 1.$$

在右边我们得到表达式

$$2 \left( C_{2m}^1 S_1(n) + C_{2m}^3 S_3(n) + \ldots + C_{2m}^{2m-1} S_{2m-1}(n) \right).$$

(9)

所以我们有

$$(n+1)^{2m} + n^{2m} - 1 = 2 \left( C_{2m}^1 S_1(n) + C_{2m}^3 S_3(n) + \ldots + C_{2m}^{2m-1} S_{2m-1}(n) \right).$$

让我们计算左右部分得到的表达式中$n^1$的系数。在左边的表达式中，这个系数将等于2$m$（显然）。获得右侧表达式中的一次幂$n$的系数形式有点困难：为此，只需将伯努利数的和$S_j(n)$（$j = 1, 3, \ldots, 2m-1$）替换为公式（9）中的相同数字即可（此说法来自伯努利数的定义）。所以这是方法：

$$C_{2m}^1 B_1 + C_{2m}^3 B_3 + C_{2m}^5 B_5 + \ldots + C_{2m}^{2m-1} B_{2m-1} = m.$$

3. 与素数的联系

Christan Staudt（1798-1867）研究伯努利数，获得了一个美丽而深刻的结果，揭示了这些数字的算术本质。给出数字$B_h$。考虑所有素数$p$不超过$k + 1$，并且$p - 1$称为$k$（即给定伯努利数的数）。对于所有这样的$p$，我们组成了$\sum \frac{1}{p}$形式的有限和——我们将其称为与给定伯努利数$B_h$相对应的和（让我们只考虑Staudt处理的此类和）。原来，数字$B_h$和对应的和$\sum \frac{1}{p}$互补为一个整数。所以，$B_h + \sum \frac{1}{p}$始终是整数！

让我们举个例子来评价Staudt这个结果的重要性。让我们知道什么是$B_6$，什么是$0 < B_6 < 1$。我们想要找到它的精确值；事实证明，现在这很容易做到。

事实上，6 的约数是数字 1、2、3、6。将它们加一，我们得到数字 2、3、4、7。其中，素数是 2、3 和 7。我们计算和 $\sum \frac{1}{p}$：

$$\frac{1}{2} + \frac{1}{3} + \frac{1}{7} = \frac{41}{42}.$$

因此，根据施陶特定理 $\frac{41}{42} + B_6$ 一定是整数，但根据条件 $0 < B_6 < 1$，唯一合适的整数是 1。因此

$$B_6 = 1 - \frac{41}{42} = \frac{1}{42}.$$

4. 关于库默尔定理

1850年，伟大的德国数学家恩斯特·库默尔（Ernst Kummer，1810-1893）在费马方程$x^n + y^n = z^n$、$n \geq 3$整数解的存在性问题上获得了重要成果——费马问题。尽管这一结果并没有完全解决问题，但它仍然是在这个方向上获得的最重要的结果之一。事实证明，这个结果与伯努利数密切相关。
