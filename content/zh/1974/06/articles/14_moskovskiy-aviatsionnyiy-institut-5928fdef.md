⟦folio 44⟧

莫斯科航空学院

我们在1973年«Kvant»第6期详细讲过MAI。现在MAI所有院系，除了应用数学院外，所有入学考试都是笔试，数学有两个考试：代数和几何三角。数学和物理的应用和任务选项包括理论问题。进入应用数学学院的申请者将参加数学口试和笔试，因此对他们来说，数学笔试的选项不包含理论问题。以下材料将向读者介绍 1973 年 MAI 入学考试中提供的任务版本。

数学
应用数学学院

选项1
1. 解方程
$$\sqrt{3-x} - \sqrt{\frac{1-x}{2-x}} = 1.$$

2. 公共汽车和出租车同时从两个城市出发前往对方。当出租车司机跑完一半距离时，出租车距离路线终点还剩 19.2 公里，当出租车司机跑完一半距离时，出租车距离路线终点还剩 12 公里。如果沿整条路线绘制了此类车辆和公共汽车的速度，并且每个车辆都必须到达对方离开的城市，则求此类车辆和公共汽车的速度之比。

3. 对于什么$a$的实数值是方程的平方根之和
$$2\log_4(2x^2-x+2a-4a^2) + \log_{0,5}(x^2+ax-2a^2) = 0$$
不止一个？

4. 半径为 $R$ 和 $\frac{R}{2}$ 的两个圆在外部相互接触。长度为 2R 的线段的一端与中心线形成 30° 角，与半径较小的圆的中心重合。线段的哪一部分位于圆之外？

5. 正四边形的顶点与立方体底边的对应边平行。底面ABCD的边与立方体底面的对应边平行。如果 $\Rightarrow ASB = \text{arctg } \frac{4}{3}$ 并且立方体的边等于 1，求位于 paramid 内的立方体的体积。

代数笔试

选项2
1. 求解二次方程。维埃塔的公式。
2. 解方程
$$2^{x-1}(2^x+3^{x-1})=9^{x-1}.$$
3. 求等比级数的前七项之和，其中第一项和第四项之和为 9，第二项和第三项之和为 6。
4. 一顿快餐比普通餐食要快 3.5 小时。如果每趟列车与另一趟列车在车站之间行驶的时间相同，那么特快列车将比货运列车多行驶 350 公里。如果每趟列车的速度提高10公里/小时，那么快速列车将比货运列车快2.4小时。计算行驶速度和车站之间的距离。
5. 方程的平方根之和在$a$取什么值时
$$2\log_4(2x^2-x+2a-4a^2) + \log_{0,5}(x^2+ax-2a^2) = 0$$
不止一个？

几何笔试

选项3
1. 证明正弦定理。
2. 如果$\sin \frac{\alpha-\beta}{4} = a$，则计算$(\sin \alpha - \sin \beta) \sin \alpha + (\cos \alpha - \cos \beta) \cos \alpha$。
3. 解方程：
$$(1-tg x)(1+\sin 2x)=1+tg x.$$
4. 在梯形ABCD中，画出对角线AC和BD，相交于点F。从顶点C画一条直线CK，平行于边AD，该直线与BD的延长线相交于点L，使得DF = BL。求 AB:CD 比率。
5. 半径为 R 的圆和边 $R\sqrt{3}$ 的等边三角形位于互相垂直的平面内。然而，三角形的边位于圆的平面内。连接圆心和三角形中心的线段与它们的平面形成等于 30° 的角。求三角形边长位于圆内的部分的长度。

⟦folio 45⟧

物理

门票1

1. 绝缘体和导体。电荷守恒定律。
2. 当 20 e 的水蒸气在 100°C 凝结并将所得水冷却至 20°C 时，会释放多少热量？水的比热$c = 4200 \text{ } \partial x/\partial z$。 100°C 时水的汽化比热$r = 539 \text{ } \kappa a/\kappa c$。
3. 重 100 N 的质量位于绝对光滑的斜面上，与水平面形成 30° 角。必须向平行于平面的质量施加什么力才能使其保持平衡？求飞机的反作用力。
4. 两个质量分别为 $m_1 = 2 e$ 和 $m_2 = 3 e$ 的球在水平面内以与彼此之间的角度 $\alpha = 90^\circ$ 相对应的速度移动。球发生非弹性碰撞。这些球撞击后的总动量是多少？
5. 在距离凹面镜顶部$d = 0,14 m$处有一个高度为$l = 0,06 m$的物体。镜子焦距$F = 0,11 m$。求物体图像的高度$L$。

门票2

1. 电容器。平行板电容器的电容。
2. 飞行员在飞机上发射大炮。飞机相对于地球的速度为900公里/小时。弹丸相对于飞机的速度为750 m/s。确定抛射体相对于地球的初始速度，如果：a）沿飞行方向发射子弹，b）沿相反方向发射。
3. 如果电力机车牵引力为250 kN，摩擦系数为$k = 0,06$，什么阵列可以驱动电力机车匀速爬上0.004的坡度？
4. 自动将2升40℃的水倒入散热器中，然后添加4升85℃的水。确定混合物的温度。
5. 在磁感应强度为2.6ml的均匀磁场中，如果导体中的电流为12A，电流方向与感应线的夹角为：a)90°，则10cm长的导体上受到什么力； b) 30°？

门票3

1. 光的折射定律。光的完全反射。
2. 波在介质中传播的速度为200 m/s。如果两个相反相位的振荡之间的最近距离为 20 cm，则计算振荡周期。
3. 磁通量（导体的任意轮廓）均匀地变化 0.6 bb，因此 e。 d. c 归纳结果等于 1.2 b．如果导体电阻为 0.24 欧姆，求磁通量的变化时间和感应电流的强度。
4. 在水平路段，汽车以72公里/小时的速度行驶10分钟，以36公里/小时的速度爬升20分钟。整个旅程的平均速度是多少？
5. 该客机有 4 个发动机，每个发动机的推力为 10 吨，飞行速度为 900 公里/小时。发动机飞行4000公里需要多少煤油？ K.p.d.发动机0.25。煤油燃烧热$q = 46,2 \cdot 10^6 \text{ } \partial x/\partial z$。

门票4

1. 光电效应。光电管及其应用。
2. 体重60公斤的人跑步的速度为8公里/小时。当他追上一辆时速 2.9 公里的马车时，他跳了上去。如果小车的质量为 80 公斤，那么此后的速度是多少？
3. 一个玻璃杯中装有 100 秒温度为 10 °C 的水。在 -10 °C 温度下放入 40 秒冰。温度均衡后，玻璃杯中还剩下什么？
4. 水的比热$c_1 = 4200 \text{ } \partial x/\partial z$。冰的比热$c_2 = 2100 \text{ } \partial x/\partial z$。冰的比热$\lambda = 3,3 \cdot 10^5 \text{ } \partial x/\partial z$。
4. 人体从 80 m 高处自由落下。在秋天的最后一秒，它会采取什么路径？
5. 电流10A时，外电路释放的功率为200W，电流15A时，外电路释放的功率为240W。内阻是多少，例如： d.和。和发电机短路电流？
门票5

1. 波伊尔-马林特定律和盖洛斯卡克定律。
2. 身高为$h = 1,75 m$的人与柱子的距离为$r = 6 m$。一个人应该在离自己多远的地方水平放置一面平面镜才能透过它看到高度$h = 7 m$的柱子顶部？
3. 如果无线电发射机的振荡电路的电容在 60 nf 到 240 nf 之间变化，并且电感为 50 mken，那么无线电发射机在什么波长范围内工作？
4. 如果一个球从塔上落下，没有初始速度，在 2 秒内跑完最后 185 英里，那么奥斯坦克电视塔的高度是多少？不考虑空气阻力。
5. 转弯时，飞机最大速度$v = 75 \text{ } \text{m}/\text{s}$，起飞前转弯长度$S = 500 \text{ } \text{m}$，飞机重量$m = 19 \text{ } \text{m}$，摩擦系数$k = 0,02$。关闭期间的运动被认为等于速度。飞机起飞的最小推进力应该是多少？
