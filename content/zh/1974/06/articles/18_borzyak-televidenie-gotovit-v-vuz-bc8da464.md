⟦folio 50⟧

电视
为大学做准备

5月，在莫斯科技术专家数学系，讨论了“内切球和外接球”、“盾和锥”、“解决立体测量各个部分的问题”、“关于数学证明”、“不等式的证明”等主题。关于立体测量，我们提供了一些典型的作业问题供您自行解决。

Mathematica

1. （莫斯科工程物理学院，1973）。有两个物体沿相反方向沿圆周运动，第一个物体以速度 v 匀速运动，第二个物体以线加速度 a 匀速加速。最初时刻，他们处于A圈的同一点，第二体的速度为零。如果第二次会议在 A 点举行，这些机构的第一次会议将在什么时间之后举行？

2. （莫斯科工程物理学院，1973）。在四边形帕拉米德的底部，a 边有一个正方形。由于通过paramida的顶点和底面的对角线，它们分别以角度φ和ψ倾斜于底面。如果其高度与 Paramid 底部的一侧相交，则求 Paramid 的体积。

3. （莫斯科工程物理学院，1973）。直陡锥体的高度等于H。两条相互垂直的母线将基圆分成两条弧，其中一条弧长是另一条弧长的一半。求圆锥体的体积。

4. 在圆锥体的高度和直径上构建一个球体。球体表面位于圆锥体内的部分面积为$1/2$圆锥底面积。求圆锥体的高度与母线之间的角度。

5. 一个直角三角形肢内接于一个半径为R的球。该标志的底边是一个锐角α的直角三角形，其最大侧面是一个正方形。求识别量。

6. （莫斯科工程物理学院，1972）。在三角形 paramid SABC 中，顶点 S 处的平面角已知：$\Rightarrow BSC = 90^\circ$、$\Rightarrow ASC = \Rightarrow ASB = 60^\circ$。顶点A、S和边SB、SC、AB、AC的中点位于半径为3m的球的表面上。证明边 SA 是该球的直径并求出 paramid 的体积。

7. （密歇根州立大学，1972）。当球成对且在某个平面上相互接触时。球与平面的接触点形成直角三角形，边长为 3 厘米，对角为 30°。确定给定球的半径。

5月底，在手机上学习了“关于数学证明”和“不等式证明”的主题。我们为您提供有关这些主题的一系列问题。

8. 证明如果 a + b = 1，其中 a 和 b 是实数，则

a) $a^2 + b^2 \geq \frac{1}{2}$; 6) $a^4 + b^4 \geq \frac{1}{8}$.

9. 证明如果 a, b, c, d > 0，则$\frac{a + b + c + d}{4} \geq \sqrt[4]{abcd}$，且等号仅对 a = b = c = d 成立。

10. 证明如果$a_1 > 0, a_2 > 0, \dots, a_n > 0, a_1a_2...a_n = 1, n \geq 2$则$a_1 + a_2 + \dots + a_n \geq n$。

在这种情况下，等号仅出现在 $a_1 = a_2 = \dots = a_n$ 处。

11. 证明如果$a_1 > 0, a_2 > 0, \dots, a_n > 0$，则$\frac{a_1 + a_2 + \dots + a_n}{n} \geq \sqrt[n]{a_1a_2...a_n}$，且等号仅对$a_1 = a_2 = \dots = a_n$成立。

12. 证明如果正数$a_1, a_2, \dots, a_n$构成等差数列，则

$$\sqrt{a_1a_n} \leq \sqrt[n]{a_1a_2...a_n} \leq \frac{a_1 + a_n}{2}$$

13. 证明当 n ≥ 2 时，不等式 $n^n \leq (n!)^2$ 成立。

14. 证明如果$\frac{\pi}{4} < \varphi < \frac{\pi}{2}$则$\frac{\sin^2 \varphi}{\cos \varphi (\sin \varphi - \cos \varphi)} \geq 4$。

15. 证明如果$\frac{\pi}{4} < \varphi < \frac{\pi}{2}$则$\frac{\sin \varphi}{\cos^2 \varphi (\sin \varphi - \cos \varphi)} > 8$。

物理
