1974年3月26日至30日，第比利斯科马罗夫物理数学中学寄宿学校第二届学生科学会议在第比利斯举行。在这次会议上，格鲁吉亚女学生Medea Toronjadze宣读了由A.D. Bendukidze领导编写的报告《皮亚诺曲线》。该报告以文章的形式呈现，供读者关注。它讨论了某些线是如何分布的，以及这条线必须改变的曲线。您可以在院士 P. S. Aleksandrov 的文章中找到最终定义的线（更准确地说，是精确集合的尺寸）（参见第 3 页）。

什么是线？

也许，许多被问到这个问题的人都会困惑地耸耸肩并回答：“线？是的，这很简单！用一支削得很好的铅笔笔尖在纸上划过，你就会得到一条线。”

看来他们是对的，因为当我们谈论一条线时，我们实际上想象的是一些看起来像纸上的又高又细的笔划的东西。

但他们不会是对的！原因很简单：它们并不是为了明确，而是为了表明一条线应该理解什么。然而，人们很难责怪他们，因为给出一条线的精确数学定义并不像乍一看那么容易。数学家花了大约2200年才做到这一点！

其名称满足 $F(x, y) = 0$ 形式的某个方程。

这是对线条的相当普遍且良好的定义。它的好处是可以将直线的研究减少到定义直线的方程 $F(x, y) = 0$ 的研究。但后来发现，函数 $F(x, y)$ 通常具有相当复杂的形式。

例如，如果半径为 $R$ 的圆由以下方程给出

$$x^2 + y^2 - R^2 = 0$$

（这里$F(x, y) = x^2 + y^2 - R^2$），那么阿基米德螺线就不能用这么简单的方程来指定。阿基米德螺线是一条曲线，由沿射线匀速移动的点描述，同时绕固定点 (图 1) 匀速旋转。这条曲线更容易从几何角度进行研究，而无需借助方程。

笛卡尔的定义还有一个缺点：如果不对函数$F(x, y)$的形式施加任何限制，那么根据笛卡尔，平面上的任何集合都是线性的（这样定义函数$F(x, y)$就足够了：在给定的一组对$(x, y)$上，在平面$F(x, y) = 1$的所有其他点上，该函数等于零）。例如，根据笛卡尔的说法，单个正方形是一条“线”，它由以下方程给出

$$|x| + |x-1| + |y| + |y-1| - 2 = 0$$

这是函数

$$F(x, y) = |x| + |x-1| + |y| + |y-1| - 2$$

进一步连续！

19世纪下半叶，另一位法国数学家卡米尔·乔丹（Camille Jordan，1838-1922）发展了笛卡尔提出的直线概念。 Jordan 将平面线定义为平面上的一组点，其坐标为 $x$ 和 $y$，由方程给出

$$x = \varphi(t), y = \psi(t)$$

food $\varphi(t)$ 和 $\psi(t)$ 是在区间 [0, 1] 上连续的函数。

图 1.

现在，这种定义线的方法称为参数化（带有参数$t$）。

例如，半径为$R$的圆的参数方程为

$$x = R \cos 2\pi t, \quad y = R \sin 2\pi t.$$

阿基米德螺线（更准确地说，是它的一部分）由简单的方程给出

$$x = vt \cos \omega t, \quad y = vt \sin \omega t.$$

有时，似乎终于找到了一个成功的线定义，其中正方形肯定不会落入“线”之内。不管怎么样！

1890年，意大利数学家朱塞佩·皮亚诺（Giuseppe Peano，1858-1932）构造了一条围绕正方形所有点的曲线的例子，同时满足乔丹对直线的定义！随后，类似“线条”的其他例子也被发现了。现在这些“线”也被称为“皮亚诺曲线”。我们将在本文末尾介绍其中一条皮亚诺曲线的构造。

皮亚诺曲线表明乔丹的定义过于宽泛。很难考虑填充整个正方形的线性曲线。同时，它也太狭隘了——本质上林尼，它不符合这个定义。

那么，什么是十呢？就平面线而言，这个问题的最终答案是由 19 世纪末至 20 世纪初最伟大的数学家之一乔治·康托 (Georg Cantor，1845-1918) 给出的。我们并没有停留在这个定义的精确表述上，而是提出了一个有趣的线指挥示例，它是由著名用户 Waszlaw Sierpinski 构建的。

我们来画一个正方形。让我们将其分成两个拥挤的正方形，并从中删除中心正方形的内部点。我们将剩余的八个正方形分成两个拥挤的正方形，并在每个正方形中再次删除中心正方形的内部点。无限期地继续这个过程，我们将获得所需的值。它被称为谢尔宾斯基地毯（封面第一页显示了在第三步之后构建谢尔宾斯基地毯时获得的图）。请注意，无论距离任何剩余点（谢尔宾斯基地毯）有多近，都会有一个点被抛出原始正方形之外。

本世纪20年代，著名数学家P. S. Uryso推广了康托尔的定义，给出了直线的一般定义*)。

皮亚诺曲线的构建

1. 令 σ 为单位线段 [0,1]。我们将其分为四个拥堵段：

$$\sigma_{1}^{(1)} = \left[ 0, \frac{1}{4} \right], \quad \sigma_{2}^{(1)} = \left[ \frac{1}{4}, \frac{1}{2} \right], \quad \sigma_{3}^{(1)} = \left[ \frac{1}{2}, \frac{3}{4} \right], \quad \sigma_{4}^{(1)} = \left[ \frac{3}{4}, 1 \right].$$

*) 这在 P. S. Alexandrov 院士“Pavel Samulovich Uryson”的文章中进行了详细描述（参见第 3 页）。另见 A. S. Parkhomenko“什么是线”，M.，Gostekhidat，1954 年。

我们将这些段称为第一次运行的段。将它们分成四个拥堵路段，我们得到第二次运行的 16 个路段$\sigma_{i}^{(2)}$ ($i = 1, 2, \dots, 16$)。继续分割过程，我们获得第三、第四和大伤口的片段。在这种情况下，第 $r$ 个伤口的片段将如下所示：

$$\sigma_{i}^{(r)} = \left[ \frac{i - 1}{4^r}, \frac{i}{4^r} \right] \quad (i = 1, 2, \dots, 4^r).$$

现在让我们来看一些观点$t_0 \in \sigma$。

如果它与任何分割点都不重合，则每个伤口恰好有一个片段包含它。让$\sigma_{i}^{(1)}, \sigma_{i}^{(2)}, \sigma_{i}^{(3)}, \dots$像这样。让我们用无限自然数序列$i_1, i_2, i_3, \dots$对应点$t_0$，并写成这样：

$$t_0 = (i_1, i_2, i_3, \dots).$$

例子。 $1/3 = (2, 6, 22, 85, \dots)$。

如果点$t_0$与任意分割点重合，即具有$m/4^n$形式，则从第$n$个伤口的线段开始，它将包含每个伤口的两个相邻线段。让我们将它与两个自然数序列（$i_1, i_2, i_3, \dots$）相关联，其中$1 \leq i_1 \leq 4$，$4i_k - 3 \leq i_{k+1} \leq 4i_k$。相反，每个这样的序列都确定了线段 $\sigma$ 的一个唯一点（证明一下！）。

2. 让我们对单位方格 Q 进行类似的构造。将其分为四个拥挤的方格，我们得到第一轮的方格：$Q_{1}^{(1)}, Q_{2}^{(1)}, Q_{3}^{(1)}, Q_{4}^{(1)}$。将这些方格中的每一个划分为四个拥塞方格给出第二个拉纳方格，依此类推。一般来说，将第 $r$ 次运行 $Q_{i}^{(r)}$ 的每个方格划分为四个拥挤的方格会产生第 $(r+1)$ 次运行的四个方格：$Q_{4i+1}^{(r+1)}, Q_{4i+1}^{(r+1)}, Q_{4i+1}^{(r+1)}, Q_{4i+1}^{(r+1)}$ ($i = 1, 2, \dots, 4^r$)。我们对正方形进行编号，以便：

1) 任何游程的第一个方格包含点 (0, 0)；

2) 可以从方格$Q_{i}^{(r)}$绕过连续的方格$Q_{4i+1}^{(r+1)}, Q_{4i+1}^{(r+1)}, Q_{4i+1}^{(r+1)}, Q_{4i+1}^{(r+1)}$并从方格$Q_{i+1}^{(r)}$退出，仅与拉纳方格$(r+1)$的边相交（而不是顶点！）。

继续推理，我们确信对于每个点$(x_0, y_0)$，平方$Q$都可以分配给一个或多个（多少个？）自然数序列，我们这样写：

$$(x_0, y_0) = [i_1, i_2, i_3, \dots]$$
$$(1 \leq i_1 \leq 4, 4i_k - 3 \leq i_k + 1 \leq 4i_k).$$

示例：$(1/3, 1/3) = [1, 3, 9, \dots]$；
$(1/2, 1/3) = [1, 3, 10, \dots] = [1, 14, 56, \dots]$;
$(1/2, 1/2) = [1, 3, 11, \dots] = [2, 8, 32, \dots] = [3, 9, 33, \dots] = [4, 14, 54, \dots].$

在这里我们可以证明每个这样的序列从$Q$确定一个唯一的点$(x_0, y_0)$。

3. 将线段 $\sigma$ 和正方形 $Q$ 的点写为无限自然数序列，使得将 $\sigma$ 映射到 $Q$ 成为可能。

事实上，路径$t_0$是任意点$\sigma$并且

$$t_0 = (i_1, i_2, i_3, \dots).$$

最后一个序列唯一确定点$(x_0, y_0)$，它对应于序列$[i_1, i_2, i_3, \dots]$。即使$t_0$可以表示为两个序列，那么它们都通向同一个点$(x_0, y_0)$。如果我们考虑到正方形的边长随着其等级的增加而趋于零，那么这一点很容易证明。因此，每个$t_0$对应于一个$(x_0, y_0)$。

现在让点 $(x_0, y_0) \in Q$ 是任意的，并且 $[i_1, i_2, i_3, \dots]$ 是该点的表示之一。取$t_0 = (i_1, i_2, i_3, \dots)$，我们确保在映射中，正方形$Q$的每个点至少对应于线段$\sigma$的一个点。这意味着$\sigma$映射到$Q$。请注意，此映射不是一对一的；非映射$Q$对应于两个、那些甚至四个点$\sigma$。
