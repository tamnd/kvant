我们邀请读者证明这种编号总是可能的。在图2上显示了前三个等级的方块，红色虚线表示方块编号的路径（从左下方块开始）。

继续推理，我们确信对于每个点$(x_0, y_0)$，平方$Q$都可以分配给一个或多个（多少个？）自然数序列，我们这样写：

$$(x_0, y_0) = [i_1, i_2, i_3, \dots]$$
$$(1 \leq i_1 \leq 4, 4i_k - 3 \leq i_k + 1 \leq 4i_k).$$

示例：$(1/3, 1/3) = [1, 3, 9, \dots]$；
$(1/2, 1/3) = [1, 3, 10, \dots] = [1, 14, 56, \dots]$;
$(1/2, 1/2) = [1, 3, 11, \dots] = [2, 8, 32, \dots] = [3, 9, 33, \dots] = [4, 14, 54, \dots].$

在这里我们可以证明每个这样的序列从$Q$确定一个唯一的点$(x_0, y_0)$。

3. 将线段 $\sigma$ 和正方形 $Q$ 的点写为无限自然数序列，使得将 $\sigma$ 映射到 $Q$ 成为可能。

事实上，路径$t_0$是任意点$\sigma$并且

$$t_0 = (i_1, i_2, i_3, \dots).$$

最后一个序列唯一确定点$(x_0, y_0)$，它对应于序列$[i_1, i_2, i_3, \dots]$。即使$t_0$可以表示为两个序列，那么它们都通向同一个点$(x_0, y_0)$。如果我们考虑到正方形的边长随着其等级的增加而趋于零，那么这一点很容易证明。因此，每个$t_0$对应于一个$(x_0, y_0)$。

现在让点 $(x_0, y_0) \in Q$ 是任意的，并且 $[i_1, i_2, i_3, \dots]$ 是该点的表示之一。取$t_0 = (i_1, i_2, i_3, \dots)$，我们确保在映射中，正方形$Q$的每个点至少对应于线段$\sigma$的一个点。这意味着$\sigma$映射到$Q$。请注意，此映射不是一对一的；非映射$Q$对应于两个、那些甚至四个点$\sigma$。
