到斜面，仍然等于重力的分力，即
$$F \sin(\beta - \alpha) = mg \cos \alpha.$$
对于这些平行于斜面的力的分量，我们可以写成
$$F \cos(\beta - \alpha) = mg \sin \alpha = ma.$$
由最后两个等式我们发现：
$$tg(\beta - \alpha) = \frac{g \cos \alpha}{g \sin \alpha + a},$$
在哪里
$$\beta = \alpha + arctg \frac{g \cos \alpha}{g \sin \alpha + a}.$$
值$a_0$可以从那些消息中找到，在$a = a_0$处，来自(4)和(5)的角度$\beta$的值重合：
$$\alpha + arctg \frac{g \cos \alpha}{g \sin \alpha + a_0} = \alpha + arctg \mu,$$
在哪里
$$a_0 = g \left( \frac{\cos \alpha}{\mu} - \sin \alpha \right).$$
所以，
在$a \leq a_0$（因此，也是匀速运动）
$$\beta = \alpha + arctg \mu,$$
在 $a > a_0$
$$\beta = \alpha + arctg \frac{g \cos \alpha}{g \sin \alpha + a}.$$
我们解决了问题。不过，我们将给出另一种解决方案。这是一个美丽的几何解决方案。
沿着舷梯匀速运动时，所有力的总和必须等于零。我们将力 $N$ 和 $F_{TP}$ 替换为等效力 $Q = N + F_{TP}$ (图 14)，并添加力 $Q$、$F$ 和 $mg$。它们应该形成一个闭合三角形。
请注意，力的方向 $Q$ 与斜面的垂线形成角度 $\delta$，使得
$$tg \delta = \frac{F_{TP}}{N} = \frac{\mu N}{N} = \mu,$$
也就是说，当改变力的大小和方向时 $F$ 力的方向 $Q$ 保持不变。因此，向量的绝对值 $F$ 如果垂直于向量则最小 $Q$ (图 15) （因为向量的大小和方向 $mg$ 不要改变）。此外，随着力量的视野 $F$ 会形成一个角度
$$\beta = \alpha + \delta = \alpha + arctg \mu$$
（角 $\beta$ 和 $\alpha + \delta$ 与边相互垂直的角相等）。
当盒子以加速度$a < a_0$移动时，问题以完全相同的方式解决。在这种情况下，向量 $mg$、$Q$ 和 $F$ 的总和必须等于 $ma$ (图 16)。这将改变力$F$的绝对大小，但不会改变其方向。
在 $a > a_0$ 处，当力 $N$、$F_{TP}$、$a$ 以及$Q$ 等于 0 时，力 $F$ 必须连接向量 $mg$ 和 $ma$ (图 17) 的末端。很容易看出，在这种情况下
$$\beta = arctg \frac{g + a \sin \alpha}{a \cos \alpha} = \alpha + arctg \frac{g \cos \alpha}{g \sin \alpha + a}.$$
