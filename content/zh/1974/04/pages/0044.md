2°。定义 1 和 2 是等价的：如果 φ 是定义 1 意义上的数 z = a + bi ≠ 0 的自变量，则满足等式 (1)；相反，如果 φ 是定义 2 意义上的复数 z = a + bi ≠ 0 的自变量，则 φ 是实轴正方向与向量 z 之间的角度。 a > 0、b > 0 的这一陈述直接来自 图（参见第 41 页）以及正弦和余弦的定义。对于其他数字 z，证明是类似的（检查一下！）。

因此，选择定义 1 或定义 2 中的哪一个作为初始定义并不重要，另一个将是必要且有价值的标准。

3°。对于数字 z = 0，参数的概念不存在。因此，为了简洁起见，在所有与论证概念相关的进一步讨论中，我们将假设（这一点不能忘记！）z ≠ 0。

4°。对于固定复数 z ≠ 0，参数的确定不明确：如果 φ₀ 是数字 z 的非作用参数，则每个数字

$$\varphi_0 + 2k\pi, \quad k = 0, \pm 1, \pm 2, \dots,$$

也是相同数字 z 的自变量，并且与 (2) 中指示的任何数字不重合的数字都不是数字 z 的自变量（证明它！）。

因此，对于每个固定数 z ≠ 0，都有无限多个参数，其中 dyres 的每两个负 dyres 都是 2π 的倍数。

5°。 4° 中描述的参数的歧义使得理解复数参数的运算变得困难。但通常正是由于这种模糊性，才有可能解决相当困难的问题。

在最近的一些初等数学中，自变量的定义包括0 ≤ φ < 2π形式的限制，即认为复数z的自变量是正轴与向量z之间的最小非负角。那么对于每个数字 z ，参数都是唯一确定的，乍一看似乎整个理论应该更简单。然而，这样的限制只会使参数的正确运算进一步复杂化（例如，两个复数的参数之和并不总是任何复数的参数）。有时这会导致显着的不明显 *)，因此最好坚持定义的一般优先级（1 或 2）。

复数参数

让我们考虑一下寻找复数参数的问题。但首先，让我们就符号达成一致。

为了表明数字 φ 是复数 z 的参数，我们写

$$\varphi = \arg z \text{ или } \arg z = \varphi.$$

(3) 例如，哪一个对应关系

$$\frac{\pi}{2} = \arg i$$

和

$$\arg i = \frac{\pi}{2}$$

仅表示数字 π/2 是数字 i 的自变量。

请注意，对应关系 (3) 虽然在形式上看起来像等式，但它是不可数的。然而，普通等式的性质如下：如果 A = B 且 B = C，则 A = C（A、B、C 是数字或几何图形）。但等式（3）不具备这个性质。例如，我们可以这样写

$$\frac{\pi}{4} = \arg (1 + i), \arg (1 + i) = \frac{9\pi}{4},$$
