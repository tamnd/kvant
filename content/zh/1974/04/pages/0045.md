$\frac{\pi}{4} \neq \frac{9\pi}{4}$.

因此，对应关系（3）可以读作如下：“f等于数的自变量 $z$ 或“数字参数” $z$ 等于 $\varphi$”，但这些短语的含义只有一个： $\varphi$ 是数字参数 $z$ 或者，换句话说， $\varphi$ 是数字参数之一 $z$，如（2）中所述。这个事实被写成公式的形式

$$\arg z = \varphi_0 + 2k\pi,$$

$$k = 0, \pm 1, \pm 2, \dots$$

例如，数字$i$的参数的所有值都包含在公式中

$$\arg i = \frac{\pi}{2} + 2k\pi, k = 0, \pm 1, \pm 2, \dots$$

请注意，在求解三角方程时，经常会遇到 (4) 中的“等式”。例如，方程$\sin x = 1$的解写如下：

$$x = \frac{\pi}{2} + 2k\pi, k = 0, \pm 1, \pm 2, \dots$$

最后一个“等式”的含义与对应关系（4）相同：对于每个整数$k$，数字$\frac{\pi}{2} + 2k\pi$满足方程$\sin x = 1$，并且只有这些数字才是方程$\sin x = 1$的根。

要找到复数$z = a + bi \neq 0$的自变量的所有值，需要找到满足两个等式（1）的所有数字$\varphi$，即一起求解方程（1）。

示例1.数字$z = -5$的参数的所有值的名称。

由于$a = \text{Re} z = -5, b = \text{Im} z = 0$，系统(1)中第一个方程$\cos \varphi = -1$的解是数字$\varphi = \pi + 2k\pi, k = 0, \pm 1, \pm 2, \dots$，第二个方程$\sin \varphi = 0$的解是数字$\varphi = n\pi, n = 0, \pm 1, \pm 2, \dots$。

方程的共同根是数字

$$\varphi = \pi + 2k\pi, k = 0, \pm 1, \pm 2, \dots$$

答案：$\arg (-5) = \pi + 2k\pi, k = 0, \pm 1, \pm 2, \dots$。

请注意，示例 1 中的答案可以写成另一种形式，例如：

$$\arg (-5) = -\pi + 2n\pi, n = 0, \pm 1, \pm 2, \dots,$$

或者

$$\arg (-5) = 3\pi + 2m\pi, m = 0, \pm 1, \pm 2, \dots$$

必须记住，所有这些公式在不同的条目中都是等价的（这些答案中的每一个都包含数字$-5$的参数的所有值），也就是说，这些是用不同公式写成的相同答案。

复数$z = a + bi \neq 0$的自变量可以找到程序第一点$z = a + bi$（例如，使用复数的几何解释），然后使用方程（1）中的一个（任意）（根据公式（4）给出示范答案）。

答案：$\arg (-1 + i) = \frac{3\pi}{4} + 2k\pi, k = 0, \pm 1, \pm 2, \dots$。

注意，如果$\varphi = \arg (a + bi), a \neq 0$，那么

$$\tg \varphi = \frac{b}{a}.$$
