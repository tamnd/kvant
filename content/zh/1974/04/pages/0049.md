⟦folio 47⟧

莫斯科国立大学
以 M.V. 命名罗蒙诺索夫

我们已经讨论过以 M.V. 命名的莫斯科国立大学的物理和数学系。罗蒙诺索夫*）。以下是1973年这些院系数学和物理入学考试的材料。

Matematika

力学与数学学院
选项1

1. 解方程
$$2(\cos x)^{5/2} - \cos 2x = 1 + \frac{\sin x}{\sqrt{3}}(1 - \sqrt{\cos x}).$$

2. 在梯形$ABCD$中，点$K$是底$AB$的中点，点$M$是底$CD$的中点。如果已知$DK$是梯形角$D$的平分线，$BM$是梯形角$B$的平分线，梯形下底的最小角为$60^\circ$，周长为30，求梯形的面积。

3. 解决不平等问题
$$5x + \sqrt{6x^2 + x^3 - x^4} \log_2 x > (x^2 - x) \log_2 x + 5 + 5\sqrt{6 + x - x^2}.$$

4. 点$K$和$M$是底面积$ABC$为$p$的三角形参数$ABCD$的对应边$AB$和$AC$。如果截面$MDK$的面积为$q$，且paramid高的底边落在三角形$ABC$中线的交点处，求面$BDC$的面积。

5. 找到所有满足条件的数字$x, y$
$$\begin{cases} \sqrt{2x^2y^2 - x^4y^4} = y^6 + x^2(1 - x), \\ \sqrt{1 + (x + y)^2} + x(2y^3 + x^2) \leq 0. \end{cases}$$

*) 参见 «Kvant»，1973 年，第 4 期。

选项2

1. 解方程
$$1 + \cos 2x + \cos^2 x \log \sqrt{3} tg^2 x + 3 \sin x = 2 \sin x \log_{1/3} tg^3 x.$$

2. 在梯形$ABCD$中，点$K$和$M$分别是底边$AB$和$CD$对应的中点。已知$AM \perp DK$和$CK \perp BM$，角度$CKD$等于$60^\circ$。如果梯形的高度为1，求梯形的面积。

3. 解决不平等问题
$$\sqrt{2 - 5x - 3x^2} + 2x > 2x \times 3^x \sqrt{2 - 5x - 3x^2} + 4x^2 \cdot 3^x.$$

4. 在三角形paramid$ABCD$中，通过等于$a$的边$AD$和点$E$（边$BC$的中间），绘制一个截面，该截面与克$ACD$和$ABD$形成相应的角度$\alpha$和$\beta$。如果横截面积$ADE$等于$S$，求聚酰胺的体积。

5. 找到所有满足条件的数字$x, y$
$$\begin{cases} 4y^2 - 2x^2 = \sqrt{2(x + 2y)^2 - (x + 2y)^4}, \\ x^4 + 2 \leq 4y(x^2 - 1). \end{cases}$$

计算数学与控制论学院

选项3

1. 求解方程组
$$\begin{cases} \sin y \cos x + \sin x = 0, \\ 2 \cos^2 y + \sin y \sin x = \cos 2y \cos x. \end{cases}$$

2. 解决不平等问题
$$\log_2 x - \frac{4}{25} \left( \frac{x^2 - 14x + 51}{50} \right) \leq 0.$$

3. 在直角三角形$ACB$中，从直角$C$的顶点绘制平分线$CL = a$和中线$CM = b$。求三角形$ACB$的面积。

4. 点 $A, B, C, D, E, F$ 位于半径为 $\sqrt{2}$ 的球的表面上。
