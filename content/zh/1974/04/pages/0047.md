复数的三角形式

让我们考虑一下复数的三角形式的概念。回想一下，复数 $z = a + bi$ 的模数是

$$r = |a + bi| = \sqrt{a^2 + b^2}.$$

设$\varphi = \arg(a + bi)$，我们将公式(1)改写如下：

$$\cos \varphi = \frac{a}{r}, \sin \varphi = \frac{b}{r},$$

$a = r \cos \varphi, b = r \sin \varphi$ 来自哪里，然后

$$a + bi = r(\cos \varphi + i \sin \varphi).$$

因此，任何复数 $a + bi \neq 0$ 都可以写成形式 (6)，如果 $r$ 是数 $a + bi$ 的模，$\varphi$ 是该数的自变量之一：

$$r = |a + bi|, \varphi = \arg(a + bi).$$

反之亦然（证明！）：如果复数$a + bi$以形式（6）表示，如果$r > 0$，则

$$r = |a + bi|, \varphi = \arg(a + bi).$$

定义。复数$z$的表示形式

$$z = r(\cos \varphi + i \sin \varphi),$$

(7) 若$r > 0$，称为复数的三角形式。

上式意味着每个复数$z \neq 0$都可以用三角函数形式（7）表示，并且

$$r = |z|, \varphi = \arg z.$$

为了找到给定复数的三角形式，您需要找到该数的方法，该数的一些参数，然后将该数写成形式（7）。如果在这种情况下$|z| = r = 1$，则像往常一样，公式（7）中的整个$r$被省略，也就是说，在这种情况下，三角符号形式具有以下形式

$$z = \cos \varphi + i \sin \varphi.$$

例如，对于数字 $i$ 条目

$$i = \cos \frac{\pi}{2} + i \sin \frac{\pi}{2}$$

是写这个数的三角形式。

请注意，由于 arg $z$ 的多义性，固定复数的三角形式也是不明确的。例如，对于数字$i$，三角函数形式也可写为

$$i = \cos \frac{5\pi}{2} + i \sin \frac{5\pi}{2},$$

$$i = \cos \left(-\frac{3\pi}{2}\right) + i \sin \left(-\frac{3\pi}{2}\right)$$

和其他人。

有必要强调的是，并非所有通过三角函数表示的复数都是该数的三角形式。例如，将数字$i$写为$i = \cos \frac{\pi}{2} + i \sin \frac{5\pi}{2}$或$i = (-1)\left(\cos \frac{3\pi}{2} + i \sin \frac{3\pi}{2}\right)$不是数字$i$的三角形式。由于数字$i$的参数是数字$i$是数字$i$。

$$\frac{\pi}{2} + 2k\pi, k = 0, \pm 1, \pm 2, \dots,$$

并且只有它们，那么数字 $i$ 的三角形式必然具有以下形式

$$z = 1 + \cos \frac{10\pi}{9} + i \sin \frac{10\pi}{9}$$

可以用以下形式表示（检查一下！）：

$$z = 2 \cos \frac{5\pi}{9} \left(\cos \frac{5\pi}{9} + i \sin \frac{5\pi}{9}\right) =$$

$$= 2 \cos \frac{14\pi}{9} \left(\cos \frac{14\pi}{9} + i \sin \frac{14\pi}{9}\right).$$
