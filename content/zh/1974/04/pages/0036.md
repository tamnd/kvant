**M214。直角三角形 f(x) = ax^2 + bx + c poppies 意味着方程 f(x) = x 无实根。证明方程 f(f(x)) = x 也没有实根。**

这个问题可以纯代数地解决，使用以下事实：如果 f(x) 是多项式，则 f(f(x)) - x 始终可被 f(x) - x 整除（作为多项式），即

$$f(f(x)) - x = (f(x) - x)g(x).$$

这里g(x)是二次多项式。简单计算表明该多项式的判别式为负。然而，大多数读者使用与图表相关的视觉信息，贡献了更丰富多彩的解决方案。

方程 f(x) = x 无实根的条件意味着抛物线 y = f(x) 完全位于直线 y = x (图 6) 的上方或下方。换句话说，对于所有 x

$$f(x) > x,$$

但对于所有 x

$$f(f(x)) > f(x) > x,$$

或对于所有 x

$$f(x) < x,$$

然后对于所有 x

$$f(f(x)) < f(x) < x.$$

因此，一般情况下方程 f(f(x)) = x 无解。
