⟦folio 44⟧

读一下$\varphi = \arg(a + bi)$。例如，对于数字 $-1 + i$，值 $\varphi = -\pi/4$ 是方程 (5) 的解，但不是该数字的自变量。

但如果我们先确定点$a + bi$位于哪个象限，然后再求方程（5）的解，即该象限内的角度，我们就得到了数$a + bi$的自变量（证明！）。

示例 3. 来自数字 $1 - i\sqrt{3}$ 的参数的名称。

点$1 - i\sqrt{3}$位于第四节。我们找到方程（5）的某个解，即$\arg(\varphi) = -\sqrt{3}$，即本季度的角度，例如：$\varphi = -\pi/3$。

答案：$\arg(1 - i\sqrt{3}) = -\frac{\pi}{3}$。

在这个例子中，问题的含义是不明确的。以下答案也是正确的：

$$\arg(1 - i\sqrt{3}) = \frac{5\pi}{3},$$
$$\arg(1 - i\sqrt{3}) = -\frac{7\pi}{3},$$
$$\arg(1 - i\sqrt{3}) = \frac{41\pi}{3}$$

和其他人。

示例 4. 号码 $\sqrt{3} + i$ 的名称。

与示例 2 或 3 中的做法类似，我们发现（发现！）：

$$\arg(\sqrt{3} + i) = \frac{\pi}{6}$$

（也就是说，$\pi/6$是数字$\sqrt{3} + i$的参数之一）。仍然需要弄清楚如何编写答案：指示一个参数值是否足够，还是需要找到所有参数值？

让我们回想一下这个问题：求解方程 $x^2 = 1$。该方程有两个根 $x_1 = 1$ 和 $x_2 = -1$。为了使答案完整，必须包括两个根。必要的答案常常可以在几何问题中找到。例如，如果 $AC = 8$ cm、$BC = 7$ cm、$\angle A = \pi/3$，则求三角形 $ABC$ 的边 $AB$。完整答案应该是：$AB = 3$厘米或$AB = 5$厘米（证明！）。

在我们的示例 4 中也是如此：为了使答案完整，您需要找到数字 $\sqrt{3} + i$ 的参数的所有值。由于已经找到了一个参数$\pi/6$，因此我们使用公式（4）找到该数字的参数的所有值。

答案：$\arg(\sqrt{3} + i) = \frac{\pi}{6} + 2k\pi, k = 0, \pm 1, \pm 2, \dots$。

所以问题 4 是问题 2 的简单简短版本。

让我们注意一个常见的错误。否则，申请者试图用公式$\varphi = \arctg\frac{b}{a}$来求数字$a + bi$的自变量，有的甚至将此公式作为自变量的定义。然而，对于每个$x$，参数函数$x$只有一个值，$-\frac{\pi}{2} < \arctg x < \frac{\pi}{2}$。这意味着公式$\arg(a + bi) = \arctg\frac{b}{a}$仅对$a > 0$有效，并且它仅给出参数的值之一。

可以证明（证明！）以下公式的有效性：

$$\arg(a + bi) = \begin{cases} \frac{\pi}{2}, \text{ если } a = 0, b > 0; \\ -\frac{\pi}{2}, \text{ если } a = 0, b < 0; \\ \arctg\frac{b}{a}, \text{ если } a > 0; \\ \pi + \arctg\frac{b}{a}, \text{ если } a < 0. \end{cases}$$

使用此公式，您可以找到参数的值之一，但通常更容易做到，如示例 2 或 3 中所做的那样。
