让我们看看船的速度如何随时间变化。

由于$m\Delta v = F\Delta t$和$F = -kv$，那么
$$\frac{\Delta v}{\Delta t} = -\frac{k}{m} v.$$

我们发现船速的变化率与速度本身成正比。但是，众所周知（例如，参见 S. D. Osyatinsky 和 ​​L. Z. Rumshinsky 的文章“Exponenta”，«Kvant»，1972 年，第 12 期），如果任何量的变化与该量本身成正比，则该量根据指数规律变化，因此

$$v = v_0 e^{-\frac{k}{m} t}.$$

从这个公式可以得出$v = 0$在$t \to \infty$。也就是说，船可以在无限长的时间内沿着路径$s_2$行驶！这意味着条件$F \sim v$下问题的第二个问题应该澄清。如果身体的速度降低了，例如降低了一千倍（当然，数字可以不同；这完全取决于实验的目标），我们就会认为身体已经停止了。

$$N + F \sin(\beta - \alpha) - mg \cos \alpha = 0.$$ (1)

沿着斯科德尼，盒子以加速度 $a$ 移动（在某些情况下匀速运动 $a = 0$），因此力的投影总和必须等于 ma：

$$F \cos(\beta - \alpha) - mg \sin \alpha - \mu N = ma.$$ (2)

$$F = \frac{ma + mg(\sin \alpha + \mu \cos \alpha)}{\cos(\beta - \alpha) + \mu \sin(\beta - \alpha)}.$$ (3)

$$\cos(\beta - \alpha) + \mu \sin(\beta - \alpha).$$

$$tg \gamma = \mu; \quad \gamma = \arctg \mu;$$

$$\sin \gamma = \frac{\mu}{\sqrt{1 + \mu^2}}; \quad \cos \gamma = \frac{1}{\sqrt{1 + \mu^2}}.$$

然后我们可以写：

$$\cos(\beta - \alpha) + \mu \sin(\beta - \alpha) = \sqrt{1 + \mu^2} \cos(\beta - \alpha - \gamma).$$
