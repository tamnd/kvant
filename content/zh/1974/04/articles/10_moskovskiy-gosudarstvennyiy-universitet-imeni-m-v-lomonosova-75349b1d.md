莫斯科国立大学
以 M.V. 命名罗蒙诺索夫

我们已经讨论过以 M.V. 命名的莫斯科国立大学的物理和数学系。 Lomonosov *).以下是1973年这些院系数学和物理入学考试的材料。

Matematika

力学与数学学院
选项1

1. 解方程
$$2(\cos x)^{5/2} - \cos 2x = 1 + \frac{\sin x}{\sqrt{3}}(1 - \sqrt{\cos x}).$$

2. 在梯形$ABCD$中，点$K$是底$AB$的中点，点$M$是底$CD$的中点。如果已知$DK$是梯形角$D$的平分线，$BM$是梯形角$B$的平分线，梯形下底的最小角为$60^\circ$，周长为30，求梯形的面积。

3. 解决不平等问题
$$5x + \sqrt{6x^2 + x^3 - x^4} \log_2 x > (x^2 - x) \log_2 x + 5 + 5\sqrt{6 + x - x^2}.$$

4. 点$K$和$M$是底面积$ABC$为$p$的三角形参数$ABCD$的对应边$AB$和$AC$。如果截面$MDK$的面积为$q$，且paramid高的底边落在三角形$ABC$中线的交点处，求面$BDC$的面积。

5. 找到所有满足条件的数字$x, y$
$$\begin{cases} \sqrt{2x^2y^2 - x^4y^4} = y^6 + x^2(1 - x), \\ \sqrt{1 + (x + y)^2} + x(2y^3 + x^2) \leq 0. \end{cases}$$

*) 参见 «Kvant»，1973 年，第 4 期。

选项2

1. 解方程
$$1 + \cos 2x + \cos^2 x \log \sqrt{3} tg^2 x + 3 \sin x = 2 \sin x \log_{1/3} tg^3 x.$$

2. 在梯形$ABCD$中，点$K$和$M$分别是底边$AB$和$CD$对应的中点。已知$AM \perp DK$和$CK \perp BM$，角度$CKD$等于$60^\circ$。如果梯形的高度为1，求梯形的面积。

3. 解决不平等问题
$$\sqrt{2 - 5x - 3x^2} + 2x > 2x \times 3^x \sqrt{2 - 5x - 3x^2} + 4x^2 \cdot 3^x.$$

4. 在三角形paramid$ABCD$中，通过等于$a$的边$AD$和点$E$（边$BC$的中间），绘制一个截面，该截面与克$ACD$和$ABD$形成相应的角度$\alpha$和$\beta$。如果横截面积$ADE$等于$S$，求聚酰胺的体积。

5. 找到所有满足条件的数字$x, y$
$$\begin{cases} 4y^2 - 2x^2 = \sqrt{2(x + 2y)^2 - (x + 2y)^4}, \\ x^4 + 2 \leq 4y(x^2 - 1). \end{cases}$$

计算数学与控制论学院

选项3

2. 解决不平等问题
$$\log_2 x - \frac{4}{25} \left( \frac{x^2 - 14x + 51}{50} \right) \leq 0.$$

3. 在直角三角形$ACB$中，从直角$C$的顶点绘制平分线$CL = a$和中线$CM = b$。求三角形$ACB$的面积。

4. 点 $A, B, C, D, E, F$ 位于半径为 $\sqrt{2}$ 的球的表面上。

物理学院

选项4

1. 解方程

$$\left(\frac{1}{4}\right)^{3x} - \left(\frac{1}{8}\right)^{x-1} - 128 = 0.$$

物理学院

以下是物理学院入学考试选项中的一些问题。

1. 质量比为 1:2 的两个小物体同时开始沿着半径为 $R$ (图 1) 的半球内表面无摩擦地滑动。物体的冲击力是完全无弹性的。撞击后身体与垂直方向偏离的角度 $\alpha$ 是多少？

2. 在一个长度为$l = 10$米、重量为$P = 500$公斤的移动平台边缘，有两个人：第一个人的重量为$P_1 = 60$公斤，第二个人的重量为$P_2 = 40$公斤。在$t = 0$时刻，他们开始沿着平台朝对方奔跑，第一个的速度是第二个的两倍。当第一个人到达终点时，平台会滚动多远$x$？忽略平台对导轨的摩擦力。

3. 一块冰块漂浮在盛有水的容器中，里面卡着一只猎枪猪肉。冰的质量为$M$，破碎机的质量为$m$，容器中水的温度为$0^\circ$ C。破碎机开始下沉需要消耗的最少热量是多少？冰的密度$\rho_1$，冰的熔化潜热$\lambda$，铅的密度$\rho_2$。

4. 该循环由两个等压线和两个等压线 (图 2) 组成。点 1 和 3 处的气体温度等于相应的 $T_1$ 和 $T_3$。如果已知点 2 和点 4 位于同一条等温线上，则确定每个循环一克分子气体所做的功。

5. 当灯泡接入电压为$U = 200$v的网络时，消耗功率$W_1 = 40$vm并明亮地燃烧，灯泡的温度为$t_1 = 3000^\circ$C。当连接到具有 $U = 100$vm 的网络时，灯泡消耗功率 $W_2 = 25$vm 并且仍然点亮，因为灯泡的温度为 $t_2 = 1000^\circ$C。求灯泡$R_0$在温度$t = 0^\circ$C下的电阻值。

6. 确定示波器阴极射线管靠近屏幕的电子束中的电子浓度。梁的横截面为$S = 1$ mm²，电流强度为$I = 1,6$ mA。电子从阴极流出时没有初速度，并在阴极和异头物之间通过电势差$U = 28500$V的电场加速。

电子电荷$e = 1,6 \cdot 10^{-19}$ k，质量$m = 9,1 \cdot 10^{-31}$ k$^2$。

7. 两条光线落在半径为 $R = 30$ cm 的半球镜 CAD 上，平行于线 $AB$，穿过中心 $O$ 并垂直于 CD (图 3)。

一束光传播一段距离 $a = 24$ 厘米，另一个在一定距离处 $a_1 = 1$ 距线厘米 $AB$。经过镜子反射后，这些光线将交叉 $AB$ 在某些两点上。求距离 $x$ 在这些点之间。

8. 将折射角$\alpha = 45^\circ$、玻璃折射率$n$的玻璃棱镜和焦距$f$的细线放置在桌子上。透镜的主光轴垂直于棱镜的垂直面，确定波长的水平平行光束被引导到棱镜的垂直面上。距主光轴$x$的距离是多少处，穿过透镜的光线与透镜会合？

修正案

«Kvant» 1974 年第 2 期，第 12 页。 61 问题 1（NSU，选项 1）的解决方案的结尾应如下所示：$u = 22, |1 - y^2| = 3^{11}$，从这里，考虑到 ODZ，我们得到 $y = -\sqrt{3^{11} + 1}$。
