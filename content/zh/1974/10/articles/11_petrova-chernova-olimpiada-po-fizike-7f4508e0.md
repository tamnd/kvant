任务 2（10 个等级）

让我们考虑两个报告系统中的事件 - 静止和移动，我们将其与机器$B$相关联。我们假设运动发生时没有滑动并且没有力。

在初始阶段（$v_A = v_B = v$），静止报告系统中地机系统的总冲量等于

$$P_1 = 2mv$$

（为了方便起见，我们假设汽车的质量相同）。在此期间，系统的总机械能为

$$E_1 = 2m \frac{v^2}{2} = mv^2.$$

系统的总能量由燃料内能中的机器动能$A$和$B$组成：

$$W_1 = E_1 + U_1.$$

由于“归属于”机器$B$的能量不会随时间变化，我们将其表示为$W_B (W_B = \text{const})$，“归属于”机器$A$的能量将表示为$W_1A = E_1A + U_1A$。因此，在运动的第一阶段 ($v_A = v_B = v$) 系统的能量等于

$$W_1 = W_B + E_1A + U_1A.$$

我们假设燃料储存期间释放的所有能量都用于提高自动化速度$A$。

由于我们的系统是封闭的，因此总冲量必须守恒。机器的冲量$B$$P_1B = \text{const}$和机器的冲量$A$改变值$m \Delta v_A = mv$（我们忽略由于去除部分燃料而导致的机器质量的变化）。因此，地球的冲量改变了相同的量，即地球的速度增加，这可以由对应关系$|Mv_2| = |mv|$确定：

$$|v_3| = \frac{m}{M}|v|.$$

（同时$v_3 = -\frac{m}{M}v$；我们认为轮子旋转而不打滑。）系统的机械能变得相等

$$E_2 = \frac{mv^2}{2} + \frac{m(2v)^2}{2} + \frac{M\left(\frac{m}{M}v\right)^2}{2}.$$

由于内部能量的变化（由于燃料储存），机械能会增加。现在让我们写下系统的总能量：

$$W_2 = W_B + E_2A + E_3 + (U_1A - \Delta U).$$

根据能量守恒定律，$W_2 = W_1$，即$E_2A - E_1A + E_3 - \Delta U = 0$，或

$$\frac{3}{2}mv^2 + \frac{m^2}{2M}v^2 - \Delta U = 0.$$

因此，

$$\Delta U = \Delta E = \frac{3}{2}mv^2 + \frac{m^2}{2M}v^2.$$

现在让我们考虑移动系统中与机器$B$相关的事件。让我们在保留假设的情况下进行上述所有推理。系统的初始冲量

$$P'_1 = -Mv$$

（因为地球相对于机器$B$以速度$-v$移动）。初始时期的机械能等于地球相对于机器运动的动能$B$)：

$$E'_1 = \frac{Mv^2}{2}.$$

所以，不存在低悖论。燃料燃烧过程中释放的能量所做的功将增加整个系统的机械能。因此，在能量变化问题的条件下得出的结论是不正确的。
