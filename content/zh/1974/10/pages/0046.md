九年级，任务 5。
$$A = 10^2 a + 10 b + c$$
其中$a, b$和$c$是数字$A$的数字。他们需要找到$A$使得$3 A = (10^2 + 10 + 1)(a + b + c)$。
从这里
$$37 (a + b + c) = 10^2 a + 10 b + c.$$
因此，
$$63 a = 27 b + 36 c$$
或者
$$7 a = 3 b + 4 c.$$
我们假设$b \geq c$。如果$7 a = 3 b + 4 c$，则$7 (a - c) = 3 (b - c)$。从这里
$$b - c = a - c = 0$$
或者
$$b - c = 7, a - c = 3.$$
如果$b < c$，则$7 (a - b) = 4 (c - b)$，从何而来
$$c - b = 7, a - b = 4.$$
（请记住，$a, b$和$c$是数字）。最终得到如下解：数字$A$，其中所有数字都相同（这样的数字有9个）；号码370、481、592和号码407、518、629——总共十五个号码。
