如果面具是恒定的，那么对于初始子弹速度$v$的所有值，释放的热量$Q$是相同的。

我们考虑子弹初速为$v_0$的情况。显然，这是子弹射穿码头所需的最低飞行速度。在这种情况下，穿过码头的子弹将具有与码头相同的速度。让我们表示这个速度 $u$ 并写出这种情况的动量和能量守恒定律：

$$mv_0 = (m + M)u,$$
$$\frac{mv_0^2}{2} = \frac{(m + M)u^2}{2} + Q.$$

从这里

$$Q = \frac{mMv_0^2}{2(m + M)}.$$

现在等式（1）-（3）可以组合成一个系统，解决这个系统后，我们可以找到值$V$。从(1)和(2)中消去速度​​$v_1$，我们得到$V$的二次方程：

$$V^2 - 2\frac{mv}{m + M}V + \frac{2mQ}{M(m + M)} = 0,$$

在哪里

$$V = \frac{m}{m + M}v \pm \sqrt{\frac{m^2}{(m + M)^2}v^2 - \frac{2mQ}{M(m + M)}}.$$

在这里代入 (3) 中的值 $Q$ 并得到

$$V = \frac{m}{m + M}\left(v \pm \sqrt{v^2 - v_0^2}\right).$$

现在我们来分析一下方程的两个根是否符合该问题的条件。码头的冲量在数值上等于阻力的冲量，即值$F_C$与其作用时间$t$的乘积。显然，子弹的初速越大，子弹通过坞站的速度就越快，即时间$t$也就越短。因此，当子弹速度等于$v_0$时，坞站速度最大。随着子弹初始速度的增加，码头的速度会降低。这对应于 $V$ 的以下表达式：

$$V = \frac{m}{m + M}\left(v - \sqrt{v^2 - v_0^2}\right).$$

在$v = 2v_0$
$$V = \frac{m}{m + M}\left(2 - \sqrt{3}\right)v_0,$$

并在 $v = nv_0$
$$V = \frac{m}{m + M}\left(n - \sqrt{n^2 - 1}\right)v_0.$$
