⟦folio 42⟧

九年级
第一天
1. 找到 $|36^k - 5^l|$ 形式的最小数，其中 $k$ 和 $l$ 是自然数。
2. 给定两个半径为 $R$ 和 $r$ 的圆，外切。构造各种梯形$ABCD$，使得每个圆都接触梯形的两侧和一个底边。找到可能的最小边长$AB$。
3. 圆圈周围写有 50 个数字，每个数字都等于 +1 或 -1。您需要找出所有数字的乘积。在一个问题中，您可以找出数字三边的乘积。最少要问多少个问题？
4. 平面上有$n$向量，每个向量的长度为1。所有$n$向量之和等于零向量。证明向量可以被封闭，使得对于所有 $k = 1, 2, \dots, n$ 满足以下条件：向量之和的长度至多为 2。
第二天
5. 找到所有具有以下性质的三位数$A$：从数字$A$通过其数字的各种排列获得的所有数字的算术平均值等于$A$。
6. 给定一个凸多边形，其中不能放置面积为 1 的三角形。证明这个多边形可以放在面积为4的三角形中。
7. 是否可以按照这样的顺序排列 1, 2, 3, ..., 100，使得没有两个数字的 half-uma 等于它们之间的任何数字？
10年级
第一天
1. 真正的$a, b, c$是什么平等
$$|ax + by + cz| + |bx + cy + az| + |cx + ay + bz| = |x| + |y| + |z|$$
对于所有真实的$x, y, z$都是如此？
2. 给定一个正方形$ABCD$。点$P$和$Q$分别位于边$AB$和$BC$，以及$BP = BQ$。设 $H$ 为从点 $B$ 到线段 $PC$ 的垂线的底边。证明角$DHQ$是直角。
3. 指定了几个红色点和几个窦点。其中一些是通过段连接的。如果连接到某个点的一半以上的颜色与其颜色不同，我们称该点为“特殊”点。如果至少有一个特殊点，则选择任何特殊点并用不同的颜色重新绘制。证明经过有限步数后将不存在奇异点。
4. 平面上有$n$个向量，每个向量的长度为1。所有向量的和等于零向量。证明向量可以被封闭，使得对于所有 $k = 1, 2, \dots, n$ 满足以下条件：向量之和的长度至多为 2。
第二天
5. 在线段$0 \leq x \leq 1$上，给出函数$f$。已知这个函数是非负的并且$f(1) = 1$。此外，对于任意两个数字$x_1$和$x_2$，使得$x_1 \geq 0, x_2 \geq 0$和$x_1 + x_2 \leq 1$，以下条件成立：向量之和的长度至多为2。
6) 是不是每个人都$x$
$$f(x) \leq 1, 9 x$$
6. 给定一个面积为 1 的三角形 $ABC$。令 $A_1, B_1$ 和 $C_1$ 分别为边 $BC$、$AC$ 和 $AB$ 的中点。如果点$K, L$和$M$分别位于线段$AB_1, CA_1$和$BC_1$上，则三角形$A_1B_1C_1$和$KLM$的公共部分的最小面积是多少？
7. 是否可以按这样的顺序排列数字 1、2、3、...、100，使得对于任何数字，它们的 half-uma 等于放置在它们之间的任何数字？
