在今年的 «Kvant» 期刊第 1 期中，E. B. Dynkin 发表了以下问题：

**M185** *。在面积为1的咖啡馆上，放置5个火焰，每个火焰的面积不小于$1/2$。证明你会找到两个公共部分面积不小于$1/5$的火焰。

我们将分析该问题的解决方案并讨论其一些概括和变体*)。我们的演示将伴随任务，其中特别会注意到证据的个别细节；最困难的问题的编号用星号标记。

我们将用字母 $M$ 来表示长袍本身及其面积（按照惯例等于 1）；我们用$M_1$、$M_2$、$M_3$、$M_4$和$M_5$表示长袍上的补丁（以及这些补丁的区域），并且，比如说，补丁的承诺部分$M_1$和$M_2$（以及这个公共部分的区域）用$M_{12}$表示；类似地，我们用$M_{123}$等表示面片$M_1$、$M_2$和$M_3$（及其面积）的公共部分。对于障碍物，例如，用$M_1$我们表示面片（几何函数）和该面片的面积（数字！），不应该让我们感到困惑 - 每次从文本中都会清楚我们使用什么意义符号$M_1$。

**我们开始解决问题**

从承诺所有补丁的果实这一事实来看

$$M_1 + M_2 + M_3 + M_4 + M_5 \geq \frac{5}{2}$$

长袍的大面积$M = 1$，因此我们的板块重叠 - 任务是估计它们公共部分的面积（更准确地说，估计数字$M_{12}$，$M_{13}, \dots, M_{45}$中最大的数字）。我们声称

$$M - (M_1 + M_2 + M_3 + M_4 + M_5) + (M_{12} + M_{13} + M_{14} + \dots + M_{45}) \geq 0.$$ (1)

事实上，如果补丁不重叠，那么就会有一个非负差$M - (M_1 + M_2 + M_3 + M_4 + M_5)$，等于长袍上根本没有被补丁覆盖的部分的面积。但事实上，我们的板块相交 - 总和 $M_1 + M_2 + M_3 + M_4 + M_5$ 远大于计划覆盖的长衫部分的总面积 $S$（其中，当然，$S \leq M = 1$）：长衫的部分 $M_{12}$ 在总和 $M_1 + M_2 + M_3 + M_4 + M_5$ 中被考虑两次，因为它包含在术语 $M_1$ 和术语中$M_2$，部分$M_{123}$ - 三次，等等。现在尝试证明这一点

$$S \geq \sum M_i - \sum M_{ij}.$$ (1')

这种情况与$n = 5$情况类似处理；让我们简单概述一下相应的推理。

首先，明确的是，为了使$n$块$M_1, M_2, \dots, M_n$的每个面积不小于$\alpha$且不重叠，需要它们的总面积$\sum M_i \geq n\alpha$不超过长袍的面积$M = 1$；这就是为什么

$$f_n(\alpha) = 0 \text{ при } 0 \leq \alpha \leq \frac{1}{n}.$$

接下来，考虑主要不等式 (4)（包含和排除公式，第 15 页）。从这个不等式可以得出

$$M - \sum M_i + \sum M_{ij} \geq 0 \tag{16}$$

（为什么？）;因此，

$$\sum M_{ij} \geq \sum M_i - M \geq n\alpha - 1.$$

并且由于一般情况下“补丁的成对交集”$M_{ij}$的总数等于$n$的对应数$C_n^2 = \frac{n(n-1)}{2}$乘以2，那么

$$f_n(\alpha) \geq \frac{1}{n(n-1)/2} (n\alpha - 1) = \frac{2}{n-1} \alpha - \frac{2}{n(n-1)}. \tag{17}$$

在这种情况下，不等式（17）只有变成等式（16）才能变成等式，也就是说，如果在包含和排除式（4）中，$\sum M_{ij}$后面的所有项都变成0（此外，如果所有补丁$M_i$都有面积$\alpha$并且完全覆盖长袍$M$）。但在这种情况下，“成对补丁交集”$M_{12}, M_{13}, \dots, M_{1n}$的$n - 1$覆盖补丁$M_1$而不重叠（因为都是$M_{ij} = 0$）。因为在这种情况下一切

$$M_{1i} = \frac{2}{n-1} \alpha - \frac{2}{n(n-1)},$$

那

$$(n - 1) \left[ \frac{2}{n-1} \alpha - \frac{2}{n(n-1)} \right] \leq \alpha,$$

因此$\alpha \leq \frac{2}{n}$（当然还有$\alpha \geq \frac{1}{n}$）。

接下来，我们必须将包含和排除的公式应用于补丁$M_i$（而不是整个长袍$M$），以及它们的交集$M_{ij}, M_{ijh}$等。例如，让我们将此公式应用于被“二阶补丁”$M_{12}, M_{13}, \dots, M_{1n}$覆盖的补丁$M_1$：

$$M_1 - \sum M_{1i} + \sum M_{1i1} i_2 - \sum M_{1i1} i_2 i_3 + \dots + (-1)^{n-2} \sum M_{1i1} i_2 \dots i_{n-2} + (-1)^{n-1} M_{123} \dots n \geq 0$$

（其中$i_1, i_2, \dots, i_{n-2} = 2, 3, \dots, n$）。

添加对应于补丁$M_1, M_2, \dots, M_n$的此类不等式的$n$，我们得到不等式

$$\sum M_i - 2 \sum M_{i1} i_2 + 3 \sum M_{i1} i_2 i_3 - \dots + (-1)^{n-2}(n-1) \sum M_{i1} i_2 \dots i_{n-1} + (-1)^{n-1} n M_{123} \dots n \geq 0 \tag{18}$$

（参见第 15 页的不等式 (5)）。从不等式 (4) 和 (18) 中，使用 $\sum M_{i1} i_2 i_3$ 项并不困难 - 为此，只需将 (4) 乘以 1/3 再乘以不等式 (18)：

$$M - \frac{2}{3} \sum M_{i1} + \frac{1}{3} \sum M_{i1} i_2 - \frac{1}{3} \sum M_{i1} i_2 i_3 i_4 + \dots + (-1)^{n-1} \frac{n-3}{3} \times M_{123} \dots n \geq 0. \tag{19}$$

由(19)可知

$$M - \frac{2}{3} \sum M_{i1} + \frac{1}{3} \sum M_{i1} i_2 \geq 0 \tag{19a}$$

因此，

$$\sum M_{i1} i_2 \geq 2 \sum M_{i1} - 3 M \geq 2 (n\alpha) - 3 = 2n\alpha - 3.$$

因此，

$$f_n(\alpha) \geq \frac{1}{n(n-1)} (2n\alpha - 3) =$$

$$\frac{4}{n-1} \alpha - \frac{6}{n(n-1)},$$

此外，等式 (20) 仅在 $\frac{2}{n} \leqslant \alpha \leqslant \frac{3}{n}$ 处变为（参见练习 8）。
