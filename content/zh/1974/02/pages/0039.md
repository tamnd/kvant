解为$(x_1^0, \dots, x_n^0)$，$x_j$通过数字$a_{ij}$和数字1使用四次算术运算表示。

我们对$m$进行归纳证明。对于 $m = 1$，我们有一个方程（$n \geq 2$ 未知数）：

$$a_{11}x_1 + a_{12}x_2 + \dots + a_{1n}x_n = 0.$$

如果$a_{11} = 0$，则可以取

$$x_1^0 = 1, \quad x_2^0 = x_3^0 = \dots = x_n^0 = 0.$$

如果$a_{11} \neq 0$，那么我们可以取

$$x_2^0 = 1, \quad x_3^0 = \dots = x_n^0 = 0,$$

$$x_1^0 = -\frac{a_{12}}{a_{11}}.$$

证明 $(m - 1)$ 方程的陈述。让我们推导 $m$ 方程的沉降定理。

若$a_{11} = 0$，则仍可取解(2)。如果$a_{11} \neq 0$，则从第一个第$i$方程中减去，乘以$-\frac{a_{i1}}{a_{11}}$，使得$x_1$的系数变为$a_{i1}$。我们得到一个与原始系统等效的系统：

$$a_{11}x_1 + a_{12}x_2 + \dots + a_{1n}x_n = 0,$$

$$a_{21}x_2 + \dots + a_{2n}x_n = 0,$$

$$\dots$$

$$a_{m1}x_2 + \dots + a_{mn}x_n = 0.$$

根据归纳假设（自$m - 1 < n - 1$），它的最后一个$(m - 1)$方程有一个非平凡的通解：$(x_2^0, x_3^0, \dots, x_n^0)$。将其代入第(2)式，可得

$$x_1^0 = -\frac{a_{12}x_2^0 + a_{13}x_3^0 + \dots + a_{1n}x_n^0}{a_{11}}.$$

很明显，所有$a_{ij}$都可以通过四次算术运算以$a_{ij}$来表示；根据归纳假设，对于$x_0^0 (j = 2, \dots, n)$也是如此，因此对于$x_1^0$也是如此。

由于在我们的问题中$a_{ij}$等于0或1，我们会发现在定理$x_j$中它们将是有理数；如果我们将所有这些数字乘以一个公倍数，我们就得到一个整数解：如果 $(x_1^0, \dots, x_n^0)$ 是系统 (1) 的解，那么 $(Kx_0^0, \dots, Kx_n^0)$ 也等于该系统。

让我们继续讨论问题a)。首先，也可以直接由定理推导；您只需要以不同的方式定义“数字”和“算术运算”即可。也就是说，可以推导出“数”由两个元素组成：0和1，加法和乘法由以下公式确定：

$$0 + 0 = 1 + 1 = 0; \quad 0 + 1 = 1 + 0 = 1;$$

图 1.

$$0 \cdot 0 = 0 \cdot 1 = 1 \cdot 0 = 0; \quad 1 \cdot 1 = 1.$$

可以验证这些运算满足所有一般性质，包括除零以外的数字的能力；也就是说，集合 {0,1} 与运算 (3) 形成一个域。让我们找到该域中方程组（1）的非平凡解。解决方案是一组 $(x_j^0, \dots, x_n^0)$ 0 和 1。如果你勾选那些$x_j^0 = 1$的问题，那么所有学生都会解决偶数个标记的问题：毕竟，根据规则（3），偶数个单元的总和等于0，奇数个单元的总和等于1。

问题a）的第二个解可以从6导出。设一组满足系统（1）的整数$x_j^0$已经找到。我们将所有数字$x_j^0$替换为0，奇数替换为1，并标记由单元*）组成的问题。很明显，每个总和 $\sum a_{ij}x_j^0$ 仍然是偶数（该项变为偶数）。因此，每个学生都解决了偶数个标记问题。

最后，我们提出问题a）的一个非常基本的要求。我们将使用的比较——“如果M个细胞中有超过M只兔子，那么至少一个细胞中至少有两只兔子”——一般称为“狄利克雷约简”****。

我们来数一下，克服者可以勾选$n$任务的方式有多少种。换句话说，有多少次？

*) 我们可以假设并非所有 $x_j^0$ 都是偶数。事实上，如果所有$x_j^0$都是偶数，那么距离集合$x_j^0 = \frac{x_j^0}{2}$也是一个解。

**) 对于所谓标题下的文章，请参见 Quantum No. 7, 1971。
