M205。 24 名学生解决了 25 个问题。老师有一张表$24 \times 25$，记录了谁解决了什么问题。事实证明，至少有一名学生解决了每个问题。证明

a) 您可以用“勾号”标记几个问题，以便每个学生从标记的问题中解决一个数字（特别是，可能是零）；

b) 可以将几个问题标为“+”，其余部分标为“-”，并为每个问题分配整数分，这样每个学生对标有“+”和“-”的问题得分相等。

使用线性方程组定理，问题 a) 和 b) 都很容易解决。首先，让我们以适当的方式表述问题 6)。

设学生数量为$m$，任务数量为$n$。让我们将数字 $a_{ij}$ ($1 \leq i \leq m, 1 \leq j \leq n$) 定义如下：如果第 $i$ 个学生解决了第 $j$ 题，则$a_{ij}$ 等于 1，否则为 0。我们必须证明存在整数 $x_j$ ($1 \leq j \leq n$) - 正数、可怕数和零，这样

$$a_{11}x_1 + a_{12}x_2 + \dots + a_{1n}x_n = 0,$$

$$a_{21}x_1 + a_{22}x_2 + \dots + a_{2n}x_n = 0,$$

$$a_{i1}x_1 + a_{i2}x_2 + \dots + a_{in}x_n = 0,$$

(1)

$$a_{m1}x_1 + a_{m2}x_2 + \dots + a_{mn}x_n = 0$$

或者，简而言之，对于从 1 到 $m$ 的每个 $i$

$$\sum_{j=1}^{n} a_{ij}x_j = 0.$$

事实上，如果我们将数字$x_j$的符号和等于$|x_j|$的点数分配给第$j$问题（并且我们跳过给定的$x_j = 0$），那么（1）中的第$i$方程将仅意味着第$i$学生用相同的总和点解决了“正”问题和“负”问题。

当然，方程组的精度很低，但我们对此不感兴趣：至少有一个问题必须标有“+”或“-”号。
