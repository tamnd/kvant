现在我们准备定义一个环。 Kolcho 是一个具有两个特定操作的集合 $M$。其中一个通常称为加法，表示与$(a, b)$和$a + b$对比较的元素，另一个通常称为乘法，表示与$(a, b)$和$ab$对进行比较的元素。这些操作的特殊性在于适用于它们的以下五个要求：

加法必须是可交换和结合的，也就是说，对于所有对 $(a, b)$ 以及对于 $M$ 中的所有简单 $(a, b, c)$ 元素，必须相等：

1) $a + b = b + a$;
2) $(a + b) + c = a + (b + c)$;
3) 在集合$M$中，必须存在一个最大元素0，使得$a + 0 = a$对于$M$的所有$a$；在这种情况下，元素 0 称为零；
4) 对于$M$的每个$a$，必须存在$M$的最大元素$c$，使得$a + c = 0$；元素 $c$ 称为零，首先称为乘法。如果你仔细观察，就会发现以下情况：
