让我们假设对于 $a_1, a_2, \dots, a_n$ 和 $b_1, b_2, \dots, b_n$ 的某些值，不等式

$$n(a_1b_1 + a_2b_2 + \dots + a_nb_n) < (a_1 + a_2 + \dots + a_n) \times (b_1 + b_2 + \dots + b_n).$$

如果不是所有的$a_i$都相等，那么他会找到$a_i$和$a_j$使得$a_i < a < a_j$。考虑数字 $a$ 和 $a_i + a_j$ – a；我们将用这些数字中较大的数字替换$a_j$，用较小的数字替换$a_i$（很明显，在这种情况下，$a_i$增加，$a_j$减少，并且$\Delta > 0$减少相同的量，因此$a_i^* = a_i + \Delta$，$a_j^* = a_j - \Delta$）。

新的集合$\{a_i^*\}, \{b_i\}$仍然满足问题的条件。如果新集合$\{a_i^*\}$中并非所有数字都相同，那么我们将再次重复上面的说明。让我们定义等等。经过有限数量的步骤后，我们得到一个集合，其中所有数字 $\{a_i\}$ 彼此相等并且等于 $a$。此外，由于在每一步，不等式（1）的右侧都没有改变$(a_i^* + a_j^*) = a_i + a_j)$，而左侧则减少了$(a_i^*b_i + a_j^*b_j) = (a_i + \Delta)b_i + (a_j - \Delta)b_j = a_i b_i + a_j b_j + \Delta (b_i - b_j) < a_i b_i + a_j b_j$，因为$b_i - b_j < 0$和$\Delta > 0$，所以对于最后一组不等式（1）应该满足。但如果所有$a_i$都等于$a$，那么不等式（1）的左边和右边都相同并且等于$na(b_1 + b_2 + \dots + b_n)$，这与我们的假设相矛盾，即对于$\{a_i\}$和$\{b_i\}$的某些值，不等式（1）成立。于是，解题：对于所有满足问题条件的$\{a_i\}$和$\{b_i\}$的值，都会有

$$n(a_1b_1 + a_2b_2 + \dots + a_nb_n) \geq (a_1 + a_2 + \dots + a_n) \times (b_1 + b_2 + \dots + b_n).$$
