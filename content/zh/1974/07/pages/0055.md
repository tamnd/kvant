⟦folio 53⟧

全年，参加课程的学生都会收到作业和特殊的准备材料。七月，课程参与者被召集到莫斯科度过非常忙碌的一天。

以下是莫斯科国立师范学院数学和物理系的数学笔试和物理口试任务的选项。六、列宁于1973年。

数学学院

选项1

1. 解决不平等问题
$$\log_{x^2-3}8 < -3.$$
2. 找到方程的所有解
$$\sqrt{1-\sin 2x} = \sin 3x + \cos 3x$$
满足条件$\frac{3}{2}\pi \leq x \leq 2\pi$。
3. 通过正三角形帕拉米德的底边顶点，以$\alpha$角，向其绘制一个截面，该截面平行于底边的对边并垂直于对边的侧面。确定 Paramid 的体积，已知其边心$a$。
4. 从普里什蒂纳$A$出发，一艘船和一艘木筏同时向下游出发。船顺流而下96公里，14小时后折返A地。如果已知小船在返回途中在距 A 24 公里处遇到木筏，求小船在静水中的速度和水流的速度。

选项2

1. 解决不平等问题
$$\log_{5}\frac{x+7}{16-2x} > \log_{5}x.$$
2. 找到方程的所有解
$$\text{ctg}x - \text{tg}x = \frac{2\sqrt{3}\cos 2x}{1+\cos 2x},$$
满足条件$|x| < \pi$。
3. paramid 的底边是一个等边三角形，其等边长度为 $a$。与它们相对应的是，侧面垂直于底座平面并相互形成角度$\alpha$。侧面三角形与底面的夹角也等于$\alpha$。确定帕拉酰胺的体积。
4. 两列火车同时从$A$和$B$点出发并会合。第一列火车的速度比第二列火车的速度快 10 公里/小时。两列火车在距离$AB$中部28公里处交汇。如果第一趟列车从$A$点出发比第二趟列车晚45分钟，那么两趟列车将在$AB$中间相遇。求两列火车的距离 $AB$ 和速度。

物理学院

选项1

1. 直角三角形特征的底边有一个等边三角形 $ABC$，其边 $AB = BC = a$ 和角 $A$ 等于 $\alpha$。通过边 $AC$ 与底面成 $\varphi\left(\varphi < \frac{\pi}{2}\right)$ 角绘制一个平面。如果已知截面形成三角形，求该截面的面积。
2. 找出构成几何级数的偶数，使得极端项之和为 35，中间项之和为 30。
3. 解方程：
$$\sin^2x - \sqrt{3}\sin x \cos x = 0.$$
4. 解方程：
$$\frac{2^{2x+1}-9}{4} + \frac{2}{4^{x+\frac{1}{2}}} = 0.$$
选项2

1. paramid 的底边是一个等边三角形，其边长等于$a$，顶点的角度等于$\alpha$。所有侧肋均与基面倾斜角度$\beta$。求出帕拉酰胺的体积。
2. 计算：
$$\sqrt{3\sqrt{5\sqrt{3}\sqrt{5}}} \dots$$
3. 解方程：
$$\cos 2x + \cos x + 1 = 0.$$
4. 解方程：
$$\frac{\log_5(2x+3)}{1-\log_5(2x+3)} + \frac{3}{5-\log_5(2x+3)} = 0.$$
选项3

1. 确定底边为锐角 $\alpha$ 直角三角形的帕拉酰胺的体积。肋与基面的倾斜角度为$\beta$且等于$b$。
2. 写一个等差数列，其第一项等于 1，前五项之和等于 $1/4$ 后五项之和。
3. 解方程：
$$4\sin^2x + 3\cos^2x = 6,5\sin 2x.$$
4. 解方程：
$$\frac{\log_2(3x-1)}{1+\log_2(3x-1)} = \frac{2}{3+\log_2(3x-1)}$$.
