数学学院

选项1

1. 简化表达式$(a \neq 0)$：
$$A = \frac{a^2 + 4}{a \sqrt{(a^2 - 4)^2 / 4a^2} + 4}.$$

2. 解决不平等问题
$$\frac{\lg(x^2 - 1)}{\lg(1 - x)} < 1.$$

3. 围绕半径为 $R$ 的圆描述一个具有锐角 $\alpha$ 和 $\beta$ 以及较大底边的梯形。求这个梯形的面积。

4. 如果一个自然数具有$2m^2 + n^2$的形式，那么这个数的平方可以表示为$2a^2 + b^2$，其中$a, b, m, n$是不等的自然数。证明。

选项2

1. 简化表达式：
$$A = \frac{\sqrt{(b + 2)^2 - 8b}}{1 \sqrt{b} - \frac{2}{1 \sqrt{b}}}.$$

$(b \neq 0, b \neq 2)$ 并计算其在 $b = 0,0025$ 处的值。

2. 解决不平等问题
$$\frac{\lg(x^2 - 6x + 8)}{\lg(x - 8)} > 1.$$

3. 直角三角形的面积与其斜边构建的正方形面积之比为$k$。求三角形锐角的强度之和。

4. 四位数字的数字是连续的，自然数字序列的递增数字。找出以相同数字但顺序相反的数字与给定数字之间的差异。

物理学院

专业“物理”
选项3

1. 解方程
$$\frac{x + 2}{x + 1} = \frac{12}{x - 2} + \frac{18x}{(x + 1)(2 - x)}.$$

3. 等边梯形的最小底等于高，并且等于$h$。梯形的锐角是$\alpha$。求梯形的周长。

4. 一名行人以 5 公里/小时的速度从$A$点移动到$B$点。骑自行车的人与行人同时出发，从$B$到$A$，1小时12分钟后与行人相遇。到达$A$点后，骑行者折返，在距离$B$点20公里处追上了行人。在 LOCIPEDST 中求出距离 $AB$ 和移动速度。

$$\sin^4 x + \cos^4 x = \frac{5}{8}.$$

4. 旅行时，游客预计在路上花费 72 卢布。前5天，他的开支与计算的相符，然后他开始平均花费1卢布。更明显的是ejeddaily。由于途中耽搁了 1 天，他在旅途中花费了 23 卢布才回到家。比我抓到的还要多。这位游客已经在路上呆了多少天了？
