⟦folio 59⟧

主题：自动运输、自动道路、筑路机械和设备、场所和隧道、自动运输的经济学和组织。

学院自成立以来，设有专职筹备部。

以下是 1973 年数学和物理入学笔试的版本。

Mathematica

选项1

1. 简化表达式：
$$\frac{\sqrt[3]{x + \sqrt{2 - x^2}} \cdot \sqrt[6]{1 - x \cdot \sqrt{2 - x^2}}}{\sqrt[3]{1 - x^2}}.$$
2. 解方程：
$$x (\lg 5 - 1) = \lg (2^x + 1) - \lg 6.$$
3. 证明接入点：
$$\frac{\text{ctg}^2 2\alpha - 1}{2 \text{ctg} 2\alpha} - \cos 8\alpha \cdot \text{ctg} 4\alpha = \sin 8\alpha.$$
4. 在正四边形帕拉米德中，等于 $H$ 的高度与侧边界形成$\alpha$ 角。通过底座对角线绘制的截面与底座成$\phi$ 角倾斜。确定横截面积。
选项2

1. 简化表达式：
$(\sqrt[3]{m^2} + n^3 \sqrt{m} + n^2) \times \frac{\sqrt[3]{m^4} - n^3 + n^2 \sqrt[3]{m} - mn}{mn^{-1} + n - n^4 m^{-1} - n^2}$.
2. 求解方程组：
$$\begin{cases} x^3 + y^3 = 7, \\ x^2 y + xy^2 = -2. \end{cases}$$
3. 解方程：
$$\sin^4 x + \cos^4 x = \frac{5}{8}.$$
4. 截锥体中心横截面的对角线相互垂直。母线与大底面的夹角为$\alpha$。生成器等于 $l$。确定截锥体的总表面积。

物理

选项1

1. 音量和音高。
2. 热量。热量的系统外单位是卡。计算加热物体所需热量的公式。
3. 导体的串联。变阻器。
4. 能量结合原子核。
5. 一辆汽车沿着曲率半径为$R = 40$米的凸面运动。如果汽车在该地点最高点的速度为 $v = 50,4$ km/h，且汽车车轮在该地点的摩擦系数为 $k = 0,6$，那么汽车在该地点最高点所能产生的最大水平加速度是多​​少？

选项2

1. 向心加速度。
2. 热机的效率系数。
3. 焦耳-楞次定律。
4. 观察粒子元素的方法。

5. 冰山与地平线形成$\alpha = 10^\circ$角。一块石头沿着它向上抛，在 $t = 3$ 秒内移动了 $s = 12$ 米的距离，然后滑落。石头向下移动需要多长时间？山与岩石之间的摩擦系数是多少？

选项3

1. 物体在斜面上保持平衡的条件。
2. 当前来源。电动势。
3. 开路振荡电路。电磁波的发射和接收。
4. 会聚透镜。所描绘人物的构造。
5. 在体积为120$m^3$、温度为15℃的房间内，相对湿度为60%。确定房间空气中水蒸气的质量。 15℃时饱和水蒸气的弹性为12.79mmrm。厘米。

选项4

1. 可变运动。平均速度和瞬时速度。加速。加速度单位。
2. 融化。比熔化热。
3. 电容量。电容量单位。
4. 镜片。镜头公式。
5. 当水的电脉冲经过$t = 25$分钟的时间时，电流为$I = 20$a。如果体积为$V = 1$升，压力为$p = 2$毫米，释放的氧气的温度是多少？氧的电化学当量为$k = 8,29 \cdot 10^{-8}$ kJ/kmol·rad。
