§ 1. 多项式 - 计算器工具

好吧，让我们开始吧！当我们读完这个故事时，我们会知道更多而不是更少。

G·H·安徒生

乍一看，在看不见的函数王国中，多项式占据着一个非常不起眼的位置。然而，这种第一印象是具有欺骗性的。

多项式确实非常简单：代数符号
$$f(x) = x^n + a_1x^{n-1} + a_2x^{n-2} + \dots + a_{n-1}x + a_n$$ (1)
也是计算多项式$^*$值的公式。虽然像$\cos x$、$\sqrt[5]{x}$、$10^x$或$\log_2 x$这样的表达式更加简洁，但从计算的角度来看它们毫无意义：例如，要计算数字$\cos 17^\circ$、$\sqrt[5]{2}$、$10^{0.13}$或$\log_2 7$，您需要特殊的近似公式（或使用相同公式编译的表格）。通常，多项式出现在此类公式中：例如，
$$\cos x \approx 1 - \frac{x^2}{2!} + \frac{x^4}{4!} - \frac{x^6}{6!} + \frac{x^8}{8!}$$

（区间$0 \leq x \leq \pi/4$的误差小于千万分之一！）。

*) 为了简化计算，我们将限制为首项为单位系数的多项式 ($a_0 = 1$)；如有必要，我们将展示如何在一般情况下进行（$a_0 \neq 1$）。

但三角函数、幂函数等（初等）函数是最简单的分析函数，被数学家、物理学家和工程师研究和使用。这位著名的计算数学家在他的书中写道*)：“因为多项式很容易处理，所以大多数经典数值分析都是基于多项式的近似。”

由于您经常需要计算多项式，因此学习如何尽可能简单地计算多项式非常重要。我们将讨论自多项式诞生（17 世纪）以来计算多项式值的方法的演变。然而，“进化”这个词在这里并不完全合适：这些方法的历史就像一部很长的小说，情节有趣但简短，动作单调，结局出乎意料。

可以根据单个多项式的特征（通过巧妙地组合其系数）来寻求此类方案，也可以通过构建通用方法来构建比霍纳方案经济得多的方案，但对于某些多项式来说可能不是最好的。第一种方法的缺点是，对于每个多项式，我们都必须想出自己的技术，并且不能保证我们总是会成功；稍后（第 10 节）我们将看到第二个在所有方面都更可靠。

不言而喻，这两种方法仅在需要花费时间和精力为其构建良好电路的特定多项式的情况下才会减少。例如，使用霍纳方案，“一次性使用”多项式更容易计算。

也许类似的推理导致 1955 年发现了六次多项式完美类型的通用方案。我们将使用 4 次多项式的更简单方案来说明该方案的主要思想。让
$$f(x) = x^4 + ax^3 + bx^2 + cx + d;$$
让我们把
$$\begin{cases} p_1 = x \cdot (x + A); \\ p_2 = (p_1 + B)(p_1 + x + C) + D \\ f(x) = p_2 \end{cases}$$
其中 A、B、C 和 D 是参数。

例子。多项式$x^4 + 3x^3 + 6x^2 + 3x + 2$可以使用以下方案计算：$p_1 = x(x + 1), f(x) = (p_1 - 1)(p_1 + x + 5) + 7$，包含两次（而不是根据霍纳的三个）乘法和五次（而不是四次）$(\pm)$运算；这里 A = 1，B = -1，C = 5，D = 7。

让我们写出 $p_2(x)$ 的显式表达式：
$$p_2(x) = x^4 + (2A + 1)x^3 + (A^2 + A + B + C)x^2 + (AB + B + AC)x + BC + D;$$
将系数$f(x)$和$p_2(x)$相等，我们将式(5)中包含的参数通过系数(4)表示：
$$A = (a - 1)/2;$$
$$B = c - b \cdot A + A^2(A + 1);$$
$$C = b - B - A(A + 1);$$
$$D = d - BC.$$
从这些公式可以看出，方案(5)是通用的。

我们将运算(6)称为多项式系数的变换处理；当然，它们不包括在电路运算的数量中：毕竟，对于每个给定的多项式，它们只执行一次，而我们的任务是学习如何快速计算不同$x$的任意但固定的多项式的值。

是时候问一下有没有比方案（7.k）更经济的方案了？但随之而来的问题就不可避免了——什么是方案？

定义。 （我）。系数初步处理方案是一系列算术运算，涉及变量$x$、参数$b_1, b_2, \dots, b_m$以及先前运算的结果。我们将最后一次操作的结果称为`результатом схемы`。 （二）。如果对于一组参数值$b_1, \dots, b_m$，该方案的结果是给定的次数为$n$的多项式，那么我们说该方案是`представляем этот многочлен`。 （三）。如果电路用多项式表示，那么从其系数计算出相应的一组参数值的过程称为`предварительной обработкой коэффициентов`。 （四）。如果一个方案由任何形式 (1) 的 $n$ 次多项式表示，则该方案称为“超度$n$”。

*) 一次“复数”加法是两次“实数”加法，一次“复数”乘法是四次（！）乘法和两次加法。
