白俄罗斯国立大学以此命名。 V·I·列宁娜

下面我们介绍了数学入学笔试的选项，这些选项是为 1973 年进入白俄罗斯国立大学物理和数学系的学生提供的。

数学学院
选项1

1. 在半径$R$的圆内有四个小于半径的相等圆。它们中的每一个都接触较大的圆以及与它相等的两个相邻的圆。计算由所有相等的圆包围的图形的面积。

2. 变数级数$a_m = n$，$a_n = m (m \neq n)$。找到$a_p$。

3. 解决不平等问题
$$|x|^{x^2-x-2} < 1.$$

4. 求函数$f(x) = \sin x - \cos x$在区间$[-2\pi, \pi]$中具有最小值的$x$的值。选项2

1. 在三角形帕拉米德中，所有六个边都是相同的。如果悬挂球的半径为$R$，求底面中心到侧面的距离。

2. 简化表达式
$$\frac{\sqrt{(a+x)(x+b)} + \sqrt{(a-x)(x-b)}}{\sqrt{(a+x)(x+b)} - \sqrt{(a-x)(x-b)}},$$
如果$x = \sqrt{ab}$，$a > b > 0$。

3. 解方程
$$\sin^2 x + \sin^2 2x = 1.$$

4. 三角形$ABC$包含bicsetrice$AD$。证明如果$AB + BD = AC + CD$，则三角形$ABC$是等边三角形。

应用数学学院
选项3

1. 平行四边形的周长与其较大对角线的比率为$k$，$k > 2$。如果已知主对角线以 1:2 的比例划分平行四边形的角度，请求平行四边形的角度。

2. 找出两个相差为 66、最小公倍数为 360 的自然数。

3. 确定方程 $a$ 的值
$$2 \lg (x+3) = \lg (ax)$$
有一个根。找到这个根。

4. 简化为方便对数化的形式，
$$\sin 2\alpha + \cos 4\alpha - \sin 6\alpha.$$

选项4

1. 圆锥内切球的体积与圆锥外切球的体积之比等于$k$，其中$0 < k < 1/8$。求圆锥体的母线与其轴平面之间的角度。

2. 两辆摩托车同时从$A$和$B$点出发，相向行驶，两点之间的距离为660公里。第一个行程为 250 公里，第二个行程为 200 公里。如果第一个电机比第二个电机早 $B$ 3 小时到达$A$，则求电机的运动速度，考虑到它们的运动均匀性。

3. 解方程
$$-2 + 4 \cos^2 x = \cos x + \sqrt{3} \sin x.$$

4. 解决不平等问题
$$\frac{|x+2| - x}{\sqrt{4-x^3}} > 0.$$
