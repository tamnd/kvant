⟦folio 44⟧

根据问题的条件，蓝色和黄色平行四边形的面积必须相同：

$$k = xy \sin 2\alpha = \left( \frac{a}{2 \cos \alpha} \right)^2 \sin 2\alpha,$$

在哪里

$$xy = \frac{a^2}{4 \cos^2 \alpha}. \tag{1}$$

我们需要找到$F_1$和$F_2$的位置（即$c$的值），使得双曲线的所有点$M$的差值$r_2 - r_1$都相同。特别是，对于其顶点 $A$，由于 $(|F_2A| = |F_1A'|)$ 的对称性，该差 $|F_1A| - |F_2A|$ 等于 $|A'A| = 2a$（双曲线的轴）。这意味着这个差值必须等于

$$r_2 - r_1 = 2a. \tag{2}$$

让我们通过常量$a, c$和$\alpha$求出表达式$r_1$和$r_2$（当然，这些表达式也包含一些变量）。将余弦定理应用于三角形 $F_1MO, F_2MO$ 和 $OMN$，我们有：

$$r_{1,2}^2 = c^2 + r^2 \pm 2cr \cos \varphi \tag{3}$$

（上面的符号代表$r_1$，下面的符号代表$r_2$）和

$$r^2 = x^2 + y^2 + 2xy \cos 2\alpha. \tag{4}$$

角度$\varphi$可以立即由公式（3）得出：从图中可以清楚地看出

$$r \cos \varphi = |OK| = |OQ| \cos \alpha = (|OL| + |LQ|) \cos \alpha =$$

$$= (|OL| + |LM|) \cos \alpha = (x + y) \cos \alpha;$$

跟随，

$$r_{1,2}^2 = c^2 + r^2 \pm 2c(x + y) \cos \alpha. \tag{3'}$$

将(4)代入(3')，并利用条件(1)以及恒等式$\cos 2\alpha = 2 \cos^2 \alpha - 1$和$x^2 + y^2 = (x + y)^2 - 2xy$，我们得到：

$$r_{1,2}^2 = c^2 + (x + y)^2 - 2xy + 2xy \cos 2\alpha \pm 2c(x + y) \cos \alpha =$$

$$= c^2 + (x + y)^2 - \frac{a^2}{2 \cos^2 \alpha} +$$

$$+ \frac{a^2}{2 \cos^2 \alpha} (2 \cos^2 \alpha - 1) \pm 2c(x + y) \cos \alpha =$$

$$= \left[ c^2 - \frac{a^2}{2 \cos^2 \alpha} \right] + \left[ (x + y)^2 + a^2 \pm 2c(x + y) \cos \alpha \right]. \tag{5}$$

做 схх 因为 $c$ 是任意的。现在让我们选择它，使公式（5）呈现出更简单的形式。让我们输入$c = \frac{a}{\cos \alpha}$（然后是$|OF_2| = |OB|$，参见图）。则式(5)的形式为：

$$r_{1,2}^2 = (x + y)^2 + a^2 \pm 2(x + y) a = [(x + y) \pm a]^2.$$

由图可知$x + y > a$($|OQ| > |OA|$)；因此，

$$r_1 = (x + y) + a, \quad r_2 = (x + y) - a.$$

这给了我们$r_1 - r_2 = 2a$。有趣的是，$r_1 + r_2 = 2(x + y)$，即从双曲线的任何幂开始考虑，直到其焦点是位于某个双曲线中的不同的可变平行四边形为止。
