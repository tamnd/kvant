氢化铀的分解反应如下方程式
$$2\mathrm{UH_3} = 2\mathrm{U} + 3\mathrm{H_2},$$
也就是说，由482*g*（两摩尔）氢化铀得到476*g*（两摩尔）铀和6*g*（三摩尔）氢。因此，从 1 *g* 氢化铀中，您将得到 $m = 6/482$ *g* 氢。考虑到氢气是一种理想气体，我们在给定条件下找到其压力 ($T = 673^\circ\mathrm{K}$, $V = 10^{-3}$ *m³*)。从理想气体的状态方程

$$p = \frac{m}{\mu}\frac{RT}{V} \approx 35\cdot 10^3 \ \ \textit{н/м}^2.$$

◆

让膜按照规律振荡
$$x = A \sin \omega t,$$
其中$x$是距平衡位置的位移，$A$是振幅，$\omega = 2\pi\nu$是振荡的循环频率。在时间$t = 0$的初始时刻，膜及其上的沙粒处于平衡位置。然后将膜移离平衡位置，例如向上移动。

沿着膜移动的沙粒受到两种力的作用：重力 $mg$ 和膜反应力 $\mathbf{N}$ (图 8)。让我们写出一粒沙子的运动方程：
$$N - mg = ma.$$
在沙粒分离的瞬间，反作用力$N$变为零，因此沙粒的加速度$a = -g$变为零。因此，一粒沙子在$t_0$时刻脱离膜，此时其加速度等于$-g$。然后，沙粒继续运动到高度$h$，就像一个垂直向上抛出的物体，高度为$h_0$，等于膜在时刻$t_0$时与平衡位置的偏差，初始速度为$v_0$，等于膜在同一时刻$t_0$的速度（见图8）。根据机械能守恒定律

$$mgh_0 + \frac{mv_0^2}{2} = mgh. \qquad (*)$$

现在让我们更详细地考虑膜的运动，并将量 $h_0$ 和 $v_0$ 与膜振荡的幅度联系起来。

任意时刻膜的速度为$v = \omega A \sin(\omega t + \pi/2) = \omega A \cos \omega t$，加速度为$a = -\omega^2 x = -\omega^2 A \sin \omega t$。分离的那一刻$t_0$

$$v = v_0 = \omega A \cos \omega t_0,$$
$$a = -g = -\omega^2 A \sin \omega t_0,$$
$$x = h_0 = A \sin \omega t_0.$$

根据加速度方程 $\sin \omega t_0 = \dfrac{g}{\omega^2 A}$，因此有 $h_0 = g/\omega^2$ 和 $v_0 = \omega A \cos \omega t_0 = \sqrt{\omega^2 A^2 - g^2/\omega^2}$

将值$h_0$和$v_0$代入方程$(*)$，我们得到

$$A = \frac{\sqrt{2gh\omega^2 - g^2}}{\omega^2} \approx 77{,}2\cdot 10^{-6} \ \textit{м} \approx 0{,}077 \ \textit{мм}.$$
