问题解决方案
M308-M315; F318-F321

M308。如果对于任何$x$$a_1\cos x + a_2\cos 2x + \dots + a_n\cos nx \geq -1$，则对于数字$a_1, a_2, \dots, a_n$，不等式$a_1 + a_2 + \dots + a_n \leq n$成立。证明是这样的陈述：a）对于$n = 2$； b) 对于$n = 3$； c) 对于任何自然的$n$。

a) 输入$x = \frac{2\pi}{3}$就足够了。

b) 将$x = \frac{\pi}{2}, x = \pi, x = \frac{3\pi}{2}$依次放入并添加所得的不等式。
b) 我们首先证明下面的公式：如果$\varphi = -\frac{2k\pi}{n+1}$，其中$k$和$n$是整数，并且$k$不能被$n+1$整除，那么
$$\cos \varphi + \cos 2\varphi + \cos 3\varphi + \dots + \cos n\varphi = -1. \quad (*)$$
设给定点为 $O$ 和 $A_0$。将点$A_0$相对点$O$旋转角度$\varphi$，得到点$A_1$。从点$A_1$以相同的旋转我们获得点$A_2$，从点$A_2$ - 点$A_3$等等。从$(n+1)\varphi = 2k\pi$开始，点$A_{n+1}$与点$A_0$重合。向量之和$\overrightarrow{OA_0}, \overrightarrow{OA_1}, \overrightarrow{OA_2}, \dots, \overrightarrow{OA_n}$等于零向量。事实上，当这些向量中的每一个相对于点$O$旋转角度$\varphi$时，等于它们之和的向量也必须旋转相同的角度。另一方面，由于等于向量$\overrightarrow{OA_0}, \overrightarrow{OA_1}, \dots, \overrightarrow{OA_n}$之和的向量在旋转过程中不会改变（因为点$A_0$将转到点$A_1$，点$A_1$将转到点$A_2$，...，点$A_n$将转到点$A_0$），因此它等于零向量。
现在我们假设点 $O$ 是原点，向量 $\overrightarrow{OA_0}$ 的长度为 1 并且沿 x 轴方向。由于向量之和在任意轴上的投影等于其在该轴上的投影之和，因此向量$\overrightarrow{OA_1}, \overrightarrow{OA_2}, \dots, \overrightarrow{OA_n}$在横坐标轴上的投影之和等于-1（向量$\overrightarrow{OA_0}$在横坐标轴上的投影等于1）。但这些投影显然等于 $\cos \varphi, \cos 2\varphi, \dots, \cos n\varphi$，根据公式 (*) 可以得出不存在的情况。

公式(*)可以用另一种方式证明，即两边都乘以$2\sin \frac{\varphi}{2}$并使用公式
$$2\sin \frac{\varphi}{2}\cos k\varphi = -\sin \left(k - \frac{1}{2}\right)\varphi + \sin \left(k + \frac{1}{2}\right)\varphi,$$
- 自己做。
