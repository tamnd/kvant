M308。如果对于任何$x$$a_1\cos x + a_2\cos 2x + \dots + a_n\cos nx \geq -1$，则对于数字$a_1, a_2, \dots, a_n$，不等式$a_1 + a_2 + \dots + a_n \leq n$成立。证明是这样的陈述：a）对于$n = 2$； b) 对于$n = 3$； c) 对于任何自然的$n$。

a) 输入$x = \frac{2\pi}{3}$就足够了。

b) 将$x = \frac{\pi}{2}, x = \pi, x = \frac{3\pi}{2}$依次放入并添加所得的不等式。
b) 我们首先证明下面的公式：如果$\varphi = -\frac{2k\pi}{n+1}$，其中$k$和$n$是整数，并且$k$不能被$n+1$整除，那么
$$\cos \varphi + \cos 2\varphi + \cos 3\varphi + \dots + \cos n\varphi = -1. \quad (*)$$
设给定点为 $O$ 和 $A_0$。将点$A_0$相对点$O$旋转角度$\varphi$，得到点$A_1$。从点$A_1$以相同的旋转我们获得点$A_2$，从点$A_2$ - 点$A_3$等等。从$(n+1)\varphi = 2k\pi$开始，点$A_{n+1}$与点$A_0$重合。向量之和$\overrightarrow{OA_0}, \overrightarrow{OA_1}, \overrightarrow{OA_2}, \dots, \overrightarrow{OA_n}$等于零向量。事实上，当这些向量中的每一个相对于点$O$旋转角度$\varphi$时，等于它们之和的向量也必须旋转相同的角度。另一方面，由于等于向量$\overrightarrow{OA_0}, \overrightarrow{OA_1}, \dots, \overrightarrow{OA_n}$之和的向量在旋转过程中不会改变（因为点$A_0$将转到点$A_1$，点$A_1$将转到点$A_2$，...，点$A_n$将转到点$A_0$），因此它等于零向量。
现在我们假设点 $O$ 是原点，向量 $\overrightarrow{OA_0}$ 的长度为 1 并且沿 x 轴方向。由于向量之和在任意轴上的投影等于其在该轴上的投影之和，因此向量$\overrightarrow{OA_1}, \overrightarrow{OA_2}, \dots, \overrightarrow{OA_n}$在横坐标轴上的投影之和等于-1（向量$\overrightarrow{OA_0}$在横坐标轴上的投影等于1）。但这些投影显然等于 $\cos \varphi, \cos 2\varphi, \dots, \cos n\varphi$，根据公式 (*) 可以得出不存在的情况。

$$2\sin \frac{\varphi}{2}\cos k\varphi = -\sin \left(k - \frac{1}{2}\right)\varphi + \sin \left(k + \frac{1}{2}\right)\varphi,$$

**M309。 a) 多项式 $x^{2n} + x^n + 1$ 能被 $x^2 + x + 1$整除，$n$ 是多少？**

b) 在 $n$ 数处

$$1 \underbrace{0 \dots 0}_{n} \underbrace{1 \dots 0}_{n}$$

能被37整除吗？

a) 考虑$n$除以3时对应不同余数的三种情况。

1°。设 $n=3k$；然后

$$x^{6k} + x^{3k} + 1 = (x^{6k} - 1) + (x^{3k} - 1) + 3 =$$
$$= (x^3 - 1)(x^{6k} - 3 + x^{6k} - 6 + \dots + 1) +$$
$$+ (x^3 - 1)(x^{3k} - 3 + x^{3k} - 6 + \dots + 1) + 3 =$$
$$= (x^2 + x + 1) \cdot Q(x) + 3,$$

其中$Q(x) = (x - 1)[(x^{6k} - 3 + x^{6k} - 6 + \dots + 1) + (x^{3k} - 3 + \dots + 1)]$。

因此，如果 $n=3k$，则多项式 $x^{2n} + x^n + 1$ 除以 $x^2 + x + 1$ 得到余数 3。

2°。让$n=3k + 1$。我们有

$$x^{6k + 2} + x^{3k + 1} + 1 = (x^{6k + 2} - x^2) + (x^{3k + 1} - x) +$$
$$+ (x^2 + x + 1) = x^2(x^{6k} - 1) + x(x^{3k} - 1) + (x^2 + x + 1)$$

在 1° 中，我们证明多项式 $(x^{6k} - 1)$ 和 $(x^{3k} - 1)$ 可被 $(x^3 - 1)$ 整除，因此也可被 $(x^2 + x + 1)$ 整除；因此，在$n=3k + 1$处，多项式$x^{2n} + x^n + 1$可被$x^2 + x + 1$整除。

3°。让$n=3k + 2$。然后

$$x^{6k + 4} + x^{3k + 2} + 1 = x^1(x^{6k} - 1) + x^2(x^{3k} - 1) + x^4 + x^2 +$$
$$+ 1 = x^4(x^{6k} - 1) + x^2(x^{3k} - 1) + x^3 - 1 + (x^2 + x + 1) = (x^2 + x + 1)[(x - 1)R(x) + 1],$$

其中 $R(x) = x^4(x^{6k} - 3 + \dots + 1) + x^2(x^{3k} - 3 + \dots + 1) + x$，多项式 $x^{2n} + x^n + 1$ 又可以被 $x^2 + x + 1$整除。

我们取面积$D$；它由 $k_0 \geq 1$ 多有机体的面组成。如果$k_0 = 1$，则该区域（以路径$P_0$为界）就是所需的面。如果$k_0 > 1$，则在区域$D$中，有一条边$A_iB$不包含在路径$P_0$中（并且$A_i$包含在$P_0$中）。从这条边开始，我们将在$D$区域内构建一条通过顶点$B$的路径，直到得到一条其中一个顶点相交两次的路径（如果我们走到区域$D$的边界，那么沿着路径$P_0$进一步返回到$A_i$）。这样我们就得到了一条新的闭合路径$P_1$(图5)。路径$P_1$位于区域$D$内且与$P_0$不重合；这意味着由路径 $P_1$ 界定的区域由聚有机物的 $k_1 < k_0$ 面组成。如果$k_1 = 1$，则$P_1$限制了所需的边缘；如果$k_1 > 1$，那么以同样的方式我们将构造一条闭合路径$P_2$，限制由$k_2 < k_1$面组成的区域，依此类推。由于所有数字$k_i$都是自然数和$k_{i+1} < k_i$，因此在有限的步骤中我们获得了一条闭合路径$P_0$，恰好限制了一个所需的面。

让膜按照规律振荡
$$x = A \sin \omega t,$$
其中$x$是距平衡位置的位移，$A$是振幅，$\omega = 2\pi\nu$是振荡的循环频率。在时间$t = 0$的初始时刻，膜及其上的沙粒处于平衡位置。然后将膜移离平衡位置，例如向上移动。

沿着膜移动的沙粒受到两种力的作用：重力 $mg$ 和膜反应力 $\mathbf{N}$ (图 8)。让我们写出一粒沙子的运动方程：
$$N - mg = ma.$$
在沙粒分离的瞬间，反作用力$N$变为零，因此沙粒的加速度$a = -g$变为零。因此，一粒沙子在$t_0$时刻脱离膜，此时其加速度等于$-g$。然后，沙粒继续运动到高度$h$，就像一个垂直向上抛出的物体，高度为$h_0$，等于膜在时刻$t_0$时与平衡位置的偏差，初始速度为$v_0$，等于膜在同一时刻$t_0$的速度（见图8）。根据机械能守恒定律

$$mgh_0 + \frac{mv_0^2}{2} = mgh. \qquad (*)$$

现在让我们更详细地考虑膜的运动，并将量 $h_0$ 和 $v_0$ 与膜振荡的幅度联系起来。

任意时刻膜的速度为$v = \omega A \sin(\omega t + \pi/2) = \omega A \cos \omega t$，加速度为$a = -\omega^2 x = -\omega^2 A \sin \omega t$。分离的那一刻$t_0$

$$v = v_0 = \omega A \cos \omega t_0,$$
$$a = -g = -\omega^2 A \sin \omega t_0,$$
$$x = h_0 = A \sin \omega t_0.$$

根据加速度方程 $\sin \omega t_0 = \dfrac{g}{\omega^2 A}$，因此有 $h_0 = g/\omega^2$ 和 $v_0 = \omega A \cos \omega t_0 = \sqrt{\omega^2 A^2 - g^2/\omega^2}$

将值$h_0$和$v_0$代入方程$(*)$，我们得到

$$A = \frac{\sqrt{2gh\omega^2 - g^2}}{\omega^2} \approx 77{,}2\cdot 10^{-6} \ \textit{м} \approx 0{,}077 \ \textit{мм}.$$
