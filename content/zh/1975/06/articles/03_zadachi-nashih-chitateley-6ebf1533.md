（回想一下，$s^2$属于字段$P$），
$p_1 + p_2 s) : (r_1 + r_2 s) =$
$$\frac{(p_1 + p_2 s) (r_1 - r_2 s)}{r_1^2 - r_2^2 s^2} =$$
$$= (p_1 + p_2 s) \left( \frac{r_1}{r_1^2 - r_2^2 s^2} - \frac{r_2 s}{r_1^2 - r_2^2 s^2} \right)$$
$(r_1^2 - r_2^2 s^2 \neq 0$，因为否则$s^2 = r_1^2/r_2^2$和$s = \pm r_1/r_2$属于$P$问题和条件）。

2) 让我们代入$\bar{q} = p_1 - p_2 s$，那么数字$q = p_1 + p_2 s$满足方程$(x - q)(x - \bar{q}) = x^2 + dx + e = 0$，其中$d = -(q + \bar{q}) = -2p_1$，$e = q \bar{q} = p_1^2 - p_2^2 s^2$。

引理1 的证明。让我们通过反证法来证明引理1。令方程(4)在域$Q$中有根$q$。那么，根据引理 2，数 $q$ 满足方程组
$$x^3 + ax^2 + bx + c = 0,$$
$$x^2 + dx + e = 0.$$
(4') 将式(4')乘以$(x + a - d)$，从式(4)中减去它。我们得到$[b - e - (a - d)d]x + [c - (a - d)e] = 0$。我们用 $f$ 表示第一个括号，用 $g$ 表示第二个括号。然后$fq + g = 0$。如果$f \neq 0$，则$q = -g/f$属于域$P$，这与条件矛盾。如果$f = 0$，则$g = 0$，这意味着
$$x^3 + ax^2 + bx + c - (x + a - d) \times (x^2 + dx + e) = fx + g = 0$$
那是
$$x^3 + ax^2 + bx + c = (x + a - d) + (x^2 + dx + e).$$
否则方程(4)有一个根$q = d - a$属于域$P$，这是一个条件问题。

由此产生的矛盾证明了引理 1，并由此证明了定理 2。
