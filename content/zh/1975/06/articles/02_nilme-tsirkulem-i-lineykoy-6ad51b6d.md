练习 10. $\sqrt{3}$ 是否属于示例 B 中的字段 $P$？

令 $x$ 为可以使用有限数量的基本动作以 1 表示的某个数字。这意味着有数字$x_1, \ldots, x_n$，其中$x_1 = 1$，$x_n = x$，每个数字$x_k$（$1 < k \leq n$）都是通过前一个数字使用一个基本动作来表达的。例如，对于 $x = \sqrt{2} - 5\sqrt{3}$，您可以采用 $x_1 = 1$、$x_2 = 1 + 1 = 2$、$x_3 = \sqrt{2}$、$x_4 = 1 + 2 = 3$、$x_5 = \sqrt{3}$、$x_6 = 2 + 3 = 5$、$x_7 = 5\sqrt{3}$、$x_8 = \sqrt{2} - 5\sqrt{3} = x$。

让我们构建一个字段链$P_1, \ldots, P_n$，其中$P_k$是由数字集$x_1, \ldots, x_k$生成的字段。在这个链中，对于每个字段$P_k$有两种可能性：

1. 如果$x_k$属于$P_{k-1}$，则$P_k$与$P_{k-1}$相同。
2. 如果$x_k$不属于$P_{k-1}$，则$P_k$由集合生成，该集合是通过将数字$x_k$与字段$P_{k-1}$相加得到的（在这种情况下，$x_k^2$必然属于$P_{k-1}$）。

从上面可以清楚地看出，为了证明定理2，建立以下内容就足够了。

引理1.设数字$s$不属于字段$P$，$s^2$属于$P$，$Q$为集合生成的字段，由数字$s$与$P$相加得到。让方程

$$x^3 + ax^2 + bx + c = 0$$

系数属于 $P$ 在域 $P$ 中没有根。 Then it has no roots in the field $Q$.

在证明这个引理之前，让我们描述一下域$Q$是如何构造的。

引理 2. 来自域 $Q$ 的任何数字 $q$

1) 表示为$q = p_1 + p_2s$，其中$p_1$和$p_2$属于$P$，
2) 满足二次方程$x^2 + dx + e = 0$，系数$d$和$e$属于$P$。

引理2的证明。

1) 显然，所有$p_1 + p_2s$形式的数字都属于$Q$。为了证明 $Q$ 中不存在其他数字，只需检查对 $p_1 + p_2s$ 形式的数字的简单操作是否再次属于同一类型的数字就足够了。这可以从公式得出

$$(p_1 + p_2s) \pm (r_1 + r_2s) = (p_1 \pm r_1) + (p_2 \pm r_2)s,$$

$$(p_1 + p_2s) \cdot (r_1 + r_2s) = (p_1r_1 + p_2r_2s^2) + (p_1r_2 + p_2r_1)s$$
