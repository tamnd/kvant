如果打开所有括号，那么在不等式的每个部分中，您都会得到 16 项，其中 12 项相同并相互抵消。剩下的项带上相似项后，形成如下明显的不等式，与原来的等价：
$$abcd (xy - uv)^2 \geq 0.$$

让我们用$M$表示包含在平面$p_0$和$p_2$之间的多面体部分；到$V$是凸多面体$M$的体积。根据条件，所有顶点 $M$ 均位于平面 $p_0$ 和 $p_2$ 内。在图中，我们将位于平面 $p_2$ 中的多面体 $M$ 的顶点和边作为头部颜色，用 $p_0$ - 绿色，以及平面 $p_1$ 的截面 - 用红色。

我们先看几个例子。
1°。 $M$ — 通过平面 $p_0$ 和 $p_2$ (图 2) 中的底座进行识别。然后$S_t = C$（常数值），部分$S_0 = S_1 = S_2 = C$，所以等式成立
$$2\sqrt{S_1} = \sqrt{S_0} + \sqrt{S_2}$$

和$V = 2S_0h$（特征的高度为2h）。
2°。 $M$ 是一个三角形 paramid，其顶点位于 $p_0$ 平面，底边位于 $p_2$ 平面 (图 3)。那么平行于 $p_0$ 的平面截取的线性尺寸与该平面到 $p_0$ 的距离成正比，因此 $S_t$ 与 $t^2$: $S_t = At^2$ 成正比，因此
$$S_0 = 0, S_1 = A, S_2 = 4A,$$
并且再次满足等式(*)；同时$V = 2S_2h/3$。
3°。 $M$ 是一个截断的三角形 paramid，其底边位于平面 $p_0$ 和 $p_2$ (图 4)。然后 $S_t = A(t - \tau)^2$ （这由距平面 $p_0$ 的距离 $|\tau|$ 确定，$\tau > 2$ 或 $\tau < 0$，取决于侧面延伸的交点是否位于 $p_0$ 与 $p_2$ 的同一侧，或另一侧），因此
$$S_0 = A\tau^2, S_1 = A(1 - \tau)^2, S_2 = A(2 - \tau)^2.$$

检查等式 (*) 是否再次成立，并且 $A$ 和 $\tau$ 可以用 $S_0$ 和 $S_2$ 表示，如下所示：
$$\frac{\tau - 2}{\tau} = \sqrt{\frac{S_2}{S_0}} \Rightarrow \tau = \frac{2\sqrt{S_0}}{\sqrt{S_0} - \sqrt{S_2}};$$
$$A = \left(\frac{\sqrt{S_0} - \sqrt{S_2}}{2}\right)^2.$$

$V$的体积等于$2(S_0 + \sqrt{S_0}S_2 + S_2)h/3$（可以通过两个未截断的paramid的体积之差：$V = \frac{S_0h\tau}{3} - \frac{S_2h(\tau - 2)}{3}$找到）。

当然，示例2°可以部分地视为情况3°。
4°。 $M$ 是一个侧卧的三角形特征 (图 5, a)。这里有$S_t = B(2 - t)$，所以
$$S_0 = 2B, S_1 = B, S_2 = 0,$$
并且满足不等式
$$2\sqrt{S_1} > \sqrt{S_2} + \sqrt{S_0},$$
a$V = S_0h$（图5，b）。
