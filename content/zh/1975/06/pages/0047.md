下面我们介绍1974年列宁格勒国立大学各院系数学笔试入学考试的选项。近年来物理入学考试中提供的物理问题示例位于«Kvant»，1974年第6期。

**数学与力学学院和应用数学学院 - 控制过程**

选项1

1. 一艘货船在两个港口之间行驶，其速度与所运输货物的重量成线性关系，载重2000吨的船比载重1000吨的船快3倍。此外，据了解，该船载重2000吨，25小时可完成港口之间的距离。在货物周转量最大的情况下，需要多长时间才能走完这段距离？最大货物周转时船舶的载重是多少？ （货物周转量是所运输货物的重量和船速的乘积。）

2. 将三个数字按从小到大的顺序排列

$a_1 = \log_{1/2} \sin 2x$, $a_2 = -1 - \log_2 \sin x$,

$$a_3 = \log_{1/2} (1 - \cos 2x),$$

如果已知$0 < x < \dfrac{\pi}{4}$。

3. 找到所有实数$a$，对于所有$b > 0$，在区间$0 < x < \dfrac{1}{2}$中存在方程的解

$$\log_2 (1 - x - x^2) = a\log_{1-x-x^2} 2 + b.$$

4. 给定一个边长为 $a$ 的等边三角形和一个接触三角形一条边并将第二条边分成相等部分的圆。另外，已知圆心位于三角形的第三条边上。求从圆心到三角形最近顶点的距离。

5. 金字塔的底面是等腰三角形，其边长等于$b$，底角等于$\alpha\ \left(\alpha > \dfrac{\pi}{4}\right)$。棱锥体的每条侧边均与底面平面形成$\beta$角。求通过金字塔高度和角$\alpha$顶点的截面面积。

选项2

1. 货运列车的速度与车厢数量成线性关系，已知60节车厢的列车速度
⟦column⟧
等于$\dfrac{2}{3}$一列40节车厢的火车的速度。此外，据了解，机车乘务组运输计划完成率100%，货运周转率最高。 （货运周转量是车厢数量和列车速度的乘积。） 机车乘务组制作一列 40 节车厢的货运列车时，能完成运输计划的百分比是多少？

2. 将三个数字按从小到大的顺序排列

$a_1 = 1 + \log_2 \cos x, \quad a_2 = \log_2 (1 + \cos 2x)$,

$$a_3 = 1 - 2\log_{\frac{1}{2}} \sin 2x,$$

如果已知$0 < x < \dfrac{\pi}{6}$。

3. 找到所有实数$a$，对于所有$b < 0$，在区间$4 < x < +\infty$中存在方程的解

$$a\log_{\left(1 - \frac{2}{x}\right)} 4 = \log_4\left(1 - \frac{2}{x}\right) + b.$$

4. 给定一个底边为 $a$ 的等腰三角形和一个中心位于三角形顶点之一的圆。我们知道，三角形的一条边被圆分​​成三等份。求圆的半径。

5. 金字塔的底面是等腰梯形，其边和小底等于$a$，锐角等于$\alpha\ \left(\alpha > \dfrac{\pi}{3}\right)$。棱锥体的每条侧边均与底面平面形成$\beta$角。求垂直于梯形底边穿过金字塔高度的横截面积。
