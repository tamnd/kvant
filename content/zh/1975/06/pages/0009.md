⟦folio 7⟧

拉基本行动。因此，根据练习8b，您可以构造任意点$(x, y)$，其坐标通过$p_1, \ldots, p_n$使用基本运算来表示。定理 1 的一半已被证明。

还需要证明相反的说法：如果可以构造点$(x, y)$，则使用基本动作通过原始配置的参数来表达$x$和$y$。该陈述紧随以下引理而来。

引理。 *将基本结构 $\alpha$、$\beta$、$\gamma$ 之一应用于具有参数 $q_1, \ldots, q_N$ 的配置。然后使用基本动作通过 $q_1, \ldots, q_N$ 表达结果配置的参数。*

我们在证明引理之前进行以下练习。

练习 9. 证明

a) 通过两个不同点 $(c_1, c_2)$ 和 $(d_1, d_2)$ 的直线由以下方程给出

$$x = c_1 \text{ при } c_1 = d_1$$

和

$$y = \frac{c_2 - d_2}{c_1 - d_1}x + \frac{c_1d_2 - c_2d_1}{c_1 - d_1} \text{ при } c_1 \neq d_1,$$

b) 点$(c_1, c_2)$和$(d_1, d_2)$之间的距离为$\sqrt{(c_1-d_1)^2+(c_2-d_2)^2}$，

c) 如果方程给出两条线

$$y = k_1x + b_1 \text{ и } y = k_2x + b_2,$$

那么对于$k_1 = k_2$，它们要么平行，要么重合，对于$k_1 \neq k_2$，它们相交于点

$$\left(\frac{b_2-b_1}{k_1-k_2},\ \frac{k_1b_2-k_2b_1}{k_1-k_2}\right);$$

线 $y = k_1x + b_1$ 和 $x = a_2$ 相交于点 $(a_2, k_1a_2 + b_1)$；线 $x = a_1$ 和 $x = a_2$ 平行或重合，

d) 圆心为$(c, d)$，半径为$r$的圆由方程$(x-c)^2 + (y-d)^2 = r^2$给出。

引理的证明。构造$\alpha$时，参数$q_1, \ldots, q_N$（方程$x = c$或$y = kx + b$的系数）添加一两个数字，用于指定绘制的线。根据练习9a，它们通过使用基本动作的$q_1, \ldots, q_N$来表达
⟦column⟧
属性（因为绘制线的标记点的坐标包含在参数$q_1, \ldots, q_N$中）。

构造$\beta$时，以$O$为圆心，以$CD$为半径绘制一个圆。参数中包含点 $O$、$C$ 和 $D$ 的坐标，并使用练习 9b 的基本运算用它们来表示半径。

构造$\gamma$时，可能存在三种情况。

第一个 - 当两条线的交点被标记时 - 使用练习 9c 来处理。

在第二种情况下，让我们标记圆 $(x-c)^2+(y-d)^2=r^2$（参见练习 9d）和直线 $y = kx + b$ 的交点或切点 $(x_0, y_0)$。坐标$(x_0, y_0)$满足两个方程。将$y=kx+b$代入第一个方程，我们得到一个二次方程来确定$x_0$

$$(x-c)^2+(kx+b-d)^2=r^2.$$

如果我们应用该公式来求解二次方程，则$x_0$（因此$y_0=kx_0+b$）将使用基本运算以$k, b, c, d$和$r$的形式表示。对于方程$x = a$给出的直线，类似的结果甚至更简单。

在第三种情况下，标记圆的交点或切点

$$(x-c)^2+(y-d)^2=r^2,$$
$$(x-c')^2+(y-d')^2=r'^2.$$

让我们打开括号并用一个方程减去另一个方程。我们得到一个线性方程

$$Px+Qy=R,$$

其中$P=2(c'-c)$、$Q=2(d'-d)$、$R=r^2-r'^2+c'^2-c^2+d'^2-d^2$。如果$Q \neq 0$，那么我们将其重写为$y=kx+b$的形式（其中$k=-P/Q$，$b==R/Q$），如果$Q=0$，$P \neq 0$，则将其重写为$x=a$的形式（其中$a=R/P$），从而将所有内容简化为已经分析过的第二种情况；相等$P=Q==0$是不可能的（如果$R \neq 0$，则圆没有公共点，如果$R = 0$则它们重合）。
