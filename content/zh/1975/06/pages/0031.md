F301。直径为 D 的克鲁兹达透镜由直径相连的两半组成。其中一个焦距为F，另一个为2F。距直线距离 a 处有一个光源，在透镜另一侧距离 2a 处有一个屏幕。绘制屏幕上源图像的照明与屏幕功率到镜头光轴的距离的关系图。变换器位于镜头的光轴上，屏幕垂直于该轴。

透镜的两半组成一个由焦距为 F（L1 为 lin）和 2F（L2 为 lin）的两个透镜组成的光学系统。这些透镜的光轴重合。根据定义，照度取决于入射到屏幕上的光通量以及屏幕上光斑的面积。在我们的例子中，当确定光源的位置时，每个镜头都会在屏幕上创建自己的光点，因为镜头距离不同。通过透镜的光通量的大小是相同的，因为透镜的面积是相同的，因此落在屏幕上的光通量所包含的立体角是相同的。因此，屏幕的照度由图像区域的大小决定。显然，当光源的位置发生变化时，其图像的位置也发生变化，因此，屏幕上光斑的面积以及图像在屏幕上的照度也发生变化。

使用透镜公式，我们发现源图像距透镜的距离为 f1 = Fa/a - F 和 f2 = 2Fa/a - 2F。让我们远离源的几个位置。

对于 a < F f1 < 0 且 f2 < 0，即两个源图像都是最小的。 图13 上显示的光线落在屏幕上。屏幕上的这些光线不会重叠，透镜会照亮屏幕的相应部分并在其上创建自己的照明。 （回想一下，在几何光学中，考虑的是窄近轴光束，因此屏幕上的光斑很小，我们可以假设光斑中任何地方的照明都是相同的。）在右侧，图显示了照明与光轴距离 x 的关系图。

对于 F < a < 2F f1 > 0 且 f2 < 0。第一个透镜中的光源图像是真实的，而在第二个透镜中它是最小的。然而，照度分布取决于f1是大于还是小于到屏幕2a的距离。这对应于以下 F < a < 3/2 F 和 3/2 F < a < 2F。
