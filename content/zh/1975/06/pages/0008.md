来自配置$\{A, B\}$，由两个点$A$和$B$（$AB = 1$）组成。如果可以用圆和尺子在$10^\circ$处将其分成三等份，那么我们可以根据构形$\{A, B\}$，在$10^\circ$处构造一个角，从而得到长度为$s = \sin 10^\circ$的线段（参见图4，其中$\Rightarrow C = 10^\circ$，$CD = 1$，$DE \perp CE$，因此$DE = \sin 10^\circ$）。

让我们证明这是不可能的，即从数字 1 开始使用有限数量的基本动作无法得到数字$s = \sin 10^\circ$。

使用公式$\sin 3\alpha = 3\sin \alpha - 4\sin^3 \alpha$，我们得到方程$\frac{1}{2} = \sin 30^\circ = 3s - 4s^3$，或$s^3 - \frac{3}{4}s + \frac{1}{8} = 0$。 (1)

由定理2，我们足以证明(1)没有有理根。您可以直接验证这一点，但使用以下通用技术更容易。

引理。令目标系数为 $a_1, \dots, a_n$ 的方程 $x^n + a_1x^{n-1} + a_2x^{n-2} + \dots + a_{n-1}x + a_n = 0$ (2) 具有有理根 $x_0$。则$x_0$为必填数；数$u$$|x_0|$是$|a_n|$的约数。

证明。让我们把$x_0$写成不可约分数$p/q$（$p$是一个整数，$q$是一个自然数，部分地，如果$x_0$是一个整数，那么$q = 1$）。我们将 $x_0 = p/q$ 代入 (2)，将所有项乘以 $q^{n-1}$ 并与右侧第一项相交。我们得到$a_1p^{n-1} + a_2p^{n-2}q + \dots + a_{n-1}pq^{n-2} + a_nq^{n-1} = -p^n/q$。

左边有一个整数，也就是说$p^n/q$也是整数，又因为$p$和$q$互质，所以$q = 1$和$x_0$也是整数。将$x = x_0$重写为$a_n = x_0(-a_{n-1} - a_{n-2}x_0 - \dots - a_1x_0^{n-2} - x_0^{n-1})$形式，我们发现$|a_n|$可以被$|x_0|$整除。引理已得证。

为了使用引理，我们在 (1) 中进行更改 $x = 2s$。我们得到方程$x^3 - 3x + 1 = 0$。 (3)

由于 1 和 -1 不是它的根，那么（根据引理）它没有有理根，因此方程（1）没有有理根。根据定理2，数s不能用有限数量的基本动作用1来表示，因此$30^\circ$中的角三等分问题是无解的。

8. 定理1的证明

我们会说数字$x$可以基于给定的配置来构造，如果基于它可以构造点$C$和$D$使得$CD = |x|$（即，如果$x \ge 0$则为$CD = x$，如果$x < 0$则为$CD = -x$）。

练习 8. 证明 a) 如果可以构造数 $z$ 和 $t$，则也可以构造数 $z + t$、$z - t$、$zt$、$z/t$（对于 $t \neq 0$）和 $\sqrt{z}$（对于 $z \ge 0$），b) 点当且仅当可以构造其坐标 - 数字$x$和$y$时，才能构造$(x, y)$，c) 基于参数$p_1, \dots, p_n$的配置，可以构造数字$p_1, \dots, p_n$。

从练习 8c 和 8a 可以看出，基于此配置，您可以构造通过其参数 $p_1, \dots, p_n$ 表示的任何数字。
