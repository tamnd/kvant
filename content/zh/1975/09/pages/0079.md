（这是以矢量形式写成的一般库仑定律）。让我们用 $x', y'$ 和 $z'$ 表示所考虑点的坐标（即 $r = \sqrt{x'^2 + y'^2 + z'^2}$）。那么报告系统$K'$中电场方向的投影等于

$$E'_x = -\frac{1}{4\pi\varepsilon_0} \frac{e}{r^2} \frac{x'}{r},$$
$$E'_y = -\frac{1}{4\pi\varepsilon_0} \frac{e}{r^2} \frac{y'}{r},$$
$$E'_z = -\frac{1}{4\pi\varepsilon_0} \frac{e}{r^2} \frac{z'}{r}.$$

在固定坐标系$K$中，此时所考虑的坐标原点与报告系统$K'$的坐标原点重合，根据公式（3）、（7）和（8）我们有

$$E_x = E'_x, \quad E_y = \frac{E'_y}{\sqrt{1-v^2/c^2}},$$
$$E_z = \frac{E'_z}{\sqrt{1-v^2/c^2}};$$
$$B_x = 0, \quad B_y = \frac{-vE'_z}{c^2\sqrt{1-v^2/c^2}},$$
$$B_z = \frac{vE'_y}{c^2\sqrt{1-v^2/c^2}}.$$

让我们将值$E'_x, E'_y,$和$E'_z$代入这些公式中。考虑到由于沿轴$X x' = \frac{x}{\sqrt{1-v^2/c^2}},$、$y' = y$和$z' = z,$的距离减少，并引入符号$\beta = v/c,$，我们得到

$$E_x = -\frac{ex(1-\beta^2)}{4\pi\varepsilon_0(\sqrt{x^2+(y^2+z^2)(1-\beta^2)})^3},$$
$$E_y = -\frac{ey(1-\beta^2)}{4\pi\varepsilon_0(\sqrt{x^2+(y^2+z^2)(1-\beta^2)})^3},$$
$$E_z = -\frac{ez(1-\beta^2)}{4\pi\varepsilon_0(\sqrt{x^2+(y^2+z^2)(1-\beta^2)})^3};$$
$$B_x = 0,$$
$$B_y = \frac{evz(1-\beta^2)}{4\pi\varepsilon_0 c^2(\sqrt{x^2+(y^2+z^2)(1-\beta^2)})^3},$$
$$B_z = \frac{evy(1-\beta^2)}{4\pi\varepsilon_0 c^2(\sqrt{x^2+(y^2+z^2)(1-\beta^2)})^3}.$$

您可以注意到电场不再是球对称的。让我们考虑$\beta \rightarrow 1,$为$v \rightarrow c$时的情况。除了垂直于电子方向运动的 $x = 0,$ 平面外，电场始终为零。在这个平面中，$E_x = 0,$以及分量$E_y$和$E_z$增长为$1/\sqrt{1-v^2/c^2}$（在$v \rightarrow c$）。因此，移动电子的电场似乎使其变平。
