$\frac{1}{b+c}, \frac{1}{c+a}, \frac{1}{a+b}$也将变得渐进。这很漂亮 - 两个级数并且都是整数......

D. 第二个是分数，因为如果 $a$ 和 $b$ 是整数，则 $\frac{1}{a+b}$ 是分数。

答：没关系。我希望根部失败。即使 $a, b, c$ 不是整数，而是有理数 - 它仍然很漂亮。但是如何选择三个有理数$a, b, c$使得$a^2 - b^2$等于$b^2 - c^2$呢？毕竟，这不是一次方程，可能无法提取根...等等，但我们有一个一次表达式！这是（1）。

D、我不明白。

哦，看。令 $\frac{1}{b+c}, \frac{1}{c+a}, \frac{1}{a+b}$ 为已知级数。例如，1、3、5。或 100、101、102。来自任何有理数。这意味着我们有一个由三个一级方程组成的系统，其中有第三个未知数$a, b, c$。可以解决*）。解又是有理数。那么$a^2, b^2, c^2$就会自动形成有理数列。

D. 来吧，来吧，我们试试吧。例如，有一个级数 1、3、5。

答：不，让我们直接讨论一般情况：考虑级数 $\alpha - \beta, \alpha, \alpha + \beta$，其中 $\alpha$ 和 $\beta$ 是任意数字。为了确定数字 $a, b, c$，我们得到以下方程组：

$$b + c = \frac{1}{\alpha - \beta},$$

$$c + a = \frac{1}{\alpha},$$

$$a + b = \frac{1}{\alpha + \beta}.$$

*) 总是可能的吗？

D. 将所有方程相加并将总和除以二；我们得到

$$a + b + c = \frac{3\alpha^2 - \beta^2}{2\alpha(\alpha^2 - \beta^2)}.$$

(7)依次减去(4)、(5)、(6)；我们得到：

$$a = \frac{\alpha^2 - \beta^2 - 2\alpha\beta}{2\alpha(\alpha^2 - \beta^2)}, \quad b = \frac{\alpha^2 + \beta^2}{2\alpha(\alpha^2 - \beta^2)},$$

$$c = \frac{\alpha^2 - \beta^2 + 2\alpha\beta}{2\alpha(\alpha^2 - \beta^2)}.$$

这意味着无论我们取什么$\alpha$和$\beta$*)，数字$a^2, b^2, c^2$（其中$a, b$和$c$是使用这些公式计算的）必须形成级数。我们来看看吧。

答：现在。这就是我的想法。对于数字 $a, b$ 和 $c$，我们现在有了分数表达式。让我们丢弃它们的分母；那么$a, b, c$增加相同的次数并且将成为整数，当然，如果$\alpha$和$\beta$被视为整数。在这种情况下，数字$a^2, b^2, c^2$仍将按顺序形成。
