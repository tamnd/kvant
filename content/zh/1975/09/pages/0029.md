新方程
$$a^2 + c^2 = 2b^2;$$
(12)
解由式(8)~(10)表示。

D. 这个等式从何而来？
答：所以，毕竟，这是数字$a^2, b^2$和$c^2$组成级数的条件的简短记录。
D：啊，我明白了。但尚未证明公式（8）-（10）提供了该方程的所有解。
哦，为什么？毕竟，这一点是清楚的；方程（12）的任何解都使得数字$\frac{1}{b+c}, \frac{1}{c+a}, \frac{1}{a+b}$形成级数；任何级数都可以表示为$\alpha - \beta, \alpha, \alpha + \beta$。对所有可能的$(\alpha, \beta)$对进行排序后，我们获得方程（12）的所有解。天气晴朗？
D. 每一个，是的。
答：但这不是重点。我们找到解的方法很奇怪：我们不是求解二阶方程 (12)，而是求解其等价的具有任意右侧的线性方程组 (4)-(6)。我想知道是否还存在未定义的二阶方程，如果用整数求解，则具有与一阶方程组类似的性质？
D. 也许我们应该搬走？我们来听听录音机吗？
O. 请...（他们启动录音机。O. 再次查看答案。他看起来很惊讶。）
D、什么？
O.（指向第 (11) 行）。看，这些是毕达哥拉斯三角形的公式！这些给出了所有具有边 $u, v$ 和斜边 $w$ 的整数直角三角形：
$$u = \alpha^2 - \beta^2, v = 2\alpha\beta, w = \alpha^2 + \beta^2, \text{— можно проверить, что } u^2 + v^2 = w^2.$$
这意味着埃及三角形（11）并非偶然。您可以采用任何具有边 $u, v$ 和斜边 $w$ 的毕达哥拉斯三角形，并从其边长得出方程 (12) 的解：
$$a = u \pm v, c = u \mp v, b = w.$$
D、好奇。让我们检查一下。设直角三角形的边长分别为5、12、13。则$12 + 5 = 17, 12 - 5 = 7$。我们得到数字$7^2, 13^2, 17^2$。确实，$7^2 + 17^2 = 2 \cdot 13^2$。
O.我怎么没有通过等式（12）的形式立即证明数字$a$和$c$是两个数字$u$和$v$的和与差？毕竟，这是毕达哥拉斯定理的属性方程；看：
$$(u + v)^2 + (u - v)^2 = 2(u^2 + v^2),$$
因此$b^2 = u^2 + v^2$。
并且这样的方程的整数解是已知的。多么美好的事情啊！毕竟，$(u + v)^2$是建立在腿之和上的正方形的面积，而$(u - v)^2$是建立在腿之差上的正方形的面积。这意味着我们已经证明，任何直角三角形的边差、斜边和边之和所构成的正方形面积可以形成级数。
D. 想想看，这是一个发现！整个证明可以放在一行中。
答：这个发现并不伟大，但却是它自己的发现。我们以前不知道这一点。
D. 不管怎样，某本书上有写到。
哦，就这样吧！而我却没有书...
D.（他的好奇心终于苏醒了）为什么必须是腿$u$和$v$的和与差？例如，$a = 2u + v, c = u - 2v$；然后
$$a^2 + c^2 = 5(u^2 + v^2) = 5w^2.$$
这意味着不定方程的整数解
$$a^2 + c^2 = 5w^2$$
(13)
使用以下公式可以从勾股三角形 $u, v, w$（$w$ 是斜边）获得相同的结果
$$a = 2u + v, c = u - 2v, b = w.$$
答：是的。很明显，通过这种方式你可以解决整数问题
