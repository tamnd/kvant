问题 6. 求解方程组

$$\begin{cases}
3x^2 - 2xy - y^2 = 0, \\
x^2 + 5y = 6.
\end{cases}$$

系统的第一个方程是 2 次齐次方程。将其两边除以 $y^2$（$y = x = 0$ 不是系统解的情况）并设置 $t = \frac{x}{y}$，我们得到二次方程 $3t^2 - 2t - 1 = 0$，从而得到 $t_1 = 1$、$t_2 = -\frac{1}{3}$。因此，要么$y = x$，要么$y = -3x$。将$y = x$和$y = -3x$代入系统的第二个方程，我们找到它的四个解：$x_1 = y_1 = 1; x_2 = y_2 = -6$；

$$x_{3,4} = \frac{15 \mp \sqrt{249}}{2},$$

问题 7. 求解方程组

$$\begin{cases}
3x^2 - \frac{25}{12}xy + 3y^2 = 50, \\
x^2 + y^2 = 25.
\end{cases}$$

该系统的特点是所有包含未知数的项都具有二级。为了去掉自由项，我们将系统的第二个方程乘以 2，然后从第一个方程中减去它。考虑一个由所得方程（齐次）和原始方程组的第二个方程组成的方程组：

$$\begin{cases}
x^2 - \frac{25}{12}xy + y^2 = 0, \\
x^2 + y^2 = 25.
\end{cases}$$

系统(5)与系统(4)等价。

由系统(5)的第一个方程代入$t = \frac{x}{y}$，可得：$t_1 = \frac{3}{4}, t_2 = \frac{4}{3}$。将$x = \frac{3}{4}y$和$x = \frac{4}{3}y$代入系统的第二个方程，我们找到四个解：$x_{1,2} = \pm 3, y_{1,2} = \pm 4; x_{3,4} = \pm 4, y_{3,4} = \pm 3$。

系统(5)的第一个方程定义了一对直线，方程为$x = \frac{3}{4}y$和$x = \frac{4}{3}y$，第二个方程是半径为5、圆心在原点的圆的方程。系统的解将是直线与圆的交点坐标 (图 2)。

问题 8（MISI）。求解方程组

$$\begin{cases}
2x^2 - 3xy + y^2 = 3, \\
x^2 + 2xy - 2y^2 = 6.
\end{cases}$$

将系统的第一个方程乘以 2，并从中减去第二个方程，我们得到系统

$$\begin{cases}
3x^2 - 8xy + 4y^2 = 0, \\
x^2 + 2xy - 2y^2 = 6,
\end{cases}$$

其中第一个方程是齐次的，它的解是$x = 2y$和$x = \frac{2}{3}y$。将它们代入系统的第二个方程，我们找到两个解：$x_{1,2} = \pm 2, y_{1,2} = \pm 1$。

让我们考虑三角方程的例子，其解可以简化为齐次方程的解。
