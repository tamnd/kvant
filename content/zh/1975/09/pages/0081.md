6) （参见 图 6 统计数据）。在“主”区间 $[-\pi, \pi]$ 上，函数 $u(t)$ 的方程具有以下形式

$$u_0 = |t|, t \in [-\pi, \pi].$$

沿 x 轴移动图形 $u_0$，我们得到

$$u_n = |t - 2n\pi|, t \in [\pi(2n-1), \pi(2n+1)].$$

c)（参见图7）。在“主”区间 $\left[-\frac{\pi}{2}, \frac{3\pi}{2}\right]$ 上，方程有

$$u_0 = \begin{cases} t, t \in \left[-\frac{\pi}{2}, \frac{\pi}{2}\right]; \\ -t + \pi, t \in \left[\frac{\pi}{2}, \frac{3\pi}{2}\right]. \end{cases}$$

将图平移 $n2\pi$，我们得到

$$u_n = \begin{cases} t - 2n\pi, \\ t \in \left[-\frac{\pi}{2} + 2n\pi, \frac{\pi}{2} + 2n\pi\right]; \\ -(t - 2n\pi) + \pi, \\ t \in \left[\frac{\pi}{2} + 2n\pi, \frac{3\pi}{2} + 2n\pi\right]. \end{cases}$$

转换后，两行可以替换为一行：

$$u_m = (-1)^m [t - m\pi],$$

$$t \in \left[\frac{\pi}{2} + (m-1)\pi, \frac{\pi}{2} + m\pi\right],$$

$$(m = 0, \pm 1, \pm 2, \ldots).$$

（对于$m = 2n$，获得第一行；对于$m = 2n + 1$，获得第二行。）等式成立：

$$u(t) = \arcsin(\sin t) = (-1)^m [t - m\pi],$$

$$t \in \left[\frac{\pi}{2} + (m-1)\pi, \frac{\pi}{2} + m\pi\right],$$

$$m = 0, \pm 1, \pm 2, \ldots.$$

2. $u(t) = A|\sin t|.$

3. 在 $[0, 2\pi]$ 上，函数有方程

$$u_0 = \begin{cases} A \sin t, t \in [0, \pi]; \\ 0, t \in [\pi, 2\pi]. \end{cases}$$

$n = 0, \pm 1, \pm 2, \ldots$ 处所有函数的方程

$$u(t) = \begin{cases} A \sin(t - n2\pi), \\ t \in [2\pi n, \pi(2n+1)]; \\ 0, t \in [\pi(2n+1), \pi(2n+2)]. \end{cases}$$

两行可以替换为一行：

$$u(t) = \frac{1 + (-1)^m}{2} A \sin t,$$

$$t \in [m\pi(m+1)\pi],$$

$$m = 0, \pm 1, \pm 2, \ldots.$$

4. 函数 $S(t)$ 在 $[0, \pi]$ 上的图形是通过平移此正弦线获得的：在 $\frac{\pi}{2}$ 上 – 向右（沿 x 轴），在 $A$ 上 – 向上（沿纵坐标轴）。这就是为什么

$$S_0 = A \sin\left(t - \frac{\pi}{2}\right) + A = -A \cos t + A,$$

$$t \in [0, \pi].$$

将图$S_0$向右移动$n\pi$，向上移动$n \cdot 2A$，我们得到函数的方程：

$$S(t) = -A \cos(t - n\pi) + A(2n+1),$$

$$t \in [n\pi, (n+1)\pi],$$

$$n = 0, 1, 2, 3, \ldots.$$
