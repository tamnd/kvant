⟦folio 7⟧

无重复序列

G·A·古列维奇

阿森序列

如果一个数字序列包含至少一对相同的数字组，那么我们将其称为“重复序列”。例如，序列1、2、3、4、2、3、4、2、1和1、2、2、7、6、2、7、6、8重复，但序列4、2、1、2、3、4、2、3和3、2、3、1、2、7不重复。我们将不重复的序列称为“不重复”。令 B(n) 表示长度为 n 的序列集合，并且 |B(n)| - 他们的号码。

直观上很清楚：序列越长，它包含相邻的两组相同数字的可能性就越大。事实上，如果你科学地写出一个足够长的序列，那么这个序列很可能会被重复。

让我们给这句话一个准确的含义。

问题1.证明对于任何数字ε > 0，可以指定n，使得在长度为n的所有序列中，无重复序列的比例将小于ε，即$$\frac{|\text{Б}(n)|}{10^n} < \varepsilon.$$

很容易证明，所有长度大于3、由两个数字1和2组成的序列都是重复的。

然而，从三个不同的数字已经可以创建一个有角度的、非重复的序列。

1937年，苏联数学家S.E.Arshon证明了这一事实，他提出了一种构造无重复序列的归纳方法，如下所示。

让我们用 $K_1$ 表示无重复序列 1, 2, 3。假设已经构造了无重复序列 $K_n$。序列$K_{n+1}$是这样得到的。

如果数字$n+1$是偶数并且序列$K_n$中的第$n+1$位是1，则序列$K_n$被分配数字3、2、1的三元组；如果成本为 2，则三元组为 1, 3, 2；如果成本为 3，则三元组为 2, 1, 3。

如果数字$n+1$是奇数，并且序列$K_n$中的第$n+1$位是1，则将三元组1,2,3添加到序列$K_n$中；如果成本为 2，则三元组为 2, 3, 1；如果成本为 3，则三元组为 3, 1, 2。

部分地，

$$K_2 = 1, 2, 3, 1, 3, 2$$
（$n = 2$为偶数，$K_1$中的第二位为2），

$$K_3 = 1, 2, 3, 1, 3, 2, 3, 1, 2, 3, 2, 1$$
（$n = 3$为偶数，$K_2$中的第三位为3），

$$K_4 = 1, 2, 3, 1, 3, 2, 3, 1, 2, 3, 2, 1$$
（$n = 4$为偶数，$K_3$第四位为1）等

使用 Arshon 方法获得的序列不重复的证明是相当强大的。
