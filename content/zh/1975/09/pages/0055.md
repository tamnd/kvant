任务 9. *解方程*
$$2\sin x + 3\cos x = 0.$$

该方程关于 sin x 和 cos x 是一次齐次的。将方程两边同时除以cos x（很容易看出没有丢根）。我们有：
$$2\mathrm{tg}x + 3 = 0, \quad \mathrm{tg}x = -\frac{3}{2}, \quad x = -\mathrm{arctg}\frac{3}{2} + \pi k \quad (k - \text{целое}).$$

方程 $a\sin^2x + b\sin x\cos x + c\cos^2x = 0$ 简化为 $a\mathrm{tg}^2x + b\mathrm{tg}x + c = 0$ 形式。

任务 10.*解方程*
$$\sin^2x - 3\sin x\cos x + 2\cos^2x = 0.$$

将方程的各部分除以$\cos^2x$，不会丢失根，所以我们得到方程$\mathrm{tg}^2x - 3\mathrm{tg}x + 2 = 0$，从中得到$\mathrm{tg}x_1 = 1$，$x_1 = \frac{\pi}{4} + \pi k$； $\mathrm{tg}x_2 = 2$、$x_2 = \mathrm{arctg}2 + \pi m \quad (k, m - \text{целые}).$

方程 $a\sin x + b\cos x = c$ 可以通过多种方式求解。通过代入 sin $x = 2\sin \frac{x}{2} \times \cos \frac{x}{2}$、cos $x = \cos^2\frac{x}{2} - \sin^2\frac{x}{2}$、$c = c\left(\cos^2\frac{x}{2} + \sin^2\frac{x}{2}\right)$，可以将其简化为 sin $\frac{x}{2}$ 和 cos $\frac{x}{2}$ 的齐次方程。

任务 11.*解方程*
$$3\sin x + 5\cos x = -3.$$

我们有：$3\sin x + 5\cos x - 3, \quad \sin^2\frac{x}{2} - 3\sin \frac{x}{2}\cos \frac{x}{2} - 4\cos^2\frac{x}{2} = 0, \quad \mathrm{tg}^2\frac{x}{2} - 3\mathrm{tg}\frac{x}{2} - 4 = 0, \quad \mathrm{tg}\frac{x_1}{2} = -4, \quad x_1 = 2\mathrm{arctg}4 + 2\pi k; \quad \mathrm{tg}\frac{x_2}{2} = -1, \quad x_2 = -\frac{\pi}{2} + 2\pi m \quad (k, m - \text{целые}).$

请注意，通过引入辅助参数来求解方程 $a\sin x + b\cos x = c$ 并不总是方便。例如，使用该方法求解方程（6），我们得到
$$3\sin x + 5\cos x$$

$$\sqrt{34}\left(\frac{3}{\sqrt{34}}\sin x + \frac{5}{\sqrt{34}}\cos x\right) =$$

$$= \sqrt{34}\sin \left[x + \arcsin \frac{5}{\sqrt{34}}\right],$$

$$\sin \left(x + \arcsin \frac{5}{\sqrt{34}}\right) = -\frac{3}{\sqrt{34}},$$

$$x = (-1)^{m+1}\arcsin \frac{3}{\sqrt{34}} -$$

$$- \arcsin \frac{5}{\sqrt{34}} + \pi m \quad (m - \text{целое}).$$

​​​​求解三角方程时使用齐次性的思想通过一年相对增加2度的能力得到丰富 $u = \sin x$, $v = \cos x$ 将它们乘以 $\sin^2x + \cos^2x$.

任务 12.*解方程*
$$4\sin^3x = \sin x + \cos x.$$

将等式右边乘以$\sin^2x + \cos^2x$，然​​后两边除以$\cos^3x$，我们得到等式
$$3\mathrm{tg}^3x - \mathrm{tg}^2x - \mathrm{tg}x - 1 = 0.$$

猜测当将左边分解为因子时，其中一个必须等​​于$\mathrm{tg}x - 1$（因为$\mathrm{tg}x = 1$满足方程），我们很容易找到这个分解
$(\mathrm{tg}x - 1)(3\mathrm{tg}^2x + 2\mathrm{tg}x + 1) = 0$

答案：$x = \frac{\pi}{4} + \pi k \quad (k - \text{целое}).$

成功的替换还可以将一些指数方程简化为齐次方程。
