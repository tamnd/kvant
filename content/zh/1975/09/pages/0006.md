到 $B_x, B_y, B_z$ - 磁感应矢量在固定报告系统坐标轴上的投影。相同数量的值在移动报告系统中发生变化，将用字符$(E_x', B_x')$等表示）。相对理论给出了这些值之间的以下关系：

$$E_x' = E_x, \quad B_x' = B_x;$$

$$E_y' = \frac{E_y - vB_z}{\sqrt{1 - v^2/c^2}},$$

$$E_z' = \frac{E_z + vB_y}{\sqrt{1 - v^2/c^2}};$$

$$B_y' = \frac{B_y + \frac{v}{c^2}E_z}{\sqrt{1 - v^2/c^2}},$$

$$B_z' = \frac{B_z - \frac{v}{c^2}E_y}{\sqrt{1 - v^2/c^2}}.$$

我们看到，电场的方向性和磁场感应的值在不同的报告系统中是不同的。所以，如果$K$系统中没有磁场$(B_x = B_y = B_z = 0)$，那么报告的驱动系统中的电场会返回$1/\sqrt{1 - v^2/c^2}$次，同时其中会出现磁场。场的方向也会改变。例如，如果在系统 $K$ 中，电场沿着 $Y$ 轴定向，那么在 $K'$ 中，它也可能在 $Z$ 轴上（在 $B_y \neq 0$ 处）有投影。

让我们考虑一下这个例子。让我们假设在静止报告系统中$(K)$有一个磁铁，它产生了磁场$B$，其感应线沿着$Z$轴，并且没有电场。然后是$B_z = B$、$B_x = B_y = 0$，此外还有$E_x = E_y = E_z = 0$。如果$v \ll c$，那么与1相比，我们可以忽略$v^2/c^2$并放入$\sqrt{1 - v^2/c^2} = 1$。根据式（3）第一个，我们发现在报告的驱动系统中电场返回，

$$E_y = \frac{E_y' + vB_z'}{\sqrt{1 - v^2/c^2}}, \quad E_z = \frac{E_z' - vB_y'}{\sqrt{1 - v^2/c^2}};$$

$$B_y = \frac{B_y' - \frac{v}{c^2}E_z'}{\sqrt{1 - v^2/c^2}}, \quad B_z = \frac{B_z' + \frac{v}{c^2}E_y'}{\sqrt{1 - v^2/c^2}}.$$
