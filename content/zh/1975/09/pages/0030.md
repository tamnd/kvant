⟦folio 28⟧

任何$a^2 + c^2 = (m^2 + n^2) b^2$形式的不定方程，其中$m$和$n$是整数。

D.如何解方程
$$a^2 + c^2 = 3b^2?$$

答：我不知道。我得考虑一下。我们还没有澄清一个问题：哪个计算能力的不定方程可以简化为线性方程组？例如，方程（12），我们简化为系统（4）-（6）。但随后我们不知道是否还有此类方程的其他例子。现在我明白你可以想出尽可能多的想法。这对我来说是某种等式，类似于（1），但系数不同。例如，这样开始：
$$\frac{2}{3a + 2b}.$$

D. 请（格言）：
$$\frac{2}{3a + 2b} - \frac{3}{c - a} = \frac{1}{b + 4c}$$

答：好的。结果是连接三个未知数 $a, b, c$ 的方程。它等价于下面的二阶方程：
$$3a^2 - 6b^2 + 8c^2 - 9ab - 47ac - 24bc = 0.$$

我们想要找到这个方程的有理解。如果 $a, b, c$ 是有理数，则 (15) 中的 dobriv 也是有理数。让我们用$2\alpha$表示第一个，用$3\beta$表示第二个：那么第三个等于$2\alpha - 3\beta$（$\alpha$和$\beta$是有理数）。我们得到系统
$$3a + 2b = \frac{1}{\alpha}, \quad c - a = \frac{1}{\beta},$$
$$b + 4c = \frac{1}{2\alpha - 3\beta}.$$

解决了之后我们就会找到它
$$a = \frac{-16\alpha^2 + 24\alpha\beta + 3\beta^2}{5\alpha\beta (2\alpha - 3\beta)},$$
$$b = \frac{24\alpha^2 - 31\alpha\beta - 12\beta^2}{5\alpha\beta (2\alpha - 3\beta)},$$
$$c = \frac{-6\alpha^2 + 9\alpha\beta + 3\beta^2}{5\alpha\beta (2\alpha - 3\beta)}.$$

这些是方程（16）所需的有理解。如果$\alpha$和$\beta$是整数，则表达式(18)的分子给出其整数解。如果我们不是取三个未知数$a, b, c$，而是更多，那么通过在左右两边写上与未知数一样多的分数，我们就可以得到一个更高次的不定方程。一般来说，分数越多，产生的不定方程的阶数越高；并且任意参数$\alpha, \beta, \gamma, \dots$的数量越多，表示的解就越多。

D. 但你事先并不知道你会得到什么样的方程。并不是每个最高次方程都等价于包含分数和的方程。如果它们相等，那么如何找到这些分数？
