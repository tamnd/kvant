这里 $a_0, a_1, \dots$ 是一个无限序列，其中有限数量的项为 1，其余项为 0。

让$a = \sum_{k=0}^{\infty} a_k \cdot 2^k, b = \sum_{k=0}^{\infty} b_k \cdot 2^k$。

让我们定义$c = a \circ b$的值：放入$c = \sum_{k=0}^{\infty} c_k \cdot 2^k$，其中数字$c_k$由以下规则确定：

$$c_k = \begin{cases} 0, & \text{ если } a_k = b_k, \\ 1, & \text{ если } a_k \neq b_k. \end{cases}$$

显然，对于这样定义的操作，条件 1) 和 2) 得到满足。让我们检查条件 3) 是否满足。让我们重新表述一下：

如果$a \circ b \neq c$，则：$a \circ b < c$，或$a < c < b$，或$b \circ c < a$。

让$a \circ b \neq c$。让我们用$k$表示不满足条件(*)的最高数。那么就会出现以下两种情况之一：

(a) $a_h = b_h = c_h = 1$.

在这种情况下，甚至三个不等式都得到满足。事实上，让我们证明，例如，$a \circ b < c$。由于数字$a \circ b$的第$k$位等于0，并且在$(k+1)-м, (k+2)-м, \dots$位中数字$a \circ b$和$c$重合，则

$$a \circ b \leq 2^0 + 2^1 + \dots + 2^{k-1} + \Delta = 2^k - 1 + \Delta,$$

其中 $\Delta$ 表示数字 $c_{k+1} \cdot 2^{k+1} + c_{k+2} \cdot 2^{k+2} + \dots$。但数$c$的第$k$位是1；这意味着$c \geq 2^k + \Delta$，因此$a \circ b < c$。

设$a_h = b_h = 0, c_h = 1$（其他情况类似）。然后$a \circ b < c$，再次​​$a \circ b \leq 2^k - 1 + \Delta, c \geq 2^k + \Delta$。
