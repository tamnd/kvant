齐次方程

在学校数学课程中，“齐次方程”（“齐次方程组”）的概念至少出现3次。因此，当求解线性方程组时，系统 $^*$) 被称为齐次

$$\begin{cases} ax + by = 0, \\ cx + dy = 0. \end{cases}$$

当考虑二次方程组时，据说方程组

$$\begin{cases} 14x^2 - 5xy + 3y^2 = 16, \\ 6x^2 - xy + y^2 = 8 \end{cases}$$

是一个等价方程组，其中一个是齐次的，第二个是原方程组$^*$的一个方程组）。当求解三角方程 $^*$) 时，方程被称为齐次方程

$$\sin x - \cos x = 0,$$

$$\sin^2 x - 5 \sin x \cos x + 6 \cos^2 x = 0.$$

是什么将上述例子与术语“齐次方程”作为一个概念结合起来？

从数字上看，我们有度$n$。例如，

$$f(u, v) = 2u^2 - 7uv + 9v^2$$

是二阶齐次多项式，并且

$$f(u, v) = u^3 - 15u^2v + 5v^3$$

是三次齐次多项式。

如果 $f(u, v)$ 是 $k$ 次齐次多项式，则方程 $f(u, v) = 0$ 称为 $k$ 次齐次方程。

请注意，齐次性的概念也适用于具有大量未知数的方程。例如，我们可以说方程 $x^3 + 3x^2y + 3xyz + z^3 = 0$ 是关于未知数 $x, y$ 和 $z$ 的齐次三次方程。

考虑具有两个未知数 $x$ 和 $y$ 的 $n$ 次齐次方程：

$$f(x, y) \equiv a_0x^n + a_1x^{n-1}y + a_2x^{n-2}y^2 + \dots + a_ny^n = 0.$$ (1)

我们假设$a_0 \neq 0$。

$a_0 = 0$的情况适合我们这样考虑：如果我们以最小的次数将$y$从括号中取出，那么括号中将存在一个首项系数非零的齐次多项式。例如，方程 $x^4y^2 + 3xy^5 - 7y^6 = 0$ 采用 $y^2(x^4 - 3xy^3 - 7y^4) = 0$ 形式，之后方程组 $y^2 = 0, x^4 + 3xy^3 - 7y^4 = 0$ 仍被视为原始方程的方程。

请注意，$x = 0, y = 0$ 是方程 (1) 的解，但 $x = x_0, y = 0$ 与 $a_0 \neq 0, x_0 \neq 0$ 不是方程 (1) 的解

问题 1（密歇根州立大学生物学院，1967 年）。一辆汽车从A点开往B点，但有一个骑自行车的人从B点径直向她驶来。会后三分钟，汽车小转，跟随骑车人$u$，到达他，再次转弯，到达B点。如果汽车在会后1分钟小转，会后骑车人报告速度为15/7倍，则汽车会同时冻结整条路。找出自行车和汽车的最佳速度。

设 $x (km/min)$ 为汽车速度，$y (km/min)$ 为自行车速度。请注意，在第一种情况和第二种情况下，从 A 点到第一次与骑车人会面的位置花费相同的时间，并且在两种情况下汽车从第一次与骑车人会面的地点移动到 B 点也花费相同的时间。因此，从第一次与骑车人相遇的那一刻到第二次经过他们第一次相遇的地点，汽车的移动花费了相同的时间。让我们计算一下每种情况下的时间。

一、与骑行者会合后，汽车向B点方向行驶3分钟，再需要3分钟才能回到集合点。在此期间，骑自行车的人将移动到距离集合点 6 公里的地方。汽车将以$(x-y) \cdot km/min$的速度升值，这将花费$\frac{6y}{x-y} \cdot min$。她也需要$\frac{6y}{x-y} \cdot min$才能回到集合地点，但只需要$3+3+2 \cdot \frac{6y}{x-y} = \left(6 + \frac{12y}{x-y}\right) \cdot min$。

二.电线类似异化，我们得到

$$1 + 1 + \frac{2 \cdot \frac{15}{7} y}{x - \frac{15}{7} y} + \frac{2 \cdot \frac{15}{7} y}{x - \frac{15}{7} y} = \left(2 + \frac{60y}{7x - 15y}\right) \cdot min$$

将找到的表达式等同，我们得到方程

$$6 + \frac{12y}{x - y} = 2 + \frac{60y}{7x - 15y},$$

在哪里

$$7x^2 - 16xy - 15y^2 = 0.$$

这是关于 $x$ 和 $y$ 的齐次二阶方程。 Polyag $t = x/y$（汽车与骑车人的速度之比）并求解方程$7t^2 - 16t - 15 = 0$，我们找到$t = 3$（负根不满足条件）。

任务 2（MISI）。解方程

$$20 \left( \frac{x-2}{x+1} \right)^2 - 5 \left( \frac{x+2}{x-1} \right)^2 + 48 \frac{x^2-4}{x^2-1} = 0.$$

让我们引入新的未知数$u = \frac{x-2}{x+1}$，$v = \frac{x+2}{x-1}$。我们得到方程 $20u^2 - 5v^2 + 48uv = 0$，关于 $u$ 和 $v$ 的二阶齐次。将其两个部分除以$v^2$（很容易看出，在$u = v = 0$的情况下没有解）并设置$\frac{u}{v} = t$。我们得到方程 $20t^2 + 48t - 5 = 0$，根为 $t_1 = -\frac{5}{2}$，$t_2 = \frac{1}{10}$。

第一种情况$\frac{u}{v} = -\frac{5}{2}$； $\frac{x-2}{x+1} : \frac{x+2}{x-1} = -\frac{5}{2}$； $\frac{x^2-3x+2}{x^2+3x+2} = -\frac{5}{2}$； $7x^2 + 9x + 14 = 0$，这个方程没有实根。

第二种情况$\frac{u}{v} = \frac{1}{10}$； $\frac{x^2-3x+2}{x^2+3x+2} = \frac{1}{10}$； $3x^2 - 11x + 6 = 0$； $x_1 = 3$； $x_2 = \frac{2}{3}$。

任务 3（MISI）。解方程

$$2(x^2+x+1)^2 - 7(x-1)^2 = 13(x^3-1).$$

让我们输入$u = x-1$，$v = x^2+x+1$。那么方程将采用 $2v^2 - 7u^2 = 13uv$ 的形式。对于情况$v = u = 0$，没有解决方案。将方程两边同时除以$v^2$，并引入新的未知数$t = \frac{u}{v}$，我们得到方程$7t^2 + 13t - 2 = 0$，根为$t_1 = 1/7$，$t_2 = -2$。

第一种情况，$\frac{x-1}{x^2+x+1} = \frac{1}{7}$，$x^2 - 6x + 8 = 0$，$x_1 = 2$，$x_2 = 4$；在第二个$\frac{x-1}{x^2+x+1} = -2$、$2x^2 + 3x + 1 = 0$、$x_3 = -1$、$x_4 = -\frac{1}{2}$。

答案：$x_1 = 2$、$x_2 = 4$、$x_3 = -1$、$x_4 = -\frac{1}{2}$。

任务 4（MISI）。解方程

$$x^2 + 2x + 15 = 2x\sqrt{2x+15}.$$

再介绍一个不为人知的$u = \sqrt{2x+15}$。我们得到齐次方程$x^2 + u^2 = 2xu$。它可以像平常一样求解，也可以用$(x-u)^2 = 0$的形式表示，因此$x = u$。从方程$x = \sqrt{2x+15}$可得出$x^2 - 2x - 15 = 0$、$x_1 = -3$、$x_2 = 5$。值$x = -3$不满足方程（3），但$x = 5$满足。

问题 7. 求解方程组

$$\begin{cases}
3x^2 - \frac{25}{12}xy + 3y^2 = 50, \\
x^2 + y^2 = 25.
\end{cases}$$

该系统的特点是所有包含未知数的项都具有二级。为了去掉自由项，我们将系统的第二个方程乘以 2，然后从第一个方程中减去它。考虑一个由所得方程（齐次）和原始方程组的第二个方程组成的方程组：

$$\begin{cases}
x^2 - \frac{25}{12}xy + y^2 = 0, \\
x^2 + y^2 = 25.
\end{cases}$$

系统(5)与系统(4)等价。

由系统(5)的第一个方程代入$t = \frac{x}{y}$，可得：$t_1 = \frac{3}{4}, t_2 = \frac{4}{3}$。将$x = \frac{3}{4}y$和$x = \frac{4}{3}y$代入系统的第二个方程，我们找到四个解：$x_{1,2} = \pm 3, y_{1,2} = \pm 4; x_{3,4} = \pm 4, y_{3,4} = \pm 3$。
