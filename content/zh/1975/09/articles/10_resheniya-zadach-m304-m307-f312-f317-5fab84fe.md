现在让我们列出反转的一些属性。

1. 通过反转中心 P 的直线在反转期间会回归自身。

2. 任何不通过反演中心 P 的直线都会成为通过点 P 的圆，反之亦然 (图 5, a, 6)。

3. 不通过反演中心 P 的圆在反演过程中会进入另一个也不通过点 P (图 6, a, 6) 的圆，或者可能进入同一个圆。后一种可能性在两种情况下实现：1）当给定圆相对于反演圆（图4）时； 2）当该圆与反转圆重合时。

您可以在已经提到的 A. P. Savin 的文章和 I. M. Yaglom 的书中找到这些属性的证据。

反演理论很容易从平面转移到空间：如果我们考虑由于图 4-6 所示的图形旋转而围绕中心线（PA、PB 或 PO₁）获得的空间体，这一点就不难验证。设一个球体 Σ，其中心为 P，半径为 k；我们将给定点 A 相对于球体 Σ 的逆点定义为属于射线 PA 的点 A'，并且距离 |PA|·|PA'|=k²。

在这个转变中，反转的球体变成了它自己。与反转球体正交的球体在反转过程中也会变成自身：反转球体将与其正交的球体分成两部分，这两个部分在反转过程中“交换位置”。

该理论将展示如何使用反演来解决问题 M305 6)。考虑一个球体 Σ，其中心位于给定点 P，与给定球体 S 正交。让我们对球体 Σ 进行反演。在这种情况下，球体 S 将向自身转移，并且圆 σεS 的任何点 A 都将转移到点 A' 的反转：点 A'：射线 PA 与球体 S 的第二个交点。因此，集合 σ' 的点是其反转对应于圆 σ 的点的点，反之亦然。从之前的所有评论可以看出 σ' 是一个圆。

应用机械能守恒定律可以发现

$$\frac{m(v_0 \cos \alpha)^2}{2} + mgh = \frac{mv_1^2}{2}.$$

在第二个水平部分，接下来穿过拐点后，速度将等于

$$v_2 = v_1 \cos \alpha = \sqrt{v_0^2 \cos^2 \alpha + 2gh \cos \alpha},$$

在第三个水平截面上 -

$$v_3 = \sqrt{v_0^2 \cos^6 \alpha + 2gh \left(\cos^4 \alpha + 1\right) \cos \alpha},$$

第四个——

$$v_4 = \sqrt{v_0^2 \cos^{10} \alpha + 2gh \left(\cos^8 \alpha + \cos^4 \alpha + 1\right) \cos \alpha},$$

于第n日——

$$v_n = \sqrt{v_0^2 \cos^{2(2n-3)} \alpha + 2gh \left(\cos^4(n-2)\alpha + \cos^4(n-3)\alpha + \ldots + 1\right)} \times \cos \alpha = \sqrt{v_0^2 \cos^{2(2n-3)} \alpha + 2gh \frac{1 - \cos^4(n-1)}{\cos^4 \alpha}} \cos \alpha.$$

从$\cos \alpha < 1$开始，对于非常大的$n \cos^2(2n-3) \alpha \ll 1$和$\cos^4(n-1) \alpha \ll 1$。因此，球将以稳定的速度沿水平面移动

$$v_{yct} \approx \frac{\cos \alpha}{\sqrt{1 - \cos^4 \alpha}} \sqrt{2gh} = \frac{\cos \alpha}{\sin \alpha \sqrt{1 + \cos^2 \alpha}} \sqrt{2gh}.$$

请注意，$v_{yct}$ 不依赖于初始速度 $v_0$。这意味着稳态速度对于方程（*）至关重要，其中需要输入$v_{yct} = v_0 = v_1 \cos \alpha$（参见图 13）。

F315。连接到城市照明系统的螺旋线充满电流。螺旋的一半开始冷却（例如用水）。这将如何影响这半螺旋释放的金属量？都是螺旋的吗？七的电压被认为是不变的。

让我们将冷却开始前每半螺旋的阻力表示为 $R$ (图 14)。由于金属的电阻取决于温度（加热时增加，冷却时减少），冷却螺旋的一半将导致该一半的电阻降低到某个值$R_1 < R$。由于电源电压 $U$ 不变，这将导致电路中的电流增加，从而导致线圈另一半的额外加热。这一半的电阻将增加并等于$R_2 > R$（图15）。

电路$I = \frac{U}{R_1 + R_2}$中的新电流值将大于先前值$I_0 = \frac{U}{2R}$。事实上，让我们假设相反的情况，即$I \leqslant I_0$。那么未冷却的一半螺旋的电阻保持不变或减小（$R_2 \leqslant R$），而冷却的一半的电阻$R_1 < R$。因此，总电阻为$R_1 + R_2 < 2R$，新的电流值为$I > I_0$，这与我们的假设相矛盾。

所以，$I > I_0$，因此整个电路释放的功率（即单位时间的热量）$P = IU$将会增加。

从$I > I_0$和$R_2 > R$开始，未冷却的一半释放的热量$P_2 = I^2 R_2$也会增加。

相反，在冷却的一半中释放的功率$P_1 = I^2 R_1 = \frac{U^2 R_1}{(R_1 + R_2)^2}$将首先减少功率$P_0 = I^2 R = \frac{U^2}{4R}$。让我们展示一下。

让我们找出比率 $P_0/P_1$：

$$\frac{P_0}{P_1} = \frac{U^2}{4R} : \frac{U^2 R_1}{(R_1 + R_2)^2} = \frac{(R_1 + R_2)^2}{4R_1 R_2}.$$

很明显

$$\frac{(R_1 + R_2)^2}{4R_1 R} > \frac{(R_1 + R_2)^2}{4R_1 R_2},$$

最后一个表达式大于或等于 1，因为两个量 $(\sqrt{R_1/R_2})$ 的几何平均值不超过算术平均值 $(\frac{R_1 + R_2}{2})$。

因此，实际上$P_1 < P_0$，即冷却的一半螺旋中释放的功率，将会减少。

F316。如果“星形”凸面是多种多样的，由塑料制成，垂直向下强力抛掷，那么它会像弹性橡胶球一样弹跳，几乎不会产生折痕。在我那个时代，塑料熔体用手很容易起皱。为什么？

在外力的影响下，任何物体都会发生变形。如果物体在受到力的作用后恢复到原来的形状和尺寸，则这种变形称为弹性变形。如果身体没有完全恢复到原来的形状，那么他们说，除了弹性变形之外，还会发生塑性变形。

能够承受与弹性变形幅度相比非常大的塑性变形而不破坏的材料称为塑性。相反，如果塑性变形后发生断裂，而塑性变形与弹性变形相比非常小，则该材料称为脆性材料。
