## 量纲法
N·D·克里斯塔尔

本文讨论了使用量纲方法解决的几个问题。这一方法在本期杂志上 A. S. Kompaneets 的文章“物理量的维度和现象的相似性”中有详细描述。

用具体的例子来说明量纲法的主要规定是最方便的。我们将通过分析两个物体弹性相互作用期间产生的变形和压力来做到这一点。物体抵抗倾向于改变其形状和大小的外部影响的力 $F$ 的绝对值由胡克定律确定：

$$F = kx, \qquad (1)$$

其中$x$是变形量，$k$是弹性系数。对于拉伸（或压缩）变形，表达式（1）可以展开形式重写：

$$F = \frac{ES}{l}\,\Delta l. \qquad (2)$$

这里$E$是弹性模量（杨氏模量）——表征材料抵抗外部影响能力的量；与所研究的样品的形状和尺寸无关，$S$是垂直于外力方向的横截面积，$l$是长度，$\Delta l$是变形体长度的变化。

让我们考虑球的弹性碰撞。

问题 1. *两个半径为 $R$、由密度为 $\rho$ 和弹性模量为 $E$ 的材料制成的球，沿连接其中心的直线以相等的速度 $v$ (图 1) 相向运动。球之间发生绝对弹性冲击。求冲击过程中的最大变形量$x$。*

显然，$x$的值可以取决于表征球在撞击过程中的所有参数，即$v$、$\rho$、$R$和$E$：

$$x = x(v,\ \rho,\ R,\ E).$$

我们将以 *) 的形式寻找这种依赖性

$$x = A v^{p}\, \rho^{b}\, R^{c}\, E^{d}, \qquad (3)$$

其中$A$是无量纲比例系数($[A] = 1$)，$p$、$b$、$c$和$d$是目前未知的无量纲指数。

根据维数原理，等式(3)左右边的维数公式应相同：

$$[x] = [v^{p}]\ [\rho^{b}]\ [R^{c}]\ [E^{d}]. \qquad (4)$$

这对指标$p$、$b$、$c$和$d$的值施加了一定的条件。让我们写出等式（3）两边出现的所有量的量纲。

我们围
$$[x] = \mathrm{L}, \quad [R] = \mathrm{L}.$$
由此可见，体积和面积的尺寸为 $\mathrm{L}^3$ 和 $\mathrm{L}^2$。根据定义，速度表征单位时间内行驶的路径，这意味着
$$[v] = \frac{\mathrm{L}}{\mathrm{T}} = \mathrm{LT}^{-1}.$$

材料的密度是每单位体积的物质的量，因此
$$[\rho] = \frac{\mathrm{M}}{\mathrm{L}^3} = \mathrm{ML}^{-3}.$$

弹性模量的量纲可以使用胡克定律和牛顿II定律来确定。由式(2)可知
$$E = \frac{F}{S}\,\frac{l}{\Delta l}.$$

根据牛顿 II 定律，力等于质量乘以加速度：
$$F = ma.$$
方法，
$$E = \frac{ma}{S}\,\frac{l}{\Delta l}. \qquad (5)$$

加速度是单位时间内速度的变化，所以
$$[a] = \frac{[v]}{[t]} = \mathrm{LT}^{-2}.$$

方程（5）中剩余量的量纲可以立即写出：
$$[m] = \mathrm{M}, \quad [S] = \mathrm{L}^2,$$
$$[l] = [\Delta l] = \mathrm{L}.$$
因此，
$$[E] = \frac{\mathrm{MLT}^{-2}}{\mathrm{L}^2}\,\frac{\mathrm{L}}{\mathrm{L}} = \mathrm{ML}^{-1}\mathrm{T}^{-2}.$$

让我们将相应量的量纲代入等式（4）：
$$\mathrm{L} = (\mathrm{LT}^{-1})^p\,(\mathrm{ML}^{-3})^b\,(\mathrm{L})^c\,(\mathrm{ML}^{-1}\mathrm{T}^{-2})^d,$$
或者
$$\mathrm{L}^1 = \mathrm{L}^{p-3b+c-d}\ \mathrm{M}^{b+d}\ \mathrm{T}^{-(p+2d)}. \qquad (6)$$
如果左侧和右侧相同符号的指数相等，则左侧和右侧尺寸的公式相同。让我们将方程（6）重写为以下形式
$$\mathrm{L}^1\mathrm{M}^0\mathrm{T}^0 = \mathrm{L}^{p-3b+c-d}\mathrm{M}^{b+d}\mathrm{T}^{-(p+2d)}.$$

将左右两边具有相同符号的指数相等，我们得到方程组
$$\begin{cases} 1 = p - 3b + c - d, \\ 0 = b + d, \\ 0 = p + 2d, \end{cases}$$
从中我们发现
$$c = 1, \quad b = \frac{p}{2}, \quad d = -\frac{p}{2}.$$

我们将这些值代入（3）：
$$x = Av^p\,\rho^{p/2}E^{-p/2}R,$$
或者
$$\frac{x}{R} = A\left(\frac{\rho^{1/2}v}{E^{1/2}}\right)^p = A\left(\frac{\rho v^2}{E}\right)^{p/2}. \qquad (7)$$

所得表达式确定了球相对变形 $\dfrac{x}{R}$ 的方程形式。然而，$A$和$p$仍然未知。

比较表达式(3)和(7)，可以看出，考虑量的量纲使得可以用两个无量纲量之间的关系来代替五维量($x$、$v$、$\rho$、$R$、$E$)之间的关系：
$$\left[\frac{x}{R}\right] = 1, \quad \left[\frac{\rho v^2}{E}\right] = 1.$$

如果我们通过实验寻找依赖关系$x = x(v,\ \rho,\ R,\ E)$，那么使用量纲方法可以让我们研究仅一个无量纲量$\dfrac{\rho v^2}{E}$对$\dfrac{x}{R}$的影响，而不是四维量对$x$的影响。这给实验者带来了很大的便利，因为它可以显着减少必要的实验次数。

需要注意的是，系数$A$无法通过量纲法确定，因为它与量纲公式中的指数没有任何关系。指标$p$与量纲公式相关，因此在某些情况下可以

定义。让我们尝试重点介绍可以做到这一点的案例。

在我们的问题中，有四个未知指数 $p$、$b$、$c$、$d$ 以及用于确定它们的三个方程。可以构造用于查找未知系数的方程的数量等于基本测量单位的数量。要确定所有未知指标的数值，需要它们的数量等于系统中独立方程的数量。这只有在两种情况下才有可能：如果您选择具有四个基本单位的测量单位系统，或者如果您合理地减少自变量的数量（从而减少未知指标的数量）。

我们将考虑第二种方式。我们假设撞击时发生的变形仅取决于弹性模量 $E$ 和球的动能 $\mathrm{K} = \dfrac{mv^2}{2}$，其中 $m$ 是球的质量。这里我们仅在动能表达式中考虑球的大小：$\mathrm{K} = \dfrac{1}{2}\ \dfrac{4}{3}\ \pi R^3 \rho v^2$。

（这是一个粗略的假设，因为变形的大小不仅取决于动能，还取决于球的半径$R$。）这个假设允许我们近似地写成：

$$x = A_1 \mathrm{K}^{p_1} E^{b_1}.$$

动能的量纲

$$[\mathrm{K}] = [mv^2] = \mathrm{ML^2T^{-2}}.$$

如果我们现在组成一个方程组并确定 $p_1$ 和 $b_1$ 的值（与上面的操作类似），我们得到

$$\frac{x}{R} = \frac{A_1}{R}\left(\frac{\mathrm{K}}{E}\right)^{1/3} = A_2 \left(\frac{\rho v^2}{E}\right)^{1/3}. \qquad (8)$$

式(8)中的指数$^1/_3$接近于问题严格数学解得到的指数$^2/_5$\*)。

使用量纲方法时，正确地表述问题非常重要，因为问题的表述确定了所需值所依赖的那些参数。在求解球的弹性碰撞问题时，我们考虑了球材料抵抗球内部变形传播的能力（$E$）、研究区域的形状和大小（半径为$R$的球）、外部对研究区域的影响（通过速度$v$和每个球材料的密度$\rho$）。

问题 2. *求半径为 $R$ 的球在沿着球中心连线的两个压缩力 $F$ 的作用下发生的变形。球体材质相同，弹性模量为$E$。*

在这里，与第一个问题一样，我们知道物体的形状和大小（半径$R$的球）、对球的外部影响（力$F$）以及球的材料特性（杨氏模量$E$）。

为了解决这个问题，我们需要找到变形幅度$x$对值$F$、$R$和$E$的依赖关系。我们将再次以这种形式寻找这种依赖性

$$x = A_3 F^n R^s E^t, \qquad (9)$$

或对于尺寸

$$[x] = [F^n]\ [R^s]\ [E^t]. \qquad (10)$$

力$F$的量纲等于

$$[F] = [ma] = \mathrm{MLT^{-2}}.$$

将量$x$、$F$、$R$、$E$的量纲代入(10)，我们得到

$$\mathrm{L} = (\mathrm{MLT^{-2}})^n \mathrm{L}^s (\mathrm{ML^{-1}T^{-2}})^t,$$

或者

$$\mathrm{L^1M^0T^0} = \mathrm{L}^{n+s-t}\mathrm{M}^{n+t}\mathrm{T}^{-2n-2t}.$$

让我们使该等式左右两侧相同符号的指数相等：

$$\begin{cases} 1 = n + s - t, \\ 0 = n + t, \\ 0 = -2n - 2t. \end{cases}$$

从这里

$$t = -n, \quad s = 1 - 2n.$$

因此，

$$x = A_3 F^n R^{1-2n} E^{-n} = A_3 R \left(\frac{F}{ER^2}\right)^n,$$

或者
$$\frac{x}{R} = A_3 \left(\frac{F}{ER^2}\right)^n. \qquad (11)$$

一般来说，对球的外部影响会改变球的材料状态。这种材料状态的变化用“应力”的概念来表征。材料在$F$作用下$S$（图2）截面的应力称为值$\sigma = F/S$，其中$S$为横截面积。在垂直于所考虑的截面的力的作用下产生的应力称为法向应力或压力。应力表征材料上的比载荷（本体单位横截面积的载荷）。随着特定载荷的增加，材料首先变得无弹性，然后塌陷。因此，应力的确定具有实际意义。

问题 3. *如果球由弹性模量 $E$ 的材料制成，则求出半径为 $R$ 的两个球在压缩力 $F$ 的作用下产生的应力 $\sigma$（参见图 2）。*

显然，$\sigma$取决于$F$、$E$和$R$：
$$\sigma = \sigma(F,\ E,\ R).$$
我们将再次假设这种依赖性具有以下形式
$$\sigma = A_4 F^{n_1}\ R^{s_1}\ E^{t_1}. \qquad (12)$$
根据电压的定义，电压的量纲为

力的大小除以面积的大小：
$$[\sigma] = \frac{[F]}{[S]} = \frac{\mathrm{MLT}^{-2}}{\mathrm{L}^2} = \mathrm{ML}^{-1}\mathrm{T}^{-2}.$$

因此，考虑到（12），
$$\mathrm{ML}^{-1}\mathrm{T}^{-2} = (\mathrm{MLT}^{-2})^{n_1}\ \mathrm{L}^{s_1}\ (\mathrm{ML}^{-1}\mathrm{T}^{-2})^{t_1},$$
在哪里
$$\left\{ \begin{array}{l} 1 = n_1 + t_1, \\ -1 = n_1 + s_1 - t_1, \\ -2 = -2n_1 - 2t_1. \end{array} \right.$$

进行适当的计算后，我们得到
$$\sigma = A_4 F^{n_1} R^{-2n_1}\ E^{1-n_1},$$
或者
$$\frac{\sigma}{E} = A_4 \left(\frac{F}{ER^2}\right)^{n_1}. \qquad (13)$$

让我们再次注意，量纲方法广泛应用于那些由于变量数量众多且描述现象的方程复杂而无法解析解的问题。在这种情况下，进行实验以找到必要的依赖关系。实验结果采用问题参数的无量纲组合进行处理，可以通过量纲方法进行区分。因此，在本文考虑的问题中，量纲方法使我们能够断言相对应变和应力不是由参数的单个数值决定的 $v$, $\rho$, $E$, $R$ 或者 $F$, $E$, $R$，而是通过参数的无量纲组合的数值 $\dfrac{\rho v^2}{E}$ 和 $\dfrac{F}{ER^2}$.
