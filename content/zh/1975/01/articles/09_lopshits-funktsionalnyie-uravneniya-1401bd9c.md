## 函数方程
A.M.洛普希茨

在开始阅读本文之前，您需要确保您很好地掌握了“函数”这个重要的数学概念。因此，我们建议您阅读 A. N. Kolmogorov 的文章 \*) 以及学校教科书中介绍和解释这一概念的页面。

让我们回想一下，要指定一个实参数的函数，其值也是实数（我们在本文中只考虑此类函数），您应该：1）首先指示“其定义域”，即指示从中选择参数值$x$的实数集合，2）明确制定规则，根据该规则为每个这样的值$x$构造相应的实数 - 它被称为：值对应于所选参数值的函数。如果任何函数用 $Ф$ 表示，则所选参数值 $x$ 所采用的值表示为 $Ф(x)$。

给定参数值$x$，该值乘以某个固定实数$a$，称为*线性齐次函数*。

这个函数将成为我们本文的主角。

**1.线性齐次函数是可加的**

在数学研究的各种函数中，读者无疑会注意到一个因其特别简单而脱颖而出的函数 - 该函数 $Л_a$ 是为参数 $x$ 的所有实值定义的，其值由以下公式确定

$$Л_a(x) = ax$$

（其中$a$是某个给定的实数）。我们称之为：*线性齐次函数*。它存在于所有研究比例量的物理问题（而不仅仅是物理）中。

教师的观察表明，学童对它的其中一个属性感觉非常好，以至于他们经常（甚至经常！）将其归因于其他更复杂的功能。事实上，学生读者是否注意到，他的一些同学在开始学习三角函数后，认为两个角度之和的正弦等于两个角度之和

这些角度的正弦是多少？这个“幼稚”错误的本质是，一个小学生在熟悉了一些新函数（我们称之为$\Phi$）后，倾向于相信它必须具有以下“简单”属性：

$$\Phi(x_1 + x_2) = \Phi(x_1) + \Phi(x_2). \qquad (1)$$

线性齐次函数确实（检查！）具有此属性，但是，唉，学校学习的其他函数*没有它*。

任何具有由等式 (1) 表示的属性的函数都称为“加法”函数。很容易检查*线性非齐次*函数，即函数 $G$，通过公式为参数的任何实值定义

$$G(x) = ax + b \qquad (b \neq 0),$$

不再是累加性的；同样，为参数$x$的任意值定义的函数，其值根据以下规则确定，不具有可加性：

$$x \to ax^2 + bx + c,$$
$$x \to \frac{1}{x^2 + a^2},$$

以及许多其他功能。

读者会问，实参的加性函数是否至少有一个不同于线性齐次函数。

如果他不懒得仔细阅读这篇短文，他就会得到这个问题的答案。

$$= \Phi(x_1) + \Phi(x_2) + \Phi(x_3). \quad (1'),$$

$$\Phi(x_1 + x_2 + x_3) = \Phi((x_1 + x_2) + x_3) =$$
$$= \Phi(x_1 + x_2) + \Phi(x_3) =$$
$$= \Phi(x_1) + \Phi(x_2) + \Phi(x_3).$$

读者不难证明

$$\Phi(x_1 + x_2 + \ldots + x_n) =$$
$$= \Phi(x_1) + \Phi(x_2) + \ldots + \Phi(x_n) \qquad (1'')$$

（当然，你必须使用数学归纳法）。

公式$(1'')$意味着相等

$$\Phi(nx) = n\Phi(x) \qquad (2)$$

（$n$是任意*整数*正数）。

由于等式（2）对于$x$的任何值都有效，因此让我们将$x$设置为等于$\frac{m}{n} y$（$m$和$n$是正整数）。我们得到

$$\Phi(my) = n\Phi\left(\frac{m}{n} y\right).$$

再次使用等式（2），我们得到

$$m\Phi(y) = n\Phi\left(\frac{m}{n} y\right),$$

那是

$$\Phi\left(\frac{m}{n} y\right) = \frac{m}{n} \Phi(y). \qquad (2')$$

因此，我们确信如果函数 $\Phi$ 是可加的，那么对于任何正有理数 $\alpha = \frac{m}{n}$ 等式成立

$$\Phi(\alpha x) = \alpha\Phi(x) \qquad (3)$$

（无论实际数字 $x$ 是什么！）。

这种显着的关系使我们*能够计算任何加性函数 $\Phi$ 对于参数的任何正有理值 $x$ 的值，只要给出其值之一 - 即当参数等于 1 时所取的值。*

事实上，在(3)中设置$x$等于1，我们得到

$$\Phi(\alpha) = \alpha\Phi(1). \qquad (4)$$

2. 同样令人惊讶的是，*用于计算任何加性函数 Ф 值的公式（4）适用于参数*的所有有理值（而不仅仅是其正值）。

a) 首先，我们要确保

$$\Phi(0) = 0\Phi(1),$$

也就是说，什么

$$\Phi(0) = 0.$$

事实上，由于函数 $\Phi$ 的可加性，等式成立

$$\Phi(x + 0) = \Phi(x) + \Phi(0),$$

那是

$$\Phi(x) = \Phi(x) + \Phi(0)$$

因此

$$\Phi(0) = 0. \qquad (5)$$

b) 此外，由于函数$\Phi$的可加性，我们有

$$\Phi(x) + \Phi(-x) =$$
$$= \Phi(x + (-x)) = \Phi(0)$$

从何而来（根据（5））

$$\Phi(-x) = -\Phi(x) \qquad (6)$$

（无论 $x$ 的实际值是多少！）。

因此，我们确信*任何加性函数都是奇函数*。

现在我们已经可以证明公式（4）适合计算加法函数的值以及参数的*负*有理值。

令 $\beta$ 为某个负有理数；那么，根据(6)，

$$\Phi(\beta) = -\Phi(-\beta). \qquad (7)$$

这里$(-\beta)$已经是一个正有理数了，所以我们可以使用公式（4）

$$\Phi(-\beta) = (-\beta)\,\Phi(1).$$

将最后一个关系式代入式(7)，我们得到

$$\Phi(\beta) = \beta\Phi(1),$$

这就是我们想要证明的。

文章中，读者会说：除了齐次线性函数之外，没有其他可加函数！”

不，那不是真的！

毕竟我们证明了公式（4）仅适用于$x$的有理值。我们没有理由使用它来计算 $x$ 的加法函数 $\Phi$ 的值，例如等于 $\sqrt{2}$。

因此，数学家坚持不懈地寻找一种不同于线性齐次函数的加性函数也就不足为奇了。

真的很难找到这样的功能！毕竟，我们已经看到它的值（如果存在的话！）必须与某个线性齐次函数$x \to xa$的值一致，粗略地说，对于所有$x$来说“几乎”：虽然有理数不能穷尽所有实数的集合，但它们实际上足以满足任何精度问题的近似解。

德国数学家 Hamel 于 1905 年构建了此类函数的一个示例 \*)。

**4.加性函数在至少一个区间上有界于上方**

1. 令加法函数 $\Phi$ 从上方有界于区间 $(p,\ p+s)$，其中 $s$ 是某个正数。很容易看出，$\Phi$ 也在区间 $(0,\ s)$ 上有界。

事实上，让 $x$ 为任何不大于 $s$ 的正数，则数字 $p + x$ 位于区间 $(p,\ p+s)$ 内，因此，$\Phi(p+x)$ 小于某个给定数字 $M$；由于可加性 $\Phi$，

$$\Phi(p) + \Phi(x) < M$$

因此

$$\Phi(x) < M - \Phi(p)$$

对于位于区间 $(0,\ s)$ 内的任何值 $x$。

2. 现在让我们考虑一个新函数 $G$，对于参数的任意值 $x$，其值将使用以下公式计算

$$G\,(x) = \Phi\,(x) - \frac{\Phi\,(s)}{s}\,x. \qquad (8)$$

函数 $G\,(x)$ 也在区间 $(0,\ s)$ 上有界：它在该区间上的值小于 $M' = M - \Phi(p) + |\,\Phi\,(s)\,|$。

3. 很明显（见（8））函数$G$是可加的并且$G\,(s) = 0$。这就是为什么

$$G\,(x + s) = G\,(x) + G(s) = G\,(x)$$

因此函数 $G$ 的数字 $s$ *周期*！

因此，函数$G$对参数$x$的某些值所采用的值等于其对区间$(0,\ s)$中参数的某些值所采用的值，因此它小于$M'$，即对于任何值$x$小于$G(x) < M'$。

4. 现在我们已经可以证明这个命题了——也许读者出乎意料：

*函数$G$的任何值都等于零。*

我们将“通过矛盾”来做到这一点。令对于参数$x$的任何正值$x_0$，小于$s$，对应的值$G(x_0)$不为零，$G(x_0) \neq 0$。

那么，由于函数$G$的可加性，我们有（见公式（4））

$$G\,(\alpha x_0) = \alpha\,G(x_0).$$

选择$\alpha$使得

$$\alpha G\,(x_0) > M',$$

我们会得到

$$G\,(\alpha x_0) > M'.$$

这与 $G(x) < M'$ 对于所有 $x$ 的事实相矛盾。因此，我们的假设是不正确的，对于$x_0$的任何值，$G\,(x_0) = 0$都位于区间$(0,\ s)$内。考虑到函数$G\,(x)$有一个周期$s$，我们得出的结论是

$$G\,(x) = 0 \qquad (9)$$

对于任何 $x$ 值。

5. 现在回到函数$G$的定义(8)，根据(9)，我们得到

$$\Phi\,(x) = ax \quad \left(\text{где } a = \frac{\Phi\,(s)}{s}\right).$$

读者大概已经预料到了这个结果。这是它的口头表述：*如果一个加性函数在至少一个（甚至任意小的）区间上从上面有界，那么它是一个线性齐次函数！*

**5.函数方程**

这个结果也可以表述如下：

任务是*找到一个为参数的任何实值定义的函数$\Phi$，并且具有对于参数的任何值$x$和$y$都保持等式的属性*

$$\Phi(x + y) = \Phi(x) + \Phi(y) \qquad (10)$$

有很多解决方案。即使我们只寻找这个*方程*的那些从上面有界的解$\Phi$——至少在某个区间上——那么仍然会有很多解。但任何这样的解都是线性齐次函数，即以下形式的函数

$$x \to ax$$

（$a$是某个实数）。

应该说，这个任务通常是这样表述的：

*求出满足函数方程(10)的函数$\Phi$。*

需要找到具有某些特定属性的函数的问题在学校中很少遇到，但在数学中经常被考虑并在其中发挥重要作用。这是另一个这样的任务：

*找到一个函数$G$，它具有以下属性：对于参数的任何值$x$和$y$（当然，属于所寻求的函数$G$的定义域）*

*平等*
$$G(x + y) = G(x) + G(y) + p, \qquad (11)$$
*其中* $p$ - *给定数字。*

读者可以轻松查看；功能是什么
$$x \to ax - p$$
是她的解决方案。人们很想知道是否还有其他解决方案？

另一个有趣的任务是求解函数方程
$$H(x + 2y) + H(x) = 2H(x + y). \qquad (12)$$
很容易验证该函数
$$x \to ax + b$$
（$a$和$b$是任意数）是方程（12）的解。还有其他解决方案吗？

过去的杰出数学家——其中包括欧拉、高斯、柯西、阿贝尔、洛巴切夫斯基、维尔斯特拉斯、达尔布、吉尔伯特——经常求助于函数方程并用它们来解决许多重要问题。函数方程的系统研究是由 Koshy 开始的 - 1821 年他出版了他的《分析课程》\*)（他在巴黎理工学院教授这门课程）。在其中，他详细研究了（但仍然不够充分）我们文章中考虑的函数方程（10）——它现在被称为“函数柯西方程”；该方程尤其常用于各种数学理论中。除此之外，柯西还考虑了以下函数方程：
$$\Phi(x + y) = \Phi(x)\Phi(y),$$
$$G(xy) = G(x)G(y),$$
$$H(xy) = H(x) + H(y).$$

毫无疑问，读者将能够找到这些方程的“特定”解。为每个问题找到所有解决方案要困难得多。我们希望在另一篇文章中讨论这个问题。
