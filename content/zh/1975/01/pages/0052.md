然后努力抵抗$R$

$$A_R = Q_1 = A_1 - A_\mathrm{д} - A_\mathrm{c} = \frac{C}{2}\left[(E - U_0)^2 - (I_0 R)^2\right].$$

随着电流从$I_0$进一步减小到0，二极管上的电压将不再恒定。根据二极管的电流-电压特性，电压将按照线性规律随着电流的减小而减小。这意味着在$t_2$时间段内，当电路中的电流从$I_0$减小到0时，二极管相当于一个常规电阻，其值为$r = \dfrac{U_0}{I_0}$（图 18 *v*）。

为了求出在时间$t_2$期间电阻$R$释放的热量$Q_2$，我们再次使用能量守恒定律：

$$A_2 = \Delta W_c + Q,$$

其中$\Delta W_c$是电容器能量的变化，$Q = Q_2 + Q_r$是电阻$R$和$r$释放的热量。

当电路中的电流停止时，二极管两端和电阻$R$两端的电压将为零，因此电容器两端的电压将为$E$，电荷将为$q' = CE$。因此，在$t_2$时间内，电荷通过电路

$q_2 = q' - q_1 = CE - C\,(E - U_0 - I_0 R) = C\,(U_0 + I_0 R)$.

然后

$$A_2 = q_2 E = CE\,(U_0 + I_0 R),$$

$$\Delta W_c = \frac{q'^2}{2C} - \frac{q_1^2}{2C} = \frac{CE^2}{2} - \frac{C}{2}(E - U_0 - I_0 R)^2$$

和

$$Q = A_2 - \Delta W_c = \frac{C}{2}(U_0 + I_0 R)^2.$$

电阻$r$和$R$串联，即任何时候都有相同的电流流过这些电阻。因此，电阻$R$和$r$同时释放的热量$Q_2$和$Q_r$与电阻值相关，即

$$\frac{Q_2}{Q_r} = \frac{R}{r}.$$

知道$Q_2$和$Q_r$之和以及它们的比率，我们可以找到$Q_2$：

$$Q_2 = \frac{R}{R+r}\,Q = \frac{R}{R+r}\;\frac{C\,(U_0 + I_0 R)^2}{2}.$$

然后最后

$$Q_R = Q_1 + Q_2 = \frac{C\left[(E-U_0)^2 - (I_0R)^2\right]}{2} +$$
$$+ \frac{R}{R+r}\;\frac{C\,(U_0 + I_0 R)^2}{2}.$$
