它在$B$点接触固定圆。 $O_2$ — 环与静止圆在点$B'$接触时环中心的位置；点$\{O,\ B,\ O_1\}$和$\{O_2,\ O,\ B'\}$位于同一条直线上。

让$0 < \varphi < \pi$。我们有 (图 6) $OB = OB' = r$、$O_2B' = R$、$OO_2 = R - r = \rho$、$O_1B = O_1C = \rho$、$O_1O = r + \rho = R$、$\sphericalangle\, BOB' = \sphericalangle\, OO_1C = \varphi$。

这意味着四边形$OO_1CO_2$是平行四边形，因此$O_2C = R$，$\sphericalangle\, CO_2B' = \varphi$。因此，点$C$位于以$O_2$为圆心、半径为$R$的圆上，且圆弧$B'C$的弧度等于$\varphi$。这意味着$C$与$C'$相同。因此，我们已经证明，*如果相同弧度 $\varphi < \pi$ 的轮子和环的弧沿静止圆滚动，则外摆线和外摆线的所得点将重合。*

仍有待验证该声明对于$\varphi \geqslant \pi$的有效性。亲自看看 图 5 与 $\varphi = \pi$ 以及 $\pi < \varphi < 2\pi$ 会“变成”什么。请注意，由于环和轮的长度之差等于$2\pi r$ - 静止圆边界的长度，因此当轮和轮都旋转一整圈时，观测点再次落在静止圆的边界上，将采取相同的位置$A_1$。如果我们将点 $A_1$ 而不是$A$ 视为起点，则情况 $2\pi < \varphi < 4\pi$ 会简化为情况 $\varphi < 2\pi$。如果我们以$A_1$为起点，同时改变滚动方向，则$\pi \leqslant \pi < 2\pi$的情况将减少为$\varphi \leqslant \pi$的情况。

*和。 G·金迪金*

这个解决方案可以用向量简单地写出来。如果您使用“广义角度” - 旋转角度$\varphi$，它可以取任何值（不仅在0到$2\pi$的范围内），那么您将不必单独考虑不同的情况：您只需将其用于任意三个向量$\mathbf{a}$，$\mathbf{b}$，$\mathbf{c}$

$$\widehat{\mathbf{ab}} + \widehat{\mathbf{bc}} = \widehat{\mathbf{ac}}$$

（这里$\widehat{\mathbf{ab}}$是向量$\mathbf{a}$和$\mathbf{b}$之间的角度的大小）。

令 $\mathbf{e}\,(\varphi)$ 为长度为 1 的向量，是从初始向量 $\mathbf{e}_0 = \mathbf{e}\,(0)$（向上）顺时针旋转角度 $\varphi$ 得到的。然后$\mathbf{e}\,(\varphi + \pi) = -\mathbf{e}\,(\varphi)$。

对于轮子的点 $M_1$ (图 7, a)

$$\overrightarrow{OO_1} = (\rho + r)\,\mathbf{e}\,(\varphi),$$

$$\overrightarrow{O_1M_1} = \rho\mathbf{e}\,(\pi + \varphi + \varphi_1).$$

由于$\rho\varphi_1 = r\varphi$（无滑动的滚动条件），$\rho = R - r$，则

$$\overrightarrow{OM_1} = \overrightarrow{OO_1} + \overrightarrow{O_1M_1} = R\mathbf{e}\,(\varphi) - (R - r)\,\mathbf{e}\left(\frac{R}{R-r}\,\varphi\right). \quad (1)$$

对于环的点 $M_2$ (图 7, b)

$$\overrightarrow{OO_2} = (R - r)\,\mathbf{e}\,(\psi + \pi),$$

$$\overrightarrow{O_2M_2} = R\,\cdot\,\mathbf{e}\,(\psi - \psi_1),$$

并且从 $R\psi_1 = r\psi$ 开始，那么

$$\overrightarrow{OM_2} = \overrightarrow{OO_2} + \overrightarrow{Q_2M_2} = R\mathbf{e}\left(\frac{R-r}{R}\,\psi\right) - (R - r)\,\mathbf{e}\,(\psi). \quad (2)$$

比较(1)和(2)，我们看到$\overrightarrow{OM_1} = \overrightarrow{OM_2}$位于$\dfrac{R}{R-r}\varphi = \psi$。这意味着点集 $M_1$ 和 $M_2$ 重合。
