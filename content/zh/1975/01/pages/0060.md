（图5）。最后一个关系很容易找到：通过毕达哥拉斯定理$AC_1 = 10$和平分线定理$CN : NC_1 = 3 : 5$。

现在计算$S_{CBMN} : S_{CBB_1C_1} = 7 : 16$并不困难，因此
$$V_{ACBMN} = \frac{7}{16}\, V_{ACBB_1C_1}.$$

另一方面，金字塔$ACBB_1C_1$由金字塔$AA_1B_1C_1$与整个棱柱互补，其体积为棱柱体积的$^1/_3$，因此金字塔$ACBB_1C_1$的体积等于棱柱体积$^2/_3$。因此，棱锥体积$ACBMN$为棱柱体积$^7/_{24}$，所需比例为$7 : 17$。

问题 6（密歇根州立大学，计算数学和控制论学院，1973 年）。 *球体经过 A、B、C、D 点并与线段 SA、SB、SC 和 SD 相交于点 $A_1$, $B_1$, $C_1$, $D_1$ 分别。据了解 $SD_1 = 9/4$, $DD_1 = 47/36$, 三角形面积比 $SA_1B_1$ 和 $SAB$ 等于* $15 : 32$, *金字塔体积比 $SB_1C_1D_1$ 和 $SBCD$ 等于* $1701 : 4096$, *和金字塔体积之比 $SA_1B_1C_1$ 和 $SABC$ 等于* $105 : 256$。 *查找细分 $SA_1$, $SB_1$, $SC_1$.*

很容易理解，这个问题是关于四棱锥的

⟦column⟧

$SABCD$，在其边缘上取点$A_1$、$B_1$、$C_1$、$D_1$ (图 6)。为了解决这个问题，我们将令人困惑的面积和体积之间的关系数据减少到相应段的关系。

制定了平等制度
$$\frac{SA_1}{SA}\cdot\frac{SB_1}{SB} = \frac{15}{32}, \qquad \frac{SB_1}{SB}\cdot\frac{SC_1}{SC}\cdot\frac{SD_1}{SD} = \frac{1701}{4096},$$
$$\frac{SA_1}{SA}\cdot\frac{SB_1}{SB}\cdot\frac{SC_1}{SC} = \frac{105}{256}$$

鉴于 $SD_1 : SD = 81 : 128$，我们发现
$$\frac{SA_1}{SA} = \frac{5}{8}, \qquad \frac{SB_1}{SB} = \frac{3}{4}, \qquad \frac{SC_1}{SC} = \frac{7}{8}.$$

另一方面，线段 $SA$、$SB$、$SC$、$SD$ 是球体的割线，这在问题陈述中已讨论过，因此这些割线与其外部部分的乘积等于从点 $S$ 绘制的球体切线的平方（这里我们使用关于切线和割线的明显但未经证实的陈述球体，它与圆的相应陈述的类比当然不是你自己证明这个陈述）。因此，$SA_1\cdot SA = SB_1\cdot SB =$
$$= SC_1\cdot SC = SD_1\cdot SD = \frac{9}{4}\cdot\frac{128}{36} = 8.$$
