第二个系统的点之间以及一个系统的每个点到另一个系统的每个点的相互距离。
让我们引入以下符号：
$$|A_i A_j| = a_{ij}, |B_s B_t| = b_{st},$$
$$|A_p B_q| = c_{pq}.$$
如上所述（见（7）），
$$d^2 = |O_1 O_2|^2 = \frac{1}{n} |O_1 B_1|^2 + \dots$$
$$\dots + |O_1 B_n|^2) - \frac{1}{n^2} \sum_{s < t} b_{st}^2,$$
$$|O_1 B_h|^2 = \frac{1}{m} (|A_1 B_h|^2 + \dots$$
$$\dots + |A_m B_h|^2) - \frac{1}{m^2} \sum_{i < j} a_{ij}^2,$$
（其中 $k$ 是数字 1、2、...、$n$ 中的任意一个）。将对应关系（8'）代入式（8），最终得到（进一步化简后）：
$$d^2 = |O_1 O_2|^2 = \frac{1}{mn} \sum_{p, q} c_{pq}^2 -$$
$$- \frac{1}{m^2} \sum_{i < j} a_{ij}^2 - \frac{1}{n^2} \sum_{s < t} b_{st}^2.$$

在最一般的情况下，使用此公式可以计算两个点系的质心之间的距离。

示例

1. 给定三角形$A_1 B_1 B_2$。由一个点 $A_1$ 组成的系统的质心 $O_1$ 与 $A_1$ 重合，点 $B_1, B_2$ 的系统的质心 $O_2$ 与中间的 $[B_1 B_2]$ (图 3) 重合。

在这种情况下，$[O_1 O_2]$是三角形$A_1 B_1 B_2$的中线。我们有
$$d^2 = \frac{1}{2} (|A_1 B_1|^2 + |A_1 B_2|^2) -$$
$$- \frac{1}{4} |B_1 B_2|^2.$$

2. 给定四边形$A_1 A_2 B_1 B_2$。点系$A_1, A_2$的质心$O_1$与线段$A_1 A_2$的中点重合，点系$B_1, B_2$的质心$O_2$与线段$B_1 B_2$（图4）的中点重合。

我们使用公式（9）：
$$d^2 = \frac{1}{4} (|A_1 B_1|^2 + |A_1 B_2|^2 +$$
$$+ |A_2 B_1|^2 + |A_2 B_2|^2 - |A_1 A_2|^2 -$$
$$- |B_1 B_2|^2).$$ (10)

这个公式通过四边形的边和对角线的平方来表示四边形对边中点之间距离的平方，称为欧拉公式。这里四边形的类型是任意的：它可以是凸四边形、自相交的或非平面的。
