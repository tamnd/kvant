⟦folio 48⟧

M273。在线段$0 \leq x \leq 1$上，给出了函数$f$。已知这个函数是非负的并且$f(1) = 1$。此外，对于任意两个数$x_1$和$x_2$，$x_1 \geq 0$、$x_2 \geq 0$和$x_1 + x_2 \leq 1$满足不等式的最大值
$$f(x_1 + x_2) \geq f(x_1) + f(x_2).$$
a) 证明无论函数$f$满足上述条件，对于所有$x$，不等式$f(x) \leq 2x$都将得到满足。
6) 对于所有 $x$ $f(x) \leq 1,9x$ 都是这样吗？

M274。找出表格中最小的数字
a) $|11^k - 5^l|$;
b) $|36^k - 5^l|$;
c) $|53^k - 37^l|$,
其中$k$和$l$是自然数。

a) 满足问题条件的函数返回多音调。事实上，如果$x_2 \geq x_1$和$x_2 \leq 1$，则$f(x_2) \geq f(x_1) + f(x_2 - x_1)$和$f(x_2 - x_1) \geq 0$；因此$f(x_2) \geq f(x_1)$。因此，如果$\frac{1}{2} < x \leq 1$，从$f(1) = 1$开始，我们有
$$f(x) \leq 1 \leq 2x.$$
现在让$0 < x \leq \frac{1}{2}$。让我们取一个自然的$n$，使得$\frac{1}{2} < nx \leq 1$（很明显，这总是可以做到的）。很容易证明（通过归纳法）如果$x \geq 0$和$nx \leq 1$，则$f(nx) \geq nf(x)$。对于$\frac{1}{2} < nx \leq 1$，已经证明了$f(nx) \leq 2 \cdot nx$。
波斯尼$nf(x) \leq f(nx) \leq 2 \cdot nx$，开场$f(x) \leq 2x$，开场$0 < x \leq \frac{1}{2}$。
剩下的就是找出零时会发生什么。让我们取$0 < x_1 \leq 1$；然后
$$f(x_1) = f(0 + x_1) \geq f(0) + f(x_1).$$
但根据定义，$f(0) \geq 0$意味着$f(0) = 0$。
6) 答案：不，事实并非如此。
让我们举个例子。我们将函数定义如下：
$$f(x) = \begin{cases} 1, & \frac{1}{2} < x \leq 1, \\ 0, & 0 \leq x \leq \frac{1}{2}. \end{cases}$$
如果$1 \geq x_1 \geq x_2 \geq 0$和$x_1 + x_2 \leq 1$，则$x_2 \leq \frac{1}{2}$和$f(x_2) = 0$。
因此，$f(x_1 + x_2) \geq f(x_1) + f(x_2)$，我们认为该函数满足问题的要求。
同时
$$f\left(\frac{51}{100}\right) = 1 > 1,9 \cdot \frac{51}{100}.$$

◆
a) 如果$11^k > 5^l$，则$|11^k - 5^l|$数为6；如果 $11^k < 5^l$，则乘 4。
容易看出，$|11^k - 5^l| = 4$对于$l = 3$、$k = 2$，即4是$|11^k - 5^l|$形式的最小数。
6) 如果$36^k > 5^l$，则数$|36^k - 5^l|$为1；如果 $36^k < 5^l$，则乘以 9。
对于$k = 1$，$l = 2$，我们有$|36^k - 5^l| = 11$。
让我们证明 11 是该类型中最小的数字。为此，我们需要证明 $|36^k - 5^l|$ 不能等于 1 或 9。
