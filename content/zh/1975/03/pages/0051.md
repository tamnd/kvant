1) 如果$36^k - 5^l = 1$，则$(6^k - 1)(6^k + 1) = 5^l$。
任何数字 $6^k + 1$ 都不能是 5 的幂，因为它以 7 结尾（在 $k > 0$ 处）。

2) 如果$5^l - 36^k = 9$，则$5^l = 9 + 36^k$，这也不会发生，因为$k > 0$的右侧可以被9整除，但左侧不能。这意味着 11 是 $|36^k - 5^l|$ 形式的最小数字。

c) 数字$N = |53^k - 37^l|$可以任何偶数结尾。另外，由于$|53^k - 37^l| = |(52 + 1)^k - (36 + 1)^l| = |(4.13 + 1)^k - (4.9 + 1)^l|$，则$N$可被4整除。对于$k = l = 1$$N = 53 - 37 = 16$。让我们证明 16 是$|53^k - 37^l|$形式的最小数。要做到这一点，只需证明 $N$ 不能等于 4、8 和 12（$N$，很明显，不等于 0，因为 53 和 37 是互质的）。

我们有$N = |53^k - 37^l| = |(54 - 1)^k - (36 + 1)^l| = |(6.9 - 1)^k - (4.9 + 1)^l|$。

波兹尼，$N$除以9时，余数只能是0.2和-2（即7）。但 4、8、12 除以 9 时都不会得到这些余数。

我们首先考虑“一维”问题。
引理 1. 给定 $n$ 数，使得每个模数不超过 1，且所有数之和等于 0。然后可以测量它们，使得对于任何 $i \leq n$，它们的前 $i$ 的模数之和至多为 1。

让我们指出其中一种填充方法：$a_1, \dots, a_k$ 和非正数：$b_1, \dots, b_{n-k}$。让我们输入$c_1 = a_1, c_2 = b_1$。如果$c_1 + c_2 < 0$，则放入$c_3 = a_2$；如果$c_1 + c_2 \geq 0$，则放入$c_3 = b_2$。一般来说，如果已经选择了$c_1, \dots, c_l$，则对于$c_1 + \dots + c_l < 0$，使用下一个正数作为$c_{l+1}$，对于$c_1 + \dots + c_l \geq 0$使用下一个正数。
