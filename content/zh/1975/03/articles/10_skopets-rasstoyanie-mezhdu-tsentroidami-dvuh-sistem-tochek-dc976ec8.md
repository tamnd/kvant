## 两个点系的质心之间的距离
Z·A·斯科佩茨

考虑一个由 $n$ 点 $A_1, A_2, \ldots, A_n$ 组成的系统，任意位于空间中。允许该系统的各个（甚至所有）点重合。点的顺序并不重要。

*点$A_1, \ldots, A_n$系统的质心是向量等式成立的点$O$*

$$\overrightarrow{OA}_1 + \overrightarrow{OA}_2 + \ldots + \overrightarrow{OA}_n = \sum_{i=1}^{n} \overrightarrow{OA}_i = \vec{0}. \quad (1)$$

质心的*存在*并不直接从这个定义得出。因此，我们将证明每个点系统都有一个质心，而且是唯一的。

让我们在空间中选择一个点$A_1, A_2, \ldots, A_n$系统，任意定义一个点$M$（我们将其作为向量的起点）和另一个点$O$（图1）。然后你可以写

$$\overrightarrow{OA}_1 = \overrightarrow{MA}_1 - \overrightarrow{MO},$$
$$\overrightarrow{OA}_2 = \overrightarrow{MA}_2 - \overrightarrow{MO},$$
$$\ldots \ldots \ldots \ldots$$
$$\overrightarrow{OA}_n = \overrightarrow{MA}_n - \overrightarrow{MO}.$$

让我们假设点 $O$ 是这个点系统的质心。将这些等式逐项相加，我们得到，考虑到 (1)

$$\vec{0} = \overrightarrow{MA}_1 + \overrightarrow{MA}_2 + \ldots + \overrightarrow{MA}_n - n \cdot \overrightarrow{MO}.$$

从这里我们发现

$$\overrightarrow{MO} = \frac{1}{n}(\overrightarrow{MA}_1 + \overrightarrow{MA}_2 + \ldots + \overrightarrow{MA}_n) = \frac{1}{n}\sum_{i=1}^{n} \overrightarrow{MA}_i. \quad (2)$$

逆序进行计算，我们可以很容易地验证等式（2）定义的点$O$满足关系式（1），即它是一个质心。因此，质心的“存在”被证明。仍有待证明*独特性*。事实上，让我们取一个与$O$不同的点$O'$。然后

$$\overrightarrow{O'A}_1 = \overrightarrow{O'O} + \overrightarrow{OA}_1, \ldots, \overrightarrow{O'A}_n = \overrightarrow{O'O} + \overrightarrow{OA}_n.$$

添加这些等式并考虑 (1)，我们得到

$$\overrightarrow{O'A}_1 + \ldots + \overrightarrow{O'A}_n = n \cdot \overrightarrow{OO'};$$

由于$O'$与$O$不同，则$\overrightarrow{O'O} \neq \vec{0}$和$n \cdot \overrightarrow{O'O} \neq \vec{0}$，即

$$\overrightarrow{O'A}_1 + \ldots + \overrightarrow{O'A}_n \neq \vec{0}.$$

因此，除了$O$之外，没有任何点$O'$是点$A_1, \ldots, A_n$系统的质心。这就完成了$n$点系统质心存在唯一性的证明。此外，还指出了构造质心的方法（参见（2））。

现在让我们证明以下命题。

定理 1. *设 $O_1$ 为点系统 $A_1, \ldots, A_m$ 的质心，$O_2$ 为点系统的质心*

在$B_1, \dots, B_n$。那么所有$m + n$点$A_1, \dots, A_m, B_1, \dots, B_n$的系统的重心$O$都位于线段$O_1O_2$上，并且满足条件$|O_1O| : |OO_2| = n : m$。

证明。对于位于线段$O_1O_2$上且满足条件$|O_1O| : |OO_2| = n : m$的点$O$，我们有$\vec{mOO}_1 + n\vec{OO}_2 = \vec{0}$。 (3)

让我们确保点$O$是所有$m + n$点系统的中心点。事实上，由于$O_1$是点$A_1, \dots, A_m$的系统的质心，那么根据(2)我们有

$$\vec{OA}_1 + \vec{OA}_2 + \dots + \vec{OA}_m - m \cdot \vec{OO}_1 = \vec{0}. \quad (4)$$

类似地，根据$O_2$是点$B_1, \dots, B_n$系统的质心，我们得到

$$\vec{OB}_1 + \vec{OB}_2 + \dots + \vec{OB}_m - n \cdot \vec{OO}_2 = \vec{0}. \quad (5)$$

将对应关系（3）、（4）、（5）逐项相加，我们得到

$$\vec{OA}_1 + \dots + \vec{OA}_m + \vec{OB}_1 + \dots + \vec{OB}_n = \vec{0},$$

这意味着$O$是点$A_1, \dots, A_m, B_1, B_2, \dots, B_n$系统的中心点。

结果。设$A_1, \dots, A_m$为点$k$为小于$m$的自然数的一些系统。让我们从$A_1, \dots, A_m$中选择一些$k$点，并让$O'$作为它们的质心，$O''$作为剩余$m - k$点的质心。然后以这种方式获得的所有线段$O'O''$）都经过一个点$O$（点$A_1, \dots, A_m$的系统中心点），并在该点按比例$(m - k) : k$划分。

从已证明的定理和这个推论，可以得出许多结论。首先，由$m = n = 1$的定理1可知，两点$A, B$的中心点与连接它们的线段的中点重合。进一步，对于$m = 2, n = 1$，由定理1可知，三个点$A_1, A_2, B$的重心$O$位于线段$A_1A_2$的$D$与点$B$、$|DO| : |OB| = 1 : 2$的连接线上。特别是，如果点$A_1, A_2, B$不在同一条直线上，则该点系的中心点与三角形$A_1A_2B$中线的交点重合（参见图2；该点称为三角形的重心）。

拉格朗日公式

设 O 为点 A₁、...、Aₘ 系统的质心，M 为任意点。那么，正如我们上面所看到的，关系式（2）是有效的。贝利亚平方 *)，我们得到

$$|\vec{M}O|^2 = \frac{1}{m^2} (\vec{M}A_1 + \dots + \vec{M}A_m)^2 = \frac{1}{m^2} \left[ |\vec{M}A_1|^2 + \dots + |\vec{M}A_m|^2 + 2 \sum_{i < j} \vec{M}A_i \cdot \vec{M}A_j \right].$$

但

$$2 \vec{M}A_i \cdot \vec{M}A_j = |\vec{M}A_i|^2 + |\vec{M}A_j|^2 - (\vec{M}A_j - \vec{M}A_i)^2 = |\vec{M}A_i|^2 + |\vec{M}A_j|^2 - |\vec{A}_i \vec{A}_j|^2.$$

将所有对 i, j 的这些关系相加，其中 i < j，我们得到

$$2 \sum_{i < j} \vec{M}A_i \cdot \vec{M}A_j = (m - 1) \left( |\vec{M}A_1|^2 + \dots + |\vec{M}A_m|^2 \right) - \sum_{i < j} |\vec{A}_i \vec{A}_j|^2.$$

将式(6')代入关系式(6)，可得（化简后）：

$$|\vec{M}O|^2 = \frac{1}{m} \left( |\vec{M}A_1|^2 + \dots + |\vec{M}A_m|^2 \right) - \frac{1}{m^2} \sum_{i < j} |\vec{A}_i \vec{A}_j|^2.$$

关系式(7)是著名的拉格朗日公式，通过点M到点Aᵢ的距离的平方和距离|AᵢAᵢ|的平方来表达点M到点A₁，…，Aₘ系统的质心O的距离的平方。

示例

1. 给定三角形$A_1 B_1 B_2$。由一个点 $A_1$ 组成的系统的质心 $O_1$ 与 $A_1$ 重合，点 $B_1, B_2$ 的系统的质心 $O_2$ 与中间的 $[B_1 B_2]$ (图 3) 重合。

在这种情况下，$[O_1 O_2]$是三角形$A_1 B_1 B_2$的中线。我们有
$$d^2 = \frac{1}{2} (|A_1 B_1|^2 + |A_1 B_2|^2) -$$
$$- \frac{1}{4} |B_1 B_2|^2.$$

2. 给定四边形$A_1 A_2 B_1 B_2$。点系$A_1, A_2$的质心$O_1$与线段$A_1 A_2$的中点重合，点系$B_1, B_2$的质心$O_2$与线段$B_1 B_2$（图4）的中点重合。

我们使用公式（9）：
$$d^2 = \frac{1}{4} (|A_1 B_1|^2 + |A_1 B_2|^2 +$$
$$+ |A_2 B_1|^2 + |A_2 B_2|^2 - |A_1 A_2|^2 -$$
$$- |B_1 B_2|^2).$$ (10)

这个公式通过四边形的边和对角线的平方来表示四边形对边中点之间距离的平方，称为欧拉公式。这里四边形的类型是任意的：它可以是凸四边形、自相交的或非平面的。

如果线段$A_1 A_2$和$B_1 B_2$的质心重合，则四边形是平行四边形，并且我们得到了众所周知的平行四边形的边和对角线之间的关系。注意（自$d^2 \geq 0$）由式（10）得出$|A_1 B_1|^2 + |A_1 B_2|^2 + |A_2 B_1|^2 + |A_2 B_2|^2 \geq |A_1 A_2|^2 + |B_1 B_2|^2$，即所有边的平方和

3. 让我们求出从点 $A_1$ 到点系统 $B_1, B_2, B_3$ (图 5) 中心的距离。在这种情况下我们有（通过公式（7））

$$d^2 = \frac{1}{3} \left( |A_1B_1|^2 + |A_1B_2|^2 + |A_1B_3|^2 \right) - \frac{1}{9} \left( |B_1B_2|^2 + |B_2B_3|^2 + |B_1B_3|^2 \right).$$

这是表示从四面体$A_1B_1B_2B_3$的顶点$A_1$到质心的距离的对应关系。通过四面体边缘的正方形的面 $B_1B_2B_3$ 的对立称为莱布尼茨公式。特别地，所有四个点可以属于同一平面，甚至属于同一条直线。
