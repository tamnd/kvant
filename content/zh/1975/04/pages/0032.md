在相似的情况下，让边$[A_1B_1]$对应于$[A'_2B'_2]$：
$$[A_1B_1] \rightarrow [A'_2B'_2], [A_2B_2] \rightarrow [A'_3B'_3], \dots, [A_{r-1}B_{r-1}] \rightarrow [A'_rB'_r], [A_rB_r] \rightarrow [A'_1B'_1].$$
然后$\hat{A}_1 = \hat{A}_2 = \dots = \hat{A}_r = 2\alpha$和$\hat{B}_1 = \hat{B}_2 = \dots = \hat{B}_r = 2\beta$，因此长度差$|A_iB_i| - |A'_iB'_i| = d$是相同的长度$i$（$d = \text{ctg} \alpha + \text{ctg} \beta$）。令 $k$ 为相似系数，$|A_iB_i| = x_i$。然后
$$\begin{cases}
x_1 - kx_r = d, \\
x_2 - kx_1 = d, \\
x_3 - kx_2 = d, \\
\dots \dots \dots \\
x_r - kx_{r-1} = d;
\end{cases}$$
但是，很容易证明，这个系统（对于$0 < k < 1$）只有一个解$x_1 = x_2 = \dots = x_r = \frac{d}{1-k}$。因此，我们已经证明对于多边形 $P$ 的任意边 $A_1B_1$
$$|A'_1B'_1| = k |A_1B_1|,$$
也就是说，彼此对应的多边形的边（在不存在的情况下！）是成比例的。在不存在的情况下，角度不会改变，因此证明了多边形与自然对应$[AB] \rightarrow [A'B']$的相似性。

**M284。 100个自然数的总和等于200，每个自然数不超过100。证明你可以从它们中选择几个总和等于100的数字。**

我们将假设给定 $n=2k$ 个自然数，每个自然数不大于 $n$ 并且其总和等于 $2n$ 来解决这个问题。让我们证明，从这些$n$数中，我们可以选择几个数，使它们的总和等于$n$。

令给定数字$a_1, \dots, a_n$的平均值为任意两个不同的数字，例如数字$a_1$和$a_2$（如果所有数字都相同，则它们都等于2，并且它们的$k$加起来为$n=2k$）。让我们创建新的 $n$ 数字：

$$\begin{cases}
A_0 = a_1, \\
A_1 = a_2, \\
A_2 = a_1 + a_2, \\
\dots \dots \dots \\
A_{n-1} = a_1 + a_2 + a_3 + \dots + a_{n-1}.
\end{cases}$$

这些数字中的每一个都小于 $2n$，但大于 0。将数字 $A_0, \dots, A_{n-1}$ 除以 $n$ 的余数平均值将找到零个或两个相等的余数（因为余数与数字一样，都是 $n$）。第一种情况，$A_m$对应零余数，等于$n$（可被$n$整除，大于0且小于$2n$）。第二个 - $A_m = A_k + n$ ($k < m$)。此外，$m \neq 0$和$m \neq 1$，因为数字$A_0$和$A_1$不超过$n$。对于$m=2$，$A_0$等于$n$或$A_1$等于$n$。在其他情况下，$A_m = A_k + a_{k+1} + \dots + a_m$，从中我们得到$a_{k+1} + \dots + a_m = n$。
