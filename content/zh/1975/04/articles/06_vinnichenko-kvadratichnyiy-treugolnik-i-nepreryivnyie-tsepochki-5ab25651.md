方形三角形和连续链

A·P·文钦科

可能有些读者提到了乌拉姆螺旋（例如，M. Gardner 的书“Mathematical Access”中对此进行了描述）。如果有人对这个螺旋一无所知，那也没关系；这是她的故事。有一天，美国数学家斯坦尼斯拉夫·乌拉姆（Stanislav Ulam）在参加一个无趣的会议时，出于无聊在一张方格纸上写了一个螺旋，给这个螺旋的单元格编号，并圈出了素数*）。乌拉姆得到了图1中所描绘的画面：他的螺旋中的素数似乎沿着对角线突出。现在我们将讨论自然级数的不同书写顺序，其中素数仍然像在对角线上一样放置。

*) 如果一个自然数（不等于 1）只能被它本身和一整除，则该自然数称为素数。

让我们制作一个“直角三角形”：在第一行中仅写入一个数字 - 1，在第二行中写入 - 2 到 4 中的数字，在第三行中 - 中 - 5 到 9 中的数字，依此类推，每次我们得到某个自然数的平方时就声明一行（参见 图 2）。因此，我们的第一条线以 $1^2$ 结尾，第二条线 - $2^2$，第三条 - $3^2$ 等等（因此结果图形的名称 - “方形三角形”；证明方形三角形的每条线都比前一条线长 2 个单元格）。

唯一的区别是数字 2)？但除此之外，在我们的图片中，我们有从“三角形”的“斜边”延伸到其“腿”的“连续链”——图 3 上有六个这样的链。让我们写下这些链上的素数：

2
3, 5
7, 11, 17
23, 31, 41, 53, 67, 83, 101
47, 59, 73, 89, ..., 227, 257
223, 251, 281, 313, ..., 1523, 1601

事实证明，所有这些数字都遵循相同的定律：

第一条链是多项式 $x^2 + x + 2$ 在 $x = 0$ 处的值（在 $x = 1$ 处我们得到 $2^2$），
第二条链是多项式$x^2 + x + 3$在$x = 0,1$的值（在$x = 2$我们得到$3^2$），
第三条链是多项式$x^2 + x + 5$在$x = 1,2,3$的值（在$x = 4$我们得到$5^2$），
第4条链是多项式$x^2 + x + 11$在$x = 3,4,5,...,8,9$处的值（在$x = 10$我们得到$11^2$），
第5条链是多项式$x^2 + x + 17$在$x = 5,6,...,14,15$处的值（在$x = 16$我们得到$17^2$），
第 6 条链是多项式 $x^2 + x + 41$ 在 $x = 13,14,...,38,39$ 处的值（在 $x = 40$ 处我们得到 $41^2$）。

欧拉已知$x^2 + x + k$形式的多项式； $k = 2, 3, 5, 11, 17, 41$的公式$x^2 + x + k$给出了所有$x = 0, 1,...,(k-1),(k-2)$的素数。

因此，我们的连续链是多项式$x^2 + x + k$值的“尾部”，其中$k = 2, 3, 5, 11, 17, 41$。是否有更长的连续链？目前尚不清楚。

让我们回到我们的方形三角形 - 将“Eramosthenes 的 reshemo”转移到它（参见 1974 年的«Kvant» No.1）：取一些自然数并划掉所有能被它整除的数字。我们会得到某种模式；例如，对于数字 2，它是一个“国际象棋”模式 (图 4)。对于 3，模式已经是后者（参见 图 5）。然而，这些价值观有一个模式。因此，如果你用纸板制作一个边长为 2 的正方形，并从中剪出两个正方形，将其放在 图 上并带有 6 个十字，那么使用这样的印章，你可以从正方形三角形中划掉所有能被 2 整除的数字。

真的吗：

1) 粘贴印章，使其上方仅可见 1；
2) 划掉答案中的数字；
3) 将图章向下、向右或向左移动两个方格；
4) 再次划掉答案中的数字等等。
