**M284。 100个自然数的总和等于200，每个自然数不超过100。证明你可以从它们中选择几个总和等于100的数字。**

我们将假设给定 $n=2k$ 个自然数，每个自然数不大于 $n$ 并且其总和等于 $2n$ 来解决这个问题。让我们证明，从这些$n$数中，我们可以选择几个数，使它们的总和等于$n$。

令给定数字$a_1, \dots, a_n$的平均值为任意两个不同的数字，例如数字$a_1$和$a_2$（如果所有数字都相同，则它们都等于2，并且它们的$k$加起来为$n=2k$）。让我们创建新的 $n$ 数字：

$$\begin{cases}
A_0 = a_1, \\
A_1 = a_2, \\
A_2 = a_1 + a_2, \\
\dots \dots \dots \\
A_{n-1} = a_1 + a_2 + a_3 + \dots + a_{n-1}.
\end{cases}$$

这些数字中的每一个都小于 $2n$，但大于 0。将数字 $A_0, \dots, A_{n-1}$ 除以 $n$ 的余数平均值将找到零个或两个相等的余数（因为余数与数字一样，都是 $n$）。第一种情况，$A_m$对应零余数，等于$n$（可被$n$整除，大于0且小于$2n$）。第二个 - $A_m = A_k + n$ ($k < m$)。此外，$m \neq 0$和$m \neq 1$，因为数字$A_0$和$A_1$不超过$n$。对于$m=2$，$A_0$等于$n$或$A_1$等于$n$。在其他情况下，$A_m = A_k + a_{k+1} + \dots + a_m$，从中我们得到$a_{k+1} + \dots + a_m = n$。

M285。将一张尺寸为$a \times b$的矩形纸切成矩形条，每条边的长度为1。证明数字$a$和$b$至少有一个是整数。

我们将作为指定分区元素的矩形条称为块。让我们用 $B$ 表示长度为 $b$ 的原始矩形的一条边；如果块的单边与边 $B$ 平行，我们称其为水平块，否则为垂直块。让我们表示平行于 $B$ 的线，与 $B$ 相距 $x$ 距离，并与该矩形相交 $L_x$（然后是 $x \leq a$）。我们假设留下直线$B$。

如果对于某个整数$i$，垂直块位于直线$L_i$和$L_{i+1}$之间，则将其涂成红色，将剩余的垂直块涂成蓝色，将所有水平块涂成黄色。我们用$K(L_x)$表示线$L_x$红色线段的长度之和，用$C(L_x)$表示蓝色线段的长度总和，用$JK(L_x)$表示黄色线段的长度总和。 （如果一个线段分隔了两种颜色的块，我们将假设它有一个正确的块。）显然，$JK(L_x)$对于任何$x$来说都是一个整数。让我们证明，如果我们将所有蓝色块重新着色为黄色，则任何直线 $L_x$ 黄色部分的长度之和将保持为多个整数。为此，我们只需证明$L_x$行的数字长度之和（即$C(L_x))$对于任何$x$来说都是整数。

让我们用 $\alpha_1, \alpha_2, \dots, \alpha_n$ 表示从蓝色块到 $B$ 的所有可能距离，并且

$$0 < \alpha_1 < \alpha_2 < \dots < \alpha_n \leq a - 1.$$

首先，我们证明可以对距离 $B$ $\alpha_1$ 的块 $C^{(1)}_1, \dots, C^{(1)}_k$ 重新着色。令$[a]$为$a$的整数部分。由于$\alpha_1$是蓝色块距线$B$和$[\alpha_1] < \alpha_1$的最小平均距离，因此$K(L_{\alpha_1}) = K(L_{\alpha_1}) = b - JK(L_{\alpha_1})$。因此，$C(L_{\alpha_1}) = b - K(L_{\alpha_1}) - JK(L_{\alpha_1}) = JK(L_{\alpha_1}) - JK(L_{\alpha_1})$是一个整数，因此，块$C^{(1)}_1, \dots, C^{(1)}_k$可以重新着色，因为任意直线$L_x$要么与所有块相交，要么不与其中任何一个相交。

以同样的方式，证明了对于所有$s \leq i - 1$，对与$B$相隔距离$\alpha_s$的块$C^{(1)}_1, \dots, C^{(1)}_k$重新着色的可能性，可以得出对$C^{(1)}_1, \dots, C^{(1)}_k$重新着色的可能性。现在该陈述遵循数学归纳法原理：$C(L_x)$对于任何$x$都是整数。

所以，我们只剩下红色和黄色块了。如果现在线 $L_a$ 与直线的边重合，则 $a$ 是一个整数。如果没有，那么

$$b = JK(L_a + \varepsilon), [a] + \varepsilon < a,$$

由于 $JK(L_x)$ 是整数，因此 $b$ 是整数。

该说法已得到充分证明。

如果振荡的幅度很小（球的速度的初始分量，垂直于铁的母线并与其表面相切，很小），则球的振荡是谐波的，并且它们的周期不依赖于幅度。在这种情况下，半个周期后，所有球都会在它们开始运动的铁的同一母线 $AA'$ 上相遇。

如果球的振动幅度很大，则振动将不是谐波，其周期将取决于幅度，并且球将在不同时间撞击母线$AA'$。这意味着球不会相遇。
