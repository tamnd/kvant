考虑四边形 $A_1A_2A_3A_6$ 和 $B_3B_4B_5B_6$（参见 图 2）。第一个四边形的对角线 $A_1A_3$ 与第二个四边形的对角线 $B_4B_6$ 和 $|A_1A_3| = 2|B_4B_6|$ 平行，因为对角线 $B_4B_6$ 是三角形 $A_1A_3A_5$ 的中线。同样，$A_2A_3$对角线平行于$B_3B_5$和$|A_2A_3| = 2|B_3B_5|$对角线，因为$B_3B_5$对角线是$A_2A_6A_4$三角形的中线。

由于凸四边形的面积等于对角线长度与对角线之间角度的正弦乘积的一半，因此我们发现四边形$B_3B_4B_5B_6$的面积比四边形$A_1A_2A_3A_6$的面积小四倍。同样，四边形$B_6B_1B_2B_3$（图中不存在）的面积比四边形$A_3A_4A_5A_6$的面积小四倍。所指示的四边形形成第一六边形和第二六边形之间的对应关系，因此我们要求证明该对应关系。

十年级，任务 2
让我们证明，对于正 $a, b$，с 不等式 $a^3 + b^3 + c^3 + 3abc \geq ab (a + b) + bc (b + c) + ac (a + c)$ 成立。
由于表达式$a^3 + b^3 + c^3 + 3abc$关于$a, b, c$对称，我们可以不失一般性地假设$a \geq b \geq c > 0$。书面表达式可以转换为以下形式：

$$(a - b)^2 (a + b - c) + c (c - a) (c - b).$$
根据假设$a \geq b \geq c > 0$，显然可以得出：

$$(a - b)^2 (a + b - c) \geq 0$$
和$c (c - a) (c - b) \geq 0$。

将这两个不等式相加，我们就得到了所需的不等式。

在第六届国际数学奥林匹克竞赛中提出了以下问题：

令 $a, b$ 和 $c$ 为某个三角形的一行长度。证明$a^2 (b + c - a) + b^2 (c + a - b) + c^2 (a + b - c) \leq 3 abc$。

很容易看出，这个不等式与刚刚分析的问题2的不等式一致，但是附加条件简化了解。

我们可以从评审团的作品集中为读者«Kvant»提供该任务的另一种观点；它应该在九年级的第二个类型中给出。由于 varnat 的过载，陪审团最后一刻排除了这个问题，而且还因为它可以使用反转方法轻松解决*：

在给定的圆弧段中，两个圆任意内切，在点 M 处相互接触。找到点集 M。
