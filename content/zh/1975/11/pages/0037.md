由于 $k$ 是整数，由 (5) 得出

$$k = \left[ \frac{n-1}{\lg 9 + 1} + 1 \right],$$

其中$[x]$是数字$x$的整数部分。

I. N. 克鲁莫娃、A. G. 莱德曼

a) 计算连续自然数的平方和$2n+1$。用 $x-n$ 表示其中最小的一个，我们得到：

$$S_{2n+1} = (x-n)^2 + (x-n+1)^2 + \dots + x^2 + (x+1)^2 + \dots + (x+n)^2 = (2n+1)x^2 + 2(1^2 + 2^2 + 3^2 + \dots + n^2) = (2n+1)x^2 + \frac{1}{3}n(n+1)(2n+1).$$

具体来说，$S_3 = 3x^2 + 2$、$S_5 = 5x^2 + 10$、$S_7 = 7x^2 + 28$、$S_9 = 9x^2 + 60$、$S_{11} = 11x^2 + 110$。三个连续整数的平方和不可能是精确的平方，因为任何整数的平方要么能被3整除，要么被3除余1，而数字$S_3 = 3x^2 + 2$除以3余2。

让我们证明，对于任何整数 $x$，数字 $S_5$、$S_7$ 和 $S_9$ 都不是完全平方数。为此，我们将使用从唯一因式分解得出的这个明显的性质：如果一个正方形可以被素数$p$整除，那么它必须可以被$p^2$整除。需要注意的是，$x^2 + 2$不能被5整除，$x^2 + 4$不能被7整除，$3x^2 + 20$不能被3整除。

6) 这些是数字 18, 19, ..., 27, 28。事实上，数字 $S_{11} = 11(x^2 + 10)$ 必须能被 $11^2$ 整除，因此，数字 $x^2 - 1 = (x^2 + 10) - 11$ 必须能被 11 整除。但是既然 $x^2 - 1 = (x - 1)(x + 1)$，那么$x - 1 = 11l$ 或 $x + 1 = 11k$ 。对于$l = 2$，我们得到$x = 23$，$S_{11} = 77^2$，所以

$$x - n = 23 - 5 = 18$$

和

$$18^2 + 19^2 + 20^2 + \dots + 28^2 = 77^2.$$
