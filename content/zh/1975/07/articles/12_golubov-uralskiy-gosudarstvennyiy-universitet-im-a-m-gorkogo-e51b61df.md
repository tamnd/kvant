状态

他们。高尔基

在«Kvant»，1973年第7期，我们已经谈到了以乌拉尔红旗勋章命名的劳动州立大学。 A.M.高尔基。在本期中，我们提供了 1974 年数学、力学和物理学院数学笔试的选项样本以及物理口试的门票。

数学
数学与力学学院
选项1

1. 是否存在参数$a$的值可以解决不等式
$$\sqrt{x^2 + 4x + 3} \geq -1 - x$$
是方程的一个解
$$|x - a| - |x + 1| = 2$$
相反，方程的每个解都是不等式的解？

2. 线 $l_1$ 和 $l_2$ 相交于三角形 $ABC$ 的顶点 $B$。构造一个三角形$ABC$，除了这些线之外，如果顶点$A$的位置位于平面上，并且已知三角形的中线位于$l_1$，高位于$l_2$。

3. 解决不平等问题
$$\frac{1}{\log x^2 \left( \frac{1}{3} + \frac{1}{6} x - x^2 \right)} \leq \log_x x^2.$$
4. 已知$\alpha = \beta + \gamma$。证明$\sin^2 \alpha + \sin^2 \beta + \sin^2 \gamma + 2 \cos \alpha \cos \beta \cos \gamma = 2$。

选项2

1. 不等式的每个解是否存在参数$a$的值
$$\sqrt{x^2 + 4x + 7} \leq x + 3$$
是方程的一个解
$$2^{x+2} - |2^{x+1} - a| = 2^{x+1} + 1$$
反过来，方程的每个解都是不等式的解吗？

2. 平面上有三点，其中两点是三角形边的中点，第三点是中线的交点。三角形的其余元素被擦除。使用圆规和尺子重建三角形。

3. 解决不平等问题
$$|\log|x|(4 + 3x - x^2) - 1| \leq \frac{1}{2} \log \sqrt{x-1}(x-1).$$

4. 已知$\alpha, \beta, \gamma$是某个三角形的内角，$tg\alpha, tg\beta, tg\gamma$构成等差级数。证明
$$2\cos \beta = \cos(\alpha - \gamma).$$

$$\log_1 - x^2(x + 1)^4 \leq \log \sqrt{2x-1}|1 - 2x|.$$
