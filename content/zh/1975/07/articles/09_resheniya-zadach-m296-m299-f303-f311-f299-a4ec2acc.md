**M299.**\*) 对于什么n，可以将一个正n边形放在一张纸上并排成一条线，使得所有顶点都位于线上？ （线是彼此距离相等的平行直线。）

⟦column⟧

我们将此表转换称为“循环移位”：第一列移动到第二列，第二列移动到第三列。 。 。 ，最后，最后一个，第 n 个 - 代替第一个。让我们用$s_0$表示表格对角线上的数字总和（在图1上的红色单元格中），用$s_1$表示循环移位后落在对角线上的数字总和（在蓝色单元格中），用$s_2$表示再次重复循环移位时落在对角线上的数字总和（在黄色单元格中），通常用$s_k$表示是循环移位 k 次后落在对角线上的数字之和。显然，表中所有数字的总和等于

$$s = s_0 + s_1 + \ldots + s_{n-1},$$

因为如果你进行循环移位 0, 1, . 。 。 , n - 1 次，那么在此期间表中的每个数字将在对角线上恰好出现一次（如果执行 n 次，您将得到原始排列）。

根据条件，s 是非负的，因此，某些 $s_k$ 一定是非负的。执行循环移位 k 次后，我们获得了所需的列排列。

**F304.** *泵通过直径为 $d$ 的管道每小时将质量 $m$ 的水输送到$H$ 的高度。泵$N$的功率应该是多少？使用较低功率的泵是否可以每小时将 $m$ 的水供应到 $H$ 的高度？*

⟦figure⟧
图 4.

⟦column⟧

在时间$\Delta t$期间，泵将质量$m\Delta t$的水输送到高度$H$，做功$A$等于水的机械能的变化。由于下面的水没有动能，泵以一定的速度$v$“驱动”它通过管道，那么

$$A = \frac{(m\Delta t)v^2}{2} + (m\Delta t)gH.$$

因此，泵浦功率为$N = \dfrac{mv^2}{2} + mgH$。

我们来求速度$v$。在时间$\Delta t$期间，体积$V = v\Delta t\dfrac{\pi d^2}{4}$穿过面积为$S = \dfrac{\pi d^2}{4}$的管道横截面，其质量等于$v\Delta t\dfrac{\pi d^2}{4}\rho$（$\rho$是水的密度）。另一方面，该质量等于 $m\Delta t$，即 $v\dfrac{\pi d^2}{4}\rho = m$，因此为 $v = \dfrac{4m}{\pi d^2\rho}$。

因此，泵浦功率

$$N = \frac{8m^3}{\pi^2 d^4\rho^2} + mgH.$$

使用较低功率的泵是否可以每小时将相同质量的水供应到相同的高度$H$？从$N$的表达式可以清楚地看出，$d$的管道直径越大，所需的泵功率越小。

但是您可以减少所需的电量，而无需更改问题陈述中指定的参数值。让我们在一定高度$h \ll H$处切断管道的整个上部。让水从管道的其余部分流出

⟦folio 44⟧

以一定速度$u$（参见图4）。

为此所需的泵浦功率为$N' = \frac{mu^2}{2}$（由于$h \ll H$，势能$mgh$被忽略）。为了使水上升到$H$的高度，离开管道时的速度必须不小于$u = \sqrt{2gH}$。因此，使用具有功率的泵可以将每小时$m$的水量供应到$H$的高度

$$N' = m \frac{u^2}{2} = mgH < N.$$

F305。将半径为 $r$ 的 L 形玻璃毛细管完全用水 (图 5) 润湿，放入盛有水的容器中。水的表面负荷系数对温度的依赖性如图 6 所示。如果$r=0,1$ mm、$h=14,1$ cm $uH=15$ cm，在什么温度范围内所有的水都会从容器中除去？忽略玻璃的厚度。

为了使水通过毛细管流出容器，它必须首先沿着毛细管的右弯头上升到其水平部分。在最初的时刻，上升的高度应等于$h$，最后，当几乎所有的水都已流出容器时，液体应上升到$h+l$的高度，其中$l$是容器中初始水位的高度。如果表面张力系数$\sigma$使得半径为$r$的毛细管中的水上升高度不小于$h+l$，即

$$\frac{2\sigma}{\rho gr} > h+l,$$ 或 $\sigma > \frac{1}{2} \rho gr (h+l).$

右膝上升后，水充满左膝，左膝末端形成凸出的半月板，可以容纳一定的水柱。毛细管上部的水（从其水平部分到容器中的水位）处于平衡状态，因此弯液面下方的附加压力必须保持初始时刻高度为$H+l$、最终时刻高度为$H$的水柱。弯月面的半径不能小于毛细管的半径$r$，这意味着弯月面下方的附加压力不能大于$\frac{2\sigma}{r}$。因此，如果水增长压力大于附加压力，水就会从毛细管中流出，即

$$\rho g (H+l) > \frac{2\sigma}{r},$$ 或 $\sigma < \frac{1}{2} \rho gr (H+l).$

因此，水将通过毛细管流出容器，如果

$$\frac{1}{2} \rho gr (h+l) < \sigma < \frac{1}{2} \rho gr (H+l),$$

或者

$$\frac{1}{2} \rho gr h < \sigma < \frac{1}{2} \rho gr H.$$

为了从表面张力系数值范围转移到温度范围，我们使用图 6所示的图表。从图中可以清楚地看出，$\sigma$对$T$的依赖关系是线性的，即

$$\sigma = \sigma_0 + \alpha T,$$

其中$\sigma_0 = 76 \text{ дин/cм}$。因此，在温度 $T=20^{\circ}\text{C}$ $\sigma = 73 \text{ дин/cм}$ 时，

让我们表示为 $I_0$ 负载电流 $R_{\mathrm{н}}$，并与其连接电流 $I_1$ 和 $I_2$，按截面流动 $CB$ 和 $AC$。我们重新画一下连接瓦特表的电气图，如图 图 8.由于导线的电阻远小于电阻 $r$，我们假设截面的电阻 $AC$ 和 $CB$ 该电线的长度包含在值中 $r$，所以电路部分的电阻 $DC$ 和 $KC$ 平等的 $r$.

由于$KC$部分电阻$R_{\mathrm{н}}$和电阻$r$处的电压相等，则

$$I_0 R_{\mathrm{н}} = I_1 r, \quad \text{или} \quad I_1 = I_0 \frac{R_{\mathrm{н}}}{r}.$$

电流$I_2 = \dfrac{U_{DC}}{r}$，其中$U_{DC}$为$DC$部分的电压。它等于 $U_{DC} = U_{KC} + I_3 r_1$，其中 $U_{KC} = I_0 R_{\mathrm{н}}$，并且

$$I_3 = I_0 + I_1 = I_0\left(1 + \frac{R_{\mathrm{н}}}{r}\right).$$

然后

$$I_2 = I_0\left(\frac{R_{\mathrm{н}} r_1}{r^2} + \frac{r_1}{r} + \frac{R_{\mathrm{н}}}{r}\right).$$

现在让我们看看电线的伸长与流过该电线的电流有何关系。在热平衡时，导线中释放的热量等于给予介质的热量：
$$I^2 R = k\Delta t,$$
其中$\Delta t$为导线与介质之间的温差，$R$为一半导线的电阻，$k$为比例系数。另一方面，导线长度的增加则按规律发生
$$l = l_0(1 + \alpha\Delta t),$$
其中$\alpha$是导线的热膨胀系数。由最后两个等式

$$\Delta l = l_0\alpha\Delta t = \frac{I^2 R}{k} l_0 \alpha = k_1 I^2$$

$\left(k_1 = l_0 \alpha \frac{R}{k}\right)$，即接线的延伸量与电流强度的平方成正比。这意味着布线第 $CB$ 部分的延长线为 $\Delta l_1 \sim I_1^2$，布线第 $AC$ 部分的延长线为 $\Delta l_2 \sim I_2^2$。

$$I_2^2 - I_1^2 = I_0^2 \left( \frac{r_1^2}{r^2} + \frac{r_1^2}{r^2} \frac{R_H^2}{r^2} + 2 \frac{r_1^2}{r^2} \frac{R_H}{r} + 2 \frac{r_1}{r} \frac{R_H^2}{r^2} + 2 \frac{R_H}{r} \frac{r_1}{r} \right).$$

$$I_2^2 - I_1^2 = 2 I_0^2 R_H \frac{r_1}{r^2} = 2 \frac{r_1}{r^2} P,$$

即差值$I_2^2 - I_1^2$与负载释放的功率成正比。因此，接线部分的长度差异以及相应的装置箭头的旋转角度与负载消耗的电流功率成正比。

F308。流量计是一张上面有油污的纸。该片材放置在两个肾光源之间。必须确定一个光源的发光强度$I_1 = 20$ sv，另一光源的发光强度$I_2$。为此，首先选择距蒙版片材的距离 $l_1$ 和 $l_2$ 源，以便从第一个源的侧面观看时，泡沫不会在纸张背景上突出。原来LOB是$l_2 = 2l_1$。然后选择距离 $l_1$ 和 $l_2$ 掩模，以便从第二个源的侧面观看时，泡沫不会在纸张背景上突出。原来LOB是$l_1' = l_2' = l$。确定第二个光源的发光强度。

Podd 与 Kazka。纸张的每个部分都可以通过其透射率和光反射率来表征。

如果光通量$\Phi_\pi$和$\Phi_6$（对应于斑点和干净纸的面积单位以及与眼睛观察到的接触）相同，则污渍不会在纸张背景下突出。纸张和纸张漫反射和透射落在其上的光，即均匀地向各个方向传播。因此，光通量$\Phi_\pi$和$\Phi_6$分别与纸张的照度$E_\pi$和纸张的照度$E_6$成正比是非常重要的。

如果从第一个光源的侧面观察该光斑，则该光斑的照度是来自第一个光源并穿过该光斑$-E_2 = \alpha_\pi \frac{I_2}{l_2^2}$的光线的照度之和（$\alpha_\pi$是该光斑的透射系数）：

$$E_\pi = E_1 + E_2 = r_\pi \frac{I_1}{l_1^2} + \alpha_\pi \frac{I_2}{l_2^2}.$$

同样，如果纸张清晰区域的光反射系数为$r_6$，而这些区域的透射系数为$\alpha_6$，则纸张干净区域的照度等于

$$E_6 = r_6 \frac{I_1}{l_1^2} + \alpha_6 \frac{I_2}{l_2^2}.$$

将 $E_\pi$ 和 $E_6$ 等式，我们得到方程

$$r_\pi \frac{I_1}{l_1^2} + \alpha_\pi \frac{I_2}{l_2^2} = r_6 \frac{I_1}{l_1^2} + \alpha_6 \frac{I_2}{l_2^2},$$

或者，鉴于 $l_2 = 2l_1$，

$$4r_\pi I_1 + \alpha_\pi I_2 = 4r_6 I_1 + \alpha_6 I_2.$$

同理，我们可以得到第二种情况下，从第二个光源一侧观察纸张时，纸张和干净纸张的光照条件：

$$\alpha_\pi \frac{I_1}{l_1^2} + r_\pi \frac{I_2}{l_2^2} = \alpha_6 \frac{I_1}{l_1^2} + r_6 \frac{I_2}{l_2^2}.$$

由于在这种情况下$l'_1 = l'_2$，那么

$$\alpha_\pi I_1 + r_\pi I_2 = \alpha_6 I_1 + r_6 I_2.$$

两个方程（2）和（4）包含五个未知数；不可能确定所有这些。然而，可以找到其中之一，即$I_2$。为此，我们将等式 (2) 中包含 $I_1$ 的项相交到等式左侧，将包含 $I_2$ 的项相交到等式右侧。我们得到

$$4I_1(r_\pi - r_6) = I_2(\alpha_6 - \alpha_\pi).$$

让我们从等式（4）中类似地构造：

$$I_1(\alpha_6 - \alpha_\pi) = I_2(r_\pi - r_6).$$

现在从方程（5）确定关系$\frac{\alpha_6 - \alpha_\pi}{r_\pi - r_6}$并将其代入方程（6），我们得到

$$\frac{4I_1}{I_2} = \frac{I_2}{I_1},$$ 或 $I_2 = 2I_1 = 40$ 圣。

F310。弹簧的末端是固定的。如何在不释放弹簧末端的情况下使其变形，以便弹簧在处理后趋于 a) 缩短？

我们首先考虑一个松动的弹簧，让我们对其进行变形，即拉伸或压缩它。定量地，变形可以用绝对变形$\Delta l = |l - l_0|$的大小（$l_0$是弹簧未变形状态下的长度）或相对变形$\frac{\Delta l}{l_0}$的值来表征。外力停止作用后弹簧会发生什么变化？事实证明，可能有两种情况：要么变形完全消失（弹簧恢复其长度），要么部分保留，即残余变形结果（弹簧的长度未恢复）。在第一种情况下，变形称为弹性变形，在第二种情况下称为塑性变形。什么决定了变形是弹性变形还是塑性变形？经验表明，变形的性质首先取决于变形本身的大小（以及弹簧的材料和该材料的状态 - 其温度、先前的加工等）。在较小的相对变形下，弹簧是弹性的，也就是说，在其端部释放后，它完全恢复其形状和尺寸。如果相对变形较大，则弹簧会发生塑性变形并产生残余变形。如果弹簧被拉伸，弹簧的长度将大于$l_0$，如果被掠过，则弹簧的长度将小于$l_0$。让我们利用弹簧的这些特性来解决这个问题。

⟦folio 50⟧

让我们将弹簧固定在两端的线圈上，该线圈距离弹簧的一端比另一端更近，然后将该线圈移动到弹簧的远端。然而，弹簧的一部分被拉伸，而另一部分被卷起。在这种情况下，它们的绝对变形$\Delta l$将相同，但它们的相对变形将不同。弹簧短部分的相对变形$\frac{\Delta l}{l_{01}}$将大于弹簧长部分的相对变形$\frac{\Delta l}{l_{02}}$：

$$\frac{\Delta l}{l_{01}} > \frac{\Delta l}{l_{02}}.$$

这意味着也可以匹配$\Delta l, l_{01}$和$l_{02}$，这样弹簧的长部分的变形仍然是弹性的，而短部分已经是塑性的。经过这样的“加工”后，长的部分（被卷起的）长度保持不变，而短的部分（被拉伸的）长度会增加。整个弹簧在未成形状态下的长度也会增加。因此，连接到端部的弹簧将趋于变长。

类似地，如果考虑将弹簧的一个线圈扭曲到弹簧的近端，并且还施加外力，使得弹簧的长（拉伸）部分的变形是弹性的，而短（倾斜）部分的变形是柔性的，那么加工后的弹簧将趋于缩短。

由于磁场随时间变化，电路中会出现电动势。感应$E$。电路中的感应电流等于

$$I = \frac{E}{R},$$

其中$R$是环路电阻。回路电阻$R = \rho \frac{l}{s}$。显然$m = dls$。从这里

$$s = \frac{m}{ld} \text{ и } R = \rho \frac{d}{m} l^2,$$

也就是说，环路电阻与环路长度的平方成正比。

电动势电路中激发的感应等于

$$E = \frac{\Delta \Phi}{\Delta t} = \frac{\Delta B}{\Delta t} S = kS,$$

其中 $S$ 是轮廓覆盖的面积。电动势$E$面积越大$S$。对于给定的轮廓长度，轮廓所覆盖的圆形区域具有最大的面积。因此，E.d.s.如果轮廓是圆形，则为最大值。让我们用 $r$ 表示这个圆的半径，然后

$$S = \pi r^2 \text{ и } E = k\pi r^2.$$

在这种情况下

$$l = 2\pi r \text{ и } R = \rho \frac{4\pi^2 r^2}{m}.$$
