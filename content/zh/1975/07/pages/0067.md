⟦folio 65⟧

平均速度约为10公里/小时。但这是否意味着它会立即“跳出”晶体呢？没有这样的事！空位随机地从一侧移动到另一侧，因此，尽管它在一秒钟内改变位置10^10次，但其移动量仅为10微米。 “拜托，这种大惊小怪是前所未有的，”亚指出。 E. Geguzin 关于这一点。原子的表现比空位更有能力，但它们每秒也会改变位置数百万次。

一个人可以影响原子和空位的运动，可以根据需要控制晶体中的扩散：将杂质引入晶体中，改变金属的强度，胶合和焊接金属和其他固体等。

 气体或液体中的扩散很容易看到：烟雾在空气中扩散，蓝莓在水中扩散——所有这些都是扩散过程。在固体中，扩散过程发生得更慢并且无法直接看到，就像一缕烟雾消失在空气中一样。雅的好处是。 E. Geguzin 的书的最大优点是，它让读者有机会看到、感觉到，并仿佛用手一样，用看不见的眼睛触摸固体中的扩散过程。作者描述了一些实验，其中固体中原子或空位的运动结果变得可见。这些实验有时令人惊讶：弯曲的晶体本身之所以能伸直，只是因为它被加热了；金属丝上的重物会飞起来；原子像风滚草一样沿着晶体表面滚动（一种平静的植物，被连根拔起，被风吹过草原）；一种物质铺展在另一种物质的表面上，就像铺开地毯一样；岩盐晶体表面的金粒相互“喂养”；在另一项实验中，金粒被扔到岩盐晶体的表面；晶体像液体一样流动，液体像玻璃一样易碎；可以说，在云母晶体中移动的铀原子记录了其路径，研究将根据该记录确定云母晶体的年龄。

作为雅。 E. Geguzin 写道：“这些被烧毁的东西绝对应该被看到。看到、感受并感到高兴。”作者对他的主题充满热情，以至于读者被这种探索和发现新事物的喜悦所感染。

作者并不试图对所描述的现象给出合理的描述。第一本书四年前出版。作者用新材料补充了第二版，添加了关于量子扩散的一章（不是书中最成功的一章），但这一次，最后一章强调了还有多少东西需要学习、看到和探索。

每个序列都是一个独立的故事，但它们都通过一个统一的主题联系在一起：扩散过程的物理本质、影响该过程的能力、晶体中扩散现象的丰富性。许多明亮、直观的类比、充实的图像和例子使这本书变得有趣和引人入胜。只是可惜书上的图并不总是像他们描述的那么清晰。

虽然作者规定他将这本书的主题限制在扩散上，但实际上它的内容更广泛：从这本书中你可以得到很多关于晶体结构、新的实验事实以及物理统计和动力学方法的信息。这本书写得明亮、生动、引人入胜；毫无疑问，它会给读者带来愉悦。

M.P.沙斯科尔斯卡娅

几何不等式

1. 让我们用 $m_a$、$m_b$、$m_c$ 表示绘制到三角形边 $a$、$b$、$c$ 的中线长度。证明

$$\frac{3}{8}(ab + bc + ca) \leq m_a m_b + m_c m_a \leq \frac{5}{4}(ab + bc + ca).$$

有一个未经证实的假设，即 3/8 的赔率可以用 9/20 代替。

2. 让我们用 $h_a$、$h_b$、$h_c$ 来表示绘制到三角形 ABC 边$a$、$b$、$c$ 的高度的长度。证明

$$\left( a^2 + b^2 - h_c^2 \right)^{\frac{1}{2}} + \left( b^2 + c^2 - h_a^2 \right)^{\frac{1}{2}} + \left( c^2 + a^2 - h_b^2 \right)^{\frac{1}{2}} \leq 6R,$$

 其中 $R$ 是 ABC 晶体外接圆的半径。

3. 让我们用 $w_a$、$w_b$、$w_c$ 表示绘制到三角形边 $a$、$b$、$c$ 的三边形的长度。证明

$$\frac{a}{w_b + w_c} + \frac{b}{w_c + w_a} + \frac{c}{w_a + w_b} \geq \sqrt{3},$$

$$\frac{w_a}{b + c} + \frac{w_b}{c + a} + \frac{w_c}{a + b} \leq \frac{3}{4} \sqrt{3}.$$

H. B.
