⟦folio 48⟧

F308。流量计是一张上面有油污的纸。该片材放置在两个肾光源之间。必须确定一个光源的发光强度$I_1 = 20$ sv，另一光源的发光强度$I_2$。为此，首先选择距蒙版片材的距离 $l_1$ 和 $l_2$ 源，以便从第一个源的侧面观看时，泡沫不会在纸张背景上突出。原来LOB是$l_2 = 2l_1$。然后选择距离 $l_1$ 和 $l_2$ 掩模，以便从第二个源的侧面观看时，泡沫不会在纸张背景上突出。原来LOB是$l_1' = l_2' = l$。确定第二个光源的发光强度。

该片材垂直于连接源的线放置。

Podd 与 Kazka。纸张的每个部分都可以通过其透射率和光反射率来表征。

如果光通量$\Phi_\pi$和$\Phi_6$（对应于斑点和干净纸的面积单位以及与眼睛观察到的接触）相同，则污渍不会在纸张背景下突出。纸张和纸张漫反射和透射落在其上的光，即均匀地向各个方向传播。因此，光通量$\Phi_\pi$和$\Phi_6$分别与纸张的照度$E_\pi$和纸张的照度$E_6$成正比是非常重要的。

如果从第一个光源的侧面观察该光斑，则该光斑的照度是来自第一个光源并穿过该光斑$-E_2 = \alpha_\pi \frac{I_2}{l_2^2}$的光线的照度之和（$\alpha_\pi$是该光斑的透射系数）：

$$E_\pi = E_1 + E_2 = r_\pi \frac{I_1}{l_1^2} + \alpha_\pi \frac{I_2}{l_2^2}.$$

同样，如果纸张清晰区域的光反射系数为$r_6$，而这些区域的透射系数为$\alpha_6$，则纸张干净区域的照度等于

$$E_6 = r_6 \frac{I_1}{l_1^2} + \alpha_6 \frac{I_2}{l_2^2}.$$

将 $E_\pi$ 和 $E_6$ 等式，我们得到方程

$$r_\pi \frac{I_1}{l_1^2} + \alpha_\pi \frac{I_2}{l_2^2} = r_6 \frac{I_1}{l_1^2} + \alpha_6 \frac{I_2}{l_2^2},$$

或者，鉴于 $l_2 = 2l_1$，

$$4r_\pi I_1 + \alpha_\pi I_2 = 4r_6 I_1 + \alpha_6 I_2.$$

同理，我们可以得到第二种情况下，从第二个光源一侧观察纸张时，纸张和干净纸张的光照条件：

$$\alpha_\pi \frac{I_1}{l_1^2} + r_\pi \frac{I_2}{l_2^2} = \alpha_6 \frac{I_1}{l_1^2} + r_6 \frac{I_2}{l_2^2}.$$

由于在这种情况下$l'_1 = l'_2$，那么

$$\alpha_\pi I_1 + r_\pi I_2 = \alpha_6 I_1 + r_6 I_2.$$

两个方程（2）和（4）包含五个未知数；不可能确定所有这些。然而，可以找到其中之一，即$I_2$。为此，我们将等式 (2) 中包含 $I_1$ 的项相交到等式左侧，将包含 $I_2$ 的项相交到等式右侧。我们得到

$$4I_1(r_\pi - r_6) = I_2(\alpha_6 - \alpha_\pi).$$

让我们从等式（4）中类似地构造：

$$I_1(\alpha_6 - \alpha_\pi) = I_2(r_\pi - r_6).$$

现在从方程（5）确定关系$\frac{\alpha_6 - \alpha_\pi}{r_\pi - r_6}$并将其代入方程（6），我们得到

$$\frac{4I_1}{I_2} = \frac{I_2}{I_1},$$ 或 $I_2 = 2I_1 = 40$ 圣。
