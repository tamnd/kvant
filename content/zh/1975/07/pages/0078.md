现在我们需要找出$T$系统

$$\begin{cases} \frac{25}{x} + \frac{6}{2-x} = T - 24, \\ 2 > x > 0, \\ T > \frac{39}{x}, \\ T > \frac{39}{2-x} \end{cases}$$

有一个解决方案。我们首先求$x$值的可能性。考虑到第一个方程，不等式 $T > \frac{39}{x}$ 等价于不等式

$$\frac{25}{x} + \frac{6}{2-x} > \frac{39}{x} - 24$$

考虑到关系 $0 < x < 2$ 我们得出不等式

$$6x^2 - 17x + 7 < 0,$$

从哪里$\frac{1}{2} < x < \frac{7}{3}$。但既然$x < 2$，那么$\frac{1}{2} < x < 2$。

类似地，条件$T > \frac{39}{2-x}$等价于不等式

$$12x^2 + 5x - 25 < 0,$$

从哪里$-\frac{5}{3} < x < \frac{5}{4}$。但既然$x > 0$，那么$0 < x < \frac{5}{4}$。

比较(2)和(3)，我们得到

$$\frac{1}{2} < x < \frac{5}{4}$$

相反，如果$x$满足(4)，那么通过取$T = \frac{25}{x} + \frac{6}{2-x} + 24$我们满足系统(1)。剩下的就是找到函数的取值范围

$$T = f(x) = \frac{25}{x} + \frac{6}{2-x} + 24,$$

如果$\frac{1}{2} < x < \frac{5}{4}$。

让我们证明在这个区间 $f(x)$ 是多音杀死的。真的吗，

$$f(x_1) - f(x_2) = -\frac{x_1 - x_2}{x_1x_2(2 - x_1)(2 - x_2)} \left[ 19x_1x_2 - 50(x_1 + x_2) + 100 \right].$$

检查方括号中的表达式是否为正就足够了。确实是平等的

$$19 \left(\frac{50}{19} - x_1\right) \left(\frac{50}{19} - x_2\right) - \frac{600}{19} > 19 \left(\frac{50}{19} - \frac{5}{4}\right)^2 - \frac{600}{19} > 0.$$

这意味着$f(x)$从$T_{\min} = f\left(\frac{5}{4}\right) = 52$变为$T_{\max} = f\left(\frac{1}{2}\right) = 78$。
