⟦folio 62⟧

建筑、建筑、大地测量、工程经济、化学技术、技术组织物质。在所有院系，学生都接受工程、技术和工程经济课程范围内的物理和数学培训。

自动化学院培养具有“工程师数学家”资格的应用数学专业。在该专业学生学习的50个学科中，一半以上是数学计算机编程、数理逻辑、数值方法和算法、线性代数和解析几何、一般代数、数学分析、微分方程、图论和组合、泛函分析、数学物理方程、随机过程、概率论和数理统计等等。

该专业的毕业生被派往设计局、计算机中心和研究所工作。

以下是 1974 年利沃夫理工学院数学和物理笔试选项的示例。

**数学**

**选项 1**

1. 三角形ABC，其中顶点A的角度为α，顶点B的角度为β，由等于c的向量AB表示。求旋转体的体积。

2. 三个数字构成一个几何级数。如果第二个数字增加 2，则级数变为等差级数，如果之后最后一个数字增加 9，则级数再次变为等比级数。找到这些数字。

3. 求解方程$\cos^2 x - (\sin 35^\circ + \cos 35^\circ) \cos x + \frac{1}{2} \sin 70^\circ = 0$。

4. 求解方程$\log_2 x - \log_4 x = \log_2 x + 16$。

**选项2**

1. 示例底为梯形，其上底和边相等，下底等于α，型角等于α。所有侧肋均与底座平面形成角度β。查找体积示例。

2. 摩托艇往返两点全程60公里，全程6小时15分钟不停歇。如果船自身速度为 20 公里/小时，求河水流速。

3. 求解方程$\cos 2x \cos x = \cos 5x \cos 4x$。

4. 解决不等式$\lg \frac{x+1}{2x-3} \geq 0$。

**选项 3**

1. 示例的底边是直角三角形，其中一个锐角等于α，内切圆的半径等于r。每个侧面与基底平面形成角度α。查找体积示例。

2. 在 3.5 小时的工作时间内，一台模压机可以生产所有订购零件的 42%。第二台压力机可以在 9 小时的工作时间内生产出所有零件的 60%，第三台压力机的工作速度与第二台压力机的工作速度相关，为 6:5。如果三台印刷机同时工作，需要多长时间才能完成整个订单？

3. 求解方程$-\sin^2 x + \cos^2 x = \cos \frac{x}{2}$。

4. 解决不等式$\frac{1}{5 - \lg x} + \frac{2}{1 + \lg x} < 1$。

**物理**

**选项 1**

1. 比汽化热。

2. 电容量。球体的电容量。电容器。

3. 杂耍者将球垂直向上扔出。当球到达其路径的顶部时，第二个球以相同的初始速度被抛出。如果投掷高度 H=4.9 m，球在 h 处相遇的高度是多少？

4. 如果在距玻璃板顶面 h = 5 cm 的距离处观察玻璃板底侧用墨水标记的点，则该玻璃板的厚度 H 是多少？视线垂直于板的表面。堆栈猜测得分 n=1.6。对于小角度 tan α≈sin α≈α。

**选项2**

1. 物体自由落体。物体自由落体的加速度。

2. 布朗运动。

3. 一个带有电荷 q₀=10 个单位的小球通过电容器的内部驱动板悬挂在细丝线上，悬浮在空气中。 SGSE 收费。为了使球以角度 α=45° 偏离垂直方向，电容器板必须传递多少电荷？球的质量为m=4 g，每个电容器极板的面积为S=314 cm²。
