F309。蛇半爬进平面上固定的窄管中。蛇的接缝部分沿着平面任意蠕动。考虑到蛇是一条细长、均匀的线，长度为$l$，找出整条蛇的柔软中心可能在哪个区域。

图 13.

管道中蛇的一半的重心位于距管道边缘 $\frac{l}{4}$ 的位置。它的坐标$(x_1, y_1)$是(图13)

$$x_1 = -\frac{l}{4} \text{ и } y_1 = 0.$$

沿着平面任意蠕动的蛇的后半部分的重心可以位于以原点为圆心、半径$\frac{l}{4}$的圆内的任意一点，即其坐标$(x_2, y_2)$满足不等式

$$x_2^2 + y_2^2 \leq \left(\frac{l}{4}\right)^2.$$

由于蛇两部分的质量相同，所以整条蛇的重心坐标由以下关系确定：

$$x_\mu = \frac{x_1 + x_2}{2} = \frac{x_2}{2} - \frac{l}{8}, \quad y_\mu = \frac{y_1 + y_2}{2} = \frac{y_2}{2}.$$

根据这些等式，我们用 $x_\mu$ 和 $y_\mu$ 来表达 $x_2$ 和 $y_2$：

$$x_2 = 2x_\mu + \frac{l}{4}, \quad y_2 = 2y_\mu.$$

将这些值代入不等式（*），我们得到

$$\left(2x_\mu + \frac{l}{4}\right)^2 + 4y_\mu^2 \leq \left(\frac{l}{4}\right)^2, \quad \text{или} \quad \left(x_\mu + \frac{l}{8}\right)^2 + y_\mu^2 \leq \left(\frac{l}{8}\right)^2.$$

这意味着整条蛇的重心可以位于半径为$\frac{l}{8}$、坐标为$x = -\frac{l}{8}$和$y = 0$的圆内的任意点（在图13处，该圆受到保护）。

F310。弹簧的末端是固定的。如何在不释放弹簧末端的情况下使其变形，以便弹簧在处理后趋于 a) 缩短？

我们首先考虑一个松动的弹簧，让我们对其进行变形，即拉伸或压缩它。定量地，变形可以用绝对变形$\Delta l = |l - l_0|$的大小（$l_0$是弹簧未变形状态下的长度）或相对变形$\frac{\Delta l}{l_0}$的值来表征。外力停止作用后弹簧会发生什么变化？事实证明，可能有两种情况：要么变形完全消失（弹簧恢复其长度），要么部分保留，即残余变形结果（弹簧的长度未恢复）。在第一种情况下，变形称为弹性变形，在第二种情况下称为塑性变形。什么决定了变形是弹性变形还是塑性变形？经验表明，变形的性质首先取决于变形本身的大小（以及弹簧的材料和该材料的状态 - 其温度、先前的加工等）。在较小的相对变形下，弹簧是弹性的，也就是说，在其端部释放后，它完全恢复其形状和尺寸。如果相对变形较大，则弹簧会发生塑性变形并产生残余变形。如果弹簧被拉伸，弹簧的长度将大于$l_0$，如果被掠过，则弹簧的长度将小于$l_0$。让我们利用弹簧的这些特性来解决这个问题。
