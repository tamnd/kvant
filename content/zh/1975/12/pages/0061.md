*retin*（25 分），*Sergey Finashin*（25 分）。

从两天的比赛结果来看，匈牙利队获得了最好的成绩，其次是东德队、美国队和苏联队。此外，只有匈牙利、东德和苏联这三个团队的所有参赛者都获得了奖项。

**第一天比赛的任务**

**1.** 令$x_i$、$y_i$和$(i = 1, 2, 3, \ldots, n)$为实数，使得$x_1 \geqslant \geqslant x_2 \geqslant \ldots \geqslant x_n$和$y_1 \geqslant y_2 \geqslant \ldots \geqslant y_n$。证明如果 $z_1$, $z_2$, ..., $z_n$ 是数字 $y_1$, $y_2$, ..., $y_n$ 的任意排列，则

$$\sum_{i=1}^{n} (x_i - y_i)^2 \leqslant \sum_{i=1}^{n} (x_i - z_i)^2$$

（捷克斯洛伐克，6分）。

**2.** 令 $a_1$、$a_2$、$a_3$、... 为任意无限正整数序列，使得 $a_k < < a_{k+1}$ $(1 \leqslant k)$。证明该序列的无数项$a_m$可以表示为$a_m = x a_p + y a_q$，其中$x$和$y$是正数，$p \neq q$（英国，7分）。

**3.** 在任意三角形 $ABC$ 的边上（在平面 $ABC$ 中），构造三角形 $BPC$、$CQA$ 和 $ARB$，使得

$$\widehat{PBC} = \widehat{CAQ} = 45°, \qquad \widehat{BCP} = \widehat{QCA} = 30°,$$
$$\widehat{ABR} = \widehat{BAR} = 15°.$$

证明$\widehat{QRP} = 90°$和$|QR| = = |RP|$（荷兰，7分）。

**第二天比赛的任务**

**4.** 令$A$为数字$4444^{4444}$的十进制数字之和，$B'$为数字$A$的数字之和（$A$和$B$也考虑为十进制）。求数字 $B$ 的各位数字之和（苏联，6 点）。

**5.** 是否可以在半径为1的圆上标记1975个点，使得连接其中任意两个点的弦长可以用有理数表示？ （苏联，6分）。

**6.** 查找具有以下属性的两个变量的所有多项式 $P$：

1) $P$是$n$次的齐次多项式，即对于所有实数$t$、$x$、$y$$P(tx, ty) = t^n P(x, y)$；

2) 对于所有真实的$a$，$b$，$c$
$$P(a + b, c) + P(b + c, a) + \\ + P(c + a, b) = 0;$$

3) $P(1, 0) = 1$
（英国，8分）。

## 第八届物理奥林匹克竞赛

1975 年 7 月，第八届国际中学生物理奥林匹克竞赛在居斯特罗（东德）市举行。来自保加利亚、匈牙利、东德、波兰、罗马尼亚、苏联、捷克斯洛伐克、法国和德国的代表队参加了奥运会。

苏联队的成员都是学生——全联盟物理奥林匹克竞赛的获奖者，他们在训练营中表现出了最好的成绩：

Leonid Avdeev - 新西伯利亚第 165 寄宿学校物理和数学毕业生；

Vad i m Boru - 扎波罗热第 28 中学毕业生；
