问题解决方案

M318—M320; F328, F330—F332, F334

M318。在三角形 ABC 中绘制平分线 AD 和 CE。证明molco模量和系数之间的$|CE| \cdot |AB| = |AD| \cdot |BC|$至少是以下两个条件之一：1）$|AB| = |BC|$； 2）$\widehat{ABC} = 60^\circ$。

让我们介绍一下标准符号：$a$是边BC的长度，$c$是边AB的长度，$l_a$是角A的平分线的长度，$l_c$是角C的平分线的长度。我们用$\alpha$，$\beta$表示相应顶点处的角度值， $\gamma$。另外，我们用$\varphi_1$表示角度AEC的值，用$\varphi_2$（图1）表示角度ADC的值。从考虑的三角形 AEC 和 ADC 可以得出：

$$\alpha + \frac{\gamma}{2} + \varphi_1 = \pi,$$

$$\frac{\alpha}{2} + \gamma + \varphi_2 = \pi.$$

此外，由于$h_a = l_a \sin \varphi_2$和$h_c = l_c \sin \varphi_1$，我们可以用两种方式表示三角形ABC的面积：$S = \frac{1}{2} al_a \sin \varphi_2$和$S = \frac{1}{2} cl_c \sin \varphi_1$。从这里

$$al_a \sin \varphi_2 = cl_c \sin \varphi_1.$$

现在让我们从信件中证明

$$al_a = cl_c$$

至少满足问题中给出的条件之一。由(2)和(3)可知

$$\sin \varphi_2 = \sin \varphi_1.$$

在两种情况下，正弦可以相等（自 $0 < \varphi_i < \pi$ 起）：

$$\varphi_1 = \varphi_2,$$

$$\varphi_1 = \pi - \varphi_2.$$

如果满足(5)，则由(1)我们得到：

$$\alpha + \frac{\gamma}{2} + \varphi_1 = \pi,$$

$$\frac{\alpha}{2} + \gamma + \varphi_1 = \pi.$$

将一个对应减去另一个对应，我们发现$\alpha = \gamma$，即三角形ABC是等边的，$a = c$。

设满足(6)式，则由(1)式可得

$$\alpha + \frac{\gamma}{2} + \varphi_1 = \pi,$$

$$\frac{\alpha}{2} + \gamma + \pi - \varphi_1 = \pi.$$

添加这些对应关系，我们得到

$$\frac{3}{2} \alpha + \frac{3}{2} \gamma = \pi,$$
