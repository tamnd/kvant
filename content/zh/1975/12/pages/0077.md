Chenyayam $n$（或$\lambda$）对应于一个值$f$。

6) 在这种情况下$f(n_1) = f(n_2)$，即

$$\frac{n_1 r_1 r_2}{(n_1 - 1) [n_1 (r_2 - r_1) + d (n_1 - 1)]} = \frac{n_2 r_1 r_2}{(n_2 - 1) [n_2 (r_2 - r_1) + d (n_2 - 1)]}$$

或者

$$r_1 - r_2 = d \left( 1 - \frac{1}{n_1 n_2} \right).$$

从物理角度考虑$n_1 > 1, n_2 > 1$和$d > 0$，因此$0 < r_1 - r_2 < d$。

1) $r_1 > 0, r_2 > 0$，而$0 < r_1 - r_2 < d$；
2) $r_1 > 0, r_2 < 0$，而$|r_1| + |r_2| < d$；
3) $r_1 < 0, r_2 < 0$，而$0 < |r_2| - |r_1| < d$。

c) 对于平凸透镜，其中一个曲率半径无限大，例如$r_1 \to \infty$。那么$f = \frac{r_2}{1 - n}$，即一个值$n$对应一个值$f$。

d) $f$ 的表达式可以重写为：$A n^2 + B n + C = 0$，其中$A = f(r_2 - r_1 + d), B = -[f(r_2 - r_1) + 2fd + r_1 r_2], C = fd$。该二次方程在下列情况下只能有一个解： 1) $A = 0$ 和 $n = -\frac{C}{B} > 1$，即

$$r_1 - r_2 = d \text{ и } \frac{fd}{fd + r_1 r_2} > 1;$$

2) $B^2 = 4AC$ 和 $n = -\frac{B}{2A} > 1$，即

$$[f(r_2 - r_1) + r_1 r_2]^2 + 4fd r_1 r_2 = 0$$

和

$$\frac{f(r_2 - r_1) + 2fd + r_1 r_2}{2f(r_2 - r_1 + d)} > 1;$$

3) $B = 0$ 和 $n^2 = -\frac{C}{A} > 1$，即

$$f(r_2 - r_1) + 2fd + r_1 r_2 = 0 \text{ и } -\frac{d}{r_2 - r_1 + d} > 1.$$
