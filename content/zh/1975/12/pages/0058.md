⟦folio 56⟧

一种几何不等式

今年的«Kvant»第7号（第65页）中表达了以下句子：

$$\frac{9}{20} (ab + bc + ca) \leq m_a m_b + m_b m_c + m_c m_a,$$

其中$a, b, c, m_a, m_b, m_c$是任意三角形的边长和相应的中线。

以下是该陈述的“几何”证明*）。

引理 1. $m_a + m_b + m_c < a + b + c$。

引理 2. $a^2 + b^2 + c^2 < 2(ab + ac + bc)$。

引理 3. $m_a^2 + m_b^2 + m_c^2 = \frac{3}{4} (a^2 + b^2 + c^2)$。

自己证明这些引理。

引理 4. $m_a m_b + m_b m_c + m_a m_c \leq \frac{5}{4} (ab + bc + ac)$。

自己证明这个引理。

根据引理1，$(m_a + m_b + m_c)^2 < (a + b + c)^2$，即$m_a^2 + m_b^2 + m_c^2 + 2m_a m_b + 2m_b m_c + 2m_a m_c < (a^2 + b^2 + c^2) + 2ab + 2bc + 2ac$。

*) 当编辑收到一封来自萨法尔尼科沃镇（捷克斯洛伐克）的彼得·塔克奇（Peter Takch）的来信，其中包含纯代数证明时，该问题已经发送到印刷厂。

由此，根据引理 3 和 2：

$$2m_a m_b + 2m_b m_c + 2m_a m_c < \frac{5}{4} (a^2 + b^2 + c^2), \quad \leq \frac{5}{2} (ab + bc + ac),$$

Q.E.D.

引理 5. 如果我们在边长为 $\frac{1}{3} m_a, \frac{1}{3} m_b$ 和 $\frac{1}{3} m_c$ 的三角形中构造中线，那么它们的长度将等于 $\frac{1}{4} a$、$\frac{1}{4} b$ 和 $\frac{1}{4} c$。

证明。令$G$为三角形$ABC, AM, BK$的离心力，$CP$为中线，$R$为线段$BG$的中点。

根据构造，$|RG| = \frac{1}{3} m_b, |PG| = \frac{1}{3} m_c$和$PR$是三角形$ABG$的中线，$|PR| = \frac{1}{2} |AG| = \frac{1}{3} m_a$由此而来。因此，三角形 $PRG$ 就是所需的三角形。让我们在其中画出中位数$PQ$。它是三角形$ABK$的中线，因此是$|PQ| = \frac{1}{2} |AK| = \frac{1}{4} a$。

引理的陈述已被证明。

现在将引理 4 应用于三角形 $PRG$，我们得到所需的不等式。

A·雷兹尼科夫
