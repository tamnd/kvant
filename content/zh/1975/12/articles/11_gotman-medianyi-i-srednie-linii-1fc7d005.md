三角形的中线

问题1. 在三角形ABC 中，绘制中线CM。证明

a) 如果$|CM| > \frac{1}{2}|AB|$，则$\hat{C} < 90^\circ$；

b) 如果$|CM| = \frac{1}{2}|AB|$，则$\hat{C} = 90^\circ$；

c) 如果$|CM| < \frac{1}{2}|AB|$，则$\hat{C} > 90^\circ$。

让我们表示 $A\hat{CM} = \alpha$，$B\hat{CM} = \beta$ (图 1)。

a) $|CM| > |AM|$ 和 $|CM| > |BM|$。考虑三角形 $ACM$ 和 $BCM$。由于在三角形中，较大的边与较大的边相对，因此$\hat{A} > \alpha$，$\hat{B} > \beta$。将这些等式逐项相加，我们得到 $\hat{A} + \hat{B} > \hat{C}$。由此得出$\hat{A} + \hat{B} + \hat{C} > \hat{C} + \hat{C} = 2\hat{C}$，并且从$\hat{A} + \hat{B} + \hat{C} = 180^\circ$开始，$\hat{C} < 90^\circ$。

问题2. 三角形ABC 的中线CM 由对应于角α 和β 的边AC 和BC 形成。如果|AC|，这些角度中哪一个更大< |BC|？

让我们表示 |BC| = a,|AC| = b，则根据条件 a > b。

让我们看看解决这个问题的两种方法。

第一种方式。让我们构造点 D，相对于边 AB 的中间 M 与点 C 对称，并将点 D 连接到顶点 A (图 2)。构造的三角形 ADM 与三角形 BCM 关于点 M 对称，因此，|AD| = |BC| = a 且 ADM = BCM = β。我们得到了一个三角形ACD，它包含角α和β的交集，对边AD和AC等于a和b的对应关系。根据条件a>b，因此α>β。

第二种方式。用第一种方式解决问题2时，我们构造了一个三角形$ADM$，一个相对于边$AB$的中间$M$对称的三角形$BCM$。要解决问题 4，您可以使用相同的技术。构造一个四边形 $AMN_1C_1$，一个相对于点 $M$ (图 4) 对称的四边形 $BMNC$。让$|AD| = a$，$|BC| = b$，$|MN| = m$，然后$|AC_1| = b$，$|DC_1| = |NN_1| = 2m$。如果$(AD) \parallel (BC)$，则$a + b > 2m$；如果$(AD) \parallel (BC)$，则$a + b = 2m$。

第三种方式。从点 $M$ 和 $N$ (图 5) 连接四边形之一对角线的中点 $E$。然后，与使用第二种方法解决问题 2 一样，我们得到一个边长分别为 $a/2$、$b/2$ 和 $m$ 的三角形 $EMN$。因此，$m < (a + b)/2$。在特殊情况下，当$(AD) \parallel (BC)$时，三角形$EMN$退化，点$E$将属于线段$MN$，因此属于$m = \frac{1}{2} (a + b)$。

从问题 4 可以看出，四边形 $ABCD$ 的中线 $MN$ 的长度等于摩尔和摩尔卡的边 $AD$ 和 $BC$ 长度的一半，当这些边平行时。
