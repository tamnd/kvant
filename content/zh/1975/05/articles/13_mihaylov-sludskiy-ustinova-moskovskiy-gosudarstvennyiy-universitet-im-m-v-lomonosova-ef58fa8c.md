莫斯科国立大学
他们。 M·V·罗蒙诺索娃
（力学与数学学院、物理学院、计算数学与控制论学院）

我们在«Kvant»，1973年，第4期详细介绍了莫斯科国立大学的这些院系。这里我们列出了1974年进入这些院系的学生所提供的数学笔试选项，以及物理口试中提供的任务。

Mathematica

力学与数学学院
选项1

1. 解方程：
$$\sqrt{1 + \sin x} + \cos x = 0.$$

2. 解决不等式：
$$\sqrt{1 - \log_5(x^2 - 2x + 2)} < \log_5(5x^2 - 10x + 10).$$

3. 三角形ABC的外接圆。中线ADprod必须与这个圆相交于E点。已知AB + AD = DE，角BAD = 60°，AE = 6。求三角形ABC的面积。

4. 在三角形paramid ABCD 中，边DC = 9，边DB = AD，边AC 垂直于面ABD。半径为 2 的球体在其中线的交点处与面 ABC、边 DC 和面 DAB 相切。求出帕拉酰胺的体积。

5. 找出 α 的所有实数值，其中每个实数值都有满足等式的偶数整数 (x, y, u, v)：
$$x^2 + y^2 = (111 - \alpha)(\alpha - 89),$$
$$50(u^2 - v^2) = \alpha(15u + 5v - \alpha).$$
选项2

1. 解方程：
$$\sqrt{2\sin 2x} + 2\sin x = 0.$$

2. 解决不等式：
$$\sqrt{1 + \log_2(7x^2 + 14x + 8)} \leq 1 + \log_8(7x^2 + 14x + 8).$$

3. 三角形ABC的外接圆。过 B 点作该圆的切线，直至与 CA 的延长线相交于 D 点。已知 AB + AD = AC，线段 CD = 3，角度 BAC = 60°。求三角形 ABC 的周长。

4. 三角形 ABCD 的底边是三角形 ABC，其中角 BAC = 60°，角 ACB 是直角。面 BCD 与面 ABC 成 60° 角。边 BD = 2。球体接触边 AB、AC 和面 BCD。球体的中心 - 点 O - 位于对位聚酰胺的底部，并且线段 OD 垂直于对位聚酰胺 ABCD 的底部平面。求边 AC 的长度。

5. 找出 α 的所有实数值，其中每个实数值都有满足等式的偶数整数 (x, y, u, v)：
$$(x + y)(x + y + 20) = (140 - \alpha)(\alpha - 80),$$
$$\alpha(8u^2 + 2v^2 - \alpha) = (4u^2 - v^2)^2.$$

物理学院

选项1

1. 解方程：
$$\sqrt{3} - \tg x = \tg \left(\frac{4\pi}{3} - x\right).$$

2. 解决不等式：
$$x^2 - 2|x + 1| < 0.$$

3. 解方程：
$$2\sqrt{3}\log_16x - \sqrt{3}\log_2x - 6 = 0.$$

4. 两个相同的正三角形 ABC 和 CDE 位于边 1。

5. 给定两条三角形线$SABC$和$NKLM$，其所有边都等于$a$。这些线的共同高度为$SN$（$S$是面$KLM$的中心，$N$是面$ABC$的中心）。另外，布置$KL \parallel BC$和线，使得穿过$KL$和$BC$的平面与线段$SN$相交。求直线 $SABC$ 和 $NKLM$ 公共部分的体积。

选项2

1. 解方程：
$$\sin x + \cos x - 1 = \text{ctg} \frac{x}{2} (\cos x - 1).$$

2. 解决不等式：
$$(|x| - 1)^2 > 2.$$

3. 解方程：
$$\frac{3}{4} \log^3 \frac{x}{3} - 30 \sqrt{\log^3 x} + 36 = 0.$$

4. 从位于以 $O$ 为圆心的圆外部的点 $K$ 开始，向该圆绘制两条切线：$MK$ 和 $NK$（$M$ 和 $N$ 是切点）。在弦 $MN$ 上取点 $C$ ($MC < CN$)。通过点$C$，垂直于线段$OC$，绘制一条直线，与线段$NK$相交于点$B$。已知圆的半径为$R$、$MKN = \alpha$、$MC = b$。求线段 $CB$ 的长度。

5. 三角形直线 $SABC$ 的底边是直角平衡三角形 $ABC$。点$D$是斜边$AB$的中点，$SD$是直线的高度，$SD = DC = a$。通过点$S$画一个垂直于$SD$的平面，并在该平面上构造一个直角三角形$SEF$，使得点$S$为直角、$SE = SF = a\sqrt{2}$和$EF \parallel AB$的顶点。此外，三角形$SEF$的位置使得穿过$EF$和$AB$的平面与边$SC$相交。求直线 $SABC$ 和 $SDEF$ 公共部分的体积。

计算数学与控制论学院

选项1

2. 找到 $a$ 的所有实值，其中不等式 $\log \frac{1}{2} x^2 \geq \log \frac{1}{2} (x+2)$ 的每个解都是不等式 $49x^2 - 4a^4 \leq 0$ 的解。

3. 找到满足同时条件的$x$的所有值：
$$\begin{cases} |x-2| + |x-3| = 1, \\ 813x - 974 \leq 163x^2. \end{cases}$$

4. 有三个互不相通的储液罐，三角软管的容积为3小时，第二软管为4小时，第三软管为5小时。每个水箱都可以连接到这三个软管中的任何一个。当一根软管以某种方式连接到每个水箱后，所有软管都会同时打开。一旦水箱已满，相应的软管就会关闭，并且以后无法连接到另一个水箱。如果所有三个储罐均已注满，则视为最终注注。采用最快的连接方式，6小时内即可完成填充。如果水箱已连接，填充将在 4 小时内结束。求第二个和第三个水箱的容积。

5. 在三角形直线$SABC$中，每个顶点$B$和$C$处的三个平面角之和等于$180^\circ$和$SA = BC$。如果面$SBC$的面积等于$100\text{ cm}^2$，且外接球中心到底$ABC$平面的距离等于3\text{cm}，求直线的体积。

物理

力学与数学学院和计算数学与控制论学院

1. 在 $l=20$ 厘米长的导光棒的末端放置两个球，第一个球是铅球 ($\rho_1=11,3\text{ e/cm}^3$)，第二个球是铝球 ($\rho_2=2,7\text{ e/cm}^3$)。 Sharirino 杆固定在中间并放入水中，使其处于平衡状态。您需要将第二个球沿着杆移动多远才能在空中恢复平衡？

2. 质量为 $m=200$ e 的球可以沿着水平杆无摩擦地滑动，该水平杆绕垂直轴以角速度 $\omega=2\text{ c}^{-1}$ 旋转。弹簧连接到球上，弹簧的另一端固定到轴上。弹簧未变形状态下的长度为$l=20$cm。确定弹簧的绝对伸长量$\Delta l$。弹簧刚度$k=4\text{ h/m}$。

3. 一颗质量为 $m=10$ e 的猪子弹，以速度 $v_0=400\text{ m/c}$ 水平飞行，击中一块质量为 $M=1990\text{ e}$ 的铅并被卡在里面。猪躺在光滑的水平表面上。求铅会加热多少度$\Delta t$。不考虑身体向周围身体的转移。铅的热容为$c=1,2\cdot 10^2\text{ дж/kг.эрад}$。

4. 高度为 $l=40\text{ cm}$ 的圆柱形容器被一个无摩擦滑动的失重薄活塞分成两部分。活塞位于气缸室上方 $h=26,7\text{ cm}$ 的高度。活塞下方有氢气，上方有未知分子量$\mu$的气体。找出 $\mu$ 气体，如果它的质量等于氢气的质量。

5. 五个电容器组合成图1所示的目标。电容器1、2、3的电容量相同且相等：$C_1=C_2=C_3=2\text{ мкф}$。电容器$C_4$和$C_5$的容量为4 µF。弹簧$u=100\text{ b}$应用于点$A$和$B$。确定第四个和第五个电容器上的污垢$q_4$和$q_5$。

6. 长度为$l=0,1\text{ m}$的导体可以在均匀磁场图1中沿着由电阻$R=0,1\text{ om}$连接的平行板条的两个导体无摩擦地滑动。

场中，指示$B=0,05\text{ m}$垂直于板条平面。必须对导体施加多大的力才能使其以 $v=1\text{ m/c}$ 的速度均匀移动？

物理学院

1. 航天器距地球表面的距离为$h=20000\text{ km}$，在与地球相关的坐标系中，其速度为$v_1=6\text{ km/c}$，从地球中心径向指向。动不动就不行了飞船会坠落地球还是飞向外太空？忽略太阳、月亮和行星的影响。地球的半径是$R_0=6400\text{ km}$，$g_0=10\text{ m/c}^2$。如果在相同条件下，船速为$v_2=5\text{ km/c}$或$v_3=4\text{ km/c}$，会发生什么？
