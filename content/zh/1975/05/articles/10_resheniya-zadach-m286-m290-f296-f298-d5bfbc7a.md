M286。平面上有 N 个点。让我们标记线段的所有中点，并在这些点处结束。平面上最少可以移动的点是多少？

让我们考虑给定 N 个点之间尽可能多的距离，并选择这些距离中最大的距离 - 将此距离作为两点 A 和 B 之间的距离。让我们将点 A 与剩余的 N - 1 个点连接起来；我们得到 N-1 个片段。这些线段的中点不同，并且都位于以 A 点为圆心、半径为 $\frac{1}{2} |AB|$ (图 1) 的圆的内部或边界上。

类似地，通过将​​B点与剩余的N-1个点连接，我们获得位于以B点为圆心的相同半径的圆的内部或边界上的N-1个肿胀点（中点）。

所构造的两个圆只有一个点——线段AB的中点。因此，总是有至少 2 (N-1) - 1 个（因为我们将线段 AB 的中点数了两次）个肿胀中点，即至少有 (2N-3) 个肿胀点。

让我们证明 2N-3 是最小的肿胀点数量。令给定的N个点位于同一条直线上，并且相邻点之间的距离相同（图2）。很容易看出，在这种情况下，肿胀点 - 中间（在 图 2 上这些是红点）的数量等于 (N-2) + N-1 = 2N-3。这样一切就都被证明了。

总之，我们邀请读者思考以下问题。对于什么N，可以将N个点放置在平面上，使得它们不在同一直线上，并且使得以这些点为端点的线段的膨胀中点的数量等于2N-3？

M287。是否存在一个自然数序列，使得任何最小的数字 1, 2, 3,... 都可以单位方式表示为该序列中两个数字的差？

这样的序列是存在的。让我们简单解释一下如何构建它。

假设我们构造了一个具有以下属性的有限序列：

1) 该序列的成员之间的所有成对差异都是不同的；
2) 数字 1,2,...,k 可以表示为其两项之差；
3) 数字 k+1 不能表示为其两项之差。

令该序列的最大项等于 M。现在让我们“添加”该序列：将数字 2M 和 2M+k+1 添加到其中。自己检查新序列是否满足属性 1.2（用 k+i 替换 k，其中 i 是某个自然数，取决于序列的第一个存在，i≥1）和属性 3（用数字 k+i+1 替换数字 k+1）。例如，将“加”的描述应用到数字 1,2，我们得到满足问题条件的无限序列。

让我们拿两个盒子并在其中排列权重，以便第一个盒子包含少于 $K$ 的权重。我们将权重安排如下。

首先，我们取不能被 $K$ 整除的权重。如果这样的权重少于$K$，则将它们放入第一个框中，然后继续下一步。如果有更多这样的权重$K$，那么我们将所有权重放入第二个框中。

在第一种情况下，我们采用那些权重可被 $K$ 整除，但不能被 $K^2$ 整除的权重。如果它们适合第一个盒子，则将它们放在那里；如果没有，则将第一个框中没有的所有权重放入第二个框中。

如果第一种情况再次发生，那么我们取那些权重可被$K^2$整除，但不能被$K^3$整除的权重，依此类推。由于总共至少有 $K$ 个权重，因此某些权重肯定会出现在第二个框中。令第一组不适合第一个盒子的权重是其权重可被$K^r$整除，但不能被$K^{r+1}$整除的权重。第二个盒子将包含那些权重可被$K^r$整除的权重，第一个盒子将包含那些权重不能被$K^r$整除的权重。

根据问题的条件，可以将权重分为$K$组等权。由于第一个框中的权重小于$K$，因此无法在其中表示所有$K$组，这意味着存在一个组，所有组都在第二个框中。因此，该组（以及每个组）的总重量除以 $K^r$。由于我们共有 $K$ 组重量相等，因此权重的总重量除以 $K^{r+1}$。

现在假设我们去掉了一些权重，剩下的权重可以分为 $K$ 个等权组。和之前一样，我们发现剩余权重的权重之和除以$K^{r+1}$。

我们去掉的权重的重量等于所有权重的总重量与剩余权重的差值；因此，该权重的权重除以$K^{r+1}$（请注意，$r$可能为零；这对应于所有权重最终都在第二个框中，而第一个框为空）。这意味着，如果我们去掉一个不能被$K^{r+1}$整除的权重，那么剩下的权重就不能被分成等权的$K$组。但由于权重数量$r$的选择，其权重不能被$K^{r+1}$整除，因此不小于$K$，否则它们将全部被放置在第一个盒子中。这样一切就都被证明了。

F296。每个具有极值 $C_1, C_2, \dots, C_k$ 的 $k$ 不同电容器被充电到标记差 $U$。然后将所有电容器用不同尺寸的条带串联成闭合电路。该电路中每个电容器的名称。

在将电容器连接到电路之前，它们的电荷为$q_1 = C_1U, q_2 = C_2U, \dots, q_i = C_iU, \dots, q_k = C_kU$。我们将电容器连接到相应电路后的电荷用$q'_1, q'_2, \dots, q'_k$表示。电容器极板上的电荷分布如图 6 所示。根据电荷守恒定律，通过极板相互连接的电容器的电荷总和（电路的此类部分之一在图 6 上用虚线突出显示）必须等于连接电容器之前这些极板上的总电荷。即（考虑到收费的迹象）

$$q'_2 - q'_1 = q_2 - q_1 = (C_2 - C_1)U,$$

$$q'_3 - q'_2 = q_3 - q_2 = (C_3 - C_2)U,$$

$$q'_k - q'_{k-1} = q_k - q_{k-1} = (C_k - C_{k-1})U.$$

此外，在发电厂场中，沿封闭计数器穿过电荷的功为零，因此各个电容器上的方向之和等于零：$U_1 + U_2 + \dots + U_k = 0$，或

$$\frac{q'_1}{C_1} + \frac{q'_2}{C_2} + \dots + \frac{q_k}{C_k} = 0.$$

根据方程组 (*) 和 (**)，我们确定电容器的新电荷，然后确定它们的方向。首先，我们通过第一个电容的电荷$q'_1$来表示所有的电荷。从系统 (*) 的第一个方程可以得出 $q'_2 = q'_1 + (C_2 - C_1)U$。将系统(*)的第一和第二方程相加，我们得到$q'_3 = q'_1 + (C_3 - C_1)U$。

类似地，对于第 $i$th 电容器的电荷，我们得到
$$q'_i = q'_1 + (C_i - C_1) U.$$
让我们将结果表达式代入方程 (**)：
$$\frac{q'_1}{C_1} + \left[ \frac{q'_1}{C_2} + \left( 1 - \frac{C_1}{C_2} \right) U \right] + \dots + \left[ \frac{q'_1}{C_k} + \left( 1 - \frac{C_1}{C_k} \right) U \right] = 0,$$
或者
$$q'_1 \left( \frac{1}{C_1} + \frac{1}{C_2} + \dots + \frac{1}{C_k} \right) + kU - C_1 U \left( \frac{1}{C_1} + \frac{1}{C_2} + \dots + \frac{1}{C_k} \right) = 0.$$
因此$q'_1 = (C_1 - kC_0) U$，其中$C_0$是电容器平衡连接的电容：
$$\frac{1}{C_0} = \frac{1}{C_1} + \frac{1}{C_2} + \dots + \frac{1}{C_k}.$$
由于$q'_i = q'_1 + (C_i - C_1) U$，那么
$$q'_i = (C_1 - kC_0) U + (C_i - C_1) U = (C_i - kC_0) U.$$
这意味着第 $i$ 个电容器两端的电压为
$$U'_i = \frac{q'_i}{C_i} = \left( 1 - k \frac{C_0}{C_i} \right) U.$$
