为了找到所需的数字μ，我们首先选择一个素数序列$q_1, q_2, \dots$，使得对于任何$n=1, 2, \dots$
$$2^q < q_{n+1} < 2^{q+1} - 1. \quad (4)$$
（任何素数都可以视为 $q_1$；序列 $\{q_n\}$ 的无限延续是可能的，但不等式 (4) 保证了 Bertrand 的构造。）

为了简洁起见，我们用数字来表示
$$2^2,$$
我们通过 $\exp^n \alpha$ 取 $n$ 幂，以及反函数，
$$\log_2 \log_2 \dots \log_2 \beta - \text{через } \log_2^n \beta.$$

让我们尝试选择数字 μ 使得在 $n=1, 2, \dots$
$$[\exp^n \mu] = q_n. \quad (5)$$
根据数的整数部分的定义，等式（5）等价于不等式
$$q_n \leqslant \exp^n \mu < q_n + 1.$$

以 2 为底将其传播 $n$ 次，我们得到另一个等价于 (5) 的双重不等式：
$$\log_2^n q_n \leqslant \mu < \log_2^n (q_n + 1). \quad (6)$$

自己检查一下 (4) 的结果
$$\log_2^1 q_1 < \log_2^2 q_2 < \dots < \log_2^n q_n < \log_2^{n+1} q_{n+1} < \dots < \log_2^{n+1} (q_{n+1} + 1) < \log_2^n (q_n + 1) < \dots < \log_2^2 (q_2 + 1) < \log_2^1 (q_1 + 1).$$

所以顺序
$$\log_2^1 q_1, \log_2^2 q_2, \dots, \log_2^n q_n, \dots$$
严格增加和限制范围；因此它有一个限制。我们将其视为数字μ；证明所选的 μ 满足比 (6) 更强的不等式
$$\log_2^n q_n < \mu < \log_2^n (q_n + 1), \quad (7)$$
因此，等式 (5) 成立。赖特定理已被证明。

梅森素数和费马素数
米拉斯、赖特的公式和其他类似的公式仍然是孤立的事实，没有得出新的结果。然而，在其他情况下，以一种或另一种特殊形式表示某些素数的能力会产生意想不到的深远后果。

现在让我们考虑两个具有兼容简单形式的公式：
$$p = 2^n - 1, \quad (8)$$
$$p = 2^n + 1. \quad (9)$$

显然，式（8）并不总是给出素数；例如，如果 $n$ 是合数 $n = kl, k > 1, l > 1$，则 $p$ 可以被 $2^k - 1$ 和 $2^l - 1$ 整除。但即使使用从公式 (8) 获得的简单 $n$，该数字也可能是合数：
$$2^{11} - 1 = 2047 = 23 \cdot 89.$$

由式(8)得到的素数在Marin Mersenne中被称为梅森数
