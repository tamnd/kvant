它 - 即使在这个简单的模型上我们也能够追踪它。 （不过，需要注意的是，这样的模型也可以具有直接的物理意义。例如，它很好地描述了金属或半导体薄膜中电子的行为。在这种情况下，$AB$部分代表薄膜的厚度，薄膜的两个表面起到了不让电子逸出的壁的作用。）要计算这种一维原子的特性，可以使用德布罗意公式。由于电子被“锁定”在有限的空间区域内（在本例中为直线段上），因此我们必须谈论驻波。例如，当固定在两个点上的弦振动时，就会出现类似的机械一维故事波。当然，这些锚定点应该与点$A$和$B$进行比较，超出这些点电子就无法穿透。弦线也不会穿过固定端。这意味着振荡期间弦的点的混乱总是使得点 $A$ 和 $B$ 是节点（它们的混合总是等于零）。从这里可以看出，段 $AB$ 必须包含整数个半波。因此，具有固定端部的振动弦只能处于某些运动状态，该运动状态可以通过点 $A$ 和 $B$ 之间适合的半波数进行编号。换句话说，在长度$\lambda$满足以下关系的弦中，只有那些波是可能的：$AB = n\lambda/2$，其中$n$是取值为1、2、3等的整数。在图上，4个sluans I、II、III、IV对应于$n$，等于1、2、3和4。让我们用字母 $L$ 表示线段 $AB$ 的长度。那么可能的波长$\lambda_n$由以下公式给出

$$\lambda_n = \frac{2L}{n}; \quad n = 1, 2, 3, \dots$$

现在让我们回到在两壁之间运行的电子并将德布罗意公式应用于它。由于只能存在一组离散的波 $\lambda_n$，因此电子速度 $v_n = \frac{h}{m\lambda_n}$ 也只能取一组离散的值：

$$v_n = \frac{h}{m\lambda_n} = \frac{h}{m2L} n; \quad n = 1, 2, 3, \dots$$

电子的动能是$E = mv^2/2$，也不能是任意的。只有离散的能级：

$$E_n = \frac{h^2n^2}{8mL^2}; \quad n = 1, 2, 3, \dots$$

（数字$n$称为量子数）。我们获得了量子力学的第一个公式之一——“锁定”在两个不可穿透的墙壁之间的电子的能级。从经典力学的角度来看，在这种情况下提出能量允许值的问题是没有意义的。如果一个经典的球在两堵墙之间跳跃，并从两堵墙弹性反射，那么它的能量 $E = \frac{mv^2}{2}$ 取决于初始速度 $v_0$ 并且可以取任何值。没有能量“阶梯”，或许能量值填进去
