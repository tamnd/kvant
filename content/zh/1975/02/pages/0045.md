⟦folio 43⟧

事实上，对于申请者来说，没有什么材料比与二次三项式研究相关的问题更熟悉了。没有一个考官怀疑每个进入大学的学生都会轻松解决二次方程，记住维塔定理并处理二次不等式。然而，应用考试的实践一次又一次地转向这个话题，而考生并不总是能取得成功。他们渴望使用表面信息，并在其帮助下尽快将问题翻译成正式语言。然而，该解决方案并不总是最佳的。

问题情况的图形表示通常更有帮助。它使得可以同时考虑所有条件并找到最简单的解决方案。

让我们用例子来展示这一点。

问题1. 方程的实数值$x_1$和$x_2$是什么

$$x^2 - 2x - a^2 + 1 = 0$$

位于方程根 $x_1'$ 和 $x_2'$ 之间

$$x^2 - 2(a+1)x + a(a-1) = 0?$$

我们需要找到所有$a$，使得它们对应的值$x_1$、$x_2$、$x_1'$和$x_2'$满足整数不等式

$$x_1' < x_1 \leqslant x_2' < x_2'.$$

很自然地，首先尝试求解这些方程并重写未知参数 $a$ 的等效整数不等式问题。

第一个方程的根是$x_1,2 = 1 \pm a$，第二个方程的根是$x_1',2 = a + 1 \pm \sqrt{3a+1}$。

由于不清楚$1-a$和$1+a$哪个数字更大，我们考虑两种情况。如果$1-a \leqslant 1+a$，那么问题就简化为系统：$x_1' < 1-a$，$x_2' > 1+a$。如果$1+a < 1-a$，那么我们得到另一个系统：$x_1' < 1+a$，$x_2' > 1-a$。

Ptak 将能够解决一组两个非理性不平等系统。你自己做一下，并与其他人比较我们现在将提出的问题的解决方案。

让$f(x)$和$g(x)$对应于第一个和第二个方程的左侧。函数$y = f(x)$和$y = g(x)$的图形是由向上分支形成的抛物线。让我们用$x_1$和$x_2$表示方程$f(x) = 0$的根，用$x_1'$和$x_2'$表示方程$g(x) = 0$的根。对于每个人来说，$x \in (x_1', x_2')$将是$g(x) < 0$。如果$x_1' < x_1 < x_2' < x_2'$，则$g(x_1) < 0$和$g(x_2) < 0$。反之亦然：如果$g(x_1) < 0$和$g(x_2) < 0$，则$x_1' < x_1 < x_2' < x_2'$。因此，问题归结为解决不等式系统

$$\begin{cases} g(x_1) < 0, \\ g(x_2) < 0. \end{cases}$$

将$x_1,2 = 1 \pm a$代入$g(x)$，得到系统

$$\begin{cases} (1-a)^2 - 2(a+1)(1-a) + a(a-1) < 0, \\ (1+a)^2 - 2(a+1)(1-a) + a(a-1) < 0. \end{cases}$$
