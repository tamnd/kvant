4. 那么 - 让我们开始工作吧

为了确保模型分支中的电流$\tilde{x}_{ij}$的数值是为最大流问题提供解决方案的流量，需要证明在$\tilde{x}_{ij} = \tilde{x}_{ij}$条件（2）和（3）满足并且网络中的流量$X$的值被视为最可能的值。

我们已经证明这不是这个陈述的第一部分。事实上，对模型$\tilde{x}_{12} \leq a_{12}, \tilde{x}_{13} \leq a_{13}, \tilde{x}_{23} \leq a_{23}, \tilde{x}_{24} \leq a_{24}, \tilde{x}_{34} \leq a_{34}, \tilde{x}_{35} \leq a_{35}, \tilde{x}_{45} \leq a_{45}$的所有分支写出不等式（6），（9）我们得到电流$\tilde{x}_{ij}$满足条件（2），并将基尔霍夫第一定律应用于模型的所有主节点，我们得到电流$\tilde{x}_{ij}$的五个相应条件（3）。

这意味着剩下的就是证明电路中的值$\tilde{X}$是磁通$X$最可能的值，与条件（2）和（3）兼容。这个事实的证明由两部分组成。

1. 我们首先证明，对于满足条件（2）和（3）的变量$x_{ij}$的任何值，不等式
$$\tilde{X} = x_{12} + x_{13} \leq \sum_{i,j} a_{ij}u_{ij},$$ (11)

其中$u_{ij}$是支路$i - j$中的电压数值，并且对电路的所有支路进行总和*)，也就是说，我们将证明对于沿网络运输弧线的任何允许的运输量，通过网络的流量$X$不超过数量$\sum_{i,j} a_{ij}u_{ij}$。

由于不等式 (2) 和 $u_{ij}$ 的非负性（参见 (8)），我们有 $x_{ij}u_{ij} \leq a_{ij}u_{ij}$；因此，
$$\sum_{i,j} x_{ij}u_{ij} \leq \sum_{i,j} a_{ij}u_{ij}.$$ (12)

现在让我们记住$u_{ij} = p_i - p_j$，其中$p_i, p_j$是对应于节点的势。这就是为什么
$$\sum_{i,j} x_{ij}u_{ij} = \sum_{i,j} x_{ij}(p_i - p_j) = x_{12}(p_1 - p_2) + x_{13}(p_1 - p_3) + x_{23}(p_2 - p_3) + x_{24}(p_2 - p_4) + x_{34}(p_3 - p_4) + x_{35}(p_3 - p_5) + x_{45}(p_4 - p_5) = p_1(x_{12} + x_{13}) + p_2(-x_{12}) + p_2(x_{13} - x_{23}) + p_3(-x_{13} - x_{23}) + p_4(-x_{24} - x_{34}) + p_5(-x_{35} - x_{45}).$$

$p_2, p_3$和$p_4$括号内的表达式等于0（见（3））；当$p_1$和$p_5$等于$X$和$-X$时（见（4）），$p_1 - p_5 = U = 1$；这就是为什么
$$\sum_{i,j} x_{ij}u_{ij} = p_1X - p_5X = (p_1 - p_5)X = X.$$ (13)

考虑(12)，我们得到所需的不等式
$$\tilde{X} \leq \sum_{i,j} a_{ij}u_{ij}.$$ (14)

*) 符号$\sum_{ij}$表示所考虑类型的项之和，对应于给定问题的所有可能的索引值集合​​$i, j$。在我们的例子中
$$\sum_{i,j} a_{ij}u_{ij} = a_{12}u_{12} + a_{13}u_{13} + a_{23}u_{23} + a_{24}u_{24} + a_{34}u_{34} + a_{35}u_{35} + a_{45}u_{45}.$$
