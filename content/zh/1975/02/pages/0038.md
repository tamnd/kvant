⟦folio 36⟧

让我们分别求出第一种情况和第二种情况下的照度，然后是它们的比率。

在第一种情况下，源位于距线 $d_1 = 3a$ 的位置。从透镜公式$\frac{1}{d} + \frac{1}{f} = \frac{1}{F}$我们发现源图像距离直线的距离为$f_1 = \frac{Fd_1}{d_1 - F} = \frac{3}{2}a$，即正好在屏幕上。

假设光源面积很小并且等于$\Delta S$（光源的实际尺寸与光源到直线的距离相比应该很小，因为使用透镜公式，我们只考虑靠近主光轴的光线）。然后我们可以假设，用单位立体角中的光源面积单位表示的光通量（我们将其表示为 $I$）是一个常数值。因此，光通量$\Phi_1 = I\Delta S\Omega_1$落在来自光源的线上，其中$\Omega_1$是光源点线可见的立体角。角度$\Omega_1$通过比率$\frac{S}{d_1^2}$来测量（$S$是线的面积，$d_1$是线到源的距离）。这是镜头照射到屏幕后的光通量。屏幕上的图像区域$\Delta S_1$与源区域$\frac{f_1^2}{d_1^2}$相关，即

$$\frac{\Delta s_1}{\Delta S} = \frac{f_1^2}{d_1^2} = \frac{1}{4}.$$

那么第一种情况下的屏幕照度等于

$$E_1 = \frac{\Phi_1}{\Delta S_1} = I \frac{S}{d_1^2} \frac{\Delta S}{\Delta S_1} = \frac{4}{9} \frac{IS}{a^2}.$$

在光源和透镜之间放置一块平面板后，板给出的光源图像就成为透镜的光源。让我们找到该图像的位置（距离 $x$ by 图 9）。

为此，我们将构建从光源的点 $A$ 发出的两条光线的路径。让一条射线垂直于板，第二条射线与第一条射线形成一个小角度$\alpha$。从三角形 $A'CK$ 线段 $CK$ 等于

$$CK = A'K \mathrm{tg} \alpha = \left(l - x + \frac{a}{2}\right) \mathrm{tg} \alpha.$$

另一边，

$$CK = CD + KD = \frac{a}{2} \mathrm{tg} \beta + l \mathrm{tg} \alpha.$$

因此，

$$\left(l - x + \frac{a}{2}\right) \mathrm{tg} \alpha = \frac{a}{2} \mathrm{tg} \beta + l \mathrm{tg} \alpha.$$

因此$x = \frac{a}{2} \left(1 - \frac{\mathrm{tg} \beta}{\mathrm{tg} \alpha}\right)$。由于角度 $\alpha$ 和 $\beta$ 小，因此 $\frac{\mathrm{tg} \beta}{\mathrm{tg} \alpha} = \frac{\sin \beta}{\sin \alpha} = \frac{1}{n}$ 和 $x = \frac{a}{2} \left(1 - \frac{1}{n}\right)$。因此，板给出的光源图像距离$d_2 = 3a - x = \frac{a}{2} \left(5 + \frac{1}{n}\right)$。
