（无初速度）。 t秒后，通知它们之间的距离。如果从 3l 的距离释放球，什么时候才能知道球之间的距离？

$$\frac{\Delta x_2}{\Delta x_1} = 3$$

让$k$改变值​​$\Delta k = \frac{\Delta x}{x_0}$。那么每个球在第一种情况（$\text{когда } 2x_0 = l$）中的位移是$\Delta x_1 = \Delta k \frac{l}{2}$，在第二种情况（$\text{когда } 2x_0 = 3l$）中是$\Delta x_2 = \Delta k \frac{3}{2} l$。球的运动比率等于

$$\frac{\Delta x_2}{\Delta x_1} = 3.$$

现在让我们比较一下球的平均速度。为此，我们将使用能量守恒定律。在初始时刻，球仅具有电相互作用势能$\Pi_0 = \frac{q^2}{2x_0}$（在SGSE系统中）。当球之间的距离为$2x$时，它们具有势能$\Pi = \frac{q^2}{2x}$和动能$K = 2 \frac{mv^2}{2}$（m为球的质量）。根据能量守恒定律$\frac{q^2}{2x_0} = \frac{q^2}{2x} + mv^2$。从这里

$$v = \sqrt{\frac{q^2}{2m} \frac{x-x_0}{xx_0}} = \sqrt{\frac{q^2}{2x_0 m} \frac{k-1}{k}}.$$

我们看到，对于相同的相对位移$k$，第一种情况下球的速度是第二种情况下球速度的$\frac{\sqrt{q^2/ml}}{\sqrt{q^2/3ml}} = \sqrt{3}$倍。

很明显，当$k$改变$\Delta k$值时，球的平均速度将相差$\sqrt{3}$倍：$\frac{v_{\text{cp.1}}}{v_{\text{cp.2}}} = \sqrt{3}$。

第一种情况下移动到 $\Delta x_1$ 所需的时间和第二种情况下移动到 $\Delta x_2$ 所需的时间分别相等

$$\Delta t_1 = \frac{\Delta x_1}{v_{\text{cp.1}}} \text{ и } \Delta t_2 = \frac{\Delta x_2}{v_{\text{cp.2}}}.$$

从这里

$$\frac{\Delta t_2}{\Delta t_1} = \frac{\Delta x_2}{\Delta x_1} \frac{v_{\text{cp.1}}}{v_{\text{cp.2}}} = 3 \sqrt{3},$$

也就是说，对于值$k$的任何变化，第一种情况下的移动时间是第二种情况下的移动时间的$3 \sqrt{3}$倍。
