图$y = f(x)$是一条通过坐标原点的直线，平面上满足不等式（9）的所有点均不低于该直线。因此，对于每个$a$，必须找到抛物线$y = \varphi(x)$的一个点，该点不低于直线$y = 2x$并且具有最大序数。抛物线与直线的相对位置有两种可能的情况：要么抛物线的顶点不低于直线$y = 2x$，要么位于该线下方（见图5）。在第一种情况下，问题的解是点$(x_0, y_0)$，它是抛物线的顶点，在第二种情况下是点$(x_1, y_1)$，其坐标同时满足直线和抛物线方程。抛物线方程可以很容易地找到其顶点的坐标：$x = a$，$y = a + 1$。我们看到抛物线 $y = \varphi(x)$ 的所有顶点

参数$a$的不同值位于直线$y = x + 1$上，反之亦然，直线$y = x + 1$的每个点$(x_0, y_0)$对应于一条抛物线$y = \varphi(x)$，其顶点在其中 - 取$a = x_0$就足够了。让我们在一张图上绘制直线 $y = x + 1$ 和 $y = 2x$ (图 6)。两条线的交点是点 (1, 2)。在$a \leqslant 1$，线$y = x + 1$将位于线$y = 2x$上方，问题的解决方案将是点$(a, a + 1)$。如果$a > 1$，那么解就是点$(x, y)$，满足系统
$$\begin{cases} y - 2x = 0, \\ -x^2 + 2ax - a^2 + a + 1 - y = 0; \end{cases}$$
因此$y = 2x$和$x^2 - 2(a - 1)x + a^2 - a - 1 = 0$。

当$D = 2 - a \geqslant 0$时，方程有两个实根，即$a \leqslant 2$。其中，较大的满足问题条件：
$$x_2 = a - 1 + \sqrt{2 - a}.$$
答案：在$a \leqslant 1$、$x = a$、$y = a + 1$、在
$$1 \leqslant a \leqslant 2, x = a - 1 + \sqrt{2 - a},$$
$$y = 2(a - 1) + 2\sqrt{a - 1},$$
对于 $a > 2$ 没有解。

然而，“格式”解决方案并不总是更加劳动密集型。否则它比图形更合适。

问题 6（MAI，1971）。 $m$ 不等式的实际值是多少
$$x^2 - 2mx + 2|x - m| + 2 < 0$$
有至少一种解决方案吗？
让我们将这个不等式转化为以下形式
$$(x - m)^2 + 2|x - m| + 2 - m^2 < 0,$$
或者
$$\begin{cases} y^2 + 2y + 2 - m^2 < 0, \\ y \geqslant 0, \end{cases}$$
