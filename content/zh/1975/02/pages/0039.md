在这种情况下，图像的尺寸与源相同（参见 图 9）。从这个新光源入射到透镜上的光通量$\Phi_2$等于$\Phi_2 = I \Delta S \Omega_2 = I \Delta S \frac{S}{d_2^2}$。

现在，根据透镜公式，找到该源的图像的位置：

$$f_2 = \frac{Fd_2}{d_2 - F} = a \frac{5n + 1}{3n + 1}.$$

很明显，屏幕上没有清晰的图像，但屏幕上可见一个模糊的点。然而，由于对于玻璃来说，$n$的范围是1.5到2，因此$f_2$的取值范围是1.54 a到1.57 a。这是距离屏幕大约 0.05 a 处的图像。与屏幕到镜头 1.5 a 的距离相比，该距离很小。此外，物体的尺寸和透镜的直径也很小（再次注意，我们只考虑窄近轴光束）。因此，我们可以假设清晰图像的大小与屏幕上光点的大小（图10）和$\frac{\Delta s_2}{\Delta S} = \frac{f_2^2}{d_2^2} = \frac{4n^2}{(3n + 1)^2}$没有区别。

那么这种情况下的照度$E_2$屏幕等于

$$E_2 = \frac{\Phi_2}{\Delta s_2} = \frac{I S \Delta S}{d_2^2 \Delta s_2} = \left( \frac{3n + 1}{5n + 1} \right)^2 \frac{I S}{a^2},$$

和照度比

$$\frac{E_2}{E_1} = \frac{9}{4} \left( \frac{3n + 1}{5n + 1} \right)^2.$$

最初，电容器极板之间的电位差为$E_2$，电容器的电荷为$q_1 = CE_2$。闭合按键后，电路中将流过电流，电容板之间的电位差（$B$和$A$点之间的电位差）将等于$U_2 = E_2 - Ir_2$，其中$I$是流过电路的电流。让我们找到这个电流。

从二极管的电流-电压特性可知，当电流流过二极管时，其两端的电压始终等于$U_2 = 1\epsilon$。让我们写出完整电路的欧姆定律：

$$E_2 - E_1 = U_{\pi} + Ir_1 + Ir_2.$$

从这里

$$I = \frac{E_2 - E_1 - U_{\pi}}{r_1 + r_2}.$$

然后，关闭按键后，电容器极板之间的电位差将等于
