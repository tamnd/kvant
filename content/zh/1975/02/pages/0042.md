⟦folio 40⟧

$$\frac{t_2}{t_1} = 3\sqrt{3}$$

首先考虑板材以$v$等速垂直向下落下的情况。与板一起下落的电子受到磁场的洛伦兹力 (图 13) $F_\pi = evB$ (e 是电子的电荷) 的作用。结果，电子将向板的右侧混合。板内电子的重新分布导致出现从左到右的电场（参见 图 13）。电子混合将发生，直到左洛伦兹力与电场作用的力 $F_3$：$F_\pi = F_3$ 或 $evB = eE$ 平衡。因此电场的方向性$E = vB$。

由于板的厚度远小于其半径，因此板内电场可以认为是均匀的（边缘效应可以忽略不计）。这意味着该板可以被认为是一个扁平电容器，其板之间的电势差为$u = Ed = Bvd$，其电荷等于

$$q = Cu = \frac{\varepsilon_0 S}{d} Bvd = \varepsilon_0 SBv$$

（$S = \pi R^2$为板的面积）。

该电荷取决于板的速度。当板以一定的加速度移动时，随着板的速度随着时间的推移，板两侧的电荷也会发生变化。因此，当板的速度改变时，板中就会产生电流

$$I = \frac{\Delta q}{\Delta t} = \varepsilon_0 SB \frac{\Delta v}{\Delta t} = \varepsilon_0 SB a$$

其中$a$是板的加速度。但是，正如我们所知，力 $F = BId$ 作用在磁场中带有电流的导体上，并且方向垂直向上。因此，当板从磁场中落下时，除了重力之外，还会作用$F$ 的力。让我们写出板的运动方程：

$$ma = mg - BId$$ 或 $ma = mg - B^2 d\varepsilon_0 a\pi R^2$。

从这里

$$a = g \frac{1}{1 + \frac{B^2 d\varepsilon_0 \pi R^2}{m}}.$$

I.Sh.斯洛博杰茨基
