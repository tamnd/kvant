事实上，对于申请者来说，没有什么材料比与二次三项式研究相关的问题更熟悉了。没有一个考官怀疑每个进入大学的学生都会轻松解决二次方程，记住维塔定理并处理二次不等式。然而，应用考试的实践一次又一次地转向这个话题，而考生并不总是能取得成功。他们渴望使用表面信息，并在其帮助下尽快将问题翻译成正式语言。然而，该解决方案并不总是最佳的。

问题情况的图形表示通常更有帮助。它使得可以同时考虑所有条件并找到最简单的解决方案。

让我们用例子来展示这一点。

问题1. 方程的实数值$x_1$和$x_2$是什么

$$x^2 - 2x - a^2 + 1 = 0$$

位于方程根 $x_1'$ 和 $x_2'$ 之间

$$x^2 - 2(a+1)x + a(a-1) = 0?$$

我们需要找到所有$a$，使得它们对应的值$x_1$、$x_2$、$x_1'$和$x_2'$满足整数不等式

$$x_1' < x_1 \leqslant x_2' < x_2'.$$

很自然地，首先尝试求解这些方程并重写未知参数 $a$ 的等效整数不等式问题。

第一个方程的根是$x_1,2 = 1 \pm a$，第二个方程的根是$x_1',2 = a + 1 \pm \sqrt{3a+1}$。

由于不清楚$1-a$和$1+a$哪个数字更大，我们考虑两种情况。如果$1-a \leqslant 1+a$，那么问题就简化为系统：$x_1' < 1-a$，$x_2' > 1+a$。如果$1+a < 1-a$，那么我们得到另一个系统：$x_1' < 1+a$，$x_2' > 1-a$。

Ptak 将能够解决一组两个非理性不平等系统。你自己做一下，并与其他人比较我们现在将提出的问题的解决方案。

让$f(x)$和$g(x)$对应于第一个和第二个方程的左侧。函数$y = f(x)$和$y = g(x)$的图形是由向上分支形成的抛物线。让我们用$x_1$和$x_2$表示方程$f(x) = 0$的根，用$x_1'$和$x_2'$表示方程$g(x) = 0$的根。对于每个人来说，$x \in (x_1', x_2')$将是$g(x) < 0$。如果$x_1' < x_1 < x_2' < x_2'$，则$g(x_1) < 0$和$g(x_2) < 0$。反之亦然：如果$g(x_1) < 0$和$g(x_2) < 0$，则$x_1' < x_1 < x_2' < x_2'$。因此，问题归结为解决不等式系统

$$\begin{cases} g(x_1) < 0, \\ g(x_2) < 0. \end{cases}$$

将$x_1,2 = 1 \pm a$代入$g(x)$，得到系统

$$\begin{cases} (1-a)^2 - 2(a+1)(1-a) + a(a-1) < 0, \\ (1+a)^2 - 2(a+1)(1-a) + a(a-1) < 0. \end{cases}$$

解决它，我们找到$-\frac{1}{4} < a < 1$。

应该注意的是，如果$x_1$和$x_2$的表达式足够简单，那么问题的这种变换是合适的。

然而，访问图形并不总是像刚刚讨论的示例那样顺利和容易。

这是另一个例子。

问题 2（MAI，1970）。对于参数m的实际值，方程根$(1+m)x^2-3mx+4m=0$服从条件$2 < x < 5$？

让我们在这里重述一位申请人提出的问题的解决方案。二次三项式的图可以向上或向下分支，具体取决于 $x^2$ 处系数的符号。在这两种情况下，二次三项式$f(2)$和$f(5)$的值将具有相同的符号，即$f(2) \cdot f(5) > 0$。然而，根$x_1$和$x_2$可以同时位于2的左侧，也可以同时位于5的右侧。在这两种情况下，$f(2) \cdot f(5)$将大于零，但抛物线$x_0$顶点的横坐标位于线段[2,5]之外。因此，我们要求它位于该段内。还需要记下这个方程有实数根，并将问题的解简化为不等式组的解

$$\begin{cases} f(2) \cdot f(5) > 0, \\ 2 < x_0 < 5, \\ D \geq 0. \end{cases}$$

上述推理并非没有根据，但不幸的是，它表明缺乏准确性。用系统（1）代替原来的任务不能被认为是合理的。对于任意二次三项式 $f(x)$ 它根本不成立（参见 图 1）。但除此之外，也可能是$x^2$的系数趋于零，那么函数的图形将是一条直线。

为了获得问题的准确解决方案，您需要找到一种方法来确保穷尽所有可能的情况。为此，可以方便地求出$x^2$的系数。它可以是负数、零或正数。

当$1+m=0$，即$m=-1$时，方程变为$3x-4=0$。其根$x=4/3$不满足问题的条件；它不在 2 和 5 之间。

若$1+m \neq 0$，则方程左边是二次三项式，其图形是抛物线。既然三项式一定有实根，那么$D \geq 0$，即$9m^2-16m(m+1) \geq 0$。因此$0 \geq m \geq -16/7$。

现在让我们利用抛物线顶点的横坐标必须位于其根之间的事实，即 $2 < \frac{3m}{2(m+1)} < 5$。

我们已经发现$m < 0$，因此仅对于$m+1 < 0$，数量$\frac{3m}{2(m+1)}$才会为正。因此，不需要考虑抛物线的分支朝上的情况。让我们解决由此产生的不平等并发现

$$-4 < m < -\frac{10}{7}.$$

$$\begin{cases} x+y=2(k+1), \\ xy=k^2+3k-1 \end{cases}$$

问题 6（MAI，1971）。 $m$ 不等式的实际值是多少
$$x^2 - 2mx + 2|x - m| + 2 < 0$$
有至少一种解决方案吗？
让我们将这个不等式转化为以下形式
$$(x - m)^2 + 2|x - m| + 2 - m^2 < 0,$$
或者
$$\begin{cases} y^2 + 2y + 2 - m^2 < 0, \\ y \geqslant 0, \end{cases}$$

其中$y = |x - m|$。当且仅当 (9) 左侧的判别式为非负且较大根 $y_2$ 不位于零的左侧时，系统 (11)、(12) 至少有一个解：

$$\begin{cases} m^2 - 1 \geq 0, \\ -1 + \sqrt{m^2 - 1} \geq 0, \\ m^2 \geq 1, \\ m^2 \geq 2. \end{cases}$$

即$\begin{cases} m^2 \geq 1, \\ m^2 \geq 2. \end{cases}$

答案：$m \leq -\sqrt{2}, m \geq \sqrt{2}$。

因此，我们看到在许多问题中使用二次三项式的图形表示是很方便的。这种方法可能对其他成瘾有用。它有助于发现更简单、更有意义的解决方案路径。然而，所有关于图的论证只有以最通用的形式执行才能成为解决方案的一部分。在参数问题中，您应该特别小心依赖类型，因为对于某些参数值，图形的外观可能会发生显着变化（在示例 2 中，我们看到在 $m = -1$ 处，二次三项式的图形将不是抛物线，而是直线）。解决问题时使用图表本身并不是目的，最后一个例子清楚地证实了这一点。首先，你需要仔细分析特定问题的所有特征，思考最合理的利用其条件——这可以帮助你找到最方便的解决方案。
