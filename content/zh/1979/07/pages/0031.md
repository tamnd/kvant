假设$\sqrt{v_x} \sim \sqrt{RT_K/\mu}$，并考虑$n = p/k T_K$（这来自门捷列夫-克拉佩龙方程），我们最终发现：

$$\Delta t \sim \frac{4Mc\Delta T \sqrt{\mu T_K}}{3p(T_c - T_k)S\sqrt{R}}.$$

代入数值（$M = 1$ kg、$\Delta T = 20$ K、$T_K = 293$ K、$p = 1$ Pa、$\mu = 29.10^{-3}$ kg/mol 等），我们得到$\Delta t \sim 3.10^4$和$\sim 10$ h。

我们假设当阳极电位大于阴极电位时，二极管开始传导电流。在这种情况下，二极管的电阻将为零，并且其两端的电压降也将为零。

让我们分阶段考虑关闭钥匙$K$后电路中发生的过程。

1. 流经电感$L$的电流对电容器充电。在电流 $I_1$ 达到一定值时，电容器充电至电压 $\%_1$。电容器的电荷$q_1 = C\%_1$，电容器的能量$W_1 = C\%_1^2/2$，电感的磁场能量$LI_1^2/2$。此时电池所做的功是$A = q_1\%_1$。

2. 尽管电池 $\%_1$ 上的电压和电容器上的电压相同，但电容器由于电感磁场的能量而继续充电。在电流 $I_0$ 达到一定值时，电容器充电至电压 $\%_0$。电容器的电荷$q_0 = C\%_0$，电容器的能量$W_0 = C\%_0^2/2$，电感的磁场能量$LI_0^2/2$。

电池$\%_1$在第1阶段和第2阶段所做的功是$A_1 = q_0\%_1 = C\%_0\%_1$。

3. 从电容器两端的电压变为$\%_0$的那一刻起，电流开始通过二极管流入电池$\%_0$。此时电容器上的电压不再变化，其能量仍等于$W_0 = C\%_0^2/2$。

因此，磁场中具有电感的能量$LI_0^2/2$开始减少 - 它负责将电荷转移到电池$\%_0$。

4. 电感磁场的能量为零。电容器的能量仍为$W_0 = C\%_0^2/2$。一些电荷 $Q$ 通过电池 $\%_0$。电池能量$\%_0$增加$\Delta W = Q\%_0$。

在第 3 阶段和第 4 阶段，电池 $\%_1$ 做功 $A_2 = Q\%_1$。

那么，在整个过程中电池$\%_1$做了以下工作：

$$A_{\%_1} = A_1 + A_2 = C\%_0\%_1 + Q\%_1.$$

这项工作将$W_0 = C\%_0^2/2$的能量传输到电容器$C$，并将电池$\%_0$的能量增加$\Delta W = Q\%_0$。根据能量守恒定律

$$A_{\%_1} = W_0 + \Delta W,$$
