R·伊兹麦洛夫

◆ 这个问题最好使用动态图来解决。一点的运动速度恒定是指它的运动图形与时间轴t形成相同的角度（图4）。设相遇时刻为 t1, t2, t3, ... 显然，t1 < t ≤ t2 和 t2 ≤ t < t3 部分中的两个运动图关于直线 t = t2 对称，因此第三次相遇将发生在与第一次相同的点 C 处。同理，直线 t = t₃ 是 t ≤ t₃ 和 t ≥ t₃ 时运动图的对称轴；因此，第四次会议将在与第二次相同的 D 点举行，依此类推：每一次奇数会议将在 C 点举行，每一次偶数会议（包括 1978 年）将在 D 点举行。

从我们的解决方案中还可以清楚地看出，数字 t1、t2、t3、... 形成一个算术级数：会议以相等的间隔 d = tₙ₁ + tₙ2 发生，并且整个情况以周期 T = 2d 完全重复。

这是一个有用事实的特殊情况：如果函数 y = f(x) 的图形相对于线 x = a 和 x = b 对称（即 f(a + x) = f(a - x) 和 f(b + x) = f(b - x)），则函数 f 是周期性的，周期为 2|b - a| （在我们的问题中，x 的角色由 t 扮演）。
