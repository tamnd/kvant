看看图中所有这些示例都涵盖了什么内容！

最后三个示例中使用的缩写符号比完整符号更方便和紧凑，但首先我们建议使用完整符号，以便记住处方的含义。

如果处方左侧的变量字段“表达式”的值被赋值，即在单词ASSIGN的左侧有一个数字或文本，则将这个数字或这个文本分配给姓名；如右侧所示。如果名称用作表达式，则将分配该名称的值。

我们来尝试追踪一下，当上述指令依次执行时，内存块的内容是如何变化的。为此，建议我们绘制一个名称值表。执行第一个分配后，该表将如下所示：

| 姓名 | 意义 |
| :--- | :--- |
| A | 5 |

也就是说，此时名称A的值为5。第二次赋值后，名称A将收到新的值。旧的将无法挽回地消失。在表中我们这样描述：

| 姓名 | 意义 |
| :--- | :--- |
| A | '线' |

最方便的方法是在黑板上用粉笔分配此类表格，擦除旧值并输入新值。 “从记忆中删除”和“记录在记忆中”这两个词清楚地传达了所发生事件的本质。

完成以下三个指令后，表格将如下所示：

| 姓名 | 意义 |
| :--- | :--- |
| A | '线' |
| 加速度 | 9.81 |
| A5 | 'A' |

现在让我们来执行最后一条指令：

分配的价值 A5；

处方的左边有一个名字，这意味着我们需要使用它的含义。

该值将与旧文本“A”一起命名为 A5。完成此分配后，该表将采用以下形式：

| 姓名 | 意义 |
| :--- | :--- |
| A | '线' |
| 加速度 | 9.81 |
| A5 | 'A' |
