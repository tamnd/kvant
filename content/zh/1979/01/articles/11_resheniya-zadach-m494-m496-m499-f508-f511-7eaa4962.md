M494。在边 1 的正方形内有 $n^2$ 个点。证明存在一条包含这些点且长度小于a) 3n​​的折线； b) 2n。

构造折线的思想从图1就很清楚了：我们将正方形分成$n$垂直条纹，然后以“蛇”的方式讨论所有的点：我们从视图的顶部经过左边的第一个条纹，从下往上经过第二个条纹，等等。折线的链接长度之和不大于它们在垂直和水平两侧的投影长度之和。正方形。很容易看出，垂直投影的总和不超过$n$，水平投影的总和可以估计如下。不与带状边界相交的连线的水平投影不超过$1/n$，与带状边界的垂直线段相交$k$的连线的投影不超过$(k+1)/n = k/n+1/n$。条带的垂直边界总数为$n-1$，因此所有$n^2-1$水平投影的总和不超过

$(n^2-1)/n+(n-1)/n=n+1-2/n \leq n+1$.

因此，对于折线的长度，我们得到估计值 $2n+1$。

问题a)的解决方案，为了证明6)，需要将估计提高1。

为此，我们需要改变我们的设计。我们将正方形分成 $n$ 不同宽度 $(h_1, h_2, \dots, h_n)$ 的条带，这样每个条带正好有 $n$ 个点（“边界”点可以分配给左侧和右侧）。让我们用红色和蓝色交替的线段连接条纹的所有上部点和所有下部点 (图 2)。我们可以选择蛇线的起点，以便它沿着所有蓝色线段或沿着所有红色线段。折线的红、蓝段水平投影$2(n-1)$之和不大于2；如果我们选择总和小于 1 的颜色，我们将获得所有水平投影总和的估计值

$(n-1)(h_1+h_2+\dots+h_n)+1 \leq n$.

与之前一样，垂直投影的总和不超过 $n$。

所以，我们构造了一条长度不大于$2n$的折线，我们决定6)。

M496。哪些六位数更大：那些可以表示为两个三位数乘积的六位数，还是那些不能表示的六位数？

三位数只有 900 个（从 100 到 999）。因此，只有$\frac{900 \cdot 899}{2} + 900 = \frac{900 \cdot 901}{2} = 405450$对（不一定不同）三位数。

因此，不超过这个数量的六位数，可以表示为两个三位数的乘积。六位数字一共有90万个。这意味着其中一半以上无法表示为两个三位数的乘积。

M498。对于每个自然数 n ≥ 3 表示最小的 k，使得平面上的任何 n 个点（其中没有三个点位于给定线上）可以被 k 条线分开。

许多向我们发送该问题解决方案的人都记得这个事实（使用归纳法证明并不困难）：

F508。水星绕太阳公转的周期为88个地球日，绕太阳轴公转的周期为59个地球日。水星上白天和黑夜的长度是多少？

让我们用$x$（地球日）来表示水星上一天的长度。在地球的一天中，水星将绕其轴旋转 $\frac{360^\circ}{59}$ 角度，并沿其轨道（同一方向）移动 $\frac{360^\circ}{88}$ 角度。差值 $\frac{360^\circ}{59} - \frac{360^\circ}{88}$ 代表在一个地球日内水星相对于太阳旋转的角度：

$$\frac{360^\circ}{59} - \frac{360^\circ}{88} = \frac{360^\circ}{x}.$$

从这里

$$x \approx 179$$

水星上的一天大约等于两个水星年。

因此，水星一天和一小时的长度大约等于一年的长度。

F510。橡胶球上铺有坚固的橡胶网，其线沿着球的经线拉动。如果对球施加压力，它会呈现什么形状？

让我们考虑其中一个线程并在其上选择长度为 $l$ (图 10) 的一小部分。让我们用$\vec{T}$表示线的张力。作用在所选区域上的合力$\vec{Q}$张力的绝对值等于$2|\vec{T}| \sin \frac{\alpha}{2}$。

在$l \ll R$（$R$是给定位置处螺纹的曲率半径）$\alpha = \frac{l}{R} \ll 1$，因此我们可以假设

$$\sin \frac{\alpha}{2} = \frac{\alpha}{2}, \quad |\vec{Q}| = \frac{l}{R} |\vec{T}|.$$

由于螺纹的选定部分处于平衡状态，因此作用在其上的所有力的总和等于零。这意味着力从球的侧面作用在螺纹上

$$\vec{F} = -\vec{Q}.$$

根据牛顿第三定律，力从螺纹一侧作用在球上

$$-\vec{F} = -(-\vec{Q}) = \vec{Q},$$

指向球的中心。

相同数量的螺纹$N$穿过球的任何平行线。对于半径为 $r = R \cos \varphi$ 的平行线（$\varphi$ 是球的半径与赤道平面的平行线所成的角度）等于 $2\pi r = 2\pi R \cos \varphi$。因此，穿过面积为 $l \times l$ 的球壳截面的螺纹数

$$n = \frac{N}{2\pi R \cos \varphi} l.$$

那么作用在壳上的压力等于

$$p = n \frac{|\vec{Q}|}{l^2} = \frac{N |\vec{T}|}{2\pi R^2 \cos \varphi}.$$

如果球壳保持球形，压力将随着角度 $\varphi$ 的增加而增加。事实上，根据帕斯卡定律，同样的事情也会增加压力。这意味着球的外壳不是球形的。沿赤道的分布比沿垂直直径的分布大；子午线的曲率半径朝赤道减小，朝极地增大，因此$R^2 \cos \varphi = \text{const}$。

外壳的形状类似于南瓜（图11）。也许南瓜的形状正是通过其经脉中存在的“筋线”和灵魂来解释的？

F511。面积为 $S$ 的平行板电容器的极板彼此之间形成小角度 $\alpha$ ($\alpha \ll 1$)。板之间的平均距离为$b$。画出电容器电子场的平线的近似图，并求出电容器的电容。

以 $O$ 为中心的圆汇合电子线的近似图。事实上，漏极线始终垂直于导体表面，这意味着它们垂直于电容器板。从对称线的报告中可以清楚地看出，它们垂直于板块形成的角度的平分线。如果用薄金属板代替平分线，梅花线的图像就不会发生任何变化。以类似的方式推理，我们会得出排水管应该

垂直于从点 $O$ 发出并位于角度 $\alpha$ 内的任何射线。这意味着强线是同心圆的弧。

场线的密度并不总是相同；它沿着 $X$ 轴减小。这并不难解释。众所周知，场线的密度与电场的电压成正比。我们来看看随着坐标$x$的增大（坐标原点位于$B$点）电压如何变化。将单位电荷沿南南强线从一个电容器板移动到另一个电容器板的功应该是相同的（该功等于板之间的电势差）。因此，电源线越长，电压（作用于单位电荷的力）越低。考虑到角度$\alpha$很小，我们得到

$$|\vec{E}| = |\vec{E}_0| \frac{b}{b + \alpha x},$$

其中 $\vec{E}_0$ 是电源线 $AB$ 上的电压（其中电容器极板之间的距离为 $b$），$\vec{E}$ 是相邻电源线上的电压，与 $AB$ 相距 $x$、$b$ 和 $b + x$ - 相应电源线的长度。

电源线的密度也会发生变化。

现在我们来求电容器的电容$C$。根据定义

$$C = \frac{q}{U},$$

其中 $q$ 是电荷，$U$ 是电容器电压。 $U$可以通过$|\vec{E}_0|$表示：

$$U = |\vec{E}_0| b.$$

剩下的就是表达$q$。

在板附近，电场与平面场相似；因此它的电压

$$|\vec{E}| = \frac{\sigma}{2\varepsilon_0},$$

其中$\sigma$是表面电荷密度，$\varepsilon_0$是电常数。从这里

$$\sigma = 2\varepsilon_0 |\vec{E}| = \frac{2\varepsilon_0 |\vec{E}_0| b}{b + \alpha x}.$$

让我们用 $l$ 表示板的“深度”，并在板上选择一条宽度为 $\Delta x$ 的窄条。其电荷相等

$$\Delta q = \sigma l \Delta x = \frac{2\varepsilon_0 |\vec{E}_0| b l}{b + \alpha x} \Delta x.$$

为了找到板的全部电荷，我们需要将所有基本条带的电荷相加，并转到介词$\Delta x \rightarrow 0$。结果我们得到

$$q = 2\varepsilon_0 b l |\vec{E}_0| \int_{-a}^{a} \frac{dx}{b + \alpha x} = \frac{2\varepsilon_0 b l |\vec{E}_0|}{\alpha} \ln \frac{b + \alpha a}{b - \alpha a}.$$

然后最后

$$C = \frac{q}{U} = \frac{2\varepsilon_0 l}{\alpha} \ln \frac{b + \alpha a}{b - \alpha a}.$$
