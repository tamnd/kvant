⟦folio 25⟧

当兔子被抓住时，$x_T = y_T = 0$。在初始时间$y_0 = a \cos \alpha$。因此，狼在捕捉野兔所需的时间$T$期间的运动在$Oy$轴上的投影等于$y_0 = a \cos \alpha$。因此，狼在$Oy$轴上的速度在时间$T$上的投影平均值

$$\bar{U}'_{\rightarrow Oy} = -y_0 / T = -a (\cos \alpha) / T.$$

现在让我们从(1)和(2)中找出$U'_{\rightarrow OB_1}$和$U'_{\rightarrow Oy}$之间的对应关系。我们有：

$$U'_{\rightarrow OB_1} = U'_{\rightarrow Oy} / n + |\vec{V}| / n - n |\vec{V}|.$$

由于$|\vec{V}| / n$和$n |\vec{V}|$项不依赖于时间，因此相同的对应关系对于所考虑的预测的平均值有效，即

$$\bar{U}'_{\rightarrow OB_1} = \bar{U}'_{\rightarrow Oy} / n + |\vec{V}| / n - n |\vec{V}| = -a (\cos \alpha) / n T + |\vec{V}| / n - n |\vec{V}|.$$

另一边，

$$\bar{U}'_{\rightarrow OB_1} = -a / T.$$

从(3)和(4)我们发现catch异常：

$$T = \frac{a}{|\vec{V}|} \cdot \frac{n}{n^2 - 1} \left(1 - \frac{\cos \alpha}{n}\right).$$

让我们检查这个答案以评估特殊情况。

$1^\circ$$\alpha = 0$：狼惹恼了兔子。在这种情况下，狼运动的相对速度等于$|\vec{V}| / (n + 1)$，所以它会在$T_1 = \frac{a}{|\vec{V}| / (n + 1)}$时间上超越兔子。

将(5)代入$\alpha = 0$，也可得到相同的结果。

$2^\circ$$\alpha = \pi$：狼打败兔子。在这种情况下，他的相对速度值为$|\vec{V}| / (n - 1)$（$n > 1$），他将在$T_2 = \frac{a}{|\vec{V}| / (n - 1)}$时间完成兔子。

将$\alpha = \pi$代入式(5)，得到相同的答案。

在 $T$ 时间内，zac 走过了距离

$$S_3 = |\vec{V}| T = \frac{an}{n^2 - 1} \left(1 - \frac{\cos \alpha}{n}\right),$$

因此，狼 LOB 在直线 $l$ 上的某个点（距离点 $A$ $S_3$）击败了野兔。
