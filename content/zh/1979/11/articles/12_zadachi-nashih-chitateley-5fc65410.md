⟦folio 40⟧

井，或两条横向贯通的裂缝。金属管制成的立柱均匀，没有裂纹。

这怎么解释呢？

由于玻璃是热的不良导体，因此玻璃管中的水的硬化非常缓慢且不均匀。经过很长一段时间，就会形成两到三根冰柱，这些冰柱彼此相连。接缝处出现裂纹。

在壁具有良好导热性的金属管中，全部水会快速且均匀地冻结。冰柱原来是整体的。

6. 将水填充到尺寸为 70x50x20 毫米的矩形盒子（塑料或金属），几乎达到边缘。用纸板剪出这个盒子的盖子，盖子要大到稍微超出边缘。从纸板中心画一个直径略小于芯宽度的圆。

任务
我们的读者

1. 通过边长为$a, b, c$的三角形内的点$K$，绘制与边平行的线。边之间的线段长度分别等于$a_1, b_1, c_1$。证明

a) $\frac{a_1}{a} + \frac{b_1}{b} + \frac{c_1}{c} = 2$;

b) $\frac{4}{3} \leq \frac{a_1^2}{a^2} + \frac{b_1^2}{b^2} + \frac{c_1^2}{c^2} \leq 2$.

2. 通过三角形$ABCD$内的点$K$以及面$S_a, S_b, S_c$和$S_d$的面积，绘制四个与三角形面平行的平面。所得截面的面积分别等于 $S_1, S_2, S_3, S_4$。证明

a) $\sqrt{\frac{S_1}{S_a}} + \sqrt{\frac{S_2}{S_b}} + \sqrt{\frac{S_3}{S_c}} + \sqrt{\frac{S_4}{S_d}} = 3$;

b) $\frac{S_1}{S_a} + \frac{S_2}{S_b} + \frac{S_3}{S_c} + \frac{S_4}{S_d} \geq \frac{9}{4}$.

3. 通过三角形内部的点$K$，绘制与其边$|BC| = a, |AC| = b, |AB| = c, |AD| = d_1, |BD| = d_2, |CD| = d_3$平行的线。这些面之间包含的直线段的长度分别等于$a', b', c', d_1', d_2', d_3'$。证明

$\frac{a'}{a} + \frac{b'}{b} + \frac{c'}{c} + \frac{d_1'}{d_1} + \frac{d_2'}{d_2} + \frac{d_3'}{d_3} = 3$.
