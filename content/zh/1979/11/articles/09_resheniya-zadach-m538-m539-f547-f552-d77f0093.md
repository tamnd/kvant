问题解决方案
M538, M539; F547—F552

M538。所有自然数的集合是所有$n \ge 1$的两个不相交子集$f(1), f(2), \dots, f(n), \dots$}、$\{g(1), g(2), \dots, g(n), \dots\}$、$\exists f(1) < f(2) < \dots < f(n) < \dots, u g(n) = f(f(n)) + 1$的耗尽。识别$f(240)$。

让我们用$F$和$G$表示集合$f(n)$和$\{g(n)\}$（按照惯例$F \cap G = \emptyset$和$F \cup G = N$）。从第一个自然数 1, 2, 3, ... 开始，很容易一致地找出下一个自然数应该分配到集合 $F$ 或 $G$ 中的哪一个，以及它对应于集合中的哪个数字 $n$：很明显，$1 = f(1)$，因此$2 = f(f(1)) + 1 = g(1)$；此外，$3 = f(2), 4 = f(3), 5 = f(f(2)) + 1 = g(2)$，...（表 1）。在这种情况下，我们得到条件 $g(n) = f(f(n)) + 1$ - 我们在放置 $f(f(n))$ 后立即放置下一个 $g(n)$。

因此，$f(n)$和$g(n)$是唯一定义的，原则上我们只需将表移至第240行即可解决问题。然而，这是乏味且无趣的。您可以通过注意新出现的模式来节省时间：

1°。不同之处 $f(n+1) - f(n)$ 总是等于 1 或 2，并且

$$f(n+1) - f(n) = \begin{cases} 1, \text{ если } n \in G, \\ 2, \text{ если } n \in F \end{cases}$$

（如果$n = f(k)$，则$f(n)+1 \neq g(k)$）；

2°。 $g(n) = f(n)+n$ 对于任何 $n$。事实上，在$g(n)$数字1、2、...、$f(f(n)), g(n)$中，有来自$F$的$f(n)$数字$f(1), f(2), \dots, f(f(n))$和来自$G$的$n$数字$g(1), g(2), \dots, g(n)$。因此，$g(n) = f(n)+n$。

属性 1° 和 2° 使我们有机会创建“加速”表 2。Teler 仍然使用属性 1° 从 234 移动到 240（表 3）。正如我们的读者 A. Balinsky 所同意的，更简单的是提前采取额外的步骤（使用等式 $f(f(n)) = f(n)+n-1$）：

$$f(57) = 90+2 \quad (56 \in F), \quad f(92) = 92+56 = 148,$$

$$f(148) = 148+91,$$

$$f(239) = 239+147 = 386, \quad f(240) = 386+2 = 388 \quad (239 \in F).$$

于是，得到了问题M538的具体问题的答案：$f(240)=388$。然而，事实证明，在这里您可以走得更远 - 找到可立即给出任何 $n$ 答案的替换简单公式：

$$f(n) = \left[ \frac{1+\sqrt{5}}{2} n \right], \quad g(n) = \left[ \frac{3+\sqrt{5}}{2} n \right]$$

（这里$[x]$是$x$的整数部分）。我们的一些读者找出了公式（*），但并不是每个人都能准确地证明它们。内容的代数证明很麻烦（虽然不是很困难）；我们将无法共同呈现一幅清晰的图片，从中可以清楚地了解公式 (*) 和构造序列 $f(n)$、$g(n)$ 的过程。但首先，我们来解释一下这个问题中无理数$\frac{\sqrt{5}+1}{2}$出现在“手指上”的情况。

查看表 1，很自然地假设序列 $f(n)$ 近似作为 $n$: $f(n) \approx \gamma n$ 的线性函数增长。那么对于大的$n$应该有$g(n) \approx f(f(n)) \approx \gamma (\gamma n) = \gamma^2 n$。但根据2°，$g(n) = f(n)+n$，所以$\gamma^2 n \approx \gamma n+n$，而这仅适用于$\gamma^2 = \gamma+1$，因此（如果$\gamma > 0$）$\gamma = (\sqrt{5}+1)/2$。从下面的内容可以清楚地看出，我们的第一个$n$自然数的集合$F$和$G$大约包含对应自然数的$n/\gamma$和$n/\gamma^2$数（正如他们所说，它们具有完整性$1/\gamma$和$1/\gamma^2$）。

对于任意$n$，我们标记线$l$与线$y = n$和$x = n$（图3）的交点$K(n/\gamma; n)$和$M(n/\gamma; n)$。然后，包含点 $K$ 的左侧单元格编号为 $f(n)$，包含点 $M$ 的底部单元格编号为 $g(n)$。让我们注意点 $K$ 和 $M$ 在轴 $y$ 上的投影 $K'$ 和 $M'$。请注意$K'KM' = 45^\circ$（记住图 1），因此包含点$K$和$M'$的单元格编号为$f(n)$。因此，在点 $M$ 处，有一条直线 $f(f(n))$ 进入单元格编号 $g(n)$，即 $f(f(n)) + 1 = g(n)$。

让我们考虑小车的两个对称位置，其中小车所在点的半径向量与垂直方向形成相同的角度 α (图 12)。 $\vec{N}_1$和$\vec{N}_2$是这些位置处的路面反作用力，$\vec{F}_{T1}$和$\vec{F}_{T2}$是牵引力，$\vec{F}_{Tp1}$和$\vec{F}_{Tp2}$是摩擦力。由于小车沿着道路滑动，$F_{Tp1} = \mu N_1$和$F_{Tp2} = \mu N_2$（这里是$N_1 = |\vec{N}_1|$、$F_{Tp1} = |\vec{F}_{Tp1}|$等）。

小车以速度v做圆周运动；因此，作用在小车上的所有力在半径方向上的投影之和等于$mv^2/R$，即（见图12）

$$N_1 - mg \cos \alpha = mv^2/R, \quad N_2 + mg \cos \alpha = mv^2/R.$$

从这里

$$N_1 = (mv^2/R) + mg \cos \alpha, \quad N_2 = (mv^2/R) - mg \cos \alpha$$

和

$$F_{Tp1} = \mu [(mv^2/R) + mg \cos \alpha], \quad F_{Tp2} = \mu [(mv^2/R) - mg \cos \alpha].$$

当半径矢量旋转一个小角度Δα时，即小车的投影在Δl=RΔα处较小且摩擦力$\vec{F}_{Tp1}$和$\vec{F}_{Tp2}$时，做功$\Delta A_1 = F_{Tp1}R \Delta \alpha$和$\Delta A_2 = F_{Tp2}R \Delta \alpha$。

小区域 Δl 内力$\vec{F}_{Tp1}$ 和$\vec{F}_{Tp2}$ 的功总和等于 $\Delta A = (F_{Tp1} + F_{Tp2})R \Delta \alpha = 2\mu mv^2 \Delta \alpha.$

ΔA 的值不依赖于 α。这意味着，当小车的半径向量从任意两个对称点（类似于 I 和 2）旋转一个小角度 Δα 时，合并会做相同的工作，与 Δα 成正比。

将小车从轨道的底部点移动到顶部对应于 α 的变化 π/2，即 ΣΔα = π/2。因此，这种突出物的摩擦力所做的功等于

$$A = \sum \Delta A = 2\mu mv^2 \Delta \alpha = \pi\mu mv^2.$$

现在让我们找出弹簧的最大变形。显然，在弹簧变形最大的时刻，在以系统质心速度运动的坐标系中，球只能绕质心滚动。这意味着系统的能量可以表示为系统整体能量$W_C$与内能之和，等于弹簧变形势能$kx^2 / 2$（x为变形量）与球体旋转动能$W_K = 1 / 2 \left[ m_1 (\omega l_1)^2 + m_2 (\omega l_2)^2 \right]$之和，其中$\omega$为旋转角速度，$l_1$和$l_2$是相应球到中心wt的距离。

让我们用 $l$ 表示弹簧的长度。然后$l_1 = lm_2 / M$，$l_2 = lm_1 / M$，所以

$$W_K = \frac{1}{2} \omega^2 l^2 \left( \frac{m_1 m_2^2}{M^2} + \frac{m_2 m_1^2}{M^2} \right) = \frac{1}{2} \omega^2 l^2 \frac{m_1 m_2}{M}.$$

让我们找到$\omega$。由角动量守恒定律可知

$$m_1 (\omega l_1) l_1 + m_2 (\omega l_2) l_2 = m_1 \omega_0 l_{10}^2 + m_2 \omega_0 l_{20}^2,$$

其中$l_{10}$和$l_{20}$是从球到质心的初始距离，$\omega_0$是初始角速度。显然，如果弹簧的初始长度为$l_0$，则

$$l_{10} = l_0 m_2 / M, \quad l_{20} = l_0 m_1 / M.$$

波兹尼姆我们可以写

$$\left[ m_1 \left( \frac{m_2}{M} \right)^2 + m_2 \left( \frac{m_1}{M} \right)^2 \right] \omega l^2 = \left[ m_1 \left( \frac{m_2}{M} \right)^2 + m_2 \left( \frac{m_1}{M} \right)^2 \right] \omega_0 l_0^2.$$

因此$\omega = \omega_0 (l_0 / l)^2$。为了找到$\omega_0$，需要找到$\vec{v}_1$和$\vec{v}_2$球在质心系统中的初始速度。由于初始时刻质心速度等于$\vec{u}_0 = \left( m_1 \vec{v}_1 + m_2 \vec{v}_2 \right) / M$，因此质心系统中球的速度对应于

F552。氖灯的伏安特性如图 16 所示。图 17 所示电路中的电阻$R$ 为多大值时，关闭钥匙$K$ 后氖灯（n.l.）不会亮？

当钥匙关闭时，电容器开始充电。当电容器上的电压以及灯上的电压等于 110V 时，灯就会点亮。从这一刻起，流过灯的电流将增加，灯两端的电压以及电容器两端的电压将下降 - 电容器将充电。如果在充电过程中电容器电压低于 80 V，灯将会熄灭 - 电路中的电流小于充电 ~80 V 时流过灯的额定电流（参见图 16）。因此，为了使灯不熄灭，电容器上的电压不应该在这个过程中。
