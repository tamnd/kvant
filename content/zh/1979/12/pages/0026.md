厨师（系数为$k$），中心为$L$。由此可知$A_0LA_2 = A_2LA_4 = 90^\circ$；因此，点 $L$ 可以构造为两个直径为 $[A_0A_2]$ 和 $[A_2A_4]$ 的半圆的交点，或者甚至更简单 - 从 $A_2$ 垂直于 $A_2L$ 降低到线段 $A_0A_4$ 上。要找到从点 $L$ 到三角形 $A_0A_1A_2$ 长度为 $a$ 和 $b$ 的边的距离 $x$ 和 $y$，您可以使用 $L \in [A_0A_4]$ 和 $|LA_4| : |LA_0| = k^2$ 的事实，或者使用 中省略的垂线这一事实将$L$分成段$A_0A_2$，$A_2A_4$，$A_4A_6$，相互获得变换$\Pi$，其中

$$\begin{cases} y = kx, \\ ka - x = ky \end{cases}$$

（在图3处，长度$x$的线段为蓝色，长度$y = kx$的线段为绿色，长度$ky$的线段再次为蓝色）。因此，

$$x = \frac{ka}{k^2 + 1} = \frac{a^2b}{a^4 + 3a^2b^2 + b^4},$$

$$y = \frac{k^2a}{k^2 + 1} = \frac{a^3b^2}{a^4 + 3a^2b^2 + b^4}.$$

在许多信件中，这些答案都是以几何级数的形式收到的，其值为$k^2$ - 正在准备变换系数$\Pi^2$。

**M543。让**

$$\rho(x, y) = \frac{|x - y|}{\sqrt{1 + x^2}\sqrt{1 + y^2}}.$$

证明对于任何实数 $a, b$，不等式

$$\rho(a, c) \leq \rho(a, b) + \rho(b, c).$$

**图 4.**

“距离”$\rho$的公式本质上可以通过在数字$y \in \mathbb{R}$和数字$\alpha \in \left[-\frac{\pi}{2}; \frac{\pi}{2}\right]$之间建立一一对应$y = tg\alpha$来投影。如果$y_1 = tg\alpha_1$，$y_2 = tg\alpha_2$，然后将$tg\alpha$替换为$\sin\alpha/\cos\alpha$，我们得到

$$\rho(y_1, y_2) = \frac{|tg\alpha_1 - tg\alpha_2|}{\sqrt{1 + tg^2\alpha_1}\sqrt{1 + tg^2\alpha_2}} = |\sin(\alpha_1 - \alpha_2)|.$$

因此，我们需要距离 $\rho$ 的三角不等式由以下不等式得出：

$$|\sin(\alpha_1 - \alpha_2)| \leq |\sin(\alpha_1 - \alpha_2)| + |\sin(\alpha_2 - \alpha_3)|;$$

(2) 毫无疑问，以下不等式（对于所有$\alpha_1, \alpha_2, \alpha_3$）有效：对于任何$\beta$和$\gamma$

$$|\sin(\beta + \gamma)| = |\sin\beta\cos\gamma + \sin\gamma\cos\beta| \leq |\sin\beta\cos\gamma| + |\sin\gamma\cos\beta| \leq |\sin\beta| + |\sin\gamma|;$$

将$\beta = \alpha_1 - \alpha_2$，$\gamma = \alpha_2 - \alpha_3$放在这里，我们得到（2）。

正如许多读者所注意到的，这些公式和三角计算可以借助距离 $\rho$ 的几何解释来阐明。让我们在平面上在点 $O(y=0)$ 处画一个与坐标线 $Oy$ 相切、直径为 $|OP|=1$ 的圆，对于直线上的每个点 $Y$（坐标为 $y$），我们将线段 $PY$ 的交点 $F=F(y)$ 与该圆 (图 4) 相关联。让$F_1=F(y_1)$，$F_2=F(y_2)$。那么 $\rho(y_1, y_2)$ 就是 dilinah $|F_1F_2|=\sin\beta$。

（从$F_1PF_2=|\alpha_1 - \alpha_2|=\beta$开始，这从（1）中可以立即清楚地看出，但也很容易在几何上建立 - 那么，在右侧，图 4上底长$|y_1-y_2|$和高长1的三角形的面积等于乘积$\sqrt{1+y_1^2}\sqrt{1+y_2^2}\sin\beta$的一半。）现在“三角形不等式”非常印度。
