⟦folio 29⟧

级数$\sum_{k=1}^{\infty} \frac{\sin kx}{k}$是函数$\frac{x}{2}$的傅里叶级数。

傅里叶级数理论 - 形式的无穷和
$$\sum_{k=1}^{\infty} a_k \cos kx + \sum_{k=1}^{\infty} b_k \sin kx$$是数学分析中极其重要且结果丰富的部分。不等式

$$\sum_{k=1}^{n} \frac{\sin kx}{k} > 0$$

（对于任何自然数 $n$ 和 $x \in ]0; \pi[$）由著名匈牙利数学家 Lipót Feyr（1880-1959）证明，他对三角级数理论的发展做出了重大贡献（特别是，他负责提出连续函数在一点发散的傅立叶级数的第一个例子）。

V·斯克沃尔佐夫

**M511。在四边形ABCD内标记有一点M，表明四边形ABMD是平行四边形。证明如果$\overrightarrow{CBM} = \overrightarrow{CDM}$则$\overrightarrow{ACD} = \overrightarrow{BCM}$。

图 4.

让我们执行 $(NC) \parallel (BM)$ 和 $(BN) \parallel MC$ (图 4)。那么四边形$BNCM$和$ANCD$是平行四边形，这意味着$\overrightarrow{NAB} = \overrightarrow{NCB}$和点$A, B, N, C$位于同一个圆上。因此$\overrightarrow{NBC} = \overrightarrow{NAC}$。但是$\overrightarrow{NBC} = \overrightarrow{BCM}$和$\overrightarrow{NAC} = \overrightarrow{ACD}$（四边形$BNCM$和$ANCD$是平行四边形）。因此$\overrightarrow{BCM} = \overrightarrow{ACD}$，这是需要证明的。

**于。米赫耶夫**

让我们基于四边形$ABCD$和$MB'CD'$相似的事实提出这个问题的另一种解决方案；这里$B' = (BM) \cap (DC), D' = (DM) \cap (BC)$。事实上，这些四边形有一个有前途的角度$C$，其余的角度是两两相邻的：$\overrightarrow{A} = \overrightarrow{M}, \overrightarrow{B} = \overrightarrow{B'}, \overrightarrow{D} = \overrightarrow{D'}$。然而，震荡角不足以类似于四边形。现在请注意，三角形 $BD'M$ 和 $DMB'$ 相似。根据这种相似性以及四边形 $ABMD$ 是平行四边形的事实，等式如下

$$\frac{|MB'|}{|AB|} = \frac{|MD'|}{|AD|},$$

由此可以得出四边形$ABCD$和$MB'CD'$的相似性。根据这种相似性，依次得出$\overrightarrow{ACD} = \overrightarrow{MCD'}(= \overrightarrow{MCB})$。

L·利马诺夫

**M512。让$f(x) = x^3 - x + 1$。证明任何自然数 $m > 1$ $m, f(m), f(f(m))$, $f(f(f(m)))$, ... 都是成对互质的。

让我们输入$f_1(x) = x^3 - x + 1$，并为每个$n = 2, 3, \dots, f_n(x) = f(f_{n-1}(x))$。

然后对于每个 $n$ $f_1(0) = f_1(1) = 1$ 和（通过归纳）$f_n(0) = f_n(1) = 1$。因此，具有整数系数的多项式$f_n(x)$的自由项$f_n(0)$等于1。因此，对于任何自然数$n$和整数$a$，数字$f_n(a)$除以$a$时得到余数1。由此可见，对于任意数字 $k > l > 0$ 和 $m$，数字 $f_k(m) = f_{k-1}(f_l(m))$ 除以 $f_l(m)$ 余数为 1，因此 $f_k(m)$ 和 $f_l(m)$ 互质。
