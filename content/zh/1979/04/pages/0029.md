相等 $2^x + 1 = 3^y$ 是不可能的）。所以，$y = 2k, 2^x = 3^{2k} - 1$，即$2^x = (3^k - 1)(3^k + 1)$。由于$x > 1$，因子$3^k - 1$和$3^k + 1$都必须是2的幂（彼此相差2）。这只有通过 $k = 1$ 才能实现。因此$y = 2$，所以$2^x + 1 = 9$，和$x = 3$。

因此，控制 a) 有两个解：(1; 1) 和 (3; 2)。
b) 对照溶液b)将分几个阶段进行。
令$z$有一个素数$p$：$z = p^m z_1, m \geq 1, z_1$和$p$。设 $y = p^n y_1$，其中 $n \geq 0$ 和 GCD $(y_1, p) = 1$。

考虑表达式 $(1 + z)^{y_1}$。我们有：

$$(1 + z)^{y_1} = 1 + y_1 z + C_{y_1}^2 z^2 + \ldots + z^{y_1} =$$

$$= 1 + z \left( y_1 + C_{y_1}^2 z + \ldots + z^{y_1} - 1 \right).$$

由于 $y_1$ 不能被 $p$整除（我们将这样写：$y_1 \neq 0$ (mod $p$)），我们得到

$$(1 + z)^{y_1} = 1 + p^m A,$$ 其中 $A \equiv y_1 z_1$ (mod $p$)。

现在让我们考虑$(1 + z)^y$。让我们证明以下辅助陈述（但是，在某些限制下是正确的）：对于任何自然数$B$

$$(1 + p^i B)^p = 1 + p^{i+1} D(i > 0),$$

与 $B \equiv D$ (mod $p$)。事实上，我们应用牛顿生物群系公式：

$$(1 + p^i B)^p = 1 + C_p^1 \cdot p^i B + C_p^2 \cdot p^{2i} B^2 + \ldots$$

$$\ldots + p^{i_p} B^p = 1 + p^{i+1} B + C_p^2 \cdot p^{2i} B^2 + \ldots + p^{i_p} B^p.$$

容易看出，如果$2i > i + 1$，即$i > 1$，则该命题为真。如果$i = 1$，则$p^{i+1}$的系数将等于$B + C_p^2 B^2$。如果 $p$ 是奇数，则 $C_p^2$ 可被 $p$整除，因此 $B + C_p^2 B^2 \equiv B$ (mod $p$)，否则奇数 $p$ 的陈述在这种情况下也成立。

令$z$有一个奇数素因数$p$。让我们将已证明的陈述应用于表达式 $(1 + z)^y$。我们有：

$$(1 + z)^y = ((1 + z)^{y_1})^{p^n} = (1 + p^m A)^{p^n} =$$

$$= (1 + p^{m+1} A_1)^{p^{n-1}} = \ldots = 1 + p^{m+n} A_n,$$

和$A \equiv A_1 \equiv \ldots \equiv A_n$ (mod $p$)，即$A_n$不能被$p$整除。我们正在寻找控制方案b)：$(1 + z)^y = 1 + z^x$，或$p^{m+n} A_n = p^{mx} z_1^x$。由于 $z_1 \neq 0$ (mod $p$)，必须执行比较 $m + n = mx$。

另一方面，$x \geq y$又很印度。如果$x > y$，则$x > p^n$，因此$m + n > mp^n \geq m (1 + n (p - 1))$，和$n > mn (p - 1)$，这是不可能的。

当 $z$ 没有奇数约数，但能被 4 整除时，也可以类似地分解。因此，如果$x > 0$，则方程b)不能有自然数解$(x; y; z)$，使得$z$能被奇数或4整除。情况$z = 2$在a)部分中分析。仍然要考虑$z = 1$的情况和$x = y$的情况。

如果$z = 1$，我们得到方程$1^x + 1 = 2^y, 2^y = 2$，其中$y = 1$，$x$为任意。

对于$x = y$，我们有：

$$z^x + 1 = (z + 1)^x,$$

那是

$$1 = (z + 1)^x - z^x = [(z + 1) - z] \times$$

$$\times [(z + 1)^{x-1} + (z + 1)^{x-2} z + \ldots + z^{x-1}] =$$

$$= (z + 1)^{x-1} + (z + 1)^{x-2} z + \ldots + z^{x-1} \geq x.$$

因此，$x = y = 1$，$z$是任意的。
