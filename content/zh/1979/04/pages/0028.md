M508。与直径为 [AB]、[BC] 和 [AC] 的三个半圆相切的圆 (Сε[AB], 图 1)。让我们证明输入圆的半径小于圆心到辣AB的距离。

设$O_1$为直径为[AC]的半圆$\gamma_1$的圆心，$O_2$为直径为[BC]的半圆$\gamma_2$的圆心，$O_3$为直径为[AB]的半圆$\gamma_3$的圆心，最后$O$为与这三个数据相切的圆$\gamma$的圆心半圆（图1）。让我们表示圆的半径长度$\gamma_1, \gamma_2$和$\gamma$，对应于$r$、$R$和$x$。那么半圆$\gamma_3$的半径长度等于$R + r$。

考虑三角形$O_1OO_2$。我们有：$|O_1O| = r + x$、$|OO_2| = R + x$、$|O_1O_2| = R + r$。让我们用$h$表示从中心$O$到辣AB的距离。用海伦公式写出三角形$O_1OO_2$的面积，并通过底边$[O_1O_2]$的长度和从顶点$O$落下的高度，我们得到方程

$$\sqrt{Rrx(R + r + x)} = \frac{1}{2}(R + r)h.$$

三角形 $O_1OO_3$ 的类似方程具有以下形式

$$\sqrt{rx(R + r)(R - r)} = \frac{1}{2}Rh.$$

通过将一般方程的左侧和右侧平方，然后从一个方程减去另一个方程，我们得到

$$rx[R(R + r + x) - (R + r)|(R - r)] = \frac{1}{4}h^2[(R + r)^2 - R^2],$$

$x^2 = h^2/4$，即$x = h/2$，这就是所需要的。

如果我们应用反演，这个问题可以得到更彻底的解决（关于反演及其性质，参见“Quant” - 1974，No.1，p.16，1976，No.2，p.34，1977，No.6，p.38）。

让我们相对于以点 $C$ 为圆心的任意圆反转 $I$。通过此反转，圆 $\gamma_1, \gamma_2, \gamma_3$ 和 $\gamma$ 变换为 图 2 所示：圆 $\gamma_1$ 和 $\gamma_2$ 将相应地变换为垂直于 [AB] 的直线 $l_1$ 和 $l_2$，以及圆 $\gamma_3$ 和 $\gamma'$，对应的直线$l_1$和$l_2$，圆心$\gamma'$属于辣AB（这条线在图1和图2中以红色突出显示）。

很容易报告，圆$\gamma$和$\gamma' = I(\gamma)$是以制备中心$C$制备的。从图3可以看出：圆$\gamma$的切线经过点$C$，反转后，$I$变成自身并与圆$\gamma' = I(\gamma)$相切。让我们用$x'$表示圆$\gamma'$的半径，用$d$表示从圆心$\gamma'$到辣AB的距离。由于$\gamma$和$\gamma'$煮熟，我们就有了$h/d = x/x'$（h是$\gamma$圆心到辣AB的距离，x是$\gamma$的半径）。但是，显然，$x' = d/2$（圆$\gamma'$和$\gamma'_3$的半径相同，请参见图2），所以$x = h/2$，这就是所需要的。
