M508。与直径为 [AB]、[BC] 和 [AC] 的三个半圆相切的圆 (Сε[AB], 图 1)。让我们证明输入圆的半径小于圆心到辣AB的距离。

图 2.

图 3.

设$O_1$为直径为[AC]的半圆$\gamma_1$的圆心，$O_2$为直径为[BC]的半圆$\gamma_2$的圆心，$O_3$为直径为[AB]的半圆$\gamma_3$的圆心，最后$O$为与这三个数据相切的圆$\gamma$的圆心半圆（图1）。让我们表示圆的半径长度$\gamma_1, \gamma_2$和$\gamma$，对应于$r$、$R$和$x$。那么半圆$\gamma_3$的半径长度等于$R + r$。

考虑三角形$O_1OO_2$。我们有：$|O_1O| = r + x$、$|OO_2| = R + x$、$|O_1O_2| = R + r$。让我们用$h$表示从中心$O$到辣AB的距离。用海伦公式写出三角形$O_1OO_2$的面积，并通过底边$[O_1O_2]$的长度和从顶点$O$落下的高度，我们得到方程

$$\sqrt{Rrx(R + r + x)} = \frac{1}{2}(R + r)h.$$

三角形 $O_1OO_3$ 的类似方程具有以下形式

$$\sqrt{rx(R + r)(R - r)} = \frac{1}{2}Rh.$$

通过将一般方程的左侧和右侧平方，然后从一个方程减去另一个方程，我们得到

$$rx[R(R + r + x) - (R + r)|(R - r)] = \frac{1}{4}h^2[(R + r)^2 - R^2],$$

$x^2 = h^2/4$，即$x = h/2$，这就是所需要的。

如果我们应用反演，这个问题可以得到更彻底的解决（关于反演及其性质，参见“Quant” - 1974，No.1，p.16，1976，No.2，p.34，1977，No.6，p.38）。

让我们相对于以点 $C$ 为圆心的任意圆反转 $I$。通过此反转，圆 $\gamma_1, \gamma_2, \gamma_3$ 和 $\gamma$ 变换为 图 2 所示：圆 $\gamma_1$ 和 $\gamma_2$ 将相应地变换为垂直于 [AB] 的直线 $l_1$ 和 $l_2$，以及圆 $\gamma_3$ 和 $\gamma'$，对应的直线$l_1$和$l_2$，圆心$\gamma'$属于辣AB（这条线在图1和图2中以红色突出显示）。

很容易报告，圆$\gamma$和$\gamma' = I(\gamma)$是以制备中心$C$制备的。从图3可以看出：圆$\gamma$的切线经过点$C$，反转后，$I$变成自身并与圆$\gamma' = I(\gamma)$相切。让我们用$x'$表示圆$\gamma'$的半径，用$d$表示从圆心$\gamma'$到辣AB的距离。由于$\gamma$和$\gamma'$煮熟，我们就有了$h/d = x/x'$（h是$\gamma$圆心到辣AB的距离，x是$\gamma$的半径）。但是，显然，$x' = d/2$（圆$\gamma'$和$\gamma'_3$的半径相同，请参见图2），所以$x = h/2$，这就是所需要的。

M509。方程的自然数解：
a) $2^x + 1 = 3^y$;
b) $z^x + 1 = (z + 1)^2$;
c) $z^x + 1 = (z + 1)^y$.

很容易看出，方程 a) 和 b) 分别是方程 b) 对于 $z = 2$ 和 $y = 2$ 的特例。我们将单独考虑情况 a)，然后求解方程 b)。
a) 如果$x = 1$，则$y = 1$。
让$x > 1$。然后$2^x + 1 \equiv 1$ (mod 4)，这意味着$y$是偶数（如果$y$是奇数，则$3^y \equiv 3$ (mod 4)，并且

相等 $2^x + 1 = 3^y$ 是不可能的）。所以，$y = 2k, 2^x = 3^{2k} - 1$，即$2^x = (3^k - 1)(3^k + 1)$。由于$x > 1$，因子$3^k - 1$和$3^k + 1$都必须是2的幂（彼此相差2）。这只有通过 $k = 1$ 才能实现。因此$y = 2$，所以$2^x + 1 = 9$，和$x = 3$。

令$z$有一个素数$p$：$z = p^m z_1, m \geq 1, z_1$和$p$。设 $y = p^n y_1$，其中 $n \geq 0$ 和 GCD $(y_1, p) = 1$。

考虑表达式 $(1 + z)^{y_1}$。我们有：

$$(1 + z)^{y_1} = 1 + y_1 z + C_{y_1}^2 z^2 + \ldots + z^{y_1} =$$

$$= 1 + z \left( y_1 + C_{y_1}^2 z + \ldots + z^{y_1} - 1 \right).$$

自从 $y_1$ 不能被整除 $p$ （我们会这样写： $y_1 \neq 0$ (mod $p$）），我们得到

$$(1 + z)^{y_1} = 1 + p^m A,$$ 其中 $A \equiv y_1 z_1$ (mod $p$)。

现在让我们考虑$(1 + z)^y$。让我们证明以下辅助陈述（但是，在某些限制下是正确的）：对于任何自然数$B$

$$(1 + p^i B)^p = 1 + p^{i+1} D(i > 0),$$

与 $B \equiv D$ (mod $p$)。事实上，我们应用牛顿生物群系公式：

$$(1 + p^i B)^p = 1 + C_p^1 \cdot p^i B + C_p^2 \cdot p^{2i} B^2 + \ldots$$

$$\ldots + p^{i_p} B^p = 1 + p^{i+1} B + C_p^2 \cdot p^{2i} B^2 + \ldots + p^{i_p} B^p.$$

It is easy to see that if $2i > i + 1$, that is, $i > 1$, then the statement is true. If $i = 1$, then the coefficient of $p^{i+1}$ will be equal to $B + C_p^2 B^2$.如果 $p$ 是奇数，则 $C_p^2$ 可被 $p$整除，因此 $B + C_p^2 B^2 \equiv B$ (mod $p$)，否则奇数 $p$ 的陈述在这种情况下也成立。

令$z$有一个奇数素因数$p$。让我们将已证明的陈述应用于表达式 $(1 + z)^y$。我们有：

$$(1 + z)^y = ((1 + z)^{y_1})^{p^n} = (1 + p^m A)^{p^n} =$$

$$= (1 + p^{m+1} A_1)^{p^{n-1}} = \ldots = 1 + p^{m+n} A_n,$$

和$A \equiv A_1 \equiv \ldots \equiv A_n$ (mod $p$)，即$A_n$不能被$p$整除。我们正在寻找控制方案b)：$(1 + z)^y = 1 + z^x$，或$p^{m+n} A_n = p^{mx} z_1^x$。由于 $z_1 \neq 0$ (mod $p$)，必须执行比较 $m + n = mx$。

另一方面，$x \geq y$又很印度。如果$x > y$，则$x > p^n$，因此$m + n > mp^n \geq m (1 + n (p - 1))$，和$n > mn (p - 1)$，这是不可能的。

当 $z$ 没有奇数约数，但能被 4 整除时，也可以类似地分解。因此，如果$x > 0$，则方程b)不能有自然数解$(x; y; z)$，使得$z$能被奇数或4整除。情况$z = 2$在a)部分中分析。仍然要考虑$z = 1$的情况和$x = y$的情况。

如果$z = 1$，我们得到方程$1^x + 1 = 2^y, 2^y = 2$，其中$y = 1$，$x$为任意。

对于$x = y$，我们有：

$$z^x + 1 = (z + 1)^x,$$

那是

$$1 = (z + 1)^x - z^x = [(z + 1) - z] \times$$

$$\times [(z + 1)^{x-1} + (z + 1)^{x-2} z + \ldots + z^{x-1}] =$$

$$= (z + 1)^{x-1} + (z + 1)^{x-2} z + \ldots + z^{x-1} \geq x.$$

因此，$x = y = 1$，$z$是任意的。

**M511。 Inside the quadrilateral ABCD a point M is marked indicating that the quadrilateral ABMD is a parallelogram.证明如果$\overrightarrow{CBM} = \overrightarrow{CDM}$则$\overrightarrow{ACD} = \overrightarrow{BCM}$。

图 4.

让我们执行 $(NC) \parallel (BM)$ 和 $(BN) \parallel MC$ (图 4)。 Then the quadrilaterals $BNCM$ and $ANCD$ are parallelograms, which means that $\overrightarrow{NAB} = \overrightarrow{NCB}$ and the points $A, B, N, C$ lie on the same circle.因此$\overrightarrow{NBC} = \overrightarrow{NAC}$。 But $\overrightarrow{NBC} = \overrightarrow{BCM}$, and $\overrightarrow{NAC} = \overrightarrow{ACD}$ (quadrilaterals $BNCM$ and $ANCD$ are parallelograms). Therefore $\overrightarrow{BCM} = \overrightarrow{ACD}$, which is what needed to be proven.

Let us present another solution to this problem, based on the fact that the quadrilaterals $ABCD$ and $MB'CD'$ are similar;这里$B' = (BM) \cap (DC), D' = (DM) \cap (BC)$。 Indeed, these quadrilaterals have a promising angle $C$, and the remaining angles are pairwise contiguous: $\overrightarrow{A} = \overrightarrow{M}, \overrightarrow{B} = \overrightarrow{B'}, \overrightarrow{D} = \overrightarrow{D'}$. However, concussive angles are not enough to resemble quadrilaterals. Note now that the triangles $BD'M$ and $DMB'$ are similar. From this similarity and the fact that the quadrilateral $ABMD$ is a parallelogram, the equality follows

$$\frac{|MB'|}{|AB|} = \frac{|MD'|}{|AD|},$$

由此已经得出四个区的相似性 $ABCD$ 和 $MB'CD'$。从这种相似性可以看出 $\overrightarrow{ACD} = \overrightarrow{MCD'}(= \overrightarrow{MCB})$.

**M512。让$f(x) = x^3 - x + 1$。证明任何自然数 $m > 1$ $m, f(m), f(f(m))$, $f(f(f(m)))$, ... 都是成对互质的。

让我们输入$f_1(x) = x^3 - x + 1$，并为每个$n = 2, 3, \dots, f_n(x) = f(f_{n-1}(x))$。

Then $f_1(0) = f_1(1) = 1$ and (by induction) $f_n(0) = f_n(1) = 1$ for each $n$.因此，具有整数系数的多项式$f_n(x)$的自由项$f_n(0)$等于1。因此，对于任何自然数$n$和整数$a$，数字$f_n(a)$除以$a$时得到余数1。由此可见，对于任意数字 $k > l > 0$ 和 $m$，数字 $f_k(m) = f_{k-1}(f_l(m))$ 除以 $f_l(m)$ 余数为 1，因此 $f_k(m)$ 和 $f_l(m)$ 互质。
