通勤多项式

来自编辑
一般来说，向学童提供的数学问题要么与新结果非常间接相关，要么涉及他们的个人细节，不允许他们看到全貌。发生这种情况的原因可能是，在数学中，一切都是相互关联的，并且通常，为了充分理解甚至是一个完全基本的问题，人们必须利用来自非基本数学领域的信息。
与本文相关的多项式交换问题被认为是一个例外：在这里，仅使用基本方法就可以相当接近一般数学兴趣的问题。
我们从两年前 E. Turkevich 写给«Kvant»的一封信中了解到这个问题，他在这里写下了第一个结果。该问题补充了某些要点，在世界奥林匹克竞赛第十一类研究中提出，并置于问题«Kvant»（M455）中。

问题表述
一个变量中的多项式 $P$ 和 $Q$ 称为交换 *) 如果 $P(Q(x)) = Q(P(x))$。书面等式的意思是，如果在等式两边打开所有括号并添加相似的项，那么我们将得到相同的多项式。这相当于对于任何实数$d$，数值相等$P(Q(d)) = Q(P(d))$成立。

*) 源自拉丁语 commutativus - 改变。

赋值 M455 仅考虑首项系数为 1 的多项式；我们将这样的多项式称为酉多项式。 （正如我们将在下面看到的，任意交换多项式的问题可以简化为首项系数等于±1的多项式的问题。）

a) 对于任何数字$\alpha$，找到所有与多项式$P(x) = x^2 - \alpha$交换的次数最多为三的多项式。

b) 证明至多有一个给定次数的多项式与给定的二阶多项式$P$可交换。

b) 找到与给定的二阶多项式$P$可交换的所有四阶和八阶多项式。

d) 证明如果两个多项式$Q$和$R$与某个二阶多项式$P$可交换，则它们彼此可交换。

d) 证明存在大量相互交换的多项式$P_1, P_2, \dots, P_h, \dots$，且多项式$P_h$的次数等于$k$和$P_2(x) = x^2 - 2$。

解决问题a)—d)

a) 设 $Q(x) = x^3 + ax^2 + bx + c$。让我们写下等式$P(Q(x)) = Q(P(x))$：
$x^3 + ax^2 + bx + c)^2 - \alpha = (x^2 - \alpha)^3 + a(x^2 - \alpha)^2 + b(x^2 - \alpha) + c$.

在打开括号之前，请注意，右侧只有 4 次方$x$，$x^5$ 处的微量系数等于 2a。所以，$a = 0$。但$x^3$的微量系数等于2c，所以$c = 0$也等于2c。因此$Q(x) = x^3 + bx$。打开括号并使系数相等，我们得到系统
$$\begin{cases} 2b = -3\alpha, \\ b^2 = 3\alpha^2 + b, \\ \alpha = \alpha^3 + b\alpha. \end{cases}$$

让$\alpha = 2\gamma$，然​​后$b = -3\gamma$。根据第二个方程$9\gamma^2 = 12\gamma^2 - 3\gamma$，即$\gamma^2 - \gamma = 0$。所以，$\gamma = 0$或$\gamma = 1$。很容易检查这两种解决方案是否合适。

因此，与多项式$P(x) = x^2 - \alpha$交换的三阶多项式$Q$仅存在于$\alpha = 0$（$P(x) = x^2$，$Q(x) = x^3$）和$\alpha = 2$（$P(x) = x^2 - 2$，$Q(x) = x^3 - 3x$）。

同样证明，如果$Q$的次数等于2，则$Q = P$，如果等于1，则$Q(x) = x$。

这一点很简单。它是在奥林匹克竞赛中送给小学生的，以便他们更好地了解任务的条件并稍微习惯它。此外，如果你仔细理解了写出的方程，那么就会产生一个关于如何解决第 6) 点的想法 - 这是问题的关键点之一。

6) 令$Q(x) = x^k + a_1x^{k-1} + a_2x^{k-2} + \dots + a_{k-1}x + a_k$，$P(x) = x^2 + px + q$。让我们写下等式$(x^k + a_1x^{k-1} + \dots + a_k)^2 + p(x^k + \dots + a_k) + q - (x^2 + px + q)^k - a_1(x^2 + px + q)^{k-1} - \dots - a_k = 0$。

将 $x^{2k}$、$x^{2k-1}$、...、$x$、$x^0$ 处的系数等于零，我们得到 $a_1$、$a_2$、...、$a_k$、$p$、$q$ 的方程组。解决这个系统甚至简单地写下来都是相当困难的。然而，很容易注意到幂 $x^{2k-1}$、$x^{2k-2}$、...、$x^k$ 的系数$b_1$、$b_2$、...、$b_k$ 具有以下形式：

$$b_1 = 2a_1 + R_1(p, q) = 0,$$
$$b_2 = 2a_2 + R_2(p, q, a_1) = 0,$$
$$b_k = 2a_k + R_k(p, q, a_1, \dots, a_{k-1}) = 0.$$

这里 $R_i$ 是$p$、$q$、$a_1$、...、$a_{i-1}$ 的一些代数表达式。从第一个方程可知，$a_1$通过$p$和$q$表示；从第二个开始 - $a_2$通过$p$，$q$和$a_1$表达，因此通过$p$和$q$表达，...所以，我们看到所有系数$a_1$，...，$a_k$都通过$p$表达， $q$，即与$P$交换的多项式$Q$的系数，唯一地用$p$和$q$表示，这就是需要证明的。

很容易验证，对于任何多项式$P$，只要其次数大于1（且$Q$是酉），都可以验证类似的推理，即第6段中的陈述对于任何多项式都成立。

第 6) 点是任务的关键。由此很容易得出 c) 和 d) 点。

c) 让我们证明多项式 $Q(x) = P(P(x))$ 与 $P$ 交换。确实，$Q(P(x)) = P(Q(x))$。多项式 $Q$ 具有四次，并且根据 6) 是唯一与 $P$ 交换的该次数的多项式。类似地，证明了唯一与$P$可交换的8次多项式是$R(x) = P(P(x))$。

d) 设 $S(x) = Q(R(x))$ 和 $T(x) = R(Q(x))$。由于$P$与$Q$和$R$交换，那么$P(S(x)) = P(Q(R(x))) = Q(P(R(x))) = Q(R(P(x))) = S(P(x));$意味着$P$与多项式$S$交换。类似地，验证了$P$与多项式$T$可交换。此外，显然$S$和$T$是同次酉多项式（如果$Q$和$R$的次数为$k$和$l$，则多项式$S$和$T$的次数为$kl$）。从6)可以得出$S = T$，即$Q(R(x)) = R(Q(x))$，这就是所要求的。

与第 6 点相同，如果 $P$ 是任何大于 1 次的多项式，且 $Q$ 和 $R$ 是酉，则该命题仍然成立。

第一种方式。让$x = t + t^{-1}$。那么很容易检查 $x^k$ 具有以下形式

$$x^k = (t + t^{-1})^k = (t^k + t^{-k}) + a_1(t^k - 1 + t^{-(k-1)}) + a_2(t^k - 2 + t^{-(k-2)}) + \dots + a_{k-1}(t + t^{-1}) + a_k,$$

其中 $a_1$, ..., $a_k$ 是一些固定数字。通过对 $k$ 的归纳，$t^k + t^{-k}$ 可以表示为

$$x^k + b_1x^{k-1} + \dots + b_{k-1}x + b_k,$$

其中 $b_1$, ..., $b_k$ 是一些固定数字。让我们将多项式 $x^k + b_1x^{k-1} + \dots + b_k$ 表示为

通勤多项式问题

我们想讨论与以下问题相关的问题：描述所有交换（不一定是酉）多项式$P$和$Q$对。

问题 1. 证明两个一次多项式 $P$ 和 $Q$ 可交换当且仅当 $P(x)=x+\alpha$、$Q(x)=x+\beta$ 或存在 $x_0$ 使得 $P(x_0)=Q(x_0)=x_0$（公共“固定”点）。

问题2. 求解当多项式$P$、$Q$之一的次数等于1时的情况的一般问题。

接下来，我们假设多项式$P$和$Q$的次数大于1。

令$P(x)=a_0x^k+a_1x^{k-1}+\cdots+a_{k-1}x+a_k$，$Q(x)=b_0x^e+\cdots+b_{e-1}x+b_e$。首先，我们证明我们可以将一般问题简化为系数 $a_1$ 和 $b_1$ 等于 0 的情况（这种类型的多项式称为*约化*）。为此，我们将使用以下操作。让我们固定数字$a$，并使用它通过公式$R^{(a)}(x)=R(x-a)+a$从每个多项式$R$构造一个新的“匹配”多项式$R^{(a)}$。显然，多项式$R$可以由多项式$R^{(a)}:R(x)=R^{(a)}(x+a)-a$重构。

问题 3. a) 证明如果多项式 $P$ 和 $Q$ 可交换，则 $P^{(a)}$ 和 $Q^{(a)}$ 也可交换。

6) 证明任意一对大于 1 次的交换多项式 $P$ 和 $Q$ 的形式为 $P=S^{(a)}$、$Q=T^{(a)}$，其中 $a$ 是某个数字，$S$ 和 $T$ 是交换归约多项式。

接下来我们假设给出多项式$P$和$Q$。另外，我们假设它们是酉的，即它们的首项系数等于1。显然，这是最有趣的特例。此外，通过与上述类似的推理，表明可以将一般问题简化为当多项式$P$和$Q$的首项系数等于±1时的情况，因此这种特殊情况与一般情况没有太大区别（在这些论证中，有必要使用“拉伸”操作，将每个多项式$R$与多项式相关联$R^{\lambda}$ 根据公式$R^{\lambda}(x)=\lambda R(x/\lambda)$）。让我们描述几个系列的交换多项式：

1. 令 $R$ 为$r$ 次多项式。考虑一系列多项式 $P_0(x)=x$、$P_1(x)=R(x)$、$P_2(x)=R(R(x))$、$P_3(x)=R(R(R(x)))$（一般为 $P_{i+1}(x)=P_i(R(x))$）。

显然，所有多项式 $P_i$ 都可交换，并且多项式 $P_i$ 的次数等于 $r^i$。

2. 多项式级数$F_k(x) = x^k$。所有多项式 $F_k$ 都可交换，并且多项式 $F_k$ 的次数为 $k$。

3. $\{P_k\}$ 是求解 e) 部分���题 M455 时构造的一系列多项式。这些多项式由条件 $P_k(t + t^{-1}) = t^k + t^{-k}$ 确定。多项式$P_k$的次数为$k$。

4. 让我们通过以下条件定义多项式系列 $H_1, H_3, H_5, \dots$：$H_k(t - t^{-1}) = t^k - t^{-k}$（k 奇数）。很容易验证这样的多项式存在并且由所写条件唯一确定。所有这些多项式都可交换，并且多项式$H_k$的次数等于$k$。

事实上，示例 3 和示例 4 是更一般示例的仆人的特例。为了描述这个一般示例，我们对多项式的系数进行评论。到目前为止，我们假设这些系数是实数。然而，在大多数代数问题中，最好使用复数。因此，我们假设多项式的系数可以是任何复数。

5. 我们固定一个自然数$m$和一个复数$\lambda$，使得$\lambda^m = 1$（对于每个$m$，都有一个不同于1的$m - 1$数）。

考虑数字对$(u, v)$使得$u.v = \lambda$，并放入$x = u + v$。很容易检查$u^k + v^k = x^k + a_1x^{k-1} + \dots + a_k$（其中$a_1, \dots, a_k$是一些数字）取决于$\lambda$。让我们输入 $P_k(x) = x^k + a_1x^{k-1} + \dots + a_k$；多项式 $P_k$ 的特征在于以下条件：$P_k(u + v) = u^k + v^k$ if $uv = \lambda$。

令 $l$ 为除以$m$ 余数为 1 的数。然后$u^lv^l = (uv)^l = \lambda^l = \lambda$，所以$P_k(u^l + v^l) = u^{kl} + v^{kl}$。因此，如果$k$和$l$除以$m$余数为1，则$P_k(P_l(u + v)) = u^{kl} + v^{kl} = P_l(P_k(u + v))$，即多项式$P_k$和$P_l$可交换。基于数字$\lambda$，我们构造了一系列交换多项式$P_1, P_{m+1}, P_{2m+1}$，……。所有这些多项式都是酉的、约化的，且次数 $P_k$ 等于 $k$。

对于 $m = 1$，$\lambda = 1$，我们得到示例 3，对于 $m = 2$，$\lambda = -1$，我们得到示例 4。

示例 1-5 穷举了所有已知的可交换多项式的示例，因此我们可以假设，如果 $P$ 和 $Q$ 是具有复系数的次数大于 1 的可交换酉约化多项式，则它们包含在示例 1、2、5 中构造的级数之一中。

在不解决总体问题的情况下，可以尝试回答一些局部问题：

1. 对于 $\alpha$，多项式 $P(x) = x^2 - \alpha$ 与某个奇数次多项式可交换。

2. 令 $P$ 为次数大于 1 的酉多项式。让我们记下所有与 $P$ 交换的酉多项式 $Q$ 的次数。这会产生自然数的哪个子集？

例如，在示例 1 中，这是一个几何级数；在示例 5 中 - 算术。

3. 令 $P, Q$ 为$k$ 和 $l$ 次的交换酉多项式。假设$l$能被$k$整除。 $Q$ 是否具有 $Q(x) = P(R(x))$ 形式，其中 $R$ 是与 $P$ 交换的酉多项式？

您可以形成一个更一般的问题 - 找到所有通勤有理函数 $P$ 和 $Q$。在这种情况下，出现了许多新的有趣的例子。

我们在多项式 e) 点的解中讨论的一般方法也适用于此。设一个函数 $f$ （取无限多个值）使得

$$f(nt) = P_n(f(t)),$$

其中 $P_n$ 是有理函数。然后对于不同的$n$和$m$，函数$P_n$和$P_m$进行通勤。

一个有趣的问题出现了：对于什么函数$f$，对于任何$n$，我们可以选择一个有理函数$P_n$，使得$P_n(f(t)) = f(nt)$。例如，很容易检查函数$f(t) = tg t$是否满足这个条件。

使用椭圆函数理论可以构造函数 $f$ 的其他示例。由于这不是一个基本理论，因此我们不会在这里描述相应的结构。

所有这些例子都表明，描述交换多项式（更一般地说，交换有理函数）的问题与非常深刻和丰富的数学理论直接相关。这个问题的解决方案显然会揭示一些新的、以前未知的事实。简而言之，这是一项值得承担的任务。
