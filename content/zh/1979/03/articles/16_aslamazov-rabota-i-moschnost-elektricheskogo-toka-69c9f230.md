电流的功和功率

当电荷$q$在电场中移动时，做功$A = q(\varphi_1 - \varphi_2) = qU$，

其中$U = \varphi_1 - \varphi_2$是电荷初始位置和最终位置之间的电势差。电流是电荷的定向运动。在时间$t$期间，电荷$q = It$穿过导体的横截面，导体沿该横截面流动，电流$I$流过该横截面。因此，电流在导体中所做的总功等于

$$A = qU = UIt.$$

这为我们提供了众所周知的总电流功率公式：

$$P = UI.$$

导体中电流产生的热量由焦耳-楞次定律确定：

$$Q = I^2Rt.$$

因此，热损失功率由以下公式确定：

$$P_T = I^2R.$$

对于欧姆定律$U = IR$成立的普通导体，公式（1）和（2）是等价的，因此，电流的所有功都转化为热量。在这种情况下，对于功率，您还可以使用以下公式：

$$P = P_T = \frac{U^2}{R}.$$

优选使用由问题的恒定特异性确定的公式(1)、(2)和(3)中的任何一个。

问题1. 两个灯泡，扩展为打开七个，电压为$U = 220$ V，功率分别为$P_1 = 25$ W 和$P_2 = 100$ W。如果将其中七个串联连接，哪个灯泡会更亮？

求普通（单个）和顺序打开时每个灯泡的亮度比。

考虑到亮度与灯泡中释放的小功率成正比。

当灯泡串联时，相同的电流流过它们。因此，为了比较分配给它们的容量，使用公式（2）更为方便：

$$\frac{P'_1}{P'_2} = \frac{I^2R_1}{I^2R_2} = \frac{R_1}{R_2}.$$

为了找到电阻比，我们填写公式（3），因为已知的额定功率$P_1$和$P_2$对应于灯泡上相同的电压$U$：

$$\frac{P_1}{P_2} = \frac{U^2/R_1}{U^2/R_2},$$ 和 $$\frac{R_1}{R_2} = \frac{P_2}{P_1}.$$

由此我们得到：

$$\frac{P'_1}{P'_2} = \frac{P_2}{P_1} = 4$$

- 25 W 灯泡串联打开时，亮度会增加 4 倍。

让我们比较一下普通（单个）和顺序打开时每个灯泡释放的热功率。在第一种情况下

$$P_1 = \frac{U^2}{R_1}$$ 和 $$P_2 = \frac{U^2}{R_2}.$$

从这里您可以找到灯泡的电阻$R_1$和$R_2$：

$$R_1 = \frac{U^2}{P_1}$$ 和 $$R_2 = \frac{U^2}{P_2}.$$

当灯泡串联时，电流$I = \frac{U}{R_1 + R_2}$流过它们。灯泡释放的功率可用公式（2）求得：

$$P_1' = \frac{U^2 R_1}{(R_1 + R_2)^2} \text{ и } P_2' = \frac{U^2 R_2}{(R_1 + R_2)^2}.$$

然后我们得到功率比：

$$\frac{P_1}{P_1'} = \left(1 + \frac{P_1}{P_2}\right)^2 = \frac{25}{16} \text{ и } \frac{P_2}{P_2'} = \left(1 + \frac{P_2}{P_1}\right)^2 = 25$$

- 串联打开时，两个灯泡的亮度都降低了，但第二个灯泡的功率降低了 16 倍。

当电路的一段有电动势源$\&$时，总功率和热损耗功率的表达式（式（1）和（2））等效，因此能量平衡中必须考虑外力$\& It$的功。在这种情况下，该部分中的方向 $U$ 与 EMF $\&$ 的不同之处在于方向 $IR$ 的大小：

$$U = \& \pm IR$$

（“减”号是指截面中的电流方向与电动势产生的电流方向一致的情况，“加”号是指相反的情况）。对应，总电流功率$U_1$不等于热功率$I^2 R$：

$$U_1 = \& I \pm I^2 R.$$

现在我们来讨论一下通过电线长距离传输能量时的热损失问题。众所周知，为了最大限度地减少热损失，在传输线路中使用高电压。传输电压$U$不要混淆——电源线导线之间的电位差和线路$\Delta U = IR$上的压降，它与流过导线的电流$I$和线路电阻$R$相关。通过电线传输的功率为$P = UI$，热量损失为$P_T = I^2 R = \frac{\Delta U^2}{R}$。然而，如果提高传输电压$U$，则可以用更少的电流传输相同的功率$P$。在这种情况下，线路 $\Delta U$ 中的电压降和热损失 $P_T$ 都会减少。
