不失一般性，我们可以假设$0 < a \leq b \leq c \leq d$。添加另外三个不等式
$$a(a-b)(a-c)(a+2d) \geq 0,$$
$$a(a-b)(a+2c)(a-d) \geq 0,$$
$$a(a+2b)(a-c)(a-d) \geq 0,$$
我们得到
$$3a^4 - 3a^2(bc + bd + cd) + 6abcd \geq 0,$$
或者
$$a^4 - a^2(bc + bd + cd) + 2abcd \geq 0.$$

另一方面，不平等
$$b^4 + c^4 + d^4 - a^2(b^2 + c^2 + d^2 - bc - bd - cd) - b^2c^2 - b^2d^2 - c^2d^2 \geq 0$$
相当于下一个
$$[(b+c)^2 - a^2](b-c)^2 + [(b+d)^2 - a^2](b-d)^2 + [(c+d)^2 - a^2](c-d)^2 \geq 0.$$

将不等式（1）和（2）相加，我们就得到了问题的描述。
让我们用数学分析来解决这个问题。我们需要以下几何估计
引理。如果函数$f$在循环$[x_0; +\infty[$的每个点都是非负任意的，那么它在这个循环上是非递减的。
请注意，如果任意两个数字 $a, b, c, d$ 重合，则不等式证明成立。事实上，让我们直接，$a = d$。那么我们的不等式可以重写如下：
$$a^4 + 2(bc - b^2 - c^2)a^2 + b^4 + c^4 - b^2c^2 \geq 0.$$

不等式(3)的左边是关于$a^2$的二次三项式，具有非正判别$-2bc(b-c)^2$，因此(3)是有效的。

现在让我们以这种形式重写所需的不等式：
$$d^4 - (a^2 + b^2 + c^2)d^2 + 2abcd + a^4 + b^4 + c^4 - a^2b^2 - a^2c^2 - b^2c^2 \geq 0$$

并将 (4) 的左侧视为 $d$ 的函数；我们用 $f$ 来表示这个函数。我们需要证明$f(d) \geq 0$对于$d \geq c$（和$0 < a \leq b \leq c$）。我们有：
$$f'(d) = 4d^3 - 2(a^2 + b^2 + c^2)d + 2abc,$$
所以$f'(c) = 2c^3 - 2(a^2 + b^2)c + 2abc \geq 0 (0 < a \leq b \leq c)$。
下一个，
$$f''(d) = 12d^2 - 2(a^2 + b^2 + c^2) \geq 0$$

在$0 < a \leq b \leq c$。因此，通过引理 $f'(d) \geq f'(c) \geq 0$ $d \geq c$。利用$f(c) \geq 0$（见上面的注释）和$f'(d) \geq 0$代表$d \geq c$这一事实，并再次应用引理，我们得到了$d \geq c$的不等式$f(d) \geq 0$，这就是所需要的。

F. Schleöfer (Ryazan) 发明了这种不等式的有趣概括：对于任意 $a_1, \dots, a_n$
$(n-1)(a_1^2 + a_2^2 + \dots + a_n^2) + n\sqrt{a_1^2 \cdot a_2^2 \cdot \dots \cdot a_n^2} \geq (a_1 + a_2 + \dots + a_n)^2$.

对于$n=4$、$a_1=a^2$、$a_2=b^2$、$a_3=c^2$、$a_4=d^2$，我们获得了问题的陈述。

6) 让我们考虑一个更普遍的问题：令 $a_1 < a_2 < \dots < a_k \leq B$ 为自然数序列；让我们尝试估计 $max (a_i, a_j)$ 的强度。为此，反演问题很有用：令 $A, B$ 为正数（不一定是整数）；确定最大 $k$，其中存在一系列 $k$ 不同自然数 $a_1, a_2, \dots, a_k$ 最大值，使得
(1) 序列中哪个元素不超过$B$；
(2) $(a_i, a_j) \leq A$ 对于任何不同的元素$a_i, a_j$。
我们将用 $k (A, B)$ 表示这个最大数量。为了解决原来的问题，你需要选择$A$，使得$k (A, 2n)$约等于$n$。事实上，如果对于每个 $A$
$$k (A, 2n) < n,$$
那么对于任何序列$a_1 < a_2 < \dots < a_n \leq 2n$都会有
$$max (a_i, a_j) > A;$$
如果$k (A, 2n) \ge n$，则存在序列$a_1 < a_2 < \dots < a_n \leq 2n$使得
$$max (a_i, a_j) \leq A.$$
令$a_1, \dots, a_k$为满足条件(1)和(2)的序列。如果该序列的某个元素 $a_i$ 的除数 $d > A$ 与 $a_i$ 不同，则根据条件 (2) $d$ 不是该序列的元素。然后，替换

现在让我们考虑所有不超过$B$且没有大于$A$的真约数的自然数的集合$M$。 M是满足条件(1)和(2)的不可约序列，并且所有其他不可约序列都包含在$M$中。因此很明显$k(A, B)$简单地等于元素数量$M$。

为了统计集合$M$的元素个数，我们分别计算四个元素的个数、能被3整除的奇数元素的个数等。更准确地说，让$M_2$包含集合$M$的所有四个元素，$M_3$包含$M$可被3整除的所有四个元素，$M_5$包含所有四个元素$M$，可被 5 整除，但不能被 2 或 3 整除。一般来说，对于任何素数 $p$，集合 $M_p$ 由集合 $M$ 中可被 $p$ 整除且没有小于 $p$ 的素数因子组成。

我们来计算集合$M_p$的元素数量。 $M_p$ 中的任何元素都具有 $pc$ 形式，其中 $c \leqslant A$（因为 $M$ 是不可约集合）、$pc \leqslant B$ 和 $c$ 没有小于 $p$ 的质因数。如果$pA \leqslant B$，则可以忽略条件$pc \leqslant B$，元素$M_p$的数量等于不具有小于$p$的质因数的自然元素$c \leqslant A$的数量（我们将这样的数字记为$m_p(A)$）。如果$pA > B$，则元素数量$M_p$等于$m_p\left(\frac{B}{p}\right)$且不超过$m_p(A)$。

让我们确定一个素数$p$。一般来说，集合$M_2, M_3, M_5, \dots, M_p$不会穷尽集合$M$。让我们用 $N$ 表示 $M$ 的所有剩余元素的集合。它们在数字 2, 3, 5, ..., $p$ 之间没有约数，因此它们的数量不会超过数字 $m_q(B)$，其中 $q$ 是$p$之后的下一个质数。因此，

$$k(A, B) \leqslant m_2(A) + m_3(A) + \dots + m_p(A) + m_q(B).$$

如果$pA \leqslant B < qA$，那么这种不等式就变成了相等。事实上，很明显每个$M_r$恰好包含$m_r(A)$元素。另一方面，每个数字$c \leqslant B$，没有小于$q$的约数，因此没有大于$A$的约数（如果$c = df$，其中$d > A$和$c \leqslant B < qA$，则$f < q$），因此包含在$N$中；因此$N$包含$m_q(B)$元素。

F513。在晴朗的晴天，当太阳位于地平线时，在右侧的白墙上的光滑屏幕上，拉直一块纸板的边缘。如果你把手指放在纸板上，如图5所示，那么在屏幕上我会将我的手指从我身上射出，被纸板甩开，然后用第二根手指擦干我。进行这个实验并解释其结果。

不可能使用衍射的概念来描述这种现象，因为在这样的距离处衍射图案的尺寸很小。

只有当我们考虑到太阳不是一个精确的光源，而是具有有限的角度尺寸时，才能解决成人问题。

要了解迎面而来的阴影是如何出现的，请参阅图 6。

由于作为光源的太阳具有一定的角度尺寸（大约半度），因此在晴天放置所有物体的阴影。阴影边缘的大小取决于物体到观察阴影的表面的距离。尽管在上述实验中，物体的阴影边缘看起来很清晰，但实际上并非如此。除了全阴影区域外，还有部分阴影区域。当手指接近物体并阻挡部分进入半影区域的光线时，屏幕上就会出现迎面而来的阴影。随着手指进一步向下移动，阴影和反阴影的合并发生在半影和屏幕的照明部分的边界处。

通过测量物体与屏幕之间、手指与物体之间的距离以及直接阴影前面迎面而来的阴影的大小，我们可以基于简单的几何考虑来估计太阳的角度大小。

F516。半径为 R 的重圆盘在缠绕在其周围的两条不可延伸的螺纹上滚动。螺纹的自由端已固定 (图 7)。当磁盘移动时，螺纹不断啮合。在某个时刻，磁盘的速度为$\omega$，线程之间的速度为$\alpha$。此时圆盘中心的速度是多少？

考虑点 $c$ 和 $d$ 与圆盘接触的点在原点与圆盘中心所在点 $O$ 重合的坐标系中的运动，当螺纹之间的角度为 $\alpha$，且轴 $OX$ 和 $OY$ 彼此成$\alpha$ 角度且与螺纹平行时（图7）。在这个坐标系中（就像在任何固定系统中一样），点 $c$ 和 $d$ 的速度分别相等

$$v_c = v_0 + v_{c0}, \quad v_d = v_0 + v_{d0}.$$

其中$v_0$是圆盘中心的速度，$v_{c0}$和$v_{d0}$是点$c$和$d$相对于圆盘中心的速度。显然，$|v_{c0}| = |v_{d0}|$，且圆盘旋转角速度为$\omega$

$$|v_{c0}| = |v_{d0}| = \omega R = u.$$

根据螺纹不可延伸的条件，当它们形成角度 $\alpha$ 时，速度 $v_d$ 和 $v_c$ 在轴 $OX$ 和 $OY$ 上的投影 $v_{dx}$ 和 $v_{cy}$ 等于 0：

$$v_{dx} = v_{0x} - u = 0, \quad v_{cy} = v_{0y} - u = 0.$$

从这里

$$v_{0x} = v_{0y} = u.$$

这意味着圆盘中心速度的向量$v_0$有向
