S·福明

不失一般性，我们可以假设$0 < a \leq b \leq c \leq d$。添加另外三个不等式
$$a(a-b)(a-c)(a+2d) \geq 0,$$
$$a(a-b)(a+2c)(a-d) \geq 0,$$
$$a(a+2b)(a-c)(a-d) \geq 0,$$
我们得到
$$3a^4 - 3a^2(bc + bd + cd) + 6abcd \geq 0,$$
或者
$$a^4 - a^2(bc + bd + cd) + 2abcd \geq 0.$$

另一方面，不平等
$$b^4 + c^4 + d^4 - a^2(b^2 + c^2 + d^2 - bc - bd - cd) - b^2c^2 - b^2d^2 - c^2d^2 \geq 0$$
相当于下一个
$$[(b+c)^2 - a^2](b-c)^2 + [(b+d)^2 - a^2](b-d)^2 + [(c+d)^2 - a^2](c-d)^2 \geq 0.$$

将不等式（1）和（2）相加，我们就得到了问题的描述。
让我们用数学分析来解决这个问题。我们需要以下几何估计
引理。如果函数$f$在循环$[x_0; +\infty[$的每个点都是非负任意的，那么它在这个循环上是非递减的。
请注意，如果任意两个数字 $a, b, c, d$ 重合，则不等式证明成立。事实上，让我们直接，$a = d$。那么我们的不等式可以重写如下：
$$a^4 + 2(bc - b^2 - c^2)a^2 + b^4 + c^4 - b^2c^2 \geq 0.$$

不等式(3)的左边是关于$a^2$的二次三项式，具有非正判别$-2bc(b-c)^2$，因此(3)是有效的。

现在让我们以这种形式重写所需的不等式：
$$d^4 - (a^2 + b^2 + c^2)d^2 + 2abcd + a^4 + b^4 + c^4 - a^2b^2 - a^2c^2 - b^2c^2 \geq 0$$

并将 (4) 的左侧视为 $d$ 的函数；我们用 $f$ 来表示这个函数。我们需要证明$f(d) \geq 0$对于$d \geq c$（和$0 < a \leq b \leq c$）。我们有：
$$f'(d) = 4d^3 - 2(a^2 + b^2 + c^2)d + 2abc,$$
所以$f'(c) = 2c^3 - 2(a^2 + b^2)c + 2abc \geq 0 (0 < a \leq b \leq c)$。
下一个，
$$f''(d) = 12d^2 - 2(a^2 + b^2 + c^2) \geq 0$$

在$0 < a \leq b \leq c$。因此，通过引理 $f'(d) \geq f'(c) \geq 0$ $d \geq c$。利用$f(c) \geq 0$（见上面的注释）和$f'(d) \geq 0$代表$d \geq c$这一事实，并再次应用引理，我们得到了$d \geq c$的不等式$f(d) \geq 0$，这就是所需要的。

F. Schleöfer (Ryazan) 发明了这种不等式的有趣概括：对于任意 $a_1, \dots, a_n$
$(n-1)(a_1^2 + a_2^2 + \dots + a_n^2) + n\sqrt{a_1^2 \cdot a_2^2 \cdot \dots \cdot a_n^2} \geq (a_1 + a_2 + \dots + a_n)^2$.

对于$n=4$、$a_1=a^2$、$a_2=b^2$、$a_3=c^2$、$a_4=d^2$，我们获得了问题的陈述。
