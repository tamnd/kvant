M504, M506, M507; F513, F516, F517

M504。在 $n \times n$ 个单元格的棋盘上，放置了 $k$ 个尺寸为 $2 \times 1$ 的 plimka，如果不移动现有的 plimka，就不可能放置第 $(k+1)$ 个 plimka。证明剩余的空闲单元不超过$a) (n^2+n+1)/3$个；
$b) (n^2+2)/3$;
$c) n^2/3$.

是否有可能对某些 $n$ 获得更有效的估计？

让有$x$个空闲单元。

a) 让我们将不位于棋盘上部水平位置的每个空闲单元与从上方“覆盖”它的图块关联起来 (图 1)。很明显，每个图块最多与一个单元相关联（因此，不在棋盘顶部水平方向上的空闲单元的数量最多为问题中所述布局的$\frac{n^2-x}{2}$图块的数量）。让棋盘的顶部水平面有 $x_1$ 个空闲单元格；然后$x_1 \leq \frac{n+1}{2}$。我们有$x-x_1 \leq \frac{n^2-x}{2}$，即

$$3x \leq n^2+2x_1 \leq n^2+n+1,$$

在哪里

$$x \leq (n^2+n+1)/3.$$

6) 让我们用$x_1$表示棋盘内部的空闲单元的数量，用$x_2$表示棋盘边界上的空闲单元的数量，不包括角单元；最后，用 $x_3$ 表示棋盘上空闲角单元的数量。然后$x=x_1+x_2+x_3$。通过$y_1$，我们表示严格位于棋盘内部的l和tok的数量；到$y_2$——至少一个方格内延伸到棋盘边缘的棋子数量；然后$y_1+y_2 = \frac{n^2-x}{2}$。

让我们计算一个空闲单元有多少个空间 - 它的边界是 plimka。一方面，它们有 $4x_1+3x_2+2x_3$ 个。另一方面，由于瓷砖的放置方式不再可能添加单个瓷砖，因此这些瓷砖对的数量不超过$4y_1+3y_2$（面向棋盘边界边缘的每个瓷砖不超过第三个正方形，并且严格位于棋盘边界内的每个瓷砖不超过四个）。波兹尼

$$4x_1+3x_2+2x_3 \leq 4y_1+3y_2.$$

由于棋盘边界上的两个空闲单元被瓦片分隔开，我们有

$$x_2+x_3 \leq y_2.$$

将不等式（1）和（2）相加，我们得到

$$4x_1+4x_2+3x_3 \leq 4(y_1+y_2),$$

或者

$$x-\frac{1}{4}x_3 \leq \frac{n^2-x}{2}.$$

但是$x_3 \leq 4$；表示$x \leq \frac{n^2-x}{2} + 1$或$3x \leq n^2+2$，因此$x \leq (n^2+2)/3$。

c) 请注意，如果不等式 (1) 是严格的，那么我们就得到了 c) 点所需要的：严格不等式 $x < \frac{n^2-x}{2} + 1$ 等价于：

$$x \leq \frac{n^2-x}{2}, \text{откуда } x \leq \frac{n^2}{3}.$$

Pozny，如果我们假设$x > \frac{n^2}{3}$，那么在任何情况下，每个图块必须与最大数量的空闲单元相邻。特别是，长度为 1 的图块的任何不适合棋盘边缘的边必须是相邻的
