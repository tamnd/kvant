⟦folio 47⟧

闭路欧姆：

$$I = \frac{\varepsilon}{R + r}$$

源极电压等于外部电阻电压：

$$U = I R = \frac{\varepsilon R}{R + r}$$

外电路释放的功率等于热损失的功率；可由式（2）确定：

$$P = I^2 R = \frac{\varepsilon^2 R}{(R + r)^2}$$

总电流功率等于外力的功率或内外电阻热损失的总功率：

$$P_\pi = \varepsilon I = I^2 (R + r) = \frac{\varepsilon^2}{R + r}$$

为了提高效率，我们有：

$$\eta = \frac{P}{P_\pi} = \frac{R}{R + r}$$

对应图如图 2 b-e 所示。注意外部电路中释放的功率$P$是否存在最大值（证明当外部和内部电阻相等时功率$P$最大）。

另一个例子，当并非所有电力功都转化为热量时，由电动机提供。

问题 4. 电动机连接到电压为 $U = 220$ V 的后洗网络。电动机绕组的电阻为 $R = 5$ 欧姆。消耗摩卡的功率$I = 10$ A. 求摩卡的机械功率及其效率。

在这种情况下，电流的总功率由机械功率和热功率组成：

$$UI = P_\pi + I^2 R$$

姿势

$$P_\pi = UI - I^2 R = 1700 \text{ Вт}$$

和电机效率

$$\eta = \frac{P_\pi}{P} = \frac{UI - I^2 R}{UI} \approx 0,77 = 77\%$$
