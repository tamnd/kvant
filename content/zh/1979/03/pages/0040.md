现在让我们回到原来的问题，找出$A$$k(A, 2n) < n$。为此，只需求解 $A$ 不等式即可

$$A(1 + Z_3 + \ldots + Z_p) + 2n \cdot Z_q + (2^i - 1) \leq n.$$

取 $p$ 等于 3.5 或 7，我们分别得到：

$$A \leq \frac{2}{9}n - \frac{14}{3}, \quad A \leq \frac{14}{55}n - \frac{90}{11},$$

$$A \leq \frac{38}{147}n - \frac{310}{21}.$$

在 $p = 7$ 处有一个微小的因子 $\frac{38}{147}$，是三个因子中最大的。取$p \geq 11$是没有意义的，因为$11 \cdot \frac{38}{147}n \geq 2n$，并且$k(A, 2n)$的不等式会不太准确。所以，我们已经证明对于$n \geq 2$对于任何序列$a_1 < a_2 < \ldots < a_n \leq 2n$

$$\max(a_i, a_j) > \frac{38}{147}n - \frac{310}{21}.$$

为了证明系数$\frac{38}{147}$不能被破坏，我们取$A = \frac{38}{147}n + \frac{310}{21}$。那么在$n \geq 543$处将会有$7A \leq 2n < 11A$，并且利用不等式(3)，我们得到$k(A, 2n) \geq n$。因此，对于$n \geq 543$，总有一个序列$a_1 < a_2 < \ldots < a_n \leq 2n$，其中

$$\max(a_i, a_j) \leq \frac{38}{147}n + \frac{310}{21}.$$

如果我们仔细估计$m_r(C)$，我们可以获得更准确的不等式：对于$n \geq 2$，对于任何序列$a_1 < a_2 < \ldots < a_n \leq 2n$

$$\max(a_i, a_j) \geq \frac{38}{147}n - \frac{73}{49};$$

此外，还有一个序列 $a_1 < a_2 < \ldots < a_n \leq 2n$ ，其中

$$\max(a_i, a_j) \leq \frac{38}{147}n + \frac{73}{49}.$$

（值得注意的是，这些不等式中的常数$\frac{73}{49}$不能再减少）。
