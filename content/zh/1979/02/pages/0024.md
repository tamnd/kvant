在一些学校，在一些学校，我正在寻找功能$f(x) = \sin x \cdot \cos x$的角色。

并收到了两个答复：

$$F_1(x) = \frac{1}{2} \sin^2 x$$

$$F_2(x) = -\frac{1}{2} \cos^2 x.$$

由于每个人都相信他们找到了相同的反导数，因此等式出现在黑板上

$$\frac{1}{2} \sin^2 x = -\frac{1}{2} \cos^2 x,$$

哪里变得更快了？

$$\sin^2 x + \cos^2 x = 0,$$

或者，简单地说；

$$1 = 0.$$

有必要逐层摆脱这种废话，得到不同写法的答案：

$$F_1(x) = \frac{1}{2} \sin^2 x + C$$

$$F_2(x) = -\frac{1}{2} \cos^2 x + C.$$

然而平等再次出现在棋盘上

$$\frac{1}{2} \sin^2 x + C = -\frac{1}{2} \cos^2 x + C,$$

从中减去$C$，我们又得到了$1 = 0$。

然后很仔细地写下了答案：

$$F_1(x) = \frac{1}{2} \sin^2 x + C_1$$

$$F_2(x) = -\frac{1}{2} \cos^2 x + C_2.$$

但这些常量可以是任何数字，包括相同的数字。平等再次出现在董事会上

$$\frac{1}{2} \sin^2 x + 1979 = -\frac{1}{2} \cos^2 x + 1979,$$

从中减去 1979 后，我们又得到$1 = 0$。

在那所学校，在那堂课上，他们最终了解到在处理反导数时可以写什么和不能写什么。你呢？
