Novesiya），载荷的轨迹仍将是椭圆形，但运动方向将变为相反。

事实证明，在所有其他情况下，负载也会沿着椭圆运动，并且运动方向将由负载在冲击时接近的极限位置决定。一探究竟。此外，请确保沿任何轨迹的运动发生的周期等于冲击时接近负载的极限位置的周期。

请注意，要成功进行所描述的实验，需要进行一些培训。当负载的移动速度记录最多时，在平衡位置撞击负载尤其困难：
$$x = x_m \cos \omega t,$$
并沿 $Y$ 轴 - 根据定律
$$y = y_m \cos (\omega t - \varphi_0).$$

其中$x$和$y$是平衡位置的混合矩阵，$x_m$和$y_m$是极值振幅，$\omega$是循环极值频率，$\varphi_0$是初始相移。

在第一种特定情况下，当在平衡位置进行打击时，相移$\varphi_0$可以等于0或$\pi$。

如果$\varphi_0 = 0$，矩阵的极值由方程描述
$$x = x_m \cos \omega t$$
和$$y = y_m \cos \omega t.$$
让我们将第二个方程除以第一个方程：
$$\frac{y}{x} = \frac{y_m}{x_m},$$
或$$y = \frac{y_m}{x_m} x.$$

这是与 $X$ 轴倾斜 $\alpha$ 角度且满足 $\tg \alpha = \frac{y_m}{x_m}$ 的直线方程。特别是，当极值 ($y_m = x_m$) $\tg \alpha = 1$ 和 $\alpha = 45^\circ$ 的幅度相等时。

若$\varphi_0 = \pi$，则极值矩阵的方程为：
$$x = x_m \cos \omega t,$$
$$y = y_m \cos (\omega t - \pi) = -y_m \cos \omega t.$$

从这里
$$\frac{y}{x} = -\frac{y_m}{x_m},$$
或$$y = -\frac{y_m}{x_m} x.$$

在 $y_m = x_m \tg \alpha = -1$ 和 $\alpha = 135^\circ$。

第二种部分情况，当在负载的极限位置施加打击时，对应于相移$\pi/2$或$3\pi/2$。对于$\varphi_0 = \pi/2$我们可以写：
$$x = x_m \cos \omega t,$$
$$y = y_m \cos (\omega t - \pi/2) = y_m \sin \omega t.$$

经过简单的代数变换我们得到：
$$\frac{x^2}{x_m^2} + \frac{y^2}{y_m^2} = 1.$$

这是椭圆的实方程。
在$\varphi_0 = 3\pi/2$，结果是一样的。
如果$y_m = x_m$，椭圆变成圆，其方程为
$$x^2 + y^2 = x_m^2.$$

请注意，对于相移 $\varphi_0 = \pi/2$，负载沿着椭圆（或者特别是沿着圆）的运动发生逆时针，而对于 $\varphi_0 = 3\pi/2$ - 顺时针。
