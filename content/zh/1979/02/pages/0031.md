⟦folio 29⟧

使用 2 的负幂，我们可以获得 $\frac{m}{2^k}$ 形式的有理数的类似展开式，其中 $m$、$k$ 是自然数。例如，

$$\frac{1477}{256} = \frac{1 + 2^2 + 2^8 + 2^7 + 2^8 + 2^{10}}{2^8} = 2^{-8} + 2^{-6} + 2^{-2} + 2^{-1} + 2^0 + 2^2.$$

没有其他有理数可以表示为二的幂之和，但事实证明，这样的和可以根据需要准确地逼近任何有理数。事实上，令 $a$ 为有理数，$\|a\| = \frac{1}{2^{k_1}}$。因此$a_1 = a - 2^{k_1}$。那么 $a_1$ 比 $a$ 更接近零（参见练习 1）。

Pozny 是 $a_1 = 0$ 或 $\|a_1\| = \frac{1}{2^{k_2}}$，其中 $k_2 > k_1$。 Polya $a_2 = a_1 - 2^{k_2}$，我们再次得到$a_2 = 0$或$\|a_2\| = \frac{1}{2^{k_3}}$，其中$k_3 > k_2$，依此类推。因此，要么某个数字 $a_s$ 等于 0，然后 $a$ 是 2 的幂之和：$a = 2^{k_1} + 2^{k_2} + \dots + 2^{k_s}$，或者所有 $a_s$ 都不为零，然后 $2^{k_1} + 2^{k_2} + \dots + 2^{k_s}$ 形式的和按照期望精确地逼近数字 $a$。在这种情况下，可以方便地假设 $a$ 等于无限和 $a = 2^{k_1} + 2^{k_2} + \dots + 2^{k_s} + \dots$。

定义。令 $x_1, x_2, \dots, x_n$ 为有理数序列。如果数 $a$ 与有限和 $S_n = x_1 + \dots + x_n$ 之间的 2-adic 考虑趋于零，而 $n$ 趋于无穷大，我们会说有理数 $a$ 等于无限和 $x_1 + x_2 + \dots + x_n + \dots$，即

$$\lim_{n \to \infty} \rho(a, S_n) = 0.$$

实际上，如果$\|q\| < 1$，则定义无限和$a + aq + aq^2 + \dots + aq^n + \dots$并且等于$\frac{a}{1 - q}$。

我们已经证明，每个有理数都可以表示为有限和$2^{k_1} + 2^{k_2} + \dots + 2^{k_n}$（$k_1 < k_2 < \dots < k_n$）或无限和$2^{k_1} + 2^{k_2} + \dots + 2^{k_n} + \dots$（$k_i$是整数，$k_1 < k_2 < \dots$）。在这两种情况下，这种表示形式（我们将其称为数字 $a$ 的 2-Adic 分解）可以写为 $\varepsilon_k 2^k + \varepsilon_{k+1} 2^{k+1} + \dots + \varepsilon_{k+n} 2^{k+n} + \dots$，其中 $k$ 是整数，每个数字$\varepsilon_{k+1}, \varepsilon_{k+2}, \dots, \varepsilon_{k+n}, \dots$ 等于 0 或 1，其中 $\varepsilon_k = 1$。数字$\varepsilon_k, \varepsilon_{k+1}, \dots$称为数字$\frac{p}{q}$的2进数。不难证明每个有理数都有一个且仅有一个2-adic分解。

练习 8. 证明 $-1 = 1 + 2 + 2^2 + 2^3 + \dots + 2^n + \dots$，

$$\frac{1}{6} = 2^{-1} + 1 + 2^2 + 2^4 + \dots + 2^{2n} + \dots$$

根据练习 8，2 进数数字 - 1 形成序列 1, 1, 1, ...，数字 $\frac{1}{6}$ 的 2 进数数字形成序列 1, 1, 0, 1, 0, 1, 0, 1, ... 两个结果序列都是周期性的。可以证明，对于任何有理数$\frac{p}{q}$，2-adic 数字的序列是周期性的*)。

为此，请考虑由等式 $\frac{p}{q} - \varepsilon_k 2^k = \frac{a_1}{q} 2^{k+1}, \frac{p}{q} - (\varepsilon_k 2^k + \varepsilon_{k+1} 2^{k+1}) = \frac{a_2}{q} 2^{k+2}, \dots,$ 定义的数字序列 $a_1, a_2, \dots, a_n, \dots$

$$\frac{p}{q} - (\varepsilon_k 2^k + \varepsilon_{k+1} 2^{k+1}) + \varepsilon_{k+1} 2^{k+1} = \frac{a_2}{q} 2^{k+2}, \dots,$$

$$\frac{p}{q} - (\varepsilon_k 2^k + \varepsilon_{k+1} 2^{k+1}) + \varepsilon_{k+1} 2^{k+1} = \frac{a_2}{q} 2^{k+2}, \dots,$$

$$\frac{p}{q} - (\varepsilon_k 2^k + \varepsilon_{k+1} 2^{k+1}) + \varepsilon_{k+1} 2^{k+1} = \frac{a_2}{q} 2^{k+2}, \dots,$$
