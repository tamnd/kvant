剩下的只是证明对于凸集不等式 (*) 只能是算术级数的等式。要做到这一点，只要证明如果$c_k \geq (c_{k-1} + c_{k+1})/2$，那么要么所有$c_k$，$k = 0, \dots, 2n$都等于0，或者所有$c_k$，$k = 1, \dots, 2n-1$都为正（在后一种情况下，（**）中的右不等式必然是严格的）。

我们选择最小的$c_i$；让它不要在边缘：$i \neq 0, i \neq 2n$。然后是$c_i \leq c_{i-1}$和$c_i \leq c_{i+1}$，由此而来$c_i \leq \frac{c_{i-1} + c_{i+1}}{2}$。但根据条件$\{c_k\}$是一个“凸”集，这意味着$c_i = c_{i-1} = c_{i+1}$。将相同的推理应用于$c_{i-1}$（或$c_{i+1}$），我们发现$c_{i-2} = c_{i-1} = c_i$（或$c_i = c_{i+1} = c_{i+2}$）等 - 直到我们到达边缘；我们得到$0 = c_1 = c_2 = \dots = c_{2n-1} = 0$。因此，如果存在非零的数字$c_k$，则最小公比位于边缘（并且等于零），因此对于$k = 1, \dots, 2n-1$，我们有$c_k > 0$。

N.瓦西里耶夫、I.克鲁莫娃

F502。封闭盒的盖子高度$h = 1$，有一个圆孔。如果孔中存在光焦度为 $D = 1$ ditre 的线，那么当天的照度会如何变化？盒子露天放置，然后笼罩着一层均匀的云层。

单个电话角度内的光通量在任何方向上都是相同的。让我们用流经单位角度并落在透镜或孔下底部单位面积上的光通量来表示。

在没有镜头的情况下，光线落到底部，在电话角度 $\Omega = S_{\text{OTB}}/h^2$ (图 8) 中窒息。因此，在这种情况下，孔下的日光照度等于

$$E_1 = \sigma \Omega = \sigma S_{\text{OTB}}/h^2$$

镜头会将落在电话角 $\omega$ (图 9) 范围内的所有光线收集在盒子底部的焦平面 $s = h^2\omega$ 区域上。这种光线的光通量$\Phi = \sigma S_{\text{OTB}}\omega$，因此在这种情况下天空图像的照度等于

$$E_2 = \Phi/s = \sigma S_{\text{OTB}}/h^2.$$

我们看到$E_1 = E_2$，即孔下方的盒子底部的光照没有变化。

F504。汽车的车轮是自动的，小心地单轮，车轮的中心质量轮单位于其医生的轴上。为什么需要车轮平衡？

力$\vec{N}$从路边作用在车轮上。如果车轮平衡，该力的绝对值等于自动变速箱 $M|\vec{g}|^*$ 重量的 1/4（在光滑路面上行驶时）。

*) 自动腕表的重量有多少部分落在车轮上取决于自动腕表的重心位置。一般来说，不等于1/4。
