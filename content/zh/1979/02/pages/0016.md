⟦folio 14⟧

数值解，我们需要以下

引理。在常规镶木地板的顶部，它们不能用不同的多边形来维护，其中一个多边形具有无限数量的边。

事实上，让这样的镶木地板存在（图5）。然后在奇数 olg 周围，剩余的 $m$- 和 $n$-边形必须相互穿过。因此，当绕过它时，附近有两个相同的多边形，这是关于引理条件的问题。

借助引理，我们可以在（2）中将$k$替换为$2k_1$，将$m$替换为$2m_1$，将$l$替换为$2l_1$，然后得出等式

$$\frac{1}{n_1} + \frac{1}{m_1} + \frac{1}{k_1} = 1.$$

不失一般性，我们可以提出$k_1 < m_1 < n_1$。然后

$$\frac{1}{n_1} + \frac{1}{m_1} + \frac{1}{k_1} < \frac{3}{k_1},$$

可摆姿势$k_1 = 2$。因此，$\frac{1}{n_1} + \frac{1}{m_1} = \frac{1}{2}$，$m_1 = 3$，$n_1 = 6$（如果$m_1 \geq 4$，则$n_1 \leq m_1$）。得到的解决方案 $\alpha_4 + \alpha_6 + \alpha_{12}$ 为我们提供了另一个镶木地板 (图 6)。

顶部有四个多边形的镶木地板

在这种情况下，我们得出等式

$$\frac{1}{n} + \frac{1}{m} + \frac{1}{k} + \frac{1}{l} = 1.$$ (3)

我们假设$l \leq k \leq m \leq n$。很容易看出$l \leq 4$。如果$l = 4$，那么我们就到达集合$4\alpha_4$。如果$l = 3$，那么我们得到方程

$$\frac{1}{n} + \frac{1}{m} + \frac{1}{k} = \frac{2}{3},$$

由此可知$k < 5$。如果$k = 4$，那么，从$m \geq k$开始，我们得到唯一解$m = 4$，$n = 6$。如果$k = 3$，那么我们得到两个解：$m = 4$，$n = 12$和$m = 6$，$n = 6$。

因此，我们将看到四组来检查：

$$4\alpha_4; \alpha_3 + 2\alpha_4 + \alpha_6; 2\alpha_3 + 2\alpha_6; \alpha_4 + 2\alpha_3 + \alpha_{12}.$$

第一组 $4\alpha_4$ 给出了一个三重方形镶木地板 (图 7)。

对于组合 $\alpha_3 + 2\alpha_4 + \alpha_6$，两个不等价的顶点是可能的 (图 8, a, b)，但只有变体 $8,a$ 给出正确的镶木地板 (图 8, b)。确保选项 $8,b$ 不会生成任何正确的镶木地板。

对于 $2\alpha_3 + 2\alpha_6$ 也可能有两个不同的顶点 (图 9, a, b)，但只有第二个给出正确的镶木地板 (图 9, b)。完成第一个就会导致矛盾。由此可见，实木复合地板存在三个“四方程”：

$$4\alpha_4; \alpha_3 + 2\alpha_4 + \alpha_6; 2\alpha_3 + 2\alpha_6.$$

顶部有第五个多边形的镶木地板

在这种情况下，您需要找到方程的解

$$\frac{1}{n} + \frac{1}{m} + \frac{1}{k} + \frac{1}{l} = \frac{3}{2}.$$ (4)

由此可以立即清楚地看出$j = k = l = 3$（我们假设$j \leq l \leq k \leq m \leq n$）。结果是方程$\frac{1}{n} + \frac{1}{m} = \frac{1}{2}$，它有两个解：$m = 3$、$n = 6$和$m = 4$、$n = 4$。

现在仍然需要考虑找到的组合：

$$\alpha_6 + 4\alpha_3 \text{ и } 2\alpha_4 + 3\alpha_3.$$

第一个给出了唯一的顶点类型和唯一的规则镶木地板 (图 11)。第二种组合允许两个不等价的顶点，每个顶点形成镶木地板（图 12 和 13）。

因此，实木复合地板存在三个“五元方程”：

$$4\alpha_3 + \alpha_6; (2\alpha_4 + 3\alpha_3)'; (2\alpha_4 + 3\alpha_3)''.$$

顶部有六个多边形的镶木地板

很明显，这样的镶木地板 (图 14) 是唯一从组合 $6\alpha_3$ 接收的镶木地板。

上面列出的案例涵盖了所有正确的镶木地板类型。从上面可以看出，总数是一样的。
