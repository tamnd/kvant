M503。一组 2n+1 个数字 $a_0, a_1, a_2, \dots, a_{2n}$ 罂粟花，对于所有 $k=1, 2, \dots, 2n-1$ 来说是 $a_k \geq \frac{a_{k-1} + a_{k+1}}{2}$。证明不平等
$$\frac{a_1 + a_3 + a_5 + \dots + a_{2n-1}}{n} \geq \frac{a_0 + a_2 + a_4 + \dots + a_{2n}}{n+1} \quad (*)$$
并找出对于哪些集合它变成相等。

首先我们要注意，如果这个集合是等差数列，那么问题陈述中写的所有不等式都会变成等式。下面我们将看到，在“凸”集合（即对于所有 $k=1, 2, \dots, 2n-1$ 都具有 $a_k \geq \frac{a_{k-1} + a_{k+1}}{2}$ 的集合）中，只有对于算术级数，不等式 (*) 才变为等式。

任意“凸”集合$\{a_k\}$的数可以表示为两个集合$\{b_k\}$和$\{c_k\}$的数$a_k = b_k + c_k$之和，其中一个$\{b_k\}$是具有极值项$b_0 = a_0$和$b_{2n} = a_{2n}$的算术级数，另一个$\{c_k\}$是具有零极值的“凸”集合条款：$c_0 = c_{2n} = 0$。

由于对于集合$\{b_k\}$来说不等式（*）变成了等式，因此对于集合$\{c_k\}$证明它就足够了。但对于具有零极值项的“凸”集，它是从“凸”条件无限地获得的：对于所有 $i=1, \dots, n$ 写出 $c_{2i-1} \geq \frac{c_{2i-2} + c_{2i}}{2}$，并添加这些不等式，我们得到：

$$c_1 + c_3 + \dots + c_{2n-1} \geq \frac{c_0}{2} + c_2 + c_4 + \dots +$$

$$+ c_{2n-2} + \frac{c_{2n}}{2} = c_0 + c_2 + \dots + c_{2n-2} + c_{2n}$$

（我们考虑到了$c_0 = c_{2n} = 0$），所以

$$\frac{c_1 + c_3 + \dots + c_{2n-1}}{n} \geq \frac{c_0 + c_2 + \dots + c_{2n}}{n+1}$$

(**)

⟦folio 38⟧

剩下的只是证明对于凸集不等式 (*) 只能是算术级数的等式。要做到这一点，只要证明如果$c_k \geq (c_{k-1} + c_{k+1})/2$，那么要么所有$c_k$，$k = 0, \dots, 2n$都等于0，或者所有$c_k$，$k = 1, \dots, 2n-1$都为正（在后一种情况下，（**）中的右不等式必然是严格的）。

我们选择最小的$c_i$；让它不要在边缘：$i \neq 0, i \neq 2n$。然后是$c_i \leq c_{i-1}$和$c_i \leq c_{i+1}$，由此而来$c_i \leq \frac{c_{i-1} + c_{i+1}}{2}$。但根据条件$\{c_k\}$是一个“凸”集，这意味着$c_i = c_{i-1} = c_{i+1}$。将相同的推理应用于$c_{i-1}$（或$c_{i+1}$），我们发现$c_{i-2} = c_{i-1} = c_i$（或$c_i = c_{i+1} = c_{i+2}$）等 - 直到我们到达边缘；我们得到$0 = c_1 = c_2 = \dots = c_{2n-1} = 0$。因此，如果存在非零的数字$c_k$，则最小公比位于边缘（并且等于零），因此对于$k = 1, \dots, 2n-1$，我们有$c_k > 0$。
