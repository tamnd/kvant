使用秒表或手表的秒针，确定矩阵的振荡周期。

现在对两个指示振动的相加进行实验。首先，使基体在主平面内沿 X 轴以 20-25 cm 的幅度振荡。然后推动重物（例如，使用锤子），期望使其在沿 Y 轴的垂直平面内振荡。

您将看到负载的运动会发生变化。首先，负载将沿着不同的轨迹移动，该轨迹由振荡分量的幅度与它们之间的初始相移的对应关系确定。

请注意，要成功进行所描述的实验，需要进行一些培训。当负载的移动速度记录最多时，在平衡位置撞击负载尤其困难：
$$x = x_m \cos \omega t,$$
并沿 $Y$ 轴 - 根据定律
$$y = y_m \cos (\omega t - \varphi_0).$$

其中$x$和$y$是平衡位置的混合矩阵，$x_m$和$y_m$是极值振幅，$\omega$是循环极值频率，$\varphi_0$是初始相移。

在第一种特定情况下，当在平衡位置进行打击时，相移$\varphi_0$可以等于0或$\pi$。

如果$\varphi_0 = 0$，矩阵的极值由方程描述
$$x = x_m \cos \omega t$$
和$$y = y_m \cos \omega t.$$
让我们将第二个方程除以第一个方程：
$$\frac{y}{x} = \frac{y_m}{x_m},$$
或$$y = \frac{y_m}{x_m} x.$$

这是与 $X$ 轴倾斜 $\alpha$ 角度且满足 $\tg \alpha = \frac{y_m}{x_m}$ 的直线方程。特别是，当极值 ($y_m = x_m$) $\tg \alpha = 1$ 和 $\alpha = 45^\circ$ 的幅度相等时。

若$\varphi_0 = \pi$，则极值矩阵的方程为：
$$x = x_m \cos \omega t,$$
$$y = y_m \cos (\omega t - \pi) = -y_m \cos \omega t.$$

从这里
$$\frac{y}{x} = -\frac{y_m}{x_m},$$
或$$y = -\frac{y_m}{x_m} x.$$

在 $y_m = x_m \tg \alpha = -1$ 和 $\alpha = 135^\circ$。

第二种部分情况，当在负载的极限位置施加打击时，对应于相移$\pi/2$或$3\pi/2$。对于$\varphi_0 = \pi/2$我们可以写：
$$x = x_m \cos \omega t,$$
$$y = y_m \cos (\omega t - \pi/2) = y_m \sin \omega t.$$

经过简单的代数变换我们得到：
$$\frac{x^2}{x_m^2} + \frac{y^2}{y_m^2} = 1.$$

这是椭圆的实方程。
在$\varphi_0 = 3\pi/2$，结果是一样的。
如果$y_m = x_m$，椭圆变成圆，其方程为
$$x^2 + y^2 = x_m^2.$$

请注意，对于相移 $\varphi_0 = \pi/2$，负载沿着椭圆（或者特别是沿着圆）的运动发生逆时针，而对于 $\varphi_0 = 3\pi/2$ - 顺时针。

如果迫使具有未连接悬浮液的矩阵在两个相互垂直的方向上同时振荡，它将如何表现？

使矩阵在主平面内振荡。当负载处于极限位置之一时，在垂直方向上将其移除 - 矩阵也将开始在垂直平面上振荡。尝试确保两种振动的幅度一致。

首先，负载绕垂直轴 (图 4) 做圆周运动。一段时间后，圆形变成椭圆形。椭圆的长轴逐渐旋转，短轴逐渐减小，从而在某一时刻椭圆收缩成一段。然后载荷再次沿椭圆移动，但方向相反；过了一会儿，椭圆变成了圆形。然后一切都会定期重复。其特征在于，随着椭圆每次转变为直线，负载的旋转方向改变为相反的方向。

让我们尝试解释一下矩阵的这种行为。让我们回想一下，两个相互垂直方向上的矩阵振荡频率并不相同 - 在沿 $X$ 轴的主平面中，频率略高于沿 $Y$ 轴的垂直方向。这导致振荡的相位差随着时间逐渐变化（并且不像垂直方向那样保持恒定）。

假设在初始时刻，振荡的相位差等于$\pi/2$ - 负载逆时针绕圆运动（参见图 4，a）。随着时间的推移，沿 $Y$ 轴的振荡越来越多地与沿 $X$ 轴的振荡保持一致 - 圆形变成椭圆形。当滞后达到$\pi$时，负载将沿直线振荡，与轴$X$形成角度$135^\circ$。由于相位差$3\pi/2$，负载将再次沿顺时针方向绕圈移动（参见图 4，b）。一段时间后，振荡之间的相位差变得等于 $2\pi$，换句话说，振荡将在相位上重合 - 负载将以 $45^\circ$ 角度倾斜于轴 $X$ 的直线移动。最后，相位差将再次增加到$\pi/2$-负载，因为在初始时刻，负载逆时针绕圆周运动。等等。
