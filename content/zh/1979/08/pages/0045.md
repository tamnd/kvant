6) 对于 $\varphi = 90^\circ$，用凸四边形的边长 $a, b, c, d$ 来表示凸四边形的面积 $S$。请注意，在这种情况下$a^2 - b^2 + c^2 - d^2 = 0$。令 $a$ 为$a, b, c, d$ 中最小的数字。长度为 $a$、端点位于射线 $l_1$ 和 $m_1$ (图 5) 的线段可以延伸至具有给定边的四边形；通过改变线段的位置，我们得到了一系列这样的四边形（顶点具有不同的角度）。让我们证明所有这些四边形的面积不等于相同的数字。为此，我们使用等式 (图 6)

$$S = \frac{1}{2} (ab \sin \varphi + cd \sin \psi),$$

其中$\varphi$和$\psi$是四边形顶点$A$和$C$的角度，我们来看看$S$可以取什么值。

角度 $\varphi$ 和 $\psi$ 的关系为

$$a^2 + b^2 - 2ab \cos \varphi = c^2 + d^2 - 2cd \cos \psi$$

（余弦定理）。

我们假设角度 $\varphi$ 是 $\varphi$ 的函数。来自匹配 (*)

$$\psi' = \frac{ab \sin \varphi}{cd \sin \psi},$$

因此对于任意 $S'$（通过 $\varphi$）我们得到：

$$S' = \frac{1}{2} (ab \cos \varphi + \psi' cd \cos \psi) = \frac{ab}{2} \left( \cos \varphi + \frac{\cos \psi}{\sin \psi} \sin \varphi \right) = \frac{ab}{2} \sin \psi \sin (\varphi + \psi).$$

我们看到，当$\sin (\varphi + \psi) = 0$时，即$\varphi + \psi = 180^\circ$时，$S' = 0$。这意味着可以围绕相应的四边形描述一个圆。

我们尊重施迈纳的著名定理，即在所有具有给定边的四边形中，可以描述圆的四边形的面积最大。几乎 - 因为我们仍然需要检查在任意 $S'$ 的指示零处，函数 $S = S(\varphi)$ 确实有最大值。我们将仅限于仅在我们正在考虑的情况下检查此陈述，即四边形的对角线垂直（我们尚未使用这种情况）。
