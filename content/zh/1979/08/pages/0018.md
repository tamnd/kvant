⟦folio 16⟧

可以想象，振荡器是一种质量为β、振荡外部刚度为γ的“粒子”。为了阐述该物体的量子力学基本思想，我们取与“粒子”相关的波过程的波长 λ：

$$\lambda = 2\pi \hbar / \beta q.$$

分母是“质量”与其速度的乘积。由于速度随着粒子的移动而变化，因此波长也会变化 - 它是平衡位置的最小值，并且在“粒子”速度较低的那些区域中增长。

让“粒子”在 - $q_0$ 到 $q_0$ 的区域内移动。 （我们强调，$2q_0$不是振荡振荡器的摆动，而是其坐标“颤抖”的区域。）为了形成驻波，必须在“长度”$2q_0$：$2q_0 = (n+1)\lambda/2$（$n=0, 1, 2, \dots$）上放置整数个半波。作为速度的估计，我们取$q=q_0$处的速度值，即$(q)_0 = 2\pi \hbar / \beta \lambda = \pi \hbar (n+1)/2\beta q_0$。将这个值代入动能表达式，我们发现：

$$W_n = \frac{\pi^2 \hbar^2}{8\beta} \frac{(n+1)^2}{q_0^2}.$$

对于我们得到的总能量：

$$E_n(q_0) = \frac{(\pi \hbar)^2}{8\beta} \frac{(n+1)^2}{q_0^2} + \frac{\gamma q_0^2}{2}.$$

对于较小的 $q_0$ 值，由于第一项，能量较高；对于较大的 $q_0$ 值，由于第二项，能量较高。如果我们将两项相等，就可以获得 $q_0$ 的近似值，甚至是最小的能量。从这个条件我们发现：

$$q_0^2 = \frac{\pi \hbar (n+1)}{2\sqrt{\beta \gamma}}.$$

代入能量表达式，可得：

$$E_n = \frac{\pi}{2} \hbar \sqrt{\gamma/\beta} (n+1) = \frac{\pi}{2} \hbar \omega (n+1) \quad (n=0, 1, 2, \dots).$$

值$\omega = \sqrt{\gamma/\beta}$代表振荡经典振荡器的频率。

准确计算能量结果：

$$E_n = \hbar \omega \left( n + \frac{1}{2} \right).$$

因此，我们在数值因子上犯了错误（$\pi/2$而不是1），以及最低状态下的能量数值，即$n=0$（$\frac{\pi}{2} \hbar \omega$而不是$\frac{1}{2} \hbar \omega$）。但其他一切都很顺利！现在已经获得了结果，我们应该考虑我们用什么来获得它，以及从我们获得的振荡器能量和值 $q_0^2$ 的表达式中得出什么结论。

首先，我们将量子力学原理应用于我们的振荡器，而对其结构并不感兴趣，量子力学原理首先是与电子相关的。当然，很自然地期望对于质量与电子质量不同的其他粒子来说，一般原理应该是相同的。事实上，这样的概括已经被实验非常准确地证实了。但为什么这些原理可以应用于谐振电路这样的系统，其中“坐标”的作用是由电容器板上的电荷发挥的呢？这里我们得出一个重要的假设，这个假设在20世纪的理论物理学中被广泛使用和使用。如果两个系统的能量同样取决于坐标和速度，那么这些系统具有相同的属性，尽管“坐标”和“速度”在这些系统中可能具有完全不同的含义。

没有一个例子表明这种假设与经验相矛盾。因此，我们有权认为我们已经解决了将量子力学一次性应用于所有可能的振荡器的问题。
