我们将系统（3）简化为一个8次代数方程如下：
1) 通过替换变量$z = ax + by + c$、$t = dx + ey + f$并选择合适的数字$a, b, c, d, e, f$，我们将方程$Q(x, y) = 0$简化为以下形式之一：
(a) $z + At^2 = B$
(b) $z^2 + At^2 = B$.

此外，方程$P(x, y) = 0$还可以用新的未知数重写：$R(z, t) = 0$；同时（这非常重要！）它将仍然是一个四次方程（解释一下！）。

2) 在情况(a)中，表达了$z = -At^2 + B$，我们将$z$的表达式代入方程$R(z, t) = 0$，得到关于$t$的8次方程。

3) 在（6）的情况下，我们取方程 $R(z, t) = 0$ 并在其中留下那些 $z$ 出现为偶数的单项式的踪迹，其余的在右侧相交并在所得方程的两侧平方。我们得到了一个八次方程，其中包含分子偶次幂$z$。将表达式$z^2 = -At^2 + B$代入其中（见（6）），我们得到关于$t$的八次方程。

$$0x + 0y + 0z + 2d = 0.$$ (3)
