我们将针对问题的 c) 点提出两种解决方案。第一个使用数学归纳法，归纳步骤是从$n = k$到$n = k + 2$进行。在这种情况下，需要检查两个初始值$n: n = 3$和$n = 4$是否满足相应的不等式。这个检查，其实就构成了任务第$a$)和$6)$的内容。
a) 所以，令$n = 3$。从条件$0 \leq x_i \leq 1$ ($i = = 1, 2, 3$) 可以得出$(x_1 - 1)(1 - x_2)(1 - x_3) \leq 0$，即$x_1x_2x_3 + x_1 + x_2 + x_3 - x_1x_2 - x_2x_3 - x_3x_1 \leq 1$。
从$x_1x_2x_3 \geq 0$开始，我们得到所需的不等式$x_1 + x_2 + x_3 - x_1x_2 - x_2x_3 - x_3x_1 \leq 1$。
b) 设 $n = 4$。让我们用几何证明$x_1 + x_2 + x_3 + x_4 - x_1x_2 - x_2x_3 - x_3x_4 - x_4x_1 \leq 2$。
让我们从长度为 1 的边取一个正方形 $A_1A_2A_3A_4$。在其边 $A_1A_2, A_2A_3, A_3A_4, A_4A_1$ 上，我们分别标记点 $B_1, B_2, B_3, B_4$，以便 $|A_iB_i| = x_i$（$i = 1, 2, 3, 4$； - 参见 图 9）。设 $S_1, S_2, S_3, S_4$ 为三角形 $A_1B_1B_4, A_2B_2B_1, A_3B_3B_2, A_4B_4B_3$ 的面积。显然，$S_1 + S_2 + S_3 + S_4 \leq 1$（三角形位于面积为1的正方形内且不相交）；这就是为什么

由此我们获得了所需的 $n = 4$ 不等式。
