⟦folio 13⟧

系统的颈部（即围绕平衡位置振荡），系统在任意时刻的能量可以写成以下形式

$$E = \gamma q^2 / 2 + \beta \dot{q}^2 / 2,$$

(*)

其中$q$是表征偏离平衡位置的量，$\dot{q}$是量$q$随时间的变化率（即$\dot{q} = \Delta q / \Delta t$，其中$\Delta t$是一小段时间）。 $\Pi = \gamma q^2 / 2$项是振荡器的势能；系数$\beta$称为振子质量。 $K = \beta \dot{q}^2 / 2$项是振荡器的动能；系数$\beta$称为振子质量。 （记住最简单的振荡器（外部重量）的能量是如何书写的，你就会明白为什么 $\gamma$ 被称为刚度，而 $\beta$ 是振荡器的质量。）

无论振子如何具体设计，其角部$\omega = 2\pi/T$通过刚度$\gamma$和质量$\beta$表示如下：

$$\omega = \sqrt{\gamma / \beta}.$$

引入“广义”振荡器，其坐标不一定是距平衡位置的距离，但可以具有任何意义，只要能量也具有表达式（*）中的$E$结构，使我们能够在不考虑物理性质及其过程起源的情况下得出有关振荡系统行为的结论。

为了清楚起见，我们举另一个振荡器的例子，它与上面给出的所有例子都不相似。假设有一个由导电良好的导线制成的电感器$L$，其两端连接到具有电荷$Q_0$的电容器电容量$C$。电路中会产生电磁振荡。如果线圈由超导体制成（这需要低温），则振荡实际上不会被阻尼。

这种系统的能量由两项组成：线圈中磁场的能量和电容器中电场的能量。电容器电场的能量与当前位于电容器极板上的电荷$Q$的平方成正比：$\Pi = \frac{1}{C} Q^2 / 2$。

线圈磁场的能量与当前流过线圈的电流$I$的平方成正比：$K = L I^2 / 2$。但电流强度等于电容器电荷随时间的变化率：$I = \dot{Q}$。因此，线圈的磁场能量为$K = L \dot{Q}^2 / 2$。

因此，系统任意时刻的能量等于

$$E = \frac{1}{C} Q^2 / 2 + L \dot{Q}^2 / 2.$$

我们的系统是一个振荡器；振荡坐标的作用是由电荷$Q$起的，振荡器的势能是电容器的能量，动能是线圈的磁场的能量。从能量记录中可以清楚地看出，该振荡器的刚度为$1/C$，电感质量的作用为$L$。您可以立即写下部分振动：$\omega = \sqrt{1/LC}$。
