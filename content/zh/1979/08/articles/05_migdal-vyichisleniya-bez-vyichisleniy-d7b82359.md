⟦folio 10⟧

仅使用纸和笔来研究自然，即依赖于先前发现的实验和理论自然定律，可观察量之间的推论关系。这两个过程分开的原因不仅在于它们每个过程都需要自己的特殊知识：在一种情况下，测量方法的知识，以及对数学思维工具和各种形式的直觉的掌握。直觉，即识别正确道路的能力，起着至关重要的作用，尤其是在工作的第一阶段。不幸的是，直觉的天赋并不是立即产生的，而是作为努力工作的结果，作为解决许多科学问题的奖励。

由于理论物理学比实验物理学处理更抽象的概念，因此理论物理学需要更抽象形式的直觉，有时接近数学的直觉。在上个世纪，当物理学还没有如此专业化时，许多物理学家将这两个过程结合起来。于是，从理论上获得了描述所有电磁现象的方程的麦克斯韦也参与到了实验中。赫兹通过实验发现了电磁波，同时也是一位优秀的理论科学家。然而，在每种情况下，都可以指出哪一个过程是主要的：对于麦克斯韦来说，它是理论物理，而对于赫兹来说，它是实验物理。

20 世纪，“全能”物理学家（理论家和实验家）最杰出的例子之一是恩里科·费米。与许多其他工作一起，费米创建了放射性衰变理论，并与他的团队的物理学家一起发现了中子轰击时产生的实验性人造放射性元素。

另一个与实验密切相关的杰出理论家的例子是院士 G.I.芽-

ker，他将理论物理与替代工程思想相结合。他在新西伯利亚学院城领导了使用带电粒子碰撞束的加速器的理论开发和实际实施。

然而，这些都是罕见的例外，对物理学感兴趣的年轻人必须自己决定选择这两个队列中的哪一个。

下面我们将讨论理论物理学家的工作。

物理和数学

因此，理论物理学家的任务是使用数学计算来获得可观测量之间的关系。这是否意味着理论物理是应用数学的一部分？这种观点是完全错误的。无论是在问题的本质上，还是在解决问题的方法上，数学和理论物理都是截然不同的。

在数学中，最重要的作用是由数学方面发挥的，即从公认的公理中得出的所有结论的逻辑无懈可击，以及对所有逻辑可能关系的研究。物理学的任务是，利用所有已知的实验和理论事实，利用契约的基本直觉，在没有严格的“游戏规则”的情况下，尽可能地构建一幅准确的世界图景，稍后将进行实验检验。因此，数学家探索所有逻辑上可能的几何类型，而物理学家则找出我们的世界中实现的几何关系。

数学家，即使他处理的是应用问题，即不是来自数学的问题，他也只解决那些不需要额外的未经证明的命题的问题。通常，物理学家处理的问题是初始数据不足的。

正是为了解决这个问题，而艺术就是猜测本质上缺失的实现关系是什么。这些合约不需要数学直觉，而是物理直觉。

对物理学的信心是通过从不同的初始句子获得相同的结果来实现的。在这种情况下，有必要强调不必要的、逻辑上的、不必要的公理，每一个公理本身都不是绝对可靠的。唯一的条件是降低提案的说服力，明确哪些提案需要进一步验证。

如果物理学的任何领域发展到其所有结果都可以从一些严格建立的实验公理中推导出来，那么该领域将不再是发展中的物理科学的一部分，而将转移到应用数学或技术领域。这就是经典力学所发生的情况。

当然，分析物理理论的结构是非常有用的，也就是说，找出从哪些初始命题中获得了某些结果。然而，这种公理化方法的重心不在于结论的普遍性和数学结构，而在于正确选择初始建议以及评估哪些建议最可靠地得到经验的证实。而这需要物理学家的直觉。如果这项工作是由数学家完成的，那么至少在一段时间内，有必要由理论物理学家来完成。否则，用有用的卡特里卡·莱茨的话来说，他可能会发现自己处于一个为刚果居民在炎热天气制定行为规则的eximoca的位置。

因此，数学和物理学是随着问题的发展和解决问题的方法的发展而发展的科学。

在数学中，逻辑结构是通过分析所有逻辑可能的解决方案来实现的。在物理学中，只考虑那些可以在自然界中实现的解决方案，并通过反复检查提出的建议来实现可靠性。在俄罗斯，物理学中的数学严谨是不可能也没有必要的。在物理学中实现数学结构并不比要求伐木工头在工作中说诗歌更必要。但与此同时，物理理论一词是指掌握数学工具，即了解并能够使用所有可能有助于解决物理问题的数学方法。

二.定性分析

让我们尝试用简单的例子来展示理论物理学家在工作的第一个、最重要的阶段是如何工作的，即完成问题的定性分析。正如我们将看到的，在这个工作阶段，几乎不需要任何计算，就可以获得问题所涉及的数量之间的粗略关系。下一阶段的工作——使用理论的数学工具获得精确的定量关系——完全基于第一阶段，在此阶段澄清了现象的物理图景，并提出了预期解决方案的草案。如果没有这样的建议，人们就无法开始寻找精确的解决方案。事实上，只能证明那些预先猜测的陈述。这条规则几乎没有例外。

定性分析的主要要素之一是使用简化模型解决问题，其中所有不存在的模型都被丢弃。让问题变得更难解决比解决复杂问题容易得多。

在一些简单的情况下，简单的量纲分析可以澄清很多关于大小问题以及它们之间关系的可能性。

尺寸等级

为了便于说明，我们使用维度消息证明毕达哥拉斯定理。从维度可以得出，直角三角形的面积 $S$ 可以写成斜边的平方与锐角之一的新函数：$S=c^2f(\alpha)$ 的乘积。以类似的方式，您可以想象两个相似的直角三角形的面积，这是通过省略直角的高度而获得的。对于这些三角形，斜边的作用由三角形的卡莫内扮演。因为

$$c^2f(\alpha)=a^2f(\alpha)+b^2f(\alpha).$$

约简$f(\alpha)$，我们得到毕达哥拉斯定理。

作为另一个例子，考虑寻找重物的外部振荡周期的问题。首先，让我们找出期间表达式中可以包含哪些数量。由于作用在重物上的力是重力和弹力，因此很自然地可以假设振荡周期取决于自由落体根 $g$ 和重物的质量 $m$ 以及弹簧的刚度 $k$。当然，如果我们忽略振动的阻尼，温度和空气粘度等量就不会包含在问题中。 （为了简化问题，你需要知道什么可以忽略！）从$g$、$m$和$k$的值中，你只能做出一种具有时间维度的组合 - $V/m/k$。因此，$T$的周期等于

$$T=C\sqrt{m/k}.$$

响应中不包含加速度$g$。从量纲消息中找不到无量纲常数$C$；只能说，它既不太大，也不太小，是统一的秩序。事实上，$C$的值必须从我们尚未写出的重物运动方程的解中找到。通常，物理学中遇到的方程产生的无量纲系数具有单位*)的数量级。精确计算得出 $C$ 的值为 2π。

因此，无需计算，仅使用尺寸分析，我们就找到了外部重物振荡周期的近似值。

泛化示例 - 振荡器

在物理学的所有领域中，都存在与近位系统烧瓶相关的问题。要理解多种现象并因此对这些现象进行定性分析，您需要了解此类系统的一般属性。围绕平衡位置振动的系统，无论其结构如何，都称为振荡器。振动最简单的例子是外部重量，即数学垫。一个更复杂的例子是一个紧张的国家；它可以有多种类型的振动：中间有波腹的振动（基音）、有一个波节、两个波节等（泛音）。因此，一个国家是一组不同频率的振荡器。类似的例子还有劳动组织中的空气柱；当空气在某些点静止时（类似于弦振动器中的节点），可以使其以最高频率（基音）或更高频率振动。

$$E = \gamma q^2 / 2 + \beta \dot{q}^2 / 2,$$

其中$q$是表征偏离平衡位置的量，$\dot{q}$是量$q$随时间的变化率（即$\dot{q} = \Delta q / \Delta t$，其中$\Delta t$是一小段时间）。 $\Pi = \gamma q^2 / 2$项是振荡器的势能；系数$\beta$称为振子质量。 $K = \beta \dot{q}^2 / 2$项是振荡器的动能；系数$\beta$称为振子质量。 （记住最简单的振荡器（外部重量）的能量是如何书写的，你就会明白为什么 $\gamma$ 被称为刚度，而 $\beta$ 是振荡器的质量。）

$$\omega = \sqrt{\gamma / \beta}.$$

为了清楚起见，我们举另一个振荡器的例子，它与上面给出的所有例子都不相似。假设有一个由导电良好的导线制成的电感器$L$，其两端连接到具有电荷$Q_0$的电容器电容量$C$。电路中会产生电磁振荡。如果线圈由超导体制成（这需要低温），则振荡实际上不会被阻尼。

这种系统的能量由两项组成：线圈中磁场的能量和电容器中电场的能量。电容器电场的能量与当前位于电容器极板上的电荷$Q$的平方成正比：$\Pi = \frac{1}{C} Q^2 / 2$。

线圈磁场的能量与当前流过线圈的电流$I$的平方成正比：$K = L I^2 / 2$。但电流强度等于电容器电荷随时间的变化率：$I = \dot{Q}$。因此，线圈的磁场能量为$K = L \dot{Q}^2 / 2$。

因此，系统任意时刻的能量等于

$$E = \frac{1}{C} Q^2 / 2 + L \dot{Q}^2 / 2.$$

我们的系统是一个振荡器；振荡坐标的作用是由电荷$Q$起的，振荡器的势能是电容器的能量，动能是线圈的磁场的能量。从能量记录中可以清楚地看出，该振荡器的刚度为$1/C$，电感质量的作用为$L$。您可以立即写下部分振动：$\omega = \sqrt{1/LC}$。

如何猜测解决方案？

让我们举一个例子，说明在建立问题的精确解决方案之前，在找到解决问题所依据的方程之前，如何要求解决方案的某些特征。这是一个比振荡器情况更复杂的维度分析的倒退示例。

理论物理中最困难和尚未解决的问题之一是引力和电磁现象之间的联系。

如果存在这种联系，那么通过求解一些尚未找到的方程，将得到一个无量纲数 *)，给出引力结构 γ 与表征电磁现象的量（例如光速 c、电子电荷 e 及其质量 m）之间的对应关系。

如果存在量子现象，那么问题可能包括普朗克h。知道了量 γ、c、e、m、h 的量纲，很容易验证这些量只能构成两个独立的无量纲组合：

$$\alpha = e^2/\hbar c; \quad \xi = \hbar c/\gamma m^2$$

（回想一下$\hbar = h/2\pi$）。

第一个组合表征了电子与电磁场（电子的无量纲“电荷”）的相互作用，被称为构建的精细结构。代入数值即可得到$\alpha = 1/137$、$\xi = 5 \cdot 10^{44}$。解任何合理的方程是否有可能产生像 xi 这样大的数？正如我们已经说过的，由于解决物理问题而产生的无量纲数具有几个单位或单位分数的量级。

三．终极简化

量子力学基本思想

让我们尝试用另一个例子来说明如何通过将问题简化到极限来确定现象的主要特征。这个例子将强调什么是解决问题的定性方法。

根据量子力学，原子中电子的能量只能取离散值。

氢原子中电子能量的可能值由以下表达式给出

$$E_n = - \frac{me^4}{\hbar^2} \frac{1}{2n^2}.$$

(**)

两个不同 $n$ (n=1,2,3,...) 的 $E_n$ 值的差异可以非常准确地确定在实验中观察到的谱线频率。

量子力学的基本思想是，每个粒子（在本例中为电子）都具有波长为无限的波动过程的特征

$$\lambda = \frac{2\pi \hbar}{mv},$$

其中$m$是粒子的质量，$v$是粒子的速度。电子能量的离散值是根据以下条件获得的：沿着电子运动轨道的长度，必须有

有整数个波。如果轨道半径为$r$，则条件$2\pi r = \lambda n$（$n=1, 2, \dots$）或$mv_n = \hbar n/r$对应于电子的$n$态。从这里不难求出$n$态的动能：

$$W_n = m v_n^2 / 2 = \hbar^2 n^2 / 2 m r^2.$$

电子的总能量是动能和核场势能之和，为负值，等于$U = -Z e^2 / r$。氢原子中电子的总能量为

$$E_n(r) = \hbar^2 n^2 / 2 m r^2 - e^2 / r.$$

在我们的推导中，我们假设轨道半径 $r$ 具有固定值。根据量子力学，轨道半径“分散”在经典轨道源附近。作为半径的估计，我们可以取值 $r$，它对应于最小能量 $E(r)$。

为了找到最小值 $E(r)$，我们进行如下操作。让我们将 $E(r)$ 的表达式重写如下：

$$E = A x^2 - B x.$$

我们使用以下名称：$x = 1 / r$、$A = \hbar^2 n^2 / 2 m$、$B = e^2$。可以看出，对于$x_1 = 0$和$x_2 = B / A$，$E$的值为零。积分$]x_1, x_2[$E内为负数。该积分内部的某个位置存在最小值 $E$。为了便于估计，我们假设$E_{\min}$对应于积分中间的值$x$，即$x = B / 2 A$。相应地，$r = 1 / x = 2 A / B$，即

$$r_n = \frac{\hbar^2 n^2}{m e^2}.$$

（请注意，对于 $n = 1$ 这个表达式

$$E_n = - \frac{m e^4}{\hbar^2} \frac{1}{2 n^2},$$

即，匹配 (**) 的表达式！

实际上，电子可以以不同的概率位于距原子核的任意距离处。我们对介词中状态的简化，即这个距离是确定的，等于$r$，是从最小能量的条件找到的。当然，我们的行为很粗鲁。因此，你不能相信这个公式前面的数字因子，即使它恰好是正确的。但其他一切都可以相信！还有集合$me^4 / \hbar^2$，最重要的是，对“量子数”$n$的依赖。

精确的解决方案需要量子力学基本方程（薛定谔方程）的值和非常复杂的（根据学校概念）数学。当结果精确到未知的数值因子时，我们获得的是定性解决方案，但准确地传达了对问题参数的依赖性的本质。定性解决方案使得获得准确的解决方案变得非常容易，因为该现象的主要特征已被阐明。此外，如果有高质量的解决方案，但不可能获得精确的分析解决方案，则可以使用计算机来完成，而不会造成问题位置的任何重大损失。

另一种概括——量子振荡器

量化振荡器的问题不再难以解决。同时，我们也不知道振荡器是如何实现的——是用外部振荡的负载来表示，还是用电振荡电路来表示。

让我们用 $q$ 表示振荡器的广义坐标。让我们写下振荡器的能量：

$$E = \gamma q^2 / 2 + \beta q^2 / 2.$$

可以想象，振荡器是一种质量为β、振荡外部刚度为γ的“粒子”。为了阐述该物体的量子力学基本思想，我们取与“粒子”相关的波过程的波长 λ：

$$\lambda = 2\pi \hbar / \beta q.$$

分母是“质量”与其速度的乘积。由于速度随着粒子的移动而变化，因此波长也会变化 - 它是平衡位置的最小值，并且在“粒子”速度较低的那些区域中增长。

让“粒子”在 - $q_0$ 到 $q_0$ 的区域内移动。 （我们强调，$2q_0$不是振荡振荡器的摆动，而是其坐标“颤抖”的区域。）为了形成驻波，必须在“长度”$2q_0$：$2q_0 = (n+1)\lambda/2$（$n=0, 1, 2, \dots$）上放置整数个半波。作为速度的估计，我们取$q=q_0$处的速度值，即$(q)_0 = 2\pi \hbar / \beta \lambda = \pi \hbar (n+1)/2\beta q_0$。将这个值代入动能表达式，我们发现：

$$W_n = \frac{\pi^2 \hbar^2}{8\beta} \frac{(n+1)^2}{q_0^2}.$$

对于我们得到的总能量：

$$E_n(q_0) = \frac{(\pi \hbar)^2}{8\beta} \frac{(n+1)^2}{q_0^2} + \frac{\gamma q_0^2}{2}.$$

对于较小的 $q_0$ 值，由于第一项，能量较高；对于较大的 $q_0$ 值，由于第二项，能量较高。如果我们将两项相等，就可以获得 $q_0$ 的近似值，甚至是最小的能量。从这个条件我们发现：

$$q_0^2 = \frac{\pi \hbar (n+1)}{2\sqrt{\beta \gamma}}.$$

代入能量表达式，可得：

$$E_n = \frac{\pi}{2} \hbar \sqrt{\gamma/\beta} (n+1) = \frac{\pi}{2} \hbar \omega (n+1) \quad (n=0, 1, 2, \dots).$$

值$\omega = \sqrt{\gamma/\beta}$代表振荡经典振荡器的频率。

准确计算能量结果：

$$E_n = \hbar \omega \left( n + \frac{1}{2} \right).$$

因此，我们在数值因子上犯了错误（$\pi/2$而不是1），以及最低状态下的能量数值，即$n=0$（$\frac{\pi}{2} \hbar \omega$而不是$\frac{1}{2} \hbar \omega$）。但其他一切都很顺利！现在已经获得了结果，我们应该考虑我们用什么来获得它，以及从我们获得的振荡器能量和值 $q_0^2$ 的表达式中得出什么结论。

首先，我们将量子力学原理应用于我们的振荡器，而对其结构并不感兴趣，量子力学原理首先是与电子相关的。当然，很自然地期望对于质量与电子质量不同的其他粒子来说，一般原理应该是相同的。事实上，这样的概括已经被实验非常准确地证实了。但为什么这些原理可以应用于谐振电路这样的系统，其中“坐标”的作用是由电容器板上的电荷发挥的呢？这里我们得出一个重要的假设，这个假设在20世纪的理论物理学中被广泛使用和使用。如果两个系统的能量同样取决于坐标和速度，那么这些系统具有相同的属性，尽管“坐标”和“速度”在这些系统中可能具有完全不同的含义。

没有一个例子表明这种假设与经验相矛盾。因此，我们有权认为我们已经解决了将量子力学一次性应用于所有可能的振荡器的问题。
