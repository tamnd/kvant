M513。证明存在一个数字$A$，使得函数$y = A \sin x$的图像可以描述至少1978个成对的非构造性正方形。 （如果一个正方形的所有顶点都属于该图，则该正方形称为内接正方形。）

图 1.

图 2.

为了使点$(x; y)$成为以$O = (0; 0)$为中心的图形$\Gamma$内接的正方形的顶点，条件$(x; y) \in \Gamma$和$(-y; x) \in \Gamma$是充分的，即条件

$$y = A \sin x, -x = A \sin y;$$

在这种情况下，$(-x; -y) \in \Gamma$和$(y; -x) \in \Gamma$，因为$O$是图$\Gamma$的对称中心（图 1；函数$y = A \sin x$是奇数）。因此，方程的每个根

$$\sin (A \sin x) = -\frac{x}{A}, x > 0, y = A \sin x > 0$$ (1)

对应于中心为 $O$ 的内接正方形。让我们证明，对于大的 $A$，这个方程有很多根。

在每个段$x \in [2\pi k; 2\pi k + \pi/2]$上，值​​$y = A \sin x$从0增加到$A$；在每个线段上，$x \in [2\pi k + \pi/2; 2\pi k + \pi]$从$A$减少到0（图2；$k = 1, 2, \dots$）。我们以$A = 2\pi n$为例。然后$y$处的值$z = \sin y$从0变为$A$，运行段$[-1; 1]$$2n$次（这个“运行”在$z = 0$开始和结束，设$k < n$。然后在每个段$[2\pi k; 2\pi k + \pi/2]$和$[2\pi k + \pi/2; 2\pi k + \pi]$方程（1）将有 $2n$ 个根 - 对于从 0 到 $(-1)$ 以及返回的每个转换 $z$，图形 $z = \sin (A \sin x)$ 与直线 $z = -\frac{x}{A}$ $2n$ 次相交，因为 $|x/A| < 1$ 在 $0 \leq x \leq 2\pi k + \pi < A$ 处，总共方程 (1) 将有 $4n^2$ 根（$k = 0, 1, \dots, n - 1$）。

为了确保平方是成对非构造性的，我们只取 $x \in [0; \pi/2]$。对于$A > 1978\pi$，方程（1）将有至少1978个根的这段，且$x$越多，$y = A \sin x$和$\sqrt{x^2 + y^2}$越多；这意味着所有相应的 1978 个方格都是非构造性的。

基于以下考虑，可以获得问题 M513 的另一个更几何的解决方案：让我们将函数 $y = A \sin x$ 的图形 $\Gamma$ 围绕点 $O$ 旋转 $90^\circ$。则图$\Gamma$与旋转图$\Gamma'$（$O$除外）的任意交点作为圆心$O$内接于$\Gamma$的正方形的顶点。

请注意，我们解决方案中讨论的所有正方形的对称中心都位于点 $O$。显然，任何内接于$\Gamma$的正方形都有一个对称中心在点$(2\pi n; 0)$之一（即在图$\Gamma$的对称中心之一）；尝试证明这一点。

第二个解决方案。让我们把$x_n = n\sqrt{2} - a_n$，其中$a_n$是最大的整数，不超过$n\sqrt{2}$。显然$0 < x_n < 1$。让我们证明对于任何 $m > k > 1$

$$|x_m - x_k| \cdot (m - k) > 1/4,$$

也就是说，序列 $(4x_n)$ 被排除。

让我们评估一下数量的强度

$$|x_m - x_k| = |(m - k)\sqrt{2} - a_m - a_k|$$

$$= \frac{|2(m - k)^2 - (a_m - a_k)|}{|(m - k)\sqrt{2} + (a_m - a_k)|}.$$

$$(m - k)\sqrt{2} + (a_m - a_k) < 2(m - k)\sqrt{2} + 1 < (m - k)(2\sqrt{2} + 1) < 4(m - k).$$

从这里我们得到$|x_m - x_k| > \frac{1}{4(m - k)}$。

F521。 图 11 显示了优质粉笔的部分轨迹，被扔到地平线下方。在波瓣 A 中，粉笔的速度等于横坐标值 20 m/s。柠檬从 A 室移动到 B 室需要多长时间？

与地平线成一定角度抛出的物体以自由落体加速度 $g$ 匀加速运动；其速度在$OX$轴上的投影保持不变，在垂直$OY$轴上的速度投影按规律随时间变化

$$v_y = v_0 + gt,$$

其中 $g = -9,8 \text{ m/c}^2$ 是向量 $g$ 在轴 $OY$ 上的投影。如果$t_0$是物体从A点移动到B点的时间，则$v_{By} = v_{Ay} + gt_0$，由此

$$t_0 = \frac{v_{By} - v_{Ay}}{g} = \frac{\Delta v_y}{g}.$$

因此，要找到$t_0$，您需要找到物体速度在轴$OY$上的投影的变化。

A 点和 B 点处的物体速度矢量 $v_A$ 和 $v_B$ 与这些点处的物体轨迹相切。让我们在任意选择的比例上绘制向量$v_A$，并在B点绘制轨迹的切线。找到A点处物体速度在轴$OX$上的投影$v_x$，并在通过B点绘制的水平线上绘制相同长度的线段。现在通过延迟线段的末端画一条垂直线，找到向量$v_B$及其投影$v_{By}$ 到轴 $OY$。使用尺子测量$v_{Ay}$和$v_{By}$后，我们找到值$\Delta v_y$（它与所选的比例无关），然后找到身体从A点移动到B点的时间$t_0$。

在我们的例子中$\Delta v_y = |v_{By}| + |v_{Ay}| = 33 \text{ (м/c)}$，$t_0 \approx 3,3 \text{ c}$。

直升机（或模型）之所以能够停留在空中，是因为螺旋桨被“抛”向气流时产生的反作用力。根据牛顿第三定律，作用在直升机上（螺旋桨上）的反作用力的绝对值等于作用在喷气机上的力。

让我们用$\rho$表示空气密度，$S$表示射流面积，$v$表示射流速度的绝对值。然后，在$\Delta t$时间内，螺旋桨被抛出空中$Sv\Delta t$，质量为$m=\rho Sv\Delta t$，空气动量变化量

$$\Delta p=mv=\rho Sv^2\Delta t.$$

根据牛顿 II 定律，作用在虎钳上的力 $F$ 其绝对值等于

$$F=\frac{\Delta P}{\Delta t}=\rho Sv^2.$$

同样的绝对力作用在直升机上。为了使直升机保持在空中，$F$必须等于作用在直升机上的重力的绝对值$Mg$：

$$\rho Sv^2=Mg.$$

推进力$N$等于1秒内传递给空气的能量：

$$N=\frac{mv^2}{2\Delta t}=\frac{\rho Sv^3}{2}.$$

代入 (*) $v=\sqrt{\frac{Mg}{\rho S}}$，我们得到

$$N=\frac{1}{2}Mg\sqrt{\frac{Mg}{\rho S}}.$$

由于直升机的质量 $M$ 与其体积（即线性尺寸 $M \sim L^3$ 和 $S \sim L^2$ 的立方）成正比，则

从 (**) 我们有：

$$N \sim L^{7/2}.$$

这意味着直升机和模型的发动机功率之比必须等于它们的线性尺寸与功率之比7/2，即

$$\frac{N}{N_{\text{мод}}} = \left( \frac{L}{L_{\text{мод}}} \right)^{7/2}.$$
