现将1978年入学考试材料公布如下。

数学

力学与数学学院
选项一
1. 不同之处
$$\sqrt{|40\sqrt{2}-57|} - \sqrt{40\sqrt{2}+57}$$
是一个整数。求这个整数。
2. 找到方程的所有解
$$\int_0^\alpha \cos(x + \alpha^2) dx = \sin \alpha,$$
属于段[2; 3]。
3. 在锐角三角形 ABC 中，高度 AP 和 CQ 从顶点 A 和 C 下降到边 BC 和 AB。已知三角形ABC的面积为18，三角形BPQ的面积为2，线段PQ的长度为$2\sqrt{2}$。计算三角形 ABC 外接圆的半径。
4. 找出不等式组中参数a的所有值
$$\begin{cases} x^2 + 2xy - 7y^2 \geq \frac{1-a}{a+1}, \\ 3x^2 + 10xy - 5y^2 \leq -2, \end{cases}$$
有一个解决方案。
5. 四面体ABCD的体积等于5。通过边AD和BC的中点画一个平面，与边CD相交于点M。在这种情况下，线段DM的长度与线段MC的长度之比为$\frac{2}{3}$。如果从指定平面到顶点 a 的距离为 1，则计算四面体的横截面积。

计算数学与控制论学院
选项2
1. 解决不平等问题
$$(x-1)\sqrt{x^2-x-2} \geq 0.$$
2. 找到函数的最小点
$$\sqrt{3}\cos \frac{x}{2} + \sin \frac{x}{2} - \frac{x-3}{2}.$$
3. 求一条穿过坐标为 $\left(\frac{1}{2}; 2\right)$ 的点、与函数 $y = -\frac{x^2}{2} + 2$ 的图形相切并在函数 $y = \sqrt{4-x^2}$ 的图形上的两个不同点相交的直线方程。
4. 集合A由不同的自然数组成。 A 中的数字个数大于七。 A 中数字的最小公倍数是 210。对于 A 中任意两个数字，它们的最大公约数都大于 1。 A 中所有数字的乘积可被 1920 整除，并且不是任何整数的平方。找出组成 A 的数字。
5. 参数ABCEH的基础是凸四边形ABCE，它被对角线BE分成两个大小相等的三角形。边AB的长度等于1，边BC和CE的长度相等。边 AH 和 EH 的长度之和为 $\sqrt{2}$。参数的体积为$\frac{1}{6}$。找出符合参数 ABCEH 的所有球中具有最常见半径的球的半径。
3. 口语考试任务
1. 求最小和最大函数$f(x) = a\sin x + b\cos x$。
2. 解自然数方程
$$A_x^2 + 3 = C_x^2 + 20.$$
3. 证明如果所有平分线的长度都小于一，则三角形的面积小于一。
4. 证明不等式$3 < \pi < 4$。
5. 绘制函数图
$$y = \log_2 |\sin x| \frac{1}{2}.$$
6. 如果已知$\lg 15 = a$、$\log_{20} 50 = b$，则计算$\log_2 40$。
