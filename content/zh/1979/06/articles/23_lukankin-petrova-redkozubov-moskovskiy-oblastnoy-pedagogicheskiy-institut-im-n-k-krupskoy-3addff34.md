⟦folio 50⟧

普通物理学和天文学，以及社会政治学科和心理学教学循环学科。

学院为培养未来数学教师的创造性技能创造了一切条件：每天提供70多名数学和教育学科的专家和专家供3-5年级的学生选择；学生撰写课程作业和论文以及各种数学和教学主题的参考文献。未来的教师从学习的第一年开始，就在学生科学协会系统的俱乐部和科学研讨会中获得了他的第一份研究工作技能。

学院最优秀的学生被推荐到院系攻读研究生，毕业后成为师范大学的研究员或教师。

该学院设有7个系：数学分析、高等代数、几何、数论、计算数学和编程、数学教学方法、物理。

数学学院设有一个计算机中心，学生可以在那里熟悉现代计算技术，获得使用电子计算机的技能，并作为一个项目进行特殊实践。

入学后，将参加以下入学考试：数学（笔试和口试）、物理（口试）、文学和俄语（笔试）。

1978年，在数学学院，证书平均分为5.0或4.5的申请者在前两次考试（数学笔试和口试）后得分至少为9分，即可被该学院录取。

数学
笔试

选项1

1. 该容器含有12升盐酸。倒出一些盐酸并向容器中加入等量的水。然后再次倒入相同量的混合物和具有相同量水的附加容器。如果容器中的结果是二十五戊丁盐酸，每次倒入多少升？

2. 计算由曲线$y=x^2+1$、$y=-x^2+3$围成的图形的面积。

3. 证明相同性

$$\cos^2 x + \cos^2 \left( \frac{\pi}{3} + x \right) + \cos^2 \left( \frac{\pi}{3} - x \right) = \frac{3}{2}.$$

4. 证明点 $A(1; -1; 1)$、$B(1; 3; 1)$、$C(4; 3; 1)$、$D(4; -1; 1)$ 是直滑雪板的顶点。

莫斯科地区师范学院以此命名。 N.K. Krupskaya 是在教学技术和职业教育的基础上组织的。 Profinentna于1931年成立。目前，该学院的师资培训在10个学院和34个系进行，聘有48名教授和理学博士，250多名副教授和理学博士生。

数学学院为中学培养数学教师。该学院的三个系提供以下专业的研究生培训：数学分析、数学教学方法、几何和拓扑、代数和数论。

物理学院培养物理教师，工业教育学院培养社会教育学科和劳动教师。这些院系设有以下专业的研究生课程：数学分析、实验物理、理论物理、物理教学方法和劳动培训。

⟦folio 51⟧

该学院的预科部门作为教职员工，开展以下专业的部分培训（从生产开始）：数学、物理、一般技术学科和劳动。

数学
笔试

数学学院

1. 计算由线 $y = \frac{5}{x}, y = 6 - x$ 围成的图形的面积。

2. 在 $AB$ 和 $CD$ 梯形 $ABCD$ 的基础上构造出正方形（在其外部）。证明连接正方形中心的线经过梯形对角线的交点。

3. 解决不等式
$$\log_{x^2}(3 - 2x) > 1.$$

4. 解方程
$$2\cos x = \sqrt{2 + \sin 2x}.$$

5. 正四边形直线的高度与侧面所成的角为30°。通过直线底边绘制一个平面，垂直于相对面。求直线与平面相交时所得到的多面体的体积之比。

物理学院

1. 写出抛物线$y = x^2 - 2x$在横坐标$x_0 = 0,5$的切线方程。

2. 在三角形$ABC$的边$AB$上取点$M$，使得$|AM| : |MB| = 1 : 1$。如果$|AC| = 6$、$|BC| = 4$、$ACB = 120^\circ$，则计算$|CM|$。

3. 解决不等式
$$\log \frac{3x - 1}{2x + 1} > 0.$$

4. 解方程
$$tg x + \frac{\cos x}{1 + \sin x} = 2.$$

5. 正四边形直线$a$的底边；两倍的高度。求通过底边相邻两条边的中点和对称中心所画截面的面积。

物理
口语考试目标

1. 要起飞，飞机必须达到 $|\vec{v}| = 250$ km/h 的海岸速度。如果在$l = 1,0$公里长的绿色车道尽头达到这个速度，加速需要多长时间？飞机的加速度是多​​少？飞机在这段航段上的平均速度是多少？飞机的运动被认为是匀加速的。

2. 质量为 $m_1 = 3 \cdot 10^4$ kg 的汽车，沿水平轨道以 $|\vec{v}| = 1,5$ m/s 的速度移动，自动以 $m_2 = 2 \cdot 10^4$ kg 的静止质量进行移动。如果摩擦系数为 $\mu = 0,005$，质量为 $m = 3000$ t 的物体将以 $|\vec{v}| = 72$ km/h 的匀速运动，其速度是多少？

3. 如果摩擦系数为 $\mu = 0,005$，电力机车在 $t = 10$ 分钟内将重量为 $m = 3000$ t 的列车以$|\vec{v}| = 72$ km/h 的匀速沿水平轨道行驶，会做什么功？

4. 在$t_1 = 17^\circ C$温度下装有$m_1 = 400$克水的容器中，在$t_2 = 100^\circ C$引入$m_2 = 10$克蒸汽，蒸汽变成水。确定最终水温。忽略容器的体积和本体的损失。水的比热为$c = 4200$J/(kg·K)，水的汽化比热为$L = 2,26 \cdot 10^5$J/kg。

5. 将一块重量为 $m_3 = 50$ 克（在 $t_2 = 0^\circ C$ 下取出）的小块放入水中后，重量为 $m_1 = 160$ 克、含有 $m_2 = 400$ 克水、温度为 $t_1 = 25^\circ C$ 的水熔化后，会达到什么温度？黄铜和水的比热相当于$c_1 = 3,8 \times 10^2$ J/(kg K)和$c_2 = 4,2 \cdot 10^3$ J/(kg K)；水的汽化比热$\lambda = 3,35 \cdot 10^5$J/kg。

6. 两个电荷 $q_1 = 0,66 \cdot 10^{-7}$ C 和 $q_2 = 1,1 \cdot 10^{-5}$ C 在距离 $r = 3,3$ cm 的水中 ($\epsilon = 81$) 相互作用的力是多大？它们应该放置在真空中多远的距离才能使相互作用力保持相同？

7. 电子在真空中沿着电场的梅花线移动，在电势差为 $U = 400$ V 的点之间完全失去速度。确定电子进入电场时的速度是多少。

8. 手电筒电池的电动势为 $G = 4,5$ V。外部电阻为 $R = 12$ Ohm，电路中的电流为 $I = 0,3$ A。确定电池的内阻及其两端的电压降。

9. 如果已知距离镜头$d = 30$cm处的物体的实际图像与镜头的距离相同，则求镜头的焦距。

10. 红宝石被长度为 $λ = 3,17 \cdot 10^{-7}$ m 的超短光束照射时发射的电子最大动能等于 $W = 2,84 \cdot 10^{-19}$ J。确定铷的电子逸出功和光电系数红限。普朗克常数 $h = 6,62 \cdot 10^{-34}$ J s。
