口语考试目标

1. 球以与水平面成 $\alpha = 60^\circ$ 的角度以 $|\vec{v}_0| = 20$ 米/秒的速度投掷。确定最高升力高度和飞行范围。忽略空气阻力。

2. 必须用多大的水平方向的最小力$\vec{F}_{\min}$将一块扁块压在墙上才能使其不会滑落？棒材的质量为 $m = 5$ kg；墙与块之间的摩擦系数$k = 0,1$。

3. 质量为 $m_1 = 50$ kg 的弹丸，以 $|\vec{v}| = 800$ m/s 的速度，与垂直方向成 $\alpha = 30^\circ$ 的角度飞行，击中带有沙子的固定平台并卡在其中。如果弹丸质量为 $m_2 = 16$ t，求抛射体撞击后平台的速度 $|\vec{u}|$。

4. 如果已知体积为 $V_2 = 0,1$ m3 的铝块冻结在浮冰上，会卡在其下沉中，浮冰在水中的最大体积 $V_1$ 是多少？水中冰和铝的密度分别为$\rho_1 = 900$ kg/m3、$\rho_2 = 2700$ kg/m3 和$\rho_3 = 1000$ kg/m3。

5. 报告温度为 $t$ 的液体的填充状态。当在其中之一加热液体时
当容器温度达到 $t_1$ 时，液位在该状态下建立在高度 $h_1$ 上，而在另一种状态下则建立在高度 $h_2$ 上。求液体的体积膨胀系数。

6. 将一块冷却至 $t_2 = -50^\circ$ C 的冰放入装有$m_1 = 10$ kg 温度为 $t_1 = 10^\circ$ C 的水的容器中，之后所得冰块的温度等于 $0 = -4^\circ$ C。容器中总共有多少冰？水的比热$c_1 = 4200$ J/(kg K)和冰的比热$c_2 = 2100$ J/(kg K)； $t_0 = 0^\circ$ C $\lambda = 3,3 \cdot 10^5$ J/kg 时冰的熔化比热。

7. 在垂直方向感应的均匀磁场中，其模型为$|\vec{B}| = 0,1$ mT，长度为$l = 2$ m的导线以$|\vec{v}| = 5$ m/s的速度垂直于导体运动。导体中感应出什么电动势？

8. 在距凹面镜顶部$d = 0,14$米处有一个物体，其高度为$l = 0,06$米。镜子的焦距为$F = 0,11$米。求物体图像的高度$L$。

9. 必须将尺寸为 $l = 8$ 厘米的物体投影到屏幕上。镜头的焦距为$F$，距屏幕的距离为$f = 4$米，这样物体在屏幕上的图像大小为$L = 2$米？

莫斯科地质研究所得名。谢尔戈·奥尔忠尼启则

莫斯科地质研究所 (MGRI) 旨在作为莫斯科矿业学院的地质系存在，是在 V.I. 的倡议下创建的。 1918年9月列宁。目前，莫斯科劳动勋章更换地质研究所以红色命名。谢尔戈·奥尔忠尼启则大学是一所培养采矿地质工程师、地球物理学家和矿床开发商的专业大学。

MGRI 设有以下院系：地质学、地球物理、技术勘探与开发、水流变学。此外，还有一个夜间学院，学生可以在那里学习日间学院的所有专业。
