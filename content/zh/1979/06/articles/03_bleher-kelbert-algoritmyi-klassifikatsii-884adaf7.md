分类算法

在这篇文章中，我们将讨论不久前出现的一门科学的一个部分——模式识别理论*)。即：我们将讨论分类方法。分类是将一组特定的对象划分为在某种意义上接近的对象组。例如，您可以对在某些区域地震中观察到的给定行业中的工厂、多年来的九月天气、灭绝的蜥蜴等进行分类。唯一重要的是要分类的对象具有一组特定的数字和特征。为了简单起见，我们将考虑每个对象仅由一组数字描述的情况。

*) 对于那些想在使用中熟悉它的人，我们建议您阅读 M. M. Bongard 所著的这本引人入胜但不是很简单的书“识别问题”（M.，“Hayka”，1967 年）。

如何对小学生进行分类？

假设我们要根据给定学校的所有九年级学生如何利用课外时间来划分他们。我们要求每个学生写下他花在课程上的时间以及娱乐上的时间。剩下的时间（吃饭、睡觉、交通等）现在对我们来说不感兴趣。因此，每个学生都会有两个数字：上课时间和娱乐时间。因此，可以用坐标平面上的点来表示。因此，我们遇到了一个纯粹的数学问题：如何将给定的一组集合划分为相似数字的组？

没有车很难

为了解决分类问题，已经开发了允许使用计算机的各种算法。使用计算机的需要有两个原因。首先，通常对象很多，手动处理所有数据根本不可能。其次，分类对象通常是多维的。

如果像小学生的例子一样，只有两个坐标并且对象数量很少，那么一个人处理分类任务的能力并不比计算机差。即：他会看一张描绘了代表物体的点的图片，他会看到与该点的凝结相对应的云。实验表明，所有人都以大致相同的方式做到这一点。这是因为他们（人们）不自觉地倾向于确保一组中的点彼此接近，而不同组中的点足够远。如果参数的数量等于或更多，则可视化消息实际上毫无用处，并且分类任务变得难以让人理解。

分组

构建最小长度的树Г后，通过绘制该树中包含的一些线段来将点集$A_1, \dots, A_N$划分为组。当然，会绘制相当长的线段，但使属于一组的点尽可能靠近。该视觉消息可以通过输入以下数量来形式化。让我们想要将点集 $A_1, \dots, A_N$ 分成 $k + 1$ 组。让我们选择树 Г 的任意 $k$ 段并丢弃它们 (图 1)。我们得到 $k + 1$ 连接的点组：$\Gamma_1, \dots, \Gamma_{k+1}$。对于每个组 $\Gamma_i$，我们将树 Г（其中包含的连接点）的线段长度之和除以线段数量。我们得到了每组中线段的平均长度$\Gamma_i$。如果某个组由一个点组成，那么根据定义，该平均长度为零。让我们用 $l_1, l_2, \dots, l_k, l_{k+1}$ 表示计算出的平均长度。此外，让重新生长的线段的长度为 $b_1, b_2, \dots, b_k$。让我们形成数量

$$F = l_1 + l_2 + \dots + l_{k+1} - b_1 - \dots - b_k.$$

显然，$F$值越小，各组中的点间隔越近，不同组之间的距离也越远。

因此，很自然地提出以下算法：从最小长度的树中，我们以所有可能的方式丢弃$k$段并计算值$F$；在所有获得的分区中，我们选择$F$值最小的一个；如果有多个“最小”分区，我们就采用其中任何一个。

作为所使用的算法的结果，值$F$通常以更复杂的方式确定。

计算实践表明，所描述类型的算法可以产生相当合理的分区。这些算法的主要缺点是它们需要太多的蛮力。随着点数的增加，即使对于现代计算机来说，该任务也变得难以完成。

为了应对这一困难，使用了以下想法。点之间的距离小于某个值$a$，往往相对属于同一组。所有施工均分两个阶段进行。在第一阶段，点集$A_1, \dots, A_N$被分成更小的组$G_1, \dots, G_m$，这样对于每个组$G_i$，都有一个半径为$R = a/2$的圆$S_i$，包含组$G_i$的所有点并且仅包含它们。我们将在下面讨论如何做到这一点。在第二阶段，仅考虑圆$S_1, \dots, S_m$的中心$O_1, \dots, O_m$，并为集合$O_1, \dots, O_m$构建最小长度的树。通过最小化与该树相对应的值$F$，可以如上所述将点集$O_1, \dots, O_m$划分为组。因此，我们还获得了点集$A_1, \dots, A_N$的划分。即，如果两个点$A_i, A_j$位于同一小组$G_i$中，或者如果在划分点$O_1, \dots, O_m$时，圆心对应于该小组并落入一组，则它们属于同一组。这个两阶段过程的意义是减少起始点的数量：$m$的数量比$N$少得多，而且处理器已经可以在计算机上实现。

一个点距离圆心$S$越近，它对值$F(S)$的贡献就越大。让我们证明数量$F(S_0), F(S_1)$的序列，

$$F(S_2), \dots$$ 增加直到圆圈停止。

为了证明这一点，我们需要层次矩和点 $A_1, \dots, A_m$ 相对于某些 $A$ 的材料系统和斯坦纳定理，这对于解决许多问题非常有用，不仅来自几何，而且还来自力学 *)。

点 $A_1, \dots, A_m$ 的材料系统相对于点 $A$ 的转动惯量是

$$I(A) = |AA_1|^2 + \dots + |AA_m|^2.$$

斯坦纳定理允许在转动惯量 $I(C)$ 已知的情况下计算 $I(A)$。该点系统相对于其重心 $C$ 的位置。该定理指出

$$I(A) = I(C) + m|CA|^2.$$

让我们证明斯坦纳定理。我们引入一个直角坐标系，其原点位于点$A_1, \dots, A_m$ - 点$C$的重心处。让我们用 $(x_1; y_1), \dots, (x_m; y_m)$ 表示点 $A_1, \dots, A_m$ 的坐标。那么重心$C$的坐标为$(x_1 + \dots + x_m)/m; (y_1 + \dots + y_m)/m)$，由于$C$与坐标原点重合，所以$x_1 + \dots + x_m = y_1 + \dots + y_m = 0$。设点 $A$ 的坐标为 $(x; y)$。然后

$$I(A) = \left[ (x_1 - x)^2 + (y_1 - y)^2 \right] + \dots + \left[ (x_m - x)^2 + (y_m - y)^2 \right] = \left( x_1^2 + y_1^2 \right) + \dots + \left( x_m^2 + y_m^2 \right) + m \left( x^2 + y^2 \right) - 2x \left( x_1 + \dots + x_m \right) - 2y \left( y_1 + \dots + y_m \right) = I(C) + m|CA|^2,$$

从$2x(x_1 + \dots + x_m) = 2y(y_1 + \dots + y_m) = 0$开始。斯坦纳定理已被证明。
