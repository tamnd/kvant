⟦folio 31⟧

通常，我们的距离要远得多（通常是 25 厘米的视觉距离），因此一束非常窄的光线，具有大致相同的倾斜角度，会立即击中我们。 （自己检查一下，对于射到瞳孔中心及其边缘的光线，类似于方程（1）-（3）的方程组将是一致的，即折射光线的延伸将相交于一点。）

因此，我们可以看到水下的物体，因为我们的眼睛立即限制了图像产生的光束的宽度。

问题 2. 在装满水的容器底部有一面平面镜。一个人弯腰在容器上，在距离 $d = 25$ cm (图 2) 的地方看到自己眼睛的图像。眼睛到水面的距离是$h = 5$厘米。水的折射率为$n = 4/3$。确定容器的深度$H$。

解决此类问题时最重要的是仔细构建光线路径。令$A$点为人眼的某个点。要构建点的图像，您需要使用至少两条射线。

图 2.

一条射线通常被视为垂直于不同介质之间界面的射线 - 在 图 2 处，这是射线 $AB$。它在没有折射的情况下通过界面，并在不改变倾斜角度的情况下从镜子反射。

空白空间的第二条射线将是任意射线$AC$。在空气和水的界面（$C$点），它会经历折射，到达镜子，在$D$点被反射，在界面（$E$点）再次折射，并沿$EF$方向释放到空气中。

在射线 $BA$ 和 $EF$ 延长线的交点处，将出现所选点 $A$ 的图像 $A'$。

现在我们来计算一下。由于眼睛瞳孔的大小（它们明显小于距离$d$、$h$和$H$），我们感兴趣的所有眼睛角度及其切线都可以用鼻烟或角度本身来代替。 （注意，在图2处，为了清楚起见，水平比例大大增加。）从图2如下，

$$|BC| = h \mathrm{tg} \alpha_1 = h \sin \alpha_1,$$
$$|CE| = 2H \mathrm{tg} \alpha_2 = 2H \mathrm{tg} \beta_1 = 2H \sin \beta_1/n,$$
$$d = h + |BA'| = h + |BE|/\mathrm{tg} \beta_3 = h + |BE|/\mathrm{tg} \alpha_1 = h + (|BC| + |CE|)/\sin \alpha_1 = 2h + 2H/n.$$

从这里

$$H = n (d/2 - h) = 10\text{ см.}$$

您已经看到，在这个问题中，眼睛既是光源又是接收器。当考虑包含平面镜或球面镜的光学系统时，类似的情况也是可能的。
