落入$S_1$但未落入$S_0$的ki是从$q + 1$到$r$的数字。因此，在圆$S_0$中有点$A_1, \dots, A_q$，在圆$S_1$中有点$A_{p+1}, \dots, A_r$。显然，$F(S_0)$可以用$A_1, \dots, A_q$点相对于$O$点——圆心$S_0$的转动惯量$I(O)$来表示，即

$$F(S_0) = (R^2 - |OA_1|^2) + \dots + (R^2 - |OA_q|^2) = qR^2 - I(O).$$

点 $O_1$ — 圆心 $S_1$ — 是点 $A_1, \dots, A_q$ 的重心，因此，根据斯坦纳定理

$$I(O) = I(O_1) + q |OO_1|^2,$$

那是

$$F(S_0) = qR^2 - I(O_1) - q |OO_1|^2 = (R^2 - |O_1A_1|^2) + \dots + (R^2 - |O_1A_q|^2) - q |OO_1|^2.$$

让我们将这个表达式与

$$F(S_1) = (R^2 - |O_1A_{p+1}|^2) + \dots + (R^2 - |O_1A_r|^2).$$

表达式 $F(S_1)$ 缺少项

$$(R^2 - |O_1A_1|^2), \dots, (R^2 - |O_1A_p|^2),$$

但出现了条款

$$(R^2 - |O_1A_{q+1}|^2), \dots, (R^2 - |O_1A_r|^2).$$

波兹尼

$$F(S_1) - F(S_0) = -(R^2 - |O_1A_1|^2) - \dots - (R^2 - |O_1A_p|^2) + (R^2 - |O_1A_{q+1}|^2) + \dots + (R^2 - |O_1A_r|^2) + q |OO_1|^2.$$

现在让我们注意——这是一个决定性的情况——根据构造，点$A_1, \dots, A_q$位于nekurata$S_1$中。因此，数量$R^2 - |O_1A_1|^2, \dots, R^2 - |O_1A_p|^2$是相对的。例如，点$A_{q+1}, \dots, A_r$位于圆$S_1$内；因此$R^2 - |O_1A_{q+1}|^2, \dots, R^2 - |O_1A_r|^2$的数量是相对的。因此，

$$F(S_1) - F(S_0) \geq q |OO_1|^2,$$

也就是说，如果点 $O_1$ 和 $O$ 不重合，则为 $F(S_1) > F(S_0)$。

同理，如果$O_{k+1}$和$O_k$不重合，则证明$F(S_{k+1}) > F(S_k)$。利用这个事实，现在很容易证明，从某个数字 $n$ 开始，所有圆 $S_n, S_{n+1}, \dots$ 都重合。根据构造，点$O_{m+1}$是落在圆$S_m$内的点的重心。如果我们考虑点$A_1, \dots, A_N$集合的所有子集以及这些子集的点的重心，则点$O_{m+1}$将是这些重心之一。由于重心集是有限的，因此在中心$O, O_1, O_2, \dots$的序列中，必须有重合的中心，例如$O_i$和$O_j$。然而，我们已经证明

$$F(S_i) \leq F(S_{i+1}) \leq \dots \leq F(S_j),$$

由于$S_i = S_j$，$F(S_i) = F(S_j)$，因此$F(S_i) = F(S_{i+1}) = \dots = F(S_j)$。

现在让我们记住，如果圆 $S_i$ 和 $S_{i+1}$ 重合，则相等 $F(S_i) = F(S_{i+1})$ 是可能的。需要注意的是，如果两个连续的圆重合，那么所有后续的圆在构造上都与其重合。这样，我们就证明了圆$S_0 \rightarrow S_1 \rightarrow S_2 \rightarrow \dots$的运动不可能是无限的，或者从数学上来说，我们证明了特劳特算法的收敛性。一路上，我们分析了上次莫斯科数学优化和问题«Kvant»中提出的问题的解决方案（参见«Kvant»中的���题 M505，1978年，第5期）。
