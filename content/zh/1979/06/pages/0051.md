数学
笔试
选项1

1. 解方程
$$3^2 - x = 3^x - 8.$$

2. 无表计算
$$\cos^4 \frac{\pi}{8} + 13 \cos^2 \frac{\pi}{4} + \cos^4 \frac{3\pi}{8} + \cos^4 \frac{5\pi}{8} + \cos^4 \frac{7\pi}{8}.$$

3. 解决不平等问题
$$\frac{(x - 1)(x - 2)(x - 3)}{(x + 1)(x + 2)(x + 3)} > 1.$$

4. 解决不平等问题
$$f'(x) \leq g'(x)$$
如果$f(x) = \frac{2}{x}$； $g(x) = x - x^3$。

5. 给定的偶数点是 $A(-2; -3; 8)$、$B(2; 1; 7)$、$C(1; 4; 5)$ 和 $D(-7; -4; 7)$。
检查向量 $\overrightarrow{AB}$ 和 $\overrightarrow{CD}$ 是否共线。

选项2

1. 解方程
$$4^x + \sqrt{x^2 - 2} - 5 \cdot 2^x - 1 + \sqrt{x^2 - 2} = 6.$$

2. 解方程
$$\sin^2 x = \sin 3x + \cos x (\cos x - 1).$$

3. 解决不平等问题
$$\left| \frac{3x}{x^2 - 4} \right| \leq 1.$$

4. 在 $z$ 的值是多少时，向量 $\overrightarrow{a} = (6; 0; 12)$ 和 $\overrightarrow{b} = (-8; 13; 7)$ 垂直。

5. 计算由线包围的图形的面积
$$y = \frac{1}{\cos^2 x}, y = 0, x = 0 \text{ и } x = \frac{\pi}{4}.$$

选项3

1. 解方程
$$7^1 gx = 98 - x^1 g^7.$$

2. 解方程
$$2 + \cos 4x = 2 \sin^2 x.$$

3. 解决不平等问题
$$\left| \frac{x^2 - 5x + 4}{x^2 - 4} \right| < 1.$$

4. 在 $z$ 的值是多少时，向量 $\overrightarrow{a} = (2; -3; 4)$ 和 $\overrightarrow{b} = (-3; 2; z)$ 垂直。

5. 计算积分
$$\int_3^{-18} \sqrt[3]{2 - \frac{x}{3}} dx.$$

物理
口语考试目标
1. 求将物体沿路径 $l = 10$ m 的速度从 $\overrightarrow{v}_1$ 增加到 $\overrightarrow{v}_2$ = 6 m/s 所需做的功。恒定的摩擦力 $\overrightarrow{F}_{\text{Tp}} = 2\text{H}$ 沿整个路径作用。体重$m = 1$公斤。

2. 钢瓶充满温度为$t = 12^\circ\text{C}$的氮气。氮气压力$p = 15\text{MPa}$。求这些条件下氮的密度。在什么温度下压力会增加到$p_1 = 18\text{MPa}$？忽略气缸壁的膨胀。

3. 在热比$C = 63\text{Дж/K}$$m_1 = 250$的量热计中，在温度$t_1 = 12^\circ\text{C}$下倒入油。将重$m_2 = 500$克的铜体放入温度$t_2 = 100^\circ\text{C}$的油中后，确定最终温度$\theta = 33^\circ\text{C}$。根据实验，油的比热$c_1$是多少？铜的比热容为$c_2 = 0,38\text{кДж/(кг·К)}$。

4. 电荷 $q_1$ 和 $q_2$ 彼此之间的距离为 $r$。如果电荷$q_1$的绝对值增加4倍，它们之间的距离必须改变多少次才能保持相互作用力相同？

5. 四个灯泡，额定电压 $U = 3\text{В}$ 和电流 $I = 0,3\text{A}$，必须并联连接并由电压源 $U_0 = 5,4\text{В}$ 供电。灯链上应串联什么附加电阻？

6. 波长$\lambda = 0,5\text{мкм}$的光从钠中射出电子的最大速度是多少？钠的红色光电边界是 $\lambda_{\text{кр}} = 0,68\text{мкм}$。普朗克常数$h = 6,62 \cdot 10^{-34}\text{Дж·с}$，电子质量$m = 9,1 \cdot 10^{-31}\text{кг}$。
