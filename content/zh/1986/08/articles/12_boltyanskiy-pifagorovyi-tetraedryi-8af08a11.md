毕达哥拉斯四面体

苏联教育科学院通讯院士
V·G·波尔扬斯基

让我们回想一下，如果一个三角形有一个直角，并且任何其他边的比率都是有理数，则该三角形被称为毕达哥拉斯三角形（然后，使用相似性，可以从中获得具有整数边长的直角三角形）。依此类推，如果一个顶点的面角为直角，且任意两条边的比为有理数，我们称该三角形为毕达哥拉斯三角形（利用相似性，我们可以得到一个顶点的面角为直角且边长为整数的三角形）。

在本文中，我们将推导出“对毕达哥拉斯四面体的尊重”，即与未知数 Ψ、Ρ、Ρ 的关系使得任何毕达哥拉斯四面体都给出该方程的有理解，反之亦然，该方程的任何有理解都给出一个毕达哥拉斯四面体。然后，利用这个，我们将找到毕达哥拉斯四面体的具体例子。

毕达哥拉斯三角形

首先我们给出一种描述所有毕达哥拉斯三角形的方法。在图1处三角形OAB是直角三角形；它的腿的长度由 a 和 b 指定，斜边的长度由 p 指定（我们保留字母 e 供以后使用）。数 xi = a/b+p

让我们同意将直角三角形的参数称为 OAB（或者更准确地说，参数“相对边 a”）。使用对应关系 p²=a²+b²，我们有

$$1+\xi^2 = \frac{(b^2+2bp+p^2)+a^2}{(b+p)^2} = \frac{2p^2+2bp}{(b+p)^2} = \frac{2p}{b+p}.$$

从这些等式我们直接得到通过其参数表达直角三角形边长之比的公式：

$$\frac{2\xi}{1-\xi^2} = \frac{a}{b}, \frac{1+\xi^2}{1-\xi^2} = \frac{p}{b}.$$

毕达哥拉斯四面体方程

现在设 OABC 为一个四面体，其顶点 O 处的平面角是直角。从顶点 O 发出的边的长度用 a、b、c 表示，其他三个边的长度用 p、q、r (图 2) 表示。我们来考虑三个直角三角形OAB、OBC、OCA的参数：

$$\xi = \frac{a}{b+p}, \eta = \frac{b}{c+q}, \zeta = \frac{c}{a+r}.$$

然后，利用公式（2），我们可以通过它们的参数来表达这些直角三角形的边长比：

$$\frac{a}{b} = \frac{2\xi}{1-\xi^2}, \frac{b}{c} = \frac{2\eta}{1-\eta^2}, \frac{c}{a} = \frac{2\varsigma}{1-\varsigma^2};$$

$$\frac{p}{b} = \frac{1+\xi^2}{1-\xi^2}, \frac{q}{c} = \frac{1+\eta^2}{1-\eta^2}, \frac{r}{a} = \frac{1+\varsigma^2}{1-\varsigma^2}.$$

从 (4) 可以看出，参数 $\xi, \eta, \varsigma$ 满足非总统的对应关系

$$\frac{2\xi}{1-\xi^2}, \frac{2\eta}{1-\eta^2}, \frac{2\varsigma}{1-\varsigma^2} = 1.$$

这是常见的“毕达哥拉斯四面体方程”。

问题 4. 证明如果 $\xi, \eta, \varsigma$ 是不定方程 (6) 的解，则数字

问题5. 证明如果$\xi, \eta, \varsigma$是不定方程（6）的解，并且每个数$\xi, \eta, \varsigma$都为小于1的正数，那么可以得到问题3中讨论的四面体$OABC$：从点$O$画出三个相互垂直的线段$OA, OB, OC$，其长度

$$OA = 1, OB = \frac{1-\xi^2}{2\xi}, OC = \frac{1-\eta^2}{2\eta}$$

问题 7. 数 $\xi, \eta, \varsigma$ 形成不定方程 (6) 的一个解，并且每个数都是正数并且小于 1。证明如果 $\xi = m/n, \eta = p/q$（其中 $m, n, p, q$ 是自然数），则一个四面体的一个顶点具有直角，并且从该顶点伸出的边的长度

$$a = 4mnpq, b = 2pq = (n^2-m^2), c = (n^2-m^2)(q^2-p^2)$$

是毕达哥拉斯学派。

由式(3)~(5)直接得出如下结论：为了使顶点$O$具有直角的四面体$OABC$是毕达哥拉斯，参数$\xi, \eta, \varsigma$（满足式（6））的排列是必要且充分的。事实上，如果四面体

$$\frac{a}{b} = \frac{2\xi}{1-\xi^2}, \frac{b}{c} = \frac{2\eta}{1-\eta^2}, \frac{c}{a} = \frac{2\varsigma}{1-\varsigma^2};$$

毕达哥拉斯（即它的任意两条边之比都是有理数），那么从 (3) 可以得出 $\xi, \eta, \varsigma$ 是有理数。反之，如果$\xi, \eta, \varsigma$是有理数，则根据（4）、（5）任意两条边的关系也是有理数，即毕达哥拉斯四面体。

总之，让我们详细讨论如何找到上述方程（6）的 11 个异质解的问题。为此，使用了电子计算机。计算机上的计算算法是根据以下消息编译的。让

$$\xi = \frac{a}{b}, \quad \eta = \frac{c}{d}, \quad \xi = \frac{e}{f},$$

(7)

其中 $a, b, c, d, e, f$ 是自然数。该算法的思想是遍历所有这样的六，给这六个数字中的每一个赋予值1,2,...,25，使用公式(7)找到对应的三元组($\xi, \eta, \zeta$)，并从中选择满足等式(6)的三元组。事实上，抛开意义，不使用$\xi, \eta, \zeta$进行计算，而是使用自然数$a, b, c, d, e, f$进行计算更为方便。关键是，当处理异构数 $\xi, \eta, \zeta$ 时，计算机会将它们替换为一些肯定不满足方程（6）的小数近似值。
