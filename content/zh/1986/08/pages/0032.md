$$\frac{a}{b} = \frac{2\xi}{1-\xi^2}, \frac{b}{c} = \frac{2\eta}{1-\eta^2}, \frac{c}{a} = \frac{2\varsigma}{1-\varsigma^2};$$

$$\frac{p}{b} = \frac{1+\xi^2}{1-\xi^2}, \frac{q}{c} = \frac{1+\eta^2}{1-\eta^2}, \frac{r}{a} = \frac{1+\varsigma^2}{1-\varsigma^2}.$$

从 (4) 可以看出，参数 $\xi, \eta, \varsigma$ 满足非总统的对应关系

$$\frac{2\xi}{1-\xi^2}, \frac{2\eta}{1-\eta^2}, \frac{2\varsigma}{1-\varsigma^2} = 1.$$

这是常见的“毕达哥拉斯四面体方程”。

问题3. 证明如果三个小于1的正数$\xi, \eta, \varsigma$满足方程（6），则存在一个顶点之一具有直角平面角的四面体，对于该四面体（记号为图2）等式（3）（然后等式（4），（5））成立。

问题 4. 证明如果 $\xi, \eta, \varsigma$ 是不定方程 (6) 的解，则数字

$$\xi' = \frac{1-\xi}{1+\xi}, \eta' = \frac{1-\eta}{1+\eta}, \varsigma' = \frac{1-\varsigma}{1+\varsigma}$$

也形成该方程的解（“解的共轭”）。证明如果每个数$\xi, \eta, \varsigma$都是正数并且小于1，那么每个数$\xi', \eta', \varsigma'$都具有这个性质。方程（6）的两个共轭解的几何相互作用是什么？

问题5. 证明如果$\xi, \eta, \varsigma$是不定方程（6）的解，并且每个数$\xi, \eta, \varsigma$都为小于1的正数，那么可以得到问题3中讨论的四面体$OABC$：从点$O$画出三个相互垂直的线段$OA, OB, OC$，其长度

$$OA = 1, OB = \frac{1-\xi^2}{2\xi}, OC = \frac{1-\eta^2}{2\eta}$$

问题6. 数字$\xi, \eta, \varsigma$构成不定方程(6)的解。是否有可能找到其中两个号码，以及第三个号码？给出答案的几何解释。

问题 7. 数 $\xi, \eta, \varsigma$ 形成不定方程 (6) 的一个解，并且每个数都是正数并且小于 1。证明如果 $\xi = m/n, \eta = p/q$（其中 $m, n, p, q$ 是自然数），则一个四面体的一个顶点具有直角，并且从该顶点伸出的边的长度

$$a = 4mnpq, b = 2pq = (n^2-m^2), c = (n^2-m^2)(q^2-p^2)$$

是毕达哥拉斯学派。

由式(3)~(5)直接得出如下结论：为了使顶点$O$具有直角的四面体$OABC$是毕达哥拉斯，参数$\xi, \eta, \varsigma$（满足式（6））的排列是必要且充分的。事实上，如果四面体

$$\frac{a}{b} = \frac{2\xi}{1-\xi^2}, \frac{b}{c} = \frac{2\eta}{1-\eta^2}, \frac{c}{a} = \frac{2\varsigma}{1-\varsigma^2};$$

毕达哥拉斯（即它的任意两条边之比都是有理数），那么从 (3) 可以得出 $\xi, \eta, \varsigma$ 是有理数。反之，如果$\xi, \eta, \varsigma$是有理数，则根据（4）、（5）任意两条边的关系也是有理数，即毕达哥拉斯四面体。
