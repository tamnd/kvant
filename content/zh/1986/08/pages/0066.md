适合小学生的量子
（见«Kvant»第7条）

1. 让我们通过$y$表达$x$：$x = \frac{5y - 3}{y + 3} (y \neq -3)$或$x = 5 - \frac{18}{y + 3}$。因此，当且仅当 18 能被 $y + 3$ 整除时，$x$ 才是整数。对于$y + 3$，我们得到十二个可能的值：$\pm 1, \pm 2, \pm 3, \pm 6, \pm 9, \pm 18$，它给出了方程的十二个整数解
$$\{(-13; -2), (23; -4), (-4; -1), (14; -5), (-1; 0), (11; -6), (2; 3), (8; -9), (3; 6), (7; -12), (4; 15), (6; -21)\}.$$

2. 让我们以刻在“彩色”圆圈中的常规巴塔哥为例。很容易理解，他总是有三个相同颜色的顶点。无论如何，这些顶点形成所需的等边三角形。

3. 让$A = \overline{ab}$。那么$(a + b) + (a + b)^2 = 10a + b$，即$(a + b)^2 = 9a$，也就是说$a$是一个完全平方数。从$1 \leq a \leq 9$开始，我们得到三种可能性：$a = 1, a = 4$和$a = 9$。因此数字$A$是12、42或90。

4. 让我们围绕三角形 $ABC$ 画一个圆。从条件$\angle CAB + \angle MCB = 90^\circ$可以得出，中位数$CM$属于该圆的直径（画图）。如果边 $AB$ 不是直径，则中线 $CM$ 与穿过弦中点的直径 $AB$ 垂直，并且三角形 ABC 是等边的（因为中线 $CM$ 也是高）。如果边$AB$是直径，则三角形$ABC$是直三角形。
