让我们放入 $a=x^{10}$, $b=y^{15}$ 并考虑该函数
$$f(x)=2x^5+3y^5-5x^2y^3, \quad x \geqslant 0$$
（固定$y > 0$）。我们必须证明$f(x) \geqslant 0$。衍生物
$$f'(x)=10x^4-10xy^3=10x(x^3-y^3)$$
在$x=y$处变为0，在$0 < x < y$处变为负值，在$x > y$处变为正值。因此（参见图），对于$x=y$，函数$f(x)$取最小值，并且对于所有$x > 0$
$$f(x) \geqslant f(y)=2y^5+3y^5-5y^5=0.$$
其他不使用微积分的证明可以通过因式分解$f(x)$得到：
$$f(x)=(x-y)^2(2x^3+4x^2y+6xy^2+3y^3)$$
或者使用均值参数和几何平均值之间的不等式作为数字的尾部$x^5, x^5, y^5, y^5, y^5$：
$$\frac{2x^5+3y^5}{5} \geqslant \sqrt[5]{x^5 \cdot 2y^5 \cdot 3}=x^2y^3.$$
（这个问题的详细讨论包含在新版《对应数学优化》一书中，M.: - “Nauka”，1986，问题 4-16。）

◆ 令 $d_1, d_2, \dots, d_n$ 为数 $a$ 的约数，使得
$$a - 1 = \frac{a}{d_1} + \frac{a}{d_2} + \dots + \frac{a}{d_n}.$$
然后
$$1 - \frac{1}{a} = \frac{1}{d_1} + \frac{1}{d_2} + \dots + \frac{1}{d_n} < 1.$$ (1)

解决问题的思路是，确保由自然数的$n$数字之和表示的数字集合$X_n$中的每个$n=2, 3, \dots$，都表示最多的数字$\mu_n$，严格小于1。然后从（1）对$a$的估计将如下：
$$1 - \frac{1}{a} \leqslant \mu_n \Rightarrow a \leqslant \frac{1}{1-\mu_n}.$$ (2)

请注意，由于集合$X_n$是无限的，即使对于每个$n$存在这样一个$\mu_n$也需要证明：这个证明的直观解释，我们将在c)点中给出，是$X_n$是通过将$X_{n-1}$中的每个数字与$1/k$（$k=1, 2, \dots$）形式的所有数字相加而获得的，因此来自$X_n$ 只能无限量地累加到$X_{n-1}$ 开始的每个点的右侧，而不能累加到每个点的左侧（特别是从点 1 开始）。

F998。滑雪者以设定速度 $v$ 下山。山体与水平面形成一个领口，并顺利地进入水平段。滑雪者应该如何倾斜才能避免在过渡过程中摔倒？考虑经过滑雪者的过渡等于 $M$。忽略空气流动​​。

由于过渡是平滑的，滑雪者的动能积聚起来，并且在过渡到水平部分后，他的速度$v_1$等于$(по модулю) v$。过渡时间$t$期间滑雪者动量的变化等于$\Delta \vec{p} = M(\vec{v}_1 - \vec{v})$，并且沿着角$ABC$的平分线方向（参见图nok）。

根据动量变化定律，考虑到$t$值较小，我们有：$\Delta \vec{p} = f\tau$，其中$\vec{f}$是滑雪板作用在滑雪者身体上的力（也是沿着平分线方向）。为了使滑雪者保持平衡，该力的矢量必须穿过滑雪者的质心。从这个条件可以发现，在过渡到水平部分的瞬间，它必须从沿斜坡移动时所占据的位置向前倾斜$\alpha/2$角度。

F999。质量为 $m_1$ 的袋子，用一根小刚性绳索连接到质量为 $m_2$ 的袋子，沿着桌子的主水平表面滑动。连接袋子的绳子穿过桌子上的一个小孔（参见图）。绳子的长度是$L$，桌子的高度是$H$，$H < L$。如果一开始整条绳子都放在桌子上并且袋子没有移动，那么袋子$m_2$落地后会上升到多高？

其中一个袋子落地时的速度 $v$ 由能量守恒定律决定：

$$\frac{1}{2} (m_1 + m_2) v^2 = m_2 g H.$$

撞击后，质量$m_1$的袋子将沿着桌子移动，直到拉动绳子。此时，躺在地板上的袋子$m_2$受到鱼的加速，使得两个袋子的速度大小相等。

在这个猛拉过程中，袋子速度的绝对值变化与质量$m_2$的袋子不是放在地板上而是放在桌子上一样。事实上，袋子之间的相互作用是通过绳索进行的，施加到放在地板上的袋子上的力与放在桌子上的袋子所受的力仅在方向上不同。

因此，可以使用动量守恒定律求出加加速度后袋子的速度$u$：

$$m_1 v = (m_1 + m_2) u.$$

袋子的进一步运动再次由能量守恒定律“控制”，并且袋子提升的最大高度$h$$m_2$由对应关系确定

$$m_2 g h = \frac{1}{2} (m_1 + m_2) u^2.$$

从(1)、(2)、(3)中消去$v$、$u$，可得：

$$h = \left( \frac{m_1}{m_1 + m_2} \right)^2 H.$$

为了找到沿轮廓 $ABCGHEA$ 流动的电流所创建的场 $\vec{B}$（参见图 2），我们使用叠加原理。请注意，如果我们采用三个电路：$ABCDA$、$DCGHD$ 和 $ADHEA$，沿着每个电路的电流为$I$，则将获得沿立方体边缘完全相同的电流分布。这意味着这三个轮廓的组合在立方体中心创建了所需的场 $\vec{B}$。根据叠加原理，$\vec{B}$等于每个电路创建的三个场的矢量和：

$$\vec{B} = \vec{B}_{ABCDA} + \vec{B}_{DCGHD} + \vec{B}_{ADHEA} = (0, B_0, 0) + (-B_0, 0, 0) + (0, 0, B_0) = (-B_0, B_0, B_0).$$

F1002。点光源位于距屏幕距离 L 处。焦距 F > (L/4) 且与屏幕平行的会聚透镜在光源和屏幕之间移动。在镜头的什么位置，屏幕上可见光斑的直径最小？

让镜头向一侧移动，使其与屏幕之间的距离不发生变化。然后屏幕上光斑的大小保持不变，因为透镜后面的光束是一个圆锥体，其顶点位于穿过透镜周边的光源和发生器的实际图像或最小图像中。由于在这种光线下，透镜和屏幕平面的交点与锥体的高度不会改变，因此（根据相似性）光斑的大小也不会改变。

因此，我们可以移动镜头，使光源位于其主光轴上。令 x 为从光源到透镜的距离。不难看出，在 F > (L/4) 的条件下，不可能在屏幕上获得清晰的光源（点）图像——在镜头的任何位置，屏幕上都会出现一个可见的光斑，其直径 d 取决于 x，在 x = x₀ 时最小。事实上，如果出现以下情况，源图像就会出现在屏幕上：

$$\frac{1}{x} + \frac{1}{L-x} = \frac{1}{F},$$

或$x^2 - Lx + FL = 0$，

但这个方程没有解——根据条件，它的判别式 $L^2 - 4FL = 4L((L/4) - F)$ 为负。

如果 x < F，则光束位于镜头后面一定距离，并且光斑越大，镜头距离屏幕越远。对于 F ≥ L，对于所有可能的 x，我们有 x < F，在这种情况下，d 在 x₀ = L 时最小，即当镜头安装在靠近屏幕时。如果 (L/4) < F < L，则显然 x₀ > F（光束必须会聚）。在这种情况下，源图像位于屏幕后面距镜头 y 的位置，使得

$$\frac{1}{x} + \frac{1}{y} = \frac{1}{F},$$

即 y = $\frac{xF}{x-F}$。

从我们获得的相似性消息中（参见图）：

$$\frac{d}{D} = \frac{y - (L-x)}{y},$$

在哪里

$$d = D \frac{y - (L-x)}{y} = D \left(1 - \frac{(L-x)(x-F)}{xF}\right) = D \left(2 \sqrt{\frac{L}{F}} - \frac{L}{F} + \left(\sqrt{\frac{L}{x}} - \sqrt{\frac{x}{F}}\right)^2\right).$$

该表达式在 x = x₀ = $\sqrt{LF}$ 处具有最小值，并且

$$d_{\min} = D \sqrt{\frac{L}{F}} \left(2 - \sqrt{\frac{L}{F}}\right).$$

因此，如果 F ≥ L，则在 x₀ = L 时光斑尺寸最小；如果 F < L，则在 x₀ = $\sqrt{LF}$ 时光斑尺寸最小。
