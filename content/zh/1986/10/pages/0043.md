⟦folio 41⟧

F1002。点光源位于距屏幕距离 L 处。焦距 F > (L/4) 且与屏幕平行的会聚透镜在光源和屏幕之间移动。在镜头的什么位置，屏幕上可见光斑的直径最小？

让镜头向一侧移动，使其与屏幕之间的距离不发生变化。然后屏幕上光斑的大小保持不变，因为透镜后面的光束是一个圆锥体，其顶点位于穿过透镜周边的光源和发生器的实际图像或最小图像中。由于在这种光线下，透镜和屏幕平面的交点与锥体的高度不会改变，因此（根据相似性）光斑的大小也不会改变。

因此，我们可以移动镜头，使光源位于其主光轴上。令 x 为从光源到透镜的距离。不难看出，在 F > (L/4) 的条件下，不可能在屏幕上获得清晰的光源（点）图像——在镜头的任何位置，屏幕上都会出现一个可见的光斑，其直径 d 取决于 x，在 x = x₀ 时最小。事实上，如果出现以下情况，源图像就会出现在屏幕上：

$$\frac{1}{x} + \frac{1}{L-x} = \frac{1}{F},$$

或$x^2 - Lx + FL = 0$，

但这个方程没有解——根据条件，它的判别式 $L^2 - 4FL = 4L((L/4) - F)$ 为负。

如果 x < F，则光束位于镜头后面一定距离，并且光斑越大，镜头距离屏幕越远。对于 F ≥ L，对于所有可能的 x，我们有 x < F，在这种情况下，d 在 x₀ = L 时最小，即当镜头安装在靠近屏幕时。如果 (L/4) < F < L，则显然 x₀ > F（光束必须会聚）。在这种情况下，源图像位于屏幕后面距镜头 y 的位置，使得

$$\frac{1}{x} + \frac{1}{y} = \frac{1}{F},$$

即 y = $\frac{xF}{x-F}$。

从我们获得的相似性消息中（参见图）：

$$\frac{d}{D} = \frac{y - (L-x)}{y},$$

在哪里

$$d = D \frac{y - (L-x)}{y} = D \left(1 - \frac{(L-x)(x-F)}{xF}\right) = D \left(2 \sqrt{\frac{L}{F}} - \frac{L}{F} + \left(\sqrt{\frac{L}{x}} - \sqrt{\frac{x}{F}}\right)^2\right).$$

该表达式在 x = x₀ = $\sqrt{LF}$ 处具有最小值，并且

$$d_{\min} = D \sqrt{\frac{L}{F}} \left(2 - \sqrt{\frac{L}{F}}\right).$$

因此，如果 F ≥ L，则在 x₀ = L 时光斑尺寸最小；如果 F < L，则在 x₀ = $\sqrt{LF}$ 时光斑尺寸最小。
