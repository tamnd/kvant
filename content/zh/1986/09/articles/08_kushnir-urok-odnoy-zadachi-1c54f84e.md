一项任务

I.A.库什尼尔

“今天，”伊万·彼得罗维奇开始了数学俱乐部课程，“我们的课程专门讨论一个问题。”
- 这么难？ - 我们很惊讶。
- 不会。尤其是这个问题，它会帮助我们解决其他问题。以下是其条款：

问题1. 在以a 和b 为底的梯形中，通过对角线的交点画一条与底平行的直线。求这条直线被两侧截断的线段的长度。

伊万·彼得罗维奇（Ivan Petrovich）将我们中的一个人叫到黑板上，黑板上出现了一张图画（图1）。我们立即注意到三角形AMO和ABC、MBO和ABD之间的相似性，并将公式写在黑板上

$$\frac{x}{b} = \frac{h_2}{h}, \quad \frac{x}{a} = \frac{h_1}{h},$$

其中$h, h_1, h_2$是三角形ABD、MBO、AMO和$x = MO$的高度。添加这些等式，我们得到

$$\frac{x}{a} + \frac{x}{b} = \frac{h_1 + h_2}{h} = 1,$$

即$x = ab/(a+b)$。与$ON = ab/(a+b)$类似，答案开放：

$$MN = \frac{2ab}{a+b}.$$

“伊万·彼得罗维奇，”班上传来消息，“我已经可以看到如何从这个问题中创造出一个新问题了。”黑板上出现了以下注释：

问题2. 证明在梯形中，一条平行于底边、属于对角线交点且其端点在梯形侧面的直线段在该点被分成两半。

“好问题，”伊万·彼得罗维奇耸耸肩，“现在我要改变图，”他继续梯形的边直到交点$E$（图2），通过点$O$和$E$画一条直线。老师指定直线与底边的交点为$F$和$H$。

“我想提请您注意上面的问题，”他继续说道，“以下问题：

问题3.证明在任意梯形中，底中点、侧边交点和对角线交点属于同一条直线。

立即得到了解决方案：毕竟，它是从上一个问题得出的，因为$EH$是三角形$EBC, EMN, EAD$的中线。

“没错，”伊万·彼得罗维奇说。 - 我怎样才能用另一种方式解决这个问题？

我们已经计划...
- 那么这将是你的作业。我建议：使用现成的。

问题4、一条直线上有三个点A、B、C，其中B位于A和C之间的中间。通过不属于线段AC的任意点K，用一条直线画出与AC平行的直线。

“这也是一个好问题，”伊万·彼得罗维奇说，“但我们下次再讨论这个问题，今天我们将讨论一个更复杂的问题：

问题 5. 两条平行线上各有一段长度为 a 和 b 的线段。使用一行构建一个线段：

$$x = \frac{ab}{a+b}.$$

如果没有伊万·彼得罗维奇的帮助，我们自己也无法迅速应对：

— 让我们继续梯形 ABCD 的边，其底边是给定的线段 a 和 b (图 3)。我们将对角线 AC 和 BD 以及线段 AB 和 DC 的交点表示为 O 和 E。我们画一条直线 EO，它将与梯形的底交于点 F 和 H。我们连接点 D 和 F、A 和 F、B 和 H、C 和 H，得到点 K 和 L。线段 KL 就是所需的线段 KL。

事实上，三角形 BKF 和 AKH、CFL 和 LHD 相似，因此

$$\frac{BK}{KH} = \frac{BF}{AH}; \quad \frac{FL}{LD} = \frac{FC}{HD}.$$

但是 BF = FC 且 AH = HD（问题 2），这意味着

$$\frac{BK}{KH} = \frac{FL}{LD},$$

因此，线段KL平行于底边BC和AD。由于点 O 属于线段 KL 且 MK = KO，且 OL = LN（问题 2），我们得到

$$OL = \frac{1}{2} \frac{ab}{a+b}, \quad KL = \frac{ab}{a+b}.$$

— 为了更好地理解此类问题，请在家中执行以下任务：

6. 长度为 a 和 b 的线段属于其中一条平行线，长度为 c 的线段属于其中另一条平行线。使用一根线构造一个长度为 x 的线段，使得

$$\frac{1}{x} = \frac{1}{a} + \frac{1}{b} + \frac{1}{c}.$$

7. 给出了平行线段。用一根线将其中一个分成两半。

8. 用一根线将梯形分成两个大小相等的形状。

9. 给定两条平行线。使用一条线通过该点绘制与数据平行的第三条线。

10. 使用一条线将位于两条平行线之一上的给定线段放大 2, 3, ..., n 倍。

11. 找到这样一个线段的一半、第三、...、第 n 部分。

“所有这些问题，”让我们提醒老师，“都在我们今天遇到的第一个问题的帮助下得到了解决。”

- 谁想出了这个问题？
