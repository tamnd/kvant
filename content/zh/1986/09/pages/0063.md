3. 由于向量 $\vec{BC}$ 和 $\vec{AD}$ 是共同校正的，因此存在以点 $E$ 为中心的相似性（参见 图 2 p. 23）和系数 $k_1 = BC:AD$，其中
$$H_0^{k_1}:BC \rightarrow AD, B \rightarrow A, C \rightarrow D, F \rightarrow H.$$
因此，点$E, F, H$位于同一条直线$EF$上。由于向量 $\vec{BC}$ 和 $\vec{DA}$ 是相反的，因此存在以中心 $O$ 和系数 $k_2 = -OB:OD$ 为相似的关系，使得
$$H_0^{k_2}:BC \rightarrow DA.$$
因此，点$O, F, H$属于线$OH$。接收$EF$和$OH$有两个公共点$(F, H)$，因此它们重合。

选定的学校问题

1. a) 使用明显的不等式：
$$a^2 \geq a^2 - (b - c)^2,$$
$$b^2 \geq b^2 - (c - a)^2,$$
$$c^2 \geq c^2 - (a - b)^2.$$
6) 使用公式 $R = \frac{abc}{4S}$、$r = \frac{2S}{a + b + c}$、其中 $S = \frac{1}{4} \sqrt{(a + b + c)(a + b - c)(a + c - b)(b + c - a)}$ 和问题 1，a)。
在等边三角形的情况下实现了相等。
2. $x^6 + 2x^4 + 2x^3 + x^2 + 2x - 1 = (x^3 + x + 1)^2 - 2$。因此，该多项式的最小值是$-2$（当$x^3 + x + 1 = 0$时）。 （有趣的是，最小值可以确定，但对应的值$x$却不能。）
3. $n^4 + 64 = (n^2 + 8)^2 - 16n^2 = (n^2 + 4n + 8)(n^2 - 4n + 8)$.
4. 通过选择找到一个解：$100 + 27 + 1 = 128$，即$x = 10, y = 3, z = 1$。
