正切方程

V.M.贝克尔，
V.M.戈尔霍维，
教育科学博士生于。 I. 爱奥宁

在本文中，我们将分析特定数学考试中经常出现的“切线”主题的几种类型的问题。

回想一下，斜率为 $k$ 并通过点 $M(x_0; y_0)$ 的直线方程可以写为 $y = k(x - x_0) + y$。由于可微函数 $y = f(x)$ 的图形在横坐标 $x_0$ 处的切线的角度系数等于 $f'(x_0)$，因此切线方程具有以下形式

$$y = f'(x_0)(x - x_0) + f(x_0).$$

因此，要写出正切方程，您需要知道三个数字：$x_0$、$f(x_0)$和$f'(x_0)$。我们先从一个问题开始，从条件中很容易找到值$x_0$，然后计算$f(x_0)$、$f'(x_0)$。

任务 1（密歇根州立大学心理学系，1980 年）。计算由坐标轴和函数图像$y = \frac{x}{2x - 1}$的切线在横坐标$x_0 = 1$点处所围成的三角形的面积。

解决方案。我们来求正切方程。为此，我们依次计算 $f(1)$、$f'(x)$、$f'(1)$：

$$f(1) = 1, f'(x) = -\frac{1}{(2x - 1)^2}, f'(1) = -1.$$

正切方程的形式为$y = -(x - 1) + 1$，即$y = -x + 2$。

该线与坐标轴相交于点 $A$ (2; 0) 和 $B$ (0; 2)。因此，所需面积为$S_{AOB} = \frac{1}{2} |OA| \cdot |OB| = 2$。

问题 2（克拉斯诺伊州立大学数学系，1980 年）。抛物线 $y = -a^2x^2 + 5ax - 4$ 的弦在点 $x_0 = 2$ 处与曲线 $y = \frac{1}{1-x}$ 相交，并被该点一分为二。找到$a$。

解决方案。函数 $f(x) = \frac{1}{1-x}$ 在点 $M$ 与横坐标 $x_0 = 2$ 的切线方程：

$$f(2) = -1, f'(x) = \frac{1}{(1-x)^2}, f'(2) = 1,$$

所以正切方程为$y = x - 3$。

假设该切线与给定抛物线相交于点 $A$ 和 $B$。点$A$和$B$的横坐标是方程$-a^2x^2 + 5ax - 4 = x - 3$的根，或

$$-a^2x^2 + (5a - 1)x - 1 = 0.$$

当且仅当横坐标等于点 $A$ 和 $B$ 的结果横坐标时，点 $M$ 是线段 $AB$ 的中点。使用维塔定理，这个条件可以写成等式$\frac{5a - 1}{a^2} = 4$，它对于$a = 1$和$a = \frac{1}{4}$成立。对于这些值，仍需检查给定抛物线的$a$与直线$y = x - 3$是否相交，即方程（1）是否有根。对于$a = 1$，我们得到带有正描述符的方程$-x^2 + 4x - 1 = 0$，对于$a = \frac{1}{4}$，我们得到带有负描述符的方程$-\frac{1}{16}x^2 + \frac{1}{4}x - 1 = 0$。

因此，$a = 1$。

问题 3. 我们的方程是抛物线 $y = 2x^2 - x - 1$ 在纵坐标为 5 的点处的切线，如果已知该切线不经过点 $M$ (1; -2)。

解决方案。问题陈述指定的不是横坐标，而是切点的纵坐标。求解$2x^2 - x - 1 = 5$的横坐标。我们得到两个根$x_1 = -\frac{3}{2}$，$x_2 = 2$。让$f(x) = 2x^2 - x - 1$。然后$f'(x) = 4x - 1$，$f'(-\frac{3}{2}) = -7$，$f'(2) = 7$。我们的切线方程是$y = -7(x + \frac{3}{2}) + 5$和$y = 7(x - 2) + 5$，即$y = -7x - 5,5$和$y = 7x - 9$。

将$M$点的坐标代入各个方程，我们发现第一个切线没有经过$M$点，但第二个切线确实经过了这个点。

所以答案是：$y = -7x - 5, 5$。

问题 4（路易斯安那州立大学，生物学院，1977 年）。在函数 $y = x^3 - x^2 - 13x + 4$ 的第二个四分之一点处绘制一条切线，该点的斜率等于 3。找到该切线与坐标轴的交点。

解决方案。设 $a$ 为切点的横坐标。根据条件$f'(a) = 3$。从$f'(x) = 3x^2 - 2x - 13$开始，为了找到$a$，我们得到方程$3a^2 - 2a - 13 = 3$，它有根$-2$和$8/3$。值$a = 8/3$必须被丢弃（根据问题的条件，切点位于第二季度）。在 $a = -2$ 处，切点的坐标为 $(-2; 18)$，位于第二象限。正切方程为$y = 3x + 24$。这条线与坐标轴相交于点 $(-8; 0)$ 和 $(0; 24)$。

问题 5（路易斯安那州立大学，数学与力学学院，1977 年）。在$a$的值是多少时，函​​数$y = a - x^2$的图像的切线从第一四分之一处切出面积等于$\frac{9}{32}$的等边直角三角形？

解决方案。从问题的条件可知，切线与横坐标轴的倾斜角等于$135^\circ$。由于$tg 135^\circ = -1$，切点的横坐标是方程$-2x = -1$的根。因此，正切方程的形式为$y = -x + a + \frac{1}{4}$。这条直线与坐标轴相交于点 $A(0; a + \frac{1}{4}), B(a + \frac{1}{4}; 0)$。

根据问题的条件，点$A$和$B$位于正半轴上，因此$a + \frac{1}{4} > 0$。条件中所指的三角形面积为$\frac{1}{2}(a + \frac{1}{4})^2$。解出方程$\frac{1}{2}(a + \frac{1}{4})^2 = \frac{9}{32}$（考虑到$a + \frac{1}{4} > 0$），我们得到答案：$a = \frac{1}{2}$。

如果将一条直线赋予$y = kx + b$形式的方程，则系数$k$等于该直线与横坐标轴的倾斜角的正切（我们在解决问题5时使用了这个）。由此可见，方程 $y = k_1x + b_1$ 和 $y = k_2x + b_2$ 给出的直线是平行的当且仅当 $k_1 = k_2$。

问题 6（埃里温国立大学应用数学学院）。平行于直线 $y = 3x + 24$ 的切线位于曲线 $y = \sqrt{1+x^2}$ 的哪一点。这条线与坐标轴相交于点 $(-8; 0)$ 和 $(0; 24)$。

解决方案。让我们计算任意给定函数：$y' = \frac{x}{\sqrt{1+x^2}}$。

函数图形在横坐标$a$处的切线的角度系数等于任意函数在该点的值。根据条件，该斜率必须等于 $\frac{1}{2}$。因此，期望点的横坐标是方程$\frac{a}{\sqrt{1+a^2}} = \frac{1}{2}$的根。解这个方程，我们得到$a = 1/\sqrt{3}$。

答案：$(1/\sqrt{3}; 2/\sqrt{3})$。

问题 7（MAI，1981）。我们应该在函数$y = (1-x)\times(1+x)^2$图中的哪些点检查其切线，以便它们通过点$(-1; 0)$？

解决方案。让我们用 $t$ 表示切点的横坐标。由于$y' = -(1+x)^2 + 2(1+x)(1-x) = (1+x)\times(1-3x)$，正切方程为$y = (1+t)(1-3t)(x-t) + (1-t)(1+t)^2$。切线穿过点 $(-1; 0)$ 的条件现在将写成 $t$ 方程的形式：

$$0 = (1+t)(1-3t)(-1-t) + (1-t)(1+t)^2,$$

可以很容易地转换为$(1+t)^2 \cdot 2t = 0$的形式。该方程的根$t = 0$、$t = -1$为所需点的横坐标；我们通过计算这个函数对应的值来找到它们的坐标。答案：$(0; 1), (-1; 0)$。

问题 8（沃罗涅日国立大学数学系）。求曲线的切线方程

$$y = \frac{x+1}{x},$$
如果已知切线经过点$M(a; b)$。
根据点$M(a; b)$，有多少种解？

解决方案。如果你看看这个函数的图形，第二个问题的答案就很容易想象。在 图 上，双曲线 $1 + \frac{1}{x}$ 及其渐近线（交点除外）显示为红色。可以通过每个红点绘制一条切线。可以绘制双曲线一根分支的两条切线的区域以蓝色显示。两条切线也穿过绿色区域的点，但一条切线穿过双曲线的每个分支。从黄色阴影区域的点开始，绘制该双曲线的切线。

现在让我们用$t$表示该双曲线任意点的横坐标，并写出该点的切线方程：$y = -\frac{1}{t^2}x + \frac{2}{t} + 1$。当且仅当$b = -\frac{1}{t^2}a + \frac{2}{t} + 1$时，这条线穿过点$M(a; b)$。这个条件相当于系统
$$\begin{cases} (b-1)t^2 - 2t + a = 0, \\ t \neq 0. \end{cases}$$

首先，考虑情况$b=1$（在这种情况下，方程（2）是线性的）和$a=0$（这是方程（2）具有根$t=0$的唯一情况）。

对于 $b=1$，方程 (2) 有一个单根 $t = \frac{a}{2}$，对于 $a \neq 0$ 来说它不为零。在这种情况下，唯一切线的方程是 $y = -\frac{4}{a^2}x + \frac{4}{a} + 1$。

对于$a=0$和$b \neq 1$，方程(2)有一个从零开始的唯一根$t = \frac{2}{b-1}$。在这种情况下，唯一切线的方程是 $y = -\frac{(b-1)^2}{4}x + b$。

最后，对于 $a=0, b=1$ 方程（2）没有非零根。

现在让$b \neq 1, a \neq 0$。二次方程(2)的判别式为$4(1+a-a b)$。如果$1+a-a b < 0$，则方程（2）无根，因此方程$M(a; b)$不能与该函数的图像相切。请注意，不等式 $1+a-a b < 0$ 对于 $a > 0$ 可以写成 $b > \frac{1+a}{a}$，对于 $a < 0$ 可以写成 $b < \frac{1+a}{a}$。因此，这种不等式将黄色区域设置为图。

如果$1+a-a b = 0$（即点$M(a; b)$位于双曲线上），则方程（2）有单根$t = a$，正切方程的形式为$y = -\frac{1}{a^2}x + \frac{2}{a} + 1$。

如果$1+a-a b > 0$，则方程（2）有两个根$t = \frac{1 \pm \sqrt{1+a-a b}}{b-1}$。将这些根代入方程$y = -\frac{1}{t^2}x + \frac{2}{t} + 1$，我们得到通过点$M(a; b)$的两条切线的方程。不等式 $1+a-a b > 0$ 与不等式 $b \neq 1, a \neq 0$ 一起定义了 图 上蓝色和绿色的区域。

任务 9（MIPT，1982）。从点 $M(1; 1)$ 向双曲线 $y = \frac{k}{x} (k < 0)$ 的两个分支绘制切线，并在点 $A$ 和 $B$ 处与这些分支相切，且三角形 MAB 是正三角形。求系数$k$和三角形MAB的面积。

解决方案。令 $t$ 为给定双曲线任意点的横坐标。给出此时的切线

当且仅当$1 = -\frac{k}{t^2} + \frac{2k}{t}$或$t^2 - 2kt + k = 0$时，方程$y = -\frac{k}{t^2}x + \frac{2k}{t}$成立并通过点$M(1; 1)$。该方程在 $k < 0$ 处有两个根 $t_1, t_2$ - 点 $A$ 和 $B$ 的横坐标。根据维埃塔定理$t_1 + t_2 = 2k, t_1t_2 = k$。由于该双曲线的分支关于线$y = x$对称，并且点$M$位于该线上，因此点$A$和$B$关于线$y = x$对称。不过，你可以这样验证：$t_1t_2 = k$，即$B$点的横坐标等于$A$点的纵坐标，$B$点的纵坐标等于$A$点的横坐标。因此，点 $A$ 的坐标为 $(t_1; t_2)$，点 $B$ 的坐标为 $(t_2; t_1)$。由此可见，对于任何 $k < 0$ 都有 $|MA| = |MB|$。因此，必须从等式$|MA| = |AB|$找到$k$。我们来计算 $|MA|^2$ 和 $|AB|^2$：

$$|AB|^2 = (t_1 - t_2)^2 + (t_2 - t_1)^2 = 2(t_1 - t_2)^2 = 2((t_1 + t_2)^2 - 4t_1t_2) = 8k^2 - 8k;$$

$$|MA|^2 = (t_1 - 1)^2 + (t_2 - 1)^2 = t_1^2 + t_2^2 - 2(t_1 + t_2) + 2 = (t_1 + t_2)^2 - 2(t_1 + t_2) - 2t_1t_2 + 2 = 4k^2 - 6k + 2.$$

We have obtained for $k$ the equation $8k^2 - 8k = 4k^2 - 6k + 2$, which has a single negative root $k = -\frac{1}{2}$. To find the plane of the correct triangle $MAB$, we substitute the found value $k$ into the expression for $|AB|^2$.我们得到$|AB|^2 = 6$，因此得到$S_{MAB} = \frac{3\sqrt{3}}{2}$。

任务 10（MISiS，1978）。开始计算抛物线 $y = x^2 + 4x + 8$ 和 $y = x^2 + 8x + 4$ 的公切线方程。

解决方案。 Let us denote by $u$ and $v$ the abscissas of the points of tangency.第一条抛物线在横坐标$u$点的切线方程为$y = (2u + 4)x - u^2 + 8$，第二条抛物线在横坐标$v$点的切线方程为$y = (2v + 8x - v^2 + 4$。 Since both equations are equations of the same line, we have $2u + 4 = 2v + 8$, $-u^2 + 8 = -v^2 + 4$. From the resulting system of equations we find $u = 2$, $v = 0$. Therefore, the equation of the desired tangent is $y = 8x + 4$.

任务 11（列宁格勒数学奥林匹克第二轮）。求函数 $f(x) = x^4 - 2x^3 + x^2 + x - 2$ 图形在两点处的切线方程。

注意$f(x) - (x - 2) = x^2(x - 1)^2$。事实证明，如果多项式$f(x)$以$f(x) = (x - a)^2g(x) + l(x)$的形式表示，其中$l(x)$是线性函数，$g(x)$是任意多项式，则直线$y = l(x)$与函数$y = f(x)$的图形在横坐标$a$的点相切。 Indeed, in this case $f(a) = l(a)$, $f'(a) = l'(a)$, so the line $y = l(x)$ passes through the point $(a; f(a))$ and has a slope $f'(a)$.在我们的例子中，直线 $y = x - 2$ 在横坐标 0 和 1 的点处与该函数的图形相接触。因此，直线 $y = x - 2$ 在两个点处与该函数的图形相接触。 Prove on your own that no other line touches the graph of this function at two points. So, the equation of the desired tangent is $y = x - 2$.
