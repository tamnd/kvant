关于函数图的正切

苏联科学院通讯院士
D.K.法德耶夫，
索科洛夫斯基

本文的主要目标是清楚地解释可微函数图的切线与穿过切点的其他线有何不同。事实证明，这个问题的答案不仅阐明了正切的几何意义，而且可以让你在不计算导函数的情况下找到它的方程。

函数 $y = f(x)$ 的图形在点 $M(x_0; f(x_0))$ 处的切线最常被定义为割线 $MN$ 的极限位置，当点 $N$ 无限接近点 $M$ 时，沿着函数图形 (图 1) 移动。从这个定义导出了著名的正切方程（“代数和分析的开始”，第 23 段）

$$y = f'(x_0)(x - x_0) + f(x_0),$$

(1) 其中 $f'(x_0)$ 是函数 $f$ 在 $x = x_0$ 的导数 $f'$ 的值。该公式在函数$f$在点$x_0$有导数的假设下有效。

可能会出现这样的问题：“为什么如此多的注意力从可理解的切线上移开？为什么在 $(x_0; y_0)$ 点（其中 $y_0 = f(x_0)$）处的切线比通过该点的其他线“更好”？事实上，在一般情况下，我们甚至不能说函数图的切线（类似于圆的切线）它与函数图有一个公共点。此外，函数图形的切线可以与图形相交，从图形的一侧移动到另一侧，恰好在切点处；例如，这是函数 $y = x^3$ 的图形在点 $(0; 0)$ 处的切线或函数 $y = x^3 - 3x^2$ 的图形在点 $(1; -2)$ 处的切线的行为。函数 $y = x^4$ sin $(1/x)$ 的图形的切线与图形相交无数次。

那么，我们如何在点 $(x_0; y_0)$ 处对函数 $y = f(x)$ 的图像应用切线呢？事实证明，在切点的足够小的邻域中，切线比任何其他穿过切点的线更接近地属于函数图。让我们更详细地看看这个。

令 $y = f(x)$ 为给定函数，在给定点 $x_0$ 处具有导数 $f'(x_0)$。通过点$(x_0; y_0)$的任意斜线的方程具有$y = k(x - x_0) + y_0$的形式。对于$k = f'(x_0)$，我们得到函数$y = f(x)$图在点$(x_0; y_0)$的切线方程。图上某点的纵坐标。函数 $y = f(x)$ 与到顶点的直线上对应点的纵坐标不同

$$\varepsilon = f(x) - (k(x - x_0) + f(x_0)) = f(x) - f(x_0) - k(x - x_0) = (x - x_0) \left( \frac{f(x) - f(x_0)}{x - x_0} - k \right).$$

通过引入符号$x - x_0 = \Delta x$和$f(x) - f(x_0) = \Delta f(x_0)$，这个表达式可以写得更简洁：

$$\varepsilon = \Delta x \cdot \left( \frac{\Delta f(x_0)}{\Delta x} - k \right).$$

如果$k = f'(x_0)$，即在切线的情况下，在$\Delta x \to 0$处我们有$\frac{\Delta f(x_0)}{\Delta x} \to f'(x_0)$，因此等式右侧的每个分量都趋向于零。

如果$k \neq f'(x_0)$，则$k = f'(x_0) + c$，其中$c$是某个不等于零的常数。然后

$$\varepsilon = \Delta x \left( \frac{\Delta f(x_0)}{\Delta x} - f'(x_0) - c \right).$$

对于$\Delta x \to 0$，等式右边的第二个因子趋向于$c \neq 0$。因此，在$\Delta x \to 0$处，切线上的点比切线以外的线上具有相同横坐标的点更快地接近图形上的相应点。

尤其重要的是，切线与曲线的拟合不仅在数量上比其他直线更好，而且在某种意义上“好一个数量级”。让我们解释一下这一点。

让我们在 $k \neq f'(x_0)$ 的情况下将 $\varepsilon$ 的表达式重写为以下形式

$$\varepsilon = \Delta x \left( \frac{\Delta f(x_0)}{\Delta x} - f'(x_0) \right) - c \Delta x.$$

从这个写式可以看出，当直线与切线不同时，直线上对应点与函数图上对应点的纵坐标之差包含一个比例项$\Delta x$，即$c \cdot \Delta x$形式，其中$c$为常数，但沿切线逼近时，直线上的点与函数图上对应点的距离减小了“一个数量级”比$\Delta x$本身更快”，即具有$\gamma \cdot \Delta x$的形式，其中$\gamma$是与$\Delta x$一起趋向于零的变量。因此，在通过函数图上的点的所有直线中，只有正切与函数的差异量不包含关于 $\Delta x$ 的线性项。

切线的这一属性是将其与穿过切点的整个直线族区分开来的特征。它充分表征了切线，因此可以作为切线定义的基础；那么函数在某一点的导数可以定义为函数图形在该点的切线的斜率。切线的导出性质证明了通过近似等式从切点估计幅值函数的值来获得切线方程的方法是正确的。我们通过例子来展示该方法的应用。 （下文中，$\Delta x$将用字母$\alpha$表示。）

例 1. 让我们写出函数 $f(x) = x^2 - 3x - 6$ 在点 $x_0 = -1$ 处的切线方程。

解决方案e.设$x = -1 + \alpha$，其中$|\alpha|$接近于零。然后$f(-1 + \alpha) = (-1 + \alpha)^2 - 3(-1 + \alpha) - 6 = 1 - 2\alpha + \alpha^2 + 3 - 3\alpha - 6 = -5\alpha + \alpha^2 - 2$。变换$\alpha^2$，我们得到$f(-1 + \alpha) \approx -5\alpha - 2$。让我们回到旧的符号；我们得到$f(x) \approx -5x - 7$震级$x_0 = -1$。取$y = -5x - 7$的大小$x_0 = -1$与$f(x)$相差一个不包含线性相对$\alpha$项的值，并且只有切线具有此属性，这意味着$y = -5x - 7$是该函数图像在点$x_0 = -1$处的切线方程。 （通过使用公式（1）获得正切方程来检查该结果。）

例2. 让我们推导出函数图像$f(x) = x^2$在任意点$x_0$的切线方程。

解决方案e.设$x = x_0 + \alpha$，其中$|\alpha|$接近于零。然后$f(x_0 + \alpha) = x_0^2 + 2x_0\alpha + \alpha^2$。我们变换$\alpha^2$并得到$f(x_0 + \alpha) \approx x_0^2 + 2x_0 \times (x - x_0) = x_0^2 + 2x_0x - 2x_0^2 = 2x_0x - x_0^2$。将函数图像在$x_0$处与$y = 2x_0x - x_0^2$相切，则切线$2x_0$的斜率是$x^2$在$x_0$处的导数。

当定义函数$f(x)$的表达式包含$(x - x_0)$形式的线性因子时，正切方程的推导变得特别简单。

示例 3. 让我们写出函数图像的切线方程

$$y = (x - x_0)(x - x_1)(x - x_2)$$

在图形与横坐标轴的交点处。

解决方案e.令$x = x_0 + \alpha$，$y = \alpha(x_0 - x_1 + \alpha)(x_0 - x_2 + \alpha)$。很明显，当打开项的括号时，线性关系 $\alpha$ 的形式为 $\alpha(x_0 - x_1)(x_0 - x_2)$，则

$$y = (x - x_0)(x_0 - x_1)(x_0 - x_2)$$

是函数图像在点 $x_0$ 处的切线方程。类似地，我们得到点 $x_1$ 和 $x_2$ 处的切线方程：

$$y = (x - x_1)(x_1 - x_0)(x_1 - x_2),$$

$$y = (x - x_2)(x_2 - x_0)(x_2 - x_1).$$
