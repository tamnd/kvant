M952。让我们用 {x} 表示数字 x 的小数部分； {x}=x-[x]，其中[x]是不超过x的最大整数。
a) 给出一个数字 a 满足 $\{a\}+\{1/a\}=1$ 的例子。
b) 证明这样的数a不可能是有理数。

M953。平面上有六个点，其中没有三个点在同一条直线上。绘制所有 15 条直线，连接

第一个三角形较小：$\angle A < \angle FOB$。同样，$\angle C < \angle BOD$，$\angle E < \angle DOF$。因此，

$$\angle A + \angle C + \angle E < \angle FOB + \angle BOD + \angle DOF,$$

a 右侧 (*) 的和要么等于 2π（当三角形 BDF 为锐角或矩形时；图 1），要么小于（当该三角形为钝角时；图 2）。同样，证明$\angle B + \angle D + \angle F < 2\pi$（自$r_1 < 1$），因此六边形所有角度的总和小于4π，这是不可能的。因此，$r \geq 1$。

更强有力的陈述也是正确的：在我们的符号中，要么是$r > 1 > r_1$，要么是$r = r_1 = 1$。为了证明这一点，我们首先证明三角形 ACE 和 BDF 是锐角三角形。例如，假设角度 BFD 不是锐角。则F点位于直径为BD的圆内，即$MF \leq MB$，其中M为BD的中点（图3）。因此，BF 的垂直平分线与线段 BD 的交点 N 位于 B 和 M 之间。等边三角形 BFA 和 BFN 有公共底 BF，同时有 $BN \leq BM < 1 = BA$（自 $2BM = BD < BC + CD = 2$），因此有 $\angle AFB > \angle FBD$。同样，$\angle DFE > \angle FDB$。但六边形在顶点 F 处的角度大于 $\pi$ ($\angle F = \angle AFB + \angle BFD + \angle DFE > \angle FBD + \angle BFD + \angle FDB = \pi$)，这与六边形的凸性相矛盾。

由此证明，不等式(*)右边部分等于2π，同理可得$r_1 \leq 1$（否则六边形的内角和将大于4π）。

最后，如果其中一个半径（例如 r）等于 1，则显然点 A、C 和 E 相对于三角形 BDF 的边 (图 4) 对称于三角形 BDF 的外心 O。从这里很容易推断出$\triangle ACE = \triangle DFB$意味着$r_1 = 1$。 （此外，在这种情况下，三角形 ACE 和 DFB 关于线段 OH 的中间对称，其中 H 是三角形 BDF 的高的交点，因此六边形的相对边是平行的。）

E. 霍瓦特、V. N. 杜布罗夫斯基

a) 答案：其中一个例子是$-a = 2 + \sqrt{3}$。确实，从$2 + \sqrt{3}(2 - \sqrt{3}) = 1$开始，
$\{a\} + \{1/a\} = (\sqrt{3} - 1) + (2 - \sqrt{3}) = 1$.

然而，$n \pm \sqrt{n^2 - 1}$形式的任何数字都是合适的，其中$n$是大于1的整数。

b) 假设数字 $a$ 是有理数，并将其表示为不可约分数：$a = m/n$。如果$\{a\} + \{1/a\} = 1$，那么显然$a + 1/a$是一个整数；我们用 k 来表示它。所以，$m/n + n/m = k$，即$m^2 + n^2 = kmn$。由此可见$m^2$可被n整除，$n^2$可被m整除，且三角形m与n互质；这仅适用于$|m| = |n| = 1$，即$a = \pm 1$。但在这种情况下$\{a\} + \{1/a\} = 0$。因此，所考虑的方程没有有理解。
