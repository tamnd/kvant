三项式的根是如何定位的？

物理和数学科学博士
G.V.多罗菲耶夫

本文致力于解决以某种方式提出关于两个平方三项式的根（通常是无理数）的相对位置的问题。就数学内容而言，这些问题相当简单，但从计算的角度来看，大多数问题都存在严重困难。例如，尝试回答一个问题。

a的什么值是方程的根

$$x^2 + \frac{8}{a}x - 2a = 0 \quad \text{и} \quad x^2 + \frac{6}{a}x - a = 0$$

变量是否也不同（即，一个方程的两个根之间恰好存在另一个方程的一个根）？

您会发现，计算这些三项式的根需要针对参数 a 的不同值将它们相互进行艰苦的比较。

同时，从图形的角度来看，很明显，当且仅当函数 f(x) 和 g(x) 的图形的交点位于横坐标之后时，在 x² 处具有相同正系数（和正判别）的两个平方三项式 f(x) 和 g(x) 的根才会改变。在代数语言中，这意味着函数 f(x) 和 g(x) 的总值为负。在我们的例子中，f(x) = g(x) ⇔ x = \frac{a^2}{2} 和 f\left(\frac{a^2}{2}\right) = \frac{a^4}{4} + 2a;因此，问题的条件满足不等式 a^4 + 8a < 0 或 -2 < a < 0 的解。

这个例子表明，两个平方三项式的根的相对位置取决于它们在点 x₀ 处的行为，其中这些三项式属于相同的值（重要的是点 x₀ 是唯一的！）。

现在让$h(x) = f(x) - g(x)$。容易看出$h(x)$是一个与常数($p \neq r$)不同的线性函数。因此，它是单调的（减少或增加）。这意味着，如果对于某些$a < b$，不等式$h(a) < h(b)$（或$h(a) > h(b)$）成立，那么对于任何$c < d$，不等式$h(c) < h(d)$（或$h(c) > h(d)$）成立。

标准 1 的证明

必要性（⇒）。让$x_2 < x_1 < x_4 < x_3$。然后$f(x_4) > 0$，$h(x_4) = f(x_4) - g(x_4) = f(x_4) > 0$。 Likewise $g(x_1) > 0$, and therefore $h(x_1) < 0$.

来自不平等 $x_1 < x_4$ 和 $h(x_1) < h(x_4)$ 我们明白了 $h(x)$ - 增加功能。

Since $h(x_0) = 0$, we have $h(x_1) < h(x_0) < h(x_4)$, hence $x_1 < x_0 < x_4$.因此，两个根$f(x)$都小于$x_0$，因此$f(x_0) > 0$、$f'(x_0) > 0$。同样，两个根$g(x)$都大于$x_0$，因此$g'(x_0) < 0$。 The necessity of criterion 1 has been proven.够了（⇔）。 Let $f(x_0) > 0$, $f'(x_0) > 0$, $g'(x_0) < 0$.从前两个不等式可知，两个根 $f(x)$ 都小于 $x_0$，并且从不等式 $g(x_0) > 0$、$g'(x_0) < 0$ 可知，两个根 $g(x)$ 均大于 $x_0$，因此大于 $x_2 < x_1 < x_0 < x_4 < x_3$。

标准 2 的证明

必要性（⇒）。让$x_2 < x_4 < x_1 < x_3$。然后$f(x_4) < 0$，$g(x_1) < 0$，所以$h(x_4) < 0 < h(x_1)$，从$x_4 < x_1$开始，我们看到$h(x)$是一个递增函数。因此，$h'(x) > 0$对于任何$x$，特别是$h'(x_0) > 0$，由此而来$f'(x_0) > g'(x_0)$。

另一方面，从条件来看 $h(x_4) < h(x_1)$ 我们明白了 $x_4 < x_0 < x_1$， 所以 $x_2 < x_0 < x_1$， 在哪里 $f'(x_0) > g'(x_0)$.

另一方面，从条件来看 $h(x_4) < h(x_1)$ 我们明白了 $x_4 < x_0 < x_1$， 所以 $x_2 < x_0 < x_1$， 在哪里 $f'(x_0) > g'(x_0)$.

够了（⇔）。令$f(x_0) < 0$，$f'(x_0) > g'(x_0)$。 Then $h'(x_0) > 0$, and since $h'(x)$ is a constant function, $h'(x) > 0$ for any $x$, that is, $h(x)$ is an increasing function.

从条件来看 $f(x_0) = g(x_0) < 0$，我们得到 $x_2 < x_0 < x_1$, $x_4 < x_0 < x_3$，并且自从 $h(x)$ 回报 $0 = h(x_0) < h(x_1)$, $h(x_4) < h(x_0) = 0$， 在哪里 $g(x_1) = f(x_1) - h(x_1) < 0$, $f(x_4) = h(x_4) + g(x_4) < 0$;

因此， $x_4 < x_1 < x_3$, $x_2 < x_4 < x_1$， 那是 $x_2 < x_4 < x_1 < x_3$.

标准 3 的证明

必要性（⇒）。让$x_2 < x_4 < x_3 < x_1$。然后$g(x_1) > 0$，$g(x_2) > 0$，从$h(x_1) < 0$，$h(x_2) < 0$，因此在区间$[x_2; x_1]$上，线性函数$h(x)$不会消失，所以$x_0 < x_2 < x_1$或$x_0 < x_2 < x_1$。

如果 $x_0 < x_2 < x_1$， 那 $x_0$ 位于公三项递减区间内，所以 $f'(x_0) < 0$, $g'(x_0) < 0$。除了， $h(x_0) > h(x_2)$， 所以 $h(x)$ - 递减函数， $h'(x) < 0$ 对于任何人 $x$，特别是， $h'(x_0) < 0$， 那是 $f'(x_0) - g'(x_0) < 0$。因此产品 $g'(x_0)|f'(x_0) - g'(x_0)|$ 积极地。

情况$x_2 < x_1 < x_0$的处理方式类似。

够了（⇔）。令$f(x_0) > 0$，并首先假设$g'(x_0) > 0$，$f'(x_0) - g'(x_0) > 0$。那么两个根$g(x)$都小于$x_0$，即$x_4 < x_3 < x_0$。另外，$h(x)$是一个返回函数，因此$h(x_4) < x_3 < h(x_0)$，因此$f(x_4) < 0$，$f(x_3) < 0$。因此，$x_2 < x_4 < x_1$，$x_2 < x_3 < x_1$，即$x_2 < x_4 < x_1 < x_3$。

案件处理方式类似 $g'(x_0) < 0$, $f'(x_0) - g'(x_0) < 0$.

1. $(x^2 + 13x - 49)(x^2 + 14x - 50) > 0$。表示$f(x) = x^2 - 13x - 49$、$g(x) = x^2 + 14x - 50$，我们很容易发现$x_0 = 1$、$f(1) = -35$，并且从$13 < 14$（参见准则5）开始，这三项的根通过不等式$x_4 < x_2 < x_3 < x_1$相关。使用积分方法（参见«Kvant»，No.12，1985，第18页和图8），我们找到这个不等式的解：$x < x_4$，$x_2 < x < x_3$，$x > x_1$，或者写出根，$x < -7 - 3\sqrt{11}, -\frac{13 + \sqrt{365}}{2} < x < -7 + 3\sqrt{11}, x > \frac{\sqrt{365} - 13}{2}$。

5. $(x^2 + 2x + 4 - a)(x^2 - 2x - a) < 0.$

让我们输入$f(x) = x^2 + 2x + 4 - a$，$g(x) = x^2 - 2x - a$。请注意，如果这些三元组之一的判别式为负，则该三元组对于所有 $x$ 均为正，并且对于 $a$ 的相应值，此不等式是二次的。这些案例代表了读者，我们假设两个判别式都是正的，这对于$a > 3$成立。那么$f(x)$和$g(x)$各有两个不同的根$x_{1,2}$和$x_{3,4}$。在本例中，$x_0 = -1$、$f(-1) = 3 - a < 0$、$2 > -2$ 以及标准 2 $x_2 < x_4 < x_1 < x_3$。因此，对于 $a > 3$，该不等式的解为（参见 图 11）

$$-1 - \sqrt{a - 3} < x < 1 - \sqrt{a + 1},$$

$$-1 + \sqrt{a - 3} < x < 1 + \sqrt{a + 1}.$$

考虑到参数$a = 3$和$a = -1$的“特殊”值（当判别式之一等于0时），不等式的完整解写为：对于$a \leq -1$没有解；有了$-1 < a < 3$，我们得到$1 - \sqrt{a + 1} < x < 1 + \sqrt{a + 1}$；有了$a > 3$我们得到$-1 - \sqrt{a - 3} < x < 1 - \sqrt{a + 1},$

$$-1 + \sqrt{a - 3} < x < 1 + \sqrt{a + 1}.$$

6. 不平等系统在 a 的值是多少时

$$2x^2 - 3ax - 9 \leq 0, x^2 + ax - 2 \geq 0$$

有解决办法吗？

请注意，每个正方形三透镜

$$f(x) = 2x^2 - 3ax - 9$$

和

$$g(x) = 2x^2 + 2ax - 4$$

有两个不同的根，并且

$$f(x) \leq 0 \Leftrightarrow x_2 \leq x \leq x_1,$$

$$g(x) \geq 0 \Leftrightarrow x \leq x_4$$ 或 $x \geq x_3$。

为了使该系统有解，线段$[x_2; x_1]$与射线$|-\infty; x_4|$和$[x_3; +\infty]$之一至少有一个公共点是必要且充分的。除了第四个标准之外，在我们的所有标准中都是如此（不考虑根重合的可能性）：系统无解当且仅当$x_4 < x_2 < x_1 < x_3$。

由于$f(x) = g(x) \Leftrightarrow ax = -1$，那么对于$a \neq 0$，我们有$x_0 = -\frac{1}{a}$，

$$f\left(-\frac{1}{a}\right) = \frac{2}{a^2} - 6, \quad f'\left(-\frac{1}{a}\right) = -\frac{4}{a} - 3a,$$

$$g'\left(-\frac{1}{a}\right) = -\frac{4}{a} + 2a$$

并且根据标准 4，必须满足不平等系统

$$2 - 6a^2 > 0, \quad -\left(\frac{4}{a} + 3a\right) 5a > 0.$$

很容易验证这个系统无解，因此$a \neq 0$不存在“坏”值，也就是说，对于任何$a \neq 0$这个系统都有解。由于它也有$a = 0$的解，所以问题6的解都是$a$的值。

7. 对于a的什么值，不等式$x^2 + 2x + a + 1 \geq 0, x^2 + x + 2a - 1 \leq 0$的解集是长度为1的线段？判别三透镜

$$f(x) = x^2 + 2x + a + 1 \quad \text{и} \quad g(x) = x^2 + x + 2a - 1$$

分别等于$-4a$和$5 - 8a$，因此对于$a > 5/8$，给定系统无解，对于$0 < a < 5/8$，它等价于不等式$g(x) \leq 0$，并且在区间$[x_4; x_3]$上得到满足。从条件来看

$$x_3 - x_4 = 1 \Leftrightarrow \sqrt{5 - 8a} = 1 \Leftrightarrow a = 1/2$$

并且从$0 < 1/2 < 5/8$开始，我们得到$a = 1/2$是问题的一个解。

在 $a = 0$ 和 $a = 5/8$ 处，系统的解是在 $x_1 - x_2 = 1$ 处的对应解，从中找到$a = -1$。答案：$a = -1$和$a = 1/2$。
