4. $$\frac{x^2 - x - 4}{4 - |3x^2 - 2x - 7|} \leq 0.$$

让我们将这个不等式两边乘以正表达式 $(4 + |3x^2 - 2x - 7|)^{-1}$。将平方差分解为分母，化简后得到不等式

$$\frac{x^2 - x - 4}{(3x^2 - 2x - 3)(3x^2 - 2x - 11)} \geq 0.$$

放入$f(x) = 3x^2 - 3x - 12$、$g(x) = 3x^2 - 2x - 3$、$h(x) = 3x^2 - 2x - 11$，就可以找出它们的根$x_{1,2}, x_{3,4}, x_{5,6}$的相对位置。

三透镜$g(x)$和$h(x)$的$x y$系数相等，因此我们的准则不适用。然而，这种情况甚至简化了解决方案。事实上，$h(x) = g(x) - 8$，所以$h(x_{3,4}) = g(x_{3,4}) - 8 = -8 < 0$，因此根$g(x)$位于根$h(x)$之间，即

$$x_6 < x_4 < x_3 < x_5.$$

对于三个镜头 $f(x)$ 和 $g(x)$，我们有 $x_0 = -9$、$f(-9) > 0$、$f'(-9) < 0$、$g'(-9) < 0$、$-3 < -2,$

$$x_2 < x_4 < x_3 < x_1.$$

因此，$x_6 < x_2 < x_4 < x_3 < x_5$，以及不等式的解（参见图 10）为：

$$x < \frac{1 - \sqrt{34}}{3}, \frac{1 - \sqrt{17}}{2} \leq x < \frac{1 - \sqrt{10}}{3},$$

$$\frac{1 + \sqrt{10}}{3} < x < \frac{1 + \sqrt{34}}{3}, x \geq \frac{1 + \sqrt{17}}{2}.$$

5. $(x^2 + 2x + 4 - a)(x^2 - 2x - a) < 0.$

让我们输入$f(x) = x^2 + 2x + 4 - a$，$g(x) = x^2 - 2x - a$。请注意，如果这些三元组之一的判别式为负，则该三元组对于所有 $x$ 均为正，并且对于 $a$ 的相应值，此不等式是二次的。这些案例代表了读者，我们假设两个判别式都是正的，这对于$a > 3$成立。那么$f(x)$和$g(x)$各有两个不同的根$x_{1,2}$和$x_{3,4}$。在本例中，$x_0 = -1$、$f(-1) = 3 - a < 0$、$2 > -2$ 以及标准 2 $x_2 < x_4 < x_1 < x_3$。因此，对于 $a > 3$，该不等式的解为（参见 图 11）

$$-1 - \sqrt{a - 3} < x < 1 - \sqrt{a + 1},$$

$$-1 + \sqrt{a - 3} < x < 1 + \sqrt{a + 1}.$$

考虑到参数$a = 3$和$a = -1$的“特殊”值（当判别式之一等于0时），不等式的完整解写为：对于$a \leq -1$没有解；有了$-1 < a < 3$，我们得到$1 - \sqrt{a + 1} < x < 1 + \sqrt{a + 1}$；有了$a > 3$我们得到$-1 - \sqrt{a - 3} < x < 1 - \sqrt{a + 1},$

$$-1 + \sqrt{a - 3} < x < 1 + \sqrt{a + 1}.$$

6. 不平等系统在 a 的值是多少时

$$2x^2 - 3ax - 9 \leq 0, x^2 + ax - 2 \geq 0$$

有解决办法吗？

请注意，每个正方形三透镜

$$f(x) = 2x^2 - 3ax - 9$$

和

$$g(x) = 2x^2 + 2ax - 4$$

有两个不同的根，并且

$$f(x) \leq 0 \Leftrightarrow x_2 \leq x \leq x_1,$$

$$g(x) \geq 0 \Leftrightarrow x \leq x_4$$ 或 $x \geq x_3$。
