2. 将不等式写成$x^2 - 3x + 1 < x - a < 3x - x^2 - 1,$形式后，我们得到一个不等式系统$f(x) < 0, g(x) < 0,$，其中$f(x) = x^2 - 4x + 1 + a, g(x) = x^2 - 2x + 1 - a.$，该系统只能对三项式$f(x)$和$g(x),$的正判别式有解，即$0 < a < 3$。

对于$0 < a < \frac{3-\sqrt{5}}{2}, \frac{3-\sqrt{5}}{2} < a < \frac{3+\sqrt{5}}{2}, \frac{3+\sqrt{5}}{2} < a < 3,$，三项式$f(x)$和$g(x)$的根分别按以下顺序排列：

$x_2 < x_4 < x_3 < x_1; x_4 < x_2 < x_3 < x_1; x_4 < x_2 < x_1 < x_3.$

在 $f(a) = 0$ 的情况下（a 是三项式的公根），使用 Vieta 定理求三项式 $f(x)$ 和 $g(x)$ 的二次根，并证明对于 $a = \frac{3-\sqrt{5}}{2}$ 和 $a = \frac{3+\sqrt{5}}{2}$，分别有 $x_2 = x_4 < x_3 < x_1$ 和 $x_4 < x_2 < x_1 = x_3.$

3. 将不等式乘以$a$并代入$y = 2ax,$，我们得到一个不等式，可以表示为$(y^2 + 2y - a)(y^2 - 2a + 4) \ge 0.$

4. 将$f_k(x) = 3x^2 + 2kx - k - 1,$放入$f_k(x) = f_n(x) \Leftrightarrow x_0 = \frac{1}{2},$和$f_k(x_0) = -\frac{1}{4}$，对于所有$k = 1, 2, \dots, 10,$即$f_k(x_0) < 0.$，用$q_k, p_k, (g_k < p_k),$表示三项式$f_k(x)$的根，我们得到以下根：

$q_{10} < \dots < q_2 < q_1 < p_{10} < p_9 < \dots < p_1,$ 所以这个方程组的解是第一个三项式的根和小数三项式的大根之间的间隔$q_1 \leq x \leq p_10,$。
