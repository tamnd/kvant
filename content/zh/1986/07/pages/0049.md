标准 1 的证明

必要性（⇒）。让$x_2 < x_1 < x_4 < x_3$。然后$f(x_4) > 0$，$h(x_4) = f(x_4) - g(x_4) = f(x_4) > 0$。同样$g(x_1) > 0$，因此$h(x_1) < 0$。

从不等式$x_1 < x_4$和$h(x_1) < h(x_4)$我们得到$h(x)$是一个增函数。

从$h(x_0) = 0$开始，我们有$h(x_1) < h(x_0) < h(x_4)$，因此有$x_1 < x_0 < x_4$。因此，两个根$f(x)$都小于$x_0$，因此$f(x_0) > 0$、$f'(x_0) > 0$。同样，两个根$g(x)$都大于$x_0$，因此$g'(x_0) < 0$。准则1的必要性已被证明。够了（⇔）。让$f(x_0) > 0$，$f'(x_0) > 0$，$g'(x_0) < 0$。从前两个不等式可知，两个根 $f(x)$ 都小于 $x_0$，并且从不等式 $g(x_0) > 0$、$g'(x_0) < 0$ 可知，两个根 $g(x)$ 均大于 $x_0$，因此大于 $x_2 < x_1 < x_0 < x_4 < x_3$。

标准 2 的证明

必要性（⇒）。让$x_2 < x_4 < x_1 < x_3$。然后$f(x_4) < 0$，$g(x_1) < 0$，所以$h(x_4) < 0 < h(x_1)$，从$x_4 < x_1$开始，我们看到$h(x)$是一个递增函数。因此，$h'(x) > 0$对于任何$x$，特别是$h'(x_0) > 0$，由此而来$f'(x_0) > g'(x_0)$。

另一方面，从条件$h(x_4) < h(x_1)$我们得到$x_4 < x_0 < x_1$，因此$x_2 < x_0 < x_1$，由此得到$f'(x_0) > g'(x_0)$。

另一方面，从条件$h(x_4) < h(x_1)$我们得到$x_4 < x_0 < x_1$，因此$x_2 < x_0 < x_1$，由此得到$f'(x_0) > g'(x_0)$。

够了（⇔）。令$f(x_0) < 0$，$f'(x_0) > g'(x_0)$。那么$h'(x_0) > 0$，又由于$h'(x)$是常函数，$h'(x) > 0$对于任何$x$，即$h(x)$是增函数。

从条件$f(x_0) = g(x_0) < 0$，我们得到$x_2 < x_0 < x_1$，$x_4 < x_0 < x_3$，并且由于$h(x)$返回，$0 = h(x_0) < h(x_1)$，$h(x_4) < h(x_0) = 0$，因此$g(x_1) = f(x_1) - h(x_1) < 0$，$f(x_4) = h(x_4) + g(x_4) < 0$；

因此，$x_4 < x_1 < x_3$，$x_2 < x_4 < x_1$，即$x_2 < x_4 < x_1 < x_3$。

标准 3 的证明

必要性（⇒）。让$x_2 < x_4 < x_3 < x_1$。然后$g(x_1) > 0$，$g(x_2) > 0$，从$h(x_1) < 0$，$h(x_2) < 0$，因此在区间$[x_2; x_1]$上，线性函数$h(x)$不会消失，所以$x_0 < x_2 < x_1$或$x_0 < x_2 < x_1$。

若$x_0 < x_2 < x_1$，则$x_0$位于公三项递减区间内，故$f'(x_0) < 0$，$g'(x_0) < 0$。另外，$h(x_0) > h(x_2)$，所以$h(x)$是递减函数，$h'(x) < 0$对于任何$x$，特别是$h'(x_0) < 0$，它是$f'(x_0) - g'(x_0) < 0$。因此乘积$g'(x_0)|f'(x_0) - g'(x_0)|$为正。

情况$x_2 < x_1 < x_0$的处理方式类似。

够了（⇔）。令$f(x_0) > 0$，并首先假设$g'(x_0) > 0$，$f'(x_0) - g'(x_0) > 0$。那么两个根$g(x)$都小于$x_0$，即$x_4 < x_3 < x_0$。另外，$h(x)$是一个返回函数，因此$h(x_4) < x_3 < h(x_0)$，因此$f(x_4) < 0$，$f(x_3) < 0$。因此，$x_2 < x_4 < x_1$，$x_2 < x_3 < x_1$，即$x_2 < x_4 < x_1 < x_3$。

情况$g'(x_0) < 0$、$f'(x_0) - g'(x_0) < 0$的处理方式类似。

现在让我们解决几个不等式。

1. $(x^2 + 13x - 49)(x^2 + 14x - 50) > 0$。表示$f(x) = x^2 - 13x - 49$、$g(x) = x^2 + 14x - 50$，我们很容易发现$x_0 = 1$、$f(1) = -35$，并且从$13 < 14$（参见准则5）开始，这三项的根通过不等式$x_4 < x_2 < x_3 < x_1$相关。使用积分方法（参见«Kvant»，No.12，1985，第18页和图8），我们找到这个不等式的解：$x < x_4$，$x_2 < x < x_3$，$x > x_1$，或者写出根，$x < -7 - 3\sqrt{11}, -\frac{13 + \sqrt{365}}{2} < x < -7 + 3\sqrt{11}, x > \frac{\sqrt{365} - 13}{2}$。

2. $(x^2 + 6x - 11) < -2x^2 - 13x + 24$。让我们将这个不等式重写为$2x^2 + 13x - 24 < x^2 + 6x - 11 < -2x^2 - 13x + 24$的形式。

因此，我们必须解决不平等系统$f(x) < 0$，$g(x) < 0$，其中

$$f(x) = 3x^2 + 21x - 39,$$

$$g(x) = 3x^2 + 19x - 35$$

（我们将三个 $f(x)$ 乘以 3，以均衡前导系数 $f(x)$ 和 $g(x)$）。

我们有：$x_0 = 2$、$f(2) > 0$、$g'(2) > 0$、$p - r > 0$ 和（参见标准 3）$x_2 < x_4 < x_3 < x_1$。因此，系统$f(x) < 0$、$g(x) < 0$以及原始不等式的解是值$x_4 < x < x_3$，即$-\frac{19 + \sqrt{781}}{2} < x < \frac{\sqrt{781} - 19}{2}$。
