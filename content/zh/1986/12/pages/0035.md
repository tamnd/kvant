⟦folio 33⟧

分别沿杆、沿力 $\vec{N}$ 和沿力 $\vec{f}$ 定向。令向量 $\vec{n}_l$ 与地平线所成的角度等于 $\alpha'$。因为，由于杆的旋转，它所在的垂直平面旋转了角度$\varphi/2$，所以很容易证明：

$$tg \alpha' = tg \alpha/\cos (\varphi/2).$$

让我们用单位向量$\vec{n}_x$、$\vec{n}_y$和$\vec{n}_z$来表达每个向量$\vec{n}_l$、$\vec{n}_N$和$\vec{n}_f$。让我们从$\vec{n}_l$开始：

$$\vec{n}_l = \vec{n}_x \left( -\cos \alpha' \cos \frac{\varphi}{2} \right) + \vec{n}_y \cos \alpha' \sin \frac{\varphi}{2} + \vec{n}_z \sin \alpha'.$$

力$\vec{N}$垂直于杆并在点$C'$（圆柱体的边缘）处与圆相切，这意味着矢量$\vec{n}_N$垂直于矢量$\vec{n}_y$，即

$$\vec{n}_N = \vec{n}_x \sin \gamma + \vec{n}_z \cos \gamma,$$

(*)

以及向量$\vec{n}_l$。从这里我们得到角度$\gamma$和$\alpha'$之间的对应关系，形式为

$$tg \gamma = tg \alpha'/\cos (\varphi/2).$$

为了确定向量$\vec{n}_f$的方向，我们考虑到它垂直于向量$\vec{n}_N$和向量$\vec{n}_l$。经过多次计算我们得到

$$\vec{n}_f = \vec{n}_x \left( -\cos \gamma \cos \alpha' \sin \frac{\varphi}{2} \right) + \vec{n}_y \left( -\sin \gamma \sin \alpha' - \cos \gamma \cos \alpha' \cos \frac{\varphi}{2} \right) + \vec{n}_z \sin \gamma \cos \alpha' \sin \frac{\varphi}{2}.$$

(**)

从方程 (*) 和 (**) 可以得出 $N_x = N \sin \gamma, N_y = 0,$

$$f_x = f \left( -\cos \gamma \cos \alpha' \sin \frac{\varphi}{2} \right),$$

$$f_y = f \left( -\sin \gamma \sin \alpha' - \cos \gamma \cos \alpha' \cos \frac{\varphi}{2} \right).$$

正如已经指出的，力矩特性方程意味着，特别是，力 $\vec{N}$ 和 $\vec{f}$ 之和的水平投影必须位于杆的平面内，即

$$f_x \sin \frac{\varphi}{2} + N_x \sin \frac{\varphi}{2} + f_y \cos \frac{\varphi}{2} = 0.$$

摩擦系数$k_{\min}$的最小值由对应关系$k_{\min} N = f$确定。然后我们终于得到

$$k_{\min} = \frac{tg (\varphi/2)}{\sqrt{1 + ctg^2 \alpha \cos^2(\varphi/2)}}.$$
