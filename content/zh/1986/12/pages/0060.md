⟦folio 58⟧

选定的学校问题

1. 根据条件$1 = (x+y+z)^2 = x^2+y^2+z^2 + 2xy+2xz+2yz$，但是$xy+xz+yz=0$。

2. 设 $K$ 为 AF 的中点，L 为 BF 的中点（令 图）。四边形 EFKL 是平行四边形，因为 EK 与 BF 平行，EL 与 AF 平行（EK 和 EL 是三角形 ABF 的中线）。设H为EF的中点；那么KL经过H，则KH=LH。同理，证明连接线段DE和CE的中点的线段MN经过点H并被该点平分。因此，四边形 KLMN 是平行四边形。

3. 在D点指示。为两名游泳者建立运动图表，并确保游泳者每隔一段时间就会在 C 点和 D 点相遇。

4. $\frac{\pm 3 \pm \sqrt{17}}{2}$。笔记。放$u = \frac{x+2}{x+1}$，$v = \frac{x-2}{x-1}$。然后是$u^2+v^2 - \frac{5}{2}uv = 0$，由此而来的$u=2v$或$v=2u$。

5. $30^\circ$。解决方案（可访问内存）。令 $C'$ 为相对于线 AB 与 C 点对称的点（令 图）。让我们描述一个围绕三角形 CAC' 的圆。由于$\angle CAC' = 150^\circ$，圆弧CAC'包含60°，因此弦线CC'等于圆的半径，B点为其圆心。因此$\angle B = 30^\circ$。

6. $\frac{5}{2} \leq x \leq 3$。笔记。输入$y = \sqrt{2x-5}$。然后$y \geq 0$和$(y+3) + |y-1| = 4$。因此$0 \leq y \leq 1$。

7. $2\sqrt{S_1S_2}$。解决方案。设三角形ABC的面积为S。三角形ABC与三角形AMK和CLM相似（令图），所以

$$\sqrt{\frac{S_1}{S}} = \frac{AL}{AC}, \quad \sqrt{\frac{S_2}{S}} = \frac{LC}{AC},$$

在哪里

$$\frac{\sqrt{S_1} + \sqrt{S_2}}{\sqrt{S}} = \frac{AL + LC}{AC} = 1,$$

即$S = S_1 + S_2 + 2\sqrt{S_1S_2}$。

8. 我们有

$$tg \alpha tg \beta + tg \gamma(tg \alpha + tg \beta) < 1,$$

$$tg \gamma \frac{tg \alpha + tg \beta}{1 - tg \alpha tg \beta} < 1$$

（根据条件$(1 - tg \alpha tg \beta > 0)$），

$$tg \gamma tg (\alpha + \beta) < 1, \quad tg \gamma < ctg (\alpha + \beta),$$

$$tg \gamma < tg \left( \frac{\pi}{2} - \alpha - \beta \right), \quad \gamma < \frac{\pi}{2} - \alpha - \beta,$$

$$\alpha + \beta + \gamma < \frac{\pi}{2}.$$

9. $x = y = z = \frac{3 + \sqrt{5}}{2}$。笔记。显然$x \geq 1$，$y \geq 1$，$z \geq 1$。让我们证明$x = y = z$。并非所有这些数字都相等。让我们选择其中最多的一个。我们假设它是$x$，即$x \geq y$，$x \geq z$。从$y = (x-1)^2$、$z = (y-1)^2$和$x = (z-1)^2$开始，它影响$(z-1)^2 \geq (x-1)^2$，这意味着$z \geq x$。因此$x = z$。与$x = y$相同。

10. 让我们构建$\overrightarrow{AN} = \overrightarrow{CN}$；令 $P$ 为线段 MN 的中点，$Q$ 为线段 N'M 的中点 (图 1)。我们有 $\overrightarrow{N'N} = \overrightarrow{AC}$，因此有 $\overrightarrow{QP} = \frac{1}{2} \overrightarrow{AC}$。三角形AN'M 是等分的，因此Q 点是等于角B 的角的二边线。P 点是从Q 点通过常数向量得到的。因此，我们要寻找的几何位置是一个线段。它的末端很容易找到。

答案（计数确定$AB > BC$）：AC边的中点与线段BB'的中点相连的线段；其中$B'$是AB边上的一个点，使得$AB' = BC$。 （顺便说一下，该线段平行于角 B 的二边线。）

11. $(1 + \sqrt{3}) \left(1 + \frac{\sqrt{3}}{2}\right)$。笔记。 $(1 + x)^4 = 2 + 2x^4$和$(1 + x)^4 - (1 - x)^4 = 2 + 12x^2 + 2x^4$，由此产生$(1 - x)^4 = 12x^2$，即$(1 - x)^2 = \sqrt{12} |x|$。情况$x \leq 0$无解；在$x > 0$的情况下，我们得到一个二次方程$(1 - x)^2 = 2\sqrt{3}x$，其根为$x_{1,2} = 1 + \sqrt{3} \pm \sqrt{3} + 2\sqrt{3} = (1 + \sqrt{3}) \left(1 + \frac{\sqrt{3}}{2}\right)$。

12. a）$b_c = \frac{2ab}{a+b} \cos \frac{\gamma}{2}$。笔记。如果$CL$是角C的二等线，则$S_{CAL} + S_{CBL} = \frac{1}{2} b \cdot l_c \sin \frac{\gamma}{2} + \frac{1}{2} a l_c \sin \frac{\gamma}{2} = S_{ABC} = \frac{1}{2} \times ab \sin \gamma$。

16. 让$l_c = l_b$。让我们证明角 C 和 B 相等。让我们假设这是真的。让$\angle C = \gamma$，$\angle B = \beta$并定义$\gamma > \beta$。然后$c > b$。现在比较表达式$l_c = \frac{2ab}{a+b} \cos \frac{\gamma}{2}$和$l_b = \frac{2ac}{a+c} \cos \frac{\beta}{2}$，我们得到$l_c < l_b$（因为$\cos \frac{\gamma}{2} < \cos \frac{\beta}{2}$和$\frac{b}{a+b} < \frac{c}{a+c}$）。矛盾。 （顺便说一句，我们证明了在三角形中，较小的角对应于较大的比色角。）
