6) 与a)点完全相同，证明如果记号中的数字为$a_1, a_2, ..., a_n$，则数字$S_n^k$是$k$块的乘积之和。那么我们可以依次找到

$$S_2^1 = x_1 + x_2, \quad S_2^2 = x_1x_2,$$

$$S_3^1 = S_2^1 + x_3, \quad S_3^2 = S_2^2 + S_1^2 \cdot x_3, \quad S_3^3 = S_2^2x_3,$$

然后$S_n^k (1 \leq k \leq 4), \quad S_5^k (1 \leq k \leq 5)$，最后$S_6^k (1 \leq k \leq 5)$，使用公式

$$S_n^1 = S_n^{1-1} + x_n, \quad S_n^k = S_n^{k-1} + S_n^{k-1}x_n$$

($1 < k < n$), $S_n^n = S_n^{n-1}x_n$.

要计算所有$S_n^k (1 \leq k \leq n)$，需要进行$n-1$加法和$n-1$乘法。因此，要执行到 $n=6$，您需要 $1+2+3+4+5=15$ 加法和相同次数的乘法。最后的乘法$S_6^k = S_5^kx_6$可以通过计算所有6个数字的乘积来保存。

类似地，可以证明$n$数与$k (k=1, 2, ..., n)$的乘积之和可以在$1+2+...+(n-1)=n(n-1)/2$加法和相同次数的乘法中找到。弄清楚是否可以用更少的操作来做到这一点将会很有趣。

F974。确定图所示系统的小振荡周期：负载质量m，弹簧弹力k，∠AOB=α。杆和块光滑，弹簧失重。固定在A点的原因。如果负载m也固定在O点，振荡周期会改变吗？

假设负载移动了一小段距离 x。让我们看看线张力如何变化。

由于弹簧在任何时刻都是失重的（参见图）

$$F_y = T \cos \alpha,$$
即$k(\Delta l + \Delta l') = T \cos \alpha'$，
其中$\Delta l' = |OO'|, \alpha' = \angle AO'B$。从图、$|OO'| = x/\cos \alpha$和$\alpha' = \alpha + \Delta \alpha$可以看出，其中$\Delta \alpha = \frac{x \mathrm{tg} \alpha}{l - x}$。
从$\cos(\alpha + \Delta \alpha) = \cos \alpha \cos \Delta \alpha - \sin \alpha \sin \Delta \alpha \approx \cos \alpha - \Delta \alpha \cdot \sin \alpha = \cos \alpha - \frac{x}{l - x} \sin \alpha \mathrm{tg} \alpha$开始，
与少量混合货物签证

$$T = \frac{k(\Delta l + \frac{x}{\cos \alpha})}{\cos \alpha - \frac{x}{l - x} \sin \alpha \mathrm{tg} \alpha} = \frac{k(\Delta l \cos \alpha + x)}{\cos^2 \alpha - \frac{x}{l - x} \sin^2 \alpha} \approx \frac{k(\Delta l \cos \alpha + x)}{\cos^2 \alpha}$$

（我们忽略了分母的第二项，因为$\frac{x}{l - x} \to 0$在$x \to 0$）。

现在让我们写出负载的运动方程：

$$ma = mg - T = mg - \frac{k \Delta l}{\cos \alpha} - \frac{kx}{\cos^2 \alpha} = -\frac{kx}{\cos^2 \alpha}$$

该方程描述了弹簧负载振荡周期的和谐公式。

从解中可以清楚地看出，如果在 O 点固定负载，则振荡周期将增加，因为在这种情况下，对于相同的 α 值，T 的值将较小；固定在 A 点的负载加速度将增加 - 振荡周期将减少。
