M962。证明对于任何具有整数系数的多项式 P(x)，不可能找到满足等式 P(x1) = x2、P(x2) = x3、...、P(xn-1) = xn、P(xn) = x1 的不同整数 x1、x2、...、xn (n ≥ 3)。

◆

让我们证明，如果整数 x1, ..., xn 满足问题条件的等式，那么它将在它们之间找到相同的值。

我们使用以下引理：如果 P(x) 是具有整数系数的多项式，b 和 c 是不同的整数，则 P(b) - P(c) 可被 b−c 整除。在这种情况下，不等式 |bc−c| ≤ |P(b)−P(c)|；只有这个结果才会用来解决问题。

由于 P(x1) = x2, P(x2) = x3, 由引理 |x1−x2| ≤ |x2−x3| ≤ |x3−x4| ≤ ... ≤ |xnx1| ≤ |x1−x2|，这意味着 |x1−x2| = |x2−x3| = ... = |xn−x1|。

如果 n ≥ 3，则 x1, x2, ..., xn 中将找到相等的数：我们可以假设 x1 是这些数中最小的；然后

x2−x1 = |x1−x2| = |xn−x1| = xn−x1,

即 xn = x2。

让我们证明以下事实。从边距中给出的等式可以清楚地看出，任何正整数 k 的数字 b^k−c^k 都可以被 b−c 整除。设 P(x) = a0 + a1x + a2x^2 + ... + anx^n；那么数字 P(b)−P(c) = a1(b−c) + a2(b^2−c^2) + ... + a(n(b^n)) 也能被 b−c 整除。
