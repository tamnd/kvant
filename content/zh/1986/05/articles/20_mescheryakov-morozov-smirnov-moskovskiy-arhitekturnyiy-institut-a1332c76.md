数学
口语考试目标
1. 简化表达式：
a）$A = \frac{\sqrt{a+x}+\sqrt{a-x}}{\sqrt{a+x}-\sqrt{a-x}},$，如果$x = \frac{2ab}{b^2+1}, a > 0, 0 < b < 1$；
b) $A = \cos \frac{2\pi}{7} + \cos \frac{4\pi}{7} + \cos \frac{6\pi}{7}$;
b) $A = \frac{\lg^2(x^3)}{\lg^3(x^2)} \cdot \lg \sqrt{x}$.
2. 不用表格计算：
a) $A = 2 \cos 20^\circ \cdot \cos 40^\circ \cdot \cos 80^\circ$;
b) $A = \tg 1^\circ \cdot \tg 2^\circ \cdot \tg 3^\circ \cdot \dots \cdot \tg 88^\circ \times \tg 89^\circ$;
b) $A = \frac{2 \cos 40^\circ - \cos 20^\circ}{\sin 20^\circ}$.
3. 寻找：
a）$\sin^3 x + \cos^3 x,$，如果$\sin x + \cos x = a$；
b) $\tg \alpha - \ctg \alpha,$ 如果 $\tg \alpha + \ctg \alpha = a$。
4. 证明准确性：
a) $\tg^2\left(\frac{\pi}{4} - \alpha\right) = \frac{1 - \sin 2\alpha}{1 + \sin 2\alpha}$;
b) $32 \sin^2\alpha \cos^4\alpha = 2 + \cos 2\alpha - 2 \cos 4\alpha - \cos 6\alpha$;
b) $\sin^2(45^\circ + \alpha) - \sin^2(30^\circ - \alpha) - \sin 15^\circ \times \cos(15^\circ + 2\alpha) = \sin 2\alpha$.
5. 解方程组：
a) $\sqrt{2x+3} - \sqrt{x+1} = 1$;
b) $7 \cdot 3^{x+1} - 5^{x+2} = 3^{x+1} - 5^{x+3}$;
b) $2 \lg \lg x = \lg (3 - 2 \lg x)$;
r) $\sin^4 x + \cos^4 x = \frac{5}{8}$.
6. 解决不等式：
a) $\frac{1}{2^x-1} > \frac{1}{1-2^{x-1}}$;
b) $0,1^{\log_2 x+1}/x-3 < 10$; b) $\sqrt{24-10x} > 3-4x$.
7. 绘制图表：
a) $y = |x^2-4|$;
b) $|y-2| = |x-1|$;
b) $y = \sin |x|$.
8. 求解方程组：
a) $\begin{cases} \log_5 x + 3^{\log_3 y} = 7, \\ x^y = 625^3; \end{cases}$
b) $\begin{cases} (x+y)3^{y-x} = \frac{5}{27}, \\ 3 \log_5(x+y) = x-y. \end{cases}$

物理
口语考试目标
1. 质量$m$的梯子靠在墙上。叶片的重心位于其上端长度的1/3处。必须向梯子中间施加多大的水平力，才能使其上端对墙壁施加压力？楼梯与墙壁的夹角为$a$。
2. 质量为 $m$ 的重球悬挂在一根线上。线能承受拉力$T = 2mg$。带球的螺纹必须与平衡位置成什么角度偏转，才能使螺纹断裂并通过平衡位置？
3. 一个小物体沿着斜面滑动，从高度$H = 2R$开始逐渐变成“死循环”，其中$R$是循环的半径（参见图）。物体在什么高度会脱离环的表面？身体应该从多高的高度滑动才不会发生分离？
4. 两个质量分别为 $m_1$ 和 $m_2$ 的绝对弹性球将会发生碰撞。他们的初始速度是$v_1$和$v_2$。求球撞击后的速度。考虑中心影响：球的速度沿着连接其中心的线定向。
5. 质量为$m$的块被附着在其上的顶部均匀地沿着板拉至高度$h$，其与地平线的倾斜角为$a$。绳子与板平行。块与板之间的摩擦系数$μ$。找出用于加热板和块的能量。
6. 求将刚度为 $k = 30$ N/cm 的弹簧压缩 $x = 10$ cm 所需做的功。
7. 一个悬挂在圆圈中的铜球垂直摆动。如果将相同半径的铝球悬挂在圆上，烧瓶周期将如何变化？铜和铝的密度分别为$\rho_1 = 8,9 \cdot 10^3$ kg/m$^3$和$\rho_2 = 2,7 \cdot 10^3$ kg/m$^3$。
8. 布置一个巨大的神秘 S 以使柱的变形仅在重力影响下保持在弹性限度内的最高可能方法是什么？神秘砖石的最大相对深度是多少？杨氏模量$E = 3000$ MPa，密度$\rho = 1,8 \cdot 10^3$ kg/m$^3$，弹性极限$\sigma_{\text{np}} = 3$ MPa。
9. 为了改变$m = 66$克水的温度，将温度计浸入其中，显示$t_1 = 32,4$°C。如果温度计的比热为 $C = 1,9$ J/K，浸入水中之前显示的室温为 $t_2 = 17,8$ °C，那么水的实际温度是多少？
