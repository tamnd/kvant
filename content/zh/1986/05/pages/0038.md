F973。物体开始从 A 点移动，经过时间 T 到达 B 点 a) 以最大可能的速度； b) 以尽可能低的速度；距离|AB|等于 l。计算这两种情况下物体的速度，如果A点的速度v₀=0，物体的加速度为-a<a<a₀。

a) 要以最大速度到达 B 点，您需要按如下方式移动。在某个时间点 t₀ 之前，您需要以加速度 -a₀ 移动，然后以加速度 a₀ 移动直到结束。 t₀点由遍历路径等于l的条件求出：

$$l = -\frac{a_0 t_0^2}{2} - a_0 t_0 (t - t_0) + \frac{a_0 (T - t_0)^2}{2} \Rightarrow t_0^2 - 2 T t_0 + \frac{T^2}{2} = \frac{l}{a_0}, t_0 = T - \sqrt{\frac{T^2}{2} + \frac{l}{a_0}}$$

（二次方程解中的符号是从条件 t₀<T). Скорость в момент времени t обозначаем через V(t). График функции V(t) показан на рисунке 1 красной линии. Пусть U(t) — скорость при другом режиме движения, удовлетворяющим нашим условиям, таком, что U(T) > V(T) 中选择的。让我们证明，对于任何 t，U(t) ≥ V(t)（参见 图 1）。假设对于某个 t₁，U(t₁) < V(t₁)（这种可能性在 图 1 中显示）。如果 t₁ ≥ t₀，则 t₁ ≤ t ≤ T 段上的平均加速度大于 a₀（图 1 处的黑线比红线更陡），如果 t₁ ≤ t₀，则 0 ≤ t ≤ t₁ 段上的平均加速度小于 -a₀ 因此，如果 U(T) > V(T)，则 U(t)对于任何 t ≥ V(t)，并且以速度 U(t) 运动的物体将在时间 T 内覆盖大于 l 的线段。因此，V(T) 是最大速度：

$$V(T) = -a_0 t_0 + a_0 (T - t_0) = a_0 (T - 2 t_0) = a_0 \left( -T + 2 \sqrt{\frac{T^2}{2} + \frac{l}{a_0}} \right) = \sqrt{2 a_0^2 T^2 + 4 a_0 l} - a_0 T.$$

6) 类似地：为了以最小速度到达 B 点，你需要以加速度 a₀ 移动直到某个时刻，然后以加速度 -a₀ 移动到终点。 t₀点由遍历路径等于l的条件求出：

$$l = \frac{a_0 t_0^2}{2} + a_0 t_0 (T - t_0) - \frac{a_0 (T - t_0)^2}{2} \Rightarrow t_0 = T - \sqrt{\frac{T^2}{2} - \frac{l}{a_0}}$$

（速度 v(t) 与时间 t 的关系图如图 图 2 所示）。 T 时刻的速度等于 a₀ t₀ - a₀ (T - t₀) = a₀ (2 t₀ - T) = a₀ \left( T - 2 \sqrt{\frac{T^2}{2} - \frac{l}{a_0}} \right) = a_0 T - \sqrt{2 a_0^2 T^2 - 4 a_0 l}。

该速度最小的证明与之前的证明类似：如果 u(t) 是另一种运动模式并且 u(T) < v(T)，则对于任何 t，u(t) ≤ v(t)。

此外，a) 可能会出现 t₀ < 0：这会发生在 l > \frac{a_0 T^2}{2} 时；那么就没有办法了。那么第6部分（根下是否定表达式）无解。
