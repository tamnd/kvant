⟦folio 11⟧

零处有一个非零导数：$F'(0) = \lim_{x \to 0} (F(x)/x) = a$，那么对于小的$x$，我们可以用$ax$替换$(F(x))$的右侧。在这种情况下，$a$必须为负，否则不可能在零附近振荡！因此，我们得到线性方程 (*)，其中 $\omega = \sqrt{-a} = \sqrt{-F'(0)}$。

当然，指定的线性化过程会产生一个非等价的微分方程，但它正确地描述了向平衡位置运动的定性图景。这普遍受线性振荡器方程 (*) 及其名称的约束。

存在和唯一的解决方案

很容易检查方程 (*) 满足函数 $x = \cos \omega t$ 和 $x = \sin \omega t$，因此满足它们的线性组合，即形式的表达式

$$x(t) = a \cos \omega t + b \sin \omega t$$

（一探究竟！） *。让我们证明这个方程没有其他解。

让我们利用这样一个事实：在运动过程中，以下数量是守恒的

$$E = \frac{1}{2} (\dot{x}^2 + \omega^2 x^2) = \text{const}$$

（能量守恒定律）。

事实上，$\dot{E} = \dot{x} \dot{x} + \omega^2 x \dot{x} = \dot{x} (\dot{x} + \omega^2 \dot{x}) = 0$，这意味着$E = \text{const}$。

现在让我们考虑方程 (*): $x = x_1(t)$ 及其初始数据 $a = x_1(0)$ 和 $\beta = \dot{x}_1(0)$ 的乘积。让我们在表达式$x_2 = a \cos \omega t + b \sin \omega t$中选择系数$a$和$b$，从而得到$x_2(0) = a$，$x_2(0) = \beta$。为此，只需输入$a = a$、$b = \beta/\omega$。现在让我们求差 $x(t) = x_1(t) - x_2(t)$，这将是 (*) 的解（检查这一点）。它的初始数据为零：$x(0) = \dot{x}(0) = 0$。由于能量守恒定律

$$E = \frac{1}{2} (\dot{x}^2 + \omega^2 x^2) = \frac{1}{2} (\dot{x}^2(0) + \omega^2 x^2(0)) = 0,$$

$\dot{x}(t) \equiv x(t) \equiv 0$来自哪里，即

$$x_1(t) \equiv x_2(t) \equiv \alpha \cos \omega t + \frac{\beta}{\omega} \sin \omega t.$$

我们已经证明，任何解$x_1(t)$都具有(**)的形式，其中$a$和$b$由初始数据唯一确定： 在证明过程中，我们还得到了根据初始数据的解的公式。

在相平面上绕圈运行

让我们关注以下值得惊讶的情况。完美数$n$出乎意料地隐藏在方程（*）中，尽管问题的陈述中没有提到任何圆。事实上，方程(*)的所有解（$x(t) \equiv 0$除外）都是时间的周期函数，它们的周期与$\omega$的乘积等于$2\pi$。既然数字$n$出现了，我们就试着找一个圆。

到哪里去找呢？我们将在相平面上寻找它，即在坐标为$(u; v)$的平面上，其中$u = x$，$v = \dot{x}$。该平面上的点$(u; v)$称为相位点；它们描述了系统的状态：坐标$u = x$表示系统偏离平衡位置的偏差，坐标$v = \dot{x}$表示系统在给定时刻的运动速度。随着时间的推移，相位点$(u; v) = (x(t); \dot{x}(t))$的位置发生变化，它在相平面上描述了一条直线，称为相轨迹。哪一个？
