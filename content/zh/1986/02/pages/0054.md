⟦folio 52⟧

莫斯科国立大学以它的名字命名。 M·V·罗蒙诺索娃

数学
笔试
选项1
（力学与数学学院）

1. 解方程
$$6 \cos x - \frac{1}{3} = \sqrt{32 \cos x - \frac{17}{9}}.$$

2. 解决不等式
$$\frac{1}{x-1} + \frac{3}{|x|+1} \geq \frac{1}{|x|-1}.$$

3. 一些圆分别在 D 点和 E 点与直线 AB 和 BC 相切。A 点位于 B 和 D 点之间，C 点位于 B 和 E 点之间。如果边 AB 和 AC 的长度分别为 13 和 1，且 A、D、E、C 点位于同一个圆上，求三角形 ABC 的面积。

4. 三个 p 值中：0.24π； 0.26π； 0.6π - 找到满足以下方程的那些
$$\left( \frac{p-5x}{\pi} + \log_3 \frac{3p}{\pi} \right)(6 \sin (p-x) - \sqrt{18}) = 0$$
至少有一个解满足条件 0 < x < π/3。

5. 在穿过半径为R的球心的平面a上，给出一个圆心为O 1 、半径为r 1 的圆位于球内部。该圆的所有点均由来自 A 点的直线连接，A 点属于球，距平面 a 的距离为 R。这些直线与不同于 A 的球表面的交点集合是一个以 O2 为圆心，以 r2 为半径的圆。如果 A 点和 O₁ 之间的距离等于 a，求 O2 点到平面 a 的距离。

选项2
（计算数学与控制论学院）

1. 求解方程组
$$\begin{cases} 6x - 2 \cdot 3y = 2, \\ 6x \cdot 3y = 12. \end{cases}$$

2. 在梯形PQRS中，底边长度QR为10，对角线长度QS为19，角度QSP为30°。找出较大的一个：底 QR 的长度或边 RS 的长度。

3. 解方程
$$4 - \cos[2\pi (13x+9)^2] = 5 \cdot \sin[\pi (13x+9)^2].$$

4. 解决不等式
$$\frac{2 \log_{1-3}|x|(42x^2 - 14|x|+1)}{\log_{1-3}|x|(x - \frac{5}{6})^2} \leq 1.$$

5. 找到所有满足方程的数字 x、y、z 三元组
$$\sqrt{\frac{3}{2} x^2 - 2y^2 + 2z^2 + 10z + 6y + \frac{\sqrt{3}}{2} x - 17} + \sqrt{3x^2 - 2\sqrt{3} (\cos \pi y + \cos \pi z)} x + 4 = 0.$$

6. 四面体ABCD的所有边都具有相等的长度。在边AB、AC、AD上，选择对应点K、L、M，使得线段KB的长度等于15，线段MD的长度等于10。已知四面体ABCD内切球的半径等于$\frac{5}{2} \sqrt{6}$，棱锥体AKLM的体积等于375$\sqrt{2}$。求两个球体的半径之和：一个球体内接于金字塔 AKLM，另一个球体外接于金字塔。

选项3
（化学学院）

1. 解方程
$$4 (\sin 6x + \sin 4x) = \cos x (4 \sin^2 5x - 5).$$

2. 解决不等式
$$5^{2x} - \frac{1}{3} x^2 < 5^{2x} - 2x (\sqrt{3}^5) x^2 + 24.$$

3. 在坐标平面 xOy 上，我们考虑一个三角形 ABC，其中顶点 A 与坐标原点重合，顶点 B 和 C 分别位于抛物线上 y = 3x² - 10x + 2 和 y = -2x² + 5x - 10，边 BC 与纵坐标轴平行，顶点 B 的横坐标属于线段$\left[ \frac{3}{5}; \frac{3}{2} \right]$。

为了使三角形ABC的面积最大，顶点B的横坐标应该取什么值？

4. 金字塔的高为2，金字塔的底面为菱形，面积为8，锐角为π/6。一些沙卡接触位于金字塔底部一侧的平坦侧面的一点。证明连接金字塔顶部到球中心的直线经过对角菱形的交点。求球体的体积。

5. 解决系统
$$\begin{cases} 2x + y + \log_2^3 (|y| - 2x + 5) - 20 = 0, \\ (2x + y)^2 - 7(2x + y) \log_2 (|y| - 2x + 5) - 8 \log_2^3 (|y| - 2x + 5) = 0. \end{cases}$$

选项4
（布鲁斯学院）

1. 解方程
$$\frac{1 - x}{(2 - x)(x - 3)} + 1 = \frac{1}{2 - x}.$$

2. 找出方程的所有根
$$3 \cos 2x - 5 \sin \left(x - \frac{\pi}{2}\right) = 1,$$

属于线段[π; 2π]。

3. 解决不等式
$$\frac{1}{\log_5(3 - 2x)} - \frac{1}{4 - \log_5(3 - 2x)} < 0.$$

4. 点 N 位于矩形 LKM 的斜边 LM 上。点 P 取在直线 LM 上，使得点 M 位于点 N 和 P 之间，并且角度 NKP 是直角。如果已知三角形LKM和NKP的面积分别等于a和b，且角LKP等于φ，求三角形NKM的面积。
