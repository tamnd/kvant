F960。为了获得两个完全相同的线圈，使用复杂的电线（图1）将它们同时缠绕在非磁芯上。然而，线圈通过钥匙 K 连接到电压为 U₀ 的电池 B，第二个电池连接到电阻器 R。钥匙关闭。计算通过电阻的电流。绘制通过电池的电流与时间的关系图。

时间 t 后钥匙被打开。从此时开始，电阻器中产生了多少热量？每个线圈的电感为L。电池被认为是理想的。电线电阻索赔。

在计算每个线圈电路中的感应电动势时，需要考虑通过该线圈的总磁通量，即线圈电流产生的磁通量之和。

关闭钥匙后，两个电路中都会产生相同的电动势$E_1 = E_2 = U_0$，电阻上释放的功率等于

$$P = \frac{E_2^2}{R} = \frac{U_0^2}{R}.$$

因此，通过第二个线圈的电流等于$I_2 = U_0/R$。任意第一个线圈的磁通量等于

$$\Phi_1 = LI_1 + LI_2,$$

其中 $I_1$ 是通过第一个线圈和电池的电流。 （电流 $I_2$ 产生的通过每个线圈的磁通量是相同的 - 线圈缠绕在一起。）因此，

$$E_1 = U_0 = \left| \frac{d\Phi_1}{dt} \right| = \left| L \frac{dI_1}{dt} + L \frac{dI_2}{dt} \right| = \left| L \frac{dI_1}{dt} \right|$$

（自 $I_2 = \text{const}$ 起）。从这里

$$I_1 = \frac{U_0}{R} + \frac{U_0}{L} t.$$

图表$I_1(t)$如图2所示。第一时刻的电流跳跃是因为通过线圈的总磁通不应突然变化，并且在接通后，会立即出现与第一个线圈产生的磁通相反的额外磁通。

当钥匙打开时，通过第二个线圈的总流量等于

$$\Phi_{2\tau} = -LI_2 + LI_{1\tau} = L \frac{U_0}{L} \tau = U_0 \tau.$$

钥匙打开后，该线圈中会立即出现电流

$$I_p = \frac{U_0 \tau}{L},$$

因为通过线圈的流量不应突然改变。从打开那一刻起，电阻器上释放的热量为

$$W = \frac{1}{2} LI_p^2 = \frac{U_0^2 \tau^2}{2L}.$$
