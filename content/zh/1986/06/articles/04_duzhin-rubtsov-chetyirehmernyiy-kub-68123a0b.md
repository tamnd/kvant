四维立方体

物理和数学科学候选人
S.V.杜仁，
物理和数学科学候选人
鲁夫佐夫

“让我们考虑一个四维立方体......”，“让我们在十维空间中识别一个六维子空间......”作者经常在科学文献中遇到这些短语以及其中的许多其他短语，在各种研讨会上听到它们，自己说出它们，总之，他们已经习惯了不会对此感到惊讶。但有一天我们想：
“但“四维立方体”、“第四维度”这些词甚至对大多数数学家来说都完全陌生，并引起非专业人士的困惑和好奇，对“大脚怪”、“飞蟑螂”和其他伪科学事物感兴趣的时代已经不远了。作者之间发生了以下对话：

A₁：四维立方体？当然是小事啦！必须使用概括学校公式的公式将其简单地定义为四维空间的子集。只有公式！

答：据此，这将使得正式定义什么是四维立方体成为可能，但它会令人难以理解和不清楚。四维立方体很容易被描述为几何图形，类似于平面上的正方形或三维空间中的立方体。预测、发展、剖面——这是唯一的方法！

经过短暂的争论后，作者决定尝试统一他们的观点，但首先从问题的视觉方面开始。

如何部署
要想象四维立方体的发展，首先看一下三维和二维立方体（图3）的发展。我们看到正方形的展开是一维的，由四部分组成；立方体的展开是二维的，由六个正方形组成。同样，四维立方体的展开是三维的，由八个三维立方体（图4）组成。

正如通过识别顶点$G_1 \equiv G_2 \equiv G_3$、$H_1 \equiv H_2 \equiv H_3$、$E_1 \equiv E_2$和$F_1 \equiv F_2$（以及相应的边）可以从网络中粘合三维立方体（参见图3.6）一样，通过“粘合”由相同字母指定的顶点，可以从其网络中获得四维立方体（参见图4），但具有不同的数字，例如 $M_1 \equiv M_2 \equiv M_3 \equiv M_4$ 或 $I_1 \equiv I_2$；在这种情况下，不仅顶点（和相应的边）被粘合，而且二维面也被粘合，例如 $M_3O_3P_3Q_3 \equiv M_4O_4P_4Q_4$。

图4值得仔细观察。可以认为它展示了一种八间房屋的模型。美国科幻作家R·海因莱因在小说《直到建成的房子》中描述了这座房子。在海因莱因笔下的英雄们穿越这座美妙的房子的“旅行”中，他们对以下情况感到震惊。当他们朝着某个方向前进，经过一个又一个房间时，最后是第五个房间。

事实证明，他们的道路正是他们所走的路。例如，如果“从下到上”移动，您穿过构成扫描中央底座的四个房间，那么您会发现自己位于“一楼”的一个房间。事实上，从指定的顶点可以看出，房子的“屋顶”粘在下层房间的“地板”上。事实上，每当你穿过房间的边界时，路线都会自动转向 90°，因此，例如，折线 $M_4AEK_3M_3$ 并不是笔直的，而是显示为正方形的轮廓。通过考虑三维立方体的发展和立方体本身的表面上的相似路径（图3），这个事实很容易理解。如果您从展开过程中理解了将四维立方体粘合在一起的想法，那么您就不会惊讶于海因莱因故事中的一位英雄从其中一个房间的窗户跳出，发现自己……又回到了房子里！

然而，这样的定义并不能满足挑剔的读者。他问：什么是四维空间坐标系？一般来说，什么是四维空间？

为了回答最后一个问题，我们首先记住 - 好吧，当然，你猜对了！ - 什么是三维空间？这是所有可能的三元组 (x; y; z) 的集合，其中 x、y 和 z 是实数（点坐标），其距离由以下公式确定
$$|MN| = \sqrt{(x_M - x_N)^2 + (y_M - y_N)^2 + (z_M - z_N)^2}$$
（参见 A.V. Pogorelov 的教科书“几何 6-10”，第 204 页）。事实证明，前一句话可以被视为三维空间的定义：从这个定义中，我们可以利用初等代数导出立体测量的所有基本原理。因此，将平面定义为满足以下形式的线性方程的点的一组点
$$Ax + By + Cz + D = 0,$$
(1)
例如，不可能证明通过新共线点 M、N、P 的任意三重点，会经过一个且仅一个平面，即具有以下方程的平面
$$((y_P - y_M)(z_N - z_M) - (z_P - z_M)(y_N - y_M)) \times (x_M - x) + ((z_P - z_M)(x_N - x_M) - (x_P - x_M)(z_N - z_M))(y_M - y) + (x_P - x_M)(y_N - y_M) - (y_P - y_M)(x_N - x_M))(z_M - z) = 0$$
(2)
（参见“几何 6-10”，第 212 页）。

现在下一个定义应该是任意自然的。四维空间是所有四个数字 (x; y; z; t) 的集合，其中 x、y、z、t 是实数，其距离由以下公式确定
$$|MN|^2 = (x_N - x_M)^2 + (y_N - y_M)^2 + (z_N - z_M)^2$$
(3)

在四维空间中定义一个平面并不是那么简单。事实上，既有一般的二维平面，也有称为“zigerplanes”的三维“平面”。从用方程指定平面的角度来看，超平面是三维空间中一般平面的精确模拟。在三个变量x、y、z的声明平面的方程(1)中，可以赋予任意值，然后从方程中唯一地确定第三个变量的值。因此，

该如何总结呢
理解前面定义的读者可以轻松确定任意$n \geq 1$的$n$立方体的定义。为此，他首先定义一个$n$维空间作为$n$数字$(x_1; x_2; ...; x_n)$的集合，它们之间的距离由以下公式给出

$$|AB| = \sqrt{(a_1-b_1)^2 + (a_2-b_2)^2 + ... + (a_n-b_n)^2},$$

然后将 $n$ 立方体作为 $n$ 维空间中满足 $0 \leq x_1 \leq 1, 0 \leq x_2 \leq 1, ..., 0 \leq x_n \leq 1$ 不等式的点的集合。

如何切割它
可以很方便地想象四维函数，使用它们的截面由一系列彼此平行的超平面（如果它们的法向量共线，则超平面彼此平行）。通过考虑普通平面的三维物体的截面（图8，其中示出了平面$y=h$的立方体的截面）可以理解这种结构的含义。平面 $t=h$ 的四维立方体的截面看起来相似 - 记住 图 2！

为了更好地理解四维立方体的几何形状，请考虑以下艰巨的任务：描绘与主对角线垂直的超平面截面族。如果我们取连接顶点$(0; 0; 0; 0)$和$(1; 1; 1; 1)$的对角线，那么这些超平面的方程将具有$x+y+z+t=h$的形式，其中$h$是某个常数。

让我们以类似的方式来看待三维问题。三维立方体可以表示为由不等式系统定义的两个八分圆的交集

$$\begin{cases} x \geq 0, \\ y \geq 0, \\ z \geq 0 \end{cases}$$

和$$\begin{cases} x \leq 1, \\ y \leq 1, \\ z \leq 1 \end{cases}$$

(图9)。 $x+y+z=h$ 形式的每个平面都沿着正三角形与这两个八分圆中的每一个相交。让我们跟踪一下此配置中 $h$ 从 0 变为 $\sqrt{3}$ 的变化。在初始时刻$(h=0)$，其中一个三角形仅由一个点组成。然后它的线性尺寸按$h$的比例增加，同时第二个三角形逐渐减小，保留一个现成的具有负系数的顶点。从较小三角形的顶点“刺穿”较大三角形的边的那一刻起，它们的交点就形成了一个六边形。当比较三角形的大小时，这个六边形就变得规则了。接下来，以相反的顺序重复所描述的过程。

类似地，四维立方体表示四维空间的两个部分的交集，通过不等式$x \geq 0, y \geq 0, z \geq 0, t \geq 0$和$x \leq 1, y \leq 1, z \leq 1, t \leq 1$来区分。很容易证明超平面 $x+y+z+t=h$ 沿着规则四分体与这些部分中的每一个相交。然而，在这些四分体中，$h$随着生长而增加，而其他则减少。所需的集合是两个这样的四面体的交集，可以是一个点、一个四面体或截断的四面体（特别是，如果两个四面体的大小一致，我们将在交点处得到一个正八面体；它在 1985 年第 6 期封面«Kvant» 第 6 期封面第四页的图 3 上进行了描述）。

我们希望读者已经熟悉四维立方体的概念，能够自己画出这些截面。
