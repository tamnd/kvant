M967。让我们用 σ(n) 表示 n（包括 1 和 n）的所有自然因数之和，用 φ(n) 表示小于 n 并与其互质的数字的数量。证明对于任何自然数 n ≥ 2
σ(n) + φ(n) ≥ 2n.

设 1 = d₁ < ... < dₖ = n - 数字 n 的所有约数。
在不超过n的自然数中，dᵢ的倍数等于n/dᵢ，因此不与n互质的数字总数等于n - φ(n)，不大于总和
$$\frac{n}{d_2} + \frac{n}{d_3} + ... + \frac{n}{d_k} = d_{k-1} + d_{k-2} + ... + d_1 = \sigma(n) - n$$
（对于 n/d₁ = dₖ，n/d2 = dₖ-1，...）。因此，
n - φ(n) ≤ σ(n) - n,
由此得出不等式的证明。
请注意，对于素数 p，我们的估计是准确的：
$$\sigma(p) = p + 1, \quad \varphi(p) = p - 1, \quad \sigma(p) + \varphi(p) = 2p.$$
V·F·列夫
