⟦folio 8⟧

正在建造的内尔开始在山体两侧挖掘，计算得如此精准，两招在深处整齐地交汇。毕索哥拉斯的父亲叫Mnesarchus，是一位著名的石巢人。据英国传记作家记载，毕索戈尔是一位求知若渴的年轻人，离开故乡的岛屿环游世界，几乎走遍了所有希腊国家和许多外国国家。毕索哥拉斯取代了希腊科学家并钦佩东方的奇迹。他们说他在埃及隐秘的圣地，拜访了迦勒底圣贤和波斯魔术师，并深入克里特岛的坦尼洞穴，那里与众神的现代性神话有关。

回到萨摩斯，毕索哥拉斯发现他的祖国处于波利克拉底的暴政之下。正如一位英国传记作家所说，暴政太过强大，“一个自由人无法有尊严地忍受专制和去专制”，因此他决定退休到意大利南部，当时被取代的希腊殖民地就在那里。他定居在意大利城市克罗托内，并为那里的公民制定了法律。他们说，在外国城市中行走时，毕多哥治愈了大型动物，野生动物允许他抚摸它们，河流用人类的声音迎接他，可以同时在两个不同的地方看到他。这位哲学家非凡的个性以及他的宗教和神秘教义促进了这项服务。

毕达哥拉斯联盟。很快，毕索哥拉斯周围出现了一大群忠实于他的弟子，“因为他远远超过了其他所有人的弱点，所以所有的年轻人都想成为他的弟子。”很快，毕达哥拉斯联盟或兄弟会就由他们组织起来，它同时是一个科学协会、一个宗教联盟和一个政治俱乐部。并非所有人都可以访问它。对象必须经过长时间的测试；他们甚至说，他被命令保持沉默五年。尽管毕索哥拉斯死后一个世纪，这个联盟已经解体，但几乎所有古代伟大的数学家都称自己为毕索哥拉斯主义者。

数学证明。我们已经说过，毕索哥拉斯是数学作为一门科学的创造者。但在他之前的人难道不知道如何计算、分数加法和乘法以及计算最简单的面积和体积吗？他们当然做到了。他们甚至可以解二次方程！然而，数学作为一门科学还不存在。几千年来代代相传的数学知识几乎没有变化，它并不是以一个系统的形式组织起来的，而是基于收集的食谱，在解决具体问题时可以验证其正确性。

毕索哥拉斯认识到数学的基础是证明。没有数学的地方就没有数学。什么是证据以及为什么需要证据？

假设我们想要确定三角形的内角和为 180°。如何做到这一点？让我们这样做：小心地画一个三角形（在笔记本上用墨水或在黑板上用粉笔）并使用量角器改变它的角度。将它们加起来我们得到一个接近 180° 的数字。我们透露了什么？只是我们画的三角形的角和等于 180°01′。我们可以通过查看正在绘制的其他三角形来继续我们的更改，并且每次我们都会得到接近我们想要建立的结果。首先，结果将是近似的，因为我们使用的尺子不会绝对直（可以通过放大镜观察）。其次，量角器改变的角度在靠近点的地方不会被发现。但即使我们设法获得了完全精确的尺子和量角器，我们仍然无法建立我们的建议，因为三角形的数量是无限的，我们永远无法找到所有三角形的角度和。

毕索哥拉斯显然是第一个提出数学考虑抽象对象（即理想的没有宽度的直线、没有尺寸的点等）并且它们的属性不应该通过变化而是通过推理来建立的想法的人。例如，为了证明三角形内角和的定理，让我们像毕索哥拉斯那样画一个任意三角形（可以用手画，无需使用尺子），并通过其顶点 B 画一条与底 AC 平行的直线 LM (图 1)。然后是$\angle LBA = \angle BAC = \alpha$和$\angle MBC = \angle BCA = \gamma$（作为交叉角）。但$\angle LBA + \angle ABC + \angle MBC$之和是一个倒角，即等于180°。这意味着任何三角形的内角之和都等于 180°。

然而，在我们的证明中，我们依赖于平行线的性质，这也需要证明。他们的证明将基于其他一些性质等等。因此，在考虑了无限数量的三角形之后，我们“落入了另一个无限的魔掌”——我们需要进行无限数量的证明。我们将命题 A 约简为命题 B，命题 B 又约简为命题 C，即$A \Leftarrow B \Leftarrow C \Leftarrow \dots$。

怎么会这样呢？很明显，在某些时候我们必须停止，一些提案必须在没有证据的情况下被接受。但这样我们就可以得到无数个“无法证明”的命题，换句话说，再次“落入无穷的魔掌”！毕索哥拉斯（或他的同时代人）的下一个伟大思想是，在几何学中，可以选择有限数量的无法证明的命题（后来称为公理），从中可以推导出所有其他命题。

因此，根据毕索哥拉斯的说法，数学研究抽象对象的属性；建立真实性的手段是证明，这是基于在没有证明的情况下接受的有限数量的显示句子来进行的。

人们不应该认为这些想法立即被接受了。毕索哥斯和他的追随者们纷纷遭到嘲笑和嘲笑。一些科学家称他是一个愚蠢、多才多艺的人，是一个江湖骗子。他们说他从未见过没有宽度的线或圆只在一点与直线相接触。然而，毕索哥拉斯和他的学生继续在新的、坚实的基础上发展科学。

“数学。”这就是毕氏学派所说的他们的知识体系。 《数学》由四部分组成：算术、几何、天文学和和声学说（乐理）。前两个是纯理论的——我们仍然把它们归因于数学，另外两个是算术和几何在天体和协和律研究中的应用——我们将它们归因于数学物理。

我们对毕氏学派的算术知之甚少。众所周知，它研究的是整数及其关系，即有理数。柏拉图在他的对话录中称算术为“对四和奇数的研究”。我们可以从欧几里得《几何原本》第九卷中重构这一教导，并在其末尾（命题 21-34）复制了这一教导。毕索哥拉斯将所有整数分为四（能被2整除）和奇数（不能被2整除），并证明了函数定理：两个数的乘积是偶数当且仅当至少有一个分量是四。这是整除性理论的第一个定理，后来提出并证明了一个更一般定理的模型：两个数字的乘积可以被素数 p 整除，当且仅当至少有一个分量可以被它整除。从最后一个定理可以得出整数分解为质因数的唯一性定律。类似地，根据勾股定理，每个整数都可以唯一地表示为$N=2^kN_1$，其中$N_1$是奇数，$k$是非负整数。四和奇的学说使毕氏学派证明了许多极其重要的定理，我们将回到这些定理。

在几何学中，毕索哥拉斯被规则的图形和身体所吸引。因此，他知道平面可以用正三角形、正方形和六边形“平铺”。他知道如何建造正五边形——凸形和星形。据说五角星是健康的象征，很快就成为散布在古代世界各地的毕氏学派的识别标记。几何学的顶峰是毕达哥拉斯定理，它对于数学本身及其应用都具有根本性的意义。毕索哥拉斯是如何证明的呢？不幸的是，我们不知道这一点。

毕索哥拉斯还发展了相似性学说，最初他显然认为所有的线段都是相称的，这意味着它们的比率可以用有理数来表达，也就是说，他的相似性理论是基于异律数的算术。

发现不可通约性。现在让我们转向毕达哥拉斯最伟大的发现，它为他带来了不朽的声誉，并带来了数学的胜利。我们谈论的是不可通约片段的发现，或者换句话说，非理性的发现。

但它是什么？给定一个边长为 1 的正方形。然后，根据毕达哥拉斯定理，其对角线的平方等于
$$c^2 = 1^2 + 1^2 = 2.$$
对角线 $c$ 等于多少？让我们尝试通过对 2 求根来找出答案。

如果你申请这个工作，你会先得到$c_1 = 1$，然​​后$c_2 = 1,4$，然后$c_3 = 1,41$，等等。最后，你必须达到第10位数字，你会厌倦这个活动。你会说：“够了！这个系列永远不会结束。”但我们会反对你：“继续！如果以第11位或第20位结尾怎么办？”唉，我们又“落入了无限的魔爪”！

但这也是毕达哥拉斯的出口。他这样推理：让$c$表示为有理分数$p/q$。我们假设 $p$ 和 $q$ 不能都是偶数（否则我们会将分数抵消 2）。通过对等式 $\sqrt{2} = p/q$ 进行平方，我们得到 $2p^2/q^2$ 或
$$p^2 = 2q^2$$
(1)

这意味着$p^2$可以被2整除。因此，毕达哥拉斯根据偶数和奇数的主要定理，得出$p$是偶数的结论。这意味着 $q$ 是奇数（否则我们会将分数 $p/q$ 减少 2）。所以，$p = 2p_1$。代入等式(1)，得到$q^2 = 2p_1^2$，即$q^2$能被2整除，再除以前一个$q = 2q_1$，即$q$是偶数。我们遇到了矛盾，因为数字$q$必须既是偶数又是奇数，这是不可能的。

这一不可估量的发现深深震撼了所有希腊人。这是一个似乎与不断变化的实践相矛盾的理论建议！毕竟，在实践中，所有的量都是可比的：我们将它们精确到厘米、毫米、微米，但结果总是得到有理数。不可通约性的发现可以与哥白尼的发现相比较，哥白尼的发现也与我们日常观察到的日出和日落相矛盾，或者与罗巴切夫斯基几何的发现相比较。据传说，毕氏学派对这一发现保密，显然是想在他们的“数学”中为其找到一个有价值的位置，而泄露这个秘密的毕氏学派海帕斯因此受到了富人的惩罚：他精疲力尽，遭遇了海难。著名的古代哲学家柏拉图（公元前5世纪末至4世纪初）写道，他很晚才了解到不可通约性，在此之前他就像一只不讲道理的动物。另一位伟大的哲学家、柏拉图的学生 ρισstele 在讨论科学如何兴起时写道：“每个人都从惊讶开始（……），无论他们是否感到惊讶，例如，神秘的自走式玩具、至日或对角线的不可通约性，或者对每个尚未理解其原因的人来说，如果某些东西无法用最小的尺寸来测量，那似乎是令人惊讶的”（《形而上学》，第 1 册，第 2 章）。

毕达哥拉斯的学生和追随者很快发现，除了$\sqrt{2}$之外，还有一整套无理数：$\sqrt{3}, \sqrt{5}, \sqrt{6}, ..., \sqrt{15}$，或者正如他们所说，面积为3、5、6、...、15的正方形的边与单位正方形的边是不可通约的。在柏拉图的对话录《泰阿特图斯》中，据说昔兰尼的毕索哥拉斯派狄奥多给雅典青年做了一次演讲，并给出了$\sqrt{17}$的相应证明。

让我们使用毕达哥拉斯方法：让我们需要证明无理数$\sqrt{d}$，其中$d$是一个非平方整数。如果$d$是偶数，则最后进行证明，方法与$\sqrt{2}$相同。令$d$为奇数，并假设$\sqrt{d} = p/q$；然后
$$p^2 = dq^2.$$
(2)

可以证明，在这种情况下，$p$和$q$将是奇数，即它们将具有$2n+1$的形式，那么它们的平方将具有$4(n^2+n)+1$或$\frac{n(n+1)}{2} + 1$的形式，其中$\frac{n(n+1)}{2}$是整数。将这些值代入公式（2）并对项进行分组，我们得到
$$8\left(\frac{n(n+1)}{2} - d\frac{m(m+1)}{2}\right) = d-1.$$
等式的左边可以被8整除，这意味着权利必须具有$8k$的形式，即它们必须是$d=8k+1$。如果数字 $d$ 的形式与 5、7、11、13、15 等不同，则会导致矛盾，从而反驳了所做的假设。如果$d$具有$8k+1$的形式，那么这种证明方法就不起作用。所以数字 9 就是，但它是一个完全平方数，并且是 17。事实上，这就是费多尔选择这个数字的原因。

费奥多尔的仆人中有年轻才华横溢的数学家泰阿特图斯。

他们认为自然规律可以用数字来表达，“一切都是数字”。正如亚里士多德所写，整个宇宙“被认为是和谐与数字”。

和谐。毕达哥拉斯将构建世界数值模型的可能性的想法作为他的音乐理论的基础。毕达哥拉斯发现，弦乐声音的质的差异是由纯粹的量的差异（即弦的长度）引起的。如果两个号角的长度比例为 1:2、2:3、3:4（对应于一个八度或音程的音程），则同时发出的声音将听起来悦耳。德国最伟大的物理学家索末菲在评价毕达哥拉斯的发现时写道，它的发现之日堪称数学物理学的生日。事实上，谐波振荡系统在物理学中发挥了巨大的作用。本世纪20年代，某种粒子的音调所发出的振荡系统与某种粒子的原子发出的辐射之间的类比，也是由整数之比决定的，后者是创立量子力学的关键。爱因斯坦注意到了这一事实：

“因此，”他写道，“我们在振动的弦和原子之间发现了一些类似的东西，从元素中发射粒子：构成原子核的重粒子，以及电子的轻粒子。这样的粒子系统的行为就像一个产生驻波的小型声学仪器”（A. Einstein，L. Infeld。进化物理学。M.：Nauka，1963，第224页）。

天文学。毕达哥拉斯认为地球是球形的，并且它位于宇宙的中心。在它周围有八个同心球体——这些是月球、太阳、行星和恒星的球体。外层球体——恒星的球体——每天绕世界轴旋转一整圈，其运动量比其他七个球体都增加。然而，月球和太阳的运动与球体昼夜膨胀的方向相反。随后，毕达哥拉斯学派得出结论，地球并不是静止不动的，而是与其他行星一起绕着中心火旋转。这个想法比哥白尼提出地球在太阳系中不占据中心位置的想法早了 2000 多年。

值得注意的是，毕达哥拉斯立即尝试从音乐理论中创造天文观点。他相信，每颗行星在其轨道上运动时都会发出声音，而当所有七颗行星运动时，就会发出“球体音乐”的声音。毕达哥拉斯甚至将太阳系称为七弦竖琴。他保证他能听到这种美妙的音乐，人们只有在死后才能听到。

我们已经说过，毕达哥拉斯的意想不到的想法在本世纪获得了新的生命，但已经应用于原子世界。我们已经提到过的索末菲写道：

“今天我们用光谱语言所理解的是原子领域的真正音乐、整数关系的和谐、不断增长的秩序以及与其多样性的和谐。

...谱线和原子论的所有整数定律最终都遵循量子理论。它代表了一种充满微妙的乐器，大自然在其上使用光谱音乐和控制原子和原子核结构的 irite”（A. Sommerfeld. Putti 物理学知识。M.，Nauka，1973 年，第 255 页）。

他们说，科学与艺术的不同之处在于，艺术的创造是永恒的，而科学的伟大创造却无可救药地消逝。幸运的是，事实并非如此，毕达哥拉斯的著作就是最好的例子。他不仅是最伟大的，而且也是最常见的天才，因为他的思想和理论从未离开舞台，直到那时仍然继续激发人们的思想。他的科学思想没有消失。随着科学的每一个新阶段，它们都会改变自己的面貌，以便再次激发科学家的思想和心灵。
