你有没有想过这个问题的答案？乍一看，似乎通过压实沙子，我们总是使其变得更密，使沙子变暗并将它们彼此压得更近。但事实上，问题可能在于环境本身。证明这一点的证据是，当您踩在海边或河流附近的湿沙上时，有时会留下痕迹。以其流体动力学研究而闻名的科学家 O. 雷诺兹 (O. Reynolds) 在 1885 年英国协会的一次会议上的一份报告中谈到了这一点：“当霍拉压在沙子上时，在温和的潮汐后，沙子变得密实，脚部周围的区域立即变得干燥……脚部的压力使沙子松动，压力越强，留下的水就越多……它使沙子干燥，直到蓝色到达足够量的水为止。”

球的密集堆积

是否有可能用实心球填满整个空间？当然不是——它们之间总是有空闲空间。球所占据的空间分数称为它们的堆积密度。球的位置越近，它们之间的自由空间越小，堆积密度越大。相同硬球的堆积密度何时达到最大？这个问题的答案提供了解开沙中脚印“谜团”的关键。

让我们首先研究一个更简单的情况——在平面上排列相同的圆。可以通过将圆拟合到由填充整个平面的正多边形组成的马赛克中来实现圆的密集堆积。构造这种马赛克的方法只有三种——正三角形、正方形和正六边形。使用方形和六角形微粒的堆积圆如图1所示。此外，“通过肉眼”您可以看到第二种方法更经济。准确的计算（请自行检查）表明，在这种情况下，大约 90.7% 的平面被圆圈填充，而在第一种情况下，只有大约 78%。平面上堆积的六边形方法是最密集的。显然，正因为如此，蜜蜂在建造蜂窝时会使用它。

球在空间中的密集堆积可以如下完成。让我们以我们已知的最密集的方式将第一层球放置在平面上。然后你可以在上面再铺上第二层。如果顶层的每个球都位于底部的正上方，使得所有球都内接在立方体蜂窝中，则浪费了太多空间。采用这种封装方式，只填充了52%的空间。

很明显如何才能将球包装得更紧密。为此，必须将上球放入由相邻下球的托盘形成的孔中。但与此同时，上面的球将无法填充所有孔 - 两个相邻凹槽之一始终是空闲的 (图 2)。因此，当我们放置第三层球时，可以通过两种方式完成：要么将第三层球放置在第一层中第二层球留下的那些凹槽上方（图2上的一个球的中心将在A点），要么放置在第一层球的正上方（在这种情况下，第三层的一个球的中心将在B点）。它被保存以供后续层使用。由此，我们得到了两种排列球的方式，如图3中的空间所示。一般情况下，大约74%的空间被球填充。

很容易计算出，采用这种封装方法，每个球都与12个相邻的球接触。接触点形成 14 面体的顶点。它的面是交替的正方形和等边三角形。因此，第二种密堆积方法产生了 图 4 所示的开普勒立方八面体。

到目前为止，我们只考虑了将球装入周期性“蜂窝”的这种包装方法。如果没有这个条件，是否可以实现密堆积？其中一种方法如图5所示。每个平面内的球位于正五边形（五边形）的边上。在每个五边形中，相邻的球彼此接触，但相对于同一平面的不同五边形，这些球在空间上是分开的。交替层的五边形的边交替包含四个和奇数个球。这种结构的空间填充率为72%，仅略逊于图2所示的密集堆积情况。可以在不从中心形成更密集的晶格的情况下堆积球，达到74%的填充系数，但是否存在更密集的堆积——这个问题至今仍然悬而未决。

让我们回到下一个沙子。我们现在知道有一种特殊的球包装，它们之间几乎没有留下任何空隙。如果违反这种安排，例如将一层的球从另一层的孔中移出，则球之间的间隙将会增加。然而，很明显，沙粒从来没有以特殊的方式包装。如何实现砂粒的密堆积？

让我们记住每天的经历。您需要粗略地填充容器，以使其包含最大量。你对此做了什么？使用容器或穿过容器，添加所需的效果。然后，将克鲁拉紧紧地装入容器中后，您可以使用此技术来减少一些额外的量。

英国科学家 G. Scott 在 20 世纪 50 年代对这个问题进行了科学研究。他用滚珠轴承填充了不同尺寸的球形瓶。如果在不摇动的情况下填充瓶子以使球随机排列，则通过实验观察到堆积密度与球数量的以下依赖性：

$$\varrho_1 = 0,6 - 0,37 / \sqrt[3]{N},$$

其中$N$是球的总数。如果球的数量非常大（在实验$N$中达到数千个），那么很明显，堆积密度趋于恒定，相当于填充了 60% 的空间。但如果在装满瓶子时摇动瓶子，堆积密度就会增加：

$$\varrho_2 = 0,64 - 0,33 / \sqrt[3]{N}.$$

确实，即使在这种情况下，结果也远低于 74%，与球的规则排列相对应。

值得考虑这里给出的依赖关系。为什么修正量与$\sqrt[3]{N}$成反比？与体积中的球相比，位于容器壁附近的球处于特殊位置，并且影响堆积密度。它们贡献的大小与表面积$\sim R^2$与容器体积$\sim R^3$的比率成正比，并且与系统的尺寸$R$成反比（在系统体积下，我们喝掉了球所占据的全部空间以及自由空间）。尺寸$R \sim \sqrt[3]{N}$，因为系统的体积与球的总数成正比。当需要考虑有效表面时，这种依赖性在物理学中经常出现。

因此，精确的实验证实了日常经验，并表明通过摇动颗粒介质，可以获得更大的堆积密度。但为什么还是会出现这样的情况呢？事实上，稳定的平衡位置总是对应于最小的势能。球可能会稳定地躺在空心处，但它肯定会从滑梯的顶部弹起。这里也发生了类似的事情。摇动时，球滚入自由空间，堆积密度增加，系统总体积减小。结果，容器中球的填充水平降低，因此重心降低并且系统的势能降低。

现在，我们终于可以足够清晰地想象沙子发生了什么。水的搅拌与沙子相遇，从而实现沙子的致密堆积。通过用脚挤压蛋糕，我们打破了这种包装并增加了毛孔的尺寸。来自上层沙子的水进入深处，填充这些扩大的间隙。结果，音高“消失”。当脚被移开时，畸形消失，紧密的包裹恢复，水从新缩小的空间中流出，填充脚留下的痕迹。它也可以以这样的方式使用，即在强压力后音调不会恢复。只有当水从下层上升并充满毛孔时，步道才会再次变湿。

奇怪的是，这是印度法克拉中发现的颗粒介质的特性。他们的三重奏之一是反复将一把窄刀插入一个狭窄颈部的容器中，容器的顶部装满了米饭。有时，刀会卡在米里，用刀就能把器皿举起来。很明显，诀窍在于，当容器装满大米时，它们会相遇，形成紧密的包装。用刀插进去会破坏这种包装并增加米粒之间的空间。由于容器的体积没有变化，挤压米粒的力增加，因此米粒与刀之间的张力增加。在某些时候，它足以将刀从容器中拔出。

然而，还有一类同样重要的物质——无长程有序的无定形体。液态体处于无定形状态。但固体也可以是无定形的。最简单的例子是普通玻璃。 图10显示了玻璃和石英的结构，石英的化学成分与玻璃相同。石英是晶体，玻璃是非晶态物体。虽然玻璃中的秩序并不比这低，但这并不意味着原子的排列完全混乱。从图可以看出，玻璃中也保留了近邻排列中的某种结构。他们说无定形物体具有紧密的有序性。

总功率
当改变两个或多个多项式时，字母的组合 - 字母组合词 - 自然会出现；而当翻译相似的术语时，组合子 - 字母组合词的系数 - 自然会出现。

两个数之和的平方公式是众所周知的：
$(a+b)^2 = a^2 + 2ab + b^2$.

对于三项或多项之和的平方，可以获得类似的公式。例如，我们计算总和 $a+b+c$ 的平方：
$(a+b+c)(a+b+c) = aa + ab + ac + ba + bb + bc + ca + cb + cc = a^2 + b^2 + c^2 + 2ab + 2bc + 2ac$.

类似的公式也适用于 $(a+b+c)^2$（在 图 3 上每年表示其矩形的面积）；一般来说，$n$数之和的平方计算如下：您需要将这些$n$数的所有平方相加，并将这些数的所有可能的成对乘积的双倍和相加。

如果我们仔细改变 $a+b+c$ 折叠到自身时的可变性，我们还会得到公式：
$(a+b+c)^3 = a^3 + b^3 + c^3 + 3(a^2b + a^2c + b^2a + b^2c + c^2a + c^2b) + 6abc$.

让我们解释一下如何在这里获得系数 1、3 和 6，而无需繁琐的乘法和类似项的匹配。这是我们已经熟悉的英语单词的数量。项 $a^3$ 只能通过一种方式获得 - 当从每个括号中获得时
$(a+b+c)(a+b+c)(a+b+c)$取自字母$a$。要获得$a^2b$的系数，您需要从一个括号中取出$b$，并从另外两个括号中取出$a$，即该项对应于两个字母$a$和一个字母$b$的字母顺序$aab, aba, baa$：它们的数量是$(2+1)!(2!1!) = 3$。最后，$abc$的系数等于由三个不同字母$a, b, c$组成的单词的字母组合词（排列）的数量$3!/(1!1!1!) = 6$。

对于更多项之和的立方，将获得类似的公式，例如
$(a+b+c+d+e)^3 = (a^3+...) + 3(a^2b+...) + 6(abc+...)$.

在这里，让我们锐化每个括号来表示从第一个书面术语通过各种字母替换获得的术语。
