**M942.** 数字 1, 2, ..., 2n−1, 2n 被分为两组，每组 n 个数字。设$a_1 < a_2 < ... < a_n$为第一组的编号，按升序排列，$b_1 > b_2 > ... > b_n$为第二组的编号，按降序排列。证明$|a_1 - b_1| + |a_2 + b_2| + ... + |a_n - b_n| = n^2$。

请注意，$a_k$和$b_k$这两个数字，其中一个始终小于$n$，另一个始终小于$n$。事实上，例如，如果$a_k \leq n$和$b_k \leq n$，那么所有数字$a_1, a_2, ..., a_k$和$b_k, b_{k+1}, ..., b_n$都不会超过$n$。我们总共得到 $k + (n - k + 1) = n + 1$ 个不超过 $n$ 的不同自然数，这是不可能的。同理，证明了$a_k$和$b_k$都不能大于$n$。

因此，我们的总和中的每一项 $|a_k - b_k|$ 都等于大于 $n$ 的数与不超过 $n$ 的数之间的差。扩展模型并重新排列术语，我们得到

$$|a_1 - b_1| + |a_2 - b_2| + ... + |a_n - b_n| = (n + 1) + (n + 2) + ... + (n + n) - (1 + 2 + ... + n) = n^2.$$

V.V.普罗兹沃尔夫

**M943.** 序列 $a_1, a_2, ...$ 由以下规则给出：$a_{2n} = a_n$ 对应 $n \geqslant 1$，$a_{4n+3} = 0$ 对应 $n \geqslant 0$。证明这个数列没有周期。

我们将通过反证法来进行证明。令序列的周期为$T = 2^p \cdot q$，其中$q$为奇数。如果$q = 4m + 3$，则$k \geqslant p + 2$

$$a_{2k} = a_{2k+T} = a_{2p(2^k - p + q)} = a_{2p-1(2^k - p + q)} = ...$$

$$... = a_{2k-p+4m+3} = a_{4(2^k - p - 2 + m)+3} = 0.$$

但同时

$$a_{2k} = a_{2k-1} = ... = a_1 = 1.$$

矛盾。

如果$q = 4m + 1$，那么在上述推理中，数字$T$必须替换为数字$3T = 2^p (4 \cdot 3m + 3)$，这也必须是我们序列的周期。
