相似项的求幂和约简，即单词 kkkzz 的字谜词的概率之和。

有趣的是，“2红3黄”和“2红2黄1绿”的概率相同

$$\frac{5!}{2!3!} \left( \frac{1}{2} \right)^3 \left( \frac{1}{3} \right)^2 = \frac{5!}{2!2!1!} \left( \frac{1}{2} \right)^2 \left( \frac{1}{3} \right)^2 \left( \frac{1}{6} \right) = \frac{5}{36}.$$

（按照我们选择的概率，这些是 5 种辣椒最可能的组合。）

生物矿物质系数

上面，我们几乎没有触及两个字母的简单且最重要的情况。多项式 (a+b)^n 的系数有一个特殊的名称 C^k_n，公式 (a+b)^n = C^0_n a^n + C^1_n a^{n-1} b + ... + C^n_n b^n

称为牛顿生物群落公式。我们知道 C^k_n - n 个字母的单词数，包括 k 个字母和 n-k 个字母 a - 可以使用以下公式找到

$$C^k_n = \frac{n!}{(n-k)! k!} = \frac{n(n-1)...(n-k+1)}{k!}.$$

例如，

$$(a+b)^4 = a^4 + 4a^3 b + 6a^2 b^2 + 4ab^3 + b^4,$$

因为

$$C^0_4 = C^4_4 = \frac{4!}{4!0!} = 1,$$

$$C^1_4 = C^4_3 = \frac{4!}{3!1!} = 4,$$

$$C^2_4 = \frac{4!}{2!2!} = 6.$$

生物系数 - 数字 C^k_n - 出现在生物力学、代数、几何、数学分析和概率论的各种问题中。它们通过多项式红色恒等式连接；例如，根据等式 C^k_n + C^k_{n-1} = C^k_{n+1}（参见问题 5），可以得出对于所有自然 n 和 k，0≤k<n，

$$C^k_n + C^k_{n+1} + ... + C^k_n = C^k_{n+1}.$$

（对于 k=1，这是我们开始本文的公式）。这些引人注目的数字将在该杂志的下一期中进行更详细的讨论。
