可以选择初始数据$a_1, \dots, a_n$，b，以便将算法A应用于它们将需要至少$\log_2(n+1)$比较。

证明。作为 $a_1, \dots, a_n$，我们取任何满足 $a_1 < \dots < a_n$ 的整数，作为 b，我们将交替比较 $a_1, \dots, a_n, a_{n+1}$。将 $A_1$ 与初始数据的这个变体一起使用应该会匹配数字 1, ..., $n+1$。将 $A_1$ 应用于这些选项中的任何一个所进行的比较结果可以写成“是”和“否”单词的序列。为了研究$a_1, \dots, a_n$和不同b的值，仅使用形式（1）的比较。因此，如果将 $A_1$ 应用于初始数据 $a_1, \dots, a_n$ b 正好需要 k 次比较，并且将 $A_1$ 应用于其他初始数据 $a_1, \dots, a_n, b'$ 过程中的前 k 次比较应产生相同的结果，则进一步将 $A_1$ 应用于 $a_1, \dots, a_n, b'$ 将不再需要比较，这将与初始数据相同$a_1, \dots, a_n, b$。因此，所得序列“是”和“否”的平均值并不重合，并且两者都不是另一个的开始。令$l$为这些序列中最长的序列中的元素数量，即$n+1$，并且不超过长度为l的所有序列的数量，即$2^l$。所以，$n+1 \leq 2^l$和$l \geq \log_2(n+1)$。由于$l$是整数，因此$l \geq \log_2(n+1)$。

两个已证明定理的比较表明，对于任何初始数据，没有一种算法可以比 $A_1$ 算法需要更少的比较来查找元素的位置。从这个意义上来说，$A_1$是一个最优（猜测）算法。

问题2. 设$a_1 < \dots < a_n$ 和平均数$a_1, \dots, a_n$ 为等于b 的数。我们需要找到$a_t = b$的t。给出一个算法来解决需要$\log_2 n$比较的问题。证明该算法是最优的。

问题 3. 考虑两种选择不等数中最小的算法。第一种算法：找到前两个数字中较小的一个，将其与第三个进行比较，再次取较小的一个，与第四个进行比较，依此类推。第二个算法（“杯赛”或“奥林匹克”系统）：将数字分成对，将每对中的较小者跳过到下一轮。如果一个数字没有配对，那么这个数字也跳到下一轮。在下一个类型中，重复相同的操作，依此类推，直到剩下一个数字。以下哪种算法需要较少的比较？

问题 4. 证明不存在需要更少 (n-1) 次比较的算法来选择 n 个不等数中最小的一个。 （理论2证明中使用的技术仅允许我们证明最坏情况下的比较数不小于$\log_2 n$。）*

现在让我们继续讨论排序问题，即将可能不相等的数字排列成一行

$a_1, \dots, a_n$。这个答案很重要，特别是对于解决与信息检索相关的计算机问题（我们已经看到有序性确保了快速搜索）。

算法$A_2$：依次对给定集合的初始数字组进行排序：$a_1; a_1, a_2; a_1, a_2, a_3; \dots; a_1, \dots, a_n$ - 最后一组与整个集合重合；要从 i 个数字的有序组移动到第 (i+1) 个数字的有序组，您需要将 $a_{i+1}$ 放置在现有 i 个数字的有序组中的位置 - 该位置是使用 $A_1$ 算法确定的。

让我们用$B(n)$表示$A_2$所需的比较数。我们有$B(n) = \log_2 2^l + \dots + \log_2 n \leqslant \log_2 2^l + \dots + \log_2 n + (n-2) = (2) = \log_2 n! + (n-2) \leqslant n(\log_2 n + 1) - 2$。

问题5.确定以下排序算法$a_1, \dots, a_n$所需的比较数，找到最小的数放在第一位，然后找到最小的平均余数放在第二位，依此类推（见问题3、4）。

问题6. 假设无序集合$a_1, \dots, a_n$可以包含相等的数。证明在这种情况下，算法 $A_2$ 确保给定的数字按非递减顺序排列。

理论 2 证明中使用的技术使我们能够确定，对于任何排序算法，都可以选择一个集合 $a_1, \dots, a_n$，该算法的应用将需要至少 $\log_2 n!$ 比较（这样的集合将是 n 个任意数字的 $n! = 1 \cdot 2 \cdot \dots \cdot n$ 排列之一）。与(2)一起表明，在任何情况下，$A_2$离最佳比较数都不远（问题5的算法不能这么说）：例如，$\lim_{n \to \infty} (B(n) / \log_2 n!) = 1$。许多作者都尝试证明 $A_2$ 的最优性，甚至以印刷形式报道了所谓的发现证据。后来我们发现$A_2$不是最优的：该算法要求所有比较都对五个数字进行排序，但实际上七次比较就足够了。这不是一个简单的事实，尽管它可以表述为一个权衡问题。

问题 7*。一切都没有权重，也没有五个不同的组。可以将一组放置在两个数字的秤上。使用七个权重按重量降序排列各组。
