总功率
当改变两个或多个多项式时，字母的组合 - 字母组合词 - 自然会出现；而当翻译相似的术语时，组合子 - 字母组合词的系数 - 自然会出现。

两个数之和的平方公式是众所周知的：
$(a+b)^2 = a^2 + 2ab + b^2$.

对于三项或多项之和的平方，可以获得类似的公式。例如，我们计算总和 $a+b+c$ 的平方：
$(a+b+c)(a+b+c) = aa + ab + ac + ba + bb + bc + ca + cb + cc = a^2 + b^2 + c^2 + 2ab + 2bc + 2ac$.

类似的公式也适用于 $(a+b+c)^2$（在 图 3 上每年表示其矩形的面积）；一般来说，$n$数之和的平方计算如下：您需要将这些$n$数的所有平方相加，并将这些数的所有可能的成对乘积的双倍和相加。

如果我们仔细改变 $a+b+c$ 折叠到自身时的可变性，我们还会得到公式：
$(a+b+c)^3 = a^3 + b^3 + c^3 + 3(a^2b + a^2c + b^2a + b^2c + c^2a + c^2b) + 6abc$.

让我们解释一下如何在这里获得系数 1、3 和 6，而无需繁琐的乘法和类似项的匹配。这是我们已经熟悉的英语单词的数量。项 $a^3$ 只能通过一种方式获得 - 当从每个括号中获得时
$(a+b+c)(a+b+c)(a+b+c)$取自字母$a$。要获得$a^2b$的系数，您需要从一个括号中取出$b$，并从另外两个括号中取出$a$，即该项对应于两个字母$a$和一个字母$b$的字母顺序$aab, aba, baa$：它们的数量是$(2+1)!(2!1!) = 3$。最后，$abc$的系数等于由三个不同字母$a, b, c$组成的单词的字母组合词（排列）的数量$3!/(1!1!1!) = 6$。

对于更多项之和的立方，将获得类似的公式，例如
$(a+b+c+d+e)^3 = (a^3+...) + 3(a^2b+...) + 6(abc+...)$.

在这里，让我们锐化每个括号来表示从第一个书面术语通过各种字母替换获得的术语。
