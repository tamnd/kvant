...，$f_n(\dot{x}) = f(f_{n-1}(x))$；类似地，我们为$m \geqslant 1$定义$f_{-1}(x) = g(x)$，...，$f_{-m-1}(x) = f_{-1}(f_{-m}(x))$。
将$f_{n-1}(x)$代替$x$代入任意整数$n$的条件中，我们得到等式
$$f_{n+1}(x) = f_n(x) + f_{n-1}(x).$$
这个公式允许我们用$x = f_0(x)$和$y = f(x) = f_1(x)$来表达任何$n$的$f_n(x)$；如页边所示，
$$f_n(x) = a_n y + a_{n-1} x,$$
其中序列$a_n$由对应关系$a_{n+1} = a_n + a_{n-1}$和所有目标$n$的“初始条件”$a_0 = 0$、$a_1 = 1$给出（我们现在再次绕过$n < 0$的定义域$f_n$的问题）。序列$a_n$是众所周知的：对于$n \geqslant 1$来说，这些是重要的斐波那契数*）；我们只要知道$|a_n|$在$n \rightarrow \pm \infty$无限制地增加就足够了（对于$n > 0$这是显而易见的；对于$n < 0$只需注意$a_n = (-1)^{n+1} a_{-n}$和$|a_{-n}| = |a_n|$就足够了）。

通过上面性质 3 的推导，可能有两种情况：所有 $x$ 的符号 $f(x)$ 与符号 - $x$ 重合，或者 - 与符号 $x$ 重合。

在第一种情况下，$f_n(x)$和$f_{n-1}(x)$对于任何$x \neq 0$具有不同的符号，因此对于$n \geqslant 2$
$$|f_{n+1}(x)| = |f_n(x) + f_{n-1}(x)| \leqslant
\leqslant |f_n(x)| \leqslant \dots \leqslant |f_2(x)| = |f(x) + x| \leqslant |x|.$$
因此，$|y + (a_{n-1}/a_n)x| \leqslant |x/a_n|$。由于这个不等式的右边趋向于零，即$n \rightarrow \infty$，因此序列$a_{n-1}/a_n$必须有一些极限$\mu$（等于$y/x$）；同时$y = -\mu x$。

在第二种情况下，所有$n$的$f_n(x)$具有相同的符号（符号$x$）。由于 $f$ 是连续函数且 $|f(f(x))| = |f(x) + x| \geqslant |x|$，$f$ 的域或反函数 $f_{-1}$ 的域都是实数，并且我们的 $f_n$ 公式已定义并且对所有 $x$ 和所有目标 $n$ 均有效。现在对于任意 $n < 0$ 我们有
$$|f_n(x)| = |f_{n+1}(x) - f_{n-1}(x)| \leqslant |f_{n+1}(x)| \leqslant \dots
\leqslant |f_{-1}(x)| \leqslant |x|,$$
因此$|y + (a_{n-1}/a_n)x| \leqslant |x/a_n|$。在这里传递给$n \rightarrow -\infty$的介词，就像第一种情况一样，我们得到$y = \mu_1 x$和$\mu_1 = -\lim_{n \rightarrow -\infty} (a_{n-1}/a_n)$。

注意$\mu_1 = \lim_{n \rightarrow \infty} (a_{n+1}/a_n) = \mu^{-1}$；从a)点如下，
$$\mu = (\sqrt{5} - 1)/2, \mu^{-1} = (\sqrt{5} + 1)/2.$$

这些数字也参与了比奈斐波那契数列的一般公式，如页边空白中所示。
