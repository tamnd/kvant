定义。数字或多项式的最大公约数是可以被任何公约数整除而没有余数的公约数。

我们将数字或多项式$a, b$的gcd表示如下：gcd$(a, b)$。例如，GCD$(5, 10) = 5$； GCD $(x^2, 3x-x^2) = x$； GCD $(x^3-x^2,x-1) = x-1$。

日语最大公约数

对于数字，有两种已知的求 GCD 的方法。

方法 1. 我们将两个数字分解为质因数，然后将两个数字中出现的质因数相乘。例如，约简分数$\frac{3770}{9425}$，可以写：$\frac{3770}{9425} = \frac{2\cdot 5\cdot 13\cdot 29}{5\cdot 5\cdot 13\cdot 29}$；

GCD $(3770, 9425) = 5\cdot 13\cdot 29 = 1885$，$\frac{3770}{9425} = \frac{2}{5}$

这个方法有什么问题吗？首先，你必须首先证明任何自然数都可以因式分解为质因数，而且是以一种独特的方式。其次，为了找到这种分解，需要做很多工作，主要是在方向上。毕竟，我们会找到每个数字的所有约数，但我们只需要它们的最大公约数。

正如我们稍后将看到的，用多项式绕过问题会更糟糕：展开式总是存在，但一般来说，不可能找到它，除非有人专门安排它以便展开式很容易找到（正如在特定示例中发生的那样）。

但您不必将数字分解为多项式。

方法2.欧几里得算法。它基于以下引理。

引理1.任何自然数$q$都可以除以另一个自然数$p$的余数，即将$q$表示为$q = kp+p_1$，其中$0 \leq p_1 < p$。

引理2.如果数字$d$是数字$p$和$q$的GCD。

请注意，这个引理不仅使我们能够找到，而且还能够证明两个数字的 GCD 的存在，因为它将有关 GCD 的存在和位置的问题减少到更小的数字。

自己证明这些引理。在引理1中，我们需要通过点$0, p, 2p, 3p, \dots$将数轴分成几段，并找到其中包含点$q$的部分。在引理2中，我们必须假设数字$d$可以被数字$p$和$p_1$的任何公约数整除，并且两个数字$p, p_1$都可以被$d$整除，并证明数字$d$相对于数字$p$具有相同的两个属性$q$。

现在，使用方法 1 中讨论的示例，我们将概述欧几里得算法本身 - 一系列操作，可让您找到数字 $q$ 和 $p$ 的 gcd。接下来，我们以一般形式编写公式序列，并在右侧 - 例如。

步骤 1. 使用引理 1，将 $q$ 除以 $p$。比方说：
$q = k_0p+p_1, 0 \leq p_1 < p$; $9425 = 2\cdot 3770+1885, 0 \leq 1885 < 3770$.
根据引理 2，我们得出结论：
GCD $(q, p) = \text{НОД}(p, p_1)$； $\text{НОД}(9425, 3770) = \text{НОД}(3770, 1885)$。

步骤 2. 看看 $p_1$ 是否等于 0。
如果$p_1$等于0，则结束该过程并转到步骤3。

在引理1中，数字$p_1$的大小小于$p$，对于多项式，“大小”被视为多项式的次数。下面给出了多项式除以余数的一个例子，你自己用它来证明这个引理。

例子。使用角点将多项式 $2x^5 + 4x^4 - 2x^3 - x + 1$ 除以多项式 $x^2 + 2x + 5$。事实证明：

$$\frac{-2x^5 + 4x^4 - 2x^3 - x + 1}{2x^5 + 4x^4 + 10x^3} = \frac{x^2 + 2x + 5}{2x^3 - 12x + 24}$$

$2x^5 + 4x^1 - 2x^3 - x + 1 = (2x^3 - 12x + 24)(x^2 + 2x + 5) + (11x - 119)$。现在我们有了所需的引理，我们可以根据欧几里得算法进行操作，即构造一个带有余数的除法序列（对于多项式！），其中多项式依次递减：

$$Q(x) = K_0(x) P(x) + P_1(x),$$
$$P(x) = K_1(x) P_1(x) + P_2(x),$$
$$P_1(x) = K_2(x) P_2(x) + P_3(x),$$

$$P_{m-2}(x) = K_{m-1}(x) P_{m-1}(x) + P_m(x),$$
$$P_{m-1}(x) = K_m(x) P_m(x).$$

在这种情况下，GCD$(Q(x), P(x)) = \text{НОД}(P(x), P_1(x)) = \dots = \text{НОД}(P_{m-1}(x), P_m(x)) = \text{НОД}(P_m(x), 0) = P_m(x)$。最后一个商 $P_m(x)$ 是原始多项式的 gcd（检查所有这些）。

这些实用公式是通过除以角点而获得的，在第一个示例中如下所示：

$$\frac{x^9 - x^8 - x^7 - 3x^6 + x^5 + 4x^4 + 4x^3 + x^2 - 2x - 1}{x^9 - x^8 - 3x^6 + x^5 + x^4 + 2x^3 - x} = \frac{x^8 - x^7 - 3x^5 + x^4 + x^3 + 2x^2 - 1}{x^8 - x^7 - 3x^5 + x^4 + x^3 + 2x^2 - x - 1}$$

现在剩下的就是将代数分数（2）除以最后一个除数$-x^7 + 3x^4 + 2x^3 + x^2 - x - 1$，即将（2）中的分子和分母除以得​​到的gcd。完成所有这些后，我们得到$\frac{x - 1}{x^2 - x - 1}$。

这就是答案。

如果您读过 N.M. Beskin 的文章“连续分数”（«Kvant» 第 8 期），您可能会注意到这里描述的过程正是通过展开为整数分数来减少多项式，其执行方式与有理数相同。我们将分数 $\frac{P(x)}{Q(x)}$ 重写如下：

$$\frac{P(x)}{Q(x)} = \frac{P(x)}{K_0(x) P(x) + P_1(x)} = \frac{1}{K_0(x) + \frac{P_1(x)}{P(x)}}$$,

等等。最后$\frac{P_m(x)}{P_{m-1}(x)} = \frac{1}{K_m(x)}$，剩下的就是将多项式的原始分数转出来。在所考虑的示例中，这样做是这样的：$\frac{1}{x + \frac{1}{-x+1}} = \frac{x-1}{x^2-x-1}$。
