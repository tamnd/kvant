M11。围成一圈的44棵树上，坐着44只欢快的黄雀（每棵树上有一只黄雀）。有时，两只黄雀会同时以相反的方向（一只顺时针，另一只逆时针）飞向邻近的树木。证明黄雀不会聚集在一棵树上。如果黄雀和树木$n$怎么办？

解决方案。我们立即解决了$n$黄雀和$n$树的问题。我们按顺序（例如，顺时针）对树进行排序，数字从 1 到 $n$ (图 1)。让我们用 $a_k$ 表示每个时刻第 $k$ 棵树上的黄雀数量（在第一棵树上 - $a_1$，在第二棵树上 - $a_2$，等等）。考虑表达式

$$S = 1 \cdot a_1 + 2 \cdot a_2 + \dots + ka_k + \dots + na_n.$$

让我们证明，当两只黄雀朝相反方向飞向邻近的树时，$S$要么不改变，要么改变为$n$。

事实上，让一只黄雀从第 $k$ 棵树按顺时针方向飞到下一棵树。然后在总和 $S$ 中，两项发生变化。如果$k < n$，则第$k$项和第$(k+1)$项发生变化，并且它们的总和变得相等

$$k (a_k - 1) + (k+1) (a_{k+1} + 1) = ka_k + (k+1) a_{k+1} + 1,$$

即增加 1。如果 $k=n$，则第 $n$ 项和第一项发生变化，并且它们的和

$$n (a_n - 1) + 1 (a_1 + 1) = na_n + 1 \cdot a_1 - (n-1)$$

减少$n-1$。相反，如果黄雀逆时针飞向邻近的树，则总和会减少 1 或增加 $n-1$。因此，当两只黄雀同时飞向邻近的树时（一只顺时针，另一只逆时针），则总和$S$要么根本不变，要么变为$n$。

最初的时候，每棵树上栖息着一只黄雀，

$$S = 1 \cdot 1 + 2 \cdot 1 + \dots + n \cdot 1 = 1 + 2 + \dots + n = \frac{n (n+1)}{2}.$$

因此，在任意次数的飞行之后，总和将等于$\frac{n(n+1)}{2} + np$，其中$p$是某个整数。如果所有黄雀都聚集在某一棵$q$树上，那么$S$将等于$nq$，也就是说，等式$\frac{n(n+1)}{2} + np = nq$成立，因此$n+1+2p = 2q$； $n = 2(q-p)-1$。

因此，如果$n$是偶数，例如$n = 44$，那么黄雀将无法聚集在同一棵树上。让我们证明对于奇数 $n$ 可以使用*）。

**M13。证明如果最大和最小$n$实数$a_1, a_2, \ldots, a_n$之差为$d$，并且这些数字的所有$\frac{n(n-1)}{2}$成对差值的模型之和

$$\sum_{i<j} |a_i - a_j| \text{ равна } s, \text{ то } (n-1) d \leqslant s \leqslant \frac{n^2}{4} d.$$

解决方案：让我们在数轴上绘制点 $a_1, a_2, \ldots, a_n$。那么$d$是这些点的最外层、最左边和最右边之间的距离，$s = \sum_{i<j} |a_i - a_j|$是这些数字之间所有成对距离的总和。

显然可以假设这些点按升序由 $a_1, a_2, \ldots, a_n$ 指定：$a_1 \leqslant a_2 \leqslant \ldots \leqslant a_n$ (图 5)。让我们用 $d_k(k=1, 2, \ldots, n-1)$ 表示相邻点 $a_k$ 和 $a_{k+1}$ 之间的距离。显然$d = d_1 + d_2 + \ldots + d_{n-1}$。

现在让我们用数量 $d_k$ 来表达 $s$。为此，我们将每个段 $[a_i - a_j]$ 的总 $s$ 长度替换为其组成的 $d_k$ 的总和：$|a_i - a_j| = d_i + d_{i+1} + \ldots + d_{j-1}$。显然，左端位于点$a_1, \ldots, a_k$之一、右端位于点$a_{k+1}, \ldots, a_n$之一的线段中包含$d_k$，即总计$d_k$包含在总和$k(n-k)$次中。这就是为什么

$$s = \sum_{k=1}^{n-1} k(n-k)d_k.$$

现在要证明的断言来自两个非常简单的不等式：对于所有 $k=1, \ldots, n-1$

1) $k(n-k) \geqslant n-1 \iff kn-k^2-n+1 \geqslant 0 \iff (k-1)(n-k-1) \geqslant 0$;
2) $k(n-k) \leqslant \frac{n^2}{4} \iff n^2-4nk+4k^2 \geqslant 0 \iff (n-2k)^2 \geqslant 0$.

让我们使用这些例子并使用我们得到的，我们得到的

$$\sum_{k=1}^{n-1} k(n-k)d_k \geqslant \sum_{k=1}^{n-1}(n-1)d_k = (n-1)d,$$

$$\sum_{k=1}^{n-1} k(n-k)d_k \leqslant \sum_{k=1}^{n-1}\frac{n^2}{4}d_k = \frac{n^2}{4}d.$$

该问题的正确答案由来自托木斯克的M. Praeger、来自基辅的十年级学生I. Protasov、来自维尔纽斯的S. Pozdnyakov 和其他读者发送。

了解问题陈述中指出的估计是否准确也很有趣；例如，是否可以将大数与 $n-1$ 放在左不等式中？为了证明相反的观点，只要举一个不平等变成平等（并且它的两个部分都包含正数）的例子就足够了。很容易想出这样一个例子，我们已经找到了证明：我们需要安排

管道在水平面上滑动的摩擦系数为$k$，碰撞时管道之间的摩擦力可以忽略不计，冲击是绝对弹性的。

解决方案。由于管道之间的摩擦力可以忽略不计，我们可以假设当管道碰撞时，其中一个管道的旋转不会传递到第二个管道。因此，在考虑管道碰撞时，我们不能考虑第一个（初始移动）管道的旋转。

让我们写下管道排列的能量和动量守恒定律：

$$mv_0 = mv_1 + mv_2, \frac{mv_0^2}{2} = \frac{mv_1^2}{2} + \frac{mv_2^2}{2}$$

（$v_1$和$v_2$分别为碰撞后对应第一、第二管道的平移速度）。

将这些方程一起求解，我们发现$v_1 = 0$和$v_2 = v_0$，也就是说，当管道撞击时，它们交换平移速度 - 就像两个相同的球撞击时一样。
