几何光学定律

光波的传播是一个相当复杂的过程。然而，如果光传播的介质的特性在大约等于光波长的距离内变化很小，那么相对简单的几何光学定律就被证明是有效的。总共有四个。

1. 在均匀介质中，光沿直线传播。

2. 反射定律。入射光束、反射光束与反射面的垂线位于同一平面，反射角β等于入射角α（图1）。

3. 折射定律。入射光束、折射光束和界面垂线位于同一平面，入射角 i 的正弦值与折射角 r 的正弦值之比 (图 2) 是一个常数，与入射角无关：

$$\frac{\sin i}{\sin r} = n.$$

n 值称为第二介质相对于第一介质的折射率。

农场原则

17 世纪中叶，伊利安科学家费马提出了所有几何光学定律的原理。如下：从一点到另一点的光总是沿着一条需要最少时间的路径传播*)。

让我们像大约 300 年前费马那样了解几何光学定律。

1. 光的直线传播定律。沿直线的距离是两点之间的最短距离。光在均匀介质中的速度在所有点上都是相同的。因此，光沿直线传播时所需的时间最少。

2. 反射定律。如何在最短的时间（图3）内从A点到达B点？当然是沿着AB线。光在均匀介质中传播。但如果先有费马严格原理，则可表述如下：光在需要最短时间或最长时间的路径中传播。然而，在大多数光情况下，更简单的公式是正确的。

必须从镜子反射然后才到达B点，不能立即清楚哪条路径对应最短时间。让我们画出几条可能的路径$AC_1B$、$AC_2B$和$AC_3B$。由于光在反射之前和之后都在均匀介质中传播，因此最短时间对应于最小长度的路径。

最短路径是什么？一个简单的技巧可以帮助找到它。让我们构造点 $A_1$ - A 点的图像。它位于垂线 $AC_0$ 的延长线上，从 A 点下降到镜子上，距镜子的距离为 $A_1C_0 = AC_0$。将点 C$_1$、C$_2$、C$_3$ 与点 A$_1$ 连接，很容易验证$AC_1 = A_1C_1$、$AC_2 = A_1C_2$、$AC_3 = A_1C_3$。因此，在计算从A点到B点的路径时，我们可以将线段$AC_1$替换为线段$A_1C_1$，将线段$AC_2$替换为线段$A_1C_2$，将线段$AC_3$替换为线段$A_1C_3$。很明显，最短路径是光束落在反射镜上的 C$_2$ 点，位于直线 $A_1B$ 上：直线 $A_1B$ 比穿过 A 点和 B 点的任何虚线都短。

费马原理的另一个有趣的结果是光传播轨迹的可逆性原理。如果光沿着提供最小传播时间的轨迹从 A 点传播到 B 点，那么显然，在从 B 点到 A 点的途中（即，如果光源位于 B 点），那么沿着相同轨迹的移动将需要最少的时间。

另一个例子。每个人都知道镜头的聚焦特性。来自 A 点 (图 8) 的光以所有可能的方式传播，在玻璃中折射并在 E 点收集。矛盾吗？毕竟，光总是沿着一条需要最少时间的路径前进！为什么无论光线从哪个方向射出，它都会到达同一个点E？

其实这并不矛盾。 ADE 路径比 ACE 路径短，但在光密介质（玻璃）中行进的距离在第一种情况下更大。因此，一般情况下的传播时间是相同的，并且两条光线将同时到达 E 点。光的路径 ADE 和 ACE 是相等的！

如果不是这样，我们就无法构建聚焦系统。

正是由于从A点向不同方向射出并通过透镜的光线，相同的最小传播时间对应到E点所引出的轨迹，透镜将入射到其上的光线聚焦。

费马原理不仅可以解释任意复杂光学系统的运行，还可以对其进行计算。然而，我们可以计算光学系统并使用反射和折射定律，这些定律早在费马工作之前就已为人所知。费马原理提供了什么新内容？首先，这条法律更具有普遍性，越普遍的法律，其意义就越大。因此，费马原理的发现是几何光学发展的一大进步。其次，从费马原理可以推导出几个新的重要推论。然而，最重要的一个是折射率等于第一和第二介质中光的相对速度。

焦面折射

让我们以您已知的光学系统的计算和镜头公式的推导为例。为此，在焦面上拉开光的折射距离就足够了。所有从确切的光源 S 发出的光线，在焦面折射之后，不会聚集在一点 S 1 处。这是因为只有形状非常复杂的表面才能提供光沿着所有可能的轨迹从 S 传播到 S₁ 的完全相同的时间。这样的表面应该很难制造，甚至没有尝试制造。跟随焦面要容易得多。尽管焦面不会聚焦所有光线，但由于垂直于表面的距离较近而产生的窄光束（称为顺强光束）几乎被收集在一个点上。

空的精确光源 S 位于距半径为 R (图 9) 的焦面距离 a 处。空气的折射率被认为等于1，玻璃球的折射率等于n，即光在空气中传播的速度是n倍。

光在玻璃中的传播速度。让我们找出从光源 $S$ 搜索的窄光束将在距离球体表面 $b$ 的距离处被收集。根据费马原理，该距离由以下条件确定：光沿直线路径$SDS_1$传播的时间等于（应用）光沿任意选择的路径$SAS_1$传播的时间，只要点$A$靠近垂直于球面的直线$SDS_1$即可。

从点 $A$ 将垂线 $AB$ 放到线 $SS_1$ 上。我们用 $h$ 来表示它的长度。由于我们考虑的是近轴光线，因此$h \ll a$、$h \ll b$和$h \ll R$。我们将距离 $DB$ 表示为 $x$。在射线 $SA$ 上，我们绘制线段 $SD_1 = a + x$，在射线 $AS_1$ 上，绘制线段 $S_1B_1 = b - x$。然后，与沿直线 $SS_1$ 的轨迹相比，沿着轨迹 $SAS_1$，光在空气中仅传播 $\Delta_1 = D_1A$ 路径，在玻璃中仅传播 $\Delta_2 = AB_1$ 路径。但是，在直线路径上，光线在玻璃中传播的路径比沿路径 $SAS_1$ 长的路径 $x - \Delta_2$ 长。路径 $x - \Delta_2$ 上玻璃中的光延迟必须与路径 $\Delta_1$ 上空气中的延迟加上路径 $\Delta_2$ 上玻璃中的延迟相同。 （在$x \leq \Delta_2$这样的补偿是不可能的。）

现在让我们找到路径 $\Delta_1$、$\Delta_2$ 和 $x$。

直角三角形$SAB$的$h$的平方，根据毕达哥拉斯定理，等于

$$h^2 = (a + x + \Delta_1)^2 - (a + x)^2,$$

或者

$$h^2 = (a + x + \Delta_1 + a + x)(a + x + \Delta_1 - a - x),$$

但是$a + x + \Delta_1 - a - x = \Delta_1$和$a + x + \Delta_1 + a + x = 2a + \Delta_1 + 2x \approx 2a$（因为$\Delta_1 \ll a$和$x \ll a$）。这就是为什么

$$h^2 = 2a\Delta_1$$

和

$$\Delta_1 \approx \frac{h^2}{2a}.$$

同样，从直角三角形$ABS_1$我们发现

$$\Delta_2 \approx \frac{h^2}{2b}.$$

最后，由直角三角形$ABC$可得确定$x$的方程：

$$h^2 = R^2 - (R - x)^2.$$

从这里

$$x \approx \frac{h^2}{2R}.$$

如果光在空气中的速度为$v_1$，光在玻璃中的速度为$v_2$，则光在$\tau_1 = \frac{\Delta_1}{v_1} = \frac{h^2}{2av_1}$内传播$\Delta_1$，在$\tau_2 = \frac{\Delta_2}{v_2} = \frac{h^2}{2bv_2}$内光在玻璃中传播$\Delta_2$。

在线段 $x$ 上，由于光在玻璃中而非空气中传播而导致光的延迟，等于光在玻璃和空气中穿过线段 $x$ 所需时间的位置：

$$\tau = \frac{x}{v_2} - \frac{x}{v_1} = \frac{x}{v_1}\left(\frac{v_1}{v_2} - 1\right) = \frac{x}{v_1}(n - 1) = \frac{h^2(n - 1)}{2Rv_1}.$$

为了聚焦光线，光沿所有轨迹从点 $S$ 到点 $S_1$ 的传播时间必须相同。因此，

$$\tau_1 + \tau_2 = \tau.$$

将这里的$\tau_1$、$\tau_2$、$\tau$的表达式代入，然后消去公因子$\frac{h^2}{2}$，得到方程

$$\frac{1}{a} + \frac{n}{b} = \frac{(n - 1)}{R}.$$

该方程允许使用已知的假设指数 $n$ 和球面半径 $R$，找到从源到球面的给定距离的图像位置（距离 $b$）。距离 $b$ 不依赖于 $h$ 的事实表明，窄光束中的所有光线（区分彼此的值 $h$）会聚于一点。

在$a \to \infty$（光束由平行光线组成）的部分情况下，光线会聚（焦点）的点的位置由以下公式确定

$$f = \frac{Rn}{n - 1}.$$

线焦距和透镜公式。

利用费马原理得到的式（1），可以计算透镜，即求出将物体到透镜的距离$a$、透镜到像的距离$b$和透镜距离的公式联系起来的公式（即得到透镜公式）。当然，不用椅子也可以做同样的事情，将费马原理本身应用于所有镜头，但这条路更加复杂。

透镜是由球面包围的固体。 图11示出了其表面曲率半径等于$R_1$和$R_2$的双凸透镜。连接球面中心$O_1$和$O_2$的线称为透镜的主光轴。

图 11.

我们假设镜片很薄，也就是说，我们假设距离$a$和$b$以及曲率半径$R_1$和$R_2$远大于镜片的厚度。那么在计算中透镜的厚度可以完全忽略。

光线折射离开点$S$后，出现$A S_1$。如果没有第二个表面，则点 $S$ 的图像将位于距镜头 $b_1$ 的点 $S_1$ 处，由以下方程确定

$$\frac{1}{a} + \frac{n}{b_1} = \frac{n-1}{R_1},$$

其中$n$是透镜材料的折射率。

但实际上，光线在第二个球面上再次折射，镜头产生的图像最终到达光轴上距镜头 $b_2$ 的点 $S_2$ 。我们利用光线的可逆性。如果将光源放置在点 $S_2$，则在半径为 $R_2$ 的球面上折射后，光线将出现，使其延续相交于点 $S_1$，从而给出光源的最小图像。利用式（1）并考虑$b_1 < 0$，我们可以写出等式

$$\frac{1}{b} - \frac{1}{b_1} = \frac{n-1}{R_2}.$$
