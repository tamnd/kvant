⟦folio 55⟧

进入一个正方形（这不会导致建筑解决方案的出现）。平方并引入相似项后，我们得到：
$$ (1+2a)x < a^2. $$
(4)

不等式(4)有以下解：

$$ \text{ если } a = -\frac{1}{2}, $$
$$ \text{ то } -\infty < x < \infty; $$
$$ \text{ если } a > -\frac{1}{2}, \text{ то } x < \frac{a^2}{1+2a}; $$
$$ \text{ если } a < -\frac{1}{2}, \text{ то } x > \frac{a^2}{1+2a}. $$

但人们不应该急于下结论并认为这已经解决了不平等问题 (2)。从找到的不等式（4）的解中，有必要显示满足条件（3）的解。为了方便进一步的工作，让我们针对任意值 $a$ 求解 $x$ 不等式系统 (3)。

系统(3)的第一个不等式有解$x \leq -1$或$x \geq 0$。第二个不等式有解$x < a$。进一步的推理取决于数字$a$相对于数字$-1$和$0$的定位。

分析$a \leq -1$、$-1 < a \leq 0$、$a > 0$情况，我们得到系统(3)的如下解：

a) 如果$a \leq -1$，则$x < a$；
b) 如果$-1 < a \leq 0$，则$x \leq -1$；
b) 如果$a > 0$，则$x \leq -1$或$0 \leq x < a$。

现在让我们从上面找到的不等式（4）的解中选择那些满足刚刚获得的条件$a$），$6$），$b$）的解。这些将是原始不等式（2）的解。

对于$a = -\frac{1}{2}$，所有实数都满足不等式（4）。条件（6）迫使我们将自己限制在$x \leq -1$的值内。因此，如果$a = -\frac{1}{2}$，则不等式（2）有解：$x \leq -1$。

对于$a > -\frac{1}{2}$，不等式(4)有解$x < \frac{a^2}{1+2a}$。根据条件（6）和（b），我们考虑两种情况：

$$ -\frac{1}{2} < a \leq 0 \text{ и } a > 0. $$

在第一种情况下，我们需要找到所有满足不等式$x \leq -1$和$x < \frac{a}{1+2a}$系统的$x$。因此$x \leq -1$的值。

因此，如果 $-\frac{1}{2} < a \leq 0$，则不等式 (2) 有解 $x \leq -1$。

在第二种情况下，即对于$a > 0$，我们需要取这样的$x$来满足不等式系统之一：

$$ \begin{cases} x < \frac{a^2}{1+2a}, \\ x \leq -1, \end{cases} $$
$$ \begin{cases} x < \frac{a^2}{1+2a}, \\ 0 \leq x < a. \end{cases} $$

这些系统中的第一个有解决方案$x \leq -1$。为了解决第二个系统，您需要比较数字$a$和$\frac{a^2}{1+2a}$。让我们做出改变$a - \frac{a^2}{1+2a} = \frac{a(a+1)}{1+2a}$。

很明显，对于$a > 0$，这个差异是正数，因此$\frac{a^2}{1+2a} < a$。这意味着第二个系统有以下解：$0 \leq x < \frac{a^2}{1+2a}$。

因此，如果$a > 0$，则不等式(2)有解$x \leq -1$；
$$ 0 \leq x < \frac{a^2}{1+2a}. $$

对于$a < -\frac{1}{2}$，不等式(4)有解$x > \frac{a^2}{1+2a}$。根据条件（6）和（b），我们考虑两种情况：

$$ a \leq -1 \text{ и } -1 < a < -\frac{1}{2}. $$
