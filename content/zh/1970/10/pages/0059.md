对于$a=0$，原始不等式采用以下形式
$$\frac{1}{x} > 1.$$
解决这个不等式，我们得到：
$$0 < x < 1.$$
结合所有获得的结果，我们写下
答案：如果$a < 0$，则$x < \frac{1 + \sqrt{1-4a}}{2a}$或$0 < x < \frac{1 - \sqrt{1-4a}}{2a}$；
如果$a=0$，则$0 < x < 1$；
如果$0 < a < \frac{1}{4}$，则$x > \frac{1 + \sqrt{1-4a}}{2a}$，或$\frac{1 - \sqrt{1-4a}}{2a} > x > 0$；
如果$a = \frac{1}{4}$，则$0 < x < 2$，或$x > 2$；
如果$a > \frac{1}{4}$，则$x > 0$。

示例 3. 求解不等式 $\log_{1/2}(x^2 - 2x + a) > -3$。
解，即这个不等式等价于不等式系统
$$\begin{cases} x^2 - 2x + a > 0, \\ x^2 - 2x + a < 8. \end{cases}$$
让我们将系统重写如下：
$$\begin{cases} (x-1)^2 > 1-a, \\ (x-1)^2 < 9-a. \end{cases}$$
让我们用 $y$ 表示 $x-1$ 并以不等式链的形式重写所得系统：
$$1-a < y^2 < 9-a.$$
如果我们现在注意，我们会注意到，对于$a \geq 9$，这条链没有解，而对于$a > 1$，所有$y$都满足不等式$y^2 > 1-a$，因此$1 < a < 9$情况下链的解将是不等式$y^2 < 9-a$的解，即$-\sqrt{9-a} < y < \sqrt{9-a}$。
如果最终$a \leq 1$，那么，求解链，我们得到
$$-\sqrt{9-a} < y < -\sqrt{1-a};$$
$$\sqrt{1-a} < y < \sqrt{9-a}.$$

答案：如果$a \leq 1$，那么
$$1 - \sqrt{9-a} < x < 1 - \sqrt{1-a},$$
或$1 + \sqrt{1-a} < x < 1 + \sqrt{9-a}$；
如果$1 < a < 9$，那么
$$1 - \sqrt{9-a} < x < 1 + \sqrt{9-a};$$
如果$a \geq 9$，则无解。
示例 4. 解决不等式
$$\cos x - \frac{1}{\cos x} \leq a (a > 0).$$
（莫斯科国立大学物理系，1966）
已解决，即我们首先注意到，所有$x$满足$\cos x > 0$（然后是$\frac{1}{\cos x} \geq 1 \geq \cos x$）。
我们现在将寻找 $\cos x < 0$ 的平均值 $x$ 的解。
在这种情况下，不等式（8）的形式为
$$\cos^2 x - a \cos x - 1 \geq 0,$$
从那里我们得到$\cos x \geq \frac{a + \sqrt{a^2 + 4}}{2}$或$\cos x \leq \frac{a - \sqrt{a^2 + 4}}{2}$。由于我们正在考虑情况$\cos x < 0$，因此我们丢弃不等式$\cos x \geq \frac{a + \sqrt{a^2 + 4}}{2}$。

所以，$\cos x \leq \frac{a - \sqrt{a^2 + 4}}{2}$。我们的结论不应回避这样一个事实：对于 $a$ 的某些值，数字 $\frac{a - \sqrt{a^2 + 4}}{2}$ 可能会小于 -1（毕竟，在这种情况下，最后一个不等式将无解）。因此，我们还是要比较数字$\frac{a - \sqrt{a^2 + 4}}{2}$和-1。很容易证明$\frac{a - \sqrt{a^2 + 4}}{2} > -1$（检查一下！）。

答案：$-\frac{\pi}{2} + 2k\pi < x < \frac{\pi}{2} + 2k\pi$，或 агссos $\frac{a - \sqrt{a^2 + 4}}{2} + 2k\pi \leq x \leq 2\pi - \frac{\pi}{2}$
弧线$\frac{a - \sqrt{a^2 + 4}}{2} + 2k\pi (k = 0, \pm 1, \pm 2, \ldots)$
