在第一种情况下，我们需要解决以下不等式系统：
$$\begin{cases} x > \frac{a^2}{1+2a}, \\ x < a. \end{cases}$$

但从等式（5）可知，对于$a \leq -1$，不等式$a \leq \frac{a^2}{1+2a}$有效，因此系统无解。因此，如果$a \leq -1$，则不等式（2）无解。

在第二种情况下，即对于$-1 < a < -\frac{1}{2}$，我们需要求解以下不等式组：
$$\begin{cases} x > \frac{a^2}{1+2a}, \\ x \leq -1. \end{cases}$$

我们来比较一下$\frac{a^2}{1+2a}$和$-1$的数字，我们补足差额
$$\frac{a^2}{1+2a} - (-1) = \frac{(a+1)^2}{1+2a}.$$

对于$-1 < a < -\frac{1}{2}$，这个差值是负数，这意味着$\frac{a^2}{1+2a} < -1$。

但最后一个不等式系统有以下解：
$$\frac{a^2}{1+2a} < x \leq -1.$$

这就是 $-1 < a < -\frac{1}{2}$ 情况下不等式 (2) 的解。

结合获得的结果，我们写下

答：若$a \leq -1$，则无解；

如果$-1 < a < -\frac{1}{2}$，那么
$$\frac{a^2}{1+2a} < x \leq -1;$$
如果$-\frac{1}{2} \leq a \leq 0$则$x \leq -1;$
如果$a > 0$则$x \leq -1;$
$0 \leq x < \frac{a^2}{1+2a}$.

3. 当心

示例 2. 解决不等式
$$\frac{1}{x} + ax > 1.$$

解决了并且e。让我们将不等式转化为以下形式
$$\frac{ax^2 - x + 1}{x} > 0.$$ (6)

让我们首先找到分子的根来分解分子：
$$x_1 = \frac{1 + \sqrt{1-4a}}{2a};$$
$$x_2 = \frac{1 - \sqrt{1-4a}}{2a}.$$

这里你需要小心，不要错过二次三项式的负判别式的情况。

这将在$a > \frac{1}{4}$。但对于所有 $x$，$ax^2 - x + 1 > 0$ 因此，在这种情况下，不等式 (6) 有一个解 $x > 0$。

对于$a = \frac{1}{4}$、$x_1 = x_2 = 2$，不等式(6)可以改写如下：
$$\frac{(x - 2)^2}{4x} > 0.$$

之后，不等式就有解$0 < x < 2$，$x > 2$。

现在让$a < \frac{1}{4}$。则不等式(6)变形为形式
$$\frac{a(x - x_1)(x - x_2)}{x} > 0$$ (7)

我们替换为应该区分两种情况：$a > 0$或$a < 0$（考虑$a = 0$的情况）。

如果 $0 < a < \frac{1}{4}$，则不等式 (7) 的形式为
$$\frac{(x - x_1)(x - x_2)}{x} < 0,$$
从那里（考虑到$a < 0$$x_1 < 0 < x_2$）我们得到$x < x_1; 0 < x < x_2$。
