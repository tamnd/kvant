⟦folio 15⟧

必须证明以下不等式：

$$\sqrt{(x_1 - x_3)^2 + (y_1 - y_3)^2} \leq \sqrt{(x_1 - x_2)^2 + (y_1 - y_2)^2} + \sqrt{(x_2 - x_3)^2 + (y_2 - y_3)^2}.$$

试试这个！方便引入特殊符号：$x_1 - x_2 = u_1, x_2 - x_3 = u_2, y_1 - y_2 = v_1, y_2 - y_3 = v_2$；然后$x_1 - x_3 = u_1 + u_2, y_1 - y_3 = v_1 + v_2$，最后一个不等式写得稍微短一些：

$$\sqrt{(u_1 + u_2)^2 + (v_1 + v_2)^2} \leq \sqrt{u_1^2 + v_1^2} + \sqrt{u_2^2 + v_2^2}$$

（顺便说一句，这种符号的改变将大大缩短不等式的证明（2））。经过两次平方和化简后，得到等效的估计不等式

$$u_1^2 v_2^2 + u_2^2 v_1^2 \geq 2u_1 u_2 v_1 v_2 < = > (u_1 v_2 - u_2 v_1)^2 \geq 0.$$

想一想什么时候这种不平等变成平等？这在几何语言中意味着什么？

原则上，所有几何定理都可以在纯代数数平面上证明，从而构建几何课程；但是，正如你所看到的，沿着这条路，定理的证明并不总是变得更简单——连同“三角不等式”，我们必须证明一个相当棘手的代数不等式。

我们已经说过，在同一组上可以不同地确定距离。以下是数平面 $R^2$ 上与 (4) 不同的度量示例。

实施例5.

$$\rho'(M_1, M_2) = |x_1 - y_1| + |x_2 - y_2|,$$

(5) 即$\rho'(M_1, M_2)$等于线段$M_1 M_2$在轴$Ox$和$Oy$上的投影长度之和。

实施例 6.

$$\rho''(M_1, M_2) = \max\{ |x_1 - y_1|, |x_2 - y_2| \}$$

（6）（符号max{a，b}表示a，b中的最多的数），即$\rho''(M_1, M_2)$等于线段$M_1 M_2$在轴$Ox$和$Oy$上的投影长度的最多。

使用不等式（2）可以轻松证明最后两个例子中的三角不等式。假设$\rho''$：

$$|x_1 - x_3| \leq |x_1 - x_2| + |x_2 - x_3| \leq \max\{ |x_1 - x_2|, |y_1 - y_2| \} + \max\{ |x_2 - x_3|, |y_2 - y_3| \}, \text{ и } |y_1 - y_3| \leq y_1 - y_2 + |y_2 - y_3| \leq \max\{ |x_1 - x_2|, |y_1 - y_2| \} + \max\{ |x_2 - x_3|, |y_2 - y_3| \},$$

因此，两个数$|x_2 - x_3|, |y_1 - y_3|$中的较大者不超过$\rho''(x_1, x_2) + \rho''(x_2, x_3)$。

同样，在三个实数的所有集合$(x, y, z)$的集合$R^3$上，“点”$(x_1, y_1, z_1)$和$(x_2, y_2, z_2)$之间的距离可以由任何公式给出

$$\sqrt{(x_1 - x_2)^2 + (y_1 - y_2)^2 + (z_1 - z_2)^2},$$

(4')

$$|x_1 - x_2| + |y_1 - y_2| + |z_1 - z_2|,$$

(5') 或

$$\max\{ |x_1 - x_2|, |y_1 - y_2|, |z_1 - z_2| \}.$$

(6')

在情况（4'）中，我们得到了一个一般的三维空间，它是通过学校立体测量学研究的，也是我们生活在其中的一个方便的现实。所有类似的$m$维空间（$m=2, 3, 4, \dots$）也很有用——在它们的帮助下，可以方便地构造$m$变量的整个函数理论，有时使用一个距离公式更方便，有时使用另一个公式更方便。
