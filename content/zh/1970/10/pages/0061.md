图 3.

对应于 图 3，这些区域是阴影的，这些线是虚线的，它们的所有点都不属于 ODZ，因此不能是不等式 (10) 的解。

如果$0 < a < \frac{1}{2}$，则不等式(10)变换为以下形式
$$a + 2x - x^2 > (\sqrt{2a})^2,$$
在哪里
$$a < -x^2 + 2x.$$

这意味着在这种情况下，不等式 (10) 由那些充当以下系统的解的 $(x; a)$ 满足：

$$\begin{cases} a > 0, \\ a < \frac{1}{2}, \\ a > x^2 - 2x, \\ a < -x^2 + 2x. \end{cases}$$

这些解决方案填充图 3 处的区域 I。

如果$a > \frac{1}{2}$，则不等式(10)变换为以下形式
$$a + 2x - x^2 < (\sqrt{2a})^2,$$
从哪里$a > -x^2 + 2x.$

这意味着在这种情况下，不等式 (10) 由那些充当以下系统的解的 $(x; a)$ 满足：

$$\begin{cases} a > \frac{1}{2}, \\ a > x^2 - 2x, \\ a < -x^2 + 2x. \end{cases}$$

这些解决方案将填充区域 II 图 3。

答：如果$a \leq 0$或$a = \frac{1}{2}$，则无解；

如果$0 < a < \frac{1}{2}$，那么
$$1 - \sqrt{1 - a} < x < 1 + \sqrt{1 - a};$$
如果$\frac{1}{2} < a \leq 1$，那么
$$1 - \sqrt{1 + a} < x < 1 + \sqrt{1 - a};$$
$$1 + \sqrt{1 - a} < x < 1 + \sqrt{1 + a};$$
如果$a > 1$，那么
$$1 - \sqrt{1 + a} < x < 1 + \sqrt{1 + a}.$$

5. 结论

当求解带有参数的不等式时，仔细检查所有情况，不要急于下结论，要小心，不要忘记图解方法。

练习

求解 $x$ 的以下不等式：

1. $2x + 3(ax - 8) + \frac{x}{3} < 4(x + \frac{1}{2}) - 5.$
2. $\frac{2ax + 3}{5x - 4a} < 4.$
3. $\left| \frac{ax - 5}{3} + x \right| < 3.$
4. $\sqrt{x} - \sqrt{x - 1} > a.$
5. $tg x + ctg x \leq a (a > 0).$
6. $\lg^2 x - 2a \lg x - a^2 + 2 > 0.$
7. $\sqrt{a^2 - x^2} + \sqrt{2ax - x^2} > a$（用图解法）。
8. $\log_x(x - a) > 2$（用图解法）。
