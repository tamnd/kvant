⟦folio 13⟧

3°。从$a$到$c$的距离不大于从$a$到$b$和从$b$到$c$的距离之和（“三角公理”）。

让我们从最简单的度量空间示例开始。

例1. $X$是数轴，即所有实数的集合*)。距离$\rho$由公式确定

$$\rho(x, y) = |x - y|.$$

(1)

回想一下，如果$a \geqslant b$则为$|a - b| = a - b$，如果$b \geqslant a$则为$b - a$，因此在所有情况下，$\rho(a, b)$都等于以$a$和$b$为端点的实线段的长度（图2，a）。

让我们检查 $\rho$ 是否满足所有三个要求 $1^\circ - 3^\circ$。显然，$|a - b| = 0$当且仅当$a = b$，并且总是$|a - b| = |b - a|$。

不等式 $3^\circ$ 也几乎是显而易见的 (图 2, b)。在直线上点 $a, b$ 和 $c$ 的相对位置的每种可能情况下，也包括当 $a, b$ 和 $c$ 中的两个点重合时，不等式

$$|a - c| \leqslant |a - b| + |b - c|$$

(2)

很容易形式化证明，无需参考图。例如，如果 $b \leqslant a \leqslant c$（下图 2, b），则

$$|a - c| = c - a,$$

$$|a - b| + |b - c| = a - b + c - b = a + c - 2b \geqslant a + c - 2a = c - a,$$

因此 (2) 为真。

示例 2. $X$ 是任意集合，

$$\rho(a, b) = \begin{cases} 0, & \text{ если } a = b, \\ 1, & \text{ если } a \neq b. \end{cases}$$

(3)

所有轴子$1^\circ - 3^\circ$显然都满足。正如他们所说，这是一个“离散”空间，其中所有点似乎都是分开的，彼此距离不太近。
