⟦folio 52⟧

将单个正电荷从电容器的一个极板转移到另一极板所需的功为 $A = E_1 d_1 + E_2 d_2$。但电容器短路，极板间电位差为零。因此，$E_1 d_1 + E_2 d_2 = 0$。

或者$\frac{2Q + q}{2\varepsilon_0 S} d_1 + \frac{2Q - q}{2\varepsilon_0 S} (d - d_1) = 0$。简化这个方程，我们得到

$$Q (d - d_1) + q d_1 = 0. \tag{1}$$

当中坝移动距离$x$时，电荷$\Delta Q$将通过连接板的电线，并且板的电荷将等于$Q + \Delta Q$和$-Q - \Delta Q$。由于在这种情况下，极板之间的电势差为零，因此，以与第一种情况相同的方式推理，我们得到方程

$$\frac{q + 2(Q - \Delta Q)}{2\varepsilon_0 S} (d_1 + x) + \frac{2(Q - \Delta Q) - q}{2\varepsilon_0 S} (d - d_1 - x) = 0$$

或者

$$(Q - \Delta Q) (d - d_1 - x) + q (d_1 + x) = 0. \tag{2}$$

将式(2)减去式(1)，可得$\Delta Q = q \frac{x}{d}$。
