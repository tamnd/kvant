1. 仔细研究所有案例

假设我们需要求解 $x$ 的以下线性不等式：

$$\frac{3ax + 4}{3a + 9} < \frac{x}{a + 3} + \frac{3a - 5}{3a - 9}.$$

看起来，还有什么比这更简单的呢？遵循众所周知的校规，我们收集不等式左边所有包含 $x$ 的项，右边包含自由项：

$$\frac{3ax}{3a + 9} - \frac{x}{a + 3} < \frac{3a - 5}{3a - 9} + \frac{4}{3a + 9},$$

并原谅由此产生的不平等：

$$\frac{a - 1}{a + 3} x < \frac{a^2 - 1}{a^2 - 9}.$$

(1)

现在剩下的就是将不等式两边除以未知数的系数。

但正是在这一步——将不等式（1）两边除以未知数的系数时——需要极其小心，否则不等式包含参数。

带参数的不等式本质上是一组不等式，每个不等式都是根据给定特定值的参数获得的。想象一下，一位朋友让你用参数解决一个不等式，而他自己想到了参数值的具体数字。你不知道其意图，你的任务不是让自己感到惊讶，而是仔细检查所有可能出现的情况。一旦你解决了不等式，伙计

向您宣布他想要的参数值，您必须在您的答案中找到与该值具体相关的案例。

让我们回到我们的例子。可能有4种情况：

1) 不等式的一个或两个部分没有意义；
2) 未知数的系数等于；
3) 未知数的系数为正；
4) 未知数的系数为负。

第一个案例将发生在$a = \pm 3$。对于这些参数值，不等式（1）无解。

第二种情况发生在$a = 1$。在这种情况下，参数不等式（1）的值采用$0 \cdot x < 0$的形式，并且显然没有解。

第三种情况发生在$a < -3$或$a > 1$、$a \neq 3$。将不等式(1)两边同时除以正数$\frac{a - 1}{a + 3}$，可得：

$$x < \frac{a + 1}{a - 3}.$$

第四种情况发生在$-3 < a < 1$。将不等式(1)两边同时除以负数$\frac{a - 1}{a + 3}$，可得：$x > \frac{a + 1}{a - 3}$。

结合获得的结果，我们写下

答：若$a = 1$，$a = \pm 3$，则无解；

如果$a < -3$，$1 < a < 3$，$a > 3$，那么

$$x < \frac{a + 1}{a - 3};$$

如果$-3 < a < 1$，则$x > \frac{a+1}{a-3}$。

给定的答案包含任意参数值的不等式 (1) 的解。这正是求解带有参数的不等式时的主要目标。

使用图 1，求解不等式$\cos x \geq a$并证明答案为：
如果$a \leq -1$，则$-\infty < x < \infty$；
如果$-1 < a < 1$则$m_1 + 2k\pi \leq x \leq m_2 + 2k\pi$，
其中$m_1 = -\arccos a$，$m_2 = \arccos a$；
如果$a = 1$，则$x = 2k\pi$；
如果$a > 1$，则无解。
($k = 0, \pm 1, \dots$)

2. 不要急于下结论

让我们看另一个简单的例子。让我们来解决不等式$\sqrt{x} > a$。人们很容易写出 $x > a^2$ 并声称该条目包含不等式的所有解。但在求解带有参数的不等式时，不要急于下结论：毕竟，$a$可以小于零；那么不等式$\sqrt{x} > a$的解将是任意非负值$x$；如果$a \geq 0$，则不等式$\sqrt{x} > a$两边同时平方是等价变换；抛光后，我们得到$x > a^2$。

答案：如果$a < 0$，则$x \geq 0$；
如果$a \geq 0$，则$x > a^2$。

示例 2. 解决不等式
$$\frac{1}{x} + ax > 1.$$

解决了并且e。让我们将不等式转化为以下形式
$$\frac{ax^2 - x + 1}{x} > 0.$$ (6)

让我们首先找到分子的根来分解分子：
$$x_1 = \frac{1 + \sqrt{1-4a}}{2a};$$
$$x_2 = \frac{1 - \sqrt{1-4a}}{2a}.$$

这里你需要小心，不要错过二次三项式的负判别式的情况。

这将在$a > \frac{1}{4}$。但对于所有 $x$，$ax^2 - x + 1 > 0$ 因此，在这种情况下，不等式 (6) 有一个解 $x > 0$。

对于$a = \frac{1}{4}$、$x_1 = x_2 = 2$，不等式(6)可以改写如下：
$$\frac{(x - 2)^2}{4x} > 0.$$

之后，不等式就有解$0 < x < 2$，$x > 2$。

现在让$a < \frac{1}{4}$。则不等式(6)变形为形式
$$\frac{a(x - x_1)(x - x_2)}{x} > 0$$ (7)

我们替换为应该区分两种情况：$a > 0$或$a < 0$（考虑$a = 0$的情况）。

如果 $0 < a < \frac{1}{4}$，则不等式 (7) 的形式为
$$\frac{(x - x_1)(x - x_2)}{x} < 0,$$
从那里（考虑到$a < 0$$x_1 < 0 < x_2$）我们得到$x < x_1; 0 < x < x_2$。

解，即这个不等式等价于不等式系统
$$\begin{cases} x^2 - 2x + a > 0, \\ x^2 - 2x + a < 8. \end{cases}$$

$$-\sqrt{9-a} < y < -\sqrt{1-a};$$

$$1 - \sqrt{9-a} < x < 1 + \sqrt{9-a};$$
如果$a \geq 9$，则无解。

5. 结论

当求解带有参数的不等式时，仔细检查所有情况，不要急于下结论，要小心，不要忘记图解方法。
