6. 如果元素$a_i$不属于某个集合$A_j$，则$k_i \geqslant s_j$。事实上，让集合$A_j$不包含元素$a_i$并且由$s_j$不同元素组成。那么元素 $a_i$ 必须与系统的某些剩余集合中的每个元素一起出现。另一方面，这些元素中没有两个可以出现在这些集合中，因为它们已经出现在 $A_j$ 中。因此，元素$a_i$不小于$s_j$的集合数。

7. 考虑第一个$k_n$集合$A_1, A_2, \dots, A_{k_n}$和$a_1, a_2, \dots, a_{k_n}$的第一个$k_n$元素。它们的选择方式是，每个集合$A_i$包含一个具有相同编号的元素$a_i$，但不包含具有其他编号的元素，那么，根据第6段，$s_1 \leqslant k_2, s_2 \leqslant k_1$如果$k_n = 2$并且

$$\begin{align*}
s_1 &\leqslant k_2, \quad s_2 \leqslant k_1, \quad \dots, s_{k_n} \leqslant k_1, \\
s_1 &\leqslant k_{k_n}, \quad s_2 \leqslant k_{k_n}, \quad \dots, s_{k_n} \leqslant k_{k_n-1},
\end{align*}$$

如果$k_n > 2$。

在示例中 $k_n = 3$ 和

$$\begin{align*}
2 &= s_1 \leqslant k_2 = 3, \quad 3 &= s_2 \leqslant k_1 = 4, \quad 3 &= s_3 \leqslant k_1 = 4, \\
2 &= s_1 \leqslant k_3 = 4, \quad 3 &= s_2 \leqslant k_3 = 4, \quad 3 &= s_3 \leqslant k_2 = 3.
\end{align*}$$

$$S = (s_1 + s_2 + \dots + s_{k_n}) + s_{k_n+1} + \dots + s_m$$

和

$$K = (k_1 + k_2 + \dots + k_n) + k_{k_n+1} + \dots + k_n.$$

10. 让我们尝试找出在什么情况下可以实现平等。如果 $m = n$，则从第 8、9、4 项可得：

$$k_1 + \dots + k_{k_n} + \dots + k_n = s_1 + \dots + s_{k_n} + \dots + s_n.$$
