F1。三个连通水的容器，其中心距离$a$相同，覆盖有相同厚度、相同材料的活塞。垂直相同的杆连接到活塞，活塞铰接地连接到杆 $AB$。如果与活​​塞和负载的质量相比，杆和杆的质量可以忽略不计，则可以在杆上的什么点处将负载连接到杆上，以便在平衡位置，杆保持水平。容器的直径分别为 $d_1$、$d_2$ 和 $d_3$。

扭矩$AB$和活塞在七个力的作用下处于平衡状态：力$Q$，来自负载的作用力，作用在活塞上的重力——这些力与活塞的面积成正比：$P_1 = k_1 d_1^2$； $P_2 = -k_1 d_2^2$； $P_3 = k_1 d_3^2$ 和作用在活塞上的三个流体压力：$N_1$、$N_2$、$N_3$ (图 10)。由于容器内的液位相同，所以所有活塞上的压力相等，压力与活塞的面积有关：$N_1 : N_2 : N_3 = d_1^2 : d_2^2 : d_3^2$。因此$N_1 = k_2 d_1^2$、$N_2 = k_2 d_2^2$、$N_3 = k_2 d_3^2$。

施加到每个活塞上的力相等：$F_1 = N_1 - P_1 = (k_2 - k_1) d_1^2 = kd_1^2$、$F_2 = kd_2^2$、$F_3 = kd_3^2$。

用$x$表示从杆中部到负载附着点的距离，我们写下杆的条件：1）作用在杆上的所有力的总和等于零：$F_1 + F_2 + F_3 - Q = 0$和2）作用在杆上的所有力相对于杆中部的力矩总和等于0：$F_1 a - F_3 a - Qx = 0$。将$F_1$、$F_2$、$F_3$的表达式代入这些方程中，然后一起求解这些方程，我们发现

$$x = \frac{d_1^2 - d_3^2}{d_1^2 + d_3^2 + d_3^2} a.$$

提出该问题解决方案的读者都没有考虑到活塞的质量。但只有两个人——来自基洛沃巴德的 G. Kalshin 和来自伏罗什尔戈夫雷德地区 Lisiansk 镇的 A. Karpenko——解释了为什么可以这样做。由于活塞由相同的材料制成并且具有相同的厚度，因此本体上的附加压力不取决于活塞的直径。活塞平衡的条件是所有气缸中的身体压力相等（因为气缸中的水位相同）。活塞产生的附加压力自动满足此条件。

F2。质量为 $m_1$ 和 $m_2$ 的两个球位于水平面上，由刚度为 $c$ 的弹簧紧固在一起。飞机很平稳。球体弯曲，释放弹簧，然后同时释放。确定球的振动周期。

系统的质心不应移动（或可以匀速直线移动），因此球以相同的频率反相振动，其与平衡位置的偏差$x_1$和$x_2$满足长度为$l_1$和$l_2$的相应弹簧片（$l_1$和$l_2$是球到物体的距离）系统的质心；

$$l_1 = l \frac{m_2}{m_1 + m_2}, \quad l_2 = l \frac{m_1}{m_1 + m_2}).$$

弹簧第 $1/q$ 部分的伸长率始终小于整个弹簧的伸长率$q$ 倍，即弹簧第 $1/q$ 部分的刚度比伸长率大$q$ 倍
