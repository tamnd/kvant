可以肯定的是，不等式$v > u^n$为真。这种情况可以在第43页给出的表格中构建。（它突出显示了数字$u^k$小于相应数字$v$的单元格）。

在验证了所指示的属性后，马蒂亚塞维奇“纠正”了斐波那契数列，删除了其中的奇怪项。也就是说，他考虑了相应的序列：$\varphi_0 = 0, \varphi_1 = 1, \varphi_{n+1} = 3\varphi_n - \varphi_{n-1}$。结果正好是第一个序列的四个成员的序列：$\varphi_0 = 0, \varphi_1 = 1, \varphi_2 = 3, \varphi_3 = 8, \varphi_4 = 21, \varphi_5 = 55, \varphi_6 = 144, \varphi_7 = 377$等。将$u$作为序列成员的编号，将$v$作为编号为$u$的序列成员，即$\varphi_u$，我们发现$u$和$v$再次满足所需的属性。 Terer 只需构造方程 $P(u, v, x_1, \dots, x_k) = 0$，当且仅当 $v = \varphi_u$ 时，该方程才有自然解 - 其余部分基于 Julia Robinson 的结果！为此，只需构造一个变量 $u, v, x_1, \dots, x_k$ 的微分方程组 $P_1 = 0, \dots, P_n = 0$，当且仅当 $v = \varphi_u$ 时，该方程组才有解 - 该方程组与唯一的方程 $P_1^2 + \dots + P_n^2 = 0$ 具有完全相同的解。

这是 Matiyasevich 获得所需方程组的形式：

1) $u + (a - 1) = v$,
2) $v + b = l$,
3) $l^2 - lk - k^2 = 1$,
4) $g^2 - gh - h^2 = 1$,
5) $l^2c = g$,
6) $ld = r - 2$,
7) $(2h + g)e = r - 3$,
8) $x^2 - rxy + y^2 = 1$,
9) $lp = x - u$,
10) $(2h + g)q = x - v$.

为了证明该系统的自然解的存在性等价于相应的$v = \varphi_u$，Matiyasevich 使用了序列$\{\varphi_k\}$的以下特征属性：

一对条件$x < y$和$x^2 - 3xy + y^2 = 1$相当于存在$k$使得$x = \varphi_k$和$y = \varphi_{k+1}$。

我们建议感兴趣的读者尝试证明这种等价性。

让我们在结论中指出，所找到的十个问题的解决方案具有许多有趣的后果，其中，也许最有效的是：您可以指定一个特定的线性多项式，其正值的集合与所有素数的集合一致！
