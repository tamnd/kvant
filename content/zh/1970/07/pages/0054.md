⟦folio 52⟧

颈穿过圆心和球心。事实上，两个圆相对于平面$P$对称，如果它们在平面$P$的一侧有一个公共点，那么它们在另一侧$P$上也必须有一个对称的公共点，但它们只有一个公共点。如果这些圆的半径相同$r$，那么它们的“中心”之间的距离就等于$2r$，因为在球体与平面$P$（图 2，$\theta$）相交所形成的大圆上，圆的直径（黑色线段）和连接它们“中心”的线段（红色）收缩的弧相等。

令$A_0, A_1, A_2, \dots, A_n$为圆$\gamma_0, \gamma_1, \dots, \gamma_n$的“中心”，这将在问题的条件中讨论。那么$A_0A_1 = A_0A_2 = \dots = A_0A_n = A_1A_2 = A_2A_3 = \dots = A_nA_12r$，换句话说，$A_0A_1A_2 \dots A_n$是一个正则$n$角形参数，内接于半径为1、顶点为$A_0$的给定球体，其所有侧面都是边长等于$2r$的等边三角形。因此，构造一个满足这些条件的paramid就足够了，那么点$A_0, A_1, \dots, A_n$将是半径为$r$、“中心”$A_0, A_1, \dots, A_n$的某些圆，这显然满足问题的条件。

由于顶点为 $A_0$ 的凸 $n$ 面角的平面角之和小于 $360^\circ$：
$$n \cdot 60^\circ = A_1A_0A_2 + A_2A_0A_3 + \dots + A_nA_0A_1 < 360^\circ,$$
然后$n < 6$。对于$n = 3, 4$和5，构造必要的paramid并不困难。

设 $O$ 为球体中心。帕拉酰胺的高度$h$及其边缘的长度$2r$是根据以下考虑得出的：帕拉酰胺底部的半径$KA_1$是腿$\Delta A_0KA_1$和边$\Delta A_1KA_2$，其中$\Delta A_1KA_2 = 2\pi/n$（图3，$a, \delta$），

$$\sqrt{4r^2 - h^2} \sin \frac{\pi}{n} = r.$$

从$\Delta A_0OA_1$我们有$r = \frac{h}{2r}$。

因此$h = 2r^2$，$r = \sqrt{1 - \frac{1}{4 \sin^2 \frac{\pi}{n}}}$。

因此，

在$n = 3$：$r = \sqrt{\frac{2}{3}} \left( \sin \frac{\pi}{3} = \frac{\sqrt{3}}{2} \right)$；

在$n = 4$：$r = \sqrt{\frac{1}{2}} \left( \sin \frac{\pi}{4} = \frac{\sqrt{2}}{2} \right)$；

在 $n = 5$: $r = \sqrt{\frac{5 - \sqrt{5}}{10}}$

（公式 $\sin \frac{\pi}{5} = \frac{\sqrt{10 - 2\sqrt{5}}}{4}$ 可以从 图 4 导出，借助该公式可以构造正十边形和正边形）。
