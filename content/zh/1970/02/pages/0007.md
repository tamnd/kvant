⟦folio 5⟧

表中符号$V$是“算术”平方根的符号。显然，公式

$$y = f(x) = (\sqrt{x})^2$$

(1)

仅当 $x$ 为非负数时，您才可以根据给定的 $x$ 计算相应的值 $y$（否则“不提取”平方根）。

对于非负 $x$

$$y = f(x) = x.$$

(2)

公式（2）比公式（1）更简单，我们希望将其视为定义我们的函数的公式。但式（2）给出的函数的定义域不仅仅由非负数$x$组成，而是由所有数$x$组成。如果我们想给公式（1）定义的函数一个新的定义，我们需要写

$$y = f(x) = \begin{cases} x \text{ при } x \geq 0, \\ \text{ не определена при } x < 0. \end{cases}$$

(3)

类似地，函数$g(x) = \frac{x^3 - 1}{x - 1}$可以写成如下：

$$g(x) = \begin{cases} x^2 + x + 1 \text{ при } x \neq 1, \\ \text{ не определена при } x = 1. \end{cases}$$

(4)

在学校和大学考试中，此类问题需要完全准确。
