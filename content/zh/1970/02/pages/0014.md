6. 描述狄利克雷函数图的结构：
$$D(x) = \begin{cases} 1, если x рационально, \\ 0, если x irrationalно. \end{cases}$$

7*) 段 [0; 中的数字 $x$; 1] 分解为无限轨道分数
$$x = 0, x_1 x_2 x_3 \dots (x_n = 0, 1, 2).$$

函数$y = C(x)$的值由双分数决定
$$y = 0, y_1 y_2 y_3 \dots (y_n = 0, 1)$$
如下：
如果$x_n = 0$则$y_n = 0$，
如果$x_n = 1$或$x_n = 2$，则：
$$y_n = 1$$，前提是$x_1, x_2, \dots, x_{n-1}$中没有数字，
$$y_n = 0$$ 前提是在数字$x_1, x_2, \dots, x_{n-1}$ 中已经遇到过一个单位。

尝试画出这个函数的图形。证明它包含无限多个水平线段。如果您熟悉可理解的函数连续性，请尝试证明我们的函数是连续的。

注 e.在这个问题中，我们并没有避免三元分数，其中从某些开始，所有符号都是二，以及双分数，其中从某些开始，所有符号都是一。比如我们在三元系中写
$$0,2222 \dots = 1; 0,1222 \dots = 0,200000 \dots$$

在双元体系中我们相信
$$0,1111111 \dots = 1; 0,01011111 \dots = 0,01100000 \dots$$

*) 这是一项艰巨的任务（参见书中第 15 节：S.V. Fomin “Number Systems”, 1968。
