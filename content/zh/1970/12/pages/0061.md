利用不等式$b + c \geq 2\sqrt{bc}$，我们得到$l_a \leq \sqrt{p(p - a)}$。与$l_b \leq \sqrt{p(p - b)}$、$l_c \leq \sqrt{p(p - c)}$类似。最后三个不等式和容易证明的对应关系$h_a \leq l_a, h_b \leq l_b, h_c \leq l_c$给出$l_ah_a + l_bh_b + l_ch_c \leq l_a^2 + l_b^2 + l_c^2 \leq p(p - a) + p(p - b) + p(p - c) = p^2$。

3. 我们将原方程转化为以下形式

$$x^3\cos^2x - 2x(x + 1)\cos x \sin x + 2(x + 1)\sin^2x = 0.$$

将左边乘以 $x$ 并分离完全平方，我们得到等效方程 $[x^2\cos x - (x + 1)\sin x]^2 + (x - 1)(x + 1)\sin^2x = 0$。如果实数$\alpha$是该方程的根，同时$(\alpha - 1)\times(\alpha + 1) > 0$，则等式$\sin^2\alpha = 0, \alpha^2\cos\alpha - (\alpha + 1)\sin\alpha = 0$必须成立，这仅适用于$\alpha = 0$，但适用于$(\alpha - 1)(\alpha + 1) < 0$。
