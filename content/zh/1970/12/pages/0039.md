以 $O$ 为圆心、半径为 $R = a + r$ 的圆，从点 $M$ 到半径为 $r$ 的两个圆之一所画的切线等于从点 $M$ 到另外两个圆所画的切线之和。注意，对于$r = 0$，得到了问题a)的结果。

让半径$OM$与半径$OC_k$($k = 0, 1, 2$)形成角度$\alpha_k = \alpha_0 + k \cdot 120^\circ$(图4)；则$MC_k^2 = R^2 + a^2 - 2Ra \cos \alpha_k^*$），从$M$点到对应圆的切线的平方为$MC_k^2 - r^2 = R^2 + a^2 - 2Ra \cos \alpha_k - (R - a)^2 = 2Ra (1 - \cos \alpha_k)$。

因此，切线等于 $2\sqrt{Ra} \sin \frac{\alpha_k}{2} \left( \sin \frac{\alpha_k}{2} \geq 0, \text{ поскольку } 0 \leq \alpha_k < 2\pi \right)$。剩下的就是检查是否相等 $\sin \frac{\alpha_0}{2} + \sin \frac{\alpha_2}{2} = \sin \frac{\alpha_1}{2}$。这已经很简单了：$\sin \frac{\alpha_0}{2} + \sin \frac{\alpha_2}{2} = 2 \cos 60^\circ \cdot \sin \frac{\alpha_0 + \alpha_2}{4} = \sin \frac{\alpha_1}{2}$。

M. Preezer 使用解析几何提出了该问题的解决方案。 A. Braverman 给我们发了一个有趣的证明（使用托勒密定理），证明了问题 a) 的以下概括：令 $M$ 为围绕正则 ($2n + 1$) 边形 $A_1A_2A_3 \dots A_{2n}A_{2n+1}$ 外接圆的圆弧 $A_1A_{2n+1}$ 上的一点；然后

$$MA_1 + MA_3 + \dots + MA_{2n+1} = MA_2 + MA_4 + \dots + MA_{2n}.$$

（解决方案是写出四边形 $MA_1A_2A_3, MA_2A_3A_4, \dots, MA_{2n-1}A_{2n}A_{2n+1}, MA_{2n+1}A_{2n}A_1, MA_{2n+1}A_2A_1$ 的托勒密方程，将所有包含 $MA_{2k}$ 的项放在等式的左侧，将所有包含 $MA_{2k+1}$ 的项放在等式的右侧，然后将所有等式相加。）考虑如何使用三角函数来证明此陈述以及问题 6）的类似推广。

M19。在无尽的忠实细胞链中，每个细胞都可以处于两种状态之一：“休息”和“兴奋”。如果在给定时刻一个细胞被激发，那么它会发出一个信号，经过一个时间单位（例如一毫秒）后，该信号到达与其相邻的两个细胞。当且仅当每个细胞接收到来自其相邻细胞之一的信号时，每个细胞才会兴奋；如果信号同时从两侧到达，那么它们就会熄灭，并且细胞不会激发。

在初始时间$t = 0$只让一个细胞兴奋。 15个月后有多少细胞会处于兴奋状态？ 65个月内？ 1000个月后？ $t$ 个月内？

如果链不是无限的，而是仅包含 $N$ 个连接成圆圈的单元，会发生什么 - 激励会长期保持无限还是会消失？

解决方案。追踪单个细胞的激发如何传播超过十到十五个时钟周期 (图 5) 就足以注意到以下模式。

1. 在时间$t = 2^k$，即$k = 0, 1, 2, \dots$，只有两个细胞被激发：$x = -2^k$和$x = 2^k$。

2. 在时间$t = 2^k - 1$，从$x = -2^k + 1$到$x = 2^k - 1$的$2^k$细胞被激发，其中$x$为奇数。

3. 让$0 \leq t < 2^k$。那么在时间 $2^k + t$ 时，兴奋的细胞数量是时间 $t$ 时的两倍。

为了证明这些规律性（通过$k$归纳），我们可以利用以下事实：在时间$2^k$活跃的两个细胞中的每一个产生的“激发波”直到时间$t = 2^{k+1} - 1$才重叠，因此它们中的每一个的结构都与来自一个细胞在$t < 2^k$时的激发波完全相同。

*) $\cos(2\pi - \alpha) = \cos \alpha$，因此该公式对于$\alpha > \pi$也有效。
