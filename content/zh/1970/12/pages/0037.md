DK⊥BC (图1)。那么AH = x，KD = BH = 8 - x，AB + BC = 2AD = 4x，BC = 4x - 8，BK = DH = x√3，KC = |BC - BK| = |4x - 8 - x√3|并满足问题的所有条件*) 满足等式 CK² + KD² = AD² 或 (4x - 8 - x√3)² + (8 - x)² = 4x² 是必要且充分的，

其中 8 - x > 0 且 4x - 8 > 0，即 2 < x < 8。变换后，我们得到 (2 - √3)x² - 2(5 - √3)x + 16 = 0。

让我们用 f(x) 表示左侧的三项式。很容易验证，只有方程 f(x) = 0 (图 2) 的较小根 x₀ 才满足条件 0 < x < 8。可以写成这样的形式

x₀ = (5 - √3 - √6√3 - 4) / (2 - √3) = 7 + 3√3 - √44 + 26√3.

农民将不得不走4x₀路线。直接从方程中更容易算出该数字是否大于 10 还是小于 10。由于 f(5/2) = 1/4(14 - 5√3) > 0，很明显 x₀ > 5/2，即 4x₀ > 10。让我们证明该方向上的距离 AC 小于 10。事实上，对于 2 < x₀ < 8，不等式 √8² + (4x₀ - 8)² < 10 相当于： (4x₀ - 8)² < 36, 4x₀ - 8 < 6, x₀ < 7/2。如上所述，我们确信 f(7/2) = 1/4(22 - 21√3) < 0，因此 x₀ < 7/2，因此 AC < 10。

这个问题的解决方案是由来自托木斯克的 M. Preezer、来自 Ekibastuz 的 A. Mikhailov 和其他读者发送给我们的。
