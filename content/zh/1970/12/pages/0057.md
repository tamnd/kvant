3. 质量体$m$以加速度$a$垂直运动。确定 $F$ 作用在身体上的力。

答案：
1) $F = m(g + a)$;
2) $F = m(g - a)$;
3) $F = m \frac{ga}{g + a}$.

4. 两个焦距为 $F_1$ 和 $F_2$ 的镜头并排放置 (图 8)。确定此类系统的焦距。

答案：
1) $F = F_1 + F_2$;

2) $F = \frac{F_1 F_2}{F_1 + F_2}$;
3) $F = \frac{F_1 F_2}{F_1 - F_2}$.

5. 两个半径为 $R_1$ 和 $R_2$ 的带电球彼此之间的距离远大于它们的半径。球的电荷分别为 $q_1$ 和 $q_2$。求球与导线连接后的电荷$q'_1$、$q'_2$以及球的电势f。

答案：
1) $q'_1 = q_1 \frac{R_1}{R_2}$; $q'_2 = q_2 \frac{R_2}{R_1}$;
$\varphi = \frac{(q_1 - q_2)}{R_1 + R_2}$.
2) $q'_1 = \frac{(q_1 + q_2) R_1}{R_1 - R_2}$;
$q_2 = -\frac{(q_1 + q_2) R_2}{R_1 - R_2}$;
$\varphi = \frac{q_1 + q_2}{R_1 - R_2}$.
3) $q'_1 = \frac{(q_1 + q_2) R_1}{R_1 + R_2}$;
$q'_2 = \frac{(q_1 + q_2) R_2}{R_1 + R_2}$;
$\varphi = \frac{q_1 + q_2}{R_1 + R_2}$.
