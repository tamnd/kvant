我记得有这样一个案例。学生被要求解一个看似无害的方程：
$(a^2 - 5a + 6)x = a^2 - 4$. (1)
学生没有多想，继续进行如下计算：
$$x = \frac{a^2 - 4}{a^2 - 5a + 6} = \frac{(a - 2)(a + 2)}{(a - 2)(a - 3)};
x = \frac{a + 2}{a - 3}.$$ (2)
他显然没有考虑到给定的方程包含参数$a$，并且带有参数的方程本质上是一组方程。因此，我们的$a = 0$方程采用$6x = -4$形式，$a = 1$采用$2x = -3$形式，等等。换句话说，给参数一个特定的数值后，我们从方程组中选择一个——与所选参数值相对应。但解决方案取决于参数。
我们已经说过，对于$a = 0$，方程（1）采用$6x = -4$的形式。该方程的根是值 $x = -\frac{2}{3}$。但根据式（2）和$a = 0$我们得到$x = -\frac{2}{3}$。
对于 $a = 1$，方程 (1) 采用 $2x = -3$ 形式，因此为 $x = -\frac{3}{2}$。但根据式（2）和$a = 1$我们得到$x = -\frac{3}{2}$。
如果这种情况发生在任何主动知识$a$上，那么可以说公式（2）决定了方程（1）的解。但事实并非如此。
让我们输入$a = 2$。等式(1)变为$0 \cdot x = 0$。该方程的根是任意实数，而公式（2）在这种情况下给出$x = -4$。
对于$a = 3$，方程(1)采用$0 \cdot x = 5$的形式。该方程无解。然而，表达式$\frac{a + 2}{a - 3}$对于$a = 3$来说没有意义。
因此，不可能断言参数的任何值都为 $x = \frac{a + 2}{a - 3}$。
事实上，有必要进行如下推理。在将方程（1）两边除以未知数的系数之前，让我们看看对于某些参数值，该系数是否会变为零。我们注意到三项式$a^2 - 5a + 6$在$a = 2$、$a = 3$处消失。这意味着我们需要单独考虑这些情况，我们已经这样做了。如果$a \neq 2$，$a \neq 3$，那么我们可以将方程两边同时除以$x$的系数，得到$x = \frac{a + 2}{a - 3}$。结合获得的结果，我们写下
答案：如果$a = 2$，则$x$是任意实数；
如果$a = 3$，则无解；
如果$a \neq 2$，$a \neq 3$，则$x = \frac{a + 2}{a - 3}$。
