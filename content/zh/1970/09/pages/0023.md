在哪里
$$x_{1,2} = \frac{1-a \pm \sqrt{2a-3a^2}}{2}.$$

两者都找到了参数 $a$ 所有允许值的根（即，对于满足不等式 $0 \leq a \leq \frac{1}{2}$ - 参见 图 1 的所有$a$）都是实数。事实上，$0 \leq a \leq \frac{2}{3}$的判别式$D = 2a-3a^2 \geq 0$；这意味着，$D \geq 0$ 和 $0 \leq a \leq \frac{1}{2}$ 更是如此。

现在我们需要找出找到的值是否满足条件$x \geq 0$，$x+a \leq \frac{1}{2}$。

让我们首先检查条件$x+a \leq \frac{1}{2}$是否满足。我们有
$$x_1+a = \frac{1-a-\sqrt{2a-3a^2}}{2} + a = \frac{1+a-\sqrt{2a-3a^2}}{2}.$$
解决不平等问题
$$\frac{1+a-\sqrt{2a-3a^2}}{2} \leq \frac{1}{2},$$
我们得到$0 \leq a \leq \frac{1}{2}$。这意味着参数 $a$ 的所有允许值都为 $x_1+a \leq \frac{1}{2}$。

下一个，
$$x_2+a = \frac{1-a+\sqrt{2a-3a^2}}{2} + a = \frac{1+a+\sqrt{2a-3a^2}}{2}.$$
不等式
$$\frac{1+a+\sqrt{2a-3a^2}}{2} \leq \frac{1}{2}$$

仅在$a = 0$执行。但对于$a = 0$，我们有$D = 0$和$x_1=x_2 = \frac{1}{2}$。

两个找到的根的非负性的证明留给读者。

答案：如果$0 \leq a \leq \frac{1}{2}$，则$x = \frac{1-a-\sqrt{2a-3a^2}}{2}$；

如果$a < 0$或$a > \frac{1}{2}$，则无解。

请注意，在求解所考虑的方程时，ODZ 的干燥是有用的。自然而然地出现了一个问题：什么时候应该做出这样的澄清？

如果我们进行一个变换，得到一个与前一个方程等价的方程，那么在 ODZ 的情况下，当然就不需要了。否则它是有用的。例如，当对方程的两个部分进行平方（或任何偶次方）时，就会出现这种情况，这就是我们在所考虑的示例中遇到的情况。

一些例子
示例 1*)。解方程
$$\frac{\sqrt{a+x}}{a} + \frac{\sqrt{a+x}}{x} = \sqrt{x}.$$
解决方案。 ODZ 由方程 $x > 0$、$a+x \geq 0$、$a \neq 0$ 确定（顺便说一句，从这里开始，方程在 $a = 0$ 处无解）。让我们将方程转换为形式
$$(a+x)^{3/2} = ax^{3/2}.$$
让我们干燥 ODZ：从最后一个方程的非负部分和方程 $x > 0$、$a \neq 0$ 可以得出 $a > 0$。

接下来我们得到：$a+x = a^{2/3}x$，从$x (a^{2/3}-1) = a$。
对于$a = 1$，有非常/没有解决方案。若$a \neq 1$，则
$$x = \frac{a}{a^{2/3}-1}.$$
