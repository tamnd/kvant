给定参数$a$（$a > 0, a \neq 1$）的值，满足条件$x > 0$（从中显然可以得出满足第二个条件$a + x \geq 0$）。

不等式$\frac{a}{a^{2/3} - 1} > 0$仅适用于$a > 1$（考虑到$a > 0$）。因此，并非对于 $a$ 的所有允许值，找到的根都适合。

答案：如果$a > 1$，则$x = \frac{a}{a^{2/3} - 1}$；如果$a \leq 1$，则无解。

示例 2：求解方程
$$\log_9 x + \log_9 \frac{2 - x}{2} = \log_9 \log_9 p.$$

解决方案。 ODZ 由不等式 $0 < x < 2$、$p > 1$ 确定（在 图 2 处，该区域为深红色）。求解方程，我们一致得到
$$\frac{x(2 - x)}{2} = \log_9 p,$$
$$x^2 - 2x + 2\log_9 p = 0,$$
$$x_{1,2} = 1 \pm \sqrt{1 - 2\log_9 p}.$$

$p \leq 3$ 满足条件$1 - 2\log_9 p \geq 0$，考虑到 ODZ，得出$1 < p \leq 3$。有了这样的$p$，根将是实数。在$p > 1$，满足不等式$\log_9 p > 0$，然后满足$1 - 2\log_9 p < 1$。由此可见，对于$1 < p \leq 3$，不等式$0 < x_{1,2} < 2$成立。

答案：如果$1 < p \leq 3$，则$x_{1,2} = 1 \pm \sqrt{1 - 2\log_9 p}$；对于剩余的$p$，没有解决方案。

评论。从方程（6）我们得到$p = 9^{\frac{x(2 - x)}{2}}$。该函数的图形绘制在 图 2 上，清楚地表明条件 $0 < x < 2$ 在 $1 < p \leq 3$ 得到满足。

示例 3：求解方程
$$\frac{a + \sin x}{a \cos x + 1} = \frac{a + \cos x}{a \sin x + 1}.$$

解决方案。我们首先考虑$a = 0$的情况。给定方程的形式为 $\sin x = \cos x$，因此为 $x = \frac{\pi}{4} + \pi n$ ($n = 0, \pm 1, \ldots$)。

现在让$a \neq 0$。然后 ODZ 由以下方程确定
$$\cos x \neq -\frac{1}{a}; \sin x \neq -\frac{1}{a}.$$

让我们将给定的方程转换为 $(\sin x - \cos x)[a^2 + a(\sin x + \cos x) + 1] = 0$ 的形式。最后一个属性方程是以下方程组：
$$a^2 + a(\sin x + \cos x) + 1 = 0,$$
$$\sin x - \cos x = 0.$$

求解集合(7)的第一个方程，我们得到：
$$a\sqrt{2}\sin(x + \frac{\pi}{4}) = -a^2 - 1$$
及以后
$$\sin\left(x + \frac{\pi}{4}\right) = -\frac{a^2 + 1}{a\sqrt{2}}.$$

最后一个方程无解，因为对于任意 $a \neq 0$ 都有 $\left| -\frac{a^2 + 1}{a\sqrt{2}} \right| > 1$。事实上，假设 $\frac{a^2 + 1}{|a|\sqrt{2}} \leq 1$；改变这种不平等，我们得到
$$a^2 + 1 \leq |a|\sqrt{2}, (a^2 + 1)^2 \leq 2a^2,$$
$$a^4 + 1 \leq 0.$$

最后一个不等式是不正确的。
