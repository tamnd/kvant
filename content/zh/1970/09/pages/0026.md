几何有助于代数

当求解带有参数的方程时，各种几何考虑因素可能对尺度有用。例如，考虑方程

$$\sqrt{x(2a-x)} = 1 - x \text{ при } a > 0.$$

方程的哪个解可以解释为直线$y = 1 - x$与半圆交点的横坐标

$$y = \sqrt{x(2a-x)}, \text{ или}$$
$$(x - a)^2 + y^2 = a^2; \text{ у} \geq 0$$

半径 $a$，以点 $(a, 0)$ (图 3) 为中心。半圆的位置及其半径随着参数$a$的变化而变化。在 图 3 上，可以清楚地看到，对于 $a$ 的某些值，半圆不与线 $y = 1 - x$ 相交（半圆位于线下方），对于其他值 $a$，半圆与线相交于两点（半圆位于中间头部区域），对于第三个值 $a$，半圆与线相交于一点（半圆位于红色区域或上方），对于 $a$ 的某些值，半圆接触线（分隔头部和棕色区域的半圆）。

让我们考虑半圆接触直线$y = 1 - x$的情况。从几何角度考虑，该半圆的圆心距直线$y = 1 - x$与横坐标轴的交点的距离等于$a\sqrt{2}$。因此$a + a\sqrt{2} = 1$，即相切的情况发生在$a = \sqrt{2} - 1$。这意味着在$a < \sqrt{2} - 1$处方程没有解（蓝色区域），但在$a = \sqrt{2} - 1$处它有一个唯一解，这是从几何考虑中找到的：$x = a + \frac{a\sqrt{2}}{2}$（参见图3），从中我们得到$x = \frac{\sqrt{2}}{2}$。

在图3处经过点$(1, 0)$的半圆对应于参数$a = \frac{1}{2}$的值。这意味着对于 $\sqrt{2} - 1 < a \leqslant \frac{1}{2}$ 方程有两个解：

$$x_1 = \frac{a + 1 - \sqrt{a^2 + 2a - 1}}{2},$$
$$x_2 = \frac{a + 1 + \sqrt{a^2 + 2a - 1}}{2}$$

（使用给定方程的代数解找到根）。最后，如果$a \geqslant \frac{1}{2}$，则方程有唯一解$x = x_1$（自$x_1 < x_2$）。
