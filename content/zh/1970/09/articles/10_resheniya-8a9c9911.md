M6。你面前有一个时钟。除非知道哪只手是时针、哪只手是分针，否则有多少指针位置无法用来确定时间？
（人们相信每个箭头的位置都可以准确确定，但无法根据箭头的移动方式确定。）

回答。这样的职位有132个。换句话说，有 66 对指针排列，其中每一对中的一种排列是通过用分针替换时针、用时针替换分针来获得的（如图1）；当然，当时针和分针的方向一致时，不考虑这样的位置：在这些情况下，时间是明确确定的。

**M7.** a、b、c 是三角形的边。

证明$\frac{a}{b+c-a} + \frac{b}{c+a-b} + \frac{c}{a+b-c} \geq 3$。

解决方案。这个问题有很多解决方案。我们将给出最短的之一。我们只需要学校课程中众所周知的不平等
$$\frac{m}{n} + \frac{n}{m} \geq 2,$$
(1)

其中$m > 0, n > 0$。

让我们引入以下符号：
$$b + c - a = x,$$
$$c + a - b = y,$$
$$a + b - c = z.$$

注意
$$x > 0, y > 0, z > 0;$$
(3)
这是因为$a, b, c$是三角形的边，并且每条边都小于其他两条边的总和（不幸的是，从发送给编辑的信中可以看出，大多数解决该问题的人甚至没有考虑他们在哪里使用$a, b, c$是三角形的边这一事实）。

由(2)可知
$$a = \frac{y+z}{2}, \quad b = \frac{x+z}{2}, \quad c = \frac{x+y}{2};$$

最初的不等式可能可以重写如下：
$$\frac{y+z}{2x} + \frac{x+z}{2y} + \frac{x+y}{2z} \geq 3.$$

对(4)的左侧进行变换并使用(1)和(3)，我们得到
$$\frac{y+z}{2x} + \frac{x+z}{2y} + \frac{x+y}{2z} =
= \frac{1}{2} \left[ \left( \frac{y}{x} + \frac{x}{y} \right) + \left( \frac{z}{x} + \frac{x}{z} \right) +
\left( \frac{z}{y} + \frac{y}{z} \right) \right] \geq \frac{1}{2} (2 + 2 + 2) = 3,
$$
这就是所需要的。

请注意，可以类似地证明更一般的不等式：
$$\frac{x_1}{x_2 + x_3 + \dots + x_n - x_1} +
\frac{x_2}{x_3 + x_4 + \dots + x_n + x_1 - x_2} + \dots +
\frac{x_{n-1}}{x_n + x_1 + x_2 + \dots + x_{n-2} - x_{n-1}} +
\frac{x_n}{x_1 + x_2 + \dots + x_{n-1} - x_n} \geq \frac{n}{n-2},$$

其中所有分母都是正数。

总之，我们注意到一个几何事实直接来自已证明的不等式。设 $R$ 为三角形外接圆的半径，$r$ 为三角形内切圆的半径。很高兴知道这一点
$$R = \frac{abc}{4S}, \quad r = \frac{S}{p},$$
(5)

$$S = \sqrt{p(p-a)(p-b)(p-c)},$$

其中$S$是三角形的面积，$p$是它的半周长。由(2)可知
$$p - a = \frac{x}{2},$$
$$p - b = \frac{y}{2},$$
$$p - c = \frac{z}{2}.$$

现在，使用（5）和（6），我们得到
$$\frac{R}{2r} = \frac{abcp}{8S^2} = \frac{abcp}{8p(p-a)(p-b)(p-c)} =
= \frac{abc}{(a+b-c)(b+c-a)(c+a-b)} =
= \frac{(x+y)(y+z)(z+x)}{8xyz} =
= \frac{1}{4} \left[ 1 + \left( \frac{y+z}{2x} + \frac{x+z}{2y} + \frac{x+y}{2z} \right) \right].$$

请注意，不等式 (4) 的左侧位于最后一个等式右侧的括号中。使用它，我们得到
$$\frac{R}{2r} \geq 1,$$
即$R \geq 2r$。

因此，三角形的外接圆的半径不小于三角形的内切圆的直径。尝试证明这个几何数（这要困难得多）。

F7。长度为 $l$ 的水平杆$O_1A$ 绕垂直轴$O_1$ (图 3) 旋转。半径为 $r$ 的轮子安装在连杆$A$ 末端的轴上。轮轴水平，与杆成$\alpha$角$O_1A$。车轮在其轴上无摩擦地旋转并沿地面滚动。车轮和土壤之间有更多的沟槽。当杆$O_1A$绕垂直轴转一圈时，轮子会转多少圈？

解决方案。如果您将位于杆 $O_1A$ 末端 $A$ 的可观察量进行推理，则解决问题是最简单的。如果杆$O_1A$相对于地面的旋转角速度等于$\Omega$，那么观察者会说，在他的坐标系中，杆是静止的，而地球绕轴$O_1$以等于$\Omega$的角速度旋转，方向与杆相对于地球的旋转方向相反。轮子接触地球的点的速度大小等于$v = \Omega l$，并且方向垂直于杆$O_1A$。让我们将该速度分解为两个分量：$v_1 = v \cos \alpha$和$v_2 = v \sin \alpha$，分别对应于车轮的平行平面和垂直平面。很明显，由于轮子在土壤上的摩擦力很大，因此轮子接触地面的点相对于点 $A$ 移动，因此轮子的轴以速度 $v_1$ 移动。这意味着轮子绕其轴以 $\omega = \frac{v_1}{r} = \Omega \frac{l}{r} \cos \alpha$ 的角速度旋转。

图 4.

杆和轮绕其轴线的旋转角度之比等于杆和轮的相对旋转角速度。因此，当杆$O_1A$绕轴$O_1$转一圈时，轮子将绕其轴$n = \frac{\omega}{\Omega} = \frac{l}{r} \cos \alpha$转。

F8。将末端带有螺纹孔的长杆 $AB$ 拧到垂直螺钉 (图 4) 上。杆被释放。螺杆和杆之间的间隙可以忽略不计。杆脱离螺钉后将如何移动？

解决方案。当杆飞离螺杆的瞬间，其质心（重心）的速度将同时具有垂直和水平分量。由于从此时起作用在杆上的唯一力将是重力的合并，因此杆的质心将沿着抛物线移动 - 与地平线成一定角度的物体的轨迹，其初始速度等于杆飞离螺旋桨时杆的质心的移动速度。但在杆飞离螺杆的瞬间，杆的不同点具有不同的水平速度。因此，杆也会在水平面内绕质心旋转。

F9。在水平桌子上，有一个使用长弹簧连接到桌子上的重物。起初弹簧没有被拉伸。然后重物从平衡位置移动20厘米并释放。重物开始沿着弹簧摆动。由于摩擦，其振荡幅度在此期间下降了 7%。重量在停止前会振动多少次？它会在距平衡位置多远的地方停止？

解决方案。如果恒定的外力作用在振动垫上，则会改变振动垫的平衡位置。例如，如果我们将附着在弹簧上且在水平面内无摩擦地移动的负载的振动与同一系统在垂直面内的振动进行比较，当负载沿着其运动线受到重力作用时，我们会发现，在第二种情况下，负载的平衡位置将远离弹簧的固定端，距离为$x = \frac{mg}{k}$，其中$k$是弹簧刚度系数，$m$是弹簧刚度系数。大量货物 在这种情况下，两种情况下负载的振荡周期将相同。

恒定外力对马特尼克的作用不会改变马特尼克的振荡周期，也不会导致其振荡阻尼，因为外力作用的位置会减少马特尼克的能量，而第二个正周期会增加相同量的马特尼克的能量。当在我们的例子中，作用在垫子上的力仅在每个周期内保持恒定并且通过偏光镜沿相反方向时，则是另一回事。在这种情况下，垫子的振动被阻尼，因为当负载移动时，作用在其上的力总是指向与其移动方向相反的方向。此外，负载振荡的每个极化曲线都发生在不同的平衡位置附近。当负载移动时，表示平衡位置 - 这是点 $A$ (图 5)，因为作用在负载上的摩擦力是有方向的

图 5.

向左移动（与悬挂在弹簧上的负载的振荡相比），并且当向左移动时 - 点$B$。

很明显，点 $A$ 和 $B$ 与点 $O$（弹簧未变形时的负载位置）的距离相同。该距离是根据弹簧拉力$F = k \Delta x$（$\Delta x$为弹簧变形）和作用在负载上的摩擦力相等的条件求得：$k \Delta x = F_{\text{тр}}$。从这里

$$a = AO = OB = \Delta x = \frac{F_{\text{тр}}}{k}.$$

负载的振荡不能限制在点 $A$ 和 $B$ 之间的区域，因为在此区域中弹簧张力不会超过最大可能的摩擦力。因此，如果该区域中每一点的负载速度都为零，则负载将保持不变：弹簧的张力将由摩擦力平衡。

如果负载从点 $O$ 向右偏转，则用字母 $y_n$ 表示负载第 $n$ 次振荡的振幅（负载相对于点 $O$ 的偏差），如果负载从点 $O$ 向左偏转，则用 $x_n$ 表示。 $y_0 = 20$ cm 是负载的初始挠度。根据条件

$$\frac{y_0 - y_1}{y_0} = 0.07.$$

让我们找出负载振动幅度的变化规律。负载移动时系统能量的变化等于摩擦力所做的功，因此，利用变形弹簧能量$W = \frac{k(\Delta x)^2}{2}$的公式，我们可以写出：

$$\frac{k y_n^2}{2} - \frac{k x_n^2}{2} = F_{\text{тр}}(y_n + x_n)$$

和

$$\frac{k x_n^2}{2} - \frac{k y_n^2}{2} = F_{\text{тр}}(x_n + y_n+1).$$

将第一个方程两边同时除以$y_n + x_n$，我们得到$y_n - x_n = 2 \frac{F_{\text{тр}}}{k}$。类似地，从第二个方程我们得到$x_n - y_n+1 = 2 \frac{F_{\text{тр}}}{k}$。将所得方程相加，我们发现

$$y_n - y_n+1 = 4 \frac{F_{\text{тр}}}{k}$$

(9)

但$\frac{F_{\text{тр}}}{k} = a$，因此$y_0 - y_1 = y_1 - y_2 = \dots = y_n - y_{n+1} = 4 a$。 (10)

在此期间负载振荡的幅度减小相同的量，等于4a。将差值代入式(7) $y_0 - y_1$ 等差 $y_n - y_{n+1}$，我们得到了 $\frac{y_n - y_{n+1}}{y_0} = 0,07$，或者在此期间负载的振荡幅度减小 $0,07 y_0 = 1,4$ 厘米。通过 $n$ 振荡变得相等 $y_n = y_0 - n \cdot 0,07 y_0$。在这种情况下，正如我们已经说过的，负载的振荡幅度不能小于 $a$。因为，根据式（7）和（10）， $4a = y_0 - y_1 = 0,07 y_0 = 1,4$ 厘米，那么 $a = 0,35$ cm.

从条件$y_n \geq a$或$20(1 - 0,07n) \geq 0,35$我们得到$n \leq 14,04$。 $n$是一个整数。因此，负载将进行14次完整的振荡。

因为，$y_{14} = 20(1 - 0,07 \cdot 14) = 0,4$厘米，即$y_{14} > a$，并且负载位于点$A$和$B$之间的区域之外。因此，作用在负载上的拉力大于摩擦力，负载将进行另一部分振荡，停在距点$O$距离$y$处。而且，负载无法达到点$O$。向左移动时，其平衡位置为$B$点，负载向$B$点偏离的距离不能大于$y_{14} - a \approx 0,5$厘米。

令负载停止前行驶的距离等于$y_{14} - y$。负载停止时系统的能量为$\frac{k y_n^2}{2}$。将摩擦力做功的系统之间的能量差等同起来，我们得到方程$\frac{k y_{14}^2}{2} - \frac{k y_n^2}{2} = F_{\text{тр}}(y_{14} - y)$。将该方程除以非零差值$y_{14} - y$，我们得到$ky_{14} + ky = 2F_{\text{тр}}$。因此$y = 2 \frac{F_{\text{тр}}}{k} - y_{14} = 2a - y_{14} = 0,3$厘米。

F10。如何用四个电阻为 $10 \text{ om}$、$20 \text{ om}$、$30 \text{ om}$ 和 $40 \text{ om}$ 的细螺旋线构造出尽可能高功率的加热器，如果存在电流源，每个螺旋线可释放不超过 $2 \text{ om}$ 的功率。 d.s. $20 \text{ b}$ 和内阻$20 \text{ om}$？

已解决。我们首先证明，外电路释放的功率越大，负载电阻越接近电源的内阻。

由与 e 串联的电源组成的电路中的电流。 d.s. $\varepsilon$和内阻$r$以及负载电阻$R$，等于$\frac{\varepsilon}{R + r}$。因此，分配给负载的功率为$W = \frac{\varepsilon^2}{(R + r)^2} R$。

让我们画一个$W$对负载电阻$R$的依赖关系图。在$R = 0$、$W = 0$；与 $R$ 相比，使用 $R \rightarrow \infty$ 可以在重大问题上击败 $r$。然后$W \approx \frac{\varepsilon^2 R}{R^2} = \frac{\varepsilon^2}{R}$。

也就是说，对于大的$R$（$R \gg r$），$W$对$R$的依赖图是双曲线，征兆正在逼近$R$轴。由于函数 $W(R)$ 是连续的，在 $R = 0$ 处等于 0，在 $R \rightarrow \infty$ 处递减，因此它必须有一个最大值。我们去找他吧。

⟦folio 56⟧

当逆表达式$\frac{(R + r)^2}{\varepsilon^2 R}$最小时，表达式$\frac{\varepsilon^2 R}{(R + r)^2}$最大。但是$\frac{(R + r)^2}{\varepsilon^2 R} = \frac{1}{\varepsilon^2} \times \frac{R^2 + 2Rr + r^2}{R} = \frac{2}{\varepsilon^2} r + \frac{1}{\varepsilon^2} \left( R + \frac{r^2}{R} \right)$。

当表达式 $R + \frac{r^2}{R}$ 最小时，该表达式也最小。

既然$R + \frac{r^2}{R} \geq 2\sqrt{R \cdot \frac{r^2}{R}}$（两个数字$R$和$\frac{r^2}{R}$的论证平均值与几何平均值之间的对应关系），那么$R + \frac{r^2}{R} \geq 2r$。因此，总和$R + \frac{r^2}{R}$的最小值为2r，并在$r = R$处达到。

因此，负载处释放的功率在$R = r$处最大。 $W(R)$的图形如图6所示。从图中可以看出，当$R$增加到$r$时，$W(R)$变大。这意味着线圈需要构建成电阻尽可能接近 20 欧姆的加热器。仅使用电阻为20欧姆的螺旋是不可能的，因为它会释放$W = \left( \frac{\varepsilon}{R + r} \right)^2 R = 5 \text{ ом}$的功率，并且每个螺旋被设计为释放不超过2欧姆的功率。

在所有可能的螺旋连接方案中，最好的方案是图7。这种加热器的电阻为20欧姆，在加热器中释放$W = \left( \frac{20}{20 + 20} \right)^2 20 = 5 \text{ ом}$功率。很容易算出，在电阻为20欧姆的螺旋上释放的功率最大，等于1.8欧姆。

来自雅罗斯拉夫尔的 L. Voronov 为这个问题提供了一个非常好的解决方案。在应用问题的解决中，他考察了效率如何依赖的问题。电气装置免受负载电阻的影响。

由于电源提供的功率等于$\varepsilon I = \frac{\varepsilon^2}{R + r}$，而我们获得的有用功率等于$\frac{\varepsilon^2 R}{(R + r)^2}$，那么，用$\alpha$表示比率$\frac{R}{r}$，我们可以得到效率$\eta$的以下表达式：

$$\eta = \frac{R}{R + r} = \frac{\alpha}{1 + \alpha}.$$

当电路中流过小电流时，在高负载电阻下效率较大。在$\alpha = 0, \eta = 0$；在$\alpha \rightarrow \infty, \eta \rightarrow 1$。在 $\alpha = 1$ 时，当最大功率释放到加热时，$\eta = 0,5$ (50%)。当然，在这种情况下，源本身释放的功率与加热时释放的功率相同。源头变成了火炉。

解决了并且e。管道系统将像虹吸管一样工作。水将从顶部桶流到中部和底部。另外，水会从中间的桶流到底部的桶。由于水流通过虹吸管的速度与容器内的水位差成正比，因此，当中桶的水位比上桶的水位更接近下桶的水位时，从上桶流入中桶的水多于从中桶流向下桶的水。在这种情况下，下桶和中桶都是水平的。如果中间桶的水位比底部的水位更接近顶部的水位，则由于水从顶部和中间的桶流动，只有底部的桶被注满。
