MIEM 考试

在本文中，我们将讨论莫斯科电子工程学院 (MIEM) 的数学入学考试。

与大多数技术学校一样，申请者要参加两项数学考试：笔试和口试。书面作业时间为 4 小时（4×60 分钟）。

请注意，所有提出的问题和任务均不会超出批准的入学考试计划。

下面我们列出了 1969 年提供的各种笔试版本中的问题，指出了申请人最常犯的错误。

选项0

1. 摩托车手和自行车手同时从 A 点和 B 点向对方行驶，在距离 AB 中心 12 公里处相遇。摩托车骑手的速度比自行车骑手的速度高32公里/小时。如果骑摩托车的人晚一个小时离开，他们就会在半路上相遇。求距离AB。

2. 解方程
$$x = a - \sqrt{a^2 - x \sqrt{x^2 + a^2}}.$$

3. 解决不平等问题
$$\log_{\sqrt{3}} \frac{\sqrt{27}}{\arctg x} \cdot \log_{\sqrt{3}} \arctg x > 2.$$

4. 解方程
$$\sin \sqrt{4 + 3x - x^2} + \cos \sqrt{4 + 3x - x^2} = \sqrt{2}.$$

5. 半径为 R 和 r 的两个圆的圆心位于直角三角形的斜边上。一个圆圈接触两条腿，另一个圆圈接触腿和第一个圆圈。找出三角形的边。

让我们提出这些问题的解决方案。

1. 我们用x表示speedster的速度，用2S表示speedster AB的速度；那么摩托车手的速度就是x+32。如果摩托车手在会面之前花费的时间等于t，那么从问题的条件我们得到
$$xt = S - 12,$$
$$(x + 32)t = S + 12.$$

如果动机iklist 晚一个小时离开，他会在会议前花费 $t_1$ 小时，而动机iklist 会花费 $(t_1-1)$ 小时，因此
$$(x + 32)t_1 = S,$$
$$x(t_1+1) = S.$$

求解这个系统，我们得到$S=48$公里。

事实证明，这项任务对于申请人来说很容易。绝大多数的申请者都解决了这个问题。然而，许多繁琐的方程组都是由于符号选择不当造成的。

从这里
$$x_1 = 0$$ 和 $2a - x = \sqrt{x^2 + a^2}$。

当执行变换（平方）时，我们可能会违反等价性，因此必须检查找到的根$x_1, x_2, x_3$。

1) $x_1 = 0$。我们将值 $x_1$ 代入原方程。那么左边就是0，右边就是：
$$a - \sqrt{a^2} = a - |a| = \begin{cases} 0 & \text{при } a \geq 0, \\ 2a & \text{при } a < 0. \end{cases}$$

2) 若$a = 0$，则等式左边为$x$，右边为：
$$- \sqrt{-x \sqrt{x^2}} = -\sqrt{-x |x|} = \begin{cases} -\sqrt{-x^2} & \text{при } x > 0, \\ -\sqrt{x^2} & \text{при } x \leq 0. \end{cases}$$

3) 将值$x_3 = \frac{3}{4} a$代入，我们发现左侧等于$\frac{3}{4} a$，右侧为：
$$a - \sqrt{a^2 - \frac{3}{4} a \sqrt{\frac{9}{16} a^2 + a^2}} = \begin{cases} a - \sqrt{\frac{a^2}{16}} = \frac{3}{4} a & \text{при } a > 0, \\ a - \sqrt{\frac{31 a^2}{16}} + a + \frac{a \sqrt{31}}{4} & \text{при } a < 0. \end{cases}$$

回答。若$a > 0$，则$x_1 = 0$，$x_3 = \frac{3}{4} a$；如果$a = 0$，则$x \leq 0$。

申请人在求解这个方程时犯的一个更典型的错误是没有检查$x_1, x_2, x_3$的发现值。当使用上述方法求解该方程时，验证是解决问题的一个组成部分。

3. 表示$\log \sqrt{3}$ arcctg $x = t$，我们得到$t^2 - 3t + 2 < 0$，因此$1 < t < 2$。
回到变量$x$，我们可以写
$$\sqrt{3} < \text{arcctg} x < 3$$
我们得到答案：$\text{arcctg} 3 < x < \text{arcctg} \sqrt{3}$。

4. 要求$4 + 3x - x^2 \geq 0$给我们$-1 \leq x \leq 4$。

现在，将加法公式应用到左侧，我们得到
$$\sqrt{2} \sin \left(\sqrt{4 + 3x - x^2} + \frac{\pi}{4}\right) = \sqrt{2},$$
在哪里
$$\sqrt{4 + 3x - x^2} = \frac{\pi}{4} + 2\pi n.$$
这意味着$n \geq 0$是必要的。

解这个无理方程，我们得到
$$x = \frac{3 \pm \sqrt{25 - 4 \left(2\pi n + \frac{\pi}{4}\right)^2}}{2};$$
从这里
$$\left(2n\pi + \frac{\pi}{4}\right)^2 = \frac{25}{4}.$$
因此，$n = 0$和$x_{1,2} = \frac{6 \pm \sqrt{100 - \pi^2}}{4}$。

通过检查我们可以很容易地验证这两个值都是方程的根。

在求解这个方程时，许多人得到了等式（1），但只有部分对该方程的构造研究留下了对应于$n = 0$的解。

最后，我们提出了 1969 年入学考试中提供的一些书面作业选项。

选项1

1. 两名游客同时朝同一个方向离开这座城市。第一个游客每公里的行程都比第二个游客快 20 分钟。第一个游客走了一段路后折返，走了1公里后又往同一个方向走。当第一个游客追上第二个游客时，第二个游客已经走了 0.5 小时。第一个游客步行 1 公里需要多少分钟？

2. 解方程

$$\sin \sqrt{4 + 3x - x^2} + \cos \sqrt{4 + 3x - x^2} = \sqrt{2}.$$

3. 解决不平等问题

$$\frac{\log_2(x^2 - 3x - 4)}{\log_2(x + 17)} \leq 1.$$

4. 解决不平等问题

$$\sin^2 2x (\text{ctg} x - \text{tg} x) > 2 \cos 2x.$$

5. 三角形帕拉酰胺的侧边相互垂直。 paramid的高度为$h$。求围绕 paramid 外接的球体的半径。

选项2

1. 两名挖掘机的任务是在 3 小时 36 分钟内挖一条沟渠。然而，第一个开始工作时，第二个已经挖了一半，就停止了挖掘。结果，7.5小时就把沟挖好了。每个挖掘机需要多少小时才能挖一条沟渠？

2. 解方程

$$\sqrt{3 + 2 \text{tg} x - \text{tg}^2 x} = \frac{1 + 3 \text{tg} x}{2}.$$

3. 解决不平等问题

$$\log_{\log_2} x \left( \log_2^2 x - \frac{7}{2} \log_2 x + \frac{45}{16} \right) < 1.$$

4. 解决不平等问题

$$\frac{\sqrt{2}}{2} \cos x - \cos^2 x}{4 \sin^2 x - 3} < 0.$$

5. 求正截角三角形Paramid的体积，如果其大于底边的边等于$a$，侧面与底平面形成的二面角等于$\pi/6$，Paramid的高度等于$a/12$。

选项3

1. 两辆自卸车需要在3小时20分钟内转移货物，但第二辆自卸车迟到了，当第一辆自卸车已经转移了总货物的2/5时才到达装货地点。此后，只有第二辆自卸车运载了剩余的货物。整个货物的运输耗时8个小时。每辆自卸车需要多少小时才能单独运输全部货物？

2. 解方程

$$\sqrt{\cos(\cos x)} = 1 - 2 \cos(\cos x).$$

3. 解决不平等问题

$$\log_{\frac{1}{3}} x \left( \log_2^2 x - 19 \log_{\frac{1}{3}} x + 84 \right) < 1.$$

4. 解决不平等问题

$$\frac{\sqrt{3}}{2} (\cos x - 1) + \sin^2 x}{4 \sin^2 x - 3} < 0.$$

5. 一个球被描述为从底面$a$ 的侧面靠近正三角形paramid 且侧边与底面平面的倾斜角$\alpha$ 。求其体积。

选项4

1. 两个数量同时从点 $A$ 和 $B$ 向彼此离开，并在 1.2 小时后相遇。如果第一个到达 $B$ 比第二个到达 $A$ 晚一个小时，他们每个人需要多少小时才完成$AB$ 的距离。

2. 解方程

$$|\cos 2x| = \left| \sin^2 x - \frac{1}{4} \right|.$$

3. 解决不平等问题

$$\log_{\frac{1}{2}} \frac{x^2 - 3x + 2}{4x - 10} < 0.$$

4. 解决不平等问题

$$\frac{1 + \sin \frac{x}{2} - \sqrt{3} \cos \frac{x}{2}}{4 + 4 \sin x + 2 \cos x + \sin 2x} > 0.$$

5. 在四边形帕拉米德的底部有一个菱形，边长为 $a$，锐角为 $\alpha$。所有侧面均与基面倾斜$\beta$角度。找到 paramid 的完整表面。
