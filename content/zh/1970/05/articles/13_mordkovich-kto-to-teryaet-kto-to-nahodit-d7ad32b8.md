我们如何解方程！基于这个方程，我们连续写出一个、另一个、第三个……——一系列方程，其中每个方程都是从一个或两个部分的先前变换中获得的，依此类推，直到我们得到一个完全简单的方程，我们已经知道如何找到其解。在这种情况下，如果从这个方程到下一个方程的所有转换都是“可逆的”，也就是说，我们看到第四个方程的变换可以通过第三个方程、从第三个方程到第二个方程的变换得到，等等，那么很明显，方程的最后一个过程与原来的方程具有相同的根。但我们经常遇到这样的带有根式、对数、三角函数的方程，其求解涉及到相当复杂的变换，因此“逆向过渡”并不十分清楚。如果在求解此类方程时，您只是公式化地进行变换，而不深入研究其含义，那么很容易犯错误：丢失一个根或添加一个额外的根。本文解释了这种情况是如何发生的以及如何避免此类问题。

1. 一些符号。

令数据为数字集$X$和$Y$。符号$X \subset Y$意味着集合$X$的每个元素同时是集合$Y$的元素，并且在$Y$中可能存在不属于集合$X$的元素。符号$x \in X$（分别为$x \in X$）表示元素$x$属于（不属于）集合$X$。

下面的条件和短语“集合$X$由所有实数$x$组成”也使用符号：$X = \{x| -\infty < x < \infty\}$。类似地，符号$X = \{x|x \ge 3\}$表示集合$X$由满足不等式$x \ge 3$的所有数$x$组成，符号$X = \{x|x \neq \pi\}$表示集合$X$包含除$x = \pi n^*$之外的所有实数）。

2. 第三方根源从何而来？

第一个原因是ODZ的扩大。求解方程时，不断应用各种变换。很多时候，通过某种变换从原始方程获得的方程的 OD 会比原始方程的 OD 更宽（术语“更宽的 OD”意味着 $X \subset Y$）。 ODZ 的扩展可导致永久根的出现。要点是，所得方程的根可能是集合 $Y$ 的元素，但不属于集合 $X$。对于原始方程，它们将是常数。

示例 1：求解方程
$$\frac{2}{2-x} + \frac{1}{2} = \frac{4}{2x-x^2}.$$
解决方案。我们首先写出方程（1）的ODZ：$X=\{x|x \neq 0;2\}$。简化为公分母，我们得到
$$4x+2x-x^2=8.$$

方程（2）已经有了另一个ODZ：$Y=\{x|-\infty < x < \infty\}$。解方程（2），得到两个根：$x_1=4$，$x_2=2$，其中$x_1 \in X$，$x_2 \in X$，因此$x_2$是方程（1）的常根。因此，方程（1）有一个单根$x=4$。

示例 2：求解方程
$$\lg (x^2+3x-4) = \lg (2x+2).$$
解决方案。解决了不平等制度
$$\begin{cases} x^2+3x-4 > 0, \\ 2x+2 > 0, \end{cases}$$
我们求出方程（3）的ODZ：$X=\{x|x > 1\}$。通过增强，我们将方程（3）转化为方程
$$x^2+3x-4=2x+2$$
ODZ 更宽：$Y=\{x|-\infty < x < \infty\}$。方程（4）有两个根：$x_1=2$、$x_2=-3$，以及$x_1 \in X$和$x_2 \in X$。这意味着 $x_2$ 是方程 (3) 的常根，因此方程 (3) 具有单根 $x=2$。

ODZ 的扩展有时是由于使用中学课程中已知的某些公式而导致的。这些是与对数、偶数根式以及某些特定性质相关的公式

$$\log_a f(x) + \log_a g(x) = \log_a [f(x) \cdot g(x)],$$
$$\frac{1-\cos x}{\sin x} = \tg \frac{x}{2}.$$

很容易看出，在右侧包含这些等式的函数比在左侧包含这些等式的函数具有更宽的定义域。

因此，函数$\log_a f(x)+\log_a g(x)$的定义域由不等式组确定
$$\begin{cases} f(x) > 0, \\ g(x) > 0, \end{cases}$$
而函数 $\log_a [f(x) \cdot g(x)]$ 的定义域由系统 (7) 的解和另一个不等式系统的解组成
$$\begin{cases} f(x) < 0, \\ g(x) < 0. \end{cases}$$

函数$\frac{1-\cos x}{\sin x}$的定义域是：$X=\{x|x \neq \pi n\}$。函数$tg \frac{x}{2}$有更广泛的定义范围：$X=\{x|x \neq \pi(2k+1)\}$。因此，求解方程时，“从左到右”使用式（5）、（6）等会导致常根的出现。

示例 3：求解方程
$$\frac{1-\cos x}{\sin x} + \tg^3 \frac{x}{2} = 0.$$

解决方案。让我们写出方程（8）的ODZ：$X=\{x|x \neq \pi n\}$。应用式（6），我们得到方程
$$tg \frac{x}{2} + \tg^3 \frac{x}{2} = 0$$

ODZ 更宽：$Y=\{x|x \neq \pi(2k+1)\}$。方程（9）的解就是$x=2\pi n$的值。所有这些值都不包含在方程（8）的ODZ中，因此是常根。因此，方程(8)无解。

3. 是什么原因导致断根？

第一个原因是 ODZ 缩小。还有一些变换会导致方程 OD 更窄。缩小 ODZ 会导致根丢失，即原方程中属于集合 $X$ 但不属于“较窄”集合 $Y$、$(Y \subset X)$ 的根可能会“丢失”。

例 6：解方程

$$\text{tg} \left( x + \frac{\pi}{4} \right) = 2 \text{ctg} x - 1.$$

解决方案。让我们将方程（12）转化为形式

$$\frac{\text{tg} x + \text{tg} \frac{\pi}{4}}{1 - \text{tg} x \cdot \text{tg} \frac{\pi}{4}} = \frac{2}{\text{tg} x} - 1.$$

代入$y = \text{tg} x$，我们得到$y$的代数方程，求解得到$y = \frac{1}{2}$，即$x = \text{arctg} \frac{1}{2} + \pi k$。

但验证使我们相信$x = \frac{\pi}{2} + \pi n$的值也满足方程（15）。我们什么时候失去了这些根？让我们比较方程（14）和（15）的 ODZ。 X 由 $x$ 的所有值组成，除了 $ctg x$ 和 $\text{tg} \left( x + \frac{\pi}{4} \right)$ 不存在的值。方法，

$$X = \left\{ x \mid x \neq \pi n, x \neq \frac{\pi}{4} + \pi n \right\}.$$

方程 (16) 的 ODZ - $Y$ - 由 $x$ 的所有值组成，除了 $ctg x = 0$、$\text{tg} x = 1$ 和 $\text{tg} x$ 不存在的值。方法，

$$Y = \left\{ x \mid x \neq \pi n, x \neq \frac{\pi}{4} + \pi n \right\}.$$

由此可知$Y \subset X$，即式(16)的ODZ比式(15)的ODZ窄。值$x = \frac{\pi}{2} + \pi n$属于集合$X$，但不属于原方程的根集合。

而不是结论

解方程时有哪些一般规则可以指导您？只有一种方法：有意识地而不是机械地求解任何方程，不要绕过任何可能出现构造根或丢失根的关键转变。在开始求解方程之前，写下定义 OD3 的所有约束很有用（它们甚至不必相对于未知数进行求解）；例如，求解式（3）时，只需写下条件：$x^2 + 3x - 4 > 0$和$2x + 2 > 0$即可；检查时，立即可以清楚地看到找到的根$x_2 = -3$之一不满足条件$2x + 2 > 0$。如果您必须进行可能出现构造根的转换，那么最后您需要进行检查，在这种情况下，这是问题解决方案的一部分，而不仅仅是额外的控制。有时，在求解过程中，将变量值集分成两个或多个部分并分别检查每个部分的方程是很方便的；例如，方程(14)在$60 - 3x < 0$处是完备的，无解，而在$60 - 3x \ge 0$处两边平方不会导致新根的出现，因为方程两边都是非负的（无关根$x_2 = 362$因不满足条件$60 - 3x \ge 0$而被自动消除）。

每个方程的解应该看起来像定理的证明，即给定的方程满足于那些且仅那些写在答案中的数字；以及转型过程中扎根和失根的“斗争”必须灵活。
