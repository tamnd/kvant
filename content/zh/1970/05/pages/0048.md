那么 $x_2 - \text{любое число},$ 如果 $a \neq 0$ 那么
$$x_2 = \frac{3}{4} a.$$

当执行变换（平方）时，我们可能会违反等价性，因此必须检查找到的根$x_1, x_2, x_3$。

1) $x_1 = 0$。我们将值 $x_1$ 代入原方程。那么左边就是0，右边就是：
$$a - \sqrt{a^2} = a - |a| = \begin{cases} 0 & \text{при } a \geq 0, \\ 2a & \text{при } a < 0. \end{cases}$$

2) 若$a = 0$，则等式左边为$x$，右边为：
$$- \sqrt{-x \sqrt{x^2}} = -\sqrt{-x |x|} = \begin{cases} -\sqrt{-x^2} & \text{при } x > 0, \\ -\sqrt{x^2} & \text{при } x \leq 0. \end{cases}$$

3) 将值$x_3 = \frac{3}{4} a$代入，我们发现左侧等于$\frac{3}{4} a$，右侧为：
$$a - \sqrt{a^2 - \frac{3}{4} a \sqrt{\frac{9}{16} a^2 + a^2}} = \begin{cases} a - \sqrt{\frac{a^2}{16}} = \frac{3}{4} a & \text{при } a > 0, \\ a - \sqrt{\frac{31 a^2}{16}} + a + \frac{a \sqrt{31}}{4} & \text{при } a < 0. \end{cases}$$

回答。若$a > 0$，则$x_1 = 0$，$x_3 = \frac{3}{4} a$；如果$a = 0$，则$x \leq 0$。

申请人在求解这个方程时犯的一个更典型的错误是没有检查$x_1, x_2, x_3$的发现值。当使用上述方法求解该方程时，验证是解决问题的一个组成部分。

3. 表示$\log \sqrt{3}$ arcctg $x = t$，我们得到$t^2 - 3t + 2 < 0$，因此$1 < t < 2$。
回到变量$x$，我们可以写
$$\sqrt{3} < \text{arcctg} x < 3$$
我们得到答案：$\text{arcctg} 3 < x < \text{arcctg} \sqrt{3}$。

4. 要求$4 + 3x - x^2 \geq 0$给我们$-1 \leq x \leq 4$。

现在，将加法公式应用到左侧，我们得到
$$\sqrt{2} \sin \left(\sqrt{4 + 3x - x^2} + \frac{\pi}{4}\right) = \sqrt{2},$$
在哪里
$$\sqrt{4 + 3x - x^2} = \frac{\pi}{4} + 2\pi n.$$
这意味着$n \geq 0$是必要的。

解这个无理方程，我们得到
$$x = \frac{3 \pm \sqrt{25 - 4 \left(2\pi n + \frac{\pi}{4}\right)^2}}{2};$$
从这里
$$\left(2n\pi + \frac{\pi}{4}\right)^2 = \frac{25}{4}.$$
因此，$n = 0$和$x_{1,2} = \frac{6 \pm \sqrt{100 - \pi^2}}{4}$。

通过检查我们可以很容易地验证这两个值都是方程的根。

在求解这个方程时，许多人得到了等式（1），但只有部分对该方程的构造研究留下了对应于$n = 0$的解。

5. 令$ABC$为给定三角形，$\rightarrow ACB$为直线，$O$和$O_1$为半径为$R$和$r$的圆心； $D$ 和 $E$ – 腿 $CA$ 圆的切点。让我们画出$EF \parallel AB$并表示$\rightarrow BAC = \alpha$。然后从$\triangle FDE$我们有
$$\sin \alpha = \frac{R - r}{R + r}.$$

注意到$CD = R$并表示$AC = b$，我们从$\triangle ODA$获得
$$\text{tg} \alpha = \frac{R}{b - R}.$$

由(1)和(2)我们可以写出
$$1 + \left(\frac{R}{b - R}\right)^2 = \left(\frac{R + r}{R - r}\right)^2,$$
由此，求解 $b$，我们得到
$$b = R \left[1 + \frac{2\sqrt{Rr}}{R - r}\right].$$
