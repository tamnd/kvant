3. 是什么原因导致断根？

第一个原因是 ODZ 缩小。还有一些变换会导致方程 OD 更窄。缩小 ODZ 会导致根丢失，即原方程中属于集合 $X$ 但不属于“较窄”集合 $Y$、$(Y \subset X)$ 的根可能会“丢失”。

例 6：解方程

$$\text{tg} \left( x + \frac{\pi}{4} \right) = 2 \text{ctg} x - 1.$$

解决方案。让我们将方程（12）转化为形式

$$\frac{\text{tg} x + \text{tg} \frac{\pi}{4}}{1 - \text{tg} x \cdot \text{tg} \frac{\pi}{4}} = \frac{2}{\text{tg} x} - 1.$$

代入$y = \text{tg} x$，我们得到$y$的代数方程，求解得到$y = \frac{1}{2}$，即$x = \text{arctg} \frac{1}{2} + \pi k$。

但验证使我们相信$x = \frac{\pi}{2} + \pi n$的值也满足方程（15）。我们什么时候失去了这些根？让我们比较方程（14）和（15）的 ODZ。 X 由 $x$ 的所有值组成，除了 $ctg x$ 和 $\text{tg} \left( x + \frac{\pi}{4} \right)$ 不存在的值。方法，

$$X = \left\{ x \mid x \neq \pi n, x \neq \frac{\pi}{4} + \pi n \right\}.$$

方程 (16) 的 ODZ - $Y$ - 由 $x$ 的所有值组成，除了 $ctg x = 0$、$\text{tg} x = 1$ 和 $\text{tg} x$ 不存在的值。方法，

$$Y = \left\{ x \mid x \neq \pi n, x \neq \frac{\pi}{4} + \pi n \right\}.$$

由此可知$Y \subset X$，即式(16)的ODZ比式(15)的ODZ窄。值$x = \frac{\pi}{2} + \pi n$属于集合$X$，但不属于原方程的根集合。
