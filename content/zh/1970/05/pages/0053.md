⟦folio 51⟧

同时，方程两边同时除以同一个函数会导致丢失根（即除数函数的根）。

而不是结论

解方程时有哪些一般规则可以指导您？只有一种方法：有意识地而不是机械地求解任何方程，不要绕过任何可能出现构造根或丢失根的关键转变。在开始求解方程之前，写下定义 OD3 的所有约束很有用（它们甚至不必相对于未知数进行求解）；例如，求解式（3）时，只需写下条件：$x^2 + 3x - 4 > 0$和$2x + 2 > 0$即可；检查时，立即可以清楚地看到找到的根$x_2 = -3$之一不满足条件$2x + 2 > 0$。如果您必须进行可能出现构造根的转换，那么最后您需要进行检查，在这种情况下，这是问题解决方案的一部分，而不仅仅是额外的控制。有时，在求解过程中，将变量值集分成两个或多个部分并分别检查每个部分的方程是很方便的；例如，方程(14)在$60 - 3x < 0$处是完备的，无解，而在$60 - 3x \ge 0$处两边平方不会导致新根的出现，因为方程两边都是非负的（无关根$x_2 = 362$因不满足条件$60 - 3x \ge 0$而被自动消除）。

每个方程的解应该看起来像定理的证明，即给定的方程满足于那些且仅那些写在答案中的数字；以及转型过程中扎根和失根的“斗争”必须灵活。

练习

求解以下方程：

1. $\frac{x}{2x-1} + \frac{25}{4x^2-1} = \frac{1}{27} - \frac{13}{1-2x}$.
2. $\frac{x^2 - 3x + 2}{x} \left( \frac{x}{3^2 - 1} - 1 \right) = 0$.
3. $\sqrt{x+1} = 1 - \sqrt{2x+3}$.
4. $\sqrt{(x+16)(x-5)} + \sqrt{x^2 - 5x} + \sqrt{x^2 - 5x} + x = 40$.
5. $\log_{5x-2} 2 + 2 \log_{5x-2} x = \log_{5x-2} (x+1)$.
6. $\frac{\lg 2 + \lg (4 - 5x - 6x^2)}{\lg \sqrt{2x-1}} = 3$.
7. $tg x + tg 2x = tg 3x$.
8. $3 tg 2x + 2 ctg x + 3 = 0$.

任务

1. 一名人口普查员敲了敲一户人家的门，询问开门的人除了他之外还有其他人住在房子里吗？那人回答道：“是的，这里还有3条不同年龄的饵鱼。它们的年龄之和等于这所房子的数量（人口普查员知道的），它们年龄的乘积是1296。”经纪人一番推算后，又问了一个问题，然后就离开了。他设定了年龄。这栋房子的门牌号是多少？

2. 当跑步者$A, B$和$C$参加100米比赛时。当$A$完成时，$B$在他身后10米，当$B$完成时，$C$在他身后10米。当$A$完成时，$C$距离$A$有多远？假设每个人都以恒定的速度跑步。

3. 使用两次除法运算确定数字 $A$，其中每个星号代表 0 到 9 之间的数字。

4. $A, B, C$和$D$这四个谎言，三次说真话的只有一次。 $A$表示$B$否认，$C$声称$D$同意。 $D$说真话的概率是多少？证明这个概率等于 $A, B, C$ 每个人都说真话的概率。
