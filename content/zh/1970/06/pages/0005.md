⟦folio 3⟧

对实践中遇到的所有数字都做同样的事情是不方便的。此外，如果我们的需求仅限于数以千计，我们就需要记住一千个特殊字符。自然地，很长一段时间以来，人们开始选择一个或另一个系列的“关键”数字，并只用特殊的符号来指定它们。例如，这是基于关键数字的罗马编号系统
1、5、10、50、100、500 和 1000。
罗马数字系统中的这些数字代表字母 I (“i”)、V (“ve”)、X (“ix”)、L (“el”)、C (“ce”)、D (“de”) 和 M (“em”)。

这些名称通常源自图，曾经描绘了相应的数字（I - 手指，V - 手指放置的五，X - 两个五），并且通常是拉丁词的缩写（centum - 一百，demimille - 五百，mille - 千）。

由于我们只需要罗马数字系统作为示例，因此我们将在较旧的简化版本中考虑它，此时数字“四”以 IIII 形式而非 IV 形式书写。在这个古罗马系统中，数字 3477 的写法如下：MMMSSSSCLXXVII=3·1000+4·100+50+2·10+5+2。

收银员也做同样的事情，有100卢布、50卢布、25卢布、10卢布、5卢布、3卢布和1卢布面额的纸币。对于收银员来说，数字是关键

100、50、25、10、5、3 和 1。
比如说，想要支付 499 卢布，他首先发行尽可能多的百元大钞，

放弃太多：
499 = 4·100 + 99.

然后，他发行尽可能多的 50 卢布票，以便发行不超过剩余的 99 卢布：
499 = 4·100 + 1·50 + 49,
有时他可能会得到小于下一个关键数字的余数。在我们的例子中，发行两张十卢布后就是这种情况：
499 = 4·100 + 1·50 + 1·25 + 2·10 + 4.

下一个关键数字是 5，但是，由于 4 < 5，因此无需给出 5 卢布。但对于这幅画，我们可以假设给出了 0 个五卢布，并在总和中包含了 0·5 项。发行499卢布的整个程序会这样写：
499 = 4·100 + 1·50 + 1·25 + 2·10 + 0·5 + 1·3 + 1·1.

现在让我们尝试概括已经说过的内容，将任何递增数字的序列作为关键数字序列（“基础”）：
$q_0 = 1 < q_1 < q_2 < \dots < q_n < \dots$ (1)
让我们描述如何在以 (1) 为基数的数系中获得任意数 $N$ 的表示法。

在关键数字序列（1）中，有最大的数字$q_n$，不超过$N$。 Delim $N$ 除以 $q_n$，我们得到（不完全）商 $a_n$ 和余数 $r_{n-1}$：
$N = a_nq_n + r_{n-1}$，其中$0 \leqslant r_{n-1} < q_n$。

第一个余数$r_{n-1}$除以下一个关键数字$q_{n-1}$。我们把
$r_{n-1} = a_{n-1}q_{n-1} + r_{n-2}$,
其中$0 \leqslant r_{n-2} < q_{n-1}$，或
$N = a_nq_n + a_{n-1}q_{n-1} + r_{n-2}$.
