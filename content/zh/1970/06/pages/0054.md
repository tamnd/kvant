现在我们需要求解两个方程：

1) $x^2 + 6x = 0$, $x_1 = 0$, $x_2 = -6$;
2) $x^2 + 6x = 7$, $x^2 + 6x - 7 = 0$, $x_1 = -7$, $x_2 = 1$.

答案：$x_1 = -7$、$x_2 = -6$、$x_3 = 0$、$x_4 = 1$。

12. 1) 分析。从$KB = KH$开始，然后$\angle KHB = \angle B$。让我们做$KC$。从$KH = HC$开始，然后$\angle HKC = \angle HCK$。但它们的和等于外角$\angle KHB$：$\angle HKC + \angle HCK = \angle KHB$（见图8）。这意味着它们每个都等于它的一半：

$$\angle CKH = \angle KCH = \frac{1}{2} \angle KHB = \frac{1}{2} \angle B.$$

2) 建造。设$\triangle ABC$。将 $\angle B$ 一分为二，并构造一个角 $\angle BCM = \frac{1}{2} \angle B$，使得射线 $CM$ 位于线 $BC$ 与点 $A$ 的同一侧。让射线$CM$与边$AB$（不是它的延长线）相交于点$K$。让我们构造角度 $\angle CKN = \frac{1}{2} \angle B$，使射线 $KN$ 与点 $B$ 位于直线 $CK$ 的同一侧。让射线$KN$与边$BC$（不是其延长线）相交于点$H$。构建的点 $K, H$ 非常出色。

3) 证明。通过构造，$\angle HKC = \angle HCK$，因此$KB = KH$。

下一个，

$$\angle KHB = \angle HKC + \angle HCK = \frac{1}{2} \angle B + \frac{1}{2} \angle B = \angle B,$$

姿势$KB = KH$。
