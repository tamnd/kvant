1、不同或相同。
在这样的数字系统中，数字被写成

$$N = \lceil a_n a_{n-1} \dots a_2 a_1 a_0 \rceil$$

倒数第一个数字 $a_0$ 可以取 $d_0$ 值 0, 1, 2, ..., $d_0$ - 1。下一个数字 $a_1$ 可以取 $d_1$ 值从 0 到 $d_1$ - 1；数字$a_2$可以取0到$d_2$ - 1等值。

此外，在以 (3) 为基数的数系中，以及在 $d$ 进制数系中（其中我们的系统在 $d_0 = d_1 = d_2 = d_3 = \dots = d$ 的情况下是相反的），任何条目都是有意义的

$$N = \lceil a_n a_{n-1} \dots a_2 a_1 a_0 \rceil,$$

其中$a_0, a_1, a_2, \dots, a_n$是自然数，例如$a_0 < d_0, a_1 < d_1, a_2 < d_2$等。事实上，很容易检查到，当使用“连除”方法将数字$N = a_n q_n + a_{n-1} q_{n-1} + \dots + a_2 q_2 + a_1 q_1 + a_0$转换到我们的数字系统时（参见上面的第4页），得到以下数字：

$$a_n, a_{n-1}, a_{n-2}, \dots, a_1, a_0.$$

我们将用一个非常简单的“数字系统”的例子来证明这种有利的情况不是一般规律。

2°“偶”数系统。

以所有偶数（以及数字$q_0 = 1$）作为数系的基础：

$$q_0 = 1, \quad q_1 = 2, \quad q_2 = 4, \quad q_3 = 6,$$

$$q_4 = 8, \quad q_5 = 10, \quad q_6 = 12,$$

自从这里

$$\frac{q_1}{q_0} = q_1 = 2$$

和

$$\frac{q_{n+1}}{q_n} = \frac{2(n+1)}{2n} = \frac{n+1}{n} = 1 + \frac{1}{n} < 2$$ 对于所有$n > 1$，

那么这个数字系统就像双数字系统一样，只知道两个“数字”：0和1。条件是将这个“偶数”数字系统中写的数字指定为红色。然后，非常印度，

$$2 = 10, \quad 3 = 11, \quad 4 = 100, \quad 5 = 101, \quad 6 = 1000, \quad 7 = 1001, \quad 8 = 10000, \quad 9 = 10001$$等

一般来说，所有数字要么被描述为末尾有一个或另一个零的数字（偶数），要么绝大多数零和一序列不表示“偶”数字系统中的任何数字，因为在“偶”数字系统中，一个只能出现在第一位，有时甚至出现在最后一位。
