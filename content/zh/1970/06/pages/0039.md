2. 在这个例子中，主要困难在于正确编写复数模型。这里complexLEX数是$z = x + iy$，complexLEX数是$z + 3i = x + iy + 3i = x + (y + 3)i$。后者的模为$|z + 3i| = \sqrt{x^2 + (y + 3)^2}$，其平方为$|z + 3i|^2 = x^2 + (y + 3)^2$。因此我们有$x^2 + (y + 3)^2 - x - iy = 3 + 2i$。

如果两个复数的实部和最小部分的系数相等，则两个复数相等。因此，

$$\begin{cases} x^2 + (y + 3)^2 - x = 3, \\ y = -2. \end{cases}$$

求解系统，我们找到$x_1 = -1$和$x_2 = 2$。从这里我们得到两个复数：$z_1 = -1 - 2i$和$z_2 = 2 - 2i$。

3. 使用基本对数方法，我们得到

$$\log_3 (\log_2 x - 1)^2 = 2.$$

然后他们犯了很多错误，就是取次数的对数，把括号2的指数移到对数符号之外，把方程缩短了二。在这种情况下，这种变换会导致根丢失，因为括号中的对数表达式可以是正数，而在原始方程中它可以是正数，也可以是负数。

正确的解决方案：

$(\log_2 x - 1)^2 = 9$ 或 $|\log_2 x - 1| = 3$。

因此$\log_2 x - 1 = \pm 3$，这导致两个解决方案：

1) $\log_2 x = 4$和$x_1 = 16$；
2) $\log_2 x = -2$ 和 $x_2 = \frac{1}{4}$。

两个根都是正数并且满足未知 $x > 0$ 的 ODZ。

4. 让我们用 $x$ 表示 $M$ 和 $N$ 之间的距离。那么从$M$到第一次第二次相遇的路径就是$(x - 50)$，从第一次第二次相遇开始的路径就是$50 + (x - 25) = x + 25$。第二次从$N$到第一秒的路径是$50$，从第一次第二次相遇的路径是$(x - 50) + 25 = x - 25$。由于它们均匀移动，因此第一次和第二次相遇以及从第一次到第二次的路径比率应该是非负的。从这里我们得到方程

$$\frac{x - 50}{50} = \frac{x + 25}{x - 25}$$

或$(x - 50)(x - 25) = 50(x + 25)$。
