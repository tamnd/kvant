3. 让我们用所需的线段 $EF$ 绘制一个梯形，并延伸其边直到它们在点 $M$ (图 1) 处相交。线 $EF$ 的延续也将经过点 $M$，因为 $MF$ 将是结果 $\angle AMD$ 的中位数。根据条件$\angle AMD = 180^\circ - \angle A - \angle D = 90^\circ$。由直角三角形中线的性质可知
$$MF = \frac{1}{2}AD \text{ и } ME = \frac{1}{2}BC.$$
许多人没有利用中位数的这一特性，因此很难解决问题。同时，不难发现直角取决于三角形外接圆的直径。这样一个圆的中心位于斜边的中间，即中线的底部。因此，$MF$ 和 $AF$ 的半径相等。这意味着上述性质。然后就很容易找到需要的段了：

$$EF = MF - ME = \frac{1}{2}(AD - BC) = \frac{1}{2}(7 - 3) = 2.$$

4. 在符号 图 2 中，圆锥的侧面
$$S_{бок} = \pi \cdot AO \cdot AS.$$
我们用$AS = BS = x$来表示它。那么，由于$\angle ASB$是直的，$AB = x\sqrt{2}$是直的，$AC = \frac{x\sqrt{2}}{2}$是直的。
根据条件 $\angle AOB = 120^\circ$，因此 $\angle AOC = 60^\circ$ 且
$$AO = \frac{AC}{\sin 60^\circ} = \frac{x\sqrt{2}}{2} \cdot \sqrt{3} = x\sqrt{\frac{2}{3}}.$$
锥体高度
$$SO = \sqrt{AS^2 - AO^2} =$$

$$\sqrt{x^2 - \frac{2}{3}x^2} = \frac{x}{\sqrt{3}} = h.$$
从这里我们找到$x = h\sqrt{3}$和$AO = h\sqrt{2}$。
圆锥体的侧面将是
$$S_{бок} = \pi h\sqrt{2} \cdot h\sqrt{3} = \pi h^2\sqrt{6}.$$
5. 我们有 $4\sin^2 x - \frac{1}{\cos x} = 1$，其中 $\cos x \neq 0$，
即$x \neq \frac{\pi}{2} + \pi k$。减少到一般值，我们得到
$$4\sin^2 x \cdot \cos x - 1 = \cos x,$$
$$4(1 - \cos^2 x) \cdot \cos x = 1 + \cos x$$
或者
$$(1 + \cos x)(4\cos^2 x - 4\cos x + 1) = 0$$
然后我们将每个因素都等于零。这里我们没有把公因数$(1 + \cos x)$放在括号外，而是把倒数第二个表达式中的括号打开，得到三次方程
$$4\cos^3 x - 3\cos x + 1 = 0,$$
他们未能解决这个问题。
然而，简单的三次方程，例如那些可以通过因式分解解决的方程，可能会出现在入学考试中，并且需要能够解决它们。
在本例中，我们将 1 表示为数字 4 和 3 之间的差，并将方程表示为以下形式
$$4\cos^3 x - 3\cos x + 4 - 3 = 0$$
分组，我们来写
$$4(\cos^3 x + 1) - 3(\cos x + 1) = 0,$$
进而
$$(\cos x + 1)[4(\cos^2 x - \cos x + 1) - 3] = 0$$
