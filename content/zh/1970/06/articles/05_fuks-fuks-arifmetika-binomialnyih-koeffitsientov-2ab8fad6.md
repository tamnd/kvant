§ 1. 二项式系数的定义和最简单的性质

如果二项式（二项式）$1+x$用某种自然幂$n$进行加权，那么显然，结果是一个$n$次数的多项式（即$x$出现在该多项式中的最高次数将等于$n$）。例如：

$$(1+x)^0 = 1,$$
$$(1+x)^1 = 1+x,$$
$$(1+x)^2 = 1+2x+x^2,$$
$$(1+x)^3 = 1+3x+3x^2+x^3,$$
$$(1+x)^4 = 1+4x+6x^2+4x^3+x^4,$$
$$(1+x)^5 = 1+5x+10x^2+10x^3+$$
$$+5x^4+x^5,$$

这些多项式的系数称为二项式。它们有特殊的符号：$(1+x)^n$中$x^m$的系数用$C_n^m$表示。例如，$C_2^1=2$、$C_4^2=6$、$C_5^3=10$。在旧的代数教科书中，数字$C_n^m$被称为“$n$到$m$的组合数”。这是有原因的，但我们没有

$$\ldots + C_n^nx^n$$

显然，$C_n^m$是非负整数，$C_n^m=0$对应$m>n$（多项式$(1+x)^n$的次数为$n$，$x^m$和$m>n$不包含在其中）。很容易进一步验证$C_n^0=C_n^1=1$。其他二项式系数 $C_n^m$（其中 $0<m<n$）可以通过 $1+x$ 的各种幂得到。表中给出了 $n\leqslant10$ 的值。

§ 2. 生物系数除以素数的余数

在本段（以及下一段）中，我们经常需要使用“数字 $a$ 和 $b$ 除以 $p$ 时余数相等”的形式。通常，这种形式被缩写符号“$a \equiv b$（mod$p$）”代替。换句话说，公式“$a \equiv b$ (mod $p$)”意味着$a-b$可以被$p$整除。例如，$4 \equiv 1$ (mod 3)、$999999 \equiv 222222$ (mod 7) 等。公式“$a \equiv b$ (mod $p$)”有时读作如下：“数字$a$ 与数字$b$ 模$p$ 相当”（但是，我们也不会使用表达式）。

以下是符号 ≡ 的两个特性：

1. 如果 $a \equiv b$ (mod $p$) 和 $k$ 是整数，则 $ka \equiv kb$ (mod $p$)。

事实上，如果$a-b$能被$p$整除，那么$ka-kb = k(a-b)$也能被$p$整除。

2. 如果 $a \equiv b$ (mod $p$) 和 $b \equiv c$ (mod $p$)，则$a \equiv c$ (mod $p$)。

事实上，如果$a-b$能被$p$整除并且$b-c$能被$p$整除，那么$a-c = (a-b)+(b-c)$也能被$p$整除。

让我们回想一下，任何自然数$a$都可以除以自然数$p$“有余数”，即$a$可以唯一地写成$a=bp+c$的形式，其中$b$，$c$是整数，使得$0 \leq c < p$。

本节的主要目标是证明以下陈述。

定理4.设$p$为素数，$m$和$n$为自然数。此外，令$k$和$l$为数字$m$和$n$除以$p$的部分，$s$和$t$为余数（即$m=kp+s$、$n=lp+t$，其中$k$、 $l$、$s$、$t$ 为整数，$0 \leq s < p$、$0 \leq t < p$）。然后

$$C_n^* = C_l^* \cdot C_s^* \pmod p.$$

正如我们将在下面看到的，该定理使我们能够找到生物系数除以素数的余数，几乎无需执行任何计算。

扫地。
1°。假设 $n > 1$ 显着，因为 $\alpha_1$ 等于 4 并且不能被 $2^{2n+2} = 2^4 = 16$ 整除。
2°。人们可能认为$n > 1$的$\alpha_n$甚至可以被$2^{3n}$整除：对于$n = 2, 3, 4$也是如此。但我们不知道如何证明这一点。

证明。让我们从一般观察开始，如果数字 $r$ 是奇数，则 $C_{2n}^{r}$ 可以被 $2^n$ 整除。事实上，由于 $r$ 是奇数，并且 $2^n$ 除了 2 之外没有素因数，因此数字 $r$ 和 $2^n$ 是互质的，我们需要的陈述来自定理 3。

让我们把理论
$$P(x) = (1+x)^{2n+1} - (1-x^2)^{2n}.$$

多项式$P(x)$包含$x^{2n}$，系数为$C_{2n+1}^{2n} - C_{2n}^{2n-1} = \alpha_n$（这里我们使用$n > 1$这一事实：当$(1-x^2) = 1 + (-x^2)$出现$2^n$次方时，我们得到系数$C_{2n}^{2n-1}$不是$x^{2n}$，而是$(-x^2)^{2n-1} = (-1)^{2n-1}x^2^n$，而数字$(-1)^{2n-1}$为1 $n > 1$ 且在 $n = 1$ 处等于 $-1$。

另一边，
$$P(x) = (1+x)^{2n+1} - (1+x)^{2n} = (1+x)^{2n}[(1+x)^{2n} - (1-x)^{2n}].$$

同时
$$(1+x)^{2n} - (1-x)^{2n} = (1+x)^{2n} - (1+(-x))^{2n} = 1 + C_{2n}^{1}x + C_{2n}^{2}x^2 + C_{2n}^{3}x^3 + \dots + x^{2n} - 1 - C_{2n}^{1}(-x) - C_{2n}^{2}(-x)^2 - C_{2n}^{3}(-x)^3 - \dots - (-x)^{2n} =$$
（因为 $(-x)^k$ 等于 $x^k$ 对于甚至 $k$ 且相等 $-x^k$ 对于奇数 $k$)
$$= 2\left(C_{2n}^{1}x + C_{2n}^{3}x^3 + C_{2n}^{5}x^5 + \dots + C_{2n}^{2n-1}x^{2n-1}\right).$$

我们强调，所得多项式 $x$ 仅以奇数次幂出现。

我们想知道 $x^{2n}$ 以什么系数进入 $P(x)$，即进入乘积
$$(1+x)^{2n}[(1+x)^{2n} - (1-x)^{2n}] = 2\left(1 + C_{2n}^{1}x + C_{2n}^{2}x^2 + C_{2n}^{3}x^3 + \dots + x^{2n}\right) \times \left(C_{2n}^{1}x + C_{2n}^{3}x^3 + C_{2n}^{5}x^5 + \dots + C_{2n}^{2n-1}x^{2n-1}\right).$$
