正如您所看到的，儒略年的平均长度比真实年份长 11 分钟。 14秒。 16世纪，教皇格列高利十三世希望纠正这一错误。 1582年，他对历法进行了如下改革。保留了简单年份和高年份之间的区别，但它补充了规则：如果年份数字是两个零，并且班次数不能被 4 整除，则查看今年。例如，据此，1700年是简单的年份，但1600年是高年份。

另外，考虑到从年表开始（从“基督诞生”开始）就已经累积了10天的误差，格列高利十三世立即加上了10天。从那时起，又累计了3天（1700年、1800年和1900年）。因此，目前儒略历与新（“公历”）历之间的差异为13天。

公历年的平均长度是多少？根据儒略历，400 年中，有 100 年是高级年份，而根据公历，有 97 年。因此

公历年的平均长度 =
= 365 $\frac{97}{400}$ 天 = 365.2425 天 =
= 365 天 5 小时。 49 分钟12秒，

即它比真实时间长 26 秒。
正如您所看到的，使用简单的方法就可以达到非常高的准确度。

二.链条柴火

3. 链分数和的概念。让我们忘记十进制数字系统。正如俄罗斯杰出数学家尼古拉·尼古拉耶维奇·卢津（Nikolai Nikolaevich Luzin，1883-1950）所说，“十进制的优点不是数学上的，而是动物学上的。如果我们手上的手指不是十个，而是八个，那么人类就会使用八进制。”十进制对于实际评估来说很方便，但在研究算术理论问题时却很碍事。

因此，让我们向特殊的数字系统敞开心扉，并问自己一个问题：用分数来近似表示正数的最自然的方法是什么。

这个问题的答案是毫不犹豫的：首先有必要指出它是在哪些数字之间得出的结论。例如，

$$\frac{61}{27} \text{ нахождение между } 2 \text{ и } 3,$$
$$\sqrt{2} \text{ » } 1 \text{ » } 2,$$
$$\pi \text{ » } 3 \text{ » } 4.$$

当然，仅指示这些数字中较小的一个就足够了：

$$\frac{61}{27} = 2 + x \quad (0 < x < 1),$$
$$\sqrt{2} = 1 + y \quad (0 < y < 1),$$
$$\pi = 3 + z \quad (0 < z < 1).$$
