⟦folio 36⟧

5. 集合$M$由三个元素组成，集合$N$由两个元素组成。有多少个映射：a) 映射$M$ 到$N$，b) 映射$M$ 到$N$，c) 映射$N$ 到$M$，d) 映射$N$ 到$M$？

6. 七位数电话号码有多少个？哪个数字仅由数字 0、1、2、3 组成？

7. 证明有超过一百万个函数只接受两个值：0 和 1，并且是在前 20 个自然数的集合上定义的。

8. 集合$M$由$m$个元素组成，集合$N$由$n$个元素组成。集合$M$上定义了多少个取值$N$的函数？

我们还要注意，任务 8、11、18、19 被认为是组合学的主要问题之一。我们在这里展示它们是为了表明组合学与零件有重要的联系，并且涉及计算一种或另一种类型的有限集到有限集的映射数量。

9. 您可以有多少种座位方式：a) 两位客人坐在两把椅子上，b) 三位客人坐在三把椅子上，c) 六位客人坐在六把椅子上？

10. 许多 $E$ 由六个要素组成。表明正好有 720 个函数 $E$ 既是一个定义域又是一组值。

11. 有限集到其自身的映射称为子集。集合的不同排列的数量仅取决于其元素 $n$ 的数量，并表示为 $n!$。表明

$$1! = 1, \ 2! = 2, \ 3! = 6, \ 4! = 24, \ 5! = 120, \ 6! = 720.$$

指出计算$n$的一般方法！

3. 反函数

12.0。下列哪些函数是反函数，哪些不是反函数？

$$f_1(x) = x^3, \ f_2(x) = x^4, \ f_3(x) = x^{17}, \ f_4(x) = x^{18}$$

13. 课堂上，每对后面坐的人不超过两个。让我们为每个学生分配他的邻桌，如果他独自坐着，则为他自己。会有什么回报？

14. 让俄语的每个单词都有一个对应的单词，用相同的字母书写，但顺序相反（单词是字母的序列）。这个函数是反函数吗？如果是，反函数是什么？

15. 有限集到其自身的映射总是可逆的。给出一组自然数到其自身的非逆映射的示例。

16. 三艘船必须容纳九名游客。如果要求a）每艘船上有三人，b）每艘船上不超过四人且不少于两人，b）每艘船上至少有一名游客，他们可以通过多少种方式做到这一点？ （船有编号：1 号、2 号、3 号。）

17*。如果主人有学生，​​那么习惯上就不会说一名学生一名客人：许多客人以相反的方式反映在许多学生身上。如果房间里只有六名学生，您可以用多少种方式让他们入座：a）一名客人，b）两名客人，c）四名，d）高跟鞋，e）六名客人？

18*。一个有限集$M$到另一个有限集$N$的逆映射称为放置（客人被“放置”在椅子上）。集合$M$到集合$N$的映射数量仅取决于集合$M$的元素数量$m$和集合$N$的元素数量$n$，并表示为$A_m^n$。表明

$$A_1^1 = 1, \ A_2^1 = A_2^2 = 2, \ A_3^1 = 3, \ A_3^2 = A_3^3 = 6, \ A_1^2 = 90,$$

并建立了计算$A_n^m$的一般规则。证明它总是$A_n^{n-1} = A_n^n$。

19*。任务16c可以抽象地形成：一组第九个元素到一组三个元素有多少个映射。让$D_n^m$表示一组$n$元素到一组$m$元素的映射数量。检查一下

$$D_3^2 = 6, \ D_4^2 = 12, \ D_4^3 = 36, \ D_n^n = n!$$

尝试计算 $D_n^m$ 的一般规则（这是一个比问题 8、11 和 18 稍微困难一些的问题）。

20*。在一组 28 个元素上定义的函数有多少个，它们分别采用四个值 P、K、C 和 B 六次？

这是一个关于在 Petya、Kolya、Sasha 和 Volodya 之间公平分配 2 月份职责的方法数量的问题（第 29 页的示例 3）。
