⟦folio 21⟧

请注意，这种估计与整数的表示方式无关，即与任何特定的数字系统无关。

将处理数字$\frac{61}{27}$。我们对“两个以上”的估计太粗略，仅适合作为*第一近似值*。如果我们想进行第二步，那么我们必须评估加法$x$。既然小于一，自然就用分子1表示为分数（我们再次诉诸“自然”，但这是最后一次）

$$\frac{61}{27} = 2 + \frac{1}{x_1}.$$

现在$x_1$大于1，我们再次重复相同的步骤：选择整个部分，等等。我们请读者仔细遵循这两个步骤的交替：

$$\frac{61}{27} = 2 + \frac{7}{27} = 2 + \frac{1}{27} =$$

$$= 2 + \frac{1}{3 + \frac{6}{7}} = 2 + \frac{1}{3 + \frac{1}{7}} =$$

$$= 2 + \frac{1}{3 + \frac{1}{1 + \frac{1}{6}}}.$$

表达

$$a_0 + \frac{1}{a_1 + a_2 + a_s},$$

其中$a_1, a_2, \dots, a_s$是自然数，$a_0$是自然数或零，称为连分数。

数字$a_0, a_1, a_2, \dots, a_s$称为连分数的元素*)。我们可以说我们已经将数字 $\frac{61}{27}$ 表示为连分数。

*) 有时它们被称为不可约商。

连分数表示法是不是太麻烦了？在我们的示例中，结果是三层楼的分数，但如果结果是二十层楼的分数，则它无法容纳在一张纸上。

这是事实，因此连分数使用不同的表示法条件。我们将使用这个：

$$a_0 + \frac{1}{a_1 + a_2 + a_s} =$$

$$+ \frac{1}{a_s}$$

$$= [a_0; a_1, a_2, \dots, a_s].$$

请注意分号。她强调整个$a_0$的作用是特殊的，与其他数字不一样（特殊并不意味着更重要，在这种情况下，恰恰相反）。

是否可以说每个实数 *) 都可以用连分数表示，而且可以以唯一的方式表示？

首先，让我们考虑一下这个例子：

$$\frac{1}{6 + \frac{1}{4}} = \frac{1}{6 + \frac{1}{3 + 1}} = \frac{1}{6 + \frac{1}{3 + \frac{1}{1}}}$$

或缩写符号

$$[0; 6, 4] = [0; 6, 3, 1].$$

这种转换（单位与最后一个元素的分离）可以用任何连分数来执行，其中最后一个元素与单位相区分。如果最后一个元素等于 1，则可以将其添加到倒数第二个元素。例如，

$$[1; 10, 3, 7, 1] = [1; 10, 3, 8].$$

然而，很容易证明这是造成歧义的唯一原因

*) 现在我们讨论的是不同的正数。负数的引入并没有改变问题的本质，但无理数的引入却改变了很多。这将在下面讨论。
