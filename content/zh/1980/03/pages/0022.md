la 与镜子到像的距离$f_1$有对应关系

$$\frac{1}{d_1} - \frac{1}{f_1} = -\frac{1}{F_1}.$$

考虑到镜子的焦距等于放大镜第一个球面的曲率半径$R_1$的一半，我们得到

$$\Gamma_1 = \frac{F_1}{F_1 + d_1} = \frac{R_1}{R_1 + 2d_1}.$$

如果物体与镜子的距离远大于其曲率半径 ($d_1 \gg R_1$)，则在上一个公式的分母中，第一项与第二项相比可以忽略不计，我们可以假设凸面镜的放大倍数等于

$$\Gamma_1 = \frac{R_1}{2d_1}.$$

类似地，放大镜（凹面镜、镜面）背面给出的物体的放大倍数也可以用相同的公式表示，只不过不是$R_1$而应该是$R_2$，并且一起是$d_1 - d_2$：

$$\Gamma_2 = \frac{R_2}{2d_2}.$$

由于放大镜是薄透镜，即其厚度与曲率半径相比较小，因此$d_1$和$d_2$的距离差可以忽略不计。那么对于放大镜表面给出的物体的放大倍数，我们有

$$\Gamma_1 = \frac{l_1}{l} = \frac{R_1}{2d} \text{ и } \Gamma_2 = \frac{l_2}{l} = \frac{R_2}{2d},$$

其中$d = d_1 = d_2$是物体到放大镜的距离。

因此，如果获得不同尺寸的图像$l_1$和$l_2$，则放大镜的曲率半径是不同的。通过测量物体到放大镜的距离并改变放大镜表面的放大倍数，可以确定其表面的曲率半径。

我们建议您用眼睛晶状体模型检查另一个实验。

用橡皮泥制作一个小矩形室；将放大镜插入腔室的侧壁。获取燃烧的骆驼的图像 -

将芽置于放大镜表面反射的光线中，并注意其亮度。现在将水倒入相机中 - 放大镜后表面创建的图像的亮度将会降低。事实证明，从两种介质之间的界面反射的光强度取决于这些介质的折射率*)。在这种情况下，当用水替换空气时，反射光的强度降低。

我们已经足够详细地分析了如果眼睛的光学系统由单晶体组成，则在反射光中应该观察到什么。然而，眼睛也有角膜和两个充满房水和玻璃体液的腔室。

您可以通过将光焦度为 +1 屈光度的窗玻璃（在所有药店均有销售）放置在放大镜前面 2-4 毫米处来模拟角膜的活动。将手电筒灯泡发出的光引导到最终的光学系统上。从灯泡的侧面观察电线，您会看到它的四个图像，其中三个是直的，一个是倒置的。请注意，光从车窗玻璃表面反射形成的图像彼此非常接近。

用水填充窗玻璃和放大镜之间的空腔以及放大镜后面的塑料室。观察这如何改变光学系​​统的各个球面创建的图像的亮度。
