5. 应用位移来解决问题

问题 4. 两个以 $O_1, O_2$ 为圆心的圆相交于点 $A$ 和 $B$。证明线 $O_1O_2$ 重新分配线段 $AB$ 并将其分成两半。

解决方案。让我们用$l_1, l_2$表示位于直线$O_1O_2$一侧的半圆，用$l'_1, l'_2$表示位于另一侧的半圆（图9），并用$s$表示相对于$(O_1O_2)$的对称性。然后$l'_1 = s(l_1), l'_2 = s(l_2)$。从$s(l_1 \cap l_2) = s(l_1) \cap s(l_2) = l'_1 \cap l'_2$开始，我们得到$s(A) = B$，即$A$和$B$相对于$(O_1O_2)$对称。这是所需声明的位置。

在这个解决方案中，我们利用了这样一个事实：对于任何运动$f$和任何数字$M, N$，对应关系$f(M \cap N) = f(M) \cap f(N)$都是有效的。你自己证明一下。

问题 5. 在任意三角形 $ABC$ 的边 $AB$ 和 $BC$ 上，在其外部构建正方形 $ABMN$ 和 $BCPQ$。点$K$是线段$MQ$的中间。证明线段 $BK$ 重新分布了底边 $AC$ 和其冠部的两倍。

解决方案。令 $L$ 为线段 $AC$ (图 10) 的中点。需要证明线段$BK$和$CL$重新分布了圆并且全等。为此，最方便的方法是确定第一段是通过围绕某个点旋转 $\pm 90^\circ$ 从第二段获得的。因此，我们希望找到一个点，旋转$90^\circ$或$-90^\circ$，围绕该点将点$C$变换为$B$，将点$L$变换为$K$。但很明显，围绕正方形中心 $BCPQ$ 旋转 $r$ $-90^\circ$ 会将点 $C$ 带到 $B$。这意味着仍然需要确定$r(L) = K$。

我们有$r(C) = B, r(B) = Q$；让我们输入$r(A) = D$。那么$r([BA]) = [QD]$，即线段$AB$和$DQ$已经重新分布并且全等。这意味着线段$BM$和$QD$平行且全等，即$BMDQ$平行。因此，点$K$（对角线$MQ$的中点）也是线段$BD$的中点。从$r([CA]) = [BD]$开始，我们得到$r(L) = K$。因此，$r(C) = B, r(L) = K$，即$r([CL]) = [BK]$，因此线段$CL$和$BK$已重新分配并且全等。
