任务

M611—M615; F623—F627

M611。在以 O 为圆心的圆的弦 AB 上，取任意一点 M。通过 A、M、O 点，画一个与第一个圆相交于 A、C 点的圆。证明$|MB| = |MC|$。

S.科尔帕科夫，十年级学生

M612。自然数的递增序列 ($a_n$) 使得$a_{n+1} \leq 10a_n$。证明如果所有数字$a_n$并排书写（没有空格或逗号），那么所得的数字序列将不是周期性的。

A·卡拉杜良

M613。在三角形ABC的边上，向外侧构造相似的三角形

$$ADB, BEC \text{ и } CFA \left( |AD| |DB| = |BE| |EC| = |CF| |FA| = k; \right)$$

$$\widehat{ADB} = \widehat{BEC} = \widehat{CFA} = \alpha.$$

证明：

a) 线段 AC、DC、BC 和 EF 的中点——平行四边形的顶；

b) 这个平行四边形有两个角，大小为$\alpha$，边长比为$k$。

L·库普佐夫

M614。对于每个自然数$n$，令$S(n)$表示从1到$n$的所有自然数的数字之和（以十进制表示）：

$$S(1) = 1, S(2) = 3, S(3) = 6, ..., S(9) = 45, S(10) = 46, S(11) = 48, S(12) = 51, ...$$

a) 找到$S(100)$。

b) 证明$S(10^k - 1) = 45k \cdot 10^{k-1}$对于所有$k = 1, 2, ...$

b) 证明对于两位数$\overline{ab}$

$$S(\overline{ab}) = 5a^2 + ab + 41a + b(b+1)/2.$$

d) 找出三位数的类似公式。
