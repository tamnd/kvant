M557。给定 n 成对的大于 1 且小于 (2n-1)² 的素数。证明其中一定存在素数。

我们用“反证法”的方法来证明问题的陈述。让我们假设所有给定的数字 $a_1, a_2, \dots, a_n$ 都是合数。让我们将它们与每个最小素因数相关联：$a_i \rightarrow q_i$。让$q = \max_{1 \leq i \leq n} \{q_i\}$。然后$q \geq p_n$，其中$p_n$是一个n-e质数（因为数字$a_1, \dots, a_n$是成对互质的）。

$k$的指示很容易证明不等式$p_k \geq 2k - 1$。 （事实上​​，对于 $p_2 = 3$ 是正确的。然后对于 $k \geq 2$ 来说，$p_{k+1} \geq p_k + 2$ 是正确的。）因此 $q \geq 2n - 1$。因此，对于 $a_j$ $q_j = q$，

$$a_j \geq q_j^2 \geq (2n-1)^2$$

M559。证明如果$x, y, z$是三角形的边长，那么

$$\left| \frac{x}{y} + \frac{y}{z} + \frac{z}{x} \right| - \frac{y}{x} - \frac{z}{y} - \frac{x}{z} < 1.$$

分解左边很方便：

$$B = \left| \frac{x}{y} + \frac{y}{z} + \frac{z}{x} \right| = \frac{\left| z \left( x^2 - y^2 \right) + x \left( y^2 - z^2 \right) \right|}{xyz} = \frac{\left| (y-z) \left( z-x \right) \left( x-y \right) \right|}{xyz}.$$

$B < 1$ 因为$|y-z| < x$、$|z-x| < y$ 和 $|x-y| < z$。

您不能将分数减少为 1：例如，使用 $x = \varepsilon$、$y = 1 + \varepsilon^2$、$z = 1 + \varepsilon$（$\varepsilon$ 是一个小正数）$B$ 将大于 $(1-\varepsilon)^3$。
