实验室“Quaita”
系统，否则调节是不可能的：在眼睛 9 的视网膜上，仅位于距眼睛一定距离处的物体的图像将是清晰的，而所有其他物体的图像将是模糊的。

研究表明，眼睛的晶状体负责调节。如果附近物体的模糊图像出现在眼睛的视网膜上，则相应的信号通过视神经传播到大脑，在大脑中形成并发送到所谓的睫状肌7，睫状肌7收缩或拉伸，改变晶状体表面的曲率，直到在视网膜上获得清晰的图像。

是否可以通过实验证明是镜头进行调节呢？我们如何确定调节是由镜片表面曲率的变化引起的？

也许，首先，您需要确保镜头确实存在。拿一面镜子，在里面看看你的眼睛。您会很容易地在其中发现一个白色致密的外壳 - 巩膜 1，该外壳的主要部分 - 角膜 2，虹膜 4（充当创建图像并确定眼睛颜色的光通量的调节器）。

问题讨论
站在距离眼睛15-30厘米的铅笔尖上，你会看到更远处的物体变得模糊。将目光转向远处的物体 - 铅笔尖会变得模糊。显然我们没有注意到这一点：我们看到的所有物体对我们来说似乎都很清晰。这意味着，无论我们的意识如何，眼睛本身似乎都会调整清晰度。这个过程称为眼睛的调节。它是如何进行的？

眼睛的光学系统（图1）由角膜2、房水3、晶状体6和玻璃体8组成。显然，眼睛具有可调节的光学功能。

捕手），插头 5 - 虹膜响应。但你不会看到镜头！怎么会这样呢？

由于眼睛的光学系统在视网膜上创建物体的图像，因此系统元件的折射率必须与环境的折射率不同。 （事实上​​，根据角膜、晶状体、房水和玻璃体的可变折射率，$n_p = 1,376$、$n_{xp} = 1,386$、$n_{B.x} = n_{c.t} = 1,336$的对应关系是相等的。）当光从一种介质传递到另一种介质时，除了折射之外，还观察到光的反射。这意味着，如果您将光源放在您的眼前，您就可以在反射光中看到其图像。

首先近似，眼睛中不同介质之间的界面是球面。因此，它们应该像球面镜一样。

因此，我们得出的结论是，眼睛的光学系统不仅在视网膜上形成物体的图像，而且由于光线在角膜和晶状体表面的反射而产生多个相似的图像。通过在现场发现这些图像，您将能够证明镜头的存在。通过检查眼睛“聚焦”时这些图像的变化，人们可以理解调节的光学本质。

模型批发

在开始对眼睛本身进行实验研究之前，请尝试刺激其角膜和晶状体。

作为眼晶状体的模型，可以使用放大倍数为2-3.5的双光束（称为时钟光束，在照相店中仍然有售）。在距离光束 10-20 厘米的地方，放置一个连接到电池的手电筒。从灯泡侧面观察光束，您会看到它的两个图像。

通常，在实验中，源的一幅图像比另一幅图像大。让我们尝试解释一下原因。

对于球面镜，所有相同的对应关系对于薄透镜都是有效的。光束前表面（凸面镜）给出的物体放大倍数等于（参见 图 3）

$$\Gamma_1 = \frac{l_1}{l} = \frac{f_1}{d_1}.$$

la 与镜子到像的距离$f_1$有对应关系

$$\frac{1}{d_1} - \frac{1}{f_1} = -\frac{1}{F_1}.$$

考虑到镜子的焦距等于放大镜第一个球面的曲率半径$R_1$的一半，我们得到

$$\Gamma_1 = \frac{F_1}{F_1 + d_1} = \frac{R_1}{R_1 + 2d_1}.$$

如果物体与镜子的距离远大于其曲率半径 ($d_1 \gg R_1$)，则在上一个公式的分母中，第一项与第二项相比可以忽略不计，我们可以假设凸面镜的放大倍数等于

$$\Gamma_1 = \frac{R_1}{2d_1}.$$

类似地，放大镜（凹面镜、镜面）背面给出的物体的放大倍数也可以用相同的公式表示，只不过不是$R_1$而应该是$R_2$，并且一起是$d_1 - d_2$：

$$\Gamma_2 = \frac{R_2}{2d_2}.$$

由于放大镜是薄透镜，即其厚度与曲率半径相比较小，因此$d_1$和$d_2$的距离差可以忽略不计。那么对于放大镜表面给出的物体的放大倍数，我们有

$$\Gamma_1 = \frac{l_1}{l} = \frac{R_1}{2d} \text{ и } \Gamma_2 = \frac{l_2}{l} = \frac{R_2}{2d},$$

其中$d = d_1 = d_2$是物体到放大镜的距离。

因此，如果获得不同尺寸的图像$l_1$和$l_2$，则放大镜的曲率半径是不同的。通过测量物体到放大镜的距离并改变放大镜表面的放大倍数，可以确定其表面的曲率半径。

我们建议您用眼睛晶状体模型检查另一个实验。

用橡皮泥制作一个小矩形室；将放大镜插入腔室的侧壁。获取燃烧的骆驼的图像 -

将芽置于放大镜表面反射的光线中，并注意其亮度。现在将水倒入相机中 - 放大镜后表面创建的图像的亮度将会降低。事实证明，从两种介质之间的界面反射的光强度取决于这些介质的折射率*)。在这种情况下，当用水替换空气时，反射光的强度降低。

我们已经足够详细地分析了如果眼睛的光学系统由单晶体组成，则在反射光中应该观察到什么。然而，眼睛也有角膜和两个充满房水和玻璃体液的腔室。

您可以通过将光焦度为 +1 屈光度的窗玻璃（在所有药店均有销售）放置在放大镜前面 2-4 毫米处来模拟角膜的活动。将手电筒灯泡发出的光引导到最终的光学系统上。从灯泡的侧面观察电线，您会看到它的四个图像，其中三个是直的，一个是倒置的。请注意，光从车窗玻璃表面反射形成的图像彼此非常接近。

用水填充窗玻璃和放大镜之间的空腔以及放大镜后面的塑料室。观察这如何改变光学系​​统的各个球面创建的图像的亮度。

他建议大家在建立模型实验时，任何情况下都不要着急。您执行得越仔细，您就越了解应该在活体眼睛中观察到什么，并且越容易显示所需的图像。
