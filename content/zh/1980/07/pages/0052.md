数学

笔试

选项1

1. 由无限等比级数的奇数项组成的无限等比级数之和为$\frac{64}{3}$，由同一级数的偶数项组成的级数之和为$\frac{32}{3}$。找到进展。

2. 它将正三角形的一个底边分配给半径为$R$的球的大圆，另一个底边的顶点属于该球的表面。确定棱柱的高度，在该高度处其所有边的长度之和最大。

3. 解方程
$$\cos 3x - \cos 7x = \sqrt{3} \sin 2x$$

4. 求函数的定义域
$$y = \log_2(2^{-x} - \frac{1}{2})$$

5. 确定 $a$ 的什么值不等式成立
$$\frac{1}{\sqrt{a}} \int \left( \frac{3}{2} \sqrt{x} + 1 - \frac{1}{\sqrt{x}} \right) dx < 4.$$

选项2

1. 算术级数的所有成员都是自然数。从第一项开始，连续九项的总和大于 200 但小于 220。如果第二项是 12，请求级数。

2. 一个正三棱柱内接于一个球体，其所有棱长都等于$a$。一个类似的棱柱，其下底位于该棱柱的上底上，其上底的顶点属于球面。求第二个棱镜的边长。

3. 求函数的最大值和最小值
$$f(x) = 4x^3 - 9x^2 - 12x$$
在区间$[-1; 1]$内。

4. 解方程
$$\log_3 (5-x) + 2 \log_3 \sqrt{3-x} = 1.$$

5. 计算由直线包围的图形的面积（使图）$y = (x-1)^2$，$y=x+1$。

物理

口语考试目标

1. 两个物体从一点垂直向上抛掷，一个接着一个，积分为 $t = 2$ s，初始速度相同 $|v_0| = 50$ m/s。多久之后，尸体会在什么高度相遇？

2. 一个小物体从半径为 $R$ 的半球顶部无摩擦地滑动。在什么高度，它会被半球表面拒绝？

3. 质量为 $M = 450$ kg 的枪沿水平方向移动。弹丸的质量为$m = 5$ kg，初速度为$|v_0| = 450$ m/s。发射时，枪管阻力 $s = 45$ 厘米。确定 Ordium 反冲装置产生的制动力的平均值。

4. 体积为$V = 10$l的钢瓶中装有氢气，温度为$t = 20^\circ$℃，压力为$p = 10^7$Pa。当剩余的氢气完全除去后，如果形成$m = 50$g水，则从钢瓶中释放出多少氢气？

5. 如果水面大气压为$p_0 = 10^5$ Pa，气泡在什么深度处的直径比水面小二分之一？水温在任何深度都被认为是恒定的。水的密度为$q = 10^3$kg/m3。

6. 内阻为 $R = 75$ 欧姆的测量设备的刻度为 $n = 150$ 格。分度值$U_0 = 10$ mV。如何使用该装置改变： a) 电流达到$I = 1,5$ A； b) 电压高达 $U = 750$ V？

7. 质量为 $m = 3$ kg 的近线性导体，流过 $I = 5$ A 的电流，在感应为 $|\vec{B}| = 3$ T 的单锅磁场中垂直上升，以与磁力线 $\alpha = 30^\circ$ 的角度移动。开始运动后$t = 2$秒后，他的速度达到$|\vec{v}| = 10$米/秒。确定导体的长度。
