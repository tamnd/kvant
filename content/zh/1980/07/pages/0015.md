图 5.

光波落在光栅狭缝中的每个点都是向各个方向传播的次级光波的源。例如，从我们选择的光栅部分发出的二次光波沿其相互增强的方向传播，确定条件 $d \sin \alpha_k = \pm n \lambda$ ($n = 0, 1, 2, \dots$) (**)

（参见物理 10，第 183 页）。到达零级 ($n=0$) 和一级 ($n=1$) 级光束的最大能量。因此，最成功的次级光波发生在由角度决定的方向上

$$\alpha_0 = 0, \sin \alpha_k = \pm \frac{\lambda}{d} = \pm \frac{\lambda}{\Delta r_k}.$$

值$\Delta r_k$会找到，使用(*)：

$$\Delta r_k = r_{k+1} - r_k = \frac{r_{k+1}^2 - r_k^2}{r_{k+1} + r_k} \approx \frac{2a \lambda}{2r_k} = \frac{a \lambda}{r_k}.$$

因此，

$$\sin \alpha_k = \pm \frac{r_k}{a}.$$

从$\sin \alpha_k$的表达式可以看出，随着$k$的增大，$\alpha_k$的值也增大。

换句话说，离板中心越远，来自一阶光束的光线传播的角度就越大。结果，所有偏转角度$\sin \alpha_k = +\frac{r_k}{a}$的光线都相交于一点$S'$，形成点$S$的实像；偏转角度 $\sin \alpha_k = -\frac{r_k}{a}$ 的光线在其延伸处相交于点 $S''$，创建点 $S$ 的最小图像。在本例中，点 $S'$ 和 $S''$ 距离板的距离为 $a$。

让我们证明一下。由图5可知，波带片到点$S'$和$S''$的距离$x$为

$$x = r_k \text{ ctg } \alpha_k = \frac{r_k \sqrt{1 - \sin^2 \alpha_k}}{\sin \alpha_k} = \frac{r_k \sqrt{1 - r_k^2 / a^2}}{r_k / a} \approx a.$$

因此，当点$S$的头架被参考平面波照射时，我们获得点$S$的两个图像：真实图像$S'$和最小图像$S''$，位于板的相对两侧，距板的距离$a$。

波带片聚焦波、创建物体真实图像的能力早在 19 世纪就已广为人知。他们创建最小图像的能力只有在 golovrafini 中才得到赞赏，因为发散的光线可以恢复物体的未扭曲图像，是光波信号的精确副本。
