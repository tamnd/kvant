因此，在相对于地球以恒定速度$\vec{v}_0$运动的参考系中，物体沿抛物线运动。

根据问题的条件，物体两次与斜线相交的距离与前方观察者的距离相同。这意味着从观察者的角度来看，物体沿垂直直线运动，即像一个垂直向上抛掷的物体。

向量 $\vec{v}_0$ 和 $\vec{v}_1$ 使得向量 $\vec{v}$ 是垂直的（参见 图）。

在移动参考系中，物体在垂直轴$Y$上投影的运动方程，方向向上，

$$y = y_0 + vt - \frac{gt^2}{2}.$$

在$t = t_0 = 0$（我们从物体第一次穿过观察到的轨迹的那一刻开始计算时间）和$t = \tau$处，物体坐标的值重合：$y = y_0$，即

$$y_0 = y_0 + vt - \frac{g\tau^2}{2}.$$

从这里

$$v\tau - \frac{g\tau^2}{2} = 0 \Rightarrow v = \frac{g\tau}{2}.$$

因此，运动参考系中的物体方程具有以下形式

$$y = y_0 + \frac{g\tau}{2}t - \frac{gt^2}{2}.$$

让我们求出身体在连续相等的时间间隔 t 内走过的路径的比率。对于$t = n\tau$

$$y_n = y_0 + n\frac{g\tau^2}{2} - n^2\frac{g\tau^2}{2};$$

在 $t = (n + 1)\tau$

$$y_{n+1} = y_0 + (n + 1)\frac{g\tau^2}{2} - (n + 1)^2\frac{g\tau^2}{2};$$

因此，

$$\Delta y_n = y_{n+1} - y_n = ng\tau^2.$$

第一段时间t内，物体坐标变化为零：$\Delta y_0 = y_1 - y_0 = 0$($n = 0$)；对于第二时间段 t（观察到物体与轨迹第二次相交后）- $\Delta y_1 = g\tau^2$； $\Delta y_2 = 2g\tau^2$等

因此，在连续相等的时间间隔 t 内观察到轨迹的第二次相交之后物体所经过的路径的比率等于

$$\Delta y_1 : \Delta y_2 : \Delta y_3 \dots = 1 : 2 : 3...$$
