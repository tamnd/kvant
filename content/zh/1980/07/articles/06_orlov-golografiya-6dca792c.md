什么是全息术？

全息术是一种记录和恢复图像的方法。但对于摄影来说也是如此。全息摄影与摄影有何不同？

拍摄配准物体时，本质上是物体反射的光波振幅在感光胶平面上的分布——毕竟，感光板的黑度是由光的强度决定的，而强度与光波振幅的平方成正比。

当在平板上进行全息照相时，记录物体反射的光波振动的振幅、相位和频率在平板平面上的分布。

为了获得板平面上的源波形，Gabor 建议使用时间恒定的波形。要计算振幅，最简单的方法是使用矢量图法（参见“物理学 10”，第 51 页）。

当两个相同频率的振荡相加时，$\omega$和初始物理振荡不同，但在每个点振幅随时间保持不变。要计算幅度，最简单的方法是使用矢量图法：

$$X_p^2 = X_1^2 + X_2^2 + 2X_1X_2 \cos(\omega t + \varphi_1) + X_2 \cos(\omega t + \varphi_2) = X_p \cos(\omega t + \varphi)$$

（参见图2）。 $X_p$的振幅和物理产生的振荡可以从矢量图中找到：

光波落在光栅狭缝中的每个点都是向各个方向传播的次级光波的源。例如，从我们选择的光栅部分发出的二次光波沿其相互增强的方向传播，确定条件 $d \sin \alpha_k = \pm n \lambda$ ($n = 0, 1, 2, \dots$) (**)

（参见物理 10，第 183 页）。到达零级 ($n=0$) 和一级 ($n=1$) 级光束的最大能量。因此，最成功的次级光波发生在由角度决定的方向上

$$\alpha_0 = 0, \sin \alpha_k = \pm \frac{\lambda}{d} = \pm \frac{\lambda}{\Delta r_k}.$$

值$\Delta r_k$会找到，使用(*)：

$$\Delta r_k = r_{k+1} - r_k = \frac{r_{k+1}^2 - r_k^2}{r_{k+1} + r_k} \approx \frac{2a \lambda}{2r_k} = \frac{a \lambda}{r_k}.$$

因此，

$$\sin \alpha_k = \pm \frac{r_k}{a}.$$

从$\sin \alpha_k$的表达式可以看出，随着$k$的增大，$\alpha_k$的值也增大。

换句话说，离板中心越远，来自一阶光束的光线传播的角度就越大。结果，所有偏转角度$\sin \alpha_k = +\frac{r_k}{a}$的光线都相交于一点$S'$，形成点$S$的实像；偏转角度 $\sin \alpha_k = -\frac{r_k}{a}$ 的光线在其延伸处相交于点 $S''$，创建点 $S$ 的最小图像。在本例中，点 $S'$ 和 $S''$ 距离板的距离为 $a$。

让我们证明一下。由图5可知，波带片到点$S'$和$S''$的距离$x$为

$$x = r_k \text{ ctg } \alpha_k = \frac{r_k \sqrt{1 - \sin^2 \alpha_k}}{\sin \alpha_k} = \frac{r_k \sqrt{1 - r_k^2 / a^2}}{r_k / a} \approx a.$$

因此，当点$S$的头架被参考平面波照射时，我们获得点$S$的两个图像：真实图像$S'$和最小图像$S''$，位于板的相对两侧，距板的距离$a$。

词汇图的性质和特征

显示使用图形重建的图像将展示任何观众的想象力。现在的图像是“真实的”，你想要触摸它以确保它只是一个图像而不是物体本身。可以从不同角度查看图像；您可以重新聚焦眼睛，检查物体的近处和远处，并观察物体上光反射的变化。图9和图10显示了从各个观察点拍摄的gogram图像的照片。

图形图的一个非常重要的特性是能够使用图形图的各个部分来恢复整个图像，并且图形图对介质配准中的灰尘颗粒、划痕和微小缺陷的敏感性较低。这些特性是由于曝光时印版的每个点都受到物体所有点散射的光的照射，而物体每个点反射的光照亮了整个印版。可以使用自制波带片轻松检查图像的这些属性：用波带片获得的图像在曝光时保留了波带片的部分内容。

结论

在本文的结论中，我想回答以下问题：为什么全息术——原则上是由两个相干点形成的干涉图案的一种简单的成像方法——直到最近才被创造出来？事实上，干涉和衍射早在 19 世纪就得到了很好的研究。摄影术发明于19世纪中叶；所以Gabor不需要任何新的科学成就的知识来打开全息。然而，需要对干涉和衍射现象有深刻的理解，当然，还需要有创造性的思维，才能将全息术的所有已知元素结合到一个聪明的想法中。全息术创造的例子已经被充分利用，在我们的形态学中，新的、有价值的想法和发现是在旧的、众所周知的概念的基础上诞生的。
