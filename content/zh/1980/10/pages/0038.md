F607。飞机沿封闭航线 ABC 飞行。 A、B、C 点位于正三角形的三个顶点。风向AB方向吹还是风向BA方向吹，哪种情况下飞行时间会更少？

图 1.

图 2.

设 $l$ 表示三角形 ABC 的边长。如果矢量的速度为 $u$ 且吹向 $\overrightarrow{AB}$ 方向，则沿着矢量 $\overrightarrow{AB}$ 飞机以速度 $u + v$ 飞行（其中 $v$ 为飞机速度模数），飞行时间为 $A \rightarrow B$
$$t_1 = \frac{l}{u + v} = \frac{l}{v(1 + d)},$$，其中$d = \frac{u}{v}$。

飞机沿向量 $\overrightarrow{BC}$ 以速度 $\overrightarrow{v}_1 = \overrightarrow{v} + \overrightarrow{u}$ (图 1) 飞行。由于向量 $\overrightarrow{v}_1$ 沿着向量 $\overrightarrow{BC}$，因此向量 $\overrightarrow{v}_1$ 的模等于向量 $\overrightarrow{v}$ 和 $\overrightarrow{u}$ 在 $\overrightarrow{BC}$ 上的投影之和，并且这些向量在垂直于 $\overrightarrow{BC}$ 的轴上的投影之和为零：
$$v_1 = v \cos \beta - u \sin \alpha,$$
$$v \sin \beta - u \cos \alpha = 0.$$
从这里开始，考虑到 $\alpha = 30^\circ$，我们得到
$$v_1 = v \sqrt{1 - \frac{u^2}{v^2} \cos^2 \alpha} - u \sin \alpha = \frac{1}{2}v \sqrt{4 - 3d^2} - \frac{1}{2}d.$$
相同的p。模块将是 CA 部分的速度。因此，飞机飞行需要时间$B \rightarrow C \rightarrow A$
$$t_2 = \frac{2l}{v_1} = \frac{4l}{v \sqrt{4 - 3d^2} - dv}.$$
航班$A \rightarrow B \rightarrow C \rightarrow A$的总时间$t$为$t_1 + t_2$。
如果风沿着向量$\overrightarrow{BA}$吹，则$A \rightarrow B$会及时完成
$$t'_1 = \frac{l}{v - u} = \frac{l}{v(1 - d)}.$$
在这种情况下，BC 和 CA 部分的速度 (图 2) 大小相等
$$v'_1 = \sqrt{v^2 - \frac{3}{4}u^2} + \frac{1}{2}u = v \sqrt{1 - \frac{3}{4}d^2} + \frac{1}{2}dv,$$
$B \rightarrow C \rightarrow A$ 航班需要时间
$$t'_2 = \frac{2l}{v'_1} = \frac{4l}{v \sqrt{4 - 3d^2} + dv}.$$
在这种情况下，航班 $A \rightarrow B \rightarrow C \rightarrow A$ 的总时间 $t'$ 等于 $t'_1 + t'_2$。 $t'$与$t$的时间比为
$$\frac{t'}{t} = \frac{1}{1 + d} + \frac{4}{\sqrt{4 - 3d^2} + d}.$$
进行代数变换，我们得到
$$\frac{t'}{t} = 1.$$
