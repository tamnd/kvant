问题6

让我们证明序列 $(n_k)$ 总是有界的。事实上，$n_k \leq n_{k+1} \leq n_k + 9^{c(n_k)}$对于所有$k$，其中$c(n_k)$表示数字$n_k$的位数。让我们假设对于某些选择$n_1$，序列$(n_k)$是无限的。让我们选择一个自然数$N$，以满足两个条件：$10^N > n_1$和$9^N < 10^{N-1}$（因为$10^N$无限制地增加，而$(9/10)^N$在$N \to \infty$趋于0，这样的选择是可能的）。从 $(n_k)$ 的无界性可以得出，从某个数字 $k$、$n_k > 10^N$ 开始，因此对于较大的数字存在平均数 $n_k < 10^N$ - 令其为 $n_p$。但是$10^N \leq n_{p+1} \leq n_p + 9^{c(n_p)} < 10^N + 9^N < 10^{N-1}$，这意味着$n_{p+1}$以数字10和$P(n_{p+1}) = 0$开头。因此，对于所有 $k \geq p+1$，$n_{p+2} = n_{p+1}$、$n_{p+3} = n_{p+1}$ 以及一般的$n_k = n_{p+1}$，这与序列 $(n_k)$ 无界的假设相矛盾。

请注意，根据上述推理，实际上，对于$n_1$的任何选择，序列$(n_k)$都是稳定的，即某个数字$k$、$n_k$的值不会改变。

问题1

因为 999 可以被 37 整除，所以是一个六位数

$$\frac{a_1 b_1 c_1 a_2 b_2 c_2}{a_1 b_1 c_1 + a_2 b_2 c_2} = \frac{a_1 b_1 c_1}{(999+1)} + \frac{a_2 b_2 c_2}{(999+1)}$$

能被 37 整除当且仅当该数能被 37 整除

$$\frac{a_1 b_1 c_1}{a_2 b_2 c_2} + \frac{a_2 b_2 c_2}{(999+1)} = (a_1+a_2) 100 + (b_1+b_2) 10 + (c_1+c_2).$$

由于数字$a_1$和$a_2$、$b_1$和$b_2$、$c_1$和$c_2$以对称方式包含在最后一个表达式中，重新排列这些对中的数字使我们能够从此数字中获得另外七个可被37整除的数字。

接下来我们注意到

$$10(100a+10b+c) = 999a + (100b+10c+a),$$

与 $\frac{a_1 b_1 c_1 a_2 b_2 c_2}{b_1 c_1 a_2 b_2 c_2}$ 一样，数字也能被 37 整除

$$\frac{b_1 c_1 a_1 b_2 c_2 a_2}{c_1 a_1 b_1 c_2 a_2 b_2}.$$

前面的排列使我们能够从这些数字中获得另外七个数字；分成37个六位数，通过排列它们的数字，我们可以得到超过23个其他数字；例如，从数字 123,876 中您可以得到 47 个数字！

问题3

显然，$(x; y; z) = (\pi k; \pi l; \pi m)$是该系统对于任意整数$k, l, m$的解。让我们证明没有其他解决方案。

从前两个方程之和中减去第三个方程并应用已知公式，我们得到

$$\sin x + \sin y + \sin (x+y+z) - \sin z = 0,$$

$$2 \sin \frac{x+y}{2} \cos \frac{x-y}{2} +$$

$$+ 2 \sin \frac{x+y}{2} \cos \left( \frac{x+y}{2} + z \right) = 0,$$

$$4 \sin \frac{x+y}{2} \cos \frac{x+z}{2} \cos \frac{y+z}{2} = 0.$$

因此，三个关系中至少有一个是正确的：

1) $\frac{x+y}{2} = \pi n$, 2) $\frac{x+z}{2} = \frac{\pi}{2} + \pi n,$

3) $\frac{y+h}{2} = \frac{\pi}{2} + \pi n,$

其中$n$是任意整数。

在第一种情况下$y = -x+2\pi n$，$x+y+z = z+2\pi n$，代入原系统的第一个和最后一个方程后，我们得到

$$\sin x + 2 \sin z = 0, \quad \sin z + 4 \sin z = 0,$$

在哪里

$$\sin z = 0 \text{ и } \sin x = 0;$$

相应的解决方案$(x; y; z)$属于所示的那些。

第二和第三种情况的划分类似。

问题6

让我们提出相反的建议。从对于任何 $a$ 这个方程有有限个解的事实来看，对于某个数字 $M$ 对于任何 $a$ 这个方程有超过 $M$ 个自然数解。让我们取任意自然数$N$，对于满足条件1≤x≤N、1≤y≤N的每个$N^2$对$(x; y)$自然数，我们计算表达式$[x^{3/2}] + [y^{3/2}]$的值。根据假设，每个值最多不会超过$M$次，因此结果将不少于$N^2/M$个不同的自然数。其中数量不少于$N^2/M$；对于某些对 $(x_0; y_0)$ 不等式将得到满足

$$[x_0^{3/2}] + [y_0^{3/2}] \geq \frac{N^2}{M}.$$
