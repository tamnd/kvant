电极之间的单位电荷。由于这项工作是任意对抗力$F = evB$，通道张力等于$d$、$\mathcal{E} = Fd/e = vBd$。对于 $d = 3$ m、$v = 1500$ m/s 和 $B = 5$ T $\mathcal{E}$ 将为 22.5 kV - 相当大的值，足以满足实际应用。

让我们回到法拉第时间，估算一下放入泰晤士河中的一对电极的电动势（当然，河流不是导电气体流，而是导电液体流，但没有根本区别）。泰晤士河是一条宽阔的河流（这很好），但水流很慢（这很糟糕），而且地球磁场很小（这也是很糟糕）。轮询$d = 30$ m，$v = 0,1$ m/s，$B = 10^{-4}$ T，我们得到$\mathcal{E} = 3 \cdot 10^{-4}$ V。（法拉第无法更改此值...）
$M\Gamma D$振荡器的当前内阻。

众所周知，长度为$L$和横截面$S$的金属导体的电阻等于$R = \frac{mL}{e^2n\tau S}$，其中$m$和$e$是电极的质量和电荷，$n$是金属中自由电极的浓度，$\tau$是电极自由通过的时间（参见“物理9”，第 175 页）。我们可以将此公式用于气体具有电子传导性的情况，将“气体”值$t$和$n$代入公式中。在$T = 2000$ K 的温度和$10^5$ Pa 通道中的气体压力（$M\Gamma D$ 发电机的常见值）下，$t$ 为$\sim 10^{-12}$ s。从图可以看出，在我们的例子中是$L = d$，$S = hl$，所以$R = 3,5 \cdot 10^{19} \frac{d}{nhl}$。因此，我们将 $R$ $M\Gamma D$ 发生器的内阻与通道尺寸和气体中电极的浓度相关联。

为了使$M\Gamma D$发电机的使用在经济上可行，必须确保$R$的值是多少？假设从通道维度为 $d = h = 3$ m、$l = 15$ m 的生成器中，我们想要获得$P = 2000$ MBt 的幂。如果负载电阻为$R_H$，则发电机和负载中的电流为$I = \mathcal{E}/(R + R_H)$，发电机产生的功率为$P_r = \mathcal{E}I = \mathcal{E}^2/(R + R_H)$，负载中释放的功率为$P = \mathcal{E}^2R_H/(R + R_H)^2$，功率损耗为$P_n = \mathcal{E}^2R/(R + R_H)^2$。由于根据条件$P = 2000$ MBt，以及$\mathcal{E} = 22,5$ kV，则$R_H = 4(R + R_H)^2$。我们“发明”$M\Gamma D$发电机的主要原因是效率高。这意味着 $P_n$ 应该只是 $P_r$ 的一小部分 - 比如说，不超过 10%。否则，$M\Gamma D$发电机的效率并不比传统火力发电厂更高。所以，$P_n \leq 0,1P_r$为空，即$\mathcal{E}^2R/(R + R_H)^2 \leq 0,1\mathcal{E}^2/(R + R_H)$；然后$R \leq 0,11R_H$。从这里开始，从$R_H = 4(R + R_H)^2$我们有$R \leq 0,022$欧姆。为了在给定值 $d = h = 3$ m、$l = 15$ m 的情况下获得这样的 $R$，电极浓度必须为 $n \geq 10^{20}$ 电极/立方米。但气体中是否缺少这么多电极呢？在 2000 K 的温度下，实际的天铜矿由氖化分子组成；它可以通过加热来焚烧，例如加热到 8000 K。但是在这个温度下，所有已知的材料都会漂浮 - $M\Gamma D$ 通道和燃烧室根本不会由......制成

然而，可以通过向气体中添加易氧化的添加剂来增加电极的浓度。此类添加剂或所谓的添加剂可以是碱金属，其中添加钾和铯是最有效的。例如，在 $\text{CO}_2 + \text{H}_2\text{O}$（煤或天然气燃烧产物）的混合物中添加 1% 钾，在气体温度为 2500 K 时产生的电极浓度是不添加钾时的 $10^{24}$ 倍。

钾添加剂以盐 $K_2\text{CO}_3$ 或 $K_2\text{SO}_4$ 的形式引入燃烧室后面的$M\Gamma D$通道的最开始处，即廉价且容易获得的钾化合物。颗粒必须很小，大约一微米大小——它们必须有时间在通道的最开始处熔化、蒸发、分解和电离，以便具有足够电导率的气体到达电极。

铯的添加进一步提高了气体的电导率。但铯非常昂贵，只有在$M\Gamma D$发电机运行过程中不需要恒流时才可以使用
