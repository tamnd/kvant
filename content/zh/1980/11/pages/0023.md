⟦folio 21⟧

问题解决方案

M605。平面上标记有 2n+1 个不同的点。让我们用数字 1, 2, ..., 2n+1 对它们进行编号，并考虑 R 平面的以下变换：首先，相对于第一个点对称，然后相对于第二个点对称，依此类推，直到第 (2n+1) 个点。

a) 表明该变换 R 有一个“不动点”（映射到自身的点）。

让我们考虑命名多达 2n+1 个点（按数字 1、2、...、2n+1）的所有可能方法。每个这样的名称都对应于它自己的平面 R 变换和它自己的固定点。令 F 为所有这些变换的不动点集。

6) 指定 n=1 的集合 F。

c) 对于每个 n=2, 3, ...，集合 F 可以包含的最大点数和最小点数是多少？

我们固定一个任意坐标系。

令点 A(x; y) 和 A*(x*; y*) 相对于点 A'(x'; y') 对称。那么 x' = (x+x*)/2, y' = (y+y*)/2，因此 x* = 2x' - x, y* = 2y' - y。

因此，坐标为 (x; y) 且相对于坐标为 (x'; y') 的点对称的点会变成坐标为 (2x' - x; 2y' - y) 的点。

通过我们的变换 R，坐标为 (x; y) 的点将转到坐标为 (-x+2x1 - 2x2+...+2x2n+1; y+2y1 - 2y2+...+2y2n+1) 的点，其中 (x_i; y_i) 是给定 2n+1 个点中第 i 个点的坐标。

a) 对于变换 R 的固定点 (x; y)，这些坐标由条件唯一确定

$$\begin{cases} -x+2x_1-2x_2+\dots+2x_{2n+1}=x, \\ -y+2y_1-2y_2+\dots+2y_{2n+1}=y \end{cases}$$

且等于 (x_1-x_2+\dots-x_{2n}+x_{2n+1}; y_1-y_2+\dots-y_{2n}+y_{2n+1}) 或

$$\left( \sum_{i=1}^{2n+1} (-1)^{i-1} x_i; \sum_{i=1}^{2n+1} (-1)^{i-1} y_i \right).$$

陈述a)已被证明。

6) 首先让给定的点 X1、X2、X3 不在同一条线上。如果对称点 X1、X2、X3 之后的点 A1 映射到自身（参见图），则 X1、X2、X3 是线段 A1A2、A2A3、A3A1 的中点，其中 A2 = S_{X1}(A1)、A3 = S_{X2}(A2)。这意味着[A1X2]、[A2X3]、[A3X1]是三角形A1A2A3的中线，因此可以从现成的以O为中心、系数为(-2)的点X1、X2、X3得到点A1、A2、A3。很容易看出，如果给定点 X1、X2、X3 位于一条直线上，则答案在某种意义上是相同的。

c) 看表达式(*)，不难看出，集合F中的点不超过从2n+1个给定点生成表达式(*)中横坐标前面加负号的n个点的方法的数量，即不超过C2n+1个。显然，这个估计是准确的（例如，取同一直线上的 2n+1 个点，整数坐标为 1, 2, 2^2, ..., 22n）。

现在让我们估计固定点的数量。让我们将这 2n+1 个点投影到一条直线上，这样就不会有两个点合二为一。在此行中，我们输入坐标并按坐标升序更改点：x1 < x2 < ... < x2n+1。让我们在前 n 个数字前面加上 n 减号，并考虑总和 - x1 - x2 - ... - xn + xn+1 + ... + x2n+1；它将对应于集合 F 中的某个固定点。接下来，我们执行以下操作：选择一对数字 x_i 和 x_i+1，使得 x_i 前面有一个减号，x_i+1 前面有一个加号，并更改它们的符号（在第一步中，估计 i=n）。每个这样的操作都会导致与集合 F 中的一个固定点相对应的和，并且由于每次操作之后该和都会减少，因此所有这些固定点都是不同的。我们可以执行所有此类操作（无论其顺序如何）n(n+1)，这已经给了我们
