I·克鲁莫娃

◆ 从方程$\frac{1}{x} - \frac{1}{y} = \frac{1}{n}$可得$\frac{1}{x} > \frac{1}{n}$，即$x < n$。因此，如果$n = 1$，则自然数无解。让$n \neq 1$，然后$x = n - i$，$0 < i < n$和$\frac{1}{n - i} - \frac{1}{n} = \frac{1}{y}$。因此$y = \frac{n(n - i)}{i}$。然而，总有一个解（自然数）：它在 $i = 1: x = n - 1, y = n(n - 1)$ 处获得。

现在令 $n$ 为素数，$i > 1$。那么数字$n$和$i$是互质的，数字$n - i$和$i$也是互质的，因此数字$n(n - i)$和$i$也是互质的（通过考虑和$n(n - i) + ni$来说服自己这一点。波兹尼姆，如果$n$是质数，和$i > 1$，我们得到$y = \frac{n(n - i)}{i} \notin \mathbb{N}$。这意味着对于一个简单的$n$，$i = 1$是必要的，并且我们的方程有唯一解。

如果$n$是合数：$n = n_1n_2$，那么例如放入$i = n_1$，我们除了得到解$x = n - 1$、$y = n(n - 1)$之​​外，还得到：$x = n - n_1$、$y = n_2(n - n_1)$。这完全证明了问题的表述。
