三点，三点，三点……

有一次，在一所数学研究很深、对申请者要求很高的大学入学考试中，一位申请者被问了一个乍一看很简单的问题：

方程$\left(\frac{1}{16}\right)^x = \log_{\frac{1}{16}} x$有多少个解？

由于解方程$\varphi(x) = \psi(x)$等价于求出函数$y = \varphi(x)$和$y = \psi(x)$的图像相交点的横坐标，因此考生将函数$y = \left(\frac{1}{16}\right)^x$和$y = \log_{\frac{1}{16}} x$的图像作了拟美加（图1）并表示：

“这个方程有一个解。此外，由于根据对数的定义，函数 $y = \left(\frac{1}{16}\right)^x$ 和 $y = \log_{\frac{1}{16}} x$ 彼此相反，因此它们的图形是负对称的。”

图 1.

相对于线$y = x$，因此图的交点位于这条线上。这意味着要找到它，我们需要求解方程 $\left(\frac{1}{16}\right)^x = x$。但我不知道如何解决。”

考官回复：

“事实上你不知道如何解方程$\left(\frac{1}{16}\right)^x = x$不是问题，我们不要求这个：它不能用初等方法解。更糟糕的是你错过了他的两个解：$x = \frac{1}{2}$和$x = \frac{1}{4}$。将这些值代入方程并检查！”

事实上，在写出解决方案$\left(\frac{1}{16}\right)^{\frac{1}{2}} = \log_{\frac{1}{16}} \frac{1}{2}$和$\left(\frac{1}{16}\right)^{\frac{1}{4}} = \log_{\frac{1}{16}} \frac{1}{4}$后，申请人悲伤地发现它们是正确的：

$\left(\frac{1}{16}\right)^{\frac{1}{2}} = \log_{\frac{1}{16}} \frac{1}{2} = \frac{1}{4}$ 和 $\left(\frac{1}{16}\right)^{\frac{1}{4}} = \log_{\frac{1}{16}} \frac{1}{4} = \frac{1}{2}$。因此，他被“可见性”所欺骗：函数$y = \left(\frac{1}{16}\right)^x$和$y = \log_{\frac{1}{16}} x$的图形不仅相交于点$P(b; b)$，而且还相交于另外两个点：$M\left(\frac{1}{4}; \frac{1}{2}\right)$和$N\left(\frac{1}{2}; \frac{1}{4}\right)$，与相对线$y = x$对称。

申请人的错误原因如下。他知道，在$0 < a < 1$处，函数$y = \log_a x$的值随着$x$接近于零而无限增加，而函数$y = a^x$在$x = 0$处的值为1。从这里他得出了“结论”：在整个区间$]0; b[$上，其中$b$是该点的横坐标$P$、$a^x < \log_a x$，因此这些函数的图像除了$P$之外没有其他交点。然而，这个结论应该以同样的方式得出，看看苏联足球锦标赛的决赛桌，人们应该得出这样的结论：即使在第一轮之后，获胜的球队仍然领先 - 众所周知，他们认为这是非常秋天的。

让我们用 $-k^{**}$ 表示 $\ln a$。那么函数$y = a^x$和$y = \log_a x$将写成如下：$y = e^{-kx}$和$y = -\frac{\ln x}{k}$。

求它们图的交点相当于求函数$F(x) = e^{-kx} + \frac{\ln x}{k}$的图与横坐标轴相交的点，后者与函数$F$增减区间的研究有关。为此，我们将找到一个任意的：

$$F'(x) = -ke^{-kx} + \frac{1}{kx} = \frac{1 - k^2xe^{-kx}}{kx}.$$

我们来看三个案例。

第一种情况：$0 < k < e$。让我们证明，在这种情况下，$F'(x) > 0$ 对于所有$x > 0$。为此，只需证明函数$1 - k^2xe^{-kx}$在$x > 0$处的最小值为正就足够了。这个最小值是在$(1 - k^2xe^{-kx})' = 0$，即$-k^2e^{-kx} + k^3xe^{-kx} = 0$的点实现的。解这个方程，我们得到$x = \frac{1}{k}$。此时，(1)中$x$的值等于$1 - ke^{-1}$，$k < e$为正。由于这个值是最小的，那么$F'(x) > 0$对于所有$x > 0$。

根据 $F'(x) > 0$ 在 $x > 0$ 的事实，可以得出函数 $F$ 在射线 $0; +\infty$ 上返回 [并且其图形将一次与 x 轴 $^*$ 相交]。因此，在$0 < k < e$处，函数$y = e^{-kx}$和$y = -\frac{\ln x}{k}$的图形仅相交一次，即在线$y = x$上（与图1相同）。

第二种情况：$k > e$。这是一个环境问题。让我们用 $b$ 表示交点的横坐标

因此，如果 $k > e$，则相关图具有三个交点。

第三种情况：$k = e$。在函数 $e^{-kx}$ 和 $-\frac{\ln x}{k}$ 的图形的交点 $(b; b)$ 处，我们有 $e^{-kb} = b$，或者在我们的例子中为 $e^{-eb} = b$。立即替换可验证数字 $\frac{1}{e}$ 是方程 $e^{-ex} = x$ 的根。由于函数$e^{-ex}$杀死（在整条线上）并且函数$x$递增，因此方程$e^{-ex} = x$至多有一个根。所以，$b = \frac{1}{e}$。很容易检查$F(b) = F'(b) = 0$，因此函数$F$在$x = b = e^{-1}$处的图形与x轴接触。

在我们的例子中$F(x) = e^{-ex} + \frac{1}{e}\ln x$。因此$F'(x) = -e^{1 - ex} + \frac{1}{ex} = \frac{e^{ex} - 2}{xe^{ex} - 1}$。

导数函数$e^{ex} - 2$对于$x < b$是引式，对于$x = b$等于0，对于$x > b$等于正数。因此，函数$e^{ex} - 2$对于所有$x \neq b$都是正的。这意味着对于所有正的$x \neq b$，我们有$F'(x) > 0$。因此，函数 $F$ 的图形在点 $x = b$ 处接触 x 轴，当经过点 $b$ 时，符号从负号变为平面。

据此，函数$y = e^{-ex}$和$y = \frac{\ln x}{e}$的图形在它们的公共点$(e^{-1}; e^{-1})$处相互接触，相互“交织”（图4）。

总结一下：如果$1 > a \geq e^{-e} \approx \frac{1}{15,18}$，则函数$y = a^x$和$y = \log_a x$的图有一个交点；如果$e^{-e} > a > 0$，则有三个交点。

现在我们可以自信地说，函数$y = \left(\frac{1}{15,5}\right)^x$和$y = \log_{\frac{1}{15,5}} x$的图像有3个交点，而函数$y = \left(\frac{1}{10}\right)^x$和$y = \log_{\frac{1}{10}} x$的图像只有一个公共点。
