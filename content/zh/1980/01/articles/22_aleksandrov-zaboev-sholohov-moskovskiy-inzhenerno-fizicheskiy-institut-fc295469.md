⟦folio 51⟧

莫斯科工程物理学院

以下是 1979 年入学考试的公布材料。

数学

笔试

选项

1. 从A点和B点，我同时将两个行人缝合在一起。当从A出发的行人走完路径的1/3时，第二个行人距离路径中间有3公里。已知从B出发的行人走到一半时，第一个行人距离他有2公里，求A和B之间的距离。绘制行人速度。

2. 在正三角形原体中，底边内接圆的半径长度等于r，原体侧面的平面之间的值等于φ。确定体积为给定基体体积的√3倍的立方体的边长。

3. 找到 A、B、C，使得函数具有以下形式

$$f(x) = Ax^2 + Bx + C$$

满足条件$f'(1) = 8$、$f(2) + f''(2) = 33$、$\int f(x) dx = \frac{7}{3}$。

4. 由曲线$y = \sin 2x$、直线$x = \frac{\pi}{6}$、$x = a$和x轴围成的图形面积为0.5。确定a.

物理

口语考试目标

1. 均匀杆的上端绕带轴 O (图 1) 自由旋转。杆的下端放置在光滑桌子上的一块块上。杆的质量为 $m = 1,50$ kg，杆与垂直方向的夹角为 $a = 30^\circ$。如果用 $\vec{F}(|\vec{F}| \ge 2,45$ N) 的力将块向右拉，它就会从原来的位置移动。杆在移动过程中用多大的力压在块上？

2. 初始温度为$T_1 = 300$K、重量为$m = 1$kg的气态氢气被等容冷却，使其压力下降η=3倍。然后气体在恒定压力下膨胀。如果在最终状态下气体温度等于初始状态，求气体所做的功。

3. 质量为 $m = 20$ 毫克、装有电的小球悬挂在$l = 60$ 厘米长的细绝缘线上。在同一水平面内距悬浮球$l$处有一个半径为$a = 3$厘米（图2）的金属球。如果通过施加相对于地球 $U = 8$ kV 的电压给球体充电，球体上的螺纹与垂直线的最大角度偏离为 90°。求球上的电荷 q。

4. 在 图 3 所示的设置中，精确光源 S 位于薄透镜的主光轴上，距其距离 $|SO| = a = 0,6$ m。镜头光焦度$D = 2$ ditr.镜头后面有一个平面镜，法线 $\vec{n}$ 与镜头主光轴形成角度 $a = 15^\circ$。镜头到镜子的距离为$|ON| = l = 1$米。镜子绕透镜主光轴以恒定角速度旋转，而运动源以 $v = 0,31$ m/s 的速度均匀分布在圆周上。求镜子的自转周期。
