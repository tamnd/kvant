电池的 EMF，如果外部电流变化不应超过 50 mA？

$U = 26 - 13I$。负载直线与巴雷特电流电压特性的交点决定了流过电路的电流： $I_0 = 1000$ 毫安。根据问题情况，允许的电流限值为950 mA和1050 mA。我们在图表上画直线 $I_1 = 950$ 毫安和 $I_2 = 1050$ 毫安。它们与巴雷特的电流-电压特性交叉。让我们通过交点绘制负载线。 （由于负载线的斜率仅取决于电阻 $R$，根据问题的条件保持不变，所有载荷线都是平行的。）这些载荷线与轴相交 $U$ 在点 $U_1 = \varepsilon_1 = 20$ 在和 $U_2 = \varepsilon_2 = 32$ B. 因此，当电池电动势在以下范围内变化时 $\varepsilon_1 = 20$ 进入 $\varepsilon_2 = 32$ 电路中的电流将在以下范围内变化 $I_1 = 950$ 毫安至 $I_2 = 1050$ mA，即变化不变，精度为±5%。

S·科泽尔

F596。木星卫星 Io 两次连续掩星之间的时间间隔全年变化，最小值为 42 又 28 分 21 秒，最大值为 42 又 28 分 51 秒。接收这些数据，确定光速，假设地球在半径为 150 毫升的圆形轨道上绕太阳运行。公里。木星轨道半径远大于地球轨道半径，木星速度远小于地球速度；我们可以假设，在一年中，地球和木星的相对位置实际上没有变化，木卫一轨道周期的每个持续时间的变化仅与地球速度方向的变化有关。当地球速度沿着连接地球和木星的直线时，可以观察到木卫一每次旋转与真实旋转的最大偏差。

连续两次木卫一食之间的最小时间间隔$t_1 = 42$和28分21秒是在地球靠近木星时观测到的，最大时间间隔$t_2 = 42$和28分51秒是在地球远离木星时观测到的。第一种情况，在$t$时间内，对应木卫一的真实公转周期，地球将以$l = v_3t$的距离接近木星（$v_3$为地球速度），观测到的木卫一的公转周期将暂时小于真实的公转周期。

$$t - t_1 = v_3t / c,$$

其中$c$是光速。考虑到$t = (t_1 + t_2) / 2, t - t_1 = (t_2 - t_1) / 2$和$v_3 = 2\pi R / T$（$R = 150$ml.km是地球轨道半径，$T = 365$天是地球轨道周期），从最后的等式我们得到

$$t_2 - t_1 = \frac{2\pi R}{T} (t_2 + t_1) / c.$$

在哪里

$$c = \frac{2\pi R}{T} \frac{t_2 + t_1}{t_2 - t_1} \approx 3,03 \cdot 10^5 \text{ км/c.}$$
