M579。证明对于属于区间 [0; 的任何数字 $x_1, x_2, \dots, x_n$ 1]，不等式成立
$$x_1 + x_2 + \dots + x_n + 1)^2 \geqslant 4(x_1^2 + x_2^2 + \dots + x_n^2).$$

第一个决定。对于$x_n$，这个不等式是二次的，$P_2(x) = 3x_n^2 + Ax_n + B \leqslant 0$，并且它在区间 [0; 1]，如果$P_2(0) \leqslant 0$和$P_2(1) \leqslant 0$。这两个关于 $x_{n-1}$ 的不等式也是平方的，具有相同的形式，并且在整个区间 [0; ] 上有效。 1]，如果对 $x_{n-1} = 0$ 和 $x_{n-1} = 1$ 有效。这样进一步论证，我们发现只要检查0和1的集合$x_1, \dots, x_n$的原始不等式就足够了。如果$x_i$等于1的个数等于$k$，那么我们就得到了明显的不等式$(k+1)^2 \geqslant 4k$（即$(k-1)^2 \geqslant 0)$）。

第二个解决方案。由于数字 $x_1, x_2, \dots, x_n$ 属于区间 [0; 1],
$$4(x_1^2 + x_2^2 + \dots + x_n^2) \leqslant 4(x_1 + \dots + x_n),$$
我们的不平等再次重合到下一个
$$4S \leqslant (S+1)^2.$$

M580。在议会中，每个议员的敌人不超过三个。证明议会可以分为两院，这样与他同处一院的每位议员的敌人不会超过一个。 （认为​​如果$A$是$B$的敌人，那么$B$就是$A$的敌人）

让我们以任意方式进行分区。如果某个议会议员$A$在任何一个房间里有$\geqslant 2$个敌人，那么他在另一个房间里的敌人数量就是$\leqslant 1$。因此，将$A$移动到另一个房间后，房间内的敌人对总数将会减少。我们将继续这样的运动，直到满足所需的条件。

M581。 a) 是否有一个三位数的立方变成三个七？
6) 对于任意一组数字，最后一个不为0，是否存在包含这组数字的立方体？

a) 为了使数字$n^3$以7结束，数字$n$本身必须以3结束，因此如果所需的三位数$n$存在，则$n = ab^3 = 100a + 10b + 3 = 10(10a + b) + 3$。然后$n^3 = 10^3 \cdot A + 10^2(7a + 2b + 9b^2) + 10(7b + 2) + 7$。

当且仅当$7b$变为5时，即$b = 5$时，数字$7b + 2$变为7。然后$n^3 = 10^3 \cdot A + 10^2(7a + 8) + 77$。

当且仅当$a = 7$时，数字$7a + 8$变成7。

因此，$753^3$ 结果（至少）是三个七。

6) 不，不适合所有人。如果数字$n^3$变成5，那么数字$n$本身就变成5。但是如果$a$是偶数，则数字$(10a + 5)^3$变成25，如果$a$是奇数，则变成75。因此，对于每个$n$，数字$n^3$最终为05、15、35、45、55、65、85、95。

另外，如果$n^3$是偶数，则$n^3$能被2整除；那么 $n$ 可以被 2 整除，因此，$n^3$ 可以被 8 整除。但是数字 $a$ 可以被 8 整除当且仅当其最后一位数字形成的数字可以被 8 整除。这意味着，对于没有 $n$ 的数字 $n^3$ 最终是一个可以被 8 整除的偶数三位数。
