M590。 a) 找到表达式 $|\cos x| + |\cos 2x|$ 的最小值。证明对于任意数 $x$ 和 $60^\circ$。但显然，这两个向量之间的差的长度不会超过 1 (图 1)。

现证明问题的陈述如下。令$n > 1$和$a_n$为具有以下性质的最小数：对于平面上的任何向量$\vec{a}_1, \dots, \vec{a}_n$，使得$|\vec{a}_1| \leq 1$，...，$|\vec{a}_n| \leq 1$，在总和$x = \pm a_1 \pm \dots \pm a_n$中，我们可以选择使得$|\vec{x}| \leq a_n$这样的符号。我们需要检查$a_n \leq \sqrt{2}$。引理表明，如果 $n > 3$ 那么 $a_n = a_{n-1}$。因此$a_n = a_2$。但显然 $a_2 = \sqrt{2}$ (图 2)，这就完成了证明。

奇怪的是，被证明的结果（常数稍差）对于测量向量长度的“非欧几里得”方法也有效，其中单位圆的作用是由平面上任意凸有界中心对称图形$\Phi$扮演的。这种方法在现代数学中非常流行，由以下内容组成。

为了改变长度$\vec{a}$，我们将这个向量与图形$\Phi$的对称中心$O$断开 - 让$\vec{a} = OA$ - 并找到最小的数字$\lambda > 0$，使得$A \in \lambda \Phi$（λФ是当与中心$O$和系数相结合时图形$\Phi$的图像） $\lambda$ - 参见 图 3；我们假设 Φ 包含其自己的边界，并且点 $O$ 位于 $\Phi$ 内部）。这个数字是$\lambda$，被视为向量$\vec{a}$的“广义长度”$|\vec{a}|_\Phi$。显然，如果$\Phi$是半径为1的圆，则$|\vec{a}|_\Phi = |\vec{a}|$，$|OA|_\Phi < 1 \iff A \in \Phi$也是。在波浪语言中，我们通过在不同方向选择不同的尺度来改变向量的长度。很容易验证输入的数字$|\vec{a}|_\Phi$具有长度的一般属性；特别是，不等式 $|\vec{a} + \vec{b}|_\Phi < |\vec{a}|_\Phi + |\vec{b}|_\Phi$ 是有效的（检查！这里您需要图形 $\Phi$ 的凸性）。

上面证明的陈述的类似物看起来像这样。如果$|\vec{a}_1|_\Phi \leq 1$，...，$|\vec{a}_n|_\Phi \leq 1$，那么在和$\vec{x} = \pm a_1 \pm a_2 \pm \dots \pm a_n$中我们可以选择满足$|\vec{x}|_\Phi \leq 2$的符号。

证明遵循相同的方案；只有引理的证明需要新的推理，因为我们现在不能断言如果$|\vec{a}|_\Phi, |\vec{b}|_\Phi \leq 1$和$(a, b) \leq 60^\circ$，则$|a - b|_\Phi \leq 1$。

所以让$|\vec{a}|_\Phi, |\vec{b}|_\Phi, |c|_\Phi \leq 1$。这意味着点 $A, B, C$ 使得 $OA = \vec{a}, OB = \vec{b}, OC = \vec{c}$ 属于 $\Phi$。

让$OD = a + b$。显然，考虑到点$C$的可能性，我们可以将自己限制在$C$属于角度$BOD$的情况。如果 $C$ 在三角形 $OBD$ 中，则 $P_-b$ (C) 位于三角形 $AOB'$ 中（这里 $P_-b$ 是向量 $-b$ 的平行平移）。因此，$P_-b$ (C) ∈ Ф，因此在本例中为$|c - b|_\Phi \leq 1$。我们将角$BOD$的剩余部分分为区域I和II，如图4所示。如果点$C$位于区域I，则点$D$属于三角形$ABC$，位于Ф，因此属于$|\vec{a} + \vec{b}|_\Phi \leq 1$，如果$C$位于区域II，则，显然，点$P_-b$（C）属于图中$\Phi$中的凸四边形$OACB$，我们再次得到$|c - b|_\Phi \leq 1$。

现在引入上面的数字$a_n = a_n(\Phi)$，我们再次在$n > 2$处看到$a_n(\Phi) = a_2(\Phi)$。但是$a_2(\Phi) \leq 2$，或$|a_1 + a_2|_\Phi \leq |a_1|_\Phi + |a_2|_\Phi \leq 2$，因此$a_n(\Phi) \leq 2$，这就是所需要的。我们还要注意，对于任意数字 $\Phi$CONSTANTУ 2 不能约简：将并行语法 $ABCD$ 视为 Ф，将向量 $OA$ 和 $OB$ 视为 $\vec{a}_1$ 和 $\vec{a}_2$。
