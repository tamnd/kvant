$$\sum_{k=1}^{5} kx_k = a, \quad \sum_{k=1}^{5} k^3 x_k = a^2, \quad \sum_{k=1}^{5} k^5 x_k = a^3.$$

由于数字$x_1, \dots, x_5$是非负数，因此最多有一个不等于0；在这种情况下，它的系数必须为零。如果所有$x_k$都为零，则匹配$\sum_{k=1}^{5} kx_k = a$给出$a = 0$。如果 $x_k$ 之一不为零，则从 (1) 中我们可以获得 $a: 1, 4, 9, 16, 25$ 的另外五个值。所有这些值确实有效：对于每个值，匹配 $\sum_{k=1}^{5} kx_k = a$ 可以让我们找到相应的解决方案：$(1; 0; 0; 0; 0); (0; 2; 0; 0; 0); (0; 0; 3; 0; 0); (0; 0; 0; 0; 4; 0); (0; 0; 0; 0; 5)$；简单的检查表明这些解决方案满足其余的对应关系。

M597。让我们把
$$x_n = 1 + \frac{1}{2} + \dots + \frac{1}{n}.$$
a) 证明极限的存在性
$$\gamma = \lim_{n \to \infty} (x_n - \ln n).$$
b) 证明对于任意 $n, m \in N$
$$\gamma < x_n + x_m - x_{nm} \leq 1.$$
c) 求 $\gamma$ 的最接近 0.1。

a) 从 Weierstrass 定理（“代数与分析原理 9”，第 32 段）很容易推论：如果 $(a_n)$ 和 $(\beta_n)$ 是递增和杀死序列，$a_n < \beta_n$ 对于所有 $n$ 和 $\lim_{n \to \infty} (\beta_n - a_n) = 0$，则序列 $(a_n)$ 和 $(\beta_n)$ 有一个共同极限$c = \lim_{n \to \infty} a_n = \lim_{n \to \infty} \beta_n$ 和 $a_n < c < \beta_n$ 以及所有 $n$。

对于给定序列 $(x_n)$，考虑两个序列：
$$\gamma_n = x_n - \ln (n + 1), \quad \Gamma_n = x_n - \ln n.$$
很容易看出它们满足引理的条件
$$(\gamma_n < \Gamma_n; \lim_{n \to \infty} (\Gamma_n - \gamma_n) = \lim_{n \to \infty} \ln \left( 1 + \frac{1}{n} \right) = 0;$$
$$\gamma_n - \gamma_n^{-1} = \int_{n-1}^{n} \left( \frac{1}{n} - \frac{1}{x+1} \right) dx > 0,$$
从 $\frac{1}{n} - \frac{1}{x+1} > 0$ 到 $x \in [n-1; n]$；类似于$\Gamma_n - \Gamma_{n-1} < 0$。因此，序列$(\gamma_n)$和$(\Gamma_n)$对于所有$n$有一个共同的极限$\gamma = \lim_{n \to \infty} \gamma_n = \lim_{n \to \infty} \gamma_n < \gamma < \Gamma_n$。

所以极限$\gamma = \lim_{n \to \infty} \Gamma_n$存在。 （这是由 L. Euler 首先指出的。数字 $\gamma$ 称为欧拉常数。）
b) 容易看出$x_n + x_m - x_{nm} = (x_n + x_m - x_n) - (x_{2n} - x_n) - (x_{3n} - x_{2n}) - \dots - (x_{nm} - x_{n(m-1)}) \leq x_m - n \cdot \frac{1}{2n} - n \cdot \frac{1}{3n} - \dots - n \cdot \frac{1}{mn} = 1$。

另一方面，$\Gamma_{nm} \leq \Gamma_n$，即
$$x_{nm} - \ln (mn) \leq x_n - \ln n, \quad x_n - x_{nm} - \ln n + \ln (mn) \geq 0.$$

但$\Gamma_m > \gamma$，即
$$x_m - \ln m > \gamma.$$

添加不等式 (*) 和 (**)，我们得到
$$x_n - x_{nm} + x_m > \gamma,$$
Q.E.D.
