任意自然数$n$之和
$$|\cos x| + |\cos 2x| + \dots + |\cos 2^n x|$$
b) 不小于$\frac{n}{4}$；
c) 不小于$\frac{n}{2}$。

$$y(t) = t + (1 - \sqrt{2} t) (1 + \sqrt{2} t) \geq t + (1 - \sqrt{2} t) = 1 - t(\sqrt{2} - 1) \geq 1 - \frac{1}{\sqrt{2}} (\sqrt{2} - 1) = \frac{1}{2}.$$

如果$\frac{1}{\sqrt{2}} < t \leq 1$，则$y(t) \geq t \geq \frac{1}{\sqrt{2}}$。因此，$y(t) \geq \frac{1}{\sqrt{2}}$对于所有$t \in [0; 1]$。但在$t = \frac{1}{\sqrt{2}}$（即$x = \frac{\pi}{4}$）$y(t) = \frac{1}{\sqrt{2}}$。这意味着表达式 $|\cos x| + |\cos 2x|$ 的最小值是 $\frac{1}{\sqrt{2}}$。

$$y(t) = \begin{cases} -2t^2 + t + 1 & \text{при } t \in \left[0; \frac{1}{\sqrt{2}}\right], \\ 2t^2 + t - 1 & \text{при } t \in \left[\frac{1}{\sqrt{2}}; 1\right], \end{cases}$$

同理，我们可以证明更简单的不等式
$$2|\cos x| + |\cos 2x| \geq 1$$
甚至将其与不平等结合起来
$$|\cos x| + |\cos 2x| \geq \frac{1}{\sqrt{2}}$$

合而为一：

$$a|\cos x| + |\cos 2x| \geq \min\{1, \frac{a}{\sqrt{2}}\},$$

对所有实数 $a \geq 0$ 和 $x$ 有效（请自行检查）。

b) 让我们表示金额
$$|\cos x| + |\cos 2x| + |\cos 4x| + \dots + |\cos 2^n x|$$

通过$\sigma_n(x)$。让我们输入$f(x) = |\cos x| + |\cos 2x|$。由a)$f(x) \geq \frac{1}{\sqrt{2}}$证明，所以

$$\sigma_n(x) = f(x) + f(4x) + f(16x) + \dots + f(2^n \left[\frac{n-1}{2}\right] x) \geq \frac{1}{\sqrt{2}} + \dots + \frac{1}{\sqrt{2}} = \left(\left[\frac{n-1}{2}\right] + 1\right) \frac{1}{\sqrt{2}} \geq \frac{n}{2\sqrt{2}} > \frac{n}{4}.$$

c) 首先证明如果$|\cos x| \leq \frac{1}{2}$，则$|\cos x| + |\cos 2x| \geq 1$。事实上，如果$t = |\cos x| \leq \frac{1}{2}$，则$\cos 2x = 2t^2 - 1 \leq 2 \cdot \left(\frac{1}{2}\right)^2 - 1 < 0$。因此，

$$|\cos x| + |\cos 2x| = t + 1 - 2t^2 = 1 + 2t \left(\frac{1}{2} - t\right) \geq 1.$$

让我们继续执行任务 c)。让我们修复$x$和$n$，如果$|\cos 2^k x| < \frac{1}{2}$则称整数$k \in [0; n]$为“坏”，如果$|\cos 2^k x| \geq \frac{1}{2}$则为“好”。从上面的证明可以看出，每个“坏”数字$k$（$k = n$除外）后面都跟着一个“好”数字$k + 1$和$|\cos 2^k x| + |\cos 2^{k+1} x| \geq 1$。现在让我们按升序对所有“坏”数字进行编号：

$$1 \leq k_1 < k_2 < \dots < k_r \leq n (r - количество «плохих» чисел).$$
