更好-同样

在各种分析和应用数学问题中，都会出现此类问题：

令给定的两个数字 v 和 p：0 < v < p。考虑所有可能的（有限）数字集合 $x_1, x_2, ..., x_k$，对于任何 i = 1, 2, ..., k，0 < x_i ≤ v，并且集合中所有数字的总和 $\sum_{i=1}^{k} x_i$ 大于 p。

对于每个这样的集合，都有一个数字 D，使得 1) 该集合的某些数字（特别是可能是全部）的总和 S 不同于 D 上的 p： |S−p| = D 和 2) 该集合中某些数字的任何其他总和与 p 的差异超过 D。

对于每组，数字 D（“近似误差”）将是最大的？

正如我们将看到的，我们正在寻找的是一组相同的数字：“更好 - 同等”。

这里我们将看看指定类型的几个具体问题（包括问题书«Kvant»中的难题M583）。

1. 考虑几组石子，每组石子的质量不超过2公斤，而该组石子的总质量超过10公斤。从这样的一组中，选择几块石头，其总质量与 10 kg 相差该组可能的数量 D。对于所有可能的石子组，数字 D 可以取的最大值是多少？

（该问题于 1979 年在莫斯科市数学优化中提出。）

显然，任何一组石子的数量 D 都不会超过 2 kg，因为任何石子的质量都不会超过 2 kg。另外，D太大不能等于2kg。因此，为了与所有石子都相同的套装一起使用，我们将最大D替换为在石子仍然很重的情况下获得的，最多10公斤半石子是不够的。四颗石头的重量与 10 公斤相差超过 2 公斤，对于石头的跟部，根据方程 5x = 10−x/2，我们发现 x = 20/11，即 D = 10/11。

现在让我们证明，对于任何集合 D 不超过 10/11，也就是说，我们将证明，从任意一组石头中，我们可以选择总质量与 10 千克相差不超过 10/11 的几个石头。

我们将一颗一颗地挑选石头：先挑选最重的一块，然后挑选其余的最重的，以此类推，直到所选石头的质量不超过10公斤。如果在所选的石头中，有一块石头重量小于 20/11 千克，那么它们的总质量小于 (10+10/11) 千克，或者在上一步（取出最后一块石头之前）我们有一组质量大于 (10−10/11) 千克 (=10+10/11−20/11)，但小于或等于 10 千克。

因此，D 的最大值为 10/11，并且该值是在一组相同的宝石上实现的。

练习 1. 证明在一般情况下，D 的最高值是在一组相同的棋子上获得的，并且该值等于 p/(1−2·[1/2−p/v])（[x] 是数字 x 的整数部分）。

这个估计并不准确，因为数字 50 不能被 20/11 整除（如果该组的总质量不是 50，而是 100 千克，那么答案将保持不变）。

考虑到所有可能的将 50 公斤分割成具有相同质量的石头的情况，我们确信此类集合的 $D$ 的最大值等于 $D_0 = 20/27$ 公斤。 （这是在一组 27 颗质量为 50/27 的宝石上实现的。）我们的目标是证明 $D_0$ 是 $D$ 的异常最大值。要做到这一点，只需证明任意集合可以被一组相同质量的石子替换，而不减少$D$（相同石子组的输入$D$不超过$D_0$）。

让我们考虑一个任意集合。让我们从中选择那些总质量与 10 公斤相差尽可能小的数（即 $D$）的石头。让我们将质量大于 $2D_0$ 的石头分为两组。第一组包括那些被选中的人（空$a_1$，$a_2$，...，$a_m$他们的质量）。第二组包括质量为$b_1$、$b_2$、...、$b_n$（大$2D_0$）的石头，未包含在选择中。为了简洁起见，我们有时会写“石头$a_i$”（对应于$b_j$），意思是“质量为$a_i$的石头”（对应于$b_j$）。令$A$为石子$a_i$的质量之和（有时$A$表示由石子$a_1$、$a_2$、...、$a_m$组成的集合；下面定义的$B$和$C$的质量之和也可用于表示相应的组），$B$是$b_i$石子的质量之和，$C$是剩余石子（即质量不超过$2D_0$的石子）的质量之和。

现在让我们证明存在一个集合，其中$a_1 = a_2 = ... = a_m = b_1 = ... = b_n$，$C = 0$，并且值$D$不小于原始值。这意味着$D \leq D_0$，因为对于由相同宝石组成的集合，$D$不会超过$D_0$。在这种情况下，可能有两种情况：

1. 所选石块的总质量为 10-D。

为了构造所需的集合，我们必须证明几个辅助陈述。

引理1.$C$中包含的所有棋子都属于被选中的棋子（即$10—D = A+C$）。

事实上，如果$C$中包含的至少一颗石头没有被选择，那么通过将其添加到所选的石头中，我们将获得几块质量与10公斤相差不超过$2D_0—D<D$的石头。这与所讨论的集合的选择相矛盾。

引理 2. $a_i \geq b_j$ 对于任意 $i$ 和 $j$ ($1 \leq i \leq m$, $1 \leq j \leq n$)。

事实上，如果一些$i$和$j$满足不等式$a_i < b_j$，那么通过将其添加到选定的那些中，我们将获得几块质量与10公斤相差不超过$2D_0—D<D$的石头。这与所选集合的最优性相矛盾。

引理 3. $b_j > C+2D_0$ 对于任意 $j$ ($1 \leq j \leq n$)。

让我们从所选集合中删除 $C$ 中包含的所有宝石，并在其中添加宝石 $b_j$。如果$A+b_j \leq 10—D$，那么通过一次从$C$添加一个石头，我们将在某个时刻得到一组质量大于10-D（自$A+b_j+C > A+C=10—D$），但小于10+D（因为每次添加质量不超过$2D_0<2D$的石头）。这意味着$A+b_j>10—D$，因此（由于$D$极小）$A+b_j>10+D=A+C+2D>A+C+2D_0$，因此$b_j>C+2D_0$。

从引理 2 可以得出，$a_i>C+2D_0$ 对于所有$i$。

引理 4. 如果 $A$ 中的石子的质量 $k$ 和 $B$ 中的石子 $l$ 的质量之和小于 10+D，则 $k+l \leq m$。

如果这个和小于10+D，那么，由于$D$极小，它小于或等于10—D。让$k+l > m$。依次用不包含在其中的棋子$a_i$替换该总和中的棋子$b_j$，我们最终将放置最后一个棋子$a_i$，从而使总和达到值$A+b_j+...>A+C+2D_0>10+D_0$（参见引理1和3）。既然大家

最后让我们证明，可以在不减少 $D$ 的情况下构造一个由相同质量的石子组成的集合。

让我们将每个石子 $a_i$ ($i = 1, \dots, m$) 替换为质量为 $a = A/m$ 的石子，将每个石子 $b_j$ ($j = 1, \dots, n$) 替换为质量为 $b = B/n$ 的石子，并保留 $C$ 中的石子不变。让我们证明对于这样的集合，数字 $D$ 并未减少。

我们假设 $D$ 减少了。那么对于某些 $k$、$l$ 和 $C' < C$，总和 $ka + lb + C'$ 严格位于 $10 - D$ 和 $10 + D$ 之间。让我们从 $A$ 中取出最轻的宝石 $k$。它们的质量总和不超过$ka$（为什么？）。同样，$B$ 中最轻的石头的质量$l$ 的总和不超过 $lb$。但是$ka + lb < 10 + D$，因此$k + l \leq m$（参见引理4）。在这种情况下$10 - D = A + C = ma + C \geq ka + la + C' \geq ka + lb + C' > 10 - D$。矛盾。

如果$a > b$，则$b$不能包含在任何等于$10 - D$的和中（用$a$替换$b$，我们得到矛盾）。因此，我们可以读（给出这些词的确切含义！）来减少所有质量为$a$的石子，读为通知质量为$b$的石子，从而使$C$保持不变。这将导致一组比原始集合具有更多值$D$。这样做几次后，我们得到了一个包含 $a = b$ 的集合。

如果该集合中有$C > 0$，则将$a$（质量为$a$的石子数量为$m + n$）增加$\varepsilon$，其中$\varepsilon < C/(m + n)$；在这种情况下，$C$将减少$(m + n)\varepsilon$。但是$D$将增加$n \cdot \varepsilon$，这就是所需要的。经过几步之后，我们得到了一个包含 $a = b$ 和 $C = 0$ 的集合。
