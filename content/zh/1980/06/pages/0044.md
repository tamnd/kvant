⟦folio 42⟧

1979年大学入学考试的选择

列宁格勒国立大学命名。 A·A·日丹诺娃

数学
笔试
选项1
（数学与力学学院）
1. 方程有多少个根？
$$f(x) - af'(x) = 0,$$
如果 $f(x) = (x-x_1)(x-x_2)(x-x_3)(x-x_4)$、$a$、$x_1$、$x_2$、$x_3$、$x_4$ 是实数 ($x_1 < x_2 < x_3 < x_4$)？
2. 求解方程（在$a \in \mathbb{R}$）
$$\log_a(1-8a^{-x}) \geq 2(1-x).$$
3. 求解方程（在$a \in \mathbb{R}$）
$$a \cdot \sin x + \mathrm{tg} x + 1 = \frac{1}{\cos x}.$$
4. 半径为$R$的圆内接于等边曲线$ABCD$； $K$是对角线图形的交点，$[AB]$是它的主底，$KBA = a$。求与给定圆相切的圆的半径和对角线段$[KB]$、$[KC]$。
5. 点 $M, N, P, Q$ 位于空间中，使得$(MN) \perp (PQ)$、$(MP) \perp (NQ)$。证明这一点和$(MQ) \perp (NP)$。

选项2
（应用数学学院 - 控制过程）
1. 如果$f(x) = x^a + 3x^\beta$、$a, \beta$是实数，$a > 1$、$\beta > 1$，对于哪个$a (a \in [0; 1])$由函数$y = f(x)$和直线$x = 0, x = 1, y = f(a)$围成的图形面积最大和最大？
2. $a (a \in \mathbb{R})$ 是方程的任意解
$$\log_3(x^2 - 3x + 7) / \log_3(3x + 2) < 1$$
也将是不等式$x^2 + (5-2a)x \leq 10a$的解？
3. 求解方程（在$a \in \mathbb{R}$）
$$(8a^2 + 1) \sin^3 x - (4a^2 + 1) \sin x + 2a \cdot \cos^3 x = 0.$$
4. 直角三角形的边长为$a$和$b$，直角小三角的长度为$l$。 $l \leq \sqrt{\frac{ab}{2}}$是真的吗？
5. 球体穿过正三角形内切球的中心，并接触从同一顶点发出的三角形的三个边。如果三角形边长为 $a$，求球体的半径。

选项3
（物理学院）
1. 河流的宽度为$a$米，流速为$w$米/秒，游泳者在静水中的速度为$v$米/秒（$v < w$），在陆地上的运动速度为$u$米/秒。游泳者在最短的时间内可以到达与他开始渡河地点相对的对岸点？假设在水中，游泳者没有改变他在穿越开始时选择的运动，并且河流的速度矢量平行于河岸，假设河岸是笔直的。
2. 如果$f(x) = x^a + 3x^\beta$、$a, \beta$是实数，并且$a > 1$、$\beta > 1$，那么位于由函数$y = f(x)$和线$x = 0, x = 1, y = f(a)$围成的三角形内的点$(a; a^2)$具有最多和最多的值，那么$a (a \in \mathbb{R})$是什么？
3. 解方程
$$\sin^6 x + \cos^6 x = 1 + \sin 4x.$$
4. 求 $\lim_{n \to \infty} x_n$ 如果
$$x_n = \frac{1}{1 \cdot 2} + \frac{1}{1 \cdot 4} + \frac{1}{2 \cdot 3} + \frac{1}{4 \cdot 7} + \dots + \frac{1}{n(n+1)} + \frac{1}{(3n-2)(3n+1)}$$
5. 三个半径相同$R$的大圆成对接触。三个小圆具有相同的半径并且成对地相互接触。如果每个小圆也与两个大圆相接触，求该小圆的半径。
