选项1

1. 在水平方向上，只有摩擦力作用在质量体$m$：$ma_{\text{гор}} = |\vec{F}_{\text{rp}}|$上。从这里
$$|\vec{F}_{\text{rp}}| = m |\vec{a}| \cos \alpha = mg \sin \alpha \cos \alpha.$$

2. 让我们记下管子不同部分的初始和最终压力值。初始压力：$p_{AB} = 2 \rho gh = p, p_{CD} = \rho gh = p/2, p_{EF} = 0$。最终压力：$p_{F} = \rho gh + p'_{CD} = p/2 + p'_{CD}, p'_{CD} = \rho gh + p'_{AB} = p/2 + p'_{AB}$。根据波义耳-马里奥特定律，$p_{AB}h = p'_{AB}x$和$p_{CD}h = p'_{CD}(3h - x)$，其中$x$和$3h - x$分别是$AB$和$CD$部分的最终长度。结果，我们得到方程$6p^2 - 12pp_F + 5p^2 = 0$，其中$p_F = p(1 + 1/\sqrt{6})$（第二个系数 - 括号中带有负号 - 被丢弃，因为根据问题的含义，必须通知压力）。

3. 根据法拉第定律，线圈上的电压为$U_L = \frac{\Delta \Phi}{\Delta t} = L \frac{\Delta I}{\Delta t}$。由于电路中的电流与时间成正比增加，因此$U_L$不随时间变化且在任何时刻$t$$U_L = L \frac{I}{t}$。因此，电容器上的电压等于线圈上的电压，也保持恒定：$\frac{Q_0}{C_0} = \frac{Q_0 - q}{C}$，其中$Q_0$是电容器上的初始电荷，$q$是在时间$t$期间离开电容器极板的电荷，$C$是电容器在$t$时刻的电容。从等式$L \frac{I}{t} = \frac{Q_0}{C_0}$我们找到$I:I = \frac{Q_0}{LC_0} t$。那么离开电容器的电荷是$q = I_{cp} t = \frac{I}{2} t = \frac{Q_0}{2LC_0} t^2$。通过绘制电容器两端的电压，我们可以找到 $C$：

$$C = C_0 \frac{Q_0 - q}{Q_0} = C_0 \left( 1 - \frac{t^2}{2LC_0} \right).$$

4. 在上方输入最小频率时，可以写：$m\omega^2 l = mg$。因此$v = \frac{\omega}{2\pi} = \frac{1}{2\pi} \sqrt{\frac{g}{l}}$。选择$l \sim 1$ m，$g = 10$ m/s$^2$，我们得到$v \sim 0,5$ Hz。
