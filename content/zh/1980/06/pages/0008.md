+0.7x = x 给出坐标 x = 333 1/3 m - 这里第一个将赶上第二个。

如果第二个运动是最后一个，那么函数 f 和相遇方程都将更加必要，但至少发生一次相遇的可能性仍然很小。

然而，这个“显然”并没有让我们作为数学家感到紧张。在进一步讨论之前，我们将澄清问题的数学表述并证明会议的存在性。

假设（如示例 1 中所示）函数 f 显示段 [a; b] 自身，即对于所有 x ∈ [a; b] 我们有 a ≤ f(x) ≤ b。那么方程 f(x) = x 的每个解称为映射 f 的不动点。 （在我们的例子中，固定点正是交汇点。）它什么时候存在？

定理。对于表示线段 [a; 的任意连续函数 f； b] 自身存在一个不动点。

在定理中，函数 f 的连续性和我们正在讨论的线段这一事实都是至关重要的。

练习 1. 给出一个表示 [a; 的不连续函数 f 的例子； b] 自身，没有固定点。

练习 2. 给出无固定点映射到自身的连续函数的示例： a) 两个线段的并集 [a; b] ∪ [c; d]； b) *积分]a； b[.

为了证明这个定理，我们将用红铅笔和照片武装自己。在使用它们之前，让我们先指出

$$\varphi(x) = f(x) - x.$$

显然 c ∈ [a;当且仅当 c 是方程 $\varphi(x) = f(x) - x = 0$ 的根时，b] 才是 f 的不动点。因此，我们将求这个方程的根。请注意，根据条件 a ≤ x ≤ b，a ≤ f(x) ≤ b，紧随其后的是 $\varphi(a) ≥ 0$ 和 $\varphi(b) ≤ 0$。我们假设两个不等式都是严格的（否则它是一个解问题）。现在让我们划分段 [a; b] 分成 10 等份，并将该值的所有部分涂成红色

$$\cos x^3 - x = 0?$$

cos x³ 函数是连续的；它将线段 [−π/2, π/2] 映射到自身（进一步映射到线段 [−1, 1]）；这意味着根据定理，存在解 c ∈ [−π/2, π/2]。
