M568。凸四边形ABCD的设计，相交于O点。证明
a) 如果三角形 AOB、BOC、COD 和 DOA 的内接圆的半径彼此相等，则 ABCD 是菱形；
b) 如果三角形 ABC、BCD、CDA 和 DAB 的内接圆的半径彼此相等，则 ABCD 是矩形。

设$r$为半径，$O_1$和$O_2$为三角形AOB和COD内切圆的圆心； $P, Q, R, S$ 是这些圆与这些三角形 (图 1) 边 AO、BO、CO、DO 的切点。

我们首先证明四边形ABCD是平行四边形。为此，只需确定其对角线 AC 和 BD 被点 O 平分即可。

我们假设情况并非如此。例如，$|AO| > |OC|$。我们将证明这个不等式蕴含着不等式$|BO| < |OD|$和$|BO| > |OD|$，这是不可能的。

从不等式$|AO| > |OC|$可以得出$|AP| > |CR|$，因为$|OP| = |OR|$；从$|O_1P| = |O_2R|$跟随$O_1AP < O_2CR$，因此$BAO < DCO$。因此，$ABO > CDO$和$BQ < DS|$，但这意味着$|BO| < |OD|$。

对三角形 BOC 和 AOD 重复上述推理（图 2；自己做），我们得到$DAO < BCO$，因此$ODA > CBO$，因此，$|DS_1| < |BQ_1|$，即$|BO| > |OD|$。

由此产生的矛盾证明$|AO| = |OC|$。也证明了$|BO| = |OD|$。所以四边形ABCD是平行四边形。

根据三角形 AOB 和 BOC 的面积相等（我们使用众所周知的公式 $S = pr$），我们得到

$$\frac{1}{2}r(|AO| + |OB| + |AB|) = \frac{1}{2}r(|OC| + |OB| + |BC|),$$

由此$|BC| = |AB|$，即四边形ABCD是菱形。

6) 第一个决定。设(图 3)$A_1$和$A_2$、$B_1$和$B_2$、$C_1$和$C_2$、$D_1$和$D_2$为三角形ABD、ABC、BCD、CDA内切圆的切点，从四边形ABCD； $O_1, O_2, O_3, O_4$ 是这些圆的中心； $P, Q, R, S$——圆对角线AC和BD的切点； $r$ — 圆的半径。

首先，我们将证明一个有趣的事实：对于任意凸四边形ABCD，四边形对边切点之间的线段长度相等，即$|A_1B_2| = |C_1D_2|$和$|B_1C_2| = |A_2D_1|$。

首先我们要确保图 3是“正确的”，即四边形各边切点的位置与图 3所示的位置完全相同。

例如，考虑三角形 ABD 和 ACD，并证明点 $A_2$ 比点 $D_1$ 更靠近点 $A$。

要做到这一点，只需证明$|AA_2| + |DD_1| < |AD|$就足够了。

很容易看出

$$|AA_2| = \frac{|AB| + |AD| - |BD|}{2}$$

$$|DD_1| = \frac{|AD| + |CD| - |AC|}{2}$$

添加这些等式，我们得到

$$|AA_2| + |DD_1| = |AD| + \frac{|AB| + |CD| - |BD| - |AC|}{2}$$

但是$|AB| + |CD| < |BD| + |AC|$（证明它！）因此

$$|AA_2| + |DD_1| < |AD|$$

现在我们证明$|A_2D_1| = |B_1C_2|$和$|D_2C_1| = |A_1B_2|$。
