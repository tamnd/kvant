⟦folio 21⟧

利用切线段的性质 (图 3)，我们得到

$$|BD| = |BP| + |PD| = |BA_1| + |DA_2| =
= |BB_2| + |A_1B_2| + |DD_1| + |A_2D_1|.$$ (1)

另一边，

$$|BD| = |BR| + |RD| = |BB_1| + |B_1C_2| + |DD_2| + |D_2C_1| =
= |BB_2| + |B_1C_2| + |DD_1| + |D_2C_1|.$$ (2)

将式(1)和(2)等式可得

$$|A_1B_2| + |A_2D_1| = |B_1C_2| + |D_2C_1|.$$ (3)

对对角线 AC 进行精确计算，我们得到

$$|A_2D_1| + |D_2C_1| = |A_1B_2| + |B_1C_2|.$$ (4)

现在添加等式（3）和（4），我们得到

$$|A_2D_1| = |B_1C_2|.$$

因此，也$|D_2C_1| = |A_1B_2|$。

到目前为止，我们还没有使用内切圆半径相等，因此我们得到的结果对于任意凸四边形都是有效的。

现在让我们完成这个问题的解决。

由于圆心到相应边的距离相等，因此我们得到$(O_1O_2) \parallel (AB)$和$(O_3O_4) \parallel (CD)$；由于$|O_1O_2| = |A_1B_2|$和$|O_3O_4| = |C_1D_2|$，我们得到$|O_1O_2| = |O_3O_4|$。

类似地，$|O_2O_3| = |O_1O_4|$，因此四边形$O_1O_2O_3O_4$是平行四边形，并且由于四边形ABCD的边与平行四边形平行，所以四边形ABCD也是平行四边形。

使三角形 ABD 和 ABC 的面积表达式相等，我们得到

$$\frac{1}{2} r (|AB| + |BD| + |AD|) = \frac{1}{2} r (|CD| + |AD| + |AC|),$$

从哪里$|BD| = |AC|$。

因此，平行四边形ABCD的对角线长度相等，即ABCD是矩形。

第二个解决方案。和第一个解一样，我们首先要证明四边形ABCD是平行四边形。

为此，请通过点 B 和 D 绘制与边 AC (图 4) 平行的直线，并在线 BD 的一侧放置长度为 $|AC|$ 的线段 BB' 和 DD'。

四边形BB'DD'显然是一个平行四边形。容易看出，三角形BCB'、B'CD'、CD'D分别与三角形ABC、ABD和ACD全等，因此平行四边形被线段CB、CB'、CD和CD'划分成的所有四边形的内接圆的半径相等。

我们证明C点与平行四边形BB'D'D'对角线交点E重合。

事实上，如果情况并非如此，则点 C 属于平行四边形被其对角线分割成的三角形之一（在 图 4 处，这是三角形 DED'）。在这种情况下，三角形DED'的内接圆的半径将大于r，而三角形BEB'的内接圆的半径将小于r，这与三角形DED'和BEB'的全等相矛盾。

因此，C点与平行四边形BB'D'D'对角线的交点E重合，因此$[DC] \parallel [AB]$和$[AD] \parallel [BC]$，即四边形ABCD是平行四边形。

为了完成这个解决方案，检查第一个解决方案末尾已经执行的推理就足够了。
