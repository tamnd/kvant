我们首先证明四边形ABCD是平行四边形。为此，只需确定其对角线 AC 和 BD 被点 O 平分即可。

我们假设情况并非如此。例如，$|AO| > |OC|$。我们将证明这个不等式蕴含着不等式$|BO| < |OD|$和$|BO| > |OD|$，这是不可能的。

从不等式$|AO| > |OC|$可以得出$|AP| > |CR|$，因为$|OP| = |OR|$；从$|O_1P| = |O_2R|$跟随$O_1AP < O_2CR$，因此$BAO < DCO$。因此，$ABO > CDO$和$BQ < DS|$，但这意味着$|BO| < |OD|$。

对三角形 BOC 和 AOD 重复上述推理（图 2；自己做），我们得到$DAO < BCO$，因此$ODA > CBO$，因此，$|DS_1| < |BQ_1|$，即$|BO| > |OD|$。

由此产生的矛盾证明$|AO| = |OC|$。也证明了$|BO| = |OD|$。所以四边形ABCD是平行四边形。

根据三角形 AOB 和 BOC 的面积相等（我们使用众所周知的公式 $S = pr$），我们得到

$$\frac{1}{2}r(|AO| + |OB| + |AB|) = \frac{1}{2}r(|OC| + |OB| + |BC|),$$

由此$|BC| = |AB|$，即四边形ABCD是菱形。

$$\frac{x_1}{1} + \frac{x_2}{2} + \frac{x_3}{3} + \dots + \frac{x_n}{n} < 2.$$

$$\sum_{k=1}^{n} \frac{x_k}{k} \leq \sum_{k=1}^{(n+1)^2-1} \frac{x_k}{k} = \sum_{k=1}^{n} \sum_{m=k^2}^{(k+1)^2-1} \frac{x_m}{m}.$$

$$\sum_{k=1}^{n} \frac{x_k}{k} \leq \sum_{k=1}^{n} x_k^2 \left( \sum_{m=k^2}^{k^2+k-1} \frac{1}{m} + \sum_{m=k^2+k}^{k^2+2k} \frac{1}{m} \right) \leq$$
$$\leq \sum_{k=1}^{n} x_k^2 \left( \frac{k}{k^2} + \frac{k+1}{k^2+k} \right) = 2 \sum_{k=1}^{n} \frac{x_k^2}{k} \leq 2,$$
这就是所需要的。

使用交流二极管$T$时，二极管截止，交流电$I = \frac{U}{R_1 + R_2}$流过电阻$R_2$。在时间$T/2$期间，电阻器$R_2$上释放能量

F586。将四级绝缘容器打开至高真空。容器周围的单原子理想气体的温度为 $T_0$。在某个时刻，水龙头打开，容器充满气体。填充后容器内气体的温度$T$是多少？

要了解当容器充满气体时温度如何变化，有必要考虑能量转换的起源。当水龙头打开时，一部分气体响应周围气体的压力被推入容器中。由于这些力的作用，释放到容器中的气体获得了定向最大运动的动能——它以流的形式进入容器。当它遇到容器壁和已经进入容器的气体射流时，方向性减弱并最终消散。在这种情况下，芯片内气体有序运动的动能就转化为内能，即其分子混沌热运动的能量。
