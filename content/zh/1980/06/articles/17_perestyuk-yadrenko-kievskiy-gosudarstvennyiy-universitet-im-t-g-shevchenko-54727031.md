⟦folio 43⟧

基辅国立大学由此得名。舍甫琴科

Matematika

笔试

选项1
（力学与数学学院）

1. 求解方程组
$$\begin{cases} \log_4 x + \log_4 y = 1 + \log_4 9, \\ x + y = 20. \end{cases}$$

2. 解决不平等问题
$$\sqrt{9^x + 3^x} \geq 9 - 3^x.$$

3. 圆锥体被描述为围绕体积为 $V$ 的球，其体积是所有可能的体积中最小的。求圆锥体的体积。

4. 在 $a$ 的值是多少时，线 $y = a$ 将线 $y = 0$ 和 $y = 2 + x - x^2$ 所围成的图形面积分成两半？

5. 解方程
$$\frac{2 \mathrm{tg} \frac{x}{2}}{1 + \mathrm{tg}^2 \frac{x}{2}} = y^2 - 4y + 5.$$

选项2
（控制论学院）

1. 让
$$\max (A, B) = \begin{cases} A, если A \geqslant B \\ B, если B \geqslant A. \end{cases}$$

计算由位于第一个正方形中的线 max $(x, y) = 1$ 和 $x^2 + y^2 = 1$ 部分界定的平面图形的面积。

2. 已知圆锥体底面的半径$r$，确定平行于底面的截面的半径，并将圆锥体的体积分成两半。

3. 解方程
$$2 \sin^2 x - 5 \sin x \cdot \cos x - 8 \cos^2 x = -2.$$

4. 对于$a$的什么值，方程$ax^2 = \ln x$有一个根？

选项3
（物理和放射物理学院）

1. 点按规律作直线运动
$$s(t) = -\frac{1}{6} t^3 + 3t^2 - 5$$
（时间以秒为单位，行驶距离以米为单位）。定义：
1) 一点的加速度为零的时刻；
2) 此时该点移动的速度是多少？
2. 球内接于圆锥体，圆锥体的高度等于底面半径。求球体体积与圆锥体体积之比。

3. 解决不平等问题
$$x + 2 < \sqrt{x + 14}.$$

4. 求解方程组
$$\begin{cases} \log_3 (\log_2 x) + \log_{\frac{1}{3}} (\log_{\frac{1}{2}} y) = 1, \\ xy^2 = 4. \end{cases}$$

5. 求一个函数的最大和最大值
$$y = \sin \left( x + \frac{\pi}{8} \right) \cdot \cos \left( x - \frac{\pi}{24} \right).$$

口语考试目标

1. 解方程
a) $\log_3 (\cos x) + \log_{\frac{1}{3}} (-\sin x) = 0$;
b) $tg |x| = |tg x|$;
b) $\pi \sin x = \left| x - \frac{\pi}{4} \right| - \left| x - \frac{3\pi}{4} \right|$.

2. 解决不平等问题
$$|x + 2|^{\frac{1}{x^2 - x - 6}} \geq |x + 2|^{\frac{2}{x^3}}.$$

3. 求函数的多重相对论区间和极值点
$$y = \left| |x^2 - 1| - 2 \right|.$$

构建该函数的图形。

4. 绘制函数图
$$y = \begin{cases} l^x - 1, \text{ если } x < 0, \\ \sqrt{4x - x^2}, \text{ если } x \geqslant 0. \end{cases}$$

5. $a$ 的作用是什么
$$f(x) = x^3 + 3(a - 7)x^2 + 3(a^2 - 9)x + 1$$ 有正的极大点吗？

6. $m$ 的作用是什么
$$f(x) = 2e^x - me^{-x} + (1 + 2m)x - 3$$

所有轴上单调增加？

7. 对于 $a$ 方程
$$3x \lg x = 1 + a \lg x$$ 有：a) 一种解； 6）两种解决方案？

8. 根据参数$a$，方程有多少个根？
$$x^2 \cdot e^{2|x|} = 4a.$$

9. 方程有多少个属于区间 $[-\pi; \pi]$ 的根？
$$3 \sin x + \sin 3x = 2a$$

取决于参数$a$？

10. $a$ 是方程根的立方和
$$6x^2 + 6(a - 1)x - 5a + 2a^2 = 0$$

最大？

11. 在平面上绘制一组点
$$\{(x; y) | x^2 + y^2 - 2x - 2y + 1 = 0 \}.$$

写出该组图像在平行交点 $\vec{p} = (0; -1)$ 处的方程。

12. 求方程组所对应的 $a$ 的值
$$\{(x; y) | x^2 + y^2 + 2x \leqslant 1 \} \cap \{(x; y) | x - y + a \geqslant 0\}$$
