$x = a_3$ 函数 $f$ 不连续。随着$x$趋于$a_4$，函数$f$也有极限：$\lim_{x \to a_4} f(x) = b_4$和$b_4 = f(a_4)$。在点$a_4$，函数$f$被称为连续的。函数$f$有一个极限，并且$x$趋向于$a_5$：$\lim_{x \to a_5} f(x) = b_5$，尽管函数$f$此时尚未定义，$a_5 \notin D(f)$。

以下是关于确定函数极限所需了解的大致信息。

现在我们可以回答这个问题了——知道定义意味着什么。知道一个定义不仅意味着能够正确地表述它，还意味着能够用图或例子来说明它，在工作中展示它，并在实践中应用它。入学考试的考官正是通过这种“措施”来了解定义的知识。

知道这个定理意味着什么？首先，你需要正确地表述它。接下来：您需要了解定理表述中所有术语的含义，能够澄清和定义它们。毕竟，在证明有关某个数学对象的属性的定理之前，您当然必须了解它是一个对象。例如，如果不知道任意函数的定义，就不可能证明关于两个函数的任意和的定理。

很容易说，在方程 $x^2 - 2y^2 = 1$ 中，数字 $x$ 是奇数，$x \ge 3$。令 $x = 2n + 1$ ($n \ge 1$)。然后是$2n(n + 1) = y^2$，也就是说$y$是偶数。让我们输入$y = 2m$（$m \ge 1$因为$y \ge 2$）。让我们输入$n(n + 1) = 2m^2$，即$T_n = K_m$形式的方程。这意味着方程$T_n = K_m$有无数个解，因为方程$x^2 - 2y^2 = 1$的每个解$(x; y)$（并且有无数个）都会生成方程$T_n = K_m$的解，我们从公式$n = \frac{x - 1}{2}$，$m = \frac{y}{2}$获得。

问题 5. 证明方程 $T_n = K_m$ 的解（自然数）可以用以下两种方式描述：

a) $n_{k+1} = 3n_k + 4m_k + 1$,
$m_{k+1} = 2n_k + 3m_k + 1$,
$n_1 = 1$, $m_1 = 1$;
b) $n_{k+2} = 6n_{k+1} - n_k$,
$m_{k+2} = 6m_{k+1} - m_k$,
$n_1 = 1$, $n_2 = 8$, $m_1 = 1$, $m_2 = 6$.
