3. 根据法拉第定律，线圈上的电压为$U_L = \frac{\Delta \Phi}{\Delta t} = L \frac{\Delta I}{\Delta t}$。由于电路中的电流与时间成正比增加，因此$U_L$不随时间变化且在任何时刻$t$$U_L = L \frac{I}{t}$。因此，电容器上的电压等于线圈上的电压，也保持恒定：$\frac{Q_0}{C_0} = \frac{Q_0 - q}{C}$，其中$Q_0$是电容器上的初始电荷，$q$是在时间$t$期间离开电容器极板的电荷，$C$是电容器在$t$时刻的电容。从等式$L \frac{I}{t} = \frac{Q_0}{C_0}$我们找到$I:I = \frac{Q_0}{LC_0} t$。那么离开电容器的电荷是$q = I_{cp} t = \frac{I}{2} t = \frac{Q_0}{2LC_0} t^2$。通过绘制电容器两端的电压，我们可以找到 $C$：

$$\frac{ph}{T} = \frac{2/3px}{T_1}, \text{ и } x = \frac{3}{2} \frac{T_1}{T} h \approx 2h.$$

2. 点之间的电位差为$AA'U_{AA'} = U$，点之间的电位差为$BB'U_{BB'} = \frac{U}{3} = U \frac{|r - R|}{r + R}$。模型符号开始是因为电压表指示的是电压的绝对值。考虑到差异$r - R$，我们得到

$$R = \begin{cases} r/2 \text{ при } R < r \\ 2r \text{ при } R > r. \end{cases}$$

3. 当质量为 $m_1 = m \frac{2\pi R}{l}$ 的绳索部分的重心（形成一个圆环）升高到高度 $R$ 时，达到最小速度：

$$\frac{m |\vec{v}_{\min}|^2}{2} = m_1 g R.$$

4. 根据模型，空气作用在人体上的浮力等于$F_{BbT} = Q_{BO3D}Vg$。体积$V$将通过人的质量$m$来表示，考虑到身体的密度几乎等于水的密度：

$$V = \frac{m}{\rho_{BO3D}}. \text{ Таким образом, } F_{BbT} \sim \frac{Q_{BO3D}}{\rho_{BO3D}} mg.$$

根据门捷列夫-克拉佩龙定律和阿伏加德罗定律：$Q_{BO3D} \sim \frac{p\mu}{RT} = \frac{p\mu T_0}{p_0V_0T}$。这里$p_0 = 10^5 \text{ Pa}, T_0 = 273 \text{ K}, V_0 = 2,24 \cdot 10^{-2} \text{ m}^3$。取$p \sim p_0 = 10^5 \text{ Pa}, T \sim 300 \text{ K}$并知道$Q_{BO3D} = 10^3 \text{ кг/m}^3$，我们得到$Q_{BO3D} / Q_{BO3D} \sim 760$。因此，浮力大约比重力小 760 倍。最后质量$m \sim 70 \text{ кг}, F_{BbT} \sim 1 \text{ H}$。

5. 初始时刻，压力表显示压力急剧下降。这主要是由于活塞下方的空气量增加所致。然后压力增加，超过初始值。这是因为丙酮剧烈蒸发，而其蒸气压以及蒸气和空气的总压增加。将混合物的温度升高至环境温度也有利于压力的升高。
