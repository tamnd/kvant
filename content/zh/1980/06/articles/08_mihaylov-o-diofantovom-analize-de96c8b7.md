关于丢番图分析

研究$P(x, y, ..., z) = 0$形式方程的整数解的数论领域称为丢番图分析，其中$P(x, y, ..., z)$是具有整数系数的多个变量的多项式，这些方程本身也称为丢番图分析。我们已经写过一些丢番图方程和求解它们的方法*)。

回想一下，求解丢番图方程意味着以下内容：

1. 它是否至少有一个整数解；
2. 其整数解的数量是有限或无限的；
3. 找出它的所有整数解。

例如，对于方程 $x^3 + y^3 + z^3 = 30$，没有显示整数解。不过，也许稍后会找到解决方案。或者也许会证明它们不存在。

但对于方程 $x^3 + y^3 + z^3 = 3$ 已知有四个解：(1; 1; 1)、(4; 4; -5)、(4; -5; 4)、(-5; 4; 4)。但问题仍然悬而未决：还有其他解决方案吗？

证明丢番图方程组整数解的无穷性的有力手段是参数化方法。该方法的本质是将变量$x, y, ..., z$表示为取决于整数参数$\alpha, \beta, ..., \gamma$：$x = A(\alpha, \beta, ..., \gamma), y = B(\alpha, \beta, ..., \gamma), ..., z = C(\alpha, \beta, ..., \gamma)$的函数，其中$A, B, ..., C$是具有整数系数的多项式。参数化方法有时非常人为，但又极其原创，通常需要极大的独创性，因此有助于数学中独立创造性活动技能的获得和发展。

让我们回到方程 $x^3 + y^3 + z^3 + z^3 = 2$ 并尝试对其进行参数化。为此，我们输入 $x = a + b, y = a - b$，其中 $a$ 和 $b$ 是整数；我们得到$2a^3 + 6ab^2 + z^3 = 2$。让$a = 1$，然后$6b^2 = -z^3$，由此得到$z = 6c$（$c$是整数），即$b^2 = -36c^3$。在这种情况下，$c = -\alpha^2$（$\alpha$是整数），然后是$b = 6\alpha^3$。最终结果是$(1 + 6\alpha^3)^3 + (1 - 6\alpha^3)^3 + (-6\alpha^2)^3 = 2$。

即$x = A(\alpha) = 1 + 6\alpha^3, y = B(\alpha) = 1 - 6\alpha^3, z = C(\alpha) = -6\alpha^2$。用整数代替$\alpha$，我们得到不同的解。

问题1. 参数化方程$x^3 + y^3 + z^3 = 2t^3$并证明其整数解的集合是无限的。

对数论感兴趣的数学家多年来一直被一个迄今尚未解决的问题所吸引：方程 $x^4 + y^4 + z^4 = t^4$ 能否以整数解？

1914年，A. Verebryusov提出了其不可判定性的证明。然而，正如我们后来发现的那样，他对这个方程的整数证明已经由欧拉给出了。 1945年，方程$x^4 + y^4 + z^4 = t^4$被证明对于$|t| < 10^8$没有整数解。但是，当然，这还不是一个完整的解决方案。

让我们尝试解决一个更简单的问题，尽管看起来“更复杂”：我们将证明方程 $x^4 + y^6 + z^{12} = t^4$ 的整数解集的无穷大。

设$x = a - b$、$t = a + b$，其中$a$和$b$为整数。然后$y^6 + z^{12} = 8a^3b + 8ab^3$。让我们放$y^6 = 8a^3b$，$z^{12} = 8ab^3$；那么$a = c^3$，$b = d^3$（c和$d$是整数）和$y^2 = 2c^3d$，$z^4 = 2cd^3$。

问题 2. 找到另一个恒等式来描述方程 $x^4 + y^6 + z^{12} = t^4$ 的解。

但为了证明某个丢番图方程的不可解性，注意到我们“根据某个模”考虑该方程是非常有用的*）。让我们解释一下我们的意思。

如果差 $a - b$ 可被 $k$ 整除，则称两个整数 $a$ 和 $b$ 可以对模 $k$ 进行比较。很容易看出，当且仅当两个数字$a$和$b$除以$k$时具有相同的余数时，它们才可以对模$k$进行比较。 $a$ 和 $b$ 可以对 $k$ 进行模运算，如下所示：

$$a \equiv b \pmod{k}.$$

假设我们需要求解丢番图方程

$$x^3 + 117y^3 = 5.$$

让我们考虑这个“模 9”的方程，即最多为 9 的倍数的项。不难证明，任何数字的立方要么能被9整除，要么被9除后余数为1或8，即$x^3 \equiv 0 \pmod{9}$或$x^3 \equiv 8 \pmod{9}$。

由于 117 能被 9 整除，$117y^3 \equiv 0 \pmod{9}$。因此，

$$x^3 + 117y^3 \equiv 0 \pmod{9}.$$

或者

$$x^3 + 117y^3 \equiv 1 \pmod{9}.$$

或者

$$x^3 + 117y^3 \equiv 8 \pmod{9}.$$

因此，方程$x^3 + 117y^3 = 5$没有整数解。
