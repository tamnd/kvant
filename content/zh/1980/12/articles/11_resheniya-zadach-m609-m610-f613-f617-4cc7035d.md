M609。 a) 面积为 S 的凸多边形在两条相互重新分布的直线上的投影长度等于 $l_1$ 和 $l_2$。证明$S \leq l_1 l_2$。
b) 体积为 V 的凸多边形在三条相互重新分布的直线上的投影长度等于 $l_1, l_2$ 和 $l_3$。证明$V \leq l_1 l_2 l_3$。
c) 体积为 V 的凸多边形在三条相互重新分布的直线上的投影面积等于 $S_1, S_2$ 和 $S_3$。证明$V \leq \sqrt{S_1 S_2 S_3}$。

M609, M610; F613—F617

a) 和 b) 点的陈述直接源自以下事实：在情况 a) 中，多边形包含在边为 $l_1$ 和 $l_2$ 的长方形中，在情况 b) 中，多边形包含在边为 $l_1, l_2, l_3$ 的长方体中。

c) 令$\pi_1, \pi_2, \pi_3$为相互重新分布的平面，$S_1, S_2, S_3$为多边形M在这些平面上的投影面积，$l_1, l_2, l_3$为多边形M在直线$\pi_2 \cap \pi_3, \pi_1 \cap \pi_3, \pi_1 \cap \pi_2$上的投影线，$V = V(M)$为其体积。平行于 $\pi_1$ 的平面从此称为水平面。

第一个决定。公平的不平等
$$V \leq \sqrt{S_1 S_2 S_3}$$

对于具有水平底座的直接特征，很容易从a)得出：对于这样的特征$S_1 \leq l_2 l_3, S_2 = l_1 l_3, S_3 = l_1 l_2$和$V^2 = (S_1 l_1)^2 = S_1 \cdot S_1 l_1^2 \leq S_1 \cdot l_1 l_2 \cdot l_1 l_3 = S_1 S_2 S_3$。

为了证明（1）对于任意多边形，我们需要

引理。令多边形M被水平面切割成n个多边形$M_1, \dots, M_n$。如果它们中的每一个都满足不等式（1），那么对于 M 也成立。

让我们首先证明 $n = 2$ 的引理。令多边形$M_1$和$M_2$在平面$\pi_2$上的投影面积分别等于$a_1^2$和$a_2^2$，并分别等于$\pi_3$ - $b_1^2$和$b_2^2$（$a_i > 0, b_i < 0$）。 $M_1$和$M_2$在$\pi_1$上的投影面积不超过$S_1$。这就是为什么
$$V(M) = V(M_1) + V(M_2) \leq \sqrt{S_1} (a_1 b_1 + a_2 b_2) \leq \sqrt{S_1} \sqrt{a_1^2 + a_2^2} \sqrt{b_1^2 + b_2^2} = \sqrt{S_1 S_2 S_3}.$$

不等式
$$(a_1 b_1 + a_2 b_2)^2 \leq (a_1^2 + a_2^2) (b_1^2 + b_2^2),$$

我们将使用的值相当于估计的$(a_1 b_2 - a_2 b_1)^2 \geq 0$。

任何$n$的引理证明可以通过$n$来证明，或者类似于$n = 2$的情况，一起使用(2)柯西不等式(«Kvant», 1972, no. 1)
$$(a_1 b_1 + \dots + a_n b_n)^2 \leq (a_1^2 + \dots + a_n^2) (b_1^2 + \dots + b_n^2).$$

现在不等式(1)的证明就这样结束了。让我们将多边形 M 切成水平大象。在厚度较小的情况下，例如多边形 M 的体积和放置在彼此顶部的某些特征的并集（以及它们相应投影的面积）的不同之处在于角度有多小。确切地：

令 $h$ 为一个小的正数。让我们绘制足够密集的水平面（包括通过多边形 M 的所有顶点），以便 M 被切割成厚度为 $h_i \leq h(l_1 = h_1 + h_2 + \dots + h_n)$ 的 $n$ 个单词。让我们将第 $i$ 层围成一条高度为 $h_i$ 的直线，其水平底与该层在第 $i$ 割平面上的投影一致。

令 $M'$ 为构造特征的并集。 $M'$在$l_1$上的投影与多边形M在$l_1$：$S_1' = S_1$上的投影重合，并且$M'$在平面$l_2$和$l_3$上的投影$S_2'$和$S_3'$面积不小于面积$S_2$和分别为$S_3$，以及在图 1 上保护的矩形面积之和与它们的差。该和不大于$cl_1 h$，其中$c$是多边形M的边在平面$l_2$和$l_3$上的投影与垂直方向形成的角度的最大度数。这就是为什么
$$V(M) \leq V(M') \leq \sqrt{S_1' S_2' S_3'} \leq \sqrt{S_1 (S_2 + cl_1 h) (S_3 + cl_1 h)}.$$

因为这个不等式对于任何 $h$、$V \leqslant \sqrt{S_1 S_2 S_3}$ 都成立。

第二个解决方案。我们引入空间直角坐标系，分别以$\pi_1 \cap \pi_2$、$\pi_1 \cap \pi_3$、$\pi_2 \cap \pi_3$为$Ox$、$Oy$、$Oz$轴。令 $[a; b]$ 为轴 $Oz$ 的一段，多面体 $M$ 投影在该轴上。通过每个点 $z \in [a; b]$ 我们绘制一个水平面。设$S(z)$为该平面多面体的横截面积，$l_2(z)$和$l_3(z)$分别为该截面在平面$\pi_2$和$\pi_3$上的投影长度。可以证明

$$V = \int_a^b S(z) dz. \tag{4}$$

在教科书“几何 9-10”（第 58 节和第 66 节）中，该公式是针对示例和旋转体推导出来的；对于任意多胞形，证明是类似的。我们还将使用该公式（自己证明一下！）

$$S = \int_a^b l(z) dz, \tag{5}$$

其中，$S$是位于$xOz$平面上的凸多边形的面积，$l(z)$是平行于$Ox$轴并经过点$z \in [a; b]$（图2）点的直线与该多边形相交的线段的长度。此外，我们还需要 Bunyakovsky 积分不等式，它是不等式 (3) 的类比：

$$\left| \int_a^b f(z) g(z) dz \right| \leqslant \sqrt{\int_a^b f^2(z) dz} \cdot \sqrt{\int_a^b g^2(z) dz}.$$

我们将证明连续函数$f$和$g$。

证明。让$\lambda \in \mathbb{R}$。让我们考虑一下这个函数

$$\varphi(\lambda) = \int_a^b (f(z) - \lambda g(z))^2 dz =$$

$$= \lambda^2 \int_a^b g^2(z) dz - 2\lambda \int_a^b f(z) g(z) dz + \int_a^b f^2(z) dz = A\lambda^2 - 2B\lambda + C$$

$$\left( A = \int_a^b g^2(z) dz, B = \int_a^b f(z) g(z) dz, C = \int_a^b f^2(z) dz \right).$$

函数$\varphi$是一个平方三项式，对于任何$\lambda$取非负值。因此，$\frac{D}{4} = B^2 - AC \leqslant 0$或$B \leqslant \sqrt{A} \cdot \sqrt{C}$，这就是所需的不等式。 （通过模拟证明不等式（3）。）

现在让我们完成问题的第二个解决方案。

$$V = \int_a^b S(z) dz = \int_a^b \sqrt{S(z)} \cdot \sqrt{S(z)} dz.$$

由于 $S(z) \leqslant S_1$ 对于任意 $z \in [a; b]$，我们得到

$$V \leqslant \sqrt{S_1} \cdot \int_a^b \sqrt{S(z)} dz.$$

根据a) $S(z) \leqslant l_2(z) l_3(z)$。这就是为什么

$$V \leqslant \sqrt{S_1} \cdot \int_a^b \sqrt{l_2(z)} \cdot \sqrt{l_3(z)} dz.$$

众所周知，如果两个集合具有相同数量的元素，则它们之间可以建立一一对应关系。严格来说，这是元素集合中相等的确定性，但有时会忘记这一事实。同时，两个数字的相等性通常是通过集合的一一对应来精确确定的。

我们需要证明恰好有一半的集合包含$a_k = k$。因此，我们将尝试在它们的集合和其余具有$a_k < k$的集合之间建立一一对应。

不可能将集合 $(a_1, a_2, \dots, a_k)$ 与集合 $(a_k, a_{k-1}, \dots, a_1)$ 关联起来，因为新集合没有增加。您可以尝试将集合$(a_1, \dots, a_k)$与集合$(k - a_k, k - a_{k-1}, \dots, k - a_1)$进行比较：它已经是不可约的，但是......$k - a_1$不必小于$k$。因此，这个对应关系并不能解决问题。 （问题：这封信解决了什么问题？）

这意味着需要更复杂的对应关系。为了构造它，我们需要给定集合的杨图的概念。

显然，如果原始集合为$(a_1, \dots, a_k)$，附加集合为$(b_1, \dots, b_k)$，则$a_k = k$当且仅当$b_k < k$。事实上，如果右上单元格包含在主杨图中，则为 $a_k = k$；如果右上单元格包含在附加单元格中，则为 $a_k < k$。

我们在$a_k = k$集合和$a_k < k$集合之间建立的对应关系是非常印度和一对一的。这样我们就解决了a)。此外，原始集合和附加集合中的数字之和等于 $k^2$（在我们的示例中为 25）。因此，当且仅当原集合中的数字之和能被$k$整除时，补集中的数字之和才能被$k$整除。这样就解决了6)。

还有另一种解决方案：我们可以无限地数$N$和$M$。确切地：

引理使得 $0 \leq a_1 \leq \dots \leq a_m \leq k$ 为 $C_{k+m}^m$ 的整数集 $a_1, \dots, a_m$ 的数量。

证明。考虑集合$(b_1, \dots, b_m)$，其中$b_i = a_i + i$：$b_1 = a_1 + 1$，$b_2 = a_2 + 2$等。那么，显然，$1 < b_1 < b_2 < \dots < b_m < k + m$，即$(b_1, \dots, b_m)$是其前$k + m$数字的$m$整数的任意集合。这样的组数为$C_{k+m}^m$。

根据引理，$a_k \leq k$等于$C_{k+k}^k$的集合数。如果$a_k = k$，那么我们所要做的就是选择数字$a_1, \dots, a_k - 1$，这样$0 \leq a_1 \leq \dots \leq a_k - 1 \leq k$；他们的数量是$C_{k+k-1}^k$。还需要计算$2C_{k+k-1}^k$等于$C_{k+k}^k$。

F616。灯泡累积灯丝的长度为$l$，直径为$d$。如果两个灯泡的效率相同，则针对相同电源电压但具有更高光通量输入而设计的另一个灯泡的长度 $l_1$ 和直径 $d_1$ 是多少？

令$W$和$W_1$为第一灯和第二灯从网络消耗的功率。那么灯以光（光通量）形式发出的能量分别等于$E = \eta W$和$E_1 = \eta W_1$，其中$\eta$是灯的效率。

在平衡状态下，灯从网络接收的功率$W$（$W_1$）必须等于灯以光和热的形式发出的功率$P$（$P_1$）。功率$P$ ($P_1$)，非常indo，与灯丝表面面积$S$ ($S_1$) 和温度$f(T)$ ($f(T_1)$) 的某个函数成正比。因此，

$$P = W = k_1 S f(T), \quad W_1 = k_1 S_1 f(T_1),$$

其中$k_1$是比例系数。灯发出的光通量也与灯丝的表面积和温度的一些函数成正比：

$$E = k_2 S \varphi(T), \quad E_1 = k_2 S_1 \varphi(T_1).$$

并且从$E = \eta W$开始，那么

$$k_2 \varphi(T) = \eta k_1 f(T), \quad k_2 \varphi(T_1) = \eta k_1 f(T_1).$$

从这些等式可以清楚地看出，灯泡的效率由灯丝的温度决定。因此，在两个灯的效率相同的情况下，它们的灯丝温度会累积，即$T_1 = T$。这意味着

$$\frac{E_1}{E} = \frac{k_2 S_1 \varphi(T)}{k_2 S \varphi(T)} = \frac{S_1}{S} = \frac{d_1 l_1}{dl}.$$

根据问题$E_1: E = 2$的条件，即

$$\frac{d_1 l_1}{dl} = 2.$$

电源电压$U$

$$E = \eta W = \eta \frac{U^2}{R}, \quad E_1 = \eta W_1 = \eta \frac{U^2}{R_1},$$

其中$R = \varrho \frac{4l}{\pi d^2}$、$R_1 = \varrho \frac{4l_1}{\pi d_1^2}$是灯丝的电阻（$\varrho$是灯丝工作温度下灯丝材料的电阻率）。因此，$\frac{E_1}{E} = \frac{ld_1^2}{l_1 d^2}$，根据条件，

$$\frac{l d_1^2}{l_1 d^2} = 2.$$
