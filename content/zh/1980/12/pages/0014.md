由于在顶点$A_0$处汇聚的所有角度之和小于2π，因此顶点$A_0$处的传递面的角度之和加起来小于$\frac{2\pi}{3}$，这表明只有一个传递面γ可以应用于$A_0$。如果这个面是正$l$边形，即有一个$\alpha = \pi - \frac{2\pi}{l}$角，那么，根据所说的，$\sigma + \alpha < 2\pi$，即$(2\pi - \frac{2\pi}{k}) + (\pi - \frac{2\pi}{l}) < 2\pi$。换句话说，$\frac{1}{k} + \frac{1}{l} > \frac{1}{2}$。考虑到$k > 2$，$l > 2$，我们从这里发现以下五种可能性：

1) $m = 2$, $k = 3$, $l = 3$;
2) $m = 2$, $k = 3$, $l = 4$;
3) $m = 2$, $k = 3$, $l = 5$;
4) $m = 2$, $k = 4$, $l = 3$;
5) $m = 2$, $k = 5$, $l = 3$.

与这些情况相对应的正传递多面体很容易构造：为此，您需要“切断”正多面体根部的顶点（对于正多面体，请参阅“几何 9-10”，第 54 节或«Kvant»，1980 年，第 7 期，第 6 页）。

要切断顶点，您需要在从顶点出来的所有边上布置长度相等、小于边长度一半的线段，并通过所得点 (图 1) 绘制一个平面。例如，图2表示对应于情况4的多面体：它是通过立方体顶点的平均值获得的。很容易看出，立方体的所有自组合都会将该多面体转变为自身，反之亦然。因此，多面体的自对准群与立方体的自对准群重合。这同样适用于列出的其余五个案例。

因此，对应于情况 A 的正传递多面体是具有平均顶点的正多面体。

B) 多面体 M 包含一个与三角形不同的异正面 γ，并且对于该面 $k = 2$。这里还有$m = 2$，即面γ是平行四边形（$m = 2$，$k = 2$），以及$\sigma = \frac{\pi}{k}(km - 2) = \pi$。因此，顶点 $A_0$ 最多与两个传递面相邻。

让我们首先考虑顶点 $A_0$ 与 2 个传递面相邻时的子情况。这些面不相邻（否则，根据引理 3，所有面都将与其中一个面全等，并且是传递性的，这是不可能的，因为存在异质面 γ）。我们假设这些面是正则$l_1$边形和正则$l_2$边形，然后是$\sigma + \left(\pi - \frac{2\pi}{l_1}\right) + \left(\pi - \frac{2\pi}{l_2}\right) < 2\pi$，即$\frac{1}{l_1} + \frac{1}{l_2} > \frac{1}{2}$。这又给出了三种可能性（我们可以考虑$l_1 \leq l_2$：

6) $m = 2$, $k = 2$, $l_1 = 3$, $l_2 = 3$;
7) $m = 2$, $k = 2$, $l_1 = 3$, $l_2 = 4$;
8) $m = 2$, $k = 2$, $l_1 = 3$, $l_2 = 5$.
