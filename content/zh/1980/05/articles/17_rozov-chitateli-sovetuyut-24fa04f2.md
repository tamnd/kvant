在各种数学入学考试中，经常会遇到控制系统。一般来说，申请人擅长解决系统问题的基本方法——替换法和消除法。期刊读者 P. Chebotarev（莫斯科）提请注意一条有趣的消息，该消息允许解决某些控制系统的问题。然而，在讨论这个之前，我们先来谈谈一种特殊类型的复杂函数。

给定函数$f$，为简单起见，我们假设$D(f) = R$。基于这个函数，可以组成一个新的函数

$$F(x) = f(f(x));$$

很大程度上，它也是在整个数轴上定义的。函数$F$通常称为*迭代*)函数$f$。从 图 1 很容易理解如何使用函数 $f$ 的图形来查找参数的特定值 $x_*$ 的迭代值 $f(f(x_*))$。

考虑方程

$$f(f(x)) = x. \tag{1}$$

首先，注意如果$x_0$是方程的根

$$f(x) = x, \tag{2}$$

则$x_0$为式(1)的根。但是，方程（1）当然可以有除方程（2）之外的其他根（尝试从 图 1 中辨别这一事实）。

由于等式(2)是等式(1)，因此指示这些等式等价的情况是有用的。例如，让我们证明以下命题：如果函数$f$满足条件

$$\begin{cases} f(x) \geq x, \text{ при всех } x < a, \\ f(a) = a, \\ a \leq f(x) \leq x, \text{ при всех } x > a, \end{cases}$$

那么方程（1）和（2）是等价的（给出该定理的几何解释）。

上面已经指出，式（2）的根始终作为式（1）的根；让我们证明相反陈述的有效性。设$x_0$为方程(1)的根：

$$f(f(x_0)) = x_0; \tag{4}$$

*) 一般来说，数学中的迭代（源自拉丁语 iteratio - 重复）是重复应用每个运算的结果。

让我们分别考虑每种可能的情况$x_0 > a$、$x_0 < a$、$x_0 = a$。

如果$x_0 > a$，则（见（3））
$$a \leq f(x_0) \leq x_0.$$ (5)

从函数 $f$ 的性质 (3) 可以看出，不等式 $a \leq f(z) \leq z$ 对于任何 $z \geq a$ 都成立。因此，选择$z = f(x_0)$，考虑到（5），我们有
$$a \leq f(f(x_0)) \leq f(x_0).$$ (6)

由(6)和(5)的对应关系可知
$$f(f(x_0)) \leq f(x_0) \leq x_0.$$
将这个整数不等式与等式（4）进行比较，我们得出$f(x_0) = x_0$，即$x_0$，是等式（2）的根。

让我们进一步假设$x_0 < a$。
在这种情况下，不等式$f(x_0) \geq a$是不可能的：如果它发生，则满足对应关系（6），考虑到不等式$x_0 < a$，这将导致与等式（4）的矛盾。因此，如果$x_0 < a$则$f(x_0) < a$。从函数$f$的性质(3)可知，不等式$f(z) \geq z$对于任何$z < a$都成立。因此，先选择$z = x_0$，然后选择$z = f(x_0)$，我们有
$$x_0 \leq f(x_0) \leq f(f(x_0)).$$
利用等式（4），我们再次得出$f(x_0) = x_0$的结论。

听$x_0 = a$非常认同。因此，在条件(3)下，方程(1)的任意根都是方程(2)的根。

总之，我们注意到，从给定函数 $f$ 显然也可以确定该函数
$$f(f(f(x))), f(f(f(f(x))))), \dots$$
以下命题成立（自己证明）：如果函数$f$满足条件（3），则每个方程$f(f(f(x))) = x, f(f(f(f(x)))) = x, \dots$
等价于式(2)。

现在让我们看看如何使用所制定的建议来求解所有方程在变量指定方面都相同且每个方程仅包含两个变量的系统。

示例 1（密歇根州立大学，力学和数学，1977 年）。找到方程组的所有解
$$\begin{cases} y^3 - 6x^2 + 12x - 8 = 0, \\ z^3 - 6y^2 + 12y - 8 = 0, \\ x^3 - 6z^2 + 12z - 8 = 0. \end{cases}$$

让我们隔离这个函数
$$f(x) = \sqrt[3]{6x^2 - 12x + 8}, x \in \mathbb{R};$$ (7)

那么这个系统可以重写为以下形式
$$y = f(x), z = f(y), x = f(z).$$ (8)

使用替换方法，我们从这里得到
$$f(f(f(x))) = x.$$ (9)

首先，考虑方程 $f(x) = x$，或者
$$x^3 - 6x^2 + 12x - 8 = 0.$$
它有一个根$x = 2$（将第一个左侧与最后一个左侧分组，将第二个左侧与第三个分组），这也是方程（9）的根。由函数$f$的表达式(7)和方程(8)我们得到原系统的解：
(2; 2; 2).

让我们检查函数（7）对于$a = 2$满足条件（3），因此方程（9）除了$x = 2$之外没有其他根。不等式 $f(x) \geq x$，在本例中简化为以下形式
$$(x - 2)^3 \leq 0$$
（进行必要的转换），确实适用于$x < 2$和$f(2) = 2$。此外，对于所有$x > 2$，$f(x) \leq x$。最后，不等式$f(x) \geq 2$可以很容易地重写为以下形式
$$6x^2 - 8x \geq 0,$$
由此可见，它对于$x > 2$有效。

因此，原系统有唯一解(2;2;2)。

12. 一致性是否有限制

掌握各种变换技术在数学中的重要性不亚于各种定理的含义或进行逻辑推理的能力。然而，这些技术之一是添加和减去一些删除的选定表达式。例如，在对多项式进行因式分解时，经常会这样做。

九年级学生 Avaz Naziev（阿塞拜疆苏联 Zangelan 区 Minjevan 村）举了以下例子：

例 4. 证明如果函数 $f(x)$ 在 $x = a$ 处任意，则

$$\lim_{x \to a} \frac{xf(a) - af(x)}{x - a} = f(a) - af'(a).$$

在计算给定表达式的代数变换之前（假设 $x \neq a$）：

$$\frac{xf(a) - af(x)}{x - a} = \frac{xf(a) - af(x)}{x - a} - \frac{af(x) - af(a)}{x - a} = f(a) - a \frac{f(x) - f(a)}{x - a}.$$

从这里已经很清楚，如果 $f'(a)$ 存在且等式 (12) 成立，则 (12) 中指示的真实极限存在。
