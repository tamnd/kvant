$$\frac{1}{p}, \frac{2}{p}, \dots, \frac{p-1}{p},$$

$$\frac{1}{q}, \frac{2}{q}, \dots, \frac{q-1}{q}.$$

我们给出两个解决方案。

第一个决定。其条件是，数字 $p$ 和 $q$ 均与数字 $n=p+q$ 互质，因此$i/p, j/q, k/n$ 点（除了 0 和 1 之外）没有两个点重合。由于$1/p > 1/n$和$1/q > 1/n$，从点$i/p$开始的任何两个都位于不同的线段$\left[\frac{k}{n}; \frac{k+1}{n}\right]$，并且从点$j/q$开始的任何两个也位于不同的线段。你只需证明$i/p$和$j/q$不能落入同一个线段$\left[\frac{k}{n}; \frac{k+1}{n}\right]$（$k=1, 2, \dots, n-2$）即可。但这是因为分数 $\frac{k}{n} = \frac{i+j}{p+q}$ 位于 $\frac{i}{p}$ 和 $\frac{j}{q}$ 之间（参见 图 1）。

$p=8, q=5, n=8+5=13$

◆

对于杆的任何位置，点 C 距直角顶点 O 的距离为$l/2$（从直角顶点绘制的中线等于斜边的一半）。因此，C 点沿着以 O 点为中心、半径为$l/2$ 的圆运动。C 点的速度$v_c$ 与轨迹相切，并且在任何时刻都垂直于 OC。

由于杆不可伸长，因此 C 点和 B 点的速度在杆方向上的投影等于 (图 2)。

$$v \cos \alpha = v_c \cos \beta = v_c \cos \left( 2\alpha - \frac{\pi}{2} \right) = v_c \sin 2\alpha.$$

因为

$$v_c = \frac{v \cos \alpha}{\sin 2\alpha} = \frac{v}{2 \sin \alpha}.$$

C 点加速度 $\vec{a}_c$ 在半径 OC = $l/2$ 上的投影必须等于 $\frac{v_c^2}{l/2} = \frac{v^2}{2l \sin^2 \alpha}$。矢量$\vec{a}_c$的方向是什么？注意C点速度$\vec{v}_c$在水平轴上的投影等于$v_c \cos (\alpha - \beta) = v_c \cos \left( \frac{\pi}{2} - \alpha \right) = \frac{v}{2}$。该量不取决于 α，因此是恒定的。这意味着向量 $\vec{a}_c$ 是垂直方向的。

因此，

$$a_c \cos \left( \frac{\pi}{2} - a \right) = \frac{v^2}{2l \sin^2 \alpha},$$

在哪里

$$a_c = \frac{v^2}{2l \sin^3 \alpha}.$$

◆

关闭按键 K1 后，电容器上的方向变为等于 E。此时，电容器的电荷等于

$$q_1 = C \varepsilon.$$

当开关 K1 闭合时，该电荷通过检流计。因此，

$$\alpha = kq_1 = kC \varepsilon,$$

其中$k = \text{const}$是比例系数。

闭合开关K2后，电容两端的方向变得等于电阻两端的电阻方向，即$U = IR$，其中I为流过电阻的电流。由于电阻器连接在压力源之后，$I = \varepsilon / (R + r)$。因此，$U = \varepsilon R / (R + r)$。关闭钥匙K2后电容器的电荷变得相等

因此，关闭钥匙 K2 后，电荷会通过检流计

$$q = q_1 - q_2 = C \varepsilon \frac{r}{R + r}$$
