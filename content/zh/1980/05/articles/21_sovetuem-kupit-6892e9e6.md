数学
笔试
选项1
（数学系）

1. 三角形$ABC$的面积等于1。如果点$P, Q, R$属于相应的中线$AK, BL, CN$和$\frac{|AP|}{|PK|} = 1, \frac{|BQ|}{|QL|} = \frac{1}{2}, \frac{|CR|}{|RN|} = \frac{5}{4}$，求三角形$PQR$的面积。

2. 解决不平等问题
$$\sqrt{x+3} < \sqrt{x-1} + \sqrt{x-2}.$$

3. 解方程
$$\cos \frac{3x}{2} \cos \frac{x}{2} - 1 = \frac{1+\sqrt{3}}{2} \cos x.$$

4. 找到不等式的参数$a$的所有值
$$(a-1)x^2 - (a+1)x + (a+1) > 0$$
对所有真正的$x$感到满意。

选项2
（物理学院）

1. 凸四边形$ABCD$的面积等于1。如果点$K, L, M, N$属于对应边$AB, BC, CD, AD$和$\frac{|AK|}{|KB|} = 2, \frac{|BL|}{|LC|} = \frac{1}{3}, \frac{|CM|}{|MD|} = 1, \frac{|DN|}{|NA|} = \frac{1}{5}$，求六边形$AKLCMN$的面积。

2. 解决不平等问题
$$\sqrt{4-\sqrt{1-x}} - \sqrt{2-x} > 0.$$

3. 解方程
$$2\sin 3x \cdot \sin x + (3\sqrt{2}-1)\cos 2x = 3.$$

4. 找到方程中参数$a$的所有值
$$\cos x = \frac{a-1,5}{2-0,5a}$$
有一个解决方案。

物理
笔试
医学院
选项1

1. 匀速圆周运动。线速度和角速度；他们之间的联系。角速度单位。向心加速度。

2. 交流电。交流发电机。交流电的周期和频率。电压和电流的有效值。使用二极管对交流电进行整流。

3. 一米中有 $m_1 = 0,4$ 千克水，温度为 $t_1 = 10^\circ\text{C}$。将$m_2 = 0,6$公斤冰放入温度为$t_2 = -40^\circ\text{C}$的水中。如果热容量可以忽略不计，仪表中的温度设置为多少？水的比热为$c_1 = 4,2$ kJ/(kg K)，冰的比热为$c_2 = 2,1$ kJ/(kg K)，冰的融化比热为$\lambda = 0,33$ MJ/kg。

4. 位于镜头光轴上的光源与屏幕之间的距离为$l = 0,5$米。镜头在两个位置上提供清晰的光源图像，两个位置之间的距离为 $a = 0,1$ 米。镜头的焦距是多少？显示光线路径。

选项2

1. 在电场中移动电荷的功。潜力的概念。潜力单位。精确的电荷场电势（无输出）。潜在的差异。均匀场的电势差和应力之间的关系。

2. 光的色散。光谱。分光镜。光谱的红外和紫外部分。发射光谱。吸收光谱。频谱分析的概念。

3. 一名游客从路口东2公里、北1公里处出发，在$t=1$小时内行驶了$s=5$公里。向东画的直线与游客的移动方向成$\alpha = 135^\circ$角。确定旅行一小时后游客所在的位置。

4. 如果在短路期间，横截面为 $S = 1$ mm²、长度为 $l = 2$ cm 的引线制成的保险丝在 $t = 0,03$ 秒内熔化，请确定电压为 $U = 120$ V 的水下电线的电阻。初始温度保险丝$t_0 = 27^\circ\text{C}$。铅比热$c = 0,13 \cdot 10^3$ J/(kg·K)，熔点$T = 600$ K，密度$D = 11,3 \times 10^3$ kg/m3，比电阻$\rho = 2,1 \cdot 10^{-7}$ Ohm·m，熔化比热$\lambda = 0,25 \cdot 10^5$ J/kg。
