⟦folio 40⟧

问题 M567 允许替代概括。令 α 和 β 为通过关系 1/α + 1/β = 1 关联的任何正数。

让我们在数轴上标出 iα 和 jβ 形式的自由数 (i ∈ Z, j ∈ Z)。然后每个段[k; k+1]轴(k ∈ Z)，其两端均不包含偏移数，恰好包含偏移数iα、jβ之一。

对于有理 α 和 β，我们的问题相当于这个事实：我们需要取 α = n/p，β = n/q（线段 [0; 1] 的作用现在将由线段 [0; n] 扮演）。最近在问题 M538 的解决方案（«Kvant»，1979，第 11 号）中提到了同样的事实（对于无理 α 和 β），与我们对 M567 的第二个解决方案非常相似。

N·瓦西里耶夫

M569。现在有几个号码已发送至。如果与所有已写入的数字不同，则允许为这些数字分配一个等于长度的算术平均值的数字或其中的几个数字。证明，从两个数字 0 和 1 开始，使用所描述的操作可以得到
a) 数字 1/5；
b) 0 到 1 之间的任何有理数。

让我们从一般地表示数字 1/5 和 1/q 开始。数字 1/2、1/4、3/4 很容易获得：

$$\frac{1}{2} = \frac{0+1}{2}, \frac{1}{4} = \frac{0+\frac{1}{2}}{2}, \frac{3}{4} = \frac{\frac{1}{2}+1}{2}.$$

也可以非常印度地获得任何双双有理分数，即 p/2^m、p<2^m (图 1) 形式的分数。

要得到分数 1/q，只需将 1 表示为 q 个不同真双有理分数之和即可：它们的算术平均值恰好为 1/q。让我们通过归纳法来证明这是可能的。 1 可以表示为两个此类分数的总和（例如，1=3/4+1/4）。

从表示 1 作为 n-1 个不同双有理分数之和，我们可以得到其表示为 n 个这样的分数之和：

$$1 = a_1 + a_2 + \dots + a_{n-1} = \frac{1}{2} + \frac{a_1}{2} + \frac{a_2}{2} + \dots + \frac{a_{n-1}}{2}.$$

特别是，按照这个构造，我们得到

$$1 = \frac{3}{4} + \frac{1}{4} = \frac{1}{2} + \frac{3}{8} + \frac{1}{8} =$$
$$= \frac{1}{2} + \frac{1}{4} + \frac{3}{16} + \frac{1}{16} = \frac{1}{2} + \frac{1}{4} + \frac{1}{8} + \frac{3}{32} + \frac{1}{32},$$

它给出了数字 1/5 的表示。

盖勒可以用多种不同的方式证明问题的第二个陈述。让我们给其中两个。

1. 让我们证明，如果一个自然数 p 可以表示为 n-1 个不同的真双有理分数之和：

$$p = a_1 + a_2 + \dots + a_{n-1} \quad (0 < a_{n-1} < \dots < a_2 < a_1 < 1),$$

那么它可以表示为 n 个这样的分数的和。令 2^m 为项 a_i 的值中的最小值。将 a_n-1 替换为总和 $\left(a_{n-1} - \frac{1}{2^m+2}\right) + \frac{1}{2^m+2}$，我们得到所需的表示。因此，每个分数$\frac{1}{q}, \frac{2}{q}, \dots, \frac{q-1}{q}$都可以表示为各种真双有理分数的算术平均值，那么分数$\frac{1}{q+1}, \frac{2}{q+1}, \dots, \frac{q-1}{q+1}$可以用类似的形式表示。为了通过归纳法证明这个证明（归纳法的基础是数字 1/2 的表示），仍然需要以所需的形式表示分数 $\frac{q}{q+1}$。将所有分数a_i替换为1—a_i，可以从数字$\frac{1}{q+1}$的表示中得到。
