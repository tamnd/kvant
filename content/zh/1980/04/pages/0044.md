情况6）。这种情况是可能的当且仅当
$$\sin \frac{\beta}{2} = \sqrt{2} \sin \frac{\alpha}{2}.$$
(2)

确实，如果$\hat{C} = 90^\circ$，$|CD| = |AD| = l \sin \frac{\beta}{2}$； $|CD| = |AC| \frac{\sqrt{2}}{2} = \sqrt{2} l \sin \frac{\alpha}{2}$（图2）。

因此$\sin \frac{\beta}{2} = \sqrt{2} \sin \frac{\alpha}{2}$。反之，若$\sin \frac{\beta}{2} = \sqrt{2} \sin \frac{\alpha}{2}$，则
$$|CD| = l \sqrt{1 - 2 \cos \alpha + \cos^2 \frac{\beta}{2}} = l \sqrt{2 - 2 \cos \alpha - \sin^2 \frac{\beta}{2}} = \sqrt{2} l \sqrt{1 - \cos \alpha - \sin^2 \frac{\alpha}{2}} = \sqrt{2} l \sqrt{\sin^2 \frac{\alpha}{2}} = \sqrt{2} l \sin \frac{\alpha}{2}.$$

因此$\cos \hat{ACD} = \frac{|CD|}{|AC|} = \frac{\sqrt{2}}{2}$。因此$\hat{ACD} = 45^\circ$，$\hat{C} = 90^\circ$。如果$\sin \frac{\beta}{2} = \sqrt{2} \sin \frac{\alpha}{2}$，则$h = |SD| = l \cos \frac{\beta}{2}$（图2），$V = \frac{l^2}{3} \sin^2 \frac{\beta}{2} \times l \cos \frac{\beta}{2}$，$V = \frac{l^3}{6} \sin \beta \sin \frac{\beta}{2}$。

情况c）。让我们输入 $x = |OD|$ (图 3)。与情况 a) 一样，我们发现：
$$x = l \frac{\cos \alpha - \cos^2 \frac{\beta}{2}}{\sqrt{1 - 2 \cos \alpha + \cos^2 \frac{\beta}{2}}};$$
$$h = |SO| = l \frac{\sqrt{\cos^2 \frac{\beta}{2} - \cos^2 \alpha}}{\sqrt{1 - 2 \cos \alpha - \cos^2 \frac{\beta}{2}}};$$
$$V = \frac{1}{3} l^3 \sin \frac{\beta}{2} \sqrt{\cos^2 \frac{\beta}{2} - \cos^2 \alpha}.$$

我们看到情况 a) 和 b) 的答案是相同的，尽管它们不是以相同的方式获得的。此外，在情况6）中这个答案也是有效的，这并不难检查（使用对应关系（2）去掉（1）中的α，我们得到（3））。

回答：
$$V = \frac{l^3}{3} \sin \frac{\beta}{2} \sqrt{\cos^2 \frac{\beta}{2} - \cos^2 \alpha}.$$

我们强调，仅分析情况 a) 的解决方案不能被认为是完整的。

示例 2. SABC 参数基于 $|AB| = |BC| = 20$ cm、$|AC| = 32$ cm 的三角形；底面与每个侧面之间的角度为45°。找到体积参数。

解决方案。高度参数的基础是等于直线 AB、AC、BC 长度的点，即内切于 $\triangle ABC$ 的圆的中心，或外部圆之一（问题 16）。因此，该问题的条件由四个参数满足，其高度的底是点$O_1$、$O_2$、$O_3$、$O_4$（图 4）。要计算这些参数的体积，只需确定高度 $SO_1$、$SO_2$、$SO_3$、$SO_4$ 即可，因为底面积为 $S = S_{\triangle ABC} = 192$ cm²。由于侧面与底面成 45° 角倾斜，因此参数的高度等于 $\triangle ABC$ 内切圆的半径，或其中一个外部圆的半径，其中心是参数高度的底面。
