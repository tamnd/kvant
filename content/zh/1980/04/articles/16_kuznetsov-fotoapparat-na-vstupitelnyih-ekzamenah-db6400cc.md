入学考试用相机

Foto相机的基本图可以表示为图1。

如您所知，Foto 相机是一种透光相机（Foto 相机通常被称为相机）。相机前面是 O 物体。该设备的物体相当复杂：它通常包含多达二十个不同的镜头。然而，为了解决大问题，物体可以被认为是薄的会聚透镜。这就是我们在本文中要做的事情。

快门用于打开和关闭物体。对象保持打开状态的时间称为实验时间，或简称为实验。实验的持续时间是利用信号物体的信号和感光胶片的感光度来进行的。

穿过物体的光能流由光圈D控制。通过改变光圈的直径，物体的或多或少的重要部分可以被曝光。事实证明，这不仅改变了图像的照明，还改变了空间图像的景深（我们稍后会更详细地讨论这一点）。

相机背面有一张照相胶片（或照相塑料）FP，在其上得到被摄物体H的图像h（见图1）。为了使图像准确地出现在摄影胶片的平面上，大多数相机都能够沿着其光轴在一定范围内移动物体。这是通过聚焦来完成的。

让我们看一下在入学考试期间向申请人提供的与 Foto 相机相关的几个具体任务。

问题 1. 在 Foto 相机的两个位置的同一个卡达尔上形成两次点物体。在第二位置，装置相对于第一位置移动h＝10cm。胶片上物体的两个图像之间的距离结果等于 p=2 毫米。如果 Foto 相机物体的焦距为 F=5 cm，请确定到物体的距离。

让物体S和它的第一张图像S₁的位置如图2所示。让我们找到第二种情况下物体图像的位置。

由于 Foto 相机垂直于物体的主光轴移动，因此第二图像 S2 与图像 S1 一样，应该位于胶卷的平面内。让我们画一条辅助光轴，穿过物体和位于 Foto 相机第二个位置的物体的光心。图像 S2 位于该轴与胶片平面的交点处。

从图2可以看出，

$$\frac{h}{p} = \frac{d}{f},$$

其中 d 是所需的距物体的距离。

问题2. 当从$d_1 = 15$米的距离拍摄物体时，其图像在胶片上的高度结果等于$h_1 = 30$毫米，而当从$d_2 = 9$米的距离拍摄时，结果为$h_2 = 51$毫米。求相机物体的焦距。

根据定义，物体的线性放大

$$\Gamma = \frac{h}{H},$$

其中$h$是图像的线性尺寸，$H$是物体的线性尺寸。

另一方面（例如，从 图 1 得出），

$$\Gamma = \frac{f}{d},$$

其中$f$是图像到物体的距离，$d$是物体到物体的距离。

因此，

$$\frac{h}{H} = \frac{f}{d},$$

或者，考虑透镜公式

$$\frac{1}{d} + \frac{1}{f} = \frac{1}{F} \quad (F \text{ — фокусное расстояние}),$$

$$\frac{h}{H} = \frac{F}{d-F}.$$

图 2.

让我们写下问题条件中指定的两种情况的最后对应关系：

$$\frac{h_1}{H} = \frac{F}{d_1-F} \quad \text{и} \quad \frac{h_2}{H} = \frac{F}{d_2-F}.$$

从这里我们得到

$$F = \frac{d_2h_2-d_1h_1}{h_2-h_1} \approx 0,43 \text{ м} = 43 \text{ см}.$$

任务 3. 对于 azrophotostems，使用相机，其镜头的焦距为 $F = 8$ cm。放置在摄影胶片上的图像细节的最小尺寸（雕刻分辨率）为$\delta = 10^{-2}$毫米。 $l = 5$ 厘米的树板应放置在多高的高度？曝光时间$\tau = 10^{-3}$s，以什么速度独立仍然不模糊？

首先，我们先来谈谈胶片的分辨率。照相胶片的感光乳剂由悬浮在明胶层中的溴化银晶体组成。这些晶体是光层的感光中心。如果光线照射到晶体上，当照相胶片显影时，它会分解成金属银（黑色）和溴。

晶体虽然很小，但尺寸仍然有限。因此，如果两个不同点的图像落在同一个晶体上，我们就会在底片上得到一个点——一颗变黑的晶体。也就是说，胶片并没有解决这两点。

还有一项功能。溴化银晶体不仅吸收光，而且散射光，这就是为什么附近未接收直射光的相邻晶体也会被检测到。正因为如此，与发光点图像对应的孔隙的最小面积总是大于一个晶体的尺寸。

无论如何，任何电影都有一定的分辨率。

在我们的例子中，如果图像之间的距离超过$\delta = 10^{-2}$毫米，胶片将解析两个点，否则在胶片上显影后，您将得到一个点（更准确地说，一个小点）。

现在让我们看看“你可以在照片中看到树叶”这句话的意思。一般来说，差异的标准是一致的问题。让我们一致假设，如果一片叶子的图像具有树的最小面积的大小，则胶片上的树的叶子会有所不同。 （当然，这种情况下我们只能讨论这个地方有没有叶子，而不能讨论它是什么叶子。）

这意味着在这个问题中，一张$l = 5$厘米大小的纸张必须绘制在至少$\delta = 10^{-2}$毫米大小的区域上，否则两个相邻的纸张将产生一个红点。

镜头产生的放大倍数由以下公式确定

$$\Gamma = \frac{f}{d} = \frac{\delta}{l},$$

其中$d$是物体到物体的距离，$f$是物体到胶片的距离。

由于航拍时飞机的飞行高度不低于几十米，因此我们可以假设$d \gg f$。那么根据镜头公式$\frac{1}{d} + \frac{1}{f} = \frac{1}{F}$可以得出$f = F$，即图像位于设备镜头的焦平面内。

因此，

$$d = f \frac{l}{\delta} = F \frac{l}{\delta} = 400 \text{ м.}$$

关于第二个问题，合同的问题是这样的。如果在曝光时间内一张纸的图像移动不超过侧面最小点的大小，我们将认为图像不同：

$$|\vec{v}| \tau \frac{F}{d} \leq \delta,$$

其中$\vec{v}$是飞机的期望速度。

从这里

$$|\vec{v}| \leq \frac{\delta d}{\tau F} = 100 \text{ м/c} = 360 \text{ км/ч.}$$

问题4.相机可以聚焦（指向）的最近点距离镜头$d = 2$米。如果一条光焦度为 $D = +5$ ditre 的细正线紧贴镜头，该点会移动到哪里？

正如我们已经说过的，相机对焦（对焦）是通过机械移动镜头来进行的。但这种移动是有限的，因此设备无法聚焦于靠近一定距离的点。在这种情况下，这个距离是$d = 2$米。

让物体位于距离物体$d_1 < d$的位置。显然，附加的镜头应该由该物体在距离$d$处的图像表示，在该距离处附加镜头而无需附加镜头。

根据透镜公式

$$\frac{1}{d_1} - \frac{1}{d} = D$$

（因为图像最小所以取负号），从哪里

$$d_1 = \frac{d}{Dd+1} \approx 0,18 \text{ м.}$$

这个问题可以通过podgrut来解决。让我们用 $D_0$ 表示物体的光焦度。根据透镜公式

$$D_0 = \frac{1}{d} + \frac{1}{f},$$

其中 $f$ 是物体到物体的距离。众所周知，如果薄透镜彼此靠近，它们的光焦度就会增加。因此，对于具有线性附件的物镜，透镜公式可以写成如下：

$$D_0 + D = \frac{1}{d_1} + \frac{1}{f}.$$

从这个等式中减去前一个，我们得到$d_1$。

相机镜头所指向的物体（位于距离 $d_0$ 处），以及距离该距离稍近和稍远的物体。换句话说，该模式将导致对象位于某个区域 $d_1 \div d_2$ ($d_1 < d_0$, $d_2 > d_0$) 内； $d_1$称为景深的近极限，$d_2$称为景深的远极限。事实证明，当将相机镜头指向距离$d_0 = 10$米的物体时，景深的近极限等于$d_1 = 7,8$米。求远极限。

假设使用镜头 $DE$ 获得位于镜头光轴上距离镜头不同距离 (图 3) 的三个点的图像。设这些点为 $C_0$、$C_1$ 和 $C_2$。让我们将影片放置在点$C_0$。我们假设薄膜胶片的最小面积的大小等于$|AB|$（在图处为了清晰起见被大大放大）。如果镜头的直径使得形成点$C_1$和$C_2$的光线不超出区域$AB$，则在拍摄这些点中的任何一个时，整个区域都会失真，即这些点的图像将同样清晰。

显然，镜头直径越小，这个条件就越容易满足。这就是为什么当您缩小镜头时，景深会增加。

现在让我们继续进行定量计算。根据三角形 $DC_2O$ 和 $AC_2C_0$ 的相似性，可以得出以下结论

$$\frac{|AC_0|}{|DO|} = \frac{|C_2C_0|}{|OC_2|}.$$

图 3.

类似地，对于三角形 $DC_1O$ 和 $AC_1C_0$

$$\frac{|AC_0|}{|DO|} = \frac{|C_1C_0|}{|OC_1|}.$$

从这里我们得到

$$\frac{|C_2C_0|}{|OC_2|} = \frac{|C_1C_0|}{|OC_1|},$$

或者

$$\frac{1}{|OC_2|} + \frac{1}{|OC_1|} = \frac{2}{|OC_0|}$$

（从$|C_2C_0| = |OC_0| - |OC_2|$和$|C_1C_0| = |OC_1| - |OC_0|$开始）。

根据透镜公式

$$\frac{1}{d_0} + \frac{1}{|OC_0|} = \frac{1}{F},$$

在哪里

$$|OC_0| = \frac{Fd_0}{d_0 - F},$$

其中$F$是镜头的焦距。同样我们得到

$$|OC_1| = \frac{Fd_1}{d_1 - F} \text{ и } |OC_2| = \frac{Fd_2}{d_2 - F}$$

将得到的表达式按照(*)代入$|OC_0|$、$|OC_1|$、$|OC_2|$，并进行简单变换，可得

$$\frac{1}{d_1} + \frac{1}{d_2} = \frac{2}{d_0}.$$

从这里我们找到$d_2$：

$$d_2 = \frac{d_0 d_1}{2 d_1 - d_0} \approx 13,9 \text{ м.}$$
