我们将立即解决第6)点。令$x_1, x_2, y_1, y_2$分别为三角形$x^2+px+q$和$x^2+qx+p$的整数根。由维塔定理

$$x_1+x_2=-p, y_1+y_2=-q, x_1x_2=q, y_1y_2=p.$$

将前两个等式的乘积除以另外两个等式的乘积 ($pq \neq 0$)，我们得到：

$$\left(\frac{1}{x_1}+\frac{1}{x_2}\right)\left(\frac{1}{y_1}+\frac{1}{y_2}\right)=1.$$

不失一般性，我们可以假设$\left|\frac{1}{x_1}+\frac{1}{x_2}\right| \geq 1$和$\left|\frac{1}{x_1}\right| \geq \frac{1}{2}$，即$|x_1| \leq 2$。

有两种可能的情况：$|x_1|=1$和$|x_1|=2$。

1°。让$|x_1|=1$。然后从不等式$\left|\frac{1}{x_1}+\frac{1}{x_2}\right| \geq 1$我们得到$|x_2|=n$，其中$n \in \mathbb{N}$，$x_1x_2>0$。从这里开始，根据维埃塔定理，对于第一个三角形，我们得到$p=\pm(n+1)$，$q=n$。三角形$x^2+nx-(n+1)$对所有$n \in \mathbb{N}$都有全根，三角形$x^2+nx+n+1$只对$n=5$有全根。事实上，这个三角形$(n-2)^2-8$的判别式一定是一个完全平方数：$(n-2)^2-8=b^2$，即$(n-2)^2-b^2=8$；因此$(n-2-b)(n-2+b)=8$、$n \in \mathbb{N}$和$b \in \mathbb{N}$。这就是为什么

$$\begin{cases} n-2-b=2 \\ n-2+b=4 \end{cases} \Rightarrow n=5.$$

2°。让$|x_1|=2$。然后从不等式$\left|\frac{1}{x_1}+\frac{1}{x_2}\right| \geq 1$得出$|x_2| \leq 2$。情况$|x_2|=1$，就符号而言，是上面的距离，情况$|x_2|=2$导致参数$(4,4)$和$(-4,4)$，其中第二个不合适（多项式$x^2+4x-4$没有整数根）。

让$|BC| = |BD| = |CE| = a, |AC| = b, |AB| = c$。

考虑一个圆心位于点 $K$ 、半径为 $|KO|$ 的圆。我们来画和弦 $[OM] \parallel [AC]$ 和 $[ON] \parallel [AB]$。让我们证明顶点 $O$ 和 $A$ 的角全等的三角形 OMN 和 ADE 是全等的。

$$|AK'| = \frac{a+b+c}{2} - a = \frac{b+c-a}{2},$$

$$|O'K'| = |AK'| - |AO'| = \frac{b+c-a}{2} - \frac{c}{2} = \frac{b-a}{2},$$

$$a_1 + a_2 + ... + a_k = n$$

问题的陈述立即来自两个引理：

1°。如果数字 $n$ 是好的，那么 $u$ $2n + 2$ 也是好的；
2°。如果数字 $n$ 是好的，那么 $u$ $2n + 9$ 也是好的。

$$n = a_1 + a_2 + ... + a_k,$$

$$\frac{1}{a_1} + \frac{1}{a_2} + ... + \frac{1}{a_k} = 1$$

$$2n + 2 = 2a_1 + 2a_2 + ... + 2a_k + 2,$$

$$\frac{1}{2a_1} + \frac{1}{2a_2} + ... + \frac{1}{2a_k} + \frac{1}{2} = 1$$

$$\frac{1}{2a_1} + \frac{1}{2a_2} + ... + \frac{1}{2a_k} + \frac{1}{3} + \frac{1}{6} = 1$$

F564。一辆汽车沿着半径为 $R$ 的道路拐弯行驶。突然，司机看到路上脏兮兮的人，开始放慢车速。如果车速为$v_0$，车轮与路面的摩擦系数为$k$，并且以最大可能的队形制动，汽车会行驶多远才停下来？

空气柱中的压力等于空气上方液体柱的重量除以管的横截面积。当温度变化时，液柱的高度和密度都会发生变化。但其余余额保持不变。柱的重量将保持不变，因此气压不会改变。因此，$T = 293$ K 和$T_0 = 273$ K 温度下空气柱的体积之比等于相对温度，因此，

$$\frac{l}{l_0} = \frac{T}{T_0}.$$

从这里

$$l = l_0 \frac{T}{T_0} \approx 10.7 \text{ см.}$$

在水平面上作用在汽车上的唯一外力是摩擦力。由于汽车的车轮相对于路面不打滑，这就是静摩擦力。该力赋予汽车一个加速度$\vec{a}$，使得汽车所在点绘制的半径上的投影$\vec{a}$模型等于向心加速度$a_1 = v^2/R$； $\vec{a}$在道路切线上的投影模型为$a_2 = \sqrt{a^2 - a_1^2}$。 “线性”加速度 $\vec{a}_2$ 会降低车速。根据问题的条件，$a_2$保持不变并且是可能的最大值。制动瞬间$a_2 = \sqrt{a^2 - v_0^4/R^2}$。该值在$a = kg$处最大（静摩擦力的最大值$kmg$）。

因此，汽车以恒定的“线性”加速度 $a_2 = \sqrt{(kg)^2 - v_0^4/R^2}$ 减速。汽车到车站行驶的距离$l$等于

$$l = \frac{v_0^2}{2a_2} = \frac{v_0^2 R}{2 \sqrt{(kgR)^2 - v_0^4}}.$$

要找到灯泡释放的功率，您需要确定灯泡两端的电压和流过灯泡的电流。

如果灯泡和阻值$R_2$的电阻两端的电压为$U$，则阻值$R_1$的电阻两端的电压为$U - U$。流过$R_1$的电流为$I_1 = (\mathcal{E} - U)/R_1$；流过$R_2$的电流等于$I_2 = U/R_2$。因此，在灯泡两端电压$U$下流过灯泡的电流等于

$$I = I_1 - I_2 = \frac{\mathcal{E} - U}{R_1} - \frac{U}{R_2} = \frac{\mathcal{E}}{R_1} - U \left( \frac{1}{R_1} + \frac{1}{R_2} \right).$$

仅当值$U$和$I$（相关关系（*））对应于灯泡伏安特性上的点时，灯泡才会点亮。这些值决定了函数$I = 5 - \frac{5}{6} U$（我们用（*）中的数值代替）的图形与灯泡伏安特性的交点。构建了一个图（参见图 1），我们发现：$U \approx 4,8$ B，$I \approx 1$ A。

因此，灯泡释放的功率为

$$P = IU \approx 4,8 \text{ Вт.}$$
