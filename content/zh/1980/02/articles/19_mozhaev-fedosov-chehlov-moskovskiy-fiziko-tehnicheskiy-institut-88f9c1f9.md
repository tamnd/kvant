莫斯科物理技术学院

以下是 1979 年笔试入学考试的公布材料。数学和物理的作业时间为 5 个小时。

Mathematica

选项1
1. 解方程
$$\sqrt{2-x} + \frac{4}{\sqrt{2-x}+3} = 2.$$
2. 解决不平等问题
$$\frac{x-1}{\log_3(9-3^x)} \leq 1.$$
3. 找到方程的所有解
$$\sin(2x - \frac{\pi}{4}) = \sqrt{2}\sin^2x,$$
满足不平等
$$\log_{\cos^23}(1 + \sin(7x+5)) < \sin 8x.$$
4. 锐角三角形 ABC 的高 AM 和 CN 的延长线与其外接圆相交于点 P 和 Q。如果 $|AC| = a, |PQ| = \frac{6}{5}a.$，则求外接圆的半径
5. 在terrada ABCD中，边AB和BD处的两个角是直角，$\widehat{ACD} = a$。圆锥体的顶部与地形的顶部之一重合，圆锥体底部的圆内切于边界之一。求圆锥体轴向截面的角度。
6. N点位于一条河流的岸边，河流的宽度为1公里，水流的速度为1公里/小时。 M点位于对岸下游至少3公里处。渔夫离开M点，以4公里/小时的速度沿着海岸向N点走去。在适当的时候，一艘承运人乘船从 N 点出发，过河，抓住渔夫，将他运送到 N 点。船沿直线来回移动，并选择移动方向，以便从出发到返回的时间尽可能短，等于 $\frac{9}{8}$ 小时。船在静水中的速度为 4 公里/小时。求 M 点和 N 点之间的距离（下游）。

选项2
1. 解决不平等问题
$$0,4^x - 2,5^{x+1} > 1,5.$$
2. 求解方程组
$$\begin{cases} \log_2y = \log_4(xy - 2), \\ \log_9x^2 + \log_3(x-y) = 1. \end{cases}$$
3. 通过直梯形 $ABCD$ ($\widehat{A} = \widehat{B} = \frac{\pi}{2}$) 的顶点 A、B、C 画的半径为 R 的圆，与线段 AD 和 CD 分别相交于点 M 和 N，使得$|AM|:|AD| = |CN|:|CD| = 1:3$。求梯形的面积。
4. 解方程
$$\sin x + \sin^2x + \cos^3x = 0.$$
5. 两列火车同时从 A 点和 B 点出发前往对方。他们每个人首先匀加速运动（火车的初始速度为零），然后，当它们达到一定速度时，匀速运动。列车匀速运动的速比为$\frac{4}{3}$。相遇时刻，两列列车速度相等，大致同时到达B点和A点。求火车加速度之比。
6. 右平行六面体$ABCDA_1B_1C_1D_1$的底是正方形ABCD。求直线 BD$_1$ 与平面 BDC$_1$ 之间最大可能的角度。

选项2

1. 由于作用核和氚相互作用，形成了凝胶核和中子：$^2\text{H} + ^3\text{H} = ^4\text{He} + n$。这会释放大量能量。中子携带什么部分？与释放的能量相比，反应前的作用和氚的动能可以忽略不计。

2. 体积为 $V_0 = 60$ cm$^3$ 的激光管必须填充摩尔比为 5:1 的凝胶和氖气混合物，总压力为 $p_0 = 6$ mmHg。艺术。这些气体有分，每份体积为$V_C = 2$升。凝胶球囊内的压力$p_1 = 50$ mmHg。艺术，霓虹灯 - $p_2 = 200$ 毫米汞柱。艺术。可以填充多少管？

3. 容量为$C$的充电电容器通过开关$K$连接到两个电感为$L_1$和$L_2$（图4）的并联线圈。在最初的时刻，钥匙是打开的。如果关闭钥匙$K$，线圈将消耗电流。已知流过电感$L_1$的线圈的最大电流等于$I_1$。求电容器的初始电荷。忽略线圈的欧姆电阻。

4. 一束细细的光线 (图 5) 垂直于其表面落在玻璃楔上。玻璃假设指示器$n = 1,41$，角度$\alpha = 10^\circ$。在楔子后面的屏幕上可以看到多少个亮点？

选项3

1. 一天的长度是多少时，地球赤道上的物体重量是极地物体的一半？地球半径为$R = 6400$公里。

2. 装有放射性药物$^{24}\text{Na}$（半衰期$\tau_{1/2} = 15$小时）的安瓿通过气流冷却。空气实验开始时，冷却空气会升温$\Delta t_0 = 2^\circ\text{C}$。什么时间后冷却空气会升温$\Delta t_1 = 1,8^\circ\text{C}$？

3. 静止带电部分（质子）位于放置在真空中的扁平电容器的极板之间。直接新形状 (图 6) 的方向 $U_c(t)$ 应用于电容器。如果已知粒子在 $\tau = 10^{-6}$ s 时间内移动了距离 $3/8L$，其中 $L$ 是电容器板之间的距离 $L = 5$ cm，则确定方向 $U_0$ 的幅度和粒子撞击电容器板时的能量 $E$。质子的质量为 $m_p = 1,67 \cdot 10^{-24}$ g，电荷为 $e = 1,6 \cdot 10^{-19}$ Cl。

4. 在直径为 $2R = 4$ 厘米的薄壁玻璃球中，可以看到蜡烛火焰的两个图像，这是由球的近壁和远壁反射引起的。图片尺寸参考19/21。确定球中心和蜡烛之间的距离。
