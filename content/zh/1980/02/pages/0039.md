M553。给定一个三角形 ABC 和 $|BC| < |AC| < |AB|$。在卫星 BA 和 CA 上，还沉积了 BD 和 CE 段，即 $|BD| = |CE| = |BC|$。证明三角形ADE的外接圆半径等于三角形ABC的外接圆圆心与其外接圆之间的距离。

设$O$为三角形ABC的外接圆圆心，$O_1$为三角形ADE的外接圆圆心，$K$为$\triangle ABC$的外接圆圆心（见图）。我们需要证明$|KO| = |O_1A|$。

让$|BC| = |BD| = |CE| = a, |AC| = b, |AB| = c$。

考虑一个圆心位于点 $K$ 、半径为 $|KO|$ 的圆。我们来画和弦 $[OM] \parallel [AC]$ 和 $[ON] \parallel [AB]$。让我们证明顶点 $O$ 和 $A$ 的角全等的三角形 OMN 和 ADE 是全等的。

让我们从中心$O$和$K$垂线$OO'$和$KK'$下降到边$AB(L = [ON] \cap [KK'])$。很容易检查

$$|AK'| = \frac{a+b+c}{2} - a = \frac{b+c-a}{2},$$

$$|O'K'| = |AK'| - |AO'| = \frac{b+c-a}{2} - \frac{c}{2} = \frac{b-a}{2},$$

$$|ON| = 2|OL| = 2|O'K'| = b - a = |AE|.$$

类似地可以证明$|OM| = |AD|$。

因此，三角形 OMN 和 ADE 的两边和它们之间的角度相等。因此$|KO| = |O_1A|$。

M554。如果还有自然数 $a_1, a_2, ..., a_k$（不一定不同），那么自然数 $n$ 是好的，这样

$$a_1 + a_2 + ... + a_k = n$$

众所周知，从33到73都是好数字。证明所有大于 73 的数字也是好的。

问题的陈述立即来自两个引理：

1°。如果数字 $n$ 是好的，那么 $u$ $2n + 2$ 也是好的；
2°。如果数字 $n$ 是好的，那么 $u$ $2n + 9$ 也是好的。

让我们证明它们。

来自平等

$$n = a_1 + a_2 + ... + a_k,$$

$$\frac{1}{a_1} + \frac{1}{a_2} + ... + \frac{1}{a_k} = 1$$

应该

$$2n + 2 = 2a_1 + 2a_2 + ... + 2a_k + 2,$$

$$\frac{1}{2a_1} + \frac{1}{2a_2} + ... + \frac{1}{2a_k} + \frac{1}{2} = 1$$

——从而证明$1^\circ$；

$$2n + 9 = 2a_1 + 2a_2 + ... + 2a_k + 3 + 6,$$

$$\frac{1}{2a_1} + \frac{1}{2a_2} + ... + \frac{1}{2a_k} + \frac{1}{3} + \frac{1}{6} = 1$$

——从而证明$2^\circ$。

使用$1^\circ$和$2^\circ$，非常强的归纳法（从$2 \cdot 36 + 2 = 74$开始表示偶数$n$，从$2 \cdot 33 + 9 = 75$开始表示奇数$n$），我们证明任何大于73的数字都是好的，特别是检查条件中表达的前提的正确性。可以很容易地证明$k^2$总是一个好数，并且如果$m$和$n$是一个好数，那么$mn$也是一个好数。
