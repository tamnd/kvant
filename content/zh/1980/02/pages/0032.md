我们光束：

$$a_n + c_n \sqrt{2} = (2 + \sqrt{2})^{n-1} (a_1 + c_1 \sqrt{2}) = (2 + \sqrt{2})^n;$$

$$a_n - c_n \sqrt{2} = (2 - \sqrt{2})^{n-1} (a_1 - c_1 \sqrt{2}) = (2 - \sqrt{2})^n.$$

因此$c_n = [(2 + \sqrt{2}) - (2 - \sqrt{2})^n] : 2\sqrt{2}$，从$e_{2n} = 2c_{n-1}$开始，我们最终得到

$$e_{2n} = [(2 + \sqrt{2})^{n-1} - (2 - \sqrt{2})^{n-1}] / \sqrt{2}; \quad e_{2n-1} = 0.$$

解决问题。只是不清楚在这个问题（以及之前的问题 6）中如何能够得出包含 $\pm \sqrt{2}$ 的公式 - 在解决问题中我们讨论的是整数！ （对于奥林匹克竞赛参与者和读者«Kvant»，任务 7 变得更容易，因为措辞表明了答案 - «Kvant»，1979，第 11 号，M595）。

然而，如果我们知道线性代数的开始（参见[12]）并应用这门科学的标准规则来求解方程（7），“共轭数”就会完全自动出现。这些规则建议首先找出哪些几何级数（$a_n = a_0 \lambda^n$，$c_n = c_0 \lambda^n$）满足给定的递推关系。也存在级数的值 - 它们称为特征值或特征值 - 由某个方程确定（也称为特征）。对于(7)，特征方程的形式为$\lambda^2 + 2 - 4\lambda = 0$，其根就是$2 + \sqrt{2}$和$2 - \sqrt{2}$。考虑到这些根，我们可以获得递推关系的任何解作为相应几何级数的“线性组合”（[11]）。 “初始条件”（在我们的例子中为$a_1 = 2$，$c_1 = 1$）唯一地决定了我们需要的解决方案。

即使是最简单的循环整数序列，其特征方程是具有整数系数的二次方程（示例与 (6) 和 (7) 或斐波那契序列 1, 1, 2, 3, 5, 8,..., $\Phi_{n+1} = \Phi_n + \Phi_{n-1}$ - 参见 [9], [10]），也可以使用“排列的”方形虹膜表示为数字的函数，这是不可改变的。

请注意，大的特征数决定了序列的增长率：对于问题$7e_n \approx (2 + \sqrt{2})^n / \sqrt{2}$中的大$n$。你也可以这样说：$\lim_{n \to \infty} (e_{n+1}/e_n) = 2 + \sqrt{2}$。

对于问题 6，我们看到类似的情况：

$$\lim_{n \to \infty} (x_n/y_n) = \sqrt{2}$$ - 表明大 $n$ 的数字 $x_n$ 和 $y_n$ 实际上彼此相等。我们在下面的问题中看到了这一事实的有趣延伸，其中包含大量“共轭”化。

我们把所有的标志都一一改变

8（M520）。设$(1 + \sqrt{2} \Phi' \sqrt{3})^n = q_n + r_n \sqrt{2} + s_n \sqrt{3} + t_n \sqrt{6}$，其中$q_n, r_n, s_n$和$t_n$为整数。求极限 $\lim_{n \to \infty} r_n/q_n$、$\lim_{n \to \infty} s_n/q_n$、$\lim_{n \to \infty} t_n/q_n$。

当然，这里我们可以用$(q_n; r_n; s_n; t_n)$来表达$(q_{n+1}; r_{n+1}; s_{n+1}; t_{n+1})$，从而得到$q_{n+1} + r_{n+1} \sqrt{2} + s_{n+1} \sqrt{3} + t_{n+1} \sqrt{6} = (1 + \sqrt{2} + \sqrt{3}) (q_n + r_n \sqrt{2} + s_n \sqrt{3} + t_n \sqrt{6}) = (1 + \sqrt{2} + 3)^n$。

不难判断其他人会是什么样子。让我们与这个数字$\lambda_1 = 1 + \sqrt{2} + \sqrt{3}$一起考虑另外三个“排列”的数字：$\lambda_2 = 1 - \sqrt{2} + \sqrt{3}$、$\lambda_3 = 1 + \sqrt{2} - \sqrt{3}$、$\lambda_4 = 1 - \sqrt{2} - \sqrt{3}$。

我们可以用 $\lambda_1, \lambda_2, \lambda_3, \lambda_4$ 来表示 $q_n, r_n, s_n, t_n$：

$$q_n = (\lambda_1^2 + \lambda_2^2 + \lambda_3^2 + \lambda_4^2) / 4,$$

$$r_n = (\lambda_1^2 - \lambda_2^2 + \lambda_3^2 - \lambda_4^2) / 4\sqrt{2},$$

$$s_n = (\lambda_1^2 + \lambda_2^2 - \lambda_3^2 - \lambda_4^2) / 4\sqrt{3},$$

$$t_n = (\lambda_1^2 - \lambda_2^2 - \lambda_3^2 + \lambda_4^2) / 4\sqrt{6}.$$

现在注意$\lambda_1 > |\lambda_2|$，$\lambda_1 > |\lambda_4|$。让我们考虑一下$\lim_{n \to \infty} r_n/q_n = \lim_{n \to \infty} s_n/q_n = 1/\sqrt{6}$。

我们上面说过，共轭数 $a \pm b\sqrt{d}$ 是作为具有整数系数的二次方程的根出现的。与最后一个任务相关，这个愿望是：

9. 写出一个具有整数系数的方程，其根等于 $1 + \sqrt{2} + \sqrt{3}$。

人们怀疑，除了这个数字$λ_1$之外，具有整数系数的方程也满足共轭，在上一个问题的解决方案中，我们将其表示为$\lambda_2, \lambda_3, \lambda_4$。所需的方程可以写成如下：

$$(x - \lambda_1)(x - \lambda_2)(x - \lambda_3)(x - \lambda_4) = 0;$$

那是

$$(x - 1 - \sqrt{2} - \sqrt{3})(x - 1 + \sqrt{2} - \sqrt{3}) \times (x - 1 - \sqrt{2} + \sqrt{3}) \times (x - 1 + \sqrt{2} + \sqrt{3}) = 0;$$
