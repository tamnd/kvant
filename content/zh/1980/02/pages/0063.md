从$N$到$K$。然后$v_x = \frac{x}{T_1}, v_y = \frac{1}{T_1}$，因此$v_{cx} = \frac{x}{T_1} - 1, v_{cy} = \frac{1}{T_1}$。但是$v_{cx}^2 + v_{cy}^2 = v_1^2 = 16$；因此$\left(\frac{x}{T_1} - 1\right)^2 + \frac{1}{T_1^2} = 16$，从哪里

$$T_1 = \frac{-x + \sqrt{16x^2 + 15}}{15}.$$

考虑到船从点$K$到点$N$的运动，我们同样可以找到该运动的时间$T_2$：

$$T_2 = \frac{x + \sqrt{16x^2 + 15}}{15}.$$

鱼从$M$点移动到$K$点的时间$T_3$是$\frac{a-x}{4}$。根据条件$T_1 < T_3$。该不等式的解集是积分 $]x_1; x_2[$，其中 $x_{1,2} = \frac{-11a + 4\sqrt{16a^2 - 9}}{9}$。

请注意，$x_1 < 0$ 和$x_2 = \frac{-11a + 4\sqrt{16a^2 - 9}}{9} > 1$ 因为$a \geq 3$。

对于$x \in ]x_1; x_2[$，从离开船到返回船的时间$T(x)$由公式$T(x) = T_2 + T_3$确定。

找到函数$T; x_0 = \frac{11}{12}$的临界点。所以，$x_0 \in ]x_1; x_2[$。由于 $x < x_0$ 为 $T'(x) < 0$，$x > x_0$ 为 $T'(x) > 0$，因此 $T(x_0)$ 是函数 $T$ 在积分 $]x_1; x_2[$ 上的最小值。因此，$T(x_0) = \frac{9}{8}$，因此$a = \frac{15}{4}$。
