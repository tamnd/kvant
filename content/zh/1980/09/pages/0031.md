一些收缩映射$f$：
对自身的积分$|a; b| \rightarrow |a; b|$有一个不动点。

固定点的单壁性是显而易见的：如果有两个固定点，那么它们之间的距离应该改变（根据条件（3）），而实际上它保持不变（因为点本身不移动）。

存在性证明基于一种简单但重要的积分方法：取任意点 $x_0 \in |a; b|$ 并对其重复应用 $f$：

$$x_0, x_1 = f(x_0), x_2 = f(x_1), \dots, x_n = f(x_{n-1}), \dots$$

那么序列 $x_1, x_2, \dots, x_n$ ... 收敛到使用不动点。

在证明这个方法的合理性（即完成定理的证明）之前，我们用一个简单的例子来说明：

令 $f: ] - 1; 1[ \rightarrow ] - 1; 1[$ 为$f(x) = \dot{x}^2$ (图 1) 给出的映射。让我们以点$x_0 = 0,1$为例。然后

$$x_1 = (0,1)^2 = 0,01,$$
$$x_2 = (0,01)^2 = 0,0001,$$

显然$\lim_{k \to \infty} x_k = 0$。点 0 确实静止，即 $0^2 = 0$。

（顺便说一句，我们是这样解方程$x^2 - x = 0, x \ni 1$;1[]的）。

回到定理的证明，我们用$(x_n)$表示序列(4)。让我们证明这个序列具有以下属性。

(K) 对于任何 $\varepsilon > 0$ ，都存在一个数 $n_0$ ，使得对于所有大数 $n, m > n_0$ 不等式

$$d(x_n, m) < \varepsilon.$$

换句话说，序列中具有足够大数量的点是任意接近的。

为了证明这一点，我们应用不等式 (3) $k$ 次；我们得到

$$d(x_k, x_{k+1}) \leq \alpha^{k-1} d(x_1, x_2).$$

因为

$$d(x_n, x_{n+p}) \leq d(x_n, x_{n+1}) + d(x_{n+1}, x_{n+2}) + \dots + d(x_{n+p-1}, x_{n+p}) \leq \alpha^{n-1} + \alpha^n + \dots + \alpha^{n+p-2} d(x_1, x_n) = \frac{\alpha^{n-1}(1-\alpha)^p}{1-\alpha} d(x_1, x_n) \leq \frac{\alpha^{n-1}}{1-\alpha} d(x_1, x_2).$$

现在对于任何给定的$\varepsilon > 0$，我们可以将其视为$n_0$

$$n_0 = \log_a \frac{\varepsilon(1-\alpha)}{d(x_1, x_2)}.$$
