奥夫钦尼科夫

当开关闭合时，电容器$C_1$与线圈组成电容电路；线圈和电容器两端的电压根据谐波定律随时间变化：

$$u = U_1 \sin \omega_1 t,$$

其中$\omega_1 = 1/\sqrt{LC_1}$是凝结频率，$U_1$是振幅。该电路中的周期$T_1$电容器电压（和电流）等于$2\pi/\omega_1 = 2\pi/\sqrt{LC_1}$。因此，电压$u$在时间$t_1 = T_1/2 = \pi/\sqrt{LC_1}$变为零。此时，电路中的电流最大，电路的所有能量都包含在线圈的磁场中。

当与电容器$C_1$串联的开关打开时，电容器$C_2$导通，形成电感$L$和电容$C = \frac{C_1 C_2}{C_1 + C_2}$的电容电路。这种电路中线圈上的电压按规律变化

$$u = U_2 \sin \omega_2 (t - t_1),$$

其中$\omega_2 = 1/\sqrt{LC} = \sqrt{\frac{C_1 + C_2}{LC_1 C_2}}$。通过凝结期的阵雨，即时刻，电压变为零

$$t_2 = t_1 + \frac{T_2}{2} = \pi \left( \sqrt{LC_1} + \sqrt{L \frac{C_1 C_2}{C_1 + C_2}} \right).$$

然后钥匙闭合，线圈上的电压又按规律变化（*）。

让我们找到 $U_1$ 和 $U_2$ 之间的对应关系。当电容器上的电压最大时，电路中的电流为零，所有能量都集中在电容器的功率场中。因此，根据能量守恒定律

$$\frac{C_1 U_1^2}{2} = \frac{CU_2^2}{2},$$

在哪里

$$U_2 = U_1 \sqrt{\frac{C_1}{C}} = U_1 \sqrt{1 + \frac{C_1}{C}}.$$

现在绘制电感器两端的电压与时间的关系并不困难。它显示在图2。
