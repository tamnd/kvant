⟦folio 59⟧

任务 7. 三位数或四位数素数的数字是否构成具有正差的等差数列？如果是modum，但也找到所有数字。

解决方案。假设一个数的数字组成一个等差数列。

对于三位数来说，$x, x+d, x+2d$的数字之和等于$S = x + (x+d) + (x+2d) = 3x + 3d$，并且能被3整除，也就是说，这些数字组成的数能被3整除，不能是素数。

对于四位数字，$x, x+d, x+2d, x+3d$的数字之和等于
$$x + x + d + x + 2d + x + 3d = 2(2x + 3d).$$

$x$不能等于3，因为这样我们会得到一个能被3整除的数字。由于$x + 3d$是一个数字，所以$x + 3d \leqslant 9$和$d$可以等于2或1。

让$d = 2$。然后$x \leqslant 3$； $x = 3$不适合； $x = 2$ 也不合适，因为结果是偶数；有了 $x = 1$，我们得到合数 1357。

让$d = 1$。考虑数字 1234、2345、...、6789，我们在其中找到一个质数 4567。

问题概率

1. 第一个盒子包含 50 个白球，第二个盒子包含 10 个白球和 10 个黑球。有人从任意盒子中取出一个球。他拿的球是白球的概率是多少？学生在解这道题时说：“既然有60个白球，10个黑球，那么所需的概率就是6/7。”这是真的吗？

2. （帕斯卡问题）。两个技能相同的玩家进行一场没有结果的游戏。他们进行等额投注，条件是10场比赛获胜次数相同的一方将获得全部奖金。比赛以9:8翻盘，无法继续进行。他们应该如何分配这笔钱？

3. 据了解，neokot一家有两个孩子，其中一个是男孩。哪个更有可能：第二个孩子是男孩还是女孩？

4. 球的数量不受限制：一个球为 1 号球，另一个球为 2 号球，第三个球为 3 号球，依此类推。玩家 $A$ 和 $B$ 一次拿一个球并查看它们的数字。获得数字较小的球的人获胜。

让我们看看玩家$A$获胜的机会是多少。假设他减去了球号$k$。由于小于 $k$ 的数字有有限个，大于 $k$ 的数字有无限多个，因此$A$ 获胜的可能性比失败的可能性大得多。但由于对于玩家$B$可以证明同样的推理，我们得出的结论是每个玩家都比其他玩家有显着的优势。为什么会发生这种情况？
