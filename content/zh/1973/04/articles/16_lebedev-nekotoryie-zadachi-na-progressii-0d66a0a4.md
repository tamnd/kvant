⟦folio 57⟧

一些进展任务

V·P·列别杰夫

本文提出了特征定理并分析了为高级大学考试提出的进展问题。

渐进的两个主要属性

一、在算术级数中，它的每一项（除了第一项和最后一项）乘以二，都等于一系列常数之和，即
$$2a_k = a_{k-1} + a_{k+1}.$$
反之亦然：如果在一个数字序列中，每个成员（第一个和最后一个除外）乘以 2，等于一系列常量的总和，则该序列是一个算术级数。

证明。根据等差数列$a_k = a_{k-1} + d$和$a_k = a_{k+1} - d$的定义，将这些表达式相加，我们得到$2a_k = a_{k-1} + a_{k+1}$。相反，让$2a_k = a_{k-1} + a_{k+1}$，然后$a_{k+1} - a_k = a_k - a_{k-1}$。

将$k = 2, 3, \dots$代入最后一个等式，并用$d$表示$a_2 - a_1$，我们得到
$$d = a_2 - a_1 = a_3 - a_2 = \dots = a_{k+1} - a_k = \dots$$
根据定义，这意味着 $a_1, a_2, \dots$ 是一个算术级数。

二.在几何级数中，其任何一项（除了第一项和最后一项）的平方等于其相邻项的乘积，即
$$b_k^2 = b_{k-1}b_{k+1}.$$

相反，如果在一个数字序列中，每个数字（除了第一个和最后一个）的平方等于一系列常数的乘积，那么这个序列就是几何级数。

这些陈述的证明是独立的。

任务及其解决方案

任务 1. 找到一个等差级数，其中前 n 项之和等于 $n^2$。

解决方案。使用算术级数项之和的公式，我们发现对于任何 n 等式
$$S_n = \left[ \frac{2a_1 + d(n-1)}{2} \right]n = n^2.$$
从这里
$$d = \frac{2(n-a_1)}{n-1}.$$
对于 $a_1 = 1$，该表达式不仅仅依赖于 n。这意味着在独占级数 $a_1 = 1$、$d = 2$ 中，级数的形式为 1, 3, 5, 7,...

否则可以得到相同的结果：
$$a_n = S_n - S_{n-1} = n^2 - (n-1)^2 = 2n - 1.$$
任务 2. 数字 1、$\sqrt{3}$、3 是同一个等差数列的余数吗？

解决方案。这些数字形成一个等差数列，其中有 $1 = a_m$、$\sqrt{3} = a_n$ 和 $3 = a_p$。然后
$$1 = a_1 + (m-1)d,$$
$$\sqrt{3} = a_1 + (n-1)d,$$
$$3 = a_1 + (p-1)d.$$
从这里
$$a_1 = 1 - (m-1)d = \sqrt{3} - (n-1)d = 3 - (p-1)d,$$
$$\sqrt{3} = 1 + (n-m)d,$$
$$3 = 1 + (p-m)d.$$

求解 $d$ 的最后一个等式，我们得到

$$\frac{n - m}{p - m} = \frac{\sqrt{3} - 1}{2},$$

这是不可能的，因为右边的数是有理数，而右边的数是无理数。

问题3. 在什么条件下，$a$、$b$、$c$是一个等差数列的整数？

解决方案。设$\{a_i\}$为原始级数，$a = a_m$、$b = a_k$和$c = a_p$。然后是$a = a_1 + d(m - 1)$、$b = a_1 + d(k - 1)$和$c = a_1 + d(p - 1)$。让我们从这些等式中排除 $a_1$：

$$a - b = d(m - k)$$
$$b - c = d(k - p).$$

将这些等式逐项相除，我们得到

$$\frac{a - b}{b - c} = \frac{m - k}{k - p}.$$

由于数字$m$、$k$和$p$是整数，因此$\frac{a - b}{b - c}$一定是有理数。

很容易检查，如果$\frac{a - b}{b - c} = \frac{s}{t}$，其中$s$和$t$是整数，那么我们可以找到包含项$a$，$b$，$c$的算术级数（证明！）。

问题4. 证明在等比级数$c$正整数的每两个连续项之间，我们可以留下$k$数，使得整个数列形成等比级数。

解决方案。让我们用 $a$、$b$、$c$、...、$n$、... 表示级数的项。我们通过第一项 $a$ 和第 $(k + 2)$ $b$ 确定原始级数 $q$ 的分母（必须提供$k$ 项）：

$$b = aq^{k + 1},$$

从哪里$q = \sqrt[k + 1]{\frac{b}{a}}$。该序列将如下所示

$$a, a \sqrt[k + 1]{\frac{b}{a}}, a \sqrt[k + 1]{\left(\frac{b}{a}\right)^2}, \dots, b.$$

在数字 $b$ 和 $c$ 之间还存在 $k$ 项，以便与值 $\sqrt[k + 1]{\frac{c}{b}}$ 形成几何级数，依此类推。

根据任务条件

$$\frac{b}{a} = \frac{c}{b},$$

这意味着整个序列将形成一个等比级数，值为$\sqrt[k + 1]{\frac{c}{b}}$，依此类推。

问题 5. 求等比级数的分母，其中从第二项开始的每一项都等于两个相邻项（下一项和上一项）的差。

解决方案。令级数的形式为$b_1, qb_1, q^2b_1, \dots$。

来自平等

$$q^{n + 2}b_1 - q^n b_1 = q^{n + 1}b_1$$

我们发现

$$q^2 - q - 1 = 0,$$

在哪里

$$q = \frac{1 \pm \sqrt{5}}{2}.$$

问题 6. 找出算术级数的三个连续项的平方是几何级数的直接连续项的条件。

解决方案。令 $a, a + d, a + 2d$ 为算术级数的连续三项。如果这些数字的平方构成等比级数，那么

$$(a + d)^4 = a^2 (a + 2d)^2,$$

在哪里

$$(a + d)^2 = \pm a (a + 2d).$$

如果$(a + d)^2 = a (a + 2d)$，则$d = 0$。

如果$(a + d)^2 = -a (a + 2d)$，则$d = a (-2 \pm \sqrt{2})$。

所以，要么$d = 0$，要么$d = a (-2 \pm \sqrt{2})$。
