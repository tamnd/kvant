⟦folio 39⟧

包含给定方程的所有整数解。

给参数$t$值$t = 0, 1, 2, \dots, 66$，我们找到这个方程的67对可能的自然根。

现在让我们进一步假设山鲁佐德希望在尽可能多的夜晚中传播她的一千零一个故事*)。这个要求可以通过 max $(x + y)$ 来满足，它是方程根对中最大的和。我们有$x + y = 333 - 2t$；显然，最大$(x + y)$在$t = 0$处实现。

因此，如果她在 332 个晚上讲 3 个故事，而只在 1 个晚上讲 5 个故事，那么山鲁佐德最多会讲 333 个晚上的故事。她可以缩短她的“工作”时间，把它变成201个晚上，只要2次（以一个有创造力的小学生的最大能力），你就得到了$x + y + \frac{4y - 1}{3} = 77$。现在我们应该如何计算和行动才能首先表达该方法$y$，然后通过整个$t$表达$x$？

使用“有创造力的数学家”的方法的解决方案**）

对于方程$ax + by = c$，过程如下：求$a$除以$b$（设$a > b$）时的余数$m$，以及$c$除以$b$时的余数$n$；如果$n = 0$，那么我们立即得到$x = bt$，$y = \frac{c}{b} - at$，$t = 0, \pm 1, \pm 2, \dots$；

*）当然，前提是她每天晚上讲三到五个童话故事。
**) 该方法的发明者 Taylor L. F.，“Numbers”，伦敦，1970 年，没有给它命名。

如果$n \neq 0$，则将$m$依次乘以1、2、...、$(b - 1)$，并记下这些乘积除以$b$所得的余数序列。生成的序列将包含数字 $n$（如果不存在，则方程将没有整数解）。残基序列中数字$n$占据的位置数是可能值$x$之一。

让我们将此方法应用于方程 $5x + 3y = 1001$。我们有：$m = 2$，$n = 2$，将$m = 2$乘以序列{1;的每个成员； 2}，我们得到{2; 4}；除以 3 并写出余数：{2; 1}。我们注意到数字$n = 2$占据了这个余数序列中的第一个位置，因此$x = 1$。这确定了相应的值$y = 332$。

一种简单且相当通用的方法来求解两个未知数的线性不定方程以用于数字目的！

但与之前的方法不同，“发明数学家的方法”只给了我们一对根：(1; 332)。方法缺陷？一点也不。考虑“通过小学生方法”获得的问题的“通解”公式：$x = 1 + 3t$，$y = 332 - 5t$。

《特解》$x_0 = 1, y_0 = 332$与一般方法相同，$t$（3和5）的系数由方程：$3 = b; -5 = -a$的解的系数确定。这不是巧合，而是一种模式：如果$(x_0, y_0)$是方程$ax + by = c$的任意整数解，并且$a$和$b$互质，那么它的所有整数解都由公式确定：$x = x_0 + bt$、$y = y_0 - at$、$t = 0, \pm 1, \pm 2, \dots$。
