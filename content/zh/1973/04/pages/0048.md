M156。在矩形ABCD中，点M是边AD的中点，N是边BC的中点。在线段 DC 的延续上，将点 D 取为点 P。用 Q 表示直线 PM 和 AC 的交点。证明 QNM = MNP。

该问题有许多简单的几何解。这是其中之一。

令 O 为矩形的中心（见 图 1）（MN 与 AC 的交点），K 为 QN 与线段 MN 中点 O 的垂线的交点。那么，很容易看出，QM/MP = QO/OC = QK/KN，因此 MK||PN。但三角形 MKN 是等边的：根据构造，KO 既有高度又有中线。姿势 QNM = KMN = MNP。

利用计算来解决这个问题并不困难。例如，您可以使用坐标方法。如果引入图2所示的坐标系，则Q点的$(x_0, y_0)$坐标满足两个方程：

$(p - 2b)x - ay = -2ab$（MP线方程）和$bx + ay = ab$（CA线方程）。

将第二个方程乘以 2，然后将其添加到第一个方程中。我们得到（$x = x_0, y = y_0$）$px_0 + ay_0 = 0$。因此，直线NQ的斜率等于$\frac{y_0}{x_0} = -\frac{p}{a}$，

M157。 n 个正数$x_1, x_2, x_3, \dots, x_n$之和等于1。设S为最大的数

$$\frac{x_1}{1+x_1}, \frac{x_2}{1+x_1+x_2}, \dots, \frac{x_n}{1+x_1+x_2+\dots+x_n}.$$

找到S的最小可能值。在$x_1, x_2, \dots, x_n$的值是多少？

假设正数 $a_1, a_2, \dots, a_n$ 使得 $a_1 + a_2 + \dots + a_n = 1$ 和

$$\frac{a_1}{1+a_1} = \frac{a_2}{1+a_1+a_2} = \dots = \frac{a_n}{1+a_1+a_2+\dots+a_n}.$$

（我们将在下面看到这样一个集合$a_1, a_2, \dots, a_n$实际上存在。）让我们证明对于$x_1 = a_1, x_2 = a_2, \dots, x_n = a_n$，值S取最小的可能值。令 $b_1, b_2, \dots, b_n$ 为另一组正数，其总和等于 1。请注意，如果 $x_k$ 增加，并且之前的所有 $(x_1, x_2, \dots, x_k-1)$ 均未增加，则数量

$$\frac{x_k}{1+x_1+\dots+x_{k-1}+x_k} = \frac{1}{\frac{1}{x_k}+\frac{x_1}{x_k}+\dots+\frac{x_{k-1}}{x_k}+1} = \frac{1}{1+x_1+\dots+x_{k-1}+x_k} + 1$$

会增加。

波兹尼，如果$b_1 > a_1$，则$\frac{b_1}{1+b_1} > \frac{a_1}{1+a_1}$；如果$b_1 \leq a_1, b_2 > a_2$，则$\frac{b_2}{1+b_1+b_2} > \frac{a_2}{1+a_1+a_2} = \frac{a_1}{1+a_1}$；如果$b_1 \leq a_1, b_2 \leq a_2, b_3 > a_3$，则$\frac{b_3}{1+b_1+b_2+b_3} > \frac{a_3}{1+a_1+a_2+a_3} = \frac{a_1}{1+a_1+a_2+a_3}$，依此类推。由于数字集合$b_1, b_2, \dots, b_n$与集合$a_1, a_2, \dots, a_n$不同，并且公共集合中的数字之和
