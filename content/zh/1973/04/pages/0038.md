角度。由于每个矩形不小于$\sqrt{2} - x$，且其高度之和等于$h - x$，则所有矩形的面积之和不小于$(\sqrt{2} - x)(h - x)$，因此，所有正方形的面积之和不小于$x^2 + (\sqrt{2} - x)(h - x)$。

但根据条件，它们的面积之和等于1。所以，

$$x^2 + (\sqrt{2} - x)(h - x) \leq 1,$$

在哪里

$$h \leq \frac{1 - x^2}{\sqrt{2} - x} + x = \sqrt{2} \left[ 3 - \left( y + \frac{1}{y} \right) \right],$$

在哪里

$$y = 2 - x \sqrt{2}.$$

因此，对于任何$y$、$h \leq \sqrt{2}$，括号中的数量$y + 1/y$不小于2。

第二个解决方案。如果在第一个解决方案中，描述平方距离的方法非常容易，而主要困难是证明所需的估计，那么在第二个解决方案中，相反，很难描述包装方法（并且估计将几乎是估计的）。一些读者建议对下面的包装进行准确的描述。

我们将在这里描述一种包装完美正式的方式。 “算法”的描述——我们建议打包方块的指令——包含在下一段中。完成上述操作$k$次后，首先将$\sqrt{2} \times \sqrt{2}$正方形放置在$k$正方形之上（我们仍然假设它们按边数降序排列），而其余的$\sqrt{2} \times \sqrt{2}$正方形则分为$(k + 1)$矩形，并为其分配一定的编号（从0到$k$）。一些矩形被声明为“闭合”（意味着不会再向其中插入任何正方形），而另一些则被声明为“开放”（任何开放矩形都适合 $(k + 1)$ 正方形）。首先，“0号矩形”声明整个正方形$\sqrt{2} \times \sqrt{2}$。因此，放置正方形的算法：

$$k - \text{шаг} (k = 1, 2, 3, \dots).$$

从所有未闭合的矩形中，我们选择数字最大的一个。 （令这个数字为$m$）。我们将第 $k$ 个正方形放在它的角落里。我们继续将这个正方形的边与矩形$m$的较小边平行（如果矩形的边相等，则选择其中任何一个），这样矩形$m$未被正方形$k$占据的部分就被分成两个矩形。在这两个矩形中，我们将数字$k$分配给与正方形$k$一起组成矩形的那个，而数字$m$现在保留给“前”矩形$m$（图4）的其余部分。除矩形 $m$ 和 $k$ 之外，所有正方形和矩形均保留旧数字。如果我们放置的第$k$正方形不是最后一个，那么我们检查第$(k + 1)$正方形是否适合矩形$k$和矩形$m$，如果不适合，则我们声明相应的矩形（或两者）关闭。
