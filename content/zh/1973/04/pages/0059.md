⟦folio 57⟧

一些进展任务

V·P·列别杰夫

本文提出了特征定理并分析了为高级大学考试提出的进展问题。

渐进的两个主要属性

一、在算术级数中，它的每一项（除了第一项和最后一项）乘以二，都等于一系列常数之和，即
$$2a_k = a_{k-1} + a_{k+1}.$$
反之亦然：如果在一个数字序列中，每个成员（第一个和最后一个除外）乘以 2，等于一系列常量的总和，则该序列是一个算术级数。

证明。根据等差数列$a_k = a_{k-1} + d$和$a_k = a_{k+1} - d$的定义，将这些表达式相加，我们得到$2a_k = a_{k-1} + a_{k+1}$。相反，让$2a_k = a_{k-1} + a_{k+1}$，然后$a_{k+1} - a_k = a_k - a_{k-1}$。

将$k = 2, 3, \dots$代入最后一个等式，并用$d$表示$a_2 - a_1$，我们得到
$$d = a_2 - a_1 = a_3 - a_2 = \dots = a_{k+1} - a_k = \dots$$
根据定义，这意味着 $a_1, a_2, \dots$ 是一个算术级数。

二.在几何级数中，其任何一项（除了第一项和最后一项）的平方等于其相邻项的乘积，即
$$b_k^2 = b_{k-1}b_{k+1}.$$

相反，如果在一个数字序列中，每个数字（除了第一个和最后一个）的平方等于一系列常数的乘积，那么这个序列就是几何级数。

这些陈述的证明是独立的。

任务及其解决方案

任务 1. 找到一个等差级数，其中前 n 项之和等于 $n^2$。

解决方案。使用算术级数项之和的公式，我们发现对于任何 n 等式
$$S_n = \left[ \frac{2a_1 + d(n-1)}{2} \right]n = n^2.$$
从这里
$$d = \frac{2(n-a_1)}{n-1}.$$
对于 $a_1 = 1$，该表达式不仅仅依赖于 n。这意味着在独占级数 $a_1 = 1$、$d = 2$ 中，级数的形式为 1, 3, 5, 7,...

否则可以得到相同的结果：
$$a_n = S_n - S_{n-1} = n^2 - (n-1)^2 = 2n - 1.$$
任务 2. 数字 1、$\sqrt{3}$、3 是同一个等差数列的余数吗？

解决方案。这些数字形成一个等差数列，其中有 $1 = a_m$、$\sqrt{3} = a_n$ 和 $3 = a_p$。然后
$$1 = a_1 + (m-1)d,$$
$$\sqrt{3} = a_1 + (n-1)d,$$
$$3 = a_1 + (p-1)d.$$
从这里
$$a_1 = 1 - (m-1)d = \sqrt{3} - (n-1)d = 3 - (p-1)d,$$
$$\sqrt{3} = 1 + (n-m)d,$$
$$3 = 1 + (p-m)d.$$
