其中 $m_1, m_2, m_3, \dots$ 是由大于 1 的整数组成的递增序列。让
$$\alpha_k = 0, \underbrace{10 \dots 0}_{m_1-1} \underbrace{10 \dots 0}_{m_2-1} \underbrace{10 \dots 0}_{m_k-1} 1.$$
显然，$\alpha_k$是一个有理数，其值为
$$q_k = 10^{m_1} + \dots + m_k + 1$$
所以呢
$$|\alpha - \alpha_k| = \alpha - \alpha_k = 0, \underbrace{0 \dots 0}_{m_1+ \dots + m_k+m_k+1} 10 \dots < 2 \times 10^{-m_k+1}.$$
现在假设序列 $m_1, m_2, m_3, \dots$ 增长得如此之快，以至于对于任何 $k$ 来说，$m_{k+1} \geq k(m_1+ \dots + m_k+2)$ 都是如此。 （例如，这就是序列 $1^1, 2^2, 3^3, 4^4, \dots$ - 证明它！）然后对于任何 $k$
$$\frac{1}{k q_k^k} = \frac{10^{-k(m_1+ \dots + m_k+1)}}{k} > 10^{-k(m_1+ \dots + m_k+1)} = 10^{-k(m_1+ \dots + m_k+2)} \geq 10^{-m_k+1} > |\alpha - \alpha_k|,$$
因此，如果 $n, N$ 是任意正数且 $k > n, k > N$，则
$$|\alpha - \alpha_k| < \frac{1}{k q_k^k} < \frac{1}{N q_k^n}.$$
因此，$\alpha$是一个很好的近似数。
现在让我们证明以下定理。
定理*)。一个很好近似的无理数不可能是代数数。
证明。让我们以无理代数为例

*) 该定理由法国著名数学家约瑟夫·刘维尔（Joseph Liouville，1809-1882）证明。

数字 $\alpha$ 并表明它不是一个好的近似值。由于 $\alpha$ 是代数，因此存在多项式
$$P(x) = a_0 x^n + a_1 x^{n-1} + \dots + a_n$$
具有整数系数使得$P(\alpha) = 0$。
我们假设 $P(x)$ 没有有理根。事实上，如果$P(x)$有一个有理根，比如$a$，那么$P(x)$可以被$(x-a)$整除而没有余数。商显然具有有理系数，因此将其乘以适当的整数会得到一个具有整数系数的多项式，其中 $\alpha$ 仍然是根，并且其次数比原始多项式小 1。重复这个操作，我们得到一个具有整数系数和根$\alpha$的多项式，它不再有有理根。

让我们用$A$表示最多的数字$|a_0|, |a_1|, \dots, |a_n|$并放入$B = |\alpha| + 1, N = n^2 AB^{n-1}$。
现在让我们证明，无论分数 $p/q$ 是多少，不等式都成立
$$|\alpha - \frac{p}{q}| \geq \frac{1}{N q^n},$$
由此可见，数字 $\alpha$ 并不是一个好的近似值。
令 $p/q$ 为任何分数。如果$|\alpha - \frac{p}{q}| > 1$，则不等式（*）显然成立，因此我们可以将自己限制在$|\alpha - \frac{p}{q}| \leq 1$时的情况。特别是（这非常重要），$|\frac{p}{q}| \leq |\alpha| + 1 = B$。
从上面可以看出
$$P\left(\frac{p}{q}\right) \neq 0.$$
因为
$$q^n \left[ a_0 \left(\frac{p}{q}\right)^n + a_1 \left(\frac{p}{q}\right)^{n-1} + \dots + a_n \right]$$
