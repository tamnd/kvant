集合运算有多少种？

集合不仅可以由数字组成，还可以由人、汽车、动物、植物等组成。在生活中，集合通常有不同的名称。因此，举例来说，不是很多牛，而是一百头牛，不是很多马，而是马文，不是很多工具，而是一套工具，等等。

这句话摘自四年级数学课本。您可能知道可以对集合执行并集和交集运算，有时称为集合的加法和乘法。您听说过任何其他集合操作吗？也许您知道一组的差异或它们的对称差异是什么？集合上到底有多少种运算？它们的数量是有限的还是无限的？为了回答这些问题，首先我们需要了解什么叫集合运算？我们给出此类操作的一般定义，并讨论它们的一些有趣的属性。较难的事情在正文中讨论，用小字体打字（初读时可以省略这部分文字）。

4. 二元法则

集合运算的研究包括获取连接运算的各个点。我们指的是以下类型的语句。一些操作序列以两种方式对集合$A_1, \dots, A_n$执行，并且指出这些操作组合总是（对于任何$A_1, \dots, A_n$）导致集合的重合。所有定律(1)、(2)、(3)也是相同点。能够从现有的点中获得新的点很重要。例如，我们实际上已经使用过这样一个事实：如果在一个点中我们将$A_1, \dots, A_n$替换为$\bar{A}_1, \dots, \bar{A}_n$，或者在点的两个部分中进行互补，我们也会得到点。

现在我们将指出一种非常重要的变换点的方法，其中包含并集、交集和加法运算（并且仅包含这些运算）。

二元性法则。如果在一个只包含并、交、加运算的点上，我们将所有交集替换为并集，并将所有并集替换为交集，那么我们再次获得点。

检查以这种方式，从并集的交换性和结合性，我们获得交集的交换性和结合性，反之亦然，并且从一个分配对应关系（2） - 另一个。

我们不会在这里给出这个陈述的证明，但会给出一个如何获得它的例子。

考虑要点

所有的运算都可以通过并集和交集来表达，而不需要借助额外的运算吗？事实证明并非如此。为了验证这一点，您需要找到所有通过并集和交集表示的运算都具有的某些属性，但有些运算不具备此属性。正如我们在讨论对应关系 (2) 时在第 1 点中指出的那样，始终可以更改并集和交集的顺序，以便首先执行交集，然后执行并集。如果 $f(A_1, \dots, A_n)$ 通过并集和交集表示，则为了定义可以包含 $f(A_1, \dots, A_n)$ 的切片集合，强加了这种表示的可能性。这些段的集合必须按如下方式排列：集合$N = \{1, 2, \dots, n\}$中有子集$M_1, \dots, M_k$，并且当且仅当$\sigma_j = 1$代表所有$j \in M_1$，或$\sigma_j = 1$代表所有$j \in M_2$，等等，替代$\sigma = (\sigma_1, \dots, \sigma_n)$的段包含在$f(A_1, \dots, A_n)$中。例如，在 $(A_1 \cap A_3 \cap \bigcap A_5) \cup A_4 \cup (A_2 \cap A_5)$ 的情况下，我们有：$M_1 = \{1, 3, 5\}, M_2 = \{4\}, M_3 = \{2, 5\}$。不难看出，这样的集合的集合的特点是，与每个集合$\sigma$一起，它们包含所有集合$\sigma'$，其中所有$\sigma$包含1的地方也有1（我们将其象征性地表示为：$\sigma' \geq \sigma$）。现在很清楚，例如操作$A \setminus B = A \cap B$不具有这个属性：它与集合(1, 0)对应的唯一部分重合，而$(1, 1) \geq (1, 0)$对应于$A \setminus B$中不包含的部分。通过并、交以及 0、1 表达的运算称为多重相关。显然，补码也是一个小数运算：计算$n = 1$，我们看到$A$与$\sigma = (0) \leq \sigma' = (1)$的分数重合。

10. 线性运算

每个操作都可以用$A \cap B, A \triangle B, I$来表示。确实，$\overline{A} = A \triangle I$，$A \cup B = (A \cap B) \triangle (A \triangle B)$，并且在第8节中我们证明了任何运算都是通过交集和加法来表达的。让我们从运算的算术解释的角度来探讨这个事实。令$f(A_1, \dots, A_n)$为任意运算；让我们看一下它的二进制表（参见第 7 段）。让我们用$\tilde{f}(x_1, \dots, x_n)$表示该表中对应于二进制集$(x_1, \dots, x_n)$的值。

如果我们用$A \cap B, A \triangle B, I$来表达$f$，那么对于$f$，通过算术运算模2产生一个表达式。通过打开括号并引入类似的项，我们获得了$\tilde{f}$作为$x_1, \dots, x_n$中的多项式的表示。考虑到$x_j$取值0、1，因此只取多项式除以2的余数，我们可以大大简化多项式的形式。首先，我们可以假设所有非零系数都等于1（2x除以2），其次，变量$x_j$将出现在不高于$x = 0, 1)$的第一个幂$(x^2 = x$的单项式中。

现在让我们检查这种类型的操作：$f(A_1, A_2, \dots, A_n) = A_1 \triangle A_2 \triangle \dots \triangle A_n$。 （在录音中我们使用了交换性和结合性$A \triangle B$；参见第2段。）结果集由包含在集合$A_1, \dots, A_n$奇数中的元素组成，然后我们将这些操作称为奇数idikars。直接验证这个陈述很容易（对于$n = 2, 3$，参见图 6, 7），并且可以注意到，在这种情况下$\tilde{f}(x_1, \dots, x_n) = x_1 + \dots + x_n$模2。这表明，例如，交集$A \cap B$不能通过对称差来表达，因为$A \cap B$由落入两个集合的元素组成。如果我们添加操作1，我们会得到更多的奇偶校验指标$A_1 \triangle \dots \triangle A_n \triangle I$；他们将被分配一阶多项式$x_1 + \dots + x_n + 1$。同样，我们将无法表达交集，因为未包含在 $A$ 或 $B$ 中的元素不会包含在 $A \cap B$ 中。我们将通过$A \triangle B$和$I$（即偶数和奇数指标）表达的运算称为线性运算，其余运算称为非线性运算。这些项与对应于这些运算的多项式相关联。

11. 基本操作系统说明

通过基本操作系统，我们理解所有其他操作都通过它们来表达的操作系统。

我们已经有几个基本操作系统的示例。而且，在前两段中我们证明了集合$\{A \cap B, A \cup B\}$，$\{A \triangle B, I\}$不能被视为基本运算系统。同时，我们获得了此类系统的必要条件；它们必须包含不完全运算和新式运算。值得注意的是，必要条件和充分条件是以同样的方式给出的。在最通用的系统中我们不会这样做。如果操作系统包含 0 和 1，我们就说该操作系统满足假设 01。
