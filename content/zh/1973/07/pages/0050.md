5. 该案例的基本参数是侧边为 $a$ 且底部角度为 $\alpha$ ($\alpha > 45^\circ$) 的髋部三角形。侧肋与基面倾斜$\beta$角。在这个素数中，通过角 $\alpha$ 之一的高度和顶点绘制一个平面。求截面积。

A.N.卢布廖夫、V.A.托尼扬

莫斯科钢铁及合金研究所

莫斯科钢铁与合金学院是全国领先的大学，致力于培养工程和科研人员，并在黑色金属、有色金属、稀有金属和放射性金属生产的冶金和自动化、金属和合金加工以及金属物理学领域开展研究。

学院现有学生5800人，其中全日制学生4300人。在学习期间，学生接受广泛的物理、化学和数学培训，以掌握金属、合金和半导体材料科学，黑色、有色和稀有金属加工的现代生产方法的理论和实践基础，以及冶金过程控制的自动化。

该学院还通过研究生院培养人才，该学院是全国最大的研究生院之一，有 548 人在那里学习。

研究所设有以下院系：黑色金属及合金冶金系（MCHMiS）、有色及稀有金属及合金冶金系（MCRMiS）、物理与化学系（FC）、半导体材料与器件系（PMP）和夜间教师。该学院在莫斯科和贝卡巴德、扎波罗热、奥尔斯克、乌斯季卡缅诺戈尔斯克、切列波维茨等工业中心附近设有日间预科部门和晚间预科课程。该研究所设有物理和数学学校以及周日讲座。

申请 PH 和 PMP 院系的学生需修读数学（笔试和口试）、物理（口试）、俄语语言和文学（笔试）； MCHMIS、MCRMiS 和夜间学院 - 数学（笔试）、物理（口试）、化学（口试）、俄语和文学（笔试）。

以下是 1972 年数学入学考试的典型选项。

物理学院和PMP

选项1

1. 确定参数范围（笔试和口试）、物理（口试）、俄语语言文学（笔试）； MCHMIS、MCRMiS 和夜间学院 - 数学（笔试）、物理（口试）、化学（口试）、俄语和文学（笔试）。

2. 简化表达式：

$$\frac{a + \sqrt{2 + \sqrt{5}} \cdot \sqrt[12]{(9 - 4\sqrt{5})^3}}{\sqrt[3]{2 - \sqrt{5}} \cdot \sqrt[6]{9 + 4\sqrt{5}} - \sqrt[3]{a^2} + \sqrt[3]{a}}.$$

3. 找到 $a$ 不等式的所有值

$$\log_{2a+1}(2x - 1) + \log_a(x + 3) < 0$$

同时执行$x = 1$和$x = 4$。

4. 解方程：

$$\text{ctg}\left(\frac{\pi}{3} \cos 2\pi x\right) = \sqrt{3}.$$

选项2

1. 直角三角形符号的底边是一个等边三角形，其边长等于$a$，形成角$\alpha$。该角对面的面的对角线与另一侧面形成$\phi$角。求识别量。

2. 简化表达式：

$$\left(\frac{\sqrt{8} + 2}{\sqrt{2} + \sqrt{2}} - \sqrt{4}\right) \left(\frac{\sqrt{8} - 2}{\sqrt{2} - \sqrt{2}} - \sqrt{12}\right)^{\frac{1}{2}}.$$

3. 众所周知，不等式：

$$\log_a(x^2 + x + 2) < \log_a(2x^2 - 18)$$

满足$x = -3,5$。解决不平等问题。

4. 解方程：

$$\text{tg}\frac{2\pi x}{x^2 + x + 1} = -\sqrt{3}.$$
