例如，结合性允许在集合$A_1, \dots, A_n$多次执行并集的情况下，不使用括号固定执行操作的顺序，而是简单地谈论集合$A_1 \cup A_2 \cup \dots \cup A_n$的并集$n$；该集合由至少一个集合中包含 $A_1, \dots, A_n$ 的元素组成。交换律表明顺序$A_1, A_2, \dots, A_n$可以根据需要改变。

在数值情况下，加法和乘法通过以下关系相互连接：$a (b + c) = ab + ac$（乘法相对于加法的分配率）。该比率允许您从括号中减去公因数并打开括号。对于一组这样的关系有两个：

$$A \cap (B \cup C) = (A \cap B) \cup (A \cap C);$$
$$A \cup (B \cap C) = (A \cup B) \cap (A \cup C).$$

图3显示了说明这些关系的图表。例如，为了证明它们中的第一个，只需注意右侧和左侧的集合由集合$A$中包含的元素以及集合$B$或$C$中的至少一个组成即可。请注意，在某些情况下，第二个关系的形式为 $a + bc = (a + b) (a + c)$，当然，这不是真的。

第一个关系（2）表明任何并集和交集的序列都可以转换为这些操作的序列，即首先执行所有交集，然后执行并集。例如，确保 $(A \cup B) \cap ((C \cap D) \cup E)$ 可以转换为 $(A \cap C \cap D) \cup (A \cap E) \cup (B \cap C \cap D) \cup (B \cap E)$。您还可以采用首先执行所有连接的方式（使用第二个关系）。思考数值案例中的类似变换。

2. 差异和对称差异

集合$A$和$B$的差$A \setminus B$称为由不包含在$B$（图4）中的元素$A$组成的集合。该差异不是对称差异。例如，为了证明它们中的第一个，只需注意右侧和左侧的集合由集合$A$中包含的元素以及集合$B$或$C$中的至少一个组成即可。请注意，在某些情况下，第二个关系的形式为 $a + bc = (a + b) (a + c)$，这当然是不正确的。

第一个关系 (2) 表明任何并集和交集序列都可以转换为这些操作的序列，即首先执行所有交集，然后执行并集。例如，确保 $(A \cup B) \cap ((C \cap D) \cup E)$ 可以转换为 $(A \cap C \cap D) \cup (A \cap E) \cup (B \cap C \cap D) \cup (B \cap E)$。您还可以以首先执行所有相交的方式执行此操作（使用第二个关系）。思考数值案例中的类似变换。
