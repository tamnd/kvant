MCHMIS 和 MCRMiS 学院

选项3
1. 正三角形长方形的边心为$a$，侧面与底面的夹角为$\alpha$。求长方形的侧面。
2. 解方程：
$$\left( x + \frac{1}{2} \right)^{\frac{1}{2}} - \left( x - \frac{1}{2} \right)^{\frac{1}{2}} = 2x^{\frac{1}{2}} \left( x + \frac{1}{2} \right)^{-\frac{1}{2}}.$$
3. 解决不等式：
$$\log_{2} \frac{x^2 + x - 6}{x - 4} < \frac{x^2 - 16}{x - 4} - x - 3.$$
4. 证明行动要点：
$$\frac{1 + \cos(2\alpha + 630^\circ) + \sin(2\alpha + 810^\circ)}{1 - \cos(2\alpha - 630^\circ) + \sin(2\alpha + 630^\circ)} = \text{ctg} \alpha.$$
选项4
1. 长方体的底等于$a$，其侧面与底平面倾斜，另外两个侧面与底平面成两个角，各等于$a$。长方形的高是$h$。确定矩形的侧面。
2. 解决不等式：
$$\lg 2 + \lg (4^{x-2} + 9) < 1 + \lg (2^{x-2} + 1).$$
3. 四个数字组成一个等差数列。如果我们分别加上1、1、3和9，我们就得到了几何级数。找到这些数字。
4. 解方程：
$$\cos^8 \left( x + \frac{\pi}{4} \right) + \sin^8 \left( x + \frac{\pi}{4} \right) = \frac{1 + \sin 2x}{4}.$$

莫斯科铁路运输工程师学院
莫斯科铁路运输工程师学院是苏联最古老的大学之一，现在是该国领先的技术大学之一。
全国范围内以及部分铁路运输领域发生的科学技术革命，决定了MINTA的发展迈出了质的一步，并为承担重要工程和科学任务的学院毕业生开辟了新的广阔前景：运输量的增加，交通速度的急剧提高，汽车、内燃机车、电力机车的新现代设计的开发和实施，引入建造铁路轨道、工程结构、场所和隧道的现代方法和手段，管理性质的变化在货物运输过程中，广泛采用自动化、远程机械、电子、计算机辅助技术方法来规划和优化运输。由于毕业生规模广泛，MINT 基本上成为最大的理工学院。

该学院设有 10 个院系，培养 19 个专业的专家：自动化控制系统；自动化和远程自动化（工业）；铁路运输自动化、远程自动化和通信；会计;马车和马车养殖；机车;场所和隧道；组织经济信息机械化处理；应用数学；工业太阳能；工业与民用建筑；铁路建设、轨道和轨道管理；建筑和昂贵的机械和设备；黄色卡车和黄色运输设施；经济和施工组织（铁路）；铁路运营；铁路运输电气化；电子计算机。

申请人将参加以下考试：数学（笔试和口试）、物理（口试）、俄语和文学（笔试）。
