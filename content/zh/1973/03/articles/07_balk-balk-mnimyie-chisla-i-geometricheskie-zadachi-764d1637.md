真实适用
虚数

虚数的诞生归功于现实数学问题的一波浪潮——求解三次方程。确实，即使在求解二次方程时，数学家也会遇到负数的平方根。求解以下形式的随机选择的方程
$$x^2 + px + q = 0,$$
(1)

其中$p, q$是“客观”，即实数，根据众所周知的公式有时会导致$A + \sqrt{B}$形式的数字，其中$B$是负数。但没有人知道“负数的平方根”是什么，应该赋予这样一个表达式什么含义。然而，有几种方法可以解决这个困难：简单地声明表达式$\sqrt{-1}$（或$\sqrt{B}$，其中$B < 0$）没有意义。这看起来完全合理：每次都可以证明对于$B < 0$，方程（1）的根不能是正数、负数或零。当求解三次方程（即三次方程）时，简单地忽略负数的平方根是不可能的。

事情就是这样的。 400 多年前，几位意大利数学家学会了求解三次方程。其中一位 Hieronymus Cardan (1545) 的代数教科书中概述的方法可归结为（以现代表示法）如下：方程的根为
$$x^3 + px + q = 0$$
(2)

可以使用以下公式计算（现在称为卡丹公式）
$$x = \sqrt[3]{-q/2 + \sqrt{D}} + \sqrt[3]{-q/2 - \sqrt{D}},$$
(3)

在哪里
$$D = \left(\frac{p}{3}\right)^3 + \left(\frac{q}{2}\right)^2.$$

唉，当方程（2）有三个不同的实根时，这个公式就失效了！例如，很容易检查方程 $x^3 - x = 0$ 的根是数字 0,1, -1。但如果我们尝试使用卡丹公式求解这个方程，我们会得到
$$x = \sqrt[3]{V - \frac{1}{27}} + \sqrt[3]{V - \frac{1}{27}}.$$

如何从这个公式中提取数字 0、1、-1？为了回答这些问题，16 - 17 世纪的数学家必须学习如何处理 $A + \sqrt{B}$ 形式的表达式，其中 $B < 0$，特别是此类表达式的立方根。

数学家们极不愿意研究这样的表达式。他们称它们为“虚数”、不存在的、不可能的、“复杂的”数、“方程的秘密解”。他们没有真正的内容，这被认为是非常令人惊讶的。
