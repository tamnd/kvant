⟦folio 56⟧

莫斯科国立大学

（经济学院）

经济科学的任务是概括社会经济生活中的新现象，研究国民经济问题，其解决有助于交通建设的成功。经济学家的注意力应该集中在国民经济中最有效地利用物质和劳动力资源的方法、现有的计划和组织工农业生产的方法、发展生产力的根本布局和建设交通的技术经济问题上。苏共第二十四次代表大会为经济科学确定的这些任务是根据莫斯科大学经济学家培养的重要性和地位而确定的。

经济学院培养专业人才：“政治经济学”和“国民经济计划”——全日制和晚间系； “经济学” - 全职。

“政治经济学”系毕业生获得“经济学家、政治经济学教师”资格，可派往高等、中等专业学校任教师，经济研究所职员，企业、国营农场、计划单位经济师。

通常，具有至少两年实际工作经验的人员可以在政治经济学系进行全日制学习。有些教师的任命是针对没有工作经验的高中毕业生。

“计划经济”系开设“国民经济计划”和“经济经济学”两个专业培养。学生经过彻底和全面的经济训练，获得深入的数学知识和经济分析的数学方法。在这里，大规模地研究了数学分析、线性代数、概率论、数学规划、经济信息系统、大众理论。

服务、运筹学。 “国民经济计划”专业毕业后，授予“经济学家、综合计划师”资格，“经济经济学”专业毕业生授予“经济师、数学家”资格，分配到计划统计机构、计算机中心、研究机构和大型企业工作。

以下是 1972 年这些院系数学入学考试的选项。

经济控制论系

1. 设计局正在建造一个长方体形状的房间，其中一堵墙应为玻璃，其余为一般材料。房间的高度应为4米，面积应为80平方米。一平方米玻璃墙售价75卢布，总米售价50卢布。房间的长度和宽度应该是多少，以使所有墙壁的总成本最小？这个最低成本是多少？

2. 求 tg x 如果
$$2y \sin x + 5 \cos x = 2y, \quad -5 \sin x + y \cos x = 1.$$

3. 找到并描绘坐标平面上坐标满足方程组的点
$$\begin{cases} (3x + 1)(x - 3y - 1) = 0, \\ (3x + 1)(6y - 2x + 1)(x + y) = 0. \end{cases}$$

4. 在最终的四边形ABCD中，角A和C是相反的。垂线 BE 和 DF 落在对角线 AC 上。证明CE=FA。

政治经济学的区别

1. 不要使用表格，确定哪个更大：$\log_3 75$ 或$\log_2 22$。

2. 找到并描绘坐标平面上坐标满足方程组的点
$$\begin{cases} 18x^2y^2 - 4x^3y^2 - 3x^2y^3 = 0, \\ 12y^2 - 2xy^2 + 3y^3 = 0. \end{cases}$$

3. 一本代数教科书、两本几何教科书和两本三角学教科书售价2卢布。 10戈比，三本代数教科书、一本几何教科书和一本三角学教科书售价2卢布。 30 戈比 几何和三角学教科书总共要多少钱？

4. 在顶点 C 的素角之外，在其平分线的延长线上取点 O，使得 OC = $\sqrt{2}$。以 O 点为圆心作一个半径为 2 的圆。求该角的各边和它们之间所围成的圆弧所围成的图形的面积。

5. 解决不平等问题
$$\frac{4x^2 + 8x - 5}{x + 1} < 0.$$
