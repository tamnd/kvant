M151。我们将9个primo分别分成两个四边形，其面积比例为2:3。证明这九个原点中至少有三个经过同一点。

如果一条直线与正方形的两个相邻边相交，那么显然它将正方形切成三角形和第五个尼克。但根据9个primo中每一个的条件，将正方形切割成四边形。因此，这样一条直线与正方形的两条相对边相交，即将正方形分成两个梯形（或两个矩形），梯形的底边位于正方形的边上，高等于正方形的边长。很明显，直线以 2:3 (图 1) 的比例划分正方形的“中线”，因为这些梯形的面积之比等于它们的中线之比（位于正方形的中线上）。

正方形的中线上有两个点将其按 2:3 的比例划分。观察正方形的另外两条相对边，我们会发现在与它们平行的中线上又多了两个点。

结果，我们得到 9 个数据点中的每一个都经过 4 个指定点之一 (图 2)。

当然，至少有三个primo经过这些点之一。事实上，如果每个点通过的原数不超过两个，那么总共不会超过 2.4 = 8 个原数，这与条件相矛盾。

读者指出了问题的自然概括：我们考虑的不是正方形，而是 2n 边形，其相反

请注意，如果多边形的两条边不平行，则每条与这些边相交并切断给定平面的直线将不再通过一个点（证明这一点！），而是会接触一些双曲线。

M152。设a、b、m、n为自然数，a与b互质且a > 1。证明如果a^m + b^m可被a^n + b^n整除，则m可被n整除。

事实证明，问题的陈述可以用更精确的陈述来代替。我们不仅要证明 m 可以被 n 整除，即 m = kn，其中 k 是某个整数，而且还证明 k 必然是奇数。我们将证明分为三个部分。

1°。设 m = kn，其中 k 是奇数。那么 a^m + b^m 可以被 a^n + b^n 整除。

2°。设 m = kn + r，其中 k 是奇数且 0 < r < n。那么 a^m + b^m 不能被 a^n + b^n 整除。

3°。设 m = ln + r，其中 l 为奇数且 0 ≤ r < n。那么 a^m + b^m 不能被 a^n + b^n 整除。

注意，通过证明 1°、2°、3°，我们将证明比一般情况还要多的证明，即：对于 polychoba a^m + b^m 可被 a^n + b^n 整除，m 等于 kn 是充分必要的，其中 k 是奇数。在 2° 和 3° 的证明中，我们将使用 a 和 b 是互质的事实，但在 1° 的证明中它们不是。

证明1°。令c和d为任意整数。然后 c^k + d^k（其中 k > 0 为奇数）可被 c + d 整除。 （因此，对于 c = a^n 和 d = b^n，我们得到 1°。）事实上，很容易看出，对于奇数 k

c^k + d^k = (c + d) (c^{k-1} - c^{k-2} d + ... - cd^{k-2} + d^{k-1}).

证明2°。我们将 a^m + b^m 写成 a^{kn+r} + b^{kn+r} = a^r (a^{kn} + b^{kn}) + b^{kn} (b^r - a^r) 的形式。

根据 1°，第一项可被 a^n + b^n 整除，但第二项不可被 a^n + b^n 整除，因为 b^{kn} 与 a^n + b^n 互质且 0 < |b^r - a^r| < a^n + b^n。因此，总和不能被 a^n + b^n 整除。
