新坐标$-ic$。波兹尼$w = ib - (-ic) = i(b + c)$。因此，$w = 2im$。这意味着$A_2A_1 \perp AM$和$A_2A_1:AM = 2$。

问题5.在三角形$A_1A_2A_3$(图13)的边上看与三角形没有共同内瓣的正方形；它们的中心$B_1, B_2, B_3$标记在方块中。检查绘图建议的对应关系的有效性：$B_1B_2 = A_3B_3, B_1B_2 \perp A_3B_3$。

解决方案。让我们在三角形平面中选择笛卡尔坐标系$xOy$。点 $A_1, A_2, A_3; B_1, B_2, B_3$ 以及向量 $B_1B_2$ 和 $A_3B_3$ 的复坐标将由 $a_1, a_2, a_3, b_1, b_2, b_3, z$ 和 $w$ 表示。让我们通过$a_1, a_2, a_3$来表达$z$和$w$。我们有$z = b_2 - b_1$，$w = b_3 - a_3$。我们来求 $b_2$ （如练习 14 所示）：

$$b_2 = \frac{a_3 + a_1}{2} + i \frac{a_3 - a_1}{2}.$$

同样地

$$b_3 = \frac{a_1 + a_2}{2} + i \frac{a_1 - a_2}{2},$$

$$b_1 = \frac{a_2 + a_3}{2} + i \frac{a_2 - a_3}{2}.$$

现在很容易计算出

$$z = \frac{a_1 - a_2}{2} + i \frac{2a_3 - a_1 - a_2}{2},$$

$$w = \frac{a_2 + a_1 - 2a_3}{2} = i \frac{a_1 - a_2}{2}.$$

这表明$w = iz$。这意味着当我们逆时针旋转向量$B_1B_2$$90^\circ$时，我们得到的向量等于向量$A_3B_3$。但在这种情况下$A_3B_3 = B_1B_2, A_3B_3 \perp B_1B_2$。

问题6. 逆时针读取平面上两个正三角形的顶点。具有相同编号的顶点通过线段连接。证明这些线段的中点是正三角形的顶点（科莫三角形可以退化为一个点）。

解决方案。令$A_1A_2A_3$和$B_1B_2B_3$为给定的三角形，$C_1, C_2, C_3$线段$A_1B_1, A_2B_2, A_3B_3$和$a_k, b_k, c_k$（其中$k = 1, 2, 3$）的中点是所考虑的9的完整坐标。那么向量 $A_1A_3$ 具有复坐标 $a_3 - a_1$，向量 $A_1A_2$ 具有复坐标 $a_2 - a_1$。由于三角形$A_1A_2A_3$是正三角形，因此向量$A_1A_2$逆时针旋转$\frac{\pi}{3}$弧度即可得到向量$A_1A_3$，所以

$$a_3 - a_1 = e^{i \frac{\pi}{3}} (a_2 - a_1).$$

同样地

$$b_3 - b_1 = e^{i \frac{\pi}{3}} (b_2 - b_1).$$

由于$C_1$是线段$A_1B_1$的中点，那么

$$c_1 = \frac{1}{2} (a_1 + b_1).$$

同样地

$$c_2 = \frac{1}{2} (a_2 + b_2), c_3 = \frac{1}{2} (a_3 + b_3).$$

从所获得的关系可以得出$c_3 - c_1 = e^{i \frac{\pi}{3}} (c_2 - c_1)$。但这意味着向量$C_1C_3$是由向量$C_1C_2$旋转$+\frac{\pi}{3}$弧度的角度得到的，即$\triangle C_1C_2C_3$是正确的。
