练习 4. 设向量 **OA** 和 **AB** (图 3) 具有复坐标 *z*1 和 *z*2，并且这些向量的和（向量 **OB**）具有复坐标 *z*。我们如何通过数字*z*1和*z*2来表达数字*z*？

解决方案。设 *z*1 = *a*1 + *b*1 *i*，*z*2 = *a*2 + *b*2 *i*。那么向量**OA**和**AB**在*Ox*轴上的投影分别等于*a*1和*a*2，它们的总和**OB**在*Oy*轴上的投影是*a*1 + *a*2。类似地，可以看出矢量 **OB** 在 *Oy* 轴上的投影等于 *b*1 + *b*2。但那么向量**OB**的复坐标*z*就等于(*a*1 + *a*2) + *i* (*b*1 + *b*2)，即

*z* = *z*1 + *z*2.

因此，当向量相加时，它们的复坐标也会被相加。

实践5. 坐标平面*xOy* (图 4) 的两点*Z*1 和*Z*2 具有复坐标*z*1 和*z*2。向量 *Z*1 *Z*2 有什么复数坐标？

解决方案。让我们用 *z* 表示向量 *Z*1 *Z*2 的复坐标。由于 *OZ*2 = *OZ*1 + *Z*1 *Z*2，则 *z*2 = *z*1 + *z*，因此

*z* = *z*2 — *z*1.

因此，向量的复坐标等于其末端的复坐标与其开头的复坐标之差。
