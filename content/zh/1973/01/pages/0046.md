问题 3. 将空气从体积为 $V$ 的容器中抽出，腔室中的压力为 $P$。活塞泵应抽吸多少$v$才能使密封容器内的压力达到$k$倍？空气温度不变。

解决方案。在活塞第一次“摆动”之前，我们可以写出容器中的气体

$$PV = \frac{m}{\mu} RT.$$

当泵活塞处于极限位置时，气体体积为$V + v$，压力为$P_1$，

$$P_1 (V + v) = \frac{m}{\mu} RT.$$

这意味着

$$P_1 = P \frac{V}{V + v}.$$

同样，我们发现第二次摆动后容器中的压力将等于

$$P_2 = P_1 \frac{V}{V + v} = P \left( \frac{V}{V + v} \right)^2.$$

$n$ 摆动后压力变​​得相等

$$P_n = P \left( \frac{V}{V + v} \right)^n.$$

根据问题的条件

$$P_n = \frac{1}{k} P.$$

由此可见

$$\frac{1}{k} = \left( \frac{V}{V + v} \right)^n,$$

那是

$$n = - \frac{\lg k}{\lg V / v} = \frac{\lg k}{\lg \frac{V}{v} + V / V}.$$

如果容器中存在多种气体的混合物，则根据道尔顿定律，该混合物对容器壁的压力等于分压之和。如果从容器中除去剩余气体，每种气体单独产生的压力称为分压。这意味着混合物中每种气体的状态独立于其他气体的状态。然而，只有体积和温度是恒定的（因为气体处于平衡状态）。因此，对于每种气体，可以不同地写出气体状态方程。让我们举个例子。

问题 4. 确定由 $m_1 = 50$ 氧气和$m_2 = 20$ 氢气组成的混合物在$t = 20^\circ C$ 温度和$P = 0,9$ 大气压下的密度。

解决方案。

$$P = P_1 + P_2,$$

其中$P_1$是氧分压，$P_2$是氢分压。

让我们表示混合物的体积$V$，然​​后

$$P_1 V = \frac{m_1}{\mu_1} RT,$$

$$P_2 V = \frac{m_2}{\mu_2} RT,$$

和

$$PV = \left( \frac{m_1}{\mu_1} + \frac{m_2}{\mu_2} \right) RT.$$

混合物的密度为

$$\rho = \frac{m_1 + m_2}{V} = \frac{m_1 + m_2}{RT} \left( \frac{m_1}{\mu_1} + \frac{m_2}{\mu_2} \right) \approx 0,23 \text{ ке/м}^3.$$
