关于何时 $p$ 是模 $q$ 的平方余数和何时 $q$ 是模 $p$ 的平方余数的问题之间存在差异。

证明。始终为 $p-q=4a$ 或 $p+q=4a$。

我的情况。让$p-q=4a$，即$p$和$q$除以4时具有相同的余数。然后$\left(\frac{p}{q}\right) = \left(\frac{q+4a}{q}\right) = \left(\frac{4a}{q}\right) = \left(\frac{a}{q}\right)$（我们将使用（9），（8），以及$\left(\frac{4}{q}\right) = 1$对于所有$q$的事实）。接下来，$\left(\frac{q}{p}\right) = \frac{p-4a}{p} = \left(\frac{-4a}{p}\right) = \left(\frac{-1}{p}\right)\left(\frac{a}{p}\right)$。凭借已经证明的欧拉假设，$\left(\frac{a}{p}\right) = \left(\frac{a}{q}\right)$，即$\left(\frac{p}{q}\right) = \left(\frac{q}{p}\right)$对应$\left(\frac{-1}{p}\right) = 1$，$\frac{p}{q} = -\left(\frac{q}{p}\right)$对应$\left(\frac{-1}{p}\right) = -1$。仍然要记住$\left(\frac{-1}{p}\right) = 1$与$p=4l+1$，$\left(\frac{-1}{p}\right) = -1$与$p=4l+3$。

二、案例。令$p+q=4a$，即$p$和$q$除以4时有不同的余数。我们有$\left(\frac{p}{q}\right) = \left(\frac{4a-q}{q}\right) = \left(\frac{a}{q}\right)$。与$\left(\frac{q}{p}\right) = \left(\frac{a}{p}\right)$相同。凭借欧拉假设的补集$\left(\frac{a}{q}\right) = \left(\frac{a}{p}\right)$，即$\left(\frac{p}{q}\right) = \left(\frac{q}{p}\right)$。证明完毕。

很容易看出，上述推理可以颠倒过来，并且可以从互反平方律推导出欧拉假设及其补集（这样做！）。我们还要注意，公式（8）-（10）提供了一种比上述组合方法更简单的计算$\left(\frac{p}{q}\right)$本质的方法。让我们用一个例子来说明这一点：$\left(\frac{59}{269}\right) = \left(\frac{269}{59}\right) = -1$，

因为
$\left(\frac{3}{59}\right) = -\left(\frac{59}{3}\right) = -\left(\frac{2}{3}\right) = 1$;
$\left(\frac{11}{59}\right) = -\left(\frac{59}{11}\right) = -\left(\frac{4}{11}\right) = -1$.

很容易证明勒让德符号的求值总是可以简化为$p$或$q$等于2的情况。

锻炼。数$\left(\frac{37}{557}\right)$，$\left(\frac{43}{991}\right)$。

总之，我们注意到二次留数问题是大规模且富有成效的数学活动的起点。高斯为获得二次互反律的新证明而进行的多次尝试并不是主要出于简化证明的愿望。高斯一直担心自己还没有真正发现互惠定律的深层规律。这直到后来在代数数理论的框架内才完全实现。高斯花费了大量的精力将二次定律推广到三次和双二次情况，取得了显着的结果。这些研究仍在继续，直到今天，各种互易定律的研究仍然是数论的中心问题之一。
