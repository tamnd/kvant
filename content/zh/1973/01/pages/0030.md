M143。让我们找到满足以下条件的最小自然数$n$：

如果 $n$ 能被 $p - 1$ 整除且 $p$ 是素数，则 $n$ 能被 $p$ 整除。

让$n$满足这个条件。由于 $n$ 能被 1 = 2-1 整除，所以它一定能被 2 整除，但它又能被 3 = 2+1、7 = 2 3+1 和 43 = 2 3 7+1 整除。因此 $n$ 必须能被 1806 整除 = 2·3·7·43。

因此，最小值 $n$（如果存在）不小于 1806。另一方面，对于 1806，问题的条件满足 1, 2, 3, 6, 7, 14, 21, 42, 43, 86, 129, 301, 1806。 (5)

现在将它们每一个增加一，我们得到：

2, 3, 4, 7, 8, 15, 22, 43, 44, 87, 130, 302, 1807. (6)

剩下的就是显示集合 (6) 中的所有素数，并确保它们包含在集合 (5) 中（1807 不是素数，它可以被 13 整除）。

答案：$n = 1806$。

M145。我们承诺平均每天计划$B$$\sqrt{2}$卢布。他们规定，在$n$第$A$天，我们将收到整数$a_n$卢布（$a_n$等于1或2），前$n$天（$a_1 + a_2 + \dots + a_n$）收到的金额尽可能接近数字$n\sqrt{2}$。例如，$a_1 = 1$、$a_2 = 2$、$a_3 = 1$、$a_4 = 2$、$a_5 = 1$。

证明序列$a_1, a_2, a_3, \dots$是非周期的。

证明的思路如下。假设从数字$N + 1$的某一天开始，这个序列是周期性的，$T$是一个周期，即$a_{N+1} + a_{N+2} = a_{N+1}$、$a_{N+2} + a_{N+3} = a_{N+2}$等。那么在$N$之后的每$T$天，$B$将收到相同的整数。

$a_{N+1} + a_{N+2} + \dots + a_{N+T} = c$ (7) 卢布。因此，平均（在很长一段时间内）他每天将收到$\frac{c}{T}$卢布。但根据构建序列$a_n$的规则，他平均每天应该收到$\sqrt{2}$卢布。我们遇到了一个矛盾：平等

$$\frac{c}{T} = \sqrt{2}$$

不可能，因为$\sqrt{2}$是无理数，而$c$和$T$是自然数。

许多向我们发送该问题解决方案的人都表达了类似的想法。但并不是每个人都对其进行了严格的证明。这个证明可能看起来像这样：

让我们用 $s_n$ 表示 $a_1 + a_2 + \dots + a_n$。由于 $n\sqrt{2}$ 是无理数且 $s_n - \text{ближайшее целое число } k\sqrt{2}$ (图 6)，则

$$|s_n - n\sqrt{2}| < 1/2.$$ (9)

假设对于$n > N$，序列$a_n$是周期性的，并且使用符号（7），对于任何自然数$m$，我们有

$$s_N + mT = s_N + mc.$$ (10)

将 (9) 应用于 $n = N + mT$，考虑到 (10) 我们得到

$$|s_N + mc - N\sqrt{2} - mT\sqrt{2}| < 1/2,$$

因此，使用不等式 $|\alpha + \beta| \geq |\alpha| - |\beta|$ 并对 $mT$ 进行操作，我们得到

$$\left| \frac{c}{T} - \sqrt{2} \right| < \frac{1}{2mT} + \left| \frac{s_N - N\sqrt{2}}{mT} \right| < \frac{1}{mT}.$$
