⟦folio 5⟧

未满足（$k$ - 奇数）。上面提出的假设成为一个定理。

问题1.证明如果$p \neq 2$是数$n^2 + 1$的素因数，则$p = 4l + 1$。

因此，我们已经证明$-1$是$p = 4l + 1$的平方留数，并且是$p = 4l - 1$的平方非留数。

让我们讨论所提出的证明的一些特征。该陈述有两部分：$p = 4l - 1$的否定陈述和$p = 4l + 1$的肯定陈述。在第一种情况下，人们自然会尝试找到平方留数满足的neokotores性质，但$-1$不满足，这正是欧拉所做的。发现的性质被证明是特征性的，也就是说，同时可以证明假设的第二部分。如果您自己未能证明这部分陈述，则您认为您正在尝试从 $p = 4l + 1$ 显式构造数字 $n^2$，除以 $p$ 后得出余数 $-1$。欧拉的证明是无效的，因为它没有提供数字 $n$ 到 $p$ 的显式构造，而只是断言其存在。换句话说，如果我们遍历数字$1,2,...,2l$，将它们平方，然后除以$p$所得余数，那么迟早我们会得到$-1$。问题仍然是是否可以指示不使用枚举过程的更明确的构造$n$到$p$。 Langgange (1736-1813) 在 1773 年使用以下定理给出了肯定的答案。

威尔逊定理*)。如果$p = 2k + 1$是质数，则$(-1)^k (k!)^2 \equiv -1 (\bmod p)$。

为了证明这个定理，我们将使用引理1。让我们设置$P(x) = (x^2 - 1)(x^2 - 4) \ldots (x^2 - k^2), Q(x) = x^{2k} - 1$。那么$R(x) = P(x) - Q(x)$是次数最多$2k - 1$的多项式，在$x = \pm 1, \pm 2, \ldots, \pm k$处可被$p$整除（$P$和$Q$具有此性质）。通过引理 $R(x) \equiv 0 (\bmod p)$ 对于所有$x$。实际上，唯一的新因子是$R(0) \equiv 0 (\bmod p)$。从 $R(0) = (-1)^k (k!)^2 + 1$ 开始，我们得到 (5)。

拉格朗日推论。对于$p = 4l + 1$，我们有：$[(2l)!]^2 \equiv -1 (\bmod p)$。

问题2.证明如果(5)为真，则$p$是素数。

这个问题使我们有理由注意到，在拉格朗日的构造中，存在简单性$p$。

*) Wilson (1741-1793) - 律师，在剑桥学习数学。

为了找出 $a = -1$ 何时是平方余数，欧拉使用大量的数值材料（他的表格比上面第二个表大得多），试图找到其他 $a$ 的类似条件。他指出，对于$a = 2$，一切都取决于$p$除以8时的余数； 2 结果是素数 $p = 8l \pm 1$ 的平方留数和 $p = 8l \pm 3$ 的非留数（素数除以 8 可以得到余数 $\pm 1, \pm 3$）。此外，3是$p = 12l \pm 1$处的平方留数，以及$p = 12l \pm 5$处的平方非留数。欧拉猜想，在一般情况下，一切都由 $p$ 除以 4a 的余数决定。

欧拉假设*)。对于算术预测$4aq + r$、$q = 0, 1, 2, \ldots, 0 < r < 4a$中包含的所有素数，数字a同时是平方留数或平方非留数。

显然，如果$4a$和$r$有一个公约数$s > 1$，那么算术级数中将不存在单个质数。如果第一项和原切差是互质的，那么，正如狄利克雷定理（1805-1859）所述，在这个原切中存在无限多个素数（关于自然级数中素数个数无穷大的定理的推广）。

让我们回到欧拉的假设。事实证明，欧拉准则在 $a = -1$ 上表现良好，但在 $a = 2$ 上就失效了。欧拉未能解决这个问题。他成功地证明了他的假设，没有计算$a = -1$，只计算$a = 3$。然后我们已经提到的拉格朗日证明了$a = 2, 5, 7$处的猜想；勒让德（Legendre，1752-1833）于1785年提出了一般公务员猜想的证明，然而，该证明存在重大问题。

*) 证明了这个猜想的高斯称其为“黄金定理”。
