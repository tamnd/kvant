让我们在多边形的每个顶点放置 1 克质量。新兴物质点系统的重心与圆心O重合。根据式(6)我们有
$$\sigma = \sum_{1 \leq i < k \leq 100} A_i A_k^2 = M J_0 = (100R)^2.$$
任务 7. 已知围绕给定三角形 ABC 描述的圆的半径 R 和同一三角形中描述的圆的半径 r，计算它们的中心之间的距离 d。

设S为外接圆的圆心，Z为内切圆的圆心，a、b、c（厘米）为三角形的边长。让我们将相应的a、b和c克的质量放在顶点A、B、C处。该系统的重心将是Z点。根据公式（4）我们有
$$J_S - J_Z = (a + b + c) d^2.$$
利用公式（2）和（6）我们发现：
$$J_S = a \cdot SA^2 + b \cdot SB^2 + c \cdot SC^2 = (a + b + c) R^2,$$
$$J_Z = \frac{abc^2 + bca^2 + cab^2}{a + b + c} = abc.$$
另外，根据众所周知的三角形面积公式，我们有
$$S_{\Delta ABC} = \frac{abc}{4R} = \frac{1}{2} (a + b + c) r,$$
在哪里
$$abc = 2Rr (a + b + c).$$
由式(7)-(10)可知
$$d^2 = R^2 - 2Rr.$$
这就是所需的公式（“欧拉公式”）。

任务 8. 已知在平行四边形中，平面上所有点的长度平方和之间的差，对于该平面，该平面中给出的 a 边上的正方形 A_1 A_2 A_3 A_4 的顶点距离的平方和是常数 c^2，如果 c^2 > 2a^2？

让我们在四边形 A_1 A_2 A_3 A_4 的顶点放置相等的质量（每个 1 克），并让 Z 为所得质点系统的重心。由定义(2)和式(6)可得
$$J_Z = ZA_1^2 + ZA_2^2 + ZA_3^2 + ZA_4^2 = \frac{1}{4} \left( A_1 A_2^2 + A_2 A_3^2 + A_3 A_4^2 + A_1 A_4^2 + A_2 A_4^2 \right).$$
现在让我们考虑一个由两个质点 (A_1, 1) 和 (A_3, 1) 组成的系统（它们的重心是线段 A_1 A_3 的中间 P）。让我们接受公式（4）：
$$ZA_1^2 + ZA_3^2 = PA_1^2 + PA_3^2 + 2ZP^2 = \frac{1}{2} A_1 A_3^2 + \frac{1}{2} PQ^2.$$
同样地
$$ZA_2^2 + ZA_4^2 = \frac{1}{2} A_2 A_4^2 + \frac{1}{2} PQ^2.$$
根据 (11)、(12) 和 (13)，所需的欧拉公式如下：
$$(A_1 A_2^2 + A_2 A_3^2 + A_3 A_4^2 + A_4 A_1^2) - (A_1 A_3^2 + A_2 A_4^2) = 4PQ^2.$$
练习
1. 利用式(6)以其他方式求解问题4。
2. 设 Z 为三角形 ABC (BC=a, CA=b, AB=c) 内切圆的圆心。证明
$$a \cdot ZA^2 + b \cdot ZB^2 + c \cdot ZC^2 = abc.$$
3. 什么公式表示平面上所有点的集合，如果 c^2 > 2a^2，则该平面中给出的 a 边上给出的正方形 A_1 A_2 A_3 A_4 的顶点的平方距离之和为常数 c^2？
4. 在某些三角形中，中线交点与外接圆中心之间的距离小于该圆半径的三倍。证明三角形是正确的。
