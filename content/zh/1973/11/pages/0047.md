引理1.如果$(x_0, y_0)$是直线$l_n$上的整数点，那么$l_n$上靠近它的整数点将是$(x_0 - b, y_0 + a)$和$(x_0 + b, y_0 - a)$（a和b互质！）。

考虑穿过 $(0, 0)$ 的线 $l_0$。令$(-b_1, a_1)$为接近$(0, 0)$的整数点$l_0$，使得$b_1 > 0$、$a_1 > 0$（我们还不知道$b_1 = b, a_1 = a$）、$(x_0, y_0)$为整数点$l_n$。当穿过向量$(x_0, y_0)$时，从$(0, 0)$到$(-b_1, a_1)$的线段$l_0$将变成从$(x_0, y_0)$到$(x_0 - b_1, y_0 + a_1)$的线段$l_n$。因此，从上面看，点$(x_0 - b_1, y_0 + a_1)$将接近$(x_0, y_0)$点$l_n$。同样，当穿过向量$(x_0 + b_1, y_0 - a_1)$时，相同的线段$l_0$将从$(x_0 + b_1, y_0 - a_1)$到$(x_0, y_0)$进入线段$l_n$。因此，在该线段上，只有其末端才是整数点。

从这里已经可以看出，在任何直线 $l_n$ 上（如果其上至少有一个整数点），相邻整数点之间的间隙是相同的：沿 $Oy$ 轴的 $a_1$ 单位和沿 $Ox$ 轴的 $b_1$ 单位。这尤其适用于直线$l_0$。由于$(-b, a)$属于$l_0$，因此有$b = db_1$、$a = da_1$，其中$d$是整数。但按照惯例，数字 $a$ 和 $b$ 互质。所以，$d = 1$，即$a = a_1$，$b = b_1$。引理1得到证明。

从这个引理可以看出，每条线 $l_n$（其中 $n$ 是一个整数）恰好穿过条带 $0 \leqslant x \leqslant b - 1$ 内的一个点。在这种情况下，显然（参见图10），如果直线是红色的，即某处经过一个红色点，那么它在所见条带中的整个点也将是红色的（而蓝色直线的点当然也是蓝色的）。

现在请注意，当相对点 $\left(\frac{b - 1}{2} - \frac{1}{2}\right)$ $(x, y) \rightarrow (x', y') = (b - 1 - x, -1 - y)$ 对称时，条带 $0 \leqslant x \leqslant b - 1$ 会变换为自身，红点变换为蓝点，反之亦然。在这条对称线之后取$l_n$进入直线$l_{ab-a-b-n}$：如果$ax + by = n$，则$ax' + by' = a(b - 1 - x) + b(-1 - y) = ab - a - b - n$。 （通过对称中心，$a\left(\frac{b - 1}{2}\right) + b\left(-\frac{1}{2}\right) = \frac{ab - a - b}{2}$，我们的直线都不能通过；在 图 10 处，中心是点$(1, -\frac{1}{2})$。

很明显，最低的红线是$l_0$。因此，最上面的蓝线是$l_{ab-a-b}$。所以，不属于该集合的最多的数是$c = ab - a - b$，

$n$和$c - n$这两个数字中，一个属于$M$，另一个不属于。

引理 2. 在每一行 $l_n$ 上，其中 $n$ 是整数，至少有一个整数点。

只要证明整数点$(x_0, y_0)$在直线$l_1$上就足够了：如果$ax_0 + by_0 = 1$，则$a(nx_0) + b(ny_0) = n$，所以$(nx_0, ny_0)$将属于$l_n$。

考虑与顶点 $(0,0)$ 的平行线； $(0,1)$； $(b,1 - a)$； $(b,-a)$，其两条变化边都等于1，较大的一侧位于$l_0$和$l_b$线上。在这条平行线内部（不在顶点处）有 $b - 1$ 一个完整的点：在每条线上 $x = 1$、$x = 2$、$x = b - 1$ - 一个。另一方面，所有这些并行性都被相同的碰撞$(b - 1)$ - 直线$l_n : l_1, l_2, \dots, l_{b-1}$（不包括$l_0$和$l_b$）相交。由于直线 $l_n$ 不能有多个坐标 $x$ 相差小于 $b$ 的整点，因此数字 $(b - 1)$ 中的所有点都位于每条直线上。特别是，$l_1$处有一个完整的点。引理2得证。

F203。电子发生器使用普鲁德，其中室和阳极之间的距离为1mm。如果阳极方向为 200 V，请估计使用该发生器可以获得的最大振荡次数。

周期性地，通过周期性地改变灯栅极电势来实现一个发生器灯电路中的灯泡点。栅极电位出现的时间$t$必须不少于电子从卡达投射到阳极的时间$t$。使用该发生器获得的最大可能振荡频率可以根据以下条件确定

$$\tau = t \Rightarrow v_{\max} = \frac{1}{\tau}.$$

（如果$\tau > t$，则电子在灯被“锁定”之前没有时间到达目录。）

电极之间的场电压为$E = \frac{U}{d}$（我们不考虑变化的栅极场），电子加速度为$a = \frac{eE}{m} = \frac{eU}{md}$。因此，

$$d = a \frac{\tau^2}{2} \Rightarrow \tau = \sqrt{\frac{2d}{a}} = \sqrt{\frac{2d^2m}{Ue}}.$$

波兹图 $v_{\max} = \sqrt{\frac{Ue}{2d^2m}} \approx 3000$ 梅斯。
