⟦folio 56⟧

莫林道路。与路段 AB 相邻的是边长为 $\frac{1}{2} AB$ 的正方形场地。路段BC毗邻边长为BC的正方形田地，路段CA毗邻长为CA、宽为4 km的矩形林地。森林面积比平方田地总和大20平方公里。求森林的面积。

乍一看，数据太少，无法解决问题。不过，让我们继续进行计算。让我们分别用 c、a、b 表示三角形 AB、BC 和 CA 的边。那么从问题条件我们有：$4b = 20 + \frac{c^2}{4} + a^2$。让我们使用三角不等式 $b \leq a + c$ 并将 b 代入其中，用 a 和 c 表示：

$$\frac{1}{4}\left(20 + \frac{c^2}{4} + a^2\right) \leq a + c.$$

对这个不等式进行简单变换后，我们得到：$\left(\frac{c}{2} - 4\right)^2 + (a - 2)^2 \leq 0$，由此得到$c = 8(\text{km})$、$a = 2(\text{km})$和$b = a + c = 10(\text{km})$。森林面积40平方公里。

所选择的解决路径是该问题中唯一可能的路径。但事实证明，它得出答案是专门选择数据的结果。这样选择的结果是，A、B、C 三点位于同一条直线上，问题数据足以得出答案。

练习

1. （莫斯科国立大学力学和数学，1969）。平面四边形在两个相互垂直的平面上的矩形投影在边 2 上是正方形。四边形对角线的面积为 $\sqrt{14}$。找到另一条对角线。

2. 在锐角三角形 ABC 中，给定 $AB = 15$、$BC = 10$，角 BAC 等于 arccos $\frac{7}{9}$。围绕三角形ABC画一圆，并通过位于AC上距A距离9的点D画一条弦BE。求三角形AEC的面积。

3. 给定一个三角形 ABC，其边长为 5、2 和 $\sqrt{22}$，以及 $AC = \sqrt{22}$。在 AC 上取点 D，使得 BD = 3。求点 D 与三角形 ABC 外接圆的圆心之间的距离。

4. （莫斯科国立大学物理学院，1971 年）。球体内切于正三角形线 SABC，其所有边都等于 a。在边 SA 上取点 M，使得 AM = MS，在边 BC 上取点 N，使得 2CN = NB。凹坑 MN 在两点 P 和 Q 处与球体相交。求线段 PQ 的长度。

5. （莫斯科国立大学化学系，1971）。在三角形 ABC 中，从边 AB = $\sqrt{3}$ cm、BC == 4 cm、AC = $\sqrt{7}$ cm 引出中线 BD。三角形ABD和BDC的内切圆分别与BD相切于点M和N。确定段MN的长度。

6. （莫斯科国立大学地理学系，1971 年）。半径为 r 的两个圆互相接触。另外，它们中的每一个都从外侧在相应三角形的A点和B点处接触半径为R的三角形。如果 AB = 12 厘米，R = 8 厘米，则确定半径 r。

7. （莫斯科国立大学生物系，1971）。边长为 3 的正三角形 ABC 内接于圆。 D点位于圆上，弦AD的长度等于$\sqrt{3}$。求 BD 和 CD 和弦的长度。

8. （莫斯科国立大学生物系，1970）。给定一个三角形 ABC，其面积等于 1。在三角形 ABC 的中线 AK、BL 和 CN 上取对应点 P、Q 和 R，使得

$$\frac{AP}{PK} = 1, \frac{BQ}{QL} = \frac{1}{2}, \frac{CR}{RN} = \frac{5}{4}.$$

求三角形PQR的面积。

9. （莫斯科国立大学经济系，1970）。长方体块的体积为 150 cm3，总表面积为 280 cm2，底周长为 40 cm。求块的尺寸。

10. （莫斯科国立大学经济学院，1971）。半径为 R 的球以 60° 的两个角度内切。如果已知连接两个球中心的直线与两个角度的边缘形成 45° 角，则求与团子球以相同角度内切且相切的球的半径。

11. 给定一个三角形，其边 AB = 4、BC = 3 和 AC = 5。点 D 位于边 AB 上，因此 DB = $\frac{7}{8}$。通过 C、D 和 B 点画圆，并与 AC 相交于 E 点。求线段 BE 的长度。
