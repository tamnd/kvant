3. 注意到$x = 0$不是这个方程的根，我们将其转换为$x^2 + ax + b + \frac{a}{x} + \frac{1}{x^2} = 0$或$(x + \frac{1}{x})^2 + a(x + \frac{1}{x}) + b - 2 = 0$的形式。

很容易验证对于任何实数$x$，不等式$x + \frac{1}{x} \geq 2$都是有效的。为了固定$x_0$，原始方程的根等于$x_0$的数对$(a, b)$的集合由线性方程$y_0^2 + ay_0 + b - 2 = 0$确定，其中$y_0 = x_0 + \frac{1}{x_0}$。这组对由坐标平面 $(a, b)$ 上的素数表示。由于在此平面中，表达式 $a^2 + b^2$ 可以在几何上使用，因此我们线上的点 $(a, b)$ 的菠萝值 $a^2 + b^2$ 将等于从原点到所讨论的线的垂线长度的平方。

很容易算出，在$y_0^2 = \left(x_0 + \frac{1}{x_0}\right)^2 \geq 4$处等于$\rho = \frac{(y_0^2 - 2)^2}{1 + y_0^2}; \rho \geq \frac{4}{5}$。不难证明$\frac{(t - 2)^2}{1 + t} \geq \frac{4}{5}$对于$t \geq 4$、对于$t = 4$是相等的。因此，对于所有可能的实根$x_0$，$a^2 + b^2$的值不小于$\frac{4}{5}$。注意到$x_0 = 1$是原始方程在$a = -\frac{4}{5}, b = -\frac{2}{5}$处的根，我们发现$\frac{4}{5}$是$a^2 + b^2$的最小原始值。
