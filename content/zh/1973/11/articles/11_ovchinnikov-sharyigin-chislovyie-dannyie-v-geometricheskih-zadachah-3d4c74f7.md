几何问题中的数值数据
S.V.奥夫钦尼科夫、I.F.沙里钦

在大多数标准的学校问题中，数字根本不起任何作用。通常，此类问题可以使用“字母”符号以通用形式解决，然后将这些数字代入结果答案中。然而，通常使用数值数据的“规范”会产生更简单的解决方案。在本文中，我们将通过示例展示数值数据如何以不同方式影响问题的解决。

问题 4（莫斯科国立大学地质系，1971）。在三角形 ABC 中，从边 AB = 3 cm、BC = 4 cm 和 AC = 5 cm 绘制平分线 BD。三角形ABD和BCD具有分别在点M和N处与BD相切的内接圆。确定段MN的长度。

该问题的数值数据表明该三角形是直角的。这可能会导致尝试使用直角三角形的度量属性来解决问题。

事实上，该问题对于任意三角形 ABC 有一个简单的几何解。让我们用 c 表示 AB，用 a 表示 BC，用 b 表示 AC (图 4)。根据平分线性质，AD = \frac{bc}{a+c}，CD = \frac{ab}{a+c}。

让我们引入未知数 x = BM、y = MN 和 z = ND。由于从一点到圆的切线相等，我们可以构造以下方程组：

$$\begin{cases} x + y + \left( \frac{ab}{a+c} - z \right) = a, \\ x + \left( \frac{bc}{a+c} - z - y \right) = c. \end{cases}$$

从第一个方程中减去

群，我们会得到

$$2y + \frac{ab}{a+c} - \frac{bc}{a+c} = a - c,$$

在哪里

$$y = \frac{1}{2} \frac{(a-c)(a+c-b)}{a+c}.$$

将它们的值代入a、b和c，我们发现MN = \frac{1}{7}。

现在我们将考虑一些问题，其中专门选择的数值数据极大地简化了问题的解决。

任务 7（莫斯科国立大学生物学系，1970 年）。在面积等于1的凸四边形ABCD的各边上取点：AB上的K，BC上的L，CD上的M，AD上的N。同时$\frac{AK}{KB} = 2, \frac{BL}{LC} = \frac{1}{3}, \frac{CM}{MD} = 1, \frac{DN}{NA} = \frac{1}{5}$。求六边形 AKLCMN 的面积。

三角形KBL和ABC的面积比为$\frac{BK \cdot BL}{AB \cdot BC} = \frac{1}{12}$(图7)。三角形MND和ADC的面积之比为$\frac{DN \cdot DM}{AD \cdot CD} = \frac{1}{12}$。因此，三角形KBL和MND的面积之和为$\frac{1}{12}$，因此所需面积为$\frac{11}{12}$。

显然，此类问题一般没有唯一的解决方案。

莫林道路。与路段 AB 相邻的是边长为 $\frac{1}{2} AB$ 的正方形场地。路段BC毗邻边长为BC的正方形田地，路段CA毗邻长为CA、宽为4 km的矩形林地。森林面积比平方田地总和大20平方公里。求森林的面积。

乍一看，数据太少，无法解决问题。不过，让我们继续进行计算。让我们分别用 c、a、b 表示三角形 AB、BC 和 CA 的边。那么从问题条件我们有：$4b = 20 + \frac{c^2}{4} + a^2$。让我们使用三角不等式 $b \leq a + c$ 并将 b 代入其中，用 a 和 c 表示：

$$\frac{1}{4}\left(20 + \frac{c^2}{4} + a^2\right) \leq a + c.$$

对这个不等式进行简单变换后，我们得到：$\left(\frac{c}{2} - 4\right)^2 + (a - 2)^2 \leq 0$，由此得到$c = 8(\text{km})$、$a = 2(\text{km})$和$b = a + c = 10(\text{km})$。森林面积40平方公里。

所选择的解决路径是该问题中唯一可能的路径。但事实证明，它得出答案是专门选择数据的结果。这样选择的结果是，A、B、C 三点位于同一条直线上，问题数据足以得出答案。
