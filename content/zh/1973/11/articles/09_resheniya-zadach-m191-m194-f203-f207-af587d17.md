**M192。给定的数字是 1, 2, 3, ..., 1000。最小的是最大的 m，它具有最大的性质：无论给定的数字中哪 m 个被划掉，剩下的 1000 - m 个数字中都会有两个，其中一个可以被另一个整除。

让我们证明最大的 m 是 499。首先，让我们检查大于或等于 500 的 m 是否具有所需的属性。事实上，如果 $m \geq 500$，那么，通过划掉 m 个数字（从 1 到 m），我们将留下从 $m + 1 \geq 501$ 到 1000 的数字，其中几乎没有一个可以被另一个整除（所有成对关系都小于 2）。

现在我们证明$m = 499$具有所需的性质。换句话说，我们将证明从1到1000的任意501个数字中，有两个，其中一个可以被另一个整除（《初等数学选题与定理》一书第1部分《算术与代数》第91期《科学》1965年的类似解题）。

让我们将每个数字（501 个）与其最奇数除数进行匹配：数字 $2^k (2l + 1)$ 与数字 $(2l + 1)$ 匹配。所有小于1000的奇数，只有500个。因此，501个数字中，有两个会对应同一个奇数。在这两个数字中，一个必然是另一个通过乘以 2 的某个幂得到的。

引理1.如果$(x_0, y_0)$是直线$l_n$上的整数点，那么$l_n$上靠近它的整数点将是$(x_0 - b, y_0 + a)$和$(x_0 + b, y_0 - a)$（a和b互质！）。

考虑穿过 $(0, 0)$ 的线 $l_0$。令$(-b_1, a_1)$为接近$(0, 0)$的整数点$l_0$，使得$b_1 > 0$、$a_1 > 0$（我们还不知道$b_1 = b, a_1 = a$）、$(x_0, y_0)$为整数点$l_n$。当穿过向量$(x_0, y_0)$时，从$(0, 0)$到$(-b_1, a_1)$的线段$l_0$将变成从$(x_0, y_0)$到$(x_0 - b_1, y_0 + a_1)$的线段$l_n$。因此，从上面看，点$(x_0 - b_1, y_0 + a_1)$将接近$(x_0, y_0)$点$l_n$。同样，当穿过向量$(x_0 + b_1, y_0 - a_1)$时，相同的线段$l_0$将从$(x_0 + b_1, y_0 - a_1)$到$(x_0, y_0)$进入线段$l_n$。因此，在该线段上，只有其末端才是整数点。

从这里已经可以看出，在任何直线 $l_n$ 上（如果其上至少有一个整数点），相邻整数点之间的间隙是相同的：沿 $Oy$ 轴的 $a_1$ 单位和沿 $Ox$ 轴的 $b_1$ 单位。这尤其适用于直线$l_0$。由于$(-b, a)$属于$l_0$，因此有$b = db_1$、$a = da_1$，其中$d$是整数。但按照惯例，数字 $a$ 和 $b$ 互质。所以，$d = 1$，即$a = a_1$，$b = b_1$。引理1得到证明。

F204。航天器沿着抛物线轨迹接近月球，几乎接触到月球表面。在与月球最大程度融合的时刻，霜推进器短时间开启，飞船进入绕月圆形轨道。确定结冰期间船速的变化。月球半径为$R_\pi = 1740$公里，在月球表面自由落体的加速度为$g_\pi = 1,7 \text{ m/c}^2$。

注：在抛物线轨迹上，船的总能量为零。

当航天器沿抛物线轨迹运动时，沿轨迹任意点满足以下条件：

$$E_{\text{полн}} = E_{\text{пот}} + E_{\text{кип}} = 0,$$

那是

$$\gamma \frac{m M_\pi}{R} = \frac{mv^2}{2},$$

其中$M_\pi$是月球的质量，$m$是飞船的质量，$R$是飞船到月球的距离，$v$是飞船在给定点的速度，$\gamma$是引力常数。在最接近月球$R = R_\pi$的时刻（由于轨道几乎接触月球表面，因此与月球半径$R_\pi$相比，我们忽略了轨道高度）。

此时船速最大；让我们从条件中找到它

$$\frac{mv^2_{\text{max}}}{2} = \gamma \frac{M_\pi m}{R_\pi};$$

从这里

$$v_{\text{max}} = \sqrt{2\gamma \frac{M_\pi}{R_\pi}} = \sqrt{2g_\pi R_\pi}$$

（$v_{\text{max}}$是月球的第二逃逸速度）。当船舶在圆形轨道上运动时，船舶的向心加速度是由重力产生的。因此，制动时，船速必须降低至值 $v_1$，由条件确定

$$\frac{mv^2_1}{R_\pi} = \gamma \frac{M_\pi m}{R^2_\pi}$$

（根据牛顿第二定律）。从这里

$$v_1 = \sqrt{\gamma \frac{M_\pi}{R_\pi}} = \sqrt{g_\pi R_\pi}.$$

制动时速度变化

$$\Delta v = v_{\text{max}} - v_1 = g_\pi R_\pi (\sqrt{2} - 1) \approx 700 \text{ m/c}.$$

在我们的例子中，来自堆栈套接字的兔子在点 $B$ 处是圆形的。它在点 $C$ 处也将是圆的，该点比点 $B$ 距离堆栈更远。这意味着在我们的例子中太阳的角度大小大于堆栈的角度大小。但在这种情况下，从图 13、$\theta$可以看出，光线进入屏幕的每个点，并不是从太阳或其最小图像的所有点进入，而是仅从屏幕上与玻璃处于相同立体角$\Omega$的点可见的那些点进入。因此，由于从堆叠反射的光线而导致的屏幕上点的照明与从屏幕上的一点可见玻璃的立体角$\Omega$成正比。对于点 $B$，这个角度等于 $\Omega_1 = \frac{S \cos \alpha_1}{R_1^2}$，其中 $S$ 是堆栈的表面积 (图 14, a)。因此，在一点上加上散射光的照明

$$B \text{ экрана равна } k \frac{S \cos \alpha_1}{R_1^2}, \text{ где } k \text{ — коэффициент пропорциональности.}$$

令 $E_0$ 为屏幕上仅接收漫射光的区域的照度。然后在点 $B$ 处散射光照明的相加为

$$\Delta E_B = 3E_0 - E_0 = 2E_0 = \frac{kS \cos \alpha_1}{R_1^2}. \tag{1}$$

在点 $C$ 处，镜子可见的立体角 (图 14, b) 等于

$$\Omega_2 = \frac{S \cos \alpha_2}{R_2^2}.$$

这意味着如果屏幕在点$C$垂直于太阳光线，那么它在点$C$的照度将相等

$$E_C = E_0 + k\Omega_2 = E_0 + k\frac{S \cos \alpha_2}{R_2^2}.$$

由于在$C$点反射的太阳光线与屏幕表面的法线形成$\beta$角，则

$$E_C = E_0 + k \frac{S \cos \alpha_2}{R_2^2} \cos \beta. \tag{2}$$

对比式（1）和式（2），我们发现

$$E_C = E_0 \left[ 1 + 2 \frac{\cos \alpha_2}{\cos \alpha_1} \left( \frac{R_1}{R_2} \right)^2 \cos \beta \right].$$

由于 $R_2 = R_1/\cos \beta$、$\alpha_1 = 22.5^\circ$、$\alpha_2 = 45^\circ$ 和 $\beta = 45^\circ$，则

F207。一块水冰漂浮在圆柱形容器中的油表面上。整个系统的温度为$0^\circ\text{C}$。当冰融化并且产生的水沉到容器底部时，容器底部的油位和压力将如何变化？

容器底部的压力不会改变。事实上，底部$F$的压力等于容器内容物的重量，并且重量不会改变。因此，压力本身等于$\frac{F}{S}$，其中$S$是容器底部的面积，不会改变。

油位如何变化？设容器内水位高度为$h_3$，油位高度为$h_2$，冰融化前油位高度为$h_1$（图15）。由于冰漂浮并且不接触容器底部，因此第一种情况下底部的压力等于

$$p_1 = \rho_M g h_1.$$

在第二种情况下它是相等的

$$p_2 = \rho_M g \left(h_2 - h_1\right) + \rho_E g h_3$$

（$\rho_M$是油的密度，$\rho_E$是水的密度）。

由压力相等可知

$$\rho_M h_1 = \rho_M \left(h_2 - h_1\right) + \rho_E h_3$$

和

$$h_2 = h_1 - \left(\frac{\rho_B}{\rho_M} - 1\right) h_3.$$

从$\frac{\rho_B}{\rho_M} > 1$开始，然后$h_2 < h_1$。

因此，当冰融化时，油位将会下降。
