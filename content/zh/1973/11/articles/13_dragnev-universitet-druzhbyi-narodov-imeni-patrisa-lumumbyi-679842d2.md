⟦folio 61⟧

大学
各国人民的友谊
以帕特里斯命名
卢姆布斯

在1973年的«Kvant»第4期我们已经讨论过
他们打电话询问人民友谊大学。现在我们将 varnatas 放在介绍中
1973年在这所大学进行数学考试。

物理、数学和自然科学学院
军事科学

选项1
1. 求解方程组：
$$\begin{cases}
x + y + z = 6, \\
xy + yz + xz = 12, \\
xyz = 8.
\end{cases}$$

2. 解决不平等问题
$$x^3 + \log_a x < a^2x^2.$$

3. 解方程
$$\frac{\sin^{10} x + \cos^{10} x}{4} = \frac{\sin^6 x + \cos^6 x}{4\cos^2 2x + \sin^2 2x}$$

4. 侧边的二面角
正四边形帕拉米德的 rah
等于$\alpha$。查找肋骨处的弧角
波罗蜜多的基础。

选项2
1. 完整值是多少$z$
两种表达方式
$(3 + i)z + 1 - 5i$ 和 $z^2 + 1 - 4i$
同时具有实际价值？
2. 解决不平等问题
$$(2^x + 2^{1-x})^{\log_x (x^3 + 1)} \log_x + 1 x - 2 > 1.$$

3. 找到所有的数字$x, y$
满足方程
$$\cos^4 x + \cos^4 y - \frac{1}{\cos^2 x \cos^2 y} = 1.$$

4. 求与横向的弧角
正三角形帕拉酰胺的边，
如果圆弧角位于底边
等于$\alpha$。

选项3
1. 解决不平等问题
$$\sqrt{x + 2a} + \sqrt{x + 2b} < 2\sqrt{x + a + b}.$$

2. 求解方程组：
$$\begin{cases}
5\lg x - 3\lg y = 0, \\
(3x)^{1/g} - (5y)^{1/g} = 0.
\end{cases}$$

3. 找到所有的数字$x, y$
满足方程
$$\sin^2 (x + y) - \cos^2 (x - y) = 1.$$

4. 如果截锥的下底和上底面积之比为 1:18，则求外接半径为$R$的半球的截锥的总表面积（使半球的底面位于截锥的大底上，并且截锥的侧表面和第二底边接触半球）。

工程学院
选项1
1. 解方程
$$(x^2 - 4x)^2 + 2(x - 2)^2 = 43.$$

2. 解决不平等问题
$$(0,125)^x + 2^{2-3x} + (0,5)^{3x+4} < 40,5.$$

3. 解方程
$$1 + \sin x - \cos x = \sin 2x - \cos 2x.$$

4. 底座和其中一个侧面
Paramids 是等边三角形。帕拉酰胺顶部的平面角之一不等于 60°，其值为$\alpha$。如果边长为，求出 Paramid 的体积
它的底数是$a$。

选项2
1. 解决不平等问题
$$x^2 + \frac{1}{x^2} > \frac{17}{4}.$$

2. 解方程
$$\log_x - 1 (2x^3 - 6x^2 - 7x - 1) = 3.$$

3. 解方程
$$\mathrm{tg} x - 2\sqrt{2} \sin x = 1.$$

4. 围绕半径为 $R$ 的球外接的正四边形 paramid 的底边等于 $a$。找到 paramid 的完整表面。
