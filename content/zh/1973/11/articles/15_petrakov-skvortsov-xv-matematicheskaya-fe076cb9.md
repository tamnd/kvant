现在让我们介绍第十五届国际数学奥林匹克竞赛的问题及其简短的解决方案。

任务

1（捷克斯洛伐克。完整解决方案得6分）。 O点位于直线l上； OP1、OP2、…、OPₙ 是单位向量，所有点 P1、P2、…、Pₙ 位于包含 l 的同一平面内，并且都在同一条直线 om l 上。证明如果 n 是奇数，则 |OP₁| + |OP2| + ... + |OPₙ| ≥ 1，其中|OM|表示 OM 向量的长度。

2（波兰，6分）。求在不在同一平面的空间中是否存在有限集合M，使得对于属于M的任意两点A、B，存在另外两个属于M的点C、D，并且AB和CD平行且不重合。

3（斯威尼斯，8分）。最小值为 a² + b²，其中 a 和 b 是实数，方程 x1 + ax3 + bx2 + ax + 1 = 0 至少有一个实数根。

4（南斯拉夫，6分）。士兵必须检查等边三角形区域（包括边界）是否有地雷。其探测器的作用半径等于三角形高的位置。士兵从三角形的一个顶点出现。他应该走哪条路才能考虑名字并完成任务？

5（波兰，6分）。不等于实参 x 的最后一个函数的非空集合 G，其形式为 f(x) = ax + b，其中 a、b 是实数，我们满足以下条件：

a) 若f, g ∈ G，则g f ∈ G，其中(g f)(x) = g(f(x))，即集合G在叠加下是闭集；

b) 如果 f ∈ G，则 f(x) = ax + b，则反函数 f⁻1 ∈ G，其中 f⁻1(x) = x - b/a；

b) 对于任何 f ∈ G，存在 x₁, ..., aₙ - 给定 n 个正数 u q - 给定实数，且 0 < q < 1。最多还有 n 个实数 b₁, ..., bₙ，使得

a) 对于从 1 到 n 的所有 k，aₙ > bₙ；

b) 对于从 1 到 n-1 的所有 k，q < (bₙ+1)/bₙ < 1/q；

b) b₁ + ... + bₙ < (1+q)/(1-q)(a₁ + ... aₙ).

问题解决方案

1. 证明可以通过归纳法来验证。对于 n = 1，该陈述是显而易见的。让它对于某些 n = k 成立。让我们执行从 n = k 到 n = k + 2 的归纳过渡。我们通过按照这些向量与直线 l 的正方向 (图 1) 形成的角度（逆时针方向的缺席角）的递增顺序移动这些向量来选择直线 l 上的方向。向量 OP₁ 和 OP2 + 2 之和是向量 OR，表示为

边长为 $OP_1$ 和 $OP_{k+2}$ 的对角菱形。因此，角度$P_1OR$和$ROP_{k+2}$均不超过$\frac{\pi}{2}$。让$OS = \sum_{i=2}^{k+1} OP_i$。从向量的可见编号可以看出，向量 $OS$ 将包含在角 $P_1OR$ 内，或者包含在角 $ROP_{k+2}$ 内，或者因此，角 $ROS$ 是锐角。总和 $OR + OS$ 由相应平行四边形的对角线 $OT$ 表示。在三角形$OST$中，$OST$是钝角。因此，边$OT$最大，即$|OT| > |OS|$。但通过归纳假设$|OS| \geq 1$。所以，$\sum_{i=1}^{k+2} OP_i = |OT| \geq 1$。

2. 很容易检查这样的集合将是例如两个具有共同中心但位于不同平面的正六边形的顶点集合。

不难证明，具有所需属性的集合中的元素数量可能非常大。找出这样一个集合中可能的最小元素是什么（在上面的示例中至少有 10 个）是很有趣的。元素有可能是奇数吗？

3. 注意到$x = 0$不是这个方程的根，我们将其转换为$x^2 + ax + b + \frac{a}{x} + \frac{1}{x^2} = 0$或$(x + \frac{1}{x})^2 + a(x + \frac{1}{x}) + b - 2 = 0$的形式。

很容易验证对于任何实数$x$，不等式$x + \frac{1}{x} \geq 2$都是有效的。为了固定$x_0$，原始方程的根等于$x_0$的数对$(a, b)$的集合由线性方程$y_0^2 + ay_0 + b - 2 = 0$确定，其中$y_0 = x_0 + \frac{1}{x_0}$。这组对由坐标平面 $(a, b)$ 上的素数表示。由于在此平面中，表达式 $a^2 + b^2$ 可以在几何上使用，因此我们线上的点 $(a, b)$ 的菠萝值 $a^2 + b^2$ 将等于从原点到所讨论的线的垂线长度的平方。

很容易算出，在$y_0^2 = \left(x_0 + \frac{1}{x_0}\right)^2 \geq 4$处等于$\rho = \frac{(y_0^2 - 2)^2}{1 + y_0^2}; \rho \geq \frac{4}{5}$。不难证明$\frac{(t - 2)^2}{1 + t} \geq \frac{4}{5}$对于$t \geq 4$、对于$t = 4$是相等的。因此，对于所有可能的实根$x_0$，$a^2 + b^2$的值不小于$\frac{4}{5}$。注意到$x_0 = 1$是原始方程在$a = -\frac{4}{5}, b = -\frac{2}{5}$处的根，我们发现$\frac{4}{5}$是$a^2 + b^2$的最小原始值。

4. 让士兵从顶点$A$出来（参见图2处的图）。要检查点 $B$ 和 $C$，它必须位于以这些点为中心、半径为 $\frac{h}{2}$（三角形的高度）的圆弧上。让他先尝试以$B$为圆心的圆弧，然后以$C$为圆心的圆弧。如果我们将到点 $C$ 的路径添加到该路径中，那么问题将归结为通过接近第一条弧找到从 $A$ 到 $C$ 的最短路径。我们留给读者来证明这样的最短路径将是折线$ADC$，其中$D$是从顶点$B$发出的高度的中点。令 $E$ 为线段 $DC$ 与第二条弧的交点。那么路径$ADE$就是检查点$B$和$C$的最短路径。很容易检查三角形的所有点也被检查，即路径$ADE$是互斥的。
