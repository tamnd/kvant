$$(\alpha + \beta)^n x_n = \alpha^n x_n x_0 + \alpha^{n-1} \beta x_{n-1} x_1 + \alpha^{n-2} \beta^2 x_{n-2} x_2 + \dots + \beta^n x_0 x_n.$$

这里$\lambda, \alpha, \beta$给出正数。分配$x_n$并找出$n$的值$x_n$最大。

让我们写下定义$n > 1$前几个值的$x_n$的等式（使用条件$x_0 = 1$）：

$$[(\alpha + \beta)^2 - \alpha^2 - \beta^2] x_2 = \alpha \beta x_1^2,$$

$$[((\alpha + \beta)^3 - \alpha^3 - \beta^3] x_3 = \alpha^2 \beta x_2 x_1 + \alpha \beta^2 x_1 x_2,$$

$$[((\alpha + \beta)^4 - \alpha^4 - \beta^4] x_4 = \alpha^3 \beta x_3 x_1 + \alpha^2 \beta^2 x_2^2 + \alpha \beta^3 x_1 x_3.$$

从这里我们发现（使用条件$x_1 = \lambda$）：

$$x_2 = \frac{\lambda^2}{2}, \quad x_3 = \frac{\lambda^3}{2 \cdot 3}, \quad x_4 = \frac{\lambda^4}{2 \cdot 3 \cdot 4}.$$

很自然地假设

$$x_n = \frac{\lambda^n}{n!},$$

其中$n! = 1 \cdot 2 \cdot \dots \cdot n$。让我们通过归纳证明这对于所有$n$都成立（如果我们按照惯例假设$0! = 1! = 1$，那么公式$x_n = \frac{\lambda^n}{n!}$对于$n = 0$和$n = 1$都成立）。

$$[((\alpha + \beta)^n - \alpha^n - \beta^n] x_n = \sum_{k=1}^{n-1} \alpha^n - k \beta^k x_{n-k} x_k = \sum_{k=1}^{n-1} \frac{\alpha^n - k \beta^k \lambda^n - k \lambda^k}{(n-k)! k!} = \frac{\lambda^n}{n!} \sum_{k=1}^{n-1} C_n^k \alpha^n - k \beta^k = \frac{(\alpha + \beta)^n - \alpha^n - \beta^n}{n!} \frac{\lambda^n}{n!}$$

$$C_n^k = \frac{n!}{k!(n-k)!}$$

释放活塞，建立平衡后，气体所占据的体积将增加一倍。气体的温度和压力将如何变化？气缸、活塞和弹簧的热容很小。

根据热力学第一定律，传给气体的热量Q等于气体内能的变化ΔU与其所做的功A之和：

$$Q = \Delta U + A.$$ (1)

但在这种情况下，容器是恒温的并且 Q = 0。因此，

$$\Delta U + A = 0.$$ (2)

也就是说，气体的做功是通过降低其内能来完成的，所以我们可以立即说气体的温度降低了。

首先设气体温度$T_1$、压力$P_1$、体积$V_1$，活塞释放并建立平衡后，气体参数变为相应的$T_2$、$P_2$、$V_2$、$V_2 = 2V_1$（根据条件）。

理想气体内能的变化与气体温度的变化成正比，等于

$$\Delta U = c_v (T_2 - T_1),$$ (3)

其中 $c_v$ 是定体积下 1 摩尔气体的温度。

此外，气体所做的功等于变形弹簧势能的变化：

$$A = \frac{kx^2}{2}$$ (4)

（x 是活塞位移）。

让我们用气体参数来表达$\frac{kx^2}{2}$的值。

由于活塞建立平衡后处于静止状态，因此弹簧力$F = kx$等于气体压力$P_2S$（S为活塞的表面积）：

$$kx = P_2S.$$ (5)

气体的压力与其内部气态的温度有关。对于一摩尔气体

$$P_2V_2 = RT_2.$$ (6)

由于气体在分布过程中体积增大，气体体积变化为$Sx$，然​​后为$V_2 = 2Sx$，因此，

$$2P_2Sx = RT_2.$$ (7)

考虑到对应关系（5）和（7），我们可以写出

$$kx = \frac{RT_2}{2x}$$ (8)

$$kx^2 = \frac{RT_2}{2}.$$ (9)

因此，气体所做的功等于

$$A = \frac{kx^2}{2} = \frac{RT_2}{4}.$$ (10)

我们将表达式（3）和（10）代入等式（2）：

$$c_v (T_2 - T_1) + \frac{1}{4}RT_2 = 0.$$

从这里

$$T_2 = T_1 \frac{1}{1 + \frac{1}{4} \frac{R}{c_v}}.$$ (11)

事实上，$T_2$小于$T_1$。

现在让我们看看气体压力如何变化。根据气体状态方程，初始气体压力$P_1$、其体积$V_1 = \frac{V_2}{2}$和温度$T_1$之间有以下关系：

$$P_1 \frac{V_2}{2} = RT_1.$$

将此等式除以等式 (6)，我们得到

$$\frac{P_1}{P_2} = 2 \frac{T_1}{T_2} = 2 \left(1 + \frac{1}{4} \frac{R}{c_v}\right),$$

$$P_2 = \frac{P_1}{2 \left(1 + \frac{1}{4} \frac{R}{c_v}\right)}$$

压力也降低了。

F168。六分钟铅笔沿水平面无声，如图图16所示。铅笔与平面之间的时间系数$\alpha$取什么值时，铅笔会沿平面滑动而不愈合？

有两个力从平面两侧作用在移动的铅笔上：平面的法向反作用力 $N$ 和摩擦力 $F_{TP}$。由于铅笔不应沿垂直方向移动，因此力 $N$ 的绝对值等于力：

$$N = mg.$$

摩擦力等于$F_{TP} = \alpha N = \alpha mg$。

考虑铅笔开始滚动、绕边缘$A$转动的那一刻。在本例中，两个力（力 $N$ 和力 $F_{TP}$）均施加到边 $A$。如果这些力的相等的力$R$经过铅笔重心下方，即铅笔轴线下方，那么这个力相对于铅笔轴线的力矩会导致铅笔旋转。如果力 $R$ 通过轴上方，则铅笔将不会旋转。

因此，铅笔不旋转的条件：

$$tg \beta = \frac{N}{F_{TP}} > tg 60^\circ,$$

或者

$$\frac{mg}{\alpha mg} > \sqrt{3}.$$

从这里我们可以找到摩擦系数应该是多少：

$$\alpha < \frac{1}{\sqrt{3}}.$$

许多给我们写信的读者通过尝试不与平面而是与铅笔相关的坐标系来解决这个问题。这是一个非惯性坐标系，铅笔在其中仍然受到很强的惯性作用。

$$F_{\pi} = ma,$$

其中$a$是铅笔相对于平面的加速度。

由于该加速度向铅笔施加了平面上的摩擦力 $F_{\pi} = \alpha mg$，然​​后是 $a = \alpha g$，因此是 $F_{\pi} = m\alpha g$。铅笔绕边缘$A$（瞬时旋转轴）旋转，如果相对于该点的力矩$F_{\pi}$大于重物的力矩（图17），即，如果

$$F_{\pi} \cdot \frac{a \sqrt{3}}{2} > \frac{1}{2} mg,$$ 或

$$\alpha mg \sqrt{3} > mg.$$
