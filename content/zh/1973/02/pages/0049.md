问题解决方案

M146—M150; F164—F169

M146。 a) 在正七边形的顶点处，通过具有相同颜色标记的顶点的一部分来考虑（如果绘制了颜色，则多边形将具有偶数条边）。

a) 很明显，在七个顶点中，他肯定会找到两个相邻顶点的标记颜色相同（如果绘制了颜色，则多边形的边数将为偶数）。

让我们用 $A_1$ 和 $A_2$ 表示这些顶点。我们可以假设芯片的侧面是白色的（图1）。注意，有三个顶点，每个顶点与顶点$A_1$和$A_2$一起是一个等边三角形；让我们用 $A_0$、$A_3$ 和 $B$ 来表示它们。如果其中一个包含白色碎片，则相应的三角形 - $A_0A_1A_2$、- $A_3A_1A_2$ 或 $BA_1A_2$ - 就是所需的三角形。如果所有三个顶点都有黑色碎片，则三角形 $A_0A_3B$ 就是所需的三角形。

同样的推理对于任何具有奇数$n \geq 5$的正则$n$边形都有效（$A_0$、$A_3$的角色由与$A_1$和$A_2$相邻的顶点扮演，而$B$的角色是较大弧$A_1A_2$的中点）。

6) 对于$n = 8$，该陈述是错误的。 图2,b,c,e)是黑白筹码的排列示例，其中相同颜色的三个筹码不位于等边三角形的顶点；其他示例也是可能的。

b) 答案：对于$n = 5$、$n = 7$ 和$n \geq 9$，该陈述成立。

图 2 中描述的示例表明该陈述对于 $n = 3, 4, 6, 8$ 是正确的。我们在上面证明了对于$n = 5$、$n = 7$和大奇数$n$是正确的。让我们证明这对于所有 $n \geq 9$ 都是正确的。

假设对于正则 $n$ 边形顶点处的标记的一定距离，该陈述为假。首先，很明显，在某处将有两个相邻顶点具有相同颜色的碎片 - 如果碎片的颜色是黑色，那么所需的等边三角形已经在连续顶点的根部中找到。我们可以假设这些是带有大色块（图 3）的顶点$A_4$和$A_5$。然后依次

| 我们正在考虑 | 我们得出结论 |
| :--- | :--- |
| $A_3A_4A_5$ 和 $A_4A_5A_6$ | $A_3$ 和 $A_6$ 为黑色 |
| $A_3A_6A_9$ | $A_9$ – 白色 |
| $A_1A_5A_9$ 和 $A_5A_7A_9$ | $A_1$ 和 $A_7$ 为黑色 |
| $A_1A_2A_3$ 和 $A_6A_7A_8$ | $A_2$ 和 $A_8$ - 白色 |
| $A_2A_5A_8$ | 矛盾 |
