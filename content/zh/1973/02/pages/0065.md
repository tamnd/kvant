例 11. 求解方程

$$\sin x + \sqrt{3} \cos x = \sqrt{2 + \cos 2x + \sqrt{3} \sin 2x}.$$

(13)

解决方案。由于等式右边非负，因此必须满足条件

$$\sin x + \sqrt{3} \cos x \geq 0.$$

(14)

如果我们通过将方程（13）两边同时平方来去掉根式，我们得到方程

$$\sin^2 x + 3 \cos^2 x + 2 \sqrt{3} \sin x \cos x = 2 + \cos 2x + \sqrt{3} \sin 2x,$$

方程之后的形式为

$$\cos 2x = \cos 2x.$$

(15)

我们收到了同样的手势。然而，这并不意味着$x$的所有值都满足原始方程，因为方程（15）只是方程（13）的结果。如果满足条件(14)，则等式(13)和(15)等价。因此，方程（13）的解都是满足不等式（14）的$x$的值，并且只有这些值。解决不等式（14）并不困难。

答案：$-\frac{\pi}{3} + 2\pi n \leq x \leq \frac{2\pi}{3} + 2\pi n$。

评论。有几种方法可以得到这个答案。我们有$2 + \cos 2x + \sqrt{3} \sin 2x = \left[ 1 + \cos \left( 2x - \frac{\pi}{3} \right) \right] = 4 \cos^2 \left( x - \frac{\pi}{6} \right)$，因此原方程采用$\cos \left( x - \frac{\pi}{6} \right) = \left| \cos \left( x - \frac{\pi}{6} \right) \right|$的形式。我们再次讨论条件（14）。

练习

解方程：
1. （MIPT，1969）。 $\sin^4 x + \sin^3 x \cdot \cos x + \sin^2 x \cos^2 x + \sin x \cdot \cos^3 x + \cos^4 x = 1$。
2. $\sin^3 x (1 + \text{ctg} x) + \cos^3 x (1 + \text{tg} x) = 2 \sqrt{\sin x \cos x}$.

4. $\cos \frac{4x}{3} = \cos^2 x$.
