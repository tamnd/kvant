**M147.** 让我们证明，如果外接圆的四边形 ABCD 使得圆在 A 点和 C 点的切线相交于重纬线 BD 的延长线上，则
a) B 点和 D 点的切线沿重纬 AC 的延长线相交；
b) 四边形内角 A 和 C 的三等分线相交于重纬线 BD（以及交点 B 和 D - 在 AC 上）。

a) 设A、B、C为圆上的三点，K为A、C点切线的交点。我们求直线BK与圆的交点D的位置的条件(图4)。

$$\triangle ABK \sim \triangle DAK: \text{угол } K \text{ у этих треугольников общий, а } \triangle BAK = \triangle ADK, \text{ поскольку каждый из них изменяется положенной дуги } AB. \text{ Поэтому}$$

$$\frac{AB}{AD} = \frac{BK}{AK} = \frac{AK}{DK}$$

（同时我们证明了著名定理：$AK^2 = BK \cdot KD$）。

同样$\triangle CBK \sim \triangle DCK$，因此

$$\frac{BC}{CD} = \frac{BK}{CK} = \frac{CK}{DK}$$

（同时我们证明了著名定理：$AK^2 = BK \cdot KD$）。

(1) 和 (2) 的右边相等，因为 $AK = CK$，因此

$$\frac{AB}{BC} = \frac{AD}{CD}$$

（请注意，当 D 点沿圆弧从 A 移动到 C 时，比率 $AD/CD$ 呈单调增加。事实上，通过应用于 $\triangle ACD$ (图 5) 的正弦定理）

$$\frac{AD}{CD} = \frac{\sin C}{\sin A} = \frac{\sin (180^\circ - D - A)}{\sin A} = \sin (180^\circ - D) \cdot \text{ctg } A - \cos (180^\circ - D);$$

这里$180^\circ - D$是一个常数，$\sin (180^\circ - D) > 0$，$\text{ctg } A$随着$A$从0增加到$180^\circ - D$，即当D点从C移动到A时，单调递减。由此可见，条件（3）对应于D点位置的一个定义（对于给定的A、B和C）。

因此，条件(3)对于B、D点和A、C点构造的切线的交点位于同一条直线上不仅是必要的，而且是充分的。

同理，可证明B、D点所画切线与AC线相交的充要条件可写为：

$$\frac{BA}{DA} = \frac{BC}{DC}.$$

但条件(3)和$(3')$显然是一致的：

$$AB \cdot CD = BC \cdot AD.$$

这使得问题a)的陈述变得显而易见。
