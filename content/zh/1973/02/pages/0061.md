⟦folio 59⟧

解决方案。在这种情况下，让解由该方程关于 sin x、cos x 的对称性来表示。显式地识别 sin x 和 cos x 的最简单对称多项式（表达式 sin x + cos x, sin x cos x），我们将方程写成以下形式

$$(\sin x + \cos x) - 4 \sin x \cdot \cos x + \sin x \cdot \cos x (\sin x + \cos x) = 2.$$

令 sin x + cos x = u；那么 $u^2 - 1 = 2 \sin x \cdot \cos x$ 且方程具有以下形式

$$u (u^2 - 4 u + 1) = 0,$$

从哪里$u_1 = 0, u_2 = 2 + \sqrt{3}, u_3 = 2 - \sqrt{3}$。

方程 sin x + cos x = u 可以很容易地求解，并且因为 |u| = |sin x + cos x| = |\sqrt{2} \cos \left( x - \frac{\pi}{4} \right)| \leqslant \sqrt{2}，则根$u_2 = 2 + \sqrt{3}$不合适。

答案：$x = -\frac{\pi}{4} + k\pi; x = \frac{\pi}{4} \pm \arccos \frac{2 - \sqrt{3}}{\sqrt{2}} + 2l\pi$。

下一组示例表明，要成功解决应用考试中提出的问题，仅仅能够将方程简化为已知类型之一（方程可简化为单个三角函数、齐次、对称等）是不够的。

实施例 4（MIPT，1970）。解方程

$$\sin x + 2 \cos x = \cos 2x - \sin 2x.$$

解决方案。使用公式 sin 2x = 2 sin x cos x 和 cos 2x = $\cos^2 x - \sin^2 x = 1 - 2 \sin^2 x$ 将方程 (1) 传递给参数 x，我们得到

$$\sin x + 2 \sin^2 x + 2 \cos x + 2 \sin x \cos x - 1 = 0.$$

使用所谓的通用标准 $u = \mathrm{tg} \frac{x}{2}$，方程 (2) 可以简化为 u 的代数方程，用 u 表示 sin x 和 cos x。很容易看出，在这种情况下我们得到方程

$$3 u^4 + 2 u^3 - 6 u^2 - 6 u - 1 = 0.$$

我们不会找到这个方程的根，虽然这可以做到，但我们将尝试根据方程左侧的因式分解找到一个更短的解。

方程 (2) 的根 sin x = -1（在本例中 cos x = 0），因此可以对方程左侧进行因式分解：

$$(1 + \sin x)(2 \sin x + 2 \cos x - 1) = 0.$$

答案：$x = -\frac{\pi}{2} + 2k\pi; x = -\frac{\pi}{4} + (-1)^n \arcsin \frac{1}{2 \sqrt{2}} + \pi n$。

评论。应该强调的是，因式分解方法与其他方法相结合是求解三角方程最有效的例子之一。
