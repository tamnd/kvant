⟦folio 25⟧

证明。让我们将$a_k = (k+1)^q$、$k=0, 1, \dots, n-1$代入恒等式(7)，首先考虑$n \leq q+1$的值。由于在这种情况下$C_p^n = 0$对应于$p > q+1$，因此在条件$1 \leq n \leq q+1$下从(7)得出公式(8)。然而，在右边我们有关于 $n$ 的 $q+1$ 次多项式，没有虚拟项，因此它们对于所有 $n$ 必须一致。事实上，否则它们的差异是一个次数不高于$q+1$的多项式——我们有$q+2$实根：$0, 1, 2, \dots, q+1$。

尝试自己证明这个多项式实际上也为零*)。

式(8)将总和$S_q(n)$表示为组合$C_n^1, C_n^2, \dots, C_n^{q+1}$的线性组合。

$$S_0(n) = C_n^1,$$
$$S_1(n) = C_n^1 + C_n^2,$$
$$S_2(n) = C_n^1 + 3C_n^2 + 2C_n^3,$$
$$S_3(n) = C_n^1 + 7C_n^2 + 12C_n^3 + 6C_n^4,$$
$$S_4(n) = C_n^1 + 15C_n^2 + 50C_n^3 + 60C_n^4 + 24C_n^5,$$

ETC。

我们让读者探索这些组合的系数之间出现的奇怪模式，例如资本系数的形成规律。

让我们用几个关于和 $S_q$ 的问题来结束。

练习
1. 表明
$$S_1 = S_1,$$
$$2(S_1)^2 = 2S_3,$$
$$4(S_1)^3 = 3S_5 + S_3,$$
$$8(S_1)^4 = 4S_7 + 4S_5,$$

*) 如果你没有做到这一点，我们可以在 «Kvant» No. 12, 1972, page 37 找到证明

一般来说，在$k=1, 2, 3, \dots$

$$2^{k-1}(S_1)^k = C_k^1 S_{2k-1} + C_k^3 S_{2k-3} + C_k^5 S_{2k-5} + \dots,$$

右边表达式的最后一项等于$S_k$或$kS_{k+1}$，取决于$k$是奇数还是偶数。

2. 表明

$$3S_2 = 3S_2,$$
$$6S_2S_1 = 5S_4 + S_2,$$
$$12S_2(S_1)^2 = 7S_6 + 5S_4,$$
$$24S_2(S_1)^2 = 9S_8 + 14S_6 + S_4$$

一般来说，在$k=1, 2, 3, \dots$

$$3 \cdot 2^{k-1}S_2(S_1)^{k-1} = (C_k^0 + 2C_k^1)S_{2k} + (C_k^2 + 2C_k^3)S_{2k-2} + \dots,$$

右侧表达式的最后一项等于 $(k+2)S_{k+1}$ 或 $S_k$，具体取决于 $k$ 是奇数还是偶数。

3. 表明

$$S_3 = (S_1)^2,$$
$$S_5 = (S_1)^2 \cdot \frac{4S_1 - 1}{3},$$
$$S_7 = (S_1)^2 \cdot \frac{6(S_1)^2 - 4S_1 + 1}{3},$$

一般来说，$S_{2k-1}$（其中$2k-1 \geq 3$）是$S_1 = \frac{n(n+1)}{2}$的$k$次多项式，可被$(S_1)^2$整除。

4. 表明

$$S_4 = S_2 \cdot \frac{6S_1 - 1}{5},$$
$$S_6 = S_2 \cdot \frac{12(S_1)^2 - 6S_1 + 1}{7},$$
$$S_8 = S_2 \cdot \frac{40(S_1)^3 - 40(S_1)^2 + 18S_1 - 3}{15},$$

一般来说，$\frac{S_{2k}}{S_2}$是$S_1$的$k-1$次多项式。

5. 证明$k \geq 1$（但不是$k=0$）

$$S_k (-x-1) = (-1)^{k-1}S_k(x).$$

6. 求总和：$1 + 27 + 125 + \dots + (2n-1)^3$。

7. 求总和：$2^2 + 5^2 + 8^2 + \dots + (3n-1)^2$。
