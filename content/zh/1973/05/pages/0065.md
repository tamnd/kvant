9. 通话打开后，电阻$R$流过电流$i = \frac{u}{R}$，其中$u$是电容两端的电位差，等于$\frac{q}{C}$。由于我们对电荷的微小变化感兴趣，因此我们不会考虑电流和电势差都取决于时间。在时间$\Delta t$期间，电容器的电荷将减少$i \Delta t$。然后

$$\Delta q = i \Delta t = \frac{u \Delta t}{R} = \frac{q \Delta t}{RC}.$$

从这里

$$\Delta t = \frac{\Delta q}{q} RC = 10^{-3} RC.$$

10. 当撞击方块时，喷射流改变运动方向，因此动量：$\Delta (mv) = F_1 \Delta t$。

流体$\Delta (mv)$在时间$\Delta t$期间的动量变化是由于高度$h$处的水质量$\rho Sv \Delta t$将垂直速度从$v_1$改变为0，即

$$\Delta (mv) = \rho Sv v_1 \Delta t.$$

从能量守恒定律

$$\frac{\mu v_1^2}{2} + \mu gh = \frac{\mu v^2}{2} (\mu - \text{масса небольшой порции воды}) \text{ найдем } v_1 = \sqrt{-2gh + v^2}.$$

那么强度就是$F_1 = \rho Sv v_1 = \rho Sv \sqrt{v^2 - 2gh}$。每个疤痕作用在块上的力大小相同。由于总共有$N$个痂，那么总强度

$$F = N \rho Sv \sqrt{v^2 - 2gh}.$$

由块$P = F$的平衡条件可得：

$$P = N \rho Sv \sqrt{v^2 - 2gh}.$$

最后我们得到

$$h = \frac{v^2}{2g} \left[ 1 - \left( \frac{P}{\rho SNv^2} \right)^2 \right].$$

11. 假设电容器已经充电，其两端的电位差等于$U$。然后，当看涨期权下一次平仓至位置$I$时，在初始时刻，电流$I_1 = \frac{E_1 - U}{R_1}$流经电阻$R_1$。在接通期间，电容器的电荷将改变值$I_1 \tau$，其中$\tau$是开关时间。当呼叫关闭到位置 2 时，将收到$I_2 = \frac{E_2 - U}{R_2}$ 的电流。由于$U$是稳态电压，因此必须满足关系式$I_1 \tau = -I_2 \tau$，即经过两次开关后，电容器上的电荷保持不变：

$$\frac{E_1 - U}{R_1} = -\frac{E_2 - U}{R_2}.$$

从这里

$$U = \frac{E_2 R_1 + E_1 R_2}{R_1 + R_2}.$$

电容器充电

$$q = CU = C \frac{E_2 R_1 + E_1 R_2}{R_1 + R_2}.$$
