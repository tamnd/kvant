⟦folio 34⟧

图 6.

第$n$行。数字$a$和$b$没有给我们，但我们知道$x + d_n = a + b$，$x = d_n + (a - d_n) + (b - d_n)$。从$b + d_{n-1} = d_n + b_n$开始，然后$b - d_n = b_n - d_{n-1}$。同样地

$$b_n - d_{n-1} = b_{n-1} - d_{n-2} = \dots = b_1 - d_0.$$

因此，$b - d_n = b_1 - d_0$。完全一样

$$a - d_n = a_n - c_{n-1} = a_{n-1} - c_{n-2} = \dots = a_1 - c_0.$$

所以，$x = d_n + (a_1 - c_0) + (b_1 - d_0)$。

因此，要确定$x$，除了$d_n$之外，您还需要知道第一行和零行中的4个数字$a_1, b_1, c_0$和$d_0$。

少于四个数字可以通过吗？

在所表达的情况下（在$n = 0$），有可能：然后$x = a_1 + b_1 - d_0$（参见图7），并且，除了$d_0$之外，只知道两个数字（$a_1$和$b_1$）就足够了。

对于$n \geq 1$来说，少于四个数字是不可能的，除了$d_n$之外，你还需要知道数字$a_1, b_1, c_0$和$d_0$：如果至少知道其中一个数字，那么即使第一行和零行中的所有其他数字的值也无法确定$x$。让我们证明一下。

图 7.

例如，假设数字 $a_1$ 未知（参见 图 6）。那么没有什么可以阻止你任意设置它。如果数字 $d_n$ 未知，这将是有意义的。在这种情况下，第一行和零行的数字没有任何对应关系 - 它们可以任意分配给所有内容，并且可以从它们确定所有其他数字（首先在第二行，然后在第三行，等等）。此外，$d_n = P - N$，其中$P$是$a_1$和$b_1$之间的第一行数字之和（不包括$a_1$和$b_1$本身），$N$是$c_0$和$d_0$之间的零线数字之和$c_0$和$d_0$）；等式$d_n = P - N$很容易通过$n$归纳证明；在这种情况下，您需要使用之前导出的公式$x = d_n + (a_1 - c_0) + (b_1 - d_0)$。

因此，$d_n = P - N$是连接$d_n$与第0行和第1行的数字的唯一匹配；不包括$a_1$。这意味着，知道$d_n$以及除$a_1$之外的第0行和第一行的所有数字，我们无法确定$a_1$；反之，可以任意指定。但是通过固定$b_1, c_0, d_0$和$d_n$并赋予$a_1$不同的含义，我们将得到$x$不同的含义。

因此，对于给定$d_n$确定$x$而言，$a_1, b_1, c_0$和$d_0$的知识是必要且充分的。

F178。在边长为1厘米的密闭容器中，有$n$个气体分子。立方体的壁是罂粟花状的，因此气体分子一旦到达壁上，就会在其上停留 $10^{-2}$ 秒。估计在从一堵墙飞到另一堵墙的时间 $t$ 时，墙上有多少气体分子：

$$\frac{n_1}{n_2} = \frac{\tau}{t}.$$

由于$n_1 + n_2 = n$，那么

$$\frac{n_1}{n} = \frac{\tau}{t + \tau}.$$

从这里

$$n_1 = n \frac{\tau}{t + \tau} = n \frac{1}{1 + \frac{t}{\tau}}.$$

让我们估计$t$的值。分子量为$\mu$的气体分子在温度$T^\circ$ K下的均方根速度等于

$$\bar{v} = \sqrt{\frac{3RT}{\mu}}.$$
