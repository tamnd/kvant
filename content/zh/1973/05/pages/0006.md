找到椭圆的半长轴。
事实上，对于质点撞击椭圆的顶点 $M_1$ 或 $M_2$ 之一（即穿过远地点或近地点）的时刻，等式 $E = E_0$ 给出

$$\frac{v_1^2}{2} - \gamma \frac{m_0}{r_1,2} = \frac{v_0^2}{2} - \gamma \frac{m_0}{r_0},$$

(4)

等式 $L = L_0$ 给出

$$mv_1,2r_1,2 = mv_0r_0 \sin \alpha_0.$$

(5)

从式（4）和（5）中消去$v_{1,2}$，我们得到$r_{1,2}$的二次方程：

$$\left( \frac{v_0^2}{2} - \gamma \frac{m_0}{r_0} \right) r_{1,2}^2 + \gamma m_0 r_{1,2} - \frac{v_0^2 r_0^2 \sin^2 \alpha_0}{2} = 0.$$

(6)

该方程的两个根$r_1$和$r_2$给出了远地点和近地点的值$r_{1,2}$。由于椭圆的长半轴为 $a = \frac{1}{2} (r_1 + r_2)$，则根据 (6) 的 Vieta 定理可得

$$a = - \frac{\gamma m_0}{2 \left( \frac{v_0^2}{2} - \gamma \frac{m_0}{r_0} \right)} = \frac{\gamma m_0 r_0}{2 \gamma m_0 - r_0 v_0^2}.$$

(7)

因此，对于固定质量的吸引中心，质点椭圆轨迹的半长轴由其初始位置（$r_0$）和初始速度值（$v_0$）确定，并且与该速度的方向无关。

3. 从初始位置到指定位置。
“安全”椭圆

我们来解决下面的问题。
为了使质点从初始位置$M_0$移动到给定位置$M$，必须在给定值$v_0$报告初始速度的哪个方向？

点$M$必须位于椭圆上，因此初始初速度意味着找到

这是椭圆在点 $M_0$ 处的切线方向。这可以通过使用椭圆的光学特性来完成，根据椭圆的光学特性，初始速度必须沿着与角度 ($r_0, r'$) (图 2) 相邻的角度的二切线定向（在一个方向或另一个方向），其中 $r_0$ 和 $r'$ 是从焦点到点 $M_0$ 绘制的半径向量。

椭圆的一个焦点已知（与点 $O$ 重合），另一个需要确定。显然，点$M_0$和$M$到该焦点的距离$r'$和$r'$满足条件

$$r_0 + r' = 2 a,$$

$$r + r' = 2 a.$$

由此可见

$$r' = 2 a - r_0$$ 和 $$r' = 2 a - r,$$

即$r_0$和$r'$由点$M_0$和$M$的位置以及初速度的大小满足。因此，所需的焦点位于两个圆的交点，两个圆的圆心分别为 $M_0$ 和 $M$，半径等于相应的 $r'$ 和 $r'$。

如果距离为$M_0 M > r' + r' = 4 a - r_0 - r$，则问题无解，因为圆不相交。

如果$M_0 M < r' + r'$，那么上面的圆将有两个交点$F_1$和$F_2$，如图2所示，问题将有两个解。
