⟦folio 24⟧

现在让我们使用这样一个事实
$$1 - C_{m+1}^1 + C_{m+1}^2 - \cdots + (-1)^{m+1} C_{m+1}^{m+1} = 0$$
因此
$$C_{m+1}^2 - C_{m+1}^3 + \cdots + (-1)^{m+1} C_{m+1}^{m+1} = C_{m+1}^1 - 1 = m.$$
还注意到
$$C_{m+1}^k \frac{m-k+1}{m+1} = C_{m}^k$$
并利用运算*的性质(4)，我们得到$S_m(n)$的以下表达式：
$$S_m(n) = \frac{n^{m+1} + nm}{m+1} + [C_m^2 S_{m-2}(n) - C_m^3 S_{m-3}(n)]^*.$$
将(3)中的$q = m-1$取入，发现方括号内的表达式等于$mS_{m-1}(n) - n^m$，因此，$S_m(n) = \frac{n^{m+1} + nm}{m+1} + [mS_{m-1}(n) - n^m]^* = \frac{n^{m+1} + nm}{m+1} + mS_{m-1}^*(n) - \frac{n^{m+1} - n}{m+1} = n + mS_{m-1}^*(n).$
因此，(5) 对于 $q = m$ 也成立。定理已被证明。
例子。假设你知道
$$S_3(n) = \frac{1}{4} (n^4 + 2n^3 + n^2).$$
让我们找到 $S_4(n)$ 的表达式：
$$S_4(n) = n + 4S_3^*(n) = n + (n^4 + 2n^3 + n^2)^* = n + \frac{n^5 - n}{5} + 2 \frac{n^4 - n}{4} + \frac{n^3 - n}{3} = \frac{n^5}{5} + \frac{n^4}{2} + \frac{n^3}{3} - \frac{n}{30}.$$
§3.一般公式
然而，牛顿二项式所能给出的远不止第 1 节中证明的恒等式 (3)。

考虑以下变换（假设 m 和 n 为自然数）：
$$m^n - 1 = [(m-1) + 1]^n - 1 = (m-1) C_n^1 + (m-1)^2 C_n^2 + \cdots + (m-1)^n C_n^n.$$
让$m \neq 1$。将恒等式两边除以$m-1$，我们得到
$$1 + m + m^2 + \cdots + m^{n-1} = C_n^1 + (m-1) C_n^2 + \cdots + (m-1)^{n-1} C_n^n.$$ (6)
这种等式对于所有自然的$m$和$n$都是成立的，包括$m=1$（在这种情况下它非常印度）。由于左侧和右侧都有相对于 $m$ 次数为 $n-1$ 的多项式，因此只有当多项式完全相同时才可能，即它们的系数一致（在这种情况下，它们都等于 1）。如果我们打开(6)右侧的括号并将$m^k$、$k=0, 1, \ldots, n-1$处的系数等于1，我们就获得了一系列连接biomp系数的恒等式。以下对我们来说很重要：如果（6）中左右的度$m^k$，$k=0, 1, \ldots, n-1$被任何数字$a_0, a_1, \ldots, a_{n-1}$替换，则不会违反等式：毕竟数字$a_k$前面的系数将保持等于1！因此，我们得出以下恒等式，对于任何数字$a_0, a_1, \ldots, a_{n-1}$都成立：
$$a_0 + a_1 + a_2 + \cdots + a_{n-1} = C_n^1 + (a_1 - a_0) C_n^2 + (a_2 - 2a_1) + a_0) C_n^3 + \cdots + [a_{n-1} - C_n^1 a_{n-2}) + C_n^2 a_{n-3} - \cdots + (-1)^{n-1} C_n^n.$$ (7)
定理2.一般情况下的总和$S_q(n)$可以使用以下公式计算
$$S_q(n) = C_n^1 + (2^q - 1) C_n^2 + (3^q - 2 \cdot 2^q + 1) C_n^3 + \cdots + [(q+1)^q - C_q^1 q^q + C_q^2 (q-1)^2 - \cdots + (-1)^q] C_n^{q+1}.$$ (8)
