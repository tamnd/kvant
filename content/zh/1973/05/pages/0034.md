M162。自然数一致 a₁ < a2 < a₃ < ... < aₙ < ... (A) Makova，每个自然数都是序列 (A) 任何句子中的任何一个。

表示为序列 (A) 中两个数字之和，可能相同。

证明对于所有 n = 1,2, ... ， a ≤ n²

考虑序列 (A) 的前 (n−1) 项

a₁, a₂, a₃, ..., aₙ−1, (1)

以及所有可以表示为这些数字中的两个之和的自然数：

a₁ + a₁, a₁ + a₂, a₁ + a₃, ..., a₁ + aₙ−1, a₂ + a₂, a₂ + a₃, ..., a₂ + aₙ−1, aₙ−1 + aₙ−1. (2)

不难计算，这里写的是$\frac{n(n−1)}{2}$两两求和。进一步地，(1)和(2)中的所有数都不同，但它们的总数不超过n。

因此，存在从 1 到 n² 的自然数，其中不包含 (1) 和 (2)。因此，如果序列 (A) 满足问题的条件（每个自然数可以表示为 (A) 中至多两个数的和），则 aₙ ≤ n²。

根据我们的推理，我们可以得到更精确的估计：

aₙ ≤ $\frac{n²+n}{2}$. (3)
