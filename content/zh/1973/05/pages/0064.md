物理

1. 在通有交流电的线圈之间的空间中，会产生交变磁通量。金属片中会感应出脊形电流，因此它们产生的磁场可以补偿通过金属片的磁通量的变化。线圈与铜片排斥，因此线圈彼此排斥。

铁片具有铁磁性；当它被磁化时，薄片和线圈之间会产生张力，该张力比脊电流产生的排斥力更强。

2. 振荡频率$\omega_1$和$\omega_2$略有不同。添加后，出现bennia；周期性收益的幅度增加和减少。这对应于声音的放大和衰减。

3. 对于大扇区，如果在两次添加之间的时间内，完成任意数量的旋转的架子以角度 $\frac{2\pi}{3}$ 或 $\frac{4\pi}{3}$ 转动，则常数可见。全带旋转角度：

$$\varphi_1 = 2\pi k + \frac{2\pi}{3} \quad \text{или} \quad \varphi_2 = 2\pi k + \frac{4\pi}{3}$$

（$k$ - 任何数字）。注意

$$\varphi_1 = 2\pi \frac{3k+1}{3}, \quad \varphi_2 = 2\pi \frac{3k+2}{3},$$

也就是说，$\varphi = \frac{2\pi}{3} n$（其中 $n$ 是任意数字）不能等于 3。

闪烁之间的时间$t = \frac{2\pi}{v}$，因此，磁盘旋转速度

$$\omega = \frac{\varphi}{t} = \frac{v}{3} n$$

4. $\omega^2 = \frac{g \mathrm{tg} \beta}{l |\sin \alpha + \sin \beta|}$.

指定角度$\alpha$和$\beta$只能通过执行质量匹配确定来实现。探索哪些角度$\alpha$和$\beta$可以实现是很有趣的。比如可以有$\alpha = 10^\circ$和$\beta = 80^\circ$吗？

5. $A = \pi r^2 \rho g l \left(h - r + \frac{l r^2}{2 R^2}\right)$.

6. 软化器开始相对于悬浮点以$T = 2\pi \sqrt{\frac{l}{g}}$周期、初速度$v$振荡。相对于地球的初始速度为零。您可以停止悬浮，使软棒相对于地球的速度为0（软棒经过平衡位置）的那一刻立即停止。这样的系统将在时间间隔$nT = \frac{a}{v}$之后发生，其中$n$是自然数。从这里

$$v = \frac{a}{nT} = \frac{a}{2\pi n} \sqrt{\frac{g}{l}}.$$

7. 在与光束一起移动的坐标系中（因此速度$v$），等质量的碎片以大小相等且方向相反的速度$v'$向任意方向散射。最大相对值适用于沿光束移动方向解冻的碎片。这个速度是$u = v + v'$。

由条件求得粒子垂直方向飞行的速度(图3)

$$u_1^2 + v^2 = v'^2.$$

从这里

$$u_1 = \sqrt{v'^2 - v^2} = \sqrt{u(u - 2v)}.$$

如果$u \leq 2v$，则不存在此类盐。
