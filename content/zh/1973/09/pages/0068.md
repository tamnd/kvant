$$y = 3 \text{ является решением системы, то } \begin{cases} a - 3b = 2a - b, \\ c + 1 + 3c = 10 - a + 3b. \end{cases}$$

因此$a = -2b, c = (5b + 9)/4$。接下来我们找到：$\Delta = ac + bc + b = (-5b^2 - 5b)/4 = 0$，从哪里$b_1 = 0, b_2 = -1$。然后$a_1 = 0, c_1 = \frac{9}{4}; a_2 = 2, c_2 = 1$。

在这两种情况下，还获得以下系统：

$$\begin{cases} 0x + 0y = 0, \\ \frac{13}{4}x + \frac{9}{4}y = 10, \\ 2x + y = 5, \\ 2x + y = 5. \end{cases}$$

两个系统都满足问题的条件。

答案：$a_1 = 0, b_1 = 0, c_1 = \frac{9}{4}; a_2 = 2, b_2 = -1, c_2 = 1$。

问题3.系统在$a$什么值时

$$\begin{cases} (a^2 - 1)x + (a + 1)y = a^2 - 2, \\ (a + 1)x + 2ay = 2a + 1 \end{cases}$$

我们有无限多个解吗？

该系统的行列式等于$\Delta = 2a^3 - a^2 - 4a - 1$，并且我们没有求解方程$2a^3 - a^2 - 4a - 1 = 0$*的公式。因此，完整地使用主要定理很重要。当且仅当$\Delta = \Delta_x = \Delta_y = 0$，但并非所有未知数的系数都等于0，或者系统的所有系数都等于0时，系统是不确定的。但是，$y$的系数不可能同时变为0，所以仍然只考虑第一种情况。

*) 确实，您可以注意到这个方程有一个根 $a = -1$。知道三次方程的一个根，我们可以将方程的左侧分解为一个线性因子（类型 $x - x_0$，其中 $x_0$ 是找到的根）和一个二阶多项式，我们知道如何找到其根。通过以这种方式找到方程的根，我们可以求解所得系统。然而，我们将给出一个更简单的问题解决方案。

我们有

$$\Delta_x = \begin{cases} a^2 - 2 & a + 1 \\ 2a + 1 & 2a \end{cases} = 2a^3 - 2a^2 - 7a - 1.$$

如果方程$\Delta = 0$和$\Delta_x = 0$有一个共同根$a_0$，那么从第一个方程中减去第二个方程我们得到$a_0^2 + 3a_0 = 0$，其中$a_0$不是0就是-3，但这两个数字都不是方程$\Delta = 0$的根，所以我们得到矛盾。

因此，方程$\Delta = 0$和$\Delta_x = 0$没有共同根，因此该系统不可能是不确定的。

答案：对于任意$a$，系统不存在无穷多个解。

问题 4. 证明如果方程

$$ax^2 + bx + c = 0$$

和$px^2 + qx + r = 0$有共同根，则$(ar - cp)^2 = (aq - bp) (br - cq)$。

让这些方程有一个共同根$x_0$。那么方程组

$$\begin{cases} au + bv = -c, \\ pu + qv = -r \end{cases}$$

有解$u = x_0^2, v = x_0$，要证明的等式采用$\Delta_v^2 = \Delta \cdot \Delta_u$的形式。如果系统(1)的行列式$\Delta$非零，那么我们纠正Cramer并找到唯一解：

$$x_0^2 = \frac{\Delta_u}{\Delta}, \quad x_0 = \frac{\Delta_v}{\Delta}.$$

因此$\frac{\Delta_u}{\Delta} = \frac{\Delta_v^2}{\Delta^2}$，因此$\Delta_v^2 = \Delta \cdot \Delta_u$，这就是需要证明的。

如果$\Delta = 0$，则系统（1）是一致的，是不确定的，因此，在其中$\Delta_x = \Delta_y = 0$，即所证明的等式再次得到满足。
