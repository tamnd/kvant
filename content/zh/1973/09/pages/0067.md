户枝

$$\frac{\Delta = 0}{\downarrow \Delta} \rightarrow \text{система определения*}$$

（点），

$$\frac{\Delta_x = \Delta_y = 0}{\downarrow \Delta} \rightarrow \text{система несовместная,}$$

$$\frac{a_1 = b_1 = a_2 = b_2}{\downarrow \Delta} \rightarrow \text{система неопределения (прямая),}$$

$$\frac{c_1 = c_2 = 0}{\downarrow \Delta} \rightarrow \text{система несовместная (плоскость).}$$

该图应如下理解。首先提出问题：$\Delta = 0$？如果不是，则判定系统（有唯一解）；如果是，则提出问题：$\Delta_x = \Delta_y = 0$？如果不是，则系统不兼容；如果是，那么我们问下一个问题，依此类推。 “点”、“直线”、“面”等词是指相应情况的几何解释。

另外还需要注意的是，在第一种情况$x = \frac{\Delta_x}{\Delta}$、$y = \frac{\Delta_y}{\Delta}$以及第三种情况（即当$\Delta = \Delta_x = \Delta_y = 0$，但并非所有未知数的系数都等于0时），系统等价于一个方程——其中存在非零系数的方程。

这个公式使得可以很容易地导出这种类型的充分必要条件：系统是定模型并且当 $\Delta \neq 0$ 时是模型；当$\Delta = 0$、但$\Delta_x \neq 0$或$\Delta_y \neq 0$，或者所有未知数的系数都等于0，并且至少有一个自由项不等于0时，系统是不一致模型和molko模型。

*）不幸的是，教科书不包含系统的“定义”和“非定义”术语。如果一个系统只有一个解，则称为确定系统；如果有多个解，则称为不确定系统。这些术语使用起来很方便，但当然不是必需的。

让我们考虑一下该定理应用的几个典型例子。

问题 1（密歇根州立大学地理学院，1970 年）。方程组在参数a取什么值时

$$\begin{cases} ax - 4y = a + 1, \\ 2x + (a + 6)y = a + 3 \end{cases}$$

有没有解决办法？

我们立即注意到，上面给出的系统不兼容条件有些麻烦，在实践中，通常建议不要“在任何情况下”应用该条件，而是仅在满足不兼容的必要条件$\Delta = 0$的情况下工作。这允许我们不计算行列式 $\Delta_x$ 和 $\Delta_y$。

我们有：$\Delta = a^2 + 6a + 8$；因此，$\Delta = 0$在$a = -2$和$a = -4$。将$a_1 = -2$代入该系统，得到系统

$$\begin{cases} -2x - 4y = -1, \\ 2x + 4y = 1, \end{cases}$$

显然（或基于定理的第三种情况），它有无限多个解。对于$a_2 = -4$，我们有系统

$$\begin{cases} -4x - 4y = -3, \\ 2x + 2y = -1, \end{cases}$$

这显然是不一致的（或基于定理的第二种情况）。

答案：$a = -4$。
