$BOA + BC_1A = AB_1C + BA_1C + BC_1A = 180^\circ$。因此，点$O$位于$\Delta ABC_1$的外接圆上。问题的(a)点的陈述已被证明。

现在让我们证明$A_1OA = 180^\circ$。确实，$A_1OA = A_1OC + COA = A_1BC + 180^\circ - AB_1C = 180^\circ$。因此，线 $AA_1$ 经过点 $O$。因此，线 $BB_1$ 和 $CC_1$ 也经过该点。问题(b)点的陈述已被证明。

9年级，任务3。问题的条件还意味着以下不等式：$-1 \leq c \leq 1$； $-1 \leq a + b + c \leq 1$； $-1 \leq a - b + c \leq 1$。从最后两个不等式得出 $-1 \leq a + c \leq 1$ 和 $-1 \leq b \leq 1$。我们假设$a \geq 0$。事实上，如果$a < 0$，则分别用$-a$、$-b$和$-c$替换$a$、$b$和$c$；新值也满足问题的条件，新的$a$（等于$-a$）将为正。

现在让我们考虑几种情况。

1. $c \geq 0$。然后$|cx^2 + bx + a| \leq c + |b| + a$ $|x| \leq 1$。但是$c + |b| + a \leq 1$（因为$|b|$要么是$b$，要么是$-b$），$|cx^2 + bx + a| < 2$和$|x| \leq 1$更是如此。

2. $c < 0$。然后$a + c \leq cx^2 + a \leq a$，因此$a + c - |b| \leq cx^2 + a + bx \leq a + |b|$。但是$-1 \leq a + c - |b|$和$a + |b| \leq 1 - c \leq 2$。因此，不等式$|cx^2 + bx + a| \leq 2$始终成立。回想起来，我们看到，如果对于某些$x_0$，满足等式$|cx^2 + bx + a| = 2$，则$c = -1$，$cx^2 + bx + a = 2$和$x_0 = 0$（回想一下，我们有$a \geq 0$），因此$a = 2$和$b = 0$（从$a + c = 1$开始）。
