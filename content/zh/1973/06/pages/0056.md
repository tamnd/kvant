⟦folio 54⟧

在《数学入学考试大纲》中，特别有以下内容：“复数及其作用的论证。复数的模和论证。”申请人不需要严格构建复数理论，但他们必须能够操纵这些数字并了解它们的几何解释。

本文研究了根据应用程序经验得出的几项任务。每个问题本质上仅使用基本定义和与复数相关的一些概念的几何解释。

任务1. 在对应于数字$z = \frac{2+i}{i-2}$的平面上画一个碗。

解决了并且e。首先，让我们用代数形式表示这个数字：

$$\frac{2+i}{i-2} = -\frac{(2+i)(2+i)}{(2-i)(2+i)} = -\frac{3+4i}{5} = -\frac{3}{5} - \frac{4}{5} i.$$

现在在复平面上描绘数字 $z$ 不再困难 - 你会在第三个正方形中得到一个点（自己画出来！）。

任务 2. 复数 $z = a+bi$ 由点 $M(a, b)$ 表示。 $z_1 = z + 3 - 2i$点在哪里？

解决了并且e。我们有$z + 3 - 2i = (a + 3) + (b - 2) i$。

位置数$z_1 = (a + 3) + (b - 2) i$由点$M_1(a + 3, b - 2)$表示，它是从二维点$M$向右三个单位、向下两个单位获得的。

任务 3. 复数 $z$ 以及 $|z| = 2$ 均被考虑。点$2z - 3i + 1$位于哪里？

解决了并且e。 $|z| = 2$ 的点 $z$ 位于以点 $(0, 0)$ (图 1) 为中心、半径为 2 的圆上。那么点 $2z$ 将位于半径为 4 的同心圆上。事实上，点 $2z$ 与点 $z$ 位于从原点发出的同一射线上，但距离原点的距离是点 $z$ 的 2 倍。

点 $2z + 1 - 3i$ 是从点 $2z$ 二维向右一维和二维向下三个单位获得的。因此，点 $2z + 1 - 3i$（其中 $|z| = 2$）形成一个以点 $(1, -3)$ 为圆心、半径为 4 的圆。

任务 4. 复平面上的哪一组点由条件 $2 < |z + 1 - 2i| \leq 3$ 给出？

解决了并且e。设 $z_1 = z + 1 - 2i$；那么这个条件的形式为

$$2 < |z_1| \leq 3. \quad (1)$$
