图 3.

每个学生至少参加过一次旅行。

6) 让第 i 次徒步旅行 ($i = 1, 2, \dots, n$) 的男孩占本次徒步旅行总人数的 $\alpha_i$ 小时。在所有游客（至少参加过一次徒步旅行的每个人）的全体会议上，男孩们能弥补的最长时间是多少？

a) 在第一次旅行中，从情况可以看出，参加本次旅行的男生人数少于女生人数的2/3。而且，还不到班里女生总数的2/3。还有男生——第二次旅行的参与者——不到班上女生总数的2/3。由于每个学生至少参加过一次旅行，班上男生的总数不到女生人数的 4/3。因此，这个班男生占学生总数的比例不超过4/7。

使用图 3 中明确的符号（$b$和$g$是英语单词boy和girl的第一个字母），我们的解决方案可以写如下。

根据条件$5b_1 < 2(b_1 + g_1)$，我们开$3b_1 < 2g_1 \leq 2g$。 Tono也证明了$3b_2 < 2g_2 \leq 2g$。从$b \leq b_1 + b_2$开始，我们得到$3b \leq 3b_1 + 3b_2 < 4g$，打开$7b < 4(b + g)$。

6) 这个问题可以用类似的方法解决。令$b_i$和$g_i$为第i次竞选中的男孩和女孩人数，$b$和$g$为参加全体会议的男孩和女孩人数。然后，根据条件$b_i = \alpha_i(b_i + g_i)$，我们打开$(1 - \alpha_i)b_i = \alpha_i g_i \leq \alpha_i g$，所以如果$\alpha_i < 1$，则$b \leq \sum_{i=1}^{n} b_i \leq \sum_{i=1}^{n} \left(\frac{\alpha_i}{1 - \alpha_i} g\right) = g \sum_{i=1}^{n} \frac{\alpha_i}{1 - \alpha_i},$

从哪里$b \left(1 + \sum_{i=1}^{n} \frac{\alpha_i}{1 - \alpha_i}\right) \leq (b + g) \sum_{i=1}^{n} \frac{\alpha_i}{1 - \alpha_i}$

（这里$\sum_{i=1}^{n} - \text{знак суммирования}$：

$$\sum_{i=1}^{n} x_i = x_1 + x_2 + \dots + x_i + \dots + x_n).$$

因此，我们已经证明，如果$\alpha_i < 1$对于所有$i$，那么男孩将不会超过徒步旅行参与者总数的$\frac{c}{1 + c}$，其中$c = \sum_{i=1}^{n} \frac{\alpha_i}{1 - \alpha_i}$。

我们仍然需要确保能够达到这个限制。这就要求将所有书面的不等式转化为等式。很容易理解，如果所有竞选活动中的女孩都是相同的，而男孩是不同的，即每个男孩只参加了一次竞选，那么情况就会如此。让我们证明这对于任何 $\alpha_i$ 都可能发生。设$\frac{\alpha_i}{1 - \alpha_i} = \frac{m_i}{N}$（数字$\alpha_i$和$\frac{\alpha_i}{1 - \alpha_i}$是有理数；我们可以将$\frac{\alpha_i}{1 - \alpha_i}$写成具有相同值的分数）。那么，如果在第i次活动中，有$N$（相同）个女孩和$m_i$（不同）个男孩，则$M = \sum_{i=1}^{n} m_i$个男孩和$N$个女孩会来参加聚会； $M$与$N$的比例正好是$c$，$M$与$M + N$的比例正好是$\frac{c}{1 + c}$。

让我们回到问题a）作为例子。

如果行程次数为$n = 2$和$\alpha_1 = \alpha_2 = \frac{2}{5}$，那么准确的估计应该是$\frac{c}{1 + c}$，其中$c = \frac{2}{5} + \frac{2}{5} + \frac{2}{5} = \frac{2}{3} + \frac{2}{3} = \frac{4}{3}$，即$\frac{c}{1 + c} = \frac{4}{7}$。这里$\alpha_1 = \frac{2}{3}$（$i = 1, 2$），如果每次旅行中有3个（相同）女孩和2个男孩（第一次旅行中 - 一个，第二次 - 其他），那么只有7个参与者，其中4个是男孩。 （如果您认为班上的学生人数太少，您可以将所有数字同时相乘：3、2、7 和 4，例如乘以 4 或 5；因为只是它们的比率，这不会影响结果）。因此，问题a)的条件中的数字4/7不能被更小的数字代替。
