4. 最佳订单

首先，考虑有两个瓶子的情况。

令其中一个的填充和购买时间等于$a$和$b$，而另一个则分别等于$c$和$d$。那么哪种顺序更好——表 5 中所示的顺序还是表 5' 中所示的顺序？

第一种方案（表5）中线路的运行时间对应于$t$。表 4 中 $N = 2$ 的符号

$$A_1 = a, \quad B_1 = b + d$$
$$A_2 = a + c, \quad B_2 = d.$$

根据陈述1，时间$t$等于数字$A_1 + B_1$和$A_2 + B_2$中的较大者：

$$t = \max(A_1 + B_1, A_2 + B_2) = \max(a + b + d, a + c + d).$$

让我们用 $S$ 表示总和 $a + b + c + d$。那么$t$的公式可以改写如下：

$$t = \max(S - c, S - b) = S - \min(b, c)$$

（如果数字$b$和$c$与$S$不同，则数字$S - b$和$S - c$将更大）。

当然，类似的公式对于$t'$也有效，其中$t'$是第二个选项中的线路运行时间（表5'）：

$$t' = S - \min(a, d).$$

所以，如果$\min(a, d) \geq \min(b, c)$，则$t \geq t'$。

换句话说，对于$N = 2$，最佳顺序由以下规则确定：从$a, b, c$和$d$中选择最多的数字；如果是$a$或$d$，则第一个选项更好（表5），但如果是$b$或$c$，则第二个选项（表5'）。即当表中$N = 2$表示最佳顺序时，大部分数字应该在左上或右下。

在任意$N$的情况下，最后一句概括如下。

陈述2.“最佳”顺序可以通过以下规则确定。让我们选择表3中最多的数字$a_1, b_1, \dots, a_N, b_N^*$。如果这个数字是$a_k$，那么第$k$瓶必须在第一瓶的线上提供；如果这个数字是 $b_k$，那么第 $k$ 瓶必须在生产线上最后提供。通过从表 3 中删除第 $k$ 行，尽可能多地找出第 $k$ 瓶的命运。在剩余的数字 $a_i, b_i$ ($1 \leq i \leq N, i \neq k$) 中，我们再次从数字 $*$ 中选择最多的数字。如果等于$a_l$，则第$l$瓶子将被发送到队列的开头，如果等于$b_l$，则第$l$瓶子将被发送到队列末尾（队列由除第$k$之外的所有瓶子组成）。就这样直到最后一瓶。

我们将证明第 6 段中的陈述 2，现在将陈述 1 和 2 应用到我们的示例中。

*) 如果有多个这样的数字，您可以取其中任何一个。
