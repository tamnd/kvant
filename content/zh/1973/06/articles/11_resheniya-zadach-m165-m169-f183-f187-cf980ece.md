M165。圆圈上有一组F功率，由100个二重奏组成。众所周知，对于集合 R (F) 的圆的任何旋转 R，我们与 F 具有共同的幂。（换句话说，对于集合 F 中从 0° 到 180° 的任何 α，我们可以指示两个极限，另一个极限与另一个极限之间的距离为 α。）对于形成集合 F 的 100 个二元体的体积，我们可以使用的最小长度总和是多少？如果数字不是 100，而是 n，答案是什么？

让我们解决n 条弧的问题。
让我们用 S*) 来表示形成集合 F 的 n 条弧的长度之和。
S可以任意接近$\frac{180^\circ}{n}$。举个例子就足够了：我们放置（n−1）条弧，每条弧的长度等于$\frac{a^\circ}{n}$，使得任意两个相邻弧的中心相距$\frac{180^\circ}{n}$，在第（n−1）条弧后面放置长度为$\frac{180^\circ}{n}$的第n条弧，使得它们最近端之间的距离等于$\frac{180^\circ}{n}$。

6) 让第 i 次徒步旅行 ($i = 1, 2, \dots, n$) 的男孩占本次徒步旅行总人数的 $\alpha_i$ 小时。在所有游客（至少参加过一次徒步旅行的每个人）的全体会议上，男孩们能弥补的最长时间是多少？

a) 在第一次旅行中，从情况可以看出，参加本次旅行的男生人数少于女生人数的2/3。而且，还不到班里女生总数的2/3。还有男生——第二次旅行的参与者——不到班上女生总数的2/3。由于每个学生至少参加过一次旅行，班上男生的总数不到女生人数的 4/3。因此，这个班男生占学生总数的比例不超过4/7。

使用图 3 中明确的符号（$b$和$g$是英语单词boy和girl的第一个字母），我们的解决方案可以写如下。

根据条件$5b_1 < 2(b_1 + g_1)$，我们开$3b_1 < 2g_1 \leq 2g$。 Tono也证明了$3b_2 < 2g_2 \leq 2g$。从$b \leq b_1 + b_2$开始，我们得到$3b \leq 3b_1 + 3b_2 < 4g$，打开$7b < 4(b + g)$。

6) 这个问题可以用类似的方法解决。令$b_i$和$g_i$为第i次竞选中的男孩和女孩人数，$b$和$g$为参加全体会议的男孩和女孩人数。然后，根据条件$b_i = \alpha_i(b_i + g_i)$，我们打开$(1 - \alpha_i)b_i = \alpha_i g_i \leq \alpha_i g$，所以如果$\alpha_i < 1$，则$b \leq \sum_{i=1}^{n} b_i \leq \sum_{i=1}^{n} \left(\frac{\alpha_i}{1 - \alpha_i} g\right) = g \sum_{i=1}^{n} \frac{\alpha_i}{1 - \alpha_i},$

从哪里$b \left(1 + \sum_{i=1}^{n} \frac{\alpha_i}{1 - \alpha_i}\right) \leq (b + g) \sum_{i=1}^{n} \frac{\alpha_i}{1 - \alpha_i}$

（这里$\sum_{i=1}^{n} - \text{знак суммирования}$：

$$\sum_{i=1}^{n} x_i = x_1 + x_2 + \dots + x_i + \dots + x_n).$$

因此，我们已经证明，如果$\alpha_i < 1$对于所有$i$，那么男孩将不会超过徒步旅行参与者总数的$\frac{c}{1 + c}$，其中$c = \sum_{i=1}^{n} \frac{\alpha_i}{1 - \alpha_i}$。

我们仍然需要确保能够达到这个限制。这就要求将所有书面的不等式转化为等式。很容易理解，如果所有竞选活动中的女孩都是相同的，而男孩是不同的，即每个男孩只参加了一次竞选，那么情况就会如此。让我们证明这对于任何 $\alpha_i$ 都可能发生。设$\frac{\alpha_i}{1 - \alpha_i} = \frac{m_i}{N}$（数字$\alpha_i$和$\frac{\alpha_i}{1 - \alpha_i}$是有理数；我们可以将$\frac{\alpha_i}{1 - \alpha_i}$写成具有相同值的分数）。那么，如果在第i次活动中，有$N$（相同）个女孩和$m_i$（不同）个男孩，则$M = \sum_{i=1}^{n} m_i$个男孩和$N$个女孩会来参加聚会； $M$与$N$的比例正好是$c$，$M$与$M + N$的比例正好是$\frac{c}{1 + c}$。

让我们回到问题a）作为例子。

如果行程次数为$n = 2$和$\alpha_1 = \alpha_2 = \frac{2}{5}$，那么准确的估计应该是$\frac{c}{1 + c}$，其中$c = \frac{2}{5} + \frac{2}{5} + \frac{2}{5} = \frac{2}{3} + \frac{2}{3} = \frac{4}{3}$，即$\frac{c}{1 + c} = \frac{4}{7}$。这里$\alpha_1 = \frac{2}{3}$（$i = 1, 2$），如果每次旅行中有3个（相同）女孩和2个男孩（第一次旅行中 - 一个，第二次 - 其他），那么只有7个参与者，其中4个是男孩。 （如果您认为班上的学生人数太少，您可以将所有数字同时相乘：3、2、7 和 4，例如乘以 4 或 5；因为只是它们的比率，这不会影响结果）。因此，问题a)的条件中的数字4/7不能被更小的数字代替。

M167。证明在任何由自然数组成的算术级数$a, a + d, a + 2d, \dots, a + nd, \dots$中，存在无限多个分解为质因数的多项式包含单质数和相同的质数。

正如信件所示，许多读者并不理解问题的用语。让我们更详细地看看它。

众所周知，任何自然数$N$都可以因式分解为质因数：

$$N = \frac{\alpha_1}{\alpha_2} \frac{\alpha_r}{p_1 p_2 \dots p_r},$$

并且这样的分解是唯一的。在问题 M167 中，需要证明在自然数的任何算术级数中，我们可以选择这样一组无限的项，使得它们每一项展开式中的质因数$p_1, p_2, \dots, p_r$对于所有这些项都是相同的（当然，幂$\alpha_1, \alpha_2, \dots, \alpha_r$可以不同）。现在让我们继续解决问题。

首先，我们注意到，如果级数的第一项$a$和级数的差$d$有一个最大公约数$q > 1$，那么级数的所有项都可以除以$q$。显然，解决这个新级数的问题就足够了，因为如果新级数的某些成员具有相同的素因数。因此，我们可以假设$a$和$d$是素数。以下引理成立：如果 $HOД(a, d) = 1$，则存在一个极大值 $k$，使得 $a^k - a$ 可以被 $d$整除（我们将在下面回忆一下如何证明这一点）。

那么对于任意整数$m > 0$

$$a^{km} - a = (a^k - a)(a^{k(m-1)} + a^{k(m-2)} + \dots + 1)$$

能被$d$整除，即$a^{km} - a = nd$，其中$n$是整数。因此，对于每个自然数$m$，数字$a^{km} = a + nd$都包含在我们的级数中。因此，存在一个无限级数多项式，它是其第一项$a$的一定次数。显然，所有这些项都具有相同的素因数。

引理的证明。考虑数字序列$a, a^2,$

$a^3, \dots$。其中有两个数除以 $d$ 所得的余数相同。让它成为$a^s$和$a^t$（$s < t$）。然后将它们的差$a^t - a^s = a^s (a^{t-s} - 1)$除以$d$。由于$a$和$d$是质数，那么$a^{t-s} - 1$可以被$d$整除，因此$a^{t-s+1} - a$可以被$d$整除，即$k$可以等于$t - s + 1$。

这个推理在《费马小定理》（«Kvant»No.10，1972）一文中已经给出了。那里也有人说，在 $k$ 的角色中，我们可以取数字 $\varphi(d)$ - 小于 $d$ 的数字的数量，并用它来取素数。 （“欧拉定理”：如果$HOД(a, d) = 1$，则$a^{\varphi(d)} - 1$可被$d$整除）。

F183。测力计，在光滑的水平桌上滑动，以恒定的力 $F = 4$ n 进行滑动。如果测力计的弹簧质量等于人体质量，并将测力计调整到水平位置，测力计会显示什么？

弹簧拉伸时产生的弹簧力与弹簧的移除量成正比。因此，测功机读数$T$等于

$$T = k \Delta L,$$

(1)

其中 $k$ 是弹簧刚度，$\Delta L$ 是其伸长率。

正常情况下，测功机静止时，弹簧任意截面的弹簧力相同，即弹簧任意相等截面被拉伸相同量时被移去。

移动测功机时情况并非如此。考虑位于测力计主体上的弹簧末端距离 $x$ 的弹簧部分 (图 8)。弹簧力 $T_x$ 对测功机主体产生加速度，并产生长度为 $x$ 的弹簧延伸。长度为 $x$ 的弹簧延伸部分的质量等于

$$M_x = \frac{M}{L} x,$$

(2)

其中 $M$ 是质量，$L$ 是弹簧的长度。

图 8.

若测功机的加速度等于$a$，则根据牛顿第二定律，$x$部分的弹簧力可写为：

$$T_x = \left( M + M \frac{x}{L} \right) a.$$

(3)

由于测力计的加速度是由力 $F$ 产生的，因此

$$a = \frac{F}{M + M} = \frac{1}{2} \frac{F}{M}.$$

(4)

所以

$$T_x = \frac{1}{2} F \left( 1 + \frac{x}{L} \right).$$

(5)

因此，力 $T_x$ 不是恒定的，并且沿着弹簧的各个部分变化。

$$k' = kn.$$

$$\Delta l_i = \frac{T_i}{k'} = \frac{T_i}{kn}.$$

所以

$$\Delta l_i = \frac{1}{2kn} F \left( 1 + \frac{i}{n} \right).$$

弹簧位置为

$$\Delta L = \sum_{i=1}^{n} \Delta l_i = \frac{1}{2kn} F \sum_{i=1}^{n} \left( 1 + \frac{i}{n} \right).$$
