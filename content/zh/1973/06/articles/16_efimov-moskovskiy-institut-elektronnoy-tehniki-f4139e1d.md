物理

选项1

1. 分化和干扰现象有哪些？

2. 一根 10 厘米长的导体在感应强度为 0.1 平方米的均匀磁场中移动，使其与磁场方向形成 60° 角。必须以多大的加速度移动导体，才能使导体两端的电位在 1 秒内均匀增加 1 V？

3. 质子必须具有多少能量才能接近 10^15 米的氮原子核？电子电荷为1.6·10⁻19 k，氮在元素周期表中的序号为7，ε₀=8.85·10⁻12 φ/m。

4. 在 0°C 时，玻璃烧瓶含有 680e 汞，在 100°C 时含有 670e 汞。测定玻璃的线膨胀系数。汞的体积膨胀系数为0.00018 εrad⁻1。

5. 在自由落体的最后一秒，身体移动的距离是前一秒的两倍。尸体从多高处坠落？绘制速度与时间的关系图，并指出其上考虑的路径。

莫斯科电子技术学院

莫斯科电子技术学院 (MIET) 是一所拥有高级物理和数学培训的大学。在该学院的主要院系中，高等数学课程与莫斯科国立大学物理学院的数学课程接近，几乎是技术学校数学课程教学量的两倍。在入学考试中，数学是一门主要科目，LIST申请人在数学考试（笔试和口试）中获得“五”分的学生无需进一步考试即可被该学院录取。

数学笔试需要四个小时作答，笔试的选项包括五道题，其中两道代数题，两道三角学题和一道几何题。每个选项都必须有一个解决不等式的例子。这些问题经过精心挑选，只有借助高中教授的方法和技术才能解决。然而，要求在解决过程中所有行动都是合理的，并且对问题的初始数据及其解决方案中包含的数量进行必要的研究。

口试门票包含两道理论题（代数和几何）；每位申请人都会获得一些示例（通常至少三个），涉及构建图形、求解代数和三角方程及不等式、初等函数的性质、复数或程序的其他部分。

目前，包括MIET在内的国内大多数大学都提供函授和晚间预科课程，并组织大学预科系列讲座。大约有 2,300 人在我们学院学习函授和晚间预科课程。函授课程的学生可以接受服务或书面咨询，晚间课程可以参加讲座和实践课程。他们收到方法论文献并完成测试作业。

总之，我们提出了 1972 年 MIET 入学考试的两种选择。

选项1

1. 解决不平等问题
$$\log_2 x \leq \sqrt{\log_x (2x^3)}$$

2. 已知对于任意n，某个数列的前n项之和可以用以下公式表示
$$S_n = 5 n^2 - 2 n$$

证明这个数列是等差数列并找出它的第 20 项。

3. 解方程
$$2 \lg 2 x + \lg 3 x = \lg 5 x$$

4. 检查方程
$$\cos (2\arctg 2) - \sin (4\arctg 3) = \frac{9}{25}$$

5. 给定一个底边为 2a、高为 h 的等边三角形。内切一个圆，并在其上画一条与底面平行的切线。求圆的半径和三角形各边之间的切线段的长度。

选项2

1. 求解方程组
$$|z + 1 - i| = |3 + 2 i - z| = |z + i|,$$
其中 z = x + iy 是复数。

2. 对于什么 x 以及数字 log 2、log (3^x - 1) 和 log (3^x + 3)（按指定顺序取）是否形成算术级数？

3. 解方程
$$4 \log_16 \cos 2 x + 2 \log_4 \sin x + \log_2 \cos x + 3 < 0,$$
如果 0 < x < π/4。
