在《数学入学考试大纲》中，特别有以下内容：“复数及其作用的论证。复数的模和论证。”申请人不需要严格构建复数理论，但他们必须能够操纵这些数字并了解它们的几何解释。

本文研究了根据应用程序经验得出的几项任务。每个问题本质上仅使用基本定义和与复数相关的一些概念的几何解释。

任务1. 在对应于数字$z = \frac{2+i}{i-2}$的平面上画一个碗。

解决了并且e。首先，让我们用代数形式表示这个数字：

$$\frac{2+i}{i-2} = -\frac{(2+i)(2+i)}{(2-i)(2+i)} = -\frac{3+4i}{5} = -\frac{3}{5} - \frac{4}{5} i.$$

现在在复平面上描绘数字 $z$ 不再困难 - 你会在第三个正方形中得到一个点（自己画出来！）。

任务 2. 复数 $z = a+bi$ 由点 $M(a, b)$ 表示。 $z_1 = z + 3 - 2i$点在哪里？

解决了并且e。我们有$z + 3 - 2i = (a + 3) + (b - 2) i$。

位置数$z_1 = (a + 3) + (b - 2) i$由点$M_1(a + 3, b - 2)$表示，它是从二维点$M$向右三个单位、向下两个单位获得的。

任务 3. 复数 $z$ 以及 $|z| = 2$ 均被考虑。点$2z - 3i + 1$位于哪里？

解决了并且e。 $|z| = 2$ 的点 $z$ 位于以点 $(0, 0)$ (图 1) 为中心、半径为 2 的圆上。那么点 $2z$ 将位于半径为 4 的同心圆上。事实上，点 $2z$ 与点 $z$ 位于从原点发出的同一射线上，但距离原点的距离是点 $z$ 的 2 倍。

点 $2z + 1 - 3i$ 是从点 $2z$ 二维向右一维和二维向下三个单位获得的。因此，点 $2z + 1 - 3i$（其中 $|z| = 2$）形成一个以点 $(1, -3)$ 为圆心、半径为 4 的圆。

任务 4. 复平面上的哪一组点由条件 $2 < |z + 1 - 2i| \leq 3$ 给出？

解决了并且e。设 $z_1 = z + 1 - 2i$；那么这个条件的形式为

$$2 < |z_1| \leq 3. \quad (1)$$

积分 $z_1$，满足条件 $|z_1| = 3$，位于以原点为圆心、半径为 3 的圆上。健康）状况 $|z_1| < 3$ 满足以原点为圆心、半径为 3 的圆的所有内点。健康）状况 $|z_1| > 2$ 满足所有点

任务 5（密歇根州立大学，经济学院，1970 年）。指出满足条件$|z| + i + z = 2 + i$的合数所对应的平面的幂。

解决方案。设 $z = a + bi$；那么这个条件将采取以下形式

$$i\sqrt{a^2 + b^2} + a + bi = 2 + i.$$

通过定义复数的等式，从这里我们得到一个方程组

$$\begin{cases} a = 2, \\ \sqrt{a^2 + b^2} + b = 1, \end{cases}$$

这很容易解决。结果，我们找到了满足赋值条件的数$z = 2 - \frac{3}{2}i$。

问题7.复数$z$满足条件

$$|z+2+i| = |z-1-4i|.$$ (4)

代表这些数字的点位于哪里？

解决方案。众所周知，$|z_1-z_2|$是表示复数$z_1$和$z_2$的点之间的距离。因此数

$$|z+2+i| = |z-(-2-i)|$$

 是从表示数字$z$的点到点$M(-2, -1)$的距离，并且数字

$$|z-1-4i| = |z-(1+4i)|$$

 是代表数字$z$的点到点$N(1, 4)$的距离。那么条件(4)意味着所需的点与点$M$和$N$等距。因此，所需的点位于垂直于线段 $MN$ 并穿过其中间的直线上。

问题 8. 指出代表数字的点集，代表同时满足两个条件的复数

$$|z-2i| \leqslant \frac{3}{2}, \frac{\pi}{3} < \arg z < \frac{2\pi}{3}.$$ (5)

解决方案。代表满足第一个条件 (5) 的复数的点填充以点 $(0,2)$ (图 4) 为中心、半径为 $3/2$ 的圆（包括圆）。第二个条件由表示位于从原点发出的光线和合成物之间的点的复数来满足

$$0 < |z|^2 - |z| + 1 < 6 + 3 |z|,$$ (6)

解决方案。不等式(6)，根据对数的性质，等价于二重不等式

$$0 < \frac{|z|^2 - |z| + 1}{2 + |z|} < 3,$$

可以用以下形式重写（从 $2 + |z| > 0$ 到任何 $z$）

$$0 < |z|^2 - |z| + 1 < 6 + 3 |z|.$$

但不平等 $|z|^2 - |z| + 1 > 0$ 对任何有效 $z$ （因为二次三项式的判别式 $x^2 - x + 1$ 负），以及不等式 $|z|^2 - |z| + 1 < 6 + 3 |z|$， 那是 $|z|^2 - 4 |z| - 5 < 0$ 执行于 $|z| < 5$ （不等式 $x^2 - 4x - 5 < 0$ 执行于 $-1 < x < 5$， 但 $|z| \geqslant 0$ 在任何 $z$）。因此，复数满足条件(6) $z$，满足条件 $|z| < 5$;这些数字填充以原点为圆心、半径为 5 的圆的内部。
