大约一个点的轨迹

1972年«Kvant»第11期“问题«Kvant»”中提出了M174问题。说出其条件。

在三角形 ABC 的边上，与底边一样，构造等边三角形 AB₁C、BA₁C 和 AC₁B (图 1)。证明从 A、B、C 点分别引至直线 B1C1、C1A1、A1B1 的垂线相交于一点。

发表的文章描述了解决此类问题的一种相当通用的方法，特别是解决问题 M174。文章最后有独立解决的任务。

经常存在需要证明三条或更多条直线相交于一点的问题。通常这些问题可以这样解决：证明所考虑的两条直线相交于满足某些条件的点，而第三条直线的所有点都满足该条件，并且只有它们满足该条件。作为例子，我们可以引用课本上的两个定理：三角形内角的二等分线相交于一点；画到三角形各边中点的垂线相交于一点。

类似地，如果你需要证明一些三个或更多的点位于一条直线上，那么你可以尝试证明所有相关点都满足某些直线上的所有点且仅它们所满足的条件（类似的推理不仅可以用于直线，还可以用于例如圆）。

现在我们将讨论有助于解决此类问题的点的一种几何位置。

声明措辞

陈述 1. 设 A₁ 和 A2 为平面上两个固定（不同）点； k、k₁ 和 k2 是实数。那么点 M 的轨迹使得

k₁ (A₁M)² + k₂ (A₂M)² = k,
我们将：

a) 一个圆或一个点，或一个空集，如果 k₁ + k2 ≠ 0；

b) 垂直于线段 A₁A2 的直线，如果 k₁ + k2 = 0（但 k₁ ≠ 0）。

陈述2.设$A_1, A_2, \dots, A_n$为平面的不动点，$k_1, k_2, \dots, k_n$（所有$k_i \neq 0$）为给定的数字。那么点 $M$ 的轨迹也是
$$k_1(A_1M)^2 + k_2(A_2M)^2 + \dots + k_n(A_nM)^2$$
不变，我们将
a) 圆、点或空集，如果 $k_1 + k_2 + \dots + k_n \neq 0$；
b) 一条直线或整个平面，如果$k_1 + k_2 + \dots + k_n = 0$。

陈述3.为了使点$A_1, B_1$和$C_1$省略的重分布对应于三角形ABC的边BC、AC和AB相交于一点，满足以下等式是必要且充分的
$$(A_1B)^2 - (BC_1)^2 + (C_1A)^2 - (AB_1)^2 + (B_1C)^2 - (CA_1)^2 = 0.$$ (1)

以下推论是从最后的陈述得出的。

陈述 4. 如果从三角形 $A_1B_1C_1$ 的顶点 $A_1, B_1, C_1$ 下降到三角形 ABC 的边 BC、AC 和 AB 的重分布相交于一点，则从点 $A, B$ 和 $C$ 下降到直线 $B_1C_1, A_1C_1$ 和 $A_1B_1$ 的重分布也相交于一点。

尝试自己证明所有这些陈述。我们将首先展示如何使用陈述 3 或 4 解决问题 M174，然后我们将证明这些陈述本身。

练习
1. 使用陈述3，证明三角形的高相交于一点。

2. 给定三个两两相交的圆。证明任意两个圆的所有公共圆都经过一点。

3. 证明如果重新分布从点 $A_1$, $A_2$, ..., $A_n$ 落到线 $B_1B_2$, $B_2B_3$, ..., $B_nB_1$ 相交于一点，则
$$(B_1A_1)^2 - (A_1B_2)^2 + (B_2A_2)^2 - (A_2B_3)^2 + \dots + (B_nA_n)^2 = 0.$$

4. 取三个圆，每个圆都与三角形的一条边和另外两条边的延长线相接触。证明在这些圆的切点处恢复到三角形各边的重新分布相交于一点。

5. 设从某点$M$到三角形ABC的顶点$A$、$B$和$C$的距离分别用数字$a$、$b$和$c$表示。证明对于平面上任意点的任意$d \neq 0$，到相同顺序的顶点的距离不能用数字表示

$$\sqrt{a^2 + d}, \sqrt{b^2 + d}, \sqrt{c^2 + d}.$$

6. 给定一个正三角形 ABC 和一个任意点 $D$。 $A_1$、$B_1$和$C_1$是三角形BCD、ACD和ABD的内接圆的圆心。证明从顶点$A$、$B$、$C$下降到$B_1C_1$、$A_1C_1$、$A_1B_1$的重分布分别相交于一点。

7. 令 $A_1$、$A_2$、$A_3$ 和 $A_4$ 为平面上的任意点。证明有四个数 $x_1$、$x_2$、$x_3$ 和 $x_4$，且不全为零，因此可以针对该平面上的任意点 $M$ 构造 $x_1(A_1M)^2 + x_2(A_2M)^2 + x_3(A_3M)^2 + x_4(A_4M)^2$。

8. 给定三角形ABC。让我们考虑所有可能的点对$M_1$和$M_2$使得$AM_1 : BM_1 : CM_1 = AM_2 : BM_2 : CM_2$。证明所有直线$M_1M_2$都经过平面上的一个固定点。

9. 圆与三角形 ABC 的边 $AB$ 以及延长边 $AC$ 和 CB 分别相切于点 $M$ 和 $N$。另一个圆分别在点$P$和$K$处接触边$AC$和延伸边$AB$和$BC$。证明线$MN$和$PK$的交点位于通过顶点$A$的三角形ABC的高处。

10. 给定两个线段$AB$和$CD$。找到点 $M$ 的轨迹，从而构建和 $S_{\triangle ABM} + S_{\triangle CDM}$。

11. 利用上一题的结果，证明外接四边形的对角线中点和内切圆的圆心位于同一条直线上（牛顿问题）。

12. 证明一个点的轨迹是一个圆（阿波罗尼圆），该点是构成平面上两个固定点的相对点并且不同于统一。
