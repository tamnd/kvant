黄金比例

开普勒说，几何学有两大瑰宝——毕达哥拉斯定理和黄金比例。如果这些宝藏中的第一个可以比作一定量的黄金，那么第二个宝藏就可以比作一块宝石。

每个小学生都知道毕达哥拉斯定理，但并不是每个人都知道什么是黄金比例。所以我们决定向读者介绍这颗宝石。

什么是黄金比例？

如果$AC : AB = CB : AC$，则点$C$据说会产生线段$AB$的黄金比例。 (1)

因此，黄金比例是将整体分为两个不相等的部分，其中较大的部分与整体相关，而较小的部分与较大的部分相关。在几何术语中，黄金比例也称为以极值和平均比例划分线段。

如果线段$AB$的长度为$a$，线段$AC$的长度为$x$，则线段$CB$的长度将为$a - x$（图1），比例（1）将采用以下形式：

$$x : a = (a - x) : x$$ (2)

从这个比例可以清楚地看出，在黄金比例中，大于线段的长度就是几何平均值，或者像人们常说的那样，是

图 1.

与整个线段及其较小部分的长度成正比：

$$x = \sqrt{a(a - x)}$$

很容易说，反之亦然：如果将一个线段分为两个不相等的线段，使得较大线段的长度是整个线段及其较小部分长度的几何平均值，那么我们就得到了该线段的黄金比例。

线段$AB$的几何黄金比例可以构造如下：在点$B$，我们重建与$AB$（图2）的垂线，并在其上绘制$BD = 0,5AB$；进一步，连接点$A$和$D$，留出$DE = BD$，最后留出$AC = AE$。点 $C$ 是所需的点 - 它产生线段 $AB$ 的黄金比例。事实上，我们注意到根据毕达哥拉斯定理

$$(AE + ED)^2 = AB^2 + BD^2$$

和建筑

$$AE = AC, ED = BD = 0,5AB.$$

从这些等式可以得出

$$AC^2 + AC \cdot AB = AB^2,$$

从这里可以很容易地得到等式（1）。

解方程(2)得$x$，我们发现

$$x = \frac{\sqrt{5} - 1}{2} a \approx 0,62a.$$

所以，$a - x \approx 0,38 a$。因此，黄金比例部分大约占整个段的62%和38%。

一点历史

发现与黄金比例相关的分段划分的最古老的文学纪念碑是欧几里得的《几何原本》（公元前 3 世纪）。在《几何原本》第二卷中，欧几里得就构建了黄金比例，后来又用它构建了一些正多边形和多面体。

但黄金比例在欧几里得之前就已为人所知。特别是毕索戈尔和他的学生都知道他（公元前六世纪）。除了哲学和数学之外，毕达哥拉斯哲学学派还研究和谐。在研究和声理论时，毕氏学派得出这样的结论：声音的质的差异是由于琴弦长度之间的量的差异造成的。这启发了他们，他们试图更进一步——通过数字来表达世界的一切模式，相信上帝将数字置于世界秩序的基础。毕多哥拉斯学派通过数字及其关系（后者被认为是分段关系）来计算神奇的、超自然的。几何学也并非没有它的报复。这里特别值得注意的是由正五边形的对角线组成的星形五边形的任何毕达哥拉斯学派。

著名数学家、数学史家范德瓦尔登在他的优秀著作《科学的觉醒》中对此写道：“这个数字，健康的象征，成为毕陀哥拉斯学派的识别标志。当他们中的一个人在异国他乡临终时，无法点亮照顾他至死的那个人时，他命令他在自己的家中画一个星形多边形；如果一个毕达哥拉斯学派曾经经过米莫，他一定会询问。事实上，几年后，一个毕多哥拉斯主义者看到了这个迹象，房子的主人得到了丰厚的奖励”*）。

星形五边形对我们来说很有趣，主要是因为构成这个图形的每条线的根部都按照黄金比例分割另一条线。事实上，由于三角形 ACD 和 ABE 相似 (图 3)，因此 AC : AB = AD : AE。但是AD = BC，AE = AC，因此AC：AB = BC：AC - 我们已经知道黄金比例的比例。毕索哥拉斯学派正是利用星形五边形的这一特性来构造正五边形，或者说他们当然知道如何构造黄金比例。

到文艺复兴初期，人们对黄金比例的兴趣日益浓厚。

卢卡·帕乔利（Luca Pacioli，约 1445 年 - 后 1509 年）是一位意大利数学家，撰写了一篇关于黄金比例的论文《神圣比例》。

蒙娜丽莎（乔康达）的肖像是由文艺复兴时期意大利伟大的艺术家和科学家列奥纳多·达·芬奇（Leonardo da Vinci，1452-1519）绘制的。这幅画引起了研究人员的注意，他们发现构图图是基于“金三角”（更准确地说，是基于正星五边形的三角形）。

首先，它是由黄金比例在几何本身和艺术（尤其是建筑）中的大量应用引起的。其后果就是《神圣比例》一书的出现，其作者是15世纪最伟大的数学家、意大利人卢卡·帕乔利。帕乔利在他的著作中给出了黄金比例的十三个属性，他首先将其称为“例外”、“不可言喻”、“最优秀”、“超自然”等绰号。然而，书名本身就说明了作者对所描述主题的态度。有趣的是，这本书的插图是由其写作发起人之一、帕乔利的朋友、伟大的达芬奇绘制的。顺便说一句，“黄金比例”这个词就是他创造的。

观察表明，从自然的角度来看，黄金比例具有一定的优势。上世纪末进行的一项实验证实了这一点：受试者必须从十个“黄金”矩形（边长比给出黄金比例）中选择一个。因此，大约有22%的受试者选择了“黄金矩形”。我们不能忽视这样一个事实：书籍、明信片、钱包、巧克力棒和许多其他物品的形状都像黄金矩形。这里让我们注意，如果您从“黄金”矩形中切下一个正方形，或者将一个正方形附加到“黄金”矩形的较大边上，您将再次得到一个“黄金”矩形。

广泛应用于建筑和艺术领域。许多建筑杰作都是按照黄金比例建造的。菲迪亚斯（Phidias）、蒂什坎（Tishchan）、达芬奇（Leonardo da Vinci）和拉斐尔（Raphael）的许多不朽创作也遵循同样的比例。

黄金比例及其显着特性

如果我们将$x = a\tau$代入比例（2），那么对于$\tau$，我们得到以下等式：

$$\tau^2 + \tau - 1 = 0$$

(3)

希腊雕塑家利奥卡雷斯（Leochares，公元前 4 世纪）创作了阿波罗贝尔韦代雷 (Apollo Belvedere) 雕像，他启发了古希腊人关于男性美的观念。照片中画出的线条决定了身体的基本比例。这些比例与黄金比例有关。

该方程的正根等于黄金比例的比率：

$$\tau = \frac{x}{a} = \frac{a-x}{x} = \frac{\sqrt{5}-1}{2}$$

这个概念是一个非凡的数字，具有许多有趣的特性。以下是其中一些。

1. 直接计算表明

$$\tau = 0,618033989\ldots, \frac{1}{\tau} = 1,618033989\ldots$$

——$\tau$的倒数大于$\tau$本身。很容易验证这是具有此属性的唯一正数。事实上，如果正数$z$满足对应关系$\frac{1}{z} = 1 + z$，那么$z$一定是方程$z^2 + z - 1 = 0$的根。但这个方程有一个正根：$z = \tau$。

2. 将等式（3）重写为$\tau = \frac{1}{1 + \tau}$的形式，并在等式右边用$\frac{1}{1 + \tau}$代替$\tau$，我们得到：

$$\tau = \frac{1}{1 + \frac{1}{1 + \tau}}.$$

这个过程得到了支持，因此我们获得了以下数字 $\tau$ 无限连分数*) 的表示形式：

$$\tau = \frac{1}{1 + \frac{1}{1 + \frac{1}{1 + \dots}}}$$

人们不禁会注意到这个演示文稿的极其简单！

3. 这是数字 $\tau$ 的另一种表示形式：

$$\tau = \frac{1}{\sqrt{1 + \sqrt{1 + \sqrt{1 + \dots}}}}.$$

为了赋予等式 (5) 意义，让我们研究序列 $\sqrt{1}, \sqrt{1 + \sqrt{1}}, \sqrt{1 + \sqrt{1 + \sqrt{1}}}, \dots,$

其中的通用术语（我们用$\varphi_n$表示）包含$n$部首。

很明显$\{\varphi_n\}$是一个递增序列。而且，它是有限的。事实上，由于$\varphi_1 = 1 < 2$和$\varphi_{n+1} = \sqrt{1 + \varphi_n}$，那么从$\varphi_n < 2$可以得出$\varphi_{n+1} < \sqrt{3} < 2$，并且通过归纳我们可以得出$\varphi_n < 2$对于任何（自然）$n$。

*) 连分数在 N. M. Beskin 的文章 («Kvant» No. 1, 8, 1970) 中进行了讨论。更详细的介绍可以在 A. Ya 的书中找到。 Khinchin 的《连续分数》（M., Fizmatgiz, 1961），以及 N. Ya 的九年级中学数学专业“代数”教科书。维伦金等人。 （M.，“Prosveshchenie”，1968）。

因此，$\{\varphi_n\}$是一个递增的有界序列。众所周知，这样的序列是收敛的。用$\varphi$表示序列$\varphi_n$的极限，我们可以写成：$\varphi = \lim_{n \to \infty} \varphi_n = \sqrt{1 + \sqrt{1 + \sqrt{1}}}.$

另一方面，传递到等式$\varphi_{n+1} = \sqrt{1 + \varphi_n}$的极限，我们得到：$\varphi = \sqrt{1 + \varphi_n}$。

因此，（正）数$\varphi$是二次方程$\varphi^2 - \varphi - 1 = 0$的根，数$\psi = \frac{1}{\varphi}$是方程$\left(\frac{1}{\psi}\right)^2 - \frac{1}{\psi} - 1 = 0$的根，或者乘以$-\psi^2$，$\psi^2 + \psi - 1 = 0$，由$\psi = \tau$，$\varphi = \frac{1}{\tau}$，我们得到等式（5）。在这里，演示的极其简单性将令人印象深刻！

用有理数近似数 $\tau$

表示式（4）对于用有理数逼近无理数$\tau$非常方便。为此，让我们转向“合适的”分数：

$$\tau_1 = \frac{1}{1}, \quad \tau_2 = \frac{1}{1 + \frac{1}{1}}, \quad \tau_{(3)} = \frac{1}{1 + \frac{1}{1 + \frac{1}{1}}}$$

一般而言，对于任何 $n$

$$\tau_n = \frac{1}{1 + \frac{1}{1 + \frac{1}{1 + \dots}}} + \frac{1}{1 + \frac{1}{1}}$$

这些分数的序列有一个极限数 $\tau$，因此每个 $\tau_n$ 都是该数的近似值。直接计算表明

$$\tau_1 = \frac{1}{1}, \tau_2 = \frac{1}{2}, \tau_3 = \frac{2}{3}, \tau_4 = \frac{3}{5}, \dots$$

这一系列多比是根据一个非常简单的定律构建的：每个多比的分子等于前一个多比的分母，分母是同一多比的分子和分母之和。接下来会发生什么？这种模式成立吗？很容易证明这是真的。事实上，从公式（6）可以看出，相邻的合适多比$\tau_n$和$\tau_{n+1}$之间有以下关系：

$$\tau_{n+1} = \frac{1}{1 + \tau_n},$$

因此，从等式$\tau_n = \frac{m}{k}$可以得出$\tau_{n+1} = \frac{k}{m + k}$。

这种形成适当附加数的简单法则使得可以轻松地写出它们的序列：

$$\frac{1}{1}, \frac{1}{2}, \frac{2}{3}, \frac{3}{5}, \frac{5}{8}, \frac{8}{13}, \frac{13}{21}, \frac{21}{34}, \dots$$

从链式多臂杆的理论可知，具有奇数的合适的多臂杆会减少并接近在右侧生成这些多臂杆的数量，而具有偶数的多臂杆会增加并接近在左侧生成这些多臂杆的相同数量。在我们的例子中应用这个属性，我们可以写：

$$\frac{1}{2} < \frac{3}{5} < \frac{8}{13} < \frac{21}{34} < \frac{55}{89} < \dots < \tau < \dots < \frac{34}{55} < \frac{13}{21} < \frac{5}{8} < \frac{2}{3} < \frac{1}{1}$$

回顾一下通过适当加法对数字 m 进行的近似，我们会注意到斐波那契数列的任意一项与后续项的比率都是数字 $\tau$ 的适当加法，即黄金分割比的近似值。所采用的项数越大，这种近似越好。

如果取三个连续项：$u_n, u_{n+1}, u_{n+2}$，则数字$\frac{u_n}{u_{n+1}}$和$\frac{u_{n+1}}{u_{n+2}}$是数字$\tau$的相邻合适扩展，并且这些扩展之一大于$\tau$，另一个小于。

最后，我们提出以下问题：如何将整数$a$分成两个整数部分，使它们相对于$\tau$？

由于$\tau$是无理数，这样的除法当然是不可能的；我们感兴趣的只能大约等于$\tau$。这个近似值是多少？这个问题的答案是由链多贝理论给出的。

令合适的多比$\tau_n$的分母为$a$。让我们考虑分母不大于 $a$ 的所有 dobe 的集合。事实证明，在这些土贝集合中，最接近数字 $\tau$ 的正好是 $\tau_n$。

合适的 dobei 的分母都不是斐波那契数列的一项，因此如果 $a$ 是斐波那契数列的一项，那么将 $a$ 除以 $\tau_n$ 将是黄金比例的良好近似值。

因此，作为斐波那契数列成员的数字可以通过具有良好近似值的黄金比例分为两个整数部分。例如，数字 8 的黄金比例给出 (3.5)，数字 13 - (5.8) 等。
