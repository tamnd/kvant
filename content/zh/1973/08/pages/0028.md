2. 将等式（3）重写为$\tau = \frac{1}{1 + \tau}$的形式，并在等式右边用$\frac{1}{1 + \tau}$代替$\tau$，我们得到：

$$\tau = \frac{1}{1 + \frac{1}{1 + \tau}}.$$

这个过程得到了支持，因此我们获得了以下数字 $\tau$ 无限连分数*) 的表示形式：

$$\tau = \frac{1}{1 + \frac{1}{1 + \frac{1}{1 + \dots}}}$$

人们不禁会注意到这个演示文稿的极其简单！

3. 这是数字 $\tau$ 的另一种表示形式：

$$\tau = \frac{1}{\sqrt{1 + \sqrt{1 + \sqrt{1 + \dots}}}}.$$

为了赋予等式 (5) 意义，让我们研究序列 $\sqrt{1}, \sqrt{1 + \sqrt{1}}, \sqrt{1 + \sqrt{1 + \sqrt{1}}}, \dots,$

其中的通用术语（我们用$\varphi_n$表示）包含$n$部首。

很明显$\{\varphi_n\}$是一个递增序列。而且，它是有限的。事实上，由于$\varphi_1 = 1 < 2$和$\varphi_{n+1} = \sqrt{1 + \varphi_n}$，那么从$\varphi_n < 2$可以得出$\varphi_{n+1} < \sqrt{3} < 2$，并且通过归纳我们可以得出$\varphi_n < 2$对于任何（自然）$n$。

*) 连分数在 N. M. Beskin 的文章 («Kvant» No. 1, 8, 1970) 中进行了讨论。更详细的介绍可以在 A. Ya 的书中找到。 Khinchin 的《连续分数》（M., Fizmatgiz, 1961），以及 N. Ya 的九年级中学数学专业“代数”教科书。维伦金等人。 （M.，“Prosveshchenie”，1968）。

因此，$\{\varphi_n\}$是一个递增的有界序列。众所周知，这样的序列是收敛的。用$\varphi$表示序列$\varphi_n$的极限，我们可以写成：$\varphi = \lim_{n \to \infty} \varphi_n = \sqrt{1 + \sqrt{1 + \sqrt{1}}}.$

另一方面，传递到等式$\varphi_{n+1} = \sqrt{1 + \varphi_n}$的极限，我们得到：$\varphi = \sqrt{1 + \varphi_n}$。

因此，（正）数$\varphi$是二次方程$\varphi^2 - \varphi - 1 = 0$的根，数$\psi = \frac{1}{\varphi}$是方程$\left(\frac{1}{\psi}\right)^2 - \frac{1}{\psi} - 1 = 0$的根，或者乘以$-\psi^2$，$\psi^2 + \psi - 1 = 0$，由$\psi = \tau$，$\varphi = \frac{1}{\tau}$，我们得到等式（5）。在这里，演示的极其简单性将令人印象深刻！

用有理数近似数 $\tau$

表示式（4）对于用有理数逼近无理数$\tau$非常方便。为此，让我们转向“合适的”分数：

$$\tau_1 = \frac{1}{1}, \quad \tau_2 = \frac{1}{1 + \frac{1}{1}}, \quad \tau_{(3)} = \frac{1}{1 + \frac{1}{1 + \frac{1}{1}}}$$

一般而言，对于任何 $n$

$$\tau_n = \frac{1}{1 + \frac{1}{1 + \frac{1}{1 + \dots}}} + \frac{1}{1 + \frac{1}{1}}$$
