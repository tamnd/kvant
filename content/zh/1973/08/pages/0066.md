M176。如果$A < B < C$，三角形$ABC$的哪条边是其高度的交点最接近？又到了哪一个高峰呢？

让我们用 $AK$、$BM$、$CP$ 表示高度，用 $O$ 表示它们的交点。

从$O$到边的距离为$OK$、$OM$、$OP$。

我们假设$\Rightarrow C \neq 90^\circ$。然后$OK < OM < OP$。

我们来证明左边的不等式（右边的不等式也同样证明）。确实，$\frac{OM}{OC} = \frac{AP}{AC} = \cos \theta A$，$\frac{OK}{OC} = \frac{BP}{BC} = \cos \theta B$。

由于$\Rightarrow A < B$，然​​后$\cos \theta A > \cos \theta B$，因此$OM > OK$，这就是所需要的。从$O$到顶点的距离按大小排列如下：$OA > OB > OC$。

我们来证明左不等式（右不等式可类推证明）。

$\frac{OA}{OP} = \frac{1}{\sin \theta OAP} = \frac{1}{\cos \theta B}$

$\frac{OB}{OP} = \frac{1}{\sin \theta OBP} = \frac{1}{\cos \theta A}$，来自$OA > OB$。上述解法适用于除矩形之外的所有三角形。

在$C = 90^\circ$的情况下，两个证明都失败。

M177。找到方程的所有解

$\sqrt[n]{x^n - a^n} + \sqrt[n]{2a^n - x^n} = a$,

food $a$ 是给定的实数，$n$ 是大于 1 的自然数。

让我们首先考虑特殊情况$a = 0$。我们得到：

$\sqrt[n]{x^n} + \sqrt[n]{-x^n} = 0$.

如果$n$是偶数，那么唯一的解是$x = 0$（因为否则$x^n$和$-x^n$具有不同的符号，并且其中一个根是没有意义的）。如果$n$是奇数，那么任意$x$都是解。

现在让$a \neq 0$。用$y$表示$\sqrt[n]{x^n - a^n}$，用$z$表示$a - y$，我们得到系统：

$$\begin{align*}
y + z &= a, \\
y^n + z^n &= a^n
\end{align*}$$

让

$$\begin{align*}
y &= a, \\
z &= 0
\end{align*}$$

或$y = 0, z = a$。

在这些情况下，两个等式都得到满足。让我们看看它能提供什么。我们来计算$x$：

$$x^n = 2a^n$$ 或 $x^n = a^n$。

当满足这些等式时

$$x = \begin{cases}
a \sqrt[n]{2}, & \text{и } x = \begin{cases}
a, \text{если } n \text{-нечетное, } \pm a, \text{если } n \text{-четное, }
\end{cases}
\end{cases}$$

分别。将$x$的这些值代入原方程，我们在一般情况下得到相同的结果：

$$\sqrt[n]{a^n} = a$$.

这是真实的：

对于所有$a$，如果$n$是奇数，对于$a \geq 0$，如果$n$是偶数。

现在让我们证明对于$a \neq 0, y \neq 0, z \neq 0$系统(1)不能满足。仅考虑$a > 0, y \geq z$时的情况就足够了。事实上，如果$y, z, a$是它的解，$a < 0$，那么$-y, -z, -a$也是它的解。进一步，如果我们交换解中$y, z$的值，我们将再次得到一个解。这意味着，如果$a \neq 0$有解，那么$a > 0$也有$y \geq z$的解。

所以让$a > 0, y \geq z$。两种情况不同。
