M174—M178

M174。参见 N. F. Sharyzin 的文章，第 17 页。 42.

M175。 a)将正三角形的每条边均分为m等份，并通过分点画出与边平行的直线，将三角形切割成m²个小三角形。在所得三角形的顶点中，必须标记 N 个顶点，以便对于每两个标记的顶点 A 和 B，线段 AB 不与任何边平行。 N（给定 m）的最大可能值是多少？
让我们将三角形的每条边分成 m 个相等的部分，并通过分割点绘制与克平行的平面。在生成的多重边界的顶点中，我们标记 N 个顶点，以便没有两个标记的顶点位于与其中一个边界平行的线上。最可能的N是多少？
b) 方程的整数解中

$$x_1 + x_2 + \dots + x_k = m,$$

满足条件 m 0 ≤ x_i ≤ m（对于所有 i=1,2,...,k），需要选择 N 个解，使得在每两个所选解中，没有未知的 x_i 属于相同的值。 N 的最大可能值是多少？ （问题a）和b）是问题b）的情况的一部分，对应于k=3和k=4。）

首先，让我们检查问题 a) 是否是问题 b) 的情况的一部分，其中 k=3 和 k=4。

1 的接收值是切割三角形的相邻平行线之间的距离 (图 1)。三角形的每个点都与 3 个数字相关联：x₁、x2 和 x₃，表示（在选定的比例上）从该点到三角形边的距离 (图 2)。

很容易证明三角形所有点的总和 x₁ + x2 + x₃ 相同。事实上，让我们用 2a 表示三角形的边长；则 ax1、ax2 和 ax3 分别是三角形 OA2A3、OA1A3 和 OA1A2 的面积 (图 2)；因此，a (x₁ + x2 + x₃) 是面积 ΔA₁A2A₃，也就是说，x₁ + x2 + x₃ 不取决于点 O 的选择。在所选比例上，x₁ + x2 + x₃ = m（其中 m 是三角形每条边所划分的线段数）。

我们将三角形的每个点与 3 个数字相匹配：x₁、x2 和 x₃。在这种情况下，小三角形的顶点与非负整数（图3）相关联。

在问题a）中，要求对于每两个标记的顶点A和B，线段AB不平行于任何一条边ΔA1A2A3。在问题 b) 中，在所选择的解决方案中，没有两个未知的 x_i 不应属于相同的值。当然，这两个要求（第二个要求 k=3）意味着相同的事情。

因此，问题a)确实是问题b)的特例，其中k=3。

类似地，验证了对于k=4，问题6）与问题b）等价。

因此，仍然需要解决问题b)。

让我们重新表述一下：

假设在一个 k 列 n 行的矩形表中，可以将非负整数排列为任意行中的数字之和等于 m，并且任意列中没有重复的数字。令k和m固定。那么n 可以取的最可能的N 是多少？

当然，新的公式与原始公式等效，但同时允许更简单、更简短地介绍解决方案。
