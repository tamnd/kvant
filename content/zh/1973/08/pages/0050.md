⟦folio 48⟧

有两个总和不等于零。设$k_1$和$k_2$。让我们取在陈述 1a 的证明中构造的点$D$，并使用公式（2）。然后平等
$$k_1(A_1M)^2 + k_2(A_2M)^2 + k_3(A_3M)^2 + \dots + k_{n+1}(A_{n+1}M)^2 = k$$
可以写成以下形式
$$(k_1 + k_2)(DM)^2 + k_3(A_3M)^2 + \dots + k_{n+1}(A_{n+1}M)^2 = k - k_1(A_1D)^2 - k_2(A_2D)^2.$$
现在构造的在右边，下一个点数减少了1，但系数之和没有改变。根据归纳假设，对于最后一个等式，命题2成立。这意味着对于 $(n+1)$ 点也是如此。命题2已被证明。

陈述 3. 必要性。令 $P$ 为 BC、AC 和 AB 上 $A_1$、$B_1$ 和 $C_1$ 省略的重新分布的交点。命题 16 意味着平等
$$(A_1B)^2 - (CA_1)^2 = (PB)^2 - (CP)^2,$$
$$(B_1C)^2 - (AB_1)^2 = (PC)^2 - (AP)^2,$$
$$(C_1A)^2 - (BC_1)^2 = (PA)^2 - (BP)^2.$$
将这三个等式相加，我们发现在这种情况下条件（1）得到满足。

充分性。满足条件(1)，并令$P$为从$A_1$到BC和$B_1$到CA的重新分布的交点。从声明 16 可以看出
$$(A_1B)^2 - (CA_1)^2 + (B_1C)^2 - (AB_1)^2 = (PB)^2 - (AP)^2.$$
但从条件(1)可知，最后一个等式的左边等于$(BC_1)^2 - (C_1A)^2$，即$(BC_1)^2 - (C_1A)^2 = (PB)^2 - (AP)^2$，这意味着$P$点位于从$C_1$到AB的重新分配上，这就是需要证明的。

陈述 4. 根据条件 (1) 关于 $A$ 和 $A_1$、$B$ 和 $B_1$、$C$ 和 $C_1$ 的对称性，它完全成立。

练习
1. 使用陈述3，证明三角形的高相交于一点。

2. 给定三个两两相交的圆。证明任意两个圆的所有公共圆都经过一点。

3. 证明如果重新分布从点 $A_1$, $A_2$, ..., $A_n$ 落到线 $B_1B_2$, $B_2B_3$, ..., $B_nB_1$ 相交于一点，则
$$(B_1A_1)^2 - (A_1B_2)^2 + (B_2A_2)^2 - (A_2B_3)^2 + \dots + (B_nA_n)^2 = 0.$$

4. 取三个圆，每个圆都与三角形的一条边和另外两条边的延长线相接触。证明在这些圆的切点处恢复到三角形各边的重新分布相交于一点。

5. 设从某点$M$到三角形ABC的顶点$A$、$B$和$C$的距离分别用数字$a$、$b$和$c$表示。证明对于平面上任意点的任意$d \neq 0$，到相同顺序的顶点的距离不能用数字表示

$$\sqrt{a^2 + d}, \sqrt{b^2 + d}, \sqrt{c^2 + d}.$$

6. 给定一个正三角形 ABC 和一个任意点 $D$。 $A_1$、$B_1$和$C_1$是三角形BCD、ACD和ABD的内接圆的圆心。证明从顶点$A$、$B$、$C$下降到$B_1C_1$、$A_1C_1$、$A_1B_1$的重分布分别相交于一点。

7. 令 $A_1$、$A_2$、$A_3$ 和 $A_4$ 为平面上的任意点。证明有四个数 $x_1$、$x_2$、$x_3$ 和 $x_4$，且不全为零，因此可以针对该平面上的任意点 $M$ 构造 $x_1(A_1M)^2 + x_2(A_2M)^2 + x_3(A_3M)^2 + x_4(A_4M)^2$。

8. 给定三角形ABC。让我们考虑所有可能的点对$M_1$和$M_2$使得$AM_1 : BM_1 : CM_1 = AM_2 : BM_2 : CM_2$。证明所有直线$M_1M_2$都经过平面上的一个固定点。

9. 圆与三角形 ABC 的边 $AB$ 以及延长边 $AC$ 和 CB 分别相切于点 $M$ 和 $N$。另一个圆分别在点$P$和$K$处接触边$AC$和延伸边$AB$和$BC$。证明线$MN$和$PK$的交点位于通过顶点$A$的三角形ABC的高处。

10. 给定两个线段$AB$和$CD$。找到点 $M$ 的轨迹，从而构建和 $S_{\triangle ABM} + S_{\triangle CDM}$。

11. 利用上一题的结果，证明外接四边形的对角线中点和内切圆的圆心位于同一条直线上（牛顿问题）。

12. 证明一个点的轨迹是一个圆（阿波罗尼圆），该点是构成平面上两个固定点的相对点并且不同于统一。
