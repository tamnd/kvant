火车时不时地冲进隧道。真是令人叹为观止。所有的智者都聚集在瓦隆的走廊里，看着敞开的窗户，他们看不够。

突然，一条隧道里传来轰鸣声、烟雾、灰尘！某种污垢掉进了窗户里。我们穿过隧道，售票员走了进来。 “有人在这里弄脏了，”他说。 — 不幸的是，火车上没有水。不过现在连续停站的次数会多一些，你可以下车洗漱一下。”

现在我需要警告你 - 瓦罗纳的智者聚集在一起作为选择：他们既聪明又懒惰。比如说，没有人会徒劳地洗（除非他确信自己已经弄脏了）。他们不会问邻居他的地方是否干净或肮脏——为什么他们理所当然地打扰别人并担心自己呢？ - 请报告。

指南公布后智者们会做什么？

据说，如果其中n个人脸脏，那么在第n站，这n个智者都会下车洗澡。

让我们证明一下归纳法的说法。

情况 n = 1。当 n = 1 时，该语句非常indo。脸色严峻的圣人$M_1$会从售票员的广播中得知瓦罗纳里有脸脏的乘客。他环顾四周，发现他们的脸都很干净。所以说，脸脏的是他。因此，在第一站他就去洗澡。

从 n = k 到 n = k + 1 的转换。让我们证明，如果该陈述对于 n = k 成立，那么对于 n = k + 1 也成立

让智者$M_1$、……、$M_{k+1}$的脸沾上污点。然后$M_{k+1}$看到周围有k个灰脸（$M_1$，...，$M_k$），原因如下：

“可能有两种情况：
1) 我有一张干净的脸；
2) 我的脸很脏。

在第一种情况下，我在周围看到的所有 k 个面容可怕的智者都会在第 k 个站点出去洗澡（因为，根据 indukini 假设，该陈述对于 n = k 是正确的）。

由于第一种情况是可能的，所以我不应该在第k站或更早下车：如果我是干净的，这将是不可原谅的能源浪费！谁代替我得出这个结论，一个暴力的人，一个不容易大惊小怪的人*）。

不过，当然，第二种情况也是有可能的：也许我也板着一张严峻的脸。然而，然后，每个肮脏的圣人$M_1$，...，$M_k$看到他周围有k张肮脏的面孔。在这种情况下，明智而悠闲的他们都不会去第k站去洗漱（见上一段）。

所以，如果智者$M_1$，...，$M_k$在第k站没有去洗漱，那么我就是grizny，我应该去洗漱。我会等第k站。如果那里洗不了脸，就到下一（k+1）站下车洗脸！”

所有面容狰狞的智者都以同样的方式推理。因此，在第（k+1）站他们都会去洗漱，这是需要证明的。
