M2862。证明对于任意正 $b$ 和 $c$ 方程
$(x + b)(x + c) = 2\sqrt{xbc(x + b + c)}$
我们有一个正根。

我们来变换等式左边：
$$(x + b)(x + c) = x^2 + xb + xc + bc$$
$$= x(x + b + c) + bc.$$
根据正数 $A = x(x + b + c)$ 和 $B = bc$ 的柯西不等式 $A + B \geq 2\sqrt{AB}$，我们有
$$x(x + b + c) + bc \geq 2\sqrt{x(x + b + c)bc}.$$
我们看到，在我们的方程中，左边总是不小于右边，并且当且仅当$A = B$，即$x(x + b + c) = bc$时，才实现相等。可以求解所得的二次方程并找到其唯一的正根。
您可以不进行计算：$x \in (0; +\infty)$的等式左侧$x(x + b + c) = bc$从$0$返回到$+\infty$，并一次取所有正值。
这样，问题就解决了。
柯西不等式的使用可以用代数计算来代替，将原方程转化为$(A - B)^2 = 0.$的形式
