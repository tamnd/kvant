M2883。是否存在一个自然数 n，使得它的约数 a、b、c 中的任意三个都大于 1，其乘积 $(a-1)(b-1)(c-1)$ 能被 $n^2$ 整除？

答：不存在。
假设调用了这样的n、a、b和c。
不失一般性，我们假设$a \leq b \leq c$。
由于 c 是 n 的约数，因此 $n^2$ 可以被 $c^2$ 整除。因此，$(a-1)(b-1)(c-1)$可以被$c^2$整除。由于 gcd($c-1,c$) = 1，我们得到 $(a-1)(b-1)$ 可以被$c^2$整除。然而，$0 < (a-1)(b-1) < ab \leq c \cdot c = c^2$（由于$a \leq c$和$b \leq c$），这与$(a-1)(b-1)$能被$c^2$整除相矛盾。
还有其他解决方案，包括分析素数n在数n、a、b、c的展开式中出现的程度。
R·伊什库瓦莫夫

M2884。中土世界有1000个县，其中之一就拥有神奇的科利亚。每天一次，魔术师可以选择任何县的子集，并从魔法石接收这些县中是否有科利亚。一块石头可能会出错，但它绝不会连续两天出错。魔术师可以执行此操作一定天数，之后他必须将末端发送到 k 个县，其中一个是 Kolya 所在的县。魔术师在 k 最小的情况下可以做到这一点？

答案：2。
年级。让我们证明，当 k = 1 时，不能保证魔术师找到 Kolya。
让我们将没有环线的县称为虚假州。让石头回答这些烘焙问题，就像科利亚在真实的县一样，而在偶数的问题上 - 就好像它在虚假的县一样。那么，无论魔术师掠夺哪个郡县，都会出现两种情况：科利亚在真郡县或在假郡县。事实上，在第一种情况下，石头至少在偶数问题上正确回答，在第二种情况下，石头回答偶数问题。因此，魔术师无法通过任何问题来区分这些情况。

例子。让我们展示如何保证魔术师在 k = 2 的情况下找到 Kolya。让我们选择两个县 A 和 B，即第一个和第二个。我们连续问关于A、B、B、A的问题。以下情况是可能的。
1. 如果石头对前两个问题分别回答“是”和“否”，那么，由于这些答案中至少有一个是正确的，因此可以保证B县不存在戒指。
2. 如果他回答“否”和“是”，则 A 中没有环。
3. 如果石头对前两个问题的回答是“是”和“是”，那么，由于这些答案中至少有一个是正确的，魔术师会立即派使者去见A和B。
4. 如果石头对前两个问题的回答都是“否”和“否”，那么请看第三个问题。如果答案为“否”，那么由于第二个和第三个答案中至少有一个是正确的，因此 B 县没有环。如果第三个问题的答案为“是”，请看第四个问题。如果答案是“是”，则最后两个问题的情况与案例 3 相同。如果答案是“否”，则我们会得到与案例 1 相同的情况。
由于对 A 和 B 两个县采取了这样的行动，魔术师要么立即找到 Kolya，要么去了解其中一个县，里面没有戒指。因此，问题就简化为在较少数量的县中出现同样的问题。重复同样的步骤，魔术师就被添加到所需的魔术师中了。
M·费多莫娃
