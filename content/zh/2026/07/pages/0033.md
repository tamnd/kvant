让我们写出系统的平衡条件：
$(M + m)g = N_1 + N_2 + N_3$,
轴$x$的力矩规则：
$N_1a = mgy + N_2a + N_3a$
以及 $y$ 轴的力矩规则：
$N_3a = mgx + N_1a + N_2a$.

从最后两个方程我们找到 $N_2$：
$N_2 = -\frac{mg}{2a}(x + y)$.

为了防止桌面翻转，必须满足条件$N_2 \geq 0$，即
$y + x \leq 0$，或$y \leq -x$。

根据轴 $y$ 的矩法则，我们表达 $N_3$：
$N_3 = mg\frac{x}{a} + N_1 + N_2$,
让我们代入系统的平衡条件并定义$N_1$：
$N_1 = \frac{M + m}{2}g + \frac{mg}{2a}y$.

为了防止桌面翻转，必须满足条件$N_1 \geq 0$，即
$\frac{M + m}{2}g + \frac{mg}{2a}y \geq 0$,

或者
$y \geq -\left(1 + \frac{M}{m}\right)a$.

让我们定义$N_3$：
$N_3 = \frac{M + m}{2}g + \frac{mg}{2a}x$.

为了防止桌面翻转，必须满足条件$N_3 \geq 0$，或者
$\frac{M + m}{2}g + \frac{mg}{2a}x \geq 0$.

为了满足这个条件，需要
$x \geq -\left(1 + \frac{M}{m}\right)a$.

让我们代入 $m = 5M$ 并在桌面表面找到一朵同时满足所有三个不等式的云：
$y \leq -x$,
$y \geq -\left(1 + \frac{M}{m}\right)a = -\frac{6}{5}a$,
$x \geq -\left(1 + \frac{M}{m}\right)a = -\frac{6}{5}a$.
