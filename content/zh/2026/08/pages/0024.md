当参数的顺序改变时，音量不会改变。让我们把它放在一起
$$V(A, A, B) = V(A, B, A) = V(B, A, A).$$
类似地，$V_{\alpha A + \beta B + \gamma C}$在外部重复展开公式$(\alpha + \beta + \gamma)^3$，附加因子等于混合体积：
$$V_{\alpha A + \beta B + \gamma C} = V_A \cdot \alpha^3 + V_B \cdot \beta^3 + V_C \cdot \gamma^3 + 3(V(A, A, B) \cdot \alpha^2 \beta + V(A, B, B) \cdot \alpha \beta^2 + V(B, B, C) \cdot \beta^2 \gamma + V(B, C, C) \cdot \beta \gamma^2 + V(C, C, A) \cdot \gamma^2 \alpha + V(C, A, A) \cdot \gamma \alpha^2) + 6V(A, B, C) \cdot \alpha \beta \gamma.$$
等等。当然，大量项$\alpha A + \beta B + \ldots$的公式推广了少量项的公式——重置“额外”项的系数就足够了。

练习 27*。证明凸多面体 $A, B, C, D$ 和常数 $\lambda > 0$
a) $V(\lambda A, B, C) = \lambda V(A, B, C);$
b) $V(A + B, C, D) = V(A, C, D) + V(B, C, D).$
对于多重约束的混合执行量 $A \subset \bar{A}, B, C$
$$V(A, B, C) \leq V(\bar{A}, B, C).$$
然而，在缺乏 $V(A, B, C)$ 的透明几何解释的情况下，证明这个性质，尤其是它的 $n$ 泛化并不容易。从单调性很容易推导出 $V(A, B, C)$ 的非负性，并考虑其中一个多胞形退化为点的情况。
从 (16) 可以得出以下结论（替换后$\alpha = 1$）
$$V_{A+tB} - V_A = 3k_2t + 3k_1t^2 + V_Bt^3.$$
我们在平面情况下进行类似的推理，并尝试找出$t$处系数的几何意义。让我们修复小值$t > 0$。
总和 $A + tB$ 是多边形 $tB$ 到向量 $\overrightarrow{OX}$ 的移位的并集，其中 $X \in A$。这里我们遇到一个困难：多边形$A + tB$的几何描述比平面情况下多边形$A + tB$的描述复杂得多（记住图5）。但有个好消息：多边形 $A$ 和 $A + tB$ 的对应面的平面之间的距离（垂直于外部法线 $\vec{n}_i$）将等于 $ty_i$。在多面体$A$的每个面上，我们在其外部构造一个高度为$ty_i$的直棱柱$R_i$。对于小$t > 0$，棱镜$R_i$的圆圈$R$是集合$(A + tB) \setminus A$的一个很好的近似，即，可以证明，对于小$t$，体积$V_R$和$V_{(A+tB) \setminus A}$相差不超过const$\cdot t^2$。这意味着$V_R = \sum (a_i \cdot ty_i)$是增量$V_{A+tB} - V_A$的线性部分。我们看到$3k_2 = \sum a_i y_i$。这就是我们获得混合体积表达式的方法
$$V(A, A, B) = \frac{1}{3} \sum a_i y_i,$$
与扁平情况下的表达式（3）类似。
同样，$V(B, B, A) = \frac{1}{3} \sum b_i x_i$。当然，这里不能再谈论恒等式$\sum a_i y_i = \sum b_i x_i$，至少从“维度消息”来看是这样——参见练习27,a。
关于混合体积的一个强有力的结果是不平等
$$V(A, B, C)^2 \geq V(A, A, C) \cdot V(B, B, C).$$
因此，对于公式（16）和不等式（17）的系数序列$k_0 = V_B, k_1 = V(A, B, B), k_2 = V(A, A, B), k_3 = V_A$，我们得到
$$k_0 k_2 \leq k_1^2, k_1 k_3 \leq k_2^2.$$
对于混合 $n$ 维体积，$$^5$$ 更一般的 Aleksadrov-Fennel 不等式成立：
$$V(A, B, C, D, E, \ldots)^2 \geq V(A, A, C, D, E, \ldots) \cdot V(B, B, C, D, E, \ldots).$$
因此，本文第一部分中的“主要”不等式 (6) 被证明是 Aleksadrov-Fennel 不等式的二维特例。
