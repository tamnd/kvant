M645。地下室共有3条走廊（图1；$|OA| = |OB| = |OC| = l$），所有出口均已关闭。沃尼克督察和一名代表在那里。如果他们之间的距离不超过$r$，Warnicke 将替换代表。他知道代表的最高速度是自己最高速度的一半。初始时刻，检查员位于点$O$，并没有看到代表。如果$a) r = l/3, 6) r = l/4, \text{в})^* r > l/5, \text{в}) r > l/7$，沃尼克应该如何行动才能确保抓住代表。忽略走廊的宽度和人数。 （沃尼克必须提出这样一个行动计划，即使代表提前知道，他仍然无法履行服务）。

1. $r > l/5$处问题的解决方案（部分位于$r = l/3$和$r = l/4$处）。
首先，沃尼克“梳理”了走廊$OC$。确定代表不在那里后，Warnicke 退至走廊$OA$，距离$2r$，然后返回点$O$，以最大速度移动（下文中假设检查员始终以最​​大速度移动）。假设返回到点$O$后，检查员没有看到代表；在这种情况下，他对代表的可能下落了解多少？

1) 罪犯不能在走廊$OC$：很容易检查，如果在$O$点检查员不在期间，他试图从走廊$OB$跑到走廊$OC$，那么当检查员返回点$O$时，代表到$O$的距离不会超过$r$。

2) 如果罪犯在走廊$OA$，那么距$O$的距离大于$2r$：事实上，当检查员在走廊$OA$，距$O$距离$2r$时，那么罪犯（如果他在$OA$）距$O$的距离，大于$3r$，当检查员返回$O$点时，犯罪者到$O$的距离减少不超过$r$（图2）。

如果$r \geq l/3$，那么罪犯根本不可能在$OA$，这样问题a）就解决了：要收割罪犯，检查员只需将走廊$OB$探索到底即可。

如果$r < l/3$，那么检查员进一步行动的意义是深入到$OB$走廊，然后进入$OA$走廊，距离越来越远，但这样罪犯就无法跑到$OC$走廊。每一次这样的“深化”以及随后回到$O$点将被称为一个循环。第一个周期已经描述过。在第二个周期中，检查员前往距离$3r$的走廊$OB$。回到第$O$点，没有看到罪犯，检查员知道

1) 走廊$OC$中没有罪犯（如果罪犯在走廊$OA$，那么他距离$O$的距离大于$2r$，因此直到Warnicke返回点$O$，当他被移至走廊$OB$距离$3r$时，罪犯将无法跑到走廊$OC$以便与$O$的距离大于$r$）；

2) 如果犯罪者在走廊$OB$，那么他到$O$的距离大于$5r/2$（大于$(3r + r) - 3r/2$）。

如果$r \geq l/4$，那么犯罪者根本不能在走廊$OB$中（从那时起它的长度大于$3r + r = 4r \geq l$ - 一个矛盾）；这解决了问题 6)。

在编号为$n$的循环结束后，让检查员知道走廊$OC$内没有违法者，而在走廊$OX$（其中$n$奇数为$X = A$，$n$偶数$X = B$），违法者与$O$的距离不能小于或等于$y_n$。然后在下一个循环中，检查员前往距离 $y_n + r$ (图 3) 的另一条走廊。回到第$O$点，检查员知道

1) 走廊内没有违法者$OC$；

2) 在刚刚探索的走廊中，入侵者距离$O$不能小于或等于$y_n + r \geq l - r$，那么在探索的走廊中就根本不存在入侵者。

让我们找出 $y_n$ 的公式。从$y_n + 1 = \frac{y_n + 3r}{2}, 3r - y_n + 1 = \frac{3r - y_n}{2}$开始，从$3r - y_n = \frac{3r - y_1}{2^{n-1}} = \frac{r}{2^{n-1}}$开始，即

如果$y_n + r \geqslant l - r$在某个$n$，即$\frac{r}{2^{n-1}} \leqslant 5r - l$，罪犯就会被抓获。由此我们可以看出，如果$5r > l$，那么经过足够多的循环次数后，它就会被捕获。

2. $l/7 < r \leqslant l/5$问题的解决方案采用了以下新思路：在第1节中描述的足够多的循环次数之后，检查员必须深入到下一个走廊，距离不是$y_n + r$，而是$l - r$（即“读”到底），而不注意罪犯可以跑进走廊$OC$。

让我们输入$\varepsilon = \frac{7r - l}{2}$。检查员必须按照第 1 节中的描述进行操作，直到满足不等式$y_n \geqslant 3r - \varepsilon$。之后，检查员深入下一个走廊（例如，$OA$），距离$l - r$。返回$O$点，没有看到罪犯，检查员知道走廊$OA$没有罪犯，并且在走廊$OC$，罪犯距离$O$的距离不能超过$(l - r) - (3r - \varepsilon) = 3r - \varepsilon$。然后检查员深入走廊$OC$，距离$4r - 2\varepsilon$。返回到点$O$并且没有看到罪犯后，检查员知道走廊$OC$中没有罪犯（因为否则罪犯就会被发现，在走廊$OC$中距沃尼克的距离小于$(3r - \varepsilon) + (4r - 2\varepsilon)/2 - (4r - 2\varepsilon) = r)$，而在走廊$OA$中罪犯不可能与$O$相距更远） $3r - 2\varepsilon = (4r - 2\varepsilon) - r$ 然后检查员前往$OA$距离$4r - 4\varepsilon$的走廊，然后前往$4r - 8\varepsilon$距离的$OC$走廊，再次前往$4r - 16\varepsilon$距离的$OA$走廊，以此类推。走廊$OB$。

然后哎呀。可以证明，在$r \leqslant l/7$时，没有办法绝对了解罪犯。 I. Golubchka 和 V. Prasolova 所提供的这一事实的证据很复杂，因此这里不再给出。

第一个决定。让我们距离函数$f(x) = x^2 + \sqrt{x}$。计算出第二个乘积$f''(x) = 2 - \frac{1}{4}x^{-3/2}$后，我们看到$f''(x) \geqslant 0$位于$x \in \left[ \frac{1}{4}; +\infty \right]$。由此可见，在区间 $\left[ \frac{1}{4}; +\infty \right]$ 上，函数 $f$ 是向下凸的（用于积分）。

$$\frac{f(x) + f(y)}{2} \geq f\left(\frac{x+y}{2}\right).$$

将最后一个不等式应用于点$a^2, b^2$，我们得到了问题的陈述。

第二个解决方案。再次将 $a^2$ 替换为 $x$，将 $b^2$ 替换为 $y$。让我们考虑一下这个函数

$$\varphi(x, y) = \left(\frac{x-y}{2}\right)^2 - \sqrt{\frac{x+y}{2}} + \frac{\sqrt{x} + \sqrt{y}}{2}.$$

我们将假设 $x \geq y \geq 1/4$ 并检查函数 $\varphi(x, y)$ 的“$x$ 中的单调性”，将变量 $y$ 视为参数。

$$\varphi'_x(x, y) = \frac{x-y}{2} - \frac{1}{2\sqrt{2(x+y)}} + \frac{1}{4\sqrt{x}} =$$

$$= \frac{1}{2} \left(x-y + \frac{\sqrt{2(x+y)} - 2\sqrt{x}}{2\sqrt{x} \cdot \sqrt{2(x+y)}}\right) =$$

$$= \frac{x-y}{2} \cdot \left(1 - \frac{1}{\sqrt{x} \cdot \sqrt{2(x+y)} \cdot (\sqrt{2(x+y)} + 2\sqrt{x})}\right) \geq$$

$$\geq \frac{x-y}{2} \cdot \left(1 - \frac{1}{\frac{1}{2} \cdot 1 \cdot 2}\right) = 0,$$

也就是说，函数$\varphi(x, y)$是相对于$x$的非减函数。

因为在$x=y=\frac{1}{4}$，函数$\varphi$消失，$\varphi(x, y) \geq 0$在$x \geq y \geq \frac{1}{4}$，这给了我们所需的不等式。

仅当没有缩放时，该问题才允许明确的解决方案。这意味着球和夹子上的接触点轨迹的弧长必须相同，即

$$|\beta|R = |\gamma|r = |\Theta|\frac{R-r}{2} \text{ и } \beta R + \gamma r = 0.$$

这里$\Theta$是球相对于$\alpha = 0$处的静止报告系统的旋转角度，$\frac{R-r}{2}$是球的半径。从书面方程可以得出：

$$n_1 = n_0 + n_3, \ n_2 = n_0 + n_4, \ n_3R + n_4r = 0.$$

从这里我们可以找到球中心绕夹子轴的转数：

$$n_0 = \frac{n_1R + n_2r}{R + r}.$$

在同一时间段内，球将相对于静止报告系统旋转角度$\varphi = \alpha - \Theta$，其中$\Theta = \beta \frac{2R}{R-r}, \ \varphi = 2\pi n.$

因此，如果外圈旋转 $n_1$，而内圈旋转 $n_2$，则不会滑过环的球将会旋转

$$n = \frac{n_1R - n_2r}{R - r}$$

相对于静止观测的革命。

当磁场变化时，就会产生输出电场。通过了解电路中的感应电动势，可以找到距螺线管轴距离 $r$ 的点处的该场强度 $E$，该磁场代表半径为 $r$ 且绝对值等于 $a = \frac{\Delta v}{\Delta t} = \frac{eE}{m}$ 的圆。

这样，在短时间内$\Delta t$，电子的速度变化了数值$\Delta t$，即$\frac{eBr}{2m} \ll c.$
