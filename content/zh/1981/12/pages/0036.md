G·古列维奇

重量系统

埃尔德姆的问题

权重系是一组自然数，不可能从中提取两个具有相同总和的不同集合（例如，数字 1、3、7、20 形成权重系，但数字 1、2、3、4、5、8 不形成：2+3+4=8+1）。

1956年，匈牙利著名数学家P. Erdem提出了如下问题：找到最小的自然数m(k)，使得从不超过m(k)的自然数中，可以选择k个数的权重系统。

另一个从某种意义上来说，形象化的Erdem问题是在不超过给定自然数N的数字中找到最大数量的权重l(N)的任务。

尽管所提出的问题引起了数论、编码理论和组合分析专家的极大兴趣，但这些问题尚未得到完全解决。仅获得了数字 m(k) 和 l(N) 的一些估计，并且这些估计的准确程度仍然悬而未决。

在���题 M675（“Quant”，1981，第3期）中，我们邀请读者获得一些与Erdem问题相关的特定k和N的估计。也就是说，我们建议证明从小于1000的数字中，可以选择一个由10个数字组成的权重系统a)； b) 从 11 个号码开始； c) 从 14 个数字中不可能选择其中之一； f) 如果数字组成一个权重系统，那么它们的象征值之和不会超过 5/2。最后，我们建议 e) 从小于 700 的数字中，选择一个由 11 个数字组成的权重系统。

上面的估计

可以从非常简单的考虑中获得数字 m(k) 的一些粗略上限。

事实上，k 个数字 1, 2, ..., 2^{k-1} 形成任何自然数 k 的权重系统。

练习1.证明它。

因此，估计m(k) ≤ 2^{k-1}。特别是，从数字 1, 2, ..., 1000 中，权重系统与 10 个数字 1, 2, ..., 2^9 = 512 区分开来。这给出了 a) ���题 M675 点的解。

用 11 个数字（不超过 1000）构建一个权重系统是很容易的。

事实上，k 个数 3, 3·2, 3·2^2, ..., 3·2^{k-1} 也构成权重系统。

苏联。让我们将两个数字 3·2^{k-1} - 1 和 3·2^{k-1} + 1 相加，并证明所得数字也形成权重系统。

如果这些数字的任何集合包含两个相加的数字（则剩余数字的集合不包含它们），则其总和不小于 3 2^k，因此大于所有其他数字的总和。

如果任何集合包含一个相加的数字，则任何不包含该数字的集合将具有一个总和，当除以 3 时，得到的余数不同于原始集合的总和除以 3 时的余数。

对于 k=9，我们从 11 个数字中获得权重 3、6、12、...、767、768、769 的系统（这给出了第 6 点的解））。

因此，m(11) ≤ 769。一般来说，我们得到估计值 m(k) ≤ 3 2^{k-2} + 1。

分数

现在让我们尝试估计数字 m(k) 的大小。令 a₁ < a2 < ... < aₖ 为 k 个数的权重系统 (k>1)。

显然，ka_k - 1 ≥ a₁ + a2 + ... + aₖ。由于任意两组给定数字的和不同，并且一组 k 个数字的总数为 2^k - 1，因此我们得到不等式 a₁ + a2 + ... + aₖ ≥ 2^k - 1。

练习 2. 确保这一点。

因此ka_k≥2^k，即a_k≥2^k/k。特别是，对于 k=14，我们得到 a₁₄ ≥ 2^14/14 > 1000。这给出了 b) 点的解。

所以 m(k) ≥ 2^k/k。

现在我们可以估计总和$\frac{1}{a_1} + ... + \frac{1}{a_k}$。由于任何权重系统本身就是一个权重系统，因此不等式 a_i ≥ $\frac{2^i}{i}$ 对于任何大于 1 的 i 都有效。因此

$$\frac{1}{a_1} + \frac{1}{a_2} + ... + \frac{1}{a_k} \leq 1 + \frac{2}{2^2} + \frac{3}{2^3} + ... + \frac{k}{2^k}.$$

让我们计算总和 S(k) = $\frac{2}{2^2} + ... + \frac{k}{2^{k-1}}$，因此，

$$S(k) = 2S(k) - S(k) = 1 + \frac{1}{2^2} + \frac{1}{2^3} + ... + \frac{1}{2^{k-1}} - \frac{k}{2^k} = \frac{3}{2} - \frac{k+2}{2^k} < \frac{3}{2}.$$

因此，

$$\frac{1}{a_1} + \frac{1}{a_2} + ... + \frac{1}{a_k} < \frac{5}{2},$$

——d)点的陈述也已被证明。
