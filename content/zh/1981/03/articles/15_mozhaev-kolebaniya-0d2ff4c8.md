振荡

我们到处都会遇到犹豫。例如，各种磁铁和乐器外壳的振动、声波中的气体分子和海浪中的液体分子。振动运动是由固体中的原子和原子中的电子来执行的。收音机和电视机的电路中会出现电荷和电流的波动。根据同样的定律，电磁波中电场和感应场的方向会发生变化。

最令人惊奇的是，所有这些完全不同的物理现象都是由相同的数学方程描述的，也就是说，它们服从于同一个定律。正是基于这个立场，我们将考虑一些最简单振荡系统的例子。我们将限制自己只考虑自由振荡，当振荡系统没有外部影响时，系统的参数和振荡发生的条件不会随时间变化。

我们将忽略振荡系统中的能量损失，也就是说，我们将假设系统的总能量保持不变。当然，这是一种理想化，但如果能量损失明显小于系统的总能量，则在足够长的时间内系统实现的振荡将与理想化系统的振荡差别不大。

问题 1. 位于主水平表面上的质量为 m 的负载使用刚性弹簧 k (图 1, a) 连接到固定墙壁上。负载从平衡位置 00' 位移量 A0 并在没有初始速度的情况下释放。寻找：
1) 负载从平衡位置的位移随时间的变化； 2）负载速度的时间依赖性； 3）负载动能和弹簧势能的时间依赖性； 4) 给定系统的平均（每周期）动能和平均势能。

1) 假设在某个时刻 t，负载位于坐标 x (图 1, b) 的点。让我们写出负载沿 X 轴的运动方程。在此方向上，只有一个力作用在负载上 - 弹簧的弹力 $\vec{F}$，指向平衡位置 ($x=0$)。该力的投影为 $F=-kx$，因此负载的运动方程具有以下形式

$$ma = -kx,$$

(1)

其中$a$是给定时间负载加速度的投影。考虑到加速度是时间$(a = x'')$中的第二个任意坐标，我们将方程（1）重写如下：

$$x'' + \frac{k}{m} x = 0,$$

或者，用 $\omega_0^2$ 表示常数系数 $\frac{k}{m}$，-

$$x'' + \omega_0^2 x = 0.$$

(2)

所得方程描述了负载的简谐振动，即负载距平衡位置的位移按规律随时间变化的振荡

$$x = x_m \cos (\omega t + \varphi_0).$$

(3)

式(3)是式(2)的解。这里$x_m$是振幅，$\omega$是圆频率，$(\omega t + \varphi_0)$是相位，$\varphi_0$是振荡的初始相位。

为了找到圆频率，我们将解（3）代入方程（2）：

$$-x_m \omega^2 \cos (\omega t + \varphi_0) + \omega_0^2 x_m \cos (\omega t + \varphi_0) = 0,$$

或者

$$x_m \cos (\omega t + \varphi_0) \cdot (\omega_0^2 - \omega^2) = 0.$$

如果$x_m = 0$或$\omega_0^2 - \omega^2 = 0$，这个等式对于任何时间$t$都有效。由于振荡幅度不能等于零，因此仍然存在

$$\omega_0^2 - \omega^2 = 0,$$ 或 $\omega = \omega_0 = \sqrt{\frac{k}{m}}$。

我们得到了一个非常重要的结果：方程（2）中$x$的系数只不过是圆振动频率的平方。

现在让我们找出振荡的幅度和初始相位。为此，我们使用初始条件：在时间$t = 0$时刻，位移$x = A_0$和速度，即时间上的第一个任意坐标$v = x' = 0$。从第二个条件我们得到$\varphi_0 = 0$，从第一个条件我们得到$x_m = A_0$。

因此，根据法律规定，货物的混合物会随着时间的推移而变化

$$x = A_0 \cos \sqrt{\frac{k}{m}} t.$$

图 3.

2) 速度（更准确地说，它的投影）是时间上的第一个任意坐标，因此它取决于时间：

$$v = -A_0 \sqrt{\frac{k}{m}} \sin \sqrt{\frac{k}{m}} t.$$

图$x = x(t)$和$v = v(t)$如图2所示。

3) 任意时刻负载的动能$t$等于

$$E_k = \frac{mv^2}{2} = \frac{A_0^2 k}{2} \sin^2 \sqrt{\frac{k}{m}} t,$$

弹簧的势能是

$$E_\pi = \frac{kx^2}{2} = \frac{A_0^2 k}{2} \cos^2 \sqrt{\frac{k}{m}} t.$$

图3显示相应的图表。

4) 动能和势能的平均（每周期）值等于相应的值。

$$\overline{E_k} = \frac{A_0^2 k}{2} \sin^2 \sqrt{\frac{k}{m}} t = \frac{A_0^2 k}{4}$$

和

$$\overline{E_\pi} = \frac{A_0^2 k}{2} \cos^2 \sqrt{\frac{k}{m}} t = \frac{A_0^2 k}{4}$$

— $E_k$和$E_\pi$的平均值相同。 （这里使用的是一段时间内正弦平方的平均值等于余弦平方的平均值，并且等于1/2。）

从上一个问题的解可以清楚地看出，要找到振荡系统的频率$\omega$或周期$T(T=2\pi/\omega)$，只需绘制运动方程并将其简化为形式（2）即可。然后第二项的系数将给出频率的平方。

显然，式（2）中混合$x$的作用可以由任何其他物理量来发挥。让我们选择连接环的质心和点$O$的直线与垂直线形成的角度$\varphi$。

为了编制环的质心的运动方程，我们将考虑能量。在某些情况下，任意时刻$t$，环具有与质心沿半径$R-r$的圆运动相关的动能$E_{\kappa1}$、相对于质心的旋转运动的动能$E_{\kappa2}$以及地球引力场中的势能$E_{\pi}$。设圆环质心速度为$v$；那么动能是$E_{\kappa1}=mv^2/2$（m是环的质量）。由于环很薄，即其所有质量都集中在一个薄环中，因此动能为$E_{\kappa2}=mV^2/2$，其中$V$是环旋转运动的线速度。当滚动而不穿孔时$V=v$，因此

$$E_{\kappa2}=\frac{mv^2}{2}=E_{\kappa1}.$$

对于势能为零的水平，我们选择处于稳定平衡位置的环的质心水平，则在给定时刻环的势能将等于

$$E_{\pi}=mg((R-r)-(R-r)\cos \varphi)=
=mg(R-r)(1-\cos \varphi)=\frac{mg(R-r)\varphi^2}{2}$$

图 5.

（最后的近似等式是考虑到角度$\varphi$：$1-\cos \varphi=2\sin^2\varphi/2=\varphi^2/2$的小度而写的）。

总环能量

$$E_{\kappa1}+E_{\kappa2}+E_{\pi}=\frac{mv^2}{2}+\frac{mv^2}{2}+
\frac{mg(R-r)\varphi^2}{2}=mv^2+\frac{mg(R-r)\varphi^2}{2}$$

随着时间的推移保持不变。考虑到半径为$R-r$的圆内速度$v$与质心角速度的关系，则相对于质心的旋转运动的动能$E_{\kappa2}$和地球引力场中的势能$E_{\pi}$。设圆环质心速度为$v$；那么动能就是$E_{\kappa2}=mV^2/2$，其中$V$是环的旋转运动的线速度。当滚动而不穿孔时$V=v$，因此

$$\varphi'(\varphi''+\frac{g}{2(R-r)}\varphi)=0.$$

由于角速度$\varphi'$不等于0，所以等式

$$\varphi''+\frac{g}{2(R-r)}\varphi=0.$$

这就是环的运动方程。因此，圆形部分为$\omega=\sqrt{\frac{g}{2(R-r)}}$，振荡周期

$$T=\frac{2\pi}{\omega}=2\pi\sqrt{\frac{2(R-r)}{g}}.$$

问题 3. 在横截面积为 $S$ 的垂直圆柱形酱汁中，质量为 $M$ (图 5) 的大型活塞可以在没有托盘的情况下移动。容器内充满气体。在平衡位置，活塞和 souza 底部之间的质量为 $h$。确定活塞偏转时发生的小振动的周期

从平衡位置。大气压$p_0$，气体理想，气体温度恒定。

让活塞在某个时刻向下移动少量$x$。活塞下方气体体积的减少将等于$\Delta V = Sx$，这将导致气体压力增加$\Delta p$。让我们找出$\Delta V$和$\Delta p$之间的联系。因为线圈的制造工艺是$pV = \text{const}$，和$\Delta(pV) = 0$。因此，$V\Delta p + p\Delta V = 0$，或$\Delta p = -\frac{\Delta V}{V} p = -\frac{Sp}{V} x$。

对于小振荡 $\Delta V \ll V$ 和 $\Delta p \ll p$，因此

$$\Delta p = -\frac{(p_0 + Mg/S)}{h} x.$$

让我们写出活塞的运动方程：

$$Mx'' = \Delta p S,$$

或者

$$x'' + \frac{p_0 S + Mg}{Mh} x = 0.$$

从这里我们找到圆频率$\omega = \sqrt{\frac{p_0 S + Mg}{Mh}}$和振荡周期

$$T = \frac{2\pi}{\omega} = 2\pi \sqrt{\frac{Mh}{p_0 S + Mg}}.$$

问题 4. 由电容为 $C$ 的电容器和电感器 $L$ 组成的振荡电路通过开关 $K$ 连接到具有恒定 EMF $\delta$ 和内阻 $r$ (图 6) 的源。按键闭合，电路建立静态模式后闭合。求打开开关后电压对电容器时间的依赖性。考虑线圈的欧姆电阻。

当开关以静态模式通过线圈闭合时，电容器上的电流以及电容器上的电荷都等于零，因为电容器上的电压等于线圈两端的电压，并且在没有线圈的有源电阻的情况下，电容器上的电压为零。

打开钥匙后，自由的烧瓶将流入回路。假设在某个时刻电容器上的电荷等于$q$，并且电容器上的电压等于$u$。显然，此时线圈上的电压也等于$u$。当顶板带正电时，我们认为电容器两端的电压为正；对于电流的正方向，我们选择图 6 上箭头指示的方向。通过选择符号，电荷$q$、电压$u$ 和电流$i$ 之间的连接将如下：$i = -q'$、$q = Cu$、$u = Li'$。

因此$i = -Cu'$，$u = -LCu''$，或

$$u'' + \frac{1}{LC} u = 0.$$

我们再次有一个方程来描述电容器上电压$u$随时间变化的谐波短路。很容易证明电路中的电流$i$和电容器上的电荷$q$都按照类似的规律变化。你自己看看吧。

一般来说，电压与时间的关系如下：

$$u = U_M \cos (\omega t + \varphi_0).$$

这种情况下的振动频率等于

$$\omega = \sqrt{\frac{1}{LC}}.$$

幅值和初始相位可以从初始条件：时间$t = 0$$u = 0$和$i = \delta/r$找到。很容易证明满足此类初始条件的解将具有以下形式

$$u = \frac{\delta}{r} \sqrt{\frac{L}{C}} \sin \sqrt{\frac{1}{LC}} t.$$
