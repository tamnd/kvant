F631。连接到城市网络的螺旋线充满电流。螺旋的一半开始冷却（例如，通过水体）。这对这半个螺旋所看到的小牛数量有何影响？另一半？一切都是螺旋式的吗？

让我们将冷却开始前每半螺旋的阻力表示为$R$。由于金属的电阻取决于温度（加热时增加，冷却时减少），冷却螺旋的一半会导致该一半的电阻降低到某个值$R_1 < R$。由于电源电压 $U$ 不变，这将导致电路中的电流增加，从而导致线圈另一半的额外加热。这一半的电阻将增加并等于$R_2 > R$。

电路$I = \frac{U}{R_1 + R_2}$中的新电流值将大于先前值$I_0 = \frac{U}{2R}$。事实上，假设$I \leq I_0$。然后，未冷却的螺旋一半的电阻保持不变或减小（$R_2 \leq R$），冷却的一半的电阻$R_1 < R$。因此，总电阻为$R_1 + R_2 < 2R$，新的电流值为$I > I_0$，这与我们的假设相矛盾。

所以，$I > I_0$，因此整个链条释放的力量（即单位时间内的小牛数量）$P = IU$将会增加。

从$I > I_0$和$R_2 > R$开始，分配给未冷却一半的小牛$P_2 = I^2R_2$的数量也会增加。

相反，在冷却的一半中释放的功率$P_1 = I^2R_1 = \frac{U^2R_1}{(R_1 + R_2)^2}$将比初始功率$P_0 = I^2R = \frac{U^2}{4R}$减少。让我们展示一下。

让我们找出比率 $P_0/P_1$：

$$\frac{P_0}{P_1} = \frac{U^2}{4R} : \frac{U^2R_1}{(R_1 + R_2)^2} = \frac{(R_1 + R_2)^2}{4R_1R}$$

很明显

$$\frac{(R_1 + R_2)^2}{4R_1R} > \frac{(R_1 + R_2)^2}{4R_1R}$$

最后一个表达式大于或等于 1，因为两个量 $(\sqrt{R_1R_2})$ 的几何平均值不超过其算术平均值 $(\frac{R_1 + R_2}{2})$。

因此，实际上$P_1 < P_0$，即冷却的一半螺旋中释放的功率，将会减少。
