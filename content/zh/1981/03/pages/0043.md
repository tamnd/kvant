“几乎”这个词是体育的一个助词。

“给你，”彼佳想。 ——我明白了，它是一个粒子，还是一个粒子，它会是一个粒子吗，但是几乎——它是什么样的粒子？一个词就像一个词。然而，这无疑是一个服务词性，即要么是介词，要么是连词，要么是国际性，要么是助词。让我们假设“almost”这个词不是一个助词；那么它就是一个借口，或者是一个联盟，或者是国际。但这个词并不用于连接单词或句子的某些部分；而是用于连接单词或句子的一部分。这意味着它不是介词或连词。说“几乎”这个词是国际性的也是不正确的：它不表达任何感情，也不鼓励采取行动。因此，“几乎”这个词是一个助词，我通过反证论证证明了这一点。老师称赞佩蒂亚回答得刚刚好。

已经过去很多时间了。佩蒂亚和米蒂亚从六年级毕业并搬到了塞尔莫伊。在我高中课堂上的第一堂几何课上，解释了这个定理：如果两条线垂直于同一条线，那么它们就是平行的。为了证明这个定理：假设垂直于线 p 的线 a 和 b 相交于点 M。然后线 p 的两条垂线穿过点 M，这与定理“通过任何点，只有一条垂直于给定线”的定理相矛盾。老师说这是反证法。

“啊哈，”彼佳回忆起去年与米蒂亚的谈话，心想，“这个定理是用一个条件句的形式表述的：如果A，则B，而这样一个句子的否定就是句子A和（不是B），也就是说，右边的a和b垂直于线p并且相交。我们已经证明了命题A和（不是B）是假的，因为它与之前证明的定理相矛盾。所以，如果A，那么B是真的。一切都是对的。

在代数课上，需要证明这样一句话：如果自然数n小于1，则$\frac{1}{n} > n$。

老师把这个推理称为反证法：假设$\frac{1}{n} \leq n$；那么$\frac{1}{n} - n \leq 0$；由此得出$\frac{1 - n^2}{n} \leq 0$，由此得出$1 - n^2 \leq 0$、$1 \leq n^2$和$n \geq 1$。在彼佳看来，这并不完全是他所学的反证法，他决定与米佳讨论这个问题。他消除了心中的疑虑。

“看，”他说，“我们假设原始命题的否定是正确的：自然数 n 小于 1 且$\frac{1}{n} \leq n$。”

从这句话中可以得出一个反驳它的矛盾：同时$n < 1$和$n \geq 1$。因此，原句是正确的。正如你所看到的，这是真正的反证法。但这个问题可以用不同的方式来处理。我们最近讨论了“对等句子”这个话题。因此，句子 If A, then B 和 If (not B), then (not A) 是等价的，也就是说，对于任何 A 和 B，它们要么同时为真，要么同时为假。方法，
