引理1和2允许我们使用直线作为坐标轴，或者通过构造一个以点$O$为中心、对称轴$l$、$m$、$n$以及任意顶点$P$（图3）的长方体。

一个自然的问题出现了：什么样的（有限）线集可以与某个多边形的所有对称轴形成多边形？

给出了多边形对称轴$n$-角规则识别的各种示例（这里一系列轴$p = n$代表$n$奇数，$p = n + 1$代表$n$偶数），四面体（或具有不同边缘的长方体，$p = 3$），立方体（或八面体，$p = 9$）和十二面体（或二十面体，$p = 15$）。尝试证明不存在其他多边形对称轴（由多于一条直线组成）。

当然，这里我们不能没有这样一个非常有用的引理，许多读者在解决问题 6) 时都使用过它。

引理 3. 任何多边形的对称轴都相交于一点。

我们假设 $l$, $m$ - 不与多边形的对称轴相交 $M$。让 $n$ - 一般垂直 $l$, $m$;以点为原点的距离直角坐标系 $O = l \cap n$, 带轴 $Oz$，沿光束方向 $OA$， 在哪里 $A = n \cap m$;让 $|OA| = a$。然后，相对轴对称 $l$ 协调 $z$ 任何一点都去 $(-z)$，并且具有相对对称性 $m$ -V $(2a - z)$。因此，通过这两个对称性的组合 $z$ 更改为 $2a$。通过重复此组合足够多次，我们将“驱动”多边形外部的任何点 $M$。矛盾！

这是引理 3 的一个更短的证明（尽管使用了从力学借用的概念）：设 $O$ 为放置在多边形 $M$ 顶点的相同权重的质心；很明显，对于多边形 $M$ 的任何自对齐，权重仅改变位置，因此点 $O$ 变成了自身；特别是，所有对称轴$M$都穿过点$O$。

**M624。找到由条件$a_1 = 1$定义的序列$(a_n)$，

$$1 + \sum_{d} (-1)^{n/d} a_d = 0,$$

在食物中，总和$\sum$除以数字$n$的所有约数$d$（包括$d = 1$和$d = n$）。

例如，如果 $n = p$ 是质数，则 (*) 的形式为 $1 + (-1)^{p/1} a_1 + (-1)^{p/p} a_p = 0$，因此如果 $p = 2$ 则为 $a_p = 2$，如果 $p > 2$ 则为 $a_p = 0$。
