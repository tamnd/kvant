⟦folio 47⟧

$$ma = -kx,$$

(1)

其中$a$是给定时间负载加速度的投影。考虑到加速度是时间$(a = x'')$中的第二个任意坐标，我们将方程（1）重写如下：

$$x'' + \frac{k}{m} x = 0,$$

或者，用 $\omega_0^2$ 表示常数系数 $\frac{k}{m}$，-

$$x'' + \omega_0^2 x = 0.$$

(2)

所得方程描述了负载的简谐振动，即负载距平衡位置的位移按规律随时间变化的振荡

$$x = x_m \cos (\omega t + \varphi_0).$$

(3)

式(3)是式(2)的解。这里$x_m$是振幅，$\omega$是圆频率，$(\omega t + \varphi_0)$是相位，$\varphi_0$是振荡的初始相位。

为了找到圆频率，我们将解（3）代入方程（2）：

$$-x_m \omega^2 \cos (\omega t + \varphi_0) + \omega_0^2 x_m \cos (\omega t + \varphi_0) = 0,$$

或者

$$x_m \cos (\omega t + \varphi_0) \cdot (\omega_0^2 - \omega^2) = 0.$$

如果$x_m = 0$或$\omega_0^2 - \omega^2 = 0$，这个等式对于任何时间$t$都有效。由于振荡幅度不能等于零，因此仍然存在

$$\omega_0^2 - \omega^2 = 0,$$ 或 $\omega = \omega_0 = \sqrt{\frac{k}{m}}$。

我们得到了一个非常重要的结果：方程（2）中$x$的系数只不过是圆振动频率的平方。

现在让我们找出振荡的幅度和初始相位。为此，我们使用初始条件：在时间$t = 0$时刻，位移$x = A_0$和速度，即时间上的第一个任意坐标$v = x' = 0$。从第二个条件我们得到$\varphi_0 = 0$，从第一个条件我们得到$x_m = A_0$。

因此，根据法律规定，货物的混合物会随着时间的推移而变化

$$x = A_0 \cos \sqrt{\frac{k}{m}} t.$$

3) 任意时刻负载的动能$t$等于

$$E_k = \frac{mv^2}{2} = \frac{A_0^2 k}{2} \sin^2 \sqrt{\frac{k}{m}} t,$$

弹簧的势能是

$$E_\pi = \frac{kx^2}{2} = \frac{A_0^2 k}{2} \cos^2 \sqrt{\frac{k}{m}} t.$$

4) 动能和势能的平均（每周期）值等于相应的值。

$$\overline{E_k} = \frac{A_0^2 k}{2} \sin^2 \sqrt{\frac{k}{m}} t = \frac{A_0^2 k}{4}$$

和

$$\overline{E_\pi} = \frac{A_0^2 k}{2} \cos^2 \sqrt{\frac{k}{m}} t = \frac{A_0^2 k}{4}$$

— $E_k$和$E_\pi$的平均值相同。 （这里使用的是一段时间内正弦平方的平均值等于余弦平方的平均值，并且等于1/2。）
