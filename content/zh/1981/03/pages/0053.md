选项1
（力学与数学学院）

1. 查找$x$满足条件的所有值
$(x^2 - 4)\sqrt{x + 1} = 0$.

2. 找到方程的所有解
$\sin 2x = \sqrt{3}\sin x$.

3. 在梯形中，中线的长度为 4，其中一个底边的角度值为 $40^\circ$ 和 $50^\circ$。如果连接梯形底边中点的线段长度等于 1，求梯形底边的长度。

4. 函数$\sqrt[3]{x^2}$的图形的切线使得切点的横坐标$c$属于线段$\left[\frac{1}{2}, 1\right]$。当$c$为多少时，由这条切线、轴$Ox$和垂直线$x = 2$所围成的三角形的面积最小，这个最小面积等于多少？

5. 找到 $a$ 的所有值，其中每个值不等式
$$\log_1(\sqrt{x^2 + ax + 5} + 1) \cdot \log_5(x^2 + ax + 6) + \log_a 3 \geq 0$$
仅有一个解。

方案1问题分析
1. 回答。 $\{-1, 2\}$。
几乎所有申请人都成功完成了这项任务。然而，有些人写道
$$(x^2 - 4)\sqrt{x + 1} = 0 \iff \left[\frac{x^2 - 4}{x + 1} = 0\right];$$
而且，即使最终答案中没有包含$x = -2$这个值，审查员也不能认为问题完美解决。

2. 回答。 $x_1 = \pi m, x_2 = \pm \frac{\pi}{6} + 2\pi n(m, n \in \mathbb{Z})$。
笔记。该方程等于两个方程的组合：
$$\sin x = 0$$
$$\cos x = \sqrt{3}/2$$

3. 回答。 3和5。

解决方案。令$KM$为梯形的中线，$ABCD, LN$为连接底边BC和AD的线段，$BAD = 50^\circ$，$CDA = 40^\circ$。请注意，自 $BAD + CDA = 90^\circ < 180^\circ$ (图 1) 以来，$|AD| > |BC|$。设 $Q$ 为线 $AB$ 和 $DC$ 的交点。从$CB \parallel AD$开始，三角形$AQD$与三角形$BQC$相似。这就是为什么
$$\frac{|BQ|}{|AQ|} = \frac{|BC|}{|AD|} = \frac{|BC|/2}{|AD|/2} = \frac{|BL|}{|AN|}.$$
由于$QBC = QAD$和$\frac{|BD|}{|AQ|} = \frac{|BL|}{|AN|}$，三角形$QBL$和$QAN$相似。因此 $BQL = AQN$ 以及点 $Q, L, N$ 位于同一条直线上。三角形$AQD$是直角三角形，因为$AQD = 180^\circ - QAD - QDA = 90^\circ$。因此 $N$ 是围绕它描述的圆的中心；意思是$|QN| = \frac{|AD|}{2}$。同样，$|QL| = \frac{|BC|}{2}$。所以，
$$\frac{|AD|}{2} - \frac{|BC|}{2} = |QN| - |QL| = |LN| = 1.$$
根据梯形中线$\frac{|AD| + |BC|}{2} = |KM| = 4$的性质。
从系统$\left\{ \begin{array}{l} |AD| - |BC| = 2, \\ |AD| + |BC| = 8 \end{array} \right.$我们找到$|AD| = 5, |BC| = 3$。
只有大约一半的申请人能够完全应对这项任务。一些收到正确答案的申请人无法证明其合理性。例如，无需证明点 $Q, L, N$ 位于同一条直线上。
