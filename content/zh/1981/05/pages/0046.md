问题 4（密歇根州立大学，普通地质学院系，1979 年）。参数$SABC$的底是一个边长为$\sqrt{3}$的正三角形。从顶点 $S$ 下降的高度的底边是点 $O$，位于三角形 $ABC$ 内。点$O$到边$AC$的距离为1。角度$OBA$的正弦与角度$OBC$的正弦关系为2:1。面$SAB$的面积等于$\sqrt{\frac{5}{6}}$。查找体积参数。

解决方案。让我们分别用 $D, E, F$ (图 4) 表示从 $O$ 到边 $AB, BC, CA$ 的垂线的底。由三角形 $OEB$ 和 $ODB$

$$\frac{|OE|}{|OD|} = \frac{\sin OBC}{\sin OBA}.$$

所以，$|OE| = \frac{1}{2} |OD|$。从等式$S_{\triangle ABC} = S_{\triangle OAB} + S_{\triangle OBC} + S_{\triangle OAC}$得出$|OD| + |OE| + |OF| = h$，其中$h$是三角形$ABC$的高的长度。 （注意，对于等边三角形内的任何点$O$，这个等式显然是正确的。）由于$h = |BC| \times \sin 60^\circ = \frac{3}{2}$和$|OF| = 1$，我们得到

$$|OD| = \frac{1}{3}.$$意味着$|AB|$和$S_{\triangle SAB}$，我们找到$|SD|$。然后从$\triangle SOD$我们找到$|SO|$。回答。 $\frac{\sqrt{3}}{4}$。

通常，在入学考试中，提出的不等式方程组包含两个变量（例如，$x$和$a$），要求是找到一个变量（例如，$a$）的所有值，其中第二个变量（分别为$x$）或使用的方程（如果从角度上看）具有某种属性。 （在这样的问题中，变量 $a$ 通常称为参数。）

由于某种原因，许多教科书的作者，包括上述书籍的作者，倾向于通过对表示x到$a$的公式进行语法研究来解决此类问题，而更合适的“几何解决方案”是在平面$Oxa$上构造一个图（这种方法有时被称为“Och方法”）。从$Oa$轴“读取”所需的集合，从而结束解决方案。

问题 5（密歇根州立大学，政治经济学系，经济系，1977 年）。找到所有 $a$，其中每个不等式

$$3 - |x - a| > x^2$$

至少有一个负解。

解决方案。这个不等式等价于

$$|x - a| < 3 - x^2.$$

因此，系统

$$-(3 - x^2) < x - a < 3 - x^2.$$

波兹尼的问题可以重新表述如下：找到所有 $a$，对于每个系统

$$\begin{cases} x - a < 3 - x^2 \\ x - a > -(3 - x^2) \\ x < 0 \end{cases}$$

或系统

$$\begin{cases} a > x^2 + x - 3 \\ a < -x^2 + x + 3 \\ x < 0 \end{cases}$$
