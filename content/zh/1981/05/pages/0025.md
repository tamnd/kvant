M638。无限张方格纸的某些单元格涂成红色，其余单元格涂成蓝色，因此每个大小为 2x3 的 6 个单元格的矩形恰好包含两个红色单元格。一个大小为 9x11、有 99 个细胞的矩形可以包含多少个红细胞？

以精度$D$和$D_1$为三角形$MBP$和$M_1BP_1$的中心分别位于线段$MP_1$上并将其分成三等份。因此，$D_1E_1$是三角形$DP_1C$、$|D_1E_1| = \frac{1}{2}|DC| = |DE|$、$[D_1E_1] \parallel [DC]$的中线。但$[D_1E_1]$是由$[DE]$旋转60°得到的；因此$EDC = 60^\circ$。其余的都是显而易见的。

第三种解决方案（代数，但几乎不需要计算）。

令 1 为三角形 $ABC$ 的边长，$x$ 为三角形 $MBP$ 的边长 (图 6)。在$x=0$和$x=1$（参见图7）

$$|DC|^2 - |DE|^2 - |EC|^2 = 0.$$ (1)

对于 $x = \frac{1}{2}$ (图 8) 可以轻松验证等式 (1)。此时我们需要增加一点：让我们绘制$(DH) \parallel (AB)$和$(DF) \parallel (AC)$。我们有$|DH| = \frac{1}{3}, |HE| = \frac{1}{12}, |EK| = \frac{1}{4}, |DF| = \frac{1}{6}$，并且$DHE, EKC$和$DFC$每个角度都是120°。根据三角形 $DHE, EKC$ 和 $DFC$ 的余弦定理

$$|DE|^2 = \frac{1}{9} + \frac{1}{144} + \frac{1}{36} = \frac{21}{144}, |EC|^2 = \frac{1}{16} + \frac{1}{4} + \frac{1}{8} = \frac{63}{144}, |DC|^2 = \frac{1}{36} + \frac{4}{9} + \frac{1}{9} = \frac{84}{144},$$

由此而来的是（1）。

对应关系（1）的左边是一个从$x$开始的正方三角形（边长的平方可以用余弦定理从对应的三角形来表示）。由于上述原因，三个点（$x=0, x=\frac{1}{2}$和$x=1$）处的三角形消失了。这意味着它实际上也为零。

因此，对于所有$x$，满足（1），即对于所有$x$，三角形$DEC$是矩形：$DEC = 90^\circ$。

类似地，我们可以检查一个正方形是否是三角形。

$$|DE|^2 - \frac{1}{4} \cdot |DC|^2$$ (2)

在三个点 ($x=0; \frac{1}{2}, 1$) 也呈现零值，因此实际上也为零。所以，$|DE| = \frac{1}{2}|DC|$，即$CDE = 60^\circ$。

另一个第四个解决方案基于以下观察：三角形 $DPC$ 是通过以下中心子群从三角形 $DKE$ 获得的：以中心 $D$ 旋转 60° 角的组合，并准备系数 2。尝试编写此解决方案，使其同时适用于所有三种情况（参见 图 1, 2, 3）。
