⟦folio 47⟧

国立高尔基大学由此得名。 N·I·洛巴切夫斯基

数学
笔试
选项1
（广播系）

1. 找到$x$满足不等式的所有实值
$$x - 3 < \sqrt{x^2 + 4x} - 5.$$
2. 解方程
$$\cos x = \sqrt{3} \sin x + 2 \cos 3x.$$
3. 如果总表面积为 2π，请确定体积最大的圆柱体的尺寸。
4. 收割时，分配了几台相同的联合收割机，如果同时开始工作，24小时内即可收割田地。但很意外的是，他们每隔一段时间就开始陆续工作，然后各自工作直到清洁完成。如果第一个联合收割机的工作时间是最后一个的 5 倍，需要多长时间才能收割庄稼？
5. 证明$53^{53} - 33^{33}$能被10整除。

选项2
（计算数学与控制论学院）

1. 解方程
$$\sin 2x + \sin^4 \frac{x}{2} = \cos^4 \frac{x}{2}.$$
2. 找到$x$满足不等式的所有实值
$$\log_{0.25} \frac{35 - x^2}{x} \geq -\frac{1}{2}.$$
3. 等差数列的第三项和第九项之和等于三元组$2x^2 - 4x + 10$的最小值。求该级数相等的第一项之和。
4. 如果等边梯形的高度为$h$，并且从外接圆中心以角度$60^\circ$可以看到其边，请计算等边梯形的面积。

5. 共有三名工人参加了比赛。其中第一个的产量是第二个的两倍，第二个和第三个的产量是第一个的三倍。每位工人在比赛中获得了什么名次？

选项3
（力学、数学和物理学院）

1. 找到$x$满足不等式的所有实值
$$\log_3 \log_{1/2} \sqrt{\frac{1-x}{1+x}} \geq 1.$$
2. 求解方程组
$$\begin{cases} \cos x + \cos y = 1/2, \\ \sin^2 x + \sin^2 y = 7/4. \end{cases}$$
3. 半径为$R$的圆的动度是正三角形的底。计算位于给定圆之外的三角形部分的面积。
4. 求函数$y = 5 + 4 \cos x - \sin^2 x$在线段$[-\frac{\pi}{2}; \frac{\pi}{2}]$上的最多和最多的值。
5. 将数字 19 想象为自然数的立方之差。

物理
口语考试目标

1. 失重立式支架安装在一块质量为 $2m$ 的物体上，质量为 $m$ (图 1) 的球悬挂在长度为 $l$ 的失重杆上。一个块可以在没有摩擦的情况下在水平桌子上滑动。如果木块最初堆积并且球从$A$点释放而没有初始速度，那么球经过底部点时木块的速度是多少？
2. 两个质量分别为 $m_1 = 4$ kg 和 $m_2 = 8$ kg 的物体通过螺纹连接，沿着与地平线形成角度 $\alpha = 30^\circ$ 的斜面移动。斜面和物体之间的摩擦系数不同：对于第一个物体，它等于$\mu_1 = 0,1$，对于第二个物体，它等于$\mu_2 = 0,2$。如果质量体 $m_1$ 以水平加速度 $|\vec{a}| = g/2$ 移动，则弦的力是多少。
