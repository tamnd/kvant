莫斯科物理技术学院

数学
笔试
选项1

1. 解方程
$$10 \cos^2 x - 16 \sin x = \cos 2x + 15.$$

2. 在坐标平面上给出一个以点 (2; 3) 为圆心、半径为 $\sqrt{7}$ 的圆。找到该圆之外坐标满足方程组的所有点
$$\begin{cases} 3x + 3y - \frac{1}{2} = 4, \\ (2x - y)^2 = \frac{9}{4}. \end{cases}$$

3. 梯形$ABCD$的边$AB$和$CD$的长度分别为8厘米和10厘米，底边$BC$的长度为2厘米。角$ADC$的平分线穿过边$AB$的中点。求梯形的面积。

4. 正四边形帕拉酰胺的高度是其底边对角线的两倍，帕拉酰胺的体积是$V$。我们考虑将规则四边形特征写入paramid，使得它们的侧边平行于paramid的底面的对角线，一个侧面属于该底面，并且相对侧面的顶点位于paramid的侧面上。寻找：

a) 该特征的体积，其侧边缘平面以 4:1 的比例划分 paramid 的高度，从顶部开始计算；
b) 所考虑的识别量的最大值。

5. 求解方程组
$$\begin{cases} 2x^2y - xy^5z = z^2, \\ xz + 3y^4z^2 = 10x^2y^5, \\ 5y^4z + 3xy^8z^2 = 2x^2. \end{cases}$$

选项2

1. 解决不平等问题
$$\left(\frac{1}{4}\right)^x - 32 \left(\frac{1}{8}\right)^{x^2-1} < 0.$$

2. 解方程
$$\log_{\cos x} \left( \frac{\sin 2x}{\sqrt{2}} + \cos x - \sin^2 x - \sqrt{2} \sin x \right) = 2.$$

3. 圆中有两条互相垂直且相交的弦$AB$和$CD$。已知$|AB| = |BC| = |CD|$。确定哪个更大：圆的面积或边长为 $AB$ 的正方形的面积。

4. 找到方程组中$a$的所有值
$$\begin{cases} 2^x(y+1)(1-y \cdot 2^x) = a^3, \\ (1+2^x)(1-y \cdot 2^x) = a \end{cases}$$
a) 无解；
b) 有无限多个解。在情况 6) 中，它包含所有解决方案。

5. 正四边形Param的底边长度为$a$，Param的边心长度为$\frac{3}{2}a$。帕酰胺在垂直于侧面之一的平面上的正交投影是等腰梯形。求这个梯形的面积。

选项3

1. 解方程
$$2x - \sqrt{x^3 + 2x^2 - 3x} = 0.$$

2. 解决不平等问题
$$\log_{\frac{x-1}{5x-6}} (\sqrt{6} - 2x) < 0.$$

3. 一个圆内接于一个等边梯形。圆心到梯形对角线交点的距离与半径的关系为3比5。求梯形的周长与圆的长度之比。

4. 在坐标平面上，我们考虑坐标$(a; b)$满足条件$a < b$、$|a| < 3$、$|b| < 3$的所有点的集合$N$，并且使得方程
$$\left(a^3 - b^3\right)x^4 + (3a + b)x^2 + \frac{1}{a-b} = 0$$
无根。

a) 点$P(-2; -1)$属于集合$N$吗？

b) 求内部区域为集合$N$的多边形的面积。

5. 在立方体$ABCDA_1B_1C_1D_1$的边$BB_1$上，我们取点$F$，以便$|B_1F| = \frac{1}{3} |BB_1|$，在边$C_1D_1$上，我们取点$E$，以便$|D_1E| = \frac{1}{3} |C_1D_1|$。当点 $P$ 位于射线 $(DE)$ 上，点 $Q$ 位于直线 $A_1F$ 上时，关系 $\frac{|AP|}{|PQ|}$ 可以取的最大有效值是多少？问题选项1的解决方案

1. 将$\cos^2 x$和$\cos 2x$用$y = \sin x$表示，我们得到系统
$$\begin{cases} 4y^2 + 8y + 3 = 0, \\ |y| \leq 1, \end{cases}$$
从哪里$y = -\frac{1}{2}$。剩下的就是求解方程$\sin x = -\frac{1}{2}$。
