不仅以分数的形式。是的，$\frac{1}{2} = \frac{2}{4} = \frac{3}{6} = \dots$。

我们将根据保留属性$1^0$的需要，寻找度$a^r$的定义，其中$a > 0$、$r = \frac{m}{n}$。这意味着对于任何$r_1$和$r_2$，对应关系$a^{r_1} + a^{r_2} = a^{r_1} \cdot a^{r_2}$必须成立。

假设我们已经知道 $a^{\frac{m}{n}}$ 是什么。让$a^{\frac{m}{n}} = k$。

那么应该是$(a^{\frac{m}{n}})^n = k^n = a^{\frac{m}{n}} + \frac{m}{n} + \dots + \frac{m}{n} = a^m$。最后我们得到$k = \sqrt[n]{a^m}$。

该对应关系提出了以下定义：

极限 4. 如果$a > 0$，则$a^{\frac{m}{n}} = \sqrt[n]{a^m}$。请注意，对于负数$a$，具有有理非整数指数的度数概念没有定义。我们还注意到，在教科书中，在研究有理指数度数之前，有一个主题“$n$度数的根及其性质”（“代数8”，§9），其中推导了$n$度数根的基本性质，使我们能够证明我们采用的$a^r$定义是正确的。在本例定义的正确性下，概念是数$a^r$与以分数形式写数$r$的独立性，即在最后的情况下，等式$\sqrt[n]{a^m} = \sqrt[n]{a^{km}}$，其中$k \in \mathbb{N}$、$m \in \mathbb{Z}$、$n \in \mathbb{N}$有效。

练习 3. 复习 $n$ 次方根的性质，并从中导出 $1^0 - 6^0$ 次方有理指数的性质。

具有实数指数的度数。

在教科书“代数和入门分析 10”中，介绍了具有任意实指数的指数函数（第 108 节）。事实上，这里的任务也是找到

*) “代数 8”，第 10 节。

具有实指数的幂的“良好”定义，并且指数函数本身的定义列出了可以从这个“良好”定义推导出来的属性。具有任何实数指数的度的“好”定义是什么？

为了确定性，设 $a > 1$。如果$x$是有理数，那么$a^x$已经被我们定义了，函数$y = a^x$凭借属性$5^0$，返回到所有有理数的集合$Q$（对于$0 < a < 1$，函数$y = a^x$将（属性$6^0$）杀死到该集合$Q$）。

为了将函数$y = a^x$扩展到所有实数的集合$R$，我们首先只要求该函数是多重相关的。

令$a$为无理数，$r_1$和$r_2$为$r_1 < a < r_2$的无理数。假设我们已经知道 $a^a$ 是什么。根据我们的要求，不等式必须有效

$$a^{r_1} < a^{a^a} < a^{r_2}.$$

因此，数字 $a^a$ 必须包含在任意两个数字 $a^{r_1}$ 和 $a^{r_2}$ 之间，其中 $r_1 < a < r_2$。

在微积分课程中，已证明存在一个唯一数$b$，其所有不等式$a^{r_1} < b < a^{r_2}$均成立，其中$r_1$和$r_2$是任意有理数，$r_1 < a < r_2$。

这允许以下定义：

在极限 5 上。设 $a$ 为无理数且 $a > 0$。那么$a^a$是任意两个数$a^{r_1}$和$a^{r_2}$之间包含的实数，其中$r_1$和$r_2$是无理数，$r_1 < a < r_2$。

学校课程的范围不允许我们证明数字$a^a$的存在，我们会相信它。我们仅限于证明独特性。

为了证明这一点，我们需要重要的伯努利不等式$(1 + h)^n \geqslant 1 + nh$，其中$n \in \mathbb{N}$和$h \geqslant -1$。
