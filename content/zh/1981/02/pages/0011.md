⟦folio 9⟧

当前温差$T_1 - T_0$将为
$$\mathcal{E} = \left( \alpha_1 + \alpha_{11} \right) \left( T_1 - T_0 \right).$$

因此，$I$出现在由热电偶支路的内部电阻$R_0$和接收器的外部电阻$R_0$组成的闭合电路中，将等于
$$I = \frac{\mathcal{E}}{R + R_0}.$$

我们在应用中获得的有用功率$P$可以表示为
$$P = UI,$$

其中$U$是外部电阻$R$两端的电位差。由于我们在这里讨论的直流电路中的电位下降与电阻成正比，因此
$$\frac{U}{\mathcal{E}} = \frac{R}{R + R_0}, \quad U = \frac{\mathcal{E} R}{R + R_0},$$

一个
$$P = \frac{\mathcal{E}^2 R}{(R + R_0)^2}.$$

将 $\mathcal{E}$ 与其值一起代入，我们得到热电偶提供的有用功率 $P$ 的通用表达式：
$$P = \left( \alpha_1 + \alpha_{11} \right)^2 \left( T_1 - T_0 \right)^2 \frac{R}{(R + R_0)^2}.$$

当 $R = R_0$ 时，$P$ 达到纳米级值（请自行证明 - 编者注）；热电偶在外部应用中可以产生的最大功率为
$$P_{\max} = \frac{\left( \alpha_1 + \alpha_{11} \right)^2 \left( T_1 - T_0 \right)^2}{4R}.$$

热电偶产生的全部电力将是
$$\mathcal{E} I = \frac{\left( \alpha_1 + \alpha_{11} \right)^2 \left( T_1 - T_0 \right)^2}{2R}.$$

为了维持温差，需要不断地将热能传递到热端以及相对地从冷端传递。方法，

所提供的温暖用户体验的主要部分是通过两个分支到冷端的热传导来实现的。热电偶产生的部分电力被浪费在加热两个分支上。这些不可逆过程急剧降低热电偶的效率。如果可以完全避免它们（这是不可行的，因为任何半导体都具有导热性和电阻），那么热电偶将根据热力学定律给出最大允许的效率系数

$$\eta_{\max} = \frac{T_1 - T_0}{T_1}.$$

在无线电接收器温度计的例子中，我们可以取$T_1 = (350 + 273) \text{K} = 623 \text{K}$和$T_0 = (50 + 273) \text{K} = 323 \text{K}$，从哪里
$$\eta_{\max} = \frac{623 - 323}{623} = 0.48 = 48\%.$$

实际上，效率系数 $\eta$ 温巴特林按百分比略有不同。这个例子显示了热传导过程和电流释放乔林热的过程所发挥的巨大作用。

如果我们有兴趣获得可能的效率$\eta$，而不是最大功率$P$，则外部电阻$R$和内部$R_0$之间的对应关系应以不同方式选择：$R$应大于$R_0$。在这种情况下，在热电偶产生的所有功率$\mathcal{E} I$中，使用了超过一半的功率$P$。

对热电偶的分析表明，与热范围可能值$\eta_{\max}$相比，效率系数$\eta$多次急剧下降，这主要是由热传导的不可逆过程引起的。让我们转向传热机制的问题；内部温度以两种方式同时发生 - 由于： 1) 来自电气的热量传递
