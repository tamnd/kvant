回答。 $x = (-1)^n \frac{\pi}{6} + \pi n \ (n \in \mathbb{Z})$。

这个任务很简单，但非研究生申请人无法正确解决。主要错误是他们没有丢弃二次方程的第二根$y = -\frac{3}{2}$并考虑表达式arcsin$\left(-\frac{3}{2}\right)$。反三角函数的知识在口语考试中也很引人注目。

2. 从第二个方程我们立即看到$y = 2x - \frac{3}{2}$或$y = 2x + \frac{3}{2}$。

在第一种情况下，我们得到方程$3^x + 3^{2x-2} = 4$，通过替换$z = 3^{x-1}$，将其简化为根为$z_1 = -4, z_2 = 1$的二次方程$z^2 + 3z - 4 = 0$。

从$z > 0$开始，我们得到$3^{x-1} = 1$，由此得到$x = 1, y = \frac{1}{2}$。

在第二种情况下，与第一种情况一样，我们得到方程 $3z^2 + z - 4 = 0$，其中 $z = 3^x$；解决它，我们找到$x = 0, y = \frac{3}{2}$。

找到的解可以通过点$M\left(1; \frac{1}{2}\right)$和$N\left(0; \frac{3}{2}\right)$在坐标平面上描绘。从点 $M$ 到给定圆的中心 $O(2; 3)$ 的距离是 $\sqrt{(1-2)^2 + \left(\frac{1}{2} - 3\right)^2} = \frac{1}{2} \sqrt{29} > \sqrt{7}$。

同样$|ON| = \sqrt{(0-2)^2 + \left(\frac{3}{2} - 3\right)^2} = \sqrt{\frac{25}{4}} = \frac{5}{2} < \sqrt{7}$。

因此，点$M$位于圆之外。

回答。 $\{(1; \frac{1}{2})\}$。

在解决这个问题时，非投票申请人无法正确写出点$(x; y)$位于给定圆之外的条件。

3. 设$E$为线段$AB$的中点。我们来画梯形$ABCD$的中线$EF$。由$ADE = DEF$、$(EF) \parallel (AD)$、$ADE = EDF$（根据条件），我们得到$DEF = EDF$，即三角形$EFD$是等边三角形。所以，$|EF| = |FD| = \frac{1}{2} |CD| = 5$。波兹尼$|AD| = 2 |EF| - |BC| = 8$。让我们画一条与边 $CD$ (图 1) 平行的线段 $BG$。我们有$|BG| = 10; |AG| = |AD| - |DG| = |AD| - |BC| = 6$（$BCDG$是平行四边形）。这意味着三角形的边长是$ABG$，我们可以计算出角度$BAG$。由余弦定理

$$\cos(\widehat{BAG}) = \frac{|BG|^2 - |AB|^2 - |AG|^2}{2|AB||AG|} = \frac{100 - 64 - 36}{2 \cdot 8 \cdot 6} = 0,$$

即$\widehat{BAG} = 90^\circ$。这意味着$AB$是梯形$ABCD$的高度，梯形的面积是$8 \cdot 5 = 40$。

回答。 40 平方厘米。

不幸的是，只有少数申请人找到了这里给出的简单几何解决方案。一些人尝试使用向量来解决问题，另一些人看到大量新参数（例如梯形的角度）并重复应用余弦定理，另一些人则使用平分线的底除三角形边的比率定理。

4. 让我们用 $A_1, B_1, C_1, D_1$ (图 2) 表示金字塔“上”侧面的平面与金字塔 $SABCD$ 侧边的交点，并用 $O_1$ 表示金字塔高度 $SO$ 与该平面的交点。让我们用$b$表示边$EH$的长度，用$a$表示底边$EE_1$的长度，用$H$表示金字塔的高度$SABCD$。让点$O_1$除以比例$\lambda : \frac{|O_1O|}{|SO|} = \lambda$（显然是$\lambda \in [0; 1]$）。

从$|O_1O| = |E_1E| = a$开始，我们有$a = \lambda H$。给定距离意味着线段 $F_1G, E_1H_1$ 和 $A_1C_1$ 成对平行。我们来求对角线 $A_1C_1$ 的长度。根据三角形$ASC$和$A_1SC_1$的相似性，我们有$\frac{|A_1C_1|}{|AC|} = \frac{|SO_1|}{|SO|}$，因此

$$|A_1C_1| = \frac{H}{2} \cdot \frac{H - \lambda H}{H} = (1 - \lambda) \frac{H}{2}.$$

我们求出识别的侧边$E_1H_1$的长度$b$：$b = |A_1C_1| - 2 |KE_1| = |A_1C_1| - |E_1F_1| = (1 - \lambda) \frac{H}{2} - \lambda H = (1 - 3\lambda) \frac{H}{2}$。
