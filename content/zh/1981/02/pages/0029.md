M620。令$x_1, x_2, \dots, x_n$为实数，使得$x_1^2 + x_2^2 + \dots + x_n^2 = 1$。证明$2^n$数的模型之和

$$\pm x_1 \pm x_2 \pm \dots \pm x_n$$

（因此对于符号“+”和“-”的所有可能组合）不超过 $2^n$。

我们首先证明，如果$a_1^2 + a_2^2 + \dots + a_k^2 = k$，则$a_1 + a_2 + \dots + a_k \leq k$。事实上，让 $a_i = 1 + a_i$ ($i = 1, 2, \dots, k$)。然后

$$a_1^2 + a_2^2 + \dots + a_k^2 = k + 2(a_1 + \dots + a_k) + (a_1^2 + \dots + a_k^2),$$

在哪里

$$a_1 + a_2 + \dots + a_k = -\frac{1}{2} (a_1^2 + a_2^2 + \dots + a_k^2) \leq 0.$$

波塞托姆

$$a_1 + a_2 + \dots + a_k = k + (a_1 + a_2 + \dots + a_k) \leq k.$$

现在让我们表示模型 $2^n$ 数字的总和

$$\pm x_1 \pm x_2 \pm \dots \pm x_n$$

（因此符号“+”和“-”的所有可能组合）到$S$。很容易检查总和$S$中包含的所有$2^n$数字的平方和等于$2^n (x_1^2 + x_2^2 + \dots + x_n^2) = 2^n$。我们用 $a_1, a_2, \dots, a_{2^n}$ 来表示 $S$ 中包含的 $2^n$ 数字。然后$a_1^2 + a_2^2 + \dots + a_{2^n} = 2^n$，由上面证明的陈述，我们得到估计$a_1 + a_2 + \dots + a_{2^n} \leq 2^n$，这就是我们需要证明的。

正如我们来自顿河畔罗斯托夫的读者 A. Heiftz 正确替换的那样，���题 M620 是 M. Klamkin 的以下承诺的特例（美国数学月刊，1975 年，82，第 8 期，第 829-830 页）：

令 $x_1, x_2, \dots, x_n$ 为任何实数。那么对于 $\lambda \geq 2$ 和 $\lambda \leq 0$ 不等式成立

$$\sum |\pm x_1 \pm x_2 \pm \dots \pm x_n|^\lambda \geq 2^n \left( \sum_{i=1}^{n} x_i^2 \right)^{\lambda/2},$$

对于 $0 < \lambda < 2$ - 具有相反含义的不等式。 （对左侧“+”和“-”符号的任意组合求和。）我们邀请您考虑自己证明这个陈述。
