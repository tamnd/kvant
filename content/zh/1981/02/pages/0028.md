M618。 a) 证明有无穷多个自然数 n 使得 n!能被$n^2+1$整除。

b) 证明对于任何 a>0，有无数个正整数 n 使得 $[\alpha n]!$ 可以被 $n^2+1$ 整除。 （这里 m!=1·2·...·m；[x] 是数字 x 的整数部分。）

例如，让我们证明有无数个 n $n^2+1$ 具有$5m^2$ 的形式。换句话说，方程 $n^2-5m^2=-1$ 有无数个自然解。这个陈述源自以下两个事实，每个事实都可以直接验证：对$n=2$，m=1满足这个方程，如果n=a，m=b是它的解，那么对$n=9a+20b$，m=4a+9b也是如此（这些公式是如何做到这一点的，在N.Vaguten的文章“Number Conjugation”中解释，«Kvant»，1980年，第10期）。 2）。

这立即为我们提供了问题 a) 陈述的证明。事实上，对于 n 的找到值，我们有 $n^2+1=5m^2$、$m=\sqrt{\frac{n^2+1}{5}}<\frac{n}{2}$ 和 n！可被 $n^2+1$整除，因为对于 n>5，乘积 1·2·3·...·n 包含数字 5、m 和 2m。

对于一般情况 6) 也可以这样做。但为此，我们必须证明存在无限多个自然 D，使得方程 $n^2-Dm^2=-1$ 的自然解的数量是无限的（然后选择 D 使得不等式 $D\geqslant5/\alpha^2$ 成立，我们将获得所需的 n 值）。这个说法是正确的，但是它的基本证明非常困难，所以我们将采取不同的路线。

我们将在$2k^2$形式的数字中寻找我们需要的n。在本例中，$n^2+1$ 分解为乘积 $n^2+1=4k^4+1=(2k^2+2k+1)(2k^2-2k+1)$，但这还不够。让我们展示如何获得多个 k 使得数字 $P(k)=2k^2+2k+1$ 和 $Q(k)=2k^2-2k+1$ 是合数（可因式分解）。让我们取自然乘积 c 并设 p=P(c), q=Q(c)。那么对于任何 l，数字 P(c+lpq) 都可以被 q 整除（证明一下！）。设$P(c+lpq)=p\cdot r$和$Q(c+lpq)=q\cdot s$。通过使 c 足够大，我们可以使 p=P(c) 和 q=Q(c) 大于 5/a（这是根据 P(k) 和 Q(k) 随着 k 的增加而无限增加的事实得出的）。在本例中，为 $n^2+1=4k^4+1=P(k)\cdot Q(k)=p\cdot q\cdot r\cdot s$，其中 $k=c+lpq$、$r=P(k)/p<\frac{P(k)}{5/\alpha}<\frac{an}{4}$（对于 k>5）和 $s=Q(k)/q<\frac{Q(k)}{5/\alpha}<\frac{an}{4}$（对于 k>5）。现在选择 l 使得 p 和 q 小于 an/4，我们发现在序列 1, 2, 3, ..., [an] 中有四个不同的数字，其中一个可以被 p 整除，另一个可以被 q 整除，第三个可以被 r 整除，第四个可以被 s 整除。因此，我们构造了一个无限多重响应 n，使得 [an] 可以被$n^2+1$整除。

该问题的其他解决方案也是可能的。最短的似乎是基于分解

$$64m^{12}+1=(4m^4+1)(4m^4-4m^3+2m^2-2m+1)\times(4m^4+4m^3+2m^2+2m+1)$$

（这个解决方案是由我们的读者 V. Yudakov 提出的）。

M619。证明如果方程 $|CD|=|AD|+|BC|$ 对于悬挂四边形 ABCD 成立，则其角 A 和 B 的二等分线相交于边 CD。

该问题本质上需要证明存在无限多个正整数 n，使得 $n!$ 可以被 $n^2+1$ 整除。

例如，让我们证明，存在无限多个自然 n，使得方程 $n^2-Dm^2=-1$ 的自然解的数量是无限的（如果我们选择 D 使得不等式 $D\geqslant5/\alpha^2$ 成立，我们将获得所需的 n 值）。这个说法是正确的，但是它的基本证明非常困难，所以我们将采取不同的路线。

在边 CD 上取一点 K，使得$|DK|=|AD|$，$|KC|=|BC|$（参见图），并围绕三角形 ABK 画一个圆。令 M 为该圆与 [CD] 的第二个交点。让我们证明 [AM] 和 [BM] 是相应角度的二等分线。例如，对于 [AM]，我们有 $BAM=BKC=90^\circ-\frac{BCK}{2}=90^\circ-\frac{1}{2}(180^\circ-DAB)=\frac{1}{2}DAB$，这就是所需的。
