对数方程

在入学考试中，您经常会遇到包含对数符号下的变量的方程。此类方程通常称为对数方程。

最简单的对数方程是 $\log_a x = b$ 形式的方程。如果$a > 0$、$a \neq 1$和$b > 0$，它有一个根$x = a^b$。

在下文中，我们经常会用到对数的以下性质：

$$\log_a xy = \log_a x + \log_a y,$$

$$\log_a \frac{x}{y} = \log_a x - \log_a y,$$

$$\log_a x^\alpha = \alpha \log_a x,$$

$$\log_a x^\beta = \frac{1}{\beta} \log_a x,$$

$$\log_a x = \frac{\log_b x}{\log_b a}$$

（这里到处都是$a > 0$，$a \neq 1$，$b > 0$，$b \neq 1$，$x > 0$，$y > 0$）。记住公式 (5) 的这种特殊情况也很有用：

$$\log_a x = \frac{1}{\log_x a}.$$

现在让我们看看一些常见类型的对数方程。

示例 1：求解方程

$$\log_4 x + \log_1 x + \log_8 x^3 = 5.$$

解决方案。利用性质 (4)，我们将所有对数都以 2 为底；考虑到性质 (3)，我们得到

$$\frac{1}{2} \log_2 x - \frac{1}{4} \log_2 x + \log_2 x = 5,$$

$\frac{5}{4} \log_2 x = 5$、$\log_2 x = 4$、$x = 16$。

回答。 {16}。

有时，经过一些变换，方程可以简化为以下形式

$$f(\log_a x) = 0.$$

式(6)代入$y = \log_a x$并求出方程$f(y) = 0$的根后的解与最简单方程$\log_a x = y$的解一致。因此，主要任务是找到将原始方程转化为（6）形式的方程的变换。

实施例 2（MIIGAiK，1977）。解方程

$$(\log_x 9x^2) \cdot \log_3^2 x = 4.$$

解决方案。传递到以 3 为底的对数，我们得到等效方程

$$\frac{\log_3 9x^2}{\log_3 x} \cdot \log_3^2 x = 4,$$

从哪里$(2 + 2 \log_3 x) \cdot \log_3 x = 4$。轮询$y = \log_3 x$，我们得到二次方程$y^2 + y - 2 = 0$，从中可以得到$y = -2$或$y = 1$。剩下的就是求解最简单的方程$\log_3 x = -2$和$\log_3 x = 1$。

回答。 $\left\{ \frac{1}{9}, 3 \right\}$。

示例 3：求解方程

$$x^{\lg x} = 10^2 \lg^2 x - 3 \lg x + 2.$$

解决方案。这里 $x$ 位于对数符号下方，因此$x > 0$。左右两边取以 10 为底的对数，得到等价方程

$$\lg^2 x = 2 \lg^2 x - 3 \lg x + 2.$$

轮询$y = \lg x$，我们得到二次方程$y^2 - 3y + 2 = 0$，它有根$y_1 = 1$和$y_2 = 2$。

回答。 {10, 100}。

通常还有以下形式的方程

$$\log_a f(x) = g(x)$$

或导出形式(7)的方程。

等式（7）（对于$a > 1$、$a \neq 1$）等价于等式$f(x) = a^{g(x)}$。
