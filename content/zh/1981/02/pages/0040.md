⟦folio 38⟧

我们用数学归纳法来证明一下。

对于$n = 1$，这个不等式成立$(1 + h) \geqslant 1 + h)$。让我们假设$(1 + h)^k \geqslant 1 + kh$并证明$(1 + h)^{k+1} \geqslant 1 + (k+1)h$。我们有$(1 + h)^{k+1} = (1 + h)(1 + h)^k \geqslant (1 + h)(1 + h)^k = 1 + hk + h^2k = 1 + h(k+1) + h^2k \geqslant 1 + h(k+1)$，这是我们需要证明的。

现在让我们证明$\lim_{n \to \infty} \sqrt[n]{a} = 1$对于$a > 0$。

给定$\varepsilon > 0$和$a > 1^*$，然后给出$\sqrt[n]{a} = 1 + \varepsilon_n$，其中$\varepsilon_n > 0$。因此，应用伯努利不等式，我们得到$a = (1 + \varepsilon_n)^n \geqslant 1 + n\varepsilon_n$。因此$0 < \varepsilon_n \leqslant \frac{a-1}{n}$。很容易看出$\frac{a-1}{n} < \varepsilon$位于$n > N = \left[ \frac{a-1}{\varepsilon} \right] + 1$。

这样我们就证明了$\lim_{n \to \infty} \varepsilon_n = 0$，但这也意味着$\lim_{n \to \infty} \sqrt[n]{a} = \lim_{n \to \infty} (1 + \varepsilon_n) = 1$。

现在让我们继续证明唯一性。

假设存在 2 个数字 $\beta$ 和 $\gamma$，对于其中 $r_1 < a < r_2$，不等式 $a^1 < \beta < a^2$ 和 $a^1 < \gamma < a^2$ 对于任何有理数 $r_1$ 和 $r_2$ 均有效。让我们定义$\beta > \gamma$。

然后$0 < \beta - \gamma < a^2 - a^1 = a^1(a^2 - r_1 - 1)$。显然$a^1 < a^{[a]+1} = c$。对于任何$n \in \mathbb{N}$，都存在$r_1^{(n)}$和$r_2^{(n)}$，使得$r_1^{(n)} < a < r_2^{(n)}$和$r_2^{(n)} - r_1^{(n)} < \frac{1}{n}$。

对于这些$r_2^{(n)}$和$r_2^{(n)}$（根据有理指数的属性$5^0$）$0 < \beta - \gamma < c\left(\frac{1}{n} - 1\right)$。

根据之前的证明，对于任何$\varepsilon > 0$，都存在一个$N$，因此对于所有$n > N$，不等式$a^{\frac{1}{n}} - 1 < \frac{\varepsilon}{c}$成立。因此，对于任何$\varepsilon > 0$，不等式$0 < \beta - \gamma < \varepsilon$都是有效的，但这是不可能的。

根据定义5，我们可以证明对于实指数的度，我们为自然指数建立的所有属性$1^0 - 6^0$都被保留。这样就完成了函数$y = a^x$的构建。

*) 听着$0 < a < 1$自己想办法。

应该注意的是，在定义无理指数的度数时，我们放弃了之前接受的方案：我们可以仅根据以无限多种方式保留属性$1^0$的需要来构建定义。

更准确地说，存在无限多重函数$y = f(x)$，使得$f(x) = a^x$对于$x \in \mathbb{Q}$，对于$f(x + y) = f(x) \cdot f(y)$。

在所有这些函数中，只有一个我们构造的函数 $y = a^x$ 是单调（且连续）的。这个家庭的所有其他功能都安排得相当疯狂。例如，它们中的任何一个都不限于数值轴的任何间隔。

如何计算$2\sqrt{2}$？

让我们考虑几个十进制近似值 $\sqrt{2}$ 来表示不足和过剩。这些近似满足不等式$1 < \sqrt{2} < 2; 1,4 < \sqrt{2} < 1,5; 1,41 < \sqrt{2} < 1,42$。然后，根据我们的定义 5，数字 $2\sqrt{2}$ 必须满足不等式 $2^1 < 2\sqrt{2} < 2^2; 2^{1,4} < 2\sqrt{2} < 2^{1,5}; 2^{1,41} < 2\sqrt{2} < 2^{1,42}$ 或 $2 < 2\sqrt{2} < 4; 2,6 < 2\sqrt{2} < 2,9; 2,65 < 2\sqrt{2} < 2,68$。

第二个不等式使我们能够以高达整数的精度求出 $2\sqrt{2}$，第三个不等式的精度高达十。可以理解的是，通过采取适当的近似值$\sqrt{2}$，可以获得任何给定精度的$2\sqrt{2}$值。
