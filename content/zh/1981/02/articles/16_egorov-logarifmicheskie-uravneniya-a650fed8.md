对数方程

在入学考试中，您经常会遇到包含对数符号下的变量的方程。此类方程通常称为对数方程。

最简单的对数方程是 $\log_a x = b$ 形式的方程。如果$a > 0$、$a \neq 1$和$b > 0$，它有一个根$x = a^b$。

在下文中，我们经常会用到对数的以下性质：

$$\log_a xy = \log_a x + \log_a y,$$

$$\log_a \frac{x}{y} = \log_a x - \log_a y,$$

$$\log_a x^\alpha = \alpha \log_a x,$$

$$\log_a x^\beta = \frac{1}{\beta} \log_a x,$$

$$\log_a x = \frac{\log_b x}{\log_b a}$$

（这里到处都是$a > 0$，$a \neq 1$，$b > 0$，$b \neq 1$，$x > 0$，$y > 0$）。记住公式 (5) 的这种特殊情况也很有用：

$$\log_a x = \frac{1}{\log_x a}.$$

现在让我们看看一些常见类型的对数方程。

示例 1：求解方程

$$\log_4 x + \log_1 x + \log_8 x^3 = 5.$$

解决方案。利用性质 (4)，我们将所有对数都以 2 为底；考虑到性质 (3)，我们得到

$$\frac{1}{2} \log_2 x - \frac{1}{4} \log_2 x + \log_2 x = 5,$$

$\frac{5}{4} \log_2 x = 5$、$\log_2 x = 4$、$x = 16$。

回答。 {16}。

有时，经过一些变换，方程可以简化为以下形式

$$f(\log_a x) = 0.$$

式(6)代入$y = \log_a x$并求出方程$f(y) = 0$的根后的解与最简单方程$\log_a x = y$的解一致。因此，主要任务是找到将原始方程转化为（6）形式的方程的变换。

实施例 2（MIIGAiK，1977）。解方程

$$(\log_x 9x^2) \cdot \log_3^2 x = 4.$$

解决方案。传递到以 3 为底的对数，我们得到等效方程

$$\frac{\log_3 9x^2}{\log_3 x} \cdot \log_3^2 x = 4,$$

从哪里$(2 + 2 \log_3 x) \cdot \log_3 x = 4$。轮询$y = \log_3 x$，我们得到二次方程$y^2 + y - 2 = 0$，从中可以得到$y = -2$或$y = 1$。剩下的就是求解最简单的方程$\log_3 x = -2$和$\log_3 x = 1$。

回答。 $\left\{ \frac{1}{9}, 3 \right\}$。

示例 3：求解方程

$$x^{\lg x} = 10^2 \lg^2 x - 3 \lg x + 2.$$

解决方案。这里 $x$ 位于对数符号下方，因此$x > 0$。左右两边取以 10 为底的对数，得到等价方程

$$\lg^2 x = 2 \lg^2 x - 3 \lg x + 2.$$

轮询$y = \lg x$，我们得到二次方程$y^2 - 3y + 2 = 0$，它有根$y_1 = 1$和$y_2 = 2$。

回答。 {10, 100}。

通常还有以下形式的方程

$$\log_a f(x) = g(x)$$

或导出形式(7)的方程。

等式（7）（对于$a > 1$、$a \neq 1$）等价于等式$f(x) = a^{g(x)}$。

示例 4：求解方程
$$\log_3(4 \cdot 3^{x-1}-1) = 2x-1.$$
解决方案。该等式等价于：
$$4 \cdot 3^{x-1}-1 = 3^{2x-1}.$$
代入$y=3^x$，我们得到二次方程
$$y^2-4y+3=0;$$
解决它，我们发现$y_1=1, y_2=3.$
回答。 {0,1}。
形式方程
$$\log_{g(x)}f(x)=a$$
(8)
相当于系统
$$\begin{cases}
f(x)=[g(x)]^a, \\
g(x)>0, \\
g(x)\neq 1.
\end{cases}$$

示例 5（MSU，地质部门，1966 年）。解方程
$$\log_{(x+1)}(x^2+x-6)^2=4.$$
解决方案。该方程等效于系统
$$\begin{cases}
(x^2+x-6)^2=(x+1)^4, \\
x+1>0, \\
x+1\neq 1.
\end{cases}$$
我们有$(x^2+x-6)^2-[(x+1)^2]^2=0$，从哪里
$$[x^2+x-6+(x+1)^2][x^2+x-6-(x+1)^2]=0,$$
所以这个系统的方程等价于：
$$(2x^2+3x-5)(x+7)=0,$$
从哪里$x_1=1, x_2=-\frac{5}{2}, x_3=-7.$
系统仅满足值$x=1$。
回答。 {1}。
在某些情况下，经过变换后，原方程可以简化为以下形式
$$\log_a f(x)=\log_a g(x).$$
(9)
容易看出式(9)的每一个根都满足系统
$$\begin{cases}
f(x)=g(x), \\
f(x)>0.
\end{cases}$$

反之，如果$x_0$是系统(9')的解，则$\log_a f(x_0)=\log_a g(x_0)$，因此系统(9')的任何解也满足方程(9)。因此，方程(9)等价于系统(9')。

例 6：解方程
$$\log_8(7x^2-5x-6)=2\log_4\sqrt{3x-1}.$$
解决方案。对数以 2 为底进行化简，得到等价方程
$$\log_2(7x^2-5x-6)=\log_2(3x-1),$$
相当于系统
$$\begin{cases}
7x^2-5x-6=3x-1, \\
3x-1>0.
\end{cases}$$
求解系统，我们得到
$$x=\frac{4+\sqrt{51}}{7}$$
($3x_2-1<0$).
回答。 $\{\frac{4+\sqrt{51}}{7}\}$。

现在让我们注意一下学生在求解对数方程时所犯的一些错误。
大多数情况下，这些错误与错误应用乘积、分数和幂的对数公式有关。
例如，在求解例 5 中的方程时，一些小学生会这样写：
“它的条件是$2\log_{(x+1)}(x^2+x-6)=4$，由此产生$x^2+x-6=(x+1)^2$或$x=-7$。但是$x=-7$不满足原方程，因此它没有根。”
根$x=1$丢失的原因是公式的应用
$$\log_a x^2=2\log_a x,$$ 仅适用于$x>0$。在我们的例子中，表达式 $x^2+x-6$ 与 $x=1$ 是不同的。
这里我们应该使用公式$\log_a x^2=2\log_a|x|$，它对于所有$x \neq 0$都成立。
另一个例子。解方程
$$\log_2[(x+1)(x-3)]=2\log_4(x+8)-\log_1[(x+1)(x-5)],$$
学生把他带到了视线中
$$\log_2(x+1)+\log_2(x-3)=\log_2(x+8)+\log_2(x+1)+\log_2(x-5),$$
或者
$$\log_2(x-3)=\log_2[(x+8)(x-5)].$$
(10)
之后，他得到了二次方程$x^2+2x-37=0$，也就是我们的$x_1=-1+\sqrt{38}, x_2=-1-\sqrt{38}$。

由于不满足方程（10），学生丢弃了第二个根，并得到了答案$x = -1 + \sqrt{38}$。

这是怎么回事？公式$\log_a xy = \log_a x + \log_a y$仅对$x > 0$和$y > 0$有效。因此，乘积和乘积取对数时，丢了根$x = -1 - \sqrt{38}$，实际上满足了原方程。

要看到这一点，请注意原始方程等效于系统
$$\begin{cases} \log_2(x+1)(x-3) = \\ = \log_2(x+8)(x+1)(x-5), \\ x+8 > 0, \end{cases}$$

$$\begin{cases} (x+1)(x-3) = \\ = (x+8)(x+1)(x-5), \\ x+8 > 0, \\ (x+1)(x-3) > 0. \end{cases}$$

最后一个系统的解是$\{-1 - \sqrt{38}, -1 + \sqrt{38}\}$。

一般来说，“从右到左”使用公式$\log_a u^2 = 2\log_a u$和$\log_a uv = \log_a u + \log_a v$会导致方程定义域的扩展，这可能需要使用构造根。如果所得方程的根非常简单并且验证并不繁琐，则根本没有必要写出方程组和不等式。您可以更改为方程并在解的末尾进行检查。

示例 7. 求解方程 $\log_{\frac{1}{2}}(x-1) + \log_{\frac{1}{2}}(x+1) - \log_{\frac{1}{\sqrt{2}}}(7-x) = 1$。

解决方案。以 2 为底的对数并重新排列右侧的项，我们得出方程
$$2\log_2(7-x) = \\ = 1 + \log_2(x-1) + \log_2(x+1),$$
由此我们得到方程结果
$$(7-x)^2 = 2(x^2-1),$$
或者
$$x^2 + 14x - 51 = 0.$$
这个二次方程的根是$x_1 = 3, x_2 = -17$。

第二次根显然不满足这个方程。将值 $x = 3$ 代入其中，我们确保 $x = 3$ 是其真正的根。

回答。 {3}。

最后，这是另一个例子，说明学生在使用转移到另一个基地的公式时如何失去根。

示例 8. 求解方程 $\log_{2x}x + \log_{8x^2}x = 0$。

“解决方案”。前往基地$x$，我们得到
$$\frac{1}{\log_x 2 + 1} + \frac{1}{2 + 3\log_x 2} = 0.$$
代入$y = \log_x 2$，我们得到方程
$$\frac{1}{y+1} + \frac{1}{3y+2} = 0.$$
这个方程有根$y = -\frac{3}{4}$。因此$\log_x 2 = -\frac{3}{4}$，从哪里
$$x_1 = 2^{-\frac{4}{3}} = \frac{1}{2^3\sqrt{2}}.$$
值$x = \frac{1}{2^3\sqrt{2}}$满足方程。然而，很容易看出值$x = 1$也是它的根。怎么了？

当移动到基数$x$时，根$x = 1$丢失了，因为到基数$x$，因为到基数$x$，因为其余的$x$按原样解决。

回答。 $\{1, \frac{1}{2^3\sqrt{2}}\}$。

一般来说，最好避免跳转到依赖于$x$的碱基。如果过渡到这样的基数，那么您需要非常仔细地监视哪些 $x$ 可以进行转换，并通过将基数等于 1 或负数的那些值 ​​$x$ 代入原始方程来检查。

因此，在求解最后一个方程时，最好以 2 为底。结果，我们得到

现在考虑两个问题，其解决方案利用了某些函数的单调性。

示例 9. 求解方程 $\log_5(x + 3) = 3 - x$。

解决方案。很容易检查$x = 2$是这个方程的根。它显然没有其他根，因为函数$\log_5(x + 3)$返回其整个定义域，而函数$y = 3 - x$杀死。

回答。 {2}。

示例 10. 求解方程 $(x + 1)\log_3^2 x + 4x\log_3 x - 16 = 0$。

解决方案。让我们设置 $y = \log_3 x$ 并求解 $y$ 二次方程 $(x + 1)y^2 + 4xy - 16 = 0$。

我们得到$y = \frac{4}{x + 1}$或$y = -4$。还有两个方程需要解：

$$\log_3 x = \frac{4}{x + 1} \text{ и } \log_3 x = -4.$$

这些方程中的第二个很容易求解，要求解第一个方程，只需替换 $x = 3$ 满足方程，并且左侧的函数在 $x > 0$ 返回，右侧的函数就杀死。

回答。 $\left\{\frac{1}{81}; 3\right\}$。

总之，考虑一个从其他考虑因素中求解出来的方程。

例 11. 求解方程 $3x^2 - 2x^3 = \log_2(x^2 + 1) - \log_2 x$。

解决方案。等式右侧定义为 $x > 0$，等于 $\log_2\left(x + \frac{1}{x}\right)$。从 $x + \frac{1}{x} \geq 2$ $x > 0; \log_2\left(x + \frac{1}{x}\right) \geq 1$ 开始。另一方面，$3x^2 - 2x^3 \leq 1$ 对应$x > 0$（例如，您可以通过使用任意函数检查函数来验证这一点）。 $\log_2\left(x + \frac{1}{x}\right) = 1$ $x = 1$。由于$3x^2 - 2x^3$在$x = 1$处也等于1，因此左侧仅在$x = 1$处等于右侧。

回答。 {1}。
