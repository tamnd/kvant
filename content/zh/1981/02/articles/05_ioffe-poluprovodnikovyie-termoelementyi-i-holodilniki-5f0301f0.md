所提供的温暖用户体验的主要部分是通过两个分支到冷端的热传导来实现的。热电偶产生的部分电力被浪费在加热两个分支上。这些不可逆过程急剧降低热电偶的效率。如果可以完全避免它们（这是不可行的，因为任何半导体都具有导热性和电阻），那么热电偶将根据热力学定律给出最大允许的效率系数

$$\eta_{\max} = \frac{T_1 - T_0}{T_1}.$$

在无线电接收器温度计的例子中，我们可以取$T_1 = (350 + 273) \text{K} = 623 \text{K}$和$T_0 = (50 + 273) \text{K} = 323 \text{K}$，从哪里
$$\eta_{\max} = \frac{623 - 323}{623} = 0.48 = 48\%.$$

实际上，效率系数 $\eta$ 温巴特林按百分比略有不同。这个例子显示了热传导过程和电流释放乔林热的过程所发挥的巨大作用。

如果我们有兴趣获得可能的效率$\eta$，而不是最大功率$P$，则外部电阻$R$和内部$R_0$之间的对应关系应以不同方式选择：$R$应大于$R_0$。在这种情况下，在热电偶产生的所有功率$\mathcal{E} I$中，使用了超过一半的功率$P$。

材料的导热系数用一定的系数$x$来表征，可以按下式确定。如果我们采用具有单位横截面的给定物质的圆柱棒，其中每单位长度温度变化一度，则每单位时间从热端到冷端的方向传递的热量等于$x$。

如果棒的横截面积为$S$，长度为$L$，两端温差为$\Delta T$，则在$t$时间内，热量将通过热传导从热端传递到冷端

$$Q = \frac{\Delta T}{L} St.$$

另一方面，给定物质中相同电子引起的电流由其特定电导率$\sigma$决定。在长度为 $L$ 、横截面为 $S$ 、两端之间存在电势差 $\Delta U$ 的同一根杆中，时间 $t$ 将通过电量

$$q = \frac{\Delta U}{L} St.$$

Wiedemann 和 Franz 纯粹凭经验建立了各种金属的热导率 $x$ 和电导率 $\sigma$ 之间的联系。即：经验表明

$$\frac{x}{\sigma} = A_M T,$$

其中 $T$ 是绝对温度，$A_M$ 是所有金属的相同因子。量子半导体理论也得出对应关系$\frac{x}{\sigma} = A_\pi T$，但系数$A_\pi$有不同的含义。

$x$和$\sigma$之间的这种对应关系使得从根本上不可能实现反向热电偶。对于导热系数，需要$x=0$；为了产生焦耳热，热水泥分支的电阻率必须等于零，并且倒数$x$ - 无穷大。但同时存在$x=0$和$\sigma \rightarrow \infty$的要求与Wiedemann-Franz定律不相容。

让我们继续考虑第二种类型的热导率。除了通过电子传递热量之外，半导体中的导热性还通过晶格原子的热运动来实现。这个过程的机制可以想象如下。混沌热传导其最多样化的振动。这包括单个原子相对于另一个原子的振动，以及它们成对、三个等的振动，直至整个身体作为一个整体的振动。温度越高，波动越剧烈。这些众多的振动中的每一个都以弹性波的形式在体内传播，传递其能量。

因此，半导体的导热系数$x$由两部分组成：由电子产生的导热系数$x_{эл}$，以及由本体原子的热运动产生的导热系数$\cdot x_\phi$。值$x_{эл}$与比电导率$\sigma$成正比。因此，随着半导体中自由电子浓度的变化，系数$x_{эл}$与$\sigma$成比例变化，而$x_\phi$几乎保持不变。总导热系数$x$可表示为

$$x = A_\pi T \sigma + x_\phi.$$

我们对真实情况的实验证实了$x$对$\sigma$的依赖性。

热电偶支路的导热系数$x_1$和$x_{11}$在决定其效率方面起着重要作用；除此之外，两个分支的热电动势$a_1$和$a_{11}$以及电阻率$q_1$和$q_{11}$也很重要。计算表明，在给定热端温度 $T_1$ 和冷端 $T_0$ 的情况下，热电偶的效率系数由一个值 $z$ 确定，具体取决于热电偶材料的列出特性：

$$z = \frac{(\alpha_1 + \alpha_{11})^2}{(\sqrt{x_1 q_1} + \sqrt{x_2 q_2})^2}.$$

$z$越大，效率越高；对于给定值 $z$ ，无论 $a$、$x$ 和 $q$ 的值分别如何，它始终相同。计算还表明，效率不取决于热电偶分支的尺寸和形状，而仅取决于$T_1$、$T_0$和$z$。热元件效率可表示为：

$$\eta = \frac{T_1 - T_0}{T_1} \frac{\sqrt{1 + \frac{1}{2} (T_1 + T_0) z} - 1}{\sqrt{1 + \frac{1}{2} (T_1 + T_0) z} + \frac{T_0}{T_1}}.$$

对于金属，$z$的值相当于几个单位乘以$10^{-5}$，对于半导体，$10^{-3}$及更高，即几十倍。因此，在$z$这样的值下，半导体热电偶的效率比金属热电偶高数十倍。

热电电池由热电偶制成。如果需要获得显着的电压，则需要相继使用大量的热电偶。因此，在热电动势$a_1 + a_{11} = 4 \cdot 10^{-4} \text{B/°C}$和温差$T_1 - T_0 = 30^\circ \text{C}$的情况下，一个元件的电动势为$\mathcal{E} = 0,12 \text{B}$。为了产生 120 伏的电动势，需要串联 1000 个这样的元件。如果需要获得大电流，则将元件并联。

通过热接点每平方厘米进入的热量越多，发射电能的热电偶套管的尺寸就越小。这些消息决定了一种或另一种热套管设计的选择。恒温器的效率并不取决于连接元件的方法或其形状。

冰箱

塞贝克发现后不久，珀尔帖在 1834 年观察到了一种与热电密切相关的现象（然而，珀尔帖本人并不怀疑）。珀尔帖想要证明弱电流加热导体并不遵守所有导体共有的焦耳-楞次定律，而是揭示了不同金属的个体特性。为此，他用不同的金属制成了链条。尽管珀耳帖并没有预期电流产生的热量发生变化，但他注意到两种不同金属边缘的象征性热效应，他对此进行了描述。 1838年，圣彼得堡院士伦茨通过一项巧妙的实验表明，在各种导体的界面上，电流要么释放或吸收一定量的热量。楞次将一滴水放在两种金属的交界处，并通过电流将其冻结。

现在我们知道，两个导体边界处释放或吸收的热量$Q$与导体交界处的电流强度$I$和绝对温度$T$成正比：

$$Q = A I T.$$

系数 $A$ 与热电偶支路的热电动势 $a_1 + a_{11}$ 之和一致。伟大的标志

等级 $Q$（即接头处热量的增加或损失）取决于 $I$ 的符号，即电流的方向。

我们之前考虑的电流，在热电偶的闭合电路中产生，冷却热接点，相反，加热冷接点，并在此处释放热量。如果使用外部源，使反向电流通过热电偶，它将在热端产生热量，并从冷端产生相对热量。两个导体的同一连接点在一个电流方向上加热，在另一个方向上冷却。

计算表明，以这种方式产生的温差，以及电流从冷却结点带走并传递到加热结点的热量，由与热电偶效率相同的值$z$决定。

材料的相同属性提供了特定的$a$、$x$和$q$值，这些值表征了热电发电机中的电能与冰箱中的冷却能力的乘积。

通过将加热结的温度保持在接近室温的水平，并不断地将此处产生的热量排入环境中，可以显着冷却另一个结，并通过它冷却周围的空气。因此，借助具有足够$z$值的半导体，可以在冰箱中获得所需的低温。家用冰箱可以根据这个原理建造。

另一方面，您可以利用珀尔帖现象来加热房间，例如，加热建筑物或加热食物。长期以来，此类问题已经通过一种更简单的方式得到解决——通过在变阻器或加热板中释放焦耳热。在这种情况下释放的热能的量等于消耗的电能的量。

房间的热电加热与加热瓷砖的作用有很大不同。通过使电流通过热电电路，除了通常加热整个导体之外，我们还冷却一个结点并加热另一个结点。从冷端优化一定量的热能$Q_0$，可以表示为：

$$Q_0 = \alpha T_0 I t,$$

其中$\alpha$是热电驱动力，$T_0$是冷端的绝对温度，$I$是电流强度，$t$是电流通过的持续时间。对应于热结，其绝对温度用$T_1$表示，释放热能

$$Q_1 = \alpha T_1 I t,$$

大于热量$Q_0$

$$\frac{Q_1}{Q_0} = \frac{T_1}{T_0}.$$

如果我们只考虑两个连接点的过程，它们可以描述如下。电流从冷端提取热量$Q_0$，并将更多的能量$Q_1 - Q_0$以电能$W$的形式转移到热端。在从冷端优化的热量$Q_0$中添加能量$W$，它们的总和$Q_0 + W = Q_1$在热端释放。

从$Q_0$和$Q_1$值的给定数据可以清楚地看出，消耗的电能$W$与热结处释放的热量$Q_1$之比等于

$$\frac{W}{Q_1} = \frac{Q_1 - Q_0}{Q_1} = \frac{T_1 - T_0}{T_1}.$$

例如，如果热结的绝对温度为 $T_1 = 300$ K，对应于 $+27^\circ$ C，并且温度为 $T_0 = 270$ K 或 $-3^\circ$ C，则

$$\frac{W}{Q_1} = \frac{30}{300} = 0,1.$$
