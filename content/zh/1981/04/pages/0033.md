F645。扬声器有一个横截面积为$S = 300 \text{ cm}^2$、质量为$m=5 \text{ e}$的扩散器。

让我们假设电路在时间 $t=0$ 连接到源。此时，电容器$C_2$将通过二极管$D_1$快速充电至等于交流电压幅值$U_0$的电压。电容器$C_2$将充电

$$Q_0 = U_0 C_2.$$

在随后的时刻，二极管$D_1$和$D_2$将闭合，即它们不会通过电流，因为阴极的电势总是大于阳极的电势并且二极管是理想的（它们在闭合状态下的电阻等于无穷大）。该电路的行为就像二极管 $D_1$ 和 $D_2$ 被禁用一样；因此，电荷$Q_0$将被保留。

在这种情况下，交流电将流过串联的电容器

$$i = I_0 \sin \omega t = \left( U_0 \omega \frac{C_1 C_2}{C_1 + C_2} \right) \sin \omega t,$$

其中$I_0 = U_0 \omega \frac{C_1 C_2}{C_1 + C_2}$是电流幅值，$U_0$、$\omega$是交流电压的幅值和频率。交流电将在每个电容器上产生交流电压：

$$u_{c1} \sim = \frac{I_0}{\omega C_1} \cos \omega t = U_0 \frac{C_2}{C_1 + C_2} \cos \omega t,$$

$$u_{c2} \sim = \frac{I_0}{\omega C_2} \cos \omega t = U_0 \frac{C_1}{C_1 + C_2} \cos \omega t.$$

除了该交流电压之外，由于电容器 $C_2$ 充电至电压 $U_0$，电容器上还会出现恒压分量。为了找到电压 $U$ 的恒定分量，我们写出电荷守恒定律：

$$C_2 U_0 = C_1 U + C_2 U.$$

从这里

$$U = \frac{C_2 U_0}{C_1 + C_2}.$$

因此，电容器上的总电压将相等

$$u_{c1} = u_{c1} \sim -U = U_0 \frac{C_2}{C_1 + C_2} \cos \omega t - \frac{C_2 U_0}{C_1 + C_2},$$

$$u_{c2} = u_{c2} \sim +U = U_0 \frac{C_1}{C_1 + C_2} \cos \omega t + \frac{C_2 U_0}{C_1 + C_2}.$$

图 2 显示了这些 $C_2 = 2C_1$ 相关常数的图。

请注意，如果电路与电源的连接发生在时间 $t \neq 0$，则当二极管 $D_1$ 打开且电容器 $C_2$ 充电至电压 $U_0$ 时，电路会在一段时间后获得建立的电阻率。
