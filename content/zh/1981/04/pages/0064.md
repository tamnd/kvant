1. 根据球的水平运动方程$|\vec{v}| \sin \alpha \cdot t - gt^2/2 = H$我们可以求出球运动到天花板的时间：

$$t = \frac{|\vec{v}| \sin \alpha}{g} - \sqrt{\left(\frac{|\vec{v}| \sin \alpha}{g}\right)^2 - \frac{2H}{g}}$$

（“+”号被丢弃，因为它不符合物理意义）。所需距离

$$|AB| = |\vec{v}| \cos \alpha \cdot 2t = \frac{|\vec{v}|^2 \sin 2\alpha}{g} \times \left(1 - \sqrt{1 - \frac{2gH}{(|\vec{v}| \sin \alpha)^2}}\right)$$

（$H < \frac{|\vec{v}|^2 \sin^2 \alpha}{2g}$因为球撞到了天花板）。

2. $|\vec{F}| = \frac{mg}{2} \sin \alpha$。笔记。写出通过力$\vec{F}$作用点的轴的力矩规则，以及所有力在斜面方向上的投影之和为零的条件。

3. 由于杆的速度恒定，因此作用在其上的力是平衡的：

$$\vec{F} = -m\vec{g},$$ 或 $F = mg$。

这里$\vec{F}$是磁场对电流的力；她的模特

$$|\vec{F}| = |\vec{B}|Il$$

电路中的电流在哪里

$$I = \frac{\mathcal{E} - \mathcal{E}_{ннд}}{R}$$.

移动导体中产生的感应电动势等于

$$\mathcal{E}_{ннд} = |\vec{B}|l|\vec{v}|$$.

因此，

$$I = \frac{\mathcal{E} - |\vec{B}|l|\vec{v}|}{R}, |\vec{B}|l \frac{\mathcal{E} - |\vec{B}|l|\vec{v}|}{R} = mg$$,

在哪里

$$|\vec{v}| = \frac{\mathcal{E}}{|\vec{B}|l} - \frac{mgR}{|\vec{B}|^2}.$$

4. 为了进行估计，我们假设催眠者的整个质量集中在距横杆 $l$ 的重心处，并且在上方位置催眠者的速度为零。然后根据较低位置的运动方程

$$\frac{mv^2}{l} = |\vec{F}| - mg$$

并根据能量守恒定律

$$\frac{mv^2}{2} = mg2l$$

让我们求出横杆侧面反作用力的模$|\vec{F}|$，从而求出催眠者对横杆的压力的模$|\vec{N}|$：

$$|\vec{N}| = |\vec{F}| = 5mg$$.

选择 $m \sim 60$ kg，我们得到

$$|\vec{N}| = 5mg \sim 3 \text{ кН}$$.
