5. 计算极限
$$\lim_{x \to -1} \frac{2x^2 - x - 3}{2x^2 + 5x + 3}.$$

数学

笔试

选项1
（物理与数学学院专业“数学”）

1. 圆锥体内切于正三角形帕拉米德，其母线与底面倾斜角度α。如果侧边等于 b，求该 Paramid 的体积。
2. 解决不平等问题
$$\lg (x - 1) + \lg (x - 2) < \lg 6.$$
3. 解方程
$$\cos 2x + \cos x + 1 = 0.$$
4. 找到函数的最大值
$$y = (2 - x)(x + 2).$$

选项2
（物理与数学学院“物理与天文学”专业）

1. 在截锥体中，轴向截面的对角线互相垂直，母线与大底面的平面所成的角α等于l。确定截锥体的表面积和体积。
2. 确定函数 y = 3x - x³, y = 0 的图形所包围的图形的面积。
3. 解决不平等问题
$$\log \frac{1}{2} \left( x + \frac{1}{2} \right)^2 > 0.$$
4. 解方程
$$2 \cos^2 x + \sin^2 2x = 1 + \cos^2 2x.$$

选项3
（普通化学学科部）

1. 在正三角形截角Paramid中，对应的下底边和上底边的边分别等于a和b（a>b），下底边的边的两个角y等于α。确定截断的帕酰胺的体积及其表面积。
2. 解方程
$$\text{ctg} x = \cos x.$$
3. 解决不平等问题
$$\frac{2x^2 - 3x - 459}{x^2 + 1} > 1.$$
4. 计算极限
$$\lim_{n \to \infty} \frac{(n - 3)(n + 5)}{2n^2 + 3n - 2}.$$
