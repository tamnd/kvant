物理

口试作业

1. 如果火星质量比地球质量小9.3倍，火星半径比地球半径小1.9倍，那么从地球穿越到火星时，矩阵振荡周期会如何变化？
2. 浮冰距海平面的高度为$h = 2$米。如果冰的密度为$q_1 = 900$ kg/m$^3$，海水的密度为$q_2 = 1050$ kg/m$^3$，则求出整个浮冰的厚度。
3. 两个体积分别为$V_1 = 60$l和$V_2 = 30$l的容器分别含有温度相同但压力不同的气体。连接容器后，容器内建立$p = 1000$ kPa 的压力。如果小容器中的初始压力为 $p_2 = 800$ kPa，那么大容器中的初始压力是多少？温度没有变化。
4. 线圈覆盖 $S = 2$ cm$^2$ 的平面，垂直于均匀磁场线。如果磁感应强度在 $\Delta t = 0,05$ s 时间内均匀地从 $|\vec{B}_1| = 0,5$ T 消灭到 $|\vec{B}_2| = 0,1$ T，线圈中会感应出多少电动势？
5. 如果金属电子所做的功为 $A = 3,3 \cdot 10^{-19}$ J，则仍可观察到光电效应的最长光波长是多少？

数学

笔试
选项1

1. 球内接一个正三角形帕米达，底边等于$a$，侧边与底面平面成$\phi$角。求球的表面。
2. 求解不等式 $f'(x) + g'(x) < 0$，其中 $f(x) = \frac{x^2 - 1}{x - 3}$，$g(x) = \frac{1}{x - 3}$。
3. 简化表达式
$$4 \sin \left( 4\alpha - \frac{\pi}{2} \right)$$
$$\text{ctg}^2 \left( 2\alpha - \frac{3\pi}{2} \right) - \text{tg}^2 \left( 2\alpha + \frac{3\pi}{2} \right)$$
4. 解方程
$$\log_2 (9^{x-1} + 7) = 2 + \log_2 (3^{x-1} + 1)$$
5. 具有 $\hat{B} = 60^\circ$ 的三角形 $ABC$ 内接于以 $O$ 为圆心、半径为 2 的圆。

求向量 $\vec{OA}$ 和 $\vec{OC}$ 的标量积。

选项2

1. 在截锥体中，主截面的对角线互相垂直，母线等于$l$并与底面成锐角$\alpha$。求截锥体的侧表面。
2. 检查极值函数
$$y = x \cdot e^{x+1}.$$
3. 解方程
$$\sin^2 2x + \sin^2 3x = 1.$$
4. 解决不平等问题
$$\log_0,3 \log_6 \frac{x^2+x}{x+4} > 0.$$
5. 身体按照$h(t) = 4 + 8t - 5t^2$定律下落，其中$h$是以米为单位的下落高度，$t$是以秒为单位的时间。求物体接触地面瞬间的速度。

物理

口试作业

1. 司机以$|\vec{v}| = 72$公里/小时的速度自动急刹车。如果摩擦系数为$\mu = 0,6$，多久后$T$会自动停止？自动制动距离$l$是多少？
2. 两个物体以不同的初始速度垂直向上抛出。第一个尸体的高度是第二个尸体的四倍。它的初速度$|\vec{v}_1|$比第二物体的初速度$|\vec{v}_2|$大多少倍？
3. 研究太阳的质量$M$，知道地球在轨道上的平均线速度为$V = 30$公里/秒，地球轨道的半径为$R = 1,5 \cdot 10^8$公里。万有引力常数$G = 6,7 \cdot 10^{-11}$N·m$^2$/kg$^2$。
4. 长度为$l = 3,5$米、直径为$d = 0,3$米的圆木漂浮在水中。一个人能站在一根圆木上而不弄湿脚，那么$M$的质量是多少？木材密度$q = 0,7 \times 10^3$公斤/米$^3$。
5. 在理想的热机中，气体将加热过程中接收到的热量的 67% 转移到冰箱。如果加热温度为$T_1 = 430$ K，则确定冰箱的温度$T_2$。
6. 如果$V = 5$升水在$\tau = 30$分钟内沸腾，电锅炉电路中的电流是多少？初始水温$t_1 = 20^\circ$C，网络电压$U = 220$V，锅炉效率$\eta = 80\%$，具体水温$c = 4,2 \times 10^3$J/(kg·K)。
7. 电热水壶有两个绕组。当您打开其中一个时，水壶中的水会在$\tau_1 = 10$分钟内沸腾，当您打开另一个时，水壶中的水会在$\tau_2 = 20$分钟内沸腾。如果接通绕组：a）串联，b）并联，水壶中的水需要多长时间才能沸腾？
8. 飞机以$|\vec{v}| = 900$公里/小时的速度水平飞行。如果翼展为 $l = 24$ m，则确定飞机机翼末端出现的感应电动势 $\epsilon$，地球磁场感应垂直分量的模型为 $B_B = 5 \cdot 10^{-5}$ T。
