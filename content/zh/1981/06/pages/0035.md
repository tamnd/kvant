问题解决方案

M641。给定一个中心为 O 的正六边形 ABCDEF。点 M 和 N 是边 CD 和 DE 的中点。线 AM 和 BN 相交于点 L。证明
a) 三角形ABL和四边形DMLN面积相等；
b) ALO = OLN = 60°；
c) 旧 = 90°。

该问题的所有陈述都可以通过一次观察轻松获得：当绕中心 O 旋转 60° 时，四边形 AMCB 映射到四边形 BNDC 上。
事实上，当转动$R_0^{60°}$（逆时针）时，A点到B点，B点到C点，CD边映射到DE边，这样CD边的中间M到DE边的中间N（参见图）。因此，四边形 AMCB 和 BNDC 是稠密的，因此它们的面积相等。用这些等面积减去四边形BCML的面积，我们得到等面积，即三角形ABL和四边形DMLN大小相等。

由于旋转 $R_0^{60°}$ 射线 AM 映射到射线 BN 上，因此这些射线方向之间的角度等于旋转角度，即 $ALB = 60°$。因此，$ALN = 120°$。我们给出了$ALO = OLN = 60°$和$OLD = 90°$的两个证明。

1°。让我们使用这个明显的事实：如果在 K 点相交的两条线到 P 点等距，那么线 PK 就是这些线（包含 P 点）之间的角度的二等分线。由于点 O 与直线 AM 和 BN 等距，因此 OL 是角 ALN 的二等分线，即$ALO = OLN = 60°$。由于D点到直线AM和BN的距离相等（与C到直线AM的距离相同），$NLD = DLM = 30°$，即$OLD = 90°$。

2°。可以围绕四边形 DMON 描述一个圆，因为其顶点 M 和 N 处的角度是直角。 L点也属于这个圆。这是因为在四边形 DMLN 中，顶点 D 和 L 处的角度之和等于 180°。注意到$ODN = 60°$，我们应用内切角定理。然后我们得到$OLN = ODN = 60°$和$OLD = OMD = 90°$。

E·戈特曼

M642。证明每个自然数都可以用$a_0 + 2a_1 + 2^2a_2 + \dots + 2^n a_n$的形式表示，其中每个数字都是$a_k = 0, -1$或1，并且$k \cdot a_{k+1} = 0$对于所有$0 \leq k \leq n-1$，并且这样的表示是唯一的。

考虑所需的视图
$$A = a_0 + 2a_1 + 2^2a_2 + \dots + 2^n a_n$$
(*)
($a_k = 0, -1$ 或 1, $a_k \cdot a_{k+1} = 0$) 对于几个自然数，很容易看出
1) 对于从 $2^n - 2^{n-2} - 2^{n-4} - \dots$ 到 $2^n + 2^{n-2} + 2^{n-4} + \dots$ 的数字 A，最后一个符号+停止在 $2^n$（最高有效数字 $a_n = +1$）（例如，在我们的表中页边距中，对于从 $2^3 - 2 = 6$ 到 $2^3 + 2 = 10$ 的数字 A，最后一个符号+停止在 $2^3$；对于从 $2^4 - 2^2 = 1 = 11$ 到 的数字 A，最后一个符号+停止在 $2^4$ $2^4 + 2^2 + 1 = 21$等）；
2) 第一个符号（小数位 $a_0 \neq 0$）以 4 的周期周期性重复，也就是说，它仅取决于 A 除以 4 时的余数（$a_0 = 0$ 重复得更频繁 - 周期为 2）。

所需表示（*）及其唯一性的两个证明是建立在这两个观察者的基础上的。这两个证明都是通过归纳法进行的，即对于给定数字 A 的有效陈述是从它对所有数字 A 的有效性推导出来的。

1°。让我们用 $M_n$ 表示数字 $2^n + 2^{n-2} + 2^{n-4} + \dots$（这里的最后一项是 $2^1 = 2$ 表示奇数 $n$，$2^0 = 1$ 表示偶数 $n$）。让我们证明每个数字 $A \leq M_n$ 都以唯一的方式以 (*) 形式表示，而 $a_n = 1$ 则代表数字
$$2^n - M_{n-2} \leq A \leq 2^n + M_{n-2} = M_n.$$
