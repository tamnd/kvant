比如说，$f(-1) = -1$、$f(0) = 0$、$f(1) = 4$。系统解决了

$$\begin{cases}
-a + b + c/9 = -1, \\
b + c = 0, \\
a + b + 9c = 4.
\end{cases}$$

我们会找到$a = \frac{5}{8}$，$b = -\frac{27}{64}$，$c = \frac{27}{64}$。

这可能正是很久以前示例 d) 的发明方式。我们建议读者自己想出一些新的例子。

定理 3. 如果 $q_1, q_2, \dots, q_r$ 是整数 $u$
$f(n) = c_1 q_1^n + c_2 q_2^n + \dots + c_{r-1} q_{r-1}^n + c_r q_r^n$
是$n = 1, 2, \dots, r$的整数，则$f(n)$是任何自然数$n$的整数。
（引理 1 是 $r = 2, q_2 = 1$ 定理的特例）。

笔记。为了证明定理 3，考虑差异 $g(n) = f(n+1) - q_r f(n)$ 是有用的。由于 $g(n) = c_1 (q_1 - q_r) q_1^n + \dots + c_{r-1} (q_{r-1} - q_r) q_{r-1}^n$ 是 $r-1$ 几何级数之和，并且在定理的条件下，数字 $g(n)$ 是 $1 \leq n \leq r-1$ 的整数，因此可以通过对 $r$ 进行归纳来证明该定理：毕竟
$$f(n) = g(n-1) + q_r g(n-2) + \\
+ q_r^2 g(n-3) + \dots + q_r^{n-1} g(1) + q_r^n f(1).
$$
