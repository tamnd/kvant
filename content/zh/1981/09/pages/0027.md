F673。负载悬挂在弹性线上。如果向负载施加力，并从零缓慢增加，当力达到值$F_1$时，螺纹就会断裂。如果施加的力小于某个值并且然后仍然微不足道，那么在最小力值是多少时，螺纹会断裂？

弹性线可以被视为一个圆。设该夹具的刚度等于$k$。根据问题的条件，随着力的缓慢增加，当施加在其上的总力$F_\pi$等于时，螺纹就会出现

$$F_\pi = mg + F_1,$$

其中$m$是悬挂负载的质量。让我们看看当施加的力立即达到某个值$F$并且随后不发生变化时会发生什么情况。

在初始时刻（力为零时），螺纹在负载$mg$的重力作用下被拉伸了$x_0$，由条件$kx_0 = mg$决定，即螺纹在平衡位置的坐标等于$x_0 = mg/k$（以无负载时螺纹末端的位置为原点）。当施加力$F$时，处于平衡位置的螺纹末端的坐标将等于$x' = mg/k + F/k$。然而，只有在空气振荡减弱后，系统才会达到平衡状态。这些振荡的初始幅度由系统与平衡位置的初始偏差决定，即$A = x' - x_0 = F/k$。由于振动阻尼很小，在正周期之后，夹具的总张力将等于

$$x_\pi = \frac{mg + F}{k} + A = \frac{mg}{k} + 2 \frac{F}{k}.$$

这意味着总力施加到螺纹上

$$F'_\pi = mg + 2F.$$

如果该力大于力 $F_\pi$（参见 (*)），线就会断裂，这决定了线的抗拉强度。这样，由条件$F'_\pi = F_\pi$求得螺纹断裂的最小力$F_{\min}$，即

$$mg + 2F_{\min} = mg + F_1;$$

从这里

$$F_{\min} = F_1/2.$$

F674。将$v_1 = 1$摩尔量的硫酸酐$SO_3$置于密闭容器中并升至$T_1 = 1000$K的温度，此时$SO_3$部分离解成硫酸酐$SO_2$和氧气：$SO_3 = SO_2 + \frac{1}{2}O_2$。

在这些条件下的解离度结果等于 $a_1 = 0,2$（即，第一个初始可用分子 $SO_3$ 的 20% 被解离）。当$v_2 = 0,4$ mol $SO_3$放入同一容器中时，结果表明，为了获得与第一个实验相同的压力，段塞上方的气体压力达到$T_2 = 2000$ K的温度。确定第二个实验中的离解度$SO_3$。一般实验中所有物质都处于气态。

F675。为了改变 CC 电路中的大电流（参见 图ok），使用分流器 Ш，

完全耗散后，1 摩尔 $SO_3$ 产生 1.5 摩尔气体（$SO_2$ 和 $O_2$）。因此，如果解剖 αᵇ 摩尔 $SO_3$，则容器中包含 1.5 个αᵇ 摩尔 $SO_2$ 和 $O_2$ 以及 (1−α)ᵇ 摩尔 $SO_3$；容器中的气体总数为 $n = 1,5αᵇ + (1−α)ᵇ = (1+0,5α)ᵇ$。

让我们写出第一种 ($v_1 = 1$ mol, $T_1 = 1000$ K, $a_1 = 0,2$) 和第二种 ($v_2 = 0,4$ mol, $T_2 = 2000$ K, $a_2 = ?$) 情况下容器中气体的状态方程（压力和体积在一般情况下相同）：

$$pV = n_1RT_1, \quad pV = n_2RT_2.$$

因此，$n_1T_1 = n_2T_2$，即

$$(1+0,5a_1)v_1T_1 = (1+0,5a_2)v_2T_2,$$

在哪里

$$a_2 = 2\left((1+0,5a_1) \frac{v_1T_1}{v_2T_2} - 1\right) = 0,75 = 75\%.$$
