问题 2. 在含有 $m_1 = 3$ 温度为 $t_1 = -10^\circ C$ 的冰、水分 $m_2 = 2$ 和温度为 $t_2 = 80^\circ C$ 的水的加热器中。热交换产生的温度是多少？忽略加热器的热容量。

很明显，最终温度$t$在 - 10 至 +80 °C 范围内：

$$-10^\circ C < t < 80^\circ C.$$

因此，它可能大于 0°C（冰的重力温度）或小于或等于该温度。不可能提前说出结果到底是什么。我们将“通过触摸”实现目标，通过可能的选择并依靠等式的意志。

我们假设$t > 0^\circ C$，即加热器中只有水。然后冰分三个阶段接收热量：作为冰本身，从-10°C加热到0°C，在0°C变成水，以及已经是水，从0°C加热到$t$。在这种情况下，水只有从温度$t_2$冷却到$t$时才会放出热量。我们写出相应的热平衡方程：

$$c_1 m_1 (0 - t_1) + \lambda m_1 + c_2 m_2 (t - 0) + c_2 m_2 (t - t_2) = 0,$$

其中$c_1 = 2,1 \cdot 10^3$ J/(kg K)和$c_2 = 4,2 \cdot 10^3$ J/(kg K)是冰和水的比热容，$\lambda = 3,4 \cdot 10^5$ J/kg是冰融化的比热。从这里我们会发现

$$t = \frac{c_1 m_1 t_1 + c_2 m_2 t_2 - \lambda m_1}{c_2 (m_1 + m_2)}.$$

代入数值数据，我们得到$t < 0^\circ C$。这意味着我们的假设是错误的。

现在我们假设$t < 0^\circ C$。在这种情况下，水分三个阶段放出热量 - 冷却到 0°C，在 0°C 变成冰，然后像冰一样冷却到所需温度 $t$，而第一年的冰仅在一个阶段接收热量 - 从 $t_1$ 加热到 $t$：

$$c_1 m_1 (t - t_1) + c_2 m_2 (0 - t_2) - \lambda m_2 + c_1 m_2 (t - 0) = 0.$$

解这个方程，我们得到

$$t = \frac{c_1 m_1 t_1 + c_2 m_2 t_2 + \lambda m_2}{c_1 (m_1 + m_2)}.$$

让我们代入数值数据并确保$t > 0^\circ C$。因此，第二句话也是错误的。

剩下的唯一选项是$t = 0^\circ C$。这将是问题的答案。

在这里，我们预见到读者会感到有些沮丧：为什么作者故意选择所有初始句子都不正确的例子，并且两列繁琐的解决方案都导致相对简单的结果（$a = 0, t = 0^\circ C$）？事实上，为什么不提前提供这些简单的选择呢？

这条道路是可行的，但它并不能保证缓解。因此，在第一个问题中，提出了静止并且没有静摩擦力的公式，我们必须创建一个由三个平衡方程组成的系统，但是在解决它并找到摩擦力之后，我们必须检查它是否实际上小于滑动摩擦力。如果事实证明并非如此，您将必须重新开始执行上述所有解决方案。

在第二个问题中，通过提出$t = 0^\circ C$，我们必须确认这个热平衡方程，但我们不知道如何构造它。我们不知道哪个等于零：“从下面”的冰或“从上面”的水，因此 - 部分（以及哪部分）冰融化或部分水冻结？当然，您可以提供一些东西，但选项的数量不会比上述解决方案少，甚至更多。
