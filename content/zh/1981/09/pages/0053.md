机器语言

计算机的机器语言只不过是其机器指令的系统（参见 «Kvant»，1981，第 4 期 - “三地址、单地址和……无地址机器”）。机器“理解”这些命令的规则嵌入在计算机的设计中，就像自动化的设计嵌入在“理解”转动方向盘的“含义”中一样。

让我们举一个该语言所使用的程序的工作示例。假设这位程序员在解决问题的过程中必须计算出在下落开始后$T$秒内自由喂食矩阵点位于什么高度$H$，如果该点的初始高度为$A_m$，则初始速度为$V_m/c$。相应的物理公式是众所周知的：

$$H = 9,81 \cdot T^2/2 + V \cdot T + A,$$

但对于程序员来说，以不同的形式重写它会更方便：

$$H = (9,81 \cdot T/2 + V) \cdot T + A.$$

在开始编写程序时，程序员必须为其执行“内存分配”，即确定将用于存储某些数量的单元的地址。

举个例子，他分配的内存如下：

| 震级 | 小区地址 |
| :--- | :--- |
| 恒定9.81 | 1001 |
| 常数2 | 1002 |
| 变量$A$ | 1101 |
| 变量$V$ | 1102 |
| 变量$T$ | 1103 |
| 变量$H$ | 1104 |

进一步，在我们的机器上（顺便说一下，这是当之无愧的国产计算机技术之风——M-220机器，至今在一些地方仍在使用）加法运算的代码为01，除法 - 04，乘法 - 05。然后，按照他的所有程序，例如从单元格0101开始，程序员写道：

$$Y = E'9.81;T,H$$
$$D = E'2';H$$
$$C = H,V,H$$
$$Y = H,T,H$$
$$C = H,A,H$$

（C - 加法，Y - 乘法，D - 除法；使用结构 = E'...' 描绘了一个数值常数）。
