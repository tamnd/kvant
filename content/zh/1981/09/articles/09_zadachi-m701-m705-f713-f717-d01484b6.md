M662。存钱罐里有四卢布的铜币。证明这些硬币可以用来支付三卢布而不找零。

足以证明不换卢布也能哭。

存钱罐可容纳四种硬币：一戈比、二戈比、三戈比和镍币。因此，某些类型的硬币不低于卢布。

如果这些硬币是镍币、两戈比或一戈比硬币，那么很明显您可以不用找钱支付卢布。

因此，让我们考虑一下这样的情况：三戈比硬币比卢布硬币多，而其他类型的硬币比卢布硬币少。

如果存钱罐里至少有一枚一戈比硬币，那么将其添加到 33 个三戈比硬币，我们就得到卢布。

如果有两个两戈比硬币或两个镍币，那么将三戈比硬币加上 32（分别为 30），我们就得到卢布。

这样，还剩下一种情况，没有一戈比硬币，有两枚二戈比硬币（398不能被3整除）；如果没有两戈比硬币，则至少有两枚镍币（395 不能被 3 整除）。所以，在这种情况下，我们有一枚镍币和一枚两戈比硬币，通过将一枚镍币和一枚两戈比硬币添加到 31 个三戈比硬币中，我们可以收集卢布。

弄清楚用存钱罐里的四轮铜币一般可以支付多少金额而不找零是很有趣的。

例如，如果存钱罐里只有两戈比的硬币，那么就不能支付零钱；如果只有镍币，则金额不能被 5 整除；如果最后，存钱罐里有 133 个三戈比硬币和一枚一戈比硬币，那么所支付的金额除以 3 后剩下 2。

这意味着，如果可以为存钱罐中的任何一套四轮铜币支付一定的金额，那么它可以被10整除，并且除以3时不会留下2的余数。是否可以支付所有这些金额？

M663。找到所有素数 p，其中数字 2$^p$ + p$^2$ 也是素数。

当p=2时，我们得到合数8，当p=3时，我们得到素数17。

让我们证明，对于素数 p>3，数字 2$^p$ + p$^2$ 始终为 3。

事实上，对于某些自然 k，p=3k±1。因此 2$^p$ + p$^2$ = (3−1)$^{3k±1}$ + (3k±1)$^2$ = (3M−1) + (3N+1) = 3(M+N)。

你可以有不同的想法。从奇数 p 可以得出 2$^p$ + 1 = (2+1) (2$^{p−1}$−2$^{p−2}$+...+1)。这意味着 2$^{p+1}$ 可以被 3 整除。由于 p 不能被 3 整除，p$^2$ − 1 = (p−1) (p+1) 可以被 3 整除。这意味着和 (2$^p$ + 1) + (p$^2$ − 1) = 2$^p$ + p$^2$ 可以整除3.

我们收到了基于不同报告的 a) 陈述的大量证据。让我们简要地引用其中的一些。

1°。有$2^N$种不同的灯光显示模式，因为每个$N$灯泡都可以处于两种状态 - 打开或关闭。让我们从初始图案$B_0$开始按键，可以得到$m$不同的图案$B_0, B_1, \dots, B_{m-1}$。然后，从任何初始模式 $X$ 中，我们都可以获得相同数量的模式 - 这些模式与 $X$ 的区别在于集合 $B_0, B_1, \dots, B_{m-1}$。因此，如果将所有$2^N$图案分成若干个按键，然后：将通过按键可以相互获取的图案分配给一类，则每个类别中将有$m$图案。因此$2^N$可以被$m$整除；因此，$m$是2的幂。

2°。让密钥以这样的方式编号：没有一个$s$模式$A_1, A_2, \dots, A_s$可以通过前面的模式（数字较小）的组合来获得，并且剩余的每个$k-s$模式$A_{k+1}, \dots, A_k$都可以通过一些操作$A_1, A_2, \dots, A_s$的组合来获得。那么从初始状态$B_0$可以得到的模式总数$m$就是$2^s$。事实上，操作$A_1, A_2, \dots, A_s$的所有组合，对应于集合$\{1, 2, \dots, s\}$的不同子集的$2^s$，给出不同的模式：如果其中任何两个重合：

$$A_{i_1}A_{i_2}\dots A_{i_m}=A_{j_1}A_{j_2}\dots A_{j_l},$$

那么通过前面的组合就可以得到这个等式中包含的数字最多的模式$A$。

3°。我们首先不是看所有 $N$ 灯泡，而是看其中的第一个 $L$。让这些灯泡从初始状态$B_0$获得$m_L$不同的图案。然后我们看第$(L+1)$号灯泡。如果$(L+1)$灯泡的状态完全由前$L$灯泡的状态集决定，则$m_L+1=m_L$。如果至少有两个灯泡，但差异在第 $(L+1)$ 处，那么您可以得到第一个 $L$ 灯泡不亮，但第 $(L+1)$ 亮的模式。然后，从我们的$L$灯泡的每个图案中，您可以从第一个$L+1$灯泡中获得两种不同的图案，即$m_L+1=2m_L$。由于一个（第一个）灯泡可以处于两种状态，因此很明显，我们的兴趣 $m=m_N$ 将是 2 的幂。

许多读者注意到，将操作$A_i$和表格状态（“模式”）表示为一组$N$数字$+1$和$-1$（在这种情况下，按键操作对应于集合的乘法）或一组$N$数字$0$和$1$（然后将集合相加）会很方便模 2，则有 $1+1=0$）。

让我们应用第一个表示法来解决问题 6)。

如果第$i$行第$j$列中的灯泡打开，我们将假设$x_{ij}=-1$，否则假设$x_{ij}=1$为$(1 \leq i \leq m, 1 \leq j \leq n)$。让我们证明从初始状态“全部$x_{ij}=1$”可以获得的模式总数等于$2^{m+n-1}$。

有效运算（有$m+n$）是行或列乘以$-1$。显然，我们可以在第一行第一列中得到任意一组$m+n-1$数字$\pm 1$：$x_{11}, x_{12}, \dots, x_{1n}, x_{21}, x_{31}, \dots, x_{m1}$。但是这些 $m+n-1$ 数字中剩余的 $x_{ij}$ 中的每一个都已被唯一确定，因为在任何允许的操作下，等式 $x_{ij}x_{11}=x_{i1}x_{1j}$ 将被保留。

F673。负载悬挂在弹性线上。如果向负载施加力，并从零缓慢增加，当力达到值$F_1$时，螺纹就会断裂。如果施加的力小于某个值并且然后仍然微不足道，那么在最小力值是多少时，螺纹会断裂？

弹性线可以被视为一个圆。设该夹具的刚度等于$k$。根据问题的条件，随着力的缓慢增加，当施加在其上的总力$F_\pi$等于时，螺纹就会出现

$$F_\pi = mg + F_1,$$

其中$m$是悬挂负载的质量。让我们看看当施加的力立即达到某个值$F$并且随后不发生变化时会发生什么情况。

在初始时刻（力为零时），螺纹在负载$mg$的重力作用下被拉伸了$x_0$，由条件$kx_0 = mg$决定，即螺纹在平衡位置的坐标等于$x_0 = mg/k$（以无负载时螺纹末端的位置为原点）。当施加力$F$时，处于平衡位置的螺纹末端的坐标将等于$x' = mg/k + F/k$。然而，只有在空气振荡减弱后，系统才会达到平衡状态。这些振荡的初始幅度由系统与平衡位置的初始偏差决定，即$A = x' - x_0 = F/k$。由于振动阻尼很小，在正周期之后，夹具的总张力将等于

$$x_\pi = \frac{mg + F}{k} + A = \frac{mg}{k} + 2 \frac{F}{k}.$$

这意味着总力施加到螺纹上

$$F'_\pi = mg + 2F.$$

如果该力大于力 $F_\pi$（参见 (*)），线就会断裂，这决定了线的抗拉强度。这样，由条件$F'_\pi = F_\pi$求得螺纹断裂的最小力$F_{\min}$，即

$$mg + 2F_{\min} = mg + F_1;$$

从这里

$$F_{\min} = F_1/2.$$

F676。周长为 4a、质量为 m 的方形线框在水平方向上赋予一定的初速度。框架在垂直平面上移动，始终处于垂直于框架平面的磁场中（参见图）。场感应按照定律$B(z) = B(0) + kz$变化，其中$k$ = const。框架的阻力等于 R。一段时间后，框架的速度变得恒定并等于 v。找到赋予框架的初始速度。自由 nadiya g 的加速。

在没有磁场的情况下，框架将在地球引力场中沿 X 轴以恒定水平速度 $\vec{v}_0$ 移动，并通过沿 Z 轴的自由填充 $\vec{g}$ 均匀加速。显然，如果框架落在均匀磁场中，框架的运动不会改变。在我们的例子中，场不均匀（沿 Z 轴）：$B(z) = B_0 + kz$，即场感应随着 z 的增加而线性增长；因此，当框架落下时，框架任意轮廓的磁感应通量F将发生变化，并且框架轮廓中将出现感应电动势。由于框架是一个闭合的导电电路，因此会有感应电流流过它。在这种情况下，根据安培定律，来自磁场的力将作用在框架的侧面。让我们找出这些力的方向和大小。

假设在某个时刻，框架的质心位于坐标为$x_t$、$z_t$的点，并且质心速度在X轴和Z轴上的投影等于$v_x$和$v_z$（参见图）。此时任意坐标系的磁感应强度 Ф 等于

$$\Phi = \frac{(B_0 + k(z_t - a/2)) + (B_0 + k(z_t + a/2))}{2} a^2 = (B_0 + kz_t) a^2.$$

这里$B_0 + k(z_t - a/2)$和$B_0 + k(z_t + a/2)$是框架上下两侧对应的磁场感应值；由于依赖关系 $B(z)$ 是线性的，为了计算 Ф，我们获得了感应的平均值（沿高度 z）。

给定时间帧中的感应电动势等于

$$|\mathcal{E}| = \frac{|\Delta\Phi|}{\Delta t} = ka^2 \frac{|\Delta z|}{\Delta t} = ka^2 |v_z|,$$

感应电流等于

$$I = \frac{|\mathcal{E}|}{R} = \frac{ka^2}{R} |v_z|.$$

根据楞次定律，产生的电流将顺时针流动。根据安培定律，框架上侧的磁场会作用一个力

$$|\vec{F}_1| = (B_0 + k(z_t - a/2)) Ia = (B_0 + k(z_t - a/2)) \frac{ka^3}{R} |v_z|,$$

下侧 - 强度

$$|\vec{F}_2| = (B_0 + k(z_t + a/2)) Ia = (B_0 + k(z_t + a/2)) \frac{ka^3}{R} |v_z|.$$

作用在框架两侧的力 $\vec{F}_3$ 和 $\vec{F}_4$（非常/不）大小相等，符号相反：

$$|\vec{F}_3| = |\vec{F}_4| = \frac{(B_0 + k(z_t - a/2)) + (B_0 + k(z_t + a/2))}{2} Ia =$$

$$= (B_0 + kz_t) \frac{ka^3}{R} |v_z|,$$

$$\vec{F}_3 + \vec{F}_4 = 0.$$

因此，$v_x = const$，即框架将以等于初始速度$v_0$的恒定速度沿$X$轴移动。

因此，框架沿$Z$轴方向的运动性质由力$\vec{F}_1$、$\vec{F}_2$和重力$m\vec{g}$决定。当框架的速度$v$稳定时，速度在$Z$轴上的投影是恒定的，即沿$Z$轴的加速度$\vec{a}_z$为零：

$$m|\vec{a}_z| = m|\vec{g}| + |\vec{F}_1| - |\vec{F}_2| = mg - \frac{k^2 a^4}{R}|v_z| = 0.$$

从这里我们找到框架稳定速度在轴$Z$上的投影$v_{yct. z}$：

$$v_{yct. z} = mgR/k^2 a^4.$$

框架的稳定速度等于 $v = \sqrt{v_0^2 + v_{yct. z}^2}$，其中 $v_0$ 是速度 $v$ 在轴 $X$ 上的投影，如我们所示，等于赋予框架的初始速度。因此，

$$v_0 = \sqrt{v^2 - v_{yct. z}^2} = \sqrt{v^2 - \left(\frac{mgR}{k^2 a^4}\right)^2}.$$

速度$v_{yct. z}$也可以从能量信息中找到。当框架运动稳定时，框架在地球引力场中的势能随时间的变化$\Delta t$等于框架在这段时间内释放的热能：

$$mgv_{yct. z}\Delta t = l^2_{yct. z}R\Delta t = \left(\frac{ka^2}{R}\right)^2 v^2_{yct. z}R\Delta t.$$

从这里

$$v_{yct. z} = \frac{mgR}{k^2 a^4}.$$

这个问题可以通过两种方式解决。

1. 在第一个镜子（半径$R_1$）的焦平面上，获得太阳的图像，这是第二个镜子（半径$R_2$）的主题。如果太阳的角度大小为$a$，则该图像的大小为$l = aF_1 = aR_1/2$；图像距离第二个镜子 $d_2 = R_2 - R_1/2$ 。第二面镜子的放大倍数为$\Gamma_2 = F_2/(d_2 - F_2) = R_2/(R_2 - R_1)$。镜像系统中获得的图像大小等于

$$L_3 = l\Gamma_2 = \frac{aR_1}{2} \frac{R_2}{R_2 - R_1} = a \frac{R_2 R_1}{2(R_2 - R_1)}.$$

一条细线在其焦平面大小中创建了太阳的图像

$$L_\pi = aF_\pi.$$

要获得图像尺寸$L_\pi = L_3$，需要使用焦距为

$$F_\pi = \frac{R_2 R_1}{2(R_2 - R_1)} = 10\text{ см}.$$
