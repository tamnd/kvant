通过游戏可以学习数学吗？事实证明这是可能的，因为数学中有很多描述“游戏情境”的问题。

我们将处理与寻找函数的最大和最大值相关的游戏。这种搜索的艺术在经济、军事、生物学、体育等许多问题中都很重要……

果断十等米

我们在足球场上。球员 A 和守门员 B 准备进行一系列 10 次等米射门。玩家将向右或向左走；守门员试图猜测射门的方向，准备跳向左侧

向右下注（这是他的策略一），守门员准备向左跳（这是B的策略一），那么平均10个进球中有7个；如果B准备向右跳，则扔10个球，依此类推。

两名玩家将随机交替选择。如果他们每个人都有大约一半的时间选择自己的策略（正如他们所说，概率为 1/2），那么平均会进球 (7 + 10 + 9 + 6): 4 = 8 个进球。

如果 A 以 0.6 的概率（在 60% 的情况下）应用第一个策略，并以 0.4 的概率（在 40% 的情况下）应用第二个策略，

守门员以 0.8 的概率使用第一个策略，以 0.2 的概率使用第二个策略，那么平均会进 $(7 \cdot 0,6 + 9 \cdot 0,4) \times 0,8 + (10 \cdot 0,6 + 6 \cdot 0,4) \cdot 0,2 = 7,92$ 个球，不到 8 个。当然，说在这个特定系列中会进 7.92 个球是没有意义的。这里的意思是，通过多次重复满足设定条件的系列赛，平均进球数（总进球数与系列赛数的比率）将接近7.92。

一般来说，让$A$以概率$x$和$1-x$（$0 \leq x \leq 1$）选择其第一和第二策略，并以$y$和$1-y$（$0 \leq y \leq 1$）的概率选择$B$。在这种情况下，据说数字$x$和$y$决定了玩家的混合策略。那么平均进球数是$m = (7x + 9(1-x))y + (10x + 6(1-x)) \times (1-y) = -6xy + 4x + 3y + 6$。 (*)

问题自然而然地出现了：$A$的$x$、$B$的$y$的最高值是多少？ $x^*$ 与 $A$ 的最佳值，应保证最低进球数（平均），无论守门员的战术如何。无论前点球手的策略如何，$y^*$ 与 $B$ 的最佳值应能保证最低进球数（平均）。

事实证明（您将通过解决练习 1 看到这一点），$x^* = 1/2$，$y^* = 2/3$；在这种情况下，（平均）将进$m^* = 8$个球。很容易检查（一定要这样做！），如果至少一个玩家坚持指定的“最佳”策略，那么无论另一个玩家的策略如何，都会得分$m^* = 8$个进球（平均）。如果其中一名玩家不遵循指定的策略，那么他就无法再保证任何事情 - 结果将取决于规则的操作。

因此，如果守门员向右和向左跳动的次数相同（即 $y = 1/2$），而球员总是呆在右角（$x = 0$），那么平均进球数会更少（$m = 7,5$）。但如果$A$是被击球者，他将始终是左侧角球（$x = 1$），然后会更频繁地得分（$m = 8,5$）。

现在让我们从足球、假设中休息一下，让我们处理“简单”函数，不受 $x$ 和 $y$ 的限制 - 这将使第一步变得更容易。

赢、输、平局

让两个玩家玩下面的游戏：$A$选择真实数字$x$，$B$选择数字$y$，各自做出自己的选择，而不知道对手的选择。两个数字都被传达给命运，然后根据玩家事先知道的规则，计算第一个$v = f(x, y)$的奖金，等于第二个的损失；更准确地说，在 $v > 0$ A 战胜 $B$ 值 $v$，在 $v < 0$ A 输掉 $B$ 值 $|v|$；如果$v = 0$，则比赛平局；符号 $f(x, y)$ 表示 $v$ 是两个变量的给定函数 ($x, y$)。

例如，计算游戏奖金的规则为：

$$v = y^2 - x^2.$$

尝试多次执行规则 (1)。经过几次“游戏”后，玩家会注意到，他们每个人都赢得零值会更好：$x = y = 0$结果是平局，即使知道对手的选择，任何玩家偏离这个选择都是不利的。

事实上，对于$x = 0$$v = y^2$，玩家$B$的最佳反应是选择$y = 0$。同样，对于 $y = 0$ $v = -x^2$，最佳着法 $A$ 是 $x = 0$。

现在很明显，使用插件功能 $v = y^2 - x^2$ 并不有趣：双方都保证平局。玩一下下面的插件功能会更难也更有趣：

$$v = y^2 - x^2 + 8x - 10y + 9.$$

在这种情况下，是否有可以向玩家推荐的数字$x$和$y$，而偏离这些数字会让他们付出“代价”？

因此，如果$A$选择$x = 4$，那么除了$y = 5$以外的任何选择的玩家$B$都会输。同样，如果$A$选择$x \neq 4$，则玩家$B$将通过采取$y = 5$获胜。

所以，第一个玩家有一步棋，他肯定不会输。第二个玩家也有同样的动作。因此，在这场游戏中，冒险不“按照理论”进行游戏的人将会失败（当然，除非他的对手也冒着放弃理论的风险）。

让我们以我们游戏中的游戏后跟的结果为例（每个三元组中第一个数字是$x$，第二个是$y$，第三个是$v$）：$(0,0,9), (0,7, -12), (4,7,4), (4,5,0), (5,5, -1)$。

研究这些游戏提出了另一种解决方案（不幸的是，并不总是合适）。我们尝试对第一个玩家进行推理：“如果$B$选择$y = y_0$，那么我们会得到一个相对于$x$的正方形三角形$v(x, y_0) = (9 - y_0 - x)(x - y_0 + 1)$，我必须通过选择合适的$x$使其尽可能大；但是这个三角形的最大值在$x = 4$，所以我想要$x = 4!$。以类似的方式推理，第二个玩家将确保他自己是最小输家$y = 5$（对于驱动器的任何移动$x = x_0$）。

鞍点和博弈解

我们已经看到，在具有函数 (2) 的游戏中，每个玩家都可以保证自己不会失败，因为能够找到一对数字 (4:5)，使得 $f(4,5) = 0$ 以及函数 $f$ 的所有其他 $x$ 和 $y$ 值满足不等式
$$f(x, 5) \leq f(4, 5) \leq f(4, y).$$

由此我们可以看出，第一个选择$x = 4$的玩家在任何情况下都不会输（这是从最后一个不等式得出的），就像第二个选择$y = 5$的玩家也不会输一样。

让我们给出一个一般的定义。

鞍点的定义。

给定一个函数$f$，定义在平面上的一些点集$G$上。点 $(x^*; y^*) \in G$ 称为函数 $f$ 的鞍点或平衡点（如果位于 $(x, y^*) \in G, (x^*, y) \in G,$）
$$f(x, y^*) \leq f(x^*, y^*) \leq f(x^*, y).$$

从这些不等式可以得出 $\max f(x, y^*) = f(x^*, y^*) =$
$$= \min f(x^*, y)$$
（在左侧，函数 $y = y^*$ 的变量 $x$ 中存在最大值，右侧 $x = x^*$ 中的函数 $y$ 中存在最小值）。

理论上，玩家鞍点$(x^*; y^*)$通常称为游戏的解（具有支付函数$v = f(x, y)$），数字$v^* = f(x^*, y^*)$称为游戏成本，数字$x^*, y^*$分别是第一和第二玩家的最优策略。

游客和登山者

游客想要从$D_1$山谷到$D_2$山谷，需要经过山口（马鞍）——而从$D_1$到$D_2$（图2）的最大高度与所有不经过马鞍的近距离路线相比是最小的。想要从$V_1$峰穿越到$V_2$峰的登山者出于不同的原因通过同一个山脊——以免“失去高度”，也就是说，从$V_1$到$V_2$途中的最小高度尽可能高。

地图上显示图 1，其中垭口高度为零，$x$、$y$分别为凿子和纬度。我们将把与轴线平行的直线视为游客和登山者的路径可能性。与山区路线一样，图 1 的主要直线（$y=5$ 和 $x=4$）通过以下事实突出显示：
$$f(x^*, y^*) = \min_{y} \max_{x} f(x, y) = \max_{x} \min_{y} f(x, y),$$
这在分析游戏时非常有用。这里 max $f(x, y)$ 是给定 $y$ 和变量 $x$ 的 $f$ 的最大值，也就是说，这是针对选定值 $y$ 找到 $B$ 的结果；显然，这个值在$y=5$处最小。以类似的方式解释玩家$A$的选择$x=4$。

现在考虑一个具有支付函数$v=x^2-y^2$的游戏，它没有鞍点（检查这个）。分析具有这样功能的游戏就变得非常复杂。在此示例中，对手将有兴趣选择要实现的最大数字。如果我们对实践中经常遇到的$|x| \leq a, |y| \leq b$形式的变量$x$和$y$引入限制，就会出现4个鞍点：$x^* = \pm a, y^* = \pm b, (v^* = a^2 - b^2)$。

然而，由于这种限制，鞍点可能不会出现（参见练习 3）。

具有平方支付函数的游戏的解决方案

我们的理论考虑结果由以下定理总结。给定一个具有支付功能的价格
$$v = ax^2 + 2bxy + cy^2 + 2px + 2qy + r.$$
该函数有一个鞍点，并且 cer 是以下七种情况下且仅在其中的解决方案：
1) $a < 0, c > 0$;
2) $a < 0, c = 0 \neq b$;
3) $a < 0, c = b = q = 0$;
4) $a = 0 \neq b, c > 0$;
5) $a = b = p = 0, c > 0$;
6) $a = c = 0, b \neq 0$;
7) $a = b = c = p = q = 0$.

鞍点是方程组的解
$$\begin{cases} ax + by + p = 0, \\ bx + cy + q = 0. \end{cases}$$

除了 cer 之外，这个解决方案在所有这些情况下都是$(x^*, y^*)$，读者：对前面的具体例子的分析会对他有所帮助。
