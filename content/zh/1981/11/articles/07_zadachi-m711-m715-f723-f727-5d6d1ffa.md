M672。令 $a$ 为自然数，且 $2^a - 2$ 可被 $a$整除（例如，$a = 3$）。让我们通过条件定义序列$(x_n)$
$$x_1 = a, x_{k+1} = 2^{xk} - 1.$$
证明对于任何 $k$，$2^{xk} - 2$ 都能被 $x_k$ 整除。

很容易注意到三角形 $ABC$ 和 $ADC$ 的大小相等： $S_{ABC} = S_{ADC}$ - 它们有一个共同的底边 $AC$ 和长度相等的高度，降低到该底边。因此$\frac{1}{2} ab \sin \widehat{B} = \frac{1}{2} cd \sin (180^\circ - \widehat{B})$，即$ab = cd$。将(1)和(2)相加，即可得到所求的结果。

R·马佐夫

让我们用数学归纳法来证明这个命题。
对于$k = 1$，根据条件成立。假设$2^{xk} - 2$能被$x_k$整除，并证明$2^{xk+1} - 2$能被$x_{k+1}$整除。
设$x_{k+1} - 1 = 2^{xk} - 2 = mx_k$，其中$m > 1$是自然数。然后
$$2^{xk+1} - 2 = 2(2^{xk+1} - 1) = 2(2^{mx_k} - 1) = 2(2^{xk} - 1)(2^{(m-1)x_k} + 2^{(m-2)x_k} + \dots + 1) = Mx_k + 1$$
其中$M$是一个自然数，这就是我们需要证明的。

F685。在墙壁和质量为 $M=10$ 的立方体之间，质量为 $m=0,1$ g 的球在光滑的控制台上飞行。开始时，当立方体堆积时，这个速度是$v_0=100$米/秒。求立方体离墙距离是开始时的2倍时的速度。

我们假设球每次撞击立方体时，立方体的速度都会发生很小的变化，并且仍然比球的速度小很多倍。

令$x$为立方体到墙壁的距离，$u$为立方体的速度，$v$为球的速度。那么两次连续碰撞之间的时间是$\tau=2x/v$。每次碰撞时，立方体都会受到 $\Delta p=2mv$ 的冲量（我们教的是 $u\ll v$）。每次击打球的速度会改变$\Delta v=-2u$（如果我们考虑与立方体相关的参考系中的运动，这是非常/否）。为了简化计算，我们假设由于碰撞，速度$u$和$v$不是跳跃式变化，而是平滑变化。那么球的“平均”加速度是$v'=\frac{\Delta v}{\tau}=-\frac{uv}{x}$。考虑到$u=x'$，我们重写这个等式：

$$v'x+x'v=0.$$

注意，下面的表达式等于乘积$vx$的乘积；该乘积为零的事实意味着在施工期间仍保留数量 $vx$。因此，

$$vx=v_0x_0,$$

其中 $x_0$ 是过程开始时立方体与墙壁之间的距离。当$x=2x_0$时，球的速度为$v_0/2$。我们根据能量守恒定律求此时立方体的速度：

$$\frac{mv_0^2}{2}=\frac{m(v_0/2)^2}{2}+\frac{Mu^2}{2} \Rightarrow u=\frac{v_0}{2} \sqrt{\frac{3m}{M}} \approx 0,27 \text{ м/с.}$$

F686。质量为 $M$ 、半径为 $R$ 的细环放置在水平面上。沿着穿过篮筐内部的光滑通道，质量为 $m$ 的小冰球从顶点滑动，没有初始速度。求当冰球位于篮圈点 $A$ 时篮圈中心的速度，该点的半径矢量与垂直方向形成$\varphi$ 角。在最初的时刻，箍会积累。环与平面之间没有摩擦力。

作用在冰球系统上的力是重力和来自平面的法向反作用力。这两个力都沿着垂直方向。因此，系统的质心不会沿水平方向移动。

由于环和平面之间没有连接，因此环向前移动。根据动量守恒定律，在任何时刻

$$M|u|=m|v_x|,$$

其中 $u$ 和 $v_x$ 是篮筐和冰球速度的水平投影（以及 $u=|\vec{u}|$）。由于$v_x$周期性地改变符号，因此$u$“同步”改变符号。篮筐运动的一般性质如下：第 $BC$ 和 $BE$ (图 1) 部分中的冰球 - 篮筐中心向右移动； $CD$ 和 $DE$ 部分的冰球 - 篮筐中心向左移动。

冰球 $\vec{v}$ 和篮筐 $\vec{u}$ 的速度根据能量守恒定律相关：

$$mgR(1+\cos \varphi)=\frac{mv^2}{2}+\frac{Mu^2}{2},$$

其中 $\varphi$ 是冰球在给定时刻（对于给定值 $\vec{v}$ 和 $\vec{u}$）所在点的半径向量与垂直方向所成的角度。

F687。位于等边矩形楔子的底面AB的A点的钢球在边AO方向上的速度为$v_0$（见图）。当$v_0$为多少时，球会从A点移动到B点？楔形边长$l$。

一般情况下，球在 O 点从楔块开出后的轨迹将如 图 所示 - 它将由抛物线段组成。在连续的相等时间间隔 $t_1, t_2, t_3, \dots, t_n$ 内球的运动在 OX 轴上的投影相关如下：

$$s_1: s_2: s_3: \dots: s_n = 1: 3: 5: \dots: (2n-1)$$

（因为当球在 O 点“分离”时，其速度 $\vec{v}_1$ 在 OX 轴上的投影等于 0）。如果在与边 OB 第 $n$ 次碰撞期间，球击中 B 点，则

$$s_1 + s_2 + s_3 + \dots + s_n = s_1(1+3+5+\dots+(2n-1)) = s_1n^2 = l.$$

让我们看看$s_1$和$v_1$是如何相关的。球加速度在 OX 和 OY 轴上的投影等于 $a_x = a_y = g\sqrt{2}/2$，并且

$$s_1 = a_x \frac{t_1^2}{2} = g \frac{\sqrt{2}}{4} t_1^2.$$

我们从条件 $v_1 - a_y \frac{t_1}{2} = 0$ 中找到球第一次撞击挖起杆之前运动的时间 $t_1$：

$$t_1 = \frac{2v_1}{a_y} = \frac{4v_1}{g\sqrt{2}}.$$

因此，

$$s_1 = \frac{2v_1^2\sqrt{2}}{g},$$ 或 $v_1^2 = \frac{gl\sqrt{2}}{4n^2}$。

我们根据能量守恒定律找到$v_1$和$v_0$之间的联系：

$$\frac{mv_0^2}{2} = \frac{mv_1^2}{2} + mgl \frac{\sqrt{2}}{2} \Rightarrow v_0 = \sqrt{v_1^2 + gl\sqrt{2}} = \frac{1}{2n} \sqrt{gl\sqrt{2}(4n^2 + 1)}$$

因此，如果在 A 点给定速度 $|\vec{v}_0| = \frac{1}{2n} \sqrt{lg\sqrt{2}(4n^2 + 1)}$，则球会击中 B 点，其中 $n$ 是自然数。注意

$$\lim_{n \to \infty} v_0 = \sqrt{gl\sqrt{2}}.$$

能量守恒定律的结果相同：在$n \to \infty v_1 \to 0$，并且

$$\frac{mv_0^2}{2} = mgl \frac{\sqrt{2}}{2} \Rightarrow v_0 = \sqrt{gl\sqrt{2}}.$$
