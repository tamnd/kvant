道尔顿定律

在关于理想气体定律的问题中，经常存在我们讨论几种气体的混合物的问题。气态方程$pV = \frac{m}{\mu} RT$不适用于这种情况，因为不知道混合物$\mu$的摩尔质量是多少。怎么会这样呢？

显然，混合物中的每种气体都会对总压力产生影响。此外，每种气体的行为独立于其他气体并遵循门捷列夫-克拉佩龙方程

$$p_i V = \frac{m_i}{\mu_i} RT.$$

当其他成分从容器中取出时，任何成分产生的压力 $p_i$ 称为分压。英国科学家道尔顿通过实验确定，对于足够稀薄的气体，气体混合物的压力等于混合物各成分的分压之和：

$$p = p_1 + p_2 + \dots + p_n.$$

该定律从此被称为道尔顿定律。

现在很容易找到描述气体混合物状态的方程。为此，您需要将从门捷列夫-克拉佩龙方程获得的分压值代入表示道尔顿定律的等式中：

$$pV = \left( \frac{m_a}{\mu_a} + \frac{m_b}{\mu_b} \right) RT,$$

或者

$$pV = \left( v_1 + v_2 + \dots + v_n \right) RT,$$

其中$v_i$是相应组分的摩尔数。

让我们考虑几个具体任务。所有这些都是在莫斯科物理学院入学考试期间一次性提供的。

问题 1. 密闭容器被固体、静止、半渗透的隔板分成两个相等的部分。将氩气和氢气的混合物以$p = 1,5 \cdot 10^5$Pa的压力引入容器的前半部分，并将真空引入容器的后半部分。只有氢气可以通过隔板扩散。扩散过程结束后，前半部分的压力局部等于$p' = 10^5$ Pa。确定容器中氩气和氢气的质量比。氩气的摩尔质量为$\mu_a = 40$$\epsilon$/mol，氢气的摩尔质量为$\mu_b = 2$$\epsilon$/mol。假设在此过程中温度保持恒定。

扩散过程进行得相当快，因此，在将混合物引入容器的前半部分后，气体混合物立即产生压力$p$：

$$p = p_a + p_b.$$

这里$p_a$是氩气分压，$p_b$是氢气分压。它们可以从状态方程中找到：

$$p_a V = \frac{m_a}{\mu_a} RT \text{ и } p_b V = \frac{m_b}{\mu_b} RT,$$

其中$V$是容器一半的体积，$m_a$和$m_b$分别是氩气和氢气的质量，$T$是容器的温度。将压力$p_a$和$p_b$代入混合物压力$p$的表达式中，我们得到

$$pV = \left( \frac{m_a}{\mu_a} + \frac{m_b}{\mu_b} \right) RT =$$

$$= \left( \frac{m_a}{m_b} + \frac{\mu_a}{\mu_b} \right) \frac{m_b}{\mu_a} RT.$$

由于我们跳过了氢气的分配，因此在扩散过程结束后氢气将进入重量

容器的体积和整个容器中氢气的密度将相同。因此，一半的氢气将保留在前半部分，其分压$p'_B$将降低2倍：$p'_B = p_B/2$。氩气压力$p_a$不会改变。然后

$$p' = p_a + p'_B,$$

或者

$$p'V = \left( \frac{m_a}{\mu_a} + \frac{1}{2} \frac{m_b}{\mu_b} \right) RT = \left( \frac{m_a}{m_b} + \frac{1}{2} \frac{\mu_a}{\mu_b} \right) \frac{m_b}{\mu_a} RT. \tag{2}$$

将式(2)除以式(1)，经过多次变换，可得所需关系式：

$$\frac{m_a}{m_B} = \frac{\mu_a}{\mu_B} \frac{2p'-p}{2(p-p')} = 10.$$

问题 2. 圆柱形容器被可移动、传导良好的活塞体分成两部分。初始时刻，活塞右侧有氧气，左侧有氦气和氢气的混合物；氧气质量$m_K = 32$ g。活塞位于容器的中部。活塞材料不能渗透氢气和氧气，但可以渗透氦气，因此活塞开始移动，最终位于距离左壁四个气缸的位置。确定混合物中氦气和氢气的质量。

在第一时刻，氧气和氢气和氦气的混合物占据相同的体积；容器两个部分的温度相同（因为活塞良好地传导主体）；活塞左侧和右侧的压力也相同（因为活塞处于平衡状态，并且扩散过程比压力均衡过程发生得慢得多）。由此我们可以得出结论，在初始时刻，容器两部分中气体的摩尔数是相同的，即活塞左侧有 1 摩尔的氦气和氢气的混合物。

在最终压力状态下，氧气 $p_K$ 和氢气 $p_B$ 相同（因为容器两个部分的压力相同，并且活塞处于平衡状态）：

$$p_K = p_B.$$

根据氧和氢的门捷列夫-克拉佩龙方程，我们有

$$\frac{3}{4} p_K V = \frac{m_K}{\mu_K} RT \text{ и } \frac{1}{4} p_B V = \frac{m_B}{\mu_B} RT,$$

其中$m_K$和$m_B$是氧和氢的质量，$\mu_K$和$\mu_B$是它们的摩尔质量。从这里我们可以找到氢的质量：

$$m_B = m_K \frac{\mu_B}{3\mu_K} = \frac{2}{3} \Gamma,$$

对应于摩尔数$v_B = 1/3$。因此，氦气的摩尔数为$v_r = 2/3$，混合物中氦气的质量为$m_r = \mu_r v_r = 8/3 \Gamma.$

问题 3. 容器中含有氮气和氢气的混合物。在$T$的温度下，当氮气完全分解成原子，而氢气仍处于分子状态时，混合物的压力为$p$。在2T的温度下，当两种气体完全解离时，容器内的压力变为3p。氮气和氢气的摩尔数之比是多少？

让我们用 $v_a$ 表示混合物中氮的摩尔数，并用 $v_B$ 表示氢的摩尔数。在温度 $T$ 时，当氢仍处于分子状态时，方程的形式为

$$pV = (2v_a + v_B)RT$$

（这里考虑到氮气完全分解，其摩尔数增加了一倍），在2T的温度下，两种气体完全解离时，-

$$3pV = 2(2v_a + 2v_B)RT.$$

将一个方程除以另一个方程，我们得到

$$\frac{v_a}{v_B} = \frac{1}{2}.$$

气体混合物的状态方程

$$pV = (v_1 + v_2 + \dots + v_n)RT$$

可以以另一种形式呈现。事实上，每种气体的摩尔数 $v_i$ 等于比率

该气体的分子数 $N_i$ 等于阿伏伽德罗数 $N_A$，因此

$$pV = \left( N_1 + N_2 + \dots + N_n \right) \frac{R}{N_A} T.$$

如果我们用$N$表示混合物中的分子总数，并考虑到比率$R/N_A$是玻尔兹曼常数$k$，则状态方程可以写成如下：

$$pV = NkT.$$

请注意，单组分气体的门捷列夫-克拉佩龙方程看起来完全相同。这意味着这种形式的状态方程既可用于一种气体，也可用于气体混合物。

问题 4. 氚（原子质量为 $A=3$ 的氢同位素）储存在体积为 $V=1$ l 的容器中。氚质量$m=1$l。经过12年的使用，氚桤木变成了绿色的果仁。求储存期结束时容器内的压力。气体温度保持在$t=27^\circ C$。所得整体的原子质量为 $A=3$。

储存期开始时的氚压为

$$p_1 = \frac{N}{V} kT = \frac{m}{\mu} R \frac{T}{V}$$

（这里$N$是氚分子数，$\mu=6$g/mol是氚的摩尔质量）。

12年后，$N/2$氚分子变成$N$凝胶分子（每个氚分子与斜氢一样，含有2个原子）。容器中的压力$p_2$由氚和凝胶的混合物产生，其分子总数为$N/2+N=3/2N$：

$$p_2 = \frac{3}{2} NkT = \frac{3}{2} p_1 = \frac{3}{2} \frac{m}{\mu} R \frac{T}{V} \approx 6,3 \cdot 10^5 \Pi.$$
