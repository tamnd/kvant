容器的体积和整个容器中氢气的密度将相同。因此，一半的氢气将保留在前半部分，其分压$p'_B$将降低2倍：$p'_B = p_B/2$。氩气压力$p_a$不会改变。然后

$$p' = p_a + p'_B,$$

或者

$$p'V = \left( \frac{m_a}{\mu_a} + \frac{1}{2} \frac{m_b}{\mu_b} \right) RT = \left( \frac{m_a}{m_b} + \frac{1}{2} \frac{\mu_a}{\mu_b} \right) \frac{m_b}{\mu_a} RT. \tag{2}$$

将式(2)除以式(1)，经过多次变换，可得所需关系式：

$$\frac{m_a}{m_B} = \frac{\mu_a}{\mu_B} \frac{2p'-p}{2(p-p')} = 10.$$

问题 2. 圆柱形容器被可移动、传导良好的活塞体分成两部分。初始时刻，活塞右侧有氧气，左侧有氦气和氢气的混合物；氧气质量$m_K = 32$ g。活塞位于容器的中部。活塞材料不能渗透氢气和氧气，但可以渗透氦气，因此活塞开始移动，最终位于距离左壁四个气缸的位置。确定混合物中氦气和氢气的质量。

在第一时刻，氧气和氢气和氦气的混合物占据相同的体积；容器两个部分的温度相同（因为活塞良好地传导主体）；活塞左侧和右侧的压力也相同（因为活塞处于平衡状态，并且扩散过程比压力均衡过程发生得慢得多）。由此我们可以得出结论，在初始时刻，容器两部分中气体的摩尔数是相同的，即活塞左侧有 1 摩尔的氦气和氢气的混合物。

在最终压力状态下，氧气 $p_K$ 和氢气 $p_B$ 相同（因为容器两个部分的压力相同，并且活塞处于平衡状态）：

$$p_K = p_B.$$

根据氧和氢的门捷列夫-克拉佩龙方程，我们有

$$\frac{3}{4} p_K V = \frac{m_K}{\mu_K} RT \text{ и } \frac{1}{4} p_B V = \frac{m_B}{\mu_B} RT,$$

其中$m_K$和$m_B$是氧和氢的质量，$\mu_K$和$\mu_B$是它们的摩尔质量。从这里我们可以找到氢的质量：

$$m_B = m_K \frac{\mu_B}{3\mu_K} = \frac{2}{3} \Gamma,$$

对应于摩尔数$v_B = 1/3$。因此，氦气的摩尔数为$v_r = 2/3$，混合物中氦气的质量为$m_r = \mu_r v_r = 8/3 \Gamma.$

问题 3. 容器中含有氮气和氢气的混合物。在$T$的温度下，当氮气完全分解成原子，而氢气仍处于分子状态时，混合物的压力为$p$。在2T的温度下，当两种气体完全解离时，容器内的压力变为3p。氮气和氢气的摩尔数之比是多少？

让我们用 $v_a$ 表示混合物中氮的摩尔数，并用 $v_B$ 表示氢的摩尔数。在温度 $T$ 时，当氢仍处于分子状态时，方程的形式为

$$pV = (2v_a + v_B)RT$$

（这里考虑到氮气完全分解，其摩尔数增加了一倍），在2T的温度下，两种气体完全解离时，-

$$3pV = 2(2v_a + 2v_B)RT.$$

将一个方程除以另一个方程，我们得到

$$\frac{v_a}{v_B} = \frac{1}{2}.$$
