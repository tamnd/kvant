a) “捉迷藏”或“Ponsk”：$a = d = -1$、$b = c = 1$。玩家$A$将在两个地方之一定居，$B$将在同一个地方寻找他。实现目标的一方获得积分，另一方则失去一分（硬币）。

6) “防御和攻击”：$a = d = c + 1$，$b = 1$，其中$c > 1$给定，例如$c = 3$。由$A$领导的小队负责2个燃料仓库（第二个燃料仓库比第一个多$c$）。 $A$的力量只够保护一个仓库。部队$B$只能攻击其中一个仓库。如果他们的选择一致，那么一切都保持不变；如果不这样做，未受保护的仓库就会被烧毁。找出游戏的答案和价格并得出结果。

b) “海滩事件”：$a = d = -\frac{b + c}{2}$，$b > c > 0$。例如，$b = 30$、$c = 10$。一个陌生人$B$接近游客$A$并提供以下游戏：两人同时展示一侧 - 硬币。如果$y A$是“正面”，$y B$是“反面”，那么$A$将赢得30个硬币；如果
