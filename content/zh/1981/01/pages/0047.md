问题 4. 一颗卫星发射进入距地球表面 $H = 500$ 公里高度的陡峭轨道，在大气层上层减速。卫星的角加速度为$\beta = -3 \cdot 10^{-13}$ rad/s²。一个月后卫星的高度是多少？

让我们用$T_0$和$r_0$表示卫星的初始公转周期和轨道半径，用$T$和$r$表示卫星发射一个月后的轨道周期和半径。根据开普勒第三定律
$$\frac{T_0^2}{T^2} = \frac{r_0^3}{r^3};$$

因此，随着轨道周期的增加（随着频率的降低），轨道半径应该增加。我们来看看有多少。

让周期增加$\Delta T$，轨道半径增加$\Delta r$。由于捕捉加速度$\beta$很小，我们可以假设$\Delta T \ll T$和$\Delta r \ll r$。来自平等
$$T_0^2 (r_0 + \Delta r)^3 = (T_0 + \Delta T)^2 r_0^3,$$
忽略除第一个之外的所有幂$\Delta T / T$和$\Delta r / r$，我们得到
$$2 \frac{\Delta T}{T_0} = 3 \frac{\Delta r}{r_0}.$$

旋转周期$T$与角速度$\omega$通过对应关系$T = 2\pi / \omega$相关联。我们来微分一下：$T'(\omega) = -2\pi / \omega^2$。由于$\Delta T$和$\Delta \omega$很小，我们假设$\frac{\Delta T}{\Delta \omega} = T'(\omega)$。然后
$$\frac{\Delta T}{T_0} = -\frac{\Delta \omega}{\omega_0} = -\frac{\beta t}{\omega_0}.$$

由卫星在高度$H \ll r_3$的向心加速度约等于$g$的条件，求出初始角速度$\omega_0$：
$$\omega_0^2 r_0 = g, \omega_0 = \sqrt{\frac{g}{r_0}} = \sqrt{\frac{g}{r_3 + H}}.$$
最后
$$\Delta r = \frac{2}{3} \frac{\Delta T}{T_0} r_0 = -\frac{2}{3} \beta t (r^3 + H) \sqrt{\frac{r_3 + H}{g}} \approx 3 \text{ км}.$$
因此，一个月后卫星的高度将达到$H' = 503$公里。
