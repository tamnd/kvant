问题解决方案
M611—M615; F618—F622

M611。在以 O 为圆心的圆的弦 AB 上，取任意一点 M。通过 A、M、O 点，画一个与第一个圆相交于 A、C 点的圆。证明$|MB| = |MC|$。

让$\widehat{ABC} = \beta$。然后$\widehat{AOC} = 2\beta$，因为$\widehat{ABC}$和$\widehat{AOC}$是内接的，并且分别是基于给定圆（黑色-参见图）的相同弧AC的圆心角。

另一方面，$\widehat{AMC}$和$\widehat{AOC}$是构造的（蓝色）圆（位于非黑色圆中）的相同弧AC所对的内切角。因此$\widehat{AMC} = 2\beta$。

$AMC$是三角形MBC的外角。所以，$\widehat{MCB} = \widehat{AMC} - \widehat{MBC} = \beta$。从 $\widehat{MCB} = \widehat{AMC}$ 开始，接着$|MB| = |MC|$。

该解法适用于[AB]上的点M的任何位置（与读者发送的一些解法不同），除了M与弦AB的中点重合的情况。在最后一种情况下，蓝色圆圈接触黑色圆圈，点 A 和 C 合并，等式 $|MB| = |MC|$ 变为等式 $|MB| = |MA|$。

考虑一下，如果 M 取于线段 AB 的延续，那么已证明的命题是否仍为真。

N·瓦西里耶夫

M612。自然数的递增序列 ($a_n$) 使得$a_{n+1} \leq 10a_n$。证明如果所有数字$a_n$并排书写（没有空格或逗号），那么所得的数字序列将不是周期性的。

假设我们有一个周期性的数字序列，并且周期的长度（其中的数字位数）等于 T。很容易看出数字$a_{n+1}$可以比数字$a_n$“长”不超过一位数字（当然也不能短）。由于序列 ($a_n$) 返回，因此它包含大于 $a_1$ 长度的任意长度的数字。因此，其中有一个错误的数字$a_m$，其长度$kT$是周期的倍数（参见图）。 $a_{m+1}$的前$kT$数字必须与$a_m$的数字匹配，因此$a_{m+1}$多了一位数字（$a_{m+1} > a_m$），并且它必须有一个零（$10a_m \geq a_{m+1}$）。但是条目 $a_m$ 中的第一个数字为零，这当然是不可能的。

请注意，如果条件 $a_{n+1} \leq 10a_n$ 被替换为稍弱的条件：$a_{n+1} \leq 10a_n + 1$ 或 $a_{n+1} \leq (10 + \varepsilon)a_n$，其中 $\varepsilon$ 是任意正数，则所得的数字序列可能是周期性的。

I·克鲁莫娃

M613。在三角形ABC的边上，向外侧构造相似的三角形ADB、BEC和CFA($|AD|/|DB| = = |BE|/|EC| = = |CF|/|FA| = k$，$ADB = BEC = CFA = \alpha$)。证明a）线段AC、DC、BC、EF的中点是平行四边形的顶点； b) 这个平行四边形有两个整数a，边长比等于k。

让我们用$\vec{a}'$表示从向量$\vec{a}$逆时针旋转角度a获得的向量。 （已知 $(k\vec{a})' = k\vec{a}'$ 对于任何数字 $k$、$(\vec{a} + \vec{b})' = \vec{a}' + \vec{b}'$，一般而言，对于任何数量的项，$(\vec{a} + \vec{b} + \dots + \vec{c})' = \vec{a}' + \vec{b}' + \dots + \vec{c}'$。）让我们介绍向量 $\vec{DA} = \vec{a}$、$\vec{EB} = \vec{b}$、$\vec{FC} = \vec{c}$（参见图）。

根据条件$\vec{DB} = \frac{1}{k}\vec{a}'$、$\vec{EC} = \frac{1}{k}\vec{b}'$、$\vec{FA} = \frac{1}{k}\vec{c}'$。

从$\vec{AD} + \vec{DB} + \vec{BE} + \vec{EC} + \vec{FC} + \vec{FA} = 0$开始，$\vec{a} + \frac{1}{k}\vec{a}' - \vec{b} + \frac{1}{k}\vec{b}' - \vec{c} + \frac{1}{k}\vec{c}' = 0$，即$\vec{a} + \vec{b} + \vec{c} = \frac{\vec{a}' + \vec{b}' + \vec{c}'}{k} = \frac{1}{k} (\vec{a} + \vec{b} + \vec{c})'$。

用$\vec{u}$表示$\vec{a} + \vec{b} + \vec{c}$，我们得到$\vec{u} - \frac{1}{k}\vec{u}' = 0$。 (*)

由于向量 $\vec{u}$ 和 $\vec{u}'$ 不共线（$\alpha \neq 0$ 和 $\alpha \neq 2\pi$），因此当 $\vec{u} = \vec{0}$ 时，相等 (*) 是可能的。因此$\vec{a} + \vec{b} + \vec{c} = \vec{0}$。
