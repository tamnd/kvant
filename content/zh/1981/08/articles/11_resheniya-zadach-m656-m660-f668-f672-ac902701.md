底部出现孔后，玻璃内外的液体分离水平将相等。在这种情况下，玻璃应该开始向上移动，因为浮力增加（软木塞底部的压力增加，因为 $\rho_2 > \rho_1$）。唯一的抵消作用是由于这样的事实而产生的：在这种情况下，向上作用在玻璃末端的力减小（玻璃是薄壁的；这意味着末端区域 $\Delta S \ll S$）。很明显，在浮力增加不是很显着的情况下（如果有必要，这将是 $H - d$），玻璃漂浮到一定距离（我们用 x 表示）后，再次发现自己处于平衡状态。让我们写下第一种和第二种情况下均衡的增加（$p_0$ — 液体界面处的压力， $L$ - 玻璃总高度）：

$$mg + (p_0 - \rho_1gH)S = [p_0 + \rho_2g(L - H)]\S + [p_0 - \rho_2g(H - d)](S - \Delta S),$$

$$mg + [p_0 - \rho_1g(H + x)]S = [p_0 + \rho_2g(L - H - x)]\Delta S + [p_0 - \rho_1g(H + x - d)](S - \Delta S).$$

打开括号并引入相似的术语，我们得到

$$m = \rho_1HS - \rho_2HS + \rho_1dS + \rho_2L\Delta S - \rho_2d\Delta S,$$

$$m = \rho_1dS + \rho_2L\Delta S - \rho_2H\Delta S - \rho_2x\Delta S + \rho_1H\Delta S + \rho_1x\Delta S - \rho_1d\Delta S.$$

等式右边，简单变换后可得：

$$x = (H - d) \frac{S - \Delta S}{\Delta S}.$$

如果条件 x < L - H 被压缩，玻璃将停止向上移动，或者

$$H - d < \frac{\Delta S}{S} (L - d).$$

如果不满足这个条件，玻璃就会浮到表面。

F670。证明 α 粒子在碰撞时可以赋予质子的最大速度是 α 粒子初始速度的 1.6 倍。

我们首先假设质子相对于静止参考系结束，并且α粒子的速度为$\vec{v}_0$。它们的控制过程由动量守恒定律描述

$$4m\vec{v}_0 = m\vec{v}_1 + 4m\vec{v}_2$$

和能量守恒定律

$$\frac{4mv_0^2}{2} = \frac{mv_1^2}{2} + \frac{4mv_2^2}{2},$$

其中$\vec{v}_1$和$\vec{v}_2$是碰撞后相应质子和α粒子在静止参考系中的速度矢量，$m$和$4m$是质子和α粒子的质量。

让我们考虑这些粒子在质心系统中的碰撞过程，即在相对于静止参考系以$\vec{v}' = \frac{4m\vec{v}_0}{m+4m} = \frac{4}{5}\vec{v}_0$速度运动的惯性参考系中（第一个分子是系统的全冲量，分母是系统的总质量）。 图表示碰撞前质心系的矢量$\vec{v}_0$以及α粒子（矢量$\vec{OB}$）和质子（矢量$\vec{OA}$）的速度矢量； $|\vec{OB}| = \frac{1}{5}|\vec{v}_0|, |\vec{OA}| = \frac{4}{5}|\vec{v}_0|$。

根据冲积碰撞定律，碰撞后α粒子和质子的速度矢量$\vec{OB}'$和$\vec{OA}'$必须位于同一直线上，并且必须满足对应关系$|\vec{OB}'|:|\vec{OA}'| = 1:4$（见图）；根据能量碰撞定律，$|\vec{OB}'| = |OB|$和$|\vec{OA}'| = |\vec{OA}|$（告诉我！）。
