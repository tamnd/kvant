⟦folio 49⟧

这样的话，问题就很容易解决了。

然而，事情可能会发生不同的情况。例如，我们可以将沙子紧紧地塞进体内，当再多的摇晃也无济于事时，就增加沙子的“堵塞”——作用在墙上的压力可能会大很多倍。

如果我们缓慢而小心地将沙子倒入圆锥体中，然后小心地填充边缘并小心地避免晃动，那么压力可能会明显小于“静水压”情况下的压力。一般来说，静不定问题有许多正确的（当然也有不正确的）解决方案。

合理选择模型可以极大地促进数学80中严重问题的解决。

1. 一张面积为 60 平方厘米的纸上覆盖着三个面积为 30 平方厘米的彩色墨水。证明有两个总面积至少为 10 cm² 的印迹。

2. 魔术师邀请您写下任何三位数。然后他出现了，看着写下的数字，立即将三位数字相加，这样得到的六位数字就可以被37整除。他是怎么做到的？

3. 查找总和等于其乘积的所有整数对。

4. 某人1962年的年数等于其出生年份的数字之和。他是哪一年出生的？

5. 找到一个数字中最特殊的值，该数字的前三位数字形成一个代表完全平方数的数字，而后三位数字形成一个完全立方体。

6. 已知$x + 1/x$是整数。那么证明数$x^8 + 1/x^8$也是整数。

7. 已知$a + b + c < 0$和方程$ax^2 + bx + c = 0$没有实根。数字$c$有什么符号？

8. 已知$a, b, c$是不同的数字，$a^3 + b^3 + pc + q = 0$； $c^3 + pc + q = 0$。证明$a + b + c = 0$。

9. 给定一个锐角和它内部的一个点$A$。构造一个周长最小的三角形 $ABC$，其顶点 $B$ 和 $C$ 位于给定角的边上。

10. 四边形有三种角。证明它的两条对角线中较大的一条是从锐角顶点引出的一条。

11. 点 $M$ 是三角形 $ABC$ 的内接圆的圆心。证明通过点$A, M, C$的圆心位于角$B$的平分线上。

12. 当$k$为多少时，方程$x^3 + kx + 1 = 0$和$x^4 + kx^2 + 1 = 0$有共同根？找到这个根。

13. 证明用 81 个单位写成的数能被 81 整除。

14. 对于什么$c$，方程$4x^3 - 3x = c$有一个、两个、三个根？

15. 证明不等式$(n \in N)$的有效性

$$\frac{2}{\sqrt{n+1} + \sqrt{n-1}} > \frac{1}{\sqrt{n}}.$$
