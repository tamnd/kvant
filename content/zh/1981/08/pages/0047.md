质量为 $m_2$ 的负载以刚度 k 悬挂。弹簧未扩张状态下的长度为$l_0$。求当系统不受干扰时负载 $m_2$ 将执行的振荡幅度。螺纹上没有摆动。

（我们假设$m_2 > m_1$）。在这种情况下，线的张力将等于

$$T = \frac{2m_1m_2}{m_1 + m_2} g.$$

我们假设在初始时刻，系统在施加到负载$m_1$的附加力的帮助下保持平衡。那么初始时刻的弹簧张力

$$T_0 = m_2g \neq T,$$

因此，除了加速运动之外，还会发生负载相对于彼此的振荡。这些振荡期间张力的振幅等于

$$T_0 - T = \frac{m_2 - m_1}{m_2 + m_1} m_2g,$$

弹簧的最大拉伸量为

$$\Delta l = \frac{T_0 - T}{k}.$$

振动过程中载荷的混合与其质量成反比。如果$l_1$和$l_2$分别是负载$m_1$和$m_2$的最大混合，则

$$l_1m_1 = l_2m_2$$

$$l_1 + l_2 = l = \frac{T_0 - T}{k} = \frac{m_2 - m_1}{m_2 + m_1} m_2g.$$

从这里我们可以找到负载的振荡幅度$m_2$：

$$l_2 = l \frac{m_1}{m_1 + m_2} = \frac{m_2 - m_1}{k(m_1 + m_2)^2} m_1m_2g.$$

我们考虑在初始时刻负载$m_2$拉伸弹簧的情况下负载的运动。自己解决问题，假设弹簧在初始时刻没有被拉伸。

F669。将底部厚度为 d 的软木底部的薄壁玻璃浮在密度为 $\rho_1$ 和 $\rho_2$ 的两种液体之间的界面上。玻璃顶部位于界面上方H处。玻璃的横截面是S。如果玻璃底部出现一个洞，玻璃会上升多远？

底部出现孔后，玻璃内外的液体分离水平将相等。在这种情况下，玻璃应该开始向上移动，因为浮力增加（软木塞底部的压力增加，因为 $\rho_2 > \rho_1$）。唯一的抵消作用是由于这样的事实而产生的：在这种情况下，向上作用在玻璃末端的力减小（玻璃是薄壁的；这意味着末端区域 $\Delta S \ll S$）。很明显，在浮力增加不是很显着的情况下（如果有必要，这将是 $H - d$），玻璃漂浮到一定距离（我们用 x 表示）后，再次发现自己处于平衡状态。让我们写下第一种和第二种情况下均衡的增加（$p_0$ — 液体界面处的压力， $L$ - 玻璃总高度）：

$$mg + (p_0 - \rho_1gH)S = [p_0 + \rho_2g(L - H)]\S + [p_0 - \rho_2g(H - d)](S - \Delta S),$$

$$mg + [p_0 - \rho_1g(H + x)]S = [p_0 + \rho_2g(L - H - x)]\Delta S + [p_0 - \rho_1g(H + x - d)](S - \Delta S).$$

打开括号并引入相似的术语，我们得到

$$m = \rho_1HS - \rho_2HS + \rho_1dS + \rho_2L\Delta S - \rho_2d\Delta S,$$

$$m = \rho_1dS + \rho_2L\Delta S - \rho_2H\Delta S - \rho_2x\Delta S + \rho_1H\Delta S + \rho_1x\Delta S - \rho_1d\Delta S.$$

等式右边，简单变换后可得：

$$x = (H - d) \frac{S - \Delta S}{\Delta S}.$$
