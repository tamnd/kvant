曲线运动

身体沿着弯曲轨迹的运动经常在自然和技术中发现。例如，卫星和陨石在地球重力场中的运动，或者行星和彗星在太阳重力场中的运动，加速器中带电部件或各种机构部件的运动。

让我们回顾一下适用于曲线运动的基本定律。众所周知，物体的速度始终与其轨迹相切，并且在运动过程中其大小和方向都会发生变化。物体的加速度矢量与速度的方向并不重合，而是与速度成一定的角度。通常更方便的做法是不谈论加速度本身，而谈论它的两个投影。然而，其中所谓的切向（或切线）投影$a_T$是在速度方向上（即，朝向轨迹的切线方向）的投影。该投影表征了速度模型的变化。另一种所谓的法向（或向心）投影 $a_H$ 是垂直于速度矢量方向的投影。它表征了速度方向的变化。特别是，当物体沿圆周匀速运动时，加速度只有一个投影 - 垂直于速度并且仅改变其方向。该投影的模数等于速度模数的平方除以圆的半径：$a_H = v^2/R$。

任何曲线轨迹的一小部分总是可以表示为某个圆的一部分；相应圆的半径称为给定位置处轨迹的曲率半径。因此，可以使用表达式$a_H = v^2/R$来确定轨迹$R$的曲率半径。

最后，对于沿曲线轨迹运动的物体以及在闪电下运动的物体，牛顿第二定律是有效的：作用在物体上的所有力的矢量和等于物体的质量乘以其加速度的矢量。

让我们考虑几个关于物体曲线运动的具体问题。

问题 1. 物体以初速度 $\vec{v}_0$ 与地平线成 $\alpha_0$ 角从地球表面抛出。求物体加速度的切向投影和法向投影与其亚高度的关系。空气阻力可以忽略不计。

投掷后，只有一种力作用在身体上——朝向地球的重力，因此，在轨迹上的任何一点，身体的加速度$\vec{a}$等于自由落体的加速度$\vec{g}$（图1）。切向加速度和法向加速度投影相等，对应于

问题2.跳台滑雪加速山的最后一段BC是一段半径为$R = 15$米（图2）的圆弧。山体总高度$H = 50$米。求角度为$\alpha = 30^\circ$时滑雪者在C点的加速度模型。假设滑雪者在没有任何初始速度的情况下下山；你会忽视训练。

当沿着加速山运动时，滑雪者会受到两个力的作用。这是垂直向下的重力$m\vec{g}$，以及反作用力

$$\vec{m}\vec{g}$$

和支撑$\vec{N}$，方向，在没有摩擦的情况下，沿着轨迹的曲率半径，在我们的例子中是沿着半径$CO$。这些力的合力为中尉提供了初始加速度 $\vec{a}$：

$$\vec{m}\vec{a} = m\vec{g} + \vec{N}$$

根据力三角形的余弦定理，我们有（参见 图 2）

$$(ma)^2 = (mg)^2 + N^2 - 2mgN \cos \alpha.$$

令 $\vec{v}$ 为滑雪者在 C 点的速度。法向加速度投影 $a_H = v^2/R$ 创建相应的力投影 $m\vec{g}$ 和 $\vec{N}$：

$$mv^2/R = N - mg \cos \alpha.$$

从最后两个方程中消除 $N$，我们得到

$$a^2 = g^2 \sin^2 \alpha + (v^2/R)^2.$$

让我们根据能量守恒定律代入模型 $v$ 滑雪者速度的值

$$mv^2/2 = mg(H - R(1 - \cos \alpha))$$

并找到滑雪者加速度的模型：

$$a = (g^2 \sin^2 \alpha + (v^2/R)^2)^{1/2} = g(\sin^2 \alpha + 4(H/R - 1 + \cos \alpha)^2)^{1/2} \approx 65 \text{ m/c}^2.$$

从其他几个计算中可以得到相同的值。沿圆弧移动时，法向加速度投影为 $a_H = v^2/R$，仅由相应的重力投影创建的切向投影为 $a_T = g \sin \alpha$。那么加速度模型为

$$a = (a_H^2 + a_T^2)^{1/2} = (g^2 \sin^2 \alpha + (v^2/R)^2)^{1/2}.$$

分离的改变。身体沿着半渡轮的运动是在两个力的影响下发生的 - 重力$m\vec{g}$和法向（因为没有摩擦）反作用力$\vec{N}$。在分离瞬间，反作用力变为零，因此法向加速度$a_H = v_0^2/R$仅由相应的重力投影传递给物体：

$$mv_0^2/R = mg \cos \alpha_0.$$

将该方程与表达能量守恒定律的方程一起求解：

$$mv_0^2/2 = mgR(1 - \cos \alpha_0),$$

让我们找到：

$$\cos \alpha_0 = 2/3, \quad v_0 = (2gR/3)^{1/2}.$$

分离点的坐标等于相应的

$$y_0 = R \cos \alpha_0 = 2R/3,$$
$$x_0 = (R^2 - y_0^2)^{1/2} = R(1 - \cos^2 \alpha_0)^{1/2} = \sqrt{5}R/3.$$

现在我们写出物体脱离半渡轮后的运动方程：

$$x = x_0 + v_0 \cos \alpha_0 \cdot t,$$
$$y = y_0 - v_0 \sin \alpha_0 \cdot t - gt^2/2.$$

显然，在到达水平面的那一刻，坐标$y$变为零：$y = 0$。坐标$x$将从相应的运动方程中找到，代入初始条件（$x_0, v_0$和$\cos \alpha_0$）的值，以及从条件$y = 0$获得的撞击前的飞行时间：

$$x \approx 1,12R.$$
