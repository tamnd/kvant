图 5.

因为$C_1$是三角形$ABD$的质心。波兹尼$\overrightarrow{OM}_1 = 1/4\overrightarrow{OC} + 3/4 \cdot 1/3(\overrightarrow{OA} + \overrightarrow{OB} + \overrightarrow{OD}) = 1/4(\overrightarrow{OA} + \overrightarrow{OB} + \overrightarrow{OC} + \overrightarrow{OD})$。对于点 $M_2, M_3$ 和 $M_4$，我们分别以 3:1 的比例划分三角形中线 $AA_1, BB_1$ 和 $DD_1$，得到完全相同的表达式。因此，$\overrightarrow{OM}_2 = \overrightarrow{OM}_3 = \overrightarrow{OM}_4 = 1/4(\overrightarrow{OA} + \overrightarrow{OB} + \overrightarrow{OC} + \overrightarrow{OD})$，因此点 $M_1, M_2, M_3$ 和 $M_4$ 重合。

四面体中线的交点$M$称为其质心。请注意，对于空间中的任意点 $O$，$\overrightarrow{OM} = \frac{1}{4}(\overrightarrow{OA} + \overrightarrow{OB} + \overrightarrow{OC} + \overrightarrow{OD})$ 为真。

总之，我们将考虑一个有趣的平面测量定理，并尝试找到类似的立体测量定理。

定理5. 通过三角形$ABC$内的任意一点$O$，可以画出与其边平行的直线。如果 $S_1, S_2, S_3$ 是本例中形成的三角形的面积 (图 5)，$S$ 是给定三角形的面积，则

$$\sqrt{S} = \sqrt{S_1} + \sqrt{S_2} + \sqrt{S_3}.$$

证明。三角形的构成与三角形$ABC$类似，因此

$$\frac{\sqrt{S_1}}{\sqrt{S}} = \frac{|MR|}{|AB|}, \quad \frac{\sqrt{S_2}}{\sqrt{S}} = \frac{|OQ|}{|AB|}, \quad \frac{\sqrt{S_3}}{\sqrt{S}} = \frac{|OP|}{|AB|}.$$

添加这些等式，我们得到

$$\frac{\sqrt{S_1} + \sqrt{S_2} + \sqrt{S_3}}{\sqrt{S}} = \frac{|MR| + |OQ| + |OP|}{|AB|} = \frac{|MR| + |BR| + |MA|}{|AB|} = 1,$$

在哪里

$$\sqrt{S} = \sqrt{S_1} + \sqrt{S_2} + \sqrt{S_3}.$$

现在让我们在空间中制定一个类似的定理。

定理6.通过三角形内任意一点，画出四个与几何平行的平面。如果 $V_1, V_2, V_3, V_4$ 是在这种情况下形成的三角形的体积，并且 $V$ 是给定三角形的体积，则

$$\sqrt[3]{V} = \sqrt[3]{V_1} + \sqrt[3]{V_2} + \sqrt[3]{V_3} + \sqrt[3]{V_4}.$$

为了证明我们向读者提供的这一定理，人们应该利用条件中讨论的四面体与原始四面体相似的事实，以及这种多面体的体积是其边长的立方这一事实。

下面提出的任务成对组合。在每一对中，点 a) 是某个平面学定理，点 6) 是其空间模拟。
