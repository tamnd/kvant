问题解决方案

M666。证明$a_1 < a_2 < ... < a_n$的最小公倍数是$A$。那么显然，$\frac{A}{a_1} > \frac{A}{a_2} > ... > \frac{A}{a_n}$是自然数。因此$\frac{A}{a_1} \geq n$，因此$A \geq n a_1$。

这个估计是准确的。事实上，如果$a_1 = \frac{n!}{n-1}$，$a_2 = \frac{n!}{n-1}$，...，$a_n = n!$，则$A = n! = n \cdot a_1$。

在这个角度$\hat{A}$的两侧，我们关闭长度为$d$的给定线段AD和长度$e$的AE。 Telery 还需要找到这些边上的 B 点和 C 点（在 D 点和 E 点后面），即 $|BD| = |BC| = |CE|$。

为此，我们首先构造一个为所需的四边形 BCED 准备的图形。为此 (图 1)，让我们在 AD 线上（在不包含 A 的射线上）绘制任意长度 $q$ 的线段 DB1，然后并行地将射线 [DE] 与相同长度 $q$ 的矢量 $\vec{q}$ 相交，方向平行于 [AE]，之后在所得射线 $l$ 上标记一个点$C_1$，其中$|B_1C_1| = q$。显然，四边形$B_1C_1E_1D$与所要求的四边形BCED相似。现在过点E画一条平行于$B_1E_1$的线，我们找到点B；然后通过 B 点画一条与 $B_1C_1$ 平行的线，我们找到 C 点。（很容易看出，所有构造总是以独特的方式满足。）

这是另一种解决方案 - 不使用相似性方法的解决方案。如果 $O$ 是所需三角形 ABC 的内接圆心，则三角形 BOD、BOC 和 COE 是构造性的 (图 2)。顶点 O 处的所有角度偏移都等于 $90^\circ + \hat{A}/2$。因此$D\hat{OE} = 90^\circ - 3\hat{A}/2$（该量在$\hat{A} < 60^\circ$处为正）。 Telery，我们可以将点 O 构造为角 A 的平分线与末端为 D、E 的线段的灵魂的交点，并结合大小为 $90^\circ - 3\hat{A}/2$ 的内切角（图 2 处的红色弧）。然后，以所需的角度向线段 DO 和 EO 绘制射线 OB 和 OC，我们找到三角形 ABC 的两个顶点。

$$x^2 = (x+d)^2 + (x+e)^2 - 2(x+d)(x+e) \cos \hat{A},$$
