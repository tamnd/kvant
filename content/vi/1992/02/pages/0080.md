$$\cos (f(x + a/2)) = \cos (f(x - a/2))$$,
ở đâu $f(z) = z/(z^2 + a^2)$. Nó tương đương với tập hợp các phương trình

$$f(x + a/2) \pm f(x - a/2) = 2\pi k, \quad k \in \mathbb{Z}.$$

Hàm $f$ luôn được xác định, liên tục, có $f' = (a^2 - z^2)/(z^2 + a^2)^2$ tùy ý bằng 0 tại $z = \pm a$ và $z = -a$ là điểm tối thiểu và $z = a$ là điểm tối đa và

$$f_{\min} = f(-a) = -1/(2a) \geq -\pi,$$

$$|f(z_1) \pm f(z_2)| \leq |f(z_1)| + |f(z_2)| < 2\pi,$$

6. $(- \infty; -0,99) \cup (-0,02; 0) \cup (0; 0,01)$.
Bất đẳng thức này tương đương với một tập các hệ bất đẳng thức
$$\begin{cases} 0 < x - p < 1, \\ x^3 > (x - p)^2 \end{cases} \text{ и } \begin{cases} x - p > 1, \\ 0 < x^2 < (x - p)^2, \end{cases}$$

lần lượt, tương đương với sự kết hợp của hai hệ thống:
$$\begin{cases} 0 < x - p < 1, \\ |x| > x - p \end{cases} \text{ и } \begin{cases} x - p > 1, \\ 0 < |x| < x - p. \end{cases}$$

Với $|x| < 0,01$, nó tương đương với tập hợp hai hệ bất đẳng thức:
$$\begin{cases} |x| < 0,01, \\ 0 < x - p < |x| \end{cases} \text{ и } \begin{cases} |x| < 0,01, \\ x - p > 1. \end{cases}$$

Nếu với một giá trị nào đó $p$ hệ thống
$$\begin{cases} 0 < x - p < |x|, \\ |x| < 0,01 \end{cases}$$

có lời giải, rồi $-0,02 < x - p < x < 0,01$; ngược lại, nếu số $p$ thuộc khoảng $(-0,02; 0,01)$ thì hệ thống có lời giải cho tất cả $p$ ngoại trừ $p = 0$. Tương tự với hệ thống

$$\begin{cases} x - p > 1, \\ |x| < 0,01 \end{cases}$$

có lời giải khi và chỉ nếu $p < x - 1 < -0,99$.
