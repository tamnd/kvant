Lượng giác bài toán

1. Tìm xem trong hai số đó số nào lớn hơn:
a) tội lỗi 5 hoặc tội lỗi 6;
b) tg 3 hoặc tg 3°;
c) sin 3 hoặc sin 3°;

d) arcsin $\frac{2}{3}$ + arcsin $\frac{3}{4}$ hoặc $\frac{\pi}{2}$;

e) arctg $\frac{1}{2}$ hoặc $\frac{\pi}{5}$; g) arctg $\frac{2}{3}$ hoặc $\frac{\pi}{5}$;

f) arctg $\frac{3}{4}$ hoặc $\frac{\pi}{5}$.

2. Tính toán:
a) arcsin sin 10; 6) arccos cos 10;
b) arctg tg 10; r) arctg ctg 10;
d) sin $\left(2 \arccos \frac{1}{3}\right)$; e) cos $\left(2 \arcsin \frac{1}{3}\right)$;
g) cos (arctg 5);
h) tg$^3$ x + cot$^3$ x, nếu sin x + cos x = a.

3. Chứng minh độ chính xác:
a) $1 + \text{tg} x + \text{tg}^2 x + \text{tg}^3 x = \frac{\sqrt{2} \cos \left(\frac{\pi}{4} - x\right)}{\cos^3 x}$;
b) $\frac{\text{tg} 2x \text{tg} x}{\text{tg} 2x - \text{tg} x} = \sin 2x$;
c) $\frac{\sin 2x - \sin 3x + \sin 4x}{\cos 2x - \cos 3x + \cos 4x} = \text{tg} 3x$;
d) $\frac{3 - 4 \cos 2\alpha + \cos 4\alpha}{3 + 4 \cos 2\alpha + \cos 4\alpha} = \text{tg}^4 \alpha$;
e) arcsin x + arccos x = $\frac{\pi}{2}$;
g) arctg x + arctg x = $\frac{\pi}{2}$.

4. Giải các phương trình lượng giác:
a) $\cos \left(2x - \frac{\pi}{3}\right) = \frac{1}{2}$;
b) $\sin \left(3x + \frac{\pi}{4}\right) = \frac{\sqrt{3}}{2}$;
c) tg $\left(5x + \frac{\pi}{8}\right) = -\frac{1}{\sqrt{3}}$;
d) cos x + cos 5x = 2; g) sin x sin 5x = 1;
e) sin cos x = cos sin x; g) tg 2x tg 7x = 1;
f) tan (4 sin x) = $\sqrt{3}$; g) ctg (3 cos x) = 1;
k) sin 5x = sin x + sin 2x;
k) cos x + cos 3x + cos 5x + cos 7x = 0;
m) sin$^2$ x + sin$^2$ 2x + sin$^2$ 3x + sin$^2$ 4x = 2;
m) 3 sin 2x + 8 cos$^2$ x = 1;

o) cos x cos 3x = cos 2x;
n) 3 sin x + 4 cos x = 5;
p) sin x sin 3x + sin 4x sin 8x = 0;
c) $2 \sin^2 x + \sin^2 2x = \frac{5}{4} - 2 \cos 2x$;
t) $2 \sin^2 x = 4 \sin^2 2x + 7 \cos 2x - 6$;
y) $\cos^6 x + \sin^6 x = \frac{15}{8} \cos 2x - \frac{1}{2}$;
f) $3(\cos x - \sin x) = 1 + \cos 2x - \sin 2x$;
x) $1 + \sin 2x = \cos x - \sin x$;
c) $\frac{1}{\sin x} - \frac{1}{\sin 2x} = \frac{1}{\sin 3x}$;
h) 4 tg 4x - 4 tg 3x - tg 2x = = tg 2x tg 3x tg 4x;

5. Giải phương trình “tổng hợp”:
a) $4 |\sin x| + 2 \cos 2x = 3$;
b) $\sqrt{10} \cos x = \sqrt{4 \cos x - \cos 2x}$;
c) $|\text{ctg}(2x - \frac{\pi}{2})| = 1 - \frac{1}{\cos^2 2x}$;
d) $\sqrt{\cos x} = \sqrt{2} \sin \frac{x}{2}$;
e) cos x - 2 sin 2x - cos 3x = = |1 - 2 sin x - cos 2x|;
g) $\sqrt{12 - 5 \sin \left(x + \frac{\pi}{4}\right)} + 2 \sin x = = \frac{3 \sqrt{2}}{2} - 2 \cos x$;
e) $(4 \sin x + 1 + \sqrt{3 + 5 \cos 2x - 16 \sin x}) \times (1 + 3 \cos 2x) = 0$.

5. Giải phương trình bằng hàm lượng giác nghịch đảo:
a) $2 \arcsin x = \arccos 3x$;
b) $\arcsin x \cdot \arccos x = -1$;
c) arctg (x - 1) = 3 arctg (x + 1);
d) $2 \arcsin x + \arccos 2x = \pi/2$;
e) arcsin x = 2 arctg x;
g) $2 \arcsin x = \arcsin \left(2x \sqrt{1 - x^2}\right)$;
e) $2 \arccos x = \arccos \left(2x^2 - 1\right)$;
h) arccos $\left(\frac{2}{\pi} \arccos x\right) = \arcsin \left(\frac{2}{\pi} \arcsin x\right)$.
