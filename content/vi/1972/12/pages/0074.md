Về bài viết “Bất bình đẳng vô lý”

1. 4 < x < 7, x < $\frac{3}{4}$.
2. x < 1.
3. x > $\frac{\sqrt{5}-1}{2}$.
4. 3 < x ≤ 4.
5. 2 + $\sqrt{0,5}$ ≤ x < 3.
6. Nhập ký hiệu $y = \frac{2}{x}$ thì ta được
$$y \geq \frac{\sqrt{3}}{2}, \quad y \leq -\frac{\sqrt{3}}{2}.$$
Đáp số: $-\frac{4}{\sqrt{3}} \leq x \leq \frac{4}{\sqrt{3}}, x \neq 0.$
7. x > 5.
8. -1 ≤ x < 1, 7.
9. -\frac{1}{2\sqrt{2}} \leq x < \frac{1}{3}, x \neq 0.
10. x > 2.
11. Nhập ký hiệu $y = \sqrt{\sin x}, 0 \leq y \leq 1$. Sau đó $\sqrt{\cos x} = \sqrt[4]{1-y^4}$. Giải quyết bất đẳng thức
$$\sqrt[4]{1-y^4} > 1-y, из которого следует
0 < y < 1;$$
2πk < x < $\frac{\pi}{2}$ + 2πk, k = 0, ±1, ±2, ...
12. Nhập ký hiệu $y = \sqrt{2x+1}, y \geq 0;$ rồi $\sqrt{2x+9} = \sqrt{y^2+8}, x = \frac{1}{2}(y^2-1)$. Giải quyết bất đẳng thức
$$\frac{y^2-1}{\sqrt{y^2+8}} < y-1, откуда получаем
1 < y < 3, 5.$$

Đáp số: 0 < x < $\frac{45}{8}$.
13. Biến tất cả các số hạng sang vế trái và loại bỏ nhân tử chung x-3.
Đáp số: x ≤ -$\frac{5}{6}$, x ≥ 3.
14. Đi tới bất đẳng thức tương đương |x| - |x-2| < 0 với x > 4, x < -4.
Đáp số: x < -4.
