«Kvant» cho học sinh nhỏ

(xem «Kvant» số 8)
1. a) Nếu $abc = (a + b + c)^3$, thì $5 \leq a + b + c \leq 9$, do đó $a + b + c = \{5, 6, 7, 8, 9\}$.
Có thể dễ dàng báo cáo rằng $a + b + c$ không thể bằng 5, 6 và 9 (các lập phương của các số này có tận cùng là 5, 6 và 9). Vẫn còn phải kiểm tra các trường hợp $a + b + c = 7$ và $a + b + c = 8$.
Chúng tôi có: $7^3 = 343$ - không phù hợp; $8^3 = 512$ - phù hợp. Vì vậy, chúng tôi loại trừ số 512.
6) Nếu $abcd = (a + b + c + d)^4$ thì $6 \leq a + b + c + d \leq 9$, tức là $a + b + c + d = \{6, 7, 8, 9\}$.
$a + b + c + d \neq 6$ một lần nữa, vì $6^4$ kết thúc bằng 6.
