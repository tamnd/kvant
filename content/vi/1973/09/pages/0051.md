Cơm. 1.

$BOA + BC_1A = AB_1C + BA_1C + BC_1A = 180^\circ$. Do đó, điểm $O$ nằm trên đường tròn ngoại tiếp $\Delta ABC_1$. Mệnh đề (a) bài toán đã được chứng minh.

Bây giờ chúng ta hãy chứng minh rằng $A_1OA = 180^\circ$. Thật vậy, $A_1OA = A_1OC + COA = A_1BC + 180^\circ - AB_1C = 180^\circ$. Do đó, đường thẳng $AA_1$ đi qua điểm $O$. Do đó, các đường $BB_1$ và $CC_1$ cũng đi qua điểm này. Câu (b) bài toán đã được chứng minh.

Lớp 9, bài toán 3. Điều kiện bài toán còn bao hàm các bất đẳng thức sau: $-1 \leq c \leq 1$; $-1 \leq a + b + c \leq 1$; $-1 \leq a - b + c \leq 1$. Từ hai bất đẳng thức cuối, suy ra $-1 \leq a + c \leq 1$ và $-1 \leq b \leq 1$. Chúng tôi sẽ giả định rằng $a \geq 0$. Thật vậy, nếu $a < 0$, thì thay thế $a$, $b$ và $c$ bằng $-a$, $-b$ và $-c$ tương ứng; điều kiện bài toán các giá trị mới cũng thỏa mãn và $a$ mới (bằng $-a$) sẽ dương.

Bây giờ chúng ta hãy xem xét một số trường hợp.

1. $c \geq 0$. Sau đó $|cx^2 + bx + a| \leq c + |b| + a$ tại $|x| \leq 1$. Nhưng $c + |b| + a \leq 1$ (vì $|b|$ là $b$ hoặc $-b$), và thậm chí còn hơn thế nữa là $|cx^2 + bx + a| < 2$ với $|x| \leq 1$.

2. $c < 0$. Khi đó $a + c \leq cx^2 + a \leq a$, Do đó $a + c - |b| \leq cx^2 + a + bx \leq a + |b|$. Nhưng $-1 \leq a + c - |b|$ và $a + |b| \leq 1 - c \leq 2$. Do đó, bất đẳng thức $|cx^2 + bx + a| \leq 2$ luôn đúng. Khi nhìn lại, chúng ta thấy rằng nếu đối với một số $x_0$ đẳng thức $|cx^2 + bx + a| = 2$ được thỏa mãn thì $c = -1$, $cx^2 + bx + a = 2$ và $x_0 = 0$ (hãy nhớ rằng chúng ta có $a \geq 0$), do đó $a = 2$ và $b = 0$ (kể từ $a + c = 1$).
