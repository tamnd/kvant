4. 1988. Доказательство. Пусть число 2$^{1987}$ содержит $n$ цифр, а число 5$^{1987}$ содержит $k$ цифр. Тогда

$$10^{n-1} < 2^{1987} < 10^n \text{ и } 10^{k-1} < 5^{1987} < 10^k.$$

Отсюда $10^{n+k-2} < 10^{1987} < 10^{n+k}$, значит, $k+n-2 < 1987 < k+n$, т. е. 1987=k+n-1, отсюда $k+n=1988$.
