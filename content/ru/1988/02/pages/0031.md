M1067. Докажите, что для неотрицательных чисел x, y, z, удовлетворяющих условию $x^2 + y^2 + z^2 = 1$, выполняем неравенство

$$\frac{x}{1-x^2} + \frac{y}{1-y^2} + \frac{z}{1-z^2} \geq \frac{3\sqrt{3}}{2}.$$

Докажем, что

$$\frac{t}{1-t^2} \geq \frac{3\sqrt{3}}{2} t^2$$

при всех $t, 0 \leq t < 1$. На этом интервале неравенство (*) равносильно неравенству

$$f(t) = \frac{3\sqrt{3}}{2} t(1-t^2) \leq 1,$$

которое доказывается с помощью стандартного исследования функции $f(t)$. (Производная $f'(t) = \frac{3\sqrt{3}}{2}(1-3t^2)$ имеет на [0; 1] единственный корень $t = 1/\sqrt{3}$, причем $f(0) = f(1) = 0 < f(1/\sqrt{3}) = 1$. Следовательно $1/\sqrt{3}$ — точка максимума $f(t)$ на [0; 1].).

В силу (*) левая часть доказывается неравенства неравенстве, чем

$$\frac{3\sqrt{3}}{2}(x^2 + y^2 + z^2) = \frac{3\sqrt{3}}{2};$$

равенство достигается лишь при $x = y = z = 1/\sqrt{3}$.
