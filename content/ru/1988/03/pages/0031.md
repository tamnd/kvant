то ускорение $a$ принимает минимальное значение при $\alpha_1 = \arccos \left( \frac{4}{3} \cos \alpha_0 \right)$ (см. рис. 2).

$$\Delta = f(1) - f(\cos \alpha_0) = 5 \cos^2 \alpha_0 - 8 \cos \alpha_0 + 3.$$

Максимальное значение $f(\cos \alpha)$ (а следовательно, ускорение $a$) принимает либо $\cos \alpha = \cos \alpha_0$, либо $\cos \alpha = 1$. Расстояние разность

$$\Delta = f(1) - f(\cos \alpha_0) = 5 \cos^2 \alpha_0 - 8 \cos \alpha_0 + 3.$$

Видим, что

$$\Delta \leqslant 0 \text{ при } \cos \alpha_0 \geqslant 3/5,$$
$$\Delta > 0 \text{ при } \cos \alpha_0 < 3/5.$$

Значит, ускорение $a$ принимает максимальное значение (см. рис. 2)

при $\alpha_2 = \alpha_0$, если $\alpha_0 \leqslant \alpha_{0B} = \arccos \frac{3}{5}$,

при $\alpha_2 = 0$, если $\alpha_{0B} < \alpha_0 \leqslant \frac{\pi}{2}$.
