1. $x_1 = x_2 = \dots = x_{100} = \frac{-1 \pm \sqrt{5}}{2}$. Решение е.
Если $x_1 = \dots = x_{100}$, то все уравнения системы превращаются в одно и то же уравнение $x_1^2 + x_1 - 1 = 0$, решая которое мы получаем $x_1 = \frac{-1 \pm \sqrt{5}}{2}$. Покажем, что других решений нет. Преобразуем уравнение к виду $x_1 = \frac{1}{1+x_2}$, $x_2 = \frac{1}{1+x_3}, \dots, x_{99} = \frac{1}{1+x_{100}}, x_{100} = \frac{1}{1+x_1}$. Подставим выражение для $x_{100}$ в выражение для $x_{99}$, выражение для $x_{99}$ — в выражение для $x_{98}$ и т. д. Получим

$$x_1 = \frac{1}{1 + \frac{1}{1 + \dots + \frac{1}{1+x_1}}}.$$

Преобразуя многоэтажную дробь в правой части равенства *) к общчной форме, мы приводим равенство к виду

$$x_1 = \frac{ax_1 + b}{cx_1 + d},$$

что равносильно квадратному уравнению. Значит, для $x_1$ имеет не более 2-х возможных значений, но 2 значения мы уже знаем: $\frac{-1 \pm \sqrt{5}}{2}$. Значит, $x_1$ обязаетльно равно одному из этих чисел. Зная $x_1$, мы находим (пользоваем вышпириведенными формулами) $x_{100}, x_{99}, \dots$

3. $\{1, 1, 1\}, \{1, 1, 2\}, \{1, 2, 3\}$ (с точностью до порядка). Решение е. Пусть $x_1, x_2, x_3$ — данные числа, и пусть $x_1 \leq x_2 \leq x_3$. Тогда $x_1 + x_2 \leq 2x_3$, откуда либо $x_1 + x_2 = x_3$, либо $x_1 + x_2 = 2x_3$. Посленее возможно только при $x_1 = x_2 = x_3$, а тогда (ввиду условия взаимной простоты) $x_1 = x_2 = x_3 = 1$. Пусть $x_1 + x_2 = x_3$. Тогда $x_1 + x_3 = 2x_1 + x_2$ делится на $x_2$; значит, $2x_1$ делится на $x_2$. Но $2x_1 \leq 2x_2$, так что либо $x_1 = x_2$, либо $2x_1 = x_2$. В первом случае $x_3 = 2x_1$ и (ввиду условия простоты) $\{x_1, x_2, x_3\} = \{1, 1, 2\}$; во втором случае $x_3 = 3x_1$ и $\{x_1, x_2, x_3\} = \{1, 2, 3\}$.
