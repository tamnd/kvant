Примечание. Перестановкой конечного множества $S$ называется взаимно однозначное отображение $f$ множества $S$ на себя; число всех перестановок множества из $n$ элементов равно $n! = 1 \cdot 2 \cdot \dots \cdot n$. Элемент $a$ множества $S$ называется неподвижной точкой перестановки $f$, если $f(a) = a$.

$$\sum_{k=0}^{n} kp_n(k) = n \sum_{k=1}^{n} p_{n-1}(k-1) = n \cdot (n-1)! = n!.$$

6) Докажем сразу более общее точекство

$$s(n, m) = \sum_{k=m}^{n} \frac{k!}{(k-m)!} p_n(k) = n!$$

при всех $n \geq m$, $m=0, 1, 2, \dots$ (по определению, $0!=1$). При $m=0$ оно совпадает с (1), при $m=1$ — с утверждением a), а при $m=2$ эквивалентно 6), поскольку

$$\sum_{k=0}^{n} (k-1)^2 p_n(k) = \sum_{k=0}^{n} k(k-1)p_n(k) - \sum_{k=0}^{n} kp_n(k) + \sum_{k=0}^{n} p_n(k) = s(n, 2) - s(n, 1) + s(n, 0).$$

Из точекства (2) следует, что при $1 \leq m \leq k \leq n$

$$\frac{k!}{(k-m)!} p_n(k) = k(k-1) \dots (k-m+1)p_n(k) = n(k-1) \dots (k-m+1)p_{n-1}(k-1) = n(n-1)(k-2) \dots (k-m+1)p_{n-2}(k-2) = \dots = n(n-1) \dots (n-m+1)p_{n-m}(k-m) = \frac{n!}{(n-m)!} p_{n-m}(k-m).$$

Суммируем эти равенства по $k=1, 2, \dots n$:

$$s(n, m) = \frac{n!}{(n-m)!} s(n-m, 0) = n!.$$

Другое доказательство (3) можно получить из почты очевидного соответствия $p_n(k) = C_n^k p_{n-k}(0)$, где $C_n^k = n!/(k!(n-k)!)$ — число $k$-элементов подмножества множества из $n$ элементов (число сочетаний).

Наш читатель Л. М. Коганов (Москва) сообщил еще об одном обобщении этой задачи, принадлежащем американскому математике Дж. Голдману: если $S(q, i)$ — это число разбиений множества $\{1, 2, \dots, q\}$ на $i$ непустых непересекающихся множества, то

$$\sum_{k=0}^{n} k^q p_n(k) = n! \sum_{i=1}^{m} S(q, i),$$

где $m=\min(n, q)$. Доказательство этого соответствия, предложенное Л. М. Когановым, написано вывод формулы (2) и совпается к подсчету двумя способами kolicheства пар $(f, \varphi)$, где $f$ — произвольная перестановка множества из $n$ элементов, а $\varphi$ — произвольное отображение множества $\{1, 2, \dots, q\}$ в множестве неподвижных точек перестановки $f$.
