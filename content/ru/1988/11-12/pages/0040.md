Для ее доказательства можно воспользоваться тем, что $\ln n = \int_{1}^{n} 1/t \, dt$ — площадь под гиперболой $f(t) = 1/t$ на участке $1 \leq t \leq n$ (рис. 1); можно не пользоваться интегралом, а, например, убедиться в справедливости неравенств

6) Логарифм среднего арифметического несколько чисел равен среднему арифметическому их логарифмов. Поэтому для решения задачи достаточно доказать, что среднее арифметическое чисел $\ln d$ (где $d=\text{НОД} (a, b)$, $a<b \leq n$) меньше 2: ведь $e^2 < 10$, т. е. $2 < \ln 10$. Действуя так же, как и выше, получим

$$\frac{2}{n(n-1)} \sum_{d=1}^{n} \ln d \cdot P_n(d) \leq \sum_{d=2}^{n} \frac{\ln d}{d^2} < \sum_{d=2}^{n} \left( \frac{1}{d^2} \sum_{h=1}^{n} \frac{1}{h} \right).$$

Здесь мы применили лемму: $\ln d \leq 1 + \frac{1}{2} + \ldots + \frac{1}{d}$.

В образовательной двойной сумме чисел вида $\frac{1}{d^2} \frac{1}{h}$ ($1 \leq h \leq d$, $2 \leq d \leq n$) удобно собрать вместе числы с одинаковыми $h$ ($1 \leq d \leq n$ при $h=1$, $h \leq d \leq n$ при $h>1$) и оценить $\sum_{d=h}^{n} \frac{1}{d^2}$ с помощью легкого сворачивающейся суммы

$$\sum_{d=h}^{n} \frac{1}{d(d-1)} = \sum_{d=h}^{n} \left( \frac{1}{d-1} - \frac{1}{d} \right) = \frac{1}{h-1} - \frac{1}{n} < \frac{1}{h-1}$$

(эта оценка понадобится сейчас раз для $h=2$).

Окончательно получаем

$$\sum_{d=2}^{n} \frac{\ln d}{d^2} < \sum_{d=2}^{n} \frac{1}{d^2} + \sum_{h=2}^{n} \left( \frac{1}{h} \sum_{d=h}^{n-1} \frac{1}{d^2} \right) < 1 + \sum_{h=2}^{n} \frac{1}{h(h-1)} < 2.$$

Доказем теперь оценку $P_k \geq k(k-1)$, используяную в решении пункта a). Положим $m=[k/2]$. Среди всех целых точек $(x, y)$, где $0 < x < y \leq k$, называем красными те, для которых $x$ и $y$ взаимно просты (рис. 2). Проведем через каждую красную точку в треугольнике $x < y \leq m$ луч из начала координат $(0, 0)$. Эти $P_m$ лучей содержат, конечно, все $m(m-1)/2$ целых точек в треугольнике $x < y \leq m$.

Рассмотрим целые точки на любом из $P_h$ лучей.
