Головоломки

(см. 4-ю с. обл.)

1) Чтобы снять челнок в позиции В надо сначала продеть в него $(k - 1)$-е колюц — это потребует $L_{k-1}$ ходов — и снять $k$-е колюц (1 ход). Получится позиция В, но для меледы с $k - 1$ колюцами. Тепер, чтобы освободить челнок, нужно выполнить еще $L_{k-1}$ ходов. Итак, $L_k = 2L_{k-1} + 1$. Если в исходном положении челнок пройдёт через все $k$ колец (рис. А), то сначала нужно снять с него колюца 1, 2, ..., $k - 2$ ($M_{k-2}$ ходов), а затем $k$-е колюц. Заключительная $L_{k-1}$ ходов также же, как в первом служебке. Таким образом, $M_k = M_{k-2} + 1 + L_{k-1}$.

2) Переписав соответствие для $L_k$ в виде $L_k + 1 = 2(L_{k-1} + 1)$ и заменяя, что $L_1 = 1$, получим: $L_k + 1 = 2^k$, т. е. $L_k = 2^k - 1$. Следовательно, $M_k = M_{k-2} + 2^{k-1}$, причем $M_1 = 1$, $M_2 = 2$. Отсюда легко вывести формулы: $M_k = (2^{k+1} - 1)/3$ при нечетном $k$, $M_k = (2^{k+1} - 2)/3$ при четном $k$. Обозначим через $i$ операцию снять $i$-го колюца с челнока, через $i'$ операцию продевания этого колюца в челнок, через $f_k$ — последовательность ходов для освобождения челнока в позиции В. Рассуждая так же, как в задаче 1), получим, что $f_k = f_{k-1} k f_{k-1}$, где $f_{k-1} = i'$ операция, обратная к $f_k$. Поляга $f^{-1} gf = f * g$, можно переписать это равенство в виде $f_k = f_{k-1} * k = (f_{k-2} * (k - 1)) * k = ... = (...(1 * 2) * 3) * ... * (k - 1)) * k$; например, для $k = 3$ $f_3 = 1'2'131'21$. последовательность для снять челнока в позиции А при произвольном нечетном $k$ выглядел так: $13f_25f_4 \dots kf_{k-1}$, а при четном $k - 214f_36f_5 \dots kf_{k-1}$.
