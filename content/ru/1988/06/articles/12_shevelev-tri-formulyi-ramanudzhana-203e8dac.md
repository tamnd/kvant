Три формулы Рамануджана
Кандидат физико-математических наук
В. С. ШЕВЕЛЕВ

В формулах Рамануджана всегда содержится горадо большие, чем это кажется на первый взгляд...

Харди

В этой статье речь пойдет о трех замечательных формулах Рамануджана*), каждая из которых содержит в левой части три кубических корня:

$$\sqrt[3]{\frac{1}{9}} - \sqrt[3]{\frac{2}{9}} + \sqrt[3]{\frac{4}{9}} = \sqrt[3]{\sqrt[3]{2} - 1},$$

(1)

$$\sqrt[3]{\cos \frac{2\pi}{7}} + \sqrt[3]{\cos \frac{4\pi}{7}} + \sqrt[3]{\cos \frac{8\pi}{7}} =$$

$$= \sqrt[3]{\frac{5 - 3\sqrt[3]{7}}{2}},$$

(2)

Эти формулы трудно спутать с формулами какого-либо другого математика: они напоминают загадочное жонглирование с числами.

Первая формула более проста и доказывает последовательным возвведение в куб. Для нас, кроме естественного воспрятия, она интересна тем, что в структуром отношений очень похожа на две следующие. Что же касается формул (2) и (3), то здесь далеко не все так просто. Приведем интересные цитаты об этих формулах из брошюры В. И. Левина**):

«Эти формулы совсем элементарны, но очень глубоки. Они обладают неповторимой внутренней симметрией, иогдается об их существовании

**) Левин В. И. Рамануджаан. — М.: Знание, 1968.

Мог только математик самого высокого ранга». И еще: «Эти точные равенства являются, конечно, частными случаями значительного более общих соотношений, которые распространяют Рамануджан, но о которых он никогда ничего не сообщил...»

Мы приглашаем читателя проследить за доказательством формул (2) и (3). В некоторых местах ему понадобятся карандаш и бумага. В награду он почти внутренний механизм, управляющий этими красивыми формулами и, по-видимому, сможет, уже самостоятьно, доказать несколько формул типа формул Рамануджана (найdenных автором, — см. упражнение 5), а возможно, и придумать свои.

Связь с формулами Виета

Связь между тригонометрией и алгеброй легко угадавается в формулах Рамануджана. Вглядимся пристальное в числа

$$\begin{cases} \cos \frac{2\pi}{7}, \cos \frac{4\pi}{7}, \cos \frac{8\pi}{7} \\ \cos \frac{2\pi}{9}, \cos \frac{4\pi}{9}, \cos \frac{8\pi}{9} \end{cases}.$$

Прежде всего бросается в глаза, что аргументы косинусов составляют в обеих тройках геометрические прогрессии со значенателем 2.

Воспользовавшись преобразованием

$$\cos \alpha \cos 2\alpha \cos 4\alpha = \frac{\sin 2\alpha \cos 2\alpha \cos 4\alpha}{2 \sin \alpha} = \frac{\sin 4\alpha \cos 4\alpha}{4 \sin \alpha} = \frac{\sin 8\alpha}{8 \sin \alpha},$$

можно установить такие равенства:

$$\cos \frac{2\pi}{7} \cos \frac{4\pi}{7} \cos \frac{8\pi}{7} = \frac{1}{8},$$

$$\cos \frac{2\pi}{9} \cos \frac{4\pi}{9} \cos \frac{8\pi}{9} = -\frac{1}{8}.$$

Это — наш первый успex, показывающий, что аргументы косинусов в формулах Рамануджана выбранны относительно не случайной.

Попробем найти теперь суммы трех косинусов. Имеем:

$$\cos \frac{2\pi}{7} + \cos \frac{4\pi}{7} + \cos \frac{8\pi}{7} =$$

$$= \frac{2 \sin \frac{\pi}{7}}{2 \sin \frac{\pi}{7}} \left( \cos \frac{2\pi}{7} + \cos \frac{4\pi}{7} + \cos \frac{6\pi}{7} \right) =$$

$$= \frac{1}{2 \sin \frac{\pi}{7}} \left( \sin \frac{3\pi}{7} - \sin \frac{\pi}{7} + \sin \frac{5\pi}{7} \right) - \sin \frac{3\pi}{7} + \sin \pi - \sin \frac{5\pi}{7} = -\frac{1}{2};$$

$$\cos \frac{2\pi}{9} + \cos \frac{4\pi}{9} + \cos \frac{8\pi}{9} =$$

$$= \cos \frac{2\pi}{9} + \cos \frac{4\pi}{9} - \cos \frac{\pi}{9} =$$

$$= 2 \cos \frac{3\pi}{9} \cos \frac{\pi}{9} - \cos \frac{\pi}{9} = 0.$$

Наконец, пошем такие суммы:

$$S_1 = \cos \frac{2\pi}{7} \cos \frac{4\pi}{7} + \cos \frac{2\pi}{7} \cos \frac{8\pi}{7} + \cos \frac{4\pi}{7} \cos \frac{8\pi}{7},$$

$$S_2 = \cos \frac{2\pi}{9} \cos \frac{4\pi}{9} + \cos \frac{2\pi}{9} \cos \frac{8\pi}{9} + \cos \frac{4\pi}{9} \cos \frac{8\pi}{9}.$$

Упражнение 1. Докажите, что $S_1 = -\frac{1}{2}, S_2 = -\frac{3}{4}$.

Напишем теперь формулы Виета для кубического уравнения. Если $x, y, z$ — корни уравнения

$$t^3 + pt^2 + qt + r = 0,$$

то, как известно,

$$\begin{cases} x + y + z = -p, \\ xy + xz + yz = q, \\ xyz = -r. \end{cases}$$

Сравним (4) с равенствами, которые мы получили выше для рамануджановских троек косинусов, заключаем, что первая тройка состоит из корней уравнения

$$t^3 + \frac{1}{2} t^2 - \frac{1}{2} t - \frac{1}{8} = 0,$$

а вторая — из корней уравнения

$$t^3 - \frac{3}{4} t + \frac{1}{8} = 0.$$

Этот этап — самый важный в нашем доказательстве. Он показывает, како-

Рассмотрим сумму трех корней...

Поставим теперь задачу так. Дано уравнение
$$t^3 + pt^2 + qt + r = 0,$$
корнями которого являются числа $x, y, z$. Требуется найти сумму их кубических корней (куб этой суммы обозначим через $A$):
$$\sqrt[3]{x} + \sqrt[3]{y} + \sqrt[3]{z} = \sqrt[3]{A}.$$
(7)

Оказывается, сумму (7) легко искать вместе с другой суммой:
$$\sqrt[3]{xy} + \sqrt[3]{xz} + \sqrt[3]{yz} = \sqrt[3]{B}.$$
(8)

Возвода в куб обе части (7), а затем (8) и учитывая формулы Виета (4), получаем (проверьте это самостояльно):
$$A = -p + 3\sqrt[3]{AB} + 3\sqrt[3]{r},$$
$$B = q - 3\sqrt[3]{ABr} - 3\sqrt[3]{r^2},$$
(10)

Умножая (9) на $\sqrt[3]{r}$ и складывая с (10), выражаем $B$ через $A$:
$$B = q - (A + p)\sqrt[3]{r}.$$
(11)

Подставляя это в (9), получаем уравнение только относительно $A$:
$$A + p - 3\sqrt[3]{r} = 3\sqrt[3]{A(q - (A + p)\sqrt[3]{r})}.$$
(12)

Наконец, возвода обе части уравнения в куб, получаем следующее кубическое уравнение относительно $A$:
$$A^3 + 3(p + 6\sqrt[3]{r})A^2 + 3(p^2 + 3p\sqrt[3]{r} + 9\sqrt[3]{r^2} - 9q)A + (p - 3\sqrt[3]{r})^3 = 0.$$ (11)

Упрощение кубического уравнения

Пусть дано кубическое уравнение
$$x^3 + 3bx^2 + 3cx + d = 0.$$ (12)

Покажем, как — в некоторых случаях особенно успешно — оно может быть упрощено.

Подставляя в (12) $x = z - b$, получим кубическое уравнение относительно $z$, не содержащие $z^2$ (проверьте!). Более того, если $b$ и $c$ в уравнения (12) связаны соотношениям
$$b^2 = c,$$
то в уравнения относительно $z$ исчезнет и член с $z^1$. В результате уравне-
ние (12) примет вид
$$z^3 = b^3 - d.$$
Возвращаясь к $x$, получим
$$x = \sqrt[3]{b^3 - d} - b.$$ (13)

Проверим, в каком случае выполняется условие $b^2 = c$ для уравнения (11). Сравнивая его с (12), имеем:
$$b = p + 6\sqrt[3]{r},$$
$$c = p^2 + 3p\sqrt[3]{r} + 9\sqrt[3]{r^2} - 9q,$$
и условие $b^2 = c$ принимает вид:
$$3\sqrt[3]{r^2} + p\sqrt[3]{r} + q = 0.$$ (14)

Тепер насупает волнующий момент: ведь числа $p, q$ и $r$ известны для уравнения, корнями которых является рамануджановские тройки косинусов (см. формулы (5) и (6))!

Для первой тройки: $p = 1/2$, $q = -1/2$, $r = -1/8$; для второй тройки: $p = 0$, $q = -3/4$, $r = 1/8$. Подставляя эти значения в (14), получаем числовые равенства! Но в этом случае, согласно (13) (при $x = A$, $b = p + 6\sqrt[3]{r}$, $d = (p - 3\sqrt[3]{r})^3$),
$$A = \sqrt[3]{b^3 - d} - b.$$
В случае первой тройки $b = \frac{1}{2} - 3 = -\frac{5}{2}$, $d = \left(\frac{1}{2} + \frac{3}{2}\right)^3 = 8$, так что
$$A = \frac{-3\sqrt{189} + 5}{2} = \frac{5 - 3\sqrt{7}}{2}.$$
В случае второй тройки $b = 3$, $d = \left(-\frac{3}{2}\right)^3 = -\frac{27}{8}$ и
$$A = \sqrt[3]{27 + \frac{27}{8}} - 3 = \frac{3\sqrt[3]{9} - 6}{2}.$$

Не это как подкоренные выражения правых частей формул Рамануджана (2) и (3). Следовательно, доказательство завершено.

Упражение 2. Положив $\sqrt[3]{x} = u$, $\sqrt[3]{y} = v$, $\sqrt[3]{z} = w$, доказите, что условие (14) при $u, v, w$, не равных 0, эквивалентно условию
$$u^3 + v^3 + w^3 + \frac{(uv)^2}{w} + \frac{(uw)^2}{v} + \frac{(vw)^2}{u} + 3uvw = 0.$$ (15)

Из нашей доказательства следует, что условию (15) удовлетворяет кубическе корни рамануджановских
