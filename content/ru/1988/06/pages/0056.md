Рассмотрим сумму трех корней...

Поставим теперь задачу так. Дано уравнение
$$t^3 + pt^2 + qt + r = 0,$$
корнями которого являются числа $x, y, z$. Требуется найти сумму их кубических корней (куб этой суммы обозначим через $A$):
$$\sqrt[3]{x} + \sqrt[3]{y} + \sqrt[3]{z} = \sqrt[3]{A}.$$
(7)

Оказывается, сумму (7) легко искать вместе с другой суммой:
$$\sqrt[3]{xy} + \sqrt[3]{xz} + \sqrt[3]{yz} = \sqrt[3]{B}.$$
(8)

Возвода в куб обе части (7), а затем (8) и учитывая формулы Виета (4), получаем (проверьте это самостояльно):
$$A = -p + 3\sqrt[3]{AB} + 3\sqrt[3]{r},$$
$$B = q - 3\sqrt[3]{ABr} - 3\sqrt[3]{r^2},$$
(10)

Умножая (9) на $\sqrt[3]{r}$ и складывая с (10), выражаем $B$ через $A$:
$$B = q - (A + p)\sqrt[3]{r}.$$
(11)

Подставляя это в (9), получаем уравнение только относительно $A$:
$$A + p - 3\sqrt[3]{r} = 3\sqrt[3]{A(q - (A + p)\sqrt[3]{r})}.$$
(12)

Наконец, возвода обе части уравнения в куб, получаем следующее кубическое уравнение относительно $A$:
$$A^3 + 3(p + 6\sqrt[3]{r})A^2 + 3(p^2 + 3p\sqrt[3]{r} + 9\sqrt[3]{r^2} - 9q)A + (p - 3\sqrt[3]{r})^3 = 0.$$ (11)

Упрощение кубического уравнения

Пусть дано кубическое уравнение
$$x^3 + 3bx^2 + 3cx + d = 0.$$ (12)

Покажем, как — в некоторых случаях особенно успешно — оно может быть упрощено.

Подставляя в (12) $x = z - b$, получим кубическое уравнение относительно $z$, не содержащие $z^2$ (проверьте!). Более того, если $b$ и $c$ в уравнения (12) связаны соотношениям
$$b^2 = c,$$
то в уравнения относительно $z$ исчезнет и член с $z^1$. В результате уравне-
ние (12) примет вид
$$z^3 = b^3 - d.$$
Возвращаясь к $x$, получим
$$x = \sqrt[3]{b^3 - d} - b.$$ (13)

Проверим, в каком случае выполняется условие $b^2 = c$ для уравнения (11). Сравнивая его с (12), имеем:
$$b = p + 6\sqrt[3]{r},$$
$$c = p^2 + 3p\sqrt[3]{r} + 9\sqrt[3]{r^2} - 9q,$$
и условие $b^2 = c$ принимает вид:
$$3\sqrt[3]{r^2} + p\sqrt[3]{r} + q = 0.$$ (14)

Тепер насупает волнующий момент: ведь числа $p, q$ и $r$ известны для уравнения, корнями которых является рамануджановские тройки косинусов (см. формулы (5) и (6))!

Для первой тройки: $p = 1/2$, $q = -1/2$, $r = -1/8$; для второй тройки: $p = 0$, $q = -3/4$, $r = 1/8$. Подставляя эти значения в (14), получаем числовые равенства! Но в этом случае, согласно (13) (при $x = A$, $b = p + 6\sqrt[3]{r}$, $d = (p - 3\sqrt[3]{r})^3$),
$$A = \sqrt[3]{b^3 - d} - b.$$
В случае первой тройки $b = \frac{1}{2} - 3 = -\frac{5}{2}$, $d = \left(\frac{1}{2} + \frac{3}{2}\right)^3 = 8$, так что
$$A = \frac{-3\sqrt{189} + 5}{2} = \frac{5 - 3\sqrt{7}}{2}.$$
В случае второй тройки $b = 3$, $d = \left(-\frac{3}{2}\right)^3 = -\frac{27}{8}$ и
$$A = \sqrt[3]{27 + \frac{27}{8}} - 3 = \frac{3\sqrt[3]{9} - 6}{2}.$$

Не это как подкоренные выражения правых частей формул Рамануджана (2) и (3). Следовательно, доказательство завершено.

Упражение 2. Положив $\sqrt[3]{x} = u$, $\sqrt[3]{y} = v$, $\sqrt[3]{z} = w$, доказите, что условие (14) при $u, v, w$, не равных 0, эквивалентно условию
$$u^3 + v^3 + w^3 + \frac{(uv)^2}{w} + \frac{(uw)^2}{v} + \frac{(vw)^2}{u} + 3uvw = 0.$$ (15)

Из нашей доказательства следует, что условию (15) удовлетворяет кубическе корни рамануджановских
