М606. Функция $f$ такова, что для всех действительных $x$ $f(x+1)+f(x-1)=\sqrt{2}f(x)$. Докажите, что $f$ — перiodическая функция.

М607. а) Разрежьте квадрат на равноведренные трапеци. б) Разрежьте равноведренный прямогольный треугольник на равноведренные трапеци. в) Докажите, что любой многоугольник можно разрезать на равноведренные трапеци.

Рис. 2. Рис. 3.

$n(n+1)+1$ неодвижных точек. Значит, в $F$ точек не меньше $n(n+1)+1$. Ровно столько неодвижных точек получится, если, например, снова взять $2n+1$ точек на прямой с целыми координатами $-n$, $-(n-1)$, ..., $-1$, 0, 1, 2, ..., $n-1$, $n$. При всевозможных способах расстановки $n$ «минусов» перед некоторыми из них максимальное значение суммы этих чисел равно $2 \cdot (1+2+\dots+n)=n(n+1)$, минимальное значение равно $-n(n+1)$, причем сумма может принимать любое четное значение между числами $-n(n+1)$ и $n(n+1)$ — всего $n(n+1)+1$ значений.

◆
По условияю для любого действительного $x$ справедливый равенства
$$f(x+2)+f(x)=\sqrt{2}f(x+1)=\sqrt{2}(\sqrt{2}f(x)-f(x-1))=
=2f(x)-\sqrt{2}f(x-1),$$
то есть
$$f(x+2)=f(x)-\sqrt{2}f(x-1).$$
Позному
$$f(x+4)=f(x+2)-\sqrt{2}f(x+1)=
=f(x)-\sqrt{2}(f(x-1)+f(x+1))=-f(x).$$
Следовательно,
$$f(x+8)=-f(x+4)=f(x)$$
для любого $x \in \mathbb{R}$, так что $f$ — периодическая функция, период которого равен 8.
Заметим, что функция, удовлетворяющие исходному уравнению, существует на пример, $f(x)=\sin \frac{\pi x}{4}$.

Заметим, что правильный треугольник легко разбит на равноведренные трапеци (рис. 1); поэтому достаточно довести разбиение до правильного треугольника.
Теперь можно предложить следующей нашей задачи:
a) Искомые разбиения могут быть, например, такими, как на рисунках 2, 3.
b) Разноведренный прямогольный треугольник может быть разрезан, например, так, как показано на рисунках 4 и 5. Каждое из этих разбиений дает новые способы разбиения квадрата.
Другие способы разрезания этих фигур получаются из пункта в).
b) Очевидно, какый многоугольник разбиется на выпуклые многоугольники, а какый выпуклый многоугольник разрезается на треугольники диагоналями, выходящими из любой вершины. Всякий же треугольник может быть разбит на два прямогольных треугольника высотой, опущенной на одну из сторон; наконец, какый прямогольный треугольник можно разрезать на два равноведренных, соединенных гипотенузы с вершиной прямого угла.
Позному достаточно доказать утверждение для произвольного равноведренного треугольника.
Будем для краткости называть равноведренный треугольник с углом $\alpha$ при основании «$\alpha$-треугольником».
Рассмотрим три случая.
1°. $30^\circ \leq \alpha < 60^\circ$. Нужное разрезание представлено на рисунке 6.
2°. $0 < \alpha < 30^\circ$. Как видно из рисунка 7, если можно разрезать $2\alpha$-треугольник, то можно разрезать и $\alpha$-треугольник. Отсюда и из 1° последовательно получаем разрезаемые равноведренных треугольников с углами при основании
$15^\circ \leq \alpha < 30^\circ$, $7,5^\circ \leq \alpha < 15^\circ$, $3,75^\circ \leq \alpha < 7,5^\circ$...
