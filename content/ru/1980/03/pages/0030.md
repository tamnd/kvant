Решения задач
M557—M561; Ф568—Ф572

М557. Дано n попарно взамимо простых чисел, больших 1 и меньших (2n—1)². Доказите, что среди их обязательно встретиется простое число.

Утверждение задачи доказем метод «от противного». Допустим, что все данные числа $a_1, a_2, \dots, a_n$ — составные. Сопоставим каждому из них его минимальный простой делитель: $a_i \rightarrow q_i$. Пусть $q = \max_{1 \leq i \leq n} \{q_i\}$. тогда $q \geq p_n$, где $p_n$ — n-e простое число (поскольку числа $a_1, \dots, a_n$ попарно взамимо просты).

Индикцией по $k$ легко доказывается неравенство $p_k \geq 2k - 1$. (Действительно, оно верно для $p_2 = 3$. Далее $p_{k+1} \geq p_k + 2$ при $k \geq 2$.) Тем самым $q \geq 2n - 1$. Следовательно, для того $a_j$, для которого $q_j = q$,

$$a_j \geq q_j^2 \geq (2n-1)^2$$

— противоречие. Значит, среди данных чисел обязательно встретиется простое.

M558. В круге расположено $k > 1$ черных секторов, угод какдого из которых меньше $180^\circ / (k^2 - k + 1)$. Доказите, что круг можно повернуть вокруг центра O так, что все черные секторы перейдет в белую часть круга.

Рис. 1.

Пусть вместе сложены два круга, на одном из которых отмечено r черных секторов с центральными углами $a_1, a_2, \dots, a_r$, на другом — s синих с углами $\beta_1, \beta_2, \dots, \beta_s$ (рис. 1). Попробуем найти достоинные условия, при которых круг с синими секторами можно повернуть на такой угол $\varphi$ ($0 < \varphi < 2\pi$), чтобы ни один из синих секторов не пересекался с черным.

Углы поворота $\varphi$ удобно отмечать на специальной окружности $c$ длины $2\pi$ с данной на ней точкой 0 (нулем). «Повернем» задачу иначе. Отметим на $c$ все запретные углы $\varphi$ — такие, при повороте на которые какой-то синий радиус совпадает с каким-то черным. Каждая пара (черный сектор с углом $a_i$, синий сектор с углом $\beta_j$) дает интервал запретных $\varphi$ длиной $a_i + \beta_j$. Поэтому, если какдое $a_i < \pi/k$, в частности, если какдое $a_i < \pi/k^2$. *) Суммирование $\sum_{i,j} \text{ произвольных } i = 1, 2, \dots, r, j = 1, 2, \dots, s$.
