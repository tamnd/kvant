М557. Дано n попарно взамимо простых чисел, больших 1 и меньших (2n—1)². Доказите, что среди их обязательно встретиется простое число.

Утверждение задачи доказем метод «от противного». Допустим, что все данные числа $a_1, a_2, \dots, a_n$ — составные. Сопоставим каждому из них его минимальный простой делитель: $a_i \rightarrow q_i$. Пусть $q = \max_{1 \leq i \leq n} \{q_i\}$. тогда $q \geq p_n$, где $p_n$ — n-e простое число (поскольку числа $a_1, \dots, a_n$ попарно взамимо просты).

Индикцией по $k$ легко доказывается неравенство $p_k \geq 2k - 1$. (Действительно, оно верно для $p_2 = 3$. Далее $p_{k+1} \geq p_k + 2$ при $k \geq 2$.) Тем самым $q \geq 2n - 1$. Следовательно, для того $a_j$, для которого $q_j = q$,

$$a_j \geq q_j^2 \geq (2n-1)^2$$

— противоречие. Значит, среди данных чисел обязательно встретиется простое.

Пусть для неокоторого $k$ такое красное множество $\Pi_0$ существует. Тогда $\Pi_0$ и его образы $\Pi_m$ ($m=1, 2, ..., k^2-k$) при поворотах на углы $m\gamma, \gamma=\pi/(k^2-k+1)$, обладают такимми свойствами:

1°. Для любых $i \neq j$ пересечение $\Pi_i \cap \Pi_j$ состоит из одной точки.

2°. Любые две из точки множества $\Pi = \bigcup_m \Pi_m$ (вершин правильного ($k^2-k+1$)-угольника) принадлежатровно одному из $\Pi_m$.

3°. Существуют четыре точки множества $\Pi$, не содержащиеся в одном $\Pi_i$.

Множество $\Pi$ с такой системой подмножества $\Pi_m \subset \Pi$ называется конечной проективной плоскостью*). Известно, что конечные проективные плоскости существуют для $k=p^r+1$, где $p$ — простое, $r$ — натуральное числа (например, $k=3, 4, 5, 6, 8, 9$) и не существует, если $k=7, 15$; понятно; теперь, что в последнем случае не может существовать и опровергающего примера в задаче М558 (так что, например, для семи секторов с углами $\pi/43$ ее утверждение верно). Но уже для $k=10$ вопрос пока не удается решить даже с помощью ЭВМ.

Отметим, что конечная проективная плоскость не обязательна и такую «циклическую» номерацию точек, при которой прямые $\Pi_m$ получаются друг из друга с двумя номерами — это дополнительное требование, возможно, облегчит доказательство отсутствия таких «циклических плоскостей» для неокоторых $k$. (Заметим, что все проективные плоскости над конечным полем из $p^r$ элементов имеют такие циклическую номерацию; см. об этом в главе «Разностные множества» книги М. Холла.)

М559. Докажите, что если $x, y, z$ — длины сторона треугольника, то

$$\left| \frac{x}{y} + \frac{y}{z} + \frac{z}{x} \right| - \frac{y}{x} - \frac{z}{y} - \frac{x}{z} < 1.$$

Левую часть удобно разложить на множители:

$$B = \left| \frac{x}{y} + \frac{y}{z} + \frac{z}{x} \right| = \frac{\left| z \left( x^2 - y^2 \right) + x \left( y^2 - z^2 \right) \right|}{xyz} = \frac{\left| (y-z) \left( z-x \right) \left( x-y \right) \right|}{xyz}.$$

$B < 1$, поскольку $|y-z| < x$, $|z-x| < y$ и $|x-y| < z$.

Уменьшить оценку 1 нельзя: например, при $x = \varepsilon$, $y = 1 + \varepsilon^2$, $z = 1 + \varepsilon$ ($\varepsilon$ — малое положительное число) $B$ будет больше $(1-\varepsilon)^3$.

(3)

Если образовательия в результате реакции нейтрон летит назад от литевой мишени, то закон сохранения импульса (2) можно записать так:

$$p_p = p_{\text{Be}} - p_n (p = |\vec{p}|),$$

или

$$\sqrt{2mE_p} = \sqrt{2ME_{\text{Be}}} - \sqrt{2mE_n}.$$

(4)

Из равенства (4) найдем

$$E_{\text{Be}} = \frac{m}{M} (E_p + E_n + 2\sqrt{E_p E_n})$$

и подставим это значение в (3). В результате получим

$$E_p = E_n + \frac{m}{M} (E_p + E_n + 2\sqrt{E_p E_n}) + \frac{M}{m+M} E_0.$$

Из последнего равенства видно, что $E_p$ минимально при $E_n = 0$. При этом

$$E_p = \frac{M^2}{M^2 - m^2} E_0 \approx 1,92 \text{ (МэВ)}.$$

Таким образом, при $E_p \approx 1,92 \text{ МэВ}$ образующейся в реакции нейтрон поконтся. При $E_p > 1,92 \text{ МэВ}$ нейтрон может лететь назад от литевой мишени.
