$$\sum_{k=1}^{5} kx_k = a, \quad \sum_{k=1}^{5} k^3 x_k = a^2, \quad \sum_{k=1}^{5} k^5 x_k = a^3.$$

Поскольку числа $x_1, \dots, x_5$ неотрицательны, отлично от нуля может быть не более чем одно из них; при этом коэффициент при нем должен обращаться в нуль. Если все $x_k$ равны нулю, соответствие $\sum_{k=1}^{5} kx_k = a$ дает $a = 0$. Если же одно из $x_k$ отлично от нуля, из (1) получаем еще пять значений для $a: 1, 4, 9, 16, 25$. Все эти значения действительно годятся: для каждого из них соответствие $\sum_{k=1}^{5} kx_k = a$ позволяет найти соответствующее решение: $(1; 0; 0; 0; 0); (0; 2; 0; 0; 0); (0; 0; 3; 0; 0); (0; 0; 0; 0; 4; 0); (0; 0; 0; 0; 5)$; тривальная проверка показывает, что эти решения удовлетворяют и остальные соответствиям.

М597. Положим
$$x_n = 1 + \frac{1}{2} + \dots + \frac{1}{n}.$$
a) Доказите существование предела
$$\gamma = \lim_{n \to \infty} (x_n - \ln n).$$
b) Доказите, что для любых $n, m \in N$
$$\gamma < x_n + x_m - x_{nm} \leq 1.$$
c) Найдите $\gamma$ с точностью до 0,1.

a) Из теоремы Вейерштрасса («Алгебра и начала анализа 9», п. 32) легко выводится легко: если $(a_n)$ и $(\beta_n)$ — возрастющая и убивающая последовательности, $a_n < \beta_n$ для всех $n$ и $\lim_{n \to \infty} (\beta_n - a_n) = 0$, то последовательности $(a_n)$ и $(\beta_n)$ имеют общий предел $c = \lim_{n \to \infty} a_n = \lim_{n \to \infty} \beta_n$ и $a_n < c < \beta_n$ при всех $n$.

Рассмотрим для данной последовательности $(x_n)$ две последовательности:
$$\gamma_n = x_n - \ln (n + 1), \quad \Gamma_n = x_n - \ln n.$$
Легко видеть, что они удовлетворяют условиям леммы
$$(\gamma_n < \Gamma_n; \lim_{n \to \infty} (\Gamma_n - \gamma_n) = \lim_{n \to \infty} \ln \left( 1 + \frac{1}{n} \right) = 0;$$
$$\gamma_n - \gamma_n^{-1} = \int_{n-1}^{n} \left( \frac{1}{n} - \frac{1}{x+1} \right) dx > 0,$$
поскольку $\frac{1}{n} - \frac{1}{x+1} > 0$ при $x \in [n-1; n]$; аналогично $\Gamma_n - \Gamma_{n-1} < 0$. Поэтому последовательности $(\gamma_n)$ и $(\Gamma_n)$ имеют общий предел $\gamma = \lim_{n \to \infty} \gamma_n = \lim_{n \to \infty} \gamma_n < \gamma < \Gamma_n$ при всех $n$.

Итак, предел $\gamma = \lim_{n \to \infty} \Gamma_n$ существует. (Впервые это было указано Л. Эйлером. Число $\gamma$ называется постоянной Эйлера.)
b) Легко видеть, что $x_n + x_m - x_{nm} = (x_n + x_m - x_n) - (x_{2n} - x_n) - (x_{3n} - x_{2n}) - \dots - (x_{nm} - x_{n(m-1)}) \leq x_m - n \cdot \frac{1}{2n} - n \cdot \frac{1}{3n} - \dots - n \cdot \frac{1}{mn} = 1$.

С другой стороны, $\Gamma_{nm} \leq \Gamma_n$, то есть
$$x_{nm} - \ln (mn) \leq x_n - \ln n, \quad x_n - x_{nm} - \ln n + \ln (mn) \geq 0.$$

Но $\Gamma_m > \gamma$, то есть
$$x_m - \ln m > \gamma.$$

Складывая неравенства (*) и (**), получаем
$$x_n - x_{nm} + x_m > \gamma,$$
что и требовалось доказать.

b) Чтобы вычислить $\gamma$ с точностью до 0,1, воспользуемся результатами решения задачи.

Так как $\gamma_n < \gamma < \Gamma_n$, то, взяв $n = 100$ членов последовательности, получим $0,57 < \gamma < 0,58$, поэтому $\gamma \approx 0,5$.

Приближенное значение числа $\gamma$ известно: $\gamma = 0,577$...
