⟦folio 33⟧

Любое натуральное число $n$ сумма
$$|\cos x| + |\cos 2x| + \dots + |\cos 2^n x|$$
б) не меньше $\frac{n}{4}$;
в) не меньше $\frac{n}{2}$.

$$y(t) = t + (1 - \sqrt{2} t) (1 + \sqrt{2} t) \geq t + (1 - \sqrt{2} t) = 1 - t(\sqrt{2} - 1) \geq 1 - \frac{1}{\sqrt{2}} (\sqrt{2} - 1) = \frac{1}{2}.$$

Если же $\frac{1}{\sqrt{2}} < t \leq 1$, то $y(t) \geq t \geq \frac{1}{\sqrt{2}}$. Таким образом, $y(t) \geq \frac{1}{\sqrt{2}}$ для всех $t \in [0; 1]$. Но при $t = \frac{1}{\sqrt{2}}$ (то есть $x = \frac{\pi}{4}$) $y(t) = \frac{1}{\sqrt{2}}$. Значит, наименьшее значение выражения $|\cos x| + |\cos 2x|$ равно $\frac{1}{\sqrt{2}}$.

К тому же результату можно было приditи, заметив, что график функции $y(t)$ на отрезке [0; 1] состоит из двух кусков парабол:

$$y(t) = \begin{cases} -2t^2 + t + 1 & \text{при } t \in \left[0; \frac{1}{\sqrt{2}}\right], \\ 2t^2 + t - 1 & \text{при } t \in \left[\frac{1}{\sqrt{2}}; 1\right], \end{cases}$$

а затем аккуратно исследовав на минимум каждой из кусков (см. рисунок).

Аналогично можно доказать и более простое неравенство
$$2|\cos x| + |\cos 2x| \geq 1$$
и даже обединить его с неравенством
$$|\cos x| + |\cos 2x| \geq \frac{1}{\sqrt{2}}$$

в одной:

$$a|\cos x| + |\cos 2x| \geq \min\{1, \frac{a}{\sqrt{2}}\},$$

справедливо для всех действительных чисел $a \geq 0$ и $x$ (убедитесь в этом самостояльно).

б) Обозначим сумму
$$|\cos x| + |\cos 2x| + |\cos 4x| + \dots + |\cos 2^n x|$$

через $\sigma_n(x)$. Положим $f(x) = |\cos x| + |\cos 2x|$. По доказанному в пункте a) $f(x) \geq \frac{1}{\sqrt{2}}$, так что

$$\sigma_n(x) = f(x) + f(4x) + f(16x) + \dots + f(2^n \left[\frac{n-1}{2}\right] x) \geq \frac{1}{\sqrt{2}} + \dots + \frac{1}{\sqrt{2}} = \left(\left[\frac{n-1}{2}\right] + 1\right) \frac{1}{\sqrt{2}} \geq \frac{n}{2\sqrt{2}} > \frac{n}{4}.$$

в) Доказем вначале, что если $|\cos x| \leq \frac{1}{2}$, то $|\cos x| + |\cos 2x| \geq 1$. В самом деле, если $t = |\cos x| \leq \frac{1}{2}$, то $\cos 2x = 2t^2 - 1 \leq 2 \cdot \left(\frac{1}{2}\right)^2 - 1 < 0$. Следовательно,

$$|\cos x| + |\cos 2x| = t + 1 - 2t^2 = 1 + 2t \left(\frac{1}{2} - t\right) \geq 1.$$

Приступим к задаче в). Зафиксируем $x$ и $n$ и назовем целое число $k \in [0; n]$ «плохим», если $|\cos 2^k x| < \frac{1}{2}$, и «хорошим», если $|\cos 2^k x| \geq \frac{1}{2}$. Из доказанного выше следует, что за каждым «плохим» числом $k$ (кроме $k = n$) следует «хорошем» число $k + 1$, причем $|\cos 2^k x| + |\cos 2^{k+1} x| \geq 1$. $$1 \leq k_1 < k_2 < \dots < k_r \leq n (r - количество «плохих» чисел).$$
