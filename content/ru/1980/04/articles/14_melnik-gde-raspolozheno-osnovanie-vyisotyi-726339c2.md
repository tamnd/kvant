Где расположено основание высоты?

Решая stereometрические задачи, важно уметить правильно определить взаимное расположение элементов возникших в них фигур. Многие ошибки, допускаемые при решении этих задач, связаны с изобравлением высоты парамиды (или призмы). Неверно расположение основание высоты относительно основания парамиды (или призмы), поступающий вследствие этого неправильно определят угол наклона бокового ребра к плоскости основания, ошибается при построении линейного угла двумя направного угла и т. д.

Цель предлагаемых ниже задачи и примеров — научить вас решать stereometрические задачи, избегая подобных ошибок. Для этого в начале статьи мы предлагаем три задачи со списком возможных ответов, из которых нужно выбрать правильный. Разумеется, здесь нельзя ограничиться угадыванием правильного ответа: его нужно обосновать. Разобраться с этим задачими, вы легкоойте решения следующих за ними примеров, взятых из практики вступительных экзаменов.

Задача 1. Какая точка плоскости ABC является основанием высоты парамиды SABC, если:
a) боковые ребра конгрузить;
b) боковые ребра образуют равные углы с плоскостью основания;
b) боковые грани образуют с плоскостью основания конгрузные углы;
г) плоские углы при вершине S прямы;

д) две пары противоположных ребер взаимно перепределить;
e) боковые ребра конгрузить между собой и
  $ASB = ASC = 60^\circ, BSC = 90^\circ$;
ж) $ACB = 90^\circ, (AC) \perp (BS)$;
з) $\vec{SO} = \frac{1}{3}(\vec{SA} + \vec{SB} + \vec{SC})$?

Возможные ответы:
1) точка пересечения медиан треугольника ABC;
2) точка пересечения его высот;
3) центр окружности, описанной вокруг треугольника ABC;
4) центр окружности, описанной в треугольник ABC;
5) центр окружности, описанной в треугольник ABC, или одной из внешних *);
6) середина отрезка BC;
7) точка прямой BC.

Для решения задачи часто бывают существенно установить, принадлежит ли основание высоты парамиде или нахождение вне ее.

Задача 2. В парамиде SABC улы наклона боковых ребер к плоскости основания конгрузить между собой. При каком достающим условии основание высоты SO парамиде принадлежит треугольнику ABC?

Возможные ответы:
1) $\triangle ABC$ — равноведренный;
2) $\triangle ABC$ — равносторонний;
3) $\triangle ABC$ — прямойный или остроугольный;
4) $\triangle ABC$ — тупоугольный;
5) в каждом из этих случаях.

Задача 3. В основании парамиды SABCD лежит трапеция ABCD ([BC]||[AD], |BC|<|AD|). Боковые ребра парамиды конгрузить между собой. При какомdestающим условии основание высоты SO парамиде лежит вне трапеция ABCD?

Возможные ответы:
1) если $ABD \leq 90^\circ$;
2) если $ABD > 90^\circ$;
3) если $(BD, CA) \geq 90^\circ$;
4) если $(BA, CD) > 90^\circ$;
5) ни при каком.

*)Вневписанной окружности треугольника называется окружность, касающаяся одной из его сторон и продолженной двух других сторон.

Перейдем теперь к разбору двух примеров, характерных для вступительных экзаменов.

Пример 1 (КГУ, 1975). Боковые ребра треугольной парамиды имеют одинаковую длину $l$. Два плоских угла при вершине парамиды равны $\alpha$, а третий — $\beta$. Найти объем парамиды.

Решение. Пусть $SABC$ — данная парамида, $\hat{ASB} = \beta$, $\hat{ASC} = \hat{BSC} = \alpha$. Из условия задачи находится:

$(\triangle ASC \cong \triangle BSC) \Rightarrow$
$\Rightarrow ([AC] \cong [BC])$;

основание $O$ высоты $SO$ находится в центре окружности, описанной вокруг треугольника $ABC$ (задача 1). Возможны три случая (см. задачу 2):

a) $\hat{ACB} < 90^\circ$ — основание высоты расположено внутри $\triangle ABC$ (рис. 1);
b) $\hat{ACB} = 90^\circ$ — основание высоты

случит середина $[AB]$ (рис. 2);
в) $\hat{ACB} > 90^\circ$ — основание высоты лежит вне треугольника $ABC$ (рис. 3).
Обозначим через $D$ середину отрезка $AB$.

Случай a). Исходя из условия, находим

$$|AB| = 2l \sin \frac{\beta}{2}; \quad |SD| = l \cos \frac{\beta}{2};$$
$$|AC| = |BC| = 2l \sin \frac{\alpha}{2};$$
$$|CD| = \sqrt{4l^2 \sin^2 \frac{\alpha}{2} - l^2 \sin^2 \frac{\beta}{2}} = l \sqrt{1 - 2 \cos \alpha + \cos^2 \frac{\beta}{2}}.$$

Положим $|OD| = x$. Из треугольника $SOD$
$$|SO|^2 = l^2 \cos^2 \frac{\beta}{2} - x^2;$$

из треугольника $CSO$
$$|SO|^2 = l^2 - (|CD| - x)^2 = l^2 - l^2 + 2l^2 \cos \alpha - l^2 \cos^2 \frac{\beta}{2} - x^2 + 2xl \sqrt{1 - 2 \cos \alpha + \cos^2 \frac{\beta}{2}}.$$

Отсюда
$$l^2 \cos^2 \frac{\beta}{2} - x^2 = 2l^2 \cos \alpha - l^2 \cos^2 \frac{\beta}{2} - x^2 + 2xl \sqrt{1 - 2 \cos \alpha + \cos^2 \frac{\beta}{2}};$$
$$x = l \frac{\cos^2 \frac{\beta}{2} - \cos \alpha}{\sqrt{1 - 2 \cos \alpha + \cos^2 \frac{\beta}{2}}};$$
$$h = |SO| = \sqrt{l^2 \cos^2 \frac{\beta}{2} - l^2 \frac{(\cos^2 \beta/2 - \cos \alpha)^2}{1 - 2 \cos \alpha + \cos^2 \beta/2}} = l \frac{\sqrt{\cos^2 \beta/2 - \cos^2 \alpha}}{\sqrt{1 - 2 \cos \alpha + \cos^2 \beta/2}}.$$

Значит,
$$V = \frac{1}{3} Sh = \frac{1}{3} l^3 \sin \frac{\beta}{2} \sqrt{\cos^2 \frac{\beta}{2} - \cos^2 \alpha}.$$

Заметание. Поскольку $\hat{ASB} < \hat{ASC} + BSC$, выполняется неравенство $\beta < 2\alpha$ и подкренное выражение положительное. Впро-

Случай 6). Этот случай возможно тогда и только тогда, когда
$$\sin \frac{\beta}{2} = \sqrt{2} \sin \frac{\alpha}{2}.$$
(2)

Действительно, если $\hat{C} = 90^\circ$, $|CD| = |AD| = l \sin \frac{\beta}{2}$; $|CD| = |AC| \frac{\sqrt{2}}{2} = \sqrt{2} l \sin \frac{\alpha}{2}$ (рис. 2).

Отсюда $\sin \frac{\beta}{2} = \sqrt{2} \sin \frac{\alpha}{2}$. Наоборот, если $\sin \frac{\beta}{2} = \sqrt{2} \sin \frac{\alpha}{2}$, то
$$|CD| = l \sqrt{1 - 2 \cos \alpha + \cos^2 \frac{\beta}{2}} = l \sqrt{2 - 2 \cos \alpha - \sin^2 \frac{\beta}{2}} = \sqrt{2} l \sqrt{1 - \cos \alpha - \sin^2 \frac{\alpha}{2}} = \sqrt{2} l \sqrt{\sin^2 \frac{\alpha}{2}} = \sqrt{2} l \sin \frac{\alpha}{2}.$$

Поэтому $\cos \hat{ACD} = \frac{|CD|}{|AC|} = \frac{\sqrt{2}}{2}$. Отсюда $\hat{ACD} = 45^\circ$, $\hat{C} = 90^\circ$. Если $\sin \frac{\beta}{2} = \sqrt{2} \sin \frac{\alpha}{2}$, то $h = |SD| = l \cos \frac{\beta}{2}$ (рис. 2), $V = \frac{l^2}{3} \sin^2 \frac{\beta}{2} \times l \cos \frac{\beta}{2}$, $V = \frac{l^3}{6} \sin \beta \sin \frac{\beta}{2}$.

Случай в). Положим $x = |OD|$ (рис. 3). Как в случае a), находим:
$$x = l \frac{\cos \alpha - \cos^2 \frac{\beta}{2}}{\sqrt{1 - 2 \cos \alpha + \cos^2 \frac{\beta}{2}}};$$
$$h = |SO| = l \frac{\sqrt{\cos^2 \frac{\beta}{2} - \cos^2 \alpha}}{\sqrt{1 - 2 \cos \alpha - \cos^2 \frac{\beta}{2}}};$$
$$V = \frac{1}{3} l^3 \sin \frac{\beta}{2} \sqrt{\cos^2 \frac{\beta}{2} - \cos^2 \alpha}.$$

Мы видим, что ответы в случае a) и b) совпадают, хотя получены они не одинаково. Более того, в случае 6) этот ответ тоже годится, что не трудно проверить (избавляясь от α в (1) с помощью соответствия (2), получаем (3)).

Ответ:
$$V = \frac{l^3}{3} \sin \frac{\beta}{2} \sqrt{\cos^2 \frac{\beta}{2} - \cos^2 \alpha}.$$

Подчеркием, что решение, при котором разобран только случай a), не может считаться полным.

Пример 2. Основанием параметры SABC служит треугольник, у которого $|AB| = |BC| = 20$ см, $|AC| = 32$ см; улымежду плоскостью основания и каждой из боковых граней равны 45°. Найдите объем параметры.

Решение. Основанием высоты параметры служит точка, равно ленghена от прямых AB, AC, BC, то есть центр окружности, вписанной в $\triangle ABC$, или одной из внешних (задача 16). Поэтому условию задачи удовлетворяют четыре параметры, основаниями высот которых служат точки $O_1$, $O_2$, $O_3$, $O_4$ (рис. 4). Для вычисления объема этих параметров достаточно определить высоты $SO_1$, $SO_2$, $SO_3$, $SO_4$, так как площадь основания равна $S = S_{\triangle ABC} = 192$ см². Поскольку боковые грани наклонены к плоскости основания под углом 45°, высота параметра равна радиусу окружности, вписанной в $\triangle ABC$, или одной из внешних, центр которой — основание высоты параметры.
