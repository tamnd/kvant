3. Ответ. Функция $f(x) = x^3 - 2x \cdot |x| - 2$ ($x \in [0; 3]$) имеет одну точку минимума $x = \frac{2}{3}$, ее наиболее значение на [0; 3] равно 21 ($\max f(x) = f(3) = 21$). Решение. По условиям областю определения исследуемой функции $f$ является отрезок [0; 3]. По определению модели

$$f(x) = \begin{cases} x^3 + 2x^2 - 4x, & \text{ если } 0 \leq x \leq 2, \\ x^3 - 2x^2 + 4x, & \text{ если } 2 < x \leq 3. \end{cases}$$

Значит,

$$f'(x) = \begin{cases} 3x^2 + 4x - 4, & \text{ если } 0 < x < 2, \\ 3x^2 - 4x + 4, & \text{ если } 2 < x < 3. \end{cases}$$

На ]0; 2[ функция $f$ имеет одну критическую точку $x = \frac{2}{3}$, причем $f'(x) < 0$ на ]0; $\frac{2}{3}$ [, $f'(\frac{2}{3}) = 0$ и $f'(x) > 0$ на ]2; $\frac{2}{3}$ [. Значит, $x = \frac{2}{3}$ — точка минимума.

На ]2; 3[ $f'(x) > 0$. Значит, на ]2; 3[ функция $f$ не имеет критических точок.

Рассмотрим теперь точку $x = 2$. Эта точка не может быть точкой минимума, так как в любой окрестности точки 2 функция $f$ принадлежит значению, меньше $f(2)$; действительно, при $0 \leq x \leq 2$ функция $f$ совпадает с многочленом $f_1(x) = x^3 + 2x^2 - 4x$, который на ]2; $+\infty$ [ возвращает.
