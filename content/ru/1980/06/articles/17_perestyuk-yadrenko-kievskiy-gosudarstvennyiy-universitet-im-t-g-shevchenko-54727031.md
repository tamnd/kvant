⟦folio 43⟧

Киевский государственный университет им. Т. Г. Шевченko

Matematika

Писменный экзамен

Вариант 1
(механико-математический факультет)

1. Решить систему уравнений
$$\begin{cases} \log_4 x + \log_4 y = 1 + \log_4 9, \\ x + y = 20. \end{cases}$$

2. Решить неравенство
$$\sqrt{9^x + 3^x} \geq 9 - 3^x.$$

3. Вокруг шара объемом $V$ описан конус таким образом, что его объем — наименьший из всех возможных. Найти объем конуса.

4. При каком значении $a$ пряма $y = a$ делит площадь фигуры, ограниченной линиями $y = 0$ и $y = 2 + x - x^2$, пополам?

5. Решить уравнение
$$\frac{2 \mathrm{tg} \frac{x}{2}}{1 + \mathrm{tg}^2 \frac{x}{2}} = y^2 - 4y + 5.$$

Вариант 2
(факультет кибернетики)

1. Пусть
$$\max (A, B) = \begin{cases} A, если A \geqslant B \\ B, если B \geqslant A. \end{cases}$$

Вычислить площадь плоской фигуры, ограниченной частими линей max $(x, y) = 1$ и $x^2 + y^2 = 1$, лежащих в первом квадрате.

2. Зная радиус $r$ основания конуса, определять радиус секения, которое параллельно основанию и делит объем конуса пополам.

3. Решить уравнение
$$2 \sin^2 x - 5 \sin x \cdot \cos x - 8 \cos^2 x = -2.$$

4. При каких значениях $a$ уравнение $ax^2 = \ln x$ имеет один корень?

Вариант 3
(физический и радиофизический факультеты)

1. Точка движется прямолинейно по закону
$$s(t) = -\frac{1}{6} t^3 + 3t^2 - 5$$
(время измеряется в секундах,ройденный путь в метрах). Определить:
1) момент времени, когда ускорение точки равно нулю;
2) с какой скоростью движется в этот момент точка?
2. В конус, высота которого равна радиусе основания, вписан шар. Найти отношение объема шара к объему конуса.

3. Решить неравенство
$$x + 2 < \sqrt{x + 14}.$$

4. Решить систему уравнений
$$\begin{cases} \log_3 (\log_2 x) + \log_{\frac{1}{3}} (\log_{\frac{1}{2}} y) = 1, \\ xy^2 = 4. \end{cases}$$

5. Найти наиболее и наиболее значения функции
$$y = \sin \left( x + \frac{\pi}{8} \right) \cdot \cos \left( x - \frac{\pi}{24} \right).$$

Задачи устного экзамена

1. Решить уравнения
a) $\log_3 (\cos x) + \log_{\frac{1}{3}} (-\sin x) = 0$;
b) $tg |x| = |tg x|$;
b) $\pi \sin x = \left| x - \frac{\pi}{4} \right| - \left| x - \frac{3\pi}{4} \right|$.

2. Решить неравенство
$$|x + 2|^{\frac{1}{x^2 - x - 6}} \geq |x + 2|^{\frac{2}{x^3}}.$$

3. Найти промежутки многоотности и точки экстремумов функции
$$y = \left| |x^2 - 1| - 2 \right|.$$

Построить график этой функции.

4. Построить график функции
$$y = \begin{cases} l^x - 1, \text{ если } x < 0, \\ \sqrt{4x - x^2}, \text{ если } x \geqslant 0. \end{cases}$$

5. При каких $a$ функция
$$f(x) = x^3 + 3(a - 7)x^2 + 3(a^2 - 9)x + 1$$ имеет положительное точку максимума?

6. При каких $m$ функция
$$f(x) = 2e^x - me^{-x} + (1 + 2m)x - 3$$

monotonно возрастает на все оси?

7. При каких $a$ уравнение
$$3x \lg x = 1 + a \lg x$$ имеет: a) одно решение; 6) два решения?

8. Сколько корней в зависимости от параметра $a$ имеет уравнение
$$x^2 \cdot e^{2|x|} = 4a.$$

9. Сколько корней, принадлежащих промежутку $[-\pi; \pi]$, имеет уравнение
$$3 \sin x + \sin 3x = 2a$$

в зависимости от параметра $a$?

10. При каком $a$ сумма кубов корней уравнения
$$6x^2 + 6(a - 1)x - 5a + 2a^2 = 0$$

набольшая?

11. На плоскости изображить множество точки
$$\{(x; y) | x^2 + y^2 - 2x - 2y + 1 = 0 \}.$$

Написать уравнение образа этого множества при параллельном пересечке $\vec{p} = (0; -1)$.

12. Найти значения $a$, при которых множество уравнений
$$\{(x; y) | x^2 + y^2 + 2x \leqslant 1 \} \cap \{(x; y) | x - y + a \geqslant 0\}$$
