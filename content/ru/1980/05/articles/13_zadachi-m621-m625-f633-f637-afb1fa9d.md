M567. Натуральные числа $p$ и $q$ взаимно просты. Отрезок $[0; 1]$ разбит на $p+q$ одинаковых отрезков (рис. 1). Доказите, что в каждом из этих отрезков, кроме двух крайних, лежитровно одно из $p+q-2$ чисел

$$\frac{1}{p}, \frac{2}{p}, \dots, \frac{p-1}{p},$$

$$\frac{1}{q}, \frac{2}{q}, \dots, \frac{q-1}{q}.$$

Приведем два решения.

Первое решение. Из условия следует, что каждое из чисел $p$ и $q$ взаимно просто с числом $n=p+q$, поэтому никакие две из точки $i/p, j/q, k/n$ (отличные от 0 и 1) не совпадают. Поскольку $1/p > 1/n$ и $1/q > 1/n$, любые две из точки $i/p$ лежат в разных отрезках $\left[\frac{k}{n}; \frac{k+1}{n}\right]$ и любые две из точки $j/q$ — тоже. Нужно лишь доказать, что какие-то две точки $i/p$ и $j/q$ не могут попасть в один и тот же отрезок $\left[\frac{k}{n}; \frac{k+1}{n}\right]$ ($k=1, 2, \dots, n-2$). Но это сразу следует из того, что дробь $\frac{k}{n} = \frac{i+j}{p+q}$ лежит между $\frac{i}{p}$ и $\frac{j}{q}$ (см., на рис. 1).

$p=8, q=5, n=8+5=13$

пример, рисунок 2: угловой коэффициент диагонали параллелограмма заклочен между угловыми коэффициентами его стороны*).

Второе решение. Нарисуем на клетчатой бумаге прямогольник размерми $p \times q$ клеток и проведем в нем диагональ $OE$ (рис. 3) — она и будет играть роль отрезка $[0; 1]$ нашей задачи. Линии одного направления (синние) делят ее на $p$ равных частей, другого (красные) — на $q$ равных частей. Проведем через вершины клеток еще ряд параллельных прямых — под углом $45^\circ$ к линяям сетки (на рисунке это черные прямые $x+y=k$, где $k=1, 2, \dots, p+q-1$). Они делят $OE$ на $n=p+q$ одинаковых отрезков. Утверждение задачи становится почти очевидным. В самом деле, на $OE$ между любыми двумя синкрасьми точкиками обязательно лежит черная точка: ведь, пересекая какую-то клетку, $OE$ обязается пересекает и ее черную диагональ. (Можно вместо этого сказаить и так: между любыми точками пересечения $OE$ с соседними черными прямыми лежит точка пересечения с синей или красной линей.)

В этом решении взаимная простота чисел $p$ и $q$ гарантирует, что $OE$ не проходит через узлы сетки, отличные от $O$ и $E$ (глядя на наш маленький рисунок, в этом можно усомниться).

Задча M567 допускает заменательное обобщение. Пусть α и β — любые положительные числа, связанные соотношением 1/α + 1/β = 1.

Отметим на числовой оси свободные числа вида iα и jβ (i ∈ Z, j ∈ Z). Тогда каждый отрезок [k; k+1] оси (k ∈ Z), ни в один из концов которого не попало отмещение число, содержитровно одно из отмещенных чисел iα, jβ.

Наша задача эквивалентна этому факту при разциональных α и β: нужно взять α = n/p, β = n/q (роль отрезка [0; 1] будет играть теперь отрезок [0; n]). Этот же факт (для инрациональных α и β) упоминался недавно в решении задачи M538 («Квант», 1979, № 11), очень похожем на нашей второе решение M567.

Начнем с представления числа 1/5 и вообше 1/q. Числа 1/2, 1/4, 3/4 получить очень просто:

$$\frac{1}{2} = \frac{0+1}{2}, \frac{1}{4} = \frac{0+\frac{1}{2}}{2}, \frac{3}{4} = \frac{\frac{1}{2}+1}{2}.$$

Так же можно, оченьindo, получить любую двойную двойно-рациональную дробь, то есть дробь вида p/2^m, p<2^m (рис. 1).

Чтобы получить дробь 1/q, достаточно представить 1 в виде суммы q различных правильных двойно-рациональных дробей: их среднее арифметическое будет равно как раз 1/q. Докажем по индукции, что это возможно. В виде суммы двух таких дробей 1 представить можно (например, 1=3/4+1/4).

Из представления 1 в виде суммы n-1 различных двойно-рациональных дробей можно получить ее представление в виде суммы n таких дробей:

$$1 = a_1 + a_2 + \dots + a_{n-1} = \frac{1}{2} + \frac{a_1}{2} + \frac{a_2}{2} + \dots + \frac{a_{n-1}}{2}.$$

В частности, следует этому построению, получим

$$1 = \frac{3}{4} + \frac{1}{4} = \frac{1}{2} + \frac{3}{8} + \frac{1}{8} =$$
$$= \frac{1}{2} + \frac{1}{4} + \frac{3}{16} + \frac{1}{16} = \frac{1}{2} + \frac{1}{4} + \frac{1}{8} + \frac{3}{32} + \frac{1}{32},$$

что дает представление числа 1/5.

1. Докажем, что если натуральное число p можно представить в виде суммы n-1 различных правильных двойно-рациональных дробей:

$$p = a_1 + a_2 + \dots + a_{n-1} \quad (0 < a_{n-1} < \dots < a_2 < a_1 < 1),$$

то его можно представить и в виде суммы n таких дробей. Пусть 2^m — наиболее низким из значений слагаемых a_i. Заменив a_n-1 на сумму $\left(a_{n-1} - \frac{1}{2^m+2}\right) + \frac{1}{2^m+2}$, получим нужное представление. Итак, каждая из дробей $\frac{1}{q}, \frac{2}{q}, \dots, \frac{q-1}{q}$ может быть представлена в виде среднего арифметического различных правильных двойно-рациональных дробей, то и дроби $\frac{1}{q+1}, \frac{2}{q+1}, \dots, \frac{q-1}{q+1}$ могут быть представлены в аналогичном виде. Следовательно, точка C движется по окружности радиуса $l/2$ с центром в точке O. Скорость $v_c$ точки C направлена по касательной к траектории и в любой момент перпендикулярна OC.

Так как стержень нерастяжим, проекции скоростей точек C и В на направление стержня равны (рис. 2).

$$v \cos \alpha = v_c \cos \beta = v_c \cos \left( 2\alpha - \frac{\pi}{2} \right) = v_c \sin 2\alpha.$$

Позтому

$$v_c = \frac{v \cos \alpha}{\sin 2\alpha} = \frac{v}{2 \sin \alpha}.$$

Проекция ускорения $\vec{a}_c$ точки C на радиус OC = $l/2$ должна быть равна $\frac{v_c^2}{l/2} = \frac{v^2}{2l \sin^2 \alpha}$. Как направлен вектор $\vec{a}_c$? Заметим, что проекция скорости $\vec{v}_c$ точки C на горизонтальном ось равна $v_c \cos (\alpha - \beta) = v_c \cos \left( \frac{\pi}{2} - \alpha \right) = \frac{v}{2}$. Эта величина не зависит от α и, следовательно, постоянна. Это означает, что вектор $\vec{a}_c$ направлен вертикально.

Таким образом,

$$a_c \cos \left( \frac{\pi}{2} - a \right) = \frac{v^2}{2l \sin^2 \alpha},$$

откуда

$$a_c = \frac{v^2}{2l \sin^3 \alpha}.$$

После замыкния ключа K1 направление на конденсаторе становится равным Е. При этом заряд конденсатора равным

$$q_1 = C \varepsilon.$$

Такой заряд и проходит через галванометр при замыкнии ключа K1. Следовательно,

$$\alpha = kq_1 = kC \varepsilon,$$

где $k = \text{const}$ — коэффициент пропорциональности.

После замыкния ключа K2 направление на конденсаторе становится равным резисторю на резисторе, то есть $U = IR$, где I — ток, текущий через резistor. Так как резistor включен после давления с источником, $I = \varepsilon / (R + r)$. Следовательно, $U = \varepsilon R / (R + r)$. Заряд же конденсатора после замыкния ключа K2 становится равным

$$q_2 = CU = C \varepsilon \frac{R}{R + r}.$$

Следовательно, через галванометр после замыкния ключа K2 проходит заряд

$$q = q_1 - q_2 = C \varepsilon \frac{r}{R + r}$$
