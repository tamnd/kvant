1. Линейные дифференциальные
уравнения

Уравнение $y' = ky$ называется линей-
ным, поскольку неизвестная функция
$y$ и ее произведение $y'$ входят в него
linейный образом. Как известно из
учебника, любое решение этого урав-
нения записывается в виде

$$y = Ae^{kx},$$

(3)

где $A$ — произвольная постоянная.

Оказывается, если на координат-
ной плоскости изображать графики
этих решений при всехозможных
значениях $A$, то они покройот всю
плоскость, причем через каждую
точку плоскости пройдет в точности
один из графиков. Плоскость ока-
зывается как бы «сотканной» из гра-
фиков $y = Ae^{kx}$ (рис. 1).

Докажем это, для чего найдем
среди функций вида (3) все те, гра-
фики которых проходят через данную
точку $(x_0; y_0)$ координатной плоскости. Для определения постоянной $A$ получаем уравнение

$$Ae^{kx_0} = y_0,$$

котрое имеет единственное решение
$A = y_0e^{-kx_0}$. Следовательно, через нашу точку проходит один и только один из графиков (3) — это

$$y = \left(y_0e^{-kx_0}\right) \cdot e^{kx} = y_0e^{k(x-x_0)}.$$

(4)

Полученный нами факт часто
формулирует следующим образом:
дифференциальное уравнение $y' = ky$ имеет единственное решение, удовлетворяющее начальном у

Рис. 1.

условию $y(x_0) = y_0$; это решение
задается формулой (4).

Более общее линейное дифферен-
циальное уравнение записывается в виде

$$y' = ky + a,$$

(5)

где $a$ (как и $k$) — постоянная. Урав-
нение (5) легко совпадается к уже ис-
следованному уравнению (1): если
правую часть записывается в виде

$$ky + a = k\left(y + \frac{a}{k}\right)$$

(напомним, что мы считаем $k \neq 0$) и обозначить функцию $y + a/k$ через $z$, то

$$z' = \left(y + \frac{a}{k}\right)' = y' = ky + a = kz.$$

Таким образом, функция $z(x) = y(x) + a/k$ удовлетворяет уравне-
нию $z' = kz$, поэтому $z = Ae^{kx}$, то есть $y + a/k = Ae^{kx}$, откуда

$$y(x) = -\frac{a}{k} + Ae^{kx}.$$

Значение постоянной $A$ опять-tаки
однозначно определяется, если за-
дано начальное условие $y(x_0) = y_0$.

Вот, по существу, и все математическая теория линейных дифференциальных уравнений первого порядка, то есть уравнения, включая их только первою произвольную от неизвестной функции.
