Теперь «свернем» неравенство (5) и поставляется получить неравенство вида (1):

$$-\frac{\varepsilon}{2} < x - \frac{1}{7} < \frac{\varepsilon}{2},$$

Мы достаточно целли. Таким образом, при $\delta = \frac{\varepsilon}{2}$ из $0 < |x - \frac{1}{7}| < \delta$ вытекает (4). В данном примере неравенство (2) = (4) верно и при $x = a$; в качестве $\delta$ можно, очевидно, взять любое число из $] 0; \frac{\varepsilon}{2}]$.

Впрочем, второе замечание привильно и носит общий характер: если для неокоторого $\varepsilon_0 > 0$ годится неокоторое $\delta_0 > 0$, то есть из $0 < |x - a| < \delta_0$ (6)

вытекает

$$|f(x) - b| < \varepsilon_0,$$

то для этого $\varepsilon_0 > 0$ годится, разумеется, и любое $\delta \in ]0; \delta_0[$: если $0 < |x - a| < \delta$, то из $\delta < \delta_0$ следует (6), а значит, и (7).

Пример 2. Докажем, что $\lim_{x \to -2} \frac{5}{x} = -\frac{5}{2}$.

Неравенство (2) в данном случае имеет вид

$$\left| \frac{5}{x} - \left( -\frac{5}{2} \right) \right| < \varepsilon.$$

Пойдем опять по тому же пути. Неравенство (8) равносильно неравенству

$$\left| \frac{5}{x} + \frac{5}{2} \right| < \varepsilon,$$
$$-\varepsilon < \frac{5}{x} + \frac{5}{2} < \varepsilon,$$
$$-\frac{5}{2} - \varepsilon < \frac{5}{x} < -\frac{5}{2} + \varepsilon.$$

Чтобы достичь целли — «обнажить» $x$, нам надо почленно разделить 1 на каждую часть двойного неравенства (9); но делать это можно только в том случае, если все части неравенства имеют одинаковый знак, поскольку соответствующее свойство и словых неравенств гласит: если $a < b$ и числа $a, b$ имеют одинаковый знак (короче: $ab > 0$), то $\frac{1}{a} > \frac{1}{b}$ (доказите это утверждение!). $-\frac{5}{2} - \varepsilon < 0$. Поэтому нам надо, чтобы остальные две части неравенства (9) были отрицательными. Достаточно потребовать $-\frac{5}{2} + \varepsilon < 0$ или $\varepsilon < \frac{5}{2}$.

Итак, пусть сначала $\varepsilon < \frac{5}{2}$ (заметьте это место — мы к немного еще вернемся). Тогда все части неравенства (9) отрицательны. Поэтому

$$\frac{1}{-\frac{5}{2} - \varepsilon} > \frac{x}{5} > \frac{1}{-\frac{5}{2} + \varepsilon},$$
$$\frac{5}{-\frac{5}{2} - \varepsilon} > x > \frac{5}{-\frac{5}{2} + \varepsilon},$$
$$\frac{5}{-\frac{5}{2} + \varepsilon} < x < \frac{5}{-\frac{5}{2} - \varepsilon},$$
$$\frac{10}{-5 + 2\varepsilon} < x < \frac{10}{-5 - 2\varepsilon}.$$

$x$ «обнажили». Теперь нам надо получить из (10) неравенство вида (1):

$$|x - (-2)| < \delta,$$
$$-\delta < x - (-2) < \delta,$$
$$-2 - \delta < x < -2 + \delta.$$

Из (10):

$$-2 + \frac{10}{-5 + 2\varepsilon} + 2 < x < -2 +$$
$$+ \frac{10}{-5 - 2\varepsilon} + 2,$$
$$-2 - \frac{4\varepsilon}{5 - 2\varepsilon} < x < -2 + \frac{4\varepsilon}{5 + 2\varepsilon}.$$

Пока еще неравенство (12) не вплоне имеет вид (11). При $\varepsilon < \frac{5}{2}$
