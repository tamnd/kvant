Предел функции

Понятие «предел функции» является одним из важнейших в школьном курсе математики. Через него определяются «непрерывность» и «производная».

Основное определение (§ 38 пособия «Алгебра и начала анализа 9») формулируем двумя способами.

Сначала на «арифметическом» языке: число $b$ называется пределом функции $f$ при $x$, стремящемся к $a$, если для любого $\varepsilon > 0$ существует такое $\delta > 0$, что при всех $x$, удовлетворяющих двойному неравенству*)

$$0 < |x - a| < \delta,$$

выполняется неравенство

$$|f(x) - b| < \varepsilon.$$

Чтобы сформировать определение предела функции на «геометрическом» языке, введем термин, который нет в школьном пособии. Как известно, окрестность точки $a \in R$ называется интервал вида $]a - \delta; a + \delta[$, где $\delta$ — произвольное положительное число. Наозем проколотой окрестностью точки $a \in R$ ее окрестность, из которого выкинута («выколота») сама точка $a$, то есть «разорванное» множество вида $]a - \delta; a[U]a; a + \delta[$. Теперь определение предела функции может быть сформированно так: число $b$ называется пределом функции $f$ при $x$, стремящемся к $a$, если для любой

$$*) |x - a| > 0 \iff x \neq a.$$

окрестности $B$ точки $b$ найдется такая проколотая окрестность $A$ точки $a$, что $f(A) \subset B$ (рис. 1).

Таким образом, не требуется, чтобы неравенство (2) выполнялось и при $x = a$. Функция $f$ в точке $a$ может быть даже не определена — этоничут не влияет на ее предел при $x$, стремящемся к $a$. Например, функция $\frac{x^2 - 9}{x - 3}$ не определена при $x = +3$, но ее предел при $x \rightarrow +3$ существует.

Более общий пример: функция $\frac{\Delta f(x_0)}{\Delta x}$ всегда не определена при $\Delta x = 0$, но ее предел при $\Delta x \rightarrow 0$ «часто» существует (он называется произвольной функцией $f$ в точке $x_0$).

Впрочем, «очень часто» неравенство (2) выполняется и при $x = a$; если при этом $b = f(a)$, функция $f$ называется непрерывной в точке $a$.

Если утверждение вида

$$\lim_{x \rightarrow 1} f(x) = b$$

доказывает исход неопределенно из определения, надо для любого $\varepsilon > 0$ найти соответствующее $\delta > 0$ или, по крайней мере, доказать, что такое $\delta > 0$ существует.

Пример 1. Докажем, что

$$\lim_{x \rightarrow \frac{1}{7}} (3 - 2x) = \frac{19}{7}.$$

Для этих «действующих лиц» $(f(x) = 3 - 2x, a = \frac{1}{7}, b = \frac{19}{7})$ неравенство (2) принимает вид

$$|3 - 2x - \frac{19}{7}| < \varepsilon.$$

Чтобы найти нужное $\delta$, «раскроем» неравенство (4) и построаем

$$\left| -2x + \frac{2}{7} \right| < \varepsilon,$$
$$-\varepsilon < -2x + \frac{2}{7} < \varepsilon,$$
$$-\frac{2}{7} - \varepsilon < -2x < -\frac{2}{7} + \varepsilon,$$

Теперь «свернем» неравенство (5) и поставляется получить неравенство вида (1):

$$-\frac{\varepsilon}{2} < x - \frac{1}{7} < \frac{\varepsilon}{2},$$
$$|x - \frac{1}{7}| < \frac{\varepsilon}{2}.$$

Мы достаточно целли. Таким образом, при $\delta = \frac{\varepsilon}{2}$ из $0 < |x - \frac{1}{7}| < \delta$ вытекает (4). В данном примере неравенство (2) = (4) верно и при $x = a$; в качестве $\delta$ можно, очевидно, взять любое число из $] 0; \frac{\varepsilon}{2}]$.

Впрочем, второе замечание привильно и носит общий характер: если для неокоторого $\varepsilon_0 > 0$ годится неокоторое $\delta_0 > 0$, то есть из $0 < |x - a| < \delta_0$ (6)

вытекает

$$|f(x) - b| < \varepsilon_0,$$

то для этого $\varepsilon_0 > 0$ годится, разумеется, и любое $\delta \in ]0; \delta_0[$: если $0 < |x - a| < \delta$, то из $\delta < \delta_0$ следует (6), а значит, и (7).

Пример 2. Докажем, что $\lim_{x \to -2} \frac{5}{x} = -\frac{5}{2}$.

Неравенство (2) в данном случае имеет вид

$$\left| \frac{5}{x} - \left( -\frac{5}{2} \right) \right| < \varepsilon.$$

Пойдем опять по тому же пути. Неравенство (8) равносильно неравенству

$$\left| \frac{5}{x} + \frac{5}{2} \right| < \varepsilon,$$
$$-\varepsilon < \frac{5}{x} + \frac{5}{2} < \varepsilon,$$
$$-\frac{5}{2} - \varepsilon < \frac{5}{x} < -\frac{5}{2} + \varepsilon.$$

Чтобы достичь целли — «обнажить» $x$, нам надо почленно разделить 1 на каждую часть двойного неравенства (9); но делать это можно только в том случае, если все части неравенства имеют одинаковый знак, поскольку соответствующее свойство и словых неравенств гласит: если $a < b$ и числа $a, b$ имеют одинаковый знак (короче: $ab > 0$), то $\frac{1}{a} > \frac{1}{b}$ (доказите это утверждение!). $-\frac{5}{2} - \varepsilon < 0$. Поэтому нам надо, чтобы остальные две части неравенства (9) были отрицательными. Достаточно потребовать $-\frac{5}{2} + \varepsilon < 0$ или $\varepsilon < \frac{5}{2}$.

Итак, пусть сначала $\varepsilon < \frac{5}{2}$ (заметьте это место — мы к немного еще вернемся). Тогда все части неравенства (9) отрицательны. Поэтому

$$\frac{1}{-\frac{5}{2} - \varepsilon} > \frac{x}{5} > \frac{1}{-\frac{5}{2} + \varepsilon},$$
$$\frac{5}{-\frac{5}{2} - \varepsilon} > x > \frac{5}{-\frac{5}{2} + \varepsilon},$$
$$\frac{5}{-\frac{5}{2} + \varepsilon} < x < \frac{5}{-\frac{5}{2} - \varepsilon},$$
$$\frac{10}{-5 + 2\varepsilon} < x < \frac{10}{-5 - 2\varepsilon}.$$

$x$ «обнажили». Теперь нам надо получить из (10) неравенство вида (1):

$$|x - (-2)| < \delta,$$
$$-\delta < x - (-2) < \delta,$$
$$-2 - \delta < x < -2 + \delta.$$

Из (10):

$$-2 + \frac{10}{-5 + 2\varepsilon} + 2 < x < -2 +$$
$$+ \frac{10}{-5 - 2\varepsilon} + 2,$$
$$-2 - \frac{4\varepsilon}{5 - 2\varepsilon} < x < -2 + \frac{4\varepsilon}{5 + 2\varepsilon}.$$

Пока еще неравенство (12) не вплоне имеет вид (11). При $\varepsilon < \frac{5}{2}$

$$\frac{4\varepsilon}{5 - 2\varepsilon} > \frac{4\varepsilon}{5 + 2\varepsilon}.$$

Значит,

$$-2 - \frac{4\varepsilon}{5-2\varepsilon} < -2 - \frac{4\varepsilon}{5+2\varepsilon}. \tag{13}$$

«Огрубим» неравенство (12):

$$-2 - \frac{4\varepsilon}{5+2\varepsilon} < x < -2 + \frac{4\varepsilon}{5+2\varepsilon}. \tag{14}$$

ИЗ (13) вытекает, что если $x$ удовлетворяет неравенству (14), то он удовлетворяет и неравенству (12) (см. рис. 2). Но (14) имеет уже вид (11). ИЗ (14)

$$|x - (-2)| < \frac{4\varepsilon}{5+2\varepsilon}.$$

Таким образом, если $\varepsilon < \frac{5}{2}$, то при $\delta = \frac{4\varepsilon}{5+2\varepsilon}$ из $0 < |x - (-2)| < \delta$ вытекает (8).

Но нам ведь надо доказать, что для любого $\varepsilon > 0$ существует такое $\delta > 0$, а мы показали это доказали только для $\varepsilon < \frac{5}{2}$. Однако, по существу, этого достаточно, потому что для $\varepsilon \geq \frac{5}{2}$ годится то же $\delta$!

В самом деле, пусть $\varepsilon_1 \geq \frac{5}{2}$; возможно произвольное $\varepsilon_2 < \frac{5}{2}$ и $\delta_2 = \frac{4\varepsilon_2}{5+2\varepsilon_2}$; по доказанному из

$$0 < |x - (-2)| < \delta_2$$

вытекает $$\left| \frac{5}{x} - \left( -\frac{5}{2} \right) \right| < \varepsilon_2;$$

но $\varepsilon_2 < \frac{5}{2} \leq \varepsilon_1$; значит,

$$\left| \frac{5}{x} - \left( -\frac{5}{2} \right) \right| < \varepsilon_1.$$

Это замечание носит общий характер: оказывается, всегда можно искать $\delta$ не для всех $\varepsilon > 0$, а для всех положительных $\varepsilon$, меньших любого выбранного нами положительного числа.

Разумеется, и в данном примере неравенство (2) = (8) верно при $x = a$.

Пример 3. Доказем, что

$$\lim_{x \to 0} \left( x \cdot \sin \frac{1}{x} \right) = 0.$$

Рис. 2.

Неравенство (2) в данном случае имеет вид

$$|x \cdot \sin \frac{1}{x} - 0| < \varepsilon,$$

$$|x \cdot \sin \frac{1}{x}| < \varepsilon. \tag{15}$$

Если мы в этом примере сразу же пошли тем же путем, что и в предыдущих, мы бы не достигли целлю: $x$ нам бы «обнажить» не удалось. Поэтому начнем с того, что «огрубим» неравенство (15): по скольку $$\left| \sin \frac{1}{x} \right| \leq 1,$$

$$|x \sin \frac{1}{x}| \leq |x|. \tag{16}$$

ИЗ (16) вытекает, что вместе (15) достаточно искать $\delta$ для неравенства $$|x| < \varepsilon.$$ Поскольку в нашем случае неравенство (1) имеет вид $0 < |x| < \delta$, ясно, что в качестве искомого $\delta$ можно взять $\varepsilon$.

В данном примере неравенство (2) = (15) при $x = a = 0$, конечно, не верно: функция $x \sin \frac{1}{x}$ при $x = 0$ не определяна.

Запомните дважды примененный нами пример «огрубения» — он часто бывают полезным.

В рассмотренных нами примерах отыскание $\delta$ не вызывало больших функций доказательство утверждения (3) в «лоб», прямым отысканием $\delta$, обусловно не удается. В таких случаях может помочь теория.

Приведем пример из «нешкольной» теории. Справедлива также теорема: если $$\lim_{x \to a} f(x) = 0, \lim_{x \to a} g(x) = 0$$ и существует $$\lim_{x \to a} \frac{f'(x)}{g'(x)},$$ то существует $u$ $$\lim_{x \to a} \frac{f(x)}{g(x)} u$$

$$\lim_{x \to a} \frac{f(x)}{g(x)} = \lim_{x \to a} \frac{f'(x)}{g'(x)}.$$

Эта теорема называется *правилом Лопитания*. По этому правилу:

$$\lim_{x \to 0} \frac{e^x - e^{-x}}{\ln(e - x) + x - 1} =$$

$$= \lim_{x \to 0} \frac{e^x + e^{-x}}{-1 - \frac{1}{e} + 1} = \frac{2}{1 - \frac{1}{e}} = \frac{2e}{e - 1}.$$
