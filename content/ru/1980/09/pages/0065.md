1. а) Если $abc = (a + b + c)^3$, то $5 \leq a + b + c \leq 9$, откуда $a + b + c = \{5, 6, 7, 8, 9\}$.
Нетрудно сообщить, что $a + b + c$ не может равнять 5, 6 и 9 (кубы этих чисел оканчиваются на 5, 6 и 9 соответственно). Остатся проверить случай $a + b + c = 7$ и $a + b + c = 8$.
Имеем: $7^3 = 343$ — не подходит; $8^3 = 512$ — подходит. Таким образом, исключим число 512.
6) Если $abcd = (a + b + c + d)^4$, то $6 \leq a + b + c + d \leq 9$, то есть $a + b + c + d = \{6, 7, 8, 9\}$.
Снова $a + b + c + d \neq 6$, поскольку $6^4$ оканчивается на 6.
