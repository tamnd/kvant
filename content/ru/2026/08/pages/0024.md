объем не меняется при изменении порядка аргументов. Складем,
$$V(A, A, B) = V(A, B, A) = V(B, A, A).$$
Аналогично, $V_{\alpha A + \beta B + \gamma C}$ внешне повторяет формулу разложения $(\alpha + \beta + \gamma)^3$ с добавыми множителими, равными смешанным объемам:
$$V_{\alpha A + \beta B + \gamma C} = V_A \cdot \alpha^3 + V_B \cdot \beta^3 + V_C \cdot \gamma^3 + 3(V(A, A, B) \cdot \alpha^2 \beta + V(A, B, B) \cdot \alpha \beta^2 + V(B, B, C) \cdot \beta^2 \gamma + V(B, C, C) \cdot \beta \gamma^2 + V(C, C, A) \cdot \gamma^2 \alpha + V(C, A, A) \cdot \gamma \alpha^2) + 6V(A, B, C) \cdot \alpha \beta \gamma.$$
И так далее. Конечно, формула для большого количества слагаемых $\alpha A + \beta B + \ldots$ обобщает формулу для меньшего числа слагаемых – достаточно обнулить коэффициенты при «лишних» слагаемых.

Упражнение 27*. Докажите для выпukлых многограничков $A, B, C, D$ и константы $\lambda > 0$, что
a) $V(\lambda A, B, C) = \lambda V(A, B, C);$
b) $V(A + B, C, D) = V(A, C, D) + V(B, C, D).$
Для смешанных объемов выполнения многоограничков $A \subset \bar{A}, B, C$
$$V(A, B, C) \leq V(\bar{A}, B, C).$$
Однако в отсутствие произрачной геометрической интерпретации $V(A, B, C)$ доказать это свойство и тем более его $n$-мерное обобщение совсем не просто. Из монotonности несложно вывести неотрицательность $V(A, B, C)$, рассмотреть случай вырожения одного из многограничков в точку.
Из (16) следует (после подстановки $\alpha = 1$)
$$V_{A+tB} - V_A = 3k_2t + 3k_1t^2 + V_Bt^3.$$
Аналогично рассуждаем в плоском случае, попробуем найти геометрический смысл коэффициента при $t$. Зафиксируем малое значение $t > 0$.
Сумма $A + tB$ это объединение сдигов многограничка $tB$ на векторы $\overrightarrow{OX}$, где $X \in A$. Здесь нас подкидает трудность: геометрическое описание многограничка $A + tB$ го-раздо сложнее, чем описание многоугольника $A + tB$ в плоском случае (вспомним рис. 5). Но есть и хорошо новость: расстояние между плоскостями соответствующих граней, перpendикularных внешней нормали $\vec{n}_i$, многограничков $A$ и $A + tB$ будет равно $ty_i$. На каждой грани многограничка $A$ построим вне его прямую призму $R_i$ высоты $ty_i$. При малых $t > 0$ обведенное $R$ призм $R_i$ – хорошо приближение к множеству $(A + tB) \setminus A$, а именно, можно показать, что при малых $t$ объемы $V_R$ и $V_{(A+tB) \setminus A}$ отличаются не более чем на const $\cdot t^2$. Значит, $V_R = \sum (a_i \cdot ty_i)$ и есть линейная часть приращения $V_{A+tB} - V_A$. И мы видим, что $3k_2 = \sum a_i y_i$. Так нами получено выражение для смешанного объема
$$V(A, A, B) = \frac{1}{3} \sum a_i y_i,$$
похожее на выражение (3) для плоского случая.
Аналогично, $V(B, B, A) = \frac{1}{3} \sum b_i x_i$. Конечно, здесь уже не может быть никакой речи о тождестве $\sum a_i y_i = \sum b_i x_i$, хотя бы из «сообщений размерности» – см. упражнение 27,a.
Сильным результатом о смешанных объемах является неравенство
$$V(A, B, C)^2 \geq V(A, A, C) \cdot V(B, B, C).$$
Так, для последовательности коэффициентов $k_0 = V_B, k_1 = V(A, B, B), k_2 = V(A, A, B), k_3 = V_A$ из формулы (16) и неравенства (17) получаем
$$k_0 k_2 \leq k_1^2, k_1 k_3 \leq k_2^2.$$
$$^5$$ Верно более общее неравенство Алексадрова-Фенхеля для смешанных $n$-мерных объемов:
$$V(A, B, C, D, E, \ldots)^2 \geq V(A, A, C, D, E, \ldots) \cdot V(B, B, C, D, E, \ldots).$$
Таким образом, нашей «главное» неравенство (6) из первой части статьи оказалось двумерным частным случае неравенства Алексадрова-Фенхеля.
