«Все», «некоторые» и отрицание

1. Есть хотя бы один белый шар.
2. Все шары — белые.
3. Все шары — красные.
4. Некоторые равноведенные треугольники не являются прямолиными.
5. Некоторые ученики класса не были на собрании.
6. Ни одной девочки не были на собрании.
7. Некоторые углы данного шестиугольника — прямые или остые.
8. По крайней мере для одного $x$ из $A x^2$ не превыходит 4.
9. Все люди — не детей.
10. Для всех $x$ из $A x^2 - 2x + 1 \neq 0$.
11. Некоторые мужчины не выше 2-х метров.
12. Некоторые простые числа четны.
13. По крайней мере для одного простого числа $p$ число $2^p - 1$ не является простым.
14. Неверно. Может быть один белый шар, а остальные — сине.
15. Верно.
16. Чтобы наверняка попался белый шар, надо вынуть, по крайней мере 20 шаров. Меньшего числа может не хватить, либо первыми могут быть вынуты красные и черные шары — их 19. Чтобы наверняка попался шары всех трех цветов, надо вынуть как минимум 22 шара; 21 может нахватить, если первыми вынуты все белые и черные шары; их как раз 21.
17. Надо вызвать 31 человек. Меньше нельзя — может служиться, что к доске вынут лишь треугольники и хорошего (их $10 + 20 = 30$) и каждый ответ не более, чем на 4. Если же вызвать 31 человек, то, по крайней мере, один из них оказывается отличником и ответит на 5.

XXI Весоюзная олимпиада по математике

8 класс

1. Указание. Воспользовитесь тем, что $x_1 + y_1 = x_2 + y_2 = ... = x_{10} + y_{10} = 9$, причем $x_1 + x_2 + ... + x_{10} = y_1 + y_2 + ... + y_{10}$.
2. Ответ: 1, 2, 4, 8, 16, 32. Указание. Если $x_1 \leq x_2 \leq ... \leq x_6$ — массей гирь, то каждая масса, которую можно уравновести с помощью этих гирь, записывается в виде $\varepsilon_1 x_1 + \varepsilon_2 x_2 + ... + \varepsilon_6 x_6$, где $\varepsilon_i = 0,1$ и не все $\varepsilon_i = 0$. Таких сумм всего 63. Поэтому все они должны быть различаны. Ясно, что $x_1 = 1$, $x_2 = 2$, $x_3 = 4$. Пусть доказано, что $x_k = 2^{k-1}$, тогда наиболее масса, уравновешивающая с помощью гирь $x_1, ..., x_{10}$, равна $x_1 + x_2 + ... + x_4 = 2^{k-1}$. Поэтому $x_{k+1} = 2^k$.
3. Пусть $A_1 A_2 A_3 \dots A_7$ — данный семиугольник, $B$ — точка пересечения прямых $A_1 A_2$ и $A_3 A_4$, $A_1 A_2 = x$, $A_1 A_3 = y$, $A_1 A_4 = z$. Треугольник $BA_3 A_4$ — равноведенный $(\angle A_1 BA_3 = \angle BA_3 A_4 = 3\pi/7)$, а треугольники $A_2 BA_3$ и $A_1 BA_4$ подобны $(A_2 A_3 \parallel A_1 A_4)$. Отсюда сразу получаем, что $\frac{y - x}{y} = \frac{x}{z}$, или $\frac{1}{x} = \frac{1}{y} + \frac{1}{z}$.
4. a) Ответ: 12 выстрелов. Решение.e. В квадрате $7 \times 7$ корабль может стать в одной из 12 позиций, показанных на рисунке 1, поэтому необходимо сделать не менее 12 выстрелов. На рисунке 2 показано, что 12 выстрелов достаточно.
