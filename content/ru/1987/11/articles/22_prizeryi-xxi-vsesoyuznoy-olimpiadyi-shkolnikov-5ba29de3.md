Братическа, 23—30 августа 1987 г.

1 тур

Задчаа 1 (СССР). Для натуральных чисел X и Y будем говорить, что X входит в Y, если двойную запись X можно получить из двойной записи Y вычеркиванием нулевого, единичного или большого количества цифр. (Например: X=1010 входит в Y=1001100). Постройте алгоритм, который для двух данных натуральных чисел A и B найдет максимальное число C, входяще как в A, так и в B.

Задчаа 2 (ЧССР). Даны п карточек, занумеранных числами 1, 2, 3, ..., п (каждый номер встреется только один раз). Постройте алгоритм, который для произвольной последовательности A₁, A₂, A₃, ..., Aₙ из этих карточек найдет наиболее число перестановок, необходимых для того, чтобы расположить карточки в порядке возрастания их номеров. Под перестановкой понимается единичный объем местами любых двух карточек. Пример: Для последовательности 1, 5, 3, 2, 4 необходимо две перестановки: № 5 и № 2, а затем № 4 и № 5, после чего получается упорядоченная последовательность 1, 2, 3, 4, 5.

2 тур

Задчаа 3 (НРВ). Постройте алгоритм, который распределяет первые N² натуральных чисел (N>2) в N группе так, что одновременно выполняется следующие три условия:

1) каждая группа содержитровно N чисел;
2) каждое число принадлежит только одной группе;
3) сумма чисел в каждой группе одинаковая для всех групп.

Задчаа 4 (ЧССР). Расстоянием следующую игру. Для заданного фиксированного натурального числа N>1 игрок A выбирает натуральное число X, не превозходимое N. Цель игрок B — угадать число X при помощи вопросов вида «Число X больше или равно K?», где K — некоторое натуральное число. На каждый вопрос игрок B игрок A obtuesет число и не меняет числа X. Игрок B плитит игрок A за каждый ответ: 2 руб. за ответ «ДА» и 1 руб. за «НЕТ». Определите для данного N наименьшую сумму P(N), достаточно для гарантийного уgradывания любого числа X от 1 до N. Постройте алгоритм, по которым игрок B задacts вопросы таким образом, что угадает число X и при этом запалит не более P(N) рублей (т. е. алгоритм, который определяет значения K в задаваемых вопросах).
