следующий способ построения генеалогического дерева для примитивных пар и примитивных пифагоровых troek. Вводятся три преобразования $t_1, t_2$ и $t_3$:

$$t_1(m, n) = (2m - n, m),$$
$$t_2(m, n) = (2m + n, m),$$
$$t_3(m, n) = (m + 2n, n).$$

При помощи этих преобразований, начиная с пары (2, 1), строится генеалогическое дерево. Здесь направление вверх соответствует преобразования $t_1$, горизонтальное направление — преобразование $t_2$, направление вниз — преобразование $t_3$.

Задача 10. Пусть пара $(m, n)$ порождает при помощи соответствий (4) пифагорову troйку $(X, Y, Z)$. Пифагорову troйку, порожденную парой $t_1$ $(m, n)$, обозначаем через $T_1(X, Y, Z)$; troйку, порожденную парой $t_2$ $(m, n)$, — через $T_2(X, Y, Z)$; наконец, troйку, порожденную парой $t_3$ $(m, n)$, — через $T_3(X, Y, Z)$. Докажите, что

$$T_1(X, Y, Z) = (X - 2Y + 2Z, 2X - Y + 2Z, 2X - 2Y + 3Z),$$
$$T_2(X, Y, Z) = (X + 2Y + 2Z, 2X + Y + 2Z, 2X + 2Y + 3Z),$$
$$T_3(X, Y, Z) = (-X + 2Y + 2Z, -2X + Y + 2Z, -2X + 2Y + 3Z).$$

Теперь при помощи преобразования $T_1, T_2, T_3$ построим еще одно генеалогическое дерево, но уже началосься с troйки (3, 4, 5).

Замечательный результат Холла заключается в том, что генеалогическое дерево на рисунке 3 содержит все без исключения примитивные пары; значит, генеалогическое дерево на рисунке 4 содержит все без исключения пары (2, 1).

К каждой паре $(m, n)$ на рисунке 3 подходитровно одна стрелка. Для преобразования $u_1, u_2, u_3$ это соответствует следующему факту.

Задача 13. Пусть пара $(M, N)$ примитивна и $(M, N) \neq (2, 1)$. Докажите, что тогда только одна из трех пар $(m, n) = u_i(M, N)$, $i = 1, 2, 3$, будет примитивной. При этом $m + n < M + N$.
