⟦folio 13⟧

еше два генеологических деревьев, содержащих все без исключений и повторений примитивные пифагоровы трейки (рис. 5).

Первое из них строится при помощи преобразования
$$T_1(X, Y, Z) = (2X - Y + Z, 2X + 2Y + 2Z, 2X + Y + 3Z),$$
$$T_2(X, Y, Z) = (2X + Y + Z, 2X - 2Y + 2Z, 2X - Y + 3Z),$$
$$T_3(X, Y, Z) = (2X + Y - Z, -2X + 2Y + 2Z, -2X + Y + 3Z).$$

Второе — при помощи преобразования
$$T_1(X, Y, Z) = (X - 2Y + 2Z, 2X - Y + 2Z, 2X - 2Y + 3Z),$$
$$T_2(X, Y, Z) = (2X + Y + Z, 2X - 2Y + 2Z, 2X - Y + 3Z),$$
$$T_3(X, Y, Z) = (-2X + 3Y + 3Z, -6X + 2Y + 6Z, -6X + 3Y + 7Z).$$

Пифагоры трейки неизменно, на протяжении тиссячелей привлекают внимание математиков. Но мы видим, что эта тема не исчерпала себя, и тут до сих пор продолжают обнаруживать новые интересные факты.

Подводя итоги
В связи с тем, что было расссказано, имеется несколько вопросов, которые необходимо если не решить, то по крайней мере задать. Например, почему для управления $XY = Z^2$ от каждой решения отходят две стрелки, а на генеологическом дереве для $X^2 + Y^2 = Z^2$ — три? Далее, почему для управления $X^2 + Y^2 = Z^2$ построено три генеологических деревьев, а для $XY = Z^2$ — только одно, и существует ли для этих управления другие деревья? Наконец, как бы найдены преобразования $T_1$, $T_2$, $T_3$, позволяющие строить генеологические деревья для пифагоровых трейки?

Наше построение генеологического дерева для управления $XY = Z^2$ напрямую связано с алгоритмом Евклида и выгладит достаточно мотивированным, чего нельзя сказать об управлении $X^2 + Y^2 = Z^2$. Однако между этим управлениями имеется связь, оправдывающая попытки сделать для одного из них то, что было сделано для другого. Действительно, записем управление $X^2 + Y^2 = Z^2$ в виде $Z^2 - X^2 = Y^2$ и разложим левую часть на множители: $(Z - X)(Z + X) = Y^2$. Сделав замену $U = Z - X$, $V = Z + X$, $W = Y$, приходим к управлению $UV = W^2$. Таким образом, существует замена, переводящая управление $X^2 + Y^2 = Z^2$ в управление $XY = Z^2$.

Имеется еще цель ряда управления, допускающих замену, переводящую их в $XY = Z^2$. Таким управлениями будут, скажем, $X^2 + Y^2 = 2Z^2$ и $X^2 + 3Y^2 = Z^2$. Вы можете попытаться построить генеологические деревья и для этих управлений.

Необходимо сказать еще об одном заменаальном управлении — управлении Маркова:
$$X^2 + Y^2 + Z^2 = 3XYZ.$$

Оно обладает уже привящным для нас свойством — все его решения, кроме двух очень низких (1, 1, 1) и (2, 1, 1), организуют в генеологическое дерево. Об этом подробно расссказано в увеличительной стате М. Г. Крейна («Квант», 1985, № 4, с. 13). Это дерево вполне аналогично генеологическому дереву для управления $XY = Z^2$. Существует ли какая-то связь между этим управлениями? Какие еще управления обладают подобными свойствами?

Так что тут есть о чем еще подумать.
