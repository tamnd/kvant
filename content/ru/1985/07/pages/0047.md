$$x^2 = \frac{1}{3} (x+1)^3 - \frac{1}{3} (x^3+3x+1).$$

б) Доказательство проведем индукцией по степени многочлена. Для многочленов нулевой степени (постоянных функций) утверждение задачи очевидно. Пусть оно справедливо для всех многочленов степени меньше $n$. Произвольный многочлен $n$-й степени $P_n(x)$ можно записать в виде

$$P_n(x) = ax^n + P_{n-1}(x),$$

где $P_{n-1}(x)$ — многочлен степени не выше $n-1$, для которого наше утверждение верно по предположению индукции. Поэтому его достаточно доказать для одного $ax^n$ (если утверждение задачи верно для двух многочленов, то оно, очевидно, верно и для их суммы). Ясно, что $ax^n$ — монотная функция при нечетном $n$; при четном $n$ существует нужно представления следует из формулы

$$(n+1)x^n = (x+1)^{n+1} - x^{n+1} - Q_{n-1}(x),$$

в котором $(x+1)^{n+1}$ и $x^{n+1}$ — возвращение функции $(n+1)$ нечетно), а для многочлена $Q_{n-1}(x)$ степени $n-1$ утверждение задачи выполняется по предположению индукции.

При четном $n=2k$ можно рассудать и иначе. По предположению индукции $x^k = P(x)-Q(x)$, где $P$ и $Q$ — монотновозрастание многочлены; следовательно,

$$x^{2k} = 2P^2(x) + 2Q^2(x) - (P(x)+Q(x))^2.$$

Подставляя в формулу пункта a) $P(x)$ вместе $x$, мы получим представление $P^2(x)$ в виде разности двух возвращающих многочленов. То же самое можно проделать с $Q(x)$ и $P(x)+Q(x)$, что в конечном случае дает нужно представление для $x^{2k}$.

А. Ю. Вайитров, В. Н. Дубровский
