⟦folio 47⟧

$$c + \delta + m = \frac{2S_{AOB}}{AB} + \frac{2S_{BOC}}{BC} + \frac{2S_{COA}}{CA} = s$$

Жать точкой внутри равностороннего треугольника высоты $s$, удаленной от его сторона на расстояния $c, \delta, m$ соответствующего рис. 1. При этом каждой операции отвечает сдигт точки в треугольнике на расстояние 2 перпендикулярно одной из сторон. Разобъем треугольник на $s^2$ одинаковых правильных треугольников высоты 1 (рис. 2); очевидно, их вершины отвечают всем целочисленным тройкам с заданной суммой $s$. Возьмем одну из этих вершин, проведем из нее стрелки в те точки, куда ее можно сдигнуть с помощью наших операций, из концов стрелок проведем новые стрелки и т. д. Все эти стрелки образуют еще одну сдигнутой треугольников со стороны 2. Их вершины изображают все тройки чисел, которые можно получить из исходной «перекрашиванием хамелеонов». Легко убедиться, что из любой красной точки за исключением вершин большого треугольника, можно перейти по красным стрелкам в любую другую. Остальные точки аналогичным образом разобются еще на два класса «связанных» точек (зеленые и синее на рисунке 2; стрелки для них не показаны). Значение инварианта $r$ для всех точок одного класса будет, разумеется, одним и тем же; причем легко проверить, что для красных точек $r=0$, для зеленых — $r=1$, для синих — $r=2$.

Таким образом, из тройки $(c, \delta, m)$ можно получить другую тройку $(c', \delta', m')$ тогда и только тогда, когда в первой тройке хотя бы два числа положительных и значения инвариантов $s$ и $r$ для данных троек совпадают (значения любого другого инварианта будут совпадать уже автоматически; доказите непосредственно, что, например, остаток от деления $m-6$ на 3 выражается через $s$ и $r$). В частности, если $s$ кратно trem, для всех вершин большого треугольника $r=0$, то есть они достижены только из точки $c = 0$ (на рисунке 2 — из красных точки); если же $s$ не делится на 3, то в одной из них будет $r=0$, в другой — $r=1$, в третьей — $r=2$, то есть из любой точки $(c, \delta, m)$ можно попасть в одну (и только одну) вершину.

В. Г. Ильцчев, Н. В. Васильев
