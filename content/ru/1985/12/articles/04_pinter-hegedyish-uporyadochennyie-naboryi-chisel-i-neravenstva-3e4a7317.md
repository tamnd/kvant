Упорядоченные наборы чисел и неравенства

Л. ПИНТЕР, И. ХЕГЕДЫШ

Родители Коли хранят бумажные деньги в конвертах. Однажды они достали три конверта и положили их перед ним. В одном из конвертов лежали рублей, в другом — трешки, а в третьем — пятерки. Родители попросили Коли вытащить из одного из конвертов две, из другого три, а из оставшегося конверта четыре бумажки.

Как Коле выбрать конверты, чтобы получить наиболее возможную сумму, и как — чтобы набрать сумму, наиболее возможную из возможных? Что бы найти набранную сумму при производном выборе конвертов, нужно в таблицу 1 в нижнюю строку вместе вопросительных знаков поставить числа 2, 3, 4 в соответствующем порядке, затем взять произведение чисел по столбцам и сложить их.

Таблица 1

1? 3? 5?

Таблица 1

Если Коля хочет набрать наиболее возможную сумму, то он должен вытащить четыре бумажки из конверта с пятерками, три бумажки из конверта с трешки и две бумажки из конверта с рублями:

$$5 \cdot 4 + 3 \cdot 3 + 1 \cdot 2 = 31.$$

Если Коля хочет набрать наиболее возможную сумму, то он должен вытащить наиболее возможные число бумажек, то есть две, из конверта с пятерками, три — из конверта с трешки и четыре — из конверта с рублями, то есть

$$5 \cdot 2 + 3 \cdot 3 + 1 \cdot 4 = 23.$$

Упорядоченные тройки

В обшем виде эту задачу можно сформировать так. Пусть данные тройки положительных чисел

$$a_1, a_2, a_3,$$

$$b_1, b_2, b_3.$$

Рассмотрим сумму

$$S = a_1 b_i + a_2 b_j + a_3 b_k,$$

где $i, j, k$ — это числа 1, 2, 3, написанные в каком уголно порядке. Как выбрать этот порядок, чтобы сумма $S$ оказалась наиболее возможной (соответственно наиболее возможной) из возможных?

Ясно, что если наиболее из чисел $a$ умножить на наиболее из чисел $b$, среднее из чисел $a$ на среднее из чисел $b$ и наконец наименование из чисел $a$ наименование из чисел $b$ и сложить эти произведение, то получится максимальное из возможных значения $S$ (если среднее из чисел $a$ или среднее из чисел $b$ имеются равные, то это максимальное значение $S$ получается не единственным способом). Если же наиболее из чисел $a$ умножить на наиболее из чисел $b$, среднее — на среднее и т. д., то получаем наиболее возможное значение $S$.

Пользовать этим методом, можно просто решить задачу M762 (см. «Квант», 1982, № 9)*.

Докажите, что для любых положительных чисел $a, b, c$ справедливые неравенства:

$$a + b + c \leq \frac{a^2 + b^2}{2c} +$$

$$+ \frac{b^2 + c^2}{2a} + \frac{c^2 + a^2}{2b} \leq \frac{a^3}{bc} + \frac{b^3}{ca} + \frac{c^3}{ab}. \quad (1)$$

Докажем сначала первое неравенство. Запишем две тройки чисел

$$a^2, b^2, c^2,$$

$$\frac{1}{a}, \frac{1}{b}, \frac{1}{c}.$$

Поскольку числа $a, b, c$ положительные, наиболее из чисел первого тройки расположено над наиболее из чисел второго тройки, наиболее из чисел первого тройки расположено над наиболее из чисел

второй тройки. Поэтому для данных троек сумма

$$a^2 \cdot \frac{1}{a} + b^2 \cdot \frac{1}{b} + c^2 \cdot \frac{1}{c}$$

является минимальной, и следовательно,

$$a^2 \frac{1}{a} + b^2 \frac{1}{b} + c^2 \frac{1}{c} \leq a^2 \frac{1}{b} + b^2 \frac{1}{c} + c^2 \frac{1}{a},$$

(2)

$$a^2 \frac{1}{a} + b^2 \frac{1}{b} + c^2 \frac{1}{c} \leq a^2 \frac{1}{c} + b^2 \frac{1}{a} + c^2 \frac{1}{b}.$$

(3)

Складывая неравенства (2) и (3), получим:

$$2(a+b+c) \leq a^2 \frac{1}{b} + b^2 \frac{1}{c} + c^2 \frac{1}{a} + a^2 \frac{1}{c} + b^2 \frac{1}{a} + c^2 \frac{1}{b} = \frac{a^2+b^2}{c} + \frac{b^2+c^2}{a} + \frac{c^2+a^2}{b}.$$

Чтобы получить второе из неравенств (1), рассмотрим тройки чисел

$$a^3, b^3, c^3,$$

$$\frac{a}{abc}, \frac{b}{abc}, \frac{c}{abc}.$$

Под наиболее (соответственно наиболее) из чисел первой тройки записано наиболее (наименьшее) число второй тройки. Поэтому

$$a^3 \frac{a}{abc} + b^3 \frac{b}{abc} + c^3 \frac{c}{abc} \geq a^3 \frac{b}{abc} + b^3 \frac{c}{abc} + c^3 \frac{a}{abc} + b^3 \frac{c}{abc} + c^3 \frac{a}{abc} + c^3 \frac{b}{abc} = \frac{a^2}{c} + \frac{b^2}{a} + \frac{c^2}{b},$$

(4)

$$a^3 \frac{a}{abc} + b^3 \frac{b}{abc} + c^3 \frac{c}{abc} \geq a^3 \frac{c}{abc} + b^3 \frac{a}{abc} + c^3 \frac{b}{abc} + c^3 \frac{a}{abc} + c^3 \frac{b}{abc} = \frac{a^2}{c} + \frac{b^2}{a} + \frac{c^2}{b},$$

(5)

Складывая неравенства (4) и (5), получаем

$$2\left(\frac{a^3}{bc} + \frac{b^3}{ca} + \frac{c^3}{ab}\right) \geq \frac{a^2}{c} + \frac{b^2}{a} + \frac{c^2}{b} + \frac{b^2}{c} + \frac{c^2}{a},$$

$$+ \frac{c^2}{a} = \frac{a^2+b^2}{c} + \frac{b^2+c^2}{a} + \frac{c^2+a^2}{b},$$

что и требовалось.

Упражнения
Доказите неравенства:
1. $a^4 + b^4 \geq a^3 b + ab^3$.
2. $a^3 b + b^3 c + c^3 a \geq a^2 bc + b^2 ca + c^2 ab$.
3. $\frac{a^3 b}{c} + \frac{a^3 c}{b} + \frac{b^3 a}{c} + \frac{c^3 b}{a} \geq 6abc$ (здеся $a > 0, b > 0, c > 0$).
4. Если $a_1 \geq a_2 \geq a_3 \geq a_4, b_1 \geq b_2 \geq b_3$, то $3(a_1 b_1 + a_2 b_2 + a_3 b_3) \geq (a_1 + a_2 + a_3)(b_1 + b_2 + b_3)$.
5. Если $a > 0, b > 0, c > 0$, то

$$\frac{a}{b+c} + \frac{b}{a+c} + \frac{c}{a+b} \geq \frac{3}{2}.$$

Некоторые обобщения

Пусть теперь даны набора из $n$ чисел

$$a_1 \geq a_2 \geq a_3 \geq ... \geq a_n,$$

$$b_1 \geq b_2 \geq b_3 \geq ... \geq b_n.$$

Рассмотрим всевозможные суммы вида $i$ $\sigma = a_1 b_1 + a_2 b_2 + ... + a_n b_n$, где $i_1, i_2, ..., i_n$ — некоторая перестановка чисел 1, 2, ..., $n$.

Число таких сумм конечно, и поэтому среди них есть наиболее $S$ и наиболее $s$. Нетрудно сообщать, что $S = a_1 b_1 + a_2 b_2 + ... + a_n b_n$, а $s = a_1 b_n + a_2 b_n - 1 + ... + a_n b_1$.

Докажем это. Предварительно заметим, что для любых четырех чисел $a, b, c, d$ таких, что $a \geq b$ и $c \geq d$, выполено неравенство

$$ac + bd \geq ad + bc,$$

(*) которое равенство очевидному неравенству

$$(a - b)(c - d) \geq 0.$$

После этого заменяя наше утверждение доказывается без труда. В самом деле, если в некоторой сумме $\sigma$ имеются следующие $a_e b_q$ и $a_k b_p$, для которых $e < k, q > p$, то есть $b_p \geq b_q$, то, переставив числа $b_p$ и $b_q$, мы получим не меньшую сумму $\sigma'$ со следующими $a_e b_p$ и $a_k b_q$.

Послеовательно проводя такие перестановки, мы приедем к сумме $S$, поэтому $S \geq \sigma$.

Аналогично, если $b_q \geq b_p$, то, меняя эти числа местами, получим сумму, не больше $\sigma$.

Так как в результате нескольких перестановок мы можем прийти к сумме $s$, то $\sigma \geq s$.

Итак, для всякой суммы $\sigma$

$$s \leq \sigma \leq S,$$

(B)

причем равенство (B) возможно лишь тогда, когда в одном из наборов $a_1, ..., a_n, \text{ либо } b_1, ..., b_n$ есть равные числа.

Подводя итоги, можно сформулировать общий метод доказательства неравенства: если наборы чисел $a_1, a_2, ..., a_n$ и $b_1, b_2, ..., b_n$ одинаково упорядочены (то есть из $a_k \geq a_l$ следует, что $b_k \geq b_l$), то $a_1 b_1 + a_2 b_2 + ... + ... + a_n b_n \geq a_1 b_1 + a_2 b_2 + ... + ... + a_n b_n$, (здеся $i_1, i_2, ..., i_n$ — произвольная перестановка номеров 1, 2, ..., $n$).
