Складывая неравенства (2) и (3), получим:

$$\frac{a}{abc}, \frac{b}{abc}, \frac{c}{abc}.$$

Под наиболее (соответственно наиболее) из чисел первой тройки записано наиболее (наименьшее) число второй тройки. Поэтому

$$a^3 \frac{a}{abc} + b^3 \frac{b}{abc} + c^3 \frac{c}{abc} \geq a^3 \frac{b}{abc} + b^3 \frac{c}{abc} + c^3 \frac{a}{abc} + b^3 \frac{c}{abc} + c^3 \frac{a}{abc} + c^3 \frac{b}{abc} = \frac{a^2}{c} + \frac{b^2}{a} + \frac{c^2}{b},$$

Упражнения
Доказите неравенства:
1. $a^4 + b^4 \geq a^3 b + ab^3$.
2. $a^3 b + b^3 c + c^3 a \geq a^2 bc + b^2 ca + c^2 ab$.
3. $\frac{a^3 b}{c} + \frac{a^3 c}{b} + \frac{b^3 a}{c} + \frac{c^3 b}{a} \geq 6abc$ (здеся $a > 0, b > 0, c > 0$).
4. Если $a_1 \geq a_2 \geq a_3 \geq a_4, b_1 \geq b_2 \geq b_3$, то $3(a_1 b_1 + a_2 b_2 + a_3 b_3) \geq (a_1 + a_2 + a_3)(b_1 + b_2 + b_3)$.
5. Если $a > 0, b > 0, c > 0$, то

$$\frac{a}{b+c} + \frac{b}{a+c} + \frac{c}{a+b} \geq \frac{3}{2}.$$

Некоторые обобщения

Пусть теперь даны набора из $n$ чисел

$$a_1 \geq a_2 \geq a_3 \geq ... \geq a_n,$$

$$b_1 \geq b_2 \geq b_3 \geq ... \geq b_n.$$

Рассмотрим всевозможные суммы вида $i$ $\sigma = a_1 b_1 + a_2 b_2 + ... + a_n b_n$, где $i_1, i_2, ..., i_n$ — некоторая перестановка чисел 1, 2, ..., $n$.

Число таких сумм конечно, и поэтому среди них есть наиболее $S$ и наиболее $s$. Нетрудно сообщать, что $S = a_1 b_1 + a_2 b_2 + ... + a_n b_n$, а $s = a_1 b_n + a_2 b_n - 1 + ... + a_n b_1$.

Докажем это. Предварительно заметим, что для любых четырех чисел $a, b, c, d$ таких, что $a \geq b$ и $c \geq d$, выполено неравенство

$$ac + bd \geq ad + bc,$$

(*) которое равенство очевидному неравенству

$$(a - b)(c - d) \geq 0.$$

После этого заменяя наше утверждение доказывается без труда. В самом деле, если в некоторой сумме $\sigma$ имеются следующие $a_e b_q$ и $a_k b_p$, для которых $e < k, q > p$, то есть $b_p \geq b_q$, то, переставив числа $b_p$ и $b_q$, мы получим не меньшую сумму $\sigma'$ со следующими $a_e b_p$ и $a_k b_q$.

Послеовательно проводя такие перестановки, мы приедем к сумме $S$, поэтому $S \geq \sigma$.

Аналогично, если $b_q \geq b_p$, то, меняя эти числа местами, получим сумму, не больше $\sigma$.

Так как в результате нескольких перестановок мы можем прийти к сумме $s$, то $\sigma \geq s$.

Итак, для всякой суммы $\sigma$

$$s \leq \sigma \leq S,$$

(B)

причем равенство (B) возможно лишь тогда, когда в одном из наборов $a_1, ..., a_n, \text{ либо } b_1, ..., b_n$ есть равные числа.

Подводя итоги, можно сформулировать общий метод доказательства неравенства: если наборы чисел $a_1, a_2, ..., a_n$ и $b_1, b_2, ..., b_n$ одинаково упорядочены (то есть из $a_k \geq a_l$ следует, что $b_k \geq b_l$), то $a_1 b_1 + a_2 b_2 + ... + ... + a_n b_n \geq a_1 b_1 + a_2 b_2 + ... + ... + a_n b_n$, (здеся $i_1, i_2, ..., i_n$ — произвольная перестановка номеров 1, 2, ..., $n$).
