⟦folio 59⟧

Отражение кривых и преобразования формул
(см. с. 29)
1. $M(y; x)$ и $M(-y; -x)$.
2. а) $y = f(-x)$; б) $y = -f(x)$; в) $y = |f(x)|$; г) $y = f(|x|)$; д) $y = |f(x) - 2| + 2$; е) $y = f(-|x|)$; ж) $y = f(1 - |x - 1|)$; з) $y = f(1 + |x - 1|)$;
и) $y = -f(-x)$;
см. также рис. 1.
3. а) $f(-x, y) = 0$; б) $f(-|x|, y) = 0$; в) $f(x, -y) = 0$; г) $f(|x|, y) = 0$; д) $f(-|x|, |y|) = 0$; е) $f(|x|, |y|) = 0$; ж) $f(|x|, -|y|) = 0$; з) $f(-2|x|, 2|y|) = 0$; и) $f(-|x|, |y|) f(-2|x|, 2|y|) = 0$;
см. также рис. 2.
4. а) $y = ||x| - 1$; б) $y = ||x| - 2| - 1|$; в) $|y| = ||x| - 2|$; г) $|y| = 2 - ||x| - 1| - 2|$; д) $|y| = 2 - ||x| - 1| - 2|$; е) $|y| = 3 - ||x| - 1| - 2|$; ж) $2|y| = ||x| - 2| - |x| + 4$.
Указание. Обратитесь к графику функции $y = |x| - x$ и использовать его для получения изображенной функции и «конструирования» подходящей формулы.
3) $2|y| = ||x| - 4| - |x| + 2|$. Указание. Воспользовитесь указанием к предыдущей задаче 4, ж.
и) $|y| = |x| - |x - 2| - x + 2$. Указание. Расмотите графику функции $y = f(x) - |x|$, где $f(x)$ — функция с «изгзагообразным» графиком, часть которого, лежащая в верхней полу-
кое разложение (окAZывается, что $\frac{1984}{5}$ + $+\frac{1984}{25}$ + $\frac{1984}{125}$ + $\frac{1984}{625}$ раз), и убедиться, что множество 2 будет больше. ([x] — целая часть числа $x$).
2. Указание. Справедливо следующее положение точки:
$2a^2 + 2b^2 + 2c^2 - 2ab - 2bc - 2ca$
$= (a - b)^2 + (b - c)^2 + (c - a)^2$.

*) Для решения подобных задач можно воспользоваться общим методом конструкирования управления ломаньх, содержащимся в решении задачи M848 (см. «Квант», 1984, № 5, c. 47).
