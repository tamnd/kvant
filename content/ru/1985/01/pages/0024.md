⟦folio 22⟧

Правило сложения чисел $p_1 + q_1\sqrt{2}$ и $p_2 + q_2\sqrt{2}$ такое же, как для стольников:
$$p_1 + q_1\sqrt{2} + (p_2 + q_2\sqrt{2}) = (p_1 + p_2) + (q_1 + q_2)\sqrt{2},$$
$$\binom{p_1}{q_1} + \binom{p_2}{q_2} = \binom{p_1 + p_2}{q_1 + q_2}.$$

Тепер переменная числа $p_1 + q_1\sqrt{2}$ и $p_2 + q_2\sqrt{2}$:
$$p_1 + q_1\sqrt{2}(p_2 + q_2\sqrt{2}) = (p_1 + p_2) + (q_1 + q_2)\sqrt{2}.$$
В результате мы приходим к числу такого же вида и получаем новое правило умножения для стольков с рациональными комплексами $p_1, q_1, p_2, q_2$:
$$\binom{p_1}{q_1}\binom{p_2}{q_2} = \binom{p_1 p_2 + 2 q_1 q_2}{p_1 q_2 + p_2 q_1}.$$

(3)

Если следовать такому правилу, то можно записать решение умножения $x^2 - 2y^2 = 1$ так:
$$\binom{x_n}{y_n} = \binom{3}{2}^n$$ (возвеси стольник $n$ раз на себя).

Для правила (3) выполнен общие свойства умножения; роль единцы здесь играет стольник $\binom{1}{0}$, так как он соответствует числу $1 = 1 + 0\sqrt{2}$.

Оперировать с числами $p + q\sqrt{2}$ очень помогает интересная симметрия в множестве таких чисел: каждому числу $a = p + q\sqrt{2}$ соответствует число $\bar{a} = p - q\sqrt{2}$, которое называется сопряженным к $a$. (Для стольников переход к сопряжному ознакомает просто изменение знака $y$ второй компоненты.)

Для операции сопряжения выполнены такие свойства:
$$\bar{a} + \bar{b} = \bar{a} + \bar{b}, \bar{a}\bar{b} = \bar{a}\bar{b}, \bar{a} = a.$$

Но самое важное — это то, что произведение сопряженных чисел $(p + q\sqrt{2})(p - q\sqrt{2}) = p^2 - 2q^2$ уже не содержит $\sqrt{2}$; $\bar{a}\bar{b}$ — рациональное число. Это позволяет делить числа вида $p + q\sqrt{2}$ друг на друга, получая при этом число такого же вида. Чтобы разделить $\beta$ на $a$, достаточно умножить $\beta$ на $\bar{a}$ и разделить результат на $\bar{a}\bar{b}$.

Мы уже пользовались параметрами сопряженных чисел при решении умножения $x^2 - 2y^2 = 1$. Левую часть $x^2 - 2y^2$ мы представили как произведение двух сопряженных чисел
$$a = x + y\sqrt{2}, \bar{a} = x - y\sqrt{2}.$$

Возьем теперь два числа $a = x_1 + y_1\sqrt{2}$ и $\beta = x_2 + y_2\sqrt{2}$ и сопряженные к ним $\bar{a} = x_1 - y_1\sqrt{2}$ и $\bar{b} = x_2 - y_2\sqrt{2}$. Расмотрим произведение $\alpha\bar{a}\beta\bar{b}$. Произведение вычисления в определенном порядке — сначала $\bar{a}\bar{b}$, потом $\beta\bar{b}$ и затем $(\alpha\bar{a})(\beta\bar{b})$ — получаем:
$$\alpha\bar{a}\beta\bar{b} = (x_1^2 - 2y_1^2)(x_2^2 - 2y_2^2).$$

(4)

Если вычисление того же произведение $\alpha\bar{a}\beta\bar{b}$ произвести в другом порядке, то мы получим
$$\alpha\bar{b} = (x_1x_2 + 2y_1y_2) + (x_1y_2 + x_2y_1)\sqrt{2},$$
$$\bar{a}\bar{b} = (x_1x_2 + 2y_1y_2) - (x_1y_2 + x_2y_1)\sqrt{2},$$
$$\alpha\bar{a}\beta\bar{b} = (x_1x_2 + 2y_1y_2)^2 = 2(x_1y_2 + x_2y_1)^2.$$

(5)

Из равенств (4) и (5) получаем также $(x_1^2 - 2y_1^2)(x_2^2 - 2y_2^2) = (x_1x_2 + 2y_1y_2)^2 - 2(x_1y_2 + x_2y_1)^2.$

Из этого тоже соответствует интересная связь между целыми решениями умножения более общего вида $x^2 - 2y^2 = c$.

Если для пары целых чисел $(x_1; y_1)$ выполнен равенство $x_1^2 - 2y_1^2 = c_1$, а для пары целых чисел $(x_2; y_2)$ выполнен равенство $x_2^2 - 2y_2^2 = c_2$, то пара целых чисел $(x_1x_2 + 2y_1y_2; x_1y_2 + x_2y_1)$ является решением умножения $x^2 - 2y^2 = c_1c_2$.

Все сказанное про числа вида $a + b\sqrt{2}$ верно и для чисел вида $a + b\sqrt{d}$, где $d$ — простое число (или натуральное, не делится на квадрат). В частности, оно верно и при $d = -1$; получающейся при этом тожество будет игреть центральную роль в следующем пункте.

5. Замечательное тожество и композиция Виета

Любые две пары чисел $(a_1; b_1)$ и $(a_2; b_2)$ связаны таким тожеством, известным еще Диофанту:
$$a_1^2 + b_1^2)(a_2^2 + b_2^2) = (a_1a_2 - b_1b_2)^2 + (a_1b_2 + a_2b_1)^2.$$

Оно получается из тожества (8) при $d = -1$ и часто используется в алгебре и теории чисел. Мы рассекем здесь о другом его применении: интересном способе, позволяющим получить из двух прямоугольных треугольников новый прямоугольный треугольник с гипотенузой, равной произведению их гипотенузи.

Возьем один прямоугольный треугольник с квадратами $a_1, b_1$ и гипотенузой $c_1$ и другой — с квадратами $a_2, b_2$ и гипотенузой $c_2$. Поскольку по теореме Пифагора
$$a_1^2 + b_1^2 = c_1^2$$ и $a_2^2 + b_2^2 = c_2^2,$
то жество (9) можно записать так:
$$(c_1c_2)^2 = (a_1a_2 - b_1b_2)^2 + (a_1b_2 + a_2b_1)^2.$$
