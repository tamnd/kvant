Два столька считаются равными тогда и только тогда, когда равны их компоненты:

$$\binom{x_1}{y_1} = \binom{x_2}{y_2},$$

только если $\begin{cases} x_1 = x_2, \\ y_1 = y_2. \end{cases}$

Сложить два столька — это значит сложить их компоненты:

пусть $u = \binom{x_1}{y_1}, v = \binom{x_2}{y_2},$

тогда $u + v = \binom{x_1 + x_2}{y_1 + y_2}$.

Так как от перемены мест слагаемых сумма чисел не меняется: $a + b = b + a$, то же самое можно сказать и про стольки: $u + v = v + u$. Для стольков верно также правило $(u + v) + w = u + (v + w)$.

Умножить стольк $u$ на число $k$ — это значит умножить на $k$ обе его компоненты:

если $u = \binom{x}{y},$ то $ku = \binom{kx}{ky}$.

Особую роль, подобную той, которую для чисел играет число 0, для стольков играет нулевой стольк $\binom{0}{0}$. Если это не приводит к путанице, то его обозначают тоже через «0». Для всякого столька $u$ верно равенство $u + 0 = u$.

Казалось бы, стол же естественно ввести умножение стольк:

$$\binom{x_1}{y_1} \binom{x_2}{y_2} = \binom{x_1 x_2}{y_1 y_2}.$$

Для такого умножения выполнения все те же свойства, что и для умножения чисел: 1) $uv = vu$, 2) $u(vw) = (uv)w$, 3) $(u + v)w = uw + vw$. Роль «единицы» играет стольк $e = \binom{1}{1}$.

Но в отличие от чисел, здесь не всегда возможность деление на нулевой стольк. Например, если $u = \binom{1}{0}$, то не существует столька $v$ такого, что $uv = e$.

В конце статьи мы познакомимся с другими, как оказывается, тоже естественным и более содержательным правлом умножения пар чисел:

$$\binom{x_1}{y_1} \binom{x_2}{y_2} = \binom{x_1 x_2 - y_1 y_2}{x_1 y_2 + x_2 y_1}.$$

Это правило заменительно тем, что для него обратная операция — деление на нулевой стольк — всегда возможна.

Пара чисел $(x; y)$, записанная не в виде столька, а в виде строчки, используется обычно для обозначения координат точки на координатной плоскости $Oxy$. Метод координат поэлеметрует связать алгебру с геометrienей. Так, например, уравнение $ax - by = c$ соответствует прямой на координатной плоскости, а целые решения этого уравнения — точкам с целыми координатами (рис. 1). С помощью правил сложения пар чисел и умножения их на число можно записывать формулы для координат точки на прямой, например, если $A = (x_1; y_1), B = (x_2; y_2)$ — две точки, то точка

$$C = \frac{1}{2} \left( (x_1; y_1) + (x_2; y_2) \right) =$$

$$= \left( \frac{x_1 + x_2}{2}; \frac{y_1 + y_2}{2} \right)$$

— середина отрезка $AB$.
