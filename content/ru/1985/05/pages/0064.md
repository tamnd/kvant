6) Указание. Каждый из условий «высоты $AA_1$ и $BB_1$ пересекаются» и «высоты $CC_1$ и $DD_1$ пересекаются» эквивалентно условию «ребра $AB$ и $CD$ перепедикулярны». Достаточно показать эквивалентность условий «высоты $AA_1$ и $BB_1$ пересекаются» и «ребра $AB$ и $CD$ перепедикулярны». Докажем эту эквивалентность. Пусть указаные высоты пересекаются, тогда плоскость, проходящая через них, содержит ребро $AB$ и перепедикулярна ребру $CD$, поэтому $(CD)$ перепедикулярна любой прямой этой плоскости, в частности, прямой $AB$. С другой стороны, если прямые $AB$ и $CD$ перепедикулярны, то существует плоскость, проходящая через $(AB)$ и перепедикулярная $(CD)$. Обе высоты лежат в этой плоскости и поэтому пересекаются.

1. $\pi/4 + \arctg (3/4)$, $\pi/4 + \arctg (3/4)$,
$\pi/2 - 2 \arctg (3/4)$.
Решение. Заметим, что $|AC| = 2 \cdot 4a \cos(a + \pi/4)$ (рис. 16). По теореме синусов для $\triangle AEC$:
$$\frac{a}{\sin \pi/4} = \frac{2 \cdot 4a \cos(\alpha + \pi/4)}{\sin(\pi/2 - \alpha)},$$
откуда $\alpha = \arctg (3/4)$.
Заметим, задачу можно решить и другими способами — без использования теоремы синусов. Ответ можно записать так же в следующем виде:
arctg 7, arctg 7, $\pi - 2 \arctg 7$
(так как $\pi/4 + \arctg (3/4) = \arctg 7$).

2. $\frac{\sin \alpha}{\sin \frac{3}{4} (\pi - \alpha)}$. Решение. По теореме синусов для $\triangle ABD : |AD| / |AB| = \sin \alpha / \sin \widehat{ADB}$, но $\widehat{ADB} = \pi - \hat{B} - \hat{A} / 2 = 3(\pi - \alpha) / 4$ (рис. 17).

3. $|AD| = \frac{c \sin \alpha}{\sin (3\alpha/2)}$, $R = \frac{c}{2 \cos (\alpha/2)}$. Решение. По теореме синусов для $\triangle ABD : |AB| / \sin \widehat{ADB} = |AD| / \sin \alpha$, но $\widehat{ADB} = \pi - (3\alpha) / 2$ (рис. 18).

4. $\sqrt{c(b + c)}$. Решение. Обозначим $|BC| = a$ и проведем биссертирусу $AD$ (рис.19). Из подобия треугольников $ABD$ и $ABC$ получаем $c / |BD| = a/c$. По свойству биссертиры $|BD| / (a - |BD|) = c/b$, откуда, исключая $|BD|$, находим $a = \sqrt{c(b + c)}$.
Заметим, возможность других решений с применением теоремы синусов для $\triangle ABC$.
