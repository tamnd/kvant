М902. Нагуральный ряд 1, 2, 3, ... разбит на несколько арифметических прогрессий. Доказите, что хотя у одной из этих прогрессий первый член делится на ее разность.

$$\angle AKB, \text{ то есть } \frac{1}{2} \angle B + \angle C = \frac{1}{2} \angle A + \angle C \text{ или } \angle A = \angle B; \text{ либо } \angle AMB + \angle AKB = 180^\circ, \text{ то есть } \angle A + \frac{1}{2} \angle B + \frac{1}{2} \angle A + \angle B = \frac{3}{2} (\angle A + \angle B) = 180^\circ \text{ или } \angle C = 180^\circ - (\angle A + \angle B) = 60^\circ.$$

В. Л. Гугенмахер

М903. Существует ли выпуклый многогранник, любое сечение которого плоскостью, не проходящей через вершину, является многоугольником с a) четным; b) нечетным числом сторон?

Овозначием через $a_1, a_2, \dots, a_n$ первые члены прогрессий, на которые разбит натуральный ряд, через $d_1, d_2, \dots, d_n$ — их разности. Произведение всех разностей входит в одну из прогрессий, то есть для некоторого $i, 1 \leq i \leq n$, и некоторого натурального $k$

$$d_1 d_2 \dots d_n = a_i + k d_i.$$

Из этого равенства следует, что $a_i$ делится на $d_i$.

А. В. Келарев

a) Ответ: существует. Покажем, что условию задачи удовлетворяет любой многогранник, из каждой вершины которого выходит четное число ребер, например, octahedр (см. рисунок).

Рассмотрим произвольное сечение такого многогранника, не проходящей через вершины. Очевидно, его можночитать пошевить так, чтобы оно стало непараллельным ни одному из ребер многогранника, а число его стороны осталось прежним. Будем теперь параллельно перемешать плоскость сечения. Тогда число его стороны будет изменяться только при перехождения вершины, причем каждый раз будет проходиться только одна вершина. Если в ней сходится четное число $n$ ребер и $k$ из них пересекали плоскость сечения до перехождения через эту вершину (а значит, $n - k$ — после перехода; см. рисунок), то число вершин сечения при этом перехождение на $n - 2k$ и следовательно, его четность сохранится. А поскольку в конце плоскости сечения не будет пересекать ни одно из ребер, число стороны должно оставаться четным все время, за исключением моментов прохождения вершин.

b) Ответ: не существует. Из решения задачи a) следует, что если у всех сечений многогранника, не проходящей через вершины, число стороны имеет одинаковую четность (в частности, нечетно), то из каждой вершины выходит четное число ребер. Но тогда, как было показано там же, число стороны у любого такого сечения должно быть чётно.

Н. В. Васильев, В. Н. Дубровский
