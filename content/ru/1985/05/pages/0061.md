1. Доказательство. Пусть, например, $b = a$. Тогда $a^2 + 2b^2 = 3b^2 a$; $a^2 = b^2 (3a - 2)$. Следовательно, $b^2 - d^2 = 3bd$, $2 = (3b - d)d$, так что $d$ делит 2, откуда $d = 1$ или $d = 2$. В обих случаях $b = 1$, так как $c = b = 1$, мы для $a$ получаем уравнение $a^2 + 2 = 3a$, откуда $a = 1$, 2, то есть получены сингулярные решения.
2. Доказательство. Мы можем считать, что $a > b > c$. Воспользовемся многочленом
$$\Psi_a(x) = x^2 - 3bcx + b^2 + c^2,$$
который имеет свойства корнями $a$ и $a'$. Так как $(b - a)(b - a') = \Psi_a(b) = 2b^2 + c^2 - 3b^2 c < 3b^2 - 3b^2 c \leq 0,$
число $b$ лежит между $a$ и $a'$, следовательно, $a > a'$. Поэтому максимальная координата решения $(a, b', c)$ больше максимальной координаты решения $(a, b, c)$. Сходным образом устанавливается, что максимальная координата решения $(a, b, c')$ больше максимальной координаты решения $(a, b, c)$.

7. Доказательство. Пусть $(A, B, C)$ — решение уравнения (3) при $k = 2$, то есть
$$A^2 + B^2 + C^2 = 2ABC.$$
(II)
Докажем сначала, что все его координаты — четные.
Если бы среди $A, B, C$ было только одно нечетное или если бы все они были нечетные, то левая часть (II) оказалась бы нечетной, тогда как правая — четная. Если же два из них были нечетными, то по задание 6 при делении на 4 левая часть (II) должна быть в остатке 2, тогда как правая делилась бы на 4 без остатка. Итак,
$$A = 2a, B = 2b, C = 2c.$$
(III)
где $a, b, c$ — натуральные числа. Используя (III) и (II), получим (после сокращения на 4) равенство
$$a^2 + b^2 + c^2 = 4abc.$$
В силу предыдущего рассуджения $a, b, c$ — четные, то есть числа $A, B, C$ делятся на 4. Поэтому этот же примем, получим, что $A, B, C$ делятся на 8, на 16, на 32 и т. д., то есть на любую натуральную степень числа 2. Для натуральных чисел это невозможно.
