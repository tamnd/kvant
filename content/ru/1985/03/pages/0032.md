(c заменной 1/5 на 1/n) справедливо для любых $n$ чисел.

6) Мы должны доказать, что для любых $n \geqslant 4$ неотрицательных чисел $a_1, \dots, a_n$ сумма которых равна 1, выполнен неравенство
$$a_1a_2 + a_2a_3 + \dots + a_{n-1}a_n + a_na_1 \leqslant 1/4.$$

При четном $n (n=2m)$ это неравенство доказывается неопределенно: пусть $a_1 + a_3 + \dots + a_{2m-1} = a$; тогда, очевидно,
$$a_1a_2 + \dots + a_na_1 \leqslant (a_1 + a_3 + \dots + a_{2m-1}) \times \times (a_2 + a_4 + \dots + a_{2m}) = a(1-a) \leqslant 1/4.$$

Пусть теперь $n$ нечетно и пусть $a_k$ — наименьшее из данных чисел. (Для удобства будем считать, что $1 < k < n-1$ — это не ограничивает общности при $n \geqslant 4$.) Положим $b_i = a_i$ при $i=1, \dots, k-1$, $b_k = a_k + a_{k+1}$ и $b_i = a_{i+1}$ при $i=k+1, \dots, n-1$. Применяя нашей неравенство к числам $b_1, \dots, b_{n-1}$, получим:
$$a_1a_2 + \dots + a_{k-2}a_{k-1} + (a_{k-1} + a_{k+2})b_k + a_{k+2}a_{k+3} + \dots + a_{n-1}a_n + a_na_1 \leqslant 1/4.$$

Остается воспользоваться тем, что
$$a_{k-1}a_k + a_ka_{k+1} + a_{k+1}a_{k+2} \leqslant a_{k-1}a_k + a_{k-1}a_{k+1} + a_{k+1}a_{k+2} \leqslant (a_{k-1} + a_{k+2})b_k.$$

Заметим, что в общих пунктах указанные оценки точные (их нельзя уменшить); в пункте a) оценка $1/n$ достигается, когда все $n$ чисел равны, а в пункте 6) — когда два из них равны 1/2, а остальные 0.

(Ортогональные проекции этих трех граней на плоскость первой грани полностью ее покрывают, а площади проекций меньше площадей самих граней.) Тем не менее, мы докажем a) независимо, поскольку при этом получится несколько более общий результат.
