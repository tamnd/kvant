7. Обозначим через $(a_n, b_n, c_n, d_n)$ четырёх учета, получающийся из $(a, b, c, d)$ за $n$ нажатий кнопки. Заметим, что во всех четырёх чисел, кроме исходной, сумма всех четырёх четырёх равна нулю. Пусть $(a, b, c, d)$ — произвольная четырёх четырёх суммой. Тогда
$$0 = (a + b + c + d)^2 = a^2 + b^2 + c^2 + d^2 + 2ab + 2ac + 2ad + 2bc + 2bd + 2cd.$$
Рассмотрим теперь четырёх четырёх $(a_1, b_1, c_1, d_1)$, получающийся из нее нажатием кнопки. Для нее
$$a_1^2 + b_1^2 + c_1^2 + d_1^2 = (a - b)^2 + (b - c)^2 + (c - d)^2 + (d - a)^2 = 2(a^2 + b^2 + c^2 + d^2) - 2ab - 2bc - 2cd - 2ad = 3(a^2 + b^2 + c^2 + d^2) - 2ac - 2bd$$
и, так как $2ac \leqslant a^2 + c^2$ и $2bd \leqslant b^2 + d^2$,
$$a_1^2 + b_1^2 + c_1^2 + d_1^2 \geqslant 2(a^2 + b^2 + c^2 + d^2).$$
В исходной четырёх четырёх суммой $(x, y, z, t)$ не все числа равны, поэтому $x_1^2 + y_1^2 + z_1^2 + t_1^2 > 0$. В силу доказанного выше
$$x_n^2 + y_n^2 + z_n^2 + t_n^2 \geqslant 2^{n-1}(x_1^2 + y_1^2 + z_1^2 + t_1^2).$$
Отсюда следует наличие такой четырёх суммой с достаточно большим номером $n$, в котором одно из чисел по модulo больше чем 3·1985. Если это число отрицательно, то в этой же четырёх сумме найдется и положительное число, больше 1985, так как сумма всех чисел в ней равна нулю.

2. Пусть $O$ — произвольная точка плоскости. Для любой точки $X$ плоскости положим $\overrightarrow{OX}=\overrightarrow{X}$. 4. Если все прямые параллельны друг другу, то они делят плоскость на $n+1$ области. Поэтому, число окрашенных области не превыходит $n \leqslant n(n+1)/3$.

Пусть теперь не все прямые параллельны друг друга. Граница каждой области состоит из нескольких отрезков и лучей, принадлежащих разным прямым. Эти отрезки и лучи называем сторонами области. Каждый область имеет не менее двух сторон. Через $m_2$, обозначим число окрашенных области, имеющих две стороны, через $m_3$ — число окрашенных области, имеющих три стороны и т. д. Наконец, через $m_k$ — число окрашенных области с максимальным числом сторонами.

Покажем, что $m_2 \leqslant n$. Граница любой области с двумя сторонами состоит из двух лучей, причем каждый луч может лежать на границе только одной из окрашенных области. Число всех таких лучей не превыходит $2n$ (не более двух на каждой прямой). Следовательно, общее число сторонами окрашенных области с двумя сторонами не превыходит $2n$ или $m_2 \leqslant n$. Каждый из $n$ прямых разбивается остальные не более, чем на $n$ частей (отрезков и лучей). Поэтому общее число всех частей не превыходит $n^2$. Каждый из частей является сторонами не более чем одной из окрашенных области. Следовательно, общее число сторона таких области не превыходит $n^2$, то есть

$$2m_2+3m_3+\dots+km_k \leqslant n^2.$$

Число окрашенных области равно $m_2+m_3+\dots+m_k$. Используя доказанные выше неравенства, находим, что

$$m_2+m_3+\dots+m_k \leqslant \frac{m_2}{3} + \frac{2m_2+3m_3+\dots+km_k}{3} \leqslant
\frac{n}{3} + \frac{n^2}{3} = \frac{1}{3}(n^2+n).$$

(см. «Квант», № 10)
1. Решим одновременную упражнения 1 и 3. Воспользовемся формулой Герона
$$S=\sqrt{p(p-a)(p-b)(p-c)},$$ где $p=\frac{a+b+c}{2}, a, b, c$ — стороны треугольника. Применяем неравенство
$$\sqrt{xyzt} \leqslant \frac{x+y}{2} \cdot \frac{z+t}{2} \leqslant \left(\frac{x+y+z+t}{4}\right)^2,$$
площадем неравенство
$$S=\sqrt{3}\sqrt{\frac{p}{3}(p-a)(p-b)(p-c)} \leqslant \left(\frac{p}{3}\right)^2,$$
из которого и следует утверждение упражнения 3. Применяя формулу $S=p \cdot r$, где $r$ — радиус вписанного круга, получаем неравенство $3\sqrt{3}r \leqslant p$ и неравенство $3\sqrt{3}r^2 \leqslant pr=S$, из которых следует утверждение упражнения 1.
2. Если треугольник, вписанный в круг, не является правлым, то его площад (и периметр) можно увеличить. Поэтому среди таких треугольников экстремальным может быть только правлый. Существование экстремума мы при этом не доказываем.
4. Достаточно доказать неравенство $S \geqslant \frac{h^2}{\sqrt{3}}$, где $h$ — наименьшая высота, и устанавливает, что в равенство оно обращается, лишь когда треугольник правлый.
Из упражнения 3 следует, что $p^2 \geqslant 12\sqrt{3}S=2\sqrt{3}(ah_a+bh_b+ch_c) \geqslant 2\sqrt{3}(a+b+c)h=2\sqrt{3}Ph$, откуда $P \geqslant 2\sqrt{3}h$, $S=\frac{ah_a+bh_b+ch_c}{6} \geqslant \frac{Ph}{6} \geqslant \frac{h^2}{\sqrt{3}}$. Равенство возможно, лишь когда $h_a=h_b=h_c$, то есть для правлого треугольника.
