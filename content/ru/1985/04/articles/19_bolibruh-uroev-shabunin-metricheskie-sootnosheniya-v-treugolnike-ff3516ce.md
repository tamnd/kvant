Метрические соотношения в треугольнике

Кандидат физико-математических наук А. А. БОЛИБРУХ,
Кандидат физико-математических наук В. М. УРОЕВ,
профессор М. И. ШАБУНИН

Опыт проведения экзаменов вузы показывает, что многое абитуренты не обладают достаочными называми в решении геометрических задач. Самые простые планиетрические задачи порой становятся камнем преткновения даже для тех абитурентов, которые успешно справляются с вопросами по алгебре и trigонометрии. Причем это относится не только к задачам, для решения которых необходимо проявить определенную изобретательность, но и к задачам, решаемым с применением стандартных теорем и формул школьного курса, таких, как теорема косинусов, теорема синусов, формулы площи треугольника и др.

В настоящее время рассматриваются задачи, в основном предложении в разные годы на вступительных экзаменах в МФТИ. Из большого материала авторы отбрали задачи, при решении которых использует основные метрические соотношения между элементами треугольника.

Выпишем эти соотношения. Расстояние треугольник ABC и введем следующие обозначения: $a = |BC|$, $b = |AC|$, $c = |AB|$, $R$ — радиус описанной около треугольника ABC окружности, $r$ — радиус вписанной окружности, $h_a$ — длина высоты, опущенной на сторону BC, $S$ — площадь треугольника. Тогда

$$\frac{a}{\sin \hat{A}} = \frac{b}{\sin \hat{B}} = \frac{c}{\sin \hat{C}} = 2R$$

(теорема синусов), (I)

$$a^2 = b^2 + c^2 - 2bc \cos \hat{A}$$

(теорема косинусов), (II)

$$S = \frac{1}{2} h_a a,$$

(III)

$$S = \frac{1}{2} bc \sin \hat{A},$$

(IV)

$$S = \frac{1}{2} (a + b + c) r.$$

(V)

Эти формулы абитурент должны знать, уметь их доказывать, а также применять их при решении задач. Есть и другие формулы, знание которых уже не предусмотрен программил для построения их, но которые часто бывают полезны при решении задач. Например, формула Герона

$$S = \sqrt{p(p-a)(p-b)(p-c)},$$

(VI)

где $p = (a + b + c)/2$ — получиметр треугольника или формула

$$S = \frac{abc}{4R},$$

(VII)

которая легко получается, подставляя значение sin $\hat{A}$, найденное из теоремы синусов (I), в формулу (IV).

Начнем с задачи на применение теоремы синусов.

1. В равноведренном треугольнике ABC ($|AB| = |BC|$) медиана AD и bisсектора CE перпендикулярны. Определите величины угла ADB.

Решение. Пусть $\alpha$ — искомый угол, $O$ — точка пересечения отрезков AD и CE (рис. 1). В $\triangle ADC$ bisсектора CO является одновременно высотой, значит, $\triangle ADC$ — равноведренный и $D\hat{AC} = A\hat{DC} = \pi - \alpha$, $\hat{A} = \hat{C} = 2\alpha - \pi$, $B\hat{AD} = \hat{A} - D\hat{AC} = 3\alpha - 2\pi$. В треугольнике ABD согласно условиям $|BD| = 1/2 |AB|$. Применяя теорему синусов, получаем $\frac{|AB|}{\sin \alpha} = \frac{|BD|}{\sin (3\alpha - 2\pi)}$, откуда $\frac{1}{\sin \alpha} = \frac{1}{2 \sin 3\alpha}$, $2 \sin 3\alpha = \sin \alpha$, $2 \sin \alpha (3 - 4 \sin^2 \alpha) = \sin \alpha$, $\sin^2 \alpha = 5/8$. Но из условия задачи следует, что $D\hat{CO} = \alpha - \pi/2 > 0$, с другой стороны, $\alpha < \pi$, то есть $\pi/2 < \alpha < \pi$, поэтому $\sin \alpha = \sqrt{10}/4$, $\alpha = \pi - \arcsin \sqrt{10}/4$.

Ответ: $\pi - \arcsin \sqrt{10}/4$.

2. В равноведренном треугольнике ABC длинна высоты BD, опущенное на основание, равна h, а радиус описанной окружности равен r. Найдите радиус окружности, описанной около этого треугольника.

Решение. Пусть $O$ — центр вписанной окружности, $E$ — точка касания окружности с отрезком $AB$, $|AC| = b$ (рис. 2). По теореме синусов радиус $R$ описанной окружности равен $\frac{b}{2 \sin \hat{B}}$. Из $\triangle BOE$ находится $\sin \frac{\hat{B}}{2} = \frac{|OE|}{|OB|} = \frac{r}{h-r}$. С другой стороны, $\tg \frac{\hat{B}}{2} = \frac{|AD|}{|BD|} = \frac{b}{2h}$, отсюда
$$b = 2h \text{ tg} \frac{\hat{B}}{2} \text{ и } R = \frac{h \text{ tg} \frac{\hat{B}}{2}}{\sin \hat{B}} = \frac{h}{2 \cos^2 \frac{\hat{B}}{2}} = \frac{(h-r)^2}{2(h-2r)}$$
Ответ: $\frac{(h-r)^2}{2(h-2r)}$.

3. Углы при вершинах $A$ и $C$ треугольника $ABC$ соответственно равны $\pi/4$ и $\pi/6$. Найдите угол между высотой $BD$ и медианой $BE$ этого треугольника.

Решение. Обозначим $|AB| = c$, $|AC| = b$, $DBE = \varphi$ (рис. 3). Тогда $|AD| = c \cos \hat{A} = c \sqrt{2}/2$, $|DE| = |BD| \times \text{tg} \varphi = (c \sqrt{2} \text{ tg} \varphi)/2$. Следовательно, $b/2 = |AE| = |AD| + |DE| = c \sqrt{2} \times (1 + \text{tg} \varphi)/2$. По теореме синусов для $\triangle ABC$ получаем $\frac{c}{\sin \hat{C}} = \frac{b}{\sin \hat{B}}$, где
$$\sin \hat{B} = \sin (\pi - \hat{A} - \hat{C}) = \sin (\hat{A} + \hat{C}) = \sin \frac{\pi}{6} \cos \frac{\pi}{4} + \cos \frac{\pi}{6} \sin \frac{\pi}{4} = \frac{\sqrt{2}}{4} \times (1 + \sqrt{3}).$$
Отсюда находится
$$\frac{c}{1/2} = \frac{4c(1 + \text{tg} \varphi)}{1 + \sqrt{3}}, \text{tg} \varphi = \frac{\sqrt{3} - 1}{2}.$$
Ответ: $\arctg \frac{\sqrt{3} - 1}{2}$.

При решении следующих задач используются теорема косинусов.

4. Биссектрисы $AD$ и $CF$ треугольника $ABC$ пересекают стороны $BC$ и $AB$ в точках $D$ и $F$ соответственно. Найди те длину отрезка $FD$, если $|AC| = 6$, $|AF| = 2$, $|CD| = 3$.

Решение. Обозначим $|BD| = x$, $|BF| = y$ (рис. 4). Воспользовемся важным свойством биссектрисы: биссектриса делит сторону треугольника на части, пропорциональные длинами прилежащих сторон. Таким образом, $|AB|/|AC| = x/3$, $|BC|/|AC| = y/2$ или $(2+y)/6 = x/3$, $(x+3)/6 = y/2$, откуда $x=9/5$, $y=8/5$, $|AB|=18/5$, $|BC|=24/5$. 5. В треугольнике $ABC$: $\hat{B} = \arccos \frac{7}{8}$, $|AC| = b$, а высота, опущенная из вершины $B$, равна сумме двух других высот. Найдите площь треугольника $ABC$.

Решение. Пусть $|AB| = x, |BC| = y$ (рис. 5). Тогда по теореме косинусов $b^2 = x^2 + y^2 - 2xy \cos \hat{B} = x^2 + y^2 - \frac{7}{4}xy$.

Далее, $h_b = \frac{2S}{b}$, $h_x = \frac{2S}{x}$, $h_y = \frac{2S}{y}$, где $S$ — площадь $\triangle ABC$, а $h_b, h_x, h_y$ — его высоты. Так как по условию задачи $h_b = h_x + h_y$, то $\frac{1}{b} = \frac{1}{x} + \frac{1}{y}$ или $x + y = \frac{xy}{b}$, откуда $x^2 + y^2 = \frac{(xy)^2}{b^2} - 2xy$. Отсюда и из уравнения (3) получаем уравнение относительно $z = xy$:

$$b^2 = \frac{z^2}{b^2} - 2z - \frac{\tau}{4}z,$$

откуда $z = xy = 4b^2$. Поэтому $S = \frac{xy \sin \hat{B}}{2} = \sqrt{15}/4 b^2$.

Ответ: $\frac{\sqrt{15}}{4} b^2$.

Замечание к теореме косинусов. С помощью теоремы косинусов легко получить формулу, выражающую длину медианы через длины сторона треугольника. Обозначим $|AB| = c$, $|AC| = b$, $|BC| = a$, длину медианы $AD$ через $m_a$, $BDA = \varphi$ (рис. 6). По теореме косинусов для треугольников $ABD$ и $ADC$ получаем:

$$a^2/4 + m_a^2 - am_a \cos \varphi = c^2,$$
$$a^2/4 + 2m_a^2 - am_a \cos (\pi - \varphi) = b^2.$$

Складывая эти уравнения и использовать то, что $\cos (\pi - \varphi) = -\cos \varphi$, находим $a^2/2 + 2m_a^2 = c^2 + b^2$, откуда

$$m_a = \frac{1}{2} \sqrt{2(b^2 + c^2) - a^2}.$$

6. В треугольнике $ABC$ длинны сторона связанных соотношениям $|BC|^2 + |AC|^2 = 5|AB|^2$. Найдите угол между мединами $AM$ и $BN$.

Решение. Обозначим $|AB| = c$, $|BC| = a$, $|AC| = b$, $NOM = \varphi$, $AM| = m_a$, $BN| = m_b$ (рис. 7). Поскольку в точке пересечения медианы делятся в отношении 2:1, считая от вершины, то согласно формуле (4), получаем:

$$|OM| = \frac{m_a}{3} = \frac{1}{6} \sqrt{2(b^2 + c^2) - a^2},$$
$$ON = \frac{m_b}{3} = \frac{1}{6} \sqrt{2(a^2 + c^2) - b^2}.$$
