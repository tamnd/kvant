3. Углы при вершинах $A$ и $C$ треугольника $ABC$ соответственно равны $\pi/4$ и $\pi/6$. Найдите угол между высотой $BD$ и медианой $BE$ этого треугольника.

Решение. Обозначим $|AB| = c$, $|AC| = b$, $DBE = \varphi$ (рис. 3). Тогда $|AD| = c \cos \hat{A} = c \sqrt{2}/2$, $|DE| = |BD| \times \text{tg} \varphi = (c \sqrt{2} \text{ tg} \varphi)/2$. Следовательно, $b/2 = |AE| = |AD| + |DE| = c \sqrt{2} \times (1 + \text{tg} \varphi)/2$. По теореме синусов для $\triangle ABC$ получаем $\frac{c}{\sin \hat{C}} = \frac{b}{\sin \hat{B}}$, где
$$\sin \hat{B} = \sin (\pi - \hat{A} - \hat{C}) = \sin (\hat{A} + \hat{C}) = \sin \frac{\pi}{6} \cos \frac{\pi}{4} + \cos \frac{\pi}{6} \sin \frac{\pi}{4} = \frac{\sqrt{2}}{4} \times (1 + \sqrt{3}).$$
Отсюда находится
$$\frac{c}{1/2} = \frac{4c(1 + \text{tg} \varphi)}{1 + \sqrt{3}}, \text{tg} \varphi = \frac{\sqrt{3} - 1}{2}.$$
Ответ: $\arctg \frac{\sqrt{3} - 1}{2}$.
