С одной стороны, таких способов $(a + b)^n$: первый ящик можно раскрасть в любой из $a + b$ оттенков, второй (независимо от первого!) — тоже в любой из $a + b$ оттенков, значит, для первых двух ящиков существует $(a + b)(a + b) = (a + b)^2$ возможных раскраски и т. д.

С другой стороны, число раскрасков равно правой части равенства (1). Показем это, сосчитав это число иначе. Сначала найдем число раскраскок, при которых все $n$ ящиков — красные (их, очень/no, — $a^n$); затем найдем число раскраскок, при которыхровно один ящик — синий (их $nba^{n-1}$), либо имеется $n$ способов выбрать ящик, который мы будем красить синей красной, для него имеется $b$ оттенков, и $a^{n-1}$ раскраскок — для оставшихся $n-1$ ящиков); ...; далее найдем число раскраскок, при которых все $n$ ящиков — синее (их $C_n^k b^k a^{n-k}$, либо имеется $C_n^k$ способов выбрать из $n$ ящиков $k$ ящиков, которые мы будем красить синей красной *), для этих $k$ ящиков имеется $b^k$ раскраскок, для оставшихся $n-k$ ящиков существует $a^{n-k}$ раскраскок); ...; наконец, найдем число раскраскок, при которых все $n$ ящиков — синее (их $b^n$). Таким образом, общее число раскраскок равно

$$a^n + nba^{n-1} + \dots + C_n^k b^k a^{n-k} + \dots + b^n,$$

а эта сумма совпадает с правой части формулы (1), которая тем самым доказана.

Если вы хорошо поняли это доказательство, то вы сумете доказать обобщение формулы Ньютона на случай $m$ (натуральных) слагаемых:

$$(a_1 + a_2 + \dots + a_m)^n = a_1^n + \dots + N_{k_1 k_2 \dots k_m}^n a_{k_1}^k a_{k_2}^k \dots a_m^k m + \dots + a_m^n,$$

(*) «Алгебра и начала анализа 9», п. 6.
