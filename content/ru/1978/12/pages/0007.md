⟦folio 5⟧

Рассмотрим теперь некоторый одночлен $q = x_1^{k_1} x_2^{k_2} \dots x_t^{k_t}$ и всевозможные упорядоченные наборы $\langle \bar{c}_1, \bar{c}_2, \dots, \bar{c}_n \rangle$, где $\bar{c}_i \in F_p$ ($i = 1, 2, \dots, n$). Таких наборов $p^n$. Будем считать, что $t \leq n$. тогда для каждой набора можно вычислить значение одночлена $q$, принимаем на этом наборе: нужно подставить вместо $x_1, x_2, \dots, x_t$ первый $t$ чисел набора. Чему равна сумма всех этих $p^n$ значений? (Решенная нами задача о сумме $k$-х степеней является частным случайем этой задачи: $q = x_1^k, n = 1$.) Мы предоставляем читателю исследовать этот вопрос.

Для дальнейшего нам понадобится только, что если $t < n$ или $0 < k_i < p - 1$ для некоторого $i$, то исключая сумма равна $0$. Это вы без труда доказательства сами.

Доказательство теоремы Варинга

Обозначим степень многочлена $R(x_1, x_2, \dots, x_n)$ через $m$, число решений уравнения $R(x_1, x_2, \dots, x_n) = 0$ через $N(R)$. Нам надо из условия $m < n$ вывести, что $N(R)$ делится на $p$.

В множество $M$ всевозможных упорядоченных наборов элементов из $F_p$ длины $n$ рассмотрим подмножество $M_R$ решений уравнения $R(x_1, x_2, \dots, x_n) = 0$. Подмножество $M_R$ состоит из наборов $\langle \bar{c}_1, \bar{c}_2, \dots, \bar{c}_n \rangle$, для которых $R(\bar{c}_1, \bar{c}_2, \dots, \bar{c}_n) = 0$.

Рассмотрим функцию $f_R$, которая каждому элементу $\langle \bar{c}_1, \bar{c}_2, \dots, \bar{c}_n \rangle \in M$ сопоставляет число 1, если $\langle \bar{c}_1, \bar{c}_2, \dots, \bar{c}_n \rangle \in M_R$, и число 0, если $c \langle \bar{c}_1, \bar{c}_2, \dots, \bar{c}_n \rangle \notin M_R$.

(Функция, определяная на некотором многочстве $M$ и принимающая значение 1 на некотором подмножестве $A \subset M$ и значение 0 на остальных элементов из $M$, называется характеристической функцией подмножества $A$. Таким образом, функция $f_R$ является характеристической функцией подмножества $M_R$.) Из самого определения функции $f_R$ следует, что число решений $N(R)$ уравнения $R(x_1, x_2, \dots, x_n) = 0$ равно сумму значений функции $f_R$ по всем элементам множества $M$. Это утверждение, казалось бы, ничего не добавляет к определению $f_R$. Тем не менее читатель увидит, что замена множества $M_R$ функцией $f_R$ является ключевой в доказательстве.

Рассмотрим теперь функцию $f_R$, которая отличается от функции $f_R$ тем, что вместо чисел 1 и 0 принимает на решении и нерешения соответствующего значения $\bar{1}$ и $\bar{0}$ из $F_p$. Сумма $S(\bar{f}_R)$ значений функции $f_R$ по всем наборам $\langle \bar{c}_1, \bar{c}_2, \dots, \bar{c}_n \rangle$ равна классу вычетов $N(R)$ (по mod $p$) числа $N(R)$. Поэтому для доказательства теоремы Варинга достаточно убедиться, что $S(\bar{f}_R) = \bar{0}$.

Воспользовавшись Малой теореме Ферма, представим функцию $f_R$ многочленом. Для этого рассмотрим многочлен $Q(x_1, x_2, \dots, x_n) = \bar{1} - R(x_1, x_2, \dots, x_n)^{p-1}$. Если $R(\bar{c}_1, \bar{c}_2, \dots, \bar{c}_n) \neq 0$, то Малой теореме Ферма $R(\bar{c}_1, \bar{c}_2, \dots, \bar{c}_n) = \bar{0}$. Если $R(\bar{c}_1, \bar{c}_2, \dots, \bar{c}_n) = \bar{0}$, то $R(\bar{c}_1, \bar{c}_2, \dots, \bar{c}_n)^{p-1} = \bar{0}$ и $Q(\bar{c}_1, \bar{c}_2, \dots, \bar{c}_n) = \bar{1}$. Поэтому $f_R = Q$.

Многочлен $Q(x_1, x_2, \dots, x_n)$ является суммой одночленов: $Q = q_1 + q_2 + \dots + q_l$.

Нам достаточно проверить, что суммы значений каждого из одночленов $q_1, q_2, \dots, q_l$ по всем наборам $\langle \bar{c}_1, \bar{c}_2, \dots, \bar{c}_n \rangle$ равны $\bar{0}$. Тогда и сумма $S(f_R) = S(Q)$ будет равна $\bar{0}$, поскольку $S(Q) = S(q_1) + S(q_2) + \dots + S(q_l)$.

Возьем, например, одночлен $q_1 = x_1^{k_1} x_2^{k_2} \dots x_t^{k_t}$. Степень многочлена $Q$ равна $(p - 1) m$. Поэтому степень одночлена $q_1$ меньше $(p - 1) n$ (по условию теоремы $m < n$). Значит, $k_1 + k_2 + \dots + k_t < (p - 1) n$. Из этого неравенства следует, что либо $t < n$, либо среди $k_1, k_2, \dots, k_t$ найдется показатель $k_i$, для которого $0 < k_i < p - 1$. Равенство $S(q_1) = \bar{0}$ следует теперь из результата, сформированного в конце предыдущого раздела.
