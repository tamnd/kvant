Существенным условиям в формулировке задачи является условие положение положения наного более простая и менее интересная задача об освещении сферической планеты несколькими неподвижными точками проекторами. Наименьшее необходимое в этом случае число проекторов — четыре.

Задача о спутниках-солнцах — сугубо математическая. Похожая практическая задача — создание системы глобальной радиосвязи на Земле — решается с помощью запуска трех спутников; правда, при этом не обеспечивает связь с полярными областями Земли.

Решение задачи о спутниках-солнцах. Нетрудно сообщить, что ни одного, ни двух спутников для освещения планеты не хватит — в каждой момент будет существовать неосвещенные точки (доказите это). Показем, что и трех спутников мало.

Действительно, в каждой момент времени на планете найдет две диаметрально противоположные точки $A$ и $B$, которые не освещаются в этот момент спутниками $P_1$ и $P_2$. Таким точеками, например, является концы диаметрально противоположны! Поэтому какая-то из точки $A$ или $B$ не будет в этот момент освещена ни один из спутников.

Хватит ли четырех спутников-солнц? Если окажется, что в некоторых момент времени какие-то три

из четырех спутников $P_1$, $P_2$, $P_3$, $P_4$ будут находиться в одной плоскости с планетой $O$, то полностью применены расчедения предыдущего абзаца. Если же такого уплощения не происходит, надо провать строй пример нужного нам движения или доказывать, что его все-taki нет. Итак, в случае, когда происходит уплощение хотя бы одной тройки спутников, в момент уплощения планата не освещена полностью. Значит, надо выяснить, существуют ли такие положительные угловые скорости $\omega_1$, $\omega_2$, $\omega_3$ и $\omega_4$, при которых никакая не происходит уплощение ни одной тройки спутников. Ответ на этот вопрос нам дает формулированная выше теорема: в любой тройке, выбранной из чисел $\omega_1$, $\omega_2$, $\omega_3$, $\omega_4$, максимальное число должно равняться сумме двух освязихся. Пусть, для определения, $0 < \omega_1 \leqslant \omega_2 \leqslant \omega_3 \leqslant \omega_4$. Тогда для тройки $\omega_1$, $\omega_2$, $\omega_3$ должны быть $\omega_3 = \omega_1 + \omega_2$, для тройки $\omega_1$, $\omega_2$, $\omega_4$ должны быть $\omega_4 = \omega_1 + \omega_2$, откуда $\omega_3 = \omega_4$. Но для тройки $\omega_1$, $\omega_3$, $\omega_4$ должны быть $\omega_4 = \omega_3 + \omega_1$, откуда $\omega_1 = 0$, что противоречит условия $\omega_1 > 0$. Тем самым доказано, что искомых четырех положительных чисел не существует. Следовательно, примера нужного нам движения четырех спутников по круговым орбитам, при котором планета была в каждой моменте положению освещена, построить нельзя; четырех спутников также недостаточно для осуществления поставленной в задаче целы.

Однако при врашающихся по круговым орбитам спутников для полного освещения все планеты в каждой момент времени уже хватет (мы предлагаем читательам самостельно построить соответствующий пример).

Кроме того, мы предлагаем читательам доказать утверждение пункта 2) теоремы для спутника, когда $\omega_1$, $\omega_2$, $\omega_3$ — целые числа. По-видимому, это можно сделать элементарно.
