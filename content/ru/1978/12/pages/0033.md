Таким образом, суммарный заряд $Q$, который получил конденсатор $C_1$ от батареи, равен
$$Q = q_1 + \Delta q = \frac{2 n^2 + n + 1}{(n + 1)^2} C_1 U.$$
Энергия, которую приобретет конденсатор, равна
$$\Pi = \frac{C_1 U^2}{2}.$$
Работа $A$, совершенная батареей при зарядке конденсатора до напряжения $U$, равна
$$A = QU = \frac{2 n^2 + n + 1}{(n + 1)^2} C_1 U^2.$$
Так что КПД равен
$$\eta = \frac{\Pi}{A} = \frac{(n + 1)^2}{2 (2 n^2 + n + 1)}.$$
Чтобы значение $\eta$ было больше 1/2, необходимо, чтобы выполнялось неравенство
$$\frac{(n + 1)^2}{2 n^2 + n + 1} > 1.$$
Отсюда находится что $n < 1$.
Итак, заряжая конденсатор $C_1$ до напряжения $U$, мы добавляем более эффективного использования батареи ($\eta > \frac{1}{2}$), если в описном выше процессе ползуемся дополнительно конденсатором $C_2$, емукость которого меньше $C_1$.
