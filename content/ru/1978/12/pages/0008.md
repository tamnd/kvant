Утверждение: «Если у диофантова уравнения есть ненулевое решение, то у любого приведенного уравнения есть ненулевое решение», не верно. Например, уравнение
$$x^2 + y^2 = 9 = 0$$
имеет ненулевое решение ($x = 3, y = 0$), но по modulo 3 приведенное уравнение
$$x^2 + y^2 = 0$$
таких решений не имеет.

Тем не менее ясно, что если у диофантова уравнения есть ненулевое решение, то для всех $p$, начиная с некоторого, у приведенного уравнения тоже есть ненулевое решение.

Обратное неверно: уравнение
$$x^2 + y^2 + z^2 = 0$$
(6)
по теореме Шевалле имеет ненулевое решение в лию бом $F_p$, а уравнение
$$x^2 + y^2 + z^2 = 0$$
ненулевых решений (не только в $Z$, но и в $R$) не имеет *).

Рассмотрим теперь снова диофантово уравнение
$$R(x_1, x_2, \dots, x_n) = 0$$,
козффициенты которого — целые числа. Интересно знать, каково множество тех простых $p$, для которых существует решение по mod $p$. Ответ на этот вопрос дает замечательная теорема Вейля — Лэнга. Если множество $R(x_1, x_2, \dots, x_n)$ абсолитно приведение, то уравнение $R(x_1, x_2, \dots, x_n) = 0$ имеет решение по простому modulo $p$ для всех $p$, начиная с некоторого.

Под абсолитно приведение многочленом мы будем понимать такой многочлен, который нельзя разложить в произведение двух многочленов по modulo $p$ для всех $p$, начиная с некоторого.

*) Это не очень интересный пример: читатель может проверить, что по modulo 8 уравнение (6) ненулевых решений не имеет. В упомянутой статье М. И. Башмакова указан пример диофантова уравнения ($3x^3 + 4y^3 + 5z^3 = 0$), не имеющего ненулевых решений, для которого приведение уравнение ненулевое решение по лию бому modulo $p$ не имеет.

Условие абсолитной неприводимости в формулировке теоремы существенно: из заданий 2 к статье «Сравнение по простому modulo» следует, что уравнение $x_1^2 + x_2^2 = 0$ разрешимо при $p = 4k + 1$ и неразрешимо при $p = 4k + 3$. Простых чисел вида $p = 4k + 3$ бесконечного много, поэтому заключение теоремы для многочлена $x_1^2 + x_2^2$ не верно. Разумеется, для него неверна и посылака: из разрешимости уравнения $x_1^2 + x_2^2 = 0$ по modulo $p = 4k + 1$ (а простых чисел этого вида тоже бесконечного много) следует, что оно разложимо на множители по этому modulo.

Можно доказать, что «подавляющее большинство» многочленов абсолитно неприводимы.

В отличие от теоремы Варинга, доказательство теоремы Вейля — Лэнга в общем случае очень трудно.

Рассмотрим один очень частный случай уравнения $R(x_1, x_2, \dots, x_n) = 0$: когда многочлен $R$ — первой степени: $R(x_1, x_2, \dots, x_n) = a_1x_1 + a_2x_2 + \dots + a_nx_n + b$ (хотя один из коэффициентов $a_i$ предполагается отличным от 0). Легко видеть, что в этом случае $N(R) = p^{n-1}$. Действительно, можно считать (переставив, если нужно, неизвестен ie), что $a_1 \neq 0$; тогда, придавая $x_2, \dots, x_n$ всевозможные значения из $F_p$ и положив $x_1 = -a_1^{-1}(a_2x_2 + \dots + a_nx_n + b)$, мы получим решение.

Teорему Вейля — Лэнга можно уточнить: при больших $p$
$$|N(R) - p^{n-1}| < c \cdot p^{\frac{n-1}{2}},$$
где $c$ — коэффициент число, зависит от многочлена $R$.

Первоначальное доказательство Вейля основано на открытых им глубоких связях между, казалось бы, дальнейми вопросами: дискретной, и даже конечной, задачей о числе решения уравнения $R(x_1, x_2, \dots, x_n) = 0$ по простому modulo и геометрическим строением непрерывного многочлена комплисных решений этого уравнения, то есть тех наборов комплисных чисел $\langle d_1, d_2, \dots, d_n \rangle$, для которых $R(d_1, d_2, \dots, d_n) = 0$.

Недавно элементарное (не использованное никаких косвенных методов), но тем не менее весба сложное доказательство теоремы Вейля — Лэнга для сверлдовский математик С. А. Степанов.
