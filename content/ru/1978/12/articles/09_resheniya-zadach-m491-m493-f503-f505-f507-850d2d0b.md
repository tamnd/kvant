М491. Расстояние геометрической прорезиса, все цлены коморой — цлены числа. (Например, 16, 24, 36, 54, 81.)
a) Докажите, что сумма квадратов трех последовательных целей прорезиса делится на сумму этих целей.
b) При каких намуральных n сумма квадратов n последовательных целей прорезиса делится на сумму этих n целей?

Мы вначале решим задачу M491 — докажем утверждение пункт a) и ответим на вопрос пункт 6), а затем сформулируем утверждение, из которого будет следовать оба пункта задачи.

a) Обозначим три последовательных целей нашей прорезсии через $a_1, a_2, a_3$ (все $a_i$ — цлены числа). Поскольку $a_1 a_3 = a_2^2$, получаем
$$\left( a_1 + a_2 + a_3 \right)^2 = \left( a_1^2 + a_2^2 + a_3^2 \right) + 2 a_2 \left( a_1 + a_2 + a_3 \right),$$
следовать
$$a_1^2 + a_2^2 + a_3^2 = \left( a_1 + a_2 + a_3 \right) \left( a_1 - a_2 + a_3 \right)$$
— что и требовалось доказать.

6) Легко приведсти пример геометрической прорезсии, у которой сумма квадратов четырех последовательных целей не будет делиться на сумму этих целей: у прорезсии 1, 2, 4, 8, 16, ... сумма $1^2 + 2^2 + 4^2 + 8^2 = 85$ не делится на сумму $1 + 2 + 4 + 8 = 15$. Вообщество, у этой прорезсии сумма квадратов первых 2k целей $1 + 2^2 + 2^4 + \dots + 2^{4k-2} = (2^{4k} - 1)/3$ не делится на сумму этих целей $1 + 2 + 2^2 + \dots + 2^{2k-1} = 2^{2k} - 1$, поскольку $2^{2k} + 1$ не делится на 3 или каком $k$. Поэтому четны $n$ не годятся. Если же $n$ нечетно ($n = 2k + 1$), то сумма квадратов $n$ последовательно четен на所学 прорезсии обязаательно делится на сумму этих целей. Справедливо это утверждение вытекает изложства
$$a_1^2 + a_2^2 + \dots + a_{2k+1}^2 = \left( a_1 + a_2 + \dots + a_{2k+1} \right) \times \left( a_1 - a_2 + a_3 - a_4 + \dots - a_{2k} + a_{2k+1} \right),$$
которое нетрудно доказать, например, по индукции.

А теперь сформулируем и докажем утверждение, о котором было сказано выше.

Теорема. Если числа $k$ и $n$ взаимно просты, то сумма $k-x$ степеней $n$ последовательно целей прорезсии, все цлены коморой — цлены числа, обязаательно делится на сумму этих целей.

(Поскольку числа 3 и 2 взаимно просты, из этого утверждения следует пункт a) задачи M491 и ответ на пункт b) — при нечетных $n$.)
Доказательство. Обозначим эти $n$ последовательных целей прорезсии через $a_1, a_2, \dots, a_n$. Мы хотим доказать, что сумма $a_1^k + a_2^k + \dots + a_n^k$ делится на сумму $a_1 + a_2 + \dots + a_n$ (при условии, что $k$ и $n$ взаимно просты). Пусть $q$ — знаменатель прорезсии. Тогда
$$a_1 + a_2 + \dots + a_n = a_1 (1 + q + \dots + q^{n-1}),$$
$$a_1^k + a_2^k + \dots + a_n^k = a_1^k (1 + q^k + \dots + q^{(n-1)} k).$$
Доказем, что если $k$ и $n$ взаимно просты, то многочлен $1 + x^k + \dots + x^{n-1}$ делится на многочлен $1 + x + \dots + x^{n-1}$.*) При доказательстве нам понадобится две вспомогательные леммы.

*) Здесь и всиду ниже, говоря о делимости многочленов, мы имеем в виду, что все коэффициенты частного — целого числа.

Лемма 1. Если числа $k$ и $n$ взаимно просты, то числа $k, 2k, 3k, \dots, (n-1)$ $k$ при делении на $n$ дают разные остатки.

Лемма 2. Если числа $l$ и $m$ дают одинаковые остатки при делении на $n$, то многочлен $x^l - x^m$ делится на многочлен $1 + x + \dots + x^{n-1}$.

Лемма 1 доказывает метод «от противного». В самом деле, если при некоторых $i$ и $j$ ($0 < i < j < n$) числа $ik$ и $jk$ дают одинаковый остаток при делении на $n$, то число $(j-i)$ $k$ нацело делится на $n$. Но число $j-i < n$; значит, числа $k$ и $n$ должны иметь общий делитель, отличный от единицы, — противоречие с взаимной простой.

Так как число различных остатков (не нулевых!) от деления на $n$ равно $n-1$, из леммы 1 следует, что если числа $k$ и $n$ взаимно просты, то среди остатков от деления на $n$ чисел $k, 2k, \dots, (n-1)$ $k$ все числа от $1$ до $n-1$ встречются по одному разу.

Докажем лемму 2. Пусть $l > m$ и $l = m+pn$. Многочлен $x^m - x^l = (1-x^{pn})x^m$ делится на $1-x^n$:

$$1-x^{pn} = (1-x^n) (1+x^n+x^{2n}+\dots+x^{(p-1)n}),$$

а $1-x^n$ делится на $(1-x)$, причем

$$(1-x^n) = (1-x) (1+x+x^2+\dots+x^{n-1}).$$

Отсюда следует утверждение леммы 2.

Перейдем теперь к доказательству того, что многочлен $1+x^k + \dots + x^{(n-1)k}$ делится на $1+x + \dots + x^{n-1}$. Обозначим через $k_i$ остаток от деления на $n$ числа $ik$. Тогда по лемме 2 многочлен $(x^k - x^{k_1}) + (x^{2k} - x^{k_2}) + \dots + (x^{(n-1)k} - x^{k_{n-1}})$ делится на многочлен $1+x + \dots + x^{n-1}$. Остается заметить, что в силу следствия из леммы 1 многочлен $1+x^{k_1} + x^{k_2} + \dots + x^{k_{n-1}}$ совпадает с многочленом $1+x + \dots + x^{n-1}$ и, значит, делится на него. Таким образом,

$$1+x^k + x^{2k} + \dots + x^{(n-1)k} = (1+x + \dots + x^{n-1}) \times (c_0 + c_1x + c_2x^2 + \dots + c_px^p),$$

где $p = (k-1)(n-1)$, и $c_0, c_1, \dots, c_p$ — некоторые числа. Следовательно,

$$a_1^k + a_2^k + \dots + a_n^k = a_1^k (1+q^k + \dots + q^{(n-1)k}) = a_1^k (1+q + \dots + q^{n-1}) (c_0 + c_1q + c_2q^2 + \dots + c_pq^p) = (a_1 + a_2 + \dots + a_n) \times (c_0 a_1^{k-1} + c_1 a_1^{k-1} q + \dots + c_p a_1^{k-1} q^p).$$

Для завершения доказательства теоремы достаточно показать, что числа $a_1^{k-1}q, a_1^{k-1}q^2, \dots, a_1^{k-1}q^p$ — целые. Действительно, числа $a_1^{k-1}q$ — целое, поскольку оно представляется в виде произведения целых чисел: $a_1^{k-1}q = a_1^{k-2}a_2$. Аналогично, $a_1^{k-1}q^2 = a_1^{k-2}a_3$, $\dots, a_1^{k-1}q^p = (a_1q^{n-1})^{k-1} = a_n^{k-1}$.

Попробуйте построить примеры, показывающие, что требование взаимной простоты $k$ и $n$ в утверждении теоремы существует.

Возьемчетверть кругга единчного радиуса: $O$ — центр кругга, $[OA]$ — радиус, $|OA| = 1$ (рис. 6). Разделим отрезок $OA$ на $n$ конгрузных частей ($n$ — произвольное натуральное число). На получившихся первых $n - 1$ отрезках деления (считая от точки $O$) построим по прямойolgныйку так, чтобы при в вые верхние вершины всех прямогольников лежали на дуге окружности $BA$, ограничивающей нашу «четверть кругга» (см. рис. 6). Мы получим $n - 1$ прямогольников, сумма площадей которых меньше четверти кругга единчного радиуса, то есть меньше $\frac{\pi}{4} < 0,79$.

Поскольку эта сумма равна
$$\frac{1}{n} \sqrt{1 - \left(\frac{1}{n}\right)^2} + \frac{1}{n} \sqrt{1 - \left(\frac{2}{n}\right)^2} + \dots +$$
$$+ \frac{1}{n} \sqrt{1 - \left(\frac{n - 1}{n}\right)^2} = \frac{1}{n^2} \left(\sqrt{n^2 - 1} + \sqrt{n^2 - 2^2} + \dots + \sqrt{n^2 - (n - 1)^2}\right),$$

из сказанного следует правое неравенство.

Чтобы доказать левое неравенство, поступим следующим образом. Построим по прямогольнику теперь уже на всех отрезках, получивших при делении $[OA]$—всего $n$ прямогольников, причем так, чтобы все левые верхние вершины прямогольников лежали на дуге $BA$ окружности (рис. 7). Мы получим изображенную на рисунке 7 ступенчатую фигуру, площадь которого уже больше шести четверти кругга единчного радиуса, то есть больше $\frac{\pi}{4} > 0,785$.

Площадь ступенчатой фигуры равна сумме площадей $n$ прямогольников с основаниями длины $\frac{1}{n}$ и высотами длины
$$1, \sqrt{1 - \left(\frac{1}{n}\right)^2}, \sqrt{1 - \left(\frac{2}{n}\right)^2}, \dots, \sqrt{1 - \left(\frac{n - 1}{n}\right)^2}$$

соответственно:
$$\frac{1}{n} \left(1 + \sqrt{\frac{n^2 - 1}{n^2}} + \sqrt{\frac{n^2 - 2^2}{n^2}} + \dots + \sqrt{\frac{n^2 - (n - 1)^2}{n^2}}\right).$$

Итак,
$$\frac{1}{n^2} \left(n + \sqrt{n^2 - 1} + \sqrt{n^2 - 2^2} + \dots + \sqrt{n^2 - (n - 1)^2}\right) > 0,785,$$

откуда
$$0,785n^2 - n < \sqrt{n^2 - 1} + \sqrt{n^2 - 2^2} + \dots + \sqrt{n^2 - (n - 1)^2}.$$
