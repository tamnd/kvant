Приведенные ниже вопросы адресованы прежнее всего тем из вас, кто в этом году окончил X класс и собирается поступать вуз — проверьте себя перед экзаменами! Из пяты ответов (а, 6, в, г или д) всякий раз нужно выgbать единственный верный.

Математика

1. Какая из указанных на рисунке 1 прямых (а, 6, в, г, д) является графиком уравнения $2x + 3y + 1 = 0$?

2. Какое из указанных множества является множество решений неравенства $\log_{1/3} x > 0$?

a) $|0; +\infty[; 6)$ $|1; +\infty[; b)$ $|1/3; +\infty[; r)$ $|0; 1[; d)$ $|0; 1/3[$.

3. При каких значениях $a$ справедливо соответствие $\exp(\ln(\ln a)) = a$?

a) Ни при каких; 6) при любых; b) при $a > 0$; г) при $a > 1$; д) при $a > e$.

4. Какая из указанных на единственной окружности (рис. 2) точек (а, 6, в, г) отвечает значению $\varphi = 1820^\circ$?

d) Нужная точка не указана.

5. Расположите числа $c = \cos 1000^\circ$, $s = \sin 1000^\circ$, $t = \tg 1000^\circ$ в порядке возрастания.

a) $t < c < s$; 6) $c < s < t$; b) $t < < s < c$; г) $s < c < t$; d) $s < t < c$.

6. Чему равна произвольная функция $f(x) = \sin(x^2)$?

a) $2\sin x$; 6) $\sin 2x$; b) $\cos 2x$; г) $2x\sin(x^2)$; d) $2x\cos(x^2)$.

7. Какая из указанных функций является первообразной для функции $f(x) = -\cos 2x$?

a) $-\sin 2x$; 6) $-2\sin 2x$; b) $-\frac{1}{2}\sin 2x$; г) $\frac{1}{2}\sin 2x$; d) $2\sin 2x$.

8. Сколько существует первообразных для функции $f(x) = e^{x^2}$, график которых проходит через точку $(c; 0)$, где $c$ — заданное число?

a) Ни одной; 6) одна; b) две; г) бесконечного много; d) ответ зависит от значения $c$.

9. Скалярное произведение двух векторов равно —1. Чему может равняться величина угла $\varphi$ между этими векторами?

a) $\varphi = 0^\circ$; 6) $\varphi = 90^\circ$; b) $\varphi = 180^\circ$; г) $0^\circ \leqslant \varphi \leqslant 90^\circ$; d) $90^\circ < \varphi \leqslant 180^\circ$.

13. Площадь боковой поверхности правлевой парамиды равна 2. В каких пределах может заключаться площадь $S$ полной поверхности этой парамиды?
а) $S > 2$; б) $S > 4$; в) $2 < S < 4$; г) $3 < S < 4$; д) ответ зависит от числа боковых граней парамиды.
