Конечно, пусть, который был выбран, далеко не единственный. В письме читателя А. Н. Броцкого из Кнева предлагается другой подход: вместо того, чтобы из решения задачи для $n = k$ получать решение задачи для $n = k + 1$ или $n = k + 2$, попробуем из решения задачи для некоторого $n$ получить другие решения задачи для того же самого $n$. Броцкий предложил следующее теорему:

Пусть $(x_1, \dots, x_{n-2}, x_{n-1}, x_n)$ — решение, получающей по лемме 2 из решения $(x_1, \dots, x_{n-2}, x_{n-1})$ и $\frac{f_{n-2}x_n + 1}{x_{n-1}} = d_1d_2$.

Если система уравнений

$$\begin{cases} f_{n-2}x + 1 = d_1y, \\ f_{n-2}y + 1 = d_2x \end{cases}$$

имеем решение в натуральных числах, то набор $(x_1, \dots, x_{n-2}, x, y)$ может являться решение задачи.
