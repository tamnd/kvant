М462. Плоскость пересекаем боковые ребра правильной четырехугольной парамиды в точках, отстоящих от вершины на расстояния a, b, c и d (рис. 1). Докажите, что

$$\frac{1}{a} + \frac{1}{c} = \frac{1}{b} + \frac{1}{d}.$$

Рис. 2.

М463. Данные натуральные числа $x_1, x_2, \dots, x_m, y_1, y_2, \dots, y_n$. Суммы $x_1 + x_2 + \dots + x_m$ и $y_1 + y_2 + \dots + y_n$ равны между собой и меньше mn. Докажите, что в равенстве $x_1 + x_2 + \dots + x_m = y_1 + y_2 + \dots + y_n$ можно вычеркить часть слагаемых макс, чтобы снова получилось верное равенство.

$$4 + 5 + 5 = 1 + 1 + 6 + 6 \quad (\text{неЛЬЗЯ}),$$
$$3 + 3 + 4 + 5 = 1 + 1 + 6 + 7 \quad (\text{МОЖНО})$$

Обозначим через $\alpha$ величины угла, которые образует высота парамиды с боковыми ребрами, через $A, B, C, D$ — точки пересечения секущей плоскости с боковыми ребрами и высотой, через $H$ — вершину парамиды (рис. 1). Ясно, что между длинами $a, b, c$ и $d$ должны быть неокоторое соответствие: ведь через три точки $A, B, C$ проходит единственная плоскость, следовательно, $d$ можно выразить через $a, b$ и $c$. Получить такое соответствие, можно, выразив длину общей бисекторицы $HK$ в каждом из треугольников $AHC$ и $BHD$ через угол $\alpha$ и длины их сторон: $a, c$ (в одном) и $b, d$ (в другом) и приравняв результаты. Именно так и получится треугольное равенство.

Для того чтобы получить нужную формулу длины бисекторицы $l = |HK|$ в треугольнике $AHC$, воспользуемся тем, что $S(AHC) = S(AHK) + S(KHC)$ (рис. 2). Умножив на 2, получим

$$ac \sin 2\alpha = al \sin \alpha + cl \sin \alpha,$$

откуда

$$\frac{2\cos \alpha}{l} = \frac{1}{a} + \frac{1}{c}.$$

Аналогично из треугольника $BHC$

$$\frac{2\cos \alpha}{l} = \frac{1}{b} + \frac{1}{d}.$$

Отсюда

$$\frac{1}{a} + \frac{1}{c} = \frac{1}{b} + \frac{1}{d}.$$

Н. Васильев

Будем вести доказательство индукцией по $k = m + n$. Так как $x_1 + x_2 + \dots + x_m \geq m, y_1 + y_2 + \dots + y_n \geq n$, то mn > m, mn > n, открываем $m \geq 2, n \geq 2, k \geq 4$. Если $k = 4$, то есть $m = n = 2, x_1 + x_2 = y_1 + y_2 < 4$, то хотя бы одно из чисел $x_1, x_2$ равно 1 и хотя бы одно из чисел $y_1, y_2$ равно 1. Так что для $k = 4$ утверждение задачи справедливо. Предположим, что утверждение доказано для $m = n = k$, и доказем его для $m + n = k + 1$.

Пусть $x_1$ — наиболее из чисел $x_1, x_2, \dots, x_m, y_1$ — наиболее из чисел $y_1, \dots, y_n$ ($m + n = k + 1$). Если $x_1 = y_1$, то вычеркиваем $x_1$ и $y_1$. Пусть $x_1 > y_1$. Расстояние равенство

$$(x_1 - y_1) + x_2 + \dots + x_m = y_2 + \dots + y_n,$$

(*) содержащшее все $m + n - 1 = k$ слагаемых. Чтобы привести к нему индукционное предложение, нужно проверить, что $y_2 + \dots + y_n < m(n - 1)$. Положим $S = y_1 + y_2 + \dots + y_n$. Тогда $y_1 \geq \frac{S}{n}$ и, следовательно,

$$y_2 + \dots + y_n < S - \frac{S}{n} = S \cdot \frac{n - 1}{n}.$$

Так как $S < mn$, то $y_2 + \dots + y_n < mn \cdot \frac{n - 1}{n} = m(n - 1)$.

Вычеркием в равенстве (*) часть слагаемых так, чтобы снова получилось верное равенство (это можно сделать по предположению индукции); мы получим либо исключаем, либо равенство, содержащшее в левой части разность $x_1 - y_1$. В последнем случае нужно $y_1$ перевести в правильную часть.
