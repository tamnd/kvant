1. Повторение

- А разве ты не видишь?
- Нет.
- И я тоже!

Изагровора Иа·Иас Винни Пухом*)

С чего же начать? Прежде всего — с ответов в школьных вариантах задачи (n=2, 3, 4). Выпишем эти ответы в таблицу:

| n = 2 | (1, 1) | (1, 2) | (2, 3) | |
| :--- | :--- | :--- | :--- | :--- |
| n = 3 | (1, 1, 1) | (1, 1, 2) | (1, 2, 3) | (2, 3, 7) |
| n = 4 | (1, 1, 1, 1) | (1, 1, 1, 2) | (1, 1, 2, 3) | (2, 3, 7, 43) |

Не правда ли, решение для различных n оцень похожи? Они образуют вертикальные серии и получаются добавлением единиц. Это наблюдение распространяется на всевозможные n с помощью следующей оцененной леммы:

Лемма 1. Пусть набор чисел (x₁, x₂, ..., xₙ) является решением задачи для n=k. Тогда набор чисел (x₁, x₂, ..., xₙ, 1) — решение задачи для n=k+1. И набором: если среди k+1 чисел, являющихся решением задачи для n=k+1, имеется единица, мо, убрав ее из набора, получим решение задачи для n=k.

А какрождаются новые серии: (2, 3), (2, 3, 7), ...?

Пусть (x₁, ..., xₙ) — решение задачи для n=k. По условию задачи, если (x₁, ..., xₙ, xₙ+1) — решение задачи для n=k+1, то x₁ ... xₙ+1 + 1 = Cxₙ+1, где C — неокоторое натуральное число. Попробуем положить C равным единице (так получаются числа 3=2+1, 7=2·3+1, 43=2·3·7+1). Докажем такую лемму:

Лемма 2. Если набор чисел (x₁, ..., xₙ) — решение задачи для n=k, то набор (x₁, ..., xₙ, xₙ+1) — решение задачи для n=k+1.

*) Все эпиграфы взяты из сказки Милна «Винни Пух и Все, Все, Все».

При помощи лемм 1 и 2 из каждой решения задачи для n=k могут быть получены два решения задачи для n=k+1. На рисунке 1 показано, как из решения задачи для n=2 при помощи леммы 1 (красные стрелки) и при помощи леммы 2 (синные стрелки) таким способом получаются решения задачи сначала для n=3, а затем — для n=4.

Ниоткуда не следует, что таким путем мы получим все решения. Впрочем, легко доказать, что набора, указанным на рисунке 1, исчерпываются все решения нашей задачи для n=2, 3, 4. К сожалению, из решения для n=4 таким способом получаются не все решения для n=5; кроме решения (2, 3, 7, 43, 1807), получающегося по решетту леммы 2, есть еще такое: (2, 3, 7, 47, 395).
