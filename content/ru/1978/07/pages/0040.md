И. Слободецкий

Ф479. Для определения неизвестного объема $V_1$ баллона I собиратом схему, приведенную на рисунке 5. Объем баллона II равен $V_2$ и $V_2 \leq V_1$. Сначала система откачивается до давления $p_0$, близко к нулю. Затем закрывают кран B и заполняют баллон II газом до давления $p_0$. После этого закрывают кран A, открываюм кран B и измеряюм установившееся в системе давления $p_1$ манометром C. Затем при закрытом кране B вынь направляюм баллон газом до давления $p_a$, открываюм кран B и измеряюм установившееся в системе давления $p_2$. Эту операцию повторяют n раз. Покажите, что отношение $\frac{p_n - p_0}{np_a}$ есть величины по стойнная и равная $\frac{V_2}{V_1 + V_2}$.

Из условия эксперимента с помощью закона Бойля — Марпорта получается система n уравнений
$$p_0 V_1 + p_a V_2 = p_1 (V_1 + V_2),$$
$$p_1 V_1 + p_a V_2 = p_2 (V_1 + V_2),$$
$$p_{n-1} V_1 + p_a V_2 = p_n (V_1 + V_2).$$
Эта система позволяет выразить все $p_i$ ($i = 1, 2, \dots, n$) через $p_0$ и $p_a$. Действительно,
$$p_i = \frac{p_{i-1} V_1 + p_a V_2}{V_1 + V_2},$$
откуда
$$p_i - p_a = \frac{V_1}{V_1 + V_2} (p_{i-1} - p_a) = \alpha (p_{i-1} - p_a),$$
где $\alpha = \frac{V_1}{V_1 + V_2}$. Следовательно,
$$p_{i-1} - p_a = \alpha (p_{i-2} - p_a), p_{i-2} - p_a = \alpha (p_{i-3} - p_a)$$ и т. д.
Таким образом, $p_n - p_a = \alpha^n (p_0 - p_a)$, откуда
$$p_n = p_a + \alpha^n (p_0 - p_a),$$
$$p_n - p_0 = (p_a - p_0)(1 - \alpha^n).$$
Но $1 - \alpha^n = (1 - \alpha)(1 + \alpha + \alpha^2 + \dots + \alpha^{n-1}) \approx n \frac{V_2}{V_1 + V_2}$ (поскольку $V_1 \gg V_2$ и, следовательно, $\alpha$ близко к единице). Значит,
$$p_n - p_0 \approx (p_a - p_0) n \frac{V_2}{V_1 + V_2},$$
$$\frac{p_n - p_0}{n (p_a - p_0)} \approx \frac{V_2}{V_1 + V_2}.$$
Если $p_0 \ll p_a$, то
$$\frac{p_n - p_0}{np_a} \approx \frac{V_2}{V_1 + V_2}.$$
