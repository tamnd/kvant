Предположим сначала, что $(x_1, \dots, x_k)$—решение задачи для $n = k$. Тогда

$$\frac{1}{x_1} + \dots + \frac{1}{x_k} + \frac{1}{f_k} = A.$$ (3)

Пусть $(x_1, \dots, x_k, x_{k+1}, x_{k+2})$—решение задачи для $n = k + 2$ и $x_{k+1} \neq 1, x_{k+2} \neq 1$. Оказывается, и в этом случае

$$\frac{1}{x_1} + \dots + \frac{1}{x_k} + \frac{1}{x_{k+1}} + \frac{1}{x_{k+2}} + \frac{1}{f_k x_{k+1} x_{k+2}} = A$$ (4)

с тем же $A$.

Следовательно,

$$\frac{1}{x_{k+1}} + \frac{1}{x_{k+2}} + \frac{1}{f_k x_{k+1} x_{k+2}} = \frac{1}{f_k},$$ (5)

откуда

$$x_{k+2} = f_k + \frac{f_k^2 + 1}{x_{k+1} - f_k}.$$ (6)

Поскольку $x_{k+2}$ должно быть целым, число $d = x_{k+1} - f_k$ является делителем числа $f_k^2 + 1$. Итак,

$$\begin{cases} x_{k+1} = f_k + d, \\ x_{k+2} = f_k + \frac{f_k^2 + 1}{d}. \end{cases}$$ (7)

Обозначим теперь через $d$ произвольный делитель числа $f_k^2 + 1$ и определим числа $x_{k+1}, x_{k+2}$ равенствами (7). Тогда для чисел $f_k, x_{k+1}, x_{k+2}$ выполняется (6), а значит, и (5). Из (3) и (5) следует (4). Значит, расширенный набор $(x_1, \dots, x_k, x_{k+1}, x_{k+2})$ является решением нашей задачи для $n = k + 2$. Итак, нами доказана.

Лемма 3. Пусть $(x_1, \dots, x_k)$—решение задачи для $n = k, f_k = x_1 \dots x_k$ и $d$—делитель числа $f_k^2 + 1$. Тогда набор $(x_1, \dots, x_k, f_k + d, f_k + \frac{f_k^2 + 1}{d})$ является решением задачи для $n = k + 2$. И наоборот: если решение задачи для $n = k$ добавленем двух чисел $n = k$ добавленем двух чисел, отличных от 1, то добавленные числа удовлетворяют равенствам (7).

Таким образом, если решение задачи для $n = k + 2$ получается добавленем двух чисел к решению задачи для $n = k$, то оно образуется либо по лемме 2, либо по лемме 3.

Два делителя $y f_k^2 + 1$ всегда: это 1 и $f_k^2 + 1$. Однако легко видеть, что для таких делителей лемма 3 не дает ничего нового по сравнению с лемкой 2. Но затем, если $f_k^2 + 1$ не является простым числом, то лемма 3 дает начало новой серии решений $(x_{k+3}$ можно строить снова по лемме 2 и т. д.). Например, для решения (2, 3, 7) имеем $f_k^2 + 1 = 1765 = 5 \cdot 353$, и мы получаем из него по лемме 3 решение (2, 3, 7, 47, 395), которое мы упоминали в п. 1.
