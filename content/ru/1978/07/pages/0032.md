Область операций теперь задается неравенствами

$$0 \leq x \leq a, \ 0 \leq y \leq b, \ 0 \leq z \leq c,$$

которые, как правило, определяют правильный или неправильный шестиугольник, ограниченный шестью прямыми

$$x = 0, \ x = a, \ y = 0, \ y = b, \ z = 0, \ z = c.$$

Но в частиных случаях эта область может превращаться в пятнуюугольник, трапецю, параллелограмм или (как мы уже видели) охватывает весь равносторонний треугольник.
