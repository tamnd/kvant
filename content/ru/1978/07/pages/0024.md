Очень простые рекуррентные формулы получаются, если помещить еще одну единшую передрядом 1, 2, 5, 14, ... (Получимряд 1, 1, 2, 5, 14...) Пусть $k$ — последнее вычисленное число Каталана, а $n$ — номер следующего числа. Тогда это число вычисляется по формуле

$$\frac{k (4n - 6)}{n}.$$

Современник Эйлера Иоганн Андреас фон Сегнер получил загадочно-reкуррентную формулу для последовательности Каталана вида 1, 1, 2, 5, ... Запишем в ряд все уже найденные числа Каталана, а поднимим запишем те же числа в обратном порядке. Умножим каждое верхнее число на соответствующее нижнее и сложим получшиеся произведение; результат и будет следующим числом Каталана. Например,

$$\frac{x \cdot 112514}{145211} = \frac{14+5+4+5+14}{42}$$

Задача Эйлера о триангуляции многоугольника в некотором смысле изоморфна задачам, казалось бы, совсем с ней не связанным. Сам Эжен Шарль Каталан, белгийский математик, именем которого называется последовательность, в 1838 году решил следующее задачу. Пусть у нас имеется целочка из $n$ букв, расположенных в заданном порядке. Необходимо расставить $n-1$ пару скобок таким образом, чтобы внутри каждой пары стоялоровно два «выражения». Эти спаренных выражениями могут быть либо две соседние буквы, либо буква и соседнее выражение в скобках, либо два соседних выражения. Сколькими способами могут быть расставлены скобки?

Для двух букв $a, b$, имеется только одна возможность: $(ab)$. Для трех букв таких возможности уже две: $((ab) c)$ и $(a (bc))$. Для четырех букв количество способов увеличивается до пяты: $((ab) (cd)), (((ab) c) d), (a (b (cd))), (a ((bc) d))$ и $((a (bc)) d)$.
