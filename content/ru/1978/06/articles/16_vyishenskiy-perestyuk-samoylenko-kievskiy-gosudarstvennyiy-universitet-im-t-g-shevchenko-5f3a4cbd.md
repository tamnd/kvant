Matematika

Вариант письменного экзамена
Механико-математический факультет

1. В правильную четырехугольную парамиду, боковые грани которого наклоны к плоскости основания под углом ф, вписан цилиндр (одно основание цилиндра лежит в плоскости основания парамиды, а окружность второго его основания имеет по одной обшей точке с каждой боковой граними). Радиус основания цилиндра и его высота равны r. Вычислить объем парамиды. При каком значении угла ф объем парамиды наименьший?

2. Вычислить площадь фигуры, ограниченной графиками функций

$$y = \frac{|4 - x^2|}{4} \text{ и } y = 7 - |x|.$$

3. Решить неравенство

$$\sqrt{\log_2^2 x + \log_1 x^2 - 3} > \sqrt{5}(\log_4 x^2 - 3).$$

4. Сколько есть четырехначных чисел, запись которых в десятичной системе счисления содержит не более двух разных цифр?

Физический факультет

1. Вокруг шара радиуса r описана правильная треугольная парамида с высотой H. Вычислить площадь боковой поверхности парамиды. При каком H эта площадь наименьшая? Найти наименьшее значение площади.

2. При каких значениях x производная функция

$$y = \sin 2x + 10\cos x - 6x$$

равна нулю?

3. Найти предел

$$\lim_{n \to \infty} \frac{n\sqrt{1 + 3 + 5 + \dots + (2n - 1)}}{2n^2 + n + 1}.$$

4. На плоскости даны две взаимно перpendикулярные прямые. Найти множество всех тех плоскостей, произведение расстояний от которых до данных прямых равно сумме этих расстояний.

Задание устного экзамена

1. Решить уравнение

$$\sin |x| = |\sin x|.$$

2. Решить неравенство

$$\sqrt{4 - x^2} + \frac{1}{x} \geq 0.$$

3. Сколько корней имеет уравнение

$$x^5 = 5x + 2a$$

в зависимости от параметра a?

4. Сколько решений имеет система уравнения

$$\begin{cases} |x| + |y| = 1, \\ x^2 + y^2 = a \end{cases}$$

в зависимости от параметра a?

5. Изображить в прямойольной системе координат множество точки

$$\begin{cases} (x; y) | \log \left( |x| - \frac{1}{2} \right) (x^2 + y^2) \leq \log \left( |x| - \frac{1}{2} \right)^4 \end{cases}$$

6. Найти все значения a, при которых многожество

$$\{(x; y) | x^2 + y^2 + 2x \leq 1 \} \cap \{(x; y) | x - y + a = 0\}$$

содержит только одну точку. Найти эту точку.

7. Построить график функции

$$y = \begin{cases} 1 - \sqrt{1 - x^2}, \text{ если } x \leq 1, \\ 1 + \log \frac{1}{2} x, \text{ если } x > 1. \end{cases}$$

8. Доказать, что функция

$$f(x) = \frac{2}{3} x^9 - x^6 + 2x^3 - 3x^2 + 6x - 1$$

monotonно возрастает на R.

9. Найти все значения a, при которых функция

$$f(x) = \frac{a^2 - 1}{3} x^3 + (a - 1) x^2 + 2x + 1$$

возрастает для всех x ∈ R.

10. Пусть x₁ и x₂ — соответствие, точка максимума и точка минимума

$$f(x) = 2x^3 - 9ax^2 + 12a^2x + 1.$$

При каких a x₁² = x₂²?

11. При каких a функция

$$f(x) = \frac{a}{3} x^3 + (a + 2) x^2 + (a - 1) x + 2$$

имеет отрицательную точку минимума?

12. При каких значения x образуется в ноль та из первогоразных функций

$$f(x) = \pi \sin \pi x + 2x - 4,$$

которая при x = 1 имеет значение 3?

13. Вычислить площад фигуры, ограниченной графиками функций

$$y = 2 + \sin x \text{ и } y = 1 + \cos^2 x$$

на промежутке [0; π].
