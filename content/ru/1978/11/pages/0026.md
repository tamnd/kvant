(Заметим еще, что координата проекции середины отрезка равна по у-сумме координат проекций концов отрезка.) Поскольку для любых трех точек $a, b, c$ на прямой можно выбрать три точки на плоскости, проекциями которых служат точки $a, b, c$, то из справедливости утверждение на плоскости следует его справедливо на прямой.

Тепер легко дать аналитическое доказательство того, что число $d = \frac{a + b + c}{3}$ является общим пределом указанных последовательностей. Для этого, очевидно, достаточно показать, что $|a_n - d| = 2 |a_{n+1} - d|$, $|b_n - d| = 2 |b_{n+1} - d|$, $|c_n - d| = 2 |c_{n+1} - d|$ (с каждым шагом последовательности вдвое приближаются к пределу).

Заметим, что для любого $n$

$$a_{n+1} + b_{n+1} + c_{n+1} = \frac{b_n + c_n}{2} + \frac{c_n + a_n}{2} + \frac{a_n + b_n}{2} = a_n + b_n + c_n.$$

Отсюда видно, что $d = \frac{a_n + b_n + c_n}{3}$ для любого $n$.

Имеем:

$$|a_n - d| = \left| a_n - \frac{a_n + b_n + c_n}{3} \right| = \left| \frac{2a_n - b_n - c_n}{3} \right| = \left| \frac{b_n + c_n - 2a_n}{3} \right| = 2 \left| \frac{b_n + c_n}{2} - \frac{a_n + b_n + c_n}{3} \right| = 2 |a_{n+1} - d|.$$

Два другие равенства проверяются аналогично.

В заключение заметим следующее. Среднее арфметическое в ух чисел, расматриваемое как операция, неассоциально (т. е., вообще говоря,

$$\frac{a + b}{2} + c \neq \frac{a + b + c}{2}),$$

и среднее арфметическое трех чисел, вообще говоря, не выражается как конечная компинация средних арфметических этих чисел, взятых по два (доказите это!). Тем не менее, как мы видели, использует переходный переход, среднее арфметическое трех чисел через среднее арфметическое двое чисел выразить можно. Аналогичные предельные соотношения связываются арфметические $k + 1$ и $k$ чисел для любого целого $k \geqslant 2$.

**M490.** $p$ — простое нечетное число. Дано $p-1$ целых чисел, не делихся на $p$. Доказите, что, заменив некоторые этих чисел на промивоположные, можно получить $p-1$ целых, сумма которых делится на $p$.

Будем писать $a \equiv b$, если числа $a$ и $b$ дают одинаковые остатки при делении на $p$ (как известно, в этом случае говорят, что $a$ сравним с $b$ по modulo $p$ — см. статью «Сравнения и классы вычетов» в «Кванте» № 10).
