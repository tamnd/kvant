многочлен
$$f(x) = (1+x)^n (x+1)^n = \left( C_n^0 + C_n^1 x + C_n^2 x^2 + \dots + C_n^n x^n \right) \times \left( C_n^0 x^n + C_n^1 x^{n-1} + C_n^2 x^{n-2} + \dots + C_n^n \right).$$

Коэффициент при $x^n$ в этом произведении равен, очевидно, $\sum_{k=0}^{n} \left( C_n^k \right)^2$.

С другой стороны, $f(x) = (1+x)^2n$. Коэффициент при $x^n$ в нем равен $C_{2n}^n$. По теореме получаем, что $\sum_{k=0}^{n} \left( C_n^k \right)^2 = C_{2n}^n$.

Тепер найдем $\sum_{k=0}^{n} (-1)^k \left( C_n^k \right)^2$.

При решении предыдущего задачи мы рассматривали многочлен $f(x) = (1+x)^n (x+1)^n$. Здесь же, по-видимому, надо взять положий многочлен, но чтобы в нем знаки у коэффициентов через линейные. Давайте попробуем рассмотреть многочлен $g(x) = (1+x)^n (x-1)^n = \left( C_n^0 + C_n^1 x + \dots + C_n^n x^n \right) \left( C_n^0 x^n - C_n^1 x^{n-1} + \dots + (-1)^n C_n^n \right)$.

Коэффициент при $x^n$ в этом произведении равен $\sum_{k=0}^{n} (-1)^k \left( C_n^k \right)^2$. С другой стороны, $g(x) = (1+x)^n (x-1)^n = (-1)^n (1-x^2)^n = (-1)^n \times \sum_{k=0}^{n} (-1)^k C_n^k x^{2k}$. В этой сумме коэффициенты при нечетных степенях $x$ равны 0. Поэтому, если $n$ нечетно, то коэффициент при $x^n$ равен 0. Если же $n$ четно, то коэффициент при $x^n$ равен $(-1)^{n+\frac{n}{2}} C_n^{\frac{n}{2}} = (-1)^{\frac{n}{2}} C_n^{\frac{n}{2}}$. Итак, $\sum_{k=0}^{n} (-1)^k \left( C_n^k \right)^2 = \left\{ \begin{array}{l} 0, n \text{ нечетно}, \\ (-1)^{\frac{n}{2}} C_n^{\frac{n}{2}}, n \text{ четно}. \end{array} \right.$

4. Преобразование Абеля

Пусть нам дана сумма $S_n = a_1 b_1 + a_2 b_2 + \dots + a_n b_n$, где $a_1, a_2, \dots, a_n, b_1, b_2, \dots, b_n$ – две последовательности. Обозначим суммы $b_1, b_1 + b_2, \dots, b_1 + b_2, \dots, b_1 + b_2 + \dots + b_n$, соответствующего, через $B_1, B_2, \dots, B_n$. Тогда $b_1 = B_1, b_k = B_k - B_{k-1}$ при $k > 1$ и $\sum_{k=1}^{n} a_k b_k$ можно преобразовать так:

$$\sum_{k=1}^{n} a_k b_k = a_1 B_1 + a_2 (B_2 - B_1) + \dots + a_n (B_n - B_{n-1}) = (a_1 - a_2) B_1 + (a_2 - a_3) B_2 + \dots + (a_{n-1} - a_n) B_{n-1} + a_n B_n = \sum_{k=1}^{n-1} (a_k - a_{k+1}) B_k + a_n B_n.$$

Это преобразование называют преобразование Абеля (о замечательном порядке математике Нильссе Хенрике Абелле см. в «Кванте» № 5 за 1976 год).
