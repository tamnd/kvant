Следовательно, во врашающей системе отчета ускорение нана равно

$$\left| \vec{a}_{\text{OTH}} \right| = - \left| \vec{a} \right| + \left| \vec{a}_{\text{II}} \right| = - \frac{bq}{m(r_0+x)} + \omega^2(r_0+x).

$$\text{ИЗ закона сохранения момента импульса следует, что}

$$m(r_0+x)^2\omega = mr_0^2\omega_0,

$$\text{где } \omega_0 \text{-угловая скорость нана в точке } A. \text{ Она же равна и угловой скорости нана, движущемся по «красной» траектории. Но центростремительное ускорение } \left| \vec{a}_0 \right| = \omega_0^2 r_0 \text{ ину, движущемся по «красной» траектории радиуса } r_0, \text{ сообщает сила } \vec{F}, равная по модулю } \frac{bq}{r_0}, \text{ поэтому}

$$\omega_0^2 r_0 = \frac{bq}{mr_0}, \text{ и } \omega_0^2 = \frac{bq}{mr_0^2}.

\text{Takим образом,}

$$\left| \vec{a}_{\text{OTH}} \right| = - \frac{bq}{m(r_0+x)} + \frac{bq}{mr_0^2}(r_0+x) \frac{r_0^4}{(r_0+x)^4} =

= \frac{bq\left[r_0^2-(r_0+x)^2\right]}{m(r_0+x)^3} = \frac{bq\left(-2r_0x-x^2\right)}{m(r_0+x)^3}.

\text{При } x << r_0

$$\left| \vec{a}_{\text{OTH}} \right| = -2 \cdot \frac{bq}{mr_0^2} x.

\text{Мы видим, что}

$$m\left| \vec{a}_{\text{OTH}} \right| = -kx, \text{ где } k = 2 \cdot \frac{bq}{r_0^2}.

\text{Как известно, при такой зависимости ускорения тела от смешения тела совершает гармоничческие колебания с периодом } T = 2\pi\sqrt{\frac{m}{k}}. \text{ Следовательно, они пучка, скорость которых в точке } A \text{ составляет малый угол } \alpha \text{ со скоростью инов, движущемся по основной траектории, будут совершать относительно основной траектории радиальные гармоничские колебания с периодом}

$$T = 2\pi\sqrt{\frac{mr_0^2}{2bq}}.

\text{Этот период одинаков для всех инов. Значит, после того как инов попадают в конденсатор в точке } A \text{ через времена } t_n = n\frac{T}{2}(n=1,2,3,\dots), \text{ все инов будут оказаться в одной и той же точке основной траектории — будут фокусироваться. Нетрудно найти угол } \varphi_0 \text{ между последовательными фокусами:}

$$\varphi_0 = \omega_0 t = \omega_0 \frac{T}{2} = \sqrt{\frac{bq}{mr_0^2}} \cdot \pi \sqrt{\frac{mr_0^2}{2bq}} = \frac{\pi}{\sqrt{2}}.

\text{Takим образом, если } \widehat{AOB} = \pi/\sqrt{2}, \text{ то ионы будут фокусироваться в точке } B.

\text{Найдем теперь максимальную ширину пучка. Для этого воспользуемся тем, что максимальное абсцистические значение скорости тела, совершающего гармоничские колебания, и амплитудa } x_{\text{max}} \text{ его колебаний связи}
