⟦folio 34⟧

Обозначим $\sum_{k=0}^{n} \frac{(-1)^k (k+1)}{C_n^k}$ через $T_n$.

Запишем $T_n$ двумя способами:

$$T_n = \frac{1}{C_n^0} - \frac{2}{C_n^1} + \dots + \frac{n+1}{C_n^n} \text{ (туда)},$$

$$T_n = \frac{n+1}{C_n^n} - \frac{n}{C_n^{n-1}} + \dots + \frac{1}{C_n^0} \text{ (назад)}.$$

Складывая, получаем $2T_n = (n+2) \times \left( \frac{1}{C_n^0} - \frac{1}{C_n^1} + \dots + \frac{1}{C_n^n} \right) = (n+2) \times S_n$. С другой стороны, $T_n = \sum_{k=0}^{n} \frac{(-1)^k (k+1) k! (n-k)!}{n!} = (n+1) \sum_{k=0}^{n} \frac{(-1)^k}{C_n^{k+1}} = (n+1) (1 - S_{n+1})$.

Но так как $S_{n+1} = 0$ ($n+1$ нечетно), $T_n = n+1$. Мы уже доказали, что $S_n = \frac{2}{n+2} T_n$. Значит, $S_n = \frac{2(n+1)}{(n+2)}$.

Осталось заметить, что $\frac{n+1}{n+2} (1 + (-1)^n) = \left\{ \begin{array}{l} 0, n нечетно, \\ \frac{2(n+1)}{n+2}, n четно. \end{array} \right.$

Доказательство равенства

$$\sum_{k=0}^{n} \frac{1}{C_n^k} = \frac{n+1}{2^{n+1}} \sum_{k=1}^{n+1} \frac{2^k}{k}. \tag{9}$$

сложнее всех предыдуших, но оно и само поучительное.

Введем следующие обозначения:

$$\sum_{k=0}^{n} \frac{1}{C_n^k} = D_n; \quad \sum_{k=0}^{n} \frac{k+1}{C_n^k} = E_n;$$

$$\frac{n+1}{2^{n+1}} \sum_{k=1}^{n+1} \frac{2^k}{k} = F_n.$$

Сначала по методу «туда-назад» дважды запишем сумму

$$E_n = \frac{1}{C_n^0} + \frac{2}{C_n^1} + \dots + \frac{n+1}{C_n^n} \text{ (туда)},$$

$$E_n = \frac{n+1}{C_n^n} + \frac{n}{C_n^{n-1}} + \dots + \frac{1}{C_n^0} \text{ (назад)}.$$

Сложим эти равенства: $2E_n = (n+2) \times \sum_{k=0}^{n} \frac{1}{C_n^k} = (n+2) D_n$. Значит, $D_n = \sum_{k=0}^{n} \frac{1}{C_n^k} = (n+2) E_n$. Теперь, продолжав выкладки, аналогичные тем, которые мы провели при решении предыдушей задачи, выразим $E_n$ через $D_{n+1}$.

А именно, $E_n = \sum_{k=0}^{n} \frac{k+1}{C_n^k} = (n+1) \times \sum_{k=0}^{n} \frac{1}{C_n^{k+1}} = (n+1) (D_{n+1} - 1)$, и мы можем выразить $D_{n+1}$ через $D_n$:

$$D_{n+1} = \frac{2}{n+2} E_n = \frac{2}{n+2} (n+1) (D_{n+1} - 1),$$

откуда

$$D_{n+1} = 1 + \frac{n+2}{2(n+1)} D_n.$$

Теперь, пользователь математической индукции, доказем, что $D_n = F_n$ при всех целых $n \geqslant 0$. Легко видеть, что $D_0 = 1$ и $F_0 = 1$. Предположим, что $D_s = F_s$. Тогда $D_{s+1} = 1 + \frac{s+2}{2(s+1)} D_s = 1 + \frac{s+2}{2(s+1)} F_s = 1 + \frac{s+2}{2(s+1)} \cdot \frac{s+1}{2^{s+1}} \sum_{k=1}^{s+1} \frac{2^k}{k} = 1 + \frac{s+2}{2^{s+1}} \sum_{k=1}^{s+1} \frac{2^k}{k} = F_{s+1}$.

Значит, $D_n = F_n$ при всех целых $n \geqslant 0$. Задча решения.
