⟦folio 64⟧

$$a + b = \lim_{n \to \infty} x_n + \lim_{n \to \infty} y_n.$$

Теорема доказана.

Ошибка Наташи заключается в том, что для числа $\varepsilon$ она взяла конкретоное значение 0,1 и от неравенства (3) перешла к неравенству (4). Ей надо было просто решить неравенство (3), рассматривая $\varepsilon$ как параметр. Решая неравенство (3), получим $\frac{2}{n} < \varepsilon$, откуда $n > \frac{2}{\varepsilon}$. В качестве номера $N$ возьмем какое-нибудь натуральное число не меньше, чем $\frac{2}{\varepsilon}$, то есть $N \geq \frac{2}{\varepsilon}$. Тогда для всех $n > N$ будет выполнять неравенство (3). Найденный таким образом номер $N$ зависит от $\varepsilon$. Для каждого конкретного значения $\varepsilon$ теперь уже легко находится «свой» номер $N$. Найример, для $\varepsilon = 0,1$ можно взять $N = 20$, для $\varepsilon = 0,001 - N = 2000$, и т. д.

Заметание 1. При отсутствии номера $N$ нет нужны нахождение минимальный номер, важно лишь указать какой-нибудь, начиная с которого будет выполнять неравенство (5). Поэтому отыскание его можно производить «грубо», «прикидной». Покажем это на примере.

Пусть требуется доказать, что $\lim_{n \to \infty} \frac{n^2}{n^4 + 16} = 0$. Пусть $\varepsilon > 0$ — произвольное число. Для отыскания $N$ надо решить неравенство

$$\left| \frac{n^2}{n^4 + 16} - 0 \right| = \frac{n^2}{n^4 + 16} < \varepsilon.$$

Но это неравенство громоздко. Поэтому делаем прикидку: отбрасываем в знаменатель дроби слагаемое 16, дробь $\frac{n^2}{n^4 + 16}$ заменяем другой $\frac{n^2}{n^4} = \frac{1}{n^2}$, которая, очевидно, больше первой, и решаем неравенство

$$\frac{1}{n^2} < \varepsilon.$$

Отсюда $n > \frac{1}{\sqrt{\varepsilon}}$. Если натуральное число $N$ выбрать больше $\frac{1}{\sqrt{\varepsilon}}$, то есть $N \geq \frac{1}{\sqrt{\varepsilon}}$, то неравенство (9) будет выполнять все $n > N$. Тогда $n > N$ и подавно будет выполнять неравенство (8). Таким образом, требуется равенство доказано.

Заметание 2. Не следует, однako, думать, что $N$ обязательно меняется при изменении $\varepsilon$. Найример, для постоянных последовательностей выбор номера $N$ вообще не зависит от числа $\varepsilon > 0$. Действительно, пусть $x_n = c$, где $c$ — постоянное число. Тогда $\lim_{n \to \infty} x_n = c$. Докажем это; пусть $\varepsilon > 0$ — произвольное число. Найдем номер $N$ такой, чтобы для всех $n > N$ выполнялось неравенство $|x_n - c| < \varepsilon$. Но это неравенство всегда справедливо, так как $|x_n - c| = 0$. Поэтому за число $N$ можно взять любое натуральное число, в частности 1.

Уражнения

1. Докажите, что
a) $\lim_{n \to \infty} \frac{3n + 1}{2n - 1} = \frac{3}{2}$.
Найдите $N$ для $\varepsilon = 0,1; 0,05; 0,001; 0,0002$.
b) $\lim_{n \to \infty} \frac{3n - 1}{2 - 3n} = -1$.
Найдите $N$ для $\varepsilon = 0,5; 0,04; 0,0001$.
b) $\lim_{n \to \infty} \frac{1}{n^2 + 5} = 0$.
2. Найдите предельных последовательностей:
a) 0; 1; 0; $\frac{1}{2}$; 0; $\frac{1}{3}$; ...; 0; $\frac{1}{n}$; ...
b) 0,2; 0,22; 0,222; ..., 0,22...2; ...
b) $\sin 1^\circ$, $\sin 2^\circ$, ..., $\sin n^\circ$, ...
г) 3; 3; ..., 3, ...
d) $x_n = (-1)^n$.
e) $x_n = \frac{\sin n}{n}$.
ж) $x_n = \frac{(-1)^n}{n} + 2$.
