⟦folio 60⟧

Задачу можно решить и по-другому — при помощи векторов. В плоскости $ABC$ через точку $C$ проведем прямую $m$, перпендикулярную $CD$. Введем прямогольную систему координат: за начало координат прямого точку $C$, за ось абсцисс прямого точку $CD$, за ось ординат — прямую $m$, за ось аппликат — прямую $CS$ (см. рис. 3; на нем указаны положительные направления осей).

Пусть $P$ и $Q$ — такие точки, соответственно, на прямых $SE$ и $CD$, что $PQ \perp SE$ и $PQ \perp CD$. Тогда искомое расстояние равно $|PQ|$. Обозначим через $\alpha$ и $\beta$ числа, определяющие положение точки $P$ и $Q$: $\overrightarrow{SP} = \alpha \overrightarrow{SE}$, $\overrightarrow{CQ} = \beta \overrightarrow{CD}$.

$$\overrightarrow{PQ} = \overrightarrow{PS} + \overrightarrow{SC} + \overrightarrow{CQ}.$$

Найдем координаты векторов $\overrightarrow{PS}$, $\overrightarrow{SC}$ и $\overrightarrow{CQ}$ в выбранной системе координат. $\overrightarrow{PS} = -\overrightarrow{SP} = (-\alpha) \overrightarrow{SE}$. Поскольку $|CE| = |EB|$ и $|BD| = |DA|$, $\overrightarrow{SE} = \left( \frac{|CD|}{2}; \frac{|AB|}{4} \right)$; $-|SC|$. $|CD| = \sqrt{|AC|^2 - |AD|^2} = 2\sqrt{6}$. Значит, $\overrightarrow{SE} = (\sqrt{6}; \sqrt{2}; -2)$.

Следовательно, $\overrightarrow{PS} = (-\sqrt{6}\alpha; -\sqrt{2}\alpha; 2\alpha)$. Очевидно, $\overrightarrow{SC} = (0; 0; -2)$. Поскольку $\overrightarrow{CD} = (2\sqrt{6}; 0; 0)$, $\overrightarrow{CQ} = (2\sqrt{6}\beta; 0; 0)$.

Итак,

$$\overrightarrow{PQ} = (-\sqrt{6}\alpha + 2\sqrt{6}\beta; -\sqrt{2}\alpha; 2\alpha - 2).$$

Незвестные $\alpha$ и $\beta$ мы найдем из условия $\overrightarrow{PQ} \cdot \overrightarrow{SE} = 0$ и $\overrightarrow{PQ} \cdot \overrightarrow{CD} = 0$.

$$\begin{cases} (-\sqrt{6}\alpha + 2\sqrt{6}\beta) \sqrt{6} + (-\sqrt{2}\alpha) \sqrt{2} + (2\alpha - 2)(-2) = 0 \\ (-\sqrt{6}\alpha + 2\sqrt{6}\beta) 2\sqrt{6} + (-\sqrt{2}\alpha) \cdot 0 + (2\alpha - 2) \cdot 0 = 0. \end{cases}$$

Из второго уравнения системы $-\sqrt{6}\alpha + 2\sqrt{6}\beta = 0$ (это можно было предвидеть: поскольку $\overrightarrow{PQ} \perp \overrightarrow{CD}$, первая координата вектора $\overrightarrow{PQ}$ равна 0). Тогда из первого уравнения $\alpha = \frac{2}{3}$. Значит, $\beta = \frac{1}{3}$. Итак,

$$\overrightarrow{PQ} = \left( 0; -\frac{2\sqrt{2}}{3}; -\frac{2}{3} \right).$$

Значит, $|PQ| = \sqrt{0^2 + \left(-\frac{2\sqrt{2}}{3}\right)^2 + \left(-\frac{2}{3}\right)^2} = \frac{2}{\sqrt{3}}$.

Из $\overrightarrow{SE} = (\sqrt{6}; \sqrt{2}; -2)$ получаем $|\overrightarrow{SE}| = 2\sqrt{3}$.
