$$\tilde{x}_1 = \sqrt{m_1} x_1, \tilde{x}_2 = \sqrt{m_2} x_2, \tilde{x}_3 = \sqrt{m_3} x_3$$

из соответствия (1) следует, что
$$\tilde{v}_1^2 + \tilde{v}_2^2 + \tilde{v}_3^2 = \tilde{z}_1^2 + \tilde{z}_2^2 + \tilde{z}_3^2.$$
Поскольку старые координаты удовлетворяют неравенствам
$$x_1 \leq x_2 \leq x_3$$ и $x_i = \tilde{x}_i / \sqrt{m_i}$,
новые координаты удовлетворяют неравенствам
$$\frac{\tilde{x}_1}{\sqrt{m_1}} \leq \frac{\tilde{x}_2}{\sqrt{m_2}} \leq \frac{\tilde{x}_3}{\sqrt{m_3}}.$$
Эти неравенства задают в координатном пространстве $O\tilde{x}_1 \tilde{x}_2 \tilde{x}_3$ двумя углов $\Phi$, ограниченный плоскостями соударений:
$$\tilde{P}_{12} = \left\{ \left( \tilde{x}_1; \tilde{x}_2; \tilde{x}_3 \right) \mid \frac{\tilde{x}_1}{\sqrt{m_1}} - \frac{\tilde{x}_2}{\sqrt{m_2}} = 0 \right\}$$ и
$$\tilde{P}_{23} = \left\{ \left( \tilde{x}_1; \tilde{x}_2; \tilde{x}_3 \right) \mid \frac{\tilde{x}_2}{\sqrt{m_2}} - \frac{\tilde{x}_3}{\sqrt{m_3}} = 0 \right\}.$$
