$1^\circ$. Рассужждение будем вести индукцией по числу шаров. В § 2 было доказано, что при $n = 3$ число столковенной конечно. Допустим, что при любых начальных условий в группе из $k < n$ шаров за время от 0 до $T$ (где $T$ может быть равно $+\infty$) проискодит только конечное число столковений. Предположим, что при каждых-то начальных условий $n$ шаров за время от 0 до $T$ стальваются бесконечного много раз. Переумерумем шары в порядке их следования по оси $Ox$, но справа налево. В каждый момент времени рассмотрим суммарный имплус $k$ правых шаров:

$$P_k = m_1 v_1 + m_2 v_2 + \dots + m_k v_k (k = 1, 2, \dots, n)$$

При каждом парном столковении величины $P_k$ может только увеличиться: действительно, $P_k$ не меняется, если стальваются шары левее $k$-го или правее $(k+1)$-го; если $k$-й шар стальвается с $(k+1)$-ым, $P_k$ увеличивается, (ибо $(k+1)$-й шар только дает $k$-й вправо).

Обозначим теперь через $v_i^{(s)}$ скорость $i$-го шара после $s$-го по порядку стольновения (в котором $i$-й шар может и не участвовать), через $P_k^{(s)}$ — имплус $P_k$ после $s$-го стольновения. Из сказанного выше следует, что при каждом $k$ последовательность $P_k^{(s)}$ ($s = 1, 2, \dots$) — неубывающегося.

С другой стороны, при всех стольновениях суммарная kinетическая энергия всех шаров сохраняется:

$$\frac{1}{2} \left( m_1 v_1^2 + m_2 v_2^2 + \dots + m_n v_n^2 \right) = E = \text{const.}$$

Отсюда следует, что при каждом $i$ в любой момент времени скорость ограничена:

$$m_i v_i^2 \leq 2E \text{ и } |v_i| \leq \sqrt{2E/m} \leq \sqrt{2E/m},$$

где $m$ — наименьшая из масс $m_1, \dots, m_n$. Отсюда вытекает ограниченность каждой из последовательностей $P_k^{(s)}$:

$$|P_k^{(s)}| \leq m_1 |v_1^{(s)}| + \dots + m_k |v_k^{(s)}| \leq (m_1 + \dots + m_k) \sqrt{2E/m}.$$

Итак, при каждом $k$ последовательность $P_k^{(s)}$ монotonная и ограниченная, поэтому, согласно теореме Вейерштраса, все эти последовательности имеют предель при $s \to \infty$. Но $P_1^{(s)} = m_1 v_1^{(s)}$, поэтому существует предель $v_1^{(s)} = w_1$. Далее, $P_2^{(s)} = m_1 v_1^{(s)} + m_2 v_2^{(s)}$, поэтому существует предель $v_2^{(s)} = w_2$ (объясните). Продолжая это рассужение, мы выводим существование пределов скоростей всех шаров:

$$\lim_{s \to \infty} v_k^{(s)} = w_k (k = 1, 2, \dots, n).$$

$2^\circ$. Тепер мы покажем, что все предельные скорости $w_k$ должны быть равны между собой. Расмотрим два соседних шара: $k$-й и $(k+1)$-й. За время от 0 до $T$ эти шары должны стальваться между собой бесконечного много раз, либо в противном случае из предоложения индукции следования бы конечность числа стольновейных шаров (объясните).
