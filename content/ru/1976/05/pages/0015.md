Все дальнейшие наши рассуждания будут чисто «аррифметическими», и может показаться сначала, что они не имеют отношения к задаче. Но именно они и приведут нас к решению задачи (вернее, первой ее части) — позволят определить конфигурацию тел.

Сложим почленно равенства из системы (1):

$$F_{12} + F_{13} + F_{21} + F_{23} + F_{31} + F_{32} = m_1 a_1 + m_2 a_2 + m_3 a_3 = -\omega^2 (m_1 r_1 + m_2 r_2 + m_3 r_3).$$

Левая часть этого равенства равна нулю — ведь согласно III закону Ньютона сумма всех внутренних сил в замкнутой системе равна нулю. (Левую часть можно записать так:

$$\sum_{i,j=1}^{3} F_{ij} + \sum_{i,j=1}^{3} F_{ji} = 0, \text{ так как } F_{ij} = -F_{ji}.$$

Итак, имеем

$$m_1 r_1 + m_2 r_2 + m_3 r_3 = 0$$

(поскольку $\omega \neq 0$). Равенство (2) по существу задает положение центра врашения: он находится в такой точке $O$, что радиус-векторы тел $m_1, m_2, m_3$ относительно этой точки должны удовлетворять условия (2).

Введем векторы $R_2$ и $R_3$ так, как показано на рисунке 2. Тогда

$$r_1 = r_2 + R_3,$$

$$r_1 = r_3 + R_2.$$

Рис. 3.
Выразим вектор $r_1$ через векторы $R_2$ и $R_3$. Для этого умножим первое равенство из (3) на $m_2$, а второе — на $m_3$ и сложим получившееся равенства почленно:

$$m_2 r_1 + m_3 r_1 = m_2 r_2 + m_3 r_3 = -m_1 r_1$$

(это следует из (2)), имеем:

$$(m_1 + m_2 + m_3) r_1 = m_2 R_3 + m_3 R_2.$$

Отсюда

$$r_1 = \frac{m_2}{m_1 + m_2 + m_3} R_3 + \frac{m_3}{m_1 + m_2 + m_3} R_2$$

Таким образом, вектор $r_1$ является суммой векторов $\rho_2 = \frac{m_3}{m_1 + m_2 + m_3} R_2$ и $\rho_3 = \frac{m_2}{m_1 + m_2 + m_3} R_3$, параллельных сторонам $R_2$ и $R_3$ треугольника масс.

А теперь изобразим на схеме треугольника масс векторы сил, действующих на тело $m_1$ (см. рис. 3). $F_{12}$ — сила, действующая со стороны тела $m_2$, $F_{13}$ — сила, действующая со стороны тела $m_3$. Эти силы направлены по сторонам $R_3$ и $R_2$ треугольника масс. Их результатируются направлена по вектору $r_1$ к точке $O$ (векторускорения тела $m_1$ направлен к центру врашения).
