4. $x_1, x_2 = 2 \pm \sqrt{6}, \quad x_3 = 2, \quad x_4 = -1$.

Указание. Переписать уравнение в виде $x^4 + 4 = 5x^3 - 10x$ и разделить обе части этого уравнения на $x^2$!

$$x^2 + \frac{4}{x^2} = 5 \left( x - \frac{2}{x} \right).$$

Затем сделать замену неизвестного $x - \frac{2}{x} = t$, в результате которого получается квадратное уравнение $t^2 + 4 = 5t$.

11. $0, 31 \leqslant x < 5 + 2\sqrt{6}$. Указание. Неравенство равносильно совокупности двух систем:

$$\begin{cases} 0 < \frac{x^2 - 10x + 31}{30} < 1, \\ 5x - \frac{11}{20} \geqslant 1; \end{cases}$$

13. $x = \frac{5\pi}{6} + 2k\pi$ ($k = 0, \pm 1, \pm 2, \dots$). Указание. Данное уравнение в ОДЗ равносильно уравнению

$$1 - \cos x - \sin x = \cos 2x - \sin 2x,$$

(которое приводится к виду)

$$(\cos x + \sin x)(2 \sin x - 1) = 0.$$

Корни уравнения $\cos x + \sin x = 0$ не входят в ОДЗ исходного уравнения: для каждой из них в силу соответствия (4) имеем $\cos 2x - \sin 2x = 1 - (\cos x + \sin x) = 1$, а в ОДЗ должно выполняться условие $\cos 2x - \sin 2x \neq 1$. Если $\sin x = 1/2$, то либо $\cos x = \sqrt{3}/2$, либо $\cos x = -\sqrt{3}/2$. В первом случае

$$1 - \cos x - \sin x = \frac{1}{2} - \frac{\sqrt{3}}{2} < 0,$$

тогда как в ОДЗ должно выполняться условие $1 - \cos x - \sin x > 0$. Во втором случае определяющие ОДЗ условия выполняются.

15. $S_{\triangle AOB}: S_{\triangle ABC} = (9 + \sqrt{3}): 26$.

Указание. Провести высоты: $SD$ – боковой грани $ASC$, $SF$ – боковой грани $CSB$, $SE$ – боковой грани $ASB$; соединить точки $D, F, E$ с точкой $O$. Доказать, что $SD = SF = SE$ и точка $O$ – центр круга, вписанной в треугольник $ABC$. Доказать, что $\triangle SDC = \triangle SFC, \triangle SFB = \triangle SEB, \triangle SEA = \triangle SDA$, и вычислить все плоские углы всех боковых граней. Выразить отрезки $AE = AD, BE = BF, CF = CD$ через длину высоты боковой грани. Составить выражения для плоскей треугольников $AOB$ и $ABC$, обозначив через $r$ радиус круга, вписанного в треугольник $ABC$.

16. $MN = 1/7$. Указание. Заметить, что $MN = DM - DN$. Для вычисления $DM$ и $DN$ использовать следующий геометрический факт: если в треугольник $PQR$ вписан круг, касающийся сторона $PQ, QR, RP$ треугольника, соответствующего в точках $A, B, C$, то $AQ = QB = p - PR, BR = RC = p - PQ, CP = PA = p - QR$, где $p$ – полyperметр треугольника $PQR$.
