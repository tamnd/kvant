Задчи

M396—M400; Ф408—Ф412

Решения задач из этого номера можно присылать не позднее 1 ноября 1976 г. по адресу: 113035, Москва, М-35, Б. Ордынка, 21/16, редакция журнала «Квант».
После адреса на конверте написите, решения каких задач вы посылаете, например: «Задчик «Кванта», М396» или «...Ф408».
Решения задач по каждому из предметов (математике и физике), а также новые задачи просбапись присылать в отдельных конвертах. Задчи из разных номеров журнала присылайте также в разных конвертах. В письмо включите конверт с написанием на нем адресом (в этом конверте вы получите результаты проверки ваших решений). Условия оригинальных задач, предлагаемых для публикации, присылайте в двух экземплярах вместе с вашими решениями этих задач (на конверте пометьте: «Задчик «Кванта», новая задача по физике» или «...новая задача по математике»).
В этом номере «Задчик «Кванта» составлен в основном из задач, предлагашихся на последней Всесоюзной олимпиде. В скобках (после задач заключительного типа олимпиды) указаан класс, для учеников которого предлагается задача.
Нанболее трудные задачи отмещены звездочкой.

M396. Треугольник, все стороны которого больше 1 см, называем «большим». Дан правильный треугольник ABC со стороны 5 см. Докажите, что a) из треугольника ABC можно вырезать 1000 «больших» треугольников; b) треугольник ABC можно разрезать на 1000 «больших» треугольников; b)* треугольник ABC можно трианглировать на 1000 «больших» треугольников, то есть разбит его так, чтобы любые два треугольника либо не имели общих точек, либо имели только общую вершину, либо имели общую сторону; г) сделайте пункты 6) и b) для правильного треугольника со стороны 3 см. (8—9 кл.)

С. Фомин

M397. На плоскости данных три окружности одинакового радиуса.
a) Докажите, что если все они пересекаются в одной точке, как показано на рисунке 1, то сумма отмеченных дуг AK, СК, EK равна 180°.
b) Докажите, что если они расположены так, как показано на рисунке 2, то сумма отмеченных дуг AB, CD, EF равна 180°. (8 кл.)

M398. На окружности расположены n действительных чисел (n≥3), сумма которых равна нулю. Одно из этих чисел равно 1.
a) Докажите, что есть два соседних числа, различающихся не менее чем на 4/n.
b) Докажите, что есть число, отличное от среднего арфметического двух своих соседей не менее чем на 8/n².
b) Оценку, предложенную в предыдущем пункте, можно улушить. Попробуйте заменить в ней число 8 каким-нибудь большим числом так, чтобы утверждение этой задачи по-прежнему выполнялось для всех натуральных чисел.

**M399**. На отрезке длины 7 можно поставить путь точек (см. рис. 3) так, чтобы для любого $m=1, 2, \dots, 7$ нашлись две из этих пятей точек на расстоянии $m$.

Попробуйте выяснить, какое наименьшее число $k_n$ точек нужно поставить на отрезке длины $n$ так, чтобы для любого $m=1, 2, \dots, n$ нашлись две из этих $k_n$ точек на расстоянии $m$.

a) Решите эту задачу для нескольких значений $n$ (нам известно $k_n$ для $n \leqslant 13$).

b) Получите оценки для $k_n$ для любого $n$. Известны оценки $(\sqrt{8n+1}+1)/2 \leqslant k_n \leqslant \sqrt{4n+5}-1$. Постраайтесь доказать эти неравенства и, если сможете, найдите более точные оценки.

**A. Савин**

**M400.** Последовательность натуральных чисел $a_1, a_2, \dots, a_h$ называем универсальной для данного $N$, если из нее можно получить вычеркивание части членов любого последовательность из $N$ чисел, в котором каждое из чисел 1, 2, ..., $N$ входит по одному разу.

a) Приведите пример универсальной последовательности из $N^2$ членов.

b) Приведите пример универсальной последовательности из $N^2-N+1$ членов.

в) Докажите, что любая универсальная последовательность состоит не менее чем из $\frac{N(N+1)}{2}$ членов.

г) Докажите, что при $N=4$ самая короткая универсальная последовательность состоит из 12 членов.

d) Попробуйте найти для данного $N$ как можно более коротную универсную последовательность. (9 кл.)
