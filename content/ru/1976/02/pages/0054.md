Уравнение (3) можно использовать следующим образом. В любой момент времени полное напряжение ($u = U_0 \cos \omega t$) на концах цепи равно сумме напряжений на активном сопротивлении ($u_R = Ri$), на катушке индуктивности ($u_L = L \frac{\Delta i}{\Delta t}$) и на конденсатор ($u_C = \frac{q}{C}$):

$$u_L + u_R + u_C = u.$$ (4)

Колебания всех трех напряжений происходит с одной и той же частотой, но имеют различные амплитуды и сdwнуты по фазе друг относительно друга.

Чтобы найти амплитуду колбаний силы тока и сdwиг фаз между током и напряжением, нужно уметь складывать гармоничские колбания, сdwинутые по фазе. Для этого надо знать амплитуды напряжения $u_R$, $u_L$ и $u_C$, а также сdwиг фаз этих напряжений относительно силы тока. Об этом и пойдет речь в следующих трех параграфах.

Напряжение на активном сопротивлении

Нибольшее простой случай электрической цепи — это, цепь, содержащая только активное сопротивление $R$. Для такой цепи основное уравнение (3) будет иметь следующий вид:

$$Ri = U_0 \cos \omega t.$$ (5)

Отсюда

$$i = \frac{U_0}{R} \cos \omega t = I_0 \cos \omega t.$$ (6)

Амплитуда напряжения связана с амплитудой силы тока соответствием

$$U_0 = I_0 R.$$ (7)

Колебания силы тока и напряжения на активном сопротивлении совпадают по фазе. Заметим, что равенство (7) ничего не отличается от закона Ома для постоянного тока.

Напряжение на индуктивном сопротивлении

Пусть цель состоит из катушки с индуктивностью $L$. Активным сопротивлением катушки пребрежем. Вместо уравнения (3) будем иметь в этом случае более простое уравнение

$$L \frac{\Delta i}{\Delta t} = U_0 \cos \omega t,$$

или

$$\frac{\Delta i}{\Delta t} = \frac{U_0}{L} \cos \omega t.$$ (8)

Тепер скорость изменения силы тока ($\frac{\Delta i}{\Delta t}$) совершает гармоничские колбания, совпадающие по фазе с колбаниями напряжения. Амплитуда этих колбаний равна $\frac{U_0}{L}$.

Для того чтобы выражение для силы тока, воспользоваться аналогичей между электромагнитными колбаниями в контуре и механическими колбаниями груза наружне. Как известно, сила тока $i$ соответствует скорости колбаний груза $v$, а скорость изменения силы тока $\frac{\Delta i}{\Delta t}$ соответствует ускорению груза $a$. Но колбания скорости отстают от колбаний ускорения на $\pi/2$, и амплитуда скорости $v_0$ связана с амплитудой ускорения $a_0$ соответствием $v_0 = a_0/\omega$. Это справедливо для гармоничских колбаний любой природы. Поэтому если скорость изменения силы тока удовлетворяет уравнению (8), то сила тока изменяется со временем по закону

$$i = \frac{U_0}{L \omega} \cos \left(\omega t - \frac{\pi}{2}\right) = I_0 \cos \left(\omega t - \frac{\pi}{2}\right).$$ (9)

Амплитуда напряжения связана с амплитудой силы тока соответствием

$$U_0 = I_0 L \omega = I_0 R_L.$$ (10)

Величину $R_L = L \omega$ называют индуктивным сопротивлением.
