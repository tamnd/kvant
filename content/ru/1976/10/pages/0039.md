6) Приведем пример, показывающий, что 0 может не встретиться ни в одной из троек. Начнем с тройки ($\lambda, \lambda^2, \lambda^3$), где $\lambda$ выбрано так, что числа в следующей тройке

$$|\lambda^2 - \lambda|, |\lambda^3 - \lambda^2|, |\lambda^3 - \lambda|$$

пропорциональны числом первого тройки. Посокльку $\lambda^2 - \lambda = \lambda(\lambda - 1), \lambda^3 - \lambda^2 = \lambda^2(\lambda - 1), \lambda^3 - \lambda = (\lambda^2 + \lambda)(\lambda - 1)$, для этого возьмем $\lambda$ равным положительным корню уравнения $\lambda^2 + \lambda = \lambda^3$: то есть $\lambda = (1 + \sqrt{5})/2$. При этом $n$-я тройка будет такой: $\lambda(\lambda - 1)^{n-1}, \lambda^2(\lambda - 1)^{n-1}, \lambda^3(\lambda - 1)^{n-1}$ (это легко проверить с помощью индукции), так что ни одно из чисел не будет равно 0.

Н. Васильев

Обозначим через $v_0$ начальное скорость первого (налетаксшего) шара, а через $v_1$ и $v_2$ — скорости первого и второго шаров в момент их максимальной деформации. Согласно закону сохранения энергии

$$\frac{mv_0^2}{2} = \frac{mv_1^2}{2} + \frac{mv_2^2}{2} + \Pi,$$

где $m$ — масса каждой шара, $\Pi$ — максимальное значение потенциальной энергии упругой деформации шаров.

Введем систему координат $XOY$ и найдем проекции скоростей $v_1$ и $v_2$ на соответствующие оси координат. Ось $OX$ направим по линни, соединяющей центры шаров при удалении (рис. 5). В этом направлении между шарами проискодит общийLOBовой упругой удар. Посокльку системы шаров изолирована, проекция импульса системы на ось $OX$ сохраняется. В начальной момент эта проекция равна $mv_0 \cos \alpha$. В тот момент, когда деформация шаров максимальная, проекция их скоростей на ось $OX$ одинаковы: $v_{1x} = v_{2x} = v_x$.

Из закона сохранения импульса

$$mv_0 \cos \alpha = 2mv_x,$$

или

$$v_{1x} = v_{2x} = v_x = \frac{1}{2} v_0 \cos \alpha.$$

Так как шары абсолютино гладкие, взаимодействия их по оси $OY$ не происходит. Проекция скорости первого шара на эту ось не изменяется:

$$v_{1y} = v_{0y} = v_0 \sin \alpha,$$

а проекция скорости второго шара остается равной нулю:

$$v_{2y} = 0.$$

Таким образом, закон сохранения энергии можно записать так:

$$\frac{mv_0^2}{2} = \frac{m(v_1^2 + v_2^2)}{2} + \frac{m(v_2^2 + v_1^2)}{2} + \Pi,$$

или

$$\frac{mv_0^2}{2} = \frac{mv_0^2 \cos^2 \alpha}{4} + \frac{mv_0^2 \sin^2 \alpha}{2} + \Pi.$$
