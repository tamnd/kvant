Словом над алфавитом $A$ мы будем называть любую конечную последовательность символов из $A$. Вот примеры слов над двумя описными выше алфавитами (чтобы отделить запись слова от окружающего текста, мы «упаковываем» его в угловые скобки):

Слово может быть и «пустым», то есть вовсе не содержать символов (последнее «слово» в первом примере), такое слово обозначают буквой $\lambda$: $\lambda = \langle \rangle$. Множество слов над данным алфавитом $A$ обозначим через $C(A)$. Его элементы, то есть слова, мы будем обозначать малыми латинскими буквами (они не принадлежат алфавитам, которые нам здесь приходит расматривать).

Произведением, или комποизценей, двух слов $a$ и $b$ из $C(A)$ мы будем называть слово $c$ ( и писать: $c = a \otimes b$), полученное приписываем к слову $a$ справа от него слова $b$. Вот примеры комποизценей слов:

$$(A_1): a = \langle \alpha \rangle, b = \langle \alpha\beta \rangle,$$
$$c = a \otimes b = \langle \alpha\alpha\beta \rangle;$$
$$(A_2): a = \langle 2 + 2 \rangle, b = \langle 4 \rangle,$$
$$c = a \otimes b = \langle 2 + 2 = 4 \rangle.$$

Пустое слово не содержит символов, поэтому $a \otimes \lambda = \lambda \otimes a = a$ для любого слова $a$ из $C(A)$, то есть пустое слово $\lambda$ при переложении слов ведет себя как единца при переложении чисел.

Если продолжить поиск сходства и различий между умножением слов и умножением чисел, то можно заметить, что операция «⊗» ассоциативна:

$$(a \otimes b) \otimes c = a \otimes (b \otimes c),$$

позному имеет смысл запись $a \otimes b \otimes c$.

$$a^m \otimes a^n = a^{m+n}.$$

Справедливо после него равенства позвольяет нам сокращать запись неотрицательных слов: вместе $a = \langle \alpha \rangle^3 \otimes \langle \beta \rangle^3 \otimes \langle \alpha \rangle^4$ или, допуская неотрицательную волность записи, $a = \langle \alpha^3\beta^3\alpha^4 \rangle$. Но менять порядок букв в слова, вообще говоря, нельзя говорить «⊗» может быть не коммутиативной, то есть $a \otimes b$ может не совпадать с $b \otimes a$.
