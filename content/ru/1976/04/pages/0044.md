⟦folio 42⟧

Появляющийся в этой формуле угол φ обычно называют вспомогательным углом. Как известно, он определяется соответствием

$$\sin \varphi = \frac{b}{\sqrt{a^2 + b^2}}, \quad \cos \varphi = \frac{a}{\sqrt{a^2 + b^2}}$$

с точностью до слагаемого $2n\pi$ (где $n = 0, \pm 1, \pm 2, \ldots$). Поэтому достаточно указать один угол φ, лежащий в каком-нибудь промежутке длины $2\pi$, чтобы получить все остальные значения вспомогательного угла.

Обратим внимание на следующую простую явную формулу для вспомогательного угла, которая отсутствует в школьных учебниках, но удобна при решении задач, особенно уравнений с параметром. Выберем в качестве промежутка длины $2\pi$ промежуток $-\pi < \varphi \leq \pi$. тогда единственный угол φ, лежащий в этом промежутке и удовлетворяющий общим соотношением (2), определяется формулой

$$\varphi = \begin{cases} \arccos \frac{a}{\sqrt{a^2 + b^2}}, & \text{ если } b \geqslant 0; \\ -\arccos \frac{a}{\sqrt{a^2 + b^2}}, & \text{ если } b < 0. \end{cases}$$

В самом деле, независимо от знака $b$ оба угла (3) удовлетворяют второму соотношению (2), а первому соотношению (2) в промежутке $-\pi < \varphi \leq \pi$ при $b \geqslant 0$ удовлетворяет только $\varphi = \arccos \frac{a}{\sqrt{a^2 + b^2}}$ и при $b < 0$ только $\varphi = -\arccos \frac{a}{\sqrt{a^2 + b^2}}$.

Следует напомнить, что ни одно из соотношений (2), взятое отделно (или вытекающей из них соотношение $tg \varphi = b/a$, также взятое отделно), не является достаочным для нахождения вспомогательного угла: оно определяет в промежутке длины $2\pi$ два угла, из которых только один удовлетворяет общим соотношением (2). Так, если $a = -1$, $b = \sqrt{3}$, то уравнение $tg \varphi = b/a$ имеет в промежутке $-\pi < \varphi \leq \pi$ два корня: $-\pi/3$ и $2\pi/3$, но лишь для второго из них справедливо (1).

Преимущества формулы (3) легко увидеть на следующем примере.

Пример 2 (МИЭМ, 1972). Peшить уравнение

$$\sin^6 x + \cos^6 x = a \sin 4x,$$

эде $a - \text{параметр}$.

Двухратным понжением степени в левой части уравнения приводится к виду

$$a \sin 4x - \frac{3}{8} \cos 4x = \frac{5}{8},$$

откуда с помощью формул (1) и (3) получаем:

$$\sqrt{a^2 + \frac{9}{64}} \sin (4x + \varphi) = \frac{5}{8},$$

$$\varphi = -\arccos \frac{a}{\sqrt{a^2 + \frac{9}{64}}}.$$

Ясно, что решение этого уравнения существует при

$$\frac{5}{8} \leq \sqrt{a^2 + \frac{9}{64}},$$

т. е. при $|a| \geqslant 1/2$, и даются формулы

$$x = \frac{(-1)^n}{4} \arcsin \frac{5}{\sqrt{64a^2 + 9}} + \frac{1}{4} \arccos \frac{8a}{\sqrt{64a^2 + 9}} + \frac{\pi n}{4},$$

где $n$ — целое. Использование формулы (3) приводило к весмам компактной записи результата (ср. с ответом, приведенным в «Кванте», 1973, № 7, с. 47, 60—61).
