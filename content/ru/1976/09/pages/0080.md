3. Оценка сизу следует из неравенства о среднем арифметическом и среднем геометрическом. Действительно, $x_{n+1} = \frac{x_n^3}{5} + \frac{1}{15x_n} + \frac{1}{15x_n} \geq 4\sqrt[4]{\frac{1}{5\cdot15\cdot15}} = \frac{4\sqrt[4]{3}}{15} > \frac{1}{3} > \frac{1}{5}$.

Чтобы получить оценку сверху, решим неравенство $x_n > x_{n+1}$. Имеем:

$$x_n > \frac{x_n^4+1}{5x_n} \text{ или } x_n^4 - 5x_n^2 + 1 < 0,$$

т. е. $$\frac{5-\sqrt{21}}{2} < x_n^2 < \frac{5+\sqrt{21}}{2},$$

т. к.

$$x_n > 0, \text{ получаем, что если } \sqrt{\frac{5-\sqrt{21}}{2}} < x_n < \sqrt{\frac{5+\sqrt{21}}{2}}, \text{ то } x_n > x_{n+1}.$$

Значит, если $1 \leq x_n \leq 2$, то $x_{n+1}$ меньше 2. Если же $x_n < 1$ (случая $x_n > 2$ быть не может, поскольку $x_1 = 2$), то $x_{n+1} < 2$.

Из этого следует, что $x_n < 2$ для всех $n > 1$, и неравенство полночного доказано.
