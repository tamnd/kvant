6. Не помогут ли комплекские числа?

Все, что написано далее, рассчитано на читателя, знакомого с комплекскими числами.

Впрочем, «знакомство» с комплекскими числами, в существии, есть не более чем привчка к употреблению определенных слов. Комплексные числа появились в математике примерно так же, как несколько раныше — отрицательные числа или дроби. Поскольку не из всякого действительного числа можно извлечь квадратный корень, удобно дополнить запас чисел новым числом $i$, квадрат которого равен —1 (как равше, желая сделать универсальный операцию вычитания, введи отрицательные числа). Вместе с $i$ вводят числа вида $a + bi$, где $a$ и $b$ — действительные числа, и условливаются, что действия над этим числами производятся по таким правилам:

$$(a + bi) + (c + di) = a + bi + c + di = (a + c) + (b + d)i,$$
$$(a + bi)(c + di) = ac + adi + bci + bdi^2 = (ac - bd) + (ad + bc)i$$

(в последнем равенстве мы учили, что $i^2 = -1$). Построенные числа называются комплекскими числами; числа $a$ и $b$ называются соответствующим действительным и минимальным числам $a + bi$; два комплекских числа равны тогда и только тогда, когда равны их действительные части и равны их минимые части. Приведем еще формулу Муавра (она нам понадобится ниже):

$$(\cos \alpha + i \sin \alpha)(\cos \beta + i \sin \beta) = \cos (\alpha + \beta) + i \sin (\alpha + \beta),$$

которая является немедленным следствием формулы для переменжения комплекских чисел и известных трионометрических формул.

Вернемся к формуле (3). В случае, когда $\frac{q^2}{4} + \frac{p^3}{27} < 0$, можно попытаться найти решение уравнения (2) с ее помощью, извлекая кубическое корни из комплекских чисел.

Извлечь кубическое корень из комплекского числа $a + bi$ — это значит решить уравнение

$$(x + iy)^3 = a + bi,$$

то есть уравнение $x^3 - 3xy^2 + i(3x^2y - y^3) = a + bi$. Последнее равенство означает, что

$$\begin{cases} x^3 - 3xy^2 = a, \\ 3x^2y - y^3 = b. \end{cases}$$

Система же эта различными способами приводится опять-tаки к кубическому уравнению. Например, так:

$$y^2 = \frac{x^3 - a}{3x} (\text{из первого уравнения}),$$

$$y \left( 3x^2 - \frac{x^3 - a}{3x} \right) = b,$$

$$y = \frac{3bx}{8x^3 + a},$$

$$x^3 - 3x \cdot \frac{9b^2x^2}{(8x^3 + a)^2} = a,$$

$$(x^3 - a)(8x^3 + a)^2 - 27b^2x^3 = 0,$$

или, полагая $x^3 = z,$

$$(z - a)(8z + a)^2 - 27b^2z = 0. \quad (4)$$

Конечно, можно снова обратиться к формуле (3). Но оказывается, что применение этой формулы к уравнению (4) всегда приводит к отрицательному под квадратным корнем. Впрочем, это и не удивительно, поскольку, как легко доказать, кубический корень из комплексного числа имеет призначение.

Таким образом, на этом пути формулой (3) воспользоваться неудается. Но все же с ее помощью можно находить приближенные значения корней уравнения (2). Для этого нужно иметь, кроме таблицы квадратных и кубических корней, еще трионометрические таблицы и применить формулу Муавра, из которой следует, что

$$\cos \alpha + i \sin \alpha = \left( \cos \frac{\alpha}{3} + i \sin \frac{\alpha}{3} \right)^3.$$
