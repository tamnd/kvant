Из этих равенств находим
$$x = \frac{385ag}{55g} = 7a,$$
то есть точка опоры совпадает с центром шарика массы $m_7$.

Рассмотренная задача по существу есть задача на определение центра тяжесте для случая линейного расположения точных масс.

Докажите, что положение центра тяжесте системы, состоящий из $n$ материалов точек, массы которых $m_1, m_2, \dots, m_n$, лежащих на одной прямой и имеющих координаты соответствующего $x_1, x_2, x_3, \dots, x_n$, определяется координатой

$$x_c = \frac{\sum_{i=1}^{n} m_i x_i}{M},$$

где $M = \sum_{i=1}^{n} m_i$ — масса всей системы.

Для тел, размеры которых очень малы по сравнению с радиусом Земли, силы тяжесте, действующие на отдельные части тела, можно считать параллельными друг другу и сохраняющими для каждой из частиц постоянную величины при любых поворотах тела. Равнодействующая всех элементов сил тяжесте есть сила тяжесте, действующая на все тело. Абсолютная величина ее равна

$$Mg = \Sigma m_i g,$$
и приложена эта сила к центру масс, так как любое тело, падающее свободно (под действием только силы тяжесте), движется поступательно. Поэтому центр масс называют центром тяжесте тела.

Итак, центром тяжесте третього тела называется точка, в которой приложена равнодействующая сил тяжесте, действующих на частию данного тела.

Нужно отметить, что центр тяжесте может лежать и вне пределов данного тела (например, для колба, согласно тонкого стержня и т. п.).
