1. Пусть $ABCD$ — выпуклый четырехугольник, удовлетворяющий условию задачи. Обозначим $|AB| = a$, $|BD| = b$, $|CD| = c$. По условиям $a + b + c = 16$ ($cm$). Оценим площадь четырехугольника $ABCD$:

$$32 \leq \frac{1}{2}ab + \frac{1}{2}bc$$ (поскольку $S_{\triangle ABCD} = S_{\triangle ABD} + S_{\triangle BCD}$), причем равенство достигается, лишь если $b = 8$ ($cm$). Значит, $b = 8$ ($cm$), $ABD = BDC = 90^\circ$, а отсюда легко следует, что $|AC| = 8\sqrt{2}$ ($cm$).

2. Сделаем замену $x = 2\cos \alpha$, тогда $P_1(x) = 2\cos 2\alpha$, $P_2(x) = (2\cos 2\alpha)^2 - 2 = 2\cos 4\alpha$ и далее по индукции несложно показать, что $P_n(x) = 2\cos (2^n\alpha)$.

Данное уравнение перепишется в виде $2\cos(2^n\alpha) = 2\cos \alpha$, откуда $\sin \frac{(2^n - 1)\alpha}{2} \times \sin \frac{(2^n + 1)\alpha}{2} = 0$, $\alpha_1 = \frac{2k\pi}{2^n - 1}$, $\alpha_2 = \frac{2l\pi}{2^n + 1}$, $x_1 = 2\cos \frac{2k\pi}{2^n - 1}$, $x_2 = 2\cos \frac{2l\pi}{2^n + 1}$ ($k = 0, 1, \ldots, 2^{n-1} - 1$; $l = 1, 2, \ldots, 2^{n-1}$). Осталось доказать, что все эти корни различины, так как многочлен $P_n(x) - x$ имеет степень $2^n$ и не может иметь большие чем $2^n$ корней. Различие корней внутри серий следует из многонотистики функции $\cos \alpha$, а различие корней из разных серий следует из взаимной простоты чисел $2^n - 1$ и $2^n + 1$.
