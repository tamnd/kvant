Рис. 7.

АСВ (рис. 6). Получим равноведенный треугольник $A_1B_1C_1$, удовлетворяющий условиям Lemmies 2. Дальше рассуждаем так же, как в доказательстве (T1).

Мы переходим, наконец, к самой задаче M372. Тепер для ее полного решения осталось сделать лишь небольшой логический шаг.

В условиям M372 требуется доказать два утверждения:

необходимость условия $\hat{C} > 120^\circ$ и его достаточно для выполнения неравенства $|AP| + |BP| + |CP| \geq |AC| + |BC|$ для любой точки $P$ плоскости. Достаточно мы только что доказали: это и есть теорема (T2). Докажем не обходиимость условия $\hat{C} < 120^\circ$, то существует $P = P_0$, для которого это неравенство неверно. Рассмотрим два случая. Если все углы в треугольнике $ABC$ меньше 120°, то, согласно (T1), в качестве такой точки $P_0$ можно взять точку Торичелли $T$. Если же один из углов — скажем $\hat{A}$ — больше или равен 120°, то в роли точки $P_0$ может выступить сама вершина $A$ (поскольку $|BC| > |AB|$).

Решение этой задачи требует только аккуратных логических умозаключений для бесконечных множества. Вот самый характерный пример: «Пусть $P$ — какое-то свойство члена последовательности $x_n$. Тогда либо для всех членов, начиная с некоторого, свойство $P(x_n)$ выполнен, либо найдется бесконечного многочленов, для которых $P(x_n)$ не выполнен. Рассуждания такого типа особенно часто встречаются в учебниках по анализу — при изучении пределов и т.п.

a) Конечные куски последовательности цифр (намуральные числа) будем называть словами (для нас это действительное слова — в алфавите из «букв» 0, 1, ..., 9). Тогда ли ибо для каждой знака нашей десятичной дроби (начиная с некоторого) есть слово первого класса, начинающийся с этого знака, или его существует бесконечного многочленов таких, что все начинающиеся с них слова — не первого класса (то есть все второго класса).

Первый случай: мы можем (начиная с некоторого места) отрезать от нашей дроби последовательного одного первого класса за другим, то есть десятичный дробя разрезать на слова первого класса (кроме, быть может, начального слова; рис. 7).

Второй случай: отметим (на рисунке 7 — красным) знаки нашей дроби, с которых начинаются слова лишь второго класса. Ясно, что слова, начинающиеся с некоторого места, идущие до следующей красной буквы, дают требуемое разрезание дроби на слова второго класса.

б) Пусть слова разбиты на $N$ классов. Мы доказем индукцией по $N$ утверждение задачи в несколько успешном виде (как часто бывают, доказать больше оказываться легче *). А именно, мы доказем, что если дробь уже как-то (начиная с некоторого места $n_0$) разделена на куски — назовем их слогами, — то можно ее разрезать (начиная с некоторого места $n_1$) на слова одного класса, не разрезая словов, то есть так, что каждое слово будем сосмотреть из нескольких словов.
