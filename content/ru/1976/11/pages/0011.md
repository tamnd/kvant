Л. Цинман

«Парадокс исследователь»

При доказательстве утверждения методом математической индукции инота возникает необходимая ситуация. Проиллюстрируем ее на двух примерах.

Пример 1

Докажем методом математической индукции, что для всех натуральных $n$ справедливо следующее утверждение: сумма кубов первых $n$ натуральных чисел есть квадрат некомороо натурального числа.

Обозначим это утверждение через $A(n)$. Доказательства методом математической индукции проводятся, как известно, в два этапа.

a) Базис идукции: $A(1)$. Убеждаемся в справедливости $A(1)$:
$$1^3 = 1^2.$$
6) Иndукции шаг: $A(k) \Rightarrow A(k+1)$. Предположим, что для неокоторого натурального числа $k$ справедливо утверждение $A(k)$, и докажем, что тогда справедливо и $A(k+1)$. Итак, путь нашлось такое натуральное число $p$, для которого
$$1^3 + 2^3 + \ldots + k^3 = p^2.$$ (1)
Докажем, что тогда существует такое натуральное число $q$, для которого
$$1^3 + 2^3 + \ldots + k^3 + (k+1)^3 = q^2.$$ (2)
Из (2) и (1) следует, что нам надо доказать существование такого $q$, для которого
$$(k+1)^3 = q^2 - p^2.$$ (3)

Но как это можно было бы доказать? Естественно пути доказательства не видно.

Итак, попытка доказать нашей утверждение неосредственным применением метода математической индукции наолкнулась на трудности при проведении индукционного шага.

Вернемся снова к рассмотрению $A(n)$ и проверим его справедливость для нескольких начальных значений $n$:
$$1^3 = 1^2;$$
$$1^3 + 2^3 = 3^2;$$
$$1^3 + 2^3 + 3^2 = 6^2;$$
$$1^3 + 2^3 + 3^3 + 4^3 = 10^2;$$
$$1^3 + 2^3 + 3^3 + 4^3 + 5^3 = 15^2.$$

Присмотревшись к этим равенствам, приходим к гипотезе: для всех натуральных $n$ справедливо утверждение: сумма кубов первых $n$ натуральных чисел есть квадрат натурального числа, равное сумме этих чисел.

Обозначим это утверждение через $B(n)$. Конечно, $B(n)$ несет в себе больше информации, чем $A(n)$, и потому его естественно считать более сильным утверждением. Доказав $B(n)$, мы получим справедливость $A(n)$ в качестве очевидного следствия.

Попробуем теперь применить метод математической индукции к доказательству усиленного утверждения.

a) Справедливость $B(1)$ фактически уже установлена:
$$1^3 = 1^2.$$
6) Допустим, что для неокоторого натурального числа $k$ справедливо $B(k)$:
$$1^3 + 2^3 + \ldots + k^3 = (1 + 2 + \ldots + k)^2.$$ (4)
Докажем, что тогда справедливо и $B(k+1)$:
$$1^3 + 2^3 + \ldots + k^3 + (k+1)^3 = (1 + 2 + \ldots + k + k + 1)^2.$$ (5)
