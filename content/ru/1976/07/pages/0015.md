Рис. 7.

Заряд $q'_2$, индуцированный на внешней сфере, найдем из условия, что алгебраическая сумма зарядов, находящихся внутри заемленной поверхности, равна нулю:

$$q'_1 + q'_2 + q = 0.$$ (9)

Таким образом, нам остается найти отношение $\varphi/\varphi_1$. Предположим, что, когда внешняя сфера заемлена, а внутренняя имеет потенциаль $\varphi_1$, заряд внутренней сферы равен $q_0$. Очевидно, что при этом на внешней сфере наведется заряд $-q_0$. Выразим потенциальы $\varphi$ и $\varphi_1$ через заряды $q_0$ и $-q_0$:

$$\varphi = \frac{q_0}{r_1 + d_1} + \frac{-q_0}{r_2},$$

$$\varphi_1 = \frac{q_0}{r_1} + \frac{-q_0}{r_2}.$$ (10)

Тогда окончательно из равенств (8) – (10) получим:

$$q'_1 = -q \frac{r_1 d_2}{(r_1 + d_1)(d_1 + d_2)},$$

$$q'_2 = -q \frac{r_2 d_1}{(r_1 + d_1)(d_1 + d_2)}.$$

$$q'_1 = -q \frac{r_1 d_2}{(r_1 + d_1)(d_1 + d_2)} = -q \frac{d_2}{(1 + d_1/r_1)(d_1 + d_2)},$$

$$q'_2 = -q \frac{r_2 d_1}{(r_1 + d_1)(d_1 + d_2)} = -q \frac{d_1}{(1 - d_2/r_2)(d_1 + d_2)}.$$

$$q'_1 = -q \frac{d_2}{d_1 + d_2},$$
