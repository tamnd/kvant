$$L(x, t) = 0 \cdot x + 1 \cdot t = t. \tag{9}$$
Мы получили задачу линейного программирования. Сведем ее к ОЗЛП.
Система (8) равносильна системы
$$\begin{cases} 2x + 9t - 45 \geq 0, \\ -2x + 45t - 25 \geq 0. \end{cases} \tag{10}$$

Обозначим $2x + 9t - 45$ через $y_1$, $-2x + 45t - 25$ через $y_2$. Тогда $2x + 9t - 45 = y_1$, $-2x + 45t - 25 = y_2$ и $y_1 \geq 0, y_2 \geq 0$. Нашу задачу мы можем теперь сформулировать так: найти неотрицательные значения переменных $x, t, y_1, y_2$, которые удовлетворяют бы системе уравнения
$$\begin{cases} 2x + 9t - y_1 = 45, \\ -2x + 45t - y_2 = 25 \end{cases} \tag{11}$$

и обращали в минимум целевую функцию $L(x, t, y_1, y_2) = t$. А это уже ОЗЛП. Решим ее симплекс-методом.

Выберем в качестве базисных переменных $y_1$ и $y_2$ (систему (11) легче всего решить относительно них) и выразим их через свободные переменные $x, t$:
$$\begin{cases} y_1 = 2x + 9t - 45, \\ y_2 = -2x + 45t - 25. \end{cases} \tag{12}$$

Полагая свободные переменные равными нулю, получим решение системы (12) и (11):
$$x^{(1)} = t^{(1)} = 0, y_1^{(1)} = -45, y_2^{(1)} = -25.$$
Это решение не является допустимым.

Выберем теперь в качестве базисных переменных две другие переменные, например $t$ и $y_2$. (В теории линейного программирования существует метод, указывающий, каким образом выбирать новые свободные переменные так, чтобы приближаться к области допустимых решений. Здесь мы этот метод не излагаем.) Разрешим систему (11) относительно них:
$$\begin{cases} t = -\frac{2}{9}x + \frac{1}{9}y_1 + 5, \\ y_2 = -12x + 5y_1 + 200. \end{cases} \tag{13}$$

Полагая свободные переменные равными нулю, получим решение системы (13) и (11):
$$x^{(2)} = y_1^{(2)} = 0, t^{(2)} = 5, y_2^{(2)} = 200. \tag{14}$$

Решение (14) уже является допустимым. Чтобы проверить, является ли оно оптимальным, выразим целевую функцию $L$ через свободные переменные $x$ и $y_1$. Из (9) и (13)
$$L(x, t, y_1, y_2) = -\frac{2}{9}x + \frac{1}{9}y_1 + 5. \tag{15}$$

Значение целевой функции $L$ на решении (14) равно 5.

Поскольку коэффициент при $x$ в (15) отрицательен, решение (14) не является оптимальным: увеличивая значение переменной $x$, мы будем уменьшать значение целевой функции $L$.

В общих уравнениях системы (13) коэффициенты при $x$ отрицательны. Поэтому увеличение значения переменной $x$ описано как для $t$, так и для $y_2$. Это увеличение может сделать их отрицательными. Из первого уравнения системы (13) следует, что значение переменной $x$ можно увеличать до $-5 / \left(-\frac{2}{9}\right) = \frac{45}{2} = 22 \frac{1}{2}$ (при таком значении $x$ и при $y_1 = 0$ получим $t = 0$; при дальнейшем увеличении $x$ значение переменной $t$ становится отрицательным); из второго — до $-\frac{200}{12} = \frac{50}{3} = 16 \frac{2}{3}$. Таким образом, при увеличении значения переменной $x$ равше обратится в нуль переменная $y_2$: она находится в «болееугрожаемом» положении, чем $t$.
