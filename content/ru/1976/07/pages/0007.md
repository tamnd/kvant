$$\begin{align*}
x_{k+1} &= \alpha_{k+1,1} x_1 + \alpha_{k+1,2} x_2 + \\
&\quad + \dots + \alpha_{k+1,k} x_k + \beta_{k+1}, \\
x_{k+2} &= \alpha_{k+2,1} x_1 + \alpha_{k+2,2} x_2 + \\
&\quad + \dots + \alpha_{k+2,k} x_k + \beta_{k+2}, \\
x_n &= \alpha_{n,1} x_1 + \alpha_{n,2} x_2 + \\
&\quad + \dots + \alpha_{n,k} x_k + \beta_n.
\end{align*}$$

Положив все свободные переменные равными нулю, получим следующие системы (1):

$$\begin{align*}
x_1^0 &= x_2^0 = \dots = x_k^0 = 0, \\
x_{k+1}^0 &= \beta_{k+1}, x_{k+2}^0 &= \beta_{k+2}, \dots \\
\dots, x_n^0 &= \beta_n.
\end{align*}$$

Если все свободные члены $\beta_{k+1}, \beta_{k+2}, \dots, \beta_n$ неотрицательны, решение (6) является допустимым.

Чтобы проверить, является ли оно оптимальным, выразим целевую функцию $L$ через свободные переменные $x_1, x_2, \dots, x_k$, подставив выражения для $x_{k+1}, x_{k+2}, \dots, x_n$ из (5) в (2):

$$L(x_1, x_2, \dots, x_n) = d_0 + d_1 x_1 + d_2 x_2 + \dots + d_k x_k.$$

Из (6) вытекает, что $L(x_1^0, x_2^0, \dots, x_n^0) = d_0$. Посмотрим, не может ли мы уменшить значение целевой функции $L$, увеличивая значения свободных переменных $x_1, x_2, \dots, x_k$ (уменьшать мы их не можем, так как в решении (6) они равны нулю, а мы ищем допустимое решение).

Если все коэффициенты $d_1, d_2, \dots, d_k$ в равенстве (7) неотрицательны, то, увеличивая значения свободных переменных, мы будем уменшать значение функции $L$, т. е. будем уличать решение. В этом случае нам решение не является оптимальным.

Пусть, например, в равенстве (7) отрицательен коэффициент $d_1$. Если в системе (5) все коэффициенты при $x_1$ неотрицательны, то любое увеличение значения переменной $x_1$ оставит значения переменных $x_{k+1}, x_{k+2}, \dots, x_n$ неотрицательными и мы не выйдем из области допустимых решений. Значение же функции $L$ будет при этом неограниченно уменьшаться. Таким образом, в этом случае уравнения системы (5) есть также, в которых коэффициент при $x_1$ отрицательен. Для переменных, стоящих в левых частях этих уравнений, увеличение значения переменной $x_1$ описано: оно может сделать их отрицательными.

Если, например, $\alpha_{k+1,1} < 0$, то, очевидно, значение переменной $x_1$ можно уменшить только до $-\frac{\beta_{k+1}}{\alpha_{k+1,1}}$. (При $x_1^0 = -\frac{\beta_{k+1}}{\alpha_{k+1,1}}$, $x_2^0 = \dots = x_k^0 = 0$ получим $x_{k+1}^0 = 0$.)

Средние переменных, для которых увеличение значения переменной $x_1$ описано, выберем ту, которая равше всех обратится в нуль, т. е. ту, для которой увеличина $-\frac{\beta_l}{\alpha_l,1}$ меньше всего.

Пусть такая «наиболее угрожаемая» переменная будет $x_r$.

Выведем теперь из числа свободных переменных $x_1$ и переведем вместе в группу свободных переменных $x_r$, т. е. разрешим систему (1) относительно базисных переменных

$$x_1, x_{k+1}, \dots, x_{r-1}, x_{r+1}, \dots, x_n.$$
