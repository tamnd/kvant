$$\overline{ab} = \overline{ab}$$ (4)
и называем $\overline{ab}$ произведением $\overline{a}$ и $\overline{b}$, а само действие — умножением. Конечно, и в этом случае нужно доказать, что определение корректно, то есть нужно убедиться в следующем:

щем:
если $\overline{a}_1 = \overline{a}_2$ и $\overline{b}_1 = \overline{b}_2$, то $\overline{a_1b_1} = \overline{a_2b_2}$.

Пусть, в самом деле, $a_i = q'_i n + r'$, $i = 1, 2$, и $b_j = q'_j n + r'$, $j = 1, 2$. Тогда
$$\overline{a_1b_1} = \overline{(q'_1 n + r')(q'_1 n + r'')} = \overline{n (nq'_1 q'_1 + r'q'_1 + r''q'_1) + r'r''} = \overline{r'r''}$$
$$\overline{a_2b_2} = \overline{n (nq'_2 q'_2 + r'q'_2 + r''q'_2) + r'r''} = \overline{r'r''}$$.
