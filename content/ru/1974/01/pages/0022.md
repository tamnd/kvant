4. Пусть окружности $\alpha, \beta, \gamma$ и $\delta$ с центрами $A, B, C$ и $D$ и радиусами $a, b, c$ и $d$ попарно касаются друг друга внешним образом. Тогда
$$\cos^2 \frac{\angle BDC}{2} = \frac{(b + d + c)d}{(b + d)(d + c)},$$
$$\sin^2 \frac{\angle BDC}{2} = \frac{bc}{(b + d)(d + c)},$$
$$\sin^2 \frac{\angle ADB}{2} = \frac{ab}{(a + d)(d + b)},$$
$$\sin^2 \frac{\angle ADC}{2} = \frac{ac}{(a + d)(d + c)}.$$

Доказательство. В $\triangle BDC$ выразим стороны и полуперimetр через $b, d$ и $c$:
$$BC = b + c, \quad BD = b + d, \quad DC = d + c,$$
$$\frac{1}{2}(BC + BD + DC) = b + d + c$$

и воспользовемся формулами пункта 3. Другие две формулы получим аналогично из $\triangle ADB$ и $\triangle ADC$.
4'. Пусть окружности $\alpha, \beta, \gamma$ с центрами $A, B, C$ и радиусами $a, b, c$ попарно касаются друг друга внешним образом и все три касаются изнутри окружности в с центром $E$ и радиусом $e$. Тогда
$$\cos^2 \frac{\angle BEC}{2} = \frac{(b - e + c)(-e)}{(b - e)(-e + c)},$$
$$\sin^2 \frac{\angle BEC}{2} = \frac{bc}{(b - e)(-e + c)},$$
$$\sin^2 \frac{\angle AEB}{2} = \frac{ab}{(a - e)(-e + b)},$$
$$\sin^2 \frac{\angle AEC}{2} = \frac{ac}{(a - e)(-e + c)}.$$

Доказательство — такое же, как в пункте 4.
5. В условях пункта 4 положим $k = 1/a, l = 1/b, m = 1/c, n = 1/d$.

Тогда
$(-k + l + m + n)^2 = 4(lm + mn + nl).$

Доказательство. Согласно пункта 2 и 4
$$\left[ \frac{ab}{(a + d)(d + b)} + \frac{ac}{(a + d)(d + c)} \right]^2 = 4 \frac{ab}{(a + d)(d + b)} \times \frac{ac}{(a + d)(d + c)} \cdot \frac{(b + d + c)d}{(b + d)(d + c)}.$$

Умножив обе части равенства на $[(a + d)(b + d)(c + d)/abcd]^2$, получим
$$\left[ \frac{c + d}{cd} + \frac{b + d}{bd} - \frac{a + d}{ad} \right]^2 = 4 \frac{b + d + c}{bdc},$$

или окончательно
$(-k + l + m + n)^2 = 4(lm + mn + nl).$

Заметание. Формулы пункта 4' получаются из формул пункта 4, если заменить $d$ на $(-e)$. Поэтому доказанная в пункте 5 формула верна и в условиях пункта 4' при $n = -1/e$.

6. Кривизны $k, l, m$ и $n$ окружностей $\alpha, \beta, \gamma$ и $\delta$, попарно касаются друг друга внешним образом, связанными формулой Содди
$(k + l + m + n)^2 = 2(k^2 + l^2 + m^2 + n^2).$

Та же формула верна, если $n$ — кривизна окружности $\varepsilon$, которое $\alpha, \beta$ и $\gamma$ касаются изнутри.

Доказательство. Преобразуем тожество
$(k + l + m + n)^2 = (-k + l + m + n)^2 + 4k(l + m + n)$

с учетом пункта 5:
$(k + l + m + n)^2 = 4(kl + km + kn + lm + ln + mn).$

Воспользовавшись тожеством
$(k + l + m + n)^2 - (k^2 + l^2 + m^2 + n^2) = 2(kl + km + kn + lm + ln + mn),$

получим
$(k + l + m + n)^2 = 2[(k + l + m + n)^2 - (k^2 + l^2 + m^2 + n^2)].$

Приведя подобные члены, получим формулу Содди.
