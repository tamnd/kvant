Цифры в кружках ознакомют оценки позиций, полученные описанным выше путем (для «низких» позиций — с помощью оценочной функции, для «вышетorious» — по минимальной процедуре). Цифры возле отрезков показывают последовательность расстояния соответствующих ходов при переборе. Двойными линиями отмещены лучшие ходы из каждой позиции.

Отметим только, что для большей наглядности рисунка мы ограничились небольшим числом возможных ходов из каждой позиции. В результате перевести этот алгоритм на язык машинны, превращив его в программу игры. Это тяжелая работа, требующая программистского искусства, так как от качества программы осуществления алгоритмов в заменной степении зависит время работы программы, то есть время выбора хода. Мы не в состоянии, естественно, воспроизвести устройство такой программы сколько-нибудь подробно, опишем его лишь в самых общих чертах.

Существуют шесть подпрограмм $P_1$—$P_6$ (по одной на каждой типи игры). Каждая из них составляет список ходов, возможных из данной позиции игрой данного типа. Подпрограмма $P_7$ координирует эти шесть подпрограмм и выписьвает все ходы, возможные в данной позиции.

Кроме перечисленных подпрограмм, имеется подпрограмма $P_8$, которая выполняет оценкой ход, получая новую позицию, подпрограмма $P_9$, вычисляющая оценку

полученной позиции, подпрограмма $P_{10}$, реализующая минимальную процедуру, и, наконец, управляющая программа $P_0$. Последняя решает, к какой из подпрограмм обратиться, назначает, какая позиция расматривается и какой ход из нее делается, и собственно реализует алгоритм выбора хода.

Подпрограммы $P_1$—$P_7$ могут использовать вспомогательную информацию относительно позиции. Так, при построении возможных ходов удобно использовать «растр возможностей», который для каждой игры записывается следующим образом. Для каждой кедетки шахматной доски отводится один разряд; для всех доски достаточно занять две ячейки памяти, по 32 разряда в каждой. В разрядах, соответствующих полям, на которые можетойти данная игруга, ставится 1, остальные разряды содержат 0.
