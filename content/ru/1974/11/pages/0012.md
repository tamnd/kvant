⟦folio 10⟧

Попробуем теперь найти необходимые и достаточно условные условия для того, чтобы точка $x = \alpha$ корень многочлена (2) является точкой экстремума функции $y = ax^3 + bx^2 + cx + d$.

Воспользуемся формулой (3). Если $x = \alpha$ не является корнем квадратного трехчлена $x^2 + px + q$, то в достаточно малой окрестности точки $x = \alpha$ этот трехчлен сохраняет постоянный знак, а потому функция $y = a(x - \alpha)(x^2 + px + q)$ меняет знак при перехождения точку $x = \alpha$. То же самое будет в случае, когда $x = \alpha$ — двукратный корень трехчлена, то есть $x^2 + px + q = (x - \alpha)^2$ и, следовательно, $y = a(x - \alpha)^3$. В рассмотренных случаях экстремума нет. И лишь в одном случае функция не меняет знак при перехождения точку $x = \alpha$ — когда $x = \alpha$ — однократный корень квадратного трехчлена, то есть $x^2 + px + q = (x - \alpha)(x - \beta)$, или, что то же самое, $x = \alpha$ — двукратный корень многочлена (2), то есть

$$y = a(x - \alpha)^2(x - \beta),$$

где $\alpha \neq \beta$.

Итак, корень многочлена имеет степеня является его точкой экстремума моеда и molько моеда, когда этом корень двукратный.

Обобщением полученного результат является следующая:

Теорема 2. Для того чтобы точка $x = \alpha$ была точкой экстремума функции $y = ax^3 + bx^2 + cx + d$, необходимо и достаточно, чтобы существовал макое число $m$, при котором многочлен $P(x) = ax^3 + bx^2 + cx + d$ имеет двукратный корень $x = \alpha$, то есть

$$P(x) = a(x - \alpha)^2(x - \beta),$$

(4)

еде $\alpha \neq \beta$.

Теорема 3 (достаточные условия максимума и минимума). Пусть функция $y = ax^3 + bx^2 + cx + d$ имеет экстремум в точке $x = \alpha$ и $m$ — значение функции в точке $x = \alpha$. Представим многочлен $P(x) = ax^3 + bx^2 + cx + d$ в виде (4). Тогда, если $a(\beta - \alpha) > 0$, то $x = \alpha$ — точка максимума; если $a(\beta - \alpha) < 0$, то $x = \alpha$ — точка минимума.

Доказательство. Если $a > 0$ и $\alpha < \beta$, то в окрестности точки $x = \alpha$, не содержащей внутри себя точку $x = \beta$ (рис. 5), имеем $P(x) \leq 0$, то есть $y \leq m$. Значит, $x = \alpha$ — точка максимума. Если $a < 0$ и $\alpha > \beta$, то также получается точка максимума. Объединяя эти два случая, получаем, что если $a(\beta - \alpha) > 0$, то в точке $x = \alpha$ функция $y$ имеет максимум. Вторая часть теоремы доказывается аналогично.

Пример 2. Исследовать на экстремум функцию

$$y = x^3 - 3x^2 - 9x + 5$$

(5)

и построить ее график.

Попробуем подобрать числа $m$, $\alpha$, $\beta$ так, чтобы выполнялось тожество $x^3 - 3x^2 - 9x + 5 - m = (x - \alpha)^2 \times (x - \beta)$ (причем $\alpha \neq \beta$). Отсюда $x^3 - 3x^2 - 9x + 5 - m = x^3 - (\beta + 2\alpha)x^2 + (2\alpha\beta + \alpha^2)x - \alpha^2\beta$. Для отыскания значений $m$, $\alpha$, $\beta$ мы получили систему уравнений:

$$\begin{align*}
\alpha_1 &= -1, \quad \beta_1 &= 5, \quad m_1 &= 10; \\
\alpha_2 &= 3, \quad \beta_2 &= -3, \quad m_2 &= -22.
\end{align*}$$
