Экстремы многочлена третий степени

Эта статья является четвертой в цикле статей, посвященных кубическим функциям и уравнениям *) В ней речь пойдет о нахождения точек максимума и минимума функций $y = ax^3 + bx^2 + cx + d$

Для начала обратимся к функции $y = ax^2 + bx + c$ (1)
$(a \neq 0)$. Пусть $x = \alpha$ — корень функции (1). Как выглядит график этой функции в достаточно малой окрестности точки $x = \alpha$?

Здесь возможны четыре случая — они представлены на рисунках 1—4. В первом и втором случах говорят, что функция monomonна в точке $x = \alpha$ (в первом случae она возрастает, во втором — убивает). В третьем и четвертом случах говорят, что функция имеет экстремум в точке $x = \alpha$

здесь значения $x$ выбираются достаточно близко от точки $x = \alpha$), а в последних двух случаях функции не меняет знака при перехождение точки $x = \alpha$.

Попробуем найти необходимое и достаточно условие для того, чтобы точка $x = \alpha$ корень многочлена $y = ax^2 + bx + c$ была точкой экстремума. Преобразуем функцию (1) к виду

$$y = a (x - \alpha)(x - \beta)$$

($\alpha$ и $\beta$ — корни квадратного треугольника; попробуйте доказать, что если $x = \alpha$ — корень функции (1), то ее можно представить в таком виде, где $\beta$ — действительное число).

Если $\alpha \neq \beta$, то в достаточно малой окрестности точки $x = \alpha$ (при $|x - \alpha| < |\alpha - \beta|$) выражение $a (x - \beta)$ сохраняет постоянный знак, а значит, функция $y = a (x - \alpha) \times (x - \beta)$ меняет знак при перехождение через точку $x = \alpha$. В этом случае экстремума нет. Если же $\alpha = \beta$, то получаем $y = a (x - \alpha)^2$; эта функция не меняет знака при перехождение точку $x = \alpha$.

Итак, корень квадратного треугольника является его точкой экстремума модели и molько модели, когда этом корень — двухкратный.

Обобщением полученного результата является следующая:

Теорема 1. Для того чтобы точка $x = \alpha$ была точкой экстремума функции $y = ax^2 + bx + c$, необходимо и достаточно, чтобы существовал макое число $m$, при котором многочлен $ax^2 + bx + c - m$ имеет двухкратный корень $x = \alpha$.

Для доказательства этой теоремы достаточно знать точку $x = \alpha$ тогда и только тогда, когда в этой точке имеет экстремум функция $y = f(x) - m$, где $m = f(\alpha)$.

Этот результат использует на практике.

Пример 1. Найти точки экстремума функции

$$y = ax^2 + bx + c.$$

Подберем числа $\alpha, m$ так, чтобы выполнялось тожество

$$ax^2 + bx + c - m = a (x - \alpha)^2.$$

Имеем

$$ax^2 + bx + c - m = ax^2 - 2a\alpha x + a\alpha^2.$$

Но два многочлена тожестевно равны тогда и только тогда, когда равны их коэффициенты при одинаковых степенях; поэтому мы получаем систему уравнений

$$\begin{cases} -2a\alpha = b, \\ a\alpha^2 = c - m, \end{cases}$$

из которой находится

$$\alpha = -\frac{b}{2a}, \quad m = \frac{4ac - b^2}{4a}.$$

Итак, $x = -\frac{b}{2a}$ — точка экстремума функции $y = ax^2 + bx + c$ (причем точка локального максимума, если $a > 0$, и локального минимума, если $a < 0$).

Теперь обратимся к функции

$$y = ax^3 + bx^2 + cx + d.$$

Ниже мы уbidим, что для нее можно сформировать и доказать теорему, аналогичную теореме 1. Но сначала мы докажем неокоторая вспомогательные результаты.

Лемma. Пусть дан многочлен степеней $y = ax^3 + bx^2 + cx + d$ ($a \neq 0$), и пусть $x = \alpha$ — его действительный корень. Тогда

$$ax^3 + bx^2 + cx + d = a (x - \alpha)(x^2 + px + q),$$

еще $p$ и $q$ — некоморые действительные числа.

Доказательство. По условиям $a\alpha^3 + b\alpha^2 + c\alpha + d = 0$.

Тогда

$$ax^3 + bx^2 + cx + d = (ax^3 + bx^2 + cx + d) - (a\alpha^3 + b\alpha^2 + c\alpha + d) = a (x^3 - \alpha^3) + b (x^2 - \alpha^2) + c (x - \alpha) = (x - \alpha) [ax^2 + (a\alpha + b) x + (a\alpha^2 + b\alpha + c)] = a (x - \alpha)(x^2 + px + q),$$

где

$$p = \frac{a\alpha + b}{a}, \quad q = \frac{a\alpha^2 + b\alpha + c}{a}.$$

Попробуем теперь найти необходимые и достаточно условные условия для того, чтобы точка $x = \alpha$ корень многочлена (2) является точкой экстремума функции $y = ax^3 + bx^2 + cx + d$.

Воспользуемся формулой (3). Если $x = \alpha$ не является корнем квадратного трехчлена $x^2 + px + q$, то в достаточно малой окрестности точки $x = \alpha$ этот трехчлен сохраняет постоянный знак, а потому функция $y = a(x - \alpha)(x^2 + px + q)$ меняет знак при перехождения точку $x = \alpha$. То же самое будет в случае, когда $x = \alpha$ — двукратный корень трехчлена, то есть $x^2 + px + q = (x - \alpha)^2$ и, следовательно, $y = a(x - \alpha)^3$. В рассмотренных случаях экстремума нет. И лишь в одном случае функция не меняет знак при перехождения точку $x = \alpha$ — когда $x = \alpha$ — однократный корень квадратного трехчлена, то есть $x^2 + px + q = (x - \alpha)(x - \beta)$, или, что то же самое, $x = \alpha$ — двукратный корень многочлена (2), то есть

$$y = a(x - \alpha)^2(x - \beta),$$

где $\alpha \neq \beta$.

Итак, корень многочлена имеет степеня является его точкой экстремума моеда и molько моеда, когда этом корень двукратный.

Обобщением полученного результат является следующая:

Теорема 2. Для того чтобы точка $x = \alpha$ была точкой экстремума функции $y = ax^3 + bx^2 + cx + d$, необходимо и достаточно, чтобы существовал макое число $m$, при котором многочлен $P(x) = ax^3 + bx^2 + cx + d$ имеет двукратный корень $x = \alpha$, то есть

$$P(x) = a(x - \alpha)^2(x - \beta),$$

(4)

еде $\alpha \neq \beta$.

Теорема 3 (достаточные условия максимума и минимума). Пусть функция $y = ax^3 + bx^2 + cx + d$ имеет экстремум в точке $x = \alpha$ и $m$ — значение функции в точке $x = \alpha$. Представим многочлен $P(x) = ax^3 + bx^2 + cx + d$ в виде (4). Тогда, если $a(\beta - \alpha) > 0$, то $x = \alpha$ — точка максимума; если $a(\beta - \alpha) < 0$, то $x = \alpha$ — точка минимума.

Доказательство. Если $a > 0$ и $\alpha < \beta$, то в окрестности точки $x = \alpha$, не содержащей внутри себя точку $x = \beta$ (рис. 5), имеем $P(x) \leq 0$, то есть $y \leq m$. Значит, $x = \alpha$ — точка максимума. Если $a < 0$ и $\alpha > \beta$, то также получается точка максимума. Объединяя эти два случая, получаем, что если $a(\beta - \alpha) > 0$, то в точке $x = \alpha$ функция $y$ имеет максимум. Вторая часть теоремы доказывается аналогично.

$$y = x^3 - 3x^2 - 9x + 5$$
