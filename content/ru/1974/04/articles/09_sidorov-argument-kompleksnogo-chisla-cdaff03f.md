Аргумент комплексного числа
Ю. В. Сидоров

В этой статье рассматривается понятие аргумента комплексного числа и тригонометрическая форма записи комплексного числа. При этом предполагается, что читатель знает определение комплексного числа, понятие модели и геометрическую интерпретацию комплексного числа *).

Определения
Начнем с определения аргумента комплексного числа. Чаще всего встречаются два определения.

Определение 1. Аргументом комплексного числа $z \neq 0$ называется угол между действительным осью и вектором $\vec{Oz}$, описываемый от положимного направления действительной оси. При этом, если

Определение 2. Аргументом комплексного числа $a + bi \neq 0$ называется угол φ, который удовлетворяет одновременно двум равенствам:

$$\begin{align*}
\sin \varphi &= \frac{b}{\sqrt{a^2 + b^2}}, \\
\cos \varphi &= -\frac{a}{\sqrt{a^2 + b^2}}.
\end{align*}$$

Чтобы до конца понять определение аргумента, необходимо условить следующее.

1°. В обихх определения угол может выражаться и в градусах, и в радианах. В школьном курсе математики равноправны обе записи. Для определности договорами в этой статье изменять углы только в радианах, причем слово «радIAN», как обычно, будем опускать. Такой выбор не случайен — в высшей математике чаще всего применяется именно радианное изменение углов. Поэтому аргументом комплексного числа следует считать отвлеченным числом.

Таким образом, в определении 1 слово «угол» надо помнить как «алгебраический угол», то есть отвлеченное число, выражающее число радиан величины «геометрического угла». Аналогично, в определении 2 число φ означает число радиан, а не градусов.

2°. Определения 1 и 2 эквивалентны: если φ является аргументом числа z = a + bi ≠ 0 в смысле определения 1, то выполняются равенства (1); наоборот, если φ — аргумент комплексного числа z = a + bi ≠ 0 в смысле определения 2, то φ — угол между положительным направлением действительной оси и вектором z. Это утверждение при a > 0, b > 0 вытекает непосредственно из рисунка (см. с. 41) и определений синуса и косинуса. Для остальных чисел z доказательство аналогично (проверьте!).

Таким образом, не имеет значения, какое из определений 1 или 2 выбрано за исходное — другое будет являться необходимым и достоинным критерiem.

3°. Для числа z = 0 понятие аргумента не существует. Поэтому для краткости во всех дальнейших расчудениях, связанных с понятием аргумента, будем предполагать (и этого нельзя забывать!), что z ≠ 0.

4°. Для фиксированного комплексного числа z ≠ 0 аргумент определяется неоднозначно: если φ₀ — неокторный аргумент числа z, то каждое из чисел

$$\varphi_0 + 2k\pi, \quad k = 0, \pm 1, \pm 2, \dots,$$

тоже является аргументом этого же числа z, и никакое число, не совпаданное ни с одним из чисел, указывается в (2), не является аргументом числа z (доказьте!).

Таким образом, для каждого фиксированного числа z ≠ 0 имеется бесконечное множество аргументов, из которых каждые два отрицательные dyres от dyres на число, кратное 2π.

5°. Многозначность аргумента, описанная в 4°, затрудняет понимание действий над аргументом комплексного числа. Но часто именно благодая этой многозначности удается решать довольно трудные задачи.

В некоторых последних по элементарной математике в определение аргумента включается ограничение вида 0 ≤ φ < 2π, то есть считается, что аргумент комплексного числа z — это наименьший неотрицательный угол между положительным оси и вектором z. Тогда для каждой числа z аргумент определяется однозначно, и на первый взгляд кажется, что все теория должна быть проще. Однако такое ограничение лишь еще больше усложняет правильная действия над аргументами (например, сумма аргументов двух комплексных чисел не всегда является аргументом какого-либо комплексного числа). Иногда это приводит к значительному неочевидному *), поэтому лучше придерживать общей приоритетю определения (1 или 2).

Arгумент комплексного числа

Рассмотрим вопрос о нахождения аргумента комплексного числа. Но сначала договораемся об обозначениях.

Для обозначения того факта, что число φ является аргументом комплексного числа z, пишут

$$\varphi = \arg z \text{ или } \arg z = \varphi.$$

(3) Например, какое из соответствий

$$\frac{\pi}{2} = \arg i$$

и

$$\arg i = \frac{\pi}{2}$$

означает только то, что число π/2 является аргументом числа i.

Заметим, что соответствия (3), хотя и выглядает формально как равенства, является необчислимыми. Однако из свойств обычных равенств является, например, следующое: если A = B и B = C, то A = C (A, B, C — числа или геометрические фигуры). А равенства (3) таким свойством не обладают. Например, можно записать, что

$$\frac{\pi}{4} = \arg (1 + i), \arg (1 + i) = \frac{9\pi}{4},$$

Таким образом, соответствия (3) можно читать так: «ф равняется аргументу числа $z$ или «аргумент числа $z$ равняется $\varphi$», но смысл этих фраз только один: $\varphi$ является аргументом числа $z$ или, другими словами, $\varphi$ является одним из аргументов числа $z$, как отмечалось в (2). Этот факт записьюот в виде формулы

$$\arg z = \varphi_0 + 2k\pi,$$

$$k = 0, \pm 1, \pm 2, \dots$$

Например, все значения аргумента числа $i$ содержатся в формуле

$$\arg i = \frac{\pi}{2} + 2k\pi, k = 0, \pm 1, \pm 2, \dots$$

Отметим, что «равенства» видна (4) часто встречаются при решении трионометрических уравнений. Например, решение уравнения $\sin x = 1$ записьяется так:

$$x = \frac{\pi}{2} + 2k\pi, k = 0, \pm 1, \pm 2, \dots$$

Смысл последнего «равенства» такой же, как и соответствия (4): для каждой целого $k$ число $\frac{\pi}{2} + 2k\pi$ удовлетворяет уравнению $\sin x = 1$ и только эти числа являются корнями уравнения $\sin x = 1$.

Для нахождения всех значений аргумента комплексного числа $z = a + bi \neq 0$ нужно найти все числа $\varphi$, удовлетворющие обимом равенством (1), то есть решить совместно уравнения (1).

Пример 1. Наимен все значения аргумента числа $z = -5$.

Так как $a = \text{Re} z = -5, b = \text{Im} z = 0$, то решениями первого уравнения $\cos \varphi = -1$ из системы (1) являются числа $\varphi = \pi + 2k\pi, k = 0, \pm 1, \pm 2, \dots$, а решениями второго уравнения $\sin \varphi = 0$ числа $\varphi = n\pi, n = 0, \pm 1, \pm 2, \dots$.

Общими корнями обонх уравнения являются числа

$$\varphi = \pi + 2k\pi, k = 0, \pm 1, \pm 2, \dots$$

Ответ: $\arg (-5) = \pi + 2k\pi, k = 0, \pm 1, \pm 2, \dots$.

Заметим, что ответ в примере 1 можно записать и в другом виде, например:

$$\arg (-5) = -\pi + 2n\pi, n = 0, \pm 1, \pm 2, \dots,$$

или

$$\arg (-5) = 3\pi + 2m\pi, m = 0, \pm 1, \pm 2, \dots$$

Нужно иметь в виду, что все эти формулы различные записи эквивалентны (в каждом из этих ответов содержатся все значения аргументов числа $-5$), то есть это одинаковые ответы, написанные разными формулами.

Arгумент комплексного числа $z = a + bi \neq 0$ можно нахождение процедуры сначала точка $z = a + bi$ (например, используя геометрическую интерпретацию комплексного числа), а затем воспользоваться одним (любым) из уравнений (1) (доказательный ответ по формуле (4)).

Ответ: $\arg (-1 + i) = \frac{3\pi}{4} + 2k\pi, k = 0, \pm 1, \pm 2, \dots$.

Заметим, что если $\varphi = \arg (a + bi), a \neq 0$, то

$$\tg \varphi = \frac{b}{a}.$$

Однако обратное утверждение неверно: из уравнения (5) нельзя

Аналогично тому, как это сделано в примерах 2 или 3, находим (найDITе!):

$$\arg(\sqrt{3} + i) = \frac{\pi}{6}$$

(то есть $\pi/6$ является одним из аргументов числа $\sqrt{3} + i$). Остается выяснить, как писать ответ: достаточно указыть одно значение аргумента или нужно найти все?

Вспомним, например, задачу: решить уравнение $x^2 = 1$. Это уравнение имеет два корня $x_1 = 1$ и $x_2 = -1$. Чтобы ответ был полным, в него необходимо включить оба корня. Часто и в геометрических задачах встречаются необходимые ответы. Например, найти сторону $AB$ треугольника $ABC$, если $AC = 8$ см, $BC = 7$ см, $\angle A = \pi/3$. Полный ответ должен быть таким: $AB = 3$ см или $AB = 5$ см (доказатель!).

Ответ: $\arg(\sqrt{3} + i) = \frac{\pi}{6} + 2k\pi, k = 0, \pm 1, \pm 2, \dots$.

Таким образом, вопроса 4 является простой короткой формулировкой вопроса примера 2.

Обратим внимание на одну распространенную ошибку. Иного абитуренты пытаются находить аргумент числа $a + bi$ по формуле $\varphi = \arctg\frac{b}{a}$, а не которые даже принимают эту формулу за определение аргумента. Однако для каждой $x$ функция аргумента $x$ имеет только одно значение, причем $-\frac{\pi}{2} < \arctg x < \frac{\pi}{2}$. Значит, формула $\arg(a + bi) = \arctg\frac{b}{a}$ верна только при $a > 0$, причем дает только одно из значений аргумента.

Можно доказать (доказатель!) справедливость следующей формулы:

$$\arg(a + bi) = \begin{cases} \frac{\pi}{2}, \text{ если } a = 0, b > 0; \\ -\frac{\pi}{2}, \text{ если } a = 0, b < 0; \\ \arctg\frac{b}{a}, \text{ если } a > 0; \\ \pi + \arctg\frac{b}{a}, \text{ если } a < 0. \end{cases}$$

По этой формуле можно находить одно из значений аргумента, но часто проще поступать так, как сделано в примерах 2 или 3.

Тригонометрическая форма комплекского числа

Рассмотрим понятие тригонометрической формы комплекского числа. Вспомним, что модуlem комплекского числа $z = a + bi$ называется число

$$r = |a + bi| = \sqrt{a^2 + b^2}.$$

Пусть $\varphi = \arg(a + bi)$, перепишем формулы (1) так:

$$\cos \varphi = \frac{a}{r}, \sin \varphi = \frac{b}{r},$$

откуда $a = r \cos \varphi, b = r \sin \varphi$, а потом

$$a + bi = r(\cos \varphi + i \sin \varphi).$$

Таким образом, любое комплекское число $a + bi \neq 0$ можно записать в виде (6), если $r$ — модуль числа $a + bi$, а $\varphi$ — один из аргументов этого числа:

$$r = |a + bi|, \varphi = \arg(a + bi).$$

Верно и обратное утверждение (доказатель!)： если комплекское число $a + bi$ представлено в виде (6), если $r > 0$, то

$$r = |a + bi|, \varphi = \arg(a + bi).$$

Определение. Представление комплексною числа $z$ в виде

$$z = r(\cos \varphi + i \sin \varphi),$$

(7) если $r > 0$, называется тригонометрической формуой записи комплексною числа.

Сказанное выше означает, что каждое комплекское число $z \neq 0$ можно представить в тригонометрической форме (7), причем

$$r = |z|, \varphi = \arg z.$$

Для того, чтобы найти тригонометрискую форму заданного комплексною числа, нужно найти метод числа, какой-нибудь аргумент этого числа, а затем записать это число в виде (7). Если при этом $|z| = r = 1$, то можно целый $r$ в формуле (7), как обычно, опускается, то есть в этом случае тригонометрическая форма записи имеет вид

$$z = \cos \varphi + i \sin \varphi.$$

Например, для числа $i$ запись

$$i = \cos \frac{\pi}{2} + i \sin \frac{\pi}{2}$$

является тригонометрической формуой записи этого числа.

Заметим, что в силу многозначности arg $z$ тригонометрическая форма фиксированного комплексною числа также неоднозначна. Например, для числа $i$ тригонометрической формуой является также записи

$$i = \cos \frac{5\pi}{2} + i \sin \frac{5\pi}{2},$$

$$i = \cos \left(-\frac{3\pi}{2}\right) + i \sin \left(-\frac{3\pi}{2}\right)$$

и другие.

Необходимо подчернуть, что не всекая запись комплексною числа через тригонометрические функции является тригонометрической формуой этого числа. Например, запись числа $i$ в виде $i = \cos \frac{\pi}{2} + i \sin \frac{5\pi}{2}$ или $i = (-1)\left(\cos \frac{3\pi}{2} + i \sin \frac{3\pi}{2}\right)$ не является тригонометрической формуой числа $i$. Так как аргументы числа $i$ являются числами $i$ является числами $i$.

$$\frac{\pi}{2} + 2k\pi, k = 0, \pm 1, \pm 2, \dots,$$

и только они, то и тригонометрическая форма числа $i$ обязательно имеет вид

$$z = 1 + \cos \frac{10\pi}{9} + i \sin \frac{10\pi}{9}$$

можно представить в виде (проверьте!):

$$z = 2 \cos \frac{5\pi}{9} \left(\cos \frac{5\pi}{9} + i \sin \frac{5\pi}{9}\right) =$$

$$= 2 \cos \frac{14\pi}{9} \left(\cos \frac{14\pi}{9} + i \sin \frac{14\pi}{9}\right).$$

Вторая из этих записей является

Итак, если $r = |z|$, $\varphi_0 = \arg z$ (мо есть $\varphi_0$ является одним из аргументов числа $z$), то для каждого целого $k$ запись $z = r[\cos(\varphi_0 + 2k\pi) + i\sin(\varphi_0 + 2k\pi)]$ является тригонометрической формуой комплексного числа $z$, и никакая другие запись не является тригонометрической формуой этого числа.

На этом в школьном курсе математики заканчивается рассмотрение свойств аргумента комплексного числа.

Одно свойство аргумента

С помощью тригонометрической формуы легко выводится следующие правила умножения и деления комплексных чисел (проверьте!): если

$$z_1 = r_1(\cos \varphi_1 + i\sin \varphi_1),$$
$$z_2 = r_2(\cos \varphi_2 + i\sin \varphi_2),$$

mo

$$z_1z_2 = r_1r_2[\cos(\varphi_1 + \varphi_2) + i\sin(\varphi_1 + \varphi_2)],$$
$$\frac{z_1}{z_2} = \frac{r_1}{r_2}[\cos(\varphi_1 - \varphi_2) + i\sin(\varphi_1 - \varphi_2)].$$

Из этого правила неоспределенно вытекает следующая важная теорема Пусть $\varphi_1 = \arg z_1$ и $\varphi_2 = \arg z_2$. Тогда

$$\varphi_1 + \varphi_2 = \arg(z_1z_2),$$
$$\varphi_1 - \varphi_2 = \arg\frac{z_1}{z_2}.$$

Вспомним, что запись $\varphi = \arg z$ означает только тот факт, что число $\varphi$ является одним из аргументов комплексного числа $z$. Значит, формулы в теореме следует читать так: сумма аргументов комплексной числа $z$ является аргументом произведения, а разность аргументов делимого и делимая аргументом частного.

Обратим внимание на одну распространенную ошибку. Иnorда первого частного теоремы записью в виде «формулы»
