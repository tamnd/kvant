3. $x_1 = 0, y_1 = 0; x_2 = 0, y_2 = 2; x_3 = 2; y_3 = 0; x_4 = 2, y_4 = 2$.

Указание е. Второе уравнение удовлетворяется при $x + y = 0$, однако при этом первое уравнение удовлетворяется лишь если $x = y = 0$. Таким образом, найдено одно решение. Для отыскания других перепущем системы в виде

$$\begin{cases} x^2 + y^2 = 2(x + y), \\ x^2 - xy + y^2 = 4, \end{cases}$$

или

$$\begin{cases} (x + y)^2 = 2(x + y) + 2xy, \\ (x + y)^2 = 4 + 3xy. \end{cases}$$

Легко исключать $xy$, в результате получим уравнение

$$(x + y)^2 - 6(x + y) + 8 = 0.$$

Остается рассмотреть две возможность: $x + y = 2$ и $x + y = 4$.
