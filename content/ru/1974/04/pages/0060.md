2. $S = 15\sqrt{3}$. Решение. Из условия видно, что углы при нижнем основании трапеции — острыя, а потому ее нижнее основание больше верхнего. Пусть $AB$ — верхнее основание трапеции $ABCD$ (рис. 2); убедитесь, что решение не изменится, если верхним основанием считать $CD$, так что $AB < CD$. Положим $AK = KB = x$, $CM = MD = y$; тогда $x < y$.

Так как $\Delta KD = \Delta KDM$ (почему?), то треугольник $DAK$ равноведренный, откуда $AD = x$. Аналогично, $BC = y$ (доказите!). Проведем $BP \parallel AD$; так как $BP = x < y = BC$, то в треугольнике $BPC$ угол $BPC$ больше угла $BCP$ (и этот факт получается независимо от того, лежит ли точка $P$ левее или правее точки $M$). Следовательно, в трапеции $\Delta ADC > \Delta BCD$, а потому $\Delta ADC = 60^\circ$.

По теореме косинусов из треугольника $BPC$ получаем:

$$y^2 = x^2 + 4(y - x)^2 - 2x(y - x)$$

(убедитесь в этом!); далее, по условию задачи,

$$x + y = 10$$

(2)

$$x_1 = 5, y_1 = 5; x_2 = 3, y_2 = 7.$$

Первое решение необходимо отбросить (почему?), а второе решение (оно, кстати, показывает, что точка $P$ действительное лежит левее точки $M$) позволяет найти площадь трапеции (как?).

3. $5/2 < x \leq 3$. Решение. ОДЗ неравенства — промежуток $0 < x \leq 3$ (убедитесь в этом!) Нераевенство переписывается в виде

$$\left( 5 - x \log_2 x \right) \left( 1 - x + \sqrt{6 + x - x^2} \right) < 0$$

(3)

(проведите соответствующее выражение!) Так как при всех $x$ из промежутка $0 < x \leq 3$ справедлива целочка неравенств $x \log_2 x \leq 3 \log_2 3 < 5$ (доказите!), то вместе (3) получаем неравенство $\sqrt{6 + x - x^2} < x - 1$. Его решение должно удовлетворять условию $x > 1$ (почему?) и находится общим методом (как?).

4. $S = \sqrt{4q^2 + \frac{p^2}{12}}$. Решение.

Ясно из условия, что $BM$ и $CK$ — медианы треугольника $ABC$, так что снованием высоты парами является точка $O$ пересечения этих медиан (рис. 3). Обозначим высоту парами через $H$, ребро $BC$ — через $a$. Высоту треугольника $ABC$, полученную из вершины $A$ на сторону $BC$, — через $h$ (на чертеже эта высота не нарисована). По условияю

$$p = \frac{ah}{2}$$

(4)

В трапеции $MKBC$ (почему это трапеция?) проведем высоту $FL$, проходящую через точку $O$. Тогда $DF$ — высота треугольника (сечения) $MDK$, а $DL$ — высота треугольника (грани) $BDC$ (доказите!). Так как $FL = h/2$ (почему?) и так как $FO:OL = 1:2$ (откуда это следует?), то

$$FO = h/6, LO = h/3.$$

Следовательно, по условияю

$$q = \frac{a}{4} \sqrt{H^2 + \frac{h^2}{36}}$$

(5)

(убедитесь в этом!), а искомая площадь грани $BDC$

$$S = \frac{a}{2} \sqrt{H^2 + \frac{h^2}{9}}.$$

Используя (4) и (5), получаем:

$$S^2 = \frac{a^2}{4} \left( H^2 + \frac{h^2}{9} \right) = 4 \frac{a^2}{16} \left( H^2 + \frac{h^2}{36} \right) + \frac{1}{12} \frac{a^2 h^2}{4} = 4q^2 + \frac{p^2}{12}.$$
