Но если сначала определить, в какой четверти находится точка $a + bi$, и затем найти также решение уравнения (5), которое является углом в этой четверти, то получим аргумент числа $a + bi$ (доказатель!).

Пример 3. Наименование из аргументов числа $1 - i\sqrt{3}$.

Точка $1 - i\sqrt{3}$ лежит в четвертой четверти. Находим какое-нибудь решение уравнения (5), то есть $\arg(\varphi) = -\sqrt{3}$, которое является углом в этой четверти, например: $\varphi = -\pi/3$.

Ответ: $\arg(1 - i\sqrt{3}) = -\frac{\pi}{3}$.

В этом примере по смыслу вопроса ответ неоднозначен. Является верным так же следующие ответы:

$$\arg(1 - i\sqrt{3}) = \frac{5\pi}{3},$$
$$\arg(1 - i\sqrt{3}) = -\frac{7\pi}{3},$$
$$\arg(1 - i\sqrt{3}) = \frac{41\pi}{3}$$

и другие.

Пример 4. Наименование числа $\sqrt{3} + i$.

Аналогично тому, как это сделано в примерах 2 или 3, находим (найDITе!):

$$\arg(\sqrt{3} + i) = \frac{\pi}{6}$$

(то есть $\pi/6$ является одним из аргументов числа $\sqrt{3} + i$). Остается выяснить, как писать ответ: достаточно указыть одно значение аргумента или нужно найти все?

Вспомним, например, задачу: решить уравнение $x^2 = 1$. Это уравнение имеет два корня $x_1 = 1$ и $x_2 = -1$. Чтобы ответ был полным, в него необходимо включить оба корня. Часто и в геометрических задачах встречаются необходимые ответы. Например, найти сторону $AB$ треугольника $ABC$, если $AC = 8$ см, $BC = 7$ см, $\angle A = \pi/3$. Полный ответ должен быть таким: $AB = 3$ см или $AB = 5$ см (доказатель!).

Так же и в нашем примере 4: чтобы ответ был полным, нужно найти все значения аргумента числа $\sqrt{3} + i$. Так как один аргумент $\pi/6$ уже найден, то все значения аргумента этого числа находим по формуле (4).

Ответ: $\arg(\sqrt{3} + i) = \frac{\pi}{6} + 2k\pi, k = 0, \pm 1, \pm 2, \dots$.

Таким образом, вопроса 4 является простой короткой формулировкой вопроса примера 2.

Обратим внимание на одну распространенную ошибку. Иного абитуренты пытаются находить аргумент числа $a + bi$ по формуле $\varphi = \arctg\frac{b}{a}$, а не которые даже принимают эту формулу за определение аргумента. Однако для каждой $x$ функция аргумента $x$ имеет только одно значение, причем $-\frac{\pi}{2} < \arctg x < \frac{\pi}{2}$. Значит, формула $\arg(a + bi) = \arctg\frac{b}{a}$ верна только при $a > 0$, причем дает только одно из значений аргумента.

Можно доказать (доказатель!) справедливость следующей формулы:

$$\arg(a + bi) = \begin{cases} \frac{\pi}{2}, \text{ если } a = 0, b > 0; \\ -\frac{\pi}{2}, \text{ если } a = 0, b < 0; \\ \arctg\frac{b}{a}, \text{ если } a > 0; \\ \pi + \arctg\frac{b}{a}, \text{ если } a < 0. \end{cases}$$

По этой формуле можно находить одно из значений аргумента, но часто проще поступать так, как сделано в примерах 2 или 3.
