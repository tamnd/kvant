Решения задач

M219—M221; Ф228—Ф232

M219. В пространстве заданы 4 точки, не лежащие в одной плоскости. Сколько существует различных параллеленедов, для которых эти точки служат вершинами?

Сначала решим аналогичную плоскую задачу. Данны три точки, не лежащие на одной прямой. Сколько существует различных параллеленедов, для которых эти точки служат вершинами?

Эта задача значительно проще пространственной. Ответ в ней: 3 параллелограмма.

Убедиться в этом можно, например, так. Предположим, что параллелограмм имеет три данные точки вершинами. Тогда одна из них (C на рис. 1) играет особую роль: она соединена с двумя другими точками сторонами параллелограмма (а те две между собой — диагональ). Ясно, что такой точкой C можно «назначить» любую из трех данных точки, после чего параллелограмм строится единственным образом (рис. 2).

Перейдем теперь к пространственной задаче. Самое замечательное в ней — ответ: 29 параллелопедов.

1-е решение. Сначала, как полагается в задаче «на построение», проведем небольшой анализ, то есть представим себе, что параллелопед (имеющий четыре данные точки вершинами) построен.

Из восемьи вершин параллелопеда четыре вершины, не лежащие в одной грани, можно выделить четырьмя существования различными способами *), как показано на рисунках 3, a, b, в, 2. Чтобы отличить эти способы, достаточно, например, посмотреть,

*) Словам «существенно различными» можно придать такой точный смысл: два 4-подмножества вершин считаются существенно различными, если нельзя отобразить множество из восемьи вершин на себя так, чтобы вершины одной грани перешли в вершины одной грани, а подмножество из четырех вершин — одно в другое.
