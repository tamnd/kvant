Бернулли удалость доказать, что и другие коэффициенты многочлена $S_k(n)$ вычисляются с помощью чисел $B_k$. Коэффициент при $n^2$ оказывается равным $\frac{B_{k-1}}{k-1} C_k^2$, коэффициент при $n^3$ равен $\frac{B_{k-2}}{k-2} C_k^3$, наконец, коэффициент при степени $n^k$ оказывается не зависящим от $k$ и всегда равным $\frac{B_1}{1} C_k^k = \frac{1}{2}$.

Таким образом, формула Бернулли имеет вид

$$S_k(n) = B_k n + \frac{B_{k-1}}{k-1} C_k^2 n^2 + \frac{B_{k-2}}{k-2} C_k^3 n^3 + \ldots + \frac{B_1}{1} C_k^k n^k + \frac{n^{k+1}}{k+1}.$$

2. Числа Бернулли с нечетными номерами

Теорема. Все числа Бернулли с нечетными номерами, кроме $B_1$, равны нулю: $B_{2m+1} = 0$ при $m \geqslant 1$.

Для доказательства воспользовемся равенством (1); применим его к разности $(1+a)^{2m} - (1-a)^{2m}$:

$$(1+a)^{2m} - (1-a)^{2m} = 2 \left( C_{2m}^1 a + C_{2m}^3 a^3 + C_{2m}^5 a^5 + \ldots + C_{2m}^{2m-1} a^{2m-1} \right).$$

Полагая здесь $a = 1, 2, \ldots, n$ и складывая полученные результаты, следует получим:

$$(S_{2m}(n) + (n+1)^{2m} - 1) - (S_{2m}(n) - n^{2m}) = (n+1)^{2m} + n^{2m} - 1.$$

Справа же получим выражение

$$2 \left( C_{2m}^1 S_1(n) + C_{2m}^3 S_3(n) + \ldots + C_{2m}^{2m-1} S_{2m-1}(n) \right).$$

(9)

Итак, имеем

$$(n+1)^{2m} + n^{2m} - 1 = 2 \left( C_{2m}^1 S_1(n) + C_{2m}^3 S_3(n) + \ldots + C_{2m}^{2m-1} S_{2m-1}(n) \right).$$

Вычислим коэффициент при $n^1$ в выражениях, получившихся в правой илевой части. В выражении, стоящем влевой части, этот коэффициент будет равен 2$m$ (очевидно). Получить вид коэффициента при первой степени $n$ в выражении, стоящем в правой части, немного сложнее: для этого достаточно в формуле (9) заменить суммы $S_j(n)$ ($j = 1, 3, \ldots, 2m-1$) числа Бернулли с теми же номерами (это утверждение следует из самого определения чисел Бернулли). Значит, имеет место такое подход:

$$C_{2m}^1 B_1 + C_{2m}^3 B_3 + C_{2m}^5 B_5 + \ldots + C_{2m}^{2m-1} B_{2m-1} = m.$$
