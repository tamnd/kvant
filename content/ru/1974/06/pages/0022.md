M222. Докажите, что у каждой выпуклого многоограничника найдуmsя две грани с одинаковым числом сторон.

Предположим, что, любые две грани не которая выпуклого многоограничника имеют различное число сторон. Расмотрим ту грань Г, у которой число сторон наиболее меньше. Рассмотрим ту грань О, у которой число сторон наиболее меньше. Рассмотрим ту грань С, у которой из остальных граней этого меньше. Значит, и количество оставшихся граней этого меньше m (введя даже если бы существовали 1-угольники и 2-угольники, мы смогли бы набрать всего лишь m — 1 разных многоугольников). С другой стороны, к грани Г примыкаютровно m других граней многоограничника (к каждой стороне — по одному). Мы получили противоречение.

Стою быть, какие-то две грани обязаательно иметь число сторон.

Приведенное решение почти дословно повторяет решение следующей, довольно известной задачи (на «приицип Дирихле» *)).

В книгеатре «Октябрь» на последнем сеанс обязаельно найдуmsя два целевка, число знакомых у которых одинаково.

Однако наша задача геометрическая по существу — в ее решении не иссure.

M223. Намуральное число называется совершенным, если оно равно сумме всех своих делителей, кроме самого числа. (Например, число 28 — совершенное: 28 = 1 + 2 + 4 + 7 + 14.) Докажите, что совершенное число не может быть полным квадратом.

Пусть n = p₁ᵢ p₂ᵢ ... pᵢᵢ m, где p₁, ..., pᵢ — различные простые, r₁, ..., rᵢ — натуральные числа (согласно основной теореме арифметики, каждое целое число n > 1 представляется в таком виде единственным образом).

Делители числа n — это числа вида

p₁ᵢ p₂ᵢ ... pᵢᵢ m,

где 0 ≤ k₁ ≤ r₁, ..., 0 ≤ kᵢ ≤ rᵢ. Поэтому сумма всех делителей числа n (включая 1 и n) равна произведению

S = (1 + p₁ + ... + p₁ᵢ) ... (1 + pᵢ + ... + pᵢᵢ).

Так как n — совершенное число, то S должно быть равно 2n, то есть быть числом четным. Но если n — квадрат целого числа, то все показатели r₁, ..., rᵢ — четные числа, поэтому квадрат крутляя скобка в произведении S

$$\frac{(1 + p_i + p_i^2 + ... + p_i^{i-1})}{1 + r_i}$$

есты число нечетное, следовательно, и S нечетное.

Получили противоречение, значит, совершенное число не может быть полным квадратом.
