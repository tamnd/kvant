(это общный закон Кулона, записанный в векторной форме). Обозначим через $x', y'$ и $z'$ координаты расматриваемой точки (то есть $r = \sqrt{x'^2 + y'^2 + z'^2}$). Тогда проекции направленности электрического поля в системе отчета $K'$ равны

$$E'_x = -\frac{1}{4\pi\varepsilon_0} \frac{e}{r^2} \frac{x'}{r},$$
$$E'_y = -\frac{1}{4\pi\varepsilon_0} \frac{e}{r^2} \frac{y'}{r},$$
$$E'_z = -\frac{1}{4\pi\varepsilon_0} \frac{e}{r^2} \frac{z'}{r}.$$

В неподвижной системе координат $K$, начало координат которого в расматриваемый момент совпадает с началом координат системы отчета $K'$, согласно формулам (3), (7) и (8) будем иметь

$$E_x = E'_x, \quad E_y = \frac{E'_y}{\sqrt{1-v^2/c^2}},$$
$$E_z = \frac{E'_z}{\sqrt{1-v^2/c^2}};$$
$$B_x = 0, \quad B_y = \frac{-vE'_z}{c^2\sqrt{1-v^2/c^2}},$$
$$B_z = \frac{vE'_y}{c^2\sqrt{1-v^2/c^2}}.$$

Подставим в эти формулы значения $E'_x, E'_y,$ и $E'_z$. Учитывая, что вследствие сокращения расстояний вдоль оси $X x' = \frac{x}{\sqrt{1-v^2/c^2}},$ в то время как $y' = y$ и $z' = z,$ и введя обозначения $\beta = v/c,$ получим

$$E_x = -\frac{ex(1-\beta^2)}{4\pi\varepsilon_0(\sqrt{x^2+(y^2+z^2)(1-\beta^2)})^3},$$
$$E_y = -\frac{ey(1-\beta^2)}{4\pi\varepsilon_0(\sqrt{x^2+(y^2+z^2)(1-\beta^2)})^3},$$
$$E_z = -\frac{ez(1-\beta^2)}{4\pi\varepsilon_0(\sqrt{x^2+(y^2+z^2)(1-\beta^2)})^3};$$
$$B_x = 0,$$
$$B_y = \frac{evz(1-\beta^2)}{4\pi\varepsilon_0 c^2(\sqrt{x^2+(y^2+z^2)(1-\beta^2)})^3},$$
$$B_z = \frac{evy(1-\beta^2)}{4\pi\varepsilon_0 c^2(\sqrt{x^2+(y^2+z^2)(1-\beta^2)})^3}.$$

Можно заметить, что электрическое поле перестает быть сферической симметриным. Расмотрим случай, когда $\beta \rightarrow 1,$ то есть $v \rightarrow c$. Электрическое поле всегда образуется в нуль, за исключением плоскости $x = 0,$ которая перепendlкулярна направленную движению электрона. В этой плоскости $E_x = 0,$ а компоненты $E_y$ и $E_z$ растут как $1/\sqrt{1-v^2/c^2}$ (при $v \rightarrow c$). Таким образом, электрическое поле движущегося электрона как бы сплюшивает.

Пусть $A = \{a_1, a_2, \dots, a_{2n-1}, a_{2n}\}$ — произвольная последовательность длины $2n.$ Разобъем эту последовательность на $n$ пар: $a_1, a_2; a_3, a_4; \dots; a_{2n-1}, a_{2n}.$ Для того чтобы последовательность $A$ была беспотронной, необходимо, чтобы каждый пара была беспотронной. Очевидно, что таких пар 90. Из 90 пар можно составить $90^n$ различных последовательностей длины $2n.$ Следовательно,

$$|\beta(2n)| \leq 90^n \text{ и } \frac{|\beta(2n)|}{10^{2n}} \leq \frac{90^n}{10^{2n}} = \left(\frac{9}{10}\right)^n.$$

2. Обозначим через $A_2$ последовательность $\{1, 2, 1\},$ через $A_3$ последовательность $\{A_2, 3, A_2\}, \dots,$ через $A_9$ — последовательность $\{A_8, 9, A_8\}.$ Эта последовательность $A_9$ и является исключой.

3. Пусть $a_1, a_2, \dots, a_n,$ — беспотронная последовательность, составленная из цифр 1, 2, 3. Расмотрим последовательность, полученную заменой в исходной последовательности цифры 1 на $\{1, 2, 3\}, цифры 2 — на $\{1, 2, 1, 2, 1\}, цифры 3 — на $\{1, 2, 2, 1\}.$

5. Пусть $a_1, a_2, a_3,$ — беспотронная последовательность. Тогда последовательности

$$a_2, a_3, \dots, a_3, a_4, \dots, a_4, a_5, \dots,$$

также беспотронные. Покажите, что все они различины.
