Задание 9. *Решить уравнение*
$$2\sin x + 3\cos x = 0.$$

Это уравнение является однородным первой степени относительно sin x и cos x. Дelimм обе части уравнения на cos x (легко видеть, что при этом потери корней нет). Имеем:
$$2\mathrm{tg}x + 3 = 0, \quad \mathrm{tg}x = -\frac{3}{2}, \quad x = -\mathrm{arctg}\frac{3}{2} + \pi k \quad (k - \text{целое}).$$

Уравнение $a\sin^2x + b\sin x\cos x + c\cos^2x = 0$ приводится к виду $a\mathrm{tg}^2x + b\mathrm{tg}x + c = 0$.

Задание 10. *Решить уравнение*
$$\sin^2x - 3\sin x\cos x + 2\cos^2x = 0.$$

При делении частей уравнения на $\cos^2x$ потери корней не будет, поэтому получаем уравнение $\mathrm{tg}^2x - 3\mathrm{tg}x + 2 = 0$, откуда $\mathrm{tg}x_1 = 1$, $x_1 = \frac{\pi}{4} + \pi k$; $\mathrm{tg}x_2 = 2$, $x_2 = \mathrm{arctg}2 + \pi m \quad (k, m - \text{целые}).$

Уравнение $a\sin x + b\cos x = c$ допускает много способов решения. Его можно привести к однородному уравнению относительно sin $\frac{x}{2}$ и cos $\frac{x}{2}$, подставив sin $x = 2\sin \frac{x}{2} \times \cos \frac{x}{2}$, cos $x = \cos^2\frac{x}{2} - \sin^2\frac{x}{2}$, $c = c\left(\cos^2\frac{x}{2} + \sin^2\frac{x}{2}\right)$.

Задание 11. *Решить уравнение*
$$3\sin x + 5\cos x = -3.$$

Имеем: $3\sin x + 5\cos x - 3, \quad \sin^2\frac{x}{2} - 3\sin \frac{x}{2}\cos \frac{x}{2} - 4\cos^2\frac{x}{2} = 0, \quad \mathrm{tg}^2\frac{x}{2} - 3\mathrm{tg}\frac{x}{2} - 4 = 0, \quad \mathrm{tg}\frac{x_1}{2} = -4, \quad x_1 = 2\mathrm{arctg}4 + 2\pi k; \quad \mathrm{tg}\frac{x_2}{2} = -1, \quad x_2 = -\frac{\pi}{2} + 2\pi m \quad (k, m - \text{целые}).$

Заметим, что решение уравнения $a\sin x + b\cos x = c$ с помощью введения вспомогательного аргумента не всегда удобно. Решая, например, этим методом уравнение (6), получим
$$3\sin x + 5\cos x$$

$$\sqrt{34}\left(\frac{3}{\sqrt{34}}\sin x + \frac{5}{\sqrt{34}}\cos x\right) =$$

$$= \sqrt{34}\sin \left[x + \arcsin \frac{5}{\sqrt{34}}\right],$$

$$\sin \left(x + \arcsin \frac{5}{\sqrt{34}}\right) = -\frac{3}{\sqrt{34}},$$

$$x = (-1)^{m+1}\arcsin \frac{3}{\sqrt{34}} -$$

$$- \arcsin \frac{5}{\sqrt{34}} + \pi m \quad (m - \text{целое}).$$

Идея использования однородности при решении тригонометрических уравнений обогащается возможность увеличивать на 2 степени однолетов относительно $u = \sin x$, $v = \cos x$ путем домножения их на $\sin^2x + \cos^2x$.

Задание 12. *Решить уравнение*
$$4\sin^3x = \sin x + \cos x.$$

Домножая правую часть уравнения на $\sin^2x + \cos^2x$ и деля затем обе части на $\cos^3x$, приходим к уравнению
$$3\mathrm{tg}^3x - \mathrm{tg}^2x - \mathrm{tg}x - 1 = 0.$$

Догадавшись, что при разложении левой части на множители один из них должен равнять $\mathrm{tg}x - 1$ (так как $\mathrm{tg}x = 1$ удовлетворяет уравнению), мы без труда находим это разложение
$(\mathrm{tg}x - 1)(3\mathrm{tg}^2x + 2\mathrm{tg}x + 1) = 0$

и ответ: $x = \frac{\pi}{4} + \pi k \quad (k - \text{целое}).$

Удачной заменой к однородным можно свести и неокоторые показательные уравнения.
