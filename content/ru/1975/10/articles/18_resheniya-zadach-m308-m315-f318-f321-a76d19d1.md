M308. Если при любом $x$ $a_1\cos x + a_2\cos 2x + \dots + a_n\cos nx \geq -1$, то для чисел $a_1, a_2, \dots, a_n$ выполняющего неравенство $a_1 + a_2 + \dots + a_n \leq n$. Доказание это утверждение: a) для $n = 2$; б) для $n = 3$; с) для любого натурального $n$.

a) Достаточно положить $x = \frac{2\pi}{3}$.

b) Положите последовательно $x = \frac{\pi}{2}, x = \pi, x = \frac{3\pi}{2}$ и сложите получшиеся неравенства.
b) Доказем предварительно следующее формулу: если $\varphi = -\frac{2k\pi}{n+1}$, где $k$ и $n$ — целые числа, причем $k$ не делится на $n+1$, то
$$\cos \varphi + \cos 2\varphi + \cos 3\varphi + \dots + \cos n\varphi = -1. \quad (*)$$
Пусть данные точки $O$ и $A_0$. Повернуть точку $A_0$ на угол $\varphi$ относительно точки $O$, получим точку $A_1$. Из точки $A_1$ тем же поворотом получим точку $A_2$, из точки $A_2$ — точку $A_3$ и так далее. Так как $(n+1)\varphi = 2k\pi$, то точка $A_{n+1}$ совпадает с точкой $A_0$. Сумма векторов $\overrightarrow{OA_0}, \overrightarrow{OA_1}, \overrightarrow{OA_2}, \dots, \overrightarrow{OA_n}$ равна нуль-вектору. Действительно, при повороте каждого из этих векторов на угол $\varphi$ относительно точки $O$ на тот же угол должен повернуть и вектор, равный их сумме. Так как, с другой стороны, вектор, равный сумме векторов $\overrightarrow{OA_0}, \overrightarrow{OA_1}, \dots, \overrightarrow{OA_n}$, не изменится при этом повороте (ибо точка $A_0$ перейдет в точку $A_1$, точка $A_1$ — в точку $A_2$, ..., точка $A_n$ — в точку $A_0$), то он равен нуль-вектору.
Предположим теперь, что точка $O$ является началом координат, а вектор $\overrightarrow{OA_0}$ имеет длину 1 и направлен по оси абсцисс. Так как проекция суммы векторов на любую ось равна сумме их проекций на эту ось, то сумма проекций векторов $\overrightarrow{OA_1}, \overrightarrow{OA_2}, \dots, \overrightarrow{OA_n}$ на ось абсцисс равна -1 (проекция вектора $\overrightarrow{OA_0}$ на ось абсцисс равна 1). Но эти проекции равны, очевидно, $\cos \varphi, \cos 2\varphi, \dots, \cos n\varphi$, отсутстви сследует формула (*).

Формулу (*) можно доказать и инначе, умножив обе части на $2\sin \frac{\varphi}{2}$ и воспользовавшись формулой
$$2\sin \frac{\varphi}{2}\cos k\varphi = -\sin \left(k - \frac{1}{2}\right)\varphi + \sin \left(k + \frac{1}{2}\right)\varphi,$$
— сделайте это самостояльно.

Перейдем к решению задачи в).
Взяв произвольное число $x_1$, положим $x_2 = 2x_1, x_3 = 3x_1, \dots, x_n = nx_1$. При $x = x_1, x = x_2, x = x_3, \dots, x = x_n$ получим неравенства:
$$a_1\cos x_1 + a_2\cos 2x_1 + a_3\cos 3x_1 + \dots + a_n\cos nx_1 \geq -1,$$

$$a_1 \cos x_2 + a_2 \cos 2x_2 + a_3 \cos 3x_2 + \dots + a_n \cos nx_2 \geq -1,$$
$$a_1 \cos x_3 + a_2 \cos 2x_3 + a_3 \cos 3x_3 + \dots + a_n \cos nx_3 \geq -1,$$
$$\dots$$
$$a_1 \cos x_n + a_2 \cos 2x_n + a_3 \cos 3x_n + \dots + a_n \cos nx_n \geq -1.$$

Учитывая, что $kx_l = klx_1 = lkx_1 = lx_k$, эти неравенства можно переписать так:

$$a_1 \cos x_1 + a_2 \cos x_2 + a_3 \cos x_3 + \dots + a_n \cos x_n \geq -1,$$
$$a_1 \cos 2x_1 + a_2 \cos 2x_2 + a_3 \cos 2x_3 + \dots + a_n \cos 2x_n \geq -1,$$
$$a_1 \cos 3x_1 + a_2 \cos 3x_2 + a_3 \cos 3x_3 + \dots + a_n \cos 3x_n \geq -1,$$
$$\dots$$
$$a_1 \cos nx_1 + a_2 \cos nx_2 + a_3 \cos nx_3 + \dots + a_n \cos nx_n \geq -1.$$

Сложив эти неравенства и положив $x_1 = \frac{2\pi}{n+1}$ (тогда $x_2 = \frac{4\pi}{n+1}$, $x_3 = \frac{6\pi}{n+1}$, $\dots$, $x_n = \frac{2n\pi}{n+1}$), придем на основании формулы (*) к неравенству

$$-a_1 - a_2 - a_3 - \dots - a_n \geq -n,$$

откуда

$$a_1 + a_2 + a_3 + \dots + a_n \leq n^*).$$

**M309. a) При каких $n$ многочлен $x^{2n} + x^n + 1$ делится на $x^2 + x + 1$?**

б) При каких $n$ число

$$1 \underbrace{0 \dots 0}_{n} \underbrace{1 \dots 0}_{n}$$

делится на 37?

a) Рассмотрим три случая, соответствующие различным остаткам от деления $n$ на 3.

1°. Пусть $n=3k$; тогда

$$x^{6k} + x^{3k} + 1 = (x^{6k} - 1) + (x^{3k} - 1) + 3 =$$
$$= (x^3 - 1)(x^{6k} - 3 + x^{6k} - 6 + \dots + 1) +$$
$$+ (x^3 - 1)(x^{3k} - 3 + x^{3k} - 6 + \dots + 1) + 3 =$$
$$= (x^2 + x + 1) \cdot Q(x) + 3,$$

где $Q(x) = (x - 1)[(x^{6k} - 3 + x^{6k} - 6 + \dots + 1) + (x^{3k} - 3 + \dots + 1)]$.

Следовательно, если $n=3k$, то многочлен $x^{2n} + x^n + 1$ при делении на $x^2 + x + 1$ дает в остатке 3.

2°. Пусть $n=3k + 1$. Имеем

$$x^{6k + 2} + x^{3k + 1} + 1 = (x^{6k + 2} - x^2) + (x^{3k + 1} - x) +$$
$$+ (x^2 + x + 1) = x^2(x^{6k} - 1) + x(x^{3k} - 1) + (x^2 + x + 1)$$

В 1° мы показали, что многочлены $(x^{6k} - 1)$ и $(x^{3k} - 1)$ делятся на $(x^3 - 1)$, следовательно, и на $(x^2 + x + 1)$; поэтому при $n=3k + 1$ многочлен $x^{2n} + x^n + 1$ делится на $x^2 + x + 1$.

3°. Пусть $n=3k + 2$. Тогда

$$x^{6k + 4} + x^{3k + 2} + 1 = x^1(x^{6k} - 1) + x^2(x^{3k} - 1) + x^4 + x^2 +$$
$$+ 1 = x^4(x^{6k} - 1) + x^2(x^{3k} - 1) + x^3 - 1 + (x^2 + x + 1) = (x^2 + x + 1)[(x - 1)R(x) + 1],$$

где $R(x) = x^4(x^{6k} - 3 + \dots + 1) + x^2(x^{3k} - 3 + \dots + 1) + x$, и многочлен $x^{2n} + x^n + 1$ снова делится на $x^2 + x + 1$.

**M312.** В параллелограмм $P_1$ висан параллелограмм $P_2$, в котором в свою очередь висан параллелограмм $P_3$, причем стороны $P_3$ параллельны сторонам $P_1$. Доказим, что хотя бы одна сторона параллелограмма $P_3$ по длине не меньше половины параллельной ей стороны $P_1$.

Пусть неокоторая бактерия, у которой $N$ потокков среды 1000 бактерии, разделилась на две, у которых соответствен $N'$ и $N''$ потокков. Тогда $N = N' + N''$, и поэтому одно из чисел $N'$ и $N''$ не меньше $N/2$.

Рассмотрим последовательность бактерии $A_1, A_2, A_3, \ldots, A_m$, где $A_1$ — самая первая бактерия, $A_{k+1}$ (для $k = 1, 2, \ldots, m-1$) — та из двух бактерии, возникших при делении $A_k$, у которой не меньше потоков, чем у ее сестры, и $A_m$ — одна из 1000 бактерии, которые получились в конце. Пусть $A_k$ имеет $N_k$ потокков. Тогда последовательность
$$N_1 = 1000, N_2, N_3, \ldots, N_{m-1}, N_m = 1$$
убываются, но каждый член в ней не меньше половины предыдущего: $N_k > N_{k+1} \geq N_k/2$. (На рисунке 1, изображаемшем процесс деления бактерии в виде «генеалогического дерева», показана цепочка бактерии $A_1, A_2, \ldots, A_m$; здесь $N_1 = 16, N_2 = 9, N_3 = 5, N_4 = 3, N_5 = 2, N_6 = 1$.) Если выбрать $j$ так, что $N_{j-1} \geq 668$, а $N_j < 668$, то получим $334 \leq N_j \leq 667$, то есть бактерия $A_j$ будет удовлетворять заданному условию.

Точно так же можно доказать, что если в конце получилось $M$ бактерии, то для любого натурального $c$ найдется бактерия, число помtokов которой $N$ удовлетворяет условием $c \leq N < 2c$.

**M313. Дан угодл с вершиной O. Рассмотрим множество четырех вершин M параллелограммов ONML, вершины N и L коморых лежам на сторонах данной угла, а площадь равна постоянной величины. (Это множество называется синерболой.) Докажите, что на биссерпсе это угла и на ее продолжении найдумся также точки $F_1$ и $F_2$ ($2de |F_1O| = |F_2O|$), для коморых разность расстояния

$$||F_1M| - |F_2M||$$

не зависит от точки $M$.**

Пусть $2\alpha$ — заданный угол, $A$ — вершина гиперболы (точка ее пересечения с биссерпсой), $A'$ — симметриная точка относительно $O$, $KMQ$ — перpendикуляр к этой биссерпсе, проходящий через $M$ (К лежит на биссерпсе, $Q$ — на стороне угла, см. рис. 3).

Введем обозначения: $r_1 = |F_1M|$, $r_2 = |F_2M|$, $a = |OA| = |OA'|$, $x = |ON|$, $y = |OL|$, $r = |OM|$, $\varphi = \widehat{AOM}$, наконец, $c$ — искомое расстояние точки $F_1$ и $F_2$ от вершины $O$ угла (центра гиперболы). (Для значших аналитических геометрию: $x$ и $y$ — косоугольные координаты точки $M$, $a$ и $\varphi$ — ее полярные координаты.)

По условию задачи, синний и желтый паралелограммы должны иметь одинаковую площадь:

$$k = xy \sin 2\alpha = \left( \frac{a}{2 \cos \alpha} \right)^2 \sin 2\alpha,$$

откуда

$$xy = \frac{a^2}{4 \cos^2 \alpha}. \tag{1}$$

Нужно найти такое положение $F_1$ и $F_2$ (то есть такое значение $c$), чтобы разность $r_2 - r_1$ была одной и той же для всех точек $M$ гиперболы. В частности, для ее вершины $A$ эта разность $|F_1A| - |F_2A|$, вследствие симметрины $(|F_2A| = |F_1A'|)$, равна $|A'A| = 2a$ (оси гиперболы). Значит, эта разность должна быть равна

$$r_2 - r_1 = 2a. \tag{2}$$

Найдем выражения $r_1$ и $r_2$ через постоянные $a, c$ и $\alpha$ (в эти выражения войдут, конечно, и какие-то переменные величины). Применяя теорему косинусов для треугольников $F_1MO, F_2MO$ и $OMN$, имеем:

$$r_{1,2}^2 = c^2 + r^2 \pm 2cr \cos \varphi \tag{3}$$

(верхний знак для $r_1$, нижний для $r_2$) и

$$r^2 = x^2 + y^2 + 2xy \cos 2\alpha. \tag{4}$$

Угол $\varphi$ можно из формулы (3) сразу использовать: из чертежа видно, что

$$r \cos \varphi = |OK| = |OQ| \cos \alpha = (|OL| + |LQ|) \cos \alpha =$$

$$= (|OL| + |LM|) \cos \alpha = (x + y) \cos \alpha;$$

следоватьно,

$$r_{1,2}^2 = c^2 + r^2 \pm 2c(x + y) \cos \alpha. \tag{3'}$$

Подставляя (4) в (3') и использовать условия (1) и то жеств а $\cos 2\alpha = 2 \cos^2 \alpha - 1$ и $x^2 + y^2 = (x + y)^2 - 2xy$, получаем:

$$r_{1,2}^2 = c^2 + (x + y)^2 - 2xy + 2xy \cos 2\alpha \pm 2c(x + y) \cos \alpha =$$

$$= c^2 + (x + y)^2 - \frac{a^2}{2 \cos^2 \alpha} +$$

$$+ \frac{a^2}{2 \cos^2 \alpha} (2 \cos^2 \alpha - 1) \pm 2c(x + y) \cos \alpha =$$

$$= \left[ c^2 - \frac{a^2}{2 \cos^2 \alpha} \right] + \left[ (x + y)^2 + a^2 \pm 2c(x + y) \cos \alpha \right]. \tag{5}$$

Do схх пор $c$ было произвольным. Подберем его теперь так, чтобы формула (5) прибрела возможность более простой вид. Положим $c = \frac{a}{\cos \alpha}$ (тогда $|OF_2| = |OB|$, см. рисунок). Тогда формула (5) принимает следующий вид:

$$r_{1,2}^2 = (x + y)^2 + a^2 \pm 2(x + y) a = [(x + y) \pm a]^2.$$

Из рисунка ясно, что $x + y > a$ ($|OQ| > |OA|$); следовательно,

$$r_1 = (x + y) + a, \quad r_2 = (x + y) - a.$$

Отсюда получается $r_1 - r_2 = 2a$. Интересно заметить, что $r_1 + r_2 = 2(x + y)$, т. е. с учм а рассмотрён любой мощи гиперболы до ее фокусов разна переменную паралелограмма, лежащое в определенной гиперболы.

Рис. 5.

Ф318. При каком $C_1$ емкость системы конденсаторов, показанной на рисунке 6, равна: a) $C$; б) $kC$ ($k \neq 1$); в) $C_1$?

Наозвемем последовательность
$$A_1A_2, A_2A_3, \dots, A_{t-1}A_t$$
ребер многоорганика путем
$$P = A_1A_2 \dots A_t$$
если на всех этих ребрах стрелки направлены в одну сторону: либо от $A_1$ к $A_2$, от $A_2$ к $A_3$, ..., от $A_{t-1}$ к $A_t$, либо же от $A_t$ к $A_{t-1}$, от $A_{t-1}$ к $A_{t-2}$, ..., от $A_2$ к $A_1$.

Так как по условию в каждую вершину многоорганика входит и из каждой выходим хотя бы одна стрелка, то любой путь можно удалить в обе стороны, присоединяя к его концам новые ребра.

Начав с произвольного ребра $A_1A_2$ многоорганика (оно, очень/no, является путем), будем последовательно стройить пути $A_1A_2A_3, A_1A_2A_3A_4$ и так далее, до тех пор, пока не получится такой путь, в котором одна из вершин встречает дважды: $A_s = A_t$, $1 \leq s < t$. Таким образом мы получим замкнутый путь $P_0 = A_sA_{s+1} \dots A_t$ (у него все вершины, кроме крайних, $A_s = A_t$, различны, рис. 4).

Так как многоорганик выпуклый, то путь $P_0$ делит его поверхность на две области $D$ и $D'$. Покажем, что в каждой области имеется по крайней мере одна грань, которая можно обойти по перimetру, двіяясь в соответствии с направлением стрелок на ее сторонах.

Возьемем область $D$; путь она состоит из $k_0 \geq 1$ граней многоорганика. Если $k_0 = 1$, то эта область (огранченная путь $P_0$) является нужной гранью. Если же $k_0 > 1$, то в области $D$ есть ребро $A_iB$, не входящее в путь $P_0$ (причем $A_i$ входит в $P_0$). Начав с этого ребра, будем стройить путь через вершину $B$ внутри области $D$ до тех пор, пока не получится путь, у которого одна из вершин встречает дважды (если мы выйдем на границу области $D$, то дальнейшее по путь $P_0$ возвращится к $A_i$). Так мы получим новый замкнутый путь $P_1$ (рис. 5). Путь $P_1$ лежит внутри области $D$ и не совпадает с $P_0$; значит, область, ограниченная путь $P_1$, состоит из $k_1 < k_0$ граней многоорганика. Если $k_1 = 1$, то $P_1$ ограничивает искому грань; если же $k_1 > 1$, то точно так же построим замкнутый путь $P_2$, ограничивающий область, которая состоит из $k_2 < k_1$ граней, и так далее. Так как все числа $k_i$ — натуральные и $k_{i+1} < k_i$, то за конечное число шагов мы получим замкнутый путь $P_0$, ограничивающийровно одну искому грань.

Вторую искому грань можно найти так же, расматривая $D'$ — вторую искому из области, на которой путь $P_0$ разделил наш многоорганик.

Пусть колебания мембраны происходят по закону
$$x = A \sin \omega t,$$
где $x$ — смещение от положения равновесия, $A$ — амплитуда, $\omega = 2\pi\nu$ — циклическая частота колебаний. В начальный момент времени $t = 0$ мембрана и песчинки на ней находятся в положении равновесия. Затем мембрана удаляется от положения равновесия, например, вверх.

На песчинку, движущуюся вместе с мембраной, действуют две силы: сила тяжести $mg$ и сила $\mathbf{N}$ реакции мембраны (рис. 8). Запишем уравнение движения песчинки:
$$N - mg = ma.$$
В момент отрыва песчинки сила реакции $N$ обращается в нуль, и, следовательно, ускорение песчинки $a = -g$. Таким образом, песчинка отрывается от мембраны в тот момент времени $t_0$, когда ее ускорение равно $-g$. Дальше песчинка продолжает двигаться до высоты $h$ как тело, брошенное вертикально вверх на высоте $h_0$, равной отклонению мембраны от положения равновесия в момент $t_0$, с начальной скоростью $v_0$, равной скорости мембраны в тот же момент $t_0$ (см. рис. 8). По закону сохранения механической энергии

$$mgh_0 + \frac{mv_0^2}{2} = mgh. \qquad (*)$$

Рассмотрим теперь более подробно движение мембраны и свяжем величины $h_0$ и $v_0$ с амплитудой колебаний мембраны.

Скорость мембраны в любой момент времени равна $v = \omega A \sin(\omega t + \pi/2) = \omega A \cos \omega t$, а ускорение $a = -\omega^2 x = -\omega^2 A \sin \omega t$. В момент отрыва $t_0$

$$v = v_0 = \omega A \cos \omega t_0,$$
$$a = -g = -\omega^2 A \sin \omega t_0,$$
$$x = h_0 = A \sin \omega t_0.$$

Из уравнения ускорения $\sin \omega t_0 = \dfrac{g}{\omega^2 A}$, следовательно, $h_0 = g/\omega^2$ и $v_0 = \omega A \cos \omega t_0 = \sqrt{\omega^2 A^2 - g^2/\omega^2}$

Подставив значения $h_0$ и $v_0$ в уравнение $(*)$, получим

$$A = \frac{\sqrt{2gh\omega^2 - g^2}}{\omega^2} \approx 77{,}2\cdot 10^{-6} \ \textit{м} \approx 0{,}077 \ \textit{мм}.$$
