⟦folio 63⟧

Можно применять закон сохранения механической энергии. 6) Поскольку ребь идет о колбанях, можно применять закон колбаней, в частности, гармоничских колбаней (если ограничиться рассмотрением малых амплитуд). Так как в системе входят пружники, можно использовать сведения о них: прежде всего, закон Гука. Можно также воспользоваться тем, что система симметрина.

Для решения задачи можно использовать закон колбаней совместно с законами Ньютона или с законом сохранения механической энергии.

Решение. Первый способ. Пусть в некоторый момент смешение каждого шара равно $x$; тогда удаление каждого пружника будет равно $x \mid \bar{3}$, а сила упругости одной пружники (по закону Гука) — $kx \mid \bar{3}$. Равноведействующая сил упругости двух пружинок, действующих на каждой шар, равна $3kx$. Согласно второму закону Ньютона для этого шара (направим ось $x$ по направлению смешения шара)

$$a_x = \frac{F_x}{m} = -\frac{3kx}{m} = -\frac{3k}{m} x.$$

Сравним полученную формулу с уравнением гармоничских колбаней:

$$a_x = -\omega^2 x.$$

Отсюда циклическая частота

$$\omega = \sqrt{\frac{3k}{m}}.$$

В положении равновесия скорость шаров максимальная, а пружники не деформированы, то есть $E_1 = K_1 = \frac{3mv_0^2}{2}$ ($v_0$ – амплитуд скорости).

В крайнем положении скорость шаров равна нулю, а смешение максимально и равно амплитуде колбаней $A$. При этом удлинение каждой пружники равно $A \mid \bar{3}$, поэтому

$$E_2 = \Pi_2 = 3 \frac{k(A\sqrt{3})^2}{2}.$$

$$\frac{3mv_0^2}{2} = 3 \frac{k(A\sqrt{3})^2}{2} \text{ и } v_0 = \sqrt{\frac{3k}{m}} A.$$

Используя известное выражение для максимальной скорости гармоничских колбаней $v_0 = \omega A$, получим то же выражение для циклической частиоты, что и при первом способе решения.

Упражнения

В приведенных ниже задах установите, какие из основных законов механики можно применять в исследуемой ситуации, а также, какие из этих законов нужно применить для решения.

1. Самолет массой $m = 2,5$ м с выключенным motor спускается, планируя, с высоты $h_1 = 2$ км до высоты $h_2 = 1$ км, пролетев при этом с постоянной скоростью $v = 144$ км/ч расстояние $l = 10$ км. Какую мощность $N$ должен развить motor самолета, чтобы он смог подняться до высоты $h_1$, пролетев расстояние $l$ с той же скоростью?

2. (Ф228). На конце длины $L$ и массы $M$ находится короткий брусок массы $m$. Доска может скольнить без трения по горизонтальной плоскости. Козффициент треня скольжения бруска по поверхности доски равен $\mu$. Какую скорость $v_0$ нужно только сообщить доке, чтобы она выскольнула из-под бруска?

3. С горки высокой $H$ съехали массы $m$ и оставились, пройда неокоторое расстояние. Какую работу нужно совершить, чтобы поднять сankи по тому же пути до первого嗽альной высоты?
