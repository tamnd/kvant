В $B_1, \dots, B_n$. Тогда центрод $O$ системы всех $m + n$ точек $A_1, \dots, A_m, B_1, \dots, B_n$ лежит на отрезке $O_1O_2$ и удовлетворяем условию $|O_1O| : |OO_2| = n : m$.

Доказательство. Для точки $O$, лежащей на отрезке $O_1O_2$ и удовлетворяющей условию $|O_1O| : |OO_2| = n : m$, имеем $\vec{mOO}_1 + n\vec{OO}_2 = \vec{0}$. (3)

Убедимся, что точка $O$ — центрод системы всех $m + n$ точек. В самом деле, так как $O_1$ — центрод системы точки $A_1, \dots, A_m$, то согласно (2) имеем

$$\vec{OA}_1 + \vec{OA}_2 + \dots + \vec{OA}_m - m \cdot \vec{OO}_1 = \vec{0}. \quad (4)$$

Аналогично, из того, что $O_2$ — центрод системы точки $B_1, \dots, B_n$, получаем

$$\vec{OB}_1 + \vec{OB}_2 + \dots + \vec{OB}_m - n \cdot \vec{OO}_2 = \vec{0}. \quad (5)$$

Складывая почленно соответствия (3), (4), (5), получаем

$$\vec{OA}_1 + \dots + \vec{OA}_m + \vec{OB}_1 + \dots + \vec{OB}_n = \vec{0},$$

а это и означает, что $O$ — центрод системы точки $A_1, \dots, A_m, B_1, B_2, \dots, B_n$.

Следствие. Пусть $A_1, \dots, A_m$ — некоторые системы точки $k$ — натуральное число, меньше $m$. Выберем из $A_1, \dots, A_m$ какие-либо $k$ точек, и пусть $O'$ — их центрод, а $O''$ — центрод оставшихся $m - k$ точек. Тогда все получающие таким образом отрезки $O'O''$) проходят через одну точку $O$ (центрод системы точки $A_1, \dots, A_m$) и делятся в этой точке в отношении $(m - k) : k$.

Из доказанной теоремы и этого следствия можно получить ряд выводов. Прежде всего из теоремы 1 при $m = n = 1$ находится, что центрод двух точек $A, B$ совпадает с серединой соединяющего их отрезка. Далее, при $m = 2, n = 1$ получаем из теоремы 1, что центрод $O$ трех точек $A_1, A_2, B$ лежит на отрезке, соединяющего $D$ отрезка $A_1A_2$ с точкой $B$, причем $|DO| : |OB| = 1 : 2$. Отсюда следует, в частности, если точки $A_1, A_2, B$ не лежат на одной прямой, то центрод этой системы точки совпадает с точки пересечения медиан треугольника $A_1A_2B$ (см. рис. 2; эту точку называют центром тяжестни треугольника).
