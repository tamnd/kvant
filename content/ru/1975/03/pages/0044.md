⟦folio 42⟧

Ду точками второй системы и взаимные расстояния каждой точки одной системы до каждой точки другой.
Введем обозначения:
$$|A_i A_j| = a_{ij}, |B_s B_t| = b_{st},$$
$$|A_p B_q| = c_{pq}.$$
Как выясено выше (см. (7)),
$$d^2 = |O_1 O_2|^2 = \frac{1}{n} |O_1 B_1|^2 + \dots$$
$$\dots + |O_1 B_n|^2) - \frac{1}{n^2} \sum_{s < t} b_{st}^2,$$
$$|O_1 B_h|^2 = \frac{1}{m} (|A_1 B_h|^2 + \dots$$
$$\dots + |A_m B_h|^2) - \frac{1}{m^2} \sum_{i < j} a_{ij}^2,$$
(где $k$ — любое из чисел 1, 2, ..., $n$). Подставляя соответствия (8') в формулу (8), получаем окончательно (после очередных упрощений):
$$d^2 = |O_1 O_2|^2 = \frac{1}{mn} \sum_{p, q} c_{pq}^2 -$$
$$- \frac{1}{m^2} \sum_{i < j} a_{ij}^2 - \frac{1}{n^2} \sum_{s < t} b_{st}^2.$$

По этой формуле и вычисляется в самом общем случае расстояние между центроидами двух систем точек.

Примеры

1. Пусть дан треугольник $A_1 B_1 B_2$. Центroid $O_1$ системы, состоящий из одной точки $A_1$, совпадает с $A_1$, центroid $O_2$ системы точек $B_1, B_2$ совпадает с серединой $[B_1 B_2]$ (рис. 3).

В этом случае $[O_1 O_2]$ есть медиана треугольника $A_1 B_1 B_2$. Имеем
$$d^2 = \frac{1}{2} (|A_1 B_1|^2 + |A_1 B_2|^2) -$$
$$- \frac{1}{4} |B_1 B_2|^2.$$

2. Пусть дан четырехугольник $A_1 A_2 B_1 B_2$. Центroid $O_1$ системы точек $A_1, A_2$ совпадает с серединой отрезка $A_1 A_2$, центroid $O_2$ системы точек $B_1, B_2$ совпадает с серединой отрезка $B_1 B_2$ (рис. 4).

Воспользовемся формулой (9):
$$d^2 = \frac{1}{4} (|A_1 B_1|^2 + |A_1 B_2|^2 +$$
$$+ |A_2 B_1|^2 + |A_2 B_2|^2 - |A_1 A_2|^2 -$$
$$- |B_1 B_2|^2).$$ (10)

Эта формула, выражющая квадрат расстояния между серединами противоположных сторон четырехугольника через квадраты его сторона и диагоналей, известна как формула Эйлера. Здесь вид четырехугольника произвольный: он может быть выпуклым, самопересекающимся, неплоским.

Если центроиды отрезков $A_1 A_2$ и $B_1 B_2$ совпадают, то четырехугольник есть параллелограмм, и мы получаем известную зависимость между сторонами и диагоналями параллелограмма.
