1) Если $36^k - 5^l = 1$, то $(6^k - 1)(6^k + 1) = 5^l$.
No число $6^k + 1$ не может быть степенью 5, так как оканчивается на 7 (при $k > 0$).

2) Если $5^l - 36^k = 9$, то тогда $5^l = 9 + 36^k$, чего также не может быть, так как правая часть при $k > 0$ делится на 9, а левая -- нет. Значит, 11 — наименьшее число вида $|36^k - 5^l|$.

в) Число $N = |53^k - 37^l|$ может оканчивать любой четной цифрой. Кроме того, поскольку $|53^k - 37^l| = |(52 + 1)^k - (36 + 1)^l| = |(4.13 + 1)^k - (4.9 + 1)^l|$, то $N$ делится на 4. При $k = l = 1$ $N = 53 - 37 = 16$. Докажем, что 16 — наименьшее число вида $|53^k - 37^l|$. Для этого достаточно показать, что $N$ не может равняться 4, 8 и 12 ($N$, очень видно, не равно 0, так как 53 и 37 взаимно просты).

Имеем $N = |53^k - 37^l| = |(54 - 1)^k - (36 + 1)^l| = |(6.9 - 1)^k - (4.9 + 1)^l|$.

Позному при делении $N$ на 9 в остатке могут получаться только 0,2 и — 2 (то есть 7). Но ни 4, ни 8, ни 12 этих остатков при делении на 9 не дают.

M275. a) На плоскости данных $n$ векторов, длина каждого из комorbix равна 1. Сумма всех $n$ векторов равна нулевому вектору. Докажите, что векторы можно заимеревать так, чтобы при всех $k = 1, 2, \dots, n$ выполнялось следующие условия: сумма первых $k$ векторов имеет длину не более 3.
б) Докажите аналогично утверждение для $n$ векторов с суммой 0, длина каждого из комorbix равна 1. b) Может ли заменить число 3 в задаче a) меньше? Постраящее уличимое оценку также в задаче 6).

Рассмотрим вначале «одномерную» задачу.
Лемма 1. Пусть данно $n$ чисел, таких, что каждое по модулю не превосходит 1, а сумма всех равна 0. Тогда их можно заимеревать так, чтобы при любом $i \leq n$ сумма первых $i$ из них была по модулю не больше 1.

Укажем один из способов наполнительные: $a_1, \dots, a_k$ и неположительные: $b_1, \dots, b_{n-k}$. Положим $c_1 = a_1, c_2 = b_1$. Если $c_1 + c_2 < 0$, положим $c_3 = a_2$; если $c_1 + c_2 \geq 0$, положим $c_3 = b_2$. И вообще, если $c_1, \dots, c_l$ уже выбраны, то при $c_1 + \dots + c_l < 0$ применя за $c_{l+1}$ очередное положительное число, а при $c_1 + \dots + c_l \geq 0$ — очередное положительное число.

Опираясь на лемму 1, решим задачу M275 6). Приложим все данные векторы к некоторой точке $O$ и выберем прямую систему координат $Oxy$ так, чтобы сумма $s$ всех векторов, смотрящих вверх ($v > 0$), была направлена в точности по оси $y$. (Вопрос, как построить такую систему координат, мы обсудим позже.) Остальные векторы (смогрицие вниз) даут тогда в сумме — $s$.

Сначала заимереемся векторами, смотрящими вверх. Их составляющие по оси $x$ обозначим через $p_1, \dots, p_k$. Так как составляющая $s$ по оси $x$ равна 0, то $p_1 + \dots + p_k = 0$. По модулю каждое из чисел $p_1, \dots, p_k$ не превосходит 1. По лемме 1 заимереем числа $p_1, \dots, p_k$ так, чтобы при всяком $i \leq k$ сумма первых $i$ из них была по модулю не больше 1. Тем самым мы заимереем векторы, смотрящие вверх, так что при всяком $i \leq k$ сумма первых $i$ из них будет лежать в полосе $|x| \leq 1$ (рис. 1). Составляющие этих векторов по оси $y$ (в выбранном порядке) обозначим через $a_1, \dots, a_k$.

Так же заимереем векторы, смотрящие вверх, и их составляющие по оси $y$ называем $b_1, \dots, b_{n-k}$.

Теперь перейдем к сквозной нумерации всех данных векторов. Каждый из чисел $a_1, \dots, a_k$ заключено между 0 и 1, каждое из чисел $b_1, \dots, b_{n-k}$ — между 0 и — 1, а сумма их равна 0. Не меняя относительной порядка чисел $a_1, \dots, a_k$ и относительной порядка чисел $b_1, \dots, b_{n-k}$, выпишем их по лемме 1 в виде набора $c_1, \dots, c_n$ так, чтобы при любом $i \leq n$ заимереем неравенство $|c_1 + \dots + c_i| \leq 1$.
