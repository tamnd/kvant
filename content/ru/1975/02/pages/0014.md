Задача о максимальном потоке. Дана трансортиная сеть, для каждой дуги комори указана пропускная способность. Требуется определить потоки по дугам сети, не превосходящие соответствующих пропускных способностей, так, чтобы для любой промежуточной вершины сумма потоков по входящим дугам была равна сумме потоков по выходящим дугам («условие неперерывности потока») и чтобы поток по сети был наиболее низ возможных.

Итак, наша задача — частный случай задачи о максимальном потоке (условие неперерывности потока — это знакомое нам условие отсутствия транспортиных «пробок»). Пользовясь веденными обозначениями, ее можно сформировать так:

Найти максимальное $x_{ij}$ потоков по дугам, при коморых достизации максимума величины потока по сети
$$X = x_{12} + x_{13}$$

(1)
при следующих условия:
a) определение пропускных способностей дуг
$$x_{12} \leq a_{12}, x_{13} \leq a_{13}, x_{23} \leq a_{23},$$
$$x_{24} \leq a_{24}, x_{34} \leq a_{34}, x_{35} \leq a_{35},$$
(2)
неперерывность потока в пропускных вершинах
$$x_{12} - x_{23} - x_{24} = 0,$$
$$x_{13} + x_{23} - x_{34} - x_{35} = 0,$$
$$x_{24} + x_{34} - x_{45} = 0.$$

3. О полные аналогий

Посмотрите внешательно на уравнение (3). Чем-то они нам очень знакомы... Ба, да ведь если трансортиную сеть считать электрической цепью, а объемы перевозок $x_{ij}$ — величины токов в соответствии их ветвях цепи, то уравнения (3) выражают просто 1-й закон Кирхгофа для промежуточных узлов цепи: аллебрацией сумма токов в узле равна нулю (то есть сумма токов, втекающих в узел, равна сумме токов, втекающих из узла)!

Правда, эта аналогия не полная, поскольку закон Кирхгофа обычно формулируется для за мкнутей цепи и относится к любом безмкнутя, а условия типа (3) неверны для крайних узлов 1 и 5. Однако можно так видно изменить задачу о потоке, что отмеченное расхождение устройства. С этой целью ведем в транспортиную сеть дополнительнуюную дуги ограничивающую не будем, а поток по ней применять равным $X$, то есть поток по сети. По полученной обобщенной сети поток будет совершать уже замкнутый путь от входа к выходу по заданной транспортиной сети, а затем — от выхода на вход по дополнительной дуге.
