⟦folio 29⟧

«срыв» сверхпроводимости — магнитная индукция внутри выхода от нуля. «Ствол» выхода находится в нормальном состоянии.

Таким образом, сверхпроводящий образец оказывается произненным нитями, представляющим собой объчные неверхпроводические области. Вихри в сверхпроводнике образуют треугольную решетку (см. рис. 5). Стволы выходе ориентированы в направлении сливых линей магнитного поля. В пространстве между выходами свойства сверхпроводимости сохраняются. Magнитный поток, произвольный сечение ствола выхода, оказывается одним и тем же для всех выходей и равным по величине кванту магнитного потока $\Phi_0$. То есть каждый выход несет один квант потока, и в виде таких отдельных порций магнитное поле проникает внутри сверхпроводника.

При увеличении поля ($B > B_{K1}$) число нормальных области растет, выходные нитки слижаются, и при некотором значении поля $B_{K2}$ (эта величина называется верхим кремтическим полем), когда расстояние между выходными нитями становится $\sim 10^{-6}$ м, сверхпроводимость полностью разрушается и вещество переходит в нормальное состояние.

Такая своеобразная картина проникновения магнитного поля в сверхпроводника второго рода позволяет использовать их для получения сливых магнитный полей. Значение верхнего критического поля $B_{K2}$ может оказаться очень большим. Например, для сплава Nb$_3$Sn $B_{K2} \approx 20$ мл. (Сверхпроводниками второго рода являются сплавы с высоким содержанием примеси.)

При использовании сверхпроводников второго рода для получения сливых магнитных полей энергетически затраты в сотни—тысячи раз меньше, чем при использовании электромагнитов. Например, для получения поля в 10 мл с помощью обычного соленода требуется источник питания мощностью 5000 кВт и, кроме того, необходима сложная установка для охлаждения обмотки соленода. При использовании сверхпроводников необходимо лишь затраты энергии для получения жидкого геля (при температуре жидкого геля металл соленода находится в сверхпроводшем состоянии). Но для этого в приведенном примере необходимо мощность всего 5 кВт. То есть энергетические затраты уменьшаются в 1000 раз.

Приложение II

Приведем вывод формулы для энергии, которой обладает ток, текущий по проводнику.

Рассмотрим контур, по которым проектируется ток $I$. Magнитный поток $\Phi$, создавший этим током, возвращает при увеличении $I$ по закону $\Phi = LI$, где $L$ — индуктивность контур. Предположим, что в начальной момент времени $t_0 = 0$ ток в контуре равен $I_0$, и, начиная с этого момента, сила тока равномерно возвращается равной $I_t$. Ясно, что возрастание силы тока сопровождается ростом энергии магнитного поля, создавшего ток.

За время $t$ по проводнику переместился заряд $q$. Заряд движения скоренено, так как сила тока возвращается (плотность тока равна $j = nev$; при постоянном $n$ возрастание $j$ обусловлено ростом $v$). Для того чтобы получить формулу для энергии тока, вычислим работу электрических сил по перемещению заряда $q$ вдоль всей замкнутой цепи. Работа выражается формулой $A = qE$, где $E$ — электродвижущая сила, равная в обычном проводнике $E = IR + \frac{\Delta \Phi}{\Delta t}$.

Первое слагаемое в правой части этого равенства связано с общными омическими потерями, а второе обусловлено наличие эффектива самондукции, ослабляющего ток. Ясно, что $q = I_{cp} \cdot t$ ($I_{cp}$ — средняя сила тока, равная при равномерном возрастании тока $I_{cp} = \frac{I_0 + I_t}{2}$). Таким образом, равна оказываться равной

$$A = \frac{I_0 + I_t}{2} t E.$$

В сверхпроводниках $R = 0$ и $E = \frac{\Delta \Phi}{\Delta t}$. Поскольку формула $\Phi = LI$, то $E = L \frac{\Delta I}{\Delta t}$. В нашем случае изменение точки $\Delta I$ равно $\Delta I = I_t - I_0$, а промежуток времени $\Delta t = t$. Тогда $E = L \frac{I_t - I_0}{t}$. Подставляя это значение для $E$ в формулу для работы, приходим к следующему выражению:

$$A = \frac{I_0 + I_t}{2} t \cdot L \frac{I_t - I_0}{t}.$$

Работа, таким образом, оказывается равной

$$A = \frac{LI^2}{2} - \frac{LI_0^2}{2}.$$

Видно, что величина работы описывается изменением величины $\frac{LI^2}{2}$. Ее естественно считать равной энергии тока, так что

$$E = \frac{LI^2}{2}.$$

(Внимательный читатель обнаружит аналогию приведенного вывода формулы для энергии тока с выводом выражения для кинетической энергии в обычной механике.)
