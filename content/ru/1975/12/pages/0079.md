1. Если $a^4 + a^3 = b^4 + b^3 = 1$, то $a^3b^3 (a + 1)(b + 1) \equiv q^3 (p + q + 1) = 1$, где $p = a + b, q = ab$. Кроме того, $a^4 - b^4 + a^3 - b^3 = 0$, то есть $a^3 + a^2b + ab^2 + b^3 + a^2 + ab + b^2 = 0$, откуда $\frac{1}{a} + \frac{1}{b} + ab(a + b + 1) = 0$ или $\frac{p}{q} + q(p + 1) = 0$. Исключая $p$, получаем $q^3 (q^3 + q + 1) = q^2 + 1$.

Мы имеем $k (1 + yz) - (y + z) = (y - z) u, k (1 + zx) - (z + x) = (z - x) u, k (1 + xy) - (x + y) = (x - y) u,$ от сюда $(kz - 1 + u) x = (1 + u) z - k, (ky - 1 + u) x = (1 - u) y - k.$ Исключая $x$, получаем $(kz - 1 + u) \{(1 - u) y - k\} = (ky - 1 + u) \{(1 + u) z - k\},$ или $2u \{(1 + yz) - (y + z)\} + (y - z) (u^2 + 1 - k^2) = 0.$ От сюда $2u^2 (y - z) + (y - z) (u^2 + 1 - k^2) = 0.$ Но $y - z \neq 0$, откуда получаем требуемое равенство.
