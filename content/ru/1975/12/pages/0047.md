⟦folio 45⟧

Рассстояние $l = SS_2$ между источником $S$ и его изображением $S_2$ в оптической системе равно $l = \sqrt{SK^2 + h^2}$, где $SK = 3,5F$. Рассстояние $h$ найдет из подобия треугольников $O_2S_1E_2$ и $S_2S_1E_1$:

$$\frac{h}{a} = \frac{F - f_2}{F}, \quad h = 0,5a.$$

Окончательное имеем:

$$l = SS_2 = \sqrt{12,25F^2 + 0,25a^2}.$$

Ф334.*) Бусинка сскальзывает без трения по вертикальной расположенной проводке длины $l$, которая изозначена в гармонику длины $l/2$. Во сколько раз время сскальзывания бусинки больше времени ее padения с высоты $l$? Амилитуда перешобов проводки много меньше ее длины. Размеры бусинки пребрежимо малы по сравнению с длиной «колена» гармоники.

При перехождение бусинки с одного прямолинейного участка проводки на другой абсолотная вершина ее скорости не меняется. Меняется только направление скорости бусинки: она становится параллельной новому участку проводки. Это означает, что время движения бусинки по проводке также же, как при движении бусинки по наклонной плоскости — развертке проводки. Это время равно

$$t = \sqrt{\frac{2l}{g \sin \alpha}} = \sqrt{\frac{2l}{gh/l}} = 2 \sqrt{\frac{l}{g}}$$

($l$ — длина наклонной плоскости, $\alpha$ — угол наклона плоскости к горизонту), т. е. оно в $\sqrt{2}$ раз больше времени

$$t' = \sqrt{\frac{2l}{g}}$$Padения бусинки с высоты $l$.

И. Ш. Слободецкий

*) Решение задачи Ф333 будет опубlikовано в следующем номере журнала.
