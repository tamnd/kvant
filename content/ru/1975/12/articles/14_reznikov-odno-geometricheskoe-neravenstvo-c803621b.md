⟦folio 56⟧

Одно геометрическое неравенство

В «Кванте» № 7 за этот год (с. 65) высказывалось следующим предложением:

$$\frac{9}{20} (ab + bc + ca) \leq m_a m_b + m_b m_c + m_c m_a,$$

где $a, b, c, m_a, m_b, m_c$ — длины сторон и соответствующего медиан произвольного треугольника.

Ниже приведится «геометрическое» доказательство этого утверждения*).

Лемма 1. $m_a + m_b + m_c < a + b + c$.

Лемма 2. $a^2 + b^2 + c^2 < 2(ab + ac + bc)$.

Лемма 3. $m_a^2 + m_b^2 + m_c^2 = \frac{3}{4} (a^2 + b^2 + c^2)$.

Докажите эти леммы самостояльно.

Лемма 4. $m_a m_b + m_b m_c + m_a m_c \leq \frac{5}{4} (ab + bc + ac)$.

Докажите это леммы самостояльно.

Согласно лемме 1, $(m_a + m_b + m_c)^2 < (a + b + c)^2$, то есть $m_a^2 + m_b^2 + m_c^2 + 2m_a m_b + 2m_b m_c + 2m_a m_c < (a^2 + b^2 + c^2) + 2ab + 2bc + 2ac$.

*) Номер был уже отправлен в типографию, когда в редакцию пришло письмо от Петера Такча из г. Шафарниково (Чехослования) с чисто алгебраическим доказательством.

откуда, в силу лемм 3 и 2:

$$2m_a m_b + 2m_b m_c + 2m_a m_c < \frac{5}{4} (a^2 + b^2 + c^2), \quad \leq \frac{5}{2} (ab + bc + ac),$$

что и требовалось доказать.

Лемма 5. Если в треугольнике с сторонами $\frac{1}{3} m_a, \frac{1}{3} m_b$ и $\frac{1}{3} m_c$ построить медианы, то их длины будут равны $\frac{1}{4} a$, $\frac{1}{4} b$ и $\frac{1}{4} c$.

Доказательство. Пусть $G$ — центряжестни треугольника $ABC, AM, BK$ и $CP$ — медианы, $R$ — середина отрезка $BG$.

По построению $|RG| = \frac{1}{3} m_b, |PG| = \frac{1}{3} m_c$, а $PR$ — средняя линия в треугольнике $ABG$, откуда $|PR| = \frac{1}{2} |AG| = \frac{1}{3} m_a$. Таким образом, треугольник $PRG$ — искомый. Проведем в нем медиану $PQ$. Она является средней линей в треугольнике $ABK$, и, следовательно, $|PQ| = \frac{1}{2} |AK| = \frac{1}{4} a$.

Утверждение леммы доказано.

Приименов теперь лемму 4 к треугольнику $PRG$, получим нужное неравенство.

A. Резников
