Поскольку $S_3 + S_4 + S_5 = S_3 + S_2 + S_7 = \frac{S}{2}$, то $S_4 + S_5 = S_2 + S_7$, и поэтому $S_3 = S_1 + S_6$. Значит, $S_3 \geq S_1$.

Кроме того, $\frac{1}{2} S = S_2 + S_4 + S_3 + S_1$, откуда следует, что $\frac{1}{2} S \geq 2 S_1$, то есть $S_1 \leq \frac{1}{4} S$. Равенство достигается для невЫпуклой фигуры, показанной на рисунке 3.

**M768. Сумма $n$ чисел, каждое из которых не превыходит по modulo 1, равна $s$. Доказите, что из них можно выбрать несколько чисел так, что сумма выбранных чисел будет отличаться от $s/3$ не более чем на 1/3.**

Докажем, что данные числа можно разить на три группы так, что суммы чисел в этих группах $s_1 \leq s_2 \leq s_3$ отличаются не более чем на 1, то есть $s_3 - s_1 \leq 1$. (Мы допускаем и «пустые» группы, состоящие из 0 чисел — сумма чисел в такой группе считается равной 0.) Для этого достаточно выбирать числа в произвольном порядке по одному и записьвать в три столбика, причем каждое очередное число добавляется в тот столбик, где сумма чисел на и больше шая, если это число отрицательно, и в тот столбик, где сумма на и меньше шая, если это число неотрицательно (вначале мы возьмем три числа одного знака из данных $n$ чисел и запишем их первыми в разные столбики). Легко видеть, что после каждого шага суммы чисел в столбиках отличаются не более чем на 1, так что в результате мы получим нужное разрешение*).

Теперь проверим, что средняя по величины сумма $s_2$ удовлетворяет требованиям — $1/3 \leq s_2 - s/3 \leq 1/3$, где $s = s_1 + s_2 + s_3$ — сумма всех чисел:

$$3s_2 \leq (s_1 + 1) + s_2 + s_3 = s + 1,$$

$$3s_2 \leq s_1 + s_2 + (s_3 - 1) = s - 1.$$

Интересно выяснить (для каждой $\theta$ между 0 и 1), для каждого наименьшего $d = d(\theta)$ верно аналогичное неравенство $|s' - \theta s| < d$, где $s$ — сумма произвольных $n$ чисел,

*) Подобный алгоритм был использован в решении задачи М575 — одной из самых трудных задач Всегоизной олимпиды в Тбилиси 1979 года. Заметим, что для $n = 3$ и $n = 4$ чисел, средние которых не более двух чисел одного знака, средняя группа у нас может оказаться пустой; убедиться в справедливости утверждения задачи (напечат не пустой группы из одного или нескольких чисел с нужной суммой) можно с помощью перебора.
