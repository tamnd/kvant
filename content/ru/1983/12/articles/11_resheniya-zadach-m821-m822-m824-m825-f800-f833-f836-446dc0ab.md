М821. Решите уравнение
$$x^3 + x^2 + x = -\frac{1}{3}.$$

Перепишем уравнение в виде $3x^3 + 3x^2 + 3x + 1 = 0$; получаем сумма кубов: $(x+1)^3 + 2x^3 = 0$. Запишем ее в виде $(x+1)^3 = -2x^3$ и извлечем кубический корень из обеих частей: $x+1 = -x\sqrt[3]{2}$; отсюда $x = -\frac{1}{1 + \sqrt[3]{2}}$.

Ю. И. Ионин

◆ Будем считать, что множество M расположено на числовой прямой и составлено из отрезков [a1, b1], [a2, b2], ..., [ak, bk], a1 < b1 < a2 < b2 < ... < bk; Длины этих отрезков обозначаем, соответствующим, δ1, δ2, ..., δk. Для каждой пары номеров i и j (1 ≤ i ≤ j ≤ k) через Mij обозначаем множество длини отрезков с концами, лежащими на отрезках [ai, bi], [aj, bj]. Эти множества, очевидно, на числовой прямой образуют отрезки, длины которых равны δi, если i = j, и δi + δj, если i < j. По условияю задачи сумма длины отрезков не меньше 1. Следовательно, δ1 + (δ1 + δ2) + ... + (δ1 + δk) + δ2 + (δ2 + δ3) + (δ2 + δ4) + ... + δk ≥ 1.

В сумме, написанной в левой части неравенства, каждое δj (j = 1, ..., k) встречает k раз. Таким образом, k (δ1 + δ2 + ... + δk) ≥ 1, откуда δ1 + δ2 + ... + δk ≥ 1/k, что и требовалось.

Koординаты брусков в начальной момент обозначаем x1 и x2', где x2' = l + x2, l — длина нераспятой пружины.

Установим соответствие электрических и механических величины в наших колбационных системах.

Пусть положительному заряду Q на пластине A конденсатора соответствует растяжение пружины на длину x. Аналогичным образом скорость изменения заряд Q определяется разностью токов, протекающих по катушкам: ΔQ/Δt = I2 — I1. Стороны S1 и S2 допускают скорости лишь одного знака: v1 > 0, v2 > 0; аналогично диоды D1 и D2 пропускают токи лишь в одном направлении. Энергия конденсатора Q²/2C соответствует потенциальная энергия пружины kx²/2 (а величине 1/C, обратной емкости, — жесткость пружины k). Ф834. На очень длинной неевесомой нити подвешен к потолку шарик массы $m_1 = 0,1$ кг, к нему прекреплен на нити длины $l = 0,2$ м шарик массы $m_2 = 0,05$ кг. Нижнему шарику толком сообщают скорость $v_0$ в горизонтальном направлении. При какой величины $v_0$ шарики могут оказаться на одной высоте?

При очень длинной верхней нити можно считать, что верхний шарик движется по горизонтальной прямой. В тот момент, когда шарики окажутся на одной и той же высоте, то есть нижняя нить займет горизонтальное положение (см. рисунок), горизонтальная проекция скорости второго шарика будет равна скорости первого шарика. Это следует из нерастяжимости соединяющей их нити. Чтобы минимальное значение скорости $v_0$, при которой шарики окажутся на одной высоте, нужно считать, что в этот момент вертикальная проекция скорости второго шарика равна нулю (то есть скорости $v$ общих шариков равны и направлены горизонтально).

Все действующие на системе внешние силы (наяжение верхней нити и силы тяжесте) направлены по вертикали. Поэтому горизонтальная проекция полного импульса системы сохраняется:

$$m_2 v_0 \min = (m_1 + m_2) v.$$

Отсюда

$$v = v_0 \min \frac{m_2}{(m_1 + m_2)}.$$

Согласно закону сохранения механической энергии,

$$\frac{1}{2} m_2 v_0^2 \min = \frac{1}{2} (m_1 + m_2) v^2 + m_2 gl.$$

Подставляя в это уравнение найденное выражение для $v$, находим

$$v_0 \min = \sqrt{2 gl \left(1 + \frac{m_2}{m_1}\right)}.$$

Подставляя числовые данные, получаем

$$v_0 \min = \sqrt{3 gl} \approx 2,4 \text{ m/c.}$$

В пределном случае $m_2 \ll m_1$ верхний шарик остается неподвижным, и, чтобы нижний шарик поднялся на высоту $l$, ему нужно сообщить скорость $v_0 = \sqrt{2 gl}$.

Ф836. Пластина А плоское конденсатора неподвижна, пластина Б прикреплена к стене пружиной и может двуцаться, оставясь параллельной пластине А (см. рисок). После замыкания ключа К пластина Б начала двуцаться и остановилась в новом положении равновесия. При этом расстояние между пластинами уменьшилось на $a_1=10\%$. На сколько изменилось бы равновесное расстояние между пластинами, если бы ключа К замкнул на короткое время? Предполагается, что за это время пластина Б не успевает заметно сdvинуться.

Когда ключ $K$ замкнут, направление на конденсатор поддерживает постоянным и равным ЭДС $\mathcal{E}$ источника. Пусть начальное расстояние между пластинами конденсатора (когда пружина не растянута) равно $d$, а смешение пластины Б при достижении нового положения равновесия равно $x_1=a_1d=0,1d$. Заряд на конденсатор при этом будет

$$Q_1 = C_1 \mathcal{E} = \frac{\varepsilon_0 S \mathcal{E}}{(d-x_1)},$$

где $S$ — площадь пластина конденсатора. Например, поля в конденсаторе $E_1=\mathcal{E}/(d-x_1)$. Это поле создает двумя пластинами, так что поле, создаваемое одной пластиной, имеет направленность $E_1/2$. В соответствии с этим для сил, действующих на пластину $B$, можно записать

$$\frac{E_1 Q_1}{2} = \frac{\varepsilon_0 S \mathcal{E}^2}{2(d-x_1)^2} = kx_1$$

(к — жесткость пружины).

Рассмотрим теперь ситuation, когда ключ $K$ замкнут на короткое время. Конденсатор при этом получаем загрязнД

$$Q_2 = \varepsilon_0 S \mathcal{E}/d$$

(плastины не успели сdvинуться с места), который в дальнейшем остается постоянным. Пусть в новом положении равновесия смешение пластины $B$ равно $x_2$. тогда направленность поля в конденсаторе будет $E_2 = Q_2/C_2(d-x_2)$, где $C_2=\varepsilon_0 S/(d-x_2)$. Условие равновесия пластины $B$ запишется в виде

$$\frac{E_2 Q_2}{2} = \frac{Q_2^2}{2\varepsilon_0 S} = \frac{\varepsilon_0 S \mathcal{E}^2}{2d^2} = kx_2.$$

Из уравнения (1) и (2) находим $x_2$:

$$x_2 = x_1 \left(\frac{d-x_1}{d}\right)^2 = 0,081d,$$

то есть расстояние между пластинами конденсатора уменьшается на $a_2=8,1\%$.
