Н. И. Авилов

◆ Будем считать, что множество M расположено на числовой прямой и составлено из отрезков [a1, b1], [a2, b2], ..., [ak, bk], a1 < b1 < a2 < b2 < ... < bk; Длины этих отрезков обозначаем, соответствующим, δ1, δ2, ..., δk. Для каждой пары номеров i и j (1 ≤ i ≤ j ≤ k) через Mij обозначаем множество длини отрезков с концами, лежащими на отрезках [ai, bi], [aj, bj]. Эти множества, очевидно, на числовой прямой образуют отрезки, длины которых равны δi, если i = j, и δi + δj, если i < j. По условияю задачи сумма длины отрезков не меньше 1. Следовательно, δ1 + (δ1 + δ2) + ... + (δ1 + δk) + δ2 + (δ2 + δ3) + (δ2 + δ4) + ... + δk ≥ 1.

В сумме, написанной в левой части неравенства, каждое δj (j = 1, ..., k) встречает k раз. Таким образом, k (δ1 + δ2 + ... + δk) ≥ 1, откуда δ1 + δ2 + ... + δk ≥ 1/k, что и требовалось.
