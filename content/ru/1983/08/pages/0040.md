⟦folio 38⟧

Когда
$$|a + \theta| = |a| + |\theta|$$?

Л. Б. ПЕЧЕРСКИЙ

Как известно («Алгебра и начала анализа 9—10», п. 3),
$$|a| - |b| \leqslant |a+b| \leqslant |a| + |b|$$ (1)

Из геометрического смысла модели легко следует, что $|a+b| = |a| + |b|$ тогда и только тогда, когда $a$ и $b$ — числа одного знака, точнее (поскольку не запрещается, чтобы какое-нибудь из них было нулем) — когда $a \geqslant 0$ и $b \geqslant 0$ или когда $a \leqslant 0$ и $b \leqslant 0$.

Очевидно, формулированный критерий равенства можно записать и так:
$$|a+b| = |a| + |b| \Leftrightarrow ab \geqslant 0.$$ (2)

Следовательно,
$$|a+b| < |a| + |b| \Leftrightarrow ab < 0.$$

Критерий равенства «в сложной форме» справедлив для любого числа слагаемых: $|a_1+a_2+\dots+a_n| = |a_1| + |a_2| + \dots + |a_n|$ тогда и только тогда, когда $a_1, a_2, \dots, a_n$ — числа одного знака (точнее — когда среди чисел $a_1, a_2, \dots, a_n$ нет чисел разного знака).

Между прочит, утверждение $|a+b+c| = |a| + |b| + |c| \Leftrightarrow abc \geqslant 0$ неверно (почему?).

Пример 1. Решим уравнение
$$|\lg(2x-3) + \lg(4-x^2)| = (3) = |\lg(2x-3)| + |\lg(4-x^2)|.$$

По критерию (2) это уравнение равносильно уравнению
$$\lg(2x-3) \cdot \lg(4-x^2) \geqslant 0$$,
которое, в свою очередь, равносильно системе
$$\begin{cases} \lg(2x-3) \cdot \lg(4-x^2) \geqslant 0 \\ 2x-3 > 0 \\ 4-x^2 > 0 \end{cases}$$

Так как $\frac{3}{2} < x < 2 \Leftrightarrow 0 < 2x-3 < 1$, последняя система равносильно системе
$$\begin{cases} \lg(2x-3) < 0 \\ \lg(4-x^2) \leqslant 0 \\ \frac{3}{2} < x < 2 \end{cases}$$

$$\begin{cases} \frac{3}{2} < x < 2 \\ 0 < 4-x^2 \leqslant 1 \end{cases}$$

$$\begin{cases} \frac{3}{2} < x < 2 \\ x^2 \geqslant 3 \end{cases}$$

$$\begin{cases} \frac{3}{2} < x < 2 \\ x \geqslant \sqrt{3} \end{cases}$$

Ответ. $[\sqrt{3}; 2]$.

Пример 2. Решим «уравнение с параметром»
$$|a-2\sin x| + 2|\sin x-\cos x| + |2\cos x-1| = a-1.$$

При $a < 1$ это уравнение, очевидно, корней не имеет. Пусть теперь $a \geqslant 1$. Так как
$$(a-2\sin x) + 2(\sin x-\cos x) + (2\cos x-1) = a-1,$$

можно воспользоваться критерием равенства для трех слагаемых. Поскольку, вдобавок, $a-1 \geqslant 0$, решение уравнения равносильно системе
$$\begin{cases} a-2\sin x \geqslant 0 \\ \sin x-\cos x \geqslant 0 \\ 2\cos x-1 \geqslant 0 \end{cases}$$

или «тройному неравенству»
$$\frac{1}{2} \leqslant \cos x \leqslant \sin x \leqslant \frac{a}{2}.$$
