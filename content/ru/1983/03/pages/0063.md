Физика

1. Запишем второй закон Ньютона для первого груза в момент прохождения стержнем вертикального положения:

$$m_1 (v^2/l) = m_1 g - N.$$

Здесь $v$ — скорость груза, $m_1 g$ — сила тяжестки, $N$ — сила, с которой стержень действует на груз (по модулю она равна силе $F$ действия груза на стержень). Для нахождения скорости $v$ используем закон сохранения энергии для системы из двух груzes, соединенных невероимм стержнем:

$$(m_2 - m_1) g l = (m_1 + m_2) (v^2/2).$$

Из полученных уравнений находим искому силу $F$:

$$F = N = m_1 g (3m_1 - m_2) / (m_1 + m_2) = (1/3) m_1 g = 2 H.$$

2. Запишем законы сохранения энергии и импульса для системы горка — шайба:

$$mg (H - h) = \frac{mv^2}{2} + \frac{MV^2}{2},$$

$$mv - MV = 0.$$

Отсюда найдем относительной скорость движения шайбы и горки:

$$v_{\text{отн}} = v - V = \sqrt{2g (H - h) (1 + n)}.$$

Время падения шайбы с высоты $h$ равно $t = \sqrt{2h/g}$, а расстояние между шайбой и горкой —

$$l = v_{\text{отн}} t = 2 \sqrt{(H - h) h (1 + n)} = 1,6 \text{ м}.$$

8. На альфа-частицу со стороны магнитного поля действует сила Лоренца $F = qvB$, которая сообщает частице центрастремительного ускорения $v^2/R$:

$$m (v^2/R) = qvB.$$

Радиус $R$ окружности, по которой действуется частица, связан с размером области поля $h$ соответствием $R = h/\sin \varphi$. Таким образом, скорость частицы

$$v = (q/m) (Bh/\sin \varphi) = 10^6 \text{ м/c}.$$
