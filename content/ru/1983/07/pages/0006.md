Жозеф Лиувилль (1809–1882)

Теорема Лиувилля (1844 г.). Если α — алгебраическое число степени n ≥ 2, то существует такое число c > 0, что для любых p ∈ Z и q ∈ N
$$|\alpha - \frac{p}{q}| \geq \frac{c}{q^n}$$

(Смысл теоремы состоит в том, что irrationalное алгебраическое число α нельзя «слишком хорошего» приближить рациональными дробями *). Поэтому, если мы найдем irrationalное число, которое можно «слишком хорошего» приближить, оно будет не алгебраическим.)

Доказательство. Пусть α — алгебраическое число степени n ≥ 2. Тогда существует такой многочлен с целыми коэффициентами
$$P(x) = a_n x^n + a_{n-1} x^{n-1} + \dots + a_1 x + a_0, \ (a_n \neq 0),$$
что P(α) = 0. Обозначим через H наиболее из моделей чисел |a_1|, |a_2|, ..., |a_n|. Покажем, что число

$$c = \frac{1}{n^2 H(1 + |\alpha|)^{n-1}}$$

обладает нужным свойством. Заметим для дальнейшего, что c < 1. Возьмем произвольные p ∈ Z и q ∈ N. Тогда

$$P\left(\frac{p}{q}\right) = \frac{a_n p^n + a_{n-1} p^{n-1} q + \dots + a_1 p q^{n-1} + a_0 q^n}{q^n} = \frac{a}{q^n}.$$

По лемме $P\left(\frac{p}{q}\right) \neq 0$. Значит, a ≠ 0.

Поскольку a ∈ Z, мы имеем |α| ≥ 1. Следовательно,

$$|P\left(\frac{p}{q}\right)| \geq \frac{1}{q^n}.$$

Так как P(α) = 0, получаем

$$\frac{1}{q^n} \leq |P\left(\frac{p}{q}\right)| = |P(α) - P\left(\frac{p}{q}\right)| = |a_n \left(a^n - \left(\frac{p}{q}\right)^n\right) + a_{n-1} \left(a^{n-1} - \left(\frac{p}{q}\right)^{n-1}\right) + \dots + a_1 \left(a - \frac{p}{q}\right)|.$$

Если |α - \frac{p}{q}| ≥ 1, то |α - \frac{p}{q}| ≥ 1 ≥ \frac{1}{q^n} > \frac{c}{q^n}.

Если же |α - \frac{p}{q}| < 1, то |\frac{p}{q}| < |\alpha| + 1. Тогда для любого 1 ≤ k ≤ n, k ∈ N, получаем

$$|\alpha^k - \left(\frac{p}{q}\right)^k| = |\alpha - \frac{p}{q}| \cdot |\alpha^{k-1}| + \alpha^{k-2} \cdot \frac{p}{q} + \dots + \left(\frac{p}{q}\right)^{k-1} \leq \left| \alpha - \frac{p}{q} \right| k(|\alpha| + 1)^{k-1} \leq \left| \alpha - \frac{p}{q} \right| n(|\alpha| + 1)^{n-1}.$$

Отсюда

$$\frac{1}{q^n} \leq |\alpha - \frac{p}{q}| n^2(|\alpha| + 1)^{n-1} H = |\alpha - \frac{p}{q}| \cdot \frac{1}{c}, |\alpha - \frac{p}{q}| \geq \frac{c}{q^n}.$$
