⟦folio 5⟧

Теорема. Если $a - a$ аллебраическая число степени $n$, то существует такое число $c_0 > 0$, что для любых $p \in \mathbb{Z}$ и $q \in \mathbb{N}$, для которых $a \neq p/q$, имеем

$$\left| a - \frac{p}{q} \right| \geq \frac{c_0}{q^n}.$$

Доказательство. Случай deg($\alpha$) $\geqslant 2$ рассмотрен выше. Пусть теперь deg($\alpha$) = 1, то есть $a = a/b$ ($a \in \mathbb{Z}$, $b \in \mathbb{N}$). тогда число $c' = 1/b$ обладает нужным свойством. В самом деле, если $a/b \neq p/q$, то $|pb - qa| \geqslant 1$. Следовательно,

$$\left| a - \frac{p}{q} \right| = \left| \frac{a}{b} - \frac{p}{q} \right| = \frac{|pb - qa|}{bq} \geqslant \frac{1}{bq} = \frac{c'}{q}.$$

Выбрав в качестве $c_0$ наименьшее из чисел $c$ и $c'$, получим искомое неравенство.

Teoreму Лиувилля можно доказать также, изучив разность $P(\alpha) - P(p/q)$ с помощью теоремы Лагранжа («Алгебра и начала анализа 9—10», п. 25). Попробуйте проделать это!

Приближение алгебраических чисел рациональных

Будем говорить, что число $a$ допускает приближення порядка $m$, если для некоторой постоянной $\gamma$ существует бесконечного много рациональных дробей $p/q$, удовлетворяющих неравенству

$$0 < \left| a - \frac{p}{q} \right| < \frac{\gamma}{q^m}.$$

Teoreма Лиувилля показывает, что аллебраическая число степени $n$ не допускает приближення порядка $m$, то из (1) и (2) получаем, что для бесконечной последовательности натуральных $q$

$$\frac{c}{q^n} < \frac{\gamma}{q^m}, \frac{1}{q^{m-n}} > \frac{c}{\gamma},$$

а это неравенство при $m > n$ и достаточно больших $q$ невозможно.

Пример трансцендентного числа *)

Теперь у нас есть средство для построения действительных чисел, не являющихся алгебраическими. (Такие числа называются трансцендентными.) Нужно построить число, допускающее приближення сколь угодно высокоого порядка. Мы зададим такое число в виде бесконечной десятичной дроби: $\alpha = 0$, $a_1 a_2 a_3 \dots$, где $a_i = \begin{cases} 1, \text{ если } t = m! \text{ (m = 1, 2,...)}, \\ 0, \text{ если } t \neq m!. \end{cases}$

В частности,

$$a_1 = a_2 = a_6 = a_{24} = a_{120} = a_{720} = \dots = 1,$$

$$a_3 = a_4 = a_5 = a_7 = \dots = a_{23} = a_{25} = \dots = a_{119} = a_{121} = \dots = 0.$$

Тогда для любого $m > 1$

$$\alpha = 0, a_1 \dots a_{(m-1)!} + 0, 0 \dots 0_{am!} = \frac{p_m}{q_m} + \beta_m,$$

где

$$p_m = a_1 a_2 \dots a_{(m-1)!},$$

$$q_m = 10^{(m-1)!}, \beta_m = 0, 0 \dots 0_{am!} \dots,$$

$$0 < \beta_m = 10^{-m!} \cdot a_m! \dots =$$

$$= 10^{-m!} \cdot 1, \dots < 2 \cdot 10^{-m!} = \frac{2}{q_m^m}$$

Таким образом,

$$0 < \left| a - \frac{p_m}{q_m} \right| < \frac{2}{q_m^m}, \quad m = 1, 2, \dots,$$

а это означает, что $a$ допускает приближення сколь угодно высокоого порядка и поэтому не может быть алгебраическим.

4. Покажите, что $a$ будет трансцендентным, если в (3)

$$a_t = \begin{cases} 1 \text{ при } t = m^m \text{ (m = 1, 2,...)}, \\ 0 \text{ при } t \neq m^m. \end{cases}$$

5. Пользовать теорему Лиувилля, постройте еще несколько трансцендентных чисел.
