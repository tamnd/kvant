⟦folio 18⟧

К тому же результату приводит и такой процесс. Пусть α — действительное число. Положим
$$\alpha = a_0 + \frac{1}{a_1}, a_0 - \text{целое},$$
где $a_1 > 1$. Если $a_1$ — не целое, то продолжим процесс dalleше. Представим $a_1$ в виде $a_1 = a_1 + \frac{1}{a_2}$, где $a_1$ — целое, положительное и $a_2 > 1$. Таким образом,
$$\alpha = a_0 \frac{1}{a_1 + \frac{1}{a_2}}.$$
Если $a_2$ — не целое, то можно продолжить процесс dalleше. Таким образом, на $k$-м шаге получаем равенство «Многоэтажная» запись дроби (1) очень громоздка, поэтому в дальнейшем мы будем часто пользоваться следующей более компактной специалной записью:
$$\alpha = a_0 + \frac{1}{a_1} + \frac{1}{a_2} + \dots + \frac{1}{a_{k-1}} + \frac{1}{a_k},$$
где $a_k > 1$.
Нетрудно доказать, что если $\alpha = \frac{p}{q}$ — рациональное число, то для некоторого $k$ число $a_k$ будет целым.

Ясно также, что если при некотором $k$ получится целое $a_k$, то число $a$ является рациональным. Если же $a$ — irrationalное число, то указанный процесс никакогда не оборвется и возникнет бесконечная цепная (или непрерывная) дробь
$$\alpha = a_0 + \frac{1}{|a_1|} + \frac{1}{|a_2|} + \dots +$$
$$\dots + \frac{1}{|a_{k-1}|} + \frac{1}{|a_k|} + \dots$$
Знак равенства здесь стоит условно, поскольку непонятно, что означает выражение справа. Для того чтобы придать ему смысл, рассмотрим конечные суммы вида
$$\pi_k = a_0 + \frac{1}{a_1 + \dots} + \frac{1}{a_k},$$
которые называются подходящими дробями непрерывной дроби (2). По определению принимают, что права часть равенства (2) представляется собой предел подходящих дробей:
$$\lim_{k \to \infty} \pi_k$$
Сформилируем теперь в виде набора задач те свойства цепных дробей, которые составляют основу их элементарной теории и, в частности, установливают равенство (2).

Основные свойства цепных дробей
1. Пусть $\pi_k = \frac{p_k}{q_k}$ — подходящая дробь цепной дроби (2). Доказите справедливость рекуррентных соотношения:
$$p_0 = a_0, p_1 = a_0 a_1 + 1, \dots,$$
$$p_{k+1} = a_{k+1} p_k + p_{k-1}, \dots$$
$$q_0 = 1, q_1 = a_1, \dots,$$
$$q_{k+1} = a_{k+1} q_k + q_{k-1}, \dots$$
для $k = 1, 2, 3, \dots$.
2. Установите следующие соотношения:
a) $q_n p_{n-1} - p_n q_{n-1} = (-1)^n, n \geqslant 1$;
b) $q_k p_{k-2} - p_k q_{k-2} = (-1)^{k-1} a_k, k \geqslant 2$;
c) $\pi_{n-1} - \pi_n = \frac{(-1)^n}{q_n q_{n-1}}, n \geqslant 1$;
d) $\pi_{k-2} - \pi_k = \frac{(-1)^{k-1} a_k}{q_k q_{k-2}}, k \geqslant 2$.
