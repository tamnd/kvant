Алгоритм Евклида и разложение числа в цепную дробь

Пусть $p$, $q$ — два натуральных числа. Производление с остатком, найдем

$$p = a_0 q + q_1, \quad 0 < q_1 < q$$

$$q = a_1 q_1 + q_2, \quad 0 < q_2 < q_1$$

$$q_1 = a_2 q_2 + q_3, \quad 0 < q_3 < q_2$$

$$q_{k-2} = a_{k-1} q_{k-1} + q_k, \quad 0 < q_k < q_{k-1}$$

$$q_{k-1} = a_k q_k.$$

Указанный набор дейстий называется алгоритмом Евклида. Можно показать, что полученное число $q_k$ будет наиболее обширным обшим дейстелем чисел $p$, $q$. Нам этот факт не потребуется, поэтому доказательство мы опускаем*).

Из полученных равенств следует

$$\frac{p}{q} = a_0 + \frac{q_1}{q} = a_0 + \frac{1}{a_1 + \frac{q_2}{q_1}} = \dots = a_0 + \frac{1}{a_1 + \frac{1}{a_2 + \dots + \frac{1}{a_k}}}.$$
