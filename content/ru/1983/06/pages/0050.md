делитель можно записать в виде

$$\sigma(n) = \frac{n}{d_{1}} + \frac{n}{d_{2}} + \dots + \frac{n}{d_{s}} = n \left( \frac{1}{d_{1}} + \frac{1}{d_{2}} + \dots + \frac{1}{d_{s}} \right).$$

где $d_{1}, \dots, d_{s}$ — это все делители числа $n.$ Таким образом, величины $\sigma(n)/n$ равна сумме нескольких чисел из конечной последовательности $1, 1/2, \dots, 1/n$ и она будет тем больше, чем больше в эту сумму войдет чисел с небольшими значениями.

a) Доказем, что $\sigma(n) > 2n$ для любого $n = 6k$, где $k > 1$ (таких чисел, разумеется, бесконечного много). Поскольку $n$ делится на 1, 2, 3, 6 и $k$, из (1) получаем

$$\sigma(n) \geq n \left( 1 + \frac{1}{2} + \frac{1}{3} + \frac{1}{6} + \frac{1}{k} \right) > 2n.$$

6) Пусть $n$ — любое число, кратное произведение $1 \cdot 2 \cdot 3 \cdot \dots \cdot 16 = 16!$. тогда $n$ делится на все натуральные числа от 1 до 16 (этих делителей нам уже хватит) и в силу (1)

$$\sigma(n) \geq n \left( 1 + \frac{1}{2} + \left( \frac{1}{3} + \frac{1}{4} \right) + \left( \frac{1}{5} + \dots + \frac{1}{8} \right) + \left( \frac{1}{9} + \dots + \frac{1}{16} \right) \right) > n \left( 1 + \frac{1}{2} + \frac{1}{4} \cdot 2 + \frac{1}{8} \cdot 4 + \frac{1}{16} \cdot 8 \right) = 3n.$$

Аналогично можно доказать, что при любом $a$ неравенство $\sigma(n) > an$ выполняется для бесконечного множества чисел $n.$ Заметим еще, что, как показывает более точная оценка, в нашем доказательстве для $a = 3$ делитель 16! можно заменить на 7!

b) Из формулы (1) вытекает, что

$$\sigma(n) \leq n \left( 1 + \frac{1}{2} + \dots + \frac{1}{n} \right).$$

Оценим сумму в правой части. Пусть $2^{k} \leq n < 2^{k+1}$, тогда $k \leq \log_{2}n$ и $1 + \dots + \frac{1}{n} < 1 + \left( \frac{1}{2} + \frac{1}{3} \right) + \left( \frac{1}{4} + \dots + \frac{1}{7} \right) + \dots + \left( \frac{1}{2^{k}} + \dots + \frac{1}{2^{k+1}-1} \right) + \frac{1}{2^{k+1}} < 1 + \frac{1}{2} \cdot 2 + \frac{1}{4} \cdot 4 + \dots + \frac{1}{2^{k}} \cdot 2^{k} + 1 = k+2$, то есть $\sigma(n) < n \cdot (k+2) \leq n(\log_{2}n+2).$

г) Оценим сумму $\frac{1}{2} + \dots + \frac{1}{n}$ в неравенстве (2) иначе, чем в пункте в) — с помощью интеграла. Каждый слагаемое $1/k$ в ней можно представить как площад прямоугольника, основанием которого является отрезок $[k-1; k]$ оси $Ox$ (см. рисунок), причем этот прямоугольник расположен под гиперболю $y = 1/x$. Поэтому суммарная площадь всех прямоугольников для $k = 2, \dots, n$ меньше кривolinейной трапеции, ограниченной гиперболой $y = 1/x$, ось $Ox$ и прямыми $x = 1$ и $x = n$. Таким образом,

$$\frac{1}{2} + \dots + \frac{1}{n} < \int_{1}^{n} \frac{dx}{x} = \ln n,$$

и, следовательно, $\sigma(n) < n(\ln n+1).$
