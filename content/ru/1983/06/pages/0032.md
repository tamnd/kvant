Цепные дроби для конкретных чисел

Мы видели выше, что квадратные irrationalности и только они раскладывают в периодические цепные дроби. Таким образом, имеется определенная ясность в структуре цепных дробей квадратических irrationalности. Естественно спросят, какие классы других irrationalных чисел обладают столь же хорошего обозримыми разложениями в цепные дроби. Удовлетворительно ответа на этот вопрос нет.

Например, для числа $\sqrt[3]{2}$ do схх пор неизвестно, будут ли ограничены или нет неполные частиные $a_0, a_1, a_2, \dots, a_k$, ... его разложения в цепную дробь

$$\sqrt[3]{2} = a_0 + \frac{1}{|a_1|} + \frac{1}{|a_2|} + \dots$$

На ЭВМ были расчетны первые несколько тысяч чисел $a_0, a_1, \dots$

Вот самые первые из них:

$$\sqrt[3]{2} = [1; 3, 1, 5, 1, 1, 4, 1, 1, 8, 1, 14, 1, 10, 2, 1, 4, 12, 2, 3, 2, 1, 3, 4, 1, 1, 2, 14, 3, 12, 1, 15, 3, 1, 4, 534, 1, 1, 5, 1, 1, 121, 1, 2, 2, 4, 10, 3, 2, 2, 41, 1, 1, 1, 3, 7, 2, 2, 9, 4, 1, 3, 7, 6, 1, 1, 2, 9, 2, 3, 3, 1, 1, 69, 1, 12, \dots]$$

Из этого разложения видно, что последовательность $a_0, a_1, \dots$ ведет себя как ограниченная последовательность и лишь «выбросы» (например, 534, 121) в отдельных местах нарушают эту картину.

Более того, до схх пор не известно ни одного алгебраического числа, не являющегося квадратной irrationalностью, о цепной дроби которого имелась бы достаточно информации.

Особый интерес вызывало разложения в цепную дробь неокотряхних классических постоянных. Число таких постоянных, для которых известно разложение в цепную дробь, весма невелико.

Л. Эйлер нашел разложение числа $e$ в цепную дробь

$$e = 2 + \frac{1}{|1|} + \frac{1}{|2|} + \frac{1}{|1|} + \frac{1}{|1|} + \frac{1}{|4|} + \dots,$$

где закон обозвращения неполных частных $a_0, a_1, \dots$ таков:

$$a_0 = 2, a_1 = 1, a_2 = 2, a_3 = 1, a_4 = 1, a_5 = 4, \dots, a_{3m} = a_{3m-2} = 1, a_{3m-1} = 2m, m = 1, 2, \dots$$

Напомним, что

$$e = \lim_{n \to \infty} \left(1 + \frac{1}{n}\right)^n = \sum_{k=0}^{\infty} \frac{1}{k!} = 2,718281828459045 \dots$$

Вывод соответствия (10) хотя и нетруден, но не является элементарным. Отметим, что такое же «хорошое» разложение в цепную дробь для числа π никакому не известно.

Мы расссказали здесь лишь о небольшей части задан, в которых встречаются цепные дроби. На самом деле круг их применения, в особенности когда оператор анализичным образом с функциональными дробями, весма широк. Это богатая и сложная область математики, весма далекая от своего завершения.
