Вобобще же уравнение вида
$$x^2 - Dy^2 = 1,$$
(6)
где $D$ — натуральное число, не являющееся квадратом $^*$), называется уравнением Пелля; разумеется, это диофантово уравнение, то есть алгебраическое уравнение с целыми коэффициентами, решение которого ищется в области целых чисел.

Как решить уравнение Пелля?
Первое, что приходит в голову, это прямой перебор: почередно подставлять числа $x = 1, 2, 3, \dots$ в формулу $y = \sqrt{(x^2 - 1)/D}$, пока подкоренное выражение не оказывается точным квадратом. Бессперспективность такого подхода показывает следующий замечательный пример. Уравнение
$$x^2 - 991y^2 = 1$$
имеет решение в целых числах, однако среди его решения $(x_0, y_0)$ наименьшее (!) $x_0$ равно
379 516 400 906 811 930 638 014 896 080.
Далее на самом мощной ЭВМ до него не добавляется простым перебором!

Оказывается, непрерывные дроби дают очень удобный инструмент для решения уравнения Пелля. Опишем алгоритм (без доказательства) решения.

При каждом натуральном $D$, отличном от квадрата целого числа, уравнение (6) имеет бесконечное число решений в целых положительных числах $x, y$. Все они могут быть найдены по формуле
$$x + y\sqrt{D} = (x_0 + y_0\sqrt{D})^k,$$
$k = 1, 2, \dots$,
где $x_0, y_0$ — решение с наименьшим значением $y$. Для нахождения наименьшего решения $(x_0, y_0)$ нужно разложить в целую дробь число $\sqrt{D}$. Если
$$\sqrt{D} = [a_0; a_1, \dots, a_n, 2a_0]$$
и $\frac{p_n}{q_n}$ — подходящая дробь числа $\sqrt{D}$ с номером $n$, то
$$p_n^2 - Dq_n^2 = (-1)^{n-1},$$
(7)
и если $n$ — нечетно (длина перiodа четна), то
$$p_n = x_0, q_n = y_0$$
будет наименьшим решением уравнения

нення Пелля. Если же период нечетен ($n$ — четно), то наименьшее решение находится по формуле
$$x_0 + y_0\sqrt{D} = (p_n + q_n\sqrt{D})^2.$$
Пример 3. Расстоярим уравнение
$$x^2 - 7y^2 = 1.$$
Из разложения $\sqrt{7} = [2; 1, 1, 1, 4]$ находим
$$\frac{p_3}{q_3} = 2 + \frac{1}{|1|} + \frac{1}{|1|} + \frac{1}{|1|} = \frac{8}{3}.$$
Так каклина перiodа четна, то наименьшее решение уравнения $x_0 = 8, y_0 = 3$, а любое решение в науравльных числах получается по формуле
$$x + y\sqrt{7} = (8 + 3\sqrt{7})^k,$$
$k = 1, 2, \dots$
При $k = 2$ имеем $x = 127, y = 48$.
Пример 4. Решим уравнение
$$x^2 - 13y^2 = 1.$$
Раскладывая $\sqrt{13}$ в целую дробь, получаем $\sqrt{13} = [3; 1, 1, 1, 1, 6]$
и $\frac{p_4}{q_4} = 3 + \frac{1}{|1|} + \frac{1}{|1|} + \frac{1}{|1|} + \frac{1}{|1|} = \frac{18}{5}$.
Длина перiodа четна, поэтому наименьшее решение находится по формуле
$$x_0 + y_0\sqrt{13} = (18 + 5\sqrt{13})^2 = 649 + 180\sqrt{13},$$
то есть $x_0 = 649, y_0 = 180$. Общее решение имеет вид
$$x + y\sqrt{13} = (649 + 180\sqrt{13})^k,$$
$k = 1, 2, \dots$
