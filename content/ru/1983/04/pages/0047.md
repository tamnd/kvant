6) Покажем, что для любого натурального $n$ можно подобраться столь малое $\alpha > 0$, что аргументческая прогрессия $1 + \frac{\alpha}{2}, \left(1 + \frac{\alpha}{2}\right) + \alpha, \dots, \left(1 + \frac{\alpha}{2}\right) + n\alpha$ с разностью $\alpha$ и геометрическая прогрессия $1 + \alpha, (1 + \alpha)^2, \dots, (1 + \alpha)^n$ со значением $1 + \alpha$ удовлетворяют условиям задачи.

Воспользуемся тождествором $q^k - 1 = (q - 1)(q^{k-1} + q^{k-2} + \dots + 1)$. Полягая в нем $q = 1 + \alpha$, получим, что при всех $k \ge 1$

$$(1 + \alpha)^k = 1 + \alpha((1 + \alpha)^{k-1} + (1 + \alpha)^{k-2} + \dots + 1).$$

Подберем столь малое $\alpha$, что $(1 + \alpha)^n < 1 + \frac{1}{2n}$, тогда при всех $k = 1, \dots, n$

$$(1 + \alpha)^{k-1} + (1 + \alpha)^{k-2} + \dots + 1 < k(1 + \frac{1}{2n}) \leq k + \frac{1}{2}.$$

При таком $\alpha$ в силу (*) будут выполены неравенства $(1 + \frac{\alpha}{2}) + (k - 1)\alpha < 1 + k\alpha < (1 + \alpha)^k < 1 + \alpha(k + \frac{1}{2}) = (1 + \frac{\alpha}{2}) + k\alpha$ при всех $k = 1, \dots, n$, то есть $k$-й член указанной геометрической прогрессии заключен между $k$-м и $(k + 1)$-м членами аргументической прогрессии, что нам и требовалось.

**M784. Шарообразная планета движется по окружности вокрезды и врачается вокруг своей оси, причем ось сутичного врачания наклонена к плоскости орбиты под углом $\alpha$ (для нашей Земли $\alpha = 66,5^\circ$). Найдите зависимость продолжительности $T$ самого короткого дня в году в данной пункте на поверхности планеты от географической широты $\varphi$ этого пункта. (Движение планеты по орбите считается очень медленным по сравнению с врачанием). Напишите формулу для функции $T = T(\varphi)$ и начерите примерный график.

Рис. 1.

Пусть плоскость, содержащая точки с широтой $\varphi$, пересекает ось врачания планеты в точке $M$, а перpendикуляр к плоскости ее орбиты, проведенный из центра планеты $O$, — в точке $K$ (рис. 2). Гранизация дня и ночи на этой шрифте служит концы хорды $P_1P_2$, по которой указывается больший круг, отделяющий освещенную поливну планеты от неосвещенной. Поэтому продолжительность дня (в сутках) на шрифте $\varphi$ равна $T = \gamma/2\pi$, где $\gamma$ — величины угла $P_1MP_2$.
