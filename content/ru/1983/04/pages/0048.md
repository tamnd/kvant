А. П. Савин

Докажем сразу, что ответ на вопрос 6) утвердительный: если (для некоторого $k > 1$) найдется $b = b_k$ такое, что $a(nk) \leq b \cdot a(n)$ при всех $n$, то $a(n) \leq cn^u$ при некоторых $c$ и $a$.

Положим $a(1) = a$. Переменная ряда головных неравенств на полях, получим, что (для любого натурального $r$)
$$a(kr) \leq a \cdot br = a \cdot kr^u,$$
где $a = \log_k b$. Для любого $n$ выберем $r$ так, что $kr^{-1} < n \leq kr$, то есть $\log_k n \leq r < \log_k n + 1$. Получясь монotonность $a(n)$ и вторым красным тождестом на полях, получаем:
$$a(n) \leq a(kr) \leq a \cdot br < a \cdot b^{\log_k n + 1} = ab \cdot n^{\log_k b} = cn^u,$$
где $c = ab$.

Построим теперь пример, показывающий, что ответ на вопрос в) — отрицательный. Нетрудно построить такую последовательность $a(n)$, которая обладала бы свойством мультитипикативности: $a(mn) = a(m)a(n)$ для всех $m, n$, и при этом (для любого натурального $r$) нашли бы такие $n$, что $a(n) \geq n^r$. Например, можно положить
$$a(n) = p_1^{i_1} p_2^{i_2} p_3^{i_3} \dots p_s^{i_s}$$
для $n = p_1^{i_1} p_2^{i_2} \dots p_s^{i_s}$ (где $p_1 = 2, p_2 = 3, p_3 = 5, \dots$ — последовательно простые числа); тогда для $m = \prod_{r=1}^{s} p_r^{i_r}$, $n = \prod_{r=1}^{s} p_r^{i_r}$ будет $a(mn) = a(m)a(n) = \prod_{r=1}^{s} p_r^{i_r(i_r+i_r)}$ и для $n = p_r^k$ (при каждом натуральном $k$) $a(n) = p_r^k = n^r$.

Для этой последовательности условия $a(n) \leq b_k a(n)$ будет выполнено, например, при $b_k = a_k$. Но ни для каких $c$ и $a$ оценка $a(n) \leq cn^a$ не может быть верной для всех $n$, поскольку при $r > \alpha$ существует бесконечного много $n$ таких, что $a(n) \geq n^r > cn^a$ (при достаточно большом $n$).

Рассмотрим движение одного шарика, свободно падающего в близости оси симметрии. Сразу после соударения с поверхностью шарика имеет скорость $v_0 = \sqrt{2gH}$ (поскольку удар абсолотно упругий); вектор $\vec{v}_0$ составляет угол $2\alpha$ с вертикальной (см. рисунок).

Пусть через время $t$ после соударения с поверхностью шарика вдоль горизонтали равно $l$ (см. рисунок), то есть
$$v_0 \sin 2\alpha \cdot t = l \Rightarrow t = l/v_0 \sin 2\alpha = l/(\sqrt{2gH} \sin 2\alpha),$$
где $v_0 \sin 2\alpha$ — горизонтальная проекция скорости $v_0$ (за время $t$ шарик не ударяется по поверхности). Высота, на которой будет находиться шарик через время $t$, равна
$$\Delta h = h_0 + v_0 \cos 2\alpha \cdot t - gt^2/2,$$
(*)
где $v_0 \cos 2\alpha$ — вертикальная проекция скорости $v_0$.
