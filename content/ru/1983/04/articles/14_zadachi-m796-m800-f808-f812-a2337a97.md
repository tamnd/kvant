6) Покажем, что для любого натурального $n$ можно подобраться столь малое $\alpha > 0$, что аргументческая прогрессия $1 + \frac{\alpha}{2}, \left(1 + \frac{\alpha}{2}\right) + \alpha, \dots, \left(1 + \frac{\alpha}{2}\right) + n\alpha$ с разностью $\alpha$ и геометрическая прогрессия $1 + \alpha, (1 + \alpha)^2, \dots, (1 + \alpha)^n$ со значением $1 + \alpha$ удовлетворяют условиям задачи.

Воспользуемся тождествором $q^k - 1 = (q - 1)(q^{k-1} + q^{k-2} + \dots + 1)$. Полягая в нем $q = 1 + \alpha$, получим, что при всех $k \ge 1$

$$(1 + \alpha)^k = 1 + \alpha((1 + \alpha)^{k-1} + (1 + \alpha)^{k-2} + \dots + 1).$$

Подберем столь малое $\alpha$, что $(1 + \alpha)^n < 1 + \frac{1}{2n}$, тогда при всех $k = 1, \dots, n$

$$(1 + \alpha)^{k-1} + (1 + \alpha)^{k-2} + \dots + 1 < k(1 + \frac{1}{2n}) \leq k + \frac{1}{2}.$$

При таком $\alpha$ в силу (*) будут выполены неравенства $(1 + \frac{\alpha}{2}) + (k - 1)\alpha < 1 + k\alpha < (1 + \alpha)^k < 1 + \alpha(k + \frac{1}{2}) = (1 + \frac{\alpha}{2}) + k\alpha$ при всех $k = 1, \dots, n$, то есть $k$-й член указанной геометрической прогрессии заключен между $k$-м и $(k + 1)$-м членами аргументической прогрессии, что нам и требовалось.

Докажем сразу, что ответ на вопрос 6) утвердительный: если (для некоторого $k > 1$) найдется $b = b_k$ такое, что $a(nk) \leq b \cdot a(n)$ при всех $n$, то $a(n) \leq cn^u$ при некоторых $c$ и $a$.

Положим $a(1) = a$. Переменная ряда головных неравенств на полях, получим, что (для любого натурального $r$)
$$a(kr) \leq a \cdot br = a \cdot kr^u,$$
где $a = \log_k b$. Для любого $n$ выберем $r$ так, что $kr^{-1} < n \leq kr$, то есть $\log_k n \leq r < \log_k n + 1$. Получясь монotonность $a(n)$ и вторым красным тождестом на полях, получаем:
$$a(n) \leq a(kr) \leq a \cdot br < a \cdot b^{\log_k n + 1} = ab \cdot n^{\log_k b} = cn^u,$$
где $c = ab$.

Построим теперь пример, показывающий, что ответ на вопрос в) — отрицательный. Нетрудно построить такую последовательность $a(n)$, которая обладала бы свойством мультитипикативности: $a(mn) = a(m)a(n)$ для всех $m, n$, и при этом (для любого натурального $r$) нашли бы такие $n$, что $a(n) \geq n^r$. Например, можно положить
$$a(n) = p_1^{i_1} p_2^{i_2} p_3^{i_3} \dots p_s^{i_s}$$
для $n = p_1^{i_1} p_2^{i_2} \dots p_s^{i_s}$ (где $p_1 = 2, p_2 = 3, p_3 = 5, \dots$ — последовательно простые числа); тогда для $m = \prod_{r=1}^{s} p_r^{i_r}$, $n = \prod_{r=1}^{s} p_r^{i_r}$ будет $a(mn) = a(m)a(n) = \prod_{r=1}^{s} p_r^{i_r(i_r+i_r)}$ и для $n = p_r^k$ (при каждом натуральном $k$) $a(n) = p_r^k = n^r$.

Для этой последовательности условия $a(n) \leq b_k a(n)$ будет выполнено, например, при $b_k = a_k$. Но ни для каких $c$ и $a$ оценка $a(n) \leq cn^a$ не может быть верной для всех $n$, поскольку при $r > \alpha$ существует бесконечного много $n$ таких, что $a(n) \geq n^r > cn^a$ (при достаточно большом $n$).

Ф797. Плоский конденсатор заполнен диэлектриком, диэлектрическая пропицаемость которого зависит от напряжения $U$ на конденсаторе по закону $\varepsilon = \alpha U$, где $\alpha = 0,1$ $B^{-1}$. Паралельно этот диэлектрик, диэлектрика, емкость «нелинейном» конденсатору (незаряженному) подключают обычный конденсатор, заряженный до разности потенциалов $U_0 = 60$ В. Каким будет напряжение на конденсаторе?

Поскольку «нелинейного» конденсатора от общного заклонается лишь в наличии между его обкладками диэлектрика, емкость «нелинейного» конденсатора при напряжении $U$ на нем равна

$$C = \varepsilon C_0 = \alpha UC_0,$$

где $C_0$ — емкость общного конденсатора. При этом заряд на «нелинейном» конденсatore —

$$q_H = CU = \alpha C_0 U^2,$$

а заряд на общном конденсatore —

$$q = C_0 U$$

(напряжение $U$ на конденсаторах при паралельном соединительном одинаковое).

Начальный заряд общного конденсатора был равен

$$q_0 = C_0 U_0,$$

и в силу закона сохранения заряда при любом напряжении $U$ на конденсаторах

$$q_H + q = q_0 \Rightarrow \alpha C_0 U^2 + C_0 U = C_0 U_0.$$

Отсюда находится напряжение $U$:

$$U = \frac{\sqrt{4\alpha U_0 + 1} - 1}{2\alpha} = 20 \text{ В.}$$
