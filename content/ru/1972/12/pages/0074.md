6. Ввести обозначение $y = \frac{2}{x}$, тогда получим
$$y \geq \frac{\sqrt{3}}{2}, \quad y \leq -\frac{\sqrt{3}}{2}.$$
Ответ: $-\frac{4}{\sqrt{3}} \leq x \leq \frac{4}{\sqrt{3}}, x \neq 0.$
7. x > 5.
8. -1 ≤ x < 1, 7.

11. Ввести обозначение $y = \sqrt{\sin x}, 0 \leq y \leq 1$. Тогда $\sqrt{\cos x} = \sqrt[4]{1-y^4}$. Решаем неравенство
$$\sqrt[4]{1-y^4} > 1-y, из которого следует
0 < y < 1;$$
2πk < x < $\frac{\pi}{2}$ + 2πk, k = 0, ±1, ±2, ...
12. Ввести обозначение $y = \sqrt{2x+1}, y \geq 0;$ тогда $\sqrt{2x+9} = \sqrt{y^2+8}, x = \frac{1}{2}(y^2-1)$. Решаем неравенство
$$\frac{y^2-1}{\sqrt{y^2+8}} < y-1, откуда получаем
1 < y < 3, 5.$$

Ответ: 0 < x < $\frac{45}{8}$.
13. Переменные все члены в левую часть и вынести общий множитель x-3.
Ответ: x ≤ -$\frac{5}{6}$, x ≥ 3.
14. Перейти к равносильному неравенству |x| - |x-2| < 0 при x > 4, x < -4.
Ответ: x < -4.
