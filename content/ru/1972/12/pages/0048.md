Для того чтобы вычислить центростремительноеускорение точек обруча через время $t$ после начала движения, нужно знать их линейную скорость в этот момент. Она равна

$$v = v_0 + at.$$

Позному

$$a_ц = \frac{(v_0 + at)^2}{R}.$$

$$a_A = \sqrt{a^2 + (a_ц + a)^2} =$$

$$= \sqrt{a^2 + \left[ \frac{(v_0 + at)^2}{R} + a \right]^2},$$

$$a_B = \sqrt{(2a)^2 + a_ц^2} =$$

$$= \sqrt{4a^2 + \frac{(v_0 + at)^4}{R^2}},$$

$$a_C = \sqrt{a^2 + (a_ц - a)^2} =$$

$$= \sqrt{a^2 + \left[ \frac{(v_0 + at)^2}{R} - a \right]^2},$$

$$a_D = a_ц = \frac{(v_0 + at)^2}{R}.$$
