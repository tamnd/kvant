Фокусы круглого отверстия

Поскольку отверстие дает изображение, мы впраve ввести для него понятия, аналогичные тем, которые вводятся при изучении идеальной линии. Обозначим диаметр отверстия через D, а максимальный разность хода волн через δ. Для любой точки x, лежащей на главной оптической оси, согласно теореме Пифагора можно записать:

$$\left(\frac{D}{2}\right)^2 = (x + \delta)^2 - x^2,$$

или

$$\frac{D^2}{4} = 2\delta x + \delta^2.$$

Величина δ² мала по сравнению с остальныеми величиными, входящими в эту формулу, можно его пренебреть. Тогда

$$x = \frac{D^2}{8\delta}.$$

Согласно критерию Рэлея максимальная разность хода δ не должна превышать четырёх волны, то есть 0 ≤ δ ≤ $\frac{\lambda}{4}$. Подставляя эти значения δ в формулу (1), получим

$$\frac{D^2}{2\lambda} \leq x < \infty.$$

Однако критерию Рэлея определяется не только многоестрою точек (2), но еще и симметрично расположенное ему относительно центра отверстия многоестрою точек (см. рис. 3),

$$-\infty < x \leq -\frac{D^2}{2\lambda}.$$

Таким образом, многоестроя бесконечно удаленного источника света, лежащero на главной оптической оси отверстия.
