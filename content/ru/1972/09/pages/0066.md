$$T_{\max} = mg \left( 1 + \frac{v_0^2}{gl} \right).$$

Максимальная скорость груза $v_0$ находится по углу α, на которой отклоняют нить, из закона сохранения энергии: $$\frac{mv_0^2}{2} = mgh = mgl (1 - \cos \alpha).$$

Используя это соотношение, для максимального значения натяжения нити получаем формулу: $$T_{\max} = mg (3 - 2 \cos \alpha).$$

По условию задачи $T_{\max} = 2mg$. Приравнивая эти выражения, находим cos α=0,5 и, следовательно, α=60°.

Определим теперь натяжение нити при β = α/2. Скорость груза в этот момент также находится из закона сохранения энергии:

$$\frac{mv_1^2}{2} = mgl \left( \cos \frac{\alpha}{2} - \cos \alpha \right).$$

Подставляя значение $v_1$ в формулу для силы натяжения, находим:

$$T = \frac{mv_1^2}{l} + mg \cos \frac{\alpha}{2} = mg \left( 3 \cos \frac{\alpha}{2} - 2 \cos \alpha \right) \approx 1,6 \text{ mg.}$$
