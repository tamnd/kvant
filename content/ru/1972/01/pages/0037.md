⟦folio 35⟧

Упражнения

1. Найти наиболее значения функции
   a) $y = a \sin x + b \sin \left( \frac{\pi}{3} + x \right) + c \sin \left( \frac{\pi}{3} - x \right) \left( a > 0, b > 0, c > 0, 0 < x < \frac{\pi}{3} \right)$;
   b) $z = a \sin (x + y) + b \sin (x - y) + c \sqrt{\cos 2x \cdot \cos 2y}$
      $(a > 0, b > 0, c > 0, 0 < x < \frac{\pi}{4}, 0 < y < \frac{\pi}{4})$;
   c) $u = a \cos x + b \cos y + c \cos z + d \sqrt{2 \cos x \cos y \cos z}$, где $a, b, c, d$ — положительные числа, $x, y, z$ — остальные углы треугольника;
   d) $u = a \sin x + b \sin y + c \sin z + d \sin t + e \sqrt{2 \cos (x + y) \cdot \cos (y + z) \cdot \cos (z + x)}$, где $a, b, c, d, e$ — положительные числа, $x + y + z + t = 2\pi$;
   e) $y = \frac{(a_1 x_1 + a_2 x_2 + \cdots + a_n x_n)^2}{x_1^2 + x_2^2 + \cdots + x_n^2}$ $(a_i > 0, x_i > 0)$.

2. Найти наиболее и наиболее значения функции $u = \sum_{i=1}^{n} x_i y_i$, если извесно, что $\sum_{i=1}^{n} x_i^2 \leq a^2$, $\sum_{i=1}^{n} y_i^2 \leq b^2$ и $a$ и $b$ — положительные числа.

3. Доказать неравенство
   $$\sum_{i=1}^{n} \sqrt{x_i y_i} \leq \sqrt{\sum_{i=1}^{n} x_i} \sqrt{\sum_{i=1}^{n} y_i},$$
   где все $x_i$ и $y_i$ — положительные числа.

4. Доказать неравенство
   $$\left( \sum_{i=1}^{n} \sqrt{a_i b_i} \right)^2 \leq \sum_{i=1}^{n} a_i x_i \sum_{i=1}^{n} \frac{b_i}{x_i},$$
   где все $a_i, b_i, x_i$ — положительные числа.

5. Доказать неравенство
   $$\sum_{i=1}^{n} x_i y_i \sum_{i=1}^{n} \frac{x_i}{y_i} \geq \left( \sum_{i=1}^{n} x_i \right)^2,$$
   где все $x_i, y_i$ — положительные числа.

6. В шар радиуса $R$ висcan цилиндр наиболее полной поверхности. Каковы его радиус и высота?
7. Внутри треугольника некоторая точка расположена так, что сумма квадратов расстояний от нее до сторона треугольника наименьшая. Выразить эти расстояния через длины сторон треугольника и найти эту точку.
8*) Площади грани треугольра равны $S_1, S_2, S_3$ и $S_4$. Точка $M$ лежит внутри треугольра на расстояниях $h_1, h_2, h_3$, и $h_4$ (соответственно) от граней.
   a) При каком положении точки $M$ сумма
      $$\frac{S_1}{h_1} + \frac{S_2}{h_2} + \frac{S_3}{h_3} + \frac{S_4}{h_4}$$

принимает наиболее значение?
6) Доказать, что любой треугольр имеет хотя бы одну точку $M$, для которого сумма (*) минимальная. Найти, сколько таких точек может быть.

*) Эту задачу прислал наш читатель Г. Ованницан из Еревана.
