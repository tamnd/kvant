⟦folio 33⟧

При решении многих математических задач применяется так называемое неравенство Буняковского-Коши

$$\sum_{i=1}^{n} a_i b_i \leq \sqrt{\sum_{i=1}^{n} a_i^2} \cdot \sqrt{\sum_{i=1}^{n} b_i^2} \quad (a_i > 0, b_i > 0).$$

Приведем сначала малозвесное, но весма простое доказательство этого неравенства. Пусть $$\sqrt{\sum_{i=1}^{n} a_i^2} = A, \quad \sqrt{\sum_{i=1}^{n} b_i^2} = B.$$ Тогда нам надо доказать, что

$$\frac{\sum_{i=1}^{n} a_i b_i}{AB} \leq 1.$$

Используя неравенство $xy \leq \frac{1}{2}(x^2+y^2)$, написем следующую целочкумнение:

$$\frac{\sum_{i=1}^{n} a_i b_i}{AB} = \sum_{i=1}^{n} \left(\frac{a_i}{A} \cdot \frac{b_i}{B}\right) \leq$$

$$\leq \sum_{i=1}^{n} \frac{1}{2} \left[ \left(\frac{a_i}{A}\right)^2 + \left(\frac{b_i}{B}\right)^2 \right] = \frac{1}{2} \left( \frac{1}{A^2} \sum_{i=1}^{n} a_i^2 + \frac{1}{B^2} \sum_{i=1}^{n} b_i^2 \right) = 1.$$

Отсюда следует неравенство (*). Как известно, равенство в нем достигается при

$$\frac{a_1}{A} = \frac{b_1}{B}, \quad \frac{a_2}{A} = \frac{b_2}{B}, \dots, \quad \frac{a_n}{A} = \frac{b_n}{B},$$

то есть при

$$\frac{a_1}{b_1} = \frac{a_2}{b_2} = \dots = \frac{a_n}{b_n}.$$

Покажем теперь, как применяется неравенство (*).

⟦folio 34⟧

1. Найти наиболее значение функции
$$y = a \sin x + b \cos x$$
$$\left(a > 0, b > 0, 0 < x < \frac{\pi}{2}\right).$$

Решение. В силу неравенства (*) имеем
$$y = a \sin x + b \cos x \leqslant \sqrt{a^2 + b^2} \cdot \sqrt{\sin^2 x + \cos^2 x} = \sqrt{a^2 + b^2}.$$
Максимум достигается при условии
$$\frac{a}{b} = \frac{\sin x}{\cos x},$$ то есть при
$$tg x = \frac{a}{b}.$$

2. Трансформатор переменного типа нужно сконструировать так, чтобы его крестообразный железный сердечник заполнялвозможно большую часть внутренней полости круглой обмотки. Каковы должны быть размеры сечения сердечника, изображенного на рисунке, если радис катушки равен $R$?
Решение. Пусть $\Rightarrow AOB = \alpha$, тогда
$$\frac{1}{4} S = y^2 - (y - x)^2 = 2xy - x^2 = R^2 \left(2 \sin \alpha \cos \alpha - \sin^2 \alpha\right).$$
Отсюда $S = 2R^2 \left(2 \sin 2\alpha + \cos 2\alpha - 1\right)$. Воспользуемся неравенством (*):
$$S \leqslant 2R^2 \left(\sqrt{2^2 + 1^2} \cdot \sqrt{\sin^2 2\alpha + \cos^2 2\alpha} - 1\right) = 2R^2 \left(\sqrt{5} - 1\right).$$
Следовательно, $S_{\max} = 2R^2 \left(\sqrt{5} - 1\right)$ и достигается при
$$\frac{\sin 2\alpha}{\cos 2\alpha} = \frac{2}{1},$$ откуда $\alpha = \frac{1}{2}$ arctg 2.

3. Рассмотрим три пары действительных чисел $(a_1, b_1), (a_2, b_2), (a_3, b_3)$. Доказать, что существует треугольник со стороны $a = \sqrt{(a_2 - a_3)^2 + (b_2 - b_3)^2}, \quad b = \sqrt{(a_3 - a_1)^2 + (b_3 - b_1)^2}, \quad c = \sqrt{(a_1 - a_2)^2 + (b_1 - b_2)^2}$.
Решение. Для того чтобы $a, b$ и $c$ были сторонами треугольника, необходимо, чтобы выполнялись неравенства $a + b > c, b + c > a, a + c > b$, каждое из которых эквивалентно неравенству Буняковского — Коши. В самом деле, соответствие $a + b \geqslant c$ эквивалентно неравенству $2ab \geqslant c^2 - a^2 - b^2$ или $2 \sqrt{(a_2 - a_3)^2 + (b_2 - b_3)^2} \cdot \sqrt{(a_3 - a_1)^2 + (b_3 - b_1)^2} \geqslant (a_1 - a_2)^2 + (b_1 - b_2)^2 - (a_2 - a_3)^2 - (b_2 - b_3)^2 - (a_3 - a_1)^2 - (b_3 - b_1)^2 = 2 \left[ (a_3 - a_1) (a_2 - a_3) + (b_3 - b_1) (b_2 - b_3) \right]$, сокращая на 2, получаем неравенство (*). Равенство достигается только, если числа $a_3 - a_1, b_3 - b_1$ пропорциональны числам $a_2 - a_3, b_2 - b_3$; проверьте, что в этом случае вершины треугольника должны лежать на одной прямой.
Аналогично доказывается, что $a + c \geqslant b, b + c \geqslant a$. Значит, треугольник со сторонами $a, b, c$ существует, хотя и может выродиться в отрезок. Можно построить этот треугольник геометрическим — в декартовой системе координат его вершины надо поместить в точки с координатами $(a_1, b_1), (a_2, b_2), (a_3, b_3)$.

   b) $z = a \sin (x + y) + b \sin (x - y) + c \sqrt{\cos 2x \cdot \cos 2y}$
      $(a > 0, b > 0, c > 0, 0 < x < \frac{\pi}{4}, 0 < y < \frac{\pi}{4})$;
   c) $u = a \cos x + b \cos y + c \cos z + d \sqrt{2 \cos x \cos y \cos z}$, где $a, b, c, d$ — положительные числа, $x, y, z$ — остальные углы треугольника;
   d) $u = a \sin x + b \sin y + c \sin z + d \sin t + e \sqrt{2 \cos (x + y) \cdot \cos (y + z) \cdot \cos (z + x)}$, где $a, b, c, d, e$ — положительные числа, $x + y + z + t = 2\pi$;
