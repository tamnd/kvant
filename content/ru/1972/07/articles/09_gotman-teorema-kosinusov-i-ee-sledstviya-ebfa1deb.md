⟦folio 29⟧

В этой статье рассказывается о том, как с помощью теоремы косинусов решать разнообразные геометрические задачи. СAMA теорема косинусов не доказывается.

Для вычисления элементов треугольника по двум сторонам и углу между ними или по трем сторонам применяется соответствие

$$a^2 = b^2 + c^2 - 2bc \cos A,$$

называемое «теоремой косинусов».

Teорему косинусов можно использовать и при решении более трудных задач.

Пример 1. Найти площадь параллелограмма, если известны его стороны a и b и острый угол α между диагонали.

Решение. Пусть $ABCD$ — параллелограмм, причем $AB = a$ и $BC = b$ (рис. 1). Будем считать, что $a > b^*$. Тогда угол $BOC$ между диагонали — острый, и согласно условию задачи $\Rightarrow BOC = \alpha$.

Если обозначить длину диагонали $AC$ через 2x, а длину диагонали $*$) Если $a = b$, то параллелограмм является ромбом, а угол между диагонали — прямой.

BD через 2y, то площадь параллелограмма $S$ равна 2xysinα. Из треугольников $AOB$ и $BOC$, используя теорему косинусов, найдем стороны a и b:

$$a^2 = x^2 + y^2 + 2xycos\alpha,$$
$$b^2 = x^2 + y^2 - 2xycos\alpha.$$

Позтому

$$a^2 - b^2 = 4xycos\alpha,$$

откуда

$$xy = \frac{a^2 - b^2}{4cos\alpha}.$$

Следовательно,

$$S = \frac{(a^2 - b^2)sin\alpha}{2cos\alpha}$$

или

$$S = \frac{a^2 - b^2}{2}tg\alpha.$$

Примечние. Если $A$ — угол параллелограмма, то $S = absinA$, откуда следует, что $0 < S \leq ab$. Позтому

$$\frac{a^2 - b^2}{2}tg\alpha \leq ab$$ и

$$tg\alpha \leq \frac{2ab}{a^2 - b^2}.$$

Таким образом, чтобы задача имела решение, необходимо параметры a, b и α выбрать так, чтобы выполнялись неравенства

$$a > b > 0, \alpha \leq arctg \frac{2ab}{a^2 - b^2}.$$

С помощью известных формул геометрии и тригонометрии из теоремы косинусов можно вывести некоторые соотношения, связывающие элементы любого треугольника.

Пример 2. Доказать, что стороны, улы и площадь S треугольника ABC удовлетворят соотношениями

$$\text{ctg } A + \text{ctg } B + \text{ctg } C = \frac{a^2 + b^2 + c^2}{4S}.$$

Решение. Из формулы $S = \frac{1}{2} bc \sin A$ находим, что $bc = \frac{2S}{\sin A}$. Подставив в формулу $a^2 = b^2 + c^2 - 2bc \cos A$ вместе $2bc$ выражение $\frac{4S}{\sin A}$, получим соотношение

$$a^2 = b^2 + c^2 - 4S \text{ctg } A.$$ (1)

Следовательно,

$$\text{ctg } A = \frac{b^2 + c^2 - a^2}{4S}.$$

Если в соответствии с этой формулой выразить через стороны треугольника $ctg B$ и $ctg C$ и полученные выражения сложить, то мы получим тожество

$$\text{ctg } A + \text{ctg } B + \text{ctg } C = \frac{a^2 + b^2 + c^2}{4S}.$$

Пример 3. Доказать, что для любого треугольника справедлицы неравенства

a) $\sin \frac{A}{2} \leqslant \frac{a}{2\sqrt{bc}}$,

b) $\text{tg} \frac{A}{2} \leqslant \frac{a}{2h_a}$,

еде $a, b, c$ — стороны треугольника ABC и $h_a$ — высота, проведенная из вершины A.

Решение. a) Формулу (*) можно записать так:

$$a^2 = (b - c)^2 + 2bc (1 - \cos A).$$

Если $1 - \cos A$ заменить теперь $2\sin^2 \frac{A}{2}$, то мы придем к такой формуле

$$a^2 = (b - c)^2 + 4bc \sin^2 \frac{A}{2}.$$ (2)

Позатем

$$a^2 \geqslant 4bc \sin^2 \frac{A}{2},$$

или

$$\sin \frac{A}{2} \leqslant \frac{a}{2\sqrt{bc}},$$

причем равенство достигается только при $b = c$.

6) Формулу (2) легко привести к такому виду:

$$a^2 = (b - c)^2 + 4S \text{tg} \frac{A}{2}.$$ (3)

Для этого достаточно выполнить следующие преобразования:

$$bc \sin^2 \frac{A}{2} = \frac{2S}{\sin A} \sin^2 \frac{A}{2} =$$

$$= \frac{2S\sin^2 \frac{A}{2}}{2\sin \frac{A}{2}\cos \frac{A}{2}} = S \text{tg} \frac{A}{2}.$$

Из формулы (3) вытекает неравенство $a^2 \geqslant 4S \text{tg} \frac{A}{2}$, откуда $tg \frac{A}{2} \leqslant \frac{a^2}{4S}$.

Учитывая, что $S = \frac{1}{2} ah_a$, получим неравенство $tg \frac{A}{2} \leqslant \frac{a}{2h_a}$.

Из приведенных примеров видно, что формулу

$$a^2 = b^2 + c^2 - 2bc \cos A$$

с помощью несложных преобразований к одному из видов 1—3. Аналогично выводятся следующие соотношения:

$$a^2 = (b + c)^2 - 4bc \cos^2 \frac{A}{2},$$ (4)

$$a^2 = (b + c)^2 - 4S \text{tg} \frac{A}{2}.$$ (5)

Рассмотрим теперь несколько задач, решающихся с помощью формул (1)—(5).

Пример 4. Вычислить площадь треугольника, если данные его стороны.

Решение. Перепишем соответствия (3) и (5) следующим образом:

$$4S \mathrm{tg} \frac{A}{2} = a^2 - (b - c)^2,$$
$$4S \mathrm{ctg} \frac{A}{2} = (b + c)^2 - a^2.$$

Если перimetр треугольника обозначить через 2p, то
$$a^2 - (b - c)^2 = (a + b - c) \times (a + c - b) = 4(p - b) \times (p - c),$$
$$(b + c)^2 - a^2 = (a + b + c) \times (b + c - a) = 4p(p - a).$$

Следовательно,

$$S \mathrm{tg} \frac{A}{2} = (p - b)(p - c),$$
$$S \mathrm{ctg} \frac{A}{2} = p(p - a).$$

Переменная эти равенства по-членно, получим известную формулу Герона для вычисления площади треугольника

$$S^2 = p(p - a)(p - b)(p - c).$$

Пример 6. Данный треугольник разделить на две равновеликие части отрезком наименьшей длины.

Решение. Пусть отрезок MN делит площадь треугольника ABC пополам (рис. 3). Если точки M и N лежат на сторонах угла BAC и S — площадь треугольника ABC, то площадь треугольника AMN равна $\frac{1}{2}S$, и по формуле (3)

$$MN^2 = (AM - AN)^2 + 2S \mathrm{tg} \frac{A}{2},$$

Отсюда сразу находим, что при AM = AN отрезок MN имеет наименьшую длину, равную $\sqrt{2S \mathrm{tg} \frac{A}{2}}$.

Рис. 3.

Длину отрезка AM легко вычислить, поскольку $S = AM^2 \sin A = \frac{1}{2} bc \sin A,$

откуда

$$AM = \sqrt{\frac{bc}{2}}.$$

Ясно, что если концы отрезка MN лежат на сторонах угла B треугольника, то наименьшая длина этого отрезка равна $\sqrt{2S \mathrm{tg} \frac{B}{2}}.$

Пусть $a < b < c,$ тогда

$$\sqrt{2S \mathrm{tg} \frac{A}{2}} < \sqrt{2S \mathrm{tg} \frac{B}{2}} < \sqrt{2S \mathrm{tg} \frac{C}{2}}.$$

Позному длина минимального отрезка MN равна $\sqrt{2S \mathrm{tg} \frac{A}{2}}.$ При этом $AM = AN = \sqrt{\frac{bc}{2}}.$

Построение отрезка MN всегда возможно; так как $c < a + b < 2b,$ то $\sqrt{\frac{bc}{2}} < b$ и подавно $\sqrt{\frac{bc}{2}} < c.$
