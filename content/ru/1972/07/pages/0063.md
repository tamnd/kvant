МОСКОВСКИЙ ГОСУДАРСТВЕННЫЙ ПЕДАГОГИЧЕСКИЙ ИНСТИТУТ ИМЕНИ В. И. ЛЕНИНА

Вариант 1

1. $$\frac{2a^2(2\sqrt{3} - 3)}{3}$$. Указание.
Заметив (и доказав), что $\Rightarrow ASC = \Rightarrow BSD = 90^\circ$ и что диагонали сечения взаимно перпендикулярны, находим диагонали и площадь четырехугольника.
2. $1 \text{ m/сек}; 1,2 \text{ m/сек}$.
3. $x < -1 - \sqrt{2}; 0 < x < \sqrt{2} - 1; x > 1$.
4. $x = \frac{\pi}{3} + 2\pi n$. Указание. ОДЗ исходного уравнения определяется условиями: 1) $\cos x + 1 > 0$; 2) $\sin x > 0$; 3) $\sin x \neq \frac{\sqrt{2}}{2}$. Перейд к уравнению $1 + \cos x = 2\sin^2 x$
и выразив $\sin^2 x$ через $1 - \cos^2 x$, получим совокупность уравнений: 1) $\cos x + 1 = 0$, 2) $\cos x = \frac{1}{2}$. Из решения выбираем только те, которые входят в ОДЗ исходного уравнения, то есть $x = \frac{\pi}{3} + 2\pi n$.
Заметание. Если $2\sin^2 x$ заменить на $1 - \cos 2x$, то получим уравнение $\cos x = -\cos 2x$, откуда $x_1 = \pi + 2\pi n$, $x_2 = \frac{\pi}{3} + \frac{2}{3} \pi n$; $\sin x_1 = 0$ и потому $x_1$ не входит в ОДЗ, а из решения серии $\frac{\pi}{3} + \frac{2}{3} \pi n$ надо отобразить те, которые входят в ОДЗ. Для этого разбиаем серию $\frac{\pi}{3} + \frac{2}{3} \pi n$ на 3, как говоря, элементарные серии:
$x_1 = \frac{\pi}{3} + 2\pi n; x_2 = -\frac{\pi}{3} + 2\pi n; x_3 = \pi + 2\pi n,$ из которых только $\frac{\pi}{3} + 2\pi n$ входит в ОДЗ.

Напомним, что центр вписанной в треугольник окружности лежит в точке пересечения биссектрис.
2. $40 \text{ km/ч}; 50 \text{ km/ч}.$
3. $x = 5$.
4. $x = \frac{\pi}{2} + 2\pi n$. Указание. Заметив $\cos^2 x$ на $1 - \sin^2 x$ и разложив уравнение на множители, получим совокупность уравнений: 1) $\sin x = 1$ и 2) $\sin x + \cos x = 2$. Второе уравнение решей не имеет.
