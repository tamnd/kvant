Но, с другой стороны, цветных диагоналей в такой доске всегда

$$r_2 + r_1 - 1 \leq \frac{k}{2} + \frac{k}{2} - 1 < k,$$

так что в ней не будет ни одной клетки хотя бы одного из употребленных для раскраски цветов. Противоречие!

Итак, доску $m \times n$ можно выложить линейным $k$-minо тогда и только тогда, когда хотя бы одно из чисел $m, n$ делится на $k$.

Эту задачу можно решить, используя инную раскраску.

2-й способ решения.

Предположим, что ни одно из чисел $m, n$ не делится на $k$, а доска $m \times n$ выложена линейным $k$-minо.

Разделим с остатком $m$ и $n$ на $k$:

$$m = kq_1 + r_1; \quad 0 < r_1 < k,$$
$$n = kq_2 + r_2; \quad 0 < r_2 < k.$$

Раскрасием доску $k$ цветами следующим образом: 1-й столбец — 1-м цветом, 2-й — 2-м, ..., $k$-й — $k$-м, $(k+1)$-й — 1-м и т. д., $m$-й — $r_1$-м цветом (рис. 9).

Раскрашения таким способом доска имеет следующое свойство: если линейное $k$-minо положить на доску вертикально, то оно будет покрывать $k$ клеток одного цвета, а если горизонтально — торовно по одной клетке каждой цвета. Доска, по предположению, выложена $k$-minо; поэтому

$$S_1 \equiv S_2 \equiv \dots \equiv S_k \pmod{k},$$

где $S_1(l=1, 2, \dots, k)$ есть число

С другой стороны, как легко подсчитать,

$$S_{r_1} - S_{r_1+1} = n;$$

следовать,

$$S_{r_1} - S_{r_1+1} \equiv r_2 \pmod{k},$$

$$S_{r_1} \neq S_{r_1+1} \pmod{k}.$$

Полученное противоречие показывает, что для существования искомой укладки необходимо $m: k$ или $k^*$).

3-й способ решения.

Предположим, что доска $m \times n$ выложена линейным $k$-minо и

$$m = kq + r_1; \quad 0 < r_1 < k;$$
$$n \equiv r_2 \pmod{k}; \quad 0 < r_2 < k.$$

Будем говорить, что $k$-minо «растет из $l$-го столбца», если оно расположено горизонтально и начинается в $l$-м столбце (рис. 10).

Обозначим через $t_l$ количество $k$-minо, растущих из $l$-го столбца. По предположению доска выложена $k$-minо; поэтому

$$t_1 \equiv r_2 \pmod{k},$$
$$t_2 \equiv 0 \pmod{k},$$
$$t_3 \equiv 0 \pmod{k},$$
$$\dots$$
$$t_k \equiv 0 \pmod{k},$$
$$t_{k+1} \equiv r_2 \pmod{k},$$
$$t_{k+2} \equiv 0 \pmod{k},$$
$$\dots$$
$$t_{kq+1} \equiv r_2 \pmod{k}.$$

*) $m: k$, как обычно,означет, что $m$ делится на $k$.
