Рассмотрим, кроме многогранника $V$ (зесь под $V$ можно понимать или выпуклую оболочку заданных $n$ точек $A_1, A_2, \dots, A_n$ или пересечение — общую часть — всех $n (n - 1)/2$ полос $\Pi_{ij}$ еще следует многогранники:

$$V_i, \text{ получищеся из } V \text{ сдигом на вектор } \overrightarrow{A_1 A_i} (i = 1, 2, \dots, n); V_1, \text{ размещется, совпадает с } V), \text{ и } V', \text{ получищеся из } V \text{ расстоянием (гомотетей) с коэффициентом 2 и центром в точке } A_1.$$

Докажем следующие три утверждения.

1. Многогранник, получищеся из $V$ сдигом на вектор $\overrightarrow{A_i A_j}$, не имеет общих внутренних точек с $V$ (то есть может пересечаться с $V$ только на границе).

2. Никакие два из многогранников $V_1, V_2, \dots, V_n$ не имеют общих внутренних точек.

3. Все $V_i$ содержится в $V'$.

Докажем 1°. При сдигге на $\overrightarrow{A_i A_j}$ полоса $\Pi_{ij}$ переходит в новую полосу, которая не имеет с ней общих внутренних точек — эти две полосы имеют только общую граничную плоскость. Но $V$ содержится в $\Pi_{ij}$, поэтому тем более верно 1°.

2° сдачу следует из 1°: достаточно заменить, что $V_j$ получищеся из $V_i$ сдигом на вектор $\overrightarrow{A_i A_j}$ (рис. 4).

$$3^\circ \text{ следует из более общого факта: если } ABC \text{ — три точки выпуклого многогранника, } W \text{ и } W' \text{ — многогранник, полученный из } W \text{ растяжением в 2 раза с центром в точке } A, \text{ то четыряя вершина } D \text{ параллелограмма } ABDC \text{ (то есть точка, получшаяся из } C \text{ сдигром на вектор } \overrightarrow{AB}) \text{ принадлежит } W'.$$

M131
Докажите, что четые точки, в которых биссектрисы углов между продолжениями противоположных сторон вписанного четырехугольника пересекают его стороны, являются вершинами ромба.

Мы решим задачу, использую известные теоремы об угле между двумя секущими (рис. 6). Обозначения ясны из рисунка 7. Поскольку $PN$ и $QK$ — биссектрисы, то

$$\alpha_6 - \alpha_1 = \alpha_5 - \alpha_2,$$
$$\alpha_7 - \alpha_4 = \alpha_8 - \alpha_3.$$

Сложив эти два равенства, получим $\alpha_6 + \alpha_7 + \alpha_2 + \alpha_3 = \alpha_1 + \alpha_4 + \alpha_5 + \alpha_8$, следовательно, сумма дуг в каждой части последнего равенства равна половине окружности. Поэтому прямые $PN$ и $QK$ перпендикулярны друг другу. Отсюда следует, что в треугольнике $KPM$ биссектриса угла $P$ является одновременным высотой; тогда она одновременно является и медианой; треугольник $KPM$ равноведенный. То же самое можно сказать о треугольнике $LQN$. Таким образом, в четырехугольнике $KLMN$ диагонали делят друг друга пополам и взаимно перпендикулярны, поэтому он — ромб.

M132
Пусть по окружности выписано $n$ чисел $x_1, x_2, \dots, x_n$, каждое из которых равно (+1) или (-1), причем сумма $n$ попарных произведений соседних чисел равна 0 (как в задаче М93, стр. 42) и вообще для каждой $n = 1, 2, \dots, n - 1$ сумма $n$ попарных произведений чисел, отстоящих друг от друга на $k$ мест, равна 0 (то есть $x_1x_3 + x_2x_4 + \dots = 0$, $x_1x_4 + x_2x_5 + \dots = 0$ и т. д.). Пример для $n = 4$ dan на рисунке 8).

a) Докажите, что $n$ — квадрат целого числа.
b) Существует ли такой набор $n$ чисел при $n = 16$?

Докажем, что $n$ — квадрат целого числа. Положим $m = x_1 + x_2 + \dots + x_n$. Тогда $m$ — целое число,

$$m^2 = (x_1 + x_2 + \dots + x_n)^2 = (x_1^2 + x_2^2 + \dots + x_n^2) + (x_1x_2 + x_2x_3 + \dots + x_nx_1) + (x_1x_3 + x_2x_4 + \dots + x_{n-1} \times x_1 + x_nx_2) + \dots + x_nx_{n-1}).$$

Как следует из условия задачи, в правой части этого равенства сумма чисел в первой скобке равна $n$, а сумма чисел в любой другой скобке равна 0. Значит, $n = m^2$. Задча a) решена.

Постотрим, при каких $n$ можно подбрать числа $x_1, \dots, x_n$, удовлетворяющие условиям задачи. Как следует из задачи М93, $n$ должно делиться на 4; значит, $n$ — квадрат четного числа. Если $n=4$, то такие числа подбрать можно: $x_1=x_2=x_3=1$, $x_4=-1$. Следующое возможное значение для $n$ — это 16.

Докажем, что для $n=16$ такие числа $x_1, \dots, x_{16}$ подбрать нельзя.

Предположим, что заданы числа $x_1, \dots, x_{16}$, удовлетворяющие условиям задачи, и попытаться прийти к противоречию.

Пусть $m = x_1 + \dots + x_{16}$. Можно считать, что $m \geq 0$ (иначе мы могли бы заменить все числа $x_i$ на $-x_i$ без нарушения условий задачи), как было показано, $m^2 = n = 16$, то есть $m=4$.

Если $p$ из чисел $x_i$ равны $1$ и $q$ равны $-1$, то

$$p + q = n = 16 \text{ и } p - q = m = 4.$$
Значит, $p=10$, $q=6$.

Будем считать, что числа $x_i$ выписаны в вершинах правильного 16-угольника. Отметим звездочками те вершины, где стоит число $-1$ (всего 6 звездочек). Пусть мы повернули всю картину на $\frac{k}{16}$ частей полного оборота ($k=1, 2, \dots, 15$).

Докажем, что при этомровно 2 звездочки перейдут в вершины, где равные были звездочки. Дейстительно, пусть $r$ чисел, равных $-1$, перешли на места, где стояли $-1$. Тогда в сумме $x_1x_{k+1} + x_2x_{k+2} + \dots + x_{16-k+1}x_1$ будет $(6-r)$ слагаемых, в которых первый сомножитель равен $-1$, а второй $+1$, и $(6-r)$ слагаемых, в которых второй сомножитель равен $-1$, а первый $+1$; значит, $2(6-r)$ слагаемых, равных $-1$.

Так как сумма равна 0, то $2(6-r) = 8$, то есть $r=2$.

Теперь можно переформулировать нашу задачу следующего образом: можно ли в вершинах правильного 16-угольника расставить 6 звездочек так, чтобы две из них стояли в противоположных вершинах, и для любого числа $k$ от 1 до 7 существовало бы равное $k$ (под расстоянием между двумя точками полиметра длина меньше из дуг, их соединяющих, причем длина всего окружности принята за 16 частей; расстояние между точками $X$ и $Y$ мы будем обозначать $(XY)$.

Обозначим через $A$ и $B$ диаметрально противоположные точки, отмещенные звездочкой, и через $C, D, E, F$ — другие отмещенные точки. Подсчитаем сумму всех расстояний между точками $A, B, C, D, E, F$. Расстояние 8 встречается один раз, а расстояния от 1 до 7 по два раза — итог общая сумма $2(1+2+3+4+5+6+7)+8=64$.

Посмотрим, какие расстояния реализуется между точками $C, D, E, F$. Так как $(AX) + (BX) = 8$ для любой точки $X$, то сумма $\Sigma$ всех расстояний между точками $C, D, E, F$ равна $64 - (AB) - 4 \cdot 8 = 24$. Кроме того, если какое-то расстояние $k$ реализуется между точками $C, D, E, F$, это значит, что среди чисел $(AC), (AD), (AE), (AF) и (BC), (BD), (BE), (BF)$ встречается меньше двух раз; но тогда и $(8-k)$ встречается меньше двух раз, то есть $(8-k)$ тоже реализуется как расстояние между точками $C, D, E, F$. Посмотрим, как же могут располагаться точки $C, D, E, F$. Легко проверить, что возможно два случая.

1) Какие-то три точки (например, $C, D, E$) образуют треугольник, содержащий центр окружности. Пусть $F$ лежит между $C$ и $D$. Тогда

$$(CD) + (DE) + (CE) = 16,$$
$$(CF) + (DF) = (CD),$$

и, кроме того, $(EF)$ больше $(CE)$ или $(DE)$. Так как $(CD) + (DE) > 8$ и $(CD) + (CE) > 8$, то $\Sigma = (CD) + (DE) + (CE) + (CF) + (DF) + (EF) = 16 + (CD) + (EF) > 24$, хотя, как мы показали раньше, эта сумма должна равнять 24. Значит, первая счучая новозможен.

2) Точки $C, D, E, F$ лежат с одной стороны от некоторого диаметра. Пусть они расположены по окружности в следующем порядке $C, D, E, F$. Тогда $(CD) + (DF) = (CF) + (CE) + (DF) + (EF) = 16$ (сумма $3(CF) + (DE)$). Значит, $3(CF) + (DE) = 24$. Так как $CF > DE$, то $(CF) = 7$, $(DE) = 3$. Если $(CD) = 1$, то $(DF) = 6$; но при этом расстояние $2 = 8 - 6$ не реализуется между точками $C, D, E, F$, что противоречит ранее доказанному. Если $(CD) = 2$, то хотя $(CF) = 7$, расстояние 1 не реализуется. Если $(CD) = 3$, то $(EF) = 1$, и этот случай не отличается от случая $(CD) = 1$.

Бывают экземпляры, у которых есть и четырехугольные, и восмиугольные клетки, но биологи заметили, что если таких «нестандартных» клеток (менее, чем с пятую и более, чем с семью стороны) нет, то пятугольных клеток всегдаровно на 12 большие, чем семиугольных (всего клеток может быть несколько сoten и даже тысячи). Не может ли объяснить этот факт?

Утверждение задачи следует из формулы Эйлера. (О формуле Эйлера смотрите «Квант» № 4, 1972, стр. 31 или Курант и Роббин и с «Что такое математика?» М., «Просвещение», 1967). Действительно, обозначим число вершин волвокса через $B$, число ребер — через $P$, а число граней с $i$ вершинами — через $\Gamma_i$. Тогда по формуле Эйлера

$$2 = B - P + \Sigma \Gamma_i.$$

Но $3B = \Sigma_i \Gamma_i$, поскольку, по условию, в каждой вершине сходятся три грани, а $2P = \Sigma_i \Gamma_i$ — к каждому ребру примыкают две грани. Следовательно,

$$12 = 6B - 6P + 6\Sigma \Gamma_i = \Sigma_{2i} \Gamma_i - \Sigma_{3i} \Gamma_i + \Sigma_{6i} \Gamma_i = \Sigma (6 - i) \Gamma_i.$$

По условию, нестандартных граней нет, то есть $\Gamma_3 = \Gamma_4 = \Gamma_8 = \Gamma_9 = \ldots = 0$. Поэтому $\Gamma_5 - \Gamma_7 = 12$ — в заменательном соответствии с наблюдами биологов.

Заряженный шарик является источником электрического поля, поляризушего нейтральный шарик. В результате поляризация нейтральный шарик становится диполем — в целом нейтральным шариком с зарядами $+q'$ и $-q'$, расстояние между которых равно диаметру шарика $2r$ (рис. 14). Величина заряда $q'$, или, как говоря, степень поляризации шарика, пропорциональная напряженность поля в центре этого шарика, то есть величины $\frac{q}{R^2}$, где $q$ — заряд другого шарика:

$$q' = \frac{\alpha q}{R^2}$$

(α — коэффициент пропорциональнойности).

Теперь найдем силу взаимодействия зарядов шариков. Эта сила равна сумме сил прияжения между зарядом $q$ и зарядом $-q'$ и силы отталкивания между зарядом $q$ и зарядом $+q'$:

$$F = \frac{qq'}{(R-r)^2} - \frac{qq'}{(R+r)^2} = \frac{\alpha q^2}{R^2} \left( \frac{1}{(R-r)^2} - \frac{1}{(R+r)^2} \right) = \frac{\alpha q^2}{R^2} \frac{4Rr}{(R^2-r^2)^2}.$$

Так как $R > r$, то в значенателе формулы можно пребречь $r^2$ по сравнению с $R^2$. В результате получим:

$$F = \frac{\alpha q^2}{R^2} \frac{4Rr}{R^4} = \frac{4\alpha q^2 r}{R^5}.$$

Таким образом, сила взаимодействия шариков пропорциональная $\frac{1}{R^5}$, где $R$ — расстояние между центрами шариков. При увеличении расстояния между шариками в 2 раза сила их взаимодействия уменьшится в 32 раза:

$$\frac{F_1}{F_2} = \frac{\frac{4\alpha q^2 r}{R^5}}{\frac{4\alpha q^2 r}{(2R)^5}} = 2^5 = 32.$$

Ф152

Объем газового пульера, образованшегося в результате глубинного подводного взрыва, колблется с перiodом, пропорциональным $pa\rho bEc$, где $p$ — давление, $\rho$ — плотность воды и $E$ — полная энергия взрыва. Найти $a$, $b$ и $c$.

Известно, что

$$T \sim pa\rho bEc.$$

Величина, стояшая слева в этой формуле, имеет размерность времени $[c]$. Точно такую же размерность должна иметь величины, стояшая справа. Запишем размерности всех величины:

$$p \rightarrow \left[ \frac{H}{m^2} \right] \rightarrow \left[ \frac{\kappa_2}{m \cdot c^2} \right]; \quad \rho \rightarrow \left[ \frac{\kappa_2}{m^3} \right];$$

$$E \rightarrow [\partial \kappa] \rightarrow \left[ \frac{\kappa_2 \cdot m^2}{c^2} \right].$$

Произведение $\rho a\rho bEc$ имеет размерность

$$\left[ \frac{\kappa_2}{m \cdot c^2} \right]^a \left[ \frac{\kappa_2}{m^3} \right]^b \left[ \frac{\kappa_2 \cdot m^2}{c^2} \right]^c \rightarrow [\kappa_2]^{a+b+c} [m]^{-a-3b+2c} [c]^{-2a-2c}.$$

Для того чтобы размерность этого произведения была $[c]$, необходимо, чтобы

$$-2a - 2c = 1,$$

$$a + b + c = 0,$$

$$-a - 3b + 2c = 0.$$

Решая эту систему уравнения, найдем

$$a = -\frac{5}{6}; \quad b = \frac{1}{2}; \quad c = \frac{1}{3}.$$

Следовательно,

$$T \sim p^{-\frac{5}{6}} \rho^{\frac{1}{2}} E^{\frac{1}{3}}.$$
