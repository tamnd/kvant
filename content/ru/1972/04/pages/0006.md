⟦folio 4⟧

РАССТАНОВКА
КУБИКОВ

Н. Б. Васильев

В этой статье мы рассекjem решение одной из задач, предлагавшихся девятиклассикам и десятиклассикам на прошлогодней Всесоюзной математической олимпiadе в Риге (см. «Квант» № 11, 1971). Она формулировалась так.

Задача. Куб с ребром длины $n$ разбит на $n^3$ единичных кубиков. Выберем несколько кубиков и проведем через центр каждой из них три прямы, параллельные ребрам. Какое наименьшее число кубиков можно выбрать так, чтобы проведенные через них прямы перечеркнуты все кубики?

a) Укажите ответ для маленьких значений $n$: для $n=2, 3, 4$.

b) Попробуйте найти ответ для $n=10$.

в) Решите общую задачу. Если вам не удалось найти точный ответ, доказите какие-либо неравенства, оценивающие сверху и снизу число отмеченных кубиков.

г) Заметьте, что эту задачу можно формулировать так. Рассмотрим всевозможные наборы $(x_1, x_2, x_3)$, где каждая из букв $x_1, x_2, x_3$ принимает одно из $n$ значений 1, 2, ..., $n$. Какое наименьшее число наборов нужно выбрать, чтобы для каждой из остальных наборов среди выбранных нашеся такой, который отличался бы от него только в одном месте (значением только одной из координат $x_1, x_2, x_3$)? Попробуйте найти оценки для числа наборов в более общей задаче, когда рассматриваются наборы не из трех, а из четырех и большего количества букв.

Формулировка с ладьями

Чтобы не путаться в словах «куб», «кубик» и «выбранный кубик», удобно переформулировать задачу в других терминах. Весь куб $n \times n \times n$ мы наозем «пространственный шахматной доской», каждый из кубиков $1 \times 1 \times 1$ — «клеткой», каждый выбранный кубик — «клеткой, занятой ладьей».
