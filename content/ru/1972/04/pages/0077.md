4. $\alpha_1 = -1$, $\alpha_2 = 0$. Решение. Перепишем систему неравенств в виде

$$\begin{cases} x^2 + 4x + 3 - \alpha \leq 0, \\ x^2 - 2x - 3 + 6\alpha \leq 0. \end{cases}$$

Если при некоторых $\alpha$ дискриминант хотя бы одного из строящих в левых частях трехчленов отрицательен, то эта система не имеет решения (почему?). Следовательно, система (1) может иметь решения только при таких $\alpha$, для которых одновременно выполнен неравенства

$$1 + \alpha \geq 0, \quad 4 - 6\alpha \geq 0,$$

то есть лишь при $-1 \leq \alpha \leq \frac{2}{3}$ (проведите необходимые выкладки).

При $\alpha = -1$ системе (1) действительно имеет единственное решение (убедитесь в этом). При $\alpha = \frac{2}{3}$ система (1) решения не имеет (доказьте это).

Пусть теперь $\alpha$ — некоторое число из промежутка $-1 < \alpha < \frac{2}{3}$. В этом случае решения первого неравенства системы (1)

является отрезок

$$-2 - \sqrt{1 + \alpha} \leq x \leq -2 + \sqrt{1 + \alpha},$$

а решением второго неравенства этой системы — отрезок

$$1 - \sqrt{4 - 6\alpha} \leq x \leq 1 + \sqrt{4 - 6\alpha}.$$

Система (1) имеет единственное решение отрезки (2) и (3) имеют лишь одну общую точку.

Так как $-2 - \sqrt{1 + \alpha} < 1 + \sqrt{4 - 6\alpha}$ (почему?), то левый конец отрезка (2) лежит левее правого конца отрезка (3), и отрезки имеют единственное общую точку только в одном случае — когда правый конец отрезка (2) совпадает с левым концем отрезка (3), то есть когда

$$-2 + \sqrt{1 + \alpha} = 1 - \sqrt{4 - 6\alpha}.$$

Решая это irrationalное уравнение, находим корень $\alpha = 0$ (проведите решение подробно).
