Решение задачи 2. Решение этой задачи похож на решение задачи 1: нужно убедиться, что коэффициент при $p$ в сумме $\theta(x) + \theta(\sqrt{x}) + \cdots$ равен $[\log_p x]$. Следать это совсем просто. $\log p$ входит слагаемым в $\theta(\sqrt{x})$, если $\sqrt{x} \geq p$, то есть $\log_p x \geq i$. Поэтому в $\sum \theta(\sqrt{x})$ логарифм $p$ входит слагаемым $k$ раз, где $k$ определяется из неравенства $k + 1 > \log_p x \geq k$, то есть $[\log_p x]$ раз.

Решение задачи 4. Эта задача очень похож на задачу M92 (см. «Квант» № 7, 1971).

Действительно, ее можно формулировать следующим образом:

В первую же поэзду в маазин Петя купил себе много маленьких шоколадок. Он решил, что в скучные дни ему следует съедать три шоколадки, в те дни, когда он занят только одним делом — две, а в остальные — по одной. Тогда $A_i + 2$ равно числу шоколадок, которые Петя съел в $i + 1$ день. (Напомним, что Петя каждый второй день зделил купаться, каждый третий — в маазин и каждый пятый решал математические задачи).

Приведем формулу для $A_i$:

$$A_i = 1 - [2^{[i/2] - i/2}] - [2^{[i/3] - i/3}] - [2^{[i/5] - i/5}] + [2^{[i/30] - i/30}].$$

Решение задачи 5. Эта задача следует из задачи 2. Действительно,

$$\psi(x) - \psi(\sqrt{x}) = \theta(x) + \theta(\sqrt{x}) + \cdots \geq \theta(x),$$

$$\psi(x) - 2\psi(\sqrt{x}) = \theta(x) - \theta(\sqrt{x}) + \cdots \leq \theta(x).$$

Решение задачи 6. Поскольку $a_p = [\log_p x]$,

$$a_p \log p \leq \log_p x \log p = \log x, \quad (a_p + 1) \log p > \log x.$$

Позному

$$\psi(x) = \sum_{p \leq x} a_p \log p \leq \sum_{p \leq x} \log x = \pi(x) \log x,$$

$$\psi(x) + \theta(x) = \sum_{p \leq x} (a_p + 1) \log x > \sum_{p \leq x} \log x = \pi(x) \log x,$$

откуда

$$\frac{\psi(x)}{\log x} < \pi(x) < \frac{\psi(x) + \theta(x)}{\log x}.$$
