К статье «Тригонометрические функции»

1. а) $\frac{2\pi}{3}$; б) $2\pi$; в) $4\pi$; г) $\pi$ (у к а-зан и е: $\sin^2 x = \frac{1 - \cos 2x}{2}$); д) $2\pi$; е) $\pi$.

2. б) Предположим, что $T$ — период данной функции, то есть что $\cos(x+T) \times \cos[\sqrt{2}(x+T)] = \cos x \cos \sqrt{2} x$ при любом $x$. Подставив в это равенство $x=0$, получим: $\cos T \cos \sqrt{2} T = 1$. Последнее равенство может выполнять лишь в двух случаях: $\cos T = 1$, $\cos \sqrt{2} T = 1$ или $\cos T = -1$, $\cos \sqrt{2} T = -1$ (если предположить, что один из компоней по абсцилотной величины меньше 1, тогда второй должен быть по абсцилотной величины больше 1, чего бы не может).

В первом случае $T=2\pi k$, $T = \frac{2\pi n}{\sqrt{2}}$, откуда, поделив первое равенство на второе, получим, что $\sqrt{2} = \frac{n}{k}$ (то есть, что $\sqrt{2} = \frac{2n}{k}$).

Второй случай приводится к противоречию аналогично.

7. а) Преобразуем:

$$\frac{\mathrm{tg}(\alpha + \beta)}{\mathrm{tg} \alpha} = \frac{\sin(\alpha + \beta)}{\sin \alpha \cos(\alpha + \beta)} = \frac{\sin \beta + \sin(2\alpha + \beta)}{- \sin \beta + \sin(2\alpha + \beta)} = \frac{\sin \beta + 5 \sin \beta}{- \sin \beta + 5 \sin \beta} = \frac{6 \sin \beta}{4 \sin \beta} = \frac{3}{2}.$$

Заметим, что утверждение задачи верно лишь при $\alpha + \beta \neq \frac{\pi}{2} (2k+1)$, $\alpha \neq \frac{\pi n}{2}$.

6) Имеем: $1 + \mathrm{tg} \frac{x+a}{2} \mathrm{tg} \frac{x-a}{2} = \frac{\cos \left( \frac{x+a}{2} - \frac{x-a}{2} \right)}{\cos \frac{x+a}{2} \cos \frac{x-a}{2}} = 2 \cos a: \left[ \cos \left( \frac{x+a}{2} - \frac{x-a}{2} \right) + \cos \left( \frac{x+a}{2} + \frac{x-a}{2} \right) \right] = \frac{2 \cos a}{\cos x + \cos a} = \frac{2 \cos a}{\cos a + \cos a \cos b} = \frac{2}{\cos b+1} = \frac{1}{\cos^2 \left( \frac{b}{2} \right)}.$

9. а) Обозначив данное выражение через $M$, имеем при $\alpha \neq \pi k$:

$$M = \frac{2^n \sin \alpha \cos \alpha \cos 2\alpha}{2^n \sin \alpha} = \frac{2^{n-1} \sin 2\alpha \cos 2\alpha}{2^n \sin \alpha} = \dots = \frac{\cos 2^{n+1}\alpha}{2^n \sin \alpha}.$$

При $\alpha = \pi k$ имеем

$$M = \cos \pi k \cos 2\pi k \dots \cos 2^n \pi k = \left\{ \begin{array}{l} 1 \text{ при } k=2p, \\ -1 \text{ при } k=2p+1. \end{array} \right.$$

6) Обозначив данное выражение через $M$, получим при $\alpha \neq \pi(2k+1)$:

$$2 \cos \frac{\alpha}{2} M = 2 \cos \frac{\alpha}{2} \cos \alpha - 2 \cos \frac{\alpha}{2} \cos 2\alpha + \dots + 2 \left(-1\right)^{n+1} \cos \frac{\alpha}{2} \cos n\alpha = \cos \frac{\alpha}{2} + \cos \frac{3\alpha}{2} - \cos \frac{3\alpha}{2} - \cos \frac{5\alpha}{2} + \cos \frac{5\alpha}{2} + \cos \frac{7\alpha}{2} - \dots + \left(-1\right)^{n+1} \cos \frac{2n-1}{2}\alpha + \left(-1\right)^{n+1} \cos \frac{2n+1}{2}\alpha = \cos \frac{\alpha}{2} + \left(-1\right)^{n+1} \cos \frac{2n+1}{2}\alpha.$$
