## Условие

Для каждой не прямого треугольника $T$ обозначим через $T_1 = H(T)$ треугольник, вершинами которого служат основания высот треугольника $T_1$; через $T_2 = H(T_1)$ — треугольник, вершинами которого служат основания высот треугольника $T_1$; пусть далее $T_3 = H(T_2)$; $T_4 = H(T_3)$, ...

Какими должны быть углы треугольника $T$, чтобы

a) треугольник $H(T)$ был остроугольным?

b) в последовательности $T_1, T_2, T_3$, ... встретился прямой треугольник $T_n$ (в этом случае $H(T_n) = T_{n+1}$ не определено)?

b) треугольник $T_3 = H(H(T))$ был подобен треугольнику $T$?

г)* Для каждой $n=1, 2, 3, ...$ укажите, сколько существует не подобных друг друг треугольников $T$, для которых $T_n$ подобен $T$.

H. В. Васильев

## Решение

Для каждого не прямого пользового треугольника $T$ обозначим через $H(T) = T_1$ треугольник, вершинами которого служат основания высом треугольника $T$; через $T_2 = H(T_1)$ треугольник, вершинами которого служат основания высом треугольника $T_1$; пусть далее $T_3 = H(T_2)$, $T_4 = H(T_3)$, ...

Каким должны быть улы треугольника $T$, чтобы
a) треугольник $H(T)$ был остроуольным?
b) в последовательности $T_1, T_2, T_3, \dots$ острёмся прямого пользового треугольник $T_n$ (в этом случае $H(T_n) = T_{n+1}$ не определено)?
c) треугольник $T_1 = H(T)$ был подобен треугольнику $T$?
e)* для каждого $n = 1, 2, 3, \dots$ указываем, сколько существует не подобных других треугольников $T$, для которых $T_n$ подобен $T$.

Углы любого треугольника можно обозначить буквами $\alpha, \beta$ и $\gamma$, так, чтобы выполнялись неравенства (2).

Если же $\alpha > \frac{\pi}{2}$, то из (2) мы можем пользоваться только тем, что $2\beta \geqslant 2\gamma$, и должны рассмотреть три возможных соотношения между углами $\alpha_1, \beta_1$ и $\gamma_1$: $2\beta \geqslant 2\gamma \geqslant 2\alpha - \pi, \quad 2\beta \geqslant 2\alpha - \pi \geqslant 2\gamma$ и $2\alpha - \pi \geqslant 2\beta \geqslant 2\gamma$. Первое из них приводит к системе
$$2\beta = \alpha, \quad 2\gamma = \beta, \quad 2\alpha - \pi = \gamma,$$
откуда находим интересное решение:
$$\alpha = \frac{4\pi}{7}, \quad \beta = \frac{2\pi}{7}, \quad \gamma = \frac{\pi}{7},$$

Как пишут читатели, занимающие решения этой задачи, для $n = 2, 3, 4$ и вообще для любого $n$ решения можно получить аналогичным, но значительно более громоздким перебором. Действительно, в принципи мы свели задачу к алгебраической. Наметим возможность план дальнейших расчудений (для произвольного натурального $n$). Из (1) по индукции можно получить формулы для углов треугольника

$$\begin{cases}
\alpha_n = s2^n & \alpha + p\pi \\
\beta_n = s2^n & \beta + q\pi \\
\gamma_n = s2^n & \gamma + r\pi,
\end{cases}$$

где $s$ равно $+1$ или $-1$, $p, q$ и $r$ — целые числа (доказите, что при данных $\alpha, \beta$ и $\gamma$ и при дополнительном условии $\alpha_n \geqslant 0, \beta_n \geqslant 0, \gamma_n \geqslant 0$, $\alpha_n + \beta_n + \gamma_n = \pi$ параметры $p, q, r$, $s$ определяются из (3) однозначно!). Напишем шесть систем, приравнявая ($\alpha_n, \beta_n, \gamma_n$) различных перестановкам ($\alpha, \beta, \gamma$), и решим каждую из них. Из полученных решения (зависших от параметров $p, q, r, s$) выберем те, которые удовлетворяют условиям $\alpha \geqslant \beta \geqslant \gamma$. $$x_{k-1} \leq n < x_k.$$

Дальше можно применить стратегию, аналогичную описанной выше стратегии $S_n$, делить оставшийся промежуток все время пополам. Очевидно, при этом будет потребно до $|\log_2(x_k - x_{k-1})|$ вопросов.

Предположим, что на втором этапе игры, то есть после первого ответа «нет», мы имеем так и играем. Остается выбрать монotonно возрастшую последовательность $x_k$, чтобы полностью определить стратегию.

Разберем три конкретных стратегии, отличношеся лишь выбором последовательности $x_k$.

1. Стратегия $T^1$: $x_k = 10k$. Тогда, как указано в условиям, $f_T(n)$ растет примерно как $\frac{n}{10}$.

2. Стратегия $T^2$: $x_k = 2^k$. Тогда число вопросов на первом этапе не больше $|\log_2 n|$, а число вопросов на втором этапе не больше $|\log_2 \frac{n}{2}|$. Всего получается примерно $2\log_2 n$ вопросов.

3. Стратегия $T^3$: $x_k = 2^{2k}$. Тепер число вопросов на первом этапе резко уменьшилось. В самом деле, пусть

$$2^{2k-1} \leq n < 2^{2k}.$$

Тогда число вопросов на первом этапе игры равно $k$ и не превышает

$$k \leq \log_2 \log_2 n + 1,$$

что при больших $n$ значительно меньше, чем $\log_2 n$. На втором этапе мы потребим приближательно

$$\log_2(2^{2k} - 2^{2k-1}) \approx \log_2 2^{2k} = 2^k$$

 вопросов. Хорошо это или плохо? Это зависит от числа $n$. Оказывается, для наиболее $n$ в промежутке (2) эта стратегия значительно лучше, чем для наиболее $n$ в том же промежутке.

Пусть $n = 2^{2k} - 1$.

Тогда

$$f_T(n) \approx \log_2 \log_2 n + 2^k \approx \log_2 n + \log_2 \log_2 n,$$

При больших $n$ второе слагаемое значительно меньше, и относение $f_T(n)$ к нижней оценке $\log_2 n$ (см. формулу (1)) близко к 1.

Пусть теперь $n = 2^{2k-1}$. Тогда величана $f_T^3(n)$ — такая же, а выраженная через $n$ она составляет

$$f_T^3(n) \approx \log_2 \log_2 n + 2^k \approx 2\log_2 n + \log_2 \log_2 n,$$

то есть примерно двое превышает нижнюю оценку (1). Таким образом, для этих значений $n$ стратегия $T^3$ ничего не лучше стратегии $T^2$.

$$\log_2 n\ln n = \log_2 n + \log_2 \ln n \approx \log_2 n$$

$$\log_2 n + \text{const}\log_2 \log_2 n$$

ворцов.
