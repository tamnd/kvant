## Условие

На сторонах треугольника ABC во внешнюю сторону построены подобные между собой треугольники

$$ADB, BEC \text{ и } CFA \left( |AD| |DB| = |BE| |EC| = |CF| |FA| = k; \right)$$

$$\widehat{ADB} = \widehat{BEC} = \widehat{CFA} = \alpha.$$

Доказите, что:

a) середины отрезков AC, DC, BC и EF — верхины параллелограмма;

b) у этого параллелограмма два угла имеют величины $\alpha$, а отношение длины сторона равно $k$.

Л. Купцов

## Решение

На сторонах треугольника ABC во внешнюю сторону построены подобные между собой треугольники ADB, BEC и CFA ($|AD|/|DB| = = |BE|/|EC| = = |CF|/|FA| = k$, $ADB = BEC = CFA = \alpha$). Докажите, что a) середины отрезков AC, DC, BC и EF — вершины параллелограмма; b) у этого параллелограмма два целых именуются a, а отношение длины сторона равно k.

Обозначим через $\vec{a}'$ вектор, получащийся из вектора $\vec{a}$ поворотом на угол a против часовой стрелки. (Известно, что $(k\vec{a})' = k\vec{a}'$ для любого числа $k$, $(\vec{a} + \vec{b})' = \vec{a}' + \vec{b}'$, и вообще, для любого числа слагаемых, $(\vec{a} + \vec{b} + \dots + \vec{c})' = \vec{a}' + \vec{b}' + \dots + \vec{c}'$.) Введем векторы $\vec{DA} = \vec{a}$, $\vec{EB} = \vec{b}$, $\vec{FC} = \vec{c}$ (см. рисунок).

По условию $\vec{DB} = \frac{1}{k}\vec{a}'$, $\vec{EC} = \frac{1}{k}\vec{b}'$, $\vec{FA} = \frac{1}{k}\vec{c}'$.

Поскольку $\vec{AD} + \vec{DB} + \vec{BE} + \vec{EC} + \vec{FC} + \vec{FA} = 0$, $\vec{a} + \frac{1}{k}\vec{a}' - \vec{b} + \frac{1}{k}\vec{b}' - \vec{c} + \frac{1}{k}\vec{c}' = 0$, то есть $\vec{a} + \vec{b} + \vec{c} = \frac{\vec{a}' + \vec{b}' + \vec{c}'}{k} = \frac{1}{k} (\vec{a} + \vec{b} + \vec{c})'$.

Обозначив $\vec{a} + \vec{b} + \vec{c}$ через $\vec{u}$, получим $\vec{u} - \frac{1}{k}\vec{u}' = 0$. (*)

Поскольку векторы $\vec{u}$ и $\vec{u}'$ неколлинеарны ($\alpha \neq 0$ и $\alpha \neq 2\pi$), равенство (*) возможно тогда, когда $\vec{u} = \vec{0}$. Поэтому $\vec{a} + \vec{b} + \vec{c} = \vec{0}$.

Далее так как $Q$ — середина $[DC]$ и $P$ — середина $[AC]$ (см. рисунок), $\overrightarrow{QP} = \frac{1}{2} \vec{a}$. Аналогично $\overrightarrow{QR} = \frac{1}{2} \overrightarrow{DB}$. Из $(PQ) \parallel (AD)$ и $(QR) \parallel (BD)$ следует $PQR = \alpha$.

Наконец,

$$\overrightarrow{RS} = \overrightarrow{RC} + \overrightarrow{CF} + \overrightarrow{FS} = \frac{1}{2} \overrightarrow{BC} - \vec{c} + \frac{1}{2} \overrightarrow{FE} =$$

$$= \frac{1}{2} \left( -\vec{b} + \frac{1}{k} \vec{b}' \right) - \vec{c} + \frac{1}{2} \left( \vec{c} - \frac{1}{k} \vec{b}' \right) = -\frac{\vec{b} + \vec{c}}{2} = \frac{\vec{a}}{2} = \overrightarrow{QP}$$

Таким образом, четырехугольник $PQRS$ — параллелограмм с углом $PQR$, равным $\alpha$, и отношением длины сторона $|PQ|/|RQ| = |AD|/|DB| = k$.

Л. Купцов
