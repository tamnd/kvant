## Условие

Можно ли числа 1, 2, ..., 30 разбит на группы
a) по пять чисел,
b) по шесть чисел
так, чтобы суммы чисел во всех группах были одинаковыми?
b) При каких n и k числа 1, 2, ..., nk можно разбит на n групп по k чисел так, чтобы суммы чисел во всех группах были одинаковыми?

С. Берколайко

Наозовем разбиение, удовлетворяющее условием задачи, правильным. Ответ на общий вопрос в) задачи дает

Теорема. Чтобы множество {1, 2, ..., nk} допускало правильное разбиение на k-элементные подмножества, необходимого и достаточно, чтобы либо k было четным, либо nk нечетным.

Необходимость этих условий очевидна. В самом деле, пустые разбиение существует; тогда сумма чисел $\frac{nk(nk+1)}{2}$ делится на n (количество подмножества), то есть число $k(nk+1)/2$ — целое; поэтому либо k четно, либо nk+1 четно, то есть nk нечетно.

Отсюда видно, что ответ на вопрос a) задачи — отрицательный ($k=5$ нечетно, а $n=6$ четно).

Для доказательства достаточно сформулируем теорему в более наглідном виде:

Чтобы nk чисел {1, 2, ..., nk} можно было разставить в таблицу из k строк и n стольцов правильным образом (суммы чисел во всех столбцах одинаковы), необходимого и достаточно, чтобы либо k было четным, либо nk — нечетным.

Пусть k четно. Тогда числа можно разставить в таблицу «змейкой» (рис. 1; для каждой двух последовательных строк сумма чисел в любом столбце одинакова).

Пусть nk нечетно. Расставим «правильно» в трех верхних строках таблицы числа {1, 2, ..., 3n} (оставшиеся числа, начиная с числа 3n+1, можно разставить в таблицу $(k-3) \times n$ змейкой, поскольку $k-3$ четно — рис. 2). Как это сделать при $n=3, 5, 7$, показано на рисунках 3, а—в. Аналогичным образом можно построить таблицу $3 \times n$ для любого нечетного $n=2m+1$ (рис. 4; проверьте, что в нее входит по разу любое число от 1 до $3n=6m+3$).

Легко видеть, что справедливо тривальное обобщение доказанной теоремы: чисles nk чисел {a+1, a+2, a+3, ..., a+nk} можно было разставить в таблицу из k строк и n стольцов правильным образом, необходимого и достаточно, чтобы либо k было четным, либо nk — нечетным.
