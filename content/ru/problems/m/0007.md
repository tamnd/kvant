## Условие

a, b, c — стороны треугольника. Докажите, что

$$\frac{a}{b+c-a} + \frac{b}{c+a-b} + \frac{c}{a+b-c} \geq 3.$$

C. Берколайко

## Решение

** a, b, c — стороны треугольника.

Докажите, что $\frac{a}{b+c-a} + \frac{b}{c+a-b} + \frac{c}{a+b-c} \geq 3$.

Решение. Эта задача имеет довольно много решений. Мы приведем одно из самых коротких. Нам понадобится лишь хорошего известное из школьного курса неравенство
$$\frac{m}{n} + \frac{n}{m} \geq 2,$$
(1)

где $m > 0, n > 0$.

Введем такие обозначения:
$$b + c - a = x,$$
$$c + a - b = y,$$
$$a + b - c = z.$$

Заметим, что
$$x > 0, y > 0, z > 0;$$
(3)
это следует из того, что $a, b, c$ — стороны треугольника, а каждая сторона его меньше суммы двух других (к сожалению, из письм, приспланных в редакцию, видно, что большинство решших задачу даже не задумывались над тем, где они используют то, что $a, b, c$ — стороны треугольника).

Из (2) следует, что
$$a = \frac{y+z}{2}, \quad b = \frac{x+z}{2}, \quad c = \frac{x+y}{2};$$

позному исходное неравенство можно переписать так:
$$\frac{y+z}{2x} + \frac{x+z}{2y} + \frac{x+y}{2z} \geq 3.$$

Преобразуя левую часть (4) и использовать (1) и (3), получим
$$\frac{y+z}{2x} + \frac{x+z}{2y} + \frac{x+y}{2z} =
= \frac{1}{2} \left[ \left( \frac{y}{x} + \frac{x}{y} \right) + \left( \frac{z}{x} + \frac{x}{z} \right) +
\left( \frac{z}{y} + \frac{y}{z} \right) \right] \geq \frac{1}{2} (2 + 2 + 2) = 3,
$$
что и требовалось.

Заметим, что аналогично можно доказать и более общее неравенство:
$$\frac{x_1}{x_2 + x_3 + \dots + x_n - x_1} +
\frac{x_2}{x_3 + x_4 + \dots + x_n + x_1 - x_2} + \dots +
\frac{x_{n-1}}{x_n + x_1 + x_2 + \dots + x_{n-2} - x_{n-1}} +
\frac{x_n}{x_1 + x_2 + \dots + x_{n-1} - x_n} \geq \frac{n}{n-2},$$

где все знаменатель положительных.

В заключение отмечим, что из доказанного неравенства непосредственно следует один геометрический факт. Пусть $R$ — радиус описанной около треугольника, а $r$ — радиус вписанной в него окружности. Хорошо изввести, что
$$R = \frac{abc}{4S}, \quad r = \frac{S}{p},$$
(5)

$$S = \sqrt{p(p-a)(p-b)(p-c)},$$

где $S$ — площадь треугольника, а $p$ — его полуперimetр. Из (2) следует, что
$$p - a = \frac{x}{2},$$
$$p - b = \frac{y}{2},$$
$$p - c = \frac{z}{2}.$$

Теперь, использую (5) и (6), получим
$$\frac{R}{2r} = \frac{abcp}{8S^2} = \frac{abcp}{8p(p-a)(p-b)(p-c)} =
= \frac{abc}{(a+b-c)(b+c-a)(c+a-b)} =
= \frac{(x+y)(y+z)(z+x)}{8xyz} =
= \frac{1}{4} \left[ 1 + \left( \frac{y+z}{2x} + \frac{x+z}{2y} + \frac{x+y}{2z} \right) \right].$$

Заметим, что в круглых скобках правой части последнего равенства стоит левая часть неравенства (4). Воспользовавшись им, получим
$$\frac{R}{2r} \geq 1,$$
то есть $R \geq 2r$.

Итак, радиус описанного около треугольника круга не меньше диаметра вписанного в него кругла. Попробуйте доказать это число геометрических (что значительное труднее).
