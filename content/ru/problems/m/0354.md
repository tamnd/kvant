## Условие

Можно ли расставить числа 1, 2, 3, ..., $4n + 2$ в вершинах и серединах сторона правильно $(2n + 1)$-угольника так, чтобы сумма трех чисел, стоящих в концах и середине каждой стороны, была для всех сторон одинаковой?

Рассмотите в качестве примеров случай $n = 3$, $n = 8$.

С. Т. Берколайко

## Решение

Можно ли рассмотреть числа 1, 2, 3, ..., $4n + 2$ в вершинах и серединах сторон правильно (2n + 1)-уzelника мак, чтобы сумма трех чисел, стоящих в концах и середине каждой стороны, была для всех сторон odинаковой?

Рассмотрим в качестве примеров случай $n = 3, n = 8$,

Рис. 1.

Ответ. Можно.

Приведем один из способов расстановки. В серединах сторон многоугольника поставим по порядку числа от 1 до $2n + 1$. Расставить остальные числа $2n + 2, \dots, 4n + 2$ помогает такое сообщение. Найдем сумму $S$ трех чисел, стоящих в конце и середине каждой стороны. Очевидно, $S = \frac{\Sigma + \Sigma'}{2n + 1}$, где $\Sigma = 1 + 2 + \dots + (4n + 2) = (2n + 1) \times (4n + 3)$ — сумма всех выписанных чисел, $\Sigma' = (2n + 2) + \dots + (4n + 2) = (2n + 1) (3n + 2)$ — сумма чисел, которые нужно расставить в вершинах; поэтому $S = 7n + 5$. Поставим теперь в вершине, обшей для сторон с числами 1 и 2 посредине, число $4n + 2$, а числа $4n + 1, 4n, \dots, 2n + 2$ будем ставить в вершинах через одну, считая вершину с числом $4n + 2$ начальной — см. рисунок 1 (на этом рисунке все точки расположены на одной окружности; черные точки — это «середины», красные — «вершины»). Покажем, что таким образом в каждую вершину будет поставлено нужное число (то, что это будет именно числа $2n + 2$, ..., $4n + 2$, сомненей не вызывает). В самом деле, через $n$ шагов мы первый раз попадем в вершину, соседнюю с начальной, причем в эту вершину будет поставлено число $(4n + 2) - n = 3n + 2$, так что сумма чисел на стороне с единичей посередине оказывает как раз $(3n + 2) + 1 + (4n + 2) = 7n + 5$.
