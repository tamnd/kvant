## Условие

Докажите, что для любых положительных чисел $a, b, c$ выполнены неравенства

$$a + b + c \leq \frac{a^2 + b^2}{2c} + \frac{b^2 + c^2}{2a} + \frac{c^2 + a^2}{2b} \leq \frac{a^3}{bc} + \frac{b^3}{ca} + \frac{c^3}{ab}.$$
