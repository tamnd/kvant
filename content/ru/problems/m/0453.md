## Условие

Дано множество положительных чисел $\{a_1; a_2; ...; a_n\}$. Для каждого его подмножества выпишем сумму входящих в него чисел (расматриваются суммы из одного, двух, ..., $n$ слгаемых). Докажите, что все выписанные числа можно так разбить на $n$ групп, чтобы в каждой группе относение набольшего числа к наименшему не превысило 2.

## Решение

Дано множество положимельных чисел $\{a_1; a_2; \dots, a_n\}$. Для каждого его подмножества выписем сумму входящих в него чисел (расматриваются суммы из однозою, двух, ..., n слааемых). Докажите, что все выписанные числа можно так разбить на n групп, чтобы в каждой группе отношение набольшего числа к наименьшему не превысило 2.

Достаточно указать $n$ отрезков вида $[b_i, 2b_i]$ ($i = 1, 2, \dots, n$), объединение которых содержит все суммы неокторых из данных $n$ чисел: тогда суммы, принадлежные каждому отрезку, образуют группу чисел, удовлетворяющих нужному условиям.

Эти отрезки можно строить по-разному. Приведем самый красивый способ (его указал Д. Берништейн).

Занутерем данные числа в порядке возрастания: $a_1 \leqslant a_2 \leqslant \dots \leqslant a_n$, положим $b_i = (a_1 + a_2 + \dots + a_i)/2$ и докажем, что каждая сумма неокторых из чисел $a_i$ попадает в один из отрезков $[b_i, 2b_i]$.

Ясно, что наименьшая «сумма» $a_1 \in [b_1, 2b_1]$, так как $2b_1 = a_1$, а наибольшая — $(a_1 + \dots + a_n) \in [b_n, 2b_n]$, так как $2b_n = a_1 + \dots + a_n$. Осталось доказать, что невозможен случай, когда неокторая сумма $s$ лежит между $2b_k$ и $b_{k+1}$. Пусть

$$s > 2b_k = a_1 + a_2 + \dots + a_k.$$

(1)

Тогда $s$ содержит неокторое $a_i \geqslant a_{k+1}$, то есть

$$s \geqslant a_{k+1}.$$

(2)

Сложив (1) и (2), получим $2s \geqslant a_1 + \dots + a_k + a_{k+1}$, то есть $s \geqslant b_{k+1}$. Значит, $s$ не может лежать между $2b_k$ и $b_{k+1}$.
