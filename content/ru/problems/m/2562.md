## Условие

Каждой точке A плоскости сопоставлено вещественное число f ( A ). Известно, что если M – точка пересечения медиан треугольника ABC, то f ( M ) = = f ( A ) + f ( B ) + f ( C ). Докажите, что f ( A ) = 0 для всех точек A. А.Голованов
