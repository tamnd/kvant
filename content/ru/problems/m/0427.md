## Условие

a) Докажите, что существует нечетное число $n$, для которых ни при каком четном $k$ ни одно из чисел бесконечной последовательности
$$k^k + 1, k^{k^k} + 1, k^{k^{k^k}} + 1, \dots$$
не делится на $n$.

b) Докажите, что для каждой натурального $n$ существует такое натуральное число $k$, что каждый из членов бесконечной последовательности
$$k + 1, k^k + 1, k^{k^k} + 1, k^{k^{k^k}} + 1, \dots$$
делится на $n$.

C. Лавренченко, 9 класс
