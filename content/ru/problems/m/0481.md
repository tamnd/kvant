## Условие

В последовательности натуральных чисел $a_1, a_2, a_3, \dots$ каждый член $a_{k+1}$ равен сумме квадратов цифр в десятичной записи числа $a_k(k \ge 1)$. Докажите, что при любом $a_1$ в этой последовательности встречается число 1 или число 89.

В. Панфилов

## Решение

В последовательности натуральных чисел $a_1, a_2, a_3, \dots$ каждый член $a_{k+1}$ равен сумме квадратов числа $b$ десятичной записи числа $a_k (k \geq 1)$. Доказим, что при любом $a_1$ в этой последовательности остремится число 1 или число 89.**

Ясно, что сумма квадратов цифр числа $x$ — обозначим ее $f(x)$ — для достаточно большого $x$ значительно меньше самого числа $x$. Так, если $x$ — четврехначное число, то есть $10^3 \leq x < 10^4$, то $f(x) \leq 4.9^2 = 364 < 10^3 \leq x$. Вообше, если $10^{n-1} \leq x < 10^n$ и $n > 3$, то $f(x) \leq 81n < 10^{n-1}$. (Последнее неравенство легко доказать по индукции: $81n < 10^{n-1} \Rightarrow 81 (n + 1) = 81n + 81 < 10^{n-1} + 81 < 10^n$.) Доказем, что и для любого трехначного $x$ также $f(x) < x$. Если первая цифра числа $x$ равна $p > 1$, то $f(x) < p^2 + 2 \cdot 81 = 162 + p^2 < 100p$ (в этом нетрудно убедиться для каждой $p = 2, 3, 4, \dots, 9$). Если первая цифра $x$ равна 1, а вторая $q$, то $f(x) \leq 1 + q^2 + 81 < 100 + 10q \leq x$ для любого $q = 1, 2, \dots, 9$.

Таким образом, для любого натурального числа $a_1, a_2, a_3, \dots$, где $a_{n+1} = f(a_n)$, (*)

встретися число, не превосходящие 99. Для двузначных и однозначных чисел приходит изучать соответствующие им последовательности (*) перебором. В вычислениях помогает табличка, у которой на пересечении $i$-й строки и $j$-го столбца стоит сумма $i^2 + j^2$ — эта таблица помещена выше. Для любого $x \leq 99$ будет $f(x) \leq 162$; таким образом, множество $X = \{1, 2, \dots, 162\}$ отображается в себя: $f(x) \leq 162$ для всех $x \leq 162$.

Для аналогичной задачи, в котором вместо суммы квадратов цифр резьет просто о сумме цифр, получается более простой результат: после нескольких применений отображения «$x \rightarrow$ сумма цифр $x$» из чисел $a_1$, кратных девятки, получится 9, а из любого числа $a_1$, не кратного девятки, получится остаток от деления $a_1$ на 9. Таким образом, здесь имеется девять неподвижных точек 1, 2, ..., 9, и по $a_1$ сразу можно сказать, в какую из них попадем.

Разумеется, можно вместе $f$ брать и другие функции скажем, сумму кубов, или четырех стеленей цифр, и т. д. Для этих отображений также можно доказать, что $f(x) < x$ при достаточно большом $x$, а значит, последовательности вида (*) рано или поздно входят в один из конечного числа «циклов» — в частности, быть может, попадают в «цикл длины 1», то есть в неподвижную точку. Хотя любители цифровых дисковинок, возможно, получают удовлетворение, наткнувшись на такие неподвижные точки, как $1^3 + 5^3 + 3^3 = 153$ (В. Панфилов) или $1^4 + 6^4 + 3^4 + 4^4 = 1634$ (Г. Гуревич), но искать здесь все циклы — дело довольно утомительное, даже если под рукой есть вычислительная машина.

**M483**). а) Доказите, что отношение квадрата радиуса вписанной окружности пря-модульного треугольника к сумме квадратов длины медиан, проведенных из острых углов, не превыходит 1/20. б) Надите наибольшее значение, которое может принимать это отношение.

Пусть $a$ и $b$ — длины катетов треугольника, $c = \sqrt{a^2 + b^2}$ — длина гипotenузы, $r$ — радиус вписанной окружности. Поскольку сумма квадратов длины медиан, о которой говорится в условия, равна

$$\left(\frac{a}{2}\right)^2 + b^2 + \left(\frac{b}{2}\right)^2 + a^2 = \frac{5}{4} (a^2 + b^2) = \frac{5}{4} c^2,$$

в задаче требуется оценить отношение $4r^2/5c^2$. Заметим, что

$$r = \frac{ab}{a+b+c} = \frac{ab}{a+b+\sqrt{a^2+b^2}} < \frac{a^2+b^2}{2\sqrt{a^2+b^2}} = \frac{c}{4},$$

поскольку $ab \leq (a^2+b^2)/2$ и $a+b > \sqrt{a^2+b^2}$. Отсюда получаем результат a):

$$\frac{4r^2}{5c^2} < \frac{4}{5\cdot 4^2} = \frac{1}{20}.$$

Более точная оценка (в ней использовется неравенства $a + b \geq 2\sqrt{ab}$ и $c^2 = a^2 + b^2 \geq 2ab$, обращающиеся в равенства при $a = b$):

$$\frac{r^2}{c^2} = \frac{a^2b^2}{(a+b+\sqrt{a^2+b^2})^2c^2} \leq \frac{ab}{2(2\sqrt{ab}+\sqrt{2ab})^2} = \frac{1}{4(1+\sqrt{2})^2},$$

откуда получаем результат 6):

$$\frac{4r^2}{5c^2} \leq \frac{1}{5(3+2\sqrt{2})} = \frac{3-2\sqrt{2}}{5}$$

(при $a = b$ получаем равенство, то есть оценка — наилучшая).

Эта задача допускает и другие решения, использующие геометрические сообщения. Приведем два решения.

1°. Если продолжить диагональ квадратика на рисунке 4 до пересечения с гипотенузой, мы получим биссертису прямоугольного угла; обозначим ее длину через $l$. Поэтому $r + r\sqrt{2} \leq l$. Но биссертиса в любом треугольнике расположена между высотой $h$ и медианой, длина которого в прямогольном треугольнике с гипотенузой длины $c$ равна $c/2$. Отсюда $r(1 + \sqrt{2}) \leq c/2$, откуда получаем результат.

2°. Зафиксируем отрезок $AB$ длины $c$. Пусть $C$ — любая точка полукругности с диаметром $[AB]$ (тогда $ACB = 90^\circ$) и $M$ — центр вписанной окружности треугольника $ABC$. Поискольку $AMB = 135^\circ$, точки $M$ лежат на дуге в $90^\circ$ с конZAМИ $A$, $B$, а поэтому расстояние от $M$ до прямой $AB$ (радиус $r$ вписанной окружности) будет набольшим, когда $M$ попадает в середину этой дуги, т. е. когда прямой треугольник $ABC$ — равноведренный.
