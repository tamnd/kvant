## Условие

а) Из произвольной точки $M$ внутри равностороннего треугольника опущены перпендикуляры $MK_1, MK_2, MK_3$ на его стороны. Докажите, что сумма векторов $\vec{MK}_1 + \vec{MK}_2 + \vec{MK}_3$ равна $\frac{3}{2} \cdot \vec{MO}$, где $O$ — центр треугольника.

6) Из произвольной точки $M$ опущены perпендикуляры $MK_1, \ldots, MK_n$ на все стороны равильно $n$-угольника (или их продолжения). Докажите, что
$$\vec{MK}_1 + \ldots + \vec{MK}_n = \frac{n}{2} \vec{MO},$$
где $O$ — центр $n$-угольника.

в) Из произвольной точки $M$ внутри равностороннего треугольника опущены perпендикуляры $MK_1, MK_2, MK_3, MK_4$ на его грани. Докажите, что
$$\vec{MK}_1 + \vec{MK}_2 + \vec{MK}_3 + \vec{MK}_4 = \frac{4}{3} \vec{MO},$$
где $O$ — центр треугольника.

## Решение

a) Из произвольной точки $M$ внутри равностороннего треугольника опущены перпендикуляры $MK_1$, $MK_2$, $MK_3$ на его стороны. Доказите что сумма векторов $MK_1 + MK_2 + MK_3$ равна $\frac{3}{2} \vec{M}O$, где $O$ — центр треугольника.

6) Из произвольной точки $M$ опущены перпендикуляры $MK_1$, ..., $MK_n$ на все стороны правильно по-уzelвика или их продолжения. Доказите, что

$$\vec{MK}_1 + \dots + \vec{MK}_n = \frac{n}{2} \vec{M}O,$$

его $O$ — центр $n$-уzelвика.

8) Из произвольной точки $M$ внутри правильно терраэдра опущены перпендикуляры $MK_1$, $MK_2$, $MK_3$, $MK_4$ на его грани, Доказите, что

$$\vec{MK}_1 + \vec{MK}_2 + \vec{MK}_3 + \vec{MK}_4 = \frac{4}{3} \vec{M}O,$$

его $O$ — центр терраэдра.

Рис. 1.

Рис. 2.

a) Проведем через точку $M$ прямые, параллельные сторонам треугольника и обозначим точки пересечения этих прямых со стороны треугольника, как показано на рисунке 1.

Ясно, что $2\vec{MK}_1 = \vec{MA}_1 + \vec{MA}_2$, $2\vec{MK}_2 = \vec{MB}_1 + \vec{MB}_2$, $2\vec{MK}_3 = \vec{MC}_1 + \vec{MC}_2$ и в то же время, $\vec{MC}_1 + \vec{MB}_2 = \vec{MA}$; $\vec{MC}_2 + \vec{MA}_1 = \vec{MB}$ и $\vec{MA}_2 + \vec{MB}_1 = \vec{MC}$. Позному

$$2(\vec{MK}_1 + \vec{MK}_2 + \vec{MK}_3) = \vec{MA} + \vec{MB} + \vec{MC} = 3\vec{MO} + \vec{OA} + \vec{OB} + \vec{OC}.$$

Но, очевидно, $\vec{OA} + \vec{OB} + \vec{OC} = \vec{0}$, следовательно, $2(\vec{MK}_1 + \vec{MK}_2 + \vec{MK}_3) = 3\vec{MO}$, что и требовалось.

6) Доказем сначала, что если $O$ — центр правильно многоугольника $A_1...A_n$, то $\vec{OA}_1 + \dots + \vec{OA}_n = \vec{0}$.

В самом деле, при повороте на $\frac{360^\circ}{n}$ вокруг $O$ вершина $A_1$, перейдет в $A_2$, $A_2$ — в $A_3$, ..., $A_n$ — в $A_1$, а вектор $\vec{s} = \vec{OA}_1 + \vec{OA}_2 + \dots + \vec{OA}_n$ — в $\vec{OA}_2 + \vec{OA}_3 + \dots + \vec{OA}_n + \vec{OA}_1 = \vec{s}$, то есть не изменится. Позному $\vec{s} = \vec{0}$.

Опустим перпендикуляры $OP_1$, ..., $OP_n$ на стороны данного правильно многоугольника $(OP_i \parallel MK_i)$, затем опустим из точки $M$ перпендикуляры $MB_i$ на прямые $OP_i$ (при четном $n$ прямые $OP_i$ и $OP_{i+n/2}$ $i=1, 2, \dots, n/2$, совпадают и $B_i = B_{i+n/2}$; см. рис. 2 для $n=6$). Поскольку $\vec{MK}_i = \vec{B}_iP_i = \vec{B}_iO + \vec{OP}_i$ и $P_1P_2...P_n$ — правильно $n$-уzelвика с центром $O$,

$$\vec{MK}_1 + \vec{MK}_2 + \dots + \vec{MK}_n = (\vec{B}_1O + \vec{B}_2O + \dots + \vec{B}_nO) + (\vec{OP}_1 + \vec{OP}_2 + \dots + \vec{OP}_n) = \vec{B}_1O + \vec{B}_2O + \dots + \vec{B}_nO.$$

(1)

Доказем, что точки $B_1$, ..., $B_n$ лежат на окружности с диаметром $MO$ (ибо $\vec{MB}_iO = 90^\circ$), поэтому достаточно доказать, что угловая вершина любой из дуг, на которой эта окружность разбиается точками $B_1$, ..., $B_n$, равна $360^\circ/n$. Пусть $B_iB_j$ — одна из этих дуг и она не содержит точку $O$. Тогда $\angle B_iOB_j$ есть один из $2m$ равных углов, на которые разбиается плоскость $m$ прямых $OB_i = OP_i$ (см. рис. 3, где $n=m=5$, $i=2$, $j=4$). Следовательно, $B_iOB_j = 180^\circ/m$ и $B_iB_j = 360^\circ/m$. Дуга, содержащая точку $O$, также имеет величины $360^\circ - (m-1) \cdot 360^\circ/m = 360^\circ/m$.

Из доказанного вытекает, что $\vec{O}_1B_1 + \dots + \vec{O}_1B_n = \vec{0}$, и согласно (1)

$$\vec{MK}_1 + \dots + \vec{MK}_n = \vec{B}_1O_1 + \vec{B}_2O_1 + \dots + \vec{B}_nO_1 + n\vec{O}_1O = \frac{n}{2} \vec{MO}.$$

Отметим, что эту задачу можно решить также методом пункта $a$.

в) Достаточно доказать, что проекции векторов $\vec{MK}_1 + \dots + \vec{MK}_n$ и $\frac{4}{3} \vec{MO}$ на какие-то две пересекающие плоскости совпадают. (Действительно, отсюда следует,

что две проекции разности $\vec{d}$ этих векторов равны нульевектору, то есть вектор $\vec{d}$ перепределилуран одновременно двум пересекающим плоскостям, а значит, $\vec{d} = 0$).

Эти плоскости можно выбрать так, чтобы доказательство свелось к плоскому случанию — задаче a). Именно, проведем через точку $M$ плоскость $p$, перепределилуран, скажем, $\vec{MK}_4$, и проектируем на нее векторы $\vec{MK}_i$, $i=1, 2, 3$ (рис. 4). Каждый из них образует с плоскостью $p$ угол $\gamma$, равный углу между высотой и боковой грани правильно тетраэдра $(\cos^2 \gamma = \frac{8}{9})$, поэтому проекция вектора $\vec{MK}_i$ равна $\vec{MH}_i = \frac{8}{9} \vec{MQ}_i$, где $Q_i$ — проекция точки $M$ на соответствующую сторону треугольника, получающейся в сечени тетраэдра плоскостью $p$. Пусть $O'$ — центр этого треугольника, тогда, согласно a),

$$\vec{MH}_1 + \vec{MH}_2 + \vec{MH}_3 = \frac{8}{9} (\vec{MP}_1 + \vec{MP}_2 + \vec{MP}_3) =$$

$$= \frac{8}{9} \cdot \frac{3}{2} \vec{MO}' = \frac{4}{3} \vec{MO}'.$$

Остается заметить, что левая часть этого равенства есть проекция суммы $\vec{MK}_1 + \ldots + \vec{MK}_4$ на плоскость $p$ (proекция суммы векторов равна сумме их проекций), а правая — проекция вектора $\frac{4}{3} \vec{MO}$. Это же рассужждение годится и для плоскостей, параллельных другим гранам тетраэдра.

Попробуйте решить задачу a) аналогичным способом, сведя двумерный случай к одномерному с помощью проекции.

Наметим еще одно решение задачи b) (которое можно приспособить и к задачам a) и 6)). Рассмотрим вектор разности $\vec{d} = (\vec{MK}_1 + \vec{MK}_2 + \vec{MK}_3 + \vec{MK}_4) - \frac{4}{3} \vec{MO}$ как функцию от вектора $\vec{a} = \vec{MO}$. Легко проверить, что утверждение задачи справедливо для вершин $A_1, A_2, A_3, A_4$ тетраэдра, значит, $\vec{d}(A_iO) = 0$. Кроме того, $\vec{d}(\vec{a})$ — линейная векторная функция, то есть $\vec{d}(\vec{a} + \vec{b}) = \vec{d}(\vec{a}) + \vec{d}(\vec{b})$ и $\vec{d}(k\vec{a}) = kd(\vec{a})$. (Действительно, сумма векторов $\vec{MK}_i$ равна сумме проекций вектора $\vec{MO}$ на четыре прямы, перепределилуран сторонам $n$-угольника. Но легко видеть, что проекция вектора на прямую является линейной функцией этого вектора.) Отсюда вытекает, что $\vec{d}(\vec{a}) = 0$ для любого вектора $\vec{a}$, поскольку его всегда можно представить в виде $k_1\vec{A}_1O + k_2\vec{A}_2O + k_3\vec{A}_3O$.
