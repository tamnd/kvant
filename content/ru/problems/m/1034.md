## Условие

Прямоугольная шоколада разбиита продольными и поперечными углублениями на 50 квадратных долек. Двое играют в такую игру. Начинающий размывывает шоколада по некоторому углублению на две прямой углубления частies. Затем играющие по очереди ломают одну из получившихся частей по некоторому углублению на две. Тот, кто первый отломит квадратную долку (без углублений)
a) проигрывает;
b) выигравает.

Кто из играющих может обеспечить себе выигрыш — начинающий или его партнер?

C. B. Фомин

## Решение

Прямоугольная шоколада разбита продольными и поперечными углублениями на 50 квадратных делек. Двое из разгара в такую цетт. Начинающий размывает шоколаду по неокторому углублению на две прямоугольные части. Затем израющение по очереди ломатот odну из получившихся частей по неокторому углублению на две. Тот, кто перым отломит квадратную дольку (без углубления), a) проррывает, b) выгрывает. Кто из израющих может обеспечить себе выгрышии — начнающий или его партнер?

Ответ: в обих вариантах игры побеждает начинающий. Это справедливо и для любой шоколада из mn долек (размером m×n), где mn четно (за исключением случая шоколада 2×n с нечетным n в вариante 6) — здесь ответ зависит от n.) Мы рассмотрим сразу общий случай. Интересно, что выигрышные стратегии в «противоположных» вариантах a) и 6) почти совпадают.

a) Стратегия, обеспечивающая выигрышная начинашему, такова. Хотя бы одно из чисел m и n четно — пусть это будет m(m=2k). Первым ходом начинающий размывает шоколаду на две одинаковые половины (по n×k долек). Затем каждый ход второго он dysplует на другой половине шоколадики. Таким образом, после каждого ход первого игре обе половины будут разломаны совершенно одинаковым образом. Ясно, что при этом первый не отломит дольку 1×1 равные, чем это сделает второй.

6) Здесь при четном m>2 и n>1 начинающий может использовать ту же «симметричную» стратегию до тех пор, пока второй не отломит полоску шрипиной 1; первый тут же отломивает он нее дольку 1×1 и выгрывает.

При публикации задачи мы по недоразумению не помещили рядом с условиям рисуок, изображаюший шоколаду из 5×10 долек; поэтому строго говоря, нужно рассмотреть еще случай шоколадики 2×25 (хотя, по видимому, в жизни таких не было). В вариante 6) игры «симметричная» стратегия для шоколадики 2×n не годится — отличать полоску шрипиной 1 нельзя (это немедленно ведет к проррышшу), так что шоколаду можно ломать только «поперек». Возникает такая игра в «разбиение». На доске написано вначале число n; затем при каждом ходе одно из чисел страется и пишут неокторы два натуральных числа, в сумме дюшных стертое. Проигрывает тот, кто вынужден написать 1 (то есть проррышная позиция — это набор чисел 2 и 3). Вопрос о том, кто выгрывает в подобных играх, оказывается далеко не простым; об интересной теории, позволяющей найти ответ без большого перебора, будет расссказано в одном из номеров

⟦folio 40⟧

«Кванта» в будущеем году. Пока сообщим лишь ответ: при $n=25$ выигрывает начнающий (один из правильных первых ходов: $25=13+12$).

Ответ для нечетного $mn$ в общем случае нам неизвестен ни для варианта а), ни для варианта 6) игры.
