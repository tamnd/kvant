## Условие

В каждую клетку таблицы n ¥ n Мортеза поместил некоторую функцию [ 0; 1 ] Æ [ 0; 1 ] (т.е. всего $n^{2}$ функций, каждая из которых определена на отрезке [ 0; 1 ] и принимает значения из отрезка [ 0; 1 ] ). Павел хочет поместить слева от каждой строки и снизу под каждым столбцом еще по одной функции [ 0; 1 ] Æ [ 0; 1 ] (т.е. еще 2n функций) так, чтобы для любой строки и любого столбца было выполнено следующее условие: если под этим столбцом помещена функция f, слева от строки помещена функция g, а в пересечении этого столбца и этой строки помещена функция h, то для любого x Œ [ 0; 1 ] верно равенство h ( x ) = f ( g ( x ) ). Докажите, что Павел всегда сможет осуществить свой замысел. М.Сагафиян (Иран)
