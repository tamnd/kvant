## Условие

Диагональ $d$ прямогольного параллелепипеда образует с его ребрами $a, b$ и $c$ углы $\alpha, \beta$ и $\gamma$. Докажите, что $\alpha + \beta + \gamma$ меньше $π$.
М. Л. Гервер

## Решение

** *Диагональ d прямоугольного параллелепипеда образует с его ребрами a, b и c углы* $\alpha$, $\beta$ *и* $\gamma$. *Докажите, что* $\alpha + \beta + \gamma$ *меньше* $\pi$.

⟦figure⟧
Рис. 13.

⟦column⟧

Приведем решение, которое прислал *Андрей Вятчин* (г. Павлово Горьковской области). Расположим три равных параллелепипеда так, как показано на рисунке 13. Тогда $\sphericalangle BOC = 2\alpha$, $\sphericalangle AOC = 2\beta$, $\sphericalangle AOB = 2\gamma$. Точка $O$ не лежит в плоскости, проходящей через точки $A$, $B$, $C$ (проверьте). Значит, $2\alpha + 2\beta + 2\gamma < 2\pi$ (по теореме о сумме плоских углов трехгранного угла), то есть $\alpha + \beta + \gamma < \pi$.

Большинство читателей, приславших верные решения, свело задачу к проверке неравенства $\sin(\alpha + \beta + \gamma) > 0$.

В заключение приведем две задачи — проверьте, что они эквивалентны задаче М265.

1. Для любого $\triangle ABC$ можно вычислить такую сумму:
$$S = \cos^2 A + \cos^2 B + \cos^2 C.$$
Докажите, что $S = 1$ для прямоугольных треугольников, $S < 1$ для остроугольных и $S > 1$ для тупоугольных треугольников.

2. Если $0 < x < \dfrac{\pi}{2}$, $0 < y < \dfrac{\pi}{2}$ и $\sin^2 x + \sin^2 y < 1$, то $\sin^2 x + \sin^2 y < \sin^2 (x+y)$.

*М. Л. Гервер*
