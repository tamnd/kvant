## Условие

Последовательность $r_1, r_2, r_3, \dots$ определяется условиями
$$r_1 = 2, r_{n+1} = r_1 r_2 \dots r_n + 1,$$
так что $r_2 = 3, r_3 = 7, r_4 = 43, \dots$
a) Докажите, что при любом $n$
$$\frac{1}{r_1} + \frac{1}{r_2} + \dots + \frac{1}{r_n} < 1.$$

6)* Пусть $n$ натуральных чисел, что сумма их обратных величины меньше 1. Докажите, что эта сумма не больше
$$\frac{1}{r_1} + \frac{1}{r_2} + \dots + \frac{1}{r_n}.$$

Известные нам доказательства опираются на такую лемму, которая мы предлагаем доказать читателем.

b)* Среди всех наборов $(a_1, a_2, \dots, a_n)$ из $n$ вещественных чисел, удовлетворяющих условиям:
$$\alpha_1 \geqslant \alpha_2 \geqslant \dots \geqslant \alpha_n \geqslant 0, \alpha_1 + \alpha_2 + \dots + \alpha_n = 1,$$
$$\alpha_1 \alpha_2 \dots \alpha_k \leqslant \alpha_{k+1} + \alpha_{k+2} + \dots + \alpha_n (k = 1, 2, \dots, n-1),$$

$$a_k = 1/r_k \text{ для } k=1, 2, \dots, n-1, a_n = 1/(r_n-1).$$
