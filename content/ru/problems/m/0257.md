## Условие

При каких натуральных $n \geq 2$ неравенство
$$x_1^2 + x_2^2 + \ldots + x_n^2 \geq p(x_1 x_2 + x_2 x_3 + \ldots + x_{n-1} x_n)$$
выполняется для любых действительных чисел $x_1, x_2, \ldots, x_n$, если $p = 1$; 6) $p = \frac{4}{3}$; 8) $p = \frac{6}{5}$?

Нeyer Конг Квил (Ханой, ДРВ)

## Решение

При каких намуральных n ≥ 2 неравенство

$$x_1^2 + x_2^2 + \dots + x_n^2 \geq p \left( x_1 x_2 + x_2 x_3 + \dots + x_{n-1} x_n \right)$$

выполняется для любых действительных чисел x1, x2, ..., xn, если a) p = 1; 6) p = 4/3; b) p = 6/5?

Ответ. a) при всех n; 6) при n ≤ 3; b) при n ≤ 4.

Рис. 1.

⟦folio 47⟧

Рис. 2. Чем ближе $p$ к единице, тем ближе расположена гипербола к окружности и тем больше ступеней имеет лестница.

Заметим, что если положить в неравенстве $x_1^2 + x_2^2 + \dots + x_n^2 - 1 + x_n^2 - px_1x_2 - px_2x_3 - \dots - px_n - 1x_n \geq 0$ (*)

несколько последних переменных $x_k, x_{k+1}, \dots, x_n$ равны нулю, то получится аналогичное неравенство, соответствующое меншему $n$. Отсюда следует, что если (*) выполняется (для всех $x_1, x_2, \dots, x_n$) при некотором $n$, то оно выполняется и при меньших $n$. Таким образом, для каждого фиксированного $p$ существует такое целое $N(p) \geq 2$, что (*) выполнен при $n < N(p)$ и не выполнен (для некоторых $x_1, x_2, \dots, x_n$) при $n \geq N(p)$; возможно также, что (*) выполнен при всех $n$ (в этом случае можно считать, что $N(p) = \infty$).

Последний случай имеет место при $p = 1$. Действительно, в этом случае (*) эквивалентно оченьному неравенству

$$x_1^2 + (x_1 - x_2)^2 + (x_2 - x_3)^2 + \dots + (x_{n-1} - x_n)^2 + x_n^2 \geq 0.$$

Пусть $p = \frac{4}{3}$. Тогда при $n = 3$ (*) эквивалентно неравенству

$$(3x_1 - 2x_2)^2 + x_2^2 + (2x_2 - 3x_3)^2 \geq 0,$$

а при $n = 4$ неравенство (*) нарушается, например, когда $x_1 = x_4 = 2, x_2 = x_3 = 3$ (при $n = 4$ неравенство (*) эквивалентно такому:

$$(3x_1 - 2x_2)^2 - x_2^2 + 6(x_2 - x_3)^2 - x_3^2 + (2x_3 - 3x_4)^2 \geq 0;$$

отсюда и возник наш пример).

Пусть $p = \frac{4}{5}$. Тогда при $n = 4$ (*) эквивалентно неравенству

$$(5x_1 - 3x_2)^2 + x_2^2 + 15(x_2 - x_3)^2 + x_3^2 + (3x_3 - 5x_4)^2 \geq 0,$$

а при $n = 5$ оно неравенства, например, когда $x_1 = x_5 = 9, x_2 = x_4 = 15, x_3 = 16$ (этот пример возникнет естественным образом, если преобразовать (*) к виду

$$16(5x_1 - 3x_2)^2 + (16x_2 - 15x_3)^2 - 50x_3^2 + (15x_3 - 16x_4)^2 + 16(3x_4 - 5x_5)^2 \geq 0).$$

Обсуждение теперь, как ответить на вопрос задачи при произвольном $p > 0$. Легко показать, что $N(p) = \infty$ при любом $p \in [0, 1]$ и $N(p)$ конечно при каждом $p > 1$, причем $N(p) = 2$ при $p > 2$. В принципие при каждом $p > 1$ можно найти $N(p)$, преобразовав левую часть (*) к сумме квадратов (причем заботиться о симметричной формуле и о том, чтобы коэффициенты получались целыми или рациональными, вовсе не обязательно; выше мы сделали это для того, чтобы записать решение покороче). Например, можно привести (*) к виду

$$(s_1x_1 - t_1x_2)^2 + (s_2x_2 - t_2x_3)^2 + \dots + (s_{n-1}x_{n-1} - t_{n-1}x_n)^2 + r_nx_n^2,$$

последовательно полагая

$$t_k = p/2s_k, s_{k+1} = \sqrt{1 - t_k^2}$$

($s_1 = 1, k = 1, 2, \dots$). Тогда $r_n = s_n^2 \geq 0$ при $n < N(p)$ и $r_n < 0$ при $n = N(p)$. Таким образом, $N(p) - 1$ (набольшее $n$, при котором (*) еще выполняется) равно числу ступеней «лестницы», заключенной между графиками $s^2 + t^2 = 1$, $st = p/2$ и начинающейся в точке $s = 1$, $t = 0$, (рис. 2). Пусть $p_k$ значение $p$, при котором лестница симметрина относительно биссерриссы $s = t$ (заканчивается в точке $s = 0$, $t = 1$) и содержит $k$ ступеней; ясно, что последовательность $p_1 = 2 > p_2 > p_3 > \dots$ стремится к 1 и $N(p) = k + 1$ при $p_{k-1} \geq p > p_k$.

Нетрудно доказать, что $p_2 = \sqrt{2}$, но следуетшие $p_k$ находится уже из громоздких уравнений, связанных к алгебраическим уравнением высокой ступеней.
