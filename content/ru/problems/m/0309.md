## Условие

a) При каких $n$ многочлен $x^{2n} + x + 1$ делится на $x^2 + x + 1$?
6) При каких $n$ число
$10 \dots 010 \dots 01$
делится на 37?

В. Г. Шлейфер

## Решение

a) При каких $n$ многочлен $x^{2n} + x^n + 1$ делится на $x^2 + x + 1$?**

б) При каких $n$ число

$$1 \underbrace{0 \dots 0}_{n} \underbrace{1 \dots 0}_{n}$$

делится на 37?

a) Рассмотрим три случая, соответствующие различным остаткам от деления $n$ на 3.

1°. Пусть $n=3k$; тогда

$$x^{6k} + x^{3k} + 1 = (x^{6k} - 1) + (x^{3k} - 1) + 3 =$$
$$= (x^3 - 1)(x^{6k} - 3 + x^{6k} - 6 + \dots + 1) +$$
$$+ (x^3 - 1)(x^{3k} - 3 + x^{3k} - 6 + \dots + 1) + 3 =$$
$$= (x^2 + x + 1) \cdot Q(x) + 3,$$

где $Q(x) = (x - 1)[(x^{6k} - 3 + x^{6k} - 6 + \dots + 1) + (x^{3k} - 3 + \dots + 1)]$.

Следовательно, если $n=3k$, то многочлен $x^{2n} + x^n + 1$ при делении на $x^2 + x + 1$ дает в остатке 3.

2°. Пусть $n=3k + 1$. Имеем

$$x^{6k + 2} + x^{3k + 1} + 1 = (x^{6k + 2} - x^2) + (x^{3k + 1} - x) +$$
$$+ (x^2 + x + 1) = x^2(x^{6k} - 1) + x(x^{3k} - 1) + (x^2 + x + 1)$$

В 1° мы показали, что многочлены $(x^{6k} - 1)$ и $(x^{3k} - 1)$ делятся на $(x^3 - 1)$, следовательно, и на $(x^2 + x + 1)$; поэтому при $n=3k + 1$ многочлен $x^{2n} + x^n + 1$ делится на $x^2 + x + 1$.

3°. Пусть $n=3k + 2$. Тогда

$$x^{6k + 4} + x^{3k + 2} + 1 = x^1(x^{6k} - 1) + x^2(x^{3k} - 1) + x^4 + x^2 +$$
$$+ 1 = x^4(x^{6k} - 1) + x^2(x^{3k} - 1) + x^3 - 1 + (x^2 + x + 1) = (x^2 + x + 1)[(x - 1)R(x) + 1],$$

где $R(x) = x^4(x^{6k} - 3 + \dots + 1) + x^2(x^{3k} - 3 + \dots + 1) + x$, и многочлен $x^{2n} + x^n + 1$ снова делится на $x^2 + x + 1$.

*) Аналогично решена эта задача в книге Полина и Сете «Задачи и теоремы из анализа».

Итак, ответ в задаче a) таков:
многочлен $x^{2n} + x^n + 1$ делится на $x^2 + x + 1$, если $n$ не кратно трех.

6) При решении этой задачи можно воспользоваться результатом пункта a), поскольку все многочлены, получающие при делении — частиные и остатки — имеют целые коэффициенты. Действительно, при $x = 10$ мы получим соответствующее
$$x^2 + x + 1 = 111, x^{2(n+1)} + x^{(n+1)} + 1 = 1 \underbrace{0 \ldots 0}_{n} \underbrace{1 \ldots 0}_{n}.$$
С другой стороны, $10^{2m} + 10^m + 1$ делится на 3 при всех $m$, и вопрос о том, делится ли $10^{2m} + 10^m + 1$ на 37, эквивалентен вопросу о делимости $10^{2m} + 10^m + 1$ на 37.3 = 111. Ответ в этой задаче такой: число $\underbrace{10 \ldots 0}_{n} \underbrace{10 \ldots 0}_{n}$ делится на 37, если $n$ кратно 3 или если $n$ при делении на 3 дает остаток 1.
