## Условие

a) Последовательность $a_0, a_1, a_2, \dots$ задана соотношениями $a_0=0, a_n=P(a_{n-1}), n=1, 2, \dots$, где $P(x)$ — многочлен с целыми коэффициентами, $P(x)>0$ при $x\geq 0$. Докажите, что для любых натуральных $m$ и $k$

$$\text{НОД}(a_m, a_k)=a_{\text{НОД}(m, k)}$$

b) Докажите аналогичное утверждение для последовательности Фибоначчи $a_0=0, a_1=1, a_2=1, a_3=2, \dots$, задаваемой условия $a_{n+1}=a_n+a_{n-1}, n=1, 2, \dots$.

B. Ф. Лев

## Решение

a) Последовательность a₀, a₁, a₂, ... задана соответствия Фибоначчи a₀=0, a₁=1, a₂=1, a₃=2, ..., задаваемой условия: aₙ+1=aₙ+aₙ-1, n=1,2,...

б) Доказите аналогичное утверждение для последовательности Фибоначчи a₀=0, a₁=1, a₂=1, a₃=2, ..., задаваемой условия: aₙ+1=aₙ+aₙ-1, n=1,2,...

Докажем общее утверждение: если последовательность a₀=0, a₁, a₂, ... целых чисел такова, что

НОД(aₘ, aₖ)=НОД(aₘ-k, aₖ) (1)

для любых m>k≥1, то

НОД(aₘ, aₖ)=aₖ, (2)

где d=НОД(m, k).

В самом деле, для любой пары начальных значений m, k повторение операции

(m, k)→(m-k, m)

(из большого числа пары вычитается меньше) приводит к пале (d, 0), где d=НОД(m, k); это вариант алгоритма Евклида для отыскания наиболее общего делителя чисел m, n, изложенный в учебнике информацией для 9 класса (объчно алгоритм Евклида называют его «сокращенный» вид, состоящий из последовательности делений с остатком.

Таким образом, из равенств (1) следует, что

НОД(aₘ, aₖ)=НОД(aₘ, a₀)=НОД(aₘ, 0)=aₖ

— это и есть (2).
