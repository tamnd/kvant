## Условие

Докажите, что при любом значении $x$, для которого права часть имеет смысл, выполены равенства
$$\frac{tg x + tg \left(x + \frac{\pi}{3}\right) + tg \left(x + \frac{2\pi}{3}\right)}{tg x \cdot tg \left(x + \frac{\pi}{3}\right) \cdot tg \left(x + \frac{2\pi}{3}\right)} = 3;$$
$$\frac{tg x + tg \left(x + \frac{\pi}{n}\right) + \dots + tg \left(x + \frac{(n-1)\pi}{n}\right)}{tg x \cdot tg \left(x + \frac{\pi}{n}\right) \cdot \dots \cdot tg \left(x + \frac{(n-1)\pi}{n}\right)} = c_n,$$
где $n$ — нечетное число, $c_n$ — константа (зависшая от $n$).
b) $^*$ Найдите $c_n$ для каждой нечетного $n=5, 7, \dots$.

## Решение

Докажите, что при любом значении $x$, для которого левая часть имеет смысл, выполнены равенства

$$\begin{align*}
tg x + tg \left( x + \frac{\pi}{3} \right) + \\
+ tg \left( x + \frac{2\pi}{3} \right) &: \begin{align*}
tg x \times \\
\times tg \left( x + \frac{\pi}{3} \right) \times \\
\times tg \left( x + \frac{2\pi}{3} \right) \end{align*}
= -3;
\end{align*}$$

$$\begin{align*}
tg x + tg \left( x + \frac{\pi}{n} \right) + \dots \\
\dots + tg \left( x + \frac{(n-1)\pi}{n} \right) &: \begin{align*}
tg x \cdot tg \left( x + \frac{\pi}{n} \right) \times \dots \\
\dots \times tg \left( x + \frac{(n-1)\pi}{n} \right) \end{align*}
= c_n
\end{align*}$$

еде $n$ — нечетное число, $n > 0$, $c_n$ — константа (зависцая от $n$).
в) Найдите $c_n$ для каждого нечетного $n$.

a) Положим $tg x = z$, $tg(\pi/3) = \sqrt{3} = t$, тогда $tg(2\pi/3) = -t$. Используя формулу тангенса суммы, получим (при $zt \neq \pm 1$)

$$\begin{align*}
tg x + tg \left( x + \frac{\pi}{3} \right) + tg \left( x + \frac{2\pi}{3} \right) &= \frac{z + \frac{z+t}{1-zt} + \frac{z-t}{1+zt}}{z \cdot \frac{z+t}{1-zt} \cdot \frac{z-t}{1+zt}} = \\
&= \frac{z (1-z^2 t^2) + 2z + 2zt^2}{z (z^2-t^2)} = \frac{-3z^3 + 9z}{z^3 - 3z} = -3.
\end{align*}$$

6) Используя формулы приведения $tg(x+\pi) = -tg(\pi-x) = tg x$ и нечетность $n$, нетрудно проверить, что и числитель, и знаменатель дроби

$$f(x) = \frac{tg x + tg \left( x + \frac{\pi}{n} \right) + \dots + tg \left( x + \frac{n-1}{n}\pi \right)}{tg x \cdot tg \left( x + \frac{\pi}{n} \right) \cdot \dots \cdot tg \left( x + \frac{n-1}{n}\pi \right)} = c_n$$

обращаются в 0 в одних и тех же точках промежуточка [0; $\pi$ [: 0, $\frac{\pi}{n}$, $\frac{2\pi}{n}$, ..., $\frac{n-1}{n}$ $\pi$ (и теряют смысл — «обращаются в бесконечность» — также в одних и тех же точках $\frac{\pi}{2n}$, $\frac{3\pi}{2n}$, ..., $\frac{2n-1}{2n}$ $\pi$, которые мы в дальнейшем исключаем из рассмотрения). Положим $tg x = z$, $tg \pi/k = t_k$ ($k=0, 1, \dots, n-1$). Числитель и знаменатель дроби $f(x)$ можно, заменив $tg(x+\pi/k/n)$ на $(z+t_k)/(1-zt_k)$, представить в виде отношений многочленов от $z$:

$$z + \frac{z+t_1}{1-zt_1} + \dots + \frac{z+t_{n-1}}{1-zt_{n-1}} = \frac{S_1(z)}{R(z)},$$

$$z \cdot \frac{z+t_1}{1-zt_1} \cdot \dots \cdot \frac{z+t_{n-1}}{1-zt_{n-1}} = \frac{S_2(z)}{R(z)},$$

где $R(z) = (1-zt_1) \dots (1-zt_{n-1})$, а оба многочленas $S_1(z)$ и $S_2(z)$ имеют степени $n$ и одни и те же корни $t_0=0$, $t_1$, $t_2$, ..., $t_{n-1}$. Тот факт, что дробь $f(x)$, то есть $S_1(z)/S_2(z)$, есть константа, сразу вытекает из следующей леммы:

Лемма. Если многочлен $az^n + bz^{n-1} + \dots + d = p(z)$ степени $n$ имеет $n$ различных корней $z_0$, $z_1$, ..., $z_{n-1}$, то он только действно равен $a(z-z_0)(z-z_1) \dots (z-z_{n-1})$.

Доказательство леммы можно проверить индукцией по степени $n$ многочлена $p(z)$. Для $n=1$ оно очевидно: $az+b=a(z-z_0)$, где $z_0=-b/a$. Пусть $p(z)$ — многочлен степени $n+1$ со старшим коэффициентом $a$ и корнями $z_0$, $z_1$, ..., $z_{n-1}$. Тогда $p(z)=p(z)-p(z_n)=az^n+bz^{n-1}+\dots+d-(az_n^n+bz^{n-1}+\dots+d)=a(z^n-z_n^n)+b(z^{n-1}-z_n^n)+\dots=(z-z_n)^q(z)$, где $q(z)$ — неотorious многочлен степени со старшим коэффициентом $a$ и корнями $z_0$, $z_1$, ..., $z_{n-1}$. По предположению индукции $p(z)=(z-z_0)\cdot a(z-z_0)(z-z_1)$. $\dots(z-z_{n-1})=a(z-z_0)(z-z_1)\dots(z-z_{n-1})$, то есть утверждение леммы справедливо и для многочлена степени $n+1$. (В доказательстве использовалось тожество

$$z^k-a^k=(z-a)(z^{k-1}+z^{k-2}a+\dots+z a^{k-2}+a^{k-1}),$$

из которого видно, что $z^k-a^k$ делится на $z-a$.

в) Найти.constantу $c_n$ для любого (нечетного) $n$ значительной трудности. Ответ: $c_n=(-1)^{\frac{n-1}{2}}n$, то есть $c_3=-3$, $c_5=5$, $c_7=-7$ и т. д. Во всех решениях, которые мы упомяны, использоваются сообщения, связанные с корнями многочленов.

Константа $c_n$ может быть получена как отношение старших коэффициентов многочленов $S_1(z)$ и $S_2(z)$. У первого старший коэффициент равен $t_1 t_2 \dots t_{n-1}$, у второго 1, поэтому $c_n = t_1 t_2 \dots t_{n-1}$. Найти знак произведения $t_1 t_2 \dots t_{n-1}$ нетрудно: среди тангенсов $t_k = \text{tg} \pi k/n$ равно $(n-1)/2$ отрицательных (причем $t_{n-k} = -t_k$). Ряд читателей заметил, что произведение $|t_1 t_2 \dots t_{n-1}|$ можно выразить как отношение $Q'_n(0)/P_{n-1}(0)$, где $Q_n(x)$ и $P_{n-1}(x)$ — многочлены Чебышева, определяемые условиями $Q_n(2 \cos \varphi) = 2 \cos n\varphi$, $P_{n-1}(2 \cos \varphi) = \frac{\sin n\varphi}{\sin \varphi}$ (см. статью Н. Васильева и А. Зелевинского в «Кванте», 1982, № 4, с. 17*).

Приведем пожожее, но более прямое рассудение.

Заметим, что $\text{tg} nx$ обращается в 0 в точках 0, $\frac{\pi}{n}, \frac{2\pi}{n}, \dots, \frac{n-1}{n}$ и может быть выражен как отношение $s_n(z)/r_n(z)$ двух многочленов от $\text{tg} x = z$; по индукции, опираясь на формулу

$$\sum_{k=0}^{m} \text{tg}^2 \frac{k\pi}{2m+1} = \frac{m(2m-1)}{3};$$

$$\sum_{k=0}^{m-1} \text{tg} \frac{(4k+1)\pi}{4m} = m;$$

$$\sum_{k=0}^{2m-1} \text{tg} \left(x + \frac{k\pi}{2m}\right) = -\frac{2m}{\text{tg} 2mx};$$

$$\sum_{k=0}^{2m} \text{tg} \left(x + \frac{k\pi}{2m+1}\right) = (2m+1) \cdot \text{tg} (2m+1)x;$$

$$\sum_{k=0}^{2m} \text{tg} \left(x + \frac{k\pi}{2m+1}\right) = (-1)^m \cdot \text{tg} (2m+1)x;$$

$$\sum_{k=0}^{n-1} \sin \left(x + \frac{k\pi}{n}\right) = \frac{1}{2^{n-1}} \sin nx.$$

Константа $c_n$ может быть получена как отношение старших коэффициентов многочленов $S_1(z)$ и $S_2(z)$. У первого старший коэффициент равен $t_1 t_2 \dots t_{n-1}$, у второго 1, поэтому $c_n = t_1 t_2 \dots t_{n-1}$. Найти знак произведения $t_1 t_2 \dots t_{n-1}$ нетрудно: среди тангенсов $t_k = \text{tg} \pi k/n$ равно $(n-1)/2$ отрицательных (причем $t_{n-k} = -t_k$). Ряд читателей заметил, что произведение $|t_1 t_2 \dots t_{n-1}|$ можно выразить как отношение $Q'_n(0)/P_{n-1}(0)$, где $Q_n(x)$ и $P_{n-1}(x)$ — многочлены Чебышева, определяемые условиями $Q_n(2 \cos \varphi) = 2 \cos n\varphi$, $P_{n-1}(2 \cos \varphi) = \frac{\sin n\varphi}{\sin \varphi}$ (см. статью Н. Васильева и А. Зелевинского в «Кванте», 1982, № 4, с. 17*).

При этом многочлен $s_n(z)$ должен иметь $n$ корней $t_0=0, t_1, \dots, t_{n-1}$ и потому по лемме равен

$$s_n = e_n z (z-t_1) \dots (z-t_{n-1}) = e_n z^n + \dots + e_n t_1 \dots t_{n-1} z.$$

Сравним (1) и (2), получаем, что $t_1 t_2 \dots t_{n-1} = e_n n$.

Приведем еще один способ отискания $c_n$. Подставим в тожество $f(x) = c_n$ значение $x = \pi/4n$. Используя формулы приведения $\text{tg} \left(\frac{\pi}{2} - x\right) = \text{tg} \left(\frac{3\pi}{2} - x\right) = 1/\text{tg} x$, не трудно показать, что произведение тангенсов углов $\frac{\pi}{4n}, \frac{5\pi}{4n}, \dots, \frac{(4n-3)\pi}{4n}$, стоящее в знаменателе, равно $(-1)^{\frac{n-1}{2}}$.

Найти сумму в числитель можно, опираясь на тот факт, что для всех этих углов $\text{tg} nx = 1$, и использовать формулу (1) (по существу, именно отисканию этой суммы послешения задача M100 — см. «Кванте», 1972, № 12; ряд соответствий между трионометрическими функциями подобного рода и интересных следствий из них разобран в книге А. М. Яглома и И. М. Яглома «Незелематриные задачи в элементарном изложении» (М., ГТТИ, 1954), задачи 130—145).
