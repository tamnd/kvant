## Условие

Может ли произведение a) трех; б) четырех последовательных натуральных чисел равняться неокоторой степени неокоторого натурального числа (квадрату, кубу, и т. д.)?

Д. Флейшман, уч. 10 класса

## Решение

Может ли произведение a) трех b) четырех последовательных натуральных чисел равнять неокоторо натурального числа (квадрату, кубу и т. д.)?

*) Задчага M364 решена в статье Л. Беве «Минигеометрия», см. «Квант», 1976, № 6, с. 11.

Ответ на все три вопроса — утвердительный. Приведем примеры, показывающие, что так случайное может be.

a) Два числа: 2 и —1.

б) Восемь чисел: 4/5, 4/5, —1/10, —1/10, ..., —1/10.

Их сумма равна 1, а сумма кубов равна $2 \cdot (4/5)^3 - 6 \cdot (1/10)^3 = 1,018$. На той же идее — сравть положительные числа и добавлять к ним отрицательные числа — в большем количестве, но величины поменше, — основан и следующей пример.

b) Составим ряд

$$1 + (-1/2) + (-1/2) + 1/2 + (-1/4) + (-1/4) + (1/2) + (-1/4) + (-1/4) + \dots$$

следующим образом: следом за суммой 1 + (-1/2) + (-1/2) поставим 2^3 = 8 сумм $1/2$ + (-1/4) + (-1/4), затем 3^3 = 27 сумм $1/3$ + (-1/6) + (-1/6), ..., $n^3$ сумм $(1/n) + (-1/2n) + (-1/2n)$, и так далее. Этот ряд сходится и сумма его равна нулю, поскольку сумма $N$ первый его членов, где 3 ($1 + 2^3 + 3^3 + \dots + n^3$) ≤ $N \leq 3$ [1 + 2^3 + 3^3 + ... + ($n + 1$)], не больше $1/(n+1)$ (именено, она либо нуль, либо $1/(n+1)$, либо $1/(n+1)$). Соответствующий же ему ряд из кубов расходится. Действительно, сумма $n^3$ сумм $(1/n)^3 + (-1/2n)^3 + (-1/2n)^3 = 3/4n^3$ равна $3/4$, так что сумма первый 3 ($1 + 2^3 + \dots + n^3$) членов ряда равна $3n/4$.

Разумеется, если в условии задачи все числа предполагаются положительным, то ответы на все три вопроса будут отрицательными.

H. Васильев

B. Колосов

a) Допустим, что $k(k+1)(k+2)=u^n$, $n>1$. Число $k+1$ взаимно просто с числами $k$ и $k+2$; поэтому $k+1=m^n$, $k(k+2)=k^2+2k=l^n$ (это — следствие Основной теоремы арифметики о единственности разложения натуральных чисел на простые множители). Тогда $(k+1)^2=k^2+2k+1=m^2n$, то есть $(m^2)^n — l^n = 1$ — противоречие: $(a^n - b^n) = (a - b)(a^{n-1} + a^{n-2}b + \dots + b^{n-1}) \neq 1$. Значит, произведение трех последовательных натуральных чисел не может быть степенью натурального числа.

b) Доказем, что и в этом случае ответ отрицательный. Предположим противное: допустим, что для некоторого $k(k+1)(k+2)=u^n$.

Идя рассудения будет такой же, как в задание a): мы конструкруем два близких числа, каждое из которых должно быть $n$-й степенью, и прием к противоречию. Расстояние отдельно случан $n = 2$ и $n \ge 3$.

I. $n = 2$. Имеем $(k^2 + 3k)(k^2 + 3k + 2) = u^2$. Обозначив $k^2 + 3k + 1$ через $y$, получим равенство $y^2 - 1 = u^2$, невозможное для натуральных $u$ и $y$.

II. $n \ge 3$. Заметим, что либо число $k + 1$, либо $k + 2$ взаимно просто с остальными треями числами.

1) Пусть число $k + 1$ взаимно просто с $k$, $k + 2$ и $k + 3$. Тогда (см. решение пункта a)) $k + 1 = m^n$, $k(k + 2)(k + 3) = l^n$. Имеем $k = m^n - 1$, $k + 2 = m^n + 1$, $k + 3 = m^n + 2$; значит $(m^n - 1)(m^n + 1)(m^n + 2) = m^{3n} + 2m^{2n} - m^n - 2 = l^n$. Поскольку $m \ge 2$ и $n \ge 3$, $2m^{2n} - m^n - 2 > 0$, то есть $l^n > (m^3)^n$, или $l > m^3$. С другой стороны, $(m^3 + 1)^n > m^{3n} + nm^{3n-3} > m^{3n} + 2m^{2n} - m^n - 2 = l^n$, откуда $l < m^3 + 1$. Итак, должно быть $m^3 < l < m^3 + 1$, что невозможно для натуральных $m$ и $l$.

2) Если же число $k + 2$ взаимно просто с $k$, $k + 1$ и $k + 3$, то тогда $k + 2 = m^n$, а $k(k + 1)(k + 3) = l^n$, или $(m^n - 2)(m^n - 1)(m^n + 1) = l^n$, то есть $l^n = m^{3n} - 2m^{2n} - m^n - 2 = l^n$, откуда $l < m^3 + 1$. Итак, должно быть $m^3 < l < m^3 + 1$, что невозможно для натуральных $m$ и $n$. Таким образом, $l < m^3$.

Сравним теперь $l$ и $m^3 - 1$. Для этого заметим следующие. Так как $m^3 > 4$, имеем $m^{3n-3} > 4m^{3n-6}$; и $3n - 6 \ge n$, поскольку $n \ge 3$. Отсюда $m^{3n-3} > 3m^{3n-6} + m^n$. Оценим теперь разность между $(m^3)^n$ и $(m^3 - 1)^n: (m^3)^n - (m^3 - 1)^n = m^{3n-3} + m^{3n-6} (m^3 - 1) + m^{3n-9} (m^6 - 2m^3 + 1) + \dots + (m^3 - 1)^{n-1} > 3m^{3n-3} - 3m^{3n-6} > 2m^{3n-3} + m^n > 2m^{2n} + m^n - 2 = (m^3)^n - l^n$.

Отсюда $(m^3 - 1)^n < l^n$, то есть $m^3 - 1 < l < m^3$ — не может быть, поскольку $m$ и $l$ — натуральные.

Полученное противоречие и доказывает нашей предположение: произведение четырех последовательных натуральных чисел не может равнять степени натурального числа.

Д. Флейшан
