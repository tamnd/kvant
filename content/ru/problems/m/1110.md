## Условие

Для данного натурального $n > 1$ выпишем наиболее общие делители всех возможных пар различных чисел от 1 до $n$. Докажите, что а) среднее арифметическое всех $n(n-1)/2$ выписанных чисел неограниченно растет с ростом $n$, но не превыходит $\ln n + 1$; б) их среднее геометрическое не превыходит 10 при любом $n$.

В. Ф. Лев

## Решение

Для каждого натурального $n>1$ выпишем наиболее общие делители всех возможных пар различных чисел от 1 до $n$. Докажите, что $a$ среднее арифметическое всех $n(n-1)/2$ выписанных чисел не ограничено расстоянием $n$, но не превышает $\ln n+1$; $b$ их среднее геометрическое не превышает 10 при любом $n$.

Рис. 1.

a) Обозначим через $P_n(d)$ количество пар $(a, b)$ натуральных чисел $a < b \leq n$ с наиболее общим делителем $d=HOД(a, b)$. Каждый такой пар можно представить в виде $a=dx, b=dy$, где $x<y \leq k=[n/d]$, причем $x$ и $y$ взаимно просты. Количество $P_k=P_k(1)$ таких пар $(x, y)$ взаимно простых чисел нетрудно оценить сверху:

$$P_k \leq 1+2+\ldots+(k-1)=k(k-1)/2,$$

поскольку при каждом $y \leq k$ число $x<y$ принимает не больше $y-1$ значений. Отсюда

$$P_n(d)=P_{[n/d]} \leq \frac{n}{2d}\left(\frac{n}{d}-1\right) \leq \frac{n(n-1)}{2d^2}.$$

В конце решения мы докажем оценку сизу $P_k \geq k(k-1)/4$; из нее получается оценка для $P_n(d)$:

$$P_n(d) \geq \frac{1}{4}\left(\frac{n}{d}-1\right)\left(\frac{n}{d}-2\right)=$$

$$= \frac{n^2-3nd+2d^2}{4d^2} > \frac{n(n-1)}{4d^2}-\frac{3n}{4d}.$$

Сумма чисел $d=HOД(a, b)$ по всем параметрам $(a, b)$ равна $\sum_{d=1}^{n-1} dP_n(d)$, а их среднее арифметическое $A$ равно $\frac{2}{n(n-1)}\sum_{d=1}^{n-1} dP_n(d)$. Используя оценки для $P_n(d)$, получаем:

$$A \leq \frac{2}{n(n-1)}\sum_{d=1}^{n-1} d\left(\frac{n(n-1)}{4d^2}-\frac{3n}{4d}\right)=$$

$$= \frac{1}{2}\left(1+\frac{1}{2}+\ldots+\frac{1}{n-1}\right)-\frac{3}{2}.$$

Далее нам потребуется следующее

Лемma. Для любого натурального $n$

$$\frac{1}{2} + \ldots + \frac{1}{n} < \ln n < 1 + \frac{1}{2} + \ldots + \frac{1}{n-1}.$$

Для ее доказательства можно воспользоваться тем, что $\ln n = \int_{1}^{n} 1/t \, dt$ — площадь под гиперболой $f(t) = 1/t$ на участке $1 \leq t \leq n$ (рис. 1); можно не пользоваться интегралом, а, например, убедиться в справедливости неравенств

$$\frac{\alpha}{1+\alpha} \leq \ln(1+\alpha) \leq \alpha \quad \text{при} \ \alpha \geq 0$$

(заметив, что при $\alpha=0$ все три члена равны 0 и сравнив производные), затем подставить в них $\alpha=1$, $\alpha=\frac{1}{2}$, ..., $\alpha=\frac{1}{n-1}$ и сложить все полученные неравенства.

Применяя лемму к оценкам (1) и (2), получим

$$\frac{1}{2} \ln n - \frac{3}{2} < A \leq \ln(n-1)+1 < \ln n+1.$$

6) Логарифм среднего арифметического несколько чисел равен среднему арифметическому их логарифмов. Поэтому для решения задачи достаточно доказать, что среднее арифметическое чисел $\ln d$ (где $d=\text{НОД} (a, b)$, $a<b \leq n$) меньше 2: ведь $e^2 < 10$, т. е. $2 < \ln 10$. Действуя так же, как и выше, получим

$$\frac{2}{n(n-1)} \sum_{d=1}^{n} \ln d \cdot P_n(d) \leq \sum_{d=2}^{n} \frac{\ln d}{d^2} < \sum_{d=2}^{n} \left( \frac{1}{d^2} \sum_{h=1}^{n} \frac{1}{h} \right).$$

Здесь мы применили лемму: $\ln d \leq 1 + \frac{1}{2} + \ldots + \frac{1}{d}$.

В образовательной двойной сумме чисел вида $\frac{1}{d^2} \frac{1}{h}$ ($1 \leq h \leq d$, $2 \leq d \leq n$) удобно собрать вместе числы с одинаковыми $h$ ($1 \leq d \leq n$ при $h=1$, $h \leq d \leq n$ при $h>1$) и оценить $\sum_{d=h}^{n} \frac{1}{d^2}$ с помощью легкого сворачивающейся суммы

$$\sum_{d=h}^{n} \frac{1}{d(d-1)} = \sum_{d=h}^{n} \left( \frac{1}{d-1} - \frac{1}{d} \right) = \frac{1}{h-1} - \frac{1}{n} < \frac{1}{h-1}$$

(эта оценка понадобится сейчас раз для $h=2$).

Окончательно получаем

$$\sum_{d=2}^{n} \frac{\ln d}{d^2} < \sum_{d=2}^{n} \frac{1}{d^2} + \sum_{h=2}^{n} \left( \frac{1}{h} \sum_{d=h}^{n-1} \frac{1}{d^2} \right) < 1 + \sum_{h=2}^{n} \frac{1}{h(h-1)} < 2.$$

Доказем теперь оценку $P_k \geq k(k-1)$, используяную в решении пункта a). Положим $m=[k/2]$. Среди всех целых точек $(x, y)$, где $0 < x < y \leq k$, называем красными те, для которых $x$ и $y$ взаимно просты (рис. 2). Проведем через каждую красную точку в треугольнике $x < y \leq m$ луч из начала координат $(0, 0)$. Эти $P_m$ лучей содержат, конечно, все $m(m-1)/2$ целых точек в треугольнике $x < y \leq m$.

Рассмотрим целые точки на любом из $P_h$ лучей.

IX kolichestvo на участке $h+1 \leqslant y \leqslant k$ может превосходить их kolichestvo на участке $1 \leqslant y \leqslant h$ не более, чем на единицу (ведь целые точки $(x, y)$ встречаются на луче через равные промежутки). Поэтому в трапеции $m+1 \leqslant y \leqslant k$, $x < y$ из всех $k(k-1)/2-m(m-1)/2$ целых точки на проведенных лучах лежат не более $m(m-1)/2+P_m$ точек. Все остальные точки в трапеции — красные; таким образом, их число

$$P_k - P_m \geqslant \frac{k(k-1)}{2} - m(m-1) - P_m,$$

откуда

$$P_k \geqslant \frac{k(k-1)}{2} - m(m-1) \geqslant \frac{k(k-1)}{4}$$

(последнее неравенство нетрудно проверить для $k=2m$ и $k=2m+1$).

Можно показать, что $\lim_{k \to \infty} \frac{P_k}{k^2} = 3/\pi^2$, т. е. верятность, что случайное взятие натуральные числа $(x, y)$, не превосходящие $k$, оказывается взаимно простыми, стремится к $6/\pi^2$ при $k \to \infty$ (см., например, задачу 30 к главе III в книге И. М. Виноградова «Введение в теорию чисел», М.: Наука, 1965).
