## Условие

В круге расположено $k>1$ черных секторов, угол каждой из которых меньше $180^\circ/(k^2-k+1)$. Доказите, что круг можно повернуть вокруг центра $O$ так, что все черные секторы перейдет в белую часть круга.

В. Произвольов

## Решение

В круге расположено $k > 1$ черных секторов, угод какдого из которых меньше $180^\circ / (k^2 - k + 1)$. Доказите, что круг можно повернуть вокруг центра O так, что все черные секторы перейдет в белую часть круга.

Рис. 1.

Пусть вместе сложены два круга, на одном из которых отмечено r черных секторов с центральными углами $a_1, a_2, \dots, a_r$, на другом — s синих с углами $\beta_1, \beta_2, \dots, \beta_s$ (рис. 1). Попробуем найти достоинные условия, при которых круг с синими секторами можно повернуть на такой угол $\varphi$ ($0 < \varphi < 2\pi$), чтобы ни один из синих секторов не пересекался с черным.

Углы поворота $\varphi$ удобно отмечать на специальной окружности $c$ длины $2\pi$ с данной на ней точкой 0 (нулем). «Повернем» задачу иначе. Отметим на $c$ все запретные углы $\varphi$ — такие, при повороте на которые какой-то синий радиус совпадает с каким-то черным. Каждая пара (черный сектор с углом $a_i$, синий сектор с углом $\beta_j$) дает интервал запретных $\varphi$ длиной $a_i + \beta_j$. Поэтому, если какдое $a_i < \pi/k$, в частности, если какдое $a_i < \pi/k^2$. Доказать утверждение и для секторов с углами $a_i < \gamma = \pi / (k^2 - k + 1)$ можно, следка уточнить в этом случае оценку

менные $2(k-1)k\gamma = 2\pi - 2\gamma$, так что и в этом случае найдется «незапретное» значение $\varphi$.

Задача решения, но возникает вопрос, нельзя ли еще поднять границы для $\alpha_i$? Утверждение задачи, вообще говоря, не сохраняется, если углы всех $k$ секторов взяты по величины равны $\gamma = \pi/(k^2-k+1)$. Опровергающие примеры для $k=2, 3, 4, 5$ весма любопытны (рис. 2): красные точки — концы биссеектрис секторов — должны быть расположены в $k$ вершинах правильного ($k^2-k+1$)-угольника, выбранных так, что для любого $m=1, 2, ..., k^2-k$ найдется пара красных точек, между которых расположено (в ту или иную сторону по окружности) $m$ сторон ($k^2-k+1$)-угольника. Проверьте, что тогда «запретное множество» — все $\varphi \in [0; 2\pi]$.

Сама по себе комбинаторная задача: при каких $k$ можно расположить $k$ красных точек на окружности длины $2C_k^2+1=k^2-k+1$ так, чтобы для любого $m=1, 2, ..., k^2-k$ найдется пара красных точек, между которых расположено (в ту или иную сторону по окружности) $m$ сторон ($k^2-k+1$)-угольника. Проверьте, что тогда «запретное множество» — все $\varphi \in [0; 2\pi]$.

Проверьте, что тогда «запретное множество» — все $\varphi \in [0; 2\pi]$.

Пусть для неокоторого $k$ такое красное множество $\Pi_0$ существует. Тогда $\Pi_0$ и его образы $\Pi_m$ ($m=1, 2, ..., k^2-k$) при поворотах на углы $m\gamma, \gamma=\pi/(k^2-k+1)$, обладают такимми свойствами:

1°. Для любых $i \neq j$ пересечение $\Pi_i \cap \Pi_j$ состоит из одной точки.

2°. Любые две из точки множества $\Pi = \bigcup_m \Pi_m$ (вершин правильного ($k^2-k+1$)-угольника) принадлежатровно одному из $\Pi_m$.

3°. Существуют четыре точки множества $\Pi$, не содержащиеся в одном $\Pi_i$.

Множество $\Pi$ с такой системой подмножества $\Pi_m \subset \Pi$ называется конечной проективной плоскостью*). Известно, что конечные проективные плоскости существуют для $k=p^r+1$, где $p$ — простое, $r$ — натуральное числа (например, $k=3, 4, 5, 6, 8, 9$) и не существует, если $k=7, 15$; понятно; теперь, что в последнем случае не может существовать и опровергающего примера в задаче М558 (так что, например, для семи секторов с углами $\pi/43$ ее утверждение верно). Но уже для $k=10$ вопрос пока не удается решить даже с помощью ЭВМ.

Отметим, что конечная проективная плоскость не обязательна и такую «циклическую» номерацию точек, при которой прямые $\Pi_m$ получаются друг из друга с двумя номерами — это дополнительное требование, возможно, облегчит доказательство отсутствия таких «циклических плоскостей» для неокоторых $k$. (Заметим, что все проективные плоскости над конечным полем из $p^r$ элементов имеют такие циклическую номерацию; см. об этом в главе «Разностные множества» книги М. Холла.)
