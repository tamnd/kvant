## Условие

Обозначим через $d_k$ количество таких домов в вашем городе, в которых живет не меньше $k$ жителей ($d_1 \geq d_2 \geq d_3 \geq \dots$), и через $c_m$ — количество жителей в $m$-м по величине населения дома ($c_1 \geq c_2 \geq c_3 \geq \dots$). Докажите равенства
a) $c_1 + c_2 + c_3 + \dots = d_1 + d_2 + d_3 + \dots$;
b) $c_1^2 + c_2^2 + c_3^2 + \dots = d_1 + 3d_2 + 5d_3 + \dots + (2k-1)d_k + \dots$;
c) $d_1^2 + d_2^2 + d_3^2 + \dots = c_1 + 3c_2 + 5c_3 + \dots$;
... + $(2m-1)c_m + \dots$,
A. Зелевинский
