## Условие

a) Постройте график функции
$$f_0(x) = \left| x - 1 \right| - 2 \left| x \right| - 3$$

б) На рисунке 1 изображены графики трех «кусочно-линейных» функции $f_1, f_2, f_3$. Запишите формулы для них в виде
$$y = kx + b + c_1 |x - a_1| + \dots + c_m |x - a_m|,$$
где $k, b, c_i, a_i$ — некоторые числа, $m$ — количество точек излома графика ($a_i$ — абсциссы точек излома, $i = 1, 2, \dots, m$).

в) Запишите в таком же виде функцию $f_0$ из пункта a).

## Решение

a) Построите график функции $f_0(x) = \|x-1\| - 2\|x\| - 3\|$.

б) На рисунке 1 изображены графики трех куссоно-линейных функций $f_1, f_2, f_3$. Запишите формулы для них в виде $y = kx + b + c_1|x - a_1| + \dots + c_m|x - a_m|$, где $k, b, c_i, a_i$ — некоторые числа, $m$ — количество точек излома графика ($a_i$ — абсциссы точек излома, $i=1, 2, \dots, m$).

в) Запишите в таком же виде функцию $f_0$ из пункта a)

e) * Некоторые функции являются комбинацией линейных функций, «модуля» и операции сложения, причем знак modular используется в ее записи $n$ раз (в примере a) $n=4$. Какое наиболее число изломов (при каждой n) может иметь ее график?

a) График функции $f_0$ изображен красным (рис. 2). Он является ломаной с конечным числом вершин — точек излома и двумя бесконечными крайными звеньями; функция с таким графиками называется куссоно-линейными. Хотя построение этого графика выполняет стандартно, мы останавемся на нем подробнее — это позволяет сделать несколько заменений, полезных при решении задачи г).

Пусть $f(x) = |x-1| - 2|x| - 3|$, тогда $f_0(x) = |f(x)|$, и потому график $f_0$ получается из графика $f$ (черная линия на рисунке 2) отражением его части, лежащей ниже оси абсцисс, относительно этой оси. Ясно, что это правило построения графика $|f|$ справедливо для любой функции $f$. В частности, из него следует, что:

1) если $m(f)$ — число изломов куссоно-линейной функции $f$, то

$$m(|f|) \leq 2m(f) + 1.$$

(Действительно, при переходе от $f$ к $|f|$ новые изломы появляются там, где график функции $f$ пересекает ось $Ox$, то есть не более чем по одному на каждой звенье, а число звеньев на 1 больше числа изломов $m(f)$.)

Далее, функция $f$ есть сумма функций $g(x) = |x-1|$ и $h(x) = -2|x| - 3|$, поэтому она может иметь изломы только там, где есть излом хотя у одного из слагаемых, то есть в точках, где обращаются в нуль выражения, стоящие под модель: $x-1$, $x$ или $|x|-3$; это точки $-3, 0, 1$ и $3$. Точно так же вообще

2) для любых куссоно-линейных функций $g$ и $h$

$$m(g+h) \leq m(g) + m(h).$$

На каждом из промежутков $] -\infty; -3]$, $[-3; 0]$, $[0; 1]$, $[1; 3]$ и $[3; \infty[$ функций $g, h$ и следовательно, $f$ линейны. «Раскрывая модель», получим, что $f(x) = -x+1$ при $x \leq -3$, $f(x) = -3x-5$ при $-3 \leq x \leq 0$ и т. д., после чего можно построить каждое звенье графика. (Впрочем, «Раскрывать модель» необязательно. Для построения графика, оченьindo, достаточно построить его точки

Решим задачу сразу в обшем виде. Пусть $f$ — кусочно-линейная функция с изломами в точках с абсциссами $a_1, \dots, a_m$ и путь $k_0, k_1, \dots, k_m$ — угловые коэффициенты звеньев ее графика на промежутках $] -\infty; a_1]$, $[a_1; a_2]$, ..., $[a_m; \infty$ [. Показем, что ее можно единственным образом представить в виде

$$f(x) = kx + b + c_1|x-a_1| + \dots + c_m|x-a_m|.$$

(1)

Это можно сделать, «раскрыв модели» на каждом из $m+1$ промежутков, приравнять коэффициент при $x$ в получившемся выражении для $f(x)$ к соответствующему $k_i$ и решив возникшую систему уравнения относительно $k, c_1, \dots, c_m$. Но можно сразу найти значения $c_1, \dots, c_m$.

Пусть $l_i(x)$ — линейная функция, совпадающая с $f(x)$ на $i$-м промежутке; ее угловой коэффициент равен $k_i$. Если функция $f(x)$ представима в виде (1), то есть $f(x) = c_i|x-a_i| + h(x)$, где $h(x)$ — линейная на промежутке $[a_{i-1}; a_{i+1}]$ функция, то на этом промежутке $l_{i-1}(x) = c_i(a_i-x)+h(x)$, $l_i(x) = c_i(x-a_i)+h(x)$, а угловой коэффициент разности $l_i(x) - l_{i-1}(x) = 2c_i x$ равен $k_i - k_{i-1}$. Следовательно, должны выполняться равенства $c_i = (k_i - k_{i-1})/2, i=1, 2, \dots, m$. Обратно, если они выполнются, то функция $c_1|x-a_1| + \dots + c_m|x-a_m|$ имеет изломы в тех же точках, что и $f$, и изменение углового коэффициента при переходе через любую из этих точек для обихих функций будет одинаковым. Поэтому разность этих функций — линейная функция $kx+b$. Угловые коэффициенты левой и правой части (1) при $x>a_m$ равны $k_m$ и $k+c_1+...+c_m=k+(k_m-k_1)/2$ соответственно, поэтому $k=(k_1+k_m)/2$. Значение $b$ можно найти, подставляя в (1) любое конкретное значение $x$, например $x=0$.

Коэффициенты $k_0, \dots, k_9$ для функции $f_0$ выписаны над ее графиком (рис. 2). Подставляя их в полученные формулы, найдем приведенный выше ответ.

г) Ответ: Если в запись функции $f$, рассматриваем в задаче, знак модели входит $n$ раз, то число изломов $m(f)$ её графика не превыходит $2^n-1$.

Это утверждение мы доказем индукцией по $n$. При $n=0$ оно очевидно (у линейной функции изломов нет). Пусть оно верно, если число модели меньше $n$, а в запись функции $f$ входит $n$ модели. Тогда эту функцию можно представить в виде $f=|g|+h$, причем функция $g$ записьается с $n_1$ модулями, а $h$ — с $n_2$ модулями, где $n_1+n_2=n-1$. В силу утверждения (1) и (2) пункту а) и предположения индукции

$$m(f) \leq m(|g|)+m(h) \leq 2m(g)+1+m(h) \leq 2 \cdot (2^{n_1}-1)+1+2^{n_2}-1=2^{n_1+1}+2^{n_2}-2 \leq 2^{n_1+n_2+1}-1=2^{n}-1,$$

поскольку $2^{n_1+n_2+1}-2^{n_1+1}-2^{n_2}+1=(2^{n_1+1}-1)(2^{n_2}-1) \geq 0$.

График функции $y=|...||x|-2^{n-2}|-2^{n-3}|...-1|$ (см. рис. 3 для $n=3$) имеетровно $2^n-1$ излом (при $n$ модулях в записи функций), поэтому оценка в задаче точная.
