## Условие

Пусть $n$ — натуральное число и $A_1, A_2, ..., A_{2n+1}$ подмножества некоторого множества $B$. Предположим, что
a) каждое множество $A_i$ ($i=1, 2, ..., 2n+1$) содержитровно $2n$ элементов;
b) каждое множество $A_i \cap A_j$ ($1 \leq i < j \leq 2n+1$) содержитровно один элемент;
b) любой элемент множества $B$ принадлежит не менее чем двум из множества $A_i$ ($i=1, 2, ..., 2n+1$).
Для каких значений $n$ можно поставить в соответствии каждому элементу множества $B$ одно из чисел — 0 или 1 — так, чтобы каждое из множества $A_1, A_2, ..., A_{2n+1}$ содержалоровно $n$ элементов, соответствующих числу 0?
