## Условие

Дан кубический многочлен f ( x ). Назовем циклом тройку различных чисел ( a, b, c ) таких, что f ( a ) = b, f ( b ) = c и f ( c ) = a. Известно, что нашлись

⟦column⟧

восемь циклов $( a_{i}, b_{i}, c_{i} ), i = 1, 2,$ …, 8, в которых участвуют 24 различных числа. Докажите, что среди восьми чисел вида $a_{i} + b_{i} + c_{i}$ есть хотя бы: а) три различных; б) четыре различных. А.Голованов, Ф.Петров
