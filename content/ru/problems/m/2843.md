## Условие

Пусть A c, B c, C c – середины сторон BC, CA, AB соответственно в правильном треугольнике ABC (рис. 1). На продолжении отрезка A c B c за B c взята точка D, а на продолжении отрезка A c C c за C c взята точка E так, что отрезок DE проходит через точку A. Отрезки B c E и C c D пересекаются в точке X.

⟦column⟧

а) Докажите, что точки X, A c, B c, C c лежат на одной окружности. б) Докажите, что отрезки A c X, CE, BD и B c C c пересекаются в одной точке. К.Байрак, ученик 11 класса
