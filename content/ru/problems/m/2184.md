## Условие

Про функцию f ( x ) известно следующее: любая прямая на координатной плоскости имеет с графиком y = f ( x ) столько же общих точек, сколько с параболой $y = x^{2}$. Докажите, что функция f ( x ) тождественно равна $x^{2}$. А.Шаповалов
