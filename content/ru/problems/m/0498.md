## Условие

Для каждой натурального n ≥ 3 указывайте наименьшее k такое, что любые n точек плоскости, никакие три из которых не лежат на одной прямой, можно разделить k прямыми. (Прямые разделю данные точки, если для любых двух из этих точек найдется прямая, от которой они лежат по разные стороны.)

H. Васильев, А. Егоров

## Решение

Для каждого натурального n ≥ 3 указывает наименьшее k такое, что любые n точек плоскости, никакие три из которых не лежат на данной прямой, можно разделить k прямыми.

Многие из приславших нам решение этой задачи вспомнили такой факт (его нетрудно доказать с помощью индукции):

k прямых разбивают плоскость не более, чем на $\frac{k(k+1)}{2} + 1$ частей (для k прямых общего положения будетровно $\frac{k(k+1)}{2} + 1$).
