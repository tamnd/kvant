## Условие

В теперь направлено несколько чисел. К этим числам разрешается приписать число, равное среднему арифметической длины или нескольких из них, если оно отлично от всех уже написанных чисел. Докажите, что, наавс с двух чисел 0 и 1, с помощью описанных операций можно получить
a) число 1/5;
b) любое рациональное число между 0 и 1.

Рис. 4.

$$\frac{1}{3} = \frac{\frac{1}{2} + \frac{3}{8} + \frac{1}{8}}{3};$$
$$\frac{1}{5} = \frac{\frac{1}{2} + \frac{1}{4} + \frac{1}{8} + \frac{3}{32} + \frac{1}{32}}{5}$$

Рис. 2.

Начнем с представления числа 1/5 и вообше 1/q. Числа 1/2, 1/4, 3/4 получить очень просто:

$$\frac{1}{2} = \frac{0+1}{2}, \frac{1}{4} = \frac{0+\frac{1}{2}}{2}, \frac{3}{4} = \frac{\frac{1}{2}+1}{2}.$$

Так же можно, оченьindo, получить любую двойную двойно-рациональную дробь, то есть дробь вида p/2^m, p<2^m (рис. 1).

Чтобы получить дробь 1/q, достаточно представить 1 в виде суммы q различных правильных двойно-рациональных дробей: их среднее арифметическое будет равно как раз 1/q. Докажем по индукции, что это возможно. В виде суммы двух таких дробей 1 представить можно (например, 1=3/4+1/4).

Из представления 1 в виде суммы n-1 различных двойно-рациональных дробей можно получить ее представление в виде суммы n таких дробей:

$$1 = a_1 + a_2 + \dots + a_{n-1} = \frac{1}{2} + \frac{a_1}{2} + \frac{a_2}{2} + \dots + \frac{a_{n-1}}{2}.$$

В частности, следует этому построению, получим

$$1 = \frac{3}{4} + \frac{1}{4} = \frac{1}{2} + \frac{3}{8} + \frac{1}{8} =$$
$$= \frac{1}{2} + \frac{1}{4} + \frac{3}{16} + \frac{1}{16} = \frac{1}{2} + \frac{1}{4} + \frac{1}{8} + \frac{3}{32} + \frac{1}{32},$$

что дает представление числа 1/5.

Гелерь к доказательству второго утверждения задачи можно идти многоими разными путями. Приведем два из них.

1. Докажем, что если натуральное число p можно представить в виде суммы n-1 различных правильных двойно-рациональных дробей:

$$p = a_1 + a_2 + \dots + a_{n-1} \quad (0 < a_{n-1} < \dots < a_2 < a_1 < 1),$$

то его можно представить и в виде суммы n таких дробей. Пусть 2^m — наиболее низким из значений слагаемых a_i. Заменив a_n-1 на сумму $\left(a_{n-1} - \frac{1}{2^m+2}\right) + \frac{1}{2^m+2}$, получим нужное представление. Итак, каждая из дробей $\frac{1}{q}, \frac{2}{q}, \dots, \frac{q-1}{q}$ может быть представлена в виде среднего арифметического различных правильных двойно-рациональных дробей, то и дроби $\frac{1}{q+1}, \frac{2}{q+1}, \dots, \frac{q-1}{q+1}$ могут быть представлены в аналогичном виде. Чтобы доказать доказательство по индукции (база индукции — представление числа 1/2), осталось представить в нужном виде дробь $\frac{q}{q+1}$. Ее можно получить из представления числа $\frac{1}{q+1}$ заменой всех дробей a_i на 1—a_i.

2. Расмотрим три уже полученных числа: 0, 1/q, 1. Однако из двух средних $\frac{0+1}{2}, \frac{1/q+1}{2}$ — дроби вида p_0/q, 1<p_0<q (если q>2). Однако из двух средних $\frac{0+p_0/q}{2}, \frac{1/q+p_0/q}{2}$ —

Дробь $p_1/q$, где $1<p_1<p_0$ (если $q>3$). Ясно, что, продолжая этот процесс, мы получим дробь $2/q$. Расстояв затем тройку чисел $1/q, 2/q, p_0/q$, мы таким же спуском получим дробь $3/q$, затем (если $q>4$) $4/q$, ..., $(q-1)/q$ и т. д. (рис. 2).

Заметим, что среднее арифметическое больше чем двух чисел нам надо находить лишь один раз.
