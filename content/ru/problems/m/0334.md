## Условие

Дан многочлен $P(x)$ с a) натуральными коэффициентами, b) * целыми коэффициентами.

⟦folio 41⟧

Для каждого натурального числа $n$ через $a_n$ обозначим сумму цифр в десятичной записи числа $P(n)$. Докажите, что найдет число, которое встречается в последовательности $a_1, a_2, a_3, \ldots$ бесконечное число раз. (9 кл.)

И. Н. Берништейн

## Решение

Дан многочлен P (x):
а) с натуральными коэффициентами,
б) с целыми коэффициентами.
Для каждого натурального числа п через aₙ обозначим сумму цифр в десятичной записи числа P (n). Докажите, что найдется число, которое встречается в последовательности a₁, a₂, a₃, ... бесконечное число раз.

Пусть P(x) = cₙxᵙ + cₙ-1xᵙ-1 + ... + c₁x + c₀, cₙ ≠ 0.
a) Числа cₙ, cₙ-1, ..., c₁, c₀ — неотрицательны.
Рассмотрим такое натуральное число l, что 10ᵀ больше чисел cₙ, cₙ-1, ..., c₁, c₀. Тогда в десятичной записи числа aᵢ = P(10ᵀ) будет сначала идти цифры числа cₙ, затем нулы; затем цифры числа cₙ-1 — опять нулы; цифры числа cₙ-2 — нулы и т. д. Таким образом, сумма цифр числа aᵢ = P(10ᵀ) равна сумме S цифр всех чисел cₙ, cₙ-1, ..., c₁, c₀. Рассуждая аналогично, мы видим, что

S = сумма цифр a₁₀l+1 = сумма цифр a₁₀l+2 = ...,
t. е. число S встречается в последовательности a₁, a₂, ... бесконечное число раз.

6) Заменив, если нужно, P (x) на — P (x), мы можем считать, что cₙ > 0. Пусть m — какое-то натуральное число. Положим Q (x) = P (x + m) = cₙ (x + m)ᵙ + cₙ-1 (x + m)ᵙ-1 + ... + c₁ (x + m) + c₀. Раскрыв скобки и приведя подобные члены, мы видим, что Q (x) — многочлен с целыми коэффициентами. Если bₖ — сумма цифр числа |Q(k)|, то ясно, что bₖ = aₖ+m. Поэтому нам достаточно подобрать число m так, чтобы все коэффициенты многочлена Q (x) были неотрицательны; тогда неокторое число будет бесконечное число раз встречается в последовательности b₁, b₂, ... и, значит, встречается бесконечное число раз и в последовательности a₁, a₂, ... Покажем, что для этого нам достаточно взять любое число m, строго больше всех чисел |cₙ-1|, |cₙ-2|, ..., |c₀|. Действительно,

P (x) = (cₙ - 1)xᵙ + (x + cₙ-1 - 1)xᵙ-1 + (x + cₙ-2 - 1)xᵙ-2 + ... + (x + c₀ - 1) + 1.

Найдем такое наиболее возможное значение числа $A = \sum_{k=1}^{7} a_k$, чтобы последнее неравенство все еще было верным. Нетрудно доказать (мы сделаем это ниже), что

$$\sum_{k=1}^{7} a_k^2 \geq \frac{1}{7} \left( \sum_{k=1}^{7} a_k \right)^2 = \frac{1}{7} A^2;$$

тогда из неравенства (**) следует, что

$$\frac{1}{7} A^2 - A \leq \sum_{k=1}^{7} a_k^2 - \sum_{k=1}^{7} a_h \leq 42,$$

или $$\frac{1}{7} A^2 - A \leq 42,$$ или $$A^2 - 7A \leq 294,$$ то есть $(A - 21)(A + 14) \leq 0$, откуда $A \leq 21$.

Доказательство для квадрата $13 \times 13$ клеток проводится аналогично, и мы советем читательм проделать все выкладки самостояльно.

Сейчас мы доказем (для любых $n \geq 1$, $a_k \geq 0$, $k = 1, 2, \dots, n$) неравенство

$$\sum_{k=1}^{n} a_k^2 \geq \frac{1}{n} \left( \sum_{k=1}^{n} a_k \right)^2.$$

Для удобства выкладок положим $na = \sum_{k=1}^{n} a_k$ и доказем, что $\sum_{k=1}^{n} a_k^2 \geq na^2$. Обозначим разность между числом $a_k$ и средним значением $a$ чисел $a_k$ через $\varepsilon_k: \varepsilon_k = a_k - a$. Тогда

$$na = \sum_{k=1}^{n} a_k = \sum_{k=1}^{n} (a + \varepsilon_k) = na + \sum_{k=1}^{n} \varepsilon_k,$$

и поэтому

$$\sum_{k=1}^{n} \varepsilon_k = 0.$$

Отсюда следует:

$$\sum_{k=1}^{n} a_k^2 = \sum_{k=1}^{n} (a + \varepsilon_k)^2 =$$

$$= \sum_{k=1}^{n} a^2 + 2a \sum_{k=1}^{n} \varepsilon_k + \sum_{k=1}^{n} \varepsilon_k^2 = na^2 + \sum_{k=1}^{n} \varepsilon_k^2 \geq na^2.$$

В заключение следует одно замечание. В условиях задания мы обошли молчанием тот факт, что правильные квадраты из $7 \times 7$, $13 \times 13$ (вобше, $(m^2 + m + 1) \times (m^2 + m + 1)$, где $m = 2, 3, \dots$) клеток допускают красивое геометрическое истолкование.
