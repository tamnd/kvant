## Условие

По гладкому столу движется, быстро врашаясь вокруг своей оси, волчок, имеющий форму конуса (рис. 2). При какой скорости $v$ поступательного движения волчок не ударится о край стола, сосочив с него? Ось волчка остается вертикальной. Размеры волчка указаны на рисунке 2. (8)

А. Зильберман

## Решение

По главному столу движется, быстро врачаясь воркут свое оси, волокок, имеющий форму конуса (см. рисунок). При какой скорости v поступательного движения волокок не ударится о край стола, сосочив с него? Ось волока остается вертикальной. Размеры волка указаны на рисунке.

Соскочив со стола, волокок будет двигаться по параболе (вращение лишь стабилизирует вертикальное положение оси волка). Горизонтальная проекция $v_x$ скорости волка будет равна скорости $v$ его поступательного движения по столе; вертикальная проекция будет меняться со временем по закону $v_y = gt^2/2$. Волокок не ударится о край стола, если за время $t$, за которое он сместится по вертикали на $H$, его смещение по горизонтали будет больше или равно $r$ (см. рисунок). Запишем это условие:

$$v_x\tau = v\tau \geq r, \quad \tau = \sqrt{\frac{2H}{g}}.$$

Таким образом, скорость поступательного движения волка должна удовлетворять условию:

$$v \geq \sqrt{\frac{r^2g}{2H}}.$$
