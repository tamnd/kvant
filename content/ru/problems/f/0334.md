## Условие

Бусинка сокальзывает без трения по вертикальной расположенной проволоке длины $l$, которая изогнута в гармошу длины $\frac{l}{2}$ (рис. 4). Во сколько раз время сокальзывания бусинки больше времени ее падения с высоты $l$? Амплитуда перегибов проволоки много меньше ее длины. Размеры бусинки пренебрежимо малы по сравнению с длиной «колена» гармошки.

Б. Н. Брейзман

## Решение

*) Бусинка сскальзывает без трения по вертикальной расположенной проводке длины $l$, которая изозначена в гармонику длины $l/2$. Во сколько раз время сскальзывания бусинки больше времени ее padения с высоты $l$? Амилитуда перешобов проводки много меньше ее длины. Размеры бусинки пребрежимо малы по сравнению с длиной «колена» гармоники.

При перехождение бусинки с одного прямолинейного участка проводки на другой абсолотная вершина ее скорости не меняется. Меняется только направление скорости бусинки: она становится параллельной новому участку проводки. Это означает, что время движения бусинки по проводке также же, как при движении бусинки по наклонной плоскости — развертке проводки. Это время равно

$$t = \sqrt{\frac{2l}{g \sin \alpha}} = \sqrt{\frac{2l}{gh/l}} = 2 \sqrt{\frac{l}{g}}$$

($l$ — длина наклонной плоскости, $\alpha$ — угол наклона плоскости к горизонту), т. е. оно в $\sqrt{2}$ раз больше времени

$$t' = \sqrt{\frac{2l}{g}}$$Padения бусинки с высоты $l$.

И. Ш. Слободецкий
