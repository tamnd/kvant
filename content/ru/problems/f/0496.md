## Условие

В цилиндрический конденсатор в точке $A$ впускается слегка расходящая пучок положительныхонов с малым углом растора $\alpha$ (рис. 3). Все они в пучке имеют одинаковую энергию. Те онны, у которых вектор скорости в точке $A$ направлен перpendикулярно $AO$, движется по окружности радиуса $|AO|=r_0$, концентрической с обкладками конденсатора. Доказать, что пучок оннов будет фокусироваться в точке $B$ такой, что $\widehat{AOB} = \pi \sqrt{2}$. Определить максимальный ширину пучка.

## Решение

В цилиндрической конденсатор в точке А впускается следа расходящей лучок положимельных юнов с малым углом расстройа $\alpha$ (рис. 28). Все они в пучке имеем одинаковую энергию. Те они, у которых вектор скорости в точке А направлен перендикулярно АO, движутся по окружности радиуса $AO=r_0$, концентрической с обкладками конденсатора. Доказать, что пучок юнов будет фокусироваться в точке В макой, что $\widehat{AOB} = \pi/\sqrt{2}$. Определить максимальный цирину пучка.

Из рисунка видно: $h_1 = R \cos \alpha + R \cos (\pi - \alpha - \alpha_1) = R [\cos \alpha - \cos (\alpha + \alpha_1)]$ и $h_2 = R \cos \alpha - R \cos (\alpha_2 - \alpha)$, где $R$ – радиус колыца. Подставляя эти выражения для $h_1$ и $h_2$ в равенство (1), найдем $(\rho_1 - \rho_3) [\cos \alpha - \cos \alpha \cos \alpha_1 + \sin \alpha \sin \alpha_1] = (\rho_2 - \rho_3) [\cos \alpha - \cos \alpha_2 \cos \alpha - \sin \alpha_2 \sin \alpha]$, или $(\rho_1 - \rho_3) (1 - \cos \alpha_1 + \sin \alpha_1 \tg \alpha) = (\rho_2 - \rho_3) (1 - \cos \alpha_2 - \sin \alpha_2 \tg \alpha)$. Решая это уравнение, найдем $\tg \alpha = \frac{(\rho_1 - \rho_3) (1 - \cos \alpha_1) - (\rho_2 - \rho_3) (1 - \cos \alpha_2)}{(\rho_1 - \rho_3) \sin \alpha_1 + (\rho_2 - \rho_3) \sin \alpha_2}$.

Для того чтобы можно было изучить движениеонов, необходимо прежде всего выяснить, какая сила действует на он в электростанческом поле цилиндрического конденсатора, то есть выяснить, какова направность электростанческого поля конденсатора.

Напряжение поля пропорциональна плотности сливых линей. Если через дугу с единичным углом проходит $n$ сливых линей, то через дугу с углом $\varphi$ проходит $N = n\varphi$ сливых линей. Плотность сливых линей, пересекающих дугу радиуса $r$, равна отношению числа $N$ к длине $r\varphi$ дуги, то есть равна $\frac{n}{r}$ (рис. 29).

Следовательно, напряжение поля конденсатора $\frac{1}{r}$:

$$E = -\frac{b}{r}, b = \text{const.}$$

В таком поле на заряд $q$, находящейся на расстоянии $r$ от конденсатора, действует сила $\vec{F}$ тakaя, что

$$|\vec{F}| = \frac{bq}{r}.$$

Эта сила сообщает заряду ускорение $a$, равное по modulo

$$|\vec{a}| = \frac{bq}{rm},$$

где $m$ – масса заряда.

Обозначим $x$ отклонение она от основной траектории радиуса $r_0$ (эта траектория показана на рисунке 28 красной линей). Тогда $r = r_0 + x$, и

$$|\vec{a}| = \frac{bq}{m(r_0 + x)}.$$

Рассмотрим движение она в системе отсечета, выраженной вокруг оси конденсатора так, что угловая скорость ее в каждой момент равна угловой скорости $\omega$ отклонившегося она. В этой системе ускорение уже не равно $a$, так как все точки тоже движутся с некоторым ускорением относительно неподвижной системы отсечета, связанной с осью конденсатора. Точка, находящаяся на расстоянии $r_0 + x$ от оси, движется с центромтельным ускорением $\|\vec{a}_\mu\| = \omega^2(r_0 + x)$.

Следовательно, во врашающей системе отчета ускорение нана равно

$$\left| \vec{a}_{\text{OTH}} \right| = - \left| \vec{a} \right| + \left| \vec{a}_{\text{II}} \right| = - \frac{bq}{m(r_0+x)} + \omega^2(r_0+x).

$$\text{ИЗ закона сохранения момента импульса следует, что}

$$m(r_0+x)^2\omega = mr_0^2\omega_0,

$$\text{где } \omega_0 \text{-угловая скорость нана в точке } A. \text{ Она же равна и угловой скорости нана, движущемся по «красной» траектории. Но центростремительное ускорение } \left| \vec{a}_0 \right| = \omega_0^2 r_0 \text{ ину, движущемся по «красной» траектории радиуса } r_0, \text{ сообщает сила } \vec{F}, равная по модулю } \frac{bq}{r_0}, \text{ поэтому}

$$\omega_0^2 r_0 = \frac{bq}{mr_0}, \text{ и } \omega_0^2 = \frac{bq}{mr_0^2}.

\text{Takим образом,}

$$\left| \vec{a}_{\text{OTH}} \right| = - \frac{bq}{m(r_0+x)} + \frac{bq}{mr_0^2}(r_0+x) \frac{r_0^4}{(r_0+x)^4} =

= \frac{bq\left[r_0^2-(r_0+x)^2\right]}{m(r_0+x)^3} = \frac{bq\left(-2r_0x-x^2\right)}{m(r_0+x)^3}.

\text{При } x << r_0

$$\left| \vec{a}_{\text{OTH}} \right| = -2 \cdot \frac{bq}{mr_0^2} x.

\text{Мы видим, что}

$$m\left| \vec{a}_{\text{OTH}} \right| = -kx, \text{ где } k = 2 \cdot \frac{bq}{r_0^2}.

\text{Как известно, при такой зависимости ускорения тела от смешения тела совершает гармоничческие колебания с периодом } T = 2\pi\sqrt{\frac{m}{k}}. \text{ Следовательно, они пучка, скорость которых в точке } A \text{ составляет малый угол } \alpha \text{ со скоростью инов, движущемся по основной траектории, будут совершать относительно основной траектории радиальные гармоничские колебания с периодом}

$$T = 2\pi\sqrt{\frac{mr_0^2}{2bq}}.

\text{Этот период одинаков для всех инов. Значит, после того как инов попадают в конденсатор в точке } A \text{ через времена } t_n = n\frac{T}{2}(n=1,2,3,\dots), \text{ все инов будут оказаться в одной и той же точке основной траектории — будут фокусироваться. Нетрудно найти угол } \varphi_0 \text{ между последовательными фокусами:}

$$\varphi_0 = \omega_0 t = \omega_0 \frac{T}{2} = \sqrt{\frac{bq}{mr_0^2}} \cdot \pi \sqrt{\frac{mr_0^2}{2bq}} = \frac{\pi}{\sqrt{2}}.

\text{Takим образом, если } \widehat{AOB} = \pi/\sqrt{2}, \text{ то ионы будут фокусироваться в точке } B.

\text{Найдем теперь максимальную ширину пучка. Для этого воспользуемся тем, что максимальное абсцистические значение скорости тела, совершающего гармоничские колебания, и амплитудa } x_{\text{max}} \text{ его колебаний связи}

соответнием

$$|\vec{v}|_{\max} = x_{\max} \Omega,$$

где $\Omega = 2\pi/T$ — частота колебаний. В нашем случае
$$|\vec{v}|_{\max} \text{ равно значению радиальной проекции скорости в точке } A \text{ иона (рис. 30):}$$
$$|\vec{v}|_{\max} = |\vec{v}_0| \sin \frac{\alpha}{2} = \omega r_0 \sin \frac{\alpha}{2} \approx \frac{1}{2} \omega r_0 \alpha$$
(так как $\alpha$ мало, $\sin \frac{\alpha}{2} \approx \frac{\alpha}{2}$). Позному
$$\frac{1}{2} \omega r_0 \alpha = x_{\max} \frac{2\pi}{T}.$$

Следовательно, максимальная ширина $d$ пучка равна
$$d = 2x_{\max} = \frac{\omega r_0 \alpha T}{2\pi} = \frac{r_0 \alpha}{\sqrt{2}}.$$
