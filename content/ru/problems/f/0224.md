## Условие

По деревянным сходям, образующим угол α с горизонтом, вставкают за вервку ящик. Козффициент трения ящика о сходии μ. Под каким углом к горизонту следует направить вервку, чтобы с наименьшим числом вставкать ящик: a) равномерно, 6) с заданнымускорением a? (8, 10 кл.)

## Решение

По деревянным скодням, образующим угол $\alpha$ с горизонтом, вмackивающим за вервку ящик. Коэффициент трения ящика о скодни $\mu$. Под каким углом к горизонту следует направить вервку, чтобы с наименьшим числом вмackиваемых ящик: а) равномерно, б) с заданным ускорением $a$?

Рассмотрим силы, действующие на ящик (рис. 14). Это — сила тяжесте mg, сила натяжения вервки F, сила реакции скодней N и сила треня F_Tp, величина которого F_Tp = μN. Спроектируем все силы на направление вдоль скодней и перpendикулярно к ним и запишем соответствующее уравнение движения.

Так как ящик не перемещается в направлении, перpendикулярном к скодням, то сумма проекций сил на это направление

$$\text{Рис. 14}$$

должна быть равна нулю, то есть
$$N + F \sin(\beta - \alpha) - mg \cos \alpha = 0.$$ (1)

Вдоль скодней ящик движется с ускорением $a$ (в частином случае при равномерном движении $a = 0$), поэтому сумма проекций сил должны равна ma:

$$F \cos(\beta - \alpha) - mg \sin \alpha - \mu N = ma.$$ (2)

Из уравнений (1) и (2)

$$F = \frac{ma + mg(\sin \alpha + \mu \cos \alpha)}{\cos(\beta - \alpha) + \mu \sin(\beta - \alpha)}.$$ (3)

В полученное выражение для силы F угол $\beta$ входит только в значатель. Следовательно, величины силы F будут минимальным при таком значении угла $\beta$, при котором значатель в формуле (3) максимален, то есть максимальная уравнение движения.

$$\cos(\beta - \alpha) + \mu \sin(\beta - \alpha).$$

Сделаем некоторые преобразования. Представим коэффициент трения $\mu$ как тангенс некоторого угла $\gamma$:

$$tg \gamma = \mu; \quad \gamma = \arctg \mu;$$

$$\sin \gamma = \frac{\mu}{\sqrt{1 + \mu^2}}; \quad \cos \gamma = \frac{1}{\sqrt{1 + \mu^2}}.$$

Тогда можно записать:

$$\cos(\beta - \alpha) + \mu \sin(\beta - \alpha) = \sqrt{1 + \mu^2} \cos(\beta - \alpha - \gamma).$$

После нее выражение максимальное и равное $\sqrt{1 + \mu^2}$ при $\beta - \alpha - \gamma = 0$, то есть при $\beta = \alpha + \gamma = \alpha + \arctg \mu.$ (4)

При таком значении угла $\beta$ и минимальная сила F. Причем, если ящик движется равномерно ($a = 0$), то

$$F_{\min} = \frac{mg(\sin \alpha + \mu \cos \alpha)}{\sqrt{1 + \mu^2}},$$

а при движении с ускорением $a$

$$F_{\min} = \frac{ma + mg(\sin \alpha + \mu \cos \alpha)}{\sqrt{1 + \mu^2}}.$$

Однако это решение верно не для любого ускорения. Так как направление силы F не зависит от $a$, а абсолотная величина силы F увеличивается с увеличением ускорения, то при некотором значении ускорения $a = a_0$ сила F становится такой, что ее составляющая $F \sin(\beta - \alpha)$, перpendикулярная к наклонной плоскости, будет равна по абсолотной величины составляющей силы тяжесте $mg \cos \alpha$. При этом обратится в нуль как сила N, так и сила $F_{\text{Tp}}$. В дальнейшем (при $a > a_0$) для того чтобы не оторвался от положев, направление силы F должно меньше с увеличением ускорения $a$ так, чтобы составляющая силы F, перpendикулярная

к наклонной плоскости, оставалась равной составляющей силы тяжесте, то есть
$$F \sin(\beta - \alpha) = mg \cos \alpha.$$
Для составляющих этих сил, параллельных наклонной плоскости, можно записать
$$F \cos(\beta - \alpha) = mg \sin \alpha = ma.$$
Из двух последних равенств найдем:
$$tg(\beta - \alpha) = \frac{g \cos \alpha}{g \sin \alpha + a},$$
откуда
$$\beta = \alpha + arctg \frac{g \cos \alpha}{g \sin \alpha + a}.$$
Величину $a_0$ можно найти из тех сообщений, что при $a = a_0$ значение угла $\beta$ из (4) и (5) совпадает:
$$\alpha + arctg \frac{g \cos \alpha}{g \sin \alpha + a_0} = \alpha + arctg \mu,$$
откуда
$$a_0 = g \left( \frac{\cos \alpha}{\mu} - \sin \alpha \right).$$
Итак,
при $a \leq a_0$ (следовательно, и при равномерном движении тоже)
$$\beta = \alpha + arctg \mu,$$
при $a > a_0$
$$\beta = \alpha + arctg \frac{g \cos \alpha}{g \sin \alpha + a}.$$
Мы решили задачу. Однако, приведем еще одно решение. Это — красивое геометрическое решение.
При равномерном движении вдоль сходней сумма всех сил должны равна нулю. Заменим силы $N$ и $F_{TP}$ их равнойствующей $Q = N + F_{TP}$ (рис. 14) и будем складывать силы $Q$, $F$ и $mg$. Они должны образовать замкнутый треугольник.
Заметим, что направление силы $Q$ составляет с перpendикуляром к наклонной плоскости угол $\delta$ такой, что
$$tg \delta = \frac{F_{TP}}{N} = \frac{\mu N}{N} = \mu,$$
то есть при изменении величины и направления силы $F$ направление силы $Q$ остается неизменным. Следовательно, абсолотная величина вектора $F$ будет минимальная, если он перепendlкулярен к вектору $Q$ (рис. 15) (так как величина и направление вектора $mg$ не меняются). При этом с горизонтом силы $F$ будет составлять угол
$$\beta = \alpha + \delta = \alpha + arctg \mu$$
(углы $\beta$ и $\alpha + \delta$ равны как углы с взаимно перепendlкулярными сторонами).
Точно так же решается задача, когда ящик движется сускорением $a < a_0$. В этом случае сумма векторов $mg$, $Q$ и $F$ должны равна $ma$ (рис. 16). Это изменит абсолотную величину силы $F$, но не изменит ее направления.
При $a > a_0$, когда силы $N$, $F_{TP}$, $a$, следовательно, и $Q$ равны нулю, сила $F$ должна соединяться концы векторов $mg$ и $ma$ (рис. 17). Легко видеть, что в этом случае
$$\beta = arctg \frac{g + a \sin \alpha}{a \cos \alpha} = \alpha + arctg \frac{g \cos \alpha}{g \sin \alpha + a}.$$
