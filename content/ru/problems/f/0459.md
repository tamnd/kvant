## Условие

Электроплита содержит три спирали с сопротивлением $R=120$ ом каждый, соединенные паралельно друг с другом. Плита включается в себя последовательное срезistorом $r=50$ ом. Как изменится, время, необходимое для нагрева на этой плитке чайника с водой до кипения, при переогранении одной из спиралей?

Н. Словодечкий

## Решение

Электрополитка содержит три спирали с сопротивлением $R=120$ Ом каждый, соединенные параллельно друг с другом. Плимка включается в семь последовательно с сопротивлением $r=50$ Ом. Как изменится время, необходимое для нарезания на этой спирали с водой до кипения, при перегорании одной из спиралей?

Рис. 13.

Пусть $v_0$ — скорость течения реки, $v_1$ — скорость мальчика относительно течения. Тогда скорость мальчика относительно берега равна

$$v = v_0 + v_1.$$

Вектор скорости мальчика относительно течения может иметь различные направления, но его конец должен обязательно лежать на окружности радиуса $|v_1|$ (рис. 13). Из рисунка видно, что вектор $v$ составляет минимальный угол с береговой линией в том случае, когда он направлен по касательной к окружности — геометрическому месту концов возможных векторов $v_1$. В этом случае мальчик, очевидно, будет снесен течением на минимальное возможное расстояние. Из рисунка найдем, что при этом мальчик должен плыть под углом к береговой линии, равным

$$\alpha = \arccos \frac{|v_1|}{|v_0|} = \arccos \frac{1}{2} = 60^\circ.$$

О. Савченко

Сопротивление плитки с тремя параллельно соединенными спираями равно $R_1 = R/3 = 40$ Ом. После перегорания одной спирали сопротивление плитки становится $R_2 = R/2 = 60$ Ом.

Do перегорания спирали по цепи идет ток $I_1 = \frac{U}{R_1 + r}$ (U — напряжение сети). После перегорания — $I_2 = \frac{U}{R_2 + r}$.

Количество теплоты $Q$, необходимое для нарезания чайника с водой до кипения, в первом случае выделяется в плитке за время

$$t_1 = \frac{Q}{I_1^2 R_1} = \frac{Q (R_1 + r)^2}{U^2 R_1},$$

во втором случа — за время

$$t_2 = \frac{Q}{I_2^2 R_2} = \frac{Q (R_2 + r)^2}{U^2 R_2}.$$

Найдем относение времени $t_1$ и $t_2$:

$$\frac{t_1}{t_2} = \frac{(R_1 + r)^2 R_2}{(R_2 + r)^2 R_1} = \frac{243}{242}.$$

Отсюда $t_2 = \frac{242}{243} t_1$.
