## Условие

Самолеты летят по одной прямой навстречу друг другу с одинаковой скоростью $v$. Предельная дальность обнаружения — $l$. Один самолет после

обнаружения другого совершает разворот, не меняя значения скорости, и летит паралельно второму самолету, который продолжает лететь со скоростью $\vec{v}$. Потеряют ли самолеты друг друга из виду после разворота, если ускорение при повороте равно $a$? Спустя какое время после обнаружения надо начинать разворот, чтобы в конце разворота расстояние между самолетами оказалось наименьшим?

## Решение

Самолеты летят по одной прямой навстречу друг друга с одинаковой скоростью v. Предельная дальность обнаружения — l. Однако самолет после обнаружения другого совершает разворот, не меняя значения скорости, и летит параллельно второму самолету, который продолжает лететь со скоростью $\vec{v}$. Потеряют ли самолеты друг друга из виду после разворота, если ускорение при повороте равно a? Спустя какое время после обнаружения надо начинать разворот, чтобы в конце разворота расстояние между самолетами оказалось наименьшим?

$$L^2 = x^2 + y^2 = (l - \pi R - 2v\tau)^2 + 4R^2.$$

Понятно, что значение $L$ (τ) минимально при минимальном возможном значении $|x(\tau)|$ (y не зависит от τ). В связи с этим возникют два случая: при $l \geqslant \pi R$ начинающее $L = 2R$ достигается при $x=0$, то есть когда

$$\tau = \frac{l - \pi R}{2v} = \frac{1}{2} \left( \frac{l}{v} - \frac{\pi v}{a} \right);$$

при $l < \pi R$ значение $L$ минимально при $\tau=0$ и равно $L = \sqrt{4R^2 + (l - \pi R)^2}$.

В случае $l \geqslant \pi R$ начинающее $L = 2R$ завершено пределной дальности обнаружения. Найдем, при каком направлении $l = l_0$ самолеты останут еще в пределах видимости после разворота, то есть когда

$$L^2 = 4R^2 + (l_0 - \pi R)^2 = l_0^2.$$

Разрешая это уравнение относительно $l_0$, получим

$$l_0 = \frac{4 + \pi^2}{2\pi} R = \frac{4 + \pi^2}{2\pi} \frac{v^2}{a}.$$

Итак, при $l \geqslant l_0$ самолеты не потребляют друг друга из виду. В противоположном случае ($l < l_0$) после разворота они оказываются вне пределов обнаружения.

И. И. Воробье
