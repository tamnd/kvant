## Условие

Для дальнейки космической связи используется спутник объемом V=100 $m^3$, наполненный воздуха при нормальных условиях. Меторит проводает в его корпусе ответные площадью S=1 $cm^2$. Оценить время, через которое давление внутри спутника изменится на 1%. Температуру газа считать неизменной. Универсальная газовая постоянная равна 8,3 дж/средом моль. (9 кл.)

А. Р. Зильберман

## Решение

Для дальнейки космической связи используется спутник обтемом $V=100$ м³, наполненный воздуха при нормальной условиях. Метерорим пробиваем в его корпусе отвергшие площадь $S=1$ см². Оценить время, через которой давление внутри спутника изменится на 1%. Температур газа ситам неизменной. Универсальная газовая постоянная равна 8,3·10³ дж/град·кмоль.

Для оценки можно принять, что каждая из молекул воздуха в спутнике может двигаться только вдоль одной из трех взаимно-перендикулярных осей, одна из которых перендикулярна плоскости отвергтия (такая прощенная модель часто используется в кинетической теории газов). Тогда вдоль этой оси движется в любой момент 1/3 часть всех молекул воздуха в спутнике, причем скорость половины этих молекул, то есть 1/6 часть всех молекул, направлена к отвергнию. Из них за время $t$ отвергится до стигнут и вылетят из спутника те молекулы, которые находятся от отвергния на расстоянии $l = \bar{v}t$, то есть молекулы, находящие в начальной момент в объеме $V_0 = S\bar{v}t$, где $\bar{v}$ — средняя квадратная скорость молекул (рис. 18). (Мы принимаем для оценки, что все молекулы движутся с одинаковыми по абсцилотной величины скоростями, равными средней квадратной скорости $\bar{v}$). Если число молекул в единице объема равно $n$, то всего за время $t$ из спутника вылетит

$$N = \frac{1}{6} S\bar{v}t n \text{ молекул.}$$

Поскольку молекул вылетела из спутника, изменится число молекул в единице объема. Это изменение есть

$$\Delta n = \frac{N}{V} = \frac{1}{6} \frac{S\bar{v}t n}{V}.$$

Это соответствие можно переписать в виде

$$\frac{\Delta n}{n} = \frac{1}{6} \frac{S\bar{v}t}{V}$$

или

$$\tau = 6 \frac{\Delta n}{n} \frac{V}{S\bar{v}}.$$

По условию задачи температура воздуха в спутнике остается неизменной. Как следует из уравнения состояния идеального газа Клапейрона — Мендлеева, в этом случае давление пропорционально плотности газа (а следовательно, и числу молекул в единице объема): $P \sim n$. Поэтому

$$\frac{\Delta P}{P} = \frac{\Delta n}{n} = 0,01.$$

Принимая во внимание выражение для средней квадратной скорости молекул

$$\bar{v} = \sqrt{\frac{3RT}{\mu}},$$

Решение. В данном случае пусть решения подсказывается симметрией данного уравнения относительно sin x, cos x. Выделяя в явном виде простейшие симметрические многочлены относительно sin x и cos x (выражения sin x + cos x, sin x · cos x), запишем уравнение в виде

$$(\sin x + \cos x) - 4 \sin x \cdot \cos x + \sin x \cdot \cos x (\sin x + \cos x) = 2.$$

Пусть sin x + cos x = u; тогда $u^2 - 1 = 2 \sin x \cdot \cos x$ и уравнение при метве вид

$$u (u^2 - 4 u + 1) = 0,$$

откуда $u_1 = 0, u_2 = 2 + \sqrt{3}, u_3 = 2 - \sqrt{3}$.

Уравнение sin x + cos x = u легко решается, причем, так как |u| = |sin x + cos x| = |\sqrt{2} \cos \left( x - \frac{\pi}{4} \right)| \leqslant \sqrt{2}, то корень $u_2 = 2 + \sqrt{3}$ не подходит.

Ответ: $x = -\frac{\pi}{4} + k\pi; x = \frac{\pi}{4} \pm \arccos \frac{2 - \sqrt{3}}{\sqrt{2}} + 2l\pi$.

Следующая группа примеров показывает, что для успешного решения предлагаемых на применных экзаменах задач недостаточно уметь свести уравнение к одному из известных типов (уравнения, приводимые к одной тригонометрической функции, однородные, симметрические и др.).

Пример 4 (МФТИ, 1970). Решить уравнение

$$\sin x + 2 \cos x = \cos 2x - \sin 2x.$$

Решение. Переходя в уравнение (1) к аргументу x с помощью формул sin 2x = 2 sin x cos x и cos 2x = $\cos^2 x - \sin^2 x = 1 - 2 \sin^2 x$, получаем

$$\sin x + 2 \sin^2 x + 2 \cos x + 2 \sin x \cos x - 1 = 0.$$

Уравнение (2) можно было бы свести к алгебраической уравнению относительно u с помощью так называемой универсальной подставки $u = \mathrm{tg} \frac{x}{2}$, выразив sin x и cos x через u. Нетрудно убедиться, что в этом случае получается уравнение

$$3 u^4 + 2 u^3 - 6 u^2 - 6 u - 1 = 0.$$

Мы не будем находить корни этого уравнения, хотя это можно было бы сделать, а попытаемся найти более коротный пусть решения, в основе которого лежит разложение левой части уравнения на множители.

Уравнение (2) имеет корень sin x = -1 (при этом cos x = 0), поэтому левую часть уравнения можно разложить на множители:

$$(1 + \sin x)(2 \sin x + 2 \cos x - 1) = 0.$$

Ответ: $x = -\frac{\pi}{2} + 2k\pi; x = -\frac{\pi}{4} + (-1)^n \arcsin \frac{1}{2 \sqrt{2}} + \pi n$.

Замечание. Следует подчеркить, что метод разложения на множители в сочетании с другими методами является одним из наиболее эффективных примеров решения тригонометрических уравнений.

Прежде чем продвинутся в этом направлении дальше, сделаем по питьку упростить уравнение (7).

Замечая, что $tg^2 x + ctg^2 x = -2 + \frac{4}{\sin^2 2x}$, находим

$$\frac{1}{\sin^2 2x} = 1 - \frac{1}{\sqrt{3}} \frac{\cos 2x}{\sin 2x}$$

и далее, преобразовывая, получим $\sqrt{3} \cos^2 2x + \sin 2x \cdot \cos 2x = 0$. Последнее уравнение легко решается.

Ответ: $x = \frac{\pi}{4} + \frac{k\pi}{2}$; $x = -\frac{\pi}{6} + \frac{l\pi}{2}$ (легко проверяется, что при этих значениях $x$ имеем $\sin 2x \neq 0$).

Решение получено, однако для сравнения доведем до конца решения уравнения (7) первый пока привед нас к уравнению (8). Группировка членов, имеющих множитель $\sqrt{3}$, дает уравнение

$$(u^2 - 1) \left[ \sqrt{3} (u^2 - 1) - 2u \right] = 0,$$

которое имеет корни: $u_1 = 1; u_2 = -1; u_3 = \sqrt{3}; u_4 = -\frac{1}{\sqrt{3}}$.

Нетрудно проверить, что эти корни приводят к тому же ответу.

Замечание. Не вызывает сомнений, что в данном случае преобразование уравнения с помощью перехода к аргументу $2x$ является предпочтительным по сравнению с подстановкой $u = tg x$. Мы еще раз убедились в том, что передко увеличение аргумента тригонометрических функций, входящих в уравнение, ведет к его упрощению.

Рассмотрим пример другого типа.

Пример 8. Решить уравнение

$$tg (120^\circ + 3x) - tg (140^\circ - x) = 2 \sin (80^\circ + 2x).$$

Решение. При отыскании разумного пути решения уравнения (9), очевидно, следует обратить особое внимание на аргументы тригонометрических функций, входящих в уравнение. Связь между аргументами становится ясно, если заметить, что $tg (140^\circ - x) = -tg (x + 40^\circ)$. Тепер целесообразность использования замены $x + 40^\circ = t$ не вызывает сомнения. С помощью этой замены исходное уравнение преобразуется к виду $tg 3t + tg t = 2 \sin 2t$, или

$$\frac{\sin 4t}{\cos t \cdot \cos 3t} = 2 \sin 2t.$$

Так как $\sin 4t = 2 \sin 2t \cos 2t$, то уравнение (10) можно представить в виде

$$\frac{2 \sin 2t (\cos 2t - \cos 3t \cdot \cos t)}{\cos t \cdot \cos 3t} = 0.$$

Преобразуем выражение, стоящее в скобках, используя формулу

$$\cos 2t = \cos (3t - t) = \cos 3t \cdot \cos t + \sin 3t \cdot \sin t.$$

Тогда задача сведется к нахождению тех решений уравнения

$$\sin t \cdot \sin 2t \cdot \sin 3t = 0,$$

которые удовлетворяют условиям $\cos t \cdot \cos 3t \neq 0$, то есть к решению уравнения $\sin 3t = 0$.

Ответ: $x = -40^\circ + \frac{n\pi}{3}$.

Пример 9. Решить уравнение

$$\cos 3x + \cos \frac{5x}{2} = 2.$$

Решение. Если преобразовать левую часть данного уравнения по формуле суммы косинусов, то мы получим уравнение $\cos \frac{x}{4} \cdot \cos \frac{11x}{4} = 1$. Так как при любом $\alpha$ справедливо неравенство $|\cos \alpha| \leq 1$, то полученное уравнение может иметь решение лишь при выполнении условия

$$\begin{cases} \cos \frac{x}{4} = 1, \\ \cos \frac{11x}{4} = 1 \end{cases}$$ или $$\begin{cases} \cos \frac{x}{4} = -1, \\ \cos \frac{11x}{4} = -1. \end{cases}$$

Этим способом можно было бы найти решение исходного уравнения. Однако к целли приводит и другой, более простой путь.

Левая часть уравнения может равнять двум лишь в том случае, когда одновременно имеются место равенства $\cos 3x = 1$ и $\cos \frac{5x}{2} = 1$.

Находя решение первого уравнения ($x = \frac{2k\pi}{3}$) и подставляя во второе, получаем $\cos \frac{5k\pi}{3} = 1$, откуда $k = 6m$.

Ответ: $x = 4m\pi$.

В следующих примерах требуется уменение использовать понятие абсолотной величины.

Пример 10 (МФТИ, 1971). Решить уравнение

$$\text{tg}x + \frac{1}{9}\text{ctg}x = \sqrt{\frac{1}{\cos^2x} - 1} - 1.$$

Решение. Правую часть уравнения (11) можно записать так: $\sqrt{\text{tg}^2x} - 1 = |\text{tg}x| - 1$. Грубой ошибкой было бы отбрасывание знака модуля (к сожалению, немало абитурентов, решащих этот пример, допустило эту ошибку). Уравнение (11) принимает вид

$$\text{tg}x + \frac{1}{9}\text{ctg}x = |\text{tg}x| - 1.$$

Рассмотрим два случая: $\text{tg}x > 0$, $\text{tg}x < 0$ (при $\text{tg}x = 0$ левая часть уравнения теряет смысл).

a) Если $\text{tg}x > 0$, то уравнение (12) приводится к виду $\text{ctg}x = -9$, откуда следует, что $\text{ctg}x < 0$, что противоречит условия $\text{tg}x > 0$. В данном случае решение нет.

b) Если $\text{tg}x < 0$, то, полагая $u = \text{tg}x$, из (12) находим $18u^2 + 9u + 1 = 0$, откуда

$$u_1 = -\frac{1}{6}; \quad u_2 = -\frac{1}{3}.$$

Оба найденных значения отрицательны, так что условие $tg x < 0$ выполняется.

Ответ: $x = -\arctg \frac{1}{6} + n\pi; \quad x = -\arctg \frac{1}{3} + m\pi$.

Пример 11. Решить уравнение

$$\sin x + \sqrt{3} \cos x = \sqrt{2 + \cos 2x + \sqrt{3} \sin 2x}.$$

(13)

Решение. Так как права часть уравнения неотрицательна, то должно выполняться условие

$$\sin x + \sqrt{3} \cos x \geq 0.$$

(14)

Если освободиться от радикала путем возведения обеих частей уравнения (13) в квадрат, то получим уравнение

$$\sin^2 x + 3 \cos^2 x + 2 \sqrt{3} \sin x \cos x = 2 + \cos 2x + \sqrt{3} \sin 2x,$$

которое после уравнения примет вид

$$\cos 2x = \cos 2x.$$

(15)

Мы получили то жество. Это не означает, однако, что исходному уравнению удовлетворяют все значения $x$, так как уравнение (15) является лишь следствием уравнения (13). Уравнение (13) и (15) становятся равносильными, если выполняется условие (14). Таким образом, решения уравнения (13) являются все значения $x$, удовлетворяющие неравенству (14), и только эти значения. Решение неравенства (14) не представляется труда.

Ответ: $-\frac{\pi}{3} + 2\pi n \leq x \leq \frac{2\pi}{3} + 2\pi n$.

Замечание. К этому же ответу можно принять несколько путьем. Имеем $2 + \cos 2x + \sqrt{3} \sin 2x = \left[ 1 + \cos \left( 2x - \frac{\pi}{3} \right) \right] = 4 \cos^2 \left( x - \frac{\pi}{6} \right)$, и поэтому исходное уравнение примет вид $\cos \left( x - \frac{\pi}{6} \right) = \left| \cos \left( x - \frac{\pi}{6} \right) \right|$. Мы снова приходим к условиям (14).
