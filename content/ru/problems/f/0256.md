## Условие

В центр квадратной свободно подвешенной dockи попадает пуля. Если скорость пуля v > v0, то она пробивает dockу насковозь. С какой скоростью будет движаться dockа, если скорость пуля будет равна 2 v0? nv0? При какой скорости пуля скорость dockи будет максимальной?

Масса пуля m, масса dockи M, сопротивление считать независим от скорости.

Задана из стимы Л. Эйлера «Об ударе пуль при стрелле по dockе», 1770 г.

Рис. 3.

## Решение

В центр квадратной свободно подвешенной точки $v > v_0$, мо она пробиваем dockу насыщь. С какой скоростью будет движаться dockа, если скорость пути равна $2v_0$, $nv_0$? При какой скорости пути скорость dockы будет максимальной?

Масса пуля $m$, масса dockи $M$, сопротивление ситамь не зависит от скорости.

В горизонтальном направлении на системе пуля — dockа не действуют никакие внешние силы, то есть система изолирована. Запишем закон сохранения импульса и энергии ($v > v_0$):

$$mv = mv_1 + MV,$$

(1)

$$\frac{mv^2}{2} = \frac{mv_1^2}{2} + \frac{MV^2}{2} + Q.$$

(2)

Здесь $v_1$ — скорость пуля по выходе из dockи, $V$ — скорость dockи, $Q$ — количество выделенного теплла. Причем это телло равно работе силы сопротивления, действующего на пуля при ее движении внутри dockи:

$$Q = A = F_c d,$$

где $d$ — толщина dockи.

Так как по условиям задачи сила сопротивления не зависит от скорости, а $d$ — ве-

личина постоянная, то и количество выделения тепла $Q$ одинаково при всех значениях начальной скорости пуля $v$.

Рассмотрим случай, когда начальная скорость пуля равна $v_0$. Очевидно, что это минимальная скорость, с которой должны лететь пуля, чтобы насквозь пробить dockу. При этом пуля, пробив dockу, будет иметь скорость такую же, как и docka. Обозначим эту скорость $u$ и запишем законы сохранения импульса и энергии для этого случая:

$$mv_0 = (m + M)u,$$
$$\frac{mv_0^2}{2} = \frac{(m + M)u^2}{2} + Q.$$

Отсюда

$$Q = \frac{mMv_0^2}{2(m + M)}.$$

Тепер равенства (1) — (3) можно обединить в систему и, решив эту систему, найти величины $V$. Исключив из (1) и (2) скорость $v_1$, получим квадратное уравнение относительно $V$:

$$V^2 - 2\frac{mv}{m + M}V + \frac{2mQ}{M(m + M)} = 0,$$

откуда

$$V = \frac{m}{m + M}v \pm \sqrt{\frac{m^2}{(m + M)^2}v^2 - \frac{2mQ}{M(m + M)}}.$$

Подставим сюда значение $Q$ из (3) и получим

$$V = \frac{m}{m + M}\left(v \pm \sqrt{v^2 - v_0^2}\right).$$

Тепер проанализируем, оба ли корня уравнения соответствует условию данной задачи. Импульс dockи численно равен импульсу силы сопротивления, то есть произведение величины $F_C$ на время ее действия $t$. Очевидно, что чем больше начальная скорость пуля, тем быстрее пуля проходит сквозь dockу, то есть тем меньше время $t$. Следовательно, скорость dockи максимальная при скорости пуля, равной $v_0$. С увеличением начальной скорости пуля скорость dockи уменьшается. Этому соответствует такое выражение для $V$:

$$V = \frac{m}{m + M}\left(v - \sqrt{v^2 - v_0^2}\right).$$

При $v = 2v_0$
$$V = \frac{m}{m + M}\left(2 - \sqrt{3}\right)v_0,$$

а при $v = nv_0$
$$V = \frac{m}{m + M}\left(n - \sqrt{n^2 - 1}\right)v_0.$$
