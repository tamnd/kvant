## Условие

В случае несамостояльного газового размера зависимость точки $I$ через газоразрядную трубку от напряжения $U$ между электродами трубки имеет вид, показанный на рисунке 2. Трубка с последовательно соедининым баллостным сопротивлением $R = 3 \cdot 10^8$ Ом подключена к источнику с постоянной ЭДС $8 = 6$ кВ. Найдите, какой ток установится через трубку и чем будет равно при этом напряжение на трубке. Внутренним сопротивлением источника претенбрець.

В. Можаев

## Решение

В случае несамостояльного газового разряда зависимость тока I через газоразрядную грубу от напряжения U между электродами грубки имеет вид, показанный на рисунке 1. Трубка с последовательным соединением баластным сопротивлением R = 3 · 10⁸ Ом подключаена к источнику с постоянной ЭДС Ε = 6 кВ. Найдите, какой ток установлен через грубку ичем будет равно при этом напряжение на грубке. Внутренним сопротивлением источника пребрежь.

Схема включения газоразрядной грубки показана на рисунке 2.

Найдем минимальное значение ЭДС источника, при котором через грубку будет достигать насыщения. Для этого заполните закон Ома для цепи:

ε_min = U_H + I_H R,

где U_H = 10³ В, I_H = 10⁻⁵ А (см. рис. 1). Подставляя численные значения, находим ε_min = 4 кВ.

В нашем случае ЭДС источника ε > ε_min. Следовательно, ток через грубку равен току насыщения. Например, при этом определяется условием ε = U + I_H R, откуда

U = ε - I_H R = 3 кВ.

Величину тока через грубку можно определить другим способом. Предположим, что ток I в цепи меньше тока насыщения. Запишем закон Ома для этого случая:

ε = I(R_Tp + R),

где R_Tp — внутреннее сопротивление грубки. Значение R_Tp находится по наклону линейного участка волтампернойxa-

Рактористки трубки (см. рис. 1):

$$R_{\text{тр}} = \frac{U_H}{I_H} = 10^8 \text{ Ом.}$$

Таким образом,

$$I = \frac{\mathcal{E}}{R_{\text{тр}} + R} = 15 \text{ мкA.}$$

Найdenное значение тока большие $I_H$. Следовательно, наше предположение о том, что $I < I_H$, неверно. Ток через трубку равен току насыщения.
