## Условие

В схеме, показанной на рисунке, ЭДС батареи Е, ее внутреннее сопротивление r, сопротивление резистора R. При замыкнии ключа K1 стрелка галванометра отклоняется на угол α. На какой угол отклоняется стрелка галванометра, если при замкнутом ключе K1 замкнуты ключи K2? Отклонение стрелки пропорционально заряду, прошедему через галванометр.

◆

Точка C при любом положении стержня находится на расстоянии $l/2$ от вершины O прямого угла (медиана, проведенная из вершины прямого угла, равна половине гипотенузы). Следовательно, точка C движется по окружности радиуса $l/2$ с центром в точке O. Скорость $v_c$ точки C направлена по касательной к траектории и в любой момент перпендикулярна OC.

Так как стержень нерастяжим, проекции скоростей точек C и В на направление стержня равны (рис. 2).

$$v \cos \alpha = v_c \cos \beta = v_c \cos \left( 2\alpha - \frac{\pi}{2} \right) = v_c \sin 2\alpha.$$

Позтому

$$v_c = \frac{v \cos \alpha}{\sin 2\alpha} = \frac{v}{2 \sin \alpha}.$$

Проекция ускорения $\vec{a}_c$ точки C на радиус OC = $l/2$ должна быть равна $\frac{v_c^2}{l/2} = \frac{v^2}{2l \sin^2 \alpha}$. Как направлен вектор $\vec{a}_c$? Заметим, что проекция скорости $\vec{v}_c$ точки C на горизонтальном ось равна $v_c \cos (\alpha - \beta) = v_c \cos \left( \frac{\pi}{2} - \alpha \right) = \frac{v}{2}$. Эта величина не зависит от α и, следовательно, постоянна. Это означает, что вектор $\vec{a}_c$ направлен вертикально.

Таким образом,

$$a_c \cos \left( \frac{\pi}{2} - a \right) = \frac{v^2}{2l \sin^2 \alpha},$$

откуда

$$a_c = \frac{v^2}{2l \sin^3 \alpha}.$$

◆

После замыкния ключа K1 направление на конденсаторе становится равным Е. При этом заряд конденсатора равным

$$q_1 = C \varepsilon.$$

Такой заряд и проходит через галванометр при замыкнии ключа K1. Следовательно,

$$\alpha = kq_1 = kC \varepsilon,$$

где $k = \text{const}$ — коэффициент пропорциональности.

После замыкния ключа K2 направление на конденсаторе становится равным резисторю на резисторе, то есть $U = IR$, где I — ток, текущий через резistor. Так как резistor включен после давления с источником, $I = \varepsilon / (R + r)$. Следовательно, $U = \varepsilon R / (R + r)$. Заряд же конденсатора после замыкния ключа K2 становится равным

$$q_2 = CU = C \varepsilon \frac{R}{R + r}.$$

Следовательно, через галванометр после замыкния ключа K2 проходит заряд

$$q = q_1 - q_2 = C \varepsilon \frac{r}{R + r}$$

## Решение

В схеме, показанной на рисунке 3, ЭДС батареи $\&$, ее внутреннее сопротивление $r$, сопротивление резистора $R$. При замыкании ключа $K_1$ стрелка галванометра $G$ отклоняется на угол $\alpha$. На какой угол отклоняется стрелка галванометра, если при замкнутом ключе $K_1$ замкнут ключ $K_2$? Отклонение стрелки пропорционально заряду, прошедшего через галванометр.
