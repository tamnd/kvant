## Условие

Газетный текст, фотографируется аппаратом «Зенит» с объективом, имеющим фокусное расстояние 50 мм, дважды:
1) с наименьшего допустимого для этого объектива расстояния $a = 0,5$ м;
2) после присоединения объектива к камере через удлинительное колюдо высотой $h = 25$ мм (также с минимально возможного расстояния).

Найдите отношение газов изобравней, полученных на фотопленке в этих двух случях.

В. Дерябкин

## Решение

Газетный текст фотографируется annaparam «Зенит» с объектным, имеющим фокусное расстояние 50 мм, дважды:
1) с наименьшего допустимого для этого объектива расстояния $a = 0,5$ м;
2) после присоединения объекта к камере через удилинительное колюцо высотой $h = 25$ мм (также с минимально возможного расстояния).
Найдите относение размеров изображений, полученных на фотопленке в этих двух случаях.

Для решения задачи воспользовемся формулой линзы
$$\frac{1}{d} + \frac{1}{f} = \frac{1}{F},$$
где $d$ — расстояние от фотографируемого предмета до объекта, $f$ — расстояние от объекта до изображения, $F$ — фокусное расстояние объекта (см. рисунок).
При фотографировании текст в первом случае (без удалительнойного колца) $d_1 = a$, и резкое изображение получается на расстоянии
$$f_1 = \frac{aF}{a-F}.$$
Линейный размер изображения в этом случае равен (см. рисунок).
$$l_1 = L \frac{f_1}{a} = L \frac{F}{a-F}.$$
При присоединении объекта к камере через удилинительное колюцо высотой $h$ резкое изображение текст получается на расстоянии
$$f_2 = f_1 + h = \frac{aF}{a-F} + h$$
от объекта. Minimalно возможное расстояние от объекта, на котором может находиться при фотографировании текст, в этом случае равно
$$d_2 = \frac{f_2F}{f_2-F} = \frac{(aF + h(a-F))F}{F^2 + h(a-F)}.$$
Размер изображения в этом случае
$$l_2 = L \frac{f_2}{d_2} = L \left( \frac{F}{a-F} + \frac{h}{F} \right).$$
Таким образом, относение размеров изображений, полученных на фотопленке в двух случаях, равно
$$\frac{l_2}{l_1} = \frac{h(a-F)}{F^2} + 1 = 5,5.$$
В. Держкин
