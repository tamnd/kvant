M1212. Множество всех целых чисел разбито на поарно непересекающийся бесконечные арифметические прогрессии с положительными разностями $d_1$, $d_2$, $d_3$, ... Может ли случайся, что

$$\frac{1}{d_1} + \frac{1}{d_2} + \frac{1}{d_3} + \dots < 0,9?$$ (*)

Рассмотрим два случая: а) число прогрессий конечно;
б) число прогрессий бесконечно (при этом условие (*) означает, что сумма любого конечного числа слагаемых в левой части (*) меньше 0,9).

Пусть число прогрессий конечно и равно $k$. Докажем, что сумма $1/d_1 + 1/d_2 + \dots + 1/d_k$ равна 1. Пусть $M$ — неокторое (например, наименьшее) общее кратное чисел $d_1$, $d_2$, ..., $d_k$. Рассмотрим любой отрезок из $M$ последовательных целых чисел; в нем будет $M/d_i$ членов $i$-й прогрессии с разностью $d_i$ ($i = 1, 2, \dots, k$). Поэтому $M/d_1 + M/d_2 + \dots + M/d_k = M$.

6) Ответ: может.

Приведем пример бесконечного числа прогрессий, для которых сумма $1/d_1 + 1/d_2 + 1/d_3 + \dots$ меньше 0,9. Возьмем в качестве $d_1$, $d_2$, $d_3$, ... числа 4, 8, 16, ..., $d_k = 2^{k+1}$, ...; тогда $1/4 + 1/8 + 1/16 + \dots \leq 1/2$. Будем строить прогрессии последовательно, по индекции. Первая прогрессия — числа, кратные 4. Для каждого $k > 1$, считая, что первые $k - 1$ уже построены, мы выберем в качестве одного из членов $k$-й прогрессии с разностью $d_k = 2^{k+1}$ наименьшее по модулю целое число, не входящие в уже построенные. Поскольку $d_k$ делится на каждое $d_i$ ($i < k$), $k$-я прогрессия не пересекается с предыдущими. С другой стороны, прогресси содержат в се без исключения целые числа: не более чем за $2k$ шагов мы включим в прогресси каждое целое число, не превысodiaщее по модулю $k - 1$.

Аналогично для любого $\varepsilon > 0$ можно построить пример, в котором $1/d_1 + 1/d_2 + 1/d_3 + \dots < \varepsilon$.

А. Толпыго, Н. Констатинов
