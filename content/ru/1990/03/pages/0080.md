2. 832. Указание. Сумма всех трех значений чисел, составленных из цифр $k, l, m$, равна $222(k + l + m)$. 3. $3 \pm \sqrt{35 - 3^c}$ при $c < 3; 3 \pm \sqrt{35 - 3^c}, 3 \pm \sqrt{3^c - 27}$ при $3 \leq c \leq \log_3 31$; при $c > \log_3 31$ корней нет. Указание. Искодное уравнение равносильно уравнению $|x^2 - 6x + 5| = 31 - 3^c$, из которого, в свою очередь, получаем совокупность из двух уравнений $x^2 - 6x + 3^c - 26 = 0$ и $x^2 - 6x + 36 - 3^c = 0$ при условии $c \leq \log_3 31$. 4. arctg $\left( \frac{2\sqrt{3}q}{1 + q} \right) \text{ctg } \varphi$ при $0 < q \leq \frac{1}{2}, 0 < \varphi < \frac{\pi}{2}$. Указание. Пусть секущая плоскость пересекает боковое ребро $RR_1 = l$ в точке $S$ (рис. 8). Т— середина $QP$. Тогда $PQ = l \text{tg } \varphi, RT = l \text{tg } \varphi \frac{\sqrt{3}}{2}, V = V_{SPQR} = \frac{1}{4} l^3 \times \text{tg}^3 \varphi \cdot \text{tg } x, V_1 = V_{PQRP_1Q_1R_1} = \frac{\sqrt{3}}{4} l^3 \text{tg}^2 \varphi$. Поискольку $\frac{V - V_1}{V_1} = \frac{1}{q}$, то после нескольких преобразований приходим к уравнению
$$\frac{2\sqrt{3}q}{1 + q} \text{ctg } \varphi = \text{tg } x,$$
откуда $x = \text{arctg} \left( \frac{2\sqrt{3}q}{1 + q} \right) \text{ctg } \varphi$, причем задача имеет решение при $0 < q \leq \frac{1}{2}, 0 < \varphi < \frac{\pi}{2}$.
