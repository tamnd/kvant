В наших наблюдениях за количеством зелени в поле мы замечали изменение в количестве зелени через равные промежутки времени (пусты для простоты это будут одни сутки).
Отношение изменения количества зелени $\Delta K_t$ за этот промежуток времени (за любые сутки) к имеющейся количеству зелени $K_t$ в эти сутки будет постоянной величины, равной порогу восприятия изменения количества зелени:

$$\frac{\Delta K_t}{K_t} = \delta_\pi^K.$$

Из этого отношения мы можем получить уравнение для скорости изменения количества зелени

$$v_t = \frac{\Delta K_t}{\Delta t} = \frac{\delta_\pi^K K_t}{t_\pi} = CK,$$

(1)

где $C = \delta_\pi^K / t_\pi$ — постоянная величины, равная относительно порога восприятия изменения количества зелени ко времени, за которого изменение количества зелени на данном поле достигает порогового (у нас это один сутки).

Полученное выражение показывает, что скорость роста количества зелени пропорциональная количеству уже имеющейся зелени. (Подобное выражение получается при описании радиоактивного распада ядер. В этом случае скорость распада, т. е. число ядер, распадающихся в единицу времени, пропорциональная числу оставшихся ядер. Но, в отличие отроста растений, для распада ядер в правой части уравнения, аналогичного (1), стоит знак минус, так как количество первого начальных ядер уменьшается со временем.) Во всех случаях, когда скорость изменения какой-либо величины пропорциональная самой величины, зависит рассматриваемой величины от времени имеет экспоненциальный характер. В нашем случае это означает, что к моменту времени $t$ количество зелени может быть найдено как

$$K_t = K_0 e^{Ct},$$

(2)

где $K_0$ — начальная величина количества зелени при $t = 0$, а $e = 2,718$.

Чтобы показать, как из уравнения (1) получается экспоненциальная за-

висимость от времени (2), можно проведити следующие настройки рассуждения. Пусть в начальной момент времени $t_0 = 0$ величина количества зелени равна $K_0$, и нас интересует значение $K_t$ через время $t$. Разобъем временной интервал $0 - t$ на $N$ равных промежутков времени длительного $\tau (\tau = t/N)$ и будем фиксировать количество зелени в моменты времени $t_0 + \tau$, $t_0 + 2\tau$ и т. д.

Через время $t$ после начального момента $t_0 = 0$ количество зелени можно найти как

$$K_1 = K_0 + \Delta K_0 = K_0 + v_0 \tau = K_0 + K_0 C \tau = K_0 (1 + C \tau)$$

(на этом интервале времени мы прияли скорость роста постоянной и равной (см. (1)) $v_0 = CK_0$); аналогично, через время $2\tau$

$$K_2 = K_1 + \Delta K_1 = K_1 + v_1 \tau = K_1 + CK_1 \tau = K_1 (1 + C \tau) = K_0 (1 + C \tau)^2$$

(скорость роста постоянна и равна $v_1 = CK_1$). Интересующое нас значение $K_t$ через время $t = N\tau$ можно найти как

$$K_t = K_N = K_0 (1 + C \tau)^N = K_0 \left(1 + \frac{Ct}{N}\right)^N = K_0 \left(1 + \frac{1}{M}\right)^{M C t} = K_0 \left(1 + \frac{1}{M}\right)^{M C t},$$

где мы ввели обозначение $M = Ct/N$ (М — безразмерная величина).
