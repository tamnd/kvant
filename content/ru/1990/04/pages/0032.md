Этот раздел ведется у нас из номера в номер с момента основания журнала. Публикуемые в нем задачи нестандартны, но для их решения не требуется знаний, выходящих за рамки школьной программы. Наиболее трудные задачи отмещаются звездочкой. После формирования задачи мы обещано указывать, кто нам ее предложил. Разумеется, не все эти задачи публикуются впервые.

Решения задачи из этого номера следует отправлять не позднее 15 июня 1990 года по адресу: 103006, Москва К-6, ул. Горького, 32/1, «Квант». Решения задачи из разных номеров журнала или по разным предметам (математике и физике) присылайте в разных конвертах. На конверте в графе «Кому» написите: «Задачник «Кванта» № 4—90» и номера задач, решения которых вы посылаете, например «M1216» или «Ф1223». В графе «...адрес отправителя» фамилию и имя просим писать разборную. В письмо вложите конверт с написанным на нем вашим адресом (в этом конверте вы получите результаты проверки решений).

Условие каждой оригинальной задачи, предлагаемой для публикации, присладайте в отдельном конверте в двух экземплярах вместе с вашим решением этой задачи (на конверте пометьте: «Задачник «Кванта», новая задача по физике» или «...новая задача по математике»).

В начале каждого письма просим указывать номер школьи и класс, в котором вы учитесь.

Задачи
M1216—M1220, Ф1223—Ф1227

M1216. Найдите углы остругольного треугольника ABC, если известно, что его биссертиса AD равна стороне AC и перpendикularна отрезку OH, где O — центр описанной окружности, H — точка пересечения высот треугольника ABC.

К. Нистореcky (Румыния)

M1217. Докажите для любого натурального n равенство
$$\frac{1}{n^2} + \left( \frac{1}{n} + \frac{1}{n-1} \right)^2 + \dots + \left( \frac{1}{n} + \frac{1}{n-1} + \dots + 1 \right)^2 = 2n - \left( 1 + \frac{1}{2} + \dots + \frac{1}{n} \right).$$
Ю. Бурман

M1218. На отрезке AC взята точка B и построены дуги: $\overline{AC} = \alpha$ и $\overline{BC} = \beta$, сумма граducных величины которых равна $\alpha + \beta = 360^\circ$, лежащие в одной полпоскости от прямой AC. Произвольная дуга AB пересекает их в точках K и L (рис. 1). Докажите, что всеозможно примыть AC в одной и той же точке.

В. Михайлов (Болгария)

M1219*. Докажите, что для любых n положительных чисел $x_1, x_2, \dots, x_n$ ($n > 1$) справедливо неравенство
$$(x_2 + \dots + x_n)^{x_1} + \dots + (x_1 + \dots + x_{i-1} + x_{i+1} + \dots + x_n)^{x_i} + \dots + (x_1 + x_2 + \dots + x_{n-1})^{x_n} > n - 1.$$
Например, для любых положительных чисел $x, y, z$ выполнен неравенство
$$(x + y)^2 + (y + z)^x + (z + x)^y > 2.$$
А. Михайлов

M1220*. Определим последовательность $b_n$ условиями: $b_1 = 0, b_2 = 2, b_3 = 3, b_{n+1} = b_{n-1} + b_{n-2}$ при $n \geqslant 3$. Докажите, что при простом p число $b_p$ делится на p.
Д. Фомин

Ф1223. Горизонтальная поверхность выбротанспортера приводится в движение эксцентриками, синхронно врашающимся вокруг неподвижных горизонтальных осей O и O' (рис. 2). При какой угловой скорости врашения эксцентриков лежащие на поверхности детали научут перемещаться? В каком направлении они будут перемещаться при врашении эксцентриков по часовой стрелке? Коэффициент трения деталей о поверхности k, радиус эксцентриков r.

Е. Бутиков
