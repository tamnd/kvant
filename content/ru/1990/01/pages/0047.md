Ф1192. На торце цилиндрического соленода лежит тонкий лист картона, на нем — маленькое сверхпроводящое колюцо из тонкой проволоки, диаметр которого $d_1$ существенно меньше диаметра колюца D. При подключини соленода к источнику последовательно с конденсатором (см. рисунок) колюцо подрызывает при $U > U_0$. Каким должно быть направление источника в аналогичном опите с колюцом такого же диаметра, но сделанным из проволоки толщиной $d_2$? Индуктивность такого колюца с достационной для практики точно можно оценить по формуле $L = kD \ln(1,4D/d)$. Сопротивление соленода считать малым.

Пренебрегая активным сопротивлением соленода, запищем закон Ома для замкнутой цепи соленода:

$$U - L_c \frac{\Delta I_c}{\Delta t} = \frac{q}{C},$$

где $L_c$ — индуктивность соленода, $I_c$ — ток через соленод, $q$ — заряд на конденсатор. Используя выражение $I_c = \Delta q/\Delta t$, получим уравнение

$$\frac{d^2 q}{dt^2} + \frac{q}{L_c C} = \frac{U}{L_c}.$$

Введем обозначения: $1/(L_c C) = \omega_0^2$, $q - UC = q^*$. Тогда уравнение, описывающее зависимость заряда $q^*$ от времени, будет иметь вид

$$\frac{d^2 q^*}{dt^2} + \omega_0^2 q^* = 0.$$

Это уравнение описывает гармоничное колебания заряда $q^*$, который с точностью до константы UC равен заряду на конденсатор. Решение этого уравнения ищем в виде

$$q^*(t) = A \sin \omega_0 t + B \cos \omega_0 t,$$

где A и B — константы, которые определяются из начальных условий. В момент замкывания колюца цепи соленода
