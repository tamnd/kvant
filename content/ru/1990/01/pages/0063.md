Дальнейшее развитие человекаских идей привело к такому результату: для $x \geq 48$ $\theta\left(\frac{9}{8}x\right) - \theta(x) > 0$, т. е. начинается с указанного места, между $x$ и $\frac{9}{8}x$ всегда есть хотя бы одно простое число.

Вы можете более детально проследить за ходом рассужdenной Чебышева, решая следующее ниже задачи 1—5.

Для того чтобы $T(x)$ выразить через $\theta(x)$, удобно ввести еще одну вспомогательную функцию. Пусть $p^{a_p}$ — наивысшая степень $p$, не превысаящая $x$. Определим функцию $\psi$ так:

$$\psi(x) = a_2 \log 2 + a_3 \log 3 + a_5 \log 5 + \dots = \sum_{p \leq x} a_p \log p.$$

Ясно, что $\psi(x)$ есть логарифм наименьшего общего кратного для всех целых чисел, не превысаящая $\psi$. Задача 1. Докажите, что

$$T(x) = \psi(x) + \psi\left(\frac{x}{2}\right) + \psi\left(\frac{x}{3}\right) + \dots$$

Тепер надо связать функцию $\psi$ и $\theta$.

Задача 2. Докажите, что

$$\psi(x) = \theta(x) + \theta\left(\sqrt{x}\right) + \theta\left(\sqrt[3]{x}\right) + \theta\left(\sqrt[4]{x}\right) + \dots$$

Решив задачи 1 и 2, вы установите тоже действующее число $e$, что при всех натуральных $n$

$$\left(\frac{n+1}{e}\right)^n < n! < n\left(\frac{n}{e}\right)^n$$

(где $n! = 1 \cdot 2 \cdot 3 \cdot \dots \cdot n$).

Для решения этой задачи полезно показать, что каждое из чисел

$$a_n = \left(\frac{n+1}{n}\right)^n$$

менные каждого из чисел

$$b_n = \left(\frac{n+1}{n}\right)^{n+1};$$

отсюда следует, что существует такое число $e$, которое больше всех $a_n$ и меньше всех $b_n$. Это и есть то число, которое мы ищем (о некоторых его свойствах рассказывавалось на последней странице нашего журнала № 1, 1971).

Решив эту задачу, вы получите также неравенства для $T(x)$:

$$(x-1)(\log(x-1) < T(x) < (x+1)\log x-x).$$

Сам Чебышев пользовался более точными неравенствами.

Из оценки для $T(x)$ Чебышев получает оценки для $\psi(x)$, а затем и для $\theta(x)$.

Чтобы выразить $\psi$ через $T$, Чебышев заменяет следующие. Расмотрим сумму

$$S = T(x) - T\left(\frac{x}{2}\right) - T\left(\frac{x}{3}\right) - T\left(\frac{x}{5}\right) + T\left(\frac{x}{30}\right).$$

Воспользовемся результатом задачи 1 и приведем эту сумму к таким виду:

$$S = A_1 \psi(x) + A_2 \psi\left(\frac{x}{2}\right) + A_3 \psi\left(\frac{x}{3}\right) + \dots$$

Задача 4. Проверите, что коэффициенты $A_1, A_2, A_3$, ... меняются с периодом 30 и что для первых трицати значений $n$ коэффициенты $A_n$ составляют следующую последовательность:

1, 0, 0, 0, 0, -1, 1, 0, 0, -1, 1, -1, 1, 0, -1, 0, 1, -1, 1, -1, 0, 0, 1, -1, 0, 0, 0, 0, 1, -1, 1.

Отсюда видно, что сумма $S$ записывается знакоперменным рядом $S = \psi(x) - \psi\left(\frac{x}{6}\right) + \psi\left(\frac{x}{7}\right) - \psi\left(\frac{x}{10}\right) + \psi\left(\frac{x}{11}\right) - \dots$.

Так как $\psi$ неубывающая функция,

$$S = \psi(x) - \left(\psi\left(\frac{x}{6}\right) - \psi\left(\frac{x}{7}\right)\right) - \left(\psi\left(\frac{x}{10}\right) - \psi\left(\frac{x}{11}\right)\right) \dots \leqslant \psi(x).$$

Аналогино

$$S = \psi(x) - \psi\left(\frac{x}{6}\right) + \left(\psi\left(\frac{x}{7}\right)\right) - \psi\left(\frac{x}{10}\right) + \dots \geqslant \psi(x) - \psi\left(\frac{x}{6}\right).$$

Из (2) сразу получается неравенство для $\psi$, которое оценивает ее сизу, так как мы знаем неравенства для $T$ и получили оценку для $\psi$ через $S$, т. е. комбинацию значений $T$. Эта оценка будет иметь такой вид: $\psi(x) \geqslant A_1(x) + \omega_1(x)$, где $\omega_1$ растет медленнее, чем $x$, т. е.

$$\lim_{x \to \infty} \frac{\omega_1(x)}{x} = 0.$$

Для получения оценки сверху надо освобождаться от $\psi\left(\frac{x}{6}\right)$. Применяя неравенство (6) к $\frac{x}{6}, \frac{x}{6^2}, \frac{x}{6^3}$ и т. д. и складываясь, найдем неравенство для $\psi(x)$ типа $\psi(x) \leqslant A_2x + w_2(x)$, где $w_2$ растет медленнее, чем $x$.

Задача 5. Докажите, что

$$\psi(x) - 2\psi\left(\sqrt{x}\right) \leqslant \theta(x) \leqslant \psi\left(\sqrt{x}\right).$$

Отсюда уже получается нужные оценки (3).

Из результатов Чебышева не только вытекала справедливость поступала Бертрана, но, что еще более важно, из них получились неравенства, позволяющие хорошо оценить функцию $\pi(x)$:

$$c_1 \frac{x}{\log x} < \pi(x) < c_2 \frac{x}{\log x},$$

где $c_1$ и $c_2$ — неокотые положительные.
