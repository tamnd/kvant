3. Если в некоторый момент времени нить отклонена от вертикали на угол $\alpha$, а скорость шарика равна $v$, то второй закон Ньютона в проекциях на направление нити имеет вид (рис. 1)

$$T - mg \cos \alpha = mv^2/l$$

где $m$ — масса шарика, $l$ — длина нити. Видно, что натяжение нити минимально в крайнем положении шара, когда $v = 0$, а cos $\alpha$ — минимальный, т. е. угол $\alpha$ максимальный:

$$T_{\min} = mg \cos \alpha_{\max}$$

Максимальное натяжение соответствует направив, нижнему положению шара:

$$T_{\max} = mg + mv^2_{\max}/2$$

Скорость шара $v_{\max}$ в этот момент найдем из закона сохранения механической энергии

$$mgl(1 - \cos \alpha_{\max}) = mv^2_{\max}/2$$

Тогда

$$T_{\max} = mg(3 - 2 \cos \alpha_{\max})$$

По условию $T_{\max} = 4T_{\min}$. Отсюда находится угол:

$$\cos \alpha_{\max} = 1/2, \alpha_{\max} = 60^\circ$$

4. Из условия задачи следует, что скорости шаров после сoduарения одинаковы по модулю, но противоположны по направлению. Запишем законы сoduарения импульса и энергии для упругого удара:

$$m_1v = -m_1u + m_2u$$

$$m_1v^2/2 = m_1u^2/2 + m_2u^2/2$$

где $v$ — скорость первого шара до удара, $u$ — скорости шаров после удара. Решая эти уравнения, получаем

$$m_1 = m_2/3 = 0,2 \text{ кг}$$

5. Чтобы найти выделившее количество теплоты, подсчитаем, на сколько конечная механическая энергия меньше начальной:

$$Q = (m_1v^2/2 + m_2gh) - (m_1 + m_2)u^2/2$$

Конечную скорость $u$ найдем из закона сoduарения импульса

$$m_1v = (m_1 + m_2)u$$

Решая эти уравнения, находим

$$Q = m_1m_2v^2/(2(m_1 + m_2)) + m_2gh = 150 \text{ Дж}$$

6. На обеих лампочках вместе выделяется мощность

$$P = U^2/(R_1 + R_2)$$

где $U$ — номинальное напряжение, $R_1$ и $R_2$ — сопротивления лампочек. Эти сопротивления (предполагая их неизменными) выразим через номинальные мощности:

$$R_1 = \frac{U^2}{P_1}, \quad R_2 = \frac{U^2}{P_2}$$

Тогда получаем

$$P = P_1P_2/(P_1 + P_2) = 60 \text{ Вт.}$$

7. Тепловая мощность, выделяющаяся в единице объема конденсатора, равна

$$q = \frac{P}{V} = \frac{UI}{dS} = \frac{(Ed)(jS)}{dS} = Ej$$

Отсюда находится

$$E = q/j = 5000 \text{ В/m.}$$

8. Пусть в батарее $N$ элементов. Тогда ЭДС батареи равна $\mathcal{E}$, внутринее сопротивление — $r/N$, а полезная мощность —

$$P = \mathcal{E}I - I^2r/N$$

Отсюда находится

$$N = 7$$

9. Полезная мощность электродвигателя $UI - I^2R$, где $R$ — сопротивление обмотки, равна механической мощности трамвая $Fv$:

$$UI - I^2R = Fv$$

$$R = (UI - Fv)/I^2 = 3 \text{ Ом.}$$

10. По первому закону электродвигателя масса меди равна

$$m = kq$$

где $q$ — произведший заряд, который равен

$$q = q_1 + q_2 = (0 + I_1)t/4 + (I_1 + I_2)t/4$$

Окончательно

$$m = k(2I_1 + I_2)t/4 = 230 \text{ мг.}$$

11. Уравнение движения протона имеет вид

$$F = \Delta p/\Delta t$$

Так как начальный импульс протона равен нулю, а сила $F = eE$ постоянна, прибретенный протоном импульс равен

$$p = eEt$$
