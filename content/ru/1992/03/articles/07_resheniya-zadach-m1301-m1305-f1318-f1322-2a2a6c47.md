M1302. Доказите, что произведение многочлена (x+1)^{n-1} на любой многочлен (отличный от нуля) имеет не менее n отличных от нуля коэффициентов, если это утверждение уже доказано для меньших n. Мы можем, оченьindo, считать, что свободный член, т. е. число P(0), отличен от нуля (при умножении на x^k число ненулевых коэффициентов не изменится).

Возьем производную:

$(P(x)(x+1)^n)' = (x+1)^{n-1}(P'(x)(x+1)+nP(x))$.

Второй сомножитель отличен от 0. Тем самым, у производной многочлена $P(x)(x+1)^n$ не менее n ненулевых коэффициентов по предположению отличии. Значит, у этого многочлена не менее n+1 ненулевых коэффициентов: свободный член P(0) и еще n.

M1303. Найдите все бесконечные последовательности натуральных чисел $q_1, q_2, \dots, q_n$, ... также, что ($n$ при всех $n > 3$)

$$q_n = (q_{n-3} + q_{n-1}) / q_{n-2}.$$

2, 2, 2, 2, ...
1, 2, 5, 3, 1, 2, ...
1, 3, 5, 2, 1, 3, ...

Эти три последовательности дают ответ (всего деять различных последовательностей).

1, 1, $a$, $a+1$, ...
1, $a$, 1, $2/a$, ...
1, $a+1$, $a$, 1, ...

Во всех этих случаях $a=2$ или $a=1$.

Все возможные ответы указаны на полях.

По условияю,

$$q_n q_{n-2} = q_{n-3} + q_{n-1}.$$ (*)

Выберем из всех сумм $q_{n-3} + q_{n-1}$ наименьшую. Тогда

$$q_{n-3} + q_{n-1} = q_n q_{n-2} \leq q_{n-2} + q_n,$$

что возможно лишь в двух случаях. Либо все числа $q_{n-3}, q_{n-2}, q_{n-1}$ и $q_n$ равны 2, либо среди них встреется 1 (для натуральных чисел $a > 1$ и $b > 1$ верно нераваенство $ab \geq a+b$, либо $(a-1)(b-1) \geq 1$).

В первом случае все числы последовательности равны 2 (по данным trem подряд ищим членам последовательности все последовательность однозначно восстанавливается по формуле (*)).

Во втором случае, т. е. когда $q_m=1$ для некоторого $m$, докажем, что $q_{m+4}=1$.

Пусть следующее за $q_m$ три числа больше 1. Из соответствий

$$q_{m+3} q_{m+1} = q_m + q_{m+2} = 1 + q_{m+2}$$

и

$$q_{m+4} q_{m+2} = q_{m+1} + q_{m+3} \leq q_{m+3} q_{m+1} = 1 + q_{m+2}$$

получаем

$$q_{m+2} (q_{m+4} - 1) \leq 1.$$

Это возможное лишь при $q_{m+4}=1$, причем $q_{m+3} q_{m+1} - 1 = q_{m+3} + q_{m+1}$, откуда $(q_{m+3} - 1) (q_{m+1} - 1) = 2$, т. е. одно из чисел $q_{m+3}, q_{m+1}$ равно 2, а другое — 3. Так мы получим еще два ответа, приведенные на полях (разумеется, возможно любые последовательности, получаем из них сдигром).

Остается рассмотреть случай, когда одно из трех следующих за $q_m=1$ чисел равно 1 и убедиться в том, что при этом последовательность, удовлетворяющая (*), будет содержать нецелые числа (на полях в возникающей при этом последовательности число $a$ должно быть делителем двух, что возможно лишь при $a=2$ и $a=1$).

Итак, ответом к этой задаче следует последовательность, указанных на полях.

Второе решение. Мы доказем, что последовательность натуральных чисел, удовлетворяющая указанию (*), перiodична с периодом 4, т. е. что $q_{n+4}=q_n$ для любого $n \geq 1$.

Из (*) при $i \geq 4$ следует, что

$$q_{i-3} + q_{i-1} = q_i q_{i-2}$$

и

$$q_{i-1} + q_{i+1} = q_{i+2} q_i.$$

Вычитая из нижнего равенства верхнее, получаем

$$q_{i+1} - q_{i-3} = q_i (q_{i+2} - q_{i-2}).$$

Запишем теперь такие равенства при $i=4, 5, \dots, n+2$:

$$q_5 - q_1 = q_4 (q_6 - q_2),$$

$$q_6 - q_2 = q_5 (q_7 - q_3),$$

(**)

$$q_{n+3} - q_{n-1} = q_{n-2} (q_{n+4} - q_n).$$

Из (**) последовательно получаем:
$$q_5 - q_1 = q_4 q_5 (q_7 - q_3),$$
$$q_5 - q_1 = q_4 q_5 q_6 (q_8 - q_4),$$
$$\dots$$
$$q_5 - q_1 = q_4 q_5 q_6 \dots q_{n-2} (q_{n+4} - q_n).$$

Поскольку среди любой четверки чисел $q_k, q_{k+1}, q_{k+2}, q_{k+8}$ обязательно встретися число, не равное 1, все эти равенства возможны лишь при $q_{n+4} = q_n$ при любом $n \geq 4$. Итак, последовательность $\{q_n\}$ обязательно переодчина.

Дальнейшее напоминает то, что делалось в первом решении. Ясно, что достаточно найти $q_1, q_2, q_3$. Имеем
$$q_2 + q_4 = q_5 q_3 = q_1 q_3,$$
$$q_1 + q_3 = q_2 q_4.$$

Если все числа $q_1, q_2, q_3, q_4$ не меньше двух, то
$$q_2 + q_4 = q_5 q_3 = q_1 q_3$$

и
$$q_1 + q_3 = q_2 q_4 \geq q_2 + q_4 = q_1 q_3,$$

т. е.
$$q_1 + q_3 \geq q_1 q_3,$$

но это возможно лишь тогда, когда все эти числа равны 2. Отсюда получается первое решение — последовательность 2, 2, 2, 2, ...

Осталось последовательно рассмотреть случай, когда одно из $q_i$ ($i=1, 2, 3, 4$) равно 1, и воспользоваться перiodичностью.

M1304. Пусть $I$ — центр вписанной окружности треугольника $ABC$, $R$ — радиус описанной окружности. Доказите, что

Это совсем простая задача.
