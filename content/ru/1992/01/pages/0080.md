Московский институт электронного машиностроения

Математика

Вариант 1

1. $a+3$ и $(-3)$ при $a \notin \{-1; -4\}$, $(-3)$ при $a=-1$ и $(-1)$ при $a=-4$.
2. $\{x \in (-3; -2) \cup (8; 9), 0 < y < x+4\} \cup \{x \in (-2; 8), y > x+4\}$.
Указание. Рассмотрим сначала функцию $u(x) = |x+1| - 2|x-1| + 6$.

Ее значения лежат между нулем и единицей при $x \in (-3; -2) \cup (8; 9)$ и больше единицей при $x \in (-2; 8)$. В первом случае $\log_u y$ убивает с возрастанием $y$, во втором — возрастает.

3. $\frac{\pi}{2} + \pi k, 2\pi k, -\frac{\pi}{6} + \pi k, k \in Z$. Указание и.e. Данное уравнение эквивалентно системе $\left\{ \begin{array}{l} (\sin x \pm 1/2) (\cos^2 x - \cos x) = 0, \\ \sin x (\cos x - 1) \cos x \geq 0. \end{array} \right.$

4. $\frac{S_1}{S_2} = \frac{3\pi \sin^2 \alpha \cos \alpha}{4(1 + \cos \alpha)}$, где $S_1$ — площадь поверхности полушара, $S_2$ — боковая поверхность пирамиды. Указание и.e. Рассмотрим сечение пирамиды плоскостью, перpendикулярной основанию и двум противоположным боковым граням. В таком случае выразить через радиус полушара все необходимые данные для нахождения площади.

5. $a \in [1/8; +\infty)$. Указание и.e. После замены переменной $u = 3^x$ данное неравенство эквивалентно системе $\left\{ \begin{array}{l} u^2 + (2a+4)u + 8a + 1 > 0, \\ u > 0. \end{array} \right.$

Остается выяснить, при каких значениях параметра $a$ часть графика парабoles $y = u^2 + (2a+4)u + 8a + 1$, лежащая в правой полушокости, целиком лежит в верхней полушокости.

Вариант 2

1. $a-2$ и $4-2a$ при $a \notin \left\{ -\frac{1}{2}; 1; \frac{4}{3} \right\}$, 5 при $a = -\frac{1}{2}, (-1)$ при $a=1, \left(-\frac{2}{3}\right)$ при $a=\frac{4}{3}$.
2. 0.
3. $\pm \sqrt{\pi k}, \pm \sqrt{\frac{\pi}{3} + 2\pi k}, k \geq 0, k \in Z$. Сумма корней, принадлежих отрезку $[-\pi; 0]$, равна $S = -(\sqrt{\pi/3} + \sqrt{\pi} + \sqrt{5\pi/3} + \sqrt{2\pi} + \sqrt{7\pi/3} + \sqrt{3\pi})$.
4. $BD = 2\sqrt{2}$, площадь сечения, являющегося квадратом, равна $8(3-2\sqrt{2})$. Указание и.e. Для нахождения ребра $BD$ удобно рассмотреть сечение пирамиды плоскостью, содержащей это ребро и перпендикулярной основанию пирамиды. Чтоби найти все сечения, являющиеся квадратами, заметьте, что в таких случаях секущая плоскость должна быть параллельна двум скрещивающимся под прямым углом ребрам. Такая пара ребер только одна $-BD$ и $AC$. Нетрудно понять, что из всех плоскостей, параллельных двум этим ребрам, только одна дает в сечении квадрат.

5. $(-4; 17/4)$. Указание и.e. График функции $y = |x+a|$ отличается от графика функции $y = |x|$ лишь сдигром вдоль оси абсцисс. Множество тех значений $x$, где выполнено данное неравенство, расположено между точками касания парабoles $y=4-x^2$ с графиком функции $y=|x+a|$ при двух указанных выше значениях параметра $a$.
