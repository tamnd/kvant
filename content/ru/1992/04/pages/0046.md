Решаем это уравнение относительно того из неизвестных, при котором нахождение наименьший (по модулю) коэффициент, т. е. в данной случае относительно $y$:

$$y = \frac{232 - 7x}{5}.$$

Подставляем в это выражение вместо $x$ натуральные числа, меньше 5, т. е. 0, 1, 2, 3, 4. В результате находим:

$$x = 0, \quad y = \frac{232}{5} = 46 \frac{2}{5},$$

$$x = 1, \quad y = \frac{232 - 7}{5} = 45.$$

Итак, одно решение данного уравнения получено: $x = 1, y = 45$.

Этот пример решения неопределенного уравнения целесообразно употреблять в тех случаях, когда коэффициент при каком-либо из неизвестных не велик по модулю.

Коль скоро найдена одна пара целых решений, то легко найти и все также решения.

Теорема 3. Неопределенное уравнение

$$ax + by = c,$$

в котором $a$ и $b$ являются взаимно простыми числами, допускает бесконечное множество целых решений. Все эти решения задаются формулами

$$x = \alpha + bt, \quad y = \beta - at,$$

где $(\alpha; \beta)$ — неокоторое решение уравнения (1), $a$ $t$ — произвольное целое число.

Доказательство. Так как по условию пара $(\alpha; \beta)$ является решением нашего уравнения, то подстановка $x = \alpha, y = \beta$ в уравнение дает тожество

$$a \mu + b \beta = c.$$

Вычитая это тожество из нашего уравнения, имеем

$$a(x - \alpha) + b(y - \beta) = 0,$$

откуда

$$x = \alpha + \frac{b(\beta - y)}{a}.$$

Чтобы $x$ было целым числом, необходимо, чтобы $b(\beta - y)/a$ было целым, т. е. чтобы произведение $b(\beta - y)$ делилось на $a$ без остатка. Но $a$ и $b$ — взаимно простые числа; стало быть, для этого необходимо, чтобы $(\beta - y)/a$ равнаяLOB неокоторому целому числу. Обозначим это целое число через $t$:

$$\frac{\beta - y}{a} = t.$$

Тогда $y = \beta - at$ и, следовательно,

$$x = \alpha + \frac{b(\beta - y)}{a} = \alpha + bt,$$

что и требовалось доказать.

Второй способ решения

Сперва рассмотрим один частный случай. Допустим, что коэффициент при одном из неизвестных равняется единице. Например, рассмотрим уравнение

$$x + by = c.$$

Отсюда

$$x = c - by.$$

Положив $y = 0$, получим для $x$ целое значение $x = c$. Следовательно, одна пара решений уравнения имеет вид $x = c, y = 0$. Все же целые решения задаются формулами

$$x = c + bt, \quad y = -t.$$

Аналогично, если коэффициент при $y$ равен 1, то все целые решения задаются формулами

$$x = t, \quad y = c - at.$$

На этом заменении основан общий способ решения неопределенного уравнения в целых числах. В самом деле, если бы нам удалось привести уравнение $ax + by = c$ к уравнению, в котором один из коэффициентов равен единице, то задача была бы решена. Но когда $a$ и $b$ — взаимно простые числа, такое приведение всегда возможно. Пусть, например, дан уравнение

$$17x - 37y = 55.$$
