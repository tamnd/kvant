Санкт-Петербургский государственный технический университет

Математика

Вариант 1
(радюфизический факультет)

1. Найдите область определения функций
$$f(y) = \sqrt{16y^{-2} - 4y^{-1} + 0,25}(4y^{-2} + y^{-3/2})(32 - y^{3/2} - 4y + 8y^{1/2})^{-1}$$
и множество ее значений на промежутке [0,25; 0,5].

2. Решите систему уравнений
$$\begin{cases} x + \log_2 y = y \log_2 3 + \log_2 x, \\ x \log_2 72 + \log_2 x = 2y + \log_2 y. \end{cases}$$

3. Решите неравенство
$$\sqrt{13^x - 5} \leq \sqrt{2(13^x + 12)} - \sqrt{13^x + 5}.$$

4. Найдите расстояние между наиболее коротким и наиболее ширим положительным корнем уравнения
$$\sin \pi(x - 1)^2 = \sin \pi(x^2 + 2x + 1).$$

5. Плоскость делит медианы граней $ABC, ACD$ и ADB треугольной прямиды $ABCD$, выходящие из вершины $A$, в отношениях 2:3, 1:2 и 2:5, считая от вершины. Пусть $P, Q, R$ — точки пересечения этой плоскости с прямыми $AB, AC, AD$. Найдите отношения $AP:PB, AQ:QC$ и $AR:RD$.

Вариант 2
(физiko-технический факультет)

1. Решите уравнение
$$2 \log \sqrt{2} 2 + \log \sqrt{2} \left(2x^2 - 1 - \frac{1}{4}\right) = \log \sqrt{2} 31.$$
2. Решите неравенство
$$32^{3(x^3 - 8)} \geq 8^{19(2x - x^2)}$$
3. Решите уравнение
$$x^3 + 3x^2 - 6x + a = 0$$
зная, что оно имеет три различных действительных корня, образующих геометрическую прогрессию.

4. Найдите все значения параметра $a$, при которых неравенство
$$|3 \sin^2 x + 2a \sin x \cos x + \cos^2 x + a| \leq 3$$
выполняется для любых значений $x$.

5. Две касающиеся сферы вращены в двумгранный угол величины $\pi/3$. Пусть $A$ — точка касания первой сферы с первой гранью, $B$ — точка касания второй сферы со второй гранью. Найдите отношение $AK:KL$, если $K$ и $L$ — точки пересечения отрезка $AB$ с первой и второй сферами соответственно.

Вариант 3
(физiko-технический факультет)

1. Варифметический прогрессии $a_7 = 9$. При каком значении разности арифметической прогрессии произведение $a_1 a_2$ будет наиболее ширим?

2. Решите неравенство
$$2\sqrt{x} \cdot 4^x + 5 \cdot 2^{x+1} + 2\sqrt{x} - 4 \geq 2^{2x+2} + 5\sqrt{x} \cdot 2^x.$$
3. Известно, что многочлен $1,5x^2 + 12x + 26$ равен сумме кубов двух линейных функций. Найдите эти функции.

4. В треугольной прямиде три двумгранных угла прямы. Один из отрезков, соединяющих середины противоположных ребер, равен 4, а другой $\sqrt{3}$. Найдите длину наиболее ребра прямиды.

5. Найдите все значения параметра $a$, при которых любой корень уравнения
$$3\sin^3 x - a(2a + 1)\cos^3 x + 2a^2 \cos x = 0$$
