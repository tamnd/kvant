12. Скорость бруска с пуляй сразу после неупругого соударения найдем из закона сохранения импульса

$$mv = (M + m) u,$$
а максимальную деформацию пружины из закона сохранения энергии

$$(M + m) u^2 / 2 = k x_m^2 / 2.$$

Отсюда находим искому воеличину:

$$x_m = \frac{mv}{M + m} \sqrt{\frac{M + m}{k}}.$$

14. Из закона сохранения электрического заряда

$$2CU_0 = \varepsilon CU + CU,$$
где $C$ — первоначальная емкость каждого конденчатора, получаем, что напряжение становится равным

$$U = 2U_0 / (\varepsilon + 1).$$

15. В соответствии с законом электромагнитной индукции, в коллеце возникнет ЭДС индукции

$$\mathcal{E} = |\Delta \Phi / \Delta t| = B \pi R^2 / \Delta t$$

(Δt — время выключения поля), и по коллецу потечет ток

$$I = \mathcal{E} / r = B \pi R^2 / (r \Delta t).$$

Поскольку заряд связыван с током соотношениям $I = q / \Delta t$, получаем

$$q = I \Delta t = B \pi R^2 / r.$$
