Тригонометрические задачи

1. Выясните, какое из двух чисел больше:
a) sin 5 или sin 6;
b) tg 3 или tg 3°;
c) sin 3 или sin 3°;

d) arcsin $\frac{2}{3}$ + arcsin $\frac{3}{4}$ или $\frac{\pi}{2}$;

e) arctg $\frac{1}{2}$ или $\frac{\pi}{5}$; ж) arctg $\frac{2}{3}$ или $\frac{\pi}{5}$;

f) arctg $\frac{3}{4}$ или $\frac{\pi}{5}$.

2. Вычислите:
a) arcsin sin 10; 6) arccos cos 10;
b) arctg tg 10; r) arctg ctg 10;
d) sin $\left(2 \arccos \frac{1}{3}\right)$; e) cos $\left(2 \arcsin \frac{1}{3}\right)$;
ж) cos (arctg 5);
з) tg$^3$ x + ctg$^3$ x, если sin x + cos x = a.

3. Доказите точность:
a) $1 + \text{tg} x + \text{tg}^2 x + \text{tg}^3 x = \frac{\sqrt{2} \cos \left(\frac{\pi}{4} - x\right)}{\cos^3 x}$;
b) $\frac{\text{tg} 2x \text{tg} x}{\text{tg} 2x - \text{tg} x} = \sin 2x$;
c) $\frac{\sin 2x - \sin 3x + \sin 4x}{\cos 2x - \cos 3x + \cos 4x} = \text{tg} 3x$;
d) $\frac{3 - 4 \cos 2\alpha + \cos 4\alpha}{3 + 4 \cos 2\alpha + \cos 4\alpha} = \text{tg}^4 \alpha$;
e) arcsin x + arccos x = $\frac{\pi}{2}$;
ж) arctg x + arctg x = $\frac{\pi}{2}$.

4. Решите тригонометрические уравнения:
a) $\cos \left(2x - \frac{\pi}{3}\right) = \frac{1}{2}$;
b) $\sin \left(3x + \frac{\pi}{4}\right) = \frac{\sqrt{3}}{2}$;
c) tg $\left(5x + \frac{\pi}{8}\right) = -\frac{1}{\sqrt{3}}$;
d) cos x + cos 5x = 2; ж) sin x sin 5x = 1;
e) sin cos x = cos sin x; ж) tg 2x tg 7x = 1;
f) tg (4 sin x) = $\sqrt{3}$; ж) ctg (3 cos x) = 1;
k) sin 5x = sin x + sin 2x;
л) cos x + cos 3x + cos 5x + cos 7x = 0;
м) sin$^2$ x + sin$^2$ 2x + sin$^2$ 3x + sin$^2$ 4x = 2;
н) 3 sin 2x + 8 cos$^2$ x = 1;

o) cos x cos 3x = cos 2x;
п) 3 sin x + 4 cos x = 5;
p) sin x sin 3x + sin 4x sin 8x = 0;
c) $2 \sin^2 x + \sin^2 2x = \frac{5}{4} - 2 \cos 2x$;
т) $2 \sin^2 x = 4 \sin^2 2x + 7 \cos 2x - 6$;
y) $\cos^6 x + \sin^6 x = \frac{15}{8} \cos 2x - \frac{1}{2}$;
ф) $3(\cos x - \sin x) = 1 + \cos 2x - \sin 2x$;
x) $1 + \sin 2x = \cos x - \sin x$;
ц) $\frac{1}{\sin x} - \frac{1}{\sin 2x} = \frac{1}{\sin 3x}$;
ч) 4 tg 4x - 4 tg 3x - tg 2x = = tg 2x tg 3x tg 4x;

5. Решите «комбинированное» уравнение:
a) $4 |\sin x| + 2 \cos 2x = 3$;
b) $\sqrt{10} \cos x = \sqrt{4 \cos x - \cos 2x}$;
c) $|\text{ctg}(2x - \frac{\pi}{2})| = 1 - \frac{1}{\cos^2 2x}$;
d) $\sqrt{\cos x} = \sqrt{2} \sin \frac{x}{2}$;
e) cos x - 2 sin 2x - cos 3x = = |1 - 2 sin x - cos 2x|;
ж) $\sqrt{12 - 5 \sin \left(x + \frac{\pi}{4}\right)} + 2 \sin x = = \frac{3 \sqrt{2}}{2} - 2 \cos x$;
э) $(4 \sin x + 1 + \sqrt{3 + 5 \cos 2x - 16 \sin x}) \times (1 + 3 \cos 2x) = 0$.

5. Решите уравнение с обратными тригонометрическими функциями:
a) $2 \arcsin x = \arccos 3x$;
b) $\arcsin x \cdot \arccos x = -1$;
c) arctg (x - 1) = 3 arctg (x + 1);
d) $2 \arcsin x + \arccos 2x = \pi/2$;
e) arcsin x = 2 arctg x;
ж) $2 \arcsin x = \arcsin \left(2x \sqrt{1 - x^2}\right)$;
э) $2 \arccos x = \arccos \left(2x^2 - 1\right)$;
ч) arccos $\left(\frac{2}{\pi} \arccos x\right) = \arcsin \left(\frac{2}{\pi} \arcsin x\right)$.
