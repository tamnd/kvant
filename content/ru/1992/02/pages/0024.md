Решения задач
M1296—M1300, Ф1313—Ф1317

М1296. Из многоугольника можно получить новый многоугольник с помощью следующей операции: разрезать его по отрезку на 2 части, одну из частей перевернуть и присать к другой части по линии разреза, если при этом части не будут общих точек, кроме точек разреза. Можно ли с помощью нескольких таких операций из квадрата получить треугольник?

Ответ: нельзя.

Прежде всего заметим, что при указанных в условии операциях не меняются ни перimetр, ни площадь многоугольника. Докажем, что площадь треугольника perimetра 2p меньше площади квадрата того же perimetра. Площадь квадрата равна $p^2/4$. Площадь треугольника, равную по формуле Герона $S = \sqrt{p(p-a)(p-b)(p-c)}$, можно оценить с помощью неравенства между средним геометрическим и средним арифметическим:

$$\sqrt{S} = \sqrt[4]{p(p-a)(p-b)(p-c)} < \frac{p+p-a+p-b+p-c}{4} = \frac{p}{2},$$

откуда $S \leqslant \frac{p^2}{4}$. (В неравенстве знак <, а не ≤, так как $p, p-a, p-b$ и $p-c$ не могут быть равны.) И. Воронивич

М1297. Числа α и β удовлетворяют равенствам
$$\alpha^3 - 3\alpha^2 + 5\alpha = 1,$$
$$\beta^3 - 3\beta^2 + 5\beta = 5.$$
Найдите α + β.

М1298. Вилет логерien — карточка, на котором имеется 50 пустых подряд расположенных клеток. Каждый участующий в логере во все клетки записывается числа от 1 до 50 без повторений. Организаторы логерien по таким же правилам заполняют свою карточку-эталон. Вызывающим считается billion, у которого хотя бы в одной клетке записано такое же число, какое записано в этой клетке карточки-эталона. Какое наиболее количество billion надо заполнить цраноцему, чтобы иметь вызывший billion независимо от того, как заполняна карточка-эталон?

Ответ: нельзя.

Пусть $f(x) = x^3 - 3x^2 + 5x = (x-1)^3 + 2(x-1) + 3$. Функция $g(y) = y^3 + 2y$ — возвращющая и нечетная. Из равенств $g(\alpha-1) = f(\alpha)-3 = -2$ и $g(\beta-1) = f(\beta)-3 = 2$ следует, что $\alpha-1 = -(\beta-1)$. Поэтому $\alpha + \beta = 2$. В. Кукушкин

Ответ: 26 билетов.

Чтобы наверняка выиграть, 26 билетов можно заполнить, например, так:

1, 2, 3, ... 25, 26, 27, ... 50
2, 3, 4, ... 26, 1, 27, ... 50
25, 26, 1, ... 23, 24, 27, ... 50
26, 1, 2, ... 24, 25, 27, ... 50

В карточке-эталоне хотя бы одно из чисел 1, 2, ..., 26 должно находиться на одном из первых 26-ти мест, поскольку остальные мест всего 24. Это число и сделает одну из заполнений карточек выиграшной.
