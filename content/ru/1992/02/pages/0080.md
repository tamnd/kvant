5. 0, $\pm (\sqrt{5}/2)a$.
Перештем уравнение в виде
$$\cos (f(x + a/2)) = \cos (f(x - a/2))$$,
где $f(z) = z/(z^2 + a^2)$. Оно равносильно совокупности уравнений

$$f(x + a/2) \pm f(x - a/2) = 2\pi k, \quad k \in \mathbb{Z}.$$

Функция $f$ всегда определяна, непрерывна, имеет произвольную $f' = (a^2 - z^2)/(z^2 + a^2)^2$, равную нулю при $z = \pm a$, причем $z = -a$ точка минимума, а $z = a$ — максимума, и

$$f_{\min} = f(-a) = -1/(2a) \geq -\pi,$$
$$f_{\max} = f(a) = 1/(2a) \leq \pi$$

при $a \geq 1/(2\pi)$. Так как точки $z_1 = x + a/2$ и $z_2 = x - a/2$ ни при каких $x$ не могут быть однозначенно точками экстремума, то

$$|f(z_1) \pm f(z_2)| \leq |f(z_1)| + |f(z_2)| < 2\pi,$$

позному возможен только случай $k = 0$. Следовательно, при $a \geq 1/(2\pi)$ исходное уравнение равносильно совокупности уравнений

$$\begin{cases} f(x + a/2) + f(x - a/2) = 0, \\ f(x + a/2) - f(x - a/2) = 0, \end{cases}$$

в свою очередь равносильно совокупности

$$\begin{cases} 2x(3a^2/4 + x^2) = 0, \\ a(5a^2/4 - x^2) = 0. \end{cases}$$

Отсюда $x_1 = 0, x_2 = a \sqrt{5}/2, x_3 = -a \sqrt{5}/2$.

6. $(- \infty; -0,99) \cup (-0,02; 0) \cup (0; 0,01)$.
Данное неравенство равносильно совокупности систем неравенств
$$\begin{cases} 0 < x - p < 1, \\ x^3 > (x - p)^2 \end{cases} \text{ и } \begin{cases} x - p > 1, \\ 0 < x^2 < (x - p)^2, \end{cases}$$

в свою очередь равносильно совокупности двух систем:
$$\begin{cases} 0 < x - p < 1, \\ |x| > x - p \end{cases} \text{ и } \begin{cases} x - p > 1, \\ 0 < |x| < x - p. \end{cases}$$

При $|x| < 0,01$, она равносначающая совокупности двух систем неравенств:
$$\begin{cases} |x| < 0,01, \\ 0 < x - p < |x| \end{cases} \text{ и } \begin{cases} |x| < 0,01, \\ x - p > 1. \end{cases}$$

Если при каком-то значении $p$ системы
$$\begin{cases} 0 < x - p < |x|, \\ |x| < 0,01 \end{cases}$$

имеет решение, то $-0,02 < x - p < x < 0,01$; наоборот, если число $p$ принадлежит интервалу $(-0,02; 0,01)$, то система имеет решение при всех таких $p$, кроме $p = 0$. Аналогично системы

$$\begin{cases} x - p > 1, \\ |x| < 0,01 \end{cases}$$

имеет решение тогда и только тогда, когда $p < x - 1 < -0,99$.
