Задача 7. Докажите неравенство
$6a + 4b + 5c \geqslant 5\sqrt{ab} + 7\sqrt{ac} + 3\sqrt{bc}$, где $a \geqslant 0, b \geqslant 0, c \geqslant 0$.

Решение. Положив $t = \sqrt{a}$, запишем неравенство как квадратичное относительное $t$:
$$6t^2 - (5\sqrt{b} + 7\sqrt{c})t + 4b + 5c - 3\sqrt{bc} \geqslant 0.$$

Дискриминант квадратного трехчлена в левой части полученного неравенства равен
$$(5\sqrt{b} + 7\sqrt{c})^2 - 24(4b + 5c - 3\sqrt{bc}) = -71(\sqrt{b} - \sqrt{c})^2,$$
т. е. отрицатель при $b \neq c$ и равен нулю при $b = c$.

Таким образом, левая часть этого неравенства всегда неотрицательна и может быть равна нулю лишь при $b = c = a$.

Задача 8. При каких значениях $a$ неравенство
$$-1 < \frac{ax^2 + x + 2}{x^2 + 1} < 3$$
выполняется при всех $x$?

Решение. Из условия сразу следует переформулировка задачи: при каких $a$ каждое из неравенств
$$ax^2 + x + 2 < 3x^2 + 3u$$
$$ax^2 + x + 2 > -x^2 - 1$$
выполняется для всех $x$?

Для первого из них, $(a - 3)x^2 + x - 1 < 0$, получаем условие
$$\begin{cases} a < 3, \\ a < 11/4, \end{cases}$$
т. е. $a < 11/4$. Аналогично, для второго неравенства имеем $a > -1/3$.
Ответ: $-1/3 < a < 11/4$.

Задача 9 (МИФИ, 1990 г.). При каких действительных значениях $a$ неравенство
$$1 - \log_{1/7}(x^2 + 1) \geqslant \log_7(ax^2 + 4x + a)$$
выполняется при всех $x$?

Решение. Исходное неравенство равносильно системе
$$7(x^2 + 1) \geqslant ax^2 + 4x + a > 0,$$
или
$$\begin{cases} (7 - a)x^2 - 4x + 7 - a \geqslant 0, \\ ax^2 + 4x + a > 0. \end{cases}$$

Посленяя система выполняется при всех $x$ тогда и только тогда, когда каждое из квадратных неравенств выполняется при всех $x$, т. е. при условиях
$$\begin{cases} 0 < a < 7, \\ 4 - (7 - a)^2 \leqslant 0, \\ 4 - a^2 < 0. \end{cases}$$

Решая полученную систему, приходим к ответу.
Ответ: $2 < a \leqslant 5$.

Задача 10 (МГУ, экономический факультет, 1988 г.). Найдите все значения параметра $a$, при которых неравенство
$$|3\sin^2x + 2a\sin x\cos x + \cos^2x + a| \leqslant 3$$
выполняется для любых значений $x$.

Решение. Если $x = 0$, неравенство принимает вид
$$|a + 3| \leqslant 3.$$

Его решение дает нам ограничения на $a: -6 \leqslant a \leqslant 0$.

При $cos x \neq 0$ поделим обе части неравенства на $\cos^2x$ и выполним замену $t = tgx$. В результате получим (воспользовавшись формулой $\frac{1}{\cos^2x} = 1 + tg^2x$) неравенство
$$|(a + 3)t^2 + 2at + a + 1| \leqslant 3(1 + t^2),$$
которое должно выполнять при всех $t$.

Это неравенство эквивалентно системе
$$-3 - 3t^2 \leqslant (a + 3)t^2 + 2at + a + 1 \leqslant 3(1 + t^2).$$
