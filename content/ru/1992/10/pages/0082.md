4. Рассмотрим единные векторы $\vec{e}_1, \vec{e}_2, \vec{e}_3, \vec{e}_4$, перpendикулярные границы тетраэдра и направленные внутри него. Пусть $\vec{a}$ — вектор, перpendикулярный данному треугольнику и по длине равный его площади. Тогда $P_i = |(\vec{a}, \vec{e}_i)|$ для $i = 1, 2, 3, 4$. Умножив равенство $S_1 \vec{e}_1 + S_2 \vec{e}_2 + S_3 \vec{e}_3 + S_4 \vec{e}_4 = 0$ скалярно на $\vec{a}$, получим $P_1 S_1 = |(\vec{a}, S_1 \vec{e}_1)| = |(-\vec{a}, S_2 \vec{e}_2) - (\vec{a}, S_3 \vec{e}_3) - (\vec{a}, S_4 \vec{e}_4)| \leq P_2 S_2 + P_3 S_3 + P_4 S_4$.

5. Решение этой задачи будет опубликовано позже в «Задачике «Кванта».

Так как $65/16 > 4$ и $25/9 < 3$, то после последней пары будет выдан ответ (левое число больше правого).
6) Предположив, что прибор бесконечно должно сравнивать числа $x_1 = \log_a b < \log_c d = y_1$, возьмем натуральные числа $m_0, m_1$, для которых $x_1 < m_0/m_1 < y_1$. Тогда, применив несколько раз первое правило, прибор перейдет к числам $\{x_1\} < \{y_1\}$, где $\{a\}$ означает дробную часть числа $a$. Между $\{x_1\}$ и $\{y_1\}$ лежит число $m_2/m_1$, где $0 < m_2 < m_1$, число $m_2$ — натуральное. Применив второе правило, прибор перейдет к числам $x_2 = 1/\{y_1\} < y_2 = 1/\{x_2\}$, между которых лежит число $m_1/m_2$. Далее снова применяется первое правило и т. д. Но тогда получается убывающая последовательность натуральных чисел $m_1, m_2, m_3, \dots$, которая не может быть бесконечной. Противоречие.
