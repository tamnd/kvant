IV Всероссийская олимпиада
по информацией

I тур. Решение п. А задачи основывает на том факте, что для заданных координат (x1, y1), ..., (xN, yN) множество W либо пусто (ломанную построить нельзя), либо включает только одну ломанную. Действительно, исходя из условия a) и 6), через каждую точку излома можно проверить одно вертикальное звено, направленное вверх или вниз. Поскольку каждое такое звено определяется двумя точками, то количество вершин, имеющих одинаковую абсциссу, должно быть четным, и тогда по этим вершинам можно однозначно восстановить все вертикальные звены ломаной путем попарного соединения вдоль каждой абсциссы. Аналогичное можно сказать и о всех звенях, параллельных оси абсцисс. Из этого следует, что при выполнении условий тестики, заданный набор точек, в которых ломаная претерпевает излом, будет однозначно определить ломаную, удовлетворяющую условия a) и b).

Легко видеть, что полученная таким образом ломаная может не являться исключой, так как здесь могут иметь место самопересечения, либо она может оказаться разомкнутой. Дополнительные проверки должны установить факт наличия или отсутствия ломаной в множестве W.

Основная идея решения п. Б задачи свойства к следующему. Оndу из заданных точек излома последовательно соединяется с каждой из оставшихся точек, совмещая при этом с полученным направлением одну из осей координат. Для каждой из расположений осей координат осуществляется пересечет координат всех заданных точек излома, после чего с помощью ранее рассмотренного для п. А алгоритма находим требуемое решение. Легко видеть, что это можно сделать в цикле, для которого равна (N — 1).

II тур. При решении этой задачи важное значение имеет структура данных, используя для формального описания компостера и конфигурации ответственный в билете. Для этих целей лучше использовать матричное представление. В частности, в качестве элементов матрицы компостера P (размерность матрицы S×S) необходимо взять квадраты расстояний между центрами соответствующих штырей. Эта матрица является симметричной с нулевыми элементами на главной диагонали. То же самое можно сказать и о матрице билета R (размерность матрицы N×N).

Для решения п. А задания матрицы P можно не использовать, так как компостер в этом случае будет однозначно определить только квадратом расстояния S0 между центрами двух штырей. Возможность произвольным компостером заданной конфигурации ответственный в билете (см. п. 1) связана с наличием S0 в каждой строке матрицы R. Это можно проверить, анализиру последовательно строки матрицы R, начняя с первой. Просмотр можно ускорить, исключая из последующего рассмотрения строки, номера которых совпадаетют с номерами позиций элементов S0 в текущей строке. При определении числа компостеров K, с помощью которых можно пробить заданного конфигурацию ответственный в билете (см. п. 2), необходимо учитывать тот факт, что возможность компостер характеризуется одним из элементов первого строки матрицы R. Выполнить для каждой элемента этой строки первый пункт задания A, можно определить искому число K. Если K=0, то для нахождения компостера, обеспечивающего пробивку максимального количества ответственных в билете (см. п. 3), необходимо для каждой элемента матрицы R, расположенного слева от главной диагонали (таких элементов будет N×(N — 1)/2), подсчитать, в скольких строках этой матрицы он содержится. Элемент, имеющий максимальное значение этой величины, будет соответствовать искому компостеру. Требуемое в п. 4 минимальное число нажатий для пробивки всех ответственных в билете заданным компостером S0 определяется из условий минимизации количества пробивок одних и тех же ответств. В худшем случае пробивается за (N — 1) нажатие, в лучшем за [(N + 1)/2] нажатий. Очевидно, что j-ю точку в билете можно пробить однозначно, если в j-ей строке матрицы R величина S0 встречается один раз. С учетом этого путем целенаправленного перебора можно определить искому число нажатий.

Выполнение п. B. задания, в отличие от п. A., существенно усложняется по двум принципам. Во-первых, компостер в этом случае необходимо отображать уже в виде матрицы P размерность S×S, а во-вторых, одна и та же конфигурация штырей компостера может описывать различными матрицами P. Посленее также справедливо и для описания конфигурации пробивных ответств в билете. Исходя из этого, на начальном этапе решения важно установить, каким образом можно определить попадание штырей компostера в ответстве в билете при однократном его нажатии. Анализируя всевозможные ситуации, можно принять к выводу, что все штыри компostера попадут в какие-либо S ответств в билете, если в матрице R найдется S различных строк, каждой из которых включает все элементы одной из строк матрицы P, причем между этим строками должно быть взятим однозначное соответствие. Если хотя бы для одной строки матрицы не удается найти соответствующее строку в матрице R, то можно сразу сказать, что таким компостером нельзя пробить заданного конфигурацию ответств в билете. В п. 1 этой части задания достаточно определить одно подходковую таких строк в матрице R. Максимальное число названных подмножества равно числу сочетаний из N по S. Если требуемые подмножества сформировать, то путем перебора 2n — 1 вариантов нажатия (n — число найденных подмножества), можно решить п. 4. Учитывая сказанное выше, находим решение и для других пунктов этой задачи.
