Найти с этого номера, мы в течение всего учебного года будем публиковать тематические подборки задачи по основным разделам школьного курса математики. Решение предлазаемых задачи помогет вам лучше усовойти школьный курс, а также подготовиться к вступительным экзаменам вузы. Публикуя их, мы надемся хотя бы частично скоппенсировать острейший дефицит литературы, дополляющей школьные учебники.
Первая наша подборка содержит алгебраические уравнения и неравенства. Задания эти взяты из вариантов вступительных экзаменов в различные buses, пособий для поступающих, а также составлены автором подборки.

1. Решите уравнения «с моделем»:
a) $2|x+1| - |x| = 1$;
b) $|x| - 2|x+1| + 3|x+2| = 4$;
c) $x^2 - |x| - \frac{1}{4}| = 0$;
d) $|x^2 - 2|x| = 3x^2 - x$;
e) $|x| - |x| - |x-1|| = 1/2$;
f) $||-x-4| + x+2| = x+7$;
g) $||x^3 - 3x^2 - 1| - 4| = x^3 + 3x^2 + 3$;

2. Решите рациональные уравнения:
a) $x^2 + 1993x + 1992 = 0$;
b) $1992x^2 - 1993x + 1 = 0$;
c) $(x^2 - 2x)^2 = 3(x-1)^2 - 13$;
d) $\frac{1}{x^2} + \frac{1}{(x+1)^2} = \frac{5}{4}$;
e) $(\frac{x-1}{x})^2 + (\frac{x-1}{x-2})^2 = \frac{40}{9}$;
f) $x(x-1)(x+3)(x-4) + 36 = 0$;
g) $(x^2 - 3x+1)^2 + 3(x-1)(x^2 - 3x+1) = 4(x-1)^2$;
h) $3\frac{x^2 + 3x+1}{x^2 - x+1} = \frac{2x^2 - x + 2}{x^2 + x+1}$;
k) $x^2 + 4x - 1 = 0$.

3. Решите irrationalные уравнения:
a) $x = 1 + \sqrt{7-x}$;
b) $\sqrt{1 + 4x - x^2} = x - 1$;
c) $\sqrt{8x+1} - \sqrt{x-2} = 4$;
d) $\sqrt{3x+1} + \sqrt{4x-3} = \sqrt{5x+4}$;
e) $\frac{\sqrt{6 - x - x^2}}{2x-5} = \frac{\sqrt{6 - x - x^2}}{x-2}$;
f) $\sqrt{x-3+4} = \sqrt{x-3}$;
g) $8\sqrt{12 + 16x - 16x^2} + 4x - 4x^2 = 33$;
h) $\sqrt[3]{x+7} - \sqrt[3]{x-9} = 4$;

k) $\sqrt[3]{x+1} + \sqrt[3]{2x+1} = \sqrt[3]{3x+2}$;
l) $\sqrt{5x+7} - \sqrt{x+4} = 4x+3$;
m) $\sqrt{x^2+x} + \sqrt{x^2+x+5} = \sqrt{2x^2+2x+17}$;
n) $\sqrt{(x+4)(2x+3)} - 3\sqrt{x+8} = 4 - \sqrt{(x+8)(2x+3)} + 3\sqrt{x+4}$;
o) $\sqrt{3x^2-1} + \sqrt{x^2+2} = \sqrt{3x^2+2x-3} + \sqrt{x^2+3x-1}$;
p) $\sqrt{\frac{1+2x\sqrt{1-x^2}}{2}} = 1 - 2x^2$;
c) $\sqrt{x+1} - \sqrt{2x+1} + \sqrt{x+5} - 3\sqrt{2x+1} = 2\sqrt{2}$;
d) $(x^2-4|x|+3|x| < 1$;
e) $(x^2-5|x| \leq x+3$;
j) $(x^2-3|x| \geq x+2$;
k) $(2x^2-x-1) \geq |x^2-3x-1|$;
i) $\frac{|2-x|}{|x-3|} \leq 2$;
k) $(x^3-3x+1) \leq |x^3+x^2-1|$;
l) $(x^3-3x+1) \leq |x^3+x^2-1|$;
m) $(x^3-3x+1) \leq |x^3+x^2-1|$;
n) во всех уравнений пункт 1 замените знак «=» на «>» и решите полученные неравенства.

5. Решите рациональные уравнения:
a) $x^3 - 36x \leq 0$;
b) $(x^2 - 2x - 1)(x^2 - 2x - 3) \leq 4$;
c) $(x^2 - 3x + 1) \leq |x^3 + x^2 - 1|$;
d) $(x^3 - 3x + 1) \leq |x^3 + x^2 - 1|$;
e) $(x^2 - x - 1) \geq \frac{x}{3x^2 - x - 3}$;
f) $(x^2 + 3x)(2x + 3) - 16\frac{2x + 3}{x^2 + 3x} \geq 0$;
g) $(x^2 + 6)(\frac{x-4}{x+4})^2 + \frac{x-6}{x+6}(\frac{x+9}{x-9})^2 > 2\frac{x^2 + 36}{x^2 - 36}$;
h) во всех уравнений пункт 2 замените знак «=» на «>» и решите полученные неравенства.
