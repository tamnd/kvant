⟦folio 43⟧

$$\frac{\log_2 x}{1 + \log_2 x} + \frac{\log_2 x}{2 + 3 \log_2 x} = 0,$$
или, после замены $y = \log_2 x$,
$$\frac{y}{1 + y} + \frac{y}{2 + 3y} = 0.$$

Решая это уравнение, найдем корни $y_1 = 0, y_2 = -\frac{4}{3}$, после чего без труда получим решение этой Equation.

Теперь рассмотрим две задачи, при решении которых используются свойства monotonности неокоторых функций.

Пример 9. Решить уравнение $\log_5(x + 3) = 3 - x$.

Решение. Легко проверить, что $x = 2$ является корнем данного уравнения. Других корней оно, очевидно, не имеет, поскольку функция $\log_5(x + 3)$ возвращает во всей своей области определения, а функция $y = 3 - x$ — убивает.

Ответ. {2}.

Пример 10. Решить уравнение $(x + 1)\log_3^2 x + 4x\log_3 x - 16 = 0$.

Решение. Положим $y = \log_3 x$ и решим относительно $y$ квадратное уравнение $(x + 1)y^2 + 4xy - 16 = 0$.

Получаем $y = \frac{4}{x + 1}$, либо $y = -4$. Осталось решить два уравнения:

$$\log_3 x = \frac{4}{x + 1} \text{ и } \log_3 x = -4.$$

Второе из этих уравнений легко решается, а для решения первого достаточно заменить, что $x = 3$ удовлетворяет уравнению и функция, стоящая в левой части, возвращает при $x > 0$, а функция, стоящая в правой части, — убивает.

Ответ. $\left\{\frac{1}{81}; 3\right\}$.

В заключение рассмотрим уравнение, которое решается из других соображений.

Пример 11. Решить уравнение $3x^2 - 2x^3 = \log_2(x^2 + 1) - \log_2 x$.

Решение. Правая часть уравнения определяна при $x > 0$ и равна $\log_2\left(x + \frac{1}{x}\right)$. Поскольку $x + \frac{1}{x} \geq 2$ при $x > 0; \log_2\left(x + \frac{1}{x}\right) \geq 1$. С другой стороны, $3x^2 - 2x^3 \leq 1$ при $x > 0$ (в этом можно убедиться, например, исследовать функцию с помощью произвольной). $\log_2\left(x + \frac{1}{x}\right) = 1$ при $x = 1$. Поскольку $3x^2 - 2x^3$ тоже равно 1 при $x = 1$, левая часть равна правой только при $x = 1$.

Ответ. {1}.
