Задачи

Этот раздел ведется у нас из номера в номер с момента основания журнала. Публикуемые в нем задачи не стандартны, но для их решения не требуется знаний, выходящих за рамки школьной программы. Найболее трудные задачи отмещаются звездочкой. После формировки задачи мы обычно указываем, кто нам ее предложил. Разумеется, не все эти задания публикуются впервые. Задачи по математике этого номера представлены на XXII Международной олимпiadе школьников, проходившей в Соединенных Штатах Америки.

Решения задач из различных номеров журнала или по разным предметам (математике и физике) присылайте в разных конвертах. Условие каждой оригинальной задачи, предлагаемой для публикации, присылайте в отдельном конверте в двух экземплярах вместе с вашим решением этой задачи.

M716—M720; Ф728—Ф732

M716. Из точки $P$ внутри данного треугольника $ABC$ опускаются перпендикуляры $PA_1, PB_1, PC_1$ на прямые $BC, CA$ и $AB$. Для каких точек $P$ внутри $\triangle ABC$ величана

$$\frac{|BC|}{|PA_1|} + \frac{|CA|}{|PB_1|} + \frac{|AB|}{|PC_1|}$$

принимает наименьшее значение?

M717. Даны натуральные числа $n$ и $r$, $1 \leqslant r \leqslant n$. Рассмотрим всевозможные подмножества множества {1, 2, ..., $n$}, состоящие из $r$ чисел, и в каждом выборе наименьшее число. Докажите, что среднее арифметическое всех выборных чисел равно $(n+1) / (r+1)$. (Например, при $n=3$, $r=2$ получаем три подмножества {1, 2}, {1, 3}, {2, 3} и среднее арифметическое равно $(1+1+2)/3 = 4/3$).

M718. Найдите наименьшее значение выражения $m^2+n^2$ для всехвозможных пар $(m; n)$ натуральных чисел, таких что $1 \leqslant m \leqslant 1981$, $1 \leqslant n \leqslant 1981$ и $|n^2-mn-m^2|=1$.

M719. а) Для каких $n \geqslant 3$ существует множество из $n$ последовательных натуральных чисел, обладающих следующим свойством: наименьшее из этих $n$ чисел является делителем наименьшего общего кратного остальных $n-1$ чисел?

6) При каких $n \geqslant 3$ существует единственное множество из $n$ последовательных чисел, обладающих указанным свойством?

M720. Про функцию $f$, определяную на множество всех пар неотрицательных целых чисел $(x; y)$, известно следующей:

$$1^\circ. f(0, y) = y+1,$$
$$2^\circ. f(x+1, 0) = f(x, 1),$$
$$3^\circ. f(x+1, y+1) = f(x, f(x+1, y))$$

для каждой пары $x \geqslant 0, y \geqslant 0$. Найдите значение $f(4, 1981)$.

Ф728. Три маленьких шарика с одинаковыми массами — красный, синий и зеленьй, закреплены неверсным каркасом в верхинах равностороннего треугольника со сторонами $l$. Система положена на главную горизонтальную поверхность и приведена во врашение с периодом $T$ воркруг центра масс.
