Г. Гуревич

Системы разновесов

Проблема Эрдема

Системой разновесов называется совокупность натуральных чисел, из которого нельзя извлечь два различных набора с одинаковой суммой (например, числа 1, 3, 7, 20 образуют систему разновесов, а числа 1, 2, 3, 4, 5, 8 не образуют: 2+3+4=8+1).

В 1956 году известный венгерский математик П. Эрдем сформировал следующую проблему: Найти наименьшее натуральное число m(k) такое, чтобы из натуральных чисел, не превысodiaщих m(k), можно было выделить систему разновесов из k чисел.

Другая, в известном смысле образная проблeme Эрдема задача состоит в нахождении наиболее колисества l(N) разновесов среди чисел, не превысodiaщих данного натурального N.

Несмотря на большой интерес, вызванный поставленными задачими у специалистов по теории чисел, теории кодирования и комбинаторному анализу, полностью они до сих пор не решены. Получены лишь некоторые оценки чисел m(k) и l(N), причем вопрос точно эти оценок остается открытым.

В задаче М675 («Кваант», 1981, № 3) мы предложили нашим читателем получить некоторые оценки, относится к проблeme Эрдема, для конкретных k и N. Именено, мы предложили доказать, что из чисел, меньших 1000, можно выделить систему разновесов a) из 10 чисел; б) из 11 чисел; с) из 14 чисел из них выбрать нельзя; е) если числа образуют систему разновесов, то сумма их образных величины не превысодит 5/2. И, наконец, мы предложили д) из чисел, меньших 700, выбрать систему разновесов, состоящую из 11 чисел.

Оценки сверху

Некоторые грубые оценки сверху числа m(k) можно получить из очень простых соображений.

В самом деле, k чисел 1, 2, ..., 2^{k-1} образуют системы разновесов при любом натуральном k.

Упражнение 1. Докажите это.

Поэтому, оценindo, m(k) ≤ 2^{k-1}. В частности, из чисел 1, 2, ..., 1000 выделяется система разновесов из 10 чисел 1, 2, ..., 2^9 = 512. Это дает решение пункта a) задачи М675.

Легко строится система разновесов и из 11 чисел, не большех 1000.

В самом деле, k чисел 3, 3·2, 3·2^2, ..., 3·2^{k-1} также образуют системы разновесов.

Совв. Добавим к ним два числа 3·2^{k-1} - 1 и 3·2^{k-1} + 1 и докажем, что получащие числа также образуют системы разновесов.

Если какой-то набор из этих чисел содержит оба добавленных числа (тогда набор из оставшихся чисел их не содержит), то его сумма не меньше, чем 3·2^k, и, следовательно, больше суммы всех остальных чисел.

Если же какой-нибудь набор содержит одно добавленное число, то любой набор, его не содержащий, будет иметь сумму, дающий при делении на 3 остаток, отличный от остатка при делении на 3 суммы исходного набора.

При k=9 получаем систему разновесов 3, 6, 12, ..., 767, 768, 769 из 11 чисел (это дает решение пункта 6)).

Итак, m(11) ≤ 769. Вообще же нами получена оценка m(k) ≤ 3·2^{k-2} + 1.

Оценка сизу

Попробуем теперь оценить число m(k) сизу. Пусть a₁ < a₂ < ... < aₖ — система разновесов из k чисел (k>1).

Очевидно, что ka_k - 1 ≥ a₁ + a₂ + ... + aₖ. Поскольку любые два набора из данных чисел имеют разные суммы, а общее число набора из k чисел равно 2^k - 1, получаем неравенство a₁ + a₂ + ... + aₖ ≥ 2^k - 1.

Упражнение 2. Убедитесь в этом.

Поэтому ka_k ≥ 2^k, то есть a_k ≥ 2^k/k. В частности, для k=14 получим a₁₄ ≥ 2^14/14 > 1000. Это дает решение пункта b).

Итак, m(k) ≥ 2^k/k.

Теперь мы можем оценить сумму $\frac{1}{a_1} + ... + \frac{1}{a_k}$. Поскольку любая система разновесов сама является системой разновесов, неравенство a_i ≥ $\frac{2^i}{i}$ справедливо при любом i, большем 1. Отсюда

$$\frac{1}{a_1} + \frac{1}{a_2} + ... + \frac{1}{a_k} \leq 1 + \frac{2}{2^2} + \frac{3}{2^3} + ... + \frac{k}{2^k}.$$

Вычислим сумму S(k) = $\frac{2}{2^2} + ... + \frac{k}{2^{k-1}}$ и поэтому,

$$S(k) = 2S(k) - S(k) = 1 + \frac{1}{2^2} + \frac{1}{2^3} + ... + \frac{1}{2^{k-1}} - \frac{k}{2^k} = \frac{3}{2} - \frac{k+2}{2^k} < \frac{3}{2}.$$

Таким образом,

$$\frac{1}{a_1} + \frac{1}{a_2} + ... + \frac{1}{a_k} < \frac{5}{2},$$

— утверждение пункта г) также доказано.
