Нет ничего проще. Подберем, например, $a, b$ и $c$ так, чтобы выражение $f(n) = an + b + c \cdot 9^n$ принадлежало (кале угодно!) целые значения при $n = -1$, $n = 0$ и $n = 1$. тогда по теореме 2 (при $k = 2$) число $f(n)$ будет целым при любом целом $n \geq -1$.

Возьем, скажем, $f(-1) = -1$, $f(0) = 0$, $f(1) = 4$. Решив систему

$$\begin{cases}
-a + b + c/9 = -1, \\
b + c = 0, \\
a + b + 9c = 4.
\end{cases}$$

мы найдем $a = \frac{5}{8}$, $b = -\frac{27}{64}$, $c = \frac{27}{64}$.

Теорема 3. Если $q_1, q_2, \dots, q_r$ – целые числа $u$
$f(n) = c_1 q_1^n + c_2 q_2^n + \dots + c_{r-1} q_{r-1}^n + c_r q_r^n$
— целое при $n = 1, 2, \dots, r$, то $f(n)$ – целое при любом натуральном $n$.
(Лемма 1 – частный случай теоремы при $r = 2, q_2 = 1$).

Указание. Для доказательства теоремы 3 полезно рассмотреть разность $g(n) = f(n+1) - q_r f(n)$. Поскольку $g(n) = c_1 (q_1 - q_r) q_1^n + \dots + c_{r-1} (q_{r-1} - q_r) q_{r-1}^n$ – сумма $r-1$ геометрических прогрессий и в условиях теоремы число $g(n)$ – целое при $1 \leq n \leq r-1$, доказать теорему можно индукцией по $r$: ведь
$$f(n) = g(n-1) + q_r g(n-2) + \\
+ q_r^2 g(n-3) + \dots + q_r^{n-1} g(1) + q_r^n f(1).
$$

Теорема 4. Пусть выражение $f(n)$ является суммой $r$ многочленов, умноженных на некоторые геометрические прогрессии. Составим многочлен со старшим коэффициентом 1, корни которого — значенатели этих $r$ прогрессий, а кратность каждого корня на единицу больше степени соответствующего ему многочлена. (Степень $k$ этого характеристикого многочлена равна сумме количества $r$ прогрессий и степени всех многочленов, на которых они умножены.) Если (1) все коэффициенты характеристикого многочлена — целые числа и (2) значения $f(n)$ – целые при $n=1, 2, \dots, k$, где $k$ – степень характеристикого многочлена, то $f(n)$ будет целым и при всех натуральных $n>k$.
