Силы $\vec{F}_3$ и $\vec{F}_4$, действующие на боковые стороны рамки, очень/no, будут равны по величины и противоположны по значку:

$$|\vec{F}_3| = |\vec{F}_4| = \frac{(B_0 + k(z_t - a/2)) + (B_0 + k(z_t + a/2))}{2} Ia =$$

$$= (B_0 + kz_t) \frac{ka^3}{R} |v_z|,$$

$$\vec{F}_3 + \vec{F}_4 = 0.$$

Следовательно, $v_x = const$, то есть рамка будет двигаться вдоль оси $X$ с постоянной скоростью, равной начальной скорости $v_0$.

Таким образом, характер движения рамки в направлении оси $Z$ определяется силами $\vec{F}_1$, $\vec{F}_2$ и силой тягости $m\vec{g}$. При установившейся скорости $v$ рамки проекция скорости на ось $Z$ постоянна, то есть ускорение $\vec{a}_z$ вдоль оси $Z$ равно нулю:

$$m|\vec{a}_z| = m|\vec{g}| + |\vec{F}_1| - |\vec{F}_2| = mg - \frac{k^2 a^4}{R}|v_z| = 0.$$

Отсюда находим проекцию $v_{yct. z}$ на ось $Z$ установившейся скорости рамки:

$$v_{yct. z} = mgR/k^2 a^4.$$

Установившаяся скорость рамки равна $v = \sqrt{v_0^2 + v_{yct. z}^2}$, где $v_0$ — проекция скорости $v$ на ось $X$, равная, как мы показали, начальной скорости, сообщенной рамке. Таким образом,

$$v_0 = \sqrt{v^2 - v_{yct. z}^2} = \sqrt{v^2 - \left(\frac{mgR}{k^2 a^4}\right)^2}.$$

Скорость $v_{yct. z}$ может быть найдена и из энергетических сообщений. При установившемся движения рамки изменение за время $\Delta t$ потенциальной энергии рамки в поле тягости Земли равно тепловой энергии, выделяющейся за это время в рамке:

$$mgv_{yct. z}\Delta t = l^2_{yct. z}R\Delta t = \left(\frac{ka^2}{R}\right)^2 v^2_{yct. z}R\Delta t.$$

Отсюда

$$v_{yct. z} = \frac{mgR}{k^2 a^4}.$$

Ф677. С помощью системы концентрических зеркал (рис. 1) на экране получено изображение Солнца. Радиус зеркал $R_1 = 12$ см, $R_2 = 30$ см. Каково должно быть фокусное расстояние тонкой линии, чтобы с ее помощью получалось изображение Солнца такое же размер?

Задча может быть решена двумя способами.

1. В фокальной плоскости первого зеркала (радуса $R_1$) получается изображение Солнца, которое является предметом для второго зеркала (радуса $R_2$). Если угловой размер Солнца равен $a$, то размер этого изображения равен $l = aF_1 = aR_1/2$; находится изображение на расстоянии $d_2 = R_2 - R_1/2$ от второго зеркала. Увеличение второго зеркала равно $\Gamma_2 = F_2/(d_2 - F_2) = R_2/(R_2 - R_1)$. Размер изображения, получается в системе зеркал, равен

$$L_3 = l\Gamma_2 = \frac{aR_1}{2} \frac{R_2}{R_2 - R_1} = a \frac{R_2 R_1}{2(R_2 - R_1)}.$$

Тонкая линия создает в своей фокальной плоскости изображение Солнца размер

$$L_\pi = aF_\pi.$$

Чтобы получить изображение размер $L_\pi = L_3$, надо взять линзу с фокусным расстоянием

$$F_\pi = \frac{R_2 R_1}{2(R_2 - R_1)} = 10\text{ см}.$$
