1. Для $n = 4k$ и $n = 4k + 1$ при любой расстояние знаков «+» и «-» четности левой и правой части не совпадают.
Для $n = 4k + 2$ возможно следующее расстояние знаков:
$$1 + 2 - 3 - 4 + 5 + 6 - \dots - (2k + 1) - (2k + 2) + (2k + 3) + (2k + 4) - \dots + (4k + 1) + (4k + 2) = 4k + 3.$$
Для $n = 4k + 3$ — следующее:
$$-1 + 2 + 3 - 4 - 5 + 6 + \dots + (4k + 3) = 4k + 4.$$
2. Обозначим исследуемую сумму через $S$. $3S - (x + y + z) = 45$ (рис. 1), то есть
$$S = 15 + \frac{x + y + z}{3}.$$
$S$ принимает минимальное значение, когда $x + y + z = 1 + 2 + 3 = 6$, и максимальное — когда $x + y + z = 7 + 8 + 9 = 24$; таким образом, $S_{\min} = 17$, $S_{\max} = 23$.
Нетрудно убедиться, что $S$ не может равнять 18. Действительно, если $S = 18$, то $x + y + z = 9$. Возьмем тот из четырех треугольников (со стороны 2), в которых входит 9; пусть остальные числа в нем $x, y$ и $t$ (рис. 2). Тогда $x + y + t + 9 = 18$, откуда $t = z$ — противоречие.
