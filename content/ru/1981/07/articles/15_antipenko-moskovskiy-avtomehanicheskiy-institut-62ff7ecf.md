⟦folio 45⟧

Задча 10. В прямугольном треугольнике $ABC$ из вершины пря-мого угла проведена высота $CD$. Перimetры треугольников $ACD$ и $CBD$ равны $P_1$ и $P_2$ соответственно. Найдите перimetр треугольника $ABC$.

Задча 11. Докажите неравенство

$$\sqrt[3]{6 + \sqrt[3]{6} + \sqrt[3]{6}} + \sqrt[3]{6 + \sqrt[3]{6}} < 5.$$

Задча 12. Докажите, что для всякого треугольника $ABC$
a) $\cos \hat{A} + \cos \hat{B} + \cos \hat{C} \leq \frac{3}{2}$;
b) $\cos 2\hat{A} + \cos 2\hat{B} + \cos 2\hat{C} \geq -\frac{3}{2}$.

Вариант 2

1. Найти площадь фигуры, многоесточеек $(x; y)$ которого удовлетворяет системе неравенств
$$\begin{cases} x^2 + y^2 \leq r^2 (r > 0) \\ x - y \leq 0 \\ y \geq 0. \end{cases}$$

2. Решить систему уравнений
$$\begin{cases} 4x = \left(\frac{1}{3}\right)^x \cdot 1728 \\ \log_4 x = \frac{1}{2} - \log_4 y + \log_4^3. \end{cases}$$

3. Написать уравнение парабoles, симметричной параболе $y = \frac{x^2}{2} - 2$ относительно прямой $x = 4$.

4. Найти области определения функций
$$f(x) = \frac{\sqrt{2x-4}}{\sqrt[3]{x-1}-2}.$$

5. Упростить выражение
$$\frac{\sin \alpha + \mathrm{tg} \alpha}{\mathrm{tg} \alpha} + 1 - \cos \alpha$$
и найти возможность значения $\alpha$.

Вариант 3

1. Найти площадь фигуры, ограниченной линиями $x = 1, x = 2, y = 0, \log_2 x + \log_2 y = 0$.

2. Найти уравнение образа парабoles $y = x^2 + 2x + 2$ при параллельном пересечении $\vec{p} = \vec{i} - \vec{j}$.

3. Варифметический прогрессии $(a_n)$ известны $a_8 = 11,2$ и $a_{15} = 19,6$. Каково число членов этой прогрессии, меньших 30?

4. Найти области определения функций
$$y(x) = \sqrt{\frac{3^x - 4^x}{2x^2 - x + 5}}.$$

5. Упростить выражение
$$\frac{2 \sin \alpha + \sin 2\alpha}{2 \cos \alpha + \sin 2\alpha} \cdot \frac{1 - \cos \alpha}{1 - \sin \alpha}$$
и найти возможность значения $\alpha$.

Задание 4

1. Указать многоесточеек $(x; y)$ плоскости, для которых
$$\log_1(x^2 + y^2) = -\frac{1}{2}.$$

3. Междук ккамиц цельми числами расположено число lg 283?

4. Последовательность $(x_n)$ задана с помощью рекуррентного соответствия $x_1 = 2, x_{n+1} = x_n + 3$. Задайте последовательность формулой $n$-го члена.

5. Найисать уравнение горизонтальной касательной к параболе $y = x^2 - 3x + 2$.

6. Найти первообразную функцию
$$\varphi(x) = \left(\sin \frac{x}{2} + \cos \frac{x}{2}\right)^2.$$
