Туристы и альпинисты

Туристы, желая пройти из долины $D_1$ в долину $D_2$, идут через перевал (седловину) — при этом максимальная высота на пути из $D_1$ в $D_2$ (рис. 2) оказывается минимальной по сравнению со всеми близкими маршрутами, не проходящими через седло. Альпинисты, желая совершить траверс от вершины $V_1$ к вершине $V_2$, проходят то же седло по другой причине — чтобы не «терять высоту», то есть чтобы была максимально возможной минимальная высота на пути от $V_1$ к $V_2$.

Рисунок 1 показан на карту, где высота перевала принята за нуль, а $x$ и $y$ — это долота и широта. Будем рассматривать прямые, параллельные осями, как возможности пути для туристов и альпинистов. Подобно маршрутам в горах, основные прямые рисуна 1 ($y=5$ и $x=4$) выделены тем, что
$$f(x^*, y^*) = \min_{y} \max_{x} f(x, y) = \max_{x} \min_{y} f(x, y),$$
и это очень полезно при анализе игра. Здесь max $f(x, y)$ — наиболее значение $f$ при заданном $y$ и переменном $x$, то есть это нахождение исход для $B$ при выбранном значении $y$; очевидно, это велича минимальная при $y=5$. Истолкуйте аналогично выбор $x=4$ для играка $A$.

Рассмотрим теперь игра с платежной функцией $v=x^2-y^2$, у которой нет седловой точки (убедитесь в этом). Анализ игра с подобной функцией сильно осложняется. В данном примере противники будут заинтересованы выбирать самые большие числа, как им достичьы. Если ввести ограничения на переменные $x$ и $y$ вида $|x| \leq a, |y| \leq b$, что передко встречается на практике, появятся 4 седловые точки: $x^* = \pm a, y^* = \pm b, (v^* = a^2 - b^2)$.

Однако при такого рода ограничения седловая точка может и не появиться (см. упр. 3).

Решение игры с квадратной платежной функцией

Итог нашим теоретическим рассмотрением подводит следующая теорема. Пусть дана цера с платежной функцией
$$v = ax^2 + 2bxy + cy^2 + 2px + 2qy + r.$$
Эта функция имеет седловую точку, а цера — решение в следующих семи случаях и только в них:
1) $a < 0, c > 0$;
2) $a < 0, c = 0 \neq b$;
3) $a < 0, c = b = q = 0$;
4) $a = 0 \neq b, c > 0$;
5) $a = b = p = 0, c > 0$;
6) $a = c = 0, b \neq 0$;
7) $a = b = c = p = q = 0$.

Седловая точка является решение системы уравнений
$$\begin{cases} ax + by + p = 0, \\ bx + cy + q = 0. \end{cases}$$

Это решение $(x^*, y^*)$ во всех этих случаях, кроме цера, читатель: разбор предыдуших конкретных примеров помогет ему.
