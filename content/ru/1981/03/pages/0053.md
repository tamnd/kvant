1. Найти все значения $x$, удовлетворяющие условию
$(x^2 - 4)\sqrt{x + 1} = 0$.

2. Найти все решения уравнения
$\sin 2x = \sqrt{3}\sin x$.

3. В трапеции длина средней линии равна 4, а углы при одном из оснований имеют величины $40^\circ$ и $50^\circ$. Найти длины оснований трапеции, если длина отрезка, соединяющего середины этих оснований, равна 1.

4. Каательная к графику функции $\sqrt[3]{x^2}$ такова, что абсцисса $c$ точки касания приладлежит отрезку $\left[\frac{1}{2}, 1\right]$. При каком значении $c$ площадь треугольника, ограниченного этой касательной, осью $Ox$ и вертикальной прямой $x = 2$, будет наименшей и чему равна эта наименшая площадь?

5. Найти все значения $a$, при каждом из которых неравенство
$$\log_1(\sqrt{x^2 + ax + 5} + 1) \cdot \log_5(x^2 + ax + 6) + \log_a 3 \geq 0$$
имеетровно одно решение.

Разбор задач варианта 1
1. Ответ. $\{-1, 2\}$.
Почти все абитриенты успешно справились с этой задачей. Оdnako некоторых писали
$$(x^2 - 4)\sqrt{x + 1} = 0 \iff \left[\frac{x^2 - 4}{x + 1} = 0\right];$$
при этом, даже если в окончательный ответ значение $x = -2$ не включалось, экзаменаторы не могли считать задачу решенной безупречно.

2. Ответ. $x_1 = \pi m, x_2 = \pm \frac{\pi}{6} + 2\pi n(m, n \in \mathbb{Z})$.
Указание. Данное уравнение равно с совокупностью двух уравнений:
$$\sin x = 0$$
$$\cos x = \sqrt{3}/2$$

3. Ответ. 3 и 5.

Решение. Пусть $KM$ — средняя линия трапеции $ABCD, LN$ — отрезок, соединяющий оснований BC и AD, $BAD = 50^\circ$, $CDA = 40^\circ$. Отметим, что $|AD| > |BC|$, поскольку $BAD + CDA = 90^\circ < 180^\circ$ (рис. 1). Пусть $Q$ — точка пересечения прямых $AB$ и $DC$. Поскольку $CB \parallel AD$, треугольник $AQD$ подобен треугольнику $BQC$. Поэтому
$$\frac{|BQ|}{|AQ|} = \frac{|BC|}{|AD|} = \frac{|BC|/2}{|AD|/2} = \frac{|BL|}{|AN|}.$$
Так как $QBC = QAD$ и $\frac{|BD|}{|AQ|} = \frac{|BL|}{|AN|}$, треугольники $QBL$ и $QAN$ подобны. Поэтому $BQL = AQN$ и, следовательно, точки $Q, L, N$ лежат на одной прямой. Треугольник $AQD$ — прямой угольный, поскольку $AQD = 180^\circ - QAD - QDA = 90^\circ$. Поэтому $N$ — центр описанной вокруг него окружности; значит, $|QN| = \frac{|AD|}{2}$. Аналогично, $|QL| = \frac{|BC|}{2}$. Итак,
$$\frac{|AD|}{2} - \frac{|BC|}{2} = |QN| - |QL| = |LN| = 1.$$
По свойству средней линии трапеции $\frac{|AD| + |BC|}{2} = |KM| = 4$.
Из системы $\left\{ \begin{array}{l} |AD| - |BC| = 2, \\ |AD| + |BC| = 8 \end{array} \right.$ находим $|AD| = 5, |BC| = 3$.
С этой задачей полностью справились лишь около половины абитриентов. Некоторые абитриенты, получившие правый ответ, не смогли его обосновать. Например, без доказательства принадлежности, что точки $Q, L, N$ лежат на одной прямой.
