$$m - 1 < \frac{99}{101} m < m \text{ при } 1 \leq m \leq 50 \text{ и } m - 2 < \frac{99}{101} m - 1 \text{ при } 51 \leq m \leq 100 \text{ следует, что точки } \left( \frac{99}{101} m; 0 \right) \text{ и } (m; 0) \text{ при } m = 1, 2, \dots, 49 \text{ будут черезаться, затем встретиться точки } \left( \frac{99}{101} \cdot 50; 0 \right), \text{ после чего снова почередно появят точки } \left( \frac{99}{101} m; 0 \right) \text{ и } (m - 1; 0) \text{ при } m = 51, 52, \dots, 100 \text{ (рис. 2). Сумма длины проекций больших отрезков равна } \frac{99}{101} + \left( 2 \cdot \frac{99}{101} - 1 \right) + \dots + \left( 50 \cdot \frac{99}{101} - 49 \right) + \left( 50 - 51 \cdot \frac{99}{101} \right) + \dots + \left( 99 - 100 \cdot \frac{99}{101} \right) = - \frac{99}{101} \cdot 50^2 + 50^2 = \frac{5000}{101},$$

сумма длины проекций черных отрезков равна $99 - \frac{5000}{101} = \frac{4999}{101}$. Искомое отношение, следовательно, равно $\frac{5000}{4999}$.

2. Любое нечетное натуральное число, больше 1, можно представить в виде разности квадратов двух натуральных чисел: $2k + 1 = (k + 1)^2 - k^2$. Запишем произвольную возрастную последовательность натуральных чисел: $a_1 < a_2 < \dots < a_{n-1}$, где $a_1 \geq 3$ — нечетное число, а остальные числа — четные. Сумма квадратов этих чисел $a_1^2 + a_2^2 + \dots + a_{n-1}^2 = 2k + 1$ — нечетное число, причем $k > \frac{a_n^2 - 1}{2} > a_{n-1}$. Положим $a_n = k$, тогда $a_1^2 + a_2^2 + \dots + a_n^2 = (a_n + 1)^2$. Аналогично построим последовательность $b_1 < b_2 < \dots < b_m$, где $b_1 > 2a_n$ — нечетное число, $b_2, \dots, b_{m-1}$ — четные, причем $\frac{b_{i+1}}{b_i} > a_n$, $i = 1, 2, \dots, m - 1$, и $b_1^2 + b_2^2 + \dots + b_m^2 = (b_m + 1)^2$. Запопним таблицу, вписав в клетку, стояшую в i-й строке и j-м столбце, число $b_i^2 a_j^2 = (b_i a_j)^2$.

Полученная таблица удовлетворяет условиям задачи.

3. a) Пусть $O_1$ и $O_2$ — центры окружностей и пусть точка $O_3$ такова, что $AO_1 O_2 O_3$ — параллелограмм. Тогда $O_3$ — центр окружности, описанной около треугольника $ABC$. Действительно, обозначим через $P, L, Q$ проекции на прямую $AB$ точек $O_1, O_2, O_3$ соответственно. Пусть, для определения, $Q$ лежит между $P$ и $L$ (см. рис. 3). Тогда $AQ = AM + MQ$, $BQ = BM - MQ$. Так как $AO_1 = O_3 O_2$, то $AP = QL$ и поэтому $BM = 2ML = 2MQ + 2QL = 2MQ + 2AP = 2MQ + AM$. Следовательно, $BQ = MQ + AM = AQ$, т. е. $O_3$ лежит на средним перепределению к отрезку $AB$. Аналогично доказывается, что $O_3$ лежит на средним перепределению к отрезку $AC$.
