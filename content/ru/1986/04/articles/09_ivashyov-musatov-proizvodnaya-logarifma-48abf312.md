Производная логарифма

В учебном пособии «Алгебра и начала анализа 9—10» на с. 208 выводится формула для произвольной логарифмической функции. Эта формула получается там с помощью теоремы о произвольной обратной функции и формулы для произвольной показательной функции. В этой заметке мы получим формулу для произвольной логарифмической функции непредседательной — нахождения соответствующего предела.

Два важных неравенства

Докажем теперь, что для любого натурального числа n выполено неравенство

$$\left(1 + \frac{1}{n}\right)^n < e < \left(1 + \frac{1}{n}\right)^{n+1}. \quad (1)$$

Из неравенства (1) непредседательно следует, что

$$\lim_{n \to \infty} \left(1 + \frac{1}{n}\right)^n = e$$

(именно так определяется число e вузовских курах математического анализа).

Действительно, возьмем любое число ε>0 и положим N=[$\frac{e}{\epsilon}$]. Тогда для любого натурального n>N выполено неравенство

$$n > \frac{e}{\epsilon} \quad \text{и}$$

$$\left| \left(1 + \frac{1}{n}\right)^n - e \right| = e - \left(1 + \frac{1}{n}\right)^n < \left(1 + \frac{1}{n}\right)^{n+1} - \left(1 + \frac{1}{n}\right)^n = \left(1 + \frac{1}{n}\right)^n \left(1 + \frac{1}{n} - 1\right) < \frac{e}{n} < \epsilon.$$
