Рис. 1.

(LM) || (SB), (KL) || (AC) и (SB) ⊥ (AC), параллелограмм KLMN являются прямогольником с площадью $\frac{ax}{4}$. По теореме косинусов $|AC|^2 = 2l^2 - 2l^2\cos \alpha = |BC|^2 = x^2 + l^2 - 2lx\cos \alpha$, откуда $x_1 = l$, $x_2 = l(1 - 2\cos \alpha)$.

Из $\triangle ASC$ получаем $\cos \alpha = \frac{2k^2 - h^2}{2k^2}$, поэтому $x_2 = l\frac{h^2 - k^2}{k^2}$. Если $h \leq k$, имеется лишь одна парамида, удовлетворяющая условию задачи. Если $k < h < k\sqrt{2}$, то имеется две парамиды (правильная с $x_1 = l$ и неправильная с $x_2 = l(1 - 2\cos \alpha)$).

Вариант 2

1. $x = \pm \frac{1}{4}\arccos \frac{9 - 4a}{9} + \frac{\pi n}{2}$, ($n \in \mathbb{Z}$) при $0 < a \leq \frac{9}{2}$. При остальных значениях $a$ решений нет. Указание. При $a = 0$ решений нет. При $a \neq 0$ воспользуйтесь соответствием $\sin^2 2x = \frac{1 - \cos 4x}{2}$.

2. $10,5 - \frac{6}{25}a$; задача имеет решение при $a \in \left[\frac{175}{6}; 35\right] \cup \left[35; \frac{175}{4}\right]$. Указание. Пусть в первом соудержится $x$ литров шелочи, а во втором — $y$ литров. Из условия следует система

$$\begin{cases} \frac{x+y}{10} = \frac{35}{100}, \\ \frac{3x}{4} + \frac{3y}{6} = \frac{a}{100}, \\ 0 < y < 6, 0 < x < 4. \end{cases}$$

3. $2\arctg \frac{\sqrt{4m_1^2 - m_2^2}}{3m_2}$ при $\frac{1}{2} < \frac{m_1}{m_2} < \sqrt{\frac{5}{2}}$; $\varphi \in \left[\frac{\pi}{2}; \pi\right]$ при $m_1 = \sqrt{\frac{5}{2}}m_2$.

Указание. Пусть $O$ — точка пересечения медиан треугольника ASB. Из $\triangle AOD$ получаем $|AD| = \frac{1}{3}\sqrt{4m_1^2 - m_2^2}$. Рассмотрим два случая: a) $\triangle ASB$ — остроугольный, b) $\triangle ASB$ — неостроугольный. В случае a) треугольник ASB является осевым сечением конуса, и поэтому искомый угол $\varphi = 2\arctg \frac{\sqrt{4m_1^2 - m_2^2}}{3m_2}$. Этот случай реализуется при $tg \frac{\varphi}{2} < 1$, то есть когда $\frac{1}{2} < \frac{m_1}{m_2} < \sqrt{\frac{5}{2}}$. В случае 6) треугольник ASB наиболее плоскый, поэтому быть прямой seizureя ASB конуса, проходящero через вершину $S$, равен $\frac{1}{2}l^2\sin \alpha$, где $\alpha$ — угол между образующими AS и BS, и поэтому принимает наиболее плоское значение $\frac{\pi}{2} \leq \varphi < \pi$.

4. $f'(x) = \frac{4-2x}{(x^2 - 4x + a)^2}; a \in ] - \infty; -21[ \cup [5; +\infty]$.

Указание. Для того чтобы $f(x)$ была определенна при всех $x \in [5; 7]$, необходимо и достаточно, чтобы уравнение $\varphi(x) = x^2 - 4x + a = 0$ не имело корней на этом отрезке. Это в свою очередь будет тогда и только тогда, когда $\varphi(5) > 0$ и $\varphi(7) > 0$, или $\varphi(5) < 0$ и $\varphi(7) < 0$, то есть, когда $\varphi(5) \cdot \varphi(7) > 0$. Поскольку $f'(x) < 0$, при $x \in [5; 7]$ задача свойства к решению неравенства $f(5) \leq \frac{1}{10}$.

Физика

1. Запишем условия равновесия стержня:

$$Mg\left(\frac{l}{2} - \Delta l\right) = 2T\left(\frac{l}{2} + \Delta l\right),$$

где $T$ — сила натяжения нити, на которой подвешены грузы массой $m_1$ и $m_2$. Эту силу можно найти, используя второй закон Ньютона:

$$m_1a = m_1g - T,$$

$$-m_2a = m_2g - T,$$

откуда

$$T = \frac{2m_1m_2g}{m_1 + m_2}.$$

Подставляя этот результат в условия равновесия стержня и использовать уравнение для масс $m_1$ и $m_2$:

$$m_1^2 - m_2^2 + M + \frac{M^2}{4}\left(\frac{l/2 - \Delta l}{l/2 + \Delta l}\right) = 0.$$

Решение этого уравнения дает

$$m_1 = \frac{M}{2}\left(1 + \sqrt{\frac{4\Delta l}{l + 2\Delta l}}\right) = 1,67 \text{ кг},$$

$$m_2 = \frac{M}{2}\left(1 - \sqrt{\frac{4\Delta l}{l + 2\Delta l}}\right) = 0,33 \text{ кг}.$$

2. При движении вверх по наклонной плоскости шайба заменяется силой тяжестеки и силой трения. При этом ускорение шайбы

$$a_1 = g(\sin \alpha + \mu \cos \alpha)$$

и время движения

$$t_1 = \frac{v_0}{a_1} = \frac{v_0}{g(\sin \alpha + \mu \cos \alpha)} = 1,6 \text{ с}.$$

Поскольку задачи требуют вычисления работы за время $t = 3,5$ с ($t > t_1$), необходимо рассмотреть также движение шайбы вниз по наклонной плоскости. В этом случае ускорение шайбы

$$a_2 = g(\sin \alpha - \mu \cos \alpha)$$
