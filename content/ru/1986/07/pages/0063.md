Как расположены корни трехчленов?

1. $x < -\frac{11+\sqrt{103}}{2}, -\frac{31+\sqrt{805}}{6} < x < -\frac{31+\sqrt{805}}{6}, x > \frac{-11+\sqrt{109}}{2}$.

2. Записав неравенство в виде $x^2 - 3x + 1 < x - a < 3x - x^2 - 1,$ получим систему неравенств $f(x) < 0, g(x) < 0,$ где $f(x) = x^2 - 4x + 1 + a, g(x) = x^2 - 2x + 1 - a.$ Эта система может иметь решение только при положительных дискриминатах трехчленов $f(x)$ и $g(x),$ то есть при $0 < a < 3$.

При $0 < a < \frac{3-\sqrt{5}}{2}, \frac{3-\sqrt{5}}{2} < a < \frac{3+\sqrt{5}}{2}, \frac{3+\sqrt{5}}{2} < a < 3,$ корни трехчленов $f(x)$ и $g(x)$ расположены соответственно в следующем порядке:

$x_2 < x_4 < x_3 < x_1; x_4 < x_2 < x_3 < x_1; x_4 < x_2 < x_1 < x_3.$

В случае $f(a) = 0$ (а — общий корень трехчленов) найдите вторые корни трехчленов $f(x)$ и $g(x)$ по теореме Виета и покажите, что при $a = \frac{3-\sqrt{5}}{2}$ и $a = \frac{3+\sqrt{5}}{2}$ соответственно $x_2 = x_4 < x_3 < x_1$ и $x_4 < x_2 < x_1 = x_3.$

3. Умножив неравенство на $a$ и сделав замену $y = 2ax,$ получим неравенство, которое может быть представлено в виде $(y^2 + 2y - a)(y^2 - 2a + 4) \ge 0.$

Обозначим через $y_1, y_2,$ и $y_3,$ корни трехчленов $y^2 + 2y - a$ и $y^2 - 2y - a + 4.$ При $0 < a \leq 3$ получаем $x \leq \frac{y_2}{2a}, x \geq \frac{y_1}{2a}.$ При $a > 3$ получаем $x \leq \frac{y_2}{2a}, \frac{y_4}{2a} \leq x \leq \frac{y_1}{2a}, x \geq \frac{y_3}{2a}.$

4. Положив $f_k(x) = 3x^2 + 2kx - k - 1,$ получим $f_k(x) = f_n(x) \Leftrightarrow x_0 = \frac{1}{2},$ причем $f_k(x_0) = -\frac{1}{4}$ при всех $k = 1, 2, \dots, 10,$ то есть $f_k(x_0) < 0.$ Обозначив корни трехчлена $f_k(x)$ через $q_k, p_k, (g_k < p_k),$ получим следующие корней:

$q_{10} < \dots < q_2 < q_1 < p_{10} < p_9 < \dots < p_1,$ так что решением данной системы является промежуток $q_1 \leq x \leq p_10,$ заключенный между корнем первого трехчлена и большим корнем десятичного трехчлена.

Ответ: $-\frac{\sqrt{7} + 1}{3} \leq x \leq \frac{\sqrt{133} - 10}{3}.$

В 9 часов угол между стрелками равен $90^\circ.$ За час часовая стрелка проходит $1/12$ часы окружности, то есть $30^\circ,$ так что за 20 минут часовая стрелка проходит $\frac{1}{3}$ от этой части, то есть $10^\circ.$ Аналогично минутная стрелка, проходящая за час $360^\circ,$ за 20 минут прошедет $120^\circ.$ Поэтому к 9 часов 20 минут угол между стрелками в $90^\circ$ уменьшится на $10^\circ$ и увеличится на $120^\circ,$ став равным $200^\circ.$ Дополнительный к нему угол равен $160^\circ.$

2. $495 + 459 = 954.$

3. Во-первых, из чайника без двючки плох разливать заварку, так как образущеся в нем разрежение прейстствует вытеканию жидкости из чайника. Во-вторых, при подогрении заварного чайника, наоборот, возникнет повышенное давление пара в чайнике, которое приводит к самопроизводному выливанию жидкости из носика чайника.

4. Если число не окачивается на 9, то сумма цифр следующнего за ним числа больше его суммы цифр на 1, поэтому такое число не может быть искомым. Если число окачивается на 9 (но не на 99), то сумма цифр следующнего за ним числа меньше его суммы цифр на 8, что опять не соответствует условиям задачи. Если же число окачивается на 99 (но не на 999), то сумма цифр у следующнего за ним числа цифр рассматриваемого числа на 17. Поэтому, если сумма цифр такого числа делится на 17, то и сумма цифр следующнего за ним числа тоже делится на 17.

Найдем наименьшее число, окачивающееся на два нуля, у которого сумма цифр делится на 17. Очевидно, это 8900. Предыдущое же число 8899 является искомым, так как числа, окачивающиеся на 999 и на 9999, не удовлетворяют условиям задачи — сумма цифр при перехождение к следующему числу в первом случае уменьшается на 26, а во втором случае — на 35. 5. Обозначим число грибов, найdenных каждым мальчиком, первой буквой его имены. Тогда по условию задачи

$A + B = B + \Gamma, A + \Gamma < B + B, \Gamma > B.$

Складывая первые два соответствия, получаем, что $B > A,$ а вычитая из второго соответствия первое, находим, что $B > \Gamma.$ Итак, $B > \Gamma > B > A,$ то есть именно расположить в следующем порядке: Воря, Гена, Витя, Алик.
