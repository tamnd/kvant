6) Пусть

$$x = \frac{1}{k_1} + \frac{1}{k_2} + \frac{1}{k_3} < 1, \quad k_1 \leqslant k_2 \leqslant k_3.$$

Если $k_1 \geqslant 3$, то $x \leqslant 1/3+1/3+1/4=11/12$; если $k_1=2, \quad k_2 \geqslant 4$, то $x \leqslant 1/2+1/4+1/5=19/20$; если $k_1=2, \quad k_2=3$, то $k_3 \geqslant 7$ и

$$x \leqslant 1/2+1/3+1/7=41/42.$$

Таким образом, $\mu_3=41/42$ и из (2) следует, что $a \leqslant 42$. Перебирая эти $a$, можно выбрать те, для которых $a-1$ представляется в виде суммы трех делительей $a-1$. Ответ: $a=4, 6, 8, 10, 12, 18, 20, 24$ и 42.

в) Докажем, что для любого $c>0$ в множество чисел, принадлежащих $X_n$ и меньше $c$, есть наиболее число $\mu_n(c)$. (Для решения задачи достаточно доказать это для $c=1$, но более общее утверждение легче доказать индикцией по $n$.) Например, что $X_n$ — бесконечное множество чисел вида

$$x = \frac{1}{k_1} + \frac{1}{k_2} + \dots + \frac{1}{k_n},$$

(3)

где $k_1, k_2, \dots, k_n$ — натуральные числа.

Для $n=1$ нашей утверждение очевидно: $\mu_n(c)$ — это наиболее число вида $1/k$, меньше $c$, то есть $1/[c+1]$ (квадратные скобки ознакомают целую часть числа). Пусть нашей утверждение доказано для $X_{n-1}$; доказем его для $X_n$.

Выберем натуральное $k$ такое, что $n/k < c$ (можно взять $k=[n/c]+1$). Тогда среди чисел $x$ из $X_n$, меньше $c$, имеется число $n/k$ (сумма $n$ дробей $1/k$), а в представлении (3) любого числа $x$, также, что $n/k < x < c$, хотя одна из дробей $1/k_i$ больше $1/k$, то есть $k_i \leqslant k-1$. При этом $x-1/k_i$ принадлежит $X_{n-1}$ и наиболее из таких $x$ — а это и есть $\mu_n(c)$ — будет равно наиболее из конечного набора чисел

$$\frac{n}{k}, \quad \mu_n\left(c - \frac{1}{k-1}\right) + \frac{1}{k-1},$$

$$\mu_n\left(c - \frac{1}{k-2}\right) + \frac{1}{k-2}, \dots, \quad \mu_n\left(c - \frac{1}{l}\right) + \frac{1}{l}$$

(где $l$ — наиболее натуральное число, для которого $c-1/l>0$, то есть $l=[1/c]+1$).

Оказывается, можно для каждой $n=3, 4, \dots$ указать наиболее число $a_n$, для которого $a_n-1$ представляется в виде суммы $n$ делительей $a_n$: довольно давно была сформированная гипотеза о том, что $\mu_n(1)$ — близкая слева к 1 число вида (3) — равно сумме первых $n$ дробей $n$ дробей

$$\frac{1}{2} + \frac{1}{3} + \frac{1}{7} + \frac{1}{43} + \frac{1}{1807} + \dots,$$

в котором знаменатель каждой дроби на 1 больше произведения знаменателя всех предыдуших; из нее вытекает, что $a_n$ — это произведение знаменателя первых $n$ дробей (то есть $a_{n+1}=a_n^2-a_n$).
