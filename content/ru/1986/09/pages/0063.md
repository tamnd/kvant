Урок одной задачи

3. Поскольку векторы $\vec{BC}$ и $\vec{AD}$ сопправлены, существует гомотетия с центром в точке $E$ (см. рис. 2 с. 23) и коэффициент $k_1 = BC:AD$, при котором
$$H_0^{k_1}:BC \rightarrow AD, B \rightarrow A, C \rightarrow D, F \rightarrow H.$$
Следовательно, точки $E, F, H$ лежат на одной прямой $EF$. Поскольку векторы $\vec{BC}$ и $\vec{DA}$ противонаправлены, существует гомотетия с центром $O$ и коэффициент $k_2 = -OB:OD$, при которой
$$H_0^{k_2}:BC \rightarrow DA.$$
Следовательно, точки $O, F, H$ принадлежат прямой $OH$. Приемые $EF$ и $OH$ имеют две общие точки $(F, H)$, следовательно, они совпадают.
4. На прямой $AK$ выберем произвольную точку $X$ (рис. 1), соединим ее с точкой $C$ и с точкой $B$. Примяя $KC$ пересекает $XB$ в точке $O$, через точки $A$ и $O$ проведем прямую $AO$, которая пересечет отрезок $XC$ в точке $E$. Отрезок $KE$ — искомый.
6. Учитывая построения, рассмотренные в задаче 5, найдем отрезок длиной $y$, чтобы
$$\frac{1}{y} = \frac{1}{a} + \frac{1}{c}.$$
Затем строим отрезок длиной $x$, чтобы
$$\frac{1}{x} = \frac{1}{y} + \frac{1}{b}.$$
9. Пусть $m$ и $n$ — данные параллельные прямые, $P$ — данные точка. Производим построения, показанные на рисунке 2: проводим через точки $P$ — произвольную прямую, которая пересечет параллельные прямые в точках $D$ и $A$, $X$ — произвольная точка, принадлежащая прямой $AP$. Проводим через эту точку произвольную прямую — получаем точки $C$ и $B$. Затем проводим $AC$ и $BD$ — получаем точку $K$, проводим $KX$, получаем точку $H$ — середину $AB$, затем проводим $CP$ — получаем точку $E$, прямая $DE$ пересечет $BX$ в точке $L$, прямая $PL$ искодая.

Избранные школьные задачи

1. a) Воспользовитесь очевидными неравенствами:
$$a^2 \geq a^2 - (b - c)^2,$$
$$b^2 \geq b^2 - (c - a)^2,$$
$$c^2 \geq c^2 - (a - b)^2.$$
6) Воспользовитесь формулами $R = \frac{abc}{4S}$, $r = \frac{2S}{a + b + c}$, где $S = \frac{1}{4} \sqrt{(a + b + c)(a + b - c)(a + c - b)(b + c - a)}$, и задачей 1, a).
Равенство достигается в случае равностороннего треугольника.
2. $x^6 + 2x^4 + 2x^3 + x^2 + 2x - 1 = (x^3 + x + 1)^2 - 2$. Отсюда наименьшее значение данного многочлена равно $-2$ (когда $x^3 + x + 1 = 0$). (Интерес представляется тот факт, что наименьшее значение определять можно, а соответствующое значение $x$ — нельзя.)
3. $n^4 + 64 = (n^2 + 8)^2 - 16n^2 = (n^2 + 4n + 8)(n^2 - 4n + 8)$.
4. Одно решение находится подбором: $100 + 27 + 1 = 128$, то есть $x = 10, y = 3, z = 1$.
