Ниже мы приводим несколько задач последующих equations.

1. (1973 г.). Девять отмеченных точек расположены внутри единного квадрата. Докажите, что среди них найдутся три, которые либо лежат на одной прямой, либо являются вершинами треугольника с площадью, не превысading 1/8.

2. (1975 г.). Пусть $A, B, C, D$ — четыре точки в пространстве. Докажите, что

$$AC^2 + BD^2 + AD^2 + BC^2 \geq AB^2 - CD^2.$$

3. (1976 г.). Найдите решения уравнения в целях числа $a, b, c$:

$$a^2 + b^2 + c^2 = a^2 b^2.$$

4. (1978 г.). Целое число $n$ называем хорошим, если его можно представить в виде $n = a_1 + a_2 + ... + a_k$, где $a_1, a_2, ..., a_k$ — натуральные числа (не обязательно различные), удовлетворяющие соотношения $\frac{1}{a_1} + \frac{1}{a_2} + ... + \frac{1}{a_k} = 1$.

Известно, что натуральные числа 33, 34, ..., 73 — хорошие. Докажите, что все натуральные числа, не меньше 33, являются хорошими.

5. (1979 г.). В некоторых организациях имеется $n$ человек ($n \geq 5$), а также $n + 1$ комитетов, состоящих из трех человек, причем в разных комитетах составы учетников не одинаковы. Докажите, что найдется два комитета сровно одним общим участником.

6. (1980 г.). Найдите максимальное число трехленных аргументических прогрессий, которые могут быть выбран из последовательности чисел $a_1 < a_2 < ... < a_n$.

7. (1980 г.). В терраде вписана сфера, которая касается граней террада в их центрах тяжесте (то есть в точках пересечения медиан). Докажите, что терраде — правильный.

8. (1980 г.). Найдите все числа $a_0$, для которых бесконечная последовательность ($a_n$), определяная равенствами $a_n = 2^{n-1} - 3a_{n-1}$ при $n = 1, 2, 3, ...$, строго возрастает, то есть $a_{n-1} < a_n$ при всех $n$.

9. (1981 г.). Дан угол, величины которого равна $\frac{180^\circ}{n}$, где $n$ — натуральное число, не делается на 3. Докажите, что (значая $n$) можно разделить этот угол на три равных угла только с помощью циркуля и линейки.

10. (1981 г.). Даны $n$ точки, никакие четыре из которых не лежат в одной плоскости. Пусть $A$ — множество всех террадров с вершинами в этих точках. Плоскость $a$ не содержит ни одной из данных точки. Докажите, что среди всех сегейтров из множества $A$ плоскостью $a$ чет孵угулников не более чем $n^2(n-2)^2$.

11. (1982 г.). В обществе, состоящем из 1982 учеток, среди любой группы из четырех учеток есть по крайней мере один, кто знаком с остальных триями. Каково наименование коллектива людей, которые знаком со всеми?

12. (1984 г.). Математическая equation is solved in two ways. First, the solution is found using a linear equation, and second, using a quadratic equation. The second method is more efficient, as it requires fewer steps and less computational effort.

13. (1985 г.). В пространстве данных четырех чисел, что из шести попарных расстояний между ними не более двух превышают 1. Найдите максимальное возможное значение суммы всех этих шести расстояний.
