Биоминальные коэффициенты

Выше мы почти не затрагивали сами простой и, пожалуйста, самый важный случай двух букв. Коэффициенты многочлена (a+b)^n имеют специальное обозначение C^k_n, а формула (a+b)^n = C^0_n a^n + C^1_n a^{n-1} b + ... + C^n_n b^n

называется формулой биома Ньютона. Мы знаем, что C^k_n — количество слов из n букв, среди которых k букв и n-k буква a — можно найти по формуле

$$C^k_n = \frac{n!}{(n-k)! k!} = \frac{n(n-1)...(n-k+1)}{k!}.$$

Например,

$$(a+b)^4 = a^4 + 4a^3 b + 6a^2 b^2 + 4ab^3 + b^4,$$

поскольку

$$C^0_4 = C^4_4 = \frac{4!}{4!0!} = 1,$$

$$C^1_4 = C^4_3 = \frac{4!}{3!1!} = 4,$$

$$C^2_4 = \frac{4!}{2!2!} = 6.$$

Биоминальные коэффициенты — числа C^k_n — возникают в самых различных задачах биоманторики, алгебры, геометрии, математической анализа, теории вероятности. Они связаны многочленскими красными тождествами; например, из равенства C^k_n + C^k_{n-1} = C^k_{n+1} (см. задачу 5) следует, что при всех натуральных n и k, 0≤k<n,

$$C^k_n + C^k_{n+1} + ... + C^k_n = C^k_{n+1}.$$

(для k=1 это — формула, с которой мы начали статью). Более подробно об этих замечательных числах будет расссказано в одном из следующих номеров журнала.

Приложение: Вычисление биоминальных коэффициентов на калькулятор В3-34.

При больших n вычисление биоминальных коэффициентов вручную — весма трудомка задача. Ниже приведется программа для калькулятор В3-34*), позволяющая вычислить коэффициенты C^k_n для любого n≤334 и всех k≤n (при этомные ответы получаются при n≤28; при больших n программах дает приближенные ответы**)).
