Задание 3

Tri частицы массой $m$ соединены упругими нерастунными пружинами каждой сжеткости $k$ и находятся в состоянии равновесия (рис. 3). Их движение ограничено по окруженным в предыдущем пункте.

1) Каждая частица смешается из равновесного положения небольшим сдигром $u_1$, $u_2$ и $u_3$. Составьте уравнения движения для каждой частицы после сдигра. Массами пружин пребрежь.

2) Показите, что система может совершать гармоничное колбаня по закону

$$u=a_n \cos \omega t \ (n=1, 2 \text{ и } 3)$$

с ускорениями $-\omega^2 u$, где $a_n$ — постоянные амплитуды, и что циклическая частота $\omega$ может иметь два возможных значения

$$\omega_0 \sqrt{3} \text{ и } 0, \text{ где } \omega_0^2=k/m.$$

3) Система из пружин и частицы увеличивается до числа $N$, каждая частица содержена пружинами с двумя соседними. Сначала пружины не растут и находятся в равновесном состоянии. Составьте уравнение движения для $n$-й частицы ($n=1, 2, 3, ..., N$), выраженное через смешение самой частицы, а также содержих части после выведения их из положения равновесия. Показите, что

$$u_n(t)=a_n \sin(2ns\pi/N+\varphi) \cos \omega_s t,$$

(где $s=1, 2, ..., N$, $n=1, 2, ..., N$, $\varphi$ — произвольная фаза) является решением уравнения движения при условии, что циклическая частота задается выражением

$$\omega_s=2\omega_0 \sin(s\pi/N),$$

где $a_n(s=1, ..., N)$ — постоянные амплитуды, не зависит от $n$. Указите диапазон возможных частот для цепи, содержащей бесконечное число частц.

4) Определите отношение $u_n/u_{n+1}$ для большого значения $N$ в двух случаях: a) низкочастичные решения; b) $\omega=\omega_{max}$, где $\omega_{max}$ — решение для максимальной частоты. Поясните графически расположение части в цепи в момент времени $t$ для a) и b).

5) Одну из частицы заменили на частицу с массой $m' \ll m$. Сделайте оценку ожиданных существенных изменений в распределении циклических частот. Определите качественное форму частотного спектра для цепи с черезюшимся массами $m$ и $m'$ на основе предыдущего результата.
