⟦folio 12⟧

Догадливый читатель наверняка подумал — не окружность ли?

Не будем опережать события. Пока у нас есть лишь эллипс — линия уровня энергии $E = \text{const}$, то есть линия

$$\omega^2 u^2 + v^2 = 2E$$

(1)

(на двойку мы умножили, чтобы не возиться с ненужными дробями), показанная на рисунке 6. В силу закона сохранения энергии фазовая точка $N(t) = (x(t); \dot{x}(t))$, имеющая в момент времени $t$ энергию $E$, будет всегда оставаться на эллипсе (1), то есть будет дивигаться по эллипсу.

Построим на его горизонтальной оси как на диаметре окружность и проведем через фазовую точку $N(t)$ прямую, параллельную оси $Ov$, до пересечения с окружностью в точке $M(t)$. Тогда координата по оси $x$ точки $N(t)$ будет совпадать с координатой по оси $x$ точки $M(t)$, то есть будет равна $x(t)$.

Преобразуем выражение (**) для $x(t)$, получясь формулими дополнительного аргумента:

$$x(t) = a \cos \omega t + b \sin \omega t = \sqrt{a^2 + b^2} \cos(\omega t + \varphi),$$

где $\varphi$ определяется из условия

$$\cos \varphi = \frac{a}{\sqrt{a^2 + b^2}}, \sin \varphi = \frac{-b}{\sqrt{a^2 + b^2}}.$$

Обозначив $A = \sqrt{a^2 + b^2}$, можно заметить, что $A = \sqrt{a^2 + b^2} = \sqrt{a^2 + \beta^2/\omega^2} = \frac{1}{\omega} \sqrt{\beta^2 + \omega^2 a^2} = \frac{1}{\omega} \sqrt{\dot{x}^2(0) + \omega^2 x^2(0)} = \sqrt{2E/\omega}$.

Поэтому $x(t)$ можно записать в виде

$$x(t) = \frac{2E}{\omega} \cos(\omega t + \varphi).$$

Величина $A = \sqrt{2E/\omega}$, характеризующая раз-

max гармоничских колебаний, называется амплитудой, $\omega$ — циклической частотой, $T = 2\pi/\omega$ — периодом, $\varphi$ — фазой.

Тепер легко установить, что точка $M(t)$ будет врашаться равномерно с угловой скоростью $\omega$ по окружности с центром $O$ радиуса $A$. Действительно, если через $\varphi$ обозначит угол $uOM$ в момент времени $t=0$, то угол $uOM(t)$ равен $\omega t + \varphi$ в силу того, что проекция на ось $Ou$ точки $M(t)$ задана формулой (4). Мы установили, что гармоничские колебания представляют собой проекцию на прямую равномерно врашения по окружности, радиус которого равен амплитуде колебании, а угловая скорость врашения равна циклической частоте.

Эквивалентный взгладкость в том, что гармоничское колебание есть одна из координат равномерно врашающегося вектора (в данном случае $-\vec{OM}$). Длина этого вектора совпадает с амплитудой, а начальное положение определяется фазой. Такое представление колебания называется его векторной диаграммой и часто бывают полезны. Попробуйте с его помощью решить следующие задачи.

Задание 1. Докажите, что сумма двух ненулевых гармоничских колебаний есть гармоничское колебание тогда и только тогда, когда они имеют одинаковую частоту (или, как говоря, координатой по оси $x$ точки $M(t)$, то есть будет равна $x(t)$).

Задание 2. Докажите, что сумма трех гармоничских колебаний одинаковой амплитуды и частоты, фазы которых суть $\varphi$, $\varphi + (2\pi/3)$ и $\varphi + (4\pi/3)$, равна нулю.
