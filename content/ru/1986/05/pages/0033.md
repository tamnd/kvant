M962. Докажите, что ни для какого многочлена P(x) с целыми коэффициентами не могут найти такие различные целые числа x1, x2, ..., xn (n ≥ 3), для которых выполнялись бы равенства P(x1) = x2, P(x2) = x3, ..., P(xn-1) = xn, P(xn) = x1.

◆

Покажем, что если целые числа x1, ..., xn удовлетворяют равенствам из условий задачи, то среди них найдет одинаковые.

Мы используем такую лемму: если P(x) — многочлен с целыми коэффициентами, b и c — различные целые числа, то P(b) — P(c) делится на b−c. При этом будет выполняться неравенство |b−c| ≤ |P(b)−P(c)|; только это следствие и попадбится для решения задачи.

Поскольку P(x1) = x2, P(x2) = x3, по лемме |x1−x2| ≤ |x2−x3| ≤ |x3−x4| ≤ ... ≤ |xnx1| ≤ |x1−x2|, а значит, |x1−x2| = |x2−x3| = ... = |xn−x1|.

Если n ≥ 3, отсюда следует, что среди чисел x1, x2, ..., xn найдет равные: можно считать, что x1 — наименьшее из этих чисел; тогда

x2−x1 = |x1−x2| = |xn−x1| = xn−x1,

то есть xn = x2.

Докажем следующее. Из равенства, приведенного на полях, ясно, что число b^k−c^k при любом натуральном k делится на b−c. Пусть P(x) = a0 + a1x + a2x^2 + ... + anx^n; тогда число P(b)−P(c) = a1(b−c) + a2(b^2−c^2) + ... + a(n(b^n)) также делится на b−c.

◆

Докажем сначала одно вспомогательное утверждение.

Пусть отрезки AB и CD параллельны, а отрезки AC и BD пересекаются в точке P (рис. 1). Тогда множество точки X, лежащих внутри APB и CPD, таких, что треугольники XAC и XBD равновелики, есть прямая, соединяющая отрезков AB и CD.
