⟦folio 48⟧

Переходы из режимы в режимы поляются с помощью класси F, ПРГ, АВТ и СП так, как показано на рисунке 2.

Программируем линейный алгоритм. Наш исполнитель понимает весь своеобразный язык — язык нажатий класси, для нас более удобна и привчена запись на алгоритмческом языке (см. «Квант» 1985, № 9, 10). Чтобы успешно программировать классилятор, нам надо научиться переводить программу с алгоритмческого языка на язык класситора — как говорят профессиональные программы: транслировать ее в код класситора (от англ. translate — переводить). Вообще-то говоря, современная ЭВМ понимает весь своеобразный код, но у нее есть свой «встроенный» транслятор, переводящий программу с языка программирования на ее код. Для класситора это придется делать вручную.

Запишем нашу программу на алгоритмческом языке.

алг КОСИНУС
(вещ a, b, c, k)
apr a, b, c
рез k
нач веш k
k := b² + c² - a² / 2bc

кон

Сформируем теперь правила перевода (трансляции).

1. По службному слову веш (других типов переменных у класситора нет) распределим регистры памяти под переменные, записывая в таблицу, какой регистр соответствует данной переменной.

2. Для запроса значения класситора должен оставаться и подождать, пока человек наберет нужное значение, затем запустится его в соответствующей регистр, затем подождать следующего значения и т. д. Таким образом,apr программается последовательностью команд засылки в памяти, разделенных командами C/П.

3. Присваивание программыруется оченьным образом.

4. Если заслуженным словомрезледует лишь один параметр, рез транслировать нет необходимости. Если же таких параметров несколько, то в конце программы, перед словом кон, нужно программировать вывод этих параметров последовательностью команд вызова на регистр X вы-

водимых значений, за каждой из которых стоит команда C/П, пристававливающего вычисления.

5. Кон программируется командой C/П.

Отметим, что в программе может оказаться несколько команд C/П. При переходе в автоматный режим по команде C/П в счетчике адреса находится адрес следующего команды (это можно проверить, нажав F, ПРГ, то есть перейдет в программиный режим, когда значение счетчика адреса видно на индикаторе, затем надо будет вернуть в автоматный режим, нажав F, ABT); если теперь нажать C/П, то начинает выполнять та команда, адрес которого находится в счетчике адреса, то есть следующего за C/П — вычислениянойой дальше.
