При расчете ЭДС индукции в цепи каждой катушки нужно учитывать полный магнитный поток через нее, то есть сумму потоков, создаваемых токами обиха катушки.

После замыкания ключа в обихах цепях возникают одинаковые ЭДС $E_1 = E_2 = U_0$, и мощность, выделяющаяся на резисторе, равна

$$P = \frac{E_2^2}{R} = \frac{U_0^2}{R}.$$

Так, текущий через 2-ю катушка, равен $I_2 = U_0/R$. Магнитный поток, произвольный 1-ю катушка, равен

$$\Phi_1 = LI_1 + LI_2,$$

где $I_1$ — ток через 1-ю катушка и через батарейку. (Поток через каждую катушка, создавемый током $I_2$, один и тот же — катушки намотаны вместе.) Следовательно,

$$E_1 = U_0 = \left| \frac{d\Phi_1}{dt} \right| = \left| L \frac{dI_1}{dt} + L \frac{dI_2}{dt} \right| = \left| L \frac{dI_1}{dt} \right|$$

(так как $I_2 = \text{const}$). Отсюда

$$I_1 = \frac{U_0}{R} + \frac{U_0}{L} t.$$

График $I_1(t)$ приведен на рисунке 2. Скачок тока в первый момент связаан с тем, что полный поток через катушки не должен меняться скачком, и сразу после включения возникнет добавочный поток, направленный против потока, создаваемого 1-й катушки.

К моменту размыкания ключа полный поток через 2-ю катушки равен

$$\Phi_{2\tau} = -LI_2 + LI_{1\tau} = L \frac{U_0}{L} \tau = U_0 \tau.$$

Сразу после размыкания ключа в этой катушка возникнет ток

$$I_p = \frac{U_0 \tau}{L},$$

поскольку поток через катушка не должен меняться скачком. Тепло, которое выделится на резисторе с момента размыкания, —

$$W = \frac{1}{2} LI_p^2 = \frac{U_0^2 \tau^2}{2L}.$$
