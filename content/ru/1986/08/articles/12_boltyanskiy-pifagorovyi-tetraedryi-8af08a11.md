Пифагоры тетраэдры

Член корреспондент АПН СССР
В. Г. БОЛТЯНСКИЙ

Напомним, что треугольник называется пифагоровым, если у него один угол прямой, а отношение любых других сторон рационально (тогда, применяя подобие, можно из него получить прямой угольный треугольник с целыми длинами сторон). По аналогии с этим будем называть треугольр пифагоровым, если его плоские углы при одной из вершин прямые, а отношение любых двух ребер рационально (из него с помощью подобия можно получить треугольр с прямыми плоскими углами при одной из вершин и целыми длинами ребер).

В этой заметке мы выведем «увавение пифагоровых tetraэдров», то есть такоеувавение с трея неизвестными ξ, η, ζ, что любой пифагоров tetraэдр дает рациональное решение этогоувавения, и наоборот, любое рациональное решениеувавения дает пифагор tetraэдр. А затем, пользоваться этимувавением, найдем конкретные примеры пифагоровых tetraэдров.

Пифагоры треугольники

Сначала даим способ описания всех пифагоровых треугольников. На рисунке 1 треугольник OAB — прямой угольный; длины его катетов обозначены через a и b, а длина гипotenузы — через p (букву e резервируем для дальнейшего). Число ξ = a/b+p

условимся называть параметром прямой угольного треугольника OAB (или, точнее, параметром «относительное катета a»). Используя соответствие p²=a²+b², имеем

$$1+\xi^2 = \frac{(b^2+2bp+p^2)+a^2}{(b+p)^2} = \frac{2p^2+2bp}{(b+p)^2} = \frac{2p}{b+p}.$$

Из этих равенств непосредственно получаем формулы, выражающие отношения сторон прямой угольного треугольника через его параметр:

$$\frac{2\xi}{1-\xi^2} = \frac{a}{b}, \frac{1+\xi^2}{1-\xi^2} = \frac{p}{b}.$$

Задача 2. Докажите, что параметр ξ′ треугольника OAB относительно катета b (то есть ξ′ = b/a+p) связана с параметром ξ соответствием ξ′ = \frac{1-\xi}{1+\xi}. Дайте интерпретацию этого соответствия с помощью тригонометрических функций (см. задачу 1).

Из формул (1) (2) непосредственно вытекает следующие утверждения:

для того чтобы прямой угольный треугольник был пифагорным, необходимо и достаточно, чтобы число рациональных. В самом деле, если треугольник пифагов, то из (1) следует, что ξ рационально. Обратно, если ξ рационально, то согласно (2) отношения сторон рациональных, то есть треугольник пифагов.

Уравнение пифагорных tetraэдров

Пусть теперь OABC — tetraэдр, у которого плоские углы при вершине O прямые. Длины ребер, исходящих из вершины O, обозначаем через a, b, c, а длины трех других ребер — через p, q, r (рис. 2). Расмотрим параметры трех прямой угольных треугольников OAB, OBC, OCA:

$$\xi = \frac{a}{b+p}, \eta = \frac{b}{c+q}, \zeta = \frac{c}{a+r}.$$

Тогда по формулам (2) можно выразить отношения сторон этих прямой угольных треугольников через их параметры:

$$\frac{a}{b} = \frac{2\xi}{1-\xi^2}, \frac{b}{c} = \frac{2\eta}{1-\eta^2}, \frac{c}{a} = \frac{2\varsigma}{1-\varsigma^2};$$

$$\frac{p}{b} = \frac{1+\xi^2}{1-\xi^2}, \frac{q}{c} = \frac{1+\eta^2}{1-\eta^2}, \frac{r}{a} = \frac{1+\varsigma^2}{1-\varsigma^2}.$$

Из (4) непредседательно вытекает, что параметры $\xi, \eta, \varsigma$ удовлетворяют соответствию

$$\frac{2\xi}{1-\xi^2}, \frac{2\eta}{1-\eta^2}, \frac{2\varsigma}{1-\varsigma^2} = 1.$$

Это и есть общанное «уравнение пифагоровых тетраэдров».

Задача 3. Докажите, что если три положительных числа $\xi, \eta, \varsigma$ каждый из которых меньше единицы, удовлетворяют уравнению (6), то существует тетраэдр с прямыми плоскими углами при одной из вершин, для которого (при обозначениях рисунка 2) справедливый равенства (3) (а потом и равенства (4), (5)).

Задача 4. Докажите, что если $\xi, \eta, \varsigma$ — решение неопределенного уравнения (6), то числа

$$\xi' = \frac{1-\xi}{1+\xi}, \eta' = \frac{1-\eta}{1+\eta}, \varsigma' = \frac{1-\varsigma}{1+\varsigma}$$

также составляют решение этого уравнения («сопряжение решения»). Докажите, что если каждое из чисел $\xi, \eta, \varsigma$ положительное и меньше 1, то и каждое из чисел $\xi', \eta', \varsigma'$ обладает этим свойством. Каково геометрическое взаимодействие двух сопряженных решений уравнения (6)?

Задача 5. Докажите, что если $\xi, \eta, \varsigma$ — решение неопределенного уравнения (6), причем каждое из чисел $\xi, \eta, \varsigma$ положительное и меньше 1, то тетраэдр $OABC$, о котором говорится в задаче 3, может быть получен следующим образом: из точки $O$ проведется три взаимно перпендикулярных отрезка $OA, OB, OC$, имеющих длины

$$OA = 1, OB = \frac{1-\xi^2}{2\xi}, OC = \frac{1-\eta^2}{2\eta}$$

Задача 6. Числа $\xi, \eta, \varsigma$ составляют решение неопределенного уравнения (6). Возможно ли, чтобы два из этих чисел были разположены, а третье и разположены? Дайте геометрическую интерпретацию ответа.

Задача 7. Числа $\xi, \eta, \varsigma$ составляют решение неопределенного уравнения (6), причем каждое из них положительное и меньше 1. Докажите, что если $\xi = m/n, \eta = p/q$ (где $m, n, p, q$ — натуральные), то тетраэдр с прямыми плоскими углами при одной из вершин и длинами выходящих из этой вершины ребер

$$a = 4mnpq, b = 2pq = (n^2-m^2), c = (n^2-m^2)(q^2-p^2)$$

является пифагородым.

Из формул (3)—(5) непредседательно вытекает следующие утверждения: для того чтобы тетраэдр $OABC$ с прямыми плоскими углами при вершине $O$ был пифагородным, необходимо и достаточно, чтобы параметры $\xi, \eta, \varsigma$ (удовлетворяющие уравнению (6)) были разположены. В самом деле, если тетраэдр

$$\frac{a}{b} = \frac{2\xi}{1-\xi^2}, \frac{b}{c} = \frac{2\eta}{1-\eta^2}, \frac{c}{a} = \frac{2\varsigma}{1-\varsigma^2};$$

пифагород (то есть отношение любых двух его ребер рационально), то из (3) следует, что $\xi, \eta, \varsigma$ рациональны. Обратно, если $\xi, \eta, \varsigma$ рациональны, то согласно (4), (5) относение любых двух ребер рационально, то есть тетраэдр пифагород.

Задача 9. Изовем прямогольный параллелипед «пифаговым параллелипедом второго рода», если все его ребра, а также диагональ параллелипеда имеют разнородные длины. Докажите, что если $x_1, x_2, x_3$ — длины ребер прямогольного параллелипеда, а $y$ — длина его diagonали, то он в том и только в том случае является пифаговым параллелипедом второго рода, если она числа (*параметры*))

$$\xi_1 = \frac{x_1}{x_3 + y}, \quad \xi_2 = \frac{x_2}{x_3 + y}$$

рациональные. Докажите, что для этого параллелипеда справедливый соответствие

$$\frac{x_1}{y} = \frac{2\xi_1}{1 + \xi_1^2 + \xi_2^2}, \quad \frac{x_2}{y} = \frac{2\xi_2}{1 + \xi_1^2 + \xi_2^2},$$

$$\frac{x_3}{y} = \frac{1 - \xi_1^2 - \xi_2^2}{1 + \xi_1^2 + \xi_2^2}.$$

Задача 10. Обобщая результат задачи 9, доказите, что любое разнородное решение неопределенного уравнения

$$x_1^2 + x_2^2 + \dots + x_n^2 = y^2$$

имеет вид

$$x_1 = k \cdot 2\xi_1, \quad x_2 = k \cdot 2\xi_2, \dots, \quad x_{n-1} = k \cdot 2\xi_{n-1},$$

$$x_n = k(1 - \xi_1^2 - \dots - \xi_{n-1}^2), \quad y = k(1 + \xi_1^2 + \dots + \xi_{n-1}^2),$$

где $\xi_1, \dots, \xi_{n-1}$ — произвольные разнородные числа (*параметры*) и коэффициент $k$ также разнороден. Можно ли вы дать геометрическую интерпретацию этого результат?

В заключении остановимся на вопросе о том, как были найдены указывающие выше 11 разнородных решений уравнения (6). Для этого была использована электронная вычислительная машина. Алгоритм для вычисления на ЭВМ был составлен на основе следующих сообщений. Пусть

$$\xi = \frac{a}{b}, \quad \eta = \frac{c}{d}, \quad \xi = \frac{e}{f},$$

(7)

где $a, b, c, d, e, f$ — натуральные числа. Идея алгоритма — перебрать все такие шестерики, придавая каждому из шести чисел значения 1, 2, ..., 25, по формулам (7) найти соответствующее тройки ($\xi, \eta, \zeta$) и из них отобрать те, которые удовлетворяют уравнению (6). В действительности целесообразнее, освобождение от значенияелей, вести вычисления не с $\xi, \eta, \zeta$, а с натуральными числами $a, b, c, d, e, f$. Дело в том, что при работе с разнородными числами $\xi, \eta, \zeta$ компьютер заменил бы их некоторыми десятичными приближениями, которые точно не удовлетворяют бы уравнению (6).
