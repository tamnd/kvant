Рис. 7. Четырехмерный куб в четырехмерной системе координат.
0 ≤ x ≤ 1, 0 ≤ y ≤ 1, 0 ≤ z ≤ 1, 0 ≤ t ≤ 1. Четырехмерный куб в системе координат x, y, z, t четырехмерного пространства изображен на рисунке 7, где у каждой вершины указаны ее координаты (в целях экономии места без скобок и запятых).

Придирчного читателя не удовлетворит, однако, такое определение. Он просит: что такое система координат в четырехмерном пространстве? И вообще, что такое четырехмерное пространство?

Что бы ответить на последний вопрос, мы сначала вспомним — ну, конечно, вы угадали! — что такое трехмерное пространство. Это набор всехможных трехек чисел (x; y; z), где x, y и z — действительные числа (координаты точки), для которых определено расстояние по формуле
$$|MN| = \sqrt{(x_M - x_N)^2 + (y_M - y_N)^2 + (z_M - z_N)^2}$$
(см. учебник А. В. Погорелова «Геометрия 6—10», с. 204). Оказывается, предыдущую фразу можно взять за определение трехмерного пространства: из этого определения можно вывести все основные положения stereometрии с помощью элементаной алгебры. Так, определяв плоскость как множество точек, удовлетворяющих точке, удовлетворяющих линейному уравнению вида
$$Ax + By + Cz + D = 0,$$
(1)
неслоюно доказать, например, что через любую тройку неоколинеарных точек M, N, P проходит одна и только одна плоскость, а именно, плоскость с уравнением
$$((y_P - y_M)(z_N - z_M) - (z_P - z_M)(y_N - y_M)) \times (x_M - x) + ((z_P - z_M)(x_N - x_M) - (x_P - x_M)(z_N - z_M))(y_M - y) + (x_P - x_M)(y_N - y_M) - (y_P - y_M)(x_N - x_M))(z_M - z) = 0$$
(2)
(cм. «Геометрия 6—10», с. 212).

Тепер следующего определения должно произвольно естественно. Четырехмерным пространством называется множество всех четырехок чисел (x; y; z; t), где x, y, z, t — действительные числа, для которых определено расстояние по формуле
$$|MN|^2 = (x_N - x_M)^2 + (y_N - y_M)^2 + (z_N - z_M)^2$$
(3)

С определением плоскости в четырехмерном пространстве дело обстоит не так просто. Дело в том, что здесь бывают как общные двумерные плоскости, так и трехмерные «плоскости», называемые zигерплоскости.
