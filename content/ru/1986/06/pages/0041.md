После соединения пластин 1 и 4 проводником, разность потенциаль между ними $U_{14}$ будет равна нулю. При этом распределение заряда на пластинах и электрических полей между ними будет таким, как показано на рисунке 2.

$$U_{14} = E_1d - E_3d + E_2d = \frac{d}{\varepsilon_0S} (q'_1 - q_3 + q'_2) = 0.$$

Из закона сохранения заряда на пластинах 2 и 3 следует:

$$q'_1 + q_3 = q_1, \quad q'_2 + q_3 = q_2,$$

откуда

$$q_3 = \frac{q_1 + q_2}{3}.$$

Следовательно, разность потенциаль между пластинами 2 и 3 равна

$$U_{23} = \frac{q_3}{\varepsilon_0S} d = \frac{q_1 + q_2}{3\varepsilon_0S} d.$$

Г. В. Федотович

Для того чтобы определить силу $N$, действующее на перегрузок $m$ со стороны груза $M$, воспользуемся вторым законом Ньютона для движения перегрузка:

$$ma = mg - N.$$

После того как грузы отпустили, они совершают гармоничные колбания (как один груз массы $M + m$). Значит, ускорение $a$ периодически изменяет свое направление. Сила

$$N = m(g - a)$$

будет максимальная в момент, когда ускорение имеет максимальную абсолотную величины и направлено вверх, то есть в момент наиболее растяжения рукки. Для определения ускорения использует второй закон Ньютона для движения груза с перегрузком:

$$(M + m)a = (M + m)g - kx.$$
