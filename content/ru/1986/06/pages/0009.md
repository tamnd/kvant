По той же причине множество всех решений одного линейного уравнения в четырехмерном пространстве $Ax+By+Cz+Dt+E=0$ само по себе трехмерно. Аналогично трехмерному случай, вектор с координатами $(A; B; C; D)$ перепределкирен данной гиперплоскости и называется ее нормальным вектором.

Как его обобщить
Читатель, разобравшийся в предыдущем определении, без труда дастелерь определение $n$-мерного куба для любого $n \geq 1$. Для этого он сначала определит $n$-мерное пространство как множество наборов из $n$ чисел $(x_1; x_2; ...; x_n)$, расстояние между которых задается формулой

$$|AB| = \sqrt{(a_1-b_1)^2 + (a_2-b_2)^2 + ... + (a_n-b_n)^2},$$

а затем и $n$-мерный куб как множество тех точек $n$-мерного пространства, для которых выполены неравенства $0 \leq x_1 \leq 1, 0 \leq x_2 \leq 1, ..., 0 \leq x_n \leq 1$.

Как его рассечить
Четыремерные функции удобно представлять себе при помощи их сечений некоторых семейством параллельных друг други гиперплоскостей (гиперплоскости параллельных между собой, если их нормальные векторы коллинеарны). Смысл этой конструкции можно понять, рассматривая сечения трехмерных тел обычными плоскостями (рис. 8, где показано сечение куба плоскости $y=h$). Аналогично выглядят и сечения четырехмерного куба плоскости $t=h$ — вспомните рисунок 2!

Для лучшего понимания геометрии четырехмерного куба рассмотрим следующие трудную задачу: изобразить семейство его сечений гиперплоскости, перепределкулярными главной диагонали. Если взять диагональ, соединяющего вершины $(0; 0; 0; 0)$ и $(1; 1; 1; 1)$, то уравнение этих гиперплоскостей будет иметь вид $x+y+z+t=h$, где $h$ — некоторая константа.

Разберемся аналогично трехмерную задачу. Трехмерный куб можно представить как пересечение двух octantов, заданных системами неравенств

$$\begin{cases} x \geq 0, \\ y \geq 0, \\ z \geq 0 \end{cases}$$

и $$\begin{cases} x \leq 1, \\ y \leq 1, \\ z \leq 1 \end{cases}$$

(рис. 9). Всякая плоскость вида $x+y+z=h$ пересекает каждый из этих двух octantов по правильному треугольнику. Проследим за изменением этой конфигурации при изменении $h$ от 0 до $\sqrt{3}$. В начальной момент $(h=0)$ один из треугольников состоит всего из одной точки. Затем его линейные размеры увеличиваются пропорционально $h$, одновременно с этим второй треугольник постепенно уменьшается, оставясь готовотипным вершому с отрицательным коэффициентом. Начиная с того момента, когда вершины меньше треугольника «протыкают» стороны большшего, их пересечение дает шестиугольник. Этот шестиугольник становится правильным, когда размер треугольников сравнивается. Далее описанный процесс повторяется в обратном порядке.

Подобным образом, четырехмерный куб представляет собой пересечение двух частей четырехмерного пространства, выделяемых системами неравенств $x \geq 0, y \geq 0, z \geq 0, t \geq 0$ и $x \leq 1, y \leq 1, z \leq 1, t \leq 1$. Нетрудно показать, что гиперплоскость $x+y+z+t=h$ пересекает каждую из этих частей по правильному тетрадру. Однако из этих тетрадров увеличивается с ростом $h$, а другой уменьшается. Искимо множество представляет собой пересечение двух таких тетрадров и может быть точкой, тетрадром или усеченным тетрадром (в частности, при совпадении размеров обихх tetraдров мы получим в пересечении правильный octаэдр; он изображен на рисунке 3 на четвертой странице обложки «Кванта» № 6 за 1985 год).

Мы надеемся, что читатели настолько освоились с понятием четырехмерного куба, что сумме нарисовать эти сечения самостояльно.
