Вступительные экзамены по математике в Московском институт стали и сплавов, типичны для большинства технических узов.

На факультетах МЧМИС (металургии черных металлов и сплавов) и МЦРМИС (металургии цветных металлов и сплавов) профиляруются дисциплинами являются математика письменная, физика и химия; на факультетах ФХ (физико-химический) и ПМП (полупроводниковых материалов и приборов) — математика письменная и устная и физика. Конкурс на все факультеты проводится разделно.

Отметим, что около 19% (179 человек) нового состава студентов было набран в промышленных центрах: Бекабаде, Волгограде, Запорожье, Норильское, Орске, Череповце.

Содержание билетов для письменных и устных экзаменов строго соответствовал программатом по математике для поступающих вузы.

2. Для решения неравенства
$$\frac{3x^2 - 2x - 1}{\lg(x - 1)} < 0$$

заметим, что дробь будет отрицательной, если числитель и знаменатель ее имеют разные значки. Таким образом, это неравенство равно сльно двум системам неравенств:

$$\begin{cases} 3x^2 - 2x - 1 > 0, \\ \lg(x - 1) < 0 \end{cases}$$

или
$$\begin{cases} 3x^2 - 2x - 1 < 0, \\ \lg(x - 1) > 0. \end{cases}$$

Решая эти системы, находим соответствующее

$$\begin{cases} x < -\frac{1}{3}, x > 1, \\ 0 < x - 1 < 1, \\ x - 1 > 1, \end{cases}$$

то есть
$$\begin{cases} x < -\frac{1}{3}, x > 1, \\ 1 < x < 2, \\ x > 2. \end{cases}$$

Вторая система решения не имеет, а решения первой служит инвервал $1 < x < 2$.

Ответ: $1 < x < 2$.

3. Рассмотрим два случая: 3x + 4 > 1 и 0 < 3x + 4 < 1.

В первом случае получим
$$\begin{cases} 3x + 4 > 1, \\ x^2 < 3x + 4, \\ x^2 > 0 \end{cases}$$ или $$\begin{cases} x > -1, \\ -1 < x < 4, \\ x \neq 0, \end{cases}$$

откуда нахождение
-1 < x < 0, 0 < x < 4.

Во втором случае имеем
$$\begin{cases} 0 < 3x + 4 < 1, \\ x^2 > 3x + 4, \\ x^2 > 0 \end{cases}$$

или
$$\begin{cases} -\frac{4}{3} < x < -1, \\ x < -1, x > 4, \\ x \neq 0, \end{cases}$$

откуда получим
- $\frac{4}{3} < x < -1$.

Ответ:
- $\frac{4}{3} < x < -1$;
- -1 < x < 0; 0 < x < 4.

При решении этой задачи многое неучтывали условия x ≠ 0 и потому вместе двух последних интегровалов получали -1 < x < 4.

Писменные экзамены показали следующие наиболее места у построаюших:

1) Все еще много ошибок допускается при упрощении алгебраических выражений: абитуренты плохо владействиями со степенями, ошибаются там, где надо пользоваться определенным аргументческою корня (см. задачу 4 из разобранного выше варианта 2).

2) У многох поступаюших нет свободного владения трионометрических формулам, в результате чего возникали ошибки при решении трионометрической задачи или же избирался далеко не самый короткий путь решения такой задачи.

3) При решении неравенств допускались ошибки, связанные с незначением как свойств неравенств, так и свойств функций. Очень часто, например, абитуренты не учитывали ОДЗ входящих в неравенство функций (см. задачу 2 из варианта 1, задачу 3 из варианта 2).

4) При решении stereometрических задачи часто камнем преткновения служило незначение основных понятий stereometрики. Например, часто поступавшие неправильно находили линейный угол дугранного угла между смежными боковыми граями параметры. Многие ошибочно считали, что линейным углом будет в этом случае угол при вершине лежшего в основании параметры многоугольника.
