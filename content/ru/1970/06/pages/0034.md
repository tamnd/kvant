3. Рассмотрим два случая: 3x + 4 > 1 и 0 < 3x + 4 < 1.

В первом случае получим
$$\begin{cases} 3x + 4 > 1, \\ x^2 < 3x + 4, \\ x^2 > 0 \end{cases}$$ или $$\begin{cases} x > -1, \\ -1 < x < 4, \\ x \neq 0, \end{cases}$$

откуда нахождение
-1 < x < 0, 0 < x < 4.

Во втором случае имеем
$$\begin{cases} 0 < 3x + 4 < 1, \\ x^2 > 3x + 4, \\ x^2 > 0 \end{cases}$$

или
$$\begin{cases} -\frac{4}{3} < x < -1, \\ x < -1, x > 4, \\ x \neq 0, \end{cases}$$

откуда получим
- $\frac{4}{3} < x < -1$.

Ответ:
- $\frac{4}{3} < x < -1$;
- -1 < x < 0; 0 < x < 4.

При решении этой задачи многое неучтывали условия x ≠ 0 и потому вместе двух последних интегровалов получали -1 < x < 4.
