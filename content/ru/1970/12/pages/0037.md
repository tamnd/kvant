DK⊥BC (рис. 1). Тогда AH = x, KD = BH = 8 - x, AB + BC = 2AD = 4x, BC = 4x - 8, BK = DH = x√3, KC = |BC - BK| = |4x - 8 - x√3| и для выполнения всех условий задачи*) необходимо и достаточно выполнение равенства CK² + KD² = AD² или (4x - 8 - x√3)² + (8 - x)² = 4x²,

где 8 - x > 0 и 4x - 8 > 0, то есть 2 < x < 8. После преобразования получаем (2 - √3)x² - 2(5 - √3)x + 16 = 0.

Обозначим трехчлен, стоящий влевой части, через f(x). Нетрудно проверить, что условия 0 < x < 8 удовлетворят только меньший корень x₀ уравнения f(x) = 0 (рис. 2). Его можно записать в виде

x₀ = (5 - √3 - √6√3 - 4) / (2 - √3) = 7 + 3√3 - √44 + 26√3.

Крестьянину придется пройти путь 4x₀. Выяснить, больше это число 10 или меньше, проще прямо из уравнения. Поскольку f(5/2) = 1/4(14 - 5√3) > 0, ясно, что x₀ > 5/2, то есть 4x₀ > 10. Покажем, что расстояние AC направик меньше 10. Действительно, неравенство √8² + (4x₀ - 8)² < 10 при 2 < x₀ < 8 эквивалентно таким: (4x₀ - 8)² < 36, 4x₀ - 8 < 6, x₀ < 7/2. Так же как и выше, убеждаемся, что f(7/2) = 1/4(22 - 21√3) < 0, откуда x₀ < 7/2, и, следовательно, AC < 10.

Решение этой задачи прислада нам M. Преезер из Томска, A. Михайлов из Экибастуза и другие читатели.
