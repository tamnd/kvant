2. Верны. В силу коммутиативности «сложения» и «умножения» эти соответствия равносильны приведеным в текст формулам (2) и (3).
3. $(a \otimes c) \otimes [(a \oplus b) \otimes c]$. Использовать формул (2) и первую из формул (5).
4. Заданную величины переписать в виде $a \otimes [(a \otimes b) \oplus (a \oplus c)]$. Так как $(a \otimes b) \oplus (a \oplus c) = [a \oplus (a \otimes b)] \oplus c = a \otimes c$ (см. вторую из формул (5)), то, используя еще первый из формул (6), получить окончательное выражение min $(a, -a, -c)$.
5. Равенство привести к виду $a \oplus b = a \otimes c$, то есть max $(a, b) = \min (a, -c)$. Это соответствие может иметь место лишь для таких действительных чисел $a, b, c$, которые удовлетворяют условию $b \leq a \leq -c$.
6. Данное соответствие привести к виду $a \oplus x = b$, или max $(a, x) = b$. Если $a < b$, то $x = b$; если $a = b$, то можно взять любое $x \leq b$;

если $a > b$, то ни одно действительное число требуемый свойством не обладает.

2. Достаточно доказать, что $l_ah_a + l_bh_b + l_ch_c \leq p^2$, где $h_a, h_b, h_c$ — длины высот треугольника. Как известно,лина биссеррисы

$$l_a = \frac{2}{b + c} \sqrt{bcp(p - a)}$$

Используя неравенство $b + c \geq 2\sqrt{bc}$, получим $l_a \leq \sqrt{p(p - a)}$. Аналогично $l_b \leq \sqrt{p(p - b)}$, $l_c \leq \sqrt{p(p - c)}$. Посление три неравенства и легко доказываемые соответствия $h_a \leq l_a, h_b \leq l_b, h_c \leq l_c$ дают $l_ah_a + l_bh_b + l_ch_c \leq l_a^2 + l_b^2 + l_c^2 \leq p(p - a) + p(p - b) + p(p - c) = p^2$.

3. Преобразуем исходное уравнение к виду

$$x^3\cos^2x - 2x(x + 1)\cos x \sin x + 2(x + 1)\sin^2x = 0.$$

Умножаялевую часть на $x$ и выделяя полный квадрат, приdem к эквивалентному уравнению $[x^2\cos x - (x + 1)\sin x]^2 + (x - 1)(x + 1)\sin^2x = 0$. Если действительное число $\alpha$ является корнем этого уравнения и при этом $(\alpha - 1)\times(\alpha + 1) > 0$, то должны выполнять равенства $\sin^2\alpha = 0, \alpha^2\cos\alpha - (\alpha + 1)\sin\alpha = 0$, что возможно лишь при $\alpha = 0$, но тогда $(\alpha - 1)(\alpha + 1) < 0$.
