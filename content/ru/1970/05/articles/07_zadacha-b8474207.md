⟦folio 38⟧

ЗАДАЧА

Агент по переписи Смит и агент по опросу населения Джонс одновременно подходит к дому № 900. Каждый хозяй узначает возраст животного дома. Владелец дома (дело проискот в США) сообщает им свой возраст и говорит, что в доме живут еще три жильца, возрасты которых — три различных цельх числа — при переменении дайот число, равное номеру дома. Владелец дома говорит, что он сообщит агенту по переписи возрастного из жильцов. Он шепотом сообщает этот возраст агенту по переписи, который после этого говорит, что он не в состоянии определить возраст двух других жильцов. Тогда Владелец дома говорит, что он сообщит агенту по опросу сумму возрастов старшего из жильцов и одного из двух других. Он шепотом сообщает сумму агенту по опросу, который говорит, что он тоже не в состоянии определить возраст животного.

Владелец дома начинает спрашивать их по очереди. В первый раз агент по переписи ответает, что он может определить эти возрасты. Агент по опросу говорит, что он может определить возрасты. Агент по опросу говорит, что он все еще не знает возрасты жильцов, а агент по опросу заявляет: «Теперя я знаю все возрасты». Каков возраст этих трех жильцов? (В условии задачи содержится все необходимая информация для решения!)
