Пример 2. Решить уравнение
$$\log_9 x + \log_9 \frac{2 - x}{2} = \log_9 \log_9 p.$$

Решение. ОДЗ определяется неравенствами $0 < x < 2$, $p > 1$ (на рисунке 2 эта область окрашена в малиновый цвет). Решая уравнение, последовательно получим
$$\frac{x(2 - x)}{2} = \log_9 p,$$
$$x^2 - 2x + 2\log_9 p = 0,$$
$$x_{1,2} = 1 \pm \sqrt{1 - 2\log_9 p}.$$

Условие $1 - 2\log_9 p \geq 0$ выполняется при $p \leq 3$, что с учетом ОДЗ дает $1 < p \leq 3$. При таких $p$ корни будут действительными числами. При $p > 1$ выполняется неравенство $\log_9 p > 0$, а потом $1 - 2\log_9 p < 1$. Отсюда следует, что при $1 < p \leq 3$ имеет место неравенства $0 < x_{1,2} < 2$.

Ответ: если $1 < p \leq 3$, то $x_{1,2} = 1 \pm \sqrt{1 - 2\log_9 p}$; при остальных $p$ решений нет.

Пример 3. Решить уравнение
$$\frac{a + \sin x}{a \cos x + 1} = \frac{a + \cos x}{a \sin x + 1}.$$

Решение. Рассмотрим сначала случай $a = 0$. Заданное уравнение принимает вид $\sin x = \cos x$, откуда $x = \frac{\pi}{4} + \pi n$ ($n = 0, \pm 1, \ldots$).

Пусть теперь $a \neq 0$. Тогда ОДЗ определяется уравнями
$$\cos x \neq -\frac{1}{a}; \sin x \neq -\frac{1}{a}.$$

Преобразуем заданное уравнение к виду $(\sin x - \cos x)[a^2 + a(\sin x + \cos x) + 1] = 0$. Последнее уравнение свойства к следующей совокупности уравнения:
$$a^2 + a(\sin x + \cos x) + 1 = 0,$$
$$\sin x - \cos x = 0.$$

Решая первое уравнение совокупности (7), получаем:
$$a\sqrt{2}\sin(x + \frac{\pi}{4}) = -a^2 - 1$$
и далее
$$\sin\left(x + \frac{\pi}{4}\right) = -\frac{a^2 + 1}{a\sqrt{2}}.$$

Последнее уравнение не имеет решения, так как $\left| -\frac{a^2 + 1}{a\sqrt{2}} \right| > 1$ при любом $a \neq 0$. В самом деле, предположим, что $\frac{a^2 + 1}{|a|\sqrt{2}} \leq 1$; преобразуя это неравенство, получаем
$$a^2 + 1 \leq |a|\sqrt{2}, (a^2 + 1)^2 \leq 2a^2,$$
$$a^4 + 1 \leq 0.$$

Последнее неравенство неверно.
