2. Рассмотрим вопрос о вычислении суммы вида

$$\sum_{k=1}^{n} f(k) = f(1) + f(2) + \dots + f(n),$$

где $f$ — известная функция целочисленного аргумента, определяная на отрезке $[1, n]$ натурального ряда.

Эту сумму легко вычислить, если удасссянная тайку функцию $F$, определяную на отрезке $[1, n+1]$ натурального ряда, что при всех $k, 1 \leq k \leq n$, справедливо равенство

$$f(k) = F(k+1) - F(k).$$

В самом деле, полагая в этом равенстве последовательно $k = 1, 2, \dots, n-1, n$, получим:

$$f(1) = F(2) - F(1),$$
$$f(2) = F(3) - F(2),$$
$$f(3) = F(4) - F(3),$$

$$f(n-1) = F(n) - F(n-1),$$
$$f(n) = F(n+1) - F(n).$$

Складывая эти равенства, приходим к следующей формуле:

$$\sum_{k=1}^{n} f(k) = F(n+1) - F(1).$$

Таким образом, если функция $F$ найдена, сумма (1) вычисляется элементарно.

Проиллюстрируем формулу (3) геометрической прогрессии.

На рисунке 1 нам нужно найти сумму (1), обозначенную просто через $\Sigma$, как длину вертикального отрезка. Каждый член вида $f(k)$ соответствует длине красного отрезка, равной разности длины зеленьх отрезков $F(k+1)$ и $F(k)$. Очевидно, сумма длины всех красных отрезков равна разности длини первого и последнего из зеленьх отрезков.

Пример 1. Вычислим сумму

$$\frac{1}{1.2} + \frac{1}{2.3} + \frac{1}{3.4} + \dots + \frac{1}{n(n+1)},$$

то есть

$$\sum_{k=1}^{n} \frac{1}{k(k+1)}.$$

Здесь

$$f(k) = \frac{1}{k(k+1)},$$

и, как нетрудно проверить, ее можно представить в виде следующей разности:

$$f(k) = \frac{1}{k} - \frac{1}{k+1}.$$

Поэтому, если обозначить

$$F(k) = -\frac{1}{k},$$

то формула (2) будет выполнена для всех натуральных $k$:

$$f(k) = F(k+1) - F(k).$$

Приимена формулу (3), легко получим

$$\sum_{k=1}^{n} \frac{1}{k(k+1)} = 1 - \frac{1}{n+1} = \frac{n}{n+1}.$$

Пример 2. Найдем сумму членов следующей геометрической прогрессии:

$$q, q^2, q^3, \dots, q^n \quad (q \neq 1).$$

Здесь $f(k) = q^k$, и, воспользоваться равенством $q^{k+1} - q^k = q^k(q-1)$, можно написать

$$q^k = \frac{q^{k+1}}{q-1} - \frac{q^k}{q-1}.$$

Отсюда видно, что можно положить

$$F(k) = \frac{q^k}{q-1},$$

и, следовательно,

$$\sum_{k=1}^{n} q^k = \frac{q^{n+1}}{q-1} - \frac{q}{q-1} = \frac{q^{n+1}-q}{q-1}.$$

Получили известную формулу.
