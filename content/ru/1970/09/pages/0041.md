Пример 3. Вычислим сумму
$$\sum_{k=1}^{n} \sin kx (x \neq 2\pi n).$$
Нетрудно проверить, что
$$\sin kx = \frac{\cos(k-0,5)x - \cos(k+0,5)x}{2\sin 0,5x},$$
то есть
$$\sin kx = F(k+1) - F(k),$$
где
$$F(k) = -\frac{\cos(k-0,5)x}{2\sin 0,5x}.$$
Тепер на основании формулы (3) после несложных преобразований получим
$$\sum_{k=1}^{n} \sin kx = \frac{\sin 0,5(n+1)x \sin 0,5nx}{2\sin 0,5x}.$$
Читатель сам убедился, что формула (3) дает эффективный способ вычисления суммы (1). Главное — нахождение функции $F$. Нередко, к сожалению, это — задача не из легких, а иногда даже незарешимая.
3. Пусть теперь заданы две конечные последовательности чисел
$$u_1, u_2, \dots, u_n,$$
и
$$v_1, v_2, \dots, v_n$$
и требуется вычислить сумму
$$\sum_{k=1}^{n} u_k v_k.$$
Здесь часто бывают полезным одно преобразование, которое было указано замещенным норвежским математиком Абелем. Именно пусть $V_k$ — сумма первых $k$ членов последовательности (4), то есть
$$V_k = \sum_{i=1}^{k} v_i = v_1 + v_2 + \dots + v_k.$$
Ясно, что $v_1 = V_1$; если же $k > 1$, то
$$v_h = V_h - V_{h-1}.$$

Позтому
$$\sum_{k=1}^{n} u_k v_k = u_1 v_1 + u_2 v_2 + \dots + u_n v_n = u_1 V_1 + u_2 (V_2 - V_1) + \dots + u_n (V_n - V_{n-1})$$
Раскрывая скобки и группируя слагаемые по два, получим
$$\sum_{k=1}^{n} u_k v_k = (u_1 - u_2) V_1 + (u_2 - u_3) V_2 + \dots + (u_{n-1} - u_n) V_{n-1} + u_n V_n$$
или окончательно:
$$\sum_{k=1}^{n} u_k v_k = u_n V_n - \sum_{k=1}^{n-1} (u_{k+1} - u_k) V_k.$$ (5)
Геометрическая интерпретация этого способа дана на рисунке 2. Каждый член вида $u_k v_k$ соответствует площади прямоугольника (зеленого). Члены вида $(u_{k+1} - u_k) V_n$ соответствуют площадям красных прямоугольников. Выражение $u_n V_n$ есть площадь всего прямоугольника. После этого формула (5) становится очень видно.

Пример 4. Вычислим сумму
$$1^2 + 2^2 + \dots + n^2.$$
Обозначим искому сумму через $S$ и запишем ее, используя знак $\Sigma$:
$$S = \sum_{k=1}^{n} k^2.$$
