Пример. Возьмем опять разложение числа $\frac{61}{27}$ в целную дробь и образуем подходящие дроби

$$\frac{p_0}{q_0} = 2,$$

$$\frac{p_1}{q_1} = [2; 3] = 2 + \frac{1}{3} = \frac{7}{3},$$

$$\frac{p_2}{q_2} = [2; 3, 1] = 2 + \frac{1}{3 + \frac{1}{1}} = \frac{9}{4},$$

$$\frac{p_3}{q_3} = [2; 3, 1, 6] = \frac{61}{27}.$$

Разумеется, последняя подходящая дробь разнонального числа $\alpha$ равна $\alpha$.

Мы получили несколько постепенно условияющихся приближений для числа $\frac{61}{27}$. Для оценки их заменим, что $\frac{61}{27} \approx 2,259$.

1-ое приближение 2, $\Delta = 0,259$ *).

2-ое $\frac{7}{3} = 2,333, \Delta = -0,074$.

3-е $\frac{9}{4} = 2,250, \Delta = 0,09$.

Мы заменаем, что погрешность убывает (по абсцидной величины) и имеет чередующесся знаки. Это — общее правило.

В случае разложения в целную дробь числа $\sqrt{2} = 1,4142$... получим

$$\frac{p_0}{q_0} = 1, \text{ погрешность } \Delta = 0,4142,$$

$$\frac{p_1}{q_1} = [1; 2] = \frac{3}{2} = 1,5, \Delta = -0,0858,$$

$$\frac{p_2}{q_2} = [1; 2, 2] = \frac{7}{5} = 1,4,$$

$$\Delta = 0,0142,$$

$$\frac{p_3}{q_3} = [1; 2, 2, 2] = \frac{17}{12} = 1,4167,$$

$$\Delta = -0,0025,$$

$$\frac{p_4}{q_4} = [1; 2, 2, 2, 2] = \frac{41}{29} = 1,4138,$$

$$\Delta = 0,0004.$$

Мы наблюдаем и здесь ту же самую картину.

*) $\Delta$-погрешность (см. стр. 17).

6. Основное свойство подходящих их дробей. Сформулируем теперь без доказательства то основное свойство подходящих дробей, которое и приведет к разгадкам наших загадок.

Если $\frac{p_n}{q_n}$ — подходящая дробь для числа $\alpha$, то абсцидная погрешность

$$|\alpha - \frac{p_n}{q_n}|$$

менные, чем при аппроксимации числа $\alpha$ любой дробью с меньшим значением *).

Например, получив для $\sqrt{2}$ подходящую дробь $\frac{p_3}{q_3}$, мы можем быть уверены, что приближение к $\sqrt{2}$ любой дроби со значением, меньшим 12, будет хуже.
