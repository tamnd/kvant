⟦folio 41⟧

ГЕОМЕТРИЧЕСКИЙ СМЫСЛ НЕКОТОРЫХ НЕРАВЕНСТВ С ДВУМЯ ПЕРЕМЕННЫМИ

А. Я. МАРГУЛИС, Б. А. РАДУНСКИЙ

При изучении курса математики школьник часто приходит решать неравенства и системы неравенств с одним неизвестным. При этом геометрическая иллюстрация решения (в совокупности с методом интегралов) помогает им кратчайшим путем нахождения правильные решения.

Рассмотрим, например, неравенство
$$\log_2 (x^2 - 4x + 3) \leq 3.$$
Его решение совпада с решению системы двух неравенств с одним неизвестным
$$\begin{cases} x^2 - 4x + 3 > 0 \\ x^2 - 4x + 3 \leq 8 \end{cases}$$
(необходимо для существования логарифма),
(получается при потенцировании заданного неравенства).

Множество значений $x$, удовлетворяющих первому неравенству, есть совокупность двух интегралов
$$x < 1 \text{ и } x > 3,$$
а второму — отрезок
$$1 \leq x \leq 5$$
(это вытекает из свойств квадратного треxcчлена).

Отметив на числовой оси эти промежутки (рис. 1), мы видим, что множество значений $x$, удовлетворяющих системе неравенств, заполняет два получкрытых интеграла, $-1 \leq x < 1$ и $3 < x \leq 5$ (на рисунке они даны пунктом).

Для большей наглядности на самом рисунке отмечено, какие из концов интегралов принадлежат к области решения, а какие — нет.

Геометрическая иллюстрация оказылась здесь весма полезной. Ее роль еще больше возрастает при решении неравенств и систем неравенств с двумя неизвестными.
