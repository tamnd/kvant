6) Положив $y = \frac{2x - 1}{2x - x^2 - 4}$, получаем квадратное (относительно $x$) уравнение $yx^2 + 2(1-y)x + 4y - 1 = 0$, дискриминант которого должен быть неотрицательным: $(1-y)^2 + y(4y - 1) \geq 0$, так как $x$ — действительное число, откуда
$$-\frac{1 + \sqrt{13}}{6} \leq y \leq \frac{-1 + \sqrt{13}}{6}.$$
Следовательно, наименьшее значение $y$ равно $-\frac{1 + \sqrt{13}}{6}$; соответствующое значение $x$, как легко подсчитать, есть $\frac{1 + \sqrt{13}}{2}$.

6) Решить неравенство
$$\left| \sqrt{2} | x | - 1 \right| \cdot \log_2 \left( 2 - 2x^2 \right) \geq 1.$$

Решения задач
1. Область допустимых значений (ОД3):
$$-\frac{\pi}{4} + 2k\pi \leq x \leq \frac{\pi}{2} + 2k\pi,$$
$k = 0, \pm 1, \dots$

Положим
$$y = \sqrt{\cos x} - 4 \sqrt[4]{2} \sqrt[4]{\cos \left( x - \frac{\pi}{4} \right)} + 5 \sqrt[4]{2},$$
тогда
$$y^2 - 2 \sqrt{\cos x} y - \sin x = 0,$$
откуда
$$y = \sqrt{\cos x} \pm \sqrt{\sqrt{2} \cos \left( x - \frac{\pi}{4} \right)},$$
т. е. имеем
$$\sqrt{\cos x} - 4 \sqrt[4]{2} \sqrt[4]{\cos \left( x - \frac{\pi}{4} \right)} + 5 \sqrt[4]{2} = \sqrt{\cos x} \pm \sqrt[4]{2} \sqrt{\cos \left( x - \frac{\pi}{4} \right)}.$$

Положив $z = \sqrt[4]{\cos \left( x - \frac{\pi}{4} \right)}$, получим $-4z + 5 = \pm z^2$. После уравнения имеет корни $z_1 = 1, z_2 = -5, z_3 = 2 \pm i$. Корни $z_2, z_3, z_4$, очень/no, построение.
Из $z_1 = 1$ следует $\cos \left( x - \frac{\pi}{4} \right) = 1$. Таим образом, $x = \frac{\pi}{4} + 2k\pi, k = 0, \pm 1$.

2. Пусть $x_i$ — расстояние, проиденное $i$-группой, $i = 1, 2, 3, 4$. Из условия задачи имеем $x_1 + x_4 - 6 = x_2 + x_3, x_1 - x_2 = 2, x_1^2 + x_2^2 + x_3^2 + x_4^2 = 494$, откуда
$$(x_1 - 1)^2 + (x_4 - 2)^2 = 242,$$
$$x_1 = 1 + \sqrt{242 - (x_4 - 2)^2}.$$

По условиях $x_1$ и $x_4$ — натуральные числа ($x_1$ — число туристов в 3-й группе, а $x_4$ — число туриста легкого подбором, исходя из последнего соответствия (и заменяя, что в силу этого же соответствия $x_4 < 18$). Перебирая последовательно
$x_4 = 1, 2, 3, \dots, 17,$ находим единственное решение:
$x_4 = 13, x_1 = 12.$
В этом случае $x_2 = 10, x_3 = 9.$
