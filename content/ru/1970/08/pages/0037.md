Приведенный выше способ доказательства удобен тем, что он позволяет доказать все эти (и многое подобные им) неравенства сразу, т. е. доказать теорему, из которой все эти неравенства следует как частные случаи. К формулировке этой общей теоремы мы и перейдем.

Назовем функцию $f$, заданную на отрезке $[a, b]$ числовой оси, выпуклой вверх (рис. 1), если для любых $x_1, x_2$ из этого отрезка

$$\frac{f(x_1) + f(x_2)}{2} \leqslant f\left(\frac{x_1 + x_2}{2}\right).$$

Геометрические это означает, что если соединить любые две точки графика хордой, то середина этой хорды будет лежать и же графика.

Точно так же определяется свойство функций быть выпуклой вниз (рис. 2), с той разницей, что неравенство (3) заменяется на противоположное:

$$\frac{f(x_1) + f(x_2)}{2} \geqslant f\left(\frac{x_1 + x_2}{2}\right).$$

Например, известная вам функция $f(x) = x^2$ выпукла вниз на всей оси; неравенство (4) для нее выглядит так:

$$\frac{x_1^2 + x_2^2}{2} \geqslant \left(\frac{x_1 + x_2}{2}\right)^2.$$

Проверьте, что оно выполняет при любых $x_1, x_2$.

Теорема. Если функция $f(x)$, заданная на отрезке $[a, b]$, выпукла вверх, то

$$\frac{f(x_1) + \dots + f(x_n)}{n} \leqslant f\left(\frac{x_1 + \dots + x_n}{n}\right).$$

для любых точек $x_1, \dots, x_n$, лежащих на отрезке $[a, b]$.

Доказательство будет проводить по индукции. Заметим, что утверждение теоремы для $n=2$ просто повторяет наше определение выпуклой функции. Значит, остается доказать неравенство (5) для $n=k+1$, предположив, что для $n=k$ оно уже доказано. Тогда

$$f(x_1) + \dots + f(x_k) + f(x_{k+1}) + (k-1)f\left(\frac{x_1 + \dots + x_{k+1}}{k+1}\right) = [f(x_1) + \dots + f(x_k)] + \left[ f(x_{k+1}) + (k-1)f\left(\frac{x_1 + \dots + x_{k+1}}{k+1}\right) \right] \leqslant kf\left(\frac{x_1 + \dots + x_k}{k}\right) + kf\left(\frac{x_{k+1}}{k} + \frac{(x_1 + \dots + x_{k+1})(k-1)}{(k+1)k}\right) \leqslant 2kf\left(\frac{1}{2}\left(\frac{x_1 + \dots + x_{k+1}}{k}\right) + \frac{(x_1 + \dots + x_{k+1})(k-1)}{(k+1)k}\right) = 2kf\left(\frac{x_1 + \dots + x_{k+1}}{k+1}\right),$$

откуда получаем требуемое неравенство для $n=k+1$. Здесь мы применили два раза неравенство (5) для $n=k$ и один раз неравенство (5) для $n=2$, т. е. использованы определение выпуклости.

Вы, конечно, заметили, что это доказательство очень похож на приведенное выше доказательство теоремы о среднем арифметическом и среднем геометриском.

Чтобы доказать неравенства a) — д) с помощью этой теоремы, надо для каждой из них придумать такую функцию, чтобы неравенство (5) в применении к этой функции совпадало с доказываемым неравенством или получалось из него простым преобразованием.
