Таким образом мы можем говорить о «сумме» трех действительных чисел $a \oplus b \oplus c$, определяя как $a \oplus (b \oplus c)$ или, что то же самое, как $(a \oplus b) \oplus c$. Более внимательное изучение этой таблицы 1 приводит нас к заключению, что $a \oplus b \oplus c = \max(a, b, c)$.

Ассоциативность «умножения», т. е. справедливо для любых действительных $a, b, c$ равенства

$$(a \otimes b) \otimes c = a \otimes (b \otimes c)$$

или, что то же самое, равенства min $(\min(a, b), c) = \min(a, \min(b, c))$ читатель проверит самостояльно тем же способом, каким мы убедились в ассоциативности «сложения».

Установим теперь дистрибутивность «умножения» относительно «сложения»:

$$(a \oplus b) \otimes c = (a \otimes c) \oplus (b \otimes c),$$

(2) что можно записать в форме

$$\min(\max(a, b), c) = \max(\min(a, c), \min(b, c))$$.

Для этого достаточно составить таблицу 2, из которого видно, что равенство (2) в самом деле справедливо для трех любых действительных чисел $a, b, c$.

Как известно, для обычных арифметических операций дистрибутивность сложения относительно умножения места не имеет: не для всех действительных чисел справедливо равенство $(ab) + c = (a + c) \times (b + c)$. Но для введенных нами операций «сложения» и «умножения» и такая дистрибутивность справедлива:

$$(a \otimes b) \oplus c = (a \oplus c) \otimes (b \oplus c).$$

Читатель сам убедится в этом проверив, что max $(\min(a, b), c) = \min(\max(a, c), \max(b, c))$ для любых действительных чисел $a, b, c$.

Интересно, что «сложение» и «умножение» обладает и другими свойствами, которые не наблюдаются в обычной арифметике действительных чисел:

$$a \oplus a = a, a \otimes a = a;$$

$$a \otimes (a \oplus b) = a, a \oplus (a \otimes b) = a.$$

Эти соотношения непосредственно вытекают из определений операций $\oplus$ и $\otimes$.
