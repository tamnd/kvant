⟦folio 57⟧

Все знают что каждому действительному числу $a$ можно поставить в соответствии противоположное число, то есть число $-a$. Мы условиями число, противоположное $a$, обозначать символом $a$. Например: $\overline{2,5} = -2,5; \overline{-V^2} = \sqrt{2}; \overline{0} = 0$.

Любопытно, что операции «сложения» и «умножения» оказываются связными с операцией взяття противоположного числа:

$$\overline{a \oplus b} = \overline{a} \otimes \overline{b}; \overline{a \otimes b} = \overline{a} \oplus \overline{b}$$

(6) (в общной арифметике также формулы неверны!).

Докажите эти формулы сами.

В заключение попробyte самостоятельно решить такие задачи:

1. Убедитесь, что для $n \geq 2$ произвольных действительных чисел $a_1, \ldots, a_n$
   $a_1 \oplus \ldots \oplus a_n = \max(a_1, \ldots, a_n), a_1 \otimes \ldots \otimes a_n = \min(a_1, \ldots, a_n)$.

2. Верны ли соответствия
   $c \otimes (a \oplus b) = (c \otimes a) \oplus (c \otimes b), c \oplus (a \otimes b) = (c \oplus a) \otimes (c \oplus b)?$

3. Докажите, что для любых действительных чисел $a, b, c$ справедливо равенство
   $\min [\min(a, c), \min(\max(a, b), c)] = \min(a, c)$ и запишите его с помощью операций $\oplus$ и $\otimes$. Как после этого можно сразу убедиться в его справедливости?

4. Пусть $a, b, c$ — произвольные действительные числа. Найите простое выражение для величины
   $\min[a, -\max(\min(a, b), \max(a, c))]$.

5. Для любых ли действительных чисел $a, b, c$ верно равенство
   $(a \oplus b) \otimes (a \oplus b \oplus c) = a \otimes [c \otimes (c \oplus b)]?$

6. Можно ли найти такое действительное число $x$, чтобы
   $\max [\min(a, \max(a, b), x)] = b$?

Ниже приведено несколько задач, взятых из построенного конкурсного отдела журнала «Matematika».

1. В некоторых царстве, в некоторых государстве есть несколько городов, причем расстояния между ними все попарно различны. В однойкрасное утро из каждого города вылетает по одному самолету, который применяется в ближайшем соседнем городе.

Может ли в одном городе произвольные более пяты самолеты?

2. Докажать; что если $a, b, c$ — длины сторон треугольника, а $l_a, l_b, l_c$ — длина проведенных к ним биссектрис внутренних углов, то
   $$\frac{l_a}{a} + \frac{l_b}{b} + \frac{l_c}{c} \leq \frac{p^2}{2S}$$

где $p$ — полуперimetр, а $S$ — площадь треугольника; знак равенства достигается только для равностороннего треугольника.

A. Мameев

3. Докажать, что если действительное число $a$ является корнем уравнения
   $2(x^2 + x)\sin 2x + (2x + 2 - x^3)\cos 2x = x^3 + 2x + 2$,
то это число удовлетворяет неравенству $|a| < 1$.

B. Петков

4. Пусть в плоскости выпуклого многоугольника существует точка, обладающая тем свойством, что любая прямая, проведенная через эту точку, делит многоугольник на две равновеликие части. Докажать, что тогда этот многоугольник является центрально симметриным.

P. Грозданов

5. Муха, не останавливаясь, полезет в одном направлении с постоянной скоростью по окружности верхнего основания цилиндрической консервной банки, высота которой в 4 раза больше диаметра $2r$ основания. В некоторых момент из наиболее дальней от мужи точки поверхности банки муку начинает преследовать путь, причем он полезет по поверхности банки с постоянной скоростью, равной скорости муки (и также не останавливается). Найти длину накратачайшего пути, по которой путь может настигнуть муку.

И. Димовски
