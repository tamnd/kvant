⟦folio 24⟧

Максимум, минимум и теорема о средних

А. П. Савин

В математике принято называть теоремими такие утверждения, которые могут быть многократно использованы при вывода других утверждения, в частности при решении задач. Мне хотелся расссказать о применении следующей следующего теоремы:

Среднее арифметическое нескольких положительных чисел не меньше, чем их среднее геометрическое, и равенство этих средних выполняется лишь моеда, когда все заданные числа равны:

$$\frac{a_1 + a_2 + \dots + a_n}{n} \geq \sqrt[n]{a_1 a_2 \dots a_n}$$

или

$$\left(\frac{a_1 + a_2 + \dots + a_n}{n}\right)^n \geq a_1 a_2 \dots a_n.$$

Есть много разных доказательств этого утверждения, одно из них вы можете прочитать в статье С. Т. Берколайко и С. Б. Каток*). Где же эта теорема применяется?

Конечно, зная ее, вы можете использовать в качестве среднего среднее арифметическое, если вам хочет, чтобы среднее было подобше, и среднее геометрическое, если хотите, чтобы оно было поменше. Например, вычисляя среднюю успеваемость в классе. Это, конечно, шутка. А если серверно?

Оказывается, с помощью этой теоремы можно находить наиболее или наиболее значения многохалгебраических выражений. Начем с простейших.

*) С. Т. Берколайко, С. Б. Каток, Об одном индуктивном методе доказательства неравенств, «Квант», № 8, стр. 33.

При мер 1. Какое наиболее значение может иметь многочлен $2x - x^2$?

Решение. Преобразуем многочлен так: $2x - x^2 = x (2 - x)$ и обозначим $2 - x$ через $y$.

По теореме

$$2x - x^2 = xy \leq \left(\frac{x + y}{2}\right)^2 = \left(\frac{x + 2 - x}{2}\right)^2 = 1.$$

Отсюда следует, что наиболее значение многочлена равно 1, и оно достигается, если $x = 2 - x$, то есть при $x = 1$ (нетрудно проверить, что $x$ и $2 - x$ не могут быть оба отрицательными; поскольку мы ищем наиболее значение, достаточно рассматривать их лишь тогда, когда они оба положительные).

При мер 2. Какое наиболее значение может иметь выражение $x + \frac{1}{x}$ для положительных значений $x$?

Решение. Обозначим $\frac{1}{x}$ через $y$. По теореме

$$x + \frac{1}{x} = 2 \left(\frac{x + y}{2}\right) \geq 2 \sqrt{xy} = 2 \sqrt{\frac{x}{x}} = 2.$$

Итак, наиболее значение равно 2, оно достигается при $x = \frac{1}{x} = 1^*$.

*) В школе проходят метод выделения полного квадрата, который решают оба эти примера:

1) $2x - x^2 = 1 - (1 - x)^2 \leq 1$;
2) $x + \frac{1}{x} = \left(\sqrt{x} - \frac{1}{\sqrt{x}}\right)^2 + 2 \geq 2$.

Но уже пример 3 выделением полного квадрата не решается.
