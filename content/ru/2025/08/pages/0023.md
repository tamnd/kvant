Умножая уравнение для $dr$ на 2 и складывая с уравнением для $dy$, получим
$$2dr + dy = 0, \ 2r + y = \text{const.}$$

Вычислим эту константу в момент начала движения ($r_A = l, y_A = 0$), откуда $r(y) = l - y/2$. В момент достижения протиположного берега
$$y_B = l, \ r_B = \frac{l}{2}.$$

В момент времени $t_1$ из геометрических сообразений можно записать, что $r \cos \alpha = l - y$. Подставляя зависимость $r(y)$ и значение угла $\alpha$ в этот момент времени, получаем
$$\frac{1}{2}\left(l - \frac{y_1}{2}\right) = l - y_1, \ y_1 = \frac{2}{3}l, \ r_1 = \frac{2}{3}l.$$

Для определения радиуса кривизны траектории найдем скорость и ускорение в нужных точках. Скорость относительно берега равна сумме скорости воды $\vec{u}$ в реке и скорости лодки $\vec{u}_{\pi}$ относительно воды: $\vec{v} = \vec{u} + \vec{u}_{\pi}$. После возвления в квадрат получаем
$$v = \sqrt{\vec{u}^2 + \vec{u}_{\pi}^2} + 2(\vec{u} \cdot \vec{u}_{\pi}) =$$
$$= \sqrt{u^2 + 4u^2 + 4u^2} \cos \angle(\vec{u}, \vec{u}_{\pi}) =$$
$$= u \sqrt{5 + 4 \cos \angle(\vec{u}, \vec{u}_{\pi})}.$$

Для точки старта $\angle(\vec{u}, \vec{u}_{\pi}) = \pi$, тогда скорость равна $v_A = u$. Для момент времени $t_1$ этот угол равен $\pi - \alpha$, тогда скорость равна $v_1 = u\sqrt{3}$.

Скорость лодки равна векторной сумме скоростей течение воды и лодки относительно воды. Скорость течение не меняется ни по модулю, ни по направлению. Скорость лодки не меняется по модулю, но меняется по направлению. Производная вектора скорости лодки по модулю равна произведению угловой скорости врашения вектора $\vec{u}_{\pi}$ на модуль этого вектора. Получим выражение для ускорения лодки:
$$\vec{a}_{a6c} = \frac{d}{dt}(\vec{u} + \vec{u}_{\pi}) = \frac{d\vec{u}}{dt} + \frac{d\vec{u}_{\pi}}{dt} = \vec{a}_{\pi},$$
$$a_{\pi} = 2u \cdot \omega_{\alpha} = 2u \frac{d\alpha}{dt}.$$

Для нахождения произвольной угла $\alpha$ надо компоненту скорости, перепendlкулярную отрезку $BC$, поделить на расстояние $r$:
$$v_{\perp} = 2u - u \cos \alpha,$$
$$\frac{d\alpha}{dt} = \omega_{\alpha} = \frac{2u - u \cos \alpha}{r}.$$

В момент выхода из пункта $A$ угол $\alpha = 0$, поэтому
$$\frac{d\alpha}{dt} = \frac{u}{l}, \ a_A = \frac{2u^2}{l}.$$

В момент времени $t_1$ угол $\alpha = \pi/3$, значит,
$$\frac{d\alpha}{dt} = \frac{3u/2}{2l/3} = \frac{9u}{4l}, \ a_1 = \frac{9u^2}{2l}.$$

В пункте отправления скорость и ускорение взаимно перепendlкулярны, поэтому радиус кривизны траектории можно следующим образом:
$$R_A = \frac{v_A^2}{a_A} = \frac{l}{2}.$$

Для момента времени $t_1$ найдем проекцию ускорения на перепendlкуляр к скорости движения, т.е. на ось $x$:
$$a_{1x} = a_1 \sin \alpha = \frac{9u^2 \sqrt{3}}{4l},$$

тогда радиус кривизны траектории в этой точке
$$R_1 = \frac{v_1^2}{a_{1x}} = \frac{4\sqrt{3}l}{9}.$$
