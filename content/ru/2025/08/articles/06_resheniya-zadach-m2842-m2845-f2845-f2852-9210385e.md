Решения задач M2842 – M2845, Ф2845–Ф2852

M2842. На доску записали несколько (большее одного) последовательных намуральных чисел. Могло ли мак случайся, что и сумма всех четырех намурального числа, и сумма всех четырех намурального числа?

Ответ: не могло.
Пусть выписано четное количество чисел, т.е. $2k$ чисел, начная с числа $n$. Тогда одна из двух указанных в условия сумма равна $S_1 = n + (n + 2) + \dots + (n + 2k - 2) = (2n + 2k - 2)k/2 = (n + k - 1)k$. Другая же сумма равна $S_2 = S_1 + k = (n + k)k$.
Если же выписано нечетное количество чисел, т.е. $2k + 1$ чисел, начная с числа $n$, то одна из сумм равна
$$S_1 = (n + 1) + (n + 3) + \dots + (n + 2k - 1) = (n + 1 + (n + 2k - 1))k/2 = (n + k)k.$$

Другая же сумма равна
$$S_2 = n + (n + 2) + \dots + (n + 2k) = S_1 + n + k = (n + k)(k + 1).$$
В обонх случае частное $\frac{S_2}{S_1}$ равно относению $\frac{m + 1}{m}$ двух последовательных натуральных чисел. Покажем, что это невозможно, если предположить, что $S_1$ и $S_2$ – точные квадраты. Пусть $S_1 = m_1^2$, $S_2 = m_2^2$ и $\frac{u}{v}$ – нескократимая запись дроби $\frac{m_2}{m_1}$.
Тогда $\frac{u^2}{v^2}$ – нескократимая запись дроби $\frac{m_2^2}{m_1^2} = \frac{S_2}{S_1} = \frac{m + 1}{m}$. Так как дробь $\frac{m + 1}{m}$ нескократимая, должно выполнять $v^2 = m$ и $u^2 = m + 1$, т.е. два последовательных натуральных числа являются точными квадратами, что неозможно.

a) Заметим, что соответствующие стороны треугольников $EAC'$ и $ADB'$ параллельны, значит, эти треугольники подобны, откуда $EC'/C'A = AB'/B'D$, или $x/a = a/y$. Полученная пропорция вместе с равенством $\angle EC'B' = \angle C'B'D = 120^\circ$ дает подобие $\Delta EC'B' \sim \Delta C'B'D$. Отсюда
$$\angle DC'B' = \angle C'EB' = 180^\circ - \angle EC'B' - \angle EB'C = 60^\circ - \angle EB'C.$$
Получаем, что $\angle XC'B' + \angle XB'C' = 60^\circ$, откуда $\angle B'XC' = 120^\circ$, следовательно, $\angle B'XC' + \angle B'A'C' = 120^\circ + 60^\circ = 180^\circ$, четыреугольник $A'B'XC'$ вписанный.
6) Покажем, что каждый из отрезков $CE$, $BD$, $A'X$ делит отрезок $B'C'$ в одном и том же отношении, равном $x/a$ (или $a/y$).
Пусть $U = CE \cap B'C'$, $V = BD \cap B'C'$, $W = A'X \cap B'C'$. Поскольку $EC' \parallel CB'$, имеем $\Delta UEC' \sim \Delta UCB'$, следовательно, $C'U/UB' = EC'/CB' = x/a$. Аналогично находим $C'V/VB'$.
Далее,
$$C'W/WB' = \frac{S_{A'C'X}}{S_{A'B'X}} = \frac{A'C' \cdot C'X \cdot \sin \angle A'C'X}{A'B' \cdot B'X \cdot \sin \angle A'B'X},$$
что равно $C'X/XB'$, поскольку $A'B' = A'C'$, а углы $A'C'X$ и $A'B'X$ дают в сумме $180^\circ$ (в силу вписанности $A'B'XC'$). Воспомним, что $\angle XC'B' = \angle C'EB'$, поэтому $\Delta B'XC' \sim \Delta B'C'E$, откуда $C'X/XB' = EC'/C'B' = x/a$. Итак, $C'W/WB' = x/a$, что завершает решение.
Сделаем еще несколько заменений по поводу этой конструкции. Оказывается, прявая, проведенная через точки пересечения

$AB \cap CE$ и $AC \cap BD$, будет касаться окружности $(A'B'C')$ в точке $X$. Получается, что утверждение задачи можно трактовать как свойства описанного четырехугольника (здеся $A'$, $B'$, $C'$, $X$ – точки касания его сторон со вписанной окружностью), или, более общо, как проектные свойства четырехугольника, описанного вокруг коники.

M2844. Хозяйка достаточно кусок мяса из холодильника, вокруг нее собрать комяма. Раз в минуту хозяйка отрезает кусок мяса и скарливаем его одному из комяма (на свой выбор), причем каждый кусок должен составлять одну и ту же долю куска, от которой его отрезают. Через некоторое время хозяйка убирает остаток мяса в холодильник. Может ли хозяйка скормить комяма поровну мяса, если все компоненты $a$ двое; $b$) мрое; $c^*$) цветер?

Ответы: может во всех пунктах.
Пусть вес исходного куска равен 1, а вес куска, оставшегося после первого отрезания, равен $a$. Тогда доля отрезаемого куска каждой раз равна 1 – $a$. Значит, вес второго отрезанного куска равен $a(1 - a)$, а вес оставшегося равен $a - a(1 - a) = a^2$ и так далее: после $k$-го отрезания вес оставшегося куска равен $a^k$, а вес отрезанного равен $(1 - a)a^k$. Сократив на $(1 - a)$, получим, что задачу можно переформулировать следующим образом.
Для некоторых числа $a \in (0;1)$ и некоторого натурального $n$ нужно разбить числа 1, $a$, $a^2$, ..., $a^{n-1}$ на $k$ групп с равными суммами (где $k$ в пунктах $a$), $6$), в равно соответствующем 2, 3 и 4).
a) Пусть $a \in (0;1)$ – корень квадратного уравнения $1 = x + x^2$ (можно указать явно: $a = \frac{\sqrt{5} - 1}{2}$). Тогда нужно нам разбиение:
$\{1\}$ и $\{a, a^2\}$.

Поскольку $1 = a + a^3$, то для любого натурального $k$ выполнен равенство $a^k = a^{k+1} + a^{k+3}$. Тогда
$$1 = a + a^3 = \left(a^2 + a^4\right) + a^3 = a^2 + \left(a^5 + a^7\right) + \left(a^4 + a^6\right) = a^2 + a^4 + a^5 + a^6 + a^7.$$
Таким образом, для $n = 8$ и указанного $a$ числа 1, $a$, ..., $a^7$ можно разбит на три группы с равными суммами:
$$\{1\}, \{a, a^3\}, \{a^2, a^4, a^5, a^6, a^7\}.$$
в) Пусть теперь $a \in (0;1)$ - корень кубичесного уравнения $1 = x^2 + x^3$ (такой корень найдется, аналогично доказательству в пункте 6).
Заметим, что
$$a^4 - a^2 - a + 1 = (a - 1)\left(a^3 - a^2 - 1\right) = 0,$$
значит, $1 + a^4 = a + a^2$. Следовательно, для любого натурального $k$ выполнен равенства
$$a^k = a^{k+2} + a^{k+3}$$
и $a^k + a^{k+4} = a^{k+1} + a^{k+2}$.
Тогда $1 = a^2 + a^3 = a + a^5$, что также равно
$$a^2 + a^3 = \left(a^4 + a^5\right) + a^3 = a^3 + a^5 + a^4 = a^3 + a^5 + \left(a^6 + a^7\right) = a^3 + \left(a^5 + a^6\right) + a^7 = a^3 + a^5 + \left(a^6 + a^7\right) + a^7 = a^3 + a^5 + \left(a^6 + a^7\right) + a^7 = a^3 + a^5 + \left(a^6 + a^7\right) + a^7 = a^3 + a^5 + \left(a^6 + a^7\right) + a^7 = a^3 + a^5 + a^7.$$
Таким образом, для $n = 13$ и указанного $a$ числа 1, $a$, ..., $a^{13}$ можно разбит на четыре группы с равными суммами:
$$\{1\}, \{a, a^5\}, \{a^2, a^3\}, \{a^4, a^6, a^7, a^8, a^9, a^{10}, a^{11}, a^{12}, a^{13}\}.$$
Пунktы a) и б) были предложены первым автором на Турир городов и Московскую математическую олимпiadу. Второй автор первым приведел primer для $k = 4$. Отметим, что в процессе работы команды составитель над вариантими олимпiadы были найдены и другие примеры. Скажем, в пункте 6) работают следующие.
Для $a - корня уравнения $1 = x + x^3$:
$$1 = a + a^4 + a^6 = a^2 + a^3 + a^5 + a^7,$$
$$1 = a^2 + a^3 + a^4 = a + a^5 + a^6 + a^7;$$
для $a - корня уравнения $1 = x^2 + x^3$:
$$1 + a^4 = a + a^2 = a^3 + a^5 + a^6 + a^7 + a^8 + a^9 + a^{10} + a^{11} + a^{12}.$$

M2845. В трехмерном координатном пространстве рассмотрим множество кубов с целочисленными координатами вершин. Докажите, что в этом множество существует такое бесконечное подложение $K$, что любые два разных куба из $K$ не имеют параллельных ребер.

Нам нужно научиться конструкировать трейки неулевых векторов $\vec{a}, \vec{b}, \vec{c}$ (направленные вдоль ребер куба), удовлетворяющих таким условиям:
(1) $\vec{a}, \vec{b}, \vec{c}$ имеют целые координаты;
(2) $\vec{a} \perp \vec{b}, \vec{b} \perp \vec{c}, \vec{c} \perp \vec{a}$ (т.e. векторы поарно ortогональных);
(3) $|\vec{a}| = |\vec{b}| = |\vec{c}|$ (т.e. длины векторов равны).
Кроме того, никакие два вектора из разных трейки не должны быть коллинеарными. Мы рассекем о нескольких подходах к решению, появившихся в процессе работы над этой задачей команды составитель Турира города.

Геометрические это означает, что векторы $\vec{a}, \vec{b}, \vec{c}$ переходят друг в друга по циклу при повороте (на угол $120^\circ$) вокруг оси $x = y = z$; тем самым мы уже обеспечиваем выполнение условия (3), а также равенство углов между векторами во всех трех парах. В самом деле, если $\vec{a}, \vec{b}, \vec{c}$ имеют рациональные координаты, то их можно домножить на подходящее натуральные число так, чтобы все их координаты стали целыми. Далее можно использовать условия (3), потребовав, чтобы длины векторов равнялись 1, т.е. чтобы $\vec{a}, \vec{b}, \vec{c}$ являются радиус-векторами точек, лежащих на единичной сфере $x^2 + y^2 + z^2 = 1$.

Умножая уравнение для $dr$ на 2 и складывая с уравнением для $dy$, получим
$$2dr + dy = 0, \ 2r + y = \text{const.}$$

Вычислим эту константу в момент начала движения ($r_A = l, y_A = 0$), откуда $r(y) = l - y/2$. В момент достижения протиположного берега
$$y_B = l, \ r_B = \frac{l}{2}.$$

В момент времени $t_1$ из геометрических сообразений можно записать, что $r \cos \alpha = l - y$. Подставляя зависимость $r(y)$ и значение угла $\alpha$ в этот момент времени, получаем
$$\frac{1}{2}\left(l - \frac{y_1}{2}\right) = l - y_1, \ y_1 = \frac{2}{3}l, \ r_1 = \frac{2}{3}l.$$

Для определения радиуса кривизны траектории найдем скорость и ускорение в нужных точках. Скорость относительно берега равна сумме скорости воды $\vec{u}$ в реке и скорости лодки $\vec{u}_{\pi}$ относительно воды: $\vec{v} = \vec{u} + \vec{u}_{\pi}$. После возвления в квадрат получаем
$$v = \sqrt{\vec{u}^2 + \vec{u}_{\pi}^2} + 2(\vec{u} \cdot \vec{u}_{\pi}) =$$
$$= \sqrt{u^2 + 4u^2 + 4u^2} \cos \angle(\vec{u}, \vec{u}_{\pi}) =$$
$$= u \sqrt{5 + 4 \cos \angle(\vec{u}, \vec{u}_{\pi})}.$$

Для точки старта $\angle(\vec{u}, \vec{u}_{\pi}) = \pi$, тогда скорость равна $v_A = u$. Для момент времени $t_1$ этот угол равен $\pi - \alpha$, тогда скорость равна $v_1 = u\sqrt{3}$.

Скорость лодки равна векторной сумме скоростей течение воды и лодки относительно воды. Скорость течение не меняется ни по модулю, ни по направлению. Скорость лодки не меняется по модулю, но меняется по направлению. В ближайших к данному узлу ветках силы токов будут одинаковы (в силу симметрии) и равны $I_+ = I_0/6$. Затем рассмотрим ту же бесконечную сетку, где из соседнего узла вытекает ток силой $I_0$. Аналогично, в данной схеме токи в ближайших к данному узлу ветках будут одинаковы и равны $I_- = I_0/6$. Далее рассмотрим суперпозицию этих двух случаев. Тогда направление на сопротивлении $r$ равно $(I_+ + I_-)r$, следовательно,
$$r_{\text{эквивалентной}} = \frac{(I_+ + I_-)r}{I_0} = \frac{r}{3}.$$
Таким образом, при использовании любых двух соседних (ближайших) узлов электрическая схема ведет себя как резistor с сопротивлением $r_{\text{эквивалентной}} = r/3$. Поэтому показанияометра не будут зависеть от полярности его подключения. С учетом этого получаем ответ для показанийометра:
$$R_1 = \frac{r}{3}, R_2 = \frac{r}{3}, R_3 = \frac{r}{3}.$$
Эти результаты не зависит от полярности подключенияометра.
Эkvивалентный источник из предыдущего пункта можно представить как параллельное соединение источника с ЭДС 2$\epsilon$ и сопротивлением $r$ (который заменяется другим источником по условияю) и источника с ЭДС $\epsilon^*$ и сопротивлением $r^*$, который эkvивалентен оставшейся часть электрической схемы (рис. 5). С учетом того, что для эkvивалентного источника $\epsilon_{\text{эквивалентной}} = 0$ и $r_{\text{эквивалентной}} = r/3$, найдем $\epsilon^*$ и $r^*$. Сопротивления связаны соотношениями
$$\frac{1}{r_{\text{эквивалентной}}} = \frac{1}{r} + \frac{1}{r^*},$$
откуда $r^* = r/2$. Приравнивая ток короткого замыкания рассмотренного параллельного соединения источников и эkvивалентного источника, приходим к соответствии
$$\frac{\epsilon^*}{r^*} - \frac{2\epsilon}{r} = \frac{\epsilon_{\text{эквивалентной}}}{r_{\text{эквивалентной}}},$$
откуда находится $\epsilon^* = \epsilon$.
