Пример. Концы отрезка и три точки, делящие его на 4 равные части.
Оценка. Покажем, что шесть чисел не могло. Введем координаты так, что наименьшая из координат отмещенных точек - это 0, а наибольшая - это 4. Пусть есть еще хотя бы 4 числа: 0 < a < b < c < d < 4. Чтобы точка a делила отрезок [0;4] в разрешенном отошении, нужно, чтобы a > 1. Чтобы точка b делила отрезок [a;4] в разрешенном отошении, нужно
b > a + (4 - a)/4 = 1 + 3a/4 > 7/4.

Чтобы точка c делила отрезок [b;4] в разрешенном отошении, нужно
c > b + (4 - b)/4 = 1 + 3b/4 > 1 + 21/16 = 2 + 5/16.
Аналогично, если рассудать с другой конца:
d < 4 - 1,
c < 4 - 7/4 = 9/4 = 2 + 4/16.
Получаем противоречие: 2 + 5/16 < c < 2 + 4/16.
