1. После удара шарик отскочит горизонтальное со скоростью $v$. Перемещение шарика по вертикали $\Delta y = 0,5H + b = \frac{gt^2}{2}$, откуда $t \approx 0,32$ с. 2. Реактивная сила струи $F = \frac{\Delta m}{\Delta t}v = \rho Sv^2$. Из правила моментов относительной шарирного подвеса $\rho \frac{L}{2}Sg \sin \alpha = \rho Sv^2$ находится $\sin \alpha = \frac{2v^2}{gL}$. 3. 1) При увеличении массы $M$ от нуля перьым начет двигаться верхиной брусок, тогда $M_{\min} = \frac{\mu m}{1 + \mu} = \frac{m}{6}$.

2) Нижний брусок начинает скольнить, когда сила трения между ним и столом достигает силы трения скольжения $F_{\text{tp2}} = \mu N_2$. Запишем уравнение движения для всех трех тел в проекциях на вертикальные и горизонтальные оси:

$$Mg - T = Ma, N + T - mg = 0,$$
$$T - \mu N = ma, N_2 - N - mg = 0,$$
$$T - \mu N - \mu N_2 = 0.$$

Отсюда найдем $M_{\min} = \frac{3\mu m}{1 - \mu^2} = \frac{5m}{8}$.

4. Так как приборы идеальны, то можем заменить волтметры на разрывы цепи, а амperметры на перемычки. Использование потенциальы в узлах (рис. 9). Видно, что ток по резистору $OC$ не печет из-за равенства потенциальов. Значит, не будет ток в амperметре $A_1$, т.е. $I_1 = 0$.

Из рисунка видно, что разность потенциаль на первом волтметре $U_1 = \varepsilon = 5$ В. При этом больший потенциаль находится у положительного контакта, а значит, показания волтметра будут положительными.

Так через второй амperметр определяется токами, протекающими через узел $B$. По ребру $BC$ ток не протекает, а значит, ток через амperметр $A_2$ будет равен току $I$, протекащему по резистору $BA$. Этот ток определяем из правила Кирхгофа для узлов $B$ и $F$: $I = 2\varepsilon \cdot 2r = 1$ мА, т.е. ток через амperметр $A_2$ будет равен $I_2 = 1$ мА. Но так как он втекает в отрицательный контакт амperметра, то знак ток будет «-». Итоговый ответ: $I_2 = -1$ мА.

Напряжение на волтметре $V_2$ определяется как разность потенциаль между узлами $O$ и $A$. Знача, что $Ir = \varepsilon$, может найти потенциаль в точке $A$. Он будет равен $\varepsilon$. Значит, разность потенциаль между узлами будет $U_2 = -\varepsilon = -5$ В.
