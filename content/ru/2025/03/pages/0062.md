Запишем второй закон Ньютона в проекциях на вертикальное ось:
$$ma_\tau = mg, a_\tau = g.$$
Для нахождения нормальной компоненты ускорения воспользовемся формулой центростремительного ускорения:
$$a_n = \frac{u^2}{L}.$$
Далее, запишем уравнение кинематической связи для проекций ускорений на нормаль к наклонной поверхности клина:
$$0 = a_\tau \cos \alpha - a_n \sin \alpha, a_\tau = a_n \mathrm{tg} \alpha,$$
$$g = \frac{u^2}{L} \mathrm{tg} \alpha, u^2 = g L \mathrm{tg} \alpha.$$
С учетом того, что $u = v \mathrm{tg} \alpha$, окончательно получим
$$v = \sqrt{\frac{g L}{\mathrm{tg}^3 \alpha}} = \sqrt{g L \mathrm{tg}^3 \alpha}.$$
4. 1) За время $\Delta t$ скигается $\Delta m_0 = \mu_0 \Delta t$ газа, т.е. выделяется $\Delta Q = \Delta m_0 q$ энергии. Лишь $\eta$ ее часть идет на нагревание воды: $\Delta Q_\pi = \eta \Delta Q$. Тогда полезная мощность
$$P = \frac{\Delta Q_\pi}{\Delta t} = \eta \mu_0 q \approx 2,3 \text{ кВт}.$$
2) Заметим, что на участке 1-2 не происходит изменения массы воды (не происходит испарений и дольаний), т.е. этот участок вертикальной. Обозначим массу воды в точке 1 через $M$. Уравнение, описывающее испарение на участке 2-3:
$$P \tau_{23} = \left( M - \frac{M}{4} \right) L = \frac{3 M}{4} L.$$
Уравнение, описывающее дольание воды на участке 3-1:
$$\mu \tau_{31} = M - \frac{M}{4} = \frac{3 M}{4}.$$
С учетом того, что $\tau_{23} = \tau_{31}$, получим
$$\mu = \frac{P}{L} = \mu_0 \frac{\eta q}{L} = 1,0 \text{ г/c}.$$
3) Уравнение теплового баланса на участке 3-1 ($t_{100} = 100^\circ \text{C}$ – температура кипения воды, $c$ – удельная тепломкость воды, $m$ и $t$ – текущие масса и температура воды на этом участке):
$$c \frac{M}{4} \left( t_{100} - t \right) = c \left( m - \frac{M}{4} \right) \left( t - t_x \right),$$
откуда
$$t (m) = t_x + \frac{M}{4} \left( t_{100} - t_x \right) \frac{1}{m}.$$
Посленяя формула показывает линейность участика 3-1. Температура воды в точке 1 равна
$$t_1 = t (M) = t_x + \left( t_{100} - t_x \right) / 4 = \left( t_{100} + 3 t_x \right) / 4 = 40^\circ \text{C}.$$
Диаграмма – это прямогольный треугольник с вершинами (1; 40), (1; 100), (4; 100).

5. 1) Необходимо проанализировать два возможных варианта подключения (рис. 11) и рассчитать показания ваттметра для каждого из них. В случае левой схемы показания амператора ($I_1$) и ваттметра ($U_1$):
$$I_1 = \frac{U}{R + r_A}, U_1 = U.$$
По условияю показания ваттметра равны произведению показаний амператора и ваттметра:
$$P'_1 = I_1 U_1 = \frac{U^2}{R + r_A}.$$
В случае правой схемы показания амператора ($I_2$) и ваттметра ($U_2$):
$$I_2 = \frac{U}{r_A}, I_V = \frac{U}{R + R_V}, U_2 = I_V R_V = \frac{U R_V}{R + R_V}.$$
Тогда
$$P'_2 = I_2 U_2 = \frac{U^2}{R + R_V} \frac{R_V}{r_A}.$$
Отношение показаний ваттметра позволяет использовать источника:
$$k = \frac{P'_1}{P'_2} = \frac{R + R_V}{R + r_A} \frac{r_A}{R_V}.$$
Выразим искомое внутреннее сопротивление ваттметра;
$$R_V = \frac{R}{k \frac{R + r_A}{r_A} - 1}.$$
Теперь подставляем числовые значения. Если $k = 100/1 = 100$, то $R_V \approx 5,0 \cdot 10^{-2} \text{ OM}$. Величина получалась меньше сопротивления амператора, значит, этот ответ неверный. Если $k = 1/100 = 0,01$, то $R_V = 50 \text{ kOm}$. Разумный результат.
