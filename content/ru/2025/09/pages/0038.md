$$x_1 + \dots + x_a \leq x = y_1 + \dots + y_a$$
$$x_{a+1} + \dots + x_{2a} \leq x = y_{a+1} + \dots + y_{2a}$$

$$x_{(t-1)a+1} + \dots + x_{ta} \leq x = y_{(t-1)a+1} + \dots + y_{ta}$$
