Задача 2. Точка $O$ лежит на отрезке $AC$. Найти множество точки $M$, для которых $M\hat{O}C=2M\hat{A}C$ (рис. 4).

Ответ. Обедининие окружности с центром $O$ радиуса $AO$ (без точки $A$) и луча $OC$ (без точки $O$) — см. рисунок 5.

Пояснение. Пусть точка $M$ искомого множество не принадлежит прямой $AO$. Доказем, что $|MO|=|AO|$. Построим треугольник $OAM$ (рис. 6). По теореме о внешнем угле треугольника $O\hat{A}M+A\hat{M}O=M\hat{O}C$. По условию $M\hat{O}C=2M\hat{A}C$.

Из условия задачи сразу получаем $O\hat{A}M=A\hat{M}O$; следовательно, треугольник $AMO$ равноведренный, то есть $|OM|=|AO|$.

На языке «движения» результат задания 2 можно представить себе так: пусть прямая $AM$ врашается вокруг точки $A$ с постоянной угловой скоростью $\omega$ (то есть за единицу времени поворачивается на угол величины $\omega$), а прямая $OM$ врашается вокруг точки $O$ с угловой скоростью $2\omega$, причем в начальной момент времени обе прямые совпадали с прямой $AO$ (рис. 7). Тогда точка $M$ пересечения этих прямых движется по окружности с центром $O$.

Отсюда мы можем извлечь теорему о вписанном угле (теорема 62 из п. 111 «Геометрии 8»). Если прямая $AM$ за время $t$ поворачивается из положения $AM_1$ в положение $AM_2$ на угол $\omega t$, то прямая $OM$ поворачивается на угол $2\omega t$, другими словами, величина вписанной угла $M_1AM_2$ равна поливне угловой величины соответствующего чентрального угла $M_1OM_2$ (рис. 8).

Можно формулировать эту теорему более наглядно:

Теорема о количестве на окружности надeto маленькое колечко. Вокруг точки $A$ окружности врашается стержень, который проходит через это колечко. Если стержень врашается равномерно с угловой скоростью $\omega$, то колечко при этом.bezем по окружности равномерно с угловой скоростью $2\omega$ (рис. 9).

*) Заметим, что теорему о количестве в буквальном смысле: воображаемое «колечко» — просто точка пересечения прямой и окружности; если же сделать проволочную модель, то после одного оборота (в тупили другую сторону) колечко застрянет.
