$$|MF_1| = \sqrt{(x+c)^2 + y^2}, \quad |MF_2| = \sqrt{(x-c)^2 + y^2}$$

в равенство (1) и возводя в квадрат, после преобразования получим

$$(x^2 + y^2 + c^2)^2 - 4c^2x^2 = a^4.$$

Получилось уравнение четырех степени. Конкретный вид кривой зависит, размещается, от того, какие мы выберем значения параметров $a$ и $c$. Давайте, для примера, зафиксируем $a$ и будем увеличивать $c$ (можно поступить и наоборот: зафиксировать $c$ и уменьшать $a$—результат будет тот же; см. рис. 1). Тут-то и произойдет самое интересное: подобно куску теста, который растягивает в разных стороны, овал сначала удлинится, потом у него появится «талия», она будет становиться все тонше, пока, наконец, наша фигура не разорвется на две части, на два меньших овала. Более точного картина будет такой (рис. 2):

1) при $c=0$ — окружность;
2) при $0 < c \leq \frac{a}{\sqrt{2}}$ — выпуклый овал, пожожий на эллипс;
3) при $\frac{a}{\sqrt{2}} < c < a$ — овал с «талейй»;
4) при $c=a$ — «лежащая восьмерка» (она имеет отдельное название — лемисскама Бернулли);
5) при $c>a$ — два овала; один из них содержит внутри точку $F_1$, другой — точку $F_2$.

Указанное свойство «делимость» овалов Кассинни впервые обнаружил и детально изучил другой французский ученый — Жан Поль де Гюа де Мальв (1712—1785). Его работа была одной из первых работ, посвященных исследованию особых точек алгебраических кривых (особой точкой в данном случае является точка самопересечения при $c=a$). Воспел逮ии из таких работ родилась общирная ветвь современной математики — алгебраическая геометрия.

Второй пример

Рассмотрим теперь множество мочек $M$, для которых сумма величины, образных квадратам рассмотреной от

$$\frac{1}{|MF_1|^2} + \frac{1}{|MF_2|^2} = \frac{1}{b^2}.$$

Как и прежде, положим $|F_1F_2|=2c$. Подставляя в (2) формулы для $|MF_1|$ и $|MF_2|$, получаем уравнение $$\frac{1}{(x+c)^2 + y^2} + \frac{1}{(x-c)^2 + y^2} = \frac{1}{b^2}.$$

Контрольный вопрос. Почему уравнение (3) является уравнением четырех степени?

Полученная кривая своим поведением очень напоминает овали Кассинни. На рисунке 3 изображены последовательные «фазы деления», которые проходят кривая при увеличении параметра $c$ (параметр $b$ остается постоянным). Рассмотрим этот процесс чуть подробнее.
