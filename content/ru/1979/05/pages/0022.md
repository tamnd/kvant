⟦folio 20⟧

Вторая серия неравенства

Здесь $a_1, a_2, \dots, a_n - n$ положительны х чисел. Введем следующие обозначения (мы предполагаем, что $k \leq n - 1$):

$$\Sigma_i = \frac{\tilde{s}_i}{S_1 - \tilde{s}_i},$$

$$\Pi_i = \frac{\tilde{p}_i}{P_1 - \tilde{p}_i} \left( i = 1, 2, \dots, C = C_n^k \right).$$

Нас интересуют границы изменения величины $^*$ $\Sigma_1 + \Sigma_2 + \dots + \Sigma_C, \Pi_1 + \Pi_2 + \dots + \Pi_C, \Sigma_1 \Sigma_2 \dots \Sigma_C, \Pi_1 \Pi_2 \dots \Pi_C$. Оказывается, эти границы для выражения $\Sigma_1 \Sigma_2 \dots \Sigma_C$ зависит от $k$; именно:

$$\text{при } k \in \left[ 1, \frac{n}{2} \right] \quad \text{имеем}$$
$$\Sigma_1 \dots \dots \Sigma_C \in \left[ 0, \left( \frac{k}{n-k} \right)^C \right], \quad (\text{III}_1)$$

$$\text{при } k = \frac{n}{2} \quad \text{(если } n \text{ четно)}$$
$$\Sigma_1 \dots \dots \Sigma_C = 1, \quad (\text{III}_2)$$

$$\text{при } k \in \left[ \frac{n}{2}, n-1 \right] \quad \text{имеем}$$
$$\Sigma_1 \dots \dots \Sigma_C \in \left[ \left( \frac{k}{n-k} \right)^C, +\infty \right]. \quad (\text{III}_3)$$

Доказательство утверждения (III$_3$). Наозовем соотношения I рода соотнения из $n$ чисел $a_1, a_2, \dots, a_n$ по $k$, соотнения II рода — соотнения из этих же чисел по $n-k$. Их тоже будет $C$, так как $C_n^k = C_n^{n-k}$. Занутерум соотнения II рода в произвольном порядке, причем сумму чисел в $i$-м соотнения II рода обозначим через $\tilde{s}_i'$. Ясно, что $\tilde{s}_1' \cdot \tilde{s}_2' \dots \tilde{s}_C' = \left( S_1 - \tilde{s}_1 \right) \times \left( S_1 - \tilde{s}_2 \right) \dots \left( S_1 - \tilde{s}_C \right)$. Расмотрим произвольное соотнение I рода с номером $i - \left( a_{i_1}, a_{i_2}, \dots, a_{i_k} \right)$. Из $k > \frac{n}{2}$ следует, что $k > n-k$ и из чисел, входящих в это соотнение, можно составить $C_n^{n-k}$ соотнения II рода (с какими-то номерами $\gamma_1, \gamma_2, \dots, \gamma_R$, где $R = C_n^{n-k}$), причем каждое число из множества $\{ a_{i_1}, a_{i_2}, \dots, a_{i_k} \}$ будет входитьровно в $C_n^{n-k-1}$ таких соотнения II рода. Значит, $C_n^{n-k-1} \tilde{s}_i = \tilde{s}'_{\gamma_1} + \tilde{s}'_{\gamma_2} + \dots + \tilde{s}'_{\gamma_R}$.

Из (1) и (4) следует, что $C_n^{n-k-1} \tilde{s}_i \geq R \left( \tilde{s}'_{\gamma_1} \tilde{s}'_{\gamma_2} \dots \tilde{s}'_{\gamma_R} \right)^{1/R}$. (5)

*) Эти величины интересны для некоторых вопросов теории вероятности (прим. ред.).
