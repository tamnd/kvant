⟦folio 19⟧

мула $(I_2)$ выглядит так:

$$4 \left( \frac{a_1 + a_2 + a_3 + a_4}{4} \right)^3 \geq a_1 a_2 a_3 + a_1 a_2 a_4 + a_1 a_3 a_4 + a_2 a_3 a_4 \geq 4 \left( a_1 a_2 a_3 a_4 \right)^{3/4}.$$

При $k=1$ неравенства $(I_2)$, $(II_1)$ превращаются в $(1)$; $(I_1)$ и $(II_2)$ превращаются в $(1)$ при $k=n$ (проверьте!). Таким образом, все четыре неравенства $(I)$, $(II)$ можно рассматривать как обобщения неравенства $(1)$.

Доказательство неравенства $(I_2)$. Положим для краткости $C = C_n^k$, а через $\tilde{p}_1, \tilde{p}_2, \dots, \tilde{p}_{C_n^k}$ обозначим слагаемые суммы $S_k$ (их, оченьindo, $C = C_n^k$ штук). Так как $\frac{S_k}{C}$ — среднее арифметическое чисел $\tilde{p}_1, \tilde{p}_2, \dots, \tilde{p}_c$, согласно (1)

$$\frac{S_k}{C} \geq \left( \tilde{p}_1 \tilde{p}_2 \dots \tilde{p}_c \right)^{1/C}.$$

Каждее $a_i$ входит компонентомровно в $C_{n-1}^{k-1}$ из чисел $\tilde{p}_1, \tilde{p}_2, \dots, \tilde{p}_c$. Значит, $\left( \tilde{p}_1 \tilde{p}_2 \dots \tilde{p}_c \right)^{1/C} = P_1^v$, где $v = \frac{C_{n-1}^{k-1}}{C} = \frac{C_{n-1}^{k-1}}{C_n^k} = \frac{k}{n}$. Поэтому $\frac{S_k}{C} \geq P_1^{k/n}$, то есть $S_k \geq CP_1^{k/n}$, что и требовалось.

Равенство в $(I_2)$ имеет место при $k=n$, при $a_1 = \dots = a_n$, или при равенстве нулю не менее $n-k+1$ чисел из множества $\{a_1, a_2, \dots, a_n\}$.

Доказательство неравенства $(II_2)$. Обозначим через $\tilde{s}_1, \tilde{s}_2, \dots, \tilde{s}_C$ компоненты произведения $P_k$ (по-прежнему $C = C_n^k$). Положим для краткости $q = k^C$. Влевой части нашего неравенства, т. е. в выражении $P_k$, раскроем скобки. Получим сумму из $q$ слагаемых, каждое из которых есть произведение $C$ чисел из множества $\{a_1, a_2, \dots, a_n\}$, взятых по одному из каждой $\tilde{s}_i$. В произведении этих слагаемых каждое $a_i$ входит компонент, в силу симметрии, одинаковое число раз (обозначим это число через $\mu$). Поэтому это произведение равно $P_1^\mu$, откуда со

$$\frac{P_k}{q} = \left( P_1^\mu \right)^{1/q},$$

причем равенство имеет место тогда и только тогда, когда все наши $q$ слагаемых равны, что, в частности, имеет место при $a_1 = \dots = a_n$; пользоваться этим, найти $\mu$.

Пусть $a_1 = a_2 = \dots = a_n = 2$. Тогда в (2) имеет место равенство $\tilde{s}_1 = \tilde{s}_2 = \dots = \tilde{s}_C = 2k, P_1 = 2^n$, откуда $\frac{(2k)^C}{q} = \left( 2^n \right)^{\frac{\mu}{q}}, 2^C = 2^{\frac{n\mu}{q}}, \mu = \frac{Cq}{n}$.

Подставляя это значение в (2), получаем $(II_2)$.

Ясно, что равенство имеет место либо при $k=1$, либо при $a_1 = \dots = a_n$, либо при равенстве нулю не менее $k$ чисел из множества $\{a_1, a_2, \dots, a_n\}$.

Для доказательства неравенства $(I_1)$ нам будет нужно неравенство Маклорена. Положим $S_k = \frac{S_k}{C_n^k}$. Тогда

$$\bar{S}_1 \geq \bar{S}_2^{\frac{1}{2}} \geq \bar{S}_3^{\frac{1}{3}} \geq \dots \geq \bar{S}_n^{\frac{1}{n}}$$

(если все $a_i$ положительные и не все $a_i$ одинаковы, то введите стопт знак >).

Доказательство этого неравенства можно найти в ХЛП, стр. 69 *).

Доказательство неравенства $(I_1)$ сразу получается из (3). Действительно $S_k C^{-1} = \bar{S}_k, S_1 n^{-1} = \bar{S}_1$, так как $C_n^k = n$. Значит, $(I_1)$ приннимает вид $\bar{S}_1 \geq \bar{S}_k^{\frac{1}{k}}$, а это содержится в (3).

Доказите самостоятельное с помощью неравенства Маклорена также и $(I_2)$.

Неравенство $(II_1)$ доказывается аналогично $(I_2)$; это доказательство мы оставляем читателю.

Условие равенства в $(I_1)$: $a_1 = a_2 = \dots = a_n$ или $k=1$, в $(II_1)$: $a_1 = a_2 = \dots = a_n$ или $k=n$.

*) Другое доказательство, прислаанное М. Розенбергом, будет опубlikован как решение задачи М565.
