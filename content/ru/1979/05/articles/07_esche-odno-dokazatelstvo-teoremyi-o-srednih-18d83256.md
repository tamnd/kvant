$$\Sigma_1 + \dots + \Sigma_c = \left( \frac{S_1}{S_1 - \tilde{s}_1} - 1 \right) + \dots + \left( \frac{S_1}{S_1 - \tilde{s}_c} - 1 \right) = S_1 \left[ \frac{1}{S_1 - \tilde{s}_1} + \dots + \frac{1}{S_1 - \tilde{s}_c} \right] - C \geqslant \frac{C^c \sqrt{H}}{C - C_{n-1}^{k-1}} \cdot \frac{C}{\sqrt{H}} - C = \frac{C^2}{C - C_{n-1}^{k-1}} - C = \frac{kC}{n-k},$$

что и требовалось доказать.

Равенство в (IV) имеет место только при $a_1 = \dots = a_n$. Если это не так, то не все $\tilde{s}_i$ равны и уже в (6) и (7) имеет место знак >.

С другой стороны, $\Sigma_1 + \dots + \Sigma_c$ можно сделать как уголно большим, например, неограниченно увеличивая $a_1$ при фиксированных значениях чисел $a_2, a_3, \dots, a_n$.

Приведем теперь для полотны оценки изменения величины $\Pi_1 + \dots + \Pi_c$ и $\Pi_1 \dots \Pi_c$. Первая величина при $k \neq n/2$ принимает любые положительные значения. При $k = n/2$ (n — четно) она имеет минимум, равный $C = C_k^n$, который достигается при $a_1 = \dots = a_n$, а сверху по-прежнему не ограничена. Вторая величина при $k \neq n/2$ также может принимать любые положительные значения, а при $k = n/2$ (n — четно) эта величина всегда равна 1.

Дешевый ящик

Две стенки ящика, имеющие форму прямогоольного параллелипеда и объем 1 м³, изготовляются из одного материала, а чемпре другие — из материала, который стоит в 8 раз меньше. При каких размерах $x, y, z$ ящика стомимость материалов, нужных для его изготовления, минимальная?

Решение е. Пусть стоимость 1 м² второго материала равна $p$ рублей. По условиям, из первого материала, — смежные, либо — нет. В первом случае стоимость материалов равна

$$S_1 = 8p(xy + yz) + p(xy + yz + 2xz) = p \cdot xyz \left( \frac{9}{z} + \frac{9}{x} + \frac{2}{y} \right) = p \left( \frac{9}{z} + \frac{9}{x} + \frac{2}{y} \right),$$

во втором —

$$S_2 = 8p2xy + p(2xz + 2yz) = 2pxyz \left( \frac{8}{z} + \frac{1}{y} + \frac{1}{x} \right) = 2p \left( \frac{8}{z} + \frac{1}{y} + \frac{1}{x} \right).$$

Приименим неравенство

$$\frac{a + b + c}{3} \geqslant \sqrt{abc}$$

между средним арфметическим и средним геометрическим (см. с. 18) к этим выражениям. Получим

$$S_1 \geqslant 9 \sqrt[3]{6} p \text{ и } S_2 \geqslant 12p.$$

Легко видеть, что $9 \sqrt[3]{6} p > 12p$. Стоимость $S_2$ будет минимальная тогда и только тогда, когда минимальный будет сумма $\frac{8}{z} + \frac{1}{y} + \frac{1}{x}$ при последнее условие будет выполнено в том и только в том случае, когда $\frac{8}{z} + \frac{1}{y} + \frac{1}{x} = \frac{1}{x}$ при последнее условие.

Для этого, в свою очередь, необходимо и достаточно, чтобы $8/z = 1/y = 1/x$.

Поскольку $xyz = 1$, от сюда следует, что $x = y = 0,5; z = 4$.

Таким образом, стенки из первого материала должны быть несмежными и имеет форму квадрата со сторонай 0,5 м, а расстояние между ними равно 4 м.
