Вариация на тему классических неравенств

Эта заметка написана десятиклассиком Мишей Севриоком на основе его доклада на конференции НОУ Московской школы № 2. В ней доказываются неравенства, найденные автором, видимsementшие и обобщенные неравенство о среднем арифметическом и среднем геометрическом. Они, конечно же, не новые: в классических области математики практические нет «белых пятен», достижимых без серверной подготовки. Доказательства упомянутых неравенств содержатся, например, в замечательной, но трудно доступной книге Харди, Литвуда и Поляна *); однако чисто комбинаторные доказательства М. Севриока оригинальных и заметно проще.

Неравенства указаанного типа интересют и многих других наших читателей. Кроме заметки М. Севриока мы в этом номере публикуем в виде задачи (М565) неравенства Маклорена, интересные доказательства которых прислал М. Розенберг, а также задачу P. Винокура, показывающего применимость неравенств указаного типа в самых разнообразных ситуациях.

В наш век электронных компьютеров приятно сознавать, что живое искусство алгебраических преобразования не утратило свою привлекательность и не перестало быть полезным …

Еще древние греки знали, что среднее геометрическое $\sqrt{ab}$ двух неотрицательных чисел не преосходит их среднего арифметического $\frac{a+b}{2}$. Эта теорема справедлива для любого числа неотрицательных чисел $a_1, a_2, \dots, a_n$:

$$\frac{1}{n} (a_1 + \cdots + a_n) \geq (a_1 \dots a_n)^{1/n}$$

(равенство наступает только тогда, когда все $a_i$ совпадают); она будет служить основой всего дальнейшего.

Первая серия неравенств

Здесь по-прежнему $a_1, a_2, \dots, a_n$ — произвольные неотрицательные числа. Кроме суммы $S_1$ всех $a_i$ по отдельности, как в неравенстве (1), нас будут интересовать сумма их всевозможных попарных произведений $S_2 = a_1 a_2 + a_1 a_3 + \dots + a_{n-1} a_n$,

сумма их всевозможных произведений по три

$$S_3 = a_1 a_2 a_3 + a_1 a_2 a_4 + \dots + a_{n-2} a_{n-1} a_n$$

и вообще сумма $S_k$ их произведений по $k$ компонентей ($k \leq n$). Аналогично, кроме произведения $P_1$ всех $a_i$ по отдельности, нас будут интересовать произведение всевозможных попарных сумм

$$P_2 = (a_1 + a_2) (a_1 + a_3) \dots \dots (a_{n-1} + a_n)$$

произведение сумм по три

$$P_3 = (a_1 + a_2 + a_3) (a_1 + a_2 + a_4) \dots \dots (a_{n-2} + a_{n-1} + a_n)$$

и вообще произведение $P_k$ их сумм по $k$ слагаемых ($k \leq n$).

Оказывается, величины $S_k$ и $P_k$ при $k=1, 2, \dots, n$ можно дать следующие оценки сверху и снизу (через $S_1 = a_1 + \dots + a_n$ и $P_1 = a_1 \dots a_n$):

$$C_n^k \left( \frac{S_1}{n} \right)^k \geq S_k \geq C_n^k P_k^{\frac{k}{n}}$$

$$\left( \frac{k}{n} \right)^{C_n^k} S_1^{C_n^k} \geq P_k \geq k^{C_n^k} P_1^{\frac{k}{n}}$$

Развернуть запись этих формул выглядит очень внутренно. Не пуляйтесь! Расшифруйте лучше одну из этих формул (при конкретных, не слишком больших значениях $k, n$) и вы увидите — все это не так страшно. Например, при $k=3, n=4$, форму

мула $(I_2)$ выглядит так:

$$4 \left( \frac{a_1 + a_2 + a_3 + a_4}{4} \right)^3 \geq a_1 a_2 a_3 + a_1 a_2 a_4 + a_1 a_3 a_4 + a_2 a_3 a_4 \geq 4 \left( a_1 a_2 a_3 a_4 \right)^{3/4}.$$

При $k=1$ неравенства $(I_2)$, $(II_1)$ превращаются в $(1)$; $(I_1)$ и $(II_2)$ превращаются в $(1)$ при $k=n$ (проверьте!). Таким образом, все четыре неравенства $(I)$, $(II)$ можно рассматривать как обобщения неравенства $(1)$.

Доказательство неравенства $(I_2)$. Положим для краткости $C = C_n^k$, а через $\tilde{p}_1, \tilde{p}_2, \dots, \tilde{p}_{C_n^k}$ обозначим слагаемые суммы $S_k$ (их, оченьindo, $C = C_n^k$ штук). Так как $\frac{S_k}{C}$ — среднее арифметическое чисел $\tilde{p}_1, \tilde{p}_2, \dots, \tilde{p}_c$, согласно (1)

$$\frac{S_k}{C} \geq \left( \tilde{p}_1 \tilde{p}_2 \dots \tilde{p}_c \right)^{1/C}.$$

Каждее $a_i$ входит компонентомровно в $C_{n-1}^{k-1}$ из чисел $\tilde{p}_1, \tilde{p}_2, \dots, \tilde{p}_c$. Значит, $\left( \tilde{p}_1 \tilde{p}_2 \dots \tilde{p}_c \right)^{1/C} = P_1^v$, где $v = \frac{C_{n-1}^{k-1}}{C} = \frac{C_{n-1}^{k-1}}{C_n^k} = \frac{k}{n}$. Поэтому $\frac{S_k}{C} \geq P_1^{k/n}$, то есть $S_k \geq CP_1^{k/n}$, что и требовалось.

Равенство в $(I_2)$ имеет место при $k=n$, при $a_1 = \dots = a_n$, или при равенстве нулю не менее $n-k+1$ чисел из множества $\{a_1, a_2, \dots, a_n\}$.

Доказательство неравенства $(II_2)$. Обозначим через $\tilde{s}_1, \tilde{s}_2, \dots, \tilde{s}_C$ компоненты произведения $P_k$ (по-прежнему $C = C_n^k$). Положим для краткости $q = k^C$. Влевой части нашего неравенства, т. е. в выражении $P_k$, раскроем скобки. Получим сумму из $q$ слагаемых, каждое из которых есть произведение $C$ чисел из множества $\{a_1, a_2, \dots, a_n\}$, взятых по одному из каждой $\tilde{s}_i$. В произведении этих слагаемых каждое $a_i$ входит компонент, в силу симметрии, одинаковое число раз (обозначим это число через $\mu$). Поэтому это произведение равно $P_1^\mu$, откуда со

$$\frac{P_k}{q} = \left( P_1^\mu \right)^{1/q},$$

причем равенство имеет место тогда и только тогда, когда все наши $q$ слагаемых равны, что, в частности, имеет место при $a_1 = \dots = a_n$; пользоваться этим, найти $\mu$.

Пусть $a_1 = a_2 = \dots = a_n = 2$. Тогда в (2) имеет место равенство $\tilde{s}_1 = \tilde{s}_2 = \dots = \tilde{s}_C = 2k, P_1 = 2^n$, откуда $\frac{(2k)^C}{q} = \left( 2^n \right)^{\frac{\mu}{q}}, 2^C = 2^{\frac{n\mu}{q}}, \mu = \frac{Cq}{n}$.

Подставляя это значение в (2), получаем $(II_2)$.

Ясно, что равенство имеет место либо при $k=1$, либо при $a_1 = \dots = a_n$, либо при равенстве нулю не менее $k$ чисел из множества $\{a_1, a_2, \dots, a_n\}$.

Для доказательства неравенства $(I_1)$ нам будет нужно неравенство Маклорена. Положим $S_k = \frac{S_k}{C_n^k}$. Тогда

$$\bar{S}_1 \geq \bar{S}_2^{\frac{1}{2}} \geq \bar{S}_3^{\frac{1}{3}} \geq \dots \geq \bar{S}_n^{\frac{1}{n}}$$

(если все $a_i$ положительные и не все $a_i$ одинаковы, то введите стопт знак >).

Доказательство этого неравенства можно найти в ХЛП, стр. 69 *).

Доказательство неравенства $(I_1)$ сразу получается из (3). Действительно $S_k C^{-1} = \bar{S}_k, S_1 n^{-1} = \bar{S}_1$, так как $C_n^k = n$. Значит, $(I_1)$ приннимает вид $\bar{S}_1 \geq \bar{S}_k^{\frac{1}{k}}$, а это содержится в (3).

Доказите самостоятельное с помощью неравенства Маклорена также и $(I_2)$.

Неравенство $(II_1)$ доказывается аналогично $(I_2)$; это доказательство мы оставляем читателю.

Условие равенства в $(I_1)$: $a_1 = a_2 = \dots = a_n$ или $k=1$, в $(II_1)$: $a_1 = a_2 = \dots = a_n$ или $k=n$.

*) Другое доказательство, прислаанное М. Розенбергом, будет опубlikован как решение задачи М565.

Вторая серия неравенства

Здесь $a_1, a_2, \dots, a_n - n$ положительны х чисел. Введем следующие обозначения (мы предполагаем, что $k \leq n - 1$):

$$\Sigma_i = \frac{\tilde{s}_i}{S_1 - \tilde{s}_i},$$

$$\Pi_i = \frac{\tilde{p}_i}{P_1 - \tilde{p}_i} \left( i = 1, 2, \dots, C = C_n^k \right).$$

Нас интересуют границы изменения величины $^*$ $\Sigma_1 + \Sigma_2 + \dots + \Sigma_C, \Pi_1 + \Pi_2 + \dots + \Pi_C, \Sigma_1 \Sigma_2 \dots \Sigma_C, \Pi_1 \Pi_2 \dots \Pi_C$. Оказывается, эти границы для выражения $\Sigma_1 \Sigma_2 \dots \Sigma_C$ зависит от $k$; именно:

$$\text{при } k \in \left[ 1, \frac{n}{2} \right] \quad \text{имеем}$$
$$\Sigma_1 \dots \dots \Sigma_C \in \left[ 0, \left( \frac{k}{n-k} \right)^C \right], \quad (\text{III}_1)$$

$$\text{при } k = \frac{n}{2} \quad \text{(если } n \text{ четно)}$$
$$\Sigma_1 \dots \dots \Sigma_C = 1, \quad (\text{III}_2)$$

$$\text{при } k \in \left[ \frac{n}{2}, n-1 \right] \quad \text{имеем}$$
$$\Sigma_1 \dots \dots \Sigma_C \in \left[ \left( \frac{k}{n-k} \right)^C, +\infty \right]. \quad (\text{III}_3)$$

Доказательство утверждения (III$_3$). Наозовем соотношения I рода соотнения из $n$ чисел $a_1, a_2, \dots, a_n$ по $k$, соотнения II рода — соотнения из этих же чисел по $n-k$. Их тоже будет $C$, так как $C_n^k = C_n^{n-k}$. Занутерум соотнения II рода в произвольном порядке, причем сумму чисел в $i$-м соотнения II рода обозначим через $\tilde{s}_i'$. Ясно, что $\tilde{s}_1' \cdot \tilde{s}_2' \dots \tilde{s}_C' = \left( S_1 - \tilde{s}_1 \right) \times \left( S_1 - \tilde{s}_2 \right) \dots \left( S_1 - \tilde{s}_C \right)$. Расмотрим произвольное соотнение I рода с номером $i - \left( a_{i_1}, a_{i_2}, \dots, a_{i_k} \right)$. Из $k > \frac{n}{2}$ следует, что $k > n-k$ и из чисел, входящих в это соотнение, можно составить $C_n^{n-k}$ соотнения II рода (с какими-то номерами $\gamma_1, \gamma_2, \dots, \gamma_R$, где $R = C_n^{n-k}$), причем каждое число из множества $\{ a_{i_1}, a_{i_2}, \dots, a_{i_k} \}$ будет входитьровно в $C_n^{n-k-1}$ таких соотнения II рода. Значит, $C_n^{n-k-1} \tilde{s}_i = \tilde{s}'_{\gamma_1} + \tilde{s}'_{\gamma_2} + \dots + \tilde{s}'_{\gamma_R}$.

Из (1) и (4) следует, что $C_n^{n-k-1} \tilde{s}_i \geq R \left( \tilde{s}'_{\gamma_1} \tilde{s}'_{\gamma_2} \dots \tilde{s}'_{\gamma_R} \right)^{1/R}$. (5)

*) Эти величины интересны для некоторых вопросов теории вероятности (прим. ред.).
