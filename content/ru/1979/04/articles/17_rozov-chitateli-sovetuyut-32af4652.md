Читатель советуют

В общирной редакционной почте «Кванта» значительная часть письма наших читателей — школьников, преподавателей, любитель математики — касается тематики раздела «Практику абитурента». Многие из них затрагивают частиные вопросы — на такие письма редакция отвечает лично их автором. Но в целом ряде письма и заметок высказываются интересные сообщения по различным теоретическим вопросам школьного курса математики, излагаются примышления некоторых типов экзаменационных задач, сообщаются полезные замечания, предложения методического характера, самостоятельно составленные задачи. Хотя приводимые в подобных письмах сообщения и задачи не всегда являются новыми и оригинальными, с их содержанием целесообразно, на наш взгляд, познакомить всех читателей «Кванта». Не считая возможным публиковать эти письма и заметки полностью, редакция подготовила подборку материалов, составленную по идеям и предложенным читателем журнала, с необходимыми дополнительными комментариями. Мы надеемся, что включенные в подборку вопросы окажут помощь поступающим вузы.

Свободное владение школьным курсом математики, которое абитурент должен показать на примемом экзамене, подразумевает, в частности, умение правильно проводить вычисления, грамотно преобразовать алгебраические выражения. К сожалению, поступающим часто снижают оценку именно за ошибки, допущенные в ходе преобразования. Такие ошибки проискодят, как правило, не из-за незначения — это, скорее, результат ненимателовости и небрежности, неумения проверять само себя, результат недостаточной практики в решении примеров, отраживающих техническую подготовку (см. «Квант», 1974, № 3, с. 49—50). Суть этого метода состоит в том, что вместо одной из входящих в алгебраические выражения переменных подставляется некоторая тригонометрическая функция вспомогательного угла, причем она подбирается так, чтобы исходное выражение в силу известных формул тригонометрии упростилось.

Конечно, удача тригонометрическая подготовка былает полезна не только для преобразования алгебраических выражений, но и во многих задачах — при решении уравнений, доказательстве неравенств и т. д. Большой набор интересных примеров такого рода прислал наш читатель В. Ольхов (Горький).

Пример 1. Доказать мождество

$$\sqrt{a + \sqrt{b}} = \sqrt{\frac{a + \sqrt{a^2 - b}}{2}} + \sqrt{\frac{a - \sqrt{a^2 - b}}{2}}.$$ (1)

Прежде всего заметим, что обе части равенства (1) одновременно имеют смысл, если

$$b \geq 0, a \geq 0, a \geq \sqrt{b};$$ (2)

для этих значений $a$ и $b$ мы и докажем наше тожество. Наличие под квадратным корнем выражения $a^2 - b$ наводит на мысль положить

$$b = a^2\sin^2\varphi, \text{ где } 0 \leq \varphi \leq \pi/2,$$ (3) — ведь тогда

$$\sqrt{a^2 - b} = a\cos\varphi.$$

Такая тригонометрическая подготовка допустима, поскольку в силу неравенств (2) дробь $b/a^2$ (при $a \neq 0$) заключается между 0 и 1 и ее можно принять за значение квадрата синуса неокторого угла первого четверти

(если $a=0$, то и $b=0$ и тождество (1) оченьно).

После подстановки (3) права часть равенства (1) запишется в виде

$$\sqrt{a} \left( \cos \frac{\varphi}{2} + \sin \frac{\varphi}{2} \right).$$

В то же время

$$\sqrt{a + \sqrt{b}} = \sqrt{a + a \sin \varphi} = \sqrt{a} \left( \cos \frac{\varphi}{2} + \sin \frac{\varphi}{2} \right),$$

так как $1 + \sin \varphi = \cos^2 \frac{\varphi}{2} + 2 \cos \frac{\varphi}{2} \sin \frac{\varphi}{2} + \sin^2 \frac{\varphi}{2} = \left( \cos \frac{\varphi}{2} + \sin \frac{\varphi}{2} \right)^2$, и тождество (1) доказано.

Пример 2. Доказать, что при $c > 0, a > c, b > c$

$$\sqrt{(a + c)(b + c)} + \sqrt{(a - c)(b - c)} \leq 2 \sqrt{ab}.$$

Коеда в этом неравенстве достигается знак равенства?

Перепишем доказываемое неравенство в виде

$$\sqrt{\left( 1 + \frac{c}{a} \right)\left( 1 + \frac{c}{b} \right)} + \sqrt{\left( 1 - \frac{c}{a} \right)\left( 1 - \frac{c}{b} \right)} \leq 2.$$ (4)

Так как по условию

$$0 < \frac{c}{a} < 1, \quad 0 < \frac{c}{b} < 1,$$

можно положить

$$\frac{c}{a} = \cos \alpha, \quad 0 < \alpha < \pi/2,$$

$$\frac{c}{b} = \cos \beta, \quad 0 < \beta < \pi/2.$$

Если влевой части неравенства (4) выполнить эту тригонометрическую подстановку, то можно последовать:

$$\sqrt{(1 + \cos \alpha)(1 + \cos \beta)} + \sqrt{(1 - \cos \alpha)(1 - \cos \beta)} = 2 \left( \cos \frac{\alpha}{2} \cos \frac{\beta}{2} + \sin \frac{\alpha}{2} \sin \frac{\beta}{2} \right) = 2 \cos \left( \frac{\alpha}{2} - \frac{\beta}{2} \right) \leq 2,$$

что и доказывает неравенство (4).

Из приведенной цепочки преобразования видно, что равенство в соответствии (4) достигается, когда

$$\cos \left( \frac{\alpha}{2} - \frac{\beta}{2} \right) = 1,$$

т. е. при $\alpha = \beta$; это возможно только при $a = b$ (проверьте самостояльно!).

Следующое ниже irrationalное уравнение с параметром без особого труда решается стандартным методом — возведением в степень; надо только внимательно проследить за тем, чтобы не получить построенных корней. Мы показем, как это уравнение решается иначе — с помощью тригонометрического подстановки.

Пример 3. Решить уравнение

$$\sqrt{p + x} + \sqrt{p - x} = x.$$ (5)

Заметим прежде все, что если уравнение (5) при каком-нибудь значении параметра $p$ имеет корень, то этот корень — неотрицательное число (почему?). Отсюда следует, что при $p < 0$ уравнение (5) корней не имеет, при $p = 0$ оно имеет один корень $x = 0$ и при $p > 0$ корни должны удовлетворять неравенству $0 < x \leq p$ (доказите эти утверждения).

Сделаем тригонометрискую подстановку

$$x = p \cos \psi, \quad 0 \leq \psi < \frac{\pi}{2};$$

тогда уравнение (5) примет вид

$$\sqrt{1 + \cos \psi} + \sqrt{1 - \cos \psi} = \sqrt{p} \cos \psi,$$

или

$$\sqrt{2} = \sqrt{p} \left( \cos \frac{\psi}{2} - \sin \frac{\psi}{2} \right)$$

(проделяйте выкладки). Возведя обе части последнего уравнения в квадрат, получим

$$\sin \psi = \frac{p - 2}{p}.$$

Определяем от сюда значение $\psi$ можно выбрать в первой четверти только тогда, когда $p \geq 2$; следовательно, уравнение (5) имеет корни только для значений параметра $p \geq 2$. При любом значении параметра, удовлетворяющим этому условию,

Пример 5 (МГУ, мехмат, 1965). Сколько корней имеет уравнение

$$\sin x + 2 \sin 2x = 3 + \sin 3x?$$

Применя известные формулы тригонометрии, предложенное уравнение перепишем в виде

$$\sin 2x - \sin x \cos 2x = \frac{3}{2}.$$

(8)

Тепер львую часть преобразуем следующим образом:

$$\sin 2x - \sin x \cos 2x =$$

$$= \sqrt{1 + \sin^2 x} \left[ \frac{1}{\sqrt{1 + \sin^2 x}} \sin 2x - \frac{\sin x}{\sqrt{1 + \sin^2 x}} \cos 2x \right].$$

Так как при любом $x$

$$\left( \frac{1}{\sqrt{1 + \sin^2 x}} \right)^2 + \left( -\frac{\sin x}{\sqrt{1 + \sin^2 x}} \right)^2 = 1,$$

существует зависщий от $x$ угол $\varphi = \varphi(x)$ такой, что

$$\frac{1}{\sqrt{1 + \sin^2 x}} = \cos \varphi(x),$$

$$- \frac{\sin x}{\sqrt{1 + \sin^2 x}} = \sin \varphi(x).$$

No тогда

$$\sin 2x - \sin x \cos 2x =$$

$$= \sqrt{1 + \sin^2 x} \sin (2x + \varphi(x)),$$

так что уравнение (8) равносильно уравнению

$$\sqrt{1 + \sin^2 x} \sin (2x + \varphi(x)) = \frac{3}{2}.$$

Поскольку левая часть последнего уравнения при всех значениях $x$ не превыходит $\sqrt{2}$, это уравнение корней не имеет.

Наш читатель В. Колмыков (Воронеж) предлагает найти ошибку в «доказательстве» следующей явно неверной «теоремы»:

10. Теорема. Если две плоскости параллельны, то они совпадают.

Доказательство. Пусть

$$ax + by + cz + d = 0$$

— уравнение плоскости $\alpha$, а

$$Ax + By + Cz + D = 0$$

— уравнение плоскости $\beta$, и пусть $\alpha \parallel \beta$. В силу параллельности этих плоскостей

$$\frac{A}{a} = \frac{B}{b} = \frac{C}{c},$$

или, если обозначит эти отношения через $k$, $A = ka$, $B = kb$, $C = kc$.

No тогда уравнение плоскости $\beta$ можно записать в виде

$$ax + by + cz + d = 0.$$

Вычитая из равенства (10) равенство (9), получаем, что $D = kd$, а потому уравнение (10) плоскости $\beta$ можно переписать в виде

$$ax + by + cz + d = 0.$$

Поскольку это уравнение совпадает с уравнением (9) плоскости $\alpha$, получаем $\alpha = \beta$.
