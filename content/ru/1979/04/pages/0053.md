$$\sin \varphi = \frac{b}{\sqrt{a^2 + b^2}}, \cos \varphi = \frac{a}{\sqrt{a^2 + b^2}}$$

(«Квант», 1976, № 4, с. 41—42).

На любопытное обобщение формулы (7) указывает в своей письме М. Шкаленюк (Одесса). Продемонстрируем это обобщение на конкретной задаче.

Пример 5 (МГУ, мехмат, 1965). Сколько корней имеет уравнение

$$\sin x + 2 \sin 2x = 3 + \sin 3x?$$

Применя известные формулы тригонометрии, предложенное уравнение перепишем в виде

$$\sin 2x - \sin x \cos 2x = \frac{3}{2}.$$

(8)

Тепер львую часть преобразуем следующим образом:

$$\sin 2x - \sin x \cos 2x =$$

$$= \sqrt{1 + \sin^2 x} \left[ \frac{1}{\sqrt{1 + \sin^2 x}} \sin 2x - \frac{\sin x}{\sqrt{1 + \sin^2 x}} \cos 2x \right].$$

Так как при любом $x$

$$\left( \frac{1}{\sqrt{1 + \sin^2 x}} \right)^2 + \left( -\frac{\sin x}{\sqrt{1 + \sin^2 x}} \right)^2 = 1,$$

существует зависщий от $x$ угол $\varphi = \varphi(x)$ такой, что

$$\frac{1}{\sqrt{1 + \sin^2 x}} = \cos \varphi(x),$$

$$- \frac{\sin x}{\sqrt{1 + \sin^2 x}} = \sin \varphi(x).$$

No тогда

$$\sin 2x - \sin x \cos 2x =$$

$$= \sqrt{1 + \sin^2 x} \sin (2x + \varphi(x)),$$

так что уравнение (8) равносильно уравнению

$$\sqrt{1 + \sin^2 x} \sin (2x + \varphi(x)) = \frac{3}{2}.$$

Поскольку левая часть последнего уравнения при всех значениях $x$ не превыходит $\sqrt{2}$, это уравнение корней не имеет.

Наш читатель В. Колмыков (Воронеж) предлагает найти ошибку в «доказательстве» следующей явно неверной «теоремы»:

10. Теорема. Если две плоскости параллельны, то они совпадают.

Доказательство. Пусть

$$ax + by + cz + d = 0$$

— уравнение плоскости $\alpha$, а

$$Ax + By + Cz + D = 0$$

— уравнение плоскости $\beta$, и пусть $\alpha \parallel \beta$. В силу параллельности этих плоскостей

$$\frac{A}{a} = \frac{B}{b} = \frac{C}{c},$$

или, если обозначит эти отношения через $k$, $A = ka$, $B = kb$, $C = kc$.

No тогда уравнение плоскости $\beta$ можно записать в виде

$$ax + by + cz + d = 0.$$

Вычитая из равенства (10) равенство (9), получаем, что $D = kd$, а потому уравнение (10) плоскости $\beta$ можно переписать в виде

$$ax + by + cz + d = 0.$$

Поскольку это уравнение совпадает с уравнением (9) плоскости $\alpha$, получаем $\alpha = \beta$.
