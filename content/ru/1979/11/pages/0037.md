Ф551. Груз массы m подвешен к двум пружинам с жесткостью $k_1$ и $k_2$ с помощью нити и блока (рис. 15). Найти перiod малых колебаний груза. Нимtb и блок ситамь невесомыми.

При смешении блока с грузом на величины $x$ суммарная деформация пружин равна $2x$, то есть
$$x_1 + x_2 = 2x,$$
где $x_1, x_2$ — деформация пружин с жесткостью $k_1$ и жесткостью $k_2$ соответственно. Силья упругости, возникшие в пружинах, одинаковы — каждая из них равна по абсцилтной величины силе $\vec{T}$ натяжения нити. Таким образом, $x_1 = T/k_1, x_2 = T/k_2$ и
$$2x = \frac{T}{k_1} + \frac{T}{k_2}$$
(здесь $T = |\vec{T}|$). Отсюда находится
$$T = 2 \frac{k_1 k_2}{k_1 + k_2} x.$$
Сила $\vec{F}$, действующая на блок с грузом, равна по абсцилтной велинице $2T$, то есть
$$F = \frac{4k_1 k_2}{k_1 + k_2} x$$
(здесь $F = |\vec{F}|$). Таким образом, колебания блока с грузом можно рассматривать как колебания груза массы $m$ на пружине с жесткостью $k' = \frac{4k_1 k_2}{k_1 + k_2}$. Период таких колебаний равен
$$T = 2\pi \sqrt{\frac{m}{k'}} = \pi \sqrt{\frac{m(k_1 + k_2)}{k_1 k_2}}.$$

Ф552. Волым-amпераная характеристика неоновой лампы показана на рис. 16. При каком значении $R$ сопротивления резистора, включено в цепь, изображенную на рис. 17, неоновая лампа (н. л.) не будет засунуть после замыкания ключа $K$?

При замыкании ключа конденсатор начинает заряжаться. Когда напряжение на конденсatore, а следовательно, и на лампе станет равным 110 В, лампа загорится. С этого момента ток, текущий через лампу, будет возрастать, а напряжение на лампе и, следовательно, на конденсatore будет падает — конденсатор будет заряжаться. Если в процессе заряжения на конденсatore станет меньше 80 В, лампа погаснет — ток в цепи меньше номинального тока, текущую через лампу при заряжении ~80 В (см. рис. 16).
