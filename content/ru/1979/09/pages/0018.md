Электрическая цепь извлекает квадратные корни

В «Сборнике вопросов и задач по физике» под редакцией Н. Гольдфарба приводится следующая задача: составлена электрическая цепь из бесконечного числа ячейек, состоящих из трех одинаковых сопротивлений r (рис. 1). Найти сопротивление этой цепи.

Для решения сосчитаем сначала сопротивление R1 первой ячейки (разомкнутые клеммы K1, L1). Очевидно, R1=3r. Замкнут снова клеммы K1, L1 и разомкнутые клеммы K2, L2, найдем сопротивление R2 двух ячейек:

$$R_2 = 2r + \frac{rR_1}{r + R_1}.$$

Аналогично,

$$R_3 = 2r + \frac{rR_2}{r + R_2}, \dots,$$

$$R_n = 2r + \frac{rR_{n-1}}{r + R_{n-1}}.$$

где Rn — сопротивление цепи при разомкнутых клеммах Kn, Ln, n=1, 2, 3, ... (рис. 1). Для бесконечной цепочки мы получим

$$R_\infty = 2r + \frac{rR_\infty}{r + R_\infty}.$$

Решим это уравнение относительно R_\infty:

$$R_\infty = r(1 + \sqrt{3}).$$

Для того чтобы это расчёжение было корректным, необходимо доказать с учетом ван и предел а lim Rn=R_\infty. Но при наших предположениях это следует из теоремы Вейерштрасса («Алгебра и начала анализ 9» п. 32); действительно, последовательность (Rn) ограничена сизу (числом (1+√3) r) и монотно убивает (проверьте!).

Из полученного ответа видно, что эта схема позволяет вычислить значение √3, изменив сопротивление цепочки при достижении большом числе ячейек.

Положив величины сопротивления в перемычках равной 2r, получим

$$R_\infty = r(1 + \sqrt{5}).$$

Для значения 3r

$$R_\infty = r(1 + \sqrt{7}),$$

для значения nr (n — любое натуральное число)

$$R_\infty = r(1 + \sqrt{2n+1}).$$

Наша цепь «извлекает корень» из любого нечетного числа!

Можно показать, что для любого вещественного числа a≥1 можно так подобрать сопротивление на перемычках, чтобы сопротивление бесконечной цепи равнялось r(1+√a).
