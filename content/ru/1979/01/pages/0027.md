⟦folio 25⟧

Когда заяц пойман, $x_T = y_T = 0$. В начальной момент времени $y_0 = a \cos \alpha$. Таким образом, проекция на ось $Oy$ перемещения волка за время $T$, необходимое для поимки зайца, равна $y_0 = a \cos \alpha$. Поэтому среднее значение проекции скорости волка на ось $Oy$ за время $T$

$$\bar{U}'_{\rightarrow Oy} = -y_0 / T = -a (\cos \alpha) / T.$$

Найде м теперь из (1) и (2) соответствие между $U'_{\rightarrow OB_1}$ и $U'_{\rightarrow Oy}$. Имеем:

$$U'_{\rightarrow OB_1} = U'_{\rightarrow Oy} / n + |\vec{V}| / n - n |\vec{V}|.$$

Поскольку слагаемые $|\vec{V}| / n$ и $n |\vec{V}|$ от времени не зависит, такое же соответствие справедливо и для средних значений расматриваемых проекций, то есть

$$\bar{U}'_{\rightarrow OB_1} = \bar{U}'_{\rightarrow Oy} / n + |\vec{V}| / n - n |\vec{V}| = -a (\cos \alpha) / n T + |\vec{V}| / n - n |\vec{V}|.$$

С другой стороны,

$$\bar{U}'_{\rightarrow OB_1} = -a / T.$$

Из (3) и (4) находим исключение поимки:

$$T = \frac{a}{|\vec{V}|} \cdot \frac{n}{n^2 - 1} \left(1 - \frac{\cos \alpha}{n}\right).$$

Проверим этот ответ для оценных частных случаев.

$1^\circ$ $\alpha = 0$: волк безит на встроечу зайцу. В этом случае величины относительной скорости движения волка равна $|\vec{V}| / (n + 1)$, так что он доогнит зайца за время $T_1 = \frac{a}{|\vec{V}| / (n + 1)}$.

Этот же результат получается из (5) при подстановке $\alpha = 0$.

$2^\circ$ $\alpha = \pi$: волк безит зайцем. При этом величина его относительной скорости равна $|\vec{V}| / (n - 1)$ ($n > 1$), и он доогнит зайца за время $T_2 = \frac{a}{|\vec{V}| / (n - 1)}$.

Подставляя $\alpha = \pi$ в выражение (5), получаем тот же ответ.

За время $T$ зац пробегает расстояние

$$S_3 = |\vec{V}| T = \frac{an}{n^2 - 1} \left(1 - \frac{\cos \alpha}{n}\right),$$

так что волкLOBит зайца в точке на прямой $l$, отстоящей от точки $A$ на этом расстоянии $S_3$.
