Вернемся теперь к исходной задаче и выясним, при каких $A$ $k(A, 2n) < n$. Для этого достаточно решить относительно $A$ неравенство

$$A(1 + Z_3 + \ldots + Z_p) + 2n \cdot Z_q + (2^i - 1) \leq n.$$

Беря $p$ равным 3,5 или 7, мы получим, соответственно,

$$A \leq \frac{2}{9}n - \frac{14}{3}, \quad A \leq \frac{14}{55}n - \frac{90}{11},$$

$$A \leq \frac{38}{147}n - \frac{310}{21}.$$

При $p = 7$ появляется тиннстевенный множитель $\frac{38}{147}$, самый большой из трех. Брать $p \geq 11$ бессмысленно, так как $11 \cdot \frac{38}{147}n \geq 2n$, и неравенства для $k(A, 2n)$ будут менее точными. Итак, мы доказали, что при $n \geq 2$ для любой последовательности $a_1 < a_2 < \ldots < a_n \leq 2n$

$$\max(a_i, a_j) > \frac{38}{147}n - \frac{310}{21}.$$

Чтобы доказать, что коэффициент $\frac{38}{147}$ нельзя увечит, возьмем $A = \frac{38}{147}n + \frac{310}{21}$. Тогда при $n \geq 543$ будет $7A \leq 2n < 11A$, и, используя неравенство (3), получаем $k(A, 2n) \geq n$. Следовательно, при $n \geq 543$ всегда найдется последовательность $a_1 < a_2 < \ldots < a_n \leq 2n$, для которого

$$\max(a_i, a_j) \leq \frac{38}{147}n + \frac{310}{21}.$$

Если оценить $m_r(C)$ следует аккуратной, то можно получить более точные неравенства: при $n \geq 2$ для любой последовательности $a_1 < a_2 < \ldots < a_n \leq 2n$

$$\max(a_i, a_j) \geq \frac{38}{147}n - \frac{73}{49};$$

и, кроме того, существует последовательность $a_1 < a_2 < \ldots < a_n \leq 2n$, для которого

$$\max(a_i, a_j) \leq \frac{38}{147}n + \frac{73}{49}.$$

(замечательно то, что константу $\frac{73}{49}$ в этих неравенствах уменьшить уже нельзя).
