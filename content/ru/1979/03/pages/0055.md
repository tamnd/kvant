Задача 5. Докажите, что для выпуклого четырехугольника ABCD справедливо неравенство
$$S_{ABCD} \leq \frac{a^2 + b^2 + c^2 + d^2}{4}, \quad (23)$$
еде $a, b, c, d$—длины его стороны.
Решение. Разобем. Четырехугольник диагонального на два треугольника (рис. 3). Тогда
$$S_{ABCD} = S_{ABC} + S_{ADC}.$$
По формуле (1)
$$S_{ABC} = \frac{1}{2} ab \sin \widehat{B}.$$

Отсюда и из неравенства $ab \geq \frac{a^2 + b^2}{2}$ получаем
$$S_{ABC} \leq \frac{a^2 + b^2}{4}. \quad (24)$$
Аналогично
$$S_{ADC} \leq \frac{c^2 + d^2}{4}. \quad (25)$$
ИЗ (24) и (25) получаем требуемое неравенство.
Если $\widehat{B} = \widehat{D} = 90^\circ$ и $a = b = c = d$, т. е. четырехугольник ABCD—квадрат, то соответствие (23) превращается в равенство.

Постройте многогранник!
(Начало на c. 50)
Многогранник на второй странице обложки получен из этой эпюры несколько более сложным образом: в нем «окружения» вершин 3 и 7 используются по пять раз — из них образован купол модели с вершиной 9. Боковые поверхности тоже получены из эпюры.
Как же строить эпюры? Делается это с помощьюравнерано полуправных многогранников.
Такие многогранники заменяются тем, что все их грани равновравны: для любых двух граней такого многогранника можно указать такое перемещение пространства, при котором многогранник перейдет в себя, а первый грань перейдет во вторую. Возьмем любой такой многогранник и рассмотрим плоскости всех его граней. Зафиксируем одну из этих плоскостей (назовем ее $\Pi$). В ней остальные плоскости «высекается» система прямых линей. Точно такие же системы образуют и в остальных плоскости. Расмотрим теперь многогранную прямую $l$ системы. Она является пересечением плоскости $\Pi$ и плоскости еще одной грани. При повороте, переводящем эту плоскость в плоскость $\Pi$, пряма $l$ перейдет в некоторую прямую $l'$ плоскости $\Pi$. Оказывается, пряма $l'$ получается из прямой $l$ либо поворотом (в плоскости $\Pi$) относительно их общей точки, либо параллельным переносом. Остается на черте точки поворотов с соответствующими джкками и стрелочками для параллельных переносов.
Эпюра на рисунке получена изравнерано полуправных шестидесятейугольника («Квант», 1976, № 1).
Совет. При изготовлении эпюры в большем масштабе воспользоваться тем, что пятуюгольник ABCD правильно.
