⟦folio 29⟧

Используя отрицательные степени числа 2, можно получить аналогичные разложения рациональных чисел вида $\frac{m}{2^k}$, где $m$, $k$ — натуральные числа. Например,

$$\frac{1477}{256} = \frac{1 + 2^2 + 2^8 + 2^7 + 2^8 + 2^{10}}{2^8} = 2^{-8} + 2^{-6} + 2^{-2} + 2^{-1} + 2^0 + 2^2.$$

Никакие другие рациональные числа нельзя представить в виде суммы степени двойки, но, оказывается, такие сумми можно сколь угодно точно приближить любое рациональное число. Действительно, пусть $a$ — рациональное число и $\|a\| = \frac{1}{2^{k_1}}$. Поэтому $a_1 = a - 2^{k_1}$. Тогда $a_1$ близке к нулю, чем $a$ (см. упражнение 1).

Позному либо $a_1 = 0$, либо $\|a_1\| = \frac{1}{2^{k_2}}$, где $k_2 > k_1$. Поляга $a_2 = a_1 - 2^{k_2}$, мы снова получим, что либо $a_2 = 0$, либо $\|a_2\| = \frac{1}{2^{k_3}}$, где $k_3 > k_2$, и так далее. Таким образом, либо некоТОРое число $a_s$ равно нулю, и тогда $a$ является суммой степени двойки: $a = 2^{k_1} + 2^{k_2} + \dots + 2^{k_s}$, либо все $a_s$ отличны от нуля, и тогда сумми вида $2^{k_1} + 2^{k_2} + \dots + 2^{k_s}$ число $a$ приближается сколь угодно точно. В этом случае удобно считать, что $a$ равно бесконечной сумме $a = 2^{k_1} + 2^{k_2} + \dots + 2^{k_s} + \dots$.

Определение. Пусть $x_1, x_2, \dots, x_n$ — последовательность рациональных чисел. Будем говорить, что рациональное число $a$ равно бесконечной сумме $x_1 + x_2 + \dots + x_n + \dots$, если 2-адичное рассмотрение между числом $a$ и конечными сумми $S_n = x_1 + \dots + x_n$ стремится к нулю при $n$, стремящемся к бесконечности, то есть

$$\lim_{n \to \infty} \rho(a, S_n) = 0.$$

У практике, что если $\|q\| < 1$, то бесконечная сумма $a + aq + aq^2 + \dots + aq^n + \dots$ определяна и равна $\frac{a}{1 - q}$.

Мы доказали, что всекое рациональное число можно представить либо в виде конечной суммы $2^{k_1} + 2^{k_2} + \dots + 2^{k_n}$ ($k_1 < k_2 < \dots < k_n$), либо в виде бесконечной суммы $2^{k_1} + 2^{k_2} + \dots + 2^{k_n} + \dots$ ($k_i$ — целые числа, $k_1 < k_2 < \dots$). В обихх случае это представление, которое мы будем называть 2-адичским разложением числа $a$, можно записать в виде $\varepsilon_k 2^k + \varepsilon_{k+1} 2^{k+1} + \dots + \varepsilon_{k+n} 2^{k+n} + \dots$, где $k$ — целое число, а каждое из чисел $\varepsilon_{k+1}, \varepsilon_{k+2}, \dots, \varepsilon_{k+n}, \dots$ равно 0 или 1, причем $\varepsilon_k = 1$. Числа $\varepsilon_k, \varepsilon_{k+1}, \dots$ называются 2-адичскими цифрами числа $\frac{p}{q}$. Нетрудно доказать, что каждое рациональное число имеет одно и только одно 2-адичское разложение.

У практике 8. Докажите, что $-1 = 1 + 2 + 2^2 + 2^3 + \dots + 2^n + \dots$,

$$\frac{1}{6} = 2^{-1} + 1 + 2^2 + 2^4 + \dots + 2^{2n} + \dots$$

В силу упражнения 8 2-адичские цифры — 1 образуют последовательность 1, 1, 1, ..., а 2-адичские цифры числа $\frac{1}{6}$ образуют последовательность 1, 1, 0, 1, 0, 1, 0, 1, ... Обе полученные последовательности перiodичны. Можно показать, что у любого рационального числа $\frac{p}{q}$ последовательность 2-адичских цифр перiodична *).

Для этого рассмотрим последовательность чисел $a_1, a_2, \dots, a_n, \dots$, определяемых равенствами $\frac{p}{q} - \varepsilon_k 2^k = \frac{a_1}{q} 2^{k+1}, \frac{p}{q} - (\varepsilon_k 2^k + \varepsilon_{k+1} 2^{k+1}) = \frac{a_2}{q} 2^{k+2}, \dots,$

$$\frac{p}{q} - (\varepsilon_k 2^k + \varepsilon_{k+1} 2^{k+1}) + \varepsilon_{k+1} 2^{k+1} = \frac{a_2}{q} 2^{k+2}, \dots,$$

$$\frac{p}{q} - (\varepsilon_k 2^k + \varepsilon_{k+1} 2^{k+1}) + \varepsilon_{k+1} 2^{k+1} = \frac{a_2}{q} 2^{k+2}, \dots,$$

$$\frac{p}{q} - (\varepsilon_k 2^k + \varepsilon_{k+1} 2^{k+1}) + \varepsilon_{k+1} 2^{k+1} = \frac{a_2}{q} 2^{k+2}, \dots,$$

Теперь заметим, что 2-адичское разложение числа $\frac{p}{q}$ можно получить из 2-адичского разложения числа $\frac{a_n}{q}$, умножив каждое слагаемое в

*) В том же смысле, в котором периодина десятичная дробь, представляющая рациональное число: периодина, начная с некоторого места.
