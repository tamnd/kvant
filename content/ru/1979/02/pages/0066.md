Поскольку функция $F_1(x) = \frac{1}{2} \sin^2 x$ является первообразной для функции $f$, любая другая perwoобразная для $f$ – в частности, $F_2(x) = -\frac{1}{2} \cos^2 x$, имеет вид $F_1(x) + C$.

Для $F_2$ константа $C$ находится из равенства $-\frac{1}{2} \cos^2 x = \frac{1}{2} \sin^2 x + C$. Подставляя, например, $x = 0$, получаем $C = -\frac{1}{2}$.

Разумеется, верно также, что любая perwoобразная для $f$ имеет вид $F_2(x) + C$. В частности, $F_1(x) = F_2(x) + \frac{1}{2}$.
