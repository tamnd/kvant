Далее, $3^{m+2} \geq 9 \cdot 10^{k-2}$, то есть $3^{m+2} - k$-значное число, то оно обязательно начинается с цифрой 9. (В любом случае $3^{m+3} \geq 27 \cdot 10^{k-1}$ — не $k$-значное число.)

Пусть теперь $3f(n) - k$-значная стеленя троики, начиная сосяя с девятки, то есть

$$9 \cdot 10^{k-1} < 3f(n) < 10^k$$

M503. Набор из 2n+1 чисел $a_0, a_1, a_2, \dots, a_{2n}$ маков, что $a_k \geq \frac{a_{k-1} + a_{k+1}}{2}$ для всех $k=1, 2, \dots, 2n-1$. Доказание неравенство
$$\frac{a_1 + a_3 + a_5 + \dots + a_{2n-1}}{n} \geq \frac{a_0 + a_2 + a_4 + \dots + a_{2n}}{n+1} \quad (*)$$
и выясните, для каких наборов оно превращается в равенство.

Заметим сначала, что если данный набор — арифметическая прогрессия, то все написанные в условии задачи неравенства превращаются в равенства. Ниже мы увидим, что из «выпуклых» наборов (то есть наборов, у которых $a_k \geq \frac{a_{k-1} + a_{k+1}}{2}$ для всех $k=1, 2, \dots, 2n-1$) только для арифметической прогрессии неравенство (*) становится равенством.

Числа произвольного «выпуклого» набора $\{a_k\}$ представим в виде суммы чисел $a_k = b_k + c_k$ двух наборов $\{b_k\}$ и $\{c_k\}$, один из которых — $\{b_k\}$ — арифметическая прогрессия с крайними членами $b_0 = a_0$ и $b_{2n} = a_{2n}$, а другой — $\{c_k\}$ — «выпуклый» набор с нулевыми крайними членами: $c_0 = c_{2n} = 0$.

Поскольку для набора $\{b_k\}$ неравенство (*) превращается в равенство, достаточно доказать его для набора $\{c_k\}$. Но для «выпуклых» наборов с нулевыми крайними членами оно получается неопределенно из условия «выпуклости»: записав, что $c_{2i-1} \geq \frac{c_{2i-2} + c_{2i}}{2}$ для всех $i=1, \dots, n$, и сложив эти неравенства, получим:

$$c_1 + c_3 + \dots + c_{2n-1} \geq \frac{c_0}{2} + c_2 + c_4 + \dots +$$

$$+ c_{2n-2} + \frac{c_{2n}}{2} = c_0 + c_2 + \dots + c_{2n-2} + c_{2n}$$

(мы учли, что $c_0 = c_{2n} = 0$), так что

$$\frac{c_1 + c_3 + \dots + c_{2n-1}}{n} \geq \frac{c_0 + c_2 + \dots + c_{2n}}{n+1}$$

(**)

⟦folio 38⟧

Осталось лишь доказать, что для выпukлы наборов неравенство (*) может быть равенством только для арифметической прогрессии. Для этого достаточно показать, что если $c_k \geq (c_{k-1} + c_{k+1})/2$, то либо все $c_k$, $k = 0, \dots, 2n$, равны нулю, либо все $c_k$, $k = 1, \dots, 2n-1$, поположи и телены (в последнем случае правое неравенство в (**) обязательно строгое).

Выберем наименьшее $c_i$; пусть оно стоит не с краю: $i \neq 0, i \neq 2n$. тогда $c_i \leq c_{i-1}$ и $c_i \leq c_{i+1}$, откуда $c_i \leq \frac{c_{i-1} + c_{i+1}}{2}$. Но по условию $\{c_k\}$ — «выпukлы» набор, значит, $c_i = c_{i-1} = c_{i+1}$. Применив то же рассужение к $c_{i-1}$ (или к $c_{i+1}$), получим, что $c_{i-2} = c_{i-1} = c_i$ (или $c_i = c_{i+1} = c_{i+2}$) и т. д. — до тех пор, пока не дойдем до краев; получим $0 = c_1 = c_2 = \dots = c_{2n-1} = 0$. Поэтому если чисел $c_k$ есть отличные от нуля, то наименьшее общеательное стоит с краю (и равно нуля), так что для $k = 1, \dots, 2n-1$ имеем $c_k > 0$.

Световой поток, душий в единичном телефонном угле, под любым направлением один и тот же. Обозначим через световой поток, душий в единичном телефонном угле и попадающий на единичную площадку линзы или дна под отверстием.

В отсутствие линзы на дно попадают лучи, душие в телефонном угле $\Omega = S_{\text{OTB}}/h^2$ (рис. 8). Следовательно, в этом случае освещенность дня под отверстием равна

$$E_1 = \sigma \Omega = \sigma S_{\text{OTB}}/h^2$$

Линза собрает в своей фокальной плоскости на дне ящика на площадке площадью $s = h^2\omega$ все лучи, душие в телефонном угле $\omega$ (рис. 9). Такие лучи несут световой поток $\Phi = \sigma S_{\text{OTB}}\omega$, так что освещенность изображения неба в этом случае равна

$$E_2 = \Phi/s = \sigma S_{\text{OTB}}/h^2.$$

Мы видим, что $E_1 = E_2$, то есть освещенность дна ящика под отверстием не меняется.

Ф504. Колеса легковых автоматический тщательно моно, имбы ценр масс колеса лежал моно на оси его врачи. Для чего необходимо балансировка колес?

На колесо со стороны дороги действует сила $\vec{N}$. Если колесо сбалансировано, эта сила равна по абсолотной величины 1/4 веса автоматия $M|\vec{g}|^*$ (при езде по гладке).

Если же колесо не сбалансировано, то его центр тяжести движется по окружности радиуса $r$ с центростремительнымускорением $\omega^2 r$ (r — расстояние между центром колеса и центром тяжести, $\omega$ — угловая скорость вращения колеса).
