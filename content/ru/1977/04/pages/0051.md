⟦folio 49⟧

Решение уравнения

Метод отделяющих константы может применяться не только для доказательства нехватки для доказательства нехватки, но и, в некоторых случаях, для решения уравнения, и при этом не приближенного, а точного решения.

Пример 4. Решение уравнения $x^2 - 2x\sin x - 2\cos x + 2 = 0$. (4) Запишем уравнение в виде

$$(x - \sin x)^2 = -(1 - \cos x)^2,$$

то есть в виде $f(x) = g(x)$, где

$$f(x) = (x - \sin x)^2,$$

$$g(x) = -(1 - \cos x)^2.$$

Очевидно, что для любого $x \in \mathbb{R}$ справедливый неравенства $f(x) \geq 0$, $g(x) \leq 0$. Отсюда ясно, что неокторое число $x_0$ только в том случае может удовлетворять равенству $f(x_0) = g(x_0)$, то есть быть корнем уравнения (4), если выполнения равенства $f(x_0) = 0$, $g(x_0) = 0$, то есть если $x_0$ является решением системы

$$\begin{cases} x - \sin x = 0, \\ 1 - \cos x = 0. \end{cases}$$

Второе уравнение этой системы имеет корни $x = 2k\pi (k = 0, \pm 1, \pm 2, \ldots)$, из которых лишь корень $x = 0$ удовлетворяет первому уравнению. Таким образом, исходное уравнение имеет единственный корень $x = 0$.

Пример 5. Решение уравнения

$$x^3 - 2x^2 + x + 1 = \sqrt{\sin \frac{\pi x}{2}}.$$ (5)

Это уравнение можно записать в виде $f(x) = g(x)$, где

$$f(x) = x^2 - 2x^2 + x + 1,$$

$$g(x) = \sqrt{\sin \frac{\pi x}{2}}.$$

Так как $f(x) = 1 + x(x - 1)^2$, то $f(x) \geq 1$ для всех $x \geq 0$. В то же время $g(x) \leq 1$ для всех $x$, принадлежащих области определения функций $g(x)$. Следовательно, на луче $x \geq 0$ число $c = 1$ является отделяющей константой для функции $f(x)$ и $g(x)$. Отсюда вытекает, что неотрицательное число $x_1 = 1$, $x_2 = 0$, из которых только $x_1$ удовлетворяет второму уравнению. Итак, уравнение (5) имеет лишь один неотрицательный корень $x_1 = 1$.

Теперь посмотрим, нет ли отрицательных корней. Так как при $-2 < x < 0$ функция $g(x)$ не определяна, то отрицательные корни надо искать лишь на луче $x \leq -2$. Но при $x \leq -2$ мы имеем $f(x) = 1 + x(x - 1)^2 \leq 1 - 2 \cdot 3^2 = -17$, а $g(x) \geq 0$ по определению функции $\sqrt{x}$. Таким образом, отделяющий для $f(x)$ и $g(x)$ на луче $x \leq -2$ (в тех точках $x$, в которых функция $g(x)$ определяна) является, например, число $c = -10$. Следовательно, рассматривается уравнение не отрицательных корней, то есть $x_1 = 1$ единственный корень уравнения (5).
