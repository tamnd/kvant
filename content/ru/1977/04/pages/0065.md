8. a) Пусть на клетке с номером n (корочие: «клетке n») стоят минус. Тогда на клетках n + a и n + b стоят плосы, поскольку с них можно пойти на клетку n, а на поле n + a + b стоят минус, так как с него можно пойать только на клетки n + a и n + b.
Пусть теперь на клетке n стоят плос. Тогда в соответствии с «золотыми правилами» на поле n — а или на поле n — b стоят минус. Если на n — а стоят минус, то, как доказано, на клетке n — a + (a + b) = n + b также стоят минус, а на клетке n + a + b — плос, так как с нее можно пойать на n + b.
Слушай, когда минус стоят на n — b, разница аналогично.
Итак, расстановка плосов и минусов периодична и полностью определяется расстановкой вертикals a + b знаков.
6) Расстотрим первый a + b клеток. Пусть для определения a < b. Расстановка знаков на первых b полях определяется только ходом на a клеток и потому такова: a минусов, a плосов, a минусов, a плосов...
Поскольку ход на b клеток bleiben с полей с номерами b + 1, ..., a + b ведет на один из первых a минусов, то на этих клетках стоят a плосов. Они едут за a минусами тогда и только тогда, когда b = a (2n + 1) (n — целое).
Итак,лина период равна 2a, если b = a (2n + 1), и равна a + b в противном случае.
9. Как следует из решения задачи 8, количество минусов в начале равно a, а больший ход имеет длину, равную длине перiodа, минус a. Так, на рисунке 7 (в статье) a = 2, b = 7 — 2 = 5.

Но если получается b = a, то есть периодность сводится к чередованию a минусов и a плосов, то меньший ход равен именно a, а про больший можно сказать лишь, что он равен a (2n + 1), где n — натуральное число.

10. Пусть n — наиболее длинная хода. Тогда для того, чтобы отметить поле плосом или минусом, достаточно знать знаки лишь на предыдущих n полях. Разобъем полоску на последовательные группы по n клеток. По принципу Дирихле (см. «Квант», 1977, № 2, с. 17) расстановка знаков в каких-то двух группах совпадает. Пусть эти две группы начинаются с клеток k и p соответственно, причем k < p. Тогда расстановка знаков на клетках k, k + 1, ..., p — 1 совпадает с расстановкой на клетках p, p + 1, ..., p + (p — k — 1) и так далее. Другими словами, имеется период длины p — k, начинающийся с клетки k.
