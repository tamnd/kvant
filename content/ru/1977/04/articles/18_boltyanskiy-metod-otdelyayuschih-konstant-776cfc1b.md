В большинстве случаев в практику письменных экзаменационных работ для поступающих вузы вошли задачи, решение которых удобно начиная с нахождения множества значений, принимаемых некоторыми функциями. Иного решения задачи на этом и заканчивается из полученных результатов сразу следует ответ; в других случаях значение множества значений функций резко сокращает объем работы, указывает кратчайший путь к ответу.

О некоторых особенностей применения этого метода и расссказывается в настоящей статье.

Доказательство неравенства
Начнем со следующей задачи.

Пример 1. Доказать неравенство
$$x^2 - 2x \geq -3 + \sin x.$$ (1)

Для решения достаточно заметить что луч [−1;∞], представляющий собой множество значений функций
$$f(x) = x^2 - 2x = (x - 1)^2 - 1,
$$ не пересекается с множеством значений функций
$$g(x) = -3 + \sin x,
$$ то есть с отрезком [−4; −2].

Можно сказать и иначе: суцестиум макое число c (например, c = −3/2), что для всех x ∈ R справедливо $$f(x) > c, c > g(x)$$ (рис. 1), открывающий все только неравенства (1), но и более сильного: $$f(x) > g(y)$$ для любых x, y ∈ R, то есть всегда
$$x^2 - 2x > -3 + \sin y.$$

В более сложных примерах уже не удается найти константу c, «отделяющийую» значения функции f(x) от значений функции g(x) на всей области их задания, но можно разбит числовую прямую на несколько промежутков, на каждом из которых существует свой отделяющий константа.

Пример 2. Доказать неравенство
$$\arctg x > 4\sqrt{3}x - x^2 - 11.$$ (2)

Таким образом, $f(x) > c_2 > g(x)$ при $x \geqslant \sqrt{3}$, то есть и при этих значениях $x$ неравенство (2) справедливо.

Рассмотренный примем доказательства неравенств во все следует считать каким-то изысканным, случайным, редкоприименным. Например, для непрерывных функций этот примем можно считать универсальным. В самом деле, пусть, например, непрерывные функции $f(x)$ и $g(x)$ заданы на отрезке $[a; b]$, причем прикинув вид этих графиков, мы обнажаем, что вроде бы на всем этом отрезке справедливо неравенство $f(x) > g(x)$. Как можно было бы доказать справедливо этого неравенства?

Если для всех $x \in [a; b]$ справедливо неравенство $f(x) > g(x)$, то графики функции $f(x)$ и $g(x)$ не имеют общих точек, и потому можно* проводить «ступенчатую ломаную» (рис. 3), отделяющий график функции $y = f(x)$ от графика функции $y = g(x)$. Но это и означает, что отрезок $[a; b]$ можно разбить на несколько меньших отрезков, на каждом из которых существует отдельной константа $c_i$.

Разумеется, в этом рассужdenении реш旦 лишь о принципальном возникновении доказательства неравенств $f(x) > g(x)$ методом отдельной константы. В каждом же конкретном случае искусство применения этого приема состоит в том, чтобы найти подходящие разбиение отрезка $[a; b]$ на части и для каждой из этих частей указывать соответствующую отделю константу.

**Итерации**

В обшем случае затруднительно дать рекомендации, как подобрать разбиение на части и соответствующие отдельные константы. Однако в некоторых случаях рекомендации предложить можно.

Пусть, например, обе функции $f(x)$, $g(x)$ — возрастащие (или обеубывающие), причем $f(a) > g(a)$. Проведем прямую $y = f(a)$ (рис. 4) и рассмотрим точку ее пересечения с графиком функции $y = g(x)$. Абсциссу этой точки обозначаем через $x_1$. На отрезке $[a; x_1]$ за отдельную константу можно принять число $c_1 = f(a)$. Действительно, на всем этом отрезке выполнен неравенства $f(x) \geqslant c_1$, $g(x) \leqslant c_1$, причем первое неравенство обращается в равенство лишь в левом конце отрезка $[a; x_1]$, а второе — лишь в правом. Решение уравнения

Метод отделяющих константы может применяться не только для доказательства нехватки для доказательства нехватки, но и, в некоторых случаях, для решения уравнения, и при этом не приближенного, а точного решения.

Пример 4. Решение уравнения $x^2 - 2x\sin x - 2\cos x + 2 = 0$. (4) Запишем уравнение в виде

$$(x - \sin x)^2 = -(1 - \cos x)^2,$$

то есть в виде $f(x) = g(x)$, где

$$f(x) = (x - \sin x)^2,$$

$$g(x) = -(1 - \cos x)^2.$$

Очевидно, что для любого $x \in \mathbb{R}$ справедливый неравенства $f(x) \geq 0$, $g(x) \leq 0$. Отсюда ясно, что неокторое число $x_0$ только в том случае может удовлетворять равенству $f(x_0) = g(x_0)$, то есть быть корнем уравнения (4), если выполнения равенства $f(x_0) = 0$, $g(x_0) = 0$, то есть если $x_0$ является решением системы

$$\begin{cases} x - \sin x = 0, \\ 1 - \cos x = 0. \end{cases}$$

Второе уравнение этой системы имеет корни $x = 2k\pi (k = 0, \pm 1, \pm 2, \ldots)$, из которых лишь корень $x = 0$ удовлетворяет первому уравнению. Таким образом, исходное уравнение имеет единственный корень $x = 0$.

Пример 5. Решение уравнения

$$x^3 - 2x^2 + x + 1 = \sqrt{\sin \frac{\pi x}{2}}.$$ (5)

Это уравнение можно записать в виде $f(x) = g(x)$, где

$$f(x) = x^2 - 2x^2 + x + 1,$$

$$g(x) = \sqrt{\sin \frac{\pi x}{2}}.$$

Так как $f(x) = 1 + x(x - 1)^2$, то $f(x) \geq 1$ для всех $x \geq 0$. В то же время $g(x) \leq 1$ для всех $x$, принадлежащих области определения функций $g(x)$. Следовательно, на луче $x \geq 0$ число $c = 1$ является отделяющей константой для функции $f(x)$ и $g(x)$. Отсюда вытекает, что неотрицательное число $x_1 = 1$, $x_2 = 0$, из которых только $x_1$ удовлетворяет второму уравнению. Итак, уравнение (5) имеет лишь один неотрицательный корень $x_1 = 1$.

Теперь посмотрим, нет ли отрицательных корней. Так как при $-2 < x < 0$ функция $g(x)$ не определяна, то отрицательные корни надо искать лишь на луче $x \leq -2$. Но при $x \leq -2$ мы имеем $f(x) = 1 + x(x - 1)^2 \leq 1 - 2 \cdot 3^2 = -17$, а $g(x) \geq 0$ по определению функции $\sqrt{x}$. Таким образом, отделяющий для $f(x)$ и $g(x)$ на луче $x \leq -2$ (в тех точках $x$, в которых функция $g(x)$ определяна) является, например, число $c = -10$. Следовательно, рассматривается уравнение не отрицательных корней, то есть $x_1 = 1$ единственный корень уравнения (5).
