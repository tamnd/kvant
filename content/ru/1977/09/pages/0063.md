IX—1. Для того чтобы соответствие между конечными множествами X и Y, заданное с помощью стрелок, являлось функцией с области определения X, необходимого и достаточно, чтобы из каждой области X выходила одна и только одна стрелка. Значит, число стрелок должны равнять числу элементов множества X; в данном случае, когда x = {x₁, x₂, x₃}, число стрелок может быть от 0 до 3 (соответствие с 0 стрелками есть функция с пустой области определения).

IX—3. x²−y²=0 ⇒ x−y=0 или x+y=0, поэтому исходное уравнение задает обведенное прямых y = x и y = −x.
