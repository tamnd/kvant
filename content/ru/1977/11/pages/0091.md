⟦folio 89⟧

Длина вектора $\vec{a} = (x; y; z)$
$$|\vec{a}| = \sqrt{x^2 + y^2 + z^2}$$

Расстояние между точками $A(x_1; y_1; z_1)$ и $B(x_2; y_2; z_2)$
$$|AB| = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2 + (z_2 - z_1)^2}$$

Угол между векторами $\vec{a} = (x_1; y_1; z_1)$ и $\vec{b} = (x_2; y_2; z_2)$
$$\cos(\vec{a}, \vec{b}) = \frac{\vec{a} \cdot \vec{b}}{|\vec{a}| \cdot |\vec{b}|} = \frac{x_1x_2 + y_1y_2 + z_1z_2}{\sqrt{x_1^2 + y_1^2 + z_1^2} \sqrt{x_2^2 + y_2^2 + z_2^2}}$$

Формулы гомотетии с центром $O(0; 0; 0)$ и коэффициентом $k$, $M(x; y; z)$
$$H_O^k(M) = M_1(kx; ky, kz)$$

Уравнение плоскости
$$ax + by + cz + d = 0$$

открытие содержат точку $O(0; 0; 0)$ при
$$ax + by + cz + d > 0 \quad d > 0$$
$$ax + by + cz + d < 0 \quad d < 0$$

замкнутые
$$ax + by + cz + d \geq 0 \quad d \geq 0$$
$$ax + by + cz + d \leq 0 \quad d \leq 0$$

Вектор, перpendикулярный плоскости $\alpha: ax + by + cz + d = 0$
$$\vec{n}_\alpha = (a; b; c)$$

Уравнение плоскости, содержащей точку $A(x_1; y_1; z_1)$ и перpendикулярной вектору $\vec{n} = (a; b; c)$
$$a(x - x_1) + b(y - y_1) + c(z - z_1) = 0$$

Угол между плоскостями $\alpha: a_1x + b_1y + c_1z + d_1 = 0$, $\beta: a_2x + b_2y + c_2z + d_2 = 0$
$$\vec{n}_\alpha = (a_1; b_1; c_1), \vec{n}_\beta = (a_2; b_2; c_2)$$

Площадь $S_{\pi p}$ ortogonalной проекции на плоскость $\beta$ многоугольника площади $S$, лежащого в плоскости $\alpha$
$$S_{\pi p} = S \cdot \cos(\alpha, \beta)$$

Уравнение сферы радиуса $R$ с центром в точке $S(a; b; c)$
$$(x - a)^2 + (y - b)^2 + (z - c)^2 = R^2$$

Уравнение плоскости, касающей сферы $(x - a)^2 + (y - b)^2 + (z - c)^2 = R^2$ в точке $A(m; p; q)$
$$(m - a)(x - a) + (p - b)(y - b) + (q - c)(z - c) = R^2$$
$$(a - m)(x - m) + (b - p)(y - p) + (c - q)(z - q) = 0.$$
