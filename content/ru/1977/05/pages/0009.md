$$\lim_{\Delta x \to 0} \frac{\Delta S(x)}{\Delta x} = f(x),$$

т. е.

$$S'(x) = f(x).$$

Доказанное равенство позволяет вычислить площадь функции $F$. Пусть $\varphi$ — какая-нибудь первогообразная для функции $f$. Так как $S$ — также первогообразная для этой функции, то $\varphi$ и $S$ отличаются на константу, т. е. существует такое число $c$, что $\varphi(x) = S(x) + c$ для любого $x \in [a, b]$.

Следовательно,

$$\varphi(b) - \varphi(a) = (S(b) + c) - (S(a) + c) = S(b) - S(a) = S(F)$$

(поскольку $S(a) = 0$, а $S(b)$ есть площадь всей функции $F$). Итак, если $\varphi$ — какая-нибудь первогообразная для функции $f$, то разность $\varphi(b) - \varphi(a)$ равна площади функции $F$, т. е. $S(F) = \int_a^b f(x) dx$.

Если, например, $F$ представляет собой «криволинейный треугольник», ограниченный параболю $y = x^2$ и прямыми $y = 0$, $x = b$ (рис. 11), то прямая, которая проходит через точку $x$ отрезка $[0, b]$ и параллельна оси ordinат, высечает из этого «треугольника» $F$ отрезок длины $x^2$, т. е. в данном случае $f(x) = x^2$. Для функции $f(x) = x^2$ одной из первообразных является функция $\varphi(x) = \frac{1}{3} x^3$. Следовательно, площадь функции $F$ находится по формуле

$$S(F) = \varphi(b) - \varphi(0) = \frac{1}{3} b^3.$$

Заметим, что, вычитая из площади прямогоугольника $ABCD$ (рис. 12) удовлетворяют площадь «треугольника» $F$, мы получаем площадь сегмента парабола, которая, таким образом, оказывается равной $\frac{4}{3} b^3$. Как видите, с помощью первогообразной оцень просто получается тот результат, который Архимед выводил с помощью сложного расчёжения, основанного на использовании метода исчерпывания *). Сегодняшие школьники знают намного больше того, что было известно великом Архимеду!
