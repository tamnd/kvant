Пример 7. Найти первообразную для функции $f$ можно задать формулой

$$F(x) = \int_a^x f(t) \, dt$$

(«Алгебра и начала анализа 10», п. 102).

В данном случае положим $a = 1$, тогда нам надо вычислить интервал

$$F(x) = \int_1^x \ln t \, dt.$$

Если $x > 1$, то этот интервал равен площади функции, отмещенной красным цветом на рисунке 12. Отразим ее относительно прямой $y = t$; тогда она отображится в функции (рис. 13), ограниченной прямыми $t = 0, t = \ln x$ и графиками функции $y = x$ и $y = e^t$ (функция, обратная к $y = \ln t$). Площадь этой функции по формуле (3) равна

$$\int_0^{\ln x} |e^t - x| \, dt.$$

Поскольку $e^t \leq x$ при $0 \leq t \leq \ln x$, мы получаем

$$F(x) = \int_1^x \ln t \, dt = \int_0^{\ln x} (x - e^t) \, dt = (xt - e^t) \bigg|_0^{\ln x} = x \ln x - x + 1.$$

Общий вид первообразной для функции $f(x) = \ln x$ при $x \geq 1$ таков:

$$F(x) = x(\ln x - 1) + C,$$

где $C$ – произвольная постоянная. Продиференцировав функцию $F$, можно убедиться в том, что она действительное является первообразной для функции $f$, причем и при $x \in ]0; 1]$.

Для этого подсчитаем работу, совершаемую 1 молем газа в цикле Карно.
