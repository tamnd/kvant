Сложив $\varphi(1-x)$ и $\varphi(x)$, получим:

$$\varphi(x) + \varphi(1-x) = \frac{a^{2x+k} + a^{k+1}}{a^{2x} + a} = a^k.$$

Пусть искомая сумма равна $S$. Тогда

$$S = \varphi(0) + \varphi\left(\frac{1}{n}\right) + \ldots + \varphi\left(\frac{n-1}{n}\right) + \varphi(1),$$

$$S = \varphi(1) + \varphi\left(\frac{n-1}{n}\right) + \ldots + \varphi\left(\frac{1}{n}\right) + \varphi(0).$$

Складывая эти два равенства и принимая во внимание, что

$$\varphi(0) + \varphi(1) = \varphi\left(\frac{1}{n}\right) + \varphi\left(\frac{n-1}{n}\right) = \ldots =$$

$$= \varphi(x) + \varphi(1-x) = a^k,$$

получаем

$$2S = (n+1)a^k,$$

то есть $S = \frac{1}{2}(n+1)a^k$.

Итак, ответ в задаче М393 следующий:

$$S = \frac{1}{2}(n+1).$$

Мы сейчас решим только задачу a) (на олимпиде школьникам 9—10 классов предлагалась именно она); решению же задач б) и в) будет посвящена заметка, которую мы опубликуем в одном из ближайших номеров журнала.

Откладывая последовательно векторы $\vec{MN} = \vec{a}, \vec{NP} = \vec{b}, \vec{PQ} = \vec{c}, \vec{QM} = \vec{d}$, мы получим замкнутую ломанную (так как $\vec{a} + \vec{b} + \vec{c} + \vec{d} = 0$). Меняя порядок следования векторов $\vec{a}, \vec{b}, \vec{c}, \vec{d}$, можно получить несколько таких ломанных. Покажем, что среди этих ломанных есть саморесекациюся. Для этого возьмем какую-нибудь из наших ломанных. Если одна из ее вершин, например $Q$, лежит внутри треугольника $MNP$, образованного треями вершинами (рис. 4, а), то отложим вектор $\vec{QQ'} = \vec{MN}$. Так как при этом $\vec{Q}'N = \vec{QM}$, то ломанную $MNPQ$ можно заменить саморесекаюшейся ломаной $NPQQ'$ (рис. 4, б). Если же $MNPQ$ — выпуклая ломанная, то сначала проделаем построение, изобранное на рисунке 5.

Итак, пусть $\vec{MN} = \vec{a}, \vec{NP} = \vec{b}, \vec{PQ} = \vec{c}, \vec{QM} = \vec{d}$, причем отрезки $NP$ и $QM$ имеют общую точку $R$ (рис. 6). Тогда $|MR| + |PR| \geq |PM|, |NR| + |QR| \geq |QN|$, откуда $|MR| + |PR| + |NR| + |QR| \geq |PM| + |QN|$. Но $|PM| = |PQ + QM| = |c + d|,$

$$|QN| = |QM + MN| = |a + d|,$$

а $|MR| + |PR| + |NR| + |QR| = |QM| + |NP| = |b + d|$. Следовательно,

$$|b| + |d| \geq |a + d| + |c + d|.$$
