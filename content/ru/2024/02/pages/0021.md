Мы изложим базовый версию этого метода. Продобнее о метода квадратичного решения читайте в статье [5].

В методе факторизации, обобщаем метод Ферма, подбирается такое число $x$, что $x^2 (\bmod r)$ является квадратом. Однако такое число подобрать тяжело. Ключевым для дальнейшего продвижения является наблюдение, что если взять несколько значений $x^2 (\bmod r)$ для различных $x$, ни одно из которых не является квадратом, то их произведение уже может являться квадратом.

Например, разложим число 1411. Расмотрим квадраты по модулю 1411:

$$38^2 (\bmod 1411) = 33,$$
$$39^2 (\bmod 1411) = 110,$$
$$40^2 (\bmod 1411) = 189,$$
$$41^2 (\bmod 1411) = 270,$$
$$44^2 (\bmod 1411) = 525,$$
$$49^2 (\bmod 1411) = 990.$$

Ни один из полученных результатов не является квадратом, однако результат произведения $33 \times 189 \times 270$ равен $980110 = 990^2$. Значит, $(33 \times 189 \times 270)^2 = 990^2$, отсюда следует, что

$$(33 \times 189 \times 270 - 990) (33 \times 189 \times 270 + 990)$$

- разложение на множители неокоторого кратного 1411 числа. Тогда

$$1411 = \text{НОД}(1411, 33 \times 189 \times 270 - 990) \times \text{НОД}(1411, 33 \times 189 \times 270 + 990).$$

Упражнение. Докажите, что если $r$ делит $x^2 - y^2 = (x - y)(x + y)$, то

$$r = \text{НОД}(r, x - y) \cdot \text{НОД}(r, x + y).$$

Как проверить, есть ли среди данных чисел несколько, произведение которых дает квадрат? Перебирать всевозможные произведения даже в нашем примере слишком трудемко. Используем метод, основанный на разложении на среди множителей:

$$33 = 3^1 \cdot 11^1,$$
$$110 = 2^1 \cdot 5^1 \cdot 11^1,$$
$$189 = 3^3 \cdot 7^1,$$

$$270 = 2^1 \cdot 3^3 \cdot 5^1,$$
$$525 = 3^1 \cdot 5^2 \cdot 7^1,$$
$$990 = 2^1 \cdot 3^2 \cdot 5^1 \cdot 11^1.$$

Заметим, что при умножении чисел складаываются показатели степени простых чисел, входящих в их разложение. Поэтому удобно рассматривать вектор показа-mелей степеней – это вектор, координаты которого суть степении входенной простых чисел. Умножение чисел соответствует сложению векторов показателей. В нашем случае векторы имеют вид

$$\vec{a}_1 = \{0, 1, 0, 0, 1\};$$
$$\vec{a}_2 = \{1, 0, 1, 0, 1\};$$
$$\vec{a}_3 = \{0, 3, 0, 1, 0\};$$
$$\vec{a}_4 = \{1, 3, 1, 0, 0\};$$
$$\vec{a}_5 = \{0, 1, 2, 1, 0\};$$
$$\vec{a}_6 = \{1, 2, 1, 0, 1\}.$$

Произведение чисел будет квадратом тогда и только тогда, когда все степени будут четными. Поскольку нас интересует только четность, будем рассматривать координаты по модулю 2:

$$\vec{a}_1 = \{0, 1, 0, 0, 1\};$$
$$\vec{a}_2 = \{1, 0, 1, 0, 1\};$$
$$\vec{a}_3 = \{0, 1, 0, 1, 0\};$$
$$\vec{a}_4 = \{1, 1, 1, 0, 0\};$$
$$\vec{a}_5 = \{0, 1, 0, 1, 0\};$$
$$\vec{a}_6 = \{1, 0, 1, 0, 1\}.$$

Наша задача – найти линейную комбинацию этих векторов, дающий вектор $\{0, 0, 0, 0, 0\}$, т.е. такие ненулевые $\alpha_1$, ..., $\alpha_6$, что

$$\alpha_1 \vec{a}_1 + \dots + \alpha_6 \vec{a}_6 = \{0, 0, 0, 0, 0\}.$$

Из линейной алгебры известно, что если количество векторов больше, чем количество координат в каждой векторе, то такая зависимость существует. (Вспомните, что на плоскости любые три и более векторы линейно зависитмы, в трехмерном пространстве – четыре и более.) В нашем случае 6
