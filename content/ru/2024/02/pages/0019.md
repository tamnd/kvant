В 1977 году американские математики Р.Ривест, А.Шампир и Л.Адлеман (R.L.Rivest, A.Shamir, L.Adleman) смогли придумать такую функцию, которая стала основой криптоисистемы RSA, называемой по первым буквам фамилий основатель. RSA – криптографический алгоритм с открытым ключом, основанный на вычислительной сложности задачи факторизация (разложения на простые множители) больших чисел, являющихся производением двух простых.

Описем, как процессит шифрование в системе RSA.

Описание криптоисистемы RSA

Будем считать, что исходный текст переведен стандартным образом в целое число $m$. Выберем два достаточно больших простых числа $p$ и $q$ и вычислим произведение $r = pq$. Затем выберем число $e < r$, которое должно быть взаимно простым с $\varphi(r)$. Здесь $\varphi(r) - \varphi(\text{йлера от } r)$, обозначающая количество натуральных чисел, меньше либо равных $r$ и взаимно простых с ним. Поскольку $p$ и $q$ – простые числа, то $\varphi(r) = (p-1)(q-1)$.

Числа $e$ и $r$ являются открытым ключом, т.е. становятся общеодоступными для использования в алгоритме шифрования.

Затем находится число $d$ из условия:

$$de \equiv 1(\bmod \varphi(r)),$$

(*)

т.е. число, обратное к $e$ по модулю $\varphi(r)$. Это делается с помощью алгоритма Евклида и может быть вычислено быстро.

Два простых множителей $p$ и $q$ и число $d$ являются закрытым ключом шифрования.

Число $m < r$ шифруется следующей функцией:

$$E_e(m) = m^e(\bmod r) = c,$$

т.е. для шифрования нужно возвести $m$ в степень $e$ и вычислить остаток от деления на $r$.

Шифрование может быть выполнено очень эффективно даже для огромных значений $r$: для этого требуется менее секунд компьютерного времени.

Обратный алгоритм, использующий для шифрования, состоит в возведении числа зашифрованного текста в степень $d$ по модулю $r$. Дешифрование сообщения $c$ осуществляется функцией

$$D_d(c) = c^d(\bmod r).$$

Дешифрование также занимает меньше секунд компьютерного времени.

Корректность работы метода расшифровки следует из равенств

$$D_d(c) = D_d(E_e(m)) = m^{ed}(\bmod r) = m^{k\varphi(r)}m(\bmod r) = m(\bmod r) = m$$

для некоторого натурального $k$. Здесь требуется равенство следует из (*), а четвертое – из теоремы Эйлера. (Для чисел $m$, не взаимно простых с $r$, необходимо отделить проверку по модулам $p$ и $q$.)

Более подробно все сведения по теории чисел, необходимые для понимания алгоритма RSA, излагаются в книге [4].

Возникает вопрос, насколько надежна система RSA?

Чтобы раскодировать сообщение, нужно знать закрытый ключ $d$. На сегодняший день единственный эфективный способ найти $d$ основан на применении алгоритма Евклида к $e$ и $\varphi(r)$, а для этого нужно знать разложение $r$ на простые множители.

Задча о факторизация числа

Быстрых алгоритмов для решения задачи факторизации do sins пор не известно. Если же он будет найден, то скорее всего будет засекречен.

По оценкам Ривesta, если бы использовался лучший из известных алгоритмов и самый быстрый из современных компьютеров того времени, требуемое время работы составило бы около 40 квадрилонов лет! Именно эта практическая новозможность разложить на множители произведение двух больших простых чисел делает возможность системы шифрования RSA.

Вскоре Ривест понял, что допустил арифметическое ошибку в оценке времени. Тем не менее, учитывая доступные в то время методы разложения чисел на простые числа, на решение данной задачи все разложны были уйти тысячи лет.
