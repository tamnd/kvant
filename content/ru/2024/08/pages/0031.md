О неравенстве
Чебышёва
для сумм
А.АНТРОПОВ

В ЭТОЙ СТАТЬЕ МЫ ВСПОМНИМ
о замечательном неравенстве Чебышёва, поговорим о его разных варианях и трактовках, а также приведем решение задачи М2797 «Заданияка «Кваента» (точнее, почтим, что по сути приведенное в задаче неравенство – частный случай неравенства Чебышёва).

Первое неравенство Чебышёва для сумм.
Пусть данные неотрицательные числа $p_1, p_2, \dots, p_n$ такие, что $p_1 + p_2 + \dots + p_n = 1$, и два упорядоченных набора вещественных чисел $a_1 \leq a_2 \leq \dots \leq a_n$, $b_1 \leq b_2 \leq \dots \leq b_n$. Тогда
$$\left( p_1 a_1 + p_2 a_2 + \dots + p_n a_n \right) \left( p_1 b_1 + p_2 b_2 + \dots + p_n b_n \right) \leq
\leq p_1 a_1 b_1 + p_2 a_2 b_2 + \dots + p_n a_n b_n. \tag{1}$$

«Что?! Это не неравенство Чебышёва!» – может воспользоваться исключением читатель. Действительно, в оптимальном фольклоре неравенством Чебышёва для сумм принято называть следующее неравенство.

Второе неравенство Чебышёва для сумм.
Для упорядоченных наборов $a_1 \leq a_2 \leq \dots \leq a_n$, $b_1 \leq b_2 \leq \dots \leq b_n$ выполено
$$\frac{a_1 + a_2 + \dots + a_n}{n} \cdot \frac{b_1 + b_2 + \dots + b_n}{n} \leq
\leq \frac{a_1 b_1 + a_2 b_2 + \dots a_n b_n}{n}. \tag{2}$$

Легко видеть, что весовое неравенство (1) является обобщением неравенства (2): достаточно положить $p_1 = p_2 = p_3 = \dots = p_n = \frac{1}{n}$.

С другой стороны, следующее упражнение показывает, что в некоторых смысле неравенство (1) можно свести к неравенству (2).

Упражнение 1. Выведите неравенство (1) из неравенства (2), если $p_1, p_2, \dots, p_n$ рациональны.

Указание. Пусть $p_i = m_i / m$, $i = 1, 2, \dots, n$. Расмотите для неравенства (2) набор
$$a_1 = a_1 = \dots = a_1 \leq a_2 = a_2 \leq \dots \leq a_n = a_n,$$
в котором $m_1$ копий $a_1$, $m_2$ копий $a_2$ и т.д.

Прежде чем доказать неравенство (1), покажем, как им воспользоваться для решения задачи M2797.

Сначала сделаем такое общее замечание.

Замечание. Пусть в неравенстве (1) все $a_i \geq 0$ и $b_i \geq 0$. Тогда оно остается верным, если в условиях заменить равенство $p_1 + p_2 + \dots + p_n = 1$ на неравенство $p_1 + p_2 + \dots + p_n \leq 1$.

Действительно, пусть $p = p_1 + p_2 + \dots + p_n \geq 0$ (в случае $p_1 + p_2 + \dots + p_n = 0$ все $p_i$ равны 0 и неравенство очевидно). Положим $q_i = \frac{p_i}{p}$, так что $p_1 + p_2 + \dots + p_n = 1$, запишем неравенство (1) с весами $q_i$ и получим
$$\frac{p_1 a_1 + p_2 a_2 + \dots + p_n a_n}{p} \cdot \frac{p_1 b_1 + p_2 b_2 + \dots + p_n b_n}{p} \leq
\leq \frac{p_1 a_1 b_1 + p_2 a_2 b_2 + \dots + p_n a_n b_n}{p}.$$

Поскольку сумма $p_i a_i b_i$ неотрицательная, а $p \leq 1$, домножение на $p^2$ дает требуемое:
$$\left( p_1 a_1 + p_2 a_2 + \dots + p_n a_n \right) \left( p_1 b_1 + p_2 b_2 + \dots + p_n b_n \right) \leq
\leq p \left( p_1 a_1 b_1 + p_2 a_2 b_2 + \dots + p_n a_n b_n \right) \leq
\leq p_1 a_1 b_1 + p_2 a_2 b_2 + \dots + p_n a_n b_n.$$

Свести случай $p \leq 1$ к $p = 1$ можно и подгрутом – путем ввода дополнительных переменных $a_0 = b_0 = 0$ и дополнительного веса $p_0 = 1 - \left( p_1 + \dots + p_n \right)$.

Теперь положим $p_i = \frac{1}{i(i+1)}$. Как извлечено, $p_1 + p_2 + \dots + p_n < 1$ при любом $n$ (действительно, $p_i = \frac{1}{i} - \frac{1}{i+1}$ и, значит,
$$p_1 + p_2 + \dots + p_n = \left( 1 - \frac{1}{2} \right) + \left( \frac{1}{2} - \frac{1}{3} \right) + \dots + \left( \frac{1}{n} - \frac{1}{n+1} \right) = 1 - \frac{1}{n+1}).$$

Тогда в силу заменяния выше выполнено
$$\left( p_1 a_1 + p_2 a_2 + \dots + p_n a_n \right) \left( p_1 b_1 + p_2 b_2 + \dots + p_n b_n \right) \leq
\leq p_1 a_1 b_1 + p_2 a_2 b_2 + \dots + p_n a_n b_n.$$

Это и есть нужное нам неравенство. Задча М2797 решена.
