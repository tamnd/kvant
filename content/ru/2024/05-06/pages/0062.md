3. А. После переода переключителя в положение 2 за очень короткое время (порядка $\tau_C = rC$) произойдет перезаряда конденсаторов, так что направление на каждом из нихстанет равно $\frac{\varepsilon}{2}$, обкладки конденсаторов, образенные к kleмме 2, будут заряжены отрицательно.
В колбательном процессе в каждой момент времени точки, текущие через батарейки, будут одинаковыми, при этом через катушку будет точок вдвое больший: $I(t) = 2q'$. Запишем уравнение обхода (второе правило Кирхгофа) для конструк, содержащого катушку и одну из батарей:
$$q'' + \frac{q'r}{2L} + \frac{q}{2LC} = \frac{\varepsilon}{2L}$.
Затухание колбаний происходит за время пояда $\frac{L}{r}$, которое значительное перiodа колбаний $\sim \sqrt{LC}$. Таким образом, достаточно рассмотреть уравнение колбаний без затухания
$$q'' + \frac{q}{2LC} = \frac{\varepsilon}{2L}$.
Общее решение этого уравнения имеет вид
$$q(t) = C\varepsilon + q_0 \cos(\omega t + \varphi_0)$,
где $\omega^2 = \frac{1}{2LC}$, параметры $q_0$ и $\varphi_0$ определяются из начальных условий. Ток через катушку равен
$$I(t) = -2\omega q_0 \sin(\omega t + \varphi_0)$.
Для нулевого момента имеем систему уравнения
$$\frac{C\varepsilon}{2} = C\varepsilon + q_0 \cos \varphi_0, \frac{\varepsilon}{R} = -2q_0 \omega \sin \varphi_0$$.
Решая систему, получаем уравнение
$$\omega tg \varphi_0 = \frac{1}{RC}$$
для определения начальной фазы. По условияю $\omega RC = \frac{RC}{\sqrt{2LC}} = 1$, поэтому $\varphi_0 = \frac{\pi}{4}$. Направление пока изменяется в момент времени $t_L$, удовлетворяющий соотношение
$$\omega t_L = \frac{3\pi}{4}$, откуда $t_L = \frac{3\pi}{4\sqrt{2LC}}$$.
Б. Количество теплоты можно найти, используя закон сохранения энергии
$$A_{\varepsilon} = \Delta W_C + \Delta W_L + Q$$.
Когда в цепи установлен стадионарный режим, ток через катушку течь не будет, а конденсаторы будут заряжены до напряжения $\varepsilon$, поэтому изменение энергии конденсаторов
$$\Delta W_C = 2\frac{C\varepsilon^2}{2} - \frac{C\varepsilon^2}{2} = \frac{C\varepsilon^2}{2}$,
а изменение энергии магнитного поля
$$\Delta W_L = -\frac{L\varepsilon^2}{2R^2} = -\frac{C\varepsilon^2}{4}$$.
Одна из батарей перемещает нулевой заряд, другой перемещает заряд $C\varepsilon$, поэтому суммарная работа $\exists\Delta C$
$$A_{\varepsilon} = C\varepsilon^2$$.
Таким образом,
$$Q = A_{\varepsilon} - \Delta W_C - \Delta W_L = \frac{3C\varepsilon^2}{4}$$.
