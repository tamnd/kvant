Видно, что число $a^2$ довольно больше уже для небольших $a$. Тепер дело за малым. Соберем вместе разложенные по одной в разных коробках монетки, после чего примем два раза действие $(a, 0, 0, 0) \rightarrow (0, a^2, 0, 0)$:
$$(1, 1, 1, 1, 1) \rightarrow (1, 1, 1, 1, 0, 3) \rightarrow (1, 1, 1, 0, 3, 0) \rightarrow$
$\rightarrow (1, 1, 0, 3, 0, 0) \rightarrow (1, 0, 3, 0, 0, 0) \rightarrow$
$\rightarrow (0, 3, 0, 0, 0, 0) \rightarrow (0, 0, 3^2, 2, 0, 0, 0) =$
$= (0, 0, 16, 0, 0, 0) \rightarrow (0, 0, 0, 16^2, 2, 0, 0)$.

Оценим, насоклько велико число $^{16}2$. Оказывается, оно гораздо больше требуемого в задаче числа $2010^{2010^{2010}}$. Для доказательства достаточно весма грубых оценок:
$$^{16}2 > 2^{2^{15}} = 2^{2^{24} \cdot 2^{11}} > 2^{2^{11} \cdot 2011} =$
$$= 2^{(2^{11})^{2011}} > 2^{2010^{2011}} > 2^{11 \cdot 2010^{2010}} =$
$$= (2^{11})^{2010^{2010}} > 2010^{2010^{2010}}.$$

Остается последний шаг - уменьшить число монет $^{16}2$ в четвертой коробке до требуемого количества $N = 2010^{2010^{2010}}$. Воспользовемся тем, что $N$ делится на 4. Так же отметим, что можно сделать следующие: $(a, 0) \rightarrow (0, 2a)$. Для этого нужно сделать $a$ раз первое действие. Тепер продолжаем следующие действия (будем писать только число монет в 4-6 коробках, так как 1-3 коробки будут все время пусть):
$^{16}2, 0, 0) \rightarrow (^{16}2 - 1, 0, 0) \rightarrow (^{16}2 - 2, 0, 0) \rightarrow \dots$
$\dots \rightarrow (N/4, 0, 0) \rightarrow (0, N/2, 0) \rightarrow (0, 0, N)$. Задча решения.

Можно ли уйти в бесконечность?

Удивительно, как из достаточно маленького числа монет (изначально их было всего 6) столбцы операции можно получить как минимум $^{16}2$ монет! Чтобы получить представление, насоклько огромно это число, отметим, что уже $^{5}2$ содержит в десятичной записи почти 20 тысяч цифр! Возникает естественный вопрос, возможно ли получить сколь угодно много монет в одной из коробок, или же количество монет ограничено сверху каким-то числом?

Сначала докажем, что при любом изначальном числе коробок и любом расположении монет в них невозможно проделывать разрешенные в задание действия сколь угодно долго. Пусть имеется $n$ коробок. Будем обозначать ситуацию, получающие по ходу наших действия, в виде упорядоченной последовательности длины $n$ целых неотрицательных чисел: $(a_1, \dots, a_n)$ ($a_i$ обозначает количество монет в $i$-й коробке).

Рассмотрим порядок на таких последовательности, называемый лексикографическим. Это совершенство естественный порядок на словах (t.e. последовательности букв некоторого алфавита), именно так упорядочивают слова в словарях и справочниках, чтобы нужно слова было легко найти. Номним, что это за порядок. Для того чтобы сравнить последовательности $(a_1, \dots, a_n)$ и $(b_1, \dots, b_n)$, сначала нужно сравнить $a_1$ и $b_1$ (просто как числа). Если $a_1 < b_1$, то первый последовательность меньше второй, если $a_1 > b_1$, то первый последовательность больше второй. Если $a_1 = b_1$, то нужно сравнить $a_2$ и $b_2$ и т.д. Формально, $(a_1, \dots, a_n) < (b_1, \dots, b_n)$,

если найдется такое $k$, что
$$\begin{cases} a_1 = b_1, \\ a_2 = b_2, \\ \dots \\ a_k = b_k, \\ a_{k+1} < b_{k+1}. \end{cases}$$

Отметим, что в нашем определении сравнить можно только последовательности одинаковой длины, в отличие от естественного лексикографического порядка на словах. Сравнивать последовательности различных следовало бы так: $(a_1, \dots, a_n) < (b_1, \dots, b_m)$, если либо найдется такое $k$, что выполена предыдущая система, либо $(a_1, \dots, a_n)$ является началом последовательности $(b_1, \dots, b_m)$.
