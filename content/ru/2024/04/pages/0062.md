5. В начальной момент времени напряжение между точками $A$ и $B$ равно нулю. Поэтому токи, протекающие через элементы цепи, в том числе предохранители, заведом меньше $I_\Pi$. Поскольку сопротивление предохранителей пребрежимо мало, через сопротивления $R_1$ и $R_2$, подключенные параллельно к $\Pi_1$, токи не протекают. Схема, эквивалентная исходной, представлена на рисунке 21,a. Общее сопротивление участка $AB$ равно $R/3$. При этом ток $I$, протекающий через предохранитель $\Pi_1$, будет определенся выражением $I = \frac{U_{AB}}{R/3} = \frac{3U(t)}{R} = \frac{3at}{R}$. Распределение токов в системе показано на рисунке 21,б. Ток $I$ достигает номинального значения на $\Pi_1$ в момент времени
$t_1 = \frac{I_\Pi R}{3a} = 4$ мин.

При этом предохранитель $\Pi_1$ перегорает, а эквивалентная схема принимает вид, изображенный на рисунке 21,в. Общее сопротивление $R^*_{AB}$ участвака $AB$ в данном случае будет равно $R^*_{AB} = \frac{R}{2} + \frac{R}{3} = \frac{5R}{6}$. Ток, протекающий через сопротивление, равен $I^* = \frac{U_{AB}}{R^*_{AB}} = \frac{6a(\tau + t_1)}{5R}$, где $\tau$ – время, отсутстваемое от момента перегорания $\Pi_1$. В силу симметрии схемы, $I_{AD} = I_{AC} = \frac{I^*}{2}$, $I_{DB} = \frac{2I^*}{3}$, $I_{CB} = \frac{I^*}{3}$. Тогда ток $I_{CD}$, протекающий через предохранитель $\Pi_2$, будет равен $I_{CD} = I_{AC} - I_{CB} = \frac{I^*}{6} = \frac{a(\tau + t_1)}{5R}$. Ток через $\Pi_2$ становится номинальнымому значению спустя время $\tau$ после перегорания $\Pi_1$, равное
$\tau = \frac{5I_\Pi R}{a} - t_1 = \frac{14I_\Pi R}{3a} = 56$ мин.

Общее время работы предохранителя $\Pi_2$ равно
$t_2 = \tau + t_1 = 60$ мин.
