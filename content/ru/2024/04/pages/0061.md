1. Запишем уравнения кinemатики для участков пути, прошедных за время $t_1$ и $t_1 + t_2$:
$$s = v_0 t_1 - \frac{g t_1^2}{2}, 2s = v_0 \left( t_1 + t_2 \right) - \frac{g \left( t_1 + t_2 \right)^2}{2},$$
где $s$ – длина двух одинаковых участков, $v_0$ – начальная скорость камня. Решая эти уравнения, получим
$$v_0 = \frac{2g t_1^2 - g \left( t_1 + t_2 \right)^2}{2 \left( t_1 - t_2 \right)}.$$

Тогда полное время полета до соударения с землей равно
$$t_{\text{пол}} = \frac{2 t_1^2 - \left( t_1 + t_2 \right)^2}{t_1 - t_2} = 7\text{с}.$$

2. Площадь правильного шестиугольника определяется формулой $S_{\text{ш}} = \frac{3\sqrt{3}}{2} a^2$, где $a$ – сторона шестиугольника. Объем прямой прізмы $V = \frac{3\sqrt{3}}{2} a^2 h$, где $h$ – высота прізмы. Давление, оказываемое основанием прізмы, будет определяться соотношение $p_1 = \frac{mg}{S_{\text{ш}}} = \frac{2mg}{3\sqrt{3} a^2}$. Отсюда найдем сторону шестиугольника: $a = \sqrt{\frac{2mg}{3\sqrt{3} p_1}}$.

Давление, оказываемое боковой гранью прізмы, определяется соотношение $p_2 = \frac{mg}{ah}$, откуда найдем высоту прізмы: $h = \sqrt{\frac{3\sqrt{3}}{2} m g p_1} \frac{1}{p_2}$. Теперь найдем плотность материалов прізмы:
$$\rho = \frac{m}{V} = \frac{m}{S_{\text{ш}} h} = \sqrt{\frac{2 p_1}{3\sqrt{3} m g}} \frac{p_2}{g} = 8160 \text{ кг/м}^3.$$

3. Количество теплоты, отданное кипятком при его охлаждении до конечной температуры: $Q_{\text{отд}} = c_B m_B \left( t_B - t_K \right)$. Количество теплоты, полученное ложкой, чашкой и заваркой при их нагревании до конечной температуры:
$$Q_{\text{пол}} = c_\phi m_\phi \left( t_K - t_\phi \right) + c_c m_c \left( t_K - t_1 \right) + c_B m_3 \left( t_K - t_1 \right).$$
Запишем уравнение теплового баланса $Q_{\text{отд}} = Q_{\text{пол}}$:
$$c_B m_B \left( t_B - t_K \right) = c_\phi m_\phi \left( t_K - t_\phi \right) + c_c m_c \left( t_K - t_1 \right) + c_B m_3 \left( t_K - t_1 \right).$$
Отсюда находится
$$m_\phi = \frac{c_B m_B \left( t_B - t_K \right) - c_c m_c \left( t_K - t_1 \right) - c_B m_3 \left( t_K - t_1 \right)}{c_\phi \left( t_K - t_\phi \right)} = 0,2 \text{ кг}.$$
