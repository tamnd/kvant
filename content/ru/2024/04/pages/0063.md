Учитывая неевесомость нитей, а также симметрию системы, можно сделать вывод о том, что силы натяжения нитей, на которых подвешен шарик $M$, равны друг другу по модулю (рис. 23,a): $|\vec{T}_O| = |\vec{T}_{O1}| = |\vec{T}_B| = |\vec{T}_{B1}| = T_1$. Записав второй закон Ньютона для шарика в проекции на ось $y$, получим $Mg = 2T_1 \cos \alpha$, открываем момент относительно оси, прохождение через точку $O$, примет вид $T_A \frac{L}{4} = mg \frac{L}{4} + T_1 \frac{3L}{4} \sin 2\alpha$, или $T_A = mg + 3Mg \sin 2\alpha$, где $L$ - длина стержня $AB$.

После пережигания нити шарик будет дивигаться по дуге окружности с центром в точке $B$ и радиусом $\frac{3L}{4}$. Сила натяжения нити, прикрепленной к шарику, будет максимальная при его прохождения точки $E$, когда нить займет вертикальное положение (рис. 23,б). Скорость $v$ шарика в точке $E$ может быть найдена из закона сохранения полной механической энергии:
$$\frac{Mv^2}{2} = Mg \frac{3L}{4} (1 - \cos \alpha),$$
откуда $v = \sqrt{\frac{3}{2} gL(1 - \cos \alpha)}$.

Значение $T_2 = T_{B2}$ может быть получено из второго закона Ньютона, записанного в проекции на

$$\text{osc } y: \frac{Mv^2}{3L/4} = T_2 - Mg, \text{откуда}$$

$$T_2 = \frac{4M}{3L} \frac{3}{2} gL (1 - \cos \alpha) + Mg = Mg (3 - 2 \cos \alpha).$$

Мoment силы натяжения $T_2$ относительно оси $O$ в этом случае также будет максимальным. Поэтому будет максимальным и сила натяжения нити, прикрепленной к точке $A$ стержня, которая может быть найдена из уравнения для моментов сил, относительно точки оси: $T_{Amax} \frac{L}{4} = mg \frac{L}{4} + T_2 \frac{3L}{4}$. С учетом полученного выше выражения для $T_2$ имеем $T_{Amax} = mg + 3Mg (3 - 2 \cos \alpha)$. Таким образом, искомое относение равно
$$\frac{T_{Amax}}{T_A} = \frac{mg + 3Mg (3 - 2 \cos \alpha)}{mg + 3Mg \sin \alpha} = \frac{1 + 18 (3 - \sqrt{3})}{10} \approx 2.4.$$

3. Из условия задачи ясно, что сначала газ изобарно сжимается. Здесь он отдает количество теплоты. Затем газ изохорно нагревается, где он получает количество теплоты. По первому закону термодинамики найдем количество теплоты, отданное газом в изобарном процессе:
$$Q_p = \Delta U_p + A_p = \frac{5}{2} vR (T_{min} - T_H),$$
где $v$ - количество вещества газа, $T_H$ - начальная температура газа. Данное количество теплоты является отрицательной величины. Теперь найдем количество теплоты, полученное газом в изохорном процессе:
$$Q_V = \Delta U_V = \frac{3}{2} vR (T_K - T_{min}),$$
где $T_K$ - конечная температура газа. Общее подводимое количество теплоты равно внешних сил при адвабатическом процессе равен
$$A_{ad} = A = \frac{3}{2} vR (T_K - T_H).$$

С помощью уравнения Менделеева-Клапейрона для двух состояний газа получаем
$$p_H V_H = vRT_H, p_H V_K = vRT_{min},$$ откуда $\frac{V_H}{V_K} = \frac{T_H}{T_{min}}$.

Объедининая записанные уравнения и учитывая, что $\frac{V_H}{V_K} = 10$, находим
$$Q = A - 9vRT_{min} = 10 \text{ кДж.}$$
