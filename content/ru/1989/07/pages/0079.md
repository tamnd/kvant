Этиоды о полупивариante

1. Соедините красные точки с синмии $N$ отрезками произвольным образом и к двум пересекающим отрезкам примените операцию, описную в стате в задание 3 так, чтобы два новых отрезка также соединили красные и синние точки.

2. Раскрасьте точки в четыре цвета произвольным образом. Если отрезков с однозвездными концами больше $N$, то из каждой-то точки выходит не менее трех таких отрезков. Эту точку можно перекрасить так, чтобы количество отрезков с однозвездными концами уменьшилось.

3. В качестве полупиварианта рассмотрите количество отрезков с концами одного цвета.

4. Не могут. В качестве полупиварианта рассмотрите разность между наиболее положительное число среди написанных на доске, а через $n$ — количество нулей на доске.

5. В качестве полупиварианта рассмотрите сумму всех чисел на окружности.

6. 1/512. В качестве полупиварианта рассмотрите величины $m/2^n$, где через $m$ обозначает наименьшее положительное число среди написанных на доске, а через $n$ — количество нулей на доске.

7. Заключим всего совокупность черных клеток в большой прямогольник и введем прямогольную систему координат с началом в левом нижнем углу этого прямогольника. Для каждой черной клетки вычислим сумму ее координат. В качестве полупиварианта рассмотрите максимальное значение чисел.

8. Заметим, что минимальное число конфет у одного человека в процессе игры не уменьшается, а максимальное может увеличиться не более чем на единицу, если оно нечетно, и не может увеличиться, если оно четно. Если исходный максимум был равен $M_0$, то в любой момент сумма чисел на окружности не превыходит $(M_0 + 1)n$, где $n$ — число участков игры. Поэтому, начиная с какого-то момента, ведущий перестанов добавлять конфеты, а это значит, что, начиная с этого момента, все числа будутчетны. Тепер в качестве полупиварианта рассмотрите величины $S = nM + k$, где $M$ — максимальное число конфет у одного игрока, а $k$ — количество игроков $M$ конфиетами.

9. В качестве полупиварианта рассмотрите величины $a_1^2 + a_2^2 + \dots + a_n^2$, где $a_1, a_2, \dots, a_n$ — номера комнаты, в которых живут панисты в данной момент. Докажите, что эта величина монотно возвращает и ограничена сверху (на самом деле каждое из чисел $a_1, a_2, \dots, a_n$ может принимать лишь конечное число значений).

10. Назовем в данной расстановке том «правым», если он стоит права от своего настоящего места, и «левым», если он стоит слева от своего настоящего места. С каждым «левым» томом с номером $k$ связем число $2^k$, а с каждым «правым» томом с номером $k$ связем число $2^{n+1-k}$. В качестве полупиварианта рассмотрите сумму всех этих чисел. Другое решение этой задачи может быть основано на использовании в качестве полупиварианта величины $\Sigma |a_k - k|$, где $a_k$ — номер места, на котором стоит $k$-ый том.

Matематические описания ФРГ

1. Пусть $x, y$ и $z$ — число ходов 1-го, 2-го и 3-го вида соответствующего. Тогда должны выполнять сравнение $x + y + z = n^2 - 1$, $z = x$ и $z + 1 = y$. Складывая их, получаем $3z + 2 = n^2$. Но квадрат целого числа при делении на 3 не может давать остаток 2.

2. Рассмотрим функцию $f(n) = [n + \sqrt{n} + 0, 5]$ и доказем, что $f(k^2 + z) = k^2 + k + z$ при $-k + 1 \leq z \leq k$. Так как $-k + 1 \leq z \leq k$, то $-k + 1 + 0, 25 < z < k + 0, 25$, а значит, $k^2 - k + 0, 25 < k^2 + z < k^2 + k + 0, 25$, т. е. $k - 0, 5 < \sqrt{k^2 + z} < k + 0, 5$.

3. Пусть $z_1 = m + \alpha$ и $z_2 = m + \alpha + 10^{-n}$, где $m$ — целое число. При достаточно большом $m$ число $z_2^2 - z_1^2 = 10^{-n}(2m + 2\alpha + 10^{-n})$ больше 1, поэтому найдется натуральное число $N$, заключенное между $z_1^2$ и $z_2^2$. Ясно, что $m + \alpha < \sqrt{N} < m + \alpha + 10^{-n}$.

4. Оно из положений — параллелограмм, если $a - c = b - d = 0$; трапеця с $b \parallel d$, если $|b - d| > |a - c|$; трапеця с $a \parallel c$, если $|b - d| < |a - c|$.

5. Пусть $a, b, c, d$ — длины последовательных сторон четырехугольника. Так как диагонали перpendикularны, то $a^2 + c^2 = b^2 + d^2$, а так как четырехугольник описанный, то $a + c = b + d$. Если $a = b$, то $c = d$, а если $a \neq b$, то $a + b = c + d$ и $a + c = b + d$, т. е. $a = d$ и $b = c$. Учитывая, что четырехугольник описан в окружность, получаем, что одна из диагоналей — диаметр этой окружности.

6. а) Пусть $a = (x_1 + x_2)/2$ и $b = \sqrt{x_1 x_2}$. Так как $a = nb$, то число вращального, а значит, оно натуральное. Числа $x_1$ и $x_2$ удовлетворяют уравнению $x^2 - 2ax + b = 0$, поэтому они равны $a \pm \sqrt{D}$, где $D = 4a^2 - 4b^2 = 4b^2(n^2 - 1)$. Число $D$ является полным квадратом, только если $n = 1$, т. е. $D = 0$ и $x_1 = x_2$.

6) Пусть $x_1 = (2n - 1)^2n$, $x_2 = \dots = x_{2n} = 1$. Отношение среднего арифметического этих чисел к их среднему геометрическому равно $(1 + (2n - 1)^2n - 1)/2n$. Это число целое, так как для любых чисел $a$ и $b$ справедливо равно $a^2n - 1 + b^2n - 1 = (a + b)(a^2n - 2 - a^2n - 3b + a^2n - 4b^2 - \dots + b^2n - 2)$.

7. Так как $2^n - 1 = 2^k(2^{n-k} - 1) + 2^k - 1$, то число $2^n - 1$ при делении на $2^k$ где $k < n$, дает остаток $2^k - 1$. А остаток от деления $2^n$ на любое другое число на 1 больше остатка от деления $2^n - 1$ на это число. Натуральных чисел, меньше $2^n$ и не делитель $2^n$, равно $2^n - 1 - n$. Поэтому $r(2^n) - r(2^{n-1}) = 2^n - 1 - n - \sum_{i=0}^{n-1} (2^i - 1) = 2^n - 1 - n - (2^n - 1) + n = 0$.

8. Пусть прямая $AA_1$ пересекает $C_1B_1$ в точке $P$, а прямая, проходящая через точку $C$ параллельно $AA_1$, пересекает $C_1B_1$ в точке $Q$. Так как $C_1P:PQ = C_1A:AC$ и $PQ:QB_1 = BC:CB_1$, то $C_1P = PQ = QB$, т. е. $C_1P:C_1B_1 = 1:3$.
