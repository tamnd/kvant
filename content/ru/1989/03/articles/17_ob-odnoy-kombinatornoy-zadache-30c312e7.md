Наимпут

Многие читатели знакомы с классической формулой числа сочетаний из $n$ элементов, взятых по $k$:

$$C_k^n = \frac{n!}{k!(n-k)!}.$$

В частности, существует $C_k^n$ способов выбора $k$ различных чисел из набора $(1, 2, 3, ..., n)$. Л. И. Плюкфельдер из Новокузнеца задался вопросом: сколько способами можно выбрать $k$ чисел из набора pa (1, 2, 3, ..., $n$) так, чтобы абсолютиная разность любых двух выбранных чисел была не меньше, чем $p$?

Обозначим это число через $C_k^n(p)$. Формула, найденная Л. И. Плюкфельдер, имеет вид:

$$C_k^n(p) = \frac{(n+k-pk+p-1)!}{k!(n-pk+p-1)!}$$

(если для некоторых $n, k, p$ в знаменателье появляется отрицательное число, то требуется сочитать не существует).

При $p=1$ формула (2), как и следовало ожидать, превращается в (1), а при $p=0$ в формулу:

$$C_k^n(0) = \frac{(n+k-1)!}{k!(n-1)!}.$$

Число $C_k^n(0)$ естественно принимать, как число способов выбора $k$ не обязательно различных элементов из данных $n$; для этого числа формула (3) дает верный результат.

Доказательство формулы (2) можно проверить по индекции; предлагаем вам сделать это самостоятельно.
