Интеррируя с учетом начальных условий, получаем
$$I = I_0 - \frac{\mathcal{E}_2}{L} t = \pm 0,6 \mathcal{E}_1 \sqrt{\frac{C}{L}} - 0,8 \frac{\mathcal{E}_1}{L} t,$$
откуда находим два решения:
1) $-1,8 \mathcal{E}_1 \sqrt{\frac{C}{L}} = 0,6 \mathcal{E}_1 \sqrt{\frac{C}{L}} - 0,8 \frac{\mathcal{E}_1}{L} t_1 \Rightarrow t_1 = 3 \sqrt{LC};$
2) $-1,8 \mathcal{E}_1 \sqrt{\frac{C}{L}} = -0,6 \mathcal{E}_1 \sqrt{\frac{C}{L}} - 0,8 \frac{\mathcal{E}_1}{L} t_2 \Rightarrow t_2 = 3/2 \sqrt{LC}.$
4. Условию задачи отвечает системе из двух собственных линз, каждая из которых дает действительное изображение (рис. 10). Используя формулу тонкой линзы для линзы $J_1$, находим $f_1 = \frac{F_1 d_1}{d_1 - F_1}$ и уведомление
$$\Gamma_{11} = \frac{f_1}{d_1} = \frac{F_1}{d_1 - F_1}.$$
Для линзы $J_2$ получаем
$$d_2 = L - f_1, f_2 = \frac{F_2 d_2}{d_2 - F_2}$$
и уведомление
$$\Gamma_{12} = \frac{F_2}{d_2 - F_2} = \frac{F_2}{L - \frac{d_1 F_1}{d_1 - F_1} - F_2}.$$
Полное уведомление системы из двух линз равно
$$\Gamma_1 = \Gamma_{11} \cdot \Gamma_{12} = \frac{F_1}{d_1 - F_1} \times \frac{F_2}{L - \frac{d_1 F_1}{d_1 - F_1} - F_2}.$$
В нашем случае удобно переписать это выражение в виде:
$$\frac{1}{\Gamma_1} = \frac{1}{\Gamma_{11}} \cdot \frac{1}{\Gamma_{12}} = \frac{d_1(L - (F_1 + F_2)) + F_1 F_2}{F_1 F_2} - \frac{L}{F_2}.$$
После перестановки линз уведомление системы задается аналогичным выражением:
$$\frac{1}{\Gamma_2} = \frac{1}{\Gamma_{21}} \cdot \frac{1}{\Gamma_{22}} = \frac{d_1(L - (F_2 + F_1)) + F_2 F_1}{F_2 F_1} - \frac{L}{F_1}.$$
Отсюда
$$\frac{1}{\Gamma_1} - \frac{1}{\Gamma_2} = L \left( \frac{1}{F_1} - \frac{1}{F_2} \right).$$
Так как оптическая сила линзы $D = 1/F$, то
$$D_2 - D_1 = \frac{1}{L} \left( \frac{1}{\Gamma_1} - \frac{1}{\Gamma_2} \right) = 3 \text{ дитр.}$$
