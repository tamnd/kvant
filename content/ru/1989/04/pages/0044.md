⟦folio 42⟧

Мой на интервале $-\frac{\pi}{2}; \frac{\pi}{2}$ (рис. 6). Отрезки, близкие к точке $x$, растяиваются функцией $f$ в $f'(x) = \frac{1}{\cos^2 x}$ раз. Значит, отрезки, близкие к точке $y = tg x$, растяиваются функцией $g$ в $(1 : \frac{1}{\cos^2 x}) = \cos^2 x$ раз. Стало быть, $g'(y) = \cos^2 x$. Осталось только выразить правую часть через $y$. Для этого воспользуемся тождеством $\cos^2 x = \frac{1}{1 + tg^2 x}$. Из него получим, что $g'(y) = \frac{1}{1 + tg^2 x} = \frac{1}{1 + y^2}$.

Итак, $(\arctg y)' = \frac{1}{1 + y^2}$. Интересно, что производная от обратной тригонометрической функции задается совсем простым выражением, не содержащим ничего, связанного с тригонометрией.

С. М. Львовский

Избранные школьные задачи

Восмой класс
1. Натуральные числа $m$ и $n$ таковы, что $m > n$, $m$ не делится на $n$ и имеет от деления на $n$ такой же остаток, как $m + n$ от деления на $m - n$. Найдите отношение $m:n$.
2. Докажите, что всякая бесконечная арифметическая прогрессия, составленная из натуральных чисел, содержит бесконечную геометрическую прогрессию.
3. При каких $a$ и $b$ уравнение $x^2 + a|x| + b = 0$ имеет 4 решения?
4. Внутри квадрата со стороны 1 нарисован треугольник, каждая из сторон которого не меньше 1. Докажите, что центр квадрата лежит внутри этого треугольника.
5. На плоскости даны две неравные окружности. Найдите геометрическое место середины отрезков, соединяющих точки одной окружности с точками другой.

Девятый класс
6. Решите уравнение
$$2^{[x^2 - 4]} = 3^{[1/x]}.$$
7. Решите систему уравнений
$$\begin{cases} x^{99}y^{99} + 3x^2 - y^2 = 3, \\ x^{99}y^{99} + 2x^2 - 2y^2 = 1, \\ x^{99}y^{99} - x^2 - 3y^2 = -3. \end{cases}$$
8. Многочлен $a_0x^n + a_1x^{n-1} + \dots + a_n$ принимает во всех целых точках $x$ целые значения. Можно один из его коэффициентов $a_i$ равнять 1/13?

9. Сколько положительных чисел есть среди первых ста членов последовательности
$$\sin 1^\circ, \sin 10^\circ, \sin 100^\circ, \sin 1000^\circ, \dots$$
10. Проекции неокоторого отрезка на две стороны правильно треугольника равны 2 и 3. Найдите проекцию этого отрезка на третью сторону.

Десять класс
11. a) Самая короткая сторона треугольника имеет длину $a = 1$, самая длинная — длину $b = 2$, один из углов равен $\varphi = 30^\circ$. Найдите длину третьей стороны. 6) Какое наиболее число решений может иметь предыдущая задача при надлежащем подборе чисел $a, b, \varphi$ (разумется, $a > 0, b > 0, 0 < \varphi < 180^\circ$)?
12. Кубищеское уравнение и квадратное уравнение, оба со старшим коэффициентом 1 и с разциональными коэффициентами, имеют общее решение. Докажите, что у кубищего уравнения есть разциональное решение.
13. Минимум функций $y = (x - a)^4 + (x - b)^4 + (x - c)^4$ равен 0, а минимум функций $y = (x - a)^4 + 2(x + b)^4 + (x - c)^4$ равен 4. Найдите $a, b$ и $c$.
14. Найдите все $x$, при которых
$$\sin x \leq \sin 2x \leq \dots \leq \sin 10x.$$
15. Докажите, что в сечении плоскостью треугrahного угла, у которого все плоские прямы, может получиться любой оструговый треугольник.
