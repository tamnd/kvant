⟦folio 51⟧

Метод Лобачевского

Доктор физико-математических наук
А. Л. БРУДНО

Создатель неевклидовой геометрии Н. И. Лобачевский придумал и метод приближенного решения алгебраической уравнения (с действительными коэффициентами)

$$a_0 + a_1x + a_2x^2 + \dots + a_nx^n = 0. \quad (1)$$

Метод позволяет найти абсолотное значение корня, имеющего максимальный модуль. После этого знак корня легко определить подстановкой в заданное уравнение. Единственное ограничение на применение метода — корень, максимальный по модулю, должен быть единственным. Если, например, он комплектный, то их уже два (т. е. еще и комплексно-сопряженный) и метод не применим. Воспледствии этот метод был усовершенствован, и стало возможным нахождение все корни уравнения, если их модули различны.

Идея Лобачевского состоит в следующем. Заменим заданное уравнение (1) другим, корни которого равны квадратам корней заданного. Будем повторять этот прием многоократно. Тогда корни уравнения «возведутся в квадрат», потом в 4-ю степень, в 8-ю и т. д. В результате максимальный по модулю корень становится играть подавляющую роль перед остальных и его легко будет вычислить по коэффициентам полученного уравнения (см. далее). Если теперь из ответа корень нужно степенки, то получится (приближенно) абсолотное значение корня исходного уравнения.

1. Итак, Лобачевскому нужно было найти многочлен, корни которого равны квадратам корней исходного многочлена, и найти его нужно было, не вычисляя корней исходного многочлена. Посмотрим, что сделал Лобачевский. Нам задан многочлен

$$P(x) = a_0 + a_1x + a_2x^2 + \dots + a_nx^n. \quad (2)$$

Есть такая теорема: многочлен $P(x)$ можно представить в виде

$$P(x) = a_n(x - x_1)(x - x_2) \dots (x - x_n),$$

где $x_1, x_2, \dots, x_n$ — корни уравнения $P(x) = 0$ (в школе это изучается только для $n=2$ и называется «разложение квадратного трехчлена на множители»). Возьмем многочлен $P(-x)$. Его можно записать в виде

$$P(-x) = a_0 - a_1x + a_2x^2 - \dots + (-1)^n a_nx^n.$$

или

$$P(-x) = a_n(-x - x_1)(-x - x_2) \dots (-x - x_n),$$

или даже так:

$$P(-x) = (-1)^n a_n(x + x_1)(x + x_2) \dots (x + x_n).$$

Рассмотрим произведение многочленов

$$P(x)P(-x) = (-1)^n a_n^2(x^2 - x_1^2)(x^2 - x_2^2) \dots (x^2 - x_n^2).$$

Заметим, что оно не содержит нечетных степеней $x$. Если в этом произведении заменить $x^2$ на $t$, то получится нужный нам многочлен

$$Q(t) = (-1)^n a_n^2 (t - x_1^2) (t - x_2^2) \dots (t - x_n^2),$$

корни которого равны квадратам корней заданного многочлена $P(x)$. Для вычисления коэффициентов $b_k$ многочлена $Q(t)$

$$Q(t) = b_0 + b_1 t + b_2 t^2 + \dots + b_{n-1} t^{n-1} + b_n t^n$$

можно переменить $P(x)$ и $P(-x)$, привести подобные члены при одинаковых степенях $x$ (нечетные степени при этом исчезнут) и заменить $x^2, x^4, \dots$ на $t, t^2, \dots$.

Вот формулы для коэффициентов $b_k$ при $n=3$ и $n=4$:

$$n = 3; a_0 + a_1 x + a_2 x^2 + a_3 x^3 = 0$$
$$b_0 = a_0 a_0$$
$$b_1 = a_0 a_2 - a_1 a_1 + a_2 a_0$$
$$b_2 = -a_1 a_3 + a_2 a_2 - a_3 a_1$$
$$b_3 = -a_3 a_3$$

$$n = 4; a_0 + a_1 x + a_2 x^2 + a_3 x^3 + a_4 x^4 = 0$$
$$b_0 = a_0 a_0$$
$$b_1 = a_0 a_2 - a_1 a_1 + a_2 a_0$$
$$b_2 = a_0 a_4 - a_1 a_3 + a_2 a_2 - a_3 a_1 + a_4 a_0$$
$$b_3 = a_2 a_4 - a_3 a_3 + a_4 a_2$$
$$b_4 = a_4 a_4$$

Вычисление коэффициентов $b_k$ не сложно поставить на компьютер или даже программируемый микрокалькулятор. После вычисления коэффициентов $b_k$ их значения присаивают коэффициентам $a_k$, вычисляются новые $b_k$ и т. д., пока максимальный по модулю корень нестанет превалирующим.

Чтобы значение этого корня, вернемся к формулам

$$Q(t) = b_0 + b_1 t + \dots + b_{n-1} t^{n-1} + b_n t^n$$
$$Q(t) = b_n (t - t_1) (t - t_2) \dots (t - t_n).$$

Если в нижней строке раскрыть скобки и приведенные члены, то должны получиться верхняя строка. Следовательно,

$$b_{n-1} = -(t_1 + t_2 + \dots + t_n) b_n$$

или

$$t_1 (1 + t_2/t_1 + t_3/t_1 + \dots + t_n/t_1) = -b_{n-1}/b_n.$$

Если корень $t_1$ по модулю значительно преосходит остальные, то выражение в скобках близко к 1 и приближению

$$t_1 \approx -b_{n-1}/b_n.$$

Любопытно, что метод Лобачевского можно находить и значения остальных корней уравнения (если все они по модулю различны). Пусть корень $t_2$ меньше $t_1$, но значительное преосходит остальные. Тогда в выражении для $b_{n-2}$

$$b_{n-2} = (t_1 t_2 + t_1 t_3 + \dots + t_2 t_3 + \dots) b_n$$

в скобках главную роль будет играть $t_1 t_2$, и можно приближенно считать, что $b_{n-2} \approx t_1 t_2 b_n$, откуда

$$t_2 \approx -b_{n-2}/b_{n-1}.$$

Аналогично $t_k \approx -b_{n-k}/b_{n-k+1}$.

2. Приближения, полученные по методу Лобачевского, исключаетлено быстро сходятся к точному решению. При вычислениях на ЭВМ или микрокалькуляторе надо завести счетчик числа iterations (обозначим его через $p$) и добавлять в него 1 после каждой iterations. Для корней $x_k$ исходного уравнения будет

$$|x_k| = t_k^{1/2^p},$$

коль скоро многочлен $Q(t)$ получен в результате $p$ iterations (повторенный перехода от многочлена $P$ к многочлену $Q$ и замены корней их квадратами). Вычисляется $|x_k|$ следует только если $t_k > 0$. Значение $t_k$ может быть отрицательным если есть корни, равные по модулю, или при первых iterationsх. Приближенные значения модели корней $x_k$ удобно выводить на экран после каждой iterations и следить за тем, как они установливаются. Именно такой метод, но в расчете наручные вычисления, и придумал Лобачевский.
