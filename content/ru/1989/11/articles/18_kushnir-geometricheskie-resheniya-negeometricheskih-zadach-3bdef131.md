⟦folio 61⟧

Геометрические решения негеометрических задач

И. А. КУШНИР

Многие задачи алгебры и трионометрии могут быть решены с помощью геометрии. В этой заметке мы показем несколько примеров таких задач.

Числовые равенства

Задание 1. Докажите равенства

a) $\cos \frac{\pi}{5} - \cos \frac{2\pi}{5} = \frac{1}{2}$;

b) $\frac{1}{\sin \frac{\pi}{7}} = \frac{1}{\sin \frac{2\pi}{7}} + \frac{1}{\sin \frac{3\pi}{7}}$

Решение. a) Для доказательства рассмотрим равноведренный треугольник $ABC$ с углами $\pi/5, 2\pi/5, 2\pi/5$ (см. рис. 1) и проведем bisсектору $BD$ угла $B$. Тогда $BC=BD=AD$. Пусть, для определности, $BC=1$. Из треугольников $ABD$ и $BCD$ получим $AB=2\cos \frac{\pi}{5}, CD=2\cos \frac{2\pi}{5}$, а из равенства $AD=AB-AC$ сразу следует соответствие.

6) Доказывает аналогично. Следует лишь рассмотреть равноведренный треугольник $ABC$ с углом при вершине $\pi/7$ (см. рис. 2) и высотой $BB_1=1$. Из треугольников $ABB_1, BDB_1, BCB_1$ находится

$$AB=AC = \frac{1}{\sin \frac{\pi}{7}}; \quad BD=AD = \frac{1}{\sin \frac{2\pi}{7}};$$

$$BC = \frac{1}{\sin \frac{3\pi}{7}}.$$

Осталось заметить, что $AC=AD+CD$.

Задание 2. Докажите, что
ctg30° + ctg75° = 2.

Решение. Рассмотрим равновесный треугольник ABC такой, что
∠A = 30°, AB = AC. Проведем его высоту BD. Пусть BD = 1. Тогда AB = AC = 2, AD = ctg30°, CD = ctg75° и AD + CD = AC.

Задание 3. Вычислите tg15°.

Решение. Рассмотрим равновесный треугольник ABC из предыдущей задачи. Тогда ∠CBD = 15°, AD = √3 и tg15° = CD = 2 - √3.

Задание 4. Вычислите sin 18°.

Решение. Вернемся к рисунку 1. Пусть AB = 1, BC = x = 2sin18°. Поискъку △BDC ∞ △ABC, имеем
x/1-x = 1/x, откуда x = -1 + √5/2. Итак, sin18° = √5 - 1/4.

Задание 5. Докажите, что
sin9° + sin49° + sin89° + ... + sin289° + sin329° = 0.

Решение. Рассмотрим равный девятнуюугольник A₁A₂...Aₙ, выпаенный в единичную окружность с центром в точке O (см. рис. 3). Пусть
e₁ = OA₁. Тогда e₁ + e₂ + ... + eₙ = 0. Требуем равенство ознакомости n-угольника A₁A₂...Aₙ (cos (9° + i40°); sin (9° + i40°)) равна нулю.
