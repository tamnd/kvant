ках тоже имеет такой вид:

$$\begin{cases}
s = 10x + 20y + 30z, \\
10x + 20y + 30z \geq 20(3-x) + 30(3-y) + 80(1-z), \\
20(3-x) + 30(3-y) + 80(1-z) \geq 10x + 20y + 30z, \\
x \geq 0, 3 \geq x, y \geq 0, 3 \geq y, \\
z \geq 0, 1 \geq z.
\end{cases}$$

«Многогранник», заданный системой неравенств, изображен снимм цветом на рисунке 1 — он совпится к плоскому патиугольнику. Вершина, в которой функиция s достигает максимума, помещена красным.

Л. В. Канторович предложил несколько подходов к решению формулированной общей задачи. Один из них основан на идее двойственности. Чтобы понять ее, решим задачу о станках другим способом.

Снова обозначим $\alpha_1 + \alpha_2 + \alpha_3$ через $x$, $\alpha_4 + \alpha_5 + \alpha_6$ — через $y$ и $\alpha_7$ — через $z$; введем новые обозначения: $x' = \alpha'_1 + \alpha'_2 + \alpha'_3$, $y' = \alpha'_4 + \alpha'_5 + \alpha'_6$, $z' = \alpha'_7$. Сопоставим каждому набору $(x, y, z, x', y', z')$, где все числа неотрицательны и связаны неравенствами

$$x + x' \leq 3, y + y' \leq 3, z + z' \leq 1,$$

(1) точку плоскости $(a; b)$ с координатами $a = 10x + 20y + 30z$, $b = 20x' + 30y' + 80z'$. (2)

Что же представляет собой множество $C$ всех точек, заданных соотношениями (1) и (2)? Это множество — сумма трех множеств: $C_1$, образованного теми точками $(a; b)$, для которых $a = 10x, b = 20x'$; $C_2$, состоящего из точек $(a; b)$, для которых $a = 20y$, $b = 30y'$; $C_3$, состоящего из точек $(a; b)$, для которых $a = 30z, b = 80z'$. При этом, конечно, выполнен неравенства (1). Множества $C_1, C_2$ и $C_3$ — это треугольники, изображенные на рисунке 2.

Чтобы построить искомое множество $C$, сначала найдем сумму $C_1$ и $C_2$, т. е. множество точек $(a; b)$ с координатами

$$a = 10x + 20y, b = 20x' + 30y'.$$

Для этого треугольник $C_2$ откладывается от верхней вершины треугольника $C_1$, а затем $C_2$ «съезжает с горки», образованной гипотенузой $C_1$. Получается четырехугольник, изображенный на рисунке 3.

Теперь можно построить и множество $C$. Отложим треугольник $C_3$ от верхней вершины на рисунке 3 и даим ему «съезжает с горки», образованной двухзвенной ломаной. Получается пятуюугольник $C$, изображенный на рисунке 4.
