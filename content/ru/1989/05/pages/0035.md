⟦folio 33⟧

6) Какое наиболее число вершин может иметь выпуклый многогранник, поверхность которого можно разрезать на правильные треугольники?

a) Сумма плоских углов при любой вершине данного многогранника может равнять только π/2, π или 3π/2. В самом деле, она меньше 2π, поскольку многогранный угол при любой вершине выпуклый. В то же время этот угол образован сгибанием и склеивания нескольких прямых углов (углов квадратов) и, может быть, развернуть угла (если рассматривается вершина прихождения на внутреннюю точку стороны одного квадратов). Следовательно, сумма его плоских углов кратна π/2. Таким образом, кривизна многогранного угла при любой вершине не меньше π/2, и по формуле Декарта число вершин не превыходит 4π:(π/2)=8. Пример 8-вершинника — куб.

6) Ответ: 12. Точно так же, как в п. a), доказывается, что кривизна многогранного угла при любой вершине не меньше π/3, значит, число вершин не превыходит 4π:(π/3)=12. Пример 12-вершинника — правильный икасдр.

M1140. Нарисуем на плоскости одну несколько пересекающий кривых (кривые могут иметь точки самопересечения, рис. 1). В каждой точке пересечения можно двумя способами выполнить «перестройку» (рис. 2). Если проделать перестройку во всех точках пересечения, то получится несколько пересекающий кривых (рис. 3).
a) Докажите, что число пересекающих кривых, которые могут получиться, не больше числа области, на которые делили плоскость исходные кривые (на рисунке 1 таких области 7).

a) Пусть первоначально данные кривые делили плоскость на области V₁, V₂,...,Vₙ. Каждый из новых, перестроенных кривых ограничивает область, состоящую из нескольких области Vᵢ. Выберем те из новых кривых, внутри которых нет других новых кривых, и отметим внутри каждой из них одну из области Vᵢ (рис. 5). Тепер сотем эти кривые, среди оставшихся слова выберем «minimalные» (внутри которых нет других кривых) и отметим внутри каждой из них одну из области Vᵢ, не отмещенных на первом шагу. (Очевидно, такие области найдет.) Продолжая в том же духе, мы сопоставили каждой новой кривой области Vᵢ внутри нее, отмещаемую на соответствующем шаге, причем разным кривым будут сопоставлены разные области. Значит, число кривых не больше числа области.
