Приицип «цепляния» последующего элемента за предыдущий часто встреется в математике, например в «цепных дробях». Всякую положительную дробь можно записать, и притом единственным образом, в виде:

$$\frac{p}{q} = a_0 + \frac{1}{a_1 + \frac{1}{a_2 + \dots + \frac{1}{a_n}}},$$

где числа $a_1, a_2, \dots, a_n$ — натуральные, а $a_0$ — целое неотрицательное. Например,

$$\frac{13}{7} = 1 + \frac{1}{1 + \frac{1}{6}};$$

$$\frac{22}{7} = 3 + \frac{1}{7},$$

$$\frac{355}{113} = 3 + \frac{1}{7 + \frac{1}{16}}.$$

Все irrationalные числа также выражаются целыми дробями. Так,

$$\sqrt{2} = 1 + \frac{1}{2 + \frac{1}{2 + \dots}}$$

$$\frac{1 + \sqrt{5}}{2} = 1 + \frac{1}{1 + \frac{1}{1 + \dots}}$$

$$\pi = 3 + \frac{1}{7 + \frac{1}{15 + \frac{1}{1 + \dots}}}.$$

Приведенные целые дроби для $22/7 = 3,1428$... и $355/113 = 3,1415929$... получены «обрыванием» целой дроби для числа л. Интересно, что обикновенные дроби, полученные «обрыванием» целой дроби для данного числа,

Являются на луущии приближениями среди всех дробей со значенателем, не большим полученого.

Понятие цепи вводится в теории графов. Граф — это некоторая совокупность точек (вершин), некоторые из которых соединены отрезками (ребрами). Например,

$$\frac{13}{7} = 1 + \frac{1}{1 + \frac{1}{6}};$$

$$\frac{22}{7} = 3 + \frac{1}{7},$$

$$\frac{355}{113} = 3 + \frac{1}{7 + \frac{1}{16}}.$$

Схема железной дороги. Цепь на графе — ломаная, составленная из его ребер.

Эйлерова цепь — цепь, проходящая по всем ребрам графа. Отсутствие такой цепи на графе, изобразенном на рисунке,

вершинам графа, по каждой — один раз. В отличие от эйлеровой цепи здесь пока нет простого критерия для определения того, существует ли на данной графе графы газильтонова цепь.

Молодой человек поселился на постоянном дворе на 31 день и договорился с хозяйним платьтить за постоян ejедневно по одному звнуу своей золотой цепочки из 31 звена, которое он носил на шее. Какое наименьшее число звенев он должен расковать, чтобы иметь возможность распластиться? При оплате он может забирать у хозяйня данных звенья, заменяя их другими. Эта задача, конечно, относится к общим цепочке. Но можно звенья цепочки сцепить так (см. рис.), что при вытяживании одного звена освобождаются все остальные звенья.
