III Международная олимпiad по информацией

I тур. В основе решения задачи лежит перебор с возвратом. На каждом шаге путем последовательного использования представленных правил определяется возможность размещения следующей номера в независимых позициях матрицы. Процесс заканчивается, если удается матрицу заполнить полностью или одно из имеющих правила не может быть использовано для заполнения таблицы. В последнем случае изменяется последовательность выбора правил и процессов повторяется. Если при выполнении задачи А) достаточно определить только один способ номера таблицы для заданной стартовой позиции, то в задании В) требуется определить все возможные варианты.

Проверка задачи А) осуществляется путем визуального контроля результатов заполнения матрицы. II тур. При выполнении задачи 1 следует обратить внимание на правильное формирование S-термов. В частности, в соответствии с определением последовательности SSS не является S-термом. Для $n=1$ число возможных термов равно 1, для $n=2-1$, для $n=3-2$, для $n=4-5$, для $n=5-14$, для $n=8-429$, для $n=10-4862$.

В качестве структуры данных для внутреннего представления S-термов (см. задание 2) может быть использован либо связанный списк, либо двойное дерево. Например, для S-терма (((S(SS))((SS(S))((SS(S))))) линейный списк может иметь вид

$$\rightarrow 3 \rightarrow 1 \rightarrow 0 \rightarrow 2 \rightarrow 0 \rightarrow 2 \rightarrow 0 \rightarrow 1 \rightarrow 0 \rightarrow nil.$$

При выполнении задачи 4 необходимо уяснить понятие «ненормализованный» S-терм. В частности, если к использовому S-терму нельзя применить процедур редукции, то такой S-терм не считается «ненормализованным». Если задан S-терм вида (((SS)(SS))(S)(SS)), то в результате использования процедуры нормализации получится последовательность S-термов

$((SS)(SS)(SS))(SS)) \rightarrow ((S(SS))((SS(S))(SS)))$

В то же время нормализация S-терма (((SS)(SS))(SS))(SS)) после 30 шагов не закончится, поэтому такой S-терм будет считаться «ненормализованным».
