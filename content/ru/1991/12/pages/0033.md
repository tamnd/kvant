Ф1306. Известны опыты, в которых диски, сделанные из немагнитных материалов, подают в недорогом магнитном поле между полосами электромагнита практические безускорения (см. рисунок). В одном из опытов были исследованы четыре диска одинаковых размеров — из сербра, платины, цинка и неизвестного металла. Диск из сербра nadал в заюре электромагнита с неокторой постоянной скоростью v при токе в обмотке $I_1=0,41$ А. Диск из платины nadал с той же скоростью при токе в обмотке $I_2=1,39$ А. При карамте диски из цинка будет nadать с той же скоростью? Из какого металла сделан четвертый диск, если он nadал с той же скоростью при токе $I_3=0,29$ А? Считайте, что в данном диапазоне токов поле в заюре электромагнита пропорционально величины тока. Необходимые данные о материалов взьмите из приложаемой таблицы.

Тормозящая сила, приводящая к padению диска безускорения, возникает при взаимодействии индукционных токов Фуко в диске с токами в обмотке электромагнита. При одинаковых размерах всех дисков можно считать, что эта сила

$$F \sim I_{\text{ннд}} I_{\text{обм}} \sim \frac{\mathcal{E}_{\text{ннд}}}{\rho} I_{\text{обм}}.$$

Пренебрегая искажениями полного поля за счет токов Фуко, для ЭДС индукции можно записать

$$\mathcal{E}_{\text{ннд}} \sim \frac{\Delta B}{\Delta h} v \sim I_{\text{обм}} v,$$

где $\Delta B/\Delta h$ — скорость изменения индукции магнитного поля с высотой.

Итак,

$$F \sim \frac{I_{\text{обм}} v}{\rho} I_{\text{обм}} = \frac{I_{\text{обм}}^2 v}{\rho}.$$

Для установившегося движения справедливо равенство

$$F - mg = 0.$$

Отсюда, введя плотность материалов $d$, получаем соответствие

$$\frac{I_{\text{обм}}^2 v}{\rho d} = \text{const}$$

(если для всех материалов использовать одинаковые единицы изменения одинаковых величины, то о размерности можно не беспокоиться). Данные задачи позволяют проверить справедливость этого соответствия:
