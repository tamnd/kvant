M1258. С $n > 3$ числа, рассставлены по окружности, разрешается продельать следующую операцию: заменить трейку идущих подряд чисел $x, y, z$ на трейку $x + y, -y, z + y$ (именно в такой порядке).

a) Можно ли с помощью таких операций получить из набора 20 чисел 1, 2, 3, ..., 9, 10, -1, -2, -3, ..., -9, -10 набор 10, 9, ..., 3, 2, 1, -10, -9, ..., -3, -2, -1?

b) Докажите, что для любого набора из $n$ чисел на окружности, сумма которых положительна, можно получить один и только один набор из $n$ неотрицательных чисел.

Будем считать, что числа $a_1, a_2, ..., a_{n-1}, a_n$ занутерованы по циклу:

$$a_{n+1} = a_1, a_{n+2} = a_2, ...$$

Заметим, что указанное в условия преобразование при повторении (на том же месте) возвращает нас к исходной последовательности. Это выводит на мысль, что за ним скрыта какая-то перестановка двух чисел — мы увидим сейчас, что дело обстоит именно так.

Рассмотрим последовательность $B$ частичных сумм:

$$b_1 = c + a_1,$$
$$b_2 = c + a_1 + a_2,$$
$$b_3 = c + a_1 + a_2 + a_3,$$
$$b_3 = c + a_1 + a_2 + a_3,$$
$$b_n = c + a_1 + a_2 + ... + a_{n-1} + a_n,$$
$$b_{n+1} = c + a_1 + a_2 + ... + a_{n-1} + a_n + a_{n+1},$$

и посмотрим, как эти числа изменятся при указанной замене. (Здеся $c$ — произвольно выбранная константа, которая не играет роли: две последовательности, отличащиеся выбором $c$, мы не различаем — для нас важны лишь разности $b_k - b_{k-1} = a_k$.) Если $x = a_{k-1}, y = a_k, z = a_{k+1}$ меняются на $x + y, -y, z + y$, то $b_{k-2} = d, b_{k-1} = d + x, b_k = d + x + y, b_{k+1} = d + x + y + z$ (где $d$ — неотрицательная константа) меняются на

$$d, d + x + y, d + x, d + x + y + z.$$

Мы видим, что при этом $b_k$ и $b_{k-1}$ просто меняются местами, а остальные $b_i$ не изменяются. Рассмотрим два случая.

1) Сумма $a_1 + a_2 + ... + a_n$ равна 0 (как в случае $a$)). Здеся числа $b_k$ периодически повторяются: $b_{n+1} = b_1, b_{n+2} = b_2$ и, продолжая последовательность $B$ частичных сумм, мы получим, что $b_{i+n} = b_i$ при любом целом $i$. Тем самым, мы можем считать, что числа $b_k$ написаны по окружности и указанные в условиям пре-

образования — просто перестановки двух соседних чисел $b_k$ и $b_{k+1}$.

Легко проверить, что для расстановок, указанных в пункте a), наборы частных сумм $b_1, b_2, \dots, b_n$ отличаются лишь порядком — и тот и другой состоит из 0 и сумм нескольких чисел подряд в последовательности 1, 2, ..., 10 (на рисунке 1, где они выписаны по кругу, каждое число помещается местами с симметриным относительной горизонтальной диаметра). Поскольку любая перестановка может быть очень но осуществлена заменами соседних чисел, ответ в пункте a) положен.

2) Сумма $a_1 + a_2 + \dots + a_n = s$ положительная. Теперь $b_{n+1} = c + a_1 + a_2 + \dots + a_{n-1} + a_n + a_{n+1} = b_1 + s$ — тем самым придает считать, что при обходе по циклу к частной сумме $b_i$ добавляется $s: b_{i+n} = b_i + s$ при любом целом $i$. Этим условием последовательность $b_i$, заданная при $1 \leq i \leq n$, определяется при всех целях $i$ — положительных и отрицательных (типичный график такой последовательности $B = (b_i)$ изображен на рисунке 2). Удобно представить себе, что ось, на которой отмечается значения индекса $i$, наматывается на окружность длины $n$; при этом каждой точке $K$ окружности, $1 \leq k \leq n$, соответствует не одно число $b_k$, а целая прогрессия с нулявым членом $b_k$ и разность $s$.

Теперь при замене $x = a_{k-1}, y = a_k, z = a_{k+1}$ на $x + y$, $-y, z + y$, числа $b_k$ и $b_{k-1}$ по-прежнему проходит местами, причем мы считаем, что это проискит одновременно со всеми членами прогрессии — то есть для всех $k$, дающих тот же остаток при делении на $n$.

Доказем существование и единственность такого расположения $b_k$, при котором набор разностей $b_k - b_{k-1} = a_k$ будет неотрицательным — для чего необходимо и достаточно, чтобы последовательность $B = (b_k)$ стала неубывающей.

Сразу ясно, что результатирующая последовательность определяется единственным образом: для каждого $b_k$ можно указать место, куда оно должно в конце концов попасть — это место определяется количеством тех $b_i$, с которым $b_k$ должно помещаться места-

Ф1304. КПД тепловой машины в цикле 1—2—3—1 (см. рис.ок), состоящем из изготовы 1—2, изхоры 2—3 и adiaбаты 3—1, равен $\eta_1$. В цикле 1—3—4—1, состоящем из adiaбаты 1—3, изготовы 3—4 и изхоры 4—1, КПД равен $\eta_2$. Чему равен КПД тепловой машины, работаюшей по циклу 1—2—3—4—1? Работим веществом является идеальный одноатомный газ.

В цикле 1—2—3—1 теплло потребляется на участке 1—2 и отделяется на участке 2—3. Поэтому

$$\eta_1 = \frac{Q_{12} - Q_{23}}{Q_{12}},$$

где $Q_{23}$ — количество теплоты, отданное газом на участке 2—3.

В цикле 1—3—4—1 теплло потребляется на участке 4—1 и отделяется на участке 3—4. Аналогично предыдущему равенству,

$$\eta_2 = \frac{Q_{41} - Q_{34}}{Q_{41}}.$$

Легко видеть, что $Q_{23}$ отдаваемое равно $Q_{41}$ потребляемому — и в том, и в другом случае все количество теплоты соответствует изменению внутренней энергии, а перепады температур одинаковы: $T_2 - T_3 = T_1 - T_4$. Итак,

$$Q_{23} = Q_{41} = Q.$$

Тепер можно записать выражение для КПД «большего» цикла:

$$\eta = \frac{A}{Q_{\text{потр}}} = \frac{A_{12} - A_{34}}{Q_{12} + Q_{41}} = \frac{Q_{12} - Q_{34}}{Q_{12} + Q_{41}}.$$

Количество теплоты $Q_{12}$ и $Q_{34}$ просто выражаются через $Q$:

Ф1305. В схеме на рисунке 1 напряжение батарейки $U_0 = 10$ В, емкость конденсатора $C = 1$ мкФ, сопротивление zalbano-mетра $R = 1$ кОм. Десять раз в секунду конденсатор отключают от цепи и сразу же подключают обратно, поменяя местами его выводы. Какой ток показывает zalbano-mетр? Во сколько раз изменяется ток при увеличении емкости конденсатора до 1000 мкФ? При такой частоте переключений стрелка zalbano-mетра практически не проходит.

При заданных значениях $R$ и $C$ за время $\tau = 0,1$ с конденсатор каждый раз успевает практические полностью перезаряditся — его заряд в конце каждого инвервала равен по модулю

$$q = CU_0.$$

Это значит, что за время $\tau$ по zalbano-mетру протекает заряд

$$q_G = q - (-q) = 2q = 2CU_0,$$

и средний ток через zalbano-mетр (именно его и показывает магнитозлектрический прибор) оказывается равным

$$I_{cp} = \frac{q_G}{\tau} = \frac{2CU_0}{\tau} = 2 \cdot 10^{-4} \text{A}.$$

При большой величины емкости конденсатора $C' = 1000$ мкФ процесс выглядит по-другому — за время $\tau$ напряжение $U$ на конденсаторе изменяется, но только очень незначительно:

$$\Delta U \approx \frac{I\tau}{C'} = \frac{U_0\tau}{C'R} = 1\text{B} \ll U_0.$$

Ясно, что напряжение на конденсаторе колблется около нуля и изменяется практически по линейному закону (рис. 2). Следовательно, средний ток в этом случае равен

$$I'_{cp} = I = \frac{U_0}{R} = 10^{-2} \text{A},$$

а относение токов —

$$\frac{I'_{cp}}{I_{cp}} = \frac{10^{-2} \text{A}}{2 \cdot 10^{-4} \text{A}} = 50.$$

Ф1306. Известны опыты, в которых диски, сделанные из немагнитных материалов, подают в недорогом магнитном поле между полосами электромагнита практические безускорения (см. рисунок). В одном из опытов были исследованы четыре диска одинаковых размеров — из сербра, платины, цинка и неизвестного металла. Диск из сербра nadал в заюре электромагнита с неокторой постоянной скоростью v при токе в обмотке $I_1=0,41$ А. Диск из платины nadал с той же скоростью при токе в обмотке $I_2=1,39$ А. При карамте диски из цинка будет nadать с той же скоростью? Из какого металла сделан четвертый диск, если он nadал с той же скоростью при токе $I_3=0,29$ А? Считайте, что в данном диапазоне токов поле в заюре электромагнита пропорционально величины тока. Необходимые данные о материалов взьмите из приложаемой таблицы.

Тормозящая сила, приводящая к padению диска безускорения, возникает при взаимодействии индукционных токов Фуко в диске с токами в обмотке электромагнита. При одинаковых размерах всех дисков можно считать, что эта сила

$$F \sim I_{\text{ннд}} I_{\text{обм}} \sim \frac{\mathcal{E}_{\text{ннд}}}{\rho} I_{\text{обм}}.$$

Пренебрегая искажениями полного поля за счет токов Фуко, для ЭДС индукции можно записать

$$\mathcal{E}_{\text{ннд}} \sim \frac{\Delta B}{\Delta h} v \sim I_{\text{обм}} v,$$

где $\Delta B/\Delta h$ — скорость изменения индукции магнитного поля с высотой.

Итак,

$$F \sim \frac{I_{\text{обм}} v}{\rho} I_{\text{обм}} = \frac{I_{\text{обм}}^2 v}{\rho}.$$

Для установившегося движения справедливо равенство

$$F - mg = 0.$$

Отсюда, введя плотность материалов $d$, получаем соответствие

$$\frac{I_{\text{обм}}^2 v}{\rho d} = \text{const}$$

(если для всех материалов использовать одинаковые единицы изменения одинаковых величины, то о размерности можно не беспокоиться). Данные задачи позволяют проверить справедливость этого соответствия:

для сербраного диска $\frac{I_{\text{обм}}^2 v}{\rho d} = 1,006,$
