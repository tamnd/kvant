M1278. Имеется п вещественных чисел $x_1, x_2, \dots, x_n$, удовлетворяющих условиям $x_1 + x_2 + \dots + x_n = 0$ и $x_1^2 + x_2^2 + \dots + x_n^2 = 1$. Доказите, что $x_i x_j \leq -1/n$ для некоторых $i, j$.

Рассмотрим сначала «крайний» случай, когда числа принимают всего два различных значения: $k$ из них равны $a < 0$, а остальные $(n-k)$ равны $b > 0$. Тогда $ka + (n-k)b = 0$, то есть $ka = -(n-k)b$ и $ka^2 + (n-k)b^2 = -(n-k)ab - kab = 1$, откуда $ab = -1/n$. Общий случай попробуем свести к этому, «развивая» переменные. Заметим, что если заменить пару чисел $u, v$ $(u < v)$ на $u - t, v + t$ $(t > 0)$, то сумма не изменится, а сумма квадратов увеличится:

$$(u - t)^2 + (v + t)^2 = u^2 + v^2 + 2t(v - u) + t^2.$$

Пусть $a < 0$ — наименьшее, $b > 0$ — наибольшее из данных $n$ чисел $x_1, x_2, \dots, x_n$. Если в этом набore есть два числа, отличных от $a$ и $b$, разделенным их, не меняя суммы так, чтобы одно из них сравнялось с одним из крайних чисел $a$ или $b$. После нескольких операций получим набор из $n$ чисел, в котором все, кроме одного — обозначим его $c$, равны $a$ (пусть их $k$) или $b$ ($m = n - k - 1$), сумма которых равна 0, а сумма квадратов — не меньше 1:

$$ka + c + mb = 0,$$

$$ka^2 + c^2 + mb^2 = -(c + mb)a + c^2 - (ka + c)b \geq 1.$$

Поскольку $a \leq c < b$, $ca - c + cb - ab = (c - a)(b - c) > 0$. Сложив это неравенство с предыдущим, получим требуемое:

$$-(m + k + 1)ab = -nab > 1,$$

или $ab < -1/n$.

(Из этого доказательства ясно, что равенство достигается лишь в «крайних» случаях, рассмотренных вначале.)

Задча имеет и прямое алгебраическое решение. Для любого $i, 1 \leq i \leq n$

$$(x_i - a)(x_i - b) \leq 0.$$

Просуммировав эти неравенства, получим

$$\sum_{i \leq 1}^{n} x_i^2 - (a + b) \sum_{i=1}^{n} x_i + nab \leq 0$$

(*)

Но $\sum_{i \leq 1}^{n} x_i^2 = 1$, $\sum_{i=1}^{n} x_i = 0$, поэтому (*) превращается в $nab \leq -1$.

Н. Васильев, Е. Столов
