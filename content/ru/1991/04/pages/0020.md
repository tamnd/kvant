Неравенство Иенсена утверждает, что для любой выпуклой на отрезке $[a; b]$ функции $\varphi(x)$ произвольного набора точек $x_1, x_2, \ldots, x_n$ из этого отрезка, а также произвольного набора положительных чисел $p_1, p_2, \ldots, p_n$, в сумме равных $1 (p_1 + p_2 + \ldots + p_n = 1)$, имеет место соотношение

$$\varphi(p_1 x_1 + \ldots + p_n x_n) \leqslant \leqslant p_1 \varphi(x_1) + \ldots + p_n \varphi(x_n).$$

Приступим к изложению доказательства. Обозначим $\frac{x_{i+1}}{x_i} = k_i$, причем $\frac{x_1}{x_n} = k_n$. Расположим полученные числа $k_i$ в порядке возрастания, а целые возникшей последовательности обозначим через $m_j$. Теперь рассмотрим две последовательности:

$$\frac{1}{m_1}, \frac{1}{m_2}, \ldots, \frac{1}{m_n} \text{ и} \frac{1}{1 + m_n}, \frac{1}{1 + m_{n-1}}, \ldots, \frac{1}{1 + m_2}, \frac{1}{1 + m_1}.$$

Одна монotonно убивает, а второй монotonно возрастает. Используя первое нашей неравенство, получаем, что

$$\frac{x_1}{x_2 + x_3} + \frac{x_2}{x_3 + x_4} + \ldots + \frac{x_n}{x_1 + x_2} = \frac{1}{k_1(k_2 + 1)} + \frac{1}{k_2(k_3 + 1)} + \ldots + \frac{1}{k_n(k_1 + 1)} \geqslant \frac{1}{m_1(m_n + 1)} + \frac{1}{m_2(m_{n-1} + 1)} + \ldots + \frac{1}{m_n(m_1 + 1)}.$$

(*)

Обозначим $m_i \cdot m_{n-i+1} = c_i$ и

$$r_i = \frac{1}{m_i(m_{n-i+1} + 1)} + \frac{1}{m_{n-i+1}(m_i + 1)},$$

тогда

$$r_i = \frac{1}{c_i} \left(1 + \frac{c_i - 1}{(1 + m_i)(1 + m_{n-i+1})}\right).$$

Так как $(1 + m_i)(1 + m_{n-i+1}) \geqslant (1 + \sqrt{c_i})^2$, то

$$r_i \geqslant \left\{ \begin{array}{l l} \frac{1}{c_i}, & c_i \geqslant 1, \\ \frac{2}{c_i + \sqrt{c_i}}, & c_i < 1. \end{array} \right.$$

Положим $c_i = e^{y_i}$. Из неравенств (*) и (**) имеем

$$\frac{2}{n} \sum_{i=1}^{n} \frac{x_i}{x_{i+1} + x_{i+2}} \geqslant \geqslant \frac{1}{n} \left( \sum_{c_i \geqslant 1} e^{-y_i} + \sum_{c_i < 1} 2\left(e^{\frac{x}{2}} + e^{y_i}\right)^{-1} \right).$$

Пусть $g$ — наиболее выпуклая функция, не превысющая функция $y = e^{-x}$ и $y = 2\left(e^{\frac{x}{2}} + e^{x}\right)^{-1}$. Тогда из неравенства (***), в силу неравенства Иенсена, имеем

$$\frac{2}{n} \sum_{i=1}^{n} \frac{x_i}{x_{i+1} + x_{i+2}} \geqslant \geqslant \frac{1}{n} \sum_{i=1}^{n} g(y_i) \geqslant g\left(\frac{y_1 + y_2 + \ldots + y_n}{n}\right) = g(0).$$

Тем самым доказано, что $\gamma \geqslant g(0)$.

Далее довольно изящными расчужениями доказывается, что $g(0) = \gamma$.

Пусть общая касательная соединиет точки $(x_1; e^{-x_1})$ и $(x_2; 2\left(e^{\frac{x}{2}} + e^{x_2}\right)^{-1})$ (рис. 2). График функции $g$ состоит из трех частей: $y = e^{-x}$ при $x \geqslant x_1$, $y = 2\left(e^{x} + e^{\frac{x}{2}}\right)^{-1}$ при $x \leqslant x_2$ и их общей касательной при $x_2 \leqslant x \leqslant x_1$. Ordината точки пересечения касательной с осью ordинат и есть $\gamma$.
