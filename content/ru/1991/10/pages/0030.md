a) Докажем, что (для любого $n \geqslant 4$) при заполненении квадрата $(2n-1) \times (2n-1)$ фигурами данных трех типов фигурок 1-го типа — угловов — будет не меньше $4n-1$. В частности, при $n=50$ получим нужную оценку 199.

Раскрасием клетки доски $(2n-1) \times (2n-1)$ в четыре цвета 1, 2, 3, 4, как показано на рисунке 2. Пусть $a_i$ — число углов, не содержащих клетку цвета $i$ ($i=1, 2, 3, 4$), т. е. содержащих по одной клетке других цветов; $b$ — общее число фигурок двух других типов, каждой из которых содержит по одной клетке разных цветов. Поскольку общее число клеток 1-го цвета равно $n^2$, 2-го, 3-го — по $n(n-1)$ и 4-го — $(n-1)^2$, то

$$a_2 + a_3 + a_4 + b = n^2,$$
$$a_1 + a_2 + a_4 + b = a_1 + a_3 + a_4 + b = n(n-1),$$
$$a_1 + a_2 + a_3 + b = (n-1)^2,$$

откуда

$$a_4 - a_1 = 2n-1, \quad a_3 - a_1 = a_2 - a_1 = n$$

и (поскольку $a_1 \geqslant 0$) $a_2 = a_3 \geqslant n$, $a_4 \geqslant 2n-1$, так что

$$a_1 + a_2 + a_3 + a_4 \geqslant n + n + 2n-1 = 4n-1.$$

Вот более короткое рассудение, в котором участвует лишь общее число $a = a_1 + a_2 + a_3 + a_4$ угловов и число $b$ фигурок двух других типов. Поскольку $3a + 4b = (2n-1)^2$ и в каждой фигуре содержится не более одной клетки 1-го цвета, то $a + b \geqslant n^2$, поэтому

$$4a \geqslant 4n^2 - 4b = 4n^2 - (2n-1)^2 + 3a = 4n-1 \geqslant 3a,$$

откуда

$$a \geqslant 4n-1.$$

6) На рисунке 3 показано, как можно заполнить квадрат $7 \times 7$, использая одну фигуру типа 2 или 3 и $15=4 \cdot 4-1$ углов*, а на рисунке 4 — как можно от заполнения квадрата $(2n-1) \times (2n-1)$ с $4n-1$ угловами перейти к заполнению квадрата $(2n+1) \times (2n+1)$ с $4(n+1)-1=4n+3$ угловами. (Заметим, что из наших оценок в пункте a) следует, что $b=n^2-a_2-a_3-a_4 \leqslant n^2-4n+1$, а это число при $1 \leqslant n < 4$ отрицательно, поэтому заполнение возможно лишь начиная с $n=4$, т. е. с квадрата $7 \times 7$.

Д. Фомин
