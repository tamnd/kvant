сложить карты в обратном порядке. Докажите, что a) $M(9) \leq 5$, 6) $M(52) \leq 27$, 8)*$M(52) \geq 17$, 9)*$M(52) \geq 27$. Найдите $M(n)$ для любого $n > 2$.

Задайте ..., $a, b, ..., c, d, ...$ и вставляем его между $p$ и $q$, то разрушаются связи $ab, cd$ и $pq$. Чтобы переложить карты в обратном порядке, нужно разрушить все $n - 1$ связи. Отсюда для числа необходимых шагов $s$ получаем оценку

$$3s \geq n - 1.$$

Чтобы получить оценку $s \geq (n + 1)/2$, будем рассуждать несколько иначе. Будем считать, что между соседними картами возможны связи двух типов: „>“ или „<“ («большие» или «меньшие»), и за $s$ операций все $n - 1$ связи типа „<“ должны превращаться в противоположные „>“. Заметим, что на каждом шаге число связи „>“ может возникнуть не более чем на 2. В самом деле, сразу 3 связи „<“ превращается в „>“ могли бы только при переходе от

...$a, b, ..., c, d, ..., p, q, ...$

к

...$a, d, ..., p, b, ..., c, q, ...$

в том случае, если

$$a < b, c < d, p < q, a > d, p > b, c > q.$$

Но эти шесть неравенств несовместимы: из них следует

$$a < b < p < q < c < d < a — противоречие.$$

Далее, на первом шаг может превращаться из „<“ в „>“ лишь одна связь: ведь здесь либо $a < b < c < d < p < q$, либо $p < q < a < b < c < d$, а при этом выполняется лишь одно из трех неравенств

$$a > d, p > b, c > q.$$

Точно так же обстоит дело и на последнем шаге, после которого получается набор из $n - 1$ связей „>“ (вообще нетрудно видеть, что обратные переходы совершенно аналогичны прямым, лишь знаки „<“ и „>“ меняются ролими).

Итак, для числа $s$ неравенств шагов получаем оценку

$$1 + 2(s - 2) + 1 \geq n - 1,$$

откуда

$$s \geq (n + 1)/2.$$
