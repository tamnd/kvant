Деление с остатком и сравнения по модулю

Третьего сентября 1990 года мне понадобилось узнать, каким днем недели будет 20 декабря 1991 года. Календарь у меня под рукой не было, поэтому пришлось занять подсчетами. Я знал, что 3 сентября — попедельник, а с 3-го сентября 1990 года по 20-e декабря 1991 года проходит

27+31+30+20+365=473 дня, т. е. 67 полных недель и еще 4 дня (473=67·7+4). Следовательно, 20-e декабря 1991 года — пятница.

Возвода в квадрат многозначное число, ученик получил ответ 46 991 075. Учитель, заглянув в его тетрадку, сразу сказал: «Ответ неверен!» Как он это понял?

Упражнение 1. Подумайте, может ли квадрат целого числа оказаться цифрами 75.

Дальше мы увидим, что в основе решения и этой нехитрой задачи, и многох других лежат сообщения делимости. Однако сначала нам нужно вспомнить, что такое деление с остатком.

Деление с остатком

Определение. Разделить натуральное число a на натуральное число b с остатком значит записать a в виде a=qb+r, где q и r неотрицательные целые числа, причем r<b. Число q при этом называется частным, a r — остатком от деления a на b.

На практике деление с остатком выполняет общим способом, т. е. «делением углом». Например:

$$\frac{179}{14} \frac{14}{12}$$

Здесь сразу остаток 11 и частное 12: 179=12·14+11.

Заметим, что в данном определении мы не требуем, чтобы a было больше, чем b. Можно, например, разделить 5 на 7: 5=0·7+5. Вообще, если a<b, то a=0·b+a, т. е. в этом случае q=0, r=a.

Заметание. Можно определить деление с остатком любого целого числа a на любое целое число b≠0 так: разделить a на b с остатком значит представить a в виде a=qb+r, где q — целое, a 0≤r≤|b|. Например, при a=-15, b=7: -15=(-3)·7+6; при a=-224, b=-9: -224=15·(-9)+1 и т. п.

Если остаток равен нулю, т. е. a=qb, говорят, что a делится на b.

Очень важно следующее простое наблюдение. Если a и b делятся на c, то при любых целых k и l число ka+lb делится на c.

Задание 1. Числа $7n+1$ и $8n+3$ делятся на некоторое натуральное число $d \neq 1$. Найдите $d$.

Сравнения по модулю
Давайте сразу условиями, что все числа, о которых поддет речь дальше, будут целыми, так что в последующем это не будет специально оговориться. Расмотрим еще одну задачу.

Задание 2. На какую цифру оканчивается число $2^{999}$?

Решение. Выпишем последовательные степени двойки:
2, 4, 8, 16, 32, 64,...
Легко видеть, что последние цифры этих чисел повторяются через 4, так что последняя цифра числа $2^n$ зависит только от того, какой остаток при делении на 4 дает показатель $n$. Поскольку $999=996+3=4 \cdot 249+3$, ответ в нашей задаче: 8.

В этом примере все множество показателей степени разбилось на 4 класса, состоящих из чисел $n$ вида $4k, 4k+1, 4k+2, 4k+3$.

Возбше, для любого натурального числа $m$ все целые числа (не только положительные!) разбиаются на $m$ классов. Каждый класс при этом состоит из чисел, дающих при делении на $m$ одинаковые остатки.

Вот эти классы:
0) числа $a$ вида $a=km$,
1) — а — а=km+1,
$m-1)$ — а — а=km+m-1.

Ясно, что любое число принадлежит одному из выписанных классов. При этом разность любых двух чисел из одного класса делится на $m$, а разность двух чисел из разных классов на $m$ не делится.

Определение. Если разность целых чисел $a$ и $b$ делятся на натуральное число $m$, то говорят, что $a$ и $b$ сравнимы по модулюм.

Записывается сравнимость чисел по модулюм $m$ так:

$a \equiv b(\text{mod } m)$.

Числа $a$ и $b$ сравнимы по модулюм $m$ тогда и только тогда, когда они принадлежат одному классу, т. е. дают одинаковые остатки при делении на $m$. Иначе говоря, $a \equiv b(\text{mod } m)$ означает, что $a=b+km$, где $k$ — целое число. Например, $27 \equiv 7(\text{mod } 10)$, $78 \equiv 6(\text{mod } 24)$, $6 \equiv 0(\text{mod } 3)$, $25 \equiv -4(\text{mod } 29)$.

Свойства сравнения
Сравнения по своим свойствам наполняют общие равенства:
1) если $a \equiv b(\text{mod } m)$ и $b \equiv c(\text{mod } m)$, то $a \equiv c(\text{mod } m)$.
2) $a+c \equiv b+d(\text{mod } m)$.
3) $a-c \equiv b-d(\text{mod } m)$.
4) $ac \equiv bd(\text{mod } m)$.
т. е. сравнения, как и общные равенства, можно складывать, вычитать и переменная.

Докажем, например, свойство 4. Так как $a \equiv b$ и $c \equiv d$, то $a - b$ и $c - d$ делятся на $m$.

Из равенства $ac - bd = a(c - d) + d(a - b)$ получается, что число $ac - bd$ делится на $m$, т. е.

$$ac \equiv bd(\text{mod } m).$$

Упражнение 14. Докажите остальные свойства сравнения.

Пусть $a \equiv b(\text{mod } m)$. Из уже установленных свойств сравнения следует
5) для любого натурального $k$
$$a^k \equiv b^k.$$

Кроме того, в некоторых случаях сравнения можно сокращать на общий множитель левой и правой части:
6) если $ac \equiv bc(\text{mod } m)$, а числа $c$ и $m$ взаимно просты, то
$$a \equiv b(\text{mod } m);$$
7) если $a \equiv b(\text{mod } m)$, $k$ — целое число и $a = ka_1$, $b = kb_1$, $m = km_1$, то
$$a_1 \equiv b_1(\text{mod } m_1).$$

Иначе говоря, обе части сравнения и модель можно разделить на их общий делитель. Докажем свойство 6. Число $c(a - b)$ делится на $m$. Так как $c$ и $m$ взаимно просты, то число $a - b$ делится на $m$. Поэтому
$$a \equiv b(\text{mod } m).$$

Упражнение 15. Докажите свойство 7.

Из сказанного следует, что в любом алгебраическом выражении, полученном из целых чисел $a, b, c, \dots$, $z$ с помощью сложений, умножений и вычитаний можно заменить эти числа их остатками от деления на $m$, не изменя при этом остатка, который дает это выражение при делении на $m$.

Задача 3. Найдите остаток от деления на 3 числа
$$N = (1^2 + 1)(2^2 + 1)(3^2 + 1)...(1000^2 + 1).$$

Решение. Из сделанного выше замечания следует, что
$$N \equiv (1^2 + 1)^{333} \cdot (2^2 + 1)^{333} \cdot (3^2 + 1)^{333} \equiv 2^{333} \cdot 2^{333} \cdot 1^{333} \equiv 2^{666} \equiv (2^2)^{333} \equiv 1^{333} \equiv 1.$$

Задача 4. При каких натуральных $n$ число $8n + 3$ делится на 13 (см. задачу 1)?

Решение. Запишем, пользоваться свойствами сравнения, следующую целочкусную соответствию:
Пусть $8n + 3 \equiv 0(\text{mod } 13)$, тогда
$$8n \equiv -3(\text{mod } 13),$$
$$8 \times 8n \equiv -24(\text{mod } 13),$$
$$-n \equiv -24 \equiv -11(\text{mod } 13).$$

Откуда $n \equiv 11(\text{mod } 13)$.

Окончательно, $8n + 3$ делится на 13, если и только если $n = 13k + 11$.

Китайская теорема об остатках

Рассмотрим $m$ членов арифметической прогрессии
$$a, a + d, \dots, a + (m - 1) \cdot d,$$ (*)
где $a$ — целое число, $a$ — взаимно прост с $m$. Часто бывают очень полезной следующая

Теорема 1. Среди чисел (*) имеют одно odd, делиеся на $m$.

Доказательство. Разность $k$-го и $l$-го чисел (*), равная $d(k - l)$, не делится на $m$. Иначе оказывается, что $k - l$ делится на $m$, что невозможно, так как $|k - l| < m$.

Тем самым числа (*) попарно не сравнимы по модulo $m$ и поэтому дают различие остатки при делении на $m$.

Теорема 2. Пусть данные $n$ попарно взаимно простых чисел $m_1, m_2, ..., m_n$ и чисел $r_1, r_2, ..., r_n$ таких, что $0 \leqslant r_i \leqslant m_i-1$ ($i=1, 2, ..., n$). Тогда существует число $N$, дающее при делении на $m_i$ остаток $r_i$.

Иначе говоря $N \equiv r_i(\text{mod } m_i)$ при всех $i=1, 2, ..., n$.

Доказательство. Применим индекцию по $n$. При $n=1$ утверждение теоремы очевидно. Пусть теорема справедлива при $n=k$. Тогда существует число $M$ такое, что $M \equiv r_i(\text{mod } m_i)$ при $i=1, 2, ..., k$.

Пусть $d=m_1m_2...m_{k-1}$.

Рассмотрим числа
$M, M+d, M+2d, ..., M+(m_k-1)d$.

Поскольку $d$ взаимно просто с $m_k$, из доказательства теоремы 1 следует, что среди выписанных чисел найдется число $N$, дающее при делении на $m_k$ остаток $r_k$. В то же время при делении на $m_1, m_2, ..., m_{k-1}$ число $N$ дает остатки $r_1, r_2, ..., r_{k-1}$ соответственно.

Теорема доказана.
И, наконец, еще одна теорема.
Теорема 3. Для любых попарно взаимно простых чисел $m_1, m_2, ..., m_n$ и остатков $r_1, r_2, ..., r_n$ по модулю $m_1, m_2, ..., m_n$ найдется $n$ последовательных чисел $a, a+1, ..., a+n-1$ таких, что $a \equiv r_1(\text{mod } m_1), a+1 \equiv r_2(\text{mod } m_2), ..., a+n-1 \equiv r_n(\text{mod } m_n)$.

Иначе говоря, для любых попарно взаимно простых модулей $m_1, m_2, ..., m_n$ найдется $n$ подряд идущих натуральных чисел, дающих соответственную любые направленные остатки при делении на эти числа.

Доказательство. По китайской теореме об остатках существует такое $a$, что
$a \equiv r_1(\text{mod } m_1),$
$a \equiv r_2-1(\text{mod } m_2),$
$a \equiv r_n-n+1(\text{mod } m_n)$.

Но тогда числа $a, a+1, ..., a+n-1$ удовлетворяют условиям теоремы.
