Теорема 2. Пусть данные $n$ попарно взаимно простых чисел $m_1, m_2, ..., m_n$ и чисел $r_1, r_2, ..., r_n$ таких, что $0 \leqslant r_i \leqslant m_i-1$ ($i=1, 2, ..., n$). Тогда существует число $N$, дающее при делении на $m_i$ остаток $r_i$.

Иначе говоря $N \equiv r_i(\text{mod } m_i)$ при всех $i=1, 2, ..., n$.

Доказательство. Применим индекцию по $n$. При $n=1$ утверждение теоремы очевидно. Пусть теорема справедлива при $n=k$. Тогда существует число $M$ такое, что $M \equiv r_i(\text{mod } m_i)$ при $i=1, 2, ..., k$.

Пусть $d=m_1m_2...m_{k-1}$.

Рассмотрим числа
$M, M+d, M+2d, ..., M+(m_k-1)d$.

Поскольку $d$ взаимно просто с $m_k$, из доказательства теоремы 1 следует, что среди выписанных чисел найдется число $N$, дающее при делении на $m_k$ остаток $r_k$. В то же время при делении на $m_1, m_2, ..., m_{k-1}$ число $N$ дает остатки $r_1, r_2, ..., r_{k-1}$ соответственно.

Теорема доказана.
И, наконец, еще одна теорема.
Теорема 3. Для любых попарно взаимно простых чисел $m_1, m_2, ..., m_n$ и остатков $r_1, r_2, ..., r_n$ по модулю $m_1, m_2, ..., m_n$ найдется $n$ последовательных чисел $a, a+1, ..., a+n-1$ таких, что $a \equiv r_1(\text{mod } m_1), a+1 \equiv r_2(\text{mod } m_2), ..., a+n-1 \equiv r_n(\text{mod } m_n)$.

Иначе говоря, для любых попарно взаимно простых модулей $m_1, m_2, ..., m_n$ найдется $n$ подряд идущих натуральных чисел, дающих соответственную любые направленные остатки при делении на эти числа.

Доказательство. По китайской теореме об остатках существует такое $a$, что
$a \equiv r_1(\text{mod } m_1),$
$a \equiv r_2-1(\text{mod } m_2),$
$a \equiv r_n-n+1(\text{mod } m_n)$.

Но тогда числа $a, a+1, ..., a+n-1$ удовлетворяют условиям теоремы.
