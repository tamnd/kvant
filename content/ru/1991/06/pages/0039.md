Задание 1. Числа $7n+1$ и $8n+3$ делятся на некоторое натуральное число $d \neq 1$. Найдите $d$.

Решение. Поскольку $7(8n+3) - 8(7n+1) = 13$, число 13 делится на $d$, то $d = 13$ (т. к. $d \neq 1$, и 13 — простое число).

Сравнения по модулю
Давайте сразу условиями, что все числа, о которых поддет речь дальше, будут целыми, так что в последующем это не будет специально оговориться. Расмотрим еще одну задачу.

Задание 2. На какую цифру оканчивается число $2^{999}$?

Решение. Выпишем последовательные степени двойки:
2, 4, 8, 16, 32, 64,...
Легко видеть, что последние цифры этих чисел повторяются через 4, так что последняя цифра числа $2^n$ зависит только от того, какой остаток при делении на 4 дает показатель $n$. Поскольку $999=996+3=4 \cdot 249+3$, ответ в нашей задаче: 8.

В этом примере все множество показателей степени разбилось на 4 класса, состоящих из чисел $n$ вида $4k, 4k+1, 4k+2, 4k+3$.

Возбше, для любого натурального числа $m$ все целые числа (не только положительные!) разбиаются на $m$ классов. Каждый класс при этом состоит из чисел, дающих при делении на $m$ одинаковые остатки.

Вот эти классы:
0) числа $a$ вида $a=km$,
1) — а — а=km+1,
$m-1)$ — а — а=km+m-1.

Ясно, что любое число принадлежит одному из выписанных классов. При этом разность любых двух чисел из одного класса делится на $m$, а разность двух чисел из разных классов на $m$ не делится.

Определение. Если разность целых чисел $a$ и $b$ делятся на натуральное число $m$, то говорят, что $a$ и $b$ сравнимы по модулюм.

Записывается сравнимость чисел по модулюм $m$ так:

$a \equiv b(\text{mod } m)$.

Числа $a$ и $b$ сравнимы по модулюм $m$ тогда и только тогда, когда они принадлежат одному классу, т. е. дают одинаковые остатки при делении на $m$. Иначе говоря, $a \equiv b(\text{mod } m)$ означает, что $a=b+km$, где $k$ — целое число. Например, $27 \equiv 7(\text{mod } 10)$, $78 \equiv 6(\text{mod } 24)$, $6 \equiv 0(\text{mod } 3)$, $25 \equiv -4(\text{mod } 29)$.

Свойства сравнения
Сравнения по своим свойствам наполняют общие равенства:
1) если $a \equiv b(\text{mod } m)$ и $b \equiv c(\text{mod } m)$, то $a \equiv c(\text{mod } m)$.
2) $a+c \equiv b+d(\text{mod } m)$.
3) $a-c \equiv b-d(\text{mod } m)$.
4) $ac \equiv bd(\text{mod } m)$.
т. е. сравнения, как и общные равенства, можно складывать, вычитать и переменная.
