$$W_H = W_Q.$$

Конфигурация электрического поля в конечном состоянии изображена на рисунке 2. Видно, что из поля заряд $Q$ как бы вырезан сферический слой с радиусами $R_1$ и $R_2$. Поэтому понятно, что энергия электрического поля в конечном состоянии будет равна

$$W_K = W_Q - W_{R_1R_2},$$

где $W_{R_1R_2}$ — энергия электрического поля в сфериском слое с радиусами

$R_1$ и $R_2$. Эта энергия может быть подсчитана что называется «в люб» — плотность энергии поля нам известна, остается просуммировать (проинтеррировать) по всему объему сфериского слоя. Мы же воспользуемся полученным в задаче 1 выражением для энергии поля заряженного сфериского конденсатора:

$$W_{R_1R_2} = \frac{Q^2}{8\pi\varepsilon_0} \left( \frac{1}{R_1} - \frac{1}{R_2} \right).$$

Итак, совершенная в первом случае работа равна

$$A_I = W_K - W_H = \left( W_Q - W_{R_1R_2} \right) - W_Q = - W_{R_1R_2} = - \frac{Q^2}{8\pi\varepsilon_0} \left( \frac{1}{R_1} - \frac{1}{R_2} \right).$$

Рассмотрим теперь случай замещенной оболочки. Конфигурация поля, когда заряд $Q$ будет находиться в центре, изображена на рисунке 3. В этом случае на оболочку перечет отрицательный заряд, равный по величины $Q$. Этот заряд будет расположен на внутренней поверхности оболочки, и поле будет сосредоточено только внутри сферы радиусом $R_1$. Работа в этом случае будет равна

$$A_{II} = W_K - W_H = \left( W_Q - W_{R_1} \right) - W_Q = - W_{R_1} = - \frac{Q^2}{8\pi\varepsilon_0 R_1}.$$

Разумеется, этот результат можно было получить сразу из выражения для $A_I$, положив в нем $R_2 \rightarrow \infty$.
