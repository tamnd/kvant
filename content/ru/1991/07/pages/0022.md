6) Получите оценки для $k(n)$ для любого $n$. Известны оценки $(\sqrt{8n+1} + 1)/2 \leq k(n) \leq \sqrt{4n+5} - 1$. Постраайте доказать эти неравенства и, если можноете, найдите более точные оценки.

Задачи 1 и 2 похожи, как близены. Разница лишь в том, что в одном случае рассматривается окружность, а в другом — отрезок. Сразу возникнет идея перености все, что известно о задаче 2, на задачу 1.

Для краткости будем называть отрезок длины $n$, размещенный так, как требуется в условиях задачи 2, универсальной линейкой длины $n$.

В статье А. Савина «От школьной задачи — к проблеме» («Квант», №12, 1976) излагаюсь решение этой задачи. Оценка сверху — $k(n) \leq \sqrt{4n+5} - 1$ — получалась там из следующей конструкции универсальной линейки произвольной длины $n$:

$$\frac{1, 1, ..., 1}{m \text{ раз}}, \frac{m+1, m+1, ..., m+1}{l \text{ раз}}.$$

Если $n < m+l(m+1)$, то последний отрезок берется соответственно короче, чем $(m+1)$, при этом линейка остается универсальной.

Вскоре мне удалось для некоторых $n$ построить удачные конструкции линейки.

$$L_1 = \begin{cases} 1, 2, 2, 5, \\ 3, 1, 2 \end{cases}$$

$$L_2 = 1, 2, \begin{cases} 2, 2, 7, 7, \\ 5, 5, 1, 2, 2 \end{cases}$$

$$L_3 = 1, 2, 2, 2, \begin{cases} 2, 9, 9, 9, \\ 7, 7, 7, 1, 2, 2, 2 \end{cases}$$

$$L_l = 1, \begin{cases} 2, ..., 2, \\ (l+1) \text{ раз} \end{cases}$$

$$2l+1, ..., 2l+1, 1, \begin{cases} 2, ..., 2, \\ l \text{ раз} \end{cases}$$

Отрезок, заключенный в скобки, можно повторять несколько раз подряд, и линейка новой длины будет попрежнему универсальной.

Задача 3 (M400, «Квант» №8, 1976): Последовательность натуральных чисел $a_1, a_2, ..., a_k$ называем частями членов из нее можно получить любую последовательность из $n$ чисел, в которой каждое из чисел 1, 2, ..., $n$ входит по одному разу. Для произвольного $n$ указывается самую коротку $(n, k)$-учиверсную последовательность.

Примером (4,12)-учиверсную последовательности является такая: 1, 2, 3, 4, 1, 2, 3, 1, 4, 2, 1, 3.

В решении, приведенном в журнале, предположен способ построения некоторой конструкции универсальной последовательности, дающий такие оценки числа $k(n)$:

$$(n(n+1))/2 + n - 2 \leq k(n) \leq n^2 - 2n + 4.$$
