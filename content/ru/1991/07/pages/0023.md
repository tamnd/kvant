Задача 4 (новая). k точек делят окружность на k дуг, длины которых — натуральные числа. Разбиле окружности наvestем (n, k)-унверсальным, если вычеркивание части дуг из него можно получить любую последовательность из n дуг, в которой дуги с длинами 1, 2, ..., n входят по одному разу. Для произвольного числа n указыва минимальное k, для которого существует (n, k)-унверсальное разбиле окружности.

Оказалось, что предложенные в решении задачи M400 конструкция и оценки числа k(n) годятся и для задачи 4.

Задача на исследование. Построение некоторых (n, k)-унверсальных разбиле окружности позволяет предположить, что k(n)=k²/2, если n — четно, и k(n)=(k²-1)/2, если n — нечетно. Доказите или проверите это предположение.

Двоичные родственники универсальной линейки

Ими оказались два варианта задачи M574 («Квант», № 7, 1979):

Задача 5. Конечная последовательность a₁, a₂, ..., aₙ из чисел 0 и 1 должна удовлетворять следующему условию: для любого целого k от 1 до n-1 сумма C(k)=a₁aₙ+a₂aₙ+aₙ-kaₙ является нечетным числом. Доказите, что такая последовательность существует для неотгораного n<1000.

Задача 6 (M574, колцевой вариант). Указите значения n, для которых существует такая последовательность a₁, a₂, ..., aₙ из расположенных по окружности чисел 0 и 1, у которой при любом k(1≤k≤(n-1)) сумма поарных произведений членов, отстоящих на k, т. е. C(k)=a₁aₙ+a₂aₙ+...+aₙ-kaₙ, нечетна.

Задача 5 полностью решена. В ее решении («Квант» № 6, 1980) не только указываются все значения n, для которых существует исключая двойная последовательность (назовем ее для краткости n-последовательностью), но и дается несколько способов ее построения.

Приведу (без доказательства) один из них.

Пусть A=a₁, a₂, ..., aₙ — некоторая последовательность, удовлетворяющая условию задачи (например, A=1101). Тогда и последовательность B=A 00...0 A 00...0 A=b₁, ..., b₇n-3, состоящая из трех наборов A и двух наборов нулей между ними, также ему удовлетворяет. В нашем случае B=1101 000 1101 000000000 1101.

Решение задачи 6 неизвестно.
