Teorema Виета и вспомогательный многочлен

Л. Д. КУРЛЯНДЧИК,
кандидат физико-математических наук
С. В. ФОМИН

Мноше задачи так или иначе сводятся к нахождению корней алгебраических уравнений. Но бывают — и об этом пойдет речь в нашей стране, — что для решения задачи полезно, наоборот, построить многочлен, корнями которого является данные, известные числа. Прием, связанный с введением вспомогательного многочлена, позволяет нам решить несколько совсем разных на вид задачи. Средние их — задачи М879 и М882 из Задачика «Кванта» и одна из задач последней международной олимпiadы.

Пусть $u$ и $v$ — два действительных числа. Как построить квадратный трехчлен, корнями которого является $u$ и $v$? Проще всего — рассмотреть многочлен
$$P(t)=(t-u)(t-v)=t^2+pt+q.$$
Его коэффициенты равны:
$$p=-(u+v), q=uv,$$
(1) то есть сумме (со знаком минус) и произведение исходных чисел. Формулы (1) называются формулами Виета. С ним связаны две теоремы из школьного учебника:
если квадратное уравнение $t^2+pt+q=0$ имеет корни $u$ и $v$, то выполняется равенства (1) (теорема Виета);
числа $u$ и $v$ являются корнями квадратного уравнения $t^2-(u+v)t+uv=0$ (обратная теорема).
Приведем несколько примеров применения обратной теоремы Виета. Начнем с совсем простой задачи.
Задача 1. Составьте квадратное уравнение с целыми коэффициентами, корнем которого является число $2+\sqrt{3}$.
Решение этой задачи, как и многих других, может быть основано на том, что квадратное уравнение с «сопряженными» корнями $a+b\sqrt{d}$ и $a-b\sqrt{d}$ (где $a, b$ и $d$ — целые числа) имеет

целые коэффициенты*). Этот факт, разумется, сразу следует из формул Виета (1).

Итак, искomme уравнение имеет корни $t_1=2+\sqrt{3}$ и $t_2=2-\sqrt{3}$, поэтому его коэффициенты равны: $p=-(t_1+t_2)=-4$, $q=t_1t_2=1$.

Ответ: $t^2-4t+1=0$.

Задача 2. Является ли число $t_1=\sqrt{37}-\sqrt{20}$ решением неравенства $t^2+9t-17>0$?

Решение. Составим квадратное уравнение, корнями которого является числа $t_1$ и $t_2=-\sqrt{37}-\sqrt{20}$:
$$t^2+2\sqrt{20}t-17=0.$$
Поскольку $2\sqrt{20}=\sqrt{80}<9$, справедливо неравенство $t_1^2+9t_1-17>t_1^2+2\sqrt{20}t_1-17=0$.

Ответ: число $t_1$ является решением данного неравенства.

Вычисление значения функций в данной точке часто упрощается, если предварительно построить многочлен, который в этой точке обращается в нуль. Вот типичный пример.

Задача 3. Вычислить $u^4-5u^3+6u^2-5u$, если $u=2+\sqrt{3}$.

Решение. Вспомним результат задачи 1: $u^2-4u+1=0$ или $u^2=4u-1$. Используя это соотношение, выразим линейно через $u$ степени $u^3$ и $u^4$:
$$u^3=u^2\cdot u=(4u-1)u=4u^2-u=4(4u-1)-u=15u-4,$$
$$u^4=u^3\cdot u=(15u-4)u=15u^2-4u=15(4u-1)-4u=56u-15.$$
Отсюда $u^4-5u^3+6u^2-5u=56u-15-5(15u-4)+6(4u-1)-5u=-1$.

Ответ: —1.

Действuyа так же, как в приведенном решении, можно значение любого многочлена с целыми коэффициентами в точке $u=a+b\sqrt{d}$ представить в виде $ku+l$ ($a, b, d, k, l$ — целые числа).
Задача 4. Доказать, что число $(7+\sqrt{48})^{13}+(7-\sqrt{48})^{13}$ целое и делится на 14.

Решение. Числа $u=7+\sqrt{48}$ и $v=7-\sqrt{48}$ являются корнями квадратного трехчлена $t^2-14t+1$. Используя формулы $u^2=14u-1$ и $v^2=14v-1$, получим «рекуррентное соотношение» для величины $a_n=u^n+v^n$:

* (Много красивых примеров, связанных с этой идеей, читатель найдет в статье Н. Вагутена «Сопряженные числа» (Квант, 1980, № 2, c. 26).

$$a_0 = 2$$
$$a_1 = u + v = 14$$
$$a_2 = u^2 + v^2 = (14u - 1) + (14v - 1) = 14a_1 - a_0$$
$$a_3 = u^3 + v^3 = u(14u - 1) + v(14v - 1) = 14a_2 - a_1$$
$$a_n = u^n + v^n = u^{n-2}(14u - 1) + v^{n-2}(14v - 1) = 14a_{n-1} - a_{n-2}.$$

Из этих соотношений следует, что все числа $a_n$ целые. Кроме того, если $n$ нечетно, то $a_n$ делится на 14. Доказать это утверждение можно по индукции: если $a_{n-2}$ делится на 14, то и $a_n$ делится на 14.

Задача 5. Найти $u^8 + \frac{1}{u^8}$, если $u = \sqrt{2} + 1$.

Формулы Виета, аналогичные формулам (1) для квадратного трехчлена, можно выписать и для многочлена $n$-ой степени

$$P(t) = (t - x_1)(t - x_2) \dots (t - x_n) = t^n + a_1 t^{n-1} + a_2 t^{n-2} + \dots + a_n$$

с корнями $x_1, \dots, x_n$. Для этого нужно раскрыть скобки, привести подобные члены и приравнять коэффициенты при одинаковых степенях $t$ в левой и правой части.

Напишем эти формулы в явном виде для многочлена третий степени

$$P(t) = (t - x)(t - y)(t - z) = t^3 + pt^2 + qt + r$$

с корнями $x, y$ и $z$:

$$p = -x - y - z$$
$$q = xy + yz + zx$$
$$r = -xyz$$

Тепер перейдем к наиболее интересным примерам применения вспомогательного многочлена — они связаны именно с тем случае, когда многочлен строится по нескольким (не менее, чем трех) корням.

Задача 6. Числа $x, y, z$ удовлетворяют соотношям:

$$x + y + z = a, \frac{1}{x} + \frac{1}{y} + \frac{1}{z} = \frac{1}{a}.$$

Докажите, что хотя бы одно из этих чисел равно $a$.

Решение. Приимем формулы (2). В нашем случае $p = -a$, $q = xyz/a = -r/a$. Поэтому

$$P(t) = t^3 - at^2 - \frac{r}{a} t + r = (t - a)\left(t^2 - \frac{r}{a}\right).$$

Следовательно, число $a$ является корнем многочлена $P(t)$ и значит, совпадает с одним из чисел $x, y, z$.

Задача 7. (М882) Сумма трех целых чисел $u, v$ и $w$ равна нулю. Докажите, что число $2u^4 + 2v^4 + 2w^4$ — квадрат целого числа.

Решение. Пусть $P(t) = t^3 + pt^2 + qt + r$ — многочлен, корнями которого является числа $u, v$ и $w$. В силу теоремы Виета, $p = -(u + v + w) = 0$. Имеем:

$$u^3 + qu + r = 0$$
$$v^3 + qv + r = 0$$
$$w^3 + qw + r = 0.$$

Чтобы получить выражение, функрирующее в условиях, домножим эти уравнения на $2u, 2v$ и $2w$ соответственно и сложим:

$$2u^4 + 2v^4 + 2w^4 + 2q(u^2 + v^2 + w^2) = 0$$

(мы используем то, что $u + v + w = 0$). Но $u^2 + v^2 + w^2 = (u + v + w)^2 - 2q = -2q$, поэтому $2u^4 + 2v^4 + 2w^4 = (2q)^2$.

Сходным образом решается и передко включаемая задача токдеством

$$x^3 + px^2 + qx + r = 0$$
$$y^3 + py^2 + qy + r = 0$$
$$z^3 + pz^2 + qz + r = 0$$,

а затем воспользовемся формулами Виета (2) и уже встречшимся в предыдущей задаче токдеством

$$x^2 + y^2 + z^2 = (x + y + z)^2 - 2(xy + yz + zx) = p^2 - 2q.$$

Получим

$$x^3 + y^3 + z^3 + p(p^2 - 2q) - qp + 3r = 0,$$

откуда

$$x^3 + y^3 + z^3 - 3xyz = -p(p^2 - 3q) = (x + y + z)(x^2 + y^2 + z^2 - xy - yz - zx)$$.

Замечание. Выражение $x^2 + y^2 + z^2 - xy - yz - zx$ неотрицательно (поскольку $(x - y)^2 + (y - z)^2 + (z - x)^2 \geq 0)$. Поэтому из доказанного токдествства вытекает неравенство

$$\frac{a + b + c}{3} \geq \sqrt[3]{abc}$$

(3)

для среднего арифметического и среднего геометрического трех неотрицательных чисел: достаточно положить в этом токдестве $x = \sqrt[3]{a}$, $y = \sqrt[3]{b}$, $z = \sqrt[3]{c}$.

Посмотрим теперь, как можно использовать вспомогательный многочлен при решении системы уравнений.

Задача 9. Решить систему

$$\begin{cases} x + y + z = 2 \\ x^2 + y^2 + z^2 = 14 \\ x^3 + y^3 + z^3 = 20. \end{cases}$$

Решение. Следуя на шему методу, введем многочлен

$$P(t) = (t - x)(t - y)(t - z) = t^3 + pt^2 + qt + r.$$

По теореме Виета

$$p = -(x + y + z) = -2$$
$$q = xy + yz + zx = \frac{(x + y + z)^2 - (x^2 + y^2 + z^2)}{2} = -5.$$

Для нахождения коэффициента $r$ домножим уравнения системы на $q$, $p$ и $1$ соответственно и сложим. Поскольку $P(x) = P(y) = P(z) = 0$, получим:

$$-3r = 2q + 14p + 20 = -10 - 28 + 20 = -18.$$

Итак, $P(t) = t^3 - 2t^2 - 5t + 6$. Это — многочлен с целыми коэффициентами, причем его старший коэффициент равен 1. Поэтому любой целый коэффициент равен $P(t)$ должен быть делителем свободного числа. В данном случае все три корня целые (и нахождение среди делителя числа 6) — это 1, -2, и 3$^*$). Таким образом, $\{x, y, z\} = \{1, -2, 3\}$.

$\cdot$) В принципе достаточно уладать — или найти перебор — хотя бы один корень, а затем использовать разложение на многочлен. Подробнее об этом применяем расссказано в статье С. В. Фомина «Разложение на многочлен» (Квант, 1983, № 7, с. 23).
