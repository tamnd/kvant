М877. Из листа клецчатой бумаги размеры 29×29 клеtok вырезали 99 квадратков размеры 2×2 каждый. Докажите, что из него можно вырезать еще один квадратик.

На рисунке серым цветом закрашены 100 квадратков 2×2. Вырезая из исходного квадрата 29×29 любой квадратик 2×2, мы «задеваем»ровно один квадратик. Следовательно, после 99 таких операций один из серых квадратков останется нетронутым.

С. В. Фомин

М878. Докажите, что если сумма плоских углов при вершине парамды больше 180°, то каждое боковое ребро парамды меньше полуперimetра ее основания.

Пусть $SA_1 \dots A_n$ — данная парамида. Разрежем ее боковую поверхность по ребру $SA_1$ и развернем ее на плоскость (см. рисунок, на котором $SA_1$ и $SA_1'$ — это два экземпляра ребра $SA_1$, образовавшиеся в результате разрезания, так что $|SA_1| = |SA_1'|$). Из условия задачи следует, что точка $S$ лежит внутри многоугольника $A_1 \dots A_nA_1'$. Продолжая отрезок $A_1'$ $S$ за точку $S$ до пересечения с ломаной $A_1 \dots A_nA_1'$, мы получим точку $B$, разбиивающий ломаню на две части: ломаную $A_1 \dots B$ длины $a$ и ломаную $A_1' \dots B$ длины $b$. Из неравенств $|SA_1| < a + |SB|$, $|A_1'S| + |SB| = |A_1'B| < b$ следует, что $2|SA_1| = |SA_1| + |SA_1'| < a + |SB| + |A_1'S| = a + b = |A_1A_2| + ... + |A_{n-1}A_n| + |A_nA_1'|$.

Остается заметить, что в правой части стопперметр основания парамиды.

Ю. И. Ионин

М880*. В последовательности 1, 0, 1, 0, 1, 0, ... каждый член, начняя с седьмого, равен последней цифре суммы предыдущих. Докажите, что в этой последовательности не встречается подряд шесть чисел 0, 1, 0, 1, 0, 1.

Эту задачу схематически можно представить так: задано преобразование некоторого множества (множества шестерок чисел; шестерке $(x_1, \dots, x_6)$ сопоставляется $(x_2, \dots, x_6, x_7)$, где $x_7$ — последняя цифра суммы $x_1 + \dots + x_6$); требуется доказать, что повторяя это преобразование, из одной данной «точки» множества (шестерки $(1, 0, 1, 0, 1, 0)$) нельзя получить другую (шестерку $(0, 1, 0, 1, 0, 1)$). Очень часто такие задания решения решить, найдая инвариант, то есть величину, не изменяющего при заданном преобразовании: достаточно установить, что значение инварианта для двух данных «точек» различны *).

В нашем случае такой величины может служить последняя цифра числа $s(x_1, \dots, x_6) = 2x_1 + 4x_2 + 6x_3 + 8x_4 + 10x_5 + 12x_6$. В самом деле, просто вычисление показывает, что разность $s(x_2, \dots, x_7) - s(x_1, \dots, x_6)$ (далее цифра $x_1 + \dots + x_6$) равна $10x_7 + 2(x_7 - (x_1 + \dots + x_6))$, то есть окончательно нулю.

*) Об инвариантах мы расссказывали неоднократно: см., например, статью А. Ходулева «Расселенение физек» («Квант», 1982, № 7, c. 28); там же приводятся ссылки и на другие статьи по этой теме. Ряд задач на инварианты можно найти в «Кванте» № 10 за 1983 г. на с. 30.
