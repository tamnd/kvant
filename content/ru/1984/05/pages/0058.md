Математика
Писменный экзамен
Вариант 1
1. Вычислите
$$1 + \frac{\pi}{6} + \frac{\pi}{6} + \dots + \frac{\pi}{6} + \dots$$
2. Решите уравнение
$$2 \cos 2x \cdot \cos 5x = \cos 7x + \frac{1}{2}$$
3. Решите уравнение
$$25^{-x} + 5^{1-x} = 50$$
4. Найдите область определения функций
$$f(x) = \sqrt{1 + \log_3 \frac{1}{x}}$$
5. Дан куб $ABCDA_1B_1C_1D_1$ с ребром $a$. Найдите радиус сферы, проходящий через вершины $A$ и $B_1$ и точки $K$ и $M$ на ребре $CC_1$ также, что $|CK| = |KM| = |MC_1|$.
Вариант 2
1. Число 108 представить в виде произведения двух положительных чисел так, чтобы сумма куба одного из них с квадратом другого была наименьшей.

$$\sin 5x - \cos \left(x + \frac{5\pi}{2}\right) = \sin \left(2x - \frac{\pi}{2}\right)$$

$$\frac{4}{2^x - 3} = 2^x$$
4. Решите неравенство
$$\frac{\log_3(4-x)}{x-2} < 0$$

1. 2. Преграда массой $M = 10$ кг, имеющая цилиндрический раздиус $R = 0,2$ м, расположена на горизонтальной плоскости (рис. 1). 3. На идеальном гладкой горизонтальной плоскости расположен брусок массой $M = 1$ кг, скрепленный с пружинами, жесткость каждой из которых $k = 30$ Н/m (рис. 2). Ускорение свободного падения $g = 10$ м/c².
4. Идеальная тепловая машина, работающая при нормальных условиях окружающей воздуха, который для нее является холодильником, поднимает груз массой $m = 400$ кг. Работее тело машины получает от нагреваляя с температурой $t = 200^\circ C$ количество теплоты $Q = 80$ кДж. На какую максимальную высоту поднимает груз эта тепловая машина? Тренем претенбрец. Ускорение свободного падения $g = 10$ м/c².

Система может только врашать в горизонтальной плоскости вокруг вертикальной оси, проходящей через середину стержня. Масса и модель заряда шарика равны $m = 5$ г и $q = 10^{-6}$ Кл. Определите максимальный угол повората этой системы. Массой стержня претенбрец. Шарики рассматриваются как материальные точки.
