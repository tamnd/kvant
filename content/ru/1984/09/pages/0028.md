Пример 3 (КПИ, 1980). Упростить:
$$\frac{\sin^4 \alpha + \cos^4 \alpha - 1}{\sin^6 \alpha + \cos^6 \alpha - 1}.$$
Решение:
$$\frac{\sin^4 \alpha + \cos^4 \alpha - 1}{\sin^6 \alpha + \cos^6 \alpha - 1} = \frac{\sin^4 \alpha + \cos^4 \alpha + 2 \sin^2 \alpha \cos^2 \alpha - 2 \sin^2 \alpha \cos^2 \alpha - 1}{\sin^4 \alpha + \cos^4 \alpha + 2 \sin^2 \alpha \cos^2 \alpha - 3 \sin^2 \alpha \cos^2 \alpha - 1} = \frac{(\sin^2 \alpha + \cos^2 \alpha)^2 - 2 \sin^2 \alpha \cos^2 \alpha - 1}{(\sin^2 \alpha + \cos^2 \alpha)^2 - 3 \sin^2 \alpha \cos^2 \alpha - 1} = \frac{2}{3}.$$
Решение уравнения
При решении irrationalных уравнений не следует торопиться возводить в квадрат, стоит посмотреть — нельзя ли его выделить?
Пример 4 (КПИ, 1979). Решить уравнение:
$$\sqrt{x-2} + \sqrt{2x-5} + \sqrt{x+2+3\sqrt{2x-5}} = 7\sqrt{2}.$$
Решение:
Имеем
$$\frac{1}{\sqrt{2}}(\sqrt{2x-5} + 2\sqrt{2x-5} + 1) + \sqrt{2x-5} + 6\sqrt{2x-5} + 9) = \frac{1}{\sqrt{2}}(\sqrt{(\sqrt{2x-5}+1)^2} + \sqrt{(\sqrt{2x-5}+3)^2} = \frac{1}{\sqrt{2}}(|\sqrt{2x-5}+1| + |\sqrt{2x-5}+3|).$$
Итак, заданное уравнение эквивалентно уравнению
$$\frac{1}{\sqrt{2}}(\sqrt{2x-5} + 1 + \sqrt{2x-5} + 3) = 7\sqrt{2}$$
или $2\sqrt{2x-5} = 10$, откуда $x = 15$.
Пример 5 (КГУ, экон. фак. 1978). Решить уравнение:
$(\sqrt{4+2\sqrt{3}} - \sqrt{4-2\sqrt{3}})^{2x} + 2^{2x+3} = 144.$
Решение:
Имеем
$$\sqrt{4+2\sqrt{3}} = \sqrt{3+2\sqrt{3}} + 1 = \sqrt{(\sqrt{3}+1)^2} = \sqrt{3}+1;$$
аналогично $\sqrt{4-2\sqrt{3}} = \sqrt{3}-1$. Поэтому заданное уравнение примет вид
$$4^x + 8\cdot 4^x = 144, x = 2.$$
Пример 6 (МГУ, 1978, филфак). Число $\alpha$ подобрано так, что уравнение $\sqrt{x-\sqrt{3}} + \alpha^2 x^2 + 2\alpha x(\sqrt{6}-\sqrt{3}) = 6\sqrt{2}-9$ имеет решение. Найти решение.
Решение: Обозначим $x_1$ корень уравнения. Тогда $x_1 \neq 0$ и $\sqrt{x_1-\sqrt{3}} + \alpha^2 x_1^2 + 2\alpha x_1(\sqrt{6}-\sqrt{3}) - 6\sqrt{2}+9 = 0$, или
$$\alpha^2 + 2\alpha \left(\frac{\sqrt{6}-\sqrt{3}}{x_1}\right) + \frac{\sqrt{x_1-\sqrt{3}} + 9 - 6\sqrt{2}}{x_1^2} = 0.$$
Выделим полный квадрат относительно чисел $x_1$ и $\alpha$. Имеем
$$\left(\alpha + \frac{\sqrt{6}-\sqrt{3}}{x_1}\right)^2 + \frac{\sqrt{x_1-\sqrt{3}}}{x_1^2} = 0.$$
Так как каждое слагаемое не отрицательно, то $x_1 = \sqrt{3}$, при этом $\alpha = 1 - \sqrt{2}$.
Пример 7. Решить уравнение $\sin^2 x + \sin^2 y = \sin x \sin y + \sin x \sin y - 1.$
Решение: Данное уравнение эквивалентно такому:
$(\sin^2 x - 2 \sin x + 1) + (\sin^2 y - 2 \sin y + 1) + (\sin^2 x + \sin^2 y - 2 \sin x \sin y) = 0$, или $(\sin x - 1)^2 + (\sin y - 1)^2 + (\sin x - \sin y)^2 = 0$, откуда $x = \sin y = 1$, $x = \sin y$. Таким образом, решение уравнения будет любая пара вида
$$x = \frac{\pi}{2} + 2\pi k, y = \frac{\pi}{2} + 2\pi n, k, n \in Z.$$
