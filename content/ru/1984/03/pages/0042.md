**M837***. Пусть $a, b, c$ — целые положительные числа, каждые два из которых взаимно просты. Докажите, что наобольшее из целых чисел, которые не представимы в виде

$$xbc + yca + zab$$

(еде $x, y, z$ — неотрицательные целые числа), равно

$$2abc - ab - bc - ca.$$

$$u = a_1a_2\dots a_n \left( \frac{x_1}{a_1} + \dots + \frac{x_n}{a_n} \right),$$

(1)

(В нашей задаче $n = 3$.)

Оно из самых коротких решений этой задачи опирается на следующее два утверждения:

1) любое целое число $u$ допускает единственное представление (1), где $x_1, x_2, \dots, x_n$ — целые числа, причем $0 \leq x_2 \leq a_2 - 1$, ..., $0 \leq x_n \leq a_n - 1$, $x_1$ может быть любым (такое представление мы будем называть стандартным);

2) целое число $u$ — красное тогда и только тогда, когда в его стандартном представлении $x_1 \geq 0$.

Из последнего утверждения ясно, что наобольшее число $m$ имеет стандартное представление $c x_1 = -1$, $x_2 = a_2 - 1$, ..., $x_n = a_n - 1$, то есть

$$m = a_1a_2\dots a_n \left( n - 1 - \frac{1}{a_1} - \dots - \frac{1}{a_n} \right).$$
