Кубическая парабола
Академик Л. С. ПОНТРЯГИН

Для понимания этой статьи нужно уметить вычислять производуную многочлен и знать теорему о том, что если функция $f(x)$, заданная на отрезке $a_1 \leq x \leq a_2$, имеет положительное производу на интервале $a_1 < x < a_2$, при этом быть может имеет производуную равную нулю в концах отрезка, то она возвращает на всем отрезке $a_1 \leq x \leq a_2^*$).

Так что для двух точек $x_1, x_2$, удовлетворяющих условию

$$a_1 \leq x_1 < x_2 \leq a_2$$

(1)

имеет место неравенство

$$f(x_1) < f(x_2).$$

(2)

*) «Алгебра и начала анализа 9—10», п. 25.

Же и для убывания функции в случае отрицательной производной.

Кроме того нужно знать, что такое вторая и третья производы функции $f(x)$. Вторая производана $f''(x)$ есть производаная от производной функции $f(x)$, то есть задается формулой

$$f''(x) = \left(f'(x)\right)'.$$

(3)

Третья производана $f'''(x)$ функция $f(x)$ есть производаная от второй производной, то есть задается формулой

$$f'''(x) = \left(f''(x)\right)'.$$

(4)

Стайя посвящена изучению графика функции

$$y = g(x) = x^3 + a_1x^2 + a_2x + a_3.$$

(5)

Этот график называется кубической параболой.

Рассмотрим прежде всего кубическую парабoly частного вида

$$y = f(x) = x^3 - px,$$

(6)

где $p$ — постоянная. Гraphik этой функции (рис. 1) обозначает через $L$.
