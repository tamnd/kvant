Автор задачи M748 А. Кузьминых и неокотые другие читательы обратили внимание на неточности в изображении решений этой задачи. Приведем краткое решение, в котором более четко выделена основная идея. Речь идет о таком утверждении (пункт 6) задачи): если несколько конусов в пространстве попарно не пересекаются, то их нельзя переведить так, чтобы они покрыли все пространство. (Здесь конус — тело, полученное врашением угла, меньшего развернутього, вокруг биссеррицы.) Идея решения — рассмотреть множество всех направлений в пространстве. Будем каждому направлению сопоставлять луч с началом в фиксированной точке O. Еще лучше: возьмем сферу (скажем, радиуса 1) с центром в точке O — каждой ее точки M отвечает определение направление OM в пространстве. Каждый конус K отвеяет «шапочка» на сфере — пересечение сферы с конусом K₀, полученным из K параллельным пересном вершины в точку O; при этом для любой точки M внутри K₀ лучше направления OM пересекает конус K по некоторому лучу, а для точки M вне K₀ — на более чем по отрезку (быть может, вовсе не пересекает K); чтобы убедиться в этом, полезно проектировать плоскость через луч OM и вершину конуса K. Если два конуса в пространстве не пересекаются, то соответствующие им шапочки на сфере направления также не могут иметь общих внутренних точек: для такой точки M луч OM должен был бы пересекаться с каждой из двух конусов по лучу, то есть конусы должны были бы иметь общий луч. Таким образом, шапочки для данных в условиях конусов в сумме имеют площадь, меньше площади сферы, поэтому как бы мы ни дивали конуса, шапочки не смогут покрыть сферу. Но для любой непокрытой или точки M луч OM пересекается с каждой из (переведенных) конусов не более чем по отрезку, так что конусы не покрыют пространство.

Наш читатель из Болгарии Иван Топов (София) получил окончательный результат, связанный с таким вопросом: при каких натуральных n>1 можно 2n точек, делящих окружность на 2n равных дуг, соединить попарно n хордами различной длины? В решении задачи M789 («Квант», 1983, № 5, с. 46) из сообщений четырехности было выведено, что при n=4m+2 и n=4m+3 это сделать нельзя, и высказываясь гипотеза, что при других n — можно; это и доказал И. Топов. Вот его построение. Для n=4m занумерем все 2n=8m точек по порядку (скажем, по часовой стрелке) чисlamи от 1 до 4m:

$$4m, 4m-2, 4m-4, ..., 4, 2; \quad 4m-1; \quad 2, 4, ..., 4m-2, 4m;$$

$$4m-3, 4m-5, ..., 2m+3;$$

$$2m-1, ..., 5, 3; \quad 2m+1; \quad 4m-1; \quad 3, 5, ..., 2m-1; \quad 1; \quad 1;$$

$$2m+3, ..., 4m-3; \quad 2m+1.$$

Тогда каждый номер k≤4m будет приписан двум точкам, между которых (по более короткой дуг окружности) стоитровно k-1 точек. Аналогичным образом, для n=4m+1 годится нумерация; 4m-2, 4m-4, ..., 6, 2; 4m; 2, 4, ..., 4m-2; 2m+1; 4m+1, 4m-1, ..., 2m+3; 2m-1, ..., 5, 3; 2m+1; 3, 5, 2m-1; 1, 1; 2m+3, ..., 4m-1, 4m+1. (См. рисунки для m=3.)
