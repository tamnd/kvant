**M837***. Пусть $a, b, c$ — целые положительные числа, каждые два из которых взаимно просты. Докажите, что наобольшее из целых чисел, которые не представимы в виде

$$xbc + yca + zab$$

(еде $x, y, z$ — неотрицательные целые числа), равно

$$2abc - ab - bc - ca.$$

Удобно рассматривать сразу более общую задачу:

пусть $a_1, a_2, \dots, a_n$ — натуральные поларно взаимно простые числа. Наовем натуральное число $u$ «красным», если его можно представить в виде

$$u = a_1a_2\dots a_n \left( \frac{x_1}{a_1} + \dots + \frac{x_n}{a_n} \right),$$

(1)

еде $x_1, x_2, \dots, x_n$ — целые неотрицательные числа, $u$ «синим» — в противном случае. Каково наобольшее число число?

(В нашей задаче $n = 3$.)

Оно из самых коротких решений этой задачи опирается на следующее два утверждения:

1) любое целое число $u$ допускает единственное представление (1), где $x_1, x_2, \dots, x_n$ — целые числа, причем $0 \leq x_2 \leq a_2 - 1$, ..., $0 \leq x_n \leq a_n - 1$, $x_1$ может быть любым (такое представление мы будем называть стандартным);

2) целое число $u$ — красное тогда и только тогда, когда в его стандартном представлении $x_1 \geq 0$.

Из последнего утверждения ясно, что наобольшее число $m$ имеет стандартное представление $c x_1 = -1$, $x_2 = a_2 - 1$, ..., $x_n = a_n - 1$, то есть

$$m = a_1a_2\dots a_n \left( n - 1 - \frac{1}{a_1} - \dots - \frac{1}{a_n} \right).$$

Докажем эти утверждения по индукции, начиная со случая $n = 2$. В этом случае 1) превращается в такую очень полезную lemma (ниже $a_1 = a, a_2 = b$):

если натуральные числа $a$ и $b$ взаимно просты, то любое целое и единственный образом представляется в виде

$$u = bx + ay,$$

(2)

еде $x, y$ — целые, $0 \leq y \leq b - 1$.

Для ее доказательства заметим, что все остки от деления $b$ чисел $0, a, 2a, \dots, (b - 1)a$ на $b$ различны (в противном случае оказалось бы, что какое-то число вид $(k - l)a$, где

⟦folio 41⟧

0 ≤ l < k ≤ b - 1, делится на b, а это невозможно), и следовательно,ровно одно из них, ay, дает такой же остаток, как и число u,то есть u - ay = bx при некоторых целях x и y, 0 ≤ y ≤ b - 1.

Утверждение 2) при n = 2 почти очевидно: если число u красное, то есть имеет представление (2) с x ≥ 0, y ≥ 0, то и в его стандартном представлении коэффициент при b будет неотрицательен (если y = qb + r, где q ≥ 0, 0 ≤ r ≤ b - 1, то u = bx + ay = b(x + aq) + ar).

Таким образом, в этом случае наиболее снимим число будет m = b · (-1) + a · (b - 1) = ab - a - b.

Покажем теперь, как с помощью этой же леммы сделать переход от n = 2 к n = 3 (тем самым задача M837 будет решена; в общем случае переход от n к n + 1 совершается аналогично). Перешем представление вида (1) числа u, как показано на полях. Поскольку c и ab взaimно просты, по лемме можно найти (причем единственным образом) целые v и z, 0 ≤ z ≤ c - 1, такие что u = cv + abz, а затем — x и y, 0 ≤ y ≤ b - 1, такие что v = bx + ay. Это доказывает утверждение 1) для n = 3. Для доказательства 2) достаточно заметить, что красным u отвечают красные v, а стандартному представлению u — стандартное представление v, в котором x ≥ 0.

На рисунке отмечены красные и сине числа для a = 2, b = 3, c = 5; здесь m = 29. Видно, что они располагаются симметрично относительно точки m/2; если u — красное число, то m - u — сине. Из нашей решения нетрудно вывести, что так будет и в общем случае (при любых a, b, c): красные числа — это всевозможные значения функции u(x,y,z) = bcx + cay + abz на множестве точек пространства с целыми координатами (x, y, z), где x ≥ 0, 0 ≤ y ≤ b - 1, 0 ≤ z ≤ c - 1, сине — ее значения на множестве x ≤ -1, 0 ≤ y ≤ b - 1, 0 ≤ z ≤ c - 1. Эти множества симметрины, а функция u — линейная, поэтому и ее значения на этих множествах расположены симметрично.

Было бы интересно исследовать аналогичные задачи для представления целых чисел в виде Ax + By + Cz с любыми взаимно простыми коэффициентами A, B, C.

M838. Все точки, лежащие на сторонах правильного треугольника ABC, разбиты на два множества E1 и E2. Верно ли, что для любого такого разбения в одном из множества E1 и E2 найдется трейка вершин прямого треугольника?

ОТВЕТ: верно. Доказательство проведем от противного. Пусть точки множества E1 окружены с ним цветом, множества E2 — красным. Предположим, что не существует прямого треугольника с однозвесными вершинами, и рассмотрим правильный шестугольник, вписанный в треугольник ABC (см. рисунок). Каждые две его противоположные вершины должны быть окрашены по-разному — если, например, противоположные вершины P и Q сине, то любая из остальных четырех вершин должны быть красной, так как образует вместе с P и Q прямой треугольник; но тогда любые три из этих красных точки образуют запрещенный однозвесный прямой треугольник.

Ясно, что в таком случае найдет две coseдние разноветные вершины шестугольника. Любо эти две вершины, либо противоположные им (то же разноветные!) лежат на одной из сторон треугольника. Пусть для определения на стороне AB лежат слияя вершина K и красная L, тогда противоположные им вершины K1 и L1 будут красной и сине (см. рисунок). Но тогда в какой бы цвет ни была окрашена вершина A, один из противоположных треугольников AKL1 и ALK1 будет однозвесным. Противоречие.

Это рассужждение показывает, что даже множество из восемми точки — вершин шестугольника и любых двух вершин треугольника — нельзя на подмножества без прямого треугольников.

Ляоцих арифметической процедсии (то есть ни одной тройки $a, b, c$, в которой $a + c = 2b$)?

Не является средним арифметическим двух других). Докажем, что из множества $1, 2, \dots, 5 \cdot 3^k$ ($k \geqslant 0$) можно выбрать «хорошое» подмножество $X_k$, состоящее из $4 \cdot 2^k$ чисел.

На рисунке показаны первые шаги индуктивного построения нужного множества: $X_0 = \{1, 2, 4, 5\}$, а $X_{k+1} = X_k \cup Y_k$, где множество $Y_k$ получается из $X_k$ сдигром на $2a_k$, $a_k$ — наиболее число в $X_k$. Таким образом, $a_{k+1} = 3a_k$ и $a_k = 5 \cdot 3^k$, то есть $X_k \subset \{1, 2, \dots, 5 \cdot 3^k\}$, кроме того, на каждом шаге количество чисел в нашем «хорошем» множестве удаливается, то есть $X_k$ состоит из $4 \cdot 2^k$ чисел. Докажем по индукции, что все множества $X_k$ «хорошие». Для $X_0$ это очевидно. Проверим, что среднее арифметическое двух чисел из $X_{k+1}$ не входит в $X_{k+1}$. Посольку по предположению индукции множества $X_k$, а с ним и $Y_k$, «хорошее», можно считать, что одно из этих чисел, $x$, содержится в $X_k$, а другое, $y$, — в $Y_k$. Тогда $0 < x \leqslant a_k$, $2a_k < y \leqslant 3a_k$, поэтому $a_k < (x + y)/2 \leqslant 2a_k$, но числа от $a_k + 1$ до $2a_k$ по построению не входят в $X_{k+1}$.

Остается заменить, что множество $X_9$ содержит $4 \cdot 2^9 = 2048 > 1983$ чисел, и все они не превосходят $a_9 = 5 \cdot 3^9 = 98415 < 10^5$.

**M840.** a) Докажите, что если $a, b, c$ — дианы сторон треугольника, то выполено неравенство

$$a^2b(a-b) + b^2c(b-c) + c^2a(c-a) \geqslant 0.$$

Выясните, в каких случаях оно превращается в равенство.

б) Докажите, что для любых положительных чисел $a, b, c$ выполено неравенство

$$a^3b + b^3c + c^3a \geqslant a^2bc + b^2ca + c^2ab.$$

Ясно, что равенство $(\vec{u} \cdot \vec{v})^2 = |\vec{u}|^2 |\vec{v}|^2$ возможно ли тогда, когда векторы $\vec{u}$ и $\vec{v}$ коллинеарны, то есть $\frac{a^3b}{c} = \frac{b^3c}{a} = \frac{c^3a}{b}$ или $a = b = c$.

Имеется и короткое прикое доказательство с помощью выделения полных квадратов:

$$a^3b + b^3c + c^3a - a^2bc - b^2ca - c^2ab = (a^3b - 2a^2bc + c^2ab) + (b^3c - 2b^2ca + a^2bc) + (c^3a - 2c^2ab + b^2ca) = ab(a-c)^2 + bc(b-a)^2 + ca(c-b)^2 \geqslant 0.$$

a) Приведем два решения.

Первое решение использует замену переменных $x + y = c$, $y + z = a$, $z + x = b$ ($x, y, z$ — это отрезки, на которые стороны треугольника разбиваются точками касания вписанной окружности). Можно проверить, что после этой замены неравенство пункта a) приводится к виду

$$xy^3 + yz^3 + zx^3 \geqslant x^2yz + y^2zx + z^2xy,$$

а это неравенство, как мы доказали выше, справедливо при любых неопределенных $x, y, z$.

При этом, чтобы не запутаться в выкладках и не вычислять всех членов разложения, можно использовать «симметричность» левой части неравенства пункта a) относительно цикли-

⟦folio 43⟧

ческой замены $a \rightarrow b, b \rightarrow c, c \rightarrow a$. Ей ответает аналогичная замена $R$ переменных $x, y, z$: $x \rightarrow y, y \rightarrow z, z \rightarrow x$, поэтому одночлены, получившие после раскрытия скобок в выражении

$$a^2 b(a-b) = (y+z)^2 (z+x)(y-x),$$

полезно группировать по «типам», как это сделано на полях: к одному типу относится однолеть, получающейся друг из друга при циклической замене переменных $R$ (на полях они выписаны в одну строку; подчерким, что попарные перестановки переменных не разрешаются — они меняют многочлен!). Ясно, что два других слагаемых $b^2 c(b-c)$ и $c^2 a(c-a)$ дают другое одночлены тех же типов (их можно получить просто заменой $R$). Благодаря этому можно сразу указать, с каким коэффициентом войдут в результате одночлены каждой типа (синние цифры на полях).

В пункте 6) мы показали, что равенство (1), а значит, и в неравенстве a) достигается только при $x=y=z$, то есть при $a=b=c$ (для равностороннего треугольника).

Второе решение основано на искусной перегруппировке (и удачных переобозначениях). Найти ее горизонтальное труднее, чем в пункте 6), потому что переменные $a, b, c$ на себя раз связаны неравенством треугольника и это должно быть использовано.

Обозначим левую часть неравенства через $f(a,b,c)$. Поскольку $f(a,b,c) = f(b,c,a) = f(c,a,b)$, без ограничения общности можно доказывать неравенство $f(a,b,c) \geq 0$, считая, что $b$ — средняя по длине сторона треугольника.

Предположим сначала, что $a \leq b \leq c$. Пусть $a=b-a, c=b+y$, тогда нужно доказывать неравенство $f(b-a,b+y) \geq 0$ при $b>0, a \geq 0, y \geq 0$ и при $b+y < (b-a)+b$, то есть $b > a+y$. Несложная, но объективы выкладка показывает, что

$$f(b-a,b+y) = b a(a+y)(b-a-y) + \gamma^2 (b-a)(b+a+y).$$

При указанных значениях переменных правая часть неотрицательна и обращается в нуль только при $a=\gamma=0$, то есть $a=b=c$. Пусть теперь $a \geq b \geq c$, тогда в тех же обозначениях выражение (2) следует рассматривать при $a \leq 0, \gamma \leq 0$ и $b > -(a+y)$, но и в этом случае оно, очевидно, неотрицательно.

На электрон, летящий в пучке, действует электрическое поле, создаваемое наимами. Найдем, как зависит напряжение этого поля от расстояния до оси пучка.

Напряжение $\vec{E}(r)$ в точках, находящая внутри пучка достаточно далеко от его торцов на расстоянии $r$ от оси OB, можно представить как сумму

$$\vec{E}(r) = \vec{E}_1(r) + \vec{E}_2(r),$$

где $\vec{E}_1(r)$ — напряжение поля, создаваемого теми зарядами, которые находятся внутри цилиндра радиуса $r$, а $\vec{E}_2(r)$ — напряжение поля, создаваемого теми, находящая на полежтеных зарядах, а заканчивать — на отрицательных, мы приходим к выводу, что $\vec{E}_2(r) = 0$. Более того, заряды, находящиеся в цилиндра радиуса $r$, во всех точках области внутри цилиндра поля не создают.

Определим теперь напряжение $\vec{E}(r) = \vec{E}_1(r)$. Известно, что с точки зрения картины словых линей напряжения поля определяется как число словых линей, произвольных площадку единичной площади, перепределующую линям. Следовательно, если мы созем заряд цилиндра радиуса $r$ равномерно к оси цилиндра, то поля, создавемые прежним распределением зарядов и новых «сжатым» распределением, в цилиндра будут совпадать. Поэтому величины $\vec{E}_1(r)$ определяем как напряжение поля бесконечной заряженной прямой на расстоянии $r$ от нее.

Рассчитаем, какой должа быть линейная плотность заряда на прямой. Заряд, находящая после скатания на отрезке длины $\Delta l$, равен $\sigma \cdot \Delta l$, где $\sigma$ — линейная плотность заряда

на прямой. Этот заряд должен равнять тому заряду, который находится внутри цилиндра радиуса $r$ и высоты $\Delta l$, то есть
$$\sigma \cdot \Delta l = \varrho \cdot \Delta l \cdot \pi r^2.$$
Отсюда получаем:
$$\sigma = \varrho \pi r^2.$$
Найдем теперь напряженность поля, создаваемого бесконечной заряженной прямой с плотностью заряда $\sigma$. Выделим на прямой малый участок длины $dx$. Заряд этого участка равен $\sigma \cdot dx$.
Напряжность поля, создаваемого этим участком в точке $M$, находится на расстоянии $r$ от прямой, равна (рис. 2)
$$\Delta E = |\vec{\Delta E}| = \frac{\sigma \cdot dx}{4\varepsilon_0(x^2 + r^2)}.$$
Из сообщений симметрии ясно, что вектор $\vec{E}(r)$ должен быть в любой точке перепределкульрен прямой. Следовательно, вклад, который в поле в точке $M$ участок $dx$, равен
$$dE = \Delta E \cdot \cos \varphi = \frac{\varrho \pi r^2 \cdot dx}{4\varepsilon_0(x^2 + r^2)} \frac{r}{\sqrt{x^2 + r^2}} = \frac{\varrho r^3}{4\varepsilon_0(x^2 + r^2)^{3/2}} dx.$$
Полная напряжность поля в точке $M$ представляет собой сумму таких вкладов, внесенных всеми участками прямой, то есть
$$E(r) = \int_{-\infty}^{\infty} dE = 2 \int_{0}^{\infty} \frac{\varrho r^3 dx}{4\varepsilon_0(x^2 + r^2)^{3/2}} = \frac{\varrho r}{2\varepsilon_0}.$$
Такова напряжность поля на расстоянии $r$ от оси пучка в тех его точках, которые достаточно далеки от торцов пучка. Вблизи торцов поле «искажено». Учет этих искажений (краевых эффектов) достаточно сложен. Мы упростим задачу: будем считать, что точки $A$ и $B$ лежат внутри бесконечного длиного пучка ионов на расстоянии $l$ (вдоль оси пучка) друг от друга.
Рассмотрим движение электрона внутри бесконечного длиного пучка ионов. Сила, действующая на электрон, когда он находится на расстоянии $r$ от оси пучка, равна
$$F = \frac{e\varrho}{2\varepsilon_0} r = -\frac{|e| \varrho}{2\varepsilon_0} r$$
и направлена перепределкульро оси пучка. Ускорение электрона в этом направлении —
$$a = \frac{F}{m}, \text{ или } r'' = -\frac{|e| \varrho}{2\varepsilon_0} r.$$
Из этого уравнения следует, что движение электрона в проекции на плоскость, перепределкульрую оси пучка, представляет собой гармоничное колбация с периодом
$$T = \frac{2\pi}{\omega} = 2\pi \sqrt{\frac{2\varepsilon_0 m}{|e| \varrho}}.$$
В направлении оси пучка скорость электрона остается постоянной и равной той скорости, которая он имел в точке $A$.

$$2v\varepsilon - \frac{3l}{4} < v(1 + \varepsilon)\tau - nl < \frac{l}{4},$$
