**M835***. На однокрутовой шахматный турир приехало пшахматов из страны $A$ и пшахматов из страны $B$. Окзадось, что как бы ни разбить шахматов на пары (читы другие с другой церрали шахматисты разных стран), найдется хотя бы одна пара шахматистов, которые уже встречались ранее другие с другой. Докажите, что можно выбрать а шахматов из страны $A$ и пшахматов из страны $B$ так, что каждый из выбранных а шахматов встречался с каждой из выбранных в шахматов, $a + b > n$.

Доказательство проводем индykцией по $n$.

При $n = 1$ утверждение задачи очевидно ($a = b = n = 1$). Теперь надо доказать его для $n = k$, предполагая, что оно верно для всех $n < k$.

В случае, когда каждый из $k$ шахматов, прибивших из страны $A$, встречался ранее с каждой, прибившим из $B$, доказываясь нечего ($a = b = k$). Поэтому будем считать, что какне-то два шахматства — $a$ из $A$ и $B$ — друг с другом не встречались. Тогда остальные шахматные удовлетворяют условию задачи для $n = k - 1$. (Если составить из них пары и присоединить к ним ($a, \beta$), то по условию в одну из этих пар, но заведomo не в ($a, \beta$), попадут встречавшиеся шахматные.) По предположению индykции можно обращать группу $A$ из $a_1$ шахматов страны $A$ и группу $B$ из $b_1$ шахматов страны $B$ так, что каждый шахматист группы $A$ встречался с каждой из $B$ и $a_1 + b_1 > k - 1$. Если окажется, что $a_1 + b_1 > k$, — все в порядке ($a = a_1, b = b_1$). Остается рассмотреть случай $a_1 + b_1 = k$; рассудения иллюстрирует рисунок на полях.

Пусть $A$ — группа из $k - a_1 = b_1$ шахматов из $A$, не вошедших в группу $A$, $B$ — группа шахматов из $B$, не вошедших в $B$. Устройм два новых турира — для групп $A$ и $B$ ($n = a_1$) и $A$ и $B$ ($n = b_1$). Один из этих туриров (для определения, с учетом групп $A$ и $B$) удовлетворяет условию задачи. (В противном случае можно так составить пары из шахматов групп $A$ и $B$, и независям, групп $A$ и $B$, что ни в одной из этих пар не попадут встречавшиеся шахматные, а это противоречит условию для «общего» турира.) По предположению индykции в группе $A$ можно найти $a_2$ шахматов, каждой из которых встречался с каждой из таких $a_1 + b_2 > a_1$. Кроме того, по выбору групп $A$ и $B$ можно найти эти $a = a_2$ шахматов встречался с каждой из $b_1$ шахматов группы $B$. В нашем случае строки и столбцов в матрице («таблице встреч» — см. рис.) одинаково (и равно $n$); условие задачи означает, что в любом наборе независящих чисел есть единица, то есть максимальное число независящих нулей меньше $n$. По теореме Кёнга можно указать меньше $n$ линей, содержащих все нулы. Тогда на пересечениях отмеченных линей — $a$ столбцов и $b$ строк, где $a+b>n$, — стояят единицы, а это, по существу, и утверждается в задаче.

Еще одно эквивалентное утверждение, часто непользуемое в оптимизации задач, — теорема Холла о различных представлениях (или «теорема о свойстваве»): пусть каждый из $n$ ионишей знаком с некоторыми из $n$ деваушек, причем для любых $k$ ионишей ($k=1, 2, \dots, n$) имеется по крайней мере $k$ деваушек, знакомх хотя бы с одним из них; тогда их можно разбить на пары так, что в каждой паре будут знакомые деваушка и иониша. Эту теорему в разных формулировках и с несколькоми доказательствами можно найти в статьях М. И. Башмакова («Квант», 1970, № 4, с. 14) и В. Н. Вагутена («Квант», 1974, № 11, с. 23).

Ф845. Внутрь камеры автоматического колеса радиуса $R$ попал небольшой камейк. При какой минимальной скорости автоматическая камейк будет вращаться вместе с колесом, если коэффициент трения камейка о камеру равен $\mu$?

На камейк внутренки камеры действуют три силы (см. рисунок): сила тяжести $mg$, сила нормальной реакции $\vec{N}$ и сила треня $\vec{F}$. Чтобы камейк вращался вместе с колесом, эти силы должны сообщать ему центростремительноеускорение $v^2/R$, где $v$ — линейная скорость вращения колеса, равная скорости движения автоматics (колеска вращаются без просkalзывания).

Запишем уравнение движения камейка в проекциях на оси $X$ и $Y$ (см. рисунок):

$$F = mg \sin (\pi - a) = 0,$$

$$N + mg \cos (\pi - a) = mv^2/R.$$

Из уравнения (1) находится:

$$F = mg \sin a.$$

Абсолютное значение силы треня не может быть больше $\mu N$, и следовательно, $N \geqslant F/\mu$. Minimalному значению $v$ соответствует как видно из уравнения (2), $N = \frac{F}{\mu} = \frac{m}{\mu} g \sin a$. С учетом этого получаем:

$$v_{\text{min}}^2 = Rg \left( \frac{\sin a}{\mu} - \cos a \right).$$

Выражение, стоящее в скобках, минимально, когда произвольная функция $f(a) = \frac{\sin a}{\mu} - \cos a$ равна нулю, то есть

$$\frac{\cos a}{\mu} + \sin a = 0 \Rightarrow -\mu = \text{ctg} a.$$

Тогда

$$\sin a = \frac{1}{\sqrt{1 + \text{ctg}^2 a}} = \frac{1}{\sqrt{1 + \mu^2}}.$$
