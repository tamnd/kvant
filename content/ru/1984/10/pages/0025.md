Условия считать по определению, что соответствие (7) справедливо для любого действительного числа $x$. Иначе говоря, мы условия считать $e^x$ просто другой формул записи для $\exp x$ (причем для рациональных $x$ эта форма записи согласно в силу доказанной lemмы с понятным стелени с рациональным показателем). При использовании этого обозначения формула (5) прибретает привчный вид $e^{p+q} = e^p e^q$. Заметим, что в математической литературе используется обе формулы записи экспоненты: $y=e^x$ и $y=\exp x$.

6. Решение дифференциальных уравнений

При записи решения дифференциальных уравнений чаще применяют обозначение $e^x$, а не $\exp x$. Этот традиции мы и будем придерживаться.

Теорема 4. При $a \neq 0$ решение дифференциального уравнения (2) с начальным условиям $y(0)=y_0$ имеет вид
$$y = -\frac{b}{a} + ce^{ax},$$
(8)
$$e\delta e = b/a + y_0.$$
Доказательство. Так как (согласно теореме 1) исключение единственного, то достаточно лишь проверить, что функция (8) (при указанном значении $c$) удовлетворяет уравнению (2) и требуему начальному условияю. Имеем
$$y' = (ce^{ax})' = c(e^{ax})' = cae^{ax} = a(ce^{ax}) = a(y + \frac{b}{a}) = ay + b,$$
то есть функция (8), действительно, удовлетворяет уравнению (2) (при любом значении постоянной $c$). Далее,
$$y(0) = -\frac{b}{a} + ce^0 = -\frac{b}{a} + c = -\frac{b}{a} + \left(\frac{b}{a} + y_0\right) = y_0.$$
значит, при указанном значении $c$ функция $y$ удовлетворяет и требуемому начальному условияю.

Доказанную теорему обещено применяют следующим образом. Слагаемое $y = -b/a$ легко запомнить: оно получается, если $y'$ приравнять нулю; далее, коэффициент $a$ при неизвестной функции в (2) становится коэффициентом при аргументе в показатель экспоненты. Что же касается常态ы $c$, то ее значение (указанное в теореме 4) обычно не запомниют, а в каждом конкретном примере находится $c$ с помощью начальных условий.

Пример 1. Масса $m(t)$ радиоактивного вещества, имеющегося в куске породы в момент $t$, с течение времени убывает, то есть производаная $m'(t)$ (скорость распада) отрицательна. При необходимости количество радиоактивного вещества скорость распада пропорциональна массе радиоактивного вещества:
$$m' = -km$$
(где коэффициент $k > 0$ зависит от вида радиоактивного вещества). Найти закон изменения массы $m(t)$ с течение времени, если в начальной момент $t=0$ масса имеющегося радиоактивного вещества была равна $m_0$.

Решение. По теореме 4 имеем $m(t) = ce^{-kt}$. Подставляя $t=0$, получаем $m_0 = ce^0$, откуда $c = m_0$. Окончательное имеем $m(t) = m_0e^{-kt}$.

Пример 2. Через какой промежуток времени $T$ количество радиоактивного вещества уменьшитсяровно вдвое?

Решение. Надо найти $T$ из уравнения $m_0/2 = m_0e^{-kT}$, то есть $e^{-kT} = 1/2$, или $e^{kT} = 2$. Это соответствие равновесью следующему: $\ln 2 = kT$, откуда $T = (\ln 2)/k \approx 0.7/k$.

Значение $T = (\ln 2)/k$ называется перiodом полураспада. Он зависит от $k$ (то есть радиоактивного вещества); например, для радия $T \approx 1600$ лет.
