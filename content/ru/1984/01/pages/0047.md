M826—M830; Ф837—Ф841

Ответ: a) нет, 6) да. Заметим сначала, что если исходными числами были 2, 2, 2 или 3, 3, 3, или вообше любые числа, больше 1, то и все последующие числа будут больше 1, причем наиболее число в каждой новой тройке всегда на 1 меньше суммы двух других. Это сообщение позволяет по последней тройке чисел восстановить все предыдущие, кроме самой первой.

Действительно, пусть в тройке $a, b, c$ для определения $a \leq b \leq c$. Тогда $c = a + b - 1$ и предыдущая тройка имеет вид $a, b, x$. Набольшим числом в ней можно считать $b$ (если $x > b$, то $x = a + b - 1 = c$). Но тогда $b = a + x - 1$. Следовательно, тройка $a, b, c$ при $a \leq b \leq c$ получается из тройки $a, b, b - a + 1$.

Пользоваться этим правилом, восстановим все записи на доске, начиная с конца:

(17, 1967, 1983) $\leftarrow$ (17, 1967, 1951) $\leftarrow$ (17, 1935, 1951) $\leftarrow$ ... $\leftarrow$ (17, 15, 31) $\leftarrow$ (17, 15, 3) $\leftarrow$ (13, 15, 3) $\leftarrow$ ... $\leftarrow$ (5, 7, 3) $\leftarrow$ (5, 3, 3).

По нашему правилу тройке 5, 3, 3 должна быть предшествовать тройка 1, 3, 3, содержащая 1, что невозможно. Поэтому 5, 3, 3 — тройка, полученная на первом шаге. (Очевидно, что остальные тройки на первом шаге возникнут не могут.) Ясно, что тройка 5, 3, 3 может получить из 3, 3, 3 и не может из 2, 2, 2.
