$$x + y = c, y + z = a, z + x = b.$$

Она, конечно, легко решается любым из вышечкаанных способов, но красивее и проще поступить иначе. Сложим все три уравнения. Получаем $2x + 2y + 2z = a + b + c$, откуда $x + y + z = \frac{a + b + c}{2}$. Вычитая из этого уравнения каждое из уравнений системы, находим $x = \frac{b + c - a}{2}, y = \frac{a + c - b}{2}, z = \frac{a + b - c}{2}$.

17. (Предлагалась воспоминания на XXIII Украинской олимпиде в 1983 г.) Прямогольник разбит на квадраты так, как показано на рисунке 2. Известно, что сторона защищенного квадрата равна 1. Найдите стороны остальных квадратов.

Решение. Обозначим искомые стороны через $x, y, z, u$ (см. рис. 2). Тогда $MN = y = u + 1, AB = x = y + 1, KL = z = x + 1$. Подставляя $y = u + 1$ во второе соответствие, находим $x = u + 2$. Подставляя $x = u + 2$ в третье соответствие, находим $z = u + 3$. Тепер запишем равенство противоположных сторон прямогольника: $x + z = y + 2u$; подставив сюда $x, y$ и $z$, получаем $(u + 2) + (u + 3) = (u + 1) + 2u$, откуда $u = 4$. Тепер находим $x = 6, y = 5, z = 7$.

18. Прямогольник разбит на квадраты так, как показано на рисунке 3. Известно, что сторона защищенного квадрата равна 2. Найдите стороны остальных квадратов.

В двух следующих задачах реш идет о разветвленных электрических цепях, составленных из проводников единичного сопротивления. Каждая цепь подключана к источнику в двух точках (полюсах). Тoki подчиняются правым Кирхгофа, которые для расматриваемых цепей можно сформулировать так:

1) Сумма токов, входяших в любой узел, равна сумме токов, выходяших из него (полюс узлом не считается).

2) В любом замкнутом контуре сумма токов, идущих по часовой стрелке, равна сумме токов, идущих против часовой стрелки$^*$).

22. (Предлагалась в восемом и десятом классах на XXIII Всегоозной олимпиде и вошла в заданок «Кваンタ» под номером М578; решение см. в разделе «Ответы, указания, решения».) Решите систему $(a$ и $b$ — данные числа)
$$\frac{x - y \sqrt{x^2 - y^2}}{\sqrt{1 - x^2 + y^2}} = a, \quad \frac{y - x \sqrt{x^2 - y^2}}{\sqrt{1 - x^2 + y^2}} = b.$$
