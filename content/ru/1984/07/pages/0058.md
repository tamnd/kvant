⟦folio 56⟧

$$\frac{\alpha + \beta}{2} = \frac{tg^2 \alpha - \beta}{2} \text{ или}$$
$$\alpha = \arctg p^2 + \arctg p, \quad \beta = \arctg p^2 - \arctg p, \quad \gamma = \pi - 2 \arctg p^2,$$
где $p$ — любое число, больше 1.

$$\pi/2 - \alpha \text{ (в этом случае } \cos \alpha - \sin \beta = \sin \alpha - \cos \beta = 0).$$

в) Ответ: наиболее изуглов $\alpha, \beta, \gamma$ может применять любое значение в промежутке $[\pi/2; \pi]$.

Мы уже показали в решении пункта 6), что наиболее угол не может быть острым, но может быть прямым ($\gamma = \pi/2$). Показем теперь, что он может применять любое значение от $\pi/2$ до $\pi$, точнее, что для любого $\alpha, \pi/2 < \alpha < \pi$, уравнение относительно $\beta$
$$\sin^2 \alpha + \sin^2 \beta = \sin(\alpha + \beta)$$
имеет решение в промежутке $0 < \beta < \pi - \alpha$ (так что $\gamma = \pi - (\alpha + \beta) > 0$). Обе части этого уравнения — непрерывные функции от $\beta$, причем при $\beta = 0$ левая часть меньше правой $(\sin^2 \alpha < \sin \alpha),$ а при $\beta = \pi - \alpha$ — больше $(2 \sin^2 \alpha > 0)$. Поэтому в некоторых точке $\beta, 0 < \beta < \pi - \alpha$, значения обихих частей совпадают. Эта точка и будет корнем уравнения.

Читателью предлагается самостоятельноеprodолжить исследование нашего уравнения: доказите, что угол $\gamma$ не может быть тупым (для этого надо умножить данные соответствие на квадрат диаметра описанной окружности, получить из него по теореме синусов неравенство для сторон треугольника и показать, что $\cos \gamma \leq 0$); проверьте, что углы $\alpha, \beta$ и $\gamma$ не $\pi/2$ могут быть заданы красивыми формулами, приведенными на полях (конечно, из этих формул сразу же следует утверждение 6) и в)).

**M859. Найдите наименьшее положительное число а также, что для любого квадратного трехчлена $f(x)$, удовлетворяющего при $0 \leq x \leq 1$ неравенству $|f(x)| \leq 1$, выполняется неравенство $|f'(1)| \leq a$.**

ОТВЕТ: $a = 8$. Пусть функция $f(x) = Ax^2 + Bx + C$ удовлетворяет условиям задачи. Заметим, что $f'(1) = 2A + B, f(0) = C, f(1) = A + B + C$ и $f(1/2) = A/4 + B/2 + C$, и потому $f'(1) = 3f(1) - 4f(1/2) + f(0)$. Следовательно,

$$|f'(1)| \leq 3 |f(1)| + 4 |f(1/2)| + |f(0)| \leq 8,$$

причем эти неравенства превращаются в равенства при $f(0) = f(1) = 1, f(1/2) = -1$, то есть для функции $f_0(x) = 8x^2 - 8x + 1$ см. рисунок. А так как эта функция удовлетворяет неравенству $|f_0(x)| \leq 1$ при $0 \leq x \leq 1$ (её график — парабола с вершиной в точке $x = 1/2$ — точке минимума), число 8 в нашей оценке $|f'(1)|$ умеешь нельзя.

По сути дела, в решении мы воспользуемся тем, что многочлен $n$-й степени, а значит, и его произведение, однозначно задается своим значениями в $n+1$ точках (при $n=2$). Попробуйте самостоятельное решение эту задачу для кубических многочленов. Отметим, что при произвольной степени $n$ наличиую оценку в задаче будет давать так называемые многочлены Чебышева, о которых можно прочитать в статье Н. Васильева и А. Зелевинского «Многочлены Чебышева и рекуррентные соотношения» («Квант», 1982, № 1, c. 12).
