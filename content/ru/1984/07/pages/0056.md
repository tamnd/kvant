И. 3. Титович

M857. Среди 1984 первых натуральных чисел (от 1 до 1984) отмечим те, которые можно представить в виде суммы пятых целых неотрицательных степени двойки (то есть пяты не обязательно различных чисел 1, 2, 4, 8, ...). Каких чисел оказывается больше: отмещенных или не отмещенных?

ОТВЕТ: отмещенных чисел больше.

Поскольку $2^n + 2^n = 2^{n+1}$, сумму нескольких степени двойки всегда можно переписать так, что все они будут различны, при этом число слагаемых может уменьшиться, например $4 + 2 + 2 = 4 + 4 + 2 = 8 + 2$. Следовательно, любое отмещенное число есть сумма не более чем пяты различных слагаемых вида $2^n$, где $n = 0, 1, ..., 10$ ($2^{11} = 2048 > 1984$).

Найдем число $N$ таких сумм, то есть набор различных степени двойки $n_1, ..., n_k$ ($0 \leq n_i \leq 10, 1 \leq k \leq 5$). Каждый набор $n_1, ..., n_k$ взаимно-однозначно соответствует набор, составленный из всех чисел от 0 до 10, кроме $n_1, ..., n_k$, поэтому количество $N_k$ наборов из $k$ чисел равно количество наборов из $11 - k$ чисел, и $N = N_1 + ... + N_5 = N_{10} + ... + N_6 = (N_1 + N_2 + ... + N_{10})/2$.
