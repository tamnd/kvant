2) Пусть $n$ частиц $A_1$, ..., $A_n$ с массами $m_1$, ..., $m_n$ движутся равномерно и пря-молинейно со скоростью $\vec{v}_1$, ..., $\vec{v}_n$ относительно некоторой системы отчета $S$. Тогда их центр масс движется в системе $S$ со скоростью $\vec{v}_0 = (m_1\vec{v}_1 + \dots + m_n\vec{v}_n) / m$ ($m = m_1 + \dots + m_n$). Скорость частицы $A_i$ в системе покоя центра масс по правлу сложения скоростей равна $\vec{u}_i = \vec{v}_i - \vec{v}_0$. Пусть $E$ и $E_0$ — полные кинетические энергии всех части в системе $S$ и в системе центра масс, то есть $E = \frac{m_1v_1^2}{2} + \dots + \frac{m_nv_n^2}{2}$, $E_0 = \frac{m_1u_1^2}{2} + \dots + \frac{m_nu_n^2}{2}$. Полягая в (8) $x_i = \vec{v}_i$, $c_i = m_i/2$, получим теорему Кёнца о кинетической энергии:

$$E = E_0 + \frac{mv_0^2}{2}$$

(полная кинетическая энергия системы части равна энергии их движения относительно центра масс плоскости энергия движения центра масс).

3) Пусть в некотором эксперименте со случайным исходом измеряется некоторая величина $X$, например, бросают игольную кость и определяют выпавшее число очков. Предположим, что, в зависимости от результата эксперимента, величина $X$ может принимать $n$ значений $x_1$, ..., $x_n$ (в примере с костью — 6 значений 1, 2, ..., 6), причем значение $x_i$ принимается с вероятностью $p_i$ (числа $p_i$ неотрицательны и дают в сумме 1; в нашем примере, оченьindo, все значения равноверятны, то есть $p_1 = p_2 = \dots = p_6 = 1/6$). Число $p_1x_1 + \dots + p_nx_n$ называется средним значением (или математическим ожиданием) случайных $X$ и обозначается $MX$ (в нашем примере $MX = (1 + \dots + 6)/6 = 3,5$). Таким образом, с точки зрения теории вероятностей выражения, входящие в (8) (при $c_i = p_i$, $c = \Sigma p_i = 1$), можно интерпретировать так*):

$$p_1x_1^2 + \dots + p_nx_n^2 = MX^2$$

— среднее значение случайной величины $X^2$ или, как говоря, второй момент (снова «момент»!) случайной величины $X$; $y_i = x_i - x_0 = x_i - MX$ — отклонения значений случайных $X$ от среднего значения;

$$p_1y_1^2 + \dots + p_ny_n^2 = MX(X - MX)^2$$

— среднее значение квадрата отклонения $X$ от $MX$; это очень важная характеристика случайной величины, показывающая степень ее «разброса» вокруг среднего значения, она называется диисперсей и обозначается $DX$; $x_0^2 = (MX)^2$.

В результате (8) превращается в формулу для вычисления дисперсии, имеющейся во всех учебниках теории вероятности (правда, не носшуюничих звучных имен):

$$DX = MX^2 - (MX)^2$$
