⟦folio 21⟧

Основная теорема

Тепер мы можем забыть все сообразения, которые приведены нас к выписанным выражениям для проигрывших полей ($a_n, b_n$), и сразу сформировать следующую основную теорему.

Теорема 1. Пусть $u = \frac{1+\sqrt{5}}{2}$, $v = u^2 = u + 1 = \frac{3+\sqrt{5}}{2}$. Поле $(a, b)$, где $b > a$, в том и только в том случае является проигрывным, если существует натуральное число $n$ такое, что $a = [nu], b = [nv]$. Если такого натурального $n$ не существует, то позиция является выигрывной.

Доказательство. Рассмотрим последовательность точек

$$(a_1, b_1), (a_2, b_2), \dots, (a_n, b_n), \dots,$$

где $a_n = [nu], b_n = [nv]$, и доказем, что для этой последовательности выполнены свойства 1 и 2 (см. с. 19). Начнем со свойства 1.

Сначала убедимся в том, что все числа $a_1, b_1, a_2, b_2, \dots$ различны. Числа $a_i = [iu]$ различны, так как $u > 1$. По той же причине ($v > 1$) различны числа $b_j = [jv]$. Предположим, что какие-то два из чисел $a_j$ и $b_j$ совпадают. Это значит, что $[iu] = [jv] = k$. Поэтому $iu = k + \delta$, где $0 < \delta_1 < 1$, $jv = k + \delta_2$, где $0 < \delta_2 < 1$. Разделив первое равенство на $u$, второе на $v$, а затем сложив полученные равенства, приходим к равенству

$$i + j = \frac{k}{u} + \frac{k}{v} + \frac{\delta_1}{u} + \frac{\delta_2}{v} = k + \frac{\delta_1}{u} + \frac{\delta_2}{v},$$

из которого следует, что

$$0 < i + j - k = \frac{\delta_1}{u} + \frac{\delta_2}{v} < \frac{1}{u} + \frac{1}{v} = 1,$$

что невозможно, так как число $i + j - k$ — целое.

Тепер доказем, что каждое натуральное число встречает в последовательности $a_1, b_1, a_2, b_2, \dots, a_n, b_n, \dots$.

Пусть $N$ произвольное натуральное число.

Существуетровно $\left[ \frac{N}{u} \right]$ чисел $a_i = [iu]$, меньше $N$. (Это числа с номерами $i = 1, 2, \dots, \left[ \frac{N}{u} \right]$.) Ировно $\left[ \frac{N}{v} \right]$ чисел $b_j = [jv]$, меньше $N$. (числа с номерами $j = 1, 2, \dots, \left[ \frac{N}{v} \right]$.) Всего чисел $a_i$ и $b_j$, меньше $N$, существуют $\left[ \frac{N}{u} \right] + \left[ \frac{N}{v} \right]$, а так как $\frac{N}{u}$ и $\frac{N}{v}$ — не целые числа, $\frac{N}{u} - 1 + \frac{N}{v} < \left[ \frac{N}{u} \right] + \left[ \frac{N}{v} \right] < \frac{N}{u} + \frac{N}{v}$, то есть

$$N - 2 < \left[ \frac{N}{u} \right] + \left[ \frac{N}{v} \right] < N.$$

Таким образом, $\left[ \frac{N}{u} \right] + \left[ \frac{N}{v} \right] = N - 1$. Но это означает, что чисел вида $a_i$ и $b_j$, меньше $N$, имеется в точности столько, сколько всего натуральных чисел, меньше $N$. Поскольку все числа $a_i$ и $b_j$ различны, свойство 1 последовательности $(a_1 b_1), (a_2 b_2), \dots, (a_n b_n)$, ... доказано.

Свойство 2 доказывает без труда:

$$b_n - a_n = [vn] - [un] = [(u + 1)n] - [vn] - [un] = [nu] + n - [un] = n.$$

Тем самым основная теорема полностью доказана.

Появляется числа Фибоначчи

Согласно основной теореме, для определения проигрывной пары с номером $n$ надо умножить $n$ на irrationalное число, заданное в виде бесконечной десятичной дроби. Возможно, что такое умножение вам не понятно, особенно если вы не имеете счетной машины. Как для определения проигрывных пар $(a_n, b_n)$ обычно только действиями над натуральными числами?

Для этой цели может послужить такое свойство проигрывных пар:

3. Если $(a_n, b_n)$ — произвольная пара, то пары $(b_n - 1, a_n + b_n - 1)$ и $(b_n + 1, a_n + b_n + 2)$ — тоже произвольные.

При этом, исходя из начального поля $(0, 0)$ или первого поля $(1, 2)$, мы можем построить, пользоваться свойством 3, все проигрывные пары.

Наметим доказательство свойства 3.

Упражнение 2. Доказите, что для проигрывных пар $(a_n, b_n)$ и $(a_{n+1}, b_{n+1}): 2 \leq b_{n+1} - b_n \leq 3$, и $1 \leq a_{n+1} - a_n \leq 2$.

Из результатов упражнения 2 следует, что числа $b_n - 1$ и $b_n + 1$ не являются большими числами проигрывных пар. По свойству 1 существуют такие $k$ и $l$, что $a_k = b_n - 1$, $a_l = b_n + 1$. Посмотрим, чему равны $k$ и $l$.

По свойству 2, номер любой пары равенности между большим и меньшим из чисел этой пары.

С другой стороны, из свойства 1 следует, что номер любой отменной пары $(a_k, b_k)$ равенности ее меньше числа $a_k$ и количество всех неулевых $b_l < a_k$. При $a_l = b_n - 1$ количество чисел $b_l$, меньше числа $a_l$, равно $n - 1$. Это значит, что $k = b_n - 1 - (n - 1) = a_n$. Поэтому пара $(b_n - 1, b + a_n - 1)$ — отмеченная.

Упражнение 3. Доказите, что пара $(b_n + 1, a_n + b_n + 2)$ является отменной для всякой отменной пары $(a_n, b_n)$.

Упражнение 4. Доказите, что любая отменная пара $(a_n, b_n)$ может быть получена из пары $(0, 0)$ или пары $(1, 2)$ с помощью последовательного применения нескольких операций, описываемых свойством 3.
