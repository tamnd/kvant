В тот момент, когда ток через катушкистанет равным нулю, энергия конденсатора будет равна работе, которое произвела батарея. Следовательно, закиденсатора в этот момент определяется условием

$$\frac{q_0^2}{2C} = U_0 q_0,$$

откуда

$$q_0 = 2CU_0.$$

Найдем максимальный ток через катушки после подключения конденсатора. Условие максимума тока — $I' = 0$, то есть $\delta_{инд} = -LI' = 0$; значит, в тот момент, когда ток максимален, направление на конденсатор равно $U_0$ и «компенсирует» направление батареи (рис. 1). Из закона сохранения энергии —

$$U_0 CU_0 = \frac{CU_0^2}{2} + \frac{LI_0^2}{2}$$

— находим максимальное значение тока:

$$I_0 = U_0 \sqrt{\frac{C}{L}}.$$

Рассмотрим схему после переключения (рис. 2). Ток через катушки равен нулю (только в тот момент, когда энергия катушки равна нулю, ее можно «безнаказанно» отключать от цепи). В тот момент, когда ток достигнет искомого максимального значения $I_1$, направление на конденсатор будет равно $U_0$; значит, к этому моменту по цепи протечет закид $3CU_0$ и, согласно законах сохранения энергии,

$$U_0 3CU_0 + C \frac{(2U_0)^2}{2} = \frac{CU_0^2}{2} + \frac{LI_1^2}{2}.$$

Отсюда

$$I_1 = 3U_0 \sqrt{\frac{C}{L}}.$$

Перед следующим, вторым, переключением, когда ток через катушки будет равен нулю, на конденсатор будет заряд $q_1$, который, как и в первом случае, найдем из условия

$$U_0 (2CU_0 + q_1) + C \frac{(2U_0)^2}{2} = \frac{q_1^2}{2C}.$$

Отсюда

$$q_1^2 - 2CU_0 q_1 - 8C^2 U_0^2 = 0 \Rightarrow q_1 = CU_0 \pm 3CU_0.$$

Корень — $2CU_0$ не подходит (подумайте, какому случай он соответствует). Значит, $q_1 = 4CU_0$.
