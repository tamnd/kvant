⟦folio 51⟧

Спиечный корпок и экстремум
Р. Ш. ДАНЕЛИЯ

Эта задача мне пришла в голову, когда я рассматривал коллекцию спиечных корпоков у своего приятелья. Он собирает не только этикетки, как делают многое, а корпки целиком. У него можно увидеть корпки самых разнообразных форм и размеров. Перебирая экспонаты корпки, я подумал: каких размеров должны быть самая «выгодная» корпка? Ведь это — чисто математический вопрос, ему можно дать следующую строгую формулировку:

Средние всех спиечных корпков данного объема V объявной конструкции (то есть состоящих из выдвижной открытой сверху корпочки и внешней части, открытой по бокам; см. рис. 1) найти форму (то есть отношение ребер x:y:z), обеспечивающего наименьшую затрату материалов при изготовлении (толщина материалов в счет не принимается).

Для решения этой задачи нам потребуется следующая Лемма. Если произведение трех положительных переменных a, b, c построено, то их сумма принимает наименьшее значение, когда a = b = c.

Доказательство. В силу неравенства между средним арифметическим и средним геометрическим

$$\frac{a+b+c}{3} \geq \sqrt[3]{abc},$$

(1)

соответствие abc = k = const дает a+b+c ≥ 3√k, причем равенство достигается только при a = b = c.

Хотя доказательства неравенства (1) приводится во многих руководствах, будет не лишним познакомить читателя с еще одним его доказательством — отличным от традиционных.

Если ввести обозначения

$$x_1 = \frac{a}{\sqrt[3]{abc}}, \quad x_2 = \frac{b}{\sqrt[3]{abc}},$$

$$x_3 = \frac{c}{\sqrt[3]{abc}},$$

то требуем неравенство записется так:

$$x_1 + x_2 + x_3 \geq 3,$$

(2)

причем равенство достигается только при x_1 = x_2 = x_3 = 1. Итак, если произведение x_1x_2x_3 равно 1, то сумма x_1 + x_2 + x_3 не меньше 3 и равна 3 только в том случае, когда x_1 = x_2 = x_3 = 1.

В самом деле, рассмотрим два возможных случаев:

1. Все три x равны между собой, то есть x_1 = x_2 = x_3 = 1. Ясно, что в этом случае x_1 + x_2 + x_3 = 3.

2. Не все x равны между собой. Так как их произведение равно единице, если одно больше 1, то другое меньше 1. Для определения положим: x_1 > 1, x_2 < 1. Имеем:

$$(x_1 - 1)(x_2 - 1) < 0 \iff x_1x_2 + 1 < x_1 + x_2 \iff x_1 + x_2 + x_3 > x_1x_2 + x_3 + 1.$$

(3)

Но x_1x_2x_3 = 1, и поэтому

$$x_1x_2 + x_3 + 1 = \frac{1}{x_3} + x_3 + 1 = \frac{1}{x_3} + x_3 - 2 + 3 = \frac{(x_3 - 1)^2}{x_3} + 3 \geq 3.$$

Это же, согласно (3), дает x_1 + x_2 + x_3 > 3, что и требовалась доказать.

Теперь мы уже можем перейти к решению нашей задачи.

Пусть размеры корпки x, y, z (рис. 1). Коробка состоит из двух частей, причем площадь поверхности первой части S_1 = xy + 2xz + 2yz, а второй S_2 = 2xy + 2xz. Общая же площадь — их сумма — будет S = 2yz + 3xy + 4xz.

Понятно, что материал, требующий на изготовление корпки, пропорционален S, то есть мы должны подобрать x, y, z так, чтобы S было наименьшим. Для этого представим S в следующем виде:

$$S = xyz \left( \frac{2}{x} + \frac{3}{z} + \frac{4}{y} \right)$$

или, учитывая равенство xyz = V,

$$S = V \left( \frac{2}{x} + \frac{3}{z} + \frac{4}{y} \right).$$

Произведение слагаемых внутри скобки постоянно (оно равно 24/V), поэтому в силу леммы наименьшее значение достигается, когда слагаемые равны, откуда x:y:z = 2:3:4.

Таким образом, расход материалов будет наименьшим, когда длина, ширина и высота корпки относится как 4:2:3. Заметим, что чаще фабрики не соблюдают этого соотношения (рис. 2), но есть и корпки, заготовленные именно с учетом этого условия (рис. 3).
