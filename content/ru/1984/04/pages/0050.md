⟦folio 48⟧

Для изобарного участка из уравнения состояния нахождения $T_2 - T_1 = T_1(T_2/T_1 - 1) = T_1(V_2/V_1 - 1)$.
Из этих соотношения получаем
$$\frac{V_2}{V_1} = 1 + \frac{Q}{vRT_1} = 2.$$
Задача 3. Из начального состояния с известной температурой $T_1$ молым идеально зазапекudit в состоянии с той же температурой двумя путями (рис. 3). В одном из них заза сначала наревается изобарно до температуры $T_2 = 2T_1$, а затем изхорно охлаждается. В другой — заза сначала изхорно охлаждается, а затем изобарно наревается. Найдите разность количества теплоты, подведенных к зазу в обих случаях.

Решение этой задачи аналогично предыдущему:
$$Q_1 = vC_p(T_2 - T_1) + vC_v(T_1 - T_2),$$
$$Q_2 = vC_v(T_3 - T_1) + vC_p(T_1 - T_3),$$
и
$$Q_1 - Q_2 = vR(T_2 + T_3 - 2T_1).$$
Приемя уравнение состояния $pV = vRT$ для изобарных участков процессов 1 и 2, найдем связь температур $T_1$, $T_2$ и $T_3$:
$$p_1 = \frac{vRT_1}{V_1} = \frac{vRT_2}{V_2}, \quad p_2 = \frac{vRT_3}{V_1} = \frac{vRT_1}{V_2},$$
откуда
$$T_1^2 = T_2T_3.$$
По условию $T_2 = 2T_1$, поэтому $T_3 = T_1/2$. Окончательно получаем
$$Q_1 - Q_2 = vRT_3 = vRT_1/2.$$
Задача 4. Моль идеально заза распределяется по закону $pV^2 = const$. Определите молярную темперакость заза в этом процессе.
Как было сказано ранее, молярная темперакость заза
$$C = C_V + \frac{p}{v} \frac{\Delta V}{\Delta T}.$$

Из уравнения состояния $pV = vRT$ и уравнения процесса $pV^2 = const$ получаем
$$VT = const.$$
Это равенство справедливо при любых $V$ и $T$, поэтому
$$(V + \Delta V)(T + \Delta T) = VT.$$
Раскрывая скобки и пренебрегая малым слагаемым $\Delta V\Delta T$, находим отношение изменения объема $\Delta V$ к изменению температуры $\Delta T$:
$$V\Delta T + T\Delta V = 0, \text{ или } \frac{\Delta V}{\Delta T} = -\frac{V}{T}.$$
Тогда окончательно молярная теплоемкость оказывается
$$C = C_V - \frac{pV}{vT} = C_V - R.$$
Нетрудно убедиться в том, что при расшириении по закону $pV^2 = const$ охлаждается (это непосредственно следует из условия $VT = const$). За счет убили его внутренней энергии совершается работа по расшириению ($A' > 0$) и некоторое количество теплоты отдается окружающим телам ($Q < 0$).
Задача 5. Моль идеально заза помещают в цилиндр с подвижным неисомным поршнем, скрепленным с дном с помощью пружины, растяжение которого поднимается закону Гука (рис. 4). Определите теплоемкость заза, считая внешнее давление равным нулю и пренебрегая диной нерастую прижины.
Пусть $p$ — давление газа, $V = Sx$ — объем, занимаемый газом, где $S$ — сечение цилиндра, $x$ — длина растянутой пружины. Обозначим жесткость пружины через $k$ и запишем условие поршня:
$$pS = kx, \text{ или } pS^2 = kV.$$
Из последней формулы следует, что изменения давления $\Delta p$ и объема $\Delta V$ связаны соотношениям
$$\Delta p = \frac{k}{S^2}\Delta V = \frac{p}{V}\Delta V.$$
Из уравнения состояния $pV = vRT$, справедливо при любых $p, V, T$, находим
$$(p + \Delta p)(V + \Delta V) = vR(T + \Delta T).$$
Раскрывая в последнем равенстве скобки и пренебрегая малым слагаемым вида $\Delta p\Delta V$, получим
$$p\Delta V + V\Delta p = vR\Delta T,$$
или, учитывая связи $\Delta p$ и $\Delta V,$
$$\frac{p}{v} \frac{\Delta V}{\Delta T} = \frac{R}{2}.$$
