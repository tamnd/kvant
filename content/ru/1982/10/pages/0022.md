Чтобы уточнить эту оценку, введем понятие вероятности события. Отношение $p$ количество способов, которые может произойти интересующее нас событие, к общему количество равновозможных вариантов называется вероятностью этого события. Очевидно, $0 \leq p \leq 1$.

В нашем случае ($n=2, m=10$) обозначим через $p_0$ вероятность события, состоящего в том, что за лимонадом пошел нулевой участник, а через $p_1$ — что пошел первый. Тогда $p_0 = \frac{61}{121} \approx 0,504, p_1 = \frac{60}{121} \approx 0,496$.

Нетрудно посчитать, что в случае «бросания» на одной руке при $n=2$ и $n=3$ шансы игроков быть выбранными одинаковыми и равны соответственно $\frac{1}{2}$ и $\frac{1}{3}$, а при $n=4$ $p_0=0,248, p_1=p_3=0,25, p_2=0,252$. С ростом $n$ перебор вариантов все более успешнее. Он проведен нами с помощью ЭВМ до $n=100$, исходя из следующих сообщений.

Обозначим через $\Pi_m^n(N)$ количество представления числа $N$ в виде суммы $n$ целых неотрицательных слагаемых, каждое из которых не превозходит числа $m$ (при этом представления, различающееся порядком слагаемых, считаются различными!). Обозначим также через $\Pi_i$ количество способов «бросания пальцев», при которых выбор падает на $i$-го участника, через $\Pi$ — общее количество вариантов «бросания пальцев», через $p_i$ — вероятность выбора $i$-го участника. Таким образом, $p_i = \frac{\Pi_i}{\Pi}$.

Числа $\Pi_i$ и $\Pi$ легко выражаются через $\Pi_m^n(N)$. Поскольку максимальное возможное число «выкинутьх пальцев» равно $mn$,

$$\Pi = \sum_{k=0}^{mn} \Pi_m^n(k).$$

Так как выбор падает на $i$-го участника, если число «выкинутьх пальцев» имеет вид $i+kn$, причем, очевидно, $k \leq m$ (заметим, что при $N > mn$ $\Pi_m^n(N)=0$),

$$\Pi_i = \sum_{k=0}^{m} \Pi_m^n(i+kn).$$

(1)

Число $\Pi_m^n(N)$ может быть подсчитано при помощи простой рекуррентной формулы. Количество интересующих нас представления числа $N$, при которых первое слагаемое есть 0, равно, очевидно, $\Pi_m^{n-1}(N)$; количество таких представлений, при которых первое слагаемое есть 1, равно $\Pi_m^{n-1}(N-1)$; при которых первое слагаемое есть 2 — $\Pi_m^{n-1}(N-2)$; и т. д. Поскольку первое слагаемое принимает одно из значений 0, 1, 2, ..., $m$, $\Pi_m^n(N) = \Pi_m^{n-1}(N) + \Pi_m^{n-1}(N-1) + \dots + \Pi_m^{n-1}(N-m) = \sum_{k=0}^{m} \Pi_m^{n-1}(N-k)$ (2)

(в этой сумме неокотряные слагаемые могут равнять 0: если $N$ — «маленькое», то, начиная с неокотряного $k$, может быть $N-k<0$ — тогда $\Pi_m^{n-1}(N-k)=0$; кроме того, если $N$ — «большое», то, вплоть до неокотряного $k$, может быть $N-k>m$ ($n-1$) — тогда тоже $\Pi_m^{n-1}(N-k)=0$).

Вычислив $\Pi_m^2(k)$ при всех $0 \leq k < N$, мы затем с помощью (2) найдем $\Pi_m^3(N)$ и т. д.

$$\Pi_i = \sum_{k=0}^{m} \Pi_m^n(i+kn) = \sum_{k=0}^{m} \left[ \Pi_m^{n-1}(i+kn) + \right. + \left. \Pi_m^{n-1}(i+kn-1) + \right. + \dots + \left. \Pi_m^{n-1}(i+kn-m) \right] = \sum_{k=0}^{m} \left\{ \Pi_m^n(i+km+k) + \right. + \left. \Pi_m^n(i+km+k-1) + \right. + \dots + \left. \Pi_m^n(i+km+k-m) \right\}.$$
