⟦folio 49⟧

Это безусловно знакомое всем уравнение парабOLSы. Заметим, что уравнение траектории второго саряда относительно земли будет точно таким же.

2) В этом случае начало системы отчета надо связать с самолетом. Относительно него начальная скорость саряда равна $u$, поэтому горизонтальная координата саряда будет изменяться по закону $x = ut$. Вертикальная же координата по-прежнему будет иметь вид $y = gt^2/2$. Следовательно перему служило преобразования, получим уравнение траектории саряда относительно движения самолета:

$$y = \frac{gx^2}{2u^2}.$$

Очевидно, что и здесь траектория движения саряда — парабола.

3) Для того чтобы описать движение первого саряда относительно второго, воспользуемся той же системой отчета, что и для первого саряда, то есть поместим начало координат в ту точку, где находится самолет в момент первого выстрела.

Запишем уравнение для координат $x_i$ и $y_i$ первого саряда и для соответствующих проекций $v_{1x}$ и $v_{1y}$ его скорости:

$$x_i = (u + v)t, \quad y_i = \frac{gt^2}{2},$$

$$v_{1x} = u + v, \quad v_{1y} = gt.$$

Здесь время $t$ отчитывается от момента первого выстрела, но по смыслу задачи оно не меньше интервала $t$ между выстреlamми, то есть $t \geq \tau$.

Аналогичные уравнения для второго саряда будут иметь вид:

$$x_2 = v\tau + (u + v)(t - \tau), \quad y_2 = \frac{g(t - \tau)^2}{2},$$

$$v_{2x} = u + v, \quad v_{2y} = g(t - \tau).$$

Если наблюдаются связи со вторым сарядом, то относительно него координаты (или проекции сористи) первого саряда равны разности соответствующих координат (или соответствующих проекций сористи) первого и второго сарядов в неподвижной системе отчета:

$$x_{1OTH} = x_1 - x_2 = (u + v)t - v\tau - (u + v)(t - \tau) = u\tau,$$

$$y_{1OTH} = y_1 - y_2 = \frac{gt^2}{2} - \frac{g(t - \tau)^2}{2} = g\tau - \frac{g\tau^2}{2},$$

$$v_{1OTH} = v_{1x} - v_{2x} = (u + v) - (u + v) = 0,$$

$$v_{1OTH} = v_{1y} - v_{2y} = gt - g(t - \tau) = g\tau.$$

Итак, после обихх выстрелов саряды по горизонтали движется с одинаковыми скоростями, так что расстояние между ними не изменяется и остается равным $x_{1OTH} = u\tau$. По вертикали же первый саряд движется относительно второго с помощью $v_{1OTH} = g\tau$, поэтому расстояние между сарядами с течениеми изменяется по закону $y_{1OTH} = g\tau - g\tau^2/2$.

Задча 2. В любой цитанке, движущемся со скоростью $v_\tau = 54$ км/ч, ударяется пуля, летящая со скоростью $v_0 = 1800$ км/ч под углом $\varphi = 60^\circ$ к направлению движения танк, и пругоотскакивает от него (рис. 1, а). С какой скоростью $\vec{v}$ полетит отскакивая пуля?

Задачу удобно сначала решить в системе отчета, связанной с танком, а затем перейти в неподвижную систему отчета.

Относительно танк скорость пуля до удара равна $\vec{v}'_0 = \vec{v}_0 - \vec{v}_\tau$ (рис. 1, б). После пругого удара модель скорости пуля $\vec{v}'$ остается прежним ($\vec{v}' = \vec{v}_0'$), а угол «отражения» $\alpha'$ будет равен углу «падения» $\varphi'$.
