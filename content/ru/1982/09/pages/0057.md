$$\left(\frac{q-n}{m-p}\right)^2 + m \left(\frac{q-n}{m-p}\right) + n < 0.$$

Получим многочлен $g(x) = (x+\beta)^3 + a(x+\beta)^2 + b(x+\beta) + c$, имеющий корни $x_1, 0, -x_1$ (рис. 4). Видно, что функция $g$ нечетна.

Докажем это. Если в выражении $g(x)$ раскрыть скобки и приведти подобные члены, коэффициент при $x^3$ оказывается равным 1. Обозначим остальные коэффициенты буквами $A, B, C$: $g(x) = x^3 + Ax^2 + Bx + C$. Поискольку числа $x_1, 0$ и $-x_1$ служат корнями многочлена $g(x)$,

$$\begin{cases}
x_1^3 + Ax_1^2 + Bx_1 + C = 0 \\
C = 0 \\
-x_1^3 + Ax_1^2 - Bx_1 + C = 0
\end{cases}$$

откуда $A = C = 0$; значит, $g(x) = x^3 + Bx$ — нечетная функция.

Полученная нами информацию о расположении графика функции $g$ пока еще неполна. Ведь нечетны и те функции, графики которых изображены на рисунке 5, однако эти кубические многочлены имеют всего по одному корню. Чтобы появились еще два корня, необходимо «изогнуть» график в начале координат. Для этого надо, чтобы касательная к графику в этой точке образовывала с осью абсцисс тупой угол, то есть чтобы произvodная $g'(0)$ была отрицательной.
