Заочная школа программирования
Урок 18: Файлы

Что такое файл?
Файл — это неокотрый набор элементов одного и того же типа, число которых заранее не определено.

Тип файла описывает следующей синтаксической диаграммой:

```
file of min
```

тип есть общий тип элементов файла. Будем называть его базовым. Имеется стандартный (то есть существующий для любой программы и не подлежащий описанию в ней) тип файла с именем text. Его базовым типом является тип char. Файлы типа text называются текстовыми файлами.

Элементы файла считаются расположенными последовательно, то есть так же, как элементы вектора. Отличается же файл от вектора, во-первых, тем, что размер его могут меняться, а, во-вторых, тем, что способ обращения к его элементам совсем другой: невозможно обратиться к произвольному элементу файла; элементы его просматривают только подряд, от начала к конца, при этом каждый раз доступен только один элемент. С каждым файлом f связана переменная, которая обозначает f↑; ее тип совпадает с базовым типом файла. Она называется буфером этого файла или буферной переменной. В буфере может размещаться только один элемент файла;

Значение этого элемента и служит значением буфера. Буфер — это как бы окошко, через которое можно просматривать файл, выбирая элементы по одному.

Если файл просмотрен до конца (или если он вообше пуст) то будем считать его оконченным. Если файл окончен, то значение его буфера не определено.

Процедуры работы с файлами
Проверить, окончен ли файл f, можно вызовом стандартной логической функции

eof(f)
Она вырабатывает значение true, если f окончен, и false — в противном случае*).

Пусть необходимо просмотрить файл f. Для этого надо прежде всего вызывать стандартную процедуру

reset(f)
(«reset» означает «возвращать»). В результате ее выполнения значением буфера f↑ станет первый элемент файла (если файл не пуст).

Перейти от одного элемента файла к следующему можно с помощью вызовов стандартной процедуры

get(f)
(«get» означает «взять»). После его выполнения в f↑ будет значение этого следующнего элемента, если он есть. (Если же следующнего элемента нет, то файл станет оконченным.) К уже оконченному файлу применять процедуру get нельзя.

Рассмотрим пример. Пусть f1 и f2 — файлы с базовым типом real, аровно и b — переменные типа boolean. Переменной равно нужно присовратить значение true, если содержимое f1 и f2 одинаково (то есть эти файлы имеют одинаковую длину, быть может нульевую, а их соответствующие элементы попарно равны), и false в противном случае.

*) eof — сокращение английских слов end of file (конец файла).

Эту задачу можно выполнить следующим образом:

```python
reset(f1); reset(f2); b:=true;
while b AND NOT eof(f1)
    AND NOT eof(f2)
do begin b:=f1↑=f2↑;
    get(f1); get(f2)
end;
if b then равно:=eof(f1)ANDeof(f2)
else равно:=false;
```

Если оба файла пустые, то тело цикла не выполнится ни разу и равно получит значение `true`. Пока очередные элементы файла попарно совпадают, `b` получает в теле цикла значение `true` и оператор цикла продолжает работу. Цикл перекратится, если очередные элементы не совпадут или хотя один из файлов будет окончен. В первом случае `b` по выходе из цикла имеет значение `false` и последний оператор присвоит это значение переменной `равно`. Если же по выходе из цикла `b` имеет значение `true`, то это значит, что один из файлов получилось совпадет с начальным фрагментом другого файла. В этом случае последний оператор проверяет, не окончился ли одновременно и второй файл. Если да, то равно получает значение `true`, а если другой файл еще не окончен, то false.

Пусть теперь известно, что файл `f1` содержит не менее 10 элементов, и требуется первые 10 из них перевести в массив `m`, тип которого есть `array [1..10]` of `real`. Это можно сделать следующим образом (i — переменная типа `integer`):

```python
reset(f1);
for i:=1 to 10 do
begin m[i]:=f1↑;get(f1) end;
```

Послеовательность операторов `v:=f↑; get(f)` (1) где `v` — переменная, а `f` — файл, встречается довольно часто. Поэтому в Паскале существует стандартная процедура `read` такая, что вызов `read(f,v)` равноселен пале операторов (1). Теперь наш пример можно переписать короче:

```python
reset(f1);
for i:=1 to 10 do read(f1, m[i]):
```

Итак, мы научились читать из файла. Посмотрим теперь, как его заполнять. Существует стандартная процедура `rewrite` (переписать) такая, что после вызова `rewrite(f)` файл `f` становится пустым и готовым к заполнению. Чтобы выполнить файл значением неокотого выражения `E`, надо выполнить присваивание `f↑:=E`, а затем — вызов стандартной процедуры `put(f)` («put» означает «поместить»). Этот вызов присоединит к концу файла значение `f↑;` файл, таким образом, удалится на один элемент. Процедура `put` можно применять, только если файл окончен, и после ее вызова он продолжает оставаться оконченным: нельзя записывать новые элементы в середину файла. Пара операторов

```python
f↑:=E; put(f)
равносильна оператору
write(f, E)
```

где `write` — стандартная процедура.

Например, заполнить файл `fi`, базовый тип которого — `integer`, целыми числами от 1 до 100, можно так:

```python
rewrite(fi);
for i:=1 to 100 do write(fi, i)
```

Особенно текстовых файлов являются то, что с помощью процедуры `write` в них можно заполнить значения не только базового типа `char`, но и других простых типов, а с помощью процедуры `read` из них можно осуществлять засылку в переменные любого простого типа. Файлы и ввод-вывод

Легко заметить, что работа с файлами очень похожа на механизм ввод-вывод. Мы сейчас покажем, какая между ними связаь.

Вызов процедуры
write (x)
с параметром простого типа осуществляется выдачу значения x на печатающее устройство (см. урок 15). Считается, что с печатающим устройством связан стандартный текстовой файл output. Выдача на печать есть не что иное, как пополнение этого файла, а write (x) — это сокращенная запись для

write (output, x)
Считалосьим устройством в свою очередь связан стандартный текстовый файл input, а
read (x)
есты сокращение для
read (input, x)
Файл input нельзя пополнять и к нему нельзя применять процедура reset. (Эта процедура как бы уже проверала к началу выполнения программы). Точно так же к файлу output неприменимы чтение и процедура rewrite. Эти два файла не нужно описывать в программе (на то они и стандартные), но, как известно из урока 15, их обязательно надо перечислять в заголовке программы.

Если задача требуется, чтобы какая-либо информация хранилась во внешней памяти, то для этой информации нужны дополнительные внешние файлы. Их надо описать наряду со всеми остальных переменными программы и перечислять в заголовке наряду с input и output. Если же имя файла в заголовке отсутствует, то этот файл служит лишь для обмена информацией внутри программы.

Сортировки по текстовым ключиам. Слияния

Сортировкой называют действие, которое упорядочивает совокупность данных по значениям некоторого признака. Таким образом, элементы упорядочиваемой совокупности являются по определенному сложными, многокомпонентными объектами — данных структурных типов; как правило, признак — это только одна из компонент сортируемых элементов. В общий литературе по методам сортировки те признаки, по значениям которых оценывается упорядоченное сортируемой совокупности, чаще называют ключими. Сортировки становятся возможными, когда на совокупности значений ключи установлено отношение порядка.

Ниболье распространяется объектами, к которым применяются сортировки, являются совокупности данных одинаковых типов. Различют две разновидности таких совокупностей: массивы — совокупности данных с известным, фиксированным количеством элементов и файлы, размеры которых, вообще говоря, неизвестны и могут изменяться в ходе выполнения программы. Соответственно, упорядочение массивов осуществляется, как правило, внутри сортировками, применяемых только к данным, расположенным в оперативной памяти ЭВМ, а для файлов чаще всего приходит пользоваться внешними сортировками, которые могут операровать с данными, расположенными на внешних запоминающих устройствах — магнитных лентах, дисках, периферийных.

С проблемой упорядоченности информации приходит встречается постоянно. В ведомости заработной платы ее элементы-строки могут быть упорядочены в порядке возрастания таблиных номеров сортиников. Здесь ключи — это таблиный номер, относение порядка — возвращение натуральных чисел. Итоговый протокол выполняет годный частотный процесс управления по результатам, показанным участникам соревнований. Здесь ключи — действительное*) число результата.

Список школьников одного класса тоже всего упорядочается. Здесь ключи фамилия являются текстами. Объчно тексты упорядочиваются как слова в словаре — по алфавиту, в порядке, который называют лексикографическим: если фиксирован порядок букв в алфавите, то из двух значений ключевой к1 и к2 представляет сумму считается тó, у которой к1[1]→к2[1] в алфавитном порядке (первая буква первого текста представляет первый букве второго текста), а при равенстве к1[1]=к2[1]—то, у которой к1[2]→к2[2] и т. д. Так, 'слое'→'слон', как в словаре.

Относительная порядок двух букв или двух слов можно, таким образом, установить и даже обозначить: значок «→» означает «предшествует». Однако для практических целей — определения и установления лексикографого упорядочения текстов в программе, написанной на примере, на Паскале — было бы полезнее иметь дело не с отношением «→»,

*) Важно помнить, что в программировании и в математике действительные числа определяются по-разному. В машине представим только числа с ограниченным числом цифр. Таким образом, «действительные» числа, как их понятие программисты, это подложево рациональные чисел.

С помощью этой константы каждой букве алфавита (и, более широко, каждому символу) ставится в соответствие число 1, букве а — число 2,..., букве я — число 34. Самому «старшему» символу — восклицательному знаку ! — поставлен в соответствие номер 64. Обратите внимание, что пробел представляет всем символам алфавита.

Тепер сравнение двух символов легко реализовать, сравнить соответствующие им числа, при наличии такой функции число:

```javascript
function число(x:char):integer;
var i:integer;
begin
i:=1;
while i<=64 do
if x=alфавит[i]
then begin число:=i;
i:=65 end;
else i:=i+1
end
```

с помощью которого, например, упоминавшееся условие `κ1/2→κ2/2` можно свести к условию `число(κ1/2)<число(κ2/2)`

Функция `число` понадобилась только потому, что для нас оказывается существенную упорядоченность по алфавиту (1). Если мы удовлетворили с стандартным алфавитом Паскала, в котором перечисляются сначала буквы от `a` до `z`, затем не совпадающее с ними по начертанию русские буквы, затем цифры и прочие символы, то тогда для целей преобразования литерах `x` в число, равное номеру этой литерам в стандартном алфавите, можно было бы воспользоваться стандартной функцией Паскала `ord(x)`.

Использовая отношения вида (2), можно определить относительной порядок любых двух текстов. Например, для ‘слое’ и ‘слон’ можно выполнить серий проверок для первых буквы `число('c')=число('c')` для вторых буквы `число('l')=число('l')` для третьих буквы `число('o')=число('o') но для четверых буквы имеет место `число('e')<число('n')`

откуда и следует, что ‘слое’→‘слон’.

Такие серии проверок можно выполнять для любых двух заданных текстов с помощью функции `сравнение` (x1, x2). Эта функция вырабатывает логическое значение `true`, если `x1→x2` или если тексты `x1` и `x2` совпадают. Если же `x2→x1`, то вырабатываемое этой функции значение есть, `false`. Тогда, если в программе важно установить истинность условия `x1→x2`, то можно пользоваться реализуемым в Паскале условиями `сравнения` (x1, x2) = `true`. Если предварительно описан тип `type` массив =
