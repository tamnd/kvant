Долго ли палке упасть?
1. В рассматриваемом промежутке
$$\frac{\varepsilon}{4} < \lg \frac{\varepsilon}{4} < \frac{\varepsilon}{2}.$$
Позному
$$Q \left[ \ln \lg \frac{\pi}{8} - \ln \frac{\varepsilon}{2} \right] \leq T \leq$$
$$\leq Q \left[ \ln \lg \frac{\pi}{8} - \ln \frac{\varepsilon}{4} \right],$$
откуда следует требуемые оценки.
2. Время падания
$$T = \sqrt{\frac{l}{2g}} \int_0^{\frac{\pi}{2}} \frac{d\alpha}{\sqrt{\frac{v^2}{2gl}} + 2 \sin^2 \frac{\alpha}{2}}.$$
Этот интервал собственный, максимум подбитерральной функции достигается при $\alpha = 0$. При $v \to 0$ этот интервал стремится к бесконечности, что видно из следующих преобразований, где $\frac{v^2}{2gl}$ обозначает через $\varepsilon$:
$$\int_0^{\frac{\pi}{2}} \frac{d\alpha}{\sqrt{\varepsilon + 2 \sin^2 \frac{\alpha}{2}}} \geq \int_0^{\frac{\pi}{2}} \frac{d\alpha}{\sqrt{\varepsilon + \sqrt{2} \sin \frac{\alpha}{2}}} \geq$$
$$\geq \int_0^{\frac{\pi}{2}} \frac{d\alpha}{\sqrt{\varepsilon + \frac{\sqrt{2}}{2} \alpha}} = \sqrt{2} \ln \left( \frac{\sqrt{2}}{2} \alpha + \sqrt{\varepsilon} \right) \Bigg|_0^{\frac{\pi}{2}} =$$
$$= \sqrt{2} \left[ \ln \left( \frac{\pi}{2 \sqrt{2}} + \sqrt{\varepsilon} \right) - \ln \sqrt{\varepsilon} \right] =$$
$$= \sqrt{2} \ln \frac{\pi}{2 \sqrt{2}} - \frac{\sqrt{2}}{2} \ln \varepsilon.$$
Попутно мы получили логарифмическую оценку силы для времена падания. Аналогичная оценка сверху может быть получена из следующих сообщений:
$$\frac{1}{\sqrt{\varepsilon + 2 \sin^2 \frac{\alpha}{2}}} \leq \min \left\{ \frac{1}{\sqrt{\varepsilon}}; \frac{1}{\sqrt{2 \alpha}} \right\}.$$
$$\int_0^{\frac{\pi}{2}} \min \left\{ \frac{1}{\sqrt{\varepsilon}}; \frac{1}{\sqrt{2 \alpha}} \right\} d\alpha =$$
$$= \int_0^{\frac{\pi}{2}} \frac{d\alpha}{\sqrt{\varepsilon}} + \frac{1}{\sqrt{2}} \int_0^{\frac{\pi}{2}} \frac{d\alpha}{\sqrt{\varepsilon}} =$$
$$= \frac{1}{\sqrt{2}} + \frac{1}{\sqrt{2}} \ln \frac{\pi}{2} + \ln \sqrt{2}) - \frac{1}{2} \ln \varepsilon.$$
3. Время падания
$$T = \sqrt{\frac{l}{2g}} \int_0^{\frac{\pi}{2}} \frac{d\alpha}{\sqrt{\cos \beta - \cos \alpha}}.$$
Этот интервал несобственный, так как подбитерральная функция стремится к бесконечности при $\alpha \rightarrow \beta$. Но он конечен, что видно из следующих оценок:
$$\cos \beta - \cos \alpha = 2 \sin \frac{\alpha + \beta}{2} \sin \frac{\alpha - \beta}{2} \geq$$
$$\geq 2 \cdot \frac{\alpha + \beta}{4} \cdot \frac{\alpha - \beta}{4} = \frac{1}{8} (\alpha^2 - \beta^2).$$
$$\int_0^{\frac{\pi}{2}} \frac{d\alpha}{\sqrt{\cos \beta - \cos \alpha}} \leq \sqrt{8} \int_0^{\frac{\pi}{2}} \frac{d\alpha}{\sqrt{\alpha^2 - \beta^2}}.$$
По формуле дифференцирования сложной функции
$$[\ln(x + \sqrt{x^2 - \beta^2})]' = \frac{1}{\sqrt{x^2 - \beta^2}}.$$
Позному
$$\int_0^{\frac{\pi}{2}} \frac{d\alpha}{\sqrt{\cos \beta - \cos \alpha}} = \ln \left( \frac{\pi}{2} + \sqrt{\frac{\pi^2}{4} - \beta^2} \right) - \ln \beta \leq$$
$$\leq \ln \pi - \ln \beta.$$
Итак, мы получили обещанную оценку сверху. Аналогичная оценка силы может быть получена следующим образом:
$$\sqrt{\cos \beta - \cos \alpha} = \sqrt{2 \sin \frac{\alpha + \beta}{2} \sin \frac{\alpha - \beta}{2}} \leq$$
$$\leq \sqrt{\frac{1}{2}} (\alpha + \beta) (\alpha - \beta) \leq \frac{\alpha}{\sqrt{2}} \leq \alpha.$$
Позному
$$\int_0^{\frac{\pi}{2}} \frac{d\alpha}{\sqrt{\cos \beta - \cos \alpha}} \geq \int_0^{\frac{\pi}{2}} \frac{d\alpha}{\sqrt{\cos \beta - \cos \alpha}} = \ln \frac{\pi}{2} - \ln \beta.$$
