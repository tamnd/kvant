Заочная школа программирования
Урок 18: Файлы

Что такое файл?
Файл — это неокотрый набор элементов одного и того же типа, число которых заранее не определено.

Тип файла описывает следующей синтаксической диаграммой:

```
file of min
```

тип есть общий тип элементов файла. Будем называть его базовым. Имеется стандартный (то есть существующий для любой программы и не подлежащий описанию в ней) тип файла с именем text. Его базовым типом является тип char. Файлы типа text называются текстовыми файлами.

Элементы файла считаются расположенными последовательно, то есть так же, как элементы вектора. Отличается же файл от вектора, во-первых, тем, что размер его могут меняться, а, во-вторых, тем, что способ обращения к его элементам совсем другой: невозможно обратиться к произвольному элементу файла; элементы его просматривают только подряд, от начала к конца, при этом каждый раз доступен только один элемент. С каждым файлом f связана переменная, которая обозначает f↑; ее тип совпадает с базовым типом файла. Она называется буфером этого файла или буферной переменной. В буфере может размещаться только один элемент файла;

Значение этого элемента и служит значением буфера. Буфер — это как бы окошко, через которое можно просматривать файл, выбирая элементы по одному.

Если файл просмотрен до конца (или если он вообше пуст) то будем считать его оконченным. Если файл окончен, то значение его буфера не определено.

Процедуры работы с файлами
Проверить, окончен ли файл f, можно вызовом стандартной логической функции

eof(f)
Она вырабатывает значение true, если f окончен, и false — в противном случае*).

Пусть необходимо просмотрить файл f. Для этого надо прежде всего вызывать стандартную процедуру

reset(f)
(«reset» означает «возвращать»). В результате ее выполнения значением буфера f↑ станет первый элемент файла (если файл не пуст).

Перейти от одного элемента файла к следующему можно с помощью вызовов стандартной процедуры

get(f)
(«get» означает «взять»). После его выполнения в f↑ будет значение этого следующнего элемента, если он есть. (Если же следующнего элемента нет, то файл станет оконченным.) К уже оконченному файлу применять процедуру get нельзя.

Рассмотрим пример. Пусть f1 и f2 — файлы с базовым типом real, аровно и b — переменные типа boolean. Переменной равно нужно присовратить значение true, если содержимое f1 и f2 одинаково (то есть эти файлы имеют одинаковую длину, быть может нульевую, а их соответствующие элементы попарно равны), и false в противном случае.

*) eof — сокращение английских слов end of file (конец файла).
