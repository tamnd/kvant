С помощью этой константы каждой букве алфавита (и, более широко, каждому символу) ставится в соответствие число 1, букве а — число 2,..., букве я — число 34. Самому «старшему» символу — восклицательному знаку ! — поставлен в соответствие номер 64. Обратите внимание, что пробел представляет всем символам алфавита.

Тепер сравнение двух символов легко реализовать, сравнить соответствующие им числа, при наличии такой функции число:

```javascript
function число(x:char):integer;
var i:integer;
begin
i:=1;
while i<=64 do
if x=alфавит[i]
then begin число:=i;
i:=65 end;
else i:=i+1
end
```

с помощью которого, например, упоминавшееся условие `κ1/2→κ2/2` можно свести к условию `число(κ1/2)<число(κ2/2)`

Функция `число` понадобилась только потому, что для нас оказывается существенную упорядоченность по алфавиту (1). Если мы удовлетворили с стандартным алфавитом Паскала, в котором перечисляются сначала буквы от `a` до `z`, затем не совпадающее с ними по начертанию русские буквы, затем цифры и прочие символы, то тогда для целей преобразования литерах `x` в число, равное номеру этой литерам в стандартном алфавите, можно было бы воспользоваться стандартной функцией Паскала `ord(x)`.

Использовая отношения вида (2), можно определить относительной порядок любых двух текстов. Например, для ‘слое’ и ‘слон’ можно выполнить серий проверок для первых буквы `число('c')=число('c')` для вторых буквы `число('l')=число('l')` для третьих буквы `число('o')=число('o') но для четверых буквы имеет место `число('e')<число('n')`

откуда и следует, что ‘слое’→‘слон’.

Такие серии проверок можно выполнять для любых двух заданных текстов с помощью функции `сравнение` (x1, x2). Эта функция вырабатывает логическое значение `true`, если `x1→x2` или если тексты `x1` и `x2` совпадают. Если же `x2→x1`, то вырабатываемое этой функции значение есть, `false`. Тогда, если в программе важно установить истинность условия `x1→x2`, то можно пользоваться реализуемым в Паскале условиями `сравнения` (x1, x2) = `true`. Если предварительно описан тип `type` массив =
`packed array [1...20] of char`
то функция `сравнение` описывается так:

```javascript
function сравнение(x1,x2: массив):boolean;
var номер:integer;
begin
номер:=0
while номер<=20 do
begin
номер:=номер+1;
if число(x1|номер|)<>
    число(x2|номер|)
then сравнение:=true
else сравнение:=false
номер:=21
end
else if номер>20
then сравнение:=true
end
end;
```

В том виде, как описана функция `сравнение` здесь, она работает с двацати-литерными словами-массивами `x1` и `x2`. Длина слова выбрана такой, чтобы сделать возможность использовать этой функции для сравнения фамилии: это один из наиболее часто используемых ключевых слови во многих применениях сортировок. Ограничение в 20 литер всегда при желании можно заменить более сильным или, наоборот, более слабым ограничением. Конечно, длинные сравнительные процедуры, которые пересылает каждое из сравнительных слов-массивов в массив, составленный из 20 пробелов. Именно результат этой процедуры, описать которой читателью, по-видимому, не составит труда, и служит фактическим параметром при обращении к функции `сравнение` (x1, x2). В прочеем, такая предварительная процедура будет не нужна, если обязатель программы, работающего с функцией `сравнение`, записывается значения ключевой так, чтобы они занималировали 20 литер, из которых последнее представляют в большинстве случайные пробелы.
