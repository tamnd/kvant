Делится на $q$; из чисел, кратных $q$,ровно $\left[\frac{l}{q^2}\right]$ делится на $q^2$; из чисел, кратных $q^2$,ровно $\left[\frac{l}{q^3}\right]$ делится на $q^3$ и т. д.;позтому

$$t = \left( \left[\frac{l}{q}\right] - \left[\frac{l}{q^2}\right] \right) + 2 \left( \left[\frac{l}{q^2}\right] - \left[\frac{l}{q^3}\right] \right) + 3 \left( \left[\frac{l}{q^3}\right] - \left[\frac{l}{q^4}\right] \right) + \ldots = \left[\frac{l}{q}\right] + \left[\frac{l}{q^2}\right] + \left[\frac{l}{q^3}\right] + \ldots$$

(очевидно, здесь все слагаемые, начная с неокоторого, — нули). Поэтому, если $s$ — показатель степени, в котором $p$ входит в $\frac{m!}{n!(m-n)!}$, то $s = \sum_k \left( \left[\frac{m}{p^k}\right] - \left[\frac{n}{p^k}\right] - \left[\frac{m-n}{p^k}\right] \right)$,причем при $k > \log_p m$ слагаемые обращаются в нуль, а при $k \leq \log_p m$ — не превозходят 1, либо являются целыми числами, меньшими 2:

$$\left[\frac{m}{p^k}\right] - \left[\frac{n}{p^k}\right] - \left[\frac{m-n}{p^k}\right] = \left\{ \frac{n}{p^k} \right\} + \left\{ \frac{m-n}{p^k} \right\} - \left\{ \frac{m}{p^k} \right\} < 2.$$

В силу этого $s$ не превозходит числа слагаемых, то есть $s \leq \log_p m$. Поэтому $r \leq s \leq \log_p m$, то есть $p^r \leq m$.

Равенство $p^r = m$ достигается для всех $m$, являющихся степенью простого числа.
