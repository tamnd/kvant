⟦folio 51⟧

В этом случае фактический параметр должен быть переменной заданного типа, а формальный параметр служит обозначением этой переменной во все время данного выполнения процедуры. Если в фактическом параметре имеются индексы, то они вычисляются в момент вызова процедуры.

Параметр-переменная необходимо во всех случаях, когда параметр используется для представления результата процедуры или функции.

В программах сортировок, расматривающихся во втором номере «Кванта», уже использовался такой вид параметров.

Пусть имеются следующие описания:

```python
var k:integer;
b:array [1...100]of real;
procedure max(var i:integer);
{1≤i<100}
var j:integer;
begin
for j:=i+1 to 100 do
if b[i]<b[j]then i:=j
end;
```

Тогда после выполнения операторов `k:=20; max(k)` переменной `k` будет присвоен индекс наиболее элемента из `b[20], b[21], ..., b[100]`.

```python
procedure заменa(var x,y:integer);
var z:integer;
begin
z:=x;
x:=y;
y:=z
end
```

для обмена значениями у любых двух переменных целого типа? Например, помещается ли значение у переменных `k` и `a[20]` после вызова замена (`k, a [k+1]`), если это его выполнения к было равно 19?

Задание 20.3. Пусть имеются описания

```python
type табличца=array[1..2,1..2] of integer;
procedure умножение(var x,y,z:tabличца);
begin
z[1,1]:=x[1,1]*y[1,1]+x[1,2]*y[2,1];
z[1,2]:=x[1,1]*y[1,2]+x[1,2]*y[2,2];
z[2,1]:=x[2,1]*y[1,1]+x[2,2]*y[2,1];
z[2,2]:=x[2,1]*y[1,2]+x[2,2]*y[2,2]
end;
```

и даны три таблицы

```python
a = (1 1) , b = (2 2) , c = (3 3) .
```

Определить вид таблицы `a`, `b` и `c` после каждого из вышеов:

`умножение (a, b, c)`, `умножение (a, b, a)`, `умножение (a, b, b)`. Что произойдет при этих же вызовах, если параметры `x` и `y` сделать параметрами значениями? Что будет, если и z становится параметром-значением?
