6) Суммы
$$\sum_{1 \le k_1 < k_2 < \dots < k_q \le p-1} \prod_i k_i$$
и
$$\sum_{1 \le k_1 < k_2 < \dots < k_q \le p-1} \prod_i (p^-k_i)$$ отличются

только порядком слагаемых (если $k<p$, то и $p-k-p$). Поэтому при нечетном $q$ (3≤q≤2)

$$S_q = \sum_{1 \le k_1 < k_2 < \dots < k_q \le p-1} \prod_i k_i =$$
$$= \sum_{1 \le k_1 k_2 < \dots < k_q \le p-1} \prod_i (p^-k_i) =$$
$$= C_q^{p-1} p^q + \sum_{i=1}^{q-1} (-1)^i C_q^{q-i-j} p^{q-j} S_j - S_q,$$

то есть
$$2S_q = C_q^{q-1} p^q + \sum_{j=1}^{q-1} (-1)^j C_q^{q-i-j} p^{q-j} S_j,$$
откуда, учитывая, что все $S_j$ делятся на $p$, получаем, что $S_q$ делится на $p^2$.
