$$\Phi(z) = \frac{1}{(u-z)(v-z)} = \left( \frac{1}{v-z} - \frac{1}{u-z} \right) \frac{1}{u-v} = \left( \frac{u}{1-zu} - \frac{v}{1-zw} \right) \frac{1}{u-v} = \sum_{n \geq 0} \frac{u^{n+1}-v^{n+1}}{u-v} z^n,$$

то есть $P_n(x) = \left( u^{n+1}-v^{n+1} \right) / (u-v)$; это формула (3).

2) Найдем из (8) отдельные коэффициенты каждого многочлена $P_n(x)$. Делается это так:

$$\Phi(z) = \frac{1}{1-(xz-z^2)} = \sum_{k>0} \left( xz-z^2 \right)^k = \sum_{k>0} \left( \sum_{0<j<k} (-1)^j C_k^j x^{k-j} z^{k+j} \right) = \sum_{n>0} z^n \left( \sum_{j} (-1)^j C_{n-j}^j \cdot x^{n-2j} \right)$$

(мы воспользовались формулами суммы бесконечной геометрической прогрессии (7), биома Ньютона (6) и выделили коэффициент при $z^n$, который и есть нужный нам $P_n(x)$). Следовательно,

$$P_n(x) = \sum_{j} (-1)^j C_{n-j}^j x^{n-2j}$$

(например: $P_6(x) = C_6^0 x^6 - C_5^1 x^4 + C_4^2 x^2 - C_3^3 = x^6 - 5x^4 + 6x^2 - 1$).

Конечно, доказать готовые формулы (3) и (10) можно без произвольных функций — самое замечательное, как они возникли, почти сами собой, из короткой формулы (8).

Обоснование всех действия с бесконечными рядами, которые мы производили — а оно, разумеется, необходимо, — можно было бы проверить, либо заметив, что при необходимости по модели числовых значениях $z$ все рассматриваемые ряды сходятся (как (7) при $|z| < 1/|q|$), то есть представляют настоящие функции от $z$, либо проверив, что для определенных формулыально операционный сложения, умножения и т. д. (каждый коэффициент ряда выражается через конечное число других, а $z$ — просто буква!) выполены все обычные законы. Подробнее с методом произвольных функций и степеними рядами можно познакомиться по книгам [3], [4], [6].
