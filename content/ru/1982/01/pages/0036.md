Из среды с показателем преломления $n_0$ в неоднородный слой входит луч света. При каких значениях уела a луч вернется в оптически более плотную среду? Рис. 2.
Ф697. Между двумя средами с показателями преломления $n_0 > 1$ и $n_1 = 1$ имеет неоднородный слой высотей $h = H \left(1 - \frac{1}{n_0^2}\right)$, где $H = \text{const}$, внутри которого показатель преломления меняется с высотой по закону $n = n_0 \sqrt{1 - \frac{y}{H}}$ (см. рисунок). Из среды с показателем преломления $n_0$ в неоднородный слой входит луч света. При каких значениях уела $a_0$ расстояние между точками входа и выхода луча максимально?

Из закона преломления света следует, что при изменяющемся коэффициенте преломления среды изменяется угол ф отклонения луча от нормали (к границе раздела между условиями участками среды с разными значениями $n$), причем
$$n \sin \varphi = n \cos \alpha = n_0 \sin \varphi_0 = n_0 \cos \alpha_0 = \text{const}, \quad \text{где } \alpha = \frac{\pi}{2} - \varphi$$
Для нахождения траектории луча в неоднородной среде воспользуемся следующей аналгейм: тело массы $m$ (размеры тела пребежжимо малы) движется по траектории луча, скорость тела в точке с ordinатой $y$ равна $v(y) = v_0 n_y$ ($v_0$ — величины начальной скорости тела в точке с ordinатой 0). Тогда проекция скорости на границу раздела (горизонтальная проекция) остается постоянной. Если при этом на точку действует постоянная сила $F = \frac{mv_0^2}{2H}$, направленная вертикально в либой точке траектории
$$\frac{m(v(y))^2}{2} = \frac{mv_0^2}{2} - m \frac{v_0^2}{2H} y.$$
Видно, что при заданном законе изменения $n(y)$ траектория луча совпадает с траекторией тела, брошенного под углом к горизонту и движущшегося под действием «силы тяжестии» $F = mv_0^2/2H$. Поэтому для ответа на поставленные в задаче вопросы можно воспользоваться формулами для такого движения, учитывая, что «ускорение свободного падения» в нашем случае равно «g» = $v_0^2/2H$.
Итак, расстояние $l$ между точками входа и выхода луча будет максимальным, если луч входит в неоднородную среду под углом $\varphi_0 = 45^\circ$. При этом
$$I_{\max} = \frac{2vA_0^2 \sin \alpha_0 \cos \alpha_0}{v_0^2/2H} = 2H$$ (так как $\alpha_0 = \frac{\pi}{2} - \varphi_0 = 45^\circ$).
Для того чтобы при $\alpha_0 = 45^\circ$ луч не прощел в верхнюю однородную среду, высота $h$ неоднородной области должна удовлетворять условию $h \geq \frac{H}{2}$. В противном случае ($h < \frac{H}{2}$) максимальное расстояние между точками входа и выхода луча соответствует такому углу $\alpha'$, при котором высота траектории равна $h'$, то есть траектория касается верхней границы раздела. Этот угол $\alpha'$ находим из условия
$$n_0 \cos \alpha' = n(y = h') \cos 0^\circ = n_0 \sqrt{1 - \frac{h'}{H}};$$
$$\cos \alpha' = \sqrt{1 - \frac{h'}{H}}.$$
П. Калуени
