Пусть теперь $A'_1, \dots, A'_n$ и $O'$ — проектини точек $A_1, \dots, A_n$ и $O$ на произвольную прямую (см. рисунок). Согласно лемме нам достаточно доказать, что

$$p' = |A'_1A'_2| + |A'_2A'_3| + \dots$$

$$\dots + |A'_nA'_1| \geqslant \frac{4}{n} \left( |O'A'_1| + \dots + |O'A'_n| \right).$$

Заметим, что $O'A'_1 + \dots + O'A'_n = 0$, так как сумма проектини несколько векторов равна проектини их суммы. Поэтому координаты точек $A'_1, \dots, A'_n$ на числовой оси $l$ с началом координат $O'$ образуют набор чисел, удовлетворяющий условию пункта a). Сумма $a$ абсолотных величины этих чисел равна сумме в правой части неравенства (*), а разность между набольшим и наименьшим из них — длине проектини многоугольника, то есть положие суммы $p'$ длин проектини всех его сторон. В силу утверждения a) $p'/2 \geqslant 2a/n$ и неравенство (*) доказано.

Второе решение. (Это решение предложил ученик 10-го класса ФМШ № 18 г. Москвы C. Матюшов.) Для любой точки $A$

$$\overrightarrow{OA} = \frac{1}{n} \left( (\overrightarrow{OA}_1 + \overrightarrow{A_1A}) + \dots + (\overrightarrow{OA}_n + \overrightarrow{A_nA}) \right) =$$

$$= \frac{1}{n} \left( \overrightarrow{OA}_1 + \dots + \overrightarrow{OA}_n \right) + \frac{1}{n} \left( \overrightarrow{A_1A} + \dots + \overrightarrow{A_nA} \right) =$$

$$= \frac{1}{n} \left( \overrightarrow{A_1A} + \dots + \overrightarrow{A_nA} \right).$$

Отсюда сразу следует неравенство

$$|OA| \leqslant \frac{1}{n} \left( |AA_1| + \dots + |AA_n| \right).$$

Полагая в нем последовательно $A = A_1, A = A_2, \dots, A = A_n$ и складывая все полученные неравенства, мы найдем, что

$$d = |OA_1| + \dots + |OA_n| \leqslant \frac{2}{n} \sum |A_iA_j|$$

(**)

(каждое слагаемое $|A_iA_j|$, $1 \leqslant i < j \leqslant n$, входит в сумму один раз, так что она представляется собой сумму длин всех сторон и диагоналей многоугольника).

При нечетном $n$ имеется $n$ сторон, $n$ диагоналей, отсекающих 1 вершину, $n$ диагоналей, отсекающих 2 вершины, ..., $n$ диагоналей, отсекающих $\frac{n-3}{2}$ вершины. Длина диагонали, отсекающей $k$ вершин, не превыходит длины $(k+1)$-звенной ломаной из сторона многоугольника, соединяющей концы диагонали. Поэтому сумма длины таких диагонали не больше $(k+1)p$, где $p$ — перimeter многоугольника и (**) переписывается так:

$$d \leqslant \frac{2}{n} \left( p + 2p + \dots + \frac{n-1}{2} p \right) = \frac{n^2 - 1}{4n} p,$$

то есть $p \geqslant \frac{4n}{n^2 - 1} d.$
