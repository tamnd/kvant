Искусство программирования

Стадартные приемы программирования
Урок 2. Линейный поиск

Задачи поиска является одним из наиболее распространенных: они возникют при построении трансляторов и во многих программах, больших и малых, с которых вам придается встречность. Если поиск ведется в файле, или если массив, в котором ищут, неупорядочен (то есть по значению элемента нельзя узнать, где он расположен), то единственный возможный вид поиск — это линейный поиск, при котором информация программирования от начала к конца, элемент за элементом. Далее массив упорядочен, но имеет малую длину, нет смысла применять что-либо сложнее, чем линейный поиск. Таким образом, все три подготовительные задачи*)

*) См. Урок 1, «Квант» № 10.

Решения
Во всех решениях: x — заданное значение, k — искомый индекс

a)
Задача 1 (первый подходящий)
i:=1; k:=0;
while (i<=n) AND (k=0) do
begin
if a[i]=x then k:=i;
i:=i+1
end;

б)
for k:=1 to n do
if a[k]=x then goto 7;
k:=0;
7:...

Задача 2 (последний подходящий)

k:=0;
for i:=1 to n do
if a[i]=x then k:=i;

задача 3 (m-й подходящий)
k:=0; i:=1; j:=0;
while (i<=n) AND (k=0) do
begin j:=j+1;
if j=m then k:=i
end;
i:=i+1
end;

j:=0;
for k:=1 to n do
if a[k]=x then
begin j:=j+1;
if j=m then goto 7;
end;
k:=0;
7:...
