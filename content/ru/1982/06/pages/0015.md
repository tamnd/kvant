$$x = \frac{a_1}{4} + \frac{a_2}{4^2} + \dots + \frac{a_n}{4^n} + \frac{a_{n+1}}{4^{n+1}} + \frac{a_{n+1}}{4^{n+2}} + \dots$$
или, по аналогии с десятичными дробями, в виде бесконечной периодической четверной дроби с периодом длины 1:
$$x = 0, a_1 a_2 \dots a_n a_{n+1} a_{n+1} = 0, a_1 a_2 \dots a_n (a_{n+1}).$$
Так как множество $E$ замкнут, любое число
$$x = \frac{a_1}{4} + \frac{a_2}{4^2} + \dots + \frac{a_n}{4^n} + \frac{a_{n+1}}{4^{n+1}} + \frac{a_{n+2}}{4^{n+2}} + \dots$$
где $a_i$ — либо единцы, либо двойки, принадлежит множество $E$. В самом деле, для каждого такого $x$ можно найти последовательность $(x_n)$ элементов из $E$, сходящую к $x$; например, если
$$x_n = \frac{a_1}{4} + \frac{a_2}{4^2} + \dots + \frac{a_n}{4^n} + \frac{1}{4^n} \cdot \frac{1}{3},$$
то $\lim_{n \to \infty} x_n = x \left(0 \leqslant x - x_n \leqslant \frac{1}{4^{n+1}}\right)$.

Таким образом, множество $E$ содержит все числа, в представлении которых $0, a_1 a_2 a_3 \dots$ в виде бесконечной четверной дроби все цифры $a_i$ — либо единцы, либо двойки (на рисунке 8 изображены четверчные разложения чисел $\frac{1}{12}, \frac{2}{12}, \dots, \frac{11}{12}$).

Докажем теперь, что других чисел $E$ не содержит. Пусть в четверной записи числа $x \in E$ на каком-либо месте после запятой имеется цифра 0, то есть $x = 0, a_1 a_2 \dots a_n 0 a_{n+2} \dots$; тогда $\{4^n x\} = 0, 0 a_{n+2} \dots \in E$.
