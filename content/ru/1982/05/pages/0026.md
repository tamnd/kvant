Другими словами,
$$S_{n-k-1} < (m-1)^2 < m^2 < S_{n-k} < (m+1)^2 < S_{n-k+1} < \dots$$
$$\dots < (m+k-1)^2 < S_{n-1} < (m+k)^2 < S_n < (m+k+1)^2.$$

Тогда $p_{n-k} = S_{n-k} - S_{n-k-1} > m^2 - (m-1)^2 = 2m-1$. Так как, очевидно, $n-k \geq 12$ и $p_{s+1} > p_s + 2$ при $s \geq 2$, получаем $p_{n+1} > p_{n-k} + 2(k+1) > 2(m+k) + 1$. Следовательно, $S_{n+1} = S_n + p_{n+1} > (m+k)^2 + 2(m+k) + 1 = (m+k+1)^2$. Поэтому $S_n < (m+k+1)^2 < S_{n+1}$, то есть интервал $]S_n; S_{n+1}$ [ содержит точный квадрат.

**M704. Вокруг квадрата описан параллелограмм (вершины квадрата лежат на разных сторонах параллелограмма). Докажите, что перепendlukляры, опущенные из вершин параллелограмма на стороны квадрата, образуют новый квадрат (рис. 1).**

**Ответ:** $\left\{ \left(\frac{1}{3}, \frac{1}{2}, 1\right), \left(-\frac{1}{3}, -\frac{1}{2}, -1\right) \right\}$.

Решение. Поскольку $\frac{x}{3(1+x^2)} = \frac{y}{4(1+y^2)} = \frac{z}{5(1+z^2)}$, чисяла $x, y$ и $z$ имеют одинаковые значки, причем если $(x, y, z)$ — решение системы, то и $(-x, -y, -z)$ — ее решение, к что можно разыскивать лишь положительные решения.

Формула $\sin 2\varphi = \frac{2tg\varphi}{1+tg^2\varphi}$ называют на мыслевые углы $\alpha, \beta, \gamma$ из промежутка $]0; \pi[$ также, что $\tg \frac{\alpha}{2} = x, \tg \frac{\beta}{2} = y, \tg \frac{\gamma}{2} = z$. Тогда (1) превращится в уравнение $\frac{\sin \alpha}{3} = \frac{\sin \beta}{4} = \frac{\sin \gamma}{5}$.

Из второго уравнения системы получаем $\frac{1}{z} = \frac{x+y}{1-xy}$ (ясно, что $xy \neq 1, z \neq 0$), что в новых обозначениях имеет вид $\text{ctg} \frac{\gamma}{2} = \text{tg} \frac{\alpha+\beta}{2}$, или

$$\text{ctg} \left(\frac{\pi}{2} - \frac{\gamma}{2}\right) = \text{tg} \frac{\alpha+\beta}{2}.$$

Посленее равенство при выбранных ограничениях на $\alpha, \beta, \gamma$ возможно тогда и только тогда, когда $\frac{\pi}{2} - \frac{\gamma}{2} = \frac{\alpha+\beta}{2}$, то есть $\alpha + \beta + \gamma = \pi$.

Итак, мы получили, что $\alpha, \beta$ и $\gamma$ — углы треугольника, длины сторона которого относится как 3:4:5 (см. (2)). Это — прямогольный треугольник, у которого $\gamma = \frac{\pi}{2}$, $\sin \alpha = \frac{3}{5}$, $\sin \beta = \frac{4}{5}$ (см. рисунок), то есть $\text{ctg} \frac{\alpha}{2} = \frac{1}{3}$, $\text{ctg} \frac{\beta}{2} = \frac{1}{2}$, $\text{ctg} \frac{\gamma}{2} = 1$.

Некоторые читатели решили эту систему чисто алгебраически, но такие решения значительно длиннее приведенного.

А. Вайитров, А. Федоров
