Второе решение. Пусть $l, m, n$ — длины сторона треугольника $LMN$ (см. рис. 1) и $\Delta$ — разность квадратов треугольника сторона треугольников, построенных Людой и Мариной. Ясно, что
$$\Delta = m^2 + n^2 - 2mn \cos \left( \widehat{L} + 60^\circ \right) - \left( l^2 + n^2 \right) + 2ln \cos \left( \widehat{M} + 60^\circ \right) = m^2 - l^2 + 2n \left( l \cos \left( \widehat{M} + 60^\circ \right) - m \cos \left( \widehat{L} + 60^\circ \right) \right) = m^2 - l^2 + n \left( l \cos \widehat{M} - m \cos \widehat{L} + \sqrt{3} \left( m \sin \widehat{L} - l \sin \widehat{M} \right) \right) = m^2 - l^2 + n \left( l \cos \widehat{M} - m \cos \widehat{L} \right),$$
поскольку по теореме синусов $l \sin \widehat{M} - m \sin \widehat{L} = 0$.

А так как $\cos \widehat{L} = \frac{m^2 + n^2 - l^2}{2mn}$, $\cos \widehat{M} = \frac{l^2 + n^2 - m^2}{2ln}$, без труда получаем, что $\Delta = 0$.

А. Каплан

М702. Обозначим через $S_n$ сумму первых $n$ простых чисел: $S_1 = 2, S_2 = 2 + 3 = 5, S_3 = 2 + 3 + 5 = 10, S_4 = 17$. и т. д.
Докажите, что при любом $n$ между $S_n$ и $S_{n+1}$ встречается точный квадрат.

$$p_{n+1} \leq 2k+1 \quad p_n \leq 2k-1 \quad p_{n-1} \leq 2k-3 \quad p_{n-2} \leq 2k-5$$

$$p_2 = 3 \leq x \quad p_1 = 2 \leq x-2$$

Первое решение. Докажем более общее утверждение, рассмотрев вместе последовательности простых чисел последовательность $(p_n)$ такую, что $p_1 = 2, p_2 \geq 3, p_{n+1} - p_n \geq 2$. Докажем, что при любом $n$ между числами $s_n$ и $s_{n+1}$, где $s_n = p_1 + p_2 + \dots + p_n$, встречается точный квадрат.

Предположим, что при каком-то $n$ между числами $s_n$ и $s_{n+1}$ нет квадратов; то есть для некоторого $k$
$$k^2 \leq s_n < s_{n+1} \leq (k+1)^2.$$

Тогда $p_{n+1} = s_{n+1} - s_n \leq (k+1)^2 - k^2 = 2k+1$, поэтому $p_n \leq p_{n+1} - 2 \leq 2k-1$ и т. д. — выполняются все выписанные в таблице на полях соответствия. Каким числом может быть $x$? Если $x=3$, то все неравенства должны превращаться в равенства (при этом $k=n$) и
$$s_{n+1} = 2 + p_2 + \dots + p_{n+1} > 1 + 3 + \dots + (2k+1) = (k+1)^2,$$
в противоречие с правым неравенством (*). Если же $x \geq 5$, то $x-2 \geq 3$ и
$$s_n = 2 + p_2 + \dots + p_n < 1 + 3 + \dots + (2k-1) = k^2,$$
в противоречие с левым неравенством (*).

Все решения, прикладные читатели, так или иначе используют идею сравнения последовательности $(p_n)$ с последовательностью $(2n-1)$, которая растет медленнее и для которого сумма первых $n$ членов равна $n^2$.

Второе решение. Пусть $S_n = p_1 + p_2 + \dots + p_n$ — сумма первых $n$ простых чисел. На полях выписаны значения $S_n$ при $n=1, 2, \dots, 12$ и все точные квадраты, лежащие в интервалах $]S_1; S_2; [,] S_2; S_3; [, \dots,] S_{11}; S_{12}$. Мы видим, что все эти интервалы содержат хотя бы по одному точному квадрату, а интервал $]S_{11}; S_{12}$ содержит даже два квадрата — 169 и 196. Условия в дальнейшем называют интервал $]S_{k-1}; S_k$ [бозагатим, если он содержит по крайней мере два точных квадратов.

Для решения задачи при $n \geq 12$ воспользуемся методом математической индукции. Пусть каждый из интервалов $]S_1; S_2; [,] S_2; S_3; [, \dots,] S_{n-1}; S_n$ содержит точный квадрат. Пусть, далее, $]S_{n-k-1}; S_n$ содержит первый интервал в последовательности интервалов $]S_{n-1}; S_n$ [,] $S_{n-2}; S_{n-1}; [,] S_{n-3}; S_{n-2}; [, \dots$. Пусть $m^2$ — максимальный квадрат, принадлежащий $]S_{n-k-1}; S_n$ [. Тогда $(m-1)^2 \in ]S_{n-k-1}; S_n$ [, а каждый из интервалов $]S_{n-k}; S_{n-k+1}; [,] S_{n-k+1}; S_n$ содержит второй интервал.
