5. $a = 2, b = 4, c = 64$. Решение. Пусть числа $a, b, c$ удовлетворяют условия задании. Обозначим через $x_0$ общий действительный корень данных уравнения (заключите из условия задания, что эти уравнения имеют по крайней мере один общий действительный корень!). Тогда число $x_0^2$ является корнем второго уравнения (доказите!). Так как $x_0 > 1$, то $x_0 \neq x_0^2$, и потому $x_0$ и $x_0^2$ — различные корни второго уравнения. По теореме Виета из этого уравнения получаем

$$b(b + 1) = x_0 + x_0^2, c = x_0^3. \quad (1)$$

Первое из соответствий (1) как квадратное уравнение относительно $b$ дает равенство $b = x_0$ (почему нужно отбросить второй корень этого уравнения?). Число $x_0$ есть корень первого уравнения; подставляя $x_0 = b$ в это уравнение, находим $a = \frac{8}{b}$. Вторым корнем первого уравнения является число $\frac{8}{b}$ (проверьте!). Так как $c = b^3$ (см. второе из соответствий (1)), то третье уравнение принимает вид

$$x^4 - b(b + 1)x^2 + b^3 = 0$$

и имеет четыре корня:

$$x_1 = b, x_2 = -b, x_3 = \sqrt{b}, x_4 = -\sqrt{b}. \quad (2)$$

Так как корни первого уравнения являются корнями третьего уравнения, то число $\frac{8}{b}$ должно совпадать с одним из чисел (2). Единственное возможное такое совпадение $\frac{8}{b} = \sqrt{b}$ (проверьте, что остальные случаи не подходят!) дает $b = 4$. Остается убедиться, что при значениях $a = 2, b = 4, c = 64$ уравнения задачи действительно выполнены; это установливается непосредственной проверкой (поясните, почему такая проверка — логическая необходимая часть решения задачи).

Вариант 1

1. Заметим, что $0 < 3^{-(x+2)^2} \leq 1$ при всех $x$. С помощью подстановки $3^{-(x+2)^2} = t$ уравнение приводится к виду $9t^2 - 18t + 7 = 0$. Это квадратное уравнение имеет корни $t_1 = 1 + \frac{\sqrt{2}}{3}$ и $t_2 = 1 - \frac{\sqrt{2}}{3}$, из которых нам подходит лишь $t_2$. Следовательно, $3^{-(x+2)^2} = 1 - \frac{\sqrt{2}}{3}$, откуда $x = -2 \pm \sqrt{-10} \left(1 - \frac{\sqrt{2}}{3}\right)$.

Большинство поступающих с решением этой задачи справилось. Некоторые абитриенты не заменили, что $t \leq 1$.

2. Прежде всего заметим, что в области допустимых значений неизвестных входят те и только те $x$, при которых $ctg x$ имеет смысл и $ctg x \neq 0$. Исходное неравенство перепишем в виде

$$ctg^2 x \geq \left| ctg x - 1 \right| + 1 \text{ ctg } x, \text{ ctg } x \neq 0. \quad (1)$$

Ясно, что при $ctg x < 0$ уравнение (1) удовлетворяя и, следовательно, все точки $x$, для которых $\frac{\pi}{2} + \pi n < x < \pi + \pi n$ ($n = 0, \pm 1, \pm 2, \dots$), является решением.
