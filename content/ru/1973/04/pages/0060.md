Решая последние равенства относительно $d$, получим

$$\frac{n - m}{p - m} = \frac{\sqrt{3} - 1}{2},$$

что невозможно, так как следа стоит число рациональное, справа — irrationalное.

Задача 3. При каком условии при числа $a$, $b$ и $c$ является целым одной арифметической прогрессии?

Решение. Пусть $\{a_i\}$ — исходная прогрессия, причем $a = a_m$, $b = a_k$ и $c = a_p$. Тогда $a = a_1 + d(m - 1)$, $b = a_1 + d(k - 1)$ и $c = a_1 + d(p - 1)$. Исключим из этих равенств $a_1$:

$$a - b = d(m - k)$$
$$b - c = d(k - p).$$

Разделив почленно эти равенства, получим

$$\frac{a - b}{b - c} = \frac{m - k}{k - p}.$$

Поскольку числа $m$, $k$ и $p$ целые, то $\frac{a - b}{b - c}$ должно быть рациональным числом.

Легко проверить, что если $\frac{a - b}{b - c} = \frac{s}{t}$, где $s$ и $t$ — целые, то можно подобрать арифметическую прогрессию с членами $a$, $b$, $c$ (доказhte!).

Задача 4. Доказите, что между каждыми двумя последовательными членами геометрической прогрессии $c$ положительным и целым можно оставить по $k$ чисел так, что все последовательность составим геометрическую прогрессию.

Решение. Обозначим члены прогрессии через $a$, $b$, $c$, ..., $n$, ... Определим знаменатель исходной прогрессии $q$ по первому ее члену $a$ и $(k + 2)$-му $b$ ($k$ членов надоставить):

$$b = aq^{k + 1},$$

откуда $q = \sqrt[k + 1]{\frac{b}{a}}$. Последовательность будет иметь вид

$$a, a \sqrt[k + 1]{\frac{b}{a}}, a \sqrt[k + 1]{\left(\frac{b}{a}\right)^2}, \dots, b.$$

Между числа $b$ и $c$ встречаются тоже $k$ членов так, что образуется геометрическая прогрессия со значением $\sqrt[k + 1]{\frac{c}{b}}$ и так далее.

По условиям задачи

$$\frac{b}{a} = \frac{c}{b},$$

значит, все последовательность составит геометрическую прогрессию со значением $\sqrt[k + 1]{\frac{c}{b}}$ и так далее.

Задача 5. Найти знаменатель геометрической прогрессии, в котором каждый член, начиная со второго, равен разности двух соседних (следующей и предыдущей).

Решение. Пусть прогрессия имеет вид $b_1, qb_1, q^2b_1, \dots$.

Из равенства

$$q^{n + 2}b_1 - q^n b_1 = q^{n + 1}b_1$$

находим

$$q^2 - q - 1 = 0,$$

откуда

$$q = \frac{1 \pm \sqrt{5}}{2}.$$

Задача 6. Найти условия, при которых квадраты трех последовательных членов арифметической прогрессии являются прямыми последовательными членами геометрической прогрессии.

Решение. Пусть $a, a + d, a + 2d$ — три последовательных члена арифметической прогрессии. Если квадраты этих чисел составляют геометрическую прогрессию, то

$$(a + d)^4 = a^2 (a + 2d)^2,$$

откуда

$$(a + d)^2 = \pm a (a + 2d).$$

Если $(a + d)^2 = a (a + 2d)$, то $d = 0$.

Если $(a + d)^2 = -a (a + 2d)$, то $d = a (-2 \pm \sqrt{2})$.

Итак, либо $d = 0$, либо $d = a (-2 \pm \sqrt{2})$.
