Некоторые задачи на прогрессии

В. П. Лебедев

В этой статье приведены характерные теоремы и разобраны задачи на прогрессии, предлагаемые наступительных экзаменах вузы.

Два основных свойств прогрессии

I. В арифметической прогрессии каждой ее член (кроме первого и последнего), умноженный на два, равен сумме ряда стоянных, то есть
$$2a_k = a_{k-1} + a_{k+1}.$$
Верно и обратное утверждение: если в последовательности чисел каждой ее член (кроме первого и последнего), умноженный на два, равен сумме ряда стоянных, то эта последовательность есть арифметическая прогрессия.

Доказательство. По определению арифметической прогрессии $a_k = a_{k-1} + d$ и $a_k = a_{k+1} - d$, складывая эти выражения, получим $2a_k = a_{k-1} + a_{k+1}$. Обратно, пусть $2a_k = a_{k-1} + a_{k+1}$, тогда $a_{k+1} - a_k = a_k - a_{k-1}$.

Подставляя в последнее равенство $k = 2, 3, \dots$ и обозначая $a_2 - a_1$ через $d$, получаем
$$d = a_2 - a_1 = a_3 - a_2 = \dots = a_{k+1} - a_k = \dots$$
По определению это и означает, что $a_1, a_2, \dots$ — арифметическая прогрессия.

II. В геометрической прогрессии квадрат любого ее член (кроме первого и последнего) равен произведению его соседних членов, то есть
$$b_k^2 = b_{k-1}b_{k+1}.$$

Обратно, если в последовательности чисел квадрат каждой из них (кроме первого и последнего) равен произведению ряда стоянных, то эта последовательность есть геометрическая прогрессия.

Доказательства этих утверждений самостояльно.

Задание и их решения

Задание 1. Найти арифметическую прогрессию, в котором сумма первого n членов равна $n^2$.

Решение. Используя формулу суммы членов арифметической прогрессии, получим, что при любом n должно выполнять равенство
$$S_n = \left[ \frac{2a_1 + d(n-1)}{2} \right]n = n^2.$$
Отсюда
$$d = \frac{2(n-a_1)}{n-1}.$$
Это выражение не будет зависеть от n только при $a_1 = 1$. Значит, в исключой прогрессии $a_1 = 1$, $d = 2$ и прогрессия имеет вид 1, 3, 5, 7,...

Этот же результат можно получить инчае:
$$a_n = S_n - S_{n-1} = n^2 - (n-1)^2 = 2n - 1.$$
Задание 2. Модум ли числа 1, $\sqrt{3}$, 3 быть иленими одной арифметической прогрессии?

Решение. Что эти числа составляют арифметическую прогрессию, причем $1 = a_m$, $\sqrt{3} = a_n$ и $3 = a_p$. Тогда
$$1 = a_1 + (m-1)d,$$
$$\sqrt{3} = a_1 + (n-1)d,$$
$$3 = a_1 + (p-1)d.$$
Отсюда
$$a_1 = 1 - (m-1)d = \sqrt{3} - (n-1)d = 3 - (p-1)d,$$
$$\sqrt{3} = 1 + (n-m)d,$$
$$3 = 1 + (p-m)d.$$

Решая последние равенства относительно $d$, получим

$$\frac{n - m}{p - m} = \frac{\sqrt{3} - 1}{2},$$

что невозможно, так как следа стоит число рациональное, справа — irrationalное.

Задача 3. При каком условии при числа $a$, $b$ и $c$ является целым одной арифметической прогрессии?

Решение. Пусть $\{a_i\}$ — исходная прогрессия, причем $a = a_m$, $b = a_k$ и $c = a_p$. Тогда $a = a_1 + d(m - 1)$, $b = a_1 + d(k - 1)$ и $c = a_1 + d(p - 1)$. Исключим из этих равенств $a_1$:

$$a - b = d(m - k)$$
$$b - c = d(k - p).$$

Разделив почленно эти равенства, получим

$$\frac{a - b}{b - c} = \frac{m - k}{k - p}.$$

Поскольку числа $m$, $k$ и $p$ целые, то $\frac{a - b}{b - c}$ должно быть рациональным числом.

Легко проверить, что если $\frac{a - b}{b - c} = \frac{s}{t}$, где $s$ и $t$ — целые, то можно подобрать арифметическую прогрессию с членами $a$, $b$, $c$ (доказhte!).

Задача 4. Доказите, что между каждыми двумя последовательными членами геометрической прогрессии $c$ положительным и целым можно оставить по $k$ чисел так, что все последовательность составим геометрическую прогрессию.

Решение. Обозначим члены прогрессии через $a$, $b$, $c$, ..., $n$, ... Определим знаменатель исходной прогрессии $q$ по первому ее члену $a$ и $(k + 2)$-му $b$ ($k$ членов надоставить):

$$b = aq^{k + 1},$$

откуда $q = \sqrt[k + 1]{\frac{b}{a}}$. Последовательность будет иметь вид

$$a, a \sqrt[k + 1]{\frac{b}{a}}, a \sqrt[k + 1]{\left(\frac{b}{a}\right)^2}, \dots, b.$$

Между числа $b$ и $c$ встречаются тоже $k$ членов так, что образуется геометрическая прогрессия со значением $\sqrt[k + 1]{\frac{c}{b}}$ и так далее.

По условиям задачи

$$\frac{b}{a} = \frac{c}{b},$$

значит, все последовательность составит геометрическую прогрессию со значением $\sqrt[k + 1]{\frac{c}{b}}$ и так далее.

Задача 5. Найти знаменатель геометрической прогрессии, в котором каждый член, начиная со второго, равен разности двух соседних (следующей и предыдущей).

Решение. Пусть прогрессия имеет вид $b_1, qb_1, q^2b_1, \dots$.

Из равенства

$$q^{n + 2}b_1 - q^n b_1 = q^{n + 1}b_1$$

находим

$$q^2 - q - 1 = 0,$$

откуда

$$q = \frac{1 \pm \sqrt{5}}{2}.$$

Задача 6. Найти условия, при которых квадраты трех последовательных членов арифметической прогрессии являются прямыми последовательными членами геометрической прогрессии.

Решение. Пусть $a, a + d, a + 2d$ — три последовательных члена арифметической прогрессии. Если квадраты этих чисел составляют геометрическую прогрессию, то

$$(a + d)^4 = a^2 (a + 2d)^2,$$

откуда

$$(a + d)^2 = \pm a (a + 2d).$$

Если $(a + d)^2 = a (a + 2d)$, то $d = 0$.

Если $(a + d)^2 = -a (a + 2d)$, то $d = a (-2 \pm \sqrt{2})$.

Итак, либо $d = 0$, либо $d = a (-2 \pm \sqrt{2})$.
