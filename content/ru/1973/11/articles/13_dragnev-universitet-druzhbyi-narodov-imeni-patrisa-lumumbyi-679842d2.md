⟦folio 61⟧

Университет
дружбы народов
имени Патриса
Луумубы

В «Кванте» № 4 за 1973 год мы уже рассka-
зывали об Университете дружбы народов. Сейчас мы помещаем варнаты вступель-
ных экзаменов в этот университет по математике в 1973 году.

Факультет физико-математических и есте-
венных наук

Вариант 1
1. Решить систему уравнения:
$$\begin{cases}
x + y + z = 6, \\
xy + yz + xz = 12, \\
xyz = 8.
\end{cases}$$

2. Решить неравенство
$$x^3 + \log_a x < a^2x^2.$$

3. Решить уравнение
$$\frac{\sin^{10} x + \cos^{10} x}{4} = \frac{\sin^6 x + \cos^6 x}{4\cos^2 2x + \sin^2 2x}$$

4. Двугранные углы при боковых реб-
рах правльной четырехугольной парамиды
равны $\alpha$. Найти дугранные углы при ребрах
основания парамиды.

Вариант 2
1. При каких комплектных значениях $z$
оба выражения
$(3 + i)z + 1 - 5i$ и $z^2 + 1 - 4i$
одновременно имеет действительные значения?
2. Решить неравенство
$$(2^x + 2^{1-x})^{\log_x (x^3 + 1)} \log_x + 1 x - 2 > 1.$$

3. Найти все пары чисел $x, y$, которые
удовлетворяют уравнение
$$\cos^4 x + \cos^4 y - \frac{1}{\cos^2 x \cos^2 y} = 1.$$

4. Найти дугранные углы при боковом
ребре правльной треугольной парамиды,
если дугранный угол при ребре основания
равен $\alpha$.

Вариант 3
1. Решить неравенство
$$\sqrt{x + 2a} + \sqrt{x + 2b} < 2\sqrt{x + a + b}.$$

2. Решить систему уравнений:
$$\begin{cases}
5\lg x - 3\lg y = 0, \\
(3x)^{1/g} - (5y)^{1/g} = 0.
\end{cases}$$

3. Найти все пары чисел $x, y$, которые
удовлетворяют уравнение
$$\sin^2 (x + y) - \cos^2 (x - y) = 1.$$

4. Найти полную поверхность усеченного конуса, описанного около полушара радиуса $R$ (так что основание полушара лежит на большем основании усеченного конуса, а боковая поверхность усеченного конуса и его второе основание касаются полусферы), если площади нижнего и верхнего основании усеченного конуса относятся как 1:18.

Инженерный факультет
Вариант 1
1. Решить уравнение
$$(x^2 - 4x)^2 + 2(x - 2)^2 = 43.$$

2. Решить неравенство
$$(0,125)^x + 2^{2-3x} + (0,5)^{3x+4} < 40,5.$$

3. Решить уравнение
$$1 + \sin x - \cos x = \sin 2x - \cos 2x.$$

4. Основание и одна из боковых граней
парамиды суть равносторонние треугольники. Один из плоских углов при вершине парамиды, не равный 60°, имеет величины $\alpha$. Найти объем парамиды, если длина стороны
ее основания равна $a$.

Вариант 2
1. Решить неравенство
$$x^2 + \frac{1}{x^2} > \frac{17}{4}.$$

2. Решить уравнение
$$\log_x - 1 (2x^3 - 6x^2 - 7x - 1) = 3.$$

3. Решить уравнение
$$\mathrm{tg} x - 2\sqrt{2} \sin x = 1.$$

4. Стороны основания правльной четырехугольной парамиды, описанной около шара радиуса $R$, равны $a$. Найти полную поверхность парамиды.
