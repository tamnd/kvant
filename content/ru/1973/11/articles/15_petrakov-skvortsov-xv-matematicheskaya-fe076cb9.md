ХV математическая

Н. С. Петраков В. А. Сковорцов

Завершилась еще одна Международная математическая олимпиада школьников. На этот раз она проходила в Москве с 5 по 16 июля. В олимпиаде приняли участие команды 16 стран: Австрии, Болгарии, Великобритания, Венгрии, ГДР, Кубы, Монголии, Нидерландов, Польщи, Румынии, Советского Союза, Финляндии, Франции, Чехословакии, Швейции, Югославии.

Это была самая представительная олимпиада за всю историю международных математических олимпиад.

В команду каждой страны входило 8 участников (за исключением команды Кубы, состоящей из 5 участников) — победителей национальных олимпиад.

В команду СССР вошли 8 учащихся десятих классов — первых и вторых призеров седьмой Всесоюзной олимпиады. Из числа вторых призеров были включены те, которые имели лучшую олимпиейскую биографию.

Приведем теперь задачи XV Международной математической олимпiadы и их краткие решения.

Задачи

1 (Чехословакия. Полное решение оценявалось б-ю очками). Точка О лежит на прямой l; ОР₁, ОР₂, ..., ОРₙ — единичные векторы также, что все точки P₁, P₂, ..., Pₙ лежат в одной плоскости, содержащей l, и все no odну стропу om l. Докажите, что если n — нечетное, то |OP₁| + |OP₂| + ... + |OPₙ| ≥ 1, где |OM| обозначает длину вектора ОМ.

2 (Польша, 6 очков). Вышить, существует ли конечное множество M может в пространстве, не лежащее в одной плоскости, такое, что для любых двух точки A, B, принадлежих M, найдется две другие точки C, D, принадлежих M, также, что приемые AB и CD паралельны и не совпадают.

3 (Швениция, 8 очков). Наимimumальное значение a² + b², где a и b — действительные числа, для которых уравнение x¹ + ax³ + bx² + ax + 1 = 0 имеет no крайней мере один действительный корень.

4 (Югославия, 6 очков). Солдат должен проверить отсутствие мин на участке, имеющем форму равностороннего треугольника, включая границу. Радусе действия его детектора равен положение высоты треугольника. Солдат выходит из одной вершины треугольника. Какой путь он должен выравнить, чтобы наименование возможно рассмотрение и выполнить задачи?

5 (Польша, 6 очков). Непустное множество G не равных последней функции действительного аргумента x вida f(x) = ax + b, где a, b — действительные числа, удовлетворяем следующим условиям:

a) если f, g ∈ G, то g · f ∈ G, где (g · f)(x) = g(f(x)), то есть множество G замкнуто относительно суперпозиции;

b) если f ∈ G, то f(x) = ax + b, то обратная функция f⁻¹ ∈ G, где f⁻¹(x) = x - b/a;

b) для любой f ∈ G существуют x₁, ..., aₙ — данные n положительных чисел u q — данные действительных числа, причем 0 < q < 1. Наимimum также n действительных чисел b₁, ..., bₙ, что

a) aₙ > bₙ при всех k от 1 до n;

b) q < (bₙ+1)/bₙ < 1/q при всех k от 1 до n-1;

b) b₁ + ... + bₙ < (1+q)/(1-q)(a₁ + ... aₙ).

Решения задач

1. Доказательство можно проверить по индукции. При n = 1 утверждение очевидно. Пусть оно верно при некотором n = k. Осуществим индуктивный переход от n = k к n = k + 2. Выберем на прямой l направление, перемещением данные векторы в порядке возрастания угла (угол отсутствия против часов стрелки), который они образуют с положительным направлением прямой l (рис. 1). Суммой векторов OP₁ и OP₂ + 2 является вектор OR, изображаемый

диагональное ромба со сторонами $OP_1$ и $OP_{k+2}$. Поэтому каждый из углов $P_1OR$ и $ROP_{k+2}$ не превосходит $\frac{\pi}{2}$. Пусть $OS = \sum_{i=2}^{k+1} OP_i$. Из виденной нумерации векторов следует, что вектор $OS$ заключит либо внутри угла $P_1OR$, либо внутри угла $ROP_{k+2}$, либо следовательно, угол $ROS$ острый. Сумма $OR + OS$ изображается диагональю $OT$ соответствующего параллелограмма. В треугольнике $OST$ угол $OST$ тупой. Поэтому сторона $OT$ является наиболеешей, то есть $|OT| > |OS|$. Но $|OS| \geq 1$ по предположению индукции. Значит, $\sum_{i=1}^{k+2} OP_i = |OT| \geq 1$.

2. Легко проверить, что таким множество будет, например, множество вершин двух правильных шестиугольников, имеющих общий центр, но лежащих в разных плоскостях.

Нетрудно показать, что число элементов в множестве с требутыми свойствами может быть скольгу углоно велико. Интересно было выяснить, каково наименьшее возможное элемент в таком множестве (в前提ном выше примере их, по крайней мере, 10). Можно ли элементов быть нечетным?

3. Заметив, что $x = 0$ не является корнем данного уравнения, преобразуем его к виду $x^2 + ax + b + \frac{a}{x} + \frac{1}{x^2} = 0$ или $(x + \frac{1}{x})^2 + a(x + \frac{1}{x}) + b - 2 = 0$.

Нетрудно проверить, что при любом действительном $x$ справедливо неравенство $x + \frac{1}{x} \geq 2$. Для фиксирования $x_0$ множество пар чисел $(a, b)$ для которых исходное уравнение имеет корень, равный $x_0$, определяется линейным уравнением $y_0^2 + ay_0 + b - 2 = 0$, где $y_0 = x_0 + \frac{1}{x_0}$. Это множество пар изображается примой на координатной плоскости $(a, b)$. Поскольку в этой плоскости выражение $a^2 + b^2$ можно геометрическим использованием ананасное значение $a^2 + b^2$ для точек $(a, b)$ на нашей прямой будет равнять квадрату длины перпендикуляра, опущенного из начала координат на расматриваемую прямую.

Легко подчитать, что оно равно $\rho = \frac{(y_0^2 - 2)^2}{1 + y_0^2}; \rho \geq \frac{4}{5}$ при $y_0^2 = \left(x_0 + \frac{1}{x_0}\right)^2 \geq 4$. Нетрудно доказать, что $\frac{(t - 2)^2}{1 + t} \geq \frac{4}{5}$ при $t \geq 4$, а при $t = 4$ достигается равенство. Таким образом, значение $a^2 + b^2$ для всехможных действительных корней $x_0$ не меньше $\frac{4}{5}$. Заметая, что $x_0 = 1$ является корнем исходного уравнения при $a = -\frac{4}{5}, b = -\frac{2}{5}$, получаем, что $\frac{4}{5}$ является наименьшим исходным значением для $a^2 + b^2$.

4. Пусть солдат вышел из вершины $A$ (см. схему на рис. 2). Для проверки точек $B$ и $C$ он должен быть на дугах радиуса $\frac{h}{2}$ (в высота треугольника) с центром в этих точках. Пусть сначала он попытал на дуге с центром в $B$, а затем с центром в $C$. Если к этому пути добавить путь до точки $C$, то дело сведется к нахождению кратчайшего пути от $A$ к $C$ с західом на первую дугу. Предоставляем читателю доказать, что таким кратчайшим путем будет ломана $ADC$ где $D$ — середина высоты, исходящая из вершины $B$. Пусть $E$ — точка пересечения отрезка $DC$ со второй дугой. Тогда путь $ADE$ является кратчайшим, при котором проверяется точки $B$ и $C$. Легко проверить, что при этом проверяется также и все точки треугольника, то есть путь $ADE$ — исключый.

5. Заметим, что из условия в) следует, что если у функции из $G a = 1$, то $b = 0$. Но у функции $f(x) = x$ имеется общая неподвижная точка с любой функцией из $G$.
