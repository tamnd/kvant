⟦folio 39⟧

Рис. 9.

Поместим в каждую вершину многоугольника массы по 1 грамму. Центр тяжести возникшей системы материальных точек совпадает с центром O кругга. По формуле (6) имеем
$$\sigma = \sum_{1 \leq i < k \leq 100} A_i A_k^2 = M J_0 = (100R)^2.$$
Задание 7. Зная радус R округности, описанной около данного треугольника ABC, и радус r округности, описанной в этом же треугольнике, вычислить расстояние d между их центрами.

Пусть S — центр описанной округности, Z — центр вписанной округности, a, b, c (см) — длины сторон треугольника. Поместим в вершины A, B, C массы соответствующего a, b и c граммов. Центр тяжести этой системы okажется точка Z. По формуле (4) имеем
$$J_S - J_Z = (a + b + c) d^2.$$
По формулам (2) и (6) находим:
$$J_S = a \cdot SA^2 + b \cdot SB^2 + c \cdot SC^2 = (a + b + c) R^2,$$
$$J_Z = \frac{abc^2 + bca^2 + cab^2}{a + b + c} = abc.$$
Кроме того, по известным формулам для плошади треугольника имеем
$$S_{\Delta ABC} = \frac{abc}{4R} = \frac{1}{2} (a + b + c) r,$$
откуда
$$abc = 2Rr (a + b + c).$$
Из формул (7) — (10) следует, что
$$d^2 = R^2 - 2Rr.$$
Это и есть искомая формула («формула Эйлера»).

Задание 8. Известно, что в параллелограмме разность между суммой квадратов длины всех точек плоскости, для которых сумма квадратов расстояний от вершин заданного в этой плоскости квадрата A_1 A_2 A_3 A_4 со стороны a есть постоянная величины c^2, если c^2 > 2a^2?

Поместим в вершинах четырехугольника A_1 A_2 A_3 A_4 равные массы (по 1 грамму), и пусть Z — центр тяжести образованшейся системы материальных точек. По определению (2) и по формуле (6) имеем
$$J_Z = ZA_1^2 + ZA_2^2 + ZA_3^2 + ZA_4^2 = \frac{1}{4} \left( A_1 A_2^2 + A_2 A_3^2 + A_3 A_4^2 + A_1 A_4^2 + A_2 A_4^2 \right).$$
Рассмотрим теперь систему из двух материальных точек (A_1, 1) и (A_3, 1) (их центр тяжести — середина P отрезка A_1 A_3). Приимем формулу (4):
$$ZA_1^2 + ZA_3^2 = PA_1^2 + PA_3^2 + 2ZP^2 = \frac{1}{2} A_1 A_3^2 + \frac{1}{2} PQ^2.$$
Аналогично
$$ZA_2^2 + ZA_4^2 = \frac{1}{2} A_2 A_4^2 + \frac{1}{2} PQ^2.$$
Из (11), (12) и (13) следует искомая формула Эйлера:
$$(A_1 A_2^2 + A_2 A_3^2 + A_3 A_4^2 + A_4 A_1^2) - (A_1 A_3^2 + A_2 A_4^2) = 4PQ^2.$$
Упражнения
1. Решите задачу 4 других способом, воспользовавшись формулой (6).
2. Пусть Z — центр окружности вписанной в треугольник ABC (BC=a, CA=b, AB=c). Доказите, что
$$a \cdot ZA^2 + b \cdot ZB^2 + c \cdot ZC^2 = abc.$$
3. Какую формулу представляется собой множество всех точек плоскости, для которых сумма квадратов расстояний от вершин заданного в этой плоскости квадрата A_1 A_2 A_3 A_4 со стороны a есть постоянная величины c^2, если c^2 > 2a^2?
4. В некоторых треугольника расстояние между точкой пересечения медиан и центром описанной окружности в три раза меньше радиуса этой окружности. Доказите, что треугольник прямойный.
