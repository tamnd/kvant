Здесь $m_1$ — масса газа в баллоне до нагрева, а $m_2$ — после нагрева. Выразим $m_1$ и $m_2$ из этих уравнений

$$m_1 = \frac{\mu V}{R} \frac{P_1}{T_1},$$

$$m_2 = \frac{\mu V}{R} \frac{P_2}{T_2}.$$

Тогда изменение массы $\Delta m = m_1 - m_2 = \frac{\mu V}{R} \left( \frac{P_1}{T_1} - \frac{P_2}{T_2} \right).$

Задча 3. Из сосуда обтемом $V$, давление в комором равно $P$, откачиваютвоздух. Сколько качанный должен сделать поршневой насос обтемом $v$ для мого, чтобы давление в сосуде уплотов в $k$ раз? Температура воздуха не меняется.

Решение. До того, как поршень сделал первое «качание», для газа в сосуде можно записать

$$PV = \frac{m}{\mu} RT.$$

Когда поршень насоса стоит в крайнем положении, объем газа равен $V + v$, давление $P_1$, причем

$$P_1 (V + v) = \frac{m}{\mu} RT.$$

Это означает, что

$$P_1 = P \frac{V}{V + v}.$$

Аналогично найдем, что после второго качания давление в сосуде будет равно

$$P_2 = P_1 \frac{V}{V + v} = P \left( \frac{V}{V + v} \right)^2.$$

После $n$ качаний давление становится равным

$$P_n = P \left( \frac{V}{V + v} \right)^n.$$

По условию задачи

$$P_n = \frac{1}{k} P.$$

Отсюда следует, что

$$\frac{1}{k} = \left( \frac{V}{V + v} \right)^n,$$

то есть

$$n = - \frac{\lg k}{\lg V / v} = \frac{\lg k}{\lg \frac{V}{v} + V / V}.$$

Если в сосуде имеется смесь нескольких газов, то согласно закону Дальтона давление этой смеси на стенки сосуда равно сумме парциальных давлений. Давление, которое создает бы каждый газ в отдельности, если из сосуда удалить остальные газы, называют парциальным давлением. Это означает, что состояние каждого газа в смеси не зависит от состояния других газов. Однакоковыми являются только объем и температура (так как газы находятся в равновесии). Поэтому для каждого из газов неравниимо можно записать уравнение газового состояния. Расстоярим пример.

Задча 4. Определить плотность смеси, состоящей из $m_1 = 50$ е кислорода и $m_2 = 20$ е водорода при температуре $t = 20^\circ C$ и давлении $P = 0,9$ атмосфер.

Решение.

$$P = P_1 + P_2,$$

где $P_1$ — парциальное давление кислорода и $P_2$ — парциальное давление водорода.

Обозначим объем смеси $V$, тогда

$$P_1 V = \frac{m_1}{\mu_1} RT,$$

$$P_2 V = \frac{m_2}{\mu_2} RT,$$

и

$$PV = \left( \frac{m_1}{\mu_1} + \frac{m_2}{\mu_2} \right) RT.$$

Плотность смеси равна

$$\rho = \frac{m_1 + m_2}{V} = \frac{m_1 + m_2}{RT} \left( \frac{m_1}{\mu_1} + \frac{m_2}{\mu_2} \right) \approx 0,23 \text{ ке/м}^3.$$
