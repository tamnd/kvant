⟦folio 31⟧

Доказательство 2.4. Напишем $n$ точекств $(x^j - \alpha^j) = (x - \alpha)(x^{j-1} + x^{j-2}\alpha + \ldots + \alpha^{j-2}x + \alpha^{j-1})$, $(j=1, 2, \ldots, n)$, умножим их соответственно на коэффициенты $a_j$ и сложим все эти точекств. Получим формулу, справедливую для любого многочлена (12) и любого числа $\alpha$:

$$f(x) - f(\alpha) = (x - \alpha)g(x),$$

где $g(x)$ — неокоторый многочлен. В частности, если $f(\alpha)=0$, получаем (13).

Доказательство 2.3. проведем индукцией по $n$. Для $n=1$ утверждение 2.3 очевидно. Докажем, что если оно верно для $n-1$, то верно и для $n$. Пусть $\alpha_0, \alpha_1, \ldots, \alpha_n$ — корни многочлена (12). Тогда, согласно 2.4:

$$f(x) = (x - \alpha_n)g(x),$$

причем многочлен $g(x)$ имеет степень не выше $n-1$ и имеет $n$ различных корней $\alpha_0, \alpha_1, \ldots, \alpha_{n-1}$. По предположению индукции, $g(x)$ равен нулю; из (14) следует, что $f(x)$ тоже равен нулю.

Доказательство 2.2. Пусть $p_1$ и $p_2$ — два многочлена, для каждой из которых верны равенства (9). Тогда их разность удовлетворяет условиям теоремы 2.3 ( многочлен $f(x) = p_1(x) - p_2(x)$) степени не выше $n+1$ корней $\alpha_0, \alpha_1, \ldots, \alpha_n$ и поэтому равна нулю, то есть $p_1(x) = p_2(x)$.

Итак, мы доказали, что через $n+1$ точку $(\alpha_0, \beta_0), (\alpha_1, \beta_1), \ldots, (\alpha_n, \beta_n)$ можно proveсти единственную кривую вида

$$y = f(x) = a_0 + a_1x + \ldots + a_nx^n,$$

и даже привели формулу, позволяющего сразу написать нужный многочлен. Эта формула (11) называется интегриционной формулой Лаэранжа.

Упражнение 2. a) Найдите квадратный треугольник, который в точках 2, 3, 5 принадлежит значения соответствующего 7, 11, 13. 6) Найдите многочлен степени не выше 4, график которого проходит через точки $(-2, -7), (-1, 0), (0, 1), (1, 2), (2, 9)$.

Вернемся к нашей задаче. Построим многочлен степени не выше $n$, который в точках $\alpha_k = k(k=0, 1, 2, \ldots, n)$ принадлежит значения соответствующего $\beta_k = k^m$. Из формулы (11) следует, что этот многочлен равен $\sum_{k=0}^{k=n} k^mD_k(x)$, где

$$D_k(x) = \frac{x(x-1)\ldots(x-k+1)(x-k-1)\ldots(x-n)}{k(k-1)\ldots1(-1)(-2)\ldots(k-n)}.$$

Ясно, что коэффициент при $x^n$ у многочлена (15) равен

$$\frac{1}{k(k-1)\ldots1(-1)(-2)\ldots(k-n)} = (-1)^{k-n} \frac{1}{k!(n-k)!} = \frac{(-1)^n}{n!} (-1)^k C_n^k,$$

позному коэффициент при $x^n$ у многочлена $P(x)$ равен

$$(1/n!) (-1)^n \sum_{k=0}^{k=n} (-1)^k k^m C_n^k.$$

С другой стороны, ясно, что многочлен $P(x)$ есть просто $x^m$, ведь $m < n$. Поэтому коэффициент при $x^n$ у $P(x)$ равен нулю.

Задание 4. Докажите, что набор чисел $y_0, y_1, \ldots, y_n$ удовлетворяет условиям: «для любого многочлена $f(x)$ степени не выше $n-1$ справедливо равенство

$$\sum_{k=0}^{k=n} f(k)y_k = 0»,$$

в том и только том случае, если $y_k = t(-1)^k C_n^k$, где $t$ — неокоторе число.
