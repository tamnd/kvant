⟦folio 29⟧

Эта последовательность называется последовательностью вторых разностей для $f$. Еще раз взявности, получим последовательность третьих разностей — $\Delta^3 f$:

$$f(3) - 3f(2) + 3f(1) - f(0), f(4) - 3f(3) + 3f(2) - f(1), \dots$$

и так далее.

Таким образом, по определению

$$\Delta^{n+1}f(x) = \Delta^n f(x + 1) - \Delta^n f(x).$$

(7)

(Напомним, что аргумент $x$ функций $f$, $\Delta f$, $\Delta^2 f$, ... принимает целые неотрицательные значения: $x = 0, 1, 2, \dots$).

Рассмотрим в качестве первого примера постоянную функцию $f$:

$$f(0) = f(1) = f(2) = \dots = a.$$

Для нее последовательность разностей $\Delta f$ будет, очевидно, состоять из одних нуляй. Кратко это запишем так: $\Delta f \equiv 0$ (при всех $x$).

Естественно, что и последовательности $\Delta^2 f$, ..., $\Delta^n f$ так же будут состоять из одних нуляй, то есть $\Delta^n f \equiv 0$.

Если $f$ — линейная функция: $f(x) = ax + b$, то есть если последовательность представляется собой арифметической прогрессию $b, a + b, 2a + b, 3a + b, \dots$, то все члены последовательности $\Delta f$ будут равны одному и тому же числу $a$. Отсюда $\Delta^2 f \equiv 0$.

Если $f$ — квадратный трехчлен $f(x) = ax^2 + bx + c$, то $\Delta f$ — линейная функция (от номера $x$):

$$\Delta f(x) = f(x + 1) - f(x) = a(x + 1)^2 + b(x + 1) + c - ax^2 - bx - c = 2ax + b.$$

Тогда $\Delta^2 f$ — постоянная функция: $\Delta^2 f = 2a$. Следовательно, $\Delta^3 f = 0$ и, конечно, $\Delta^n f = 0$ для всех $n > 2$.

У правах не имеем 1. а) Пусть $f(x) = x^3$. Найдите $\Delta f$, $\Delta^2 f$, $\Delta^3 f$, ... 6) Тот же вопрос, если $f(x) = 2^x$.

Наши наблюдения обобщаются в следующих двух теоремах.

1.1. Число $\Delta^n f(x)$ выражается через значения функций $f$ по формуле

$$\Delta^n f(x) = C_n^0 f(x + n) - C_n^1 f(x + n - 1) + \dots + (-1)^n C_n^n f(x) =$$

$$= \sum_{k=0}^{k=n} (-1)^k C_n^k f(x + n - k).$$

1.2. Если $f(x)$ — многочлен степени $m < n$, то $\Delta^n f = 0$.

Оба утверждения 1.1 и 1.2 доказываются индукцией по $n$. Для $n = 1, 2, 3$ мы их уже проверили. Предполагается, что они верны для $n$, доказываем для $n+1$.

1.1. Используя (7), (8) и (2), получаем

$$\Delta^{n+1}f(x) = \Delta^n f(x + 1) - \Delta^n f(x) =$$

$$= C_n^0 f(x + n + 1) - C_n^1 f(x + n) + \dots + (-1)^n C_n^n f(x) - C_n^0 f(x + n) + \dots + (-1)^n C_n^n f(x) =$$

$$= C_n^0 f(x + n + 1) - C_n^1 f(x + n) + \dots + (-1)^n C_n^n f(x + n) + (-1)^n \times C_n^n f(x).$$

1.2. Пусть $f(x) = a_0 + a_1 x + \dots + a_j x^j + \dots + a_m x^m$. Нашим $m$ равенств (они следуют из (4))

$$(x + 1)^j - x^j = C_j^1 x^{j-1} + C_j^2 x^{j-2} + \dots + C_j^{j-1} x + 1$$

(здесь $j = 1, 2, \dots, m$). Умножим их соответственно на коэффициенты $a_j$ и сложим. Получим: влевой части $\Delta f(x) = f(x + 1) - f(x)$, в правой — неокторый многочлен от $g(x)$ степени не выше $m - 1$. Если $m < n$, то $m - 1 < n - 1$ и по предположению индукции $\Delta^{n-1}g = 0$. Следовательно, $\Delta^n f = \Delta^{n-1} (\Delta f) = \Delta^n g = 0$.
