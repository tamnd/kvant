Воспользовемся теперь тем, что
$$1 - C_{m+1}^1 + C_{m+1}^2 - \cdots + (-1)^{m+1} C_{m+1}^{m+1} = 0$$
и, следовательно,
$$C_{m+1}^2 - C_{m+1}^3 + \cdots + (-1)^{m+1} C_{m+1}^{m+1} = C_{m+1}^1 - 1 = m.$$
Замечая еще, что
$$C_{m+1}^k \frac{m-k+1}{m+1} = C_{m}^k$$
и использует свойство (4) операции*, получим такое выражение для $S_m(n)$:
$$S_m(n) = \frac{n^{m+1} + nm}{m+1} + [C_m^2 S_{m-2}(n) - C_m^3 S_{m-3}(n)]^*.$$
Полягая в (3) $q = m-1$, получим, что выражение в квадратных скобках равно $mS_{m-1}(n) - n^m$, следовательно, $S_m(n) = \frac{n^{m+1} + nm}{m+1} + [mS_{m-1}(n) - n^m]^* = \frac{n^{m+1} + nm}{m+1} + mS_{m-1}^*(n) - \frac{n^{m+1} - n}{m+1} = n + mS_{m-1}^*(n).$
Таким образом, (5) верно и для $q = m$. Теорема доказана.
Пример. Предположим, вы знаете, что
$$S_3(n) = \frac{1}{4} (n^4 + 2n^3 + n^2).$$
Найдем выражение для $S_4(n)$:
$$S_4(n) = n + 4S_3^*(n) = n + (n^4 + 2n^3 + n^2)^* = n + \frac{n^5 - n}{5} + 2 \frac{n^4 - n}{4} + \frac{n^3 - n}{3} = \frac{n^5}{5} + \frac{n^4}{2} + \frac{n^3}{3} - \frac{n}{30}.$$
§ 3. Общая формула
Бином Ньютона, однако, может даить значительное больше, чем тожество (3), доказанное в § 1.

Рассмотрим следующие преобразования (м и n предполагаются натуральными числами):
$$m^n - 1 = [(m-1) + 1]^n - 1 = (m-1) C_n^1 + (m-1)^2 C_n^2 + \cdots + (m-1)^n C_n^n.$$
Пусть $m \neq 1$. Разделив обе части тождества на $m-1$, получим
$$1 + m + m^2 + \cdots + m^{n-1} = C_n^1 + (m-1) C_n^2 + \cdots + (m-1)^{n-1} C_n^n.$$ (6)
Это равенство справедливо для всех натуральных $m$ и $n$, в том числе и для $m=1$ (в этом случае оно оченьindo). Поскольку слева и справа мы имеем многочлены степени $n-1$ относительно $m$, то это возможно лишь в том случае, если многочлены тождественно равны, то есть их коэффициенты совпадают (в данном случае все они равны единице). Если раскрыть скобки в правой части (6) и приравнять коэффициенты при $m^k$, $k=0, 1, \ldots, n-1$, единице, то получится ряд тождеств, связывающих биомпальные коэффициенты. Для нас важно следующее: если степени $m^k$, $k=0, 1, \ldots, n-1$ слева и справа в (6) заменить любыми числами $a_0, a_1, \ldots, a_{n-1}$, равенство не нарушится: ведь коэффициенты перед числами $a_k$ останутся равными единице! Таким образом, мы приходим к следующему тождеству, верному для любых чисел $a_0, a_1, \ldots, a_{n-1}$:
$$a_0 + a_1 + a_2 + \cdots + a_{n-1} = C_n^1 + (a_1 - a_0) C_n^2 + (a_2 - 2a_1) + a_0) C_n^3 + \cdots + [a_{n-1} - C_n^1 a_{n-2}) + C_n^2 a_{n-3} - \cdots + (-1)^{n-1} C_n^n.$$ (7)
Теорема 2. Сумма $S_q(n)$ в общем случае может быть вычислена по формуле
$$S_q(n) = C_n^1 + (2^q - 1) C_n^2 + (3^q - 2 \cdot 2^q + 1) C_n^3 + \cdots + [(q+1)^q - C_q^1 q^q + C_q^2 (q-1)^2 - \cdots + (-1)^q] C_n^{q+1}.$$ (8)
