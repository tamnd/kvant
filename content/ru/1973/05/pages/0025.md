§ 2. Вместо $q$ членов — один

Итак, к каждой из формул для вычисления сумм $S_q(n)$, $q = 1, 2, \ldots$ можно последовательно принять с помощью общего соответствия (3). Такие соответствия, которые определяют новый член неокоторой последовательности по ее предыдущим членам, называются *рекуррентными*.

Конечно, более предопчитательными является также рекуррентные соответствия, которые содержат в правой части возможного меньше членов, — в лучшем случае только один: предшествующий определяемому.

Для последовательности сумм $S_q(n)$ такое простое рекуррентное соответствует.

Для того чтобы его записать, ведем следующие обозначение. Пусть $P_m(n)$ — неокоторый многочлен степени $m$ относительно $n$:

$$P_m(n) = a_0n^m + a_1n^{m-1} + \ldots + a_{m-1}n + a_m.$$

Тогда $P_m^*(n)$ — это многочлен степени $m+1$, получающийся из многочлена $P_m(n)$ заменой в нем степени $n^k$ выражениями:

$$\frac{n^{k+1}-n}{k+1} \quad (k=0, 1, \ldots, m).$$
