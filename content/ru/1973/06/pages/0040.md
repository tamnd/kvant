$$e^x = 1 + x + \frac{x^2}{1 \cdot 2} + \dots + \frac{x^k}{1 \cdot 2 \cdot \dots k} + \dots$$

(16)

подобно тому, как бесконечная геометрическая прогрессия $1 + x + x^2 + \dots$ представляется при $|x| < 1$ функция $y = \frac{1}{1-x}$.

Такое представление удобно по двум причины. Во-первых, для вычисления экспоненты с высокой точностью (например, при составлении таблицы) по формуле $e^x \approx 1 + x + \frac{x^2}{2!} + \dots + \frac{x^n}{n!}$ хватает сравнительно небольшого числа слагаемых и, во-вторых, это разложение позвольет глубже изучить экспоненту (например, доказать irrationalность числа $e$ (см. задачи 11, 12).

Мы ограничимся доказательством формулы (16) при $x > 0$.

Итак, пусть $T_n(x) = \left(1 + \frac{x}{n}\right)^n$ и $S_n(x) = 1 + x + \frac{x^2}{1 \cdot 2} + \dots + \frac{x^n}{n!}$. Мы должны доказать, что

$$\lim S_n(x) = \exp x.$$

$$\left(1 + \frac{x}{n}\right)^n = 1 + n \cdot \frac{x}{n} + \frac{n(n-1)}{1 \cdot 2} \frac{x^2}{n^2} + \dots + \frac{x^n}{n!} = 1 + x + \frac{\left(1 - \frac{1}{n}\right) x^2}{1 \cdot 2} + \dots + \frac{\left(1 - \frac{1}{n}\right) x^k}{1 \cdot 2} + \dots + \frac{x^n}{n!}.$$
