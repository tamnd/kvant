В «Программе вступительных экзаменов по математике» имеется, в частности, такой пункт: «Комплекские числа и аргументы действия над ними. Модуль и аргумент комплекского числа». Строгого построения теории комплекских чисел от поступающих не требуется, но они должны владель们 действий с этим числами и знать их геометрическую интерпретацию.

В этой статье разбирается несколько задач, взятых из опыта применения. В каждой задаче по существу использются лишь основные определения и геометрическая интерпретация некоторых понятий, связанных с комплекскими числами.

Задание 1. Изобразить на плоскости миску, соответствующее числу $z = \frac{2+i}{i-2}$.

Решен и е. Прежде всего представим данное число в алгебраической форме:

$$\frac{2+i}{i-2} = -\frac{(2+i)(2+i)}{(2-i)(2+i)} = -\frac{3+4i}{5} = -\frac{3}{5} - \frac{4}{5} i.$$

Тепер изобразить число $z$ на комплекской плоскости уже нетрудно — получается точка в третьем квадрате (нарисайте ее сами!).

Задание 2. Комплекское число $z = a+bi$ изобрается точкой $M(a, b)$. Где находится точка $z_1 = z + 3 - 2i$?

Решен и е. Имеем $z + 3 - 2i = (a + 3) + (b - 2) i$.

Позному числу $z_1 = (a + 3) + (b - 2) i$ изобрается точкой $M_1(a + 3, b - 2)$, которая получается из точки $M$ с двумром вправо на три единиц и вниз на две единицы.

Задание 3. Рассматриваются комплекские числа $z$ также, что $|z| = 2$. Где расположены точки $2z - 3i + 1$?

Решен и е. Точки $z$, для которых $|z| = 2$, расположены на окружности радиуса 2 с центром в точке $(0, 0)$ (рис. 1). Тогда точки $2z$ будут лежать на концентрической окружности радиуса 4. В самом деле, точки $2z$ лежит на том же исходящем из начала координат луче, что и точка $z$, но отсутствот от начала в 2 раза дальше, чем точка $z$.

Точка $2z + 1 - 3i$ получается из точки $2z$ с двумром вправо на единицу и с двумром вниз на три единиц. Поэтому точки $2z + 1 - 3i$, где $|z| = 2$, образуют окружность с центром в точке $(1, -3)$ и радиуса 4.

Задание 4. Какое множество точки комплекской плоскости задается условием $2 < |z + 1 - 2i| \leq 3$?

Решен и е. Пусть $z_1 = z + 1 - 2i$; тогда данное условие принимает вид

$$2 < |z_1| \leq 3. \quad (1)$$

Точки $z_1$, удовлетворющие условиям $|z_1| = 3$, лежат на окружности радиуса 3 с центром в начале координат. Условию $|z_1| < 3$ удовлетворяют все внутренние точки круга радиуса 3 с центром в начале координат. Условию $|z_1| > 2$ удовлетворяют все точки, лежащие в

Задание 5 (МГУ, экономический факультет, 1970). Указать мощи плоскости, соответствующие тем комплисным числом комплисным числом, которые удовлетворяют условияю $|z| + i + z = 2 + i$.

Решение. Пусть $z = a + bi$; тогда данное условие примет вид

$$i\sqrt{a^2 + b^2} + a + bi = 2 + i.$$

По определению равенства комплисных чисел от сюда получаем систему уравнений

$$\begin{cases} a = 2, \\ \sqrt{a^2 + b^2} + b = 1, \end{cases}$$

которая легко решается. В результате находим удовлетворящее условию заданий число $z = 2 - \frac{3}{2}i$.

Задча 7. Комплексные числа $z$ удовлетворяют условиям

$$|z+2+i| = |z-1-4i|.$$ (4)

Где расположены точки, изображающие эти числа?

Решение. Как известно, $|z_1-z_2|$ есть расстояние между точками, изображающими комплексные числа $z_1$ и $z_2$. Поэтому число

$$|z+2+i| = |z-(-2-i)|$$

 есть расстояние от точки, изображающей число $z$, до точки $M(-2, -1)$, а число

$$|z-1-4i| = |z-(1+4i)|$$

 есть расстояние то точки, изображающей число $z$, до точки $N(1, 4)$. Условие (4) тогда означает, что искомые точки равнодалены от точки $M$ и $N$. Следовательно, искомые точки лежат на прямой, перpendикулярной отрезку $MN$ и проходящей через его середину.

Задча 8. Указать множество точки, изображающей числа, изображающей комплексные числа, которые одновременно удовлетворяют двум условиям

$$|z-2i| \leqslant \frac{3}{2}, \frac{\pi}{3} < \arg z < \frac{2\pi}{3}.$$ (5)

Решение. Точики, изображающие те комплексные числа, которые удовлетворяют первому из условий (5), заполняют круг (включая окружность) радиуса $3/2$ с центром в точке $(0,2)$ (рис. 4). Второму условия удовлетворяют комплексные числа, изображающей точки, которые расположены между лучами, выходящими из начала координат и составing

$$0 < |z|^2 - |z| + 1 < 6 + 3 |z|,$$ (6)

Решение. Нераевенство (6), согласно свойством логарифмов, равносильно двойному неравенству

$$0 < \frac{|z|^2 - |z| + 1}{2 + |z|} < 3,$$

которое можно переписать (поскольку $2 + |z| > 0$ при любом $z$) в виде

$$0 < |z|^2 - |z| + 1 < 6 + 3 |z|.$$

Но неравенство $|z|^2 - |z| + 1 > 0$ справедливо при любом $z$ (так как дискриминант квадратного трехчлена $x^2 - x + 1$ отрицательен), а неравенство $|z|^2 - |z| + 1 < 6 + 3 |z|$, то есть $|z|^2 - 4 |z| - 5 < 0$ выполняется при $|z| < 5$ (неравенство $x^2 - 4x - 5 < 0$ выполняется при $-1 < x < 5$, но $|z| \geqslant 0$ при любом $z$). Поэтому условия (6) удовлетворяют комплексные числа $z$, удовлетворяющие условия $|z| < 5$; эти числа заполняют внутренность круга радиуса 5 с центром в начале координат.
