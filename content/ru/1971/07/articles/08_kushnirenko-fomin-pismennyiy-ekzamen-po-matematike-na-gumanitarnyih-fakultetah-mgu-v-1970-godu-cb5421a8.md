⟦folio 48⟧

Писменный экзамен по математике сдается при поступлении на следующие гуманитарные факультеты МГУ: психологический, экономический и отделение структурой и прикладной лингвистики филологического факультета *). Об уровне требований по математике, предъявляемых к абитриентам, поступающим на эти факультеты, можно судить по приведенным ниже вариантом письменного экзамена 1970 года, а также по вариантом 1969 года **).

На отделении структурой и прикладной лингвистики филологического факультета на письменную работу давалось 5 часов (300 минут). Для получения пятерки требовалось решить первые три задачи и любые две из последних четырех. Практические пятерка ставилась и за чуть худшую работу, а положительное оценку получали во всяком случае те абитриенты, которые решили не менее двух задач, из которых хотя бы одна входила в число первых трех задач.

Вариант письменного экзамена на отделении экономического кибертеки экономического факультета здесь не приводится, с уровнем требований по математике на этом отделении лучше познакомиться по вариантом 1969 года.

На психологическом факультете и на отделении политического экономии экономического факультета на письменную работу отводилось 4 часа (240 минут) и для получения пятерки требовалось решить все 4 задачи. Практические пятерка ставилась и за чуть худшую работу, а положительное оценку гарантировало решение любых двух задач. Ниже мы разберем решения некоторых задач подробно, а к неокоторым данным лишь ответы. Все приводимые ниже варианты являются реальными (не сборными).

Филологический факультет

Вариант

1. В современных условиях три байдарки. Первая байдарка продолжит каждые 100 м на 2 сек быстрее второй и на 3 сек быстрее третьей. За какое время первая байдарка прошла один kilометр, если за каждые 30 сек вторая байдарка опережает третью на 60/13м?

2. Найти все x, для которых 0,5<x<2,5 и которые удовлетворяют $\log_3x-x^2$ (3a—ax) < 1 при всех a из промежутка 0<a<2.

*) На отделении экономического кибертеки экономического факультета и на отделении структурой и прикладной лингвистики филологического факультета сдается также и устный экзамен по математике.
**) Их можно найти в статье «Гуманитарии сдают математике» («Квант» № 4, 1970).

3. Найти все $x$, удовлетворяющие условию $\frac{\pi}{2} < |3x - \frac{\pi}{2}| \leq \pi$ и являющиеся решением уравнения $1 + \cos x + \cos 2x = \sin x + \sin 2x + \sin 3x$.

4. Доказать, что $11n^2 - 14n + 3 \geq 0$ при всех целых $n$.

5. Не пользовать таблицами, доказать, что $tg 208^\circ < \sin 492^\circ$.

6. В окружность вписан треугольник со сторонами 7, 24, 25. Вычислить площадь круганого сегмента, стянутого хордой, длина которого 7.

7. Сколько способами сумму 4 руб. 96 коп. можно составить из монет по 2 и 15 коп.?

Решения задач

1. Ответ: первая байдарка прошла 1 км за 230 сек.

2. Прежде всего докажем, что при $0,5 < x < 2,5$ выполняется неравенство $3x - x^2 > 1$. Действительно, $3x - x^2 = \frac{9}{4} - \left( x - \frac{3}{2} \right)^2$, но при наших ограничениях $\left( x - \frac{3}{2} \right)^2 < 1$, следовательно, $3x - x^2 > \frac{5}{4} > 1$. Поскольку основание логарифма больше 1, неравенство можно переписать так: $3x - x^2 > 3a - ax$ или

$$x (3 - x) > a (3 - x).$$

(*)

Мы должны найти все $x$ из промежутка $0,5 < x < 2,5$, которые являются решением неравенства (*) при всех $a$ из промежутка $0 < a < 2$. Для любого $x$ из промежутка $0,5 < x < 2,5$ выполняется неравенство $3 - x > 0$, и, значит, неравенство (*) эквивалентно неравенству $x > a$.

При всех $a$ из промежутка $0 < a < 2$ неравенству $x > a$ удовлетворяют все $x \geq 2$; учитывая неравенство $0,5 < x < 2,5$, получаем ответ: $2 \leq x < 2,5$.

3. $1 + \cos x + \cos 2x = \sin x + \sin 2x + \sin 3x$,

$$\cos x (1 + 2 \cos x) = \sin 2x (1 + 2 \cos x), \quad \cos x (1 + 2 \cos x) (1 - 2 \sin x) = 0.$$

Посленее уравнение эквивалентно исходному. Будем решать его и для каждой серии ответов проверять условие $\frac{\pi}{2} < |3x - \frac{\pi}{2}| \leq \pi$.

I. $\cos x = 0$, $x = \frac{\pi}{2} + \pi k$. Отсюда $\left| 3x - \frac{\pi}{2} \right| = \left| 3 \frac{\pi}{2} + 3\pi k - \frac{\pi}{2} \right| = |(3k + 1)\pi|$. При $k = 0$ $\left| 3x - \frac{\pi}{2} \right| = \pi$, то есть нашей условие $\left(\frac{\pi}{2} < \pi \leq \pi\right)$, и, значит, $x = \frac{\pi}{2} + \pi \cdot 0 = \frac{\pi}{2}$ является ответом задачи. Если же $k \neq 0$, то, как легко видеть, $|(3k + 1)\pi| \geq 2\pi$ и из серии корней вида $\frac{\pi}{2} + k\pi$ только $x = \frac{\pi}{2}$ удовлетворяет нашему условию.

II. $1 + 2\cos x = 0$, $\cos x = -\frac{1}{2}$, $x = \pm \frac{2\pi}{3} + 2k\pi$. Отсюда $\left| 3x - \frac{\pi}{2} \right| = \left| \pm 2\pi + 6k\pi - \frac{\pi}{2} \right| = |(3k \pm 1)2\pi - \frac{\pi}{2}|$.

При любом $k$ последнее выражение слишком велико:

a) $k = 0$, $\left| (3k \pm 1)2\pi - \frac{\pi}{2} \right| = \left| \pm 2\pi - \frac{\pi}{2} \right| \geq \frac{3\pi}{2}$;

b) $k \neq 0$, $\left| (3k \pm 1)2\pi - \frac{\pi}{2} \right| \geq |(3k \pm 1)2\pi| - \left| \frac{\pi}{2} \right| \geq 4\pi - \frac{\pi}{2} = \frac{7}{2}\pi$.

Таким образом, ни одно значение $x$ из серии $x = \pm \frac{2\pi}{3} + 2k\pi$ не удовлетворяет условиям.

III. 1 - 2 sin $x = 0$; а) $x = \frac{\pi}{6} + 2k\pi$; б) $x = \frac{5\pi}{6} + 2k\pi$.

a) $|3x - \frac{\pi}{2}| = |\frac{\pi}{2} + 6k\pi - \frac{\pi}{2}| = |6k\pi|$. Если $k = 0$, то $|3x - \frac{\pi}{2}| = 0 < \frac{\pi}{2}$; если $k \neq 0$, то $|3x - \frac{\pi}{2}| \geq |6\pi| > \pi$.

b) $|3x - \frac{\pi}{2}| = |\frac{5}{2}\pi + 6k\pi - \frac{\pi}{2}| = |2\pi + 6k\pi| \geq 2\pi$.

Таким образом, ни одно из решений уравнения $\sin x = \frac{1}{2}$ не удовлетворяет условиям. Ответ: $x = \frac{\pi}{2}$.

4. Найдем, при каких $x$ трехчлен $11x^2 - 14x + 3$ меньше нуля. Этот трехчлен имеет корни $x_1 = \frac{3}{11}, x_2 = 1$. Таким образом, $11x^2 - 14x + 3 < 0$ при $\frac{3}{11} < x < 1$. Но в последнем промежутке нет ни одного целого числа, значит, при всех целых $n$ $11n^2 - 14n + 3 \geq 0$.

5. Очевидно, $tg 208^\circ = tg 28^\circ < tg 30^\circ = \frac{1}{\sqrt{3}}$; $\sin 492^\circ = \sin 48^\circ > \sin 45^\circ = \frac{1}{\sqrt{2}}$. Но $\frac{1}{\sqrt{3}} < \frac{1}{\sqrt{2}}$, значит, $tg 208^\circ < \frac{1}{\sqrt{3}} < \frac{1}{\sqrt{2}} < \sin 492^\circ$, что и требовалось доказать.

6. У казан и е: по теореме, обратной к теореме Пифагора, наш треугольник прямоугольный $(7^2 + 24^2 = 25^2)$. Ответ: $\frac{625}{4} \arcsin \frac{7}{25} - 42$.

7. Заметим, что каждый способ вполне определяется числом 15-копеечных монет. Посмотрим, каково может быть это число. Поскольку общая сумма (496 коп.) четна и любая сумма, составленная из 2-копеечных монет также четна, то число 15-копеечных монет должно быть четно. Кроме того, это число неотрицательно и не слишком велико, так как в любом способе сумма, составленная из 15-копеечных монет, неотрицательна и не превышает 496, то есть $0 \leq 2n \cdot 15 \leq 496$. Легко видеть, что никаких других чисел из 15-копеечных монет нет: если мы составим из четного числа 15-копеечных монет любую сумму, не превыходит 496 коп., то недостаточно сумму (она четна) всегда можно составить из 2-копеечных монет. Осталось решить в целых числа неравенство $0 \leq 2n \cdot 15 \leq 496$, или $0 \leq n \leq 16 \frac{16}{30}$. Ясно, что это неравенство имеет 17 целых решений: $n = 0, 1, 2, \dots, 16$.

Ответ: 17 способов.

Нибольшие затруднения в этом варианте вызывали задачи 2 и 3, скорее всего из-за несовсем обычной формулировки. Судя по работам, некоторые абитриенты не суммали до конца условия этих задач. Так, например, в задаче 3 некоторые абитриенты просто решили (притом не всегда верно) тригонометрическое уравнение, не учитывая дополнительного условия на $x$. Другие абитриенты, получив бесконечное число решений тригонометрического уравнения и понятия, что нужно проверять выполнение дополнительного условия, не смогли проверсти также проверку. «Раскрыв модель» в дополнительном условиям, многое не смогли проверсти проверку до конца.

Писхологическая факультет (дневное отделение)

Вариант 1

1. Два одинаковых парохода отправляются от двух пристаней: первый пароход от пристании $A$ вниз по течение, второй — от пристании $B$ вверх по течение. Каждый пароход, одной до конечного пункта, стоит там 45 мин и возврашается обратно. Если пароходы отправляются от начальных пунктов одновременно, то на обратном пути они встречаются в точке $K$, которая в 2 раза близке к $A$, чем $B$. Если пароход отходит от $A$ на 1 час позже, чем второй пароход отходит от $B$, то на обратном пути они встречаются в 20 км от $A$. Если пароход отходит от $A$ на 30 минут ранше, чем второй отходит от $B$, то на обратном пути пароходы встречаются в 5 км выше $K$. Найти скорость реки и время, за которой второй пароход доходит от $A$ до $K$.

2. Найти все действительные значения $a$, при которых уравнение

$$x^8 + ax^4 + 1 = 0$$

имеет рфно четыре действительных корня, образующих арфметическую прогрессию

3. Найти все $x$, удовлетворяющие неравенству

$$\log_{\cos x^2} \left( \frac{3}{x} - 2x \right) < \log_{\cos x^2} (2x - 1).$$

4. В правильную треугольную парамиду помещены 3 шара так, что 1-й шар касается всех боковых граней парамиды и 2-го шара, а 2-й шар касается боковых граней и 3-го шара, а 3-й шар касется боковых граней, основания парамиды и 2-го шара. Какую долю объема парамиды занимают три шара, если ее боковые грани наклонены к основанию под углом $\alpha^2$?

Решения задач

1. По условию задачи пароходы одинаковы, значит, и скорости пароходов в стоячей воде одинаковы. Обозначим эту скорость через $v$ ($\kappa m/\mu$). Обозначим через $v_0$ ($\kappa m/\mu$) скорость реки, через $S$ ($\kappa m$) — расстояние между $A$ и $B$. Ниже время будем измерять в часах и размерности всех величины будем опускать. Сравнивая времена, которые затратили пароходы на путь от момента выхода до момента встречи на обратном пути (включая и стоянку), составляем систему трех уравнений с темя неизвестными:

$$\begin{align*}
\frac{S}{v + v_0} + \frac{\frac{2S}{3}}{v - v_0} &= \frac{S}{v - v_0} + \frac{\frac{S}{3}}{v + v_0}, \\
\frac{S}{v + v_0} + \frac{S - 20}{v - v_0} + 1 &= \frac{S}{v - v_0} + \frac{20}{v + v_0}, \\
\frac{S}{v + v_0} + \frac{\frac{2S}{3} + 5}{v - v_0} &= \frac{S}{v - v_0} + \frac{\frac{S}{3} - 5}{v + v_0} + \frac{1}{2}.
\end{align*}$$

Из первого уравнения получаем, что $v = 3v_0$, а из первого и третьего находим: $v_0 = 7,5$; $v = 22,5$. Подставляя во второе уравнение эти значения $v$ и $v_0$, находим $S = 30$, откуда $AK = 10$. Значит, второй пароход доходит от $A$ до $K$ за $\frac{10}{30} = \frac{1}{3}$ часа. Ответ: скорость реки 7,5 $\kappa m/\mu$, и второй пароход доходит от $A$ до $K$ за 20 минут.

2. Нетрудно доказать, что исходное уравнение свойства квадратному. Уравнение такого вида разбираются в школьном учебнике. Положим $x^4 = t$. Тогда уравнение перепишется в виде $t^2 + at + 1 = 0$. Пусть $t_1$ и $t_2$ — действительные корни этого уравнения. Легко видеть, что $t_1$ и $t_2$ должны быть положительные и различны. Предположим для определениясти, что $0 < t_1 < t_2$. Тогда исходное уравнение имеет следующие корни (заумерованные в порядке возрастания): $x_1 = -\sqrt[4]{t_2}$, $x_2 = -\sqrt[4]{t_1}$, $x_3 = \sqrt[4]{t_1}$, $x_4 = \sqrt[4]{t_2}$.

Экономический факультет (дневное отделение)

Вариант

1. Объем бруска, имеющего форму прямогольного параллелипеда, равен 150 куб. см, площадь полной поверхности равна 280 куб. см, перimetр основания равен 40 см. Найти размеры бруска.

2. В квадратте $ABCD$ площади $J$ сторона $AD$prodолжена за точку $D$ и на продолжении взята точка $O$ на расстоянии 3 от точки $D$. Из точки $O$ проведены два луча. Первый луч пересекает отрезок $CD$ в точке $M$ и отрезок $AB$ в точке $N$, причем длина отрезка $ON$ равна $a$. Второй луч пересекает отрезок $CD$ в точке $L$ и отрезок $BC$ в точке $K$, причем $\Rightarrow BKL = \alpha$. Найти площадь многоугольника $BKLMN$.

3. Решить уравнение $\log_2\log_2 x = \log_4\log_4 2x$.

4. Решить уравнение $|z| \cdot i - z = 1 + 2i$.

Решения задач

1. Обозначим стороны основания бруска через $x$ ($cm$) и $y$ ($cm$), а высоту бруска через $z$ ($cm$). Пусть для определения $x \geq y$. Тогда

$$\begin{cases} xyz = 150, \\ 2(xy + yz + xz) = 280, \\ 2(x + y) = 40, \\ x \geq y. \end{cases}$$

(*)

Из первого и третьего уравнений $xy = \frac{150}{z}$ и $x + y = 20$. Подставив эти выражения во второе уравнение, получим уравнение относительно $z$:

$$\frac{15}{z} + 2z = 14,$$

откуда $z_{1,2} = \frac{7 \pm \sqrt{19}}{2}$. Тепер нам известны сумма $x + y$ и произведение $xy = \frac{150}{z}$ чисел $x$ и $y$, значит, $x$ и $y$ являются корнями квадратного уравнения $t^2 - 20t + \frac{300}{7 \pm \sqrt{19}} = 0$. Решая его, находим

$$t_{1,2} = 10 \pm \sqrt{100 - \frac{300}{7 \pm \sqrt{19}}}.$$

При $z = \frac{7 - \sqrt{19}}{2}$ дискриминант этого уравнения отрицательен: 100 – $\frac{300}{7 - \sqrt{19}} < 100 - \frac{300}{7 - 4} = 0$, а при $z = \frac{7 + \sqrt{19}}{2}$ дискриминант положительен и меньше 100. При этом значения $z$ $t_1 > 0$, $t_2 > 0$, то есть $x > 0$, $y > 0$. Легко видеть, что числа $z = \frac{7 + \sqrt{19}}{2}$, $x = 10 + \sqrt{100 - \frac{300}{7 + \sqrt{19}}}$, $y = 10 - \sqrt{100 - \frac{300}{7 + \sqrt{19}}}$ действительно являются решением системы (*). Ответ: стороны основания равны $10 \pm \sqrt{100 - \frac{300}{7 + \sqrt{19}}}$, высота равна $\frac{7 + \sqrt{19}}{2}$.

Почти ни у кого из абитурентов составление правильной системы уравнения в этой задаче не вызывало затруднений. Однако решение полученной системы многоимоказалось не под силу. Некоторые абитуренты, найдая два значения $z$, формировало нахождение соответствующего значения $x$ и $y$, не заботая о том, что в одном из указанных им ответов $x$ и $y$ не являются действительными числами.

2. Ответ: $S_{BKLMN} = 1 + \frac{(1 + 3\log a)^2}{2\log a} - \frac{7}{8} \sqrt{a^2 - 16}$.

3. $\log_2 \log_2 x = \log_4 \log_4 2x, \log_4 (\log_2 x)^2 = \log_4 \log_4 2x, (\log_2 x)^2 = \log_4 2 + \frac{1}{2} \log_2 x,$

$$(\log_2 x - 1) \left( \log_2 x + \frac{1}{2} \right) = 0.$$

(*)

Уравнение (*), как легко видеть, является следствием исходного, то есть всякий корень исходного уравнения удовлетворяет (*). Найди корни (*) и проверив их подстановкой в исходное уравнение, получаем ответ: $x = 2$.

4. Запишем комплексное число $z$ в виде $z = x + iy$, где $x, y$ — действительные числа. По определению $|z| = \sqrt{x^2 + y^2}$, в частности, $|z|$ — действительное число. Перепишем уравнение в виде $|z| \cdot i = (x + iy) = 1 + 2i$. Комплексные числа равны тогда и только тогда, когда у них равны действительные и минимые части. Поэтому решаемое уравнение эквивалентно системе

$$\begin{cases} -x = 1, \\ |z| - y = 2. \end{cases}$$

Из первого уравнения $x = -1$, поэтому $|z| = \sqrt{x^2 + y^2} = 1 \sqrt{1 + y^2}$, и для определения $y$ получаем уравнение $\frac{1}{1 + y^2} = y + 2$. Возвядя обе части в квадрат и сделав проверку, находим $y = -\frac{3}{4}$, то есть $z = -1 - \frac{3}{4} i$.
