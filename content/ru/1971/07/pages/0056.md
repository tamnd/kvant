4. Запишем комплексное число $z$ в виде $z = x + iy$, где $x, y$ — действительные числа. По определению $|z| = \sqrt{x^2 + y^2}$, в частности, $|z|$ — действительное число. Перепишем уравнение в виде $|z| \cdot i = (x + iy) = 1 + 2i$. Комплексные числа равны тогда и только тогда, когда у них равны действительные и минимые части. Поэтому решаемое уравнение эквивалентно системе

$$\begin{cases} -x = 1, \\ |z| - y = 2. \end{cases}$$

Из первого уравнения $x = -1$, поэтому $|z| = \sqrt{x^2 + y^2} = 1 \sqrt{1 + y^2}$, и для определения $y$ получаем уравнение $\frac{1}{1 + y^2} = y + 2$. Возвядя обе части в квадрат и сделав проверку, находим $y = -\frac{3}{4}$, то есть $z = -1 - \frac{3}{4} i$.
