Логарифмические уравнения
В. В. Гольдберг

Логарифмические уравнения приято называть уравнения, содержащие неизвестную величины под знаком логарифма.
Решение простейшего логарифмического уравнения

$$\log_a x = b$$

(1)
основано на следующем свойстве логарифмов: если логарифмы двух (положимых) чисел по одному и тому же основанию $a(a > 0, a \neq 1)$ равны, то равны и сами эти числа.

Записав уравнение (1) в виде $\log_a x = \log_a a^b$ и воспользоваться указыным свойством, получим ответ: $x = a^b$.

Этот прием применим и для решения более сложных логарифмических уравнений вида

$$\log_a f(x) = b.$$

(2)
Для уравнения (2) получаем $f(x) = a^b$.

Пример 1. Решить уравнение

$$\log_5 [2 + \log_3(3+x)] = 0.$$

Решение е. Сначала получаем, что

$$2 + \log_3(3+x) = 5^0, \quad 2 + \log_3(3+x) = 1, \quad \log_3(3+x) = -1.$$

Далее находим: $3 + x = 3^{-1}, x = \frac{1}{3} - 3, x = -\frac{8}{3}$.

Некоторые логарифмические уравнения легко свойства к простейшим. Так, уравнения вида

$$f(\log_a x) = 0$$

(3)
заменой $\log_a x = y$ свойятся к уравнению $f(y) = 0$. Если $y_1, \dots, y_k$ — корни последнего уравнения, то мы получаем совокупность простейших логарифмических уравнений:

$$\log_a x = y_1, \dots, \log_a x = y_k.$$

Пример 2. Решить уравнение $\lg^3 x - \lg^2 x - 6 \lg x = 0$.

Решение е. Обозначим $\lg x$ через $y$. Тогда получим кубическое уравнение относительно $y$:

$$y^3 - y^2 - 6y = 0.$$

Решаем его: $y(y^2 - y - 6) = 0, y_1 = 0, y_2 = 3, y_3 = -2$. Рассматриваем три возможных случая:

a). $\lg x = 0, x_1 = 1$; 6) $\lg x = 3, x_2 = 1000$; b) $\lg x = -2, x_3 = 0,01$.

К уравнением вида (3) свойятся показательно-логарифмические уравнения, если их предварительно прополагарифмировать.
