Прием 3. Решить уравнение $x^2 + \log_3 x = 3^8$.

Решение. Поскольку обе части уравнения положительные (ОДЗ: $x > 0$), приравниваем их логарифмы по основанию 3: $\log_3 x^2 + \log_3 x = \log_3 3^8$, откуда находится, что $(2 + \log_3 x) \log_3 x = 8$. Обозначая $\log_3 x$ через $y$, приходим к квадратному уравнению $y^2 + 2y - 8 = 0$ с корнями $y_1 = -4, y_2 = 2$. Разбиваем два случая:

a) $\log_3 x = -4, x_1 = 1/81$ 6) $\log_3 x = 2, x_2 = 9$.

Прием 4. Решить уравнение $9x^{\lg x} + 91x^{-\lg x} = 60$.

Решение. Введем обозначение $x^{\lg x} = y$; тогда $x^{-\lg x} = \frac{1}{y}$, иначе уравнение свойства к следующему уравнению относительно $y$: $9y^2 - 60y + 91 = 0$. Корни последнего $y_1 = \frac{13}{3}, y_2 = \frac{7}{3}$. Расматриваем обе возможности:

a) $x^{\lg x} = \frac{13}{3}$; логарифмируя, получаем $\lg x^{\lg x} = \lg \frac{13}{3}, \lg^2 x = \lg \frac{13}{3}$, откуда $\lg x = \pm \sqrt{\lg \frac{13}{3}}, x_1 = 10^{\sqrt{\lg \frac{13}{3}}}, x_2 = 10^{-\sqrt{\lg \frac{13}{3}}}$;

b) $x^{\lg x} = \frac{7}{3}$; аналогично тому, как это сделано в первом случае, находим $x_3 = 10^{\sqrt{\lg \frac{7}{3}}}, x_4 = 10^{-\sqrt{\lg \frac{7}{3}}}$.

При решении логарифмических уравнений часто дело свойства к решению уравнения типа

$$\log_a f(x) = \log_a g(x).$$

Здесь с помощью потенцирования надо перейти к уравнению

$$f(x) = g(x).$$

Но следует иметь в виду, что при максимере мы расширяем ОДЗ уравнения, и помому возможно появление посторонных корней. Поэтому надо проверить, входит ли каждой из корней уравнения (5) в ОДЗ уравнения (4).

Прием 5. Решить уравнение $\log_2(2x^2 - 2) = \log_2(5x - 4)$.

Решение. Находим ОДЗ:

$$\begin{cases} 2x^2 - 2 > 0, \\ 5x - 4 > 0, \end{cases}$$

то есть $$\begin{cases} x < -1, x > 1, \\ x > \frac{4}{5}. \end{cases}$$

Следовательно, ОДЗ: $x > 1$. Потенция данного уравнения, получим $2x^2 - 2 = 5x - 4$, или $2x^2 - 5x + 2 = 0$, откуда находим $x_1 = 2, x_2 = 1/2$.

Поскольку $x_2 = 1/2$ не входит в ОДЗ, уравнение имеет только одно решение: $x = 2$.

Хорошо известны следующие свойства логарифмов чисел:

$$\log_a(AB) = \log_a A + \log_a B \quad (A > 0, B > 0, a > 0, a \neq 1),$$

$$\log_a \frac{A}{B} = \log_a A - \log_a B \quad (A > 0, B > 0, a > 0, a \neq 1),$$

$$\log_a A^p = p \log_a A \quad (A > 0, p - \text{любое действительное число}),$$

$$\log_a q^p = \frac{p}{q} \log_a A \quad (A > 0, q \neq 0).$$
