Пусть $AB=a$, $\Rightarrow BAC=x$, $\Rightarrow ABC=y$ (рис. 1). Найдем длину отрезка $AN$ из треугольника $ABN$ (по свойству bicсектрисы внутринего угла треугольника и по теореме синусов):

$$AN = AB \frac{NO}{BO} = a (\sqrt{3} - 1) = \frac{a \sin \frac{y}{2}}{\sin \left(x + \frac{y}{2}\right)}$$

Аналогично из треугольника $ABM$ находится:

$$BM = \frac{a}{\sqrt{3}} = \frac{a \sin \frac{x}{2}}{\sin \left(\frac{x}{2} + y\right)}$$

Таким образом, получена система уравнения:

$$\begin{cases} \sin \left(\frac{x}{2} + y\right) = \sqrt{3} \sin \frac{x}{2}, \\ (\sqrt{3} - 1) \sin \left(x + \frac{y}{2}\right) = \sin \frac{y}{2}. \end{cases}$$

Большинство абитурентов, которые решали задачу таким способом, не сумели найти решение этой довольно сложной системы. Но плохо не то, что они не решили полученную систему, а то, что они не пытались найти другой способ решения данной задачи. Эту задачу проще решить следующим способом (то же алгебраическим).

Пусть $AB=x$, $BC=y$, $AC=z$. Из треугольников $ABM$ и $ABN$ по свойству bicсектрисы внутринего угла треугольника получаем:

$$\frac{BM}{AB} = \frac{MO}{AO} = \frac{1}{\sqrt{3}},$$

$$\frac{AN}{AB} = \frac{NO}{BO} = \sqrt{3} - 1.$$

Отсюда $BM = \frac{x}{\sqrt{3}}, AN = x (\sqrt{3} - 1)$. Из треугольника $ABC$ имеем:

$$\frac{AN}{CN} = \frac{AB}{BC}, \quad \frac{BM}{CM} = \frac{AB}{AC},$$

то есть

$$\begin{cases} \frac{x (\sqrt{3} - 1)}{z - x (\sqrt{3} - 1)} = \frac{x}{y}, \\ \frac{x}{y \sqrt{3} - x} = \frac{x}{z}. \end{cases}$$

Из этой системы уравнения находится: $y = x \sqrt{3}, z = 2x$. Отсюда следует, что $x^2 + y^2 = z^2$ и по теореме, обратной теореме Пифагора, $\Rightarrow ABC = \frac{\pi}{2}$.

Следовательно,

$$\Rightarrow BAC = \arcsin \frac{y}{z} = \frac{\pi}{3},$$

$$\Rightarrow ACB = \frac{\pi}{6}.$$

Рассмотрим еще одну задачу.

2. Наzinоменузе $BC$ прямоеольное треугольника $ABC$ расположена точка $M$, а на стороне $AC$ — точка $N$ такая, что $MN \parallel AB$. Известно, что $AB=AN=1$ см, $CM = \sqrt{3}$ см. Найти длину отрезка $MN$.

Естественно попытаться решить эту задачу следующим образом. Обозначим $MN$ через $x$ (рис. 2). Тогда $CN = \sqrt{3} - x^2$ и из подобия треугольников получаем уравнение

$$\frac{\sqrt{3} - x^2}{1 + \sqrt{3} - x^2} = x,$$

которое легко преобразуется к виду $x^4 - 2x^3 - x^2 + 6x - 3 = 0$.
