В января — апреле этого года впервые Московским экономико-статическойским институтом была проведена математическая олимпиада для школьников выпускных классов с учетом электронно-вычислительной машины. 3. Пусть искомая последовательность имеет вид
$$k + 1, k + 2, \dots, n - 1, n$$
Тогда ее сумму можно представить как разность сумм отрезков натурального ряда от 1 до $n$ и от 1 до $k$, то есть
$$\frac{(n + 1)n}{2} - \frac{(k + 1)k}{2} = 1000$$
или $n^2 + n - k^2 - k = 2000$.
Левую часть этого равенства разложим на два множители, а правую на простые множители:
$$(n + k + 1)(n - k) = 2^4 \cdot 5^3$$
Заметим, что оба множители $n + k + 1$ и $n - k$ в левой части этого равенства четными быть не могут, так как их сумма $2n + 1$ нечетна. Кроме того, первый множитель больше второго. Тем самым мы приходим к совокупности четых систем:
$$\begin{cases} n + k + 1 = 2000, \\ n - k = 1, \end{cases} \quad \begin{cases} n + k + 1 = 400, \\ n - k = 5, \end{cases} \quad \begin{cases} n + k + 1 = 80, \\ n - k = 25, \end{cases} \quad \begin{cases} n + k + 1 = 125, \\ n - k = 16. \end{cases}$$
Первая из этих систем дает тривальную «последовательность», состоящую из единственного числа 1000. Остальные системы приводят к последовательности:
198, 199, 200, 201, 202;
28, 29, ..., 51, 52;
54, 55, ..., 69, 70.

4. Пусть для определения типы будет угол $C$. Тогда $0 < B < \frac{\pi}{2} - A$, и поэтому
$$\cos B > \cos \left( \frac{\pi}{2} - A \right) = \sin A > 0$$
а следовательно, $\cos^2 B > \sin^2 A$.

Тогда $\cos^2 A + \cos^2 B > \cos^2 A + \sin^2 A = 1$, то есть $\cos^2 A + \cos^2 B > 1$, и тем самым подавно
$$\cos^2 A + \cos^2 B + \cos^2 C > 1$$
что и требовалось доказать.

Введением в рассмотрение вспомогательной окружности (см. «Квант» № 1, 1971). Однако эта задача допускает более короткое решение (Галина Авербух, $10^6$ класс шкoles № 200, Алексей Водовозов, $10^a$ класс шкoles № 569).

Пусть в треугольнике $ABC$ (рис. 3) медиана $BD$, биссерриса $BE$ и высота $BF$ делят угол $B$ на четые равные части, каждая из которых обозначается $\alpha$. Тогда
$$AF = h \ tg 3\alpha; DF = h \ tg 2\alpha$$
и $FC = h \ tg \alpha$.
Далее
$$AD = AF - DF = h \ (tg 3\alpha - tg 2\alpha)$$
$$DC = DF + FC = h \ (tg 2\alpha + tg \alpha)$$
но по условию $AD = DC$, то есть
$$tg 3\alpha - tg 2\alpha = tg 2\alpha + tg \alpha$$
или
$$2 \ tg 2\alpha = tg 3\alpha - tg \alpha$$
$$\frac{2 \sin 2\alpha}{\cos 2\alpha} = \frac{\sin 2\alpha}{\cos 3\alpha \cos \alpha}$$

Так как $\sin 2\alpha \neq 0$, то $2 \cos 3\alpha \cos \alpha = \cos 2\alpha$ или
$$\cos 2\alpha + \cos 4\alpha = \cos 2\alpha$$
то есть $\cos 4\alpha = 0$.
Отсюда следует, что угол $B$ принадлежит.

Второй тур

Сорок воемь ребят, успешно прошедших первый тур, собрались 25 апреля в МЭСИ, чтобы продолжить «соревнование».

Во втором туре одним из «членов» организационного комитета олимпiadы была электронно-вышистельная машина «Минск-22». На долю этого «члена» выпала основная работа. В машинную память было заложено несколько тысяч задач. Каждая задача была снабжена специальным кодом, указывающим раздел математики, к которой относится эта задача, и степень трудности (все задачи были различных разделов математики одинаковой суммарной трудности).

Машина для каждой участника олимпiadы наречала варнант.

По истечении срока (четыре часа по 45 минут) работы были отделены машине на проверку*). Машина сравнила полученные решения задачи с свойствами и тех, кто решил все пять задач правильно, объявила победители. Все эти работы машина проделала за то время, пока участники олимпiadы знакомились с институтом.

Шесту учеников десятых классов Москвыских школ были нагружены грамотами МЭСИ, памятными подарками:

*Елена Савина, Виктор Зак, Сергей Мапенов, Марк Рицель, Алексадр Розин, Леонид Терехов.

Проведение математической олимпiadы машиной явилось завершаюшим этапом работы по проведению встретильных экзаменов по математике и физике с помощью ЭВМ.
