Системы алгебраических уравнений

М. И. Шабунин

На вступительных экзаменах вузы передко предлагаются системы алгебраических уравнений; в частности, такие системы возникают в задачах на составление уравнений. Опыт экзаменов показывает, что многое поступающее с решением системы уравнения справляется неудовлетворительно.

Дело в том, что обычно учащся вопрос о нахождения решений системы поннимают просто как формальное выполнение ряда «привычных» алгебраических преобразований. При этом уpusケется из виду, что некоторые из примеремы преобразования могут привести к появлению посторонних решений или к потере решения исходной системы.

Без соответствующего обоснования решения системы уравнения логических неполюнено. В частности, мы можем не заменить потери некоторых решений. К сожалению, обоснованные, грамотно изложенные решения системы в работе поступающих встречаются крайне редко.

Подробное изложение всех важных вопросов, относящихся к системе уравнения, потребовано бы слишком много места *). Поэтому мы ограничим тем, что приведем основные теоретические положения, касающиеся решения трех алгебраических уравнений с темя неизвестными, а затем рассмотрим несколько примеров.

Сначала напомним некоторые определения.

Систему трех уравнений с темя неизвестными можно записать в виде

$$\begin{cases}
f_1(x, y, z) = 0, \\
f_2(x, y, z) = 0, \\
f_3(x, y, z) = 0
\end{cases}$$

или, опуская для краткости неизвестные, в виде

$$\begin{cases}
f_1 = 0, \\
f_2 = 0, \\
f_3 = 0.
\end{cases}$$

Мы будем рассматривать только алгебраические системы, то есть такие

системы, у которых левая часть каждой уравнения системы является многочленом относительно неизвестных.

Решением системы (1) называется тройка чисел $(x_0, y_0, z_0)$, при подстановке которых соответствующего вместо $x, y, z$ каждое уравнение системы (1) становится верным числовым равенством. Решить систему ознакомает найти все ее решения.

называются *равносильными* (эквивалентными), если они имеют одни и те же решения, то есть если решение системы (2) является решение системы (3) и, наоборот, если решение системы (3) является решение системы (2). Для обозначения равносильности системы (2) и (3) используется запись «(2) ⟨=⟩ (3)».

Заметим, что если мы наши все решения системы (3), равносильной системе (2), то тем самым найдены и все решения системы (2). В этом случае проверку проводить не нужно, то есть не нужно подставлять найденные при решении системы (3) значения неизвестных в исходную систему (2).

$$F(x, y, z) = 0$$
(4)
наозовем *следствие* системы (1), если каждое решение системы (1) удовлетворяет уравнению (4). Запись «(1) ⟨=⟩ (4)» будет означать, что уравнение (4) есть следствие системы (1).

Будем говорить, что система (1) равносильна *совокупности* системы
$$\begin{cases} F_1 = 0, \\ F_2 = 0, \\ F_3 = 0 \end{cases}$$
и
$$\begin{cases} G_1 = 0, \\ G_2 = 0, \\ G_3 = 0, \end{cases}$$
если выполнены следующее условия:
a) каждое решение системы (1) является решение по крайней мере одной из системы (5), (6);
b) каждое решение любой из системы (5), (6) является решение системы (1).

 Запись «(1) ⟨=⟩ [(5) ∨ (6)]» будет означать, что система (1) равносильна *совокупности* системы (5) и (6).

Если система (1) равносильна *совокупности* системы (5) и (6), то можно решить системы (5), (6) и обединить множества решений этих системы; это обедининие и дакт все решения системы (1) (*совокупность* система по является при рассмотрении различных случаев типа $x > 0$, $x < 0$, $x = 0$).

Сформируем теперь несколько свойств, наиболее часто используемых при решении системы уравнения. Мы не будем доказывать эти свойства; используя приведенные определения, читатель легко сможет самостоятельно проверить необходимые обоснования.

I. Пусть одно из уравнений системы (1), для определения первого, «распадается» на два уравнения, например представляется в виде
$$g_1(x, y, z) g_2(x, y, z) = 0,$$
где $g_1$ и $g_2$ — многочлены от $x, y, z$. Тогда система (1) равносильна совокупности следующих двух систем:
$$\begin{cases} g_1 = 0, \\ f_2 = 0, \\ f_3 = 0 \end{cases} \quad \text{и} \quad \begin{cases} g_2 = 0, \\ f_2 = 0, \\ f_3 = 0. \end{cases}$$

Это утверждение легко обобщается на случай, когда два или три уравнения системы (1) «распадаются» на несколько уравнений.

II. Если уравнение (4) является следствием системы (1), то, при соединении к системе (1) уравнение (4), мы получим систему {{1}, {4}} четырех уравнений, равносильную исходной.

III. Пусть уравнение (4), является следствием системы (1), «распадается» на два уравнения:
$$F_1(x, y, z) \cdot F_2(x, y, z) = 0,$$
где $F_1$, $F_2$ — многочлены от $x, y, z$. Тогда система (1) равносильна совокупности следующих двух систем:
$$\begin{cases} f_1 = 0, \\ f_2 = 0, \\ f_3 = 0, \\ F_1 = 0 \end{cases} \quad \text{и} \quad \begin{cases} f_1 = 0, \\ f_2 = 0, \\ f_3 = 0, \\ F_2 = 0. \end{cases}$$

IV. Система уравнения (1) равносильна каждой из следующих системы:
$$\begin{cases} f_1 - f_2 = 0, \\ f_2 - f_3 = 0, \\ f_3 - f_4 = 0; \end{cases} \quad \text{и} \quad \begin{cases} f_1 - f_2 = 0, \\ f_2 - f_3 = 0, \\ f_3 - f_4 = 0; \end{cases}$$

$$\begin{cases} f_1 + f_2 = 0, \\ f_1 + f_3 = 0, \\ f_2 + f_3 = 0 \end{cases}$$

(возможность прибавлять к одному уравнению системы другое, умноженное на произведение число).

V. Пусть одно из уравнений системы (1), например первоое ее уравнение $f_1(x, y, z) = 0$, равносильно уравнение $x = \varphi(y, z)$ — многочлен от $y$ и $z$. Тогда система (1) равносильна системе
$$\begin{cases} x = \varphi(y, z), \\ f_2[\varphi(y, z), y, z] = 0, \\ f_3[\varphi(y, z), y, z] = 0. \end{cases}$$

Это утверждение лежит в основе метода исключения неизвестных: система (1) свойится к системе управления
$$\begin{cases} f_2[\varphi(y, z), y, z] = 0, \\ f_3[\varphi(y, z), y, z] = 0 \end{cases}$$
с двумя неизвестными $y, z$.

Прежде чем переходить к разбору примеров, сделаем одно заменение. При рассмотрении конкретной системы далеко не всегда удается сразу заметить ту комбинацию данных управления, которая служит «ключом» к решению, найти такой способ преобразования, который позволяет добиться достаточно упрощения. Никаких общих решений для нахождения решения системы даь, разумется, нельзя. Только достаточно богатый опыт может помочь «увидеть» те особенности предлагаемой системы, которые позволяют свести ее к другой, решаемой просто.

Пример 1. Решить систему управления
$$\begin{cases} xy + z^2 = 2, \\ yz + x^2 = 2, \\ xz + y^2 = 2. \end{cases}$$

Решение. Вычитая из второго управления этой системы первое управление и разлагая разность левых частей на множители, получим
$$(x - z)(x - y + z) = 0.$$
Аналогично, вычитая из третьего управления системы (7) второе управление, найдем
$$(y - x)(x + y - z) = 0.$$
В силу свойства IV система (7) равно сcilна системе
$$\begin{cases} (x - z)(x - y + z) = 0, \\ (y - x)(x + y - z) = 0, \\ xz + y^2 = 2. \end{cases}$$

Так как левые части первых двух управлений системы (8) представляют собой произведение двух многочленов, то система (8) равно сcilна (свойство I) совокупности следующих четырех систем:
$$\begin{cases} x - z = 0, \\ y - x = 0, \\ xz + y^2 = 0; \end{cases}$$

$$\begin{cases} x - z = 0, \\ x + y - z = 0, \\ xz + y^2 = 2; \end{cases}$$

$$\begin{cases} x - y + z = 0, \\ y - x = 0, \\ xz + y^2 = 2; \end{cases}$$

Ясно, что каждая из полученных четырех систем проще исходной системы (7).

Решив системы $(8_1), (8_2), (8_3), (8_4)$ методом исключения неизвестных (свойство V) и объединив решения этих системы, мы получим следующее восем трое чисел:
$$(1, 1, 1), (-1, -1, -1), (\sqrt{2}, 0, \sqrt{2}), (-\sqrt{2}, 0, -\sqrt{2}), (\sqrt{2}, \sqrt{2}, 0), (-\sqrt{2}, -\sqrt{2}, 0), (0, \sqrt{2}, \sqrt{2}), (0, -\sqrt{2}, -\sqrt{2}).$$
