Упражнения

1. Докажите, что если позиция (a, b, c) в игре «ним» не является проигрывной, то есть не удовлетворяет указанным в формулировке теоремы I условиям, то играющий своим ходом может сделать ее проигрывной.

2. Докажите, что если позиция (a, b, c) в игре «ним» не является проигрывной, то есть не удовлетворяет указанным в формулировке теоремы I условиям, то играющий以其 ходом может сделать ее проигрывной.

3. Укажите правильная игре в игре «ним» в том случае, если число кучек спичек есть любое наперед заданное число число n ≥ 2 (прочее правильная игре мы оставляем прежним). К чему свидетельства беспроигрывной игре в случае n = 2?

4. Опишите проигрывные позиции (a, b, c) в игре «ним», записывая числа a, b, c не в двойной, а в четверчной системе счисления (то есть представляя, скажем, число a в виде a = aₙaₙ₋₁...a₂a₁a₀ = aₙ4ⁿ + aₙ₋₁4ⁿ⁻¹ + ... + a₂4² + a₁4 + a₀; здесь 0 ≤ aᵢ ≤ 3 для всех i = n, n − 1,..., 2, 1, 0 *))

5. Докажите, что для любого целого положительного числа p существует одна и только одна проигрывная позиция (a, b) в игре «изяныццы» (то есть позиция, удовлетворяющая условиям теоремы II) такая, что b − a = p. Проверьте это для первых 15 проигрывных позиций, перечисленных в таблице II.

6. Докажите, что если позиция (b, a) в игре «изяныццы» не удовлетворяет условиям теоремы II, то играющий своим ходом может либо сразу выиграть, либо вести позицию к проигрывной.

7. Докажите, что если позиция (a, b) в игре «изяныццы» является проигрывной, то после любого хода играющего она перестает быть таковой.

8. Укажите правильная игре в церем «изяныццы», если число кучек нечетно (играющий каждым своим ходом имеет право взять любое число спичек из каждой-то одной кучки, либо поровну — и тоже любое число! — из всех кучек).
