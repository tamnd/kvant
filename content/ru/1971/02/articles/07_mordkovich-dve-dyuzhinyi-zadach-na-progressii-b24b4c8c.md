ДВЕ ДЮЖИНЫ
ЗАДАЧ НА ПРОГРЕССИИ

Для успешного решения задач на программирование нужно знать определения арифметической, геометрической и бесконечно убывающей геометрической программы, формулу обещено члена для каждой из этих программы, формулы суммы $n$ членов программы, а также определение и формулу суммы членов бесконечно убывающей геометрической программы. Кроме того, очень часто в задачах на программирование приходится использовать так называемые характические свойства программы. Опыт вступительных экзаменов показывает, что если с формулиами $n$-х членов и суммы $n$- членов программы дело обстоит сравнительно неплохо, то этого нельзя сказать о характических свойствах. Поэтому прежде всего мы остановимся на этих свойствах.

Характические свойства арифметической программы

Последовательность $a_1, a_2, \dots, a_n$, ... является арифметической программы моеda и molко моеda, когда каждый ее член, кроме первого (и последнего, в случае конечной последовательности), равен среднему арифметическому своих соседних.

Доказательство. Дана последовательность $a_1, a_2, \dots, a_n$, ... Пусть она является арифметической программы. Докажем, что $a_{k+1} = \frac{a_k + a_{k+2}}{2}$ ($k = 1, 2, 3, \dots$).

В самом деле, $a_{k+1} - a_k = a_{k+2} - a_{k+1}$, откуда $a_{k+1} = \frac{a_k + a_{k+2}}{2}$.

Пусть теперь $a_{k+1} = \frac{a_k + a_{k+2}}{2}$. Тогда $a_{k+1} - a_k = a_{k+2} - a_{k+1}$, то есть разность между последующим и предыдущим членами последовательности постоянна для данной последовательности, а это и означает, что $a_1, a_2, \dots, a_n$, ... — арифметическая программа.

Характические свойства геометрической программы

Последовательность $b_1, b_2, \dots, b_n$, ... является геометрической programma моеda и molко моеda, когда каждой ее член, кроме первого (и последнего, в случае конечной последовательности), равен произведению своих相邻 (то есть $b_2^{k+1} = b_k \cdot b_{k+2}$).

Доказательство. Пусть последовательность $b_1, b_2, \dots, b_n$, ... является геометрической programma. Тогда $\frac{b_{k+1}}{b_k} = \frac{b_{k+2}}{b_{k+1}}$, откуда $b_2^{k+1} = b_k \cdot b_{k+2}$, что и требовалось доказать.

Пусть, наоборот, $b_2^{k+1} = b_k \cdot b_{k+2}$. Тогда $\frac{b_{k+1}}{b_k} = \frac{b_{k+2}}{b_{k+1}}$, то есть отношение членов последовательности к предыдущему постоянному для данной последовательности, а это и означает, что $b_1, b_2, \dots, b_n$, ... — геометрическая программа.

Арифметическая прогрессия

Задание 1. Доказать, что $\frac{1}{a_1 a_2} + \frac{1}{a_2 a_3} + \dots + \frac{1}{a_n a_{n+1}} = \frac{n}{a_1 a_{n+1}}$.

Решение. $\frac{1}{a_1 a_2} = \frac{d}{a_1 a_2 d} = \frac{1}{d} \frac{a_2 - a_1}{a_1 a_2} = \frac{1}{d} \left( \frac{1}{a_1} - \frac{1}{a_2} \right)$. Аналогично

$$\frac{1}{a_2 a_3} = \frac{1}{d} \left( \frac{1}{a_2} - \frac{1}{a_3} \right), \dots, \frac{1}{a_n a_{n+1}} = \frac{1}{d} \left( \frac{1}{a_n} - \frac{1}{a_{n+1}} \right).$$

Позному

$$\frac{1}{a_1 a_2} + \frac{1}{a_2 a_3} + \dots + \frac{1}{a_n a_{n+1}} = \frac{1}{d} \left( \frac{1}{a_1} - \frac{1}{a_2} \right) +$$

$$+ \frac{1}{d} \left( \frac{1}{a_2} - \frac{1}{a_3} \right) + \dots + \frac{1}{d} \left( \frac{1}{a_n} - \frac{1}{a_{n+1}} \right) = \frac{1}{d} \left( \frac{1}{a_1} - \frac{1}{a_{n+1}} \right) =$$

$$= \frac{1}{d} \frac{a_{n+1} - a_1}{a_1 a_{n+1}} = \frac{1}{d} \frac{a_1 + dn - a_1}{a_1 a_{n+1}} = \frac{n}{a_1 a_{n+1}}.$$

Задание 2. Последовательность $u_1, u_2, \dots, u_n, \dots$ обладает тем свойством, что сумма $S_n$ первых ее $n$ членов равна $2n^2 + 3n$. Доказать, что эта последовательность является арифметической прогрессей.

Решение. Используя характеристическое свойство арифметической прогрессии, заключаем, что нам достаточно доказать следующие соотношения: $2u_{k+1} = u_k + u_{k+2}$, где $k=1, 2, 3, \dots$.

Замечаем, что $u_{k+1} = S_{k+1} - S_k$. В самом деле, $S_{k+1} - S_k = (u_1 + u_2 + \dots + u_k + u_{k+1}) - (u_1 + u_2 + \dots + u_k) = u_{k+1}$. Значит,

$$u_{k+1} = [2(k+1)^2 + 3(k+1)] - (2k^2 + 3k) = 4k + 5.$$

Аналогично $u_k = S_k - S_{k-1}$ (в частности, полагаем $S_0 = 0$), откуда $u_k = (2k^2 + 3k) - [2(k-1)^2 + 3(k-1)] = 4k + 1$ и, наконец, $u_{k+2} = S_{k+2} - S_{k+1} = 4k + 9$. Поскольку для чисел $u_k = 4k + 1$, $u_{k+1} = 4k + 5$, $u_{k+2} = 4k + 9$ соответственно $2u_{k+1} = u_k + u_{k+2}$ выполняется, то доказательство того, что $u_1, u_2, \dots, u_n, \dots$ — арифметическая прогрессия, законено.

Задание 3. Доказать, что для арифметической прогрессии справедливо соотношение $\frac{S_n}{n} (m - p) + \frac{S_m}{m} (p - n) + \frac{S_p}{p} (n - m) = 0$.

Решение. Используя для $S_n$ известную формулу $S_n = \frac{a_1 + a_n}{2} n$ и аналогичные формулы для $S_m$ и $S_p$, приведем левую часть доказываемого равенства к виду

$$\frac{a_1 + a_n}{2} (m - p) + \frac{a_1 + a_m}{2} (p - n) + \frac{a_1 + a_p}{2} (n - m).$$

Приименив к $a_n$ формулу общого члена арифметической прогрессии $a_n = a_1 + d(n-1)$ и сделав то же самое для $a_m, a_p$, получим

$$\frac{1}{2} \left\{ [2a_1 + d(n-1)] (m-p) + [2a_1 + d(m-1)] (p-n) + [2a_1 + d(p-1)] (n-m) \right\}$$

и далее

$$\frac{1}{2} \left\{ 2a_1 [(m-p) + (p-n) + (n-m)] + d [(n-1)(m-p) + (m-1)(p-n) + (p-1)(n-m)] \right\}.$$

Поскольку суммы в обеих квадратных скобках равны 0, то и все выражение равно 0, что и требовалось доказать.

Задание 4. Найти трехзначное число, которое делится на 45 и цифры которого образуют арифметическую прогрессию.

Решение е. Пусть $x$ — цифра сотен, $y$ — цифра десятков и $z$ — цифра единиц искомого числа. Так как по условию $x, y, z$ — арифметическая прогрессия, то

$$2y = x + z. \tag{1}$$

Искомое число имеет вид $100x + 10y + z$. Так как по условию оно делится на 45, то

$$100x + 10y + z = 45p. \tag{2}$$

Итак, искомое число определяется условиями (1) и (2).

Для цифры единиц имеется две возможности: либо $z=0$, либо $z=5$ (это вытекает из делимости искомого числа на 5). Рассмотрим случай $z=0$. Тогда из (1) получаем $x=2y$, а из (2) — $100x + 10y = 45p$, или $20x + 2y = 9p$, $20x + x = 9p$ или $7x = 3p$. Это означает, что $x$ делится на 3. Так как, кроме того, $x$ — число четное ($x=2y$), то заключаем, что для $x$ имеется единственная возможность: $x=6$. Тогда $y=3$, а искомое число равно 630.

Рассмотрим теперь второй случай: $z=5$. В этом случае условия (1) и (2) принимают соответствующее вид:

$$2y = x + 5; 100x + 10y + 5 = 45p.$$

Посленее равенство преобразуется к виду $20x + 2y + 1 = 9p$ и далее, с учетом равенства $2y=x+5$, получаем $21x+6=9p$, или $7x+2=3p$. Посленее равенство возможно при $x=1, 4, 7$. Но поскольку $x+5$ — четное число ($x+5=2y$), то для $x$ остаются лишь две возможности: $x=1, x=7$. В первом случае $y=3$, во втором случае $y=6$. Искомое число соответствующего в первом случае равно 135, во втором 765. Итак, условию задачи удовлетворяют три числа: 135, 630, 765.

**Геометрическая прогрессия**

Задание 5. Вычислить сумму $2 + 22 + 222 + \ldots + 222\ldots 2$

Решение е. $2 + 22 + 222 + \ldots + 222\ldots 2 = 2[1 + (1+10) + (1+10+10^2) + \ldots + (1+10+10^2 + \ldots + 10^{n-1})] = 2[S_1 + S_2 + S_3 + \ldots + S_n]$, где $S_k$ — сумма $k$ членов геометрической прогрессии 1, 10, $10^2$, $10^3$, ... ($k=1, 2, \ldots, n$). Применив формулу $S_k = \frac{b_1(q^k - 1)}{q-1}$ суммы членов геометрической прогрессии, получим

$$2(S_1 + S_2 + S_3 + \ldots + S_n) = 2\left(\frac{10 - 1}{9} + \frac{10^2 - 1}{9} + \ldots + \frac{10^n - 1}{9}\right) = \frac{2}{9}[10(1 + 10 + 10^2 + \ldots + 10^{n-1}) - n] = \frac{2}{9}\left[\frac{10(10^n - 1)}{9} - n\right] = \frac{2(10^{n+1} - 10 - 9n)}{81}.$$

Задание 6. Доказать, что последовательность $u_1, u_2, u_3$, где
$$u_1 = 9, \quad u_2 = 3^{\frac{1}{2}} \text{tg} x, \quad u_3 = \left(\frac{1}{9}\right)^{\cos 2x},$$
является геометрической прогрессей тогда и только тогда, когда
$$x = \pi l, \quad x = \frac{\pi}{12} + \pi l, \quad x = \frac{5\pi}{12} + \pi l \quad (l = 0, \pm 1, \pm 2, \ldots).$$

Решение. На основании характерастического свойства геометрической прогрессии заключаем, что задача свойства к решению уравнения
$$9^{\frac{1}{2}} \text{tg} x = 9\left(\frac{1}{9}\right)^{\cos 2x}$$

Выполним последовательные преобразования этого уравнения:
$$\frac{1}{2} \text{tg} x = 1 - \cos 2x,$$
$$\text{tg} x = 4 \sin^2 x, \quad \sin x (2 \sin 2x - 1) = 0 \quad (\cos x \neq 0).$$
Таким образом, должно выполняться одно из двух уравнений:
$$\sin x = 0, \quad \sin 2x = \frac{1}{2},$$

откуда
$$x = \pi l, \quad x = \frac{\pi}{12} + \pi l, \quad x = \frac{5\pi}{12} + \pi l.$$

Полученные серии и только они удовлетворяют уравнению (3). Следовательно, при полученных значениях $x$ и только при них $u_1, u_2, u_3$ — геометрическая прогрессия.

Задание 7. Могут ли числа 10, 11, 12 быть членами одной геометрической прогрессии?

Решение и е. Предположим, что заданные числа являются членами геометрической прогрессии с первым членом $b_1$ и знаменательем $q$. Тогда $10 = b_1 q^n, 11 = b_1 q^m, 12 = b_1 q^p$. Из этих соотношений получаем
$$\frac{11}{10} = q^{m-n}, \quad \frac{12}{10} = q^{p-n}$$

и далее
$$\left(\frac{11}{10}\right)^{p-n} = \left(\frac{12}{10}\right)^{m-n},$$
$$\frac{11^{p-n}}{12^{m-n}} = 10^{p-m}.$$

Посленее равенство не может выполнять ни при каких попарно различных натуральных $n, m, p$. Это значит, что числа 10, 11, 12 не могут быть членами одной геометрической прогрессии.

Задание 8. Сумма членов бесконечного убивающей геометрической прогрессии равна 9, а сумма квадратов ее членов равна 40,5. Найти первый член и значатель прогрессии.

Решение. Используя формулу $S = \frac{b_1}{1-q}$ суммы членов бесконечного убивающей геометрической прогрессии, получим $\frac{b_1}{1-q} = 9$.

Рассмотрим последовательность $b_1^2, b_2^2, \ldots, b_n^2, \ldots$. Заметаем, что это бесконечно убивающая геометрическая прогрессия с первым членом $b_1^2$ и значательем $q^2$. Тогда сумма членов этой прогрессии определяется формулой $\frac{b_1^2}{1-q^2}$ и равна 40,5.

В итоге задача сводится к решению системы

$$\frac{b_1}{1-q} = 9, \quad \frac{b_1^2}{1-q^2} = 40,5.$$

Из этой системы получаем: $b_1 = 6, \quad q = \frac{1}{3}$.

Смешанные задачи на прогрессии

Задание 9. Найти четые числа, если известно, что первые три из них образуют геометрической прогрессию, последние три — арифметическую прогрессию, сумма крайних чисел равна 21, сумма средних — 18.

Решение. Пусть $a, b, c, d$ — искочные числа; $a, b, c$ — геометрическая прогрессия, значит, $b^2=ac$; $b, c, d$ — арифметическая прогрессия, значит, $2c=b+d$. В итоге приходим к следующей системе уравнения:

$$\begin{cases}
b^2=ac, \\
2c=b+d, \\
a+d=21, \\
b+c=18.
\end{cases}$$

Решив эту систему, получим $a=3, b=6, c=12, d=18$ или

$$a = \frac{75}{4}, \quad b = \frac{45}{4}, \quad c = \frac{27}{4}, \quad d = \frac{9}{4}.$$

Задание 10. При числа образуют геометрической прогрессию. Если второе число увеличит на 2, то полученные числа образуют арифметическую прогрессию. Если затем третье число увеличит на 9, то вновь получится геометрическая прогрессия. Найти эти числа.

Решение. Условия задачи перепишем следующим образом:

$$b_1, b_2, b_3 \text{ — геометрическая прогрессия;}$$
$$b_1, b_2+2, b_3 \text{ — арифметическая прогрессия;}$$
$$b_1, b_2+2, b_3+9 \text{ — геометрическая прогрессия.}$$

Использовав характические свойства прогрессий, получим

$$\begin{cases}
2(b_2+2) = b_1+b_3, \\
(b_2+2)^2 = b_1(b_3+9).
\end{cases}$$
