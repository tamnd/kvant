2. Введем новые неизвестные. Положим
$$u = \sqrt{\frac{\sqrt{x^2+66^2}+x}{x}},$$
$$v = \sqrt{x\sqrt{x^2+66^2}-x^2}.$$
Тогда данное уравнение перепишется в виде
$$u-v = 5.$$ (1)
Заметим теперь, что
$$u \geq 0, \quad v \geq 0$$ (2)
и
$$uv = \sqrt{\frac{\sqrt{x^2+66^2}+x}{x}} \times \sqrt{x\sqrt{x^2+66^2}-x^2} = \sqrt{(\sqrt{x^2+66^2}+x)}\sqrt{\sqrt{x^2+66^2}-x} = \sqrt{x^2+66^2}-x^2 = 66.$$
Посленее уравнение вместе с (1) и (2) дает смешанную систему
$$\begin{cases} uv = 66, \\ u-v = 5, \\ u \geq 0, \quad v \geq 0, \end{cases}$$
которую можно переписать следующим образом:
$$\begin{cases} u(-v) = -66, \\ u+(-v) = 5, \\ u \geq 0, \quad v \geq 0. \end{cases}$$
Вспомним формулы Виета, заменаем что $u$ совпадает с положительным корнем уравнения $x^2-5x-66 = 0$. Таким образом,
$$u = \sqrt{\frac{\sqrt{x^2+66^2}+x}{x}} = 11,$$
откуда
$$\sqrt{x^2+66^2}+x = 121x,$$
а, следовательно,
$$\sqrt{x^2+66^2} = 120x.$$
Отсюда видно, что $x \geq 0$. Возвода в квадрат, получаем уравнение
$$x^2+66^2 = 120^2x^2,$$ (3)
откуда находится:
$$x = \frac{6}{\sqrt{119}}.$$
Мы нашли этот корень, выполняя эквивалентные (при оговориваемых ограничениях) преобразования, а потом проверка не обязательна. С этой задачей справились многое поступавшие, однако много было и таких работ, в которых ответ содержал построение корни, например отрицательный корень уравнения (3).
Еще раз напомним: если при решении уравнения выполняются неэквивалентные преобразования, то проверка найденных корней является составной частью решения задачи, и без этой проверки решения не может быть признано правильным.
3. Допустимыми значениями является только те значения $x$, для которых $-x^2+5x-6 > 0$, то есть $2 < x < 3$, тогда $4 < x^2 < 9$ и $8 < x^3 < 27$, так что $14 < x^3+x^2+x < 39$ и $0 < x^3+x^2+x-14 < 25$. Телерь для основания первого логарифма находится
$$0 < \frac{1}{5}\sqrt{x^3+x^2+x-14} < 1.$$
Следовательно,
$$\log_{\frac{1}{4}}(-x^2+5x-6) > 1,$$
откуда получаем ответ: $2 < x < 2,5$ или $2,5 < x < 3$.
