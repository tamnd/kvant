⟦folio 48⟧

Решение. Полягая $y = \text{tg} x$, мы, как и в предыдущем примере, приходим к квадратному неравенству: $y^2 - (1 + \sqrt{3}) y + \sqrt{3} \leq 0$.
Решая его, получаем, что $1 \leq y \leq \sqrt{3}$. Таким образом, вопрос снова свелся к решению системы неравенств
$$\begin{cases} \text{tg} x \leq \sqrt{3}, \\ \text{tg} x \geq 1. \end{cases}$$

Перiod функция $y = \text{tg} x$ равен $\pi$. Рассуждая так же, как в примере 5, находим сначала для интеграла от $-\frac{\pi}{2}$ до $\frac{\pi}{2}$ следующие значения $x$:
$\frac{\pi}{4} \leq x \leq \frac{\pi}{3}$. Учитывая периодность, получаем окончательный ответ:
$$\frac{\pi}{4} + k\pi \leq x \leq \frac{\pi}{3} + k\pi$$
($k = 0, \pm 1, \pm 2, \dots$).

Все разобраные до сих пор примеры были подобраны так, чтобы в ответах фигурировали «круглы» значения аргументов типа $\frac{\pi}{6}, \frac{\pi}{4}, \frac{\pi}{3}$.

Однако в принципе это совсем не обязательно, так как ответ может быть записан всегда с помощью символов обратных тригонометрических функций. Для использования этого рассмотрим пример, отличнойся от примера 6 лишь значениями числовых коэффициентов.

Пример 7. Решить неравенство $\text{tg}^2 x - 5\text{tg} x + 6 \leq 0$.

Решение. Рассуждая дословно так же, как в примере 6, приходим к системе неравенств
$$\begin{cases} \text{tg} x \leq 3, \\ \text{tg} x \geq 2. \end{cases}$$

Ответ теперь запишется в виде
$$k\pi + \text{arctg} 2 \leq x \leq k\pi + \text{arctg} 3$$
($k = 0, \pm 1, \pm 2, \dots$).

Пример 8. Решить неравенство $12\sin^2 x - 19\sin x + 5 < 0$.

Решение. Полягая $y = \sin x$, получаем квадратное неравенство $12y^2 - 19y + 5 < 0$, откуда $\frac{1}{3} < y < \frac{5}{4}$. Таким образом, неизвестное $x$ должно удовлетворять все шестенные значения $x$. Поэтому фактически нужно решить лишь второе неравенство $\sin x > \frac{1}{3}$. Нетрудно убедиться, что ему удовлетворяют следующие значения $x$:
$$2k\pi + \text{arcsin} \frac{1}{3} < x < (2k + 1)\pi - \text{arcsin} \frac{1}{3}$$
($k = 0, \pm 1, \pm 2, \dots$).

Это и есть окончательный ответ для заданного неравенства. Очень грубой ошибкой будет, если в связи с неравенством $\sin x < \frac{5}{4}$ в «ответе» появится «выражение» $\text{arcsin} \frac{5}{4}$. Так как $\frac{5}{4} > 1$, то символь $\text{arcsin} \frac{5}{4}$ не имеет никакого смысла.

Пример 9. Решить неравенство $\log_2 \sin x < -1$.

Решение. Введем вспомогательное неизвестное $y = \sin x$. Нераевенство тогда примет вид $\log_2 y < -1$.
