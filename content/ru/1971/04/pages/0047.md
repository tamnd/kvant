⟦folio 45⟧

Для того чтобы ответ записьвался как можно короче, желательно исходный интервал длины $l$ выбрать так, чтобы принадлежшие ему решения заполняли в свою очередь какой-то один сплошной интервал. Из рисунка опять-tаки видно, что так будет остоять дело, если в качестве исходного интервала взять, например, интервал от $-\frac{\pi}{2}$ до $\frac{\pi}{2}$. На этом интервале ниже пример $y = 1$ лежат те точки графика, которые соответствуют значениям $x$, удовлетворяющим неравенству $-\frac{\pi}{2} < x < \frac{\pi}{4}$. Поэтому окончательный ответ имеет вид
$$-\frac{\pi}{2} + k\pi < x < \frac{\pi}{4} + k\pi$$
($k = 0, \pm 1, \pm 2, \dots$).

Ответ, таким образом, представляет собой совокупность интервалов, каждой из которых получается при некотором фиксированном значении $k$.

Аналогично обстоит дело и в ответах на все дальнейшие примеры.

Пример 2. Решить неравенство
$$\sin x \geq -\frac{1}{2}.$$

Решение. Рассмотрим график функции $y = \sin x$ (рис. 2). Неравенству $\sin x \geq -\frac{1}{2}$ удовлетворяет те значения $x$, для которых соответствующие точки графика лежат не ниже пунктной прямой $y = -\frac{1}{2}$ (если точка графика лежит на самом этой прямой, то значение $x$ удовлетворяет заданному неравенству, так как оно «не строгое», в нем допускается равенство левой и правой части). Функция $y = \sin x$ имеет период $2\pi$. Поэтому рассмотрим сначала какой-нибудь интервал длины $2\pi$, например интервал от $-\frac{\pi}{2}$ до $\frac{3\pi}{2}$. Из рисунка 2 видно, что неравенству $\sin x \geq -\frac{1}{2}$ в этом интервале удовлетворяют следующие значения $x$: $-\frac{\pi}{6} \leq x \leq \frac{7\pi}{6}$.

Учитывая периодность, получаем ответ:
$$-\frac{\pi}{6} + 2k\pi \leq x \leq \frac{7\pi}{6} + 2k\pi$$
($k = 0, \pm 1, \pm 2, \dots$).

Пример 3. Решить неравенство
$$\cos(3x + 2) > -\frac{\sqrt{2}}{2}.$$

Решение. Введем вспомогательное неизвестное $t = 3x + 2$. Тогда относительно $t$ мы получим неравенство $\cos t > -\frac{\sqrt{2}}{2}$. Так как оно совершенно аналогично неравенству из примеров 1 и 2 (для его решения можно рассмотреть график функции $y = \cos t$), мы сразу ответ для $t$:
$$-\frac{3\pi}{4} + 2k\pi < t < \frac{3\pi}{4} + 2k\pi$$
($k = 0, \pm 1, \pm 2, \dots$).
