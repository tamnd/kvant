На самом деле при использовании симплекс-метода задачу преобразуют, вводя некоторые дополнительные неизвестные, что позволяет с алгебраической точки зрения упростить процессуру решения. Однако для сохранения геометрической наглядности мы не будем этого делать.

Итак, начнем с вершины
$$O = (0, 0, 0),$$

в существовании которого мы уверены, и рассмотрим ребра многогранника $A$, выходящие из этой вершины. Пусть $P$ — второй конец одного из таких ребер. Значение функции
$$f(x) = x_1 + x_2 + x_3$$

в точке $P$ больше, чем в О. Расмотрим теперь все ребра многогранника $A$, выходящие из точки $P$. При движении из точки $P$ по некоторым из этих ребер значение функции $x_1 + x_2 + x_3$ может убивать или оставаться постоянным. Эти ребра мы сразу отбросим и выберем одно из ребер, при движении по которой значение функции $x_1 + x_2 + x_3$ возрастает. Пусть $P'$ — второй конец этого ребра. Значение функции $x_1 + x_2 + x_3$ в вершине $P'$ больше, чем в вершине $P$. Расмотрим все ребра, выходящие из точки $P'$ и выберем какое-нибудь ребро $P'P''$, при движении по которой значение функции $x_1 + x_2 + x_3$ возрастает и т. д.

На каждом шаге мы будем получать вершину многогранника $A$, в которой значение функции $x_1 + x_2 + x_3$ больше, чем в предыдущих. В конце концов мы приедем к такой вершине
$$M = (x_1^0, x_2^0, x_3^0),$$
что при движении вдоль любого ребра, выходшего из этой вершины, значения функции $x_1 + x_2 + x_3$ не будут возникать. Это значит, что плоскость
$$x_1 + x_2 + x_3 = x_1^0 + x_2^0 + x_3^0,$$

опорная к многограннику $A$ и $M$ — одно из решений задачи линейного программирования. Для нахождения других решений нужно найти такие ребра, выходящие из $M$, при движении по которым значение функции $x_1 + x_2 + x_3$ остается постоянным.

Если таких ребер нет, то $M$ — единственное решение задачи.

Если такое ребро одно, то решения задачи — все точки этого ребра. Если ребер два, то решениями служат все точки грани, в которой лежат эти ребра.

Чаще всего из каждой вершины многогранника $A$ исходит три ребра. В этом случае на каждом шаге прощеся приходиться проверять всего два ребра (так как ребро, на котором лежит предыдущая вершина, можно сразу отбросить). Если вдоль общих этих ребер значения функции в двух положениях вершинах и выбрать ту из них, в которой это значение больше. Если из вершины исходит больше число ребер, вдоль которых значения функции в двух положениях вершинах и выбрать ту из них, в которой это значение больше. Если из вершины исходит больше число ребер, вдоль которых значения функции в двух положениях вершинах и выбрать ту из них, в которой это значение больше. Такой способ может оказаться более экономным с вычислительной точкой зрения, так как не требуется предварительно нахождение концов всех ребер, выходящих из данной вершины.
