ВСТУПИТЕЛЬНЫЕ ЭКЗАМЕНЫ
ПО MATЕМАТИКЕ
В МИЭМ
В.А. ТОНЯН

В Московском институте электронного машиностроения на экзамене по математике к построающим предъявляются повышенные требования. Первый экзамен для всех абитриентов — письменная математика.

Мы уже обсуждали на страницах «Кваента» (№ 5, 1970) некоторые вопросы, касающиеся письменного экзамена по математике 1969 года. Здесь я хочу расссказать об экзаменах 1970 года.

Ниже приведится разбор одного варианта с указанием наиболее типичных ошибок, допущенных построению экзамена.

В конце приведется задание письменных экзаменов, предлагавшиеся в 1970 году.

Вариант

1. Данны два треугольника, площадь каждого из которых 50 cm². Основание первого из них на 10 cm больше основания второго. В каждих пределах может изменяться основание первого треугольника, чтобы разность высот треугольников была не менее 5/6 cm?

2. Решить уравнение

$$\sqrt{\frac{x^2+66^2}{x}} - \sqrt{x \sqrt{x^2+66^2}-x^2} = 5.$$

3. Решить неравенство

$$\log \frac{1}{5} \sqrt{x^3+x^2+x-14} \log \frac{1}{4} (-x^2 + 5x - 6) < 0.$$

4. Решить уравнение

$$\sqrt{3+2(2\sin x-\cos 2x)} + \sqrt{3-2(2\sin x+\cos 2x)} = 2.$$

5. В примеру, основанием которого служит ромб с острым углом α, вписан шар радиуса R. Боковые грани примеры наклонены к плоскости основания под углом β. Найти объем примеры.

Разбор задач варианта

1. Обозначим основание первого треугольника через x, тогда основание второго будет x−10, и потому x > 10. (1)

Высота первого треугольника будет $$\frac{50}{x/2} = \frac{100}{x},$$ а второго $$\frac{100}{x-10}.$$

Согласно условиям задачи, учитывая, что $$\frac{100}{x-10} > \frac{100}{x},$$ написем $$\frac{100}{x-10} - \frac{100}{x} \geq \frac{5}{6},$$ а вспомнить условия (1), преобразуем его так:

$$x^2 - 10x - 1200 \leq 0,$$ (2)

⟦folio 52⟧

или
$(x+30)(x-40) \leq 0,$
откуда
$-30 \leq x \leq 40.$
Если учесть теперь ограничение (1), то получаем ответ: $10 < x \leq 40.$
Некоторые абитриенты, решавшие эту задачу, не задумывались о том, что обозначено буквой $x$ и приводили в качестве ответа решение неравенства (2).
2. Введем новые неизвестные. Положим
$$u = \sqrt{\frac{\sqrt{x^2+66^2}+x}{x}},$$
$$v = \sqrt{x\sqrt{x^2+66^2}-x^2}.$$
Тогда данное уравнение перепишется в виде
$$u-v = 5.$$ (1)
Заметим теперь, что
$$u \geq 0, \quad v \geq 0$$ (2)
и
$$uv = \sqrt{\frac{\sqrt{x^2+66^2}+x}{x}} \times \sqrt{x\sqrt{x^2+66^2}-x^2} = \sqrt{(\sqrt{x^2+66^2}+x)}\sqrt{\sqrt{x^2+66^2}-x} = \sqrt{x^2+66^2}-x^2 = 66.$$
Посленее уравнение вместе с (1) и (2) дает смешанную систему
$$\begin{cases} uv = 66, \\ u-v = 5, \\ u \geq 0, \quad v \geq 0, \end{cases}$$
которую можно переписать следующим образом:
$$\begin{cases} u(-v) = -66, \\ u+(-v) = 5, \\ u \geq 0, \quad v \geq 0. \end{cases}$$
Вспомним формулы Виета, заменаем что $u$ совпадает с положительным корнем уравнения $x^2-5x-66 = 0$. Таким образом,
$$u = \sqrt{\frac{\sqrt{x^2+66^2}+x}{x}} = 11,$$
откуда
$$\sqrt{x^2+66^2}+x = 121x,$$
а, следовательно,
$$\sqrt{x^2+66^2} = 120x.$$
Отсюда видно, что $x \geq 0$. Возвода в квадрат, получаем уравнение
$$x^2+66^2 = 120^2x^2,$$ (3)
откуда находится:
$$x = \frac{6}{\sqrt{119}}.$$
Мы нашли этот корень, выполняя эквивалентные (при оговориваемых ограничениях) преобразования, а потом проверка не обязательна. С этой задачей справились многое поступавшие, однако много было и таких работ, в которых ответ содержал построение корни, например отрицательный корень уравнения (3).
Еще раз напомним: если при решении уравнения выполняются неэквивалентные преобразования, то проверка найденных корней является составной частью решения задачи, и без этой проверки решения не может быть признано правильным.
3. Допустимыми значениями является только те значения $x$, для которых $-x^2+5x-6 > 0$, то есть $2 < x < 3$, тогда $4 < x^2 < 9$ и $8 < x^3 < 27$, так что $14 < x^3+x^2+x < 39$ и $0 < x^3+x^2+x-14 < 25$. Телерь для основания первого логарифма находится
$$0 < \frac{1}{5}\sqrt{x^3+x^2+x-14} < 1.$$
Следовательно,
$$\log_{\frac{1}{4}}(-x^2+5x-6) > 1,$$
откуда получаем ответ: $2 < x < 2,5$ или $2,5 < x < 3$.
4. Преобразуем выражение, стоящее под первым радиком:
$$3+2 \quad (2\sin x-\cos 2x) = 3+4\sin x + 4\sin^2x-2 = (2\sin x+1)^2,$$
аналгорично
$$3-2 (2\sin x+\cos 2x) = (2\sin x-1)^2.$$

⟦folio 53⟧

Теперь данное уравнение может быть переписано в виде
$$|2 \sin x+1|+|2 \sin x-1|=2.$$
Легко убедиться, что последнее уравнение удовлетворяется, при том тождественно, только при $|\sin x| \leq \frac{1}{2}$, откуда находится:
$$-\frac{\pi}{6} + \pi n \leq x \leq \frac{\pi}{6} + \pi n$$
$(n=0, \pm 1, \dots)$.

5. Центр $O'$ вписанного шара (рис. 1) является точкой, равноудаленной от всех граней параметров, и потому он лежит на пересечении bicсектриальных плоскостей всех двумя границах углов параметров. Так как диагонали ромба являются bicсектриками его внутренних углов, то плоскости, проходящие через высоту и диагонали, bicсектриальные для двумгрёных углов при боковых ребрах (проверьте это самостояльно). По условию грани равновакlonены к основанию, и потому точка пересечения диагоналей ромба $O'$ является основанием высоты $SO$. Таким образом, центр шара $O'$ лежит на высоте параметров. Перpendикуляр, опущенный из точки $O'$ на боковую границу параметров, лежит в плоскости, проходящей высоту $SO$ и высоту основания $FE$ (FE проходит через точку $O$), — это легко выводится из теоремы о трех перпендикулярах. Теперь из прямогольного треугольника $SOE$ ($O'O = O'O'' = R$, $\Rightarrow SEO = \alpha$) находится
$$SO = OE \mathrm{tg} \beta = R \mathrm{tg} \beta \mathrm{ctg} \frac{\beta}{2}.$$
Высота параметры найдена, осталось определить площадь основания.
Из прямогольного треугольника $OO'E$ ($OO' = R$, $\Rightarrow O'EO = \frac{\beta}{2}$) находится
$$OE = OO' \mathrm{ctg} \frac{\beta}{2} = R \mathrm{ctg} \frac{\beta}{2}.$$
Далее заменаем, что
$$CD = \frac{FE}{\sin \alpha},$$
и потому
$$S_{\text{ромба}} = \frac{FE^2}{\sin \alpha} = \frac{4OE^2}{\sin \alpha} = \frac{4R^2 \mathrm{ctg}^2 \frac{\beta}{2}}{\sin \alpha}.$$
Для объема параметры получаем окончательное ответ:
$$V = \frac{4}{3} R^3 \frac{\mathrm{ctg}^3 \frac{\beta}{3} \mathrm{tg} \beta}{\sin \alpha}.$$

Немного об устном экзамене

Устные экзамены в МИЭМ'e сделаются по билетам. В каждом билете указаны два теоретических вопроса, которые находятся в строго соответствии с «Программой применных экзаменов». Каждый экзаменующийся билет и готовится примерно 45 минут к ответу. После того как он ответил на вопросы билета, ему предлагаются дополнительные вопросы из не вошедших в билет разделов теории и задачи для проверки его умения применять теорию к решению задач. Эти задачи, как правило, не требуют вычислений. Вот примеры таких вопросов и задач с некоторыми замечаниями.

⟦folio 54⟧

1. Если сложить две перiodические десятичные дроби, то будем ли их сумма снова перiodической десятичной дробью?

Объчно следует правильно ответ: «Да, будет, так как перiodическая десятиная дробь — это рациональное число, а сумма двух рациональных чисел снова рациональная».

Это, в общем, верно; стоит лишь оговорить, что может получить не только перiodическая, но и конечная десятиная дробь, например: 0, (3)+0, (6) = 1, так как $\frac{1}{3} + \frac{2}{3} = 1$.

Более трудным оказывается следующий вопрос.

2. Если первая дробь имеет p цифр в перiode, а вторая q цифр, то какой перiod может быть у их суммы?

Объчно без дополнительной помощи абитриент затрудняет дать правильный ответ. Между тем на вопрос «Каков перiod функции f(x)+g(x), если перiod f(x) равен 2π, а перiod g(x) равен 3π?» абитриенты, как правило, дают правильный ответ: «6π». Между тем оба вопроса по сути дела относится к одному и тому же разделу арифметики: наименьшее общее кратное (НОК) и наибольший общий делитель (НОД). Правильный ответ на исходный вопрос: перiod суммы не превосходит НОК чисел p и q.

Предлагаем читательам самим разобрать несколько примеров, когда перiod суммы в точности равен НОК и когда он меньше этого общего кратного.

Более трудным является вопрос о перiode произведения двух перiodических десятичных дробей, из которых первая имеет p цифр в перiode, а вторая — q цифр.

Приведем лишь ответ: перiod произведения не превосходит m (10^n−1), где m — НОК чисел p и q, n — их НОД. Расмотите пример: 0, (1)×0, (1) = 0, (012345679); здесь p = q = 1, перiod произведения составляет 9 цифр.

3. Дано: tg α = a, $\frac{3\pi}{2} < \alpha < 2\pi$.

Найти sin α.

Мне не раз приходимы видеть такое «решение» этого примера. Поступают пшет:

$$\sin^2 \alpha = \frac{1}{1 + \text{ctg}^2 \alpha},$$

откуда

$$\sin \alpha = -\sqrt{\frac{1}{1 + \text{ctg}^2 \alpha}}$$

$$= -\sqrt{\frac{a^2}{1 + a^2}} = -\frac{a}{\sqrt{1 + a^2}},$$

и только после заменения, что если последнее равенство верно, то sin α в IV четверти имеет положительный знак, аbitриент начинает искать ошибку в решении.

4. Определить знак разности

$$\left(\frac{3}{8}\right)^2 \sqrt{2} - 1.$$

В связи с этой задачей возникнет вопрос: что такое $2^{\sqrt{3}}$? Многие абитриенты, подробно расссказывающие о свойствах показательной функции, на этот вопрос ответить не умюют.

5. Решить уравнение $x^4 - 10x^2 + 169 = 0$.

Obviously пусть решение бывают таким.

Обозначим $x^2$ через y, тогда получим уравнение $y^2 - 10y + 169 = 0$, корни которого комплисные. Для определения x, продолжает рассуждать экзаменующейся, нам надо извлечь корень из комплисного числа, а это действие не предусмотрен школьной программиой. На этом основании некоторые абитриенты приходит к выводу, что на вступительных экзаменах предлагаются задачи, решить которые не может тот, кто знает только школьный курс математики. А верно ли такое умозаключение? Можно ли вообще сделать такой вывод, заменить лишь, что какую-то задачу можно решить, применя методы, которые не изучаются в средней школе? Не свидетельствует ли

⟦folio 55⟧

такое умозаключение о незначии его автора того, что не всякое обратное утверждение справедливо?

Вернемся, однако, к нашему биквадратному уравнению.
$$x^4 + 2 \cdot 13 \cdot x^2 + 169 - 36x^2 = 0,$$
откуда
$$(x^2 + 13)^2 - 36x^2 = 0,$$
а это приводит к двум квадратным уравнениям с действительными коэффициентами:
$$x^2 - 6x + 13 = 0, \quad x^2 + 6x + 13 = 0.$$

Попробуйте доказать, что всякое биквадратное уравнение $x^4 + px^2 + q = 0$, где $p^2 - 4q < 0$ указывает выше методом может быть приведено к двум квадратным уравнениям с действительными коэффициентами.

6. Начертим график функции $y = \arcsin(\sin x)$.

Функция определяна на интервале $-\infty < x < \infty$. В силу периодности функции $z = \sin x$ функция $y = \arcsin z$ также является периодической с периодом $2\pi$, и достаточно ее изучить, например, на отрезке $[-\frac{\pi}{2}, 3\pi/2]$.

На отрезке $[-\pi/2, \pi/2]$ sin $y = \sin x$ и $y = x$; если же $\frac{\pi}{2} \leq x \leq \frac{3\pi}{2}, -\frac{\pi}{2} \leq \pi - x \leq \frac{\pi}{2}$ и из равенства sin $(\pi - x) = \sin x$ следует, что $y = \pi - x$. Окончательно график изображен на рисунке 2.
