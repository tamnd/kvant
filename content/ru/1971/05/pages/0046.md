4. По условияю

$$BC = \frac{AB + AC}{2}.$$

(1)

С помощью теоремы синусов найдем

$$AB = BC \frac{\sin C}{\sin \alpha}, \quad AC = BC \frac{\sin B}{\sin \alpha}$$

и подставим в (1). Получим

$$\sin B + \sin C = 2 \sin \alpha,$$

$$\sin \frac{B + C}{2} \cos \frac{B - C}{2} = \sin \alpha.$$

Так как

$$B + C = \pi - \alpha,$$

(2)

то $$\sin \frac{B + C}{2} = \cos \frac{\alpha}{2},$$ и

$$\cos \frac{B - C}{2} = 2 \sin \frac{\alpha}{2}.$$

(3)

Поскольку по условияю $B \geq C$ и, кроме того, $0 < C < \pi, 0 < B < \pi$, то

$$0 \leq B - C < \pi.$$

(4)

Заметая, что $$\sin \frac{\alpha}{2} > 0$$, из условия (2), (3), (4) для определения $B$ и $C$ имеем систему:

$$\begin{cases} B - C = 2 \arccos \left(2 \sin \frac{\alpha}{2}\right), \\ B + C = \pi - \alpha. \end{cases}$$

(5)

Из (5) находится

$$\begin{cases} B = \frac{\pi - \alpha}{2} + \arccos \left(2 \sin \frac{\alpha}{2}\right), \\ C = \frac{\pi - \alpha}{2} - \arccos \left(2 \sin \frac{\alpha}{2}\right). \end{cases}$$

Таким образом, для всех значений $\alpha$, при которых существует треугольник $ABC$, удовлетворяющий всем условиям задачи, величины углов $B$ и $C$ вышесляются по формулам (6).

Исследуем, при каких значениях $\alpha$ задача имеет решение. Из (6) необходимо следует

$$\left| 2 \sin \frac{\alpha}{2} \right| \leq 1.$$

Так как $0 < \alpha < \pi$, то отсюда $0 < \sin \frac{\alpha}{2} \leq \frac{1}{2}$ и, следовательно, $0 < \alpha \leq \frac{\pi}{3}$.

При найденных значениях $\alpha$ величины $A = \alpha, B$ и $C$, определяемые по формулам (6), положительные и в сумме равны $\pi$. Для доказательства этого достаточно проверить условия $C > 0$, либо $0 < \alpha \leq \frac{\pi}{3}$ и, как следует из (6), $B \geq C, \alpha + B + C = \pi$.

Покажем, что $C > 0$ или, согласно (5),

$$\frac{\pi - \alpha}{2} > \arccos \left(2 \sin \frac{\alpha}{2}\right).$$

(7)

Так как cos $x$ на отрезке $0 \leq x \leq \pi$ монотонно убивает, а величины $\frac{\pi - \alpha}{2}$ и arccos $\left(2 \sin \frac{\alpha}{2}\right)$ принадлежат этому отрезку, то, вычисляя косинус от обеных частей неравенства (7), имеем $$\cos \frac{\pi - \alpha}{2} = \sin \frac{\alpha}{2} < 2 \sin \frac{\alpha}{2}.$$

При $0 < \alpha < \frac{\pi}{3}$ это неравенство верно.

Повторив наш рассужждение в обратном порядке, убеждаемся в справедливости неравенства $C > 0$.

Таким образом, треугольник $ABC$ с углами $A = \alpha, B \geq C$ и удовлетворяющий условиям задачи, величины углов $B$ и $C$ вышесляются по формулам (6), $0 < \alpha \leq \frac{\pi}{3}$.

Многие поступавшие, получив систему для определения $B$ и $C$, не смогли ее решить, а нехоторы выписали ответ в виде (6), но не исследовали, при каких значениях $\alpha$ задача имеет решение. Часть абитриентов указали лишь случай равностороннего треугольника

$$\alpha = B = C = \frac{\pi}{3}.$$
