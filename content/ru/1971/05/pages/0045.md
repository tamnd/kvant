⟦folio 43⟧

Разбор задач

1. Заметим, что $0 \leq \cos^2 x \leq 1$ при всех $x$. Тогда с помощью подстановки $\cos^2 x = t$ уравнение приводится к системе:

$$\begin{cases} t^2 - (a - 2)t - 3(a + 1) = 0, \\ 0 \leq t \leq 1, \end{cases}$$

которая имеет решение $t = a + 1$ при $-1 \leq a \leq 0$. Следовательно,

$$\cos^2 x = a + 1,$$

где $-1 \leq a \leq 0$. Отсюда

$$x = \pm \arccos \sqrt{a + 1} + \pi n$$

($n = 0, \pm 1, \pm 2, \dots; -1 \leq a \leq 0$).

Большинство поступавших с решением этой задачи справилось. Часть абитриентов неверно решила уравнение (1), ошибочно полагая, что $\arccos (-\sqrt{a + 1}) = \arccos \sqrt{a + 1}$, и потеряла решение, соответствующие уравнению $\cos x = -\sqrt{a + 1}$. Некоторые абитриенты не указали всех значений $a$, при которых существует решение задачи.

2. Область допустимых значений неизвестного: $x > 0$. Перепишем уравнение в виде

$$|1 + t| = 3 + |2 - t|,$$

где $t = \log \frac{1}{3} x$. Последовательно расстоянием промежутки $t \leq -1, -1 < t < 2, t \geq 2$. При $t \geq 2$ имеем $1 + t = 3 + t - 2,$

то есть уравнение (1) удовлетворяется тогдадействно при всех $t \geq 2$. Далее убеждаемся, что уравнение (1) при $t \leq -1$ и $-1 < t < 2$ не имеет решения. Таким образом, уравнение (1) является все $t \geq 2$. Отсюда $\log \frac{1}{3} x \geq 2$, и с учетом области определения нахождения

$$0 < x \leq 1/9.$$

Некоторые абитриенты, заметив то жество (2), писали, что уравнение удовлетворяется тогдадействно при всех $t$, не учитывая ограничения $t \geq 2$.

3. Пусть $t(u)$ — время движения автоматоля до первого встречи с автоматом. Так как автоматль и автомат выехали одновременно, то справедливо равенство

$$40t + vt = 240.$$

(1)

Автомобиль поверхности через $t + \frac{1}{2}(u)$ после выхода из города $B$ и, следовательно, вернулся в $B$ через $2t + 1(u)$. Автобус после первого встречи прошел $vt(\kappa m)$, затратив на этот путь $\frac{vt}{40}(u)$. Таким образом, Автобусу потребовалось на весь путь от $A$ до $B$ $t + \frac{vt}{40}(u)$. Для того, чтобы автоматль приехал в $B$ раныше, чем автобус, должно выполнять неравенство

$$2t + 1 < t + \frac{vt}{40}.$$

(2)

По условияю автоматоля поверхности, не доезжая до города $A$. Поскольку в момент первого встречи он находится от $A$ на расстоянии $40t(\kappa m)$ и в течение получения путь $\frac{v}{2}$, то это условие приходит к неравенству

$$\frac{v}{2} < 40t.$$

(3)

Объединия (1), (2) и (3), мы приходим к системе:

$$\begin{cases} 40t + vt = 240, \\ 2t + 1 < t + \frac{vt}{40}, \\ \frac{v}{2} < 40t. \end{cases}$$

Из уравнения (1) найдем $t = \frac{240}{v + 40}$ и подставим в неравенства (2) и (3). Совместно решая получающие при этом неравенства относительно $v$, найдем $56 < v < 120$.

С составлением уравнения (1) и неравенства (2) справилось большимство абитриентов, хотя неокоторые из них заменили знак < в (2)
